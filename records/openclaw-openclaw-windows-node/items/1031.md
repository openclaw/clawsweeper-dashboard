## Summary

## What This Changes

Fix Windows Tray persistence so an already-paired gateway reuses its per-gateway Ed25519 device key across reboots instead of requesting pairing again.

## Best Possible Solution

Add a focused Windows regression that pairs once, restarts the Tray process, and proves the key fingerprint and device ID remain stable; then route every identity-file mutation and recovery decision through one atomic, non-destructive persistence contract.
