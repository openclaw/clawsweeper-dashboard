## Summary

## What This Changes

Adds opt-in OpenTelemetry spans and metrics for native tray chat turns, response phases, transcript loading, and lifecycle outcomes, with documentation and regression coverage.

## Best Possible Solution

Adopt a stable, documented, privacy-safe native-chat telemetry contract that remains disabled without a configured endpoint, exports no conversation content or identifiers, and treats gateway trace-context propagation as a separately coordinated protocol enhancement.
