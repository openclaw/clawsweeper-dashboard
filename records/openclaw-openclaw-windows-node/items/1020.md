## What This Changes

The issue requests that `NodeConnector.ForwardIfCurrent` stop invoking connection-event subscribers while `_clientLifecycleLock` is held, without allowing a retired client to publish after replacement.

## Best Possible Solution

Adopt a small, tested dispatch/retirement protocol that lets lifecycle transitions complete independently of subscriber execution while making retirement a barrier for all events from the retired generation; document that invariant at the dispatch seam.
