## What This Changes

Add a bottom-origin virtualizing layout to Reactor chat so it opens at the latest item and follows streaming output only while the user remains at the tail.

## System Context

Reactor hosts the app's chat transcript as a virtualized `ItemsView`. Chat history and streaming updates enter the list layout and scroll controller, which must preserve efficient item realization while producing stable initial positioning and user-controlled navigation.

## Architecture Diagram

flowchart TD
  A[Chat history and streamed updates] --> B[Reactor chat host]
  B --> C[Virtualized item layout]
  C --> D[Scroll and follow policy]
  D --> E[Chat transcript viewport]
  F[User scroll or annotated scrollbar] --> D
  D --> G[Preserved follow or scroll-away intent]

## Best Possible Solution

First characterize current Reactor chat behavior in each host, then implement the smallest supported layout and follow-policy seam that preserves virtualization and user scroll intent, adding direct UI coverage for all four stated navigation scenarios.
