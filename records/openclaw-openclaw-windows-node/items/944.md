## Summary

Keep open: current native chat appears to preserve the selected session only while the FunctionalUI tree stays mounted, while a remount falls back to the provider default session instead of the user's last active session.

## What This Changes

The issue asks native chat to reopen the last active session after closing to tray instead of selecting a different session from the list.

## Best Possible Solution

Persist the user's last selected native chat session and initialize remounted chat surfaces from it, falling back to the gateway default only when that session no longer exists.
