## Summary

The locale-formatting fix is focused and consistent with prior repository behavior, but the default LKG bump is not merge-ready: it points new Setup Engine runs at an OpenClaw release with a documented gateway-start regression, while the PR explicitly lacks live installer and runtime proof.

## What This Changes

The PR makes three compact-number UI formatting paths culture-invariant, updates Setup Engine documentation and comments, and changes the pinned OpenClaw LKG from 2026.6.11 to 2026.7.1.

## Best Possible Solution

Land the invariant-formatting fix with current-head pt-PT visible proof, and advance the LKG only in a dedicated update after fresh-install and upgrade runs demonstrate that the Windows installer completes and the 2026.7.1 gateway starts reliably, or after the upstream regression is fixed.
