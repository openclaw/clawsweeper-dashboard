## What This Changes

This PR adds SHA-256 verification for composed OpenClaw packages before Windows Companion setup installs them, and also changes Gateway setup lifecycle, version-specific command-policy handling, CI, documentation, and regression coverage.

## System Context

The Windows Companion Setup Engine provisions a WSL-based OpenClaw Gateway, configures its node-command policy, and then connects the Tray and Windows node to it. This PR changes both the package selected for setup and the checks that validate package consumption before the Gateway service is installed and started.
