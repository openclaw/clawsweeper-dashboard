## Summary

Current main has useful representative wizard answer-shaping coverage, but the merged work explicitly excludes live channel/provider authentication and CI still lacks a named combination matrix. Because the collaborator author reopened this item and repository policy requires focused onboarding and real gateway-path validation, the broader regression gate remains necessary.

## What This Changes

Add automated regression coverage across the primary setup wizard channel and provider combinations.

## Best Possible Solution

Define a tiered, versioned matrix: hermetic tests for every supported answer shape, plus a small risk-based Crabbox live smoke set covering representative provider-auth and channel-install families, with redacted artifacts and an explicit CI gating policy.
