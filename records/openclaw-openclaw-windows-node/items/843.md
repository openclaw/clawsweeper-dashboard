Current main now defaults first-run setup to installing a local gateway in WSL and includes a substantially redesigned onboarding flow, but this collaborator-authored issue remains necessary because its parent epic explicitly targets a local Windows gateway and still lists this outcome as incomplete. The merged WSL work is meaningful partial progress, not high-confidence evidence that the broader no-manual-step Windows-local golden path is finished.

## What This Changes

Make first-run onboarding default to the local gateway and end with a working node without manual steps.

## Best Possible Solution
