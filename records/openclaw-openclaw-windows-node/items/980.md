## What This Changes

Restore a session’s default reasoning behavior after “off” is selected and make the reasoning picker follow coherent gateway model capabilities.

## Best Possible Solution

Define one gateway contract in which model metadata, accepted patch values, and clearing an override agree; then expose a visible Default/Restore option in WinUI that clears the explicit level and surfaces any gateway rejection instead of silently retaining `off`.
