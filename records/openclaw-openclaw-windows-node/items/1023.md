## Summary

Keep this PR open for normal merge review: current main still lets `CloseWebSocketAsync` bypass the semaphore used by `SendRawAsync`, while this branch closes that race with focused real-transport coverage. No actionable patch defect was identified.

## What This Changes

The PR serializes graceful WebSocket close operations with active sends and adds deterministic loopback regression tests for ordering and disposal cancellation.

## Best Possible Solution

Retain one semaphore boundary for all outbound WebSocket operations so an in-flight send completes before graceful close begins, with cancellation remaining tied to client disposal.
