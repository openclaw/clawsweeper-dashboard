## Summary

This PR should remain open but is not ready to merge: the real collector evidence validates gRPC, while the advertised OTLP/HTTP mode cannot send all three signals to standard signal-specific endpoints, and the long-term telemetry/privacy contract still requires maintainer approval.

## What This Changes

Adds persisted opt-in OTLP endpoint and protocol settings, a WinUI diagnostics surface, long-lived trace, metric, and log exporters, shared telemetry helpers, localization resources, dependencies, and tests.

## Best Possible Solution

Treat an HTTP configuration as a collector base URL and derive separate `/v1/traces`, `/v1/metrics`, and `/v1/logs` endpoints, add current-head WinUI and collector proof for every supported protocol, and document and enforce a narrow non-sensitive telemetry contract before exposing the shared API broadly.
