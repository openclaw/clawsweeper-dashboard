This detailed, maintainer-authored issue should remain open: the requested Gateway presentation contract, privacy-bounded fallback titles, and explicit background-session navigation are not proven implemented on the supplied current main, and no canonical open or merged fix owns the work.

## What This Changes

## Best Possible Solution

Introduce a typed session-presentation projection that consumes structured Gateway presentation, agent, grouping, and lineage fields first; retain the opaque key only for identity/actions, add privacy-bounded compatibility fallbacks, and drive a clearly labeled background-session view from structured classification.
