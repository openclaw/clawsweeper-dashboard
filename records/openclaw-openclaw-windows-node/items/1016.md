## What This Changes

The branch classifies cleanly completed gateway sessions as completed chat threads and filters those threads from the Chat composer session picker while retaining non-clean terminal sessions.

## Best Possible Solution

Merge this focused reuse of `SessionVisibilityFilter.IsCleanCompleted` after the remaining required CI checks pass, preserving the existing Sessions-page toggle and keeping aborted, failed, killed, timeout, unknown, running, and suspended sessions visible.
