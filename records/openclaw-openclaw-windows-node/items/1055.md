## What This Changes

This PR replaces the default FunctionalUI native chat host with a Microsoft UI Reactor tree for the chat timeline, composer, keyed virtualized rows, and annotated scrollbar binding.

## System Context

The tray chat page receives snapshots and events from the shared chat data provider, then mounts either the native chat surface or the legacy Gateway WebView. This PR replaces the native rendering layer while preserving provider-driven conversations, voice controls, tool-call visibility, and session actions.
