## What This Changes

This PR replaces the default native FunctionalUI chat page and pop-out host with a Microsoft UI Reactor renderer, adds Reactor timeline and slash-command components, and updates related chat settings, session filtering, and tests.

## System Context

The tray app receives gateway-backed chat snapshots through a shared provider, then renders the selected session in the main chat page or a pop-out window. This PR swaps the native renderer while retaining the provider, host callbacks, session state, voice controls, attachments, and persisted display settings.
