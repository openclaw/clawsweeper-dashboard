## What This Changes

Fix GitHub Copilot device authorization so completed browser authentication is detected promptly instead of advancing only after the device code expires and the gateway is restarted.

## Best Possible Solution

Make completed Copilot browser authorization advance immediately, prevent an expired code from silently succeeding through stale credentials, and provide in-product Retry, credential-status, and gateway-restart recovery so first-time users do not need terminal knowledge or a 15-minute wait.
