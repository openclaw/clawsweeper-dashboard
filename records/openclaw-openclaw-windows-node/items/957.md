## Summary

Keep this reopened issue open: the v0.6.12 first-use WhatsApp pairing path remains credibly blocked, no merged fix or canonical replacement is linked, and the prior source review found that Windows offers QR linking when the connected gateway has no loaded web-login provider, then exposes an internal exception rather than actionable recovery.

## What This Changes

Fix WhatsApp pairing on Windows x64 so users can link an account successfully or receive an actionable in-product recovery path.

## Best Possible Solution

Make WhatsApp pairing capability-driven: verify the connected gateway exposes the required web-login provider before enabling QR linking, complete normal pairing when available, and otherwise show a Doctor/Fix flow that diagnoses provider loading and gives gateway-appropriate recovery without exposing an internal exception.
