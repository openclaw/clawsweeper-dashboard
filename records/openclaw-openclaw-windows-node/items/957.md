## Summary

This is a valid release blocker that remains on current main: Windows advertises WhatsApp QR linking even when the pinned gateway has no loaded web-login provider, then exposes an internal exception instead of a usable recovery path.

## What This Changes

Repair WhatsApp QR pairing when the connected gateway lacks the required loaded WhatsApp channel plugin.

## Best Possible Solution

Ensure managed gateways install and load the supported WhatsApp provider, detect provider availability before or during Show QR, and offer an explicit in-product Doctor/Fix or guided install-and-refresh path with real gateway QR proof.
