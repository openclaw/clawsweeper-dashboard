The issue asks for Teams channel setup in the configuration wizard to survive plugin download/install/configuration without timing out or losing previously entered wizard settings.

Land a narrow shared setup-wizard timeout fix that gives slow channel/plugin/install/download/Teams selections the extended budget in both wizard callers, preserves current cancel-before-disconnect recovery, and includes focused regression tests plus redacted Teams-path proof or a documented blocker.
