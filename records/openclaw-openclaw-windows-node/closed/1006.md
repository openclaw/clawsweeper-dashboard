## Summary

Keep this PR open: the current head has credible live proof and substantial regression coverage, but it still introduces an unapproved breaking contract for existing standalone SetupEngine users with safe custom WSL distro names outside the new ASCII 1–64-character grammar.

## What This Changes

The PR adds a centralized WSL distro install-path policy, routes setup cleanup and rollback deletion through it, documents the new ownership boundary, and adds traversal/reparse-point regression tests.

## Best Possible Solution
