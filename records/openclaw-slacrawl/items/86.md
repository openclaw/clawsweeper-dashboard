## What This Changes

The branch adds `provider:<name>` sync sources that run a configured local JSONL archive provider and transactionally import its workspace catalog, messages, and checkpoints into Slacrawl’s SQLite archive.

## System Context

Slacrawl’s sync command collects Slack data from configured sources and writes canonical workspace, message, search-index, and checkpoint records to a local SQLite database. This change adds a local subprocess provider as another explicit source while preserving source-precedence and resume behavior.
