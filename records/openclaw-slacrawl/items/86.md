## What This Changes

Adds an opt-in `provider:<name>` sync source that launches a configured local JSONL archive provider, imports its catalog and messages into Slacrawl's SQLite store, and documents its configuration and protocol.

## System Context

Slacrawl syncs Slack-derived records from several source adapters into one canonical SQLite archive and FTS search index. This PR adds a configured local-provider adapter that feeds the same catalog, message, checkpoint, and source-precedence pipeline.
