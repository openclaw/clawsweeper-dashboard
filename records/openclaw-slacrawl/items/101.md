## What This Changes

The PR adds support for newer Blink-wrapped V8 payloads in Slack Desktop IndexedDB blobs, introduces the `SLACRAWL_V8_RUNTIME` runtime override, documents it, and adds regression coverage.

## System Context

Desktop mode reads Slack Desktop IndexedDB data, locates and decodes serialized Redux state, and merges the recovered workspace records into Slacrawl's local archive. This PR changes the binary-payload detection and external V8 runtime used before decoded data reaches the archive.
