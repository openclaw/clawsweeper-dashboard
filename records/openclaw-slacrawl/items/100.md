## What This Changes

This PR recognizes known V8 v15/v16 Slack Desktop IndexedDB cache framings, adds sanitized decode diagnostics, and turns complete recognized-cache decode failure from a silent empty sync into an error.

## System Context

Desktop-mode sync reads Slack Desktop’s local IndexedDB cache, decodes Redux state through Node, and passes recovered channels, users, messages, and threads into the normal local archive ingestion path. This PR changes the cache-framing recognition and the failure signal that reaches operators when the cache cannot be decoded.
