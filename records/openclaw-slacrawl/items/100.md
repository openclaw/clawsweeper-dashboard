## What This Changes

This PR extends Slack Desktop IndexedDB cache decoding to recognize known v15 and v16 framings, reports decode diagnostics, and fails ingestion when every recognized cache candidate fails instead of silently completing with no decoded messages.

## System Context

Slacrawl’s desktop mode reads a local Slack Desktop profile, decodes Redux data stored in IndexedDB through Node, and ingests the recovered channels, users, messages, and threads into its archive. The changed decoder sits between cache-file discovery and the desktop ingestion pipeline, where decode failures currently become an empty successful sync.
