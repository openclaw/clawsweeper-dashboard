## What This Changes

This PR adds a 202-line GitHub Actions dispatch workflow that forwards issue, comment, and pull-request events from Slacrawl to ClawSweeper for automated review.

## System Context

The new GitHub Actions workflow receives repository issue and pull-request metadata, filters/debounces it, and sends a dispatch request to ClawSweeper. ClawSweeper then uses that request to review the originating repository item and report the result back to GitHub.
