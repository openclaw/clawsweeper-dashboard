## Summary

## What This Changes

This PR expands Slack Desktop IndexedDB cache decoding to support known V8 v15 and v16 framings, exposes decode diagnostics, and turns complete recognized-cache decode failure into an ingestion error instead of an empty successful sync.

## System Context

The Slack Desktop importer snapshots local application data, scans IndexedDB blobs, asks Node to deserialize Redux cache state, then converts the recovered channels, users, and messages into archive rows. A framing mismatch at the blob-decoding stage currently prevents downstream archive ingestion while appearing to succeed.
