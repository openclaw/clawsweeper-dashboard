## Summary

Keep this PR open for collaborator review. The build-contract unification is a coherent change, but it changes bare `make` from building the CLI to printing help and includes a release-owned changelog edit; both should be resolved before merge.

## What This Changes

This PR adds shared Makefile help, check, and snapshot targets, retains `release-snapshot` as an alias, and updates contributor and README command guidance.

## System Context

The Makefile is the local developer entry point for building, testing, linting, and producing credential-free release snapshots. Its targets feed both contributor workflows and the repository’s CI-only release process, so target defaults and aliases affect existing automation as well as documentation.
