## Summary

Keep open: current main has target-checkout and cache groundwork, but it still uses ordinary checkouts and target dependency setup rather than a warmed per-repo workspace with snapshot-forked per-issue isolation; the remaining work needs maintainer architecture direction.

## What This Changes

The issue requests one warmed per-repo workspace that can snapshot-fork isolated clones for each issue worker to reduce repeated setup cost and prevent sibling workspace contamination.

## Best Possible Solution

Define an opt-in warmed workspace lease contract, then integrate it through the cluster worker and fix executor with clear isolation, credential, cache, cleanup, and ordinary-checkout fallback semantics.
