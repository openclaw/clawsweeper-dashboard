## Summary

## What This Changes

Proposes warming one repository workspace and snapshot-forking an isolated prebuilt workspace for each issue worker.

## Best Possible Solution

Provide an opt-in, backend-neutral workspace lease abstraction that creates clean writable forks from a sanitized immutable warm image, with credential isolation, deterministic revision checks, bounded cleanup, cold-clone fallback, and measured setup-time savings.

Rationale: The choice changes Clownfish's infrastructure boundary and must define credential isolation, repository revision freshness, cache ownership, cleanup guarantees, fallback behavior, and acceptable backend coupling before implementation.

- **Keep current provisioning:** Treat existing runner and package-store caching as sufficient and close the proposal without adding a workspace-pool architecture.
