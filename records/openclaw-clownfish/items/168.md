## Summary

Keep open: current main still dispatches isolated per-job workers using ordinary target checkouts; the merged checkout, concurrency, and preflight improvements reduce adjacent costs but do not provide a repository-scoped warmed snapshot pool or per-issue fork leases. This remains a substantive architecture proposal requiring maintainer direction.

## What This Changes

Add a repository-scoped warmed environment that snapshot-forks isolated, prebuilt workspaces for parallel per-issue agents.

## Best Possible Solution

Provide an opt-in Crabbox-backed or runtime-neutral fork-lease backend that warms immutable repository inputs once, injects job credentials only after each fork, guarantees cleanup, and retains ordinary isolated checkout provisioning as the fallback.
