## Summary

Keep open: current main still uses ordinary target checkouts plus dependency/cache reuse, not a warmed per-repo box with snapshot-forked isolated issue workspaces. The merged target-checkout PRs are useful groundwork but only partially overlap this architecture request.

## What This Changes

The issue requests a warmed per-repository workspace that can snapshot-fork isolated checkouts for parallel issue agents instead of cloning, installing, and building per issue.

## Best Possible Solution

Define an opt-in warmed workspace lease backend, then integrate it through the cluster worker and fix executor with explicit isolation, credential, cache, and cleanup semantics.
