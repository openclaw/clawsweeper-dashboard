## Summary

Keep open: current main still uses fresh target checkouts, temporary executor checkouts, worktrees, and dependency caches rather than a warmed repository box that snapshot-forks isolated per-issue workspaces. This is a valid architecture/performance feature request, but it needs maintainer direction before implementation.

## What This Changes

The issue requests warming one repository workspace per target repo and snapshot-forking isolated per-issue agent workspaces for parallel Clownfish runs.

## Best Possible Solution

Define an opt-in warmed workspace lease contract, then integrate it through the cluster worker and fix executor with clear isolation, credential, cache, cleanup, and ordinary-checkout fallback semantics.
