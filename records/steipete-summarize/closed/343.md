## Summary

Keep this open: current main still leaves the reported CLI/core Reddit URL flow on generic HTML/Readability plus optional Firecrawl, while the only Reddit-specific extractor is in the Chrome extension background router.

## What This Changes

The issue asks for reliable CLI extraction of Reddit threads instead of returning Reddit verification/CAPTCHA page content.

## Best Possible Solution

Define the CLI support boundary for Reddit, then either add a core-safe public `.json` extractor with blocked-page diagnostics or fail clearly with guidance to a supported browser/Firecrawl path.
