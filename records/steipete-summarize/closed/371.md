## What This Changes

The PR exposes the options page’s DOM-backed active-tab lookup before Logs and Processes viewers are created, then adds controller and built-extension regression tests for restoring a persisted Logs tab.

## System Context

The Chrome extension options page restores a saved tab while it wires the Logs and Processes viewers. Those viewers query the selected tab to decide whether to refresh, which determines whether the restored panel and daemon-status UI finish loading correctly.
