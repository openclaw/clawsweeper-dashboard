## Best Possible Solution

## Reproduction Assessment

## Solution Assessment

Yes, the proposed code path is the narrow maintainable fix: only expand bare `~` and `~/...`, and derive the metrics provider type from the model-id provider union. The main missing pieces are proof and regression coverage, not a different implementation direction.
