## Summary

Keep this open: current main still lets the CLI URL extraction path treat Reddit's verification/block page as extractable content, while the existing Reddit-specific JSON extractor only covers Chrome-extension page extraction.

## What This Changes

The issue reports that extracting a Reddit thread returns Reddit's verification screen instead of the actual post and comments.

## Best Possible Solution

Handle blocked Reddit CLI extraction explicitly: either add a maintained core-safe Reddit extraction path, or fail with a clear diagnostic that points users to browser/extension extraction or a configured supported fallback instead of summarizing the verification page.

## Reproduction Assessment

Yes, with high confidence from source plus a live network check: the reported Reddit URL and its .json endpoint returned Reddit block content, and current CLI extraction routes that response through generic HTML/readability extraction. I did not run the full CLI because this review is read-only and avoids commands that may create local artifacts.

## Solution Assessment

Unclear: adding a core Reddit .json fallback is plausible, but Reddit is returning a network-security block to unauthenticated requests, so maintainers should choose the supported boundary before implementation.
