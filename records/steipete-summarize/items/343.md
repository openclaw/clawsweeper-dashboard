## Summary

Keep this open: current main still has Reddit-specific extraction only in the Chrome extension router, while the reported CLI/core URL path has no Reddit-aware extraction or explicit verification-page handling. The item also matches the repository’s conservative cleanup policy, so it should remain for maintainer product direction rather than be auto-closed.

## What This Changes

The issue asks for reliable Reddit thread extraction when CLI URL extraction receives Reddit verification or CAPTCHA content instead of the post and comments.

## Best Possible Solution

Handle blocked Reddit CLI extraction explicitly: either add a maintained core-safe Reddit extraction path, or fail with a clear diagnostic that points users to browser/extension extraction or a configured supported fallback instead of summarizing Reddit's verification page.

## Reproduction Assessment

Yes from source inspection: the CLI/core path has no Reddit-specific extractor and routes non-special URLs through generic HTML/readability plus optional Firecrawl. I did not run the full CLI because this review must keep the checkout read-only.

## Solution Assessment

Unclear: a maintained Reddit-specific core extractor may be useful, but the right boundary needs maintainer direction because authenticated browser extraction, developer-token access, Firecrawl, and fail-fast diagnostics have different privacy and support tradeoffs.
