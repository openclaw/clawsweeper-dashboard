## Summary

Keep open: current main still streams raw MiniMax direct-provider content in the Chrome extension, while the existing native MiniMax reasoning split is only wired through the CLI/daemon path. The related merged work in https://github.com/steipete/summarize/pull/250 and https://github.com/steipete/summarize/pull/307 explains the gap but does not close it, and no canonical fix PR is currently open.

## What This Changes

The issue reports that Chrome extension Direct mode with the MiniMax provider shows `<think>` reasoning tags in summary output instead of hiding them.

## Best Possible Solution

Align the Chrome extension MiniMax Direct-provider path with the existing native MiniMax contract by requesting separated reasoning and adding focused extension regression coverage that proves reasoning never reaches visible summary text.

## Solution Assessment

Yes. The narrow maintainable fix is to make the extension MiniMax Direct-provider path follow the existing provider-specific separated-reasoning contract, rather than adding a broad sanitizer for every provider.
