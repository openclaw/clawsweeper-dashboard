## Summary

Keep this PR open. The workflow consolidation is coherent and CI is green, but retiring the existing Cloudsmith APT/RPM publishers can break users who rely on those configured package repositories; that compatibility decision needs an explicit migration or maintainer approval before merge.

## What This Changes

The PR replaces repository-specific release, package-publication, and Homebrew workflows with the shared OpenClaw Go CLI release pipeline, updates release documentation, and disables local publishing commands.

## System Context

Notcrawl’s release subsystem turns a maintainer-selected version into GitHub release assets, Linux packages, signed macOS archives, and a Homebrew formula update. This PR routes that publication path through a shared reusable GitHub Actions workflow while retaining local build and verification diagnostics.
