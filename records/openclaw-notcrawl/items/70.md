## Summary

Keep this PR open for maintainer direction and a compatibility-safe default: it changes established import behavior from replacement to merge, which can leave records that existing users expect a snapshot import to remove.

## What This Changes

The PR makes share imports merge local and snapshot rows by default, adds `--restore` and `--retain-revisions`, and stores tombstone/revision provenance.

## Best Possible Solution

Preserve the established replacement behavior for existing import APIs and CLI defaults, then offer merge retention through an explicit opt-in until maintainers intentionally approve a documented default change with upgrade coverage.
