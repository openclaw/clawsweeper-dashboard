## What This Changes

Make Notion API sync treat unsupported `ai_block` child-fetch validation errors as a warning, continue crawling, and preserve previously synced blocks for the partially traversed page.

## Best Possible Solution

The block walker should classify only Notion's unsupported child-fetch validation response as partial traversal, emit a useful warning, preserve prior page-block data, withhold the page-complete marker, and continue the workspace sync.
