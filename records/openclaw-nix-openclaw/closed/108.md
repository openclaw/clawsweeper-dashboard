## Label Justifications

- `P2`: The report concerns a bounded gateway-network default, but the requested safe behavior is already shipped.
- `impact:security`: Gateway bind defaults determine whether the service is exposed beyond the local host.

## Summary

Current main already provides the requested behavior: the Nix module passes through an omitted `gateway.bind`, and the packaged OpenClaw release defaults that value to loopback while preserving explicit overrides.

## What This Changes

Make gateway `mode = "local"` default `bind` to loopback unless the user explicitly overrides it.

## Best Possible Solution

Keep bind unset when users omit it so the packaged upstream loopback default remains authoritative, while continuing to pass through any explicit bind override.

## Maintainer Decision

Required: false

## Reproduction Assessment

No. On the shipped current configuration path, omitting `gateway.bind` retains the packaged upstream loopback default, so the reported need for a second bind setting does not reproduce.

## Solution Assessment

Yes, the existing solution is preferable: preserving the upstream default avoids duplicating configuration semantics in the Nix module and still respects explicit overrides.
