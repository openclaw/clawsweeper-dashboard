## Summary

Current `main` now packages supported runtime-plugin sources and their dependencies as Nix artifacts, rather than relying on a runtime install into the extension directory. That addresses the immutable-store ACPX failure described here; the narrower writable `pluginInstallDir` option discussion remains open separately.

## What This Changes

The issue requests prebuilding ACPX plugin dependencies into the Nix derivation so gateway startup does not write `node_modules` beneath `/nix/store`.

## Best Possible Solution

Keep supported ACPX/runtime-plugin dependencies in the generated Nix package closure; handle any optional writable plugin-directory configuration through the scoped module work in https://github.com/openclaw/nix-openclaw/issues/110 rather than restoring runtime installs under package paths.
