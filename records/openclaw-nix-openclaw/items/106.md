Ensure ACPX dependencies are built into the Nix package so gateway startup never attempts to install them beneath `/nix/store`.

## Best Possible Solution

Use `programs.openclaw.runtimePlugins = [ "acpx" ];` so Nix provides the generated ACPX artifact; a fresh report should include the exact current configuration, package version, and gateway logs if that supported path still writes beneath `/nix/store`.
