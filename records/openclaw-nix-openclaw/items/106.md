## Summary

Current main already solves the reported immutable-store dependency failure: ACPX is a supported runtime plugin whose npm graph is materialized from shrinkwrap into the Nix artifact, so it no longer depends on a plugin-local runtime install.

## What This Changes

Request that ACPX runtime dependencies be prebuilt into the Nix derivation so gateway startup does not attempt writes under `/nix/store`.

## Best Possible Solution

Keep ACPX on the generated shrinkwrap-backed `runtimePlugins` path and treat any new EACCES report on `v2026.7.1` as a fresh regression with current configuration and gateway logs.
