## Summary

Current-main inspection from the prior review confirms that workspace symlinks can fail the resolved-path root check, but it also found a separate `skills.load.extraDirs` path that may load the original Nix-store skill directories; live runtime inventory is still needed to establish whether `goplaces` is unavailable or this is only duplicate-discovery noise.

## What This Changes

Ensure skills installed by the nix-openclaw Home Manager module remain discoverable when their workspace entries are symlinks into the Nix store.

## System Context

The Home Manager module materializes packaged skills for an OpenClaw workspace, while OpenClaw discovers skill directories and applies a path-containment safety check. The resulting inventory determines which packaged skills are available to the gateway at runtime.
