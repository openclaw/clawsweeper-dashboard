Investigate and fix Nix-managed plugin skills being rejected when workspace links resolve to immutable Nix store paths.

## Best Possible Solution

Confirm the rendered configuration and actual skill inventory first, then either remove redundant workspace-link discovery or generate a merged allowlist containing only the exact resolved skill directories declared by enabled Nix plugins.
