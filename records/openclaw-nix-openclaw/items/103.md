## What This Changes

This PR separates generic runtime-tool PATH generation from Codex app-server handling, adds a Nix-managed Codex launcher that rewrites HOME and profile links, and adds runtime-path checks and documentation.

## Best Possible Solution

Rebase onto current main and preserve upstream HOME semantics by exposing runtime tools through the supported execution-path configuration; if isolated HOME is intentional, add an explicit state migration and collision-safe startup behavior.
