## What This Changes

The PR splits generic OpenClaw runtime-tool PATH generation from a Nix-managed Codex app-server launcher, then uses that launcher to expose `runtimePackages` to Codex `command/exec`.

## Best Possible Solution

Preserve existing Codex user state while making Nix runtime tools available, preferably through an upstream-supported per-agent command-path mechanism; if managed HOME is retained, provide a narrow, tested upgrade/migration behavior and safe handling of pre-existing profile state.
