## Summary

## What This Changes

The PR adds RFC 0018 and three supporting specifications for an opt-in, subject-aware Gateway readiness contract with selectable criteria, reusable core conditions, and bounded plugin observations.

## System Context

Gateway readiness determines whether a running OpenClaw Gateway should accept work. This RFC would place configured core and plugin observations behind one canonical result, which then feeds HTTP readiness endpoints, health/status projections, and the optional CLI.
