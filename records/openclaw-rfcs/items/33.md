## What This Changes

This PR adds RFC 0018 and three supporting specifications for opt-in, subject-aware Gateway readiness conditions, required/advisory evaluation, and bounded plugin-provided observations.

## System Context

The Gateway exposes readiness information to hosts and operators through endpoints and operational status surfaces. This RFC would introduce one canonical evaluator that combines Gateway facts, selected criteria, and plugin observations before projecting the result to those consumers.
