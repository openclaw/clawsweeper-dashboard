## What This Changes

This PR adds RFC 0018 plus three specification documents defining opt-in, subject-aware Gateway readiness conditions, operator-selected requirements, and bounded plugin readiness providers.

## System Context

Gateway readiness turns runtime observations such as startup, drain, channel, and event-loop state into the `/ready` and `/readyz` responses that operators and hosts consume. This RFC would add a canonical result shared by HTTP, health, status, and CLI projections, with optional plugin observations participating only after explicit configuration activation.
