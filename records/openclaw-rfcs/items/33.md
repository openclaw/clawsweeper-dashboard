## What This Changes

The branch adds RFC 0018 and its v1 sidecar specification for opt-in canonical readiness conditions, operator-selected required/advisory criteria, and activation-scoped plugin readiness providers.

## System Context

Gateway readiness feeds the HTTP readiness endpoints that hosts and operators use to decide whether OpenClaw can serve work. The RFC would normalize existing runtime observations and optional plugin observations into one result projected through HTTP, health/status, and a CLI surface.
