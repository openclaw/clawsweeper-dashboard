## What This Changes

Adds RFC 0018 and two normative draft specifications for opt-in, subject-aware Gateway readiness conditions, operator-selected requirements, and bounded plugin readiness providers.

## System Context

Gateway readiness tells hosts and operators whether an OpenClaw Gateway can serve work. This RFC would place a canonical condition evaluator between existing runtime observations and the HTTP, status, and CLI readiness projections, while allowing activated plugins to contribute bounded observations.
