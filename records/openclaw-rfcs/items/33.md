## What This Changes

This PR adds RFC 0018 plus normative readiness and subject-identity specifications for an opt-in, structured Gateway readiness contract with selectable core criteria and bounded plugin providers.

## System Context

The proposed readiness subsystem gathers bounded Gateway and plugin-owned runtime observations, reconciles them into one canonical result, and projects that result to readiness endpoints, health/status views, and an optional CLI command. Operators would opt in through Gateway configuration, while legacy readiness remains the default when no activation is configured.
