## What This Changes

This PR adds RFC 0018 plus two normative sidecars that define opt-in, subject-aware Gateway readiness conditions, operator-selected requirements, and bounded plugin readiness providers.

## System Context

Gateway readiness turns current runtime observations into HTTP, health/status, and CLI readiness results for operators and hosts. This RFC would introduce a common condition result between runtime owners and those output surfaces, with optional plugin-provided observations.
