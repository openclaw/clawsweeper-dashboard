## What This Changes

The PR adds an RFC and two normative specifications for opt-in, subject-aware Gateway readiness conditions, operator-selected requirements, and bounded plugin readiness providers.

## System Context

Gateway readiness determines whether an OpenClaw runtime is ready for traffic. This RFC would let configuration and activated plugins feed a single canonical readiness result that HTTP endpoints, status surfaces, and the CLI can project consistently.
