## What This Changes

The branch revises RFC 0016 and its package and manifest sidecars so a portable Claw manifest can reference a strict, package-local OpenClaw harness profile through a namespaced metadata pointer.

## System Context

RFC 0016 defines the package contract that Claw authors, registries, and OpenClaw use when inspecting and applying agent packages. This addendum separates portable identity and prompt data from OpenClaw-specific settings, which then flow into validation, integrity checks, planning, consent, and host-policy enforcement.

  Profile --> Validation
  Validation --> Plan[Integrity-bound plan and consent]
  Plan --> Policy[Host policy enforcement]
  Policy --> Runtime[Managed OpenClaw agent]
