## Summary

This new draft RFC proposes compatibility- and security-sensitive core contracts. It remains useful, is not implemented in the RFC repository’s current main, and needs explicit maintainer direction plus inspectable runtime proof before acceptance.

## What This Changes

Adds a 348-line draft RFC proposing plugin-gated per-session OpenShell workers, provider-authenticated SSH transport, and optional credential-free worker-local inference.

## Best Possible Solution

Keep the RFC in draft, link its PR metadata and maintainer discussion, add a focused threat model and redacted end-to-end proof, then accept only the smallest provider-neutral contracts maintainers want to support long term.
