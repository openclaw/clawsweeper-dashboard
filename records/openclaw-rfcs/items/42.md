Full review comments:

- **[P2] Preserve script and region locale identities:** `rfcs/0024/localization-runtime-v1-spec.md:46-48`
  - body: Do not define `zh-Hans` as an alias of `zh-CN` or `zh-Hant` as an alias of `zh-TW`. Script tags cover multiple regions, while region tags can require regional wording, so collapsing them prevents the shared registry from representing valid preferences and embeds the semantic problem tracked by https://github.com/openclaw/openclaw/issues/28303. Keep them distinct with explicit fallback and migration rules, or make script tags canonical while retaining region tags as compatibility inputs with recorded provenance.
