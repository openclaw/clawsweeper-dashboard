Keep this draft RFC open for maintainer review: it is a well-developed cross-owner product proposal, but its Gateway, channel locale, plugin metadata, and release-gate contracts require explicit sponsorship before acceptance. The linked implementation stack is still open, so it does not supersede the RFC.

## What This Changes

This draft RFC adds six Markdown documents defining a shared localization runtime, locale-coverage model, localized metadata contract, issue catalog, and staged implementation plan.

## Best Possible Solution

Sponsor a narrowly bounded first localization foundation with named owners and compatibility criteria, then keep Gateway, recipient-locale persistence, plugin metadata, and release-gate commitments as explicitly approved follow-up decisions.
