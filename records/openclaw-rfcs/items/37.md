## What This Changes

The PR adds RFC 0023 and its normative sidecar, defining four opt-in hosting profiles—local, container, reverse-proxy, and node-mode—that compose readiness conditions into named support postures.

## System Context

Hosting profiles sit above the proposed Gateway readiness system: deployment configuration selects a named posture, which adds profile-specific checks to common readiness conditions. The resulting status feeds `/readyz`, operator diagnostics, and release conformance scenarios without changing unprofiled startup.
