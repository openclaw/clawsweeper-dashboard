## What This Changes

Adds RFC 0023 and its normative sidecar specification for four opt-in, release-tested Gateway hosting profiles: local, container, reverse-proxy, and node-mode.

## System Context

This RFC sits above OpenClaw Gateway readiness: operators select an optional named hosting posture through startup/config inputs, which selects a set of readiness conditions and projects a host-visible readiness result. The proposed catalog would affect deployment support contracts, proxy trust assumptions, and release conformance scenarios rather than changing runtime code in this repository.
