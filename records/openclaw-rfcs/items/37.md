## What This Changes

This PR adds RFC 0023 and a normative sidecar defining four optional hosting profiles—local, container, reverse-proxy, and node-mode—that compose readiness conditions into supported deployment postures.

## System Context

Hosting profiles sit above Gateway readiness: startup configuration selects an optional named posture, readiness evaluates its required runtime facts, and `/readyz` reports whether that posture can serve work. The proposal affects deployment support contracts, startup validation, proxy trust checks, and packaged release scenarios rather than ordinary request handling.
