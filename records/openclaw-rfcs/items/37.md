## What This Changes

This draft RFC adds a normative specification for four opt-in Gateway hosting profiles—local, container, reverse-proxy, and node-mode—that compose readiness conditions into release-tested support postures.

## System Context

Gateway startup accepts configuration, environment, and CLI inputs, then exposes readiness and health information to operators and deployment systems. The proposed profile layer would select a named set of readiness conditions and packaged conformance scenarios without changing unprofiled startup.
