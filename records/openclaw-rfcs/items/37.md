## What This Changes

Adds RFC 0023 and a normative sidecar specification for four opt-in OpenClaw hosting profiles—local, container, reverse-proxy, and node-mode—composed from readiness conditions.

## System Context

This RFC repository records OpenClaw design contracts before implementation. The proposed hosting-profile layer would select Gateway readiness conditions from operator configuration and project the resulting status to host-facing readiness endpoints and release conformance scenarios.
