## What This Changes

Adds a draft RFC and normative v1 specification defining four opt-in standard hosting profiles composed over the proposed readiness-condition framework.

## Best Possible Solution

Accept the profiles only after the readiness contract stabilizes, keep selection opt-in, version the standard catalog and predicate changes, obtain explicit security approval for the reverse-proxy trust model, and define ownership of packaged-conformance failures before changing the RFC to accepted.
