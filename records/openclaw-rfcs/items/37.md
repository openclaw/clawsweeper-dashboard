## What This Changes

Adds RFC 0023 and a normative sidecar specification for four opt-in Gateway hosting profiles—local, container, reverse-proxy, and node-mode—composed from readiness conditions.

## System Context

The RFC repository records proposed OpenClaw product contracts before runtime work lands in the main application repository. This proposal would sit on top of Gateway readiness: deployment configuration selects a named hosting posture, readiness evaluates its conditions, and operators receive ordinary readiness and status outputs.
