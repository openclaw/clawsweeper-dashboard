## What This Changes

This PR adds RFC 0023 and a normative sidecar defining four opt-in Gateway hosting profiles that compose readiness criteria into supported deployment postures.

## System Context

Gateway readiness reports whether a running OpenClaw deployment can serve traffic. This RFC proposes an optional layer that selects named readiness criteria for local, container, reverse-proxy, and node-controller deployments, then exposes the resulting support posture through existing readiness surfaces.
