## System Context

Claws package a complete experimental OpenClaw agent and use the canonical lifecycle to inspect, plan, add, update, and remove it. This RFC would feed bounded setup answers and seed templates into that lifecycle, then expose the same server-owned operations through the Control UI rather than introducing browser-owned mutation logic.
