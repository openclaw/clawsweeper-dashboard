## What This Changes

The PR adds RFC 0013 sidecar specifications for multi-component recovery points, host-accepted final handoff, and restore-gated Gateway admission, including a proposed read-only restore-status protocol method.

## System Context

RFC 0013 defines verified SQLite snapshot artifacts owned by OpenClaw. These proposed sidecars sit above that artifact boundary: a host coordinates suspension, accepts an exact recovery point, restores it, and only then allows Gateway work admission.
