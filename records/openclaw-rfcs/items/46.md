## What This Changes

This PR adds draft RFC 0013 sidecars for aggregate recovery-point composition, final host handoff, and recovery-point-bound Gateway admission after restore.

## System Context

RFC 0013 defines how OpenClaw creates and verifies a SQLite snapshot artifact. These proposed sidecars place additional contracts around that artifact so a host can collect owner state, durably accept it, and keep a restored Gateway from taking work before recovery is complete.
