## What This Changes

This PR adds three draft RFC 0013 sidecar specifications for aggregate recovery points, host-protected final handoff, and restore-gated Gateway admission.

## System Context

RFC 0013 defines verified SQLite snapshot artifacts produced by OpenClaw state owners. The proposed sidecars would compose those artifacts with host acceptance and Gateway readiness evidence before a host retires one Gateway generation and admits work on another.
