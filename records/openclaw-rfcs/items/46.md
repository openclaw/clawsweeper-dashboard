## What This Changes

The branch extends RFC 0013 with three draft specifications for aggregate recovery-point composition, host-accepted final handoff, and restore-gated work admission.

## System Context

RFC 0013 defines the application-owned SQLite snapshot boundary used by a host to preserve database state. This PR adds proposed contracts above that boundary so a host can bind owner artifacts, accept a recovery point, and reopen Gateway work only after restoration.
