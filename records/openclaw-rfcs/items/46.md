## What This Changes

This PR adds three draft RFC 0013 sidecar specifications for aggregate recovery points, host-protected final handoff, and readiness-gated restored Gateway admission.

## System Context

RFC 0013 defines verified snapshot artifacts for individual OpenClaw-owned SQLite databases. The proposed sidecars coordinate those owner artifacts with host shutdown, durable handoff, restoration, and the point at which a Gateway can safely accept work again.

## Architecture Diagram

  C --> D[Host durable handoff]

  F --> G[Gateway work admission]

## Best Possible Solution

Either explicitly adopt a narrow optional sidecar boundary that preserves host ownership of ingress, durable acceptance, wake, placement, and destruction, or keep RFC 0013 artifact-only and move lifecycle coordination to a separate RFC.
