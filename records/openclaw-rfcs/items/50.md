## Summary

Keep this RFC open for a maintainer product decision. The author incorporated the concrete review concerns about a runtime tool-identity migration, localization alignment, and CLI-help lifecycle, and the proposal remains a forward-looking contract rather than something already implemented on this repository’s default branch.

## What This Changes

This PR adds RFC 0026, proposing an “Automations” product-name sweep for the cron feature plus locale-aware configurable terminology for user-facing UI, agent prompts, and post-bootstrap CLI output.

## System Context

OpenClaw’s scheduling feature spans agent tools, persisted policy names, CLI output, Gateway-to-Control-UI bootstrap data, and localized UI copy. This RFC would change the presentation and model-visible identity while preserving the underlying scheduler protocol and storage identifiers.

  Gateway --> UI[Control UI labels]

## Best Possible Solution

Accept Phase 1 as an independently shippable terminology migration only with the specified compatibility contract and owner tests, then implement Phase 2 as a separately owner-gated locale-aware terminology setting under the accepted localization model.
