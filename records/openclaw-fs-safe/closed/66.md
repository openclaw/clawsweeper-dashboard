## What This Changes

This PR updates the changelog and security/migration guides to identify direct `resolveRootPath()` helper exposure through v0.4.7 and distinguish it from unaffected `root()` capability handles.

## System Context

fs-safe offers direct root-path resolver helpers as well as `root()` capability handles for guarded filesystem operations. Caller-controlled paths enter either surface; the resolver validates a path while the capability handle carries the confinement boundary into reads, writes, and opens.
