## Summary

Keep this PR open, but do not merge it yet. The updated Node fallback fix is focused and addresses the earlier review findings, yet the Python pinned-write helper still rejects every symlinked directory component with `O_NOFOLLOW`; behavior therefore depends on helper mode, including on normal POSIX installations using `auto` or `require`.

## What This Changes

The PR changes guarded directory creation and fallback pinned writes to accept symlinked directory components that resolve inside the root, while adding containment and error regression tests.

## Best Possible Solution

Implement one containment-preserving symlink-parent contract across both the Node fallback and Python pinned-write helper, then prove successful in-root writes and escaping-symlink rejection with the helper both enabled and disabled.
