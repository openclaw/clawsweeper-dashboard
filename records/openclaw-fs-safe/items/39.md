## Summary

The core bug is real and the fallback-path patch is focused, but the prior P1 blocker remains: the same public write call still rejects in-root symlink parents whenever the default Python helper path is active. The PR also lacks after-fix live runtime proof, so it is not ready to merge.

## What This Changes

The PR changes guarded directory creation and Node fallback pinned writes to accept symlinked directory components that resolve inside the root, and adds focused regression tests.

## Best Possible Solution

Define one containment-preserving symlink-parent contract for pinned writes, implement it consistently in the Node fallback and Python helper, and prove contained success plus outside-root rejection in real helper-enabled and helper-disabled runs.
