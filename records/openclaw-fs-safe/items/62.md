## What This Changes

This PR adds opt-in hardlink rejection and original-content restoration to atomic replacement, and adds sibling-directory staging as an atomic-output mode for externally produced files.

## System Context

`replaceFileAtomic()` is the package’s guarded final-write primitive, taking caller content and publishing it at a destination after temporary staging and optional durability work. `writeExternalFileWithinRoot()` lets an external producer write a staged file under a rooted boundary, then validates and commits it to the requested output path.
