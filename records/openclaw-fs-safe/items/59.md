## What This Changes

Adds the proposed 0.5 release surface: optional native filesystem packages, archive and publication policies, bounded root walking, locks, secret and temp APIs, Windows permission facts, migration docs, and release/CI validation.

## System Context

fs-safe is a Node package that turns a trusted filesystem root into guarded operations for untrusted relative paths. This PR expands the policy layer and its optional native mechanisms, affecting package installation, filesystem mutations, archive extraction, security checks, and release publishing.
