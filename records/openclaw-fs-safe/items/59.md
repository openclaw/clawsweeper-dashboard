## What This Changes

This PR adds archive, exclusive-publication, lock, secret, root-walk, and cleanup APIs while replacing the Python helper path with optional N-API platform bindings and a multi-package release pipeline.

## System Context

`@openclaw/fs-safe` turns a trusted filesystem root into guarded read, write, archive, lock, and cleanup operations for Node applications handling untrusted paths. This PR changes both those runtime boundary primitives and the optional native-package/release path that supplies stronger platform operations.
