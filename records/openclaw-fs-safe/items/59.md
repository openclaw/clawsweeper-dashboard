## Summary

Keep this PR open. It has a concrete P1 security-boundary defect in the new native package loader, and the reported CI results are not after-fix real-behavior proof for this release-scale filesystem change.

## What This Changes

This PR adds archive, publication, locking, secret, walking, and cleanup APIs while replacing the Python helper with optional N-API native bindings and a multi-package release pipeline.

## System Context

`@openclaw/fs-safe` gives Node applications root-bounded filesystem capabilities for untrusted paths. This PR routes public filesystem operations through TypeScript policy code and optional platform-native primitives, then publishes the main package and native platform packages through GitHub Actions.

## Best Possible Solution

Remove the PATH-based `ldd` execution from the native loader, retain deterministic non-executing musl detection or safely fall back, document the Python-to-native upgrade path, and attach redacted live proof of native and fallback behavior before merge.
