## What This Changes

## System Context

`@openclaw/fs-safe` gives Node applications capability-style filesystem roots that constrain untrusted paths. This PR routes archive extraction, guarded writes, locks, secret handling, and publication through either optional native primitives or guarded JavaScript fallbacks, then packages those paths for release.
