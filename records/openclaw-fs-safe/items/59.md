## What This Changes

Adds archive extraction policies and reads, exclusive file publication, synchronous sidecar locks, create-only and async secret helpers, root-bounded walking, and identity-safe temporary cleanup receipts.

## System Context

fs-safe gives Node.js applications guarded filesystem primitives for roots, archives, secrets, locks, and durable writes. Application-controlled paths and untrusted archive metadata enter these APIs, which must preserve confinement, identity checks, and least-privilege filesystem outcomes.
