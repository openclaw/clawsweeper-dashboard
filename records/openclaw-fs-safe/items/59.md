## What This Changes

This branch adds the 0.5.0 filesystem-safety API surface, optional cross-platform native primitives and packages, archive/publication/walking/lock/secret helpers, accompanying tests and docs, and release automation for publishing the native packages.

## System Context

`@openclaw/fs-safe` is a Node.js capability-style filesystem library: applications pass untrusted relative paths into a trusted Root boundary, which validates and performs guarded reads, writes, archive extraction, and cleanup. This PR expands those public operations and optionally delegates low-level platform mechanisms to a lazily loaded native binding while TypeScript retains policy and fallback decisions.
