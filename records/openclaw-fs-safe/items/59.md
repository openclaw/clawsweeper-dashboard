## What This Changes

This PR introduces the 0.5.0 public API surface and optional native filesystem binding, covering archive policy, exclusive publication, synchronous locks, secret-file helpers, bounded root walking, cleanup receipts, Windows permissions, package publishing, and release automation.

## System Context

fs-safe provides Node.js applications guarded filesystem operations for untrusted paths. This PR adds an optional N-API mechanism layer beneath the TypeScript policy layer, then packages and validates that layer across supported operating systems.
