## What This Changes

This PR makes `sanitizeUntrustedFileName()` return its fallback for Windows reserved device basenames, including extension and trailing-dot/space variants, and adds coverage for accepted and rejected names.

## System Context

`sanitizeUntrustedFileName()` converts an attacker-controlled basename into a safe filename used by staging and external-output helpers. The device-path subsystem already recognizes Windows device aliases before filesystem reads; this change applies the same identity rule before a basename is reused for output.
