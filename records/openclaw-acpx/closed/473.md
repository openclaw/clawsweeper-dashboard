## What This Changes

The PR makes structured `argv` arrays the Windows agent-launch contract, migrates compatible config and session data, preserves batch-file argument boundaries through `cmd.exe`, and documents migration from raw commands.

## System Context

acpx resolves a configured or built-in agent into a command, starts it as an ACP subprocess, and persists that launch identity with sessions for reconnects. This PR changes the boundary between configuration/runtime registries and Windows process spawning, affecting one-shot commands, sessions, queues, embedded runtimes, and flows.

  F --> G[Persisted launch identity]

## Best Possible Solution

Adopt the structured argv contract only with explicit maintainer approval, a concise Windows migration path for CLI and embedded-runtime consumers, and redacted real Windows evidence covering a batch wrapper, an explicit `bash` plus `.sh` argv launch, and a persisted-session reconnect or expected recreation failure.
