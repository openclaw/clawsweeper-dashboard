## What This Changes

This PR adds `--no-fs`, a global opt-out that advertises ACP filesystem read/write support as disabled so compatible agents can use their own filesystem implementation.

## System Context

acpx initializes ACP agent connections with client capability declarations, then reuses that setup for direct commands, persistent sessions, queue owners, comparisons, and flow nodes. The new option changes the filesystem capability declared during each new ACP client initialization while leaving the default proxied filesystem behavior unchanged.
