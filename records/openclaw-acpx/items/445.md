## Summary

Current main still suppresses the detached queue owner’s output and reports poll exhaustion without observing an early child failure. The report identifies a narrow, actionable diagnostic bug that remains present after v0.12.0 and should stay open for a focused fix.

## What This Changes

Report actionable queue-owner startup failures instead of reducing early child-process crashes to a generic startup timeout.

## Best Possible Solution

Observe the owner during its bounded startup window, preserve enough stderr or structured startup-error context to identify the failing operation and errno, then release those observation resources once IPC binds so normal detached ownership remains unchanged.
