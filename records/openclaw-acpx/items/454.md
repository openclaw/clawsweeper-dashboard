## What This Changes

This PR adds `acpx agents` and `acpx [<agent>] models` runtime-discovery commands, registers Devin as a built-in agent, and adds related tests and documentation.

## System Context

The CLI resolves global options and agent commands from built-in and configured agent definitions, then starts ACP clients for session operations. This change adds discovery output for that registry and a one-off ACP handshake that reads an agent's currently advertised model metadata.
