## What This Changes

This PR catches rejected best-effort flow-heartbeat writes launched by `setInterval` and adds a regression test that asserts such rejections do not become `unhandledRejection` events.

## System Context

The flows runtime executes workflow nodes and periodically writes live heartbeat state for nodes that are still running. The heartbeat timer feeds the live-run store; rejected storage writes currently escape the timer callback and can surface as process-level unhandled-rejection noise.
