## Summary

This PR remains necessary because current `main` still derives atomic-write temporary names only from the destination, process ID, and millisecond, allowing concurrent saves to collide. The UUID-suffixed helper is a focused correction, the regression test exercises the implicated production store, and the updated after-fix live output satisfies the prior proof request.

## What This Changes

The PR adds a shared UUID-suffixed atomic-write temporary-path helper, applies it to three session persistence writers, adds concurrent-save coverage, and updates the changelog.

## Best Possible Solution

Land the shared per-write unique temporary-path implementation with its deterministic concurrency regression coverage, preserving the existing destination paths and atomic rename behavior.
