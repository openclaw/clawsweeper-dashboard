## Summary

This PR remains necessary: current `main` still constructs session temporary filenames from only destination, PID, and millisecond, so concurrent writes can collide. The proposed shared UUID suffix is a narrow, compatible fix with sufficient real-behavior proof and no actionable patch defect; it is ready for ordinary maintainer review.

## What This Changes

The branch adds a shared UUID-suffixed temporary-path helper for three session persistence writers, a concurrent-save regression test, and a changelog fix entry.

## Best Possible Solution

Merge the shared collision-resistant temporary-path helper with the focused runtime regression coverage, retaining the existing destination path and atomic-rename semantics.

## Maintainer Decision

Required: false

## Reproduction Assessment

Yes at source level: freezing `Date.now()` and issuing concurrent saves makes current `main` select one shared temporary pathname, exposing the rename race. The contributor also supplied direct after-fix production-store evidence.

## Solution Assessment

Yes. A per-write UUID removes temporary-file aliasing while preserving the destination path and atomic-rename contract, and sharing the helper prevents the three writers from drifting.
