## What This Changes

The PR adds a three-state prompt-session banner so a session with no queue-owner lease reports “agent starting,” while a leased but unhealthy owner still reports “agent needs reconnect.”

## System Context

The CLI prints a prompt-session banner before submitting work to a persistent queue owner. Queue-owner health and lease presence determine the banner text, which helps operators distinguish a normal on-demand startup from a failed live owner before the prompt is sent.
