## What This Changes

Adds Poolside’s installed `pool acp` command as the `pool` built-in ACP agent, with registry coverage and synchronized harness documentation.

## System Context

The agent registry maps friendly CLI names to the stdio command that exposes an ACP server. A resolved command is launched by the session runtime, which then creates ACP sessions and carries prompts, tool activity, and results back to the acpx CLI.

## Architecture Diagram

flowchart LR

  Command --> Registry[Built-in agent registry]
  Registry --> Launch[Pool ACP command]
  Launch --> Protocol[ACP stdio session]
  Protocol --> Result[CLI output and session result]

## Best Possible Solution

Accept the exact `pool -> pool acp` built-in only after a maintainer confirms that Poolside is intended to be a durable first-class registry name; otherwise keep the supported per-user agent override path rather than adding a competing built-in convention.
