- **[P1] Stop capture when IPC accepts the task:** `src/cli/session/queue-owner-runtime.ts:540`
  - body: The default path passes `waitForCompletion: true`, so this await does not resolve when the owner socket binds; it resolves after the first prompt completes. Calling `stopStartupCapture()` here therefore retains post-bind stderr for the entire prompt, contrary to the startup-only boundary and potentially captures sensitive runtime diagnostics. Add an IPC acknowledgement hook or split acknowledgement from completion, then stop buffering at that boundary.
  - confidence: 0.98
- **[P1] Drain post-bind stderr instead of closing its pipe:** `src/cli/session/queue-owner-process.ts:324`
  - body: Destroying the parent-side stderr stream closes the only reader while the detached owner remains alive. This re-raises the prior blocker on the unchanged reviewed head.
  - confidence: 0.94
