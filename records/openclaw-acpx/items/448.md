## Summary

Keep this PR open for a narrow repair: the cold-start diagnostics direction is sound and well-proven, but the unchanged current head still leaves the drained stderr pipe referenced after startup, which can prevent a successful no-wait submitter from exiting until the detached owner exits.

## What This Changes

## Best Possible Solution

Keep bounded stderr capture through first IPC acceptance, then continue draining while unrefing the parent-side stderr stream and add a process-level regression test proving the submitter exits while a long-lived owner remains alive and writes post-bind stderr.
