- `P1`: The patch can make ordinary session submissions hang for the queue-owner TTL or indefinitely with `--ttl 0`.

## Summary

The prior IPC-acceptance and EPIPE blockers are fixed at the current PR head, but the replacement drain path leaves the piped stderr handle referenced after startup, so an invocation can remain alive until a long-lived queue owner exits.

## What This Changes

The PR adds bounded queue-owner stderr and exit-state diagnostics during cold start, clearer queue-directory errors, an IPC-acceptance callback, lifecycle tests, and a changelog entry.

## Best Possible Solution

Keep the bounded diagnostic capture and discard-mode draining, but unref the parent-side stderr pipe when startup capture stops and add a subprocess-level exit regression test with a still-running owner.
