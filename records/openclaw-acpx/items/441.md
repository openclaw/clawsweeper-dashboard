## What This Changes

This PR adds synchronous fatal diagnostics for rejected CLI startup and non-EPIPE output-stream errors, then adds focused regression tests for the new exit behavior.

## System Context

The `acpx` CLI starts command execution through its top-level entrypoint and writes user-visible diagnostics to stdout and stderr. This change sits at that process boundary, converting unexpected rejected execution and stream failures into explicit diagnostics and exit statuses.
