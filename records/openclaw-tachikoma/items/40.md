## What This Changes

This PR routes ChatGPT OAuth credentials through the ChatGPT Codex Responses backend, refreshes and persists rotated credentials, and adds vision-request coverage while leaving OpenAI API-key requests on the public Responses API.

## System Context

Tachikoma’s OpenAI Responses provider converts application text, images, and tools into streaming model requests for embedding applications such as Peekaboo. The provider selects credentials and a backend before returning streamed model output as a provider response.
