## Summary

Keep open: the branch does not eliminate the reported non-Node discovery path because unconditionally invoked Node mappers immediately call the new getters, while the regression test expects the existing one-call behavior. Real after-fix runtime proof is also missing.

## What This Changes

The PR converts Node project and Turbo task-graph data in `MapperContext` to memoized async getters and updates four Node-family mappers and mapper tests to consume them.

## Best Possible Solution

Prevent Node-family mappers from requesting shared Node context when existing detection shows no relevant Node workspace, without regressing package-less or monorepo Node discovery, while retaining exactly-once promise memoization for genuine Node consumers.
