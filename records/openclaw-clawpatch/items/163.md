## What This Changes

The branch reorders the review prompt so shared instructions and the JSON output contract precede feature-specific metadata, then tests that distinct features retain an identical shared prefix.

## System Context

Clawpatch builds one provider prompt for each semantic feature found in a repository. The prompt combines shared review policy with project, feature, evidence-path, and file-excerpt context, then the provider returns JSON that Clawpatch validates and uses for review findings.
