## Summary

Current main still performs uncached filesystem operations inside the shared walk helper, and the linked closing PR remains the active unmerged implementation path, so this issue should stay open until that PR lands or is closed.

## What This Changes

Share per-run filesystem reads across concurrent Go, C/C++, and .NET mapper walks to avoid repeated full-root traversal I/O.

## Best Possible Solution

Land one per-map-run shared filesystem cache after the linked PR proves unchanged symlink, skip-filter, and error behavior plus a measurable reduction on a representative large tree.
