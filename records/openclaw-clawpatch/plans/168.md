## Summary

Keep open. This is a concrete reliability bug: a killed local review can leave durable feature state that blocks later reviews until an operator manually clears it; the report provides a focused failure mode and a conservative reclaim rule.

## Plan

Fix stale per-feature lock recovery for `clawpatch review`.
