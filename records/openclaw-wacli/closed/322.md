Keep this collaborator-authored PR open for maintainer review. The self-recipient preflight is a focused response to the linked delivery report, but the branch also edits the release-owned changelog; that hunk should be removed before merge.

## What This Changes

The PR rejects `send text` requests that target the linked WhatsApp account’s own phone-number or LID identity, applies the guard to direct and delegated sends, adds regression tests, and documents the limitation.

## System Context

The `send text` command resolves a WhatsApp recipient and either sends directly or delegates through a running `sync --follow` process. Both routes ultimately dispatch through the WhatsApp client and persist outbound state, so the self-recipient check must prevent unsafe delivery attempts before either protocol dispatch or local message creation.
