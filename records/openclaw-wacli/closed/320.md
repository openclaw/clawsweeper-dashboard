## What This Changes

This PR stores outbound self-chat text under the canonical phone-number JID after resolving a send-time LID, preventing local inbound and outbound self-chat messages from being filed as separate chats.

## System Context

The send command warms up a recipient through WhatsApp identity lookup, sends text to the resolved network JID, and then writes a local chat/message record to `wacli.db`. Incoming sync already normalizes LID identities to phone-number JIDs, so outbound persistence must use the same identity to keep one local self-chat history.
