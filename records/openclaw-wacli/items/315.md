## What This Changes

This PR adds opt-in receipt and chat-presence events to the `wacli sync` webhook while preserving the established message webhook body.

## System Context

`wacli sync` receives live WhatsApp events, stores messages locally, and sends selected events through a bounded asynchronous webhook worker. This change adds receipt and typing-presence event selection to that outbound integration without changing the legacy message payload.
