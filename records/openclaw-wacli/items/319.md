## What This Changes

Ensure that sending text to the linked account’s own phone-number JID reaches WhatsApp’s Message Yourself conversation instead of being sent and stored against a separate LID chat.

## System Context

The CLI resolves a requested WhatsApp recipient before choosing a direct or delegated send socket, then records the outbound message in the local SQLite chat store. A self-recipient resolution mistake can change both the remote delivery target and the local chat identity shown by later `chats` and history commands.
