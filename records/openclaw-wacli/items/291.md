- **[P2] Key retry state by chat and message ID:** `internal/app/media_retry.go:136-148`
  - body: `messages` is unique by `(chat_jid, msg_id)`, but this code stores prepared work, media info, notifications, and ordered retry IDs by `p.MsgID` alone.
