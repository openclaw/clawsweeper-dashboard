## What This Changes

The PR adds an optional `display_title` field to channels, persists and exposes it through the API and SDK, and uses it for human-facing web and embed labels while retaining `name` for routing and uniqueness.

## System Context

ClickClack receives channel create and update requests from users and integrations, stores channel records in SQLite or Postgres, then returns them to the web app, embeds, and SDK clients. This PR inserts a presentation-only title into that path so user-visible labels can differ from the stable slug used for URLs and integration targets.
