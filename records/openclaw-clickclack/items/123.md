## What This Changes

Adds `clickclack reactions add` and `clickclack reactions remove` commands, documents them, and decodes the DELETE-route emoji parameter so escaped reaction values can be removed.

## System Context

ClickClack's agent-friendly CLI turns command-line arguments and authentication options into requests to the API's message and reaction endpoints. The API authorizes the message resource, updates reaction state, emits an event, and returns the event plus reaction summaries to the CLI.
