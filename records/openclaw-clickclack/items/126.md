## What This Changes

Adds an idempotent managed-channel reconciliation endpoint that lets integrations create, update, archive, or reopen one workspace channel for a stable external provider/reference identity across SQLite, PostgreSQL, OpenAPI, and the TypeScript SDK.

## System Context

ClickClack’s channel API accepts workspace-scoped bot or user requests, persists channel records in SQLite or PostgreSQL, and emits durable events for realtime consumers. This PR adds a reconciliation boundary for external integrations that need one stable ClickClack channel per external work item.
