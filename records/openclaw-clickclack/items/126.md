## What This Changes

This PR adds a desired-state reconciliation endpoint that lets integrations create or update one externally managed channel per workspace/provider/reference identity across SQLite, Postgres, OpenAPI, and the TypeScript SDK.

## System Context

External integrations use ClickClack’s HTTP API to create durable collaboration channels. This change adds a provider-scoped identity layer between an integration’s work item and ClickClack’s channel storage, then returns a canonical channel and durable event result to the caller.
