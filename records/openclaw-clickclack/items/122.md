## What This Changes

Add `clickclack reactions add` and `clickclack reactions remove` commands that call the existing public reaction endpoints and support the CLI’s existing human and JSON output conventions.

## System Context

ClickClack’s agent-friendly CLI turns script arguments and resolved authentication into requests to ClickClack’s public HTTP API, then renders machine-readable or terminal-safe output. This change would add reaction mutations to that command-to-API path without changing server reaction semantics.
