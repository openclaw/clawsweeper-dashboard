## What This Changes

This PR lets web users choose an existing topic for a root channel message, shows topic labels in the timeline, and filters paginated channel history by topic through the API, SDK, and both database backends.

## System Context

ClickClack’s web channel view loads root-message pages from the Go API and renders them with realtime updates. The proposed flow selects an existing workspace or channel topic in the composer, persists it with the message, and feeds a topic filter back into the paginated timeline.
