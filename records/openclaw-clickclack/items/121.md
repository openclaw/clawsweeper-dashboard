## What This Changes

This PR lets ClickClack web users assign existing topics to root channel messages, display topic labels, and filter paginated channel history by topic through the API, SDK, and both database backends.

## System Context

ClickClack stores topics alongside channel messages and serves channel history through its Go API. This change carries an optional topic selection from the web composer into message creation, then uses the same topic identity to filter paginated history returned to the timeline.
