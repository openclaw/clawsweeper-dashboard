## What This Changes

This PR lets web users select existing topics for root channel messages, renders topic labels in the timeline, and filters paginated channel history by topic through the API and TypeScript SDK.

## System Context

ClickClack’s channel-message system accepts root messages through the web composer and serves paginated history from the Go API backed by SQLite or PostgreSQL. This change threads an existing topic assignment through message creation, history retrieval, SDK contracts, and the timeline UI.
