## What This Changes

The PR lets web users select existing topics for root channel messages, display topic labels, and filter paginated channel history by topic through the API, generated SDK, and both database backends.

## System Context

ClickClack stores optional workspace- and channel-scoped topics on root channel messages. This change connects those existing records to the web composer and timeline, while the message-list API applies the selected topic consistently across pagination and realtime updates.
