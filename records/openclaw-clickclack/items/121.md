## What This Changes

Adds web composer topic selection, clickable topic labels, server-side topic-filtered message pagination, and matching OpenAPI and TypeScript SDK contracts.

## System Context

ClickClack stores optional workspace- and channel-scoped topics on root channel messages. This PR connects those stored topics to the web composer and timeline, then routes selected-topic history through the existing paginated channel-message API.
