## Summary

Keep this PR open: it has strong real-app proof and a focused feature scope, but it currently mounts edit UI on both the timeline and thread surface for the same root message, contradicting its single-editor requirement. The feature also needs maintainer confirmation that message editing belongs in the ClickClack product surface before merge.

This PR adds author-only inline editing for channel messages and thread roots/replies, including editor controls, client-side state updates, proof documentation, generated web assets, and Playwright coverage.

## Best Possible Solution

Retain one global edit session but pass and enforce its selected surface at every rendering site, then merge only if a maintainer confirms that author message editing is intended product behavior.
