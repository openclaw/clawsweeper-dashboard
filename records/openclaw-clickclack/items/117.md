## System Context

ClickClack stores channel messages in SQLite or PostgreSQL and exposes them through authenticated HTTP APIs, the TypeScript SDK, realtime events, and the embedded web client. This change adds a persisted pin relation that feeds those APIs and UI surfaces and must remain consistent through deletes, exports, and database upgrades.
