## Summary

Keep this PR open: current documentation preserves author-only deletion and DM membership, but the proposed workspace-owner fallback does not retain the private-conversation boundary. The deletion policy needs maintainer confirmation, a DM authorization fix, and stronger live proof before merge.

## What This Changes

The PR lets message authors and workspace owners soft-delete messages, adds channel and thread delete controls and deleted-message placeholders, adjusts related message styling, and rebuilds embedded web assets.

## Best Possible Solution

Preserve author-only deletion and direct-conversation membership for DMs; if owner moderation is approved, scope it explicitly to the intended channel and thread surfaces, update the permission docs, add SQLite, Postgres, and HTTP coverage for private DMs, and provide redacted browser proof of the role matrix.
