## Summary

The feature remains useful, but owner deletion may extend into private DMs, the thread CSS introduces a concrete global-selector collision, and the supplied screenshot does not prove the permission matrix.

## What This Changes

The PR expands soft deletion from message authors to workspace owners, adds delete controls and deleted placeholders in channel/thread UI, updates store and HTTP tests, and rebuilds embedded web assets.

## Best Possible Solution

Define the deletion contract explicitly—prefer owner moderation for workspace channels and threads while keeping DMs author- or participant-scoped—then enforce it in both stores, scope the thread CSS, and prove the full role matrix in a real browser run.
