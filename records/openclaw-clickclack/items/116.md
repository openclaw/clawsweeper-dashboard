## What This Changes

Adds per-channel all, mentions-only, and muted notification preferences, records resolved mention recipients on message events, and applies those preferences to Pushover and browser/desktop alerts.

## System Context

ClickClack creates durable message and thread-reply events in its Go API and delivers them to push and realtime clients. This PR adds per-user channel preferences between event creation and those alerting clients, while exposing the setting through the HTTP API, OpenAPI contract, SDK, and embedded web app.
