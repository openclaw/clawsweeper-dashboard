## What This Changes

## Best Possible Solution

Keep the multi-format viewer architecture, but enforce documented maximum PDF backing dimensions and a total-pixel budget before canvas allocation, accounting for capped device pixel ratio and zoom, then use the existing authenticated download fallback and prove the limit with an oversized-page fixture.
