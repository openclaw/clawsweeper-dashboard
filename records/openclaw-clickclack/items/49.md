## Summary

## What This Changes

Adds an in-app read-only artifact viewer for code, text, Markdown, PDF, DOCX, and uploaded HTML attachments, including responsive UI, parser safeguards, browser tests, documentation, dependencies, and embedded production assets.

## Best Possible Solution

Move syntax highlighting into a terminable worker with elapsed-time limits or use a conservative size threshold with escaped-source fallback, add live diagnostic proof for HTML isolation, and then obtain maintainer acceptance for the supported format set.
