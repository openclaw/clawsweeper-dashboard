## What This Changes

This PR adds an embed-only host theme protocol so channel and thread discussions can apply an initial light or dark mode and receive live, origin-checked palette snapshots without writing changes to standalone user appearance preferences.

## System Context

ClickClack channel and thread embeds run inside a host application such as OpenClaw Control. The host supplies an initial URL mode and later sends a validated palette message; the embedded document applies those values locally while ordinary ClickClack appearance preferences remain the source of truth outside embeds.
