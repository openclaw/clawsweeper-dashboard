## Summary

Current main still allows an interrupted Anthropic thinking block to retain a partial streamed signature in finalized or retained output, while the direct candidate fix closed unmerged for an administrative PR-limit reason. The existing rejection-time retry and transcript rewrite provide defense in depth but do not remove this write-time corruption path, so the focused stability bug remains necessary.

## Plan
