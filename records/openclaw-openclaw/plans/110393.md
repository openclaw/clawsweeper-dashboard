# Coding Plan for openclaw/openclaw#110393: fix: readability extraction handles raw-text pseudo tags

## Summary

Keep this PR open: the revised parser correctly handles several recognized raw-text/RCDATA tags and unclosed recognized elements, but it still omits HTML `<plaintext>`, whose content is raw text through EOF. Pseudo-tags after `<plaintext>` can therefore still inflate the preflight depth and suppress readability extraction.

## Plan

Update `extensions/web-readability/web-content-extractor.ts` so `<plaintext>` is handled as raw text through EOF by the estimated nesting-depth preflight, without weakening the depth guard for real markup or relaxing the bounded start-tag scan. Add a focused regression in `extensions/web-readability/web-content-extractor.test.ts` using an otherwise readable article followed by a large `<plaintext>` pseudo-tag tail; prove readable extraction still succeeds and preserve existing long-tag and malformed-input coverage. Do not add config, change fetch/provider fallback behavior, or edit `CHANGELOG.md` because it is release-owned.
