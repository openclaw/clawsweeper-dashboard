## Summary

Keep open: npm 12’s documented array-only `npm view --json` output conflicts with the current object-only metadata parser, and the reported fallback escalates that compatibility failure by disabling healthy provider plugins and removing activation state.

## Plan

Then change plugin update/update-repair handling so failures occurring before any replacement artifact is installed leave the existing plugin files, `plugins.entries.<id>.enabled`, `plugins.allow`, and install record unchanged. Add focused regression tests for object output, one-element array output, relevant multi-entry output, malformed arrays, and an npm metadata preflight failure against an enabled allowlisted plugin.
