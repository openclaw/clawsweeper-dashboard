Keep open: current main still returns the timer-built cron timeout outcome when the cron watchdog wins, while the cleanup drain does not propagate the embedded Codex missing-tool-result cause back into cron-visible diagnostics.

## Plan

Fix the cron/Codex diagnostics gap for this issue. Preserve the existing cron timeout guard and provider/model/session attribution, but add a narrow handoff so an embedded run terminal error such as incomplete-turn / missing_tool_result can become cron-visible when it is observed before or during timeout cleanup.
