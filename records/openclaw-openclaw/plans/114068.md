## Summary

Keep this PR open: the performance approach is promising and has credible live CLI measurements, but the new probe duplicates config-directory resolution while omitting the supported `OPENCLAW_HOME` route. That can print precomputed root help even when the actual configuration under `OPENCLAW_HOME` changes plugin help. Likely related people: FelixIsaac (prior area contributor; medium confidence).

## Plan

Repair the root-help config fast path without changing its performance goal. Make the probe use the same complete configuration-directory precedence as the live config reader, including `OPENCLAW_HOME`, without importing the heavyweight config facade. Add focused regression coverage where `OPENCLAW_HOME` points to a config whose plugin settings alter root help and verify the live path is used. Preserve the existing dotenv, injected-env, JSON/JSON5, include, and plugin-affecting fallbacks. Related context: https://github.com/openclaw/openclaw/issues/114067 and https://github.com/openclaw/openclaw/pull/85396. Do not edit release-owned CHANGELOG.md.
