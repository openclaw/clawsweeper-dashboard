## Summary

Current `main` still has a source-level mismatch: the documented embedded ChatGPT OAuth path accepts `params.transport: "websocket"`, but the OpenClaw runtime’s WebSocket selector deliberately rejects the ChatGPT backend URL and falls through to the HTTP Responses transport. The earlier legacy-provider fix does not cover this canonical `openai/*` plus explicit OpenClaw-runtime path, so this issue remains necessary.
