## Summary

The PR is a useful and well-evidenced direction, but it still has a merge-blocking security-boundary regression: explicit `tools.fs.roots` are widened by appending the agent workspace after root resolution, so even a deny-all roots policy can still allow workspace-local outbound media reads.

## Plan

Fix PR #52951 so explicit `tools.fs.roots` are terminal for outbound media roots. In `src/media/read-capability.ts`, avoid calling `appendWorkspaceDirToLocalRoots` when `resolveToolFsConfig(...).roots` is defined, including `[]`, except for the existing sandbox path that intentionally ignores configured roots. Preserve legacy/default behavior when no explicit roots are configured. Add focused tests in `src/media/read-capability.test.ts` for `roots: []` plus `workspaceDir` and for a non-empty configured root that must not gain workspace access. Validate with `pnpm test src/media/read-capability.test.ts src/media/local-roots.test.ts` and `git diff --check`.
