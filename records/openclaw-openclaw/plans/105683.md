## Summary

Current main still violates the documented JSON5 editing contract: every normal config mutation prepares the correct semantic object, then replaces the authored document with plain JSON, deleting comments and commented-out settings. No active issue or pull request owns this core fix; the merged `oc-path` work is useful reference for patch-based editing but is plugin-local, JSONC-focused, and does not change canonical config persistence.

## Plan

Fix silent loss of comments and commented-out settings when OpenClaw rewrites `openclaw.json`. Inspect maintained lossless JSON5 editing libraries and adopt one only if its source, license, dependency weight, and tests establish preservation of comments, trailing commas, unquoted keys, single-quoted strings, additions, updates, and removals; otherwise implement a focused core source-mutation helper. Integrate the helper inside the canonical `writeConfigFile` pipeline without importing plugin internals, adding a parallel config/state file, or introducing a config option. Preserve include ownership and routing, environment-reference restoration, managed unset behavior, tilde restoration, metadata stamping, schema/plugin validation, stale-snapshot and config-path conflict checks, clobber detection, audit hashes, backups, file permissions, and atomic replacement. Add focused regression coverage for representative JSON5 syntax, updates, additions, removals, commented-out settings, env refs, includes, and concurrent-write protection. Keep the change focused and do not edit `CHANGELOG.md`.
