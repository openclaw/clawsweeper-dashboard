## Plan

Refresh this PR branch against current main and repair the Gateway custom-scheme origin allowlist fix. Keep `gateway.controlUi.allowedOrigins` configured values exact after trim/lowercase except `*`; do not reparse configured normal URL entries into their origin because values like `https://trusted.example/app` must not start authorizing all of `https://trusted.example`. Reject literal `Origin: null`, malformed origins, unlisted custom origins, and empty-host opaque schemes such as `file:` or `data:`. Preserve host-header fallback, private-same-origin, local-loopback, token/device auth, wildcard behavior, and leave scheme wildcard support to https://github.com/openclaw/openclaw/issues/39739.
