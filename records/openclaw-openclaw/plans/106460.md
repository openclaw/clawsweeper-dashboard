## Summary

Current main still stages a Context Profile preset into the complete editable configuration and submits that whole document through `config.set` or `config.apply`. The supported API already provides `config.patch` for partial writes, so this remains a concrete, bounded bug with no viable canonical fix identified.

## Plan
