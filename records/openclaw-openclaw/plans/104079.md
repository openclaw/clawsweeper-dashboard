## Summary

Current main has a concrete lifecycle gap: backgrounded exec sessions remain live in the bash registry after their originating run settles, but the shared Gateway active-work snapshot has no corresponding count or blocker, so suspension preparation can report ready while that process is still running. This is a narrow, current-main bug in an unreleased core suspension API, not the broader plugin telemetry proposal.

## Plan
