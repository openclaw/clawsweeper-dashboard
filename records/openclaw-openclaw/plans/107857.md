## Summary

This is a valid, narrowly scoped localization regression: the 2026.7.1 Quick Settings surface ships many English literals, and current main still has tests keyed to those untranslated labels. The issue remains necessary because no current-main implementation or linked fix PR covers the new surface.

## Plan

Fix the Quick Settings/Simple settings localization regression described by https://github.com/openclaw/openclaw/issues/107857. Audit the entire Quick Settings renderer and move all user-facing semantic labels, descriptions, statuses, buttons, preset text, avatar messages, and errors into the existing Control UI i18n catalog; reuse existing common keys where appropriate and do not translate model names, configuration keys, enum values, or other technical identifiers without an established catalog convention.
