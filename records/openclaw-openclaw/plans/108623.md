# Coding Plan for openclaw/openclaw#108623: fix(agents): remove empty parent directory on agent delete

Source report: [records/openclaw-openclaw/items/108623.md](records/openclaw-openclaw/items/108623.md)

## Summary

Keep open: the cleanup goal is valid, but the proposed parent deletion is unsafe because `agentDir` is configurable and both trash implementations move an entire directory rather than requiring it to be empty. A custom agent directory can therefore make deletion target an unrelated parent such as the user's home directory. ([docs.openclaw.ai](https://docs.openclaw.ai/start/wizard?utm_source=openai))

## Plan

Repair this PR's agent-parent cleanup without broadening deletion scope. Replace the CLI and Gateway calls that trash `path.dirname(agentDir)` with one shared helper that derives only the canonical per-agent state container, verifies the expected ownership relationship, and removes it only if empty after known child cleanup. Preserve supported custom `agents.list[].agentDir` paths and preserve any unexpected files in the canonical parent. Add regression tests for the default empty parent, a custom agentDir whose parent must never be targeted, and a canonical parent containing an unexpected file. Do not change workspace retention, config pruning, session-store cleanup, Gateway delegation, public flags, or CHANGELOG.md.
