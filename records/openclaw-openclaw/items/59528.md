## Summary

Keep open: current main and the latest release still leave sandbox CLI commands on the default no-plugin startup path, while the bundled OpenShell backend manager is registered only during full plugin activation. The open linked pull request is the active candidate fix, so this issue should wait for maintainer review or landing of that fix rather than be closed or queued again.

## What This Changes

The issue reports that the documented OpenShell sandbox backend path shows OpenShell-backed sandboxes as stopped after setup, even when the sandbox exists in OpenShell.

## Best Possible Solution

Settle the sandbox backend manager activation boundary, then land https://github.com/openclaw/openclaw/pull/87696 or an equivalent scoped fix so sandbox list, recreate, and explain can see OpenShell backend managers before reading OpenShell-backed registry entries.
