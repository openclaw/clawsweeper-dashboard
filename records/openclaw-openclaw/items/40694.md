## Summary

Keep open. Current main and the latest release have browser tab tracking, reset cleanup, subagent/cron lifecycle cleanup, and idle/excess primary-tab sweeps, but they still intentionally keep active primary-session tabs reusable instead of closing run-opened temporary tabs at ordinary task completion.

## What This Changes

The issue requests ownership-aware automatic cleanup of browser tabs or windows opened temporarily for automation tasks after completion.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, close only unpreserved run-owned tabs at a maintainer-approved completion boundary, and keep idle/cap cleanup as the fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent browser tabs opened during ordinary agent runs be closed at run completion by default, and which user actions should preserve a tab?

Rationale: Current main and the latest release intentionally keep active primary-session tabs reusable, so changing the default needs maintainer intent for the terminal event, run-owned marker, and preservation contract.

Likely owner: steipete

Owner reason: steipete has the strongest recent history in primary browser cleanup and peer-scoped reset cleanup, which are the paths this decision would extend.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not foregrounded, pinned, or explicitly requested to be kept.
- **Keep reusable primary tabs:** Treat idle/cap cleanup plus reset cleanup as the supported model and decline task-end closing if it is too surprising.
- **Opt-in strict cleanup:** Preserve current behavior by default while adding a documented strict cleanup mode after the ownership model is defined.

## Reproduction Assessment

Yes. Source inspection shows browser-opened tabs are session-tracked and cleaned by idle/cap sweeps, reset, cron, or subagent lifecycle paths, but ordinary primary-agent task completion has no run-owned cleanup hook.

## Solution Assessment

No for blanket auto-close. The maintainable solution is an ownership-based cleanup model that closes temporary run-created tabs while preserving user-owned or explicitly kept pages.
