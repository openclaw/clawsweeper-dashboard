## Summary

Keep open. Current main has config-validated `browser.tabCleanup`, background idle/cap cleanup, session reset cleanup, cron cleanup, and subagent lifecycle cleanup, but it still does not define ordinary primary-agent task-completion cleanup for run-owned temporary tabs with preservation semantics.

## What This Changes

Browser automation should close temporary tabs/windows opened for one-off tasks after the task completes unless the user explicitly keeps them.

## Best Possible Solution

Implement run-owned temporary-tab tracking for primary-agent browser opens, close eligible run-owned tabs at the primary-agent terminal boundary, preserve user-requested or foregrounded tabs, and keep idle/cap cleanup as the fallback safety net.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should ordinary primary-agent task completion close run-owned temporary browser tabs by default, and which user actions should preserve a tab?

Rationale: Current behavior intentionally keeps active primary-session tabs reusable while background cleanup handles idle/excess tabs, so changing the default needs maintainer intent around the terminal event, ownership marker, and preservation contract.

Likely owner: steipete

Owner reason: steipete authored the current idle cleanup and reset cleanup boundaries most directly related to this product choice.

Owner confidence: high

Options:

- **Run-Owned Cleanup With Preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep Idle/Cap Cleanup Only:** Treat current reusable-tab behavior plus background cleanup as the product choice and close the task-completion direction as not planned.
- **Opt-In Strict Cleanup:** Add a documented opt-in cleanup mode while preserving reusable primary-session tabs by default.

## Reproduction Assessment

Yes, as a source-level reproduction. Browser opens are tracked by session, primary cleanup is idle/cap based, and lifecycle cleanup call sites cover reset, cron, and subagents rather than ordinary primary-agent task completion.

## Solution Assessment

No, a blanket auto-close is not the best shape yet. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
