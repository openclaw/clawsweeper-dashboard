## Summary

Keep open. Current main and v2026.6.11 have tracked-tab idle/cap cleanup plus reset, cron, subagent, and rollover cleanup paths, but they still do not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

Request browser-opened temporary tabs/windows to close automatically after a task completes unless the user explicitly wants to keep them.

## Best Possible Solution

Define a run-owned or agent-owned tab lifecycle in the browser plugin and primary-agent terminal path, preserving user-attached, foregrounded, pinned, or explicitly retained tabs while closing temporary automation tabs.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent browser tabs close at ordinary task completion, and what ownership/preservation contract distinguishes temporary automation tabs from user-owned tabs?

Rationale: Current behavior intentionally keeps primary-session tabs reusable until idle/cap/reset cleanup, and changing that default can surprise users unless maintainers choose the product contract.

Likely owner: steipete

Owner reason: He has the strongest recent history across the current idle cleanup, reset cleanup, and shared browser lifecycle helper surfaces.

Owner confidence: high

Options:

- **Adopt ownership-based cleanup (recommended):** Track run-owned temporary tabs and close only those at primary-agent terminal completion while preserving explicit user-owned tabs.
- **Keep idle/cap cleanup only:** Leave primary tabs reusable and rely on the existing idle and per-session cap cleanup policy.
- **Add explicit opt-in behavior:** Expose task-completion cleanup only behind a deliberate setting or command after proving the existing defaults cannot satisfy users.

## Reproduction Assessment

No live repro was run, but the source path is high-confidence: current main tracks browser-opened tabs by session and only closes them through explicit close, reset/lifecycle cleanup, or idle/cap sweeps. There is no primary-agent ordinary task-completion cleanup hook.

## Solution Assessment

Unclear until maintainers choose the lifecycle contract. A blanket close or new flag alone is not the best fix; the safer direction is ownership-based cleanup that preserves explicit user-owned tabs.
