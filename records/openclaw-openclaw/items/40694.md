## Summary

Keep open. Current main partially addresses browser cleanup through tracked tabs, idle/cap sweeps, and reset/subagent/cron lifecycle cleanup, but it still does not implement ordinary primary-agent task-completion cleanup for temporary tabs.

## What This Changes

Request automatic cleanup of browser tabs/windows opened for temporary automation tasks after task completion while preserving explicitly user-owned pages.

## Best Possible Solution

Add an ownership-based primary-agent tab lifecycle: track tabs created for the current run, close only agent-owned ephemeral tabs at successful task completion, and preserve user-requested, foregrounded, pinned, or externally owned tabs with focused browser and session tests.

Rationale: The code can already close exact session-owned tabs, but choosing a default task-completion cleanup policy changes browser ownership semantics and could close pages users expected to keep.

Options:

- **Adopt ownership-based cleanup (recommended):** Close tabs created by the current primary-agent run after completion while preserving explicitly user-owned or keep-open tabs.
- **Keep idle/cap cleanup only:** Leave current shipped behavior unchanged and rely on background cleanup plus manual close/reset paths.
- **Make task cleanup opt-in:** Add an explicit opt-in mode after defining upgrade-safe config and documentation.

## Solution Assessment

Unclear until maintainers choose the product semantics. The safer direction is ownership-based cleanup rather than blanket tab closing, matching the external FSB comment and current exact-key cleanup design.
