## Summary

Keep open. Current main and v2026.6.11 have tracked-tab idle/cap sweeps plus reset, cron, and subagent lifecycle cleanup, but ordinary primary-agent task completion still lacks run-owned temporary-tab cleanup and needs a maintainer product decision.

## What This Changes

The issue asks for temporary browser tabs or windows opened by automation to close automatically after task completion while preserving user-owned or explicitly retained pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, while the requested default changes browser/session state at task completion and can close user-visible pages if ownership semantics are wrong.

Likely owner: steipete

Owner reason: This decision sits on the browser cleanup helper, session lifecycle, and plugin/runtime ownership boundaries where steipete has the strongest history.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat current reusable primary tabs plus idle/cap cleanup as the intended behavior and close or reject the stronger task-end default.
- **Opt-in strict cleanup mode:** Preserve current behavior by default and add a documented opt-in mode for stricter task-end cleanup.

## Reproduction Assessment

Yes for source-level reproduction: `browser open` tracks tabs by session, while ordinary primary-agent task completion has no ownership-based cleanup hook. I did not run a live browser task in this read-only review.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
