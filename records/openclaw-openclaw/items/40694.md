## Summary

Keep open. Current main still has tracked-tab idle/cap cleanup plus reset, cron, subagent, and ACP lifecycle cleanup, but it does not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

Requests ownership-based cleanup so browser tabs/windows opened only for temporary automation close after task completion while explicitly preserved tabs remain open.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the current idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current product behavior intentionally keeps active primary-session tabs reusable, so changing the default needs maintainer intent around task terminal events, tab ownership, and preservation rules.

Likely owner: steipete

Owner reason: steipete has the strongest recent history on browser tab cleanup and reset-cleanup behavior.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat the current cleanup model as sufficient and close this direction as not planned if task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in cleanup mode while preserving reusable primary tabs by default.

## Reproduction Assessment

Yes. Source inspection shows browser-opened tabs are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary primary-agent task completion has no ownership-based cleanup hook.

## Solution Assessment

No. Blanket auto-close is not the best final shape; the maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
