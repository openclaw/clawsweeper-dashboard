## Label Justifications

- `impact:session-state`: The issue is about browser tab ownership, preservation, and cleanup state after an agent run completes.
- `impact:ux-friction`: Accumulated temporary browser tabs create avoidable clutter and confusion without fully blocking setup or first use.

## Summary

Keep open. Current main has session-tracked browser tabs, idle/cap background cleanup for primary sessions, and explicit lifecycle cleanup for reset/cron/subagents, but it still does not define run-owned temporary-tab cleanup at ordinary primary-agent task completion.

## What This Changes

Request that browser tabs or windows opened temporarily by agent browser automation close automatically after task completion while preserving pages the user explicitly wants to keep.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit user-preserve semantics, and keep idle/cap cleanup as the fallback safety net.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current behavior intentionally keeps active primary-session tabs reusable, so changing the default needs maintainer intent around terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner reason: steipete authored the two current cleanup boundaries most directly related to this product choice.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap cleanup only:** Treat current reusable-tab behavior plus background cleanup as the product choice and close this direction as not planned.
- **Opt-in strict cleanup:** Add a documented opt-in cleanup mode while preserving reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection shows browser-opened tabs are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary primary-agent task completion has no ownership-based cleanup hook.

## Solution Assessment

No. Blanket auto-close is not the best final shape; the maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
