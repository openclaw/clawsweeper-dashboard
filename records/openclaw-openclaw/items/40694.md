## Summary

Keep open. Current main has idle/cap sweeps plus reset, cron, subagent, and gateway-session cleanup paths, but it still does not implement ownership-based closure of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

The issue asks for browser tabs/windows opened only for temporary automation work to close automatically after task completion unless the user explicitly wants to keep them.

## Best Possible Solution

Add an ownership-based primary-agent browser-tab lifecycle that marks run-created temporary tabs and closes them at the maintainer-chosen terminal boundary while preserving user-owned, explicitly requested, foregrounded, or pinned tabs.

## Maintainer Decision

Rationale: Current code has the cleanup primitives, but the requested default changes user-visible browser ownership and can discard useful browser state if the boundary is too broad.

Likely owner: steipete

Owner confidence: high

Options:

- **Add run-owned task cleanup (recommended):** Define a run-owned temporary-tab marker, close only those tabs at the chosen primary-agent terminal event, and keep existing idle/cap/reset cleanup as fallback.
- **Keep idle and reset cleanup only:** Leave the current 120-minute idle sweep, tab cap, reset, cron, and subagent cleanup behavior as the safe default and rely on explicit user/model tab closure for task-level hygiene.
- **Make it opt-in first:** Introduce task-completion cleanup behind an explicit policy flag or debug-safe rollout before making it the default.

## Reproduction Assessment

Yes, by source inspection rather than a live browser run. Current main tracks browser tabs and cleans them on idle, cap, reset, cron, subagent, and gateway-session boundaries, but I found no primary-agent task-completion cleanup path.

## Solution Assessment

Unclear until maintainers choose the ownership contract. The cleanest likely fix is to extend the existing tracked-tab registry with run-owned temporary-tab semantics instead of adding a blanket browser close at every final reply.
