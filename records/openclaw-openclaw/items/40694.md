## Summary

Keep open. Current main has idle/excess cleanup plus reset, cron, delete, and subagent lifecycle cleanup, but it still lacks task-owned cleanup at ordinary primary-agent turn completion; the FSB comment usefully points toward an ownership-preserving design.

## What This Changes

The issue requests automatic cleanup of browser tabs or windows opened only for temporary browser automation work after the task finishes.

## Best Possible Solution

Add an ownership-aware browser-tab lifecycle that marks tabs opened for a task, closes only those tabs after a completed turn, and preserves explicitly focused, user-owned, pinned, or reusable primary-session tabs.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent browser tabs become task-owned and close at ordinary turn completion by default, or should the current idle/cap cleanup remain the primary-session default?

Rationale: Current main intentionally keeps active primary-session tabs reusable and reclaims them by idle/cap policy; changing to completion cleanup is a user-visible default behavior choice with possible surprise-close impact.

Likely owner: steipete

Owner reason: Recent merged work on browser tab reset cleanup and earlier lifecycle cleanup history make this the strongest routing candidate.

Owner confidence: high

Options:

- **Design task-owned cleanup (recommended):** Introduce explicit temporary-tab ownership and close only those tabs after successful turn completion, with preservation rules for user-owned or explicit keep-open tabs.
- **Keep idle/cap cleanup only:** Leave the current 120-minute idle and per-session cap behavior as the primary-session default and close the request only after maintainer confirmation.

## Reproduction Assessment

Yes from source for the remaining feature gap: current main tracks opened browser tabs and runs idle/cap/lifecycle cleanup, but it does not record per-task temporary ownership or close primary-agent tabs on ordinary task completion.

## Solution Assessment

No for a blanket close-all behavior; the best direction is an ownership-based design that closes task-owned tabs while preserving tabs the user explicitly wants to keep.
