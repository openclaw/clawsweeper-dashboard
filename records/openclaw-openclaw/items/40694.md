## Summary

Keep open. Current main and v2026.6.11 have tracked-tab idle/cap sweeps plus reset, cron, and subagent cleanup paths, but they still do not implement task-completion cleanup for temporary primary-agent browser tabs.

## What This Changes

Request automatic cleanup of browser tabs or windows opened only for temporary agent automation after the task finishes, while preserving user-owned or explicitly kept pages.

## Best Possible Solution

Define run-owned temporary browser tabs for primary-agent runs, close only unpreserved run-owned tabs at a maintainer-approved terminal event, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close run-owned temporary browser tabs by default, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, so changing the default needs maintainer intent around task terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner reason: steipete has the clearest recent history on the tracked-tab cleanup implementation and shared browser lifecycle helper.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap cleanup only:** Treat current reusable-tab behavior as the product default and close or defer this issue as not planned.
- **Opt-in strict cleanup:** Add a documented strict cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection shows browser open tracks tabs by session, cleanup is idle/cap or explicit lifecycle-key based, and the docs say primary tabs remain reusable; I did not run a live browser task in this read-only review.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
