## Summary

Keep open. Current main and v2026.6.11 have tracked browser-tab cleanup through idle/cap sweeps plus reset, cron, and subagent lifecycle hooks, but they still do not implement ownership-based cleanup of temporary tabs at ordinary primary-agent task completion.

## What This Changes

Request to close browser tabs or windows opened only for temporary automation work after the task completes while preserving explicit user-owned pages.

## Best Possible Solution

Implement ownership-based cleanup for browser tabs created by a primary-agent run, with explicit preserve/user-owned semantics, and keep idle/cap cleanup as a fallback.

## Reproduction Assessment

Yes, source-reproducible. Current source shows browser opens are session-tracked and cleaned by idle/cap sweeps or selected lifecycle paths, while ordinary primary-agent task completion has no ownership-based browser cleanup hook.

## Solution Assessment

No, a blanket auto-close default is not the best final shape. The maintainable solution needs a run-owned temporary-tab model plus explicit user-preservation semantics before wiring cleanup to the chosen primary-agent terminal event.
