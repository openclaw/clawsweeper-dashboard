## Summary

Keep open. Current main has idle/cap sweeps, reset cleanup, and cron/subagent lifecycle cleanup, but still does not close primary-agent browser tabs at ordinary task completion; the linked FSB pattern usefully points toward ownership-based cleanup rather than blanket tab closing.

## What This Changes

The issue asks OpenClaw to close tabs/windows opened only for temporary browser automation once the task completes, while preserving explicitly user-owned pages.

## Best Possible Solution

Add ownership-based primary-agent task cleanup only after maintainers define the terminal event and preservation contract: close run-owned temporary tabs, preserve user-owned/pinned/explicitly kept tabs, and reuse existing tabCleanup semantics unless a new config mode is approved.
