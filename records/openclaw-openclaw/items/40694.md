## Summary

Keep open. Current main has tracked idle/cap cleanup plus reset, cron, subagent, and rollover cleanup paths, but it still does not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

The issue requests automatic cleanup of browser tabs/windows opened for temporary automation work after the agent completes the task, while preserving explicit user-owned pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, so changing the default requires maintainer intent about task terminal events, tab ownership, and preservation rules.

Likely owner: steipete

Owner reason: steipete authored the idle/cap tracked-tab cleanup implementation that partially addresses this request and is the clearest feature-history owner for the product tradeoff.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap cleanup only:** Treat the current reusable-tab model as sufficient and close this behavior request as not planned if task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in mode while preserving the current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence reproduction path: browser opens are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary primary-agent task completion has no ownership-based cleanup hook.

## Solution Assessment

No, a blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
