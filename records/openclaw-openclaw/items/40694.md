## Summary

Keep open. Current main has browser tab tracking, idle/cap sweeps, reset cleanup, cron cleanup, and subagent lifecycle cleanup, but it still does not close primary-agent temporary tabs at ordinary task completion with ownership/preservation semantics.

## What This Changes

Request automatic cleanup of browser tabs/windows opened for temporary automation tasks after task completion while preserving explicitly kept or user-owned pages.

## Best Possible Solution

Add run-owned temporary-tab tracking in the browser plugin, close only unpreserved run-owned tabs at a maintainer-chosen primary-agent terminal event, and keep idle/cap cleanup as the fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close run-owned temporary browser tabs by default, and which user actions should preserve a tab?

Rationale: Current behavior intentionally keeps active primary-session tabs reusable, so changing the default needs maintainer intent for the terminal event, ownership marker, and preservation contract.

Likely owner: steipete

Owner reason: steipete has the strongest recent history in the browser cleanup and peer-reset cleanup code paths this decision would extend.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not foregrounded, pinned, or explicitly requested to be kept.
- **Keep reusable primary tabs:** Treat idle/cap cleanup plus reset cleanup as the supported model and decline task-end closing if it is too surprising.
- **Opt-in strict cleanup:** Preserve current behavior by default while adding a documented strict cleanup mode after the ownership model is defined.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: browser-opened tabs are session-tracked and cleaned by idle/cap sweeps, reset, cron, or subagent lifecycle paths, but ordinary primary-agent task completion has no run-owned cleanup hook.

## Solution Assessment

No for blanket auto-close. The best path is an ownership-based cleanup model that closes temporary run-created tabs while preserving user-owned or explicitly kept pages.
