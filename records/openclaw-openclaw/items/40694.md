## Summary

Keep open. Current main and v2026.6.11 have idle/cap sweeps plus reset, cron, subagent, and rollover cleanup paths, but they still do not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

Request automatic cleanup for browser tabs or windows opened only for temporary agent browser tasks while preserving explicitly user-owned pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, so changing that default requires a product decision about task terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner reason: steipete has the strongest recent history on the tracked-tab cleanup implementation and browser lifecycle helper.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat the current cleanup model as sufficient and close this as not planned if immediate task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes, source inspection gives a high-confidence reproduction path: open tabs are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary primary-agent task completion has no ownership-based cleanup hook. I did not run a live browser task in this read-only review.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
