## Summary

Keep open. Current main and the latest release have tracked-tab idle/cap sweeps plus subagent, cron, reset, and rollover cleanup paths, but they still do not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

Request automatic cleanup of browser tabs/windows opened for temporary primary-agent automation tasks when the task completes, while preserving explicitly user-owned pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current behavior intentionally keeps active primary-session tabs reusable, so changing the default requires maintainer intent on task terminal events, tab ownership, and preservation rules before an implementation can be safe.

Likely owner: steipete

Owner reason: steipete has the strongest recent history on the tracked-tab cleanup implementation and the reset-specific cleanup replacement.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap cleanup only:** Treat the current background cleanup model as sufficient and close this direction as not planned if task-end closure is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in mode for task-end cleanup while preserving reusable primary tabs by default.

## Reproduction Assessment

Yes, source inspection gives a high-confidence reproduction path: primary-agent browser opens are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary task completion has no ownership-based cleanup hook. I did not run a live browser task in this read-only review.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
