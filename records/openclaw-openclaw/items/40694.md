## Summary

Keep open. Current main and v2026.6.11 have tracked-tab cleanup, background idle/LRU sweeps, bounded cron/subagent lifecycle cleanup, and reset cleanup, but they still do not close run-owned temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

Request automatic cleanup of temporary browser tabs/windows opened for one-off automation tasks after completion while preserving explicitly user-owned pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep existing idle/cap cleanup as the fallback safety net.

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps primary-session tabs reusable, so changing the default requires maintainer intent about task terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat the current reusable-tab model as sufficient and close this issue as not planned if immediate task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: browser opens are tracked by session and cleaned by idle/cap sweeps or specific lifecycle resets, while ordinary primary-agent task completion has no run-owned temporary-tab cleanup hook.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned or foregrounded pages.
