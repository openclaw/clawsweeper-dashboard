## Summary

Keep open. Current main has session-tracked browser cleanup for idle/excess tabs, reset, cron, and subagent lifecycle paths, but it still does not implement ownership-based cleanup of temporary primary-agent tabs at ordinary task completion.

## What This Changes

The issue requests automatic cleanup for browser tabs/windows opened only for temporary automation tasks while preserving pages the user explicitly wants to keep.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current behavior intentionally keeps primary-session tabs reusable, so changing the default needs maintainer intent for the terminal event, run-owned marker, and preservation contract.

Likely owner: steipete

Owner reason: steipete has the strongest recent history in the browser cleanup and peer-reset cleanup code paths this decision would extend.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not foregrounded, pinned, or explicitly requested to be kept.
- **Keep reusable primary tabs:** Treat idle/cap cleanup plus reset cleanup as the supported model and close this direction as not planned if task-end closing is too surprising.
- **Opt-in strict cleanup:** Preserve current behavior by default while adding a documented strict cleanup mode after the ownership model is defined.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: browser-opened tabs are session-tracked and cleaned by idle/cap sweeps, reset, cron, or subagent lifecycle paths, but ordinary primary-agent task completion has no run-owned cleanup hook.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
