## Summary

Keep open. Current main has tracked-tab idle/cap cleanup plus reset, subagent, and cron cleanup paths, but it still does not implement task-completion cleanup for ordinary primary-agent temporary browser tabs.

## What This Changes

Requests automatic cleanup of browser tabs or windows opened only for temporary automation tasks after the task completes.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preservation semantics, and keep idle/cap cleanup as the fallback for reusable primary tabs.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should ordinary primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, so changing the default needs maintainer intent around task terminal events, tab ownership, and user preservation rules.

Likely owner: steipete

Owner reason: steipete has the strongest recent history on tracked-tab cleanup and the merged peer-scoped reset cleanup path.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat the current reusable primary-tab cleanup model as sufficient and close the requested task-end behavior as not planned.
- **Opt-in strict cleanup:** Add a documented opt-in mode for task-end cleanup while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: browser opens are tracked by session, and cleanup runs on idle/cap sweeps or selected lifecycle reset paths, with no primary-agent task-completion hook.

## Solution Assessment

No, blanket auto-close is not the best final shape. The maintainable path is ownership-based cleanup for run-created temporary tabs with explicit rules for user-owned or preserved pages.
