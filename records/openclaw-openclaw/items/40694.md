## Summary

Keep open. Current main and v2026.6.11 have tracked-tab idle/cap sweeps plus reset, cron, and subagent lifecycle cleanup, but ordinary primary-agent task completion still preserves active tabs for reuse rather than closing run-owned temporary tabs; the FSB comment usefully points toward an ownership-based design rather than a blanket close.

## What This Changes

Request automatic cleanup of temporary browser tabs/windows opened for one-off browser automation tasks after task completion while preserving explicitly user-owned pages.

## Best Possible Solution

Add run-owned temporary tab tracking for primary-agent browser tasks that closes only tabs created for the completed run, preserves user/pinned/explicitly kept tabs, and keeps the existing idle/cap sweeps as a fallback for reusable primary sessions.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent browser tabs close at ordinary task completion by default, and if so what ownership/preservation contract should define a temporary tab?

Rationale: Current behavior intentionally keeps active primary-session tabs reusable; changing that default can surprise users unless maintainers choose the terminal event, run-owned marker, and preservation rules.

Likely owner: jalehman

Owner reason: The current cleanup and session-reset code paths are recently owned by jalehman and are the likely place where the terminal boundary would be wired.

Owner confidence: medium

Options:

- **Adopt run-owned cleanup (recommended):** Track tabs opened by each primary-agent run and close them on terminal completion unless the user explicitly preserved or took ownership of them.
- **Keep idle/cap cleanup only:** Leave current reusable primary-session behavior as the product contract and close this request after documenting why task-completion cleanup is not planned.
- **Add an explicit cleanup mode:** Introduce a documented policy or config mode for task-completion cleanup while preserving the current default for upgrade safety.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: primary-agent opened tabs are tracked, then closed by idle/cap sweeps or selected lifecycle boundaries, while ordinary primary-agent task completion has no ownership-based close hook.

## Solution Assessment

Unclear. Ownership-based cleanup is the right shape, but the best fix needs maintainer choice on the terminal event and preservation contract before implementation.
