## Summary

Keep open. Current main and v2026.6.11 already have tracked-tab idle/cap sweeps plus reset, cron, subagent, and rollover cleanup paths, but ordinary primary-agent task completion still lacks run-owned temporary-tab cleanup and needs a product decision on preservation semantics.

## What This Changes

Request automatic cleanup of browser tabs/windows opened only for temporary agent browser tasks while preserving user-owned or explicitly kept pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, close only unpreserved tabs at the chosen task terminal event, and leave the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should OpenClaw close primary-agent run-owned browser tabs at task completion by default, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, so changing the default requires maintainer intent on task terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner reason: steipete has the strongest current history across idle tab cleanup, lifecycle cleanup helpers, and peer-scoped reset cleanup.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat the current reusable-tab model as sufficient and close this direction as not planned if task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence reproduction path: opening a tab records only session-level ownership, and cleanup runs on idle/cap sweeps or selected lifecycle reset keys rather than ordinary primary-agent task completion.

## Solution Assessment

No. Blanket auto-close is not the best final shape; ownership-based cleanup for run-created temporary tabs with explicit preservation rules is safer and matches the useful discussion on the issue.
