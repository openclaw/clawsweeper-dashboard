## Summary

Keep open. Current main and the latest release have idle/cap sweeps plus reset, cron, subagent, and peer-reset cleanup paths, but they still do not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

Request automatic cleanup of browser-opened temporary tabs/windows after task completion while preserving pages the user explicitly wants to keep.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current main intentionally keeps active primary-session tabs reusable, so changing the default requires a product decision about task terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner reason: steipete has the strongest recent history on tracked-tab cleanup and the peer-scoped reset cleanup implementation.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat current reusable primary tabs plus background cleanup as sufficient and close this direction as not planned.
- **Opt-in strict cleanup:** Add a documented strict cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence reproduction path: primary browser tabs are tracked by session and cleaned by idle/cap sweeps or selected reset/lifecycle paths, not ordinary primary-agent task completion.

## Solution Assessment

No for blanket auto-close. The maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
