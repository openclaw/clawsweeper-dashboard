## Summary

Keep open. Current main and v2026.6.11 still provide tracked-tab idle/cap sweeps plus reset, cron, and subagent lifecycle cleanup, but ordinary primary-agent task completion still lacks run-owned temporary-tab cleanup; the linked FSB comment is useful supporting context for an ownership-based design.

## What This Changes

The issue asks OpenClaw to close browser tabs/windows opened only for temporary automation work after the task completes, while preserving pages the user explicitly wants to keep.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs by default, and which user actions should preserve a tab?

Rationale: Current OpenClaw behavior intentionally keeps active primary-session browser tabs reusable, so changing the default needs maintainer intent around task terminal events, tab ownership, and preservation rules before implementation.

Likely owner: steipete

Owner reason: steipete has the strongest recent history across browser lifecycle cleanup, the idle cleanup implementation, and the merged peer-scoped reset cleanup.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap cleanup only:** Treat current reusable primary-tab behavior as the product default and close this direction as not planned if task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented opt-in cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection shows browser-opened tabs are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary primary-agent task completion has no ownership-based cleanup hook.

## Solution Assessment

No. Blanket auto-close is not the best final shape; the maintainable solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
