## Summary

Keep open. Current main has idle/cap sweeps, explicit reset cleanup, and cron/subagent lifecycle cleanup, but it still does not implement ownership-based cleanup of temporary primary-agent browser tabs at ordinary task completion.

## What This Changes

The issue requests automatic cleanup of browser tabs/windows opened only for temporary automation tasks after task completion.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, close only unpreserved run-owned tabs at a maintainer-chosen terminal event, and keep idle/cap cleanup as a fallback.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close run-owned temporary browser tabs by default, and which user actions should preserve a tab?

Rationale: Current behavior intentionally keeps primary-session tabs reusable, so changing the default requires maintainer intent for the terminal event, ownership marker, and preservation contract.

Likely owner: steipete

Owner reason: steipete owns the strongest recent browser cleanup and peer-scoped reset cleanup history around this exact behavior.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep current reusable-tab model:** Treat idle/cap cleanup plus reset cleanup as sufficient and close this direction as not planned if task-end closing is too surprising.
- **Opt-in strict cleanup:** Preserve current behavior by default while adding a documented strict cleanup mode after the ownership model is defined.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence reproduction path: browser-opened tabs are tracked by session and cleaned by idle/cap sweeps, reset, cron, or subagent lifecycle paths, but ordinary primary-agent task completion has no run-owned cleanup hook.

## Solution Assessment

No for blanket auto-close. The best path is an ownership-based cleanup model that closes temporary run-created tabs while preserving user-owned or explicitly kept pages.
