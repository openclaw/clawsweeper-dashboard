## Summary

Keep open. Current main and latest release have browser tab tracking, idle/cap sweeps, reset cleanup, cron cleanup, and subagent lifecycle cleanup, but they still do not implement ownership-based cleanup of temporary primary-agent tabs at ordinary task completion.

## What This Changes

Request automatic cleanup of temporary browser tabs or windows opened for one-off automation tasks after the task completes, while preserving user-owned or explicitly kept pages.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, define explicit preserve/user-owned semantics, and keep the existing idle/cap cleanup as the fallback safety net.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should primary-agent task completion close only run-owned temporary browser tabs, and which user actions should preserve a tab?

Rationale: Current code intentionally keeps active primary-session tabs reusable, so changing the default requires a product decision about task terminal events, tab ownership, and user-preservation rules.

Likely owner: steipete

Owner reason: steipete has the clearest recent ownership of the browser lifecycle helper and the merged narrow reset cleanup behavior.

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not explicitly foregrounded, pinned, or requested to be kept.
- **Keep idle/cap behavior only:** Treat the current reusable-tab model as sufficient and close this later as not planned if immediate task-end cleanup is too surprising.
- **Opt-in strict cleanup:** Add a documented strict cleanup mode while preserving current reusable-tab behavior by default.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: browser-opened tabs are tracked by session and cleaned by idle/cap sweeps or selected lifecycle resets, while ordinary primary-agent task completion has no ownership-based cleanup hook.

## Solution Assessment

No, blanket auto-close is not the best final shape. The safer solution is ownership-based cleanup for run-created temporary tabs with explicit preservation rules for user-owned pages.
