## Summary

Keep open. Current main has idle/excess cleanup for primary browser tabs plus reset, cron, and subagent lifecycle cleanup, but it still lacks ownership-based cleanup for temporary primary-agent tabs at ordinary task completion; the FSB comment usefully supports an owner-marked, preservation-aware design.

## What This Changes

Request primary-agent browser tabs/windows opened only for temporary automation work to close automatically after task completion while preserving user-owned tabs.

## Best Possible Solution

Add run-owned temporary-tab tracking for primary-agent browser opens, close only unpreserved run-owned tabs at a maintainer-chosen terminal event, and keep idle/cap cleanup as the fallback.

## Maintainer Decision

Question: Should primary-agent task completion close run-owned temporary browser tabs by default, and which user actions should preserve a tab?

Rationale: Current main intentionally keeps active primary-session tabs reusable, so changing the default needs maintainer intent for the terminal event, run-owned marker, and preservation contract.

Likely owner: steipete

Owner confidence: high

Options:

- **Run-owned cleanup with preservation (recommended):** Track tabs created during a primary-agent run and close only those not foregrounded, pinned, or explicitly requested to be kept.
- **Keep reusable primary tabs:** Treat idle/cap cleanup plus reset cleanup as the supported model and decline task-end closing if it is too surprising.
- **Opt-in strict cleanup:** Preserve current behavior by default while adding a documented strict cleanup mode after the ownership model is defined.

## Reproduction Assessment

Yes. Source inspection shows browser-opened tabs are session-tracked and cleaned by idle/cap sweeps, reset, cron, or subagent lifecycle paths, but ordinary primary-agent task completion has no run-owned cleanup hook.

## Solution Assessment

No for blanket auto-close. The best path is an ownership-based cleanup model that closes temporary run-created tabs while preserving user-owned or explicitly kept pages.
