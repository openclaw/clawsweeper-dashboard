## Summary

Keep open. Current main still lacks per-agent dreaming control and the linked issue remains open, but this PR is not merge-ready because its all-disabled path falls back to the default agent and it has no real behavior proof.

## Best Possible Solution

Land a refreshed implementation or successor that preserves default fallback only for no configured agents, treats explicitly disabled configured agents as a real opt-out, aligns schema/docs/tests with the maintainer-approved memory config path, and includes real behavior proof.

## Reproduction Assessment

## Solution Assessment

No. A per-agent opt-out is plausible, but this implementation is too narrow because it does not distinguish no configured agents from all configured agents explicitly opting out, and the accepted config location still needs maintainer confirmation.
