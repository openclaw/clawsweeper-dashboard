## What This Changes

The PR adds `agents.list[].dreaming.enabled` to config types, strict Zod schema, generated schema, docs, and `resolveMemoryDreamingWorkspaces()`, with a focused unit test for mixed enabled and disabled agents.

## Best Possible Solution

Land a refreshed version or successor that uses the maintainer-approved per-agent dreaming config shape, makes explicit opt-out a true full opt-out when every configured agent is disabled, keeps fallback only for no configured valid agents, aligns type/Zod/generated schema/docs, and includes focused tests plus redacted real behavior proof.
