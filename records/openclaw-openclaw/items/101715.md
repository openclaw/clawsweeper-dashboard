Full review comments:

- **[P2] Preserve symlink dereference in copy fallback:** `scripts/stage-bundled-plugin-runtime.mjs:35-37`
  - body: This replacement no longer matches the old `fs.cpSync(..., { dereference: true })` behavior. In the Windows/no-symlink fallback path, any nested directory symlink now hits `fs.symlinkSync` again and then falls back to `copyFileSync(src, dest)`, which cannot copy a directory target; that can make bundled plugin runtime staging fail for skill/plugin trees containing symlinked directories. Either keep `fs.cpSync` with `dereference: true`, add equivalent directory-symlink dereferencing, or split this unrelated build-script change into a tested PR.
  - confidence: 0.83

  - body: The code now rethrows `LiveSessionModelSwitchError` when the switch target is outside the candidate list, but the public failover docs still say this error is normalized into the failover path. Please update `docs/concepts/model-failover.md` so operators can distinguish stale in-chain switches from genuine user-requested switches that escape to the outer retry loop.
  - confidence: 0.8
