## Summary

The patch addresses a real privacy problem, but it is not merge-ready: it bypasses the webhook server’s existing injected plugin logger with a second global logger, removes meaningful output assertions from the regression test, and provides no real webhook log proof.

## What This Changes

The PR adds a `voice-call/webhook` subsystem logger, migrates webhook console calls to it, and replaces transcript, inbound-message, and AI-response bodies with character-count metadata.

## Best Possible Solution

Use the existing injected plugin logger as the single webhook logging path, retain metadata-only conversation messages, preserve safe actionable error details, and test the actual emitted output for absence of every removed body.
