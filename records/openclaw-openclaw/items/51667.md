## Summary

Keep open: current main and v2026.6.11 still route inbound audio through transcription/text, while native audio forwarding needs maintainer decisions for typed media content blocks, provider routing, raw-media egress, fallback behavior, and session audit semantics.

## What This Changes

The issue requests opt-in native audio forwarding to omni-modal models instead of always converting voice notes through STT transcription first.

## Best Possible Solution

Define a capability-gated native audio media contract with typed content blocks, provider serialization, explicit raw-media egress policy, fallback behavior, transcript/audit metadata, and redacted live channel proof before landing an implementation.
