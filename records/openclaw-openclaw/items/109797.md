## Summary

This PR fixes the reported blank-key behavior in ElevenLabs realtime and batch transcription, but the prior blocking finding remains: the same plugin’s active speech provider still treats a whitespace-only `XI_API_KEY` as configured and can pass it to voice discovery or synthesis.

## What This Changes

Normalizes request and environment API keys in ElevenLabs batch and realtime transcription and adds missing-key, no-egress, and trimming regression coverage.

## Best Possible Solution

Use one plugin-local ElevenLabs credential resolver that preserves existing precedence while trimming every explicit, `ELEVENLABS_API_KEY`, profile, and `XI_API_KEY` candidate, then reuse it across batch transcription, realtime transcription, voice discovery, configured-state, and all speech synthesis modes.
