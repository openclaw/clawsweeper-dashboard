## Summary

The branch adds a bundled `google-antigravity` provider and `agy --print` CLI backend, changes `google-gemini-cli` OAuth setup/refresh to import the official Gemini CLI cache with identity checks, and adds Plugin SDK auth forwarding for CLI backends with docs/tests/proof updates.

## Best Possible Solution

Land a narrower owner-approved Google auth/runtime contract that forwards only selected credential material, preserves or explicitly migrates shipped Gemini CLI OAuth profiles unless maintainers accept the cache-only break, and exposes Antigravity setup through manifest/setup-entry metadata.

## Reproduction Assessment

Yes for the review blockers from source inspection. Current PR head shows the full auth store crossing the new provider hook, cache-only Gemini CLI refresh failure without official cache, and missing Antigravity manifest/setup metadata.

## Solution Assessment

No. Antigravity through `agy --print` and official Gemini CLI cache import are plausible directions, but this is not the best merge shape until the credential boundary, shipped-profile upgrade behavior, and setup metadata are settled.
