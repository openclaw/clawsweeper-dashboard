## Summary

Keep open: the PR has useful Antigravity/Gemini direction and credible terminal proof, but current head still has blocking SDK credential-boundary, shipped Gemini CLI OAuth compatibility, and manifest-first setup gaps before merge.

The PR adds a bundled `google-antigravity` provider and `agy --print` CLI backend, changes `google-gemini-cli` setup/refresh to import the official Gemini CLI OAuth cache with identity checks, adds provider-owned CLI auth forwarding SDK surface, and updates related docs/tests/proof scripts.

## Reproduction Assessment

## Solution Assessment

No. Antigravity via `agy --print` and official Gemini CLI cache import are plausible directions, but this is not the best merge shape until the credential boundary is narrowed, shipped OAuth profiles are preserved or deliberately broken with approval, and setup metadata is aligned.
