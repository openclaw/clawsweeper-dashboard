## Best Possible Solution

Align the public contract before merge: either keep this bridge Google-private and preserve or migrate shipped API-key staging, or implement a real generic provider-owned credential resolver with docs, tests, and upgrade proof.

No. The typed Google resolver is a reasonable building block for the bundled backend, but exposing it as generic SDK API and removing shipped API-key staging without maintainer direction is not the narrowest maintainable solution.
