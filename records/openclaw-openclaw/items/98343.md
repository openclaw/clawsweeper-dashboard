Full review comments:

- **[P1] Validate the imported Gemini account before refresh:** `extensions/google/oauth.ts:101`
  - body: `refreshGeminiCliOAuthToken` now imports the active official Gemini CLI cache for any expiring google-gemini-cli profile, but it never checks that the imported `email` matches the selected profile's stored account. The generic OAuth manager persists provider refresh output back into that same profile, so a gateway where Gemini CLI is signed into another Google account can silently rewrite or stage the wrong user's OAuth material. Reject mismatched cache accounts or require an explicit re-auth/import for the target profile before returning the imported credential.
  - confidence: 0.86
- **[P2] Update the remaining OAuth setup hints:** `extensions/google/gemini-cli-provider.ts:87`
  - body: The runtime provider still advertises `PKCE + localhost callback` and `Google OAuth with project-aware token payload` even though this branch replaces OpenClaw's OAuth browser/callback flow with official Gemini CLI cache import.   - confidence: 0.9
- **[P3] Fix the Gemini CLI docs tab close:** `docs/providers/google.md:133`
