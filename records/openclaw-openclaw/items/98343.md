## Summary

The PR should stay open because it changes Google auth/provider behavior and plugin SDK credential forwarding, but the current branch can import and persist the active official Gemini CLI account into a selected OpenClaw profile without proving the account identity matches, adds an overlapping Antigravity provider surface inside the same PR, and lacks real Gemini CLI end-to-end proof.

## What This Changes

The PR adds a Google provider-owned CLI auth credential forwarding path for Gemini CLI auth profiles, imports the official Gemini CLI OAuth cache during setup/refresh, expands plugin SDK types, updates Google docs/tests, and adds a `google-antigravity` provider entry.

## Best Possible Solution
