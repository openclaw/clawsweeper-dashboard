## Summary

Current main still permits malformed cursor values to become normalized or omitted and return plausible pagination results. The latest PR head fixes that behavior at the Anthropic owner boundary, has focused regression coverage and convincing live command proof, and has no actionable correctness or security finding; it should remain open for ordinary owner review and completion of exact-head checks.

## What This Changes

The PR makes Anthropic Claude session-list, transcript, and gateway catalog cursors reject present-but-invalid values without normalizing opaque tokens, with regression tests for invalid and omitted cursors.

## Best Possible Solution

Land the focused Anthropic-local validation after exact-head checks and owner review, preserving omitted-cursor pagination while rejecting every present invalid cursor without trimming or fallback.

## Solution Assessment

Yes. Rejecting malformed values in the Anthropic catalog parameter parser is the narrowest maintainable fix because list, transcript, and gateway callers share that owner boundary, while downstream cursor decoding remains responsible for token contents.
