## Summary

This is a focused owner-boundary fix with convincing real-runtime proof, but one blocking cursor-validation gap remains: the new helper rejects missing-shape and whitespace errors without rejecting non-canonical base64url tokens that decode to a valid cursor.

## What This Changes

The PR makes Anthropic Claude session list, transcript, and gateway catalog cursors reject present-but-invalid values and adds regression coverage for those paths.

## Best Possible Solution

Keep the present-versus-absent input checks, then validate Claude list and transcript cursors by decoding and round-tripping to the exact unpadded base64url token, with gateway, list, and transcript regressions for ignored characters and padding.
