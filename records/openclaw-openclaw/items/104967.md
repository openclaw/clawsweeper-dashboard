## Summary

Keep this PR open: the current validator still permits non-canonical base64url tokens that Node decodes permissively, so malformed cursors can continue to produce a normal pagination page. The latest head also lacks after-fix behavior proof for this remaining case.

## What This Changes

The branch adds validation for Claude session-list, transcript, and local gateway catalog cursors, rejecting absent-invalid, blank, overlong, and whitespace-wrapped values.

## Best Possible Solution

Require exact unpadded-base64url round-trip equality before parsing a supplied Claude catalog cursor, then prove list, transcript, and gateway-local paths reject appended ignored characters and padded variants while canonical cursors continue to paginate.
