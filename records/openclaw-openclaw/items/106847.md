## Summary

Keep this issue open: OC Path publicly promises patch-in-place JSONC fidelity, while the report identifies insertion as a remaining contract violation; no merged fix or canonical replacement was found, and the protected `maintainer` label requires explicit maintainer handling.

## What This Changes

Make OC Path object and array insertion preserve JSONC comments, trailing commas, line endings, and unrelated formatting while retaining existing insertion semantics.

## Best Possible Solution

Add one JSONC insertion helper using `jsonc-parser.modify` plus `applyEdits`, route object and array insertion through it, remove the redundant renderer path, and add regression coverage for comments, trailing commas, CRLF/LF preservation, duplicate handling, sentinels, markers, coercion, and errors.
