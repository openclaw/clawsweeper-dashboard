  - body: `pathWin32.isAbsolute()` accepts UNC paths, and the later basename/dirname checks allow values like `\\server\share\Windows`, causing codepage detection to execute `\\server\share\Windows\System32\cmd.exe` from a tainted environment.   - confidence: 0.92

  - body: The new SDK decoder repeats the same SystemRoot-to-cmd.exe resolution and accepts UNC roots before spawning `chcp`. Please share or mirror the local-drive validation used by current main so the SDK path does not create a separate executable trust boundary.
  - confidence: 0.9
- **[P2] Inject the Windows decoder for the QMD test:** `packages/memory-host-sdk/src/host/qmd-process.test.ts:153-161`

Add a decoder factory/platform override seam or pass explicit platform/encoding into the path under test.
