Full review comments:

- **[P1] Reject UNC roots before spawning cmd.exe:** `src/infra/windows-encoding.ts:70-78`
  - body: `pathWin32.isAbsolute()` accepts UNC paths, and the later basename/dirname checks allow values like `\\server\share\Windows`; that makes codepage detection execute `\\server\share\Windows\System32\cmd.exe` from tainted environment data. Reuse current main's hardened local-drive Windows install-root helper or require a local drive root here.
  - confidence: 0.93
- **[P1] Reuse hardened root validation in the SDK decoder:** `packages/memory-host-sdk/src/host/windows-output-decoder.ts:143-150`
  - body: The new SDK decoder repeats the same SystemRoot-to-cmd.exe resolution and accepts UNC roots before spawning `chcp`. This creates a second executable trust-boundary path, so the SDK path should share or mirror current main's local-drive validation.
  - confidence: 0.91
