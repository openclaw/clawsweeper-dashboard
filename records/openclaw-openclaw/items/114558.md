## What This Changes

The branch makes automatic command review reject policy-blocked shell and dispatch wrappers, Fish startup options, and PowerShell profile, login, and encoded-command carriers so they require human approval across gateway, node, direct-system, and plugin execution paths.

## System Context

OpenClaw resolves shell and dispatch wrappers before deciding whether a command can receive one-time model auto-review or must wait for human approval. The same resolved command reaches gateway execution, node execution, direct system runs, and plugin agent-harness review input, so a trust-classification error can bypass the intended approval boundary on several hosts.
