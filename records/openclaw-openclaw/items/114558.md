## What This Changes

The PR makes automatic command review require human approval for opaque Fish and PowerShell startup, encoded-command, remoting, and dispatch-wrapper carriers while retaining review for explicit profile-free commands.

## System Context

Agent command execution resolves shell wrappers into semantic command segments before gateway, node-host, direct-system, and plugin-harness paths decide whether an automatic reviewer may approve them. This PR feeds a shared blocked-carrier decision into each of those approval entrances so unreviewed startup behavior reaches human approval instead.
