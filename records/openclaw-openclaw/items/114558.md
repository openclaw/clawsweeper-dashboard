## What This Changes

The PR makes automatic command review require human approval for opaque Fish and PowerShell startup, encoded, remoting, stdin, script-file, and dispatch-wrapper carriers while retaining review for explicitly profile-free inline PowerShell commands.

## System Context

OpenClaw’s execution hosts assemble approval requests before a shell command can run. Shell-wrapper resolution classifies whether the reviewed payload represents all executed behavior, and gateway, node, system-run, and plugin review paths use that classification to select automatic review or human approval.
