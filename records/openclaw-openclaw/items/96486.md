## What This Changes

The issue asks OpenClaw to remove or further harden the dangerous Control UI Host-header origin fallback because it may weaken CSRF protection on a network-exposed gateway.

## Best Possible Solution

Maintainers should explicitly choose the security boundary: remove the fallback with upgrade/docs handling, or retain it only with defense-in-depth such as Sec-Fetch-Site or CSRF-token coverage while keeping explicit `allowedOrigins` as the hardened default.
