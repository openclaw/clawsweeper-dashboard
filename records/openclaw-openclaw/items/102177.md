## Summary

Keep open: current main still lacks a native iOS APNs path for assistant chat finals, and background Talk remains a privacy/platform-sensitive product decision rather than a settled always-on background behavior.

## What This Changes

The issue requests opt-in native iOS push notifications for assistant messages plus continued or clearly paused/resumable Talk behavior when the app backgrounds.

## Best Possible Solution

Define a dedicated privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in if maintainers want transcript text, correct chat tap routing, and live iOS proof; keep background Talk paused/resumable by default unless a broader background-audio policy is approved.
