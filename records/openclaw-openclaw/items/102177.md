## Summary

Keep open: current main still lacks a Gateway-owned assistant-message APNs path for native iOS, while background Talk is only partly covered by a default-off keep-active setting plus paused/resume behavior. The remaining work is privacy- and product-sensitive, not a narrow strict bug fix.

## What This Changes

Add opt-in native iOS push notifications for assistant messages and improve or clearly pause/resume Talk mode while the app is backgrounded.

## Best Possible Solution

Define a dedicated, privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in if desired, correct tap routing, iOS live proof, and keep the current default-off background Talk/pause behavior unless maintainers approve a broader background audio mode.
