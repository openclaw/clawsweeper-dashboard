## Summary

Keep open: current main and the latest release still do not convert assistant chat finals into native iOS APNs alerts, and background Talk remains a privacy/product-sensitive behavior rather than a settled default.

## What This Changes

Request APNs-based native iOS notifications for assistant messages and an approved background Talk mode or clear paused/resume UX.

## Best Possible Solution

Define a dedicated privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in if desired, correct chat tap routing, and live iOS proof; keep background Talk paused/resumable unless maintainers approve broader background audio.
