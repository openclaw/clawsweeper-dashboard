## Summary

Keep open: current main and the latest release still do not convert assistant chat finals into native iOS APNs alerts, and background Talk remains a privacy-sensitive default-off or pause/resume behavior rather than a settled product path.

## What This Changes

The issue requests native iOS APNs notifications for assistant replies plus a background Talk mode policy or clearer paused/resume behavior.

## Best Possible Solution

Ship a dedicated privacy-safe chat notification APNs path with generic default content, optional explicit preview opt-in, foreground duplicate suppression, tap routing, and live-device proof; keep background Talk default-off or paused/resumable unless maintainers approve broader background capture.
