## Summary

Keep open: current main still does not turn assistant chat finals into native iOS APNs alerts, and background Talk remains a default-off or pause/resume behavior rather than a settled background-audio product path.

## What This Changes

Request APNs-based iOS notifications for assistant messages and a background-capable or clearly paused/resumable Talk mode.

## Best Possible Solution

Define a dedicated privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in if desired, correct chat tap routing, and live iOS proof; keep background Talk default-off or paused/resumable unless maintainers approve broader background audio.
