## Summary

Keep open: current main still lacks a Gateway-owned APNs path for native iOS assistant-message notifications, while background Talk is only partly covered by a default-off keep-active setting plus pause/resume behavior. The remaining work is product- and privacy-sensitive, so it is not a narrow strict bug-fix candidate.

## What This Changes

Request APNs notifications for native iOS assistant messages and improved background Talk behavior.

## Best Possible Solution

Define a privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in if approved, correct tap routing, iOS live proof, and keep the existing default-off background Talk/pause behavior unless maintainers approve broader background audio.
