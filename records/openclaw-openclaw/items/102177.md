## Summary

Keep open: current main still lacks a Gateway-to-iOS APNs path for assistant chat replies, and background Talk behavior remains a product/privacy decision rather than a settled always-on background mode.

## What This Changes

Request APNs notifications for native iOS assistant replies and background or paused-resume Talk behavior when the app leaves the foreground.

## Best Possible Solution

Define a privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in only if approved, correct gateway/agent/session tap routing, foreground duplicate suppression, and a conservative background Talk pause/resume or entitlement-backed path proven on real iOS.

## Solution Assessment
