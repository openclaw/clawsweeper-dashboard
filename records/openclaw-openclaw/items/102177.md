## Summary

Keep open: current main still does not provide a Gateway-owned APNs path for native iOS assistant-message notifications, and background Talk remains a privacy/product-sensitive mobile behavior rather than a narrow bug fix.

## What This Changes

The issue requests APNs-based native iOS notifications for assistant messages plus background Talk-mode continuation or clearer paused/resume behavior.

## Best Possible Solution

Define a dedicated, privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in only if approved, correct iOS tap routing, and live iOS proof; keep background Talk paused/resumable by default unless maintainers approve a broader background-audio mode.
