## Summary

Keep open: current main and v2026.6.11 still lack a Gateway APNs path for ordinary assistant chat finals, and background Talk remains a privacy- and platform-policy-sensitive product decision rather than a completed feature.

## What This Changes

Request APNs-based iOS notifications for assistant messages and background-capable or clearly paused/resumable iOS Talk mode.

## Best Possible Solution

Define a dedicated privacy-safe assistant-reply APNs contract with generic default content, explicit preview opt-in if desired, correct tap/session routing, and live iOS proof; keep background Talk conservative unless maintainers approve broader background audio behavior.
