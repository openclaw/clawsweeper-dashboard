## Summary

Keep this PR open. The supplied current-head context still describes `write`/`create` fallbacks as exact additions even though the underlying write operation may overwrite an existing file, so the collapsed `+N −0` statistic can misstate what actually changed; the protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The PR adds inline colored edit/write diff previews and collapsed diffstats to shared iOS/macOS SwiftUI tool rows, including tool-result detail propagation, reconciliation preservation, accessibility labels, and regression tests.

## Best Possible Solution

Use authoritative result-side before/after diff metadata for exact write statistics; otherwise show a bounded write-content preview without an exact diffstat when creation versus overwrite is unknown.
