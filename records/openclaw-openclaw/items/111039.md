## What This Changes

Adds inline diff statistics and expandable colored diffs for edit/write tool rows in the shared iOS/macOS SwiftUI chat, including tool-result detail propagation through message reconciliation.

## Best Possible Solution

Preserve a bounded cache-safe applied-diff preview, carry terminal result state into the activity row so synthesized previews are never presented as applied after failures or no-ops, and support the established `apply_patch` argument format before merging.
