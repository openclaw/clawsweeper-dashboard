## Summary

This PR remains useful, but its final head still renders successful `write` operations as exact additions even when the tool may have overwritten an existing file. That makes the displayed `+N −0` statistic materially misleading, so it needs an authoritative-diff-only policy or a preview-without-stat fallback before merge.

## What This Changes

The PR adds inline colored diffs and collapsed diffstats for edit/write tool rows in the shared iOS/macOS SwiftUI chat, carrying tool-result details through message merge and reconciliation paths.

## Best Possible Solution

Use `details.diff` for exact edit statistics; when write/create lacks authoritative prior content, render a bounded content preview without a deletion-aware diffstat unless the result explicitly proves creation or supplies before/after data.
