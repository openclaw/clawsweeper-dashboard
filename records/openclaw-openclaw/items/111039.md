Keep this PR open for repair: its screenshots convincingly show the desired Apple chat UI, but the current implementation still creates misleading or missing diffs across cache-backed history and several real tool-result paths. Likely related people: `steipete` appears to own the recent shared SwiftUI tool-row work (high confidence).

## What This Changes

Adds inline diff statistics and expanded colored diffs for edit/write tool rows in the shared iOS/macOS chat UI, while carrying gateway result details through message reconciliation.

## Best Possible Solution

Make the renderer consume only recognized tool kinds and authoritative successful-result metadata; persist bounded diff inputs or a bounded derived preview through transcript caching, add the apply-patch family, and suppress exact statistics when the tool result cannot prove the before/after change.
