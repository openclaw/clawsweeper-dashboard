## Summary

This PR remains necessary: it narrows the release-validation cleanup lifecycle so a failed parent GitHub Actions run keeps its SHA-pinned workflow ref available for failed-job reruns. It is also a member-authored, `maintainer`-labeled PR, so conservative cleanup should leave it for normal maintainer review rather than auto-close it.

## What This Changes

The branch keeps the temporary SHA-pinned `release-ci/*` ref after a failed Full Release Validation parent workflow, deleting it only for successful or dry-run attempts.

## System Context

The full-release-validation script creates a temporary immutable workflow ref, dispatches GitHub Actions against it, waits for the parent workflow, and verifies release evidence. GitHub reruns and child workflow dispatches depend on that ref still existing after a failed parent run.
