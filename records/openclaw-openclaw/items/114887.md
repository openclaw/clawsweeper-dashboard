## What This Changes

This PR recognizes Google’s invalid API-key error wording as an authentication failure so model fallback marks that candidate failed and can continue to later configured models.

## System Context

OpenClaw’s embedded-agent model runner receives provider result payloads and classifies terminal failures before the model-fallback loop settles a candidate. The shared authentication matcher feeds that decision, which determines whether the next configured provider is attempted.
