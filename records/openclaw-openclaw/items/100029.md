  - body: This guard rejects raw `file:` and URL specs, but `openclaw plugins install` strips an `npm:` prefix before npm install handling. Values like `npm:file:../pkg` or `npm:https://...` bypass the intended Crestodian no-local/no-URL boundary.
  - confidence: 0.95

  - body: `setupChannels` can register `afterConfigWritten` hooks, and the normal channels add path drains them after committing config. The chat path passes no collector and writes directly, so setup flows that need post-write finalization silently skip it.
  - confidence: 0.89

  - body: The old macOS wizard only started local gateway work when the app was not paused. This page starts the Crestodian RPC as soon as the page is reached and the CLI is installed, so onboarding can reactivate local gateway work while OpenClaw is paused.
  - confidence: 0.86
