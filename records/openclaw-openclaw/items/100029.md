- **[P1] Do not echo sensitive wizard replies:** `apps/macos/Sources/OpenClaw/OnboardingCrestodianChat.swift:49`
  - body: Hosted channel setup can still ask for sensitive text, but the chat appends the raw input before the gateway can tell the client the step is sensitive.   - body: This guard rejects raw `file:`/URL specs, but `openclaw plugins install` strips an `npm:` prefix before npm install, so `npm:file:../pkg` or `npm:https://...` bypasses the intended Crestodian restriction. Reject local and URL forms after normalizing the npm prefix, or reject those prefixed forms explicitly.
  - confidence: 0.95
- **[P2] Run channel post-write hooks after chat setup:** `src/crestodian/chat-engine.ts:94-103`
  - body: `setupChannels` can register `afterConfigWritten` hooks, and the normal `channels add` path collects and drains them after writing config. The chat path passes no `onPostWriteHook` and writes the config directly, so channel setup flows that need post-write finalization will silently skip it.
  - confidence: 0.89
- **[P2] Respect paused local mode before starting Crestodian:** `apps/macos/Sources/OpenClaw/OnboardingView+CrestodianSetup.swift:43`
  - body: The old macOS wizard only started the local gateway when the app was not paused. This page now starts the Crestodian RPC as soon as the CLI is installed, and local gateway requests auto-activate the gateway, so entering onboarding can start work even while OpenClaw is paused.
