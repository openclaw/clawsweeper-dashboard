## Summary

## What This Changes

The issue reports provider transport AbortError timeouts being treated as aborts instead of failover-worthy errors, preventing configured model fallbacks.

## Best Possible Solution

Keep the current abort boundary: caller-aborted signals stop immediately, while provider-side AbortError timeouts enter failover and use the configured fallback chain.
