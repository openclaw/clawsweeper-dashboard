## Summary

The hang is real and the shared timeout owner is appropriate, but the fixed five-minute whole-transfer cutoff can regress valid supported uploads; the overlapping timeout PR also needs a coordinated shared contract.

## What This Changes

This PR adds a shared abortable Microsoft Teams request-timeout helper, a five-minute SharePoint upload deadline, and applies them to file-consent PUT uploads with stalled and slow-success coverage.

## Best Possible Solution

Centralize a transfer-aware deadline in `request-timeout.ts`, derive it from payload size with a documented conservative minimum throughput and base floor, reuse it from both upload paths, and prove stalled abort plus throttled 100 MiB success.
