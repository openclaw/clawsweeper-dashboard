## Summary

The exact-head patch is a focused, runtime-proven fix for an unbounded Microsoft Teams consent upload, and no discrete correctness or security defect remains. Keep it open for an explicit area-owner decision on the new five-minute whole-request cutoff, because existing slow valid uploads previously had no deadline and a timeout can force the user through consent again.

## What This Changes

Adds a five-minute abort deadline to Microsoft Teams file-consent PUT uploads and tests stalled, successful, validation-failure, and HTTP-failure cleanup behavior.

## Best Possible Solution

Retain the focused AbortSignal and finally cleanup, but land the five-minute default only after a Microsoft Teams area owner accepts its slow-transfer tradeoff; otherwise derive or enlarge the bound from the supported payload envelope without adding another user-facing config option.
