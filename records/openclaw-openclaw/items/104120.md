## Summary

Keep open because the retained P1 correctness finding remains on the exact reviewed head. The hang is source-reproducible and the runtime proof supports adding cancellation, but the fixed deadline is not yet justified for the supported transfer envelope.

## What This Changes

The PR adds a shared abortable Microsoft Teams request-timeout helper and applies a five-minute deadline to file-consent upload PUTs with stalled and slow-success coverage.

## Best Possible Solution

Use one Teams-owned abortable helper with a transfer-aware deadline derived from payload size and a documented minimum throughput, floor, and cap, then apply that policy consistently to consent and SharePoint uploads with throttled supported-size proof.
