## Summary

## What This Changes

This PR adds a shared abortable Microsoft Teams request-timeout helper, a five-minute SharePoint upload deadline, and applies them to file-consent PUT uploads with stalled and slow-success coverage.

## Best Possible Solution

Define one transfer-aware Microsoft Teams upload deadline from payload bytes with a documented minimum rate, floor, and cap; reuse it for both file-consent and group/channel SharePoint uploads, with stalled-abort and throttled supported-size success proof.
