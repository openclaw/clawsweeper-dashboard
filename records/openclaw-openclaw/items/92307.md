## Summary

## What This Changes

Adds a read-only gateway-startup warning when host approvals clamp requested exec security, centralizes exec-target resolution, adds regression coverage, and updates exec-policy troubleshooting guidance.

## System Context

Gateway startup reads OpenClaw configuration and the host-local approvals file before accepting agent exec work. The exec-policy layer resolves their effective policy, and this PR logs a warning when host approvals make the default agent’s gateway-owned exec path more restrictive than the requested setting.
