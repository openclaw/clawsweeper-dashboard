## Summary

Keep open: current main and v2026.6.11 still let partial model cost configs produce undefined cost estimates, which can leave diagnostics-otel without a cost counter value. The linked fork PR is useful evidence but remains open and unmerged outside openclaw/openclaw.

## What This Changes

The issue requests defaulting missing cacheRead/cacheWrite model cost rates to zero so cost metrics are still reported.

## Best Possible Solution

Normalize missing flat cacheRead/cacheWrite cost rates to zero at the shared pricing boundary and add focused regression coverage for the cost estimate plus diagnostics-facing costUsd behavior.

## Reproduction Assessment

Yes. Source inspection on current main shows partial cost config can reach estimateUsageCost, produce a non-finite total, and leave diagnostics-otel without costUsd to record.

## Solution Assessment

Yes. Defaulting missing cache price rates at the shared pricing boundary is narrower than changing provider token reporting or adding an OTEL-only fallback.
