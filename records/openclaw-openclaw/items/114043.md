## What This Changes

## System Context

`openclaw agent exec` turns an agent result into terminal output that users and scripts consume. Its runtime abstraction separates protocol output on stdout from diagnostics and errors on stderr, while retaining a lightweight fallback runtime for tests and embedded callers.
