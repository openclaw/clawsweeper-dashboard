Request to extend the read tool so audio files are passed as native multimodal attachments instead of decoded as text.

## Best Possible Solution

Define a shared native-audio content contract, provider capability gate, payload limits, fallback behavior, and transcript/audit semantics, then wire the read tool through that contract.
