## Summary

## What This Changes

The issue requests native audio-file handling in the read tool so supported audio types are sent to multimodal models as attachments instead of being decoded as text.

## Best Possible Solution

Define a shared native audio attachment contract across read-tool output, provider capability metadata, model payload shaping, transcript/session storage, and operator media policy before implementing read-tool audio parity.
