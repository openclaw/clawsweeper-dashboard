## Summary

Keep open. Current main has fixed some thread-context loss cases, but it still lacks the requested structured `sessions_send` skip/announce action contract and still depends on exact sentinel text for `REPLY_SKIP` / `ANNOUNCE_SKIP`; the maintainer discussion explicitly kept this available as an acceptance-test requirement for A2A handoff reliability.

## What This Changes

Request structured `sessions_send` callback actions and explicit announce routing/thread overrides so agent handoffs do not depend on magic reply text and preserve channel/thread context.

## Best Possible Solution

Maintainers should define one backward-compatible handoff contract that adds structured skip/no-reply semantics to `sessions_send`, preserves legacy sentinel compatibility, carries resolved delivery context/thread IDs through announce delivery, and coordinates with the open parent-routing and announce-suppression issues.

## Reproduction Assessment

Yes. Source inspection is a high-confidence reproduction path for the missing structured-control surface: current main and `v2026.6.11` expose no `sessions_send` action/routing parameters, and skip/announce suppression still depends on exact sentinel helpers.

## Solution Assessment

Unclear as a final product shape. Structured actions are a better direction than broadening string matching, but maintainers should unify this with parent announce routing and deterministic announce suppression before implementation.
