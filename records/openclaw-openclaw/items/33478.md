## What This Changes

Request structured `sessions_send` skip/routing parameters plus inherited channel/thread context for agent-to-agent announce and final-delivery handoffs.

## Best Possible Solution

Define a backward-compatible A2A handoff contract that carries structured skip/no-reply outcomes and inherited or explicit route context, coordinated with the open announce-target design instead of adding ad hoc sentinel parsing.

## Solution Assessment
