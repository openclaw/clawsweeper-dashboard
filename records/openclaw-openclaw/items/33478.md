## Summary

Keep open. Current main partially covers thread preservation for A2A announce delivery, but it still lacks the requested structured `sessions_send` skip/no-reply action and explicit announce routing/thread override; a maintainer comment also asked to keep this available as handoff acceptance coverage.

## What This Changes

Request adding structured `sessions_send` skip/announce callback actions plus channel/thread inheritance and explicit announce routing overrides for agent handoffs.

## Best Possible Solution

Define one typed A2A handoff contract that preserves `channel`/`to`/`threadId` metadata and replaces model-emitted control tokens with structured outcomes, while keeping shipped token behavior only as an explicit compatibility path or migration boundary.
