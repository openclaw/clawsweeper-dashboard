Add structured `sessions_send` skip/announce routing controls and preserve channel/thread context through A2A and sub-agent handoff announce turns.

## Best Possible Solution

Keep this as a maintainer-sponsored A2A handoff reliability requirement: define the structured `sessions_send` outcome/routing contract, preserve current defaults, and add focused tests for skip/no-reply control outcomes plus channel/thread inheritance.
