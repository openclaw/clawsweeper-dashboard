## Summary

Keep open: current main and the latest release still lack the requested structured sessions_send action/routing contract, while A2A suppression remains exact sentinel-text driven; a narrower threadId fallback bug has landed separately but does not resolve the central handoff API request.

## What This Changes

The issue requests structured sessions_send callback actions plus inherited or explicit channel/thread routing for agent handoff announce delivery.

## Best Possible Solution

Define one backward-compatible A2A handoff contract that carries structured control intent and routing context, preserves shipped sentinel compatibility where required, and lands with focused sessions_send, announce, docs, and regression coverage.
