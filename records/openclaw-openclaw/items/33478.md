## Summary

Keep open: current main and v2026.6.11 still lack structured `sessions_send` skip/routing parameters, while A2A suppression remains exact sentinel-text driven. A narrower threadId fallback was fixed, but the requested model-facing handoff contract still needs maintainer API/product direction.

## What This Changes

The issue requests structured `sessions_send` callback actions plus inherited channel/thread context for agent handoff announce delivery.

## Best Possible Solution

Define one backward-compatible A2A handoff contract that carries structured control intent and routing context, preserves shipped sentinel compatibility where required, and lands with focused `sessions_send`, announce, docs, and regression coverage.

## Reproduction Assessment

Yes, at source level: current main still exposes no structured `sessions_send` action or announce routing parameters, and skip suppression still depends on exact sentinel text. ## Solution Assessment

Unclear as a final API shape. A structured handoff contract is likely the maintainable direction, but maintainers still need to settle how it relates to announceTarget, dispatch-only mode, private delivery, and handoff acknowledgements.
