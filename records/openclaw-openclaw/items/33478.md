## Summary

Keep open: current `main` and the latest release still lack the requested structured `sessions_send` action/routing parameters, while A2A suppression remains driven by exact sentinel text. The narrower threadId fallback path is fixed, but it does not cover the central structured handoff contract that the issue asks maintainers to define.

## What This Changes

The issue requests structured agent handoff callback actions for `sessions_send`, plus inherited or explicit announce routing/thread context for A2A completion delivery.

## Best Possible Solution

Define one backward-compatible A2A handoff contract that carries structured control intent and routing context, preserves shipped sentinel compatibility where required, and lands with focused `sessions_send`, announce, docs, and regression coverage.

## Reproduction Assessment

Yes. At source level, current `main` exposes no structured `sessions_send` action or announce routing parameters, and skip suppression still depends on exact sentinel text; I did not run a live Telegram handoff because the missing model-facing surface is directly visible in source and docs.

## Solution Assessment

Unclear as a final API shape. A structured handoff contract is likely the maintainable direction, but maintainers still need to settle how it relates to announceTarget, dispatch-only mode, private delivery, and handoff acknowledgements.
