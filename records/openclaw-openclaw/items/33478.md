## Summary

Keep open: current main and the latest release still expose sentinel-text A2A suppression rather than the requested structured sessions_send handoff controls, and a maintainer comment explicitly keeps this as concrete handoff acceptance work.

## What This Changes

Request structured sessions_send callback actions and routing-context inheritance so agent handoffs can suppress or route announces without fragile magic text.

## Best Possible Solution

Define one backward-compatible A2A handoff contract that carries structured control intent and routing context, preserves shipped sentinel compatibility where required, and lands with focused sessions_send, announce, docs, and regression coverage.

## Reproduction Assessment

Yes, at source level: current main still exposes no structured sessions_send action or announce routing parameters, and skip suppression still depends on exact sentinel text. I did not run a live Telegram handoff because the missing model-facing surface is directly visible in source and docs.

Unclear as a final API shape. A structured handoff contract is likely the maintainable direction, but maintainers still need to settle how it relates to announceTarget, dispatch-only mode, private delivery, and handoff acknowledgements.
