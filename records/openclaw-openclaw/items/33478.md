## Summary

Keep open: current main and the latest release preserve some thread-routing paths, but `sessions_send` still has no structured skip/announce action and still relies on exact model-output sentinel text for the remaining handoff control flow.

## What This Changes

The issue requests structured `sessions_send` callback actions plus inherited or explicit announce thread routing for agent handoff completion delivery.

## Best Possible Solution

Adopt one maintainer-approved A2A handoff contract that replaces model-text sentinels for skip/no-reply outcomes, preserves requester channel/thread context by default, and adds focused compatibility tests for legacy sentinel behavior.

## Reproduction Assessment

Yes, from source inspection: the current schema has no structured action parameter, and skip/no-reply handling still depends on token-only model text. I did not run a live Telegram or multi-agent repro in this read-only cleanup pass.

## Solution Assessment

Unclear: structured actions are the right class of fix, but the exact `sessions_send` API shape should be decided alongside the related announceTarget and dispatch-mode issues before implementation.
