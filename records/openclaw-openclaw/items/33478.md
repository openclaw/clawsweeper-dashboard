## Summary

Keep open: current `main` and the latest release still lack the requested structured `sessions_send` action/routing parameters, while A2A suppression remains sentinel-text driven. The narrower threadId fallback path has been fixed, but the central structured handoff contract remains unresolved and still needs maintainer product/API direction.

## What This Changes

The issue requests structured `sessions_send` callback actions plus inherited announce routing context so agent handoffs do not depend on exact skip-token text or lose thread/topic delivery metadata.

## Best Possible Solution

Define one backward-compatible A2A handoff contract that carries structured control intent and routing context, preserves shipped sentinel compatibility where required, and lands with focused `sessions_send`, announce, docs, and regression coverage.

## Reproduction Assessment

Yes, at source level: current main still exposes no structured `sessions_send` action or announce routing parameters, and skip suppression still depends on exact sentinel text. I did not run a live Telegram handoff because the missing model-facing surface is directly visible in current source and docs.

## Solution Assessment

Unclear as a final API shape. A structured handoff contract is likely the maintainable direction, but maintainers still need to settle how it relates to announceTarget, dispatch-only mode, private delivery, and handoff acknowledgements.
