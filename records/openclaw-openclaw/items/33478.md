## Summary

Keep open: current main and the latest release still lack structured `sessions_send` action/routing parameters, while A2A suppression remains exact sentinel-text driven. The narrower announce `threadId` fallback bug has been fixed, but the central model-facing handoff contract still needs maintainer API/product direction.

## What This Changes

Request to add structured `sessions_send` handoff controls for skip/no-reply behavior and preserve or override channel/thread context during A2A announce turns.

## Best Possible Solution

Define one backward-compatible A2A handoff contract that carries structured control intent and routing context, keeps shipped sentinel compatibility where required, and lands with focused `sessions_send`, announce, docs, and regression coverage.

## Reproduction Assessment

Yes. Source inspection is a high-confidence path: current main and `v2026.6.11` expose no structured `sessions_send` action or announce routing parameters, and skip suppression still depends on exact sentinel text.

## Solution Assessment

Unclear as a final API shape. A structured handoff contract is likely the maintainable direction, but maintainers still need to settle how it relates to announceTarget, dispatch-only mode, private delivery, and handoff acknowledgements.
