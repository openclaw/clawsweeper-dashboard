## What This Changes

The PR routes dependency-pin Git reads through a one-minute bounded subprocess helper, reports the stalled command, exposes a test-only timeout option, and adds a cross-platform stalled-Git regression test.

## System Context

The dependency-pin guard is a repository validation script that enumerates tracked package manifests and reads index-backed manifest content through Git. Its result feeds developer and CI checks that reject unpinned dependencies, so a stalled Git subprocess currently blocks the whole validation step.
