## Summary

Keep open for normal maintainer review: current main still under-renders decimal model context windows, while this focused PR fixes the shared models-command formatter, adds targeted regression coverage, and does not introduce a blocking functional or security concern.

## What This Changes

The PR changes the models-command compact token formatter from binary K to decimal K and updates focused shared/table tests.

## Best Possible Solution

Land the focused formatter and regression-test update after normal maintainer and required-check gating, while leaving the separately tested heartbeat context label behavior unchanged.

## Reproduction Assessment

Yes, at source level: current main divides model-command token labels by 1024, so decimal catalog windows such as 200000 and 400000 render as 195k and 391k. I did not run the CLI because this read-only review must not create checkout artifacts.

## Solution Assessment

Yes. Changing the existing shared models-command formatter is the narrowest maintainable fix for list, scan, and picker hints while preserving the dash/K-only table contract; replacing it with formatTokenCount would change missing-value and million-window display semantics.
