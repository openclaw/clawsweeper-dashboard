The PR changes the shared models-command context-window formatter from binary K to decimal K and updates focused formatter/table tests.

## Best Possible Solution

## Solution Assessment

Yes. Changing the existing shared models-command formatter is the narrowest maintainable fix for list, scan, and picker hints while preserving the dash/K-only table contract; replacing it with formatTokenCount would alter missing-value and million-window display semantics.
