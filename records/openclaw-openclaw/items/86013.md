  - body: This cleanup runs on every LINE message after Markdown stripping, so text that legitimately contains repeated pipes, such as `a || b`, is changed before delivery even when no table was extracted.   - body: The guard allows generated bubble contents up to 32,568 bytes, but LINE documents bubble JSON at 30 KB and carousel JSON at 50 KB.   - confidence: 0.91

  - body: Current main already records `running: true` after webhook registration, and this branch adds a second identical write a few lines later. That duplicates runtime-state updates and advances `lastStartAt` twice for one startup; keep one write at the intended lifecycle point.
