## Summary

Keep open: current main and v2026.6.11 fixed the direct Google tagged/native reasoning conflict, but valid same-route Gemini text signatures are still stored on assistant text blocks and replayed as `thoughtSignature`, so the central session-bloat/session-failure path remains.

## Best Possible Solution
