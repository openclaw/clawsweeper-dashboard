## Summary

Keep open: current main and v2026.6.11 fixed the Gemini tagged/native reasoning conflict and have coverage for segmented pre-tool visible text, but valid same-route Gemini `textSignature` values are still retained and replayed as `thoughtSignature`, so the central session-bloat failure remains.

## What This Changes

The issue asks OpenClaw to prevent Gemini 2.5 Pro signature bloat, `<think>` tag suppression, and dropped Telegram replies from mixed text/tool responses.

## Best Possible Solution

Define a Google provider replay policy that preserves required function-call/native-thinking signatures while bounding, externalizing, or dropping optional completed visible-text signatures, with regression coverage and live Gemini/Telegram proof.

## Maintainer Decision

Required: true

Kind: product_direction

Question: What retention and replay contract should OpenClaw use for Gemini same-route `textSignature` and `thoughtSignature` values after a turn is complete?

Rationale: Current code intentionally replays valid same-route signatures, but official Google docs distinguish required function-call signatures from recommended non-function-call signatures, so automation should not choose the permanent provider semantics alone. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thought-signatures))

Likely owner: steipete

Owner reason: The remaining choice spans Google provider behavior, session replay compatibility, and release risk rather than a purely mechanical code fix.

Owner confidence: medium

Options:

- **Bound completed text signatures (recommended):** Preserve required tool-call/native-thinking signatures but drop, cap, or externalize completed visible `textSignature` values before session replay.
- **Externalize replay metadata:** Store provider signatures outside visible transcript content and replay only the signatures Google requires for active same-route continuation.
- **Keep current replay pending proof:** Accept ongoing bloat risk until maintainers obtain live Google contract proof for a narrower strip rule.
