## Summary

Keep open: current main and v2026.6.11 have fixed the tagged/native reasoning subset, but the central Gemini signature-bloat path remains because same-route visible text signatures are still stored and replayed as Gemini thought signatures.

## What This Changes

This issue requests a fix for Gemini sessions where stored signatures, reasoning-tag handling, and mixed text/tool turns bloat history and can drop Telegram replies.

## Best Possible Solution

Define a Google replay policy that preserves required tool-call/native-thinking signatures while bounding, externalizing, or dropping optional visible-text signatures, then prove it with focused replay tests and a live Gemini tool-turn run.

## Reproduction Assessment

Yes, at source level: current Google replay stores valid same-route text signatures and sends them back as Gemini thought signatures. I did not run a paid Gemini plus Telegram loop during this read-only review.

## Solution Assessment

No, current main is only a partial solution. The best fix needs a maintainer-selected Google signature retention and replay contract rather than an unconditional strip-all patch.
