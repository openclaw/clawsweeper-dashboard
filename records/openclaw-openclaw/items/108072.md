## Label Justifications

- `P1`: The remaining race can silently discard restored CLI agent history during transcript compaction, breaking an active agent workflow and session state.

## Summary

Keep open: the direction and live proof are strong, but the patch still trusts the size captured before opening the file, so a sufficiently large compaction can leave the bounded read starting at or beyond EOF and still restore no message history.

## What This Changes

The PR switches bounded CLI session-tail loading to the shared short-read-safe file-window reader, decodes only bytes actually read, and adds a transcript-shrink regression test.

## Best Possible Solution

Open the transcript once, obtain its current size from that file descriptor, choose full or bounded loading from that same size, and add coverage for compaction from over 5 MiB to below 5 MiB and for a stale offset beyond the replacement EOF.
