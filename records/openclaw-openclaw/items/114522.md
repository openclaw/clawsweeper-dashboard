## What This Changes

The PR lets an agent schedule archival of its own non-main session until its active turn and competing session work complete, using identity-checked Gateway patches to avoid archiving a reset replacement.

## System Context

The sessions tool runs inside an agent turn and asks the Gateway to change persisted session metadata. This change defers a self-requested archive until lifecycle admissions release, then sends a compare-and-swap patch so reset or replacement sessions remain protected.
