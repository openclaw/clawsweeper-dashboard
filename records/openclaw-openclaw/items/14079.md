## Summary

Keep open. Current main and v2026.6.11 still do not deliver Linux desktop notifications for the core `system.notify` node command; the source gap is clear, but the Linux backend contract needs maintainer direction before an automated fix.

## What This Changes

Request Linux desktop notification delivery for the core node `system.notify` command, likely through `notify-send` or a similar Linux notification backend with graceful headless behavior.

## Best Possible Solution

Choose the Linux notification backend contract, then add a focused core node-host `system.notify` path with safe invocation, display/headless detection, structured unavailable results, CLI/docs updates, regression coverage, and Linux desktop proof.
