## Summary

Keep open. Current main and v2026.6.11 still do not deliver Linux desktop notifications for the core `system.notify` node command: the Linux allowlist can include it, but the headless node host neither advertises nor dispatches it, and maintainers still need to choose the Linux backend contract.

## What This Changes

The issue requests Linux desktop notification support for OpenClaw nodes, likely through `notify-send` or a D-Bus-style backend with graceful headless degradation.

## Best Possible Solution

Choose the Linux notification backend contract, then implement a focused core node-host `system.notify` path with safe invocation, structured unavailable results, CLI/docs updates, targeted regression coverage, and real Linux desktop-session proof.
