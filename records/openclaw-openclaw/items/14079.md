## Summary

Keep open. Current main and the latest release still do not implement Linux desktop notification delivery for the existing `system.notify` node command; the code gap is clear, but backend and dependency scope need maintainer direction.

## What This Changes

The issue requests Linux desktop notification support for OpenClaw node notifications, likely via `notify-send` or another Linux notification backend.

## Best Possible Solution

Choose the Linux notification backend contract, then implement a focused core node-host `system.notify` path with safe invocation, structured unavailable results, docs/CLI updates, regression coverage, and real Linux desktop-session proof.
