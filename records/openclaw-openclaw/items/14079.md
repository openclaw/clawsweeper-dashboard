## Summary

Keep open. Current main and the latest shipped release still do not deliver Linux desktop notifications for the existing `system.notify` node command: Linux policy can allow it, but the headless node host neither advertises nor dispatches the command, and backend scope remains a maintainer product/security choice.

## What This Changes

The issue requests Linux desktop notification support for OpenClaw node notifications, comparable to the existing macOS notification path.

## Best Possible Solution

Approve a minimal core Linux node-host `system.notify` contract, likely `notify-send` first with argv-only invocation and structured unavailable results, then add docs/tests plus real Linux desktop-session proof.
