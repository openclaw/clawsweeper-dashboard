## Summary

Keep this PR open: the shared resolver is the right boundary, but the proposed nullish-coalescing order lets a nonfatal existing failure signal suppress the terminal failure sentinel, leaving a silent-success path unaddressed.

## What This Changes

## Best Possible Solution

Normalize an explicitly fatal structured signal first, otherwise promote the terminal sentinel, add the nonfatal-signal regression case, and show one redacted isolated cron run reaching the failure-alert/status path.
