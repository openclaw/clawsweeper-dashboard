## What This Changes

This PR detects a terminal `===DONE_ERR===` line from an isolated cron agent, converts it into the existing structured failure signal, and lets the existing cron error and failure-alert flow handle it.

## System Context

An isolated cron agent run produces final visible text and terminal metadata in the embedded agent runner. The cron layer classifies that metadata into a run status, updates persisted job failure state, and sends a configured failure alert when the run is fatal.
