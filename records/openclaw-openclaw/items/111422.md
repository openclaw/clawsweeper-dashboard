## What This Changes

The PR treats a last non-empty final assistant-text line beginning with `===DONE_ERR===` as a fatal isolated-cron failure and adds resolver coverage for sentinel variants.

## Best Possible Solution

Keep cron failure classification driven by typed runtime outcome signals; if maintainers want a textual sentinel, define and document an explicit producer-side contract, scope it deliberately, and prove fresh and upgrade behavior with a real isolated-cron run.
