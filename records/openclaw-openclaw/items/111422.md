## Summary

Keep this PR open: its latest helper still turns free-form final visible text into durable cron failure state, so the prior P1 protocol concern remains unresolved despite moving the check out of the shared resolver.

## What This Changes

The branch classifies a terminal `===DONE_ERR===` line in isolated-agent final visible text as a fatal cron signal and passes it through both final and interim cron outcome paths.

## Best Possible Solution

Define a producer-owned structured cron failure contract, have the agent runtime emit it when a run truly fails, and prove an end-to-end isolated cron run records failure and delivers its configured alert without changing ordinary final-text semantics.
