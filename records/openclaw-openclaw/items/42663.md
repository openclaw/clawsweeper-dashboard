## Summary

Keep open: current main and v2026.6.11 still lack a Discord trusted webhook allowlist or webhook-to-user mapping, and the remaining work is a maintainer security/product decision rather than stale cleanup.

## What This Changes

Requests a guild-scoped Discord `trustedWebhooks` allowlist that lets specific webhook-authored messages trigger agent responses without enabling all bot messages.

## Best Possible Solution

Have maintainers define the Discord trusted-webhook authority first; if accepted, implement it inside the Discord plugin with strict schema, conservative identity rules, docs, focused preflight/security tests, and live Discord proof.

Rationale: The request is narrower than `allowBots: true`, but it turns webhook possession into authority to enter agent sessions and optionally crosses sender authorization/session boundaries through identity mapping.

Likely owner: steipete

Owner confidence: high

Options:

- **Approve Narrow Trusted Webhooks (recommended):** Allow a webhook-id allowlist to pass the bot-message gate, but keep user mapping disallowed or separately constrained until its authorization semantics are defined.
- **Approve Webhook-To-User Mapping:** Permit `mapToUser` only with strict validation against configured guild users, audit behavior, and tests proving it cannot bypass sender authorization or session isolation.
- **Use Generic Hook Ingress:** Decline a Discord-specific surface and direct external automation to authenticated Gateway hooks when same-channel Discord replies are not required.

## Reproduction Assessment

Yes, source-level: current Discord preflight resolves a webhook id but still drops non-PluralKit bot-authored messages when `allowBots` is off. I did not run a live Discord webhook scenario in this read-only review.

## Solution Assessment

Unclear. A webhook-id allowlist is a plausible narrower fix than `allowBots: true`, but the proposed `mapToUser` authority crosses security and session boundaries, so maintainer approval should come before implementation.
