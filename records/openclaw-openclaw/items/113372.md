## Summary

The PR addresses the linked, current iOS Talk regression with a narrow locale-resolution path and direct simulator evidence. It should remain open for normal review and CI completion; no concrete patch defect or security concern was established from the available source and PR evidence.

## What This Changes

The branch preserves BCP 47 speech locales for iOS system-voice playback, applying the configured or directive locale when Talk falls back from gateway/provider synthesis.

## System Context

iOS Talk turns a configured speech locale and optional response directive into provider speech requests or native `AVSpeechSynthesizer` playback. This change affects the native fallback after gateway/provider TTS is unavailable, so non-default-language replies can use a matching installed system voice.
