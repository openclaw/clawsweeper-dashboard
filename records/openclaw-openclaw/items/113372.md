## What This Changes

The PR extends iOS Talk so native system-voice fallback resolves an installed BCP 47 voice locale from a response directive, local selection, or existing gateway `talk.speechLocale` setting, and documents that setting’s expanded behavior.

## System Context

Talk receives speech-language preferences from response directives, the device’s local selection, and Gateway configuration. When provider speech cannot play, the iOS native fallback now selects an installed system voice before synthesizing the response, otherwise preserving Apple’s device-default voice.
