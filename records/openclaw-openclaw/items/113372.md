## What This Changes

The PR makes iOS Talk system-voice fallback select the configured or per-response BCP 47 speech locale while keeping the provider-facing two-letter language value separate for gateway synthesis.

## System Context

Talk mode receives a response directive plus local and gateway Talk configuration, then chooses either gateway/provider speech or native Apple synthesis. This change affects the native fallback so a user’s existing speech-language choice reaches the system voice without changing provider routing.
