## What This Changes

The PR makes iOS Talk’s local system-voice fallback resolve an available BCP 47 speech locale from response directives, local settings, and gateway settings while preserving the provider-facing language value for gateway synthesis.

## System Context

iOS Talk receives speech directives and Talk configuration, optionally sends text to gateway TTS, and falls back to Apple’s local speech synthesizer when needed. This change sits at the locale-selection boundary before local synthesis, affecting which installed system voice reads the reply.
