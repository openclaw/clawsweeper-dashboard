## Summary

Keep this PR open: its watchdog-side change references a parent-script constant after the watchdog function is serialized into a separate Node process, so the watchdog can throw `ReferenceError` when it probes a PID. The intended subprocess bound is worthwhile, but this branch needs a small repair plus real after-fix workspace-flow evidence before merge.

## What This Changes

Adds a five-second timeout to the three synchronous `ps` probes used by workspace quiesce, identity, and watchdog handling.

## Best Possible Solution

Keep the timeout local to the serialized watchdog program, or pass it as a serialized argument, then add focused watchdog-child coverage and show a redacted real workspace quiesce/renew/resume run.
