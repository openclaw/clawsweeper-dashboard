## Label Justifications

- `P2`: This is a bounded memory embedding/provider-routing bug and PR with real impact for proxy users but not a whole-runtime outage.
- `merge-risk: 🚨 compatibility`: The diff can break existing custom OpenAI-compatible endpoints that currently receive bare model IDs through an OpenAI provider base URL.
- `merge-risk: 🚨 auth-provider`: The changed model string controls provider routing for bearer-authenticated OpenAI embedding requests.
- `merge-risk: 🚨 session-state`: The same `client.model` value is persisted in memory cache/index identity, so merging can invalidate or drift existing vector indexes.

## Summary

Keep open: current main still misses the bare-model proxy case, but this branch is not merge-ready because it lacks real behavior proof and broadens prefixing to every non-native OpenAI embedding endpoint, which is compatibility-sensitive.

## What This Changes

This PR removes the original-model prefix guard in the OpenAI embedding provider so non-native OpenAI embedding base URLs always send an `openai/`-qualified model, and adds regression tests for bare/proxy and native cases.

## Best Possible Solution

Narrow the change so Requesty-style routers get provider-qualified model IDs without changing bare-model custom OpenAI-compatible endpoints unless maintainers explicitly accept that contract, and require real after-fix endpoint proof.

## Reproduction Assessment

Yes, at source level: current main and `v2026.6.11` normalize a bare OpenAI embedding model to a bare request model, and the current guard only re-adds `openai/` when the original model already had that prefix. I did not run a live Requesty or local endpoint request in this read-only review.

## Solution Assessment

No as submitted: the PR fixes the bare Requesty-style proxy case, but the unconditional non-native endpoint rule is too broad without maintainer-approved endpoint semantics and upgrade proof. A safer fix would distinguish provider-routing proxies from generic OpenAI-compatible endpoints or explicitly document the contract change.
