## Summary

Keep open: current main and v2026.6.11 still append workspace-path guidance after resolving the configured heartbeat prompt, while the docs promise the custom prompt is sent verbatim. The related same-repo fix PRs are closed unmerged, and the remaining open related PRs are partial/conflicting rather than safe canonical fixes.

## What This Changes

The issue asks OpenClaw to respect user-configured heartbeat prompts instead of mutating or replacing them with internal heartbeat guidance.

## Best Possible Solution

Keep the default-prompt workspace guardrail, but skip internal path-hint/directive mutation for user-authored heartbeat prompts and add regression coverage proving the configured prompt is model-visible/verbatim while transcript filtering remains internal.
