Keep open: current main and v2026.6.11 still do not satisfy the documented heartbeat prompt contract, and an open conflicting fork PR references this issue with closing syntax, so maintainers need to choose the repair path before another automated fix is queued.

## What This Changes

This issue asks OpenClaw to honor user-configured heartbeat prompts without appending workspace path guidance or replacing the model-visible prompt with the heartbeat transcript marker.

## Best Possible Solution

Land or replace a narrow heartbeat-runtime fix that keeps configured heartbeat prompt text model-visible, limits workspace-path guidance to default or internally generated prompts, and keeps `[OpenClaw heartbeat poll]` transcript-only.
