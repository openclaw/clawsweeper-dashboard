## Summary

Keep open: current main and v2026.6.11 still append internal workspace-path guidance to the resolved heartbeat prompt whenever it mentions HEARTBEAT.md, while the public docs say custom heartbeat prompts are sent verbatim. The linked fork PR is open but conflicting and unmerged, so the issue remains the canonical place to track the regression until a viable fix lands.

## What This Changes

The issue reports that user-configured heartbeat prompts are mutated by internal heartbeat guidance instead of being honored verbatim.

## Best Possible Solution

Keep the issue open until a narrow fix preserves user-authored heartbeat.prompt text verbatim while retaining workspace-path guidance for the built-in/default heartbeat prompt, with regression coverage for both paths.
