## Summary

Keep open: current main and the latest release still append the workspace HEARTBEAT.md path hint after resolving the configured heartbeat prompt, while the docs promise configured heartbeat prompts are sent verbatim. The issue also has an open closing-syntax fork PR, but that PR is currently conflicting, so the safe cleanup outcome is maintainer routing rather than closure.

## What This Changes

The issue reports that user-configured heartbeat prompts are no longer respected because generated heartbeat guidance is appended or substituted in the heartbeat run path.

## Best Possible Solution

Land or refresh a narrow heartbeat-runtime fix that leaves user-authored heartbeat prompts unchanged, limits workspace-path hints to default or internally generated prompts, and adds prompt-boundary coverage for the transcript marker.
