## Summary

Keep open: current main and v2026.6.11 still append the workspace HEARTBEAT.md hint after resolving the configured heartbeat prompt, which violates the documented verbatim prompt contract when a custom prompt mentions HEARTBEAT.md. The linked fix candidate is open but conflicting, so this issue should remain the canonical tracker until maintainers revive, replace, merge, or close that PR.

## What This Changes

The issue requests restoring user-configured heartbeat prompts so OpenClaw does not append the workspace HEARTBEAT.md path hint to custom prompt text.

## Best Possible Solution

Land a narrow heartbeat-runner fix that preserves the workspace path hint for built-in/default internal heartbeat prompts while keeping user-authored heartbeat prompts verbatim, with regression coverage for both paths.
