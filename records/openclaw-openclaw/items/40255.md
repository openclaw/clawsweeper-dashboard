Keep open: current main and v2026.6.11 still pass configured heartbeat prompts through the unconditional workspace-path hint, and the open closing-syntax fork PR is conflicting rather than merged.

## Best Possible Solution

Land or replace a narrow heartbeat runtime fix that keeps configured heartbeat prompts model-visible and verbatim, limits workspace-path guidance to default or internally generated prompts, and keeps `[OpenClaw heartbeat poll]` transcript-only.
