## Summary

Keep open: current main and the latest release still append the workspace HEARTBEAT.md hint after resolving the configured heartbeat prompt, which contradicts the documented verbatim prompt contract when a custom prompt mentions HEARTBEAT.md. A linked open fork PR uses closing syntax for this issue, but it is currently conflicting, so the issue should remain the canonical tracker until that PR is updated, replaced, merged, or closed.

## What This Changes

The issue asks OpenClaw to respect user-configured heartbeat prompts instead of mutating or replacing them with hardcoded heartbeat guidance.

## Best Possible Solution

Keep this issue open as the canonical tracker and land a narrow fix that preserves the workspace path hint only for the built-in default/internal heartbeat prompts while keeping user-authored prompts verbatim.
