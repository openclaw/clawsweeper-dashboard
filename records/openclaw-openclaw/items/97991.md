- Sessions with multiple runtime or configured Feishu bindings now fail closed instead of falling back to `defaultAccount`; that is safer for cross-tenant boundaries but can stop existing workflows until operators disambiguate routing.
- The new `openclaw/plugin-sdk/routing-runtime-internal` subpath is scoped to bundled Feishu and excluded from public package exports, but it is still a private loader/package-boundary seam that should be maintainer-accepted before merge.
