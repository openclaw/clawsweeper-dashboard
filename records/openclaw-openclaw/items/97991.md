## Summary

Keep open: the patch appears correct and the contributor supplied sufficient real Feishu proof, but it intentionally changes credential precedence and adds public Plugin SDK exports, so maintainer acceptance is still required before merge.

## What This Changes

The branch threads session keys through Feishu resource tools, resolves runtime and configured Feishu bindings before global `defaultAccount`, exports two routing helpers through the Plugin SDK, and updates focused tests plus SDK surface baselines.

## Best Possible Solution

Merge the binding-first Feishu resource-tool fix only after maintainers explicitly accept the credential precedence and public SDK export shape, then let the linked issue close when this PR lands.

## Reproduction Assessment

Yes, at source level. Current main and `v2026.6.11` can return global `channels.feishu.defaultAccount` before any runtime or configured binding lookup when a Feishu resource tool has no valid `ctx.agentAccountId`; the PR body also includes redacted live Feishu proof of the corrected route.

## Solution Assessment

Yes, with maintainer acceptance. Reusing existing session-binding and configured-routing helpers inside the shared Feishu resolver is the narrow maintainable fix; the open decision is whether maintainers accept the public SDK exports and credential-precedence change.
