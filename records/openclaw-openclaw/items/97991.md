  - body: `resolveFeishuToolAccount` only runs the capability-before-default branch when `requiredTool` is set, but Bitable still calls it without that field.   - confidence: 0.94
- **[P2] Honor peer-scoped configured bindings before ambiguity:** `extensions/feishu/src/tool-account.ts:128-133`
  - body: This fallback collapses every Feishu `bindings[]` entry for the agent into account ids and throws when there is more than one, without checking whether the current session key carries a peer route that would select one binding. For a route-scoped session like `agent:main:feishu:group:chat-b`, existing routing semantics can match the exact peer binding, but this code reports ambiguity before considering that context.
  - confidence: 0.88
