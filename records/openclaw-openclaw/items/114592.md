## What This Changes

This PR records private agent-reply ownership in session write locks, suppresses the duplicate generic error only for a different active owner of the same session lock, and corrects the Codex prewarm test’s full-suite shard routing.

## System Context

Agent turns register an active reply run and acquire a session transcript write lock before they update the conversation. If lock acquisition times out, the terminal error handler normally sends a generic failure reply; this change classifies one correlated contention case as silent so the other active turn can finish.

## Best Possible Solution

Keep the private, session-scoped active-owner design and land it only if maintainers explicitly accept the product rule that a contender should stay silent while the distinct active owner is expected to deliver the session’s outcome; retain the three-way regression coverage and the single-shard Codex test assignment.
