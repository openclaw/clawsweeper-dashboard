## What This Changes

The PR adds reply-run ownership metadata to session write locks so the reply handler suppresses only a duplicate timeout caused by another live reply run.

## System Context

Embedded agent turns acquire a per-session write lock before persisting transcript changes. When acquisition times out, the reply error handler decides whether to show a failure to the user or leave the live owning turn to finish.
