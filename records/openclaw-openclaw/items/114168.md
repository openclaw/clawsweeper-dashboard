## What This Changes

The branch adds an `sbx` plugin that lets agents run sandboxed tools through Docker Sandboxes, with backend selection/configuration, plugin catalog metadata, documentation, unit tests, and an opt-in live smoke test.

## System Context

OpenClaw chooses an agent sandbox backend from configuration, then loads the corresponding plugin to create, execute in, inspect, and clean up isolated workspaces. This PR adds `sbx` to that plugin-backed path, delegating sandbox lifecycle and commands to the local Docker Sandboxes CLI while file tools use the existing remote-shell filesystem bridge.
