## What This Changes

This PR adds the external `@openclaw/sbx-sandbox` plugin, documentation, configuration metadata, and tests so agents can use Docker Sandboxes’ `sbx` CLI for sandboxed tool execution.

## System Context

OpenClaw selects a sandbox backend when an agent tool call needs isolation. This plugin registers `sbx` through the public sandbox SDK, then uses the local Docker Sandboxes CLI to create, execute in, inspect, and remove per-scope sandboxes while the shared sandbox registry continues to manage lifecycle.
