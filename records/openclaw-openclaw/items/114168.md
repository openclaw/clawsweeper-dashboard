## What This Changes

This PR adds the external `@openclaw/sbx-sandbox` plugin, its `sbx` backend configuration and documentation, catalog metadata, and unit/E2E coverage so configured agent tools can run through Docker Sandboxes instead of Docker, SSH, or OpenShell.

## System Context

OpenClaw routes agent tool execution through a configured sandbox backend; plugins register backend lifecycle and command adapters through the public sandbox SDK. This plugin would create and manage Docker Sandboxes and use their same-path workspace mounts for tool execution and file operations.
