## Summary

Keep this PR open: the current head appears to close the cross-plugin patch authorization gap without a remaining line-level defect, but the fail-closed policy for persisted ownerless rows needs explicit maintainer approval and the external PR still lacks deployed real-behavior proof.

## What This Changes

The PR adds transaction-safe plugin ownership authorization to `sessions.patch`, stamps ownership on patch-created session rows, and adds regression coverage for foreign, ownerless, concurrent, and self-owned mutations.

## Best Possible Solution

Keep the writer-locked, pre-migration authorization and ownership stamping, then land only after maintainers explicitly approve the ownerless-row transition and a deployed plugin-runtime run proves foreign denial, intended ownerless behavior, and self-owned create-then-patch success.
