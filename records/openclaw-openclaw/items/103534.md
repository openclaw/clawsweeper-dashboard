## Summary

The latest branch appears correct and well-proven, but merge still needs explicit approval of the intentional fail-closed rule for legacy ownerless sessions and coordinated ownership-helper direction with the adjacent sessions.create work.

## What This Changes

The PR adds pre-lock and authoritative in-transaction plugin ownership checks to `sessions.patch`, stamps plugin ownership on newly created rows, and adds authorization, race, and persistence regression coverage.

## Best Possible Solution

Adopt exact plugin-owner equality as the single gateway invariant for create, patch, and delete, keep ownerless plugin mutations fail-closed, and converge this PR with the sibling branch on one shared ownership helper and regression matrix.
