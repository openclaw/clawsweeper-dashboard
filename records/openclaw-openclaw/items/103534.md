## Summary

The reported cross-plugin mutation bug remains present on current `main`, and this PR has the strongest fix shape among the open candidates because authorization uses the transaction-selected entry and new plugin-created rows receive ownership. It should remain open, but the current head is not merge-ready: it includes an unrelated doctor behavior change, intentionally denies legacy ownerless rows without a confirmed upgrade contract, and still lacks deployed after-fix proof.

## What This Changes

The PR adds transaction-scoped plugin ownership authorization to `sessions.patch`, stamps ownership on new session rows, adds race and ownership regression tests, and also registers a doctor health contribution.

## Best Possible Solution

Keep the transaction-selected authorization callback and creation-time ownership stamping, remove the unrelated doctor commit, then either explicitly approve fail-closed legacy behavior or add a narrow doctor/operator ownership migration before merge, with deployed Gateway proof for same-owner success and foreign/ownerless rejection.
