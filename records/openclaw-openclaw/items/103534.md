## What This Changes

This PR makes `sessions.patch` reject plugin-runtime mutations of foreign or ownerless sessions and stamps the caller’s plugin owner when patching creates a session row.

## Best Possible Solution

Use this branch as the canonical fix, retain the transaction-selected ownership check and creation-time owner stamp, and land it only after a deployed plugin-runtime proof demonstrates owned success plus foreign and ownerless rejection with actionable errors.
