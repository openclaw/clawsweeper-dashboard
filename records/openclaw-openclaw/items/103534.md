## Summary

## What This Changes

## Best Possible Solution

Land a narrowly scoped gateway fix that authorizes the transaction-selected entry before migration, stamps authenticated ownership only on newly created rows, fails closed on unattributable ownerless rows with a clear operator recovery path, and excludes the unrelated doctor change.
