## Summary

## What This Changes

The PR enforces plugin ownership for `sessions.patch`, records ownership on patch-created sessions, and adds handler and projection regression tests.

## Best Possible Solution

Make exact-owner authorization canonical for plugin-owned session mutations, stamp ownership at creation, and provide an explicit operator-visible migration or recovery path for any legitimate legacy ownerless rows.
