## Summary

## What This Changes

Adds plugin-owner authorization to `sessions.patch`, stamps the owner on patch-created session rows, and adds handler and projection regression tests.

## Best Possible Solution

Authorize the transaction-selected entry before any key migration or persistence, retain exact-owner enforcement and creation stamping, and land only after redacted deployed Gateway/plugin-runtime proof covers owned, foreign, ownerless, and newly created rows.
