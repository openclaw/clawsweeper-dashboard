## Summary

## What This Changes

The branch adds plugin-runtime ownership checks to `sessions.patch`, rechecks authorization against the projection snapshot, and stamps `pluginOwnerId` when a plugin creates a new session row.

## Best Possible Solution

Adopt one explicit ownership policy: plugin-runtime callers may mutate only rows with an exact stored owner match, retain operator access to legacy ownerless rows, and coordinate any shared ownership helper with the adjacent creation-path work.
