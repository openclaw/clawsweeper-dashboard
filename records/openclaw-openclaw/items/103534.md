## Summary

Keep this PR open for maintainer review. The patch consistently fences plugin-runtime `sessions.patch` mutations and its supplied real gateway transcript demonstrates the intended outcomes, but rejecting legacy ownerless rows is an intentional compatibility boundary that needs an explicit maintainer decision before merge.

## What This Changes

The branch adds plugin-owner checks to `sessions.patch`, repeats authorization against the projection snapshot, and stamps `pluginOwnerId` when a plugin creates a new session row.

## Best Possible Solution

Approve a single documented ownerless-row policy, preserve non-plugin operator control, and align the `sessions.patch` and `sessions.create` ownership helpers before merging the focused fix.
