## Summary

This PR remains necessary because current `main` still allows plugin-runtime callers to patch foreign-owned sessions. The implementation appears correct and race-safe, but merge should wait for real behavior proof and a maintainer decision on the compatibility-sensitive treatment of legacy ownerless rows.

## What This Changes

The PR enforces plugin ownership for `sessions.patch`, stamps ownership on sessions created through patching, and adds regression coverage for ownership and concurrency cases.

## Best Possible Solution

Keep the transaction-selected ownership check and creation-time owner stamping, then land after live proof with a maintainer-approved operator recovery path or provenance-safe migration for legacy ownerless rows.
