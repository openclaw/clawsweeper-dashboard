## Summary

Source and regression coverage support the central fix, but the current branch is not merge-ready: it still carries an unrelated doctor-health change, lacks required real Gateway proof, and intentionally fails closed for legacy ownerless rows without explicit Gateway/session owner approval.

## What This Changes

The branch adds pre-migration, transaction-selected plugin ownership authorization and new-row owner stamping for `sessions.patch`, with ownership and race regression tests, plus an unrelated local-audio doctor-health change.

## Best Possible Solution

Land a sessions-only patch that authorizes the freshest transaction-selected row before migration, stamps plugin ownership only on newly created rows, preserves non-plugin behavior, and includes owner-approved legacy-row recovery semantics plus redacted live Gateway RPC proof.
