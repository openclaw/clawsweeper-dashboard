## Summary

Keep open: current main still permits the reported cross-plugin mutation, and this branch appears correct and more complete than the competing PR, but deployed real-behavior proof is missing and the fail-closed policy for legacy ownerless rows needs explicit maintainer approval.

## What This Changes

The PR adds transaction-safe plugin ownership authorization to `sessions.patch`, stamps ownership on newly created session rows, and adds regression coverage for foreign, ownerless, concurrent, and self-owned mutations.

## Best Possible Solution

Keep the locked pre-migration authorization and new-row ownership stamping, then merge only after maintainers explicitly accept or migrate legacy ownerless rows and deployed plugin-runtime proof demonstrates foreign and ownerless rejection, self-owned success, and non-plugin operator recovery.
