## Summary

Keep open: the patch appears functionally sound with no blocking line-level defect, but merge should wait for deployed plugin-runtime proof and an explicit maintainer decision on rejecting legacy ownerless sessions.

## What This Changes

The PR adds plugin-runtime ownership authorization to session patch mutations, stamps plugin ownership on newly created rows, and adds authorization, persistence, and race regression coverage.

## Best Possible Solution

Use one canonical exact-owner authorization rule across plugin-runtime create, patch, and delete paths; fail closed for ownerless rows unless maintainers approve an explicit operator-mediated recovery path, and prove the final behavior through a deployed Gateway trace.
