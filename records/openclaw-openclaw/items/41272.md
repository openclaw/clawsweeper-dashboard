## Summary

Keep open: current main and release v2026.6.11 still reject or drop explicit `timeoutSeconds: 0` in the Control UI cron form, while the gateway cron contract accepts zero. The linked open pull request at https://github.com/openclaw/openclaw/pull/41275 uses closing syntax for this issue, so the issue should remain open until that fix lands, is refreshed, or is replaced.

## What This Changes

The issue requests that the Control UI cron form accept `timeoutSeconds: 0` as the no-timeout value instead of treating it as invalid.

## Best Possible Solution

Land or replace the focused Control UI fix so validation accepts finite zero, the payload preserves explicit zero, invalid values remain rejected, and regression coverage includes zero plus non-numeric input.
