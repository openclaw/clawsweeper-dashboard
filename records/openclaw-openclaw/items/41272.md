## Summary

## What This Changes

The issue requests that the cron job Control UI accept `timeoutSeconds: 0` as the no-timeout value instead of treating it as invalid.

## Best Possible Solution

Update the Control UI cron form to accept and preserve explicit `timeoutSeconds: 0`, with regression coverage for validation and payload creation; review or close https://github.com/openclaw/openclaw/pull/41275 before queuing a replacement.
