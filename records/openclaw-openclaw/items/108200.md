## Summary

This PR should remain open for a narrow correction: its new regression test still passes with the pre-fix `in` check, and the change does not itself make an own `__proto__` config key safe to project onto a normal object.

## What This Changes

The branch replaces the inherited-property check in `projectSourceOntoRuntimeShape` with `Object.hasOwn` and adds a dedicated prototype-named-key regression test.

## Best Possible Solution

Preserve the own-property predicate if its contract is desired, but first define and test the actual supported projection invariant: safely retain hostile own keys as data properties or explicitly reject them, using a JSON-parsed `__proto__` case and a test that fails on the prior implementation.
