## Summary

Current main contains the reported unconditional cleanup: both rejected Gateway operations still mutate browser-persisted collapsed state through `finally`. This is a valid bounded bug, and the protected `maintainer` label requires explicit maintainer handling. Likely related people: `steipete` is the assigned reporter and likely follow-up owner, with medium confidence.

## What This Changes

Prevent rejected sidebar group rename and delete operations from changing the browser-persisted collapsed-section state.

## Best Possible Solution

Update both handlers to change collapsed-state keys only after successful Gateway completion, preserve the prior state on rejection, surface the existing sessions mutation error feedback, and add focused success-and-rejection tests.
