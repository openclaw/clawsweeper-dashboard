## Summary

Keep this PR open: the patch appears correct and current main still lacks the private-controller/run-budget terminal abort pieces, but merging it intentionally changes fallback/provider behavior and should stay with maintainer acceptance rather than conservative cleanup closure.

## What This Changes

The PR adds marker-gated terminal abort detection, run-budget timeout state, HTTP disconnect reason tagging, cron timeout reason matching, trajectory metadata, and focused regression tests so OpenClaw-owned terminal aborts stop model fallback and auth rotation.

## Best Possible Solution

Land this PR after fallback/provider owner acceptance of the terminal-abort contract, preserving provider-owned AbortErrors as retryable and leaving separate budgeted-fallback design questions to the related cron work.

## Solution Assessment

Yes as a candidate, pending maintainer acceptance. Marker-gating OpenClaw abortable wrappers plus an explicit run-budget state is narrower than treating every AbortError(cause: TimeoutError) as terminal, and it preserves provider-owned abort fallback semantics.
