- `P1`: The PR addresses a real agent/fallback workflow that can waste API calls, hold lanes, and delay user-visible error delivery on timeout-heavy systems.

- `merge-risk: 🚨 message-delivery`: Stopping fallback earlier can change whether a user gets an eventual fallback response versus a surfaced timeout or disconnect error.

## Summary

Keep open: current main has the base caller-abort fix from the merged related gateway PR, but this branch still adds unique internal run-budget, cron-string, compaction, HTTP-disconnect, and marked abort-wrapper coverage with no discrete code defect found; merge still needs explicit owner acceptance because fallback behavior changes are upgrade-sensitive.

## What This Changes

The PR extends agent model-fallback and embedded-runner failover so terminal aborts stop retrying fallback candidates, adds HTTP disconnect abort reasons, cron timeout reason matching, run-budget timeout state, trajectory metadata, and focused regression tests.

## Best Possible Solution

Land this only after the agent/fallback owners explicitly accept the terminal-abort contract and upgrade impact; otherwise narrow it to the accepted subset of terminal sources.
