## Summary

## What This Changes

The PR extends agent model-fallback and embedded-runner failover so OpenClaw-owned terminal aborts stop fallback attempts, tags HTTP disconnect aborts, exports cron terminal reason matching, records run-budget timeout metadata, and adds regression tests.

## Best Possible Solution

Land this after fallback/agent owners accept the terminal-abort contract and upgrade impact; otherwise narrow the patch to only the accepted terminal sources.

## Reproduction Assessment

Yes. Source inspection shows current main lacks the PR's internal run-budget/cause-chain and cron string terminal checks, and the July 3 live Crabbox proof shows current main making real fallback calls while PR head stops before fallback.

## Solution Assessment

Yes, this appears to use the right bounded seam: model-fallback classifies terminal aborts while embedded-runner failover carries the run-budget fact. The broader open cron budget hook is a separate budget-design proposal, and the merged WebChat PR intentionally left this remaining scope here.

## Risks / Open Questions

- Merging intentionally changes configured fallback chains so run-budget, cron timeout-string, HTTP disconnect, compaction, and marked OpenClaw abort-wrapper paths stop earlier instead of trying another model.
