## Summary

Keep this PR open: current main only has the base terminal caller-abort behavior from the merged gateway timeout fix, while this branch still adds useful remaining coverage for tagged HTTP disconnects, OpenClaw-wrapped private run-budget aborts, compaction abort-signal forwarding, and run-budget timeout failover state. No concrete line-level patch defect showed up in the inspected paths, but the fallback/auth semantics are compatibility-sensitive and need maintainer acceptance before merge.

## What This Changes

The PR extends terminal-abort handling in model fallback, tags HTTP disconnect aborts, threads embedded run-budget timeout state through failover and trajectory metadata, and adds focused regression tests.

## Best Possible Solution

Keep this PR as the generic terminal-abort fix, have owners accept or narrow the terminal-vs-retryable abort contract, and leave the cron-specific remaining-budget gate to the separate open cron PR unless maintainers choose to combine them.
