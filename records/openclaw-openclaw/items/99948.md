Full review comments:

- **[P1] Require auth on Telnyx stream URLs:** `extensions/voice-call/src/manager/events.ts:260`
  - body: This sends Telnyx a stable public WebSocket URL with no per-call token, while the existing media stream validator only checks tokens for Twilio. Any client that can reach the endpoint and knows an active Telnyx providerCallId can send a Telnyx-shaped start frame and feed audio into STT, so the Telnyx classic path needs a per-call credential or tokenized URL that is validated before accepting media.
  - confidence: 0.9
- **[P1] Gate stream deferral on a wired handler:** `extensions/voice-call/src/providers/telnyx.ts:93-95`
  - body: Telnyx reports stream-connect support as soon as publicUrl and streamPath exist, but the webhook server can leave mediaStreamHandler null when the streaming provider is missing or unconfigured. In that state conversation calls now defer the initial greeting waiting for a stream that cannot connect, so this should only return true after the media handler is actually available, matching Twilio's readiness contract.
  - confidence: 0.86
