## Summary

## What This Changes

## Best Possible Solution

Derive Telnyx classic stream URLs from the same public origin/path-prefix contract as the existing voice-call stream paths, keep per-call token validation, and require redacted live Telnyx call/WebSocket proof before merge.

## Reproduction Assessment

Yes. Source inspection shows `getClassicStreamUrl()` appends `streamPath` to the full `publicUrl`, while current runtime/tunnel tests commonly use public URLs that already include `/voice/webhook`, producing a WebSocket path the server does not upgrade.

## Solution Assessment

No. The overall direction is plausible, but the best fix must align Telnyx classic stream URL derivation with the existing public origin/path-prefix contract and then prove the real Telnyx call path, not only unit tests.
