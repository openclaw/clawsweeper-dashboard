The branch adds four optional Gateway hosting profiles—local, container, reverse-proxy, and node-mode—that select deployment-specific readiness criteria through configuration, an environment variable, or a Gateway startup flag.

## System Context

Gateway readiness turns startup configuration and live runtime facts into `/ready` and `/readyz` results for deployment hosts and operators. Hosting profiles would layer named deployment postures over the shared readiness system so orchestration treats a Gateway as available only when that posture's required conditions pass.
