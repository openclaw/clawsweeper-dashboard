## What This Changes

This PR adds optional Gateway hosting profiles—local, container, reverse-proxy, and node-mode—selected by config, environment, or a Gateway CLI option to compose readiness requirements for host probes and the `openclaw ready` command.

## System Context

Gateway startup reads configuration, environment, and invocation options, then exposes health and readiness state to host probes and CLI clients. This PR adds a hosting-profile layer that selects additional readiness criteria before `/readyz`, Gateway RPC, status, and `openclaw ready` report whether the running Gateway can accept work.
