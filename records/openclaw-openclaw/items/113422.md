## What This Changes

This PR adds optional Gateway hosting profiles—local, container, reverse-proxy, and node-mode—that select composed readiness requirements through configuration, environment, or a Gateway CLI flag.

## System Context

Gateway readiness turns the running Gateway's lifecycle, configuration, plugin, authentication, storage, and node facts into `/ready` and `/readyz` responses for operators and hosting platforms. This PR adds named deployment postures that select which of those facts must be true before a host treats the Gateway as ready to serve work.
