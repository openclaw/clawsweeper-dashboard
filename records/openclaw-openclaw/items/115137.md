## What This Changes

Fix Claude CLI selected-profile handling so an expired OpenClaw OAuth access token is never forwarded to Claude Code in place of its valid native authentication.

## System Context

OpenClaw resolves an agent’s selected auth profile before preparing a Claude CLI process. The Anthropic CLI integration then supplies compatible selected credentials to Claude Code; an unusable or expired selected OAuth credential must stop the run safely rather than override Claude Code’s native login.
