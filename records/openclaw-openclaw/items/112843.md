## What This Changes

The issue proposes an autonomous retrieval sub-agent that searches code and tools in multiple rounds and returns filtered findings to the main agent.

## System Context

An OpenClaw agent receives a task, uses tools and repository context while reasoning, and produces an answer or code change. The proposed subsystem would sit between task planning and the main agent context, turning a retrieval objective into condensed code or tool findings.
