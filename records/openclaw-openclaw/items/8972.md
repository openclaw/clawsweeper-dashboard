## Summary

Current main and v2026.6.11 still provide exact channel matching, thread-parent fallback, and a literal `*` fallback rather than glob evaluation. The request remains distinct, but its public grammar, mutable-name safety, and authorization precedence require maintainer direction.

## What This Changes

Add glob or wildcard channel-name entries to Discord guild allowlists so dynamically created matching channels work without per-channel config edits.

## Best Possible Solution

Define a Discord-owned explicit pattern contract with exact-ID precedence, opt-in mutable-name matching, deterministic pattern ordering, literal `*` last, audit/status visibility, and focused authorization tests; keep category inheritance and runtime reload separate.

## Solution Assessment

Unclear until maintainers choose the authorization grammar. A dedicated opt-in pattern form with exact-ID precedence is safer than silently treating every existing channel-map key as a glob.
