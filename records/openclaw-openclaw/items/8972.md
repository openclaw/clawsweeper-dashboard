## What This Changes

The issue requests glob-style Discord guild channel allowlist entries so newly created channels with matching names can be accepted without adding each channel to configuration.

## Best Possible Solution

Adopt a Discord-plugin-owned, documented pattern form only if an owner approves its grammar and deterministic precedence; preserve existing exact and parent behavior, keep literal `*` distinct, and add schema, docs, audit/status, and regression coverage.
