## Summary

Keep open: current main and v2026.6.11 still treat Discord guild channel entries as exact id/name/slug keys, thread-parent fallbacks, or the literal `*`; adding pattern admission remains a useful but authorization-sensitive product decision rather than an autonomous bug fix.

## What This Changes

Add documented wildcard or glob matching to Discord guild channel allowlist entries so dynamically named channels can be accepted without per-channel config edits.

## Best Possible Solution

After maintainer approval, add one typed Discord-owned pattern admission surface with exact id/name/slug and thread-parent matches first, deterministic pattern ordering next, literal `*` last, and aligned schema, docs, audit/status output, and focused authorization tests; keep category admission and runtime config reload as separate tracked behaviors.

- **Keep exact allowlists:** Retain exact channel entries and literal `*`, addressing restart latency only through the separate reload work.

## Solution Assessment

Unclear pending maintainer direction.
