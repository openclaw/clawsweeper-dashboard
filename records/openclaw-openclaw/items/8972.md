## What This Changes

The issue requests wildcard/glob matching for Discord guild channel allowlist entries so dynamically created matching channels can be handled without per-channel configuration changes.

## Best Possible Solution

Define a documented Discord-owned pattern authorization form with explicit precedence and regression coverage, while leaving category inheritance to the separate category proposal unless owners intentionally combine the contracts.
