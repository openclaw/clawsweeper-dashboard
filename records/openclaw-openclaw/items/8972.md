## Summary

Keep open: current main and v2026.6.11 still treat Discord guild channel allowlist keys as exact id/name/slug entries, thread-parent fallbacks, or the literal `*`; glob keys such as `ws-*` remain an unresolved authorization-sensitive feature.

## What This Changes

Request support for glob or wildcard-pattern Discord guild channel allowlist entries so dynamically created channels can be admitted without per-channel config edits and gateway restarts.

## Best Possible Solution

Keep this as the canonical Discord glob-pattern tracker until maintainers approve one allowlist contract covering syntax, precedence, schema/types/docs/status/audit behavior, and resolver/preflight tests.
