## Best Possible Solution

Fix the Mattermost plugin's externally installed slash route/activation state path with live Mattermost proof and focused regression tests, while preserving per-command token validation.

## Solution Assessment

Yes, the best path is a narrow Mattermost plugin repair that proves and fixes the state/token mismatch under external package loading. Moving this into core or loosening callback token validation would be the wrong boundary.
