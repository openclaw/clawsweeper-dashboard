Fix a latest-release regression where externalized Mattermost native slash-command callbacks under `/api/channels/mattermost/command` are rejected with 401 before reaching the plugin handler.

## Best Possible Solution

Implement registry-aware gateway-auth public-artifact resolution for externally installed official channel plugins, with packaged-install regression coverage and preserved Mattermost per-command token validation.

## Solution Assessment

Yes. The best fix is core-side registry-aware loading of the plugin-declared gateway-auth artifact, not relaxing `/api/channels/*` auth or moving Mattermost token validation into core.
