## Best Possible Solution

Land or revise the linked registry-aware public-artifact resolution PR so installed official plugins expose the same gateway-auth bypass artifacts as bundled/source plugins without weakening Mattermost's per-command token validation.

## Solution Assessment

Yes, the linked fix direction is the right boundary: make the shared public-artifact loader registry-aware for installed official plugins, instead of adding a Mattermost-only auth exception or weakening token validation.
