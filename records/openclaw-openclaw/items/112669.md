## What This Changes

The PR makes stuck-session recovery act on the captured embedded run and reply operation rather than whichever operation later occupies the same session identifier, preserving replacement work during abort, drain, and force-clear cleanup.

## System Context

The agent runtime tracks active embedded runs and auto-reply operations by session. When stuck-session recovery runs, it must clean up stale work without terminating a replacement that was registered under the same session before cleanup finishes.
