## Summary

This PR addresses the open canonical bug report by capturing the recovery-time embedded and reply run instances instead of acting on whichever run later occupies the session ID. The patch looks directionally correct and has active maintainer involvement, but its supplied evidence is a deterministic Vitest regression rather than after-fix runtime proof, so it should remain open for review and real behavior evidence before merge.

## What This Changes

The PR changes stuck-session recovery to abort, wait for, and force-clear only the captured embedded/reply run generation, with a regression test for a replacement run registered under the same session ID.

## System Context

Embedded-agent recovery cleans up agent runs that appear stuck so a session can resume safely. It reads the active embedded and reply registries, attempts cancellation and draining, then either preserves a replacement run or clears only the stale generation it originally captured.
