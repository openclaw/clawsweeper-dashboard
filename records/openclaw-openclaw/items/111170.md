## What This Changes

This PR rejects malformed UTF-8 JWT payloads before OAuth execution-auth fingerprints use `sub` or `email` as a stable identity, and adds a regression test for the fallback behavior.

## System Context

Execution auth binding converts configured credentials into fingerprints used to associate executions with their OAuth owner. A valid JWT subject or email produces a stable identity fingerprint; absent or invalid identity claims use the opaque OAuth grant so the fingerprint changes with token rotation.
