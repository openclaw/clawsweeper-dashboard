## What This Changes

The issue requests that deleting a cron job also clean up its session-store records and obsolete run artifacts so deleted jobs stop appearing as ghost sessions in the Control UI.

## Best Possible Solution

Define and land one ownership-aware cleanup policy that removes deleted-job cron artifacts while preserving active cron base sessions that carry user state.
