## What This Changes

The issue requests cleanup of cron session records and cron run artifacts when a cron job is removed so deleted jobs stop appearing as ghost sessions in the Control UI.

## Best Possible Solution

Land one maintainer-approved cron deletion/session lifecycle path that clears deleted-job ghost sessions without pruning live base cron state or creating competing cleanup policies.

## Reproduction Assessment

Yes. Source inspection on current main shows `cron.remove` deletes only the cron job row, while the current reaper skips base cron session keys that match the reported ghost-session shape.

## Solution Assessment

Unclear. Direct deletion is plausible for the reported ghost session, but related retention work shows base cron rows can carry live job state, so maintainers need to approve the cleanup boundary before treating this as automation-ready.
