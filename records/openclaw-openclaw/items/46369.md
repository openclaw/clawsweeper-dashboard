## Summary

Keep open: current main and v2026.6.11 still remove only the cron job row while base cron session rows remain outside both `cron.remove` and the `:run:`-only retention sweep. ## What This Changes

The issue asks for deleting a cron job to also remove its associated session records and obsolete run artifacts so deleted jobs do not appear as Control UI ghost sessions.

## Best Possible Solution

Land one maintainer-approved cron session lifecycle policy that removes deleted-job ghost sessions while preserving live cron base rows that carry user preferences.
