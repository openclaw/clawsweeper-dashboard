## Summary

Keep open: current main and v2026.6.11 still remove only the cron job row, while cron base session rows can remain in the session store and appear as ghost sessions. The issue asks cron.remove and Control UI deletion to remove associated cron session records and run-log history so deleted jobs no longer appear as ghost sessions.

## Best Possible Solution

Adopt one owner-approved cron session lifecycle policy that clears deleted-job ghost sessions promptly while preserving live cron base rows and user preferences.
