## Summary

Keep open: current main and the latest release fix the schema-padded modifier/default subset, but the shared message schema still exposes poll fields and `message.send` still rejects content-bearing poll params before Feishu or other channel delivery; the remaining fix needs a maintainer-owned message-tool contract decision.

## What This Changes

Fix the shared message tool so Feishu and other channel `send` actions with files or text are not rejected because poll fields are exposed or auto-filled from the generic schema.

## Best Possible Solution

Land one maintainer-approved shared contract, preferably action/channel-scope poll creation fields away from ordinary `send` while preserving real `poll` validation, with Feishu/Telegram send-with-attachment regression coverage.

Rationale: Current main intentionally rejects content-bearing poll fields on `send`, while the issue asks that ordinary sends not be blocked by fields exposed through the shared schema; the choice changes a cross-channel tool contract.

Owner confidence: high

Options:

- **Action-scope the schema (recommended):** Expose poll creation fields only on the poll-capable action/schema path, keeping ordinary sends small while preserving strict misuse errors for real poll payloads.
- **Sanitize send params:** Strip poll creation params from `action="send"` before the guard, matching the linked PR direction but silently ignoring poll-looking content on send.
- **Keep current guard:** Treat `pollQuestion` and `pollOption` on `send` as true poll intent and close only if maintainers decide the modifier-only fix is sufficient.

Yes for source-level reproduction: current source and tests show `action="send"` with `pollQuestion` or `pollOption` still throws before channel dispatch. I did not run a live Feishu file-send path in this read-only review.

## Solution Assessment

Unclear until maintainer direction: the current metadata-only narrowing is a useful partial fix, but it does not settle whether the best long-term fix is action-scoped schema exposure or send-path sanitization.
