## Summary

Keep open: the report describes a real plugin setup blocker, and current main still installs managed npm plugins with lifecycle scripts disabled, which explains why native addon builds can be missing on Node 24 when no prebuild exists; the remaining fix needs maintainer/security direction before an automated repair should run.

## What This Changes

The issue asks OpenClaw plugin installs to compile, validate, or clearly diagnose native addon dependencies such as better-sqlite3 so installed plugin tools do not fail at first runtime use.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add a guarded native-addon recovery path that detects missing native build artifacts, gives clear install/doctor guidance, and only runs rebuilds through an explicit trusted-plugin/operator-approved flow.

Rationale: The observable bug is valid, but the most direct repair runs untrusted package build scripts during plugin install, which conflicts with an intentional security hardening decision already present in history.

Options:

- **Guarded rebuild and doctor flow (recommended):** Keep --ignore-scripts as the default install behavior, detect missing native bindings or declared native packages, and offer an explicit trusted rebuild or doctor fix path with clear diagnostics.
- **Diagnostics only:** Document and surface native-addon failures without running rebuilds, leaving plugin publishers to ship prebuilts or user-run rebuild instructions.
- **Always rebuild native dependencies:** Run npm rebuild automatically after plugin installs, accepting broader install-time code execution for better native addon compatibility.
