## Summary

Keep open: current main and the latest release still run managed npm plugin installs with lifecycle scripts disabled, while the reported dependency chain relies on better-sqlite3's install script to fetch or build its native binding. The fix needs maintainer security direction before repair automation should run.

## What This Changes

The issue asks OpenClaw plugin install to handle or diagnose native-addon build artifacts so plugins with better-sqlite3 work after install without a hidden manual npm rebuild.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add native-addon detection plus an explicit trusted install or doctor repair path that gives actionable diagnostics before running any rebuild.
