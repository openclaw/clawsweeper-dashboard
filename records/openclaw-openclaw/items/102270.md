## Summary

Keep open: current main and the latest release still run managed npm plugin installs with lifecycle scripts disabled, while the reported dependency chain relies on native addon install/build scripts; the remaining fix needs a maintainer security-boundary decision before repair automation should run.

## What This Changes

The issue reports that managed npm plugin installs do not compile native addon dependencies, causing plugins using better-sqlite3 to fail at runtime on Node 24 with a missing binding.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add native-addon detection plus an explicit trusted install or doctor repair path that surfaces clear diagnostics and rebuilds only after an operator-approved trust gate.
