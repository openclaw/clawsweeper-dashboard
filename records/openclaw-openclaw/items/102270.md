## Summary

Keep open: current main and the latest release still install managed npm plugins with lifecycle scripts disabled, and the reported plugin path depends on a native addon install script; the remaining repair needs maintainer security direction rather than cleanup closure.

## What This Changes

The issue asks OpenClaw to detect, rebuild, warn about, or smoke-test native plugin dependencies so better-sqlite3-based plugins work after `openclaw plugins install` on Node 24 without a hidden manual rebuild.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add native-addon detection plus an explicit trusted install or doctor repair path that gives clear diagnostics and runs targeted rebuilds only after an operator-approved trust gate.
