## Summary

Keep open: current main still installs npm plugins through the script-disabled managed npm path, so plugins whose native dependencies need install/rebuild scripts can still hit the reported missing-binding failure; the right fix needs maintainer direction because enabling rebuilds changes the plugin install security boundary.

## What This Changes

The issue asks OpenClaw plugin installation to handle native-addon dependencies such as better-sqlite3 on Node 24 without leaving users with runtime-only internal server errors.

## Best Possible Solution

Keep script-disabled plugin installs as the default, then add a maintainer-approved native-addon path: either explicit manifest/trust-gated rebuild support or post-install detection that fails with actionable doctor/reinstall guidance instead of a later generic tool error.
