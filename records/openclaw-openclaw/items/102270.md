## Summary

Keep open: current main and v2026.6.11 still run managed npm plugin installs with lifecycle scripts disabled, while the reported dependency chain relies on a native install script; the remaining fix needs maintainer security direction instead of cleanup closure.

## What This Changes

The issue requests that managed npm plugin installs detect, build, rebuild, or clearly repair native addon dependencies such as better-sqlite3 on Node 24.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add native-addon detection plus an explicit operator-approved install or doctor repair path with clear diagnostics and focused tests.

Options:

- **Guarded rebuild and doctor flow (recommended):** Keep --ignore-scripts as the default, detect missing native artifacts or native packages, and offer an explicit trusted rebuild or doctor fix path with clear logs and tests.
- **Diagnostics only:** Warn or fail with actionable guidance and leave rebuilds to plugin publishers or operators without adding install-time code execution to OpenClaw.
- **Automatic rebuild:** Run npm rebuild during managed plugin install and accept broader install-time code execution for native dependency compatibility.

## Reproduction Assessment

Yes at source level: current main suppresses npm lifecycle scripts for managed plugin installs, and better-sqlite3 relies on an install script to obtain or build its native binding. I did not run the live Node 24 @askjo/camofox-browser repro in this read-only review.

## Solution Assessment

Unclear pending maintainer direction: automatic rebuild would address the symptom, but it is not clearly the best default because it executes package scripts. A guarded diagnostic and doctor repair path is the safer maintainable direction unless maintainers choose a different trust model.
