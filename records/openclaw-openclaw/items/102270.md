## Summary

Keep open: current main and the latest release still install managed npm plugins with lifecycle scripts disabled, while the reported dependency chain relies on native addon build/download scripts; the remaining fix needs maintainer security direction before repair automation should run.

## What This Changes

The issue requests managed plugin install or doctor support for native-addon dependencies that fail when npm lifecycle scripts are disabled during plugin installation.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add native-addon detection plus an explicit trusted install/doctor repair path that surfaces clear diagnostics and only rebuilds after an operator-approved trust gate.

- **Automatic rebuild:** Run npm rebuild during managed plugin install and accept broader install-time code execution for native dependency compatibility.
