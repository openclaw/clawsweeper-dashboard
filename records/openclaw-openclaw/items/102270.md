## Summary

Keep open: current main and v2026.6.11 still install managed npm plugins with lifecycle scripts disabled, while the reported dependency chain reaches better-sqlite3, whose native binding depends on its install script. The issue is valid, but the repair needs maintainer security/product direction because the obvious fix path executes plugin dependency scripts.

## What This Changes

The issue reports that managed plugin installs skip native addon build steps, causing plugins with better-sqlite3 to fail on Node 24 until users manually rebuild dependencies.

## Best Possible Solution

Keep lifecycle scripts disabled by default, then add native-addon detection plus an explicit operator-approved Doctor/Fix repair path with clear diagnostics, docs, and focused install tests.
