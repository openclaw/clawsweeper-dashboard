## Summary

The proposed adapter metadata aligns pre-initialization index identity with the provider’s existing default model, and the supplied persisted-index before/after result supports the intended behavior; it should continue through normal PR checks and maintainer review rather than be closed.

## What This Changes

The PR exposes GitHub Copilot’s existing preferred embedding model as adapter metadata and adds regression coverage so plain memory status does not falsely mark a valid Copilot vector index mismatched before provider initialization.

## System Context

Memory Core stores semantic-index identity alongside embeddings and compares that identity during `openclaw memory status`. Before a remote embedding provider is initialized, the comparison uses provider metadata; this PR supplies the Copilot default model so status can validate the stored index without first performing provider discovery.
