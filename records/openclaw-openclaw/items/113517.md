## What This Changes

Adds an optional, sanitized external-verification label and allow-once/allow-always choice set to plugin approval presentations, Gateway schemas, SDK exports, and the generated Swift Gateway model.

## System Context

Plugins submit approval requests that OpenClaw converts into a bounded reviewer-safe presentation; the Gateway then projects that presentation to clients, while the host remains responsible for the approval lifecycle and final decision. This PR adds only the optional external-verification presentation data used by future plugin-owned verification flows.
