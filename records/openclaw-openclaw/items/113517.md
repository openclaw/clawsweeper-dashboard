## What This Changes

Adds a plugin-owned external-verification approval flow so a plugin can verify an allow decision while the Gateway retains approval identity, reviewer authorization, denial, cancellation, and final audit ownership.

## System Context

Plugins can stop a protected tool call and ask the Gateway to create an approval visible to authorized reviewers. This flow adds an external verification ceremony between the review request and the Gateway’s final decision, then resumes or blocks the protected tool call.
