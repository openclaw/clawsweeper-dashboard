## What This Changes

This PR adds a plugin-owned external verification ceremony for protected tool calls, with Gateway-owned approval lifecycle and decisions, native TUI/client actions, plugin SDK APIs, protocol messages, durable attempt records, and Codex hook integration.

## System Context

A plugin may intercept a protected tool call and request an approval before execution. The Gateway stores and presents that approval to clients, an external verifier may complete only its host-issued attempt, and the Gateway then records the terminal decision that allows or blocks the original tool call.

  C --> D[Native client action]
  D --> E[External verifier attempt]
  E --> F[Gateway decision ledger]
  C --> F
  F --> G[Continue or deny tool call]

Land only a narrowly documented, verifier-agnostic core seam after an owner confirms the permanent plugin API and a redacted real run shows a successful verifier completion authorizing only the exact host-bound protected call; keep World-specific proof, broker, and signing behavior in AgentKit or another external plugin.
