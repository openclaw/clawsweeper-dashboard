The implementation is a focused, behavior-neutral public contract that aligns the core approval projection, Gateway protocol, generated Swift client, and plugin SDK baseline; however, adopting the new field and its decision literals creates a durable compatibility commitment that needs explicit maintainer acceptance.

## What This Changes

Adds an optional, sanitized external-verification label and allow-once/allow-always choice set to plugin approval presentations, Gateway schemas, SDK exports, and generated Swift Gateway models.

## System Context

Plugin approval requests enter core, where OpenClaw sanitizes them into reviewer-safe presentation data before Gateway clients render an approval flow. This PR adds a provider-neutral external-verification descriptor while leaving the existing approval resolver and lifecycle unchanged.
