## What This Changes

Adds a plugin-owned external-verification path for protected tool approvals, including Gateway actions, plugin SDK APIs, durable attempt history, native client flows, and Codex hook routing.

## System Context

Plugins can request approval before a tool call; Gateway owns the approval record, reviewer authorization, and final decision. This change lets a plugin run an external verification ceremony while the host controls denial, expiry, retry, and protected-tool continuation.
