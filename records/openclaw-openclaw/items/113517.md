## What This Changes

Adds a plugin-owned external-verification ceremony for protected tool calls, including host-bound Gateway approval attempts, plugin SDK APIs, native reviewer actions, durable audit records, client protocol projections, documentation, and tests.

## System Context

Plugins can request a protected-tool approval from the agent tool-call hook; the Gateway owns the pending approval, reviewer authorization, lifecycle, and final allow or deny result. This PR adds a narrow verifier capability so an external ceremony can complete only a host-bound attempt before the tool call resumes.

  D --> E[Plugin-bound external verifier]
  E --> F[Host validates attempt completion]
  F --> G[Final allow or deny]
  G --> H[Protected tool call continues or stops]
