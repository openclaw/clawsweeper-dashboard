## What This Changes

Adds plugin-owned external verification for protected tool approvals, with Gateway-owned approval state, plugin SDK APIs, persistent attempt records, command/UI fallbacks, lifecycle recovery, and documentation.

## System Context

Plugins can ask OpenClaw to pause a protected tool call while an external verifier performs a separate ceremony. The Gateway keeps the approval identity, reviewer authorization, denial, timeout, cancellation, and final tool-continuation decision, while the plugin receives only a bound verification attempt and completion interface.
