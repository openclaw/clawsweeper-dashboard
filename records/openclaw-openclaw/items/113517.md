## What This Changes

This PR adds a provider-agnostic, plugin-owned external verification ceremony that can gate protected tool calls while the Gateway retains approval lifecycle, authorization, and final decision ownership.

## System Context

Plugins can request a protected-tool approval before an agent action runs. This change lets a plugin present an external verification challenge through the Gateway and native clients, then lets the Gateway resolve or deny the specific bound approval and continue or block the tool call.
