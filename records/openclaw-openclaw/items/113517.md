## What This Changes

This PR lets a plugin require an external verification ceremony before allowing a protected tool call, while the Gateway retains approval identity, denial, timeout, cancellation, and durable resolution authority.

## System Context

Plugin hooks can stop a tool call and create a Gateway approval. This change adds a plugin-owned verifier path for allow decisions, then records the result in Gateway state and presents safe instructions to CLI, channel, and Control UI reviewers.
