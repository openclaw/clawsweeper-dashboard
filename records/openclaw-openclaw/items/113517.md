## What This Changes

This PR adds a plugin-owned external-verification approval flow so an installed plugin can verify a reviewer before Gateway authorizes a protected tool call.

## System Context

Plugin hooks can pause a protected agent tool call and request an approval through Gateway. Gateway stores and presents the approval, lets a plugin run an external verification ceremony, then records the final allow or deny outcome before the tool call continues or remains blocked.
