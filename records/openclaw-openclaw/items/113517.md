## What This Changes

This PR adds a plugin-owned external-verification flow that can complete configured allow decisions for protected tool calls while Gateway retains approval lifecycle, denial, reviewer authorization, and audit ownership.

## System Context

Plugin `before_tool_call` hooks can require approval before a protected agent tool call proceeds. This change carries an external-verification choice into Gateway-owned approval state, dispatches the plugin verifier, and returns a final allow or deny outcome to the waiting agent run.
