## Summary

Current main does not implement durable parent invalidation for direct child or ACP changes. The issue is concrete, vision-aligned, and protected by the maintainer label, so it should remain open for an explicit architecture decision.

## What This Changes

Add durable child-session state versioning and parent invalidation so direct human or ACP interactions do not leave parents stale.

## Best Possible Solution

Adopt a core-owned SQLite version-and-invalidation contract first: monotonic per-session heads, durable parent-child cursors, restart recovery, and one coalesced ephemeral system-event projection; add retained typed history and changesSince only when concrete reconciliation consumers justify the larger contract.
