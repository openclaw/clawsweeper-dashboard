## Summary

Keep this PR open for repair: the locale-independent marker is a sound direction, but the pre-`stat` existence test changes established dangling-symlink behavior and leaves a check-before-use race. Likely related people: @steipete (high confidence), @davidbors-snyk (medium confidence), and @hydro13 (medium confidence), based on the sandbox filesystem bridge’s introduction and subsequent hardening history.

## What This Changes

The PR makes sandbox stat classify missing paths through a reserved stdout marker instead of English stderr matching and adds mocked regression coverage.

## Best Possible Solution

Run `stat` first, then emit the reserved marker only when the failed basename is neither an existing target nor a symlink entry, preserving dangling-symlink metadata, non-missing errors, and locale independence without a check-before-use gap.
