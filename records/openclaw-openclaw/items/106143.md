## Summary

The central locale bug is valid and the structured marker direction is preferable to localized stderr matching, but the current shell classifier can still convert an inaccessible entry into a successful missing result. The prior P1 finding remains on the unchanged reviewed head, and the external PR still lacks live container proof, so it is not merge-ready.

## What This Changes

The PR replaces English sandbox `stat` stderr matching with a reserved missing-path marker emitted by the shell plan and adds regression tests for missing paths, dangling symlinks, and non-missing failures.

## Best Possible Solution

Keep one structured, locale-independent stat outcome, but emit the missing marker only from a primitive that reliably distinguishes true `ENOENT` from access or I/O failures, preserve dangling-symlink metadata, and prove missing, dangling-symlink, and permission-denied cases in a real localized sandbox container.
