This PR remains necessary: it is the active candidate fix for the linked Signal false-success report, and the renewed evidence addresses the prior real-behavior-proof gate with a production HTTP/JSON-RPC loopback run. ## What This Changes

The PR changes Signal send handling to reject failed per-recipient JSON-RPC results for direct sends while retaining a receipt for partially delivered group messages, with regression coverage using a local real HTTP JSON-RPC server.

## System Context

The bundled Signal extension turns OpenClaw send requests into signal-cli JSON-RPC calls and converts their responses into delivery receipts or errors. This change sits between the RPC response and the channel receipt returned to agents and callers.
