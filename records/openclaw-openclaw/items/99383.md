## Summary

The source, focused tests, production discussion, and final-head live Anthropic matrix support the no-compaction failure and a coherent symmetric prevention fix. This PR should remain open for explicit maintainer approval because it intentionally changes the default replay policy for all thinking-enabled native Anthropic sessions.

## What This Changes

The PR makes both native Anthropic request builders omit completed-turn signed thinking while preserving the active/current tool-use turn and ignoring trailing runtime-context carriers when locating boundaries.

## Best Possible Solution

Adopt one documented current-turn replay policy across both native Anthropic builders, retain active-turn and rejection-recovery protections, and explicitly record that completed-turn reasoning and cache continuity are intentionally traded for replay resilience.
