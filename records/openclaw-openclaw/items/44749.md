## Summary

Keep open: current main and the latest release still mutate a previously loaded exec approvals object and write the whole approvals file, so concurrent allow-always approvals can still clobber earlier allowlist entries.

## What This Changes

The issue asks OpenClaw to preserve every concurrently approved allow-always exec allowlist entry instead of letting the last whole-file write win.

## Best Possible Solution

Land a vetted exec-approvals persistence fix that reloads and merges or hash-checks under one serialization boundary for allow-always and usage metadata writes across gateway and node paths, with focused concurrent-write regression coverage.
