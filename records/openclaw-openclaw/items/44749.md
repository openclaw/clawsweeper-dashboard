## Summary

Keep open: current main and the latest release still persist allow-always and usage updates by saving caller-held exec approval snapshots, so concurrent approval handlers can still overwrite earlier allowlist entries.

## What This Changes

The issue asks for concurrent allow-always exec approvals to preserve all allowlist entries instead of letting stale exec-approvals.json snapshots overwrite each other.

## Best Possible Solution

Land a vetted exec-approvals persistence fix that reloads and merges or hash-checks under one lock/CAS boundary for allow-always and usage metadata writes across gateway and node paths, with focused concurrent-write regression coverage.
