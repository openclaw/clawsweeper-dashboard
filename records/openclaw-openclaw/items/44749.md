## Summary

Keep open: current main and the latest release still mutate a caller-supplied exec approvals snapshot and save the whole approvals file, so concurrent allow-always approvals can still overwrite earlier persisted allowlist entries.

## What This Changes

The issue reports silent loss of persisted exec allowlist entries when multiple allow-always approvals resolve concurrently.

## Best Possible Solution

Land a vetted exec-approvals persistence fix that serializes or CAS-merges allow-always and usage metadata writes across gateway and node paths, with focused concurrent-write regression coverage.
