## Summary

Keep open: current main and v2026.6.11 still save request-local exec approval snapshots back to `exec-approvals.json`, so concurrent `allow-always` approvals can still clobber earlier allowlist entries. The direct fix PRs are closed unmerged, and the overlapping open PR is conflicting/proof-gated rather than a safe canonical fix for this issue.

## What This Changes

The issue reports that concurrent `allow-always` exec approvals overwrite `exec-approvals.json` from stale snapshots, silently dropping earlier allowlist entries.

## Best Possible Solution

Land a vetted exec-approval persistence fix that serializes or freshness-checks every allow-always and allowlist-usage write, re-reads or merges current state before saving, and covers both gateway and node execution paths with focused regression tests.
