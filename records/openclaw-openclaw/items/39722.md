- `P2`: This is a normal user-facing Gateway/TUI session-list bug with limited blast radius and no evidence of data loss or a hard setup/runtime blocker.
- `impact:session-state`: The issue affects session list identity/title projection by deriving display state from injected transcript metadata instead of the intended session metadata or user text.
- `impact:ux-friction`: Wrong session titles make the TUI session picker harder to scan, but users can still continue by using keys or other context.
- `maturity:stable`: The affected sessions.list Gateway RPC surface maps to gateway-runtime, which is currently scored M4 Stable in qa/maturity-scores.yaml.

## Summary

Keep open: current main still lets Gateway/TUI derived session titles come from the raw first user transcript text, so the injected metadata envelope can still win over a clean title. The same-repo fix PR was closed unmerged, and the currently open fork PR is an implementation candidate rather than a reason to close this issue before a fix lands.

## What This Changes

The issue asks for TUI and Gateway session lists to strip injected inbound metadata from derived titles and prefer session display names or subjects before transcript excerpts.

## Best Possible Solution

Land or reject a current-main fix that strips inbound metadata before title derivation and gives clean session label/displayName/subject precedence in both Gateway/TUI session-list hydration paths.

## Reproduction Assessment

Yes for source-level reproduction: the TUI asks for derived titles and prefers them, while current Gateway title extraction returns the raw first user message without stripping inbound metadata. I did not run a live TUI/Gateway session in this read-only review.

## Solution Assessment

Yes, the narrow maintainable fix is to sanitize only the title-extraction display path and thread the already-computed display metadata through the Gateway title hydration paths. Rewriting persisted user messages would be the wrong boundary and was rejected in the related closed PR discussion.
