## Summary

Keep open: current main and the latest release still let the TUI session picker render a transcript-derived title before the useful display name, while the title extractor still returns inbound metadata text without using the existing sanitizer. ## What This Changes

Fix the TUI session list so gateway-injected inbound metadata is stripped from derived titles and computed session display names take precedence over raw first-message text.

## Best Possible Solution

Land or adopt one narrow Gateway fix that strips inbound metadata during title extraction and threads computed row displayName through both sync and async derived-title hydration, with focused regression coverage and real TUI/Gateway proof.
