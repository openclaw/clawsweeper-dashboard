## Summary

Keep open: current main and latest release still allow Gateway/TUI session titles to be derived from unstripped inbound metadata, and the same-repo fix PR was closed while the remaining fork PR is open but conflicting and uneditable by maintainers.

## What This Changes

The issue asks for TUI session titles to prefer usable session display metadata and to strip gateway-injected inbound metadata before using transcript text as a fallback title.

## Best Possible Solution

Land or adopt one narrow Gateway fix that strips inbound metadata during title extraction and threads computed row displayName through every Gateway-derived title path, while leaving broader title-quality work to https://github.com/openclaw/openclaw/issues/81781.
