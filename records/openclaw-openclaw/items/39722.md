## Summary

Keep open: current main and the latest release still let the TUI prefer a transcript-derived title over row display metadata, while the transcript title extractor does not strip the gateway-injected `Sender (untrusted metadata)` block. The remaining direct fix path is an open, conflicting fork PR, so this needs maintainer branch-path review rather than cleanup closure.

## What This Changes

The issue asks for TUI `/sessions` titles to prefer populated session display metadata and strip gateway-injected inbound metadata before deriving titles from transcript text.

## Best Possible Solution

Land or adopt one narrow Gateway fix that strips inbound metadata during title extraction and lets explicit computed row display metadata win before raw transcript fallback, with focused regression coverage for sync and async sessions.list hydration plus TUI picker proof.
