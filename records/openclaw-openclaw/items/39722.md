## Summary

Keep open: current main and the latest release still let the TUI gateway session picker prefer a derived title built from unsanitized first-user transcript text, while the direct session display name lives on the projected row rather than the entry passed to `deriveSessionTitle`. A conflicting open fork PR already targets this issue, so the next step is maintainer review rather than closing or queueing another fix.

## What This Changes

The issue asks for TUI `/sessions` titles to prefer explicit session display metadata and ignore gateway-injected inbound metadata when deriving fallback titles.

## Best Possible Solution

Land or replace a narrow gateway/TUI fix so session titles prefer explicit label/displayName/subject metadata and strip inbound metadata before falling back to transcript text; keep broader title-quality work in https://github.com/openclaw/openclaw/issues/81781.
