## Summary

Keep open: current main still lets a gateway-injected metadata envelope become the derived session title, and the TUI still prefers that derived title over the useful row display name. The matching fix path exists only as an open conflicting fork PR, so this should not be closed as implemented.

## What This Changes

The issue requests that TUI session titles strip gateway-injected inbound metadata and prefer usable session display metadata before falling back to transcript text.

## Best Possible Solution

Land one narrow Gateway session-title fix that strips inbound metadata during title extraction and lets explicit or computed row display metadata win before raw transcript fallback, with sync/async session-list regression coverage and TUI picker proof.
