## Summary

Keep open: current main and v2026.6.11 still let the TUI session picker render a transcript-derived title before displayName, while the transcript title extractor does not strip gateway-injected inbound metadata. The direct same-repo fix PR is closed unmerged and the remaining open fork PR is conflicting, so this should stay open for maintainer routing rather than be closed as implemented.

## What This Changes

The issue asks OpenClaw to keep TUI session titles from using gateway-injected inbound metadata by preferring displayName/subject and stripping metadata before transcript-derived fallbacks.

## Best Possible Solution

Land or adopt one narrow Gateway fix that strips inbound metadata during title extraction and threads computed row displayName through both sync and async derived-title hydration, with focused regression coverage and real TUI/Gateway proof.
