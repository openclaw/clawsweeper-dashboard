## Summary

Keep open: current main and the latest release still let the TUI prefer a transcript-derived title that can contain unstripped gateway inbound metadata, while the direct same-repo fix PR is closed unmerged and the remaining fork PR is open but dirty.

## What This Changes

Strip gateway-injected inbound metadata from session-derived titles and prefer the resolved session display name before transcript excerpts in the TUI `/sessions` list.

## Best Possible Solution

Land a narrow shared gateway fix that strips inbound metadata before first-user-message title extraction, passes the resolved row display name into both sync and async derived-title paths, and adds focused session-list/TUI regression coverage.
