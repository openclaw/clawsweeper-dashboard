## Summary

Keep open: current main and the latest release still let TUI session rows prefer a transcript-derived title over the resolved row display name, and the transcript title extractor still does not strip inbound metadata. The exact fix is already paired with an open fork PR, but that PR is conflicting and not maintainer-editable, so this needs maintainer branch-path review rather than a second automated fix.

## What This Changes

The issue requests that TUI `/sessions` titles ignore gateway-injected inbound metadata and prefer the resolved session display name before transcript-derived text.

## Best Possible Solution

Land one narrow Gateway/TUI session-title fix that strips inbound metadata before deriving transcript titles and feeds the already-resolved row display name into every derived-title call path, including sync, async, and agent-tool session listing.
