Full review comments:

- **[P1] Require real auth before task execution:** `extensions/a2a/index.ts:100-103`
  - body: This route declares `auth: "plugin"`, which current OpenClaw docs define as plugin-managed auth, but the handler never checks `auth.mode`, `X-Gateway-Token`, or any plugin credential before creating sessions and invoking `sessions.send`.   - confidence: 0.91

  - body: The standalone server accepts a caller-supplied `target` and `auth` token, then posts the token-bearing request to that URL with no allowlist or trust boundary. Bundling this as a supported utility creates SSRF and credential-forwarding risk; remove the forwarding path or gate it behind explicit trusted targets and credential handling.
  - confidence: 0.82
