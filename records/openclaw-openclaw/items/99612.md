- **[P1] Require auth before dispatching A2A tasks:** `extensions/a2a/index.ts:100-103`
  - body: This route is declared with `auth: "plugin"`, which means the plugin must verify the caller itself; the handler never checks the documented gateway token before creating a session and sending work, so enabling it exposes task execution to any reachable caller.
  - confidence: 0.91
- **[P1] Restrict outbound forwarding targets:** `extensions/a2a/standalone.ts:142-146`
  - body: `params.target` is used as the fetch URL and `params.auth` is forwarded as a bearer token without an allowlist or trust boundary, so the standalone utility can be driven into SSRF and credential-forwarding behavior if bundled as supported code.
  - confidence: 0.82
- **[P2] Align the manifest with documented config:** `extensions/a2a/openclaw.plugin.json:7-8`
  - body: The schema rejects unknown top-level keys but does not define `gatewayUrl`, while the docs tell users to set it and the runtime reads it; the same mismatch exists between documented `agents.expose` and runtime `agents.list`, so documented setup cannot configure the plugin as described.
  - confidence: 0.86
