## Summary

Keep open: current main and the latest release still let QuickStart Anthropic setup carry an Opus default into terminal hatch without a paid-credit or billing-readiness warning, so the first-run UX problem remains.

## What This Changes

The issue requests safer Windows QuickStart behavior when Anthropic is selected so the first terminal chat does not surprise new users with a paid Opus model billing failure.

## Best Possible Solution

Add an in-product pre-hatch warning or readiness check for Anthropic Opus billing state, with a non-technical recovery path such as choosing a cheaper model or opening model setup before the first terminal chat.
