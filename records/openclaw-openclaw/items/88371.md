## Summary

Keep open: current main and the latest checked release still route Anthropic setup-token onboarding to an Opus default and the terminal hatch path lacks a clear pre-hatch billing or credit warning, so the Windows QuickStart first-run problem remains.

## What This Changes

Windows QuickStart should avoid sending the first terminal chat through a paid Anthropic Opus default without credit or billing readiness warning.

## Best Possible Solution

Choose a billing-safe Anthropic QuickStart policy, then align the provider default, model picker/finalize warning, first-chat failure copy, docs, and Windows QuickStart proof.
