## Summary

Keep open: current main has better Anthropic billing observability and friendlier billing-error copy, but Anthropic API-key/setup-token onboarding still seeds Opus 4.8 and I found no pre-hatch paid-credit warning or credit-readiness check for the reported Windows QuickStart first chat.

## What This Changes

The issue asks Windows QuickStart Anthropic onboarding to avoid silently launching the first terminal chat on a paid/high-cost Anthropic model without a clear credit or billing warning.

## Best Possible Solution

Make the Anthropic-owned onboarding path explicitly handle API-key billing before terminal hatch, either by using a maintainer-approved lower-cost first-run default or by requiring a clear paid-credit confirmation, then validate on Windows QuickStart.
