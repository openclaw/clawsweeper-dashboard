## Summary

Keep open: current main and the latest release still let Windows QuickStart select Anthropic's Opus default and launch the first Terminal chat without a paid-credit warning or billing-readiness check.

## What This Changes

The issue asks for Windows QuickStart to avoid or warn about a paid Anthropic first-chat default that can fail immediately for users without API credits.

## Best Possible Solution

Add a billing-aware pre-hatch warning or readiness check for Anthropic API-key/setup-token first runs, with clearer first-chat billing/auth recovery copy, while preserving existing model choices unless maintainers explicitly choose a lower-cost default.
