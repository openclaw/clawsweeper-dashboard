## Summary

Keep open: current main and the latest release still let Windows QuickStart choose Anthropic and proceed to first Terminal chat with an Opus default but no pre-hatch billing/credit warning or readiness check.

## What This Changes

The issue asks OpenClaw to avoid or warn about paid Anthropic Opus defaults during Windows QuickStart before the first chat can fail on provider credits.

## Best Possible Solution

Add an owner-approved setup-wizard billing readiness or paid-model warning before Terminal hatch, with an in-product switch-provider or safer-model path that preserves explicit existing model choices.
