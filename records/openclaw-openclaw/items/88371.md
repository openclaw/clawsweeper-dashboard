## Summary

Keep open: current main and the latest release still route Anthropic QuickStart auth through an Opus default and only run a generic model/auth check before terminal hatch, so the paid-credit first-run policy remains unresolved.

## What This Changes

The issue asks Windows QuickStart to avoid or clearly warn about a paid Anthropic Opus default before the first terminal chat.

## Best Possible Solution

Add an explicit Anthropic paid-credit or billing-readiness warning before terminal hatch, or adopt a maintainer-approved safer first-run default, while preserving existing stored model choices during upgrades.
