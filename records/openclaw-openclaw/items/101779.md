## Label Justifications

- `P1`: The PR addresses real auth/session test breakage on paired developer Macs, including leakage and possible clobbering of device-auth tokens.
- `merge-risk: 🚨 compatibility`: Existing override-based macOS runs may stop importing App Group identity/auth into the selected state dir after this change.
- `merge-risk: 🚨 session-state`: Device identity selection controls reconnect continuity and whether a run keeps or mints a device identity.
- `merge-risk: 🚨 auth-provider`: The affected migrated files include device-auth tokens keyed to the preserved identity, so mistakes can force re-pairing or token loss.

## Summary

No blocking correctness finding found. Keep this PR open for maintainer handling because it has the protected `maintainer` label and intentionally changes auth/session migration semantics for explicit `OPENCLAW_STATE_DIR` overrides.

## What This Changes

The branch makes OpenClawKit skip App Group identity/auth migration when `OPENCLAW_STATE_DIR` is set and centralizes Swift test state-dir isolation in `StateDirectoryIsolationTrait`.

## Best Possible Solution

Land the override-isolation behavior after a maintainer accepts the compatibility tradeoff and exact-head checks are refreshed, keeping App Group migration only for the implicit legacy fallback path.
