## Summary

Keep open: this is a focused bug-fix PR that still appears necessary because current main's App Group fallback migration can run even when the destination store was selected by an explicit OPENCLAW_STATE_DIR override. The patch is correct on source review, but the maintainer label plus identity/auth storage compatibility risk mean it should get human merge review rather than cleanup close.

## What This Changes

The branch makes App Group identity/auth migration skip explicit OPENCLAW_STATE_DIR stores and centralizes repeated Swift test state-dir setup in StateDirectoryIsolationTrait.

Land the override guard and test-isolation refactor after maintainers accept the override-isolation compatibility choice and exact-head Swift/CI proof is green.
