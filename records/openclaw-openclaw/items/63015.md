## What This Changes

## Best Possible Solution

## Reproduction Assessment

Yes from source inspection. Current main and v2026.6.11 normalize only `mediaUrl`, so `normalizeOutboundReplyPayload({ filePath: ... })`, `{ path: ... }`, or `{ media: ... }` will not produce outbound media.
