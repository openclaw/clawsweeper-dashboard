## Review Findings

Full review comments:

- **[P2] Skip blank aliases before falling back:** `src/plugin-sdk/reply-payload.ts:40-49`
  - body: This chain treats an empty string in `mediaUrl`, `filePath`, or `path` as the selected value. A payload such as `{ mediaUrl: "", filePath: "/tmp/a.png" }` normalizes to an empty `mediaUrl`, and downstream media resolution treats that as no media, so the attachment is still silently dropped.
  - confidence: 0.88
- **[P2] Match message-send media alias precedence:** `src/plugin-sdk/reply-payload.ts:40-49`
  - body: The current message-send path resolves `media` before `mediaUrl`/`path`/`filePath` and has regression coverage for `media` winning over `mediaUrl`, but this patch locks `media` to the lowest priority. Payloads with multiple aliases would send different attachments depending on whether they travel through reply normalization or message send.
  - confidence: 0.83
