## Summary

## What This Changes

The issue asks OpenClaw to stop oversized session transcripts from entering a crash-restart/OOM loop by bounding transcript loading, bootstrap replay growth, media duplication, and degraded-session retry behavior.

## Best Possible Solution

Define a default recovery boundary that prevents oversized transcripts from being whole-file retried indefinitely, caps bootstrap marker re-appends on the active runner path, and offers an in-product doctor/session recovery path for degraded sessions.
