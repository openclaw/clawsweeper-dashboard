## What This Changes

## Best Possible Solution

Keep canonical auth profiles inside provider-owned code, reject provider/profile/kind inconsistencies before any callback, return a closed minimal backend envelope, and review that complete runtime seam together with SDK baselines, docs, focused tests, security-owner approval, and redacted live CLI proof.
