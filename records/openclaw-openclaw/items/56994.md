## Summary

Keep open: current main and v2026.6.11 still rewrite shell profile files with direct `fs.writeFile` in `installCompletion`, even though the shared JSON, exec-approval, and restart-sentinel parts of the original report are now fixed or superseded.

## What This Changes

The issue requests atomic writes for crash safety across exec approvals, restart sentinel state, shell profile updates, and shared JSON saves.

## Best Possible Solution

Land a narrow `src/cli/completion-runtime.ts` change that routes profile creation and update through the existing atomic text replacement helper with shell-profile permissions, while leaving the already-fixed JSON, exec-approval, and restart-sentinel paths alone.

## Solution Assessment
