## What This Changes

The issue requests atomic writes for crash-safety across exec approvals, restart sentinel persistence, shell completion profile updates, and shared JSON saves.

## Best Possible Solution

Keep the already-fixed JSON, exec-approval, and restart-sentinel paths as-is, and land a narrow maintainer-approved completion-profile patch that uses the existing atomic text replacement helper with `0o644` profile mode and focused tests.
