## Summary

The stalled-request bug is real and the aborting mechanism is well proven, but the existing P1 blocker remains: applying the 30-second control-plane budget to supported SharePoint file transfers can make previously successful slow sends fail.

## What This Changes

## Best Possible Solution

Keep the shared abortable timeout owner, give SharePoint content transfer an upload-specific deadline, retain 30 seconds for membership, link, and metadata calls, and prove both hard-stall cancellation and slow successful transfer behavior.
