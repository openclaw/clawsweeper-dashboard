## Summary

This PR fixes a real unbounded-request bug and has strong transport proof, but the fixed five-minute SharePoint upload ceiling can abort valid configured large or slow sends. The upload deadline should be size-aware and reconciled with the adjacent consent-upload work before merge.

## What This Changes

The branch adds an abort-aware timeout helper, applies a five-minute deadline to SharePoint content uploads and 30-second deadlines to related Graph control-plane requests, and adds focused timeout regression tests.

## Best Possible Solution

Keep the full-lifecycle abort behavior, retain short deadlines for Graph control-plane calls, and use one shared payload-size-aware SharePoint upload deadline across group/channel and consent upload paths.
