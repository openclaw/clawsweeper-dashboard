## Summary

Keep open: current main and the latest release still apply MCP `toolFilter` entries to raw server tool names while `openclaw mcp probe` returns projected namespaced tool names. The linked open PR is the active candidate fix, so this issue remains necessary until that PR lands or is replaced.

## What This Changes

The issue reports that MCP per-server tool filters silently hide all tools when users copy namespaced names from `openclaw mcp probe` into `mcp tools --include` or `--exclude`.

## Best Possible Solution

Land or replace the focused MCP filter fix so filters accept the names users see from probe, raw-name filters keep working, and zero-match includes produce a clear diagnostic.
