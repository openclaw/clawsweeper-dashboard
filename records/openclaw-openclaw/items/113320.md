## What This Changes

This PR backports Doctor’s post-plugin-install channel compatibility and repair pass to `release/2026.7.2`, allowing legacy plugin-owned channel settings to be normalized before Gateway restart.

## System Context

During an upgrade, OpenClaw Doctor may install a configured channel plugin that was missing locally. The plugin exposes its compatibility and repair contracts only after installation, and those contracts must run before later validation and Gateway restart consume the configuration.
