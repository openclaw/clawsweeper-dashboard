Keep open. Current main and v2026.6.11 still omit the Signal `linkPreview` config and outbound preview pass-through, and implementation needs maintainer direction because it changes Signal account configuration and touches untrusted URL preview metadata.

Request adding a first-class `channels.signal.linkPreview` config option and passing Signal preview configuration/fields through outbound signal-cli sends.

## Best Possible Solution

Add maintainer-approved Signal plugin support that is opt-in/default-safe, documents native/container and primary-device behavior, and passes only explicit preview fields unless the link-preview security design approves metadata fetching.
