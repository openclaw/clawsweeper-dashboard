## What This Changes

Add a first-class `channels.signal.linkPreview` setting and pass safe Signal link-preview fields through outbound Signal sends.

## Best Possible Solution

Define a Signal-plugin-owned preview control that preserves unset behavior, separates explicit preview metadata pass-through from any metadata fetching, documents native/container limits, and keeps fetched metadata out of agent context unless the security design approves it.
