- **[P1] Include quoted text in BodyForAgent:** `extensions/signal/src/monitor/event-handler.ts:231`
  - body: For a quoted Signal reply with new text, this keeps `BodyForAgent` as only the new message and puts the quoted target only in reply metadata.   - confidence: 0.9
- **[P1] Keep null suppression out of the public reply payload API:** `src/plugin-sdk/reply-payload.ts:45`
  - body: `OutboundReplyPayload` is a public plugin SDK contract, and widening `replyToId` to `string | null` exposes an internal suppression sentinel to third-party plugin callers. Keep null suppression internal, or land it only with explicit API approval, docs/baseline updates, and compatibility tests.
  - confidence: 0.88
- **[P2] Forward quote metadata through container mode:** `extensions/signal/src/send.ts:267-270`
  - body: This adds quote fields to the Signal send RPC params, but the configured Signal adapter can route sends through container mode, whose send translation currently ignores quote fields. Container users would still send top-level messages with no native quote indicator, so the PR's Signal quote support is incomplete for a documented Signal transport.
  - confidence: 0.78
