## Summary

Keep open for maintainer product/security review: current main and v2026.6.11 still define one trusted Gateway operator domain and do not provide tenant claims, tenant-scoped operator scopes, tenant-aware approval/audit storage, or fail-closed tenancy.

## What This Changes

The issue requests first-class hostile multi-tenant RBAC primitives across Gateway sessions, runs, approvals, operator scopes, audit, and tenancy defaults.

## Best Possible Solution

Keep this FRD open until maintainers accept or reject hostile same-gateway tenancy as a core goal, then split any accepted direction into protocol/auth, session/run storage, approval, audit, config/default, migration, and docs sub-issues.
