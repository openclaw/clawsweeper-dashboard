## Summary

Keep this PR open, but do not merge it as written: the bounded-read branch now hashes only the first 50 MiB of an oversized file, so changes after that boundary no longer invalidate the installed-plugin index. The prior P1 concern remains unresolved; real after-fix runtime proof is also still required before merge.

## What This Changes

The PR adds metadata checks and bounded chunked hashing for oversized files used by the installed-plugin index, with a sparse-file regression test.

## Best Possible Solution

Stream the entire regular file in fixed-size chunks so memory remains bounded while the resulting SHA-256 stays identical to the existing whole-file hash contract, then prove a real installed-plugin indexing run with an oversized fixture.
