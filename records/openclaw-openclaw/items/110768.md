## Summary

Keep this PR open: it still replaces the current full-file SHA-256 contract with a digest of only the first 50 MiB for oversized metadata files, so distinct files can share an installed-plugin index hash. The previously raised blocker remains at the same head; the PR body also has test output only, not after-fix runtime proof.

## What This Changes

The PR changes `safeHashFile` to use a bounded 64 KiB synchronous read loop for files above 50 MiB and adds a sparse-file regression test.

## Best Possible Solution

Keep bounded memory but read and hash through EOF, then add a regression test that changes bytes after 50 MiB and proves both hashes differ; supply a redacted real index-refresh transcript for an oversized valid metadata file.
