## Summary

Keep this PR open: its QMD fallback is useful, but it still memoizes a hint-derived location under a document-ID cache key, so a stale lookup can remain pinned after the local index catches up. The newer shared-global-session behavior also lacks current-head real behavior proof.

## What This Changes

This PR preserves QMD file-URI search hits when local document-ID lookup misses and allows shared global-session transcript hits through session-memory visibility filtering.

## System Context

Memory Core turns QMD command-line search hits into OpenClaw memory results by resolving document identifiers or file hints against managed collections. It then filters session-memory results according to the active session scope before returning them to CLI and agent memory-search callers.

## Architecture Diagram

  F --> E

## Best Possible Solution

Keep file-hint fallback as a one-search recovery path, cache only locations confirmed by the local document index, and add redacted current-head terminal or runtime-log proof for both the stale-docid and shared-global-session cases.
