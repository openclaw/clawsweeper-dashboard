## Summary

The QMD resolver change is a focused repair for a source-reproducible empty-results path, and the branch fixes the earlier cache-invariant review concern. The current head still lacks after-fix evidence from a real QMD setup for its added shared-global-session visibility behavior, so this PR should remain open pending that proof rather than be closed or merged.

## What This Changes

This PR falls back to QMD-provided file URIs when local document-ID lookup misses, avoids caching that fallback as authoritative, and allows the shared `global` session key during global session scope.

## System Context

Memory Core invokes QMD to search indexed workspace and session documents, then resolves each QMD hit into an OpenClaw-readable memory path. Session-result filtering subsequently applies the configured session visibility policy before results reach `memory_search` and the CLI.
