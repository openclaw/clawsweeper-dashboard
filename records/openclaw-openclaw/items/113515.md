## What This Changes

This PR lets QMD-backed memory search use a returned `qmd://` file hint when the local document-ID index has no usable matching location, and adds a regression test for that case.

## System Context

The Memory Core plugin serves `memory_search` and the memory CLI. Its QMD backend invokes QMD, resolves returned document identifiers or file hints into OpenClaw-relative paths, then returns those locations as searchable memory hits.
