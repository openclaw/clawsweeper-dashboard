## Summary

This PR still addresses an open QMD memory-search regression, and the latest branch fixes the earlier hint-cache concern by caching only database-backed locations. It should remain open, but needs current-head real behavior proof for the independently changed shared-global-session visibility path before merge.

## What This Changes

The PR makes QMD-backed memory search fall back to a returned `qmd://` file hint when local document-ID lookup misses, and permits the shared `global` session key during global session scope.

## System Context

The bundled Memory Core plugin turns QMD command results into OpenClaw memory-search hits by resolving document identifiers and file hints to workspace paths. A separate session-visibility filter removes transcript-backed hits that the active agent is not allowed to see before results reach memory search.
