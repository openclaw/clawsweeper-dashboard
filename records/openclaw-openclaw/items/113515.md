## What This Changes

The PR preserves QMD file URI hints when a local document-ID lookup misses and allows a shared global session transcript to remain visible to non-default agents.

## System Context

Memory Core converts QMD search results into OpenClaw memory-search hits by resolving each QMD document ID or file hint to a managed location. The resulting locations are cached for later searches and then filtered by session-visibility rules before they reach the CLI or agent tool.

## Architecture Diagram

flowchart LR
  A[QMD search result] --> B[Document ID and file hints]
  B --> C[Local document index lookup]
  C --> D[Hint-based location fallback]
  D --> E[Location cache]
  E --> F[Session visibility filter]
  F --> G[Memory search results]

## Best Possible Solution

Preserve the QMD file-hint fallback for an unresolved lookup, but cache only authoritative document-index resolutions or give fallback entries an invalidation strategy that forces a later authoritative retry.
