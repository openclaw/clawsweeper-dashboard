## What This Changes

The branch makes QMD search-result resolution fall back to QMD file hints when local document-ID lookup misses, while caching only index-backed locations and adding focused regressions.

## System Context

Memory Core invokes QMD for search results, then resolves each result’s document ID or QMD file hint against OpenClaw’s local index before returning portable memory-search hits. This resolver affects both CLI and runtime memory-search output, including results sourced from indexed session transcripts.
