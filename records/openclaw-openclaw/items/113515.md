## What This Changes

This PR preserves a QMD search hit’s normalized `qmd://` file hint when the local OpenClaw document-ID lookup cannot map the hit to a managed file.

## System Context

The memory-core plugin runs QMD searches and converts QMD hit metadata into OpenClaw memory-search results. The resolver first tries the local QMD document index, then maps accepted collection and file hints to a workspace-relative path returned to the CLI or agent tool.
