## Summary

The patch is a narrow, source-consistent repair for the linked QMD empty-result report: current main drops a hit when docid lookup yields no usable location, while the new fallback preserves an already-normalized, collection-bounded `qmd://` hint. No code defect was found in the proposed change, but this external PR still needs redacted after-fix evidence from a real OpenClaw/QMD setup before merge.

## What This Changes

The PR lets QMD memory search use a returned `qmd://` file URI when the local OpenClaw document-ID index cannot resolve the hit to a managed collection path.

## System Context

Memory Core is OpenClaw’s bundled local-memory plugin. QMD returns ranked document hits to the memory manager; the document resolver turns their document IDs and file hints into safe OpenClaw search/read paths, which are then surfaced by `memory_search` and `openclaw memory search`.
