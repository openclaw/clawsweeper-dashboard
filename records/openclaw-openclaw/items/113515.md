## What This Changes

The branch lets QMD-backed memory search return a file-hinted hit when the local document-ID index has no usable match, while caching only locations confirmed by the index.

## System Context

The memory-core plugin runs QMD searches and translates QMD result metadata into OpenClaw memory-search hits. A QMD hit can carry both a document ID and a qmd:// file/collection hint; the resolver checks the local QMD index first, then returns a portable path to the memory-search caller.
