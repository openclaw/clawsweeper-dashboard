The PR updates plugin manifest trust calculation and regression tests so source-linked official ClawHub installs for npmSpec-only catalog entries can set `trustedOfficialInstall` while non-official or mismatched installs remain untrusted.

## Best Possible Solution

Land the narrow official ClawHub npmSpec trust rule after maintainer security approval, preserving rejection of non-official or mismatched installs and leaving self-hosted/community keyed-store access to separate issues.
