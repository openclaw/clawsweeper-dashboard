## What This Changes

Fix Telegram forum-topic routing so each inbound message maps to one topic-scoped conversation and produces one reply.

## System Context

Telegram forum-topic messages flow through conversation identity resolution before OpenClaw persists and binds a conversation to an agent session. That identity then feeds reply-run and turn-capture paths, so inconsistent topic addressing can create two rows for one incoming topic message and send duplicate replies.
