- `P2`: This is a normal-priority group-chat correctness gap with meaningful multi-agent routing impact but no emergency data-loss, security bypass, or crash-loop evidence.

## Summary

Keep open: current main and the latest release still carry flat Telegram group history/reply context without current-agent versus other-bot attribution, and the implementation PRs that attempted the direct fix are closed unmerged while the remaining open related PR is only a prompt/docs mitigation.

## What This Changes

The issue asks OpenClaw to make multi-agent group-chat context target-aware so an agent can distinguish messages addressed to itself, another bot, or ambient room context.

## Best Possible Solution

Keep this issue open until maintainers approve the target-state contract and a refreshed core plus Telegram implementation lands with focused prompt/history tests and redacted two-bot Telegram proof.
