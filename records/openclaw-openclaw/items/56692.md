## Summary

Keep open: current main and v2026.6.11 still lack per-message current-agent, other-agent, or ambient target attribution in Telegram group history and reply context. Current-turn mention facts and prompt guidance are useful partial mitigations, while the broader implementation PRs are closed unmerged and the remaining open PR is prompt-only.

## What This Changes

The issue asks OpenClaw to make group-chat history and reply context identify whether messages are addressed to the current agent, another agent, or ambient conversation.

## Best Possible Solution

Land a maintainer-approved target-aware history and reply metadata contract for Telegram group turns, with focused regression tests and redacted two-bot Telegram proof.

Yes, at source level: current main records and renders flat Telegram group history without per-message target-state fields. No live two-bot Telegram run was performed in this read-only review.

## Solution Assessment

Yes for the target-aware metadata direction, but the exact contract still needs maintainer approval. Prompt-only guidance is an acceptable interim mitigation, not the durable fix.
