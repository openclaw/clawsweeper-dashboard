## Summary

Keep open: current main and the latest release still do not mark Telegram group-history entries as addressed to the current agent, another bot, or ambient context; related work only adds current-turn bot facts or prompt-level mitigation.

## What This Changes

The issue requests clearer per-message target relationship metadata in multi-agent Telegram group-chat history and reply context so the active agent can distinguish its messages from other bots' or ambient chatter.

## Best Possible Solution

Land a maintainer-approved target-aware history/reply metadata path with focused core and Telegram tests plus redacted two-bot Telegram proof, while keeping prompt-only mitigation separate from the durable metadata contract.

## Reproduction Assessment

Yes, at source level but not as a live Telegram run. Current main records and renders flat group history without a field that says whether each prior message was addressed to this bot, another bot, or ambient context.

## Solution Assessment

Unclear as a final product solution. Per-message target metadata is the right layer, but the sibling-bot identity source and target-state semantics still need maintainer direction and live Telegram proof.
