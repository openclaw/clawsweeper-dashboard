## Summary

Keep open: current main still stores and renders Telegram group history without per-message target attribution, and the implementation attempts found in related PRs are closed unmerged or only partial prompt mitigations.

## What This Changes

The issue requests clearer target attribution and context separation for Telegram group chats with multiple agents so each agent can tell whether prior messages were addressed to it, another agent, or ambient group context.

## Best Possible Solution

Keep the issue open until target-aware history/reply metadata lands with maintainer-approved semantics, focused tests, and redacted two-bot Telegram proof.
