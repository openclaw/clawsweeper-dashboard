## Summary

Keep open: current main and the latest release still expose Telegram group history as flat sender/body/timestamp context, while the closed metadata PR did not merge and the remaining open PR is only a prompt-level mitigation.

## What This Changes

The issue requests clearer multi-agent group-chat targeting context so an agent can distinguish messages addressed to itself, another agent, or ambient group history.

## Best Possible Solution

Land an additive target-aware history and reply-context contract, populate it in Telegram from native mentions/reply targets, cover unknown and ambient cases in tests, and prove the result with redacted two-bot Telegram behavior evidence.
