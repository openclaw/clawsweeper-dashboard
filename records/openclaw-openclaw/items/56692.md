## Summary

Keep open: current main and the latest release still expose Telegram/group history as sender/body/timestamp/messageId/media without durable current-agent versus other-agent target attribution, and the related implementation PRs are closed unmerged or only prompt-level partial mitigations.

## What This Changes

The issue requests stronger per-message target attribution and context separation for multi-agent group chats so the active agent can distinguish messages addressed to itself, another agent, or ambient room context.

## Best Possible Solution

Adopt a maintainer-approved target-aware context contract, populate it first in Telegram, cover history and reply-chain metadata with focused tests, and require redacted live multi-agent group proof before treating the issue as fixed.
