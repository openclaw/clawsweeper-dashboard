## Summary

Keep open: current main and v2026.6.11 still expose Telegram/group history as flat sender/body context without per-message current-agent, other-bot, or ambient target attribution; the implementation attempts are closed unmerged and the remaining open PR is only a prompt-level mitigation.

## What This Changes

The issue requests clearer per-message target attribution and context separation for multi-agent Telegram group chats so an agent can distinguish messages addressed to itself, other agents, or ambient group context.
