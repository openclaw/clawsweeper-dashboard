## Summary

Keep open: current main and the latest release still carry Telegram group history as flat messages without per-message current-agent versus other-bot target attribution, and the related open PR is only a prompt-level mitigation rather than the durable metadata fix.

The issue requests clearer per-message target attribution and context separation for Telegram group chats with multiple agents.

## Best Possible Solution

Keep this issue open until a maintainer-approved target-aware history/reply metadata path lands with focused tests and redacted two-bot Telegram proof.

Unclear as a final product solution. Per-message metadata is the right layer, but the permanent sibling-bot identity source and unknown/ambient semantics still need maintainer direction and live Telegram proof.
