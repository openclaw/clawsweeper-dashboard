## Summary

Keep open: current main and v2026.6.11 still carry Telegram group history as flat sender/body/timestamp/messageId context without per-message current-agent, other-agent, or ambient target attribution. Current main has prompt guidance and current-message mention metadata, but the durable history/reply-chain bot-target signal requested here is still missing; the open prompt PR is only a partial mitigation and the broader bot-targeting PR was closed unmerged.

## What This Changes

Requests target-aware group-chat context so a Telegram agent can distinguish current-agent, other-agent, and ambient messages in recent history and reply context.

## Best Possible Solution

Land a maintainer-approved target-aware history/reply metadata design through the core prompt contract and Telegram plugin, with focused tests and redacted two-bot Telegram proof; keep prompt-only mitigation separate from this canonical metadata issue.

## Reproduction Assessment

Yes at source level, but not as a live Telegram run. Current main stores and renders flat group history without a field that says whether each prior message was addressed to this bot, another bot, or ambient.

## Solution Assessment

Unclear as a final product solution. Per-message target metadata is the right layer, but the sibling-bot identity source, unknown/ambient semantics, and reply-chain handling need maintainer direction and live Telegram proof.
