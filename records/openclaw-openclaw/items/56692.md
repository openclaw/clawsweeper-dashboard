## Summary

Keep open: current main and v2026.6.11 still do not carry per-message current-agent, other-agent, or ambient target attribution through Telegram group history or reply context; the current prompt guidance is only a partial mitigation, and the related implementation PRs are closed/unmerged while the remaining open PR is prompt-only and conflicting.

## What This Changes

The issue requests clearer per-message target attribution and context separation for Telegram multi-agent group chats so agents can distinguish messages addressed to them from messages addressed to other agents.

## Best Possible Solution

Keep this issue open until target-aware history and reply metadata land with approved current-agent, other-agent, and ambient semantics, focused regression tests, and redacted two-bot Telegram proof.
