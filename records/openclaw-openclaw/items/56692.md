## Summary

Keep open: current main now carries current-turn Telegram mention classification, but group history and reply-context rendering still lack per-message current-agent versus other-bot target attribution, and the durable design still needs maintainer direction plus live Telegram proof.

## What This Changes

The issue requests clearer per-message target attribution in multi-agent group chat history so the current agent can distinguish messages meant for itself, another bot, or ambient context.

## Best Possible Solution

Keep this issue as the canonical target-attribution work until a maintainer-approved core/Telegram design lands per-message history and reply-chain target facts with focused tests and redacted two-bot Telegram proof.
