## Summary

Keep open: the cron phase change is plausible, but the `zhipu` exception is ordered before stronger z.ai endpoint and model-prefix detectors, so it can re-enable the session-state guard bug for z.ai-style routes; the external PR also has only test-output proof.

## What This Changes

This PR exempts `zhipu` GLM models from the silent-overflow compaction guard and moves several isolated cron setup phases into the watchdog execution bucket.

## Best Possible Solution

Keep z.ai endpoint and model-prefix detection authoritative, exempt only verified non-z.ai Zhipu bare-GLM routes, and let maintainers choose whether this PR or #93914 owns the cron watchdog contract.

## Reproduction Assessment

## Solution Assessment

No as written: the zhipu fix should preserve stronger z.ai route signals and only narrow the bare-GLM Zhipu case. The cron change is a plausible subset, but it overlaps the broader #93912/#93914 watchdog fix path.
