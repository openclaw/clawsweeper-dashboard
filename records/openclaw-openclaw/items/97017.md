## Summary

Keep open. The PR is focused and useful in intent, but the current patch needs changes because it bypasses existing z.ai endpoint/model-prefix detection for any provider named `zhipu` and it weakens the isolated-cron pre-model watchdog boundary that previously fixed phase-specific startup stalls.

## What This Changes

The PR adds a `zhipu` exception to silent-overflow-prone model detection and moves three isolated cron phase buckets from pre-execution to execution while updating focused tests.

## Best Possible Solution

Land a narrowed patch that preserves z.ai endpoint and model-prefix detection, only exempts a proven first-party zhipu bare-GLM route, and keeps model-resolution/auth/context-engine stalls covered by the pre-model watchdog unless new runtime proof justifies a different boundary.

Full review comments:

- **[P1] Preserve z.ai endpoint detection before exempting zhipu:** `src/agents/agent-settings.ts:146-147`
  - body: The new `zhipu` check returns `false` before the existing `baseUrl` and `z-ai/` model-prefix detectors run. Since `models.providers` supports arbitrary custom provider IDs, a user can have a valid provider named `zhipu` that points at `api.z.ai` or advertises `z-ai/glm-*`; this patch would leave embedded auto-compaction enabled again for that z.ai-style route and can reintroduce the transcript-loss regression fixed by https://github.com/openclaw/openclaw/pull/76056. Keep the explicit z.ai endpoint/prefix checks ahead of any bare-GLM zhipu exemption and add coverage for those cases.
  - confidence: 0.88
- **[P1] Keep pre-model phases under the watchdog:** `src/cron/service/agent-watchdog.ts:36-38`
  - body: Changing `model_resolution`, `auth`, and `context_engine` to `execution` clears the pre-execution watchdog as soon as bootstrap reaches those phases. That removes the phase-specific pre-model timeout added by https://github.com/openclaw/openclaw/pull/80130 for stalls before the first model call; the updated regression now only proves `runtime_plugins` still times out and no longer protects the `context_engine` stall that closed https://github.com/openclaw/openclaw/issues/74803. Leave these phases under the pre-model watchdog or add a narrower transition that still preserves that stall timeout.
  - confidence: 0.9
