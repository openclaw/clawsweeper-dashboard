## Summary

Keep open: the PR addresses the right ACP/Gateway bug, but the current patch still sends Gateway replacement snapshots as ACP chunks; ACP v1 chunks append, so clients can render stale text plus the replacement instead of the authoritative revised answer.

## What This Changes

The branch passes Gateway `replace` deltas into ACP translation and adds regression tests for divergent and shorter replacement snapshots.

## Best Possible Solution

Implement replacement with an ACP-compatible replacement mechanism, such as ACP v2 `agent_message` / `agent_thought` upserts keyed by `messageId` or a maintainer-approved v1 fallback, then verify aggregate rendered text and thought output.
