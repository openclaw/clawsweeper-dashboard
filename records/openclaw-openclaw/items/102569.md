## Summary

Keep open: the patch addresses the byte-offset slice mechanically, but it still emits a full replacement as a normal append-only ACP chunk, so standard ACP clients can render stale text plus the revised text instead of the Gateway-authoritative replacement.

## What This Changes

## Best Possible Solution
