## Summary

Keep open: current main and the latest release still route the named provider-supplied video download URLs through unguarded fetch helpers, and the related open PRs only cover adjacent or partial slices of the five-provider issue.

## What This Changes

The issue reports that byteplus, minimax, xai, runway, and vydra video-generation providers fetch provider-returned result URLs without reapplying the SSRF/private-network guard.

## Best Possible Solution

Land a security-reviewed provider hardening change that carries the resolved request policy through each affected poll, metadata, and result-download leg, uses existing guarded fetch helpers by default, and adds SSRF regression coverage for the named provider download shapes.
