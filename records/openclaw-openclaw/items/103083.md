## Summary

Keep open: current main and the latest release still expose the reported provider-supplied video download paths through unguarded fetch helpers, and the related open PRs only cover adjacent or partial slices of the five-provider issue.

## What This Changes

The issue reports that BytePlus, MiniMax, xAI, Runway, and Vydra video-generation result downloads use unguarded fetch paths for provider-supplied result URLs.

## Best Possible Solution

Land a security-reviewed provider hardening change that carries the resolved request policy through each affected submit, poll, metadata, and result-download leg, uses the existing guarded fetch helpers by default, and adds SSRF regression coverage for the named provider download shapes.
