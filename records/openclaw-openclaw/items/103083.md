## Summary

Keep open: current main and the latest release still route the affected provider result downloads through unguarded fetch paths, and the related open PRs do not cover the full five-provider issue.

## What This Changes

The issue reports that BytePlus, MiniMax, xAI, Runway, and Vydra video generation download provider-supplied result URLs without reapplying OpenClaw's SSRF guard.

## Best Possible Solution

Carry the resolved provider request policy through each affected provider's poll, metadata, and result-download legs, use the existing guarded fetch helpers for provider-supplied URLs, and add focused default-deny SSRF regression coverage for each affected download shape.
