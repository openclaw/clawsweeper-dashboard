Keep open: current main and v2026.6.11 still lack a selective shared-session contract for chosen group/channel/thread chats, and the related groupScope PR is narrower, open, and not a safe replacement for this broader tracker.

## What This Changes

The issue requests opt-in shared sessions across selected group, channel, and thread chats while preserving isolation for unlisted chats.

## Best Possible Solution

Use this issue as the broad product/security tracker for one opt-in shared-session routing contract covering selected channels and threads, isolated defaults, grouped queue serialization, origin-preserving replies, docs, diagnostics, and regression coverage.
