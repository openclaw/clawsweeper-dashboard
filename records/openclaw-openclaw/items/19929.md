## Summary

Keep open: current main and v2026.6.11 still lack a selective shared-session contract for chosen group/channel/thread chats, and the related open groupScope work is narrower than this tracker.

## What This Changes

The issue requests an opt-in way to map selected group/channel/thread chats for the same agent into a shared session key while preserving isolated defaults and origin-channel reply routing.

## Best Possible Solution

Keep this as the broad product/security tracker for one additive shared-session routing contract with isolated defaults, explicit channel/thread membership, optional thread inheritance, grouped queue serialization, origin-preserving replies, diagnostics, docs, and regression coverage.
