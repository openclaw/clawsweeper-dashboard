## Summary

Keep open: current main and v2026.6.11 still lack a selective shared-session contract for chosen group/channel/thread chats, and the related open groupScope PR only covers a narrower group-to-main path that is not merged or proof-ready.

## What This Changes

This issue requests an opt-in config surface that maps selected Discord/Slack channels or threads to one shared session key while preserving isolated defaults and origin-specific replies.

## Best Possible Solution

Keep this as the broad canonical tracker for one explicit, opt-in shared-session routing contract with isolated defaults, selected channel/thread membership, origin-preserving replies, grouped queue serialization, docs, diagnostics, and security guidance.
