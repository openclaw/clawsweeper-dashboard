## Summary

Keep this PR open for a maintainer decision and contributor proof. It correctly targets the Anthropic CLI launch-normalization path, but it unconditionally adds a Claude Code flag that the PR itself says requires version 2.1.169 or newer, without establishing a repository-wide minimum or compatibility behavior for existing installations; it also still lacks after-fix real launch evidence.

## What This Changes

The PR adds `--safe-mode` to Anthropic Claude CLI fresh and resumed launch arguments and re-inserts it after user backend-argument overrides are normalized.

## System Context

The Anthropic extension converts OpenClaw agent configuration into command-line arguments for the locally installed Claude Code CLI. Its backend normalizer applies mandatory launch policy before fresh or resumed agent sessions start a Claude subprocess.

## Best Possible Solution

Choose and document the Claude CLI compatibility contract, then implement one canonical path: enforce a supported minimum with a clear upgrade diagnostic, or retain existing launches on older CLIs while enabling safe mode only where supported; add focused coverage and redacted live fresh/resume launch proof.
