## What This Changes

This PR changes Code Mode’s suspended tool-call handling so concurrent and detached calls resume in settlement order and are drained safely before execution finishes.

## System Context

Code Mode executes guest JavaScript in a worker and bridges guest tool requests into OpenClaw’s agent-tool runtime. Its execution coordinator persists snapshots and pending requests, resumes the worker with completed tool results, and returns a terminal result to the agent.

## Architecture Diagram

flowchart LR

  B --> C[Execution coordinator]
  C --> D[Agent tool bridge]
  D --> E[Settled tool responses]
  E --> C
  C --> F[Resumed worker result]
  F --> G[Agent response]

## Best Possible Solution

Retain one canonical worker-to-host completion contract: resume with responses in actual completion order, drain only requests that the worker explicitly requires, and prove race, abort, snapshot-resume, and clean-worker-exit behavior with redacted real-worker output before merge.
