## What This Changes

The branch adds an opt-in `includeFamily` flag to Gateway `chat.history` and the `sessions_history` tool so callers can read a bounded reset-family history tail alongside the active session transcript.

## System Context

Gateway `chat.history` reads persisted session transcripts for the Control UI and remote clients, while `sessions_history` exposes sanitized history to agents. This change follows a session store's reset-family identifiers to select archived and active transcript segments before returning a bounded message history.
