## What This Changes

This PR updates provider local-service defaults and `models list` status output so canonical IPv4 addresses throughout `127.0.0.0/8` are recognized as local loopback hosts.

## System Context

Model configuration uses a provider URL classifier to decide whether a local service receives local defaults, and the models command uses a separate classifier to display local endpoint status. Both accept a configured base URL, classify its hostname, and feed that result into operator-visible model behavior.
