- `impact:session-state`: The failure can make semantic memory recall unavailable or degraded for agent sessions while the Gateway process otherwise remains alive.

## Summary

This issue is still necessary: current main still forks the local embedding worker without an explicit executable, and the issue is now the canonical tracker for several open candidate fixes rather than something safe to close before merge.

## What This Changes

The issue reports that Homebrew Node upgrades can delete the Gateway process's resolved Cellar `process.execPath`, causing new local embedding worker forks to fail with `ENOENT` and degrade semantic memory.

## Best Possible Solution

Land one narrow worker-executable fix that reuses stable Homebrew Node resolution or a bounded ENOENT retry, then close this issue and dedupe the competing PRs.

## Reproduction Assessment

Yes at source level, though not with a live macOS Homebrew upgrade run here. Current main omits `execPath` in the local worker `fork()`, and Node's fork implementation defaults that executable to `process.execPath`.

## Solution Assessment

Yes, stabilizing the worker fork executable or retrying once after stale-execPath `ENOENT` is the narrow maintainable fix. A health-check-only warning would still leave new worker forks broken until restart.
