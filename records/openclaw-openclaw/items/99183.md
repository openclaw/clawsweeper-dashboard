## Summary

Keep open: current main and the latest release still fork the local embedding worker without an explicit executable, and two open closing PRs are candidate fixes rather than merged resolution.

## What This Changes

Fix local embedding worker forks so a running macOS/Homebrew Gateway survives a Node upgrade instead of spawning a deleted Cellar Node path and degrading memory recall.

## Best Possible Solution

Land one corrected closing PR that gives the local embedding worker fork a stable Node executable or a reliable ENOENT retry with focused regression coverage, then close this issue.

## Reproduction Assessment

Yes, at source level. Current main omits execPath in the worker fork, and Node's fork contract defaults to the parent's process.execPath, matching the deleted Homebrew Cellar path failure.

## Solution Assessment

Yes, the narrow maintainable solution is to fix worker executable selection or retry at the worker launch boundary. A health-check-only warning would still leave fresh worker forks broken.
