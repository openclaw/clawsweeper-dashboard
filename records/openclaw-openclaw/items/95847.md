## Summary

Keep this PR open: its explicit descendant matching is useful, but one blocking lifecycle gap can still mark an unconsumed fallback-steered completion as delivered, and the external PR also lacks required real behavior proof.

## What This Changes

The PR adds durable delivery credit when requester-owned cron or nested-subagent flows consume explicit descendant completion output.

## Best Possible Solution

Model completion handoff with a closed lifecycle outcome where only `adopted` permits requester-consumption credit, `committed_pending` remains reconciliation-owned without replay, and definitively `terminal_unconsumed` may fall back once; for this PR, omit credit for fallback-steered delivery until that contract exists.
