## Summary

Keep this PR open, but do not merge the current head: the previously reported P1 remains unchanged, because a replacement requester run is treated as consumption before it actually processes the descendant findings. The external PR also still lacks exact-head real behavior and restart proof.

## What This Changes

The PR adds durable delivery credit for descendant subagent completions included in requester-owned nested announcements and cron fallback output.

## Best Possible Solution

Record nested delivery credit only after the replacement requester run acknowledges or processes the exact descendant findings; if no reliable acknowledgement exists, keep the cron-owned fallback credit and omit nested wake credit.
