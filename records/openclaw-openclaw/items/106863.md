## What This Changes

Remove Android’s 30-second server-run override and keep waiting when the 120-second client check confirms the chat run is still active.

## Best Possible Solution

Land the narrow Android-owned fix after adding focused coverage for omitted timeoutMs and in-flight timer re-arming, then prove a real Android chat turn exceeding two minutes completes without an abort, false banner, removed optimistic bubble, or failed outbox row.
