## What This Changes

Request adds a `/models test-fallback` command that deliberately skips the primary model and probes configured fallback candidates.

## Best Possible Solution

Define one canonical fallback-chain probe that reuses the real fallback/auth resolution path, starts at configured fallback candidates, reports which model answered, supports first-fallback and all-fallback modes, and documents how it differs from broad configured-model health checks.

## Solution Assessment
