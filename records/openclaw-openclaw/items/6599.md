## What This Changes

Request to add a `/models test-fallback` command that skips the primary model and probes configured fallback candidates, optionally across the whole chain.

## Best Possible Solution

Pick one maintainer-approved UX, then implement a read-only fallback-chain probe that reuses the real model/auth resolution path, reports the responding model, supports first/all modes, and documents how it differs from auth-profile probes.
