## Summary

Keep open: current main and the latest release still lack a targeted `/models test-fallback` command, and the adjacent health-check and staged-migration issues do not fully replace this fallback-chain probe.

## What This Changes

Request a `/models test-fallback` command that intentionally skips the primary model and probes one or all configured fallback models before a real failure occurs.

## Best Possible Solution

Define one canonical fallback-chain diagnostic that reuses the real model/auth fallback resolution path, starts at configured fallback candidates, reports which model answered, supports first-fallback and all-fallback modes, and documents how it differs from broad configured-model health checks.
