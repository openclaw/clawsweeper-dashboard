## Summary

Keep open: current main and the latest stable release still lack a targeted fallback-chain test command, and the remaining blocker is product scoping rather than conservative cleanup.

## What This Changes

The issue requests a `/models test-fallback` command that intentionally skips the primary model and probes configured fallback models before an outage.

## Best Possible Solution

Define one canonical fallback validation surface that reuses real model/auth fallback resolution, can intentionally start at configured fallback candidates, reports the model that answered, and documents how it differs from auth probes and broad configured-model health checks.
