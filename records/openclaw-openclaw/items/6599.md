A maintainer-sponsored design should choose whether to add a dedicated fallback-chain probe or fold it into the models probe/migration workflow, then reuse the real fallback/auth resolution path and document the distinction from auth-profile probes.

- **Sponsor a narrow fallback-chain probe (recommended):** Add a first-class command that starts at configured fallback candidates, supports first/all modes, and reports the responding model while reusing runtime fallback/auth resolution.
