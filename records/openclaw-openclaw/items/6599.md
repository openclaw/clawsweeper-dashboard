## What This Changes

## Best Possible Solution

Define one canonical fallback-chain probe that reuses the real model/auth fallback resolution path, starts at configured fallback candidates, reports which model answered, supports first-fallback and all-fallback modes, and documents how it differs from broad model-health probes.

## Reproduction Assessment

## Solution Assessment
