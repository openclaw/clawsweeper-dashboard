## What This Changes

The issue requests a `/models test-fallback` command that intentionally skips the primary model and probes configured fallback candidates.

## Best Possible Solution

Ship one canonical fallback validation surface that can intentionally start at configured fallback candidates, report the responding model, support first-fallback and all-fallback modes, and document how it differs from auth-profile probes and broad per-model health checks.
