## What This Changes

The issue requests a `/models test-fallback` command that intentionally skips the primary model and probes configured fallback models on demand.

## Best Possible Solution

Ship one canonical fallback validation surface that reuses real fallback/auth resolution, can intentionally begin at configured fallback candidates, reports which model answered, and documents how it differs from auth probes and broad per-model health checks.
