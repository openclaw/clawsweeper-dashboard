## What This Changes

The PR changes plugin wizard numeric parsing to accept only finite JSON-number spellings and reject fractional values for integer schema fields, with expanded regression coverage.

## Best Possible Solution

Adopt JSON-number grammar and integer enforcement for plugin wizard writes while preserving valid decimal and scientific notation; explicit prompt feedback for rejected input would be a useful follow-up UX improvement.
