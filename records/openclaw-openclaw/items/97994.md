## Summary

Keep open: current main and v2026.6.11 still require a finish-reason-derived terminal signal before no-finish streamed tool calls can become executable, and the linked fix is an open PR rather than merged. The report remains actionable, but the safe completion contract needs maintainer review because it changes when provider output may trigger tools.

## What This Changes

The issue requests preserving parsed OpenAI-compatible streaming `delta.tool_calls` and executing them when a provider cleanly ends the stream without a final `finish_reason`.

## Best Possible Solution

Review and land the paired PR or an equivalent transport-level fix that promotes only native parsed tool calls from cleanly terminated OpenAI-compatible SSE streams while keeping truncated EOF and ambiguous visible-text cases fail-closed.
