## Summary

Keep open: current main and v2026.6.11 still drop the reported no-finish streamed tool-call path, and the open linked fix PR now owns the implementation decision rather than this issue being ready to close.

## What This Changes

The issue asks OpenClaw to preserve and execute valid OpenAI-compatible streamed `delta.tool_calls` when a custom provider ends with `[DONE]` but omits a final `finish_reason`.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/98124; an accepted fix should preserve complete native tool-call chunks only after a clean stream terminal while keeping truncated and visible-text-spurious cases fail-closed.
