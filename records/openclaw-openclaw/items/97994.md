## What This Changes

The issue reports that OpenAI-compatible streamed native `delta.tool_calls` are parsed but not executed when the provider ends with `[DONE]` without a final `finish_reason`.

## Best Possible Solution

Review the linked transport fix and land a clean-terminal contract that preserves native no-finish tool calls only when the SSE stream ends cleanly, while keeping EOF-without-`[DONE]` and visible-text ambiguous cases fail-closed.
