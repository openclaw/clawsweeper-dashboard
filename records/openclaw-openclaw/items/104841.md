## Summary

Current main still allows Amazon Bedrock discovery calls to wait without a local deadline. The patch is correct and well-proven, but the fixed 30-second availability policy needs an Amazon Bedrock owner to accept or retune it before merge.

## What This Changes

Adds a 30-second abort deadline around Amazon Bedrock foundation-model and paginated inference-profile discovery calls, with regression coverage for stalled requests.

## Best Possible Solution

Land the bounded dispatch helper after a Bedrock owner confirms the 30-second budget or selects a better fixed value, while retaining the existing best-effort fallback and abort regression coverage.
