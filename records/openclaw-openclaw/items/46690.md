## Summary

Keep open: current main still discovers skills only from configured roots and workspace-only audits, so arbitrary off-root SKILL.md orphan detection remains missing and needs a maintainer product decision on scan scope and warning location.

## What This Changes

Request a guard or diagnostic that warns when valid skill directories are created outside OpenClaw's canonical or configured skill roots.

## Best Possible Solution

Add a bounded explicit openclaw skills check or Doctor orphan diagnostic that excludes all configured and trusted roots and gives move, install, or configure remediation; avoid startup or home-wide scans unless maintainers intentionally accept that tradeoff.
