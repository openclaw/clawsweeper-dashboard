## Summary

Keep this open: current main still limits skill discovery, list/check output, and workspace audit to configured skill roots, so standalone off-root SKILL.md directories remain invisible unless the user configures that root.

## What This Changes

The issue asks OpenClaw to warn or diagnose skill directories with SKILL.md files created outside canonical skill roots.

## Best Possible Solution

Add a bounded, explicit orphan-skill diagnostic to doctor or openclaw skills check after maintainers define the safe scan scope and remediation copy.
