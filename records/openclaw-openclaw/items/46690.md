## Summary

Keep open: current main and the latest release still load and report only configured skill roots, so off-root `SKILL.md` directories remain invisible unless the user moves them or configures `skills.load.extraDirs`. The remaining decision is product policy around scan scope, timing, privacy, and remediation copy.

## What This Changes

The issue requests guardrails or diagnostics for skill directories with `SKILL.md` that are created outside OpenClaw’s canonical skill roots and therefore are not loaded or cleaned up.

## Best Possible Solution

Add a bounded, explicit skills diagnostic that detects likely off-root `SKILL.md` directories, explains move/install/`skills.load.extraDirs` remediation, and avoids broad startup or home-wide scanning unless maintainers approve that policy.
