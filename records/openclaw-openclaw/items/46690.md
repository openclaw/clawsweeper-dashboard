## Summary

Keep open: current main still limits skill discovery, skills status, Doctor readiness, and workspace audit paths to configured skill roots; Skill Workshop now guards generated skill creation, but arbitrary off-root SKILL.md orphan detection remains missing and needs product direction.

## What This Changes

Request a guard or diagnostic that warns when valid SKILL.md directories are created outside canonical or configured skill roots and will not be loaded.

## Best Possible Solution

Add a bounded explicit orphan diagnostic to openclaw skills check or Doctor that excludes configured/trusted roots and gives move, install, or configure remediation; avoid startup or home-wide scans unless maintainers intentionally accept that tradeoff.
