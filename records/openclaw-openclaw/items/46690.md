## Summary

Keep open: current main still scopes skill discovery, `skills.status`, Doctor readiness, and workspace audit to configured skill roots; Skill Workshop now creates durable skills under the workspace path, but arbitrary off-root `SKILL.md` orphan detection is still missing and needs a maintainer product decision.

## What This Changes

Request to add guards or diagnostics for skill directories created outside canonical or configured OpenClaw skill roots.

## Best Possible Solution

Add a bounded explicit orphan diagnostic to `openclaw skills check` or Doctor that excludes configured/trusted roots and gives move, install, or configure remediation; avoid startup or home-wide scans unless maintainers intentionally accept that tradeoff.
