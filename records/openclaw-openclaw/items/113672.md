## What This Changes

This PR lets selected Control UI chat-bubble text fall through to the browser’s native context menu while retaining OpenClaw’s Reply, Rewind, and Fork menu when no text is selected.

## System Context

The Control UI chat thread receives browser context-menu events from rendered conversation bubbles. It decides whether to preserve the browser’s text-selection actions or replace them with OpenClaw’s message-action menu.
