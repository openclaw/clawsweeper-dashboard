## What This Changes

The PR lets selected Control UI chat-bubble text keep the browser’s native context menu and removes OpenClaw’s duplicate selection-copy menu action while retaining message actions for unselected bubbles.

## System Context

The Control UI chat thread receives browser right-click events from rendered message bubbles. It decides whether to leave a text selection to the browser or open OpenClaw’s message-action menu for reply, rewind, and fork operations.
