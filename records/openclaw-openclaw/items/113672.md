## What This Changes

This PR changes Control UI chat bubbles so right-clicking selected message text leaves the browser’s native context menu available, while right-clicking an unselected bubble retains OpenClaw’s custom message-action menu.

## System Context

The Control UI chat thread renders conversation bubbles and handles browser context-menu events to expose OpenClaw actions such as reply, rewind, and fork. The handler decides whether a right-click should remain a browser-native text-selection gesture or be converted into a bubble-action menu.
