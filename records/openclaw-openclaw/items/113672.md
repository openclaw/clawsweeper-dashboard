## What This Changes

The PR lets selected text in Control UI chat bubbles retain the browser’s native context menu while preserving OpenClaw’s Reply, Rewind, and Fork menu for right-clicks without a selection.

## System Context

The Control UI chat thread receives right-click events from rendered conversation bubbles and chooses between OpenClaw’s message-action menu and the browser’s own context menu. This decision controls whether people can use standard browser copy actions on selected chat text without losing unselected-bubble reply actions.
