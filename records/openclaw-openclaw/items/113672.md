## What This Changes

This PR lets selected text in Control UI chat bubbles retain the browser’s native context menu while preserving OpenClaw’s Reply, Rewind, and Fork menu for unselected bubbles.

## System Context

Control UI renders chat history as interactive message bubbles in the browser. A bubble-level right-click handler chooses between the browser’s native selection actions and OpenClaw’s message-action menu.
