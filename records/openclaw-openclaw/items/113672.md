## Summary

This PR targets a reproducible Control UI regression and proposes the narrow expected behavior: selected chat text should retain the browser’s native context menu. The patch has no definite correctness or security defect from the supplied diff, but it is a draft external PR and provides test-only evidence rather than an after-fix browser run, so it needs real behavior proof before merge.

## What This Changes

The PR changes Control UI chat bubbles so right-clicking selected message text leaves the browser’s Copy/Search context menu available while unselected bubbles retain OpenClaw’s reply actions.

## System Context

The Control UI chat thread renders conversation bubbles and intercepts unselected-bubble right clicks to offer OpenClaw actions such as Reply. This handler sits between browser pointer events and the contextual actions shown to a user, so it determines whether the browser or OpenClaw owns the right-click menu.
