## What This Changes

The PR changes Control UI chat bubbles so selected text keeps the browser’s native context menu while unselected bubbles retain OpenClaw’s Reply, Rewind, and Fork action menu.

## System Context

The Control UI renders conversation messages as chat bubbles and routes right-click events through a thread-level handler. That handler either hands the interaction to the browser’s native selection menu or creates OpenClaw’s message-action menu for reply and user-message actions.
