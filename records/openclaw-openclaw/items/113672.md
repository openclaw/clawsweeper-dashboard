## What This Changes

This PR changes Control UI chat bubbles so right-clicking selected message text leaves the browser’s native context menu available, while unselected bubbles retain OpenClaw’s custom message-action menu.

## System Context

The Control UI chat thread receives browser context-menu events from rendered conversation bubbles. It either opens OpenClaw’s message-action menu or, for selected text, must leave the browser event untouched so the browser can provide copy and selection actions.
