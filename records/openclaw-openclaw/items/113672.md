## Summary

This PR still addresses the reported Control UI regression and its patch is narrowly scoped, but it needs inspectable real-browser after-fix proof before merge; the current PR body provides mocked-browser tests and CI results rather than a user-observable native-menu result.

## What This Changes

The branch lets selected text in Control UI chat bubbles use the browser’s native context menu while preserving OpenClaw’s Reply, Rewind, and Fork menu for unselected bubbles.

## System Context

The Control UI chat thread receives right-click events from rendered conversation bubbles. It decides whether to leave the event to the browser for selected text or open OpenClaw’s message-action menu for an unselected message.
