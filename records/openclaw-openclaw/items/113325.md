## What This Changes

The PR makes Workboard ignore a card’s running state, execution, and claim for global owner-capacity accounting after the claim has passed the existing five-minute reclaim grace period, with regression coverage at the boundary.

## System Context

The bundled Workboard plugin persists cards, running executions, and claims, then its dispatcher selects ready cards to start while enforcing global per-owner capacity. A claim’s reclaimability is used by board-scoped cleanup and now also determines whether a stale card blocks another board’s ready work.
