## What This Changes

The PR makes Workboard ignore a running card with a claim past the existing five-minute reclaim grace when enforcing global owner capacity, and adds regression coverage for that cross-board case.

## System Context

Workboard dispatch reads all cards to enforce a global per-owner concurrency limit, then selects ready cards from the requested board. Claim expiry and execution state determine whether a card reserves capacity before the dispatcher invokes a subagent.
