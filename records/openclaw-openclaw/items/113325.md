## What This Changes

The PR makes Workboard exclude a claimed running card from global owner-capacity accounting once its claim is reclaimable, so ready same-owner work on another board can start without waiting for cleanup on the stale card’s board.

## System Context

Workboard dispatch loads all cards to enforce an owner-wide concurrency limit, then starts ready cards from the requested board. Claim expiry determines when a stale card can be reclaimed by board cleanup and, with this change, when it stops reserving global dispatch capacity.
