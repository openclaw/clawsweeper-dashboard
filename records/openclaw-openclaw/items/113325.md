## Summary

Keep this PR open for normal review. The patch is a focused repair that aligns dispatcher capacity accounting with the existing claim-reclaim grace rule and directly addresses the linked fleet-wide starvation report, but the PR body provides only test/tooling assertions rather than inspectable after-fix real-behavior evidence.

## What This Changes

The PR shares Workboard’s expired-claim reclaimability rule between store cleanup and dispatcher capacity accounting so a reclaimable claim on one board no longer blocks ready work for the same owner on another board.

## System Context

Workboard stores cards and their temporary owner claims, then its dispatcher calculates each owner’s active capacity before starting ready cards. This change feeds claim expiry plus the existing grace window into that capacity decision, affecting which queued cards can start a subagent run.
