## Summary

Keep open: the live loopback plumbing is useful, but this head still leaves prompt-time session reuse keyed from a different auth scope than the live MCP tools/list path, so claude-cli sessions can stay tied to the no-xAI tool surface. The credential-boundary choice also needs maintainer acceptance before merge.

## What This Changes

This PR threads authProfileStore and agentDir through gateway loopback tool resolution, loads agent-local auth profiles for live MCP loopback requests, and adds gateway/auth/xAI tests plus a proof script.

## Best Possible Solution

Use one explicit credential boundary for both prompt-time loopback tool hashing and live MCP tools/list resolution, with a regression covering a claude-cli session that has xAI OAuth but no explicit xAI authProfileId.

- **Hold for broader auth policy:** Pause this PR until the auth-profile inheritance policy for CLI backends is documented across native, prompt-time, and live loopback paths.
