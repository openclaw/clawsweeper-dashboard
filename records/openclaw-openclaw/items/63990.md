## Summary

Keep open. Current main protects the single memory index with provider/model identity checks, but it still lacks the requested per-model indexes, coordinated multi-index ingestion, active/fallback index routing, and index-level status/observability.

## What This Changes

The issue requests first-class multi-index memory embeddings so each embedding model has its own index and failover never mixes vector spaces.

## Best Possible Solution

Keep this as the canonical design tracker for memory-core multi-index failover, define the config/storage/migration/status contract first, preserve current single-index compatibility, and handle narrower fallback recovery bugs separately.
