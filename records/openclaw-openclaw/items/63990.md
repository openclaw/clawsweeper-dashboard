## Summary

Keep open. Current main and the latest stable release still prevent mixed vector search by pausing incompatible vector search, but they do not provide per-model indexes, dual ingestion, active/fallback index routing, or observable memory failover.

## What This Changes

Requests first-class multi-index memory search so each embedding model has its own index and query routing can fail over without mixing vector spaces.

## Best Possible Solution

Approve a bounded memory-core/plugin design for per-model indexes with doctor migration and status surfaces, then implement it behind backward-compatible config.
