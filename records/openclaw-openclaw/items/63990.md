## Summary

Keep open. Current main and the latest release still use one resolved memorySearch provider/model/fallback and one canonical memory index; they guard against mixed vector spaces, but do not implement per-model indexes, coordinated ingestion, active/fallback index routing, or safe failover without a rebuild.

## What This Changes

The issue requests first-class multi-index embedding memory so each embedding model has its own index, ingestion status, active/fallback routing, and observability without mixing vector spaces.

## Best Possible Solution

Keep this as the canonical maintainer design tracker for memory-core multi-index failover, define the config/storage/migration/status contract first, and let https://github.com/openclaw/openclaw/issues/96534 handle the narrower fallback recovery bug separately.
