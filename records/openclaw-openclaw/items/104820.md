## Summary

The patch is technically sound, proof-positive, and has no remaining actionable correctness finding; keep it open because a maintainer must explicitly accept the deliberate upgrade change that configured-but-unavailable SearXNG endpoints now stop searches instead of falling through to ambient configuration.

## What This Changes

The PR makes an explicit SearXNG `baseUrl` authoritative by failing before network access when it is unresolved, blank, null, or malformed, while retaining `SEARXNG_BASE_URL` fallback only when no value is configured, with regression tests and matching documentation.

## Best Possible Solution

Make an explicit SearXNG `baseUrl` authoritative: resolve and use it or return the actionable pre-network error, reserve ambient fallback for the genuinely unconfigured state, and retain the added runtime matrix and upgrade-facing documentation.
