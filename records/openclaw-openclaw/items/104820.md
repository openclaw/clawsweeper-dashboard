## Summary

This PR has credible real runtime proof and a bounded implementation, but it intentionally changes the compatibility contract for existing configured SearXNG deployments. The remaining blocker is an explicit owner decision on whether an unresolved configured value must fail closed rather than retain the current ambient fallback.

## What This Changes

The PR changes the SearXNG plugin so an explicitly configured but unavailable or invalid base URL reports an actionable error instead of falling back to ambient `SEARXNG_BASE_URL`.

## System Context

The SearXNG plugin resolves a configured search endpoint before `web_search` sends requests through its client. The resolved URL determines whether searches use the plugin’s explicit configuration, an ambient environment setting, or stop with a diagnostic before network access.
