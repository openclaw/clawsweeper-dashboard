- `P1`: A plausible agent-generated directive can cause a complete LINE agenda reply to fail in an active channel workflow.

## Summary

Current main still permits blank comma-separated entries to become empty LINE Flex text or action labels. The directly linked fix PR remains open, so this issue is still necessary until that PR or an equivalent fix lands.

## What This Changes

Drop blank entries from LINE agenda, buttons, and device directive lists so generated Flex payloads contain no empty text or action labels.

## Best Possible Solution

Normalize the three directive lists before mapping them into Flex events or actions, preserve nonblank values, and land focused regression coverage for trailing and doubled commas with redacted LINE validation proof.
