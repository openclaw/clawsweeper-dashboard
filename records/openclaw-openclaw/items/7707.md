## Summary

Keep open: current main and v2026.6.11 still lack durable memory trust metadata, trust-policy config, review/expiration gates, and trust-weighted retrieval; the newer AKF and world-model-mcp comments are useful prior art but do not close the OpenClaw memory contract gap.

## What This Changes

The issue requests source-based trust metadata on agent memories plus policy enforcement for expiration, review gates, and trust-weighted retrieval.

## Best Possible Solution

Keep this issue open for maintainer/security design of a SQLite-backed memory provenance and trust contract across memory-core, QMD, session memory, Active Memory, Memory Wiki, and plugin SDK surfaces, using AKF and world-model-mcp as prior art rather than treating them as shipped core behavior.
