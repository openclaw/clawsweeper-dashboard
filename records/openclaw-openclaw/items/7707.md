## Summary

Keep open: current main and v2026.6.11 still expose source buckets, citations, Active Memory untrusted framing, and Memory Wiki provenance, but not a native durable-memory trust contract with persisted trust tiers, review state, expiration gates, or trust-weighted retrieval.

## What This Changes

The issue requests source-based trust metadata and policy enforcement for agent memory to reduce persistent memory-poisoning risk from untrusted inputs.

## Best Possible Solution

Define a maintainer-approved trust/provenance contract first, then implement source-authoritative ingestion, persisted trust and review metadata, retrieval-time filtering or weighting, expiration policy, and docs/tests across memory-core, QMD, Active Memory, Memory Wiki bridge inputs, and SDK surfaces.
