## Summary

Keep open: current main and v2026.6.11 still lack native durable memory trust metadata, review/expiration policy, and trust-aware retrieval, while the newer world-model-mcp comment is useful external MCP prior art rather than a replacement for OpenClaw's default memory contracts.

## What This Changes

The issue requests source-based trust tagging, expiration/review policy, and trust-weighted retrieval for durable agent memory.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract that persists host-authored source and review metadata through memory-core, QMD, session memory, Memory Wiki bridges, compaction/dreaming, SDK/config surfaces, and retrieval policy, while treating MCP/plugin projects as complementary self-serve integrations.
