## Summary

Keep open for maintainer product and security design. Current main documents manual source/authority boundaries and supports alternative memory plugins, but the default memory contract still lacks framework-authenticated trust metadata, review or influence state, trust-based expiration, and retrieval enforcement; the external world-model-mcp implementation is useful prior art, not equivalent default behavior. ([github.com](https://github.com/openclaw/openclaw/blob/main/docs/concepts/memory.md?utm_source=openai))

## What This Changes

Requests source-derived trust metadata and policy enforcement for persisted agent memory, including review, expiration, and influence controls.

## Best Possible Solution

Define a framework-authenticated provenance and influence contract in the memory plugin SDK, store canonical metadata in SQLite with a named migration owner, preserve it across compaction and plugin bridges, and enforce configurable review, expiry, and retrieval gates without trusting agent-supplied labels.

Options:

- **Keep trust plugin-owned:** Document memory-core as operator-trusted storage and route trust-governed memory to external plugins or MCP backends such as world-model-mcp.
- **Limit scope to provenance:** First land source attribution through the portable contract, while tracking expiration and influence enforcement as separately approved follow-up work.
