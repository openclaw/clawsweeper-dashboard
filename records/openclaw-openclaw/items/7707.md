## Summary

Keep open for maintainer product and security design. Current main documents source authority and review boundaries as Markdown guidance but explicitly does not enforce memory policy; the default retrieval contract still lacks durable trust metadata, review state, trust-aware expiration, and influence controls. The open provenance issue and actor-context PR cover prerequisites rather than the complete request, while AKF and world-model-mcp are useful prior art and optional deployment paths, not native protection for the default memory path.

## What This Changes

Requests persistent source-based trust metadata, expiration and review policies, and trust-aware memory retrieval.

## Best Possible Solution

Define framework-assigned provenance plus orthogonal review and influence states in the memory host/plugin SDK, implement them in the recommended default backend with migration and enforcement tests, and let other memory plugins map that portable contract; evaluate AKF and world-model-mcp as prior art rather than adding the proposed config shape directly.
