## Summary

Keep open: current main and v2026.6.11 still have source buckets, citations, Active Memory untrusted framing, and Memory Wiki provenance, but not a native durable-memory trust contract with persisted trust tiers, review state, expiration gates, or trust-weighted retrieval.

## What This Changes

Request adds native memory trust metadata by source, policy config for expiration/review/isolation, and trust-aware retrieval to mitigate memory poisoning.

## Best Possible Solution

Define a maintainer-approved trust/provenance contract first, then implement framework-owned source authority, persisted trust/review metadata, retrieval-time filtering or weighting, expiration policy, and docs/tests across the native memory surfaces.
