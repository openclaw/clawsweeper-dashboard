## Summary

Keep open: current main and v2026.6.11 still lack persistent memory trust metadata, trust-policy config, review/expiration gates, and trust-weighted retrieval; related provenance and capture-filter issues overlap but do not replace this security/product design item.

## What This Changes

The issue requests source-derived trust tags and policies for durable memory so untrusted content cannot silently influence later agent behavior.

## Best Possible Solution

Keep this open for maintainer product/security design, aligned with the durable provenance tracker, and define one native trust contract before implementation touches memory schema, config, retrieval, promotion, compaction, UI/docs, or plugin SDK surfaces.
