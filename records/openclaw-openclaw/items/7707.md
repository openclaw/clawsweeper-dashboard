## Summary

Keep open: current main and the latest release still provide source buckets, input provenance, untrusted wrapping, Memory Wiki provenance, temporal decay, and Active Memory filtering, but not durable memory trust metadata, trust authority, review/expiration gates, or trust-weighted retrieval for the default memory path. The AKF and world-model-mcp comments are useful existing-solution prior art, but they do not replace the OpenClaw memory/plugin contract decision this issue is asking for.

## What This Changes

The issue requests source-based trust metadata, policy, expiration/review gates, and trust-weighted retrieval for persistent agent memory.

## Best Possible Solution

Run a maintainer product/security design pass that chooses the native-vs-plugin/MCP boundary first, then implement the smallest core/plugin SDK contract needed to persist framework-assigned provenance and enforce review, expiration, and retrieval policy consistently across memory backends.
