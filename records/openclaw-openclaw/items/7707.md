## Summary

Keep open: current main and latest stable release still expose memory source buckets, citations, manual guidance, Active Memory framing, and Memory Wiki provenance, but not a native durable-memory trust contract with persisted trust tiers, review state, expiration gates, or trust-weighted retrieval.

## What This Changes

Request durable memory entries be tagged by source trust, reviewed or expired by policy, and filtered or downweighted during retrieval to mitigate memory poisoning.

## Best Possible Solution

Define a maintainer-approved trust/provenance contract first, then implement source-authoritative ingestion, persisted trust and review metadata, retrieval-time filtering or weighting, expiration policy, and docs/tests across memory-core, QMD, Active Memory, Memory Wiki bridge inputs, and SDK surfaces.
