## Summary

Keep open: current main and v2026.6.11 still have source buckets, citations, session visibility filtering, temporal decay, and Active Memory untrusted framing, but not native durable trust metadata, trust authority, review/expiration gates, or trust-weighted retrieval. The AKF and world-model-mcp comments are useful prior art, not shipped OpenClaw default-memory coverage.

## What This Changes

The issue requests native memory trust metadata by source, with configurable expiration, review/isolation policy, and trust-aware retrieval weighting to mitigate memory poisoning.

## Best Possible Solution

Define one native, non-agent-forgeable memory trust/provenance contract, then persist source and review metadata at ingestion and enforce filtering, downweighting, review, and expiration across memory-core, QMD, SDK/results, and UI/docs while evaluating AKF and world-model-mcp as prior art.
