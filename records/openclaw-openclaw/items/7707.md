## Summary

Keep open: current main and v2026.6.11 still have only source buckets, citations, untrusted prompt framing, and provenance-rich optional paths, not persistent memory trust metadata, trust-policy config, review/expiration gates, or trust-weighted retrieval for the default memory path. The recent world-model-mcp comments are useful external prior art, but they do not close the native OpenClaw memory-core and SDK contract gap.

## What This Changes

The issue requests persistent memory trust tagging by source, with configurable trust tiers, expiration, review isolation, and trust-aware retrieval to reduce memory-poisoning risk.

## Best Possible Solution

Adopt a maintainer-approved native memory trust/provenance contract, then implement source authority, review state, expiration/influence policy, retrieval enforcement, and docs across the default and optional memory paths.
