## Summary

Keep open: current main and v2026.6.11 still have source buckets, citations, Active Memory untrusted framing, and Memory Wiki provenance, but not persistent memory trust tiers, trust-policy config, review/expiration gates, or trust-weighted retrieval. The world-model-mcp adapter linked in the discussion is useful external prior art, but it does not close the native memory contract gap.

## What This Changes

Requests source-derived trust metadata and policies for memory entries so untrusted web, tool, and third-party content can expire, require review, or be downweighted at retrieval.

## Best Possible Solution

Define one maintainer-approved memory trust/provenance contract, then implement ingestion-time source authority, persisted trust/review metadata, retrieval-time filtering/downweighting, expiration policy, and docs/tests across memory-core, QMD, Active Memory, Memory Wiki bridge inputs, and SDK surfaces.
