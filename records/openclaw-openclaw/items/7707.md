## Summary

Keep open: current main has only coarse memory/session source buckets plus adjacent untrusted-context mitigations; it does not implement native durable memory trust metadata, review or expiration policy, or trust-aware retrieval for the default memory path.

## What This Changes

Request durable memory trust tagging by origin, with trust-level policy, expiration and review isolation, and trust-weighted retrieval to reduce memory poisoning.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract with host-authored source and review metadata plus retrieval-time policy, treating AKF/world-model-mcp and manual governance patterns as prior art rather than replacements.
