## Summary

Keep open: current main and v2026.6.11 still have source buckets, citations, Memory Wiki provenance, and Active Memory framing, but not a native durable-memory trust contract with persisted trust tiers, review state, expiration gates, or trust-weighted retrieval.

## What This Changes

The issue requests source-derived trust metadata and policy enforcement for persistent memory entries to reduce memory poisoning risk.

## Best Possible Solution

Define a maintainer-approved trust/provenance contract first, then implement framework-owned source attribution, persisted trust and review metadata, retrieval-time filtering or weighting, expiration policy, and docs/tests across memory-core, QMD, Active Memory, Memory Wiki bridge inputs, and SDK surfaces.
