## Summary

Keep open for maintainer product and security design. Current memory documentation provides advisory source-authority guidance, but the default memory contract still lacks framework-owned trust provenance, review state, trust-aware retention, and enforceable influence controls; related work covers narrower prerequisites rather than the complete request.

## What This Changes

Add source-derived trust metadata and configurable retention, review, isolation, and retrieval-influence policies to persistent agent memory.

## Best Possible Solution

Define a framework-owned provenance and influence contract in the memory/plugin SDK, carry trusted origin facts from ingestion through promotion and recall, implement a reference policy in memory-core with explicit review and expiry transitions, and let external memory plugins map their richer schemas onto that portable contract without adding backend-specific policy to core.
