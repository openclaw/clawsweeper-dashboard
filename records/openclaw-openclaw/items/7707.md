## Summary

Keep open: current main and v2026.6.11 still have source buckets, session visibility, and adjacent untrusted-context framing, but not native durable memory trust metadata, review/expiration policy, or trust-aware retrieval. The AKF and world-model-mcp comments are useful prior art and external options, but they do not close the native OpenClaw memory/security gap.

## What This Changes

Request native trust metadata for memory entries by source, with trust-policy config for expiration, review isolation, and trust-weighted retrieval.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract with host-authored source and review metadata plus retrieval policy, treating AKF, world-model-mcp, and Memory Wiki as prior art rather than replacements.
