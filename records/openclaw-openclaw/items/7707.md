## Summary

Keep open: current main and v2026.6.11 still lack durable memory trust metadata, trust-policy config, review/expiration gates, and trust-weighted retrieval; AKF and world-model-mcp are useful prior art, but they do not close the native OpenClaw memory contract gap.

## What This Changes

Request to tag durable memory entries with source-derived trust metadata and enforce review, expiration, and retrieval influence policy to mitigate memory poisoning.

## Best Possible Solution

Keep open for maintainer/security design of a SQLite-backed memory provenance and trust contract across memory-core, QMD, session memory, Active Memory, Memory Wiki, and plugin SDK surfaces, using world-model-mcp and AKF as prior art rather than treating them as shipped core behavior.
