## Summary

Keep open: current main and v2026.6.11 still have source buckets, session visibility filtering, Active Memory untrusted framing, and provenance-oriented docs/prior art, but not persistent trust metadata, trust-policy config, review/expiration gates, or trust-weighted retrieval for the default memory path.

## What This Changes

Request native memory trust tagging by source, with configurable trust policy, isolation/review behavior, expiration, and trust-aware retrieval to reduce memory poisoning risk.

## Best Possible Solution

Keep this as a maintainer-owned memory security design item; define one native trust/provenance contract, then implement persisted trust metadata, trust policy config, review/expiration gates, retrieval weighting/filtering, and docs/tests across default and optional memory paths.
