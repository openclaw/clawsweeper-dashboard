## What This Changes

The issue requests source-based trust metadata and trust-policy enforcement for persistent memory so untrusted content cannot poison later agent behavior.

## Best Possible Solution

Define a maintainer-approved native trust/provenance contract first, then implement framework-owned source classification, persisted trust and review metadata, storage-vs-influence policy, retrieval-time filtering or weighting, expiration, UI/docs, migrations, and regression coverage across memory-core, QMD, Active Memory, Memory Wiki inputs, and SDK surfaces.
