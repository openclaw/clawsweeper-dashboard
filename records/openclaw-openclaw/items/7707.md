## Summary

Keep open: current main and the latest release have adjacent source labels, session visibility filtering, Active Memory untrusted framing, Memory Wiki provenance, and external-content wrapping, but they still lack native persistent trust metadata, trust-policy config, review/expiration gates, and trust-weighted retrieval for the default memory path.

## What This Changes

Add source-derived trust tagging for durable memories, with expiration, review isolation, and retrieval influence policies for lower-trust origins.

## Best Possible Solution

Adopt a maintainer-approved native memory trust contract that persists source, review, storage, influence, expiry, and provenance metadata through ingestion, compaction, retrieval, SDK/backends, UI, and docs before implementing policy knobs.
