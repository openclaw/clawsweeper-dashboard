## Summary

Keep open: current main and v2026.6.11 still lack native durable memory trust metadata, review/expiration policy, and trust-aware retrieval, while world-model-mcp and Memory Wiki are useful adjacent paths rather than replacements for OpenClaw's native memory contracts.

## What This Changes

The issue requests source-derived trust tags for persistent memory, with policy-driven expiration, review gates, isolation, and trust-weighted retrieval to reduce memory-poisoning risk.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract that persists host-authored source and review metadata through memory-core, QMD, session memory, Memory Wiki bridges, compaction/dreaming, SDK/config surfaces, and retrieval policy, while treating MCP/plugin projects as complementary integrations.
