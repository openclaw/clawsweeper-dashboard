## Summary

Keep open: current main and latest stable v2026.6.11 still expose coarse memory/session source buckets and adjacent provenance/framing layers, but not native durable memory trust metadata, review/expiration policy, or trust-aware retrieval for the default memory path.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract with host-authored source and review metadata plus retrieval policy, treating AKF, world-model-mcp, and Memory Wiki as prior art rather than replacements.
