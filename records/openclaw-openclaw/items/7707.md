## Summary

Keep open: current main and the latest checked release still expose source buckets and adjacent untrusted-context handling, but not persisted memory trust metadata, trust-policy configuration, review or expiration gates, or trust-weighted retrieval for durable memory.

## What This Changes

Add memory trust metadata and policy enforcement so durable memory is tagged by source and retrieval can filter, downweight, expire, or require review for lower-trust entries.

## Best Possible Solution

Complete a maintainer/security design for a native memory provenance and trust contract across memory-core, QMD, active memory, SDK/config/schema, ingestion authority, retrieval filtering/weighting, review/expiration gates, docs, and tests.
