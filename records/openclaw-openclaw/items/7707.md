## Summary

Keep open: current main and v2026.6.11 still provide source buckets, session visibility, citations, and Active Memory untrusted framing, but not native durable trust metadata, review/expiration policy, or trust-aware retrieval across the default memory paths. AKF and world-model-mcp are useful prior art or external integrations, but they do not close the native OpenClaw memory/security design gap.

## What This Changes

The issue requests source-based trust tagging for persistent memory entries, with policy-driven expiration, review/isolation, and trust-weighted retrieval to reduce memory poisoning risk.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract with host-authored source and review metadata plus retrieval policy, treating AKF, world-model-mcp, and Memory Wiki as prior art rather than replacements.
