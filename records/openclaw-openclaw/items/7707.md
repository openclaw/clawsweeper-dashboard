## Summary

Keep open: current main and v2026.6.11 still have source buckets, session visibility, Active Memory untrusted framing, Memory Wiki provenance, and external prior-art integrations, but not native durable memory trust metadata, trust-policy config, review/expiration gates, or trust-aware retrieval for the default memory path.

## What This Changes

Request to tag durable agent memory by source trust level and enforce expiration, review, isolation, and trust-weighted retrieval policies to mitigate memory poisoning.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract with host-authored source and review metadata, SQLite-backed schema/migrations, plugin SDK/config coverage, and retrieval-time review, expiration, and downweighting policy.
