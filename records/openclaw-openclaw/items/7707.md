## Summary

Keep open: current main still has source buckets, citations, session visibility, and adjacent provenance work, but it does not provide durable memory trust metadata, trust-policy config, review/expiration gates, or trust-weighted retrieval for the default memory path.

## What This Changes

Add durable memory trust tagging by source with policy config, expiration/review isolation gates, and trust-weighted retrieval to reduce memory poisoning risk.

## Best Possible Solution

Define a native, framework-owned trust/provenance contract first, then implement it through memory-host SDK, SQLite/QMD storage, memory-core retrieval, session/active-memory/wiki/dreaming flows, config, docs, and tests.
