## Summary

Keep open: current main and v2026.6.11 still have coarse memory/session source buckets, adjacent untrusted-context framing, Memory Wiki provenance, and external MCP prior art, but not native durable memory trust metadata, trust policy config, review/expiration gates, or trust-aware retrieval in OpenClaw's memory path.

## What This Changes

The issue requests native memory trust tagging by source, with durable trust metadata, configurable trust policies, review/expiration gates, and trust-weighted retrieval.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract with host-authored source and review metadata, durable SQLite-backed storage, migration behavior, and retrieval-time policy, treating AKF, world-model-mcp, and Memory Wiki as prior art rather than replacements.
