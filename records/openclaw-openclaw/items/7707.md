## Summary

Keep open: current main has adjacent source buckets, citations, Active Memory untrusted framing, and an external world-model-mcp implementation, but still lacks native persistent trust metadata, review/expiration gates, policy config, and trust-weighted retrieval for OpenClaw memory.

## What This Changes

Request persistent memory trust metadata and policy by source so untrusted memory can be reviewed, expired, filtered, or downweighted during retrieval.

## Best Possible Solution

Define one native trust/provenance contract, then implement framework-owned trust assignment through ingestion, storage, retrieval, promotion, compaction, Active Memory, SDK/docs, and safe-default policy modes.
