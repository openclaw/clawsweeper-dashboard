## Summary

Keep open: current main and v2026.6.11 still lack persistent memory trust metadata, trust-policy config, review/expiration gates, and trust-weighted retrieval. The AKF and world-model-mcp links are useful prior art, and the open source-actor recall PR is adjacent, but none of them replaces a native OpenClaw memory trust contract.

## What This Changes

The issue requests source-derived trust metadata and trust-policy enforcement for persisted agent memory to reduce memory poisoning risk.

## Best Possible Solution

Define a maintainer-approved native memory trust/provenance contract, then implement source-derived metadata, storage/review/expiration state, retrieval-time filtering or weighting, SDK/plugin/MCP interop, docs, and regression coverage across the default and optional memory paths.
