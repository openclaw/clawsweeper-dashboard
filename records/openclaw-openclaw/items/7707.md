## Summary

Keep open for a maintainer-owned security and product decision. The discussion and the prior completed review identify a still-missing framework-authenticated provenance and influence contract; the active related provenance item is overlapping but does not make this request redundant.

## What This Changes

Request source-derived trust metadata for persisted memories, with retention, review, and retrieval-influence controls to reduce memory-poisoning risk.

## Best Possible Solution

Establish one maintainer-approved provenance and influence contract, likely coordinated with https://github.com/openclaw/openclaw/issues/42647: framework-derived origin must be immutable, endorsement/review must remain separate from origin, and each supported memory backend must either enforce the same retrieval policy or explicitly remain outside the contract.
