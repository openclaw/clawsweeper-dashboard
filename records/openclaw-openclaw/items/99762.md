## Summary

Keep open: current main already collapses tool cards and offers a side-panel/raw-output inspection path, but it still retains generic full text and does not provide the requested thresholded JSON artifact contract or array pagination. This is a cross-runtime MCP and Control UI product decision, not a narrow bug repair.

## What This Changes

The issue requests structured artifact/previews and pagination for large MCP JSON tool outputs instead of rendering full payloads inline.

## Best Possible Solution

Define one typed, transcript-backed large-result artifact reference with explicit agent visibility, retention/privacy limits, and Control UI retrieval; keep server-specific formatting or catalog pagination in MCP/plugin code unless the generic contract proves insufficient.
