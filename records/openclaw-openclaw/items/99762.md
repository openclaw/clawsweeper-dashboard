## Summary

Keep open: current OpenClaw has generic transcript-derived artifacts, plugin-SDK JSON tool-result helpers, and MCP content coercion, but the evidence does not show an automatic large-MCP-JSON preview/artifact path that preserves a stable agent-visible payload. This remains a cross-runtime product decision, not a narrow repair.

## What This Changes

The issue requests structured artifact/previews and bounded human-facing rendering for large JSON results returned by MCP tools.

## Best Possible Solution

Design one generic tool-result presentation contract that preserves a canonical model-visible payload while emitting a bounded summary plus a transcript-derived artifact reference; let MCP results adopt that contract rather than adding MCP-only pagination or storage.
