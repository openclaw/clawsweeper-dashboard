## Summary

Keep open: current main still protects large tool output with textification, truncation, placeholders, and media-oriented artifact RPCs, but it does not implement the requested MCP-aware structured JSON artifact, preview, or pagination path.

## What This Changes

Request structured previews or artifacts for large MCP JSON tool outputs so full payloads remain inspectable without flooding the visible chat/context.

## Best Possible Solution

Design a bounded generic MCP/tool-output preview path that reuses existing transcript artifact RPCs and Control UI sidebar/canvas patterns, with concise default previews and full-payload access only under clear retention and redaction rules.

## Reproduction Assessment

Not applicable: this is a feature request, not a report of broken documented behavior. Source inspection shows current main textifies or truncates large tool results rather than producing structured JSON artifacts/previews.

## Solution Assessment

Unclear until maintainers choose the product boundary. The artifact-plus-preview direction is plausible, but the best implementation needs decisions on storage owner, redaction, retention, UI affordance, and whether existing limits avoid new config.
