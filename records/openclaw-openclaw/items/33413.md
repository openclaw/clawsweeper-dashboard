## Summary

Keep open: current main partially improves Slack assistant-thread status with fixed rotating loading messages, but it still does not update `assistant.threads.setStatus` with the active tool. The remaining work is valid, but it needs Slack product/safety direction before another implementation attempt.

## What This Changes

Request to update Slack assistant-thread status during agent runs with human-readable tool-level progress instead of only generic typing/status text.

## Best Possible Solution

Keep this issue open, settle the Slack-safe native status policy, then implement coarse per-tool status in the Slack plugin using the existing `onToolStart` and `setSlackThreadStatus` seams with focused tests, docs, and live Slack proof.
