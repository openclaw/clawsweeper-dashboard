## Summary

Keep open: current main still does not update native Slack assistant thread status per active tool. The remaining work is a Slack UX/product decision because main already has fixed loading messages plus draft/reaction progress, and per-tool native status intersects the open Slack-safe visibility policy.

## What This Changes

Requests Slack assistant thread status to update with the active tool during an agent run instead of showing only a generic typing/status indicator.

## Best Possible Solution

Choose one Slack-owned status/progress policy; if native per-tool status is accepted, derive sanitized shared progress labels into assistant thread status with dedupe, clear behavior, tests, docs, and live Slack proof.
