## Summary

Keep open: current main still does not update Slack native assistant-thread status with the active tool. The source now has fixed Slack loading messages, but per-tool events still feed status reactions and draft-preview progress rather than `assistant.threads.setStatus`, so this remains a Slack UX/disclosure product decision.

## What This Changes

Request to make Slack assistant-thread native status show the currently running tool instead of only a generic typing/loading status.

## Best Possible Solution

Choose the Slack native-status disclosure policy first, then either implement sanitized per-tool native status with live Slack proof or explicitly keep native status generic while existing progress surfaces carry tool detail.
