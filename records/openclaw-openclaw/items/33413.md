Request Slack assistant-thread status to show active tool-level progress instead of only a generic typing indicator.

## Best Possible Solution

Choose one Slack-owned progress UX policy, then either implement sanitized per-tool native status from the shared progress model with dedupe and live proof, or explicitly keep native status generic and rely on loading messages, preview progress, task cards, and reactions.
