## Summary

Keep open: current main has improved Slack assistant-thread status with fixed rotating loading messages, but it still does not update `assistant.threads.setStatus` with the active tool name. The remaining work is a valid Slack UX request, but it needs maintainer product direction because native per-tool labels overlap Slack progress disclosure policy and configurable status-message work.

## What This Changes

The issue requests Slack assistant-thread status updates that name the currently running tool instead of using only a static or generic processing status.

## Best Possible Solution

Decide Slack’s status visibility policy first, then implement a Slack-owned per-tool assistant-status path that reuses structured progress labels, preserves clear behavior, documents safe defaults, and includes live Slack proof.
