Keep open: current main still sets Slack native assistant-thread status to generic start/loading text and clears it at completion, while per-tool events feed Slack preview/status-reaction surfaces rather than `assistant.threads.setStatus`. ## What This Changes

Request dynamic Slack assistant-thread status text that reflects the currently running tool during agent execution.

## Best Possible Solution

Choose the Slack native-status disclosure policy first, then either implement sanitized per-tool native status with live Slack proof or explicitly keep native status generic while existing progress surfaces carry tool detail.
