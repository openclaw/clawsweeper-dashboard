## What This Changes

The PR moves lifecycle, agent-dedupe, and chat-dedupe terminal observations and waiter resolution into the agent job registry, removes the separate dedupe waiter module, and simplifies affected Gateway callers and tests.

## Best Possible Solution

Retain the single registry, but apply terminal precedence only within each source or logical run and choose cross-source agent/chat collisions by the latest observation, with focused disagreement tests and subsequent lifecycle-owner approval.
