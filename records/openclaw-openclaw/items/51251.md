The issue asks OpenClaw to prevent stale persisted session model overrides from silently shadowing changed config defaults and to provide clearer visibility and reset behavior.

## Best Possible Solution

Adopt a maintainer-approved source-aware policy that preserves explicit pins by default, clears auto or invalid stale pins, exposes the source chain, and adds an opt-in bulk reset or reconcile path if maintainers want that workflow.
