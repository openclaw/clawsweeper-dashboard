## Summary

Keep open: current main now makes pinned session models visible and supports per-session clearing, but explicit and legacy user model pins are still intentionally preserved across reset/restart, and bulk reset or precedence changes remain compatibility-sensitive product work.

## What This Changes

The issue requests clearer handling of persisted session model overrides so config default changes are not silently shadowed and users can reset stale pins.

## Best Possible Solution

Keep explicit pins durable by default, but add a maintainer-approved, dry-run-first reset/reconcile path and keep status/doctor visibility source-aware.
