## What This Changes

The issue asks for session-level `/model` overrides to stop silently masking changed config defaults across gateway restarts and new sessions, or to be clearly visible and resettable.

## Best Possible Solution

Adopt a maintainer-approved model/session recovery design: keep explicit pins visible, provide scoped dry-run reset or reconcile tooling, and only clear or rewrite persisted overrides with explicit user/operator intent.
