## Summary

Keep open: this targets a real user-visible reply wedge, but the current PR head still retries after `fail()` without clearing retained lifecycle operations, so the production dispatch shape can remain wedged; real Telegram/runtime proof is also still absent.

## What This Changes

The branch changes reply-turn admission to time out aborted active runs, fail and retry them for visible turns, and adds admission tests for superseded and healthy active runs.

## Best Possible Solution

Use force-clear or complete-equivalent semantics for aborted retained reply operations, cover that retained dispatch/lifecycle shape in tests, and require redacted Telegram or runtime proof before merge.

## Solution Assessment

No. Bounding already-aborted active-run waits is the right layer, but the proposed cleanup must use complete-equivalent clearing and test the retained dispatch shape before it is the narrow maintainable fix.
