## Summary

Keep open. Current main still exposes the deprecated broad `agent-runtime` surface, while the documented private testing-subpath policy does not prevent `testing` and `__testing` object shapes from leaking through that wildcard export. The broader SDK-consolidation issue overlaps architecturally but does not replace this concrete compatibility migration, and the maintainer-authored/protected item requires explicit API-direction review.

## What This Changes

Create an intentional Plugin SDK testing boundary, migrate consumers away from `agent-command` wildcard exports, preserve shipped imports through deprecation, and guard declarations against internal-field leakage.

## Best Possible Solution

Inventory released and in-repo consumers, define the smallest supported testing contract, migrate bundled callers, retain the shipped aliases through an explicit deprecated adapter with a removal plan, replace the wildcard facade, and add a semantic API-baseline guard against internal-field expansion.
