## Summary

Keep open: the timestamp fix direction is right, but the branch moves the only trajectory flush behind cleanup. Because cleanup can hang during bundle runtime disposal, `model.completed`, `trace.artifacts`, and other pre-cleanup events can remain buffered and never persist.

## What This Changes

The PR defers embedded-runner `session.ended` trajectory emission until after cleanup, carries terminal status/error data, marks cleanup failures as errors, and flushes after the final event.

## Best Possible Solution

Use a two-phase trajectory flush: flush already-recorded runtime events before potentially hanging cleanup, then record `session.ended` after cleanup and flush again.
