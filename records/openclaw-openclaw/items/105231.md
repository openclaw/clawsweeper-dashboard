Keep open: current main and the latest release retain an unbounded projected transcript for every no-limit session-history SSE connection, and no linked fix PR currently owns the repair.

## What This Changes

Bound the in-memory transcript projection retained by long-lived session-history SSE connections while preserving access to older SQLite-backed history.

## Best Possible Solution

Keep durable history in SQLite and make every long-lived SSE projection bounded, using the existing recent-tail and cursor paths for older messages while preserving the non-streaming API contract and inline projection behavior.
