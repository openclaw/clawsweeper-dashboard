## Summary

Keep open: current main and v2026.6.11 still route retryable `requests-in-flight` heartbeat skips through the shared 1 second wake retry path, and the linked debounce fix remains open and unmerged.

## What This Changes

The issue reports that the heartbeat drift fix made `requests-in-flight` skips retry too aggressively, letting heartbeat runs block active Telegram and other channel conversations.
