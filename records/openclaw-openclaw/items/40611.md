## Summary

Keep this open: current main and v2026.6.11 still retry `requests-in-flight` heartbeat skips through the shared 1 second wake timer, and the open linked PR remains the candidate fix rather than a reason to close the issue early.

## Best Possible Solution

Keep this issue as the canonical bug report until https://github.com/openclaw/openclaw/pull/89989 or an equivalent narrow wake-layer retry fix is reviewed and merged; keep broader activity-based or non-blocking heartbeat work separate.
