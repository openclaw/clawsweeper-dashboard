## Summary

Keep open: current main and the latest release still route `requests-in-flight` heartbeat skips through the shared 1 second wake retry path, and the open linked PR remains the candidate fix rather than a reason to close this issue.

## What This Changes

The issue asks to stop `requests-in-flight` heartbeat skips from retrying so aggressively that a heartbeat can grab the session lock immediately after an active conversation turn.
