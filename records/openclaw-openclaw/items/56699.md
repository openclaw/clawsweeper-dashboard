## Summary

Keep open: current main and the latest release still make Telegram native slash commands skip topic/group `groupPolicy` overrides, so disabled forum topics can still trigger bots that should ignore the command.

## What This Changes

The issue asks for Telegram native slash commands in forum topics to respect per-account topic `groupPolicy: "disabled"` and avoid triggering non-owning bots.

## Best Possible Solution

Land a narrow Telegram plugin fix that makes native slash commands resolve the same effective topic/group policy as regular messages and silently drop disabled-topic commands, with focused regression tests and real Telegram proof.

## Reproduction Assessment

Yes, source-level: current main passes `useTopicAndGroupOverrides: false` for Telegram native-command policy evaluation while topic `groupPolicy` is only read when that flag is true. I did not run a live Telegram forum repro in this read-only review.

## Solution Assessment

Yes for the fix direction, but not the previously closed one-line PR as-is. The maintainable solution should align native commands with regular message policy resolution and preserve silent ignore behavior for disabled topics.
