## Summary

Keep open: current main and the latest release still evaluate Telegram native slash-command group policy without topic/group overrides, so disabled forum topics can still bypass the intended per-account topic policy. The duplicate issue is closed to this one, the same-repo fix PR was closed unmerged as incomplete, and the open callback PR covers adjacent but different Telegram authorization behavior.

## What This Changes

The issue asks Telegram native slash commands in forum topics to respect topic/group `groupPolicy` overrides so non-owning bots ignore disabled topics instead of handling the command.

## Best Possible Solution

Land a narrow Telegram plugin fix that makes native slash commands use the same effective topic/group policy as regular messages and silently ignores disabled-topic commands, with focused regression tests and real Telegram forum proof.
