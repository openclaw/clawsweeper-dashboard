Keep open: current main and the latest release still evaluate Telegram native slash-command group policy with topic/group overrides disabled, so disabled forum topics remain a source-reproducible authorization and routing bug. ## What This Changes

The issue asks Telegram native slash commands in forum topics to respect per-topic and per-group `groupPolicy: "disabled"` so non-owning bots ignore them.

## Best Possible Solution

Land a narrow Telegram plugin fix that makes native slash commands use the same effective topic/group policy as regular messages and silently drops disabled-topic commands before session creation, with focused regression tests and real Telegram forum proof.
