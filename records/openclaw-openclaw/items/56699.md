## Summary

Keep open: current main and v2026.6.11 still evaluate Telegram native slash-command group policy with topic/group overrides disabled, so disabled forum topics can still trigger bots that should ignore the command. The same-repo fix PR was closed unmerged, the open fork PR is the same incomplete one-line approach, and the open `/models` callback PR covers a different Telegram authorization path.

## What This Changes

Make Telegram native slash commands in forum topics honor the effective topic/group `groupPolicy` so disabled topics do not trigger non-owning bots.

## Best Possible Solution

Land a narrow Telegram plugin fix that applies the same effective topic/group policy to native slash commands as regular messages, silently ignores disabled-topic commands, and includes focused regression coverage plus real Telegram forum proof.
