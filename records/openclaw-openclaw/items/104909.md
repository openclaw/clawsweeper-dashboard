## Summary

Keep open: current `main` still leaves each QA smoke invocation bounded only by the 60-minute job timeout, while this narrow patch adds the missing per-invocation limit without disrupting exit capture or artifact upload. Source review found no correctness or security defect; both exact-head smoke profiles and the workflow guard passed, and the remaining red shards fail unrelated session and usage-cost tests outside the changed surface.

## What This Changes

The PR wraps each Linux QA smoke-profile invocation with a ten-minute GNU `timeout`, followed by a 15-second KILL grace, and adds a workflow guard assertion for the command.

## Best Possible Solution

Keep a measured per-profile Linux deadline above normal runtime variance, preserve nonzero timeout reporting and always-run artifact upload, and rely on the existing one-second parent watchdog to clean detached QA gateways.
