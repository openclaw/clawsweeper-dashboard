## What This Changes

The PR adds a `toolsAllow` result to `before_prompt_build` plugin hooks so plugins can narrow the tools submitted to a model for one turn, including zero-tool turns.

## System Context

Prompt hooks run after OpenClaw has assembled a turn and before the model receives it. This change carries a plugin-requested tool restriction through the embedded agent runner and Copilot harness so the final submitted tool schemas and tool-search catalog can be narrowed for that turn.
