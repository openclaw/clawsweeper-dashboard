## Summary

Keep open, but do not merge the current patch. Supported Exa flows already resolve credentials through centralized runtime preparation, so the proposed provider-level rule duplicates that owner, conflicts with its documented recovery behavior, and lacks a real supported reproduction.

## Best Possible Solution
