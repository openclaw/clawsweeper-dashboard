## Summary

This is a substantial, proof-backed feature proposal, not a cleanup candidate. The remaining blocker is explicit maintainer acceptance of the intentional fail-closed behavior: a pending approval shown for one proposal version cannot apply a later revision.

## What This Changes

This PR adds a read-only Skill Workshop review action that shows the canonical skill content for creates or a unified diff for updates before an operator approves a proposal.

## System Context

Skill Workshop stores reusable-skill proposals and applies approved proposals to workspace skill files. The new review projection reads the proposed and live content, presents it through the agent tool or CLI, and binds lifecycle decisions to the reviewed proposal version.
