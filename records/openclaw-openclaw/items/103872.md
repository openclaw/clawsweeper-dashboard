## Summary

Keep this PR open for maintainer product review. It has concrete operator support and recorded Telegram behavior proof, but it adds a durable Skill Workshop approval contract: pending approvals become version-bound and fail closed after a revision; the contributor explicitly notes this still lacks upstream maintainer endorsement.

## What This Changes

Adds a read-only Skill Workshop review action that shows the canonical create result or update diff before a proposal is approved, with bounded pagination and optional proposal-version checks for lifecycle actions.

## System Context

Skill Workshop stores and validates reusable-skill proposals before they can change workspace skill files. This PR adds a read-only projection between proposal creation and lifecycle approval, then carries the reviewed version into the approval gate so a changed proposal cannot be approved through an older prompt.
