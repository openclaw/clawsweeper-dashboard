## Summary

Keep this PR open, but the current patch is not mergeable: it preserves `0` while still sending `thinking: { type: "enabled" }`, which creates a zero-token enabled-thinking payload instead of using OpenClaw's existing disabled-thinking path.

## What This Changes

The PR changes the Anthropic provider and agent transport thinking budget fallback from `|| 1024` to `?? 1024`.

## Best Possible Solution

Preserve the current provider contract by never emitting `budget_tokens: 0` with `type: "enabled"`; if zero should mean off, normalize it through the existing disabled-thinking path before payload construction.
