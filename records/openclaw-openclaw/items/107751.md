## What This Changes

The PR adds format-aware Windows launcher encoding and deterministic readback, applies it to scheduled-task install and restart scripts, promotes iconv-lite, and adds regression coverage.

## Best Possible Solution

Land one shared launcher codec that writes VBS as UTF-16LE with BOM, writes CMD in a verified console-compatible code page when possible, records that encoding for deterministic readback, and fails with an actionable error rather than emitting a broken launcher.
