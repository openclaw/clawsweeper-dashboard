## Summary

## What This Changes

The issue reports that token-based memory flush can be disabled when `reserveTokensFloor` is configured equal to the active context window.

## Best Possible Solution

Centralize a context-window-aware effective reserve or positive threshold for memory flush and token-based preflight compaction, with focused regression coverage for `reserveTokensFloor >= contextWindowTokens` and documented upgrade behavior for existing oversized configs.
