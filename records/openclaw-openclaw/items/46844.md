## Summary

Keep open: current main and v2026.6.11 still lack a between-turn Talk idle timeout or public idle-timeout config, so this remains valid product work rather than cleanup-close material.

## What This Changes

Request to add a configurable Talk Mode idle timeout that deactivates inactive Voice Wake-started Talk sessions and returns to wake-word waiting.

## Best Possible Solution

Define one additive Talk idle-timeout contract, expose it through config and talk.config/protocol/docs, and implement Talk so inactive sessions return to wake-word waiting without changing silenceTimeoutMs semantics.
