## Summary

Keep open. Current main and v2026.6.11 still support Voice Wake activating Talk Mode and intra-turn silence handling, but they do not provide the requested between-turn Talk idle deactivation or public idle-timeout config contract.

## What This Changes

The issue requests a configurable Talk Mode idle timeout that turns off Voice Wake-started Talk sessions after inactivity and returns to wake-word listening.

## Best Possible Solution

Define one additive Talk idle-timeout contract, expose it through config/protocol/docs, and implement macOS Talk lifecycle so inactive sessions return to wake-word waiting without changing silenceTimeoutMs semantics.
