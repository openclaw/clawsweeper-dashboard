## What This Changes

The issue requests a configurable Talk Mode idle timeout that auto-deactivates Talk after Voice Wake activation when no user interaction occurs.

## Best Possible Solution

Keep this issue as the canonical tracker until https://github.com/openclaw/openclaw/pull/102956 or another maintainer-approved PR lands an additive config/protocol/docs/macOS runtime idle-timeout contract.
