## Summary

Keep this issue open as the canonical remaining Telegram forum-topic lifecycle request. Creation and editing are already merged, but the close, reopen, and destructive delete operations still need an explicit maintainer decision on the shared action and safety contract before implementation.

## What This Changes

Add Telegram forum-topic create, edit, close, reopen, and delete capabilities to the shared message-tool action surface.

## Best Possible Solution

Extend the existing Telegram plugin with typed `topic-close`, `topic-reopen`, and explicitly destructive `topic-delete` actions, backed by separate transport helpers, discovery/config gates, documentation, and focused contract/runtime tests after maintainers approve the deletion safety boundary.
