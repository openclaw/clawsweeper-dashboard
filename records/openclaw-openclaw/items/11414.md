## What This Changes

Request support for Telegram forum topic lifecycle management through the message plugin: create, edit, close, reopen, and delete.

Define one typed Telegram forum-topic lifecycle surface in the shared message-action contract and Telegram plugin, then add close, reopen, and delete with aligned config, docs, tests, and live Telegram proof.

Options:

- **Add explicit lifecycle actions (recommended):** Add `topic-close`, `topic-reopen`, and `topic-delete` as distinct shared actions mapped to Telegram Bot API lifecycle calls, keeping generic message deletion separate.

- **Defer destructive operations:** Implement only non-destructive lifecycle work until maintainers approve delete semantics and proof requirements.
