## Summary

Keep this canonical feature request open: current main exposes Telegram topic creation and editing, but close, reopen, and delete remain unavailable; deletion also needs an explicit authorization and safety decision because it permanently removes the topic and all messages.

## What This Changes

Requests full Telegram forum topic lifecycle management through the message tool, including create, edit, close, reopen, and delete actions.

## Best Possible Solution

Add distinct topic-close and topic-reopen actions in the Telegram plugin, and expose topic-delete only through a separately named, default-off destructive-action control with explicit authorization, documentation, and live Telegram proof.

- **Keep create and edit only:** Retain the current surface and decline agent-controlled topic archival or deletion.
