Keep open. Current main and the latest release still expose Telegram forum-topic create/edit only; close, reopen, and delete remain missing, and the deletion-only related PR was closed unmerged rather than becoming a canonical fix.

## What This Changes

The issue requests Telegram forum topic create, edit, close, reopen, and delete operations through the message plugin.

## Best Possible Solution

Define one typed Telegram forum-topic lifecycle surface in the shared message-action contract and Telegram plugin, then add close, reopen, and delete with aligned discovery, runtime dispatch, config, docs, focused tests, and live Telegram proof.

Options:

- **Add explicit lifecycle actions (recommended):** Add topic-close, topic-reopen, and topic-delete as distinct shared actions mapped to Telegram Bot API lifecycle calls, keeping generic message deletion separate.
- **Overload generic delete:** Route delete to message deletion or forum-topic deletion by supplied IDs, accepting higher compatibility and user-confusion risk from one overloaded action.
- **Defer destructive operations:** Keep create/edit only until maintainers approve delete semantics and proof requirements for forum-topic lifecycle management.
