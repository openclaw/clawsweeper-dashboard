## Summary

Current main and the latest release still support only Telegram forum topic creation and editing through the message tool; close, reopen, and delete remain meaningful missing capabilities. Keep this canonical feature request open for a maintainer decision because Telegram deletion permanently removes the topic and its messages and uses a distinct administrator permission, so it should not automatically inherit the existing default-enabled topic-action model.

## What This Changes

Add Telegram forum topic close, reopen, and delete actions alongside the message tool’s existing create and edit support.

## Best Possible Solution

Keep one canonical Telegram-plugin lifecycle design, add reversible close and reopen under topic management, and expose permanent deletion only through a separately named, explicit capability gate with clear all-messages deletion wording and focused live Telegram proof.

## Solution Assessment
