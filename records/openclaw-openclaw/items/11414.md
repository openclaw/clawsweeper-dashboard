## Summary

Keep this canonical feature request open. Current main and v2026.6.11 still expose Telegram forum-topic creation and editing but not close, reopen, or delete; permanent deletion has a distinct permission and safety boundary that needs maintainer-approved action naming and gating.

## What This Changes

Add Telegram forum-topic create, edit, close, reopen, and delete operations to the message tool.

## Best Possible Solution

Add explicit `topic-close`, `topic-reopen`, and `topic-delete` actions in the Telegram plugin, keep permanent deletion separately and default-off gated with its `can_delete_messages` requirement, and align discovery, dispatch, transport exports, config schema, docs, focused tests, and real Telegram proof.
