## Summary

Keep open. Current main and the latest release still expose Telegram forum-topic create/edit only; close, reopen, and delete remain missing, and the closed deletion-only pull request is not a viable implementation path.

## What This Changes

Request support for Telegram forum topic create, edit, close, reopen, and delete lifecycle actions through the message plugin.

## Best Possible Solution

Define one explicit typed Telegram forum-topic lifecycle surface in the shared message-action contract and Telegram plugin, then add close, reopen, and delete with aligned config, docs, tests, and live Telegram proof.

Options:

- **Add explicit topic lifecycle actions (recommended):** Add `topic-close`, `topic-reopen`, and `topic-delete` as distinct shared actions mapped to Telegram Bot API lifecycle calls, keeping generic message delete separate.

- **Defer destructive topic operations:** Implement only non-destructive lifecycle actions until maintainers approve delete semantics and proof requirements.
