## Summary

Keep open: current main implements important direct-invoke slices, but the umbrella still covers high-risk exec, filesystem, session, generic CLI/slash, and startup-readiness decisions that are not safely resolved by the shipped code.

## What This Changes

## Best Possible Solution

Keep this as the canonical umbrella while maintainers land, narrow, or reject each remaining direct-invoke surface behind explicit Gateway auth, owner identity, tool policy, audit, docs, and upgrade-safety gates.
