## Summary

Keep open: current main and v2026.6.11 already ship the HTTP, RPC, SDK, and command-cron parts of direct invocation, but the broader request still includes high-risk exec, host-filesystem, slash-command, CLI, session, and startup-readiness surfaces that need maintainer security and product direction.

## What This Changes

The issue requests a way to invoke explicit OpenClaw tools from chat/slash commands, CLI, and cron without an LLM turn.

## Best Possible Solution

Keep this as the canonical umbrella while maintainers land, narrow, or reject each remaining direct-invoke surface behind explicit Gateway auth, owner identity, policy, audit, docs, and upgrade-safety gates.
