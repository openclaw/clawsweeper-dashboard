## Summary

Keep open: current main and v2026.6.11 cover important direct-invoke slices, but the umbrella still includes high-risk exec, host-filesystem, session, generic slash-command, CLI, and startup-readiness surfaces that need maintainer security and product direction.

## What This Changes

The issue requests a direct tool invocation mode for explicit tool calls from chat or slash commands, CLI, and cron without a model round trip.

## Best Possible Solution

Keep this as the canonical umbrella while maintainers land, narrow, or reject each remaining direct-invoke surface behind explicit Gateway auth, owner identity, policy, audit, docs, and upgrade-safety gates.
