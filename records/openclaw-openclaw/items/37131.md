## Summary

Keep open: current main and v2026.6.11 already cover HTTP `/tools/invoke`, SDK/RPC `tools.invoke`, command cron jobs, and skill-owned direct slash dispatch, but the broader request still has unresolved host-filesystem, exec/session/control-plane, generic slash-command, CLI, and startup-readiness decisions.

## What This Changes

The issue requests direct invocation of OpenClaw tools from chat, slash commands, CLI, cron payloads, and API surfaces without an LLM round trip.

## Best Possible Solution

Keep this as the canonical umbrella while maintainers land, narrow, or reject each remaining direct-invoke surface behind explicit Gateway auth, owner identity, policy, audit, docs, upgrade-safety, and real behavior proof.
