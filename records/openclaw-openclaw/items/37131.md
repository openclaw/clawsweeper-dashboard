## Summary

Keep open: current main and v2026.6.11 already ship the HTTP, RPC, SDK, and command-cron direct-invocation slices, but the broader request still covers unresolved host-filesystem, exec/session, slash-command, CLI, and startup-readiness surfaces that need maintainer security and product direction.

## What This Changes

Request to invoke explicit OpenClaw tool calls from chat, slash/CLI, or cron inputs without routing through an LLM turn.

## Best Possible Solution

Keep this as the canonical umbrella while maintainers land, narrow, or reject each remaining direct-invoke surface behind explicit Gateway auth, owner identity, policy, audit, docs, and upgrade-safety gates.
