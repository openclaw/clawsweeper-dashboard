## Summary

Keep open: current main and v2026.6.11 cover HTTP/RPC/SDK direct invoke plus command cron, but host-filesystem tools, exec-class tools, slash/CLI dispatch, generic cron tool-call payloads, and startup-readiness behavior remain active product and security-boundary decisions.

## What This Changes

The issue requests a supported way to invoke OpenClaw tools directly without routing each call through an LLM turn.

## Best Possible Solution

Maintain the current HTTP/RPC/SDK direct-invoke foundation, then land or reject each remaining privileged surface as a narrow, documented, owner-gated security decision with upgrade proof.
