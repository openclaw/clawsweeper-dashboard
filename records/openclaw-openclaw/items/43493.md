Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: The editor only offers Text and Image and then writes that exact selection into `result.input`. Current config accepts audio and video model inputs, so accepting this prompt on an existing configured model with those values silently removes valid metadata.
  - confidence: 0.93
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: The prompt labels `__auto` as provider inheritance, but selecting it only omits `updated.api`; the final merge keeps any existing `entry.model.api`. Users therefore cannot use this editor to return a model to provider inheritance, or the label should say it keeps the current override.
  - confidence: 0.88
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is enabled, this rebuilds `cost` from only flat input/output/cache fields. Existing configured models can carry `cost.tieredPricing`, so walking through the editor can erase tiered rates and change cost reporting.
  - confidence: 0.9
