## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: This prompt only offers `text` and `image`, then saves the returned selection over `entry.model.input`. If an existing custom model has another configured modality or forward-compatible value, opening the editor and accepting defaults drops that metadata from `models.providers.*.models[]`; preserve uneditable existing values or expose the full supported set.
  - confidence: 0.88
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting `Auto (inherit from provider)` leaves `result.api` unset, but the final merge spreads over `entry.model`, so an existing model-level `api` override remains. The saved config continues overriding the provider while the UI says it inherits; either delete the override for Auto or label this as keeping the current adapter.
  - confidence: 0.9
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When pricing is configured, this replaces `cost` with only the four flat fields. Current model metadata can carry `cost.tieredPricing`, so editing flat rates through the wizard silently discards tiered pricing data and can degrade cost reporting; preserve the existing tiered pricing unless the UI explicitly edits it.
  - confidence: 0.86
