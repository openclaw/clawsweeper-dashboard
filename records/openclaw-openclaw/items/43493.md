  - body: The new prompt only offers Text/Image and then writes that choice back to `input`, so accepting the prompt on a model already configured with valid `audio` or `video` input will erase that metadata even though current config types and schema allow it.
  - confidence: 0.9

  - body: The Auto option says it will inherit from the provider, but omitting `updated.api` means the later merge keeps any existing model-level `api` override, so the stored config can continue using the old adapter while the prompt reports Auto.
  - confidence: 0.87

  - body: Rebuilding `result.cost` from only the flat token fields drops an existing `tieredPricing` block, which is part of the current model cost config and can change downstream usage or cost reporting after a metadata edit.
  - confidence: 0.86
