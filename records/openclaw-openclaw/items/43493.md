Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:145-149`
  - body: The editor only offers `text` and `image`, then saves that returned array over the existing model entry. Current model config accepts `audio` and `video`, so editing metadata for a custom model that already has either modality will silently remove it from `models.providers.*.models[]`.
  - confidence: 0.9
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting `Auto (inherit from provider)` leaves `result.api` unset, but the later merge keeps `entry.model.api` when it already exists. That means the prompt says provider inheritance while preserving a model-level adapter override, so users cannot actually clear the override through this flow.
  - confidence: 0.88
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is enabled, this creates a fresh flat cost object and replaces the existing `cost` value. Any existing `cost.tieredPricing` metadata is dropped, changing cost accounting for custom models that use tiered rates.
  - confidence: 0.86
