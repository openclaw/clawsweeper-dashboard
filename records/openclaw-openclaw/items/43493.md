- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: `ModelDefinitionConfig.input` currently allows `audio` and `video`, but this prompt only offers Text/Image and then writes the returned selection over the existing model.   - confidence: 0.9

  - body: The menu says Auto inherits from the provider, but choosing it leaves `result.api` unset and the later merge keeps any existing `entry.model.api`. Users cannot actually return a model to provider inheritance through this option, so provider routing may stay pinned to the old adapter.
  - confidence: 0.86
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is accepted, this block replaces the whole `cost` object with only flat fields. Existing custom models can contain `cost.tieredPricing`, so walking through the prompt can silently drop tiered pricing and change usage/cost calculations.
  - confidence: 0.82
