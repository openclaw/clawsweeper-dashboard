## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:149`
  - body: This prompt only offers `text` and `image`, then always writes `result.input` back over the existing model entry. Current config accepts `audio` and `video`, so editing metadata for a model that already declares those modalities will silently drop them.
  - confidence: 0.93
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Choosing `Auto (inherit from provider)` leaves `result.api` unset, and the later merge preserves any existing `entry.model.api`. That means the UI says the model will inherit from the provider while the saved config can still force the old model-level adapter.
  - confidence: 0.9
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is enabled, this replaces the entire `cost` object with flat fields only. Existing `cost.tieredPricing` is valid current metadata and is used by cost calculation, so accepting the prompt can silently switch a model from tiered to flat pricing.
  - confidence: 0.91
