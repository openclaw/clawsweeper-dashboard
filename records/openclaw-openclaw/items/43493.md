## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Preserve configured media input modalities:** `src/commands/model-metadata.ts:149`
  - body: `ModelDefinitionConfig.input` can include `audio` and `video`, but this prompt only offers text/image and then writes the returned list back over the model. Editing metadata for a custom model that already has audio/video input can narrow the config and stop those inputs from routing; preserve existing modalities the prompt does not edit or include the full supported set.
  - confidence: 0.9
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:131-133`
  - body: The option says `Auto (inherit from provider)`, but when selected `result.api` is omitted and the later `{ ...entry.model, ...updated }` merge keeps any existing model-level `api`. Users therefore cannot clear an override through the new wizard; either delete the model `api` when Auto is selected or label the option as keeping the current adapter.
  - confidence: 0.88
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When a model has `cost.tieredPricing`, choosing to configure pricing rebuilds `cost` with only flat input/output/cache fields. That silently drops tiered pricing metadata used by configured catalogs, so merge the existing `tieredPricing` back unless the flow intentionally edits or removes it.
  - confidence: 0.87
