Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: This prompt offers only `text` and `image`, then writes that selection back over `entry.model.input`. Current main accepts `audio` and `video` in model config, so editing metadata for a model that already declares those modalities can silently remove supported input metadata.
  - confidence: 0.93
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: The option says Auto will inherit from the provider, but choosing it leaves `result.api` unset and the later merge preserves any existing model-level `api`. Users therefore cannot clear an override through the prompt, or the prompt should say it keeps the current model adapter.
  - confidence: 0.9
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is enabled, this replaces the whole `cost` object with flat rates and drops any existing `cost.tieredPricing`. Current main accepts tiered pricing and uses it for usage-cost estimation, so the editor can degrade configured cost reporting.
  - confidence: 0.92
