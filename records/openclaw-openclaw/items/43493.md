Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: The prompt only offers `text` and `image`, then writes `result.input` over the existing model. Current model config supports `audio` and `video`, so editing any metadata on a model that already has those modalities silently removes capabilities the wizard cannot display or restore.
  - confidence: 0.96
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: `Auto (inherit from provider)` leaves `result.api` unset, and the final `{ ...entry.model, ...updated }` merge preserves an existing model-level API override. Since runtime inheritance only happens when `modelDef.api` is absent, the saved config does not match the selected UI state.
  - confidence: 0.93
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is enabled, the wizard replaces `cost` with flat rates only. Current config supports `cost.tieredPricing` and usage calculation prefers it, so this can silently remove existing tiered pricing from custom model metadata.
  - confidence: 0.94
