Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: The wizard only offers `text` and `image` and then overwrites `input` with that narrower selection, but model config supports `audio` and `video` too.   - confidence: 0.92
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting `Auto (inherit from provider)` leaves `result.api` unset, but the merge keeps `entry.model.api`, so users cannot clear an existing model-level adapter through this prompt. Either clear the override when Auto is chosen or label the option as keeping the current adapter.
  - confidence: 0.89
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:189-215`
  - body: When the user edits pricing, this branch replaces the whole `cost` object with flat rates and drops any existing `cost.tieredPricing`, which current cost estimation consumes. Preserve existing tiers when editing flat fields or add an explicit tier-aware edit or clear path.
  - confidence: 0.88
