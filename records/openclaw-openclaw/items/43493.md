## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: Existing model configs can include `audio` and `video`, but this multiselect only offers `text` and `image` and then writes `result.input` back to the model. Editing any other metadata for such a model can silently drop valid modalities and change downstream capability routing.
  - confidence: 0.92
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting Auto/Inherit leaves `result.api` undefined, and the final merge preserves `entry.model.api`, so an existing model-level API override remains in effect. Either use an explicit clear/delete path for Auto or label this choice as keeping the current override when one exists.
  - confidence: 0.9
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When pricing is configured, this assignment replaces `cost` with only flat rates and drops any existing `cost.tieredPricing`. Those tiers are part of the current model config contract and are used by cost reporting, so the editor should preserve them unless it explicitly supports editing or clearing them.
  - confidence: 0.88
