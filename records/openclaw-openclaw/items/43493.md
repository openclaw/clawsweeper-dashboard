Full review comments:

- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: `ModelDefinitionConfig.input` and the schema accept `audio` and `video`, but this prompt only offers `text` and `image` before writing `result.input` over the model entry. Editing an existing custom model with `audio` or `video` will silently remove accepted metadata, so preserve unknown/current selections or expose the full supported set.
  - confidence: 0.93
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting Auto leaves `result.api` undefined, and the later merge spreads `entry.model` before `updated`, so an existing model-level `api` override is retained. The UI says Auto inherits from the provider, but it cannot clear the override; either delete the model override for Auto or label it as keeping the current value.
  - confidence: 0.9
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When an existing cost object has `tieredPricing`, accepting the default pricing editor path replaces it with only flat `input`/`output`/cache fields. That drops pricing metadata used by cost reporting, so keep `tieredPricing` unless the user explicitly removes it and add a regression test.
  - confidence: 0.89
