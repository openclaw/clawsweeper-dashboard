- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: `ModelDefinitionConfig.input` now accepts `audio` and `video`, but this prompt only offers `text` and `image` and then writes that selected array back over the existing model.   - confidence: 0.91
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting `Auto (inherit from provider)` leaves `result.api` unset, and the later merge preserves `entry.model.api`, so users cannot actually return to provider inheritance through this wizard. Either remove the existing model-level override when Auto is selected or label the option as keeping the current override.
  - confidence: 0.89
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When token pricing is configured, this reconstructs `cost` with only flat rates, dropping any existing `tieredPricing`. Current usage-cost calculation prefers `tieredPricing` when present, so a metadata edit can silently change cost estimates for models with tiered pricing.
  - confidence: 0.9
