- **[P1] Preserve all configured input modalities:** `src/commands/model-metadata.ts:140-149`
  - body: The metadata editor only offers `text` and `image`, then writes that returned list over the existing model `input`. Current model config also supports `audio` and `video`, so editing an existing custom model with those modalities silently removes valid routing metadata.
  - confidence: 0.9
- **[P2] Make Auto clear or relabel the API override:** `src/commands/model-metadata.ts:122-133`
  - body: Selecting `Auto (inherit from provider)` omits `result.api`, but the later merge spreads the existing model first, so an existing model-level `api` override remains. Users cannot actually clear the override through the prompt, and the saved routing state contradicts the UI label.
  - confidence: 0.88
- **[P2] Preserve tiered pricing when editing cost:** `src/commands/model-metadata.ts:210-215`
  - body: When cost editing is enabled, the new cost object only keeps the flat rates and drops any existing `cost.tieredPricing`. Current usage-cost code consumes tiered pricing, so accepting the prompt defaults can silently change cost reporting for models that already use tiers.
  - confidence: 0.9
