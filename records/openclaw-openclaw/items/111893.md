## What This Changes

This PR makes Control UI session navigation update the selected agent consistently when a user opens named-agent, default-agent, global, or unknown sessions.

## System Context

Control UI session-navigation entry points receive a session key, update the gateway route, and render the active chat plus selected-agent chip. The new shared synchronization step resolves the session key to an agent when appropriate so the sidebar selection and routed chat remain consistent.
