The branch centralizes Control UI session-to-agent synchronization so sidebar, command-palette, and active-chat navigation update the visible agent picker for named and default-agent sessions while preserving global and unknown session scope.

## System Context

The Control UI turns a session key from sidebar, command-palette, or chat-pane navigation into both a chat route and an active agent selection. This change keeps those two UI state outputs synchronized so the agent picker reflects the session that the Gateway-backed chat view opens.
