## What This Changes

This PR centralizes Control UI session-to-agent synchronization so sidebar, command-palette, and active-chat navigation select the agent that owns the opened session without changing global or unknown-session scope behavior.

## System Context

Control UI navigation receives a session key from the sidebar, command palette, or chat route and uses it to select a conversation through the Gateway. The selected-agent chip and scope state must follow that same session identity so the sidebar remains consistent with the conversation shown next.
