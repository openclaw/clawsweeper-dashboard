## What This Changes

Provider-prefixed Gemini 2.x model ids should be classified like bare Gemini 2.x ids so image tool results use the separate image-turn fallback instead of `functionResponse.parts`.

## Best Possible Solution

Land a reviewed PR that makes the Gemini major-version check prefix/segment-aware in both Google converter paths and proves prefixed Gemini 2.x image tool results use separate image turns.
