## What This Changes

Repair Slack Socket Mode so a transport that stops delivering events can be detected, logged, and recovered without manually restarting OpenClaw.

## System Context

The Slack plugin receives Socket Mode WebSocket traffic and publishes channel health to the gateway. Its reconnect supervisor waits for a disconnect signal; gateway health then uses reported transport activity to decide whether to restart a stale channel.

## Best Possible Solution

Land a narrowly tested Slack-plugin repair that records genuine transport activity separately from application events, bounds the event-only waiter, and proves that quiet keepalive traffic remains healthy while a stale transport recovers.
