## Summary

Keep open: the July 11 rewrite addresses the repeated bootstrap loop, but it introduces full-config serialization and hashing on the unresolved outbound hot path, and the posted live proof covers an earlier implementation rather than this head.

## What This Changes

The PR suppresses repeated failed outbound channel bootstrap attempts per configuration and plugin-registry generation, with tests for retry suppression and lifecycle re-arming.

## Best Possible Solution

Track attempted channels with lifecycle-owned configuration identity or a prepared generation key, resetting on meaningful config or registry lifecycle changes without serializing and hashing the full configuration during delivery.
