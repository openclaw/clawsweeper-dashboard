## Summary

This PR is still addressing a real heartbeat latency regression and the prior per-agent pre-activation finding has been fixed, but it is not merge-ready because `target: "last"` plugin routes can still lose the wake-time bootstrap path and the PR still lacks real gateway behavior proof.

## What This Changes

The branch pre-activates configured heartbeat channel plugins at gateway startup, adds an `allowBundledFallback` resolver option, disables heartbeat wake-path bootstrap/bundled fallback, and updates outbound heartbeat tests.

## Best Possible Solution

Keep bootstrap off the repeated wake loop, but preserve external plugin heartbeat delivery for explicit config, per-agent overrides, session-derived `target: "last"` routes, and reload-updated targets, then require focused regression coverage plus redacted real gateway proof.
