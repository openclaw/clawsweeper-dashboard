## Summary

Keep open: the PR is still a useful hot-path heartbeat fix, but the previously raised targeted-wake gap remains. A partial requested heartbeat can be preactivated before it inherits the configured recipient, then the no-bootstrap delivery resolver can miss an inactive external plugin and drop delivery.

## What This Changes
