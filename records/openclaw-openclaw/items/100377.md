## Summary

Keep this PR open: the per-agent pre-activation gap from the earlier cycle is fixed, but the current head still removes wake-time bootstrap from `target: "last"` heartbeat routes that are derived from session or turn-source state, so existing external-plugin heartbeat delivery can regress before merge.

## What This Changes

The branch adds startup pre-activation for configured heartbeat channel plugins, adds an `allowBundledFallback` resolver option, disables bootstrap and bundled fallback on heartbeat wake-path lookups, and updates outbound heartbeat tests.

## Best Possible Solution

Keep bootstrap off the repeated wake loop, but preserve external-plugin heartbeat delivery for explicit config, per-agent overrides, and session or turn-source-derived `target: "last"` routes, then add focused regression coverage plus redacted real gateway proof.
