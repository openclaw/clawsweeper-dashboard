## What This Changes

The branch extracts Chrome storage configuration reads and OpenClaw tab-group consent helpers from the browser extension’s background service worker into `modules/config.js` and `modules/tab-groups.js`.

## System Context

The browser extension background service worker reads pairing and gateway settings, manages the OpenClaw tab group that grants agent access to tabs, and serves popup and side-panel requests. This refactor keeps those configuration and consent-boundary operations available to the existing background message flow while reducing the size of the central worker file.
