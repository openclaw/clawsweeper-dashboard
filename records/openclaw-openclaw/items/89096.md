## Summary

The prior unrelated-port-owner blocker is addressed: the new guard permits a busy port only when every observed listener PID equals the current LaunchAgent PID, and otherwise fails before launchd or plist mutation. The remaining merge gate is real macOS after-fix proof on the final head; the PR body explicitly says its live transcript predates the final ownership guard.

## What This Changes

The PR makes macOS LaunchAgent restart accept a busy gateway port only when launchd confirms that the current managed PID owns every listener, with focused regressions for managed and unrelated owners.

## Best Possible Solution
