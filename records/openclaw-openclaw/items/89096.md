## Summary

Keep this PR open for maintainer review: the focused change has a credible macOS before/after proof and targeted regression coverage, but it intentionally leaves the cross-platform contract for direct `service.restart` callers unresolved.

## What This Changes

This PR removes the macOS LaunchAgent restart precondition that rejects a still-busy gateway port before `launchctl kickstart -k`, and updates launchd restart tests accordingly.

## Best Possible Solution

Keep the restart path free to delegate a managed busy listener to launchd and retain CLI health verification; define a separate cross-platform readiness contract only if direct service callers must also await a healthy replacement.
