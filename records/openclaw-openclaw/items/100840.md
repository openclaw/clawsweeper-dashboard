## Summary

The EXDEV bug remains on current main and the PR proves the successful fallback path, but direct copying into the canonical credential file can expose a partial file after interruption, causing later loads to ignore still-valid legacy credentials. The added stress test also executes synchronous calls sequentially and therefore does not test the concurrency claimed by its name and assertions.

## What This Changes

The PR adds an EXDEV copy-and-unlink fallback for Matrix legacy credential migration, one canonical regression test, and three standalone reproduction test files.

## Best Possible Solution

Copy the legacy credentials to a unique sibling temporary file in the destination directory, atomically rename that completed file into `currentPath`, then unlink the legacy source; clean up the temporary file on failure and keep returning the already-loaded legacy credentials, with focused canonical tests for success and failure boundaries.
