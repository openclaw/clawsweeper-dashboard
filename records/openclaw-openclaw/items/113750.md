## Summary

Keep this PR open: it addresses a real cron-health blind spot, but the new helper bypasses the cron state owner by reading and rewriting the cron store directly, which can race normal cron updates. It also still needs redacted after-fix behavior proof showing a detached media failure changes the originating cron record to failed.

## What This Changes

The branch records a failure on the cron run that initiated detached media generation when the later background media task throws, and adds regression coverage for that propagation path.

## System Context

Detached media-generation tasks run after an agent request has returned; cron uses the originating request session key to track scheduled-run health. This change connects a later task failure back to the cron job state that health and heartbeat checks consume.
