## What This Changes

This PR records a detached media-generation failure on the cron run that initiated it, so cron health and heartbeat auditing no longer leave that completed run green after a later provider error.

## System Context

Detached media generation is started from an agent turn and completes after the initiating cron invocation may have returned. The patch bridges that late task outcome to the Gateway-owned cron service, which persists job health state and emits cron-run completion information.
