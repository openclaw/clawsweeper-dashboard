## What This Changes

The PR makes a detached media-generation error mark the cron run that launched it as failed, so cron health and heartbeat reporting no longer remain green after a provider failure.

## System Context

A cron run can start an agent turn that schedules media generation in the background. When that later task fails, the gateway cron service owns the durable run state consumed by cron health checks and heartbeat audits.
