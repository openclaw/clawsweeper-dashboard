## What This Changes

The branch propagates detached media-generation failures back to the cron run that initiated them, updating cron health while preserving newer run state.

## System Context

A cron run can launch a media-generation task whose completion happens later than the initiating agent turn. The Gateway-owned cron service persists run health, and this change lets the detached task report its failure to that owner for audits and heartbeat handling.
