## Summary

Keep open: the rebuilt PR fixes the earlier missing-prefix-state blocker, but the new partial JSONL path still bypasses the full reader's legacy normalization and can run migration on an incomplete head/tail sample, so it is not safe to merge yet.

## What This Changes

The PR adds a successor-rotation-specific transcript reader that samples the session header and recent tail, falls back when preservation-sensitive prefix rows are detected, and adds long-transcript regression tests.

## Best Possible Solution

Keep the bounded successor-rotation optimization, but make it fall back for legacy or migration-needed transcripts and ensure sampled records use the same normalization contract as the full reader before they can be trusted.
