## Summary

Keep open: this is a useful rebuilt replacement for the earlier unsafe optimization, but the new prefix completeness gate still misses preserved branch/custom-message rows, so the fast path can write a successor transcript with less state than the current full-reader rotation.

## What This Changes

The PR adds a file-backed successor-rotation transcript reader that samples a session header and recent tail, falls back to the full reader for selected prefix state rows, and adds long-transcript regression tests.

## Best Possible Solution

Keep the bounded reader, but make the completeness gate cover every successor-preserved row type or fall back to the full transcript reader whenever the prefix can contain such rows.
