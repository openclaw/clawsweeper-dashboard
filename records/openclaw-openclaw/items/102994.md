## Summary

The latest commit fixes the previously reported sibling-branch omission, but this head remains unsafe because a short sampled tail read can silently omit final transcript rows before successor rotation; the PR’s own current measurements also show no performance win.

## What This Changes

The PR adds a rotation-specific transcript reader that samples the session header and tail, scans prefix state to decide whether to fall back, and expands successor-rotation regression coverage.

## Best Possible Solution

Use one exact-range helper that loops until every requested sampled byte is read and falls back to the canonical full reader on EOF or incomplete completion; then retain this design only if differential tests prove identical successor output and fresh measurements show lower bytes read and rotation latency.
