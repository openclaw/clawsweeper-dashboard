## Summary

Keep open: current main supports direct parent/depth lineage and child discovery, but still lacks the durable root-session and chain-identity contract needed to correlate a multi-hop spawn chain. The prior implementation PR is closed and unmerged, while the merged ACP work only exposes the lineage fields that already exist.

## What This Changes

Add durable parent, root, trace, and depth metadata for spawned session chains and expose it through session APIs.

## Best Possible Solution

Define one purpose-specific spawn-chain identity contract, persist optional root and chain identifiers consistently in native and ACP spawn paths, and expose aligned fields across Gateway, agent-tool, and ACP projections with multi-hop and legacy-session coverage.
