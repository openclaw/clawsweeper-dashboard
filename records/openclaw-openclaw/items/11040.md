## Summary

Keep open: current main and the latest release still only expose partial spawned-session lineage, while persisted rootSessionKey and a durable session-chain traceId remain missing and need maintainer API direction.

## What This Changes

The issue requests optional persisted parent/root/trace/depth metadata for spawned session chains and exposure through session list APIs.

## Best Possible Solution

Approve a focused additive core session-chain contract that persists optional rootSessionKey and traceId, derives them for native and ACP child sessions, exposes them through Gateway and agent list projections, documents the fields, and leaves traversal/UI work as follow-ups.
