## Summary

Keep open: current main and v2026.6.11 still provide only partial spawned-session lineage; the requested persisted root session key and durable session-chain trace contract are absent from the core session model, Gateway protocol/list projections, agent-facing `sessions_list` rows, and native/ACP spawn writes.

## What This Changes

The issue requests first-class persisted session/task chain metadata for spawned sessions: parent, root, trace, and depth fields exposed through session APIs.

## Best Possible Solution

Decide the public spawned-session chain contract first, then land a focused additive implementation that persists root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
