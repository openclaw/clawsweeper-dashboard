## Summary

Keep open: current main and the latest release still have only partial spawned-session lineage, while the requested persisted root session key and durable session-chain trace contract remain absent.

## What This Changes

Request first-class parent/root/trace/depth metadata for spawned sessions so session APIs can reconstruct multi-hop subagent execution chains.

## Best Possible Solution

Decide the public spawned-session chain contract first, then land a focused additive implementation that persists root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
