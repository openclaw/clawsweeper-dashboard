## Summary

Keep open: current main and v2026.6.11 still only provide partial spawned-session lineage, while the requested persisted root/root-chain trace contract remains absent and needs maintainer API direction before another fix PR.

## What This Changes

The issue requests first-class parent, root, trace, and depth metadata for spawned session/task chains so tools can reconstruct subagent execution DAGs from session APIs.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
