## Summary

Keep open: current main and v2026.6.11 still provide only partial spawned-session lineage; the requested persisted root session key and durable session-chain trace contract remain absent and need maintainer API direction.

## What This Changes

Request to add first-class persisted parent/root/trace/depth metadata for spawned sessions and expose it through Gateway and agent session-list APIs.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
