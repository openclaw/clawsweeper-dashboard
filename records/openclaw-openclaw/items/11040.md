## Summary

Keep open: current main and v2026.6.11 still provide only partial spawned-session lineage, while the requested persisted rootSessionKey and durable session-chain traceId contract remains missing and needs maintainer API/product direction.

## What This Changes

The issue requests first-class persisted session-chain metadata, including parent/root/trace/depth fields and list output exposure for spawned-session DAG reconstruction.

## Best Possible Solution

Approve a focused additive core session-chain contract that persists optional rootSessionKey and a clearly named chain trace id, derives them for native and ACP child sessions, exposes them through Gateway and agent list projections, and leaves traversal/UI work as follow-ups.
