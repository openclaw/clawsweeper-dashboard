## Summary

Keep open: current main and v2026.6.11 still provide only partial spawned-session lineage, while the requested durable root session key and session-chain trace contract remain absent from the persistent session model, Gateway protocol/projections, agent-facing session-list rows, and native/ACP spawn writes.

## What This Changes

The issue requests first-class parent/root/trace/depth metadata for spawned session chains so clients can reconstruct subagent execution DAGs from session APIs.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
