## Summary

Keep open: current main and v2026.6.11 still only expose partial spawned-session lineage, while the requested persisted rootSessionKey and durable session-chain traceId contract remains missing and needs maintainer API/product direction.

## What This Changes

The issue requests first-class spawned-session chain metadata with parent, root, trace, and depth fields persisted and exposed through session APIs.

## Best Possible Solution

Approve a focused additive core session-chain contract that persists optional rootSessionKey and traceId, derives them for native and ACP child sessions, exposes them through Gateway and agent list projections, and leaves traversal/UI work as follow-ups.
