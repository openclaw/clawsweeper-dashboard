## Summary

Keep open: current main and the latest release still provide only partial spawned-session lineage; the requested durable root session key and session-chain trace contract remain absent and need maintainer API direction before another implementation attempt.

## What This Changes

Request to add first-class spawned-session chain metadata, including parent, root, trace, and depth fields, to persisted sessions, spawn writes, and session listing APIs.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
