## Summary

Keep open: current main and the latest stable release still only provide partial spawned-session lineage. The requested durable rootSessionKey and session-chain traceId contract is absent from the persisted session model, Gateway protocol/projections, agent-facing sessions_list rows, and native/ACP spawn writes.

## What This Changes

Add first-class persisted session/task-chain metadata so spawned-session APIs and tools can expose parent, root, trace, and depth for DAG reconstruction.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
