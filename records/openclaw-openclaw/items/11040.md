## What This Changes

Add canonical parent/root/trace/depth metadata for spawned sessions and expose it through session-listing surfaces so callers can reconstruct multi-hop execution chains.

## Best Possible Solution

Choose one canonical owner and identifier contract for session-chain lineage, then add optional persisted root/trace metadata consistently across native and ACP spawning, gateway projections, and agent-facing listings with multi-hop regression coverage.
