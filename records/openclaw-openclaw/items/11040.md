## Summary

Keep open: current main still provides only partial spawned-session lineage. The persistent model, Gateway protocol/projections, agent-facing `sessions_list` output, and native/ACP spawn writes still lack the requested durable `rootSessionKey` and session-chain `traceId` contract, so this needs maintainer API direction before another fix attempt.

## What This Changes

Add first-class spawned-session chain metadata so parent, root, trace, and depth can be reconstructed from session APIs without external loggers.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
