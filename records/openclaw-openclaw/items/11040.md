## Summary

Keep open: current main still has only partial spawned-session lineage and does not implement the requested first-class root session key or durable session-chain trace contract.

## What This Changes

The issue requests optional parent/root/trace/depth metadata for spawned session chains so tools can reconstruct multi-hop subagent DAGs.

## Best Possible Solution

Decide the public spawn-chain contract first, then land a focused additive implementation that persists root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
