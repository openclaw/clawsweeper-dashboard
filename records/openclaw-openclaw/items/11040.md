## Summary

Keep open: current main and v2026.6.11 still only provide partial spawned-session lineage, while the requested persisted root/root trace contract remains absent and the issue already has a maintainer-review/product-decision signal.

## What This Changes

Request to add first-class session/task chain metadata for spawned sessions, including parent/root/trace/depth fields in persisted sessions, spawn writes, and session listing outputs.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
