## Summary

Keep open: current main and v2026.6.11 still only provide partial spawned-session lineage; the requested persisted root session key and durable session-chain trace contract remain absent and need maintainer API direction before another fix attempt.

## What This Changes

The issue requests first-class parent/root/trace/depth metadata for spawned session chains in persisted session entries, spawn writes, Gateway rows, and agent-facing session list output.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
