## Summary

Keep open: current main and v2026.6.11 still provide only partial spawned-session lineage; the requested persisted root session key and durable session-chain trace contract are absent and need maintainer API direction before another implementation attempt.

## What This Changes

Requested first-class spawned session/task chain metadata across persisted sessions, native and ACP spawn writes, and Gateway/tool session-list outputs.

## Best Possible Solution

Decide the public spawned-session chain contract, then land a focused additive implementation that persists optional root/trace metadata, derives it in native and ACP spawn paths, exposes it in Gateway and agent session-list projections, and documents/tests multi-hop reconstruction.
