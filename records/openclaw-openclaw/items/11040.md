## Summary

Keep open: current main and the latest release still provide only partial spawned-session lineage, while the requested persisted rootSessionKey and durable session-chain traceId contract is still missing and needs maintainer API direction.

## What This Changes

The issue requests first-class spawned-session chain metadata across persisted sessions, spawn write paths, Gateway listings, and agent-facing session list output.

## Best Possible Solution

Approve a focused additive core session-chain contract that persists optional rootSessionKey and traceId, derives them for native and ACP child sessions, exposes them through Gateway and agent list projections, documents the fields, and leaves traversal/UI work as follow-ups.
