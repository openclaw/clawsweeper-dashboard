## Summary

Keep open: current main has adjacent batch media transcription and realtime Talk transcription relay paths, but the requested native custom ASR/STT endpoint setting and provider seam for platform voice workflows is still missing and needs maintainer product/security direction.

## What This Changes

Request to let users configure an opt-in custom ASR/STT server endpoint, model, language, and auth instead of always using platform speech recognition for voice input.

## Best Possible Solution

Define a maintainer-approved native STT provider boundary that keeps platform speech as the default, starts with a narrow macOS PTT slice, and reuses Gateway/provider contracts without forwarding unrelated credentials.
