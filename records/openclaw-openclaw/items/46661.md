## Summary

Keep open: current main and v2026.6.11 still keep native companion-app voice recognition on platform speech paths, while the OpenAI-compatible/custom audio transcription support exists in separate media/Talk provider surfaces. This is a valid feature request, but it needs maintainer product and security design before implementation.

## What This Changes

Request to add a configurable custom ASR/STT endpoint for voice input, including endpoint URL, optional auth, model, language hint, and fallback behavior while preserving built-in Apple/platform speech by default.

## Best Possible Solution

Define a maintainer-approved native STT boundary that keeps platform speech as the default, reuses tools.media.audio or Talk/realtime provider contracts where appropriate, and documents credential, network, fallback, and UI behavior before implementation.
