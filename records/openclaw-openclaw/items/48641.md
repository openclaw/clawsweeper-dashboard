## Summary

Keep open: current main and v2026.6.11 still preserve Discord account-scoped allowFrom precedence, while the closed direct PR and current docs show that a union-style repair would change the Discord DM authorization contract.

## What This Changes

The issue asks OpenClaw to stop silently dropping inbound Discord DMs from allowlisted users in multi-account allowlist configurations where outbound DMs and guild messages work.

## Best Possible Solution

Have maintainers define the Discord DM account-inheritance and multi-account ownership contract, then implement it in the Discord plugin with focused precedence tests, docs updates, and live DM proof.
