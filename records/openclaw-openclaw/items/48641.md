## What This Changes

The issue reports allowlisted inbound Discord DMs being dropped before logs or routing in a multi-account setup while outbound DMs and guild messages work.

Have maintainers define the Discord root-versus-account DM authorization contract, then implement it with focused precedence tests, docs updates, denied-DM diagnostics, and live multi-account DM proof.

Options:

- **Union Root And Account Lists:** Allow root-listed users through account DMs too, which addresses this report's proposed root cause but broadens access for narrowed accounts.
- **Require Explicit Account Lists:** Treat this as setup diagnostics and documentation work, requiring every allowed DM sender to be listed on the receiving account.
