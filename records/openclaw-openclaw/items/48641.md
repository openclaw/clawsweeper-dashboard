## What This Changes

The issue reports inbound Discord DMs from an allowlisted user being silently dropped while outbound DMs and guild channel messages still work.

## Best Possible Solution

Have maintainers define the Discord root-versus-account DM authorization contract, then implement that contract with focused precedence tests, docs, denied-DM diagnostics, and live multi-account DM proof.
