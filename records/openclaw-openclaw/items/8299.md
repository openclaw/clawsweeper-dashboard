## Summary

Keep open: current main and the latest release still lack a documented config option or public `sessions_spawn` parameter for deterministic sub-agent announce suppression. The source gap is clear, but the public tool/config shape overlaps per-channel suppression and parent-routing requests, so it needs maintainer product direction before implementation.

## What This Changes

Request a framework-level config option and/or per-spawn parameter to suppress sub-agent completion announcements without relying on `ANNOUNCE_SKIP`.

## Best Possible Solution

Keep this issue open as the canonical deterministic suppression request and design one additive announce-control surface that defaults to current behavior, supports explicit skip, composes with parent/per-channel routing, and updates config schema, tool schema, docs, and regression tests together.
