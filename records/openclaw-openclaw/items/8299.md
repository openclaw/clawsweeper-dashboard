## Summary

Keep open: current main and the latest checked release still rely on model/output-token suppression and do not expose a documented config option or public `sessions_spawn` parameter for deterministic sub-agent announce suppression.

## What This Changes

Request a config or per-spawn control to suppress sub-agent completion announces without relying on `ANNOUNCE_SKIP` or `NO_REPLY`.

## Best Possible Solution

Design one additive announce-control surface that defaults to current behavior, supports deterministic skip, composes with parent/per-channel routing, and updates config schema, tool schema, docs, and regression tests together.

Options:

- **Adopt a unified announce policy (recommended):** Add an additive policy that defaults to current behavior, supports deterministic skip, and leaves room for parent/per-channel routing without parallel controls.

- **Defer to routing design:** Keep the suppression request open but wait for broader `announceTarget` and per-channel suppression decisions before adding any public surface.
