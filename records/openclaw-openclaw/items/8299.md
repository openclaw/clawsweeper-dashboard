## Summary

Keep open: current main and v2026.6.11 still lack a documented config option or public `sessions_spawn` parameter for deterministic sub-agent announce suppression. This remains the canonical suppression request, but the public config/tool API shape needs maintainer product direction because it overlaps per-channel suppression, parent routing, and broader A2A handoff requests.

## What This Changes

The issue requests a framework-level config option or per-spawn parameter to deterministically suppress sub-agent completion announcements instead of relying on `ANNOUNCE_SKIP`.

## Best Possible Solution

Keep this issue open as the canonical deterministic suppression decision and design one additive announce-control surface that defaults to current model-driven behavior, supports explicit skip, composes with parent/per-channel routing, and updates config schema, tool schema, docs, and regression tests together.
