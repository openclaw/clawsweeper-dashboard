## Summary

Keep open: current main and the latest checked release still lack a public config option or `sessions_spawn` parameter for deterministic sub-agent announce suppression. The source gap is clear, but the final API shape needs maintainer product direction because it overlaps per-channel suppression and parent-routing requests.

## What This Changes

Request a framework-level config option or per-spawn parameter to suppress sub-agent completion announcements without relying on `ANNOUNCE_SKIP` model output.

## Best Possible Solution

Design one additive announce-control surface that defaults to current model-driven behavior, supports deterministic skip, composes with parent/per-channel routing, treats intentional suppression as successful cleanup, and updates schema, docs, and focused regression tests together.
