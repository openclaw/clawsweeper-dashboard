## Summary

Keep open: current main and the latest checked release still lack a documented config option or public `sessions_spawn` parameter for deterministic sub-agent announce suppression. This remains the canonical suppression request, but the public config/tool API shape needs maintainer product direction because it overlaps per-channel and parent-routing requests.

## What This Changes

The issue requests a framework-level config or `sessions_spawn` option to suppress sub-agent completion announcements instead of relying on the model to emit `ANNOUNCE_SKIP`.

## Best Possible Solution

Keep this issue open as the canonical deterministic suppression decision and design one additive announce-control surface that defaults to current model-driven behavior, supports explicit skip, composes with parent/per-channel routing, and updates config schema, tool schema, docs, and regression tests together.
