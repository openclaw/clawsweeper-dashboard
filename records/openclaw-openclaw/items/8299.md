## Summary

Current main and v2026.6.11 still provide no deterministic public control for suppressing sub-agent completion announces; suppression remains dependent on exact model-emitted tokens. This remains the canonical narrow request, but maintainers must choose one public policy contract before adding overlapping config, tool, routing, or channel controls.

## What This Changes

Add deterministic framework-level control to suppress sub-agent completion announcements instead of relying on model-emitted skip tokens.

## Best Possible Solution

Define one backward-compatible sub-agent completion policy, resolve it once at spawn, persist it through the lifecycle, and treat intentional skip as a successful terminal outcome across direct delivery, queueing, retries, cleanup, restart recovery, and nested completion paths.
