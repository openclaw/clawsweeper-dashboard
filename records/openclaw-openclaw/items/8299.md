## Summary

Current main mitigates the original safety concern by routing completion through a parent-review turn, but it still has no supported deterministic skip control; this remains the canonical narrow request, with maintainer direction needed for the permanent public API.

## What This Changes

Requests a config default or per-spawn parameter that deterministically suppresses sub-agent completion announcements without relying on model sentinel output.

## Best Possible Solution

Reuse the existing completion-delivery gate behind one approved policy, preserve parent-review delivery as the default, and cover deterministic skip across cleanup, nested runs, and delivery fallbacks.
