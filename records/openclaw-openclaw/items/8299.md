## Summary

Current main and v2026.6.11 still lack a supported deterministic suppression control: the public spawn schema and strict subagent config omit it, while documented suppression remains dependent on model-emitted sentinel text. This remains the canonical narrow request, but maintainers must choose the public API boundary because global config, per-channel policy, and parent-routing proposals overlap without replacing this behavior.

## What This Changes

Add a deterministic framework-level control that prevents selected sub-agent completion announcements from reaching the requester chat.

## Best Possible Solution

Define one closed, opt-in completion-delivery mode at the `sessions_spawn` boundary—keeping current behavior as the default and supporting deterministic skip—then carry that mode through persisted registry state, announce dispatch, cleanup/retry outcomes, focused tests, schema/help, and the subagent guide; consider global or per-channel defaults only after the canonical mode is stable.

- **Unified routing:** Design skip, requester delivery, and parent wake-up together with https://github.com/openclaw/openclaw/issues/27445 before exposing a public control.
