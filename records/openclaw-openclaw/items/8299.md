## Summary

Keep open: current main and the latest release still lack a documented config option or public `sessions_spawn` parameter for deterministic sub-agent announce suppression. This remains the canonical suppression request, but implementation needs maintainer API direction because it overlaps per-channel suppression and parent-routing requests.

## What This Changes

Request a deterministic framework-level way to suppress sub-agent completion announces, either through `agents.defaults.subagents` config or a public `sessions_spawn` parameter.

## Best Possible Solution

Keep this issue as the canonical deterministic suppression decision and add one additive announce-control surface that defaults to current behavior, supports explicit skip, composes with parent/per-channel routing, and updates config schema, tool schema, docs, and regression tests together.
