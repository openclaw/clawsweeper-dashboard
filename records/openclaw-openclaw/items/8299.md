Keep open: current main and the latest release still lack a documented public `sessions_spawn` parameter or `agents.defaults.subagents` config policy that deterministically suppresses sub-agent completion announces. ## What This Changes

Request a framework-level way to suppress sub-agent completion announcements, either through `agents.defaults.subagents` config or a public `sessions_spawn` parameter.

## Best Possible Solution

Add a documented, default-preserving deterministic sub-agent announce suppression policy, preferably a narrow per-spawn control first, with config or broader routing only after maintainers decide how it coordinates with https://github.com/openclaw/openclaw/issues/13911 and https://github.com/openclaw/openclaw/issues/27445.
