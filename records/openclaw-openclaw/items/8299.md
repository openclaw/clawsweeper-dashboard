## Summary

The completed review updated July 17, 2026 found that current main routes native sub-agent completions through the requester agent but still lacks a deterministic public suppression contract. The remaining API/config direction needs maintainer confirmation, so this issue should stay open.

## What This Changes

Requests a deterministic framework-level option or `sessions_spawn` argument that prevents sub-agent completion announcements from reaching the requester without relying on `ANNOUNCE_SKIP`.

## Best Possible Solution

Add one explicit, documented per-spawn completion-delivery mode only after maintainers choose its stable contract; retain current behavior as the default, thread it through every completion path, and cover suppression, cleanup, retry, and requester-agent handoff with regression tests before considering any persistent default.
