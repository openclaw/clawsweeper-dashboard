## What This Changes

Request a deterministic configuration or `sessions_spawn` control that suppresses sub-agent completion announcements instead of relying on the child model to emit `ANNOUNCE_SKIP` or `NO_REPLY`.

## System Context

A parent agent uses `sessions_spawn` to start a sub-agent, then the sub-agent completion lifecycle prepares an announce and can deliver it to the requester channel. This request changes the policy decision between completion and delivery so the parent or configured default can suppress that external announce deterministically.

  D -->|suppress| F[Successful cleanup]
  E --> G[Requester channel]
  E --> H[Parent session routing]

## Best Possible Solution

Define one typed per-spawn completion-routing policy that preserves the existing default and includes an explicit skip mode; add a persistent default only if maintainers confirm that it solves a distinct supported workflow. Thread the resolved policy through the sub-agent lifecycle before delivery, document the contract, and add regression coverage for delivery, deterministic skip, and cleanup.
