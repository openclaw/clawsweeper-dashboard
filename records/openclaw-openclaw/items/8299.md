## Summary

Keep open: current main and v2026.6.11 still lack a public deterministic skip control. The active routing PR only adds `channel | parent`, so it does not yet resolve this narrower suppression requirement.

## What This Changes

Add a framework-level config or per-spawn control that deterministically suppresses sub-agent completion announcements without relying on model output tokens.

## Best Possible Solution

Use one public announce disposition containing `channel`, `parent`, and `skip`; map `skip` to successful no-delivery cleanup, preserve `channel` as the default, and keep required task-completion bookkeeping independent.
