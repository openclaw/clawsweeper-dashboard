## Summary

Current main and v2026.6.11 still lack a public deterministic sub-agent announce-suppression control: the public spawn schema omits it, strict config omits it, and documented suppression remains model-token driven. This issue remains the canonical narrow request, but implementation requires maintainer API direction because a new public config/tool contract overlaps parent-routing and per-channel policy work.

## What This Changes

Add a public framework-enforced config or per-spawn control that prevents sub-agent completion announcements from reaching the requester channel.

## Best Possible Solution

Define one typed completion-destination policy at the existing spawn and registry lifecycle owner, defaulting to current channel delivery and supporting deterministic skip plus coordinated parent routing across native subagent and ACP paths.

- **Keep token convention:** Decline new public surface and retain exact model-output tokens as the only supported suppression mechanism.
