## Summary

Keep open: current main and the latest checked release still lack a documented framework-level sub-agent announce suppression control. This issue remains the canonical narrow suppression request, but the public config/tool API shape needs maintainer product direction because it overlaps per-channel and parent-routing requests.

## What This Changes

The issue requests deterministic sub-agent announce suppression through either `agents.defaults.subagents` config or a public `sessions_spawn` parameter.

## Best Possible Solution

Design one additive announce-control surface that defaults to current model-driven behavior, supports deterministic skip, composes with parent/per-channel routing, and updates config schema, tool schema, docs, and regression tests together.
