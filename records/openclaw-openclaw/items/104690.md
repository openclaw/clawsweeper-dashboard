## Summary

Keep this PR open for maintainer review. The reported Teams remove/re-add session-boundary bug has credible live proof and the patch has no concrete correctness defect in the reviewed evidence, but it introduces a public Plugin SDK lifecycle-reset contract whose ownership and long-term scope require an explicit maintainer decision before merge.

## What This Changes

The branch handles observable Microsoft Teams removal and reinstall lifecycle events by rotating matching personal-chat sessions, clearing Teams conversation references, and adding a guarded Plugin SDK session-reset helper.

## System Context

Microsoft Teams activities enter the msteams channel adapter, which resolves a personal-chat session and conversation reference before dispatching work to OpenClaw. This change treats observable uninstall, reinstall, or changed-conversation boundaries as a session lifecycle transition so the next message cannot resume the prior chat transcript.

## Best Possible Solution

Confirm that a generic, public, owner-coordinated lifecycle-reset API is the intended Plugin SDK contract; if it is not, narrow the implementation to the smallest owner-specific seam that still lets the Teams plugin reset only observable personal-chat boundaries.
