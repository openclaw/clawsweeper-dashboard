## What This Changes

The branch handles observable Microsoft Teams app-removal and reinstall events by clearing affected conversation references and rotating matching personal-chat sessions so later messages start with fresh context.

## System Context

Microsoft Teams activities enter the bundled channel plugin, which resolves a personal-chat route and session before agent work begins. The new lifecycle path handles removal/reinstall signals by clearing the Teams conversation reference and asking the session owner to replace the persisted session entry before the next inbound message.
