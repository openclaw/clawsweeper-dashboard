## Summary

The live Teams proof is strong for ordinary sessions, but these owner-boundary defects block merge.

## Best Possible Solution

Expose a host-owned lifecycle-reset dispatcher that discovers and coordinates the registered harness owner while an authoritative exact-row reservation blocks competing writers; storage, transcript archival, admissions, and physical ownership must either all rotate or all remain unchanged.
