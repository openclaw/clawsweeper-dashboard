## Summary

The prior assertion-type finding is fixed, but the intended privacy reset still fails for locked harness-owned sessions because Microsoft Teams invokes the unscoped lifecycle helper without a physical-owner release path. Exact-head CI is otherwise nearly complete and green, so the remaining blocker is the cross-plugin ownership contract rather than routine validation.

## What This Changes

The PR dispatches Microsoft Teams removal and reinstall lifecycle signals, rotates matching personal-chat sessions through a new Plugin SDK lifecycle-reset API, and adds documentation and regression coverage for session, transcript, and harness-owner handling.

## Best Possible Solution

Expose a narrow core-owned lifecycle-reset orchestration seam that resolves the registered harness owner, invokes its reset hook under the existing lifecycle fence, and only then rotates the persisted session and transcript; Microsoft Teams should call that seam and cover both ordinary and locked harness-owned sessions.
