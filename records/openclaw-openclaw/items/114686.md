## Summary

The PR appears to correctly close two concrete Workboard dashboard bugs: it carries the board/widget write capability to the embedded card, blocks the mutation again at its owner, and isolates pending moves from a replaced Gateway connection. No discrete patch defect was identified; because the PR has the protected `maintainer` label and its head is behind current `main`, it should remain open for explicit maintainer review of the refreshed merge result.

## What This Changes

The branch disables read-only Workboard card status controls, rejects programmatic status changes without mutation capability, and prevents old Gateway move completions from overwriting the replacement connection’s card state.

## System Context

The Control UI renders session-dashboard board widgets using a connected Gateway client. Workboard card widgets read cards and statuses through that client, optionally send a card-move RPC, and then update the visible dashboard state.
