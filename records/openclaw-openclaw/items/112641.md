## Summary

Keep this PR open. The proposed split between age-based preservation and hard-cap eviction is a focused response to the linked store-growth bug, but merge should wait for redacted after-fix real behavior proof and a refreshed review against current `main` after rebasing.

## What This Changes

The branch makes durable thread, topic, group, and channel sessions evictable oldest-first for `maxEntries` and `maxDiskBytes`, while preserving them from age-based pruning and never evicting primary, active, archived, or model-locked sessions.

## System Context

Session maintenance controls the durable conversation records that agents and channels resume between runs. Configuration supplies age, entry-count, and disk budgets; maintenance then decides which records remain in the session store and which transcripts must begin fresh on the next message.
