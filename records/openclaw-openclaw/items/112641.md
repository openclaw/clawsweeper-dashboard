## Summary

Keep this PR open for explicit session-retention direction. The branch has credible after-fix terminal proof and passes the stated checks, but it intentionally changes existing enforce-mode deployments so an over-budget maintenance pass can delete old durable thread/topic/channel transcripts; that upgrade behavior needs a session-owner decision before merge.

## What This Changes

The PR makes durable conversation entries evictable oldest-first for configured session entry-count and file-store disk caps, while retaining their exemption from age-based pruning and preserving primary, active, archived, and model-locked sessions.

## System Context

Session maintenance prunes or caps stored agent conversations after session-store writes. It receives stored session entries and runtime preserve keys, applies age and capacity rules, then leaves a bounded session store for later agent and channel conversations.
