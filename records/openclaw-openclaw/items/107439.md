## What This Changes

The PR makes Slack accounts sharing an app-level Socket Mode token reuse one Bolt connection, demultiplexes inbound events by workspace, and introduces per-account Web API clients.

## Best Possible Solution

Keep one Socket Mode connection per app token, but give Bolt a team-aware `authorize` mapping that returns each workspace account's token and bot identity, retain explicit per-account clients for non-listener work, and prove two-workspace inbound and reply delivery with redacted live evidence.
