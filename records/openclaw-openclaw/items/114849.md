## What This Changes

This PR changes `/hooks/agent` to reject unsupported `channelId` payloads with HTTP 400 and documents `channel` plus `to` as the supported way to target an agent’s final reply.

## System Context

Gateway hooks accept external HTTP payloads and normalize them into agent-run requests. When final-reply delivery is requested, the normalized target feeds the channel delivery path, so invalid targeting fields should be rejected before an agent run is dispatched.
