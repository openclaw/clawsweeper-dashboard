## Summary

Keep this open: current main and v2026.6.11 still do not expose or forward `memorySearch.local.maxThreads`, while the pinned `node-llama-cpp` API supports `getLlama({ maxThreads })`. The remaining blocker is maintainer approval for a new public local-memory config knob.

## What This Changes

Request to add an optional `memorySearch.local.maxThreads` config value for local node-llama-cpp embeddings and forward it to `getLlama`.

## Best Possible Solution

If maintainers approve the product/API direction, add a narrow optional `memorySearch.local.maxThreads` field through schema, types, help/docs, resolved memory config, llama.cpp provider options, node-llama forwarding, and focused tests.
