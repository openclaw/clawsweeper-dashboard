## Best Possible Solution

If maintainers approve the config surface, add a narrow optional `memorySearch.local.maxThreads` field through schema/types/help/docs, resolved memory config, provider option types, node-llama facade, `getLlama` forwarding, and focused tests without broadening into unrelated GPU or flash-attention tuning.
