## What This Changes

Expose configured per-agent descriptions through `agents_list` so an orchestrator can discover each available agent’s stated specialization at runtime.

## System Context

Agent definitions enter OpenClaw through the canonical configuration schema and are resolved into the agent runtime. The `agents_list` tool then returns the requester-visible roster used by orchestrators before they delegate work to sub-agents.
