## What This Changes

The issue asks OpenClaw to keep macOS Codex OAuth/keychain auth and fresh runtime launch paths working when the Gateway/runtime environment has `NODE_USE_SYSTEM_CA=1`.

## Best Possible Solution

Reproduce on macOS, then fix the narrow service/auth boundary so status, auth-list, and Codex app-server launch paths avoid the CA/keychain conflict without globally regressing launchd TLS defaults.
