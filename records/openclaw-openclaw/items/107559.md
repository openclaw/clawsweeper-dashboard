## Summary

This PR is not merge-ready: the handoff uses cross-reset `systemEvent` delivery for state tied to an earlier durable run, and the cumulative durable-runtime product and upgrade surface still needs explicit owner approval.

## What This Changes

## Best Possible Solution

Use the existing session delivery queue but bind each durable wake to the resolved session generation, suppress or explicitly re-resolve mismatches after reset, and land the durable-runtime surfaces only with owner-approved product and upgrade semantics.
