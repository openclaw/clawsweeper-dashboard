## Best Possible Solution

Resolve this through the linked candidate PR or a narrow replacement that carries existing queue wait facts through Gateway to the CLI, preserves lane ordering, and documents the busy-result contract.

Options:

- **Preserve queued execution:** Keep CLI calls waiting by default and track only diagnostic improvements, leaving the silent-exit bug to a smaller timeout/error-rendering fix.
