## Summary

The previous agent-targeting blocker is fixed, and the updated implementation appears technically sound with strong runtime evidence. This PR should remain open because it changes the default persisted-session recovery policy from semantic compaction-first to deterministic truncation-first; that compatibility tradeoff still needs explicit owner acceptance, and the public compaction documentation must be aligned before merge.

## What This Changes

The PR changes embedded-agent overflow recovery to truncate oversized or aggregate-heavy tool results before model-driven compaction, with regression coverage for retry ordering, active-session targeting, persisted-turn continuation, fallback, and compaction-budget accounting.

## Best Possible Solution

Keep the bounded truncation-first branch with full active-target scoping and compaction fallback, explicitly approve that default session-state policy, and update the compaction docs to describe the pressure-qualified recovery order.
