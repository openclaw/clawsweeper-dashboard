## Summary

Keep this PR open: current main still performs model-driven overflow compaction before persistent tool-result truncation, while the branch supplies a focused, proven fix and resolves the previous agent-identity finding.

## What This Changes

The PR reorders generic embedded-agent overflow recovery to try deterministic tool-result truncation before model-driven compaction, with tests for retry state, targeting, fallback, and attempt budgeting.

## Best Possible Solution

Adopt one owner-approved recovery path that uses the existing pressure heuristic and complete active-session scope to truncate once before compaction, preserves transcript continuation, and always retains compaction as the tested fallback.
