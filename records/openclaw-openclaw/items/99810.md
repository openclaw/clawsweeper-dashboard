## Summary

Keep open: the PR targets a real auth-profile bug, but the patch can make existing active profile-wide or conflicting-model subscription blocks bypassable after it starts honoring `blockedModel`, and the contributor proof is not from the patched OpenClaw runtime.

## What This Changes

## Best Possible Solution

Land a narrow `blockedModel` fix that preserves active unscoped blocks, widens conflicting model blocks, covers stored-state upgrade cases, and includes redacted patched-runtime proof.
