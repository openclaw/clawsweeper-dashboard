## Summary

## What This Changes

The PR makes `getOAuthApiKey` refresh credentials when their stored expiry is within the auth manager’s five-minute refresh margin.

## Best Possible Solution

Keep the generic helper’s expired-only contract and make the manager-owned adapter explicitly perform or request refresh after the manager has determined that a credential is inside its refresh margin, with regression coverage for both paths.
