## Summary

Keep open for maintainer review: the report identifies a plausible durable-ingress liveness gap where persistent settlement-write failure can leave a lane process-locally active, but the current `main` implementation and regression coverage could not be independently re-read in this constrained review.

## What This Changes

The issue requests a safe recovery or explicit unhealthy state when a stalled ingress claim cannot be dead-lettered and its lane remains permanently held in process.

## Best Possible Solution

Keep the single-lane settlement invariant, add deterministic persistent-write-failure coverage, and expose a bounded explicit unhealthy/recovery state rather than silently retaining a guillotined claim indefinitely.
