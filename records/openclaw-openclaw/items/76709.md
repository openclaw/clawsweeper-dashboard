## Summary

Keep open: this is a focused Matrix E2EE shutdown-persistence fix candidate, but it is not merge-ready because the new awaited helpers are not wired into existing runtime shutdown paths and the external PR still lacks real Matrix shutdown proof. ## What This Changes

This PR adds async Matrix shared-client stop helpers that await `stopAndPersist()`, exports two helper variants from the Matrix client barrel, adds unit tests, and adds a changelog entry.

## Best Possible Solution

Keep the useful helper work only if it is paired with migration of the real Matrix shutdown call sites, focused regression tests for those owners, and redacted live/log proof that final crypto/sync persistence completes before process exit; keep the broader event-driven crypto flush work tracked in the canonical issue.

## Reproduction Assessment
