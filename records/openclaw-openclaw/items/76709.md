The PR adds async Matrix shared-client stop helpers that await `MatrixClient.stopAndPersist()`, deprecates the synchronous stop helpers, re-exports two helpers from the Matrix client barrel, adds unit coverage, and adds a root changelog entry.

## Best Possible Solution
