## What This Changes

The PR persists a validated `openclaw doctor --fix` migration result before runtime-backed diagnostics, then keeps the later write phase for repairs discovered by those diagnostics.

## System Context

Doctor first normalizes and validates an existing OpenClaw configuration, then runs health contributions that can require prepared model runtime state. This PR changes the boundary between the safe config-migration write and those later fallible diagnostics so a timeout cannot discard an already-valid migration.
