## What This Changes

The PR changes Codex conversation turn collection to return collected reply text on failed turns, adds collector regressions, marks `ps` shell probes as read-only, and adds an internal handoff note.

## Best Possible Solution

Revise the collector to override failed status only when completed turn-item or `item/completed` assistant text proves a final answer, keep partial-delta-only failures as errors, and add real behavior proof for recovered and unrecovered turns.
