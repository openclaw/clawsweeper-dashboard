## Summary

Keep open: the bug is source-backed, but the current patch still suppresses failed-turn errors when only partial assistant deltas were collected, and the supplied runtime proof does not exercise a recovered failed Codex turn.

## What This Changes

The branch changes the Codex conversation turn collector to resolve failed turns from collected assistant text, adds collector regressions, marks `ps` shell probes as read-only for agent payload classification, and adds an internal handoff note.

## Best Possible Solution

Revise the collector to distinguish completed assistant-message text from streamed progress, resolve failed turns only when completed text exists, keep partial-delta-only failures as errors, and add real behavior proof.
