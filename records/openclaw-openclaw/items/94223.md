## Summary

Keep open: the collector is the right layer for recovered Codex conversation replies, but this patch is still too broad because it treats partial streamed deltas as a successful recovered answer and the supplied real-environment proof does not exercise the recovered failed-turn behavior.

## What This Changes

The PR changes the Codex conversation turn collector to return collected assistant text on failed turn completion, adds collector regressions, marks `ps` shell probes as read-only, and adds an internal handoff note.

## Best Possible Solution

Revise the collector to override failed status only when completed assistant-message evidence exists, keep partial-delta-only failures as errors, and add redacted real behavior proof for recovered and unrecovered failed turns.
