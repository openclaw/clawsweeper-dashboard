## Summary

Keep open: the useful Codex reply-recovery idea is still not merge-ready because the branch suppresses failed-turn errors for partial streamed deltas, and the supplied live output does not exercise the recovered failed-turn behavior.

## What This Changes

The branch changes the Codex conversation turn collector to prefer collected assistant text on failed completions, adds collector and agent-tool regression tests, marks `ps` shell probes as read-only, and adds an internal handoff note.

## Best Possible Solution

Narrow the collector to override failed status only when completed assistant-message evidence exists, keep delta-only failed turns as errors, and add redacted real behavior proof for recovered and unrecovered failed turns.
