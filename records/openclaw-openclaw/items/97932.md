## Summary

Keep open. The PR addresses a real Telegram/topic restart recovery and tool-isolation bug, but the current patch also disables the delivery-only `message` tool path that existing `message_tool_only` subagent completion routes require, so it is not merge-ready.

## What This Changes

The branch adds a shared subagent announce-completion classifier, disables tools for those handoffs, records `announceLastRun` lifecycle state, and reconciles interrupted announce runs without human restart recovery.

## Best Possible Solution

Keep the shared announce classifier and restart reconciliation, but make the handoff boundary delivery-safe: block shell/file/apply_patch/Codex native Code Mode while preserving required `message` delivery or using a direct non-LLM delivery path for `message_tool_only` routes.
