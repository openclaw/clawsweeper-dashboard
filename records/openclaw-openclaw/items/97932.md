## Summary

Keep open for maintainer signoff: the current branch appears correct and well-proven, with no blocking code findings, but it intentionally changes session restart semantics and the tool/security boundary for subagent announce handoffs.

## What This Changes

The PR classifies subagent completion announce handoffs, disables tools for those handoffs across agent, CLI, embedded, and Codex native paths, persists an announce-run marker, and reconciles interrupted announce runs without human restart recovery.

## Best Possible Solution

Land this branch after owner signoff and exact-head validation, keeping subagent completion announce delivery tool-free and restart-reconciled instead of reviving it as a human recovery turn.
