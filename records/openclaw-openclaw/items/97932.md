## Summary

Keep open: the fix is still necessary and has strong Telegram proof, but one blocking edge remains because announce recovery is currently keyed from a caller-supplied `announce:` idempotency/run-id prefix.

## What This Changes

The branch classifies subagent completion announce handoffs, runs them tool-free across agent execution paths, persists announce-run lifecycle state, and skips human restart recovery for interrupted announce deliveries.

## Best Possible Solution

Reserve or gate announce run IDs to real internal subagent announce deliveries, then land after maintainer signoff on the persisted marker, killed reconciliation, and tool-free invariant.
