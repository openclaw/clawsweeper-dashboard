- **[P1] Do not trust the public announce: run-id prefix:** `src/agents/announce-idempotency.ts:30`
  - body: Late catch: this helper treats any run id starting with `announce:` as a delivery-only announce, but `agent` reuses the caller's public `idempotencyKey` as `runId` and the protocol only requires a non-empty string. Gate this on trusted subagent announce provenance or reserve/reject that prefix for non-internal callers before persisting/recovering.
