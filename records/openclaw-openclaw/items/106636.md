The PR converts large Docker and SSH sandbox command stdin buffers into 64 KiB zero-copy stream chunks while retaining direct input for strings and small buffers.

## Best Possible Solution

Keep the shared large-input conversion at the Docker and SSH command boundary, with focused byte/error tests, and land it after a redacted real sandbox run demonstrates successful large writes plus meaningful before/after memory or backpressure evidence.
