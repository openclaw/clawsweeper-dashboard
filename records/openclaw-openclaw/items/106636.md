## What This Changes

Streams large Docker and SSH sandbox command-input buffers through a shared 64 KiB backpressure-aware Readable while retaining direct input for strings and small buffers.

## Best Possible Solution

Keep one shared bounded-input helper used by both sandbox transports, retain the focused byte-preservation regression test, and land only after a real large-write run demonstrates checksum integrity and bounded memory or queued stdin behavior.
