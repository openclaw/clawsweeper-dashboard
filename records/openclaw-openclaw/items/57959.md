- **[P2] Suppress prompt image loading whenever retry images are stripped:** `src/agents/command/attempt-execution.ts:552`
  - body: `resolveRetryImages` strips explicit images for same-provider `format` failures, but this flag only suppresses prompt image detection on cross-provider retries. A same-provider format retry can still reload local image refs from the prompt and send them to the fallback model, recreating the failure this PR says it strips; derive the suppression from the same strip decision or include `previousFailureReason === "format"`.
  - confidence: 0.88

  - body: The PR adds `previousPartialExecution` consumers, but the diff only creates `partialExecution` in tests and current production `FailoverError` throw sites do not set it. As a result the replay-avoidance system prompt never emits after real tool execution; either capture tool metadata at the failover throw sites or remove this as a claimed fix.
  - confidence: 0.86
