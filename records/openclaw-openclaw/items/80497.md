## Summary

This PR should not merge until maintainers choose one canonical plugin telemetry contract. Current main already exposes typed `model_call_started`, `model_call_ended`, and `llm_output` hooks covering the central model identity, timing, output, and usage workflow, while this PR adds a parallel diagnostics subscription with different trust and access semantics. citeturn19search0turn20search0turn23search1

## What This Changes

Adds an `onModelDiagnosticEvent` Plugin SDK subscription that delivers five allowlisted trusted-marked model lifecycle events, with tests, documentation, and SDK surface-budget updates.

## Best Possible Solution

Use the typed Plugin SDK hook dispatcher as the canonical boundary, add narrowly typed fields or a dedicated failover hook only where those hooks cannot satisfy per-call correlation, and enforce the appropriate provider or conversation access policy rather than adding a parallel diagnostics listener.
