## Summary

Keep open: current main has command cron for zero-LLM command payloads, but it still lacks the persisted pre/post/onError cron hook lifecycle and per-job pre-agent gate requested by this issue.

## What This Changes

The issue requests persistent cron job hooks for pre-run, post-run, error handling, and conditional repeat or escalation workflows.

## Best Possible Solution

Settle a maintainer-approved cron hook or deterministic gate API across persisted job/protocol schemas, scheduled/startup/manual execution paths, CLI/UI/docs/tests, and an explicit trust model.
