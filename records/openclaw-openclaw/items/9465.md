## Summary

Keep open. Current main and the latest release still lack persisted cron pre/post/onError hooks or a conditional pre-agent gate; command cron jobs and the existing cron_changed plugin hook cover adjacent subsets, but not the requested lifecycle contract.

## What This Changes

Request to add cron job lifecycle hooks that can run pre, post, and error logic such as shell gates, agent turns, system events, and webhooks around scheduled execution.

## Best Possible Solution

Design a maintainer-approved additive cron hook or gate contract across persisted job types, Gateway protocol, scheduler paths, CLI/UI/docs/tests, and security policy, while reusing command payloads and plugin cron_changed where they already fit.

## Reproduction Assessment

Yes for source-level current-state verification: current main's cron types, protocol schemas, config schema, CLI/UI surfaces, and scheduler execution paths do not accept or run the requested lifecycle hooks. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

Unclear as proposed. The need is well supported, but maintainers need to choose the permanent boundary between command payloads, plugin hooks, and a persisted cron hook or gate API before implementation.
