## Summary

Keep open. Current main still lacks persisted cron pre/post/onError hooks or a per-job conditional pre-agent gate, and the remaining shell/webhook lifecycle semantics require maintainer product and security direction.

## What This Changes

The issue requests a cron job hooks lifecycle for pre-run gating, post-run/error handling, shell/webhook execution, and conditional notifications around scheduled jobs.

## Best Possible Solution

Settle a maintainer-approved cron hook or deterministic gate API across persisted job/protocol schemas, scheduled/startup/manual execution paths, CLI/UI/docs/tests, and an explicit trust model, or explicitly route the capability to plugins/ClawHub if current plugin hooks are sufficient.
