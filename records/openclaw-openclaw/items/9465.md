## Summary

Keep open: current main has shipped command cron for zero-LLM scripts, but it still lacks the persisted cron pre/post/onError hook lifecycle and per-job conditional pre-agent gate requested here.

## What This Changes

The issue requests a cron hooks system with pre/post/error lifecycle actions, including shell or webhook gates that can skip, repeat, or escalate scheduled agent jobs.

## Best Possible Solution

Settle a maintainer-approved cron hook or deterministic gate API across persisted job/protocol schemas, scheduled/startup/manual execution paths, CLI/UI/docs/tests, and an explicit trust model, or explicitly route the capability to plugins/ClawHub if current extension points are sufficient.
