## Summary

Keep open: current main still lacks persisted cron pre/post/onError hooks or a conditional pre-agent gate, while command cron and plugin hooks only cover adjacent subsets and the remaining work is product/security-sensitive.

## Best Possible Solution

Design and land a maintainer-approved additive cron gate or hook API across persisted types, protocol schemas/RPCs, scheduled/startup/manual execution paths, CLI/UI/docs/tests, with an explicit trust model and reuse of command payloads or plugin hooks where those fit.
