## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Reject snapshot directory symlinks before writing:** `src/backup/snapshot-store/provider-folder.ts:67`
  - body: `writeFileAtomic` and `copyFileAtomic` create the destination parent with recursive `mkdir` and then rename/copy through it. If a synced or shared backup target contains `snapshots` or an installation directory as a symlink, snapshot writes can escape `backup.target`; add a no-symlink directory-segment creation/check before writing or copying.
  - confidence: 0.9
- **[P1] Check workspace backup roots before mkdir:** `src/commands/workspace-backup.ts:350-351`
  - body: `workspaceBackupRunCommand` creates `backup.target/workspace/mirrors` and `.staging` before proving the target-side path is not a symlink, and the later containment check follows the same realpath. A symlinked `backup.target/workspace` can redirect mirror writes and stale cleanup outside the backup folder.
  - confidence: 0.9
- **[P2] Remove or implement retention config:** `src/config/zod-schema.backup.ts:25`
  - body: The schema accepts `backup.retention` fields, but no snapshot pruning path uses them. Once this ships, users can persist retention settings that appear supported while snapshots keep accumulating, so either implement pruning with tests/docs or leave the config key out for now.
  - confidence: 0.86
- **[P2] Restore config when in-state paths differ:** `src/commands/backup-restore.ts:715-721`
  - body: Full-host restore suppresses a config operation whenever the source config was inside source state and the current config path is inside current state. If those relative paths differ, replacing the state directory will not create the active config path and restore can report success with stale or missing config.
  - confidence: 0.82
- **[P2] Restore OAuth when in-state paths differ:** `src/commands/backup-restore.ts:741-747`
  - body: The credentials branch has the same containment-only shortcut as config restore. A backup whose OAuth dir was under state at one relative path restored onto a host using a different in-state OAuth path can skip credentials restoration and leave provider auth missing after a successful full-host restore.
  - confidence: 0.82
