Overall confidence: 0.88

Full review comments:

- **[P1] Reject snapshot-store symlink segments before writes:** `src/backup/snapshot-store/provider-folder.ts:85`
  - body: `copyFileAtomic` creates the destination parent and writes under `targetDir/snapshots/...` without checking existing `snapshots` or installation path segments. A symlink planted in a shared backup target can redirect payload/envelope writes outside `backup.target`, so snapshot storage is not bounded by the configured backup directory.
  - confidence: 0.9
- **[P1] Validate workspace backup roots before mkdir:** `src/commands/workspace-backup.ts:350-351`
  - body: `workspaceBackupRunCommand` creates `mirrorRoot` and `.staging` before any target-side no-symlink check, and `canonicalizePathForContainment` follows existing symlinks. A symlinked `backup.target/workspace` can cause mirror writes or stale-mirror removals to operate in the symlink target.
  - confidence: 0.91
- **[P1] Validate restore parents before rollback writes:** `src/commands/backup-restore.ts:426-428`
  - body: When the target exists, `moveTargetToRollbackPath` creates the rollback directory and renames through `targetParent` before `copySourceToTarget` validates that parent. If an intermediate parent is a symlink, restore can move or write outside the intended target before the guard runs.
  - confidence: 0.89
- **[P2] Cap archive path depth during verification:** `src/commands/backup-verify.ts:341-342`
  - body: `collectNestedArchiveParents` adds every parent segment for each normalized entry, but scan limits only total path bytes and entry count. A single deeply segmented 4 MiB path can allocate millions of parent strings during verify/restore.
  - confidence: 0.86
- **[P2] Recheck archive entry types during tar packing:** `src/infra/backup-create.ts:406-412`
  - body: `createBackupArchive` rejects symlinks and special files only in a pre-scan, then `tar.c` writes later without a filter or entry-type guard. A source tree that changes between scan and pack can produce an archive that verify/restore reject or that is unsafe with external tar tools.
  - confidence: 0.82
- **[P2] Remove or enforce backup retention config:** `src/config/zod-schema.backup.ts:25`
  - body: `backup.retention` is accepted by schema and types, but no backup runtime reads it. Users can configure pruning that never happens while snapshots keep accumulating.
  - confidence: 0.93

## Security Review

Status: needs_attention

Summary: The diff introduces concrete filesystem and archive security concerns in encrypted backup and restore paths.

Concerns:

- **[high] Snapshot store can write through target-side symlinks:** `src/backup/snapshot-store/provider-folder.ts:85`
  - body: Snapshot payload/envelope writes create parent directories inside the configured backup target without rejecting symlinked intermediate segments, allowing writes outside the target under the current user's permissions.
  - confidence: 0.9
- **[high] Workspace mirror can operate through symlinked backup roots:** `src/commands/workspace-backup.ts:350`
  - body: Workspace mirroring creates and later removes paths under backup.target/workspace after resolving containment through symlinks, which can redirect writes or deletes into the symlink target.
  - confidence: 0.91
- **[high] Restore rollback can move targets before parent validation:** `src/commands/backup-restore.ts:426`
  - body: Restore rollback creates a directory and renames the existing target before validating parent path segments, so a symlinked parent can move data outside the intended restore destination.
  - confidence: 0.89
- **[medium] Backup export has a scan-to-pack race:** `src/infra/backup-create.ts:406`
  - body: The export path pre-scans for symlinks and special files but does not recheck tar entries at write time, allowing changed source entries to produce archives that later restore/verify paths reject.
  - confidence: 0.82
- **[medium] Archive verification can expand deep paths excessively:** `src/commands/backup-verify.ts:341`
  - body: Verification can allocate a parent-path Set proportional to path segment depth without a depth cap, enabling resource exhaustion from crafted archive paths.
  - confidence: 0.86
