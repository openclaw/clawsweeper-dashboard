  - body: `workspaceBackupRunCommand` creates `backup.target/workspace/mirrors` and `.staging` before it validates the target-side backup root.   - confidence: 0.93
- **[P1] Reject symlinked snapshot-store parents before writes:** `src/backup/snapshot-store/provider-folder.ts:67-85`
  - body: `writeFileAtomic` and `copyFileAtomic` mkdir the destination parent and then write/rename through it without walking existing parent segments under `backup.target`.   - confidence: 0.93
- **[P1] Validate restore parents before rollback moves:** `src/commands/backup-restore.ts:442-443`
  - body: `applyRestoreOperations` moves an existing target to rollback before `copySourceToTarget` validates the target parent with `ensureDirectoryPathWithoutSymlinks`. A symlinked parent can therefore be followed during the rollback rename before the intended restore-path guard runs.
  - confidence: 0.9
- **[P2] Validate tar entries while writing archives:** `src/infra/backup-create.ts:412-418`
  - body: The export path pre-scans source trees, but `tar.c` does not re-check entry types as it writes. A source tree changed between pre-scan and packing can still produce an archive with symlinks or special files that OpenClaw later rejects or that external extractors may handle unsafely.
  - confidence: 0.86
- **[P2] Cap archive path depth before parent expansion:** `src/commands/backup-verify.ts:337-346`
  - body: Verification still builds every parent directory for every archive entry without a per-entry depth cap. A crafted deep path can fit under the total path-byte limit while forcing excessive parent string creation during `backup verify` and restore preflight.
  - confidence: 0.86
- **[P2] Compare in-state restore paths before suppressing copies:** `src/commands/backup-restore.ts:710-741`
  - body: The full-host restore skip checks only whether the source path and target path are both inside their state dirs, not whether the relative paths match. If config or OAuth moved to a different in-state location between backup and restore, the operation can be suppressed and leave the active path stale or missing after a reported restore.
  - confidence: 0.84
