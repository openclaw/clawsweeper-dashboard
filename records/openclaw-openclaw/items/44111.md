  - confidence: 0.93

  - body: Restore validates parents only inside `copySourceToTarget`, after `applyRestoreOperations` has already moved an existing target into a rollback directory.   - confidence: 0.9

  - body: `createBackupArchive` pre-scans sources for symlinks/special files, then lets `tar.c` walk the filesystem later without an at-write entry-type guard.   - confidence: 0.86

  - body: Verification limits total entry path bytes, but `collectNestedArchiveParents` still expands every parent segment for every normalized path.   - confidence: 0.88

  - body: Full-host restore skips standalone config/credentials copies whenever the source path was inside the old state dir and the current target path is inside the current state dir.   - confidence: 0.86
