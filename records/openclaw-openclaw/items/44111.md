A synced/shared target pre-populated with a `snapshots` or installation-id symlink can redirect payload/envelope writes outside `backup.target`; validate or create the target directory chain without symlink segments before `mkdir`, `rename`, or `copyFile`.
  - confidence: 0.9

  - body: `workspaceBackupRunCommand` creates `mirrorRoot` and `.staging` before the safety/containment checks. If `backup.target/workspace` is a symlink in a synced folder, the first `mkdir` and later mirror cleanup can operate through the link before the guard runs; reject symlinked `target`, `workspace`, `mirrors`, and `.staging` paths before any write.
  - confidence: 0.9
