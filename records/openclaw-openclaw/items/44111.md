Full review comments:

- **[P1] Reject symlinked snapshot target directories:** `src/backup/snapshot-store/provider-folder.ts:67`
  - body: `writeFileAtomic` creates `targetDir/snapshots/...` with recursive `mkdir` before checking whether any existing path segment under the configured target is a symlink. In a synced/shared backup folder, another client can replace `snapshots` or the installation directory with a symlink, causing the payload/envelope copy and rename to write outside `backup.target`. Validate each existing target-side directory segment with `lstat` before creating or writing snapshot files.
  - confidence: 0.91
- **[P1] Reject target-side symlinks before mirroring workspaces:** `src/commands/workspace-backup.ts:350`
  - body: `workspaceBackupRunCommand` creates `backup.target/workspace/mirrors` and `.staging` before any non-symlink validation, then containment checks canonicalize both the root and child through symlinks. If `backup.target/workspace` is a symlink planted by a sync client or another local process, OpenClaw writes mirrors/staging under the symlink target instead of the backup folder. Check the target/workspace/mirrors/.staging path segments with `lstat` before any `mkdir`, `cp`, `rename`, or stale mirror cleanup.
  - confidence: 0.9
- **[P2] Restore config when the in-state path moved:** `src/commands/backup-restore.ts:715-716`
  - body: This branch skips `configSourcePath` whenever the archive's config was covered by the state asset and the current config path is inside the current state directory. If the archive stored `oldState/openclaw.json` but the restore host uses `OPENCLAW_CONFIG_PATH=$stateDir/custom.json`, full-host restore only restores the state tree and leaves the active config path missing or stale. Compare the archived and current relative config paths before treating state restore as covering the active config.
  - confidence: 0.88
- **[P2] Restore OAuth when the in-state path moved:** `src/commands/backup-restore.ts:741-742`
  - body: The credentials path uses the same coverage shortcut: any archived OAuth dir under the old state and any current OAuth dir under the current state are treated as equivalent. A restore from `oldState/credentials` into a host configured with `OPENCLAW_OAUTH_DIR=$stateDir/auth` will skip the credentials copy and leave provider auth missing after a reported successful full-host restore. Compare the archived and current relative OAuth paths before suppressing the credentials operation.
  - confidence: 0.87
