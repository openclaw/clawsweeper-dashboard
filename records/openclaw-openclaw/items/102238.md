## What This Changes

The issue reports that disabling and re-enabling an in-flight cron job clears its run reservation, allowing the next timer tick to dispatch the same job concurrently.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/102255 so cron due-job selection and disable/update handling preserve the single active run invariant across a disable and re-enable while a run is in flight.
