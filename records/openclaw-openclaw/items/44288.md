## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Require opt-in before loading `.backupignore`:** `src/infra/backup-exclude.ts:189-194`
  - body: `resolveExcludePatterns()` reads `stateDir/.backupignore` for every backup unless `--include-all` is set. That means an existing install with this file can have plain `openclaw backup create` start omitting files after upgrade, which breaks the PR's stated no-flag compatibility and can create incomplete backups. Make file loading explicit, or add a maintainer-approved migration/default policy before this ships.
  - confidence: 0.9
- **[P1] Apply excludes to external backup assets:** `src/infra/backup-exclude.ts:362-363`
  - body: This early return makes every path outside the single `baseDir` immune to exclude patterns. Because backup plans can include external workspaces and custom config or credential locations, a user-provided pattern such as `*.pem` or `logs/` can be ignored for exactly the paths the user expected to filter; warning after resolution is not enough because the archive is still written with those files included.
  - confidence: 0.88
- **[P2] Preserve ordered duplicate gitignore rules:** `src/infra/backup-exclude.ts:225-233`
  - body: The resolver removes later duplicate patterns before handing them to `ignore`, but gitignore rules are order-sensitive when negation is involved. A sequence like `*.log`, `!important.log`, `*.log` intentionally re-excludes `important.log`; deduplication drops the final rule and changes backup contents from the user's declared policy.
  - confidence: 0.82
- **[P2] Do not rescan every backup during create:** `src/infra/backup-create.ts:528-535`
  - body: The create path now lists the full archive and stores every entry path even when the user did not request `--verify`. For multi-GB installs, this adds another full `.tar.gz` pass and O(entry count) memory to the same path this PR is trying to keep from stalling; keep this behind verify or stream-check only the required roots.
  - confidence: 0.8
