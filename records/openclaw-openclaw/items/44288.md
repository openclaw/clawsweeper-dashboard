  - confidence: 0.9

  - body: Still unfixed from the prior ClawSweeper review: every created archive is decompressed and all entry paths are stored so a few asset roots can be checked. This adds another full pass and O(entry count) memory to the same large-backup path the PR is trying to improve; keep this in verify or stream the check without retaining the whole archive listing.
  - confidence: 0.86
- **[P2] Preserve gitignore rule order:** `src/infra/backup-exclude.ts:225-232`
  - body: Late discovery on the same reviewed head: gitignore rules are order-sensitive, but this deduplicates repeated patterns before passing them to `ignore`. A sequence like `*.log`, `!important.log`, `*.log` changes meaning when the final rule is removed, so the full ordered rule list should be preserved and stats/source attribution handled separately.
