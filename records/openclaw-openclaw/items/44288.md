  - confidence: 0.91

  - body: This manifest extractor accumulates chunks without the current `MAX_MANIFEST_BYTES` cap. A crafted or corrupt backup can force unbounded memory use during `backup verify`, so keep the bounded reader from current main when adding `excludedStats`.
  - confidence: 0.88

  - body: The exclude path calls `tar.c` directly on source assets and then gzips the tar, but current main's writer now wraps archive creation with retry handling, SQLite snapshot/remap, volatile-path filtering, and link-cache behavior.   - confidence: 0.86

  - body: Every create now reads the completed `.tar.gz` back into an in-memory entry list before publishing. For the multi-GB backups this feature is meant to unblock, that adds a second full pass and O(entry count) memory even when the user did not ask for `--verify`.
  - confidence: 0.84
