## Summary

Keep open: current main still subscribes the TUI to session events but does not dispatch `session.message`, while Gateway broadcasts displayable transcript appends on that event and the active closing PR is still unmerged.

The issue asks for an already-running `openclaw tui` to display live messages appended from Web UI or another OpenClaw surface without restarting.
