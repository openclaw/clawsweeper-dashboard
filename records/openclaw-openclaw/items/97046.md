## Summary

Keep this PR open for human product and architecture review, not merge. ## What This Changes

This PR adds a Gee runtime envelope that carries host-owned routing, credential-reference, tool, compaction, and failover facts through the Codex extension and embedded-agent runtime.

## System Context

The Codex extension starts OpenClaw embedded-agent turns, which then select providers, authorize tools, compact sessions, and persist thread bindings. This PR inserts a Gee-specific ownership envelope into that path so a host can override those runtime decisions.

## Best Possible Solution

Do not merge a Gee-named core path. If maintainers sponsor hosted runtime ownership, first define and document a narrow generic plugin/SDK host-runtime contract with explicit lifecycle, persistence, revocation, and compatibility rules; keep the Gee implementation and policy in its owner plugin, then provide redacted live proof on a clean rebase.
