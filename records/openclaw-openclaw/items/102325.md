## Summary

Keep open. The branch is a focused bug-fix attempt, but it only fixes direct `runHeartbeatOnce` calls; the production queued cron wake path can still return disabled before that function is reached.

## What This Changes

The PR wraps per-agent heartbeat-enabled and interval guards in `runHeartbeatOnce` so `source: "cron"` calls bypass them, and adds a cron wake regression test.

## Best Possible Solution

Update the heartbeat wake scheduler so cron-sourced targeted wakes can run for the cron target even when that agent is not part of the periodic heartbeat schedule, while preserving the global heartbeat disable gate and busy retry behavior.
