## What This Changes

This PR stages backup archives privately, publishes completed archives through no-overwrite hard links with durability confirmation, and uses identity-aware cleanup for retries and failures.

## System Context

The backup command streams a compressed archive into temporary storage and then publishes it at an operator-selected output path. This publication layer governs whether a final-looking backup can be partial, overwritten, or reported successful before its data and directory entry are durable.
