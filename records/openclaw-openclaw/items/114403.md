## What This Changes

The branch replaces Copilot’s best-effort transcript mirroring with a journal that buffers tool-call groups and commits each completed assistant/result group atomically into the SQLite-backed canonical transcript.

## System Context

Copilot SDK events flow through the Copilot event bridge into OpenClaw’s session transcript projection. The new journal prepares and filters projected messages, then uses the session-transcript runtime to persist complete tool groups for later history and replay.
