## What This Changes

This PR replaces Copilot’s best-effort transcript mirroring with an ordered journal that writes complete assistant-and-tool-result groups atomically to the canonical SQLite session transcript.

## System Context

Copilot SDK events flow through the Copilot event bridge into the session transcript used for history and replay. The new journal holds an assistant tool-call group until all results are available, then commits the group through the shared SQLite transcript path before CLI finalization can add a duplicate assistant turn.

## Best Possible Solution
