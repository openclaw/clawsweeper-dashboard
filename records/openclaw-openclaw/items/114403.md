## What This Changes

The branch replaces Copilot’s best-effort transcript mirroring with an SQLite-backed journal that commits assistant tool calls and their results as complete ordered groups and prevents finalization from duplicating runtime-owned assistant messages.

## System Context

Copilot’s agent harness receives provider SDK events and projects durable user, assistant, and tool-result records into OpenClaw’s canonical session transcript. That transcript feeds session history, CLI persistence, and future resumed attempts, so a partial tool group can make replay unsafe or confusing.
