## What This Changes

The branch replaces Copilot’s best-effort transcript mirroring with a journal that buffers assistant tool-call groups and atomically writes complete assistant/result groups to the SQLite-backed canonical session transcript.

## System Context

Copilot SDK events pass through the Copilot event bridge into OpenClaw’s session transcript, which is used by replay and CLI history. This change makes the transcript journal defer tool-using assistant messages until all matching tool results can be committed as one ordered SQLite group.
