## What This Changes

Request support for a new `extended-stable` foreground npm update channel across CLI selection, persisted config, status checks, Gateway handoff, and update safeguards.

## Best Possible Solution

A maintainer-sponsored implementation should extend the existing update-channel model end to end, keep `stable` mapped to npm `latest`, keep `extended-stable` foreground/on-demand only, and add focused config/schema/docs/status/update tests after the release publication path is approved.

## Solution Assessment
