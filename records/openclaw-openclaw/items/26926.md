## Summary

Keep open: current main and v2026.6.11 still only accept text-bearing Synology Chat inbound webhooks, while images, CSVs, and PDFs are not parsed, staged, or passed into inbound media context.

## What This Changes

The issue requests inbound image, CSV, and PDF attachment support for the Synology Chat plugin.

## Best Possible Solution

Confirm Synology's attachment webhook and retrieval contract, then implement plugin-local bounded parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
