The issue requests inbound Synology Chat support for image, CSV, and PDF attachments instead of text-only webhook handling.

## Best Possible Solution

Confirm Synology's attachment payload and retrieval contract, then implement bounded plugin-local parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
