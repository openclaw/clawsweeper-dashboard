## Summary

Keep open: current main and v2026.6.11 still require text for Synology Chat inbound webhooks and have no parsed attachment fields or inbound media context, so image, CSV, and PDF support remains missing and needs Synology API proof plus security/product direction.

## What This Changes

Request inbound Synology Chat support for images, CSVs, and PDFs so private-network users can send attachments to agents.

## Best Possible Solution

Confirm Synology's attachment payload and retrieval contract, then implement plugin-local bounded parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
