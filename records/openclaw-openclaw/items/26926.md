## Summary

Keep open: current main and the latest release still parse Synology Chat inbound webhooks as required-text messages only, so image, CSV, and PDF attachments are not accepted or passed into the inbound media context.

## What This Changes

Request inbound image, CSV, and PDF attachment support for the Synology Chat plugin.

## Best Possible Solution

Confirm Synology's attachment webhook/API contract, then implement plugin-local bounded parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
