## Summary

Keep open: current main and the latest release still keep Synology Chat inbound webhooks on a required-text path with no parsed attachment fields or inbound media context, so inbound image, CSV, and PDF support remains missing and needs maintainer security/product direction.

## What This Changes

The issue asks for Synology Chat support for inbound images, CSV files, and PDFs instead of text-only chat messages.

## Best Possible Solution

Confirm Synology's attachment webhook/API contract, then implement plugin-local bounded parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
