Keep open: current main and v2026.6.11 still keep Synology Chat inbound webhooks on a text-required path with no inbound attachment parsing, staging, or media-context population, so the requested image, CSV, and PDF support remains missing.

## What This Changes

Request inbound image, CSV, and PDF attachment support for the Synology Chat channel so private-network Synology users can send files to agents instead of text only.

## Best Possible Solution

Confirm Synology's attachment webhook and retrieval contract, then implement plugin-local bounded parsing, safe retrieval or staging, existing inbound media-context population, docs, and focused tests.
