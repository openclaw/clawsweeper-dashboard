## Summary

Keep open: current main and the latest stable release still make Synology Chat inbound webhooks text-only, with no parsed attachment fields or inbound media context for images, CSV files, or PDFs.

## What This Changes

Request support for inbound images, CSV files, and PDFs in the Synology Chat plugin.

## Best Possible Solution

Confirm Synology's attachment payload and retrieval contract, then implement bounded plugin-local parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
