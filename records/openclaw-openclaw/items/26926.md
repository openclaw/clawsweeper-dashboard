## Summary

Keep open: current main and the latest release still keep Synology Chat inbound webhooks on a required-text path with no attachment fields or media context, so image, CSV, and PDF support remains missing and needs maintainer security/product direction before implementation.

## What This Changes

Synology Chat should support inbound images, CSV files, and PDFs instead of accepting only text webhooks.

## Best Possible Solution

Confirm Synology's attachment payload and retrieval contract, then implement bounded plugin-local parsing, safe retrieval/staging, generic inbound media-context population, docs, and focused tests.
