## What This Changes

Reject or redact browser open/navigate URLs containing embedded username/password credentials before they reach browser runtime or logs.

## Best Possible Solution

Land or replace the linked browser PR with a browser-plugin guard that rejects and redacts credential-bearing HTTP(S) navigation input before local, proxy, Playwright, Chrome MCP, or Chromium dispatch, with maintainer-approved auth guidance.
