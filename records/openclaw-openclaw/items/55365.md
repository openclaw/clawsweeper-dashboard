The issue asks the browser tool to reject credential-bearing navigation URLs early and redact credential-bearing URL text in surfaced errors or logs.

## Best Possible Solution

Land a reviewed browser-plugin fix that rejects and redacts credential-bearing HTTP(S) navigation input before any local, proxy, Playwright, or Chromium dispatch.
