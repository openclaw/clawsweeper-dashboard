## What This Changes

The branch bounds local debug-proxy CA generation to 30 seconds, stages and validates the certificate/key pair before publishing it, and adds recovery and concurrency coverage.

## System Context

The debug proxy creates a short-lived local certificate authority before it can intercept development traffic. Proxy startup and CA-installation callers depend on that pair being valid and available, so generation failures must not leave reusable partial files or block the process indefinitely.
