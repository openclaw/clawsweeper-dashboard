## Summary

Keep this PR open for revision: bounding OpenSSL is the right direction, but the new timeout can leave both directly written CA files present and therefore eligible for reuse even when generation was interrupted; the supplied validation is also mock-only.

## What This Changes

Adds a 30-second timeout to debug-proxy root CA generation and a mocked regression test for the OpenSSL invocation and propagated failure.

## Best Possible Solution

Generate the key and certificate at temporary sibling paths, atomically promote both only after OpenSSL succeeds, remove temporary outputs on every failure, and demonstrate a timed-out attempt followed by a successful retry.
