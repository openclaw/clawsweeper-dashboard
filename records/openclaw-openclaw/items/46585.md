## What This Changes

The issue reports that `openclaw nodes camera snap --device-id <iPhone Continuity Camera> --facing front` captures the same rear-camera image as `--facing back`.

## Best Possible Solution

Live-test the current macOS companion with a paired iPhone Continuity Camera, then either implement a supported front/back selection path or document/diagnose that explicit Continuity Camera device IDs select only the OS-exposed camera.
