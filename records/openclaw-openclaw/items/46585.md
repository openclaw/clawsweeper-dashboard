## What This Changes

The issue requests that `openclaw nodes camera snap --facing front --device-id <iPhone Continuity Camera>` select the iPhone front camera instead of always returning rear-camera output.

## Best Possible Solution

Live-test the current macOS companion with a paired iPhone Continuity Camera, then either implement a supported front/back lens-selection path that preserves exact device-id targeting where possible, or document and diagnose the OS limitation clearly.
