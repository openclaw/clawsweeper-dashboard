## What This Changes

The issue asks for `openclaw nodes camera snap --device-id <iPhone Continuity Camera> --facing front` to select the iPhone front camera instead of always capturing from the rear camera.

## Best Possible Solution

Live-test the current signed macOS companion with a paired iPhone Continuity Camera, then either implement supported front/back selection without breaking exact `deviceId` targeting or document/report the platform limitation.
