## Summary

Keep open: current main and v2026.6.11 still have adjacent pre-tool, final-answer revision, and outbound-cancel hooks, but not the requested fail-closed response gate with mandatory tool-call accounting, typed validators, two-phase planning, fallback semantics, and audit records.

## What This Changes

The issue requests a pre-response enforcement layer that blocks final output until required tool calls and validator checks have run and passed.

## Best Possible Solution

Keep this as the canonical response-gate policy-as-code design item, with domain policy packs in plugins and a versioned core/plugin seam for mandatory tool-call accounting, typed validators, fail-closed final-response gating, bounded retry/fallback behavior, and audit records.
