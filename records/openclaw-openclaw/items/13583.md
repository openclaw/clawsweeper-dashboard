## Summary

Keep open: current main still has adjacent pre-tool blocking, final-answer revision, reply-dispatch, and outbound cancellation hooks, but not the requested fail-closed response gate with mandatory tool-call accounting, typed validators, two-phase planning, bounded retry/fallback, and audit records.

## What This Changes

The issue requests a pre-response enforcement layer that mechanically blocks final output until required tool calls and validator policies pass.

## Best Possible Solution

Keep this as the canonical response-gate design item and define a versioned core/plugin API for mandatory tool accounting, validators, fail-closed final-response gating, retry/fallback, and audit, with domain policy packs in plugins or ClawHub.
