## Summary

Keep open. Current main and v2026.6.11 still have adjacent pre-tool fail-closed hooks, before-agent-finalize revision, reply/outbound cancellation, and related plugin/governance work, but not the requested fail-closed responseGate with mandatory-tool accounting, typed validators, two-phase planning, fallback semantics, and audit records.

## What This Changes

Request a pre-response enforcement layer that blocks final output until mandatory tool calls and configured validators pass.

## Best Possible Solution

Design a versioned core/plugin response-gate API for mandatory tool-call accounting, typed validators, bounded retry/fallback behavior, and audit records, while keeping domain policy packs in plugins or ClawHub.

## Reproduction Assessment

Yes from source inspection for the missing capability: current main exposes before_tool_call and before_agent_finalize but no responseGate, validator, ledger, or audit contract; no live canary was run.

## Solution Assessment

Yes, keeping it open as the canonical design item is best; a narrow patch to existing hooks would be too small because fail-closed semantics, config, and audit behavior need maintainer design.
