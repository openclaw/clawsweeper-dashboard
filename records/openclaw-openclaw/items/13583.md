## Summary

Keep open. ## What This Changes

Request to add hard pre-response enforcement hooks and responseGate configuration so final output or consequential actions can be blocked until required tools and validators pass.

## Best Possible Solution

Define a versioned core/plugin response-gate API for mandatory-tool accounting, typed validators, fail-closed final-response gating, bounded retry/fallback behavior, and audit records, with domain policies shipped as plugins or ClawHub packages.
