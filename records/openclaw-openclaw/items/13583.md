## Summary

Keep open: current main and v2026.6.11 have adjacent pre-tool gates, final-answer revision hooks, outbound cancellation hooks, and narrow HTTP `tool_choice` enforcement, but not the requested fail-closed responseGate with mandatory tool-call accounting, typed validators, two-phase planning, fallback/retry semantics, and audit records.

## What This Changes

Request a pre-response enforcement layer that gates final output on mandatory tool calls or validators, with config, bounded retry/fallback behavior, and audit logging.

## Best Possible Solution

Keep this as the canonical response-gate design item and land a versioned core/plugin seam for mandatory tool-call ledgers, typed response validators, fail-closed finalization, bounded retry/fallback, and audit records, with domain policy packs delivered as plugins or ClawHub packages.
