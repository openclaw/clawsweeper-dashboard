## Summary

Keep open: current main and v2026.6.11 still provide adjacent pre-tool blocking, final-answer revision, reply-dispatch, and outbound cancellation hooks, but not the requested fail-closed response gate with mandatory tool accounting, typed validators, fallback/retry policy, and audit records.

## What This Changes

Request a fail-closed pre-response enforcement layer that gates final answers on mandatory tool calls and validator results.

## Best Possible Solution

Keep this as the canonical response-gate design item: define a versioned core/plugin API for mandatory tool-call accounting, typed response validators, fail-closed final-response gating, bounded retry/fallback behavior, and audit records, while leaving domain policy packs to plugins or ClawHub.
