## Summary

Keep open: the reported directory bug remains real and the standalone proof is convincing, but the new CLI path can open a second Baileys socket over the same persisted WhatsApp session while the gateway already owns it, risking connection replacement and concurrent credential writes.

## What This Changes

The branch registers WhatsApp `listGroupsLive`, fetches group metadata through either the process-local controller or a temporary stored-auth Baileys socket, falls back to configured groups, and adds focused tests.

## Best Possible Solution

Perform live group discovery through the gateway-owned WhatsApp controller/socket, retain the configured-directory fallback when that owner is unavailable, and prove that a CLI lookup leaves an active gateway connected without modifying or racing its auth state.
