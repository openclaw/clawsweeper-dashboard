## What This Changes

The PR adds a Control UI note explaining that private browser profiles which discard site data lose their paired device identity, require re-pairing, and can leave removable stale device entries.

## System Context

The Control UI presents a browser-held device identity to the Gateway during pairing and later connections. When a browser profile discards its site data, the next Control UI session lacks that identity, so the Gateway follows the normal new-device approval path and retains the prior trusted-device record until it is removed.
