## Summary

Keep open: the current head convincingly demonstrates the subscription-only failure and preserves the important tool and transcript contracts, but the prior timeout blocker remains because the 45-second default follows configured Claude CLI routing rather than actual subscription-auth dispatch eligibility; the permanent provider-dispatch ownership also needs explicit runtime-owner approval.

## What This Changes

The PR adds opt-in subscription-auth CLI backend dispatch for active-memory helper runs, with grant-scoped MCP tools, transcript mirroring, and a conditional 45-second recall timeout.

## Best Possible Solution

Use one shared dispatch preflight, driven by provider-owned CLI backend capability metadata, for both execution and timeout selection; active-memory should opt into the generic capability, and tests should cover subscription auth, API-key precedence, missing backend, canonical runtime aliases, and denied MCP tools.
