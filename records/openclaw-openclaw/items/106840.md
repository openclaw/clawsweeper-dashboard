## Summary

The current head is technically strong, fixes a reproduced P1 auth-routing failure, resolves all prior review findings, and includes convincing live proof. Keep it open because it creates a public embedded-run/plugin-runtime dispatch contract while retaining Claude-specific eligibility policy in core; that permanent owner boundary requires explicit maintainer approval.

## What This Changes

Adds opt-in embedded-agent dispatch through the Claude CLI backend for subscription authentication, applies it to active-memory recall, hard-limits loopback MCP tools, mirrors transcripts, and conditionally raises the default recall timeout.

## Best Possible Solution

Have the Claude CLI backend declare a provider-owned subscription-auth dispatch capability that the generic embedded runner consumes, while preserving the PR's lane admission, transcript parity, hard MCP grant filtering, API-key passthrough, focused tests, and proven 45-second recall budget.
