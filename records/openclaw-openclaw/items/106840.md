## Summary

Keep this PR open for maintainer review: the same-head patch is technically strong and well proven, but the permanent provider-ownership and plugin-runtime contract still requires an explicit product decision before merge.

## What This Changes

Adds opt-in embedded-agent dispatch through the Claude CLI backend for subscription authentication, applies it to active-memory recall, enforces scoped MCP tool grants, mirrors transcripts, and conditionally extends the default recall timeout.

## Best Possible Solution

Keep the verified CLI-backed behavior, but express subscription dispatch as a provider-owned CLI-backend capability and expose only one generic canonical eligibility decision to dispatch and timeout callers, with the public plugin API documented as stable only if maintainers intentionally approve it.
