## Summary

Keep open: the linked bug is valid and the live proof is convincing, but the unchanged head still contains the previously reported explicit-auth-profile routing defect, while the permanent provider-versus-core contract remains unapproved.

## What This Changes

The PR adds subscription-auth CLI-backend dispatch for embedded Claude CLI runs, enables it for active-memory recall, hard-scopes loopback MCP tools, mirrors transcripts, and conditionally increases the default recall timeout.

## Best Possible Solution

Use one canonical eligibility function that receives and honors the explicit auth profile, derive Claude subscription capability from provider or CLI-backend-owned metadata rather than a core provider allowlist, and cover explicit OAuth, explicit API-key, ordered fallback, missing-backend, and timeout-selection cases.
