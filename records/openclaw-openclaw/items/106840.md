## Summary

Keep this PR open for maintainer review: the reported subscription-only Claude CLI recall failure is real, the patch is well-proven and has no remaining correctness finding, but it establishes a new provider/auth-sensitive embedded-run and Plugin SDK contract whose permanent ownership requires explicit approval.

## What This Changes

Adds opt-in embedded-agent dispatch through the Claude CLI backend for subscription authentication, applies it to active-memory recall, hard-limits loopback MCP tools, mirrors transcripts, and conditionally raises the default recall timeout.

## Best Possible Solution

Keep generic one-shot embedded dispatch, transcript mirroring, and grant enforcement in core, but expose provider-owned dispatch capability from the Anthropic plugin and have active-memory consume that generic contract with focused API-key, subscription, missing-backend, timeout, and tool-denial coverage.
