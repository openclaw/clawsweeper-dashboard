The PR adds opt-in subscription-auth CLI-backend dispatch for embedded Claude CLI runs, enables it for active-memory recall, enforces per-run MCP tool grants, mirrors transcripts, and conditionally raises the default recall timeout.

Represent subscription-auth dispatch as a provider-owned CLI-backend capability consumed by a generic embedded-runner plan, keep the grant enforcement and transcript parity, and derive the active-memory timeout from that same plan while preserving explicit user values and testing subscription, API-key, fresh-install, and upgrade paths.
