## Summary

Keep this PR open: the live proof is now convincing, but the prior P1 blocker remains because the longer recall deadline is selected from the configured route rather than the actual backend and credential decision, and the permanent helper-dispatch boundary still needs owner confirmation.

## What This Changes

Adds opt-in subscription-auth CLI backend dispatch for embedded active-memory recall, with restricted loopback MCP grants, transcript mirroring, lane admission, and a conditional 45-second timeout default.

## Best Possible Solution

Create one prepared CLI-dispatch decision at the agent-runtime owner boundary, carry it into both deadline selection and execution, preserve the 15-second direct/API-key path, and reuse the server-side MCP grant and transcript protections with focused upgrade tests and refreshed exact-head live proof.
