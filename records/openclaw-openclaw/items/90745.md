## Summary

Keep this PR open, but it is not ready to merge: the new runtime-only path forwards the full inbound context, including quoted reply bodies, into a system-prompt channel despite the stated requirement to keep that content out of trusted metadata. The current head also lacks after-fix live Telegram evidence. Likely related people: `openperf` is a medium-confidence routing candidate from the merged runtime-context work in this area.

## What This Changes

This PR adds structured reply, thread, quote, and reply-chain identifiers to inbound prompt context and carries them through embedded and CLI agent runtime paths without changing persisted user prompt text.

## System Context

OpenClaw channel handling creates an inbound prompt envelope containing user text and channel-derived context; the embedded and CLI runners then separate the visible user prompt from hidden runtime context before the model is invoked. This PR changes the reply-context portion of that envelope, including the special runtime-only-turn path.
