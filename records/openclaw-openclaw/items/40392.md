Full review comments:

- **[P1] Preserve legacy backup slots during migration:** `src/config/backup-rotation.ts:147`
  - body: This branch treats every non-datetime `.bak.*` file as an orphan, so the first config write after upgrade deletes the shipped `.bak.1` through `.bak.4` recovery ring before the new datetime set is populated. Preserve or convert those legacy slots until the bounded timestamp set can safely replace them.
  - confidence: 0.95
- **[P2] Make timestamp destinations collision-safe:** `src/config/backup-rotation.ts:53`
  - body: Using the millisecond timestamp as the complete destination means two writes in the same millisecond target the same path; POSIX can replace the previous backup and Windows can fail the rename before `.bak` is overwritten by the new copy. Add a collision fallback instead of accepting silent retention loss.
  - confidence: 0.88
