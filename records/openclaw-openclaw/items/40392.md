  - body: `cleanOrphanBackups` now deletes every non-datetime `.bak.*` file, including shipped `.bak.1` through `.bak.4` recovery slots.   - body: The code still derives exactly one destination filename per millisecond, so two rotations with the same timestamp overwrite on POSIX or fail best-effort on Windows.   - confidence: 0.86
