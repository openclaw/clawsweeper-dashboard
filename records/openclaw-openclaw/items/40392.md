- **[P1] Preserve legacy numbered backups during migration:** `src/config/backup-rotation.ts:147-149`
  - body: Current main and the latest release manage `.bak.1` through `.bak.4` as recovery points, but this branch treats every non-datetime `.bak.*` as an orphan and deletes it on the first config write. That collapses existing users' rollback history instead of migrating or preserving it, so legacy numbered backups need to be retained or converted before cleanup prunes them.
  - confidence: 0.93
- **[P2] Add a real collision fallback for timestamped rotations:** `src/config/backup-rotation.ts:53-56`
  - body: `formatBackupTimestamp` is only millisecond-precision, so two config writes in the same millisecond target the same backup filename. On POSIX the second rename can replace the earlier snapshot, and on Windows the failure is swallowed; choose a unique suffix or retry target instead of losing a backup slot.
  - confidence: 0.86
