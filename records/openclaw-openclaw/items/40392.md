Full review comments:

- **[P1] Preserve legacy numbered backups during migration:** `src/config/backup-rotation.ts:146-147`
  - body: The current released rotation treats `.bak.1` through `.bak.4` as managed recovery points, but this cleanup now deletes every non-datetime suffix on the first config write. That can collapse an upgraded user's rollback history before the timestamp ring has equivalent backups, so migrate or retain the numbered files until replacement recovery points exist.
  - confidence: 0.92
- **[P2] Avoid timestamp-collision overwrites:** `src/config/backup-rotation.ts:53`
  - body: Using the millisecond timestamp as the only destination means two writes in the same millisecond target the same backup filename; POSIX `rename` can replace the prior backup and Windows failures are caught. Add a collision fallback such as a checked counter suffix or exclusive create path so burst writes do not silently lose a recovery point.
  - confidence: 0.84
