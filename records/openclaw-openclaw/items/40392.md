  - body: This treats every non-datetime `.bak.*` as an orphan, including the shipped `.bak.1` through `.bak.4` ring.   - confidence: 0.94

  - body: The rotated filename is only the millisecond timestamp, so two config writes in the same millisecond target the same path.   - confidence: 0.84
