Full review comments:

- **[P1] Keep legacy backups through the upgrade:** `src/config/backup-rotation.ts:146-149`
  - body: The branch treats every non-datetime `.bak.*` file as an orphan, so an existing user with `.bak.1` through `.bak.4` loses those recovery points on the first config write. Preserve them until displaced or migrate them into timestamped backups before pruning.
  - confidence: 0.95
- **[P2] Avoid overwriting same-millisecond backups:** `src/config/backup-rotation.ts:52-56`
  - body: `formatBackupTimestamp(now)` is the full destination name, so two rotations in the same millisecond target the same path; POSIX rename overwrites the previous backup and Windows can drop the rotation. Add a collision fallback instead of documenting the loss.
  - confidence: 0.86
