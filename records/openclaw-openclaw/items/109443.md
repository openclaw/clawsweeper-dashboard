## Summary

Keep open: current main still applies transcript-global tool-result ID deduplication, the reported failure is source-reproducible, and the linked fix pull request remains open; this issue should close only after that PR or an equivalent fix merges.

## What This Changes

Preserve legitimate tool results when tool-call identifiers repeat across assistant turns so repaired transcripts remain acceptable to strict providers.

## Best Possible Solution

Land a centralized occurrence-aware pairing fix in the shared transcript-repair helper, with regression coverage for repeated IDs, synthesized gaps, displaced results, normalized clones, and later-turn reservation so every replay consumer inherits the same valid ordering.
