## Summary

The active PR appears to be a correct, well-proven fix with no discrete contributor-facing defect established. Keep it open for the current-head Windows checks and final maintainer merge review.

## What This Changes

The PR encodes generated Windows `.cmd` launchers using the boot-time OEM code page, declares that page in the script, reuses registry lookup logic, fails unsupported pages closed, and expands regression coverage.

## Best Possible Solution

Land the OEMCP-based encoder after exact-head Windows checks confirm fresh installs, legacy launcher readback, and upgrade rewrites, while retaining explicit markers, round-trip validation, and actionable fail-closed errors.

## Maintainer Decision

## Reproduction Assessment

Yes. The PR provides a concrete real-host reproduction on Windows 11 Turkish locale with ACP 1254 and OEMCP 857, showing the current launcher failing before the patched production encoder succeeds.

## Solution Assessment

Yes. Encoding installer-resolved paths for the actual boot-time OEM page is narrower and safer than substituting `%APPDATA%` or `%ProgramFiles%`, which could break custom npm prefixes, portable Node, and version managers.
