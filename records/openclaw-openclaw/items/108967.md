## Reproduction Assessment

Yes. On a Turkish Windows host with OEMCP 857, executing the current-main UTF-8 launcher containing a Turkish profile path garbles the path and exits unsuccessfully; the PR body provides before-and-after live output.

## Solution Assessment

Yes. Encoding the already-resolved absolute paths in the code page used by fresh `cmd.exe` sessions is narrower and safer than substituting environment variables that would misrepresent custom npm prefixes, portable Node installations, or version managers.
