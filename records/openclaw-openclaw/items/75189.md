- `P2`: The report describes a serious but model-dependent tool-dispatch reliability problem with available configuration workarounds and no confirmed current-main regression.

## Summary

Keep open: current main partially mitigates the report by lowering bootstrap caps and documenting an opt-in lean local-model mode, but it does not establish a small-model-safe default or prove reliable tool dispatch on the reported 7B–14B setups. The open tiered-bootstrap PR is one possible implementation, while the broader prompt-bloat report covers additional system and tool overhead, so neither safely supersedes this narrower issue.

## What This Changes

Make default workspace bootstrap context small enough that constrained local models reliably issue structured tool calls instead of claiming actions they did not perform.

## Best Possible Solution

Validate current main with a small-model tool-dispatch matrix, then add an onboarding or doctor recovery path that detects constrained local models and offers an explicit fix using the existing per-agent bootstrap limits and lean-mode controls, avoiding a parallel config surface unless those controls prove insufficient.
