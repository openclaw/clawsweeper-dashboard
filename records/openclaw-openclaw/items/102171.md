- **[P2] Honor link label escaping inside nested styles:** `packages/markdown-core/src/render.ts:212`
  - body: When an auto-linked URL is exactly wrapped by a style, for example `**https://example.com/?a=1&b=2**`, the renderer opens the link and then the style for equal start/end spans, so the style frame sits at the top of `stack`. This line only checks that top frame, falls back to `options.escapeText`, and re-encodes the URL label as `&amp;`, leaving the reported Telegram corruption in place for formatted bare URLs. Please apply the nearest active link escape hook through the stack, or otherwise carry the link escape through nested style spans, and add a styled bare-URL regression.
