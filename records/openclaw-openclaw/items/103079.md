## What This Changes

The issue requests unified Gateway `node.invoke` timeout normalization so zero disables the deadline and oversized values are clamped before both Gateway scheduling and node dispatch.

## Best Possible Solution

Normalize one canonical `node.invoke` timeout at the Gateway boundary, treat zero as no deadline, clamp oversized values once, and reuse that value for plugin policy, Gateway scheduling, and the forwarded node payload with focused regression coverage.
