## What This Changes

Align Gateway node.invoke timeout handling so zero disables the deadline and oversized values are clamped before both the Gateway timer and the forwarded node payload.

## Best Possible Solution

Normalize one canonical timeout at the Gateway node.invoke boundary, use no Gateway deadline for zero, clamp oversized values before policy/registry/forwarding, and add focused regression coverage for both cases.
