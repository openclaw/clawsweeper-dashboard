The issue reports that Gateway node.invoke timeout handling treats timeoutMs: 0 and oversized values differently from the receiving node.

Resolve one canonical node.invoke timeout before dispatch, where zero disables the deadline and oversized values are clamped before both the Gateway timer and the forwarded node payload.
