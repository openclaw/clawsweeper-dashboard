The contributor proof is useful context but still does not show current-head real behavior for the final branch.

## What This Changes

The PR changes Active Memory config normalization so omitted `config.agents` targets configured agents or implicit `main`, and updates docs, manifest help, and regression tests for omitted, empty, and explicit agent lists.

## Best Possible Solution

Land this only if maintainers accept omitted `config.agents` as the configured-agents default and the contributor supplies redacted current-head runtime proof; otherwise narrow the fix to a lower-blast-radius default-main, setup, docs, or doctor path for the canonical issue.

## Solution Assessment

Unclear as final product direction. Central normalization is the clean layer if maintainers want omission to mean configured agents, but a narrower default-main, setup, docs, or doctor repair would solve the canonical single-agent issue with less upgrade blast radius.
