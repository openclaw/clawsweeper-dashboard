This PR remains useful but not merge-ready: it changes a shipped fail-closed targeting contract into automatic multi-agent activation, and the supplied runtime output does not directly demonstrate the changed behavior on the final head.

## What This Changes

The PR makes omitted Active Memory agent targeting inherit configured agent IDs or implicit `main`, while preserving explicit empty and non-empty allowlists and updating tests, docs, help text, and generated baselines.

## Best Possible Solution

Keep omission fail-closed unless the Memory owner explicitly approves inherited targeting; if approved, document the upgrade contract, account for multi-agent recall concurrency, and require direct final-head proof for both inherited activation and explicit-empty suppression.
