## Summary

This PR should remain open for an Active Memory owner decision: the implementation is focused, but it changes the shipped omitted-field contract from no targets to automatic activation and lacks direct final-head runtime proof of that behavior.

## What This Changes

The PR makes omitted Active Memory agent targeting inherit configured agent IDs or implicit `main`, preserves explicit empty and non-empty lists, and updates tests, docs, plugin help, and generated baselines.

## Best Possible Solution

Keep omission fail-closed and have setup or doctor write explicit target agents; if maintainers intentionally approve inherited targeting, land it only with clear upgrade guidance and direct final-head runtime proof for omitted, empty, and explicit lists.
