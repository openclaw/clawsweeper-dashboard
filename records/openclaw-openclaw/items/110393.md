## Summary

The PR fixes a real readability false positive, but the bounded tag-end scan can now skip valid long opening tags entirely and thereby bypass the shipped nesting-depth availability guard; it needs a narrow security-preserving repair before merge.

## What This Changes

Updates the web-readability nesting preflight to ignore apparent tags inside HTML raw-text/RCDATA-like elements and adds focused regressions for pseudo-tags and malformed input.

## Best Possible Solution

Keep the raw-text exclusion, but fail closed or conservatively count a start tag when its closing delimiter is beyond the bounded scan, then add a regression containing deeply nested valid long opening tags.
