## Summary

Keep this PR open: the revised parser correctly handles several recognized raw-text/RCDATA tags and unclosed recognized elements, but it still omits HTML `<plaintext>`, whose content is raw text through EOF. Pseudo-tags after `<plaintext>` can therefore still inflate the preflight depth and suppress readability extraction.

## What This Changes

The PR changes web-readability’s estimated HTML nesting preflight to ignore pseudo-tags inside selected raw-text-like elements and adds focused extractor regressions.

## Best Possible Solution

Treat `<plaintext>` as an EOF raw-text element in the same bounded preflight model, preserve real-markup depth accounting elsewhere, and add a regression that demonstrates readable extraction survives pseudo-tags in that tail.
