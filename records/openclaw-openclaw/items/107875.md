## Summary

The prior stale-import and acceptance-order defects are addressed, and the central fix has convincing live proof, but the hot-reload handler still advances the transform generation after hook configuration resolution fails. That can silently activate an edited transform under the previously accepted mapping, so one blocking repair remains.

## What This Changes

Adds generation-based cache busting for gateway hook transforms, commits generations at gateway startup and hot-reload edges, and adds regression coverage for cache reuse, rejected candidates, and overlapping imports.

## Best Possible Solution

Track whether the hooks candidate resolved successfully and advance the transform generation only when that candidate is synchronously committed; add a reload-handler regression proving an invalid hooks candidate preserves the active transform despite an edited module file.
