## Summary

Keep this PR open: the lifecycle boundary and submitted proof are strong, but a reload can overlap an unresolved dynamic import and allow the prior generation to repopulate the cleared function cache.

## What This Changes

This PR clears the gateway hook-transform function cache when mappings are rebuilt, imports transform modules with a reload-generation token, and adds filesystem-backed reload regression tests.

## Best Possible Solution

Make transform caching generation-scoped, or condition cache insertion on the captured generation still being current, and add a deterministic regression test where a prior-generation import remains pending across mapping reload.
