## Summary

The proposed lifecycle-owned invalidation is directionally correct and well proven, but an older asynchronous module import can finish after a newer reload and repopulate the cleared cache with a stale transform, so the PR needs one bounded concurrency fix before merge. ([raw.githubusercontent.com](https://raw.githubusercontent.com/openclaw/openclaw/main/src/gateway/hooks-mapping.ts))

## What This Changes

Clears cached gateway hook transforms when mappings are rebuilt, cache-busts imports with a reload-generation token, and adds filesystem-backed reload regression coverage.

## Best Possible Solution

Capture the reload generation before importing and cache the resolved function only when that generation remains current, with a regression that holds an older import across a newer mapping reload.
