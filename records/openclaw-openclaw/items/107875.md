## What This Changes

The PR adds generation-based hook-transform cache invalidation at accepted gateway startup and hot-reload commit edges, with regression coverage for rejected reloads and overlapping imports.

## Best Possible Solution

Hot reload should atomically publish a new transform generation only after the candidate hooks configuration is accepted, preserve the active generation on rejection, and prevent older in-flight imports from repopulating the current cache.
