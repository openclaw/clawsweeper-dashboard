## What This Changes

The PR makes configured gateway hook-transform modules reload after an accepted hooks configuration reload, allowing later webhook deliveries to use an edited transform without restarting the gateway.

## System Context

Gateway hooks accept incoming webhook requests and resolve configured mappings into agent actions. A mapping may load a local transform module; the transform result then determines the action that gateway dispatches for the webhook.
