## Summary

Keep open: the previously reported P2 concurrency blocker remains on the unchanged PR head. An import started before a mapping reload can finish afterward and overwrite the new-generation cache with the stale transform.

## What This Changes

The PR clears cached hook transforms during mapping reload, cache-busts module imports by reload generation, and adds filesystem-backed reload coverage.

## Best Possible Solution

Make cache ownership generation-specific: capture the generation before importing and only publish the resolved function if that generation is still current, while allowing the initiating request to finish with its own resolved function; add a deterministic overlapping-import regression test.
