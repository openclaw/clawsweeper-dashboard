- **[P1] Exclude Wear identity files from backups:** `apps/android/wear/src/main/AndroidManifest.xml:10-12`
  - body: The new Wear app opts into backup/data extraction while the shared identity store writes an Ed25519 private key under app files.   - confidence: 0.91

  - body: Adding `:wear` here creates a new app module with its own source and tests, but current CI and npm scripts still build/test only `:app`. A Wear-only compile or test failure would not block merge, so the Android gates need explicit Wear/shared build and test tasks.
  - confidence: 0.88
- **[P2] Clear stale bootstrap auth when direct password changes:** `apps/android/wear/src/main/java/ai/openclaw/wear/ui/ConnectionSettingsScreen.kt:51`
  - body: The password editor preserves `bootstrapToken`, and `buildWearConnectParams` checks bootstrap auth before password auth when no token is set. After fallback sync seeds a bootstrap token, changing the password can still send bootstrap auth and keep direct login broken until some other reset clears it.
  - confidence: 0.84
