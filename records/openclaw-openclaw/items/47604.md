  - confidence: 0.92

  - body: The direct credential fields update `token` or `password` without clearing an existing `bootstrapToken`, and `buildWearConnectParams` chooses bootstrap auth before password whenever token is blank. A user switching from fallback/bootstrap to password auth can keep sending the stale bootstrap token until they reset config, so clear bootstrap auth when direct token/password changes.
