## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Exclude Wear identity files from backups:** `apps/android/wear/src/main/AndroidManifest.xml:10`
  - body: The Wear manifest enables backup while `backup_rules.xml` and `data_extraction_rules.xml` include the whole files domain. The shared identity store writes `openclaw/identity/device.json` with `privateKeyPkcs8Base64`, so cloud backup or device transfer can clone the watch's gateway-signing identity. Disable Wear backup or explicitly exclude the identity/secrets/pin paths before merge.
  - confidence: 0.95
- **[P1] Wire the Wear module into Android gates:** `apps/android/settings.gradle.kts:21`
  - body: This adds `:wear` to the Gradle project, but the Android CI matrix still runs only `:app` tasks and no `:wear:assemble*`, `:wear:test*`, lint, or ktlint task. A broken Wear app can therefore merge with green Android checks. Add focused Wear build/test/lint coverage to the Android gate before landing.
  - confidence: 0.92
- **[P2] Clear bootstrap auth when direct credentials change:** `apps/android/wear/src/main/java/ai/openclaw/wear/ui/ConnectionSettingsScreen.kt:51`
  - body: The token/password remote-input handlers copy only the edited field, so a fallback-synced `bootstrapToken` remains stored. `buildWearConnectParams` then prefers `bootstrapToken` over password when token is blank, leaving users who enter a password still sending stale bootstrap auth with no visible field to clear it. Clear `bootstrapToken` when token or password is edited.
  - confidence: 0.9
- **[P2] Update Android license notices for new dependencies:** `apps/android/wear/build.gradle.kts:72`
  - body: The Wear module adds new AndroidX Wear, Play Services Wearable, Tiles, Protolayout, and related dependencies, and the phone app adds Data Layer dependencies, but the bundled Android license notice files are unchanged. The scoped Android policy requires auditing `apps/android/THIRD_PARTY_LICENSES/openclaw/licenses/` when dependencies change so the in-app Licenses screen stays complete.
  - confidence: 0.86
