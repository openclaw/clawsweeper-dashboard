  - confidence: 0.9

  - body: Editing the token or password keeps any existing `bootstrapToken`, and `buildWearConnectParams` prefers bootstrap auth before password when token is blank. A watch that received fallback bootstrap config can keep sending stale bootstrap auth after the user enters a password, making direct reconnect fail until the config is reset elsewhere.
  - confidence: 0.86
