Full review comments:

- **[P1] Exclude Wear identity files from backups:** `apps/android/wear/src/main/res/xml/backup_rules.xml:3`
  - body: The Wear app enables backup and includes the entire file domain, but `GatewayDeviceIdentityStore` writes `privateKeyPkcs8Base64` under `context.filesDir`.   - confidence: 0.94
- **[P1] Wire the Wear module into Android gates:** `apps/android/settings.gradle.kts:21`
  - body: Adding `include(":wear")` creates a separate application module, but current Android CI, package scripts, and Android CodeQL still build or scan only `:app`. As a result, this PR can stay green without directly compiling, testing, releasing, or security-scanning the new watch app.
  - confidence: 0.9
- **[P2] Clear bootstrap auth when direct auth changes:** `apps/android/wear/src/main/java/ai/openclaw/wear/ui/ConnectionSettingsScreen.kt:47-51`
  - body: Editing the token or password keeps any existing `bootstrapToken`, and the connect builder prefers bootstrap auth before password when token is blank. If fallback sync previously stored a bootstrap token, entering a password can keep sending stale bootstrap auth and make direct reconnect fail until the config is reset elsewhere.
  - confidence: 0.86
