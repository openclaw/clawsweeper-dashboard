  - body: The password editor saves only `password`, while the connect builder still prefers any stored `bootstrapToken` over password. If fallback sync previously stored a bootstrap token, switching to password auth can keep sending the stale bootstrap token until another reset clears it.
  - confidence: 0.8

  - confidence: 0.78
