  - body: The Wear app opts into backup/data extraction for the whole file domain, while the shared identity store writes the Ed25519 private key to `openclaw/identity/device.json`.   - body: This PR includes `:wear`, but the Android CI matrix and package scripts still run only `:app` and `:benchmark` tasks.   - body: The password editor copies the config with a new password but preserves any existing `bootstrapToken`; `buildWearConnectParams` then prefers bootstrap auth before password.   - confidence: 0.91
