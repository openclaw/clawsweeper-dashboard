## Summary

Keep open: current main and v2026.6.11 still treat assistant shell snippets as copy-only markdown, while approve/run controls are only driven by Gateway-created exec approval events. The requested Control UI command-proposal flow remains a distinct security-sensitive feature that needs maintainer product/security direction before implementation.

## What This Changes

Request a Control UI command card for assistant-suggested terminal commands with Copy, Approve and Run, Cancel, risk labels, exact command text, working directory, host, and guarded execution semantics.

## Best Possible Solution

Define a structured assistant command-proposal contract that feeds the existing exec approval request/resolve path and `systemRunPlan` safeguards, instead of adding a run button to arbitrary markdown code blocks.
