## Summary

Keep open: current main and v2026.6.11 still render assistant-authored shell snippets as copy-only markdown, while approve/run controls are reserved for Gateway-created exec approval events with bound command context. ## What This Changes

The issue requests Control UI command cards with Copy, Cancel, and Approve and Run actions for assistant-suggested terminal commands.

## Best Possible Solution

Define a typed command-proposal contract that binds exact command text, argv, cwd, host, session, risk metadata, and output routing, then connect it to the existing Gateway exec approval flow instead of running arbitrary markdown blocks directly.

## Reproduction Assessment

Yes, at source level. Assistant markdown code blocks render with copy-only `.code-block-copy` buttons, while the existing approve/run UI is populated only by Gateway approval events.

## Solution Assessment

No final implementation path is proven yet. The maintainable solution is a typed proposal-to-approval flow through Gateway exec approval semantics, not a direct run button attached to arbitrary markdown.
