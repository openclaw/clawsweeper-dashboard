## Summary

Keep open: current main and the latest release still have separate copy-only markdown code blocks and Gateway-created exec approval prompts, but no Control UI contract that turns assistant-suggested shell commands into an explicit approve-and-run command proposal.

## What This Changes

The issue requests Control UI command cards with copy and explicit approve-and-run actions for assistant-suggested shell commands.

## Best Possible Solution

Design a structured command-proposal contract that reuses existing exec approval and systemRunPlan safeguards instead of adding a run button to arbitrary markdown code blocks.

## Reproduction Assessment

Yes, at source level. Current main shows assistant code blocks render with copy-only markdown chrome, while approve/run controls are only created for Gateway approval events.

## Solution Assessment

Unclear until maintainers choose the product/security boundary. The maintainable direction is a typed command-proposal-to-exec-approval path, not heuristic execution from rendered Markdown.
