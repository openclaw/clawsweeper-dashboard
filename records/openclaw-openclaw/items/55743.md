## Summary

Keep open: current main still renders assistant shell snippets as markdown code blocks with copy-only chrome, while approve/run controls are only driven by Gateway-created exec approval events. This remains a distinct Control UI product/security design request, not a duplicate of the pending-approval dashboard or approved-command-output work.

## What This Changes

The issue requests Control UI command cards that can copy or explicitly approve and run assistant-suggested shell commands.

## Best Possible Solution

Design a structured command-proposal contract that reuses existing exec approval and `systemRunPlan` safeguards instead of inferring executable actions from arbitrary markdown code blocks.
