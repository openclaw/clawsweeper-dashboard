## Summary

## What This Changes

The issue requests Android chat composer support for sending with Enter on a physical keyboard while preserving newline entry with Shift+Enter.

## Best Possible Solution

Add a focused handler in the Android chat composer so hardware Enter sends only when the existing send action is enabled, while Shift+Enter still inserts a newline and the gateway send path remains unchanged.
