## What This Changes

The branch changes the transient npm-lock generator to combine global and parent-scoped dependency overrides, preserving scoped forks unless npm collapses conflicting peer contexts under one parent selector.

## System Context

OpenClaw’s release packaging generates transient npm lockfiles from `pnpm-lock.yaml` so official plugin packages install reproducibly with npm. The override planner converts pnpm package versions and peer-context edges into global or parent-scoped npm constraints before Slack and Discord packages are built.

## Best Possible Solution

Accept a single deterministic global pin only for npm parent-selector collisions whose locked versions share an exact stable major/minor line, retain scoped overrides everywhere else, and merge after the release owner confirms the Discord proof and the rebased head passes required checks.
