## Summary

Keep open: current main and v2026.6.11 have provider-scoped stream-liveness timeouts and a global non-resetting run budget, but neither exposes the requested typed per-model total deadline; the related open Gemini PR addresses a narrower idle-watchdog defect and does not supersede this request.

## What This Changes

Requests a configurable global and per-model total generation deadline that aborts runaway model turns and can trigger fallback handling.

## Best Possible Solution

Extend the existing non-resetting run deadline with a typed global default and per-model override, documenting precedence and keeping first-event, idle-watchdog, and semantic-repetition behavior as separate contracts.
