## Summary

Keep open: current main and the latest release still lack the requested typed global/per-model generation timeout surface, while existing provider, run, idle, and first-event timeout paths only cover adjacent behavior.

## What This Changes

The issue requests a global and per-model generation timeout config that can abort or fail over long-running model generation loops without relying only on provider or run timeouts.

## Best Possible Solution

Define one canonical agent model timeout contract with explicit precedence across fallback candidates, schema/docs coverage, runtime enforcement at the embedded attempt boundary, and separate tracking for first-token and repetition safeguards.
