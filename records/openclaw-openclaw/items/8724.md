## Summary

Keep open: current main has adjacent provider request, idle, and first-event timeout controls, but it still lacks the requested typed global/per-model non-resetting generation timeout contract.

## What This Changes

The issue requests configurable global and per-model generation timeouts that abort runaway active model generation, log the timeout, and optionally trigger fallback.

## Best Possible Solution

Choose and document one canonical timeout contract, then enforce an effective non-resetting generation budget per selected fallback candidate while preserving existing provider request timeout behavior.

## Reproduction Assessment

Yes for the missing capability: current source shows agents.defaults.models.* is strict and has no timeout field, while the available timeout contract is provider-scoped. I did not run a live runaway-generation repro because the central review question is the absent config/enforcement surface.

## Solution Assessment

Unclear as a product direction: a per-model total generation timeout is plausible, but maintainers need to choose whether it belongs under agents.defaults.models, provider config, or another canonical model-routing surface before a fix PR.
