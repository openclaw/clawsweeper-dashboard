## Summary

Keep open: current main and v2026.6.11 still lack a typed global/per-model generation timeout contract; existing provider request timeout, run timeout, idle watchdog, and first-event timeout behavior are adjacent but do not settle the requested public config surface.

## What This Changes

Request to add global and per-model generation timeout configuration so long or looping model generation can be aborted, logged, and optionally routed through fallback handling.

## Best Possible Solution

Define one canonical agent model timeout contract with documented precedence across fallback candidates, enforce it at the embedded attempt boundary, and keep first-token and semantic repetition safeguards tracked separately.
