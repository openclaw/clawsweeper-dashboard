## Summary

Keep open: current main and v2026.6.11 still lack the requested typed global/per-model generation timeout surface, and the adjacent provider/run/idle/first-event timeout paths do not settle the public config contract.

## What This Changes

The issue requests global and per-model generation timeout configuration so model attempts can be aborted, logged, and optionally failed over before runaway generation wastes time or tokens.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document precedence across fallback candidates, enforce it at the embedded attempt boundary with a non-resetting budget, and keep first-token and repetition safeguards tracked separately.
