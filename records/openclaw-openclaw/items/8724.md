## Summary

Keep open: current main and v2026.6.11 still lack the requested typed global/per-agent-model non-resetting generation timeout, while adjacent provider request, first-event, idle-watchdog, and run-level timeout paths are already separate behavior.

## What This Changes

The issue requests a global and per-model generation timeout that aborts long-running model generation and can feed fallback handling.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document its precedence across fallback candidates, enforce it as a non-resetting generation budget at the embedded attempt boundary, and keep first-token and repetition safeguards separate.
