## Summary

Keep open: current main and v2026.6.11 still lack the requested typed per-agent-model generation timeout surface; existing provider request, run, idle, and first-event timeout paths are adjacent but do not settle the public config/product decision.

## What This Changes

Requested global and per-model generation timeout configuration so operators can bound slow or looping model generation differently by model.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document precedence across fallback candidates, enforce it at the embedded attempt boundary, and keep first-token and repetition safeguards tracked separately.
