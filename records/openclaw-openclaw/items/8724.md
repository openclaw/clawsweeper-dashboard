## Summary

## What This Changes

Add configurable global and per-model hard generation deadlines with timeout logging and fallback integration.

## Best Possible Solution

Add one canonical effective model-call deadline, resolved from an approved model-level override over provider defaults and capped by the remaining whole-run budget, while retaining the resetting idle watchdog and documenting timeout classification and precedence.
