Keep open: current main and v2026.6.11 still lack the requested typed global or per-model non-resetting generation-timeout config, while the existing provider request timeout, first-event timeout, and reset-on-chunk idle watchdog only cover adjacent failure modes. ## What This Changes

Request to add global and per-model generation timeout configuration so model attempts can be aborted, logged, and possibly failed over after a bounded generation budget.

## Best Possible Solution

Define one maintainer-approved timeout hierarchy, then implement a typed global/per-model non-resetting generation budget with schema/docs/tests and clear precedence against provider request, first-event, idle, run, and fallback timeouts.
