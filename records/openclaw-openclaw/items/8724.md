## Summary

Keep open: current main and v2026.6.11 still lack the requested typed global or per-agent-model non-resetting generation timeout, and the open related PR only addresses an adjacent Gemini thinking idle-watchdog path.

## What This Changes

The issue requests a typed global and per-model generation timeout configuration so slow or looping model generations can be aborted or routed differently.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document its precedence across fallback candidates, enforce it at the embedded attempt boundary without weakening existing provider/run caps, and keep first-token, thinking-idle, and repetition safeguards as separate narrower work.
