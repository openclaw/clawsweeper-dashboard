## Summary

Keep open: current main and v2026.6.11 still lack the requested typed global/per-model generation timeout surface, and the existing provider, run, idle, and first-event timeout paths do not fully cover the public config contract.

## What This Changes

Requests a public global/per-model generation timeout config for agent model runs so operators can bound long or looping model streams differently per model.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document precedence across fallback candidates, enforce it at the embedded attempt boundary with a non-resetting budget, and keep first-token and repetition safeguards tracked separately.
