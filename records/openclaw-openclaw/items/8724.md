## Summary

Keep open: current main and v2026.6.11 provide provider-scoped request/idle timeouts and a whole-run timeout, but no typed per-model non-resetting generation deadline; the open Gemini PR addresses a narrower idle-watchdog bug and does not supersede this product/config request.

## What This Changes

Requests global and per-model generation-timeout configuration that aborts runaway model generation, logs the timeout, and can participate in fallback routing.

## Best Possible Solution

Add one typed runner-owned total-generation budget with a global default and per-model override, resolve it for each selected fallback candidate, enforce it with a non-resetting deadline, and classify the abort for logging and fallback while leaving first-event and semantic-repetition controls separate.
