## Summary

Keep open: current main and v2026.6.11 still lack the requested typed global or per-agent-model non-resetting generation timeout, while existing run, provider request, first-event, and idle-watchdog controls cover adjacent failure modes only.

## What This Changes

Request to add global and per-model generation timeout configuration that can abort long-running model generation and feed fallback handling.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document its precedence across fallback candidates, enforce it at the embedded attempt boundary without weakening existing provider/run caps, and keep first-token and repetition safeguards tracked separately.
