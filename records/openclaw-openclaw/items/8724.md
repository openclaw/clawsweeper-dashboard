## Summary

Keep this issue open: the active related PR improves the implicit cloud-thinking idle watchdog, but it does not establish the requested supported per-model total-generation timeout contract. The remaining choice is product-sensitive because it adds configuration surface and must define precedence, fallback behavior, and protection for legitimate long-thinking runs.

## What This Changes

Add a supported global and per-model generation-timeout configuration that can bound runaway model generation and participate safely in fallback handling.

## Best Possible Solution

Choose one canonical per-model total-generation deadline contract, document its precedence against provider and run limits, resolve it for every fallback candidate, and enforce it with a non-resetting attempt deadline while leaving first-token and semantic repetition safeguards as separate behaviors.
