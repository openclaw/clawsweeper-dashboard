## Summary

Keep open: current main still lacks a per-model, non-resetting total-generation deadline, so continuously streaming thinking or repetition can evade the existing idle watchdog; the related Gemini work addresses a narrower idle-timeout failure rather than this configuration contract.

## What This Changes

Add an optional global and per-model total-generation timeout that aborts runaway generations, logs the timeout, and can trigger model fallback.

## Best Possible Solution

Define one optional canonical total-generation deadline on global agent defaults and model runtime entries, preserve existing behavior when unset, resolve it per selected fallback candidate, enforce it with a non-resetting timer, and classify the abort consistently for logs and fallback handling.

## Solution Assessment
