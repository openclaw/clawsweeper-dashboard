## Summary

Keep open: current main and v2026.6.11 still lack the requested typed per-model generation timeout surface, and adjacent provider/run/idle/first-event timeout paths do not settle the public config contract.

## What This Changes

The issue requests a global and per-model generation timeout so selected LLMs can be aborted or failed over when they keep generating or thinking without useful output.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document precedence across fallback candidates, enforce it at the embedded attempt boundary, and keep first-token and repetition safeguards tracked separately.
