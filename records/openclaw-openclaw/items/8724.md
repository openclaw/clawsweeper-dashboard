## Summary

Keep open: current main still lacks the requested typed global/per-model non-resetting generation timeout, while the existing provider request timeout, first-event timeout, and reset-on-chunk idle watchdog only cover adjacent failure modes.

## What This Changes

Request a global and per-model generation timeout so long-running or looping model generations can be aborted and optionally trigger fallback.

## Best Possible Solution

Define one maintainer-approved timeout hierarchy, then add a typed global/per-model non-resetting generation budget with docs, schema, fallback classification, and regression coverage that preserves existing provider and run timeout behavior.
