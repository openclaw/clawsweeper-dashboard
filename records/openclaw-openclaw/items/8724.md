## Summary

Keep open: current main and latest stable release v2026.6.11 still lack the requested typed global or per-agent-model non-resetting generation timeout, while existing controls cover adjacent provider request, first-event, idle-watchdog, and run-level timeout paths.

## What This Changes

The issue requests a public global and per-model generation timeout configuration that can abort long or looping model output and interact with fallback routing.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document its precedence across fallback candidates, enforce it at the embedded attempt boundary without weakening existing provider/run caps, and keep first-token and repetition safeguards tracked separately.
