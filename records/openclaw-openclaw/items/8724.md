## Summary

Keep open: current main and v2026.6.11 have adjacent provider, run, idle, and first-event timeout controls, but not the requested typed per-model total-generation budget under `agents.defaults.models`; the remaining work is a config-surface product decision.

## What This Changes

Request a typed global and per-model generation timeout config so operators can bound long or looping model generations differently by model.

## Best Possible Solution

If maintainers accept the new surface, add one typed per-model generation/request timeout contract with schema, docs, generated metadata, focused runner enforcement, fallback classification, and tests, while keeping first-token and repetition-circuit-breaker work separate.
