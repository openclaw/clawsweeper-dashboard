## What This Changes

Add supported global and per-model timeout configuration that lets operators bound an individual model generation/attempt and preserve usable fallback behavior for slower or looping models.

## Best Possible Solution

Define one backward-compatible timeout contract with explicit model-over-default precedence, enforce it as a non-resetting per-attempt deadline before fallback, and document how it differs from idle and first-token timeouts.
