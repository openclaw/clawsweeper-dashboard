## Summary

Keep open for a maintainer product decision: current main still lacks the requested typed global/per-model non-resetting generation budget, and the adjacent open Gemini watchdog PR does not implement that contract.

## What This Changes

Add a global and per-model non-resetting generation timeout that aborts runaway model generation and participates in fallback handling.

## Best Possible Solution

Add one typed global/per-model total-generation budget, resolve it for each fallback candidate, enforce it with a non-resetting generation timer, and keep provider request, first-event, idle-gap, and semantic repetition controls distinct.
