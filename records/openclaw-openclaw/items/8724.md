## Summary

Keep open: current main still lacks the requested typed per-agent-model generation timeout config, and the remaining decision is whether OpenClaw should add that public timeout surface rather than rely on existing provider, run, first-event, and idle-watchdog controls.

## What This Changes

The issue asks for a global and per-model generation timeout configuration that can abort long or looping model generations and optionally trigger fallback.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document its precedence across fallback candidates, enforce it at the embedded attempt boundary without weakening existing provider/run caps, and keep first-token and repetition safeguards tracked separately.
