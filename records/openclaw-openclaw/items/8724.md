## Summary

Keep open: current main and the latest release still lack the requested typed global/per-model generation-timeout config surface, and the adjacent provider, run, idle, and first-event timeout paths do not settle the public config contract.

## What This Changes

The issue requests a global and per-model generation timeout config that can abort long-running model generation and optionally participate in fallback handling.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document precedence across fallback candidates, enforce it at the embedded attempt boundary with a non-resetting budget, and keep first-token and repetition safeguards tracked separately.
