## Summary

Keep open: current main and latest release still lack the requested typed global/per-model generation timeout config, while existing provider request timeout, run timeout, idle watchdog, and first-event timeout controls are adjacent but do not settle the requested public contract.

## What This Changes

Request to add global and per-model generation timeout configuration so looping or slow model generations can be aborted and routed through fallback behavior.

## Best Possible Solution

Define one canonical agent model timeout contract with documented precedence across fallback candidates, enforce it at the embedded attempt boundary, and keep first-token and semantic repetition safeguards tracked separately.
