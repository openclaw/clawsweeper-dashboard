## Summary

Keep open: current main and the latest stable release still lack the requested typed global or per-agent-model non-resetting generation timeout, while existing code covers adjacent provider request, first-event, idle-watchdog, and run-level timeout paths.

## What This Changes

The issue requests global and per-model generation timeout configuration so long-running model generation can be aborted, logged, and optionally failed over by model.

## Best Possible Solution

Define one canonical timeout contract for agent model selection, document its precedence across fallback candidates, enforce it at the embedded attempt boundary without weakening provider/run caps, and keep first-token and repetition safeguards tracked separately.
