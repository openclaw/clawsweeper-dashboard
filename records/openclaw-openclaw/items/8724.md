Request a global and per-model generation timeout so operators can abort runaway model generation and optionally fail over.

## Best Possible Solution

Choose the timeout ownership model, then either add a typed non-resetting generation budget at the approved global/per-model level with docs and regression coverage, or document the existing provider request timeout path as the supported answer and close the feature.

## Reproduction Assessment

Unclear. A per-model generation timeout is plausible, but maintainers should first decide whether this belongs under agents.defaults.models, provider request config, or another canonical timeout hierarchy.
