Keep open: current main and the latest release still carry the mutable `workspacePackagePaths` path, and this PR is a narrow, plausible fix, but it is not merge-ready without contributor real-behavior proof and a refresh against current main.

## What This Changes

The branch makes `scripts/audit-seams.mjs` collect workspace package paths into a fresh local array per `main()` run and passes that list into missing-package analysis.

## Best Possible Solution

Keep the immutable-base implementation as the repair direction, then land it only after the branch is refreshed and after-fix proof, ideally with a focused `main()` idempotence regression test, is added.

## Reproduction Assessment

No live high-confidence repro was completed: importing the script in this checkout fails before execution because `typescript` is not installed. Source inspection does show the repeated-call failure path because `main()` appends extension package paths into a module-global array before `buildMissingPackages()` reads it.

## Solution Assessment

Yes, the proposed fix shape is the best narrow repair: make the base package list immutable, collect a fresh list per run, and pass it to the only missing-package builder call. De-duplicating only inside the existing global reader would mask the mutation instead of removing it.
