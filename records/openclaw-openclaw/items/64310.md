## Best Possible Solution

Land this narrow script fix after a current-main refresh, contributor-provided real behavior proof, and preferably a focused idempotency regression test.

## Reproduction Assessment

## Solution Assessment

Yes, this is the best narrow fix shape: keep the base package list immutable, collect a fresh list per run, and pass it into the only missing-package builder call. A downstream de-duplication-only fix would hide the mutable state instead of removing it.
