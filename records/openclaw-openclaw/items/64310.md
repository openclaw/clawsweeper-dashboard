## What This Changes

The PR makes `scripts/audit-seams.mjs` collect workspace package paths per `main()` invocation and pass them into missing-package analysis instead of mutating a module-global list.

## Best Possible Solution

Land the narrow script fix after the contributor adds redacted after-fix terminal proof and refreshes the branch; a focused regression guard for repeated in-process `main()` calls would make the fix more durable.

## Reproduction Assessment

Yes, from source inspection: current main exports `main()`, appends extension package paths to a module-global array, and later reads that same array for `missingPackages`. I did not establish a live failing run because the checkout lacks the `typescript` dependency needed to import the script.

## Solution Assessment

Yes, the proposed shape is the narrow maintainable fix: keep the base list immutable, collect a fresh list per run, and pass it to the only missing-package builder call. De-duping only inside `buildMissingPackages()` would mask the global mutation instead of removing it.
