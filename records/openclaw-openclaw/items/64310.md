The branch makes `scripts/audit-seams.mjs` collect workspace package paths per `main()` invocation and pass them into missing-package scanning instead of mutating a module-global list.

## Best Possible Solution

Land the localized workspace-package-path fix after the contributor refreshes the branch and adds real before/after proof; a focused idempotency regression test would make the script invariant durable.

## Reproduction Assessment

Yes, at source level: import `main` and call it twice in one Node process; current main appends extension package paths into the same module-global list before missing-package scanning. I did not run a live before/after command in this read-only review, and the PR body lacks contributor proof.

## Solution Assessment

Yes, this is the best fix shape: computing a fresh path list per invocation removes the shared mutable state at the source. De-duplicating only inside `buildMissingPackages()` would hide duplicate output while preserving the underlying mutation.
