The branch changes `scripts/audit-seams.mjs` so workspace package paths are collected as a fresh de-duplicated list per `main()` call and passed into `buildMissingPackages`.

## Best Possible Solution

Land this narrow fix, or a maintainer refresh of it, after redacted terminal/log proof and a current-main refresh; adding a focused repeated-`main()` regression test would make the script contract durable.

## Solution Assessment

Yes, the proposed shape is the narrow maintainable fix: keep the base list immutable, collect a fresh package path list per run, and pass that list to the only missing-package builder call. The remaining gap is proof and a possible regression test, not a different code layer.
