## Best Possible Solution

Land this scoped script-state fix after a current-main refresh and after-fix proof, ideally with a focused idempotency test or redacted terminal output showing repeated in-process runs stay stable.

## Reproduction Assessment

## Solution Assessment

Yes, the proposed shape is the narrow maintainable fix: keep the base list immutable, collect a fresh list per run, and pass it to the only missing-package builder call. The remaining blockers are proof, branch refresh, and ideally regression coverage rather than a different code layer.
