## Summary

Keep open: current main and the latest release still expose only the global Microsoft Teams streaming mode and gate native Teams streaming on `conversationType === "personal"`, so the requested Copilot-only path remains a real product/config decision.

## What This Changes

Request per-surface Microsoft Teams streaming configuration so Copilot custom-engine conversations can stream while Teams DMs, group chats, and channels stay non-streaming.

## Best Possible Solution

Add a plugin-local, backward-compatible Teams streaming surface override only after live Copilot activity metadata proves a stable detector; keep global streaming as the fallback and document any best-effort limits.
