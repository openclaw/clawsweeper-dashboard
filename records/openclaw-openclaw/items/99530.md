## What This Changes

The PR adds an OpenClaw lifecycle-command classifier and uses it to force explicit approval before gateway-host, node-host, and direct `system.run` exec paths can run gateway/daemon lifecycle mutations.

## Best Possible Solution

Keep the lifecycle classifier internal to core exec approval policy, revert the SDK surface budget increases, and refresh current-head proof that lifecycle mutations gate before durable allowlist or auto-review while read-only and yolo-mode paths still behave as intended.

## Solution Assessment
