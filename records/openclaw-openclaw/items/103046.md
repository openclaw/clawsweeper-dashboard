## Summary

## What This Changes

This PR adds a 10 MB `Content-Length` guard inside the embedded bundle LSP stdio message parser.

## Best Possible Solution

Bound the LSP parser by either failing/disposing the session on invalid or oversized `Content-Length`, or by tracking and draining the declared body bytes before resuming normal parsing, with focused coverage and real runtime proof.
