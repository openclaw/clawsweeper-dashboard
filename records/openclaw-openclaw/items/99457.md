## What This Changes

The issue reports that plugin-bound `missing_plugin`/`no_handler` fallback can drop unmentioned messages before always-on group/channel dispatch sees them.

## Best Possible Solution

Land a policy-aware dispatch fix that suppresses only mention-required plugin fallback while allowing `requireMention: false` routes to continue into normal agent dispatch.

## Reproduction Assessment

Yes. Source inspection shows the current `missing_plugin`/`no_handler` branch returns before policy-aware dispatch whenever `ctx.WasMentioned === false`.

## Solution Assessment

Yes. The best fix is to gate this fallback on the existing effective mention-policy resolver, not raw mention state or unconditional fallthrough.
