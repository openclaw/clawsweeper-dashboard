## Summary

Keep open: current main and v2026.6.11 still expose completed-call cost and usage by provider/model/session, but not by the resolved auth profile that paid for the call.

## What This Changes

Request native per-call cost visibility that attributes each completed model call to the resolved auth profile and exposes fallback/profile cost information through transcript, status, or events.

## Best Possible Solution

Define one additive, privacy-safe completed-model-call attribution contract that records resolved authProfileId and cost metadata, then derive transcript, status, gateway/API/UI, diagnostics, and plugin views from that source.
