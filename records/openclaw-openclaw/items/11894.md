## Summary

Keep open: current main and v2026.6.11 still join cost/usage to provider and model, but not to the resolved auth profile that paid for each completed call. Related usage-ledger and plugin-observer work is useful, but it does not replace native auth-profile attribution.

## What This Changes

Request native per-call cost tracking that records the resolved auth profile, aggregates cost by profile, and signals profile fallback/rotation.

## Best Possible Solution

Define one additive, privacy-safe completed-model-call attribution contract that records resolved authProfileId and cost metadata, then derive transcript, status, gateway/API/UI, diagnostics, and plugin views from that source.
