## Summary

Keep open: current main and v2026.6.11 still expose usage and cost by provider/model/session, but not by the resolved auth profile that paid for each completed call. Related ledger, OpenRouter exact-cost, tokenomics, and plugin model-usage work is useful context but does not replace native auth-profile attribution.

## What This Changes

The issue requests per-call cost visibility tied to the resolved auth profile, especially when fallback moves a call from a free profile to a paid profile.

## Best Possible Solution

Define one additive, privacy-safe completed-model-call attribution contract that records the resolved authProfileId and cost metadata, then derive transcript, status, gateway/API/UI, diagnostics, and plugin views from that source.
