## What This Changes

Prevent plain `openclaw memory status --json` from calling a healthy GitHub Copilot vector index mismatched solely because its embedding provider has not initialized.

## System Context

Memory Core stores an agent’s vector-index identity when indexing content, then the memory status command compares that stored identity with the configured embedding setup. Plain status avoids expensive provider initialization, while deep/index status may initialize the provider and obtain a resolved model identity.

## Architecture Diagram

  B --> D

  F --> D

## Best Possible Solution

Make non-deep status represent an unresolved configured vector-provider identity as pending or obtain a provider-owned stable identity without network initialization, while preserving correct comparisons for indexes built under explicit and implicit model configuration.
