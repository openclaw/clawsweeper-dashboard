## Summary

This PR is still necessary because current main leaves all three device-code HTTP operations unbounded beyond caller cancellation. No blocking correctness or security finding remains; the patch is well-proven and should stay open for routine OpenAI auth-owner review and exact-merge-head validation.

## What This Changes

Adds 30-second fetch-and-body deadlines to OpenAI device-code authentication, retries timed-out authorization polls within the existing 15-minute window, preserves caller cancellation, and expands regression coverage.

## Best Possible Solution

Land the bounded operation-timeout implementation after refreshing it against current main, retaining caller cancellation precedence and retrying only authorization-poll operation timeouts within the existing overall deadline.
