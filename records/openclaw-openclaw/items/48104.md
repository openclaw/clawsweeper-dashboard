## Summary

Keep open: current main has a narrow Anthropic Fable 5 server-side fallback and provider-refusal observability, but it still does not define the requested trusted-operator contract for authorized SSH/read-only infrastructure diagnostics or fully separate model soft refusal from tool/auth failure.

## What This Changes

The issue asks OpenClaw to respect explicitly authorized operator intent for read-only infrastructure diagnostics and make model refusal, authorization denial, and tool failure visibly distinct.

## Best Possible Solution

Define a narrow, security-reviewed trusted-operator diagnostics contract that records model refusal versus auth/tool failure and biases read-only infrastructure diagnostics toward execution only inside existing operator scopes, tool policy, and exec approval boundaries.
