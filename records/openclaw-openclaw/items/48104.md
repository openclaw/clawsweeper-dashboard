## Summary

Keep open: current main only has a generic execution-bias prompt plus a narrow Anthropic Fable 5 provider-side fallback, while the requested trusted-operator SSH/read-only diagnostics contract and model-refusal-vs-auth/tool-failure visibility remain unresolved.

## What This Changes

The issue requests clearer handling when model safety behavior blocks explicitly authorized operational work such as SSH diagnostics, including visibility into model refusal versus auth or tool failure.

## Best Possible Solution

Define a security-reviewed trusted-operator diagnostics contract that records model refusal versus auth/tool failure and biases read-only infrastructure diagnostics toward execution only inside existing scopes, tool policy, sandbox, and exec approval boundaries.
