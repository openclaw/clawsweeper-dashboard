## Summary

Keep open: current main only covers a narrow Anthropic Fable 5 provider-side fallback path, while the broader trusted-operator SSH/read-only diagnostics contract and refusal-vs-auth/tool failure distinction remain unresolved and need maintainer security/product direction.

## What This Changes

The issue asks OpenClaw to distinguish model soft refusals from permission/tool failures and to better support explicitly authorized read-only operational diagnostics such as SSH troubleshooting.

## Best Possible Solution

Define a narrow, security-reviewed trusted-operator diagnostics contract that records model refusal versus auth/tool failure and biases read-only infrastructure diagnostics toward execution only inside existing operator scopes, tool policy, and exec approval boundaries.
