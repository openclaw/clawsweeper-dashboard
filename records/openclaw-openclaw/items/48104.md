## Summary

Keep open: current main covers a narrow Anthropic Fable 5 refusal fallback and exposes provider-refusal diagnostics, but it still does not define the requested trusted-operator/read-only infrastructure diagnostics contract or a clear model-refusal versus SSH/tool/auth failure path.

## What This Changes

The issue requests better handling and observability when model safety behavior blocks explicitly authorized read-only operational work such as SSH diagnostics.

## Best Possible Solution

Define a narrow, security-reviewed trusted-operator diagnostics contract that records model refusal versus auth/tool failure and biases read-only infrastructure diagnostics toward execution only inside existing operator scopes, tool policy, and exec approval boundaries.
