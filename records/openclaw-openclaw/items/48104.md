## Summary

Keep open: current main only covers a narrow Anthropic Fable 5 server-side fallback path, while the broader trusted-operator SSH/read-only diagnostics contract and generic/OpenAI refusal behavior remain unresolved product and security work.

## What This Changes

The issue requests a trusted-operator path and observability so explicitly authorized read-only infrastructure diagnostics are not confused with model/provider refusals or SSH/tool/auth failures.

## Best Possible Solution

Define a narrow, security-reviewed trusted-operator diagnostics contract that records model refusal versus auth/tool failure and biases read-only infrastructure diagnostics toward execution only inside existing operator scopes, tool policy, and exec approval boundaries.
