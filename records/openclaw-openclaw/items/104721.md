## Summary

This is a credible core tool-result delivery regression, not a stale or duplicate report. In v2026.6.11 the OpenAI Responses conversion maps any tool result without a top-level text block to the image placeholder, while current main has a shared serializer that preserves structured result blocks; however, the report says ordinary outputs and multiple models remain affected, so current main cannot yet be declared fixed without the failing session content shape or a current-main reproduction. Likely related people: @snowzlmbot (high confidence, introduced structured-result replay preservation), @steipete (high confidence, recent shared AI runtime/conversion owner), and @vincentkoc (medium confidence, recent adjacent provider conversion work).

## What This Changes

Fix the regression that replaces model-facing tool result content with the literal “(see attached image)” placeholder across tools, models, and sessions.

## Best Possible Solution

Capture the failing tool-result block before provider conversion, then enforce one shared invariant across transports: explicit text and structured payloads serialize as model-visible text, genuine image/audio blocks use media placeholders and attachments, and malformed empty results surface a diagnostic rather than masquerading as an image; add focused replay tests for the captured Windows tray/session shape and an in-product Doctor/Fix recovery if persisted session state can be poisoned.
