## Summary

Keep open: current main and v2026.6.11 still reject blank optional integer params, and the linked open PR is the active fix candidate.

## What This Changes

The issue reports that optional Telegram reply/thread routing params emitted as blank strings are treated as invalid integers and can abort scheduled or agent-initiated message sends.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/100273, or an equivalent narrow fix that treats blank optional integer strings as absent while preserving rejection of invalid present values.
