## Summary

Keep open: current main and v2026.6.11 still reject blank optional integer routing params, and the linked open pull request is the candidate fix path. This issue should remain canonical until that PR or an equivalent narrow fix lands.

## What This Changes

The issue asks OpenClaw to treat blank optional Telegram reply/thread integer tool parameters as unset instead of aborting message delivery.

## Best Possible Solution

Keep this issue open as the canonical report, then close it after https://github.com/openclaw/openclaw/pull/100273 or an equivalent fix makes blank optional integer params absent while preserving rejection of real invalid values.
