## What This Changes

This PR makes session MCP tool catalogs with discovery diagnostics expire after five seconds so a recovered server is retried, while healthy catalogs remain stably cached and invalidation or disposal clears retry state.

## System Context

The agent runtime discovers tools from configured Model Context Protocol (MCP) servers and caches each session’s catalog. Combined session runtimes merge those per-server snapshots before exposing tools to agent turns, so an expired failed snapshot must be visible to both the individual and combined cache paths.
