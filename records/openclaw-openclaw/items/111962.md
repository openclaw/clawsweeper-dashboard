## What This Changes

This PR changes session MCP tool-catalog caching so catalogs containing discovery diagnostics are retried after a five-second cooldown, while healthy catalogs remain stably cached.

## System Context

OpenClaw’s session MCP runtime discovers tools from configured MCP servers and passes the resulting catalog to the agent runtime. The combined MCP runtime merges those per-server catalogs, so retry and cache semantics determine whether recovered servers become available during later agent turns.
