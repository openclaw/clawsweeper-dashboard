## What This Changes

The PR retries session MCP tool catalogs that contain discovery diagnostics after a five-second cooldown, while preserving stable caching for healthy catalogs and keeping healthy sibling servers available during recovery.

## System Context

The session MCP runtime starts configured MCP servers and discovers their tool catalogs for an agent session. A combined runtime merges catalogs from multiple servers, and the resulting tools and diagnostics determine what the next agent turn can use.
