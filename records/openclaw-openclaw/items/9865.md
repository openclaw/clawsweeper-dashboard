Keep open. Current main and v2026.6.11 still lack first-class provider Batch API routing for delayed/background agent turns, and the related closed reports are duplicate or narrower context rather than shipped fixes.

## What This Changes

## Best Possible Solution

Define an additive delayed/batch agent-turn contract in provider runtime and the Plugin SDK, then expose explicit background opt-ins with provider implementations, docs, accounting, cancellation, fallback, and delivery semantics.
