## What This Changes

This PR aggregates each captioned item in an incoming Telegram media album into the agent turn while preserving Telegram formatting entities and group mention/control-command behavior.

## System Context

Telegram's inbound album buffer collects individual Bot API messages before dispatching one combined agent turn. This change derives album text and mention authorization from the original item captions, then passes the synthesized message and associated media into the existing Telegram reply-chain processing path.
