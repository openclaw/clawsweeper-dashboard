## Summary

Keep this PR open for maintainer review. The patch is a narrow, coherent repair for a Gateway-mode local-media allowlist bypass, has focused coverage and credible terminal proof, but deliberately changes upgrade behavior: existing Gateway-mode sends from paths outside configured roots will start failing with `LocalMediaAccessError`.

## What This Changes

The PR passes agent-scoped local-media roots into Gateway durable message delivery so gateway-mode channel sends enforce the configured local-file allowlist.

## System Context

The `message send` CLI can route channel delivery through the Gateway RPC server. The Gateway handler prepares an outbound message, hands it to durable channel delivery, and that delivery path resolves which local files it may read before sending media to a channel.

## Architecture Diagram

  C --> D[Durable outbound delivery]
  D --> E[Local-media access resolver]
  E --> F[Channel plugin delivery]
  F --> G[Media sent or rejected]

## Best Possible Solution

Retain the explicit root handoff and focused regressions, then merge once an owner confirms that Gateway-mode sends must enforce the documented configured-root boundary even for existing out-of-root workflows.
