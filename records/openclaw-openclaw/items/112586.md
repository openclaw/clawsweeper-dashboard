## Summary

## What This Changes

The PR passes agent-scoped local-media roots from the Gateway send handler into durable message delivery and adds a gateway test asserting that the media-access object reaches delivery.

## System Context

`openclaw message send --media` can enter through the Gateway for gateway-mode channels, then flows into shared durable outbound delivery. That delivery path resolves local-file access rules before channel plugins load the attachment, so the roots passed at the Gateway boundary determine whether a local path is allowed.
