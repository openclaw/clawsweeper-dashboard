## Summary

Keep this PR open for normal merge review. The patch addresses the linked Gateway-mode authorization gap by supplying the already-computed agent-scoped roots to durable delivery; it is narrow, matches the downstream resolver contract, and the updated PR body now includes credible after-fix terminal evidence. The remaining merge consideration is intentional compatibility: Gateway-mode sends that previously accepted out-of-root files will now reject them under the documented allowlist boundary.

## What This Changes

This PR passes the Gateway handler’s agent-scoped local-media roots into durable outbound delivery so Gateway-mode channels enforce the same local-file allowlist as direct-mode channels, with focused regression tests.

## System Context

`openclaw message send --media` can dispatch through the Gateway for channels configured for Gateway delivery. The Gateway handler passes an outbound payload to durable delivery, which resolves allowed local media roots before a channel plugin reads and sends the attachment.
