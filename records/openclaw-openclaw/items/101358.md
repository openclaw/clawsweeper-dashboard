## Summary

Keep this PR open: the Podman backend remains useful and is not implemented on current main, and the earlier sandbox-explain and documentation findings are fixed. The PR adds a Podman local-container sandbox backend through a shared Docker/Podman engine abstraction, including automatic engine selection, lifecycle management, policy and doctor integration, Codex network-policy mapping, documentation, and tests.

## Best Possible Solution
