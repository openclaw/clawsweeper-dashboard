## What This Changes

Adds Podman as an explicit built-in agent-sandbox backend that shares the existing local-container configuration while preserving Docker-only selection, browser sandboxing, and Docker error behavior.

## System Context

OpenClaw’s agent sandbox selects a backend before running isolated tools. This change adds Podman beside Docker at the local-container boundary, then carries the selected backend through container lifecycle management, policy/Doctor checks, and Codex’s external-sandbox network policy.
