## What This Changes

This PR adds `podman` as an explicit built-in local container backend for agent sandboxes, reusing Docker-compatible sandbox settings while preserving Docker-only selection as the default.

## System Context

OpenClaw resolves an agent’s sandbox configuration, selects a registered backend, creates or reuses an isolated runtime, and exposes its shell/filesystem tools to agent providers. This change adds Podman to that local-container path so agent tool calls can run in a native Podman container while policy, doctor, registry, and Codex integration retain the configured backend identity.
