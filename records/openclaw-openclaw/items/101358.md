## What This Changes

Adds Podman as an explicit built-in backend for OpenClaw’s local agent container sandbox, sharing Docker-compatible container settings while preserving Docker-only selection as the default.

## System Context

Agent sandbox configuration selects a backend that creates and manages isolated environments for tool execution. The proposed Podman backend joins Docker at the local-container boundary, then feeds its resolved backend identity into sandbox lifecycle management, policy/Doctor checks, and Codex’s external-sandbox network policy.
