## What This Changes

The PR passes Slack’s configured default agent into thread-context freshness resolution so legacy or global unqualified session keys can refresh the intended session.

## System Context

Slack thread-context preparation asks the shared session layer whether a stored thread session is fresh before assembling prior thread history. The shared resolver derives the session owner from the key or, when Slack knows it, the configured default agent; that result controls whether Slack seeds or refreshes thread context.
