Fix the all-agent `usage.cost` fanout reported in https://github.com/openclaw/openclaw/issues/101552. In `src/gateway/server-methods/usage.ts`, replace the unbounded `Promise.all(agentIds.map(...loadCostUsageSummaryFromCache...))` in `loadAllAgentCostUsageSummary` with the existing `runTasksWithConcurrency` helper and a bounded limit consistent with the nearby `SESSIONS_USAGE_AGENT_LOAD_CONCURRENCY` usage. Preserve response ordering/aggregation behavior, do not add a config/env option, and do not broaden this into the separate Gateway usage-cache storage/isolation work tracked by https://github.com/openclaw/openclaw/issues/86718. Add focused regression coverage in the usage handler tests that creates many agents with delayed loaders and asserts peak concurrent per-agent loads stay at or below the chosen cap while all agents still contribute to totals.
