## Summary

Keep open: current main and the latest release still run `usage.cost` all-agent aggregation through unbounded `Promise.all`, while three linked open pull requests are only candidate fixes until one lands.

## What This Changes

The issue asks OpenClaw to bound all-agent `usage.cost` aggregation so large usage-dashboard loads do not fan out unbounded per-agent usage cache or storage work.
