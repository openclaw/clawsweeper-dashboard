## Summary

Keep open: current main and v2026.6.11 still run `usage.cost` all-agent aggregation through unbounded `Promise.all`, and the proof-positive fix candidate at https://github.com/openclaw/openclaw/pull/101589 is open but not merged.

## What This Changes

The issue asks OpenClaw to bound `usage.cost` all-agent usage aggregation so loading the usage dashboard cannot start one cache/database task per configured agent.

## Best Possible Solution

Review and land the narrow bounded-concurrency fix in https://github.com/openclaw/openclaw/pull/101589, then close this issue while leaving broader Gateway usage/cost isolation work to https://github.com/openclaw/openclaw/issues/86718.
