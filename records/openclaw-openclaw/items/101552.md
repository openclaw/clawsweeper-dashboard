## Summary

Keep open: current main and the latest release still run all-agent `usage.cost` aggregation through unbounded `Promise.all`, and the issue is now paired with open fix candidates, especially https://github.com/openclaw/openclaw/pull/101589.

## What This Changes

Bound the all-agent `usage.cost` aggregation so loading the usage dashboard does not start one usage-cache load per configured agent at once.

## Best Possible Solution

Land one narrow bounded-concurrency fix in `loadAllAgentCostUsageSummary`, with regression coverage for peak in-flight loads and unchanged aggregation semantics; leave broader workload isolation to the existing Gateway memory-pressure tracker.
