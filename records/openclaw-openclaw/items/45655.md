Keep open. Current main has improved input-modality schema handling, but the central Poe media-output session-runtime problem remains unresolved: chat model metadata still has no output-modality contract, while image/video generation is routed through separate provider-tool settings.

## What This Changes

The issue requests clear rejection/diagnostics or first-class support for Poe/custom-provider image- and video-output models that can be configured but fail or fall back at runtime.

## Best Possible Solution

Define one explicit contract: either reject media-output chat models with clear diagnostics while documenting separate generation tools, or add first-class output-modality metadata and route supported image/video generation through provider capabilities and channel renderers.
