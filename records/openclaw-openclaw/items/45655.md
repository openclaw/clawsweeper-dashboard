## Summary

Keep open. Current main and the latest release still lack a chat/session output-modality contract for Poe image/video-output models, while the supported media path is separate generation tooling, so the confusing configured-model failure/fallback behavior remains a maintainer product decision rather than resolved cleanup.

## What This Changes

Request clear rejection/diagnostics or first-class support for Poe image/video-output models that can be configured but fail or fall back in chat sessions.

## Best Possible Solution

Define the chat model output contract, with a short-term clear unsupported-media-output diagnostic for chat/session selection and media generation routed through typed image_generate/video_generate provider capabilities until first-class chat media output is designed.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should OpenClaw reject non-text-output models when they are configured as chat/session models, or add first-class output-modality metadata and runtime support for image/video output?

Rationale: Both paths are plausible, but the choice changes public config semantics, provider/tool ownership, fallback behavior, and channel rendering expectations.

Likely owner: steipete

Owner reason: Recent history shows the broadest work across provider/model registry, media-generation docs, and plugin SDK boundaries touched by the decision.

Owner confidence: medium

Options:

- **Reject unsupported chat output now (recommended):** Add a clear diagnostic for image/video-output models selected as chat/session models and direct users to image_generate or video_generate until first-class support exists.
- **Add output-modality support:** Extend config/catalog metadata plus runtime and channel handling so selected session models can intentionally produce image/video outputs.
- **Docs-only clarification:** Document that media generation must use the generation tools while leaving current custom-provider behavior unchanged, accepting continued runtime confusion.
