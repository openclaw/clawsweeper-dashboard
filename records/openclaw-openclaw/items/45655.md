## Summary

Keep open: current main and v2026.6.11 still lack a chat/session output-modality contract or clear unsupported-media-output diagnostic for Poe image/video-output models; related input-modality work does not cover the reported output/runtime behavior.

## What This Changes

Request clear support or rejection for Poe image/video-output models configured as chat/session models, including Nano Banana image generation failures and Veo/Sora fallback behavior.

## Best Possible Solution

Define one canonical output-modality policy: either reject non-text chat/session models with a clear diagnostic and docs, or add first-class image/video output routing through the generation tools and channel delivery paths.
