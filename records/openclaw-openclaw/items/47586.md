## Summary

Keep open: current main and the latest release still match plain memory promises as reminder commitments, and two open linked PRs already own candidate fixes rather than a merged implementation.

## What This Changes

The issue asks for the reminder guard to stop treating plain memory promises such as `I'll remember that` as unscheduled reminder commitments while preserving real temporal reminder detection.

## Best Possible Solution

Land or replace a focused linked PR that excludes plain memory promises while preserving genuine reminder-action phrasing, with broader cron-success problems tracked separately.

## Reproduction Assessment

Yes. Source inspection and a direct regex probe show current main still matches plain memory promises, and the reply runner appends the note when matched reply text has zero successful cron adds and no covering session cron.

## Solution Assessment

Yes on direction: the narrow maintainable solution is to adjust the existing reminder-guard matcher and add regression coverage. The separate cron-success/session-state suppression bugs should remain on their own linked tracks.
