## What This Changes

This PR adds a Git push preflight script, package command, tests, and contributor guidance intended to block unsafe branch publication from local checkouts.

## System Context

The contributor workflow moves a local Git branch through repository hooks and `git push` to a remote. This checker reads local Git configuration and tracked-path history to decide whether that publication should be blocked before network transfer.
