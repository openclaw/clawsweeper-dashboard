## Summary

Keep this PR open. The branch adds an opt-in command and documentation, but it does not connect that command to Git’s pre-push lifecycle, so ordinary `git push` bypasses the claimed fail-closed protection; the latest PR body also still lacks inspectable after-fix proof of a blocked push and an allowed fork push.

## What This Changes

The PR adds a Git preflight script, package command, tests, and contributor guidance intended to detect unsafe branch publication before a contributor pushes.

## System Context

Contributor Git configuration and the current branch’s tracked files determine where `git push` sends commits. This proposed preflight reads those local facts and reports unsafe targets or sensitive paths before publication, but it must be invoked by the push lifecycle to intercept a normal push.
