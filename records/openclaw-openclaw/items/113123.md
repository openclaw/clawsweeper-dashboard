## Summary

Keep this PR open, but it is not ready to merge: the new command is only exposed as `pnpm git:push-preflight` and documented as a manual step, so an ordinary `git push` never invokes it. That leaves the stated fail-closed pre-push protection bypassable by the exact accidental publication path this PR aims to prevent.

## What This Changes

The branch adds a Git preflight script, a package command, tests, and contributor documentation to identify unsafe local publication settings and paths before a contributor pushes.

## System Context

This is contributor-side repository tooling rather than OpenClaw runtime behavior. It reads a local checkout’s branch, remotes, Git configuration, tracked files, and unpublished history, then should stop or warn before a branch reaches a remote.
