## Summary

This PR remains necessary only if it becomes an actual push-lifecycle guard. The current branch adds an opt-in `pnpm git:push-preflight` command, but ordinary `git push` does not invoke it, so it cannot provide the stated fail-closed protection against publishing contaminated history or sensitive local paths. The previous ClawSweeper lifecycle finding remains unresolved at the current head. It also still needs inspectable, redacted real-behavior proof of a blocked unsafe push and an allowed safe fork push.

## What This Changes

The branch adds a Git preflight checker, a package command, tests, and contributor documentation intended to prevent unsafe publication of local branches.

## System Context

The contributor Git workflow runs local repository hooks and package scripts before code reaches a remote. This proposed checker reads branch, remote, push-default, and tracked-path facts and should decide whether publication is allowed before `git push` sends commits to a remote.
