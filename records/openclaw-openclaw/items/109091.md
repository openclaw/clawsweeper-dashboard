## What This Changes

The PR gives Codex Computer Use's macOS `/bin/ps` inspection a two-second deadline, preserves fail-closed cleanup on timeout, and adds focused timeout and fixture-regression coverage.

## System Context

Codex Computer Use runs inside the Codex extension and periodically inspects the local macOS process table to identify verified stale MCP children. The inspection result feeds cleanup and retry logic used during setup readiness and health checks, so a stalled process command can otherwise hold those flows indefinitely.
