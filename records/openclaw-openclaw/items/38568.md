## Summary

Keep open: current main and v2026.6.11 still omit passive context-window usage from the system-prompt Runtime line, and the open broader runtime self-context issue does not yet replace this narrower product-decision tracker.

## What This Changes

Request to inject current context-window usage percentage or token/window metadata into the system-prompt Runtime section so agents can see context pressure without calling session_status every turn.

## Best Possible Solution

Define the snapshot freshness and formatting contract, then either add a bounded Runtime context field below the prompt cache boundary using existing session usage accounting, or explicitly document that status/context tools are the intended boundary.
