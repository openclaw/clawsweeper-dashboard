## What This Changes

Request to add passive context-window usage, such as context=49%, to the agent system prompt Runtime metadata so agents do not need to call session_status every turn.

## Best Possible Solution

Define the freshness and display contract first, then either add a bounded Runtime context segment using existing session usage accounting with focused prompt/runner/status/docs coverage, or explicitly keep context usage on status/tool surfaces only.
