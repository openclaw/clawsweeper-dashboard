## Summary

Keep open: current main and v2026.6.11 still omit passive context-window usage from the system-prompt Runtime line, while existing status/session tools expose context usage only through explicit inspection and the duplicate reports point back here as the narrow tracker.

## What This Changes

The issue requests adding context-window usage to the system prompt Runtime metadata so agents can see context pressure without calling `session_status` each turn.

## Best Possible Solution

Define the snapshot freshness and formatting contract, then add a bounded Runtime context segment below the cache boundary using existing session usage accounting with focused prompt, runner, status, compaction, and model-switch coverage.
