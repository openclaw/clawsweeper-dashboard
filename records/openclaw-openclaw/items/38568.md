## Summary

Keep open: current main and v2026.6.11 still omit passive context-window usage from the system-prompt Runtime line, and this remains the narrow canonical tracker while broader runtime self-context work is only partial overlap.

## What This Changes

Request to inject current context-window usage percentage or token budget into the system-prompt Runtime section so agents can see it without calling `session_status` every turn.

## Best Possible Solution

Define the snapshot freshness and formatting contract, then add a bounded `context=` Runtime segment using existing session usage accounting with focused prompt, runner, status/context, model-switch, compaction, and cache-boundary coverage.
