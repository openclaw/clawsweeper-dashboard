## Summary

Keep open: current main and v2026.6.11 still omit passive context-window usage from the system-prompt Runtime line, and this remains a product decision rather than a stale or already-implemented request.

## What This Changes

Request to inject current context-window usage percentage or token/window count into the system-prompt Runtime metadata so agents can see it without calling `session_status`.

## Best Possible Solution

Maintainers should decide the prompt contract, then implement a bounded Runtime-line field from the latest reliable session token snapshot below the stable cache boundary, with focused tests for fresh, stale, and unknown usage.
