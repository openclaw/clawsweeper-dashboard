## Summary

Keep open: current main and the latest release still omit passive context-window usage from the system-prompt Runtime line, and this issue is the canonical narrow tracker after related duplicates were closed here. The remaining choice is product/API direction, not missing reproduction data.

## What This Changes

The issue requests adding current context-window usage, such as `context=49%`, to the per-turn system-prompt Runtime metadata.

## Best Possible Solution

Define the prompt exposure contract first, then either add a fresh-only `context` Runtime field from the existing session token snapshot path or fold the behavior into the broader runtime self-context design.
