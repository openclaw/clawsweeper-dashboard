## Summary

Keep open: current main and v2026.6.11 still omit passive context-window usage from the system-prompt Runtime line, and the broader runtime self-context issue is only a partial overlap rather than a safe replacement for this narrow product decision.

## What This Changes

The issue requests adding context-window usage percentage to the system prompt Runtime metadata so agents can see context pressure without calling session_status.

## Best Possible Solution

Define the snapshot freshness and formatting contract, then add a bounded Runtime context segment below the prompt-cache boundary using existing session usage accounting with focused prompt, runner, status, and compaction coverage.
