## Summary

Keep this PR open for contributor proof. The patch appears to correctly preserve the resolver contract by distinguishing an explicit `null` rejection from an absent resolver result, and the linked issue remains the canonical bug report, but the external PR currently supplies only focused unit-test output rather than after-fix behavior from a real plugin setup.

## What This Changes

The PR makes inbound claim hook mapping suppress generic conversation-ID fallback when a channel plugin explicitly returns `null`, and adds regression coverage for context and event payloads.

## Best Possible Solution
