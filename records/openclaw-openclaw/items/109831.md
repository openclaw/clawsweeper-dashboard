## Summary

Keep open: the report describes a distinct process-exit regression on the shared startup-refusal path, while the related issues cover migration triggers or lease behavior rather than the observed SIGSEGV. ## What This Changes

Make gateway startup-migration refusal terminate with a clean non-zero status instead of SIGSEGV and a supervisor crash loop.

## Best Possible Solution

Make startup refusal unwind every partially initialized channel, sidecar, signal handler, and lease before returning a typed exit status of 1; add a child-process regression that exercises the refusal with representative channel/sidecar initialization and proves both exit status and supervisor-stable cleanup, plus expose a pre-restart Doctor/Fix recovery action where the update UI is available.
