## What This Changes

The branch consolidates several agent-runtime helpers, removes retired branches and a request-time orphan-session migration fallback, and deletes a deprecated agent-harness lifecycle option.

## System Context

Agent execution enters through CLI, gateway, and embedded TUI startup paths, which prepare session state before runs dispatch. The agent-harness runtime exposes execution controls to plugin and integration callers, then forwards those controls into individual embedded-run attempts.
