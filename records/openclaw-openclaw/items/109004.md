## Summary

Keep open: the fix direction matches the linked source-backed bug, but the package transport classifies commentary before its existing stop-reason recovery, which can suppress a valid final answer, and the PR provides tests rather than after-fix real chat proof.

## What This Changes

The PR tags text in Chat Completions tool-use turns as commentary and buffers unclassified streamed deltas so pre-tool narration is not delivered to chats.

## Best Possible Solution

Classify text only after final tool-call/stop-reason reconciliation and only when an actual tool-use turn remains, add regression coverage for tool-use-without-a-parsed-call and ordinary final answers, then provide redacted live channel proof.
