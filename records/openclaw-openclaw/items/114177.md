## Summary

Keep this PR open for a maintainer compatibility decision. The bounded name fixes the fresh-create limit and the submitted live report covers fresh reuse, but changing a deterministic runtime identifier means existing OpenShell sandboxes for the same scope will no longer be found; in remote mode those sandboxes hold the canonical workspace. The author explicitly leaves that identity transition unhandled, so this is not safe to merge as an unannounced compatibility break.

## What This Changes

The PR changes generated OpenShell sandbox names to a deterministic DNS-safe 19-character format and adds unit coverage for name bounds and fresh lifecycle reuse.

## System Context

The bundled OpenShell plugin maps an OpenClaw sandbox scope such as a session, agent, or shared scope to an OpenShell sandbox name, then uses that name to create, find, execute in, and clean up the remote sandbox. In remote workspace mode, the identified sandbox also owns the canonical workspace state used by later agent runs.
