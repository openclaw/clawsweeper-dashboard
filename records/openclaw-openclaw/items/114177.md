## Label Justifications

## Summary

Keep this PR open, but do not merge it as written: changing the deterministic runtime-ID format makes existing OpenShell sandboxes undiscoverable after upgrade and creates new sandboxes instead. The PR’s tests cover new-format creation and reuse only; they do not preserve or migrate the prior remote sandbox identity.

## What This Changes

The PR replaces scope-derived OpenShell sandbox names with deterministic DNS-safe names capped at 19 characters and adds unit coverage for the new naming format and lifecycle reuse.

## System Context

The OpenShell plugin converts an agent, session, or shared scope into a remote sandbox name, then looks up or creates that sandbox before running commands. That generated name is the stable identity used to reuse an existing remote workspace across backend instances.

## Best Possible Solution

Keep bounded names for newly created sandboxes, but preserve existing remote sandbox identity through an explicit plugin-owned adoption or migration plan, with upgrade coverage proving that a prior sandbox is reused rather than duplicated.
