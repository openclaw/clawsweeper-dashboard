## What This Changes

This PR adds a shared `node:sqlite` location classifier for ordinary Windows filesystem paths, applies it across OpenClaw-owned state and recovery database opens, and adds deep-path regression coverage and Windows CI routing.

## System Context

OpenClaw stores shared and per-agent runtime state in SQLite, then reopens those databases from startup, doctor, migration, maintenance, snapshot, and managed-update flows. The PR places one path-normalization boundary between those filesystem locations and Node’s synchronous SQLite constructor, while leaving SQLite URI and in-memory locations unchanged.
