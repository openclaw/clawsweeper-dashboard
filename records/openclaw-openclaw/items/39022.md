## Summary

Keep open: current main and v2026.6.11 still provide persistent session model selection, but not a multi-turn model lease with warning, auto-revert, or per-model turn-limit config. Related open items overlap on temporary model routing, but none replaces this product/API decision.

## What This Changes

Requested support for per-model turn limits that temporarily switch models and automatically revert after N turns.

## Best Possible Solution

Define one additive, session-owned temporary model lease contract across `/model` and any Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queued runs, retries, fallbacks, auth profiles, and live switches.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should OpenClaw define a session-owned multi-turn model lease contract for `/model --turns N`, and should that same contract also shape one-turn Gateway/chat model overrides?

Rationale: The request adds public command/API/config and persisted model-routing semantics; automation should not choose turn counting, warning timing, auth-profile preservation, fallback interaction, or overlap with one-turn override work without maintainer intent.

Likely owner: steipete

Owner reason: steipete has the strongest history signal on session patch, session controls, and model-selection boundaries that own this product/API choice.

Owner confidence: high

Options:

- **Specify a unified lease contract (recommended):** Define a maintainer-approved temporary model lease design first, then implement `/model --turns N` and any Gateway fields against that single session-state contract.
- **Settle one-turn override first:** Keep this issue open but use https://github.com/openclaw/openclaw/issues/83565 and https://github.com/openclaw/openclaw/pull/100876 to settle request-local override semantics before adding multi-turn leases.
- **Decline native leases:** Do not add native turn leases and document manual `/model default`, allowlists, or operational policy as the supported cost-governance path.

## Reproduction Assessment

Yes, at source level as a missing feature rather than a broken bug. Current `/model`, `sessions.patch`, and chat-send paths support persistent or unrelated per-run choices, but no N-turn lease with warning and auto-revert.

## Solution Assessment

Unclear until maintainers pick the product/API shape. The maintainable solution is likely a shared temporary model-lease primitive for command, chat, and session surfaces rather than an isolated command-only special case.
