## Label Justifications

- `P2`: This is a normal-priority model-routing feature with clear cost-governance value but no urgent regression in an existing shipped turn-limit contract.
- `impact:session-state`: The feature would add temporary model state, turn counters, warning state, and automatic reversion to session model selection.
- `impact:auth-provider`: The feature changes provider/model routing duration and must honor model visibility, auth profiles, and override-source semantics.

## Summary

Keep open: current main and the latest release still support persistent session model selection plus narrower one-turn fast/thinking overrides, but not an N-turn model lease with warnings, turn counting, configured max turns, and automatic reversion.

## What This Changes

Request support for `/model <name> --turns N` plus per-agent model turn limits that warn and auto-revert to the default model after N turns.

## Best Possible Solution

Define one session-owned temporary model lease contract covering slash commands, chat/session APIs, turn counting, warnings, auto-revert, provider/auth validation, docs, and tests before implementation.
