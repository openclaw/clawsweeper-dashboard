## Summary

Keep open: current main and the latest release still only support persistent model switches, while the requested N-turn lease with warning, automatic revert, and per-agent/per-model policy remains unimplemented and needs product/API direction.

## What This Changes

Add `/model <name> --turns N` plus per-model turn-limit configuration that temporarily switches models and automatically reverts to the default after N turns.

## Best Possible Solution

Define one canonical temporary-model override contract covering `/model`, `sessions.patch` or `chat.send`, warning/revert behavior, persistence, and config defaults before implementation.
