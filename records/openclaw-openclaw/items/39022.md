## Summary

Keep open: current main and the latest release still only support persistent session model overrides, not a `/model --turns N` lease with turn counting, warning, configured limits, and auto-revert. The related one-turn and image-specific items overlap, but they do not replace this broader product/API decision.

## What This Changes

Request support for temporary per-model turn limits via `/model <name> --turns N`, warning before expiry, auto-revert, and optional per-agent config.

## Best Possible Solution

Define one session-owned temporary model lease contract that covers `/model`, Gateway/session APIs, turn counting, warning/revert behavior, compatibility, docs, and tests before implementation.
