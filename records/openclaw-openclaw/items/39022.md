## Summary

Keep open: current main and v2026.6.11 still only provide persistent `/model` and `sessions.patch` model overrides, not an N-turn model lease with warning, auto-revert, or per-model turn-limit config. The related open items cover one-turn overrides, fallback persistence, or media-specific auto-revert, but none replaces this broader product/API decision.

## What This Changes

Request adds `/model <name> --turns N` with warning and auto-revert behavior plus per-agent/per-model turn-limit config.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any Gateway/session API, with explicit counting, warning/revert semantics, config docs, and tests for queues, cron, retries, fallbacks, auth profiles, and live switches.
