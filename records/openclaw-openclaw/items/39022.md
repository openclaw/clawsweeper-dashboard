## Summary

Keep open: current main and v2026.6.11 still support persistent `/model` and `sessions.patch` model overrides, but not an N-turn model lease with warning, auto-revert, or per-model turn-limit config.

## What This Changes

Request to add `/model <name> --turns N`, warning/revert behavior, and per-agent model turn-limit configuration.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and regression coverage.
