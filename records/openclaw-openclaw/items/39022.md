## Summary

Keep open: current main still lacks `/model <name> --turns N`, a turn-counted warning/revert lease, and the proposed per-agent model-limit config. Related one-turn, image-revert, and iteration-budget work overlaps, but none replaces this broader model-routing and session-state product contract.

## What This Changes

Add a temporary per-model turn limit so `/model <name> --turns N` warns near expiry and reverts to the session default after N turns.

## Best Possible Solution

Define one core model-lease contract that composes with persistent `/model`, request-local one-turn overrides, allowlist/auth validation, session state, warning delivery, config docs, and upgrade behavior before implementation.
