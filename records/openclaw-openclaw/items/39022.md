## Summary

Keep open: current main and v2026.6.11 still expose persistent `/model` and `sessions.patch` model overrides, but not the requested multi-turn model lease with turn counting, warning, auto-revert, or per-agent turn-limit config. The one-turn and image-specific related items are useful partial overlaps, not replacements for this request.

## What This Changes

Request adds `/model <name> --turns N` plus per-agent model turn limits, warning, and automatic revert to the default model after the limit.

## Best Possible Solution

Define one core model-lease contract that composes with persistent `/model`, the one-turn override proposal, allowlist/auth validation, session persistence, user notifications, and docs before implementing it.
