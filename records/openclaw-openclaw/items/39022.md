## Summary

Keep open: current main and v2026.6.11 still provide persistent `/model` and `sessions.patch` model overrides, but no N-turn model lease, warning threshold, automatic revert, or per-model turn-limit config. The related open issues overlap on temporary model routing, but none replaces this generic multi-turn lease request.

## What This Changes

Add `/model <name> --turns N` plus per-agent configuration so model selections automatically warn and revert after a bounded number of turns.

## Best Possible Solution

Define one additive, session-owned model lease contract across `/model`, session state, and any public API surface maintainers approve, with explicit turn counting, warning/revert semantics, docs, and regression coverage for queues, cron, fallbacks, auth profiles, and live switches.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers choose the product/API contract. The requested turn lease is plausible, but the maintainable path should be one session-owned lease mechanism rather than prompt enforcement, ad hoc config, or a second model-switch path.
