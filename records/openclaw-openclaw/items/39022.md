- `impact:session-state`: The requested behavior would add temporary model state, turn counting, warnings, and auto-revert behavior to session model overrides.

## Summary

Keep open: current main still supports persistent model overrides and some one-turn internal plumbing, but it does not implement the requested multi-turn `/model --turns` lease with turn counting, expiry warning, auto-revert, or per-agent model turn-limit configuration. The related one-turn and image-specific items are narrower partial overlaps, so this remains a product/API decision rather than a cleanup close.

## What This Changes

Request adding per-model turn limits so `/model <name> --turns N` temporarily switches models, warns before expiry, and auto-reverts to the session default after N turns.

## Best Possible Solution

Define one session-owned temporary model lease contract covering `/model --turns`, any gateway/session API surface, turn counting, expiry warnings, auto-revert, provider/auth validation, docs, and tests, with #83565 treated as the one-turn subset.
