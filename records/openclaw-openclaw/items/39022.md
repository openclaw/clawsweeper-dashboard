## Summary

Keep open: current main and v2026.6.11 still provide persistent model selection through `/model` and `sessions.patch`, but do not implement an N-turn model lease with warnings, auto-revert, or per-model turn-limit config. The related open issues overlap on one-turn overrides, fallback persistence, and media-specific auto-revert, but none replaces this broader product/API decision.

## What This Changes

Add `/model <name> --turns N` plus per-agent model limit config that reverts a session to its default model after the configured number of turns.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any exposed Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.
