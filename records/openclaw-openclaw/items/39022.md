## Summary

Keep open: current main still supports sticky session model overrides and one-turn fast-mode tuning, but not a multi-turn model lease with turn counting, warning, per-agent limits, and automatic revert. The overlapping one-turn and media-specific items are useful related work, but they do not replace this broader product/API decision.

## What This Changes

The issue requests `/model <name> --turns N` plus per-agent model turn limits that warn near expiry and revert to the default model after the limit.

## Best Possible Solution

Define one session-owned temporary model lease contract that covers `/model`, any Gateway/session API surface, turn counting, warning/revert behavior, provider/auth validation, compatibility, docs, and tests before implementation.
