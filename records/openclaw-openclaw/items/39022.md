## Summary

Keep open: current main and v2026.6.11 still provide sticky `/model` and persistent session model overrides, but not a turn-counted model lease with warning, configured caps, and automatic revert. The related one-turn and image-specific items overlap, but they do not replace this broader product/API decision.

## What This Changes

Request support for `/model <name> --turns N`, per-agent model turn caps, warning before expiry, and automatic revert to the default model.

## Best Possible Solution

Define one session-owned temporary model lease contract covering `/model`, Gateway/session APIs, turn counting, warning/revert behavior, provider/auth validation, compatibility, docs, and tests.
