## Label Justifications

- `P2`: This is a normal-priority model/session routing feature with real cost-governance impact but no urgent regression in existing shipped behavior.
- `impact:session-state`: The request adds turn-counted model leases and auto-revert behavior that would control session model state across later turns.
- `impact:auth-provider`: The requested lease controls provider/model selection for premium models and must respect model allowlists and auth-profile routing.

## Summary

Keep open: current main and the latest release still only support persistent session model overrides, while this request needs a new multi-turn model lease with counting, warning, auto-revert, and per-agent/config policy. The related one-turn and image-revert items are useful partial overlaps, not replacements for this broader contract.

## What This Changes

Add `/model <name> --turns N` plus per-agent model turn-limit config so temporary model switches warn and auto-revert after N turns.

## Best Possible Solution

Define one core model-lease contract that composes with persistent `/model`, the one-turn override proposal, allowlist/auth validation, session persistence, user notifications, and docs before implementing it.
