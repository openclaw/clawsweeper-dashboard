## Summary

Keep open: current main still has persistent `/model` and `sessions.patch` model override behavior, but no N-turn lease, warning, auto-revert, or per-model turn-limit config. The related one-turn override, fallback persistence, and image-revert items overlap but do not replace this broader multi-turn product/API request.

## What This Changes

Request support for `/model <name> --turns N` plus per-agent/per-model turn limits that warn and revert to the default model after the limit.

## Best Possible Solution

Define one additive session-owned model lease contract, then implement `/model --turns N`, config/schema/docs, warning/revert behavior, and focused tests against that single contract.
