## Summary

Keep open: current main and v2026.6.11 still only have persistent user `/model` and `sessions.patch` model overrides, not a multi-turn model lease with warning, auto-revert, or per-model turn-limit config. The related open items overlap on temporary model routing but do not replace this broader product/API decision.

## What This Changes

Add `/model <name> --turns N` plus per-agent/per-model config so temporary premium-model selections warn and revert after a bounded number of turns.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, retries, fallbacks, auth profiles, and live switches.

Rationale: The request adds public command, config, Gateway/session semantics, and persistent model-routing state; automation can identify the likely files, but should not choose the product contract for turn counting, warning timing, auth-profile preservation, and overlap with one-turn overrides.

Owner confidence: high

Options:

- **Specify a unified lease contract (recommended):** Define a maintainer-approved session lease design first, then implement `/model --turns N` and any Gateway shape against that single contract.
- **Defer to one-turn API first:** Keep this issue open but require https://github.com/openclaw/openclaw/issues/83565 to settle request-local model override semantics before multi-turn leases are designed.
- **Do not add native leases:** Reject native turn leases and document manual `/model default` or operator policy as the supported cost-governance path.
