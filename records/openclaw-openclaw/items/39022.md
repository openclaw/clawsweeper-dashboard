## Summary

Keep open: current main still supports persistent model/session overrides and limited one-turn fast-mode/heartbeat paths, but it does not implement an N-turn `/model` lease, warning, auto-revert, or per-model turn-limit config. The related one-turn, fallback-persistence, and image-revert items overlap but do not cover this broader product/API request.

## What This Changes

Request support for `/model <name> --turns N` plus per-model config that warns near expiry and automatically reverts to the default model after N turns.

## Best Possible Solution

Define one additive session-owned model lease contract before implementing command syntax, config/schema/docs, warning/revert behavior, and focused tests.
