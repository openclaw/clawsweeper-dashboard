## Summary

Keep open: current main and the latest release still support persistent session model selection and adjacent one-turn/fallback mechanisms, but not an N-turn `/model` lease with warning, auto-revert, or per-model turn-limit config.

## What This Changes

The issue requests `/model <name> --turns N` with warning and automatic revert to the session default model after the turn budget expires.

## Best Possible Solution

Define one additive, session-owned temporary model lease contract across `/model` and any Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queued runs, retries, fallbacks, auth profiles, and live switches.

Owner confidence: high

Options:

- **Specify a unified lease contract (recommended):** Define a maintainer-approved temporary model lease design first, then implement `/model --turns N` and any Gateway fields against that single session-state contract.
- **Settle one-turn override first:** Keep this issue open while https://github.com/openclaw/openclaw/issues/83565 and https://github.com/openclaw/openclaw/pull/100876 settle request-local override semantics before adding multi-turn leases.
- **Decline native leases:** Document manual `/model default`, allowlists, or operator policy as the supported cost-governance path instead of adding native turn leases.

## Reproduction Assessment

Yes from source inspection, if treated as a missing feature rather than a broken bug: current `/model`, `sessions.patch`, and execution paths support persistent or internal request-local model choices but no N-turn lease with warning and auto-revert.

## Solution Assessment

Unclear until maintainers pick the product/API shape. The maintainable endpoint should likely be a general temporary model-lease primitive shared by `/model`, Gateway callers, and session status instead of an isolated command-only special case.
