## Summary

Keep open: current main and the latest release still lack the requested `/model --turns N` parser, turn counter, warning/revert session state, and per-model max-turn config. ## What This Changes

The issue requests `/model <name> --turns N` plus per-agent model turn-limit config that warns before expiry and reverts to the default model after the requested number of turns.

## Best Possible Solution

Define one additive session-owned model lease contract, then implement `/model --turns N`, config/schema/docs, warning/revert behavior, and focused tests against that single contract.
