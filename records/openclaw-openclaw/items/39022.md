## Summary

Keep open: current main still has persistent session model overrides and some one-turn run override machinery, but it does not implement `/model <name> --turns N`, warning/revert lease state, or per-model turn-limit config. This is a real product/API design request, not stale cleanup.

## What This Changes

Request support for `/model <name> --turns N` with warnings, automatic revert to the session default model, and per-model/per-agent turn-limit configuration.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any Gateway/session API, then implement it with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests.

- **Decline native model leases:** Document manual `/model default`, one-turn overrides, or operational policy as the supported cost-governance path instead of adding lease state.
