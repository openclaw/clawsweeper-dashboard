## Summary

Keep open: current main and v2026.6.11 still provide persistent `/model` and `sessions.patch` model overrides, but not an N-turn model lease with warning, auto-revert, or per-model turn-limit config. The related open items overlap on temporary model routing, but they do not replace this broader product/API decision.

## What This Changes

Request adds `/model <name> --turns N`, optional per-agent per-model turn limits, warnings before expiry, and automatic reversion to the default model.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model`, Gateway/session APIs, and config, with explicit turn counting, warning/revert semantics, compatibility-safe defaults, docs, and focused tests.
