## Summary

Keep open: current main and v2026.6.11 still only show persistent model override paths, while the requested N-turn `/model` lease with warning, auto-revert, and per-model turn-limit config remains a product/API decision. The related open one-turn, fallback, and image-revert items overlap on temporary model routing but do not replace this broader multi-turn lease request.

## What This Changes

Request adding `/model <name> --turns N` plus per-model config that warns before and auto-reverts model selection after N turns.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any exposed Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.
