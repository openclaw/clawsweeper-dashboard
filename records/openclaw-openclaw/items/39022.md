## Summary

Keep open: current main and v2026.6.11 still support persistent session model selection and adjacent one-turn/fallback concepts, but not an N-turn `/model` lease with warning, automatic revert, or per-model turn-limit config.

## What This Changes

Request adds `/model <name> --turns N` plus per-agent per-model limits that warn near expiry and revert to the session default after N turns.

## Best Possible Solution

Define one additive, session-owned temporary model lease contract shared by `/model` and any Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests.

## Maintainer Decision

Rationale: The request adds public command syntax, config shape, persisted session state, provider/auth routing, warning timing, and fallback interaction; automation should not choose those semantics without maintainer intent.

Owner confidence: high

Options:

- **Specify a unified lease contract (recommended):** Define the temporary model lease state and counting rules first, then implement `/model --turns N` and any Gateway fields against that single contract.
- **Settle one-turn override first:** Keep this issue open while https://github.com/openclaw/openclaw/issues/83565 and https://github.com/openclaw/openclaw/pull/100876 settle request-local override semantics before multi-turn leases are added.
- **Decline native leases:** Do not add native turn leases and instead document manual `/model default`, allowlists, or operational policy as the supported cost-governance path.

## Reproduction Assessment

Yes, at the source-contract level: current `/model`, `sessions.patch`, and session override paths support persistent model choices but have no N-turn lease, warning, or automatic revert state. This is a missing feature rather than a broken existing behavior.

## Solution Assessment

Unclear until maintainers choose the product/API shape. The maintainable path is a shared temporary model-lease primitive rather than an isolated command-only special case.
