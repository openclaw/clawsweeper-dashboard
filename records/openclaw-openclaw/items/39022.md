## Summary

Keep open: current main and v2026.6.11 still support sticky `/model` and `sessions.patch` model overrides, but not a multi-turn model lease with warning, auto-revert, or per-model turn-limit config. Related open items overlap on temporary model routing, but none replaces this broader command/API/config product decision.

## What This Changes

The issue requests `/model <name> --turns N` plus per-agent model turn-limit config and automatic default-model reversion after the configured turn count.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.
