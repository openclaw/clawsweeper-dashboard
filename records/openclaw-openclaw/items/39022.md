## Summary

Keep open: current main and the latest release still lack a multi-turn model lease with warning, auto-revert, and per-model turn-limit config. The related one-turn and image-specific items overlap on temporary model routing but do not replace this broader product/API decision.

## What This Changes

Add `/model <name> --turns N` plus optional per-model turn-limit config so model overrides warn and revert to the default after a bounded number of turns.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any exposed Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests.

- **Do not add native leases:** Reject native turn leases and document manual `/model default` or operational policy as the supported cost-governance path.
