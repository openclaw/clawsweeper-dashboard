## Summary

Keep open: current main and v2026.6.11 still support persistent `/model`, model picker, `session_status(model=...)`, and `sessions.patch` overrides plus auto-fallback recovery, but not an N-turn model lease with warning, auto-revert, or per-model turn-limit config. The related open items cover one-turn overrides, image-only revert, or fallback persistence, so none fully supersedes this broader product/API request.

## What This Changes

Request adds `/model <name> --turns N`, warning and auto-revert after N turns, plus per-model turn-limit config for cost governance.

## Best Possible Solution

Define one temporary model-routing contract that preserves existing persistent `/model` semantics, then add any lease or one-turn API with explicit session state, auth/profile behavior, upgrade-safe config, docs, and focused tests.
