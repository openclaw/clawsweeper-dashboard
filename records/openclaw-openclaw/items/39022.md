- `impact:session-state`: The request would add temporary model lease state, warning thresholds, and automatic session model reversion.
- `impact:auth-provider`: The feature would change model/provider selection and can affect which provider credentials are used on later turns.

## Summary

Keep open: current main and v2026.6.11 still only support persistent `/model`, model picker, `session_status(model=...)`, and `sessions.patch` model overrides, not an N-turn model lease with warning, automatic reversion, or per-model turn-limit config. The related open items cover one-turn overrides or image-analysis-specific revert, so they overlap but do not supersede this broader product/API request.

## What This Changes

Add `/model <name> --turns N` with a warning before expiry, automatic reversion to the session default model, and optional per-model turn-limit config.

## Best Possible Solution

Define one temporary model-routing contract that preserves existing persistent `/model` semantics, then add any lease or one-turn API with explicit session state, auth/profile behavior, upgrade-safe config, docs, and focused tests.
