## Summary

Keep open: current main still has persistent model overrides and one-turn fast-mode overrides only; the requested N-turn model lease, warning, auto-revert, and per-model limit config remain unimplemented and need product/API direction.

## What This Changes

Request support for `/model <name> --turns N` with near-limit warning, automatic revert to the session default, and configurable per-model turn limits.

## Best Possible Solution

Define one canonical model-lease contract across `/model`, `sessions.patch` or `chat.send`, session state, and visible notifications, then implement turn-limit config only after maintainers choose how it relates to the one-turn override work.
