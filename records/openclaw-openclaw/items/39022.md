## Summary

Keep open: current main still has persistent `/model` and `sessions.patch` model overrides, but not the requested N-turn lease, warning, auto-revert, or per-model turn-limit config. The related open items overlap on temporary model routing, but none replaces this broader product/API decision.

## What This Changes

Request support for `/model <name> --turns N` with warning and automatic reversion to the session default model, plus per-agent/per-model config limits.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model`, session/Gateway APIs if exposed, and model-selection state, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.

## Reproduction Assessment

Not applicable as a feature request. Source and release inspection show current main and v2026.6.11 have persistent model overrides and heartbeat-only internal one-shot override support, but no `/model --turns`, lease counter, warning state, or per-model turn-limit config.

## Solution Assessment

Unclear until maintainers choose the product contract. The requested turn lease is plausible, but the maintainable path should be one session-owned lease mechanism rather than prompt enforcement, ad hoc config, or a second model-switch path.
