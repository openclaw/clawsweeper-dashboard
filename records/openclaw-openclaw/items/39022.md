## Summary

Keep open: current main and the latest release still provide persistent `/model` and `sessions.patch` model overrides, but not a multi-turn model lease with warning, auto-revert, or per-model turn-limit config. The related open items overlap on temporary model routing but do not replace this broader product/API decision.

## What This Changes

Request support for `/model <name> --turns N` plus per-model/per-agent turn-limit configuration that reverts a session to its default model after the limit.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any exposed Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.

- **Do not add native leases:** Reject native turn leases and document manual `/model default` or operational policy as the supported cost-governance path.
