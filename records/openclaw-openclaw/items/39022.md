## Summary

Keep open: current main has sticky session model overrides and narrower one-turn plumbing, but not the requested N-turn `/model --turns` lease with warning, configured limits, and auto-revert. The remaining work is a maintainer product/API decision across command UX, session state, Gateway/session contracts, and provider routing.

## What This Changes

Add `/model <name> --turns N` plus per-agent per-model limits that warn before expiry and revert to the default model after N turns.

## Best Possible Solution

Define one temporary model lease contract covering `/model`, Gateway/session APIs, persisted session state, provider/auth validation, warnings, reverts, docs, and tests before implementation.
