## Summary

Keep open: current main still has persistent `/model` and session model overrides plus adjacent fallback/one-turn work, but not the requested N-turn model lease with warning, automatic revert, and per-model turn-limit config.

## What This Changes

Request to add `/model <name> --turns N` so a session temporarily uses a model for N turns, warns near expiry, then reverts to the default model.

## Best Possible Solution

Define one additive session-owned temporary model lease contract shared by `/model` and any Gateway/session API, with explicit turn counting, warning/revert behavior, config shape, docs, and regression coverage for auth profiles, fallbacks, queued runs, and live switches.

Owner confidence: high

Options:

- **Settle one-turn overrides first:** Keep this issue open while https://github.com/openclaw/openclaw/issues/83565 and https://github.com/openclaw/openclaw/pull/100876 settle request-local override semantics before adding multi-turn leases.
- **Decline native leases:** Do not add turn-limited model leases and document manual `/model default`, allowlists, or operational policy as the supported cost-governance path.
