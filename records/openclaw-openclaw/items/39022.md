## Summary

Keep open: current main and v2026.6.11 still support persistent `/model` and `sessions.patch` model overrides, but not an N-turn model lease with warning, auto-revert, or per-model turn-limit config. The related open items overlap on temporary model routing but do not replace this broader product/API decision.

## What This Changes

Request to add `/model <name> --turns N` plus per-agent config so selected models automatically warn and revert after a bounded number of turns.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any exposed Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.
