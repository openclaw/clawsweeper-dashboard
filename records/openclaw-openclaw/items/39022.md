## Summary

Keep open: current main still has persistent `/model` and `sessions.patch` model overrides, but no N-turn model lease, warning, auto-revert, or per-model turn-limit config. The related one-turn and image-revert items overlap on temporary model routing but do not replace this broader product/API decision.

## What This Changes

Add `/model <name> --turns N` plus per-agent/per-model limits that warn near expiry and auto-revert the session to the default model after the configured number of turns.

## Best Possible Solution

Define one additive session-owned model lease contract across `/model` and any exposed Gateway/session API, with explicit turn counting, warning/revert semantics, compatibility-safe config, docs, and focused tests for queues, cron, retries, fallbacks, auth profiles, and live switches.
