## What This Changes

The PR resolves the requester agent’s configured identity name from its session and adds it to the initial, reply, and announce agent-to-agent `sessions_send` prompt contexts.

## System Context

`sessions_send` turns a request from one OpenClaw agent session into prompt context for another agent, then may run bounded replies and a final announcement. This change supplies the receiving agent with the requester’s configured display name while preserving placeholder-based session identifiers for prompt-cache stability.
