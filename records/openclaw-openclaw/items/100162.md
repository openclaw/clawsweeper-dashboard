## Summary

Keep this open: current main still has a source-reproducible empty isolated cron completion path that can finish without a deliverable channel reply, and the open mergeable fix candidate is https://github.com/openclaw/openclaw/pull/100229 rather than landed code.

## What This Changes

The issue asks OpenClaw to treat delivery-requested embedded/isolated cron agent runs with an empty final payload as a retryable/error-signaled failure instead of silently dropping the channel reply.

## Best Possible Solution

Review and land or intentionally replace https://github.com/openclaw/openclaw/pull/100229 for genuinely empty isolated cron completions, while keeping https://github.com/openclaw/openclaw/pull/90450 as the separate streamed-then-empty parser repair.
