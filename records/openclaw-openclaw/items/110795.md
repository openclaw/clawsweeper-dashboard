## What This Changes

This PR makes the GitHub Copilot usage plugin treat successful `null` or array JSON responses as an empty usage result and adds regression coverage for both payload shapes.

## System Context

The GitHub Copilot plugin fetches a usage JSON payload from GitHub, converts quota snapshots into provider usage windows, and returns them to OpenClaw’s usage display. This change sits at the boundary between the remote response reader and quota parsing, preventing malformed successful responses from aborting that flow.
