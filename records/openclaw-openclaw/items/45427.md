## What This Changes

Request to add a trusted sender display name or equivalent trusted sender identity to inbound metadata so agents do not resolve names from untrusted context.

## Best Possible Solution

Settle the trusted identity contract first, preferably around stable channel IDs, `session.identityLinks`, or operator-attested principals, then land one focused implementation with protocol, auto-reply, channel, and regression-test coverage.
