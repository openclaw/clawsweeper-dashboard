## What This Changes

Request adding a trusted sender display/name identity to inbound metadata so agents do not infer recipients from untrusted conversation context.

## Best Possible Solution

Keep this issue as the canonical trusted inbound identity decision, then land one approved contract that exposes a stable provider ID or configured principal without trusting conversational display names and with focused prompt, channel, privacy, and routing tests.

## Solution Assessment
