## What This Changes

The PR rewrites the Control UI’s bundled favicon, touch-icon, and manifest links to the dashboard root or configured base so nested dashboard pages do not request those assets relative to the current route.

## System Context

The Gateway serves the Control UI HTML document for both root-mounted and base-mounted dashboards. Browsers resolve the document’s public asset links before the single-page application starts, so this response layer determines whether nested routes request the intended static assets.
