## Summary

Keep open. Current main has improved parent-mediated sub-agent completion handoff, but it still lacks the requested public `announceTarget` tool/config contract and thread-bound native session spawns still register without a completion announce wake.

## What This Changes

Request native sub-agent completion routing so a spawned sub-agent can wake the parent session instead of posting directly to the channel.

## Best Possible Solution

Make a maintainer-sponsored routing decision, then either add `announceTarget: "channel" | "parent"` with thread-bound completion coverage or document the current parent-mediated behavior as canonical and track only narrower remaining handoff bugs.

## Reproduction Assessment

Yes. Source inspection is a high-confidence path: current main has no native `sessions_spawn.announceTarget` or `agents.defaults.subagents.announceTarget`, and thread-bound session spawns can still register without a completion announce wake.

## Solution Assessment

Unclear as a final product choice. The requested option is plausible, but current main already moved toward requester-session completion handoff, so maintainers should decide whether `announceTarget` or a narrower completion-delivery policy is the durable contract.
