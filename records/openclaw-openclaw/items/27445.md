## Summary

Keep open. Current main has improved sub-agent completion handoff toward parent/requester sessions, but the requested native `announceTarget` tool/config contract is still absent from current main and the latest release, and related open issues show the routing policy still needs maintainer product review.

## What This Changes

The issue requests a native `announceTarget` option for `sessions_spawn` and `agents.defaults.subagents` so sub-agent completion can wake the parent session instead of announcing directly to the channel.

## Best Possible Solution

Define one maintainer-approved, backward-compatible subagent completion routing contract that covers native spawn, config defaults, thread-bound sessions, and related suppression/callback behavior without creating a second orchestration framework.

## Reproduction Assessment

Yes. Source inspection is enough to reproduce the missing contract: current main has no native `announceTarget` tool parameter or `agents.defaults.subagents` config key, and the latest release lacks it too.

## Solution Assessment

No, not as an autonomous fix lane yet. A focused implementation is plausible, but the best solution needs maintainer approval for the public tool/config API and how it should interact with current requester-agent handoff behavior.
