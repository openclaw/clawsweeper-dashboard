Request an `announceTarget` option for sub-agent completion announces so completions can route into the parent session instead of directly to the channel.

Land a backward-compatible opt-in parent-routing implementation after maintainer approval, with default channel behavior preserved, per-spawn/config precedence documented, restart-safe persisted routing, and focused delivery tests.
