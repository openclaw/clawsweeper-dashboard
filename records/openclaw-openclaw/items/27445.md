## Summary

Keep open. Current main and v2026.6.11 still lack the requested public native `announceTarget` tool/config contract; `sessions_yield` covers some active wait flows, but not the explicit per-spawn/config parent-routing behavior requested here.

## What This Changes

Request to add `announceTarget: "channel" | "parent"` to `sessions_spawn` and `agents.defaults.subagents` so sub-agent completions can wake the parent session instead of posting directly to the channel.

## Best Possible Solution

Define the minimal opt-in completion-routing contract, preserve `channel` as the default, keep ACP `streamTo` separate, and cover active/yielded top-level plus thread-bound session spawns in focused tests.

Options:

- **Approve per-spawn plus config default (recommended):** Add `announceTarget` to `sessions_spawn` and `agents.defaults.subagents`, default it to current channel behavior, and route `parent` completions into the requester session without direct channel delivery.
- **Approve per-spawn only:** Add only an explicit per-call override first, avoiding new global config while still enabling orchestrator-owned handoffs.
- **Decline native routing for now:** Keep current `sessions_yield`, depth-based completion delivery, and explicit callback patterns while tracking narrower routing bugs separately.
