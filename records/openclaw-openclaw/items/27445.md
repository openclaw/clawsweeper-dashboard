## What This Changes

Add a native `announceTarget: "channel" | "parent"` option for sub-agent completion announces, with a config default and per-spawn override for parent-session orchestration.

## Best Possible Solution

Define the minimal default-compatible completion-routing contract, then implement native `announceTarget: "channel" | "parent"` for `sessions_spawn` and `agents.defaults.subagents` while keeping ACP `streamTo` separate and covering schema, docs, and delivery tests.
