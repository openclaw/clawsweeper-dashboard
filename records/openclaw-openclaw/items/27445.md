## Summary

Keep open. Current main and v2026.6.11 still lack the requested native `announceTarget` tool/config contract, and the remaining choice is a compatibility-sensitive product/API decision rather than cleanup.

## What This Changes

Request to add `announceTarget: "channel" | "parent"` routing for native sub-agent completion announces, with both a `sessions_spawn` override and an `agents.defaults.subagents` default.

## Best Possible Solution

Add a backward-compatible native routing contract only if maintainers approve it: default to current channel behavior, route `parent` completions into the requester session with `deliver:false`, avoid a direct channel announce, and cover native run/session/thread cases without changing ACP `streamTo`.
