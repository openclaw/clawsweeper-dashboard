## Summary

Keep open. Current main has improved requester-session completion handoff, but the requested public `sessions_spawn` / `agents.defaults.subagents` `announceTarget` contract is still absent and the thread-bound native session case can still skip completion announce registration.

## What This Changes

Request to add config-level and per-`sessions_spawn` `announceTarget` routing so sub-agent completions can wake the parent session instead of going straight to the channel.

## Best Possible Solution

Make this a maintainer-sponsored public sub-agent routing contract: preserve current defaults, keep ACP `streamTo` separate, and require thread-bound completion wake coverage before adding tool/config surface.

## Reproduction Assessment

Yes. Source inspection is a high-confidence path: current main lacks native `sessions_spawn.announceTarget` and `agents.defaults.subagents.announceTarget`, and thread-bound native session spawns can still register with completion announce disabled.

## Solution Assessment

Unclear as a final product choice. The requested option is plausible, but current main already has requester-session completion handoff, so maintainers should decide whether `announceTarget` or a narrower completion-delivery policy is the durable contract.
