## Summary

Keep open. Current main and v2026.6.11 still do not provide native parent-targeted subagent completion routing for `sessions_spawn` or `agents.defaults.subagents`, and the remaining work is a compatibility-sensitive tool/config product decision rather than cleanup.

## What This Changes

Add a native `announceTarget` option so subagent completion announces can route into the parent session instead of posting directly to the channel.

## Best Possible Solution

Define the minimal public completion-routing contract first, then implement native parent-targeted completion routing with backward-compatible `channel` default, ACP `streamTo` kept separate, and focused source/docs/config tests.
