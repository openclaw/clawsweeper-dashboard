## Summary

Close as implemented: current main and v2026.6.11 already route native sub-agent completions through the requester/parent agent turn and `sessions_yield`, which solves the central orchestration wake-up problem without adding the exact `announceTarget` option.

## What This Changes

## Best Possible Solution
