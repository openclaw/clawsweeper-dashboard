## Summary

Keep open. Current main and the latest release still lack native `announceTarget` support for `sessions_spawn` or `agents.defaults.subagents`, and the linked implementation PR at https://github.com/openclaw/openclaw/pull/101248 is open, unmerged, and currently not a safe reason to close this issue.

## What This Changes

The issue requests an opt-in `announceTarget: "channel" | "parent"` setting for sub-agent completion routing at both config-default and per-spawn levels.

## Best Possible Solution

Land or replace the linked implementation with a backward-compatible opt-in parent-routing contract that preserves channel delivery by default, keeps ACP `streamTo` separate, persists routing for restart safety, and proves both fresh and upgrade behavior.
