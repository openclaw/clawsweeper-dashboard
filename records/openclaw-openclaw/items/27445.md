## Label Justifications

- `P2`: This is a normal-priority feature/product decision for advanced multi-agent orchestration with clear source gaps but no core runtime outage.
- `impact:session-state`: The request is about routing child completion state into the parent session so the orchestrator can continue with the correct context.
- `impact:message-loss`: The current missing explicit parent-routing mode can leave completion handoffs posted to the channel, suppressed for thread-bound session spawns, or unavailable to the parent workflow.

## Summary

Keep open. Current main has improved active-parent completion wake and several routing fixes, but it still lacks the requested public `announceTarget` tool/config contract and thread-bound native session spawns still skip completion announce registration.

## What This Changes

Add an `announceTarget` default and `sessions_spawn` override so sub-agent completion announces can route into the parent session instead of directly to the channel.

## Best Possible Solution

Adopt one maintainer-approved, backward-compatible announce-routing contract that keeps current channel behavior as the default, allows parent-session injection without direct channel announce, keeps ACP `streamTo` separate, and covers thread-bound session spawns with tests and docs.
