## Summary

Keep open: current main still lacks a public native `announceTarget` parameter or config default, and the remaining work is a compatibility-sensitive tool/config API decision rather than already-implemented cleanup.

## What This Changes

The issue requests a `sessions_spawn` and `agents.defaults.subagents` option to route sub-agent completion announces to the parent session instead of directly to the channel.

## Best Possible Solution

Add one backward-compatible native completion routing policy that defaults to current channel behavior, supports explicit parent-session wake with `deliver:false` and no direct final channel announce, and composes with the related suppression/per-channel requests.
