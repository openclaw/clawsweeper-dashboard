## Summary

Keep open for maintainer product/API review: current main and the latest stable release still lack the requested native `announceTarget` parameter/config contract, even though #80242 already fixed part of the parent-requester handoff behavior.

## What This Changes

Request a `sessions_spawn` and `agents.defaults.subagents` `announceTarget` option to route sub-agent completion announces to the parent session instead of direct channel delivery.

## Best Possible Solution

Define a minimal backward-compatible `announceTarget` contract, default it to current behavior, keep ACP `streamTo` separate, and cover schema, config docs, user docs, and delivery tests.
