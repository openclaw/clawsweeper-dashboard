## Summary

Keep open. Current main and the latest release still lack native parent-targeted `announceTarget` routing for `sessions_spawn` or subagent defaults, and the open linked PR is the implementation candidate rather than a reason to close this issue before merge.

## What This Changes

Request adds a config-level and per-spawn `announceTarget` option so native sub-agent completion announces can route to the parent session instead of directly to the channel.

## Best Possible Solution

Review and land or reject the linked implementation PR; the desired end state is a backward-compatible `channel` default with explicit opt-in parent routing, ACP `streamTo` kept separate, and coverage for active, dormant, thread-bound, and persisted completion cases.
