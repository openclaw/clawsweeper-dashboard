## Summary

Keep open. Current main has improved parent-mediated completion handoff, but it still lacks the requested public `announceTarget` tool/config contract and thread-bound native session spawns can still register with completion announces disabled, so this remains a maintainer product/config decision.

## What This Changes

Request native sub-agent completion announce routing so `sessions_spawn` and `agents.defaults.subagents` can send completions to the parent session instead of directly to the channel.

## Best Possible Solution

Keep this as a maintainer-sponsored sub-agent routing design: decide the public contract, preserve the current default behavior, and require explicit coverage for thread-bound session completion wakeups before implementation.

## Reproduction Assessment

Yes. Source inspection is a high-confidence reproduction path: current main has no native `sessions_spawn.announceTarget` or `agents.defaults.subagents.announceTarget`, and thread-bound session spawns can still register without a completion announce wake.

## Solution Assessment

Unclear as a final product choice. The requested option is plausible, but current main has already moved toward requester-session completion handoff, so maintainers should decide whether `announceTarget` or a narrower completion-delivery policy is the durable contract.
