## Summary

Keep open. Current main and v2026.6.11 still lack the requested native `announceTarget` tool/config contract, and the related open work covers adjacent suppression, A2A fallback, or handoff semantics rather than superseding this parent-targeted completion-routing request.

## What This Changes

Add an `announceTarget` option on `sessions_spawn` and `agents.defaults.subagents` so subagent completion announcements can wake the parent session instead of posting directly to the channel.

## Best Possible Solution

Define the minimal default-compatible completion-routing contract, then implement `announceTarget: "channel" | "parent"` for native `sessions_spawn` and `agents.defaults.subagents` while keeping ACP `streamTo` separate and covering schema, docs, and delivery tests.
