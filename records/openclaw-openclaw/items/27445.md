## Summary

Keep open. Current main and the latest release still lack a native `announceTarget` tool/config contract, and the remaining work is a compatibility-sensitive product/API decision rather than an implemented cleanup item.

## What This Changes

The issue requests native parent-session routing for sub-agent completion announces via `sessions_spawn` and `agents.defaults.subagents.announceTarget`.

## Best Possible Solution

Define the minimal public completion-routing contract first, then implement parent-targeted native completion routing with `channel` as the backward-compatible default, ACP `streamTo` kept separate, and focused coverage for native run-mode, thread-bound session-mode, config parsing, and docs.

- **Decline native routing for now:** Keep the current depth-based completion delivery model and leave users on explicit callback or suppression patterns while narrower related issues continue separately.
