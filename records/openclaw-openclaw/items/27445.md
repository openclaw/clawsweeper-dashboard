## Summary

Keep open. Current main now routes sub-agent completions through requester-session handoff by default, but it still lacks the requested public `announceTarget` tool/config contract, so the remaining work is a compatibility-sensitive product/API decision rather than cleanup.

## What This Changes

The issue requests a native `announceTarget` option for `sessions_spawn` and `agents.defaults.subagents` so sub-agent completion announces can route to the parent session instead of directly to the channel.

## Best Possible Solution

Define one additive, default-compatible sub-agent completion routing contract that composes with suppression and per-channel policy instead of adding competing controls.
