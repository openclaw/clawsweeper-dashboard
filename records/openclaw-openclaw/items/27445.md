## Summary

Keep open. Current main and the latest release still lack the requested native `announceTarget` tool/config contract, and the remaining work is a compatibility-sensitive product/API decision rather than conservative cleanup.

## What This Changes

The issue requests a native `announceTarget` option for `sessions_spawn` and `agents.defaults.subagents` so sub-agent completion announces can wake the parent session instead of posting directly to the channel.

## Best Possible Solution

Define a minimal default-compatible completion-routing contract, then implement `announceTarget: "channel" | "parent"` for native `sessions_spawn` and the subagent defaults while keeping ACP `streamTo` separate and covering schema, docs, and delivery tests.
