## Summary

Keep open. Current main partially improved requester-session completion handoff, but it still lacks the requested public `sessions_spawn.announceTarget` and `agents.defaults.subagents.announceTarget` contract, and thread-bound native session spawns can still register with completion announces disabled.

## What This Changes

Request native sub-agent completion announce routing so a spawn can route final completion to the parent session instead of directly to the channel.

## Best Possible Solution

Keep this as a maintainer-sponsored sub-agent routing design: preserve current channel behavior by default, add an explicit `channel | parent` contract only if approved, keep ACP `streamTo` separate, and cover thread-bound parent wake behavior in tests and docs.

## Reproduction Assessment

Yes. Source inspection is a high-confidence path: current main has no native `sessions_spawn.announceTarget` or `agents.defaults.subagents.announceTarget`, and thread-bound native session spawns can still register without a completion announce wake.

## Solution Assessment

Unclear as a final product choice. The requested option is plausible, but it adds public tool/config surface and overlaps current partial parent-wake behavior, so maintainers should choose the durable contract before implementation.
