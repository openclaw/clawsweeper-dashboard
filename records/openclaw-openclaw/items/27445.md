## Summary

Keep open. Current main and v2026.6.11 still lack the requested native `announceTarget` tool/config contract, and the remaining choice is a compatibility-sensitive product/API decision rather than cleanup.

## What This Changes

Request to add a native `announceTarget` option so sub-agent completion announces can either keep current channel delivery or wake the parent session for orchestration.

## Best Possible Solution

Define the minimal default-compatible completion-routing contract, then implement `announceTarget: "channel" | "parent"` for native `sessions_spawn` and `agents.defaults.subagents` while keeping ACP `streamTo` separate and covering schema, docs, and delivery tests.
