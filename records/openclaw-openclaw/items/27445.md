## Summary

Keep open. Current main still lacks the requested public per-spawn and config-level `announceTarget` contract; existing code has some parent handoff behavior, but delivery remains hard-coded by activity/thread state with no caller-selectable parent-routing option.

## What This Changes

Add an `announceTarget` option to native `sessions_spawn` and `agents.defaults.subagents` so sub-agent completion announces can route to the parent session instead of the user channel.

## Best Possible Solution

Define a minimal default-compatible native completion-routing contract, then implement the maintainer-approved shape across the tool schema, config schema/types, docs, delivery path, and thread-bound tests while keeping ACP `streamTo` separate.
