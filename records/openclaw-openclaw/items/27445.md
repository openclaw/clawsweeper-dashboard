## Summary

Keep open. Current main and the latest release still lack a native `announceTarget` contract for `sessions_spawn` or subagent defaults, and the open linked PR is the correct implementation candidate rather than a reason to close this issue before merge.

## What This Changes

The issue requests a native `announceTarget` option so sub-agent completion announces can wake the parent session instead of being delivered directly to the channel.

## Best Possible Solution

Land or reject the linked implementation PR after maintainer review; the desired end state is a backward-compatible `channel` default with explicit opt-in parent routing, ACP `streamTo` kept separate, and tests for active, dormant, thread-bound, and persisted completion cases.
