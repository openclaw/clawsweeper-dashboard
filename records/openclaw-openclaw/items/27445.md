## Summary

Keep open. Current main has improved default parent-session completion handoff, but the requested public `announceTarget` tool/config contract is still absent and thread-bound native session spawns can still skip completion announce registration, so this remains a maintainer product/config decision.

## What This Changes

Request to add `announceTarget` on `sessions_spawn` and `agents.defaults.subagents` so sub-agent completions can wake the parent session instead of posting directly to the channel.

## Best Possible Solution

Decide a narrow public completion-routing contract, preserve compatible defaults, keep ACP-only `streamTo` separate, and require targeted coverage for normal and thread-bound native spawns before implementation.
