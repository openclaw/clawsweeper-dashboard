## Summary

Keep open. Current main has improved requester-session completion handoff, but it still does not expose the requested native `sessions_spawn.announceTarget` or `agents.defaults.subagents.announceTarget` contract, and thread-bound native session spawns can still suppress completion announce registration.

## What This Changes

Request adds a config default and per-spawn `announceTarget` option so native sub-agent completion announces can route to the parent session instead of direct channel delivery.

## Best Possible Solution

Keep this as a maintainer-sponsored native subagent routing design: choose the public contract, preserve current default behavior, keep ACP-only `streamTo` separate, and cover thread-bound completion wakes before implementation.

## Reproduction Assessment

Yes. Source inspection is a high-confidence path: current main and the latest release lack native `sessions_spawn.announceTarget` and `agents.defaults.subagents.announceTarget`, and thread-bound native session spawns still register without a completion announce wake.

## Solution Assessment

Unclear as a final product choice. The requested option is plausible, but current main has already moved toward requester-session completion handoff, so maintainers should decide whether `announceTarget` or a narrower completion-delivery policy is the durable contract.
