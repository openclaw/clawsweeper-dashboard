## Summary

## Best Possible Solution

Land the narrow recovery gate if maintainers accept preserving the old files as backups and treating non-deliverable terminal transcripts as poisoned state.

## Solution Assessment

Mostly yes: the pre-open gate is a narrow place to prevent replaying a known poisoned transcript and it preserves backups. The remaining question is maintainer acceptance of runtime archive-and-reset as the desired session-state policy.
