## What This Changes

This PR wraps sandbox backend startup failures in a typed local provisioning error so a sandboxed agent stops after one failed attempt instead of consuming configured model fallbacks.

## System Context

Agent runs create a sandbox backend before the model attempt begins; failures from that setup path feed into model-fallback classification. The classifier decides whether to try another model candidate or surface the local runtime failure to the child and its parent run.
