## What This Changes

The PR wraps sandbox backend startup failures in a typed local provisioning error so the model-fallback loop stops after one failed sandbox attempt while explicit provider failures continue to use fallback models.

## System Context

Sandbox context resolution creates the configured backend before an agent model attempt runs. Errors then reach the model-fallback classifier, which either stops for a local runtime failure or advances to another configured provider/model for an actual provider failure.
