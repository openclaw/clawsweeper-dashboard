## What This Changes

The branch introduces a typed sandbox-provisioning error so local sandbox backend startup failures stop the model fallback chain after one attempt while explicit provider failures can still fall back.

## System Context

Agent runs first resolve a sandbox backend when sandboxing is enabled, then invoke the selected model through the fallback loop. This change marks backend-startup failures as local infrastructure errors so the fallback loop returns the actionable sandbox error instead of trying additional models.
