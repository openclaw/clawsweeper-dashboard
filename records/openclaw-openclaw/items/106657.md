## Summary

Keep this PR open for normal merge review. The current main branch still treats sandbox backend startup errors as ordinary errors, while this patch introduces a typed local-provisioning path that prevents futile model fallback; its focused coverage and posted real Docker output support the behavior. The remaining gates are sandbox-owner review and a current-base merge refresh, not a demonstrated patch defect.

## What This Changes

This PR classifies sandbox backend startup failures as typed local provisioning errors so OpenClaw stops model fallback after the first failed sandbox attempt while preserving fallback for explicit provider failures.

## System Context

A sandboxed agent prepares a backend and workspace before its model run proceeds. Failures from that setup currently enter the model-fallback classifier; this change marks backend provisioning as local infrastructure failure so the run and parent outcome receive the actionable error instead of retrying different models.
