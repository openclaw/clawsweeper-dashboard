## Summary

Keep this PR open for maintainer-led review: it introduces a broad new gateway and persistent-state feature, but the current branch still exposes capability-declared widget HTML without enforcing the stored grant at serving time, has no usable rendering contract for MCP-app widgets, and lacks inspected after-fix runtime proof. ## What This Changes

This PR adds a persisted per-agent session-dashboard board domain with board RPCs/events, ticketed HTML widgets, a dashboard agent tool, and additive SQLite storage.

## Best Possible Solution

Preserve the additive per-agent design, but make authorization state part of both ticket issuance and ticket validation, define one authorized render contract for MCP-app widgets, avoid creating storage on read-only unknown-session probes, and prove fresh plus existing-v13 behavior on the current merge result.
