## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.96

Full review comments:

- **[P1] Gate widget frames on the persisted capability grant:** `src/gateway/server-methods/board.ts:73-79`
  - body: `board.get` can return a ticketed frame URL for a widget whose declared capabilities remain `pending` or are `rejected`, and the ticketed endpoint serves that HTML without checking the grant. A read-scoped client can therefore execute content the UI intentionally withholds; mint and honor frames only for the allowed grant states.
  - confidence: 0.97
- **[P1] Expose a renderable contract for MCP-app widgets:** `src/gateway/server-methods/board.ts:73-79`
  - body: The new store accepts `mcp-app` widgets, but snapshots expose neither their descriptor nor a renderable view, while `board-http` serves only HTML documents. Those widgets can be persisted yet cannot be rendered by any client; add an appropriately authorized descriptor/view path or reject this content kind until one exists.
  - confidence: 0.96
- **[P2] Do not create agent databases from board reads:** `src/boards/sqlite-board-store.ts:76-82`
  - body: The read handler passes arbitrary syntactically valid session keys into the SQLite board store, which opens and initializes the mapped agent database. An `operator.read` caller can create unbounded per-agent database files by probing keys; resolve against existing state first and return an empty or not-found board without materializing storage.
  - confidence: 0.94
