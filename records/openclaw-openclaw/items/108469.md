## What This Changes

This PR makes bundled llama.cpp-backed providers project tool schemas into a GBNF-compatible form, adds an opt-in `llamacpp` schema profile for custom endpoints, and includes unrelated SecretRef path-policy changes.

## System Context

Agent runs build a portable list of tool schemas before sending a request to the selected model provider. Provider plugins may adapt that list for backend-specific constraints, while custom OpenAI-compatible models use declared compatibility settings; the resulting schema affects whether the backend can begin inference.
