## What This Changes

The PR makes `openclaw nodes status` split and compact a node PATH using semicolons for Windows-reported nodes while retaining colons for other platforms.

## System Context

The Nodes CLI requests node status records from the gateway and renders a human-readable terminal table. This change affects only PATH compaction in that display path, leaving the gateway record and JSON-oriented data unchanged.
