## What This Changes

The PR updates `openclaw nodes status` to compact Windows node PATH values with semicolons while retaining colon-based formatting for other platforms, and adds Windows/Linux renderer regression cases.

## System Context

Connected nodes report status records, including platform and PATH data, through the Gateway. The nodes-status CLI consumes those records and formats a compact terminal detail field without changing the Gateway record, JSON output, or persisted node state.
