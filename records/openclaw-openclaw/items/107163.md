## Summary

## What This Changes

Allow hostname-restricted Microsoft Teams Graph and media guarded fetches to accept RFC2544 fake-IP DNS results used by host egress proxies.

## Best Possible Solution

Keep the exception inside the Teams plugin, combine it with concrete Graph/media hostname allowlists, preserve strict behavior for wildcard or unscoped URLs, and validate both allowed RFC2544 proxy DNS and blocked arbitrary private targets before merge.
