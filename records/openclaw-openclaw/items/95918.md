## What This Changes

This PR changes Feishu `agents add --bind` parsing so a bare Feishu value becomes a group-peer route and adds a separate `account:` form, while also changing heartbeat acknowledgement filtering.

## System Context

The `agents add --bind` CLI converts channel binding text into persisted route records; channel messages later match those records to select an agent. Separately, heartbeat filtering removes internal heartbeat prompts and acknowledgements from the transcript sent to the model.
