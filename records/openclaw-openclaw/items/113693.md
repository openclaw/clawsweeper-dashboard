## What This Changes

Forward the abort controller’s existing cancellation or timeout reason to the active embedded-agent session and assert that both focused cancellation paths receive that exact reason.

## System Context

Embedded-agent runs use an abort controller to coordinate the outer run, compaction, and the active session. Cancellation and timeout signals must carry one terminal reason into the active session so transcripts and downstream consumers explain why the run ended.
