  - body: `same-window` and `new-window` launch plugin-owned routes and then navigate a top-level window to the result.   - body: The new entry iframe inherits `embedSandboxMode`, and `trusted` resolves to `allow-scripts allow-same-origin`. Plugin entry pages are a new plugin UI trust boundary and should not gain same-origin access through the generic embed setting; use a fixed opaque sandbox for this surface.
  - confidence: 0.9

  - body: When `plugins.uiEntryPointLaunch` rejects, this catch renders the raw plugin path; the sidebar helper also returns the raw path on launch failure. That skips the launch-token/session path and can bypass the entry's `requiredScopes` behavior, so show an unavailable state instead.
