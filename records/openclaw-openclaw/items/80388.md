## Summary

PR #80388 should stay open: it is a useful candidate for native plugin Control UI entry points, but the current branch still creates a parallel public plugin UI contract beside the existing tab descriptor seam and leaves security-sensitive launch paths that can bypass or weaken iframe isolation and fail open after launch errors.

## What This Changes

## Best Possible Solution
