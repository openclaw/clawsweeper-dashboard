- **[P1] Use an opaque sandbox for plugin entry frames:** `ui/src/pages/plugin/plugin-page.ts:180`
  - body: This remains from the prior review cycle. Plugin entry pages are served from same-origin `/plugins/...` routes, but this iframe still uses the global embed sandbox setting; in `trusted` mode `resolveEmbedSandbox` adds `allow-same-origin`, which removes the opaque-origin isolation this feature relies on. Use a fixed plugin-entry sandbox that never grants same-origin to plugin code.

  - body: This remains from the prior review cycle. That bypasses the short-lived launch/session URL boundary; show an unavailable state and avoid navigation instead.
  - confidence: 0.9
