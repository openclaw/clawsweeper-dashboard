## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Fold entry points into the existing tab surface:** `src/plugins/types.ts:2599`
  - body: Current main already supports plugin Control UI navigation through `api.session.controls.registerControlUiDescriptor({ surface: "tab", path, ... })`, projected as `controlUiTabs`. Adding `registerControlUiEntryPoint` plus separate `plugins.uiEntryPoints` RPCs creates a second public plugin UI contract for the same sidebar/navigation job; fold the launch-token/root-hardening pieces into the existing tab descriptor path or get explicit maintainer approval for a second API.
  - confidence: 0.87
- **[P1] Keep plugin entry pages sandboxed:** `ui/src/components/app-sidebar.ts:1307-1312`
  - body: The new `openMode` branch lets a plugin choose `same-window` or `new-window`, then navigates to its plugin route outside the iframe. That bypasses the frame/window binding and sandbox isolation this security model relies on, giving third-party plugin UI a normal top-level same-origin page; entry-point pages should stay in-app and sandboxed unless maintainers explicitly approve a different trust model.
  - confidence: 0.89
- **[P1] Use an opaque sandbox for entry frames:** `ui/src/pages/plugin/plugin-page.ts:180`
  - body: This iframe reuses the global embed sandbox setting, whose `trusted` mode resolves to `allow-scripts allow-same-origin`. Plugin-owned entry content should not become same-origin with the authenticated Control UI; use a fixed opaque sandbox for plugin entry frames, independent of the canvas/embed setting. This was visible in the prior cycle and remains on the current head.
  - confidence: 0.91
- **[P2] Fail closed when entry launch fails:** `ui/src/pages/plugin/plugin-page.ts:157-160`
  - body: If `plugins.uiEntryPointLaunch` rejects because the entry is unavailable, out of scope, or the auth minting path fails, this catch still loads the raw plugin path into the iframe. That bypasses the launch/session-token gate and can mask an auth failure as an unauthenticated plugin page; keep the frame empty or show an error instead, and apply the same fail-closed rule to the sidebar external-mode helper.
  - confidence: 0.86
