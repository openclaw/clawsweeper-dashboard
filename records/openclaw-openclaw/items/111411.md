## Summary

Keep this maintainer-labeled PR open: current `main` still has the unbounded agent-handle cache, but the proposed LRU can close a handle retained across an `await`, producing a closed-`DatabaseSync` failure under cache pressure.

## What This Changes

The branch caps the per-agent SQLite-handle cache at 64 with LRU eviction, adds non-registering read-only session/cache reads, and reduces fleet-wide refresh contention.

## Best Possible Solution

Make cache eviction safe for every live database borrower—by scoped pinning/reference counting or by reopening at deferred-use boundaries—then add a stress regression that holds an async accessor across forced eviction and obtain explicit approval for the SDK read-only contract.
