## Summary

Keep open; this is a narrow, useful bug-fix PR for current main's trajectory window comparator returning `NaN` when two corrupt/unparseable rows are compared, with focused tests and terminal proof in the PR body.

## What This Changes

The PR changes `compareTrajectoryWindowLines` to use relational comparisons plus a raw-line tiebreaker, and adds direct regression tests for corrupt trajectory JSONL rows.

## Best Possible Solution

Keep the comparator finite and deterministic at the trajectory window sort boundary, with focused regression coverage for corrupt JSONL rows.
