## What This Changes

The issue requests a shared async resource lifecycle/shutdown coordination pattern for retry and cleanup paths that currently rely on targeted ad hoc guards.

## Best Possible Solution

Define a narrow lifecycle/shutdown protocol only if maintainers want a shared seam, then prove it by migrating one agent cleanup path and one plugin or gateway path while leaving stale-delivery TTL policy to its separate tracker.
