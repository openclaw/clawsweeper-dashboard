## What This Changes

The issue requests a standard async resource lifecycle protocol for retry, cleanup, and shutdown paths so async work cannot outlive disposal boundaries and lose state or messages.

## Best Possible Solution

Keep this as the canonical design tracker, define the owner boundary and shutdown semantics first, then prove any new primitive across representative agent retry, channel/plugin cleanup, and gateway restart paths.
