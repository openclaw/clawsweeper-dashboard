## Summary

Keep open: current main has several focused lifecycle mechanisms, but no shared ResourceManager-style shutdown protocol across retry, cleanup, plugin, and session boundaries. The related concrete bugs were fixed or narrowed separately, while this issue remains the canonical product/API design tracker.

## What This Changes

The issue asks OpenClaw to standardize async resource cleanup and retry lifecycle handling with a shared ResourceManager-style shutdown protocol.

## Best Possible Solution

Keep this as the canonical design tracker, decide the owner boundary and shutdown semantics first, then prove any new primitive across representative agent retry, plugin cleanup, and gateway/session lifecycle paths.
