## Summary

Keep this PR open, but it is not merge-ready: the new failed-recovery branch can declare a session idle after recovery fails while non-embedded model or tool work may still be active. The supplied coordinator-level before/after evidence resolves the prior proof gate, but it does not establish that this broader state transition is safe.

## What This Changes

The PR makes a current, ownerless diagnostic session state transition to idle after a failed stuck-session recovery, while preserving stale-generation and active embedded-run states.

## Best Possible Solution

Keep failed outcomes non-mutating unless recovery can return a distinct, positively proven no-live-work outcome that accounts for every active-work owner; add focused coverage for each owner class before merging.
