For prompt-only runs, this helper can synthesize `transcriptPrompt` from the raw user prompt after appending the generated runtime block; if that prompt contains line-delimited internal-context markers, `resolveRuntimeContextPromptParts` extracts the user block together with the generated block and stores it as hidden `openclaw.runtime-context`. Escape the raw prompt before synthesis or extract only the block appended by `appendRuntimeSelfContextToPrompt`.
  - confidence: 0.92

  - body: Late discovery: this was visible at the same reviewed head. Callers use `transcriptPrompt: ""` for runtime-only heartbeat/memory events; returning the appended prompt while preserving an empty transcript makes the resolver prefer the generated runtime self-context and drop the original event text from the runtime system context. Preserve the pre-append prompt for empty-transcript mode or avoid appending through this extraction path.
  - late: true
