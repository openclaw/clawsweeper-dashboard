Full review comments:

- **[P1] Escape user delimiters before synthesizing the split:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:50-62`
  - body: This still copies the raw pre-append prompt into `transcriptPrompt`. If a prompt-only user message contains line-delimited `<<<BEGIN_OPENCLAW_INTERNAL_CONTEXT>>>` markers, `resolveRuntimeContextPromptParts` extracts that user-authored block along with the generated runtime block and stores it as hidden `openclaw.runtime-context`. Escape the user prompt before the synthesized split or extract only the block appended by this helper.
  - confidence: 0.93
- **[P2] Preserve runtime-event text for empty transcripts:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:56-57`
  - body: When callers intentionally pass `transcriptPrompt: ""`, this returns the appended prompt while keeping the empty transcript. The later split treats the turn as runtime-only and, because the extracted generated block is present, drops the original event prompt text from the hidden runtime context delivered to the model. Preserve the pre-append event text in the runtime context or skip this append path for empty-transcript runtime events.
  - confidence: 0.9
- **[P2] Report omitted accelerator data as unknown:** `src/runtime-self-context/render.ts:92-96`
  - body: `resources?.accelerators ?? []` makes an omitted accelerator field look like an explicit empty list, so a CPU/memory-only config renders `no accelerator` even though the provider did not report accelerator availability. Render `no accelerator` only for an explicit empty array and otherwise leave accelerator status unknown.
  - confidence: 0.91
