- **[P1] Escape user delimiters before synthesizing the split:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:62`
  - body: This still sets `transcriptPrompt` to the raw pre-append user prompt after adding the generated runtime block.   - confidence: 0.94
- **[P2] Preserve runtime-event text for empty transcripts:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:56-57`
  - body: When callers intentionally pass `transcriptPrompt: ""` for runtime-only turns, this branch keeps the empty transcript while returning the appended prompt. The extraction path then keeps the generated runtime self-context but drops the original event text, so memory flushes or heartbeat/runtime events can deliver only the new runtime summary to the model.
  - confidence: 0.91
- **[P2] Report omitted accelerator data as unknown:** `src/runtime-self-context/render.ts:92-96`
  - body: `resources?.accelerators ?? []` treats an omitted optional field as an explicit empty list. Common configs that provide CPU or memory but do not probe accelerators will tell the model `no accelerator`, which is a negative hardware claim rather than unknown availability.
  - confidence: 0.95
