## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.93

Full review comments:

- **[P1] Keep user delimiters out of runtime context:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:62`
  - body: This prior blocker remains at current head. For prompt-only runs, this helper preserves the raw original prompt as `transcriptPrompt` after appending the generated runtime block; `resolveRuntimeContextPromptParts` then extracts every line-delimited internal-context block from the combined prompt, so user-authored marker blocks are duplicated into hidden `openclaw.runtime-context` as runtime-generated context. Escape user markers before appending, or extract only the block this helper generated.
  - confidence: 0.93
- **[P2] Preserve empty-transcript runtime events:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:56-57`
  - body: When `transcriptPrompt` is the intentional empty string for a runtime-only turn, returning the appended prompt with the empty transcript lets the resolver extract the new runtime self-context block and drop the original event text from `runtimeSystemContext`; heartbeat or memory-flush style turns can reach the model as only the self-context summary. Preserve the pre-append event text as runtime context too, or avoid appending through this extraction path for empty-transcript events.
  - confidence: 0.89
- **[P2] Report missing accelerator data as unknown:** `src/runtime-self-context/render.ts:92-96`
  - body: `RuntimeResources.accelerators` is optional, but this default treats omission as an empty list and tells the model `no accelerator` whenever CPU or memory is configured. That converts unprobed resource data into a negative placement signal; only render `no accelerator` when the config explicitly supplies `accelerators: []`, otherwise leave accelerator availability unknown.
  - confidence: 0.87
- **[P3] Regenerate the docs map for the new page:** `docs/docs.json:1326`
  - body: Adding `tools/runtime` to the docs navigation makes the live `check-docs` job fail because `docs/docs_map.md` is out of date. Refresh the generated docs map alongside this nav change so the docs gate can pass.
  - confidence: 0.96
