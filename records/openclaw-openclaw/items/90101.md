Full review comments:

- **[P1] Keep user delimiters out of runtime context:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:62`
  - body: The prior blocker remains: this prompt-only path preserves the raw original prompt after appending the generated runtime block, and the resolver extracts every line-delimited internal-context block from the combined prompt. A user can include those marker lines and have their text duplicated into hidden `openclaw.runtime-context` as runtime-generated data; escape or strip user markers before appending, or extract only the generated block.
  - confidence: 0.94
- **[P2] Preserve empty-transcript runtime events:** `src/agents/embedded-agent-runner/run/runtime-context-prompt.ts:56-57`
  - body: When `transcriptPrompt === ""`, this keeps the empty transcript while appending runtime self-context to the prompt. The resolver then treats the turn as empty-transcript and can deliver only the generated self-context instead of the original runtime event text; preserve the pre-append event text as runtime context too, or skip this append path for runtime-only events.
  - confidence: 0.9
- **[P2] Report missing accelerator data as unknown:** `src/runtime-self-context/render.ts:92-96`
  - body: `resources?.accelerators ?? []` turns an omitted optional field into an empty list, so partial resource data renders as `no accelerator`. That is a negative placement signal from unprobed data; only render `no accelerator` when the field is explicitly present and empty.
  - confidence: 0.91
- **[P3] Regenerate the docs map for the new page:** `docs/docs.json:1326`
  - body: The PR adds `tools/runtime` to the docs navigation, but `docs/docs_map.md` was not regenerated and `check-docs` now reports it is out of date. Regenerate the docs map so the new page is reflected in the indexed docs metadata.
  - confidence: 0.98
