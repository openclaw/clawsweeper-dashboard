## Summary

Keep open. Current main and the latest release still lack opt-in, domain-scoped agent attestation for arbitrary outbound HTTP requests; existing provider attribution and provider request-header surfaces are narrower transport features, so this remains a security/product design item.

## What This Changes

Request an opt-in OpenClaw agent attestation mechanism for outbound HTTP requests so external services can distinguish OpenClaw agents from ordinary clients.

## Best Possible Solution

Define the trust model and outbound scope first, then implement a privacy-preserving opt-in attestation contract with domain allowlists, schema/API coverage, docs, and non-leakage tests.
