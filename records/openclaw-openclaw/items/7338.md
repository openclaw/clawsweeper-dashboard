## Summary

Keep open. Current main and v2026.6.11 still lack opt-in, domain-scoped agent attestation for arbitrary outbound HTTP requests; existing provider attribution, static provider request headers, and plugin trust hooks are narrower surfaces, so this remains a product/security design item.

## What This Changes

Requests opt-in OpenClaw agent attestation headers or signed tokens for outbound HTTP requests so external services can verify agent-origin traffic.

## Best Possible Solution

Define a maintainer-approved trust model and outbound scope first, then implement a privacy-preserving opt-in attestation contract with domain allowlists, schema/API coverage, docs, and non-leakage tests.
