Keep open. Current main and v2026.6.11 still lack opt-in, domain-scoped agent attestation for arbitrary external HTTP requests; existing provider attribution and provider request headers are narrower transport features, and the issue remains a security/product design tracker.

## What This Changes

The issue requests optional, domain-scoped agent attestation headers or signed tokens for outbound OpenClaw agent HTTP requests.

## Best Possible Solution

Keep this open for maintainer product/security design, then implement a privacy-preserving opt-in attestation contract with explicit outbound scope, domain allowlists, non-leakage tests, docs, and any required plugin/config API changes.
