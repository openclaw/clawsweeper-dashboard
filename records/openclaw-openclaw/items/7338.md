## Summary

Keep this protected feature request open for maintainer-led product and security design. The current discussion distinguishes provider-specific attribution from the requested general outbound-request attestation, and a human-review label was explicitly applied on July 16, 2026.

## What This Changes

The issue requests opt-in, domain-scoped static or cryptographic headers that let external services verify that an HTTP request originated from an OpenClaw agent.

## Best Possible Solution

First approve a narrow security contract that states what an assertion proves, who issues and verifies it, its replay/audience/privacy rules, and the exact egress paths; then prefer a plugin-scoped implementation if existing seams can meet that contract, adding a generic core capability only for a demonstrated shared gap.
