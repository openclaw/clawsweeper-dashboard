## Summary

Keep open. Current main and v2026.6.11 still lack general opt-in, domain-scoped agent-origin attestation for external HTTP requests, and no canonical replacement owns the work; the remaining identity, privacy, and signing contract requires explicit product/security direction.

## What This Changes

Add opt-in, domain-scoped static or cryptographically signed attestation metadata to external requests made by OpenClaw agents, potentially configured globally or through skill metadata.

## Best Possible Solution

Approve a threat model first, then expose the smallest generic opt-in domain/audience-scoped signing seam needed by plugins, with no stable identifier by default, strict redirect non-leakage, key rotation and replay semantics, and tests across every explicitly supported outbound path.
