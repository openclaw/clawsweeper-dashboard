## Best Possible Solution

Land a maintainer-approved core TUI plain-text mode that updates config types/schema/help/docs, threads the setting through TUI startup and rendering components, covers tool summaries/selectors/status/settings, and adds focused config plus TUI rendering proof.

## Solution Assessment

Unclear until maintainers choose the public config contract. A core TUI setting is the right boundary, but a narrow tool-display-only change would be too small because selectors, settings, separators, status/loading text, and tool-card rendering also need coverage.
