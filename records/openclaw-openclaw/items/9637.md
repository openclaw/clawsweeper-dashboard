## Best Possible Solution

Add an opt-in core TUI plain-text accessibility mode across config types, strict schema, generated labels/help, public docs, TUI startup loading, tool cards, selectors/theme rendering, and focused rendering/config tests while preserving rich glyph output by default unless maintainers choose otherwise.
