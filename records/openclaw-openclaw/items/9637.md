## What This Changes

Request to add a TUI accessibility configuration option that suppresses emoji and Unicode glyphs in favor of screen-reader-friendly plain-text output.

## Best Possible Solution

Add an opt-in core TUI plain-text accessibility mode across config types, strict schema, generated labels/help, public docs, TUI startup loading, tool display, selector/theme rendering, and focused tests while preserving current rich glyph output by default unless maintainers choose otherwise.
