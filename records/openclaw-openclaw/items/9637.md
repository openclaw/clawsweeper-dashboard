## Best Possible Solution

Land a maintainer-approved core TUI plain-text mode that updates config types/schema/help/docs, threads the flag through TUI startup and rendering components, covers tool summaries/selectors/status/settings, and adds focused config plus TUI rendering proof.

## Solution Assessment

Unclear until maintainers choose the public config contract. A core TUI setting is the right boundary, but a tool-display-only patch would be too narrow because selectors, settings, separators, status/waiting text, and dependency-backed controls also need coverage.
