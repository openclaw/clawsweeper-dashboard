## Summary

Current main still has no TUI plain-text accessibility mode, the prior implementation at https://github.com/openclaw/openclaw/pull/9685 closed unmerged, and two screen-reader users confirm the usability problem; the issue remains necessary, but maintainers must choose the durable activation contract and canonical ASCII presentation.

## What This Changes

Add a TUI accessibility mode that replaces emoji and Unicode presentation with screen-reader-friendly ASCII or text.

## Best Possible Solution

Define one TUI-owned plain-presentation contract, load it once at startup, and apply canonical text/ASCII alternatives across tool summaries, selectors, separators, status indicators, spinners, and the verified pi-tui theme seam with screen-reader validation.
