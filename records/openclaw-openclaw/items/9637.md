Add an optional core TUI plain-text accessibility mode across config types, strict schema, generated labels/help, public TUI/config docs, TUI startup loading, tool display, selector/theme rendering, and focused rendering/config tests while preserving current rich glyph output by default unless maintainers choose otherwise.
