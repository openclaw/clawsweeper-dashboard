Request a TUI accessibility option to disable emojis and Unicode symbols so screen-reader users can use plain-text terminal output.

## Best Possible Solution

Land a maintainer-approved core TUI plain-text mode that updates config types/schema/help/docs, loads the setting once at TUI startup, threads it through all affected render surfaces, and proves ASCII output with focused config and TUI rendering tests.

## Solution Assessment

Unclear until maintainers choose the public config contract. A core TUI setting is the right boundary, but a narrow tool-display-only change would be too small because selectors, settings, status/waiting text, separators, and tool-card rendering also need coverage.
