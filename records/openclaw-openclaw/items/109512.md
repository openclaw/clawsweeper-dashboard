## What This Changes

The PR gives memory-embedding errors classified as rate limits a 30-second exponential backoff with a 120-second cap while retaining the existing short retry policy for other transient failures.

## Best Possible Solution

Keep short retries for generic transport failures, apply long waits only to confirmed temporary throttling using provider retry metadata or narrowly classified text, fail quota and billing exhaustion promptly with an actionable message, and prove the final behavior through a redacted real-provider indexing run.

## Solution Assessment

No. Longer backoff is appropriate for confirmed temporary throttling, but classifying every matching 429 or RESOURCE_EXHAUSTED message as temporary also delays permanent quota and billing failures; provider retry metadata or a narrower classifier is safer.
