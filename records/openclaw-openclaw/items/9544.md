## Summary

Keep open. Current main and the latest release still use Baileys useMultiFileAuthState for the bundled WhatsApp plugin, while the related consolidated-auth PR closed unmerged and the remaining storage/migration/security direction needs maintainer judgment.

## What This Changes

Request replacing the bundled WhatsApp plugin's Baileys multi-file credential and signal-key persistence with a production-safe SQL or database-backed auth store.

## Best Possible Solution

Keep this issue open for a maintainer-approved WhatsApp auth-store design that replaces Baileys multi-file key persistence, migrates existing auth dirs safely, preserves logout/status/setup behavior, and adds focused fresh-install, migration, recovery, and key-persistence proof.

## Reproduction Assessment
