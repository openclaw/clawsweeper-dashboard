## Summary

Keep open. Current main and v2026.6.11 still use Baileys `useMultiFileAuthState` for WhatsApp auth, and this MEMBER-authored, security-sensitive session storage migration needs maintainer direction rather than cleanup closure.

## What This Changes

Replace WhatsApp's Baileys `useMultiFileAuthState` with a production database-backed auth store for credentials and signal keys.

## Best Possible Solution

Replace Baileys multi-file auth in the WhatsApp plugin with SQLite-backed state plus plugin-owned doctor migration and security proof, preserving fresh install, upgrade, logout, status, backup, and signal-key behavior.
