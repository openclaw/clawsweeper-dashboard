## Summary

Keep open. Current main and latest release still use Baileys `useMultiFileAuthState` for WhatsApp auth, and this MEMBER-authored, security-sensitive storage migration needs maintainer product/security direction rather than conservative cleanup closure.

## What This Changes

Request replacing WhatsApp's Baileys multi-file JSON auth storage with a production database-backed or consolidated auth-state store with caching and safe migration.

## Best Possible Solution

Replace Baileys multi-file auth in the WhatsApp plugin with a maintainer-approved SQLite-backed state store plus plugin-owned doctor migration and security proof, preserving fresh install, upgrade, logout, status, backup recovery, and signal-key behavior.
