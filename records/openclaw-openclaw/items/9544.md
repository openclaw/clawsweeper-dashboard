## Summary

Keep open. Current main and v2026.6.11 still use Baileys `useMultiFileAuthState` for WhatsApp auth, and this MEMBER-authored, security-sensitive storage migration needs maintainer direction rather than conservative cleanup closure.

## What This Changes

The issue requests replacing the bundled WhatsApp Baileys multi-file auth state with a production database-backed auth store for credentials and signal keys.

## Best Possible Solution

Replace Baileys multi-file auth in the WhatsApp plugin with a SQLite-backed, plugin-owned store plus doctor migration and security proof that preserves fresh install, upgrade, logout, status, backup, and signal-key behavior.
