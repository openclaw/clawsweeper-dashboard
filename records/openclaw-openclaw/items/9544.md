## Summary

Keep open. Current main and v2026.6.11 still use Baileys `useMultiFileAuthState` for WhatsApp auth, and this MEMBER-authored credential/signal-key storage migration needs maintainer product and security direction rather than cleanup closure.

## What This Changes

The issue requests replacing the bundled WhatsApp plugin's Baileys multi-file auth-state storage with a production database-backed auth store for WhatsApp credentials and signal keys.

## Best Possible Solution

Replace Baileys multi-file auth in the WhatsApp plugin with SQLite-backed state plus plugin-owned doctor migration and security proof, preserving fresh install, upgrade, logout, status, backup, and signal-key behavior.
