Keep open: current main still exposes native JSON parser text through the QA Bus/Lab body reader, and no linked or searched PR has landed a fix. The attached patch comment points in the right narrow direction, but it is not a canonical repository fix.

## What This Changes

Reports that malformed JSON POST bodies to QA Bus/Lab HTTP endpoints leak parser-specific text instead of a stable QA HTTP diagnostic.

## Best Possible Solution

Normalize invalid JSON at the shared QA body-reader boundary so QA Bus and QA Lab return one stable malformed-body diagnostic while preserving empty-body `{}` behavior and existing size/time limit responses.
