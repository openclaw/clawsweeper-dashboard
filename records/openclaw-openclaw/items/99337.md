## Summary

Keep open: this targets a real MCP tool-filter ReDoS class, but the proposed cap still permits slow regex cases and the after-fix proof is not strong enough for a security-hardening merge.

## What This Changes

The PR adds a wildcard-count guard to both MCP tool-filter glob helpers before they convert simple `*` globs into regular expressions.

## Best Possible Solution

Replace both private helpers with a shared linear simple-glob matcher, preserve documented exact and `*` semantics, and add adversarial plus normal-pattern coverage before merge.

## Reproduction Assessment

Yes. Source inspection shows both helpers build regexes from configured MCP tool filters, and a read-only probe of the exact algorithm plus proposed cap reproduced multi-second matching with an allowed 24-wildcard pattern.

## Solution Assessment

No. The threshold is only a partial mitigation; the maintainable fix is to remove regex matching for simple `*` globs and use a linear segment matcher in both paths.
