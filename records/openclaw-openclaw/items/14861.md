## Summary

Keep open. Current main and the latest release still lack the requested redacted Gateway subsystem startup outcome summary; the Gmail missing-account path remains silent during normal startup, and the direct implementation PR is closed unmerged and conflicting.

## What This Changes

## Best Possible Solution

Land a fixed-vocabulary, redacted Gateway startup outcome summary after sidecars settle, covering Gmail watcher, hooks, channels, plugin services, recovery, and other startup sidecars without changing readiness semantics.

## Solution Assessment

Yes in direction, but not as an unreviewed log contract. The maintainable path is a fixed, redacted boot outcome collector rather than ad hoc warnings from each subsystem.
