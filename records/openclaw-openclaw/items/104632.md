## Summary

This PR is still necessary and the patch matches the gateway’s existing authority-scoped idempotency design: a timed-out client can reattach to the original in-flight action or its cached result without dispatching a second action. No concrete code defect was found, but the external PR lacks after-fix real gateway/channel proof, which remains a merge gate for this message-delivery change.

## What This Changes

Adds one-time timeout reconciliation for gateway-backed message actions by retrying with the original payload and idempotency key, plus focused tests and a gateway error-type export.

## Best Possible Solution

Keep the narrow same-key reconciliation and require a redacted delayed gateway/channel run proving one visible delivery; treat durable idempotency across gateway restarts as separate follow-up work if maintainers need that stronger guarantee.
