## Summary

Keep open: the deny-policy bypass is valid and the parse-boundary approach is focused, but the patch still changes the established manifest/runtime identity contract and the new Gateway-surface evidence is test-fixture output rather than after-fix proof from a real Gateway setup.

## Best Possible Solution

Preserve the manifest/runtime identity while deriving one lowercase policy key for deny, allow, entry, duplicate, and reserved-ID checks; add upgrade coverage for a mixed-case manifest with a matching runtime export and provide redacted real-Gateway registry or log proof.
