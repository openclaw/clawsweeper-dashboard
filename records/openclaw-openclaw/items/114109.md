## Summary

Keep open. The report gives a concrete current-release reproduction of a session-state regression after transient fallback, while the related closed reports establish a likely shared history but do not prove that current `main` or v2026.7.1 has corrected this exact persistence path.

## What This Changes

Prevent transient provider fallback from permanently replacing a session’s configured or explicitly selected model.

## System Context

Model selection combines configured defaults, user session overrides, and request-time provider fallback before an agent run starts. The selected route is persisted in session state and then affects later channel turns, restarts, and user-facing model/status commands.

## Architecture Diagram

  E -->|Yes| G[Use request fallback]

  H --> B

## Best Possible Solution

Trace the current model-resolution and session-write paths so automatic transient fallback remains request-scoped, while explicit user model selections remain durable; add regression coverage for recovery after a fallback, restart, and a normal later inbound turn.
