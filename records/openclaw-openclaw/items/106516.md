## What This Changes

Classify sandbox and Docker provisioning failures as non-retryable infrastructure errors so they fail once instead of consuming the model fallback chain.

## Best Possible Solution

Introduce a typed non-provider runtime or sandbox-provisioning failure at the sandbox boundary, make the fallback runner terminate immediately for that class, and verify the child and parent receive one clear infrastructure failure without matching error-message strings.
