## Summary

Keep this PR open. Current main accepts sender identity and owner status on embedded runs but the realtime consult boundary does not carry them, so the patch addresses a real owner-context gap. Before merge, a maintainer should confirm the new public realtime-voice SDK version contract and the contributor should provide redacted live evidence that an authenticated owner retains owner-only behavior through a consult; the `maintainer` label also requires explicit human handling.

## What This Changes

The PR forwards a realtime voice caller’s authenticated sender ID and owner flag into an embedded agent consult, and exports a capability version for external voice plugins.

## System Context

Realtime voice plugins authenticate a caller at ingress, then invoke OpenClaw’s shared consult runtime to run an agent and return speakable text. The consult runtime constructs embedded-agent parameters, where sender identity and owner status govern owner-aware tools and approval behavior.

## Best Possible Solution

Keep the core change narrowly limited to forwarding ingress-authenticated context, approve and document the stable host-plugin capability contract if it is needed, and add redacted live proof covering both authenticated-owner and unauthenticated-caller consult behavior.
