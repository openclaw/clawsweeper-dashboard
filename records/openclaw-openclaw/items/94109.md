## Summary

Keep open: the branch still skips every OpenClaw tsdown wrapper cleanup call in CI while the wrapper runs tsdown with `--no-clean`, and CI/Testbox restore built output trees before artifact builds. The pasted timing logs are useful, but they do not prove stale-output or restored-cache artifact safety.

## What This Changes

The branch wraps all four pre-tsdown cleanup calls in `scripts/tsdown-build.mjs` with `process.env.CI !== "true"` so CI skips OpenClaw wrapper cleanup before running tsdown.

## Best Possible Solution

Keep stale-output cleanup in CI by default, then optimize only a measured slow sub-step with focused regression coverage and Windows/Testbox proof for restored-cache artifact builds.
