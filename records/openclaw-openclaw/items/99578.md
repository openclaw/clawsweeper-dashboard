Full review comments:

- **[P2] Register the streamed aggregate echo before skipping final output:** `extensions/codex/src/app-server/event-projector.ts:1649`
  - body: This only stores raw echo keys for each emitted progress message. For streamed command output, the item is marked as streamed and the completed aggregate is skipped, so a raw assistant item containing the full formatted command output can miss the echo filter and be promoted into `assistantTexts` or `messagesSnapshot`, bypassing the replay cap this PR is trying to enforce.
  - confidence: 0.82
- **[P3] Avoid concatenating deltas after the replay buffer is capped:** `extensions/codex/src/app-server/event-projector.ts:2746`
  - body: This builds `current + delta` before truncating even when `current` already holds the capped replay text. A verbose command can keep forcing copies of the capped buffer plus each later delta on the projector hot path; append only the remaining slice while updating the original-length counter.
  - confidence: 0.78
