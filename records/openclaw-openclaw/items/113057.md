## What This Changes

This PR teaches native iOS chat to preserve canonical assistant image blocks, load gateway-managed image bytes with the active authenticated connection, and render bounded inline image attachments after history reloads.

## System Context

The gateway returns assistant chat content as typed blocks that are decoded into the shared OpenClaw chat model, persisted through transcript reconciliation, and rendered by the native iOS SwiftUI transcript. For managed images, the iOS transport retrieves bytes from the gateway-origin media endpoint using the current operator credentials, headers, and TLS-pinning configuration.
