## What This Changes

This PR teaches native iOS chat to retain canonical assistant image metadata, fetch authenticated managed image data from the active gateway connection, and render bounded inline image attachments after history reloads and reconnects.

## System Context

The gateway sends assistant transcript content to native iOS chat, which maps it into shared OpenClaw chat models and stores it in the transcript cache. The iOS view then uses the current gateway connection to retrieve managed media and render decoded image attachments in the chat transcript.
