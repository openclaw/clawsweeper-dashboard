## What This Changes

This PR makes embedded-agent run deadlines slide on progress events, adds unit coverage for that timeout behavior, and unconditionally enables lane heartbeat and timeout-abort callbacks for plugin-owned transports.

## System Context

The embedded-agent runner dispatches an attempt through either a native path or a plugin-provided agent harness, while separate run-budget and lane watchdogs decide when to abort or release work. Progress callbacks flow from the running attempt into timeout management, which then affects transcript completion and lane availability.

  D --> F[Lane watchdog]
  E --> G[Abort or complete attempt]
  F --> G
  G --> H[Transcript and session result]

Retain the plugin-owned transport boundary, add the activity reset only at the supported attempt-progress seam, and prove the fix with a redacted real multi-tool embedded run while covering both native and plugin-harness timeout behavior.
