## What This Changes

This PR refreshes an embedded agent run’s abort deadline when model or tool progress is reported, cancels superseded abort timers, and adds timeout regression tests.

## System Context

The embedded-agent runner starts model/tool work and uses a run-budget timer to stop work that is no longer progressing. Progress callbacks travel through the stream-runtime preparation layer into the timeout controller, which either permits the response to complete or aborts the run when its deadline expires.
