## What This Changes

This PR changes scoped agent-harness plugin activation to load missing plugin IDs into an unpublished registry and merge their registrations into the active registry without re-registering unrelated plugins.

## Best Possible Solution

Keep the narrow missing-plugin load, but land it only after an exact-head real Gateway run proves an unrelated active plugin remains usable and registers once, the newly requested harness works, and representative lifecycle surfaces remain intact across the scoped miss.
