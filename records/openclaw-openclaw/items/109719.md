## Summary

Keep open: the browser-direct design and real-provider proof are strong, but the current head introduces a source-reproducible compatibility regression for existing installations whose normal Talk transport is configured as `gateway-relay`.

## What This Changes

Adds Gemini Live browser-direct Video Talk with bounded one-frame-per-second camera streaming, `describe_view` handling, shared frame encoding, provider capability gating, lifecycle cleanup, documentation, and focused tests.

## Best Possible Solution

Keep provider selection configurable, but treat `camera-frame` as requiring the selected provider's browser-owned transport unless the caller explicitly requests `gateway-relay`; retain explicit camera consent, bounded frames, direct provider delivery, cleanup coverage, and clear continuous-stream disclosure.
