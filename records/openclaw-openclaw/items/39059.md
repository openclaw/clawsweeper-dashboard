## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Target the active auth-profile store:** `src/agents/auth-profiles/store.ts:526`
  - body: This new save path only seals legacy `auth-profiles.json`, but current main persists active auth profiles in `openclaw-agent.sqlite` as `store_json`. Rebasing this branch as-is would advertise credential sealing while leaving the real auth-profile store unsealed.
  - confidence: 0.9
- **[P1] Block plaintext downgrades without a passphrase:** `src/agents/auth-profiles/store.ts:438`
  - body: When the existing store is sealed and `OPENCLAW_PASSPHRASE` is missing, the loader returns `undefined`; this path can then treat the store as empty and write a new plaintext store after OAuth/legacy/external sync. That breaks the PR's fail-closed security claim and can leak or lose credentials.
  - confidence: 0.94
- **[P1] Write sealed credential files atomically and privately:** `src/infra/sealed-json-file.ts:113-114`
  - body: `writeFileSync(pathname, ...)` creates or truncates the credential file directly and only applies `chmod(0600)` afterward. Credential-bearing writes should use the repo's atomic/private write pattern so a failed write, permissive creation window, or symlink path cannot expose or clobber secrets.
  - confidence: 0.88
- **[P2] Preserve long-running final-response requests:** `src/gateway/client.ts:520-524`
  - body: This default timeout also applies when `expectFinal` is true and no per-call timeout is supplied. Current main intentionally avoids an implicit default for final-response requests, so the branch would break long-running gateway operations that first return `accepted` and finish later.
  - confidence: 0.82
- **[P2] Persist KDF parameters in the envelope:** `src/infra/sealed-json-file.ts:38-39`
  - body: The sealed format derives keys with implicit `scryptSync` defaults and stores no KDF metadata. Once files are written, that makes the strength hard to audit and future tuning ambiguous for already-sealed stores.
  - confidence: 0.78
