## What This Changes

This PR keeps newly created Workboard cards assigned to the currently selected named agent and replaces a native label wrapper that reopens the shared agent selector after a mouse selection.

## System Context

The Control UI stores a page-level agent scope and sends it into the Workboard view. Creating a card turns that scope or a named board filter into the card’s owner, then the returned card is filtered back into the visible board; the shared selector is also used by other scoped pages.
