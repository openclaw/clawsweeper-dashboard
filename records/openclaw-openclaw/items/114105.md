## Summary

## What This Changes

Correct the Qwen Token Plan curated model picker after a fleet-wide catalog pass listed an unavailable coding-plan model and omitted newer Token Plan family entries.

## System Context

The Qwen extension supplies static recommended model catalogs to OpenClaw’s provider picker and model-listing commands. A selected model then flows through the Token Plan request wrapper to Alibaba’s compatible OpenAI-style endpoint, so a catalog row must identify a model that the subscription gateway can actually serve.
