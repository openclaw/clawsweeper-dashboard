## Summary

This remains a valid, additive feature request: current voice-call documentation limits realtime media streaming to Twilio and Telnyx, while Plivo remains on the XML flow. The existing carrier-streaming adapter suggests a bounded implementation is plausible, but adding another commercial telephony integration to the bundled plugin needs an owner-sponsored product and security-contract decision before code work starts.

## What This Changes

Add Plivo bidirectional media streaming to the voice-call plugin so Plivo calls can use realtime voice agents with live barge-in and continuous audio.

## Best Possible Solution

Have the voice-call owner choose the packaging boundary, then implement Plivo behind the existing realtime configuration and stream-frame abstraction with carrier-specific authentication/session binding, bidirectional audio and barge-in tests, documentation, and redacted live-call proof.
