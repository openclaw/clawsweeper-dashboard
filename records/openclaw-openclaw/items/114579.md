## Summary

This remains a useful Feishu-plugin feature request: public Feishu plugin material exposes reactions and editing but not agent-visible message recall, and no merged canonical implementation was found. Because message recall is destructive and platform-constrained, it needs an owner decision on the supported action and policy before implementation.

## What This Changes

Add an agent action for the Feishu channel plugin to retract messages previously sent by the bot.

## System Context

Channel actions let an agent perform message-level operations after delivery. The Feishu plugin receives an action request, applies its enabled-action policy and message ownership constraints, then calls Feishu’s messaging API to affect the delivered chat message.

## Best Possible Solution

Implement a Feishu-plugin-owned generic delete action only after confirming the desired agent-visible policy; preserve explicit action controls and add focused coverage for bot ownership, expired recall windows, permissions, and API failures.
