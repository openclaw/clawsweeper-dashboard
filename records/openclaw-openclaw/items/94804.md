## Summary

Keep open: current main still only has lower-level targeted wake, hook ingress, delivery-context, and dedupe primitives; it does not implement the requested first-class async route registry with lifecycle, external-event matching, ambiguity handling, privacy policy, and safe action policy.

## What This Changes

The issue requests a framework-level async result routing contract that matches later external events to saved originating topic sessions, posts safe summaries, dedupes events, and wakes the saved session.

## Best Possible Solution

Keep this open for maintainer product/API review and define a narrow plugin-friendly async route contract that composes existing hooks, targeted wake, delivery context, dedupe, and approval policy before deciding whether any core-owned registry is warranted.
