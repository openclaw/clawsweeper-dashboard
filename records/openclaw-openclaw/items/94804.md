## Summary

Keep open: current main has targeted wake, hook mappings, delivery context, and plugin hook building blocks, but not the requested first-class async route registry with durable route lifecycle, event matching, ambiguity handling, privacy policy, dedupe, visible topic summary, and safe action policy.

## What This Changes

The issue requests a framework-level async result routing layer that maps later external events back to originating topic sessions, posts safe summaries, dedupes events, and wakes the saved session.

## Best Possible Solution

Define a narrow plugin/API-friendly async route contract first; only add a core Gateway registry if maintainers explicitly sponsor the storage, matching, privacy, dedupe, and approval-policy boundary.
