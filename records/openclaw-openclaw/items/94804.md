## Summary

Keep open: current main has targeted wake/sessionKey, hook ingress, delivery-context carry, and dedupe primitives, but not the requested first-class async route registry with lifecycle, event matching, ambiguity handling, visible topic summary routing, privacy policy, and safety policy.

## What This Changes

The issue requests a framework-level async result routing layer that maps later external events back to the originating topic session and can notify, summarize, wake, dedupe, and enforce safe action policy.

## Best Possible Solution

Define a narrow plugin/API-friendly async route contract that composes existing hooks, targeted wake, delivery context, dedupe, queued followups, and approval policy before deciding whether any core-owned registry is warranted.
