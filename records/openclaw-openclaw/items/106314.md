## What This Changes

The PR buffers Gmail watcher stderr across chunks, classifies bind errors before truncating the retained tail, and waits for child stdio closure before deciding whether to respawn.

## Best Possible Solution

Keep the close-based stderr-drain decision and bounded combined-text classifier, but record child spawn errors and suppress respawn from the subsequent close event, with regression coverage for both spawn failure and normal non-bind exits.
