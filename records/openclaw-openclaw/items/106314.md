## Summary

Keep open: the revised `close` boundary follows the Node child-process contract and the supplied real-process proof is adequate, but the bounded-tail implementation still misses some split bind markers when the completing stderr chunk exceeds 512 bytes.

## What This Changes

The PR carries Gmail watcher stderr across chunks and waits for child stdio closure before deciding whether to stop or respawn the watcher.

## Best Possible Solution

Match the combined previous tail and current chunk before truncating the retained suffix, then add a regression where the completing chunk has more than 512 trailing characters while preserving the new `close`-event decision boundary.
