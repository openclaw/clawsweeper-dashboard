## What This Changes

The PR adds local embedding-worker Node executable resolution before `fork()`, preferring the current executable, then a Homebrew stable symlink, then PATH, with focused resolver tests.

## Solution Assessment

Yes, this is now the right repair layer: the worker launch boundary resolves the executable before forking and preserves the existing failure when no replacement is found. The only remaining judgment is whether maintainers accept PATH fallback as the final recovery step.
