## Summary

Keep open: current main and the latest release still allow raw host exec to run OpenClaw config/model-default writes and gateway restarts under the documented full/off policy, while the broader confirmation-gate policy remains open for maintainer security/product direction at https://github.com/openclaw/openclaw/issues/23451.

## What This Changes

The issue asks OpenClaw to stop model-issued example config, model-switch, and gateway-restart commands from executing without explicit user confirmation.

## Best Possible Solution

Define a hard, tested exec-boundary policy for model-initiated OpenClaw self-management commands, coordinated with the broader confirmation-gate design and existing exec/plugin approval paths.
