## What This Changes

The issue reports a v2026.6.9+ regression where Codex app-server heartbeat/internal turns become `webchat`-bound and silently lose Discord heartbeat notifications under the cross-context guard.

## Best Possible Solution

Land a narrow runtime fix that removes the internal `webchat` binding only for Codex heartbeat/cron/inter-session turns, keeps genuine WebChat user turns bound, and preserves regression coverage for both delivery and containment.
