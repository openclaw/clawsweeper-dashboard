## Summary

Keep open: current main and latest v2026.6.11 still contain the Codex internal-turn `webchat` binding that can trip the default cross-provider outbound guard and silently suppress heartbeat-style Discord notifications. The work is now owned by open PR #102232, which appears to be the scoped fix path, so the issue should stay open until that PR or an equivalent repair lands.

## What This Changes

Codex-backed heartbeat, cron, and inter-session internal turns can be stamped as `webchat`, causing cross-provider message sends such as Discord notifications to be denied while the heartbeat tool can still report success.

## Best Possible Solution

Review and land #102232 or an equivalent scoped resolver fix that drops only spurious internal `webchat` containment for heartbeat, cron, and inter-session turns while preserving genuine WebChat conversation guarding.
