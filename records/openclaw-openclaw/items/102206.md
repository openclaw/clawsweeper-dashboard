## Summary

Keep open: current main and the latest checked release still carry the reported Codex app-server channel binding path, so heartbeat-originated Discord message sends can still hit the default cross-provider denial instead of being proven fixed.

## What This Changes

Fix a v2026.6.9+ regression where Codex app-server heartbeat/internal turns are stamped as `webchat`-bound, causing Discord heartbeat notification sends to be denied while the heartbeat outcome can still report success.

## Best Possible Solution

Keep the cross-provider guard for real channel-bound turns, but make heartbeat/internal Codex app-server turns avoid a deliverable `webchat` provider binding and add regression coverage that failed notification sends cannot be masked by heartbeat success.
