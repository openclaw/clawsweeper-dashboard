## What This Changes

The issue reports a v2026.6.9 regression where Codex internal heartbeat turns are treated as `webchat`-bound, causing Discord heartbeat `message` sends to be denied while the heartbeat still appears successful.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/102232 or an equivalent scoped fix that drops the internal `webchat` binding only for heartbeat, cron, and inter-session Codex turns while preserving real WebChat containment.
