## Summary

Keep the PR open: it fixed the prior hidden-`x` blocker, but current head still unwraps `bun --cwd ./pkg x ...` as Bunx even though upstream Bun dispatches that argv shape as AutoCommand, so the approval target can be wrong.

## What This Changes

The PR adds Bun `x` handling to package-manager exec approval resolution and tests persistence, allowlist matching, and node-host mutable operand binding.

## Best Possible Solution

Only unwrap Bun when Bun itself dispatches to Bunx; leave ordinary AutoCommand/global-option forms outside package-manager binding or fail closed with targeted approval tests.
