## What This Changes

The PR updates PR-preparation scripts to detect ancestry-rewriting rebases, publish same-repository rebased heads with a leased Git push, and refuse unsafe cross-repository GraphQL publication.

## System Context

`scripts/pr prepare-sync-head` publishes a locally prepared pull-request head after rebase and validation. Its push-mode decision chooses either GitHub GraphQL or a leased Git push, and the resulting remote parent determines whether GitHub’s three-dot PR diff remains focused.

Keep the split publication model: use a leased Git push only when a same-repository prepared head must change ancestry, retain GraphQL for ancestry-preserving updates, and fail closed for cross-repository ancestry rewrites until a safe owner-authorized path exists.
