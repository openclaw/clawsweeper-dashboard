  - body: The new CI job uses floating major tags for `actions/checkout` and `actions/upload-artifact`, while current workflows pin these actions to commit SHAs.   - confidence: 0.92

  - body: Boundary and module labels come from repository paths controlled by the PR, then get interpolated into Mermaid and Markdown without escaping quotes, newlines, brackets, or HTML-sensitive characters.   - confidence: 0.86

  - body: This buffers up to 64 MiB of dependency-cruiser JSON in memory and then parses the whole string, with the graph size controlled by PR contents. Stream the output to an artifact with a size limit or otherwise bound the module/edge count before parsing so an oversized PR cannot spike or fail the CI report job.
  - confidence: 0.84
- **[P2] Move the report off Blacksmith runners:** `.github/workflows/ci.yml:969`
  - body: This adds an advisory summary/artifact job on a 16-vCPU Blacksmith runner even though the CI limits guidance keeps summarizing jobs on hosted runners unless measured evidence shows Blacksmith is required. Please use `ubuntu-24.04` or include timing/capacity proof for the self-hosted runner choice.
  - confidence: 0.88
