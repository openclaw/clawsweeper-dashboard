  - confidence: 0.82

  - body: The report job buffers the entire dependency-cruiser JSON output in memory and then parses it. On PR-controlled source graphs this can turn an advisory report into a reliable CI availability failure; stream to a file or use `--output-to` plus a size check before parsing.
  - confidence: 0.84
- **[P2] Move advisory reporting off Blacksmith capacity:** `.github/workflows/ci.yml:969`
  - body: This short, non-blocking summary/artifact job reserves a `blacksmith-16vcpu-ubuntu-2404` runner. CI docs say routing/summarizing jobs should stay on hosted runners unless measured Blacksmith-specific needs exist, so this needs hosted execution or registration-budget proof.
