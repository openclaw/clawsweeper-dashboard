## What This Changes

The branch passes QQBot's plugin runtime current-config accessor into the gateway engine, removes the global snapshot fallback, and adds focused coverage for the bridge wiring.

## System Context

QQBot's bridge starts the channel gateway and supplies runtime services to the message engine. The engine reads routing bindings for inbound messages and approval interactions, so the config accessor determines whether edits take effect immediately or a runtime lifecycle failure is surfaced.
