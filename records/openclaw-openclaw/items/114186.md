## What This Changes

This PR disables embedded-agent trajectory capture for one-shot JSON-only `llm-task` helper runs and checks that both tools and trajectories are disabled.

## System Context

The `llm-task` plugin invokes an embedded agent for a one-shot JSON helper call and returns the collected result to the calling agent. The embedded runner can otherwise create trajectory records that are flushed during cleanup, so the flag controls whether these temporary runs enter that persistence path.
