## What This Changes

This PR stores queued follow-up messages in shared SQLite, migrates the retired JSON sidecar through Doctor, restores queues after gateway restart, and wakes affected sessions so the normal queue drain can deliver them.

## System Context

Follow-up queues hold messages received while an agent turn is active. This change moves that queue from process memory into OpenClaw’s shared state database, then uses gateway startup and heartbeat wake handling to resume delivery after a restart.
