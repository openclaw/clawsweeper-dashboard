## Summary

Keep open: current main covers adjacent cron CRUD/run history/delete-after-run UI, Web Push settings, and an inline context ring with Compact action, but it still lacks the generic in-app notification/action queue, actionable cron-result popups, snooze/reschedule flow, and context-warning toast workflow requested here.

## What This Changes

Request to add Control UI in-app notifications for cron results and context pressure, including cron popup actions, snooze/reschedule, one-shot UI exposure, and context flush/compact prompts.

## Best Possible Solution

Define one shared connected-Control-UI notification/action contract first, then wire cron-finished actions and context-pressure actions into it with explicit cron snooze semantics, authorization boundaries, focused tests, and browser proof.
