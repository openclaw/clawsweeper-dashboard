## Summary

Keep open. Current main still only partially covers the request: Web Push settings, cron edit/history/delete-after-run UI, cron finished delivery hooks, and an inline context usage/compact control exist, but the central in-app toast queue, actionable cron-result popup layer, and snooze/reschedule flow are still missing.

## What This Changes

The issue requests a native WebUI notification/toast system with cron-result management popups, snooze/reschedule controls, and context usage warning prompts with a flush/compact action.

## Best Possible Solution

Scope this as product-led Control UI notification architecture: one in-app notification/action queue, cron-finished actionable notifications, explicit snooze/reschedule semantics, and a decision on whether context pressure remains inline-only or also emits prompts.
