## Summary

Keep open. Current main and the latest release still only partially cover this broad WebUI request: Web Push settings, cron editing/delete-after-run, run history, cron events, and inline context-pressure indicators exist, but there is still no generic Control UI toast queue, no actionable cron-result popup/snooze flow, and no decided product boundary for context-warning notifications.

## What This Changes

Request to add a native WebUI notification/toast system with actionable cron job result popups, snooze/reschedule controls, inline cron management, one-shot job UI, and context usage warnings with a flush/compact action.

## Best Possible Solution

Scope this into focused maintainer-led design for a generic connected-Control-UI notification queue, cron-finished actionable result notifications with explicit snooze semantics, and a context-pressure policy that decides inline-only versus notification prompts.
