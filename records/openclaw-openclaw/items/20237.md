Keep open. ## What This Changes

Request to add a native Control UI notification/toast system with actionable cron-result popups, inline cron management and snooze/reschedule controls, one-shot job UI exposure, and context-usage warnings with a compact/flush action.

## Best Possible Solution

Scope this as product-led Control UI notification architecture: one in-app notification queue/action contract, cron-finished actionable notifications, explicit snooze/reschedule semantics, and a decision on whether context pressure remains inline-only or also emits prompts.
