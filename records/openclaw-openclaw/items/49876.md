## Summary

Keep open: current main has targeted cron/tool-error hardening, but ordinary failed or missing tool work can still be followed by final assistant text that becomes scheduled output, so the reported trust and delivery-boundary problem remains.

## What This Changes

Cron or unattended agent sessions should fail closed or suppress delivery when tool calls fail or the task cannot be verified, instead of sending fabricated or placeholder output.

## Best Possible Solution

Define a core cron/unattended finalization contract that derives deliverability from structured run and tool state, preserves explicitly verified recovery, and suppresses or cleanly errors unsupported success-looking assistant text before delivery.
