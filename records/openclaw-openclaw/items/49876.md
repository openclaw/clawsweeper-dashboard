## Summary

Keep open: current main has targeted cron/tool-error hardening, but it still lacks a general fail-closed or ledger-backed finalization policy for fabricated final output after failed or missing tool work.

## What This Changes

Issue #49876 asks OpenClaw to prevent cron and tool-backed agent sessions from delivering fabricated, placeholder, or unsupported success output when required tool work failed or never happened.

## Best Possible Solution

Define a maintainer-approved core finalization policy for unattended and tool-backed turns that uses structured run/tool state to suppress, replace, or clearly mark unsupported output without relying only on model self-suppression or marker text.

## Reproduction Assessment

Source-reproducible: current main still has final-output recovery paths and no general ledger-backed gate, but this review did not run a live cron or interactive repro.

## Solution Assessment

No; current main's targeted cron hardening is incomplete and the issue's marker-filter proposal is too narrow without structured failed-tool and unsupported-claim finalization semantics.
