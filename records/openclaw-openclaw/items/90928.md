## Summary

Current main resolves the central no-GMS launch/setup problem by replacing the old Google Play Services Code Scanner path with an ML Kit/CameraX scanner plus setup-code/manual fallbacks; broader non-Play APK distribution remains separately tracked.

## What This Changes

The issue requests HarmonyOS/Huawei no-GMS support for the Android app so it can launch and pair without Google Mobile Services.

## Best Possible Solution

Keep the current ML Kit/CameraX setup scanner and setup-code/manual fallbacks as the no-GMS launch/setup fix, while leaving AppGallery, Huawei Push, and official non-Play APK distribution to the broader Android distribution tracker.
