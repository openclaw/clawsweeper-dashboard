## What This Changes

The PR makes embedded agent runs return an actionable timeout reply when a tool-execution budget timeout would otherwise finish with no visible user response, while preserving intentionally silent and resumable terminal states.

## System Context

The embedded-agent runner converts an attempted model/tool turn into reply payloads and a persisted liveness state. Its terminal-resolution path receives timeout and delivery evidence, then feeds the gateway and channels with either visible output, a resumable state, or a deliberately silent completion.
