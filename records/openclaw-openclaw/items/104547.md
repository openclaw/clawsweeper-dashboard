## Summary

This PR remains necessary: current main still skips all runtime-auth output protection when the source key is neither a sentinel nor redaction-registered, allowing Mantle’s IAM marker to produce a plaintext bearer token. The output-sensitive fix is the best shared-boundary repair, the prior caller-test findings are resolved at the current head, and the contributor supplies convincing live behavior proof; merge should follow a current-main refresh and security/auth owner review.

## What This Changes

The branch removes source-key gating from provider runtime-auth protection, preserves recognized non-secret markers, sentinel-protects other exchange outputs, and updates affected Copilot, Mantle, image, and BTW assertions.

## Best Possible Solution

Refresh the branch against current main, retain the generic output-sensitive guard, verify the affected provider-auth and caller tests on the refreshed head, and merge after security/auth ownership confirms that only canonical non-secret markers bypass protection.
