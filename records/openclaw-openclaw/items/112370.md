## What This Changes

The PR changes the shared streaming-draft retry path so a newer pending update is retained when a send-or-edit operation returns `false`, and adds a regression test for that race.

## System Context

Channel adapters use the shared draft stream loop to coalesce partial agent output before sending or editing a preview. An adapter reports send success or a deferred/failed result to the loop, which then either advances its send state or keeps text pending for a later flush.
