## Summary

Keep open: current main and the latest release still provide the SecretRef/runtime foundation, but Control UI still renders structured SecretRefs as generic read-only empty fields instead of source-aware env/config/unset secret UX.

## What This Changes

Request first-class CLI and Control UI UX for env-backed secret config, including masked source-aware display, env reference preservation, and guidance away from plaintext secrets in `openclaw.json`.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow with masked labels, safe resolved/unresolved state, explicit config/env/unset editing, and aligned docs plus UI/gateway SecretRef tests.
