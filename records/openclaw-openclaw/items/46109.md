## Summary

Keep open: current main has a solid SecretRef runtime, CLI, redaction, and docs foundation, but the requested source-aware Control UI/config UX is still missing and needs maintainer product/security direction before implementation.

## What This Changes

The issue requests first-class source-aware secret configuration UX for `.env`/environment-backed secrets in the CLI and Control UI.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow on top of existing SecretRef contracts, with masked display, safe source labels, optional env identity, resolved/unresolved state, explicit config/env/unset editing, and aligned docs/tests.
