## Summary

Keep open: current main and the latest release have strong SecretRef/runtime foundations, but the requested source-aware Control UI and config UX is still missing and needs a maintainer security/product decision before implementation.

## What This Changes

The issue requests first-class `.env` and environment-backed secret config UX, including masked source badges, env-reference editing, and clearer `config`/`env`/`unset` state in Control UI and CLI surfaces.

## Best Possible Solution

Define one safe SecretRef source-awareness contract, then add masked Control UI source badges, env-reference editing, resolved/unresolved diagnostics, and matching CLI/docs behavior on top of the existing SecretRef runtime.
