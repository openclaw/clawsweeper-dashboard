## Summary

Keep open: current main has solid SecretRef runtime, redaction, CLI, and docs foundations, but it still does not provide the requested source-aware Control UI/config UX for env-backed secrets.

## What This Changes

Request first-class `.env` / environment-backed secret UX so secret fields show config/env/unset source state, preserve env references, and avoid blank-looking Control UI fields.

## Best Possible Solution

Add a maintainer-approved SecretInput renderer and metadata flow with masked source labels, safe env identity/resolution disclosure, config/env/unset editing, and aligned docs/tests on the existing SecretRef contracts.
