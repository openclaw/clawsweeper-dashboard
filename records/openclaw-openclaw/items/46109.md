## Summary

Keep open: current main and the latest release still render structured env SecretRefs as generic read-only empty fields, while the existing SecretRef CLI/runtime support is only the foundation for the requested source-aware UX.

## What This Changes

The issue requests first-class environment-backed secret UX across config and Control UI so env-sourced secrets are visible as masked/source-aware rather than blank.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow that shows masked source/resolution state, preserves SecretRef editing, and avoids exposing more secret metadata than policy allows.
