The issue requests first-class CLI and Control UI UX for secrets sourced from environment variables, including source badges, preserved env references, and safer migration guidance.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow: masked display, safe source labels, optional env identity where allowed, resolved/unresolved state, explicit config/env/unset editing, and aligned docs/tests on the existing SecretRef contracts.
