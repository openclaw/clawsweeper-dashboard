## Summary

Keep open: current main and v2026.6.11 still have the generic read-only SecretRef Control UI behavior, while the requested env/config/unset source-aware UX remains a security-sensitive product decision rather than cleanup-closeable work.

## What This Changes

Add first-class env-backed SecretRef UX in CLI and Control UI so secret fields show source/resolution state and preserve or edit env references without exposing values.

## Best Possible Solution

Define one safe SecretRef source-metadata contract, then add masked Control UI source badges, env-reference editing, resolved/unresolved diagnostics, and aligned CLI/docs behavior on top of the existing SecretRef runtime.
