Keep open: current main and the latest release still provide SecretRef runtime/redaction foundations, but the requested first-class source-aware Control UI/config UX is not implemented and needs a maintainer security/UX decision before a fix PR is safe.

## What This Changes

The issue requests first-class `.env` and environment-backed secret UX, including source-aware secret fields, env-reference preservation, masked-but-visible status, and clearer migration guidance in CLI and Control UI.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow that keeps values masked, shows safe source/resolution state, supports explicit config/env/unset editing, and stays aligned with the existing SecretRef registry, write preflight, and docs.
