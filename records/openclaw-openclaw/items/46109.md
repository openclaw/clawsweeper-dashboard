## Summary

Keep open: current main and v2026.6.11 have solid SecretRef runtime, redaction/restore, CLI, and docs foundations, but the requested first-class source-aware Control UI/config UX is still missing and needs maintainer product/security direction.

## What This Changes

The issue requests first-class `.env` and environment-backed secret awareness in OpenClaw's CLI and Control UI config experience.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow on top of existing SecretRef contracts, with masked display, safe source labels, optional env identity, resolved/unresolved state, explicit config/env/unset editing, and aligned docs/tests.
