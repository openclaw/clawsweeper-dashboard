## Summary

Keep open: current main still renders env-backed SecretRefs as generic read-only structured values, so the requested source-aware Control UI/config UX is not implemented and needs a maintainer security/product decision.

## What This Changes

The issue requests first-class `.env` and environment-backed secret configuration UX across CLI and Control UI, including source badges, env reference preservation, and safer secret migration guidance.

## Best Possible Solution

Add a maintainer-approved source-aware SecretInput renderer and metadata flow that keeps values masked, shows safe source/resolution status, supports explicit config/env/unset editing, and stays aligned with SecretRef registry, redaction, docs, and tests.
