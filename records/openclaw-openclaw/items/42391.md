## Summary

Keep open: current main and v2026.6.11 still omit structured numeric metrics from the relevant plugin hook event types, producers, and docs; this is a public Plugin SDK semantics decision, not a conservative cleanup close.

## What This Changes

The issue requests optional structured progress metrics on existing plugin hook events so plugin-based live progress cards can render numeric progress.

## Best Possible Solution

Define a producer-owned optional progress metrics contract for plugin hooks, emit only authoritative values, document unknowns as absent, and cover each affected producer with focused SDK and docs tests.
