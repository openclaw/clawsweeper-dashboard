## Summary

Keep open: current main and the latest stable release still omit structured numeric progress metrics from the relevant plugin hook payloads, and adding them would define new public Plugin SDK semantics rather than conservative cleanup.

## What This Changes

The issue requests optional structured progress metrics on `before_tool_call`, `after_tool_call`, and `agent_end` hook events so plugin-rendered live progress cards can show numeric completion.

## Best Possible Solution

Define a producer-owned optional progress metrics contract, emit only authoritative values, document unknowns as absent, and cover each affected hook producer with focused SDK/docs tests.
