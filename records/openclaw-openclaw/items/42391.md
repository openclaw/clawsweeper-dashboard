## Summary

Keep open: current main and the latest release still omit structured numeric progress metrics from the requested plugin hook payloads, and nearby hook-observability issues do not define the requested progress contract.

## What This Changes

The issue asks OpenClaw to add optional structured progress metrics such as step counts, percent, and ETA to existing plugin hook events for live progress-card rendering.

## Best Possible Solution

Define an optional producer-owned progress metrics contract in the Plugin SDK, emit only authoritative values, document unknowns as absent, and cover the affected hook producers with focused tests.

- **Design a separate progress event:** Introduce a dedicated progress event or agent-event projection instead of attaching percentages to tool and terminal hooks.
