## Summary

Keep open: current main and the latest stable release still lack the requested structured numeric progress metrics on `before_tool_call`, `after_tool_call`, and `agent_end` hook payloads. The Feishu progress-card integration context is useful, but the remaining OpenClaw work is a public Plugin SDK semantics decision, not a conservative cleanup close.

## What This Changes

The issue requests optional structured numeric progress metrics on existing plugin hook payloads so plugin-rendered live progress cards can show step counts or percent complete.

## Best Possible Solution

Define a producer-owned optional progress metrics contract for plugin hooks, emit only authoritative values, document unknowns as absent, and cover each affected producer with focused SDK and docs tests.
