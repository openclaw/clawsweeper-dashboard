## Summary

Keep open: current main and the latest release still lack structured numeric metrics on the relevant plugin hook payloads, and adding them is a public Plugin SDK semantics decision rather than conservative cleanup.

## What This Changes

The issue asks OpenClaw to add optional structured progress metrics to existing plugin hook events so plugin-rendered live progress cards can show numeric completion.

## Best Possible Solution

Define a producer-owned optional metrics contract for plugin hooks that emits only authoritative values, documents unknowns as absent, and covers the affected tool and agent-end producers with focused SDK/docs tests.
