## Summary

Keep open: current main and the latest stable release still lack the requested structured numeric progress metrics on plugin hook payloads, and adding them is a public Plugin SDK semantics decision rather than a conservative cleanup close.

## What This Changes

The issue asks OpenClaw to add optional structured progress metrics such as step index, total, percent, and ETA to existing plugin hook events for live progress-card plugins.

## Best Possible Solution

Define a producer-owned optional progress metrics contract for plugin hooks, emit only authoritative values, document unknowns as absent, and cover each affected producer with focused SDK and docs tests.
