## Summary

Keep open: current main and v2026.6.11 still omit structured numeric progress metrics from the relevant plugin hook event types, producers, tests, and public docs, so this remains a public Plugin SDK product decision rather than conservative cleanup.

## What This Changes

Request structured progress metrics on existing plugin hook payloads so live progress-card plugins can render numeric completion.

## Best Possible Solution

Define a producer-owned optional progress metrics contract for plugin hooks, emit only authoritative values, document unknowns as absent, and cover each affected producer with focused SDK and docs tests.
