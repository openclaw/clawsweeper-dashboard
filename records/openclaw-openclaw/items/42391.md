## Summary

Keep open: current main and v2026.6.11 still do not expose the requested numeric progress metrics on the relevant plugin hook payloads, and this is a public Plugin SDK semantics decision rather than a narrow bug fix.

## What This Changes

The issue requests optional structured progress metrics on existing plugin hook payloads so live progress-card plugins can render numeric completion.

## Best Possible Solution

Define an optional producer-owned progress metrics contract in the Plugin SDK, emit only authoritative values, document unknowns as absent, and cover the affected hook producers with focused tests.

Unclear as proposed. Enriching hook payloads is plausible, but the best maintainable solution needs a producer-owned metrics contract and explicit absent-value semantics before implementation.
