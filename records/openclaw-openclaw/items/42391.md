## Summary

Keep open: current main and latest release still do not expose the requested structured numeric progress metrics on the relevant plugin hook payloads, and adding them would define public Plugin SDK semantics that need maintainer product direction.

## What This Changes

The issue requests optional structured progress metrics on existing plugin hook payloads for plugin-based live progress-card renderers.

## Best Possible Solution

Define a producer-owned optional progress metrics contract for plugin hooks, emit only authoritative values, document unknowns as absent, and cover each affected producer with focused SDK/docs tests.
