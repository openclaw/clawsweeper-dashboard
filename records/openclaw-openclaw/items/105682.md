## Summary

Current main and shipped releases already satisfy the report: every socket close enters shared teardown, which cancels the handshake timer before any client-dependent cleanup. This invariant has existed since the Gateway WebSocket control plane was introduced, so the alleged leak is not reproducible against current or released code.

## What This Changes

Ensure an aborted pre-auth Gateway WebSocket connection cancels its handshake timeout and does not later log a false timeout warning.

## Best Possible Solution

Retain the single shared teardown path; a separate narrow test improvement could close a pre-auth socket, advance fake timers, and assert that no handshake-timeout warning occurs.
