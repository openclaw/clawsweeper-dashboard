## Summary

Keep open: current main and v2026.6.11 still let legacy GitHub Copilot OAuth refresh build a token endpoint from persisted `enterpriseUrl`, while the newer plugin/config allowlist does not cover that legacy refresh path.

## What This Changes

The issue requests hardening legacy GitHub Copilot OAuth token refresh so persisted `enterpriseUrl` values cannot redirect bearer refresh tokens to arbitrary hosts.

## Best Possible Solution

Apply a narrow security fix that routes every legacy GitHub Copilot OAuth `enterpriseUrl` through the existing `github.com`/single-label `*.ghe.com` allowlist before any token-bearing request, with regression coverage for migrated and persisted legacy credentials.
