## What This Changes

The branch adds capability-gated native Apple Messages polls for iMessage approval prompts, binds returned poll-option IDs to authorized approval decisions, and retains text, tapback, and manual-command fallbacks.

## System Context

The iMessage plugin turns outbound approval requests into Messages controls and consumes inbound poll votes. Its poll binding and ingress path pass an authorized decision to the Gateway approval resolver, which records the terminal approval outcome.
