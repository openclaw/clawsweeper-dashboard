## What This Changes

This PR adds capability-gated native Apple Messages polls for iMessage approval prompts, persists opaque poll-option bindings, and keeps reaction and text-command approval fallbacks when polling cannot be used.

## System Context

The iMessage plugin renders approval prompts and receives native Messages events, then resolves an approved or denied request through the Gateway. This change inserts a poll-control path between approval delivery and the existing durable approval-resolution flow while retaining older reaction and text-command paths.
