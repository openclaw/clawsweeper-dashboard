## What This Changes

This PR adds capability-gated native Apple Messages poll controls for iMessage approval prompts, while retaining tapback and manual-command fallbacks when the bridge cannot safely provide polls.

## System Context

The iMessage plugin renders approval requests sent by the gateway, then receives Messages events back through its monitor. This change sends a poll after the approval details, binds the bridge-minted poll option IDs to allowed approval decisions, and resolves authorized vote events before they become agent chat input.
