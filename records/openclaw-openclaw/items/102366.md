## Summary

The patch is technically coherent and preserves ESM as the default, but this PR has a protected `maintainer` label and introduces a permanent compatibility-sensitive package-build metadata seam. Keep it open until a package-runtime owner confirms that seam and the contributor demonstrates the packed Microsoft Teams runtime and setup entrypoints loading in a real installation.

## What This Changes

The PR adds an opt-in CommonJS format to the publishable plugin runtime builder, rewrites generated internal sidecar specifiers, enables `.cjs` output for Microsoft Teams, and adds centralized artifact-build coverage.

## Best Possible Solution

Use one opt-in format value to drive tsdown output, runtime/setup metadata, and sidecar specifiers while preserving ESM for every non-opted-in plugin, then prove a packed Microsoft Teams package can load both generated entrypoints under Node before landing.
