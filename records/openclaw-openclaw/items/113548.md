## What This Changes

Adds opt-in per-agent daily alerts for text-model spend, persisting provider costs in agent SQLite state and appending pending notices only to configured owner direct replies.

## System Context

The agent runtime receives terminal text-model call usage from foreground turns, compaction, and worker inference, then records eligible per-agent provider cost. The reply-delivery layer claims pending alerts only for configured owner direct messages and settles their durable delivery state.
