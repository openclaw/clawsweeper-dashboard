## What This Changes

Adds opt-in per-agent daily text-model spend alerts that record provider costs in each agent database and append threshold notices only to configured owner direct-message replies.

## System Context

Agent, compaction, and worker model calls emit terminal usage observations that feed per-agent spend accounting. Pending threshold alerts persist in the agent database and are attached only when a final reply is going to an explicitly configured owner direct-message route.
