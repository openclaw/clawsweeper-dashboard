## What This Changes

The PR adds opt-in per-agent daily text-model spend alerts, recording provider costs in each agent database and appending pending notices only to final replies sent through configured owner direct-message routes.

## System Context

Foreground agent turns, compaction, and gateway worker inference each produce text-model usage; this change collects configured provider costs into per-agent SQLite state. Final channel replies then either claim and settle the alert for an approved owner DM or leave it pending for a later safe delivery route.

## Best Possible Solution

Obtain explicit sponsorship for a narrowly documented core alerting contract, including authoritative-versus-estimated cost semantics, storage retention and repair ownership, timezone behavior, and the privacy/delivery guarantee for owner routes; otherwise keep proactive spend reporting outside this core configuration surface.
