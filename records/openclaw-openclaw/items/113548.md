## What This Changes

Adds opt-in per-agent daily text-model spend alerts that persist provider spend in each agent database and append threshold notifications only to configured owner private replies.

## System Context

Agent inference, compaction, and worker model calls produce terminal usage observations. This PR turns eligible observations into per-agent daily accounting state, then appends pending alerts when a final reply is going to an explicitly configured owner direct message.
