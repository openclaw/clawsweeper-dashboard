## What This Changes

This PR adds opt-in per-agent daily text-model spend alerts, records eligible model costs in the per-agent SQLite database, and appends pending alerts to configured owners' private final replies.

## System Context

OpenClaw's agent runner and worker inference paths produce terminal model-call usage, while reply-delivery paths send final responses through channels. This PR inserts cost accounting between those stages, persists per-agent alert state, and conditionally adds a notice only when the final route is a configured private owner route.
