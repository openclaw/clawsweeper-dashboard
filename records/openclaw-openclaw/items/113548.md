## What This Changes

This PR adds opt-in per-agent daily text-model spend alerts that persist per-provider usage in agent SQLite state and append threshold notices only to configured owner direct-message replies.

## System Context

Agent runs invoke text models through foreground, compaction, and worker paths, then channel and reply pipelines deliver final responses. The feature records eligible model-call cost per agent, stores pending alerts durably, and claims them only when a final reply targets a configured private owner route.
