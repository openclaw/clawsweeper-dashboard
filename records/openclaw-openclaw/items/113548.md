Adds opt-in per-agent daily text-model spend accounting in SQLite and appends threshold alerts to configured owners’ final private replies.

## System Context

Model calls from foreground agent runs, compaction, and gateway workers emit terminal usage data. This feature aggregates that usage per agent and provider, then conditionally adds a private owner-facing alert to the final outbound reply.
