## What This Changes

Adds opt-in `agents.entries.*.modelSpend` settings that persist per-agent/provider daily text-model costs and append threshold alerts to configured private owner replies.

## System Context

Text-model calls flow through embedded agent turns, compaction, and gateway worker inference before final replies reach channel delivery. This PR records those calls in each agent’s SQLite state, detects daily provider thresholds, and conditionally adds an informational notice to a private owner reply.

## Architecture Diagram

  B --> C[Per-agent SQLite daily totals]
  C --> D[Daily threshold decision]
  D --> E[Private owner-route check]
  E --> F[Final channel reply with alert]
