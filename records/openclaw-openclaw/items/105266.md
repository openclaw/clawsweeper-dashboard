Investigate and fix nondeterministic Control UI locale-rendering test failures caused by shared i18n state or asynchronous locale loading.

## Best Possible Solution

Sequence locale operations so stale lazy loads cannot commit after newer state, notify active consumers when their translation map changes, and prove the invariant with controlled overlap tests plus repeated full-UI and exact-shard runs.
