## Summary

Keep open: current main and v2026.6.11 have useful opt-in Docker/SSH/OpenShell sandbox backends and a plugin-facing backend seam, but they do not implement the central request for secure-by-default tiered presets, plugin/process isolation, IPC-proxied plugin execution, per-plugin env/fs/net/resource manifest policies, or default credential scoping.

## What This Changes

The issue requests a unified, multi-platform sandbox architecture with tiered presets, plugin/process isolation, IPC proxying, manifest-declared capabilities, credential scoping, and resource limits.

## Best Possible Solution

Keep this as the canonical sandbox/isolation architecture tracker until maintainers split it into reviewed milestones for defaults, plugin/process isolation, IPC proxying, manifest policy, credential scoping, resource limits, and upgrade guidance.
