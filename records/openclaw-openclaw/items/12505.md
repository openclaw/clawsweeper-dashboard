## Summary

Keep open: current main has useful opt-in sandbox backends and a plugin SDK seam for sandbox backends, but it still does not implement the central request for secure-by-default tiered presets, plugin/process isolation, IPC-proxied plugin execution, per-plugin env/fs/net/resource manifest policy, or default credential scoping.

## What This Changes

The issue requests a unified secure-by-default sandbox architecture with multi-platform isolation backends, tiered presets, manifest-declared plugin capabilities, credential scoping, IPC-proxied plugin execution, and resource controls.

## Best Possible Solution

Keep this as the canonical sandbox/isolation architecture tracker and split it into reviewed milestones for default posture, plugin/process boundaries, manifest policy shape, credential scoping, migration compatibility, and backend-specific proof.
