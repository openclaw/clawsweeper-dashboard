## Risks / Open Questions

- Changing sandboxing from opt-in to a secure-by-default preset can break existing plugins and user workflows unless upgrade behavior and migration policy are explicitly designed.
- Moving plugins across a process or IPC boundary changes plugin SDK semantics, lifecycle ordering, error propagation, performance, and compatibility for external plugins.
- Credential filtering and manifest-declared permissions create a new security authority whose bypass, confused-deputy, and secret-lifetime behavior requires threat modeling and adversarial proof.
- Cross-platform filesystem, network, syscall, and resource controls have materially different guarantees; presenting them under one preset name could overstate protection unless each platform's degraded modes are explicit.
