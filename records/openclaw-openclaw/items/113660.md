## What This Changes

This PR adds a hosted model-catalog metadata refresh that stores a validated overlay in shared SQLite state, exposes `openclaw models refresh`, adds `models.catalogRefresh` settings, and publishes catalog bundles from provider plugin manifests.

## System Context

OpenClaw builds its model catalog from installed provider plugin manifests, then uses that catalog for model selection, provider discovery, pricing, and CLI listing. This PR introduces a hosted metadata source that the Gateway fetches and persists before merging it with trusted manifest transport details.
