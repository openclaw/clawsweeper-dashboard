Mount a per-cell Codex home or redirect `CODEX_HOME` into persisted tenant storage and prove upgrade retention.
  - confidence: 0.99

  - body: Automatic allocation excludes only ports recorded in `fleet_cells`. If another process or foreign container owns port 19100, create fails and releases its row, so every retry selects port 19100 again instead of advancing to a usable port. Check host availability for automatic allocation and cover the retry path while retaining explicit `--port` collision errors.
