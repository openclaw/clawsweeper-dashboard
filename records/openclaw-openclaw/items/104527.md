## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.98

Full review comments:

- **[P1] Persist the complete cell-owned user home:** `src/fleet/cell-profile.ts:282-284`
  - body: The replacement-safe mounts cover only `.openclaw` and `.config/openclaw`, while `HOME=/home/node` and upstream Codex defaults to `~/.codex`. Installing or authenticating Codex inside a cell therefore writes outside the persistent mounts and that state disappears on upgrade or recreation. Persist `/home/node`, or explicitly relocate every supported user-scoped tool state into a mounted cell directory.
  - confidence: 0.99
- **[P1] Preserve named image users during replacement:** `src/fleet/service-support.runtime.ts:175-195`
  - body: `docker inspect` commonly reports the official image user as `node`, but this parser accepts only numeric `uid:gid` values and otherwise substitutes the current host operator. A root-created cell upgraded later by a non-root docker-group user is recreated under that user's UID and can no longer read the mode-0700 directories owned by UID 1000. Preserve the inspected user or map the official `node` identity consistently.
  - confidence: 0.98
- **[P2] Skip host ports already occupied outside Fleet:** `src/fleet/cell-profile.ts:97-100`
  - body: Automatic allocation checks only the Fleet registry, so it can select port 19100 even when another host process already listens there. Container creation then fails instead of moving to the next usable port. Probe loopback availability while selecting automatic ports and retain the transactional reservation against concurrent Fleet creates.
  - confidence: 0.97
- **[P2] Add the documented Docker host-gateway alias:** `src/fleet/cell-profile.ts:277-280`
  - body: Linux Docker cells omit `host.docker.internal:host-gateway`, even though the existing Docker documentation requires that mapping for custom runs that access host-side Ollama or LM Studio. Add the Docker-only host mapping while leaving Podman's native alias behavior unchanged.
  - confidence: 0.98
