## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.98

Full review comments:

- **[P1] Persist the user-scoped Codex home across replacements:** `src/fleet/cell-profile.ts:281-284`
  - body: Fleet replaces the container during upgrade but only mounts `.openclaw` and `.config/openclaw`. Codex and OpenClaw both default user-scoped state to `$HOME/.codex`, so authentication, config, plugins, and native threads disappear after replacement unless the user manually overrides `CODEX_HOME`. Add a per-cell persistent Codex mount or set `CODEX_HOME` to a mounted path and cover upgrade retention.
  - confidence: 0.99
- **[P2] Skip host ports already occupied outside the registry:** `src/fleet/cell-profile.ts:96-99`
  - body: Automatic allocation considers only ports stored in `fleet_cells`. If another process already listens on 19100, container creation fails, cleanup removes the reservation, and the next create selects 19100 again. Probe the host bind before reserving or retry the next port after a bind failure.
  - confidence: 0.99
- **[P2] Add the documented Docker host-gateway alias:** `src/fleet/cell-profile.ts:277-280`
  - body: Linux Docker Fleet cells cannot use the documented `host.docker.internal` URLs for host-side Ollama or LM Studio because the run/create arguments never add `host.docker.internal:host-gateway`. This concern was also visible on the earlier reviewed head; add the Docker-only mapping and cover it in profile and live Linux proof.
  - late: true
  - confidence: 0.99
