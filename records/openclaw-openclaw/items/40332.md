## Summary

Keep open: current main and v2026.6.11 still expose ACPX permission defaults only through plugin-global config, while the requested scoped ACP permission contract remains absent and security-sensitive.

## What This Changes

Request per-binding and per-agent ACP permission defaults so ACPX sessions with different trust levels do not share one global permission mode.

## Best Possible Solution

Approve a generic scoped ACP permission-profile contract, then implement schema, binding materialization, runtime option propagation, docs, and security-focused regression coverage together.
