## Summary

Keep open: current main still lacks static per-binding or per-agent ACP permission defaults, and the remaining work is a security-sensitive public config contract rather than a narrow bug fix.

## What This Changes

Requested behavior is per-binding and per-agent ACP permissionMode overrides so ACP sessions can use narrower permissions than the global acpx plugin default.

## Best Possible Solution

Approve a generic scoped ACP permission-profile contract, then implement schema, binding materialization, runtime option propagation, docs, and security-focused regression coverage together.
