## Summary

Keep open: current main and latest release v2026.6.11 still only support ACPX permission defaults through global plugin config, while the requested per-binding and per-agent ACP permission defaults remain absent and security-sensitive.

## What This Changes

Request scoped ACP permission defaults at `bindings[].acp` and `agents.list[].runtime.acp`, falling back to global `plugins.entries.acpx.config.permissionMode`.

## Best Possible Solution

Approve a generic scoped ACP permission-profile contract, then implement schema, binding materialization, runtime option propagation, docs, and security-focused regression coverage together.
