## Summary

Keep open: current main still lacks per-binding or per-agent ACP permission defaults; the shipped path is still global ACPX plugin config plus live per-session runtime controls, which does not solve initial scoped defaults for different trust levels.

## What This Changes

The issue requests scoped ACP permissionMode overrides per binding and per agent instead of only the current global ACPX plugin setting.

## Best Possible Solution

Define a maintainer-approved generic scoped ACP permission profile contract, map it to ACPX/Codex-compatible backend permission keys, and document/test the precedence across binding, agent runtime, live session option, and global plugin defaults.
