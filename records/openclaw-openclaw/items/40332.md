## Summary

Keep open: current main and latest release still only provide ACPX permission defaults through plugin-global config, while the requested scoped ACP permission defaults remain absent and security-sensitive.

## What This Changes

Request scoped ACPX permission defaults per ACP binding and per agent runtime so mixed-trust ACP sessions do not require one global permissionMode.

## Best Possible Solution

Approve a generic scoped ACP permission-profile contract, then implement schema, binding materialization, runtime option propagation, docs, and security-focused regression coverage together.
