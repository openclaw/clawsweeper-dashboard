## Summary

Keep open: current main still lacks scoped ACP permission defaults for configured bindings or per-agent ACP runtime config, and the remaining work is a security-sensitive public config/runtime contract rather than maintainer-cleanup closure.

## What This Changes

The issue requests per-binding and per-agent ACP permission defaults so different ACP sessions can use different approval policies instead of sharing one global ACPX permission mode.

## Best Possible Solution

Define one documented scoped ACP permission contract with explicit precedence, preferably reusing the canonical ACP runtimeOptions/permissionProfile path and adding only the missing non-interactive policy surface if maintainers approve it.
