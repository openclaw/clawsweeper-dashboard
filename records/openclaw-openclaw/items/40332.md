## Summary

Keep open: current main and latest release still lack static per-binding or per-agent ACP permission defaults, while the existing session-level permissionProfile control does not solve the requested defaulting/precedence problem.

## What This Changes

The issue requests scoped ACPX permission policy so ACP permissions can be set per ACP binding and per agent runtime instead of only through global plugin config.

## Best Possible Solution

Approve a generic scoped ACP permission-profile contract, then implement schema, binding materialization, runtime option propagation, docs, and security-focused regression coverage together.
