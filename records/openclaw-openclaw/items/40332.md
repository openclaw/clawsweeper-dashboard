## Summary

Keep open: current main and v2026.6.11 still only support ACPX permissionMode through plugin-global config, while the requested per-binding/per-agent static permission default remains absent and security-sensitive.

## What This Changes

Request adding per-binding and per-agent ACP permission defaults so different ACP sessions can run with different file-write and shell authority.

## Best Possible Solution

Approve a generic scoped ACP permission-profile contract, then implement schema, binding materialization, runtimeOptions propagation, docs, and security-focused regression coverage together.
