## What This Changes

The branch modifies Discord's `createThreadDiscord` helper to read a forum/media channel's `default_auto_archive_duration` and send it as `auto_archive_duration` when no explicit archive duration is provided.

## Best Possible Solution

Apply the inheritance in the forum/media `sendMessageDiscord` create-thread body, or in a shared helper used by both send and thread-create, with regression coverage and redacted live metadata proof.
