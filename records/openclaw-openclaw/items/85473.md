## Summary

Keep open: current main and the latest release still expose memory-core-owned dreaming plus a memory-core sidecar path for selected memory plugins, not a public dreaming provider protocol. The linked ClawHub plugin helps LanceDB users today, but it does not settle the requested core/plugin-SDK API boundary.

## What This Changes

The issue requests a public dreaming protocol so non-memory-core memory plugins can participate in Light/Deep/REM consolidation.

## Best Possible Solution

Keep this as the core plugin-API design item until maintainers either define a narrow public dreaming provider contract or explicitly document memory-core sidecar plus ClawHub plugins as the supported path.
