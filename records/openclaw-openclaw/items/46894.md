## What This Changes

The issue requests that Control UI `/model status` and `/model list` be handled as informational model commands instead of model IDs passed to `sessions.patch`.

## Best Possible Solution

Land a refreshed narrow Control UI executor fix that handles `status` and `list` locally as model-info modes, with regression tests proving those subcommands never call `sessions.patch`.

## Solution Assessment
