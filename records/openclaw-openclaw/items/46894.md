## What This Changes

The issue reports that WebUI `/model status` and `/model list` are treated as model IDs instead of informational slash-command subcommands.

## Best Possible Solution

Land one refreshed Control UI fix in `ui/src/pages/chat/chat-command-executor.ts` that routes documented `/model list` and `/model status` before model mutation, preserves real model IDs, and adds focused tests plus UI proof.
