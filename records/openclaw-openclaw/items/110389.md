## Label Justifications

- `P1`: The defect can affect a live agent turn and mutate its active session transcript during a normal gateway operation.
- `merge-risk: 🚨 session-state`: The changed guard can permit transcript compaction while a worker-owned turn is still streaming or appending state.

## Summary

Keep this PR open for a targeted correction. The new active-work guard appears to omit worker-only cloud inference, so compaction can still mutate a transcript while that turn is streaming; the protected `maintainer` label also requires explicit maintainer handling.

## What This Changes

The PR adds manual-compaction preflight and active-work refusal so no-op or live session compactions do not abort an in-flight turn.

## Best Possible Solution

Use one pre-mutation active-work predicate that covers visible runs, worker inference ownership, and competing admissions, then add a worker-only inference regression test proving compaction refuses without interrupting the turn.

No; preflight-before-mutation is the right design, but the implementation must preserve the prior worker-inference protection rather than treating visible runs and lifecycle admissions as the complete active-work set.
