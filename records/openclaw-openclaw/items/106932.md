## What This Changes

The PR changes gateway session lifecycle emission so detached dashboard children and forks start without ending their still-active parent session.

## Best Possible Solution

Classify succession from explicit operation and parent semantics: forks and channel-to-dashboard detached children keep the parent active, while dashboard-to-dashboard Control UI `/new` and other true successors end the replaced parent; every successful child still receives `session_start`.
