## Summary

The branch fixes the reported detached-parent failure, but its dashboard-key predicate also suppresses the established parent `session_end` for genuine Control UI `/new` rollovers; the lifecycle distinction must be narrowed before merge, followed by real after-fix proof.

## What This Changes

## Best Possible Solution
