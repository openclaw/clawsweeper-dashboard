## Summary

Keep this PR open: the earlier lifecycle regression is fixed and the patch appears technically correct, but the external contribution still needs after-fix proof from a real Codex-backed parent/child workflow before merge.

## What This Changes

Stops detached dashboard children and forks from emitting terminal `session_end` for their still-active parent while preserving the created child's `session_start`, with gateway regression coverage.

## Best Possible Solution

Land the gateway-layer distinction after redacted live proof shows a real Codex-backed parent remains usable after creating a detached dashboard child, the child can run normally, and—if retained in scope—an accepted fork also leaves its parent usable.

Yes. The gateway owns whether a created session succeeds or merely branches from its parent, so narrowing parent lifecycle emission there is safer than weakening Codex's legitimate terminal handling of `session_end(reason: "new")`.
