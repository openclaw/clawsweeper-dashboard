## Summary

Keep open: the gateway is the correct ownership boundary, but the dashboard-key heuristic still suppresses the established parent `session_end` for dashboard-to-dashboard Control UI `/new`, and the contributor evidence remains test-based rather than a live Codex-backed parent/child run.

## What This Changes

The PR gates the gateway's parent `session_end` lifecycle hook for forks and dashboard-keyed children while preserving the new child's `session_start`, with focused lifecycle regression tests.

## Best Possible Solution

Keep the gateway-level fix, but classify succession from both parent and operation semantics so only true detached children and forks preserve the parent, then prove both the detached-parent continuation and genuine dashboard `/new` retirement in a redacted live Codex-backed setup.
