## What This Changes

The PR changes the environment-variable budget checker so a branch is compared with its common fork point with the selected base branch rather than that base branch’s moving tip.

## System Context

The environment-variable ratchet is a repository CI guard that reads the checked-out branch’s budget and compares it with a baseline selected from Git history. Its result determines whether CI allows a branch’s environment-variable count or reports disallowed growth.
