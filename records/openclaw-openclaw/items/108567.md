Keep this PR open for one small documentation fix. The shell-specific instructions correctly address the native PowerShell failure and have convincing before/after proof, but the copy-paste examples should also show how to remove both session-scoped API keys after use.

## Best Possible Solution

Keep the separate POSIX and PowerShell examples, then add an explicit `Remove-Item Env:ANTHROPIC_API_KEY, Env:OPENAI_API_KEY` cleanup step immediately after the PowerShell commands.
