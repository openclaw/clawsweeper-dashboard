## Summary

This remains a useful, mergeable bug fix: current main still reports encoded Base64 character length as image bytes in three agent/history projections, while the PR consistently switches those paths to the existing decoded-byte estimator and preserves metadata when image data is already omitted. No actionable correctness or security defect was found; the branch is merely behind main and needs an exact-head refresh before normal maintainer merge review.

## What This Changes

The PR changes live tool-result, gateway chat-history, and sessions_history image sanitization to report estimated decoded Base64 byte sizes and adds regression coverage for raw, empty, and already-omitted image data.

## Best Possible Solution

Land one shared decoded-byte rule across all image-omission projections, retaining supplied numeric metadata only when raw image data is already absent, with the focused regression cases in this PR preserved after refreshing onto current main.
