## Summary

This PR remains necessary: current main still derives omitted-image metadata from encoded character length, while the proposed shared-estimator approach corrects all three user-observable projection paths without changing their schemas or redaction behavior. The patch is focused, well-proven, and has no actionable correctness or security finding.

## What This Changes

The PR changes live tool-result, gateway chat-history, and sessions_history image sanitization to report estimated decoded Base64 byte sizes and adds regression coverage for raw, empty, and already-omitted image data.

## Best Possible Solution

Use the media-core estimator as the single byte-count rule at every omitted-image projection boundary, preserving existing numeric metadata only when the raw Base64 data is already absent.
