## Summary

The previous node-executable blocker is resolved by limiting reuse to gateway requests, and the reported live proof convincingly demonstrates the cost reduction. The PR should remain open because it reuses the existing single-use `allow-once` verdict across multiple executions; that security-boundary contract needs explicit owner approval before merge.

## What This Changes

The PR adds a bounded per-reviewer memo for completed low-risk gateway exec `allow-once` decisions and regression tests for reuse and invalidation behavior.

## Best Possible Solution

Define a distinct, explicitly approved run-scoped reusable verdict with exact gateway plan binding, documented lifetime, and focused security tests; keep `allow-once` genuinely single-use.
