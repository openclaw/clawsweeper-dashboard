## Summary

Keep open: current main still has the claude-cli cleanup-to-cancel-to-process-tree kill path, while the existing mitigation only denies native background Bash and Monitor and does not settle Workflow-backed survival or durable completion delivery.

## What This Changes

The issue reports that claude-cli in-turn background work such as Workflow, native background Bash, and Workflow-backed skills is killed at turn boundaries and loses completion delivery.

## Best Possible Solution

Define an owner-approved claude-cli longwork lifecycle contract that either boundedly hosts or detaches post-turn work with durable origin delivery, or explicitly denies unsupported native background work with a visible failure path.
