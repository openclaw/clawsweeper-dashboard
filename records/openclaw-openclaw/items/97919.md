## Summary

Keep open: current main and v2026.6.11 mitigate the exact native Claude `Bash(run_in_background:true)` and `Monitor` affordances by denying them, but the broader Workflow-backed/background-work survival plus durable completion-delivery contract remains unresolved.

## What This Changes

The issue requests a durable lifecycle contract so claude-cli background work can either survive turn boundaries and deliver completion or be explicitly refused when unsupported.

## Best Possible Solution

Define one owner-backed background-work contract: unsupported claude-cli background affordances should be refused, while approved longwork must run in an OpenClaw-owned durable host with origin snapshot, queued completion, and delivery tests.
