## Summary

Keep open, but do not merge in the current form: current `main` already gives omitted `runExec` calls a 10-second deadline, so the claimed indefinite hang is not reproducible; the patch instead introduces an unproven five-second policy and a lint-blocking unused import. ## What This Changes

The PR changes the `which tailscale` and `locate Tailscale.app` discovery probes from the shared execution timeout to explicit five-second deadlines and adds mocked option-forwarding coverage.

## Best Possible Solution

Keep one canonical execution-timeout policy unless a real host demonstrates that Tailscale discovery needs a shorter deadline; if it does, introduce a named, justified discovery timeout and test both actual timeout termination and fail-soft continuation without unused test churn.
