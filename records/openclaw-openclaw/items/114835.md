## Summary

Keep this PR open. It has a concrete prompt-parity defect: live prompt preparation supplies capability tool names to watched-session preparation, while the compaction path does not, so capability-only session tools can produce a different watched-session section during compaction. It also needs inspectable real after-fix behavior proof before merge; the protected `maintainer` label leaves the product choice with a human owner.

## What This Changes

This PR adds a watched-session section and recall guidance to full agent system prompts, while updating session-tool descriptions and denial text to describe the existing same-agent watched-read behavior.

## System Context

Ambient watches record same-agent group and topic sessions that a main agent may read under the existing session-visibility policy. The agent prompt is assembled for live turns and compaction turns; this change turns those stored watch facts into model-visible guidance and aligns tool copy with the policy.

## Best Possible Solution

Pass the same normalized capability-tool set into watched-session preparation for both live and compaction prompts, add a parity regression case, then let the session-watch owner confirm that automatic watched-session names in every full prompt are the intended product boundary.
