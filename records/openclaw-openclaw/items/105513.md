## Label Justifications

## Summary

Keep open: current main still starts Dreaming narrative runs with a deterministic `dreaming-narrative-*` session key, the narrative subagent contract has no explicit prompt-mode override, and the runner derives prompt mode from the session key. An open linked fix PR, https://github.com/openclaw/openclaw/pull/106404, explicitly targets this remaining behavior, so this issue should stay open until that work is reviewed and merged or replaced.

## What This Changes

Use a minimal, Dreaming-specific system prompt for scheduled memory narrative subagent runs instead of inheriting the generic chat prompt.

## System Context

The bundled `memory-core` plugin schedules Dreaming passes that turn selected memory fragments into diary entries in `DREAMS.md`. Each narrative pass launches an internal subagent; its prompt mode determines whether the model receives only diary guidance or the full interactive-chat instruction set.
