## Summary

Keep open: this maintainer-labeled PR is still relevant to the channel status contract work, but it should not pass yet because arbitrary `probe` and `audit` payloads still bypass the new redaction boundary.

## What This Changes

The PR separates channel status output from plugin/runtime snapshot input by adding `ChannelAccountStatus` and `ChannelAccountSnapshotInput`, projecting status data through the gateway protocol schema, updating bundled channel callers, SDK exports, docs, and validation fixtures.

## Best Possible Solution

Close the public status contract by either sanitizing or schema-typing `probe` and `audit` before merge, while keeping the deprecated `ChannelAccountSnapshot` alias only as a documented migration bridge.
