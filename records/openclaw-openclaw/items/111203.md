## What This Changes

This PR adds and documents `agents.defaults.compaction.enabled`, allowing operators to set `false` to disable proactive embedded auto-compaction while retaining overflow recovery, OpenClaw preemptive compaction, and manual `/compact`.

## System Context

OpenClaw loads `openclaw.json` into the agent-defaults configuration contract, then prepares settings for embedded and CLI agent turns. This setting flows into the agent runtime’s compaction guard, affecting threshold-driven embedded compaction while separate recovery and manual paths continue afterward.
