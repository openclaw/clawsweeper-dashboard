## What This Changes

This PR adds the optional `agents.defaults.compaction.enabled` boolean to configuration validation, help, docs, tests, and CLI/embedded guard paths so operators can disable proactive embedded auto-compaction.

## System Context

Agent compaction settings flow from `openclaw.json` through the strict Zod configuration schema into CLI-backed and embedded agent sessions. The resulting settings control automatic context compaction behavior while manual `/compact` and overflow-recovery paths remain separate.

## Best Possible Solution

Approve the setting only as a clearly documented, scoped opt-out for proactive embedded auto-compaction, retaining overflow recovery and manual compaction; otherwise defer the new configuration surface until maintainers choose a broader compaction-control contract.
