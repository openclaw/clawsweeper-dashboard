## What This Changes

This PR speeds gateway chat startup and session switching by replacing whole-store session reads with exact SQLite reads, caching config-derived startup projections, and applying the chat startup model-catalog budget to history.

## System Context

Gateway chat handlers build history and startup payloads from SQLite session rows, runtime configuration, and model-catalog data. The changed lookup and projection layers feed both interactive chat clients and session-message subscriptions.
