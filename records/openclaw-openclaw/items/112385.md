## Summary

The branch has a coherent, proof-backed private composition implementation, but it intentionally establishes recovery identities, owner inventory, and obligation rules before OpenClaw maintainers have accepted whether those durable responsibilities belong in core or the host lifecycle.

## What This Changes

Adds a private recovery-point composer that verifies selected global and per-agent SQLite snapshot receipts, rejects incomplete inventories, and derives deterministic recovery-point and acceptance-set identities for later recovery flows.

## System Context

The SQLite snapshot provider produces verifiable state artifacts for the shared OpenClaw database and each selected agent database. This PR sits above those owner receipts and would supply one aggregate identity to a later host-controlled capture, restore, and Gateway-admission flow.
