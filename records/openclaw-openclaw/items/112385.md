## What This Changes

This PR adds a private recovery-point composer that re-verifies selected global and per-agent SQLite snapshots and emits deterministic recovery-point and acceptance-set identities for later host-driven capture and restore.

## System Context

OpenClaw’s snapshot provider produces owner-level SQLite artifacts for global and agent state. The new composition layer receives those artifacts, a canonical agent inventory, and declared recovery obligations, then produces an aggregate receipt that later capture and restore flows can consume.
