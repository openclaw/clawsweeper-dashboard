## What This Changes

The branch adds a private recovery-point composer that verifies selected global and per-agent SQLite snapshot manifests, binds a closed runtime inventory and reconstruction obligations, and emits deterministic recovery-point and acceptance-set identities for later host-managed recovery flows.

## System Context

OpenClaw’s existing snapshot provider produces and verifies snapshots for individual state owners such as global and per-agent SQLite databases. This proposed composition layer consumes those owner manifests plus a runtime-state inventory and emits one aggregate identity that later capture, restore, and host lifecycle code can use without defining storage or wake policy itself.
