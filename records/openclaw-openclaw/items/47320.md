## Summary

Keep open: current main still exposes `subagents` as a direct-controller list with descendant summaries, but no depth or recursive option that returns nested worker rows.

## What This Changes

The issue requests recursive or depth-limited subagent listing so a top-level agent can inspect nested worker agents spawned by depth-1 orchestrators.

## Best Possible Solution

Define a maintainer-approved read-only descendant listing that keeps direct-child listing as the default, adds explicit depth/recursive output with parent/depth metadata, and does not expand mutation permissions.
