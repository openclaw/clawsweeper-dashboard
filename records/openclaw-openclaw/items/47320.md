## Summary

Keep open: current main and the latest release still expose `subagents` as a direct-controller list with descendant counts/child session keys, but no `depth` or `recursive` mode that returns descendant worker rows.

## What This Changes

Feature request for recursive or depth-limited `subagents list` output so a parent agent can inspect descendant subagents beyond direct children.

## Best Possible Solution

Define an additive read-only descendant listing that keeps direct-child listing as the default, adds explicit depth or recursive output with parent/depth metadata, and preserves existing kill, steer, send, focus, and stop permissions.
