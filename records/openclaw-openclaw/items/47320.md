## Summary

Keep open: current main and v2026.6.11 still expose `subagents` as a direct-controller list with descendant summaries, but there is no public `depth` or `recursive` list mode that returns nested worker rows.

## What This Changes

Request an additive `subagents list` depth/recursive option so a depth-0 orchestrator can inspect nested subagent labels, status, runtime, model, and parent hierarchy.

## Best Possible Solution

Define an additive read-only descendant listing that preserves direct-child listing as the default, returns parent/depth metadata for requested descendants, and keeps mutation permissions scoped to direct controller ownership.
