## Summary

Keep open: current main and the latest release still provide only direct-controller `subagents` listing with descendant summaries, not the requested depth or recursive rows for depth-2 workers.

## What This Changes

Add a depth or recursive mode to `subagents list` and the model-facing `subagents` tool so an orchestrator can inspect nested descendant agents.

## Best Possible Solution

Define a read-only descendant listing that keeps direct-child listing as the default, adds explicit depth or recursive output with parent/depth metadata, and does not expand kill, steer, send, focus, or stop permissions.
