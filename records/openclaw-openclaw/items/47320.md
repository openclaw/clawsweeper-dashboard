## Summary

Keep open: current main still exposes `subagents list` as a direct-controller listing with descendant summaries, but no depth/recursive API returns nested worker rows to the top-level controller.

## What This Changes

Add depth/recursive support to `subagents list` so a parent agent can inspect nested subagent rows with status, runtime, model, and parent metadata.

## Best Possible Solution

Define a maintainer-approved read-only descendant listing that keeps direct-child listing as the default, adds explicit depth/recursive output with parent/depth metadata, reuses existing lineage traversal, and does not expand mutation permissions.
