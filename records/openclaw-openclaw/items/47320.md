## Summary

Keep open: current main still exposes `subagents list` as a direct-controller list with descendant summaries, but no `depth` or `recursive` option that returns nested worker rows.

## What This Changes

Request adding recursive or depth-limited visibility to `subagents list` so a depth-0 orchestrator can inspect depth-2 worker labels, status, runtime, model, task, and parent hierarchy.

## Best Possible Solution

Define an additive read-only descendant listing that keeps direct-child output as the default, includes parent/depth/session metadata for recursive rows, and preserves existing mutation permissions.
