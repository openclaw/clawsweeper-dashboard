## Summary

Keep open: current main and v2026.6.11 still expose `subagents` as a direct-controller list with descendant summaries, but no public depth or recursive listing that returns nested worker rows.

## What This Changes

The issue requests a `--depth`/`--recursive` option for `subagents list` and the model-facing tool call so parent agents can inspect descendant subagents with hierarchy metadata.

## Best Possible Solution

Define an additive read-only descendant listing that preserves direct-child listing as the default, returns parent/depth metadata for requested descendants, and keeps mutation permissions scoped to direct controller ownership.
