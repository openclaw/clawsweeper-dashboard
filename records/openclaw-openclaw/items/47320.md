## Summary

Keep open: current main and the latest release still expose `subagents list` as a direct-controller list with descendant summaries, but no depth or recursive mode that returns nested worker rows.

## What This Changes

The issue requests a depth or recursive option for `subagents list` so a top-level orchestrator can inspect depth-2 worker subagents with hierarchy metadata.

## Best Possible Solution

Approve a narrowly scoped read-only descendant listing that keeps direct-child listing as the default, adds explicit depth/recursive output with parent/depth metadata, and does not expand kill, steer, send, focus, or stop permissions.
