## Summary

Keep open: current main and v2026.6.11 still expose `subagents` as a direct-controller listing with descendant counts, not the requested depth/recursive listing of nested worker rows.

## What This Changes

Request to add `--depth` or `--recursive` support to `/subagents list` and the `subagents` tool so a parent session can inspect nested descendant agents.

## Best Possible Solution

Add a maintainer-approved read-only depth/recursive descendant list that keeps direct listing as the default, includes parent/depth/session metadata, reuses existing traversal helpers, and does not broaden mutation permissions.
