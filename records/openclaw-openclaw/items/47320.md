## Summary

Keep open: current main and the latest release still expose `subagents` as a direct-controller list with descendant counts, but no depth or recursive mode that returns nested worker rows.

## What This Changes

The issue requests a recursive or depth-limited `subagents list` option so a parent agent can inspect depth-2 worker labels, status, runtime, model, and hierarchy metadata.

## Best Possible Solution

Define a maintainer-approved read-only descendant listing that keeps direct-child listing as the default, adds explicit depth or recursive output with parent/depth metadata, and does not expand kill, steer, send, focus, or stop permissions.
