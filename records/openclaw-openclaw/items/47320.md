## Summary

Keep open: current main and v2026.6.11 still expose `subagents` as a direct-controller listing with descendant summaries, but no `depth` or `recursive` mode that returns nested worker rows.

## What This Changes

Request adding `--depth` / `--recursive` options to `subagents list` and a model-facing depth argument so parent agents can inspect nested descendant subagents.

## Best Possible Solution

Define a maintainer-approved read-only descendant listing that keeps direct-child listing as the default, adds explicit depth or recursive output with parent/depth metadata, and does not expand kill, steer, send, focus, or stop permissions.
