## What This Changes

The PR normalizes Mattermost websocket error values with the shared plugin error formatter and adds a regression test that preserves object details in diagnostics and account status.

## System Context

Mattermost’s websocket monitor receives connection events, captures proxy diagnostics, writes runtime errors, and updates channel status for reconnect handling. The patch formats an unknown websocket error once at this plugin boundary before those downstream diagnostic outputs consume it.
