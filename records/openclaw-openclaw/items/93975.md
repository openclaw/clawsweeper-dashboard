## Summary

Keep this PR open, but the current patch is not merge-ready: it follows the right explicit-marker direction for missing plugin load paths, yet it also creates overbroad stale detection that can reintroduce perpetual rediscovery for stable diagnostics.

## What This Changes

The PR adds an `orphan-source-path` plugin diagnostic code, persists diagnostic codes in the SQLite plugin index schema, and expands persisted-registry stale detection and tests for explicit and legacy orphan diagnostics.

## Best Possible Solution

Keep the explicit missing-load-path marker and schema preservation, but avoid marking stable unsupported files as orphaned and narrow or move the legacy no-code cleanup so current main's non-plugin diagnostic guardrail remains protected.
