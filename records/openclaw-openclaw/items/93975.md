## What This Changes

The PR adds an explicit code for diagnostics from missing configured plugin paths and invalidates version-1 persisted plugin indexes so Gateway re-derives a current plugin registry.

## System Context

Plugin discovery creates diagnostics while resolving configured plugin paths, then persists an installed-plugin index for later Gateway starts. The registry snapshot loader either reuses that stored index or rebuilds it before Gateway validates and loads plugins.
