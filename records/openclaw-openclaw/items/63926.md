## Summary

Keep open: current main has browser CLI/tool/gateway primitives and generic plugin-tab plumbing, but it still lacks the visible Control UI browser-login handoff surface the issue asks for. The issue discussion explicitly treats this as the canonical same-browser-state login handoff tracker, and the remaining work needs maintainer UX, security, and API direction.

## What This Changes

The issue requests a visible Control UI browser panel for managed-browser login handoff, tab/status management, and same-session agent resume.

## Best Possible Solution

Design an operator-scoped browser handoff surface with typed profile/tab context, redaction, read-only status by default, explicit write controls, and same-state resume semantics coordinated with browser preview and plugin UI work.
