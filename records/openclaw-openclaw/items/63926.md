## Summary

Keep open: current main has browser CLI/RPC primitives and generic plugin tab infrastructure, but no browser-specific Control UI login-handoff panel; the issue remains a product and security-boundary decision, not conservative cleanup.

## What This Changes

Request a visible Control UI browser panel for managed-browser status, tab management, user login handoff, and same-browser-state agent resume.

## Best Possible Solution

Design and ship an operator-scoped browser handoff surface with read-only status/tab context by default, explicit write controls, redaction, structured manual-action state, and same-state resume semantics coordinated with the broader preview and plugin UI work.
