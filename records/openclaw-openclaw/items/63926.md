## Summary

Keep open: current main still has browser tool/CLI/RPC primitives, but no Control UI route, sidebar entry, or browser-login handoff panel that lets a user access the exact managed browser session and then resume agent work. The discussion also has an explicit maintainer-side comment treating this as the canonical browser-login handoff tracker, with the FSB link as useful design context rather than a replacement.

## What This Changes

The issue requests a visible Control UI browser handoff panel that shows managed browser status/tabs and lets users complete login before the agent resumes against the same browser state.

## Best Possible Solution

Design and ship an operator-scoped, read-only-first browser handoff surface with typed profile/tab context, explicit write controls, redaction, and same-state resume semantics coordinated with the broader browser preview and plugin UI work.
