## Summary

Keep open: current main still has browser control primitives and generic Control UI plugin-tab plumbing, but no visible browser-login handoff panel, and the discussion treats this as the canonical same-browser-state login handoff tracker.

## What This Changes

Request to add a visible Control UI browser panel for managed-browser status, tab management, manual login handoff, and same-state agent resume.

## Best Possible Solution

Design and ship an operator-scoped, read-only-first browser handoff surface with typed profile/tab context, explicit write controls, redaction, and same-state resume semantics coordinated with the broader browser preview and plugin UI entry-point work.
