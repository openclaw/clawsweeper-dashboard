## Summary

Keep open: current main and v2026.6.11 still provide browser tool, CLI, and RPC primitives but no Control UI browser-login handoff panel, and the discussion identifies this as canonical product/security work.

## What This Changes

Request to add a visible Control UI browser handoff panel with browser status, tab management, managed-session access, manual login completion, and agent resume support.

## Best Possible Solution

Design and ship an operator-scoped browser handoff surface with typed profile/tab context, read-only status by default, explicit write controls, redaction, and same-state resume semantics coordinated with the generic UI entry-point work.
