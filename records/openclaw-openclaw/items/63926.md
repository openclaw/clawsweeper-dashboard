- `P2`: This is a meaningful Control UI/browser workflow feature with limited blast radius, but current CLI and agent browser paths mean it is not an outage or urgent regression.
- `impact:security`: The requested panel would expose or control authenticated browser pages, URLs, logs, downloads, and session-derived state.

## Summary

Keep open: current main has browser CLI/RPC/tab primitives and generic plugin-tab plumbing, but still lacks a visible Control UI browser-login handoff panel; the issue remains the canonical same-state login handoff tracker and needs maintainer security/product design.

## What This Changes

Request a visible Control UI browser section for managed-browser login handoff, tab management, and same-state agent resume.

## Best Possible Solution

Design an operator-scoped, read-only-first browser handoff surface with typed node/profile/tab context, explicit write controls, redaction, audit/retention policy, and same-state resume semantics.
