## Summary

Keep open: current main still has browser CLI/RPC primitives and Control UI routing, but no browser-login handoff surface that lets an operator complete auth and resume the same browser state. The issue remains the canonical product/security decision point for that workflow rather than something fixed by the adjacent browser preview or plugin UI work.

## What This Changes

Add a Control UI browser-login handoff flow so users can complete site authentication in the agent's browser session and let the agent continue with the same tab/profile state.

## Best Possible Solution

Define a secured operator-scoped browser handoff surface with typed node/profile/tab context, read-only status/tab visibility by default, explicit write controls, redaction, and same-state resume semantics coordinated with browser preview and plugin UI work.
