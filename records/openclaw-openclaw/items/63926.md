## Summary

Keep open: current main has browser CLI/RPC/control primitives and generic plugin-tab rendering, but no browser-specific Control UI panel for login handoff, tab management, or same-browser-state resume. The live discussion also explicitly treats this issue as the canonical browser-login handoff tracker.

## What This Changes

The issue requests a visible Control UI browser handoff and management panel for managed-browser login flows, tab visibility/actions, and same-browser-state agent resume.

## Best Possible Solution

Design and ship an operator-scoped, read-only-first browser handoff surface with typed profile/tab context, explicit write controls, redaction, and same-state resume semantics.
