## Summary

Keep open: current main has browser CLI/RPC primitives and generic plugin tab infrastructure, but still lacks a visible Control UI browser-login handoff and browser-management panel for the same managed session.

## What This Changes

Request a visible Control UI browser panel for managed-browser status, tabs, login handoff, tab actions, and same-session resume.

## Best Possible Solution

Design and ship a secured, admin-scoped, read-only-first browser handoff panel that reports structured manual-action state, shows node/profile/tab context, gates write actions, and resumes the agent against the same managed browser state after user login.
