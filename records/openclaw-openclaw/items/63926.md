## Summary

Keep open: current main has generic plugin tab plumbing and browser CLI/RPC primitives, but the browser plugin still exposes no browser-specific Control UI login handoff panel, tab list, profile/tab context view, or same-state resume surface. The issue discussion also identifies this as the canonical browser-login handoff tracker rather than a duplicate of the broader preview or plugin-UI work.

## What This Changes

The issue requests a visible Control UI browser section for managed-browser login handoff, tab/profile management, and resuming agent work against the same browser state.

## Best Possible Solution

Design and ship an operator-scoped, read-only-first browser handoff surface with explicit profile/tab context, visible manual-action status, gated write controls, redaction rules, and same-state resume semantics coordinated with the broader preview and plugin UI work.
