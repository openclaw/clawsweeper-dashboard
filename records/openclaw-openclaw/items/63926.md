## Summary

Keep open: current main still has browser CLI/RPC/control primitives and generic plugin tab descriptors, but no visible Control UI browser-login handoff panel; the discussion also identifies this as the canonical same-browser-state login handoff tracker.

## What This Changes

Request a visible Control UI browser section for managed-browser status, tab management, manual login handoff, and agent resume against the same browser state.

## Best Possible Solution

Design a secured, admin-scoped, read-only-first browser handoff surface that shows the exact managed profile/tab and lets users complete login or permission prompts before explicitly resuming the agent against that same browser state.
