## Summary

Keep open: current main has browser control primitives and generic plugin-tab infrastructure, but no visible Control UI browser-login handoff panel or same-state resume flow. The issue discussion also treats this as the canonical tracker, with FSB linked as useful design context rather than a replacement.

## What This Changes

The issue requests a visible Control UI browser handoff panel with status, tabs, managed-browser access, manual login completion, and resume support.

## Best Possible Solution

Design an operator-scoped browser handoff surface with typed node/profile/tab context, read-only status by default, explicit write controls, redaction, and same-state resume semantics coordinated with browser preview and plugin-tab infrastructure.
