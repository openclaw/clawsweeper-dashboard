## What This Changes

The PR adds a search-pattern safety guard in the exec tool-display formatter and tests so recursive or malformed `rg`/`grep` summaries fall back to neutral `search text` labels.

## System Context

Agent exec commands are parsed into concise labels for tool timelines and transcripts. The exec formatter recognizes common commands and pipelines, then supplies a presentation-only detail string to the tool-display layer.
