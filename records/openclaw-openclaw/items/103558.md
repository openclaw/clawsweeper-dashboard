## Summary

Keep this feature request open: current main supplies aliases, configured-model allowlisting, per-model parameters, session-scoped switching, and Telegram buttons, but it does not provide the requested ordered first-screen profile picker or a defined contract for atomically switching additional runtime settings.

## What This Changes

Add named configurable LLM profiles and expose them as a curated, fast, session-scoped Telegram picker with direct profile commands.

## Best Possible Solution

Extend existing configured model entries and aliases with the smallest generic ordering or presentation metadata needed for a portable curated `/model` picker, preserving current session-only overrides; design credential or multi-setting profile switching separately only if maintainers explicitly approve its persistence, authorization, reset, and status semantics.
