## Summary

This PR addresses a real outbound ownership invariant, but its recovery-path change can permanently fail queued deliveries created before the new rule without an upgrade decision or migration. It also needs refreshed real-behavior proof from the current head before merge.

## What This Changes

The branch adds shared outbound validation that rejects mismatched explicit agent IDs and agent-scoped session or mirror keys across Gateway, helper, delivery, recovery, tests, and protocol documentation.

## Best Possible Solution

Keep one canonical outbound-owner invariant for new requests, but require maintainers to choose and document an upgrade path for already-persisted queue entries before enabling permanent recovery rejection; then add exact-head redacted runtime proof for rejection and permitted cases.
