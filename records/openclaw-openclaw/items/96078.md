## What This Changes

The branch adds a shared validation rule that rejects outbound requests and queued recoveries when an explicit agent owner disagrees with a canonical agent-scoped session or mirror key, while allowing a separate policy key.

## System Context

Gateway RPCs and agent message tools prepare an outbound session context that controls media policy, plugin delivery, transcript mirroring, and durable queue recovery. This PR inserts ownership validation before those paths dispatch work or replay stored deliveries.
