## What This Changes

This PR returns immediately when plugin policy rejects `openclaw plugins enable <id>`, preventing rejected requests from changing plugin slots, persisted configuration, or the plugin registry.

## System Context

The plugin CLI reads the current OpenClaw configuration, checks whether a requested plugin may be enabled, then updates exclusive plugin slots and persists the resulting configuration. This change makes the policy decision a hard gate so rejected commands only report the denial and do not reach mutation or registry-refresh steps.

  C -->|Allowed| F[Apply exclusive slot selection]
