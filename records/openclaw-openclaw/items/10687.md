## Summary

Keep open: current main and latest stable release include partial OpenRouter runtime dynamic-model support, but the requested text catalog/list/picker discovery, wildcard allowlist, cache/offline, and cross-provider policy decisions remain unresolved under a maintainer-labeled design thread.

## What This Changes

Request fully dynamic provider model discovery so OpenRouter and other fast-moving catalogs list and select current models without static catalog or manual allowlist refresh.

## Best Possible Solution

Settle a provider-owned live text catalog contract through the plugin SDK, then wire OpenRouter and generic /v1/models discovery into list, picker, and validation with explicit cache, offline, wildcard allowlist, and safety semantics.
