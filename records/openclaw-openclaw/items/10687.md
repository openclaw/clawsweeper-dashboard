## Summary

Keep open: current main and the latest release only partially mitigate explicit OpenRouter runtime model IDs, while provider-backed list/picker discovery, wildcard/allowlist behavior, cache/offline policy, and credential safety still need maintainer decisions. The issue also carries the protected `maintainer` label, so it should not be auto-closed by this cleanup pass.

## What This Changes

Request provider-backed dynamic model discovery so OpenRouter and other fast-moving providers can list and select current models without waiting for static catalog refreshes while preserving allowlist and cost controls.

## Best Possible Solution

Keep this as the canonical design thread, then implement provider-owned OpenRouter live catalog discovery through the existing guarded SDK after maintainers settle picker defaults, wildcard allowlists, caching/offline behavior, credential safety, and large-catalog UX.
