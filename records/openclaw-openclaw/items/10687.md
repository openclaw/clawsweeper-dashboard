## Summary

Keep open for explicit product direction. The original OpenRouter unknown-model runtime failure appears addressed on current main according to the prior source review, but the remaining request—live provider catalog discovery with safe picker visibility, caching, credential scoping, and allowlist semantics—is still a meaningful unresolved capability; the existing `maintainer` label also requires human handling.

## What This Changes

Add provider-backed runtime model discovery, initially for OpenRouter, so current models can be listed and selected without waiting for bundled catalog updates while preserving configured selection controls.

## Best Possible Solution

Define one provider-owned dynamic catalog contract that refreshes configured-provider models with credential-scoped caching, keeps execution authorization authoritative, and specifies how OpenRouter models enter picker and CLI surfaces without adding a broad unsafe allowlist mode.
