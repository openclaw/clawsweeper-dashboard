## What This Changes

Request provider-backed dynamic model discovery so OpenRouter and similar fast-changing catalogs can be listed and selected without waiting for a static catalog release.

## System Context

Provider/model references are resolved into catalog entries that drive agent execution, model validation, and model-selection interfaces. Dynamic discovery would introduce provider data into that catalog while existing configured-model policy continues to control what users can select.
