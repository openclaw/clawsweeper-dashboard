## Summary

Keep open: current main now supports provider-owned live catalogs and dynamic OpenRouter runtime resolution, but the protected issue’s central picker-discovery behavior still needs a maintainer decision on filtering, allowlist authority, metadata trust, caching, and offline behavior.

## What This Changes

Add provider-backed runtime model discovery so current provider models can be listed and selected without waiting for static catalog updates.

## Best Possible Solution

Use the shipped unified catalog and dynamic-model hooks, keep fetching and normalization provider-owned, and establish one core policy for filtered picker visibility, existing allowlist authority, metadata fallback, credential-scoped caching, refresh, and offline behavior.
