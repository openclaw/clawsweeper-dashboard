## Summary

Keep open: current main and v2026.6.11 cover parts of this through OpenRouter runtime fallback, provider wildcard visibility, and shared live-catalog infrastructure, but OpenRouter text model list/picker discovery and the broader cache, offline, allowlist, and safety policy remain unresolved under a protected maintainer-labeled design issue.

## What This Changes

The issue requests fully dynamic runtime model discovery for fast-moving provider catalogs, especially OpenRouter, without losing model allowlist and safety controls.

## Best Possible Solution

Settle a provider-owned live text catalog contract through the plugin SDK, then wire OpenRouter and generic provider discovery into list, picker, and validation with explicit cache, offline, wildcard allowlist, and safety semantics.
