## Summary

Keep open: current main addresses part of the original problem through provider-owned dynamic resolution and `provider/*` allowlists, but full OpenRouter and generic configured-provider catalog refresh still lacks an agreed cache, metadata-trust, visibility, and security contract. The protected `maintainer` label also requires explicit human direction.

## What This Changes

Requests runtime discovery of current provider model catalogs while preserving usable selection UX and model safety and cost controls.

## Best Possible Solution

Use the existing provider-plugin catalog and dynamic-model seams, preserve `agents.defaults.models` authority through `provider/*` scopes, and standardize one bounded credential-scoped refresh contract with conservative metadata fallbacks and no steady-state JSON cache.
