## Summary

Keep open: current main has runtime OpenRouter mitigation and shared live-catalog infrastructure, but OpenRouter text catalog browsing, picker/list freshness, allowlist semantics, cache policy, and credential-safety behavior are still incomplete maintainer design work.

## What This Changes

The issue requests fully dynamic model discovery for OpenRouter and similar fast-moving providers across runtime validation, model listing, picker UX, and allowlist freshness.

## Best Possible Solution
