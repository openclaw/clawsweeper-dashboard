Keep open. ## What This Changes

Prevent one `image_generate` completion artifact from being delivered twice to Telegram through normal reply attachment and completion delivery.

## Best Possible Solution

Assign exactly one visible delivery owner to each generated-media completion artifact, carry that ownership through the completion event and final-reply pipeline, and add channel-generic regression coverage proving one captioned Telegram delivery.
