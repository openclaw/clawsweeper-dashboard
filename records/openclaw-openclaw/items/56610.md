## What This Changes

Request Discord outbound messages attempted during WebSocket reconnect windows be queued and retried after reconnect, matching existing delivery-queue behavior in other channels.

## Best Possible Solution

Add a Discord plugin reconnect drain through the existing delivery queue helper, retry disconnected-gateway send failures using resolved account ids, and prove recovery with focused lifecycle tests plus redacted real Discord reconnect evidence.
