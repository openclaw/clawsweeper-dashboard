## Summary

Keep the PR open: the patch is a focused mitigation for idle Codex `PreToolUse` relay subprocess fan-out, but it changes the default native loop-detection relay behavior and only partially addresses the linked P1 issue, so it needs maintainer sign-off rather than conservative cleanup closure.

## What This Changes

The PR removes no-op Codex `PreToolUse` native hook relay command installation when the relay has no local work, and makes default native loop-detection relay installation require explicit `tools.loopDetection.enabled: true`.

## Best Possible Solution

Land this only as a scoped idle/default relay mitigation after maintainer approval of the default behavior change, and keep or split #91009 for explicit loop-detection and broader relay fan-out work if that remains unsolved.

## Reproduction Assessment

## Solution Assessment

Partly: this is a good bounded fix for idle no-work PreToolUse relays, but it is not clearly the complete best fix for #91009 because explicit loop-detection relay fan-out and the default-behavior policy choice remain open.
