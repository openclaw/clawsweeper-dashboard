## Summary

## What This Changes

The PR changes Codex native hook relay gating so inactive PreToolUse events clear the generated hook array instead of installing a no-op command hook, and updates focused relay tests for default and explicit loop-detection behavior.

## Best Possible Solution

Land this only if maintainers accept the broader default behavior change, and keep or split canonical tracking for explicit loopDetection and relay concurrency unless that scope is intentionally accepted as fixed.
