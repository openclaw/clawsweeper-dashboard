## What This Changes

Add a supported, crash-safe operation for renaming an existing agent ID without losing or misassigning agent-scoped state.

## System Context

Agent configuration selects an agent ID and its workspace, while the per-agent SQLite database verifies that it belongs to that same ID before runtime uses it. A safe rename would have to coordinate configuration, owned filesystem paths, database identity metadata, and any participating plugin state before the renamed agent can resume.

## Architecture Diagram

## Best Possible Solution

Define and implement one journaled core rename operation that preserves explicit workspace paths by default, moves only clearly OpenClaw-owned default paths, requires typed plugin participation where needed, and leaves runtime accepting only the canonical current ID.
