## Summary

Keep open. Current main and v2026.6.11 still emit heartbeat prompt time through the shared natural-language `Current time:` plus `Reference UTC:` helper, and the wake trigger timestamp is still internal coalescing state rather than a separate model-visible field.

## What This Changes

Request to render heartbeat `Current time` in ISO 8601 and optionally add a separate `Heartbeat triggered at` timestamp.

## Best Possible Solution

Define one shared model-visible timestamp contract for current time, UTC reference, and heartbeat trigger time, then update the helper, heartbeat/wake plumbing, affected callers, docs, and focused tests together.
