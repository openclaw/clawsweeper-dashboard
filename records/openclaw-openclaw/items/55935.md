## Summary

Keep open. Current `main` and latest release still use the shared natural-language `Current time:` plus `Reference UTC:` helper for heartbeat prompts, and the wake trigger timestamp is stored internally but not exposed to `runHeartbeatOnce`.

## What This Changes

The issue requests ISO 8601 heartbeat prompt time formatting plus an optional separate model-visible heartbeat trigger timestamp.

## Best Possible Solution

Define the shared model-visible timestamp contract first, then update the helper, heartbeat wake plumbing, docs, and focused tests so ISO current time and any trigger timestamp appear only in approved prompt locations.
