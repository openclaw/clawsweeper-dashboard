## Summary

Keep open. Current `main` and `v2026.6.11` still use the shared natural-language `Current time:` plus `Reference UTC:` prompt block, and the wake queue’s `requestedAt` timestamp is not exposed to the heartbeat runner as a separate model-visible trigger timestamp.

## What This Changes

Request to make heartbeat prompt time ISO 8601 and optionally add a separate heartbeat trigger timestamp field.

## Best Possible Solution

Define the automation timestamp contract first, then update the shared helper, heartbeat wake plumbing, docs, and focused tests so ISO current time and any trigger timestamp appear only in approved prompt locations.

- **Split heartbeat from cron:** Add heartbeat-specific trigger metadata while leaving cron/system-event current-time formatting unchanged.
