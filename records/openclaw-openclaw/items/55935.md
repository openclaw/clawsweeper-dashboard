## Summary

Keep open. Current main and v2026.6.11 still use the shared natural-language `Current time:` plus `Reference UTC:` helper for heartbeat prompts, and the wake trigger timestamp is only internal coalescing state rather than a separate model-visible field.

## What This Changes

The issue requests ISO 8601 heartbeat current-time formatting and an optional separate heartbeat-trigger timestamp.

## Best Possible Solution

Define one shared model-visible timestamp contract for current time, UTC reference, and heartbeat trigger time, then update the helper, heartbeat/wake plumbing, affected callers, docs, and focused tests together.
