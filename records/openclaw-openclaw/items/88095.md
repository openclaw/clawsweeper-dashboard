## Summary

Keep open: current main and v2026.6.11 still route Voice Wake, push-to-talk, and Talk through transcript, wake-word, silence, and provider audio paths with no enrolled-speaker match gate. ## What This Changes

Request adds voice enrollment and speaker-identification gating so Voice Wake, push-to-talk, and Talk ignore non-enrolled voices and avoid background-speaker contamination.

## Best Possible Solution

Define one speaker-gating contract for native and realtime voice input that covers enrollment UX, local SQLite state, matching thresholds, fallback semantics, provider egress, and plugin/API ownership before implementation.
