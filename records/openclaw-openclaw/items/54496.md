## Summary

Keep open. Current main still has thinking-effort controls, reasoning visibility controls, replay sanitizers, and partial memory/display cleanup, but no schema-backed silent-reasoning mode that runs reasoning while excluding thinking blocks from durable session transcripts and transcript-facing APIs.

## What This Changes

The issue requests a silent reasoning mode that allows model reasoning while preventing thinking blocks from being persisted in session transcripts.

## Best Possible Solution

Define a core transcript-persistence policy separate from model thinking effort and reasoning visibility, preserving provider-required replay state while excluding hidden reasoning from user/history/memory transcript surfaces by a documented contract.

## Reproduction Assessment

Yes, source-level: current main has reasoning visibility and thinking effort settings, but the schema and transcript paths do not provide a durable silent-reasoning persistence mode.

## Solution Assessment

Unclear pending maintainer API choice. Decoupling reasoning production from persistence is the right boundary, but stripping in one writer or one memory consumer would be too narrow without provider replay and transcript-consumer semantics.
