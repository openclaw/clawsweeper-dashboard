## Summary

Keep open: current main has thinking effort controls, reasoning visibility controls, provider replay sanitizers, and plugin hook workarounds, but it still lacks a first-class contract for running reasoning while excluding thinking blocks from durable session transcripts and transcript-facing consumers.

## What This Changes

The issue requests decoupling reasoning/thinking production from transcript persistence so thinking can run without polluting session history, memory, compaction, or recall.

## Best Possible Solution

Define a core transcript-persistence policy separate from thinking effort and reasoning visibility, with explicit storage, replay, session API, compaction, memory, UI/config, plugin hook, and docs semantics.

## Solution Assessment

No for a one-site strip; decoupling production from persistence is the right direction, but the best fix must be a maintainer-approved cross-surface policy that accounts for provider replay state and transcript consumers.
