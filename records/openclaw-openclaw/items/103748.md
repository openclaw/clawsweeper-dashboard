## What This Changes

This PR redesigns Control UI tool-call rendering, fixes interleaved call/result pairing, and adds cached model-generated purpose titles through a new gateway RPC.

## Best Possible Solution

Keep the demonstrated deterministic rendering and pairing improvements, derive implicit Luna eligibility from the loaded session's effective model, impose one aggregate computation and rendered-row budget across multi-edit fallback diffs, and document the approved explicit-utility-model egress policy.
