## Summary

Keep open: the permission hardening is useful, but this PR is not merge-ready because the current head can still chmod caller-owned session-store/imported transcript parents and GitHub reports the branch conflicts with current main.

## What This Changes

## Best Possible Solution

Guard private-directory creation and chmod repair to recognized OpenClaw-managed directories only, preserve caller-owned custom paths, add focused upgrade/custom-path tests, and then let maintainers accept the managed-dir upgrade tightening explicitly.
