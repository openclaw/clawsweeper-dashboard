## Summary

Keep open: this is a useful security hardening PR for managed OpenClaw state, but the current head is still not merge-ready because two runtime paths can chmod caller-owned custom session or transcript directories despite the PR contract that custom paths are unchanged.

## What This Changes

The PR adds explicit `0o700` creation and best-effort chmod repair to selected managed session, settings, tool, Gateway transcript, and plugin-skill directories while retaining plain mkdir in some config session-store paths.

## Best Possible Solution

Land the private-directory hardening only after chmod repair is guarded to recognized OpenClaw-managed directories and focused tests prove custom store, imported session, and Gateway transcript parents keep their existing modes.

## Solution Assessment

No. Managed-only hardening is the right direction, but this patch is not the best mergeable shape until caller-owned session and transcript parents are preserved in every runtime path.

  - body: `SessionManager.open()` now chmods `dir` even when `sessionDir` is omitted and `dir` is only the parent of the supplied session file.   - confidence: 0.91
