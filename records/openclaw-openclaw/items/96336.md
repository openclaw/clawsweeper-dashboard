## Summary

Keep open: current main still has the managed-directory permission gap, and this PR is a useful candidate, but the branch is not merge-ready because it can still chmod caller-owned session and Gateway transcript parents.

## What This Changes

The PR adds explicit 0700 creation and best-effort chmod repair for several OpenClaw-managed state/session directories while leaving some caller-owned session store/accessor paths on plain mkdir.

## Best Possible Solution

Land managed private-directory hardening only after chmod repair is guarded to recognized OpenClaw-owned directories, caller-owned paths are preserved, and focused tests cover both managed upgrade repair and custom-path preservation.

## Solution Assessment

No. Managed-only hardening is the right direction, but this patch is not the best mergeable shape until it preserves caller-owned session and transcript parents in all runtime paths.
