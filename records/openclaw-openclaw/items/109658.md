## Summary

The requested retention strategy is useful, but current main already exposes token-aware, plugin-owned context compaction hooks that can implement staged thresholds without adding another core session configuration surface. Existing ClawHub context-engine plugins also address the same long-session information-loss problem, so this belongs in the plugin ecosystem rather than OpenClaw core.

## What This Changes

Add configurable context-compaction stages at approximately 60%, 80%, and 95% utilization, with progressively more aggressive summarization while retaining decisions and unfinished work.

## Best Possible Solution

Publish a context-engine plugin through ClawHub that registers an entrypoint with ownsCompaction, computes stage utilization from currentTokenCount/tokenBudget, validates plugin-specific threshold and retention settings, documents permissions and secrets if any, provides install/update and example configuration instructions, and includes a long-session smoke proof; ClawSweeper should not create, track, or publish that package on the contributor’s behalf.
