## Summary

Keep open. Current main and the latest release still use an Activity preview redaction regex that misses `app.api.key=...`, and the linked fix PR at https://github.com/openclaw/openclaw/pull/99460 is open and unmerged, so this issue should stay paired until that PR lands.

## What This Changes

Control UI Activity previews should redact dotted API-key assignments such as `app.api.key=...` the same way they redact `api_key=...` and `api-key=...`.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99460 if it passes, then close this issue through the merged fix provenance.
