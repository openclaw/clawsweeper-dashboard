## Summary

The targeted tests are useful but do not yet show the updated echo in a real channel flow.

## What This Changes

Updates opt-in audio transcript echoes to use a microphone-prefixed quoted format and, where a source message ID exists, send the echo as a reply to the inbound voice message.

## System Context

Media understanding transcribes inbound audio before agent processing; when transcript echo is enabled, it sends a best-effort confirmation message back through the originating message channel. This PR changes how that confirmation is formatted and associated with the original inbound message.
