## Summary

This PR should stay open: the new helper replaces one broad heuristic with another and would newly treat every Slack action ID ending in `_all` as a disposable bulk row, although Slack action IDs are app-defined and current OpenClaw has no producer establishing that suffix as reserved. The added whole-handler tests improve regression coverage, but they construct synthetic IDs and mocked client calls rather than proving the claimed contract or real Slack behavior.

## What This Changes

The PR changes Slack bulk-action row detection from substring matching to an `_all` suffix helper and adds focused grammar and mocked handler regression tests.

## Best Possible Solution

Give bulk rows an explicit producer-owned marker—preferably a reserved block ID or shared typed/encoded action contract—and test actual generated blocks plus unrelated custom IDs, while preserving any shipped encoded IDs that remain supported.
