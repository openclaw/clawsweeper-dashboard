## Summary

## What This Changes

Bounds Discord probe response-body reads, preserves successful bot identity when optional application metadata stalls, and carries the remaining status timeout through cold lazy loading.

## Best Possible Solution

Discord status probes should use the shared bounded reader for every JSON body, preserve an already-resolved bot identity when optional metadata fails, and keep the complete cold-load-plus-probe operation within the caller’s budget.

## Solution Assessment
