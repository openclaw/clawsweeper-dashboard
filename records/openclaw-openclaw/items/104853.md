## Summary

The requested positive case is real and the live Tlon proof is convincing, but the proposed regex also newly classifies image-looking text inside a fragment as media even when the URL path is not an image. That message-delivery regression should be fixed before merge; the unrelated session-state CI failures do not change this verdict.

## What This Changes

The PR broadens Tlon’s image URL regex to accept fragment suffixes, adds a positive `buildMediaStory` regression test, and includes a generated docs-map refresh.

## Best Possible Solution

Parse the URL and test the image extension on `URL.pathname`, preserving query and fragment text in the original emitted `src`, with positive and negative fragment regression cases.
