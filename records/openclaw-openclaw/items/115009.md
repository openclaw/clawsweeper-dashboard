## What This Changes

Mirrors optimistic chat-session setting changes into the sessions capability snapshot so refresh publishes cannot briefly restore an older reasoning-slider or fast-mode value.

## System Context

The web chat composer writes session-level model settings through the sessions capability, whose published list is then consumed by chat hosts. This change keeps the optimistic row in that shared snapshot so loading-state publishes do not overwrite the host’s temporary UI state before the gateway refresh returns.
