## Summary

Keep this PR open for explicit maintainer security-boundary approval. The implementation consistently changes the operator terminal from opt-in to opt-out, but an upgrade with no terminal setting gains an admin-accessible host PTY and a less strict Control UI CSP; that is a product and security decision rather than a routine default cleanup.

## What This Changes

The PR makes OpenClaw’s existing admin-scoped operator terminal enabled unless `gateway.terminal.enabled` is explicitly set to `false`, then updates gateway HTTP/UI behavior, tests, schema help, and documentation to match.

## System Context

The Gateway serves the Control UI and authorizes operator methods, including a browser/mobile terminal backed by a host PTY in an agent workspace. The terminal policy feeds both session launch authorization and the Control UI HTML/CSP configuration that enables the embedded terminal client.
