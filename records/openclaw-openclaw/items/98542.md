## Summary

Keep open: current main has the prerequisite scoped capability profile and trusted direct/shared/unknown scope classification from https://github.com/openclaw/openclaw/pull/98536 and https://github.com/openclaw/openclaw/pull/99816, but it does not yet implement the requested personal/team/external identity-mode decision or no-personal-fallback enforcement. The protected `maintainer` label and security/session-state impact make this explicit maintainer product/security review work.

## What This Changes

The issue requests a canonical conversation identity/audience mode layer for personal, organization/team, and external/shared contexts so unresolved audiences cannot inherit personal agent identity or workspace context.

## Best Possible Solution

Keep this open for maintainer product/security review, then implement one small core decision on top of the resolved capability profile that denies unresolved shared audiences before personal workspace or instructions are loaded, with upgrade-aware tests for direct-owner, explicit service binding, guest/unknown deny, and existing fallback behavior.
