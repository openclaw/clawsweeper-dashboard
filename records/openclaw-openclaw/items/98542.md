## Summary

Keep open: this maintainer-labeled feature is still needed on current main. ## Best Possible Solution

Add one reviewed core identity-mode decision on top of the scoped profile, with tests for owner direct personal mode, explicit service-agent team mode, external/shared deny, and no new config unless maintainers choose it.
