## Summary

Keep this PR open for normal merge review. The narrow `isIP` guard appears to correct the DNS-prefix bypass while retaining the intended literal loopback cases; the remaining merge consideration is validating the intentional upgrade behavior for previously implicit `127.*` DNS names.

## What This Changes

The branch changes LiteLLM loopback auto-allow detection so DNS hostnames beginning with `127.` no longer bypass the existing private-network opt-in.

## Best Possible Solution

Preserve literal loopback auto-allowing, require explicit opt-in for every non-literal hostname, and add focused coverage that exercises both the blocked DNS-prefix case and the explicit opt-in path before landing.
