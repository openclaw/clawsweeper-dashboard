Full review comments:

- **[P2] Preserve flat token expiry coercion:** `src/commands/doctor-auth-flat-profiles.ts:223`
  - body: This new parser path changes legacy-flat token imports that have a token or tokenRef plus a malformed `expires` value. Before, the flat migration only copied `expires` when it was a number; with this call, the canonical parser converts a present non-number/null expiry to `0`, and runtime eligibility rejects token credentials with `expires: 0` as `invalid_expires`. That makes a previously usable no-expiry legacy token unusable after doctor migration. This was visible at the earlier reviewed head; I missed it in the first cycle.
