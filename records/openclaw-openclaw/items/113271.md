## What This Changes

This PR adds an accessible drag handle to the primary Control UI chat composer so a user can set, persist, nudge, and reset its textarea height while retaining the existing autosize default.

## System Context

The Control UI chat composer receives a user's draft through a textarea and adjusts its visible height before the message enters the chat-send flow. This change adds an input-side resize control and a browser-local height preference that feeds the composer sizing behavior.

## Best Possible Solution
