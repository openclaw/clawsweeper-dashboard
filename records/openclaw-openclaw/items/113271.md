## What This Changes

This PR adds an accessible drag handle to the primary Control UI chat composer, allowing users to set, reset, keyboard-adjust, and persist its textarea height in browser-local storage.

## System Context

The Control UI chat composer turns a draft into a textarea-based message input and resizes that textarea as content changes. This change inserts an accessible resize control and a browser-local height preference into that sizing path, while leaving secondary and suggestion composers on their existing autosize behavior.
