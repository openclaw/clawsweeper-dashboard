## What This Changes

This PR adds an accessible drag handle to the Control UI chat composer, allowing users to resize it with pointer or keyboard controls and persist one global height preference in browser storage.

## System Context

The Control UI chat composer receives a user’s draft and autosizes its textarea before sending it through the chat flow. This PR inserts a resize control beside that textarea, changes the height calculation, and stores the user-selected height locally for later chat sessions.

## Architecture Diagram

flowchart LR

  Handle[Pointer or keyboard resize handle] --> Preference[Global browser height preference]
  Preference --> Autosize
  Autosize --> Textarea[Visible composer textarea]
  Textarea --> Chat[Chat send flow]

## Best Possible Solution
