## What This Changes

The issue reports that Matrix homeserver URLs deployed under reverse-proxy path prefixes fail because slash-prefixed API endpoints resolve from the origin instead of the configured base path.

## Best Possible Solution

Review and land or replace https://github.com/openclaw/openclaw/pull/93516 so Matrix transport resolves helper endpoints relative to the full homeserver base path, then close this issue after the fix merges.
