## Summary

Keep this PR open for maintainer review: it implements a valuable dashboard feature, but the current patch can silently pin reconstructed apps without their declared tool set and can churn leases once a board mounts more MCP apps than the shared 32-view capacity.

## What This Changes

Adds pinned MCP App dashboard widgets with transcript-backed lease re-minting, revision-bound tool grants, gateway protocol support, and Control UI rendering and stale-state recovery.

## Best Possible Solution

Preserve or explicitly reject stale-source pins before tool declarations are persisted, make mounted-board lease ownership compatible with the global capacity, and demonstrate fresh plus upgraded board behavior in a real Control UI session.
