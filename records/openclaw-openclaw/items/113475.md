## What This Changes

Fix or precisely diagnose isolated `agentTurn` cron executions in which a configured, healthy MCP server is not exposed as callable tools to the embedded agent.

## System Context

OpenClaw stores third-party MCP server definitions centrally, while `mcp probe` independently opens a live connection to inspect them. An isolated cron `agentTurn` then launches an embedded agent runtime, which must project eligible MCP tools and apply its tool-policy filters before the model can call them.
