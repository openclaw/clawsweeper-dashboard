## Summary

Keep open: current main and the latest release still lack `metadata.openclaw.setup.script`, install/update-time setup execution, or a core `skills.setup` method. The published ClawHub plugin is useful prior art, but its README explicitly says it is a manual `operator.admin` RPC and not the automatic install/update lifecycle hook requested here.

## What This Changes

Request to add a skill-authored `setup.script` metadata hook that runs after skill install/update with a defined environment contract.

## Best Possible Solution

Define one security-reviewed setup boundary: either a default-off core install/update hook with explicit operator approval and shared path/env/timeouts/logging tests, or a documented external plugin/RPC path after the installed-skill SDK helpers are stable.
