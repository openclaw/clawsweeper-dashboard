## Summary

Keep open: current main still lacks a skill-authored setup metadata contract, automatic post-install/update setup execution, and a core `skills.setup` lifecycle method; the published ClawHub plugin is useful prior art but does not satisfy the requested install/update lifecycle behavior.

## What This Changes

The issue requests a `metadata.openclaw.setup.script` skill hook that runs after skill install and update with a defined environment contract.

## Best Possible Solution

Choose one security-reviewed setup boundary: either an explicit opt-in core install/update hook with path/env/timeout/logging semantics, or a documented external plugin path backed by stable SDK helpers.
