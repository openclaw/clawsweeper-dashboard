## Summary

Keep open: current main still lacks a skill-authored `setup.script` metadata contract, automatic post-install/update setup execution, or a core `skills.setup` method. The published ClawHub plugin is useful prior art, but it is an explicit admin RPC and its README says it does not run automatically after install/update, so the core lifecycle/security decision remains unresolved.

## What This Changes

The issue requests a skill-authored setup hook that runs a bundle-relative script after skill install/update with a defined environment contract.

## Best Possible Solution

Choose one maintainer-approved setup execution boundary: either a core install/update hook with explicit consent, containment, env, timeout, logging, and docs, or a documented external plugin path backed by stable SDK helpers and clear operator expectations.
