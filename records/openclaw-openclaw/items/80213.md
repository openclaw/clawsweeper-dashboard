## Summary

Keep open: current main and v2026.6.11 still lack `metadata.openclaw.setup.script`, post-install/update setup execution, or a core `skills.setup` lifecycle method. The published ClawHub plugin is useful prior art, but the linked PR and README context describe a manual admin RPC, not the automatic install/update lifecycle hook requested here.

## What This Changes

Request a SKILL.md `metadata.openclaw.setup.script` hook that runs a skill-supplied setup script after skill install/update with a defined environment contract.

## Best Possible Solution

Choose one security-reviewed setup execution boundary: a core install/update lifecycle hook with explicit path/env/consent/timeout/logging/rollback semantics, or a documented external ClawHub/admin-plugin path that maintainers explicitly accept as the supported behavior.
