## Summary

Keep open: current main and the latest release still lack a skill-authored `setup.script` metadata contract, a post-install/update setup execution phase, or a core `skills.setup` RPC. The published ClawHub plugin is useful prior art, but it is a manual admin RPC and explicitly says it does not run setup automatically after install/update, so the remaining work is a maintainer product/security decision.

## What This Changes

The issue requests a skill-authored setup script hook in SKILL.md metadata that runs after skill install/update with a defined environment contract.

## Best Possible Solution

Define one security-reviewed setup execution boundary: either a core install/update lifecycle hook with explicit consent, path/env/timeout/logging semantics, or a documented external plugin/admin-RPC path backed by stable SDK helpers.
