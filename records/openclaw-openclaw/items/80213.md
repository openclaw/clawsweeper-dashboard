## Summary

Current main still lacks automatic skill-authored setup execution during install or update, and the related ClawHub plugin/closed PR only provides a manual/admin setup path, so the core product/security decision remains open.

## What This Changes

The issue requests a standard skill metadata hook that can run a skill-supplied setup script automatically after install or update, with author-controlled environment and working-directory semantics.

## Best Possible Solution

Make one security-reviewed product decision for the setup boundary: either add a narrow core lifecycle hook with explicit consent/env/sandbox semantics or document that setup remains a manual ClawHub/plugin-admin workflow.
