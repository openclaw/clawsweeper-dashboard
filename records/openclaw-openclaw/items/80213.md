## Summary

Keep open: current main still lacks a skill-authored setup contract and no skill install/update path runs a declared setup script after installation. The published `@alexminza/skills-setup` ClawHub plugin is useful prior art and a manual admin RPC workaround, but it explicitly does not run automatically on install/update, so the remaining decision is whether OpenClaw core should own an opt-in lifecycle execution boundary or keep this in ClawHub plus SDK surfaces.

## What This Changes

Request a skill-authored setup hook that runs a declared setup script after skill install/update with a defined environment contract.

## Best Possible Solution

Maintain a clear reviewed boundary: either approve a default-safe, explicit-opt-in core install/update setup hook with shared path/env security helpers and docs, or declare the ClawHub admin RPC plus stable installed-skill SDK helpers as the supported external path.
