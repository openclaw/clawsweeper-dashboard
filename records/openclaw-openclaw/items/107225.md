## Summary

Current main still exposes LINE group mention gating to an intentionally broad inline-token detector, and the focused linked fix remains open; keep the issue as canonical tracking until that PR is merged or closed.

## What This Changes

Prevent ordinary allowlisted LINE group messages containing inline slash or bang tokens from bypassing `requireMention`.

## Best Possible Solution

Land a focused fix that uses precise configured-command detection for LINE group mention bypass while retaining the broad authorization-computation detector for DMs, with regression coverage for ordinary inline tokens and genuine commands.

## Solution Assessment

Yes. Splitting precise group activation detection from broad DM authorization computation is narrower and more maintainable than weakening the shared mention gate, and it follows the existing Google Chat sibling pattern.
