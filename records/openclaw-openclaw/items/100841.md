## Summary

Keep open: the patch fixes the runtime-snapshot OAuth cleanup branch, but the locked persisted `lastGood` cleanup still resolves provider aliases without workspace/config context and can leave stale credentials selected.

## What This Changes

## Best Possible Solution

Both persisted owner-store and inherited runtime-snapshot cleanup paths should resolve provider auth aliases with the same cfg/workspaceDir context, with regression coverage for same-agent and inherited profile cases.
