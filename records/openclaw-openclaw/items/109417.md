Keep this PR open for normal landing review: current main still leaves both synchronous root-help renderers on Node’s default `SIGTERM`, while this narrow patch makes the existing 120-second deadlines enforceable. The implementation, dependency contract, regression coverage, and real-process proof support the fix, with no blocking findings; the behind-main branch should be refreshed before merge. ## What This Changes

The PR configures both synchronous root-help subprocesses to use `SIGKILL` on timeout and adds regression coverage verifying the hard-kill option.

## Best Possible Solution

Land the two-call `SIGKILL` timeout hardening after refreshing the branch and focused proof, while preserving the existing graceful TERM-to-KILL process-tree lifecycle for asynchronous command-help rendering.
