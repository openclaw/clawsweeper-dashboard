## Summary

This PR remains necessary because current main can produce an unpaired UTF-16 surrogate in OpenRouter Fusion prompt text. The exact-head patch is narrow, uses the established public plugin SDK helper, preserves configuration and provider payload behavior, adds focused regression coverage, and has convincing real Gateway-path proof; no actionable defect or merge-specific compatibility risk was found.

## What This Changes

This PR replaces raw UTF-16 slicing in OpenRouter Fusion prompt model-ID display sanitization with the shared safe truncation helper and adds a boundary regression test for both analysis and final model lines.

## Best Possible Solution

Land the provider-owned sanitizer change using the existing plugin SDK UTF-16 helper, retaining the current filtering and display cap together with the focused regression and Gateway-path proof.
