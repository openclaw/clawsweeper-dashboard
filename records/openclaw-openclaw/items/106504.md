## Summary

Keep open as a model-routing observability feature. Current OpenClaw provides agent-scoped model inspection, but there is no established aggregate CLI and UI contract that clearly separates global defaults, per-agent configured overrides, and the active runtime fallback; maintainers should choose that presentation before implementation.

## What This Changes

Surface per-agent model overrides alongside global defaults in model diagnostics and the settings or agent-management UI.

## Best Possible Solution

Add an explicit all-agent diagnostics mode that reuses canonical effective-model resolution, and show inherited-versus-overridden configured models on the Agents UI separately from active session or fallback state.
