## Summary

Keep open as a model-routing observability feature rather than a broken-behavior bug. Current OpenClaw supports inspecting a specific agent with `openclaw models status --agent <id>` and has an agent-oriented Control UI surface, but the evidence does not show an aggregate defaults-versus-overrides view in the normal models output or settings page. citeturn619344search0turn600835search0turn453977search0

## What This Changes

Surface configured per-agent model overrides alongside global defaults in the models CLI and Control UI.

## Best Possible Solution

Add an additive all-agent status view that clearly separates global defaults, configured per-agent overrides, and active session selection, then mirror that distinction with an override badge or comparison in the Agents UI without adding another config option.
