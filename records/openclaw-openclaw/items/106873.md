## Summary

The protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

## Best Possible Solution

Keep exact workflow-URL matching, bounded GraphQL retries, and the pre-mutation main-target guard, but derive the polling deadline from the selected release profile or set it above the workflow’s maximum end-to-end duration with explicit completion margin.
