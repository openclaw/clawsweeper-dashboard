## Summary

The runtime change is the strongest of the three candidate fixes because it preserves concurrent single-capture behavior while allowing retries after failure, but this branch is not merge-ready: both new `readFile` wrappers violate the overloaded Node type contract, and the external-PR real behavior gate is still test-only.

The PR replaces the pre-update snapshot path set with a per-path promise map that shares in-flight work, retains successful operations, clears failed operations for retry, and adds read-failure, write-failure, and concurrency tests.

## Best Possible Solution
