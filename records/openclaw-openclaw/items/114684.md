## What This Changes

Prevent an obsolete pending Workboard card move from a disconnected Gateway client from overwriting the replacement dashboard connection’s authoritative card state.

## System Context

The Control UI session dashboard renders Workboard cards using a Gateway client. Card mutations travel to that client and then update the visible dashboard, so reconnect handling must reject callbacks from an earlier connection after a replacement client becomes authoritative.
