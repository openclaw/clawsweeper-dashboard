Keep open. Current main and the latest release still derive non-shared sandbox scope and container identity without workspace or instance identity, while the active candidate fix remains unmerged.

## What This Changes

The issue reports Docker sandbox container collisions across HOME-isolated co-hosted OpenClaw instances because non-shared sandbox identity is derived from agent/session scope without instance identity.
