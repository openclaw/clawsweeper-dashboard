## Summary

Keep open. Current main and the latest release still derive non-shared sandbox runtime names from the sandbox scope key without workspace or instance identity, while https://github.com/openclaw/openclaw/pull/96866 is the active but unmerged and currently conflicting candidate fix.

## What This Changes

The issue reports Docker sandbox container-name reuse across separate OpenClaw instances that share the default agent key, causing cross-instance workspace contamination.

## Best Possible Solution

Land or replace the active workspace-scoped sandbox identity fix so non-shared Docker, browser, SSH, registry, and recreate paths include an instance/workspace discriminator, then close this issue with the merged commit and release provenance.
