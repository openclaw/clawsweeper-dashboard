## Summary

Keep open. Current main and v2026.6.11 still derive non-shared Docker/browser sandbox names from scope keys without workspace or instance identity, and https://github.com/openclaw/openclaw/pull/96866 is the active unmerged candidate fix rather than a shipped resolution.

## What This Changes

The issue requests instance-unique Docker sandbox container names so multiple OpenClaw instances on one host do not share a sandbox container.

## Best Possible Solution

Review, refresh, and land https://github.com/openclaw/openclaw/pull/96866, or an equivalent security-reviewed fix that scopes non-shared sandbox runtime identity by resolved workspace across Docker, browser, SSH, recreate, docs, and regression tests.
