## Summary

Keep this PR open: current main still sends a Synology reply as one webhook message, so the linked long-message delivery bug remains. The proposed use of the shared chunker is a narrow, plausible repair, but it needs redacted proof from an actual Synology Chat delivery before merge because the contributor explicitly could not run that integration.

## What This Changes

This PR splits oversized Synology Chat agent replies into bounded sequential webhook messages, with a one-second pause between chunks, and adds unit coverage for the chunking helper.

## System Context

The Synology Chat plugin accepts an inbound Chat webhook, asks the routed OpenClaw agent for a reply, then posts that visible reply back to the configured Synology webhook. This PR changes that final outbound delivery step so a long reply can be represented by several Chat messages instead of one oversized request.
