## Summary

This PR identifies real stale surfaces after the heartbeat migration, but the proposed gateway-only removal is incomplete: current main still treats `HEARTBEAT.md` as an active workspace bootstrap file. Merging would make the Agents → Files API reject edits to a file that the workspace runtime can still load, so this needs one canonical runtime cleanup before merge.

## What This Changes

The branch removes retired `HEARTBEAT.md` references from the gateway’s editable file list, sandbox workspace seeds, Docker release smoke checks, a QA scenario, and operator documentation.

## System Context

The agent workspace bootstrap layer defines files that runtime sessions may load; the gateway exposes a subset of those files for editing in the Control UI. Heartbeat instructions are intended to come from a monitor job’s cron scratch, while Doctor remains responsible for migrating old workspace files.
