## What This Changes

This PR changes Claude CLI recovery so lifecycle-only no-output stalls fork the native Claude session, persist its returned successor ID, and use transcript reseeding only if that cache-preserving retry fails safely.

## System Context

Claude CLI-backed agent turns retain a provider-native session binding in OpenClaw’s session store. The live CLI stream reports activity to the runner; on an eligible stall, the runner can retry from a forked native session and update the persisted binding used by the next turn.
