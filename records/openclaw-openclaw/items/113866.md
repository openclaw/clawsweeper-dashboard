## What This Changes

This PR changes stalled Claude CLI resume recovery to fork the native Claude session and persist its successor before falling back to rebuilding context from the OpenClaw transcript.

## System Context

OpenClaw’s CLI agent runner resumes provider-native sessions and watches their JSONL output for stalled turns. This change feeds a narrowly classified Claude timeout into session-store binding updates, then either continues on the forked native session or rebuilds from the portable OpenClaw transcript.
