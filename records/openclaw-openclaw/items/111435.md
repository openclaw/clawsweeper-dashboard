## Summary

## What This Changes

The branch preserves a catalog estimate beside provider-billed cost totals, parses OpenRouter-compatible cache-write tokens in the agent completions transport, includes them in overflow accounting, and serializes the new optional cost field through worker transcript paths.

## Best Possible Solution

Land the narrow cache-write parsing and overflow-accounting correction only with an explicit decision that retaining and serializing catalog estimates is a supported public `Usage.cost` API; otherwise split that API addition into a separately sponsored design and keep the bug fix internal to the existing cost semantics.
