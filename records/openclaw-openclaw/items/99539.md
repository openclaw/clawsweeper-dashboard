## What This Changes

## Reproduction Assessment

Yes, from source inspection: current main slices command previews by UTF-16 code units in the Discord approval payload path. The same cut shape can leave a lone surrogate or partial grapheme before the ellipsis.

## Solution Assessment

Yes. The PR fixes the private Discord presentation formatter used by pending/resolved/expired approval payloads; the existing shared UTF-16 helper would avoid lone surrogates but would still split multi-code-point graphemes like flags.
