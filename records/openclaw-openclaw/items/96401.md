## Summary

## What This Changes

The PR adds Discord-only implicit default-account handling to the Discord SecretRef collection contract and a regression test for file-backed default plus named account token materialization.

## Best Possible Solution

Land the Discord-owned SecretRef collector fix after maintainer acceptance of the implicit-default compatibility change and normal merge gates.

## Reproduction Assessment

Yes. Source inspection shows current main can skip materializing channels.discord.token when explicit named accounts all provide tokens, while Discord still lists that top-level token as an implicit default account and fails closed if it remains an unmaterialized SecretRef.

## Solution Assessment

Yes. The PR fixes the Discord-owned SecretRef collection boundary to match Discord account listing, avoiding both a shared helper API change and a runtime token fallback that would create another credential source of truth.
