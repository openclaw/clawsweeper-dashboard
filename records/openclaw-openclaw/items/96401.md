## What This Changes

The PR adds Discord-only implicit default-account SecretRef collection and a regression test for file-backed default plus named Discord account tokens.

## Best Possible Solution

Land the Discord-owned SecretRef collector fix after maintainer acceptance of the compatibility-sensitive active-surface change and normal merge gates; keep the linked issue open until the PR merges.

## Solution Assessment

Yes. The PR fixes the Discord-owned SecretRef collection boundary, matches the existing Discord account-listing contract, and avoids adding a shared helper API change or runtime token fallback.
