- **[P2] Return batch ids through the receipt:** `extensions/discord/src/outbound-payload.ts:158-160`
  - body: This returns `allMessageIds` as a top-level `platformMessageIds` field, but the outbound delivery contract preserves platform ids through `receipt`.   - confidence: 0.91

  - body: The new overflow loop passes `replyTo` only for the first batch. Existing Discord text and media-caption chunk sends preserve explicit reply references on follow-up posts, so a 12-file replied send loses its `message_reference` on the second Discord POST.
  - confidence: 0.88
- **[P2] Carry silent delivery into one-file overflow batches:** `extensions/discord/src/outbound-payload.ts:105-115`
  - body: The one-file overflow branch builds send options manually and omits `silent`. A silent payload with 11, 21, or similar attachment counts will send the final one-file batch with notifications enabled while the other media paths keep `silent`.
  - confidence: 0.87
