Full review comments:

- **[P1] Fix the new component test spec shape:** `extensions/discord/src/send.components.test.ts:431`
  - body: `check-test-types` fails because this new test passes `{ text, components }` as a `DiscordComponentMessageSpec`, but that type does not define `components`; use an existing valid classic spec shape so the required type check can pass.
  - confidence: 0.95
- **[P1] Scope overflow retries per Discord POST:** `extensions/discord/src/send.outbound.ts:104`
  - body: `sendMessageDiscord` can now emit multiple Discord POSTs inside one call, while outbound callers wrap that call in `withDiscordDeliveryRetry`. If a later overflow batch fails after an earlier batch succeeded, the outer retry can replay the earlier attachments and duplicate delivery; split the retry boundary per actual batch instead.
  - confidence: 0.84
- **[P2] Aggregate overflow batch receipts:** `extensions/discord/src/send.outbound.ts:92-106`
  - body: The overflow loop overwrites `lastResult` on each batch and returns only the final batch. Since Discord receipts are built from returned `platformMessageIds`, a 12-file send drops the first message ID from durable delivery metadata even though that message was sent.
  - confidence: 0.91
- **[P2] Batch ordinary payload mediaUrls before fallback:** `extensions/discord/src/outbound-payload.ts:177-187`
  - body: The new native batch helper only runs inside the Discord-specific components/embeds/filename branch. A normal payload with `mediaUrls` and no Discord channel data still falls through `sendTextMediaPayload`, whose shared contract sends one scalar media item at a time.
  - confidence: 0.89
- **[P2] Keep overflow sends in the created forum thread:** `extensions/discord/src/send.outbound.ts:104`
  - body: For forum/media channels, each overflow loop iteration re-enters `sendMessageDiscordInternal` with the original target, so later batches can create separate new threads instead of continuing in the first thread. Carry the created thread target through the overflow send sequence.
  - confidence: 0.79
