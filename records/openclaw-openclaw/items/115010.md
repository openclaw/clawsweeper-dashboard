The PR retries the terminal UI’s Gateway session-event subscription once after a transient startup failure and adds PTY tests that verify recovery after one failure and bounded behavior after two failures.

## System Context

The terminal UI connects to the Gateway and subscribes to session-event updates so its conversation view stays synchronized with other clients. This change sits in connection startup: it turns a transient subscription error into one bounded retry while retaining a visible error for a persistent failure.
