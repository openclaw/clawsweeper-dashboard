- `P1`: The report describes near-limit sessions repeatedly spending about a minute in doomed preflight compaction before proceeding un-compacted, affecting real agent turns.

## Summary

Keep open: current main and v2026.6.11 still pass the reply-operation abort signal into required budget/preflight compaction, and https://github.com/openclaw/openclaw/pull/95590 is an open candidate fix rather than a merged implementation.

## What This Changes

The issue reports that budget-triggered preflight compaction ignores `agents.defaults.compaction.timeoutSeconds` because it inherits the reply-operation abort signal, and asks for either timeout-aligned preflight compaction or a preflight disable gate.

## Best Possible Solution

Land one canonical fix that lets required preflight compaction run under `compaction.timeoutSeconds` while preserving explicit stop/restart cancellation; treat any preflight disable gate as a separate config-surface decision.
