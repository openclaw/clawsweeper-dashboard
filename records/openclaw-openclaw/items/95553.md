## Summary

Keep open: current main and v2026.6.11 still wire required budget/preflight compaction to the reply-operation abort signal, while the open linked pull request is an unmerged candidate fix rather than implemented behavior.

## What This Changes

The issue asks OpenClaw to stop budget/preflight compaction from being prematurely capped by the reply-operation abort signal instead of `agents.defaults.compaction.timeoutSeconds`.

## Best Possible Solution
