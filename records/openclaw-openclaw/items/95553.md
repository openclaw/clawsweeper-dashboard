## Summary

Keep open: current `main` and the latest release still pass the raw reply-operation abort signal into required budget/preflight compaction, and the open closing PR is a candidate fix rather than a merged implementation.

## What This Changes

The issue asks OpenClaw to stop budget-triggered preflight compaction from being prematurely canceled by the reply-operation abort signal before `agents.defaults.compaction.timeoutSeconds` can govern the work.

## Best Possible Solution

Land a focused fix that gives required preflight compaction a compaction-owned cancellation signal, preserving explicit stop/restart cancellation while preventing lifecycle timeout aborts from overriding `compaction.timeoutSeconds`.
