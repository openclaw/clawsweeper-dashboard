## Summary

Keep open: current main and v2026.6.11 already support per-call `forceDocument`/`asDocument` for Telegram and WhatsApp, but the requested durable `MEDIA:#doc` syntax or deployer-level channel default is still missing and needs a maintainer product/API decision.

## What This Changes

Request a public way to force media delivery as document attachments, either through `MEDIA:` syntax such as `#doc` or a channel-level default that avoids platform image compression.

## Best Possible Solution

Choose one canonical force-document contract, then implement it at the shared message-tool/channel boundary with docs, focused tests, and live transport proof for affected channels.
