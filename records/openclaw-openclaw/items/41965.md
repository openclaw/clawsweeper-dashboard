## Summary

Keep open: current main and v2026.6.11 cover explicit per-call `forceDocument`/`asDocument` delivery for Telegram and WhatsApp, but this issue still asks for a new durable media-delivery contract such as `MEDIA:#doc` syntax or a deployer-level channel default.

## What This Changes

Request a way to force media that would normally be sent as compressed image/video payloads to be delivered as document/file attachments instead.

## Best Possible Solution

Choose one canonical force-document contract, then implement it at the message-tool/channel boundary with docs, focused tests, and live transport proof for affected channels.
