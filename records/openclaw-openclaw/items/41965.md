## Summary

Keep open: current main and the latest release already support per-call `forceDocument`/`asDocument` for Telegram and WhatsApp, but the requested durable `MEDIA:#doc` syntax or deployer-level channel default is still missing and needs a product/API decision.

## What This Changes

The issue requests a way to force media, especially images, to be delivered as document attachments so channel compression does not destroy fidelity.

## Best Possible Solution

Choose one canonical, default-safe force-document contract and implement it at the message-tool/channel boundary with docs, focused tests, and live transport proof.
