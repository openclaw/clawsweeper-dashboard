## Summary

Request a way to force media attachments to be delivered as document/file payloads instead of compressed inline image/media payloads, potentially via `MEDIA:` syntax or a channel-level default.

## Best Possible Solution

Choose one canonical media-delivery contract, then implement it at the message-tool/channel boundary with docs, focused tests, and live transport proof for each affected channel.
