## Summary

Keep open: current main implements per-call `forceDocument`/`asDocument` delivery for Telegram and WhatsApp, but the requested `MEDIA:#doc` directive and deployer-wide channel default are still absent and need maintainer product direction.

## What This Changes

Request a public way to force outbound media to be delivered as document attachments instead of compressed image/media uploads.

## Best Possible Solution

Choose one plugin-owned, default-preserving delivery contract for document-mode media, then document it and cover CLI/tool, gateway, Telegram, WhatsApp, and any opted-in sibling channels with focused tests.
