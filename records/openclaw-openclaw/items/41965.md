## Summary

Keep open: current main and v2026.6.11 support explicit per-call `forceDocument`/`asDocument` for Telegram and WhatsApp, but the requested durable `MEDIA:#doc` syntax or deployer-level channel default is still absent and needs a product/API decision.

## What This Changes

The issue requests a way to force media attachments to be delivered as document/file payloads instead of compressed image/video payloads, originally via `MEDIA:` `#doc` syntax and later via a channel-level default.

## Best Possible Solution

Choose one canonical force-document contract, keep it at the message-tool/channel boundary, and require docs, focused regression tests, and live transport proof for each affected channel.
