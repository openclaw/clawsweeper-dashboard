- `impact:data-loss`: Channel compression can irreversibly change original media bytes or pixel fidelity when users expect screenshots, scans, or generated files to transfer unchanged.

## Summary

Keep open: current main covers per-call forced document sends for Telegram and WhatsApp, but neither the requested `MEDIA:#doc` syntax nor a deployer-wide channel default is implemented; choosing that public contract remains a product decision.

## What This Changes

Request a durable way to force outbound media to be delivered as document attachments so channel compression does not degrade images or generated files.

## Best Possible Solution

Keep `forceDocument`/`asDocument` as the shipped contract unless maintainers choose one explicit durable extension with docs, regression tests, and live proof on affected channels.
