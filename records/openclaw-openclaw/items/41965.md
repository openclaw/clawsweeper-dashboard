## Summary

Keep open: current main and v2026.6.11 already support per-call `forceDocument`/`asDocument` for Telegram and WhatsApp, but the requested durable `MEDIA:#doc` syntax or deployer-level channel default is still missing and requires a maintainer product/API decision.

## What This Changes

Request a way to force outbound media, especially images, to be delivered as document/file attachments instead of compressed image uploads.

## Best Possible Solution

Choose one canonical, default-safe force-document contract and implement it at the message-tool/channel boundary with docs, focused tests, and live transport proof.
