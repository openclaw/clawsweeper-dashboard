## Summary

Keep open: current main and v2026.6.11 support explicit per-send `forceDocument`/`asDocument` for Telegram and WhatsApp, but the broader requested `MEDIA:#doc` syntax or deployer-level channel default is still missing and needs a product/API decision.

## What This Changes

The issue requests a way to force media delivery as document attachments, first via a `MEDIA:` `#doc` fragment and later through discussion of a channel-level default for uncompressed delivery.

## Best Possible Solution

Choose one canonical media-delivery contract, then implement it at the message-tool/channel boundary with docs, focused tests, and live transport proof for each affected channel.
