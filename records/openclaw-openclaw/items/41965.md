## Summary

Keep open: current main and v2026.6.11 already ship per-call forced-document delivery for Telegram and WhatsApp, but the remaining request for `MEDIA:#doc` syntax or a deployer-wide channel default is still absent and needs a product/API decision.

## What This Changes

Request a public way to force fidelity-sensitive media to be delivered as document attachments instead of compressed image/video payloads.

## Best Possible Solution

Keep the shipped per-call `forceDocument`/`asDocument` contract unless maintainers choose one durable extension, then implement that single contract with docs, regression tests, and live proof on affected channels.
