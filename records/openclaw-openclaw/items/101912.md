Full review comments:

- **[P2] Preserve existing model names on blank updates:** `apps/android/app/src/main/java/ai/openclaw/app/NodeRuntime.kt:3503`
  - body: The UI labels display name optional and passes `null` for blank input, but this line always sends `name` after defaulting it to the model id. `models.configure` then replaces an existing entry with that value, so updating a configured model without retyping its display name silently renames persisted config metadata; omit `name` for blank updates and preserve the existing name when replacing.
  - confidence: 0.94
- **[P2] Use the active source snapshot for provider-config lists:** `src/gateway/server-methods/models-list-result.ts:337`
  - body: This Gateway browse branch calls `readConfigFileSnapshot()` on every `provider-config` request while the rest of `buildModelsListResult` uses the request context runtime config. That can mix disk state with the active Gateway state during reloads or external edits and reintroduces request-time config JSON reads; build this view from the active source snapshot owned by the Gateway lifecycle instead.
  - confidence: 0.89
