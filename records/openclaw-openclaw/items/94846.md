## Summary

Keep open: current main still has the source-level pre-dispatch fatal-classification path for recovered isolated-cron tool errors, and the latest maintainer discussion explicitly keeps the issue open for typed exec phase evidence plus cron degraded/warning semantics. ## What This Changes

The issue asks OpenClaw cron isolated `agentTurn` delivery to avoid skipping dispatch when an early tool error is recovered and final assistant output exists.

## Best Possible Solution

Add typed exec failure-phase/process-started evidence and a first-class degraded or warning cron outcome that preserves delivery eligibility, persistence, alerts, and retry/backoff semantics without treating real preflight/provider failures as success.

No existing PR shape is clearly best: the safer fix is not simply trusting final prose, but carrying typed exec phase/process-started evidence into cron and deciding degraded/warning status semantics.
