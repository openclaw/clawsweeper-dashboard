## Summary

Keep open: current main still has the pre-dispatch fatal-error path, and live maintainer discussion keeps the issue valid pending typed exec phase evidence plus first-class degraded cron outcome semantics.

## What This Changes

The issue reports scheduled isolated `agentTurn` cron runs that recover from tool failures, produce final assistant output, but are recorded as fatal before delivery dispatch.

## Best Possible Solution

Add typed exec failure-phase/process-started metadata that cron can trust, then represent recovered process-ran failures with an explicit degraded/warning cron outcome that separates execution status, delivery attempt, delivery result, alerts, and retry/backoff state.
