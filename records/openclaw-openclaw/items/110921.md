## Summary

This PR remains necessary: it addresses the linked, still-open LINE media-loss report by letting pre-adoption transient download failures re-enter the durable ingress retry path. The revised head was also updated by `steipete`; the stated approach matches the existing channel-local retry pattern and introduces no plugin SDK, dependency, or configuration surface.

## What This Changes

The branch converts transient LINE inbound-media download failures into classified `MediaFetchError`s and rethrows them from the media handler so durable ingress retries the event instead of degrading the attachment immediately.

## Best Possible Solution

Merge a focused LINE-local retry classification that preserves permanent-failure degradation, retains the existing ingress retry budget, and keeps regression coverage for both retry and non-retry outcomes.
