## Summary

The intended retry is blocked by LINE’s replay dedupe: the new rethrow reaches the top-level handler, which commits the event key, so the durable drain’s next delivery is skipped as a duplicate. This needs one focused repair before merge.

## What This Changes

The PR replaces LINE’s opaque media-download failures with classified `MediaFetchError`s, rethrows transient failures for durable-ingress retry, adds LINE media tests, and adds a changelog entry.

## Best Possible Solution
