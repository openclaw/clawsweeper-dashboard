## Summary

Keep open: the credential-isolation direction is sound, but replacing the entire Codex home also discards existing worker configuration, skills, plugins, hooks, and native state; the linked live evidence does not validate the submitted branch or that compatibility boundary.

## What This Changes

The PR updates the bundled coding-agent skill to require a dedicated command-scoped `CODEX_HOME`, adds login setup and preflight guidance, and changes both documented Codex launch commands.

## Best Possible Solution

Initialize a dedicated worker Codex profile that never reuses ambient auth while deliberately preserving, migrating, or clearly excluding selected non-auth worker settings, then prove both OAuth separation and representative configured-worker behavior.
