## Summary

Keep this open: current main and the latest release still do not expose Slack `channel-info` or `channel-list` as agent-facing message actions, and the live same-repo candidate is a broad conflicting PR paused for human review.

## What This Changes

Request to add Slack message-tool `channel-info` and `channel-list` actions so agents can resolve Slack channel IDs to readable metadata and list workspace channels.

## Best Possible Solution

Land or split a focused Slack plugin change that exposes both requested actions through discovery, dispatch, runtime helpers, public exports, docs, and tests while preserving Slack read-target authorization and token boundaries.

## Reproduction Assessment

Yes. Source inspection on current main shows Slack discovery omits `channel-info` and `channel-list`, and the Slack dispatcher would reject those actions as unsupported.

## Solution Assessment

Yes on owner boundary, but not yet on merge path. The implementation belongs in `extensions/slack`; maintainers should repair or split https://github.com/openclaw/openclaw/pull/79818, or land a narrower focused change.
