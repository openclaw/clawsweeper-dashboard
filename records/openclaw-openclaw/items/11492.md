## What This Changes

Add agent-facing Slack `channel-info` and `channel-list` message actions for channel metadata lookup and conversation discovery.

## Best Possible Solution

Implement targeted `channel-info` under an explicitly confirmed Slack authorization contract, then add paginated `channel-list` only through a separately approved discovery policy covering credentials and conversation types.
