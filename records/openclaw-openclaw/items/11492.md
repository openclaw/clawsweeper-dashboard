## Summary

Keep open: current main and the latest release still omit the requested Slack channel discovery actions, while the remaining open implementation candidate only covers `channel-list` and leaves `channel-info` plus the permanent discovery/authorization policy unresolved.

## What This Changes

Add Slack message-tool actions that resolve a channel ID to metadata and list channels visible to the configured Slack account.

## Best Possible Solution

Implement both operations inside `extensions/slack`, preferably using the existing `channelInfo` capability unless maintainers deliberately require separate enumeration control, with paginated Slack API helpers, explicit conversation filtering and token-scope behavior, public/runtime wiring, focused authorization and contract tests, and updated Slack documentation.

- **Limit scope to channel lookup:** Implement only `channel-info` for ID resolution and decline broad channel listing until a stronger product need and access policy are established.
