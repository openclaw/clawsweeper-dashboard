## What This Changes

The issue requests Slack message-tool parity with Discord by adding agent-facing `channel-info` and `channel-list` actions for Slack channel ID-to-name and metadata discovery.

## Best Possible Solution

Land or split a focused Slack plugin change that exposes both requested actions through discovery, dispatch, runtime helpers, public exports, docs, and tests while preserving Slack read-target authorization and token boundaries.

## Solution Assessment
