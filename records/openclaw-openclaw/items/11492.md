Keep open: current main and the latest release still do not expose Slack `channel-info` or `channel-list` as agent-facing message actions, and the only open same-repo implementation path is broad, conflicting, and human-review blocked.

## What This Changes

The issue requests Slack message actions that let agents resolve channel IDs to channel metadata and list workspace conversations.

## Best Possible Solution

Land or split a focused Slack plugin change that exposes both requested actions through discovery, dispatch, runtime helpers, public exports, docs, and tests while preserving Slack read-target authorization and token boundaries.

## Reproduction Assessment

Yes, at source level: current main's Slack discovery omits `channel-info` and `channel-list`, and the dispatcher/runtime have no branches or helpers for those actions. The latest release tag shows the same missing surface.

## Solution Assessment
