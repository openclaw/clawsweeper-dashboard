## What This Changes

Add Slack channel-info and channel-list message actions so agents can resolve channel IDs and discover visible workspace conversations.

## Best Possible Solution

Implement both actions inside the Slack plugin after policy approval: use the selected read credential, paginate conversations.list, return bounded untrusted metadata, reuse the existing channelInfo gate if approved, and cover discovery, dispatch, runtime, docs, and authorization contracts without adding core-specific Slack policy.
