## What This Changes

Add Slack message-tool actions that let agents retrieve a channel’s metadata by ID and list conversations visible to the configured Slack account.

## System Context

Slack’s plugin supplies actions to the shared agent message tool. The tool discovers enabled Slack actions, dispatches a selected action to Slack runtime helpers, and returns formatted results to the agent.
