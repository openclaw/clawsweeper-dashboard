## Summary

Keep open: current main still uses blind text replacements and explicitly applies output transforms to structured tool-call arguments, while the linked fix PR is open and conflicting. The remaining work is a real path-safety bug, but the durable boundary needs maintainer choice because tool-argument transforms are also a documented Plugin SDK capability.

## What This Changes

The issue reports that legacy-to-current brand text substitutions can rewrite path strings in tool-call/file-operation arguments and silently redirect file operations when legacy and current workspace directories both exist.

## Best Possible Solution

Review, land, or replace the linked fix with a maintainer-approved design that preserves non-path tool-argument transforms while preventing path/file-operation rewrites, with regression coverage and real dual-directory proof.
