## What This Changes

The issue requests preventing plugin/rebrand text substitutions from silently rewriting filesystem paths in tool-call arguments and related agent I/O surfaces.

## Best Possible Solution

Land or sponsor a narrow core fix that keeps cosmetic text transforms where intended but prevents executable path/tool-bearing argument strings from being rewritten without an explicit maintainer-approved contract, with regression tests and live dual-directory proof.
