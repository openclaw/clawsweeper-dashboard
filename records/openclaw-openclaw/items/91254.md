## What This Changes

The issue asks OpenClaw to stop rebrand/plugin text transforms from silently rewriting path-like tool-call argument strings and misrouting file operations.

## Best Possible Solution

Define a durable transform boundary that preserves cosmetic/masking restores but never silently rewrites path-like OpenClaw-owned tool inputs, then land or supersede the linked candidate with focused regression tests and live dual-directory proof.
