## Summary

Keep open: current main still allows the non-admin in-process subagent `agent` dispatch to inherit the caller client without `operator.write`, and the direct fix candidate at https://github.com/openclaw/openclaw/pull/99199 remains open and unmerged.

## What This Changes

Fix a regression where channel-triggered `sessions_spawn` on a token-auth local Gateway loses effective `operator.write` and fails to start subagents.

## Best Possible Solution

Land a narrow, proof-backed fix at the `callSubagentGateway` in-process dispatch boundary after confirming `sessions_spawn` tool authorization is the intended boundary for synthetic `operator.write`.
