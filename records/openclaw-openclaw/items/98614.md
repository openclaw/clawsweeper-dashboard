The issue reports a regression where Google Chat-triggered `sessions_spawn` fails with `missing scope: operator.write` on token-auth local Gateway deployments after upgrading from v2026.6.1 to v2026.6.11.

## Best Possible Solution

Keep this issue open until a merged PR changes or proves the token-auth `callSubagentGateway` to `agent` server path; retarget https://github.com/openclaw/openclaw/pull/98788 or remove its closing reference if it remains auth-none-only.
