## What This Changes

The issue reports a regression where token-auth, channel-triggered `sessions_spawn` fails with `missing scope: operator.write` after upgrading from v2026.6.1 to v2026.6.11.

## Best Possible Solution

Keep this issue open until https://github.com/openclaw/openclaw/pull/99199 is reviewed and either merged as the focused token-auth fix or replaced by an equivalent narrow repair.

## Reproduction Assessment

Yes, at source level: the in-process `sessions_spawn` path can inherit a channel/plugin scoped client for the `agent` method instead of forcing the synthetic operator write-scope client. I did not run a live Google Chat token-auth reproduction in this read-only review.
