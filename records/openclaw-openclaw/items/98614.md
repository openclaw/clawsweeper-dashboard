## What This Changes

The issue reports a regression where Google Chat-triggered `sessions_spawn` fails under token-auth loopback Gateway setups with `missing scope: operator.write` after upgrading from v2026.6.1 to v2026.6.11.

## Best Possible Solution

Keep this issue open and route the remaining work to a maintainer-approved token-auth `callSubagentGateway` fix with focused Gateway auth tests and real token-auth `sessions_spawn` proof; the auth-none PR should not be treated as the complete fix unless it is retargeted and proven for token auth.
