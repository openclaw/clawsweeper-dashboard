## What This Changes

This PR adds Amazon Bedrock regression tests that verify Claude Opus 5 model identifiers select adaptive thinking and emit the adaptive Bedrock request shape with the requested effort level.

## System Context

The Amazon Bedrock extension maps an agent’s selected model and reasoning level into Converse API request fields. The thinking-policy layer classifies model identifiers, and the streaming runtime uses that classification to choose either adaptive thinking with an effort value or the older extended-thinking request format.
