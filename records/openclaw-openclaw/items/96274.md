## Summary

The runtime metadata contract is sound and well-proven, but a late review pass found that the PR duplicates the repository’s canonical agent-config lookup; replace that local lookup before merge, then refresh the branch and exact-head checks.

## What This Changes

The PR resolves `agents.list[].identity.name` into runtime prompt parameters and renders it as a sanitized `agentName` field while preserving `agent=<id>`.

## Best Possible Solution

Use `resolveAgentConfig(config, agentId)?.identity?.name` as the single identity lookup, retain the sanitized `agent=<id>` and conditional `agentName=<identity>` rendering, then update onto current main and rerun focused and required checks.
