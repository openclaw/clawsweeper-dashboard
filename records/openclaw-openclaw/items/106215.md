## What This Changes

Add a Control UI flow that previews and imports durable Codex CLI and Claude Code memory into a selected OpenClaw agent workspace through the existing migration providers.

## Best Possible Solution

Keep source discovery and item construction in the Claude and Codex migration providers, add a narrow provider-neutral Gateway plan/apply contract, and expose an agent-scoped Settings wizard that shows only source labels, paths, counts, conflicts, and outcomes while preserving verified backup and report semantics.
