## Evidence

- **Sequence identifiers are ordering metadata:** The protocol defines `seq` only on server event frames, while request and response frames correlate through a separate string `id`; side-effecting methods additionally use idempotency keys.
  - file: [docs/gateway/protocol.md:260](https://github.com/openclaw/openclaw/blob/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b/docs/gateway/protocol.md#L260)
  - sha: [21ec1546e5a8](https://github.com/openclaw/openclaw/commit/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b)
- **Request IDs are cryptographically random:** The Node gateway client imports `randomUUID` from `node:crypto` and supplies it as `GatewayProtocolClient.createRequestId`; requests are stored and resolved by that UUID rather than by event sequence numbers.
  - file: [packages/gateway-client/src/client.ts](https://github.com/openclaw/openclaw/blob/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b/packages/gateway-client/src/client.ts)
  - sha: [21ec1546e5a8](https://github.com/openclaw/openclaw/commit/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b)
- **Event sequence handling cannot select a session:** The protocol client only compares event `seq` against `lastSeq` to report delivery gaps, then forwards the event; responses are accepted only when their independently generated `frame.id` matches an entry in the connection-local pending-request map.
  - file: [packages/gateway-client/src/protocol-client.ts](https://github.com/openclaw/openclaw/blob/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b/packages/gateway-client/src/protocol-client.ts)
  - sha: [21ec1546e5a8](https://github.com/openclaw/openclaw/commit/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b)
- **RPC dispatch follows authentication and authorization:** For the initial connection, the server validates the connect frame, authenticates it, authorizes the device, and attaches the authenticated session. Subsequent frames are then passed to the authenticated request dispatcher with that connection's established client context.
  - file: [src/gateway/server/ws-connection/message-handler.ts](https://github.com/openclaw/openclaw/blob/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b/src/gateway/server/ws-connection/message-handler.ts)

  - file: [docs/gateway/protocol.md:267](https://github.com/openclaw/openclaw/blob/21ec1546e5a83975e5ffb3535bc8bc8b0cf2365b/docs/gateway/protocol.md#L267)
