## Evidence

- **Sequence numbers are ordering metadata:** The protocol documents event `seq` as a per-client, monotonically increasing value used to preserve ordering on each socket, not as a session identifier, credential, or authorization token.
  - file: [docs/gateway/protocol.md:480](https://github.com/openclaw/openclaw/blob/9d3de463a5da5378d52af5b511f5711923073a44/docs/gateway/protocol.md#L480)
  - sha: [9d3de463a5da](https://github.com/openclaw/openclaw/commit/9d3de463a5da5378d52af5b511f5711923073a44)
- **Client consumes sequence numbers only for gap detection:** The browser gateway client compares an event sequence number with `lastSeq`, calls the gap notification when numbers are skipped, updates `lastSeq`, and then delivers the event; it does not use the number for identity or authorization.
  - file: [ui/src/ui/gateway.ts:806](https://github.com/openclaw/openclaw/blob/9d3de463a5da5378d52af5b511f5711923073a44/ui/src/ui/gateway.ts#L806)
  - sha: [9d3de463a5da](https://github.com/openclaw/openclaw/commit/9d3de463a5da5378d52af5b511f5711923073a44)
- **Requests remain bound to an authenticated connection:** The WebSocket handler authenticates the connect request, authorizes the device, attaches the authenticated session, and only then dispatches later frames through the authenticated request dispatcher.
  - file: [src/gateway/server/ws-connection/message-handler.ts:623](https://github.com/openclaw/openclaw/blob/9d3de463a5da5378d52af5b511f5711923073a44/src/gateway/server/ws-connection/message-handler.ts#L623)
  - sha: [9d3de463a5da](https://github.com/openclaw/openclaw/commit/9d3de463a5da5378d52af5b511f5711923073a44)
- **Connection authentication uses a signed server challenge:** Gateway architecture requires clients to sign the server-provided `connect.challenge`; non-local connections also require approval and gateway authentication applies to local and remote connections.
  - file: [docs/concepts/architecture.md:78](https://github.com/openclaw/openclaw/blob/9d3de463a5da5378d52af5b511f5711923073a44/docs/concepts/architecture.md#L78)
