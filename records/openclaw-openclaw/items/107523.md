## Evidence

- **Sequence numbers are ordering metadata:** The browser Gateway client records each received event sequence, reports only forward gaps through `notifyGap`, then delivers the event normally; the sequence is not used as a session identifier, credential, or authorization input.
  - file: [ui/src/ui/gateway.ts:3886](https://github.com/openclaw/openclaw/blob/61df1dbe7b0ce82c99d960ded69d94758214c3a6/ui/src/ui/gateway.ts#L3886)
  - sha: [61df1dbe7b0c](https://github.com/openclaw/openclaw/commit/61df1dbe7b0ce82c99d960ded69d94758214c3a6)
- **Sequences are isolated per authenticated connection:** Gateway protocol documentation states that every client connection has its own monotonic sequence number so scope-filtered event streams remain ordered independently.
  - file: [docs/gateway/protocol.md:480](https://github.com/openclaw/openclaw/blob/61df1dbe7b0ce82c99d960ded69d94758214c3a6/docs/gateway/protocol.md#L480)
  - sha: [61df1dbe7b0c](https://github.com/openclaw/openclaw/commit/61df1dbe7b0ce82c99d960ded69d94758214c3a6)
- **Broadcast content is scope-gated:** Chat, agent, and tool-result broadcasts require operator read scope; unknown broadcast families fail closed unless explicitly relaxed, so guessing another connection's sequence does not grant receipt authority.
  - file: [docs/gateway/protocol.md:473](https://github.com/openclaw/openclaw/blob/61df1dbe7b0ce82c99d960ded69d94758214c3a6/docs/gateway/protocol.md#L473)
  - sha: [61df1dbe7b0c](https://github.com/openclaw/openclaw/commit/61df1dbe7b0ce82c99d960ded69d94758214c3a6)
