## Summary

Keep open: current main still source-reproduces the silent native-image drop across embedded, CLI, and harness paths, and no merged or canonical PR currently owns the skipped-image visibility contract.

## What This Changes

The issue asks OpenClaw to surface failed native image attachment loads instead of omitting them from model prompts.

## Best Possible Solution

Define one safe skipped-native-image visibility contract in core image loading, avoid full local path leaks by default, and consume it consistently from embedded, CLI, and harness callers with focused regression coverage.

## Solution Assessment

Unclear until maintainers choose the visible failure surface. The narrowest maintainable fix appears to be a shared skipped-image result contract rather than ad hoc per-caller wording.
