## Summary

Keep open: current main still source-reproduces the silent failed-image-load drop, and no merged fix or canonical open PR owns the skipped-image visibility contract.

## What This Changes

The issue requests a visible failure contract when native image attachments cannot be loaded into a model prompt.

## Best Possible Solution

Define one safe skipped-image visibility contract in core image loading and consume it consistently from embedded, CLI, and harness callers, with focused tests and no full local-path leak by default.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Where should OpenClaw surface failed native image attachment loads: model-visible prompt markers, user/operator diagnostics, turn failure, or a combination?

Rationale: The source bug is clear, but the durable behavior affects model-visible text, user-facing diagnostics, log level, path disclosure, and multiple caller surfaces.

Likely owner: vincentkoc

Owner reason: Recent commits touch the embedded, CLI, and harness image paths that would need to share the selected contract.

Owner confidence: high

Options:

- **Prompt Marker Contract (recommended):** Return skipped-image metadata and have embedded, CLI, and harness callers add a safe model-visible marker or count without full local paths, so the model cannot answer as if no image was sent.
- **Diagnostics Only:** Emit a user/operator warning while leaving the model prompt unchanged, which avoids prompt wording policy but still lets the model answer without the missing image.
- **Fail Current Turn:** Treat failed current-turn image attachment loads as input errors, which gives the strongest user signal but may break workflows where optional prompt refs fail.

## Reproduction Assessment

Yes, source-reproducible: failed image loads return null, are counted in skippedCount, and are then discarded by current callers. A live corrupt-image or sandbox-denied model run has not been captured.

## Solution Assessment

Unclear until maintainers choose the visible surface. A shared skipped-image result contract consumed by embedded, CLI, and harness callers appears narrower than one-off caller behavior.
