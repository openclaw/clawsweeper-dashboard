## What This Changes

The issue asks OpenClaw to make failed native image attachment loads visible instead of silently omitting them from the model prompt.

## Best Possible Solution

Define one safe skipped-image visibility contract in core image loading and consume it consistently from embedded, CLI, and harness callers, with focused tests and no full local-path leak by default.
