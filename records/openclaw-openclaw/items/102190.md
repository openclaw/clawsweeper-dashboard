## Summary

Keep open: current main still source-reproduces failed native image loads being counted and then dropped before model submission, and no merged fix or canonical PR currently owns the skipped-image visibility contract.

## What This Changes

Surface failed native image attachment loads instead of silently omitting skipped image refs from the model prompt.

## Best Possible Solution

Define one safe skipped-image visibility contract in core image loading and consume it consistently from embedded, CLI, and harness callers, avoiding full local-path disclosure by default.
