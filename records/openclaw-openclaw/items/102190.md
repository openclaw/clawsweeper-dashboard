## What This Changes

The issue requests visible handling when native prompt image attachment loading fails instead of dropping the image before model submission.

## Best Possible Solution

Define one safe skipped-image visibility contract in the core image loader result and consume it consistently from embedded, CLI, and harness callers without exposing full local paths by default.
