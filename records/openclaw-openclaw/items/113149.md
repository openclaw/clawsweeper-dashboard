## What This Changes

Fix CLI-backend fallback recovery so an empty response resets only the failed provider session and does not stop concurrent background agent runs, while considering an automated recovery path for genuinely orphaned runs.

## System Context

The gateway routes an agent turn to a CLI-backed provider and may switch models after an empty response. Session-reset logic clears CLI session bindings before the fallback attempt; overly broad clearing can affect concurrent background agent work sharing the same parent session context.
