## What This Changes

This PR keeps active embedded-run steering visible through diagnostics while preventing those accepted steering messages from inflating the session backlog depth.

## System Context

Embedded-agent sessions can accept steering messages while a run is already active. The diagnostics layer emits queue and state events from those paths, which feed liveness and stuck-session reporting for operators and integrations.

## Architecture Diagram

  D -->|Yes, ordinary queued turn| F[Backlog depth increases]
  E --> G[Liveness and stuck-session diagnostics]
  F --> G

## Best Possible Solution

Keep queue events for observability, count only real waiting session work as backlog, and add redacted after-fix evidence from a live embedded-agent session covering steering during a run and its normal completion.
