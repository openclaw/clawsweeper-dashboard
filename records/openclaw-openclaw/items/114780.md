## What This Changes

This PR keeps active-run steering visible in diagnostics while excluding it from the queued-turn backlog, with regression coverage for embedded and reply-backed agent runs plus a Gateway QA scenario.

## System Context

OpenClaw’s embedded agent runner accepts steering messages while an agent turn is already active. Those messages feed diagnostic events and session liveness state, which downstream operator tooling uses to distinguish real queued work from an active turn’s in-place steering.
