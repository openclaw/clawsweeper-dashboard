## Summary

Keep open: the intended implicit-main repair is useful, but the new route-resolution shortcut regresses configurations that explicitly define a normalized `MAIN` agent id, which the schema continues to accept.

## What This Changes

This PR permits an exact `main` binding alongside named agents, preserves it through Doctor repair, and routes matching traffic to the implicit main agent.

## System Context

Agent bindings choose which agent receives inbound channel traffic. Config validation and Doctor repair protect valid bindings before the routing layer resolves the matched binding into an agent session.
