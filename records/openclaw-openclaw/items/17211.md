Keep open: current main provides compaction snapshot recovery and adjacent restart-recovery state, but still lacks the requested general checkpoint creation, deterministic resume packet, audit diff, and task-boundary validation contract. Recent discussion explicitly preserves this issue as the broader product/API umbrella rather than treating narrower snapshot and restart issues as replacements.

## What This Changes

Requests a native checkpoint engine with create/list/resume/diff APIs, deterministic replay packets, structured task-boundary state, and validation hooks.

## Best Possible Solution

Define one versioned session-checkpoint contract, backed by the canonical state database, that extends current compaction recovery with explicit creation, validated task-boundary state, deterministic continuation packets, auditable diffs, and strict non-inheritance of approvals, credentials, and executed side effects.
