## Summary

Keep open: current main and the latest release still provide compaction-scoped checkpoint metadata plus branch/restore recovery, not the requested native checkpoint engine with deterministic replay packets, diffing, task-boundary contracts, or validation hooks.

## What This Changes

The issue requests first-class checkpoint create/list/resume/diff APIs with structured task-boundary state, deterministic replay packets, diffing, and validation hooks for reliable long-running task continuation.

## Best Possible Solution

Define a versioned Gateway/session checkpoint contract that composes existing compaction checkpoints with canonical persistence, deterministic replay/diff/audit data, validation semantics, security rules, UI/CLI behavior, docs, and focused tests.
