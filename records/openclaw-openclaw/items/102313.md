## Summary

Keep open: current main still lowercases direct Matrix peer IDs before non-main DM session-key construction, so case-distinct MXIDs can collide under per-peer DM scopes. This is source-reproducible and security-sensitive, so it should stay with maintainer/security review rather than conservative cleanup close.

## What This Changes

The issue reports that Matrix direct-message session keys fold case-distinct MXIDs into the same per-peer DM session key, causing transcript sharing across distinct peers.

## Best Possible Solution

Matrix direct-peer session keys should preserve provider-owned MXID case under non-main `dmScope`, keep case-insensitive channels folded, and include focused legacy-safety tests; Signal direct should be added only with direct-ID contract proof.
