## Summary

Keep open: current main and the latest release still lowercase Matrix direct peer IDs before non-main DM session-key construction, so case-distinct direct IDs can collide under per-peer DM scopes. The merged room/channel fix at https://github.com/openclaw/openclaw/pull/87366 added the case-preservation registry but explicitly left Matrix DM/MXID keys lowercased.

## What This Changes

The issue requests preserving case-distinct Matrix direct-message peer IDs under non-main DM scopes so separate peers do not share one persisted transcript.

## Best Possible Solution

Preserve Matrix direct-peer ID case for non-main DM scopes through the shared case-preserving session-key policy, add focused collision and legacy-alias tests, and decide Signal direct enrollment separately with contract proof.
