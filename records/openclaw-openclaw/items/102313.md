## Label Justifications

- `P1`: A documented DM isolation mode can collapse distinct Matrix direct senders into one transcript session, which is urgent despite non-default and homeserver-dependent exposure.
- `impact:security`: The reported failure can expose one Matrix peer's private DM transcript to another distinct peer.
- `impact:session-state`: Two peer identities can map to the same persisted session key under per-peer DM scopes, mis-associating transcript state.

## Summary

Keep open: current main and the latest release still lowercase Matrix direct peer IDs before constructing isolated non-main DM session keys, so case-distinct MXIDs can collide into one transcript session despite the documented DM isolation contract.

## What This Changes

Fix Matrix direct-message session keys so per-peer DM scopes preserve case-distinct MXIDs and do not share transcripts across distinct users.

## Best Possible Solution

Preserve Matrix direct MXID case through the existing case-preserving session-key policy for non-main DM scopes, add focused regressions for case-distinct direct peers and legacy folded rows, and only enroll Signal direct after separate identity-contract proof.
