## Summary

Keep open: current main and the latest release still lowercase Matrix direct peer IDs before non-main DM session-key construction, so case-distinct MXIDs can collide under per-peer DM scopes. The prior Matrix case-preservation PR fixed room/channel keys but explicitly left direct peers folded.

## What This Changes

The issue reports that Matrix direct-message session keys lower-case case-distinct MXIDs under non-main DM scopes, causing different peers to share one transcript.

## Best Possible Solution

Matrix direct-peer session keys should preserve provider-owned identity case under non-main `dmScope`, leave case-insensitive channels folded, and handle legacy lowercased rows safely; Signal direct should be included only with direct-ID contract proof.
