## Label Justifications

## Summary

Keep open: current main and the latest release still lowercase Matrix direct peer IDs before non-main DM session-key construction, so case-distinct MXID-like peers can collide under DM isolation. The prior Matrix case-preservation work fixed channel/group room keys and explicitly left direct peers folded.

## What This Changes

The issue asks OpenClaw to preserve opaque Matrix direct-peer identity case when building per-peer DM session keys so distinct peers do not share one persisted transcript.

## Best Possible Solution

Preserve Matrix direct peer ID case through the existing case-preserving session-key policy for non-main DM scopes, add regression coverage for Matrix direct keys and legacy lowercased rows, and include Signal direct only after direct-ID contract proof.
