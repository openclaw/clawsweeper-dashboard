## Label Justifications

- `P1`: A documented DM isolation mode can collapse distinct Matrix direct senders into one transcript session, which is urgent despite non-default and homeserver-dependent exposure.
- `impact:security`: The reported collision can expose one Matrix peer's private DM transcript to another distinct peer.

## Summary

Keep open: current main and the latest release still lowercase Matrix direct peer IDs before non-main DM session-key construction, so case-distinct MXIDs can collide despite the documented per-peer DM isolation contract. The Matrix `per-room` sessionScope is a workaround for DM rooms, but it does not fix the sender-scoped direct peer path reported here.

## What This Changes

The issue asks OpenClaw to preserve case-sensitive Matrix direct peer IDs when building per-peer DM session keys so case-distinct MXIDs cannot share one transcript.

## Best Possible Solution

Preserve Matrix direct MXID case in non-main DM session-key construction and canonicalization, add regressions for case-distinct Matrix DMs and legacy folded rows, and decide Signal direct separately with contract proof.
