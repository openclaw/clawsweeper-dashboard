## What This Changes

This PR resolves one Gateway plugin-metadata snapshot for each auto-reply model-selection run and reuses it while normalizing policy, configured, stored-override, and fallback model references.

## System Context

Auto-reply model selection converts incoming reply context, configured model policy, session overrides, and fallback choices into the provider/model sent to an agent. Plugin metadata supplies provider-owned normalization facts, so repeated discovery in this path can delay a reply before its model request begins.
