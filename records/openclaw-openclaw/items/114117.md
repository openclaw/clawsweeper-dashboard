## What This Changes

The PR resolves the Gateway’s current plugin-metadata snapshot once for each auto-reply model-selection run and reuses it for visibility policy, configured catalogs, stored overrides, and fallback model normalization.

## System Context

Auto-reply model selection converts requested, stored, and configured model references into the provider/model choice used for an agent reply. Plugin metadata supplies provider-owned normalization facts, so avoiding repeated manifest discovery reduces work before the provider request begins.
