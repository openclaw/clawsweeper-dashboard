## What This Changes

The PR prepares one Gateway plugin-metadata snapshot for each auto-reply model-selection run and reuses it for visibility policy, configured model catalogs, stored overrides, and fallback model normalization to reduce pre-request latency.

## System Context

Before an agent reply reaches a provider, auto-reply selects and normalizes a provider/model using configured policy and plugin-contributed metadata. The changed path carries the Gateway’s process-stable metadata snapshot through that decision so repeated normalization does not rediscover plugin manifests.
