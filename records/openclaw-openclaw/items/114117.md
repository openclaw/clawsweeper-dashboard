## What This Changes

This PR resolves one current Gateway plugin-metadata snapshot per auto-reply model-selection run and reuses it during policy, catalog, override, and fallback model normalization to reduce reply preparation delay.

## System Context

Auto-reply selects a provider and model before an agent sends a reply. That selection combines user configuration, session overrides, visibility policy, model catalogs, and Gateway plugin metadata before provider execution begins.
