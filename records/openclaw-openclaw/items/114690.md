## What This Changes

Investigate and prevent a Codex-backed Discord turn from sending a second semantically duplicate `message(action=send)` reply after native compaction resumes the same inbound turn.

## System Context

A Discord inbound message starts an OpenClaw agent turn whose visible source-channel output is sent through the message tool. Native Codex compaction can resume that turn with altered context, so delivery state and the resumed tool decisions determine whether Discord receives one reply or an unintended duplicate.
