## Summary

## What This Changes

The PR changes Slack lifecycle status reactions to require explicit `messages.statusReactions.enabled: true`, updates docs/help/changelog text, and adds tests for static acknowledgement behavior.

## Best Possible Solution

Preserve the existing reaction lifecycle whenever Slack native status cannot actually run, and suppress duplicate reactions by default only for paths with a usable native status thread or explicit opt-in threading.
