## Summary

Keep open: the prior blocker still applies because the branch suppresses Slack lifecycle reactions for unset config even when native Slack status has no thread target, so common default top-level channel mentions would lose visible progress feedback.

## What This Changes

The branch changes Slack lifecycle status reactions from default-on to opt-in for unset config, keeps static acknowledgement reactions, updates Slack/config docs and help text, and adds focused Slack tests.

## Best Possible Solution

Use native Slack assistant thread status by default only when a usable `statusThreadTs` exists, and preserve lifecycle reaction progress for unthreaded fallback paths unless maintainers explicitly accept the static-ack compatibility break.
