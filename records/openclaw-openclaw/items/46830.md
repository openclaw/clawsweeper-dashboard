## Summary

Keep open. Current main and the latest release already have durable outbound outcome types, CLI/Gateway delivery-status reporting, pending-final recovery, and one MS Teams-specific delivery-failure system event, but they still do not define the requested shared cross-channel agent-visible delivery-failure notification or permanent message-tool failure-status contract.

## What This Changes

The issue requests a cross-channel way for agents to learn when outbound channel delivery fails, either through a system event in agent context or structured delivery status in message sends.

## Best Possible Solution

Define one shared typed delivery-failure/status contract over the existing durable outbound outcomes, then expose it through the maintainer-approved agent/tool surface with cross-channel tests and docs.
