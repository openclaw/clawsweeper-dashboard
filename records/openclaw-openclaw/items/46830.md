## Summary

Keep open. Current main and v2026.6.11 already have delivery-status reporting, durable outbound outcome types, pending-final recovery, and some channel-specific failure notices, but they still do not provide the requested shared agent-visible cross-channel delivery-failure notification or message-tool failure-status contract.

## What This Changes

Request a cross-channel mechanism that tells the agent when outbound channel delivery fails, either through an injected system event or structured message-tool delivery status.

## Best Possible Solution

Define one typed shared delivery-failure contract that reuses existing durable outbound outcomes and `deliveryStatus`, then expose it through the agent/tool surface with cross-channel tests instead of adding more per-channel ad hoc injections.
