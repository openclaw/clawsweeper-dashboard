## Summary

Keep open because current main has shipped delivery-status reporting and several narrower recovery paths, but it still lacks the requested shared cross-channel agent-visible delivery-failure notification contract.

## What This Changes

The issue requests a shared way for agents to observe failed outbound channel delivery through a system event or structured message-tool status instead of assuming the user received the response.

## Best Possible Solution

Define one typed shared delivery-failure/status contract over existing durable outbound outcomes and expose it consistently through the maintainer-chosen agent, tool, or system-event surface with cross-channel tests.
