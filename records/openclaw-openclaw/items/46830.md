## Summary

Keep open. Current main and the latest release have durable delivery outcomes, CLI/Gateway deliveryStatus, and a Teams-specific system event, but they still do not define the requested shared cross-channel agent-visible delivery-failure contract.

## What This Changes

Request a shared way for agents to learn when outbound channel delivery fails, either via system-event injection or structured delivery status.

## Best Possible Solution

Define one sanitized typed delivery-failure/status contract over existing durable outbound outcomes, then expose it through the maintainer-chosen agent or tool surface with cross-channel tests and docs.
