## Summary

Keep open. Current main has narrower deliveryStatus, durable-send, task, and cron diagnostics, but it still does not provide the shared agent-visible cross-channel delivery-failure notification or message-tool status contract requested here.

## What This Changes

Request a shared notification or status mechanism so agents can know when channel message delivery fails and recover instead of assuming success.

## Best Possible Solution

Define a maintainer-approved typed delivery outcome contract at the agent/channel boundary, then implement channel adapters so failed final replies become agent-visible without duplicating per-channel policy.
