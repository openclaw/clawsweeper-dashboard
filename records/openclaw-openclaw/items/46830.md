## Summary

Keep open: current main has durable outbound outcomes, caller-facing CLI/Gateway delivery status, diagnostics/hooks, and cron/Teams-specific awareness events, but no shared cross-channel agent-visible delivery-failure notification or permanent message-tool failure-status contract.

## What This Changes

Request shared notification/status semantics so agents can detect and recover from failed outbound channel delivery.

## Best Possible Solution

Define one shared typed delivery-failure/status contract over the existing durable outbound outcomes, then expose it through a maintainer-approved agent/tool surface with cross-channel tests and docs.
