## Summary

Keep open. Current main has partial delivery-status primitives, narrow requester notifications, cron-specific awareness, and a Teams-specific delivery-failure system event, but it still does not define the requested shared cross-channel agent-visible delivery-failure contract.

## What This Changes

The issue requests an agent-visible notification or structured status when channel message delivery fails so the agent does not assume the user received the reply.

## Best Possible Solution

Define one typed shared delivery-failure/status contract on top of durable outbound outcomes, then expose it through the maintainer-chosen agent/tool surface with cross-channel coverage.
