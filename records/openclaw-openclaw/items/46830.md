## Summary

Keep open. Current main and v2026.6.11 have durable delivery statuses and a Teams-specific system event, but no shared cross-channel model-visible delivery-failure contract or permanent message-tool failure-status policy; related issues cover only overlapping slices.

## What This Changes

The issue requests a shared channel-delivery failure notification contract so agents can detect failed outbound sends and recover instead of assuming delivery succeeded.

## Best Possible Solution

Define one shared typed delivery-failure/status contract over the durable outbound outcomes, then expose it through the maintainer-approved agent/tool surface with cross-channel tests and docs.
