## Summary

Keep open. Current main has durable delivery outcome primitives, CLI/Gateway delivery-status reporting, pending-final recovery, and a Microsoft Teams-specific failure system event, but it still lacks the requested shared cross-channel agent-visible delivery-failure contract.

## What This Changes

The issue requests a shared way to notify agents or message-tool callers when outbound channel delivery fails so agents do not assume a user received a failed send.

## Best Possible Solution

Define one typed shared delivery-failure/status contract over the existing durable outbound outcomes, then expose it to the agent/tool surface with cross-channel tests and docs.
