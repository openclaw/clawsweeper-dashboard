## Summary

Keep open. Current main has durable outbound delivery outcomes, direct message/agent caller-facing status, and one Microsoft Teams-specific failure system event, but it still does not provide the requested shared cross-channel agent-visible delivery-failure notification or permanent model/tool-visible failure contract.

## What This Changes

The issue requests a cross-channel agent-visible notification or status contract when outbound channel message delivery fails.

## Best Possible Solution

Define one shared typed delivery-failure/status contract over the existing durable outbound outcomes, then expose it through the maintainer-approved agent/tool surface with cross-channel tests and docs.
