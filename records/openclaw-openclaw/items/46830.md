## Summary

Keep open. Current main exposes delivery status to CLI/Gateway/direct-send callers and has narrower Teams/cron awareness paths, but it still does not define the requested shared cross-channel agent-visible delivery-failure contract.

## What This Changes

Request to notify agents when outbound channel delivery fails, either by injecting a delivery-failure system event into context or returning structured delivery failure status to the agent/tool surface.

## Best Possible Solution

Define one sanitized typed delivery-failure/status contract on top of existing durable outbound outcomes, then expose it through the maintainer-chosen agent/tool surface with cross-channel tests and docs.
