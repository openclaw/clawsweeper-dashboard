## Summary

Keep open. Current main has CLI/Gateway deliveryStatus, durable outbound failure outcomes, and a Teams-specific failure system event, but it still lacks the requested shared cross-channel agent-visible delivery-failure contract.

## What This Changes

The issue requests a shared mechanism for channel delivery failures to become visible to the agent, either as context events or message-tool delivery status.

## Best Possible Solution

Define one typed shared delivery-failure contract that reuses existing durable outbound outcomes and deliveryStatus, then expose it through the chosen agent/tool surface with cross-channel tests and docs.
