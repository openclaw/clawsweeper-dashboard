## Summary

Keep open. Current main has durable outbound outcome types, CLI/Gateway delivery-status reporting, and channel-specific failure handling, but it still lacks the requested shared cross-channel agent-visible delivery-failure notification or permanent model/tool contract.

## What This Changes

Request a shared delivery-failure notification/status contract so agents can learn when outbound channel sends fail and recover.

## Best Possible Solution

Define one shared typed delivery-failure/status contract over the existing durable outbound outcomes, then expose it through the maintainer-approved agent/tool surface with cross-channel tests and docs.
