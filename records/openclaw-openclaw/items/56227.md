## Summary

Keep open: current main still closes or restarts the active gateway before replacement health is proven, so the requested old-instance-preserving handoff is not implemented.

## What This Changes

The issue requests an atomic gateway restart flow that starts and verifies a replacement before stopping the currently reachable gateway.

## Best Possible Solution

Define a cross-platform restart-continuity contract that keeps the current listener reachable until a replacement passes health checks or the restart is rejected with an in-channel recovery path.
