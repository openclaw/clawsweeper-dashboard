## Summary

Keep open: current main has safe restart deferral, restart health checks, and startup-failure recovery, but the general restart path still closes or restarts the active gateway before a replacement instance is proven healthy, so the requested old-instance-preserving handoff remains missing.

## What This Changes

The issue requests restart handoff behavior that starts and verifies a replacement gateway before stopping the currently reachable gateway.

## Best Possible Solution

Design one owner-approved restart handoff contract that keeps the current gateway reachable until a replacement has bound and passed a real health probe, with explicit fallbacks for supervisors that cannot safely overlap listeners.
