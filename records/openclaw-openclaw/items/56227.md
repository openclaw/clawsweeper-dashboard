## Summary

Keep open: current main still lacks an old-instance-preserving gateway restart handoff. Source shows managed and in-process restarts act on the current gateway before replacement health is proven, and exact related searches did not find a narrower canonical fix.

## What This Changes

The issue requests an atomic gateway restart path that keeps the previous gateway process available until a replacement is healthy.

## Best Possible Solution

Define a cross-platform restart continuity contract, then implement old-instance-preserving handoff only where supervisor, port binding, lock, rollback, and in-product recovery or channel notification semantics are explicit.

Unclear as an implementation-ready proposal: the atomic handoff goal is sound for availability, but the best fix needs a designed cross-platform supervisor, port, lock, rollback, and notification contract.
