## Summary

Keep open: current main and the latest shipped release still restart or close the active gateway before replacement health is proven, so the requested old-instance-preserving handoff is not implemented. Existing safe-restart preflight, deferral, sentinels, and post-restart health checks reduce damage but do not provide the availability contract this issue asks for.

## What This Changes

The issue requests a gateway restart handoff that starts and health-checks a replacement gateway before stopping the active instance.

## Best Possible Solution

Define a supported cross-platform restart continuity contract, then implement gateway lifecycle code that keeps the current listener available until replacement health succeeds or rejects the restart safely.
