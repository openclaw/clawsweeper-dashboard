## Summary

Keep open: current main and the latest release still use shared inbound media storage, flat managed-media references, and flat sandbox staging, so the multi-agent media privacy gap remains unresolved.

## What This Changes

Request scoped inbound media storage and sandbox staging so media received by one agent/account is not readable as another agent's media.

## Best Possible Solution

Keep this as the canonical broad tracker and define one scoped managed-media contract across storage, channel/plugin saves, media references, sandbox staging, local access, cleanup, docs, and tests.
