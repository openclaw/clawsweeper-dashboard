## Label Justifications

- `P2`: The issue reports a real multi-agent privacy and correctness gap with limited blast radius and no immediate runtime outage.
- `impact:security`: The report describes one agent being able to read sensitive inbound media intended for another agent through shared managed storage.

## Summary

Keep open: current main and the latest release still route managed inbound media through a shared flat media store and flat sandbox staging path, so the cross-agent media privacy gap remains unresolved.

## What This Changes

Request to isolate inbound media so files received for one agent, account, or session are not visible to other agents through the shared `media/inbound` pool.

## Best Possible Solution

Keep this issue as the canonical broad tracker and define one scoped managed-media contract across storage, channel saves, URI/path resolution, sandbox staging, local-root access, cleanup, docs, and regression tests.
