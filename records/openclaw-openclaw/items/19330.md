## Summary

Keep open: current main and the latest release still use a shared inbound media bucket and flat sandbox staging, so the cross-agent media privacy gap remains unresolved.

## What This Changes

Request scoped inbound media storage so media received for one agent/account is not visible to other agents through the shared media directory.

## Best Possible Solution

Define a scoped managed-media isolation contract across storage, bundled/plugin channel saves, media URI/path resolution, local-root access, sandbox staging, cleanup, docs, and regression tests.
