## Summary

Keep open: current main and the latest release still route representative inbound media through a shared `inbound` media bucket and first-level `media://inbound/<id>` contract, so the cross-agent privacy gap remains unresolved.

## What This Changes

Request scoped inbound media storage and staging so media sent to one agent/account is not visible to other agents through the shared media directory.

## Best Possible Solution

Define one canonical scoped managed-media contract across storage, channel saves, URI/path resolution, sandbox staging, local access, cleanup, docs, and regression tests.
