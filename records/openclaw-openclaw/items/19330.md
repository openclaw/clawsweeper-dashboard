## Summary

Keep open: current main and the latest release still use a shared inbound media store and flat sandbox staging path, so the reported multi-agent media privacy gap remains unresolved.

## What This Changes

Request scoped inbound media storage so media received for one agent cannot be read or staged by another agent.

## Best Possible Solution

Keep this issue as the canonical broad tracker and define a scoped managed-media contract across storage, channel saves, URI/path resolution, sandbox staging, local-root access, cleanup, docs, and regression tests.
