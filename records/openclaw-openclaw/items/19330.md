## Label Justifications

- `P2`: The issue reports a real source-backed multi-agent media privacy gap with limited blast radius, but it needs a design/security decision before implementation.
- `impact:security`: The reported failure mode is cross-agent access to private inbound media through a shared managed media root.
- `impact:session-state`: Media intended for one routed agent or session can become visible to another agent/session through shared storage and flat staging.
- `maturity:stable`: The issue affects Discord/channel inbound media handling, and Discord is scored M4 Stable in qa/maturity-scores.yaml.

## Summary

Keep open: current main and the latest release still use a shared inbound media store, flat managed-media references, and flat sandbox staging, so the reported multi-agent media privacy gap remains unresolved.

## What This Changes

The issue requests per-agent isolation for inbound media so media received by one agent cannot be read or selected by another agent through the shared media store.

## Best Possible Solution

Keep this as the canonical broad tracker and define one scoped managed-media contract across storage, channel saves, URI/path resolution, sandbox staging, local-root access, cleanup, docs, and tests.

Options:

- **Define Scoped Contract First (recommended):** Choose the ownership identity, compatibility behavior, and explicit sharing semantics before implementation touches storage and staging paths.
- **Limit To Account Scoping:** Implement the lower-friction account-based directory model while accepting that non-1:1 account-to-agent and tenant-sharing cases may need follow-up.
- **Defer Broad Core Change:** Keep only channel-specific slices open until a maintainer sponsors the cross-channel core media-isolation design.

## Reproduction Assessment

Yes, at source level. Current main still saves representative inbound media into the shared `inbound` bucket, rejects scoped managed refs, and stages sandbox media into flat `media/inbound/<fileName>` paths; I did not run a live multi-agent deployment.

## Solution Assessment

Unclear as proposed. Scoped storage is the right direction, but the best fix must cover the durable media-reference, sandbox-staging, access-control, compatibility, cleanup, and explicit-sharing contract rather than only changing save-time subdirectories.
