## Summary

Keep open: current main and the latest release still use a shared flat inbound media store and flat sandbox staging, so the multi-agent media privacy gap remains unresolved and still needs maintainer product/security direction.

## What This Changes

The issue requests scoped inbound media storage so files received for one agent/account are not pooled with media for other agents.

## Best Possible Solution

Keep this as the canonical broad tracker and define a scoped managed-media contract across storage, channel saves, URI/path resolution, sandbox staging, local-root access, cleanup, docs, and regression tests.
