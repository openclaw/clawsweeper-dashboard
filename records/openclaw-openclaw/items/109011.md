## Summary

Keep open: the linked LINE bugs have strong live reproduction evidence and the reply-token direction is sound, but the patch introduces a blocking failure mode where one rejected rich or media item can suppress the accompanying text reply.

## What This Changes

The PR combines LINE text, rich content, and media into reply-token batches when possible, moves quick replies to the final delivered message, and adds regression coverage.

## Best Possible Solution

Keep the unified reply-token batching and final-message quick replies, but make definitive mixed-batch rejection preserve text delivery by splitting or validating the failing rich/media portion, with regression coverage proving text still arrives.
