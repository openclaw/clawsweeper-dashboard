## Summary

## What This Changes

Refactors LINE auto-reply delivery to batch text, rich, and media messages onto an available reply token and attach quick replies to the final outgoing message.

## Best Possible Solution

Land the unified batching implementation so reply-token capacity is consumed before quota-bound push delivery, with overflow and quick-reply placement protected by the added regression tests.
