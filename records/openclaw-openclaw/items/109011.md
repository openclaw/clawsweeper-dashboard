## What This Changes

Refactors LINE auto-reply delivery to batch text, rich, and media messages onto an available reply token and place quick replies on the final outgoing message.

## Best Possible Solution

Update the branch to current main, preserve the unified reply-token batch and trailing quick-reply rule, then land it after the focused LINE delivery tests and CI confirm fallback, overflow, ordering, and partial-delivery behavior on the refreshed head.

## Solution Assessment

Yes. Building one ordered batch before consuming the single-use reply token is narrower and more maintainable than extending the chunk helper or toggling a flag after token consumption, and it reuses the existing five-message overflow and push-fallback path.
