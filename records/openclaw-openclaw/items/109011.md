## Summary

Keep this PR open for landing: current main still splits token-delivered text from push-delivered rich content and caps overflow quick replies at the fifth message, while this branch addresses both defects with strong live LINE evidence and no concrete review finding. Refresh the branch against current main and complete the remaining checks before merge. ([github.com](https://github.com/openclaw/openclaw/blob/main/extensions/line/src/auto-reply-delivery.ts))

## What This Changes

The branch unifies LINE text, rich, and media auto-replies into reply-token batches with push overflow, and moves quick replies to the final delivered message.

## Best Possible Solution

Rebase the unified batching implementation onto current main, preserve its reply-failure and overflow regression coverage, and merge it so the two linked LINE issues close together.
