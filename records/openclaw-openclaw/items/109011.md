## Summary

Keep this PR open as the viable fix for two reproducible LINE delivery defects: current `main` still routes mixed rich replies through quota-bound push delivery, while this branch consolidates reply-token batching and preserves quick replies on overflow. The implementation and live A/B evidence are convincing, but the branch should not merge until its failing test-type check is diagnosed and exact-head validation is green.

Bundles LINE text, rich, and media reply parts onto one reply-token batch when possible, attaches quick replies to the final delivered message, and expands regression coverage for batching and failure behavior.
