## Summary

Keep open: the batching direction is sound and the live evidence is strong, but the new error handling can classify a total delivery failure as visible partial success, which is a blocking message-delivery defect.

## What This Changes

The PR changes LINE auto-reply delivery to batch text, rich, and media messages onto the reply token when possible and attach quick replies to the final delivered message.

## Best Possible Solution

Keep the unified LINE batch assembly, but propagate total first-batch failures normally and apply visible-send evidence only after at least one reply or push batch has actually succeeded.
