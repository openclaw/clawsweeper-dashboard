## What This Changes

This PR records a durable schedule edit on the active cron run and prevents the older run’s completion from deleting, disabling, retrying, advancing, or disarming the replacement one-shot schedule.

## System Context

Cron jobs are persisted scheduler records that can run agent or command payloads. A job update writes the replacement schedule, while later completion handling updates outcome metadata and normally advances, retries, disables, or deletes one-shot schedules.
