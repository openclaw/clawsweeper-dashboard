## Summary

Keep this PR open for normal maintainer review. The latest head replaces the earlier process-local cache approach with an explicit lightweight SQL-side session-list projection, carries that projection through gateway, TUI, and embedded-tool list paths, preserves full reads by default, and includes production-derived before/after proof; no discrete patch defect is established from the available evidence. The remaining decision is whether the projection’s session-metadata contract and gateway-wide compatibility risk are acceptable before merge.

## What This Changes

This PR makes SQLite-backed gateway session lists request a lightweight entry projection that omits large prompt snapshots while leaving full session-entry reads as the default.

## System Context

OpenClaw’s gateway, embedded tool, and TUI list persisted session metadata to drive session browsing and sharing decisions. The changed accessor projection reduces the data parsed and retained for those list-oriented consumers while full entry reads continue to serve paths that need prompt snapshots.
