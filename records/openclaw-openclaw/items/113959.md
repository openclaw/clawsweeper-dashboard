## What This Changes

This PR adds a process-local cache for SQLite session listings, detects local and foreign changes before reuse, invalidates on mutations, and supports lightweight paginated results to keep large session stores from stalling the gateway.

## System Context

Gateway session APIs read conversation metadata from each agent’s SQLite session database for operator views, session routing, and agent lifecycle work. This change places a cache between those readers and the full row parser, so it affects both gateway responsiveness and how quickly session mutations become visible.
