## Summary

Keep this PR open. The bounded-drain direction addresses the blocking path, but the implementation does not actually enforce its advertised 64 KiB limit for an oversized single stream chunk, and merge still needs contributor-supplied live Urbit authentication proof plus maintainer acceptance of the intentional compatibility cutoff.

## What This Changes

The PR replaces unbounded successful Tlon/Urbit login-body consumption with a 64 KiB, 250 ms best-effort drain and adds stream tests for oversized, stalled, and slow-trickling responses.

## Best Possible Solution

Make the drain contract honest and bounded for arbitrary chunks, add focused coverage for a single oversized chunk, and attach redacted evidence from a real Urbit login showing the expected cookie path still succeeds within the chosen cutoff.

## Solution Assessment
