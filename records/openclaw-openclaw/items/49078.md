## Summary

Keep open. Current main and the latest release still define cron completion delivery as `none`, `announce`, or `webhook`; the requested file/channel/session/silent multi-target output contract remains missing and needs maintainer product and security design.

## What This Changes

Request to add deterministic cron job output targets for files, channels, sessions, silent discard, and fallback handling instead of relying on prompt-directed routing.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract covering schema/protocol, safe workspace file writes, channel fan-out, session delivery, silent/discard behavior, fallback/status semantics, docs, and focused tests.
