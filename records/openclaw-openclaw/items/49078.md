## Summary

Keep open. Current main and v2026.6.11 still only expose cron completion delivery as `none`, `announce`, or `webhook`; the requested file/channel/session/silent output-target contract remains a product and security design item.

## What This Changes

The issue requests a first-class cron output field that can deterministically route job results to files, channels, sessions, or silent discard.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract covering schema/protocol, safe workspace file writes, channel fan-out, session delivery, silent/discard behavior, fallback/status semantics, docs, and focused tests.
