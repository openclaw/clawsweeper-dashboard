## Summary

Keep open. Current main and the latest release still expose cron completion delivery as `none`, `announce`, or `webhook`; the merged target-awareness work helps delivered channel context, but the requested deterministic file/channel/session output-target contract is still missing and needs maintainer API/security direction.

## What This Changes

Request adds first-class cron output configuration for deterministic file, channel, session, and silent routing of finished job output.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract covering schema/protocol, safe file writes, channel fan-out, internal session delivery, fallback/status semantics, docs, and focused tests before implementation.
