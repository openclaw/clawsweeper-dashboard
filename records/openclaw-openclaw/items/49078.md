## Summary

Keep open. Current main and the latest release still expose cron completion delivery as `none`, `announce`, or `webhook`; the requested deterministic file/channel/session output-target contract remains missing and needs maintainer product and security decisions before implementation.

## What This Changes

Add a deterministic cron job output target contract so completed job results can be routed to file, channel, or session destinations without relying on prompt instructions.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract spanning schema/protocol, safe file targets, channel/session routing, fallback/status semantics, docs, and tests, then implement it behind the chosen cron config/API surface.
