## Summary

Keep open. Current main and v2026.6.11 still expose cron completion delivery as `none`, `announce`, or `webhook`; the requested file/channel/session/silent output-target contract remains a product and security design item rather than a cleanup close.

## What This Changes

Add deterministic cron output targets so scheduled job results can be routed to files, channels, sessions, or discarded without relying on prompt compliance.

## Best Possible Solution

Define one maintainer-approved cron output-routing contract covering schema/protocol, safe file writes, channel fan-out, session delivery, silent/discard behavior, fallback/status semantics, docs, and focused regression proof.
