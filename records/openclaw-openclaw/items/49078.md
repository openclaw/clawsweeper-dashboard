## Summary

Keep open. Current main and v2026.6.11 still expose cron completion delivery as `none`, `announce`, or `webhook`; no merged related item has added the requested deterministic file/channel/session output-target contract.

## What This Changes

The issue requests deterministic cron output routing targets for files, channels, and sessions so job results are not solely dependent on prompt-following.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract that covers schema/protocol, safe file writes, channel fan-out, internal session delivery, fallback/status semantics, docs, UI/CLI behavior, and focused tests before implementation.
