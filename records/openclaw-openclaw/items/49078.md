## Summary

Keep open because current main and v2026.6.11 still only support cron delivery as chat announce, webhook, or none; the requested file/channel/session/silent output target contract remains a product and security design item.

## What This Changes

The issue requests deterministic cron output routing to configured file, channel, session, or silent targets instead of relying on prompt instructions.

## Best Possible Solution

Define one maintainer-approved cron output-routing contract covering schema/protocol, safe file writes, channel fan-out, session delivery, silent/discard behavior, fallback/status semantics, docs, and focused regression proof.
