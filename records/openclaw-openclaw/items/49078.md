## Summary

Keep open. Current main and the latest v2026.6.11 release still expose cron completion output as one primary `delivery` mode plus limited webhook/failure destinations, while this issue asks for a new first-class, multi-target output contract covering file writes, channel delivery, session injection, silent discard, and fallback/status policy.

## What This Changes

The issue requests a cron job `output.targets` schema so scheduled run results can be routed deterministically to files, channels, sessions, or discarded without relying on prompt instructions.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract covering schema/protocol, safe workspace file writes, channel fan-out, session delivery, fallback/status semantics, docs, and focused tests.
