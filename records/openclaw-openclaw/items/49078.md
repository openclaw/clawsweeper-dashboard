## Summary

Keep open. Current main and the latest release still expose cron completion delivery as `none`, `announce`, or `webhook`; the related merged work improves target-session awareness after existing delivery but does not add the requested deterministic file/channel/session output-target contract.

## What This Changes

The issue requests a first-class cron output target contract so cron job results can be routed to files, channels, and sessions independently of prompt compliance.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract that covers schema/protocol, safe file writes, channel fan-out, internal session delivery, fallback/status semantics, docs, and focused tests before implementation.
