## Summary

Keep open: current main and v2026.6.11 still only support cron delivery as none, announce, or webhook, while the requested deterministic file/channel/session output-target contract remains a product and security design item.

## What This Changes

Add deterministic cron output targets for files, channels, sessions, and silent/discard behavior so job results do not rely on prompt-directed routing.

## Best Possible Solution

Design one maintainer-approved cron output-routing contract covering schema/protocol, safe file writes, channel/session authorization, fallback/status semantics, docs, UI/CLI, and tests before implementation.
