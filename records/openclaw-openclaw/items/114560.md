## What This Changes

Keeps OpenClaw’s core file and shell tools directly available when tool-search compaction is enabled, while leaving non-core catalog tools deferred.

## System Context

Agent tool search reduces prompt size by placing a large tool inventory in a catalog and exposing only selected tools directly. This change adjusts the visibility decision for built-in coding primitives before the agent receives its executable tool list.
