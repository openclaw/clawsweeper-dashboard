## What This Changes

This PR persists machine receipts for detached native Codex workers, renews relay-health binding across parent turns, and blocks successful completion when required liveness or artifact evidence is stale or missing.

## System Context

The bundled Codex plugin mirrors native app-server child-thread notifications into OpenClaw’s detached task runtime. The runtime persists task state and receipts, evaluates liveness gates, and emits a final task completion back to the originating session or channel.
