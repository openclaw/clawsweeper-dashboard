## Summary

Keep open for maintainer review: the patch has sufficient proof and no blocking code finding, but it deliberately changes ambiguous no-adapter outbound rows from terminal failure to pending/backoff, which needs explicit message-delivery policy acceptance before merge.

## What This Changes

The branch changes outbound delivery queue recovery so ambiguous `send_attempt_started` and `unknown_after_send` rows without available reconciliation are deferred in pending/backoff state, with related storage, recovery, reconnect-drain tests, and Discord troubleshooting docs updated.

## Best Possible Solution

Merge only after maintainers accept the pending/backoff policy for no-adapter ambiguous delivery rows, and keep https://github.com/openclaw/openclaw/issues/87544 open for the broader ledger, reconciliation, and UI/API design.
