## Summary

This PR addresses a real parent/child stale-state gap, but two P1 lifecycle-boundary defects block merge: rejected ACP turns can be logged as child state changes, and durable parent notices can be acknowledged before any model turn receives them. The persistent core contract also needs owner approval and inspectable upgrade/runtime proof after those defects are fixed.

## What This Changes

The PR adds three shared-state tables for typed session events and parent watcher cursors, records six event kinds across embedded and ACP lifecycles, proactively notifies parents, and exposes `stateVersion` and `changesSince` through session tools.

## Best Possible Solution

Move ACP event creation to confirmed runtime prompt acceptance and move notice acknowledgement to actual model-turn commitment, preserving pending notices on every pre-turn exit; then obtain owner approval for the durable core contract with inspectable upgrade, restart, success, and failure-path proof.
