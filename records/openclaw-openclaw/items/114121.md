## What This Changes

The PR changes gateway restart recovery so an assistant transcript tail marked `aborted` can resume regardless of its recorded abort-message text, while `error` tails still require an allowlisted restart-abort message.

## System Context

When a gateway restarts, main-session recovery examines a persisted interrupted transcript and either resumes the agent or posts a resend notice. The changed classifier determines that branch, while downstream logic restricts unresolved tool calls before continuation.
