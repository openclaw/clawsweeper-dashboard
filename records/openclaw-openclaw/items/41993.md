## Summary

Keep open: current main and the latest release still reject mixed DNS result sets as soon as any resolved address is blocked, while the direct fix PRs for this report are closed unmerged. The remaining choice is a maintainer-owned SSRF security-boundary decision.

## What This Changes

The issue requests that `web_fetch` allow a DNS result set with at least one safe public address while filtering out IPv6 special-use addresses before pinned dispatch.

## Best Possible Solution

A maintainer-approved fix should filter resolved DNS answers to allowed candidates, fail closed when none remain, keep all-blocked private/special-use protections, and add mixed-answer plus all-blocked regression coverage.
