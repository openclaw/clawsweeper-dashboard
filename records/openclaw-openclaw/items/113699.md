## What This Changes

This PR propagates an embedded agent’s non-deliverable terminal outcome into fallback settlement and queued follow-up delivery so `message_tool_only` runs emit one specific failure reply instead of finishing without a user-visible result.

## System Context

Embedded agent execution returns payloads plus terminal metadata to OpenClaw’s auto-reply layer. The follow-up runner settles terminal lifecycle state, chooses whether source-reply suppression applies, and dispatches any required user-visible fallback reply.
