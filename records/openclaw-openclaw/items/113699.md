## What This Changes

The PR propagates an embedded agent’s non-deliverable terminal state into fallback and queued reply delivery so `message_tool_only` runs emit one specific terminal failure response rather than finishing silently.

## System Context

Embedded agent execution produces terminal metadata and reply payloads; the auto-reply fallback and follow-up runner settle that result and decide whether a channel-visible reply should be dispatched. This change carries a terminal non-delivery signal through that pipeline while retaining normal `message_tool_only` suppression for successful turns.
