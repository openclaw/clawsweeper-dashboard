## Summary

Keep this PR open for maintainer review. The non-deliverable-reply repair is a focused bug fix, but the same branch changes `truncateAfterCompaction` from an established opt-in behavior to an opt-out default without product approval, documentation alignment, or upgrade proof; that can change existing session behavior immediately after upgrade.

## What This Changes

This PR rotates successor transcripts by default after compaction and carries a non-deliverable terminal-run signal through fallback settlement so affected conversations receive a specific failure reply.

## System Context

Long-lived embedded agent runs compact their transcripts to stay within context limits, then return run metadata to the auto-reply pipeline. The follow-up runner settles fallback outcomes and decides whether a reply is delivered to the originating channel.
