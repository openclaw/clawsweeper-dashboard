## What This Changes

The branch propagates a terminal non-delivery outcome from embedded agent execution into fallback and queued follow-up delivery so a silent failed turn emits one specific user-visible error reply, while retaining the existing opt-in compaction setting.

## System Context

Embedded agent attempts produce terminal metadata that auto-reply fallback settlement and queued follow-up delivery use to decide whether a turn completed and whether a reply should be emitted. This change adds a non-delivery signal to that handoff so message-tool-only mode does not suppress the only terminal failure reply.
