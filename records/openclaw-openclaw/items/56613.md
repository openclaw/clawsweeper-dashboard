Request Talk/Voice mode agent or session switching in companion apps plus per-agent TTS voice configuration for multi-agent voice conversations.

## Best Possible Solution

Keep this issue as the canonical Talk/Voice session-selection request, reuse existing gateway agent/session state for the selector, and keep voice identity on the already-canonical `agents.list[].tts` path instead of adding `talk.voiceId`.

## Solution Assessment

Unclear until maintainers choose the UX and platform scope. The maintainable direction is a focused Talk/Voice selector using existing gateway-agent/session data, with TTS voice identity staying on `agents.list[].tts` rather than adding a new `talk.voiceId` shape.
