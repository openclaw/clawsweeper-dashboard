## Summary

Keep open: current main and v2026.6.11 implement the per-agent TTS half through `agents.list[].tts`, but Android Voice/Talk still has no user-facing agent/session picker and Talk routing still follows the runtime main session key. ## What This Changes

Request Voice/Talk mode agent/session switching on companion apps and per-agent TTS voice identity for multi-agent setups.

## Best Possible Solution

Keep this issue as the canonical Talk/Voice session-selection tracker, reuse existing gateway agent/session state for the selector, and keep voice identity on the canonical `agents.list[].tts` config path.
