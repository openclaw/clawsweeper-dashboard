## Summary

Keep open: current main and v2026.6.11 already implement the per-agent TTS half through `agents.list[].tts`, but the remaining Talk/Voice agent or session picker is still missing from Android Voice and Talk routing still uses the resolved main session key. The related Android Chat selector PR only partially overlaps because it changes Chat, not Voice/Talk.

## What This Changes

Request Android, iOS, and macOS Talk/Voice surfaces to support agent or session switching and per-agent TTS voice identity for multi-agent setups.

## Best Possible Solution

Add a Talk/Voice agent or session selector that reuses existing gateway agent/session metadata and active session routing, while keeping `agents.list[].tts` as the canonical per-agent voice configuration.
