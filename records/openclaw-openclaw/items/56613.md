## Summary

Keep open: current main and v2026.6.11 implement the per-agent TTS half through `agents.list[].tts`, but the Android Talk/Voice path still has no agent/session selector and continues routing Talk turns through the gateway/default main session key. ## What This Changes

Request Talk/Voice agent/session selection across companion apps plus per-agent TTS voice identity for multi-agent setups.

## Best Possible Solution

Keep this as the canonical Talk/Voice session-selection request, reuse existing gateway agent/session state for the selector, and keep voice identity on the already-canonical `agents.list[].tts` config path.
