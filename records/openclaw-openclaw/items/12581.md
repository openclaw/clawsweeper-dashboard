  - body: `triggerInternalHook()` awaits each handler sequentially with no timeout, and this call now runs inside context pruning before model calls. A slow or stuck installed hook can hang prompt assembly, so delivery needs to be non-blocking or time-bounded before merge.
  - confidence: 0.9

  - body: `toolName` values can originate from transcript/tool-call data and are forwarded to hook consumers without a bounded contract. Counts-only metadata, sanitization, length caps, or an explicit opt-in is needed before exposing these strings to logs, telemetry, or indexers.
  - confidence: 0.86

  - body: The docs add the event name but not the fields consumers can rely on, the timing semantics, or the trust boundary for metadata. A new hook surface should document `softTrimmedCount`, `hardClearedCount`, session identity, timestamp behavior, and whether tool names are sanitized.
