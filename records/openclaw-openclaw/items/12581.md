  - body: `emitPruneHook` awaits `triggerInternalHook`, and the current internal hook runner awaits each handler sequentially with no timeout.   - confidence: 0.94

  - body: The new payload forwards raw `toolName` values from pruned transcript messages to hook handlers. Tool metadata can be user/model-influenced and may be logged or exported by handlers, so the hook contract should sanitize, bound, or omit these names by default before exposing them as lifecycle metadata.
