  - body: The new `toolNames` payload forwards tool-result names to internal hook handlers without a documented sanitization, length, or trust contract.   - confidence: 0.86

  - body: The docs add `session:prune` but omit the context fields and trust guidance, so hook consumers cannot know whether `softTrimmedCount`, `hardClearedCount`, `toolNames`, `sessionId`, and `prunedAt` are available or safe to log. The docs should match the final approved payload.
