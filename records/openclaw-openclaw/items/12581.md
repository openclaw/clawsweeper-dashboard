  - confidence: 0.93

  - body: This adds raw `ToolResultMessage.toolName` values to internal hook context. Tool names can be replayed or synthesized from assistant tool-call names, so exposing them to hook handlers needs a normalized, capped, and documented contract, or counts-only metadata, before merge.
  - confidence: 0.9
