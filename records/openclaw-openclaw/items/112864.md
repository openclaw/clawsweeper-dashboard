## What This Changes

The issue requests that rapid `openclaw config set` updates cannot destabilize hot reload or leave a containerized gateway restart waiting indefinitely.

## System Context

`openclaw config set` persists the canonical configuration, then the Gateway observes the resulting file change and either applies it live or coordinates a restart. The reload and lifecycle paths affect whether a running Gateway retains its last valid state and whether its supervisor can return it to service.
