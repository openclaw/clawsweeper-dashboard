## What This Changes

Adds a default Doctor lint warning when a positive compaction transcript-byte limit is configured without the required transcript-rotation setting, plus coverage for active, inactive, and zero-value configurations.

## System Context

OpenClaw's compaction settings govern when a long session is summarized and whether its active transcript is rotated to a smaller successor. Doctor reads the effective configuration before runtime and reports unsafe or ineffective settings to operators and automation.
