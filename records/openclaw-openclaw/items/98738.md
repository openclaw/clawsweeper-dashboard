## What This Changes

The PR marks closed bundled MCP sessions disconnected, fails tool/resource/prompt calls with an attributable server-specific error, retires dead sessions during catalog refresh, and adds regression tests plus a lint-suppression allowlist entry.

## Best Possible Solution

Merge the session-owner close-lifecycle fix after ordinary maintainer and current-head CI review, keeping automatic reconnect/self-heal behavior as a separate MCP product decision.

## Solution Assessment
