## Summary

Keep this PR open: it removes public plugin SDK paths still imported by separately published plugins, and its new CLI metadata capture can execute canonical plugin registration with an incomplete runtime stub. Both are user-visible compatibility failures, not cleanup-only churn.

## What This Changes

The PR demotes five retained public plugin SDK subpaths, replaces `defineToolPlugin` authoring with `definePluginEntry` plus `api.registerTool`, and updates CLI metadata capture, package exports, docs, tests, and compatibility budgets.

## Best Possible Solution

Retain the five public exports until every known external consumer has migrated and released against capability-complete replacements, then remove them after a documented shipped compatibility window; redesign authoring metadata capture so it does not require runtime-backed registration to succeed under a stub context.
