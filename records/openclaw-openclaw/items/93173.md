Issue requests richer Skill Workshop lifecycle approval details plus a longer or configurable approval timeout for Skill Workshop apply approvals.

## Best Possible Solution

Define a bounded Skill Workshop approval-detail contract for proposal id, target skill, short description, safe preview, and inspect action, then choose one maintainer-approved timeout policy that preserves pending approval safety.
