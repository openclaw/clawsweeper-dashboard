## What This Changes

Add a recovery path for forward SQLite state-schema upgrades by preserving a pre-migration copy that can be restored if an operator must downgrade.

## System Context

OpenClaw’s shared state database is opened by gateway startup and Doctor repair paths, which may advance its SQLite schema before normal runtime use. The migration result determines whether an older OpenClaw build can subsequently open the same persisted state.
