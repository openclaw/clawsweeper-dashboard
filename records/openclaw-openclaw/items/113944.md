## What This Changes

This PR changes gateway branch-diff resolution to recognize already-merged PR heads and updates the Control UI chat stream to refresh PR chips when a PR link first appears mid-turn.

## System Context

Control UI chat renders pull-request chips and a possible Create PR row for the active workspace branch. The gateway combines local Git ancestry with GitHub pull-request state, and streamed chat events can request a refresh so the UI reflects newly created or merged PRs before the turn ends.
