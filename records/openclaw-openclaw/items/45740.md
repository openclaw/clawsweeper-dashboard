## Summary

Keep open: current main and v2026.6.11 still leave the gh-issues automation dependent on GitHub issue bodies and review comments reaching spawned worker tasks, while the runtime content-boundary and per-spawn least-privilege pieces are still only partial or unmerged.

Keep this as the canonical gh-issues hardening tracker; land or replace runtime content-boundary work and the per-spawn child capability API, then update gh-issues to use them with regression proof.
