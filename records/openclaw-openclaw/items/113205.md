## What This Changes

This PR replaces separate complete-response and streaming reasoning-tag sanitizers with a shared Markdown-aware parser so malformed tags and code delimiters do not hide visible assistant text or expose hidden reasoning.

## System Context

Model output reaches users through two paths: complete responses are sanitized before display, while stream chunks are partitioned into visible and hidden reasoning segments. The new Markdown Core parser supplies common tag and code-span ownership rules to both paths before channels render assistant text.
