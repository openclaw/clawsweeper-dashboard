## What This Changes

The PR makes self-closing reasoning markers depth-neutral in the static assistant-text sanitizer and streaming text partitioner, preserving visible text that follows markers such as `<thinking/>`.

## System Context

OpenClaw filters model reasoning markup before rendering assistant output. Complete responses use the shared-text sanitizer, while streamed responses pass through a partitioner that separates visible text from hidden reasoning before channel delivery.
