## What This Changes

This PR makes self-closing reasoning markers depth-neutral in complete-response sanitization and streamed-text partitioning so visible assistant text after markers such as `<thinking/>` is retained.

## System Context

OpenClaw removes or separates model reasoning markup before assistant content reaches users. Complete responses go through visible-text sanitization, while streamed chunks go through a partitioner that emits visible text and hidden reasoning on separate lanes for later delivery.
