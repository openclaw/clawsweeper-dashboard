## Summary

Keep open: this is a focused, still-useful Tlon shutdown bug fix. The branch replaces both uncancellable reconnect timers with terminal-close-owned cancellation, covers the ordinary and max-attempt paths, and has no concrete correctness or security blocker.

## What This Changes

Makes both Tlon SSE reconnect delays abortable by `close()` and adds production-path and focused regression coverage for reconnect cancellation.

## Best Possible Solution

Keep terminal shutdown as the single owner of all reconnect-delay cancellation, while preserving normal reconnect behavior and focused coverage for both retry branches.
