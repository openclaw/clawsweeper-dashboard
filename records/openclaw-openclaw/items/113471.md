## What This Changes

This PR makes embedding-provider replacement wait for the old provider and any local llama.cpp worker to finish shutting down before fallback, retry, gateway, or CLI code creates another provider.

## System Context

Memory Core uses embedding providers to index and search local agent data, while gateway and CLI endpoints can create short-lived embedding providers for requests. This PR changes the lifecycle boundary between provider use, provider retirement, and local child-worker termination so later embedding work does not overlap a retiring worker.
