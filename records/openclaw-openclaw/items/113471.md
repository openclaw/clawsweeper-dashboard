## What This Changes

The PR serializes retirement and replacement of Memory Core embedding providers so local worker processes are closed before fallback or retry initialization proceeds.

## System Context

Memory Core selects an embedding provider for indexing and search, including local providers that may run child worker processes. When a provider degrades or is retried, the manager retires the old provider before initializing a fallback or replacement so subsequent embedding requests use a live runtime.
