## What This Changes

This PR serializes Memory Core embedding-provider retirement before replacement or fallback initialization and makes local embedding-worker shutdown wait for the child process to exit.

## System Context

Memory Core creates embedding providers for indexing and semantic search. When a local provider fails, degrades, retries, or falls back, the manager retires its provider and worker before allowing the next provider to serve embedding requests.

## Architecture Diagram

flowchart LR
  A[Memory index or search] --> B[Embedding provider manager]
  B --> C{Provider transition}
  C --> D[Retire current provider]
  D --> E[Local embedding worker exits]
  E --> F[Initialize primary or fallback]
  F --> G[Embedding requests resume]
