## What This Changes

The PR serializes Memory Core embedding-provider retirement before replacements, retries, fallbacks, and shutdown, and makes local embedding-worker closure wait for confirmed child-process termination.

## System Context

Memory Core creates embedding providers for indexing and semantic search, including a local child-process worker for llama.cpp embeddings. Searches, syncs, gateway embedding requests, and CLI capability checks use those providers, so replacement and shutdown must retire the old provider without interrupting active work or leaving a worker process behind.

  Use --> Idle[Operation becomes idle]
  Retire --> Worker[Local embedding worker]
  Worker --> Exit[Confirmed process exit]
  Exit --> Next[Primary or fallback provider]
  Next --> Output[Embedding result or availability error]
