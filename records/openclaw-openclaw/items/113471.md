## What This Changes

This PR serializes embedding-provider retirement across Memory Core, local embedding workers, CLI requests, and Gateway requests so a replacement provider does not run before the previous worker has actually exited.

## System Context

Memory Core selects embedding providers for semantic indexing and search; local providers can own child worker processes. CLI and Gateway consumers also create providers, so their request and shutdown lifecycles must release workers without racing a replacement or in-flight embedding work.
