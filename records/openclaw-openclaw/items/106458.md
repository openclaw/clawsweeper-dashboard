## What This Changes

Adds an `inbound_debounce` plugin hook and WhatsApp integration so an admitted inbound message can bypass or use a bounded, policy-selected debounce window.

## System Context

Inbound channel messages pass WhatsApp admission and debounce handling before they become agent turns. This PR adds a plugin decision point in that path, affecting batch timing, message ordering, media context, and graceful close draining.
