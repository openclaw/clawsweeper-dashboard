## What This Changes

Adds an `inbound_debounce` plugin hook so the WhatsApp channel can let plugins bypass or set bounded per-message inbound batching windows while preserving ordered drain and rich-message context.

## System Context

Inbound channel messages enter a channel-owned debounce buffer before agent routing. This PR inserts an optional plugin policy decision after WhatsApp admission; the decision determines whether a message joins a keyed batch or dispatches immediately, then the resulting batch is delivered to the agent loop.
