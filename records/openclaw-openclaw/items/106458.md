## What This Changes

This PR adds an `inbound_debounce` plugin hook so the WhatsApp channel can choose whether each admitted inbound message bypasses or enters a bounded debounce batch.

## System Context

Inbound channel messages pass admission and channel-specific policy before OpenClaw buffers or dispatches them to an agent. This PR puts a new plugin decision point between WhatsApp admission and the shared keyed debounce queue, affecting delivery timing, batching, and graceful shutdown draining.
