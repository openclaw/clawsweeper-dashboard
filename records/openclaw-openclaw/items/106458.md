## What This Changes

Adds a typed `inbound_debounce` plugin hook so the WhatsApp channel can let installed plugins choose whether an admitted inbound message bypasses, joins, or shortens a bounded debounce batch.

## System Context

Inbound WhatsApp messages are admitted and checked for control commands before a keyed debouncer either batches them or forwards them to agent dispatch. This PR inserts a plugin-policy decision at that ingress boundary while preserving channel-owned keys, ordering, and message delivery.
