## What This Changes

The branch adds an `inbound_debounce` plugin hook and uses it in WhatsApp inbound handling so plugins can bypass or set bounded per-message batching windows while close-drain waits for pending policy decisions.

## System Context

WhatsApp receives inbound messages, admits them under channel policy, optionally batches them by a channel-owned key, and then sends the combined input to agent dispatch. The proposed hook runs after admission and before the keyed debounce buffer so a plugin can influence that batching decision.
