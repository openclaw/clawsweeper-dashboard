## What This Changes

This PR adds an `inbound_debounce` plugin SDK hook so the WhatsApp channel can let installed plugins bypass, join, or shorten admitted inbound-message debounce batches, including bounded media batching and close draining.

## System Context

WhatsApp inbound messages are admitted and classified before a keyed core debouncer combines them for agent dispatch. This PR inserts plugin policy evaluation between WhatsApp admission and buffering, then publishes the resulting decision type through the plugin SDK.
