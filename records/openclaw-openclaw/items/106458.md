## What This Changes

This PR adds an `inbound_debounce` plugin hook, lets the shared inbound debouncer honor asynchronous per-message decisions, and wires WhatsApp to use that hook for admitted inbound messages and graceful close draining.

## System Context

WhatsApp admits an inbound message, derives its channel-owned debounce key and default policy, then sends it through the shared keyed debouncer before agent dispatch. This change inserts an optional plugin decision between admission and buffering, affecting when messages are grouped, bypassed, or flushed during shutdown.
