## Summary

The earlier P1 findings are resolved and the live TLS proof is convincing; keep this PR open for explicit owner approval because the new hard limits can reject previously accepted gateway TLS files during startup.

## What This Changes

The PR routes gateway certificate, key, and CA loading through the bounded secret-file reader with 64 KiB cert/key limits, a 256 KiB CA limit, and focused regression tests.

## Best Possible Solution

Use the shared pinned reader, but land the limits only after a gateway TLS owner explicitly accepts the thresholds as the permanent upgrade contract and ensures the operator-facing configuration guidance states the accepted sizes.
