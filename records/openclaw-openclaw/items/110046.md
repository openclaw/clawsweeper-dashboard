## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.97

Full review comments:

- **[P1] Use a bounded file reader instead of stat-then-read:** `src/infra/tls/gateway.ts:131`
  - body: The size check and read are separate pathname operations, so a path or symlink can be replaced after `statSync`, and a FIFO or device-like input reports no useful bounded size before `readFile`. That defeats the hardening this PR claims to provide. Load the bytes through OpenClaw's shared fs-safe bounded regular or pinned reader and add coverage for non-regular or swapped inputs.
  - confidence: 0.98
- **[P1] Preserve valid CA bundles when adding size limits:** `src/infra/tls/gateway.ts:14`
  - body: `gateway.tls.caPath` is a documented CA-bundle input that previously had no size contract, but this line subjects it to the same 256 KiB limit as a leaf certificate and key. Existing enterprise or combined trust bundles can therefore make TLS fail after upgrade. Use a separately justified CA limit or otherwise preserve the existing contract, with upgrade coverage and documentation.
  - confidence: 0.93
