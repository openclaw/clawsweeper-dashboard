## Summary

Keep this PR open: the deadline addresses a valid Gateway startup hang, but the patch can convert a timed-out generation into a persistent cert/key-missing startup failure, and the contributor has supplied mock-based tests rather than required real behavior proof.

## What This Changes

The PR adds a 30-second timeout to Gateway self-signed certificate generation and regression coverage for the bounded invocation and existing error result.

## Best Possible Solution

Generate the key and certificate transactionally through temporary files and atomic renames, or reliably remove both outputs on failure, then prove with a real stalled-OpenSSL run that timeout leaves no orphan process or partial artifacts and that the next Gateway start succeeds.
