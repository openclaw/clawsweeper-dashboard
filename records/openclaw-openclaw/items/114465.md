## What This Changes

This PR changes the Mantis Telegram Desktop proof harness so fork or worktree candidates build and run in a root-mediated, container-isolated environment with attested inputs and restricted networking.

## System Context

Mantis is OpenClaw’s maintainer-operated proof path for Telegram Desktop behavior: a workflow prepares baseline and candidate revisions, then launches a local OpenClaw system under test and publishes redacted evidence. This PR changes the candidate execution boundary between untrusted PR code, the credentialed proof environment, Docker networking, and the resulting proof artifacts.
