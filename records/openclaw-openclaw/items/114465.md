## What This Changes

Updates the Mantis Telegram Desktop proof workflow so its restricted candidate-build user can traverse the GitHub runner worktree and uses run-scoped `/tmp` directories for that user's HOME and Corepack state.

## System Context

The Mantis Telegram Desktop proof workflow prepares trusted baseline and candidate worktrees, then builds the candidate as a restricted system user before leasing credentials and exercising Telegram behavior. This change affects the filesystem-access boundary that lets the restricted build reach its candidate checkout while attempting to leave trusted inputs non-writable.
