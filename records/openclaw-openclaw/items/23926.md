## Summary

Keep open: current main covers the blocking pre-install side through operator `security.installPolicy` and plugin `before_install`, but it still lacks the requested plugin-visible post-install/update observer and remains a security-sensitive API decision.

## What This Changes

The issue requests blocking skill pre-install and observational skill post-install hook events so scanners and audit plugins can protect ClawHub and UI skill installs.

## Best Possible Solution

Keep `security.installPolicy` and `before_install` as the blocking path, then design a minimal redacted non-blocking skill install/update completion observer for OpenClaw-managed CLI, Gateway, and UI install paths.
