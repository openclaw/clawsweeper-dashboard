## Summary

Keep open: current main now covers the blocking pre-copy install-policy side for skill installs, including ClawHub and UI-backed flows, but the requested plugin-visible post-install/update observer with audit/outcome metadata is still missing and security-sensitive.

## What This Changes

The issue requests blocking and observational skill install lifecycle hooks so plugins and security tools can scan, warn, block, and audit skill installs.

## Best Possible Solution

Keep the existing `security.installPolicy` and `before_install` blocking path, then add a documented plugin-visible skill install/update completion observer only after maintainers choose the redacted payload and failure semantics.
