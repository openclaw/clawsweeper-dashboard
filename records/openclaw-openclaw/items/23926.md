## Summary

Keep open: current main covers the blocking pre-install side through `security.installPolicy` and plugin `before_install`, but the requested plugin-visible post-install/update observer is still missing and needs maintainer security/product direction.

## What This Changes

The issue requests blocking pre-install and observational post-install skill lifecycle hook events for ClawHub/UI skill installation security and audit integrations.

## Best Possible Solution

Keep `security.installPolicy` and `before_install` as the blocking path, then define or explicitly reject a minimal redacted, non-blocking skill install/update completion observer for OpenClaw-managed flows.
