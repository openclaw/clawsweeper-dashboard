## Summary

Keep open: current main covers the blocking pre-install side through `security.installPolicy` and plugin `before_install`, but the requested post-install/update audit observer is still missing and needs maintainer security/product direction.

## What This Changes

Request to add blocking skill pre-install and observational post-install hook events so plugins or scanners can vet and audit skill installs.

## Best Possible Solution

Keep the existing blocking `security.installPolicy` and `before_install` seams, then design a minimal redacted non-blocking skill install/update completion observer with explicit ordering, failure semantics, docs, and coverage for OpenClaw-managed ClawHub, upload, git/local, Gateway, UI, and update paths.

## Solution Assessment
