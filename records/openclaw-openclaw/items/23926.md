## Summary

Keep open: current main covers the blocking pre-install side through `security.installPolicy` and `before_install`, but it still lacks the requested plugin-visible post-install/update observer and audit/outcome contract.

## What This Changes

Request to add skill install lifecycle hook events that can block before install and observe or audit after install across ClawHub, UI, and CLI skill flows.

## Best Possible Solution

Keep `security.installPolicy` and `before_install` as the blocking path, then design a minimal redacted non-blocking skill install/update completion observer for OpenClaw-managed CLI, Gateway, and UI flows.

- **Defer To ClawHub Trust Design:** Hold the observer until maintainers define a broader ClawHub trust/provenance API that can supply the same audit events.

## Solution Assessment
