## Summary

Keep open: current main now covers much of the blocking install-policy side through `security.installPolicy` and plugin `before_install`, but the requested plugin-visible post-install/update observer is still missing and needs maintainer security/product direction.

## What This Changes

Request to add blocking pre-install and observational post-install hook events for skill installation.

## Best Possible Solution

Keep `security.installPolicy` and `before_install` as the blocking path, then design a minimal redacted non-blocking skill install/update completion observer with explicit ordering, failure semantics, docs, and coverage for OpenClaw-managed install, update, Gateway, UI, and CLI paths.
