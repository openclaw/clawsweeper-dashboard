## Summary

Keep open: current main and v2026.6.11 cover the blocking install-policy side through `security.installPolicy` and `before_install`, but they still lack the requested plugin-visible post-install/update observer, and that remaining lifecycle API is security-sensitive.

## What This Changes

The issue requests blocking pre-install and observational post-install skill lifecycle hook events for skill installation security and audit integrations.

## Best Possible Solution

Keep `security.installPolicy` and `before_install` as the blocking path, then either add a minimal redacted non-blocking skill install/update completion observer for OpenClaw-managed install paths or explicitly reject that observer as out of scope.
