## Summary

Keep open: current main covers the blocking pre-install policy side with operator install policy and plugin `before_install`, but the issue's remaining post-install/update audit observer is still missing and is security-sensitive public plugin contract work that needs maintainer product and security review.

## What This Changes

## Best Possible Solution

Design a minimal redacted, non-blocking plugin-visible skill install/update completion observer that complements `security.installPolicy` and `before_install` without reopening the blocking pre-install path.
