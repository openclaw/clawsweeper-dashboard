## Summary

Keep open: current main covers the blocking pre-install side through `security.installPolicy` and plugin `before_install`, but it still lacks the requested plugin-visible post-install/update observer and remains a security-sensitive API decision.

## What This Changes

Request to add blocking pre-install and observational post-install skill lifecycle hooks for ClawHub/UI skill installation and updates.

## Best Possible Solution

Keep `security.installPolicy` and `before_install` as the blocking path, then design a minimal redacted non-blocking skill install/update completion observer for OpenClaw-managed CLI, Gateway, and UI install paths.

- **Defer To ClawHub Trust Design:** Hold the observer until maintainers define a broader ClawHub trust/provenance API that can supply the same audit events.
