## What This Changes

This PR moves Codex native-hook relay invocation onto an early, small read-only client path so cold hook processes avoid loading the general OpenClaw CLI and Gateway graph unless the existing Gateway fallback is needed.

## System Context

Codex invokes OpenClaw as a short-lived native-hook command before or after tool activity. That command locates the active relay bridge in OpenClaw state, calls the local relay server, and falls back to the Gateway RPC path when direct delivery cannot be used.
