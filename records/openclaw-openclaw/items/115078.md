## What This Changes

The branch routes Codex native-hook relays through an early lightweight CLI path that reads the bridge locator from SQLite and defers Gateway loading until direct relay fallback is necessary.

## System Context

Codex native hooks invoke OpenClaw as a short-lived relay process before or after tool actions. The relay locates a locally registered bridge in the state database, sends the hook request to the local endpoint, and emits a Codex-compatible response or uses Gateway fallback.
