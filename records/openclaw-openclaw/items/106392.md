Full review comments:

- **[P1] Preserve cron retention before switching history reads:** `src/gateway/server-methods/cron.ts:960`
  - body: `cron.runs` becomes ledger-only in this PR, but cron-specific per-source retention is explicitly deferred to the follow-up. Imported terminal rows therefore enter ordinary task cleanup and older history can vanish from the API even while the legacy rows still exist. Add cron-aware retention before this read flip, or retain the legacy reader until the follow-up lands.
  - confidence: 0.94
- **[P1] Reconcile existing thin cron mirrors during import:** `src/infra/state-migrations.cron-run-logs.ts:52`
  - body: The migration only considers rows with non-null `detail_json` as already mirrored. Every pre-change cron task mirror lacks that column value, so its matching run-log entry is inserted as a second task and both records remain visible to task listings and summaries. Match and upgrade the existing mirror instead of adding another logical execution.
  - confidence: 0.97
- **[P1] Move persistent history import out of database open:** `src/state/openclaw-state-db.ts:1558`
  - body: Calling the full cron-history import from `ensureSchema` makes ordinary startup mutate persistent user history and lets migration failures block the shared state database. Repository policy requires persistent migrations to be doctor-owned and verified before runtime assumes the canonical shape. Move the import to `openclaw doctor --fix` and gate the read flip on successful migration.
  - confidence: 0.9
- **[P2] Recover stale tasks through the migrated run identity:** `src/tasks/task-registry.maintenance.ts:300`
  - body: A stale pre-change task uses `cron:<job>:<startedAt>`, while migration creates its terminal record under `cron-runlog-import:*`. Exact task/run identity matching cannot find that completed execution, so maintenance can mark the original task lost. Match the canonical execution using job, store key, and reservation/start timestamp, then finalize the original row.
  - confidence: 0.95
