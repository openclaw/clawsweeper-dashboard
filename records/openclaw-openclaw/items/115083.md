## What This Changes

The branch makes `openclaw plugins update --all` derive the official-plugin registry channel from the installed core version when `update.channel` is unset, so beta installs keep selecting beta official packages.

## System Context

The plugin-update CLI collects installed plugin records and, for bulk updates, supplies an official-package channel to the plugin updater. That channel determines which registry release line is selected before the updater refreshes official plugin installations.
