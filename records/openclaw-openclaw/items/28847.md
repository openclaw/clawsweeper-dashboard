## Summary

Keep open: current main and v2026.6.11 support flat API-key rotation plus bounded same-provider auth-profile rotation, but they still do not expose native quota-bucket/project metadata or bucket-level cooldown for Gemini-style shared project quotas.

## What This Changes

Request native provider key pools with Gemini project/quota-bucket-aware cooldown and backoff on 429/RESOURCE_EXHAUSTED so retries avoid exhausted buckets without a gateway restart.

## Best Possible Solution

Define one additive generic provider/auth quota-bucket contract that preserves current flat rotation defaults, lets providers or profiles expose shared quota buckets, and documents status, migration, and proof expectations before adding Gemini-specific behavior.
