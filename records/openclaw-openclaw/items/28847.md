## Summary

Keep open: current main supports flat provider API-key rotation, auth-profile cooldowns, and rate-limit profile rotation caps, but it still has no quota-bucket/project grouping contract for Gemini keys that share a quota source.

## What This Changes

Request provider key pools with bucket-aware cooldown/backoff for Gemini project-scoped 429 quota failures to avoid retry storms.

## Best Possible Solution

Define an additive provider/auth quota-bucket contract that preserves flat rotation defaults, lets providers expose shared quota groups, and documents status, migration, and Gemini behavior before implementation.
