## Summary

Keep open: current main and v2026.6.11 support flat API-key rotation and bounded auth-profile cooldown/rotation, but there is still no native quota-bucket/project grouping or bucket-level cooldown contract for Gemini-style project quotas.

## What This Changes

The issue requests native provider key pools with quota-bucket-aware cooldown/backoff so Gemini project-scoped 429s cool down the whole quota bucket and avoid retry storms.

## Best Possible Solution

Define an additive generic provider/auth quota-bucket contract that preserves current flat rotation defaults, lets providers or profiles expose shared quota buckets, and documents status, migration, and recovery behavior before adding Gemini-specific policy.
