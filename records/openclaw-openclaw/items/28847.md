## What This Changes

Request provider key pools with bucket/quota-group-aware cooldown and backoff for Gemini project-scoped 429/RESOURCE_EXHAUSTED failures.

## Best Possible Solution

Keep this issue as the canonical quota-bucket tracker and design an opt-in generic provider/auth bucket identity with bucket-wide cooldowns, preserved single-key defaults, docs, focused regression tests, and any required doctor/config migration.

## Solution Assessment
