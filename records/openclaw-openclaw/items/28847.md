## Summary

Keep open: current main supports flat API-key rotation and bounded same-provider auth-profile rotation, but it still has no native quota-bucket/project grouping or bucket-level cooldown contract for Gemini-style project quotas.

## What This Changes

Request to add provider API-key pools with rate-limit cooldown/backoff and Gemini project/quota-bucket-aware rotation to avoid retry storms.

## Best Possible Solution

Define one additive generic provider/auth quota-bucket contract that preserves current flat rotation defaults, lets providers or profiles expose shared quota buckets, and documents migration/status behavior before adding Gemini-specific policy.
