## Summary

Keep open for maintainer product review: current main covers generic alternate-key retry and capped same-provider auth-profile rotation, but it does not provide quota-bucket/project grouping or an explicit provider-pool routing contract for Gemini-style shared quota groups.

## What This Changes

The issue requests native provider key pools with bucket-aware cooldown/backoff on 429s so Gemini keys sharing a Google project are cooled down together and new requests can switch to a different quota bucket without a gateway restart.

## Best Possible Solution

Define an additive maintainer-approved provider/auth-pool contract that reuses current key rotation and auth-profile cooldown state, preserves existing defaults, and handles Gemini quota buckets only after the config, status, and migration behavior are explicit.
