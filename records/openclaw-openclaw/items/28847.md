## Summary

Keep open: current main and v2026.6.11 support flat provider API-key rotation and bounded auth-profile rotation, but they still do not provide native Gemini project/quota-bucket metadata or bucket-level cooldown behavior.

## What This Changes

Request native provider API-key pools with Gemini project/quota-bucket-aware cooldown and backoff on 429/RESOURCE_EXHAUSTED to avoid retry storms.

## Best Possible Solution

Define one additive generic provider/auth quota-bucket contract that preserves current flat rotation defaults, lets Google/Gemini expose project bucket metadata, and documents persisted/status behavior before adding provider-specific policy.
