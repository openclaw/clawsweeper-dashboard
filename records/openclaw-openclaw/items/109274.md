## What This Changes

Prevent ACP sessions from repeatedly replaying persisted API failures and provide reliable in-product recovery from poisoned resume state.

## Best Possible Solution

Add a structured ACP/acpx outcome for confirmed unrecoverable persisted-session state, rotate only on that outcome before user-visible output, and make `/reset` reliably discard both runtime and persistent binding state while preserving sessions for ordinary transient provider errors.
