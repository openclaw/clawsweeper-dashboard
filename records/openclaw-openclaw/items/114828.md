## What This Changes

This PR preserves the most recent Control UI navigation requested during asynchronous startup so router initialization cannot restore the stale chat URL, and bounds text-read polling in the affected E2E tests.

## System Context

The Control UI publishes its application runtime and sidebar before asynchronous startup completes. Sidebar navigation enters the application router, which later initializes browser-history routing and can otherwise resolve the old URL over an early user selection.
