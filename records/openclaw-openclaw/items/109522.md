## Summary

Keep this issue open: current main still lacks per-tool registration scope, and https://github.com/openclaw/openclaw/pull/109603 is an open, directly linked implementation candidate that requires maintainer approval of the plugin API and fail-closed matching contract before landing.

## What This Changes

Add per-tool matcher scope to plugin hooks, trusted-tool policies, and result middleware so Codex native relay subprocesses only spawn for targeted tools.

## Best Possible Solution

Use one generic exact-tool scope contract across hooks, trusted policies, and result middleware only after the linked PR proves pinned-Codex name and alias coverage, deterministic trust hashing, omitted-as-match-all compatibility, and fail-closed fallback; track stuck-process lifecycle controls separately.
