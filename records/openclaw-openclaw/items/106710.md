## Summary

Keep this issue open for security-boundary and product review, not immediate implementation: current plugin mutation paths already enforce explicit operator-controlled installation policies, while the report provides no concrete administrator-compromise or SSRF path reaching those operations; durable lifecycle auditing may still be worthwhile defense in depth. 

## What This Changes

Add rate limiting and a cryptographically verifiable audit trail for plugin install, update, and removal operations.

## Best Possible Solution

Define one durable plugin-mutation event contract covering operation, artifact identity and digest, source, outcome, and authenticated actor context when available, then apply abuse throttling only at a demonstrated remote authorization boundary rather than inside local lifecycle commands.
