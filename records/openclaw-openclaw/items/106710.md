## Summary

Keep this security-sensitive issue open for maintainer design review, not immediate implementation: current main already restricts plugin mutations through trusted local CLI or gated Gateway command surfaces and supports operator install-policy decisions, but it does not provide the requested end-to-end durable lifecycle audit trail; the report also does not demonstrate the claimed SSRF or administrator-account path. ([github.com](https://github.com/openclaw/openclaw/raw/refs/heads/main/src/cli/plugins-install-command.ts))

## What This Changes

Add durable audit records and abuse-rate controls for plugin installation, update, enablement, disablement, and removal operations.

## Best Possible Solution

Define one structured lifecycle-security event contract for attempted and completed mutations, persist bounded source/version/digest/result metadata in the shared state database or diagnostics pipeline, carry authenticated actor identity only where available, and place rate limits at the specific remote authorization boundary proven vulnerable rather than unconditionally throttling local CLI work.
