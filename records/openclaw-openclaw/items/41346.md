## Summary

Keep open. Current main and the latest stable release still allow cron/plugin-created recurring agentTurn jobs to be enabled and to inherit the configured default model without the requested consent, provenance, or cost circuit-breaker policy.

## What This Changes

The issue requests safer defaults and guardrails for externally or plugin-registered cron jobs that run model-backed agent turns.

## Best Possible Solution

Define one cron safety policy for operator-authored, plugin-registered, and future agent-authored schedules, then add explicit activation/provenance, model-cost visibility, and upgrade/doctor handling for recurring model-backed jobs.
