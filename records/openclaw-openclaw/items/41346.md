## Summary

Keep open. Current main and the latest release still allow cron jobs to be created enabled by default, plugin scheduled turns still register enabled recurring `agentTurn` jobs without a payload model, and the remaining consent, provenance, model-cost, and circuit-breaker decisions are not fully owned by any narrower related item.

## What This Changes

The issue asks OpenClaw to require explicit activation or confirmation and cost guardrails for externally or plugin-registered recurring cron jobs that otherwise run on inherited model defaults.

## Best Possible Solution

Define one cron safety policy for externally or plugin-registered recurring `agentTurn` jobs covering operator-visible activation, non-forgeable provenance, explicit model or cost-warning behavior, doctor/update visibility, and quota-aware pause or notification semantics.
