## Summary

Keep open. Current main and v2026.6.11 still default omitted cron enablement to true, plugin scheduled turns still create enabled recurring agent-turn jobs without a payload model, and the remaining consent, provenance, model-cost, and quota circuit-breaker behavior needs maintainer security/product direction.

## What This Changes

The issue asks OpenClaw to require safer consent, model-cost, dry-run, and circuit-breaker behavior for externally registered recurring cron jobs.

## Best Possible Solution

Define a maintainer-owned cron registration policy for external/plugin recurring agent-turn jobs: explicit operator activation or declarative consent, non-forgeable provenance, safe model selection, doctor/update dry-run visibility, and quota-aware pausing coordinated with #71712, #14376, and #42475.
