## Summary

Keep open. Current main and the latest release still expose only daily and idle reset modes, and this issue remains the clearest canonical tracker for an explicit manual-only session reset mode.

## What This Changes

Add a true manual-only session reset mode, such as `session.reset.mode: "never"`, for base, type-specific, and channel-specific reset policies.

## Best Possible Solution

Choose one canonical manual-only reset mode, then update the schema, exported types, resolver, docs, config help, and focused reset-policy tests while preserving existing daily and idle behavior.
