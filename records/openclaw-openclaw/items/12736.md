## Summary

Keep open: current main and v2026.6.11 still lack `tools.cron.tools.allow/deny` or explicit inheritance from `tools.subagents.tools`; per-job `toolsAllow` and delivery safeguards do not satisfy the requested system-wide cron tool boundary.

## What This Changes

Request a cron-scoped tool allow/deny policy, or explicit inheritance from subagent tool restrictions, so isolated cron jobs can be prevented from using tools such as `message`.

## Best Possible Solution

Maintainers should approve a cron-scoped tool-policy contract with explicit precedence, schema/types/help/docs updates, and regression coverage for isolated cron message-tool denial across delivery modes.
