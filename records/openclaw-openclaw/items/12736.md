## Summary

Keep open: current `main` and v2026.6.11 still lack a cron-scoped tool deny config surface, and existing per-job `toolsAllow` plus delivery safeguards do not replace the requested enforced cron-wide policy.

## What This Changes

Request to add a cron-scoped tool restriction surface, such as `tools.cron.tools.deny`, or make cron jobs inherit `tools.subagents.tools` restrictions for tools such as `message`.

## Best Possible Solution

Keep this as the cron-scoped policy tracker until maintainers choose explicit `tools.cron.tools.allow/deny`, documented inheritance from subagent policy, or the current per-job-only model, then update schema, types, docs, generated metadata, and regression coverage together.
