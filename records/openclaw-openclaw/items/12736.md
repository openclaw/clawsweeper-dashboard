## Summary

Keep open: current main and v2026.6.11 still have per-job `toolsAllow` and message-delivery safeguards, but no cron-scoped tool policy or cron inheritance from `tools.subagents.tools`; choosing that boundary is a product/security decision.

## What This Changes

The issue requests a cron-scoped tool deny policy such as `tools.cron.tools.deny`, or explicit inheritance from existing subagent tool restrictions.

## Best Possible Solution

Keep this as the cron-scoped policy tracker until maintainers choose explicit `tools.cron.tools.allow/deny` or documented cron inheritance, then update schema/types/help/docs and add regression coverage across announce, none, webhook, and per-job `toolsAllow` precedence.
