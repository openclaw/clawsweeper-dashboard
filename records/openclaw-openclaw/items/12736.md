## Summary

Keep open: current main still lacks a cron-scoped tool deny policy, and the shipped per-job `toolsAllow` plus cron message-delivery knobs do not provide the requested config-level enforcement.

## What This Changes

The issue requests a cron-scoped tool deny or inheritance config so isolated cron jobs can be prevented from calling tools such as `message`.

## Best Possible Solution

Keep this as the narrow cron tool-policy tracker until maintainers choose explicit `tools.cron.tools.allow/deny` or documented cron inheritance, then update schema/types/help/docs and add regression coverage for isolated cron message-tool denial across delivery modes.
