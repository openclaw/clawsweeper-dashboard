## What This Changes

## Best Possible Solution

Define a scoped first-party local archive restore/import contract with manifest validation, dry-run, safe extraction, component modeling, conflict/rollback behavior, and explicit decisions on which cloud, encryption, and scheduling pieces stay plugin-owned.
