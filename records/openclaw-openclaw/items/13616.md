## Summary

Keep open: current main and v2026.6.11 still provide local backup archive creation and verification only, while the requested native restore/import/list/cloud/encryption/scheduled workflow and component-aware cron/session restore semantics remain unresolved.

## What This Changes

Requested native backup and restore tooling for OpenClaw configuration, cron jobs, workspace state, and session history, including import/export, cloud storage, encryption, and scheduled backups.

## Best Possible Solution

Keep this as the native backup lifecycle umbrella until maintainers define and land a security-reviewed first-party restore/import contract, with optional cloud/scheduled integrations routed through plugin or ClawHub surfaces unless core APIs are missing.
