## Summary

Keep open: current main and v2026.6.11 still provide local backup archive creation and verification only, while native restore/import/list/cloud/encryption/scheduled backup and component-aware cron/session restore remain unresolved and security-sensitive.

## What This Changes

The issue requests built-in backup and restore utilities for OpenClaw config, cron jobs, workspace state, sessions, and disaster-recovery workflows.

## Best Possible Solution

Keep this as the native backup lifecycle umbrella until maintainers define and land a security-reviewed first-party restore/import contract, with optional cloud, scheduled sync, and broad storage-provider integrations routed through plugin or ClawHub surfaces unless core APIs are missing.
