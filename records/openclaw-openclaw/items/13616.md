## Summary

Keep open: current main and v2026.6.11 still provide local backup archive creation and verification, but not the requested first-party restore/import/list/cloud/encryption/scheduled workflow or component-aware cron and session-history restore. ## What This Changes

Add first-party backup and restore utilities for OpenClaw config, cron jobs, session history, migration, and disaster recovery.
