## Summary

Keep open: current main and v2026.6.11 still provide local backup creation and verification only, while native restore/import/list/cloud/encryption, component-aware cron restore, and session-history recovery remain unresolved.

## What This Changes

The issue requests built-in backup, export, import, restore, list, scheduled cloud backup, encryption, cron-job recovery, and session-history archival for OpenClaw state.

## Best Possible Solution

Keep this as the native umbrella for a maintainer-sponsored backup lifecycle built on the existing create/verify archive path, with scoped follow-ups for safe restore, transcript policy, cron semantics, cloud/encryption boundaries, and docs that point to community tools as optional workarounds.
