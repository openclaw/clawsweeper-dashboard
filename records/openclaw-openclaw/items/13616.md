## Summary

Keep open: current main and v2026.6.11 still provide local backup archive creation and verification, but the requested first-party restore/import/list/cloud/encryption/scheduled workflow and component-aware cron/session restore semantics remain unresolved.

## What This Changes

The issue requests a first-party backup and restore utility covering configuration, cron jobs, session history, cloud storage, encryption, scheduling, and disaster recovery.

## Best Possible Solution

Keep this as the native backup lifecycle umbrella until maintainers define and land a security-reviewed first-party restore/import contract, with optional cloud/scheduled integrations routed through plugin or ClawHub surfaces unless core APIs are missing.
