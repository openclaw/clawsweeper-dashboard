## Summary

Keep open: current main and v2026.6.11 still provide local backup archive creation and verification only, while native restore/import/export/list/cloud/encryption/scheduled backup and component-aware cron/session restore remain unresolved product and security design work.

## What This Changes

Add a first-party backup/restore lifecycle for OpenClaw config, cron jobs, session history, and optional cloud/encrypted/scheduled backups.

## Best Possible Solution

Keep this as the native umbrella for a scoped first-party backup lifecycle: safe local archive restore/import with manifest validation, dry-run, component modeling, conflict and secret policy, and explicit decisions on which cloud/encryption/scheduling pieces stay plugin-owned.
