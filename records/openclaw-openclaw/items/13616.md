## Summary

Keep open: current main and v2026.6.11 still provide local backup creation and verification only, while native restore/import/list/cloud/encryption/scheduled backup and component-aware cron/session recovery remain unresolved. Community tools such as openclaw-workspace-sync and keepmyclaw cover useful workaround scope, but they do not complete the first-party session-history and destructive-restore contract.

## What This Changes

Request to add built-in backup/restore commands for config, cron jobs, workspaces, session history, optional cloud/encryption/scheduling, and disaster recovery.

## Best Possible Solution

Keep this as the native backup lifecycle umbrella until maintainers define and land a reviewed first-party restore/import contract, with optional cloud/sync workflows routed to plugins unless a core API gap is proven.
