## Summary

The previous continuation-ownership blocker is resolved on the current head, and the shared handoff owner is the right fix boundary. Keep this external PR open because it still lacks after-fix proof from a real managed service showing concurrent requests launch one updater and return the Gateway healthy.

## What This Changes

The PR makes managed-service update handoffs process-single-flight, rejects concurrent manual update continuations, prevents joiners from scheduling duplicate restarts or persisting owner sentinel state, and adds Control UI, protocol, and regression coverage.

## Best Possible Solution

Keep single-flight ownership in the shared detached-handoff infrastructure, retain explicit rejection for concurrent manual continuations, and merge only after redacted live supervisor output proves one updater and a healthy post-update Gateway.
