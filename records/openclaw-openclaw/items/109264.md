## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P1] Pass the resolved installer URL into the container:** `scripts/test-install-sh-docker.sh:594`
  - body: The new script expands `$OPENCLAW_INSTALL_CLI_URL` inside the container, but this invocation does not forward the host's resolved `$CLI_INSTALL_URL`. Docker does not inherit arbitrary host variables, so curl can receive an empty URL and the non-root CLI smoke never tests the installer.
  - confidence: 0.98
- **[P1] Stop before executing the installer when curl fails:** `scripts/test-install-sh-docker.sh:595`
  - body: The `bash -lc` body does not enable `errexit`, and curl and bash are separate newline-delimited commands. A timeout or transfer error therefore still runs the empty or partial temporary file; an empty file can exit successfully and turn the failed download into a false-positive smoke.
  - confidence: 0.99
