## Summary

Keep this PR open for a narrow correction: the per-fetch deadline is useful, but the inner shell still executes the downloaded file after curl times out or otherwise fails, so the central safety invariant is not met.

## What This Changes

The PR changes the non-root Docker CLI installer smoke to download the installer into a temporary file with curl connection and transfer deadlines before executing it, and adds a focused source-level test.

## Best Possible Solution

Enable strict failure handling inside the container shell or connect the download and execution with `&&`, then add behavioral coverage proving that a timed-out or failed curl never invokes Bash and provide redacted terminal or CI output from that scenario.
