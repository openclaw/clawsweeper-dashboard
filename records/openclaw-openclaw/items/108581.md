## Summary

Keep this issue open: current main provides a fail-closed `before_agent_run` gate over the composed prompt, but no documented hook exposes authoritative workspace/skill source paths and digests from the exact bytes used for context. The remaining question is the permanent plugin SDK shape, not whether the capability already exists.

## What This Changes

Requests a blocking plugin hook before workspace files or skill content are injected into model context, carrying a content hash so external integrity tools can veto changed inputs.

## Best Possible Solution

Extend the existing final pre-model gate with immutable, structured context-source records derived from the exact captured workspace and skill bytes, unless maintainers determine that per-source vetoes must occur earlier for memory or performance reasons.
