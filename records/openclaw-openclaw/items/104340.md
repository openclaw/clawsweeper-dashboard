## Summary

Keep open: the intended fixes are useful and well-proven, but the secrets-path change is not merge-ready because it replaces the existing config-directory `.env` contract with the state directory, which can leave plaintext credentials behind for supported external-config layouts.

## What This Changes

The branch emits structured JSON for missing `config get --json` paths, uses typed `ExitError` signaling, and changes secrets audit/apply to reuse a resolved state directory for `.env` access with regression coverage.

## Best Possible Solution

Resolve the contract-preserving `.env` path once at the start of each secrets operation, keep explicit config-path behavior, add legacy `.clawdbot` fallback without re-resolution, and test both legacy fallback and separated config/state roots.
