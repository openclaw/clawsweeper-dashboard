## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Pass parent stats options into the usage subcommand:** `src/cli/program/register.stats.ts:73-74`
  - body: `openclaw stats usage` gets its own child `opts`, so options placed before the subcommand, such as `openclaw stats --json usage` or `--all-agents usage`, are parsed on the parent and then dropped here. The sibling `sessions list` command reads `command.parent?.opts()` and merges those values before dispatching; `stats usage` needs the same shape so the explicit subcommand really shares the parent command's options.
  - confidence: 0.87
- **[P3] Normalize unknown providers before filtering:** `src/commands/stats.ts:169-170`
  - body: Rows with no `modelProvider` are emitted under the visible `unknown` provider name, but the filter compares `--provider` against `undefined` before applying that fallback. As a result, users cannot select the exact provider bucket the command prints; compute the provider key once, using `UNKNOWN_PROVIDER`, and use it for both filtering and breakdowns.
  - confidence: 0.9
- **[P3] Keep invalid durations on the duration parser path:** `src/commands/stats.ts:93-96`
  - body: The date fast path treats any `-` as an absolute date marker, so invalid duration-like values such as `--since -5d` report an ISO-date error instead of the shared duration parser guidance. Restrict the absolute-date branch to ISO-looking values so malformed durations get the right CLI error.
  - confidence: 0.78
