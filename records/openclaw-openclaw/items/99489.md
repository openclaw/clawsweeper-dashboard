Overall correctness: patch is incorrect

Full review comments:

- **[P2] Aggregate the canonical usage records instead:** `src/commands/stats.ts:63-70`
  - body: `entry.inputTokens`, `entry.outputTokens`, and `entry.estimatedCostUsd` are not lifetime session counters: current writers overwrite them from the latest run/context snapshot and assign estimated cost directly. Summing them here makes `openclaw stats` report misleading totals for multi-turn sessions; use the existing transcript-backed usage summary path instead, or present this as latest-session snapshot data.
  - confidence: 0.91
- **[P3] Normalize unknown providers before filtering:** `src/commands/stats.ts:169-170`
  - body: The output groups missing providers under `unknown`, but the filter compares `--provider` against the raw normalized `entry.modelProvider`, so `--provider unknown` excludes the very bucket the command displays. Normalize to `provider ?? UNKNOWN_PROVIDER` before filtering so every displayed provider bucket can be selected.
  - confidence: 0.84
