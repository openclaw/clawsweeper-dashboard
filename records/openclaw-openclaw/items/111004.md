## Summary

The PR fixes the previously identified descriptor/TOCTOU and symlink-compatibility problems, includes direct terminal proof for normal, boundary, oversized, and symlinked stores, and appears functionally sound. It should remain open for maintainer review because the new fixed 10 MiB authentication-store limit deliberately changes recovery for existing oversized stores: they become indistinguishable from a missing credential source at runtime.

## What This Changes

The PR routes auth-profile JSON discovery through a 10 MiB descriptor-bounded regular-file reader and adds oversized-file plus symlink regression coverage for current and legacy auth stores.

## Best Possible Solution

Adopt a bounded auth-store read only with an explicitly accepted cap and recovery contract, ideally ensuring oversized persisted stores have a clear supported diagnostic or Doctor recovery path rather than being indistinguishable from absent credentials.
