## Summary

This PR has a sound bounded-read goal, but the descriptor helper changes the existing auth-store file contract by rejecting symlinks; that can silently make an existing provider appear unauthenticated. Keep it open for an auth-store owner decision and real after-fix runtime evidence.

## What This Changes

## Best Possible Solution

Choose and document the auth-store symlink contract, then either preserve linked regular-file reads under the bounded descriptor-level cap or intentionally reject them with an explicit upgrade path and focused coverage for both current and legacy stores.
