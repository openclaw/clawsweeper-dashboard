## What This Changes

The PR suppresses a terminal QA-channel reply when it duplicates an already delivered streamed block, while still delivering a final reply that adds tool-call trace data.

## System Context

The QA channel turns inbound QA-bus messages into agent runs, then forwards streamed previews and durable agent replies back onto the QA bus. This change sits in that delivery funnel and affects whether consumers receive one durable reply or a duplicate final message.
