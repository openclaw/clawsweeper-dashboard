## Summary

Keep open. ## What This Changes

The PR adds a `collected.length === 0` guard to memory-host SDK archive cron classification and adds a regression test for mid-transcript `[cron:]` user text.

## Best Possible Solution

Use trusted session-store or record-level cron provenance for archive-wide suppression while preserving human-authored `[cron:]` archive content, then back it with regression coverage and redacted real behavior proof.

## Solution Assessment
