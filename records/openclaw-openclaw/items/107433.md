## Summary

Keep open: current main deliberately skips a fixed set of volatile and reconstructable artifacts, but it has no operator-declared, manifest-verified omission contract for protected paths; the remaining work is real and requires an explicit core backup security/product decision.

## What This Changes

Requests manifest-backed, classified omissions so verified backups can safely exclude protected or reconstructable runtime paths while remaining fail-closed for unexpected unreadable data.

## Best Possible Solution

Add a versioned backup omission-plan contract with exact anchored paths in its first iteration, explicit classification and recovery guidance, observed omission status in the archive manifest, and verifier checks that reject traversal, undeclared omissions, rule drift, and every unexpected unreadable path; avoid a generic emergency skip flag.
