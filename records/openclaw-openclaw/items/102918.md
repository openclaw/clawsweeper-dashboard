## Summary

Keep open: current main still allows this source path, because macOS CLI installs without file-backed credentials are treated as unknown and Crestodian setup selects unknown credentials as usable. The protected `maintainer` label also prevents conservative cleanup automation from closing or queuing this automatically.

## What This Changes

Fresh Crestodian onboarding can persist an installed but logged-out Claude/Codex CLI as the default AI backend instead of sending the user to provider setup.

## Best Possible Solution

Gate automatic CLI reuse on each CLI's noninteractive auth-status command, keep logged-out installs visible for manual setup, and only persist a default model after verified working auth.
