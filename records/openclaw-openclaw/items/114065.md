## What This Changes

Ensure a restrictive agent-scoped `tools.allow` excludes non-allowed built-in and plugin tools from the provider-visible tool set.

## System Context

The embedded agent runner builds built-in and plugin tools, adds bundled MCP/LSP tools, then passes tools to the selected model provider. Agent, provider, sender, sandbox, and owner-only policies are intended to restrict that provider-visible set before a model can call a tool.

  E[Bundled MCP and LSP tools] --> D
  B --> F[Policy filtering]
  D --> F
  F --> G[Provider-visible tools]
  G --> H[Model tool calls]

## Best Possible Solution

Confirm the `2026.7.1` reproduction against current main, then keep one resolved-policy filter over the complete provider-visible tool list and add regression coverage for restrictive per-agent allowlists across built-in, plugin, bundled MCP/LSP, run, and compaction paths.
