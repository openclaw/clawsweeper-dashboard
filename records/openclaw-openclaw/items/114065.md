## What This Changes

The issue requests enforcement of a restrictive per-agent `tools.allow` policy across built-in and plugin tools exposed to the provider, not only bundled MCP/LSP tools.

## System Context

OpenClaw constructs the provider-visible tool set from built-in, plugin, and bundled tool sources before an agent can call a tool. Per-agent policy is expected to constrain that assembled set so each agent sees and can invoke only tools permitted by its resolved configuration.

## Best Possible Solution

Define whether any forced tools are exempt, then enforce the resolved per-agent policy at one canonical final provider-visible tool-set boundary with regression coverage for built-in, plugin, MCP/LSP, run, compaction, and no-policy behavior.
