## Summary

Keep this PR open for a maintainer decision on the compatibility contract of the existing Codex relay switch. The terminal-abort design, focused coverage, and redacted runtime proof support the central fix, but changing `loopDetectionPreToolUseRelay: false` from suppressing the PreToolUse marker to suppressing its companion PostToolUse outcome relay changes an existing user setting's meaning.

## What This Changes

The branch makes critical tool-loop detection terminate the active embedded, Codex, or Copilot run as blocked while retaining the session for a subsequent turn.

## Best Possible Solution

Keep the single terminal-abort path, then explicitly confirm whether the existing Codex relay switch should disable both loop-detection relays; if not, preserve its prior narrow behavior or introduce a clearly documented migration-compatible control with focused coverage for both settings.
