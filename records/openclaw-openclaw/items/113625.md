## What This Changes

This PR prevents execution-phase activity from starting a channel typing indicator in `typingMode: "message"` until renderable assistant text exists, and adds regression tests for both sides of that gate.

## System Context

Inbound channel turns enter the auto-reply lifecycle, whose execution and text events feed a shared typing controller. The controller starts or refreshes each channel's typing indicator, so its mode gate affects visible typing behavior across adapters that use this core path.
