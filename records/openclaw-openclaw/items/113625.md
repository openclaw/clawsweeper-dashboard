## Summary

This PR is a coherent implementation of a different typing-policy contract, but current `main` and the public typing documentation explicitly define `message` mode to start on active execution before text. Keep it open for a maintainer decision rather than merge it as a bug fix; its terminal red/green tests are useful but do not replace real channel proof.

## What This Changes

The PR changes the shared auto-reply typing controller so execution activity in `typingMode: "message"` waits for renderable assistant text, with focused tests for before-text and after-text cases.

## System Context

Inbound messages enter the auto-reply agent runner, which reports accepted turns, model calls, and tool activity to the shared typing signaler. The signaler decides when channel adapters show and refresh typing indicators until reply dispatch completes.
