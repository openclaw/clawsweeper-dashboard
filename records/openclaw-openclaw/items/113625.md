## What This Changes

This PR makes the shared auto-reply typing controller wait for renderable assistant text before execution-phase activity can start typing in `message` mode, with focused tests for the before-text and after-text cases.

## System Context

OpenClaw’s auto-reply path receives agent execution events and translates them into channel typing activity for transports such as Telegram and WhatsApp. The typing controller decides whether to start or refresh the channel indicator before reply text is emitted.
