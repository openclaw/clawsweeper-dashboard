## Summary

Keep this PR open: the proposed guard matches the existing `message`-mode invariant and its focused tests cover the intended state transition, but the external contribution has only mock/unit-test evidence and needs a redacted real channel run before merge.

## What This Changes

The PR prevents execution-phase activity from starting a channel typing indicator in `message` mode until renderable assistant text exists, with focused tests for before and after text emission.

## System Context

OpenClaw’s auto-reply runner reports execution activity and text deltas to a shared typing controller used by channel adapters. The controller decides when a channel should display a composing indicator, so its mode gate affects what recipients see before an assistant reply is rendered.
