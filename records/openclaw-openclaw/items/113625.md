## What This Changes

This PR changes the shared auto-reply typing controller so execution activity in `typingMode: "message"` waits for renderable assistant text, with tests for the before-text and after-text cases.

## System Context

The auto-reply typing controller receives execution and text events from an agent run, then tells channel adapters when to display a typing indicator. This change affects the decision between early execution activity and the channel-visible typing loop.
