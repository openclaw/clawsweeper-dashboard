## Summary

Keep open: current main and v2026.6.11 still record unmentioned Feishu `requireMention` group messages into group history and replay that history into later admitted turns, while the requested mention-only/per-bot context policy is still absent.

## What This Changes

Request a Feishu group context-isolation option so each bot records context only from messages that explicitly mention that bot in multi-bot groups.

## Best Possible Solution

Add an explicit Feishu-owned mention-only/per-bot context policy that preserves current defaults unless maintainers choose otherwise, with strict schema/docs updates, focused history-window tests, and redacted live multi-bot Feishu proof.
