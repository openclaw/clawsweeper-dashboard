## Summary

Keep open: current main and v2026.6.11 still record unmentioned Feishu group messages into shared pending history and replay that history into later handled turns, while the requested per-bot or mention-only context policy is absent. Existing `contextVisibility` filters supplemental context by allowlisted sender, not by which Feishu bot was mentioned, so it does not solve the central request.

## What This Changes

Request to add Feishu per-bot context isolation so multi-bot groups only record context for messages that explicitly mention the current bot.

## Best Possible Solution

Add a maintainer-approved Feishu group context policy in the Feishu plugin, with explicit defaults, schema/docs, focused regression tests, and redacted multi-bot Feishu proof before changing current history behavior.
