## Summary

Keep open: current main and latest release still record unmentioned Feishu group messages into the shared group history window and replay that history into later handled turns, while the requested per-bot/mention-only context policy is not implemented.

## What This Changes

The issue requests Feishu group context isolation so each bot records context only for messages explicitly addressed to it, likely via a new Feishu context policy or config option.

## Best Possible Solution

Add a maintainer-approved Feishu-owned context policy that preserves existing defaults unless explicitly changed, with schema/docs, regression tests, and redacted live multi-bot Feishu proof.
