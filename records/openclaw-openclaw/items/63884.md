## Summary

Keep open: current main and v2026.6.11 still record unmentioned Feishu requireMention group messages into the shared group history window and replay that history into later handled turns, while the requested per-bot or mention-only context policy is still absent.

## What This Changes

The issue requests a Feishu group context-isolation option so each bot records only messages explicitly addressed to that bot.

## Best Possible Solution

Add a maintainer-approved Feishu-owned context policy with schema/docs, focused tests, and redacted multi-bot Feishu proof; keep existing history behavior unless the compatibility change is explicit.
