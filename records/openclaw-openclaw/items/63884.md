## Summary

Keep open: current main and v2026.6.11 still store unmentioned Feishu group messages as pending group history and replay that history into later mentioned turns, while the requested per-bot or mention-only context policy is still absent.

## What This Changes

Add Feishu group context isolation so bots with `requireMention` only record context when the current bot is mentioned, avoiding other bots' conversations in later prompts.

## Best Possible Solution

Add a maintainer-approved Feishu group context policy with explicit defaults, schema/docs, regression tests, and redacted live multi-bot Feishu proof; keep `historyLimit: 0` as the coarse existing workaround, not the final per-bot policy.
