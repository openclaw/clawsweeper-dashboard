## Summary

Keep open: current main and v2026.6.11 still record unmentioned Feishu requireMention group messages into the shared group history window, and the requested mention-only/per-bot context isolation policy is not implemented.

## What This Changes

Requested behavior: add mention-scoped Feishu group context isolation so each bot records only messages explicitly addressed to it in multi-bot Feishu groups.

## Best Possible Solution

Add an opt-in Feishu-owned context policy that preserves the documented default, suppresses unrelated unmentioned or other-bot group history for selected groups, and ships with schema, docs, focused regression tests, and redacted live multi-bot Feishu proof.
