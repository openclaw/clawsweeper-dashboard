## Summary

Keep open: current main still has a blocking-capable CLI agent hook path whose context omits resolved provider/model identity, while model_call_ended is only post-hoc attribution, so the security-sensitive plugin API gap remains actionable.

## What This Changes

The issue asks OpenClaw to expose resolved provider/model identity to policy plugins before a blocking-capable enforcement point and to confirm or expose provider-call attribution hooks.

## Best Possible Solution

Ship an additive, read-only resolved provider/model identity on before_agent_run for every agent runtime, document it as the supported enforcement point, and keep model_call_ended as observe-only audit telemetry.
