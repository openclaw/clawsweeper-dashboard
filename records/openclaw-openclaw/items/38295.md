  - body: Current main deliberately sets the LaunchAgent throttle to 10s so crash loops back off while supervised restarts still recover promptly.   - body: Using `snapshot.hash` first suppresses later invalid-reload warnings when root config bytes are unchanged but include, env, or plugin-derived issues change.   - confidence: 0.9
- **[P2] Keep future-version warning text unforgeable:** `src/config/io.ts:644`
  - body: The PR head accepts versions with trailing text and logs `meta.lastTouchedVersion` raw, while current main has anchored parsing and safer warning behavior. Rebase onto current main and preserve that hardening, or sanitize/reject the touched version before it reaches logs.
  - confidence: 0.86
- **[P2] Use the current macOS LaunchAgent log path:** `docs/gateway/logging.md:52`
  - body: Current launchd services write supervisor logs under `~/Library/Logs/openclaw`, but this docs addition points CLI LaunchAgent users at `$OPENCLAW_STATE_DIR/logs`. That sends users to the wrong files when diagnosing or truncating service log growth.
  - confidence: 0.9
