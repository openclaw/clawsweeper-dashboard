## Summary

Keep open: current main and the latest release still lack per-mention/background model routing and per-group mention-context sizing, and the related open items cover adjacent activation or passive-observation work rather than this exact request.

## What This Changes

Request configurable group behavior that routes mentioned messages to one model, unmentioned background context to another model, and limits the context window used when a mention wakes the bot.

## Best Possible Solution

Design this as an explicit WhatsApp/group capability or trusted pre-gating plugin/API hook with safe defaults, clear model-routing precedence, bounded background turns, per-group context limits, schema/docs, and focused tests.
