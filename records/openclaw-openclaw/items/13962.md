## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware group model routing and per-group mention-context sizing; this remains a useful but security-sensitive product/config design request.

## What This Changes

The issue requests per-group configuration for routing mentioned and unmentioned group messages to different models, plus a configurable context window for mentioned turns.

## Best Possible Solution

Define a deliberate default-off mention-state routing and context policy, preferably through a generic channel/plugin contract unless maintainers choose a WhatsApp-only surface, then update schema, docs, and tests for provider precedence and privacy boundaries.
