## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware model routing and per-group mention-context sizing. WhatsApp now stores skipped mention-gated group messages for later context, but there is no `mentionModel`, `backgroundModel`, or `mentionContextMessages` config surface, and the remaining work needs product/security review.

## What This Changes

The issue requests configurable model routing based on whether a group message mentions the agent, plus a configurable context window for mention-gated group replies.

## Best Possible Solution

Define a default-off, consent-aware group mention-routing design that reuses pending group history and existing channel/session model precedence while making provider exposure and per-group limits explicit.
