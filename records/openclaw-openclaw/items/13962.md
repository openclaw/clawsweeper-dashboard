## Summary

Keep open: current main and v2026.6.11 still provide buffered WhatsApp group history plus channel/group/session model overrides, but not mention-state-aware model routing or per-group mention-context sizing. The remaining work is useful, but it changes public config, provider/model selection, context visibility, and privacy boundaries for unmentioned shared-room traffic, so it needs maintainer product/security design before implementation.

## What This Changes

The issue requests per-group routing that uses one model for mentioned group messages and another model for unmentioned background context, plus a configurable context window for mention-gated group replies.

## Best Possible Solution

Define a deliberate mention-state routing and context policy, preferably as a generic channel/plugin contract unless maintainers choose a WhatsApp-only surface, then update config schema/docs and tests around provider precedence, context visibility, skipped-message buffering, and per-group limits.
