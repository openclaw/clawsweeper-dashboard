## Summary

Keep open: current main and v2026.6.11 still only provide channel/group/session-level model overrides plus buffered group-history context, not mention-state-aware model routing or per-group mention-context sizing. The remaining work is a product and security contract choice because it would let unmentioned shared-room content route through a configurable background model.

## What This Changes

The issue requests per-group controls for routing mentioned group messages to one model, unmentioned group messages to a cheaper background model, and sizing the context window used when a mention arrives.

## Best Possible Solution

Define a default-off mention-state routing and context policy, preferably as a generic channel/plugin contract unless maintainers choose a WhatsApp-only surface, then update schema/docs and tests around provider precedence, context visibility, skipped-message buffering, and per-group limits.
