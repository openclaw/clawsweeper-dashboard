## Summary

Keep open: current main and v2026.6.11 still only buffer unmentioned WhatsApp group traffic as pending context and still route models by channel/session rather than mention state. The requested per-mention routing, background model, and per-group mention-context controls remain absent and need maintainer product/security design.

## What This Changes

Request to add per-group mention-aware model routing and a configurable prior-message context window for group chats when `requireMention` is enabled.

## Best Possible Solution

Define a maintainer-sponsored, default-off group mention-routing design that reuses pending group history, preserves allowlist/context-visibility boundaries, and documents model precedence before implementation.

## Reproduction Assessment

Not applicable as a bug reproduction: this is a feature request, not a broken existing behavior report. Source inspection gives high confidence that current main only partially covers the context-window side through global pending group history and lacks mention-state routing config.

## Solution Assessment

Unclear: the requested capability is useful, but the exact config shape and background-model behavior are not yet the safest confirmed solution. The best path is a maintainer-approved design that defines provider exposure, group context limits, and precedence with existing model overrides.
