## Summary

Keep open: current main and v2026.6.11 still support skipped-message buffering plus channel/group/session-level model overrides, but not mention-state-aware model routing or per-group mention-context sizing.

## What This Changes

The issue requests per-group configuration that routes mentioned and unmentioned group messages to different models and controls how many prior group messages are included when a mention is processed.

## Best Possible Solution

Keep this issue open until maintainers define a default-off group-routing contract that covers mention-state model selection, per-group context limits, provider precedence, and privacy boundaries before implementation.
