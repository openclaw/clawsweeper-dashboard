## Summary

Keep open: current main and v2026.6.11 still lack per-mention model routing, background processing for skipped group messages, and per-group mention context sizing. Adjacent ambient-room and passive hook work cover different boundaries, so this remains product/security/config work rather than conservative cleanup.

## What This Changes

The issue requests configurable group mention behavior that routes mentioned and non-mentioned messages to different models and includes a bounded prior-message context window when a mention triggers processing.

## Best Possible Solution

Define a default-off, consent-aware mention-state routing design that composes with existing channel model overrides and ambient room semantics before implementing any new config surface.

## Reproduction Assessment

Not applicable as a broken-behavior bug, but yes at source level for the missing feature: current WhatsApp gating records unmentioned group messages and returns before processing, and the requested config keys are absent.

## Solution Assessment

No as an automatic fix. The requested direction is useful, but the best solution needs a maintainer-approved privacy/config/routing contract rather than a narrow code-only repair.
