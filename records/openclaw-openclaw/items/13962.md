## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware model routing and per-group mention-context sizing. Main does already buffer skipped WhatsApp group messages for later context, so the remaining work is narrower than the original context-window ask, but the `mentionModel`/`backgroundModel` routing and per-group context controls remain unresolved and need product/security review.

## What This Changes

Request per-group controls for routing mentioned group turns to one model, unmentioned background context to another, and sizing the mention context window.

## Best Possible Solution

Define a maintainer-sponsored, default-off group mention-routing design that reuses existing pending group history and channel model override semantics while making provider exposure, allowlists, and precedence explicit.
