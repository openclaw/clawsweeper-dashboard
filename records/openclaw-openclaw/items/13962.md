## Summary

Keep open: current main still has pending WhatsApp group-history context and channel/session model overrides, but not mention-state-aware model routing or a per-group mention-context limit. The remaining work needs maintainer product and security direction because it would process unmentioned shared-room traffic through configurable model/provider paths.

## What This Changes

Request per-group controls that route mentioned and unmentioned group messages to different models and cap the context window included when a mention triggers a reply.

## Best Possible Solution

Define a default-off mention-state routing and context policy, preferably through a generic channel/plugin contract unless maintainers choose a WhatsApp-only surface, then update WhatsApp config schema/docs and tests for provider precedence, skipped-message buffering, background-model behavior, and per-group context limits.
