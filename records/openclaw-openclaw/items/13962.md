## Summary

Keep open: current main and v2026.6.11 still only buffer skipped WhatsApp mention-gated group messages as later context and route models by channel/group/session, not by mention state. The requested per-group `mentionModel`, `backgroundModel`, and `mentionContextMessages` controls remain absent and need maintainer product/security direction before implementation.

## What This Changes

The issue requests per-group mention-state model selection and a configurable context window for mention-gated group chats.

## Best Possible Solution

Keep this open until maintainers choose a default-off group-routing design that preserves current skipped-message context buffering, adds any per-group context control through the channel config contract, and explicitly approves how unmentioned group traffic may be processed by a background model.

## Reproduction Assessment

Yes. Source inspection reproduces the missing behavior: the requested config keys are absent, skipped unmentioned WhatsApp group messages return before model processing, and model overrides are not keyed by mention state.

## Solution Assessment

Unclear. Per-mention routing is plausible, but the best implementation needs maintainer design around existing channel model overrides, ambient room events, skipped-message history, and security boundaries for unmentioned group traffic.
