- `impact:auth-provider`: The feature would route the same group conversation across different providers or models based on mention state.

## Summary

Keep open: current main and v2026.6.11 still buffer skipped WhatsApp mention-gated group messages and support channel/group/session-level model overrides, but not mention-state-aware model routing or per-group mention-context sizing. The remaining work is a product and security design decision, not conservative cleanup.

## What This Changes

Request per-group configuration that routes mentioned and unmentioned group messages to different models and limits how many prior group messages are included when a mention is processed.

## Best Possible Solution

Define a default-off shared channel/plugin contract, or an explicitly approved WhatsApp-only exception, for mention-state model routing and per-group context sizing with privacy, provider-precedence, config, and regression-test coverage.
