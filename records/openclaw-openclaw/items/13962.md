## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware model routing and per-group mention-context sizing. Existing pending group history and `channels.modelByChannel` cover adjacent pieces, but the requested `mentionModel`, `backgroundModel`, and `mentionContextMessages` controls remain missing and need product/security review.

## What This Changes

Request per-group controls to route mentioned and unmentioned group messages to different models and include a configurable context window when the bot is mentioned.

## Best Possible Solution

Define a maintainer-sponsored, default-off group mention-routing design that reuses pending group history and existing channel/session model precedence while making provider exposure and per-group limits explicit.
