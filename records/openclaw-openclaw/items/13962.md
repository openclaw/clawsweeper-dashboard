## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware model routing, background processing for unmentioned group messages, and per-group mention-context sizing. The remaining work needs maintainer product and security design because it changes provider exposure and public config for shared-room traffic.

## What This Changes

Request per-group controls that route mentioned group messages to one model, process non-mentioned messages through a cheaper background model, and include a configurable previous-message window when mentioned.

## Best Possible Solution

Define a default-off, consent-aware mention-routing design in the WhatsApp/group pipeline that reuses pending history and existing model-override precedence before adding schema, docs, and focused tests.
