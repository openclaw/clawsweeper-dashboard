## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware model routing and per-group mention-context sizing. The existing WhatsApp path buffers skipped mention-gated group messages as pending context, but unmentioned messages do not run through a background model and the requested config keys are absent.

## What This Changes

The issue requests group-chat controls for routing mentioned and unmentioned messages to different models and setting a per-group mention context window.

## Best Possible Solution

Define a maintainer-sponsored, default-off group mention-routing design that reuses pending group history and existing channel model/session precedence while making provider exposure and per-group limits explicit.
