## Summary

Keep open: current main and v2026.6.11 still lack per-mention/background model routing and per-group mention-context sizing, and the related open items cover adjacent passive observation or activation behavior rather than this exact request.

## What This Changes

Request configurable group behavior so mentioned messages can use a premium model, unmentioned messages can use a cheaper background model, and mentioned turns can include a bounded prior-message context window.

## Best Possible Solution

Design this as an explicit WhatsApp/group capability or trusted pre-gating plugin/API hook with safe defaults, clear model-routing precedence, bounded background turns, per-group context limits, schema/docs, and focused tests.

## Reproduction Assessment

No as a bug reproduction: this is a feature request. Source and release inspection give high confidence that current main and v2026.6.11 lack the requested config keys and equivalent mention-state routing behavior.

## Solution Assessment

Unclear until maintainers choose the product and security contract. The suggested direct config is plausible, but the safer solution needs explicit routing-precedence, provider/auth, and group-context security design first.
