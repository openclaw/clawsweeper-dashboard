## Summary

Keep open: current main and the latest release still do not provide per-mention/background model routing or a per-group mention context-size control. The issue remains a meaningful product/security design item rather than a stale cleanup candidate, and related open items cover adjacent activation or passive-observation needs rather than superseding this request.

## What This Changes

The issue requests per-group controls for routing mentioned group messages to one model, unmentioned/background group messages to another model, and adding a configurable mention context window.

## Best Possible Solution

Design a default-off WhatsApp/group capability or trusted pre-gating plugin/API hook with safe defaults, explicit routing precedence, bounded background processing, per-group context limits, schema/docs, and focused tests.
