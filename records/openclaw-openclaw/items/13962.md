## Summary

Keep open: current main and v2026.6.11 still lack mention-state-aware model routing and per-group mention-context sizing. The remaining work is a product and security contract decision because it would route unmentioned shared-room content through configurable background providers.

## What This Changes

The issue requests per-group model routing based on whether the bot was mentioned, plus a configurable context window for mention-gated group chats.

## Best Possible Solution

Define a default-off mention-state routing and context policy, preferably as a generic channel/plugin contract unless maintainers choose a WhatsApp-only surface, then update schema, docs, and tests around provider precedence, context visibility, skipped-message buffering, and per-group limits.
