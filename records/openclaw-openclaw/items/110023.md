## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.99

Full review comments:

- **[P1] Read through EOF before accepting the certificate:** `extensions/msteams/src/sdk.ts:198`
  - body: `fs.readSync` may return fewer bytes than requested without reaching EOF. This code immediately decodes that partial buffer, so an ordinary certificate at or below the limit can be truncated and authentication will fail. Loop until EOF or overflow, preferably by using the shared reader.
  - confidence: 0.99
- **[P1] Use the shared secret-file reader:** `extensions/msteams/src/sdk.ts:191`
  - body: `openclaw/plugin-sdk/secret-file-runtime` already exposes the repository's bounded secret-file implementation. Keeping a second security-sensitive reader here creates divergent file-type, descriptor, error, and read-completion behavior; replace this helper with the shared API and explicit compatibility options.
  - confidence: 0.98
