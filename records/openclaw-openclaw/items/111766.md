## What This Changes

This PR makes live provider model-catalog downloads reject malformed UTF-8 before JSON parsing, adds a regression test for static fallback, and replaces a ripgrep-dependent auto-merge error classifier with portable shell matching.

## System Context

Live provider catalogs augment a provider’s configured static models by downloading JSON through a guarded HTTP fetch. The decoded response is parsed into catalog rows; a fetch or decoding failure falls back to the provider’s static model list, while the PR helper classifies auto-merge service errors for repository automation.
