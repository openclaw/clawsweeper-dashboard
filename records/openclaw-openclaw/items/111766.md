## What This Changes

The PR makes live provider model-catalog responses reject malformed UTF-8 bytes and adds a regression test proving the static catalog is used after that rejection.

## System Context

Provider model catalogs can be fetched live from provider HTTP endpoints and are then normalized into the configuration used for model selection. This change sits at the byte-decoding boundary before JSON parsing, so a corrupt response falls into the existing static-catalog fallback instead of contributing mangled model metadata.
