## What This Changes

This PR adds a process-local `sessions.changed` subscription to the plugin service runtime and changes ClickClack discussion reconciliation from regular polling to event-driven updates with a polling fallback.

## System Context

Gateway session lifecycle and transcript changes are broadcast to connected clients today. This PR also routes those change notices to long-lived plugin services, letting ClickClack refresh a bound discussion channel when its session is renamed, archived, or moved.

## Architecture Diagram

  B --> D[Process-local plugin event facade]
  D --> E[Long-lived plugin service]
  E --> F[ClickClack coalesced reconciliation]
  F --> G[Updated discussion sidebar]
