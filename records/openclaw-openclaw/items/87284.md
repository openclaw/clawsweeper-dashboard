## Summary

Keep open: current main fixes parts of the Dashboard flow and adds guardrails against empty manual compaction, but the central Claude CLI over-cap recovery contract remains unresolved and is not superseded by the adjacent open PRs/issues.

## What This Changes

## Best Possible Solution

Define a Claude CLI over-cap contract that either proves native carry-over, fails loudly with export/manual-prune guidance, or implements a tested fallback, while preventing empty checkpoints and cold-session rotation.
