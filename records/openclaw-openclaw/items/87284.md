## Summary

Keep open: current main has partial UI and stale-meter safeguards, but no source, test, or live proof shows Dashboard `/compact` can preserve or clearly recover an already over-cap Claude CLI session.

## What This Changes

The issue asks OpenClaw to stop Dashboard context metering and `/compact` from silently losing Claude CLI session context once the native transcript is near or over the 1M-token cap.

## Best Possible Solution

Define and implement a Claude CLI over-cap contract that either proves native context carry-over, fails loudly with export/manual-prune guidance, or uses a tested fallback path while never writing empty checkpoints or rotating into a cold session.
