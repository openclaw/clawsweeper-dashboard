## Summary

Keep open: current main has partial UI/status safeguards, but it still does not prove Dashboard `/compact` can preserve or loudly recover an already over-cap Claude CLI transcript; ordinary `claude-cli` compaction remains backend-owned and deferred by OpenClaw.

## What This Changes

The issue asks OpenClaw to fix Dashboard context-meter accuracy, wire visible compaction feedback, and prevent `/compact` from silently losing Claude CLI session context past the native cap.

## Best Possible Solution

Define a Claude CLI over-cap recovery contract that either proves native context carry-over, fails loudly with export/manual-prune guidance, or uses a tested fallback path, while preventing empty checkpoints or cold-session rotation.
