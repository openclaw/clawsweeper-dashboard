## Summary

Keep open: current main has important partial safeguards for Dashboard compaction feedback and stale context display, but Claude CLI over-cap recovery is still deferred to native Claude Code compaction and remains a maintainer product decision with live-repro gaps.

## What This Changes

The issue reports that Dashboard context usage, the Compact button, and `/compact` can combine to silently lose Claude CLI session context after the native 1M-token cap is exceeded.

## Best Possible Solution

Define and implement a tested Claude CLI over-cap recovery path that either produces a valid carry-over summary, refuses with visible recovery/export guidance, or proves native compaction cannot rotate away useful context silently.
