## Summary

Keep open: current main fixes part of the Dashboard UX, but ordinary `claude-cli` compaction still deliberately defers to backend-owned native compaction and no merged fix proves Dashboard `/compact` can preserve or loudly recover an already over-cap Claude CLI transcript.

## What This Changes

Fix Dashboard context-meter and `/compact` behavior so over-cap Claude CLI sessions do not silently rotate or lose usable prior context.

## Best Possible Solution

Define a Claude CLI over-cap recovery contract that either proves native context carry-over, fails loudly with export/manual-prune guidance, or uses a tested fallback, while preventing empty checkpoints and cold-session rotation.
