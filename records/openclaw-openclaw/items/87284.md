## Summary

Keep open: current main has partial Dashboard and stale-meter safeguards, but it still does not prove that Dashboard `/compact` can preserve or clearly recover an already over-cap Claude CLI session; related open items only cover narrower configured-budget, transcript-scope, and backend-aware status pieces.

## What This Changes

The issue asks OpenClaw to stop Dashboard `/compact` from misleading users or losing Claude CLI session context when a long-running native Claude session is near or past its context cap.

## Best Possible Solution

Define a Claude CLI over-cap Dashboard compaction contract that either proves native carry-over, fails loudly with export/manual-prune guidance, or uses a tested fallback path before any cold rotation or empty checkpoint can be accepted.

- **Build OpenClaw Fallback Recovery:** Implement a tested OpenClaw-owned over-cap recovery path that reads bounded native Claude transcript content or uses a fallback model before any session rotation.
