## Summary

Keep open: current main has partial safeguards for the Dashboard button, slash-command result reporting, and empty-transcript compaction, but it still does not prove a safe Claude CLI over-cap recovery path or a trustworthy live-transcript context meter.

## What This Changes

The issue requests that Dashboard context usage and `/compact` for Claude CLI sessions avoid misleading 100% meters and never silently wipe context when the native transcript exceeds the 1M cap.

## Best Possible Solution

Define a Claude CLI over-cap recovery contract that either proves native context carry-over, fails loudly with export/manual-prune guidance, or uses a tested fallback path, while keeping Dashboard compaction from writing empty checkpoints or rotating into a cold session.
