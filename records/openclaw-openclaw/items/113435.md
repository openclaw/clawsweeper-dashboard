## What This Changes

The PR prevents grep and ripgrep search summaries from re-wrapping patterns that already look like tool-display text, falling back to a neutral label while retaining normal short search patterns.

## System Context

OpenClaw turns shell commands into concise tool-display summaries for browser and log output. The grep/ripgrep branch extracts a search pattern and target, then emits a human-readable label shown alongside the command result.
