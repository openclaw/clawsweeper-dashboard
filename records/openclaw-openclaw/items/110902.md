## Summary

Keep this PR open for maintainer review. The earlier P1 remains: the new runtime surface gives every loaded plugin access to a process-global Talk PCM subscriber, while caller-selected session filters are not an authorization boundary; this needs an explicit plugin capability and session-access contract before merge.

## What This Changes

The branch adds `runtime.talk.subscribeOutputMedia` for Gateway Talk PCM/lifecycle events and an opt-in `agentConsultOwner: "gateway"` Talk-session parameter.

## Best Possible Solution

Define a narrow manifest/runtime capability for observing Talk output, bind each subscription to authorized sessions or an explicit user-approved scope, and add focused isolation tests before publishing the plugin SDK API.
