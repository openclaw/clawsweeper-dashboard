## What This Changes

This PR adds `api.runtime.talk.onActivity`, allowing eligible plugins to receive anonymous process-wide Talk lifecycle, state, and speech-timing events for ambient interfaces such as speaking avatars.

## System Context

Talk session controllers coordinate realtime voice sessions and emit their lifecycle events within the Gateway process. This PR records a redacted subset of those events, delivers it through bounded listener queues, and exposes it through the Plugin SDK after manifest and plugin-enable checks.
