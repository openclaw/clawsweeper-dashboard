## Summary

Keep this PR open. The previous P1 security-boundary concern remains: every plugin runtime receives a process-global Talk watcher, allowing an unrelated plugin to learn when other Talk sessions are listening, thinking, speaking, or failing. The `maintainer` label also requires explicit human handling rather than automated cleanup.

## What This Changes

The branch adds `api.runtime.talk.watch`, a Plugin SDK API for ambient plugins to receive anonymous Talk lifecycle, state, and speech-pulse events without audio or transcript content.

## System Context

Talk session controllers emit realtime voice-session events while OpenClaw coordinates conversations. The new activity layer converts those events into anonymous notifications and exposes them through the Plugin SDK runtime to plugins that render ambient UI.

Publish a scoped observer: bind activity to a Talk session owner or require an explicit reviewed capability/grant, and document exactly which plugin trust tier may subscribe before freezing the Plugin SDK contract.
