## Summary

Keep this PR open for maintainer review. It introduces a new plugin runtime API that can expose exact gateway-session PCM; the branch adds session filters, but the public `scope: "all"` path still has no plugin capability or authorization boundary, so the earlier security finding remains materially unresolved.

## What This Changes

The branch adds `runtime.talk.subscribeOutputMedia` for Talk PCM/lifecycle events and an optional `agentConsultOwner: "gateway"` parameter for Gateway-managed realtime consultations.

## Best Possible Solution

Define a capability-gated plugin contract that authorizes a plugin for explicitly owned Talk sessions, rejects global observation by default, and documents the approved `agentConsultOwner` behavior before exposing either API as a stable runtime surface.
