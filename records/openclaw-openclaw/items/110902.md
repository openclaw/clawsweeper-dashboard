## What This Changes

The PR adds `api.runtime.talk.onActivity`, allowing plugins to receive anonymous lifecycle, state, and speech-timing events from Talk sessions across the Gateway process for ambient interfaces such as avatars.

## System Context

Talk session controllers emit canonical voice-session events as conversations start, listen, think, speak, fail, and end. This PR reduces those events to anonymous activity signals and exposes the feed through the Plugin SDK runtime resolver to installed plugins.
