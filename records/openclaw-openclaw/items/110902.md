## What This Changes

This PR adds `api.runtime.talk.onActivity`, a Plugin SDK subscription that sends plugins redacted process-wide Talk lifecycle, state, and speech-timing events for ambient UI such as avatars.

## System Context

Talk session controllers receive realtime voice events and coordinate each conversation’s lifecycle. This change records a redacted activity stream and exposes it through the Plugin SDK so a plugin can animate ambient UI without receiving audio, transcripts, provider data, or session identifiers.

## Architecture Diagram

## Best Possible Solution

Either make the observer owner-scoped, or define a separately trusted operator/registry capability that grants audited process-wide Talk activity observation; do not treat a plugin’s manifest declaration and ordinary enabled state as the permanent authorization boundary.
