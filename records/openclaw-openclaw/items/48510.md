## Summary

Keep open: current main still lacks declared behavioral capability descriptors on tool definitions, plugin tool metadata, before_tool_call/trusted-policy payloads, and Gateway tool projections; the related issues and PRs are adjacent rather than a merged replacement.

## What This Changes

Request to add optional behavioral capability descriptors to tool definitions so policy, audit, and documentation can reason about tool behavior without brittle name matching.

## Best Possible Solution

Define one additive, documented policy-facts contract for tool behavior descriptors, project it through tool inventory and hook policy surfaces, and keep declarations advisory unless host authorization or explicit grants enforce them.
