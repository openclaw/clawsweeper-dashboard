## Summary

Keep open: current main still lacks the requested behavioral capability descriptors on tool definitions, plugin tool metadata, before_tool_call/trusted-policy payloads, and Gateway tool catalog projections; related open items overlap but do not replace this focused API design request.

## What This Changes

Request to add optional tool behavior capability descriptors to built-in and plugin-registered tool definitions for policy, audit, documentation, and hook consumers.

## Best Possible Solution

Define one additive, documented policy-facts contract for tool behavior descriptors and project it through tool definitions, plugin metadata, hook/trusted-policy payloads, tool inventory, and Gateway schemas without treating third-party declarations as authorization.
