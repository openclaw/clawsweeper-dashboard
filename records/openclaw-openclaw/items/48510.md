## Summary

Keep open: current main still lacks optional behavioral capability descriptors on core tool definitions, plugin tool metadata, before_tool_call/trusted-policy events, and Gateway tool catalog projections; related issues and the open Security Matrix PR are adjacent rather than merged replacements.

## What This Changes

This issue requests optional self-declared behavioral capability descriptors on built-in and plugin tool definitions so policy, onboarding, docs, and audit consumers can reason without brittle tool-name lists.

## Best Possible Solution

Define one additive, documented policy-facts contract for tool behavior descriptors, project it through tool definitions, plugin metadata, inventories, Gateway protocol, and hook policy surfaces, and keep declarations advisory unless host authorization or explicit grants enforce them.
