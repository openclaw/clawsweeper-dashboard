## What This Changes

The PR changes Nextcloud Talk room-kind lookup failures from a cached group fallback into durable webhook deferral, retrying the lookup and caching only successful direct or group classifications.

## System Context

Nextcloud Talk receives Activity Streams webhook messages whose payloads lack a room type, so the inbound path queries Nextcloud before applying direct-message or group policy. The durable webhook spool owns the queue claim and must release it when that authoritative lookup temporarily fails so replay can deliver the message later.
