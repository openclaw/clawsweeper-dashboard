## Summary

Keep this PR open for a retry-contract fix: the new failed-lookup branch can return without scheduling a retry when its optional durable-ingress lifecycle is absent, so it can silently suppress an inbound message while logging that it was deferred.

## What This Changes

The branch replaces Nextcloud Talk's cached room-kind lookup failures with an explicit result, deferring inbound processing until a transient room-info lookup recovers.

## System Context

Nextcloud Talk webhooks enter the channel's inbound handler with a room token but no authoritative direct-versus-group classification. The handler queries Nextcloud room information before applying routing and access policy, then hands accepted messages to the channel dispatch pipeline.

## Best Possible Solution

Make room-info failure a durable-ingress outcome that cannot be mistaken for successful handling, then prove one failed replay is released and one recovered replay dispatches exactly once.
