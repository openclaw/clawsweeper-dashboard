Expose optional resolved outbound target context on the `message_sending` plugin hook so policy plugins can distinguish internal, external, and cross-context delivery targets.

## Best Possible Solution

Approve and document a narrow optional `message_sending` target-context contract that reuses canonical outbound resolver and cross-context policy facts without adding duplicate request-time discovery.
