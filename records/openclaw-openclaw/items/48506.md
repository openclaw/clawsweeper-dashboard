## Summary

Keep open: current main and v2026.6.11 still do not expose resolved target, externality, or cross-context facts on the public `message_sending` hook, and the remaining work is a Plugin SDK security-boundary decision rather than conservative cleanup.

## What This Changes

The issue requests optional resolved outbound target context on `PluginHookMessageSendingEvent` so policy plugins can reason about destination type, channel, cross-context delivery, and externality without reimplementing target resolution.

## Best Possible Solution

Approve a narrow optional `message_sending` target-context contract, then implement it from canonical outbound resolver and cross-context policy facts with SDK docs and focused hook/delivery tests.
