## Summary

Keep open: current main and the latest release still do not expose resolved target, externality, or cross-context facts on the public `message_sending` hook, and the remaining work is a Plugin SDK security-boundary/product decision rather than cleanup.

## What This Changes

The issue requests optional resolved outbound target context on the public `message_sending` plugin hook for DLP, allowlisting, compliance, and cross-context policy plugins.

## Best Possible Solution

Approve a narrow optional `message_sending` target-context contract, then implement it from canonical outbound resolver and cross-context policy facts with SDK docs and focused hook/delivery tests.
