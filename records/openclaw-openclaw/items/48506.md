## Summary

Keep open: current main and v2026.6.11 still expose only raw destination/content/routing metadata on `message_sending`, while resolved target and cross-context facts remain internal; the remaining work is a Plugin SDK and security-disclosure decision.

## What This Changes

The issue requests optional resolved target context fields on the public `message_sending` hook so plugins can enforce outbound and security policy without reimplementing target resolution.

## Best Possible Solution

Approve a narrow optional `message_sending` target-context contract, then populate it from canonical outbound resolver and cross-context policy facts with SDK docs and focused hook/delivery tests.
