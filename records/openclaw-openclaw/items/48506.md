## Summary

Keep open: current main and v2026.6.11 still do not expose resolved outbound target context on `message_sending`, and the remaining work is a public Plugin SDK plus security-disclosure decision rather than stale cleanup.

## What This Changes

Request to add optional resolved outbound target context to `PluginHookMessageSendingEvent` so policy plugins can distinguish internal, cross-context, and external destinations.

## Best Possible Solution

Approve a narrow optional `message_sending` target-context contract, then populate it from canonical outbound resolver and cross-context policy facts with SDK docs and focused hook/delivery tests.
