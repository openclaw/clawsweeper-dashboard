## What This Changes

The issue requests optional resolved outbound target context on the `message_sending` plugin hook for DLP, allowlisting, auditing, and cross-context policy plugins.

## Best Possible Solution

Approve a narrow optional `message_sending` target-context contract, then populate it from canonical outbound resolver and cross-context policy facts with SDK docs and focused hook/delivery tests.
