## Summary

Keep open: current main and v2026.6.11 still do not expose resolved target, externality, or cross-context facts on the public message_sending hook, and the remaining work is a Plugin SDK/security disclosure decision rather than stale cleanup.

## What This Changes

The issue requests optional resolved target context on the public message_sending plugin hook so security plugins can reason about outbound message targets without duplicating target-resolution logic.

## Best Possible Solution

Approve a narrow optional message_sending target-context contract, then implement it from canonical outbound resolver and cross-context policy facts with SDK docs and focused hook/delivery tests.
