## Summary

The revised branch fixes the previously reported relative-only regression, but it can still collapse a legitimate mixed absolute-and-relative multi-media directive into one nonexistent path. Keep this PR open for a narrow parser correction and regression coverage before merge.

## What This Changes

This PR changes reply `MEDIA:` parsing so an unquoted absolute local path containing spaces stays one attachment, while attempting to preserve separately listed media sources.

## System Context

Agent replies may contain `MEDIA:` directives that the media parser converts into attachment source strings before channel delivery. The parser must distinguish one local file path containing spaces from multiple requested attachments without changing which media items are sent.

## Architecture Diagram

  Attachments --> Delivery[Channel delivery]

## Best Possible Solution

Use a disambiguation rule that never merges independently valid later local media sources, and add coverage for mixed absolute-plus-relative directives alongside the spaced-path regression.
