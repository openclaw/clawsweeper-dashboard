Full review comments:

- **[P1] Reuse the guarded live catalog runtime:** `extensions/openai/discovery.ts:181-187`
  - body: This helper sends an OpenAI bearer token to a caller-derived `${baseUrl}/models` URL with raw `fetchFn`. Current main already has `provider-catalog-live-runtime` for guarded live model catalogs, including SSRF policy, timeout, bounded reads, fallback, and cache behavior, so this adds a second security-sensitive path.
  - confidence: 0.9
- **[P2] Scope the cache by the full auth identity:** `extensions/openai/discovery.ts:76-80`
  - body: `cacheKey()` keeps only the last eight characters of the API key, so two keys for the same base URL with the same suffix share a catalog. Tenant-scoped gateways can then silently show the wrong model list during the TTL.
  - confidence: 0.86
- **[P3] Keep test resets out of the public barrel:** `extensions/openai/api.ts:12`
  - body: `resetOpenAIDiscoveryCacheForTest` is test-only but is exported from the OpenAI plugin public `api.ts` barrel, which can accidentally make it part of the plugin contract.
  - confidence: 0.78
