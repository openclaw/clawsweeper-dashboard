## What This Changes

The PR adds `AgentId` to the heartbeat reply context and adds a regression test asserting global-scope secondary-agent heartbeats preserve the configured agent identity.

## Best Possible Solution

Keep the one-field identity handoff if live proof confirms that a secondary agent heartbeat under global scope uses the secondary agent workspace, session owner, and provider/auth configuration without changing the global session-key contract.

## Solution Assessment
