## Summary

Keep open: current main and v2026.6.11 still expose adjacent tool, transcript-message, session, and cron hooks, but no dedicated durable-state pre-write hook for memory, file, cron, config, or preference writes. This remains a coherent, security-sensitive Plugin SDK design item rather than conservative cleanup.

## What This Changes

The issue requests an additive `before_persistence_write` plugin hook for durable state changes that cross session boundaries.

## Best Possible Solution

Define one additive durable-write Plugin SDK contract with minimal redacted payloads, explicit ordering after before_tool_call, block or mutate semantics, bounded failure behavior, docs, API baseline updates, and focused coverage across representative writer paths.
