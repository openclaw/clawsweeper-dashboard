## Summary

Keep open: current main and v2026.6.11 still expose adjacent tool, transcript-message, cron, and session hooks, but no dedicated durable-state pre-write hook for memory, file, cron, config, or preference writes. This remains a coherent Plugin SDK security-boundary design item, with this issue acting as the canonical durable persistence hook thread.

## What This Changes

Request an additive Plugin SDK `before_persistence_write` hook that can inspect or block durable state writes before they cross session boundaries.

## Best Possible Solution

Define one additive durable-write Plugin SDK contract with minimal redacted payloads, explicit block or mutate semantics, ordering relative to before_tool_call, bounded failure behavior, docs, and representative writer coverage.
