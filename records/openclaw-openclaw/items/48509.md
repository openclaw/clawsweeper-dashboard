## Summary

Keep open: current main still has adjacent tool, message/transcript, session, and cron hook surfaces, but no generic pre-write Plugin SDK hook for durable memory, file, cron, config, or preference writes. This remains a coherent Plugin SDK and security-boundary design item rather than stale or already implemented work.

## What This Changes

The issue requests a new Plugin SDK hook that fires before durable state writes such as memory, file, cron, config, and preference changes.

## Best Possible Solution

Define one additive durable-write Plugin SDK contract with minimal redacted payloads, explicit block or mutate semantics, ordering relative to `before_tool_call`, bounded failure behavior, docs, and focused coverage across representative writer paths.
