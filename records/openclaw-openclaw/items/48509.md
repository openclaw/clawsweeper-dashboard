## Summary

Keep open: current main and v2026.6.11 still lack a dedicated durable pre-write hook; the current Plugin SDK exposes adjacent tool, transcript-message, session, and cron hooks, but not a generic pre-write boundary for memory, file, cron, config, or preference writes.

## What This Changes

The issue requests a Plugin SDK `before_persistence_write` hook that can block or audit durable state writes crossing session boundaries.

## Best Possible Solution

Define one additive durable-write Plugin SDK contract with minimal redacted payloads, explicit block or mutation semantics, ordering relative to existing tool/message hooks, bounded failure behavior, docs, and focused coverage across representative writer paths.
