## Summary

Keep open: current main and v2026.6.11 still expose adjacent tool, transcript-message, session, and cron hooks, but no dedicated durable-state pre-write hook for memory, file, cron, config, or preference writes. This remains a coherent Plugin SDK and security-boundary design item, with this issue acting as the canonical durable persistence hook thread.

## What This Changes

Request an additive Plugin SDK hook that fires before durable state writes crossing session boundaries and can block memory, file, cron, config, or preference persistence.

## Best Possible Solution

Define one additive durable-write Plugin SDK contract with minimal redacted payloads, block or mutate semantics, ordering relative to before_tool_call, bounded failure behavior, docs, and focused coverage across representative writer paths.
