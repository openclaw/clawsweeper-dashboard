## Summary

Keep open: current main and the latest release still expose adjacent tool, transcript-message, session, and cron hooks, but no generic durable-state pre-write hook. This remains a coherent Plugin SDK and security-boundary design item rather than conservative cleanup.

## What This Changes

The issue requests a new Plugin SDK `before_persistence_write` hook for memory, file, cron, config, preference, and other durable state writes.

## Best Possible Solution

Define a narrow additive durable-write Plugin SDK contract with redacted payloads, clear block or mutation semantics, ordering relative to existing hooks, bounded failure behavior, docs, and coverage across representative writer paths.
