## Summary

Keep open: current main still has tool and transcript hooks, but no generic durable-state pre-write hook for memory, file, cron, config, or preference writes; this remains the canonical Plugin SDK and security-boundary design item.

## What This Changes

Add a Plugin SDK hook that fires before durable memory, file, cron, config, or preference writes so plugins can audit or block cross-session state changes.

## Best Possible Solution

Settle one additive durable-write policy contract with minimized payloads, explicit block/mutate/failure semantics, docs, and representative coverage across file, memory, cron, config, and preference writers.
