## What This Changes

This PR makes `sessions.list` reuse request-scoped session-store discovery, batch ACP metadata reads, index active runs once, and memoize stable agent-database registry metadata to reduce repeated work per session row.

## System Context

The gateway serves Control UI session lists by combining session-store entries with sharing visibility, ACP metadata, and active-run state. This PR changes the data-preparation path before the gateway returns those rows, aiming to avoid repeating stable lookups for every row.
