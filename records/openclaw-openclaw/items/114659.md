## What This Changes

This PR makes `sessions.list` reuse request-scoped discovery and active-run data, batch ACP metadata reads, and memoize agent-database registry listings to avoid repeated filesystem and SQLite work for every returned session row.

## System Context

The gateway’s `sessions.list` handler gathers session rows for Control UI and other gateway clients, then enriches each row with sharing, ACP, and active-run state. This PR changes the per-request data preparation that feeds those row projections without changing the response shape.
