## Summary

Keep this PR open: the reported silence is valid and the branch has strong live proof, but one production-path edge case would expose a generic acknowledgment when the model supplied no message, so it is not merge-ready yet.

## What This Changes

The PR carries `sessions_yield` acknowledgment text through embedded and Codex run results and emits it for otherwise silent interactive initial and queued-followup turns.

## Best Possible Solution

Preserve whether `sessions_yield.message` was explicitly supplied, keep the existing default text for internal tool result and hidden continuation context, and synthesize a public acknowledgment only for an explicit nonblank message across both harnesses and both reply runners.
