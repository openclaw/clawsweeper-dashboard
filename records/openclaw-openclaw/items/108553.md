## Summary

The central fix is necessary and the live proof is strong, but the patch currently turns every `sessions_yield` call without an authored message into a visible generic “Turn yielded.” reply, contradicting its stated silent-without-message behavior.

## What This Changes

The PR propagates `sessions_yield` text through embedded and Codex attempt results and synthesizes it as a normal reply for otherwise silent interactive yielded turns, including queued followups.

## Best Possible Solution

Carry whether the model explicitly supplied non-blank yield text through the tool callback and attempt metadata, deliver only that authored acknowledgment, and add production-path tests for omitted messages in both embedded and Codex harnesses plus direct and queued-followup reply paths.
