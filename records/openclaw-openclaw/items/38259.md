## What This Changes

The issue requests expansion of `$VAR` and `${VAR}` references when OpenClaw loads workspace/global `.env` files, while preserving existing environment precedence.

## Best Possible Solution

Define and document a maintainer-approved dotenv expansion policy, then implement only that policy with focused precedence, trust-boundary, missing-reference, and service-env tests.
