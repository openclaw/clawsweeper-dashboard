- `maturity:stable`: The affected Gateway runtime dotenv/config startup surface maps to `gateway-runtime`, which is scored M4 Stable in `qa/maturity-scores.yaml`.

## Summary

Keep open: current main and the latest release still load dotenv values literally, and the merged state-dir service-env work only skips whole-value unresolved references rather than implementing general expansion. The remaining choice is security-sensitive because expansion changes which credentials can propagate across workspace, global, runtime, and service-env boundaries.

## What This Changes

The issue requests dotenv-style expansion for `$VAR` and `${VAR}` references loaded from OpenClaw `.env` files while preserving shell environment precedence.

## Best Possible Solution

Define one maintainer-approved dotenv expansion policy across workspace, global/state-dir, legacy gateway, config substitution, and service-env paths, then implement it with focused precedence and security tests or document literal dotenv values as intentional.
