## Summary

Keep open: current main and the latest release still load dotenv references literally, and the remaining question is a maintainer product/security decision because upstream dotenv does not expand variables by default and this affects credential-bearing env surfaces.

## What This Changes

The issue requests `$VAR` and `${VAR}` expansion when OpenClaw loads project and global `.env` files while preserving existing process-env precedence.

## Best Possible Solution

Approve or reject a single documented trusted-dotenv expansion contract, then implement it in the shared dotenv loader with tests for precedence, same-file references, unresolved references, workspace blocklist interaction, and literal dollar-containing secrets.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should OpenClaw support `$VAR` and `${VAR}` expansion in trusted/global dotenv loading, and if so should the same expansion apply only after the workspace `.env` security blocklist filters untrusted keys?

Rationale: The source issue is real, but expanding dotenv values changes credential interpretation and overlaps with existing SecretRef/config-substitution guidance, so automation should not choose the permanent env contract alone.

Likely owner: vincentkoc

Owner reason: Vincent Koc has the most recent current-main ownership signal on the dotenv/config env files and the latest release commit carrying the behavior.

Owner confidence: medium

Options:

- **Approve narrow trusted expansion (recommended):** Implement expansion in the shared dotenv loader after existing precedence and workspace blocklist rules, with docs and regression tests for literal-dollar secrets and unresolved references.
- **Reject dotenv expansion:** Keep dotenv values literal and document that users should use process env, config `${VAR}` substitution, or SecretRef-supported credential fields instead.
- **Defer to broader secret UX work:** Keep this issue open but block implementation until the env.vars SecretRef and first-class environment-backed secret direction is settled.
