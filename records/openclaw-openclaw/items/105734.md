## Summary

This PR remains necessary: current main reads only the workspace ClawHub lockfile when building skill status, while globally managed skills are tracked under the managed parent directory. The patch uses the loader-owned `openclaw-managed` source signal, handles symlinked installs, and has no supported equivalent on current main; however, the contributor’s new screenshot uses a manually mocked install rather than a genuine global ClawHub installation, so real-behavior proof remains insufficient before merge.

## What This Changes
