## What This Changes

The PR changes `voicecall tail --file` to advance by the actual number of bytes read and retain UTF-8 and unfinished-line state between initial and follow-mode reads.

## System Context

The Voice Call extension exposes a CLI command that can tail a user-specified JSONL debug log. The command reads appended file bytes, turns complete records into console output, and must preserve byte and UTF-8 boundaries between filesystem reads.
