## What This Changes

This PR fixes the Voice Call custom-log tail command so short filesystem reads, split JSONL records, and split UTF-8 characters are buffered and emitted correctly.

## System Context

The Voice Call plugin exposes a CLI command that either reads call history from SQLite or follows a user-supplied JSONL file. For custom files, the tail loop reads appended bytes and writes complete records to stdout for provider debugging and operational monitoring.
