## Summary

This PR remains necessary: the linked security report at https://github.com/openclaw/openclaw/issues/71211 is still open, while the branch adds the missing exec/process/node-host result-boundary redaction and marker behavior. The remaining blocker is a maintainer decision to make agent-visible command output redacted by default despite the deliberate loss of byte-exact output. **Likely related people:** `amknight` is the strongest routing candidate from the merged redaction work; `steipete` is a recent adjacent owner of the affected agent-test boundary.

## What This Changes

The branch redacts secret-shaped text and structured details returned by exec, process, node-host, live-update, and active-process tool-result surfaces, adding a visible warning and `redacted: true` marker when masking occurs.

## Best Possible Solution

Adopt a single redacted-by-default contract for agent-visible exec, process, and node-host results, retain the structured marker and warning, and design any raw-output capability later as an explicit security-reviewed product surface rather than a fallback.
