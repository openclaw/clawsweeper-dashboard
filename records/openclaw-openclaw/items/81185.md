## Summary

This remains a viable, well-proven candidate fix for the open exec-output exposure, but it is currently dirty against `main` and still needs an exec/runtime security-owner decision on the intentional redacted-by-default contract before merge.

## What This Changes

The PR redacts secret-shaped foreground exec, background process, node-host, live-update, and active-process output before returning it to agents, and adds a `redacted` marker plus a warning when masking occurs.

## System Context

OpenClaw’s exec and process tools run commands for an agent and return text plus structured details into that agent’s context. This PR changes the shared output-formatting boundary so secret-shaped command output is masked before downstream agent, process-control, and runtime-context consumers receive it.

Resolve the current merge conflict, preserve one shared redaction boundary across every agent-visible exec/process result surface, and land it only after an exec/runtime security owner accepts redacted-by-default output with any future raw-reveal behavior designed as an explicit opt-in.
