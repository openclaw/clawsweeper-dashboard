## Summary

Keep open: current main still lacks a first-class shell-facing `openclaw notify <message>` or equivalent admin-scoped Gateway event that renders visible notifications in connected Control UI sessions. Existing Web Push, `system event`, `chat.inject`, node-local notify, and task notify surfaces are adjacent but do not solve the requested no-agent-turn connected-UI notification path.

## What This Changes

Request a CLI or equivalent admin-scoped path that broadcasts a visible notification bubble to connected Control UI sessions without routing through an agent turn.

## Best Possible Solution

Define one typed admin-scoped notification contract first, then implement the CLI entry point, Gateway RPC/event guard, Control UI renderer, focused tests, and docs against that contract.
