## Summary

Keep open because current main has adjacent Web Push, Control UI notification settings, node-local notifications, and agent session event paths, but not the requested shell-facing admin command plus Gateway/UI event contract for pushing visible notifications to connected Control UI sessions.

## What This Changes

Request a core `openclaw notify <message>` admin command that pushes visible notifications to connected Control UI sessions without starting an agent turn.

## Best Possible Solution

Define one maintainer-approved notification contract that covers CLI authorization, Gateway event/RPC shape, UI rendering behavior, and how it composes with existing Web Push and broader WebUI notification work.
