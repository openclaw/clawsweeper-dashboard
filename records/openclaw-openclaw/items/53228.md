## Summary

## What This Changes

The issue requests an `openclaw notify <message>` command or equivalent admin-scoped shell path that shows visible notifications in connected Control UI sessions without creating an agent turn.

## Best Possible Solution

Define one intentional notification contract first: an authenticated admin RPC/event, Gateway broadcast scope guard, CLI entry point, visible Control UI renderer, and tests that distinguish it from `system event`, `chat.inject`, node notifications, and Web Push subscription tests.
