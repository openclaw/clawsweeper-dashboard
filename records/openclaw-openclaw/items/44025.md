Keep open: current main and the latest release still only support explicit flat model fallback lists, while provider-family wildcard/auto fallback selection and the commenter-proposed `fallbackFamilies` contract remain absent. The issue requests provider-family model fallback selection such as `provider/auto` or wildcard refs, with optional ordered family fallback groups before cross-provider router fallback.

## Best Possible Solution

Keep this issue open for a maintainer decision on one canonical provider-family fallback contract, then align schema, docs, fallback candidate construction, session/fallback availability checks, and focused regression coverage around that contract.

## Solution Assessment
