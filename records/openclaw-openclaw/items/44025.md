Request provider-family model fallback selection via wildcard/auto model refs and optional ordered family fallback lists before cross-provider fallback.

## Best Possible Solution

Pick one provider-family fallback contract, then update schema, docs, runtime candidate construction, fallback-availability gates, and doctor/config behavior around that contract.
