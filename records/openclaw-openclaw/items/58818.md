## Summary

Keep open: current main and v2026.6.11 have narrower continuity mechanisms, including Claude CLI raw-tail reseed opt-in and compaction recent-turn preservation, but they still do not provide the requested session-level guarantee that the last N raw messages survive both compaction and reset.

## What This Changes

Request a configurable session-level guarantee that at least the last N raw messages survive compaction and reset and are injected into new agent context.

## Best Possible Solution

Define a maintainer-approved continuity contract that bounds raw-tail replay, preserves auth/channel/thread and clean-reset boundaries, and adds cross-runtime regression coverage before adding config.
