## What This Changes

The PR adds two Ask OpenClaw hosted setup flows—workspace skills and web-search providers—so chat can collect wizard answers, guard persistent effects, mask gateway-entered secrets, and report plugin-install failures without writing misleading config or audit state.

## System Context

Ask OpenClaw parses an operator request into a system-agent directive, then its chat engine hosts selected onboarding wizards and commits validated configuration only after the live inference authority guard permits it. The resulting setup affects workspace skill dependencies or web-search provider configuration, while one-shot CLI mode redirects sensitive search setup to a masked terminal wizard.
