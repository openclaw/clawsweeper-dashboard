## Summary

This PR remains necessary because current main still misclassifies Signal daemon lines split across process-output chunks. The patch is narrowly owned, matches Node stream behavior, has focused regression coverage and sufficient real-daemon proof, and has no blocking correctness or security finding.

## What This Changes

The PR buffers Signal daemon stdout and stderr into complete lines before severity classification and adds regression coverage for split chunks, CRLF/LF delimiters, and a final unterminated line.

## Best Possible Solution

Land the plugin-owned complete-line framing for both Signal daemon streams, retaining the focused regression and real-daemon evidence while leaving classification, lifecycle, configuration, and delivery contracts unchanged.
