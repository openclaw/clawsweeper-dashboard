## Summary

The requested goal-level autonomous orchestration is useful, but OpenClaw’s roadmap explicitly assigns heavy orchestration to plugins or companion projects, and current plugin command, TaskFlow, subagent, cancellation, and lifecycle surfaces are sufficient to build it without adding a core command.

## What This Changes

Add a `/loop` command that autonomously plans, executes, verifies, retries, and reports multi-step work within token, iteration, boundary, and interruption limits.

## Best Possible Solution

Publish this as a ClawHub plugin or plugin-plus-skill bundle that registers `/loop`, composes TaskFlow and subagents, persists resumable state through supported storage, and enforces cancellation, iteration, token, permission, and boundary checks; verify manifest metadata, entrypoint, permissions, secrets/config, install/update docs, example usage, and live smoke proof. ClawSweeper should not open a ClawHub issue or PR, create a tracking issue, publish the package, or act on the contributor’s behalf.
