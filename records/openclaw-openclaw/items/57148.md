## Summary

Keep open: current main and the latest release still pass subagent and harness task-completion result text into parent-session internal events without a dedicated cap. The issue is valid at source level, but the requested public config key/default is a product/API decision rather than a strict bug-fix lane.

## What This Changes

Request to cap or truncate subagent completion result text before it is injected into the parent session, preferably via a `session.maxSubagentResultChars` configuration key.

## Best Possible Solution

Choose the cap contract first, then bound both OpenClaw subagent and plugin harness task-completion handoffs while preserving prompt-data wrapping and documenting any public config under existing context-limit surfaces.
