## Summary

## What This Changes

The PR changes the process `send-keys` success response to report the UTF-8 byte length of the encoded key string instead of its UTF-16 code-unit length.

## Best Possible Solution

Keep the focused UTF-8 calculation and merge it after redacted live process output demonstrates multibyte `send-keys` input and the corrected response; a targeted regression assertion would further preserve the invariant.
