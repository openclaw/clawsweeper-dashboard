## What This Changes

Prevent unavailable or stale Codex native-hook relay state from declining command approvals when the effective runtime policy is full-auto, while preserving explicit denials and fail-closed malformed responses.

## Best Possible Solution

Land a narrowly scoped fix that passes the effective full-auto state into native-hook evaluation, ignores only unavailable or stale relay state in that mode, still runs the normal before-tool-call hook, and preserves explicit-denial and malformed-response blocking with focused regression and live app-server proof.

## Solution Assessment

Yes in principle: making relay unavailability non-authoritative only for the already-established full-auto policy is narrower than weakening relay denials globally, provided the linked PR proves explicit denial and malformed responses remain blocking.
