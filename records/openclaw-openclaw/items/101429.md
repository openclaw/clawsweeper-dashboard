## Summary

Keep open: current main still buffers workspace ignore files with an unbounded `readFileSync`, and the PR now preserves the symlink-chain compatibility issue raised in the previous review. The remaining merge question is whether maintainers accept silently treating over-cap ignore files as unreadable during scans.

## What This Changes

The PR replaces unbounded shared ignore-file reads with a 4 MiB bounded regular-file read, resolves symlink chains before reading, and adds focused regression tests.

## Best Possible Solution

Merge the shared bounded-read implementation after maintainer acceptance that over-cap ignore files should be treated like unreadable files; otherwise revise the policy to add diagnostics, streaming parsing, or a different threshold.
