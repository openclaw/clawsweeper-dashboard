## Summary

This PR is still necessary because current main retains the unbounded read, but the final head introduces a blocking fallback: an oversized ignore policy becomes equivalent to no policy across recursive resource scanners. That can make previously excluded workspace resources discoverable, so the prior concern remains unresolved.

## What This Changes

The PR replaces unbounded workspace ignore-file reads with a 4 MiB bounded regular-file read, preserves chained-symlink behavior, and adds five focused tests.

## Best Possible Solution

Keep the byte bound, return a distinct oversized result, and make each recursive scanner prune or stop the affected subtree before enumeration; add caller-level proof that content excluded by an oversized policy is not discovered.
