## Summary

Keep this PR open, but do not pass it yet. It fixes the earlier direct fs-safe import concern and adds a real byte cap, but the current patch also changes symlinked ignore files from followed to silently skipped and only provides unit-test proof rather than a live workspace-scan run.

## What This Changes

The PR adds a 4 MiB cap to workspace ignore-file reads by switching `addIgnoreRules` to `readRegularFileSync` and adds focused ignore-rule tests.

## Best Possible Solution

Keep the bounded read, but preserve current ignore-file semantics for symlinked ignore files or explicitly approve and test a regular-file-only policy, then add live workspace-scan proof.
