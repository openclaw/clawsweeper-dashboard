## Summary

This PR remains necessary, but the prior P1 blocker is unchanged on the same reviewed head: an oversized ignore file is treated as though no ignore policy exists, so workspace scanning continues into content the operator excluded.

## What This Changes

Bounds workspace ignore-file reads at 4 MiB, preserves symlink-chain resolution, and adds focused ignore-rule tests.

## Best Possible Solution

Keep the bounded regular-file reader, but make an oversized ignore policy conservatively stop or exclude the affected scan subtree and cover that behavior with an end-to-end scanner regression.
