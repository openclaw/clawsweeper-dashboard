## Summary

The resource bound is valuable and well proven, but the prior merge-blocking finding remains on the current head: over-cap inputs silently lose all exclusions, broadening several workspace scan paths without a diagnostic. The PR should remain open for an explicit failure-policy decision and corresponding caller-level repair.

## What This Changes

The PR replaces unbounded ignore-file reads with a 4 MiB bounded regular-file read, preserves single and chained symlinks, and adds five regression tests.

## Best Possible Solution

Keep the race-safe bounded reader and symlink preservation, but return a closed oversized-file result and have every scan owner either stop the affected traversal with an actionable diagnostic or explicitly warn before continuing.
