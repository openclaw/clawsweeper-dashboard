## Summary

The memory bound is worthwhile and well-proven, but the latest head still silently drops oversized exclusion policy across recursive skill and package scans; this should not merge until the shared failure contract is made safe.

## What This Changes

The PR replaces unbounded workspace ignore-file reads with a 4 MiB bounded regular-file read, preserves symlink-chain behavior, and adds five regression tests.

## Best Possible Solution

Keep the bounded read, return a closed result that distinguishes over-limit from ordinary absence, and make recursive scan entry points stop safely or skip the affected subtree with an actionable warning rather than silently widening traversal.
