## Label Justifications

## Summary

The previously reported fail-open and cross-file-negation defects are resolved, and the final-head standalone proof covers the real scan path. This PR should remain open because the intentional 4 MiB terminal fail-closed policy still needs explicit owner approval before merge.

## What This Changes

Caps shared workspace ignore-file reads at 4 MiB, excludes the affected subtree when the cap is exceeded, preserves symlink handling, and adds focused regression tests.

## Best Possible Solution

Keep the bounded read in the shared ignore-rule owner, preserve final-target symlink semantics, and land a terminal fail-closed fallback only after an owner approves the threshold and ensures users receive a visible diagnostic when a subtree is excluded.
