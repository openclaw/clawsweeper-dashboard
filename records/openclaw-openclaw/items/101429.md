## Summary

Keep open: the current head has no actionable correctness defect and has strong behavioral proof, but merging intentionally makes oversized ignore files terminally hide a workspace subtree, so a core owner must approve that compatibility policy.

## What This Changes

The PR replaces unbounded ignore-file reads during workspace scans with a 4 MiB bounded reader, terminally excludes subtrees whose ignore policy is oversized, preserves symlink handling, and adds regression tests.

## Best Possible Solution

Use the shared bounded regular-file helper with one explicit oversized-policy contract that preserves existing symlink semantics; the current implementation is a sound end state if the core owner accepts terminal subtree exclusion at 4 MiB.
