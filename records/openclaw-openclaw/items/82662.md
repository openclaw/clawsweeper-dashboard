## Summary

Keep open. Current `main` and the latest release still use the fixed 60s isolated-agent setup watchdog that can produce the reported pre-runner timeout, while the focused fix candidate at https://github.com/openclaw/openclaw/pull/96219 is still open and needs maintainer acceptance of the longer setup-window tradeoff.

The issue reports memory-core managed isolated `agentTurn` cron jobs failing with `setup timed out before runner start` before any model call, with provider fallback attempts all exhausting on the same setup-phase timeout.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/96219, or an equivalent bounded setup-watchdog fix, if maintainers accept the cron-capacity tradeoff while keeping backend-specific cron failures on their own trackers.
