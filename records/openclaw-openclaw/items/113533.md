## Summary

Keep this PR open for maintainer review. Current `main` explicitly retains the flat delivery-key and scalar streaming readers for bundled channels that still use those shapes and for external SDK plugins; the latest supplied release is `v2026.7.1`, while the removal’s warning/deprecation window is described as `v2026.7.2`-gated. The branch therefore removes supported behavior before the documented compatibility boundary has closed.

## What This Changes

This PR deletes legacy flat/scalar channel-streaming compatibility readers, keeps Doctor migration to nested `streaming.*` configuration, and removes the deprecated group-introduction adapter from the channel plugin API.

## System Context

Channel configuration reaches schema validation and then feeds channel delivery, auto-reply, ACP relays, and plugin-SDK helpers. Doctor converts older saved configuration into the canonical nested form, while the channel streaming module currently preserves selected compatibility reads for channels and external plugins that still rely on them.
