## Summary

Keep open: the reported failure is well supported and the live proof is strong, but the current head is not merge-ready because the released lifecycle compatibility path remains incorrect for concurrent out-of-order completion.

## What This Changes

The PR tracks the oldest active channel run, projects its start time into account snapshots, and uses that age to classify long-running disconnected work as stuck.

## Best Possible Solution

Separate exact handle-aware accounting from conservative anonymous compatibility behavior so only identity-known active runs publish `activeRunStartedAt`.
