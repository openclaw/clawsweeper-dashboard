## Summary

Current main still allows heartbeat updates to keep a disconnected hung channel classified as busy indefinitely. The latest PR head fixes that shared health decision at the queue-owned run-lifecycle boundary, preserves the public lifecycle callbacks, resolves every prior review finding, and has no remaining correctness blocker.

## What This Changes

The PR adds a private oldest-active-run timestamp to channel queue status and uses it in the shared gateway health policy to bound the healthy-busy override by actual run age.

## Best Possible Solution

Keep run identity private to the shared queue, publish only the oldest active start through the existing snapshot, and apply the already-established stale ceiling in the single shared health policy with the monitor's existing cooldown and hourly restart cap.
