## Label Justifications

- `P1`: The issue describes a real agent/channel safety gap where model-issued tool calls can modify files, send messages, or execute host actions before the user can answer a visible confirmation question.
- `impact:data-loss`: The missing gate can allow unintended file edits, deletes, or config mutations when the model emits a risky tool call alongside confirmation text.
- `impact:security`: The request is about enforcing a human-consent boundary before sensitive tool execution instead of relying on model narration or prompt compliance.

## Summary

Keep open: current main still has lower-level plugin `before_tool_call.requireApproval`, trusted tool policies, and exec approvals, but it does not implement the requested built-in `tools.confirmation` config, deterministic risk-tier classifier, or same-response assistant-text-aware hold before the first tool executes. The only matching implementation PR, https://github.com/openclaw/openclaw/pull/85872, was closed unmerged as an unmergeable stacked branch.

## What This Changes

Request a configurable tool-level confirmation gate that can pause risky tool calls before execution and require human approval, especially when assistant text asks for confirmation in the same response.

## Best Possible Solution

Define a backward-compatible core confirmation design with deterministic tool/action risk classification, explicit approve/deny/timeout semantics, transcript handling for skipped calls, docs/config/schema coverage, and regression tests that preserve existing plugin approval hooks.

## Reproduction Assessment

Yes, at source level. Current main has strict config schemas without `tools.confirmation`, a before-tool hook event without assistant text, and tool execution continues immediately after existing hook approval/block checks.

## Solution Assessment

Unclear until maintainers choose the product and security semantics. A core confirmation gate is a plausible right layer, but the proposed text-question heuristic should be replaced or constrained by deterministic authorization and risk-tier rules.
