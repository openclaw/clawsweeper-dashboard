## Summary

Keep open: current main still has exec and plugin approval primitives, but no built-in configurable response-level confirmation gate that can pause risky same-response tool calls before execution.

## What This Changes

Request to add a configurable runtime confirmation gate that can pause risky tool calls before execution when assistant text and tool calls appear in the same model response.

## Best Possible Solution

Design a core confirmation policy that composes with existing plugin approvals, uses deterministic risk and current-turn authorization signals, flushes visible assistant text before holding tools, and documents approve, deny, timeout, transcript, and channel behavior with regression coverage.

Rationale: Source inspection shows the missing gate, but the permanent policy defines a new authorization boundary and config contract that automation cannot safely choose.

Owner confidence: medium

Options:

- **Design core gate (recommended):** Approve a maintainer-led core design with disabled-by-default config, deterministic risk/current-turn authorization rules, explicit approve/deny/timeout behavior, and regression coverage around existing plugin approvals.
- **Keep plugin-only:** Leave core behavior unchanged and require operators to implement contextual approvals through before_tool_call.requireApproval or trusted tool policies, accepting no built-in same-response confirmation gate.
- **Fold into broader policy work:** Wait for related action-level deny, response-gate, and HITL interrupt designs to settle into one authorization model before adding a new config surface.

## Reproduction Assessment

Yes, at source level: current main has no tools.confirmation type/schema and the tool execution path proceeds after existing lower-level hooks when they do not block; I did not run a destructive live scenario.

## Solution Assessment

Unclear until maintainers choose the policy. A runtime gate between parsed tool calls and execution is the right layer, but text-pattern auto-confirm should be constrained or replaced by deterministic risk/current-turn authorization signals.
