## Summary

Keep open: current main and the latest release have exec and plugin approval primitives, but they do not provide the requested configurable response-level tool confirmation gate before the first risky tool call executes.

## What This Changes

The issue requests a configurable risk-aware tool confirmation gate that can pause same-response tool calls for human approval before execution.

## Best Possible Solution

Define a maintainer-approved core confirmation policy that is disabled by default, schema-validated, documented, and composed with existing plugin, trusted-policy, and exec approval flows before any risky tool executes.
