## Summary

This PR remains necessary: current `main` truncates providerless-model warning values at C0/DEL but not residual C1 controls, allowing visible suffix text after a C1 byte to appear in the warning and suggested config value. The one-line fix matches the existing containment invariant and has no correctness defect, but this external PR still requires after-fix real behavior proof before merge.

## What This Changes

The PR adds the C1 control range (`0x80`–`0x9f`) to the first-control truncation predicate used for providerless-model warning values.

## Best Possible Solution

Keep the narrow C1 predicate extension, add a providerless-model warning regression case with a residual C1 byte followed by visible suffix text, and show redacted live warning output where that suffix is no longer echoed.
