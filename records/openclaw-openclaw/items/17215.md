## Summary

Keep open: current main and v2026.6.11 have adjacent doctor lint, post-upgrade plugin probes, update dry-run, plugin convergence, and rollback docs, but they still do not provide the requested unified pre/post-update scanner with risk scoring, smoke recommendations, or rollback hints.

## What This Changes

The issue requests a native pre/post-update compatibility scanner with schema checks, smoke recommendations, risk-scored JSON and human reports, and rollback hints.

## Best Possible Solution

Define a maintainer-owned `openclaw update` and/or `openclaw doctor --upgrade-scan --json` contract that composes doctor lint, post-upgrade plugin probes, update dry-run/convergence, targeted smoke checks, redacted risk scoring, and rollback guidance into one documented operator workflow.
