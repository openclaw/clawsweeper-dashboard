Status: needs_attention

Summary: This issue is security-sensitive because scanner reports, smoke checks, and rollback hints need explicit redaction, non-destructive execution, and safe recovery semantics.

Concerns:

- **[medium] Define report redaction and sensitive-field handling:**

  - confidence: 0.88
