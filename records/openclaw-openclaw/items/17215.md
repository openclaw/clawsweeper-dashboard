## Summary

Keep open: current main and v2026.6.11 have useful adjacent update/doctor pieces, but they still do not provide the requested unified pre/post-update compatibility scanner with risk scoring, smoke recommendations, and rollback hints.

## What This Changes

The issue requests a built-in `doctor --upgrade-scan` style upgrade scanner with pre-update checks, post-update smoke checks, risk-scored JSON/human reports, and rollback recommendation hints.

## Best Possible Solution

Define a maintainer-owned `openclaw update` and/or `openclaw doctor --upgrade-scan --json` contract that composes existing doctor lint, post-upgrade plugin probes, update dry-run/convergence, health/status checks, redacted risk scoring, smoke guidance, and rollback guidance into one documented operator workflow.

## Solution Assessment
