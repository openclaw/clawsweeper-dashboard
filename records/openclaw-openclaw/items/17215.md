## Summary

## What This Changes

The issue requests a native `doctor --upgrade-scan` style scanner for pre/post-update compatibility checks, risk-scored JSON/human reports, smoke recommendations, and rollback guidance.

## Best Possible Solution

Define a maintainer-approved upgrade assessment contract that composes existing doctor lint, config migration, update dry-run, plugin post-upgrade probes, plugin convergence, health/status, backup, and rollback guidance with explicit redaction and smoke-check semantics.
