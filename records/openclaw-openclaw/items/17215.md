## Summary

Keep open: current main and the latest release have adjacent doctor lint, plugin-only post-upgrade probes, update dry-run planning, plugin convergence checks, and rollback guidance, but they still do not provide the requested unified pre/post-update compatibility scanner with risk scoring, smoke recommendations, and rollback hints.

## What This Changes

The issue requests a built-in `doctor --upgrade-scan` style scanner that checks upgrade compatibility before and after updates and emits risk reports, smoke recommendations, and rollback guidance.

## Best Possible Solution

Define a maintainer-approved upgrade assessment layer that composes existing doctor lint, config migration, update dry-run, plugin post-upgrade probes, plugin convergence, health/status, backup, and rollback guidance with explicit redaction and non-destructive smoke-check semantics.
