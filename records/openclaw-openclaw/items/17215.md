## Security Review

Status: needs_attention

Summary: The future scanner needs explicit security review for report redaction, non-destructive smoke checks, and safe rollback guidance.

Concerns:

- **[medium] Define report redaction and sensitive-field handling:**
  - body: Machine-readable upgrade reports need an explicit redaction contract so support artifacts do not leak tokens, private endpoints, credential locations, local paths, provider account details, or channel identifiers.
  - confidence: 0.9
- **[medium] Keep smoke checks explicit and non-destructive:**
  - body: Recommended smoke checks should not send channel-visible messages, mutate durable sessions, execute tools, or spend provider quota unless the operator explicitly opts into that behavior.
  - confidence: 0.88
- **[medium] Bound rollback advice to safe recovery policy:**
  - body: Rollback hints can be unsafe if they suggest restoring incompatible state or credentials across versions without a version-aware recovery and backup policy.
