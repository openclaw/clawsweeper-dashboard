## Summary

Keep open: current main and v2026.6.11 have adjacent doctor lint, plugin-only post-upgrade probes, update dry-run, and post-update plugin convergence, but not the requested unified pre/post-update compatibility scanner with risk scoring, smoke recommendations, and rollback hints.

## What This Changes

The issue requests a native `doctor --upgrade-scan` style workflow that checks upgrade compatibility before and after updates and emits human and JSON risk reports with smoke and rollback guidance.

## Best Possible Solution

Define a maintainer-owned `openclaw update` and/or `openclaw doctor --upgrade-scan --json` contract that composes doctor lint, post-upgrade plugin probes, update dry-run/convergence, targeted smoke checks, redacted risk scoring, and rollback guidance into one documented operator workflow.
