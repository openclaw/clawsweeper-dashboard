## Summary

Request a native upgrade compatibility scanner that runs before and after updates, reports config/plugin/runtime risks in JSON and human form, and recommends smoke tests or rollback actions.

Define a maintainer-owned upgrade compatibility contract that composes existing doctor lint, post-upgrade plugin probes, update dry-run/convergence, static plugin smoke, health/status, backup state, redacted risk scoring, and rollback guidance behind one stable CLI/JSON surface.
