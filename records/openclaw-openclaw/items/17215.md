## Summary

## What This Changes

## Best Possible Solution

Define one maintainer-approved upgrade assessment contract that composes existing doctor, update dry-run, plugin compatibility, config migration, health/status, backup, and rollback guidance surfaces with explicit redaction, severity, JSON, and smoke-check semantics.
