## Summary

Keep open: current main and the latest release still use env-marker-only Windows Scheduled Task detection, and the open linked PR is the active fix candidate rather than merged implementation.

## What This Changes

The issue asks for Windows channel `/restart` to produce a real gateway process restart when a Scheduled Task exists but the running process lacks the service marker environment.

## Best Possible Solution

Review or revise https://github.com/openclaw/openclaw/pull/95095 so env-less Windows Scheduled Task gateways detect the exact task they will hand off to, prove the PID-changing restart on Windows, and leave broader schtasks failure recovery to https://github.com/openclaw/openclaw/issues/90158.
