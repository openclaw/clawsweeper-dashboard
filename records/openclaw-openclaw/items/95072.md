## Summary

Keep open: current main and the latest release still use env/service-marker-only Windows Scheduled Task detection, and the open linked PR remains the active candidate for the env-missing restart case.

## What This Changes

The issue asks for Windows `/restart` to use the Scheduled Task restart path when a task exists but service environment markers are missing, instead of reporting success while only doing an in-process restart.

## Best Possible Solution

Review, repair if needed, and land or reject https://github.com/openclaw/openclaw/pull/95095 as the canonical fix, preserving the safe Scheduled Task handoff without restoring unmanaged detached Windows respawn.
