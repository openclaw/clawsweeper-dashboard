## Summary

Keep open: current main has Google Play distribution and local signed third-party APK archive tooling, but GitHub Releases still do not publish an official standalone Android APK asset, so the remaining request is a maintainer-owned release-channel, signing, provenance, and security decision.

## What This Changes

Request official prebuilt Android APK downloads in OpenClaw GitHub Releases so Android users do not need to build the companion app locally.

## Best Possible Solution

Define a maintainer-approved standalone Android APK distribution policy, then either publish the signed third-party APK with provenance/checksums and docs or explicitly document Google Play-only support plus endorsed alternatives.
