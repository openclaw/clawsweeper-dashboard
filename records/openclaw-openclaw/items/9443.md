## Summary

Keep open: current main has Google Play distribution and local signed third-party APK archive tooling, but GitHub Releases still do not publish an official standalone Android APK asset, so the remaining work is a maintainer-owned release-channel, signing, provenance, and support decision.

## What This Changes

Request prebuilt official Android APK downloads in GitHub releases so users do not need Android Studio, the Android SDK, or local build knowledge.

## Best Possible Solution

Define a maintainer-approved standalone Android APK distribution policy, then either publish the signed third-party APK with provenance/checksums and docs or explicitly document Google Play-only support plus endorsed alternatives.
