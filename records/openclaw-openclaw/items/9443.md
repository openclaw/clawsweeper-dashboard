## Summary

Keep open: current main now has official Google Play distribution and local signed third-party APK archive tooling, but GitHub Releases still do not publish an official standalone Android APK asset, so the remaining request is a maintainer-owned release-channel, signing, provenance, and security decision.

## What This Changes

Request official prebuilt Android APK downloads in GitHub Releases or another non-Play channel so users can install without Android build tooling.

## Best Possible Solution

Define an explicit standalone Android APK distribution policy, then either publish the signed third-party APK with provenance/checksums and docs or document Google Play-only support plus any endorsed alternatives.
