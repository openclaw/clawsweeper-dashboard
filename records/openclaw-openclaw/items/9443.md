## Summary

Keep open: current main and the latest stable release now have Google Play distribution plus local signed third-party APK archive tooling, but GitHub Releases still do not publish an official standalone Android APK asset, so the remaining request needs maintainer release-channel, signing, provenance, and support-policy direction.

## What This Changes

The issue requests official prebuilt Android APK downloads in GitHub Releases or another non-Play install channel for users who cannot or do not want to build the Android app from source.

## Best Possible Solution

Define a maintainer-approved standalone Android APK distribution policy, then either publish the signed third-party APK with checksums/provenance and docs or explicitly document Google Play-only support plus any endorsed alternatives.
