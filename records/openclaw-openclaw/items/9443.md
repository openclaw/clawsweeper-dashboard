## What This Changes

The issue requests official prebuilt Android APK downloads, preferably built and uploaded by release automation for GitHub Releases or another non-Play channel.

## Best Possible Solution

Define a maintainer-approved standalone Android APK distribution policy, then either publish the existing signed third-party APK archive with provenance/checksums and docs or explicitly document Google Play-only support plus any endorsed alternatives.
