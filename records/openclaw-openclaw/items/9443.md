## Summary

Keep open: current main supports Google Play distribution and local signed third-party APK archiving, but it still does not publish an official standalone Android APK through GitHub Releases, and the recent workflow candidate was closed unmerged.

## What This Changes

Request official prebuilt Android APK downloads in GitHub Releases, preferably produced and uploaded by release automation.

## Best Possible Solution

Publish maintainer-approved signed standalone APKs through the existing Android release/signing lane to GitHub Releases or F-Droid, or explicitly document Google Play as the only official Android channel with a non-technical path for no-GMS users.

## Reproduction Assessment

Yes. Source and release inspection show current docs point to Google Play/source builds, current tooling only archives the third-party APK locally, and current stable/beta GitHub releases do not include an APK.

## Solution Assessment

No complete fix is on main yet. The best implementation should reuse the existing Android signing/archive lane and publish only maintainer-approved signed artifacts, rather than adding a parallel ad hoc workflow.
