## Label Justifications

## Summary

Keep this PR open, but it needs one focused repair before merge: the new empty-map backfill turns a valid settled-empty verdict state or a failed verdict request into repeated `skills.securityVerdicts` retries on later gateway snapshots.

## What This Changes

The PR loads ClawHub security verdicts after route-provided Skills reports and renders a neutral Pending badge while verdict retrieval is in flight.

## Best Possible Solution

Represent verdict hydration completion separately from the verdict map, retrying only a skipped disconnected/no-client attempt while preserving settled-empty and error outcomes until the report or gateway scope changes.

## Reproduction Assessment

Yes from source: provide a linked report, let `skills.securityVerdicts` settle empty or reject, then deliver another gateway snapshot; the new empty-map condition invokes the loader again.

## Solution Assessment

No. Reusing the loader is appropriate, but an empty object cannot distinguish a skipped disconnected attempt from a completed empty or failed request; a completion/outcome marker is the narrower durable fix.
