## Summary

Keep this PR open, but do not merge the current head: source-derived root expansion can still re-authorize a sibling sandbox directory, so the central isolation guarantee remains bypassable despite the stronger proof added to the PR body.

## What This Changes

## Best Possible Solution

Apply the sandbox isolation filter after every root-expansion step: reject source-derived parents under the shared sandboxes tree unless they are contained by the trusted exact active sandbox workspace, thread that workspace through every legitimate caller, and prove both sibling rejection and owning-session delivery with root expansion enabled.
