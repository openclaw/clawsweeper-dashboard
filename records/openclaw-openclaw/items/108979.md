## Summary

Keep this PR open for explicit security-boundary and compatibility approval. The patch appears technically correct and the updated terminal proof demonstrates that the owning sandbox remains readable while a sibling sandbox is rejected through production authorization code, but removing sandbox access from every agent-scoped caller without exact sandbox context is an intentional fail-closed contract change that CI alone cannot approve.

## What This Changes

The PR removes the shared sandboxes parent from agent-scoped media roots, optionally permits the exact active sandbox workspace, threads that context through outbound media access, and adds regression coverage.

## Best Possible Solution

Keep the shared sandbox parent out of all agent-scoped authorization, pass an exact active sandbox workspace or prepared media-access capability through every legitimate sandbox-media flow, and retain regression proof that owning-session media succeeds while sibling-session media fails.
