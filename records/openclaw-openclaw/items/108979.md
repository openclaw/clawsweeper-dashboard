## Summary

The earlier fail-open branch is fixed, but this PR still does not close the reported security boundary: agent-scoped callers without active sandbox context retain the shared sandboxes parent, so sibling-session media can remain authorized outside the two narrowed message-action paths.

## What This Changes

Adds optional exact-sandbox narrowing to agent-scoped media roots, passes the active sandbox root through message actions and outbound media access, and adds root-list regression coverage.

## Best Possible Solution

Make shared sandbox-parent access unavailable by default for every agent-scoped media authorization path, explicitly add only the exact active session workspace where known, and prove both sibling rejection and owning-session media flows across all affected callers.
