## Summary

Keep this PR open for revision: the security hardening is valuable, but the new narrowing is skipped whenever agent identity or workspace resolution is unavailable, so the helper can still return the shared sandboxes parent despite receiving the exact active sandbox path.

## What This Changes

Adds an optional active sandbox workspace path to agent-scoped media authorization, threads it through outbound message actions, and adds root-list regression tests.

## Best Possible Solution

Make agent-scoped roots exclude the shared sandboxes parent by construction and add only the exact active session workspace through explicit context, with authorization tests covering resolved and unresolved agent identity plus the message-action caller.
