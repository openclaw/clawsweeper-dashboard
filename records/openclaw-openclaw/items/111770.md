## What This Changes

The PR changes Anthropic OAuth response-body decoding to use a fatal UTF-8 `TextDecoder`, rejecting malformed bytes instead of silently substituting U+FFFD.

## Best Possible Solution

Keep the fatal decoder at the shared Anthropic OAuth response boundary and land it once the normal PR checks complete, preserving the existing caller-level OAuth failure handling.
