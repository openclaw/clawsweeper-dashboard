  - confidence: 0.9
- **[P2] Skip assignment words before downloader matching:** `src/security/skill-scanner.ts:487-493`
  - body: `isDownloadCommandSegment()` returns on the first token that is not `sudo`, `doas`, or `env`; shell assignment prefixes such as `HTTPS_PROXY=http://p curl ... | bash` execute the downloader but are rejected before `curl` is checked. That leaves a practical bypass for the new critical Markdown rule.
  - confidence: 0.86
- **[P2] Fold shell pipe continuations in Markdown commands:** `src/security/skill-scanner.ts:354-361`
  - body: `logicalMarkdownLines()` only joins backslash continuations, but shells also continue a pipeline when a line ends with `|`. A fenced command split as `curl ... |` followed by `bash` will execute as one pipeline while this matcher sees two unrelated lines and emits no finding.
  - confidence: 0.84
- **[P3] Remove the release-owned changelog entry:** `CHANGELOG.md:14`
