## Summary

This PR remains necessary as a bug-fix attempt, but the current fallback is unsafe: it converts an unknown Funnel state into “no route,” contradicting the shipped `preserveFunnel` contract and potentially disrupting operator-managed exposure.

## What This Changes

The PR catches malformed `tailscale funnel status --json` output, returns `false` instead of throwing, and changes the focused unit-test expectation accordingly.

## Best Possible Solution

Model Funnel inspection as covered, uncovered, or unknown; on unknown output, emit a diagnostic and skip route-changing Serve/reset actions, with tests for all three outcomes and real Tailscale proof that an external route remains intact.
