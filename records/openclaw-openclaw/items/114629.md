## What This Changes

This PR makes SDK channel metadata lookup fall back from the bundled channel catalog to the active plugin registry, with tests for bundled, third-party, and unknown channel ids.

## System Context

Channel plugins provide metadata used by message-action helpers such as `describeMessageTool`. The SDK currently reads bundled-channel metadata first; this patch lets it also read a properly registered active third-party channel before returning a clear error for an unknown id.
