## Summary

Keep open: current main and the latest release still provide adjacent macOS menu-bar HoverHUD, WebChat, Canvas, Talk, and session activity surfaces, but not configurable floating per-agent desktop bubbles with persisted placement and click-to-chat routing.

## What This Changes

Request configurable native macOS floating bubbles, one per running agent, with names, drag/anchor or mouse-follow placement, persisted state, and click-to-chat routing.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator, or a native UI plugin API, that reads canonical agent/session activity, persists placement through an approved owner, supports accessible click-through and drag behavior, and routes chat to the selected agent/session.
