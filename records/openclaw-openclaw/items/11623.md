Request a native macOS floating bubble surface that shows one visible agent orb per running agent and opens chat for that agent.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator or native UI plugin/API that derives bubble state from canonical agent/session activity, persists placement through an approved state owner, and routes chat to the selected agent/session.
