## Summary

Current main has native macOS WebChat, Gateway event, and multi-agent identity/routing surfaces, but no configurable floating per-agent desktop bubbles, persisted positions, mouse-follow behavior, or direct per-bubble chat routing. The existing maintainer discussion explicitly keeps the proposal open pending a macOS product decision.

## What This Changes

Add native always-on-top macOS bubbles for active agents, with agent identity, repositioning, anchoring or mouse-follow behavior, and direct agent-targeted chat.

## Best Possible Solution

Define a maintainer-sponsored macOS design covering bubble lifecycle, agent/session identity, routing, persistence, accessibility, and window behavior, then implement it within the native app only if that interaction model is approved.
