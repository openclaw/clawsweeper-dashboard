## Summary

Keep open: current main and v2026.6.11 still have adjacent macOS HoverHUD, WebChat, TalkOverlay, and session-menu surfaces, but not configurable floating per-agent desktop bubbles with persisted positions, drag/anchor or mouse-follow behavior, and per-agent chat launch/routing. This remains a macOS product-direction item, not conservative cleanup.

## What This Changes

The issue requests native macOS floating per-agent bubbles that show agent identity, support drag/anchor or mouse-follow behavior, and open chat for the selected agent.

## Best Possible Solution

Define a maintainer-approved native macOS bubble/window coordinator, or a native macOS UI plugin API, that reads canonical agent/session activity, persists placement through an approved state owner, handles accessible click-through and drag behavior, and routes chat to the selected agent/session.
