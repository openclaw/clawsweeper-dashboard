## Summary

Keep open: current main still has adjacent macOS HoverHUD, menu status, and WebChat panel/window surfaces, but not configurable floating per-agent desktop bubbles with persisted placement, drag/anchor or mouse-follow behavior, and per-agent chat routing. The remaining work is a native macOS product/API decision, not a conservative cleanup close.

## What This Changes

The issue requests native macOS floating per-agent bubbles that show agent names/activity, persist placement, support drag/anchor or mouse-follow behavior, and open chat for the selected agent.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator, or a native UI plugin API, that reads canonical agent/session activity, persists placement through an approved owner, supports accessible click-through and drag behavior, and routes chat to the selected agent/session.
