Keep open: current main and v2026.6.11 still have adjacent macOS HoverHUD, Canvas, WebChat, activity, and session-menu surfaces, but not configurable floating per-agent desktop bubbles with persisted placement, mouse-follow/anchor behavior, and click-to-agent chat routing.

## What This Changes

Request a native macOS floating bubble UI, Clawi, that shows one movable per-agent orb and launches chat for the selected agent.

## Best Possible Solution

Define a maintainer-approved native macOS bubble/window coordinator or native macOS window plugin API that derives bubble state from canonical agent/session activity, persists placement through an approved state owner, and routes chat to the selected agent.

## Reproduction Assessment

Not applicable as a bug: this is a new macOS capability request, not a failing existing behavior. Source inspection gives high confidence that the requested floating-bubble surface is absent on current main and the latest release.

## Solution Assessment

Unclear until maintainers choose the product direction. Native SwiftUI/AppKit is a plausible owner, but persistence, click-through behavior, accessibility, activity state, and chat routing need a maintainer-designed contract rather than an autonomous patch.
