## Summary

Keep open: current main still has adjacent macOS HoverHUD, WebChat, Canvas, voice overlay, and session-state surfaces, but it does not implement configurable floating per-agent desktop bubbles with click-to-chat, persisted placement, drag/anchor or mouse-follow behavior. The remaining work is a native macOS product/API decision, not conservative cleanup.

## What This Changes

The issue requests native macOS floating bubbles for each running agent, showing agent identity/status and supporting click-to-chat, drag or anchor placement, mouse-follow behavior, and persisted state.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator, or a native UI plugin API, that reads canonical agent/session activity, persists placement through an approved owner, supports accessible click-through and drag behavior, and routes chat to the selected agent/session.
