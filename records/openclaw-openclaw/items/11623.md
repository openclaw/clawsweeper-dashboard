The issue requests a native macOS floating bubble UI for each running agent, with persisted placement, drag/anchor or mouse-follow behavior, and click-to-chat routing.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator or native UI plugin/API that derives bubble state from canonical agent/session activity, persists placement through an approved state owner, and routes chat to the selected agent.
