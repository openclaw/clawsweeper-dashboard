## Summary

Keep open: current main and the latest release still have adjacent macOS HoverHUD, WebChat, Canvas, activity, and session-menu surfaces, but not configurable floating per-agent desktop bubbles with persisted placement and per-agent chat routing.

## What This Changes

The issue requests native macOS floating bubbles for running agents, with labels, drag or anchor behavior, mouse-follow mode, persisted state, and click-to-chat entrypoints.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator, or a native UI plugin API, that reads canonical agent/session activity, persists placement through an approved owner, supports accessible click-through and drag behavior, and routes chat to the selected agent/session.
