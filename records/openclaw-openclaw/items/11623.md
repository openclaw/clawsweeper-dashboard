## Summary

Current main provides adjacent menu-bar activity, session context, HoverHUD, and WebChat surfaces, but not the requested persistent per-agent desktop bubbles. The recent maintainer discussion also explicitly keeps this feature open pending a macOS product and interaction decision.

## What This Changes

Add native macOS floating bubbles for active agents, with per-agent identity, chat launch, dragging, anchoring or mouse-follow behavior, and persisted placement.

## Best Possible Solution

Define a native macOS contract that derives bubble lifecycle from canonical agent/session activity, routes chat through the existing WebChat session path, persists only UI preferences in the established app-owned store, and specifies accessibility, focus, window-level, Spaces, drag, anchor, and Reduce Motion behavior before implementation.
