## Summary

Keep open for maintainer product direction. The request remains a distinct native macOS interaction model—not an established bug—and the supplied prior review found only adjacent menu-bar and WebChat surfaces rather than per-agent floating bubbles; current roadmap treats companion apps as a next priority while keeping optional work plugin-first when viable.

## What This Changes

Add configurable floating macOS bubbles for individual agents, with drag/anchor or follow interactions, persisted placement, and direct chat routing to the selected agent.

## Best Possible Solution

Choose a supported macOS interaction model first; if first-party, design a bounded native window/state layer that derives agent activity and opens the existing agent-targeted chat path, and if externalization is preferred, define the minimum stable macOS UI extension API before asking for a plugin.
