Keep open: current main and the latest release still provide adjacent macOS HoverHUD, WebChat, Canvas, Talk, and menu/session surfaces, but not configurable floating per-agent desktop bubbles; the remaining work needs maintainer product direction.

## What This Changes

Request to add native macOS floating per-agent bubbles with visible agent names, persisted positioning, click-to-chat routing, and drag/anchor or mouse-follow behavior.

## Best Possible Solution

Define a maintainer-approved macOS bubble/window coordinator, or a native UI plugin API, that reads canonical agent/session activity, persists placement through an approved owner, supports accessible click-through and drag behavior, and routes chat to the selected agent/session.
