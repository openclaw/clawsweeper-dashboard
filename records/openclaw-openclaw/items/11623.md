## What This Changes

Request to add native macOS floating per-agent bubbles that show running agent names, persist placement, support drag/anchor or mouse-follow behavior, and open chat for the selected agent.

## Best Possible Solution

Define a maintainer-approved native macOS bubble/window coordinator, or a native macOS UI plugin API, that reads canonical agent/session activity, persists placement through an approved state owner, handles accessible click-through and drag behavior, and routes chat to the selected agent/session.
