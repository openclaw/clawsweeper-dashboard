## Summary

Keep open: current main and the latest release still have Skill Workshop proposal storage, static scanning, apply-time write checks, rollback, CLI, Gateway, and agent-tool surfaces, but no pre-apply runtime validation command, tool action, or RPC.

## What This Changes

The issue requests automated pre-apply runtime validation for Skill Workshop proposals, including discovery/load checks, schema visibility, optional invocation, and proposal health reporting.

## Best Possible Solution

Define a bounded Skill Workshop validation contract first, then implement one shared service surfaced through CLI, Gateway, and the agent tool with load/schema checks and invocation only under explicit side-effect rules.

- **Fold into broader dry-run design:** Keep this open but implement it only after the broader skills/cron/tool dry-run contract is settled in https://github.com/openclaw/openclaw/issues/13617.
