## Summary

Keep open: current main still has Skill Workshop proposal storage, static scanning, stale-target checks, rollback, CLI, and agent-tool lifecycle actions, but no pre-apply runtime load/schema/invocation validation. The broader lifecycle-contract issue is related, not a safe canonical replacement for this concrete runtime gate.

## What This Changes

The issue requests a Skill Workshop test phase that validates proposed skills can load, expose valid tool schema, and optionally run safe representative behavior before apply.

## Best Possible Solution

Design a narrow Skill Workshop-owned proposal health gate: candidate registry load and schema validation first, optional invocation only under an explicit safe-input and side-effect policy, with pass/fail/skipped status recorded before apply.
