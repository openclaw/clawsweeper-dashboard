## What This Changes

The issue requests an optional Skill Workshop runtime validation phase that loads a proposed skill, verifies its tool schema, and, when safe, invokes representative behavior before apply.

## Best Possible Solution

Define a bounded Skill Workshop validation contract first, then wire one shared service through CLI, Gateway, and the agent tool with load/schema checks and isolated invocation only where the side-effect boundary is clear.
