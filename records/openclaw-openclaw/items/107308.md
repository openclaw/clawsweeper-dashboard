## Summary

Close as a duplicate of the prior cross-session transcript-browsing request: the reported one-day boundary is the documented automatic session rollover, while current-session history already has a paginated retrieval path.

## What This Changes

Requests loading older messages when scrolling beyond the visible day of chat history, without the user explicitly running `/new` or `/reset`.

## Best Possible Solution

Keep paginated loading scoped to the active session, and if maintainers revisit cross-session browsing, sponsor the canonical transcript-browser direction with explicit session boundaries and archived-session selection rather than presenting prior sessions as one continuous active transcript.
