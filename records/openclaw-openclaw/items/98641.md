## Summary

Current main and the latest release already provide deterministic TUI clean-exit paths for automation through `/exit`, Ctrl+D on an empty editor, and SIGTERM/SIGHUP handling, so harnesses do not need to race on the armed Ctrl+C render state.

## What This Changes

The issue requests a stable TUI automation contract for armed-quit synchronization or deterministic clean exit.

## Best Possible Solution

Keep the existing `/exit`/Ctrl+D/SIGTERM clean-exit paths as the supported automation contract rather than adding a separate armed-Ctrl+C marker.
