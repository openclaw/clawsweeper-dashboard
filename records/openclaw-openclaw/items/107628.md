## What This Changes

Make Discord agent delivery and subagent announcements resolve named channel targets consistently with message sending and persist the canonical destination for recovery.

## Best Possible Solution

Resolve targets once through the shared outbound resolver before agent or session routing, persist only the canonical resolved destination for recovery, and keep Discord normalization limited to distinguishing numeric targets from names rather than duplicating resolver policy.
