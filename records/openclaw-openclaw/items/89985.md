## Summary

This PR remains necessary because current `main` does not preserve or replay local packaged `dist` overrides. The patch is well-proven and has no concrete correctness finding, but merging it would establish a new supported update, compatibility, and executable-replay contract that requires explicit maintainer approval. ## What This Changes

Preserves locally modified packaged `dist` files across updates, adds opt-in trusted replay, introduces content-integrity inventories with legacy-package compatibility, and updates the CLI, docs, release checks, and regression coverage.

## Best Possible Solution

Adopt a documented recovery-first contract: preserve modified packaged files by default, allow replay only through explicit trusted opt-in, and retain fail-closed identity, content, topology, conflict, and rollback verification.
