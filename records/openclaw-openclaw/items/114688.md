## Summary

Keep this PR open. The previous bridge-count finding is addressed, but `costUsd` still prices usage accumulated from retries or fallbacks using only the final model’s pricing, so the advertised whole-run cost can be wrong; it also still needs redacted real CLI output before merge.

## What This Changes

This PR adds additive `codeModeEngaged`, `assistantTurns`, `bridgeCalls`, and estimated `costUsd` fields to embedded-agent metadata and the `openclaw agent exec --json` envelope.

## System Context

Embedded agent runs collect model-attempt usage and tool-surface events, then prepare terminal metadata consumed by `openclaw agent --json` and `openclaw agent exec --json`. This change projects additional run telemetry from those attempt-level signals into the public CLI JSON responses.

## Architecture Diagram

flowchart LR
  A[Agent run] --> B[Model attempts]
  B --> C[Usage and run-stat accumulator]
  B --> D[Final reported model]
  C --> E[Terminal metadata preparation]
  D --> E
  E --> F[agent JSON response]
  E --> G[agent exec JSON envelope]

## Best Possible Solution

Accumulate estimated cost at each model attempt using that attempt’s resolved pricing, retain the existing omission semantics when no priced usage exists, add a different-priced fallback regression test, and attach redacted live JSON output after the repair.
