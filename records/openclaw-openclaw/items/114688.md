## Summary

Keep this PR open for repair and maintainer review. Its new JSON fields are documented as per-run aggregates, but the patch only retains bridge-call counts from the final attempt and estimates all accumulated retry usage using the final reported model's pricing; fallback or retry runs can therefore report misleading operational and cost data.

## What This Changes

This PR adds code-mode engagement, assistant-turn, bridge-call, and estimated-cost statistics to embedded-agent metadata and mirrors them on `openclaw agent exec --json`, with CLI and code-mode documentation.

## System Context

The embedded agent runner executes one or more model attempts, accumulates terminal metadata, and returns it to the agent CLI. The proposed fields turn internal tool-surface, subscription, catalog, usage, and pricing facts into machine-readable run-envelope telemetry for CLI consumers.

## Best Possible Solution

Accumulate per-attempt bridge counters and cost at each attempt's resolved model pricing, then project those run-level totals only after retries and terminal finalization complete; retain the documented omission behavior when pricing is unavailable.
