## Summary

Keep open: current main and latest v2026.6.11 still preserve active/background exec work during normal SIGTERM shutdown, while the merged websocket-close fix addressed only an adjacent shutdown hang. The child-process handle shutdown policy remains unresolved.

## What This Changes

The issue asks OpenClaw to avoid dirty gateway shutdowns when active child-process handles block cleanup and to define whether shutdown should detach, cancel, or debug those child processes.

## Best Possible Solution

Define a normal gateway stop contract that rejects new work, bounds active run and session drains, cancels managed exec/process scopes before the watchdog, and documents any preserved background-process exception.
