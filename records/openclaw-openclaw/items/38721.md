## Summary

The remaining child-process shutdown policy needs maintainer direction and live Ubuntu/systemd proof.

## What This Changes

The issue asks OpenClaw to stop gateway shutdown timeouts caused by referenced child-process handles and clarify whether shutdown should cancel or preserve those child processes.

## Best Possible Solution

Define an owner-approved normal gateway stop contract that rejects new work, bounds active run/session drains, cancels managed exec/process scopes before the watchdog, and documents any preserved background-process exception.
