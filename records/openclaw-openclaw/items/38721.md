## Summary

This should stay open: current main and v2026.6.11 still preserve active/background exec work during normal shutdown, while the merged websocket-close fix at https://github.com/openclaw/openclaw/pull/61565 covered a different shutdown blocker.

## What This Changes

The issue requests a fix for dirty gateway shutdowns when referenced child-process and pipe handles keep the Node process alive after SIGTERM/SIGINT.

## Best Possible Solution

Define one gateway stop contract that rejects new work, bounds active run/session drains, cancels managed exec/process scopes before the watchdog, and documents any background-process exception maintainers choose to preserve.
