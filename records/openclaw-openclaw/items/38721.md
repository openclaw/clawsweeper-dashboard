## Summary

Keep open: current main and latest v2026.6.11 still preserve active/background exec work during normal SIGTERM shutdown, while the merged websocket-close fix only addressed an adjacent shutdown hang. The child-process shutdown policy remains unresolved and needs maintainer direction plus live Ubuntu/systemd proof.

## What This Changes

Report that OpenClaw 2026.3.2 gateway shutdown can hit the watchdog while Node diagnostic reports show active child-process and pipe handles, leaving dirty shutdown and lane waits.

## Best Possible Solution

Define a normal gateway stop contract that rejects new work, bounds active run and session drains, cancels managed exec/process scopes before the watchdog, and documents any preserved background-process exception.
