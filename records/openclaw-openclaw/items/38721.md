## Summary

Keep open: current main and latest v2026.6.11 still have the dirty-shutdown watchdog and intentionally preserve active/background exec work on normal SIGTERM, while https://github.com/openclaw/openclaw/pull/61565 only bounded websocket close. The child-process shutdown policy remains unresolved.

## What This Changes

The issue asks OpenClaw to resolve or diagnose gateway shutdown timeouts caused by referenced child-process and pipe handles that can leave dirty shutdowns and lane waits after supervised stops.

## Best Possible Solution

Define a normal gateway stop contract that rejects new work, bounds active run and session drains, cancels managed exec/process scopes before the watchdog, and documents any preserved background-process exception.
