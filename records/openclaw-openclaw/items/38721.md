## Summary

Keep open: current main and v2026.6.11 still keep normal shutdown separate from the restart-only active-run drain/abort path, so the reported child-process shutdown timeout is not resolved by the merged websocket shutdown fix at https://github.com/openclaw/openclaw/pull/61565.

## What This Changes

The issue asks OpenClaw to avoid dirty gateway shutdowns when active child or exec process handles outlive SIGTERM/SIGINT and leave lane waits.

## Best Possible Solution

Define and document a normal gateway stop contract that rejects new work, bounds active run and session drains, then either cancels or explicitly preserves managed process scopes before the watchdog with live Ubuntu systemd proof.
