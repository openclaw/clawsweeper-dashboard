## Summary

## What This Changes

The issue asks OpenClaw to investigate and fix gateway shutdown timeouts where active child-process handles leave dirty shutdowns and lane waits.

## Best Possible Solution

Define a normal gateway stop contract that rejects new work, bounds active run/session drains, cancels managed exec/process scopes before the watchdog, and documents any preserved background-process exception.
