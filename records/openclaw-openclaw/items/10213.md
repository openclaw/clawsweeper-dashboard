## Summary

Current main and v2026.6.11 still lack Anthropic-native server-side compaction, and both implementation PRs closed unmerged. Keep this focused tracker open because the capability is valid, but the public configuration owner and pause-after-compaction agent-loop behavior require maintainer direction before implementation.

## What This Changes

Add opt-in Anthropic server-side context compaction with request configuration, compaction-block replay, streaming and stop-reason handling, logging, tests, and documentation.

## Best Possible Solution

Add an opt-in Anthropic provider-owned model/run-parameter path that injects the current beta request fields, preserves typed compaction blocks through streaming and replay, handles pause and usage semantics deliberately, and leaves non-Anthropic and default local compaction unchanged.
