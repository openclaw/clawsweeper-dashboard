## Summary

The feature is still absent from current main and the latest release, while both prior implementation PRs are closed unmerged. Keep this focused tracker open for a maintainer decision because Anthropic’s current compaction contract is broader than request injection and the public configuration plus pause semantics remain product choices.

## What This Changes

Add opt-in Anthropic-native server-side compaction with provider request configuration, compaction-block round-trip handling, terminal-state and usage support, logging, tests, and documentation.

## Best Possible Solution

Add a typed Anthropic-provider capability using the pinned SDK contract: opt-in threshold/pause/instructions, correct beta and request construction, verbatim compaction block/delta persistence and replay, usage accounting, explicit agent-loop handling, focused docs/tests, and a redacted live Anthropic proof.
