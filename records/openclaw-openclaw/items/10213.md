## Summary

Keep this focused tracker open. Current main and v2026.6.11 still lack Anthropic-native server-side compaction, and the previous implementation PRs closed unmerged; the remaining blocker is a maintainer decision on the public configuration owner and initial agent-loop semantics.

## What This Changes

Add opt-in Anthropic-native server-side context compaction, including request configuration, compaction-block replay, response handling, and diagnostics.

## Best Possible Solution

Add semantic model-scoped parameters owned by the bundled Anthropic provider, gate them to direct supported Anthropic models, preserve typed compaction blocks through streaming and history replay, and initially omit pause-after-compaction unless maintainers explicitly approve its continuation semantics.
