## What This Changes

Add opt-in Anthropic-native server-side compaction with request configuration, compaction-block history round-trip, stop-reason and usage handling, logging, tests, and documentation.

## Best Possible Solution

Add one provider-owned, opt-in Anthropic compaction capability that uses the current API contract, preserves compaction blocks through history and streaming, handles the stop reason and iteration usage, and leaves all non-Anthropic and existing Anthropic defaults unchanged.
