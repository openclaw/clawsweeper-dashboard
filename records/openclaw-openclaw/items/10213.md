## What This Changes

Add an opt-in Anthropic server-side compaction integration that configures the provider request and preserves provider-generated compaction state across turns.

Add a provider-scoped, opt-in Anthropic model-parameter path that injects the current compaction contract only for supported direct Anthropic routes, round-trips compaction blocks through native transport history, and leaves existing local compaction unchanged.
