Keep open. Current main and latest release still keep session transcript recall experimental and opt-in, while open related work leaves privacy, visibility, QMD export, duplicate-indexing, and ranking/source-policy questions unresolved.

## What This Changes

## Best Possible Solution

Keep `sessionMemory` opt-in until maintainers define the stable transcript source, visibility, privacy, cost, QMD export, and duplicate-indexing contract; then graduate the config/docs and decide default-on separately.
