## Summary

Keep open: current main and the latest release still resolve Telegram approval prompts with `clear-actions`, which removes buttons but leaves the delivered approval text in chat; the known same-repo fix attempts are closed unmerged, and the remaining linked fork PR is open but conflicting.

## What This Changes

The issue reports that Telegram exec approval prompts remain visible in chat after the user clicks approve.

## Best Possible Solution

Adopt or replace the linked fork PR with a narrow Telegram adapter fix that returns `delete` for resolved approvals, implements `transport.deleteEntry` through `deleteMessageTelegram`, preserves `clear-actions` for expired approvals, and adds focused tests plus Telegram-visible proof.

## Reproduction Assessment

Yes. Source inspection on current main shows resolved Telegram approvals return `clear-actions`, and the shared runtime explicitly says that action leaves delivered content in place.

## Solution Assessment

Yes. The maintainable fix is to use the existing shared `delete` final-action seam for resolved approvals and leave expired approvals on the existing button-only `clear-actions` path.
