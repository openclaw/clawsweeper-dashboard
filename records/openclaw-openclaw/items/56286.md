The issue requests that Telegram exec approval messages be removed from chat after approval instead of leaving stale approval prompts visible.

## Best Possible Solution

Keep this issue as the canonical bug and land a narrow fix in `extensions/telegram/src/approval-handler.runtime.ts` that uses the shared `delete` final action for resolved approvals while preserving button-only cleanup for expired approvals.
