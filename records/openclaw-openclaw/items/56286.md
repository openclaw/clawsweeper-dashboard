The issue reports that Telegram exec approval prompts remain visible in chat after the user clicks approve.

## Best Possible Solution

Fix the active Telegram native approval runtime so resolved approvals use the shared `delete` final-action path, expired approvals keep button-only clearing, and the fix includes focused tests plus redacted real Telegram proof.

Yes, source-level: current main resolves Telegram approvals with `clear-actions`, and the shared runtime leaves delivered content in place for that action. I did not run a live Telegram bot flow in this read-only review.

## Solution Assessment
