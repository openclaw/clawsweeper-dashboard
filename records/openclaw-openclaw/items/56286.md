## What This Changes

The issue reports that Telegram exec approval messages remain visible after the user approves an exec request, instead of disappearing from chat.

## Best Possible Solution

Fix the active Telegram native approval runtime so resolved approvals use the shared `delete` final-action path, expired approvals keep button-only clearing, and the branch includes focused tests plus redacted real Telegram proof.
