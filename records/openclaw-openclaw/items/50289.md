- `impact:crash-loop`: The reported 15-27 second message delays and lane wait warnings can make affected Gateway deployments effectively unavailable even without a process crash.

## Summary

Keep open: current main and v2026.6.11 still use per-authorization array walks and `Array.includes` checks for large `commands.ownerAllowFrom` lists, and all linked fix PRs are closed unmerged, so this remains a valid narrow fix candidate.

## What This Changes

The issue reports severe Gateway slowdown when `commands.ownerAllowFrom` has about 9,000 entries because command authorization repeatedly normalizes and linearly checks the list.

## Best Possible Solution

Add a narrow command-auth optimization that compiles or caches normalized owner authorization state and membership Sets per stable raw array plus provider/plugin/account, while preserving the existing `commands.ownerAllowFrom` config contract.
