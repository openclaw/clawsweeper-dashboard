## Summary

Keep open: current main and v2026.6.11 still walk large `commands.ownerAllowFrom` arrays and use linear owner membership checks, while https://github.com/openclaw/openclaw/pull/100362 is an open closing fix candidate that has not merged.

## What This Changes

The issue reports severe Gateway latency when `commands.ownerAllowFrom` contains thousands of entries because owner allowlist normalization and sender membership checks scale linearly.

## Best Possible Solution

Review and land a narrow command-auth fix that caches or compiles normalized owner authorization state and Set membership for stable config snapshots, then close this issue after that fix reaches main.
