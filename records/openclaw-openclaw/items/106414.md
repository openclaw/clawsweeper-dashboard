## What This Changes

The PR makes text-model fallback list and mutation commands accept agent scope, rejects agent scope for image fallbacks, and adds corresponding tests and CLI documentation.

## Best Possible Solution

Make every validated explicit `--agent` fallback mutation materialize or update that agent's `agents.list[].model.fallbacks`, reserve global writes for commands without agent scope, and move the write helper to a core-internal module that is not plugin-SDK exported.
