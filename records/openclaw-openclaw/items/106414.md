## Summary

## What This Changes

The PR makes text-model fallback list/add/remove/clear operations agent-aware, rejects agent scope for image fallbacks, and adds unit, CLI, end-to-end, and documentation coverage.

## Best Possible Solution

Make --agent create or update an explicit per-agent fallback override while keeping no-agent operations global, retain clear rejection for agent-scoped image fallbacks, and cover both fresh and upgrade behavior with focused tests and CLI documentation.
