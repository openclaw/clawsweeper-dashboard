## Summary

Keep this maintainer draft open, but the current implementation should not merge as-is because it represents an entire Claude CLI turn as one event under the existing per-model-call diagnostics contract. The extensive lifecycle coverage is useful, and the feature can remain viable after the telemetry boundary is clarified.

## What This Changes

The PR adds synthetic Claude Code CLI model-call diagnostics for one-shot, managed-stdio, and paired-node execution, plus OpenTelemetry export coverage, lifecycle tests, and tracing documentation.

## Best Possible Solution

Keep model.call request-scoped and represent the observable Claude CLI lifecycle with a dedicated turn or harness span linked to the agent trace; only emit model-call events when actual request-level boundaries can be established truthfully.
