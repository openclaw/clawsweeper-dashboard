## What This Changes

This PR splits OpenClaw’s heartbeat runner into five typed stages for wake admission, preparation, agent invocation, outcome classification, and finalization while intending to preserve existing delivery and state-write behavior.

## System Context

The heartbeat runner receives scheduled or system-triggered wakes, selects the applicable agent/session work, invokes the agent, then records outcomes and delivers any resulting messages. This refactor changes the orchestration layer that preserves ordering between agent execution, message delivery, and heartbeat state updates.
