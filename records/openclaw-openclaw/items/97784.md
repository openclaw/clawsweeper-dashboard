## What This Changes

The PR replaces seven MS Teams Graph upload, sharing, driveItem, chat lookup, and chat-member success `res.json()` calls with `readProviderJsonResponse` and adds loopback tests for normal, malformed, and oversized JSON responses.

## Best Possible Solution

Land the narrow helper reuse after maintainers accept the shared 16 MiB fail-closed cap for graph-upload success responses, while keeping adjacent MS Teams raw-reader hardening in separate PRs.
