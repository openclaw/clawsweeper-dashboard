## Label Justifications

- `P2`: The PR fixes a bounded gateway lifecycle race that can restart a channel during shutdown or health-monitor reload.

## Summary

Current main still permits an in-flight health-monitor restart to continue after shutdown or reload retires that monitor. The proposed post-await guard is narrowly placed, preserves normal recovery behavior, has no actionable review finding, and remains necessary despite the branch being behind current main.

## What This Changes

Adds a stopped-state recheck after an awaited channel stop and regression tests for manual and AbortSignal retirement during an in-flight health-monitor restart.

## Best Possible Solution

Land the focused post-await retirement guard with both lifecycle regression cases so an old monitor cannot mutate restart state or start a runtime after gateway ownership moves on.
