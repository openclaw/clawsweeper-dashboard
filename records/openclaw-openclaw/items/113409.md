## What This Changes

The branch preserves bounded, redacted local-provider error causes during isolated cron preflight and includes that reason when a scheduled job continues with a fallback model.

## System Context

Isolated cron jobs select a model, preflight local provider endpoints, and then either run the chosen model, skip with a diagnostic, or select a configured fallback. This PR changes the diagnostic path between the provider probe and the operator-facing cron warning.
