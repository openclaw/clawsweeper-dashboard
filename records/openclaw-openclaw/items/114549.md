## What This Changes

The PR fences Android and iOS gateway reconnect, approval refresh, background-timer, and push-to-talk cleanup to the connection or audio-capture generation that started the work, with regression tests for cancelled work not changing a replacement lifecycle owner.

## System Context

OpenClaw’s Android and iOS apps maintain gateway connections and realtime voice capture while the app moves between foreground and background. Native cancellation and cleanup callbacks feed those lifecycle owners; this PR tries to ensure retired callbacks cannot disconnect, publish failure for, or release resources belonging to a replacement session.
