## Summary

The patch is a narrow, still-needed fix on current main: malformed managed-image JSON is still collapsed into the same null result as a missing file. The ENOENT-only classification is technically sound, but this external PR still lacks after-fix real gateway proof, and the shared reader also feeds message-attachment retention, so maintainers should confirm that sibling path while reviewing the controlled 500 behavior.

## What This Changes

Changes `readManagedImageRecord` to return null only for ENOENT and propagate corrupt JSON or other record-read failures.

## Best Possible Solution
