## What This Changes

This PR makes WhatsApp classify buffer uploads with a filename but no explicit content type from the filename extension, and lets `.ogg` or `.opus` audio receive the native voice MIME type.

## System Context

OpenClaw normalizes outbound media before the WhatsApp plugin gives it to the WhatsApp transport. The resolved media kind and MIME type determine whether recipients receive a document, image, video, audio item, or native voice note.
