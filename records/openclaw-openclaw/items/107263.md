## What This Changes

The PR makes qmd subprocess stdout and stderr decoding stateful across pipe chunks, adds mocked and real-child-process UTF-8 regressions, and removes a stale Vitest fast-path entry.

## Best Possible Solution

Land one canonical stateful UTF-8 decoding path inside the memory-host qmd process owner, retaining both real-process fragmentation tests and the existing cap, abort, timeout, and nonzero-exit contracts.
