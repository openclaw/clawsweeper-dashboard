Requests browser SSRF private-network confirmation, allow/block policy, and temporary grant controls so agents can reach local resources only with explicit operator approval.

Keep this open for maintainer security design, preferably choosing a staged browser SSRF policy with non-overridable metadata semantics, upgrade-safe config, focused tests, and interactive approval only after prompt/session behavior is defined.
