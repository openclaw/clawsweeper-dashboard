- **[P1] Block Basic proxy auth on cleartext WebSockets:** `apps/ios/Sources/Gateway/GatewayConnectionController.swift:824-826`
  - body: The new proxy header is built regardless of the gateway URL scheme, while manual gateways can still be configured with `Use TLS` off.   - confidence: 0.86
- **[P2] Carry proxy auth into share relay sends:** `apps/ios/Sources/Model/NodeAppModel.swift:2653-2660`
  - body: The main app now saves a share relay config after connecting, but that config still contains only URL, token, and password.   - confidence: 0.88
- **[P2] Sync the native i18n inventory:** `apps/ios/Sources/Design/SettingsProTabSections.swift:843-850`
  - body: These new user-visible Settings strings are not reflected in `apps/.i18n/native-source.json`; the PR's `native-i18n` check fails with inventory drift. Run the native i18n sync and commit the updated inventory with the new proxy strings.
