Report that an isolated cron agent run can hit `EmbeddedAttemptSessionTakeoverError` when session cleanup renames its active transcript to `.deleted.*` before final message delivery.

## Best Possible Solution

Make cron/session cleanup lifecycle-aware so it skips or drains active admitted work before archiving/removing transcripts, with focused regression coverage for an isolated cron run through final delivery.
