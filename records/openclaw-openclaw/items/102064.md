## Summary

Keep open: current main still prunes expired cron run-session entries without consulting active session-work admissions, and the broader run-lifecycle landing did not change this cron reaper path.

## What This Changes

The issue reports intermittent cron-spawned isolated agent sessions failing when retention cleanup renames their active `.jsonl` transcript to `.deleted.*` during final delivery.

## Best Possible Solution

Make cron/session cleanup lifecycle-aware so it skips or drains active admitted run identities before archiving or removing transcripts, with focused regression coverage for an isolated cron run through final delivery.
