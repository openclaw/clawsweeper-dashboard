- `maturity:stable`: The affected gateway/session lifecycle surface maps to `gateway-runtime`, which is scored M4 Stable in `qa/maturity-scores.yaml`.

## Summary

Keep open: current main still has a cron run-session reaper path that archives `.jsonl` transcripts from stale `:run:` entries without checking active session-work admissions, while current isolated cron execution is intentionally admitted through execution and final delivery.

## What This Changes

The issue reports intermittent `EmbeddedAttemptSessionTakeoverError` when cron-spawned isolated agent session cleanup renames an active transcript to `.deleted.*` before final message delivery completes.

## Best Possible Solution

Make cron run-session pruning lifecycle-aware so it skips or drains active admitted work before archiving/removing transcripts, with focused coverage for an isolated cron run through final delivery.
