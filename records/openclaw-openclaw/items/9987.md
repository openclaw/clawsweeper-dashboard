## What This Changes

The issue requests an `openclaw approvals pending` CLI command that lists pending exec approval requests with command details and scriptable output.

## Best Possible Solution

Land a narrow CLI implementation that reuses `exec.approval.list`, preserves the approval-runtime visibility boundary, renders sanitized table and JSON output, adds focused CLI/docs coverage, and defers `--watch` unless maintainers explicitly scope it in.

## Solution Assessment
