## What This Changes

## Best Possible Solution

Land a narrow approvals CLI implementation that reuses the existing visibility-filtered `exec.approval.list` RPC, renders sanitized table and JSON output, adds focused CLI/docs coverage, and leaves `--watch` or resolve/respond behavior to explicit maintainer scope.

## Solution Assessment

Yes for the narrow direction, but it is not implemented on main. The maintainable solution is a CLI wrapper over the existing visibility-filtered RPC with sanitized output and focused docs/tests, not a new backend protocol method unless maintainers explicitly choose that.
