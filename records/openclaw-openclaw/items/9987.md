## Summary

Keep open: current main and the latest release still have the backend pending approval list RPC, but they do not expose the requested `openclaw approvals pending` CLI command, CLI tests, or docs; the closest open PR is broader and security-boundary gated.

## What This Changes

Add a CLI command such as `openclaw approvals pending` with human-readable and JSON output for currently pending exec approval requests.

## Best Possible Solution

Add a narrow read-only `openclaw approvals pending` or `list` command backed by the existing `exec.approval.list` RPC, with sanitized table output, `--json`, focused CLI tests, docs, and explicit maintainer scope for any resolve/respond or watch follow-up.
