## What This Changes

The issue asks for a CLI command such as `openclaw approvals pending` that lists pending exec approval requests with command details, JSON output, and possibly watch mode.

## Best Possible Solution

Land a narrow approvals CLI implementation that reuses `exec.approval.list`, preserves approval-runtime visibility rules, renders sanitized table and JSON output, adds focused tests/docs, and treats `--watch` or resolve/respond as separately scoped unless maintainers include them.

## Reproduction Assessment

## Solution Assessment

Yes for the narrow list-and-JSON direction, but it is not implemented on main. The maintainable path is a CLI wrapper over the existing RPC with sanitized output, tests, docs, and explicit security review rather than a new protocol method.
