## What This Changes

Add an authorized `openclaw approvals pending` command that displays pending exec-approval requests with readable command details and JSON output for automation.

## System Context

Exec requests that require approval are held by the gateway until an authorized operator decides. The requested CLI would query that pending queue through the existing approval boundary and render it for headless operators and monitoring tools.

## Architecture Diagram

flowchart LR
  A[Exec request] --> B[Approval queue]
  B --> C[Gateway approval API]
  C --> D[Authorized CLI]
  D --> E[Table or JSON output]
  E --> F[Operator or monitoring tool]

## Best Possible Solution

Land a narrowly scoped, authorized read-only pending-approvals CLI that reuses `exec.approval.list`, includes table and JSON output with focused tests and documentation, and defers approval resolution, watch mode, and durable cross-surface redesign to explicitly sponsored work.
