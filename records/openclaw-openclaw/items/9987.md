Keep this issue open while maintainers decide whether that CLI should remain read-only or also gain approval-resolution authority.

## What This Changes

Add a scriptable CLI command that lists pending exec approvals with command details, human-readable output, JSON output, and optionally live updates.

## Best Possible Solution

Land a focused `openclaw approvals pending`/`list` command backed by `exec.approval.list`, with sanitized table and JSON output plus focused CLI tests and docs; keep `--watch` and mutation commands separate unless maintainers explicitly approve their stronger lifecycle and authority contracts.
