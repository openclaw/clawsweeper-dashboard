## Summary

Current main has the authorized `exec.approval.list` Gateway backend but still lacks the requested CLI command, tests, and documentation. Keep this issue open because https://github.com/openclaw/openclaw/pull/83440 is the active maintainer implementation candidate, while its additional approval-resolution authority still needs explicit scope and security review.

## What This Changes

Add a CLI command that lists pending exec approval requests, including human-readable command details and JSON output for automation.

## Best Possible Solution

Land a read-only `openclaw approvals pending` command with a `list` alias, table and JSON output, focused tests, and CLI documentation by consuming `exec.approval.list`; treat resolution commands as a separately approved security capability unless maintainers deliberately include them.
