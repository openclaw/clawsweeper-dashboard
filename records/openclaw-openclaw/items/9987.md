## What This Changes

## Best Possible Solution

Land one coordinated approvals CLI implementation that reuses `exec.approval.list`, preserves `operator.approvals` and approval-runtime visibility semantics, adds table and `--json` output plus focused CLI/docs tests, and leaves resolve/watch behavior to a maintainer-scoped follow-up unless explicitly included.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers settle the approval authority contract. The narrowest maintainable direction is a CLI table/JSON wrapper over existing `exec.approval.list`, not a second gateway method.
