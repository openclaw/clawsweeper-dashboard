The issue requests a CLI subcommand to list currently pending exec approval requests, including command details, table output, JSON output, and possibly watch mode.

## Best Possible Solution

Land a narrow CLI implementation that reuses `exec.approval.list`, uses the approved operator approval authority path, renders sanitized table and JSON output, adds focused CLI/docs coverage, and defers `--watch` unless maintainers explicitly include it.

## Solution Assessment

Yes for the narrow direction, but it is not implemented on main. The best path is a CLI wrapper over the existing RPC with the established approval-runtime authority, sanitized output, tests, docs, and live proof rather than a new protocol method.
