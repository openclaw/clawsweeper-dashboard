## What This Changes

The issue requests a CLI command to list pending exec approval requests, including command details, table output, `--json`, and optionally watch mode.

## Best Possible Solution

Add a narrow `openclaw approvals pending` command backed by `exec.approval.list`, with table and `--json` output, sanitized command display, tests, and docs; treat watch or resolve flows as explicit follow-up scope.
