## Summary

## What This Changes

Request to add an `openclaw approvals pending` CLI command that lists pending exec approvals with command details, JSON output, and optional watch behavior.

## Best Possible Solution

Land a narrow approvals CLI implementation that reuses `exec.approval.list`, preserves approval visibility authority, renders sanitized table and JSON output, adds focused CLI/docs coverage, and scopes `--watch` separately unless maintainers explicitly include it.

## Reproduction Assessment

Yes. Source inspection of current main shows `openclaw approvals` only registers `get`, `set`, and `allowlist`, while the backend `exec.approval.list` RPC and tests already exist.

## Solution Assessment

Yes for the narrow direction, but it is not implemented on main. The best path is a CLI wrapper over the existing RPC with the correct approval authority, sanitized output, tests, docs, and live proof rather than a new protocol method.
