## Summary

## What This Changes

The issue requests an `openclaw approvals pending` CLI command with table, JSON, and optional watch output for pending exec approval requests.

## Best Possible Solution

Add a narrow `openclaw approvals pending`/`list` command backed by the existing `exec.approval.list` RPC with table and `--json` output, sanitized display, focused CLI tests, docs, and an explicit maintainer decision before bundling resolve/respond or watch behavior.
