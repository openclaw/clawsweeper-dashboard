## What This Changes

Request to add an `openclaw approvals pending` CLI command that lists pending exec approval requests with command details and scriptable output.

## Best Possible Solution

Land a narrow CLI implementation that reuses `exec.approval.list`, renders sanitized table and JSON output, adds focused CLI/docs coverage, preserves the approval visibility boundary, and defers `--watch` unless maintainers explicitly scope it in.

## Reproduction Assessment

## Solution Assessment

Yes for the narrow direction, but it is not implemented on main. The maintainable path is a CLI wrapper over the existing RPC with approval-runtime authority, sanitized output, tests, docs, and live proof rather than a new protocol method.
