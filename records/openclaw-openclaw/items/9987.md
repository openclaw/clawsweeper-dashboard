## Summary

The issue remains necessary: current main has the pending-approval RPC but no CLI listing command, and the only open implementation is conflicting and blocked on approval-authority scope and live proof.

## What This Changes

Add a CLI command that lists pending exec approval requests with command details and scriptable JSON output.

## Best Possible Solution

Land a focused `approvals pending`/`list` command backed by the existing visible-list contract and trusted approval-runtime authority, with display-safe table output, JSON mode, tests, docs, and redacted live gateway proof; decide resolve/respond and watch separately.
