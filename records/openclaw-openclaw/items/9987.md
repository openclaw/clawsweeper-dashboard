## Summary

## What This Changes

Add a CLI command such as `openclaw approvals pending` to list currently pending exec approval requests, including command details and scriptable output.

## Best Possible Solution

Land a narrow approvals CLI implementation that reuses `exec.approval.list`, preserves approval-runtime visibility rules, renders sanitized table and JSON output, adds focused CLI/docs coverage, and treats `--watch` as a follow-up unless maintainers explicitly include it.

## Reproduction Assessment

Yes. Source inspection of current main shows `openclaw approvals` only registers `get`, `set`, and `allowlist`, while the backend `exec.approval.list` RPC already exists.

## Solution Assessment

Yes for the narrow direction, but it is not implemented on main. The best implementation is a CLI wrapper over the existing RPC with the correct approval-runtime authority, sanitized output, tests, docs, and live proof rather than a new protocol method.
