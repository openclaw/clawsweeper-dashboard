## What This Changes

Add a narrow `openclaw approvals pending` or `list` command backed by the existing `exec.approval.list` RPC, with table and `--json` output, sanitized command display, focused CLI tests, docs, and explicit maintainer approval before bundling resolve/respond or watch behavior.
