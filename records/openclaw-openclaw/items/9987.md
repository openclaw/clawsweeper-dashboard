## What This Changes

Add a CLI subcommand such as `openclaw approvals pending` to list pending exec approval requests with command details and scriptable output.

## Best Possible Solution

Land or replace with a narrow approvals CLI implementation that reuses `exec.approval.list`, preserves visibility filtering, renders sanitized table and JSON output, and adds focused CLI tests plus docs; keep `--watch` separate unless maintainers explicitly include it.

## Solution Assessment

Yes for the narrow direction, but it is not implemented on main. The maintainable fix is a CLI wrapper over the existing visibility-filtered RPC with sanitized output and focused docs/tests, not a second protocol method.
