## What This Changes

The issue requests an `openclaw approvals pending` CLI command with command details, JSON output, and optional watch mode for pending exec approval requests.

## Best Possible Solution

Add a narrow read-only `openclaw approvals pending` or `list` command backed by the existing `exec.approval.list` RPC, with sanitized table output, `--json`, focused CLI tests, docs, and a maintainer-approved authority contract; keep resolve/respond and watch as explicit follow-ups unless intentionally included.
