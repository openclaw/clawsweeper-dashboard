## Label Justifications

- `impact:other`: The issue affects browser target identity and wrong-tab action routing, a concrete maintainer-visible impact outside the specific owned impact categories.

## Summary

Current main still contains and tests the unsafe sole-survivor fallback, so this fresh, maintainer-protected correctness bug remains necessary. The shared route-level identity guess can return an unrelated tab after navigation or an action invalidates the selected target.

## What This Changes

Prevent browser navigation and action responses from adopting an unrelated sole remaining tab when the acted-on target disappears.

## Best Possible Solution

Have each browser backend return an explicit exact open-or-closed target outcome, give extension-relay tabs a relay-owned stable handle with strict retirement semantics, and remove route-level identity discovery.
