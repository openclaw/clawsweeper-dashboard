## What This Changes

This branch adds `canPinMcpApps` to the chat transcript render dependencies and changes the associated transcript regression test so MCP app Pin controls refresh after a Gateway capability-only update.

## System Context

The Control UI turns Gateway board state and capability flags into cached chat-transcript items. MCP app cards consume those rendered items to decide whether Pin controls are shown, so every capability that changes a control must participate in the render-cache key.
