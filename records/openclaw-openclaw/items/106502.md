## Summary

Current main still permissively decodes malformed relay audio, so this PR remains necessary. The patch has no definite correctness defect, but the external-PR proof gate remains unmet because the supplied run uses an in-process Gateway context and stub audio providers rather than a real configured setup.

## What This Changes

The branch adds a shared strict base64 decoder for realtime and transcription Talk relay audio, routes both relay modes through it, and adds regression tests for malformed and valid frames.

## Best Possible Solution

Keep the shared fail-closed decoder at the relay boundary, then prove both valid browser microphone flow and malformed-frame rejection through a real Gateway with configured realtime and transcription providers before merge.
