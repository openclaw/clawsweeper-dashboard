## Summary

This member-authored, maintainer-labeled PR remains open, but it is not merge-ready: the patch resolves localized copy before storing it in process-owned runtime/controller state, so existing notices and errors can remain in the previous language after the app locale changes.

## What This Changes

The PR generates Android resources for 21 locales, localizes native app copy across major workflows, and adds deterministic extraction, resource-parity, and uncovered-literal checks.

## Best Possible Solution

Keep application-owned runtime and controller state locale-neutral using closed message identifiers plus canonical arguments, then resolve localized copy only at Compose, dialog, toast, notification, or other presentation boundaries.
