## Best Possible Solution

## Solution Assessment

Yes: extending the centralized volatile filter and archive writer is the right layer for backup payload behavior, and the upstream tar contract supports the stat-cache race mitigation. The only safer alternative is to narrow specific path families if maintainers decide one is durable restore state.
