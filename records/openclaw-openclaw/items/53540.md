## What This Changes

The issue asks OpenClaw to stop embedded runs from failing with a generic network-loss error when slow models generate large tool-call parameters, especially OpenRouter-routed Anthropic writes.

## Best Possible Solution

Live-reproduce the OpenRouter Anthropic large-argument tool-call path, then land a provider-owned fix that preserves hang detection while either streaming tool arguments where supported or applying a narrowly justified timeout/error-recovery policy.
