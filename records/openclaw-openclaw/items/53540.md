## Summary

Keep open: current main has useful timeout mitigation plumbing, but I did not find source, test, merged-PR, release, or live-provider proof that the default OpenRouter-to-Anthropic large tool-argument path now succeeds. The central timeout/provider policy decision still remains.

## What This Changes

The issue asks OpenClaw to stop embedded/main/subagent LLM turns from failing when a hosted provider stays silent while generating large tool-call parameters.

## Best Possible Solution

Keep this as the canonical tracker until maintainers choose and prove the narrow provider/runtime policy: supported OpenRouter tool-argument streaming, a deliberate timeout policy for silent large arguments, or a tool-loop strategy that avoids one huge `Write` payload.
