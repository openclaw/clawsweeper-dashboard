## Summary

Close: current main already runs compaction through fallback model candidates and clamps each compaction attempt to the selected model's resolved context window; the same behavior is present in v2026.6.11.

## What This Changes

Reporter asks compaction to use the active fallback model's context window instead of the primary/default model window during fallback-chain dispatch.

## Best Possible Solution

Keep the shipped fallback-aware compaction path; broader carried-context model-switch UX should stay with https://github.com/openclaw/openclaw/issues/58957 rather than reopening this narrower fallback-window report.
