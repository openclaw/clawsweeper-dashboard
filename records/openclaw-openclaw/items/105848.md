The added standalone transcript exercises admission internals, not an actual gateway process exiting after SIGTERM/SIGINT, so merge still needs a small correctness fix and real process-level proof.

## What This Changes

The PR adds a bounded two-second drain for tracked gateway root-work continuations before direct gateway stop exits, with helper and run-loop regression tests.
