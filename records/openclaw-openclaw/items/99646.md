Keep open: current main and the latest release still build the internal CLI reseed wrapper and import Claude CLI user transcript rows into chat history without recognizing that wrapper. ## What This Changes

The issue asks OpenClaw to stop rendering internal CLI-runner reseed prompts as visible user chat-history bubbles when importing Claude CLI session history.

## Best Possible Solution

Review and land or replace https://github.com/openclaw/openclaw/pull/99653 so gateway-imported Claude CLI history displays only the real user message and drops known internal reseed scaffolding.

## Reproduction Assessment

Yes. The source path is high-confidence: current main still builds the exact reseed wrapper and the Claude CLI history importer still maps user transcript entries into chat history without stripping that envelope.

## Solution Assessment

Yes. A gateway-side Claude CLI history import sanitizer or internal-prompt tagging fix is the narrowest maintainable solution because it covers iOS, macOS, and webchat clients without teaching each client CLI-runner scaffolding.
