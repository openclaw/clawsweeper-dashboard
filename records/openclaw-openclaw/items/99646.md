## Summary

Keep open: current main still builds the internal CLI reseed wrapper and imports Claude CLI user transcript rows into `chat.history` without recognizing that wrapper, while https://github.com/openclaw/openclaw/pull/99653 is the open candidate fix that should be reviewed or replaced before this issue closes.

## What This Changes

The issue requests hiding OpenClaw's internal CLI reseed prompt envelope from chat history while preserving the actual user message.

## Best Possible Solution

Review and land or replace the open gateway-side CLI-history sanitizer so `chat.history` clients see only the actual user message from reseed envelopes.

## Reproduction Assessment

Yes at source level: current main constructs the reseed envelope, imports Claude CLI user rows unchanged, and projects merged CLI history through `chat.history`. I did not run the live Claude CLI plus iOS reload path in this read-only review.

## Solution Assessment

Yes: filtering at the gateway CLI-history import/display boundary is the narrowest maintainable fix because all history API clients share that path. The open linked PR is the candidate implementation, but it still needs normal PR review before this issue closes.
