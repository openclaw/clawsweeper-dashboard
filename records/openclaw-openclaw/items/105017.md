This PR remains necessary because current `main` and the latest release still count UTF-16 code units despite the original 32KB contract. The focused implementation appears correct and CI is broadly green, but this external PR needs after-fix real behavior proof before merge.

## What This Changes

The PR changes sandbox environment-value validation to measure UTF-8 bytes and adds multibyte and exact-boundary regression tests.

## Best Possible Solution

Measure the existing 32KB suspicious-value heuristic in UTF-8 bytes, preserve warning-only forwarding across sandbox and skill callers, and describe it as an OpenClaw sanitizer threshold rather than a universal operating-system limit.
