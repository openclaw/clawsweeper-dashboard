## What This Changes

Threads an agent run’s abort signal through image and PDF media loading, provider calls, retries, fallback dispatch, prepared runtime leases, and Codex bounded turns so cancelled work does not continue consuming network or model resources.

## System Context

Agent image and PDF tools load media, select a configured model runtime, and dispatch provider requests before returning tool output to an agent run. This change carries a run-level cancellation signal through those stages so later downloads, retries, fallbacks, and remote Codex turns can stop promptly.
