## What This Changes

The branch passes an agent run’s abort signal through the image and PDF tools so a cancelled run interrupts media loading, stops later inputs, and skips model calls that have not begun.

## System Context

The image and PDF agent tools fetch user-supplied media and then send prepared content to a selected model provider. A run-level abort signal enters the tool execution path and should stop download and dispatch work before it consumes more network or model capacity.
