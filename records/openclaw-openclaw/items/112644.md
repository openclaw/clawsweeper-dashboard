## What This Changes

Threads an agent run’s abort signal through the image and PDF tools so cancelled runs interrupt media downloads, skip later inputs, and do not start a new model request.

## System Context

Agent tool execution wraps image and PDF requests with a run-level cancellation signal. These tools download remote media, prepare it for a provider, and then make a model call that returns tool output to the agent run.
