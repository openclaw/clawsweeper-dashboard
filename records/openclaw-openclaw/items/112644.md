## What This Changes

The branch propagates an agent run abort signal through image and PDF downloads, provider requests, retries, fallbacks, prepared runtimes, and Codex app-server turns so cancellation stops further remote work.

## System Context

Image and PDF agent tools load media, choose a configured model/provider, and may retry or fall back before returning a tool result. This change carries the enclosing agent run's cancellation signal across those stages so cancelled work stops before additional downloads or model calls occur.
