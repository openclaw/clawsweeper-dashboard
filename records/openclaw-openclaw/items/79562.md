  - confidence: 0.9

  - body: When timeoutMs is omitted, this helper now gives every app-server RPC a 60s deadline. Current main only times out explicit caller deadlines, and the checked sibling Codex app-server docs do not define a generic 60s JSON-RPC timeout, so valid long operations can fail without opt-in.
