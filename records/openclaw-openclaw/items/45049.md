## Summary

Keep open: current main still does not provide a strict internal agent-loop enforcement policy for simulated tool calls. The code executes structured `toolCall` blocks, warns on unstructured JSON/XML/ReAct-style tool-looking text, and preserves bounded compatibility promotion for standalone text-tool-call formats; the merged Gateway HTTP work only enforces caller-supplied `tool_choice` contracts.

## What This Changes

The issue requests stricter agent-loop handling for assistant text that simulates tool use instead of emitting a real structured tool call.

## Best Possible Solution

Keep arbitrary tool-looking assistant text non-executable, preserve the Gateway HTTP `tool_choice` contract, and design a maintainer-approved strict internal enforcement path for tool-required turns with upgrade-safe defaults, local-model guidance, and regression tests.
