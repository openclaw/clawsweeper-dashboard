## Summary

Keep open: current main still has warning-only handling for unstructured tool-looking text, bounded compatibility promotion for standalone text tool-call formats, and Gateway-only `tool_choice` enforcement, so the internal agent-loop enforcement decision remains unresolved.

## What This Changes

The issue requests stricter agent-loop handling so models cannot satisfy tool-required turns by emitting simulated or prose tool usage instead of real structured tool calls.

## Best Possible Solution

Keep arbitrary tool-looking assistant text non-executable, preserve the Gateway HTTP `tool_choice` contract, and design a maintainer-approved strict internal enforcement path for tool-required turns with upgrade-safe defaults, local-model guidance, and regression coverage.
