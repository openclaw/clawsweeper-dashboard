## Summary

Keep open: current main has shipped the Gateway HTTP `tool_choice` enforcement and has bounded repair/sanitization for leaked plain-text tool-call blocks, but ordinary agent/local-model turns still do not have a maintainer-approved strict policy for simulated tool calls, so the core security boundary remains unresolved.

## What This Changes

The issue requests stricter agent-loop handling for model text that simulates or announces tool calls instead of emitting structured tool calls.

## Best Possible Solution

Maintainers should choose the strict-tool boundary for ordinary agent turns/local models, then implement a bounded policy with safe structured execution, provider-specific repair only where proven, and clear fail-closed or retry behavior for configured strict paths.
