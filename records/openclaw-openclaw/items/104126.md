## Summary

The linked bug is still present on current main, but this PR is not merge-ready: its retry path keeps the deferral interval alive while the unchanged gateway callback releases the duplicate-loop guard, and the latest commit adds only single-request recovery coverage. The previous P1 finding therefore remains, and contributor-provided real runtime proof is still missing.

## Best Possible Solution
