Keep open: the fail-closed direction is valid, but the helper’s new retry lifecycle is inconsistent with the sole production caller’s pending-state contract, and the external PR supplies tests rather than required real-runtime proof.

## What This Changes

The PR changes gateway restart deferral so pending-count inspection exceptions enter or preserve polling instead of immediately emitting a restart, and adds focused regression tests for those exception paths.

## Best Possible Solution

Keep inspection failures fail-closed, preserve the gateway caller’s pending guard while retrying, change its error message to describe continued deferral, and cover repeated reload requests with one eventual restart in an integration-level regression test.
