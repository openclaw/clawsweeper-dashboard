## What This Changes

The PR changes oc-path relational predicates to accept only finite plain-decimal strings and adds tests rejecting hexadecimal, exponent, and blank-string operands.

## Best Possible Solution

Preserve finite-number coercion while explicitly rejecting blank or whitespace-only operands, unless maintainers deliberately approve strict-decimal grammar; either outcome should align CLI documentation, compatibility tests, and a live command transcript.
