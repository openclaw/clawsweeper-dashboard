## What This Changes

The PR passes hook-supplied cron job names through the existing external-content sanitizer and renders them as fenced `Task:` metadata, with regression tests for prompt-boundary containment.

## System Context

External hooks can schedule isolated cron-agent runs using a hook-provided job name and message. Isolated-run preparation builds the agent command prompt, where the external-content wrapper must keep untrusted hook metadata inside its marked boundary before the agent receives it.
