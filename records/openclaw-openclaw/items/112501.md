## What This Changes

Moves an external hook job name into sanitized, fenced external-content metadata so isolated agent prompts no longer present that value as trusted context.

## System Context

Hook-triggered cron jobs prepare an isolated agent turn from job metadata and an external payload. The external-content wrapper labels and sanitizes untrusted data before the resulting prompt is handed to the agent runtime.
