Keep open: current main and the latest release still forward exec approval prompts immediately, and there is no hold/retract config or agent-accessible retraction operation. ## What This Changes

The issue requests an opt-in `approvals.exec.holdMs` window plus an agent-accessible retraction action so forwarded exec approval prompts can be cancelled before delivery.

## Best Possible Solution

Design this as an opt-in approval lifecycle extension with a documented `holdMs` config, a clear agent retraction contract, fail-open human delivery, fail-closed execution, audit logging, and Gateway/Codex compatibility proof before implementation.
