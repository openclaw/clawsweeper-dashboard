## Summary

Keep open: current main and v2026.6.11 still have immediate forwarded exec approval delivery and no hold/retract approval contract. The request is valid product/security design work, not conservative cleanup, because it adds config, Gateway protocol, forwarding, audit, and native/Codex approval semantics.

## What This Changes

Request an opt-in `approvals.exec` hold window plus an agent-accessible retract action that cancels a pending forwarded exec approval before the human prompt is delivered.

## Best Possible Solution

Keep this open for a maintainer-designed, opt-in approval hold/retract contract that updates config, Gateway schema/docs, forwarding, audit logging, tests, and native/Codex approval handling without weakening approval safety.
