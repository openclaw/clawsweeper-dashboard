## Summary

Keep open: current main and v2026.6.11 still deliver forwarded exec approvals immediately and expose no hold/retract config or agent-accessible retraction RPC. The request is useful approval UX work, but it needs maintainer design because it changes approval timing, Gateway protocol, config, audit, and execution-safety semantics.

## What This Changes

Add an opt-in forwarded exec approval hold window plus an agent-accessible retraction action that cancels a pending approval before human prompt delivery.

## Best Possible Solution

Keep the issue open for a maintainer-designed, opt-in Gateway approval hold/retract mechanism with default instant delivery, explicit audit logging, protocol/schema/docs updates, and regression coverage for both delivery and retraction safety.
