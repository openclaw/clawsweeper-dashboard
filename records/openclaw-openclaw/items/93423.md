## Summary

Keep open: current main and v2026.6.11 still deliver forwarded exec approvals immediately and expose no hold window or agent-accessible retraction RPC. ## What This Changes

The issue requests an opt-in `approvals.exec` hold window plus an agent-accessible way to retract a pending forwarded exec approval before it reaches the human.

## Best Possible Solution

Have a maintainer choose the core approval contract first, then implement one coherent opt-in design across config/schema/docs, Gateway RPC, forwarder buffering, manager cancellation/denial semantics, audit events, Codex/native mappings, and focused tests.
