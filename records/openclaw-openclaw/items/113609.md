## What This Changes

This PR excludes the exact OpenAI-compatible `/v1` namespace from the root-mounted Control UI fallback so disabled API routes return HTTP 404 instead of the Control UI HTML document.

## System Context

The gateway receives HTTP traffic and decides whether each request belongs to an OpenAI-compatible API route or the Control UI single-page application. The Control UI route classifier runs before the SPA fallback, so its result determines whether disabled API paths reach normal HTTP not-found handling or return UI HTML.
