## What This Changes

The PR strips one leading decoded UTF-8 byte-order marker from text-file output in OpenClaw’s built-in read tool and adds a regression test that preserves embedded markers.

## System Context

The built-in read tool receives bytes from local or injected file backends, decodes text, then applies line offsets and truncation before returning content to the model. This change normalizes decoded text at that shared boundary so models do not receive a leading encoding marker.
