## Summary

Keep open: the PR addresses the right bug shape, but it is not merge-ready because compaction retry can clear the side-effect counters used to build currentAttemptReplayMetadata while preserving only hadDeterministicSideEffect, allowing a later empty provider error in the same outer attempt to retry after side effects.

## What This Changes

The PR adds current-attempt replay metadata for embedded agent attempts, uses it to gate silent provider-error retries, routes empty server_error turns into retry, and adds regression coverage.

## Best Possible Solution

Make current-attempt replay metadata monotonic across compaction-reset-preserved side effects, keep the missing-field fallback conservative, and then require redacted full-runner or gateway proof of retry, recovered reply, and no duplicate side effects.
