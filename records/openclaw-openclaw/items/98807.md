## What This Changes

Request to show in Control UI chat history which provider/model generated each assistant reply and whether it came from the default, fallback, or deliberate per-request selection.

## Best Possible Solution

Define a structured selected/configured/resolved/source model contract for chat history events and transcripts, then render a compact per-reply disclosure in the Control UI using those fields.
