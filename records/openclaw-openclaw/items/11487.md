## What This Changes

The issue requests an optional ignored string field such as `name`, `label`, or `description` for channel group configuration entries so numeric group IDs are easier for humans and agents to identify.

## Best Possible Solution

Approve one canonical descriptive string field and apply it consistently across relevant group-entry types, strict schemas, generated channel metadata, docs, and validation tests while preserving the value through config load/write and ignoring it at runtime.
