## What This Changes

The issue requests one optional ignored string metadata field, such as `name`, `label`, or `description`, on channel group config entries for human and agent readability.

## Best Possible Solution

Choose one canonical optional string metadata field and add it consistently across relevant group-entry types, strict schemas, generated metadata, docs, and validation tests while preserving it through config load/write and ignoring it at runtime.
