The issue asks OpenClaw to accept an optional ignored human-readable metadata string on channel group config entries.

## Best Possible Solution

Approve one canonical descriptive string field, likely name, then update the relevant group-entry schemas, TypeScript types, generated metadata, public docs, and validation coverage while preserving it through config load/write and ignoring it at runtime.
