The issue requests an optional string `name`, `label`, or `description` field on channel group config entries for human and agent readability.

## Best Possible Solution

Choose one canonical optional string metadata field, then update all relevant strict schemas, exported config types, generated channel metadata, docs, and validation tests together while keeping runtime behavior unchanged.
