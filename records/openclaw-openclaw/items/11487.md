## What This Changes

The issue requests one optional string metadata field such as `name`, `label`, or `description` on channel group config entries for human and agent readability.

## Best Possible Solution

Approve one canonical descriptive string field, likely `name`, then update the relevant group-entry schemas, TypeScript types, generated metadata, public docs, config-tool behavior, and validation coverage while preserving the field and ignoring it at runtime.
