## What This Changes

Requests an optional human-readable string metadata field such as `name`, `label`, or `description` on group config entries across channel configs.

## Best Possible Solution

Approve one canonical descriptive string field, likely `name`, then update the relevant group-entry schemas, TypeScript types, generated metadata, docs, and validation coverage while preserving the field through config load/write and ignoring it at runtime.
