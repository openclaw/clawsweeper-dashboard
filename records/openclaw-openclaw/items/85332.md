## Summary

Keep open: current main and v2026.6.11 only support extra APT packages during local image builds, while this issue asks for a pulled-image startup or production-safe derived-image workflow that still needs maintainer product and security direction.

## Best Possible Solution

Maintainers should choose an explicit derived-image or prebuild/restart contract, with docs and tests, while keeping the official runtime image slim and avoiding package installation during gateway downtime by default.

## Solution Assessment
