## Summary

Keep open: current main and v2026.6.11 only support extra APT packages during local image builds, while the requested pulled-image startup or production-safe prebuild workflow still needs product and security direction.

## What This Changes

The issue requests an opt-in Docker image mode or bootstrap flow that installs deployer-specified APT packages while keeping the official base image slim.

## Best Possible Solution

Maintainers should choose an explicit derived-image or prebuild/restart contract, with docs and tests, while preserving the slim non-root default image and avoiding package installation during gateway downtime.
