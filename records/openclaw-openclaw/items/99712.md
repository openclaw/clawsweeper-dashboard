## What This Changes

The issue asks OpenClaw to synthesize a visible fallback for user-originated interactive direct/channel turns that finish with no assistant payload, no prompt error, no side-effect delivery, and no explicit silent policy.

## Best Possible Solution

Land one canonical PR that adds a shared empty-interactive reply guard at the direct-run and follow-up final delivery boundaries, preserving heartbeat, cron, message-tool-only, explicit silent, and proven side-effect-only silence.
