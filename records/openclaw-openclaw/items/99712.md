## Summary

## What This Changes

Interactive direct/channel turns should emit a visible fallback when a non-silent run completes with no renderable assistant payload or committed source-channel delivery.

## Best Possible Solution

Review and land one canonical linked PR that covers both `runReplyAgent` and `createFollowupRunner`, preserves explicit silent and side-effect-only cases, and then close this issue as implemented after merge.

## Solution Assessment
