## Label Justifications

- `P1`: The issue breaks active agent verification loops by hiding tool output from the model across real user sessions and multiple channels.
- `impact:message-loss`: Model-visible tool-result text can be replaced by a placeholder, effectively dropping the content the agent needs to continue.
- `impact:session-state`: The reported failure is tied to transcript, replay, compaction, and provider projection state drifting away from stored text tool results.

## Summary

Keep open: earlier main fixes preserve structured tool-result text in several provider paths, but current main still allows a text-bearing tool result with stale media blocks to fall back to a media placeholder, and the open fix PR https://github.com/openclaw/openclaw/pull/99756 targets that remaining model-visible projection path.

## What This Changes

The issue asks OpenClaw to preserve model-readable text for tool outputs instead of replacing stdout/stderr or tool-result content with image attachment placeholders.

## Best Possible Solution

Keep this as the canonical issue until a provider/projection fix lands that makes explicit tool-result text authoritative over stale media placeholders, with regression coverage across the shared helper and affected provider transports.
