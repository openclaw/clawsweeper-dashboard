## Summary

Keep open: current main and the latest release still have the fast main-session `next-heartbeat` cron handoff that records `ok` without proving an agent turn ran, and https://github.com/openclaw/openclaw/pull/72677 is the open closing PR rather than a merged fix.

## What This Changes

The issue reports silent main-session cron ghost runs and requests a scoped warning or annotation for fast successful `systemEvent` jobs using `wakeMode: "next-heartbeat"`.

## Best Possible Solution

Land, narrow, or replace https://github.com/openclaw/openclaw/pull/72677 so fast main-session `next-heartbeat` handoffs surface a deliberate operator warning without creating avoidable config or protocol compatibility churn.
