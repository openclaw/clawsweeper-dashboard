## Label Justifications

## Summary

Keep open: current main still records the main-session `next-heartbeat` cron handoff as `ok` without a ghost-run warning, and https://github.com/openclaw/openclaw/pull/72677 is the open linked implementation candidate rather than a reason to close this issue before merge.

## What This Changes

The issue asks OpenClaw to warn or annotate suspiciously fast successful main-session `systemEvent` cron runs so operators can spot ghost runs when the gateway or agent cannot process the handoff.

## Best Possible Solution

Review, refresh, and either land or replace https://github.com/openclaw/openclaw/pull/72677 with an accepted warning shape that surfaces fast main-session next-heartbeat ghost runs without avoidable config or protocol churn.
