## What This Changes

Add a canonical policy for suppressing, deduplicating, or redirecting operational runtime notices before they are delivered to an external source chat.

## System Context

OpenClaw routes inbound channel events through agent execution and reply-delivery policy before sending text or status to the originating chat. This request adds a separate operator-controlled decision for host-generated operational notices, while normal assistant replies and stronger existing delivery denials continue through their current paths.
