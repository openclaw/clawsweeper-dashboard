## What This Changes

Add a global operational-reply policy that can always deliver, suppress, deduplicate per source session, or redirect runtime-generated notices away from an external source chat.

## System Context

OpenClaw produces runtime notices from agent dispatch, ACP, follow-ups, heartbeat, compaction, and plugin-binding paths before channel delivery. This proposal would introduce one delivery-policy decision that filters or redirects those notices while preserving stronger send-denial and ambient-room suppression rules.
