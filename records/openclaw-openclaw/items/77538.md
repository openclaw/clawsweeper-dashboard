- **[P1] Enforce auth caps in bytes or token shape:** `packages/gateway-protocol/src/schema/primitives.ts:32-34`
  - body: `Type.String({ maxLength })` does not bound the byte work this PR is trying to cap. Please enforce a UTF-8 byte cap or a closed token shape before the secret-compare path.
  - confidence: 0.91
