Full review comments:

- **[P1] Bound auth bytes, not graphemes:** `packages/gateway-protocol/src/schema/primitives.ts:33-43`
  - body: This remains from the previous review: `Type.String({ maxLength })` in TypeBox 1.3.3 validates grapheme clusters, while the protected work in `safeEqualSecret` scales with UTF-8 bytes. A value such as one base character plus many combining marks can stay under the PR's character cap while still driving large allocation and scan work, so use byte-length or strict token-shape validation and add byte-heavy regression coverage.
  - confidence: 0.95
- **[P1] Document or narrow the new connect auth caps:** `packages/gateway-protocol/src/schema/frames.ts:74-79`
  - body: This also remains from the previous review: the PR changes connect auth from frame-size-only acceptance to rejecting bootstrap/device tokens over 256 graphemes and shared/runtime secrets over 4096 graphemes. Existing custom clients or long operator secrets could fail at handshake, so the branch needs gateway/security acceptance plus docs for the new protocol contract, or it should narrow the cap to generated-token paths.
  - confidence: 0.87
