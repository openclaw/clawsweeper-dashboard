- **[P1] Enforce auth caps in bytes or token shape:** `packages/gateway-protocol/src/schema/primitives.ts:32-43`
  - body: This prior blocker is still present. The new primitives rely on TypeBox `maxLength`, but typebox@1.3.3 checks grapheme clusters while `safeEqualSecret` allocates and scans UTF-8 bytes.   - confidence: 0.91

Because invalid agent-runtime identity connect params fail closed and approval-runtime params trigger compatibility retry behavior, either remove these two fields from the PR or add explicit rationale and at/over-cap coverage for them.
  - confidence: 0.86
