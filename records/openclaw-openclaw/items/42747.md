## Summary

Keep open: current main and v2026.6.11 still expose Slack as static credential inputs, while native token rotation would add a new Slack OAuth refresh lifecycle that needs maintainer product and security design.

## What This Changes

The issue requests native Slack OAuth token rotation for refreshing expiring Slack bot tokens with oauth.v2.access and managed refresh-token state.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent refresh state, transactional token replacement, runtime adoption, status/doctor recovery, docs, and live Socket Mode plus HTTP Mode proof while preserving existing static-token setups.
