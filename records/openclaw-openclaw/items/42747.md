Design and implement this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, redacted status/doctor recovery, docs, and live Slack token-rotation proof while preserving existing static-token setups.

Summary: The issue itself is security-sensitive because a correct implementation must safely store and rotate Slack refresh tokens and client secrets.
