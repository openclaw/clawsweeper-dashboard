## Summary

Keep open: current main and v2026.6.11 still model Slack credentials as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth token-rotation lifecycle that needs maintainer security and product design before implementation.

## What This Changes

Add native Slack OAuth token rotation so OpenClaw can refresh expiring Slack bot tokens via oauth.v2.access without an external daemon.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack proof while preserving existing static Slack credential setups.
