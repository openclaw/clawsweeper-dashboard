## Summary

Keep open: current main and v2026.6.11 still model Slack credentials as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth token-rotation lifecycle that needs maintainer security and product design before implementation.

## What This Changes

This issue requests native Slack OAuth token rotation support so OpenClaw can refresh expiring Slack bot tokens and manage associated credentials without an external daemon.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with maintainer-approved secure storage, transactional refresh-token replacement, runtime token adoption, redacted status/doctor recovery, docs, and live Slack rotation proof while preserving static-token setups.
