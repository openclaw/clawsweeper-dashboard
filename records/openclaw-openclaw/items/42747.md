## Summary

Keep open: current main and v2026.6.11 still model Slack credentials as static bot/app/user/signing-secret inputs, while Slack token rotation requires a refresh-token lifecycle that OpenClaw has not implemented and that needs maintainer security/product design before code work.

## What This Changes

The issue requests native Slack OAuth token rotation with refresh-token storage, oauth.v2.access refresh, runtime token adoption, and CLI/status support.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack proof while preserving existing static Slack credential setups.
