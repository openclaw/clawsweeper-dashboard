## Summary

Keep open: current main and v2026.6.11 still treat Slack credentials as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth token-rotation lifecycle that needs maintainer security and product design before implementation.

## What This Changes

Add native Slack token rotation support using oauth.v2.access refresh-token grants, plus setup/status/config handling for refreshed Slack credentials.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, redacted status/doctor recovery, docs, and live Slack rotation proof while preserving static-token setups.
