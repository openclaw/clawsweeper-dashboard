## Summary

Keep open: current main and the latest release still model Slack credentials as static token inputs, while Slack OAuth token rotation would add a new security-sensitive auth lifecycle that needs maintainer design before implementation.

## What This Changes

Request Slack plugin support for rotating bot tokens through Slack OAuth token rotation, including refresh credential storage, background refresh, setup/status UX, and runtime adoption.

## Best Possible Solution

Design a Slack-plugin-owned rotating-credential lifecycle that keeps existing static-token configs working, stores refresh material securely, refreshes transactionally, adopts tokens in running clients, and exposes redacted status/doctor recovery.
