## Summary

Keep open: current main and v2026.6.11 still model Slack credentials as static token inputs, while native Slack token rotation would add a new OAuth refresh, secret storage, and live credential adoption lifecycle that needs maintainer product and security design.

## What This Changes

The issue requests native Slack oauth.v2.access token rotation support, including refresh-token storage, proactive refresh, runtime token adoption, setup/status commands, and Socket/HTTP mode compatibility.

## Best Possible Solution

Design this as a Slack-plugin-owned credential rotation lifecycle with secure storage, transactional refresh/update, status/doctor recovery, docs, and Socket/HTTP/relay adoption proof while preserving static-token setups.
