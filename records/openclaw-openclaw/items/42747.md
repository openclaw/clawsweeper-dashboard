## Summary

Keep open: current main and v2026.6.11 still expose Slack as static bot/app/user token inputs, while native Slack token rotation would add a new OAuth refresh lifecycle that needs maintainer product and security design.

## What This Changes

Request native Slack token rotation support using oauth.v2.exchange/oauth.v2.access, managed refresh credentials, proactive refresh, runtime adoption, and setup/status UX.

## Best Possible Solution

Design this as a Slack-plugin-owned credential rotation lifecycle with secure storage, transactional refresh/update, status or doctor recovery, docs, and Socket/HTTP/relay adoption proof while preserving static-token setups.
