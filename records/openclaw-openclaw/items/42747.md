## Summary

Keep open: current main still has a static Slack credential model, while native token rotation would add mutable Slack OAuth credential storage, refresh scheduling, runtime token adoption, setup/status UX, and security policy choices that need maintainer direction before implementation.

## What This Changes

The issue requests native Slack OAuth token rotation support using oauth.v2.access refresh-token flow, including config/state fields, proactive refresh, runtime adoption, and Slack setup/status commands.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh replacement, runtime token adoption, status/doctor recovery, docs, and live Slack rotation proof while preserving existing static-token setups.
