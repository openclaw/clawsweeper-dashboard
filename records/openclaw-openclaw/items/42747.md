## Summary

Keep open: current main and v2026.6.11 still treat Slack credentials as static bot/app/user/signing-secret inputs, while native Slack OAuth token rotation would add new secret storage, refresh ownership, and runtime auth adoption behavior that needs maintainer security and product design.

## What This Changes

The issue requests native Slack OAuth token rotation support with refresh-token storage, oauth.v2.access refresh behavior, runtime credential adoption, and setup/status CLI support.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack proof while preserving existing static Slack credential setups.
