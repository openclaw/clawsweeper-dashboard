## Summary

Keep open: current main and v2026.6.11 still model Slack credentials as static token inputs, while native Slack token rotation would add OAuth refresh, rotating secret storage, and live runtime credential adoption that needs maintainer product and security design.

## What This Changes

Add native Slack OAuth token rotation so OpenClaw can exchange and refresh expiring Slack bot tokens without an external daemon.

## Best Possible Solution

Design a Slack-plugin-owned credential rotation lifecycle with secure storage, transactional refresh/update, status and doctor recovery, docs, and Socket/HTTP adoption proof while preserving static-token setups.

- **Create a generic refresh seam first:** Define a reusable plugin credential-refresh contract before implementing Slack as one consumer of that contract.
