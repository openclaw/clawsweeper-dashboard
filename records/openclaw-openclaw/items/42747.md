## Summary

Keep open: current main and the latest release still expose Slack as static token inputs, while native OAuth token rotation would add new credential storage, refresh ownership, and live runtime adoption that needs maintainer product and security direction first.

## What This Changes

Request to add native Slack token rotation support using Slack OAuth refresh tokens, including config/schema, refresh runtime, CLI bootstrap, and operational status handling.

## Best Possible Solution

Design a Slack-plugin-owned rotation lifecycle with secure persisted state, transactional refresh/update, status and doctor recovery, docs, and Socket/HTTP adoption proof while preserving static-token setups.
