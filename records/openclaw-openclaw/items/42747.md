## Summary

Keep open: current main and latest release still treat Slack credentials as static bot/app/user/signing-secret inputs, while this asks OpenClaw to own a new rotating Slack OAuth credential lifecycle that needs security and product approval before implementation.

## What This Changes

Add native Slack token rotation support using Slack's oauth.v2.access refresh_token flow so expiring Slack bot tokens can refresh without an external daemon or manual restart.

## Best Possible Solution

Design this as a Slack-plugin-owned rotating credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack rotation proof while preserving existing static-token setups.
