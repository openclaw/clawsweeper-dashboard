## Summary

Keep open: current main and v2026.6.11 still expose Slack as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth refresh-token lifecycle that needs maintainer product and security design before implementation.

## What This Changes

Add native Slack OAuth token rotation so OpenClaw can refresh expiring Slack bot tokens with `oauth.v2.access` instead of external tooling.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent refresh state, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Socket Mode plus HTTP Mode proof while preserving existing static-token setups.
