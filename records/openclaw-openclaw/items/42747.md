## Summary

Keep open: current main and v2026.6.11 still expose Slack as static bot/app/user/signing-secret inputs, while this request asks OpenClaw to own a new Slack OAuth refresh-token lifecycle that needs maintainer product and security design before implementation.

## What This Changes

Add Slack token-rotation support that stores refresh metadata, calls Slack oauth.v2.access before bot tokens expire, updates runtime credentials, and exposes setup/status UX.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent refresh state, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Socket Mode plus HTTP Mode proof while preserving existing static-token setups.
