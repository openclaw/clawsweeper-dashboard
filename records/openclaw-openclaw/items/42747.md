## Summary

Keep open: current main and the latest release still use static Slack bot/app/user/signing-secret credentials, while this request adds a new OAuth token-rotation lifecycle that needs maintainer product and security direction before implementation.

## What This Changes

The issue requests native Slack oauth.v2.access token rotation for the Slack plugin, including refresh-token storage, proactive refresh, runtime credential adoption, setup/status commands, and backward-compatible static-token behavior.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack rotation proof while preserving existing static-token setups.
