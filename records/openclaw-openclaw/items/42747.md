## Summary

Keep open: current main and v2026.6.11 still expose Slack as static token inputs, and the requested Slack OAuth refresh-token lifecycle is missing; the remaining work is a product and security design decision rather than conservative cleanup.

## What This Changes

Request native Slack token rotation support using Slack's oauth.v2.access refresh-token flow.

## Best Possible Solution

Implement this as a Slack-plugin-owned design that preserves existing static token setups, stores refresh/client secrets through approved SecretRef or credential surfaces, refreshes via Slack OAuth with explicit operational status, and proves both Socket Mode and HTTP mode plus live credential adoption.
