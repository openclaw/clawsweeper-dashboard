## Summary

Keep open: current main and v2026.6.11 still expose Slack as static bot/app/user/signing-secret credentials, while Slack token rotation would add a new credential refresh lifecycle that needs maintainer security and product direction before implementation.

## What This Changes

The issue requests native Slack OAuth token rotation using oauth.v2.exchange/oauth.v2.access, storing refresh metadata and refreshing Slack bot tokens without an external daemon.

## Best Possible Solution

Implement a Slack-plugin-owned rotating credential lifecycle with deliberately chosen secure storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Socket Mode plus HTTP Mode proof while preserving existing static Slack credential setups.
