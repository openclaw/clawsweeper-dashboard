## Summary

Keep open: current main and v2026.6.11 still use static Slack credential inputs, while native Slack token rotation would add a new OAuth refresh lifecycle that needs maintainer product and security design.

## What This Changes

Add native Slack OAuth token rotation support so OpenClaw can refresh expiring Slack bot tokens with `oauth.v2.access` instead of relying on external rotation tooling.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent refresh state, transactional token replacement, runtime adoption, status/doctor recovery, docs, and live Socket Mode plus HTTP Mode proof while preserving existing static-token setups.
