## Summary

Keep open: current main and v2026.6.11 still model Slack credentials as static token inputs, while native Slack token rotation would add OAuth refresh, rotating secret storage, and live runtime credential adoption that needs maintainer product and security design.

## What This Changes

Request native Slack plugin support for Slack OAuth token rotation using oauth.v2.access refresh-token flow.

## Best Possible Solution

Design a Slack-plugin-owned token rotation lifecycle with secure persisted state, transactional refresh/update, status and doctor recovery, docs, and Socket/HTTP adoption proof while preserving static-token setups.
