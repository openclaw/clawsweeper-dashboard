## Summary

Keep open: current main still supports Slack static bot/app/user/signing-secret credentials, while this requests a new Slack OAuth token-rotation lifecycle that needs maintainer product and security direction before implementation.

## What This Changes

The issue requests native Slack token rotation using `oauth.v2.exchange` and `oauth.v2.access`, including new config/storage fields, refresh scheduling, runtime token adoption, setup/status UX, and retry behavior.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack rotation proof while preserving existing static-token setups.
