## Summary

Keep open: current main and v2026.6.11 still support Slack as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth refresh-token lifecycle that needs maintainer security and product design before implementation.

## What This Changes

The issue requests native Slack OAuth token rotation, including refresh-token storage, proactive oauth.v2.access refresh, runtime adoption of refreshed bot tokens, and setup/status CLI support.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent refresh state, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack proof while preserving existing static Slack credential setups.
