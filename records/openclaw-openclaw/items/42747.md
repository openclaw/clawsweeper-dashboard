## Summary

Keep open: current main and v2026.6.11 still model Slack auth as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth refresh-token lifecycle that needs maintainer product and security design before implementation.

## What This Changes

Request to add native Slack OAuth token rotation support, including refresh-token storage, proactive oauth.v2.access refresh, config updates, and setup/status CLI support.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent refresh state, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack proof while preserving existing static Slack credential setups.
