## Summary

Keep open: current main and the latest release still model Slack credentials as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth token-rotation lifecycle that needs maintainer security and product design before implementation.

## What This Changes

Add native Slack OAuth token rotation for refreshing expiring Slack bot tokens, storing refresh metadata, updating runtime credentials, and exposing setup/status flows.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, redacted status/doctor recovery, docs, and live Slack rotation proof while preserving static-token setups.
