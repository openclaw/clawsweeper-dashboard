## Summary

Keep open: current main and v2026.6.11 still model Slack as static bot/app/user/signing-secret credentials, while this request adds a new Slack OAuth token-rotation lifecycle that needs explicit security and product design.

## What This Changes

Add native Slack token rotation using oauth.v2.access refresh-token grants, including config/setup/status support and runtime refresh without external tooling.

## Best Possible Solution

Design a Slack-plugin-owned rotating credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, status/doctor recovery, docs, and live Slack proof while preserving static-token setups.
