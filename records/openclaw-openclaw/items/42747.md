## Summary

Keep open: current main and v2026.6.11 still treat Slack credentials as static bot/app/user/signing-secret inputs, while this request adds a new Slack OAuth token-rotation lifecycle that needs security and product design before implementation.

## What This Changes

Add native Slack token rotation support using Slack OAuth refresh tokens, including credential storage, refresh scheduling, runtime token adoption, setup/status UX, and backwards-compatible static-token behavior.

## Best Possible Solution

Design this as a Slack-plugin-owned credential lifecycle with secure persistent storage, transactional refresh-token replacement, runtime token adoption, redacted status/doctor recovery, docs, and live Slack rotation proof while preserving static-token setups.
