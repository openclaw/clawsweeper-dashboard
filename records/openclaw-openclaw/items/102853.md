## Summary

Keep this PR open: it fixes the direct `auth.json` bootstrap symlink path and has sufficient real filesystem proof, but the shared plugin-facing replacement wrapper still suppresses final-path chmod without preserving exact mode semantics for the copy-fallback path.

## What This Changes

The PR routes missing `auth.json` creation through atomic replacement and wraps OpenClaw's async and sync atomic file replacement helpers to set temp-file modes before rename while skipping final-path chmod.

## Best Possible Solution

Preserve exact mode semantics for both rename and copy-fallback replacement without chmodding a swappable final path, preferably in the fs-safe primitive or with explicit secops approval for a wrapper-level fix.
