## Summary

Keep open: the revised PR addresses the earlier post-rename symlink chmod gap, but the wrapper now suppresses fs-safe's final chmod for every OpenClaw atomic file replacement and can break the helper's exact file-mode contract for non-0600 or preserve-existing-mode callers.

## What This Changes

The branch routes missing `auth.json` bootstrap through atomic replacement and wraps OpenClaw's fs-safe atomic replacement exports to skip final-path chmod, with symlink regression tests.

## Best Possible Solution

Preserve exact file-mode semantics while eliminating followable final-path chmod, preferably by safely setting the replacement file's final mode before rename or by fixing the fs-safe primitive, then merge after secops review.
