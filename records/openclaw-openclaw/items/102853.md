- **[P2] Preserve modes on copy fallback too:** `src/infra/replace-file.ts:51-53`
  - body: This still skips fs-safe's final `chmod(filePath, mode)` for every replacement, but fs-safe's copy fallback creates the destination with `open(..., sourceStat.mode & 0o777)`, which is still filtered by the process umask.   - confidence: 0.86
