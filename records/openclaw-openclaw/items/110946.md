## Summary

Keep open. The report describes a concrete machine-consumer correctness failure that remains distinct from the completed-turn liveness bug in https://github.com/openclaw/openclaw/issues/110206 and the sub-agent completion problem in https://github.com/openclaw/openclaw/issues/76145. Current CLI documentation makes `--timeout` a command-level deadline and reserves `--json` stdout for parsable results, but it does not establish that a nonterminal `toolUse` result may be projected as successful; the current command and gateway-result implementation need a focused source/test check rather than cleanup closure.

## What This Changes

Fix `openclaw agent --json` so a command deadline reached before a terminal assistant result cannot be reported as successful completion.

## Best Possible Solution

Make the CLI emit `status: "ok"` and `summary: "completed"` only after a terminal result with final assistant output; return a distinct non-success/incomplete timeout result when the command deadline wins, while preserving any documented fresh-session fallback only when it itself reaches a terminal outcome.
