## Summary

Keep this PR open: the previously raised P1 remains unresolved because the new stop hook is wired into the repository’s internal `createAgentSession`, while the primary embedded runner still creates sessions through the external Pi runtime; the synthetic `agentLoop()` transcript therefore does not prove the affected production path stops.

## What This Changes

The PR marks critical tool-loop veto results as terminating, adds a post-turn stop hook for mixed tool-call batches, and adds related tests, documentation, and a standalone proof harness.

## Best Possible Solution

Place the critical-veto stop at the canonical session/runtime boundary used by embedded production runs, retain completion of ordinary sibling tools, define whether queued input is cancelled or preserved for a fresh run, and prove the complete behavior through a real OpenClaw session.
