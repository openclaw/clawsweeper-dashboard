## Label Justifications

## Summary

Keep this PR open: the reported runaway-loop bug remains valid, but the patch only stops the embedded AgentSession path while the shared critical-veto wrapper also serves externally controlled runtimes such as Codex, where the Pi-style `terminate` field and `shouldStopAfterTurn` hook are not consumed. The standalone transcript also injects the hook directly, so it does not prove the changed production session wiring.

## What This Changes

Marks critical tool-loop veto results as terminating, exposes a post-turn stop hook through agent-core, wires it into the embedded session runtime, and adds regression coverage, documentation, and a standalone proof script.

## Best Possible Solution

Land one canonical fix that translates a critical tool-loop veto into each runtime owner's real termination mechanism, preserves or deliberately requeues pending steering and follow-up input, and proves single and mixed batches through an after-fix OpenClaw session transcript.
