## Summary

Keep open: current main and v2026.6.11 still lack a general hard agent iteration budget, while the linked implementation PR remains open, conflicting, and narrower than the requested total-call and timeout contract. Maintainers need to choose the first public budget semantics before refreshing that canonical implementation path.

## What This Changes

Add configurable agent-level limits for model-tool iterations, total tool calls, and elapsed time after the first tool call to prevent runaway runs and missing replies.

## Best Possible Solution

Define one opt-in generic run-budget contract at the agent-core and harness boundary, initially counting a clearly documented model-tool round invariant with fail-closed tool blocking and a bounded final-response path; treat total tool invocations and elapsed-time-after-tool limits as separate controls unless maintainers explicitly approve combined semantics.
