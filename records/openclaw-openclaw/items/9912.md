## Summary

Current main and v2026.6.11 still lack a hard global/per-agent iteration or tool-call budget. The active implementation candidate remains open and conflicting, and its public budget unit and exhaustion behavior still require maintainer direction, so this issue should remain the canonical request.

## What This Changes

Add global and per-agent hard limits for model-tool iterations, total tool calls, and optionally elapsed time after the first tool call so runaway runs terminate with a user-visible result.

## Best Possible Solution

Adopt one canonical opt-in agent-run budget under agent defaults and per-agent overrides, enforce it before the next tool executes, give the model at most one tool-disabled final response turn, and separately track individual-call or post-tool elapsed-time limits only if production evidence shows the round budget is insufficient.
