## Summary

Keep this issue open as the canonical global/per-agent hard iteration-budget request. Current main has not absorbed the requested behavior, and the linked candidate PR remains open with unresolved correctness, documentation, contract, and real-behavior-proof blockers.

## What This Changes

Add configurable global and per-agent limits for model/tool iterations, tool calls, and post-tool response time so a run stops safely instead of continuing a runaway tool loop.

## Best Possible Solution

Adopt one documented global/per-agent budget contract in the embedded agent runtime, count one clearly named unit exactly once, select parent versus subagent limits correctly, and provide a bounded final-response outcome with real-run proof.
