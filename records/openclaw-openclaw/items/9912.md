## Summary

Keep open: current main and v2026.6.11 still lack a hard agent iteration or tool-call budget, while the linked implementation PR remains open with blocking counter semantics, incomplete config documentation, and no real-run proof.

## What This Changes

Add configurable agent-level limits for model/tool iterations, total tool calls, and optionally elapsed time after tool use, with defined exhaustion behavior.

## Best Possible Solution

Adopt one canonical core budget contract with explicit parent/subagent precedence, separately named counters where needed, deterministic exhaustion and final-response behavior, aligned schema/help/docs, focused regression tests, and redacted real-run proof before landing the implementation.
