## What This Changes

Add global and per-agent limits for model-tool rounds, total tool calls, and elapsed time after the first tool call, with defined exhaustion behavior.

## Best Possible Solution

Establish one opt-in budget contract for defaults and per-agent overrides, enforce each budget unit exactly once at the embedded-runner boundary, select parent and subagent limits correctly, document precedence with loop detection and timeouts, and prove exhaustion behavior in a real run.
