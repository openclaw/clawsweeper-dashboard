Keep open: current main and v2026.6.11 still lack a global/per-agent hard budget for agent model-tool turns or total tool calls. ## What This Changes

Request configurable agent-level max-turn, max-tool-call, and timeout-after-tool-call limits to stop runaway model/tool loops and force a user-visible response.

## Best Possible Solution

Adopt one opt-in agent-run budget contract in the core runtime, strict config schema, docs, and focused tests, preferably by landing the active candidate once maintainers approve the public semantics; close this issue only after that reaches main.

## Reproduction Assessment

Yes for the missing capability: current strict schemas, docs, and the core agent loop show no global or per-agent hard max-turn or max-tool-call budget. The specific KIMI/NVIDIA production loop was not live-reproduced in this review.
