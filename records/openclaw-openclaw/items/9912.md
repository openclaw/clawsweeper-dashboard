## What This Changes

Add global and per-agent hard limits for model-tool iterations, total tool calls, and post-tool waiting time, with deterministic exhaustion behavior.

## Best Possible Solution

Land one opt-in core agent-budget contract with a single clearly named counting unit, correct parent/subagent scope, deterministic terminal outcome that preserves a useful user response, aligned schema/help/docs, focused exhaustion tests, and redacted real-run proof.
