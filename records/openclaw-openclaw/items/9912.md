## Summary

Keep open: current main and the latest release still do not provide a global/per-agent hard budget for model-tool turns or total tool calls. Existing loop detection and whole-run timeouts are adjacent guardrails, and https://github.com/openclaw/openclaw/pull/97485 is an open implementation candidate rather than a merged fix.

## What This Changes

Request a global/per-agent `maxTurns`, `maxToolCalls`, or `toolCallTimeout` style configuration surface that caps agent tool-loop iterations and forces a final response.

## Best Possible Solution

Review, land, narrow, or close https://github.com/openclaw/openclaw/pull/97485 or an equivalent maintainer-approved implementation that adds opt-in global/per-agent iteration budgeting with explicit exhaustion semantics, docs, and focused runtime tests.
