## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Parse the final summary block, not the first tag:** `src/agents/compaction-analysis-strip.ts:42`
  - body: `stripAnalysisBlock` takes the first `<summary>...</summary>` match anywhere in the response. Because the new prompt asks the model to reason about the `<summary>` format inside `<analysis>`, a compliant analysis can mention a literal summary-tag example before the real final summary; this would persist that fragment and drop the required compaction sections. Anchor extraction after `</analysis>` or choose the final summary block, and add that regression case.
  - confidence: 0.89
- **[P1] Gate transcript self-read before adding it to the prompt:** `src/agents/pi-hooks/compaction-safeguard.ts:943-945`
  - body: Appending the full session JSONL path to every compacted summary tells the model exactly where to read the raw transcript. OpenClaw documents session transcripts as sensitive because they can contain pasted secrets, file contents, command output, and links, so this needs an explicit opt-in/access/redaction policy instead of becoming the default compaction suffix.
  - confidence: 0.86
- **[P2] Reuse the existing pruning policy instead of hard-coding tools:** `src/agents/micro-compact.ts:11-21`
  - body: `microCompactMessages` adds a separate list of clearable tools and a fixed preserve count, bypassing the existing contextPruning policy surface for tool-result hard-clear behavior. That can clear data even when maintainers or operators expect the documented thresholds, allow/deny rules, placeholder, and hardClear toggle to govern pruning; wire this through the existing policy or make the new behavior explicitly approved.
  - confidence: 0.78
