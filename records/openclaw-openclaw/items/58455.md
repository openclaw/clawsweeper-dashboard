- **[P2] Parse the final summary block instead of the first tag:** `src/agents/compaction-analysis-strip.ts:42`
  - body: `stripAnalysisBlock` matches the first `<summary>...</summary>` pair in the whole response.   - confidence: 0.86
- **[P1] Do not expose transcript paths in compacted context by default:** `src/agents/pi-hooks/compaction-safeguard.ts:943-945`
  - body: This appends the full session JSONL path to the summary that remains in model-visible context. OpenClaw documents session transcripts as sensitive local state that can contain private messages and tool output, so making the path part of default compaction can expand what the model or a later tool-use step can disclose without an explicit security/product decision.
  - confidence: 0.78
