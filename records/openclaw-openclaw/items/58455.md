## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Do not expose raw transcript paths in compaction summaries:** `src/agents/pi-hooks/compaction-safeguard.ts:943-945`
  - body: The new suffix tells future model turns the exact JSONL transcript path. Current docs describe compaction as changing what the model sees next turn, while `sessions_history` intentionally redacts, truncates, and bounds transcript reads; pointing the model at the raw file bypasses that safer path and can re-expose private prior prompts or tool output. Please remove this or route recovery through an explicit redacted/authorized session-history mechanism.
  - confidence: 0.87
- **[P2] Extract the final summary block, not the first one:** `src/agents/compaction-analysis-strip.ts:42-44`
  - body: `text.match(/<summary>([\s\S]*?)<\/summary>/)` returns the first matching block anywhere in the response. If the analysis section mentions a literal summary tag pair, the compaction entry can keep that analysis fragment and drop the real final summary, which loses session context when the quality guard is off or misses it. Parse after `</analysis>` or otherwise select the intended final summary block.
  - confidence: 0.84
