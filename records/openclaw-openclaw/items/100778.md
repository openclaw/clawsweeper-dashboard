## Summary

Keep open: current main and the latest release still hard-fail non-skipped preflight compaction failures, and the linked closing PRs are open candidate fixes rather than merged implementation evidence.

## What This Changes

The issue asks OpenClaw to recover gracefully when transient preflight compaction failures would otherwise leave the chat Composer/session in a terminal state.

## Best Possible Solution

Land one focused runtime fix with a structured retryability contract, keep auth/request/billing failures terminal, prove the Composer remains usable with redacted real behavior evidence, then close or supersede the duplicate PRs.
