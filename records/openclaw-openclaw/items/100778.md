Keep open: current main and the latest release still hard-fail transient preflight compaction failures, while three open closing PRs now own candidate fixes, so this issue should remain the canonical tracker until one lands.

## What This Changes

Fix a preflight compaction failure path where transient compaction LLM errors terminate the run and leave the Control UI Composer disabled instead of allowing retry.

## Best Possible Solution

Land one focused runtime fix that skips only transient preflight compaction failures such as timeout, 429, and 5xx, keeps 400/401/403 terminal, includes regression coverage, and closes this issue after merge.
