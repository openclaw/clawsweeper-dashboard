## Summary

Keep open: current main still treats transient preflight compaction timeout/provider failures as hard pre-run errors, and three open linked PRs now compete to fix the same canonical bug rather than making the issue obsolete.

## What This Changes

The issue requests graceful recovery when preflight compaction fails so the Composer does not remain disabled in a terminated session state.

## Best Possible Solution

Land one canonical narrowed runtime fix that skips timeout, true retryable 429, and 5xx preflight compaction failures while preserving 400/401/403 and billing/auth failures as terminal, with regression tests and redacted WebChat/Control UI proof.
