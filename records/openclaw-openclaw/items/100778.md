## What This Changes

The issue reports that transient preflight compaction failures can terminate a chat dispatch before the agent run starts, leaving the Composer disabled until refresh.

## Best Possible Solution

Land one canonical narrow runtime guard that skips only transient preflight failures such as timeout, true rate limit, and 5xx while keeping auth, request-shape, and billing failures terminal; add real behavior proof, and use UI recovery only if the runtime fix still leaves the Composer locked.
