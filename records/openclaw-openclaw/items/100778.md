## Summary

Keep open: current main still hard-fails transient preflight compaction failures, and the linked fix PRs are open but unmerged.

## What This Changes

The issue asks for transient preflight compaction failures to stop wedging the Composer/session state when provider timeout, rate-limit, or 5xx errors occur.

## Best Possible Solution

Land one canonical fix that skips only clearly transient preflight compaction failures, keeps 400/401/403 and broad summary failures terminal, includes regression coverage, and adds real behavior proof for the Composer recovery path.
