The issue requests a way to force or reliably preserve replies back to the originating messaging channel across Telegram, Discord, WhatsApp, and similar channels.

## Best Possible Solution

Define a safe turn-origin delivery invariant that preserves the captured route through agent, ACP, tool, and queued follow-up paths, with fallback or mirroring only behind explicit maintainer-approved security policy.
