## Summary

Keep open: current main still has internal-WebChat and same-surface origin-routing gates, the requested force/fallback policy is absent, and multiple related reports show the channel-delivery problem remains active rather than implemented.

## What This Changes

The issue requests reliable delivery of generated replies back to the originating messaging channel, with a proposed force-origin and fallback-channel policy for Telegram, Discord, WhatsApp, and similar channels.

## Best Possible Solution

Define a durable turn-origin delivery invariant that preserves the captured channel and target through agent, ACP, tool, and queued follow-up paths, then add fallback or mirroring only as an explicit security-reviewed policy.

Rationale: The next change can alter which external conversation receives generated content, so code inspection cannot decide the product and privacy boundary without maintainer intent.

Likely owner: steipete

Owner confidence: high

Options:

- **Adopt durable turn-origin delivery (recommended):** Capture the inbound turn's external channel, account, target, and thread once, preserve it through the agent and follow-up pipeline, and route final replies there unless the turn explicitly chooses another route.
- **Add opt-in force/fallback policy:** Keep current defaults but add a documented default-off policy for force-origin or fallback delivery with schema, doctor/docs, authorization, route freshness, and live-channel proof.
- **Keep gates and fix narrow bugs:** Leave WebChat and same-surface suppression as the security default and address only proven channel-specific delivery defects such as WhatsApp same-surface drops.

## Reproduction Assessment

Yes, source-level reproduction is high confidence: current main and v2026.6.11 still gate origin routing on non-internal-WebChat and origin-vs-current-surface checks, and tests assert those gates. I did not run a live channel scenario in this read-only review.

## Solution Assessment

No, the proposed unconditional force/fallback config is not proven as the best fix. The safer path is a durable turn-origin invariant first, with any fallback or mirroring added only after maintainer security and product approval.
