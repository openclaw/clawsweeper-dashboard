## What This Changes

The issue reports final agent replies appearing internally but not in the originating messaging client, and requests force-origin or fallback delivery behavior across Telegram, Discord, WhatsApp, and similar channels.

## Best Possible Solution

Define a durable turn-origin delivery invariant that preserves the captured external channel, account, target, and thread through agent, tool, ACP, and follow-up paths; add fallback or mirroring only as an explicit security-reviewed policy.
