## What This Changes

Prevent Workboard card mutations from turning metadata-size trimming into permanent deletion of historical SQLite proof records.

## System Context

Workboard is a bundled plugin that records cards, lifecycle events, and proof for operator coordination and audit history. Card mutations persist updated state, after which CLI, gateway, agent tools, exports, and the Control UI read the resulting card and proof history.
