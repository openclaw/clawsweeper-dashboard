## Summary

Keep this PR open: it wires the timeout constant into the Git invocation, but it still omits the claimed `SIGKILL` option, so the synchronous release-closeout script can remain blocked when the child handles the default `SIGTERM`.

## What This Changes

The PR adds a 120-second timeout to the stable-main closeout script’s synchronous Git SHA lookup.

## Best Possible Solution

Set `killSignal: "SIGKILL"` on the existing `execFileSync("git", ...)` call and replace the transcript with redacted after-fix proof using a Git shim that ignores `SIGTERM` but terminates on `SIGKILL`.
