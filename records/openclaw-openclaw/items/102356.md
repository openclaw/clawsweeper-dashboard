## Summary

Keep open: current main still uses length-only delta slicing in the Microsoft Teams stream controller, and the issue is maintainer-protected plus paired with an open closing PR at https://github.com/openclaw/openclaw/pull/102357.

## What This Changes

Fix Microsoft Teams personal-chat streaming so cumulative partial replies whose trailing whitespace is normalized emit the full next chunk instead of slicing by the prior emitted length.

## Best Possible Solution

Review and land the linked open fix PR if its regression test and proof hold; the controller should compute deltas from the previous cumulative text/shared prefix rather than only the previous emitted length.

## Solution Assessment

Yes. Fixing the Teams controller's delta calculation and adding a focused regression test is the narrow owner-boundary solution; this issue should stay open until the linked PR merges or is replaced.
