## Summary

Keep open: current main still lacks the requested side-effect-free cron test/validate commands, input-driven skill test runner, and shared dry-run/mock/read-only tool interception contract; related items cover narrower slices but do not replace this broader design request.

## What This Changes

Request to add side-effect-free dry-run/test/validate support for cron jobs and skills, including mock/read-only tool calls and CI-friendly JSON output.

## Best Possible Solution

Keep this issue open for a maintainer-owned additive design: cron test/validate RPC plus CLI, a skills test runner with explicit input/CI output semantics, and a shared dry-run/mock/read-only tool interception contract coordinated with https://github.com/openclaw/openclaw/issues/41418 and https://github.com/openclaw/openclaw/issues/92783.
