## Summary

Keep open: current main and the latest release still do not expose ACP child tool calls, arguments, tool results, or thinking through `streamTo="parent"`; the remaining work is a security-sensitive visibility policy decision, not a stale implementation cleanup.

## What This Changes

The issue requests parent-session visibility for ACP child tool calls, tool arguments, tool results, and thinking when `sessions_spawn` uses `runtime="acp"` with `streamTo="parent"`.

## Best Possible Solution

Keep this as the canonical ACP parent-stream visibility tracker and define a default-off, bounded, redacted projection contract, preferably reusing existing ACP tag visibility and channel progress settings before adding any new option.

- **Add raw verbose relay:** Forward raw tool and thought data behind an explicit verbose switch, accepting a larger security and privacy burden.
