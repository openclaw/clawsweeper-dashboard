## Summary

Keep open: PR #89505 shipped opt-in assistant commentary/status progress, but current main and v2026.6.11 still do not expose ACP child tool calls, raw arguments, tool results, or thinking through `streamTo="parent"`; the remaining work is a security-sensitive visibility policy decision.

## What This Changes

The issue requests parent-visible ACP child tool calls, arguments, tool results, and thinking when `sessions_spawn` uses `runtime="acp"` with `streamTo="parent"`.

## Best Possible Solution

Keep this as the canonical ACP parent-stream tool/thought visibility tracker and define a default-off, bounded, redacted projection contract that reuses existing ACP tag visibility and channel progress settings where possible.

- **Define Redacted Projection (recommended):** Expose only bounded summaries through existing ACP/channel visibility policy, with raw arguments, raw results, and thought hidden by default and covered by focused tests and docs.

- **Add Raw Verbose Relay:** Forward raw tool and thought data behind an explicit verbose switch, accepting a larger privacy and security review burden.
