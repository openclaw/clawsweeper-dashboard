## Summary

Keep open: current main still does not expose ACP child tool calls, raw arguments, tool results, or thinking through `streamTo="parent"`; the merged commentary/status progress work only partially overlaps and the remaining request is a security-sensitive product decision.

## What This Changes

The issue requests parent-visible ACP child tool calls, tool arguments, tool results, and thinking/progress details when `sessions_spawn` uses `runtime="acp"` with `streamTo="parent"`.

## Best Possible Solution

Define a bounded ACP parent-stream projection contract that emits redacted tool/progress summaries through existing progress and tag-visibility controls while keeping raw arguments, full results, and thinking hidden by default.

- **Add Explicit Full Relay:** Allow raw tool and thought visibility only behind an explicit opt-in, accepting a larger security and privacy review burden.
