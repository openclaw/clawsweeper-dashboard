## Summary

Keep open: current main and the latest stable release still do not expose raw ACP tool calls, tool results, arguments, or thinking through `streamTo="parent"`; the remaining request needs an explicit visibility and redaction decision before implementation.

## What This Changes

The issue requests parent-visible ACP `streamTo="parent"` progress for tool calls, tool arguments, tool results, and thinking, with a maintainer choice about verbose gating.

## Best Possible Solution

Define a bounded ACP parent-progress projection that is opt-in, redacted, and tag/verbosity-aware before wiring additional raw runtime events into parent-visible messages.
