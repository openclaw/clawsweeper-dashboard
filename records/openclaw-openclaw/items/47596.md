## Summary

Keep open: current main still only relays assistant/commentary/status/lifecycle progress for ACP parent streams; tool calls, raw results, and thought-like data exist but remain hidden or omitted, and exposing them needs an explicit maintainer security/product policy.

## What This Changes

Expose ACP child tool calls, tool results, and thinking/progress details to the parent session when `sessions_spawn` uses `runtime="acp"` and `streamTo="parent"`.

## Best Possible Solution

Define a bounded ACP parent-stream projection contract that emits redacted tool/progress summaries through existing progress and tag-visibility controls while keeping raw arguments, full results, and thinking hidden by default.
