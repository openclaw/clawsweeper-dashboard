## Summary

Keep open: current main still does not expose ACP child tool calls, raw arguments, tool results, or thinking through `streamTo="parent"`; the merged commentary/status progress work only partially overlaps and this remains a security-sensitive product decision.

## What This Changes

Request parent-session visibility for ACP child tool calls, arguments/results, and thinking/progress when `sessions_spawn` uses `runtime="acp"` with `streamTo="parent"`.

## Best Possible Solution

Define a bounded ACP parent-stream projection contract that emits redacted summaries through existing progress/tag-visibility controls while keeping raw arguments, full results, and thinking hidden by default.
