## Summary

Keep open: current main still does not expose ACP child tool calls, tool results, or thought-like updates through `streamTo="parent"`; merged commentary/status progress work only partially overlaps, and the remaining visibility boundary is security-sensitive.

## What This Changes

Request parent-session visibility for ACP child tool calls, tool results, and thinking/progress details when `sessions_spawn` uses `runtime="acp"` with `streamTo="parent"`.

## Best Possible Solution

Define a bounded ACP parent-stream projection that emits redacted tool/progress summaries through existing progress and tag-visibility controls while keeping raw arguments, full results, and thinking hidden by default.
