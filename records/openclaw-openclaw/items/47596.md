## Summary

Keep open: current main still omits the requested ACP parent-stream tool/result/thought visibility, and the remaining cross-session visibility boundary needs maintainer and security intent.

## What This Changes

Request to make ACP `sessions_spawn(..., streamTo: "parent")` surface child tool calls, tool results, and thinking/progress internals to the parent session.

## Best Possible Solution

Define a bounded ACP parent-stream projection that emits redacted tool/progress summaries through existing progress and tag-visibility controls while keeping raw arguments, full results, and thinking hidden by default unless maintainers approve a stronger opt-in.
