## Summary

The requested workflow is only partly present on current main: custom session groups, transcript forks, lifecycle controls, and split chat panes now cover organization and parallel viewing, but selected-message split/move and explicit composer routing or fanout remain absent. Those remaining behaviors need a maintainer decision about durable project identity and safe transcript-copy semantics.

## What This Changes

Request durable project-tree session organization, routed or fanned-out composer entry points, selected-message split/move triage, and cross-project context seeding in the Control UI.

## Best Possible Solution

Extend the existing session category, fork, and split-pane model with an additive message-copy branch operation and explicit route-target contract; avoid a parallel topic store unless the broader Project proposal establishes additional workspace or security invariants.
