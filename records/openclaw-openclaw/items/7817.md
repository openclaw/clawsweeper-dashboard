## Summary

Current main now covers much of the organization request through custom session groups, pin/archive/rename controls, whole-session forks, checkpoint branches, worktrees, and multi-pane chat. It still lacks arbitrary selected-message split/move semantics and multi-session composer delivery, and no narrower canonical item owns both gaps, so this issue remains useful but should be narrowed by a maintainer product decision.

## What This Changes

Add project-oriented session trees, targeted or fanout composer entry points, selected-message split/move actions, and cross-project context seeding to Control UI.

## Best Possible Solution

Narrow this tracker to non-destructive branching from a selected transcript point on the existing session model; treat destructive moves and multi-session fanout as separate product decisions unless maintainers explicitly approve their semantics.
