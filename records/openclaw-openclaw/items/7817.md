## Summary

Current main covers much of the original organization request through custom session groups, whole-transcript forks, worktree-aware session creation, and multi-pane chat, but it still lacks selected-message split/move semantics and multi-target composer delivery. Recent human review explicitly kept the issue open, and no single related item owns all remaining behavior, so conservative cleanup should retain it for a scope decision.

## What This Changes

Add project-oriented session trees and Control UI workflows for targeted or fanned-out input, selected-message split/move triage, and seeding context into other branches.

## Best Possible Solution

Keep existing session groups, whole-transcript forks, worktree targets, and split panes, route durable Project identity to https://github.com/openclaw/openclaw/issues/13676, and narrow this issue to explicitly sponsored selected-message branch/copy and multi-target composer contracts.
