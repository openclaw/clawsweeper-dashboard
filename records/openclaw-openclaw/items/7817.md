## Summary

Current main now covers most session organization and parallel viewing, but selected-message transcript triage and deliberate multi-session composer delivery remain meaningful, unresolved capabilities. Keep the issue open, narrowed around those semantics rather than rebuilding the session-management features that have already landed.

## What This Changes

Requests project-organized session trees, routed or fanout composer targets, selected-message split or move actions, and cross-project context seeding in the Control UI.

## Best Possible Solution

Add an immutable selected-range branch-copy contract and an explicit multi-target send contract with per-target idempotency and results, while tracking first-class project/workspace policy separately in https://github.com/openclaw/openclaw/issues/13676.
