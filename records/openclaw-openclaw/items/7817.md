## Summary

Current main now covers session-level organization through custom groups, batch session triage, whole-transcript forks, worktree-aware creation, and thread-management controls. It still lacks selected-message split/move semantics and multi-session composer delivery, so meaningful unique work remains and the issue should stay open pending a narrower product decision.

## What This Changes

Add project-oriented session organization, selected-message branching or movement, cross-session context seeding, and composer routing to one or more conversation threads in Control UI.

## Best Possible Solution

Narrow the end state to non-destructive selected-message branch/copy plus an explicitly designed multi-session composer target built on current groups and whole-session forks, or preserve those unique requirements in one designated broader canonical tracker.
