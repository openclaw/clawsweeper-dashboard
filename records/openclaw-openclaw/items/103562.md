## What This Changes

This PR adds bounded Discord reply-dispatch retries for transient reply-session initialization conflicts and regression coverage.

## Best Possible Solution

Split preparation from execution so Discord records and prepares the inbound turn once, retries only the session-init/agent-dispatch operation with the existing abort-aware delays, and reopens replay ownership after final exhaustion.
