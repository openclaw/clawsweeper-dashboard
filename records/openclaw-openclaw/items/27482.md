## Summary

Keep open: current main and v2026.6.11 still reject WebChat video uploads and lack a provider-native chat/model video input contract; the related implementation PRs were closed unmerged, so this remains the canonical product/security tracker.

## What This Changes

The issue requests direct video file uploads and native LLM video input support for video-capable models, with UI preview, validation, and provider delivery similar to image uploads.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
