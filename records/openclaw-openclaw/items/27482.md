## Summary

Keep open: current main and the latest release still block WebChat video uploads, and the backend/model contracts only provide native image content plus generic media staging rather than first-class video delivery to an active LLM model.

## What This Changes

Request direct MP4/WebM/MOV video upload in chat/message flows with preview, validation, and native delivery to video-capable LLMs.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve and land one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
