## Summary

Keep open: current main still does not provide direct chat video upload/native LLM video content delivery, even though it has adjacent generic media staging and video media-understanding paths.

## What This Changes

Request support for uploading video files in chat and sending them directly to LLMs that support native video understanding.

## Best Possible Solution

Keep this as the canonical generic tracker until maintainers approve a video-aware contract across WebChat accept/preview, Gateway validation/staging, native provider content, fallback/security policy, docs, and tests.
