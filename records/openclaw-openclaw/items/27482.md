## Summary

Keep open: current main and v2026.6.11 still lack the requested direct WebChat/message-tool video upload path to video-capable LLM chat models; existing media-understanding video.description support is adjacent, and the remaining work needs maintainer product and security direction.

## What This Changes

Request direct MP4/WebM/MOV upload support from chat/message surfaces to video-capable LLMs, including validation, preview, provider delivery, and fallback behavior.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve and land one coherent video-aware contract across WebChat, Gateway validation/staging, model capability metadata, provider delivery, fallback/security policy, docs, and tests.
