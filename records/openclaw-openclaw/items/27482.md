## Summary

Keep open: current main and the latest checked release still filter video uploads from WebChat and expose native chat attachments as image blocks plus generic media staging, while related direct-video PRs were closed unmerged and the remaining provider-specific tracker is narrower than this generic product/security decision.

## What This Changes

Request support for direct video file uploads in chat/message flows so video-capable LLMs can receive MP4/WebM/MOV clips natively with preview and validation.

## Best Possible Solution

Keep this as the canonical generic tracker until maintainers approve one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
