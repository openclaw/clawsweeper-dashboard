## Summary

Keep open: current main and the latest release still do not provide direct video upload to a video-capable LLM chat/model path; existing video.description media-understanding support is adjacent but not the requested WebChat/message-tool native video input contract.

## What This Changes

Request direct video uploads in chat/message flows so video-capable LLMs can receive supported clips natively with preview and common format support.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve and land one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
