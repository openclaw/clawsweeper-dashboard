## Summary

## What This Changes

Request direct video file upload in chat/message flows so video-capable LLMs can receive MP4/WebM/MOV content natively instead of requiring frame extraction or separate media tools.

## Best Possible Solution

Keep this as the canonical generic tracker until maintainers approve one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
