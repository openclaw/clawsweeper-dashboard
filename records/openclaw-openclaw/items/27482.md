- `P2`: This is a source-proven multimodal feature gap with meaningful user friction, but not an outage, data-loss event, urgent regression, or active security incident.

## Summary

Keep open: current main and the latest release still lack direct video upload/native video delivery for chat-model turns, and the related implementation PRs were closed unmerged rather than landing the feature.

## What This Changes

Request direct video file upload in WebChat/message flows and provider-native delivery to LLMs that support video input.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve and land one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
