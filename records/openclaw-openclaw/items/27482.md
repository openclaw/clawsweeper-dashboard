## Summary

Keep open: current main and v2026.6.11 still do not provide direct video upload into a provider-native LLM chat/model input path; the closed implementation PRs are not viable landing paths, so this remains the canonical product and security tracker.

## What This Changes

Request direct MP4/WebM/MOV-style chat uploads to video-capable LLMs, including validation, provider-native delivery or fallback, and chat UI preview support.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
