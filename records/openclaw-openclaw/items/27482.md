## Summary

Keep open: current main and v2026.6.11 still do not provide direct video upload into a provider-native LLM chat/model input path, and the closed implementation PRs are not viable landing paths. This remains the canonical product/security tracker.

## What This Changes

Request support for uploading MP4/WebM/MOV-style video files in chat and delivering them directly to LLM models that support native video understanding.

## Best Possible Solution

Keep this as the canonical tracker until maintainers approve and land one coherent video-aware contract across WebChat, Gateway validation/staging, model catalog metadata, provider delivery, fallback/security policy, docs, and tests.
