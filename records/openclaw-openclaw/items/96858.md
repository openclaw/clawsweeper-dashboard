## Summary

Current main still skips gateway memory flush for native CLI runtimes and renders context usage without backend-owned transition stages. The direct fix closed unmerged, while the open runtime-classification PR preserves the skip and does not own this request.

## What This Changes

Add a native CLI-compatible pre-compaction handoff mechanism and replace misleading bare context percentages with backend-aware status.

## Best Possible Solution

Define a generic CLI-backend pre-transition capability with authoritative context-state events, implement it where the native harness can support it, and suppress or explicitly label context meters when OpenClaw lacks authoritative state.
