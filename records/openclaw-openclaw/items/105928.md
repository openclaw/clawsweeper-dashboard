## Summary

Keep this PR open: the current head still permits a full-access setup token to reach generic local silent pairing without verified official-mobile metadata, its CLI documentation understates the resulting pairing authority, and inspectable native behavior proof remains missing.

## What This Changes

This PR makes official mobile setup grant full operator access by default, adds explicit limited-access choices, and updates gateway authorization, CLI, protocol, Control UI, native apps, tests, and documentation.

## Best Possible Solution

Grant full access only when redemption matches the exact official iOS or Android bootstrap profile and metadata, reject every other mobile-full consumer before generic silent pairing, retain the explicit limited mode, document admin-derived pairing authority, and provide redacted native Full, Limited, and upgrade proof.
