## What This Changes

Ensure subagent completions arriving after `sessions_yield` produce a parent-authored user update instead of being suppressed as `NO_REPLY`.

Make every completion delivered after `sessions_yield` reliably trigger one parent synthesis turn, reserving `NO_REPLY` only for events whose result was already substantively delivered, with regression coverage for single-child, parallel top-level, active-run steering, and post-yield completion paths.
