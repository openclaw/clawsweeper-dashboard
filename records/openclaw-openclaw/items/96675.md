## Summary

Keep open. Current main has adjacent approval hooks, Skill Workshop proposal gates, untrusted-content marking, and memory/wiki provenance, but it still lacks the requested owner-confirmed durable lifecycle for promoting assistant or skill outputs into persistent memory, reusable evidence, revocable rules, or future context.

## What This Changes

The issue requests optional owner-confirmation gates before assistant outputs, skill results, memories, and evidence can become reusable persistent context.

## Best Possible Solution

Define a maintainer-approved responsibility/trust contract that coordinates existing approval hooks, Skill Workshop, and memory/wiki provenance with durable owner-confirmed reuse state, adding core or plugin API only where current seams cannot represent it.
