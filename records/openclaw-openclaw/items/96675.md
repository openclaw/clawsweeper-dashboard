## Summary

Keep open: current main has adjacent memory provenance, input provenance, approval hooks, Skill Workshop lifecycle gates, and Memory Wiki evidence metadata, but not the requested durable owner-confirmed lifecycle for promoting assistant or skill outputs into trusted memory, actions, reusable evidence, revocable rules, or future context.

## What This Changes

Add optional owner-confirmation gates so assistant outputs, skill results, actions, persistent memory, and reusable evidence require explicit owner review before becoming durable trusted context.

## Best Possible Solution

Define a maintainer-approved responsibility/trust contract that coordinates memory, plugin SDK hooks, approvals, Skill Workshop, and Memory Wiki, then implement only the narrow core or plugin API gaps with migrations, docs, and tests.
