## Summary

Keep open. Current main has adjacent memory provenance, external-content wrapping, approval hooks, and Skill Workshop proposal gates, but it still lacks the requested owner-confirmed durable lifecycle for promoting assistant or skill outputs into persistent memory, reusable evidence, revocable rules, or future context.

## What This Changes

Add optional owner-confirmation gates so assistant outputs, skill results, actions, and memories cannot become persistent memory, rules, or reusable evidence without explicit owner review.

## Best Possible Solution

Keep this as a maintainer-owned security/product design item until OpenClaw chooses a responsibility-state contract, then land narrow PRs for memory provenance, approval/plugin APIs, and UI/audit reuse state only where existing seams are insufficient.
