## Summary

Keep open. Current main has adjacent external-content markers, inter-session provenance, plugin approvals, and Skill Workshop proposal gates, but it still lacks the requested owner-confirmed durable lifecycle for promoting assistant or skill outputs into persistent memory, reusable evidence, revocable rules, or future context.

## What This Changes

The issue requests optional owner-confirmation gates so assistant outputs, skill results, and memories cannot become persistent memory, rules, or reusable evidence without explicit user review.

## Best Possible Solution

Define a maintainer-approved responsibility/trust contract that coordinates existing approvals, Skill Workshop, memory provenance, and plugin APIs, then split the first shippable core/API slice from optional external interoperability work.
