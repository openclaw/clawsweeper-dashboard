## What This Changes

This PR changes Slack legacy interactive reply choice parsing to strip style suffixes before splitting at the last colon, and adds regression tests for time-like labels.

## Best Possible Solution

Land a Slack parser fix that preserves existing colon-containing callback values while fixing time-style label colons, with focused regression coverage and redacted Slack or packaged-runtime proof.

## Reproduction Assessment

Yes, from source inspection: current main uses the first colon as the delimiter, so `9:00` in a label shifts `00:` into the callback value. I did not execute a current-main failing test because this review is read-only.

## Solution Assessment

No. The patch fixes the timestamp-label case, but a global last-colon split is not the safest fix because it can corrupt existing colon-containing callback values unless maintainers explicitly change the legacy grammar.
