## Summary

Keep open: the bounded-reader approach addresses the memory-risk report, but this patch newly makes every value in an existing state-directory `.env` disappear silently when it exceeds 1 MiB. That compatibility and operator-diagnostics choice needs resolution before merge.

## What This Changes

The PR replaces the state-directory `.env` unbounded synchronous read with a 1 MiB `readRegularFileSync` boundary, preserves symlink targets via `realpathSync`, and adds oversized and symlink regression tests.

## Best Possible Solution

Keep the bounded read, but make an oversized state-directory `.env` a distinct, operator-visible condition and obtain maintainer agreement on the 1 MiB compatibility boundary before landing.
