## What This Changes

The PR adds a bounded `--startup-js-bytes` option so Control UI startup-budget baseline updates can record the byte count measured in CI instead of locally rebuilding compressed assets.

## System Context

The Control UI build produces compressed startup assets, and a budget script compares those sizes with a checked-in baseline. When CI detects an overage, this script provides the remediation command that maintainers use to update the baseline without weakening the fixed ratchet.
