## Summary

This issue remains necessary: current main combines a read-only federated catalog with separate command-level native-thread controls, but it does not provide the proposed interactive, model-locked supervised Chat flow or unified plugin ownership. The protected `maintainer` label and unresolved ownership and security choices require explicit maintainer direction.

## What This Changes

Make native Codex session supervision interactive and consolidate it into the official Codex plugin.

## Best Possible Solution

Consolidate Gateway-local supervision under the official Codex plugin in phases: source-preserving model-locked branches first, freshly verified and explicitly confirmed local archive second, and no paired-node mutation until a correlated runner lease exists.
