## Summary

Keep this canonical issue open for explicit maintainer direction. Current main deliberately splits official Codex thread interaction from the read-only federated catalog, so the requested interactive fleet workflow and ownership consolidation remain necessary; the protected `maintainer` label also rules out automated cleanup closure.

## What This Changes

Move federated Codex session supervision into the official Codex plugin and add safe transcript, continuation, interruption, archive, unarchive, and live-status controls.

## Best Possible Solution

Make the official `codex` plugin the sole interactive App Server owner, migrate `codex-supervisor` configuration through the plugin doctor contract, and deliver federation, read/resume, then interrupt/archive as separately reviewable phases with fresh-install, upgrade, authorization, and active-runner proof.
