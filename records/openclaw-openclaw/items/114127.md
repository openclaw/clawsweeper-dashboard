## Summary

Keep this PR open: it is a narrow, source-aligned fix for a still-present reply-normalization gap, with focused coverage for the shared token helper and two delivery paths. The proposed lookahead preserves the established punctuation safeguard while allowing whitespace- and newline-separated visible word-start content to reach the existing leading-token stripper.

## What This Changes

The PR changes silent-reply prefix detection so a leading `NO_REPLY` token separated from visible word-start reply text by spaces or newlines is removed before channel delivery, and adds regression coverage.

## System Context

OpenClaw normalizes model output before it is sent through channel delivery. The silent-reply token helpers decide whether to suppress a response or remove a control token from mixed-content text, and the normalized text then feeds final delivery.
