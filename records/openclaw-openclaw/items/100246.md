## Summary

Keep open: current main has pairing, allowlists, hook-token/transform gating, and plugin-owned signature-verification patterns, but not the requested owner-key signed-message gate; the remaining work is a security-boundary product decision, not a safe automatic fix.

## What This Changes

Request owner-key signature verification for selected inbound channels, such as email, so invalidly signed messages are logged or deleted before agent exposure.

## Best Possible Solution

Prefer plugin-owned or hook-transform verification for channel-specific signatures, and add a narrow SDK/pre-routing capability only if current hooks cannot keep unsigned content out of agent routing.
