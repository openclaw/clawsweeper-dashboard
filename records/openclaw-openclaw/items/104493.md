## Summary

Current main can read already-bound Claude CLI transcripts but does not discover Claude CLI/Desktop session catalogs across hosts. This fresh, protected feature proposal should remain open for explicit product and privacy direction.

## What This Changes

Add read-only discovery and cursor-paginated browsing of Claude CLI and Claude Desktop sessions from the Gateway and paired computers in the Control UI and native macOS app.

## Best Possible Solution

Define a narrow vendor-neutral, read-only plugin session-catalog capability with cursor-paginated transcripts and `operator.read` authorization, then keep Claude CLI/Desktop discovery and compatibility handling in its owning plugin while shared Control UI and macOS surfaces render the capability.
