## Summary

Current `main` still exposes `process.offset` and `process.limit` as unrestricted numbers, while the process log helper floors and clamps them. This PR is a narrow, correct schema-contract fix, and the updated terminal proof directly exercises the changed TypeBox definition; it should remain open for normal maintainer merge review.

## What This Changes

The PR changes the process tool’s optional `offset` and `limit` parameters from unrestricted numbers to non-negative integers.

## Best Possible Solution

Keep the integer, non-negative schema contract while retaining the existing runtime flooring and clamping as defense-in-depth for nonstandard callers.
