## What This Changes

The PR makes the legacy session-watch SQLite migration reject marker payloads that are not valid UTF-8, preventing malformed sentinel rows from changing an unrelated cursor's provenance.

## System Context

OpenClaw opens its shared SQLite state database during normal startup and doctor repairs. The session-watch migration converts legacy sentinel rows into a `provenance` value on cursor rows, then removes those sentinel rows.
