## Summary

Keep this PR open. The planned onboarding direction is documented, but the new wizard path only skips discovery after acceptance; a stored pending offer falls through to another scan/model call if onboarding is rerun before bootstrap completes, which contradicts the stated once-semantics and can replace the deferred offer.

## Best Possible Solution
