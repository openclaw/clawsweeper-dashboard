## Summary

This PR is a coherent, proof-backed QA Lab enhancement, but it adds a new documented environment surface whose scope needs maintainer product approval before merge. The implementation deliberately raises the shared fallback, so a high value can also extend mock-lane turns; that is a valid design choice only if maintainers want the variable to be QA-wide rather than live-frontier-only.

## What This Changes

The PR adds `OPENCLAW_QA_LIVE_TURN_TIMEOUT_MS`, a documented raise-only timeout floor for QA Lab turn resolution, with regression tests that preserve caller and provider minimums.

## System Context

QA Lab runs scenario turns through a provider-specific timeout policy. The caller supplies a fallback, the provider applies model-family minimums, and the resulting timeout controls how long a QA scenario waits for a turn to complete.
