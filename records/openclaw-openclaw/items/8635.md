## Summary

Current main still lacks a stable agent-facing contract for cumulative session usage, last-turn tokens, cost, and provider quota windows. The merged context-budget work is useful partial progress, while the related provider-cost, logging, and freshness items cover distinct slices rather than superseding this request.

## What This Changes

Expose cumulative session, last-turn, token, cost, and quota-window usage as structured agent-facing data from `session_status` or an equivalent supported tool.

## Best Possible Solution

Define one documented structured agent-facing usage contract—preferably additive `session_status.details.usage` fields or a dedicated usage tool—that reuses existing aggregation, preserves visibility checks, and reports source, freshness, and unavailable states explicitly.
