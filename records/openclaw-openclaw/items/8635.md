## Summary

Keep open: current main and v2026.6.11 still expose `session_status` primarily as rendered status text, while structured session totals, last-turn usage, costs, provider windows, availability, and freshness remain outside its agent-facing contract.

## What This Changes

Expose raw per-session, last-turn, cost, and quota usage through the agent-facing `session_status` tool.

## Best Possible Solution

Add an additive `details.usage` contract to `session_status` that reuses shared bounded usage parsers, exposes session and last-turn totals plus optional provider windows, includes explicit source/availability/as-of metadata, and applies the existing session visibility and agent-to-agent guards before reading usage.
