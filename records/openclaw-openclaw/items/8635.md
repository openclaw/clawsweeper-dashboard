## Summary

Keep open: current main and the latest release still provide a rendered status card rather than a stable agent-facing structured usage contract, and no related item supersedes the broader request.

## What This Changes

Expose structured per-session, last-turn, cost, and quota usage through the agent-facing `session_status` tool.

## Best Possible Solution

Add an additive typed usage object to `session_status.details` that reuses existing aggregation and visibility checks, preserves the rendered card, and explicitly reports source, freshness, estimation, and unavailable states for session totals, last-turn usage, costs, and quota windows.
