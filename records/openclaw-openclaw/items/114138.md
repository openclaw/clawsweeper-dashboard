## What This Changes

The PR makes unavailable implicit OpenAI embeddings fall back to read-only lexical FTS memory recall, preserves fail-closed behavior for explicitly configured remote providers, and uses API-key-only authentication for direct OpenAI embedding requests.

## System Context

Memory Core indexes workspace memory for agent recall using lexical FTS and optional semantic vectors. Embedding-provider initialization determines whether search uses hybrid semantic recall or safely serves compatible existing data through lexical-only recall while synchronization protects vector-index metadata.
