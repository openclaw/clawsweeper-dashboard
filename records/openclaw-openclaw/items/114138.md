## Summary

Keep this PR open for maintainer review. It repairs a documented implicit-provider behavior and includes strong after-fix runtime proof, but it intentionally changes existing users’ failure mode from unavailable memory search to read-only lexical recall, so the compatibility boundary should be explicitly accepted before merge.

## What This Changes

The branch lets Memory Core keep read-only lexical full-text recall from a compatible existing index when implicit OpenAI embeddings cannot authenticate, while explicit remote embedding providers remain fail-closed.

## System Context

Memory Core indexes workspace and session material into a local SQLite-backed search store with lexical full-text search and optional vector embeddings. Provider configuration and authentication choose hybrid recall when embeddings are usable, lexical-only recall when an implicit provider is unavailable, or an error for an explicitly requested unavailable remote provider.

Accept the documented implicit-provider fallback as the canonical behavior, retain explicit remote-provider fail-closed semantics, and preserve the index-identity and sync guards that prevent lexical-only mode from rewriting semantic metadata.
