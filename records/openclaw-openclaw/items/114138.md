## Summary

Keep this PR open for maintainer review. The patch has strong after-fix runtime proof and no concrete correctness or security defect found in the supplied diff, but it deliberately changes the upgrade-time contract for an unset or legacy-auto embedding provider: unavailable OpenAI API-key auth now serves read-only lexical recall rather than making memory search unavailable. That compatibility decision needs owner confirmation before merge.

## What This Changes

The PR makes implicit OpenAI memory embeddings degrade to read-only lexical FTS recall when API-key auth is unavailable, while retaining fail-closed behavior for explicitly configured remote providers.

## System Context

Memory Core indexes agent workspace and session material in SQLite for semantic vector search and lexical FTS recall. Provider initialization and index-identity checks determine whether search can use embeddings, lexical recall, synchronization, or a protected read-only mode.
