## What This Changes

The PR changes Memory Core so an unavailable implicit OpenAI embedding provider falls back to lexical FTS recall, while explicit remote embedding providers still fail closed and direct OpenAI embedding calls request API-key-only auth.

## System Context

Memory Core converts workspace memory sources into a local index used by agent recall. Provider initialization and authentication determine whether semantic vectors are available; index metadata and sync logic then decide whether results can safely come from vectors, lexical full-text search, or neither.
