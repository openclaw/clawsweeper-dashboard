## Summary

Keep this PR open for a Memory Core owner decision before merge. The supplied runtime proof is strong and the branch appears to implement the documented implicit-provider fallback, but it deliberately changes an existing unavailable-search outcome into read-only FTS recall for implicit and legacy-auto OpenAI setups; that compatibility promise needs explicit owner acceptance.

## What This Changes

The branch preserves lexical full-text memory recall from a compatible existing index when implicit OpenAI embeddings lack API-key authentication, while explicit remote embedding providers still fail closed.

## System Context

Memory Core builds local lexical and vector indexes from workspace and session sources, then serves agent memory searches. Provider authentication determines whether semantic embeddings are available; this change permits compatible local FTS results when only the implicit embedding provider is unavailable.
