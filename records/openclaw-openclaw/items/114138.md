## Summary

The patch appears to restore the documented implicit/auto embedding fallback while preserving explicit-provider failure, and the contributor supplied strong redacted runtime evidence; however, merging deliberately changes the post-auth-loss behavior of existing implicit semantic indexes from unavailable search to verified read-only FTS recall.

## What This Changes

This PR makes implicit or legacy-auto OpenAI memory embeddings fall back to verified lexical full-text recall when direct OpenAI API-key authentication is unavailable, while explicit remote providers remain fail-closed.

## System Context

Memory Core indexes configured memory files with lexical full-text search and optional vector embeddings. The embedding provider and index identity determine whether a query uses hybrid search, FTS-only recall, or an explicit-provider error.
