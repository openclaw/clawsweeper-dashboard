Request to add an opt-in agent/default config setting that omits the human-readable Tooling list from the generated system prompt while preserving callable tool schemas.

## Best Possible Solution

Decide the product direction, then implement a narrow opt-in prompt-surface setting that suppresses only visible Tooling-list text while preserving callable schemas, diagnostics, docs, and regression coverage.
