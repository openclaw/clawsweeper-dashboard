## Summary

Keep open. Current main still emits a per-tool name/summary list in the system prompt while separately supplying callable tool definitions, and it has no scoped option or automatic runtime rule that removes only the duplicated list; the optimization remains useful but needs maintainer direction because adding config is not clearly the best solution.

## What This Changes

Allow selected agent runs to omit the human-readable per-tool list from the system prompt while preserving callable tool schemas.

## Best Possible Solution

Make per-tool summary omission harness-aware for runs that provably receive structured callable definitions, retain the minimal Tooling rules, and add a config knob only if model/provider evaluation shows an operator override is necessary.
