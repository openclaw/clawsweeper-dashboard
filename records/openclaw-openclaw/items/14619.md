Request an opt-in config setting to omit the human-readable tool list from the agent system prompt while preserving callable tool schemas.

## Best Possible Solution

Make a maintainer product decision, then either keep this closed by policy against new prompt knobs or add a narrow opt-in setting that suppresses only the human-readable Tooling list while preserving customTools, Tool Search/code-mode behavior, context reporting, docs, and focused tests.
