## Summary

Keep this PR open: the patch is a focused security fix with sufficient terminal proof and no blocking code findings, but the owner-only archive default is a compatibility-sensitive shipped CLI artifact change that needs maintainer/security acceptance before merge.

## What This Changes

The branch creates backup archive temp files with `0o600` permissions and adds a regression test asserting the published archive is owner-only.

## Best Possible Solution

Ship the owner-only archive default after maintainer/security acceptance, with PR or release context telling operators who intentionally share backup artifacts to chmod or copy them explicitly after creation.
