## Summary

Keep open: current main still creates the backup archive stream without an owner-only mode, and this PR is a focused security hardening with no blocking code findings. The remaining decision is maintainer acceptance of the safer file-permission default because it can affect shared-user backup collection workflows.

## What This Changes

The PR changes the backup archive writer to create temp archives with `0o600` permissions and adds a regression test asserting the published archive mode.

## Best Possible Solution

Land the owner-only archive mode after maintainer acceptance of the file-permission compatibility change, with release-note context for operators who intentionally collect backups from another user or group.
