## Summary

Keep this issue open: current main still prefixes the active user turn with inbound metadata while the LLM boundary strips that same metadata once the turn is historical, and the closing implementation candidate at https://github.com/openclaw/openclaw/pull/100272 is still open rather than merged.

## What This Changes

The issue reports that active user-turn inbound metadata makes provider prompt bytes change when that same turn becomes history, breaking prompt-cache prefix stability.

## Best Possible Solution
