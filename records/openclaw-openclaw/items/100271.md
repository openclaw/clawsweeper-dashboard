## Summary

Keep this issue open: current `main` and the latest release still keep inbound metadata on the active user turn while stripping it once the same turn becomes historical, and the linked closing PR is still open rather than merged.

## What This Changes

The issue reports that active user turns include inbound channel metadata that is later stripped from history, making prompt-cache bytes change on every new turn.

## Best Possible Solution

Review and either land or close https://github.com/openclaw/openclaw/pull/100272; this issue should close only after that candidate fix merges or maintainers choose a different implementation.
