## Summary

The branch addresses the shared-client race, but it still loses the original one-shot retirement request when a retained native subagent holds a lease. That leaves the Codex app-server registered after the retained subagent drains, so this PR needs the existing deferred-retirement behavior restored before merge.

## What This Changes

The PR replaces unconditional one-shot Codex app-server client retirement with unclaimed-only retirement and adds shared-lease regression coverage.

## Best Possible Solution

Retain the unclaimed-only guard for concurrent sibling runs, while recording deferred retirement when a one-shot cleanup encounters a retained lease; add a regression that releases the retained subagent and proves the final release closes the shared client.
