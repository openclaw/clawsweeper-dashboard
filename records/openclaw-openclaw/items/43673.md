## Summary

Keep open: current main and v2026.6.11 have useful per-agent workspaces, routing, sender-scoped tool policy, sandbox policy, and Gateway operator scopes, but they still do not provide the requested team scaffold CLI, declarative deployment manifest, or first-class RBAC/tenant authorization model. The remaining work is a broad product/security decision rather than conservative cleanup.

## What This Changes

The issue requests first-class org/team deployment support: team workspace scaffolding, per-session or per-role tool policy, declarative agent deployment manifests, and org deployment docs.

## Best Possible Solution

Keep this as the org/team deployment umbrella, then split accepted work into maintainer-approved designs for team scaffolding, deployment manifests, scope or tenant RBAC, conversation identity, gateway session/auth semantics, and docs.
