## Summary

Keep open: current main has useful per-agent workspace, routing, sender/group tool-policy, operator-scope, and security guidance, but it still lacks the requested team scaffold CLI, declarative deployment manifest, and first-class org/team RBAC or tenant authorization contract. The April comment pointing to narrower per-session/per-sender policy work was directionally useful, but those slices do not close the broader umbrella.

## What This Changes

Requested first-class org/team deployment support, including workspace scaffolding, per-session tool policy/RBAC, deployment manifests, and org deployment documentation.

## Best Possible Solution

Keep this as the org/team deployment umbrella, then split accepted work into maintainer-approved designs for scaffolding/manifests, scope or tenant RBAC, gateway/session identity, and docs while preserving separate-gateway guidance until the threat model changes.
