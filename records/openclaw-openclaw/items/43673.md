## Summary

Keep open: current main has per-agent workspace/config primitives, sender/group tool policy, operator scopes, and security guidance, but it still lacks the requested team scaffold CLI, declarative deployment manifest, and approved org/team RBAC or tenant isolation contract. The linked incremental policy PRs and related RFCs are useful context, but they do not close the broader umbrella.

## What This Changes

The issue requests first-class org/team deployment support: workspace scaffolding, per-session tool/RBAC policy, declarative manifests, and org deployment documentation.

## Best Possible Solution

Keep this as the org/team deployment umbrella, then split accepted work into maintainer-approved designs for deployment scaffolding/manifests, scope or tenant RBAC, Gateway/session identity, and docs while preserving separate-Gateway guidance until the threat model changes.
