## Summary

Keep open: current main and v2026.6.11 still provide adjacent temporal recency decay and manual LanceDB importance fields, but not the requested write-time importance scoring, Weibull/access decay, contradiction handling, or builtin/QMD parity.

## What This Changes

Request to add write-time long-term memory importance scoring, time/access decay, and importance-weighted retrieval for long-running assistants.

## Best Possible Solution

Define a maintainer-approved memory-plugin design for durable importance metadata, decay/access reinforcement, contradiction replacement, and builtin/QMD behavior, then implement it with schema, docs, migration or doctor coverage, and focused ranking tests.
