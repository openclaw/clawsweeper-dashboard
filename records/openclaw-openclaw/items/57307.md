## What This Changes

## Best Possible Solution

Define a maintainer-approved memory-plugin contract for durable importance metadata, write-time scoring, decay/access reinforcement, contradiction handling, and backend parity before implementing schema, docs, migrations or doctor support, and focused ranking tests.
