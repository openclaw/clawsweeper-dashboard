## Summary

Keep open: current main still intentionally shortens home-contained paths in shared, TUI/session-tool, terminal-table, and web chat display helpers, while related merged work only fixed sibling-prefix corruption. This remains a product/display-contract decision rather than an implemented bug fix.

## What This Changes

The issue requests that agent-visible file paths use full absolute paths instead of tilde-based home-relative shorthand.

## Best Possible Solution

Define one central path-output contract for agent-visible displays, then update the shared helpers, TUI/session tools, web chat display, docs, and tests consistently; if full paths should be opt-in, keep the current default and document the upgrade-safe setting.
