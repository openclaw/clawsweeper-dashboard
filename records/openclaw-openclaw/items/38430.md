## Summary

Keep open: current main still intentionally shortens home paths to `~/...` in agent-visible display helpers, and the merged related PR only fixed corrupted sibling-prefix shortening rather than the broader request for full absolute paths.

## What This Changes

The issue asks OpenClaw to stop showing `~`-shortened paths in agent responses and use full absolute file paths instead.

## Best Possible Solution

Define a canonical path-display policy first, then update prompt guidance, shared display helpers, session renderers, and tests consistently without adding a new config/env option unless maintainers explicitly choose an opt-in mode.
