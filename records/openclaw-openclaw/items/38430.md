## Summary

Keep open: current main still intentionally shortens home-contained paths to `~` or `$OPENCLAW_HOME` in shared display helpers, session tool rendering, terminal tables, and ACP prompt prefixes; the merged related PRs fixed corrupted sibling-prefix rewrites, not the broader request to show full absolute paths everywhere.

## What This Changes

The issue asks OpenClaw agent responses to show full absolute file paths instead of `~` home-directory shorthand.

## Best Possible Solution

Define one central user-visible path display contract, then update shared helpers, ACP prompt prefixes, session/tool displays, terminal rendering, docs, and regression tests consistently if maintainers choose full paths or an explicit full-path mode.
