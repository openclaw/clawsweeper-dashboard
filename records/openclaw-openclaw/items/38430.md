## Summary

Keep open: current main and the latest release still intentionally shorten home-contained paths to `~` or `$OPENCLAW_HOME` across shared display helpers, ACP prompt prefixes, terminal display, and session tool rendering; related merged PRs fixed corrupted sibling-prefix rewrites, not the broader request to show full absolute paths everywhere.

## What This Changes

The issue requests that agent responses and related user-visible path displays use full absolute file paths instead of `~` home-directory shorthand.

## Best Possible Solution

Maintain one explicit display policy: if maintainers accept the request, implement it through shared display helpers and prompt-prefix guidance with focused tests, rather than post-processing arbitrary model text in one channel.
