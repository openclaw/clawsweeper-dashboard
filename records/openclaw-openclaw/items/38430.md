The issue requests agent-visible file paths to render as full absolute paths instead of home-relative `~/...` shorthand.

## Best Possible Solution

Define one explicit path-output contract for agent-visible replies and tool displays, then implement it centrally across shared helpers, prompts, and tests; if full paths are optional, prefer a documented upgrade-safe mode over ad hoc output post-processing.
