## Summary

Keep open. Current main still intentionally shortens home-contained paths to `~` or `$OPENCLAW_HOME` in shared display helpers, session tool rendering, terminal-core display, and tests; the merged related PR fixed malformed sibling-prefix shortening only, so the requested full absolute-path policy still needs maintainer direction.

## What This Changes

The issue requests that agent file-path output use full absolute paths instead of `~` shorthand.

## Best Possible Solution

Decide the path-display policy centrally; if full absolute paths are accepted, update the shared display helpers, session renderers, terminal-core display, and prompt guidance with focused regressions instead of ad hoc output post-processing.
