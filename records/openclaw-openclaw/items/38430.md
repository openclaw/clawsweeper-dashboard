## Summary

Keep open. Current main and the latest release still intentionally shorten home-contained paths to `~` or `$OPENCLAW_HOME`; the merged related work fixed corrupted sibling-prefix shortening, not the requested full absolute-path policy.

## What This Changes

The issue asks OpenClaw to stop rendering agent file paths with `~` shorthand and instead show full absolute paths.

## Best Possible Solution

Decide the path-display policy centrally; if full absolute paths are accepted, implement it in the shared display helpers and embedded-agent prompt with focused regression tests.
