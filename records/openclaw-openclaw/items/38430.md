## Summary

Keep open. Current main still intentionally shortens home paths to `~` or `$OPENCLAW_HOME`; related merged work fixed corrupted sibling-prefix shortening, not the requested full absolute-path policy, so this needs maintainer product direction rather than cleanup closure.

## What This Changes

Request that OpenClaw stop using home-directory tilde shorthand in agent-facing file path output and show full absolute paths instead.

## Best Possible Solution

Decide the path-display policy centrally; if full absolute paths are accepted, implement it in the shared display helpers and embedded-agent prompt with focused regressions instead of ad hoc message post-processing.
