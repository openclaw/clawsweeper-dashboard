Keep open. Current main and the latest release still intentionally shorten home-contained paths to `~` or `$OPENCLAW_HOME`, and the merged related work only fixed corrupted sibling-prefix shortening, so the remaining request needs maintainer product direction rather than cleanup closure.

The issue requests that agent responses use full absolute file paths instead of `~` home-directory shorthand.

## Best Possible Solution

Decide the path-display policy centrally; if full absolute paths are accepted, update shared display helpers, prompt guidance, and affected display surfaces with focused regression coverage instead of post-processing final text ad hoc.
