## Summary

This PR still needs changes before merge: its new shared code-region helper recognizes fenced and inline backtick spans but no longer preserves four-space-indented Markdown code blocks. A qualified `antml:` or `mm:` invoke example in an indented block therefore reaches the delivery and persistence scrubbers as ordinary text and is removed. The prior ClawSweeper finding remains unresolved on the current head.

## What This Changes

The branch removes proxy-degraded `antml:`/`mm:` and `<function_calls>`-wrapped tool-call XML from visible replies and persisted assistant text while trying to preserve legitimate Markdown examples.

## System Context

OpenClaw sanitizes model-generated text before delivering it to chat channels and before saving assistant text to session history. Markdown code-region detection is the safeguard that lets these sanitizers remove leaked tool-call markup without deleting documentation examples.

## Best Possible Solution

Restore the prior block-aware Markdown-code-region semantics, including indented code blocks, in the one shared implementation used by both core sanitizers and `tool-call-repair`, then add delivery and history regressions for qualified invoke examples in indented blocks.
