## What This Changes

This PR recognizes proxy-degraded `antml:`/`mm:` and `<function_calls>`-wrapped attribute-style tool-call XML, removes qualified leaks from visible replies and persisted assistant text, and preserves bare or Markdown-code XML examples.

## System Context

Provider responses can arrive as text when a proxy degrades a structured tool call; OpenClaw then sanitizes text for delivery and separately stores the completed assistant message. The PR changes both paths so qualified proxy-shaped XML is not shown to users or retained as a completed response.
