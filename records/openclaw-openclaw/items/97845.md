## Summary

This remains a useful, mechanically coherent fix for a current-main gap, but it should stay open for an explicit owner decision on whether qualified proxy-style XML may be deleted from durable assistant history as well as visible delivery.

## What This Changes

The PR adds recognition and removal of proxy-degraded `antml:`/`mm:` and `<function_calls>`-wrapped invoke XML from assistant-visible and persisted text, while preserving bare and Markdown-code XML examples.

## System Context

OpenClaw sanitizes assistant text before it reaches chat channels and before completion text is retained in session history. This PR extends the shared text and tool-call-repair paths so provider-degraded tool-call markup is removed rather than exposed or persisted.
