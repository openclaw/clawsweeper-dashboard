## What This Changes

The branch removes namespaced or `<function_calls>`-wrapped degraded invoke XML from visible replies and persisted assistant text while preserving bare and Markdown-code XML examples.

## System Context

Assistant output passes through shared visible-text sanitization before delivery and through tool-call-repair before terminal assistant text is persisted. This PR changes both paths so proxy-degraded tool-call markup is discarded rather than displayed or retained in session history.
