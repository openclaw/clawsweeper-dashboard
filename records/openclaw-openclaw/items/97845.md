## Summary

This PR addresses a real current-main sanitizer gap and supplies credible direct-helper before/after proof. The patch is mechanically coherent and preserves bare XML examples, but merging deliberately deletes qualified tool-call-shaped text from durable assistant history as well as visible delivery; that shared policy needs an explicit owner decision before merge.

## What This Changes

The PR strips proxy-degraded `antml:`/`mm:` and `<function_calls>`-wrapped invoke-style tool-call XML from visible replies and persisted assistant text while preserving bare and Markdown-code XML examples.

## System Context

OpenClaw’s agent output passes through shared visible-text and plain-text tool-call cleanup before it is delivered to channels and retained in assistant/session history. This PR changes how that shared cleanup classifies provider-qualified invoke XML, affecting both immediate replies and durable `done.message` content.
