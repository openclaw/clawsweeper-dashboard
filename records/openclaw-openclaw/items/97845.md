## Summary

Keep this PR open for explicit maintainer direction. The reported sanitizer gap remains a valid P1 concern and the branch has focused tests and real before/after output, but merging deliberately makes qualified `antml:`/`mm:` invoke markup destructive in durable assistant history when it appears outside Markdown code regions; that compatibility boundary is a product-policy choice rather than a mechanical defect.

## What This Changes

The branch removes namespace-qualified or `<function_calls>`-wrapped degraded invoke-style XML from user-visible replies and persisted assistant text while preserving bare unqualified and Markdown-code XML examples.

## System Context

Provider or proxy output is passed through shared visible-text cleanup and tool-call-repair before OpenClaw sends a reply and records its assistant text in session history. This PR extends the classifiers that distinguish leaked tool-call markup from retained user-facing content.
