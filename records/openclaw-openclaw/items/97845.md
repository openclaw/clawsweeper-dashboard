## Summary

Needs changes before merge. The PR’s new shared code-region helper recognizes fenced and inline-backtick Markdown only, replacing the current block-aware helper that also protects indented code. As a result, a namespaced leaked-looking `<invoke>` example inside a four-space-indented code block can be stripped from both delivered text and persisted history. Likely related people: current-main ownership is unclear from the available history, so route this to the shared text-sanitizer area with low confidence.

## What This Changes

This PR strips proxy-degraded `antml:`/`mm:` and `<function_calls>`-wrapped invoke XML from visible replies and persisted assistant text while preserving recognized Markdown code examples and bare unqualified invoke examples.

## System Context

OpenClaw sanitizes model text before sending it to chat channels and before recording assistant text in session history. The shared code-region detector tells those sanitizers when tool-call-shaped XML is a documentation example rather than leaked provider markup.
