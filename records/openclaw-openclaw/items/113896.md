## What This Changes

Adds `dreaming.nephesh.enabled` to the bundled memory plugin so new Dream Diary entries include a Nephesh-oriented HTML-comment provenance envelope, with tests and user documentation.

## System Context

The bundled memory plugin generates Dream Diary narratives and appends them to the workspace’s `DREAMS.md` file. This PR adds an optional metadata envelope at that write boundary so a separate memory system can classify the resulting entries during ingestion.
