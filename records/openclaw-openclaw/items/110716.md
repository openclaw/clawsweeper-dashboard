## Summary

This PR does not yet bound the actual read operation: it stats first and then calls unbounded `FileHandle.readFile()`, so a file that grows after the stat can still exhaust host memory. It also needs real after-fix runtime proof rather than only test-suite output.

## What This Changes

The branch adds a 100 MiB stat-based pre-read cap and regular-file check to OpenShell sandbox reads in `extensions/openshell/src/fs-bridge.ts`.

## Best Possible Solution

Use the existing filesystem-safe bounded-read primitive with an enforced `maxBytes` limit, preserve the bridge’s path-safety contract, add focused regression coverage for normal and oversized reads, and provide a redacted real runtime transcript showing both outcomes.
