## Label Justifications

- `P1`: The issue describes a real automated cron workflow silently stopping after async media completion, which is an urgent broken agent workflow rather than low-risk polish.
- `impact:session-state`: The generated-media completion resumes the same cron session key without the original run context, causing session/task state drift.
- `impact:message-loss`: The cron job can end with `NO_REPLY` and no final user notification after completing only part of the requested work.
- `impact:auth-provider`: The reported failure changes the continuation from the cron-configured model to the account default model, which is provider/model routing impact.

## Summary

Keep open: current main still has a source-reproducible cron/media continuation gap where generated-media completion is routed as a requester-agent handoff that carries the media completion event and session key, but not the originating cron task prompt, configured model, or thinking level.

## What This Changes

The issue reports that an isolated cron `image_generate` async completion resumes under the default model and generic prompt, dropping the original cron task and configured model.

## Best Possible Solution

Add a generated-media continuation path that resumes with the originating cron run's model, thinking level, bootstrap mode, and task prompt, or an explicit maintainer-approved equivalent, with regression coverage for image, music, video, and silent-abandon diagnostics.

## Reproduction Assessment

Yes, source-level reproduction is high confidence: session-backed media generation detaches, the completion handoff omits model/thinking/original cron prompt, and the agent-run path then falls back to ordinary model/session selection. I did not run a live cron/media replay in this read-only review.

## Solution Assessment

Unclear until maintainers choose the boundary: preserving the originating cron runtime context looks like the narrowest fix, while `background: false` is a workaround feature and diagnostics alone would not restore the dropped task.
