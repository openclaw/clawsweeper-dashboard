## Summary

Keep this PR open for maintainer product/auth review. The implementation is mechanically focused and has strong after-fix live proof, but it turns free-priced OpenCode Zen models into an anonymous access path while both current OpenClaw and OpenCode documentation still describe Zen as API-key authenticated.

## What This Changes

The PR adds model-scoped synthetic no-auth handling for six OpenCode Zen models, passes the selected model ID through provider synthetic-auth resolution, and removes their OpenAI-compatible Authorization header.

## Best Possible Solution
