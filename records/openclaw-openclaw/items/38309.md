## Summary

Keep open: current main and the latest release still reject structured `SecretRef` values in `sandbox.docker.env`, and https://github.com/openclaw/openclaw/pull/98216 is the open implementation candidate rather than a merged fix.

## What This Changes

Request support for structured SecretRef values in `sandbox.docker.env` so sandbox containers can receive secrets without storing plaintext values in `openclaw.json`.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/98216 after explicit maintainer/security acceptance of static SecretRefs resolving into Docker env metadata, keeping per-call credential injection separate.
