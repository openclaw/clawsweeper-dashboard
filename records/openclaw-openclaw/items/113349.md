## Summary

This PR is still necessary: current `main` builds normalized SDK event IDs with a truthiness filter, which drops protocol-valid zero values. The proposed focused change preserves `seq: 0` and `payload.ts: 0` without altering the gateway schema or adding a parallel API path; it looks ready for normal merge once required CI completes.

## What This Changes

The PR changes normalized gateway-event ID construction to retain zero-valued sequence and timestamp components and adds a regression test for that protocol-valid case.

## System Context

The SDK normalizes gateway protocol events into stable client-facing events. Those normalized IDs feed replay/live deduplication in SDK consumers, so the normalizer must retain every valid identity component before clients process the event stream.
