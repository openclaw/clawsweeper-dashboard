## What This Changes

The PR stores a canonical agent owner on Google Meet sessions, threads trusted tool agent identity through `test_listen`, reuses sessions only for the same agent, and ends an existing Chrome talk-back bridge before another agent reuses the same tab.

## Best Possible Solution

Land the narrow session-owner fix after exact-head CI and maintainer merge checks so each Google Meet session carries one canonical agent owner and same-tab reassignment ends the old bridge first.
