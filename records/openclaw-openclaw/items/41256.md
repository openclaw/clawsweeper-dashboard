## Summary

Keep open: current main still drops MIME metadata on Discord media sends and native interaction replies, and WebP or animated image preservation is only partial. The same-repo closing PR remains open and conflicting rather than merged.

## What This Changes

Discord uploads should preserve MIME content type and avoid converting WebP or animated images in ways that drop format or frames.

## Best Possible Solution

Land or replace the linked same-repo fix so Discord standard sends, component sends, and native interaction replies preserve MIME type, while animated/WebP media is preserved or rejected with a clear cap error instead of silently re-encoded.
