## What This Changes

This PR makes background-session `process kill` and `process remove` request supervisor cancellation and also invoke process-tree termination when a supervisor record exists, while leaving final session-state observation to the supervisor.

## System Context

The agent `process` tool controls backgrounded shell commands created by `exec`. It coordinates the in-memory session registry with the process supervisor and the platform process-tree terminator so a user action stops the underlying command without prematurely reporting its terminal state.
