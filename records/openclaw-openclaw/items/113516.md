## What This Changes

The PR changes agent background-session kill and remove actions so they request supervisor cancellation and also invoke process-tree termination when the session is supervisor-managed.

## System Context

OpenClaw's process tool manages background shell sessions created by agent tool calls. Kill and remove requests consult the supervisor and process registry, then must terminate the child process tree while preserving accurate session completion state.
