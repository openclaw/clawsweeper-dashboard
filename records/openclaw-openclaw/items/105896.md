## What This Changes

The PR changes the bundled LanceDB memory plugin to create an empty schema-defined table atomically, retry brief table-readiness races, and test initialization from six concurrent Node processes.

## System Context

The bundled `memory-lancedb` plugin lazily opens the persistent `memories` table when an agent stores, searches, lists, or counts memory. This initialization produces the table handle used by later memory operations, so a cross-process create race can make gateway or worker startup fail before memory is available.
