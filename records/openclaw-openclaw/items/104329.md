## Summary

This PR should stay open because its central isolation fix does not work through the selected command path: after the checkout advances, `pnpm openclaw gateway stop` rebuilds stale `dist` before stopping the running Gateway. The local-log fallback is directionally useful, but the pre-build lifecycle blocker makes the patch unsafe to merge as written.

## What This Changes

The PR stops the managed Gateway before rebuilding the live checkout and adds local structured-log fallback auditing when RPC verification or log retrieval fails.

## Best Possible Solution

Run the existing managed-service stop lifecycle through a non-building entry point, prove the service is stopped before the first `dist` mutation, then preserve exact-SHA build validation, restart, deep health checks, and restart-window RPC/local-log auditing.
