## Summary

Keep open: current main and the latest release still do not provide DashScope/Qwen provider-account usage snapshots, even though older DashScope streaming token accounting was fixed. The linked Token Plan PR is adjacent and explicitly leaves Alibaba usage accounting as a separate follow-up.

## What This Changes

Request adding DashScope/Qwen provider usage API support so UI/provider usage status no longer shows zero while tokens are actually consumed.

## Best Possible Solution

Add Qwen-owned resolveUsageAuth and fetchUsageSnapshot hooks, map Qwen/DashScope aliases into provider usage only after endpoint semantics are proven, and update docs/tests with redacted live usage proof.

## Reproduction Assessment

Yes, at source level: current main cannot resolve Qwen/DashScope IDs into UsageProviderId and the Qwen plugin has no usage auth or snapshot hook. I did not run a live DashScope credential scenario in this read-only review.

## Solution Assessment

No, adding DashScope to the allowlist alone is not the best fix because the loader still needs provider-owned auth and response normalization. The best path is a Qwen plugin usage hook plus resolver/docs/test/live-proof work.
