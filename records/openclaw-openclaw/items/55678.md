## Summary

Keep open: the generic provider-usage platform is now on current main, but Qwen/DashScope still has no `contracts.usageProviders` declaration or usage auth/snapshot hook, so the reported provider-side usage gap remains.

## What This Changes

Request to add DashScope/Qwen provider usage support so the Usage UI does not show zero or missing provider usage while tokens or credits are being consumed.

## Best Possible Solution

Implement the usage snapshot inside the Qwen plugin using the existing `contracts.usageProviders` seam, with provider-owned auth resolution and tests for the supported DashScope/Qwen plan variants.
