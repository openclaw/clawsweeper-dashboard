## Summary

Keep open: current main and v2026.6.11 still omit Qwen/DashScope from the provider-usage resolver, and the qwen plugin has no usage auth or snapshot hook. The linked Token Plan PR is adjacent but explicitly leaves Alibaba usage accounting as a separate follow-up.

## What This Changes

Request to add DashScope/Qwen provider account-usage support so UI and status surfaces do not show zero usage while tokens are being consumed.

## Best Possible Solution

Add qwen-owned resolveUsageAuth and fetchUsageSnapshot support, then map Qwen/DashScope aliases into the usage resolver with docs, focused tests, and redacted live endpoint proof.
