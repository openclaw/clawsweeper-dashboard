## Summary

Keep this PR open. It is a focused candidate fix for the linked silent-channel bug, but it intentionally changes the `message_tool_only` delivery contract and still lacks redacted after-fix proof from a real SDK channel; that contract needs maintainer direction before merge.

## What This Changes

The branch carries a non-deliverable terminal-turn classification from the embedded agent runner into reply settlement so message-tool-only channel plugins can send one fallback error instead of remaining silent.

## System Context

Embedded agent runs classify terminal outcomes before auto-reply settles a user turn. The resulting payloads and metadata drive follow-up routing and outbound channel-plugin delivery, including the special `message_tool_only` mode.
