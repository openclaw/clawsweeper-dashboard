## Summary

Keep open: current main still shows a concrete owner-authorization gap across `/learn`, `skill_workshop apply`, and `/approve`, and no merged canonical fix owns this specific non-owner self-approval bypass.

## What This Changes

The issue requests owner-tier authorization for `/learn`, Skill Workshop lifecycle apply, and `/approve` so non-owner authorized senders cannot self-apply workspace skills.

## Best Possible Solution

Enforce owner-tier authorization at every Skill Workshop lifecycle mutation boundary and approval resolution path, with regression tests proving non-owner authorized senders cannot create, apply, or self-approve live workspace skills.
