## Summary

Keep open for explicit owner handling: the report identifies a credible latent session-state invariant, but current adoption still uses the default agent, and the protected `maintainer` label plus plugin-contract implications make automatic cleanup inappropriate.

## What This Changes

Carry the provider-authoritative owning agent ID through catalog session continuation so adopted-session upstream links remain correctly scoped for future non-default-agent adoption.

## Best Possible Solution

Define one canonical provider-authoritative agent identity, carry it unchanged through the gateway, watch cursor, and upstream-link write/join, cover duplicated bare session keys across agents, and use a maintainer-approved additive contract shape that does not strand external providers.
