## What This Changes

The PR makes Control UI chat right-clicks defer to the browser context menu when the selected range is inside the clicked message bubble, while retaining the custom Reply menu when no text is selected.

## Best Possible Solution

Land the selection-aware early return with its two regression cases after required checks are green; using the native menu is preferable to a custom Copy item or new setting because it retains browser-provided search, spell-check, and accessibility integrations.
