## Summary

Keep this PR open, but it is not ready to merge as written: it fixes a real plugin-stall path while changing the intentional full-catalog contract so `models.list` with `view=all` can return a partial catalog after 15 seconds. The branch needs a narrower route-specific design or explicit maintainer approval for that behavioral change.

## What This Changes

The branch runs provider `augmentModelCatalog` hooks concurrently with 15-second abortable deadlines, returns healthy-plugin rows after timeouts, and avoids caching incomplete full-catalog results.

## Best Possible Solution

Keep the existing exact semantics for full catalog requests, and introduce a clearly scoped degraded/stale response path only for catalog consumers that explicitly permit partial discovery; then prove both paths with Gateway and provider-runtime tests.
