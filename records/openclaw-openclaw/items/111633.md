## What This Changes

The branch gives in-tab Google Docs text exports a 30-second abort deadline so a stalled Chrome-extension page share returns through the existing error path instead of remaining pending indefinitely.

## System Context

The Chrome extension captures a user-selected browser tab and relays extracted page content to OpenClaw. Google Docs requires an in-tab authenticated export using the user's browser session before the page-share relay can complete.
