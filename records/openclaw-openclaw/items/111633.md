## What This Changes

The PR gives Google Docs text exports from the Chrome page-share flow a 30-second abort deadline, preventing the send UI from remaining pending indefinitely when the in-tab export stalls.

## System Context

The Chrome extension captures the current browser tab, and Google Docs pages are exported from inside that tab so the request can use the user’s signed-in browser session. The extracted text is then passed to the page-share relay; errors return to the existing popup and keyboard/context-menu rejection paths.
