## What This Changes

The issue asks memory-core to bound SQLite embedding-cache and index-chunk growth, clean obsolete index revisions, store embeddings more compactly, and honor configured dimensions.

## System Context

memory-core turns configured workspace files and, optionally, prior session transcripts into searchable chunks stored in each agent’s SQLite database. Extraction and embedding writes feed the index and cache, which later serve semantic memory-search queries.

## Best Possible Solution

Audit the current cache-pruning trigger and index replacement/deletion paths against a redacted database sample, then define a plugin-owned bounded-cache default and rebuild-safe retention policy; treat any JSON-to-BLOB conversion as a separately proven persistent-data migration.
