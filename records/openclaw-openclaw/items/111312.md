## What This Changes

This PR gives the gateway’s self-signed TLS certificate generation a 30-second process deadline and adds a regression test that verifies the timeout reaches the execution wrapper.

## System Context

Gateway startup and doctor can create a local self-signed certificate when TLS is enabled but certificate files are absent. That path invokes the system `openssl` binary; its result determines whether TLS startup can proceed or fails with a surfaced error.
