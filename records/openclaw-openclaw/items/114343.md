## What This Changes

This PR adds a fresh, tool-free completion path for `llm-task` and supported agent runtimes, requiring an exact selected provider, prepared credentials, empty native tool surface, and fail-closed behavior when isolation cannot be enforced.

## System Context

`llm-task` is a plugin tool that needs one JSON-oriented model response without entering a normal agent turn. The new path selects a provider and authentication profile, dispatches to a harness or CLI runtime that can enforce zero tools, then returns validated text to the calling tool without transcript, hook, or channel-delivery side effects.
