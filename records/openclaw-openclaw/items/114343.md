This PR replaces `llm-task`’s embedded agent turn with a fresh, tool-free isolated completion path implemented by supported harnesses and CLI runtimes.

## System Context

`llm-task` needs one model completion that cannot inherit the calling agent’s transcript, lifecycle hooks, delivery flow, or tool surface. The new coordinator selects the requested runtime, passes prepared model/auth state to an owner-specific zero-tool boundary, then returns a single text assistant result to the task caller.
