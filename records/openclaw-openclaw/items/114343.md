## What This Changes

Adds a fresh, tool-free isolated-completion path for `llm-task` and other pure-inference callers, with implementations for the built-in, Codex, Copilot, Claude CLI, and Gemini CLI runtimes.

## System Context

`llm-task` is a plugin tool that asks a selected model for structured output. This PR routes that request through a new one-shot inference boundary so runtime owners receive a prepared model and credential, enforce a zero-tool request, and return one assistant completion without entering the normal agent-turn lifecycle.
