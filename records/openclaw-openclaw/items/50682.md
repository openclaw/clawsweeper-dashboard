## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Limit unknown actions to truly unlisted chats:** `extensions/telegram/src/unknown-group.ts:12`
  - body: `group-policy-allowlist-empty` is also returned for wildcard-covered groups that lack sender allowlist entries, as the current group-access test documents. Treating that as an unknown group means `unknownGroupAction: "leave"` can eject the bot from a group covered by `groups["*"]` instead of only from a truly unlisted chat.
  - confidence: 0.9
- **[P2] Use the Telegram thread helper for warning sends:** `extensions/telegram/src/bot-handlers.runtime.ts:1660`
  - body: This sends raw `resolvedThreadId`, but existing Telegram helpers omit `message_thread_id=1` because Telegram rejects General-topic sends with that value. In a General-topic forum, warn/leave mode can fail to post the warning and then still leave the chat.
  - confidence: 0.88
- **[P2] Apply unknown-group actions to native commands:** `extensions/telegram/src/bot-handlers.runtime.ts:1645-1646`
  - body: The new action path only runs from the normal message handler. Native slash/plugin commands are registered first and `resolveTelegramCommandAuth` handles `group-chat-not-allowed` with a fixed denial response, so an unknown group whose first activity is `/help` or a plugin command will not warn or leave as configured.
  - confidence: 0.86
