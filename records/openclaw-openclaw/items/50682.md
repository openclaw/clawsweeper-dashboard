## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Stop treating empty sender allowlists as unknown groups:** `extensions/telegram/src/unknown-group.ts:12`
  - body: `group-policy-allowlist-empty` is not the same as an unregistered chat: current group policy treats `groups["*"]` as admitting the group while sender filtering still applies. Marking that reason as unknown means `unknownGroupAction: "leave"` can eject the bot from wildcard-configured groups instead of only from chats missing the group allowlist.
  - confidence: 0.91
- **[P2] Route native commands through the same unknown-group action:** `extensions/telegram/src/bot-handlers.runtime.ts:1645-1646`
  - body: The new action only runs in the normal message handler, but Telegram native commands are registered first and `resolveTelegramCommandAuth()` still sends fixed denial text for disallowed groups. If the first activity in an unknown group is `/help` or a plugin command, the configured warn/leave behavior is bypassed.
  - confidence: 0.88
- **[P2] Use the Telegram thread helper for warning sends:** `extensions/telegram/src/bot-handlers.runtime.ts:1660`
  - body: This warning send passes `resolvedThreadId` directly, so a forum General topic resolves to `message_thread_id: 1`; current Telegram helpers intentionally omit that id because Telegram rejects it for message sends. Use the existing thread spec/helper path before calling `sendMessage`.
  - confidence: 0.9
- **[P2] Document the new Telegram config surface:** `src/config/zod-schema.providers-core.ts:283-285`
  - body: The PR adds strict `unknownGroup*` config keys but does not update the Telegram docs/config reference or setup guidance, leaving a security-sensitive opt-in behavior undiscoverable and the config contract incomplete.
  - confidence: 0.82
- **[P3] Prune expired cooldown entries:** `extensions/telegram/src/unknown-group.ts:27`
  - body: `lastActionAt` only grows; a long-running bot exposed to many unknown group IDs will retain entries after their cooldown window and even after successful leaves. Delete expired entries when checking cooldown, or bound the tracker by time/size.
  - confidence: 0.78
