## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Separate unknown chats from sender allowlist misses:** `extensions/telegram/src/unknown-group.ts:11-12`
  - body: `group-policy-allowlist-empty` is not only an unregistered chat. With `groups: {"*": ...}` the chat is intentionally covered, but current group policy still returns this reason when no sender allowlist is configured; mapping it to unknown means `unknownGroupAction: "leave"` can eject the bot from a configured wildcard group. Classify only true unregistered chats, or carry a more precise access result from the group policy helper.
  - confidence: 0.91
- **[P2] Use thread helper for unknown-group warnings:** `extensions/telegram/src/bot-handlers.runtime.ts:1657-1661`
  - body: This direct `message_thread_id` send will include `1` for a forum's General topic, but `buildTelegramThreadParams()` intentionally omits that value because Telegram rejects it for message sends. In General-topic forums, `warn` will 400 and `leave` will leave without the configured warning, so this path should use the same thread helper as normal sends.
  - confidence: 0.9
- **[P2] Cover native commands with the same unknown-group action:** `extensions/telegram/src/bot-handlers.runtime.ts:1644-1646`
  - body: The new action runs only in the normal message handler. Native command handlers are registered before `registerTelegramHandlers`, and command auth currently replies with a fixed denial for `group-chat-not-allowed`, so `/help` or plugin commands in an unknown group bypass the configured warn/leave behavior. Move this into shared authorization preflight or thread the action into native command auth too.
  - confidence: 0.86
- **[P2] Publish the new config surface consistently:** `src/config/zod-schema.providers-core.ts:283-285`
  - body: Adding strict config fields in the schema is not enough for a user-visible Telegram option. The PR does not update public Telegram docs or generated config metadata/help, so setup/UI/docs surfaces will drift from the runtime contract. Add the docs and regenerate the committed metadata that exposes channel config fields.
  - confidence: 0.82
- **[P3] Bound the cooldown tracker state:** `extensions/telegram/src/unknown-group.ts:16-31`
  - body: `lastActionAt` only grows. A long-running bot that is added to many unknown groups can retain one entry per chat forever, including chats it already left; evict expired entries when checking cooldown or otherwise bound the map.
  - confidence: 0.8
