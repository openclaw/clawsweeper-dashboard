- **[P1] Classify only real chat misses as unknown groups:** `extensions/telegram/src/unknown-group.ts:11`
  - body: `group-policy-allowlist-empty` is a sender-authorization failure, not necessarily an unknown chat.   - confidence: 0.88
- **[P1] Apply unknown-group actions before native commands:** `extensions/telegram/src/bot-handlers.runtime.ts:1650`
  - body: Native slash/plugin commands are registered before the message handler and return from their own grammY handlers after authorization. A first `/help` or plugin command in an unknown group therefore bypasses this new warn/leave path, so the configured action is not consistently enforced.
  - confidence: 0.9
- **[P2] Use the Telegram thread helper for warning sends:** `extensions/telegram/src/bot-handlers.runtime.ts:1666`
  - body: This sends `{ message_thread_id: resolvedThreadId }` directly. For a forum General topic, `resolvedThreadId` can be `1`, and current `buildTelegramThreadParams` omits `1` because Telegram rejects it; `warn` can fail and `leave` can happen without the configured warning.
  - confidence: 0.91
