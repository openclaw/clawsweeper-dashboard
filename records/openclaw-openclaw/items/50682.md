## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Restrict unknown actions to unregistered chats:** `extensions/telegram/src/unknown-group.ts:12`
  - body: `group-policy-allowlist-empty` is not the same as an unregistered group. With `groups: {"*": ...}` the chat is intentionally admitted by wildcard config, but sender authorization can still be empty; this PR can warn or eject the bot from a configured group instead of only unknown groups.
  - confidence: 0.9
- **[P2] Apply unknown-group handling to native commands:** `extensions/telegram/src/bot-handlers.runtime.ts:1647`
  - body: The new warn/leave handling only runs in the regular message path. Native slash commands are registered before the message handlers and return their own auth denial, so `/help` or plugin commands in an unknown group bypass `unknownGroupAction` and leave the bot in place.
  - confidence: 0.87
- **[P2] Use the thread helper for warning sends:** `extensions/telegram/src/bot-handlers.runtime.ts:1660`
  - body: This sends raw `resolvedThreadId` as `message_thread_id`. For a forum General topic that value can be `1`, and the existing Telegram helper omits that value because Telegram rejects it; the warning can fail before a configured leave action.
  - confidence: 0.86
- **[P3] Prune expired cooldown entries:** `extensions/telegram/src/unknown-group.ts:16-32`
  - body: The cooldown map only grows as new unknown chat IDs are seen. A long-running bot exposed to many unknown groups can retain expired entries forever, so `isOnCooldown` should drop stale records or bound the map.
  - confidence: 0.74
