## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Count the same messages assemble receives:** `src/agents/harness/context-engine-lifecycle.ts:165-167`
  - body: `assembleHarnessContextEngine` strips OpenClaw runtime-context custom messages before invoking the engine, but this spread forwards a caller-supplied `currentTokenCount` unchanged. When the input contains a hidden runtime-context custom message, the engine receives the stripped `messages` array while `currentTokenCount` still includes the hidden message, so `tokenBudget - currentTokenCount` underestimates headroom and can make the new field unreliable. Compute the count from the same stripped message set, or have the wrapper derive/pass both together.
  - confidence: 0.89
- **[P2] Regenerate the SDK API baseline:** `src/plugin-sdk/agent-harness-runtime.ts:360-362`
  - body: This adds `computeContextEngineMessageBudget` and `estimateTranscriptTokenPressure` to the public `openclaw/plugin-sdk/agent-harness-runtime` surface, but the generated SDK API baseline/hash artifacts are not updated in this diff. The plugin SDK contract checks use those artifacts to track public export drift, so the PR needs the regenerated baseline committed with the new exports.
  - confidence: 0.86
