Full review comments:

- **[P2] Count the same messages assemble receives:** `src/agents/harness/context-engine-lifecycle.ts:165-167`
  - body: `assembleHarnessContextEngine` strips hidden runtime-context custom messages before calling the engine, but the new `currentTokenCount` is computed by callers from the unstripped array and then forwarded unchanged here. On turns with runtime-context carriers, engines using `tokenBudget - currentTokenCount` will see less headroom than the `messages` they actually receive consume, which can make them skip valid `systemPromptAddition`s. Derive the estimate from the same stripped messages array or have the wrapper own both values together.
  - confidence: 0.87
