## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P2] Count the same messages assemble receives:** `src/agents/harness/context-engine-lifecycle.ts:164-166`
  - body: `assembleHarnessContextEngine` strips runtime-context custom messages before calling the engine, but the new `currentTokenCount` is computed by callers from the unstripped arrays. When hidden runtime-context messages are present, engines receive fewer messages than the count covers, so `tokenBudget - currentTokenCount` underestimates available headroom and can make plugins skip or over-trim valid context. Derive the count from the same stripped message set, preferably in the wrapper, and cover that case.
  - confidence: 0.86
- **[P2] Regenerate the SDK API baseline:** `src/plugin-sdk/agent-harness-runtime.ts:360-362`
  - body: This PR adds public exports from `openclaw/plugin-sdk/agent-harness-runtime`, but it does not update `docs/.generated/plugin-sdk-api-baseline.sha256`. The plugin SDK baseline check is meant to catch exactly this contract drift, so the public API hash needs to be regenerated and committed with the export changes.
  - confidence: 0.93
