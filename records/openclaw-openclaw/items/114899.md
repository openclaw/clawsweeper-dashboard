The proposed readiness correction is coherent and has live package validation, but it intentionally changes the public dry-run plan from ready to not ready when a plugin declares unmet setup credentials; maintainers should confirm that additive prerequisite is the intended compatibility contract before merge.

## What This Changes

The branch preserves plugin manifest setup metadata through ClawHub package preflight and adds a `plugin-setup` prerequisite so `claws add --dry-run` reports plugin credential readiness accurately.

## System Context

Claws package planning resolves requested packages, preflights plugin installation, and produces a dry-run readiness plan before installation. Plugin manifest setup metadata now feeds into that plan so operators can see whether a package needs credentials before it can run.
