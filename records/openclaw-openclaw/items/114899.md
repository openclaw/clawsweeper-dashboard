## Summary

Keep this PR open for a focused correction before merge. The readiness check is useful and the PR includes credible real-package validation, but it reduces plugin setup state to plain environment-variable presence and ignores the manifest’s declared local auth-evidence contract, so valid non-env credential setups can be reported incorrectly.

## What This Changes

The PR carries plugin setup metadata through ClawHub package installation and adds plugin credential prerequisites to `claws add --dry-run` readiness and package-action details.

## System Context

Claws package planning resolves skills, plugins, and MCP prerequisites before creating an agent workspace. Plugin installation returns normalized manifest metadata to the Claws preflight, which decides whether the generated setup plan is ready or needs operator action.

Use the canonical manifest setup-auth evaluation for Claw readiness, including declared `authEvidence`, and add focused coverage for both environment-variable and local-file credential paths before merging.
