## What This Changes

The branch preserves plugin manifest setup metadata during ClawHub package preflight and makes `claws add --dry-run` report a missing plugin setup credential as an unmet readiness requirement.

## System Context

Claws combines a manifest, package installation preflight, and local prerequisites into a dry-run plan before creating an agent workspace. Plugin package preflight now carries declared provider setup metadata forward so the plan can distinguish an installable plugin from a plugin that still lacks usable local credentials.
