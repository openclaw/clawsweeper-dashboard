## What This Changes

The browser extension records relay WebSocket close details and uses them to show host-specific authentication, reachability, or reconnecting messages instead of a generic gateway-down warning.

## System Context

The Chrome extension service worker maintains the relay WebSocket and exposes its status to the popup. The popup combines that status with the active shared-tab count, so relay failures directly affect the message users see while pairing or controlling browser tabs.
