## What This Changes

This PR records browser relay WebSocket close details and uses them in the extension popup so users see a host-specific authentication, reachability, or reconnecting message instead of one generic gateway-down warning.

## System Context

The Chrome browser extension connects to OpenClaw through a relay WebSocket and reports that connection state in its popup. The background service worker owns the socket lifecycle, passes status to the popup, and the popup turns that status into user guidance before users pair, share, or control browser tabs.
