- **[P1] Use the current Pi TUI package:** `src/tui/components/file-browser-select-list.ts:10`
  - body: Current main imports and depends on `@earendil-works/pi-tui`, but the new file-browser component imports the retired `@mariozechner/pi-tui` package. Rebase and update the new TUI files to the current package before this can build against main.
  - confidence: 0.95
- **[P1] Do not reserve /upload ahead of dynamic commands:** `src/tui/commands.ts:117`
  - body: `getSlashCommands` seeds `seen` from built-ins before appending Gateway and dynamic command aliases, so adding `upload` here suppresses any plugin or Gateway command with that alias. This needs an explicit collision or namespace decision instead of claiming the name by insertion order.
  - confidence: 0.92
- **[P1] Keep upload context queued until sendChat accepts the turn:** `src/tui/tui-command-handlers.ts:572`
  - body: `pendingFileContext` is cleared before `client.sendChat` returns. If the send fails or times out, retrying sends only the typed message and drops the files the user selected.
  - confidence: 0.93
- **[P1] Clear stale upload context when replacement attaches nothing:** `src/tui/tui-command-handlers.ts:278-282`
  - body: When every selected path is skipped or fails to read, `blocks.length` stays zero and the old queued context remains. Clear the pending upload before processing a replacement or explicitly clear it on an empty result.
  - confidence: 0.91
- **[P1] Validate regular bounded files before reading:** `src/tui/tui-command-handlers.ts:257`
  - body: The handler reads each selected path fully before size or regular-file validation. A FIFO, device, socket, or large text file can block the event loop or create an enormous prompt, so stat and cap the path before reading through a bounded regular-file helper.
  - confidence: 0.9
- **[P1] Wrap attached file text as untrusted content:** `src/tui/tui-command-handlers.ts:273`
  - body: Raw file text is concatenated into the user message with spoofable delimiters, bypassing the external-content wrapper used for decoded file text. Use that boundary so local file bytes are treated as data, not trusted prompt structure.
  - confidence: 0.88
