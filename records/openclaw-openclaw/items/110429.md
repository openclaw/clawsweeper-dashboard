## What This Changes

The PR adds a bounded local-file reader for Comfy `workflowPath` JSON files, rejects files over 16 MiB before any Comfy request, and adds tests for valid and oversized file paths.

## System Context

The Comfy plugin reads a configured local workflow JSON before it builds and submits an image-generation request to a Comfy server. The new helper sits at that local-file boundary, so it controls whether a configured workflow reaches JSON parsing and provider network calls.
