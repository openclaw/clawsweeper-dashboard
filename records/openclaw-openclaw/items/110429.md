## Summary

Keep open for maintainer review before merge. The patch correctly bounds an otherwise unbounded local-file read, but it silently changes every existing Comfy `workflowPath` over 16 MiB from accepted input to a pre-request failure without an established compatibility contract, documented limit, or upgrade decision.

## What This Changes

This PR adds a bounded reader for configured local Comfy workflow JSON files, rejecting files larger than 16 MiB before the image provider sends a request.

## System Context

The bundled Comfy plugin resolves a configured local `workflowPath`, parses the JSON workflow, then submits the workflow to a Comfy image-generation server. The new helper sits on that file-to-provider boundary and controls whether an existing configured workflow can reach the request stage.

## Best Possible Solution

Retain bounded streaming reads, but first make an explicit Comfy plugin decision on the supported workflow-file limit and document/test the upgrade behavior for existing `workflowPath` users before landing the hard failure boundary.
