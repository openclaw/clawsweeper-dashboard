## Summary

Keep open: current main and the latest release still omit the deprecated runtime alias, and this PR is the correct candidate fix, but it now needs maintainer API-contract approval plus a rebase because GitHub reports the branch as conflicting.

## What This Changes

The PR restores `PluginRuntime.channel.turn.*` as an object-identical deprecated alias of `channel.inbound.*`, updates the runtime mock/tests/API baseline, and revises SDK docs to keep `inbound` canonical.

## Best Possible Solution

Keep `channel.inbound` as canonical while restoring `channel.turn` as an object-identical deprecated compatibility alias, then document the deprecation/removal policy and land after the branch is clean against current main.
