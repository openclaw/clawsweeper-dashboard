## What This Changes

When lossless-claw is selected as the context engine, use its compacted context for the model prompt instead of rebuilding the prompt from the raw session transcript.

## System Context

OpenClaw’s embedded-agent runner prepares session messages for a model call. A configured context engine may compact or project that history first; the resulting message list must remain the source passed to provider prompt construction.

## Architecture Diagram

flowchart LR

  A --> D[Session-context builder]
  C --> E[Embedded agent runner]

  F --> G[Provider request]

## Best Possible Solution

Trace all prompt-construction paths after context-engine assembly, make the assembled context the canonical source for every applicable embedded-agent model call, and add a regression test that distinguishes compacted engine output from raw-session reconstruction.
