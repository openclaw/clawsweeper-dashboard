## Summary

Keep this PR open for the protected maintainer review path. Current `main` still has the low-contrast semantic-token values and lacks `--info-subtle`; centralizing the fix in shared theme tokens is the right approach, but the new CSS audit comments should be reduced to the repository’s concise invariant style before merge.

## What This Changes

Retunes shared Control UI status-color tokens for accessible text-on-tint contrast, adds the missing `--info-subtle` token, and uses it for group session avatars.

## System Context

Control UI theme CSS defines shared semantic status colors that status badges, logs, sessions, and configuration views consume. Components combine each status foreground token with a subtle background tint, producing the labels users see throughout the web interface.
