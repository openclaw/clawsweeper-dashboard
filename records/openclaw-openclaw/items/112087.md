## Summary

The reported redirect-hop SSRF bypass is already covered by the shared guarded-fetch path used for web-search and redirect resolution, with regression coverage for redirects targeting disguised private hosts; this shipped in v2026.2.26.

## What This Changes

The issue requests validation of every redirect hop in internal web-search and link-understanding URL fetching to prevent redirects into private or metadata-network addresses.

## Best Possible Solution
