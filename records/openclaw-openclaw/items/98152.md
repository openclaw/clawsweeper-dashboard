## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Keep install-record keys compatible with lifecycle callers:** `src/plugins/installs.ts:57`
  - body: This starts writing scoped records under keys like `demo:coding`, but current lifecycle code still treats the install-record map key as the plugin id: the installed index looks up `installRecords[record.id]`, and update iterates `Object.keys(installs)` as plugin ids. A scoped install will therefore be missed by per-plugin metadata and updated/disabled/migrated under the wrong id. Preserve canonical plugin identity or update every install-record consumer before writing scoped keys.
  - confidence: 0.91
- **[P1] Add scoped uninstall before writing scoped install records:** `src/cli/plugins-cli.ts:191`
  - body: This exposes `plugins install --agent`, but the same CLI still has no `plugins uninstall --agent` path and the command removes only the global id. After an agent-only install, `plugins uninstall demo` can remove shared activation config while leaving the `demo:<agent>` install record behind, so users cannot cleanly undo the scoped install they just created.
  - confidence: 0.93
- **[P1] Preserve shared plugin config on scoped uninstall:** `src/plugins/uninstall.ts:393`
  - body: When an `agentId` is passed, this helper still removes `plugins.entries[pluginId]`, allow/deny entries, slots, and shared channel config by the unscoped plugin id; the new comment says that path is skipped, but the code below is not guarded. A scoped uninstall would disable or remove shared configuration for global or other-agent installs of the same plugin. Compute remaining installs first and only remove shared config when the last install is gone.
  - confidence: 0.9
- **[P2] Reject unknown agents before choosing an install root:** `src/cli/plugins-install-command.ts:1011`
  - body: `resolveAgentWorkspaceDir` does not validate that the requested agent exists; for an arbitrary id it falls back to a synthesized `workspace-<id>` path. As written, `plugins install --agent typo` can create a new scoped install record and directory for a typo instead of failing closed. Validate against configured/listed agents or make create-new-agent semantics explicit and tested.
  - confidence: 0.86
