## Summary

Keep open: the feature direction is useful, but this branch is not merge-ready because agent-scoped installs still flow into shared plugin discovery, scoped uninstall is not exposed, and the internal scoped uninstall path can remove shared plugin config. The new CLI/config/security surface needs maintainer direction before landing.

## What This Changes

The branch adds an optional `--agent` flag to `plugins install`, persists an `agentId`/compound install-record key, routes installs into an agent workspace extensions directory, and adds internal agent-aware uninstall helpers.

## Best Possible Solution

Define the per-agent plugin lifecycle contract first, then land a branch that validates target agents, keeps install/update/uninstall/discovery semantics consistent, preserves shared config while other installs remain, adds upgrade/security tests, and includes real CLI proof.
