  - body: `resolveAgentWorkspaceDir` is a resolver, not an existence check: for an unknown id it falls back to defaults or `workspace-<id>`. As written, `plugins install --agent codnig ...` creates a trusted install record and plugin directory for a typo instead of failing before any install work starts.
  - confidence: 0.88
