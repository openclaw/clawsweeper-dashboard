## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Preserve scoped records through the update lifecycle:** `src/plugins/installs.ts:57`
  - body: This adds `pluginId:agentId` install-record keys, but the existing update and index paths still treat record keys as plugin ids. For example, `plugins update --all` reads raw install-record keys and later calls `recordPluginInstall` without preserving `record.agentId`, so updating `demo:coding` can collapse the scoped record back to the manifest id `demo` and lose the agent scope. Please thread scoped identity through update selection, update writes, and installed-index metadata before writing compound records.
  - confidence: 0.91
- **[P2] Add the matching scoped uninstall surface:** `src/cli/plugins-cli.ts:191`
  - body: The PR exposes `plugins install --agent`, but `plugins uninstall` still has no `--agent` option and `runPluginUninstallCommand` never passes an agent id or agent workspace extensions root into `planPluginUninstall`. After an agent-scoped install, the public CLI cannot target that scoped record or remove files from the agent workspace, leaving the new install lifecycle incomplete.
  - confidence: 0.93
- **[P1] Preserve shared plugin config on scoped uninstall:** `src/plugins/uninstall.ts:393`
  - body: The new `agentId` parameter makes this helper look scoped, but the code below still deletes shared `plugins.entries[pluginId]`, allow/deny entries, and selected slots by plain plugin id. A scoped uninstall must remove only the scoped install record and files, while preserving shared/global config when any other global or agent install still references the plugin.
  - confidence: 0.94
- **[P2] Validate the agent before resolving its workspace:** `src/cli/plugins-install-command.ts:1011`
  - body: `resolveAgentWorkspaceDir` synthesizes a workspace for any normalized id, so `openclaw plugins install --agent typo ...` can create an install record and plugin files for an unconfigured agent instead of failing closed. Other agent-facing CLI paths validate against `listAgentIds(cfg)` and show `openclaw agents list`; this new plugin code-execution surface should do the same before choosing the install root.
  - confidence: 0.9
