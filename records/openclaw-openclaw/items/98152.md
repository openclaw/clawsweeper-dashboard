- **[P1] Keep scoped installs attached to lifecycle lookups:** `src/plugins/installs.ts:57`
  - body: This starts writing agent installs under `pluginId:agentId`, but the manifest/index lifecycle still reads installed records by bare `pluginId` when assigning managed-record metadata and duplicate precedence.   - confidence: 0.9
- **[P1] Keep agent installs out of shared discovery until scoped:** `src/cli/plugins-install-command.ts:1011-1012`
  - body: The `--agent` path writes the agent workspace install into the shared install ledger, and discovery later iterates every install record as a `global` candidate. Until runtime discovery filters by the active agent, a plugin installed for one agent can be loaded in the shared registry rather than being isolated to that agent. Late discovery: this install path plumbing was unchanged from the earlier reviewed head.
  - late: true
  - confidence: 0.88
- **[P1] Preserve shared config during scoped uninstall:** `src/plugins/uninstall.ts:393-395`
  - body: Even when `agentId` is passed, this helper still removes `plugins.entries`, allow/deny policy, slots, and channel config by bare `pluginId`. A scoped uninstall would therefore disable or reset the global/shared plugin configuration while only removing one scoped install record.
  - confidence: 0.92
- **[P2] Add the scoped uninstall CLI before exposing scoped installs:** `src/cli/plugins-cli.ts:191`
  - body: The install command can now create `pluginId:agentId` records, but `plugins uninstall` still has no `--agent` option and calls the record remover without an agent. Users can create scoped records from the CLI but cannot remove the targeted scoped install from the CLI.
  - confidence: 0.91
- **[P2] Reject unknown agent ids before choosing a workspace:** `src/cli/plugins-install-command.ts:1011`
  - body: `resolveAgentWorkspaceDir` synthesizes a fallback workspace for unconfigured ids, so `--agent typo` will install into a new fallback path instead of failing before writes. Validate against configured agent ids before resolving the install root.
  - confidence: 0.86
