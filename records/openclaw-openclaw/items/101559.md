  - body: This regex treats any `${...}` substring with lowercase or mixed-case names as an env placeholder, and the same broader parser is duplicated in `dashboardURL`. The core contract only accepts exact `$NAME` or `${NAME}` with uppercase ids, so literal tokens such as `${custom_gateway_token}` or `prefix-${TOKEN}` can be dropped or rewritten instead of preserved.
  - confidence: 0.93
- **[P2] Use the resolver environment when expanding placeholders:** `apps/macos/Sources/OpenClaw/GatewayEndpointStore.swift:223`
  - body: `resolveGatewayToken` and `localConfig` already accept an `env` snapshot, but this helper reads `ProcessInfo.processInfo.environment` directly. A caller or test that supplies `env["RESOLVED_TOKEN"]` without mutating the process env will still treat the placeholder as unresolved and fall through to LaunchAgent or nil; thread the env snapshot into the helper.
  - confidence: 0.88
