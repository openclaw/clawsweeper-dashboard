## Summary

Keep open: the PR fixes the unhandled stream-error listener gap, but the current head still rejects immediately after sending kill signals, so the active session guard can be released before the `codex exec resume` child has actually exited.

## What This Changes

## Best Possible Solution

Record the first stream error, terminate the resume child with bounded SIGTERM/SIGKILL, settle from child exit or close, then reject and release the active-session guard; cover that with real-spawn tests that prove rejection waits for child shutdown.
