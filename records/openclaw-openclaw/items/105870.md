## Summary

Keep this PR open: current main still waits for browser cleanup before MCP retirement and completion delivery, and the patch has no supported actionable correctness finding, but the external-PR proof gate remains unmet and the new public Plugin SDK `runId` contract needs explicit owner confirmation.

## What This Changes

The PR dispatches run-mode subagent browser cleanup independently of MCP retirement and completion delivery, adds run-owned browser-tab coordination, and exposes an optional opaque `runId` in plugin tool context.

## Best Possible Solution

Land an owner-approved minimal run-identity contract with browser-owned tab coordination, detached best-effort cleanup, and redacted real-browser proof showing completion delivery proceeds before cleanup release while successor browser access resumes afterward.
