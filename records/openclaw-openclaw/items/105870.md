## Summary

Keep open: the fix direction is plausible and addresses a real lifecycle bottleneck, but the branch expands a public plugin context without completing its contract work, lacks after-fix runtime proof, and still has failing exact-head checks.

## What This Changes

The PR dispatches run-owned browser-tab cleanup independently from subagent MCP retirement and completion delivery, adding per-session browser access gates and an opaque run identifier to plugin tool context.

## Best Possible Solution

Use one owner-approved opaque per-run resource identity contract—public and documented if generally useful, otherwise browser-private—then keep cleanup ownership-aware and demonstrate that completion proceeds while a successor browser request waits and later resumes.
