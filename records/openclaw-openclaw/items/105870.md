## Summary

The earlier SDK-contract finding is resolved and the implementation is coherent enough to continue review, but this external PR still needs real browser-path proof and explicit approval for the new public plugin context contract before merge.

## What This Changes

The PR dispatches subagent browser cleanup independently of MCP retirement and completion delivery, adding run-scoped tab ownership, per-session browser access gates, and an optional plugin tool-context run identifier.

## Best Possible Solution

Keep the owner-scoped browser cleanup design if maintainers approve the narrowly documented opaque `runId` contract, then require a browser-capable before/after run showing completion returns during a blocked close and successor browser access resumes after cleanup releases.
