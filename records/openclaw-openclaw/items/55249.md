## Summary

Keep open: current main now has substantial session-name plumbing, including Gateway label APIs, CLI JSON label projection, Control UI label editing, `/name <title>`, and generated dashboard titles, but the requested terminal-friendly `openclaw sessions` label display and CLI label/rename command are still missing, and the durable `label`/`displayName`/`title` contract is still under active review.

## What This Changes

The issue requests persistent human-readable labels or nicknames for sessions, including CLI listing/renaming, programmatic label support, and optional auto-labeling.

## Best Possible Solution

Settle the canonical session-name field first, then expose one consistent user-facing name through Gateway, Control UI, chat commands, `openclaw sessions` text output, and any supported CLI rename command.

## Reproduction Assessment

Yes. Source inspection shows the remaining current-main gap: CLI text output still has no label/name column and the `openclaw sessions` command tree has no label/rename subcommand, while adjacent Gateway/UI/chat primitives already exist.

## Solution Assessment

No. Current main is only a partial solution; the maintainable path is a unified session-name contract before adding or renaming CLI/chat surfaces.
