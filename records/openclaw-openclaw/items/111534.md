## Summary

Keep this PR open: the cross-user repair is useful, but it currently rewrites a valid custom D-Bus address when only `XDG_RUNTIME_DIR` is absent or cross-user, so existing custom-bus setups can stop working. It also needs real after-fix Linux runtime proof before merge.

## What This Changes

The PR adds Linux update-restart handling that replaces missing or cross-user user-session D-Bus variables with the effective UID’s verified `/run/user/<uid>/bus` socket, plus regression tests.

## Best Possible Solution

Repair only the individual variable that is missing or explicitly points at another `/run/user/<uid>` bus, preserve any nonempty custom D-Bus address, add the missing boundary regression, and provide a redacted real Linux user-session restart transcript.
