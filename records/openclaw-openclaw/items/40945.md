## Summary

Keep open: current main and v2026.6.11 still intentionally flatten remote Markdown image URLs and block remote Control UI image fetches, so the requested behavior remains a product/security decision rather than cleanup.

## What This Changes

The issue requests that Control UI chat markdown render remote http/https image URLs inline instead of flattening them to alt text.

## Best Possible Solution

Decide the Control UI remote-media policy first, then either keep the current no-remote-fetch default or land a coordinated renderer, CSP, docs, tests, and real browser-proof change with an explicit trust model.
