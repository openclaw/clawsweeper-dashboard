## Summary

Keep open: current main and the latest release still intentionally flatten remote Markdown images and enforce a no-remote-image-fetch Control UI policy, so this needs maintainer product/security direction rather than cleanup closure.

## What This Changes

The issue requests rendering remote `http/https` Markdown image URLs inline in Control UI chat instead of showing only alt text while data URI images render.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or land coordinated renderer, sanitizer/CSP, docs, tests, and browser-proof updates together.
