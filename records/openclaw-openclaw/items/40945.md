## Summary

Keep open: current main and the latest release still intentionally flatten remote Markdown images and enforce a no-remote-image-fetch Control UI policy, so this is a product/security decision rather than conservative cleanup.

## What This Changes

Requested behavior: Control UI WebChat should render remote `http/https` Markdown image URLs inline instead of flattening them to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or land coordinated renderer, sanitizer/CSP, docs, tests, and browser-proof updates together.
