## Summary

Keep open: current main and the latest release still enforce no remote Control UI image fetches, so the request remains a focused product/security decision rather than conservative cleanup-close material.

## What This Changes

Request to render remote http/https Markdown image URLs inline in Control UI/WebChat instead of falling back to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or update the renderer, CSP, docs, sibling renderers, tests, and browser proof together.
