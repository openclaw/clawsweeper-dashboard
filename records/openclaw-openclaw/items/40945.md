## Summary

Keep open: current main and the latest release still intentionally flatten remote Control UI markdown images, and enabling them would change the documented no-remote-browser-fetch security policy rather than clean up an obsolete report.

## What This Changes

The issue requests inline rendering of remote http/https markdown image URLs in Control UI chat instead of showing only alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or update the renderer, CSP, docs, sibling renderers, tests, and browser proof together.
