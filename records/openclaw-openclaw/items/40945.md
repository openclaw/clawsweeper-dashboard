## Summary

Keep open: current main and v2026.6.11 still intentionally flatten remote Control UI markdown images and the documented CSP blocks remote browser image fetches, so this remains a focused product/security decision rather than cleanup-close material.

## What This Changes

The issue asks Control UI chat to render remote http/https markdown images inline instead of flattening them to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or update the renderer, CSP, docs, tests, and browser proof together.

## Solution Assessment

No for the suggested renderer-only fix. The maintainable path needs an explicit remote-media trust policy and coordinated renderer, CSP, docs, tests, and browser proof rather than only allowing http(s) image src values.
