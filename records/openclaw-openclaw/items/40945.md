## Summary

Keep open: current main and v2026.6.11 still deliberately flatten remote Markdown images and block remote image fetches, so the requested change needs a maintainer product/security decision rather than conservative cleanup.

## What This Changes

Request to render remote http/https Markdown image URLs inline in Control UI chat instead of flattening them to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the current no-remote-fetch behavior or implement an approved renderer, CSP, docs, tests, and browser-proof update together.
