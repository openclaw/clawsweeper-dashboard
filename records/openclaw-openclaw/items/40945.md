## Summary

Keep open: current main and the latest release intentionally block remote Control UI image fetches through the markdown renderer, CSP, tests, and docs, so this remains a security/product decision rather than cleanup-close material.

## What This Changes

Render remote http/https Markdown image URLs inline in Control UI chat instead of flattening them to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or update the renderer, CSP, docs, sibling renderers, tests, and browser proof together.
