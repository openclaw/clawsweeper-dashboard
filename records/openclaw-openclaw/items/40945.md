## Summary

Keep open: current main and the latest release intentionally flatten remote Markdown images and enforce a no-remote-image-fetch Control UI policy, so the remaining work is a product/security decision rather than conservative cleanup.

## What This Changes

The issue requests inline rendering for remote `http/https` Markdown image URLs in Control UI chat instead of converting them to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch default or land coordinated renderer, sanitizer/CSP, docs, tests, and browser-proof updates together.
