## Summary

Keep open: current main and the latest release intentionally flatten remote Markdown images and enforce a no-remote-image-fetch Control UI policy, so this is a product/security decision rather than a cleanup close.

## What This Changes

The issue asks for Control UI chat markdown to render remote `http`/`https` image URLs inline instead of flattening them to text.

## Best Possible Solution

Define the approved Control UI remote-media trust policy first, then either keep the no-remote-fetch default or land coordinated renderer, CSP, docs, tests, and browser-proof updates together.
