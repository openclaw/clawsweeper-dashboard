## Summary

Keep open: current main and v2026.6.11 still intentionally flatten remote Markdown image URLs and block remote browser image fetches, so the requested UX change needs an explicit product/security decision rather than conservative cleanup.

## What This Changes

The issue requests rendering remote http/https Markdown image URLs inline in Control UI chat instead of flattening them to alt text.

## Best Possible Solution

Decide the Control UI remote-media policy first, then either keep the current no-remote-fetch behavior or update the renderer, sanitizer/CSP, docs, tests, and real browser proof together under an approved direct-fetch, proxy, or opt-in model.
