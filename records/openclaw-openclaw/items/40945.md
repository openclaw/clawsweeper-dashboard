## Summary

Keep open: current main and v2026.6.11 still intentionally flatten remote Markdown images and enforce a no-remote-image-fetch Control UI CSP, so the request is a security-sensitive product decision rather than cleanup.

## What This Changes

Request remote http/https Markdown image URLs in Control UI chat to render inline instead of being flattened to alt text.

## Best Possible Solution

Define the approved Control UI remote-media policy first, then either keep the no-remote-fetch behavior or update the renderer, CSP, docs, tests, and browser proof together.
