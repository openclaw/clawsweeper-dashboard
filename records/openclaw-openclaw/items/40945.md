## Summary

Keep open: current main and the latest release still intentionally flatten remote Markdown images and the Control UI CSP blocks remote browser image fetches, so this remains a maintainer security/product decision rather than a cleanup close.

## What This Changes

The issue requests Control UI chat Markdown to render remote http/https image URLs inline instead of flattening them to alt text.

## Best Possible Solution

Keep the current no-remote-fetch behavior unless maintainers approve a remote-media design that updates the renderer, sanitizer/CSP, docs, tests, and browser proof together.

## Solution Assessment

No for the suggested renderer-only fix. The maintainable path needs an explicit remote-media trust policy and coordinated renderer, sanitizer/CSP, docs, tests, and browser proof rather than only allowing http(s) image src values.
