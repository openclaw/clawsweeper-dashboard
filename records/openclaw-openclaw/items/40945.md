## Summary

Keep open: current main and the latest release still intentionally flatten remote Markdown image URLs and block remote Control UI image fetches, so this remains a product/security decision rather than cleanup.

## What This Changes

The issue requests that Control UI chat render Markdown image syntax with remote http/https URLs inline instead of flattening it to alt text.

## Best Possible Solution

First decide the approved Control UI remote-media policy, then either keep the no-remote-fetch default or implement a coordinated renderer, CSP, docs, tests, and browser-proof change.
