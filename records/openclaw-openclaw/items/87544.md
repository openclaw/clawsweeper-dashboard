## Summary

Keep open. Current main has durable queue recovery, dead-letter health, and transcript mirror markers, but it still lacks the requested transcript-entry to provider-message receipt ledger, per-entry client delivery state, and origin-delivery reconciler.

## What This Changes

Track and reconcile per-transcript-entry delivery state for channel-scoped assistant replies so transcripted outputs can be matched to expected client-visible messages.

## Best Possible Solution

Design one generic SQLite-backed delivery ledger keyed by transcript entry and expected channel target, feed it from outbound send/recovery receipts, expose it through session APIs and Control UI, and let adapters add reconciliation capability without duplicating queue state.
