## Summary

Keep open: current main still lacks the requested WebChat/Control UI inline-button protocol, authenticated callback RPC, WebChat capability/config contract, and Control UI rendering/click handling. The discussion has converged on this issue as the canonical tracker, but implementation needs maintainer product and security direction first.

## What This Changes

The issue requests Webchat/Control UI inline button support, including a capability/config contract, WebSocket delivery of interactive message blocks, callback RPC handling, and Control UI rendering.

## Best Possible Solution

Settle the WebChat interaction contract around shared `presentation` blocks and an authenticated Gateway `chat.callback` RPC, then implement protocol projection, Control UI rendering/click state, focused tests, and docs while deferring webhook routing.
