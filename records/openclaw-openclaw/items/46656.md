## What This Changes

Request WebChat/Control UI support for inline buttons, callback routing, and an optional capability/config contract comparable to existing channel button workflows.

Settle the WebChat interaction contract around shared presentation typed actions and an authenticated chat.callback RPC, then implement protocol projection, Control UI rendering/click state, focused tests, and docs while deferring webhook routing.
