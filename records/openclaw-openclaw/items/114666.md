This PR replaces the plugin loader’s 67 hand-written workspace SDK alias records with nine ordered descriptors that regenerate the same source and packaged-runtime resolver mappings.

## System Context

OpenClaw’s plugin loader resolves SDK and workspace-package imports for extension code running from either a source checkout or a packaged installation. The alias registry translates those imports into the correct source or distribution entrypoints before the plugin runtime loads them.
