## Summary

Keep this PR open: the existing review finding is valid because the new empty-catalog filter also suppresses provider failure states, removing the sidebar’s only user-visible indication that native sessions failed to load. The repair is narrow, but the protected maintainer label and requested review require normal human handling rather than cleanup closure.

## What This Changes

The PR hides exhausted native-session catalog groups with no rows, while retaining empty groups that still have a pagination cursor, and adds component and mocked Chromium coverage.

## Best Possible Solution

Hide a catalog only when it has no sessions, no continuation cursor, and no catalog or host error; add focused component coverage for both error shapes while retaining the empty and pagination cases.
