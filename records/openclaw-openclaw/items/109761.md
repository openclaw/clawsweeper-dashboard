## What This Changes

Request an additive public plugin-tool result control that persists the successful result and then cleanly yields the active agent turn while awaiting an externally correlated callback.

## Best Possible Solution

Define one additive, channel-agnostic plugin result control that records the normal tool result first, reuses the canonical `sessions_yield` lifecycle, preserves existing results unchanged, and returns an explicit unsupported-runtime error where equivalent semantics cannot be guaranteed.
