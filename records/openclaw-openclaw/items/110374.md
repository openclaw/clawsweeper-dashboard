## Summary

This PR is still necessary only if maintainers want to establish a durable transcript-generation migration and two public Plugin SDK cursor contracts. The current branch retains the two previously raised P1 blockers: it advances the agent SQLite schema for an additive table, and it exports new long-lived SDK APIs without maintainer acceptance of that contract; the protected `maintainer` label also requires human handling.

## What This Changes

The branch adds generation-aware, count- and byte-bounded raw and visible transcript cursor APIs, persists transcript generations in the agent SQLite database, and makes active-memory inspection use bounded raw reads.

## Best Possible Solution

Keep bounded active-memory reading narrowly owned for now, and split any durable generation-backed public cursor API into a maintainer-sponsored design that uses the repository’s additive-table migration policy and defines the permanent Plugin SDK contract.
