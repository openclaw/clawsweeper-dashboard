## Summary

Keep open: current main still has hardcoded task notify defaults, no schema-backed config default, and no merged canonical item that resolves the broader ACP/subagent/Task Flow default-policy request.

## What This Changes

Request a config-level default task notify policy so ACP, subagent, and related task records do not have to inherit hardcoded `done_only` behavior or race per-task CLI overrides.

## Best Possible Solution

Add a maintainer-approved, backward-compatible task notify default resolver that preserves current behavior when unset, lets explicit task or flow policies win, keeps cron/CLI/media silent defaults intact, and updates schema, docs, and tests together.
