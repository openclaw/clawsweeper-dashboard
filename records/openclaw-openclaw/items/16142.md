## Summary

Keep open. Current main and v2026.6.11 provide no-model command cron for scripted jobs, but main-session `systemEvent` reminders still enter the heartbeat prompt and model reply path; deciding whether those reminders may bypass the model remains a product decision.

## What This Changes

Provide a deterministic, lower-cost path for simple scheduled watcher alerts instead of repeatedly using a model to format reminder text.

## Best Possible Solution

Keep `systemEvent` model-backed by default, use command cron for scripts that already produce final output, and—if maintainers want broader coverage—add an explicit deterministic reminder payload or option with clearly documented delivery and upgrade semantics.
