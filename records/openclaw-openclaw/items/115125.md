## What This Changes

The PR sends Telegram image payloads larger than the Bot API’s 10 MiB photo limit through the existing document-delivery path while preserving captions, HTML parsing, forum-topic routing, and notification settings.

## System Context

The Telegram plugin receives outbound media from durable sends and agent reply delivery, then chooses a Bot API method and attaches Telegram-specific caption and thread options. This change alters the image-method decision so oversized images reach the chat as documents instead of failing at the `sendPhoto` API boundary.
