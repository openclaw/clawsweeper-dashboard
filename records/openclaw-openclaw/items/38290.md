## Best Possible Solution

Land a narrow current-main origin-check repair that keeps configured allowlist values exact, synthesizes `scheme://host` only for incoming hosted opaque origins, rejects empty-host opaque origins, and leaves scheme wildcard policy to the separate related issue.
