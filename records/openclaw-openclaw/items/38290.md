## Summary

## What This Changes

This PR changes Gateway browser-origin matching so non-standard origins such as `chrome-extension://<id>` can match `gateway.controlUi.allowedOrigins`, with unit and WebSocket handshake coverage.

## Best Possible Solution

Land a narrow gateway fix that normalizes only incoming host-bearing opaque origins to `scheme://host`, keeps configured `allowedOrigins` exact except `*`, rejects hostless opaque origins, and preserves current main's private-same-origin behavior.
