  - body: This parses every configured allowlist entry and compares only its normalized origin. Because this is the browser-origin allowlist, please preserve exact trimmed/lowercased config entries and only synthesize `scheme://host` for the parsed incoming origin.
  - confidence: 0.94
- **[P2] Reject empty-host opaque origins:** `src/gateway/origin-check.ts:17`
