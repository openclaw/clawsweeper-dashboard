The PR removes runtime and public SDK fallback reads for six legacy flat streaming keys, adds doctor-owned migrations for nested-streaming channels, tightens channel schemas, and updates tests, generated metadata, and documentation.

Keep validated bundled runtime configuration nested-only, make doctor preserve each channel’s effective pre-migration behavior, and retain the released flat-aware SDK resolver semantics until a separately approved, documented, tested, and versioned plugin API deprecation or break is available.
