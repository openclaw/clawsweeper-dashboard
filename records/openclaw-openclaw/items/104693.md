## Summary

The patch is directionally aligned with doctor-owned migration, but it directly changes shipped public plugin SDK resolver behavior and can silently break external channel plugins; the separate early-removal timing decision also remains explicitly on hold.

## What This Changes

The PR removes runtime support for six legacy flat channel streaming keys on nested-streaming channels and moves their migration into channel doctor contracts, with schema, docs, and tests updated accordingly.

## Best Possible Solution

Preserve the existing flat-aware SDK resolver functions, add separately named nested-only helpers for bundled channel runtime callers, and keep doctor warnings and migrations active until an explicitly approved removal window with fresh-install and upgrade proof.
