This PR hardens gateway-connected node reconnection, propagates cancellation through node execution, preserves unbounded node invocation timeouts, serializes local embedding-worker ownership, and avoids LM Studio preload after cancellation.

## System Context

Node commands travel from the CLI and agent tools through the Gateway to a connected node host, which returns results, progress, and events. Local inference providers also use shared worker processes, so reconnect and cancellation decisions must preserve request ownership without disrupting other callers.
