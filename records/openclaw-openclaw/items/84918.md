## What This Changes

Investigate an OpenWebUI integration report where an image uploaded through OpenClaw’s OpenAI-compatible `/v1/chat/completions` endpoint reaches image handling as an empty value.

## System Context

The Gateway’s OpenAI-compatible HTTP surface accepts Chat Completions requests and turns them into normal OpenClaw agent runs. Multimodal request parts must be parsed into managed image inputs before routing and image-model fallback can use them.
