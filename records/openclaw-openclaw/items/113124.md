## What This Changes

Reduce repeated full-buffer parsing in native Anthropic tool-call streaming so large `input_json_delta` sequences do not cause quadratic synchronous CPU work and event-loop stalls.

## System Context

The native Anthropic Messages transport converts streamed provider events into OpenClaw tool-call updates. Each JSON delta grows a partial argument buffer, which feeds a partial preview during streaming and a final authoritative tool-call argument value when the provider finishes the block.

## Architecture Diagram

  B --> C[Partial argument buffer]
  C --> D[Preview parse cadence]
  D --> E[Tool-call update events]
  C --> F[Final block parse]
  F --> G[Authoritative tool arguments]
  E --> H[Agent tool execution]
  G --> H

## Best Possible Solution

Review and, if the cadence trade-off is acceptable, land the linked focused transport fix with its regression coverage; track a resumable incremental parser separately only if profiling shows the remaining bounded reparse cost is still material.
