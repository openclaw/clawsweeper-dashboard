## What This Changes

This PR stamps local JSON and Markdown review artifacts with a pull-request number and head SHA, validates that chain against PR metadata, archives mismatched artifacts, and moves review-claim logs into the dedicated PR worktree.

## System Context

The `scripts/pr` landing flow creates a dedicated worktree, records pull-request metadata, gathers a review verdict, and gates merge preparation on those artifacts. This change binds each artifact to the intended PR and checked-out revision before the merge gate consumes it.
