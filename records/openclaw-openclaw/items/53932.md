## Summary

Keep open: current main and v2026.6.11 still route Slack uploads through the shared media loader, and Slack has no upload-fidelity opt-out or force-document equivalent, so the remaining work needs a maintainer product decision.

## What This Changes

Requests a Slack-owned way to disable image optimization so uploaded images can preserve original file bytes and format.

## Best Possible Solution

Choose a default-off, documented Slack upload-fidelity contract in the Slack plugin, then thread it through outbound/message-tool media loading with focused tests and live Slack proof.
