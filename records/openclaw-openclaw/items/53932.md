## Summary

Keep open: current main still routes Slack file uploads through the shared optimizing media loader, Slack has no raw-upload or image-optimization opt-out, and the linked implementation PR was closed unmerged; the remaining work is a maintainer product decision about Slack upload fidelity.

## What This Changes

The issue requests a way to disable image optimization for Slack uploads so generated or shared image files can be delivered without lossy format or quality changes.

## Best Possible Solution

Choose and document a Slack upload-fidelity contract, then implement it at the Slack outbound/message-tool boundary with focused tests and live Slack upload proof.
