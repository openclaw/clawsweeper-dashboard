## Summary

Keep open. The current PR still permits unbrokered manifest-provided stdio commands and exact-name reuse of a global MCP declaration without a host authorization contract; those remain P1 security and compatibility blockers, and the protected `maintainer` label requires explicit human direction.

## What This Changes

The PR adds experimental Claw ownership, provenance, lifecycle status/export, reconciliation, and removal behavior for MCP server declarations in OpenClaw configuration.

## Best Possible Solution

Define and implement a host-controlled MCP contract: only brokered or allowlisted stdio commands may be introduced by Claws, and reuse of a global declaration must require explicit host authorization or a resource scope that cannot collide across Claws; then provide redacted exact-head runtime proof for add, launch, status, export, drift recovery, and removal.
