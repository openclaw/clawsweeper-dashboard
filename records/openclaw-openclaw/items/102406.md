## Summary

Keep this protected, maintainer-routed experimental PR open. Its current MCP ownership model still lets a bundle declare an arbitrary local stdio command and treats an exact global declaration as shareable by another Claw without host authorization; the branch also has only test evidence, not after-fix real behavior proof.

## What This Changes

The branch adds experimental Claw-managed MCP declaration creation, ownership persistence, status/export, reconciliation, and guarded removal through the shared MCP source-config writer.

## Best Possible Solution

Define one approved MCP ownership boundary: broker or allowlist manifest-provided commands, use an explicit host authorization record for any shared declaration, and prove the resulting add/status/export/drift/remove flow in a redacted real configuration before merge.
