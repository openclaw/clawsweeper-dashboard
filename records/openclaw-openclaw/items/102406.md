## Summary

Keep this PR open for human security/product review. It is a meaningful experimental feature, but the current patch still permits a Claw manifest to register an unbrokered stdio command into global MCP configuration and treats cross-Claw reuse of that global declaration as sufficient ownership evidence; both prior P1 concerns need an explicit host authorization model before merge.

## What This Changes

The branch adds experimental Claw ownership tracking, source-config mutation, status/export, reconciliation, and removal behavior for MCP server declarations.

## Best Possible Solution

Define a host-authorized MCP resource model first: Claw manifests should request only brokered or explicitly allowlisted stdio commands, and any globally shared declaration should have explicit host authorization and scoped ownership before the lifecycle code writes or removes it.
