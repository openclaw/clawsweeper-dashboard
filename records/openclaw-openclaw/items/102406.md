## Summary

Keep this PR open: it remains necessary for the experimental Claw lifecycle stack, but its MCP ownership model still permits unbrokered stdio command registration and cross-role use of a global MCP namespace. The `maintainer` label and the unresolved security boundary require explicit maintainer direction before a safe repair can be scoped.

## What This Changes

The branch adds experimental Claw ownership tracking and lifecycle operations for MCP declarations, including validated config writes, provenance, reconciliation, status/export, and guarded removal.

## Best Possible Solution

Define a host-authorized MCP resource model first—broker or allowlist executable commands, sanitize the child environment, and bind any shared declaration to an explicit host-approved scope—then adapt lifecycle ownership and add redacted real CLI proof for add, isolation, status/export, drift, and removal.
