## Label Justifications

- `P1`: The branch can alter the host command-execution boundary for experimental Claw installs, which warrants urgent maintainer review before merge.

## Summary

This experimental lifecycle feature is still necessary, but it should not merge until maintainers choose and the patch enforces a host-authorized model for Claw-provided MCP processes. The submitted test output is useful supplemental validation, not real after-fix MCP proof, and the remaining security boundary is not a safe mechanical repair without that decision.

## What This Changes

The PR adds experimental Claw ownership records and lifecycle operations for MCP declarations, including validated config writes, provenance, shared exact declarations, status/export, reconciliation, and guarded removal.

## Best Possible Solution

Keep MCP ownership behind the experimental gate, but require a maintainer-approved host authorization model: only brokered or allowlisted stdio launch paths may be introduced by Claws, and shared global declarations must require explicit host authorization with clear isolation semantics.

Rationale: The branch creates privileged host configuration and executable-process declarations; choosing the permitted command set and cross-Claw sharing policy changes OpenClaw's security contract and cannot be resolved safely from implementation mechanics alone.

Likely owner: Patrick-Erichsen

Owner confidence: high

Options:

- **Require brokered, explicitly shared MCP resources (recommended):** Permit only host-authorized or brokered stdio commands and require an explicit host grant before a Claw can adopt or share a global declaration.
- **Allow direct manifest MCP ownership:** Accept manifest-provided commands and exact global reuse as an intentional experimental capability, with the resulting host-execution and tenancy risk owned by maintainers.
- **Defer MCP ownership from the Claws lifecycle:** Land no MCP mutation support until the RFC or a narrower design establishes the authorization and isolation contract.
