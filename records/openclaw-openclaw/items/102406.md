## Summary

Keep this PR open for maintainer review: it adds a new experimental core ownership model for globally shared MCP configuration, but the current patch still permits unbrokered manifest stdio commands and treats exact global declarations as implicitly shareable across Claws. It also needs inspectable real CLI/config evidence before merge.

## What This Changes

The branch adds experimental Claw ownership, reconciliation, status/export, and removal handling for MCP server declarations stored in OpenClaw source configuration.

## Best Possible Solution

Define one maintainer-approved MCP authority model before merge: broker or allowlist Claw-provided stdio execution, require explicit host authorization for any shared global declaration, and prove the resulting add/status/export/drift/remove lifecycle with a redacted real configuration transcript.
