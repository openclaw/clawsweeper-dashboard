Define and approve one core MCP execution and sharing policy first: manifest stdio servers must use a host-authorized broker or allowlist with an explicit environment policy, and sharing a global declaration must require host authorization or be namespaced per Claw; then prove the exact head with a redacted real MCP lifecycle run.
