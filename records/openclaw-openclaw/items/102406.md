## Summary

This draft should remain open, but it is not merge-ready: the apply consent omits shared MCP configuration writes, ambiguous write outcomes can create ownership state with no supported reconciliation path, real current-head behavior proof is missing, and the draft RFC has not yet accepted the global ownership contract.

## What This Changes

The PR installs manifest-declared MCP servers into shared configuration, stores digest-only Claw ownership in SQLite, reports drift through status and export, and conditionally removes unchanged owned declarations.

## Best Possible Solution

Keep the validated writer and digest-based drift protection, but add a visible deterministic reconciliation or Doctor/Fix path for pending ownership, disclose shared MCP mutation before consent, prove fresh-install and upgrade behavior, and land only after maintainers approve the global namespace and cleanup contract.
