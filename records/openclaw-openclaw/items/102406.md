## Summary

Keep open: the exact head fixes the previously reported URL-redaction defect, but it still promotes Claw-supplied stdio commands into the global MCP registry without a brokered execution boundary or per-agent isolation, and the submitted proof remains test-only. The protected maintainer label and assigned review appropriately require a human security and product decision.

## What This Changes

The PR adds Claw-managed MCP declaration installation, SQLite ownership records, source-preserving reconciliation, status and export reporting, shared ownership, and guarded removal.

## Best Possible Solution

Define Claw packages as either explicitly host-trusted artifacts or untrusted role packages in the RFC, then implement the chosen boundary consistently—preferably brokered executable selection, an explicit child-environment allowlist, agent/install-scoped MCP resources, host-authorized sharing, and compensating cleanup for partially created global state.
