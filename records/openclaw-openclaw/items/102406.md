## Summary

Keep this PR open for human security-boundary review. The branch still registers manifest-provided stdio commands and reuses exact declarations in a global `mcp.servers` namespace without a host-approved broker or sharing authorization; focused tests and CI do not establish that either boundary is safe. ## What This Changes

The PR adds experimental Claw ownership, provenance, status/export, reconciliation, and removal semantics for MCP server declarations in shared OpenClaw configuration.

## Best Possible Solution

Define and implement a host-authorized MCP contract: broker or allowlist manifest stdio commands, make cross-Claw sharing explicit and authorized (or namespace declarations), then add redacted real-server proof for add, launch/connect, status/export, and removal.
