## Summary

This PR remains necessary as part of the experimental Claws stack, but it should not merge yet: the latest branch still accepts a reusable global MCP declaration without host authorization and does not establish a brokered execution boundary for stdio commands. The PR body also confirms that live MCP startup was not exercised, so the required real after-fix behavior proof is still missing.

## What This Changes

The branch adds experimental Claw ownership, source-config mutation, provenance, status/export, reconciliation, and removal handling for MCP server declarations.

## Best Possible Solution

Keep MCP declarations global only when the host explicitly authorizes a share, otherwise scope them to the owning Claw, and route stdio servers through a host-controlled broker or allowlist before persistence; then demonstrate add, status, remove, and attempted unsafe inputs in a redacted exact-head runtime transcript.
