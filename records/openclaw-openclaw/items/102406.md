## Summary

Keep open: the current head resolves the earlier redaction and pending-reconciliation findings, but the two P1 blockers from the latest review remain—Claw manifests can register arbitrary host commands, and their MCP declarations occupy a globally shared namespace. The assigned reviewer also needs to settle this security and ownership model before merge.

## What This Changes

The PR adds Claw-managed MCP declaration installation, SQLite ownership records, source-preserving reconciliation, shared ownership, status/export reporting, and guarded removal.

## Best Possible Solution

Require Claw MCP declarations to use a trusted, pinned or brokered launcher with a minimal explicit environment; namespace resources per agent or installation; make cross-Claw sharing an explicit host-authorized resource; compensate newly created global config when add fails; then prove add, sibling isolation, status, drift, export, failure recovery, and removal in a redacted real setup.
