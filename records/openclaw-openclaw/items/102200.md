- `P1`: The report describes a latest-stable regression that breaks multi-turn Ollama Cloud tool use after the first tool call for channel-bound agents.

## Summary

Close as implemented: the report is valid for v2026.6.11 stable, but current main and the v2026.7.1-beta.1 prerelease contain the merged Ollama fix that preserves OpenAI-compatible tool-call arguments as strings while keeping native Ollama object arguments.

## What This Changes

The issue reports that Ollama OpenAI-compatible second-turn tool-call replay sends function.arguments as a JSON object instead of the required JSON string for embedded/channel-bound agents.

## Best Possible Solution

Keep the merged native-versus-OpenAI-compatible split from https://github.com/openclaw/openclaw/pull/96474 and route stable users to a fixed prerelease or the next stable package.
