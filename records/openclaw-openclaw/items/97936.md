  - body: Still unfixed from the prior review: `scrubEnvRaw` receives one global value set and one global key set, so a mixed migration can delete a credential when the key came from one target and the matching value came from another.   - confidence: 0.92
- **[P1] Preserve file and exec cleanup coverage:** `src/secrets/apply.ts:697-698`
  - body: Still unfixed from the prior review: scrub keys are recorded only for env refs, and `scrubEnvFiles` now returns early when no keys were recorded.   - confidence: 0.9
