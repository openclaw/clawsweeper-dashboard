## What This Changes

The PR updates OpenAI-compatible Chat Completions and Responses streaming so a lifecycle error yields an error terminal rather than a false successful completion, with regression coverage for partial output and lifecycle-event ordering.

## System Context

The Gateway exposes OpenAI-compatible streaming HTTP endpoints over an agent run. Agent lifecycle and assistant-delta events are translated into SSE frames, which downstream OpenAI clients interpret as successful completion, failure, usage, and final stream termination.
