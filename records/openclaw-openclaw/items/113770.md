## What This Changes

This PR changes Gateway’s OpenAI-compatible Chat Completions and Responses streams so an agent lifecycle error produces an error or `response.failed` terminal event instead of a successful completion.

## System Context

Gateway exposes OpenClaw agent runs as OpenAI-compatible Server-Sent Event streams. It receives assistant text, lifecycle state, and final usage from an agent run, then emits a single terminal success or failure sequence to the HTTP client.
