## Summary

Keep open: current main and the latest release still return no-argument `/reasoning` as a text-only `Options:` reply, while Feishu only renders clickable controls when the reply carries typed presentation/card data. Related native args-menu and Feishu presentation PRs provide building blocks, but they do not complete the Feishu command-status button path.

## What This Changes

The issue requests Feishu clickable buttons for command options such as `/reasoning` instead of plain text choices.

## Best Possible Solution

Define selectable command-status replies as typed command-action presentation and let Feishu render them through its existing card renderer while preserving text fallback and coordinating with native args-menu work.

Question: Should no-argument command-status replies such as `/reasoning` and `/verbose` emit shared typed command-action presentation for capable channels, or should this stay a Feishu-only/card-specific UX?

Rationale: Current policy favors typed portable presentation actions and channel renderers over Feishu-only parsing of `Options:` text, but the exact product surface spans shared command replies and channel-native menu behavior.

Likely owner: steipete

Owner confidence: high

Options:

- **Shared typed presentation (recommended):** Emit typed command-action buttons from the shared command-status reply path and let capable channels such as Feishu render them natively while text-only channels keep fallback text.
- **Feishu-only card transform:** Teach Feishu to transform recognized command-status option replies into cards, accepting a channel-specific parser and maintenance burden.
- **Native args-menu only:** Rely on command registry `argsMenu` surfaces and leave no-argument status replies as text-only.

## Reproduction Assessment

Yes. Source inspection shows no-argument `/reasoning` still returns only a text `Options:` reply, while Feishu clickable controls require typed presentation/card data.

## Solution Assessment

No as a Feishu-only text transform; the better solution is shared typed command-action presentation that Feishu can render natively and other channels can safely fall back from.
