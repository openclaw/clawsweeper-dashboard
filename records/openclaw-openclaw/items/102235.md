## Summary

Keep open: current main still allows a job-level channel-shaped cron failure destination without `mode` to inherit a global webhook mode, and the two open closing PRs are implementation candidates rather than closure evidence.

## What This Changes

The issue requests that cron job-level failure destinations shaped like channel delivery default to announce instead of inheriting a global webhook failure destination mode.

## Best Possible Solution

Land one resolver-level fix, preferably the proof-backed https://github.com/openclaw/openclaw/pull/102445 or an equivalent with gateway regression coverage, then let this issue close after merge.
