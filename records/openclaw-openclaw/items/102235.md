## What This Changes

The issue reports cron failure notifications being dropped when a global webhook failureDestination combines with a job-level channel-shaped failureDestination that omits mode.

## Best Possible Solution

## Reproduction Assessment

Yes. Source inspection reproduces the path by resolving a job-level channel/to failure destination without mode over a global webhook default, then following the dispatcher webhook URL gate.

## Solution Assessment

Yes. The best fix is resolver-level normalization so channel-shaped job overrides without mode resolve to announce before the gateway dispatcher chooses webhook versus announce, while preserving to-only webhook inheritance.
