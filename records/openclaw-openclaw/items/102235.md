## Repair Work Prompt

Fix the cron failure-destination resolver bug reported at https://github.com/openclaw/openclaw/issues/102235. In `resolveFailureDestination`, a job-level failure destination that supplies channel-shaped announce fields such as `channel` and `to` but omits `mode` must not inherit a global `webhook` mode and feed the channel target to webhook URL validation. Keep existing partial inheritance and clear-field semantics intact for legitimate global defaults and explicit mode overrides. Add focused regression coverage for the resolver and, if practical, the gateway dispatcher branch showing the channel alert path is used instead of the invalid-webhook skip path. Do not add config options, change webhook URL validation, or refactor unrelated cron delivery behavior.
