## Summary

Keep open: current main and the latest release still have the resolver/dispatcher path that can turn a job-level channel-shaped failure destination into an inherited webhook route, and open linked PRs now own the fix path.

## What This Changes

A channel-shaped cron `delivery.failureDestination` without `mode` should resolve as announce delivery instead of inheriting a global webhook failure mode.

## Best Possible Solution

Land the proof-sufficient resolver-level fix in https://github.com/openclaw/openclaw/pull/102445 or an equivalent patch, preserving to-only webhook inheritance and clear-field behavior with regression coverage, then close this issue through the merged PR.
