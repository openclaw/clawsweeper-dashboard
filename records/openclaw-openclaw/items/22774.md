## Summary

Keep open: current main has provenance traces and forwarded sender labels, but it still lacks the requested durable per-message sender identity contract that can distinguish human users, main agents, and subagents across Gateway schemas, session history, live events, and Control UI rendering.

## What This Changes

Request durable multi-role sender identity in the Chat UI for human, main-agent, and subagent messages in multi-agent workflows.

## Best Possible Solution

Define an additive per-message sender identity contract and carry it through chat.send, sessions.send/steer, subagent delivery, persisted history, live events, grouping, labels, avatars, and tests.
