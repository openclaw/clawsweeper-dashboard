## Summary

Keep open: current main and v2026.6.11 still provide provenance plus senderLabel display projections, but not the requested durable human/main-agent/sub-agent sender identity contract across protocol, transcripts, live/history events, subagent announcements, and Control UI rendering.

## What This Changes

The issue requests durable multi-role sender identity in Chat UI so human, main-agent, and sub-agent messages are distinguishable in multi-agent workflows.

## Best Possible Solution

Define one additive durable sender identity object for chat/session messages, persist it with transcripts, expose it through history/live events, carry it through chat.send, sessions.send/steer, and subagent announce paths, and render per-message labels/avatars/colors in Control UI.
