## Summary

Keep open. Current main has generic forwarded-message display hints, but it still lacks the requested durable sender identity contract for human/main-agent/sub-agent attribution across Gateway inputs, transcripts, history/live events, subagent announcements, and Control UI avatars.

## What This Changes

Request support for distinct human, main-agent, and sub-agent sender identity in Chat UI and multi-agent transcript rendering.

## Best Possible Solution

Add an additive trusted per-message sender identity contract across Gateway protocol, session transcripts, `chat.history` and live events, subagent announce delivery, and Control UI rendering, while keeping current generic forwarded labels as the interim behavior.

## Reproduction Assessment

Yes. Source inspection on current main shows the relevant schemas and provenance types cannot carry durable sender id/kind/display/avatar metadata, while tests show only a generic `senderLabel` projection.

## Solution Assessment

No existing current-main path is the full solution. The best fix is a core protocol/transcript/UI sender metadata contract, not another one-off UI label or color patch.
