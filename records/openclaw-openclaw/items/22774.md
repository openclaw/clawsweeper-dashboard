## Summary

Keep open: current main and the latest release have provenance traces, `spawnedBy` event metadata, and `sessions_send` forwarded `senderLabel` projection, but they still lack the requested durable per-message sender identity contract for human, main-agent, and subagent attribution across protocol, transcripts, live/history payloads, and Control UI avatars.

## What This Changes

Request multi-role Chat UI sender identity so human, main-agent, and subagent messages have distinct durable attribution, labels, avatars, and colors.

## Best Possible Solution

Define one additive sender identity object with stable id, kind, display name, source agent/session, render metadata, and trust/provenance semantics, then thread it through chat.send, sessions.send/steer, subagent announcements, persistence, history/live events, and Control UI grouping/avatar rendering.
