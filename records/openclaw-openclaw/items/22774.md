Keep open: current main has partial sender-label and provenance hints, but it still lacks the durable per-message sender identity contract needed for multi-agent Chat UI attribution across gateway schemas, history/live events, stored session data, and Control UI rendering.

## What This Changes

## Best Possible Solution

Define one additive per-message sender identity object and thread it through chat.send, sessions.send/steer, subagent announcements, persisted transcripts, chat.history/session.message events, and Control UI grouping/avatar rendering while coordinating the narrower related PRs.
