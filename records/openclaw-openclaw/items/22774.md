## Summary

Keep open: current main has useful inter-session provenance, forwarded sender labels, and WebChat grouping support, but it still lacks the requested durable per-message sender identity contract across Gateway schemas, transcript/history/live events, and Control UI rendering. Related open work covers narrower slices and does not replace this canonical tracker.

## What This Changes

The issue requests multi-role sender identity in Chat UI so human, main-agent, and sub-agent messages are visually and auditably distinguishable in multi-agent workflows.

## Best Possible Solution

Keep this issue as the canonical durable sender-identity tracker and design an additive per-message sender metadata contract that persists through transcripts, chat history/live events, sessions.send/chat.send, subagent announcements, and Control UI rendering.
