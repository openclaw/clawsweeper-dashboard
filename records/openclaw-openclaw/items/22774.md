## Summary

Keep open: current main and v2026.6.11 still provide provenance and senderLabel display hints, but not the requested durable per-message sender identity contract across Gateway protocol, persisted/live history, and Control UI rendering.

## What This Changes

Request durable human, main-agent, and sub-agent sender identity in the Chat UI so multi-agent steer and completion messages render with distinct, auditable origins.

## Best Possible Solution

Define one additive sender identity object and thread it through chat.send, sessions.send/sessions.steer, subagent announcements, persisted transcripts, chat.history/session.message events, and Control UI grouping/avatar rendering.
