## What This Changes

The issue requests an optional per-agent subagent concurrency cap so one target agent can be serialized without globally limiting all subagents.

Add a validated per-target subagent concurrency setting in the existing subagents namespace and enforce it alongside the global subagent lane cap across native and ACP spawn paths.
