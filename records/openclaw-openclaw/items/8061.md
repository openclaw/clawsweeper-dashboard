## What This Changes

The issue requests a per-agent subagent concurrency limit so one target subagent, such as a local TTS agent, can be serialized without globally limiting all subagent spawns.

## Best Possible Solution

Add a validated per-target-agent subagent concurrency setting, likely under `agents.list[].subagents.maxConcurrent`, and enforce it alongside the global subagent lane cap with focused native and ACP spawn coverage plus docs/schema updates.
