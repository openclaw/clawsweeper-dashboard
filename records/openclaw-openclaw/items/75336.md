## Summary

Keep this PR open. The proposed safeguard directly addresses the linked identifier-survival report, and the earlier code findings appear addressed, but the current proof still exercises helpers and controlled handler mocks rather than an actual compaction-handler run with a real summarizer; strict cancellation also needs an explicit maintainer decision because it can intentionally interrupt an existing session instead of returning a capped summary.

## What This Changes

This PR extends compaction quality checks to retain identifiers from the transcript, redact credential-like tool arguments before scanning, retry strict summaries with missing identifiers, and cancel strict compaction when final recovery cannot fit the summary cap.

## System Context

The agent compaction safeguard turns older conversation turns into a bounded summary before the next model run. This PR feeds transcript identifiers into its quality guard so the resulting summary either preserves critical references, retries, or—in strict mode—stops compaction rather than continuing with known context loss.
