## What This Changes

The branch adds an optional npm install-strategy argument when generating temporary package locks and uses the shallow strategy for bundled plugin dependency packaging, with focused validation coverage.

## System Context

OpenClaw's plugin publish tooling builds package-local artifacts and validates their npm locks before packaging or publishing a plugin. This change keeps temporary lock generation aligned with the later bundled-dependency install so npm does not reject the generated lock during plugin release packaging.
