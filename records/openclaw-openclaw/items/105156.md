## Summary

Keep open for landing: current main still loses the delivery path when post-turn compaction throws, while this branch provides a broader, well-proven fix than the older overlapping PR. No actionable correctness or security defect was found; agent/session ownership review and current-base validation remain appropriate before merge.

## What This Changes

The PR persists a normalized sendable final before optional post-turn compaction, continues delivery after ordinary compaction failure, transfers cleanup ownership across known session successors, expands lifecycle regression coverage, and removes one stale dead-code baseline entry.

## Best Possible Solution

Keep the agent lifecycle as the single owner: persist only a canonical sendable final before optional compaction, transfer ownership only to explicitly known session successors, retain state after failed delivery, and clear it through exact-session and run guards after confirmed success.
