## Label Justifications

- `P1`: The PR fixes completed channel replies being lost after a post-turn compaction failure.
- `merge-risk: 🚨 message-delivery`: The patch changes when completed replies are persisted, delivered, retained, and cleared, so an ownership mistake could drop or duplicate messages.
- `merge-risk: 🚨 session-state`: The patch transfers pending-final cleanup ownership across provider and compaction session successors and affects restart recovery state.

## Summary

The reported delivery bug remains on current main, and this PR is a correct, proof-backed candidate rather than a duplicate to close: the older competing PR is conflicting and does not cover the restart-durability and successor-ownership gaps.

## What This Changes

Persists a normalized sendable final before optional post-turn compaction, continues delivery after ordinary compaction failure, transfers cleanup ownership across known session successors, and adds lifecycle regression coverage.

## Best Possible Solution

Keep the agent lifecycle as the single owner: persist only a canonical sendable final before optional compaction, transfer ownership only to known successors, retain state after failed delivery, and clear it with exact-session guards after success.
