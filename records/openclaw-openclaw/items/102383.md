## Label Justifications

- `P2`: This is a substantial experimental product feature with bounded current exposure, but it needs normal-priority correctness, proof, and product review before landing.
- `merge-risk: 🚨 compatibility`: The PR adds durable ownership state and changes existing agent-deletion semantics, creating upgrade and lifecycle behavior that future releases must preserve or migrate.

## Summary

Keep this protected draft open: the earlier convergence, schema, and session-target findings appear fixed, but agent deletion can still strand cron jobs after a post-commit cleanup failure, after-fix live proof is absent, and the open Claws RFC has not yet confirmed this permanent ownership contract.

## What This Changes

Adds Gateway-owned installation, durable provenance, status/export projection, and removal for cron jobs declared by experimental grouped Claw packages, while extending canonical agent deletion to remove agent-owned cron jobs.

## Best Possible Solution

Keep `agents.delete` as the single owner, but make agent teardown durably resumable or idempotent after config removal, add partial-failure and retry coverage, and demonstrate the complete add/reconcile/status/export/remove lifecycle against a real isolated Gateway before accepting the RFC-backed contract.
