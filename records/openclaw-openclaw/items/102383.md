## Summary

Keep open. The current head addresses the earlier declaration-reconciliation, canonical-schema, session-mode, and Claw-removal findings, but generic agent deletion still has two blocking lifecycle gaps and the PR provides tests rather than after-fix live Gateway proof.

## What This Changes

The PR installs Claw-declared cron jobs through Gateway APIs, persists their ownership in shared state, exposes them through status/export, and extends agent and Claw deletion to remove owned jobs.

## Best Possible Solution

Use one Gateway-owned, resumable agent-deletion state machine that durably records targeted cron jobs and completed teardown steps, fails safely before agent mutation, handles the documented offline fallback explicitly, and is proven with a redacted live lifecycle transcript.
