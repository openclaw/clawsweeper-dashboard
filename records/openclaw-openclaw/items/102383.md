## Summary

Keep this PR open. The earlier deletion-durability blocker remains on the canonical `agents.delete` path, and the new proof simulates Gateway-shaped calls rather than demonstrating the behavior against a running Gateway; the protected stacked feature still needs maintainer review.

## What This Changes

The PR adds Gateway-managed Claw cron installation and reconciliation, persists cron ownership in shared SQLite state, exposes it through status/export, and integrates cron teardown with Claw and agent deletion.

## Best Possible Solution

Make cron teardown a durable prerequisite of every agent-deletion path, including offline behavior, preserve retryable ownership state until cleanup completes, and prove add/reconciliation/failure/retry/removal against a running Gateway before landing the stack.
