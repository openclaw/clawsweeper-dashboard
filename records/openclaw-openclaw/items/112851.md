## Summary

This PR remains necessary: current `main` still sends Venice discovery through the strict default path, so proxy-required networks fall back to the bundled catalog. The proposed provider-local opt-in uses the existing guarded-fetch preset, preserves the hostname allowlist and fallback behavior, follows merged sibling fixes, and includes convincing terminal and proxy-harness proof.

## What This Changes

The PR makes Venice’s official live model-catalog request honor eligible HTTP(S) proxy environment settings and adds a regression test for that guarded transport mode.

## System Context

The Venice bundled provider supplies model rows to the CLI and model-selection paths. Its live catalog request is routed through the shared guarded-fetch layer, which enforces the provider hostname policy while selecting either direct or explicitly trusted environment-proxy transport.
