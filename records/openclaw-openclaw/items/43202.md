## Summary

Keep open. Current main and the latest release still narrow Feishu card-action callbacks to `action.value` plus `tag`, and the live linked pull request at https://github.com/openclaw/openclaw/pull/43953 is an unmerged fix candidate rather than an implemented solution.

## What This Changes

The issue asks Feishu card-action callbacks to pass through `form_value`, `input_value`, `name`, `option`, and `options` so agents receive structured interactive-card form and selector data.

## Best Possible Solution

Refresh, land, or replace the linked Feishu-plugin PR so the raw parser preserves form/input/select fields and the handler exposes them through a documented, tested payload while preserving simple button commands.
