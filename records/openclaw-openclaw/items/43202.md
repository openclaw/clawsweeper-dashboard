## Summary

Keep open. Current main and v2026.6.11 still preserve only `action.value` and `tag` from Feishu card-action callbacks, and the open same-author PR remains the active closing candidate for `form_value`, `input_value`, `name`, `option`, and `options` pass-through.

## What This Changes

The issue requests Feishu card-action callbacks to pass form, input, component-name, and selector fields through to the synthetic agent message while preserving simple button behavior.

## Best Possible Solution

Land or replace the linked Feishu PR with a backward-compatible parser/handler change that preserves simple button command extraction, passes through form/input/select fields, and includes focused tests plus redacted live Feishu callback proof.
