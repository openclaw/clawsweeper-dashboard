- `P2`: Feishu interactive card submissions can silently drop user-entered form and selector data, but the blast radius is bounded to one bundled channel plugin path.
- `impact:data-loss`: Callback payload fields such as `form_value` and `input_value` are discarded before agents can consume them.

## Summary

Keep open. Current main and v2026.6.11 still narrow Feishu card-action callbacks to `action.value`/`tag`, while the linked closing PR remains open and unmerged.

## What This Changes

The issue asks Feishu card actions to preserve `form_value`, `input_value`, `name`, `option`, and `options` fields from interactive card callbacks in the synthetic agent message.

## Best Possible Solution

Review, refresh, and either land or close the linked Feishu-plugin PR, preserving simple button command behavior while documenting a stable structured payload for form/input/select callbacks.
