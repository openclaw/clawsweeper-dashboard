## Summary

Keep open. Current main and v2026.6.11 still narrow Feishu card action callbacks to `action.value`/`tag`, while the open closing pull request is an unmerged fix candidate rather than an implemented solution.

## What This Changes

The issue requests Feishu card action callbacks to pass through interactive-card fields such as `form_value`, `input_value`, `name`, `option`, and `options` while preserving simple button behavior.

## Best Possible Solution

Refresh, review, and land or replace the linked Feishu-plugin fix so raw form/input/select fields survive parsing and dispatch, with focused tests and redacted real Feishu callback proof.
