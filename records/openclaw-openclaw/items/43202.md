## Summary

Keep open. Current main and v2026.6.11 still narrow Feishu card-action callbacks to `action.value`/`tag`, and the open closing PR remains unmerged.

## What This Changes

## Best Possible Solution

Review and refresh the linked Feishu-plugin PR, settle a stable structured payload contract, and preserve simple button command behavior.
