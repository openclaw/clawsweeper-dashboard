## Summary

Keep open. Current main and the latest release still narrow Feishu card-action callbacks to `action.value` and `tag`, and the same-author open PR remains the active but conflicting/proof-gated fix candidate for preserving the missing callback fields.

## What This Changes

The issue asks for Feishu card-action callbacks to pass through `form_value`, `input_value`, `name`, `option`, and `options` instead of delivering only `action.value`.

## Best Possible Solution

Land or replace the linked Feishu PR with a backward-compatible parser/handler change that preserves simple button text/command behavior, passes through form/input/select fields, and includes focused unit coverage plus redacted live Feishu callback proof.
