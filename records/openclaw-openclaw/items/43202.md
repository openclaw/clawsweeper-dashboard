## Summary

Keep open. Current main and v2026.6.11 still narrow Feishu card-action callbacks to `action.value`/`tag`, while the same-author linked PR remains open and unmerged as the active fix candidate.

## What This Changes

The issue requests that Feishu card-action callbacks pass through `form_value`, `input_value`, `name`, `option`, and `options` fields instead of only forwarding `action.value`.

## Best Possible Solution

Review, refresh, and either land https://github.com/openclaw/openclaw/pull/43953 or replace it with an equivalent narrow Feishu plugin fix that preserves the extra callback fields at the parser boundary, adds focused regression tests, and includes redacted live Feishu proof before closing this issue.
