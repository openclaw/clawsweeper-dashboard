## Summary

Keep open. Current main and latest release still narrow Feishu card-action callbacks to `action.value`/`tag`, while the same-author linked PR remains open and unmerged as the active fix candidate.

## What This Changes

Pass Feishu card-action `form_value`, `input_value`, `name`, `option`, and `options` fields through to the agent-visible synthetic message while preserving simple button behavior.

## Best Possible Solution

Refresh, review, and land or replace the linked Feishu plugin PR with parser-boundary field preservation, a clear structured payload contract, focused handler/parser tests, and redacted real Feishu proof.
