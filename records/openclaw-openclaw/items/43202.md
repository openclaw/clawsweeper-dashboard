## Summary

Keep open. Current main and v2026.6.11 still narrow Feishu card-action callbacks to `action.value`/`tag`, and the live closing pull request is the implementation candidate rather than a merged fix.

## What This Changes

The issue asks the Feishu card-action path to pass through `form_value`, `input_value`, `name`, `option`, and `options` fields to the agent instead of dropping them.

## Best Possible Solution

Keep this issue open until the linked PR or a narrow replacement lands in the Feishu plugin, preserving simple button-command fallback while passing through form/input/select fields with focused tests and redacted real Feishu proof.
