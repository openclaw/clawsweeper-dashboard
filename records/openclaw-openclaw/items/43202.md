## Summary

Keep open. Current main and v2026.6.11 still preserve only `action.value`/`tag` from Feishu card-action callbacks, and https://github.com/openclaw/openclaw/pull/43953 is the open fix candidate rather than a merged implementation.

## What This Changes

Request Feishu card-action callbacks to pass through `form_value`, `input_value`, `name`, `option`, and `options` to the agent while preserving existing simple button behavior.

Refresh, review, and land or replace https://github.com/openclaw/openclaw/pull/43953 with a Feishu-plugin fix that preserves raw callback fields at the parser boundary, documents the payload shape, and adds focused parser/handler tests plus redacted real Feishu proof.
