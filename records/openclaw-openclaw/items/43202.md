## Summary

Keep open. Current main and the latest release still preserve only `action.value` and `tag` from Feishu card-action callbacks, so `form_value`, `input_value`, `name`, `option`, and `options` are still dropped; the open linked pull request is the active fix candidate, not a merged implementation.

## What This Changes

Request to pass Feishu card-action form and interactive component fields through to the synthetic agent message instead of dropping them.

## Best Possible Solution

Keep this issue open until the linked Feishu pull request is either landed with an agreed payload contract and real card-action proof, or closed in favor of a narrower replacement.
