The issue asks Feishu card action callbacks to pass through `form_value`, `input_value`, `name`, `option`, and `options` so agents receive interactive-card form and selection data.

## Best Possible Solution

Review and either land or replace the linked Feishu PR with a focused parser-to-handler fix that preserves the missing fields, locks the payload contract in tests, and provides real Feishu card-action proof.
