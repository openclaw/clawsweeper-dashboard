## Summary

Keep open. Current main and v2026.6.11 still preserve only `action.value`/`tag` from Feishu card-action callbacks, and the same-author open PR remains the active fix candidate for `form_value`, `input_value`, `name`, `option`, and `options` pass-through.

## What This Changes

Request to preserve Feishu card-action callback fields such as `form_value`, `input_value`, `name`, `option`, and `options` in the synthetic agent message while keeping simple button clicks compatible.

## Best Possible Solution

Land or replace the linked Feishu PR with a backward-compatible parser/handler change that preserves simple button command extraction, exposes form/input/select callback fields, and includes focused unit coverage plus redacted live Feishu callback proof.
