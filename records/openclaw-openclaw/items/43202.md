## Summary

Keep open. Current main and v2026.6.11 still narrow Feishu card-action callbacks to `action.value`/`tag`, and the open linked fix candidate at https://github.com/openclaw/openclaw/pull/43953 has not merged.

## What This Changes

Request that Feishu card action callbacks pass through form/input/select fields such as `form_value`, `input_value`, `option`, `options`, and `name` instead of only delivering `action.value`.

## Best Possible Solution

Refresh, land, or replace the linked Feishu-plugin fix so raw form/input/select fields survive parsing and dispatch through a documented payload while simple button commands remain unchanged.
