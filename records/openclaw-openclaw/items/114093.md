## What This Changes

This PR changes OpenAI device-code polling so errors other than explicit caller cancellation retry until the existing 15-minute authorization deadline.

## System Context

The bundled OpenAI plugin starts a device-code authorization flow, then polls the provider until authorization succeeds, expires, or the caller cancels. The polling result is passed to the plugin’s auth flow, which persists credentials or reports an authorization failure to the operator.

## Best Possible Solution

Retry only errors proven retryable by the OpenAI polling helper or its upstream transport contract, preserve immediate propagation for terminal failures and caller cancellation, add focused regression coverage for both paths, and attach redacted live authorization evidence.
