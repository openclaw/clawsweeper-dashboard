## What This Changes

The branch adds count-only live background-exec accounting to the process registry, detached approval handoff, suspension, safe restart, reload, protocol, tests, and docs.

## Best Possible Solution

Separate termination request from terminal state, retain count-only activity through fallback PID-tree shutdown, and clear it only after observed exit or a liveness check confirms the tree is gone.
