## Summary

## What This Changes

Restore a Discord session to the current configured primary model after changing the default, using `/new` or `/model` without requiring a gateway restart.

## System Context

OpenClaw resolves an agent's configured primary model, then lets a session-level user selection pin a different provider/model. Discord slash commands operate on that session state: `/model default` should clear the pin, while `/new` should create a fresh session that resolves from current configuration.

## Best Possible Solution

Keep one canonical repair discussion that makes `/model default` clear the session pin and makes `/new` create an unpinned session resolved from the live configured primary, with regression coverage across Discord and other channel sessions.
