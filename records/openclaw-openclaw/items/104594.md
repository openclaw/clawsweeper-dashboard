## Summary

Current main does not contain the change, and the protected `maintainer` label also rules out cleanup closure.

## What This Changes

The PR adds a full-jitter strategy and injectable randomness to the shared retry helper, adds focused timing tests, and migrates Mattermost direct-channel creation from its hand-written retry loop to `retryAsync`.

## Best Possible Solution

Use the canonical shared retry engine for Mattermost, keep full-jitter semantics explicitly tested, and expose only the smallest maintainer-approved plugin SDK contract—preferably retaining deterministic randomness as an internal test seam unless external consumers need it.
