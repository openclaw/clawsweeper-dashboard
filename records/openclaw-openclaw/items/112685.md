## What This Changes

The issue requests that successful WhatsApp voice-note transcripts reach the model as clearly machine-generated, untrusted audio content while retaining raw transcript data and audio metadata for channel behavior.

## System Context

The WhatsApp extension receives inbound audio, optionally obtains a preflight speech-to-text result, and constructs the message fields passed into the shared agent loop. That envelope then determines how the model interprets the content and how channel reply behavior uses the original audio metadata.
