## What This Changes

Fix WhatsApp inbound voice notes so successful speech-to-text remains identifiable to the agent as machine-generated audio transcription rather than appearing as typed user text.

## System Context

The WhatsApp extension receives an audio message, optionally runs audio preflight transcription, and builds the inbound envelope consumed by the agent. That envelope determines whether the model can distinguish a user’s typed text from speech-to-text output while later reply delivery uses the same turn context.
