## What This Changes

Fix WhatsApp voice-note transcription so agent-facing content identifies speech-to-text output as machine-generated and untrusted while retaining raw transcript and audio facts for parsing and media behavior.

## System Context

The WhatsApp plugin receives inbound media, optionally transcribes audio before the agent run, and constructs the message fields consumed by the agent. Those fields also carry media metadata used by later reply and audio-handling behavior.
