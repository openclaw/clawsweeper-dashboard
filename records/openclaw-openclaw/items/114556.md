## What This Changes

This PR renders model-authored `<details>` and `<summary>` blocks as native disclosures in the Control UI, preserves them for Telegram rich messages, and flattens them into portable Markdown for other outbound channels.

## System Context

Assistant responses flow through the Control UI Markdown renderer for web presentation and through outbound channel adapters for delivery. This change recognizes disclosure markup at those boundaries so supported renderers preserve collapsible content while unsupported transports receive readable expanded text.
