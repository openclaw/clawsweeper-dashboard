Keep open: current main and v2026.6.11 still allow the reported false 12-hour OpenAI OAuth cooldown, and the issue has both a protected maintainer label and an open linked fix PR that should resolve it through maintainer review.

## What This Changes

The issue asks OpenClaw to skip WHAM probing when an OpenAI OAuth access token is already locally expired so refreshable profiles stay on normal transient cooldown instead of a 12-hour token-expired cooldown.
