## Summary

Keep open: current main and the latest release still do not compose Feishu text or presentation plus image attachments into one interactive card; the remaining blocker is maintainer product direction on trigger semantics and image-card safety limits.

## What This Changes

Request a Feishu/Lark channel send path that uploads multiple image attachments and sends them with text or presentation content as one Feishu interactive card.

## Best Possible Solution

Implement a Feishu-plugin-local controlled image-card builder that reuses existing media loading/upload policy and card sending after maintainers choose opt-in versus automatic triggering and safety limits.
