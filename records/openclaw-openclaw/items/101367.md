## Summary

## What This Changes

The PR moves OpenRouter image generation/editing to the shared OpenAI-compatible image provider factory, adds `endpointPath` and `media_type` support, enables MIME sniffing, updates tests, and documents `/api/v1/images`.

## Best Possible Solution

Land the shared-factory migration only after maintainers explicitly accept `endpointPath` as the public flat-endpoint seam and are comfortable with the OpenRouter endpoint change for upgrades and custom base URLs.
