## What This Changes

This PR bounds Web Push broadcast sends at 12 concurrent requests, supplies VAPID identity per request, and conditionally removes expired subscription snapshots in one locked state update.

## Best Possible Solution

Keep Web Push broadcast scheduling in one bounded, order-preserving owner with request-local VAPID credentials and compare-before-clear cleanup for expired registrations.
