## What This Changes

The PR bounds Web Push broadcasts at 12 concurrent sends, passes VAPID identity per request, and removes expired subscriptions only when their attempted snapshots remain current.

## Best Possible Solution

Keep one bounded, order-preserving scheduler in the Web Push broadcast owner, use request-local VAPID credentials, and preserve snapshot-aware expired cleanup through any subsequent SQLite store migration.
