## What This Changes

The PR changes Web Push broadcasting to schedule sends through a bounded concurrency worker, passes VAPID credentials per notification, and avoids deleting a subscription that changed while an expired send was in flight.

## System Context

Web Push stores browser/device subscriptions and sends a notification to each one when OpenClaw broadcasts an event. This path reads persisted VAPID credentials and subscriptions, sends outbound HTTPS requests, then removes endpoints that the push service reports as expired.
