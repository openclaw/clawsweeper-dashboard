## Summary

Keep open: current main and the latest release have URL-backed `[embed]` Canvas previews, but they do not have the requested client-capability-gated tool availability or a Canvas-owned `show_widget` tool. The protected `maintainer` label plus the new plugin/tool API and sandboxed markup policy make this a maintainer design item rather than cleanup closure.

## What This Changes

Add client-capability-gated tool availability for web-capable clients and a Canvas-owned inline widget tool for sandboxed SVG or HTML rendering in web chat.

## Best Possible Solution

Have maintainers approve the generic client-capability-gated tool contract and sandbox policy, then implement the first widget tool in the Canvas/plugin boundary with CSP, cleanup, size-limit, and web-chat rendering tests.
