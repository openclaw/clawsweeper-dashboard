## Summary

Keep open: current main and the latest release have the hosted embed foundation, but they do not provide an `inline-widgets` client capability, a `requiredClientCaps` tool contract, or a Canvas-owned `show_widget` tool. The protected `maintainer` label plus the plugin/API and model-authored markup security design make this a maintainer product decision, not cleanup closure.

## What This Changes

Add client-capability-gated tool availability and a Canvas-owned inline widget tool for sandboxed SVG/HTML rendering in web chat.

## Best Possible Solution

Keep this open for maintainer design review of a generic client-capability-gated tool contract, then implement the first widget tool in the Canvas/plugin boundary with explicit sandbox, CSP, persistence, cleanup, and deterministic filtering tests.
