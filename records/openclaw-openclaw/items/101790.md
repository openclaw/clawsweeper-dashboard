## Summary

Keep open. Current main does not implement the requested `inline-widgets` client capability, `requiredClientCaps` tool contract, or Canvas-owned `show_widget` tool, and the protected `maintainer` label plus markup-rendering security boundary make this a maintainer design item rather than conservative cleanup.

## What This Changes

The issue requests client-capability-gated tool availability plus a Canvas-owned inline widget tool for web chat.

## Best Possible Solution

Define one additive Gateway client-capability contract for renderable client surfaces, then implement any widget renderer as a Canvas-owned plugin tool using hosted sandboxed documents, restrictive CSP, size/session limits, docs, and focused Gateway/UI/Canvas tests.
