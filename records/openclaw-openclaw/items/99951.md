## Summary

Keep open. Current main has a newer Codex package pin and package-vs-gateway plugin drift checks, but it still does not expose or gate the active Codex route plugin's embedded runtime dependency; the open linked PR is the current implementation candidate.

## What This Changes

The issue asks OpenClaw to detect and warn or block when the active Codex route plugin embeds an older `@openai/codex` runtime than the approved release-train minimum, even if the plugin package and host CLI look current.

## Best Possible Solution

Review and land, narrow, or replace https://github.com/openclaw/openclaw/pull/99956 so Codex route-runtime dependency drift is visible in status/doctor and blocked in release/package guard paths, then close this issue after merge proof.
