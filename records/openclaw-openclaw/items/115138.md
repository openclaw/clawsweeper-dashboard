## Summary

Keep this PR open for maintainer review. The local-filesystem branch and network-filesystem exclusion are thoughtfully targeted, and the contributor supplied a real benchmark, but enabling a 256 MiB per-connection mmap ceiling changes the memory profile of every local WAL database without proving aggregate RSS behavior across the agent-database handle cache.

## What This Changes

This PR enables a 256 MiB SQLite memory-mapped-read ceiling after local-filesystem WAL setup and adds tests that exclude known network filesystems.

## System Context

SQLite connection setup configures journal and maintenance behavior for OpenClaw state and agent databases. Those connections serve synchronous `node:sqlite` reads, so a local-WAL mmap setting affects runtime latency as well as the process memory profile.
