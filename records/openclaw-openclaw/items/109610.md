Keep this PR open for normal landing review: it addresses a real bounded-memory problem in the best-effort reply-usage handoff with a focused capacity limit, regression coverage, and credible live Gateway proof. I found no concrete correctness or security defect in the patch.

## What This Changes

Bounds the in-memory reply usage handoff at 1,024 snapshots after expiry pruning and adds a regression test for oldest-entry eviction.

## Best Possible Solution

Land the bounded post-expiry handoff so extreme bursts discard only the oldest optional usage metadata while recent exact-run correlations and the documented five-minute behavior remain intact.
