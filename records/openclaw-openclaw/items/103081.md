## Summary

Keep open: current main only mitigates stale gateway model-run rows when session-entry cap pressure is reached, while each gateway probe still creates a visible explicit model-run session and below-cap stores still show those rows in session lists.

## What This Changes

The issue asks for `openclaw infer model run --gateway` to stop leaving durable visible `model-run-*` session rows and transcripts on each one-shot probe.

## Best Possible Solution

Route gateway infer model probes through an existing backend-only internal/ephemeral session-effects path so raw isolated execution still works, no visible session row or normal transcript is created, and existing pressure-gated cleanup remains for old polluted stores.
