## Summary

Keep open: current main still creates durable explicit model-run sessions and only pressure-gates cleanup, so the requested no-persistence, hidden-session, or sessions-list filtering behavior remains unresolved and needs a maintainer product decision.

## What This Changes

The issue requests that `openclaw infer model run --gateway` stop creating or exposing durable model-run session and transcript state for one-shot invocations.

## Best Possible Solution

Choose and document one explicit lifecycle contract for Gateway model-run probes, ideally making them ephemeral or hidden from normal session lists by default while retaining pressure cleanup for legacy rows already created by older releases.
