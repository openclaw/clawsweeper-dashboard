- `P2`: The report has concrete production impact and source-level support, but it has a workaround and is not an immediate outage or data-loss emergency.
- `impact:session-state`: The issue is about one-shot gateway model probes creating durable session rows and transcript artifacts.

## Summary

Keep open: current main only provides pressure-gated cleanup for stale gateway model-run probe rows, while the issue asks for a stricter lifecycle or visibility contract so one-shot probes do not leave normal durable session clutter on every invocation.

## What This Changes

The issue asks for `openclaw infer model run --gateway` to stop leaving durable, client-visible session and transcript state on every one-shot invocation.

## Best Possible Solution

Choose and document one explicit lifecycle contract for gateway model probes: preferably make them internal/ephemeral or hidden from normal session lists by default, while keeping current pressure-gated cleanup for legacy rows.
