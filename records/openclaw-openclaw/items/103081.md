## Summary

Keep open: current main has a merged pressure-gated cleanup for model-run rows, but `infer model run --gateway` still creates visible explicit model-run sessions and current tests preserve below-cap stale probe rows, so the no-persistence/filter request remains unresolved.

## What This Changes

The issue asks for one-shot `openclaw infer model run --gateway` invocations to stop leaving durable visible session rows and transcript files, or at least expose a supported way to hide or prune them.

## Best Possible Solution

Choose one explicit lifecycle contract for gateway model probes: make them internal/ephemeral by default while keeping pressure-gated cleanup for legacy rows, or deliberately keep visible probe history and add a documented session-list filter.
