## Summary

Keep open: v2026.6.11 still leaves explicit model-run sessions with no model-run cleanup, and current main only adds pressure-gated pruning, so the requested no-persistence or session-list filtering behavior remains unresolved and needs maintainer product direction.

## What This Changes

The issue requests that `openclaw infer model run --gateway` stop leaving visible durable `model-run-*` session rows and transcripts on every one-shot invocation, or provide a supported way to hide or prune them.

## Best Possible Solution

Pick one explicit lifecycle contract for gateway model probes: make them internal/ephemeral or hidden from normal session lists by default, while keeping pressure-gated cleanup for legacy rows, or deliberately document visible probe history as intended.
