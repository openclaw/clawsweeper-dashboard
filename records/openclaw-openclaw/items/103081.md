## Summary

Keep open: current main still creates a durable explicit `model-run-<uuid>` gateway session for each `infer model run --gateway` invocation, and current cleanup only prunes stale model-run rows under session-entry/cap pressure, so the requested no-persistence or normal-session-list hiding behavior remains unresolved.

## What This Changes

The issue asks OpenClaw to stop, hide, or reliably clean up durable session rows and transcript artifacts created by each `openclaw infer model run --gateway` invocation.

## Best Possible Solution

Pick one explicit lifecycle contract for gateway model probes, then align persistence, cleanup, docs, and session-list visibility with that contract while preserving legacy cleanup for rows already created by shipped releases.
