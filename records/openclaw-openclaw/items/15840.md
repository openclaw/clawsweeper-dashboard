## What This Changes

The issue requests a default-off messages configuration option to suppress visible media placeholder text such as `<media:audio>` for media-only outbound messages.

## Best Possible Solution

Keep this as the canonical product/config request until maintainers choose a default-off global messages policy or a narrower Signal hidden-body policy, preserving iMessage's channel-local fix.

## Solution Assessment

Unclear: the requested global config option is plausible, but iMessage was solved channel-locally and Signal may need a hidden non-empty body, so maintainers should choose the product surface before implementation.
