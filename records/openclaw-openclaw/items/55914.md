## Summary

Request to add an `openclaw invite` command that creates short mobile pairing invite codes backed by configurable cloud register/resolve endpoints.

Settle the shared mobile cloud trust/config model first, then either implement a narrow approved invite-code discovery path or explicitly keep the supported path as QR/setup-code plus direct LAN, Tailnet, or SSH reachability.
