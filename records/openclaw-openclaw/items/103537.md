## Summary

This PR remains necessary, but the final head is not merge-ready: SIGINT or SIGTERM after successful launchd quiescence can bypass the exact-state rollback and leave the Gateway persistently disabled and unloaded.

## What This Changes

The branch makes mutable updates quiesce respawn-capable managed Gateways and adds exact launchd state restoration for unsuccessful updates.

## Best Possible Solution

Register the exact launchd rollback with the existing signal-exit gate and barrier immediately after quiescence, disarm it when successful update or restart ownership completes, add interruption regression coverage, and then provide redacted final-head macOS proof.
