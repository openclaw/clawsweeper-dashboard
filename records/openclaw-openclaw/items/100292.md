## Summary

Keep open: current main documents and policy-gates host-local MEDIA attachment reads, but the fresh report still identifies a real diagnostics gap because dropped or missing MEDIA directives only produce generic user feedback and verbose-only logging rather than a reason-bearing warn/event path.

## What This Changes

The issue asks for Telegram MEDIA directives with absolute local paths outside default media roots to either attach under the agent file-read policy or fail with clear, consistent diagnostics and documented/configurable root behavior.

## Best Possible Solution

Keep the file-read trust model, add reason-bearing dropped-media diagnostics for every MEDIA directive failure, and leave persistent configurable root expansion to the maintainer-approved root-policy work.
