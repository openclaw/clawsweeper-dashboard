## Summary

Keep open: current main and the latest stable release preserve the safe local-media allowlist and now add only a generic failure warning, while the issue still needs maintainer scoping between better blocked-media diagnostics and the broader configurable-root security contract.

## What This Changes

The issue asks OpenClaw to stop silently dropping Telegram `MEDIA:` attachments for host-local paths outside effective media roots, document or align the policy, and possibly add a root configuration escape hatch.

## Best Possible Solution

Keep the managed host-read boundary, add reason-specific dropped-media diagnostics, and route persistent root expansion through #47002 or the approved shared `tools.fs.roots` contract.
