## Summary

Keep open: current main still rejects out-of-policy local reply media and only gives generic dropped-media feedback, while the broader configurable-root contract remains unresolved in the open root-policy issue and candidate PR.

## What This Changes

The issue asks OpenClaw to make Telegram reply MEDIA directives for absolute local paths outside allowed roots either deliver safely, fail with clear diagnostics, or use a documented/configurable policy.

## Best Possible Solution

Keep the managed-root default, add reasoned warn/user-visible diagnostics for every dropped reply MEDIA directive, and let https://github.com/openclaw/openclaw/issues/47002 or the approved tools.fs.roots design own any root expansion.
