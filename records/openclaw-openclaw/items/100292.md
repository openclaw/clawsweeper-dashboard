## Summary

Keep open: current main has a generic dropped-media warning path, but the remaining Telegram MEDIA problem is still not fully resolved because reasoned warn-level diagnostics and the host-local root policy are still open product/security questions.

## What This Changes

The issue asks OpenClaw to make Telegram `MEDIA:` directives for absolute local paths either deliver safely, fail with clear diagnostics, or support a controlled root configuration.

## Best Possible Solution

Keep the safe host-read boundary, add reasoned warn-level diagnostics and a clear attachment-unavailable user notice for dropped reply media, and leave persistent root expansion to https://github.com/openclaw/openclaw/issues/47002 or an approved `tools.fs.roots` design.
