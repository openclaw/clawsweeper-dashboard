## What This Changes

The branch bounds an older completed reply’s wait behind a newer active reply turn, lets non-stale tool-status payloads avoid that wait, and moves the foreground freshness fence into a dedicated auto-reply module with regression tests.

## System Context

OpenClaw’s auto-reply dispatcher turns inbound chat events into tool-status and final reply payloads, then passes them through channel delivery hooks. The foreground reply fence coordinates concurrent turns for one session target, suppressing an older payload after a newer visible reply while this PR adds a deadline so an active but silent newer turn cannot hold completed output indefinitely.
