## What This Changes

This PR prevents global-session observer updates from another agent, or stale reconnect replays, from replacing the active agent’s current session progress in the Gateway, web UI, Apple clients, and Android.

## System Context

The Gateway emits global session-observer updates to connected clients, while the web, Apple, and Android chat views project those updates into the currently selected agent’s session status. The changed paths decide which agent owns a global update and whether a replayed update is newer before rendering it in chat and sidebar state.
