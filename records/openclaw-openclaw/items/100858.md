Full review comments:

- **[P1] Validate cursors before sending the Graph token:** `extensions/msteams/src/graph-messages.ts:520-523`
  - body: `params.cursor` comes from the new CLI flag and is passed directly to `fetchGraphAbsoluteUrl`, whose Graph helper adds `Authorization: Bearer ...` to the requested URL. A cursor such as `https://attacker.example/next` would receive the MSTeams Graph token; restrict cursors to the expected Microsoft Graph nextLink origins/path before making the authenticated fetch, or encode an internal cursor instead.
  - confidence: 0.94
- **[P1] Preserve existing pagination hints during migration:** `src/commands/message-format.ts:422`
  - body: The formatter now only checks `result.pagination`, but current providers still return pagination signals in their payloads, such as Discord `total_results`, Slack `hasMore`, and Matrix `nextBatch`. Because those provider migrations are listed as follow-up work, this drops the existing "More results" hint for them; keep the current fallback or migrate all providers in the same change.
  - confidence: 0.9
- **[P2] Expose cursor only where the CLI can consume it:** `src/cli/program/message/register.permissions-search.ts:30`
  - body: Adding `--cursor` to `message search` does not make the advertised MSTeams command work: this command is still registered as Discord search and still requires `--guild-id` plus `--query`, while the PR body's MSTeams example uses `--target`. Either update the cross-channel search CLI shape and tests, or keep the cursor flag off unsupported commands until the action consumes it end to end.
  - confidence: 0.87
