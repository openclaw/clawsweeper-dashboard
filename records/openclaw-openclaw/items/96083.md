## Summary

Keep this PR open, but do not merge it yet: both previously reported P1 correctness defects remain on the current head, and the submitted evidence still does not exercise the changed production recovery entrypoints.

## What This Changes

The branch adds a shared persistent restart-recovery attempt counter and quarantine metadata for main and subagent sessions, clears that state after successful lifecycle completion, and adds focused tests plus a standalone logic model.

## Best Possible Solution

Use one atomic owner-specific durable fuse: gate main-session recovery only after routing, process-owner, and dedupe checks with locked exact-row revalidation, and extend the existing `subagentRecovery` state for slow cross-boot loops instead of layering a parallel counter.
