## Summary

Keep open: the main-session bug remains real on current `main`, but this head is not merge-ready because quarantine still bypasses ownership guards, can mutate a replaced session row, and adds a second conflicting subagent recovery fuse.

## What This Changes

The PR adds persisted restart-recovery attempt and quarantine fields for main-session and subagent recovery, clears them after successful lifecycle completion, and adds regression tests plus a pure-logic repro script.

## Best Possible Solution

Keep the established `subagentRecovery` state machine and implement a main-only durable fuse that reserves accepted attempts under the session-store lock, runs after routing and ownership guards, and revalidates the exact session generation before quarantine.
