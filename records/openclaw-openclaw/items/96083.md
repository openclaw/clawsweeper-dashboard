## Summary

The PR should stay open: the latest head fixes the earlier ownership and duplicate-fuse findings, but its recovery budget resets only after a successful terminal event, so a fresh user turn that wedges before completion inherits the previous incident’s exhausted budget and can be quarantined immediately. Real behavior proof through the production recovery entrypoints is also still missing.

## What This Changes

The branch adds persistent cross-boot retry and quarantine state for main-session recovery, makes subagent recovery attempts cumulative across boots, clears main recovery metadata after successful completion, and adds regression tests plus a standalone modeled repro script.

## Best Possible Solution

Clear only the main restart-recovery budget and quarantine at the canonical fresh non-recovery turn start or acceptance boundary, add a start-then-interrupt regression, preserve independent subagent state and stale-event guards, and provide final-head file-backed production-entrypoint proof.
