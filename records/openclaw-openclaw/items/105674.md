## What This Changes

The PR adds an opt-in delayed background review of substantial successful agent turns that can create or revise one pending Skill Workshop proposal, along with exact-model isolation, literal-credential rejection, documentation, and tests.

## Best Possible Solution

Keep successful-work learning inside the existing pending-proposal boundary, but make review ownership explicit across persistent and one-shot runtimes and ship it only with a maintainer-approved consent contract for the existing autonomy setting.
