## What This Changes

The PR replaces raw UTF-16 slicing in exported-session tree previews with a bounded Unicode code-point scan and adds surrogate-pair and large-input regression coverage.

## Best Possible Solution

Land the bounded code-point scan and its focused regressions after refreshing against current `main`, while preserving the independently merged optional-scroll changes.

## Maintainer Decision

## Reproduction Assessment

Yes. On current `main`, a tree preview containing 99 BMP characters followed by an emoji crosses the raw 100-UTF-16-unit slice boundary and leaves only the emoji's high surrogate; the regression constructs exactly that boundary.

## Solution Assessment

Yes. A bounded `for...of` scan is the narrowest maintainable fix for this standalone browser template because it preserves complete code points without the full-string traversal and allocation of `Array.from`.
