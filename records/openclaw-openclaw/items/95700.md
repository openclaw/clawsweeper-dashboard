## What This Changes

This branch adds explicit session naming through `/new --name` and native title input, plus `/close` and `/delete` commands that archive the active non-main chat session through the gateway lifecycle.

## System Context

Chat commands are parsed in the auto-reply layer, then call session and gateway services to reset, name, or delete the active session. The Control UI intercepts some slash commands locally, while gateway lifecycle handling coordinates active runs, session bindings, transcripts, and cleanup.
