## What This Changes

The PR adds explicit naming to new chat sessions, adds `/close` and `/delete` commands for non-main sessions, and threads the session-deletion lifecycle through gateway and Control UI paths.

## System Context

Chat slash commands enter the auto-reply command dispatcher, where `/new` resets or creates a session and `/close` delegates deletion to the gateway lifecycle. The gateway updates session metadata, cancels competing work, archives or removes the transcript, and returns a terminal reply to the initiating chat surface.
