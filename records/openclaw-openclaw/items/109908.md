## Summary

Keep this PR open: the native embedded-run path is carefully covered, but the timeout cleanup is explicitly withheld from plugin-owned transports even though built-in Codex and Copilot harnesses can materialize OpenClaw MCP tools. That leaves a significant sibling runtime path without the proposed lease cleanup, and the PR supplies mock-based tests rather than live child-process proof.

## What This Changes

The PR adds synchronous command-lane timeout cleanup and immediate registration of an idempotent MCP run-lease disposer for abandoned embedded runs.

## Best Possible Solution

Decouple OpenClaw MCP lease ownership from transport ownership: register lane-timeout cleanup for every harness that materializes OpenClaw MCP tools, add Codex/Copilot sibling coverage, and demonstrate a real child process or file lock being released after timeout while an independent lease remains usable.
