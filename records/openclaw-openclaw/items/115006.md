## What This Changes

The branch routes service-qualified iMessage or SMS attachment sends addressed to a handle through `imsg` RPC so it resolves the existing Messages conversation instead of synthesizing a chat GUID.

## System Context

The iMessage extension turns an OpenClaw outbound message plus optional media into either a bridge attachment command or an `imsg` RPC request. This routing decision determines which existing Messages chat receives the attachment and what receipt is returned to the agent/channel runtime.
