## What This Changes

Adds a bounded, display-projected tail of the source conversation to detached `sessionTarget: "current"` cron agent-turn prompts at run time, with tests for filtering, truncation, and isolated-job non-interference.

## System Context

Cron agent-turn jobs prepare a prompt before invoking a detached embedded agent. `current` jobs retain a durable source-session binding for delivery and settings; this change reads a small source transcript tail and supplies it to the detached run without continuing or writing to the source session.
