## What This Changes

Renames the scheduler agent tool advertised to models and MCP clients from `cron` to `automations`, updates name-keyed policy and security consumers, and routes legacy external calls to the canonical tool.

## System Context

OpenClaw assembles agent tools from configuration and exposes them through agent sessions, MCP servers, and Gateway HTTP invocation. This change alters the scheduler tool’s public identity while preserving scheduling RPCs and persisted job structures underneath.
