## What This Changes

This PR renames the agent scheduler tool presented in tool schemas, prompts, catalog entries, and MCP loopback checks from `cron` to `automations`, while mapping legacy policy names to the new identifier.

## System Context

OpenClaw assembles an agent tool catalog that is exposed to models and to the MCP loopback interface. Tool names then drive policy matching, replay/mutation safety, scheduling behavior, and tool-call dispatch.
