## Summary

Keep open: this PR targets a real stale-DM routing defect, but the new condition rewrites every requester session to the agent main key whenever `session.dmScope` is `main`, including group, cron, hook, subagent, and other non-DM sessions.

## What This Changes

The PR canonicalizes the `sessions_send` requester key to the agent main session under `dmScope="main"` and uses that key for provenance, same-session checks, watch registration, and A2A replies.

## Best Possible Solution

Canonicalize only requester keys positively identified as legacy direct-message keys, preferably through a central session-routing helper, while preserving all non-DM session classes and adding regressions for direct, group, cron, hook, and subagent callers.
