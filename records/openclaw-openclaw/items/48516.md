## Summary

Keep open. Current main still lets allowed Android third-party notifications become node-session system events, and the remaining cross-session/native-channel boundary needs maintainer security and product direction rather than cleanup closure.

## What This Changes

The issue asks OpenClaw to stop Android-forwarded native channel notifications from causing duplicate or misrouted node-session replies.

## Best Possible Solution

Choose a single maintainer-approved boundary that suppresses native-channel notification echoes and prevents node-session sends to unrelated channel conversations, then prove it with Android, gateway, and live WhatsApp coverage.
