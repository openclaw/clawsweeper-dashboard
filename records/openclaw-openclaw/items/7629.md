## Summary

Keep open: current main and the latest release still leave memory-lancedb on vector-only LanceDB retrieval, while the exact implementation PR closed unmerged and the open reranker PR is scoped to memory-core rather than LanceDB.

## What This Changes

Request to add BM25/full-text plus vector hybrid retrieval to the official memory-lancedb plugin, including FTS indexing, hybrid config, weighted/reranked search, and query-text propagation.

## Best Possible Solution

Keep this open until maintainers choose official plugin ownership; if accepted, implement memory-lancedb-owned hybrid search with FTS index lifecycle, explicit config/defaults, vector fallback, docs, and exact-keyword recall tests.
