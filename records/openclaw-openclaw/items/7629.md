## Summary

Keep open for a maintainer product decision. Current main and v2026.6.11 remain vector-only, while both a focused official implementation and the actively maintained community-plugin path are technically viable; prior repository-admin discussion deliberately kept this narrower official-plugin parity request open.

## What This Changes

Add BM25 full-text retrieval to the official `memory-lancedb` plugin and combine it with vector similarity, potentially with configurable enablement and fusion weights.

## Best Possible Solution

If official parity is sponsored, add an opt-in RRF-based hybrid recall path within `memory-lancedb`, preserve vector-only defaults and duplicate detection, create or verify the text FTS index through the pinned LanceDB API, and require focused local and object-store fallback proof before adding weight controls.
