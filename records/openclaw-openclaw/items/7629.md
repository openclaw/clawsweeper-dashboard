## Summary

Keep open: current main and the latest release still leave the official memory-lancedb plugin on vector-only retrieval, and the related exact implementation PR was closed unmerged while the open reranker PR explicitly leaves LanceDB out of scope.

## What This Changes

Request to add BM25 plus vector hybrid retrieval, FTS index setup, and hybrid weighting config to the memory-lancedb plugin.

## Best Possible Solution

Keep this open until maintainers choose official plugin ownership; if accepted, implement memory-lancedb-owned hybrid search with FTS index lifecycle, explicit config/defaults, vector fallback, docs, and exact-keyword recall tests.
