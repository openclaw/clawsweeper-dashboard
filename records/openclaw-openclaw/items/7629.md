## Summary

Keep open: current main and v2026.6.11 still leave `memory-lancedb` on vector-only LanceDB retrieval, while the exact prior implementation PR is closed unmerged and the open reranker PR explicitly excludes LanceDB.

## What This Changes

Add BM25 plus vector hybrid search support to the `memory-lancedb` plugin so exact keyword matches can participate in LanceDB memory recall.

## Best Possible Solution

Keep this as a focused official `memory-lancedb` parity decision; if maintainers approve it, implement plugin-local FTS indexing, query-text propagation, explicit hybrid defaults/config, vector fallback behavior, docs, and regression proof.
