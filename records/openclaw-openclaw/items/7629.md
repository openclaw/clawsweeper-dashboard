## What This Changes

The issue requests hybrid BM25 plus vector retrieval for the memory-lancedb plugin, including FTS indexing, hybrid config, and query-text-aware search.

## Best Possible Solution

Implement plugin-owned hybrid retrieval after maintainers choose the default/config, FTS index lifecycle, scoring, and fallback contract, preserving vector-only fallback with targeted tests and docs.
