## Summary

Keep open: current main and v2026.6.11 still leave memory-lancedb on vector-only retrieval, while the earlier exact implementation PR closed unmerged and the open reranker work explicitly excludes LanceDB.

## What This Changes

The issue requests BM25 plus vector hybrid retrieval for the official memory-lancedb plugin so exact keyword matches can participate in memory recall.

## Best Possible Solution

Keep this open until maintainers choose official plugin ownership; if accepted, implement memory-lancedb-owned hybrid search with FTS index lifecycle, explicit config/defaults, vector fallback, docs, and exact-keyword recall tests.
