## Summary

Keep open: current main and v2026.6.11 still leave the official memory-lancedb plugin on vector-only retrieval, while the exact implementation attempt at https://github.com/openclaw/openclaw/pull/7636 is closed unmerged and the open reranker work at https://github.com/openclaw/openclaw/pull/92725 explicitly targets memory-core, not LanceDB.

## What This Changes

Requests BM25 plus vector hybrid retrieval in the official memory-lancedb plugin, including FTS indexing, hybrid config, and query-text search.

## Best Possible Solution

If maintainers choose official parity, implement hybrid retrieval inside memory-lancedb with explicit config/defaults, FTS index lifecycle, query propagation, vector fallback, docs, and regression tests; otherwise document vector-only behavior and route advanced retrieval to external plugins.
