## Summary

Keep open: current main and the latest release still leave the official memory-lancedb plugin on vector-only recall, while the exact implementation PR was closed unmerged and adjacent memory-core/reranker work does not cover LanceDB parity.

## What This Changes

The issue requests BM25 plus vector hybrid retrieval for the official memory-lancedb plugin, with FTS indexing, query-text propagation, and optional weighting config.

## Best Possible Solution

If maintainers want official parity, implement hybrid retrieval inside memory-lancedb with explicit config/defaults, FTS index lifecycle, query propagation, vector fallback, docs, and regression tests; otherwise document vector-only behavior and route advanced retrieval to external plugins.
