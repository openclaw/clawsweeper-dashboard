## What This Changes

The issue requests adding BM25/full-text hybrid search to the memory-lancedb plugin so exact keyword matches participate alongside vector similarity.

## Best Possible Solution

Keep this as the canonical memory-lancedb parity request, then implement hybrid retrieval in the plugin after maintainers choose the config/default, FTS index lifecycle, scoring, and fallback contract.

## Reproduction Assessment

Yes, at source level: configure memory-lancedb and use memory_recall, memory_forget by query, ltm search, or auto-recall; current main embeds the query and calls LanceDB vectorSearch without BM25/FTS. This is a missing parity feature rather than a broken existing contract.
