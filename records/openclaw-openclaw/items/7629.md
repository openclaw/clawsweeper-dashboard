## Summary

Keep open: current main and v2026.6.11 still provide vector-only retrieval in the official `memory-lancedb` plugin. A maintained community implementation exists, but recent issue-specific discussion retains official parity as a valid path, so maintainers must choose the plugin’s product direction rather than closing this as already implemented or superseded.

## What This Changes

Add BM25 plus vector hybrid retrieval to the official `memory-lancedb` plugin, including FTS indexing and optional ranking configuration.

## Best Possible Solution

If maintainers sponsor official parity, add an opt-in TypeScript-native hybrid mode inside `extensions/memory-lancedb`, create and verify an FTS index on `text`, propagate normalized query text through every retrieval path, calibrate hybrid scores separately from vector thresholds, preserve vector-only operation on unsupported or failed FTS setups, and prove fresh-table plus existing-table behavior against real LanceDB.
