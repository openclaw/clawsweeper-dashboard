## What This Changes

The issue requests hybrid BM25 plus vector retrieval for the official memory-lancedb plugin, including FTS indexing, hybrid config, and query-text propagation.

## Best Possible Solution

Implement plugin-owned hybrid retrieval after maintainers choose the config/default, FTS index lifecycle, scoring, and fallback contract, with docs and targeted tests for query-text propagation and vector-only fallback.
