## Summary

This PR still drops a complete surrogate pair at a split boundary: both new boundary adjustments move inward, so adjacent Markdown chunks can omit an emoji or supplementary-plane character rather than merely avoid producing orphaned UTF-16 code units.

## What This Changes

The branch replaces raw Markdown IR slice offsets with UTF-16-surrogate-aware offsets and applies them consistently to text, style, link, and annotation spans.

## Best Possible Solution

Choose and document one ownership rule for a split surrogate pair so it is retained by exactly one adjacent slice, apply that rule consistently to every span type, and demonstrate the corrected behavior with a focused regression test plus redacted real runtime output.
