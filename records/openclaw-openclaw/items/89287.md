## Summary

Keep this PR open for maintainer review: the target-aware evidence design is coherent and proof-positive, but the compatibility contract for incomplete route evidence still needs an explicit owner decision before it changes completion-delivery accounting.

## What This Changes

The branch records per-payload outbound targets and requires ACP/subagent completion evidence to match the requester provider, account, destination, and thread before it counts as visible delivery.

## Best Possible Solution

Define and document the canonical completion-evidence rule—exact provider/destination/thread plus strict account matching for threaded routes, with any non-threaded omission compatibility explicitly retained—then rebase and prove the selected rule against the merge result.
