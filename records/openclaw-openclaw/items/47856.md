## Summary

Keep open: current main and v2026.6.11 still do not expose a configurable image/media local-root allowlist. The narrower iMessage attachment-root case is now handled through scoped inbound roots, but the requested operator-controlled host-root policy remains a security-sensitive product/config decision with an open broader candidate PR.

## What This Changes

The issue requests a `tools.image.mediaLocalRoots`-style config field so image/media tools can read operator-approved local attachment directories outside the default roots.

## Best Possible Solution

Choose one canonical operator-controlled filesystem/media-root policy, keep scoped channel inbound roots separate from broad host-local reads, and wire the accepted policy through schema, docs, shared media loaders, and focused security tests.
