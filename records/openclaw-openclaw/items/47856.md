## Summary

Keep open: current main has a narrow iMessage attachment-root fix, but it still does not expose a public configurable image/media local-root allowlist. The remaining request is a security-sensitive host filesystem access decision and overlaps the open broader filesystem-roots PR.

## What This Changes

The issue requests a configurable allowlist for image-tool local media roots so channel attachments outside OpenClaw-managed directories can be read without manual copying.

## Best Possible Solution

Choose one security-reviewed explicit root policy for media and host filesystem access, then align the schema, types, docs, doctor/upgrade expectations, and focused media-tool tests around that policy.
