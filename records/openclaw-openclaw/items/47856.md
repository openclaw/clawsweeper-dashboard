## Summary

Keep open: current main partially addresses scoped iMessage inbound attachment roots, but it still does not expose a public configurable image/media local-root allowlist. The remaining request is a security-sensitive host filesystem access policy decision, with a broader open implementation candidate still unmerged.

## What This Changes

The issue requests an operator-configurable allowlist for image-tool local media roots so iMessage and similar attachment paths can be read without copying them into the workspace.

## Best Possible Solution

Choose one security-reviewed explicit root policy for media and host filesystem access, then align schema, types, docs, doctor/upgrade expectations, and focused media-tool tests around that policy.
