## What This Changes

The issue requests fixes for incorrect session grouping, an empty Workboard, and a nonfunctional session-agent filter after `2026.7.2-beta.3`, plus more distinct or configurable dashboard typography.

## System Context

The Control UI reads session records from Gateway RPC and renders those records into the Sessions view. Workboard is a bundled plugin with its own SQLite-backed card state; the dashboard reloads its canonical card data through Workboard read RPC after plugin invalidations.
