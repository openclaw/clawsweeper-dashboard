## Summary

The reported ordering defect appears actionable on current main: the node-list contract carries `lastSeenAtMs`, while the reported default-node comparator only ranks `connectedAtMs` before falling back to opaque IDs. This is a narrow core bug rather than the per-sender exec-routing request or the separate node-activity work mentioned in the report.

## What This Changes

Rank implicit canvas targets by meaningful node recency when all eligible paired nodes are disconnected instead of using lexicographic node ID order.

## Best Possible Solution

Update the shared implicit-node ranking to prefer the most recent valid `lastSeenAtMs` after connected-node precedence, retain a deterministic ID fallback only for equal or absent recency, and add regression coverage for disconnected canvas-capable nodes.
