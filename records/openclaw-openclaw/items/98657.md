- **[P1] Do not skip `--` after the flock lock target:** `src/infra/dispatch-wrapper-resolution.ts:287-290`
  - body: util-linux `flock` parses options only before the first non-option and executes `argv[optind + 1]`. For `flock /tmp/lock -- bash`, that executable is literally `--`, so skipping it makes approval analysis claim `bash` ran when the real command fails before reaching it. Keep this form blocked. citeturn980575view0.
  - confidence: 0.99
- **[P1] Keep BSD `script --` in transcript-file form:** `src/infra/dispatch-wrapper-resolution.ts:356-358`
  - body: `unwrapScriptInvocation` is gated to Darwin and FreeBSD, whose grammar is `[file [command ...]]`. In `script -- echo hello`, `echo` is the transcript file and `hello` is executed; this branch instead returns `echo`, which can bind approval state to the wrong executable. Preserve the positional behavior or add a separate Linux-only parser. citeturn474450view0turn102522view0.
  - confidence: 0.99
