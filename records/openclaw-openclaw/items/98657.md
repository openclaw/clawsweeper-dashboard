  - body: The new skip treats `flock /tmp/lock -- bash` as executing `bash`, but util-linux `flock` tries to execute `--` in that position; the supported separator belongs before the lock operand. This would bind approval analysis to a command the wrapper did not execute.

  - confidence: 0.92
