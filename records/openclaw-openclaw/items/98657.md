## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.99

Full review comments:

- **[P1] Do not skip `--` after the flock lock target:** `src/infra/dispatch-wrapper-resolution.ts:290-292`
  - body: util-linux stops option parsing before the lock target and passes `argv[optind + 1]` directly to `execvp`, so `flock /tmp/lock -- bash` attempts to execute `--`. Skipping that token makes approval analysis trust `bash` even though it is not the wrapper's executed target; keep this unsupported form fail-closed.
  - confidence: 0.99
- **[P1] Keep `script --` fail-closed across implementations:** `src/infra/dispatch-wrapper-resolution.ts:356-358`
  - body: This basename does not have one stable grammar: FreeBSD treats the first positional token as the transcript file, and util-linux 2.41 rejects extra positional arguments. Returning `echo` for `script -- echo hello` can therefore approve `echo` while another command runs or no command runs; require implementation-aware detection or keep the form blocked.
  - confidence: 0.98
