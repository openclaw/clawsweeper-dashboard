- **[P1] Keep flock separators before the lock target:** `src/infra/dispatch-wrapper-resolution.ts:288-290`
  - body: The patch skips `--` after the lock path and analyzes the following token as the wrapped command, but util-linux `flock lock -- sh` tries to execute `--`; the supported separator form is before the lock target. This would bind approval analysis to a command OpenClaw is not actually executing.
  - confidence: 0.93
- **[P1] Keep script `--` on the transcript-file contract:** `src/infra/dispatch-wrapper-resolution.ts:356-359`
  - body: This branch treats every token after `script --` as command payload, but BSD/macOS-style `script` uses `[file [command ...]]`, so the first positional token is still the transcript file. `script -- echo hello` would analyze `echo` as the executable even though it is the file operand.
  - confidence: 0.91
