## What This Changes

The issue requests a native Plugin SDK API for registering managed MCP servers that OpenClaw can lifecycle-manage and inject into embedded OpenAI-backed runs.

## Best Possible Solution

A maintainer-sponsored design should either add a narrow, additive, validated Plugin SDK MCP registration contract or explicitly keep dynamic MCP exposure on existing bundle/config paths until the security model is settled.
