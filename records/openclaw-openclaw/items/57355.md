The request remains a concrete Plugin SDK design item, not a stale support report or ClawHub-only plugin request, because existing bundle/config MCP paths do not provide native plugin lifecycle registration for dynamic managed MCP servers.

## Best Possible Solution

A maintainer-sponsored design should decide on a narrow, additive, validated Plugin SDK MCP registration contract, or explicitly keep dynamic MCP exposure outside core until the security model is settled.
