## Summary

Keep this PR open for the assigned Android/Wear review. The lifecycle ownership change is a narrow, plausible repair for a Talk client whose coroutine scope dies when an activity is closed, but the submitted evidence is unit-test and lint output rather than an after-fix Wear runtime session; real device or emulator proof of Talk starting again after exit and reopen is still needed before merge.

## What This Changes

Moves the Wear Talk realtime client from process-wide application ownership into each `WearViewModel` and adds a regression test that clears and recreates a ViewModel against one application instance.

## System Context

The Wear app creates a ViewModel for the Wear activity, which uses the shared gateway repository to run realtime Talk. The ViewModel-owned Talk client is created for an activity session and should be shut down when that session is cleared, so a reopened activity can create a live replacement.
