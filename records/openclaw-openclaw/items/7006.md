## Best Possible Solution

Define the selected-versus-resolved model and provider-cost metadata contract, capture OpenRouter response model and billed-cost details at the transport/plugin boundary, and thread them through agent metadata, session/status, transcripts, and reply usage rendering with explicit source labels.
