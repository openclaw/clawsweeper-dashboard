## Summary

Keep open: current main still uses the selected `openrouter/auto` identity and estimated or partially reconciled cost data, but it does not expose the resolved OpenRouter backend model plus provider-cost metadata through the runtime/session/footer contract requested here.

## What This Changes

Expose the OpenRouter auto routed backend model and provider-reported cost so agents and response footers can report the actual model and charge.

## Best Possible Solution

Define an additive metadata contract, capture `chunk.model` and OpenRouter cost metadata at the transport/provider boundary, and thread it through assistant records, session/status surfaces, usage templates, and footers with targeted tests.
