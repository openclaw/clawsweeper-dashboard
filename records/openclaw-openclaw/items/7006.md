## Summary

Keep open: current main has partial OpenRouter billed-cost reconciliation and generic usage plumbing, but it still does not expose the resolved `openrouter/auto` backend model or provider-cost metadata through the agent/runtime/session/footer contract requested here.

## What This Changes

Request to expose the actual OpenRouter-selected model and cost for `openrouter/auto` so agents and response footers can report the resolved model and usage cost.

## Best Possible Solution

Define an additive selected-versus-resolved model and provider-cost metadata contract, then capture OpenRouter response model/cost at the provider boundary and thread it through assistant records, session/status surfaces, usage templates, and response footers with targeted `openrouter/auto` coverage.
