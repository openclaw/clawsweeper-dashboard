## Summary

Keep open: current main still does not expose OpenRouter's resolved `openrouter/auto` model or provider-reported cost through the requested agent, session, or response-footer surfaces, and the related issues/closed PRs are overlapping prior art rather than a merged replacement.

## What This Changes

Expose the concrete OpenRouter backend model and provider-reported cost selected by `openrouter/auto` to agents, session metadata, and response footers.

## Best Possible Solution

Define an additive selected-versus-resolved model and provider-cost metadata contract, capture OpenRouter response model/cost at the OpenAI-compatible boundary, and thread it consistently through assistant records, session/status surfaces, usage templates, and response footers.
