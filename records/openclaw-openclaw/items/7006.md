## Summary

Current main partially advances the request by accepting provider-reported usage cost, but it still does not preserve OpenRouter’s routed model as distinct per-turn metadata or expose routed identity and exact cost through the requested agent, session, and footer surfaces. The related open issues divide cost reporting and generic resolved-model state, but neither alone owns this issue’s complete user-visible outcome, so closing it would lose acceptance criteria.

## What This Changes

Expose the concrete model selected by `openrouter/auto` and its provider-reported cost to the agent and response usage footer.

## Best Possible Solution

Add canonical per-call provider metadata that preserves requested model, resolved model, and provider-reported cost separately; define multi-call aggregation semantics, then use the same metadata in agent context, transcripts, session/status state, and response footers.
