## Summary

Keep open: current main has adjacent OpenRouter billed-cost reconciliation and some lower-level response-model plumbing, but it still does not expose the resolved `openrouter/auto` backend model and provider-cost semantics through the agent/session/footer contract requested here.

## What This Changes

Request that OpenRouter auto responses expose the actual routed model and cost so replies can show a resolved model label and cost instead of only the selected `openrouter/auto` placeholder.

## Best Possible Solution

Define an additive selected-versus-resolved model and provider-cost metadata contract, then thread it through transport, assistant records, session/status surfaces, usage templates, and response footers with OpenRouter auto coverage.
