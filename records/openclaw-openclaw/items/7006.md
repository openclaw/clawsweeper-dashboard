## Summary

Keep open: current main now captures provider-reported cost and defines a routed-model field, but it still does not propagate the concrete OpenRouter Auto model into runner/session metadata or render that model and authoritative cost in the standard response footer. The related open issues split the broader model and cost contracts rather than replacing this combined user-facing request.

## What This Changes

Expose the concrete model selected by OpenRouter Auto and its provider-reported usage cost to agent-visible response and session surfaces.

## Best Possible Solution

Define one additive generic per-turn contract carrying requested model, actual response model, and provider-billed cost with origin metadata; propagate it through runner, session, status, and hook surfaces, then render it through the existing usage template/footer path with OpenRouter Auto regression coverage.
