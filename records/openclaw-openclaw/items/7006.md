## Summary

Keep open: current main and the latest release have partial building blocks for this request, but they still do not expose the routed `openrouter/auto` model plus provider-reported cost through the agent-visible footer/session/runtime contract.

## What This Changes

The issue requests exposing the concrete OpenRouter model selected by `openrouter/auto` and its provider-reported usage cost to agents and response footers.

## Best Possible Solution

Define and implement one selected-versus-resolved model plus provider-cost metadata contract that feeds the existing usage-bar/footer, session/status, transcript, and agent runtime surfaces.

## Reproduction Assessment

Yes. Source inspection shows current main captures some response-model and billed-cost information internally, but the agent-visible usage and session metadata paths still use selected model identity and locally estimated cost; I did not run a live OpenRouter turn in this read-only review.

## Solution Assessment

Unclear until maintainers choose the metadata contract. The durable fix should preserve selected `openrouter/auto` while separately exposing the routed model and exact/provider-reported cost source.
