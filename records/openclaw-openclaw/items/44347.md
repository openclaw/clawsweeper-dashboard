## Summary

Keep open: current main and v2026.6.11 cover much of the Google Chat thread-reply plumbing, but optional all-message Space ingestion is still missing and needs a Google Chat OAuth or Workspace Events security/product decision.

## What This Changes

Requests Google Chat replies to stay in the originating thread and optionally receive non-mention messages in Spaces.

## Best Possible Solution

Keep the shipped thread-reply plumbing, then define a SecretRef-backed opt-in Google Chat user OAuth or Workspace Events/Pub/Sub contract before implementing all-message Space ingestion.
