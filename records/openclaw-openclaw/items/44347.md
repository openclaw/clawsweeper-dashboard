## Summary

Keep open: current main and v2026.6.11 cover the threaded-reply plumbing, but Google Chat still has no all-Space-message ingestion path beyond delivered webhook events, and that remaining request needs a maintainer security/product decision.

## What This Changes

Request Google Chat to reply inside incoming threads and optionally ingest all Space messages without requiring @mentions.

## Best Possible Solution

Keep the shipped thread-reply implementation and design a plugin-owned, opt-in Google Chat all-message ingestion mode with explicit OAuth or Workspace Events scopes, subscription lifecycle, consent, docs, tests, and live proof.
