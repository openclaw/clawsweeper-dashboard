## Summary

Keep open: current main covers the basic Google Chat threaded-reply plumbing, but the all-Space-message request still lacks an implementation and needs an explicit Google Chat OAuth or Workspace Events security decision.

## What This Changes

## Best Possible Solution

Keep the shipped thread-reply plumbing, resolve the narrow thread/session work separately, and define an explicit SecretRef-backed Google Chat user OAuth or Workspace Events contract before adding all-message Space ingestion.
