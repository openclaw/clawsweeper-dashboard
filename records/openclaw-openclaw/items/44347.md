## Summary

Keep open: current main and v2026.6.11 cover much of the Google Chat thread-reply plumbing, but the all-message Space ingestion request remains missing and needs maintainer-approved OAuth or Workspace Events security design.

## What This Changes

The issue asks Google Chat to keep bot replies in the originating thread and optionally receive non-mention messages from Spaces.

## Best Possible Solution

Keep the existing thread-reply plumbing, land or close the narrower thread/session PRs on their own merits, and define an explicit SecretRef-backed Google Chat user OAuth or Workspace Events contract before adding all-message Space ingestion.
