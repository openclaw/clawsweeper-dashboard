## Summary

Keep open: current main and v2026.6.11 cover thread-targeted Google Chat replies, but non-mention Space ingestion remains absent and needs maintainer-approved OAuth or Workspace Events design.

## What This Changes

Request Google Chat replies to stay in the triggering Space thread and optionally let the bot receive non-mention messages in Spaces.

## Best Possible Solution

Keep the service-account webhook model as-is until maintainers approve a plugin-owned OAuth or Workspace Events contract with SecretRef-backed credentials, explicit scopes, consent/admin docs, Space filtering, lifecycle ownership, tests, and live proof.
