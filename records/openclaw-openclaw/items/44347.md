## Summary

Keep open: current main and released builds cover the basic Google Chat thread-reply plumbing, but the all-message Space ingestion request is still missing and needs a security-sensitive Google Chat OAuth or Workspace Events product decision.

## What This Changes

The issue asks Google Chat to reply in the triggering thread and optionally ingest non-mention messages from Spaces.

## Best Possible Solution

Keep the shipped thread-reply path, review per-thread session behavior separately, and design a plugin-owned Google Chat OAuth or Workspace Events ingestion model with SecretRef/redaction, setup docs, and live Space proof before implementing all-message ingestion.
