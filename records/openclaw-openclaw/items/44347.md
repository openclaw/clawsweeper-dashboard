## What This Changes

## Best Possible Solution

Keep this as the combined Google Chat design issue: finish or supersede the narrow thread-routing work separately, then either approve a plugin-owned SecretRef-backed OAuth or Workspace Events ingestion design or explicitly decline all-message Space ingestion.
