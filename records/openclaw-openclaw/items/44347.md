## Summary

Keep open: current main and v2026.6.11 cover important Google Chat threaded-reply plumbing, but the requested all-message Space ingestion remains missing and requires a security-sensitive Google Chat OAuth or Workspace Events product decision.

## What This Changes

The issue requests Google Chat threaded outbound replies and optional ingestion of all Space messages rather than only messages that mention the bot.

## Best Possible Solution

Keep this open until maintainers decide the Google Chat all-message design, then implement it inside the Google Chat plugin with secret-aware OAuth or Workspace Events configuration, documented fallbacks, focused tests, and live Space proof; review thread-placement PRs separately for the threaded-reply subset.
