## Summary

Keep open: current main and v2026.6.11 cover the core Google Chat thread-reply plumbing, but the optional all-message Space ingestion request remains unimplemented and needs maintainer-approved Google Chat OAuth or Workspace Events security direction.

## What This Changes

The issue requests Google Chat replies in the originating thread and optional Space-wide message ingestion without requiring @mentions.

## Best Possible Solution

Keep the shipped thread-reply plumbing, handle narrower thread/session fixes separately, and define a SecretRef-backed Google Chat user OAuth or Workspace Events/Pub/Sub contract with scope, consent, setup docs, and live proof before adding all-message Space ingestion.
