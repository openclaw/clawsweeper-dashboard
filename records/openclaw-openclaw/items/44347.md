## Summary

Keep open: current main and v2026.6.11 cover part of Google Chat thread handling, but the requested all-message Space ingestion without @mentions is still missing and requires a maintainer security/product decision around Google Chat user OAuth or Workspace Events/Pub/Sub.

## What This Changes

## Best Possible Solution

Finish or supersede the narrow thread-reply PRs separately, then design a plugin-owned, SecretRef-backed Google Chat OAuth or Workspace Events ingestion path before implementing all-message Spaces.
