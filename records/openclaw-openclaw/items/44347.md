## Summary

Keep open: current main and the latest release cover the thread-reply plumbing, but Google Chat still has no implemented all-Space-message ingestion path beyond delivered webhook interactions, and that remaining request needs an explicit OAuth/subscription/security decision.

## What This Changes

The issue asks Google Chat to reply inside inbound Space threads and optionally receive all Space messages without requiring @mentions.

## Best Possible Solution

Keep the shipped thread-reply path, and design a plugin-owned, opt-in Google Chat all-message ingestion mode with explicit Workspace Events/user OAuth scope handling, security documentation, setup/doctor checks, tests, and live Google Chat proof.
