## Summary

Keep open: current main and v2026.6.11 cover important Google Chat thread-reply plumbing, but the requested all-message Space ingestion remains missing and depends on a security-sensitive Google Chat auth/events product decision.

## What This Changes

## Best Possible Solution

Split the outcome: finish or supersede the narrow Google Chat thread-reply/thread-session work, then make a maintainer-approved SecretRef-backed Google Chat user OAuth or Workspace Events design for opt-in all-message Space ingestion before implementation.
