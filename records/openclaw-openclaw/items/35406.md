## Summary

Keep open: current main and the latest release still let the `read` tool decode non-image PDF/Office bytes as text, and the open linked fork PR is conflicting rather than a merged canonical fix.

## What This Changes

Requests that `read` avoid raw binary output for PDF and Office documents by returning a safe fallback or extracting text.

## Best Possible Solution

Approve a narrow read-tool binary document fallback using shared MIME detection and route richer parsing or provider-native forwarding to the existing document-input design issues.
