## Summary

Keep open: current main and latest release still let non-image PDF/Office files fall through the read tool's text-decoding path, while the linked guard PR is open but conflicting and unmerged. Maintainers still need to choose the read-tool boundary before this can close.

## What This Changes

Request to make the agent read tool avoid returning raw binary-looking output for document formats such as PDF, DOCX, PPTX, and XLSX, either by warning or by extracting text.

## Best Possible Solution

Adopt or replace the linked guard PR with a narrow read-tool fallback that blocks raw PDF/Office bytes and points users to supported document tools, while tracking richer extraction/provider forwarding in the broader file-input issues.
