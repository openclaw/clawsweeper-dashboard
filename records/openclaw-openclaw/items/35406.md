## Summary

Keep open: current main and the latest release still route non-image reads through text decoding, while the linked closing PR is an open fork PR rather than a merged target-repo fix.

## What This Changes

The issue requests that `read` avoid returning garbled raw binary output for document formats such as DOCX, PDF, PPTX, and XLSX, either by warning or by extracting text.

## Best Possible Solution

Add a narrow bounded binary-document guard in the shared read path with a clear fallback message, while leaving richer Office extraction and provider-native file forwarding to the linked document/media design tracks.
