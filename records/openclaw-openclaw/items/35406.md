Keep open: current main and the latest listed releases still route non-image `read` inputs through text decoding, while the direct guard PRs are closed or conflicting and broader document-native work remains separate.

## What This Changes

Request that the `read` tool stop returning raw UTF-8-decoded binary document bytes for PDF/Office files, either by warning/fallback or extraction.

## Best Possible Solution

Adopt a maintainer-approved narrow binary-document fallback in the shared read path, and leave rich parsing/provider-native forwarding to the broader document work.
