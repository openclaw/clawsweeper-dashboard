## Summary

Keep this issue open: current main and the latest release still let the shared read tool treat non-image binary documents as text, while the open cross-repo closing PR and older same-repo PR attempts are not merged fixes.

## What This Changes

The issue requests a safe fallback or document parsing path so `read` does not return raw binary output for `.docx`, `.pdf`, `.pptx`, and `.xlsx` files.

## Best Possible Solution

Add bounded binary/document detection in the shared read path that returns a compact actionable fallback, and leave full parsing or provider-native document handling to dedicated document/media-input work.
