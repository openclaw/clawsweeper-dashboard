## Summary

Keep open: current main still sends non-image read targets through text decoding, the latest release has the same behavior, and the only open linked implementation candidate is a conflicting fork PR rather than a landed fix.

## What This Changes

Request the read tool stop returning raw decoded binary for PDF and Office-style documents, either by returning a safe fallback message or extracting document text.

## Best Possible Solution

Add a narrow read-tool safe fallback that detects common binary document MIME types before text decoding, points PDFs to the existing `pdf` tool, and leaves full Office parsing or provider-native file forwarding to the broader document-input tracks unless maintainers approve that larger scope.
