## Summary

Keep open: current main and the latest release still send non-image `read` targets through text decoding, and the open closing PR is the active candidate for the safe fallback while broader document/file issues cover different surfaces.

## What This Changes

The issue requests that the agent `read` tool stop returning raw binary-looking output for Office/PDF documents and either warn clearly or extract readable text.

## Best Possible Solution

Land or replace a narrow current-main `read` fallback that detects Office/PDF-style binary documents before text decoding, returns a clear unsupported-document message, and leaves full extraction to the dedicated PDF tool, document-extract plugin path, or broader file-input design.
