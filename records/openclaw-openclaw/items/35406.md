## Summary

Keep open: current main and the latest release still route non-image PDF/Office files through the text read path, and an open closing PR exists but is conflicting and outside the target repository.

## What This Changes

Request that the read tool avoid returning raw binary-looking content for PDF and Office formats by warning or extracting document text.

## Best Possible Solution

Approve a narrow read-tool fallback that detects PDF/Office documents before text decoding and returns a clear unsupported-document message, while leaving native parsing or provider-file forwarding to the broader document issues or ClawHub/MCP paths.
