## Summary

Keep open: current main still lets non-image document bytes fall through the read tool's text path, and an open linked PR is only a stale fork candidate rather than a landed fix.

## What This Changes

The issue requests that the read tool stop returning raw binary-looking content for document formats such as DOCX, PDF, PPTX, and XLSX, either by warning or extracting text.

## Best Possible Solution

Add a narrow read-tool guard for known binary document MIME/extensions that returns an actionable unsupported-document message, points PDFs at the existing pdf tool, and leaves native Office extraction/provider-native forwarding to the broader document-input issues.
