## Summary

Keep open: current main and v2026.6.11 still treat non-image files as text in the read path, so Office/PDF reads can still return decoded binary-looking content. The remaining choice is product scope: a narrow guard is straightforward, while automatic document parsing overlaps broader media/document work.

## What This Changes

Request to prevent the read tool from returning raw binary document data for .docx, .pdf, .pptx, and .xlsx by either returning a structured fallback message or extracting text.

## Best Possible Solution

Add a narrow current-main read-tool fallback for known binary document formats, then keep real extraction or provider-native document support in the broader media/plugin design threads.
