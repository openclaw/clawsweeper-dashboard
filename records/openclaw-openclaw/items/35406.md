## What This Changes

The issue asks OpenClaw to prevent the `read` tool from returning raw decoded content for binary document formats such as DOCX, PDF, PPTX, and XLSX, either by warning or by extracting text.

## Best Possible Solution

Keep the issue open until maintainers either land a narrow read-tool fallback for known binary documents or explicitly fold this into the broader document attachment/provider-input design.
