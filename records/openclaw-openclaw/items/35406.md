## Summary

Keep open: current main and the latest release still let the read tool decode any non-image file as text, and the only linked open implementation PR is a stale/conflicting fork PR rather than a merged target-repo fix.

## What This Changes

The issue asks for the read tool to stop returning raw binary document bytes for DOCX/PDF/PPTX/XLSX-style files, preferably by warning or by using document extraction.

## Best Possible Solution

Add a narrow binary-document guard to the read tool using shared MIME/extension detection and a clear fallback message, while leaving richer Office extraction, generic binary upload, and provider-native forwarding to their separate linked design tracks.
