## What This Changes

This PR records blocked tool-loop vetoes as typed no-progress outcomes so repeated blocked calls can reach the global circuit breaker, and it also updates test-project routing for isolated UI tests and a Codex extension test shard.

## System Context

The agent tool wrapper records each tool call and its outcome in diagnostic session state, then loop detection uses that history to block repeated no-progress calls. This change affects the escalation path from a local critical loop veto to the session-global circuit breaker, which determines whether an agent run stops promptly or continues until its turn timeout.
