## Summary

Current main directly fixes the reported refresh-time login flash: stored token, password, or eligible device credentials now show a connecting splash until the initial connection succeeds or explicitly fails. The exact fix merged after the latest published releases, so it is implemented on main but not yet shipped.

## What This Changes

Prevent the Control UI from briefly showing the login gate during an authenticated page refresh while the initial Gateway connection is pending.

## Best Possible Solution

Keep the credential-aware connecting splash as the canonical initial-auth state, with the login gate reserved for missing or rejected credentials.

## Solution Assessment
