## Summary

Keep open: current main still lacks Android reasoning gating, but this PR is not merge-ready because it misclassifies optional reasoning metadata and can flush queued sends before model metadata is reloaded; it also has only test/CI proof and a current Android CI failure.

## Best Possible Solution

Keep the Android reasoning gate, but gate only explicit unsupported metadata, make active-session reconnect outbox flush wait for or retain current model metadata, add focused regressions for both cases, and include redacted Android device or emulator proof.
