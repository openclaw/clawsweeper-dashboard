## Summary

Keep open: this is a narrow availability fix for a remaining MCP stderr logging stream crash path. Current main already guards the child stderr source stream, but `attachStderrLogging()` still subscribes to the exposed stderr stream without an `error` listener, and the PR adds focused coverage plus real terminal proof for that path.

## What This Changes

Adds a stderr `error` listener in MCP transport stderr logging and a regression test that emits a mocked stdio stderr stream error.

## Best Possible Solution

Land the narrow logging-stream handler with the focused regression test after exact-head CI, keeping child stderr source handling in the stdio transport and consumer logging handling in `mcp-transport`.
