## Summary

Keep open: the reported defect and supplied runtime proof are convincing, but the current patch introduces a blocking compatibility regression by normalizing scores for every hybrid candidate, including ordinary non-media results under existing custom weight configurations.

## What This Changes

The PR makes hybrid fusion modality-aware for vector-only image/audio candidates, wires MemoryIndexManager to multimodal path classification, and adds regression coverage.

## Best Possible Solution

Collapse the content score to the vector signal only when the candidate is classified non-text media, has a vector result, has no keyword result, and vector weight is positive; otherwise retain the established unnormalized weighted formula exactly.
