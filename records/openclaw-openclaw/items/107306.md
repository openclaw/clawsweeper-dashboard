## Summary

The defect is real, but this branch uses runtime-state availability as a proxy for plugin registration mode. OpenClaw’s documented contract makes `api.registrationMode` the authoritative boundary, so the branch should remain open for correction; the competing PR is not yet a safe superseding target because it also lacks positive real-behavior proof.

## What This Changes

Adds an early Codex registration guard that registers only CLI metadata when `runtime.state.openSyncKeyedStore` is unavailable, plus a regression test for an empty runtime object.

## Best Possible Solution

Register the lightweight CLI descriptors first, then return for every non-`full` registration mode so binding-store, harness, provider, tool, command, and event setup runs only during full activation.
