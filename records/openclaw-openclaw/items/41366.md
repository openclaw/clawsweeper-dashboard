## Summary

Keep open: current main still has memory dreaming/promotion and channel mention gates, but it does not implement the requested governed durable natural-language rule layer or a settled all-explicitly-mentioned-bots reply contract. The Feishu self-mention/message-loss subset is tracked more narrowly in https://github.com/openclaw/openclaw/issues/72504 and the broader Feishu bot-to-bot candidate is https://github.com/openclaw/openclaw/pull/89783.

## What This Changes

The issue requests a durable natural-language rule promotion layer plus explicit group-chat semantics where every directly mentioned bot replies and unmentioned bots stay silent.

## Best Possible Solution

Define a maintainer-approved memory/rule governance contract and explicit channel mention policy, while keeping the Feishu self-mention loss on https://github.com/openclaw/openclaw/issues/72504 or its eventual merged fix path.
