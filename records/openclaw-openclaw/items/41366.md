## Summary

Keep open: current main now has useful pieces such as Skill Workshop durable-instruction suggestions, memory dreaming, memory-wiki, and Feishu mention gates, but it still does not define the requested first-class durable rule-governance layer, conflict precedence, or cross-channel contract that every explicitly mentioned bot replies once.

## What This Changes

The issue requests durable natural-language rule promotion with conflict handling, plus explicit multi-bot mention semantics where all mentioned bots reply and unmentioned bots stay quiet.

## Best Possible Solution

Keep this as a maintainer-sponsored design tracker for rule authority, durable storage, conflict precedence, and cross-channel mention semantics, while resolving Feishu parser and bot-to-bot delivery bugs through narrower Feishu trackers and candidate PRs.
