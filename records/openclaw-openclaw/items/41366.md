## Summary

Keep open: current main and the latest release still lack a governed durable conversational rule layer and a settled cross-channel contract that every explicitly mentioned bot replies once. The linked open Feishu work and the posted listen-only plugin context help with narrower failure modes, but they do not cover the broader memory authority and multi-agent semantics requested here.

## What This Changes

The issue requests durable promotion of conversational rules into a governed long-term rule layer plus explicit multi-mention reply semantics for group chats.

## Best Possible Solution

Keep the issue open for a maintainer-approved design that defines rule authority, durable storage/promotion, conflict precedence, and channel mention semantics, while letting narrower Feishu parser and bot-to-bot fixes proceed through their own linked work.
