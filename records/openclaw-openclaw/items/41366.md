## Summary

Keep open: current main still has memory promotion and channel mention gates, but not the requested governed durable natural-language rule layer or a settled all-explicitly-mentioned-bots reply contract. The linked `openclaw-listen-only` approach is useful prompt-level mitigation for context vs. interaction, but it explicitly does not solve durable rule learning, and the narrower Feishu message-loss subset remains tracked in https://github.com/openclaw/openclaw/issues/72504.

## What This Changes

Request durable natural-language rule learning with explicit conflict precedence plus group-chat semantics where every explicitly mentioned bot replies once and unmentioned bots stay silent.

## Best Possible Solution

Define a maintainer-approved rule-governance contract and explicit channel mention policy, while keeping Feishu-specific message-loss fixes in the narrower Feishu trackers.
