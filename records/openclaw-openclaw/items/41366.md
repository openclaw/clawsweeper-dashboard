## Summary

Keep open: current main has memory, Dreaming, and per-channel mention gates, but it still lacks a governed durable conversational rule layer with conflict precedence and a settled cross-channel explicit multi-mention reply contract. The Feishu message-loss slice is real and separately tracked, but it does not cover the broader memory-authority/product request here.

## What This Changes

Request a durable natural-language rule-learning path with explicit conflict precedence plus group-chat semantics where every explicitly mentioned bot replies once and unmentioned bots stay silent.

## Best Possible Solution

Define a narrow durable-rule authority and conflict model, or explicitly route it to memory/plugin surfaces, while leaving the Feishu mention-loss bug to the narrower canonical issue.
