## Summary

Keep open: current main and v2026.6.11 have MEMORY.md guidance, dreaming promotion, and Feishu mention gates, but they still do not implement a governed durable natural-language rule layer or a settled cross-channel rule that every explicitly mentioned bot replies once.

## What This Changes

The issue requests durable natural-language rule learning with explicit conflict precedence, plus group-chat semantics where all explicitly mentioned bots reply and unmentioned bots stay silent.

## Best Possible Solution

Keep this as a maintainer-sponsored design tracker for rule authority, durable storage, conflict precedence, and cross-channel mention semantics, while resolving Feishu-specific message-loss subsets through their narrower trackers and candidate PRs.
