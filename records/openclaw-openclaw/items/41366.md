## Summary

Keep open: current main and v2026.6.11 still have durable memory promotion and Feishu mention gates, but they do not implement the requested governed natural-language rule layer, conflict precedence, or settled contract that every explicitly mentioned bot replies once while unmentioned bots stay silent.

## Best Possible Solution
