## Summary

Keep open: current main and v2026.6.11 still have memory promotion, MEMORY.md guidance, Feishu mention gates, and narrower Feishu mention-delivery trackers, but they do not implement the requested governed durable rule layer or a settled cross-channel contract that every explicitly mentioned bot replies once.

## What This Changes

The issue requests durable promotion of conversational rules into governed long-term behavior plus explicit group-chat semantics where every mentioned bot replies once and unmentioned bots stay silent.

## Best Possible Solution

Keep this as a maintainer-sponsored design tracker until OpenClaw defines one rule-authority model, one durable promotion/review path, and one channel reply contract; resolve Feishu parser and bot-to-bot delivery bugs through the narrower Feishu items.
