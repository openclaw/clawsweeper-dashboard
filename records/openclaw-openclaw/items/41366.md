## Summary

Keep open: current main and the latest release have memory dreaming, MEMORY.md guidance, and mention gates, but they still do not implement the requested governed durable natural-language rule layer or a settled cross-channel contract that every explicitly mentioned bot must reply once. The Feishu self-mention/message-loss subset remains narrower work tracked by https://github.com/openclaw/openclaw/issues/72504, and https://github.com/openclaw/openclaw/pull/89783 is a partial Feishu candidate rather than a merged replacement for this broader product issue.

## What This Changes

The issue requests a durable natural-language rule layer with conflict precedence plus explicit multi-bot mention semantics where every mentioned bot replies and unmentioned bots stay silent.

## Best Possible Solution

Keep this as a maintainer-sponsored design tracker for rule authority, durable storage, conflict precedence, and cross-channel mention semantics, while resolving the Feishu parser and bot-to-bot delivery subset through the narrower Feishu tracker and candidate PR.
