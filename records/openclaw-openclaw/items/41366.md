## Summary

Keep open: current main and the latest release have memory dreaming, MEMORY.md prompt guidance, and channel mention gates, but they still do not implement a governed durable natural-language rule layer or a settled contract that every explicitly mentioned bot replies once.

## What This Changes

The issue requests durable promotion and conflict handling for conversationally taught rules, plus explicit group-chat semantics where all mentioned bots reply and unmentioned bots stay silent.

## Best Possible Solution

Define a maintainer-approved memory/rule governance contract and explicit channel mention policy, while handling the Feishu self-mention parser subset through https://github.com/openclaw/openclaw/issues/72504 or its eventual merged fix.
