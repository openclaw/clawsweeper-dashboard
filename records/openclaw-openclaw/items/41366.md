## Summary

Keep open: current main has memory flush/dreaming and Feishu mention-gating pieces, but it still lacks a maintainer-approved durable conversational rule authority with explicit precedence, and the multi-mention behavior is only partially covered by narrower open Feishu items rather than a settled product contract.

## What This Changes

The issue requests durable natural-language rule promotion with conflict handling plus explicit multi-bot mention semantics where every mentioned bot replies once and unmentioned bots stay silent.

## Best Possible Solution

Define a maintainer-approved rule authority and promotion model through the memory/plugin boundary, keep AGENTS.md and SOUL.md precedence explicit, and let the narrower Feishu mention bugs progress through https://github.com/openclaw/openclaw/issues/72504 and https://github.com/openclaw/openclaw/issues/40768.
