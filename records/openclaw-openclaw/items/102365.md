## Summary

Keep open: current main still hardcodes publishable plugin runtime output metadata to `.js` and calls `tsdown` without a CJS format option. The issue also has the protected `maintainer` label and an open closing PR, so it should stay open while https://github.com/openclaw/openclaw/pull/102366 is reviewed.

## What This Changes

The issue requests an opt-in way for publishable plugin runtime builds, especially msteams, to emit native `.cjs` runtime/setup entrypoints and matching package metadata.

## Best Possible Solution

Use the linked PR as the candidate fix: keep ESM as the default, add a narrowly documented CJS runtime-build opt-in for publishable packages that need it, prove msteams emits matching `.cjs` files and metadata, then close this issue after the PR lands.
