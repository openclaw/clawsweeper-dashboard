## Summary

Keep this PR open for a focused repair: local node commands receive the abort signal, but the Mac app execution-host route only suppresses its completion after the host call returns and does not receive a cancellation channel. That leaves a command launched through that route running after a gateway cancellation or disconnect, which conflicts with the PR’s central cancellation guarantee.

## What This Changes

The PR threads cancellation through node command execution, normalizes worker request deadlines, makes shared LM Studio preload waits independently cancellable, and expands Ollama chat-model discovery beyond embedding-heavy catalogs.

## System Context

Gateway node invocations enter the node-host runtime, which tracks an invocation and dispatches system commands either to a local process-tree runner or to the Mac app execution host. The same PR also adjusts local-provider preload and model-discovery paths that determine whether LM Studio and Ollama requests can start and recover under stress.

## Best Possible Solution

Extend the Mac app execution-host boundary with a cancellable request or explicit host-side terminate operation, propagate the invocation cancellation through it, and add an end-to-end regression that proves the host-launched command tree exits after cancellation; retain the bounded Ollama probe policy only with an accepted latency budget.
