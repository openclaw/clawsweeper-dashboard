## Summary

This PR is still necessary and contains a substantial implementation, but it should not merge yet: the import path can reuse an existing managed profile despite promising a fresh destination, and the default-enabled agent-triggered credential transfer needs explicit maintainer security approval. The linked feature issue should remain open while this candidate PR is reviewed.

## What This Changes

The PR adds macOS Chrome-family system-profile cookie import to managed browser profiles through new CLI commands, an agent-tool action, host-local HTTP routes, config, docs, and focused tests.

## Best Possible Solution

Gate system-profile import behind an explicit user-visible authorization policy, require a newly created empty managed destination with rollback on failure, and preserve the host-local and domain-filter protections already added.
