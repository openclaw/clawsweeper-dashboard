## Summary

Keep open: this targets a real native hook relay pressure problem, but the patch is not merge-ready because it changes the default Linux hook command path to `systemd-run` without fail-safe viability checks or real scoped-relay proof.

## What This Changes

The branch wraps native hook relay commands in `systemd-run --user --scope` on Linux when a user runtime and `systemd-run` path are present, adds `OPENCLAW_SYSTEMD_RUN_PATH`, and adds a command-builder unit test.

## Best Possible Solution

Make any systemd scoping opt-in or viability-checked and fail-safe, preserve hook stdin/stdout behavior, and keep the canonical relay fan-out decision tied to https://github.com/openclaw/openclaw/issues/91009 and its stronger open fix candidates.
