## Summary

The review found a blocking upgrade regression: a stable app can continue using the managed Git-main CLI because the new policy still relies on the existing same-major, not-older SemVer check. The channel-selection direction is reasonable, but stable builds need install-method-aware validation and real macOS proof before merge.

## Best Possible Solution

Persist or inspect the managed install method and target, then make stable builds reject Git-managed wrappers regardless of reported SemVer, with regression coverage and real macOS proof for Dev installation followed by exact stable restoration.
