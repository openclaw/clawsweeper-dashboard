## Summary

Keep this PR open, but do not merge the reviewed head: current main does not contain the fix, the producer-owned progress intent is the right direction, and a native-block delivery branch currently bypasses that generic intent. ## What This Changes

Adds a generic tool-progress reply-payload marker from Codex and changes Slack to convert marked transient progress into a thread reaction or suppressed delivery without consuming normal reply state.

## Best Possible Solution

Make typed progress authoritative before Slack text, native-block, or media rendering so suppressed payloads never post or mutate delivery state, then provide redacted exact-head live Slack proof that transient progress is suppressed or reacted while semantic, completed, failed, and verbose output still posts.
