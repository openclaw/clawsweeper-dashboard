## What This Changes

## Best Possible Solution

Detect typed progress once before Slack reply decomposition, convert it to a thread reaction when possible, otherwise return a suppressed receipt, and ensure no text, media, native-block, fallback, hook, thread-participation, or delivery-state path can treat it as a posted message.
