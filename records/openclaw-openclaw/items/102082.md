## Summary

This PR addresses a real Slack message-noise bug with the right producer-typed design, but the current head still drops that progress intent for native block segments, allowing those payloads to post and count as delivered. The branch should remain open for a narrow repair; earlier live proof covers direct text sends, not the defective structured path.

## Best Possible Solution
