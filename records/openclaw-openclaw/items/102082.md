## Summary

This PR addresses real Slack progress-chrome leakage and includes strong live proof, but the generic text classifier can silently suppress legitimate messages. The valuable suppressed-delivery bookkeeping should be retained while the classifier is replaced with explicit progress intent.

## What This Changes

The PR detects progress-like Slack text, converts thread-scoped matches to reactions or suppresses them, and propagates suppressed-send state through reply, hook, stream, and thread bookkeeping.

## Best Possible Solution

Carry an explicit typed progress-only disposition from the producer or dispatch owner into Slack, preserve the branch’s suppressed-delivery bookkeeping, and never infer delivery semantics from arbitrary outbound text.
