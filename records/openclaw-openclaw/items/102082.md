## Summary

The exact current head still has the previously reported native-block bypass: Slack only applies the authoritative progress-chrome gate when no blocks or media are present, so a marked structured payload can continue into ordinary message posting. Producer-side typing is directionally sound, but the consumer must enforce it across every payload representation before merge.
