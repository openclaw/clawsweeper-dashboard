## Summary

The central Slack noise fix is incomplete: producer-typed progress still posts normally whenever Slack cannot infer a reaction from the rendered text, and the exact-head live proof covers only mapped examples.

## What This Changes

## Best Possible Solution

Keep the single generic producer-owned progress marker, make marked Slack progress unconditionally non-posting, and use text classification only to choose an optional reaction while preserving every unmarked terminal, failed, verbose, and semantic reply.
