## Summary

The typed producer signal is a sound direction, but the prior P1 blocker remains: structured Slack block sends drop progress intent, bypass suppression, and are counted as delivered. The latest live proof also predates substantial rebases and does not cover that path.

## What This Changes

The PR adds generic tool-progress metadata to reply payloads, marks transient Codex tool summaries, and makes Slack convert or suppress those payloads without consuming normal delivery state.

## Best Possible Solution

Use one producer-owned, closed progress intent, carry it through every Slack text and structured-block rendering path, suppress or react before any platform post, and represent suppression so hooks and delivery state cannot mistake it for a sent message.
