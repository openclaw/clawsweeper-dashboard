## Summary

Keep open: current main and v2026.6.11 mitigate the `skillsSnapshot.prompt` half with prompt blobs, but `systemPromptReport` is still built and persisted per session entry, matching the latest field data that prompt-report duplication is now the dominant retained payload.

## What This Changes

The issue asks OpenClaw to stop unbounded session-store growth from repeated `skillsSnapshot` and `systemPromptReport` metadata in `sessions.json`.

## Best Possible Solution

Keep this focused tracker open until maintainers choose and implement a compact session-store policy that preserves warning-dedupe state without duplicating full `systemPromptReport` payloads across retained session rows.
