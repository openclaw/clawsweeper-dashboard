## Summary

Keep open: current main mitigates the `skillsSnapshot.prompt` half with prompt blobs, but still persists full `systemPromptReport` payloads per session row; recent production data says that report is now the dominant duplicated session-store payload.

## What This Changes

The issue reports unbounded per-session persistence of `skillsSnapshot` and `systemPromptReport` data in `sessions.json`, causing session-store growth and runtime stalls.

## Best Possible Solution

Keep this focused tracker open until maintainers implement a compact session-store policy that preserves warning-dedupe state without duplicating full prompt-report tools, skills, and workspace-file payloads across retained rows.
