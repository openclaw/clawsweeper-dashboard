## Summary

Keep open: current main and v2026.6.11 have mitigated large `skillsSnapshot.prompt` duplication with prompt blobs, but `systemPromptReport` is still persisted inline per session entry and the latest field data says that is now the dominant duplicated payload.

## What This Changes

The issue requests preventing `sessions.json` bloat from repeated `skillsSnapshot` and `systemPromptReport` persistence across agent runs.

## Best Possible Solution

Keep the issue open until OpenClaw has a durable `systemPromptReport` policy that prevents duplicated large prompt-report payloads in retained session rows while preserving required warning-dedupe and diagnostic behavior.

## Maintainer Decision

Required: true

Kind: product_direction

Question: What durable storage policy should OpenClaw use for `systemPromptReport` in retained session entries?

Rationale: The remaining code change is not just a guard: maintainers need to choose whether prompt reports stay inline, move out of line, are truncated, or are retained only for active sessions because that affects diagnostics and warning-dedupe behavior.

Likely owner: steipete

Owner reason: This is the strongest current routing signal for both the original prompt-report feature and the later prompt-blob storage mitigation.

Owner confidence: high

Options:

- **Out-of-Line or Compact Retention (recommended):** Store only the small dedupe/diagnostic subset inline and move, truncate, or drop the large repeated report payload for stale rows.
- **Keep Full Inline Reports:** Preserve current diagnostics exactly and accept continued `sessions.json` bloat until a broader session-store redesign lands.
- **Drop Reports After Each Run:** Remove prompt reports aggressively from persisted rows, reducing bloat but risking lost warning-dedupe and diagnostic context.

Yes at source level: current main still copies `systemPromptReport` into each durable session row when run metadata supplies it. I did not run a live long-duration gateway reproduction in this read-only review.

## Solution Assessment

No complete fix is on main: prompt blobs address the largest `skillsSnapshot.prompt` duplication path, but the remaining prompt-report persistence policy still needs a bounded design.
