## Summary

Keep open: current main and v2026.6.11 mitigate the skillsSnapshot prompt duplication with promptRef blobs, but systemPromptReport is still persisted inline per session entry and the latest production data says that is now the dominant sessions.json bloat source.

## What This Changes

The issue reports unbounded sessions.json growth from repeated skillsSnapshot and systemPromptReport session metadata across agent runs.

## Best Possible Solution

Persist only compact durable warning/report state or refs, keep diagnostics available through active or recomputed reports, and revise or replace the linked PR so inactive session entries no longer duplicate full systemPromptReport payloads.
