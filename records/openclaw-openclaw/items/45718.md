## Summary

Keep open: current main has reduced the `skillsSnapshot.prompt` duplication with prompt blobs, but it still builds and persists `systemPromptReport` in each session entry, and the linked open cross-repo PR intentionally preserves that field.

## What This Changes

The issue asks OpenClaw to stop unbounded `sessions.json` growth caused by repeated `skillsSnapshot` and `systemPromptReport` metadata persistence across agent runs.

## Best Possible Solution

Define the minimal load-bearing prompt-report state that must remain durable, then strip, dedupe, or move the bulky recomputable `systemPromptReport` payload out of per-session `sessions.json` entries while keeping current prompt-blob behavior.
