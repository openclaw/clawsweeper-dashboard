## Summary

Keep open: current main dedupes large `skillsSnapshot.prompt` payloads with prompt blobs, but it still persists `systemPromptReport` per session entry and recent v2026.6.10 production data shows that payload now dominates `sessions.json`.

## What This Changes

The issue asks OpenClaw to stop `sessions.json` from growing by accumulating `skillsSnapshot` and `systemPromptReport` metadata on retained session rows.

## Best Possible Solution

Keep this focused tracker open until maintainers choose and implement a session-store metadata policy that preserves needed warning-dedupe state without duplicating full `systemPromptReport` payloads across retained rows.

## Reproduction Assessment

Yes for source reproduction: current main still stores `systemPromptReport` on durable session entries from agent-command, cron, and auto-reply paths, but no live long-running Gateway soak was run in this read-only review.

## Solution Assessment

No: current main is only a partial solution because prompt blobs address `skillsSnapshot.prompt`, while `systemPromptReport` remains durable per session row and the open linked PR preserves that payload.
