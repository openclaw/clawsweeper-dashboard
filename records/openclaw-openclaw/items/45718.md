## Summary

Keep open: current main has reduced the `skillsSnapshot.prompt` part with content-addressed prompt blobs, but it still deliberately persists the full `systemPromptReport` on session entries, so the central session-store bloat report is only partially addressed.

## What This Changes

The issue asks OpenClaw to stop repeatedly persisting bulky `skillsSnapshot` and `systemPromptReport` metadata into `sessions.json` across agent runs.

## Best Possible Solution

Keep the skill-prompt blob mitigation, then split or compact `systemPromptReport` so only the small durable warning-dedupe state stays in the session index while bulky prompt/tool report data is omitted, summarized, or moved behind an explicit maintenance-owned storage path.
