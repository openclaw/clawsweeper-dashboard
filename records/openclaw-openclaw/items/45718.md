## Summary

Keep open: current main now externalizes large `skillsSnapshot.prompt` values into prompt blobs, but `systemPromptReport` is still persisted into durable session rows and recent v2026.6.10 field data says that report payload is now the dominant `sessions.json` bloat.

## What This Changes

The issue asks OpenClaw to stop accumulating duplicate `skillsSnapshot` and `systemPromptReport` metadata in `sessions.json` across agent runs.

## Best Possible Solution

Keep this focused tracker open until maintainers choose and implement a durable session-metadata policy that preserves needed warning-dedupe state without duplicating full `systemPromptReport` payloads across retained rows.

## Reproduction Assessment

Yes; source inspection shows current main still persists `systemPromptReport` into durable session entries from multiple run paths. I did not run a live long-running Gateway soak in this read-only review.

## Solution Assessment

No; current main is only a partial fix because prompt blobs address the `skillsSnapshot.prompt` side while `systemPromptReport` remains per-row durable metadata. The safer path is a maintainer-approved report compaction or out-of-line policy with compatibility coverage.
