## Summary

Keep open: current main and v2026.6.11 mitigate the large `skillsSnapshot.prompt` duplication with prompt blobs, but they still persist full `systemPromptReport` payloads into durable session entries, matching the latest production evidence that this is now the dominant remaining `sessions.json` bloat.

## What This Changes

The issue asks OpenClaw to stop repeated per-run `skillsSnapshot` and `systemPromptReport` session-store bloat in `sessions.json`.

## Best Possible Solution

Land a maintainer-approved durable metadata policy that keeps session rows lightweight while preserving `/context` reporting and warning dedupe, likely by compacting inactive `systemPromptReport` data or moving large report payloads out of line.
