## Summary

Keep open: current main mitigates large `skillsSnapshot.prompt` duplication with prompt blobs, but `systemPromptReport` is still a durable per-session payload and recent production data says it is now the dominant retained bloat.

## What This Changes

The issue asks OpenClaw to stop `sessions.json` from accumulating repeated `skillsSnapshot` and `systemPromptReport` payloads across agent runs.

## Best Possible Solution

Keep this focused tracker open until maintainers implement a durable session metadata policy that preserves needed warning-dedupe state without duplicating full `systemPromptReport` payloads across retained rows.

## Reproduction Assessment

Yes for source reproduction: current main still has durable `systemPromptReport` on `SessionEntry`, and agent-command, auto-reply, and cron paths write report metadata back into session rows. I did not run a live long-running Gateway soak in this read-only review.

## Solution Assessment

No: current main is only a partial solution because prompt blobs address the `skillsSnapshot.prompt` subset, while full `systemPromptReport` payloads remain durable per retained session row. The maintainable fix needs a maintainer-approved compaction, reference, or reduced-report policy that preserves warning dedupe.
