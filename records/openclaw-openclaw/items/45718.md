## Summary

Keep open: current main and v2026.6.11 externalize large skillsSnapshot.prompt payloads, but still persist full systemPromptReport inline in session entries, matching the latest production data that prompt reports are now the dominant sessions.json bloat source.

## What This Changes

The issue asks OpenClaw to stop duplicating skillsSnapshot and systemPromptReport payloads in persisted sessions.json entries across repeated runs.

## Best Possible Solution

Persist only compact durable warning/report state or content-addressed refs, keep diagnostics available through active or recomputed reports, and avoid duplicating full systemPromptReport payloads across inactive session entries.
