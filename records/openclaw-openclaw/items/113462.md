## What This Changes

This PR registers a Moonshot provider hook that rewrites eligible JSON Schema `anyOf` branches so Kimi receives a type declaration in each branch when OpenClaw registers MCP tools.

## System Context

MCP servers provide tool parameter schemas that OpenClaw materializes and registers with the embedded agent runner. The runner invokes the selected provider's schema hook before sending tool definitions to the Moonshot/Kimi completion endpoint, so this change affects only Moonshot-routed tool payloads.
