## What This Changes

The PR adds a 15-minute response-header deadline to image, image-generation, and PDF remote media loads, extends `WebMediaOptions` forwarding, and adds a root-level stalled-server proof script.

## Best Possible Solution

Use the canonical header-only deadline for every unbounded agent-tool remote-media caller, including video generation, preserve callers with explicit total-timeout contracts, add focused caller assertions, and keep PR-specific proof artifacts off the product branch.
