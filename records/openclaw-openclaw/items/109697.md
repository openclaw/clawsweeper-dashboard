## Summary

This PR addresses a valid current Tlon availability problem, but the newly added non-stream fallback still buffers the complete response and therefore leaves the reported resource-exhaustion path reachable; the branch should remain open for that bounded repair.

## What This Changes

The PR replaces Tlon Urbit login response buffering with a capped streaming drain and adds focused authentication drain tests.

## Best Possible Solution

Keep the streaming drain, remove the response.text() fallback, ensure the reader is cancelled through a finally-style cleanup path, and add coverage proving that a response without getReader() never invokes an unbounded body-reading method.
