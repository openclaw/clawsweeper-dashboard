## Summary

Keep open: current main still has no per-channel or per-spawn policy to suppress sub-agent completion announcements, while the implementation and related reports show this is an unresolved product/config decision rather than stale cleanup.

## What This Changes

Request a framework-level per-channel or per-spawn control that suppresses or reroutes sub-agent completion announcements away from selected chat channels.

## Best Possible Solution

Define one backward-compatible completion-delivery policy that defaults to current behavior and can mark selected channel or spawn completions as suppressed/internal before active wake, requester handoff, and direct fallback delivery paths.

## Reproduction Assessment

Yes for the missing capability. Source inspection on current main shows no per-channel sub-agent announce suppression config or public sessions_spawn parameter while top-level completion delivery still resolves an external requester target.

## Solution Assessment

Unclear as a final product shape. A channel key is plausible, but maintainers should choose one completion-delivery policy that composes with global suppression, parent routing, extension hooks, and fallback reliability.
