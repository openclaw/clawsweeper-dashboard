## Summary

Keep open: current main and v2026.6.11 still lack structural per-channel or per-spawn suppression for sub-agent completion announcements, and the related open items overlap without superseding this channel-specific config/API decision.

## What This Changes

Request per-channel control to suppress or reroute sub-agent completion announcements from channel-bound sessions so the main agent can decide what reaches chat.

## Best Possible Solution

Define one backward-compatible completion-delivery policy that defaults to current behavior and can mark selected channel or spawn completions as suppressed or internal-only before active wake, requester handoff, and direct fallback paths.
