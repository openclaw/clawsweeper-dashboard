## What This Changes

The branch makes Control UI workspace image previews fetch approved same-origin managed outgoing-media URLs with existing session credentials, render returned bytes as local data URLs, and keep denied previews contained instead of opening an unauthenticated protected URL.

## System Context

A generated image artifact enters the Control UI session workspace as a managed-media URL. The workspace classifies that URL, fetches it through the existing authenticated Gateway media route, and turns successful bytes into a local preview while showing contained recovery for denied or unavailable media.
