## Summary

This PR addresses a real Control UI workflow failure with focused UI, Gateway, config, and browser evidence, but it creates an explicit opt-in path that forwards an existing Control UI credential to managed-media HTTP. The remaining blocker is an owner decision that this credential-routing contract is intended; it should stay open for that review rather than be closed or auto-repaired.

## What This Changes

The branch adds a default-off Gateway setting that lets the Control UI fetch approved same-origin managed outgoing-image URLs with its existing credential and render the returned image bytes locally in the session workspace.

## System Context

A session workspace asks the Gateway for an artifact URL, then the Control UI decides whether it can safely preview that URL. This change carries an operator-controlled setting through the Gateway bootstrap response so the UI can authenticate only same-origin managed-media image requests while the existing Gateway authorization checks decide whether bytes are returned.
