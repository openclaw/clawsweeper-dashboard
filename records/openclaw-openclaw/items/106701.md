## What This Changes

The PR makes the Control UI workspace fetch protected generated-image media with its existing authentication path and render a local preview instead of opening an unauthorized managed-media URL.

## System Context

The Control UI workspace opens artifact records returned by the Gateway and chooses a sidebar representation for each file. Generated images can be backed by managed outgoing-media URLs, which require authentication headers that a normal browser navigation does not send.

## Best Possible Solution

Keep the Gateway as the authorization owner, use the established authenticated managed-media fetch only for validated managed image URLs, and retain the contained denied-state UI with focused allowed, denied, and cross-session coverage.
