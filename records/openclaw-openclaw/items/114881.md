## What This Changes

This PR changes the Signal inbound verbose-log preview to escape actual LF characters as literal `\n` text and adds a focused regression test for multiline inbound bodies.

## System Context

The Signal extension turns an inbound Signal envelope into an OpenClaw message context, then optionally emits a verbose diagnostic preview. This change affects only that diagnostic preview after the message body has been prepared; it does not alter delivery to the agent or Signal replies.
