## What This Changes

The issue reports that https://github.com/openclaw/openclaw/pull/100835 made the browser navigation guard's explicit hostname allowlist contract fail when a non-localhost allowed hostname resolves to loopback.

## Best Possible Solution

Have the browser/SSRF owner align code, tests, and docs around one explicit contract, preferably keeping the fail-closed loopback-rebinding hardening unless a scoped browser-navigation exception is deliberately approved.
