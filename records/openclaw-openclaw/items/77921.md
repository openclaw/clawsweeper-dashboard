## What This Changes

The PR changes the bundled Inworld TTS provider to default to `inworld-tts-2`, adds that model to the accepted model list, adds an `X-User-Agent` header to Inworld requests, and updates related tests, docs, generated config baselines, and `CHANGELOG.md`.

## Best Possible Solution

Add TTS-2 as a supported Inworld model, preserve the shipped default unless maintainers explicitly approve moving unpinned users to TTS-2, refresh the branch onto current main, keep current Inworld hardening and `speakerVoiceId` docs wording, and remove the changelog edit.

## Solution Assessment
