## What This Changes

Preserves a future one-shot cron occurrence when an operator manually runs it before its scheduled time, including when that manual request waits in the cron command lane.

## System Context

The cron service accepts manual and timer-triggered job runs, persists each job's scheduling state, and finalizes results through shared outcome handling. This change carries the time at which a manual run acquired schedule ownership so result handling can distinguish an out-of-band verification from the real future scheduled occurrence.
