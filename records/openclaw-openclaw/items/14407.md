## Summary

Keep open: current main still has only partial sensitive-field reveal support, with concrete gaps in web Skills and native credential-entry surfaces, and the requested persisted/cross-platform behavior needs maintainer product and security direction.

## What This Changes

## Best Possible Solution

Implement reusable masked-by-default reveal controls per UI stack, reuse existing Control UI reveal patterns where possible, and treat persisted visibility as a separate maintainer security/product decision.

## Reproduction Assessment

## Solution Assessment

No, not as a blanket persisted clear-text preference. The safer maintainable path is masked-by-default reveal controls with any persisted visibility behavior decided explicitly by maintainers.
