Keep open: current main still has only partial web reveal support, while web Skills plus native iOS, macOS, and Android credential-entry surfaces still lack a consistent reveal control; the linked implementation attempts are closed unmerged, and persistence of clear-text visibility needs maintainer security/product direction.
