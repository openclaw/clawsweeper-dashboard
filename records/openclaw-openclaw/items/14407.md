## Summary

Keep open: current main only partially covers web reveal controls, while web Skills, macOS, iOS, and Android credential-entry surfaces still lack a consistent show/hide pattern; the linked implementation attempts are closed unmerged.

## What This Changes

## Best Possible Solution

Implement reusable masked-by-default sensitive-input reveal controls across the affected web and native credential fields, and leave persistence out unless maintainers explicitly approve that exposure tradeoff.
