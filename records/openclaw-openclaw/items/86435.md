## Summary

Keep open: current main and v2026.6.11 still leave the broader partial-reload contract unresolved. ## What This Changes

The issue asks OpenClaw to prevent macOS launchd plugin/config maintenance from leaving Control UI and session RPCs in a misleading partial-reload state that may require `doctor --fix` recovery.

## Best Possible Solution

Define one Gateway partial-reload/readiness state that `sessions.resolve` and Control UI can consume, keep launchd restart recovery deterministic, and validate it with a live managed-macOS replay; treat the open WebChat notice PR as a narrower subset if maintainers accept it.
