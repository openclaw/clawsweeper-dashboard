## What This Changes

Maps raw and typed provider `invalid_request_error` values into the existing `format` failover lane, after more-specific classifiers, so configured model fallbacks can advance instead of retrying the same rejected request.

## System Context

Agent runs pass provider failures through a shared classifier before the model-fallback loop decides whether to retry, compact context, surface an error, or switch models. This PR changes the classifier so raw provider JSON can reach the existing fallback path without adding provider-specific recovery code.
