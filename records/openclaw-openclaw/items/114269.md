## What This Changes

Restore gateway recovery after a transient shared state-database corruption or read failure instead of reusing a poisoned SQLite connection until process restart while health reporting remains green.

## System Context

OpenClaw's gateway and channel workers use the shared SQLite state database for durable queues, approvals, audit events, and session-related state. State callers obtain a cached database handle; a corruption error must lead to safe reopen or a clear unavailable signal rather than repeated failures through the running gateway.
