## Summary

Keep open: current main still lacks a first-class Android Chat agent selector, but this branch is not merge-ready because it adds the selector to the legacy ChatSheet path while the active shell uses ChatScreen, and the selected agent can be overwritten by gateway refresh or reconnect.

## What This Changes

The PR adds Android gateway agent summaries to chat UI state and renders agent chips so Chat can target a selected gateway agent.

## Best Possible Solution

Port the selector onto current ChatScreen using the existing gateway agent state, preserve explicit selected-agent state across refresh/reconnect, add focused regression coverage, and then refresh real Android multi-agent proof before final UX acceptance.
