The patch is technically sound, but it intentionally changes how existing invalid environment settings fail, so it should remain open for a maintainer compatibility decision before merge.

## What This Changes

The PR trims Google Vertex project and location options plus their environment fallbacks, rejecting blank values early and adding regression coverage for blank and padded values.

## System Context

The Google Vertex provider resolves a project and location from explicit model options or Google Cloud environment variables before creating the Google SDK client. Those resolved values determine whether OpenClaw returns a clear configuration error or begins a Vertex request.
