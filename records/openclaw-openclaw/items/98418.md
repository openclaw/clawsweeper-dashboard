## Summary

This PR remains necessary because current main still uses the caller GUI domain and can bootstrap after a failed kickstart. The proposed probe-before-bootstrap fix is well supported, but merge should wait for maintainer agreement on the new launchd override contract and unloaded cross-user fallback semantics. ([github.com](https://github.com/openclaw/openclaw/blob/main/src/infra/restart.ts))

## What This Changes

The PR changes both macOS gateway restart surfaces to probe candidate launchd domains, kickstart an already-loaded LaunchAgent, bootstrap only when unloaded, and detect duplicate post-restart listeners. ([github.com](https://github.com/openclaw/openclaw/pull/98418))

## Best Possible Solution

Keep probe-before-bootstrap and loaded-domain kickstart behavior, but define a single caller-owned fallback for genuinely unloaded jobs and either remove the two new override inputs or explicitly document and test their supported operator contract.
