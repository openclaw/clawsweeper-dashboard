## Summary

Keep this PR open: the refreshed head has convincing live proof and resolves the earlier intermediate-log concern, but the prior missing-binary blocker remains because every status error is retried before candidate fallback.

## What This Changes

The PR adds up to three same-binary attempts with 500 ms delays for Tailscale status JSON during hostname discovery and adds focused transient-failure coverage.

## Best Possible Solution

Classify command failures before retrying: retry bounded transient daemon/status failures on the same binary, but immediately fall through for ENOENT and other clearly non-retryable failures, with tests for both paths.
