## Summary

Keep this PR open: it has strong Linux live-behavior evidence, but a completed idempotent `chat.send` retry is still treated as an active stream and can leave Quick Chat’s composer locked. The `maintainer` label also requires explicit maintainer handling rather than automated cleanup.

## What This Changes

The branch streams run-correlated Gateway chat replies in Linux Quick Chat and distinguishes pairing-required connection failures from missing shared-credential failures.

## Best Possible Solution

Preserve the Gateway ACK status through the native result and immediately render cached-complete `ok` replies as terminal, with a regression test covering a post-completion idempotent retry.
