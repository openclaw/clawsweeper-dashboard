## Summary

## What This Changes

The PR changes Exa web-search credential lookup to resolve configured SecretRefs before the ambient `EXA_API_KEY` fallback and adds regression tests.

## Best Possible Solution

Keep runtime secret preparation as the single credential-resolution owner and retain provider-local code as a consumer of the prepared credential string.
