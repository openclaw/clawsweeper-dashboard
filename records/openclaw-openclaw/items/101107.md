## Summary

## What This Changes

The PR changes the SMS Twilio webhook replay cache to preserve live replay keys, prune only expired entries before capacity checks, return 429 when the live replay cache is saturated, and add saturation regression tests.

## Best Possible Solution

Land the owner-local replay-protection fix after the SMS owner explicitly accepts or documents the saturated-cache delivery semantics; if rejecting legitimate overflow webhooks is not acceptable, replace the edge behavior with a maintainer-approved durable replay design.
