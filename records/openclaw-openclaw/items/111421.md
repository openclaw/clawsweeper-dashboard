## Summary

Keep this PR open for maintainer review: it adds a default server-to-Gravatar fallback that can disclose an email-derived identifier to a third party whenever a profile lacks an uploaded avatar. The `maintainer` label also requires explicit human handling. Likely related people: steipete (high confidence from the merged identity/profile/avatar work).

## What This Changes

The PR adds self-service Control UI profile editing and avatar uploads, then serves uploaded avatars or a cached server-side Gravatar fallback through an authenticated gateway route.

## Best Possible Solution

Keep uploaded avatars and deterministic initials as the default, and add any Gravatar lookup only after maintainers choose and document an explicit privacy-preserving opt-in contract with a clear disable and refresh path.
