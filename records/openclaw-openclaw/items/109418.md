## Summary

Keep this PR open, but do not merge it as written: schema-v1 cannot distinguish a legacy feed that lacks `featured` from an intentional unfeature, so the current production feed and older hosted snapshots can clear the existing Featured shelf.

## What This Changes

## Best Possible Solution
