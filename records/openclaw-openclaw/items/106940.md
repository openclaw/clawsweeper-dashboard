## Summary

The QMD adapter cleanup is well-targeted, but the same parser is also applied to every persisted short-term recall entry, so the automatic repair can delete legitimate diff-hunk text from non-QMD memories. The PR also lacks after-fix proof from a real QMD or mcporter setup.

## What This Changes

The PR adds a strict QMD snippet-envelope parser, applies it to QMD search results and persisted short-term recall repair, regenerates concept tags, and adds focused regression tests.

## Best Possible Solution

Keep envelope removal at the QMD adapter, make old-store cleanup conditional on verifiable QMD provenance or equivalence with the live source range, regenerate tags only after that verification, and prove direct CLI, mcporter, and repair behavior with redacted live output.
