## Summary

## What This Changes

The PR makes embedded-run bootstrap context loading more cooperative by async-reading root bootstrap files, replacing fs.glob extra-file resolution with a yielding walker, yielding between bootstrap hook handlers, and adding bootstrap substage diagnostics with focused tests.

## Risks / Open Questions

- Extra-bootstrap match order remains walker/filesystem-order dependent; that can affect prompt bytes and session context when multiple configured files match one pattern.
