## What This Changes

This PR makes embedded-agent bootstrap preparation cooperative by asynchronously reading workspace files, yielding during extra-file traversal and bootstrap hook dispatch, and reporting slow bootstrap substages.

## System Context

Embedded agent runs load workspace bootstrap files and apply bootstrap hooks before they construct the agent context. Those steps share Node’s event loop with channel and gateway activity, so a blocking workspace scan can delay message handling and timers.

## Best Possible Solution

Preserve Node glob compatibility by recognizing bracket classes as glob syntax, routing them through the yielding resolver, and adding a regression test that proves a configured bracket-class pattern returns the same files as the prior resolver.
