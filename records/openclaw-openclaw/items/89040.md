## Summary

The asynchronous workspace-read and cooperative glob changes are a well-supported fix for the reported bootstrap stall. However, the PR separately permits unrelated event-loop work between ordered handlers mutating one shared bootstrap event; that scheduling contract needs explicit owner approval before merge, and current main does not already contain the central fix.

## What This Changes

The PR replaces blocking bootstrap file reads and configured glob traversal with cooperative asynchronous implementations, adds embedded-run bootstrap timing diagnostics, and yields between ordered bootstrap hook handlers.

## Best Possible Solution

Retain the asynchronous descriptor reads, cooperative full glob traversal, compatibility coverage, and slow-bootstrap diagnostics, while keeping the ordered bootstrap handler chain uninterrupted unless the hook owner explicitly adopts cooperative interleaving with reentrancy and shared-event mutation coverage.
