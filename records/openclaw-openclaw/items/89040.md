## Summary

This PR is still necessary, but the current head retains the prior P1 compatibility defect: the replacement walker does not recognize `[`/`]` character-class glob syntax. Existing `bootstrap-extra-files` patterns such as `rules/[AB]GENTS.md` can therefore stop loading configured context after the upgrade, so the branch needs one focused repair before merge.

## What This Changes

The PR replaces blocking workspace bootstrap reads and native glob traversal with cooperative asynchronous loading, yields between embedded-run hook handlers, and adds slow-bootstrap timing diagnostics.

## System Context

Embedded agent runs assemble workspace bootstrap files and apply internal bootstrap hooks before creating an agent turn. This path feeds context into the agent while sharing the event loop with channel delivery, timers, and gateway activity.

## Architecture Diagram

  F --> G[Channel and gateway activity]

## Best Possible Solution

Preserve the cooperative walker, add `[` and `]` to glob detection and glob-root selection, and add a parity regression proving bracket-class patterns load the same configured files as the previous native glob path.
