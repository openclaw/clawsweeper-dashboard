## Risks / Open Questions

- Replacing Node fs.glob with a custom yielding walker is compatibility-sensitive because existing bootstrap-extra-files users may observe differences in glob parity, dot-directory traversal, symlink handling, or traversal order despite focused tests.
- The walker now completes the full matching traversal rather than imposing a cap, so very large workspaces can still spend substantial wall time in bootstrap; the availability gain is cooperative yielding rather than bounded total work.
- Yielding between bootstrap hook handlers changes event-loop interleaving while handlers can mutate bootstrapFiles, so maintainers should explicitly accept the session-context timing tradeoff before merge.
