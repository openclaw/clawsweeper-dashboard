## Summary

This PR has strong real-behavior evidence for reducing bootstrap event-loop stalls, but its replacement glob implementation can silently stop honoring existing bracket-class `bootstrap-extra-files` patterns. Preserve the native glob contract before merge rather than landing a prompt-context compatibility regression.

## What This Changes

The branch moves embedded-run bootstrap file loading and extra-file traversal onto asynchronous yielding paths, yields between bootstrap hooks, and adds slow-bootstrap timing diagnostics.

## System Context

Embedded runs assemble workspace bootstrap files and hook-provided context before an agent turn begins. Those files feed the prompt-building path, so traversal latency affects gateway responsiveness while file-selection compatibility affects the context each turn receives.
