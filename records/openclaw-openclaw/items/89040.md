## Summary

This PR remains necessary: current `main` still uses synchronous guarded bootstrap reads and `fs.glob` on the embedded-run bootstrap path, while this branch makes those paths cooperative and preserves the public plugin SDK signature. The branch has sufficient real-path benchmark proof and no discrete correctness finding, but replacing Node glob traversal and changing bootstrap hook scheduling remain compatibility-sensitive prompt/session decisions that need runtime-owner acceptance before merge. Likely related people: steipete (high), solstead (high), and vincentkoc (medium).

## What This Changes

The branch replaces blocking workspace bootstrap reads and extra-file glob resolution with asynchronous yielding paths, yields between bootstrap hooks, and records slow bootstrap substages without expanding the plugin SDK.

## System Context

Embedded agent runs build bootstrap context from workspace files and configured extra-file patterns before starting an agent turn. That context passes through internal bootstrap hooks into the agent runtime, so its file-selection, ordering, and scheduling behavior can affect responsiveness and session prompt bytes.
