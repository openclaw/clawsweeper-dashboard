## Summary

Keep this PR open, but it needs one mechanical compatibility repair before merge: the cooperative bootstrap-file walker still treats bracket character classes as literal paths, unlike the current `fs.glob` path. The supplied benchmark is meaningful real-path evidence for reduced event-loop stalls, but it does not make a context-dropping upgrade regression acceptable.

## What This Changes

This PR makes embedded-agent bootstrap preparation cooperative by replacing synchronous workspace reads and blocking extra-file glob traversal with asynchronous yielding paths, then yields between bootstrap hook handlers.

## System Context

Embedded agent runs prepare workspace bootstrap context before dispatching an agent turn. The loader resolves configured workspace files and hook changes into context that affects the prompt and session behavior of the upcoming run.

## Architecture Diagram

  Hooks --> Context[Agent bootstrap context]

  Run --> Channels[Responsive channel and gateway work]

## Best Possible Solution

Retain the cooperative async walker, but make its pattern recognition and matching cover the supported bracket-class glob contract, with regression tests that compare configured bracket patterns against the pre-change behavior before merge.
