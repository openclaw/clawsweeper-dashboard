## Summary

Needs changes before merge: the custom walker still excludes bracket character classes from glob detection, so an existing configured bootstrap pattern such as `rules/[AB]GENTS.md` is treated as a literal path and its matching file is omitted. This is the previously reported P1 compatibility blocker and remains present at the current head.

## What This Changes

This PR replaces synchronous workspace-bootstrap reads and native glob traversal with cooperative asynchronous loading, adds yielding between bootstrap hook handlers, and records embedded-run bootstrap timing.

## System Context

Embedded agent runs build bootstrap context from workspace files and internal bootstrap hooks before executing an agent turn. Those files become prompt context for the run, while the same Node event loop continues to serve gateway and channel work.

## Architecture Diagram

flowchart LR

  C[Internal bootstrap hooks] --> D[Bootstrap context preparation]
  B --> D
  D --> E[Embedded agent turn]
  E --> F[Prompt and session context]
  E --> G[Gateway and channel event loop]

## Best Possible Solution

Preserve the performance-oriented yielding walker, but recognize `[` and `]` as glob metacharacters everywhere the walker classifies or locates a glob root, then add a regression test comparing a bracket-class pattern with the existing native-glob behavior.
