## Summary

This PR remains necessary, but the current head still has the prior P1 compatibility defect: bracket-class bootstrap globs are treated as literal paths instead of globs. The primary event-loop benchmark is strong, yet this regression can omit configured bootstrap context after upgrade, so the patch needs one focused repair before merge.

## What This Changes

The branch replaces blocking bootstrap workspace reads and extra-file glob traversal with asynchronous yielding paths, and yields between embedded-agent bootstrap hook handlers to keep the event loop responsive.

## System Context

Embedded agent runs load workspace bootstrap files, resolve configured extra files, and apply bootstrap hooks before constructing agent context. Those steps run alongside gateway and channel work, so blocking filesystem traversal can delay message handling and session progress.

## Best Possible Solution

Extend the internal glob detection and matcher to support Node-style bracket classes, add focused parity coverage for matching and no-match cases, then rebase and rerun the bootstrap-file tests plus the plugin SDK surface check.
