## Summary

This PR is still necessary, but it remains incorrect because its replacement glob detector treats `[` and `]` as literals. A configured bracket-class pattern such as `rules/[AB]GENTS.md` therefore bypasses the cooperative walker and is handled as a literal path, unlike the replaced Node glob behavior; that can silently remove configured bootstrap context after upgrade. The prior P1 finding remains on the current head, whose final commit only splits tests.

## What This Changes

This PR makes embedded agent bootstrap preparation more cooperative by replacing synchronous workspace reads and blocking extra-file glob traversal with asynchronous yielding paths, while timing bootstrap stages and yielding between bootstrap hook handlers.

## System Context

Embedded agent runs load workspace bootstrap files and apply internal bootstrap hooks before constructing the context for an agent turn. This preparation shares Node's event loop with gateway and channel work, so filesystem traversal and hook scheduling directly affect message responsiveness and the bootstrap context an agent receives.

## Best Possible Solution

Extend glob detection and walk-root calculation to recognize bracket classes, then add a focused parity regression showing that a configured bracket-class pattern loads the same bootstrap file set as the prior Node glob path.
