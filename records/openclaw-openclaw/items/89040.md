## Summary

Keep open: this is a useful targeted fix for the bootstrap-context stall, but the current patch is not merge-ready because the replacement glob walker still drops explicit symlink-directory matches that current main loads through Node's glob implementation.

## What This Changes

The PR replaces synchronous/bootstrap-context file loading and fs.glob-based extra bootstrap resolution with async/yielding workspace reads, adds bootstrap hook scheduling/timing, and updates focused tests.

## Best Possible Solution

Land a narrow version that keeps the async/yielding bootstrap improvements while preserving current fs.glob semantics for explicitly named symlink-directory patterns.
