## Summary

Keep this PR open, but it is not ready to merge: the new walker still classifies square-bracket glob classes as literal paths, so an existing `bootstrap-extra-files` pattern such as `rules/[AB]GENTS.md` loses matching bootstrap context after upgrade. The prior ClawSweeper P1 finding remains unfixed at the latest head.

## What This Changes

The PR replaces synchronous workspace bootstrap reads and glob traversal with asynchronous yielding paths, adds slow-bootstrap timing diagnostics, and yields between bootstrap hook handlers during embedded agent preparation.

## System Context

Embedded agent runs load workspace bootstrap files and apply internal bootstrap hooks before each agent turn. This preparation runs on the same Node.js event loop as channel delivery, WebSocket activity, and timers, so file traversal latency affects both prompt context and runtime responsiveness.

## Best Possible Solution

Extend glob detection and walker matching to support square-bracket character classes with Node-compatible semantics, add focused parity coverage for matching and no-match cases, then rebase and rerun the relevant bootstrap-file checks.
