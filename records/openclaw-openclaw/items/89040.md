## Summary

This PR should stay open and needs changes before merge: the async/yielding bootstrap work is useful, but the custom glob walker still drops explicit symlink-directory matches that current Node `fs.glob` returns, so existing extra-bootstrap configs can lose context on upgrade.

## Best Possible Solution
