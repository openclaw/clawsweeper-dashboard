## Summary

This PR addresses a real bootstrap responsiveness problem and includes strong direct-loader benchmark evidence, but it still regresses an existing `fs.glob` configuration syntax: bracket classes. The current head continues to classify patterns such as `rules/[AB]GENTS.md` as literal paths, so merging can silently omit configured bootstrap context; keep the PR open for that focused compatibility repair.

## What This Changes

The PR replaces blocking bootstrap workspace reads and glob traversal with cooperative asynchronous paths, and yields between embedded-agent bootstrap hook handlers so agent setup does not monopolize the event loop.

## System Context

Embedded-agent runs assemble workspace bootstrap files and apply internal bootstrap hooks before constructing the context sent to the agent. Workspace configuration feeds file discovery and reading, then the resulting context affects each agent turn and its channel/session responsiveness.

## Best Possible Solution

Keep the cooperative reader and walker, but make the custom glob detector and matcher preserve every relevant `fs.glob` syntax used by existing configuration—especially bracket classes—and lock that contract with focused regression coverage.
