## Summary

Keep open for maintainer acceptance: the patch appears correct for the scoped bootstrap-context event-loop stall, but it intentionally changes bootstrap glob traversal and bootstrap hook scheduling, which are compatibility, session-state, and availability tradeoffs maintainers should accept before merge.

## What This Changes

The PR makes embedded-run bootstrap work more cooperative by using async guarded bootstrap file reads, replacing active `fs.glob` bootstrap traversal with a yielding walker, yielding between agent bootstrap hooks, recording bootstrap substage timings, and adding focused tests.

## Best Possible Solution

Land this focused mitigation once maintainers accept the hook-scheduling and glob-traversal tradeoffs, while keeping broader Gateway worker/offload work tracked separately under the wider event-loop architecture issue.
