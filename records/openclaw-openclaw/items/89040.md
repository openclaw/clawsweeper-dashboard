## Summary

## What This Changes

The PR makes embedded-run bootstrap context loading async/yielding by changing workspace file reads, extra-bootstrap glob walking, bootstrap hook dispatch scheduling, timing diagnostics, and focused tests.

## Best Possible Solution

Land this PR or an equivalent bounded bootstrap-context liveness fix after maintainers accept the glob and hook-scheduling tradeoffs and current-head gates finish cleanly.

Yes, this is an acceptable bounded mitigation for the bootstrap-specific event-loop stall: it removes the blocking read/glob/hook pieces without growing the public SDK surface. Broader worker-thread isolation or prep scheduling is a separate architecture path rather than a prerequisite for this fix.
