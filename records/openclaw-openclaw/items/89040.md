## Summary

Keep open: the performance fix direction is useful and the supplied terminal proof is sufficient for the core loader path, but the current patch still replaces `fs.glob` with a walker that drops explicit symlink-directory glob descendants.

## What This Changes

The PR makes embedded-run bootstrap file loading and extra-bootstrap glob resolution async/yielding, adds bootstrap substage timing, and moves bootstrap hook scheduling/timing into an internal dispatch module.

## Best Possible Solution

Land the async/yielding bootstrap mitigation after the custom walker preserves Node `fs.glob` parity for explicit in-workspace symlink-directory traversal while retaining workspace escape protection and focused regression coverage.
