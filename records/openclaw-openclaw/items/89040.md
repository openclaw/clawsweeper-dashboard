## Summary

Keep this PR open for a narrow repair. The event-loop responsiveness problem is convincingly reproduced and the asynchronous/yielding direction is sound, but the custom glob walker returns filesystem traversal order after the branch removed deterministic sorting, allowing identical workspaces to produce different bootstrap prompt bytes and session/cache behavior.

## What This Changes

The PR makes bootstrap file reads asynchronous, replaces native extra-bootstrap glob collection with a cooperative yielding walker, yields between bootstrap hook handlers, and adds bootstrap-stage timing diagnostics and regression coverage.

## Best Possible Solution

Keep the asynchronous reads and cooperative scheduling, but sort normalized relative matches with a locale-independent code-unit comparator before context assembly and retain focused parity tests for patterns, dot paths, and symbolic links.
