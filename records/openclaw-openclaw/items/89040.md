## Summary

Keep open: this PR is still the active candidate for the bootstrap-context event-loop stall, but it is not merge-ready because the custom glob walker drops descendant files under explicit symlink-directory roots that current Node `fs.glob` loads.

## What This Changes

The PR replaces synchronous bootstrap file loading and extra-bootstrap glob scanning with async/yielding paths, adds bootstrap substage timing, and routes bootstrap hook dispatch through an internal yielding scheduler.

## Best Possible Solution

Land the async/yielding bootstrap mitigation after the custom walker preserves Node `fs.glob` parity for explicit symlink-directory traversal while keeping workspace escape protection and the plugin SDK boundary unchanged.
