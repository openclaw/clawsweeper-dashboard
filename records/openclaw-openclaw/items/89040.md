## Summary

This PR remains necessary: it targets a real bootstrap responsiveness problem and includes credible real-path benchmark evidence, but the latest head still changes existing `bootstrap-extra-files` semantics for bracket-class globs. The previous P1 finding remains unresolved, so the patch should not merge until it preserves the Node glob contract and adds focused coverage.

## What This Changes

The PR replaces blocking workspace bootstrap reads and glob traversal with asynchronous yielding paths, yields between bootstrap hook handlers, and adds timing diagnostics for slow embedded agent bootstrap stages.

## System Context

Before an embedded agent turn starts, OpenClaw reads workspace bootstrap files and applies bootstrap hooks to construct agent context. Configured extra-file patterns flow through the workspace glob resolver, then the resulting files affect the context supplied to the embedded runner.
