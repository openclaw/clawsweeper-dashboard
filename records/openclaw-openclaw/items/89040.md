## Summary

Keep open: the bootstrap event-loop mitigation is still useful and not on current main, but the PR remains blocked because the custom extra-bootstrap glob walker drops files under explicit symlink-directory patterns that current Node `fs.glob` would load.

## What This Changes

The PR replaces synchronous workspace bootstrap reads and `fs.glob` extra-bootstrap scans with async/yielding logic, adds bootstrap substage timing, and moves bootstrap hook scheduling into an internal dispatcher.

## Best Possible Solution

Land the async/yielding bootstrap mitigation after the custom walker preserves Node `fs.glob` parity for explicit symlink-directory traversal while keeping workspace escape protection and focused regression coverage.
