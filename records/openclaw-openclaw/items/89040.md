## Summary

Keep this PR open, but do not merge it yet: the prior P1 compatibility finding remains on the latest head. The new cooperative walker still treats bracket-class patterns such as `rules/[AB]GENTS.md` as literal filenames, whereas the replaced Node glob path resolves them, so existing configured bootstrap files can disappear from agent context after upgrade.

## What This Changes

This PR replaces blocking bootstrap-file reads and extra-file glob traversal with yielding asynchronous paths, and adds embedded-run bootstrap timing plus yielded internal-hook dispatch.

## System Context

Before an embedded agent run starts, OpenClaw loads root and configured workspace bootstrap files, then applies bootstrap hooks to form the agent context. That context feeds the run scheduler, so matching the existing configured file set matters alongside keeping the Node.js event loop responsive for gateway and channel work.

Extend the walker’s glob detection and matching path to preserve bracket-class patterns, add a regression proving the same configured file set as the prior glob behavior, then retain the cooperative traversal design.
