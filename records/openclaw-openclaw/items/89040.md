## Summary

Keep open: this PR is the active candidate fix for https://github.com/openclaw/openclaw/issues/87509, and current main plus v2026.6.11 still have the blocking bootstrap-context path. The patch looks correct with sufficient real behavior proof and green current-head checks, but it still needs maintainer acceptance for the configured-glob and bootstrap-hook interleaving tradeoffs before merge.

## What This Changes

This PR makes embedded-run bootstrap context loading async/yielding by replacing synchronous guarded reads and fs.glob expansion, adding bootstrap substage timing, and yielding between agent bootstrap hook handlers with focused tests.

## Best Possible Solution

Land this PR or an equivalent bounded bootstrap-context liveness fix after maintainers explicitly accept the glob-walker and hook-interleaving tradeoffs while keeping the public SDK surface unchanged.
