## Summary

Keep open: the async/yielding bootstrap direction is useful and the supplied terminal proof is meaningful, but the latest head still has a compatibility blocker because the new active glob walker does not traverse explicit symlinked directory globs that Node fs.glob currently matches.

## What This Changes

The branch makes workspace bootstrap reads and extra-bootstrap glob resolution async/yielding, adds internal bootstrap hook scheduling and timing, instruments embedded-run bootstrap timing, and expands focused tests.

## Best Possible Solution

Land this after preserving fs.glob-compatible explicit symlinked-directory glob behavior and after maintainers accept the bootstrap hook interleaving tradeoff, keeping the new scheduling and timing APIs internal.

## Solution Assessment

No: the async/yielding bootstrap fix is the right direction, but it is not the best merge shape until the new resolver preserves fs.glob parity for explicit symlinked directories. The safer repair is a narrow walker parity fix plus regression coverage, not reverting the whole performance change.
