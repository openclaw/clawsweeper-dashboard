## Summary

Keep open: current main and the latest release still attach recent history images with only sender and optional message id in the direct recent-image note; sent-time and bounded thread-position metadata remain missing, and all PRs that attempted this specific annotation are closed unmerged.

## What This Changes

Request image attachments carried from thread history into agent prompts to include sent-time, position/total, and sender metadata so models can reason about image freshness.

## Best Possible Solution

Add sent-time and bounded message-position metadata in the shared recent-history image prompt note, using existing HistoryEntry ordering/timestamps while preserving path redaction and current-image precedence.
