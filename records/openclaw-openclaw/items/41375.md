  - confidence: 0.9
- **[P2] Prefer the inbound sender for hook replies:** `src/auto-reply/reply/dispatch-from-config.ts:218`
  - body: The reply target falls back to `ctx.To` before `ctx.From`, but on a direct inbound channel `ctx.To` is usually the bot address and `ctx.From` is the user. This can send the hook reply back to the bot-side identity instead of the person who sent the message.
  - confidence: 0.92
- **[P2] Validate hook messages before trimming them:** `src/auto-reply/reply/internal-hook-replies.ts:28`
  - body: Internal hooks can be plain runtime JavaScript, so `event.messages` can contain non-string values despite the TypeScript type. Calling `.trim()` directly can throw and abort `/new` or `/reset` hook reply processing where the previous join-based path did not.
  - confidence: 0.84
