## Summary

Keep open: current main and the latest release still allow an elevated-enabled, allowed session with no explicit default to resolve to active host exec, so the sandbox-to-gateway routing concern remains and needs a maintainer security-boundary decision.

## What This Changes

The issue asks for elevated exec enablement to preserve sandbox routing for non-elevated calls, default implicit elevated state to off, and clarify or change `/elevated ask` semantics.

## Best Possible Solution

Make a maintainer-owned security decision, then align the elevated fallback, `/elevated ask` semantics, prompt text, docs, and regression coverage in one change.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should allowed elevated sessions with no explicit `agents.defaults.elevatedDefault` default to `off`, and should `/elevated ask` remain a host-with-approval alias or become sandbox-by-default per-call opt-in elevation?

Rationale: The narrow safer default changes upgrade behavior, while changing `/elevated ask` would redefine a documented sandbox escape contract; automation should not choose that boundary alone.

Likely owner: steipete

Owner reason: The strongest history for the current elevated default and exec security boundary points to steipete-owned paths.

Owner confidence: high

Options:

- **Default implicit elevation off (recommended):** Change only the no-explicit-default fallback to `off`, preserve `/elevated ask` as documented, and update docs/tests for the safer default.
- **Redefine ask as opt-in:** Make `/elevated ask` keep normal exec in the sandbox and route only explicit elevated calls to host approval, accepting the broader contract change.
- **Keep current behavior:** Leave elevated-enabled allowed sessions as host exec by default and update docs to make that security posture unmistakable.

## Reproduction Assessment

Yes, at source level. Current main resolves allowed elevated sessions with no configured elevated default to `on`, omitted exec calls inherit that active mode, and elevated target resolution selects the gateway host.

## Solution Assessment

Unclear pending maintainer decision. Defaulting the implicit elevated level to `off` is the narrowest safety fix, while changing `/elevated ask` is a broader operator-command contract change.
