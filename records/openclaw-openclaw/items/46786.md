## Summary

Keep open: current main and v2026.6.11 still let an allowed elevated session with no explicit `agents.defaults.elevatedDefault` fall back to elevated `on`, which makes ordinary exec calls leave the sandbox; changing that is a security-boundary/default-policy decision rather than a safe cleanup close.

## What This Changes

The issue asks for elevated exec to remain sandbox-default when `tools.elevated.enabled` is turned on, with gateway execution used only for explicit elevation.

## Best Possible Solution

Settle the elevated security contract, then align directive resolution, exec routing tests, system prompt text, and docs so enabling elevated cannot silently change sandbox routing unless that behavior is explicitly retained.

Unclear. Defaulting to `off` is the safer security shape, but changing the current documented `/elevated ask` and default behavior needs maintainer approval.
