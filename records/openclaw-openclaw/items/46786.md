## Summary

Keep open: current main still lets an elevated-enabled, allowlisted session with no explicit elevated default resolve to active host exec, so the sandbox-to-gateway routing concern remains a real security-boundary issue rather than stale cleanup.

## What This Changes

The issue reports that enabling `tools.elevated.enabled` makes ordinary exec calls route to the gateway instead of staying in the sandbox unless elevation is explicitly turned off.

## Best Possible Solution

Make a maintainer-owned security decision, then align the elevated fallback, `/elevated ask` semantics, prompt text, docs, and regression coverage in one change.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should allowlisted elevated sessions with no explicit `agents.defaults.elevatedDefault` default to `off`, and should `/elevated ask` remain a host-with-approval alias or become sandbox-by-default per-call opt-in elevation?

Rationale: The narrow safer default changes upgrade behavior, while changing `/elevated ask` would redefine a documented sandbox escape contract; automation should not choose that security boundary alone.

Likely owner: steipete

Owner reason: The strongest feature-history signal for elevated modes, default handling, and exec target behavior points to steipete-authored commits.

Owner confidence: high

Options:

- **Default implicit elevation off (recommended):** Change only the no-explicit-default fallback to `off`, preserve `/elevated ask` as documented, and update docs/tests for the safer default.
- **Redefine ask as opt-in:** Make `/elevated ask` keep normal exec in the sandbox and route only explicit elevated calls to host approval, accepting the broader contract change.
- **Keep current behavior:** Leave elevated-enabled allowlisted sessions as host exec by default and update docs to make that security posture unmistakable.

## Reproduction Assessment

Yes, at source level. Current main resolves allowlisted elevated sessions with no configured elevated default to `on`, omitted exec calls inherit that active mode, and elevated target resolution selects the gateway host.

## Solution Assessment

Unclear pending maintainer decision. Defaulting the implicit elevated level to `off` is the narrowest safety fix, while changing `/elevated ask` is a broader operator-command contract change.
