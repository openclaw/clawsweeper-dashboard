## Best Possible Solution

Adopt one clearly owned, additive deny-over-allow contract with consistent matching and human-approval semantics across gateway and node hosts, strict validation, deny-first precedence, pre-dispatch revocation, UI/docs coverage, and fresh-install plus upgrade proof.
