Request mobile iOS and Android support for per-gateway custom HTTP headers so gateway WebSocket connections can pass through authenticating reverse proxies.

Keep this issue as the canonical mobile tracker until the iOS and Android PRs either land with owner/security proof and real authenticated-proxy validation, or maintainers choose a narrower mobile proxy-auth contract.
