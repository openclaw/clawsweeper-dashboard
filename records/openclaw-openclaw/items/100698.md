## Summary

Keep open: current main and v2026.6.11 still lack mobile per-gateway custom-header support, and the linked iOS and Android implementation PRs are open under maintainer/security review.

## What This Changes

Request support in the iOS and Android apps for securely stored per-gateway custom HTTP headers attached only to Gateway connections behind authenticating proxies.

## Best Possible Solution

Settle one shared mobile Gateway proxy-header contract, then land or reject the linked iOS and Android PRs after secure storage, redaction, gateway-only tests, upgrade behavior, and real authenticated-proxy proof are accepted.
