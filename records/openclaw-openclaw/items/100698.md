## What This Changes

Request to add iOS and Android per-gateway custom HTTP headers for gateway connections behind authenticating reverse proxies, with secure storage and gateway-only attachment.

## Best Possible Solution

Keep this issue as the canonical mobile custom-header tracker and resolve it by owner/security reviewing the linked iOS and Android PRs, then close only after the accepted platform work lands or maintainers explicitly narrow the product direction.
