## Summary

Keep open: current main and the latest release still lack a Ralph-style STOP-driven repeated same-prompt loop or per-agent `loop.max_ralph_iterations` default. The existing `runRetries`, tool-loop detection, and compaction prechecks are adjacent safeguards, not the requested loop/control surface, and open pull request https://github.com/openclaw/openclaw/pull/97485 only partially overlaps the generic iteration-budget part.

## What This Changes

Request adding a per-agent Ralph Loop iteration-limit default with clear CLI, agent, global, and default precedence.

## Best Possible Solution

Keep this open until maintainers either accept a native per-agent loop/iteration-budget design or explicitly choose a different product direction; any accepted fix should align schema, resolver, runtime, docs, and tests around the chosen precedence and STOP/unlimited semantics.

## Reproduction Assessment

Yes for the missing capability, but not as a broken existing-behavior repro. Current source inspection shows no Ralph/per-agent loop field, strict schemas reject unknown agent keys, and the resolver has no runtime setting to propagate.

## Solution Assessment

Unclear; the requested shape is plausible, but maintainers still need to choose the product/API contract. A generic opt-in iteration budget like https://github.com/openclaw/openclaw/pull/97485 may be the right narrower path for part of the problem, but it does not by itself settle Ralph STOP-loop semantics.
