## Summary

Keep open: current main and v2026.6.11 still lack a Ralph-style repeated same-prompt loop and a per-agent Ralph iteration default; the active iteration-budget PR overlaps but does not yet land or fully cover the STOP-driven Ralph semantics.

## What This Changes

Request an OpenClaw agent-level Ralph/repeated-prompt loop iteration default with CLI > agent > global precedence.

## Best Possible Solution

Define one OpenClaw-native continuation and budget contract that separates intentional repeated-prompt workflows from accidental tool loops, then expose the smallest typed config surface with documented precedence and terminal-outcome semantics.

## Reproduction Assessment

Yes for the missing capability, not as a broken-behavior bug: current source has no Ralph/repeated-prompt loop field, strict schemas reject unknown agent keys, and the resolver has no setting to propagate to the runner.

## Solution Assessment

Unclear as proposed. The user need fits agent-harness work, but Kimi-specific field names, STOP sentinels, unlimited-loop behavior, and interaction semantics need an OpenClaw-native contract first.
