## Summary

Keep open: current main still lacks a Ralph-style repeated same-prompt loop and any per-agent `loop.max_ralph_iterations` or equivalent iteration-budget config surface; the related iteration-budget PR is open but unmerged, so this remains a product/config decision.

## What This Changes

Request to add a per-agent Ralph Loop iteration limit with CLI-over-agent-over-global precedence and matching runtime/docs/tests.

## Best Possible Solution

Settle the product shape first, then implement one canonical OpenClaw loop-budget surface with strict schema/help/docs, explicit precedence, runner wiring, and focused fresh/upgrade tests.

## Reproduction Assessment

Yes for the missing capability: current source has no Ralph/iteration-budget field, strict agent schemas reject unknown per-agent keys, and the resolver has nothing to pass into the runner. This is source-reproducible as a feature gap, not a broken existing behavior bug.

## Solution Assessment

Unclear until maintainers choose the product model. A general opt-in iteration-budget surface like the open related PR may be more maintainable than a Ralph-specific field, but the final precedence and STOP/unlimited semantics need owner approval.
