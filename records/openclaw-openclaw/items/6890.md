## Summary

Current main and v2026.6.11 still lack the requested STOP-driven repeated-prompt mode. The open iteration-budget PR provides a narrower circuit breaker for tool-calling rounds, so the unique orchestration request remains open pending product direction.

## What This Changes

Add an OpenClaw-native “Ralph Loop” that repeats a prompt until STOP, with configurable global and per-agent iteration limits plus explicit override precedence.

## Best Possible Solution

Define one generic orchestration contract covering explicit completion signals, hard safety budgets, interruption, transcript/state adoption, and restart behavior; expose it through a plugin or harness seam unless maintainers deliberately sponsor Ralph mode as core behavior.
