## Summary

Keep open for maintainer product direction. ## What This Changes

Add a Ralph-style repeated-prompt agent loop with configurable per-agent iteration limits and explicit CLI, agent, global, and default precedence.

## Best Possible Solution

Adopt one bounded per-agent harness safety contract for runaway tool-calling rounds, and add a separate Ralph lifecycle only if maintainers explicitly define a distinct repeated-prompt use case with interruption, persistence, and finite safety bounds.
