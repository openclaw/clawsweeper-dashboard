## Summary

Keep open: current main still lacks a Ralph-style repeated same-prompt loop and a per-agent Ralph iteration default. The open iteration-budget PR is relevant, but it is not merged and does not settle the requested STOP-driven loop semantics.

## What This Changes

Request to add a per-agent Ralph loop iteration default with CLI-over-agent-over-global precedence and documentation/tests for disabled, finite, and unlimited behavior.

## Best Possible Solution

Define one OpenClaw-native continuation and budget contract that separates intentional repeated-prompt workflows from accidental tool loops, then expose the smallest typed config surface with documented precedence and terminal-outcome semantics.

## Reproduction Assessment

Yes at source level for the missing capability, not as a broken-behavior bug: current schemas accept no Ralph loop field and the resolver/runtime have no setting to carry it into execution.

## Solution Assessment

Unclear as proposed. The need fits agent-harness work, but Kimi-specific field names, STOP sentinels, unlimited looping, and precedence should be settled as an OpenClaw-native contract before implementation.
