## Summary

Keep open: current main still lacks a Ralph-style repeated-prompt loop or per-agent loop iteration default, and the active iteration-budget PR is open, conflicting, and only partially overlaps the requested STOP-driven behavior.

## What This Changes

The issue requests a per-agent agent-spec/default config field for Ralph-style repeated-prompt looping with clear CLI, per-agent, global, and default precedence.

## Best Possible Solution

Define one OpenClaw-native continuation and iteration-budget contract that separates intentional repeated-prompt workflows from accidental tool loops, then expose the smallest typed config surface with documented precedence and runtime tests.
