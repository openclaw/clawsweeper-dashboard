## Summary

Current main still lacks the requested STOP-driven repeated-prompt mode and per-agent iteration default. The open iteration-budget PR is a well-proven but narrower safety circuit breaker, so this issue remains necessary for an explicit product decision rather than closing as implemented or superseded.

## What This Changes

Requests a Ralph-style repeated-prompt loop with a per-agent maximum-iteration default and explicit CLI, agent, global, and default precedence.

## Best Possible Solution

Specify proactive repeated-prompt execution and runaway tool-round budgeting as separate OpenClaw runtime contracts; if Ralph mode is approved, use bounded opt-in defaults, a typed terminal result instead of prompt-string inference, explicit cancellation and restart behavior, and canonical per-agent precedence with focused lifecycle tests.
