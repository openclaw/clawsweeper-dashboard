## Summary

Keep open. The Telegram outbound delivery path still handles media item-by-item rather than using a native grouped-media call, so the requested album behavior remains absent. This is a bounded Telegram-plugin enhancement, but maintainers should first confirm the intended compatibility contract for captions, reply/thread metadata, and groups beyond Telegram’s per-call limit.

## What This Changes

Add Telegram-native album delivery when one message action contains multiple image attachments, instead of sending each image as a separate photo message.

## System Context

The message tool produces outbound media attachments that the Telegram channel converts into Bot API calls. Today that adapter emits individual media messages; an album path would instead turn a compatible image batch into one Telegram media group while preserving the ordinary fallback paths.

## Best Possible Solution

Implement a Telegram-extension-only all-image album branch for a maintainer-approved compatible batch size, preserve individual sends for single, mixed, or unsupported batches, and add focused adapter tests plus redacted live Telegram proof for caption, reply, thread, and fallback behavior.
