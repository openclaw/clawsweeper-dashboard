## Summary

Keep open: the current head still has two P1 compatibility blockers, and the external PR still lacks live gateway hot-reload proof. The branch can silently route valid runtime-only model rows back to agent defaults and returns reset model identity through a new field existing consumers do not read.

## What This Changes

The branch changes gateway session reset and model resolution so default-derived runtime model fields are not persisted, no-override runtime rows can re-resolve from agent defaults, and `sessions.reset` returns a computed model field.

## Best Possible Solution

Keep default-derived reset metadata out of persisted rows, preserve legitimate runtime-only model rows unless there is a reliable stale-default marker, return reset identity through the existing `resolved` contract, and add redacted live hot-reload proof.
