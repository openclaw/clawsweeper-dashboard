- **[P1] Preserve non-default runtime model metadata:** `src/gateway/session-utils.ts:1653-1663`
  - body: This branch treats any persisted `modelProvider`/`model` pair that differs from the current agent default as stale. That is not always true: channel model routing can intentionally select a non-default model when there is no session override, and `updateSessionStoreAfterAgentRun` persists the actual provider/model used into these runtime fields. With the new branch, gateway callers that pass `agentId` can resolve those sessions back to the agent default, making model display, prompt-cache keys, and image-support preflight wrong for existing non-default routing setups. Please only invalidate metadata known to mirror the old agent default, or clear/update it from the hot-reload owner with tests that preserve channel/non-default runtime selections.
  - confidence: 0.9
