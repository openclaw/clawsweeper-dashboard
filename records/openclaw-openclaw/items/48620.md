Existing `pairing`, `directory`, `channels status`, and in-chat `/allowlist` surfaces cover pieces only, and the narrower related request at https://github.com/openclaw/openclaw/issues/56621 does not replace this broader product/security decision.

## What This Changes

Request an admin-facing way to list/manage approved WhatsApp contacts with DM/group permissions and last-active data instead of manually combining partial commands or editing config.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
