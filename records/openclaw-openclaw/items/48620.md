## Summary

Keep open: current main and v2026.6.11 still lack one admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing pairing, directory, channels status, and in-chat allowlist surfaces cover pieces only, so this remains a security-sensitive product decision rather than a cleanup close.

## What This Changes

Request an admin CLI surface to list or manage approved WhatsApp contacts with sender ID, DM policy, group policy, and last-active state.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
