## Summary

Keep open: current main and v2026.6.11 still do not provide one admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data; existing pairing, directory, channel status, and in-chat allowlist surfaces only cover pieces of the request.

## What This Changes

Issue requests an admin-facing CLI surface to list and manage approved WhatsApp contacts with sender ID, DM policy, group policy, and last-active metadata.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
