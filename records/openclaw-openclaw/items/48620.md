## Summary

Keep open: current main and v2026.6.11 still lack one admin-facing WhatsApp contact inventory with approved pairing entries, DM/group permission state, and per-contact activity. Existing `pairing`, `directory`, `channels status`, and in-chat `/allowlist` surfaces cover pieces only, and https://github.com/openclaw/openclaw/issues/56621 is a narrower partial overlap rather than a replacement.

## What This Changes

The issue requests an admin-facing CLI view and management surface for approved WhatsApp contacts, their DM/group permissions, and last-active information.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
