## Summary

Keep open: current main and v2026.6.11 still lack a single admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing terminal `pairing`, `directory`, `channels status`, and in-chat `/allowlist` surfaces cover pieces only, so this remains a security-sensitive product decision rather than conservative cleanup.

## What This Changes

Request an admin CLI surface to view and manage paired WhatsApp contacts, permissions, and last-active state without manually editing `openclaw.json`.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
