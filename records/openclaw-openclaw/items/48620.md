## Summary

Keep open: current main and the latest release still lack a single admin-facing inventory for approved WhatsApp contacts with merged DM/group permissions and last-active data. Existing `pairing`, `directory`, `channels status`, and in-chat `/allowlist` surfaces cover pieces only, so this remains a security-sensitive product decision rather than conservative cleanup.

## What This Changes

The issue requests an admin-facing way to view and manage approved WhatsApp contacts, their DM/group permission state, and last-active metadata without editing configuration files manually.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
