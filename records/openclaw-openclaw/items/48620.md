## Summary

Keep open: current main and the latest stable release still lack one admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing pairing, directory, channel-status, and in-chat allowlist surfaces cover pieces only, and #56621 is a narrower partial overlap rather than a replacement.

## What This Changes

Request a CLI/admin command to list paired or connected WhatsApp senders with DM policy, group policy, and last-active information.

## Best Possible Solution

Define one account-scoped admin inventory/management surface that merges pairing-store approvals, configured DM/group allowlists, directory identity lookup, and chosen activity data with explicit redaction and authorization semantics.
