## Summary

Keep open: current main still lacks a single admin-facing WhatsApp contact inventory that merges approved pairings, configured DM/group authorization state, and last-active data. Existing pending pairing, directory, channel status, and in-chat `/allowlist` surfaces cover pieces, so this remains a product/security design item rather than conservative cleanup.

## What This Changes

Request an admin-facing way to list and manage approved WhatsApp contacts with DM/group permission state and last-active information.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and privacy semantics.
