Keep open: current main still lacks one admin-facing WhatsApp contact inventory that combines approved pairing entries, DM/group permission state, and per-contact activity; existing CLI, directory, status, and chat allowlist surfaces only cover parts of the request.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
