## Summary

Keep open: current main and the latest release still lack one admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing `pairing`, `directory`, `channels status`, and in-chat `/allowlist` surfaces cover pieces only, and the narrower related request at https://github.com/openclaw/openclaw/issues/56621 does not replace this broader product/security decision.

## What This Changes

The issue requests an admin CLI or similar surface to view and manage paired WhatsApp contacts, their DM/group permissions, and last-active state without manually editing config.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
