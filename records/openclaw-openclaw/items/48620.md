## Summary

Keep open: current main and v2026.6.11 still lack a single admin-facing WhatsApp contact/permission inventory with approved sender IDs, merged DM/group policy, and last-active data. Existing `pairing`, `directory`, `channels status`, and in-chat `/allowlist` cover pieces, but the remaining work is a security-sensitive product decision rather than a narrow bug fix.

## What This Changes

Request an admin-facing way, likely CLI-based, to list/manage approved WhatsApp senders with sender ID, DM/group permission state, and last-active information without manual config edits.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory labels, and an explicit activity source with redaction and authorization semantics.
