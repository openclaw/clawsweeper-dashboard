## Summary

Keep open: current main and v2026.6.11 still do not provide one admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing `pairing`, `directory`, `channels status`, and `/allowlist` surfaces cover pieces only, so the remaining work needs a security-sensitive product decision rather than cleanup closure.

## What This Changes

Add an admin-facing CLI/contact inventory for paired WhatsApp senders that shows sender IDs, DM/group policy, and last-active data without manual config editing.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
