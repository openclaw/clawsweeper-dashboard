## Summary

Keep open: current main and v2026.6.11 still do not provide a single admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing `pairing`, `directory`, `channels status`, and in-chat `/allowlist` surfaces cover pieces only, so the remaining work needs maintainer product and security direction.

## What This Changes

The issue requests an admin-facing way to view and manage approved WhatsApp contacts and their DM/group permissions without manually editing configuration.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
