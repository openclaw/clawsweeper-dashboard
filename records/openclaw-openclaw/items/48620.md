## Summary

Keep open: current main and v2026.6.11 still lack one admin-facing inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing pairing, directory, channel status, and in-chat allowlist surfaces cover pieces only, so this remains a product and security decision rather than cleanup-close material.

## What This Changes

The issue requests an admin-facing CLI surface to list and manage paired WhatsApp contacts, showing sender ID, DM policy, group policy, and last-active information.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
