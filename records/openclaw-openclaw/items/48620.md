## Summary

Keep open: current main and v2026.6.11 still lack one terminal/admin inventory for approved WhatsApp contacts with merged DM/group permission state and last-active data. Existing pairing, directory, channel status, and in-chat allowlist surfaces cover pieces only, while the narrower approved-pairing request remains a partial overlap rather than a replacement.

## What This Changes

Add an admin-facing way to view or manage paired WhatsApp contacts, including sender ID, DM policy, group policy, and last-active data.

## Best Possible Solution

Define one account-scoped admin inventory and management surface that coordinates pairing-store approvals, configured DM/group allowlists, directory identity lookup, and activity data with explicit redaction and authorization semantics.
