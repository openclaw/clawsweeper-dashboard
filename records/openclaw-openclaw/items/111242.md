## Summary

## What This Changes

Fix gateway startup handling so a live startup-migration lease cannot exhaust the shipped systemd restart budget and leave the user service failed indefinitely.

## Best Possible Solution

Make a live startup-migration lease a bounded, observable transient startup condition—preferably retrying acquisition at the gateway lifecycle boundary—and add service-level regression coverage proving the gateway recovers without exhausting systemd’s permanent-failure protection.
