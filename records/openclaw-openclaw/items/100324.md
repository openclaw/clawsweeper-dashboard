## Summary

Keep open: current main and v2026.6.11 still reject workspace-origin plugin candidates before the trusted official ClawHub install record can grant WhatsApp the state APIs it needs to start.

## What This Changes

Fix official ClawHub WhatsApp installs so a linked account can receive trusted plugin state access and start normally after login.

Add a generic install-record-and-path-based trusted-official propagation rule for official user-extension installs, with tests proving untracked workspace, raw load-path, and `plugins.allow` installs remain untrusted.
