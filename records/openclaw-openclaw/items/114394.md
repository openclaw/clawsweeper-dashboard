## What This Changes

The PR prevents sidebar session catalogs from treating an omitted gateway catalog payload as a failed refresh and makes the replay-failure test return its structured fallback on subsequent refreshes.

## System Context

The web sidebar asks the Gateway browser client for the active agent's session catalogs, then merges the returned pages into its visible catalog snapshot. This refresh loop can run again after replay failures, so an omitted transport payload must leave the current sidebar state intact rather than dereference it as a catalog response.
