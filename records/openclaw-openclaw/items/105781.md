## Summary

## What This Changes

The PR changes Nostr profile imports in the Control UI to abortable, control-locking drafts that require explicit Save & Publish, while preserving explicit HTTP `autoMerge: true` persistence.

## Best Possible Solution

Keep the explicit HTTP compatibility mode, make the Control UI draft-only with lifecycle-owned cancellation, and merge after a redacted real-browser demonstration confirms Cancel and form replacement reject late responses.
