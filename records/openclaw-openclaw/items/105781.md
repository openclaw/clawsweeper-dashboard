## What This Changes

The branch makes Control UI Nostr profile imports cancellable drafts, prevents stale responses from changing newer forms, disables form controls during import, and removes server-side `autoMerge` persistence.

## Best Possible Solution

Keep `autoMerge` as an opt-in server contract, have the Control UI explicitly request draft mode with `autoMerge: false`, retain its abort and stale-generation protections, and demonstrate import, Cancel, and delayed-response behavior against a real relay.

## Solution Assessment

No. UI-owned draft imports with abort and generation guards are appropriate, but deleting the server's existing opt-in merge behavior is broader than necessary; preserving that contract is the narrower fix.
