## What This Changes

The PR makes Control UI Nostr profile imports non-persisting, abortable drafts, prevents conflicting form actions during import, rejects stale responses, and preserves explicit HTTP `autoMerge: true` behavior.

## Best Possible Solution

Use the existing draft HTTP contract in Control UI, retain explicit `autoMerge: true` for intentional callers, and keep cancellation plus operation-generation guards so only Save & Publish persists a reviewed profile.
