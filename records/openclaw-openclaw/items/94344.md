The PR makes the OpenAI-compatible embedding client derive its SSRF policy from configured provider `request.allowPrivateNetwork`, adds omitted/false/true policy-state tests, and documents the memory config behavior.

## Best Possible Solution

Land this provider-policy inheritance only after explicit maintainer/security acceptance and release-note context; otherwise choose a different explicit memory embedding trust boundary and rework or close this PR.
