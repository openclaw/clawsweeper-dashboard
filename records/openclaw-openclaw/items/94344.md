## Summary

Keep open for maintainer/security review. The patch is a focused and well-proven candidate fix, but it intentionally extends the existing provider `request.allowPrivateNetwork` trust contract into memory embedding fetches, so green CI does not settle the SSRF and upgrade behavior decision.

## What This Changes

The PR makes OpenAI-compatible memory embeddings consume configured provider `request.allowPrivateNetwork`, adds omitted/false/true regression coverage, and documents the memory config behavior.

## Best Possible Solution

Land this provider-policy approach only after explicit maintainer/security acceptance of the SSRF and explicit-false upgrade semantics; otherwise supersede it with one documented trust boundary rather than adding a parallel memory-only knob.
