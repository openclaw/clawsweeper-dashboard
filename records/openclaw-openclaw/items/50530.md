Keep open. Current main and the latest release still preserve or hard-materialize Telegram single newlines rather than collapsing model hard-wraps inside prose/list items, so this remains a valid Telegram formatting policy request that needs maintainer direction before implementation.

## What This Changes

The issue requests Telegram outbound formatting that collapses model hard-wrapped single newlines inside prose/list items while preserving intentional paragraph breaks.

## Best Possible Solution

Define a Telegram-owned, Markdown-aware soft-wrap normalization policy, likely opt-in by default, that preserves blank lines, code/pre/math blocks, blockquotes, list boundaries, rich messages, and plain fallback behavior.
