## Summary

Keep open. Current main and the latest release still do not collapse Telegram mid-paragraph/model hard-wrap newlines, and the remaining work is a Telegram formatting product/default decision because recent rich-message fixes intentionally preserve line breaks.

## What This Changes

Request to add Telegram-specific normalization that collapses single mid-paragraph newlines while preserving intentional double-newline paragraph breaks.

## Best Possible Solution

Define a Telegram-owned, Markdown-aware soft-line-break policy that preserves blank lines, code/pre blocks, blockquotes, lists, rich messages, and the plain fallback path, with maintainer-approved default behavior.

Unclear as a product choice. The Telegram plugin is the right owner, but unconditional collapse conflicts with newline-preservation behavior while the safer opt-in path adds compatibility-sensitive config surface.
