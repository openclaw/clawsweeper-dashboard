## Summary

Keep open. Current main and the latest release still preserve or materialize Telegram single newlines rather than collapsing model hard-wraps, and the remaining work is a Telegram formatting/default policy decision.

## What This Changes

The issue requests Telegram-specific normalization that collapses single mid-paragraph newlines before sending while preserving intentional double-newline breaks.

## Best Possible Solution

Define a Telegram-owned, Markdown-aware soft-line-break policy, likely opt-in, that collapses model hard-wraps only where intended while preserving blank lines, code/pre/math, blockquotes, list structure, rich messages, and the plain fallback path.
