## Summary

Keep open. Current main and v2026.6.11 still preserve Telegram single newlines rather than collapsing model hard-wraps, and the remaining work is a Telegram formatting/default policy choice because related rich-message fixes intentionally preserve visible line breaks.

## What This Changes

The issue requests Telegram-specific normalization that collapses soft mid-paragraph newlines while preserving intentional paragraph breaks.

## Best Possible Solution

Define a Telegram-owned, Markdown-aware soft-wrap policy, preferably opt-in, that collapses prose hard-wraps while preserving blank lines, code/pre blocks, blockquotes, list semantics, rich messages, and the plain fallback path.
