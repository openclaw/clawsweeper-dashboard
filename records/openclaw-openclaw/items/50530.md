## Summary

Keep open. Current main and v2026.6.11 still preserve or materialize Telegram single newlines rather than collapsing model hard-wraps, and there is no collapse setting; because related rich-message work depends on preserving visible line breaks, this remains a Telegram formatting/default policy decision rather than a cleanup close.

## What This Changes

Requests Telegram outbound formatting that collapses single mid-paragraph/model hard-wrap newlines while preserving intentional paragraph breaks, possibly behind a channel option.

## Best Possible Solution

Define a Telegram-owned, Markdown-aware soft-wrap policy, preferably opt-in, that collapses prose hard-wraps while preserving blank lines, code/pre blocks, blockquotes, list semantics, rich messages, and the plain fallback path.
