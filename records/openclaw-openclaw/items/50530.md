## Summary

Keep open. Current main still preserves single Telegram Markdown newlines through the plain and rich outbound paths, and changing that behavior needs a maintainer default/config decision because related Telegram formatting work intentionally preserves line breaks.

## What This Changes

Request to normalize Telegram outbound text by collapsing single mid-paragraph or list-item newlines while preserving intentional double-newline paragraph breaks.

## Best Possible Solution

Define a Telegram-owned, Markdown-aware soft-wrap normalization policy, likely opt-in, that preserves blank lines, code/pre/math, blockquotes, list semantics, rich HTML, and the plain fallback path.
