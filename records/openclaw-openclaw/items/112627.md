## What This Changes

The PR prevents `openclaw gateway call` from running local state-migration preflight during CLI bootstrap and adds regression tests for both command-path detection and config-guard behavior.

## System Context

OpenClaw’s CLI bootstrap decides whether a command should run doctor/state-migration preflight before dispatching it. `gateway call` then acts as a remote Gateway RPC client, so this decision determines whether a monitoring probe can touch local state before making its WebSocket request.
