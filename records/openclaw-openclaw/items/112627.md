## What This Changes

The PR prevents the remote `gateway call` CLI command from running local state migrations during bootstrap, while adding tests that keep sibling gateway commands on their existing migration path.

## System Context

CLI startup classifies the requested command before its configuration guard decides whether to run doctor-based state migration work. `gateway call` is a remote RPC client: it reads connection settings, then sends a request to the running gateway rather than operating on local gateway state.

## Best Possible Solution

Keep the exemption limited to `gateway call`, preserve migration ownership in gateway startup and `openclaw doctor --fix`, and land only after the rebased merge result confirms both the bypass and the sibling-command control.
