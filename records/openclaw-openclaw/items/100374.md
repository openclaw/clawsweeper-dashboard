## Summary

No blocking patch findings remain. The change is still useful because current main buffers Tlon external image uploads with an unbounded `response.blob()`, while the PR switches that path to the shared SSRF-protected bounded media reader and keeps the existing fallback-to-original-URL behavior.

## What This Changes

The PR replaces Tlon external image upload's direct guarded fetch and unbounded blob read with `readRemoteMediaBuffer` capped by `MAX_IMAGE_BYTES`, and updates focused upload tests.

## Best Possible Solution

Land the bounded-reader fix after required exact-head checks complete, keeping Tlon external uploads on the shared media cap while preserving fallback to the original URL on fetch or upload failure.
