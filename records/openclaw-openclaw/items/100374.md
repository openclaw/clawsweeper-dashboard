## Summary

Keep open for merge review: current main still has the unbounded blob path, the PR moves the read to the shared bounded media helper, prior ClawSweeper findings are fixed, and I found no blocking patch or security issue.

## What This Changes

This PR replaces Tlon external image upload's direct guarded fetch/blob read with `readRemoteMediaBuffer` capped at `MAX_IMAGE_BYTES` and updates upload tests for the bounded fallback path.

## Best Possible Solution

Land the focused Tlon upload hardening after normal CI and maintainer gates, keeping outbound upload reads aligned with the shared `MAX_IMAGE_BYTES` media policy.

## Solution Assessment
