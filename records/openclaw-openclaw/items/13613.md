- `impact:message-loss`: Multiple Gateways can duplicate scheduled channel deliveries when cron jobs run without shared ownership.

## Summary

Keep open: current main and v2026.6.11 still implement cron as Gateway-local scheduling with process-local locking and no accepted distributed cron ownership contract, so this remains a real HA feature gap that needs maintainer architecture direction.

## What This Changes

Request distributed coordination for cron jobs across multiple OpenClaw Gateways so HA deployments do not run the same scheduled work more than once.

## Best Possible Solution

Define a backend-neutral cron ownership contract first, then implement leased claiming or leader election with upgrade-safe config or plugin API, health/status and CLI visibility, docs, and separate-process tests.
