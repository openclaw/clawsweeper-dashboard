## Summary

Keep open for maintainer product review. This is a current, maintainer-labeled feature request rather than a broken established contract, and it combines one concrete browser-tool response change with broader availability, remediation, and lifecycle policy questions.

## What This Changes

Add an optional compact interactive-page snapshot to successful browser navigation results and reduce browser-tool setup and failure round-trips.

## System Context

OpenClaw’s browser plugin exposes browser actions such as navigation and snapshots to an agent model. Navigation loads a page and returns action results; snapshots provide the page state the model uses to choose its next browser action.

## Best Possible Solution

Approve or narrow the product direction first, then implement snapshot-on-navigate as a bounded browser-plugin change with explicit size/error semantics and focused tests; assess runtime gating and session warmth as separate follow-up work.
