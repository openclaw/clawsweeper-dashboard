## Summary

Keep open: current main still routes `system event --mode now` through heartbeat/system-event queues, and heartbeat retries later when main or session lanes are busy; the requested priority alert surface remains unresolved.

## What This Changes

Request a high-priority or bypass-queue mode for `openclaw system event --mode now` so operational alerts can appear during congested in-session LLM lanes.

## Best Possible Solution

Define one intentional alert contract first: either a typed priority wake with auth, sanitization, rate limits, ordering, and busy-lane tests, or a canonical notification surface for urgent UI alerts.
