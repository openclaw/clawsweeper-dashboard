## Summary

Keep open. Current main and the latest release still route `openclaw system event --mode now` through queued system events plus heartbeat wake delivery, with no priority or queue-bypass contract; the remaining decision is a product/security boundary, not stale cleanup.

## What This Changes

Request to add a high-priority or queue-bypass mode to `openclaw system event` so urgent in-session alerts surface immediately during session-lane congestion.

## Best Possible Solution

Define a typed urgent-alert contract that separates immediate operator-visible notification from ordered prompt/transcript injection, then add CLI, protocol, gateway, TUI, and regression-test support around that boundary.

Rationale: Current code intentionally defers prompt-visible system-event delivery while the session lane is active, and bypassing that guard would change both product semantics and prompt-injection/session-ordering boundaries.

Options:

- **Split alert and transcript paths (recommended):** Add an immediate operator-visible alert path for TUI/control surfaces while keeping prompt-visible system events ordered through a reviewed queue or drain contract.
- **Allow prompt-visible priority injection:** Add an explicit high-priority prompt/transcript event mode with strict authorization, ordering semantics, and regression tests for active turns.
- **Defer to scheduler fairness:** Keep `system event` best-effort for now and solve foreground/background ordering through the broader session-lane policy tracked at https://github.com/openclaw/openclaw/issues/54488.

Yes, source-reproducible: current main has no priority or bypass field, and `mode: now` still enqueues a system event before requesting heartbeat delivery that skips busy lanes. I did not run a live provider-outage replay in this read-only review.

## Solution Assessment

No, a bare `--bypass-queue` flag is not yet the best fix. Maintainers should first choose the boundary between immediate operator-visible notification and prompt-visible transcript mutation, then encode that as a typed contract.
