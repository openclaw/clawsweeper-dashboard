## Summary

Keep open: current main still has no priority or bypass contract for system events, and `--mode now` still reaches the session through queued system events plus heartbeat retry when lanes are busy.

## What This Changes

The issue requests a high-priority or queue-bypass mode for `openclaw system event --mode now` so degraded-session alerts can appear immediately instead of waiting behind failing model turns.

## Best Possible Solution

Define one intentional priority alert contract with authorization, sanitization, rate limits, ordering rules, and busy-lane tests, keeping immediate operator visibility separate from any prompt-visible transcript mutation unless maintainers explicitly approve both.
