## Summary

Keep open. Current main still implements `system event --mode now` as queued system-event text plus heartbeat delivery, with no priority or queue-bypass contract; adding one needs maintainer product and security direction because prompt-visible `System:` events are trusted session content.

## What This Changes

Request a high-priority or queue-bypassing `openclaw system event --mode now` path so urgent alerts appear in-session immediately during provider or lane congestion.

## Best Possible Solution

Define a typed urgent-alert contract that gives TUI/operator-visible immediate notification and, only if approved, ordered prompt/transcript injection with auth, sanitization, and busy-lane tests.
