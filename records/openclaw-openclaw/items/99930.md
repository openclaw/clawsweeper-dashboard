Full review comments:

- **[P2] Only borrow structured-capable media defaults:** `extensions/logbook/src/service.ts:321-326`
  - body: When no explicit `visionModel` is set, this accepts any non-CLI image-capable media default, but `runBatch` then calls `extractStructuredWithModel`, which throws if the provider lacks `extractStructured`. A default such as `openai/*` can be reported as `media-defaults` and then make every Logbook batch fail instead of surfacing that no compatible structured vision model is configured.
  - confidence: 0.9
- **[P2] Gate write-only controls from read-only Logbook tabs:** `extensions/logbook/index.ts:105`
  - body: The descriptor makes the tab visible to `operator.read` sessions, but the bundled view still renders Pause, Analyze now, Standup, Ask, and keyframe-preview paths that call methods registered with `operator.write`. Read-only sessions will hit missing-scope errors or silently miss previews; require write for the tab or pass scopes into the view and hide/disable those affordances.
  - confidence: 0.88
