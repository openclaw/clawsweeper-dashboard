## Summary

Keep this active maintainer-authored regression fix open for normal maintainer merge review. The patch centralizes an existing channel-capability rule in the shared QA profile planner, removes the duplicate server-side pass, and its linked before/after Testbox evidence shows the documented smoke profile proceeds past the former Discord-channel abort.

## What This Changes

The PR makes QA profile planning exclude otherwise compatible flow scenarios whose effective channel is unsupported by the selected driver, so Crabline runs do not abort on Discord-only taxonomy scenarios.

## System Context

QA Lab converts taxonomy-backed profiles into runnable scenario selections for both the CLI and the dashboard server. The selected channel driver supplies capability constraints, and the resulting eligible scenarios are partitioned and executed by the QA suite runner.
