  - confidence: 0.9
- **[P1] Avoid duplicate replay on in-process restart:** `src/gateway/server-close.ts:132`
  - body: After persisting `FOLLOWUP_QUEUES`, the shutdown path leaves the live global queue intact. Current restart handling can fall back to an in-process restart, so the same followup can drain from memory and also be replayed from the disk snapshot.
  - confidence: 0.85
- **[P2] Remove the fixed five-minute recovery drop:** `src/auto-reply/reply/queue/persist.ts:110-116`
  - body: The loader drops all persisted queue entries older than five minutes, which means a slow update, manual downtime, or repeated restart failure can still silently lose exactly the messages this PR is meant to preserve.
