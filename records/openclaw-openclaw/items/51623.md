  - body: This writes OpenClaw-owned runtime queue state to `state/pending-messages.json`. The repository state contract keeps runtime queues and caches in SQLite-backed stores, with sidecars handled only by doctor or migration code, so this creates a parallel source of truth with no upgrade owner.

- **[P1] Keep replay text out of trusted system events:** `src/gateway/server-pending-messages.ts:30-37`
  - body: `item.prompt` comes from user/channel messages, but this path embeds it in a recovery summary and queues that summary as a system event.   - confidence: 0.9
- **[P1] Avoid duplicate replay on in-process restart:** `src/gateway/server-close.ts:125-130`
  - body: After persisting `FOLLOWUP_QUEUES`, the shutdown path leaves the live global queue intact. Current SIGUSR1 in-process restart reset intentionally preserves queued work, so the same followup can drain from memory and also be replayed from the disk snapshot.
  - confidence: 0.85
- **[P2] Remove the fixed five-minute recovery drop:** `src/auto-reply/reply/queue/persist.ts:110-116`
  - body: The loader drops all persisted queue entries older than five minutes, which means a slow update, manual downtime, or repeated restart failure can still silently lose exactly the messages this PR is meant to preserve. Durable queue recovery should restore until consumed or use an explicit visible product policy.
  - confidence: 0.8
