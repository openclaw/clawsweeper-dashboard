## What This Changes

The issue asks OpenClaw to restore Discord elevated authorization fallback from `channels.discord.allowFrom` when `tools.elevated.allowFrom.discord` is omitted, and to align `sandbox explain` diagnostics with runtime behavior.

## Best Possible Solution

Make the Discord elevated authorization contract explicit: either restore the released fallback through the channel plugin hook with shared runtime and `sandbox explain` tests, or retire it with shipped docs and a clear upgrade note requiring explicit `tools.elevated.allowFrom.discord`.
