## What This Changes

This PR refactors agent terminal handling so the embedded runner’s retry/failover decisions and Gateway task settlement reuse one typed terminal outcome instead of reconstructing cancellation and timeout state from separate flags.

## System Context

An agent attempt produces a terminal outcome such as completion, cancellation, or timeout; the embedded runner uses it to choose retry or profile failover behavior. Gateway then settles the task and returns the corresponding `agent.wait` result, so both layers must preserve the same termination meaning.
