## What This Changes

Make `/new` and `/reset` create a genuinely fresh session and transcript rather than only acknowledging a reset command.

## System Context

Chat commands enter the shared command handler, which emits lifecycle hooks and must coordinate a gateway session reset before the next agent turn. The resulting session identity and transcript determine which conversation context the agent receives.
