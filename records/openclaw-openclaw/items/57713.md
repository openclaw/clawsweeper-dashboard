## Summary

Current main and the shipped v2026.4.27 release fix the default-image failure: OpenClaw no longer aliases plain Debian as the default sandbox image, the default sandbox Dockerfile includes python3, and tests/docs now lock in that contract.

## What This Changes

The issue reports Docker sandbox write/edit failures when the default `openclaw-sandbox:bookworm-slim` image lacked python3 required by the sandbox mutation helper.

## Best Possible Solution

Keep the shipped fail-fast default-image contract; custom slim sandbox images remain operator-owned and should include python3 or use a documented non-slim base.
