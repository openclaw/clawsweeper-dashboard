The issue reports Docker sandbox write/edit failures when the default `openclaw-sandbox:bookworm-slim` image lacked Python required by the pinned mutation helper.

## Best Possible Solution

Keep the shipped default-image guard and build contract, and treat custom slim images without Python as operator-configured images that must include the documented sandbox write/edit dependency.
