## Summary

Current main no longer creates an incompatible default sandbox tag and the default sandbox build includes python3; the matching fix was merged in https://github.com/openclaw/openclaw/pull/73362 and is present in the v2026.4.29 release. The remaining custom slim-image case is now an explicit operator image contract rather than the original default-image bug.

## What This Changes

The issue asks OpenClaw to make Docker sandbox write/edit work with the default `openclaw-sandbox:bookworm-slim` image, or fail earlier with clear guidance when python3 is missing.

## Best Possible Solution

Keep the current fail-fast default-image contract and docs; users who choose custom slim images should build or select an image containing `python3` or `python` for sandbox mutation helpers.
