## Summary

Keep this PR open. The revised head fixes the earlier unsafe resend advice, but the disconnect deadline still awaits ACP client delivery before rejecting the prompt, so a stalled client can leave the turn hanging and prevent the durable ledger record; the external PR also lacks after-fix live ACP proof.

## What This Changes

The PR makes ACP disconnect-grace expiry emit a recorded outcome-unknown interruption before rejecting the pending prompt, with replay tests and a design note.

## Best Possible Solution

Make disconnect-deadline settlement reject the original prompt at the deadline while recording the interruption independently of potentially blocked client delivery, preserve run-scoped stale-send isolation, and prove both live notification and one-time replay in a real ACP session.
