## Summary

Keep open: current main still silently drops malformed CDP client frames in the browser extension relay, adjacent relay tests do not cover this protocol-error path, and no open PR or canonical issue owns the same remaining fix.

## What This Changes

The issue reports that browser extension relay CDP clients hang because malformed JSON and structurally invalid request frames are silently ignored instead of receiving JSON-RPC errors.

## Best Possible Solution

Add a narrow relay-boundary fix that returns JSON-RPC parse and invalid-request errors for malformed CDP client frames, with regression coverage, without changing extension-side frame handling or normal CDP routing.
