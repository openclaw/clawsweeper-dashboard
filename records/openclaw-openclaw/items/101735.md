## What This Changes

The PR adds a predicate-first `selectTaskRecords` registry helper, exports it, and switches Gateway `tasks.list` to use it before activity sorting and pagination.

## Best Possible Solution

Implement a bounded Gateway or task-registry listing path that filters, orders, and selects only the requested activity-ordered page window before cloning response records, while preserving the current `tasks.list` params, response shape, ordering, and cursor behavior.
