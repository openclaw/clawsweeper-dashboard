## What This Changes

Add an off-by-default, read-only iOS HealthKit summary command with fixed on-device aggregates and explicit iOS and Gateway authorization.

## Best Possible Solution

Implement the maintainer-preferred node-command architecture after approving one fixed aggregate contract: user-initiated read authorization and disclosure in Settings, conditional command advertisement, on-device aggregation, explicit Gateway arming, conservative no-data semantics, and no webhook credentials, background ingestion, raw samples, or durable health queue.
