## What This Changes

The issue reports GitHub Copilot Claude runs failing when Anthropic-compatible replay sends an error `tool_result` whose content sanitizes to empty text.

## Best Possible Solution

Review and land or deliberately replace https://github.com/openclaw/openclaw/pull/97293 with an equivalent provider-boundary guard, then close this issue only after the selected fix is merged.

## Reproduction Assessment

Yes. Source inspection shows current main can pair sanitized-empty legacy Anthropic tool-result content with `is_error: true`, and the issue plus follow-up comments include matching redacted provider 400 logs from GitHub Copilot Claude sessions.

## Solution Assessment

Yes for the narrow bug. A provider-boundary guard that preserves non-empty tool output but substitutes a non-empty placeholder for empty error tool results is the most maintainable fix; pinned-session fallback behavior is a separate product question.
