## What This Changes

## Best Possible Solution

Land a provider-boundary normalization that makes Anthropic error `tool_result` content non-empty on Copilot Claude replay paths, with regression coverage and maintainer acceptance of the placeholder behavior, then close this issue after the fix merges.
