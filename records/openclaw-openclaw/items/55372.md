## What This Changes

The issue requests an option to suppress restart-sentinel outbound notifications while preserving session wake and recovery behavior.

## Best Possible Solution

Maintainers should choose one narrow core-owned suppression contract that gates only the direct outbound restart notice while preserving queued system events, heartbeat wake, continuation routing, and thread routing.
