## What This Changes

The issue requests a public configuration option to suppress restart-sentinel outbound notifications while preserving session wake behavior.

## Best Possible Solution

Maintainers should approve one narrow core-owned suppression contract that gates only the direct outbound restart notice while preserving queued system events, heartbeat wake, continuation routing, and route/thread behavior.

## Solution Assessment
