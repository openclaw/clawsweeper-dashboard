- `merge-risk: 🚨 compatibility`: The patch changes an existing configuration and environment-value resolution contract by trimming nonblank certificate paths.

## Summary

Keep this PR open, but fix the compatibility regression before merge: the new helper correctly treats whitespace-only values as absent, yet it also rewrites every nonblank certificate path by trimming it. The supplied terminal proof is strong for the intended blank-value behavior; the remaining blocker is preserving valid nonblank filesystem paths verbatim.

## What This Changes

The PR changes Microsoft Teams federated credential resolution so blank certificate, thumbprint, and managed-identity values do not count as configured and can fall back to environment settings.

## Best Possible Solution

Use whitespace trimming only to detect absence, then return the selected nonblank certificate path unchanged; retain normalized handling for identifier-like values such as thumbprints and managed-identity client IDs, and rebase the repaired patch on current `main`.
