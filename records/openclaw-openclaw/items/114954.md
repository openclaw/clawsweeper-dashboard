## What This Changes

The PR makes the agent `edit` and `apply_patch` tools reject existing files with invalid UTF-8 bytes before a text rewrite can replace those bytes with UTF-8 replacement characters.

## System Context

Agent coding tools read a target workspace file, apply a textual edit or unified patch, and write the updated content back through host, sandbox, or workspace-root file access paths. This change adds strict UTF-8 validation at those read boundaries so unsupported byte sequences cannot enter the whole-file rewrite path.
