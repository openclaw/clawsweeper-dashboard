## Summary

Keep open: the branch still lets a timed-out parent-size probe proceed as a fork, so current callers can enter the same parent transcript copy path that may hang and can bypass the oversized-parent isolation contract.

## What This Changes

The branch imports fresh-token resolution, adds a 1s timeout wrapper around parent-fork token counting, and adds tests for fresh, stalled, and oversized parent-fork decisions.

## Best Possible Solution

Make timeout or unresolved parent sizing choose a bounded non-fork path, or bound the subsequent fork transcript read too, while preserving fresh-token and oversized-parent behavior.
