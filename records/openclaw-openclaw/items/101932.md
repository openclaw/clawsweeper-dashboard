## Summary

Keep open: this PR targets a valid source-backed session-fork hang, but the current patch should not merge because the timeout path returns an unknown-size `fork` decision and can immediately enter the same unbounded parent transcript fork read.

## What This Changes

The PR changes parent-session fork decision logic to prefer fresh persisted token counts and time-box parent transcript token probing before continuing with a fork decision.

## Best Possible Solution

Do not let a timed-out parent size probe proceed into an unbounded fork; either return a conservative non-fork/isolated result on timeout or bound the subsequent fork transcript read, then refresh one candidate branch onto current main.
