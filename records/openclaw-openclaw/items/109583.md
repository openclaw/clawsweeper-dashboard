## What This Changes

The PR sets a 16 MiB inbound `ws` frame limit for QQBot gateway connections and updates constructor assertions for direct and proxy connection paths.

## System Context

QQBot receives gateway events through a WebSocket client, which hands JSON envelopes to the gateway connection and then into channel message handling. This change limits frame size before `ws` and JSON parsing allocate memory, but rejected frames take the normal disconnect and reconnect path.
