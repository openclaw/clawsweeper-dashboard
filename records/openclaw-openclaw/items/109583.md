## What This Changes

The branch applies a 16 MiB `ws` inbound-frame limit to QQBot gateway connections and updates all proxy-path constructor assertions to retain that limit.

## System Context

QQBot receives gateway events through a WebSocket, passes their raw payloads to JSON parsing, and then routes message events into the channel’s ingress and queue lifecycle. This change constrains the payload before parsing, affecting both resource use and the reconnect behavior for oversized gateway events.
