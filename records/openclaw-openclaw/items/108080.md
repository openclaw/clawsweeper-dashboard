## Summary

The report is recent, concrete, and not clearly fixed or owned by another item, so it should remain open pending a focused current-main browser reproduction and regression fix.

## What This Changes

Ensure the Control UI Chat sidebar’s displayed agent scope stays consistent with the active or highlighted session in multi-agent setups.

## Best Possible Solution

Make the route or active session authoritative for the UI’s active-agent label while preserving agent browsing as clearly separate expansion state, then add regression coverage for switching between multiple agents’ main sessions.
