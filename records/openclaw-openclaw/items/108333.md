## Summary

The patch appears correct and well-proven, but the fixed 15-second deadline becomes an availability contract for every Reef relay HTTP operation and needs explicit Reef-owner confirmation before merge.

## What This Changes

The branch wraps Reef relay HTTP requests in the shared 15-second timeout helper and adds regression coverage for a relay that stalls before returning headers.

## Best Possible Solution

Adopt one Reef-owner-approved relay request deadline through the shared SDK helper, keep it consistent across all relay HTTP operations, and retain focused timeout plus reconnect-recovery coverage without adding a new config knob unless real relay requirements prove one necessary.
