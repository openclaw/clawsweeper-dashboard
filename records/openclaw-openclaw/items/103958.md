## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P1] Do not swallow invalid thinking values:** `src/acp/control-plane/manager.runtime-controls.ts:94-96`
  - body: This matcher treats any `session/set_config_option` `-32602` or `invalid params` response as an unsupported optional key. ACP sends both a config ID and value, so a backend that advertises `thinking` but rejects an invalid or unsupported value will now silently retain its default, including when the user explicitly requested that value. Restrict this fallback to `ACP_BACKEND_UNSUPPORTED_CONTROL` or an error that specifically identifies the key as unsupported; let value-validation failures propagate.
  - confidence: 0.93
