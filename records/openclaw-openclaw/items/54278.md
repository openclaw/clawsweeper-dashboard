## What This Changes

The issue requests native Codex quota/auth diagnosis, native Codex rate-limit display, and bounded brokered reauth execution when credentials truly need reauthentication.

## Best Possible Solution

Define a typed provider/Gateway/UI recovery-state contract first, then connect it to explicit, auditable reauth actions that reuse existing device-code primitives only for authorized private contexts and avoid implicit host command execution.
