Full review comments:

- **[P1] Do not require a later user after every compaction summary:** `packages/agent-core/src/harness/messages.ts:42`
  - body: Late discovery: this line was already present in the earlier reviewed head. Compaction summaries are replayed as a user message before the retained tail, and split-turn compaction can retain assistant/tool output without any later user message. Telling the model to respond only to a latest user message after the summary can make it ignore the retained continuation and stall or drift after compaction; make this boundary wording say to continue from the retained messages after the summary, not only from a later user message.
  - late: true
  - confidence: 0.88
- **[P2] Keep the safety floor inside the entry range:** `packages/agent-core/src/harness/compaction/compaction.ts:464`
  - body: Late discovery: this line was already present in the earlier reviewed head. If the branch slice has a single valid entry, `cutIndex` starts at `startIndex` and this assignment advances it to `startIndex + 1`, which can equal `endIndex`; the following `entries[cutIndex]` read is then undefined and compaction preparation throws instead of returning a valid no-op/keep-tail cut. Clamp to an existing entry or only force the floor when another entry exists.
  - late: true
  - confidence: 0.9
