Full review comments:

- **[P2] Preserve recent tool results before pruning:** `src/agents/agent-hooks/compaction-safeguard.ts:1033-1035`
  - body: The pruning pass runs before the existing recent-turn preservation logic, but `recentTurnsPreserve * 2` counts only tail messages, not the full turn closure. A real multi-pass caller would compact the old transcript on later passes, so either return/update next-pass params from adoption or remove this helper until it can be wired safely.
