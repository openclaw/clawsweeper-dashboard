Full review comments:

- **[P1] Recompute token accounting after pruning:** `src/agents/agent-hooks/compaction-safeguard.ts:1033-1038`
  - body: This shortens `baseMessagesToSummarize` before the LLM path calls the existing history planner, but that planner computes recent/new content as `tokensBefore - estimateMessagesTokens(messagesToSummarize + turnPrefixMessages)`. Since `tokensBefore` is still the pre-prune total, every token saved by summarizing old tool results is misclassified as unsummarized recent content, which can trigger the drop-chunk path and lose extra history even when pruning already made room.
  - confidence: 0.91
- **[P2] Keep internal knobs out of exported settings:** `packages/agent-core/src/harness/compaction/compaction.ts:139-142`
  - body: `CompactionSettings` is re-exported through `openclaw/plugin-sdk/agent-core`, so adding `maxPasses` and `progressThreshold` here changes the public SDK type even though current `prepareCompaction`/`shouldCompact` ignore them and the user config schema rejects them. `@internal` JSDoc does not keep these fields out of the contract; keep them on a private multi-pass parameter type or wire and document the behavior.
  - confidence: 0.88
