  - body: `setTimeout` only aborts the composed signal, then the loop awaits `contextEngine.compact()`. Late discovery: this code was unchanged from the earlier reviewed head and should have been raised then.
  - late: true

  - body: Each pass spreads the original `compactParams`, but `CompactResult` can return a successor sessionId/sessionTarget/sessionFile after transcript rotation. Keep the next pass aligned with `resolveCompactionSuccessorTranscript()` or a production caller can compact the old transcript again instead of the adopted successor.
  - confidence: 0.88
