## Summary

Current main still allows an artifact block to resolve to the protected managed outgoing `/api/` media URL, which plain browser navigation cannot authenticate. The issue remains necessary and should stay open while the linked fix candidate at https://github.com/openclaw/openclaw/pull/106701 receives review and either lands or is replaced.

## What This Changes

Ensure authorized Web/Control UI users can preview generated workspace images without navigating directly to an auth-header-dependent managed media URL.

## Best Possible Solution

Resolve recognized managed outgoing images to bounded bytes inside the authenticated artifact RPC while retaining the protected media route and testing shared-secret, paired-device, unauthenticated, wrong-owner, MIME, and size-limit behavior.
