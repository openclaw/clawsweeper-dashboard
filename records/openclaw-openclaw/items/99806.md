## What This Changes

The PR finalizes killed subagent task-registry rows as `cancelled` in the shared termination path and adds focused subagent-control tests for kill/admin/failure cases.

## Best Possible Solution

Land the shared termination-path task finalizer after required CI completes, keeping normal success/failure lifecycle finalization unchanged.

## Reproduction Assessment

Yes. Current main is source-reproducible because subagent registration creates a running task row while the kill primitive only marks the in-memory run ended; the PR body also supplies before/after real-runtime output, though I did not rerun it locally in this read-only review.

## Solution Assessment

Yes. The shared `markSubagentRunTerminated` primitive is the best fix point because lower `killSubagentRun` handling would miss parent-reply abort callers, while the normal lifecycle watcher cannot be relied on after the kill path sets `endedAt`.
