## What This Changes

This PR adds a short-lived per-session-key reservation so concurrent first reply dispatches reuse one session ID instead of creating parallel sessions.

## System Context

The auto-reply pipeline receives channel messages, resolves or creates a session entry, then uses that session identity to start or steer an agent run and transcript. This patch changes the pre-persistence new-session path where simultaneous messages can otherwise each mint an ID.
