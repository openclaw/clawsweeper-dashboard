## Summary

Keep open: current main and the latest release still route `sessions_send` target turns as `inter_session` with `message_tool_only`, still teach exact skip tokens, and still suppress exact non-deliverable tokens before visible delivery. ## What This Changes

The issue asks OpenClaw to stop treating explicit WhatsApp `inter_session` delivery requests as coordination chatter that can be suppressed by `REPLY_SKIP`, `ANNOUNCE_SKIP`, or `NO_REPLY`.

## Best Possible Solution
