## Summary

Keep open: current main still routes `sessions_send` target runs as `inter_session`/`message_tool_only`, still exposes generic `REPLY_SKIP`/`ANNOUNCE_SKIP` prompt guidance, and still suppresses exact skip/no-reply tokens before visible channel delivery. ## What This Changes

The issue asks OpenClaw to stop suppressing explicit WhatsApp inter-session delivery requests as `REPLY_SKIP`, `ANNOUNCE_SKIP`, or `NO_REPLY` when a normal group message should be emitted.
