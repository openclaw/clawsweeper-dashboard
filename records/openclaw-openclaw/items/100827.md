## Summary

Keep open: the PR is aimed at the right SQLite cache-owner boundary, but the changed CLI ordering can now run debug-proxy finalization after initialization fails and re-enter the same failing store-open path during process exit.

## What This Changes

The branch adds process-exit close hooks for shared, agent, and proxy-capture SQLite handle caches, revalidates cached proxy-capture stores, and moves CLI debug-proxy finalization before state DB exit-close registration.

## Best Possible Solution

  - body: This listener is now armed before `initializeDebugProxyCapture("cli")` has successfully opened the capture store. Keep the ordering, but make the handler no-op until initialization has completed successfully.
