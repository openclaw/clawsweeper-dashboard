## What This Changes

The PR keeps policy-required trusted native tools visible in Code Mode, retains Google Gemini compatibility metadata during discovery, escapes reserved MCP declaration names, and rejects suspended-run resumes whose recorded owner identity is absent from the caller.

## System Context

Code Mode compacts an agent's broad tool set into a small direct surface and a searchable catalog before provider transports receive tool declarations. It also persists execution context for suspended work, so catalog filtering and resume authorization affect whether an agent can reply and whether a later caller can resume the same run.
