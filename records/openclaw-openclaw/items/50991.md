## Summary

Keep open: current main and the latest release still limit the bundled session-memory archive hook to `/new` and `/reset`; `/compact` reaches the separate compaction lifecycle hook surface, and the open continuity PR is only a partial foundation that explicitly does not add command or compaction hooks.

## What This Changes

Request adds a compaction-time trigger to the bundled session-memory hook so conversation context is archived before `/compact` compresses session history.

## Best Possible Solution

Define the compaction-time memory archive contract on the compaction lifecycle surface, then update the bundled session-memory hook, docs, and focused tests without duplicating memoryFlush or continuity-snapshot behavior.
