## Summary

Keep open: current main and the latest release still limit the bundled session-memory archive hook to `/new` and `/reset`. Compaction lifecycle hooks and memoryFlush exist, but they do not currently provide the requested session-memory archive on `/compact`, and the open continuity PR is only a partial foundation.

## What This Changes

The issue requests firing the bundled session-memory hook when `/compact` runs so session context can be archived before compaction.

## Best Possible Solution

Define the compaction-time memory archive contract on the compaction lifecycle surface, then update the bundled session-memory hook, docs, and focused tests without duplicating memoryFlush or post-index-sync behavior.
