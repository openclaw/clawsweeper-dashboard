## Summary

Keep open: current main and v2026.6.11 still limit the bundled session-memory archive hook to `/new` and `/reset`, while compaction emits `session:compact:before/after`. The KeepMyClaw comment is complementary backup context rather than an OpenClaw implementation, and the adjacent continuity, memoryFlush, and plugin-hook items do not implement this bundled archive trigger.

## What This Changes

The issue requests firing the bundled session-memory archive hook when `/compact` or compaction runs so pre-compaction context is preserved.

## Best Possible Solution

Define the compact-time archival contract, then wire session-memory through `session:compact:before` with metadata, docs, regression tests, and explicit retention/dedupe behavior if maintainers approve it.

## Reproduction Assessment

Yes. Source inspection shows session-memory metadata and handler logic only register and accept `/new` and `/reset`, while compaction currently emits `session:compact:before/after`; I did not run a live compaction because this review is read-only.

## Solution Assessment

No as written. The preservation gap is real, but `command:compact` is not the current lifecycle surface; the safer implementation is a maintainer-approved `session:compact:before` session-memory contract.
