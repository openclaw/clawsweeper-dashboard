## Summary

Keep open: current main and v2026.6.11 still scope the bundled session-memory archive hook to `/new` and `/reset`; compaction has lifecycle hooks and memoryFlush, but no session-memory archive is written at the requested compaction boundary. The KeepMyClaw comment is useful complementary backup context, not an OpenClaw implementation of this hook behavior.

## What This Changes

Requests that session-memory preserve or archive context when compaction runs, rather than only on `/new` and `/reset`.

## Best Possible Solution

Define compaction-time memory preservation on the existing compaction lifecycle surface, then update the bundled session-memory behavior, docs, and regression coverage without duplicating memoryFlush or continuity-helper responsibilities.
