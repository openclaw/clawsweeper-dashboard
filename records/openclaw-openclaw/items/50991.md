## Summary

Keep open: current main and the latest release still do not make bundled session-memory archive on compact. The report is source-reproducible, but the literal `command:compact` proposal needs maintainer direction because current code already has a shared `session:compact:before` lifecycle surface and separate memoryFlush/continuity work.

## What This Changes

The issue asks OpenClaw to trigger the bundled session-memory hook when `/compact` runs so conversation context can be archived before compaction.

## Best Possible Solution

Define the compaction-time archive contract on the existing compaction lifecycle surface, then update session-memory, docs, and focused tests without duplicating memoryFlush or continuity-snapshot behavior.
