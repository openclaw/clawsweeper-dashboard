## Summary

Keep open: current main and v2026.6.11 still keep the bundled session-memory archive hook scoped to `/new` and `/reset`, while compaction uses separate lifecycle and memoryFlush paths that do not settle the requested archive contract.

## What This Changes

The issue requests adding a compaction-time trigger to the bundled session-memory hook so memory archives are written before `/compact` compacts conversation context.

## Best Possible Solution

Define the compaction-time memory archive contract on the compaction lifecycle surface, then update the bundled session-memory hook, docs, and focused tests without duplicating memoryFlush or continuity-snapshot behavior.
