## Summary

Keep open: current main and v2026.6.11 still do not trigger the bundled session-memory archive on `/compact`; existing compaction lifecycle hooks, memoryFlush, and the open continuity-helper PR are adjacent but do not implement this requested behavior.

## What This Changes

The issue requests adding compaction-time triggering for the bundled session-memory hook so conversation context is archived before compaction.

## Best Possible Solution

Define one compaction-memory contract, likely through `session:compact:before` with enough context for archival, while preserving current `/new` and `/reset` behavior and avoiding duplicate memory protocols.
