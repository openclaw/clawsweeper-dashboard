## Summary

Keep open: current main and the latest release still limit the bundled session-memory archive hook to `/new` and `/reset`; compaction has separate lifecycle hooks, but none currently write the requested session-memory archive.

## What This Changes

Request adding a compaction-time trigger for bundled session-memory archival so long conversations are preserved before compaction.

## Best Possible Solution

Define a maintainer-approved `session:compact:before` session-memory contract, including the needed session-file context, then update the bundled hook metadata, handler, docs, and regression coverage around that lifecycle surface.

## Solution Assessment
