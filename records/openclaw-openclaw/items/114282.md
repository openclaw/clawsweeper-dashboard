## What This Changes

The PR replaces GitHub Copilot’s legacy short-lived-token exchange with direct validation of the original GitHub credential and uses the returned Copilot API endpoint so fine-grained tokens can work across existing model, streaming, embeddings, media, usage, and cache paths.

## System Context

The GitHub Copilot provider accepts a GitHub PAT or OAuth credential, resolves the account’s Copilot API endpoint, then passes the resulting authorization and headers to model, embedding, media, and usage requests. This patch changes that shared authentication handoff and the Copilot integration identity used by those downstream requests.
