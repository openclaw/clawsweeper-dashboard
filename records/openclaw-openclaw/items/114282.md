## What This Changes

This PR replaces GitHub Copilot’s short-lived runtime token exchange with validation and direct use of the stored GitHub credential so fine-grained tokens can authenticate across catalog, inference, embeddings, usage, and media flows.

## System Context

OpenClaw’s GitHub Copilot plugin receives a durable GitHub credential from the OAuth profile layer, validates Copilot access to obtain an account-specific endpoint, and prepares request identity and headers for provider traffic. The prepared auth then reaches agent requests, model discovery, embeddings, usage, and image understanding.
