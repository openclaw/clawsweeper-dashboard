## Summary

Keep open: the PR targets a real, still-unfixed WhatsApp gateway restart loop, but the current patch still lets terminal-disconnected accounts restart through the timed-out recovery branch before the new guard runs.

## What This Changes

Adds a `terminalDisconnect` channel snapshot flag, forwards it from WhatsApp status, and uses it to report terminal disconnects and skip gateway auto-restarts with focused tests.

## Best Possible Solution

Move the terminal guard ahead of every ChannelManager recovery restart branch, clear recovery bookkeeping when skipping, and land only after maintainers accept the generic terminal-stop snapshot contract.

## Solution Assessment

No, not yet. The restart-suppression direction is plausible and narrow, but the guard must run before timed-out recovery restarts and maintainers still need to accept the plugin-facing snapshot contract.
