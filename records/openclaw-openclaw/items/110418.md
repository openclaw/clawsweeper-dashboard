## What This Changes

Migrates WhatsApp accepted inbound messages from its private replay guard and journal flow to the shared durable channel-ingress drain, adding lifecycle binding and regression coverage.

## Best Possible Solution

Persist or derive a monotonic queue-claim order for WhatsApp messages within a conversation, add a regression that replays equal-millisecond messages in receive order, then attach redacted live receive/restart/flush evidence from a WhatsApp account before merge.
