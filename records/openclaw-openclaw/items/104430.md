## Summary

The PR addresses a real restricted-agent privilege bypass and its in-memory cap enforcement is coherent, but it is not merge-ready because the canonical SQLite store drops the new cap for both added payload kinds after save/load, reopening full trigger tool access after a gateway restart.

## Best Possible Solution
