## Summary

Keep open: current main and v2026.6.11 still do not support `agents.list[].subagents.workspace`; no-agentId same-agent children still inherit the requester workspace. The linked Plur1bus repository is useful adjacent workspace/memory-isolation context, but it does not replace the missing OpenClaw core spawn workspace policy.

## What This Changes

Add a per-agent `subagents.workspace` config option so default child subagents can use an isolated workspace without defining and targeting a separate agent profile.

## Best Possible Solution

Maintainers should choose the security/product boundary first: either keep explicit target-agent profiles as the supported isolation model, or add a narrow opt-in default-child workspace config with schema, docs, doctor/security review, and regression coverage for same-agent, cross-agent, cwd, and sandbox paths.
