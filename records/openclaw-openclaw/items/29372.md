## Summary

Keep open: current main and v2026.6.11 still do not support `agents.list[].subagents.workspace`; the existing paths are explicit child agent profiles, `requireAgentId`, sandbox policy, and per-call `cwd`, so the requested default-child workspace override remains a product and security-boundary decision.

## What This Changes

Request adding `agents.list[].subagents.workspace` so default child subagents spawned without `agentId` can use a configured child workspace instead of inheriting the parent workspace.

## Best Possible Solution

Maintainers should choose the supported isolation model first: keep explicit child profiles plus `requireAgentId`, or approve a narrow opt-in `subagents.workspace` contract with schema, docs, doctor/security review, and regression coverage across same-agent, cross-agent, `cwd`, and sandbox paths.
