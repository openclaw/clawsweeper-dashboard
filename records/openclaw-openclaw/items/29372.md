## Summary

Keep open: current main and v2026.6.11 still lack `agents.list[].subagents.workspace`; the remaining decision is whether OpenClaw should add a new security-sensitive config surface or keep explicit child agent profiles plus `requireAgentId` as the supported isolation model.

## What This Changes

Request adds `agents.list[].subagents.workspace` to set the workspace for default child subagents spawned without `agentId`.

## Best Possible Solution

Maintainers should choose the product boundary first: either document explicit target profiles with `requireAgentId` as the supported isolation model, or add a narrow opt-in `subagents.workspace` config with schema, docs, doctor/security review, and regression coverage for same-agent, cross-agent, `cwd`, and sandbox paths.
