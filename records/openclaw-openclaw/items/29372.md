## Summary

Keep open: current `main` still lacks `agents.list[].subagents.workspace`; same-agent default child spawns inherit the requester workspace, while current mitigations are explicit child profiles, `subagents.requireAgentId`, sandbox workspace policy, and per-call `cwd`.

## What This Changes

Request a per-agent `subagents.workspace` config option so default child subagents spawned without `agentId` can use a separate workspace from the parent agent.

## Best Possible Solution

Maintainers should choose the supported isolation model first: keep explicit child profiles plus `requireAgentId`, or approve a narrow opt-in `subagents.workspace` contract with schema, docs, doctor/security review, and regression coverage across same-agent, cross-agent, `cwd`, and sandbox paths.
