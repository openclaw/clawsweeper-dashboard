## Summary

Keep open: current main still lacks the requested per-agent child workspace override, and the merged `requireAgentId` and cross-agent workspace fixes only cover adjacent mitigations.

## What This Changes

Add an `agents.list[].subagents.workspace` option so default child subagents can use a configured workspace instead of inheriting the parent agent workspace.

## Best Possible Solution

Define a maintainer-approved opt-in child-workspace isolation contract across config schema, spawn resolution, docs, and tests, with explicit precedence against `agentId`, `cwd`, sandbox settings, and existing profile-based isolation.

## Solution Assessment

Unclear: the per-agent override is plausible, but maintainers still need to choose the exact security boundary and precedence. The existing explicit-profile plus `requireAgentId` path is a mitigation, not the same UX or isolation contract.
