## Summary

Keep open: current main and v2026.6.11 still do not support per-agent `subagents.workspace`; related merged work only added `requireAgentId`, fixed explicit cross-agent workspace inheritance, and added per-call `cwd`, so the remaining request is a product/security-boundary decision.

## What This Changes

Request to add `agents.list[].subagents.workspace` so same-agent default subagents can use a different workspace from their parent without separate agent profiles.

## Best Possible Solution

Maintain a documented isolation model: either keep explicit target-agent profiles plus `requireAgentId`, or approve a narrow opt-in `subagents.workspace` contract with schema, docs, doctor/security review, and regression coverage across same-agent, cross-agent, `cwd`, sandbox, and ACP/native paths.
