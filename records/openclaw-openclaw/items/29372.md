## Summary

Keep open: current main and v2026.6.11 still do not expose `agents.list[].subagents.workspace`, and source/tests show same-agent default subagents inherit the requester workspace. ## What This Changes

Requested a per-agent `subagents.workspace` config option so default child subagents can use an isolated workspace without separate child agent profiles.

## Best Possible Solution

Choose one canonical isolation policy: either document and harden explicit child agent profiles with `requireAgentId`/sandbox guidance, or add a narrow opt-in `agents.list[].subagents.workspace` contract with schema, docs, security review, and focused spawn tests.
