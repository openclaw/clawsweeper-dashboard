## Summary

Keep open: current main and v2026.6.11 still do not support `agents.list[].subagents.workspace`; the remaining decision is whether OpenClaw should add a new public, security-sensitive workspace-boundary config or keep explicit child agent profiles plus `requireAgentId` as the supported isolation model.

## What This Changes

This issue requests an `agents.list[].subagents.workspace` config option so default child subagents spawned without `agentId` can use a workspace separate from the parent agent.

## Best Possible Solution

Maintainers should choose the supported isolation model first; if approved, implement a narrow opt-in `subagents.workspace` contract with schema, docs, doctor/security review, and focused same-agent, cross-agent, `cwd`, and sandbox coverage.
