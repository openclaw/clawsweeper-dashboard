## Summary

Keep open: current main still does not implement a per-agent `subagents.workspace` override, and the existing `requireAgentId` path only forces explicit child profiles rather than providing an isolated default-subagent workspace.

## What This Changes

Request to add a per-agent subagent workspace override so default child subagents can use an isolated workspace instead of inheriting the parent agent workspace.

## Best Possible Solution

Define one opt-in child-workspace isolation contract across config, spawn resolution, docs, and tests, preserving current inheritance unless maintainers choose a migration.

## Reproduction Assessment

Yes, at source level: current main omits `subagents.workspace` from the strict config schema and same-agent omitted-agent spawns still inherit `ctx.workspaceDir`. I did not run a live spawn because this is a read-only review.

## Solution Assessment

Unclear: a per-agent `subagents.workspace` override is plausible, but maintainers still need to choose precedence and the exact isolation boundary. The supported existing mitigation is explicit child agent profiles with `agentId` and optional `requireAgentId`, which is not the same UX.
