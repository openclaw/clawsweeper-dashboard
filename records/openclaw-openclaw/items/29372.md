## Summary

Keep open for maintainer product/security review: current main still lacks `agents.list[].subagents.workspace`, while the shipped controls are explicit target agents, `requireAgentId`, sandbox policy, and per-call `cwd`.

## What This Changes

Request to add `agents.list[].subagents.workspace` so default child subagents spawned without `agentId` can use a configured child workspace instead of inheriting the parent workspace.

## Best Possible Solution

Maintainers should choose the workspace-boundary policy first, then either preserve explicit child profiles as the supported isolation model or add a narrow opt-in `subagents.workspace` with schema, docs, doctor/security review, and regression coverage.
