## Summary

Keep open: current main still does not implement a per-agent `subagents.workspace` override, and the supported `requireAgentId` mitigation only blocks omitted-agent spawns rather than giving default subagents an isolated workspace. The linked Plur1bus memory plugin is useful adjacent context, but it does not replace the missing core config/runtime contract.

## What This Changes

The issue requests a per-agent `subagents.workspace` config option so default spawned subagents can use an isolated workspace instead of inheriting the parent agent workspace.

## Best Possible Solution

Define one opt-in child-workspace isolation contract across config, spawn resolution, docs, and tests, preserving current inheritance unless maintainers choose a migration.

## Reproduction Assessment

Yes, at source level: current main omits `subagents.workspace` from the strict config schema and same-agent omitted-agent spawns still pass `ctx.workspaceDir` as the inherited workspace. I did not run a live spawn because this is a read-only review.

## Solution Assessment

Unclear: the requested override is plausible, but maintainers still need to define precedence and whether it covers only bootstrap workspace or also cwd, sandbox, attachments, and resumed sessions.
