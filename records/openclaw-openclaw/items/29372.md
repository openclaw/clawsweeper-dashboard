## Summary

Keep open: current main and v2026.6.11 still do not support `agents.list[].subagents.workspace`, and the remaining choice is a public, security-sensitive workspace-boundary product decision. The linked PLUR1BUS memory plugin is useful adjacent per-agent isolation context, but it isolates memory namespaces rather than replacing OpenClaw's missing default-child workspace config.

## What This Changes

Request adds `agents.list[].subagents.workspace` so default child subagents can use a separate workspace without requiring a separate child agent profile.

## Best Possible Solution

Maintainers should choose the supported isolation model first: keep explicit child profiles plus `requireAgentId`, or approve a narrow opt-in `subagents.workspace` contract with schema, docs, doctor/security review, and focused workspace regression coverage.
