## Best Possible Solution

Decide a narrow opt-in child workspace policy first; if accepted, implement schema, docs, doctor/config guidance, and subagent runtime tests while preserving explicit `agentId`, `cwd`, sandbox, and gateway-boundary behavior.

## Reproduction Assessment

## Solution Assessment

Unclear: the proposed config is plausible, but existing explicit child profiles, `requireAgentId`, per-call `cwd`, and sandbox workspace controls are supported mitigations. Maintainers should decide whether another config key is the right security/ergonomics tradeoff.
