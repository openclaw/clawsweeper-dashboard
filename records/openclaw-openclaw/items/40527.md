## Summary

Keep open: current main and the latest release still have the macOS remote skill-bin probe/readiness shape that can hit this timeout, while the linked repair PRs are open/conflicting or not safe canonical fixes.

## What This Changes

The issue reports timeout and warning spam when remote skill-bin probing runs against macOS app-backed nodes, especially when app and gateway are co-located.

## Best Possible Solution

Keep the macOS app node exec contract intact, make remote skill-bin refresh readiness-aware with bounded deferral/backoff, and require live proof for both co-located and remote macOS app nodes.
