Keep open: current main has partial mitigations and macOS handlers, but the active runtime still probes app-backed macOS nodes immediately on connect/reconnect, and no merged related PR settles the remaining readiness, co-location, or backoff policy.

## What This Changes

The issue reports remote macOS app-backed node skill-bin probes timing out or warning during gateway startup and reconnect, especially when the app node is co-located with the gateway.

## Best Possible Solution

Settle the macOS app-node readiness and remote-bin probe policy in the active runtime so probes wait, skip only proven co-located non-exec cases, or back off cleanly while preserving valid remote node execution.
