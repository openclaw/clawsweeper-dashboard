## Summary

Keep open: current main preserves the macOS app-node exec contract and still starts automatic remote-bin probes on node connect, while the live comments and related PRs show the remaining timing/co-location policy has not been resolved by a merged fix.

## What This Changes

The issue asks OpenClaw to stop remote skill bin probes from timing out for macOS app-backed nodes, especially when the app node is co-located with the gateway.

## Best Possible Solution

Preserve documented macOS app-node exec commands while moving the remote-bin probe to a readiness/backoff or proven co-located skip policy in the active runtime, with real macOS app-node proof.

- **Disable App-node Probing By Default:** Make automatic app-node remote skill probing opt-in, reducing warnings but weakening default remote macOS skill support.
