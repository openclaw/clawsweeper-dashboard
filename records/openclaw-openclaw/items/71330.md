## What This Changes

Request to add a memory-core promotion destination configuration so short-term promotions can write somewhere other than `MEMORY.md` while remaining searchable.

## Best Possible Solution

Define one memory-core promotion routing contract with safe workspace-relative destinations, canonical lanes where possible, search/index coverage, lifecycle metadata, docs/schema alignment, and focused upgrade tests.
