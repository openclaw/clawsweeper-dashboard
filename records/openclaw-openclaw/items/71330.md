## Best Possible Solution

Define one memory-core promotion routing contract with canonical lanes plus safe customization, including workspace-relative path validation, date-token rules, frontmatter behavior, docs/schema alignment, lifecycle metadata, and `memory_search` coverage for every supported destination.

## Reproduction Assessment

## Solution Assessment

Unclear. A configurable target addresses the immediate report, but the best maintainable fix likely needs a canonical lane/routing design rather than a raw free-form path knob.
