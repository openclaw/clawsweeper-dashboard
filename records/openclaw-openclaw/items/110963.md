Keep open for explicit native-app ownership and product direction: the web bridge is merged, but the requested iOS/macOS/Android producers are not evidenced as implemented on current `main`; the `maintainer` label also requires human handling.

## What This Changes

Add native iOS, macOS, and Android web-view producers that send the existing `openclaw:widget-theme` snapshot to `show_widget` documents.

## Best Possible Solution

Implement platform-owned native web-view injection from each app’s active theme system, reuse the current full token allowlist and snapshot semantics, and add focused native integration proof for forced modes and custom theme families.
