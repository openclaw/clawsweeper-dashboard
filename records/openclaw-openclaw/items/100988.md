## Summary

This issue should stay open: current main and the latest release still persist a restrictive bridge-visible inherited allowlist onto spawned child sessions, and the child path later applies that stored allowlist as a real tool policy. The bug is source-reproducible, but the fix needs an explicit security-boundary decision so CLI-harness native capability is not confused with genuine parent restrictions.

## What This Changes

CLI-harness parent sessions should not pass a bridge-only OpenClaw-visible tool allowlist to spawned embedded child sessions in a way that strips the child's configured coding tools.

## Best Possible Solution

Represent the parent CLI harness's actual native tool capability separately from the OpenClaw bridge-visible tool list, while preserving explicit operator denies and true restrictive policies for spawned children.

Options:

- **Add native-capability inheritance (recommended):** Model CLI-harness native file/shell capability as a prepared fact and inherit that for child allowlists while preserving explicit denies and real restrictive config policies.
- **Exempt bridge-only allowlists:** Do not capture runtime bridge allowlists from native CLI parents, which is simpler but may miss future harnesses with genuinely narrower native capability.
- **Add an operator switch:** Expose inheritance mode as config, which gives operators control but adds new surface in an already security-sensitive tool-policy area.

## Reproduction Assessment

Yes, from source inspection: a bridge-only inherited allowlist is stored on the child and later becomes an allow policy during embedded child tool construction. I did not run the live claude-cli probe, so this is source-reproducible rather than live-reproduced.

## Solution Assessment

No final implementation should be chosen without a maintainer security-boundary decision. Removing inherited allowlist propagation wholesale is too broad; the maintainable direction is a narrow runtime-policy distinction between native CLI capability and real configured restrictions.
