## What This Changes

This PR makes `agents.defaults.modelPolicy.allow` accept provider/model references padded around separators, while preserving rejection of whitespace inside resolved identifiers and preserving nested wildcard scope.

## System Context

Model policy is read from OpenClaw configuration during startup and determines which provider/model keys agents may use. The configuration validator feeds the model-visibility policy, which then classifies exact references and namespace-scoped wildcards before model selection.
