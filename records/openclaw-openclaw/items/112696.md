## What This Changes

The issue reports that upgrading to 2026.7.1-2 broke multi-agent Control UI avatars, sidebar session selection/status/filtering, Edge PWA behavior, and cross-channel session-corpus search.

## System Context

The Control UI obtains identity and session data from the Gateway, then renders avatar, session-picker, and running-state information in the browser. Separately, session-search tools query stored transcripts through a visibility policy, so cross-channel retrieval can have a different cause from the UI regressions.
