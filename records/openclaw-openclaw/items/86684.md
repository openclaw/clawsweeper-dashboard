## Summary

Keep open: current main has partial usage-accounting and context-snapshot safeguards, but the central issue is not fully implemented because successful-turn overflow still has an aggregate-input fallback when no trusted context snapshot exists, and compaction transcript entries still lack the requested trigger/cause metadata.

## What This Changes

The issue requests that subagent completion or sessions_yield wake handling not compact a low-usage parent session, and asks for persisted compaction trigger attribution.

## Best Possible Solution

Harden compaction so yielded parent wake and successful-turn overflow paths rely on trusted context snapshots or explicit overflow signals, persist a bounded compaction cause enum if maintainers approve that schema, and prove the behavior with a focused subagent/yield regression plus live long-context evidence.
