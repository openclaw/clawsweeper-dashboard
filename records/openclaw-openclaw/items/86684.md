## Summary

Keep open: current main narrows some usage accounting paths, but the successful-turn overflow classifier still falls back to raw `usage.input + cacheRead` when no explicit context snapshot exists, and persisted compaction entries still lack the requested trigger/cause metadata.

## What This Changes

The issue reports premature parent-session compaction during `sessions_yield` subagent wake/direct-announce handling, plus a request to record compaction trigger metadata.

## Best Possible Solution

Keep this focused issue open until the overflow decision uses trusted per-turn context snapshots, yielded subagent wake compactions are not triggered by aggregate child usage, and compaction entries persist a closed trigger reason.
