## Summary

Current main contains the July 5 Anthropic context-accounting repair, but a non-CLI session-store fallback still uses aggregate run usage when the last call lacks `contextUsage`. The focused open fix at https://github.com/openclaw/openclaw/pull/108272 addresses that remaining path, so this issue remains necessary until the candidate lands and the original `sessions_yield` wake scenario is reverified.

## What This Changes

Prevent subagent completion or `sessions_yield` wake handling from compacting a parent session at low real context usage, and improve compaction-cause attribution.

## Best Possible Solution

Land the last-call context snapshot fix with focused session-store coverage and a live spawn → yield → child-completion proof, then consider compaction-trigger metadata as a separate diagnostic enhancement.
