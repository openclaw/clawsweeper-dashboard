## Summary

Keep open: current main reduces the inflated successful-turn overflow path by honoring `contextUsage`, but the issue is not fully fixed because OpenAI-compatible usage paths still lack a context snapshot and compaction records still cannot identify the trigger that compacted the yielded parent branch.

## What This Changes

Reported regression where a yielded parent session can be auto-compacted during subagent wake/direct-announce despite low visible context usage, with a request for compaction trigger attribution.

## Best Possible Solution

Use a trustworthy last-call/context snapshot or explicit unavailable marker for all parent-wake compaction decisions, persist a closed compaction trigger reason, and prove the subagent-yield wake path live before closing.
