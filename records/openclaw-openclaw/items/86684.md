## Summary

Keep open: current main has partial usage-accounting guards, but it still does not fully satisfy the reported behavior because persisted compaction entries lack trigger/cause metadata and the successful-turn compaction path still needs maintainer-approved policy for untrusted usage snapshots.

## What This Changes

Prevent subagent completion or `sessions_yield` wake-ups from compacting a parent session far below its context limit and record why each compaction was triggered.

## Best Possible Solution

Tighten OpenClaw-owned compaction decisions so successful-turn auto-compaction uses only trustworthy current-context snapshots or content estimates, persist an auditable compaction reason, and prove the fix with a live subagent-yield wake replay.
