## Summary

Keep open: current main partially mitigates the inflated successful-turn usage path when context snapshots are present, but the fallback overflow predicate and transcript compaction metadata gaps still leave the reported subagent/yield compaction failure unresolved.

## What This Changes

The issue requests fixing subagent-yield compaction so successful completion wakes do not trigger spurious overflow compaction or lose exact parent context, and adding trigger metadata to compaction transcript entries.

## Best Possible Solution

Make successful-turn overflow depend on trustworthy last-call/context-window evidence, persist a closed compaction trigger reason in transcript entries, and prove the subagent-yield wake path on current main and a shipped upgrade path.
