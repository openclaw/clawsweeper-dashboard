## Summary

The exact-head patch is a focused and well-proven fix for the linked launchd outage: it reuses the established detached handoff, yields to a healthy KeepAlive replacement, actively revives an inert job, and retains in-process fallback when helper startup fails. No actionable correctness or security finding remains; the PR should stay open for ordinary maintainer approval and completion of the still-running exact-head checks.

## What This Changes

The PR adds a PID-aware launchd `kickstart-if-dead` handoff, confirms detached-helper startup before gateway exit, falls back to an in-process restart on spawn failure, and expands launchd restart regression tests.

## Best Possible Solution

Keep one launchd-owned restart path that waits for the exiting gateway, yields when KeepAlive already produced a healthy replacement, actively kickstarts an inert job, and resumes in process if the detached helper cannot start; merge this implementation after exact-head gates and lifecycle-owner approval.
