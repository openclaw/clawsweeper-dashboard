## Summary

This PR addresses a reproduced P0 gateway-availability bug at the correct launchd owner boundary, but it is not merge-ready because the forced restart mode can disrupt a healthy replacement and the new test mock fails typechecking.

## What This Changes

The PR changes launchd-supervised gateway restarts to schedule the existing detached launchctl handoff before exit and adds regression tests for launchd detection and scheduling failure.

## Best Possible Solution

Add a PID-gated ensure-running launchd handoff that starts an inactive job without killing an already-running KeepAlive replacement, retains bootstrap fallback for unloaded jobs, and type the test mock against the helper contract.
