## Summary

This issue is a duplicate of the open canonical report for unwanted persisted cron `toolsAllow` state. Its no-global-allowlist A/B is useful confirming evidence, but the remaining repair boundary—preventing inherited/stamped job policy and allowing it to be cleared—is already tracked in the canonical issue.

## What This Changes

The issue requests that isolated `agentTurn` cron jobs retain core tools unless an operator explicitly configured a per-job or global tool restriction.

## System Context

Isolated cron jobs persist an `agentTurn` payload, including an optional per-job tool policy. At execution time, that policy is combined with the resolved tool inventory before the embedded agent receives its callable tools.
