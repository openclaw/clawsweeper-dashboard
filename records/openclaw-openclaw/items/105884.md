## Summary

This PR remains necessary, but the current head still applies the configured request policy completely only to submission; polling and generated-asset retrieval can bypass the configured dispatcher or private-network policy, and the loopback proof does not exercise external routing.

## What This Changes

Applies the configured Vydra provider request settings during image and video request-context resolution and adds mocked plus loopback HTTP regression tests.

## Best Possible Solution

Carry the resolved SSRF and dispatcher policy through submission, polling, result retrieval, and asset download using one canonical request context, while keeping authorization and provider headers scoped to trusted Vydra endpoints; add focused stage-by-stage tests and redacted external-routing proof.
