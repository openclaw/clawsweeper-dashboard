## Summary

This PR remains necessary, but the current head still leaves the runtime SSRF policy out of the video and speech follow-up request policies. Those are the same security-boundary gaps identified in the prior review cycle, so the patch is not ready to merge until they are repaired and exact-head controlled runtime proof is refreshed.

## What This Changes

The PR refactors Vydra image, video, and speech media flows to reuse configured request policy for submission, polling, and same-origin generated-media downloads while stripping configured headers for cross-origin assets.

## Best Possible Solution

Carry req.ssrfPolicy into every Vydra prepared request policy, pass it to video submission as well as polling/downloads, then publish redacted controlled submit→poll→download output captured from the repaired exact head.
