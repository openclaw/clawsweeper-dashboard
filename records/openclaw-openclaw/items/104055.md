- **[P1] Preserve the configured character ceiling:** `src/agents/embedded-agent-runner/tool-result-truncation.ts:348-351`
  - body: `getToolResultTextLength` now feeds CJK-weighted estimates into every caller, including the path using `agents.*.contextLimits.toolResultMaxChars`. That setting is documented as a character ceiling and currently compares against physical `text.length`; after this change an existing value such as 8000 can keep only about 2000 dense-CJK characters.   - confidence: 0.96
- **[P2] Keep the minimum within the adjusted CJK budget:** `src/agents/embedded-agent-runner/tool-result-truncation.ts:403-408`
  - body: For dense CJK under a small cap, `physicalBudget` is roughly `maxChars / 4`, but `Math.max(minKeepChars, physicalBudget)` raises it toward the physical 2000-character floor. A 1000 estimated-character cap can therefore retain roughly 900 CJK characters plus the suffix, leaving the estimated length far above 1000. Clamp the effective minimum to this block's adjusted physical allocation and add a small-cap CJK regression.
  - confidence: 0.98
