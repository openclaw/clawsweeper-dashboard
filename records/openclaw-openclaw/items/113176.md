## What This Changes

The PR makes Google Chat authentication fall back to lowercase `no_proxy` when uppercase `NO_PROXY` is blank, and adds a regression test for bypassing a configured proxy.

## System Context

Google Chat authentication builds a guarded HTTP transport for Google token requests. Proxy and bypass environment values feed that transport, which decides whether an authentication request uses a proxy dispatcher or connects directly.
