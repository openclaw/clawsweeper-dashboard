## Summary

## What This Changes

Expose a supported Plugin SDK path for channel plugins to remove injected inbound metadata from generated output without copying the core sanitizer.

## Best Possible Solution

Choose one supported channel-plugin delivery contract: first verify whether plugins can use the existing `channel-inbound` dispatch path for sanitized output; if that cannot meet external channel needs, add a narrow documented SDK subpath with focused compatibility tests instead of exporting the internal parser from the root barrel.
