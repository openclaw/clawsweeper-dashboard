## Summary

Keep open: current main still has the one-shot Claude CLI parser/decoder gaps described in the issue, and the open synthetic-placeholder PR only covers an overlapping subset rather than this broader `is_error`, raw fallback, line-buffer, and POSIX decoding bundle.

## What This Changes

The issue asks OpenClaw to unify Claude CLI one-shot output classification with live-session behavior for error results, raw stream-json fallback, streaming line limits, and incremental UTF-8 decoding.

## Best Possible Solution

Land one focused runtime fix that normalizes Claude CLI one-shot errors into `errorText`, removes raw stream-json fallback for structured dialects, caps pending JSONL lines consistently with live sessions, and uses incremental UTF-8 decoding on every platform.

## Solution Assessment
