- `P0`: Current main permits a channel-scoped sender to cross an owner authorization boundary and persist configuration changes for another channel.

## Summary

Keep open: the central security fix is necessary, but this patch also revokes two established owner-authority paths—trusted context owner overrides and explicit owner wildcards—and lacks after-fix proof from a real channel setup.

## What This Changes

Separates channel command allowlists from global owner authority, ignores wildcard owner entries, updates doctor detection, documentation, and authorization tests.

## Best Possible Solution

Narrow owner derivation so explicit `commands.ownerAllowFrom`, trusted `OwnerAllowFrom` context metadata, and internal `operator.admin` remain owner authorities, while channel allowlists authorize only ordinary commands; preserve the shipped owner-wildcard behavior unless it is separately deprecated with migration and upgrade proof.
