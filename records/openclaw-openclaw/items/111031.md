## What This Changes

This PR replaces the shared heartbeat running flag with generation-owned execution state so a retired wake handler cannot alter the active replacement handler’s timer, retry, execution slot, or unattempted wake batch.

## System Context

Heartbeat wake scheduling collects requests from intervals and lifecycle hooks, coalesces them by target, and calls the active handler to admit agent work. Handler completion then controls retries, timers, and delivery of any remaining pending wakes.
