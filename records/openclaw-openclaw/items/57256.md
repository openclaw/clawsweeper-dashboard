Keep open. ## What This Changes

This issue asks for `openclaw status --deep` and doctor/status memory diagnostics to report a working live memory plugin as healthy instead of unavailable when gateway memory operations succeed.

## Best Possible Solution

Settle one canonical status contract where memory status is read-only, prefers live gateway runtime health when available, distinguishes runtime health from embedding readiness, and avoids heavyweight local plugin startup side effects.
