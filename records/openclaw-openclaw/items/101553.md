## Repair Work Prompt

Fix the Gateway `agents.delete` cleanup fanout reported in https://github.com/openclaw/openclaw/issues/101553. In `src/gateway/server-methods/agents.ts`, replace the unbounded `Promise.all(pathsToTrash.map(...))` with the existing `runTasksWithConcurrency` helper or an equally local bounded worker pattern. Preserve current behavior: `deleteFiles=false` skips cleanup, shared workspaces are not trashed, workspace attestations are only trashed when `shouldRemoveWorkspaceAttestation` allows them, and `moveToTrashBestEffort` remains best-effort without surfacing per-path trash failures to the RPC response. Do not add a config option, env var, dependency, fallback trash policy, or hard-delete behavior. Add focused coverage in `src/gateway/server-methods/agents-mutate.test.ts` that creates enough cleanup targets to prove the trash calls never exceed the chosen limit and that the existing delete/shared-workspace cases still pass.
