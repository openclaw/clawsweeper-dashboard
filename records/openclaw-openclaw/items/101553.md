## Summary

Current main and the latest release do not match the reported failure mechanism: Gateway agent deletion still uses `Promise.all`, but the list is a small fixed set and trash errors are best-effort, so the claimed unbounded bulk unlink crash is not reproducible from source.

## What This Changes

The issue reports that Gateway `agents.delete` can crash during cleanup because `Promise.all` allegedly launches unbounded file trash operations for thousands of attestation files.

## Best Possible Solution

Keep the current bounded cleanup behavior; if maintainers still want style consistency, serialize the small Gateway trash list like the CLI without treating it as a crash fix.
