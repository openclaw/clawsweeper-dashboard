## Best Possible Solution

Run a packaged Windows v2026.6.11 install/start reproduction and inspect the real Scheduled Task XML; if it still targets `gateway.cmd`, fix the package, upgrade, or start/repair path so gateway tasks consistently launch through `gateway.vbs` or another approved silent launcher.
