## Summary

Keep open: the revision fixes the missing-Content-Length streamless case, but it still trusts declared Content-Length, so an underreported streamless body can reach the shared `arrayBuffer()` fallback and allocate before the cap.

## What This Changes

This PR routes hosted external plugin catalog response reads through `readResponseWithLimit`, adds oversized stream-backed and streamless regression tests, and commits a loopback proof script.

## Best Possible Solution

Use the shared reader for stream-backed responses, but fail closed before `arrayBuffer()` for streamless hosted catalog responses unless a truly bounded non-streaming path can be proven, then cover missing and underreported Content-Length cases.
