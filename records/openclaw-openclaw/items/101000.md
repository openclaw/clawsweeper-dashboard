## Summary

Keep open for maintainer review: the patch fixes a source-visible unbounded streamless hosted feed read and has sufficient terminal proof, but the fail-closed streamless behavior is an availability tradeoff maintainers should explicitly accept.

## What This Changes

The PR replaces the hosted external plugin catalog's custom response-reading loop with `readResponseWithLimit`, rejects streamless hosted feed responses before buffering, adds regression tests, and adds a loopback proof script.

## Best Possible Solution

Merge after maintainers accept fail-closed streamless hosted feed fallback and exact-head checks pass; otherwise require a bounded streamless design before merge.
