## Summary

Keep open: the prior P1 blocker remains because current head still trusts declared Content-Length for streamless responses and then reaches the shared helper's `arrayBuffer()` fallback before enforcing the byte cap. The updated proof text claims the underreported case, but the committed proof script does not exercise that path.

## What This Changes

The branch replaces hosted external plugin catalog response reading with `readResponseWithLimit`, adds regression tests, and adds a loopback proof script for oversized hosted feed reads.

## Best Possible Solution

Fail closed before `arrayBuffer()` for untrusted streamless hosted catalog responses, or add a proven bounded streamless reader, then cover missing and underreported Content-Length cases with regression and terminal proof.
