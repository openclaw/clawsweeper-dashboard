## Summary

Keep open for maintainer review: current main still has the unsafe streamless hosted feed read, and this PR fixes it with focused tests and terminal proof, but it intentionally makes streamless hosted responses fall back instead of loading hosted data.

## What This Changes

The branch routes hosted external plugin catalog response reads through the shared bounded HTTP helper, rejects streamless responses before buffering, and adds regression/proof coverage.

## Best Possible Solution

Merge after maintainers accept fail-closed streamless hosted feed fallback; otherwise require a bounded streamless design that does not trust `Content-Length` or buffer untrusted bodies.
