## What This Changes

The PR routes hosted external plugin catalog reads through `readResponseWithLimit`, rejects streamless hosted feed responses before whole-body buffering, and adds regression tests for streamless and oversized responses.

## Best Possible Solution

Land the fail-closed catalog reader after maintainer acceptance; if streamless hosted-feed availability is required, replace this with a bounded streamless design that never trusts headers or buffers the whole body.
