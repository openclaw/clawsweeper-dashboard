## What This Changes

This PR routes hosted external plugin catalog response reads through the shared bounded reader, rejects streamless hosted feed responses before buffering, and adds regression plus loopback proof coverage.

## Best Possible Solution

Merge after exact-head checks if maintainers accept fail-closed streamless hosted feed handling; keep streaming reads on the shared bounded helper and rely on snapshot or bundled fallback when a fetch implementation cannot provide a stream.
