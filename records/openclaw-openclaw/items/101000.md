## What This Changes

The branch replaces the hosted plugin catalog's custom streaming read loop with `readResponseWithLimit`, rejects streamless responses before body buffering, and adds regression/proof coverage.

## Best Possible Solution

Merge after maintainers accept the fail-closed streamless hosted feed fallback and exact-head checks are clean, or require a bounded streamless design that avoids trusting `Content-Length` and avoids whole-body buffering.
