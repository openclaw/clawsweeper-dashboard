## What This Changes

The branch changes the Zalo send decision so whitespace-only optional media does not override usable text, while retaining the existing rejection for a blank photo with no text.

## System Context

Zalo is a bundled channel plugin that converts portable message-tool actions into Zalo Bot API text or photo requests. The send helper receives the action parameters, chooses the appropriate API endpoint, and returns a delivery receipt to the channel runtime.
