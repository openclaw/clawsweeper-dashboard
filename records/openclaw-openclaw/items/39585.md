## What This Changes

The issue requests an opt-in trusted-owner mode that lets explicitly allowlisted Telegram group owners bypass approval prompts for configured privileged action classes with auditability.

## Best Possible Solution

Design a disabled-by-default shared trusted-owner approval policy that composes with Telegram group authorization, elevated and exec approval policy, action-class/destructive-operation rules, audit records, docs, and live Telegram proof.
