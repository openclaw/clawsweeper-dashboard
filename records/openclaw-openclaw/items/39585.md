## Summary

Keep open. Current main and v2026.6.11 still do not provide a scoped Telegram trusted-owner approval bypass; the existing owner-approver path and `/elevated full` shortcut are adjacent controls, not the requested group/sender/tool-class policy.

## What This Changes

Request an opt-in Telegram group mode that lets explicitly trusted owners bypass approval prompts for configured privileged action classes while preserving auditability and safety fallbacks.

## Best Possible Solution

Design a disabled-by-default trusted-owner execution policy that composes with Telegram group authorization, existing elevated and approval policy, tool-class/destructive-operation rules, audit records, docs, and live Telegram proof.

- **Add Telegram-only shortcut:** Implement the proposed Telegram config directly, accepting a smaller patch but higher risk of policy drift from shared approvals and elevated execution.
