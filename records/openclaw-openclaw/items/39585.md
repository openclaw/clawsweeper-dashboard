## Summary

Keep open. Current main and v2026.6.11 still do not implement a Telegram trusted-owner approval bypass; the existing ownerAllowFrom path makes owners approvers, while /elevated full is a broad exec policy and not the requested group/sender/tool-class bypass.

## What This Changes

Requests an opt-in trusted-owner mode so allowlisted Telegram group owners can bypass approval prompts for configured privileged action classes with audit logging.

## Best Possible Solution

Design a disabled-by-default shared trusted-owner approval policy that composes with Telegram group authorization, existing elevated and approval policy, action-class/destructive-operation rules, audit records, docs, and live Telegram proof.
