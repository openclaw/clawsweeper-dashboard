## Summary

Keep open. Current main and v2026.6.11 still do not implement a Telegram trusted-owner approval bypass; the existing Telegram owner path makes owners approvers, while elevated full is a broader exec policy that is not scoped to sender, allowlisted group, tool class, destructive-operation fallback, or bypass audit.

## What This Changes

Request an opt-in Telegram group mode that lets explicitly allowlisted owners bypass approval prompts for configured privileged action classes while preserving auditability and safety limits.

## Best Possible Solution

Design a disabled-by-default shared trusted-owner approval policy that composes with Telegram group authorization, elevated and approval policy, action-class and destructive-operation rules, audit records, docs, and live Telegram proof.
