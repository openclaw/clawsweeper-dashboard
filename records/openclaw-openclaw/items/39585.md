## Summary

Keep open. Current main and the latest release still only route Telegram exec/plugin approval prompts to configured approvers; they do not implement a sender-and-group-scoped trusted-owner bypass, and adding one is a security/config product decision rather than conservative cleanup.

## What This Changes

The issue requests an opt-in Telegram group mode that lets explicitly trusted owners bypass approval gates for selected tool classes while preserving group allowlisting and auditability.

## Best Possible Solution

Define a maintainer-approved shared trusted-owner execution policy that composes with Telegram group authorization, existing exec/elevated/plugin approvals, explicit tool-class rules, destructive-operation handling, audit records, docs, and Telegram proof.
