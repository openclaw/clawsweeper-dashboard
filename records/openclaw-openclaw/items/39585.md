## Summary

Keep open: current main and v2026.6.11 still lack the requested opt-in Telegram trusted-owner approval bypass, and adding it would change a privileged execution approval boundary rather than clean up an obsolete issue.

## What This Changes

The issue requests an opt-in Telegram trusted-owner mode that bypasses approval prompts for allowlisted owners in allowlisted group chats for selected tool classes, with audit logging and safety gates.

## Best Possible Solution

Design a maintainer-approved shared trusted-owner execution policy that composes with Telegram group authorization, existing exec/elevated and plugin approvals, tool-class gates, destructive-operation handling, audit records, docs, and Telegram proof.
