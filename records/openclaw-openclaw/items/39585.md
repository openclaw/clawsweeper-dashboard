## Summary

Keep open. Current main and v2026.6.11 still do not implement a Telegram trusted-owner approval bypass; existing Telegram owner IDs authorize approval actions, while broad elevated full mode is not the requested group/sender/tool-class bypass.

## What This Changes

The issue requests an opt-in Telegram group mode that lets explicitly trusted owners bypass approval prompts for selected privileged tool classes while preserving auditability.

## Best Possible Solution

Design a disabled-by-default shared trusted-owner approval policy that composes with Telegram group authorization, elevated and approval policy, action-class/destructive-operation rules, audit records, docs, and live Telegram proof.
