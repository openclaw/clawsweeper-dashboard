## Summary

Keep open: current main and the latest release still lack a Telegram trusted-owner approval-bypass mode, and the request intentionally changes a security boundary rather than reporting broken existing behavior.

## What This Changes

The issue requests an opt-in Telegram group mode that lets explicitly trusted owners bypass approval gates for configured privileged action classes while preserving group allowlists and auditability.

## Best Possible Solution

Design a disabled-by-default shared trusted-owner approval policy that composes with Telegram group authorization, elevated and approval policy, action-class and destructive-operation rules, audit records, docs, and live Telegram proof.
