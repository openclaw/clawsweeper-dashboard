## Best Possible Solution

Decide the approval-boundary policy first, then either document existing `tools.elevated` and `/elevated full` as the supported trusted-owner workflow or implement a narrow opt-in shared policy with group, owner, tool-class, destructive-op, audit, docs, and Telegram proof.
