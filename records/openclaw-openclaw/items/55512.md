## Summary

Keep open. Current main and the latest release still measure Markdown code-table widths and padding with UTF-16 string length, so CJK table columns can remain misaligned; the linked fix PR is still open and targets obsolete `src/markdown` paths rather than the active `packages/markdown-core` renderer.

## What This Changes

Request to render Markdown tables with CJK-aware column widths on Telegram and Discord, including aligned code-block conversion where native tables are unsupported.

## Best Possible Solution

Port display-width measurement and padding into `packages/markdown-core`, add focused CJK and emoji table regression tests, keep Telegram and Discord on the shared converter, and land or replace the linked PR before closing this issue.
