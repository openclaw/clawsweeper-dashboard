Keep open. ## What This Changes

The issue requests CJK-aware markdown table alignment for Telegram and Discord, including code-block conversion where native table rendering is unsupported.

## Best Possible Solution

Port display-width measurement and padding into `packages/markdown-core`, add focused CJK/emoji table tests, keep Telegram and Discord on the shared converter, and land or replace the linked PR before closing this issue.

## Reproduction Assessment

Yes. Source inspection shows current main still measures markdown code-table widths and padding with `cell?.text.length`, and both Telegram and Discord route table output through that shared renderer.

## Solution Assessment
