## Summary

Keep open. Current main and the latest release still measure Markdown code-table columns with JavaScript string length, and the open closing PR remains the implementation candidate but needs to be ported from removed renderer paths to the active markdown-core package.

## What This Changes

The issue reports CJK display-width misalignment in Markdown tables delivered through Telegram and Discord.

## Best Possible Solution

Port display-width-aware width and padding logic into `packages/markdown-core`, keep Telegram and Discord on the shared table converter, and close this issue only after the linked PR is landed, replaced, or explicitly closed with a current-path alternative.
