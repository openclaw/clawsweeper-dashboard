## Summary

Keep open. Current main still uses code-unit length for Markdown code-table width and padding, so CJK cells remain misaligned in the shared Telegram/Discord table-rendering path; the linked closing PR is still open but targets obsolete `src/markdown` files and needs a markdown-core port before this issue can close.

## What This Changes

Fix CJK-width Markdown table alignment for Telegram and Discord by making shared code-table conversion display-width aware.

## Best Possible Solution

Port display-width measurement and padding into `packages/markdown-core`, add focused CJK/emoji table regression coverage, keep Telegram and Discord on the shared converter, and close this issue only after the linked PR is landed, replaced, or closed.

## Reproduction Assessment

Yes, source-level. Current main still measures and pads markdown code-table cells with `cell?.text.length`, and Telegram plus Discord route markdown table conversion through that shared renderer.

## Solution Assessment

Yes for the shared-renderer direction, but not through the stale linked branch as-is. The narrow maintainable fix belongs in `packages/markdown-core` with focused CJK/emoji coverage, not by reviving deleted `src/markdown` files.
