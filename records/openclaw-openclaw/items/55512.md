## Summary

Keep open. Current main and v2026.6.11 still measure Markdown code-table cells with UTF-16 string length, so CJK columns remain misaligned even though Discord now routes tables through the shared code-table converter; the open linked PR is the current implementation candidate but targets obsolete files.

## What This Changes

The issue requests CJK-aware Markdown table rendering for Telegram and Discord, including aligned code-block output where native table rendering is unsupported.

## Best Possible Solution

Port display-width measurement and padding into `packages/markdown-core`, add focused CJK/emoji table regression tests, keep Telegram and Discord on the shared converter, then land or replace https://github.com/openclaw/openclaw/pull/55596 before closing this issue.
