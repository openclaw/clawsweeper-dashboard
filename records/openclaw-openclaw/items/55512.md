## Summary

Keep open: current main and the latest release still size markdown code-table cells with JavaScript string length, and the open linked PR remains the implementation candidate but needs porting from removed `src/markdown` paths.

## What This Changes

Request to make Telegram and Discord markdown table code fallbacks use display-width-aware padding for CJK text.

## Best Possible Solution

Port display-width measurement and padding into `packages/markdown-core`, reuse or mirror the existing visible-width logic where the package boundary allows, add CJK/emoji table tests, and land or replace the linked PR.

## Reproduction Assessment

Yes, source-level: current main still measures code-table cell width and padding with `cell?.text.length`, and both Telegram and Discord route markdown table conversion through that shared renderer. I did not run a live channel repro in this read-only review.

## Solution Assessment
