## What This Changes

Adds a doctor-only recovery for a sibling `moltbot.json` when the canonical config is missing or only metadata, plus a gateway diagnostic hint and regression tests.

## System Context

Doctor preflight inspects the canonical OpenClaw config before gateway use and can surface or repair upgrade-state problems. This PR would copy a legacy sibling config into the canonical location only through the explicit repair flow, affecting subsequent gateway startup and agent/channel configuration.
