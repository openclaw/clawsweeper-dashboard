Full review comments:

- **[P2] Use the shared queue directive parser:** `src/tui/tui-command-handlers.ts:84-85`
  - body: This busy-guard escape now decides which `/queue` commands can reach Gateway during an active run, but the local regex only matches a leading `/queue` followed by whitespace or end. The shared Gateway parser accepts the current command grammar, including `/queue:...` and inline queue directives, so those valid forms can still be blocked as busy instead of reaching queue handling. Use `extractQueueDirective(text).hasDirective` or a shared wrapper here.
  - confidence: 0.91
- **[P2] Keep session mismatch stricter for queued aborts:** `src/gateway/server-methods/chat.ts:3424-3425`
  - body: Late discovery: this branch was already present in an earlier reviewed head. The queued runId path uses `canRequesterAbortQueuedChatTurn` to bypass a session-key mismatch, and that helper returns true when no owner ids are stored, so a caller with a runId can cancel an ownerless queued turn from a different session. Active runs use a separate session-mismatch helper that only permits admin or matching owner; mirror that split for queued turns and add coverage.
  - late: true
  - confidence: 0.82
