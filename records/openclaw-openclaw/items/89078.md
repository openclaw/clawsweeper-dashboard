- **[P1] Complete collect-batch queued-turn lifecycles:** `src/gateway/server-methods/chat.ts:4385-4401`
  - body: This registers every queued `chat.send` with `chatQueuedTurns`, but collect mode groups multiple `FollowupRun`s into a synthetic run. In that path `collectRuntimeMetadata` drops `queuedLifecycle` when `items.length > 1`, and the drain removes the originals without completing them, so two collected prompts leave stale abort identities after they already ran. Complete each grouped source lifecycle when the collect batch is consumed, or carry an aggregate cleanup that drops all source run IDs.
  - confidence: 0.87
- **[P2] Mirror the shared queue directive parser:** `src/tui/tui-command-handlers.ts:85`
  - body: `extractQueueDirective` accepts `/queue` followed by end, whitespace, or `:`, so `/queue: followup` is valid Gateway input. This TUI bypass only recognizes whitespace/end, meaning that during an active steer-mode run the valid directive still hits the busy guard and never reaches Gateway. This prior finding remains unfixed on the current head.
  - confidence: 0.9
