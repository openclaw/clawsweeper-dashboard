- **Persist Session Attribution:** Store the first CTWA payload on session state only after retention, redaction, and access rules are explicitly defined.

## Reproduction Assessment

Yes, source-level: current main extracts only partial `externalAdReply` data and does not project CTWA click/referral fields even though the pinned Baileys type surface exposes `ctwaClid`. I did not run a live Click-to-WhatsApp webhook reproduction.

## Solution Assessment

Unclear as proposed: the WhatsApp plugin is the right extraction owner, but broad prompt/session exposure is not automatically the safest contract. The best likely direction is typed CTWA attribution behind the existing untrusted-context or plugin-hook boundary, with persistence only after an explicit retention decision.
