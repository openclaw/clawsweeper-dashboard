## Best Possible Solution

Define a WhatsApp-owned CTWA attribution payload, expose it through an approved untrusted-context or plugin-hook boundary, and persist it only if maintainers set explicit retention and redaction rules.

Unclear as proposed: the WhatsApp plugin is the right extraction owner, but broad prompt/session exposure is not automatically the safest contract. The best likely direction is typed CTWA attribution behind the existing untrusted-context or plugin-hook boundary, with persistence only after an explicit retention decision.
