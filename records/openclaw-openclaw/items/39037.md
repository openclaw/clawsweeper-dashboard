Keep open. Current main and v2026.6.11 expose only partial WhatsApp external-ad metadata; the requested CTWA click id, source id/type, plugin/session visibility, and retention boundary still need maintainer direction.

## What This Changes

Expose WhatsApp Click-to-WhatsApp attribution fields, especially ctwaClid, from inbound contextInfo/externalAdReply into an approved session or agent-visible metadata surface.

## Best Possible Solution

Define a WhatsApp-owned CTWA attribution payload, expose it through an approved untrusted prompt or plugin-hook boundary, and persist it only after maintainers approve retention and redaction rules.

Rationale: The extraction path is bounded, but ctwaClid is ad attribution data and the issue asks for prompt/session visibility, so automation should not choose the payload shape, plugin access, retention, or redaction boundary.

Options:

- **Per-turn untrusted context (recommended):** Extract CTWA fields in the WhatsApp plugin and expose them only through the existing untrusted structured-context prompt path without durable persistence.
- **Opted-in plugin hook payload:** Define a typed WhatsApp attribution payload for opted-in plugin hooks so a Conversions API plugin can consume it without showing the identifier in every prompt.
- **Persist session attribution:** Store the first CTWA payload on session state only after maintainers define retention, redaction, export, and deletion behavior.

## Reproduction Assessment

Yes, source-level: the pinned Baileys contract exposes CTWA attribution fields, while current OpenClaw extraction and forwarding only carry title, sourceUrl, and body. No live Click-to-WhatsApp webhook reproduction was run in this read-only review.

## Solution Assessment

Unclear as proposed: WhatsApp is the right extraction owner, but broad prompt/session exposure is not automatically the safest contract. The safer shape is a typed CTWA attribution payload behind the existing untrusted context or plugin-hook boundary, with persistence only after an explicit retention decision.
