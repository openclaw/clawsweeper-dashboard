## What This Changes

Expose WhatsApp Click-to-WhatsApp ad referral and click-id metadata so agents or plugins can report qualified leads to Meta attribution flows.

## Best Possible Solution

Add a narrow WhatsApp-owned attribution metadata object that extracts Baileys `externalAdReply.ctwaClid` plus approved source fields from the first CTWA inbound message, exposes it only on the approved plugin/session seam, and locks retention with focused tests.
