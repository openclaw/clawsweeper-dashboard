## Summary

Keep this issue open: current main still resolves the default periodic memory sync interval to disabled and the interval timer does not force a dirty memory rescan, while the linked open pull request is the active candidate fix and still needs compatibility/product review.

## What This Changes

The issue reports that memory_search can return stale results after filesystem watcher events stop because the memory index has no default periodic fallback.

## Best Possible Solution

Land a reviewed fix that gives memory indexing a reliable fallback after watcher loss, preserves an explicit opt-out, and has accepted upgrade behavior for existing users.
