## Summary

Keep this issue open: current main and the latest release still leave the periodic memory sync fallback disabled by default and the interval path does not force a memory-file rescan, while the linked open PR is the active fix candidate and still needs maintainer direction on the default behavior.

## What This Changes

The issue reports that memory_search can return stale or missing results after memory file watcher events stop because the memory index has no effective periodic fallback under default configuration.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/90019 or an equivalent scoped fix with accepted default and opt-out semantics, an interval rescan path that actually catches stale memory files, and regression proof for missed watcher events.
