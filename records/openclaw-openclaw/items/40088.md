## Summary

Keep open. Current main and the latest release still leave the default periodic memory sync disabled, and the interval path does not mark memory dirty before syncing; an open linked PR is the right candidate path but is not merged yet and needs maintainer review for the default-background-sync behavior.

## What This Changes

The issue reports `memory_search` returning stale or empty results after the memory file watcher stops delivering events, and asks for watcher health, fallback indexing, and warning coverage.

## Best Possible Solution

Land a compatibility-reviewed fix that makes interval fallback dirty-aware and either adopts a documented opt-out default interval or provides equivalent watcher health recovery, with focused tests and proof that stale memory files reindex without `openclaw memory index --force`.
