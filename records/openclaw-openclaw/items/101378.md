Overall correctness: patch is incorrect

Full review comments:

- **[P2] Preserve npm's adjacent node.exe lookup:** `src/process/supervisor/adapters/child.ts:39-42`
  - body: When a configured Windows npm shim is an absolute path and the service PATH does not include that directory, npm's `.cmd` launcher still works by trying `%dp0%\node.exe` first. This direct unwrap searches only `params.env`/`process.env` for `node`, so it can spawn bare `node` or a different Node instead of the shim-local executable and reintroduce an `ENOENT` launch failure. Resolve the Node executable relative to the shim before falling back to PATH.
  - confidence: 0.9
