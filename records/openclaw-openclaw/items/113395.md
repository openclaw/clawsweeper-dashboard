## What This Changes

The branch makes the auth-profile refresh path invoke a built-in OAuth provider’s existing `refreshToken` operation directly after the manager enters its pre-expiry refresh window, removes the now-unused OAuth API-key wrapper, and adds focused regression coverage.

## System Context

Auth profiles store OAuth credentials used to authenticate model requests. Before a request uses a near-expiry credential, the auth manager chooses whether to refresh it, then persists the provider’s rotated credential for subsequent model authentication.
