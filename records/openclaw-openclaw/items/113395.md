## What This Changes

The PR makes the auth-profile refresh path invoke the selected built-in OAuth provider’s existing token-refresh operation directly once the pre-expiry margin says a credential needs rotation, and removes the now-unused OAuth API-key wrapper.

## System Context

Auth profiles provide credentials to agent model requests. When a stored OAuth credential approaches expiry, the auth-profile resolver chooses whether to refresh it, persists a rotated credential when successful, and then supplies the resulting API key to the agent runtime.
