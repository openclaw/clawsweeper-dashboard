## What This Changes

The branch makes built-in OAuth credentials refresh directly after the auth-profile manager enters its pre-expiry margin, removes the now-unused OAuth API-key wrapper, and updates focused regression tests.

## System Context

Auth profiles select and refresh credentials before an agent run obtains an API key. The profile manager uses a pre-expiry margin to decide when to rotate a credential, then persists the refreshed result for the provider and caller.
