## Summary

Keep open: current main and the latest release have slash-command autocomplete, plugin command discovery, and plugin sidebar tabs, but they do not provide a user-defined shortcut/prompt panel with click-to-insert browsing. The remaining work is a product/API decision because the request could be solved as first-party Control UI UX, command metadata, or a plugin contribution surface.

## What This Changes

Add a collapsible, scrollable WebChat sidebar panel for user-defined shortcut keywords that inserts configured prompt text into the composer and shows descriptions/tooltips.

## Best Possible Solution

Expose shortcut discovery through one canonical command/prompt metadata surface in Control UI, preferably reusing `commands.list` and plugin descriptors unless maintainers explicitly approve a new first-party shortcut config.
