## Summary

Keep open. Current main still has slash-command discovery, a command palette, and generic plugin Control UI tabs, but it does not provide a user-defined WebChat prompt-shortcut sidebar or a settled metadata/storage owner for shortcut definitions.

## What This Changes

The issue requests a collapsible WebChat/Control UI sidebar of user-defined shortcut keywords with labels, prompt insertion, descriptions/tooltips, optional icons/categories, and a new shortcut storage/config source.

## Best Possible Solution

Define the shortcut metadata and storage owner first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata if maintainers choose that boundary.
