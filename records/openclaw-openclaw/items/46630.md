## Summary

Keep open. Current main and v2026.6.11 have runtime slash-command discovery, the Control UI command palette, and existing sidebar readers, but they still do not provide a user-defined WebChat keyword or prompt-snippet browser with click-to-insert behavior; the remaining work needs a product decision about shortcut ownership and storage.

## What This Changes

Request to add a collapsible, scrollable WebChat sidebar listing user-defined shortcut keywords with labels, prompt text, descriptions/tooltips, optional icons/categories, and click-to-insert behavior.

## Best Possible Solution

Define the maintainer-approved shortcut ownership and storage/API contract first, then add a responsive Control UI panel or drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that becomes the chosen boundary.

## Reproduction Assessment

Not applicable: this is a feature request rather than a broken existing behavior report. Source and docs checks show no current user-defined prompt-snippet browser or supported WebChat shortcut config.

## Solution Assessment
