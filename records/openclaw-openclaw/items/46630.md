## Summary

Keep open. Current main and v2026.6.11 have slash-command discovery, a slash menu, a small command palette, and generic plugin Control UI tabs, but they still do not provide a user-defined WebChat prompt-shortcut sidebar or an approved storage/config contract for shortcut definitions.

## What This Changes

Add a WebChat/Control UI sidebar that lists user-defined shortcut keywords and inserts the selected prompt into the chat input.

## Best Possible Solution

Define the shortcut metadata and storage owner first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where maintainers choose that boundary.
