## Summary

Keep open. Current main and v2026.6.11 have runtime slash-command discovery, slash-menu autocomplete, and a small command palette, but they still lack a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining work is a product/storage/API decision rather than conservative cleanup.

## What This Changes

The issue requests a collapsible WebChat sidebar or mobile drawer listing user-defined shortcut keywords with descriptions and click-to-insert prompt text.

## Best Possible Solution

Define the maintainer-approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
