Keep open: current main still has slash-command autocomplete, command discovery, and plugin Control UI tabs, but not a user-defined shortcut/prompt sidebar with click-to-insert browsing. The remaining work needs maintainer product/API direction because it could be command metadata UX, new first-party shortcut storage, or plugin contribution-slot work.

## What This Changes

Add a collapsible WebChat sidebar panel for user-defined shortcut keywords with labels, descriptions, optional icons/categories, and click-to-insert prompt text.

## Best Possible Solution

Expose shortcut discovery through one canonical command or prompt metadata surface in Control UI, reusing `commands.list` and plugin descriptors where possible unless maintainers explicitly approve a new first-party shortcuts config.
