## Summary

Keep open. Current main and v2026.6.11 have slash-command discovery, a command palette, and plugin Control UI tab descriptors, but not a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining work needs a product decision on shortcut metadata and storage ownership.

## What This Changes

The issue requests a scrollable WebChat/Control UI sidebar for user-defined shortcut keywords with click-to-insert prompt text, tooltips, optional icons, categories, and a storage/config source.

## Best Possible Solution

Define the approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
