## Summary

Keep open. Current main and the latest release have runtime command discovery, slash autocomplete, skill/plugin command surfaces, and a small command palette, but they still do not provide a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining work is a product and storage/API decision rather than cleanup.

## What This Changes

Request to add a collapsible WebChat/Control UI sidebar listing user-defined shortcut keywords with labels, prompt text, descriptions, optional icons/categories, and click-to-insert behavior.

## Best Possible Solution

Define the maintainer-approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
