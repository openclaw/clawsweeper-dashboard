## Summary

Keep open. Current main and v2026.6.11 have slash-command discovery and a Control UI command palette, but not a user-defined WebChat shortcut/prompt-snippet sidebar with click-to-insert behavior; the remaining work needs a product decision about shortcut metadata and storage ownership.

## What This Changes

Request a collapsible WebChat sidebar or drawer that lists user-defined shortcut keywords and inserts their prompt text into the chat composer.

## Best Possible Solution

Define the approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
