Keep open: current main has command-palette and slash-command discovery, plus narrow plugin Control UI tabs, but it does not provide user-defined prompt shortcuts in a browsable sidebar. The remaining work is a product/API/storage decision, not a stale or already-implemented issue.

Add a collapsible WebChat/Control UI sidebar listing user-defined shortcut keywords that click into the chat input with labels, descriptions, icons, and optional categories.

## Best Possible Solution

Choose the product boundary first: browser-local shortcuts, first-party Control UI shortcut panel, or a host-owned plugin contribution under #71736, while avoiding retired WebChat config and preserving click-to-insert-not-autosend behavior.
