## Summary

Keep open. Current main still has command discovery, slash completion, command palette plumbing, and generic plugin tabs, but it does not provide a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining work needs a product decision about metadata and storage ownership.

## What This Changes

The issue requests a collapsible WebChat sidebar for user-defined shortcut keywords with click-to-insert prompts and hover descriptions.

## Best Possible Solution

Define the approved shortcut metadata and storage/API contract first, then add a responsive WebChat sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
