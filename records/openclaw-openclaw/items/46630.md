## Summary

Keep open. Current main and v2026.6.11 have dynamic slash-command discovery, a command palette, and a markdown/canvas/image sidebar, but they still do not provide a user-defined WebChat shortcut or prompt-snippet browser with click-to-insert behavior; the remaining work needs a maintainer product decision about shortcut ownership, storage, and UI placement.

## What This Changes

Request a WebChat/Control UI sidebar or drawer for user-defined shortcut keywords and prompt snippets with click-to-insert, descriptions, optional icons/categories, and a proposed config-backed source.

## Best Possible Solution

Define the maintainer-approved shortcut ownership and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that is the chosen boundary.
