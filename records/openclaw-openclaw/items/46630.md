## Summary

Keep open. Current main and the latest release have runtime slash-command discovery, a slash menu, a command palette, and a generic chat detail sidebar, but they still do not provide a user-defined WebChat shortcut or prompt-snippet browser with click-to-insert behavior; the remaining work needs a product decision about ownership, storage, and UI placement.

## What This Changes

Request to add a discoverable WebChat sidebar or drawer for user-defined shortcut keywords with click-to-insert prompts and hover descriptions.

## Best Possible Solution

Define the maintainer-approved shortcut ownership and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that is the chosen boundary.
