## Summary

Keep open. Current main has command discovery, slash-menu autocomplete, and an adjacent command palette, but it still lacks a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining work is a product/storage/API decision, not conservative cleanup.

## What This Changes

Add a WebChat sidebar or drawer that lists user-defined shortcut keywords and inserts the configured prompt text into the chat composer without auto-sending.

## Best Possible Solution

Define the maintainer-approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that is the chosen boundary.
