## Summary

Keep open. Current main and v2026.6.11 have runtime slash-command discovery, a slash menu, and a small command palette, but they still do not provide a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining question is product ownership plus storage/API shape.

## What This Changes

Request to add a collapsible WebChat sidebar listing user-defined shortcut keywords with labels, descriptions, optional icons/categories, and click-to-insert prompt text.

## Best Possible Solution

Define the maintainer-approved shortcut ownership and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that is the chosen boundary.
