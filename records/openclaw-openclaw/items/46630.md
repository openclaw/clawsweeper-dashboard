## Summary

Keep open. Current main and v2026.6.11 still provide runtime slash-command discovery, a slash menu, and a small command palette, but not a user-defined WebChat shortcut or prompt-snippet sidebar with click-to-insert behavior; the remaining work needs a product decision about shortcut metadata and storage ownership.

## What This Changes

The issue requests a user-configurable WebChat sidebar that lists shortcut keywords/prompts with labels, descriptions, optional icons/categories, and click-to-insert behavior.

## Best Possible Solution

Define the approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
