## Summary

Keep open. Current main and v2026.6.11 have runtime command discovery, slash autocomplete, and a small command palette, but they still do not provide a user-defined WebChat shortcut/prompt-snippet sidebar with click-to-insert behavior.

## What This Changes

Request a collapsible WebChat sidebar that lists user-defined shortcuts and inserts their prompt text into the chat composer.

## Best Possible Solution

Define the maintainer-approved shortcut metadata and storage/API contract first, then add a responsive Control UI sidebar or mobile drawer that inserts prompt text without auto-sending and reuses command, skill, or plugin metadata where that boundary is chosen.
