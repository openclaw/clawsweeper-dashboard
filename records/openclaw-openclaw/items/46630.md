## Summary

Keep open. Current main and v2026.6.11 provide slash-command discovery, a command palette, plugin Control UI tabs, and model-proposed task suggestion cards, but not a user-defined WebChat prompt-snippet sidebar with click-to-insert behavior; the remaining work needs a product/API decision around shortcut metadata and storage ownership.

## What This Changes

Add a collapsible WebChat sidebar listing user-defined shortcut keywords or snippets with descriptions and click-to-insert behavior.

## Best Possible Solution

Define a maintainer-approved shortcut metadata and composer-insertion surface, preferably plugin/skill-backed or stored in owned SQLite/plugin state, before adding any core WebChat sidebar or new config key.
