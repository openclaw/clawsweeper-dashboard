## Summary

The 16 MiB cap is well-proven and appropriately applied through the shared loader, but the selected helper also rejects symlinked local marketplace paths that current main accepts. That upgrade-sensitive behavior should be narrowed or explicitly approved before merge.

## What This Changes

The PR replaces unbounded marketplace manifest reads with a 16 MiB regular-file read and adds regression coverage for oversized and symlinked manifests.

## Best Possible Solution

Keep the 16 MiB bound, preserve established local marketplace path behavior, and apply strict non-symlink path validation only to cloned or downloaded untrusted marketplace material unless maintainers explicitly adopt the stricter local policy.
