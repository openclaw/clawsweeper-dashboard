## Summary

## What This Changes

Bounds local marketplace manifest reads at 16 MiB, adds distinct oversized and unreadable errors, and adds regression coverage for oversized and symlinked manifests.

## Best Possible Solution

Use a bounded handle-based read that follows the user-selected manifest path, verifies the opened target is a regular file, rejects targets over 16 MiB before allocating the full buffer, and preserves distinct diagnostics with tests for regular, oversized, and symlinked manifests.
