## Summary

The latest head still introduces a blocking compatibility regression: local marketplace manifests that currently load through symlinked files or parent directories become unreadable, and the dependency documentation directs caller-influenced paths to a root-scoped API instead.

## What This Changes

The PR caps marketplace manifest reads at 16 MiB, adds distinct oversized and unreadable errors, and adds oversized-file and symlink-rejection tests.

## Best Possible Solution

Read local manifests through the dependency's bounded root-scoped file API so symlinks that resolve within the authorized local marketplace boundary remain usable, while cloned remote marketplaces retain strict canonical containment and the 16 MiB cap.
