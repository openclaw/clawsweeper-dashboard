## Summary

Keep open: the 16 MiB bound is useful and well-proven, but the current patch still replaces the shipped symlink-following read with a helper that rejects symlinked local marketplace manifests, so it needs the previously reported compatibility repair before merge.

## What This Changes

The PR caps local marketplace manifest reads at 16 MiB and adds distinct oversized-versus-unreadable diagnostics with regression tests.

## Best Possible Solution

Keep the 16 MiB cap while resolving and bounding valid local symlink targets as regular files; retain stricter symlink rejection only for remote or otherwise untrusted marketplace boundaries, with focused coverage for both cases.
