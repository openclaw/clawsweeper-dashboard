## Summary

The patch is correct, focused, and supported by real CLI proof, but it also intentionally changes marketplace manifest acceptance from any readable file path to regular files only. Keep it open for the marketplace owner to approve that security-versus-compatibility boundary before merge.

## What This Changes

The PR replaces unbounded marketplace manifest reads with a 16 MiB regular-file read and adds regression coverage for oversized and symlinked manifests.

## Best Possible Solution

Keep the 16 MiB bound and use the shared race-aware regular-file reader, provided the marketplace owner explicitly accepts regular-file-only manifests; otherwise design a bounded, root-contained symlink policy before merge.
