## Summary

The latest head still introduces the previously reported compatibility regression: the memory bound is valuable and well proven, but the patch rejects local symlinked marketplace manifests even though established marketplace behavior intentionally preserves logical local paths. The newest commit only improves error classification and adds a test that codifies the rejection, so the PR needs the narrow local-versus-remote policy repair before merge.

## What This Changes

The PR caps marketplace manifest reads at 16 MiB and adds distinct errors and regression tests for oversized versus non-regular manifest files.

## Best Possible Solution

Retain the 16 MiB bound for every origin, follow trusted-local manifest symlinks only when they resolve to regular files, and keep cloned or downloaded marketplace staging strictly symlink-rejecting with focused coverage for both paths.
