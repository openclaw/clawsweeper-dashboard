## Summary

The size cap addresses a real unbounded read, but the latest head still applies a symlink-rejecting primitive to both trusted local and staged remote manifests. That makes released local marketplace inputs fail even though the existing resolver and prior compatibility work preserve logical local paths, so the repeated P1 blocker remains unresolved.

## What This Changes

The PR caps marketplace manifest reads at 16 MiB with `readRegularFile`, maps overflow separately from other read failures, and adds oversized and symlink-rejection tests.

## Best Possible Solution

Use a bounded symlink-following read for trusted local manifests, retain regular-file-only validation for cloned or downloaded remote manifests, and add focused positive-local and negative-remote symlink coverage.
