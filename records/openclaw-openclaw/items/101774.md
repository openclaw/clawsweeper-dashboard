## Summary

The memory-safety goal is valid, but the latest head still changes trusted local marketplace path compatibility: symlinked manifest files that current main reads normally would fail closed. The prior blocking finding is unchanged on the latest head, so the PR is not merge-ready.

## What This Changes

The PR replaces unbounded marketplace manifest reads with a 16 MiB capped regular-file read and adds distinct oversized/unreadable errors plus regression tests for oversized and symlinked local manifests.

## Best Possible Solution

Bound all marketplace manifest allocations at 16 MiB while preserving current trusted local symlink-following behavior, and apply strict regular-file validation to cloned or downloaded remote material with separate source-specific regression tests.
