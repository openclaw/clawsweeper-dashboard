## Summary

The 16 MiB bound is worthwhile and has convincing CLI proof, but the current patch still turns previously supported symlinked marketplace manifests into hard failures. The repeated compatibility blocker remains present at the reviewed head, so this PR needs a narrow repair before merge.

## What This Changes

The PR replaces unbounded marketplace manifest reads with a 16 MiB regular-file read and adds oversized-file and non-regular-file error coverage.

## Best Possible Solution

Follow and validate the final manifest target, require that target to be a stable regular file, and enforce the 16 MiB limit without rejecting an otherwise valid symlinked marketplace path.
