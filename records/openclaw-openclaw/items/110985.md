## Summary

Keep this PR open for maintainer review: it turns two intentionally different native-approval sets into one manifest flag, expanding known native approval-prompt discovery to iMessage and WhatsApp without evidence that those channels provide the prompt UI required by that path. The `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The branch moves native-approval metadata to bundled channel manifests, reuses messaging session-key comparison metadata for native commands, and adds portable session-attachment hints while deprecating Telegram and Slack nested hint shapes.

## Best Possible Solution

Preserve separate manifest semantics for native same-turn approval resolution and native approval-prompt UI, then migrate each caller to the flag that matches its established behavior and prove the affected approval flows on the newly covered channels.
