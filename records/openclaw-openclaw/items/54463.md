## What This Changes

The issue asks OpenClaw to prevent QMD memory indexing from failing on workspace-visible temporary monorepos with recursive symlink structures and to align docs with runtime behavior.

## Best Possible Solution

Keep this as the canonical QMD traversal robustness item until maintainers recreate the symlink-loop fixture against current main and current QMD, then either document/version-gate the upstream fix or add OpenClaw-side pre-update safety for supported older QMD installs.
