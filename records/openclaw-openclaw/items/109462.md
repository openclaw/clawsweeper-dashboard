## Summary

The shared catch remains unsafe: it collapses distinct Tailscale failure semantics into an empty object, breaking the current WHOIS error-cache contract and changing the intentional Funnel preservation path. The PR also still lacks valid caller-level real-behavior proof.

## What This Changes

The PR catches malformed JSON in the shared Tailscale stdout parser, changes malformed Funnel-status handling to return false, and adds parser tests through a test-only global API.

## Best Possible Solution

Keep parsing failures distinguishable in the shared parser; add graceful degradation only in a caller whose public contract explicitly permits it, with separate coverage for Funnel preservation and WHOIS error-TTL recovery.
