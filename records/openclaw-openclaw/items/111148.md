## Summary

Keep this PR open: the contributor supplied credible after-fix production logs, but the current branch still treats every non-archived `THREAD_UPDATE` as an unarchive. It needs a narrow transition check before merge so ordinary active-thread updates do not trigger misleading rejoin requests.

## What This Changes

The PR changes the Discord thread update listener to rejoin the bot through Discord REST whenever it handles a non-archived thread update, while preserving archived-thread session cleanup.

## Best Possible Solution

Rejoin only after proving an archived-to-unarchived transition through the Discord event contract or a bounded listener-owned prior-state mechanism, and cover both that transition and an ordinary active-thread update.
