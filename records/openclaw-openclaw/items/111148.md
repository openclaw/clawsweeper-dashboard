## Summary

Keep this PR open, but do not merge it yet: it restores the reported recovery path, yet the current branch still treats every active `THREAD_UPDATE` as an unarchive and can issue redundant join requests during ordinary thread edits.

## What This Changes

The PR changes the Discord thread-update listener to reset sessions on archive and call Discord’s thread-members endpoint when a thread update reports an active thread.

## Best Possible Solution

Keep the recovery behavior, but record whether each thread has already been reconciled since startup or its last archive; rejoin once on the first active update, clear that marker on archive, and add focused lifecycle coverage.
