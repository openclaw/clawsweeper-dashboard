## Summary

Keep open: current main still does not auto-forward Node `agent.request` image attachments to IM users, and the remaining work is a new media relay contract across a credentialed channel boundary rather than conservative cleanup.

## What This Changes

The issue requests an opt-in way for Node `agent.request` image attachments with `deliver: true` to be forwarded to IM users without the agent explicitly echoing media.

## Best Possible Solution

Approve a narrow explicit opt-in protocol/API design with route authorization, media caps, audit receipts, and agent override semantics, or keep media forwarding on direct send/message-tool surfaces.
