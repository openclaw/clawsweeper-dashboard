## Summary

Keep this PR open: current main still has the three unbounded installer downloads, while the branch applies the repository’s established bounded-download pattern without a blocking correctness defect. The remaining action is normal maintainer review and completion of CI, with awareness that the fixed transfer deadline can reject unusually slow but healthy downloads.

## What This Changes

The branch replaces three installer `curl | bash` paths with downloads to temporary files using 10-second connection and 120-second transfer deadlines, then adds source guards for that pattern.

## Best Possible Solution

Use the bounded download-to-temporary-file pattern consistently for all installer runners, preserve the existing installer arguments and execution timeout, and land after CI confirms the chosen 120-second transfer budget is practical.
