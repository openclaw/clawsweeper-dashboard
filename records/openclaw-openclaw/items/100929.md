## What This Changes

The PR adds Control UI composer handling that turns plain-text paste payloads over 2000 characters into compact text/plain attachments with a show-in-composer action and send-path regression coverage.

## Best Possible Solution

Land the focused composer attachment behavior after normal maintainer review, keeping pasted text on the existing attachment, send, queue, retry, and cleanup paths.

## Solution Assessment

Yes, this is the best maintainable shape I found: it reuses the existing attachment payload and gateway file-attachment path instead of adding a separate composer-only state model. A separate large-paste model would duplicate send, retry, queue, cleanup, and payload snapshot behavior.
