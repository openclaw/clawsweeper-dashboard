## Summary

Keep open: current main still carries the reported terminal-control path, with imported transcript text flowing into `summary.md` and the plain `transcripts show` command writing that file directly to stdout.

## What This Changes

Imported transcript summary text should be sanitized so terminal escape sequences from external transcript content are not persisted into or emitted from `summary.md`.

## Best Possible Solution

Fix the current transcript summary boundary by stripping terminal controls from externally supplied transcript text and speaker labels before `summary.md` can be stored or printed, with regression coverage for CSI and OSC-style escapes.
