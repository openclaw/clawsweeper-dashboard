## What This Changes

The issue asks OpenClaw to prevent imported transcript text and speaker labels from carrying terminal escape sequences into `openclaw transcripts show` output.

## Best Possible Solution

Make human-readable transcript summaries terminal-safe for external text and labels, preferably at render/store time, while preserving raw machine-readable transcript data where fidelity is needed.
