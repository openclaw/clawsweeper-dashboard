## Summary

Keep open: current main and the latest release still let imported transcript text reach `summary.md` and `openclaw transcripts show` stdout without terminal-control sanitization, and the protected security label requires maintainer/security handling before cleanup.

## What This Changes

Imported transcript text containing terminal escape sequences can be persisted in transcript summaries and emitted by `openclaw transcripts show`.

## Best Possible Solution

Sanitize externally supplied transcript text and speaker labels at the summary or terminal-display boundary with the existing terminal-core sanitizer, then add regression coverage for CSI and OSC escapes through the real `transcripts show` path.
