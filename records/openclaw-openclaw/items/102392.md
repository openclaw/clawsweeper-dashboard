## Summary

Keep open: current main still carries imported transcript text and speaker labels into `summary.md` without terminal-control sanitization, then `openclaw transcripts show` writes that markdown directly to stdout. The adjacent exec-output sanitizer fix does not touch this transcript summary/display path, so this issue remains the canonical open work pending maintainer/security boundary direction.

## What This Changes

Sanitize imported transcript text and speaker labels before persisted summary output or terminal display so `openclaw transcripts show` cannot emit terminal escape bytes.

## Best Possible Solution

Sanitize externally supplied transcript text and speaker labels at the chosen summary/display boundary with terminal-core sanitizer behavior, then add regression coverage for CSI and OSC escapes through the real `transcripts show` path.
