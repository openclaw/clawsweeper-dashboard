## Summary

Keep open: current main still carries untrusted imported transcript text and speaker labels into stored Markdown and then writes `summary.md` directly to stdout, so the reported terminal-control path remains present and security-sensitive.

## What This Changes

## Best Possible Solution

Sanitize externally supplied transcript text and speaker labels at the summary or terminal-display boundary with the existing terminal-safe helper, then add regression coverage for CSI and OSC escapes through the real `transcripts show` path.
