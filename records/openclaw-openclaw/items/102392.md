## Summary

Keep open: current main still carries imported transcript text and speaker labels into `summary.md` without terminal-control sanitization, then `openclaw transcripts show` writes that markdown directly to stdout. The nearest related sanitizer issue fixed exec-output handling, not this transcript summary/display path, so this issue remains the canonical open work.

## What This Changes

The issue reports that imported transcript text can carry terminal escape bytes into stored transcript summaries and the `openclaw transcripts show` stdout path.

## Best Possible Solution

Sanitize externally supplied transcript text and speaker labels with the existing terminal-core sanitizer at the chosen summary/display boundary, then add regression coverage for CSI and OSC escapes through the real `transcripts show` path.
