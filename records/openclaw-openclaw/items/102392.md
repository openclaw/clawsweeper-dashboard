## Summary

Keep open: current main still carries imported transcript text and speaker labels into `summary.md` without terminal-control sanitization, then `openclaw transcripts show` writes that markdown directly to stdout. The related exec-output sanitizer work is adjacent but does not cover this transcript summary/display path.

## What This Changes

Sanitize imported transcript text and speaker labels before generated transcript summaries can emit terminal controls through `openclaw transcripts show`.

## Best Possible Solution

Sanitize externally supplied transcript text and speaker labels with the existing terminal-core sanitizer at the chosen summary/display boundary, then add regression coverage for CSI and OSC escapes through the real `transcripts show` path.
