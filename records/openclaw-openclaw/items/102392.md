## Summary

Keep open: current main still carries imported transcript text and speaker labels into `summary.md` without terminal-control sanitization, then `openclaw transcripts show` writes that markdown directly to stdout. This remains a valid, transcript-specific security-hardening issue rather than an implemented or duplicate item.

## What This Changes

The issue reports that imported transcript text can preserve terminal escape sequences into stored summaries and `openclaw transcripts show` output.

## Best Possible Solution

Sanitize externally supplied transcript text and speaker labels with the existing terminal-core sanitizer at the chosen summary/display boundary, then add regression coverage for CSI and OSC escapes through the real `transcripts show` path.
