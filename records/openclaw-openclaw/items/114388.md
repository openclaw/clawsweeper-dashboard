## What This Changes

This PR removes the stored multi-agent default marker and requires either a sole configured agent or explicit ownership for routing, migrations, Gateway clients, CLI flows, channels, and related documentation.

## System Context

Agent selection sits between OpenClaw configuration and every ambient execution surface, including inbound channels, cron jobs, sessions, setup, and provider-backed agents. The migration layer must preserve legacy ownership before these surfaces begin failing closed on unowned multi-agent work.
