## What This Changes

This PR replaces stored multi-agent `default: true` selection with sole-agent selection or explicit per-surface ownership, including Doctor/state migration, routing, Gateway/CLI contracts, and documentation.

## System Context

Agent routing chooses an owner for inbound channels, background work, sessions, and operator commands. This PR changes that common selection boundary so a fleet either has one agent or records an owner at the specific channel, job, session, or setup surface before work reaches agent-scoped state and runtime providers.

flowchart LR

  Channel[Channels, CLI, and cron] --> Select
  Select --> Doctor[Doctor migration]
  Doctor --> State[Agent-scoped sessions and state]
  Select --> Gateway[Gateway protocol and clients]
  Gateway --> Runtime[Selected agent runtime]

## Best Possible Solution

Retain the sole-or-explicit ownership model, but merge only after a redacted exact-head upgrade proof shows Doctor materializing a legacy multi-agent configuration, restarting or reloading the Gateway, and successfully routing an owned channel or job while an intentionally unowned new surface fails with the documented actionable error.
