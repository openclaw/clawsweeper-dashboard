## What This Changes

This PR removes the stored `default: true` agent marker, preserves legacy multi-agent ownership through Doctor and state migrations, and requires sole-agent selection or explicit ownership for new ambient work.

## System Context

OpenClaw selects an agent for inbound channels, CLI calls, cron jobs, sessions, setup, and Gateway requests before using that agent’s workspace, credentials, and state. This PR changes the shared ownership-selection boundary and migrates legacy default-agent behavior into explicit per-surface ownership.
