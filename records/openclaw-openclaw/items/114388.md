## What This Changes

This PR removes the stored per-agent default marker, selecting the sole configured agent automatically and requiring explicit ownership for ambient work in multi-agent fleets, with migration, protocol, CLI, channel, cron, and documentation updates.

## System Context

OpenClaw’s agent roster supplies the agent identity used by channel routing, scheduled work, sessions, setup, and Gateway clients. This change replaces ambient default-agent selection with either a sole-agent choice or an explicit surface owner, so unowned multi-agent work fails rather than being silently attributed.
