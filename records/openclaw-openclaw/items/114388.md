## What This Changes

This PR removes persisted `default: true` agent selection, adds a sole-versus-explicit ownership model, migrates legacy multi-agent ownership, and updates routing, CLI, Gateway, plugins, docs, and tests to require an explicit owner where needed.

## System Context

OpenClaw resolves an agent owner before processing inbound channel work, background jobs, CLI requests, or Gateway calls. That owner selects the agent workspace, credentials, session store, and runtime, so roster migration must preserve existing owners while making newly unowned multi-agent work fail clearly.
