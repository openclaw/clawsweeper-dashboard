## What This Changes

This PR retires the stored `default: true` agent marker, migrates legacy multi-agent ownership into explicit bindings and targets, and makes new multi-agent ambient work require an explicit agent selection.

## System Context

OpenClaw routes inbound channels, scheduled jobs, session work, setup, and provider state to an agent roster. This change replaces fleet-wide default selection with either the only configured agent or an explicit owner, affecting config migration, Gateway clients, CLI flows, persisted sessions, cron jobs, and channel routing.
