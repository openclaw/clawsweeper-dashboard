The PR adds a lazy sweep-scoped snapshot of pending generated-media session keys and replaces repeated per-session task scans with set lookups in the cron session reaper.

## Best Possible Solution

Keep one lazy task-owner snapshot per relevant reaper sweep, preserve the existing requester/owner matching contract, and land it after a current-main refresh confirms the focused tests and runtime proof.
