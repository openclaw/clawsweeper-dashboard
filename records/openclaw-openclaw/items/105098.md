## Summary

The fix direction is valid, but the unchanged head still solves a supplement-only deadline bug by fully serializing a shared vault reader used by direct search and other memory-wiki workflows; the prior blocking concurrency finding therefore remains, and representative gateway proof is still insufficient.

## What This Changes

The PR propagates the memory-search deadline into corpus supplements, disables exhaustive fallback for memory-wiki supplement searches, and makes shared wiki page reads abort-aware by processing files sequentially.

## Best Possible Solution

Keep the additive deadline signal and supplement-only `exhaustiveFallback: false`, but use deterministic bounded workers that stop claiming new paths after abort, preserve input-order results, and validate the real large-vault gateway path.
