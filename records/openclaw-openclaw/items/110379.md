## Summary

Keep this issue open as a Control UI ergonomics decision. The current navigation deliberately keeps a customizable pinned set and places all remaining destinations under “More,” so the report identifies a credible discoverability concern rather than a missing or broken destination; a maintainer should decide whether to strengthen that affordance or change the default layout.

## What This Changes

Improve discoverability of the Control UI “More” navigation row by moving it below the session list or otherwise making it more prominent.

## Best Possible Solution

Keep the configurable pinned-destination model, then make a focused, user-tested improvement to the More affordance or pinning discovery before changing the default sidebar hierarchy.
