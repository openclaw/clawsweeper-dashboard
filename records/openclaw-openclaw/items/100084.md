## What This Changes

The PR forwards custom Slack identity into native stream starts, skips identity-losing draft edit previews for custom-identity replies, and adds fallback coverage for deferred stream-start failures.

## Best Possible Solution

Land this Slack plugin fix after maintainer review, preferably with a redacted Slack smoke showing custom identity through native streaming and non-stream fallback paths; keep the linked issue open until the PR merges.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 route custom-identity Slack replies through paths where draft edits omit identity and native streaming is disabled when identity exists. I did not run a live Slack workspace reproduction in this read-only review.

## Solution Assessment

Yes, this appears to be the best code direction: the Slack plugin is the right boundary, `chat.startStream` is the supported authorship surface, and the PR avoids adding unsupported identity fields to `chat.update`. The remaining gap is live Slack proof and maintainer merge judgment, not a concrete code defect.
