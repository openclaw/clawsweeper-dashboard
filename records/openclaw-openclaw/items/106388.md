## Summary

Keep open: the report provides a deterministic real-Gateway fault-injection path and identifies an existing Control UI error-handling gap, with no linked fix and a protected `maintainer` label requiring explicit maintainer handling.

## What This Changes

Surface failed second-page external session-catalog requests in the Control UI while preserving the pagination cursor for retry.

## Best Possible Solution

Store a catalog- or host-scoped pagination error when Load More fails, render it through the existing accessible catalog error presentation, retain the cursor for retry, and clear the error after a successful retry or fresh catalog result.
