  - confidence: 0.87

  - body: Lobster resolves `ctx.llmAdapters[provider]` before its built-in HTTP providers, so registering a direct adapter as `openclaw` changes embedded `llm.invoke --provider openclaw` behavior. Use a distinct provider id or get maintainer approval and docs for that compatibility change.
  - confidence: 0.84
