## Summary

Keep this PR open: it addresses a credible completion-cleanup regression, but the current fallback can delete non-completion user profile lines that merely contain OpenClaw’s cache path. It also still needs an after-fix `openclaw uninstall` transcript and clean-shell-startup proof before merge.

## What This Changes

This PR removes marked OpenClaw shell-completion entries from user shell profiles during state uninstall and reports the profiles that would change during dry-run mode.

## System Context

OpenClaw completion installation adds a marked source block to shell startup profiles, pointing to a completion cache under OpenClaw state. State uninstall removes that cache, so this path must identify only OpenClaw-owned profile entries and leave unrelated shell configuration intact.
