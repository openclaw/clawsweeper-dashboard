## Summary

## What This Changes

The PR makes state uninstall remove OpenClaw completion blocks from shell profiles, including both standard Bash startup files, and adds tests for profile-content cleanup.

## System Context

OpenClaw installs shell-completion source lines into users’ startup profiles, pointing at generated completion files under OpenClaw state. The uninstall command removes that state, so its state-cleanup scope must remove only the installer-owned profile entries before later shells source a deleted file.
