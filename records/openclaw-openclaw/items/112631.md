## Summary

This PR addresses a real uninstall regression, but its Bash cleanup path does not target the profile that the existing installer uses when `~/.bashrc` is absent. The branch should stay open for a narrow repair and real end-to-end proof rather than merge as-is.

## What This Changes

The branch adds shell-profile completion-block removal to the state scope of `openclaw uninstall`, with tests for the new content-stripping helper.

## System Context

OpenClaw's completion installer writes a marked source line into a shell startup profile and stores the generated completion script under the OpenClaw state directory. The uninstall command removes that state directory, so it must remove the matching profile block from the same profile selection path before leaving users with a stale source line.

## Architecture Diagram

flowchart TD

  B --> C[Write OpenClaw completion block]
  C --> D[Completion cache in state directory]
  E[Uninstall state scope] --> F[Remove state directory]
  E --> G[Remove profile completion block]
  G --> H[Clean future shell startup]

## Best Possible Solution

Use one shared, testable Bash profile-selection routine for installation, detection, dry-run reporting, and removal; preserve all non-OpenClaw bytes around the removed block; then show a redacted real uninstall run for both Bash profile variants.
