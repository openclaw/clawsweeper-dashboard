## What This Changes

The issue asks for media:// image inputs and explicit media-understanding image descriptions to use the same imageMaxDimensionPx/imageQuality resize ladder as file-path image-tool inputs.

## Best Possible Solution

Land a narrow fix that applies the existing model-aware image compression ladder at the media-understanding image preparation boundary for configured provider entries and explicit infer image describe calls, with focused regression coverage and redacted real-behavior proof.
