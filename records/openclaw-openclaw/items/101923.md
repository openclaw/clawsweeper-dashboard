## What This Changes

Request downscaling `media://` and media-understanding image inputs through the same `imageMaxDimensionPx`/`imageQuality` resize ladder used by image-tool paths.

## Best Possible Solution

Share a model-aware image compression boundary across both media-understanding entry points, preserve HEIC normalization and under-limit pass-through behavior, then land one proof-positive fix PR.
