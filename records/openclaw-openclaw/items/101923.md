## Summary

Keep open: current main covers the image-tool media reference path better than the report’s original failure, but the media-understanding image paths still pass ordinary non-HEIC image buffers to providers without the shared resize/compression ladder.

## What This Changes

The issue asks for media:// image references and media-understanding image description inputs to be downscaled through the same resize ladder before provider calls.

## Best Possible Solution

Centralize image compression at the media-understanding image preparation boundary so file paths, media:// refs, configured media-understanding runs, and explicit-model infer image describe calls obey the same imageMaxDimensionPx/imageQuality behavior.
