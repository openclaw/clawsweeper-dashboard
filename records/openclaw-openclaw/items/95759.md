## What This Changes

Prevent an ACP-spawned OpenCode session from being recorded as successfully completed with an empty transcript when no agent turn actually ran.

## System Context

`sessions_spawn` routes a requested ACP agent through the Gateway and acpx, then records ACP lifecycle events into the spawned session’s history. The reported failure is at the point where an apparently completed agent run produces no assistant, tool, or transcript events for the parent session to inspect.

  E --> G[Completion status]

## Best Possible Solution

Capture a redacted live OpenClaw ACP run that proves whether OpenCode receives and dispatches the task; then add a narrow typed launch/model/no-dispatch failure path only for the identified invalid state, while preserving intentionally eventless backend completions.
