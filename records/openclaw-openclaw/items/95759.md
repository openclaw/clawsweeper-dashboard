## What This Changes

## System Context

`sessions_spawn` creates an ACP-backed agent session and sends its event stream through the Gateway into the stored session transcript. The reported failure sits between ACP harness launch/model dispatch and transcript projection, leaving a completed session with no visible assistant or tool events.
