## Summary

Keep this PR open: the ByteString failure is valid and the fix is narrowly placed, but replacing every Unicode code point with `_` makes distinct agent or session identifiers collide in ClawRouter attribution, and the supplied evidence is test-only rather than a real dispatch.

## What This Changes

The PR rewrites non-printable-ASCII characters in automatic ClawRouter agent and session attribution headers to `_` and adds a Unicode `Headers` construction regression test.

## Best Possible Solution

Use a deterministic collision-resistant ASCII representation within the 256-character limit—such as bounded encoding with a hash suffix—while preserving CR/LF omission and explicit operator headers, then prove a live request carries distinguishable sanitized agent and session values.
