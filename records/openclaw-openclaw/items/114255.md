## What This Changes

Fix a gateway restart during an in-flight agent run so its orphaned session claim cannot leave the chat permanently unable to process later Telegram messages.

## System Context

Channel messages enter auto-reply turn admission, which reads the persisted session entry and any restart-recovery delivery claim before deciding whether a new run can adopt or retire that claim. A rejected admission propagates back through Telegram ingress handling, where a retryable failure can block subsequent messages in the same spool lane.
