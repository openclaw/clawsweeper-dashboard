## Summary

Keep open: current main and latest release still intentionally block sandboxed requester sessions from ACP spawns, and the open execution-backend PR is adjacent rather than a sandbox-to-ACP bridge. The remaining work needs maintainer product and security agreement before implementation.

## What This Changes

Request an opt-in way for sandboxed OpenClaw sessions to spawn and control ACP harness sessions without giving up sandbox isolation.

## Best Possible Solution

Keep the fail-closed guard until maintainers define an explicit opt-in sandbox-to-ACP bridge or execution-placement contract with allowlisting, audit controls, docs, tests, and live Docker/acpx proof.
