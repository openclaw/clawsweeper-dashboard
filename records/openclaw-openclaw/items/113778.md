## Summary

This PR does not yet implement the described refresh: it publishes a notification after local-node inventory update, but the Skills model neither observes that notification nor coalesces a forced refresh. The reported macOS UI bug therefore remains owned by the canonical issue, and the branch needs a narrow functional repair plus after-fix macOS evidence before merge.

## What This Changes

The branch adds a macOS local-node inventory-published notification and posts it after inventory publication, while the Skills settings file receives only a whitespace change.

## System Context

The macOS app’s local node publishes resolved binary inventory to the Gateway after reconnecting, while the Settings > Skills screen separately reads authoritative skill status from the Gateway. The screen must refresh after that inventory reaches the Gateway so its availability badges reflect the new eligibility result.
