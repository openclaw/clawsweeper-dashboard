## Summary

Keep open: current main and the latest release still lack a per-binding Discord visible identity override, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

The issue requests an optional Discord binding nickname or identity override so one bot token can present different agent names in different channels.

## Best Possible Solution

A maintainer-approved Discord plugin-owned visible-identity contract should define whether this is webhook persona delivery, self-profile mutation, or a deferred feature, with schema, docs, tests, and live Discord proof.

- **Defer per-binding identity:** Keep current bot-account replies plus thread-bound webhook persona behavior and ask users to use multiple bot accounts or existing thread-bound flows for now.
