## What This Changes

The issue requests an optional Discord binding-level nickname/display identity override so one bot token can present different agent names in different channels.

## Best Possible Solution

Have maintainers approve one Discord plugin-owned visible-identity model, likely webhook persona delivery if accepted, with explicit schema, credential handling, docs, tests, and live Discord proof.
