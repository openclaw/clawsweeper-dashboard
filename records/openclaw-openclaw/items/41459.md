## Summary

Keep open: current main and v2026.6.11 still do not provide a per-binding Discord nickname or ordinary routed-reply identity override; the related self-profile issue is adjacent but does not settle this routed reply identity contract.

## What This Changes

Request an optional Discord binding identity override so one bot token can show different agent names per channel.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, regression tests, and live Discord proof.

- **Defer per-binding identity:** Keep current bot-account replies plus thread-bound webhook persona behavior and ask users to use multiple bot accounts or existing thread-bound flows for now.
