## Summary

Keep open: current main and v2026.6.11 still do not expose a per-binding Discord visible-identity override, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

The issue requests an optional Discord binding-level nickname or identity override so one bot token can present different agent names in different Discord channels.

## Best Possible Solution

Have maintainers approve one Discord plugin-owned visible-identity model, likely webhook persona delivery if accepted, with explicit schema, credential handling, docs, tests, and live Discord proof.
