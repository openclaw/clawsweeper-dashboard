## Summary

Keep open: current main and v2026.6.11 still do not provide a per-binding Discord nickname or ordinary routed-reply identity override, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

Request an optional Discord binding nickname or identity override so one bot token can show different agent names per channel.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
