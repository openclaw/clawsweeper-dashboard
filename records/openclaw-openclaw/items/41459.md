## Summary

Keep open: current main and v2026.6.11 still lack a Discord binding-level nickname or ordinary routed-reply identity override; the open self-profile item overlaps only part of the identity space, so this still needs a maintainer product/security decision.

## What This Changes

Request adds an optional Discord binding-level nickname or identity override so one bot token can display different agent names in different channels.

## Best Possible Solution

Choose one Discord plugin-owned visible-identity model, preferably webhook persona delivery if approved, with explicit config schema, credential handling, docs, tests, and live Discord proof.
