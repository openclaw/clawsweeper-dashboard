## Summary

Keep open: current main and the latest release still do not provide a normal Discord binding-level nickname or visible identity override, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

Request adding an optional Discord binding-level nickname or identity override so one Discord bot token can show different agent names in different bound channels.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
