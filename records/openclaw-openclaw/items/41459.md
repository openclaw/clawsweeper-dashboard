## Summary

Keep open: current main and v2026.6.11 still lack a per-binding Discord nickname or ordinary routed-reply identity override, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a per-binding Discord nickname override so one Discord bot token can display different agent identities in different Discord channels.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
