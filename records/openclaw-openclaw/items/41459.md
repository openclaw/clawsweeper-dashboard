## Summary

Keep open: current main still lacks a per-binding Discord nickname or ordinary routed-reply identity override, and the requested fix needs maintainer product/security direction because it would add public config plus a bot-credential-backed identity path.

## What This Changes

Request to add an optional Discord binding identity override so one bot token can show different agent names in different bound channels.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
