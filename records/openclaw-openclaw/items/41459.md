## Summary

Keep open: current main and v2026.6.11 still lack a per-binding Discord nickname or ordinary routed-reply identity override; existing Discord webhook persona delivery is limited to thread-bound flows, and the remaining choice needs maintainer product/security direction.

## What This Changes

Request adds an optional Discord per-binding nickname or visible identity override so one bot token can show different agent names per channel.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, fallback behavior, docs, tests, and live Discord proof.
