## Summary

Keep open: current main and v2026.6.11 still do not expose a per-route-binding Discord nickname, persona, or ordinary routed-reply identity override. The only implemented webhook username/avatar path is tied to Discord thread bindings, so the remaining work is a product and security decision about a new Discord plugin-owned identity/config surface.

## What This Changes

The issue requests an optional Discord binding-level nickname or visible identity override so one bot token can appear as different agents in different channels.
