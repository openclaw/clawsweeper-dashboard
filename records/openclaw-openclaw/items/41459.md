## Summary

Keep open: current main and v2026.6.11 still lack a per-binding Discord nickname or ordinary routed-reply identity override, while the existing username/avatar webhook path is limited to thread-bound delivery and the remaining work needs product and security direction.

## What This Changes

Add an optional Discord per-binding identity or nickname override so one bot token can show different agent names per channel.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
