## Summary

Keep open: current main and v2026.6.11 still do not support a Discord binding-level nickname or ordinary routed-reply identity override, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

Add an optional Discord binding-level nickname or identity override so agents sharing one Discord bot token can display distinct names per bound channel.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
