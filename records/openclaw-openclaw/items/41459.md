## Summary

Keep open: current main and v2026.6.11 still lack a per-binding Discord visible-identity override, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

Request an optional Discord binding-level nickname or identity override so multiple agents using one bot token can appear with different visible identities per channel.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity contract, likely webhook persona delivery if approved, with explicit schema, credential handling, fallback behavior, docs, regression tests, and live Discord proof.
