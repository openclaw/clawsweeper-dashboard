## Summary

Keep open: current main and v2026.6.11 still lack a binding-level Discord nickname or ordinary routed-reply identity override. The existing Discord webhook persona path is bound-thread-only, and choosing between binding config, webhook persona delivery, or self-profile mutation needs maintainer product and security direction.

## What This Changes

Requests an optional Discord binding identity or nickname override so one bot token can present different agent names in different bound channels.

## Best Possible Solution

Approve one Discord plugin-owned visible-identity contract, likely webhook persona delivery if accepted, with explicit schema, credential handling, docs, tests, and live Discord proof.
