## Summary

Keep open: current main and v2026.6.11 still do not support a Discord route-binding nickname or ordinary per-channel visible identity override, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

The issue requests an optional Discord binding-level nickname override so one Discord bot token can present different agent names in different bound channels.

## Best Possible Solution

Have maintainers choose one Discord plugin-owned visible-identity model, likely webhook persona delivery if approved, with explicit schema, credential handling, docs, tests, and live Discord proof.
