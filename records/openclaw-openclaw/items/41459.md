## Summary

Keep open: current main and v2026.6.11 still lack an ordinary Discord binding-level visible-identity override. The existing webhook persona path is limited to Discord thread bindings, while the requested routed-reply identity behavior still needs maintainer product and security direction.

## What This Changes

The issue requests an optional Discord binding-level nickname or visible-identity override so one Discord bot token can present different agent names per channel.

## Best Possible Solution

Maintainers should choose one Discord plugin-owned routed-reply identity model, likely webhook persona delivery if accepted, with explicit schema, credential handling, docs, tests, and live Discord proof.
