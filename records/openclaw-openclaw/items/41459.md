## Summary

Keep open: current main and v2026.6.11 still lack an ordinary Discord route-binding visible-identity override; the existing webhook persona path is limited to thread-bound Discord delivery, so the remaining work needs maintainer product and security direction.

## What This Changes

Add an optional Discord binding-level visible identity or nickname override so one bot token can display different agent names per channel.

## Best Possible Solution

Have maintainers approve one Discord plugin-owned visible-identity model, likely webhook persona delivery if accepted, with explicit schema, credential handling, docs, tests, and live Discord proof.
