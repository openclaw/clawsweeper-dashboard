## Summary

Keep open: current main and v2026.6.11 still do not expose per-binding Discord visible identity for ordinary routed replies. The existing webhook persona path is limited to Discord thread bindings, while the open self-profile item covers adjacent bot-profile mutation rather than this one-token, multi-agent routed-reply identity problem.

## What This Changes

Request to add a Discord binding-level visible identity override so one bot token can present different agent names per channel.

## Best Possible Solution

Have maintainers approve one Discord plugin-owned visible-identity model, likely webhook persona delivery if accepted, with explicit schema, credential handling, docs, tests, and live Discord proof.
