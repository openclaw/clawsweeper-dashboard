## What This Changes

This PR changes bundle-MCP tool-result materialization so an image block is retained beside the serialized `structuredContent` block, with a focused regression test for that mixed result.

## System Context

Bundle-MCP tools return MCP `content` blocks and optional machine-readable `structuredContent`; OpenClaw materializes that result into the agent-visible tool payload. The resulting payload becomes model context, so this boundary decides which tool output modalities remain available to the agent.
