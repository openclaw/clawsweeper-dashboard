## Summary

Keep this PR open: it convincingly proves the image-loss bug and fixes that case, but the new structured-content branch still drops other supported non-text MCP result blocks after they are converted to text. The patch needs one bounded generalization before merge.

## What This Changes

The PR changes bundle-MCP tool-result materialization so an image returned beside `structuredContent` remains visible to the agent, with a regression test for that combined result.

## System Context

Bundle-MCP tool execution receives MCP `content` blocks and optional `structuredContent` from an MCP server, then materializes them into the model-visible tool result. This boundary controls which server-returned text, images, audio, and resources reach the agent prompt while retaining structured details for other consumers.
