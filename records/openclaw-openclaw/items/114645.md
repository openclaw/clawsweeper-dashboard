## Summary

Keep this PR open for security-owner review rather than closing or auto-repairing it. The patch has strong source-level and real-runtime evidence for the credential-redaction leak, but it selects a security lifecycle policy—two independently bounded retention tiers and two durable caller classifications—that the linked security report explicitly says needs an owner decision.

## What This Changes

The PR adds a durable exact-secret-redaction tier and uses it for audit identity keys and SecretRef-resolved runtime values so transient credential churn cannot evict those boot-time values.

## System Context

OpenClaw registers resolved credential values for exact-value masking before diagnostics, proxy captures, and support-oriented output pass through the logging redactor. This PR changes how long those registrations remain eligible for matching, affecting whether long-running gateway logs can reveal active credentials.
