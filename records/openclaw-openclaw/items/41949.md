## Summary

Keep open. Current main has browser snapshot caps, opt-in efficient snapshots, and role-snapshot stats, but it still does not implement the central requested behavior: default compact, goal-shaped browser reads plus bounded post-action change reports instead of large page snapshots entering model context.

## What This Changes

The issue requests browser-specific context-budget controls so multi-step browser interactions avoid repeatedly injecting large raw page content into model context.

## Best Possible Solution

Define and document a canonical browser model-facing output contract: compact, task-relevant reads and bounded post-action reports by default, with explicit raw snapshots or scoped reads for debugging and detailed extraction.
