## Summary

Keep open. Current main and v2026.6.11 have useful browser snapshot caps, optional efficient mode, and generic tool-result guards, but they still do not provide the requested default compact goal-shaped browser read contract or compact post-action change report behavior.

## What This Changes

The issue asks for browser interactions to avoid exhausting model context by sending task-relevant compact page state instead of repeated large page snapshots.

## Best Possible Solution

Define compact goal-shaped browser reads as the intended interactive default, keep explicit full/raw snapshot access, add compact post-action state or change signals, and prove it on a noisy multi-step browser flow.
