## Summary

Keep open. Current main and v2026.6.11 have useful caps, opt-in efficient snapshots, and generic session pruning, but they still do not make compact, goal-shaped browser reads or post-action change reports the default browser interaction contract requested here.

## What This Changes

The issue requests browser interactions that are context-budget aware by default, returning compact task-relevant page state instead of repeatedly injecting large page snapshots into model context.

## Best Possible Solution

Define a browser output contract that defaults to compact, task-relevant snapshots and small post-action change reports, while preserving explicit raw/full-page reads with tests, docs, and live noisy-page browser proof.
