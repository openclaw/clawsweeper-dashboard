## Summary

The current browser tool has bounded AI snapshot output, opt-in efficient snapshots, generic live tool-result truncation, and some action metadata, but the browser-specific default compact, goal-shaped read and post-action change-summary contract requested here is still missing. Keep this open for maintainer product review rather than closing it as implemented or duplicative.

## What This Changes

The issue requests browser interactions that avoid overfilling model context by defaulting to task-relevant page state, compact structural reads, budget-aware degradation, and smaller post-action context.

## Best Possible Solution

Define a maintainer-approved browser read contract that keeps the default model payload compact and goal-shaped, preserves explicit raw/full snapshot escape hatches, and returns concise action-change/readiness signals with focused docs, tests, and live browser proof.
