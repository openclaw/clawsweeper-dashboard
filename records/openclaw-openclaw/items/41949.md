## Summary

Keep open. Current main and v2026.6.11 have browser snapshot caps, optional efficient snapshots, and generic tool-result truncation after overflow, but they still do not make compact goal-shaped browser reads or post-action change reports the default contract requested here; the FSB comment is useful prior art for that product decision.

## What This Changes

Request browser interactions to avoid exhausting model context by defaulting to compact, task-relevant page reads and safer action outputs instead of repeated large page snapshots.

## Best Possible Solution

Define a browser plugin output contract that defaults to compact task-relevant snapshots and small post-action change reports, while keeping explicit raw/full reads with focused tests, docs, and live noisy-page proof.
