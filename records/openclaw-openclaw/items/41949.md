## Summary

Keep open. Current main has useful partial mitigations for browser context pressure, including capped AI snapshots, opt-in efficient mode, compact action results, and generic truncation, but it does not fully implement the requested default compact, goal-shaped browser read contract with an explicit raw/full escape hatch; the FSB comment is useful prior-art context for the maintainer decision.

## What This Changes

The issue requests browser-tool reads that are context-budget aware, compact by default for interactive work, and paired with an explicit raw/full page escape hatch.

## Best Possible Solution

Define a browser-plugin-owned contract where default model-facing browser reads are compact and task-shaped, raw/full reads are explicit, and tests plus live browser proof cover both paths.
