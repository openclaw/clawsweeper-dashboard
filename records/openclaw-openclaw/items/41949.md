## Summary

Keep open. Current main and the latest release have useful browser snapshot caps and an optional efficient mode, but they still do not make compact, goal-shaped browser reads or post-action change reports the default browser interaction contract requested here.

## What This Changes

The issue requests context-budget-aware browser interaction outputs so large page content does not consume model context during multi-step browser tasks.

## Best Possible Solution

Define a browser output contract that defaults to compact, task-relevant snapshots and small post-action change reports, while preserving explicit raw/full-page reads with tests, docs, and live noisy-page browser proof.
