## Summary

Keep open. Current main and v2026.6.11 have useful partial mitigations, but they still do not settle the requested browser-specific default of compact, goal-shaped page reads with an explicit full/raw escape hatch.

## What This Changes

The issue asks for browser interactions to be context-budget aware so agents receive compact, task-relevant page state instead of large noisy page snapshots.

## Best Possible Solution

Define a browser-plugin-owned contract where default model-facing reads are compact and task-shaped, raw/full reads remain explicit, and tests plus live browser proof cover both paths.
