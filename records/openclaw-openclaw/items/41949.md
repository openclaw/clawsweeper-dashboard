## Summary

Keep open. Current main has browser snapshot caps, opt-in/configurable efficient mode, role snapshots, and a generic tool-result guard, but it still lacks the requested default compact, goal-shaped browser read contract and compact post-action change reports; the FSB comment is useful prior art but the remaining behavior needs maintainer product direction and live noisy-page proof.

## What This Changes

Request browser interactions avoid injecting large page snapshots into model context by using compact, goal-shaped page reads and smaller post-action state updates.

## Best Possible Solution

Define compact goal-shaped browser reads as the intended interactive default, preserve explicit full/raw snapshot access, add compact post-action state signals, and prove the contract with focused tests plus live noisy-page browser evidence.
