## Summary

Keep open. Current main and the latest release already have partial mitigations for browser context pressure, including AI snapshot caps, opt-in efficient mode, compact role snapshots, and compact action responses, but they still do not implement the requested default compact, goal-shaped browser read contract with an explicit raw/full escape hatch.

## What This Changes

The issue asks for browser interactions to avoid injecting large page snapshots into model context and instead use compact, goal-shaped page state with graceful context-budget handling.

## Best Possible Solution

Define a browser-plugin-owned contract where default model-facing browser reads are compact and task-shaped, raw/full reads are explicit, and tests plus live browser proof cover both paths.
