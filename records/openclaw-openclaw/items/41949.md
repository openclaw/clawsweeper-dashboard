## Summary

Keep open. Current main has meaningful partial mitigations for browser context pressure, but it does not fully implement the requested default compact, goal-shaped browser read behavior with an explicit raw/full escape hatch; the linked FSB comment is useful prior-art context for the remaining product decision.

## What This Changes

The issue requests context-budget-aware browser interactions so large page snapshots do not crowd out multi-step agent reasoning.

## Best Possible Solution

Define a browser-plugin-owned contract where default browser reads are compact and task-shaped, raw/full page reads stay explicit, and focused tests plus live browser proof cover both paths.
