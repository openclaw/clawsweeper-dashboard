## Summary

Keep open. Current main and the latest release have snapshot caps, opt-in efficient mode, and a generic tool-result context guard, but they still do not provide the requested default compact, goal-shaped browser read contract or compact post-action change signals for multi-step browser work.

## What This Changes

Request browser interactions to use context-budget-aware page reads and compact action feedback instead of repeatedly injecting large snapshots into model context.

## Best Possible Solution

Define compact goal-shaped browser reads as the intended interactive default, preserve explicit full/raw snapshot access, add compact post-action state signals, and prove the contract with focused tests plus live noisy-page browser evidence.
