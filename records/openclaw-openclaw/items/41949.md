## Summary

Keep open. Current main and the latest release have partial browser snapshot caps, opt-in efficient mode, compact action results, and generic Codex dynamic-tool truncation, but browser snapshots can still place snapshot text directly into model-facing tool output and there is no default compact, goal-shaped browser read contract with an explicit raw/full escape hatch.

## What This Changes

Request browser interactions to send compact, task-relevant page state instead of large raw/full snapshots into model context during multi-step automation.

## Best Possible Solution

Define a browser-plugin-owned contract where default browser reads are compact and actionable, raw/full page reads stay explicit, and focused tests plus live browser proof cover both paths.
