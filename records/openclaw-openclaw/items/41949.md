## Summary

Keep open. Current main has useful partial mitigations, including AI snapshot caps, opt-in efficient snapshots, batch execution plumbing, and a generic tool-result guard, but it still does not provide the requested default compact goal-shaped browser read contract or compact post-action change reports.

## What This Changes

The issue requests browser tool output semantics that keep page reads and actions within the model context budget by using compact task-relevant snapshots and small post-action state reports instead of repeated full page content.

## Best Possible Solution

Define compact goal-shaped browser reads as the interactive default, preserve explicit full/raw page reads, add small post-action state/change signals, and prove the behavior with focused tests plus live noisy-page browser evidence.
