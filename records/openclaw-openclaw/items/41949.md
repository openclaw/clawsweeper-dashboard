## Summary

Keep open. Current main and v2026.6.11 still have useful browser snapshot caps, efficient mode, skill guidance, and generic tool-result context guards, but they do not implement the requested default compact, goal-shaped browser read contract or compact post-action change reports.

## What This Changes

The issue requests browser-tool context-budget controls so large page snapshots do not consume too much model context during multi-step browser interactions.

## Best Possible Solution

Define compact goal-shaped browser reads as the interactive default, preserve explicit full/raw snapshot access, add compact post-action state or change signals, and prove the result on a noisy multi-step browser flow.
