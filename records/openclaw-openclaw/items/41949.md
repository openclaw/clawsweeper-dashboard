## Summary

Keep open. Current main has browser snapshot caps, efficient mode, and a generic tool-result guard, but it still lacks the requested default compact, goal-shaped browser read contract and compact post-action change signals.

## What This Changes

The issue asks for browser interactions to avoid exhausting model context by sending compact task-relevant page state instead of large noisy page content.

## Best Possible Solution

Define compact goal-shaped browser reads as the intended interactive default, preserve explicit full/raw snapshot access, add compact post-action state signals, and prove it with focused tests plus live noisy-page browser evidence.
