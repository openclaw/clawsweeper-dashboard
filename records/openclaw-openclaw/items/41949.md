Keep open. Current main and the latest release have meaningful safeguards for browser context pressure, but they still do not implement the requested default compact, goal-shaped browser read contract or compact post-action change-report semantics.

## What This Changes

The issue requests browser interaction outputs that are context-budget aware so large page content does not crowd out multi-step agent reasoning.

Define compact goal-shaped browser reads as the intended interactive default, keep explicit full/raw snapshot access, add compact post-action state or change signals, and prove the result on a noisy multi-step browser flow.
