## Summary

Keep open. Current main has capped AI snapshots, an optional efficient snapshot mode, and generic tool-result truncation, but it still does not provide the compact goal-shaped browser reads or post-action change reports requested here.

## What This Changes

The issue requests context-budget-aware browser interactions that avoid repeatedly injecting large full-page snapshots into model context.

## Best Possible Solution

Define a maintainer-approved browser interaction contract: compact goal-shaped reads and small post-action change reports by default, with explicit full snapshot or maxChars escape hatches and live noisy-page proof.
