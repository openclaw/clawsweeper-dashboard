## Summary

Keep open. Current main has browser snapshot caps, opt-in/configured efficient snapshots, and generic tool-result truncation, but it still does not make browser reads goal-shaped by default or return compact post-action change reports, so the central browser-specific context-budget request remains.

## What This Changes

Request browser-tool context-budget mitigation so browser reads are compact and task-shaped, with raw page data kept out of model context unless explicitly requested.

## Best Possible Solution

Choose a browser-tool contract where default model-facing reads are compact and goal-shaped, raw/full snapshots are explicit, and actions return bounded change reports, then prove it on a content-heavy multi-step browser task.
