## Summary

Keep open. Current main and the latest release have snapshot caps, optional efficient snapshots, and generic tool-result guards, but they still do not make compact goal-shaped browser reads or post-action change reports the default browser interaction contract requested here.

## What This Changes

The issue requests browser-tool context handling that avoids injecting large page snapshots into model context during multi-step browser interactions.

## Best Possible Solution

Define a browser plugin output contract that defaults to compact task-relevant snapshots and small post-action change reports, while keeping explicit raw/full reads with tests, docs, and live noisy-page proof.
