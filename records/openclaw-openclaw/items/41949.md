## Summary

Keep open. Current main and v2026.6.11 include useful browser snapshot caps, efficient mode, and generic tool-result context guards, but they still do not provide the requested default compact, goal-shaped browser-read contract or compact post-action change reports.

## What This Changes

The issue requests browser-tool context-budget controls so interactive browser reads and actions avoid injecting excessive page content into model context.

## Best Possible Solution

Make compact, goal-shaped browser reads the interactive default, keep explicit raw/full snapshot access, add compact post-action change signals, and prove the behavior on a noisy multi-step browser flow.
