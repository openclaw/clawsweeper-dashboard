## Summary

Keep open. Current main has useful safeguards for browser context pressure, including AI snapshot caps, efficient mode, selector and batch actions, browser skill guidance, and generic tool-result truncation, but it still does not make compact goal-shaped browser reads or post-action change reports the default interaction contract.

## What This Changes

The issue requests browser-tool context-budget controls so large page snapshots do not crowd out multi-step browser reasoning.

## Best Possible Solution

Define compact goal-shaped browser reads as the intended interactive default, preserve explicit full/raw snapshot access, add compact post-action state or change signals, and prove the result on a noisy multi-step browser flow.
