## Summary

Keep open. Current main has browser snapshot caps, efficient/role snapshot modes, and generic tool-result truncation, but the default browser interaction loop still returns model-visible page snapshots and lacks the requested goal-shaped browser read plus compact post-action change-report contract.

## What This Changes

Request browser interactions to be context-budget aware by default so large page snapshots do not consume model context during multi-step browser tasks.

## Best Possible Solution

Make browser reads compact and task-shaped by default, keep raw/full snapshots as explicit escape hatches, and return compact post-action change signals for multi-step flows.
