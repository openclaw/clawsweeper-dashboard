## Summary

Keep open. Current main has meaningful browser snapshot caps, optional efficient mode, and generic tool-result context guards, but it still does not implement the requested default compact, goal-shaped browser read contract or compact post-action change-report semantics.

## What This Changes

Request browser interactions to avoid injecting excessive page content into model context by returning compact, task-relevant page state and action feedback.

## Best Possible Solution

Define compact, actionable browser state as the intended interactive default, preserve explicit full/raw snapshot access, add compact post-action state or change signals, and prove the result on a noisy multi-step browser flow.
