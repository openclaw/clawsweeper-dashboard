## Summary

Keep open. Current main has useful browser snapshot safeguards, including capped AI snapshots and an optional efficient mode, but it still does not implement the requested default compact, goal-shaped browser read contract or compact post-action change reports.

## What This Changes

The issue asks OpenClaw browser interactions to avoid exhausting model context by sending compact, task-relevant page state instead of repeatedly injecting large page snapshots.

## Best Possible Solution

Define a maintainer-approved browser read/action-output contract: compact goal-shaped snapshots by default for interactive work, compact post-action change reports, and an explicit raw/ARIA full-snapshot escape hatch with docs, focused tests, and live browser proof.
