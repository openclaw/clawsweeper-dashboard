## Summary

Keep open. Current main and the latest release have browser snapshot caps, efficient snapshot mode, and generic tool-result truncation, but they still do not implement the requested default browser contract: compact, goal-shaped reads plus small post-action change reports for multi-step browser work.

## What This Changes

The issue asks for browser interactions to become context-budget aware so large page snapshots do not consume the model context during multi-step browser automation.

## Best Possible Solution

Define a maintainer-approved browser output contract that defaults to compact, task-relevant reads and small post-action change reports while preserving explicit raw/full snapshot escape hatches with tests, docs, and live noisy-page proof.
