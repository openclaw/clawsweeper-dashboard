## Summary

The live Azure terminal evidence is strong, but automatically adding request fields for existing Azure/Foundry configurations remains a maintainer-visible compatibility choice before merge.

## What This Changes

The branch automatically enables stable OpenAI Chat Completions prompt-cache keys for dedicated Azure OpenAI endpoints and OpenAI-family Azure AI Foundry deployments, while retaining explicit compatibility overrides and cache-retention controls.

## System Context

OpenClaw resolves model compatibility before its OpenAI Chat Completions provider and boundary-aware agent transport build upstream requests. The resolved capability determines whether session cache keys and requested retention are retained or removed before the request reaches Azure/OpenAI endpoints.
