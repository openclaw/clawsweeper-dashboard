## What This Changes

The PR moves prompt-cache-key enablement into the shared OpenAI Chat Completions compatibility rules so direct OpenAI and Azure OpenAI endpoints automatically send stable session cache keys.

## System Context

OpenClaw resolves a model’s provider and endpoint compatibility before building OpenAI Chat Completions requests. Those resolved capabilities determine whether session cache-routing fields and long cache retention reach the upstream Azure or OpenAI endpoint.

## Best Possible Solution

Add the regional `*.api.cognitive.microsoft.com` hostname suffix to the shared Azure rule, document it with the other Azure families, and add a regression case that proves the resolved compatibility enables the cache key without an explicit override.
