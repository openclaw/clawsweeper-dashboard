## Summary

Keep open: current main and the latest release still lack Workers AI model or endpoint selection for the Cloudflare AI Gateway non-interactive auth choice, and the remaining fix needs maintainer product direction because it changes provider onboarding, model routing, credentials, and compatibility behavior.

## What This Changes

The issue requests non-interactive Cloudflare AI Gateway onboarding support for selecting Workers AI models such as `workers-ai/@cf/...`.

## Best Possible Solution

Define a provider-owned Cloudflare endpoint-family and model-selection contract that can generate Workers AI `@cf/...` config while preserving current Anthropic Gateway behavior, then update docs and focused onboarding tests.

## Reproduction Assessment

Yes, at source level: the Cloudflare non-interactive auth choice has no Workers AI model or endpoint option and always applies the Anthropic provider config. I did not run a credentialed Cloudflare onboard flow in this read-only review.

## Solution Assessment
