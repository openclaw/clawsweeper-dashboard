## Summary

Keep open: current main and v2026.6.11 still generate a Cloudflare AI Gateway Anthropic/Claude-only onboarding config, while the requested Workers AI model-selection path for non-interactive onboarding remains missing and product-sensitive.

## What This Changes

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
