## Summary

Keep open: current main and v2026.6.11 still configure Cloudflare AI Gateway onboarding as an Anthropic/Claude passthrough, while the requested Workers AI model-selection path remains missing and needs a product decision.

## What This Changes

The issue requests non-interactive Cloudflare AI Gateway onboarding support for selecting Workers AI `@cf/...` models instead of accepting the current default model.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
