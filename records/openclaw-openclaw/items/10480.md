## Summary

Keep open: the supported Cloudflare AI Gateway path remains documented as an external official plugin, but the requested non-interactive Workers AI model-selection flow is not established by the current setup docs. The two open Cloudflare provider issues overlap on endpoint and catalog design, yet neither clearly replaces this issue’s narrow onboarding requirement.

## What This Changes

Add a supported non-interactive onboarding path that configures Cloudflare AI Gateway for a selected Workers AI `@cf/...` model.

## Best Possible Solution

Choose one official Cloudflare AI Gateway contract, then implement Workers AI as a plugin-owned onboarding mode that writes the correct OpenAI-compatible endpoint and model configuration, documents the exact non-interactive command, and covers fresh setup with focused tests.
