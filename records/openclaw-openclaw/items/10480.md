## Summary

Keep open: current main and the latest release still generate an Anthropic/Claude-only Cloudflare AI Gateway onboarding config, while the requested Workers AI model-selection path remains unsolved and broader Cloudflare bridge issues do not replace this onboarding-specific acceptance criterion.

## What This Changes

Request to let non-interactive Cloudflare AI Gateway onboarding choose Workers AI endpoints and `@cf/...` models instead of always using the default Anthropic/Claude gateway config.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the right endpoint, `@cf/...` model entries, default model selection, docs, tests, and upgrade behavior without breaking existing Anthropic Gateway setups.
