## What This Changes

Add non-interactive onboarding support for selecting a Cloudflare Workers AI model and generating the corresponding provider and model configuration.

## Best Possible Solution

Define Workers AI as a plugin-owned Cloudflare endpoint and model mode, coordinate it with the REST and multi-provider design, then generate canonical OpenAI-compatible configuration and document scripted setup and upgrade behavior.
