## Summary

Keep open: current main and latest release still configure Cloudflare AI Gateway onboarding as a fixed Anthropic/Claude path, while Workers AI model selection remains missing and product-sensitive.

## What This Changes

The issue requests non-interactive Cloudflare AI Gateway onboarding support for selecting Workers AI models or generating the corresponding Workers AI provider config.

## Best Possible Solution

Define a provider-owned Workers AI/REST onboarding mode in the Cloudflare plugin, with explicit model/endpoint semantics, generated config, docs, tests, and live proof; if maintainers decline that surface, document the exact custom-provider command instead.
