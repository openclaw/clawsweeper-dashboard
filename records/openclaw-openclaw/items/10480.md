## Summary

Keep open: current main and v2026.6.11 still configure the Cloudflare AI Gateway onboarding path as an Anthropic/Claude passthrough, while the requested Workers AI model-selection flow remains missing. The broader Cloudflare bridge and REST issues overlap, but they do not replace this onboarding-specific acceptance criterion.

## What This Changes

The issue requests a way to select Cloudflare Workers AI `@cf/...` models during non-interactive Cloudflare AI Gateway onboarding.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, selected `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
