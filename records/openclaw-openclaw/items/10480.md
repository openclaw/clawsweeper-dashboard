## Summary

Keep open. The captured prior review and the two still-open Cloudflare provider design issues show that Workers AI model selection during bundled non-interactive onboarding remains a concrete gap, but the durable endpoint, catalog, and provider contract needs maintainer direction before a focused implementation should proceed.

## What This Changes

Add a supported `openclaw onboard --non-interactive` flow that selects Cloudflare Workers AI models through Cloudflare AI Gateway rather than defaulting the bundled provider to Anthropic/Claude.

## Best Possible Solution

Choose one Cloudflare AI Gateway contract for new setups, then implement Workers AI as a plugin-owned onboarding mode that emits the correct endpoint, API type, model identifiers, and documentation with focused generated-config coverage.
