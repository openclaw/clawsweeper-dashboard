## Summary

Keep open: current main and v2026.6.11 still configure the Cloudflare AI Gateway onboard flow as an Anthropic/Claude passthrough, while the requested Workers AI model-selection path remains missing and product-sensitive.

## What This Changes

The issue requests non-interactive onboarding support for selecting Cloudflare Workers AI models when using the `cloudflare-ai-gateway-api-key` auth choice.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, selected `@cf/...` model entries, default model, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
