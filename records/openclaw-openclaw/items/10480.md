## Summary

Keep open: current main and v2026.6.11 still configure the bundled Cloudflare auth choice as an Anthropic-only provider with one Claude default. The generic custom-provider workaround does not provide the requested supported Workers AI onboarding flow, and the broader related issues remain open without replacing this concrete setup requirement.

## What This Changes

Add supported Cloudflare Workers AI endpoint and model selection to non-interactive onboarding with the bundled Cloudflare AI Gateway auth choice.

## Best Possible Solution

Add one Cloudflare plugin-owned, backward-compatible Workers AI mode that selects the `/workers-ai/v1` OpenAI-compatible endpoint and an explicit `@cf/...` model while preserving the existing Anthropic mode; document and test both fresh non-interactive paths. If maintainers reject a first-class mode, formally document and validate the exact generic custom-provider command instead.
