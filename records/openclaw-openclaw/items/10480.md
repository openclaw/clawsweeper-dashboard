## Summary

Keep open: current main still does not let `openclaw onboard --non-interactive --auth-choice cloudflare-ai-gateway-api-key` select a Workers AI endpoint or `@cf/...` model, and the broader Cloudflare bridge issues overlap without replacing this onboarding-specific acceptance criterion.

## What This Changes

Support selecting Cloudflare Workers AI models during non-interactive onboarding for the Cloudflare AI Gateway auth choice.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that generates the right endpoint, `@cf/...` model catalog entries, default model selection, docs, and upgrade behavior without breaking existing Anthropic Gateway setups.
