## Summary

Current main still documents and configures the official Cloudflare path as an Anthropic-only provider, so Workers AI selection during non-interactive onboarding remains necessary. The concrete onboarding requirement overlaps broader Cloudflare provider work but is not yet replaced by a merged implementation or confirmed canonical issue.

## What This Changes

Allow non-interactive Cloudflare AI Gateway onboarding to configure and select a Workers AI `@cf/...` model.

## Best Possible Solution

Make the official Cloudflare provider own an explicit endpoint/provider mode and pinned-model selection, generate the correct Workers AI OpenAI-compatible configuration, preserve the existing Anthropic setup, and prove both fresh non-interactive onboarding and a live redacted Cloudflare request.
