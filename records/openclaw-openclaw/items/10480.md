## Summary

Keep open: current main and v2026.6.11 still configure Cloudflare AI Gateway onboarding as a fixed Anthropic/Claude path, while Workers AI endpoint and @cf model selection remain missing and product-sensitive.

## What This Changes

Request Workers AI endpoint and model selection in non-interactive Cloudflare AI Gateway onboarding so @cf models can be selected without manual config edits.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, @cf model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
