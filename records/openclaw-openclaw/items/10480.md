## Summary

Keep open: current main and v2026.6.11 still configure Cloudflare AI Gateway onboarding as an Anthropic Messages/Claude default with no Workers AI endpoint or `@cf/...` model selector, and the remaining work needs maintainer product direction.

## What This Changes

The issue requests Workers AI endpoint/model selection for `openclaw onboard --non-interactive --auth-choice cloudflare-ai-gateway-api-key`.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, selected `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
