## Summary

Keep open: current main and v2026.6.11 still configure the bundled Cloudflare AI Gateway auth choice as an Anthropic Messages provider with one Claude default, so the requested Workers AI model-selection path during non-interactive onboarding remains missing. The broader Cloudflare bridge and REST issues overlap, but they do not replace this onboarding-specific acceptance criterion.

## What This Changes

The issue asks for non-interactive Cloudflare AI Gateway onboarding to support Workers AI endpoint and model selection instead of leaving users on the bundled default model.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, selected @cf model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
