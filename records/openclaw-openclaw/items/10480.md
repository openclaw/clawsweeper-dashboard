## Summary

Keep open: current main and v2026.6.11 still configure Cloudflare AI Gateway onboarding as a fixed Anthropic/Claude passthrough, while the requested Workers AI model-selection path for non-interactive onboarding remains missing and product-sensitive.

## What This Changes

The issue requests a non-interactive onboarding path that can configure Cloudflare Workers AI model IDs through Cloudflare AI Gateway instead of accepting the bundled default model.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, @cf model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
