## Summary

Keep open: current main and v2026.6.11 still lack Workers AI model or endpoint selection for the Cloudflare AI Gateway non-interactive auth choice, and the remaining fix needs maintainer product direction because it changes provider onboarding, model routing, credentials, headers, and compatibility behavior.

## What This Changes

The issue requests a non-interactive Cloudflare AI Gateway onboarding path that can select Workers AI endpoints and `@cf/...` models instead of only the current default model.

## Best Possible Solution

Define a provider-owned Cloudflare endpoint-family and model-selection contract in `extensions/cloudflare-ai-gateway` that can generate Workers AI `@cf/...` config while preserving the current Anthropic Gateway behavior or providing an explicit migration story, then document and test that contract.

## Reproduction Assessment

Yes, at source level: current main's Cloudflare non-interactive auth choice has no Workers AI model or endpoint option and always applies the Anthropic provider config. I did not run a credentialed Cloudflare onboard flow in this read-only review.

## Solution Assessment

Unclear. The user need is valid, but maintainers need to choose whether the durable fix is a first-class Workers AI mode, the broader Cloudflare REST bridge, or a documented custom-provider workflow.
