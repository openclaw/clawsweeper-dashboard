## Summary

Keep open: current main and v2026.6.11 still generate a Cloudflare AI Gateway Anthropic/Claude-only onboarding config, while the requested Workers AI model-selection path for non-interactive onboarding remains missing.

## What This Changes

The issue requests Workers AI model and endpoint selection for non-interactive Cloudflare AI Gateway onboarding so `@cf/...` model config can be generated without manual edits.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
