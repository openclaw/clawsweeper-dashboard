## Summary

Keep open: current main and v2026.6.11 still configure Cloudflare AI Gateway onboarding as an Anthropic Messages/Claude default with no Workers AI endpoint or `@cf/...` model selector, and the remaining fix needs maintainer product direction.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the requested endpoint, `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
