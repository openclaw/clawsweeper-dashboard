## Summary

Current main and v2026.6.11 still do not provide a supported Workers AI model or endpoint selector for the bundled Cloudflare non-interactive onboarding path. The broader Cloudflare issues share the Anthropic-only provider limitation but do not replace this issue’s concrete generated-config and onboarding requirement, so it should remain open for a provider-direction decision.

## What This Changes

Add a supported way to select Cloudflare Workers AI models when using the Cloudflare AI Gateway auth choice during non-interactive onboarding.

## Best Possible Solution

Add a backward-compatible, plugin-owned Cloudflare endpoint mode that accepts a Workers AI model ID, writes the `/workers-ai/v1` OpenAI-compatible provider configuration, preserves the existing Anthropic path, documents automation usage, and proves the generated config with focused tests plus a live Cloudflare round trip.
