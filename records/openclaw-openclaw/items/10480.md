## Summary

Keep open: current main and v2026.6.11 still configure Cloudflare AI Gateway onboarding as an Anthropic/Claude path, while the requested Workers AI model-selection path remains missing and product-sensitive.

## What This Changes

The issue requests Workers AI model selection support during non-interactive Cloudflare AI Gateway onboarding.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, selected `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
