## Summary

Keep open: current main and v2026.6.11 still configure the Cloudflare AI Gateway onboarding path as an Anthropic Messages provider with a Claude default, with no Workers AI endpoint mode or `@cf/...` model selector.

## What This Changes

The issue asks for non-interactive Cloudflare AI Gateway onboarding to select Workers AI `@cf/...` models or generate the Workers AI provider config automatically.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, `@cf/...` model entries, default selection, docs, tests, and upgrade behavior while preserving existing Anthropic Gateway setups.
