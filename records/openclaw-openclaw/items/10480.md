## Summary

Keep open: current main and the latest release still generate Cloudflare AI Gateway onboarding as an Anthropic Messages provider with one Claude default, while Workers AI model selection remains unimplemented and product-sensitive.

## What This Changes

The issue requests a non-interactive Cloudflare AI Gateway onboarding path that can select Workers AI models such as `workers-ai/@cf/...` instead of only using the bundled default model.

## Best Possible Solution

Define the provider-owned Cloudflare onboarding contract first, then implement either an explicit Workers AI endpoint/model mode or a documented custom-provider command while preserving the existing Anthropic Gateway path.
