## Summary

Keep open: current main and v2026.6.11 still configure the Cloudflare AI Gateway onboarding path as an Anthropic/Claude passthrough, while the requested Workers AI model and endpoint selection path remains missing and product-sensitive.

## What This Changes

The issue requests Workers AI model selection support in non-interactive Cloudflare AI Gateway onboarding.

## Best Possible Solution

Define a Cloudflare plugin-owned Workers AI onboarding contract that writes the correct endpoint, selected `@cf/...` model entries, default model, docs, tests, live proof, and compatibility behavior for existing Anthropic Gateway setups.
