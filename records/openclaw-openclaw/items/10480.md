## Summary

Current main and v2026.6.11 still cannot generate a Workers AI model configuration through the bundled Cloudflare non-interactive auth choice. This remains a distinct onboarding requirement, but implementation depends on a maintainer decision about the provider-wide Cloudflare endpoint, model-ID, and credential contract.

## What This Changes

Add a supported way to select Cloudflare Workers AI models when running non-interactive onboarding with the bundled Cloudflare AI Gateway auth choice.

## Best Possible Solution

Define the Cloudflare plugin’s canonical REST/legacy, credential, and model-ID contract, then expose an in-product Workers AI model selector through shared config builders used by interactive onboarding, non-interactive onboarding, catalog generation, and docs.
