## Summary

Keep open: current main and v2026.6.11 still lack terminal commands to list approved DM pairings or revoke an approved sender, while the existing in-chat `/allowlist` support only partially overlaps the requested admin workflow. The remaining work is a security-sensitive product decision because it exposes and mutates sender authorization state and overlaps the broader contact inventory issue.

## What This Changes

The issue requests CLI/admin support to list approved channel pairings, revoke a paired sender, and show merged config plus credentials allow-lists in channel status.

## Best Possible Solution

Define one account-scoped admin pairing/contact management surface that coordinates terminal CLI behavior with in-chat allowlist management and the broader contact inventory issue.
