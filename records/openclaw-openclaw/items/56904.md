  - body: These truthy checks skip intentional `resultText: ""` or `replyInstruction: ""` rewrites. A guard plugin trying to redact child output by clearing the text would leave the original child findings or instruction in place.
  - confidence: 0.88
- **[P2] Define or remove the redact guard decision:** `src/plugins/types.ts:2162`

A plugin returning `decision: "redact"` without also rewriting payload fields gets no redaction, which is unsafe for a security-facing API.
  - confidence: 0.84
