Full review comments:

- **[P1] Make escalation terminal before lower-priority hooks run:** `src/plugins/hooks.ts:794`
  - body: `runBeforeToolCallHook` treats `decision: "escalate"` without approval as a hard block, but this reducer keeps running lower-priority hooks unless the merged result is `block` or `deny`. A later plugin can attach `requireApproval`, changing a stricter guard decision into approvable execution.
  - confidence: 0.9
- **[P2] Preserve empty-string subagent result rewrites:** `src/agents/subagent-announce.ts:561-565`
  - body: These truthy checks skip intentional `resultText: ""` or `replyInstruction: ""` rewrites. A guard plugin trying to redact child output by clearing the text would leave the original child findings or instruction in place.
  - confidence: 0.88
- **[P2] Define or remove the redact guard decision:** `src/plugins/types.ts:2162`
  - body: The PR exports `redact` as a public guard decision and ranks it in the reducer, but the delivery call sites only implement behavior for `warn`, `deny`, and `escalate`. A plugin returning `decision: "redact"` without also rewriting payload fields gets no redaction, which is unsafe for a security-facing API.
  - confidence: 0.84
