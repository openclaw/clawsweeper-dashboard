## Label Justifications

- `P3`: This is low-severity skill onboarding ergonomics and product direction rather than an urgent runtime regression.
- `impact:security`: The requested behavior would move skill setup from displaying Homebrew guidance to executing package-manager bootstrap code.

## Summary

Keep open: current main and the latest release still use Homebrew guidance or missing-brew failures rather than installing Homebrew, and the requested automatic bootstrap needs maintainer product and security direction before implementation.

## What This Changes

Request automatic Homebrew installation when skill/onboarding installers need brew-backed dependencies and brew is missing.

## Best Possible Solution

Keep manual Homebrew guidance unless maintainers approve an explicit-consent bootstrap policy; if approved, implement it through the shared skill install lifecycle with docs and coverage for onboarding, direct install, macOS, Linux, and container cases.

## Reproduction Assessment

Yes. Source inspection shows onboarding displays Homebrew guidance or a command and direct brew-backed skill installs return missing-brew guidance instead of installing Homebrew.

## Solution Assessment

Unclear. Automatic Homebrew installation may reduce onboarding friction, but it is only the best solution after maintainers approve the consent, supply-chain, platform, and failure policy.
