## Summary

Keep open. Current main and the latest release still intentionally show Homebrew guidance or missing-brew failures instead of installing Homebrew, and changing that behavior needs maintainer product/security direction.

## What This Changes

The issue asks OpenClaw to automatically install Homebrew when a brew-backed skill installer finds brew missing.

## Best Possible Solution

Keep manual Homebrew guidance unless maintainers approve an explicit-consent bootstrap policy; if approved, implement it through the shared skill install lifecycle with docs and coverage for onboarding, direct install, macOS, Linux, and container cases.
