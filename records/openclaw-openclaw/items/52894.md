## Summary

Keep open. Current main and latest release still intentionally show Homebrew guidance or missing-brew failures instead of bootstrapping Homebrew, and changing that behavior needs maintainer product/security direction.

## What This Changes

The issue requests that OpenClaw automatically install Homebrew when a skill install needs `brew` and it is missing.

## Best Possible Solution

Keep the missing-Homebrew path explicit unless maintainers approve a trusted opt-in bootstrap flow with clear consent, platform limits, failure behavior, docs, and security proof.

## Reproduction Assessment

Yes. Source inspection shows onboarding displays the Homebrew install command and direct brew-backed skill installs return missing-brew guidance instead of installing Homebrew.

## Solution Assessment

Unclear. Automatic Homebrew installation may improve first-run UX, but it is only the best solution after maintainers approve the consent, supply-chain, platform, and failure policy.
