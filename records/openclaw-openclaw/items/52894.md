## Summary

Keep open. Current main and v2026.6.11 still deliberately show or return Homebrew guidance instead of installing Homebrew, and turning that into an automatic bootstrap remains a product/security decision.

## What This Changes

Request that skill/onboarding installers automatically install Homebrew when a brew-backed dependency is needed and brew is absent.

## Best Possible Solution

Keep manual Homebrew guidance unless maintainers approve an explicit, operator-controlled Homebrew bootstrap policy; if approved, implement it through the shared skill lifecycle and onboarding paths with docs and coverage for macOS, Linux, and containers.

## Reproduction Assessment

Yes. Source inspection on current main shows setupSkills only displays the Homebrew install command when brew is missing, and installSkill returns brew-not-installed failures instead of bootstrapping Homebrew.

## Solution Assessment

Unclear. Automatic Homebrew installation may reduce first-run friction, but the best fix requires maintainer approval of the consent, supply-chain, platform, and failure policy first.
