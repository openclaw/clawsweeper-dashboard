## Summary

Keep open. Current main still deliberately shows Homebrew guidance or skips missing-brew installers instead of bootstrapping Homebrew, and the remaining change is a security/product choice about whether skill setup may run a package-manager installer.

## What This Changes

Request automatic Homebrew installation when skill dependency setup finds brew missing.

## Best Possible Solution

Keep manual Homebrew guidance as the default unless maintainers approve an explicit-consent bootstrap policy with platform limits, supply-chain controls, docs, and focused onboarding/install coverage.
