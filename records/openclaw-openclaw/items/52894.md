## Summary

Keep open. Current main and the latest release still treat missing Homebrew as a manual prerequisite, and changing that into running the Homebrew bootstrapper needs maintainer product and security direction.

## What This Changes

Request for OpenClaw onboarding or skill installation to automatically install Homebrew when a brew-backed skill needs it and Homebrew is missing.

## Best Possible Solution

Keep manual Homebrew guidance unless maintainers approve an explicit-consent bootstrap policy; if approved, implement it through the shared skill install lifecycle with docs and coverage for onboarding, direct install, macOS, Linux, and container cases.

## Reproduction Assessment

Yes, at source level. Current onboarding shows Homebrew guidance and skips brew-backed installs when readiness says brew is missing, while direct brew installs return a missing-brew failure instead of bootstrapping Homebrew.

## Solution Assessment

Unclear. Automatic Homebrew installation may improve first-run UX, but it is only the best solution if maintainers approve the consent, supply-chain, platform, and failure policy.
