## Summary

Keep open. Current main and the latest release still deliberately show Homebrew guidance or return a missing-brew failure instead of installing Homebrew, and turning that into an automatic bootstrap remains a maintainer product/security decision rather than conservative cleanup.

## What This Changes

The issue requests that skill installation/onboarding install Homebrew automatically when a brew-backed skill dependency is selected and `brew` is missing.

## Best Possible Solution

Keep the manual Homebrew policy until maintainers approve an explicit bootstrap design; if approved, implement it through the shared skill install lifecycle with consent, platform limits, docs, and regression coverage for onboarding and direct install paths.

## Reproduction Assessment

Yes. Source inspection shows current main and v2026.6.11 display Homebrew guidance and return missing-brew guidance instead of bootstrapping Homebrew.

## Solution Assessment

Unclear. Automatic Homebrew installation may improve first-run skill setup, but it is only the best solution if maintainers approve the consent, supply-chain, privilege, and platform policy.
