## Summary

Keep open. Current main and the latest release still use manual Homebrew guidance or skip missing brew-backed installers, so the remaining request is a maintainer product/security decision about whether skill setup may execute a Homebrew bootstrapper.

## What This Changes

Request OpenClaw skill onboarding and skill dependency installation to automatically install Homebrew when a brew-backed skill needs it and `brew` is missing.

## Best Possible Solution

Keep manual Homebrew guidance as the default unless maintainers approve an explicit-consent bootstrap policy with platform limits, supply-chain controls, docs, and focused onboarding/install coverage.
