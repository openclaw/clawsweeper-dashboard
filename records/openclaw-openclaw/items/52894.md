## Summary

Keep open. Current main and the latest stable release still do not auto-install Homebrew for skill dependency setup, and the documented policy explicitly keeps Homebrew bootstrap manual; changing that is a product and security decision rather than a safe cleanup close.

## What This Changes

Request that skill onboarding or direct skill installs bootstrap Homebrew automatically when `brew` is missing instead of showing manual install guidance.

## Best Possible Solution

Keep manual Homebrew guidance unless maintainers approve an explicit-consent bootstrap policy; if approved, implement it in the shared skill install lifecycle with docs, security review, and coverage for onboarding, direct install, macOS, Linux, and container cases.

## Reproduction Assessment

Yes, at source level. Current main displays Homebrew guidance and direct brew installs return a missing-brew failure instead of installing Homebrew; I did not live-run the interactive installer in this read-only review.

## Solution Assessment

Unclear. Automatic Homebrew installation could reduce setup friction, but it is only the best solution if maintainers approve the consent, supply-chain, platform, and failure policy.
