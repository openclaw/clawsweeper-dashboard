## Summary

Keep open. Current main and the latest release still show or document Homebrew setup guidance instead of automatically bootstrapping Homebrew, and the remaining request is a security/product decision about whether onboarding may execute package-manager setup code.

## What This Changes

Request to let skill onboarding install Homebrew automatically when brew-backed skill dependencies need it and brew is missing.

## Best Possible Solution

Keep manual Homebrew guidance as the default unless maintainers approve an explicit-consent bootstrap policy with platform limits, supply-chain controls, docs, and focused onboarding/install coverage.
