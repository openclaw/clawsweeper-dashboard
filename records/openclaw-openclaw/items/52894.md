## Summary

Keep open. Current main and the latest release still intentionally show Homebrew guidance or a missing-brew failure instead of bootstrapping Homebrew, and changing that into an executed installer needs maintainer product and security direction.

## What This Changes

The issue requests that skill installation/onboarding install Homebrew automatically when `brew` is missing instead of showing manual install guidance.

## Best Possible Solution

Keep manual Homebrew guidance unless maintainers approve an explicit-consent bootstrap policy; if approved, implement it through the shared skill install lifecycle with docs and coverage for onboarding, direct install, macOS, Linux, and container cases.

## Reproduction Assessment

Yes. Source inspection shows onboarding displays a Homebrew install command for supported platforms when brew is absent, while direct brew-backed skill installs return missing-brew guidance instead of bootstrapping Homebrew.

## Solution Assessment

Unclear. Automatic Homebrew installation may reduce first-run friction, but it is only the best solution after maintainers approve the consent, supply-chain, platform, and failure policy.
