## Summary

Keep open: automatic Homebrew bootstrap is still absent on current main and in the latest release, while current docs/tests intentionally keep Homebrew as guidance-only behavior that needs explicit product and security direction before changing.

## What This Changes

Request that skill onboarding install Homebrew automatically when brew-backed dependencies are selected and `brew` is missing.

## Best Possible Solution

Keep guidance-only behavior unless maintainers approve an explicit-consent Homebrew bootstrap policy; if approved, implement it in the shared skill install lifecycle with platform/container docs and focused coverage.
