## Summary

Keep this PR open: the direct tool-context alias path is useful, but the patch is not merge-ready because it leaves the real embedded deferred catalog path exact-name only and splits alias calls across raw start events and canonical completion/result events.

## What This Changes

## Best Possible Solution

Move alias resolution into one shared tool-resolution boundary used by direct and embedded deferred catalog hydration, and keep lifecycle event identity consistent before merge.
