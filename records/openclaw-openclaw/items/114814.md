## Summary

Keep this PR open for explicit browser-tool product review. It is a fresh, protected-label feature proposal tied to an open canonical request, and it changes every successful navigation result by attaching compact page state; no safe cleanup or close reason applies.

## What This Changes

The PR makes browser `navigate` and document-changing batch `act` results include a compact inline snapshot so the agent can use fresh refs without a separate snapshot call.

## System Context

The browser plugin converts agent browser-tool calls into direct or node-proxied browser operations. A navigation result becomes input to the next model action, so attaching page state can reduce model round trips but also changes the tool's normal response payload and context use.
