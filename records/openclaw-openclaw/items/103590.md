- `impact:security`: The issue concerns unauthorized cross-agent exposure of potentially sensitive persisted information.

## Summary

Keep open: current main and the latest release retain a confirmed cross-agent memory disclosure path, while both prior isolation PRs closed unmerged. This issue is now the active canonical report and needs an explicit security and migration decision before implementation.

## What This Changes

Prevent memory-lancedb auto-recall from injecting shared persisted memories into agents whose effective per-agent memory search is disabled.

## Best Possible Solution

Establish a secure-by-default memory-plugin isolation contract, honor effective per-agent disablement, and scope LanceDB reads and writes by agent with one tested migration path for existing shared records.
