## Summary

Keep open: current main and the latest release still lack a hook/webhook-specific cleanup or archival policy, while the merged cleanup work only covers cron-keyed `deleteAfterRun` sessions. The remaining work needs maintainer product direction because it adds config/default behavior and controls transcript retention.

## What This Changes

The issue requests configurable cleanup or archival behavior for hook/webhook-created sessions after processing completes.

## Best Possible Solution

Define a maintainer-approved core hook session lifecycle policy that covers on-complete cleanup, delayed retention, transcript retention, completed-session visibility, and precedence with existing session and cron maintenance.

Rationale: The fix adds a new config/default surface and can affect stored session history and transcripts, so automation should not choose cleanup defaults or transcript-retention behavior without maintainer intent.

Options:

- **Add explicit hook cleanup policy (recommended):** Add a default-preserving `hooks.sessionCleanup`-style policy with explicit on-complete, delayed, never, and transcript-retention behavior plus upgrade-safe docs/tests.
- **Rely on existing session maintenance:** Keep hook sessions governed only by generic `session.maintenance` and document operational cleanup instead of adding a hook-specific config surface.
- **Defer pending session-mode decisions:** Wait for the hook session-reuse and persistent-session direction to settle before adding cleanup semantics that could conflict with multi-turn hooks.

## Reproduction Assessment

Yes, source inspection reproduces the missing capability: hook config/schema omit lifecycle fields, hook dispatch does not pass cleanup flags, and the cron cleanup helper ignores non-cron hook session keys. I did not run a live hook workload in this read-only review.

## Solution Assessment

Unclear until maintainers choose the product contract; an unconditional cleanup patch would be too risky. The narrowest maintainable path is an explicit default-preserving hook cleanup policy with transcript-retention and precedence rules.
