## Summary

Keep open: current main provides generic age/count/disk-budget session maintenance, but hook agent runs still lack a hook-specific completion, delayed-retention, transcript-retention, and completed-session visibility contract. The issue remains useful, but implementation must wait for a product decision because current main also supports persistent hook sessions when a stable key remains fresh, so unconditional cleanup could destroy intended multi-turn state. ([github.com](https://github.com/openclaw/openclaw/blob/main/docs/reference/session-management-compaction.md?utm_source=openai))

## What This Changes

Add configurable lifecycle rules for hook-triggered sessions, including completion or delayed cleanup, transcript retention, and completed-session listing behavior.

## Best Possible Solution

Define one core hook-session lifecycle contract with the current persistent behavior as the compatibility default, explicit persistent versus ephemeral intent per hook or mapping, optional completion/TTL cleanup, transcript preservation rules, and consistent completed-session visibility.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should hook sessions remain persistent by default with an explicit per-hook ephemeral/retention mode, or should all hook sessions inherit a new global cleanup policy?

Rationale: Current main supports both one-shot generated hook keys and intentionally reusable stable keys, so the default, policy scope, transcript semantics, and interaction with generic maintenance cannot be chosen safely from implementation evidence alone.

Likely owner: steipete

Owner reason: The prior review and broad hook/config history make steipete the strongest available routing candidate for the product-level default and config-surface choice.

Owner confidence: medium

Options:

- **Explicit lifecycle per hook (recommended):** Keep current persistence as the default and add a mapping/request lifecycle mode for persistent, completion-cleaned, or TTL-cleaned sessions with explicit transcript handling.
- **Global hook retention:** Add only a global `hooks.sessionRetention` duration, preserving sessions until the timer expires but leaving immediate disposal and per-mapping intent unsupported.
- **Use generic maintenance:** Decline a hook-specific surface and document `session.maintenance` as the supported age/count/disk-budget cleanup mechanism.
