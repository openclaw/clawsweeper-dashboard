  - body: This external PR still adds `typebox` to the dashboard plugin and updates the lockfile. The dependency-graph guard blocks contributor graph changes unless admin/secops explicitly authorizes the current head SHA, so this needs approval or removal before merge.

  - body: The dashboard store creates and mutates `stateDir/dashboard/workspace.json` plus JSON undo sidecars as runtime state.   - body: The manifest validates an `entrypoint`, but the iframe host drops that value and always builds the URL for `index.html`. Any approved widget whose manifest points at a different entrypoint will mount the wrong file or fail despite passing manifest validation.
  - confidence: 0.88

  - body: The unauthenticated widget asset route sends CSP, referrer, and cache headers on successful assets, but `notFound()` responses omit them. Traversal, pending, rejected, or missing widget iframe responses should keep the same sandbox headers so the route never serves an unprotected document response.
  - confidence: 0.86
- **[P2] Preserve hidden widgets in the UI model:** `ui/src/lib/dashboard/index.ts:168-180`
  - body: The backend schema has a `hidden` flag and `hideWidget()` sends `{ hidden: true }`, but the UI read model omits `hidden` and then removes the widget locally. Hidden widgets cannot be restored or represented consistently because the client loses the state it just wrote.
  - confidence: 0.84
