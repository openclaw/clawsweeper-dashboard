  - body: This external PR adds `typebox` to the dashboard plugin and updates the lockfile. The dependency-graph guard blocks contributor graph changes unless admin/secops explicitly authorizes the current head SHA, so this needs either that approval or removal of the new dependency before merge.

  - body: The dashboard store creates and mutates `stateDir/dashboard/workspace.json` plus JSON undo sidecars as runtime state. OpenClaw-owned plugin runtime state should use the SQLite-backed plugin state surfaces, so this JSON store would ship a second persistent state path with unclear migration and backup semantics.
  - confidence: 0.92
- **[P2] Serve the manifest-approved entrypoint:** `ui/src/components/dashboard-custom-widget.ts:224-244`
  - body: The manifest validates an `entrypoint`, but the iframe host drops that value and always builds the URL for `index.html`. Any approved widget whose manifest points at a different entrypoint will mount the wrong file or fail despite passing manifest validation.
  - confidence: 0.88
- **[P2] Apply sandbox headers to widget-route 404s:** `extensions/dashboard/src/serve.ts:136-140`
  - body: The unauthenticated widget asset route sends CSP, referrer, and cache headers on successful assets, but `notFound()` responses omit them and tests currently expect that weaker behavior. Traversal, pending, rejected, or missing widget iframe responses should keep the same sandbox headers so the route never serves an unprotected document response.
  - confidence: 0.86
- **[P2] Preserve hidden widgets in the UI model:** `ui/src/lib/dashboard/index.ts:159-180`
  - body: The backend schema has a `hidden` flag and `hideWidget()` sends `{ hidden: true }`, but the UI read model omits `hidden` and then removes the widget locally. Hidden widgets cannot be restored or represented consistently after the patch because the client loses the state it just wrote.
  - confidence: 0.84
