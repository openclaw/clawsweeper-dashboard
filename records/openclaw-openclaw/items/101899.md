## Summary

Keep open. The previously reported P2 remains on the current head: rejected `chat.send` or disconnected-client dispatches are swallowed without operator feedback. The patch otherwise has strong proof and a defensible security design, but the bundled prompt-producing action-form capability still needs explicit Workspaces product sponsorship.

## What This Changes

The PR adds expiring and pinnable Workspace widgets plus a confirmed, rate-limited built-in action form that dispatches prompts through `chat.send`.

## Best Possible Solution

Sponsor the action form as a bounded Workspaces capability only if maintainers want that product direction, then route rejected dispatches through the existing Control UI error/toast mechanism while retaining exact-prompt confirmation, declared-field validation, per-widget rate limits, and transactional expiry cleanup.
