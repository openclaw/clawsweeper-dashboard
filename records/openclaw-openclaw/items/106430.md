## Summary

Current main still deliberately appends the reported plain-text directive when isolated announce delivery lacks the message tool, and the focused test codifies that behavior even while other tools remain available. The merged related work at https://github.com/openclaw/openclaw/pull/65638 usefully removed summarization language but retained the conflicting output-format instruction, so it does not resolve this report. Likely related people: @srinivaspavan9 (high confidence, introduced the current wording), @shakkernerd (high confidence, sustained isolated-cron runner work), and @steipete (high confidence, major runner refactor and merge history).

## What This Changes

Remove the plain-text output directive from isolated announce cron prompts so models can continue using available tools before automatic delivery.

## Best Possible Solution

Use neutral delivery guidance such as “Your response will be delivered automatically,” and add regression coverage proving the prompt does not constrain response format when non-message tools remain available.
