## Summary

Current main still appends a plain-text output directive to delivery-enabled isolated cron prompts, including the tested case where non-message tools such as `read` remain available. The source conflict is credible and narrowly fixable, while the reporter’s eight experiments are useful live evidence but were not independently reproduced. Likely related people: @srinivaspavan9 (high confidence, introduced the current wording), @shakkernerd (high confidence, sustained isolated-cron runner work), and @steipete (high confidence, major runner refactors and merges).

## What This Changes

Remove the isolated announce-delivery prompt’s plain-text output directive so models can continue making API-level tool calls before automatic delivery.

## Best Possible Solution

Keep automatic-delivery guidance but remove output-modality language that can be read as forbidding tools, then add regression coverage proving delivery-enabled prompts permit non-message tool calls and no longer contain `as plain text`.
