## Summary

## What This Changes

The issue reports that Google Chat accepts `channels.googlechat.replyToMode: "off"` but still sends replies into threads instead of suppressing thread targets.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/89790 or a maintainer-equivalent Google Chat threading fix, then close this issue once the fix reaches main.
