## Summary

Keep open: current main and v2026.6.11 still let Google Chat thread metadata reach outbound delivery despite `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 is the open closing fix candidate.

## What This Changes

Google Chat should honor `channels.googlechat.replyToMode: "off"` by suppressing implicit thread replies for text, media, typing-placeholder, and durable final delivery.

## Best Possible Solution

Review and land one canonical Google Chat thread-routing fix, preferably https://github.com/openclaw/openclaw/pull/89790, then close this issue with the merged commit and release provenance.
