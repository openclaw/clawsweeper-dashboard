## Label Justifications

- `P1`: This breaks an existing Google Chat channel workflow for users who configured off mode to avoid threaded replies.
- `impact:message-loss`: Replies can be routed into unintended Google Chat threads instead of the configured flat conversation, which is message misrouting.

## Summary

Keep open: current main and the latest release still carry Google Chat thread targets through paths that can bypass `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 is the open closing fix candidate.

## What This Changes

The issue asks Google Chat to honor `channels.googlechat.replyToMode: "off"` by suppressing implicit thread replies for text, media, typing, and durable delivery paths.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/89790 or a maintainer-equivalent Google Chat threading fix, then close this issue once the fix reaches main.
