## Summary

Keep open: current main and v2026.6.11 still allow Google Chat thread targets to survive into typing and delivery paths despite the existing off-mode config, and https://github.com/openclaw/openclaw/pull/89790 is the active open closing fix candidate.

## What This Changes

Honor `channels.googlechat.replyToMode: "off"` by preventing Google Chat replies and typing placeholders from carrying thread targets.

## Best Possible Solution
