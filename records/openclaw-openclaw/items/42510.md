## Summary

Keep open: current main and latest release still let Google Chat thread metadata reach outbound delivery despite `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 is the open closing fix candidate.

## What This Changes

The issue reports that Google Chat ignores `channels.googlechat.replyToMode: "off"` and still sends replies into Google Chat threads.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/89790, or a maintainer-equivalent Google Chat plugin fix, then close this issue once the fix reaches main.
