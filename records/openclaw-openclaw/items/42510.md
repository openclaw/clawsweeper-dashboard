## Summary

Keep open: current main and v2026.6.11 still let Google Chat thread metadata reach outbound send paths despite `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 is an open unmerged closing fix candidate.

## What This Changes

Fix Google Chat so `channels.googlechat.replyToMode: "off"` suppresses automatic threaded replies for text, media, typing, and durable delivery paths.

## Best Possible Solution

Land one canonical Google Chat off-mode threading fix, preferably https://github.com/openclaw/openclaw/pull/89790 or a maintainer-equivalent branch, then close this issue after the fix reaches main.
