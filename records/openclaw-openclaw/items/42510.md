## Summary

Keep open: current main and latest v2026.6.11 still allow Google Chat thread metadata to reach outbound sends despite `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 is the open closing fix candidate.

## What This Changes

Google Chat should honor `channels.googlechat.replyToMode: "off"` by suppressing automatic thread replies for text, media, typing, and durable reply delivery.
