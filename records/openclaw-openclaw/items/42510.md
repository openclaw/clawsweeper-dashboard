## Label Justifications

- `P1`: A configured Google Chat channel can keep routing replies into threads despite an explicit off-mode setting, breaking a real channel workflow for users.
- `impact:message-loss`: The bug misroutes Google Chat replies into thread targets when the user requested flat conversation delivery.

## Summary

Keep open: current main and v2026.6.11 still have Google Chat paths where a thread target can reach outbound sends despite `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 is the open closing fix candidate.

## What This Changes

Google Chat should honor existing `channels.googlechat.replyToMode: "off"` by suppressing automatic thread replies for text, media, typing, and durable delivery.

## Best Possible Solution

Review, rebase if needed, and either land or explicitly reject https://github.com/openclaw/openclaw/pull/89790; close this issue only after the chosen fix is merged or the direction changes.
