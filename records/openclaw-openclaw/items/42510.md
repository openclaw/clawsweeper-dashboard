## Summary

Keep open: current main and v2026.6.11 still allow Google Chat thread metadata to reach outbound send paths despite `replyToMode: "off"`, and https://github.com/openclaw/openclaw/pull/89790 remains open as the linked closing fix candidate.

## What This Changes

Google Chat should honor `channels.googlechat.replyToMode: "off"` by suppressing implicit thread targets for typing, text, media, and durable reply sends.
