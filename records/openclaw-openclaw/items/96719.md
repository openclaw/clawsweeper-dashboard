## What This Changes

The PR delays progress-mode tool-message suppression until a visible draft exists and buffers eligible Discord block updates so an empty preview can flush them before the final reply.

## Best Possible Solution

Keep a single progress owner per turn: show standalone text progress until a visible draft starts, flush buffered progress before the final answer when the draft stays empty, discard it once the draft becomes visible, and prove both branches in a real Discord conversation.
