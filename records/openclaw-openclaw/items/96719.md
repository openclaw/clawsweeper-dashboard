## Best Possible Solution

Land the focused Discord/channel fix after redacted real Discord proof shows the fallback progress block arrives before the final reply and no duplicate block appears once a progress draft is visible.

## Reproduction Assessment

Yes, source-reproducible: current main and v2026.6.11 suppress progress-mode standalone tool progress before proving a Discord progress draft is visible, and Discord drops text-only block replies while a draft stream exists.

## Solution Assessment

Yes for code shape: delaying suppression until a draft is visible and flushing empty-draft fallback blocks is narrower than globally unsuppressing tool messages and preserves visible-draft ownership, but it is not proof-sufficient without live Discord ordering evidence.
