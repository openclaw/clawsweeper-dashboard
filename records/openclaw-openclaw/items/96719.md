## Best Possible Solution

## Solution Assessment

Yes for the code shape: compared with always unsuppressing all tool messages or only changing the shared resolver, this PR better preserves visible-draft ownership and flushes empty-draft fallback blocks before final delivery. It is not merge-ready until real Discord proof confirms the live behavior.
