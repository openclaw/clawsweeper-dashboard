## Summary

## What This Changes

The PR delays progress-mode tool-message suppression until a visible draft exists and buffers eligible Discord block updates so an empty preview can flush them before the final reply.

## Best Possible Solution

Keep the state-based single-owner delivery design, but prove on a real Discord turn that fast empty-preview tools remain visible, finals preserve ordering, and later-visible drafts do not duplicate interim updates; add sibling-channel coverage if those callers share the changed suppression getter.
