## Summary

Keep open. Current main still generates the Claude CLI MCP config from enabled bundle/configured servers without applying the effective `tools.deny` policy before handoff, and the only direct fix PR is closed unmerged after review found a permission-widening bug.

## What This Changes

The issue asks OpenClaw to enforce configured MCP `tools.deny` policy for `claude-cli` backend sessions.

## Best Possible Solution

Resolve effective global/provider/agent MCP policy before the Claude CLI handoff, preserve deny-wins for exact and wildcard entries without widening access, and fail closed or warn clearly for patterns the CLI cannot enforce.
