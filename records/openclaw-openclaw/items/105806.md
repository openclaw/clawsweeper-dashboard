## What This Changes

This PR changes stuck-session recovery to reclaim terminal-phase or activity-free embedded reply operations instead of indefinitely preserving their channel lane claim.

## System Context

Inbound channel messages are serialized through per-session lanes; stuck-session recovery decides whether a lane still has live reply work or should be aborted and released. The reply-run registry and diagnostic activity feed that decision, which then determines whether queued messages can resume delivery.
