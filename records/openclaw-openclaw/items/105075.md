## What This Changes

The PR makes MCP App tool calls follow the originating run’s effective tool policy, isolates optional preview failures from MCP backoff, reports the applied sandbox CSP, and marks MCP Apps listener changes as restart-required.

## Best Possible Solution

MCP App views should retain one immutable authorization snapshot derived from the originating run’s complete MCP catalog and enforce it consistently for App tool discovery and execution, while optional preview operations remain isolated from normal tool backoff and the host advertises its actual sandbox policy.
