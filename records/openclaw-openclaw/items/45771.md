## Summary

Keep open. Current main exposes Anthropic/provider usage windows in status surfaces, but the requested pace tiers, response-header capture, persisted pace state, agent-visible context, notifications, and autonomous throttling policy are still missing and require maintainer product/API scoping.

## What This Changes

The issue requests built-in Anthropic pace-aware rate limiting for autonomous agents, including usage/header capture, pace tiers, status/session context, persisted state, notifications, and throttling policy.

## Best Possible Solution

Define a provider-owned visibility-first pace projection and session-context contract first, then add automatic throttling only behind explicit opt-in policy with persisted state and upgrade-safe tests.
