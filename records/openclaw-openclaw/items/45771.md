## Summary

Keep open. Current main has provider usage visibility and reactive auth-profile cooldowns, but the requested Anthropic header capture, pace tiers, pace config, persisted pace state, status/session_status pace output, and autonomous throttling policy are still missing.

Request built-in pace-aware rate limiting for autonomous agents using Anthropic usage signals, status visibility, session context, and subagent throttling.

## Best Possible Solution

Define an observability-first provider usage/pace contract and status surface, then add opt-in throttling only after maintainers settle config, persistence, and recovery semantics.
