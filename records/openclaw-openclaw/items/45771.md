## Summary

Keep open. Current main has provider usage snapshots, status visibility, and reactive auth-profile cooldowns, but the requested Anthropic response-header capture, pace projection tiers, persisted pace state, session_status pace output, and autonomous throttling policy are still missing and need maintainer scoping.

## What This Changes

Request built-in pace-aware rate-limit tracking for autonomous agents, including Anthropic usage/header capture, projected pace tiers, optional throttling, persisted state, status output, and session_status exposure.

## Best Possible Solution

Define an observability-first provider usage/pace contract and status surface, then add opt-in throttling only after maintainers settle config, persistence, and recovery semantics.
