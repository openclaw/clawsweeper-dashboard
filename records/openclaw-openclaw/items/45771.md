## Summary

Keep open. Current main has provider usage visibility and reactive auth-profile cooldown/failover, but the requested Anthropic response-header capture, pace-tier projection, pace config, status/session_status pace output, and autonomous throttling policy remain missing and need maintainer product scoping.

## What This Changes

Request built-in Anthropic-aware pace tracking, status/session_status visibility, and configurable autonomous-agent throttling based on projected usage windows.

## Best Possible Solution

Define a maintainer-approved provider usage/pace contract first, likely starting with read-only status/session_status visibility, then add throttling only as an opt-in policy with upgrade-safe config and persisted state.
