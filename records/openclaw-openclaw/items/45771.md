## Summary

Keep open. Current main ships Anthropic/Claude quota visibility through normalized usage/status surfaces, but it does not implement the requested pace tiers, persisted pace state, `agents.defaults.pace` config, or agent/subagent throttling policy; the remaining work needs maintainer product/API scoping.

## What This Changes

Request built-in pace-aware Anthropic quota tracking, pace projection, status/session_status exposure, and autonomous throttling for agents/subagents.

## Best Possible Solution

Keep the shipped provider-usage visibility, then design a narrow opt-in pace policy that exposes pace context first and only adds automatic throttling after maintainers choose thresholds, defaults, persistence, and subagent failure modes.
