## Summary

Keep open. Current main has provider usage visibility and reactive auth-profile cooldown/fallback behavior, but the requested Anthropic response-header capture, persisted pace state, pace-tier projection, pace config, status/session_status contract, and autonomous/subagent throttling policy remain absent.

## What This Changes

Add built-in pace-aware Anthropic/provider usage tracking, status/session_status pace reporting, and optional autonomous/subagent throttling.

## Best Possible Solution

Approve a provider-aware first phase that exposes read-only pace visibility/context through existing usage surfaces before adding persisted policy or automatic blocking.
