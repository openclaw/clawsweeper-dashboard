## Summary

Keep open. Current main exposes provider usage windows and static subagent concurrency limits, but the requested Anthropic response-header capture, pace projection, persisted pace state, config, status/session_status pace output, and autonomous throttling policy are still missing and need maintainer scoping.

## What This Changes

Add built-in Anthropic/provider pace tracking and optional autonomous-agent throttling from usage windows or rate-limit headers.

## Best Possible Solution

Define an observability-first provider pace contract through provider-owned usage hooks and status/session_status output, then add opt-in throttling only after maintainers settle config, persistence, and recovery semantics.
