Keep open. ## What This Changes

Add built-in pace-aware rate limiting for autonomous agents, including Anthropic usage signal capture, pace tiers, opt-in throttling config, and status/session_status output.

## Best Possible Solution

Define a maintainer-scoped, additive pace/resource-governance contract that reuses provider usage windows where possible, starts with visibility/status if desired, and only adds throttling after explicit opt-in defaults, persistence, status/session_status schema, docs, and upgrade-safe config behavior are agreed.
