## Summary

Keep open: current main and the latest release still lack a MiniMax M3 native video path and timestamp-scaling metadata hint, while the broader direct-video tracker overlaps but does not preserve the MiniMax-specific evidence.

## What This Changes

The issue requests MiniMax M3 native video input support, including video content blocks and a metadata hint that maps provider frame labels back to actual video seconds.

## Best Possible Solution

Keep this as the MiniMax M3-specific tracker and split any accepted work into provider-owned video support, explicit raw-media policy, and a separately approved core/session VideoContent or readVideo contract only if maintainers choose that direction.
