## Summary

Keep open. Current main and v2026.6.11 still hardcode text-only thread/topic isolated cron completions to direct outbound delivery, and no public cron schema, config, or docs selector exists for the requested main-agent handoff route.

## What This Changes

Request an opt-in cron delivery mode or config that lets text-only thread/topic completions route through the main-session announce/agent-turn path instead of always direct-sending.

## Best Possible Solution

Define one explicit job-level text-completion route selector for thread/topic cron delivery, default it to current direct delivery, keep structured payloads on direct delivery, and specify delivery status plus fallback behavior before implementation.
