## Summary

Keep open. Current main and v2026.6.11 still force thread/topic isolated cron completions with a resolved `threadId` through direct delivery, and there is no public config, protocol, or docs selector for the requested main-agent processing route.

## What This Changes

Allow text-only isolated cron deliveries to thread/topic targets to opt into main-session announce or agent-turn processing instead of always using direct delivery.

## Best Possible Solution

Define a narrow backward-compatible per-job text-completion route selector for thread/topic cron delivery, keep current direct delivery as the default, keep structured payloads direct-only, and settle delivery status plus fallback semantics before coding it.

Rationale: The source gap is clear, but adding the route changes cron's public config/protocol and delivery failure behavior, and repository policy treats config/default/fallback surfaces as compatibility-sensitive product decisions.

Options:

- **Add job-level route enum (recommended):** Add a narrow per-job selector that defaults to direct delivery, applies only to text-only thread/topic completions, and has explicit fail-closed or direct-fallback semantics.
- **Add global default plus override:** Add a global cron default with per-job override for operators who want consistent topic behavior across many jobs, accepting a wider config surface.
- **Keep direct delivery only:** Preserve current thread/topic direct-send behavior and document target-awareness or message-tool patterns as the supported alternatives.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows `threadId` cron targets still force direct delivery, while cron types, protocol schemas, config, and docs expose no opt-in main-agent route selector.

## Solution Assessment

Unclear until maintainers choose the surface. A job-level opt-in selector looks like the narrowest plausible shape, but the API, fallback, timeout, duplicate-delivery, and delivery-status semantics need product direction first.
