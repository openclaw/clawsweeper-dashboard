## Summary

Keep open. Current main still forces resolved thread/topic cron deliveries through direct outbound delivery, and the public cron type, protocol, config, and docs surfaces still have no opt-in main-session announce or agent-turn route.

## What This Changes

Request an opt-in cron delivery mode so text-only isolated cron completions for topic/forum targets can use the main-session announce/agent-turn flow instead of forced direct send.

## Best Possible Solution

Define one explicit job-level text-completion routing enum for thread/topic cron delivery, default it to current direct delivery, keep structured payloads on direct delivery, and specify delivery status plus fallback behavior before implementation.
