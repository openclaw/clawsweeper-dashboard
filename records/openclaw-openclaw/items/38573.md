## Summary

Keep open. Current main and the latest release still force text-only isolated cron completions for thread/topic targets through direct outbound delivery, and the remaining work is a product/config contract choice for an opt-in main-agent processing route.

## What This Changes

Request to add an opt-in cron delivery route or config option so text-only thread/topic isolated cron completions can go through main-agent announce processing instead of forced direct send.

## Best Possible Solution

Define a narrow backward-compatible job-level text-completion route enum for thread/topic cron delivery, keep current direct delivery as the default, keep structured payloads direct-only, and specify delivery status plus fallback semantics before coding it.
