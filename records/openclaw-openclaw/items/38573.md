## Summary

Keep open: current main and v2026.6.11 still force thread/topic isolated cron completions through direct outbound delivery and expose no opt-in route selector, so this remains a product/API decision.

## What This Changes

Request an opt-in cron delivery mode or config so text-only isolated cron completions in topic/forum threads can route through the main-session announce/agent-turn flow instead of forced direct send.

## Best Possible Solution

Define a narrow, backward-compatible job-level text-completion route enum for thread/topic cron delivery, keep current direct delivery as the default, keep structured payloads direct-only, and specify delivery status plus fallback semantics before coding it.
