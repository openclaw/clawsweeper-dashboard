## Summary

Keep open. Current main still forces thread/topic cron completions through direct outbound delivery and exposes no opt-in main-session announce or agent-turn route; adding one would change cron config, protocol, and fallback semantics.

## What This Changes

The issue requests an opt-in cron delivery mode so text-only topic/forum completions can go through the main-session announce/agent-turn flow instead of forced direct delivery.

## Best Possible Solution

Define one explicit job-level text-completion routing enum for thread/topic cron delivery, default it to current direct delivery, keep structured payloads on direct delivery, and specify delivery status plus fallback behavior before implementation.
