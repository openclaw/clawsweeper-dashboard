## Summary

Keep open. Current main and v2026.6.11 still force thread/topic isolated cron completions through direct delivery, and choosing an opt-in route plus fallback behavior is a product/config contract decision.

## What This Changes

Request to add a config or per-cron option that lets text-only topic/forum isolated cron completions use main-agent announce/agent-turn processing instead of forced direct delivery.

## Best Possible Solution

Define a narrow backward-compatible job-level text-completion route enum for thread/topic cron delivery, keep current direct delivery as the default, keep structured payloads direct-only, and specify delivery status plus fallback semantics before coding it.
