## What This Changes

Fix native iOS chat reconciliation so delayed history refreshes cannot duplicate, reorder, or flatten completed tool-using turns.

## Best Possible Solution

Make shared native history application generation-safe and idempotent: coalesce refresh demand, reject stale responses, reconcile canonical rows without appending old snapshots below newer state, preserve tool-step roles, and add a deterministic replay covering delayed responses completing in reverse order.
