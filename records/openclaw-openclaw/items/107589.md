## What This Changes

Prevent the native iOS chat transcript from duplicating, reordering, or flattening completed tool-using turns when live events and overlapping `chat.history` responses reconcile.

## Best Possible Solution

Make the Apple chat model converge deterministically on stable Gateway identity and sequence: add a delayed, out-of-order multi-request replay covering a live tool run, preserve typed tool-step projection, and verify on an iOS simulator or device that the final transcript exactly matches canonical history without duplicate rows.
