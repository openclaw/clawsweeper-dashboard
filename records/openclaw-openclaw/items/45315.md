- **[P1] Carry prefix context into routed abort delivery:** `src/channels/reply-prefix.ts:34-46`
  - body: This fix only seeds the dispatcher-owned prefix context. A templated prefix can still leak `{model}` / `{thinkingLevel}` on that routed abort path, so the branch does not satisfy the claimed all-channel fix.
  - confidence: 0.9

Fast abort skips `onModelSelected`, so the new user-visible prefix can show stale provider/model/thinking values instead of the active turn.
  - confidence: 0.86
