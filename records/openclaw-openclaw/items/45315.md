Full review comments:

- **[P1] Carry prefix context into routed abort replies:** `src/channels/reply-prefix.ts:44-49`
  - body: The fast-abort path calls `routeReplyToOriginating(payload)` before normal model selection, but `routeReply()` still normalizes with only `responsePrefix` and no `responsePrefixContext`. This added pre-seeded context will not be used for routed-origin abort delivery, so those replies can still expose raw `{model}` or `{thinkingLevel}` tokens; thread the context into routed delivery and cover that path.
  - confidence: 0.87
- **[P2] Seed abort prefixes from active model state:** `src/channels/reply-prefix.ts:44-52`
  - body: `resolveDefaultModelForAgent()` resolves the configured default, while normal turns can use session `/model` overrides, `channels.modelByChannel`, auto fallback, and catalog-derived thinking defaults before `onModelSelected()` fires. Fast abort skips that callback, so this patch can display the wrong model or thinking value for the active turn; seed from active session/channel/runtime state where available.
  - confidence: 0.84
