- **[P1] Carry prefix context into routed abort replies:** `src/channels/reply-prefix.ts:51-56`
  - body: The fast-abort path first delivers through `routeReplyToOriginating`, but `routeReply()` normalizes with `responsePrefix` and no `responsePrefixContext`.   - confidence: 0.87

  - body: This seed uses `resolveDefaultModelForAgent`, while the real reply path can use session `/model` overrides, `channels.modelByChannel`, fallback, and catalog-derived thinking before `onModelSelected()` fires. Fast abort skips that callback, so abort prefixes can show the wrong model or thinking value; derive the abort context from active session/channel/runtime state where available.
  - confidence: 0.84
