  - body: The new seed only helps callers that normalize through the dispatcher. This remains from the prior review cycle at this head.
  - confidence: 0.9
- **[P2] Seed Abort Prefixes From Active Model State:** `src/channels/reply-prefix.ts:44-56`
  - body: This seeds `{model}` and `{thinkingLevel}` from config defaults, but the normal reply path can later apply stored session overrides and `channels.modelByChannel`. Because fast abort exits before that selection path, users who switched models or matched a channel override can see the wrong model/thinking values in the abort reply. This remains from the prior review cycle at this head.
  - confidence: 0.86
