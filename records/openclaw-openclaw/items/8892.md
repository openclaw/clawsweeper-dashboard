## Label Justifications

- `P2`: This is a normal-priority TUI and multi-agent routing improvement with clear user value but limited blast radius.
- `impact:session-state`: The requested selector determines which agent session, workspace context, and remembered-session state the TUI attaches to at startup.

## Summary

Keep open: current main and the latest release still do not provide a native `openclaw tui --agent <id>` startup selector, and the remaining work needs a maintainer product decision about TUI session-routing precedence.

## What This Changes

Add a native `openclaw tui --agent <id>` flag so TUI startup can attach to a configured non-default agent, model, workspace, and context from arbitrary directories.

## Best Possible Solution

Ship a focused additive TUI CLI design that validates `--agent <id>`, threads a typed startup agent id through startup, preserves existing session/workspace behavior, and updates focused tests plus public TUI docs after precedence is decided.
