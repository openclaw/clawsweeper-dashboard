## Summary

Keep this PR open for repair. The latest commit fixes the prior import and request-expectation failures, but two user-visible blockers remain: scroll-anchor correction runs before the asynchronous page arrives, and the bounded renderer always selects the newest tail, making fetched history older than 2,000 messages unreachable. Exact-head CI is green, but the PR still has only test-based evidence and no real browser proof.

## What This Changes

The PR adds offset-based older-history loading to Control UI chat, prepends fetched pages, tracks pagination metadata, updates transcript notices, raises the bounded render ceiling to 2,000 messages, and adds focused tests.

## Best Possible Solution

Retain the gateway’s existing pagination contract, apply scroll-anchor restoration only after an asynchronous prepend has rendered, and maintain a bounded but movable transcript window so every fetched history region remains reachable.
