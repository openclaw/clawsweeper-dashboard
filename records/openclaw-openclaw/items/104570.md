## Summary

This is the direct candidate fix for the linked Control UI transcript-pagination bug, but the unchanged head remains unmergeable: it fails production typecheck and the full UI suite, restores scroll position before asynchronous content arrives, and cannot display fetched messages older than its newest-2,000 window. The pagination direction is sound, and all code blockers are focused enough for a bounded repair.

## What This Changes

The PR adds offset-based Control UI chat-history pagination, scroll-triggered older-page loading, pagination state and notices, bounded transcript rendering, and focused tests.

## Best Possible Solution

Keep gateway offset pagination, but move the loader import to its actual caller, update every first-page request contract, restore scroll geometry only after the prepend renders, and represent the transcript as a bounded movable visible range rather than a fixed newest-message slice.
