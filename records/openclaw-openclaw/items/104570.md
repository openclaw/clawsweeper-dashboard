## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.98

Full review comments:

- **[P2] Preserve the scroll anchor after the page arrives:** `ui/src/pages/chat/components/chat-thread.ts:346-347`
  - body: The saved anchor is scheduled and cleared on the next animation frame before `onLoadOlderHistory()` normally resolves. With an ordinary network delay, `scrollHeight` is unchanged in that frame, so the adjustment is discarded; when older messages later prepend, the viewport jumps. Retain the geometry until the post-response render or schedule the correction from load completion, and cover a delayed response.
  - confidence: 0.99
- **[P2] Allow the render window to move beyond 2,000 messages:** `ui/src/lib/chat/chat-types.ts:61`
  - body: The new hard cap keeps `historyRenderLimit` at 2,000. Once more than 2,000 messages are loaded, another older page is prepended but `buildChatItems` still selects from the newest end, so the fetched page remains hidden and the user can never reach it. Use a bounded sliding or virtualized window and add an over-cap regression test.
  - confidence: 0.98
