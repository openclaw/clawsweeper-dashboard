## What This Changes

The issue asks for Control UI chat streaming to avoid token-by-token screen-reader announcements and announce the completed assistant response only once.

## Best Possible Solution

Control UI should suppress per-token announcements during active streaming while preserving accessible navigation or final-message announcement, backed by focused DOM coverage and live screen-reader proof before closing.
