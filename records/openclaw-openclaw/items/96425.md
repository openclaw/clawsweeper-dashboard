## Summary

Keep open: this PR is a useful candidate for the open Nova prompt-caching request, and current main plus v2026.6.11 still lack that support. ## What This Changes

The PR updates the Amazon Bedrock plugin, prompt-cache retention resolver, docs, and tests to treat Amazon Nova models as cache-point eligible while leaving other non-Anthropic Bedrock models on no-cache.

## Best Possible Solution

Tighten Nova eligibility so application profiles still resolve through GetInferenceProfile, then merge after redacted live Nova proof confirms accepted cache points, cache usage accounting, and intended default and explicit retention behavior.

## Solution Assessment

Mostly yes, but not merge-ready: the provider helper plus shared resolver is the right narrow shape for direct Nova. The app-profile matching needs tightening and the change still needs live Bedrock proof plus maintainer acceptance of default-on behavior.
