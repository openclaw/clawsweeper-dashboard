## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Archive the env-free trajectory sibling on reset:** `src/gateway/session-transcript-files.fs.ts:467-472`
  - body: `runtimeTargets` only seeds the path resolved with the current `process.env`, while pointer-resolved files are accepted only when their basename is `<sessionId>.jsonl`. If a session was created before `OPENCLAW_TRAJECTORY_DIR` was enabled, its sibling `<sessionId>.trajectory.jsonl` is neither the current env path nor an accepted pointer target, so reset can archive the pointer while leaving the actual runtime live and vulnerable to later cleanup. Add the env-free sibling path, or an equivalent owned-runtime candidate, and cover this env-change case.
  - confidence: 0.91
- **[P1] Constrain override cleanup to owned trajectory archives:** `src/gateway/session-transcript-files.fs.ts:640-642`
  - body: Adding `OPENCLAW_TRAJECTORY_DIR` to the generic archive cleanup directory list sends the transcript retention loop over an operator-configured directory. That loop removes any regular file whose name parses as `.reset.<ts>` or `.deleted.<ts>`, so a shared directory containing unrelated archive-looking files can lose data. Only scan or delete header-proven OpenClaw trajectory archives in the override directory.
  - confidence: 0.94
