## Summary

Keep open: the reset trajectory preservation is useful and the proof is strong, but the latest patch introduces a blocking cleanup compatibility bug when `OPENCLAW_TRAJECTORY_DIR` overlaps a normal session archive directory.

## What This Changes

## Best Possible Solution

Keep the reset trajectory preservation, but fix override-dir-only cleanup so it does not disable normal transcript archive cleanup for directories passed in by the session store.
