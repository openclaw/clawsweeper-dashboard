## Summary

Keep this PR open: current `main` still has the abort-path ownership gap, but the draft knowingly leaves separately daemonized descendants outside its containment boundary and has no real service-managed proof for the reported incident.

## What This Changes

The branch adds executor/background roles to supervised processes, isolates POSIX CLI executors into cancellable process groups, preserves background lifetimes, and adds documentation and focused tests.

## Best Possible Solution

Adopt a turn-owned containment mechanism that covers daemonized descendants, preserves explicitly persistent background sessions, reports any unavoidable survivors, and proves both abort cleanup and startup compatibility in a real service-managed setup.
