## Summary

## What This Changes

The PR makes ACPX abort and startup cleanup identify lease-owned detached descendants, close cached runtime handles, escalate termination, and report containment failures instead of normal abort success.

## Best Possible Solution

First propagate survivor state through the broad startup reaper and add a pending-lease survivor regression test; then land the identity-safe lease cleanup only after the ACPX/runtime owner confirms the fail-closed cancellation and startup contract.
