Full review comments:

- **[P1] Do not let protocol cancel block the lease drain:** `src/acp/control-plane/manager.cancel-session.ts:38-45`
  - body: `cancelActiveTurn()` is awaited before `runtimeHandles.close()`, but acpx 0.11.2 awaits `connection.cancel()` without a timeout on this path. If the agent or transport never settles it, the close/reaper never starts and the autonomous descendant remains alive. Make cancellation best-effort with a bounded wait or run containment independently so cleanup always progresses.
  - confidence: 0.96
- **[P1] Verify PIDs even when a signal call fails:** `extensions/acpx/src/process-reaper.ts:384-393`
  - body: Only PIDs whose `SIGTERM` call succeeds are added to `terminated`, and only that subset is checked after escalation. A failed signal can therefore return no survivors and mark the lease closed while the PID is still alive. Keep every targeted PID in the verification set and distinguish already-gone processes from live signal failures.
  - confidence: 0.99
