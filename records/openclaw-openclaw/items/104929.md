## Label Justifications

- `P0`: The linked incident describes an aborted autonomous executor continuing with write credentials and causing destructive concurrent repository actions.
- `merge-risk: 🚨 compatibility`: Executor runs lose the existing no-detach fallback, so a retryable detached-spawn failure can make previously starting CLI backends fail closed.
- `merge-risk: 🚨 security-boundary`: The patch may not terminate credential-bearing autonomous descendants that leave the executor process group.

## Summary

Keep open: the patch correctly reaps descendants that remain in the executor process group, but it does not establish containment for the daemonized child shape described by the linked incident, so the central security guarantee remains incomplete and unproven.

## What This Changes

The PR adds typed process roles so CLI executors use independently cancellable POSIX process groups while background jobs retain service-owned lifecycle behavior.

## Best Possible Solution

Contain autonomous CLI executors in a turn-owned primitive that covers the real supported production hierarchy, including daemonizing child paths, while retaining typed persistent background jobs and proving service-managed startup and abort behavior in a live setup.
