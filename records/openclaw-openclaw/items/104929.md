## Summary

The exact-head patch is technically sound and directly fixes the linked abort-containment failure: the previous survivor-propagation blocker is resolved, dependency inspection confirms direct-child ACPX close cannot contain detached descendants, and public artifacts prove the leased process is removed without killing unrelated work. Keep the draft open for explicit ACPX/control-plane owner acceptance because it intentionally overrides cooperative cancel reuse and makes unverifiable stale containment block backend startup.

## What This Changes

The PR makes ACPX cancellation and startup cleanup identify and drain detached lease-owned descendants, evicts live runtime handles on cancellation, and reports containment failures instead of normal abort success.

## Best Possible Solution

Keep the lease-scoped containment verifier, resumable metadata, and explicit containment-failure feedback, then land only after ACPX/control-plane owners accept destructive live-handle cancellation and fail-closed startup as the supported contract; a visible diagnostic or Doctor-style recovery path is the best follow-up for blocked startup.
