## Summary

This is still a useful, unmerged two-file hardening fix for malformed successful DeepSeek responses. The supplied regression coverage and real loopback HTTP result support ordinary maintainer review; no concrete patch defect or security concern is visible in the provided current-head evidence.

## What This Changes

The PR guards DeepSeek balance parsing so successful `null` or array JSON responses produce the existing empty-usage result instead of accessing balance fields as an object.

## System Context

OpenClaw’s provider-usage fetchers call provider billing endpoints and normalize their responses into usage snapshots for downstream usage displays. This DeepSeek adapter converts a successful balance response into summary, billing, and availability fields while preserving a stable empty snapshot when balance data is unavailable.
