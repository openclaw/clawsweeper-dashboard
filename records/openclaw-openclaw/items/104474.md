This fresh issue is member-authored and carries the protected `maintainer` label, requiring explicit product direction; likely routing is `steipete` for current layout ownership and `shakkernerd` for the requested UX.

## What This Changes

Center the Control UI chat transcript and composer within one responsive conversation frame while preserving role alignment, configured message width, and split/mobile/workspace layouts.

## Best Possible Solution

After choosing the canonical width policy, add one centered inner conversation-frame owner under `.chat-main`, reuse `--chat-message-max-width`, and prove unchanged behavior across desktop, split-pane, workspace-panel, tool-heavy, landscape, and mobile layouts.
