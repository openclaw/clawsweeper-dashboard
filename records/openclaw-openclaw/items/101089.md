## Summary

Keep open: current main and v2026.6.11 still have the reported mismatch where the preemptive context-overflow guard can emit a synthetic assistant error that the cleanup predicate does not recognize. The directly linked pull request is open and uses closing syntax, so this issue should close only after that PR or a replacement fix lands.

## What This Changes

Scrub synthetic preemptive context-overflow assistant errors from resumed agent transcripts so the model does not treat them as failed tool output.

## Best Possible Solution

Land or replace the linked fix so both mid-turn and generic preemptive overflow signals are treated as recovery-owned synthetic session artifacts, with focused regression coverage for resumed transcripts.

## Solution Assessment
