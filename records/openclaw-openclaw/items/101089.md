## Summary

The linked open PR is the right fix candidate, so this issue should stay open until that PR lands or is replaced.

## What This Changes

The issue asks to scrub the preemptive tool-loop context overflow assistant error from session history the same way the mid-turn precheck error is scrubbed.

## Best Possible Solution

Land a narrow fix that treats both internal overflow sentinel strings as synthetic assistant errors and adds focused regression coverage for active and persisted session cleanup.
