## What This Changes

The PR bounds Reef audit and replay JSONL reads at 32 MiB using chunked file-handle reads, preserving a truncated audit prefix while rejecting oversized replay ledgers.

## System Context

Reef persists its audit history and replay ledger as encrypted JSONL files. The audit store records history, while the replay ledger prevents already-completed receipts from being claimed again before Reef returns a channel result.
