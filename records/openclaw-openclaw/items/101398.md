The branch adds a `maxBytes` cap to Feishu string-path image/file upload helpers, forwards the configured media cap from `sendMediaFeishu`, and adds regression coverage for oversized path rejection.

## Best Possible Solution

Keep the media limit enforcement in the Feishu upload helper path, with focused regression tests covering path reads and no SDK upload after rejection.
