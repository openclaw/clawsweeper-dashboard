## What This Changes

This PR makes Codex transcript mirroring use bounded SQLite identity lookups instead of repeatedly decoding a session’s full persisted transcript, reducing latency and memory growth for large histories.

## System Context

Codex App Server events are mirrored into OpenClaw’s SQLite-backed session transcript so later agent and UI paths can read a durable conversation history. The change replaces full-transcript reads during mirroring with indexed identity facts while preserving write-time idempotency, sequence assignment, hooks, and transcript-update publication.
