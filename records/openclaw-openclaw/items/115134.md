## Summary

Keep this maintainer-authored, maintainer-labelled regression fix open for the owner decision on the selected-profile compatibility contract. The proposed fix is focused and the prior review found no line-level defect, but merging intentionally replaces sibling-profile/native fallback with an actionable fail-before-spawn path for selected Claude CLI OAuth credentials.

## What This Changes

This PR refreshes and persists the exact selected Claude CLI OAuth credential before launch, prevents fallback to a different profile, and rejects expired OAuth descriptors before Claude Code starts.

## System Context

CLI-backed agents select an auth profile before OpenClaw prepares a Claude Code process. The preparation layer resolves or refreshes the selected credential, then the Anthropic plugin converts it into Claude Code’s descriptor input; this PR changes the failure decision when that selected credential cannot be used.

## Best Possible Solution

Keep the exact selected profile authoritative, refresh and persist it when possible, and otherwise fail before spawn with the profile-specific recovery command; land only after the responsible owner confirms that this is the intended upgrade contract for existing multi-account setups.
