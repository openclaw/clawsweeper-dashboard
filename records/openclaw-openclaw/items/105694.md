This should remain open as a focused performance bug; the reported outage threshold is not live-proven, and the proposed `sessionId` implementation must be corrected to preserve the current requester/owner session-key contract.

## What This Changes

Remove repeated global task and generated-media activity scans from cron run-session reaping.
