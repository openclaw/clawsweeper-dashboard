Implement a canonical task-registry batch/index lookup preserving matches on both `requesterSessionKey` and `ownerKey`, and use one snapshot/index per sweep or equivalent indexed queries. Preserve active generated-media activity, terminal-status semantics, cron-run key parsing, the five-minute throttle, lifecycle mutation, transcript archive cleanup, and writer-owned active-work protection. Do not implement the issue's `sessionId` map, add configuration or compatibility paths, or edit `CHANGELOG.md`. Add regression coverage proving many continuation rows do not cause repeated full snapshots and pending generated media still prevents removal.
