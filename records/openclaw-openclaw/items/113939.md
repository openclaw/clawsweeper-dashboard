## What This Changes

Starts the Browser plugin’s lightweight page-share service during default Gateway startup so an already-paired Chrome extension can deliver a shared page without eagerly starting browser automation.

## System Context

The Chrome extension sends an approved active-page share through the Browser plugin into the Gateway’s page-share delivery sink, which then forwards it to the main session. The changed registration path decides which Browser services start with the Gateway and which remain lazy until browser control is needed.
