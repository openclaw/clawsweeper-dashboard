## Summary

Keep this PR open: the reported terminal-navigation problem is credible and the exact-head recording is strong, but the patch enables replayable Back navigation for custom and external setup adapters without a compatibility guard for adapters that perform persistent effects without invoking the new cutoff callback.

## What This Changes

The PR adds channel-scoped Back navigation, prompt replay, rollback handling, and persistent-effect boundaries to terminal channel setup flows.

## Best Possible Solution

Make scoped Back navigation an explicit replay-safe setup capability that defaults off for existing custom and external adapters, opt known-safe adapters in, require a persistence cutoff before durable effects, and cover a legacy adapter that ignores the callback with a compatibility test.
