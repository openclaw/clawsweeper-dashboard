## Summary

This PR remains necessary: current `main` still invokes channel setup and external-plugin installation directly, without the proposed scoped navigation outcome. The patch has strong terminal proof and no discrete correctness finding, but the new optional adapter-level persistence boundary is a compatibility contract that needs setup-area maintainer approval before merge.

## What This Changes

The branch adds channel-scoped terminal Back navigation to interactive channel setup, replaying reversible prompts and returning from a channel’s first prompt to the shared picker before declared persistent effects.

## Best Possible Solution

Adopt one explicit, documented setup-adapter persistence contract: Back is permitted only before an adapter declares its first durable effect, with shared coverage for built-in and custom adapters that have installs, key writes, auth handshakes, or post-write hooks.
