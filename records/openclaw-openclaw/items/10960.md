## Summary

Keep open: current main has a partial active-run steering fix, but this issue asks for a stronger pause-or-abort, inject, and resume lifecycle that current source and docs still do not implement.

## What This Changes

The issue requests true mid-stream soft steering so a user message can interrupt active generation or long tool work, enter context immediately, and let the agent continue with that new input.

## Best Possible Solution

Keep this issue as the product/runtime tracker for true soft-steer semantics while reviewing https://github.com/openclaw/openclaw/pull/89238 or a successor for the narrower ordinary-message admission gap.
