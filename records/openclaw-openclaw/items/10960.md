## Summary

Keep open: current main has improved active-run steering admission, but it still implements boundary steering rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests true mid-stream soft steering that cleanly pauses or aborts an active generation, injects new user context, and resumes with that input.

## Best Possible Solution

Define an opt-in soft-steer contract that preserves current boundary steering by default, then implement abort/capture/inject/resume semantics with focused runtime, transcript, provider, channel, and upgrade proof.

Unclear as an implementation, because the issue asks for a product-level lifecycle change rather than one broken code path. The safer path is an opt-in soft-steer design while preserving current boundary steering and tracking narrower active-run ingress fixes separately.
