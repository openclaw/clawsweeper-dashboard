## Summary

Keep open. Current main has partial active-run steering fixes, but the requested true soft-steer lifecycle still is not implemented: documented steering waits for model/tool boundaries and does not abort, inject, and resume mid-generation or mid-tool execution.

## What This Changes

The issue requests mid-stream soft steering so new user input can pause or abort an active agent run, enter context immediately, and let generation resume with that input.

## Best Possible Solution

Maintain boundary steering as the current contract, land or resolve the narrower active-run ingress work separately, and only add true soft-steer after maintainers define the abort/capture/resume lifecycle and whether it is a new queue mode or an opt-in policy.
