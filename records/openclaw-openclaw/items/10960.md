## Summary

Keep open. Current main has boundary steering and a merged partial active non-streaming admission fix, but it still does not implement true soft-steer semantics: pause or abort the in-flight work, inject the new user input, and resume with that input in context.

## What This Changes

Request true mid-stream soft steering so a user message can interrupt active generation or long-running work, enter context immediately, and let the agent continue with the new guidance.

## Best Possible Solution

Preserve current boundary steering as the documented contract, resolve the narrower active-run ingress tracker separately, and add true soft-steer only after maintainers define opt-in abort/capture/inject/resume semantics with transcript, tool-result, fallback, and provider-harness coverage.
