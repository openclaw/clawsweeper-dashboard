## Summary

Keep open: current main contains a partial active-run steering admission fix, but OpenClaw still documents and implements boundary-based steering rather than the requested pause-or-abort, inject, and resume lifecycle.

## What This Changes

Request true mid-stream soft steering so a user message can interrupt or pause an active generation, enter context immediately, and resume with the new input.

## Best Possible Solution

Keep this as the broad product/runtime tracker, finish narrower active-run admission work separately, and design any true soft-steer behavior as an explicit lifecycle with fallback and upgrade semantics.
