## Summary

Keep open: current main has a partial active-run steering admission fix, but it still implements and documents boundary-based steering rather than the requested pause-or-abort, inject, and resume lifecycle.

## What This Changes

The issue requests soft-steer behavior that can interrupt active generation or long tool work, inject the user's message into context, and resume with that input.

## Best Possible Solution

Keep this as the broad soft-steer product/runtime tracker, finish the narrower active-run admission work separately, and design any true soft-steer behavior as an explicit lifecycle with fallback and upgrade semantics.
