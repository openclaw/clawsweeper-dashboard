## Summary

Keep open. Current main improves boundary steering and active non-streaming admission, but it still documents and implements steering at runtime/model boundaries rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

Request true soft-steer behavior that can interrupt an active generation, inject the new user message into context, and resume with awareness of that input.

## Best Possible Solution

Define an opt-in soft-steer mode or policy with explicit abort/capture/inject/resume semantics, while keeping current boundary steering and landing narrower ingress fixes separately.
