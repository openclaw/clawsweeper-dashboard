## Summary

Keep open: current main has partial active-run steering fixes, but this issue asks for a stronger pause-or-abort, inject, and resume lifecycle that current docs, OpenClaw source, and Codex turn/steer contracts still do not provide.

## What This Changes

Request true mid-stream soft steering so a user message can interrupt or pause active generation, enter context immediately, and let the agent resume with the new input.

## Best Possible Solution

Keep this as the broad product/runtime tracker, finish the narrower active-run admission work separately, and design any true soft-steer lifecycle as an explicit opt-in mode or command with fallback, Codex, and channel behavior documented.
