## Summary

Keep open: current main implements boundary-based steering plus partial active-run admission, but the requested pause-or-abort, inject, and resume lifecycle is still not implemented and needs product/runtime design. The narrower ordinary-message admission gap is already tracked by https://github.com/openclaw/openclaw/issues/48003 and https://github.com/openclaw/openclaw/pull/89238.

## What This Changes

The issue requests true mid-stream soft steering that can pause or abort an active generation, inject a new user message into context, and resume with that input.

## Best Possible Solution

Keep this issue as the broad product/runtime tracker, finish the narrower active-run admission work separately, and design true soft-steer as an explicit lifecycle with documented fallback, partial-output, tool-execution, and Codex/native runtime semantics.
