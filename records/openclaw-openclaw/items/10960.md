## Summary

Keep open: current main has partial active-run steering fixes, but the issue asks for a stronger pause-or-abort, inject, and resume lifecycle that current source and docs still define as boundary-based steering.

## What This Changes

The issue requests soft-steer behavior that can interrupt an active generation or long-running turn, inject the user's new message into context, and resume with that input considered.

## Best Possible Solution

Keep this as the broad product/runtime tracker, resolve the narrower active-run admission work separately, and design any true soft-steer behavior as an explicit lifecycle with documented fallback and upgrade semantics.
