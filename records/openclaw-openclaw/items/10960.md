## Summary

Keep open. Current main has boundary steering plus partial active/non-stopped admission, but it still does not implement true soft-steer semantics: pause or abort an in-flight generation, inject the user message, and resume with that input.

## What This Changes

The issue requests a mid-stream soft-steer mode where user input can interrupt or pause active generation, enter the run context immediately, and resume without waiting for the next boundary.

## Best Possible Solution

Preserve boundary steering as the current contract, finish the narrower active-run delivery tracker separately, and add true soft-steer only after maintainers define opt-in abort/capture/inject/resume semantics with transcript, tool-result, fallback, and provider-harness coverage.
