## Summary

Keep open: current main has partial steering fixes, but this issue asks for a stronger pause-or-abort, inject, and resume lifecycle that is still not implemented and is also paired with open implementation work.

## What This Changes

Requests a soft-steer mode that can interrupt active generation, inject the user's prompt into context, and resume without waiting for the current model or tool boundary.

## Best Possible Solution

Keep this issue open as the broad product/runtime tracker, and land https://github.com/openclaw/openclaw/pull/89238 or a refreshed successor only after maintainer review defines the intended soft-steer lifecycle and proves same-session channel behavior.
