## Summary

Keep open: current main has a useful partial active-run steering admission fix, but it still documents and implements boundary-based steering rather than the requested true mid-generation pause-or-abort, inject, and resume lifecycle. The issue is also paired with narrower open work, so closing it now would hide remaining product/runtime decisions.

## What This Changes

The issue requests true mid-stream soft steering: pause or abort an active generation, inject the user's new message into context, and resume with awareness of that input.

## Best Possible Solution

Keep this as the broad soft-steer product/runtime tracker, reconcile the narrower active-run ingress work, and only close after maintainers approve and document the pause-or-boundary lifecycle semantics.

## Reproduction Assessment

Yes at source level: docs and the agent loop show queued steering is drained at runtime/model boundaries rather than true mid-generation pause, injection, and resume; I did not run a live channel replay in this read-only review.

## Solution Assessment
