## Summary

Keep this issue open: current main still provides safe-boundary steering rather than the requested transparent abort, immediate injection, and context-aware continuation lifecycle, and an open linked implementation PR means the issue should remain the product tracker until that path is resolved.

## What This Changes

Requests a soft-steer mode that interrupts active generation, injects new user input, and resumes with preserved context.

## Best Possible Solution

Keep existing `steer` lossless and boundary-based, fix its narrower delivery regressions separately, and add a capability-gated `soft-steer` mode only after defining cancellation, partial-output persistence, tool-side-effect, fallback, and resume semantics across embedded and reply runtimes.

- **Use abort and follow-up:** Treat cancellation followed by a normal queued turn as the supported interruption workflow and close the broader feature direction.

## Solution Assessment

Unclear pending product direction. A capability-gated separate mode is safer than silently changing existing `steer`, but maintainers must first decide whether transparent continuation is a supported cross-backend contract.
