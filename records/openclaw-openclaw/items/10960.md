## Summary

Keep open: current main has narrowed active-run steering admission, but the documented/runtime contract is still boundary steering, not the requested true pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests true mid-stream soft steering so a user message can interrupt or pause an active generation or long tool wait, enter context, and resume the run.

## Best Possible Solution

Preserve documented boundary steering as the default, resolve the narrower active-run ingress fixes through their canonical path, and add true soft-steer only after maintainers define opt-in abort/capture/inject/resume semantics with transcript, tool-result, provider, Codex, and channel proof.
