## Summary

Keep open: current main has improved active-run steering admission, but it still implements boundary steering rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests a true soft-steer mode that can interrupt active generation, inject new user input into context, and resume without waiting for the next tool or model boundary.

## Best Possible Solution

Preserve documented boundary steering as the default, land narrower active-run ingress fixes through their canonical path, and add true soft-steer only after maintainers define opt-in abort/capture/inject/resume semantics with transcript, tool-result, provider, Codex, and channel proof.
