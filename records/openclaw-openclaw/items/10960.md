## Summary

Keep this issue open because the requested contract remains a product choice: OpenClaw now ships immediate abort-and-new-turn interruption, but not transparent checkpoint-and-resume of an in-flight generation, and an external PR still claims to close this issue without resolving that distinction.

## What This Changes

Add immediate mid-run course correction that interrupts active work, incorporates the user’s new message, and continues with the updated context.

## Best Possible Solution

Standardize the shipped abort-and-immediate-contextual-next-turn behavior as OpenClaw’s supported interrupt contract, resolve the stale conflicting PR, and create a separate sponsored design item only if maintainers want resumable partial-generation and tool-state checkpoints.

## Solution Assessment

The existing interrupt path is the best bounded solution for immediate course correction because it cleanly aborts, waits, refreshes state, and starts the corrective turn. Transparent checkpoint resume is a separate, substantially larger capability rather than a narrow steer-path fix.
