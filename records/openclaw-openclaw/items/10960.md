- `P2`: This is a valuable runtime and messaging UX improvement with clear user impact, but it is a product-level feature decision rather than an urgent regression or outage.
- `impact:session-state`: Soft steering would change how active session context, partial assistant output, tool results, and late user input are associated with one run.

## Summary

Keep open. Current main contains partial active-run steering fixes, but the requested true soft-steer lifecycle still is not implemented: current docs and agent-loop source preserve boundary steering rather than clean mid-generation or mid-tool abort, inject, and resume behavior.

## What This Changes

This issue requests true mid-stream soft steering so a user message can pause or abort an active generation, enter context immediately, and resume with the new instruction.

## Best Possible Solution

Define an opt-in soft-steer lifecycle or explicitly reject it; if accepted, document abort/capture/resume semantics and prove streaming, tool execution, Codex turn/steer, fallback, transcript, and channel behavior together.
