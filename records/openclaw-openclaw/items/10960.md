## Summary

Keep open: current main partially improves active-run steering, but the requested pause-or-abort, inject, and resume lifecycle is still not implemented and remains a product/runtime design decision.

## What This Changes

The issue requests true mid-stream soft steering so a user message can interrupt an active generation, enter context immediately, and resume with the new instruction.

## Best Possible Solution

Keep this issue as the broad product/runtime tracker, land or reject the narrower active-turn admission work separately, and design any true soft-steer behavior as an explicit lifecycle with fallback, security, and upgrade semantics.
