## Summary

Keep open: current main has a partial active-run steering admission fix, but OpenClaw still documents and implements boundary-based steering rather than the requested pause-or-abort, inject, and resume lifecycle.

## What This Changes

The issue requests soft-steer behavior that can interrupt or pause an active generation, inject a new user message into context, and resume with that input.

## Best Possible Solution

Keep this issue as the broad product/runtime tracker, finish narrower boundary-steering delivery work separately, and design any true soft-steer behavior as an explicit lifecycle with fallback and upgrade semantics.
