## Summary

Keep open. Current main has boundary steering and a partial active-non-streaming admission fix, but it still does not implement the requested true soft-steer lifecycle that pauses or aborts mid-generation/tool work, injects the new user message, and resumes with preserved context.

## What This Changes

The issue requests a soft-steer capability that can interrupt an active generation or long tool phase, inject the user's follow-up into context, and resume with that input.

## Best Possible Solution

Keep boundary steering as the current contract, resolve the narrower active-turn admission work separately, and only add true soft-steer after maintainers define whether abort/capture/inject/resume is a new queue mode, an opt-in policy, or out of scope.
