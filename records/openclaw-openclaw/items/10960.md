## Summary

Keep open: current main has partial active-run steering fixes, but the requested pause-or-abort, inject, and resume soft-steer lifecycle is still not implemented and needs maintainer product/runtime direction.

## What This Changes

Request true mid-stream soft steering that can interrupt active generation or long tool work, inject the user message into context, and resume with awareness of the new input.

## Best Possible Solution

Keep this as the broad runtime/product tracker, finish narrower active-run admission work separately, and design an explicit opt-in soft-steer lifecycle with documented fallback, interrupt, partial-output, and backend-rejection semantics.
