## Summary

Keep open. Current main has partial active/non-streaming steer admission, but it still implements boundary-based steering rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

Request true mid-stream soft steering so user input can interrupt active generation or long tool waits, enter context immediately, and resume with the new constraint.

## Best Possible Solution

Keep this as the broad soft-steer tracker until maintainers land or reject a lifecycle design covering interrupt/resume semantics, fallback behavior, transcript ordering, backend failures, and channel ingress.

## Reproduction Assessment

Yes, at source level: current docs and the agent loop show steering drains at runtime/model boundaries and does not abort in-flight tools. I did not run a live channel replay in this read-only review.

## Solution Assessment

No, current main is only a partial solution. The best path needs maintainer-approved lifecycle semantics that preserve tool-result pairing and transcript ordering while deciding interrupt/resume, fallback, admission, and security behavior.
