## Summary

Keep open: current main has improved active/non-stopped boundary steering, but it still delivers steering at runtime/model boundaries rather than the requested abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests soft-steer behavior that can interrupt an active agent generation or long tool phase, inject a user message, and resume with the new context.

## Best Possible Solution

Define an opt-in soft-steer contract that preserves current boundary steering by default, then implement abort/capture/inject/resume semantics with focused runtime, transcript, provider, channel, and upgrade proof.
