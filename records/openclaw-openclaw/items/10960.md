## Summary

Keep open: current main only partially improves active-run steering, while #10960 still asks for a stronger pause-or-abort, inject, and resume lifecycle that the current docs/source do not implement.

## What This Changes

Add true mid-stream soft steering that can interrupt active generation, inject user input into context, and resume with awareness of the new input.

## Best Possible Solution

Keep #10960 as the broad product/runtime tracker, finish the narrower #48003/#89238 admission fixes separately, and design any true soft-steer behavior as an explicit lifecycle with fallback and upgrade semantics.
