## Summary

Keep open: current main has partial active-run steering fixes, but it still documents and implements steering as boundary-based behavior rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests true mid-stream soft steering so a user message can interrupt an active generation, enter context, and let the run resume with the new input.

## Best Possible Solution

Keep this issue open as the broader soft-steer product/runtime tracker while maintainers land or replace the narrower active-run admission work, then decide whether true pause/resume steering should be designed separately.

Rationale: Current main supports boundary steering and explicit interrupt behavior, but the requested pause/resume lifecycle would define new active-run semantics beyond the existing docs and related bug-fix PRs.

- **Keep Boundary Steering For Now (recommended):** Land or refresh the ordinary-message active-run steering fix and leave true pause/resume soft-steer as a separate maintainer-sponsored feature design.
