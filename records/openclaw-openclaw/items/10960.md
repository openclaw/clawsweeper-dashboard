## Summary

Keep open: current main includes the active/non-streaming steering admission slice, but the agent loop and docs still describe boundary-based steering, and related ingress work remains open, so true pause/abort, inject, and resume soft-steer is not implemented.

## What This Changes

Request true mid-stream soft steering so user guidance can interrupt an active generation or long tool phase, enter context immediately, and resume without losing state.

## Best Possible Solution

Keep this as the broad soft-steer product/runtime tracker, reconcile the narrower ingress work, and close only after maintainers approve and document the lifecycle semantics.

## Reproduction Assessment

Yes. Source inspection shows current main still drains queued steering at model/tool boundaries rather than pausing or aborting an active generation and resuming with injected context; no live channel replay was run in this read-only review.

## Solution Assessment

No. Current main is only a partial solution; the best fix still needs maintainer-approved lifecycle semantics plus remaining ordinary-message ingress work.
