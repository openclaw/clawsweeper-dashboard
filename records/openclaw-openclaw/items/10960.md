## Summary

Keep open. Current main has boundary steering plus a partial active-run admission fix, but it still does not implement the requested true soft-steer lifecycle: pause or abort an in-flight generation, inject the new user message into context, and resume with that input.

## What This Changes

The issue requests true mid-stream soft steering so a user message can interrupt an active agent generation, enter context immediately, and resume with that input.

## Best Possible Solution

Keep boundary steering as the current contract, resolve the narrower active-run ingress tracker separately, and only add true soft-steer after maintainers define an opt-in abort/capture/inject/resume lifecycle with transcript, tool-result, fallback, and provider-harness semantics.
