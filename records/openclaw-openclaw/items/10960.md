## Summary

Keep open: current main has narrowed part of the active-run steering gap, but it still implements boundary steering rather than the requested true pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests true mid-stream soft steering: interrupt an active generation or long-running turn, inject the new user message into context, and resume with that context.

## Best Possible Solution

Preserve documented boundary steering as the default, land the narrower active-run ingress fixes through their canonical path, and add true soft-steer only after maintainers define opt-in abort/capture/inject/resume semantics with transcript, tool-result, provider, Codex, and channel proof.
