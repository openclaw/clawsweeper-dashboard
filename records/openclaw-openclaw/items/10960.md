## Summary

Keep open: current main now has partial active-run steering fixes, but this issue asks for a stronger pause-or-abort, inject, and resume lifecycle that current source and docs still do not implement.

## What This Changes

The issue requests a soft-steer mode that can interrupt or pause an active generation or long tool phase, inject the new user message into context, and resume with that input.

## Best Possible Solution

Keep this issue as the broad product/runtime tracker, finish the narrower active-run admission fixes separately, and design soft steer as an explicit lifecycle with documented fallback, partial-output, tool-call, and upgrade semantics.
