- `P2`: The issue describes a meaningful active-run steering improvement with real workflow impact, but it is not a total runtime outage and the urgent regression slice is tracked separately.

## Summary

Keep open: current main has a merged partial fix for command-lane and active/non-streaming steering, but it still documents boundary steering rather than true pause-or-abort/resume soft steering, and the remaining ordinary-message admission path is still represented by an open candidate PR.

## What This Changes

The issue requests mid-stream soft steering that can pause or abort active generation, inject a user message immediately, and resume with the new context.

## Best Possible Solution

Keep this issue open as the broader runtime/product tracker, refresh or land the https://github.com/openclaw/openclaw/pull/89238 path for ordinary same-session admission, and document whether true pause-or-abort/resume soft steering belongs in existing `steer` or a new mode.
