## Summary

Keep open. Current main has a partial active-run steering admission fix, but the requested true soft-steer lifecycle still is not implemented: documented steering waits for runtime/model boundaries and does not pause or abort, inject the new user message, then resume the same generation with explicit partial-output semantics.

## What This Changes

Request to add true mid-stream soft steering so a user message can interrupt an active generation or long tool phase, enter context immediately, and let the agent continue with the new input.

## Best Possible Solution

Maintain boundary steering as the current contract, resolve the narrower active-run ingress work separately, and only add true soft-steer after maintainers define an opt-in abort/capture/inject/resume lifecycle with transcript, provider, tool, and fallback semantics.
