## Summary

Keep open: current main has boundary steering and a merged partial active-run admission fix, but it still does not implement the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests mid-stream soft steering so user input can interrupt or pause an active generation, enter context immediately, and resume with the new instruction.

## Best Possible Solution

Define an opt-in soft-steer contract that preserves current boundary steering by default, then implement abort/capture/inject/resume semantics with runtime, transcript, provider, channel, and upgrade proof.

## Reproduction Assessment

Yes, at source level: current docs and agent-loop contracts show steering is delivered at runtime/model boundaries, not by aborting an in-flight generation and resuming with injected context. I did not run live channel proof for this read-only review.

## Solution Assessment

Unclear as an implementation because the issue requests a product-level lifecycle change rather than one broken code path. The safer direction is an opt-in soft-steer design while preserving current boundary steering and tracking narrower active-run ingress fixes separately.
