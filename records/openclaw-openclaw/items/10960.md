## Summary

Keep open. Current main has useful partial steering fixes, but it still documents and implements boundary steering rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests a soft-steer mode that can interrupt an active generation, inject a new user message, and resume with the added context.

## Best Possible Solution

Keep boundary steering as the current contract, resolve the narrower active-run ingress work separately, and add true soft-steer only after maintainers define an opt-in abort/capture/inject/resume lifecycle with transcript, provider, tool, and fallback semantics.
