## Summary

Keep open: current main only provides boundary-based steering plus a partial active/non-streaming admission fix, while the issue asks for a stronger pause-or-abort, inject, and resume lifecycle. The narrower ordinary-message admission work remains tracked by open issue https://github.com/openclaw/openclaw/issues/48003 and open PR https://github.com/openclaw/openclaw/pull/89238, so this broader tracker is still necessary.

## What This Changes

Issue #10960 requests true mid-stream soft steering so a user message can interrupt or pause an active turn, enter context immediately, and let generation resume with that input.

## Best Possible Solution

Keep #10960 as the broad product/runtime tracker, finish the #48003/#89238 admission work separately, and design true soft steer as an explicit lifecycle with documented fallback, backend rejection, partial-output, and upgrade semantics.
