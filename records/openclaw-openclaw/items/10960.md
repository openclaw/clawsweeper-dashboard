## Summary

Keep open: current main implements boundary steering plus partial active-run admission, but not the requested pause-or-abort, inject, and resume soft-steer lifecycle. The narrower active-run ingress work remains tracked separately at https://github.com/openclaw/openclaw/issues/48003 and https://github.com/openclaw/openclaw/pull/89238, so closing this broader product tracker would lose the remaining lifecycle decision.

## What This Changes

Request true soft-steer behavior that pauses or aborts an in-flight generation, injects user guidance into context, and resumes with awareness of that input.

## Best Possible Solution

Define an opt-in soft-steer contract that preserves current boundary steering by default, then implement abort/capture/inject/resume semantics with focused runtime, transcript, provider, channel, and upgrade proof.
