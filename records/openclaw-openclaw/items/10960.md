## Summary

Keep open: current main has partial active-run steering fixes, but the requested soft-steer lifecycle still is not implemented because documented and source behavior remains boundary-based rather than pause-or-abort, inject, and resume.

## What This Changes

The issue requests mid-stream soft steering that can pause or abort active generation, inject a new user message into context immediately, and resume with awareness of that input.

## Best Possible Solution

Keep this issue as the broad product/runtime tracker, finish narrower active-run admission fixes separately, and design any true soft-steer behavior with explicit lifecycle, fallback, upgrade, and proof semantics.
