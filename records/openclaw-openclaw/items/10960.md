## Summary

Keep open: current main has partial active-run steering fixes, but this issue asks for a stronger pause-or-abort, inject, and resume lifecycle that current docs and source still do not implement.

## What This Changes

The issue requests true mid-stream soft steering: abort or pause an active generation, inject the user's message into context, and resume with the new input.

## Best Possible Solution

Keep this as the broad product/runtime tracker, finish the narrower active-run admission work separately, and design any true soft-steer behavior as an explicit lifecycle with fallback, upgrade, docs, and regression proof.
