## Summary

Keep open: current main has a useful partial active non-streaming steer fix, but the agent loop and docs still implement boundary-based steering rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

The issue requests true mid-stream soft steering so a user message can interrupt active generation or tool work, enter context, and let the run continue with that new input.

## Best Possible Solution

Keep this issue as the broad soft-steer product/runtime tracker and resolve it with a maintainer-approved lifecycle design covering streaming, active tool execution, abort/resume, backend rejection, transcript ordering, and fallback behavior.

## Reproduction Assessment

Yes, at source level for the current limitation: current main drains steering at supported runtime boundaries, and docs say it does not abort in-flight tools. The full pause-or-abort/resume behavior is a requested feature, not an existing behavior contract.

## Solution Assessment

No, current main is not the full requested solution. PR https://github.com/openclaw/openclaw/pull/98126 is a useful partial fix, but the maintainable path still needs an explicit soft-steer lifecycle design rather than another isolated admission patch.
