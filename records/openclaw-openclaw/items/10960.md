## Summary

## What This Changes

Add a soft-steer lifecycle that interrupts an active generation, injects new user input, and resumes with preserved context.

## Best Possible Solution

Keep boundary steering and interrupt as explicit primitives, then add a maintainer-approved soft-steer orchestration only if it preserves transcript and tool invariants and defines safe cross-runtime fallback behavior.
