## What This Changes

Request true mid-stream soft steering that pauses or aborts active generation, injects new user input into context, and resumes with that input applied.

## Best Possible Solution

Keep this as the broad soft-steer tracker until maintainers land or explicitly split the remaining lifecycle design, ordinary-message admission, and abort/resume semantics into narrower canonical work.

## Reproduction Assessment

Yes, at source level: current docs and agent-loop code show steering drains at model/tool boundaries rather than pausing or aborting active generation. The remaining pause/resume behavior is a requested feature, not a current documented contract.

## Solution Assessment

No, current main is only a partial solution. The maintainable path is a maintainer-approved lifecycle design that combines active-run admission with explicit interrupt/resume and fallback semantics.
