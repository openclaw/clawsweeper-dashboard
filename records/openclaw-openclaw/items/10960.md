## Summary

Keep open: current main has boundary-based steering and a partial active non-streaming admission fix, but the requested pause-or-abort, inject, and resume lifecycle is still not implemented and needs maintainer product/runtime design.

## What This Changes

The issue requests a soft-steer capability that can interrupt active generation or long tool work, inject new user input into context, and resume the run with awareness of that input.

## Best Possible Solution

Keep this issue as the broad product/runtime tracker, finish the narrower active-run admission work separately, and design any true soft-steer behavior as an explicit opt-in lifecycle with documented fallback, partial-output, tool-call, backend-rejection, and regression-test coverage.
