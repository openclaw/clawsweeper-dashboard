## Summary

Keep open. Current main has partially improved active/non-streaming steer admission, but it still does not implement the requested true soft-steer lifecycle that pauses or aborts in-flight generation/tool waiting, injects context immediately, and resumes with documented semantics.

## What This Changes

Request mid-stream message injection so steer mode can pause or abort active generation/tool waits, inject user context, and resume without waiting for the next boundary.

## Best Possible Solution

Keep this issue open as the broad soft-steer product/runtime tracker until maintainers land or reject the remaining pause-or-abort/resume lifecycle and any admission follow-up work with documented semantics.

## Reproduction Assessment

Yes, at source level: current docs and agent-loop code show steering drains at model/runtime boundaries and does not abort in-flight tools. I did not run a live channel replay in this read-only review.

## Solution Assessment

No, current main is only a partial solution. The best path is maintainer-approved lifecycle semantics that preserve tool-result pairing and transcript ordering while deciding interrupt/resume, fallback, admission, and security behavior.
