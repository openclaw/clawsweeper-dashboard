## Summary

Keep open. Current main has partial active/non-streaming steer admission, but the documented and implemented behavior is still boundary-based steering rather than the requested pause-or-abort, inject, and context-aware resume lifecycle.

## What This Changes

The issue requests a soft-steer runtime mode that can interrupt an active generation or long tool phase, inject a new user message into context, and resume with that input instead of waiting for the next boundary.

## Best Possible Solution

Keep this as the broad soft-steer tracker until maintainers land or reject lifecycle semantics for pause/abort, context injection, resume, fallback, transcript ordering, backend failure, and channel ingress.

## Reproduction Assessment

Yes, at source level: current docs and the agent loop show steering drains at runtime/model boundaries and does not abort in-flight tools. I did not run a live channel replay in this read-only review.

## Solution Assessment

No, current main is only a partial solution. The best path needs maintainer-approved lifecycle semantics that preserve tool-result pairing and transcript ordering while deciding interrupt/resume, fallback, admission, and security behavior.
