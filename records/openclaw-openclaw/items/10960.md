## Summary

Keep open. Current main has partial active-run steering fixes, but it still documents and implements boundary steering rather than the requested pause-or-abort, inject, and resume soft-steer lifecycle.

## What This Changes

Request true mid-stream soft-steer semantics that pause or abort active generation, inject new user input, and resume with the updated context.

## Best Possible Solution

Keep boundary steering as the current contract, resolve the narrower active-run ingress work separately, and add true soft-steer only after maintainers define an opt-in abort/capture/inject/resume lifecycle with transcript, provider, tool, and fallback semantics.
