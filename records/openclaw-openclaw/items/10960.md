## Summary

Keep this issue open: current main still provides boundary-based steering and a separate abort-and-replace interrupt mode, not the requested transparent pause/abort, context injection, and continuation lifecycle. The open linked implementation branch at https://github.com/BingqingLyu/openclaw/pull/2307 also means this issue should remain open until maintainers decide the permanent contract and that work is resolved.

## What This Changes

Request a soft-steer capability that interrupts an active generation or long tool phase, incorporates a new user message into context, and continues the same task.

## Best Possible Solution

Maintain the existing explicit steer and interrupt behavior unless maintainers approve a single documented soft-steer lifecycle contract covering cancellation, partial output, transcript persistence, tool execution, and continuation across all supported runners.
