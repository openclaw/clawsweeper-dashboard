## Summary

Keep open. Current main has boundary steering plus a partial active-run admission fix, but it still does not implement true soft-steer semantics: pause or abort an in-flight generation, inject the user message, and resume with that input.

## What This Changes

Request to add a soft-steer queue behavior that can redirect an active generation before the next normal tool/model boundary.

## Best Possible Solution

Preserve current boundary steering as the documented contract, resolve the narrower active-run ingress tracker separately, and add true soft-steer only after maintainers define opt-in abort/capture/inject/resume semantics with transcript, tool-result, fallback, and provider-harness coverage.
