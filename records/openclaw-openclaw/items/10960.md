## Summary

Keep open. Current main partially improves active/non-streaming steering through the merged runtime-admission fix, but this issue asks for a broader true soft-steer lifecycle that can pause or abort in-flight generation/tool waiting, inject context immediately, and resume; current docs and agent-loop behavior remain boundary-based and related admission/security/product work is still open.

## What This Changes

Request true mid-stream soft steering so user messages can interrupt active generation or long tool waits, enter context immediately, and let the agent resume with the new input.

## Best Possible Solution

Keep this as the broad soft-steer tracker until maintainers land or reject the remaining admission work and define documented lifecycle semantics for tool execution, streaming generation, abort/resume, fallback, and steering security hooks.

## Reproduction Assessment

Yes, at source level: current docs and agent-loop code still drain steering at model/runtime boundaries rather than pausing or aborting the in-flight work and resuming immediately. Current main partially fixes active non-streaming admission, but not the full soft-steer lifecycle requested here.

## Solution Assessment

No, current main is only a partial solution. The best path is a maintainer-approved lifecycle design that preserves tool-result pairing and transcript ordering while explicitly deciding interrupt/resume, fallback, admission, and security semantics.
