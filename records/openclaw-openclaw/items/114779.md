## Summary

## What This Changes

The PR threads the live run session key into the message tool so terminal source-reply delivery reads restart-recovery ownership from the live session while capability checks continue to use the sandbox session.

## System Context

Channel messages enter an agent run, where a sandboxed runtime can use a distinct policy session from the live run session. The message tool authorizes a send with the sandbox identity but hands terminal-reply delivery to the channel path, which must consult the live session that owns restart-recovery state.
