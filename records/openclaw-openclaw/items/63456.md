  - body: The replay path now truncates `validated` history directly, so heartbeat prompt/ack artifacts are no longer removed before the provider prompt is assembled. Those synthetic turns can persist as instruction-like context and push real user turns out of the retained history.
  - confidence: 0.86
- **[P2] Use channel approval capability metadata:** `src/agents/system-prompt.ts:179-184`
  - body: Hardcoding native approval guidance to four channel names misses channels whose plugins declare native exec approval support through `approvalCapability`, such as Matrix or other installed plugins. That makes affected agents emit duplicate or wrong `/approve` instructions instead of trusting the native approval surface.

  - body: The PR reads a stored provider API key and passes it to a provider-supplied stream function, broadening the credential boundary from central auth resolution into plugin/runtime stream code.
