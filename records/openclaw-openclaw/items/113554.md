## What This Changes

This PR updates CLI-runner message tracking so an explicit `message` send that resolves to the active channel source is counted as delivery evidence, preventing stranded-reply recovery from duplicating that reply.

## System Context

CLI-runner agents call the message tool through a loopback MCP server and record completed sends as delivery evidence. That evidence feeds the stranded-reply safeguard, which either accepts the reply as delivered or issues a recovery send to the channel.
