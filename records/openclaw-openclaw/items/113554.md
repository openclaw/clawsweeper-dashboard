## What This Changes

The PR makes explicit `message` sends count as source-reply delivery evidence when their resolved destination is the active conversation, across the CLI runner and two embedded-agent paths.

## System Context

Agent runtimes execute a messaging tool call and record whether it delivered the reply to the source conversation. That record feeds stranded-reply recovery, which otherwise may send a second visible channel message when it thinks the original reply was not delivered.
