## Summary

Keep open: current main still lacks a Telegram config-level per-agent outbound topic binding, while existing explicit topic targets and active-context auto-threading only cover adjacent delivery paths.

## What This Changes

Requested Telegram support for a config-level per-agent default outbound topic/thread binding so proactive sends can target forum topics without passing threadId each time.

## Best Possible Solution

Define a Telegram-owned outbound topic-default contract with explicit precedence, then update schema, docs, and proactive message.send coverage for forum-topic sessions.

## Solution Assessment
