## Summary

Keep open: current main and the latest release still lack the requested Telegram config-level per-agent outbound topic default. Existing explicit `:topic:` targets, per-call `threadId`, and active-context auto-threading are useful but do not settle the new config/default and delivery-precedence contract.

## What This Changes

Request adds a Telegram per-agent default outbound topic/thread binding so proactive sends can target configured forum topics without per-call `threadId`.

## Best Possible Solution

Define a Telegram-owned outbound-topic default contract with explicit precedence and opt-outs, then document and test proactive `message.send` behavior from forum-topic sessions with live Telegram proof.
