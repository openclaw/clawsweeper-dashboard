## Summary

Keep open: current main and v2026.6.11 still lack a Telegram config-level per-agent outbound topic default, while the reported no-thread proactive send path remains a real product gap rather than an already-implemented fix.

## What This Changes

The issue requests a Telegram topic config option that lets each agent default proactive outbound sends to its configured forum topic without passing `threadId` on every send.

## Best Possible Solution

Define a Telegram-owned outbound-topic default contract with explicit precedence and opt-outs, then document and test proactive `message.send` behavior from forum-topic sessions with live Telegram proof.
