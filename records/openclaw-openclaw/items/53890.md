## Summary

Keep open: current main still lacks a Telegram config-level per-agent outbound topic binding, and the existing explicit topic targets plus active-context auto-threading cover adjacent paths rather than the requested default delivery contract.

## What This Changes

Add a Telegram per-agent outbound topic default so proactive sends can target an agent's forum topic without per-call `threadId`.

## Best Possible Solution

Define a Telegram-owned outbound topic-default contract with maintainer-approved precedence, then land schema/types/docs and regression coverage for proactive `message.send` from forum-topic sessions.
