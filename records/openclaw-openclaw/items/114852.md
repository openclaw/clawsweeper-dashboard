## What This Changes

This branch changes agent prompts, scheduler tool output, session labels, notifications, validation errors, and the workspace template to call scheduled work “automations” while retaining cron syntax, configuration keys, RPC names, and stored identifiers.

## System Context

OpenClaw’s scheduler accepts jobs through the agent tool and cron service, then exposes their state through prompts, sessions, task status, delivery notices, and failure alerts. This PR changes the reader-facing terminology at those boundaries without changing the scheduler’s persisted or wire-level cron identifiers.
