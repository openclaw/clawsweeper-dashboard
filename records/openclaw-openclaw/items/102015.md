## Summary

Keep open: current main still records ordinary model fallback transitions as `model.fallback_step` trajectory events, while the `model.failover` diagnostic event is only emitted from the cooldown suspension branch. The issue is now actively paired with open fix candidates, including a closing PR, so it should stay open until one lands.

## What This Changes

The issue asks for model fallback telemetry to mark ordinary retry chains as fallback events so operators can see retry storms in traces.

## Best Possible Solution

Land one narrow fix that emits the existing trusted `model.failover` diagnostic event for ordinary failed-candidate to next-candidate transitions, with focused tests, while leaving new `has_fallback`, backoff, and circuit-breaker policy out of this bug fix.
