## Summary

Keep open: current main has a documented `model.failover` telemetry/exporter contract, but normal fallback transitions appear to be recorded only as trajectory `model.fallback_step` events rather than emitted to the diagnostic event stream. The prior broader fallback-telemetry PR is closed unmerged, so it is related context but not a safe superseding fix.

## What This Changes

The issue asks for model fallback/retry chains to be visible in telemetry traces when multiple models are attempted.

## Best Possible Solution

Emit the existing trusted `model.failover` diagnostic event for ordinary model fallback transitions, with focused regression coverage, and leave backoff/circuit-breaker policy out of this narrow bug fix.
