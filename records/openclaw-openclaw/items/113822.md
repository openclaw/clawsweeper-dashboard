## What This Changes

Adds `runtime.providerUsage.read` so trusted plugins can obtain a token-free usage snapshot for one exact provider authentication profile without refresh or credential fallback.

## System Context

A trusted plugin runtime call is bound to the active agent, resolves one auth profile from that agent’s store, applies provider-owned usage authorization, and returns a sanitized provider usage snapshot. The result lets plugins display quota information while keeping credentials out of the plugin API.
