## What This Changes

This PR adds `runtime.providerUsage.read` so plugins can obtain a token-free usage snapshot for one exact provider auth profile without refresh or fallback, while propagating plugin and agent scope through runtime callbacks.

## System Context

Provider usage normally resolves credentials and fetches quota data for a provider. This PR adds a plugin SDK bridge that selects one configured profile using the active agent’s workspace, applies provider-owned usage authorization, and returns a sanitized snapshot to plugin code.
