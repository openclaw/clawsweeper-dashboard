## What This Changes

This PR adds `runtime.providerUsage.read`, a token-free plugin-runtime API that reads usage for one exact provider auth profile without refresh or credential fallback.

## System Context

Trusted plugins use the runtime API to inspect a provider quota for the active agent. The runtime must bind the request to that agent’s auth store and plugin workspace, apply provider-owned usage authorization, and return a sanitized snapshot without credentials or identity fields.
