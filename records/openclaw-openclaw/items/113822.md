## What This Changes

This PR adds `runtime.providerUsage.read` so trusted plugins can retrieve a token-free usage snapshot for one exact provider authentication profile without refresh, fallback, or identity output, while extending plugin callback scope propagation to carry the active agent.

## System Context

OpenClaw's plugin runtime lets trusted installed plugins invoke host-owned capabilities during commands, hooks, tools, and lifecycle events. This change introduces an agent-scoped provider-usage bridge that resolves a selected auth profile through provider-owned authorization and usage-fetch hooks, then returns a sanitized snapshot to the plugin.
