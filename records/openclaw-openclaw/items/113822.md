## Summary

Keep this PR open: current `main` does not expose this exact-profile runtime seam, and the related user-facing follow-up at https://github.com/openclaw/openclaw/pull/113920 still depends on it. However, the proposed public plugin API is not restricted to trusted plugins despite handling provider-auth-backed reads, and it still lacks maintainer approval for the new SDK contract and real after-fix provider proof.

## What This Changes

This PR adds `api.runtime.providerUsage.read` so plugins can fetch a token-free provider-usage snapshot for one exact auth profile without credential refresh or fallback.

## System Context

Plugin callbacks receive a host-scoped runtime API during agent work. This new bridge resolves the active agent’s profile, applies provider-owned usage authorization and fetch hooks, then returns a sanitized usage snapshot to the plugin.
