## What This Changes

Adds `runtime.providerUsage.read(...)`, a token-free plugin-runtime API for reading provider usage for one exact stored auth profile without refresh or credential fallback.

## System Context

OpenClaw’s plugin runtime exposes selected host capabilities to trusted native plugins. This change connects a plugin request for an exact auth profile to the provider-usage resolver and provider-owned usage hook, returning a sanitized usage snapshot to the plugin.
