## What This Changes

This PR adds `runtime.providerUsage.read` so trusted plugins can retrieve a token-free usage snapshot for one exact provider auth profile without credential refresh or fallback, while propagating trusted agent scope through plugin callbacks.

## System Context

Trusted plugins run through OpenClaw’s host runtime and may need provider quota data without receiving raw credentials. The proposed path binds a plugin call to the active agent, resolves one profile, applies provider-owned usage authorization, and returns a sanitized usage snapshot.
