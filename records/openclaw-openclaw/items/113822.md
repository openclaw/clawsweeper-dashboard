## What This Changes

Adds `runtime.providerUsage.read`, letting trusted plugins obtain a token-free provider-usage snapshot for one exact auth profile without credential refresh or fallback, and propagates trusted plugin and agent scope through relevant runtime callbacks.

## System Context

Provider usage normally resolves credentials and fetches quota data for a provider. This change introduces a plugin SDK bridge that binds a request to the active agent and workspace, resolves one named profile without fallback, applies provider-owned usage policy, and returns a sanitized usage snapshot to the plugin.
