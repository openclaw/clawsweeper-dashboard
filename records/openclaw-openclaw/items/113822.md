## Summary

## What This Changes

Adds a trusted plugin-runtime method that reads a usage snapshot for one exact provider auth profile without returning credentials, identity fields, refreshes, or profile fallback.

## System Context

Plugins call the PluginRuntime facade for privileged runtime services. This new provider-usage path resolves a named auth profile, obtains provider-specific usage authorization, calls a provider-owned usage hook, and returns a sanitized snapshot to the plugin.

## Architecture Diagram

  Sanitize --> Snapshot[Usage snapshot]

## Best Possible Solution

Define a provider-owned exact-profile usage-auth contract that normalizes usage owners, preserves exact-profile and no-refresh semantics on every error path, then expose the SDK method only after its permanent API direction is approved and proven against real provider profiles.
