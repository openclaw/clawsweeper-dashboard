## What This Changes

This PR adds `runtime.providerUsage.read`, allowing trusted plugins to fetch a token-free provider-usage snapshot for one exact auth profile without credential refresh or fallback.

## System Context

Trusted plugin code invokes the plugin runtime, which derives the active agent’s directories and resolves an exact auth profile through provider-owned authorization and usage hooks. The result is a sanitized usage snapshot returned to the plugin without exposing tokens or identity fields.
