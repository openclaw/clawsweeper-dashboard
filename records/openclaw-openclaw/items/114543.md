## Summary

Keep it open only for an owner decision on whether a distinct non-card live-preview contract is needed; likely related people: Marvinthebored (low confidence, recent Feishu streaming-card release work) and openperf (low confidence, adjacent agent-streaming work).

## What This Changes

Request a Feishu adapter live-preview contract matching Telegram so long agent replies show draft, finalization, and progress updates.

## System Context

Feishu is an official channel plugin that receives chat events, sends responses through Feishu message and card APIs, and returns visible updates to the user. Its existing streaming mode uses Card Kit interactive cards to update partial agent output before final delivery.
