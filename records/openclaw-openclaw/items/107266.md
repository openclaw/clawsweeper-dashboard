## What This Changes

The branch sanitizes reconstructed GitHub Copilot reasoning history and outbound replay items, then adds one pre-output retry that removes rejected reasoning and compaction items from OpenAI Responses requests.

Keep Copilot cold-resume sanitation in the provider plugin, but place the single pre-output encrypted-reasoning retry in the shared Responses lifecycle used by every runner, preserving visible messages and tool call/output pairs, then prove the exact merged head with both a polluted cold session and a same-loop tool turn.
