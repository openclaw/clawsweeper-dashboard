Keep this draft open for maintainer review: it combines two valid fixes and has strong mocked coverage, but the lineage-aware Copilot replay policy still lacks token-backed real behavior proof and competes with an open maintainer-authored strip-all approach.

## What This Changes

The draft replaces GitHub Copilot’s ID-rewrite replay policy with lineage-aware reasoning sanitation and extends OpenAI Responses recovery to retry pre-output encrypted-content failures encountered during stream creation or draining.

## Best Possible Solution

Use the provider boundary to retain only exact or idless reasoning proven to belong to the active user turn, pair it with one generic pre-output sanitized retry, and merge only after live Copilot runs prove sequential tools, parallel tools, token rotation, and streamed rejection recovery without duplicate output.
