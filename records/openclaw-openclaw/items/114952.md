## What This Changes

Adds a validated plugin-level OpenShell control-plane workspace setting, sends it to OpenShell CLI calls, and documents and tests the new configuration.

## System Context

The OpenShell extension creates and manages remote sandboxes through the OpenShell CLI, then uses generated SSH configuration to run commands and transfer files. Plugin configuration feeds lifecycle CLI calls and must also reach the later SSH proxy process so both routes address the same control-plane workspace.

## Architecture Diagram

  C --> F

## Best Possible Solution

Choose an explicit upgrade policy, preserve the legacy ambient workspace path unless maintainers intentionally approve a breaking transition, and serialize an explicitly selected workspace into the generated SSH proxy route with end-to-end coverage for lifecycle, exec, and transfer paths.
