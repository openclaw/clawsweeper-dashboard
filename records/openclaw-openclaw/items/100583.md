## Summary

Keep open: the previous CLI-subagent terminal/finalizing blocker is fixed at the new head, but the childless maintenance allowlist can falsely terminalize active deferred context-engine maintenance because it does not stop or prove absence of the owner worker.

## What This Changes

The PR changes task-registry cancellation to kill CLI rows backed by subagent child sessions, reconcile subagent kill outcomes, and allow selected childless maintenance rows to be cancelled, with task-registry regressions.

## Best Possible Solution

Gate childless context-engine maintenance cancellation on the maintenance owner actually cancelling the queued worker or proving no active deferred run exists, while keeping stale post-restart rows clearable.
