## Summary

Keep this PR open, but the patch is not merge-ready: the new CLI-subagent cancellation branch ignores the admin kill result and can force a CLI task row to `cancelled` even when the backing subagent is finalizing or already completed with a non-cancelled terminal state.

## What This Changes

The PR changes task-registry cancellation so stopped subagent wrappers, CLI rows backed by subagent child sessions, and childless ACP context-engine maintenance rows can be cancelled from the operator entrypoint.

## Best Possible Solution

Merge this only after the CLI-subagent cancellation path preserves the same terminal/finalizing result handling already used by the subagent cancellation branch.
