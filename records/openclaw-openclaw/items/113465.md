## What This Changes

The PR bounds Markdown previews and file editors inside the chat detail sidebar so their inner scroll areas remain usable, and adds browser tests for Markdown and CodeMirror scrolling.

## System Context

The Control UI chat detail sidebar renders several content kinds, including Markdown, files, and session discussions. A host wrapper controls whether those views receive a bounded flex height; the wrapped Markdown renderer and CodeMirror editor then provide their own overflow scrolling.
