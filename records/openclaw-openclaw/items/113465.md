## Summary

Keep this PR open for ordinary maintainer review: it remains necessary because current main still applies the full-height sidebar host only to discussion content, while this branch extends that established layout boundary to Markdown and preserves the related Firefox flex fix. The patch is small, coherent, proof-positive, and has no discrete correctness or security finding; pending exact-head CI is the remaining merge gate.

## What This Changes

The PR makes long Markdown previews in the chat detail sidebar use the existing full-height flex host, adds flex minimum-height rules for sidebar and modal scroll containers, and adds a browser regression test that verifies real scrolling.

## System Context

The Control UI displays chat detail content, including rendered Markdown, in a flex-based sidebar. The detail panel chooses whether content gets a bounded host wrapper; that wrapper and the inner scroll container together determine whether overflow becomes a usable scrollbar instead of clipped content.
