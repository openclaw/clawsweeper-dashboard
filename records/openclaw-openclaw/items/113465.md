## Summary

The requested scroll repair is still necessary: current main still leaves the sidebar scroll child without the explicit flex minimum-height reset, while this PR also supplies the missing bounded host for Markdown and file content. The focused browser proof and green exact-head checks support the patch, but the clean PR is behind current main and needs a refresh plus exact-head validation before landing.

## What This Changes

The PR bounds Markdown previews and CodeMirror file editors inside the chat detail sidebar, adds the flex minimum-height repair, and adds browser assertions that their inner scroll areas can scroll.

## System Context

The Control UI chat detail sidebar renders several content kinds, including Markdown documents and file previews. Those views pass through a host wrapper before reaching either the sidebar scroll area or CodeMirror, so both the wrapper and the inner flex child must have a resolved bounded height for overflow scrolling to work.
