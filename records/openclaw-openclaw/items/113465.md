Keep open: this is a focused, evidence-backed fix for an open Firefox sidebar-scrolling regression, and the branch adds the missing bounded host constraint plus a browser assertion that exercises real overflow and `scrollTop` behavior.

## What This Changes

The PR makes Markdown chat-sidebar previews use a full-height flex host, preserves the flex minimum-height fixes for the sidebar and modal, and adds a browser regression test for independently scrolling long Markdown content.

## System Context

The Control UI chat detail panel receives a selected sidebar content kind and renders Markdown into the right-hand detail rail. The rail’s host and inner scroll container must remain bounded so long Markdown can overflow and scroll rather than expand beyond the available chat layout.
