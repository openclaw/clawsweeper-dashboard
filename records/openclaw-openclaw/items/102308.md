## Summary

Keep open. Current main still renders iOS chat activity from chat-owned pending runs, while the report covers the separate case where history says the session is active but no chat in-flight snapshot is present; the open linked PR is the candidate fix and should be reviewed before this issue closes.

## What This Changes

The issue requests that iOS Chat keep visible assistant activity when returning to a long-running active session whose history has no chat in-flight snapshot.

## Best Possible Solution

Shared Apple chat UI should surface a bounded activity indicator from session active-run metadata only while the latest user turn is unanswered, then clear it on assistant output, terminal state, session switch, reset, or timeout.
