## What This Changes

The issue requests a durable offline command queue for the iOS/Android mobile node apps that captures commands while disconnected and syncs them when gateway connectivity returns.

## Best Possible Solution

Define and land a staged durable mobile outbox: Android text queue can proceed as a guarded first slice, while shared captured-time, idempotency, privacy, iOS, and voice semantics remain tracked here.
