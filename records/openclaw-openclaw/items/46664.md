## What This Changes

Request a durable iOS/Android offline command queue that captures text or voice intents while disconnected and replays them to the Gateway after reconnect.

## Best Possible Solution

Define a staged mobile outbox contract, then land durable encrypted storage and idempotent reconnect replay for one narrow surface before expanding to voice, iOS, and queue-management UI.
