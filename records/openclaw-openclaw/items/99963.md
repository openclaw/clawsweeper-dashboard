## Label Justifications

- `P1`: A source-reproducible main-turn timeout can bypass a configured model fallback chain and fail a live agent turn.
- `impact:session-state`: The failure is triggered by embedded prompt cleanup detecting session-file takeover while preserving the original prompt error.
- `impact:auth-provider`: The reported bug changes provider/model fallback routing for timeout-class provider failures.

## Summary

Keep this issue open: current main still aborts model fallback for takeover-named embedded attempt wrappers before inspecting the preserved provider timeout in `promptError`. The remaining blocker is a maintainer decision on whether preserved provider failures should override the session-takeover abort contract that was intentionally landed in https://github.com/openclaw/openclaw/pull/84321, likely through the broader open fix candidate at https://github.com/openclaw/openclaw/pull/89039.

## What This Changes

The issue requests that main-turn timeout errors preserved inside `EmbeddedAttemptPromptErrorWithCleanupTakeoverError.promptError` participate in model fallback instead of being aborted as pure session-takeover coordination errors.

## Best Possible Solution

Define one maintainer-approved contract that distinguishes pure cleanup/session takeover from wrappers whose preserved prompt failure is a provider timeout, then cover both fallback continuation and pure-takeover abort with focused regression tests.

## Reproduction Assessment

Yes for source reproduction: current main constructs a takeover-named wrapper with `.promptError`, then the fallback classifier returns local coordination before any path can inspect that field. I did not run a live timeout race, so this is source-reproducible rather than fully reproduced.

## Solution Assessment

Unclear as a final fix: the narrow `promptError` unwrapping is plausible, but maintainers need to decide how it interacts with the intentional takeover-aborts-fallback safety contract from https://github.com/openclaw/openclaw/pull/84321 and the broader open fix at https://github.com/openclaw/openclaw/pull/89039.
