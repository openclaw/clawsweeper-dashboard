## Label Justifications

- `P1`: A configured fallback chain can be bypassed during real main-turn timeouts, breaking a live agent workflow for affected users.
- `impact:session-state`: The timeout is wrapped by embedded session-takeover cleanup state, and the safe behavior depends on that session-state contract.
- `impact:auth-provider`: The issue is about provider/model fallback routing deciding whether to try configured fallback candidates after a timeout.

## Summary

Keep this issue open: current main and the latest release still abort model fallback for takeover-named wrappers even when the original timeout is preserved in `promptError`. The remaining decision is whether maintainers want to change the session-takeover safety contract that was intentionally merged in https://github.com/openclaw/openclaw/pull/84321, possibly through the broader open fix candidate at https://github.com/openclaw/openclaw/pull/89039.

## What This Changes

The issue asks for main assistant turn timeouts preserved inside cleanup-takeover wrappers to remain eligible for the configured model fallback chain.

## Best Possible Solution

Maintainers should decide the contract, then either land or narrow the promptError-aware path from https://github.com/openclaw/openclaw/pull/89039 so timeout/rate-limit prompt errors fall back while pure takeover errors still abort, or explicitly keep the current takeover-fatal behavior.

## Reproduction Assessment

Yes, at source level: current main constructs a takeover-named wrapper with `.promptError`, then the fallback classifier returns local coordination before any path can inspect that field. I did not run a live timeout race, but the inspected path matches the reporter's logs.

## Solution Assessment

Unclear until maintainers decide the session-takeover versus provider-fallback contract. The suggested `promptError` unwrapping is a plausible narrow repair, and https://github.com/openclaw/openclaw/pull/89039 already explores the adjacent implementation path, but the current abort behavior was intentionally merged for session-state safety.
