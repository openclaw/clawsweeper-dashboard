## Summary

The requested isolation model matches current guidance that adversarial users need separate gateways, but adding a privileged fleet control plane is a new security and operations product direction. The protected `maintainer` label also requires explicit maintainer handling, so this should remain open for a core-versus-external orchestration decision.

## What This Changes

Add an `openclaw fleet` CLI supervisor that provisions and manages hardened, isolated per-tenant OpenClaw container instances and documents the hosted trust model.

## Best Possible Solution

Approve a cell threat model and lifecycle contract first, then either document and validate hardened externally orchestrated cells or sponsor a deliberately bounded core supervisor with explicit security, SQLite registry, upgrade, rollback, recovery, and deletion guarantees.
