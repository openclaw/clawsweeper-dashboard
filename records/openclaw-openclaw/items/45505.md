## What This Changes

The issue requests a generalized, idempotent post-timeout compaction completion reconciliation model for session counters, token/status snapshots, downstream events, and recovery state.

## Best Possible Solution

Define a bounded, idempotent compaction-completion reconciliation boundary and move only clearly compaction-derived session state into it, with narrower follow-up issues retaining unrelated provider, channel, or metadata-only fixes.
