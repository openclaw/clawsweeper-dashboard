## What This Changes

The issue requests a generalized post-timeout compaction completion reconciliation model across session-state surfaces.

## Best Possible Solution

Define one maintainer-approved compaction-completion reconciliation boundary, then deliberately enroll only compaction-derived session fields with monotonic/idempotent semantics and focused regression coverage.

## Reproduction Assessment

No high-confidence live reproduction is available for a remaining current-main user-visible bug. Source inspection does confirm the current design is still a narrow count reconciler while other session-state consumers remain separate.

## Solution Assessment
