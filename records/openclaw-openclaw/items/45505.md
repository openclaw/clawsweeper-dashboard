## Summary

Keep open: current main and the latest release still have a narrow count-only late-success reconciliation path, while the requested authoritative compaction-completion boundary for other compaction-derived session state remains undecided.

## What This Changes

The issue requests a generalized post-timeout compaction-completion reconciliation model for session counters, token/status snapshots, and related session-state convergence.

## Best Possible Solution

Define one authoritative compaction-completion reconciliation boundary that owns monotonic compaction-derived session fields, then land narrower status, activity, token, and recovery follow-ups against that contract.
