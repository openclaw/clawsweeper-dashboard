## Summary

Keep open: current main still contains the reported timeout-path cleanup gap, while this PR is an actively maintained, viable fix for the linked issue. No concrete correctness defect is established on the latest head, but the exact-head validation run is not yet merge-ready.

## What This Changes

The branch makes gateway reset and delete arm lease-preserving MCP runtime retirement before waiting for active runs, then completes cleanup after timed-out or replacement runs release their final leases.

## Best Possible Solution

Keep one manager-owned required-retirement marker across reset/delete, runtime reuse, and replacement runs; preserve active leases, dispose immediately after the final lease, and land only with exact-head type, boundary, gateway-timeout, and real child-process lifecycle proof.
