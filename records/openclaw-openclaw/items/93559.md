## Summary

Keep open: the stale MCP process bug is still source-reproducible on current main, but this PR still retires the session MCP runtime before proving the old embedded run drained, so the previous lifecycle-safety blocker remains.

## What This Changes

The PR moves gateway session MCP runtime retirement to run unconditionally immediately after aborting the embedded run and before the 15-second drain wait.

## Best Possible Solution

Retire stale MCP runtimes only after the old run drains, is explicitly force-cleared, or disposal can defer until active MCP leases release, with reset/delete timeout coverage and live active-MCP proof.
