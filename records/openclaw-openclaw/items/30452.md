## Summary

Keep open: current main and v2026.6.11 already include the requested global compaction and memory-flush model override surfaces, but the successful flush-then-reset mode is still absent and needs a maintainer product/security decision.

## What This Changes

Request configurable housekeeping model overrides and an opt-in mode that resets a session after a successful pre-compaction memory flush instead of compacting.

## Best Possible Solution

Keep the shipped model override surfaces, land or replace the separate safeguard-mode fix, and decide one default-off reset/memory policy that covers compaction-threshold reset-after-flush alongside reset-time memory preservation.
