## Summary

Keep open: the compaction and memory-flush model override pieces are already present on current main and in v2026.6.11, but the successful flush-then-reset mode is still absent and requires maintainer product/security direction.

## What This Changes

The issue requests configurable housekeeping models for compaction and memory flush, plus an opt-in mode that resets the session after a successful memory flush instead of compacting.

## Best Possible Solution

Keep the shipped model override behavior, then define one maintainer-approved reset/memory policy that covers compaction-threshold reset-after-flush alongside explicit, daily, and idle reset memory preservation.
