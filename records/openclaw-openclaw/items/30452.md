## Summary

Keep open: current main and v2026.6.11 already implement the requested compaction and memory-flush model overrides, but there is still no successful flush-then-reset mode; the remaining behavior needs maintainer product and security direction.

## What This Changes

Requests compaction and pre-compaction memory-flush model override config plus an opt-in mode that resets after a successful memory flush instead of compacting.

## Best Possible Solution

Keep the shipped model override behavior, then define one default-off reset-memory policy that covers compaction-threshold reset-after-flush together with explicit, daily, and idle reset memory preservation.
