## What This Changes

## Best Possible Solution

Keep the shipped model overrides, then handle reset-after-flush as an explicit session-lifecycle design: opt-in, documented, tested across reset/compaction paths, and reconciled with https://github.com/openclaw/openclaw/issues/45608.
