## Summary

Keep open: current main and the latest release already cover the requested `compaction.model` and `memoryFlush.model` overrides, but the requested successful flush-then-reset mode is still absent and needs maintainer product/security direction.

## What This Changes

The issue requests configurable cheaper models for compaction and memory flush, plus a mode that flushes memory and resets the session instead of compacting.

## Best Possible Solution

Keep the shipped model override behavior, then define one maintainer-approved reset/memory policy that covers compaction-threshold reset-after-flush alongside explicit, daily, and idle reset memory preservation.
