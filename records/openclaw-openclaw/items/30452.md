## Best Possible Solution

Keep the shipped model override behavior, and decide the remaining flush-then-reset mode as an explicit opt-in session lifecycle policy that is coordinated with https://github.com/openclaw/openclaw/issues/45608 rather than closed as already done.

## Solution Assessment
