## Summary

Keep open: current main and v2026.6.11 already support the compaction and memory-flush model override parts, but the requested successful flush-then-reset mode is still absent and needs maintainer product/security direction.

## What This Changes

The issue requests configurable compaction and memory-flush housekeeping model overrides plus an opt-in mode that flushes memory and resets the session instead of compacting.

## Best Possible Solution

Keep the shipped model-override behavior and design one explicit opt-in reset-after-flush lifecycle policy, coordinated with reset-memory lifecycle work, before implementing the remaining mode.
