## Summary

Keep open: the compaction and memory-flush model override portions are already implemented on current main and present in v2026.6.11, but the requested successful flush-then-reset mode is still absent and needs maintainer product/security review.

## What This Changes

Request to reduce compaction housekeeping cost with model overrides and optionally reset the session after a successful memory flush instead of compacting.

## Best Possible Solution

Keep the shipped model overrides and design one explicit opt-in reset-after-flush lifecycle policy coordinated with reset-memory and auto-split work before implementation.
