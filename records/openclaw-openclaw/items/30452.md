## Summary

Keep open: current main and the latest release cover the compaction and memory-flush model override portions, but the requested successful flush-then-reset mode is still absent. The remaining behavior is a session-lifecycle and security policy decision, not a cleanup close.

## What This Changes

The issue requests compaction and pre-compaction memory-flush model overrides plus an opt-in mode to reset after a successful memory flush instead of compacting.

## Best Possible Solution

Keep the shipped model-override behavior and design one explicit opt-in reset-after-flush lifecycle policy, coordinated with https://github.com/openclaw/openclaw/issues/45608, before implementing the remaining mode.
