## What This Changes

The PR adds `CNContactFormatter.descriptorForRequiredKeys(for: .fullName)` to the iOS contacts payload fetch keys so contacts.add/search fetch every key needed before formatting display names.

## Best Possible Solution

Land this narrow `ContactsService` fetch-key fix after normal maintainer checks, while keeping https://github.com/openclaw/openclaw/issues/99056 open for the separate ReplayKit crash path.

## Reproduction Assessment

Yes: the contributor supplied a before crash backtrace and after `node.invoke contacts.add` success on a current-main simulator, and source inspection confirms the formatter runs after a narrower key fetch. I did not rerun the simulator locally.

## Solution Assessment

Yes: adding the official formatter required-key descriptor at the shared `payloadKeys` fetch boundary is the narrowest maintainable fix; fetching individual extra name keys or replacing the formatter would be more brittle.
