## What This Changes

The PR centralizes cancellation/timeout precedence for agent runs, applies that terminal result when merging Gateway agent and chat observations, and continues embedded-run cleanup after an individual release callback fails.

## System Context

The agent runtime turns provider completions, cancellations, and timeouts into a terminal run result that feeds session persistence and Gateway wait responses. The embedded runner tears down active resources after a run settles, while Gateway combines observations from agent and chat sources before returning the final state to callers.
