## What This Changes

Centralizes terminal cancellation/timeout precedence for agent runs, applies it consistently to Gateway observations, and makes embedded-run cleanup continue releasing resources after an individual teardown callback fails.

## System Context

Agent runs report terminal events from providers and Gateway observation sources, which are merged into a session-facing terminal result. Embedded-run teardown then releases the active-run registry and abort listeners so the next user message can be admitted instead of remaining blocked.
