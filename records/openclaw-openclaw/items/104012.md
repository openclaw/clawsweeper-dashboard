- **[P2] Require CSS metrics before forwarding pointer actions:** `ui/src/components/browser/browser-panel.ts:747-749`
  - body: When the metrics probe is unavailable, this maps the displayed pointer through the decoded screenshot dimensions. The browser action contract consumes CSS viewport coordinates, while screenshots can use a non-1 device scale factor, so clicks and inspection can target the wrong location. Disable precise pointer actions or obtain authoritative CSS geometry instead of using `naturalWidth` and `naturalHeight`.
  - confidence: 0.98
- **[P2] Resolve the inspected element at pointer-down:** `ui/src/components/browser/browser-panel.ts:850-853`
  - body: Inspect capture sends the last throttled hover result rather than resolving the element at the click coordinates. A user who moves and clicks before the request finishes can attach and describe the previous element, so inspect the pointer-down position or verify the cached result belongs to that position before dispatching.
  - confidence: 0.99
- **[P2] Clear provisional new-tab state when canceled:** `ui/src/components/browser/browser-panel.ts:1094-1096`
  - body: The plus button sets `pendingNewTab`, but Escape, empty submission, and selecting an existing tab do not clear it. A later URL submission therefore opens an unexpected extra tab instead of navigating the active tab; clear the provisional state whenever the new-tab flow is abandoned.
  - confidence: 0.99
- **[P2] Serialize forwarded browser keystrokes:** `ui/src/components/browser/browser-panel.ts:843-844`
  - body: Each keydown starts an independent browser.request without waiting for the preceding key. The gateway dispatches general requests concurrently, so rapid typing can reach the remote page out of order; queue keyboard mutations per active tab before sending the next key.
  - confidence: 0.96

  - body: Adding this documentation section changes the generated docs inventory, and the exact-head `check-docs` job fails because `docs/docs_map.md` was not refreshed. Regenerate the docs map so the documented surface passes the repository docs gate.
