Full review comments:

- **[P2] Require CSS metrics before forwarding pointer actions:** `ui/src/components/browser/browser-panel.ts:747-749`
  - body: When evaluation is disabled or the metrics probe fails, `remotePoint()` substitutes screenshot pixel dimensions for the remote CSS viewport. The coordinate routes consume CSS pixels, so HiDPI or resized captures send clicks and inspect queries to the wrong location; disable coordinate-sensitive actions until real CSS metrics are available.
  - confidence: 0.99
- **[P2] Resolve the inspected element at pointer-down:** `ui/src/components/browser/browser-panel.ts:849-853`
  - body: Inspect pointer-down sends `this.inspected`, which is only the last throttled hover result. A fast move-and-click can therefore attach and highlight the previous element; inspect the current pointer coordinates before dispatching the annotation.
  - confidence: 0.99
- **[P2] Clear provisional new-tab state when canceled:** `ui/src/components/browser/browser-panel.ts:1094-1099`
  - body: The plus action leaves `pendingNewTab` set until a successful navigation. Escape, an empty submit, or selecting an existing tab can abandon that flow, but a later URL edit still opens an extra tab; clear the intent on every cancel or tab-selection path.
  - confidence: 0.99
- **[P2] Serialize forwarded browser keystrokes:** `ui/src/components/browser/browser-panel.ts:830-845`
  - body: Every keydown launches a separate `browser.request` without waiting for the prior mutation. Rapid typing can overlap downstream and arrive out of order or be dropped; queue forwarded mutations per active tab before sending the next key.
  - confidence: 0.98
- **[P3] Regenerate the docs map:** `docs/web/control-ui.md:275`
  - body: This PR adds a new `Browser panel` heading but does not update the generated `docs/docs_map.md`; the exact-head `check-docs` job fails. Run the repository docs-map generator and commit the regenerated map.
  - confidence: 1
