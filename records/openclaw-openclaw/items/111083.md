## Summary

The requested cache-stable hook contract is already implemented, documented, and shipped: plugins can return `prependSystemContext` for stable system-prompt guidance before the host prompt and cache boundary. A separate `stableSystemContext` alias or placement variant would duplicate the existing public SDK surface. ([docs.openclaw.ai](https://docs.openclaw.ai/plugins/hooks?utm_source=openai))

## What This Changes

Request a documented cache-stable hook result and pre-cache-boundary placement for session-stable plugin system context.

## Best Possible Solution

Use the documented `before_prompt_build` `prependSystemContext` field for session-byte-stable context, retaining dynamic recall in `prependContext` only when it must vary by turn.
