## What This Changes

This PR adds an opt-in Beam plugin that accepts authenticated, redacted local coding-session snapshots and shows them in OpenClaw’s read-only external-session catalog.

## System Context

Beam sits between a developer’s local coding-session helper and the OpenClaw Gateway. The helper uploads a bounded text snapshot; the plugin stores it in expiring plugin state and the existing session catalog exposes list/read-only views to authorized Gateway clients.
