## What This Changes

This PR adds an opt-in bundled Beam plugin that accepts authenticated, sanitized coding-session snapshots and presents them as read-only rows in OpenClaw’s external-session catalog.

## System Context

Beam is a bundled plugin at the Gateway boundary: a trusted local helper uploads a bounded transcript snapshot through authenticated HTTP, then the plugin stores it in OpenClaw plugin state. The existing session catalog reads that stored snapshot into the Control UI without granting continuation, archive, terminal, tool, node, or source-machine access.
