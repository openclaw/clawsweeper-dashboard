## Summary

Keep this issue open: current `main` still has a real mismatch between the curated static Ollama Cloud MiniMax entry and live discovery, but the repository does not establish whether static suggestions must track the newest hosted model or intentionally favor a stable recommendation. This needs a small provider-owner product decision rather than an automatic catalog replacement.

## What This Changes

Clarify or update the bundled static Ollama Cloud MiniMax model from `minimax-m2.7:cloud` to `minimax-m3:cloud`.

## Best Possible Solution

Define static Ollama Cloud entries as an explicitly curated fallback, add M3 as the preferred MiniMax suggestion after confirming its metadata and compatibility, and retain M2.7 as a secondary entry only while it remains supported; keep the manifest, defaults, docs, and focused discovery/fallback tests synchronized.
