## Summary

Keep open: current main still bundles `minimax-m2.7:cloud`, while Ollama now publishes M3; because the hardcoded list is an outage fallback rather than the normal live catalog, replacing its MiniMax entry requires an explicit provider-policy decision.

## What This Changes

Clarify whether the bundled Ollama Cloud MiniMax fallback should remain `minimax-m2.7:cloud` or move to `minimax-m3:cloud`, then align the provider metadata, tests, and docs.

## Best Possible Solution

Have the Ollama provider owner verify M3 through the live hosted catalog, then either atomically promote it across fallback metadata, manifest, tests, and docs or document why M2.7 remains the deliberately conservative outage fallback.
