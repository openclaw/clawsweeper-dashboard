  - body: `buildNarrativePrompt(data, language?: string)` never reads `language`, and `tsconfig.extensions.json` enables `noUnusedParameters`. Either remove the parameter or use it intentionally; otherwise the extension type lane should fail before this can merge.
  - confidence: 0.93

  - body: The phase callers pass `language` and this success path reads `params.language`, but `generateAndAppendDreamNarrative` still does not declare that param. Add the typed parameter and pass it into prompt/fallback handling instead of leaving the narrative API inconsistent.
  - confidence: 0.94

Keep one top-level contract or fully schema, document, test, and wire execution-level overrides.
