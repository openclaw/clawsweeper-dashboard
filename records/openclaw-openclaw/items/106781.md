## Summary

Keep open: this is a fresh report against v2026.6.11 of a severe recurring session-corruption failure. Current main already has broad replay pairing repair, so the remaining task is to identify the persistence or replay path bypassing those guards; without a sanitized malformed record or deterministic current-main reproduction, neither an implemented close nor an automated fix is safe.

## What This Changes

The issue reports that interrupting an Anthropic tool call can persist an unmatched tool-use block and permanently poison subsequent runs in the same session.

## Best Possible Solution

Enforce one end-to-end invariant: incomplete tool-call pairs must not be durably committed, and every persisted transcript must be validated and safely repaired before provider replay while preserving as much valid session context as possible.
