## What This Changes

Add consistent active-run elapsed-time and cumulative output-token telemetry, followed by a short completed-turn recap, across the Control UI, shared iOS/macOS chat UI, and Android chat.

## System Context

Chat clients receive agent lifecycle and usage events for a selected session and project them into visible run-progress UI. The requested behavior keeps that projection stable through streamed assistant text and tool activity, then converts it into a terminal recap until the next turn begins.

## Architecture Diagram

  B --> C[Per-run sequence reconciliation]
  C --> D[Client telemetry projection]
  D --> E[Working row during text and tools]
  E --> F[Completed-turn duration and token recap]
  F --> G[Clear recap when next turn starts]
