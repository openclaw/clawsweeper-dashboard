- `P2`: This is a real subagent lifecycle reliability issue with limited blast radius and no current proof of a crash, data-loss emergency, or unusable core runtime.
- `impact:session-state`: The reported failure is that parent/session state can say a subagent is complete while delegated work is still active.
- `impact:message-loss`: False completion can make parent agents stop monitoring and miss or prematurely report final child results.

## Summary

Keep this open: current main covers nested subagent descendant gating and active embedded-run cleanup, but child-owned background exec/process work can still outlive the child agent run without blocking subagent completion.

## What This Changes

The issue asks OpenClaw to keep subagents running until delegated user-relevant background work is actually finished.

## Best Possible Solution

Define an explicit completion-required child-work contract and make subagent/task status follow it while leaving ordinary fire-and-forget processes visible separately.

## Maintainer Decision

Kind: product_direction

Question: Should subagent completion remain tied to child agent-run terminal lifecycle, or should explicitly completion-required child work such as background exec/process sessions block completion?

Rationale: Current source intentionally separates background process follow-up from subagent liveness, so a broad fix changes runtime semantics rather than applying a small mechanical bug fix.

Likely owner: steipete

Owner confidence: medium

Options:

- **Add completion-required child-work contract (recommended):** Introduce a narrow runtime signal for child work that must block subagent completion, with timeout, cancel, cleanup, and status coverage.
- **Keep terminal-run semantics:** Leave subagent completion tied to agent-run terminal state and improve separate process/task visibility in status surfaces.
- **Block on all child processes:** Hold subagent completion while any child-owned background process remains active, accepting compatibility risk for deliberately detached jobs.

## Reproduction Assessment

No high-confidence live current-main reproduction was established, but source inspection shows the likely remaining path: background exec/process sessions can outlive the child agent run while subagent completion only gates on agent-run and descendant-subagent state.

## Solution Assessment

Unclear as an automatic fix; the best repair depends on a maintainer choosing the lifecycle contract for detached child work before implementation.
