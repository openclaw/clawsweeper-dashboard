## Summary

Keep open: current main has fixed several overlapping premature-completion paths, but the reported background exec/process case still has a credible source path where subagent completion follows the child agent run while child-owned background work is tracked separately.

## Best Possible Solution

Define the lifecycle contract explicitly, then implement one coherent path: either surface child-owned background processes as separate active work, or defer subagent finalization through an owned-process liveness seam with timeout, cancellation, cleanup, and regression coverage.
