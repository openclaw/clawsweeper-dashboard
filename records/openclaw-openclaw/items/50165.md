## Summary

Current main fixes several adjacent subagent announce races, but the central lifecycle mismatch still needs maintainer direction: a subagent can reach agent-run terminal completion while child-owned background process work remains tracked outside the subagent completion gate. Closing this as implemented would overstate the current behavior.

## What This Changes

The issue asks OpenClaw to stop reporting subagents as complete while delegated background work owned by that subagent is still running.

## Best Possible Solution

Define a single subagent completion contract that either surfaces active child-owned process work as still-running task state or explicitly excludes it from subagent completion, then align registry, process tracking, docs, and regression coverage to that contract.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should subagent completion wait for child-owned background exec/process sessions, or should those sessions be reported as separate still-running work after the subagent agent turn completes?

Rationale: Both behaviors are plausible product contracts, and current docs make agent lifecycle authoritative while the issue expects delegated work liveness to affect completion state.

Likely owner: Peter Steinberger

Owner reason: Recent subagent lifecycle and cleanup work is closest to the contract boundary that needs a product/runtime decision.

Owner confidence: medium

Options:

- **Surface background work separately (recommended):** Keep agent-run lifecycle as the terminal subagent turn but make active child-owned process sessions visible in tasks/subagents status and parent handoff so users are not told all delegated work is done.
- **Block completion on child process liveness:** Treat scoped background process sessions as part of the subagent completion gate with timeout and escape rules for intentional long-running processes.
- **Document current semantics:** Close the behavioral gap by documenting that subagent completion means the child agent turn ended, while background processes must be tracked through process/task status.

## Solution Assessment

Unclear: current main has better descendant announce gating, but the best remaining fix depends on whether OpenClaw wants subagent completion to include active child process liveness or expose that work as separate task state.
