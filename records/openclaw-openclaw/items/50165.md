## Summary

Keep this open: current main still finalizes subagent task state from the child agent-run terminal result, while child-owned background exec/process sessions remain separately tracked and can outlive that agent turn.

## What This Changes

The issue reports that subagent completion/status can appear done before delegated background work or the final user-relevant result is actually complete.

## Best Possible Solution

Define the lifecycle contract explicitly, then align subagent finalization, child-owned process visibility, docs, and regression coverage around either separate active-work surfacing or a bounded process-liveness gate.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should child-owned background exec/process sessions block subagent completion, or should they be surfaced as separate active work after the child agent turn completes?

Rationale: Both contracts are plausible: blocking avoids false completion, but detached process work is already a separate scoped registry and could intentionally outlive the child agent turn.

Likely owner: tyler6204

Owner reason: The highest-confidence history is the merged descendant-gating and announce-delivery work on the same subagent completion surface.

Owner confidence: medium

Options:

- **Surface active child processes separately (recommended):** Keep subagent completion tied to the child agent-run terminal state, but show child-owned running processes in task/session status and parent handoff so users are not told all delegated work is done.
- **Block completion on owned process liveness:** Defer subagent task success until scoped child-owned processes settle, with explicit timeout, cancel, cleanup, and detached-work escape rules.
- **Document current semantics:** Treat subagent completion as the child agent turn ending and document that background exec work must be tracked through process/task status.

## Solution Assessment

Unclear until maintainers choose the contract; current main fixes several descendant announce and wake races, but not whether child-owned process liveness is part of subagent completion.
