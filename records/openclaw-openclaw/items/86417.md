## Summary

Keep open: current main and v2026.6.11 still scope `OPENCLAW_NO_AUTO_UPDATE` to configured startup/background auto-update applies, while supervised `update.run` can still create a managed launchd handoff and schedule an `update.run` restart.

## What This Changes

The issue asks OpenClaw to document and optionally make `OPENCLAW_NO_AUTO_UPDATE=1` suppress supervised macOS Gateway `update.run` handoff restarts.

## Best Possible Solution

Make the kill-switch contract explicit: either preserve it as a background-auto-update-only guard and route launchd reliability to the broader `update.run` tracker, or add a maintainer-approved `update.run` guard with docs, tests, and live macOS proof.
