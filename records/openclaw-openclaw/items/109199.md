## Summary

Keep this PR open, but do not merge it yet: the direct Podman/Docker timeout is sound, while the same `SIGKILL` only terminates the supported `sudo` wrapper and cannot be relayed to its Podman child, so that probe may continue running and can keep the synchronous call blocked. ([man7.org](https://man7.org/linux/man-pages/man8/sudo.8.html?utm_source=openai))

## What This Changes

The PR adds a 10-second `SIGKILL` timeout to Docker, Podman, and sudo-wrapped Podman inspection probes and updates their call-shape assertions.

## Best Possible Solution

Use a process-tree-aware timeout for the sudo-wrapped inspection path, verify that the underlying Podman process is gone after expiry, and keep the selected container command itself unrestricted.
