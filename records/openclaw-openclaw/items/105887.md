## What This Changes

The PR forwards DeepInfra video-generation requests through the configured provider request policy and adds tests for custom headers, proxy routing, private-network access, and fail-closed defaults.

## System Context

DeepInfra’s video provider builds a submission request from provider configuration and passes it to the plugin SDK’s shared HTTP layer. That layer resolves headers, proxy dispatching, and SSRF/private-network policy before it sends the request and returns the generated video result.
