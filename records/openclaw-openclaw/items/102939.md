The PR relaxes `parseMediaContentLength` to accept comma-separated repeated numeric Content-Length members only when all parsed values match, and adds parser plus media fetch regression tests.

## Best Possible Solution

Merge the shared media-core parser change after normal maintainer review and exact-head merge gates, keeping Content-Length policy centralized in media-core.
