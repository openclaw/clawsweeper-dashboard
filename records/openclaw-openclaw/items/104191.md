## Summary

Keep this PR open, but it is not merge-ready: the dedicated hook is a sound API direction, while two exact-head lifecycle defects can lose the startup baseline or indefinitely block later reconciliation events. The protected `maintainer` label also requires explicit maintainer handling.

## What This Changes

The PR adds a typed `cron_reconciled` plugin hook after Gateway cron startup and reload reconciliation, with lifecycle guards, SDK exports, tests, and documentation.

## Best Possible Solution

Preserve the focused `cron_reconciled` API, but make startup delivery wait for the applicable plugin runner to be ready and apply a bounded fail-open timeout so later reconciliations always make progress.
