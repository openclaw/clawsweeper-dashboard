Keep open: current main and the latest release still consume the paragraph separator in the shared block-streaming path, and two open closing PRs need maintainer consolidation and a boundary-contract choice before this can close.

## What This Changes

The issue reports that block-streamed replies can lose blank-line paragraph separators when multiple streamed deliveries are reconstructed.

## Best Possible Solution

Land one consolidated shared chunker/subscriber/coalescer fix that preserves paragraph boundaries across ordinary and maxChars split cases without doubled separators, then close this issue after the fix merges.
