Keep open: current main and v2026.6.11 still consume the paragraph separator in the shared block chunker, while https://github.com/openclaw/openclaw/pull/94216 and https://github.com/openclaw/openclaw/pull/94247 are open candidate fixes rather than merged implementation.

## What This Changes

The issue reports that block-streaming paragraph boundaries can be lost when multi-paragraph Markdown is split across streamed deliveries.

## Best Possible Solution

Preserve paragraph boundary semantics in the shared chunker/coalescer path, with regression coverage proving concatenated streamed chunks reconstruct Markdown and separator-carrying chunks do not double blank lines when coalesced.
