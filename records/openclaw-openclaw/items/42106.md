## Summary

Keep open: current main and the latest release still consume paragraph separators in the shared block-streaming path, and two open candidate PRs already target the fix pending a maintainer boundary-contract choice.

## What This Changes

Preserve Markdown paragraph separators across block-streamed deliveries so visible replies reconstruct without collapsing paragraphs.

## Best Possible Solution

Land one consolidated shared chunker/coalescer/subscriber fix that preserves paragraph boundaries for ordinary and maxChars-adjacent splits without doubled separators, backed by focused regression coverage and delivered-behavior proof.
