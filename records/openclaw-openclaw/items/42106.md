Keep open: current main and the latest release still consume paragraph separators in shared block streaming, and two open closing PRs are candidate fixes awaiting a maintainer boundary-semantics decision.

## What This Changes

The issue reports that shared block streaming can drop blank-line paragraph separators when streamed block deliveries are reconstructed as visible text.

## Best Possible Solution

Land one consolidated shared chunker/subscriber/coalescer fix that preserves paragraph boundaries for ordinary and near-maxChars splits without doubled separators, backed by regression coverage and delivered-behavior proof.
