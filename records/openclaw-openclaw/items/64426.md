## Summary

Keep open: current main and the latest release still only warn on repeated first-class `read` calls when opt-in tool-loop detection is enabled, and there is no read-specific same-turn reread nudge by default. This remains a product/runtime policy decision, not a cleanup close.

## What This Changes

Request to add a warning-only same-turn guard for repeated first-class `read` tool rereads that burn tokens and stall turns.

## Best Possible Solution

Extend the existing before-tool-call loop detector with a read-aware warning policy after maintainer approval, then cover default or opt-in behavior with focused tests, docs, and a live replay proof.
