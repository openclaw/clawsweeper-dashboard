## Summary

The revised head resolves the earlier heading requirement and preserves an approval path for complete replacements, but it still treats any nonzero body-line overlap as safe for automatic apply, so a plan document that copies one existing instruction can still overwrite the skill. The supplied evidence remains focused-test output rather than a real Skill Workshop run.

## What This Changes

The PR adds apply-time Skill Workshop content validation, conditional approval for zero-overlap updates, bounded line-change summaries in approval/apply output, regression tests, and rollback troubleshooting documentation.

## Best Possible Solution

Keep validation at the central apply boundary, but classify low-retention or plan-shaped updates as replacement-risk even when they share an incidental line, require an owner-confirmed explicit approval for those cases, and prove both rejection/no-write and valid apply/summary behavior in a real redacted run.
