## Summary

Keep open: current main and v2026.6.11 still derive the Mattermost interaction signing secret from the bot token with a public HMAC key, and the linked same-repository fix remains open for maintainer/security direction.

## What This Changes

The issue reports that Mattermost button callback `_token` values can be forged by anyone who knows the bot token because the signing secret is deterministically derived with a public HMAC key.

## Best Possible Solution

Land a refreshed version of https://github.com/openclaw/openclaw/pull/64546, or a narrow replacement, that removes bot-token-derived Mattermost interaction signing and proves the replacement secret is durable, documented, setup-visible, and safe across restart or split sender/verifier paths.
