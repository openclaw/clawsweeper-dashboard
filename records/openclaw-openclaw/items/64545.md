## Summary

Keep open: current main and the latest release still derive the Mattermost interaction signing secret from the bot token using a public HMAC key, and the same-repository candidate fix remains open, conflicting, and security/product-sensitive.

## What This Changes

The issue requests replacing Mattermost interaction token signing derived from the bot token with a non-forgeable per-account secret.

## Best Possible Solution

Land a refreshed security fix, or a narrow replacement, that removes bot-token-derived Mattermost interaction signing and makes the replacement secret durable or explicitly fail-closed through supported setup, SecretRef or doctor coverage, docs, tests, and restart or split-process proof.
