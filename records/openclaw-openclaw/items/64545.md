- `P1`: The issue reports a security-sensitive Mattermost callback signing weakness that can affect interaction authorization, but exploitation still depends on bot-token access and a valid interaction context.

## Summary

Keep open: current main and latest release v2026.6.11 still derive the Mattermost interaction signing secret from the bot token with a public HMAC key, and the linked same-repository fix PR remains open and conflicting with unresolved security/upgrade decisions.

## What This Changes

The issue asks OpenClaw to stop deriving Mattermost button interaction tokens from a bot-token-rooted public HMAC key and use a non-forgeable per-account interaction secret instead.

## Best Possible Solution

Land a refreshed linked PR or narrow replacement that removes bot-token-derived Mattermost interaction signing and provisions a durable per-account secret through supported setup, SecretRef or doctor flows, docs, tests, and restart/split-process proof.
