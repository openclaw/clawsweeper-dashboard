## What This Changes

This PR lets users link and configure a Signal account through OpenClaw chat clients by adding QR-code setup prompts, Signal transport validation and recovery, and cancellation-safe hosted setup sessions.

## System Context

The system-agent chat flow turns client messages into hosted setup prompts through the Gateway, then invokes channel-owned setup logic. This change lets the Signal plugin return a QR prompt and validated account transport back through that flow so desktop, mobile, and Control UI clients can guide account linking without a separate terminal wizard.
