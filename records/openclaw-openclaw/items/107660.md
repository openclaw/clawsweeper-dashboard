## What This Changes

This PR adds a read-scoped Gateway `skills.changed` event and makes the macOS Skills pane subscribe to it so it refetches `skills.status` after remote-node eligibility or skill-source changes.

## System Context

Remote Mac nodes contribute executable and command-surface facts to the Gateway’s skills eligibility snapshot. The Gateway broadcasts an invalidation event after that snapshot changes, and an open macOS Skills pane uses it to refresh the displayed availability state.
