  - body: This handler imports `mkdirPathWithinRoot` and `removePathWithinRoot`, which current `src/infra/fs-safe.ts` no longer exports. A current-main rebase would fail to typecheck unless the workspace handler moves to the supported root API or adds an intentional shared helper.
  - confidence: 0.91
- **[P1] Bound recursive workspace listings:** `src/gateway/server-methods/agents-workspace.ts:143-145`
  - body: When `recursive` is true, this read-scoped RPC recurses through every directory and appends all entries without a depth, entry-count, or response-size limit. A large workspace can make a single list request consume Gateway CPU, memory, and bandwidth, so the API needs pagination or a hard traversal budget before merge.
  - confidence: 0.88
