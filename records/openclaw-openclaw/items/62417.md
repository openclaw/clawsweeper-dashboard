- **[P1] Register workspace methods through core descriptors:** `src/gateway/server-methods.ts:8`
  - body: The branch wires the new handlers by importing them into the old eager `server-methods.ts` aggregator, but current main builds the Gateway method table from `CORE_GATEWAY_METHOD_SPECS` plus lazy handler families.   - confidence: 0.92

  - body: The new public schemas are added under `src/gateway/protocol`, but current main uses `packages/gateway-protocol` as the canonical source for validators, generated types, and clients.   - confidence: 0.9
- **[P1] Use supported fs-safe root APIs:** `src/gateway/server-methods/agents-workspace.ts:5-8`
  - body: This handler imports `mkdirPathWithinRoot` and `removePathWithinRoot`, which current `src/infra/fs-safe.ts` no longer exports. A current-main rebase will fail to typecheck unless the workspace handler moves to the supported `root()` API or adds an intentional shared helper.
  - confidence: 0.91
- **[P1] Bound recursive workspace listings:** `src/gateway/server-methods/agents-workspace.ts:143-145`
  - body: When `recursive` is true, this read-scoped RPC recurses through every directory and appends all entries without a depth, entry-count, or response-size limit. A large workspace can make a single list request consume Gateway CPU, memory, and bandwidth, so the API needs pagination or a hard traversal budget before merge.
  - confidence: 0.88
