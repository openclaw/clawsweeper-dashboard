  - body: This branch wires the new handlers into the old eager `server-methods.ts` aggregator, but current main builds core Gateway methods from `CORE_GATEWAY_METHOD_SPECS` plus lazy handler families.   - confidence: 0.92

  - body: The PR adds public schemas under `src/gateway/protocol`, but current main's canonical protocol source is `packages/gateway-protocol`. Keeping this stale path would create a parallel protocol surface that generated clients and current Gateway imports do not use.
  - confidence: 0.9
- **[P1] Use current fs-safe root APIs:** `src/gateway/server-methods/agents-workspace.ts:5-8`
  - body: This handler imports `mkdirPathWithinRoot` and `removePathWithinRoot`, which current `src/infra/fs-safe.ts` no longer exports. The workspace handler needs to use the supported root API or add an intentional shared helper before it can typecheck against current main.
  - confidence: 0.91
- **[P1] Bound recursive workspace listings:** `src/gateway/server-methods/agents-workspace.ts:143-145`
  - body: When `recursive` is true, this read-scoped RPC descends into every directory and accumulates every entry without a depth, entry-count, or response-size budget. A large workspace can make one list request consume excessive Gateway CPU, memory, and bandwidth, so the API needs pagination or a hard traversal limit before merge.
  - confidence: 0.88
