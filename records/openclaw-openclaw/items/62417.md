  - body: This import and the companion schema changes still target the old `src/gateway/protocol` layout.   - confidence: 0.9
- **[P1] Bound recursive workspace listings:** `src/gateway/server-methods/agents-workspace.ts:143-145`
  - body: When `recursive` is true, this walks every subdirectory and accumulates one response array without max depth, max entries, byte budget, pagination, or cancellation. A large workspace can force the Gateway to spend unbounded CPU/memory and serialize an oversized response from a read-scoped call.
  - confidence: 0.88
- **[P1] Use root-bounded helpers for destructive mutations:** `src/gateway/server-methods/agents-workspace.ts:343`
  - body: The move path validates with `realpath` and then performs raw `fs.mkdir`/`fs.rename`, so the actual parent-directory mutation is no longer owned by the fs-safe root helper that OpenClaw uses for untrusted paths. This new Gateway RPC surface should route mkdir/move/delete through supported root-bounded helpers or an equivalent reviewed primitive before merge.
  - confidence: 0.82
