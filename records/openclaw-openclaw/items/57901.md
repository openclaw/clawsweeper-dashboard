## Summary

## What This Changes

The issue requests that safeguard compaction honor `agents.defaults.compaction.model` instead of always using the active session model.

## Best Possible Solution

## Reproduction Assessment

Yes, source-level: current main registers the active session model into safeguard runtime and then the hook prefers `ctx.model`, while the docs define `agents.defaults.compaction.model` as an exact compaction model override. I did not run a live provider compaction session.
