## Summary

Keep open: current main and the latest v2026.6.11 release still register safeguard runtime with the active session model and the hook still prefers `ctx.model`, while the open linked PR remains the candidate fix for the documented compaction override bug.

## What This Changes

The issue reports that safeguard compaction ignores `agents.defaults.compaction.model` and uses the active session model instead.

## Best Possible Solution

Keep this issue as the canonical tracker until https://github.com/openclaw/openclaw/pull/73704, or an equivalent focused safeguard runtime fix, is reviewed and merged while preserving the shared compaction resolver behavior.

## Reproduction Assessment

Yes. At source level, current main and v2026.6.11 still register the active session model into safeguard runtime and the hook prefers `ctx.model`, so a configured compaction model can be ignored; I did not run a live provider compaction session.

## Solution Assessment

Yes in direction. The best fix is to resolve the safeguard runtime target through the shared compaction resolver and then prefer `runtime.model`; the open linked PR implements that shape but still needs maintainer review and merge.
