## Best Possible Solution

Keep this issue as the canonical tracker until https://github.com/openclaw/openclaw/pull/73704, or an equivalent focused fix, makes safeguard registration resolve the same compaction target as explicit compaction and preserves the intended runtime-model precedence.

Yes in direction. The maintainable fix is to reuse the existing compaction target resolver for safeguard runtime registration and make the hook prefer the resolved runtime model, which is the path proposed by the open linked PR.
