## Summary

Keep open: current main and v2026.6.11 still register safeguard compaction with the active session model and the hook still prefers `ctx.model`, while https://github.com/openclaw/openclaw/pull/73704 is the open candidate fix for this issue.

## What This Changes

The issue requests that safeguard compaction honor `agents.defaults.compaction.model` instead of using the active session model.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/73704 or an equivalent focused fix that resolves the safeguard runtime target through the shared compaction resolver, prefers the runtime compaction model, and preserves no-override fallback plus provider/auth handling.

Yes, the linked PR’s shared-resolver approach is the right fix shape; the earlier one-line precedence swap was too narrow because runtime registration also needs the configured compaction target.
