## Summary

Keep this PR open for maintainer direction: it fixes the sole-survivor case and has credible live Chrome/CDP evidence, but its remaining route-level heuristics can still adopt a target that did not execute the operation. The open canonical report describes a backend-owned target-outcome design that resolves this across managed Playwright, relay, and Chrome MCP paths.

## What This Changes

The branch removes sole-tab fallback adoption, snapshots pre-action browser target IDs for `/act`, selects a unique newly observed target or navigated-URL match as a replacement, adds regression tests, and adds a Chrome/CDP proof harness.

## Best Possible Solution

Make each backend return the exact target outcome of the operation, keep stable relay-owned handles where required, and delete route-level replacement discovery once managed Playwright, extension relay, and Chrome MCP expose that contract.
