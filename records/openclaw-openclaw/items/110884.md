## Summary

The patch correctly removes unsafe route-level adoption of unrelated tabs, but it still falls back to the pre-action raw target when an extension-relay page detaches during a renderer swap. That regresses the established relay continuation behavior, so this PR needs a relay-owned continuity outcome and real relay proof before merge.

## What This Changes

The PR replaces post-navigation/action tab-list heuristics with backend-reported target IDs across Playwright, extension-relay, and Chrome MCP browser routes.

## Best Possible Solution

Keep the no-inference route rule, but make the relay backend own a stable public tab handle or an equally authoritative reconnect-safe target outcome, then prove a real extension-relay renderer swap followed by a successful snapshot and action on the same shared tab.
