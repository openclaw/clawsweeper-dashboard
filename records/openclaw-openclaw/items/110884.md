## Summary

Keep this PR open, but do not merge it as the durable fix: it removes the unsafe sole-tab fallback and has credible focused Chrome/CDP proof, yet its replacement selection still relies on route-level inference rather than the backend-owned target outcome required to prevent wrong-tab routing across browser backends.

## What This Changes

The branch removes sole-tab fallback adoption, snapshots pre-action target IDs for `/act`, chooses a unique newly observed or navigated-URL target as a replacement, adds regression tests, and includes a Chrome/CDP proof harness.

## Best Possible Solution

Move target continuity ownership into each browser backend: return the exact acted-on target or an explicit closed/stale outcome, retain relay-stable identity for extension paths, and remove shared route-level replacement discovery.
