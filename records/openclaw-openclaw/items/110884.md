## Summary

Keep this PR open. The removal of route-level target inference is directionally correct, but the new relay target IDs can revive after a relay restart and the changed production extension-relay path still lacks live paired-extension proof.

## What This Changes

The branch replaces post-action tab-list inference with backend-provided target outcomes and changes extension-relay CDP target IDs to opaque relay-owned handles.

## Best Possible Solution

Use an instance-scoped opaque relay handle such as `openclaw-relay-<nonce>-<ordinal>`, preserve it only for one tab binding, add restart/reconnect regression coverage, and provide a redacted live paired-extension transcript before merge.
