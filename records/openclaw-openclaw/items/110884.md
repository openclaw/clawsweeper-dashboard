## Summary

Keep this PR open, but do not merge the current heuristic: it removes the sole-tab guess yet still treats either a newly observed target or a uniquely URL-matching target as the operation’s identity. The linked canonical bug remains open, and the permanent ownership boundary needs maintainer direction before a safe repair can land.

## What This Changes

The branch removes sole-tab fallback adoption, snapshots pre-action target IDs for `/act`, adds heuristic replacement selection to the shared resolver, and adds regression plus live-CDP proof coverage.

## Best Possible Solution

Make each browser backend return an operation-owned target outcome, preserve stable relay/MCP handles at their owners, and delete route-level replacement discovery rather than refining tab-count or URL heuristics.
