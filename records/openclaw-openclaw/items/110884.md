## Summary

Keep this PR open for a maintainer architecture decision: at the unchanged reviewed head, it still replaces one unsafe target-selection guess with two narrower but unproven continuity guesses. The live CDP transcript is useful after-fix evidence for the resolver, but it does not establish backend-owned identity across managed Playwright, relay, and MCP paths.

## What This Changes

The branch removes sole-tab fallback adoption, snapshots pre-action tab ids for `/act`, adds heuristic replacement selection to the shared resolver, updates regression tests, and adds a real-Chrome/CDP resolver proof harness.

## Best Possible Solution

Adopt a backend-owned target-outcome contract: each managed Playwright, extension-relay, and Chrome MCP operation should return its exact operated target or explicit closed/stale outcome, while routes only serialize that outcome and never discover identity from tab lists, URL equality, or cardinality.
