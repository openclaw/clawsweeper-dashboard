## Summary

Keep this PR open: it removes the unsafe sole-tab and URL inference, but it still replaces extension-relay renderer-swap continuity with a stale raw target when the original Playwright Page has detached. The supplied live Chrome proof is useful for managed Playwright, yet it does not demonstrate the changed extension-relay or Chrome MCP public routes after a target replacement.

## What This Changes

The PR removes route-level post-action target-list heuristics, returns target outcomes from Playwright and Chrome MCP operations, and adds focused tests plus a live Chrome/CDP harness.

## Best Possible Solution

Keep the no-guessing rule, but make extension relay own a stable public tab handle across renderer detach/reattach and prove `/navigate` and `/act` against a real shared relay tab; retain Chrome MCP’s pinned-handle behavior only when its backend can authoritatively confirm that handle.
