## Summary

Keep open, but the patch is not correct as-is. Current main still has the reported skipped/disabled cron path, yet this PR masks disabled heartbeat failures as ok, can still fail to wake the main session, and regresses the disabled one-shot retry behavior preserved by https://github.com/openclaw/openclaw/pull/92225 and explicitly rejected in the earlier patch shape at https://github.com/openclaw/openclaw/pull/91794.

## What This Changes

The PR changes main-session cron wake handling to keep an enqueued system event and return ok whenever the immediate heartbeat is skipped or errors, and rewrites disabled-heartbeat one-shot tests around that behavior.

## Best Possible Solution

Fix the disabled cron wake at the heartbeat owner boundary, or scope any cron-layer fallback to recurring jobs, while preserving disabled one-shot retry cleanup and requiring real cron-run proof before merge.
