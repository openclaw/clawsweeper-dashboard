## What This Changes

The PR uses `fs.readSync`’s returned byte count when slicing and scanning qqbot log-tail buffers and adds a test API export barrel.

## Best Possible Solution

Fill each selected backward-read window using bounded positional retries, handle a zero-byte read without spinning, and verify that the exact newest tail bytes and newline count survive a forced partial read.
