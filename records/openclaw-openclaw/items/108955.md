## What This Changes

The PR changes QQBot log-tail reading to use the byte count returned by `fs.readSync` and exports the private helper through a testing object.

## Best Possible Solution

Keep the helper internal, retry positional reads until the requested region is filled or no progress is possible, and add a deterministic test that forces partial `readSync` returns while verifying exact byte and line preservation.
