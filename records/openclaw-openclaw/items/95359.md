## What This Changes

The PR adds a shared ClawHub owner-match guard for install/update/verify, blocks different-owner forced installs before download or replacement, adds lifecycle regressions, and updates the skills CLI reference.

## Best Possible Solution

Merge the shared owner guard after a ClawHub owner accepts the fail-closed compatibility change, preserving the documented ownerless fallback and the branch-complete lifecycle coverage.
