## Summary

## What This Changes

This PR adds a shared ClawHub owner-match guard for install, update, and verify, adds lifecycle regression tests for owner mismatch and ownerless cases, and documents the narrowed `install --force` contract.

## Best Possible Solution

Merge the shared owner guard after maintainer acceptance of the fail-closed compatibility behavior, preserving the documented ownerless fallback and branch-complete lifecycle tests.
