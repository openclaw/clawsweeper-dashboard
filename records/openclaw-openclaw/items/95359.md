## Reproduction Assessment

Yes. Current main lacks an install-side owner comparison before forced ClawHub install reaches the replace path, and the PR includes before/after CLI and runtime output showing the clobber on main and refusal after the patch.

## Solution Assessment

Yes. The lifecycle-layer guard is the best narrow fix because it covers CLI and gateway callers, while a CLI-only guard would miss other install entry points and an unconditional ownerless refusal would regress the preserved legacy fallback.
