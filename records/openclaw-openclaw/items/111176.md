## Summary

Keep this PR open: the prior P1 remains because a synchronous `spawnSync` timeout only requests termination and still waits for the child to exit, so it does not establish the claimed hard liveness bound for a filesystem-stalled `find` process.

## What This Changes

The branch adds a five-second `SIGKILL` timeout, typed timeout propagation, and delayed-`find` regression coverage for the channel-document test helper.

## Best Possible Solution

Replace the synchronous probe with a maintainer-approved isolation design whose parent process can stop waiting at the deadline, with explicit child cleanup and test-runner resource semantics.

- **Remove the fallback path:** Avoid filesystem enumeration when `git ls-files` is unavailable if preserving an alternate checkout mode is not required.
