## Summary

This PR improves the cooperative-child case, but its synchronous timeout does not solve the stated stalled-filesystem hang: Node keeps `spawnSync` blocked until the child has exited even after sending `SIGKILL`. Keep it open for a design that can actually release the test runner.

## What This Changes

The PR adds a five-second `SIGKILL` timeout to the channel-doc test helper’s `find` fallback, maps timeouts to a dedicated error, and adds regression coverage using a delayed fake `find`.

## Best Possible Solution

Replace the synchronous fallback with an execution design whose deadline can return control to the test runner without waiting for the blocked child, and document or test the cleanup/liveness behavior explicitly.
