## Summary

No blocking findings. This focused bug fix remains necessary: the documented 16 MiB byte contract is not satisfied for multibyte JSONC on the reviewed base/current path, and the merged adjacent OC Path work explicitly leaves this JSONC boundary separate.

## What This Changes

Measures JSONC limits in UTF-8 bytes before parsing and propagates oversized-input diagnostics through every OC Path CLI verb that loads JSON or JSONC.

## Best Possible Solution

Keep the byte limit in the shared JSONC adapter before tree allocation, preserve the existing diagnostic code, and ensure every file-loading CLI verb consistently returns the documented structured parse error.

## Solution Assessment
