## Summary

Keep open. Current main still treats configured provider headers as literal strings, Fireworks does not supply generic session-affinity templating, and related open PRs only cover narrower provider-specific or static-header paths.

## What This Changes

Request dynamic placeholder interpolation in custom provider headers so values such as session, agent, or run identifiers can be sent per request.

## Best Possible Solution

Define one narrow, documented provider-request metadata contract that preserves static headers, SecretRef/auth handling, retries, and attribution headers while expanding only approved runtime placeholders.
