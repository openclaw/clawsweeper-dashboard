## Summary

Keep open. Current main and v2026.6.11 still treat configured provider headers as literal strings, while the related open PRs cover narrower session-affinity, compat-schema, or static-header paths rather than this issue's generic runtime placeholder contract.

## What This Changes

Request dynamic interpolation of session, agent, and run metadata in custom LLM provider header configuration.

## Best Possible Solution

Define one narrow, documented provider-request metadata contract that preserves static headers, SecretRef/auth handling, retries, attribution headers, and provider-owned stream hooks while expanding only approved runtime placeholders.
