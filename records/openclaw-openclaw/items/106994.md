## Summary

Keep open: the head is unchanged from the prior review at `8c6a26f1a2b4cba4c06c3e4eb6468f493e8b605c`, so four P1 upgrade-safety defects remain, and the live proof covers an earlier candidate rather than the materially changed final head.

## What This Changes

The PR makes staged global updates validate the candidate package’s Node engine, lifecycle contract, completion guard, and package-manager policy before replacing the existing installation.

## Best Possible Solution

Keep the candidate-owned preinstall safeguard, but align validation with the actual packed lifecycle, accept verified shipped guardless targets, defer user-state migration until after activation, validate the Node selected by the installed shim, and then prove both unsupported-runtime preservation and supported-runtime activation using an exact-head package.
