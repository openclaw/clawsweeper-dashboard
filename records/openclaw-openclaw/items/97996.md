## Summary

Keep open. Current main still has the OAuth-only gateway auth-status rollup that can misreport token/setup-token auth, and the linked fix is an open unmerged PR, so this issue should remain open until that PR lands or is replaced.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/98105, or replace it with the same gateway status-boundary fix, so token/setup-token profiles selected by auth ordering are reflected without weakening explicit exclusions.
