Keep open. Current main still has a source-backed token-only `claude-cli` status mismatch, and https://github.com/openclaw/openclaw/pull/98105 is the open closing fix candidate rather than a merged implementation.

## What This Changes

Treat healthy `claude-cli` token/setup-token auth profiles as effective for model-auth status so the UI stops showing a false expired-auth warning.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/98105; the desired end state is an OAuth-first status rollup that counts selected setup-token credentials when no effective OAuth profile exists, with regression coverage.
