## Summary

The PR is also assigned to `steipete`, so it requires maintainer handling rather than cleanup closure.

## What This Changes

The PR changes Gmail webhook setup to skip Python interpreters below 3.10 when selecting the interpreter passed to gcloud, and adds a regression test for a PATH where Python 3.9 precedes Python 3.10.

## System Context

Gmail webhook setup invokes the Google Cloud CLI and chooses a Python interpreter from the process PATH for that CLI. The selected interpreter becomes `CLOUDSDK_PYTHON`, so an incompatible choice prevents the gcloud command from starting and blocks Gmail setup.
