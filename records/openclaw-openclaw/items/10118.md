## Summary

Keep open: current main and the latest release have dependency-backed Shift+Enter newline support in the TUI editor, but OpenClaw still does not document the shortcut in the TUI guide or `/help`, and configurable send/newline behavior remains a maintainer-owned product/config decision.

## What This Changes

The issue requests multiline TUI composition with Enter kept as send and Shift+Enter or configurable keybindings inserting newlines.

## Best Possible Solution

Document the current pi-tui Shift+Enter, Ctrl+J, and backslash-enter behavior in TUI docs and `/help`, then add a configurable TUI keybinding bridge only if maintainers approve that public surface.
