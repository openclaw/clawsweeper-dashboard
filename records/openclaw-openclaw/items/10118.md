## Summary

Keep open: current main already gets Shift+Enter/Ctrl+J/backslash newline behavior through the pi-tui editor, but OpenClaw still does not document that path in TUI docs or `/help`, and a configurable send/newline keybinding remains a product/config-surface decision.

## What This Changes

The issue asks OpenClaw TUI to support multiline composition with Shift+Enter or related shortcuts while keeping Enter as send, with possible configurable keybindings.

## Best Possible Solution

Document the current Shift+Enter/Ctrl+J/backslash multiline behavior in TUI docs and `/help`, then add configurable send/newline keybindings only if maintainers choose the public config or CLI surface.
