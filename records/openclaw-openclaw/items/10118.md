## Best Possible Solution

Keep the dependency-backed Enter-to-send and multiline editor behavior, document Shift+Enter/Ctrl+J/backslash-enter fallback in TUI docs and `/help`, and add a configurable keybinding surface only after maintainers choose the public contract.
