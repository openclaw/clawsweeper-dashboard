Keep open: current main already gets TUI newline composition through pi-tui, but OpenClaw still does not document the shortcut in TUI docs or `/help`, and configurable send/newline keybindings remain a product/config-surface decision.

## Best Possible Solution

Document the current Shift+Enter, Ctrl+J, and backslash multiline behavior in TUI docs and `/help`, then add configurable send/newline keybindings only if maintainers approve the public config or CLI surface.
