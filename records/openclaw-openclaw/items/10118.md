## Summary

Current main already supports multiline TUI composition through the pinned editor, but this issue remains necessary because visible TUI help and public docs omit the supported newline keys, and configurable submit-key behavior remains an unresolved product choice. The closed implementation PR did not merge, and no viable open PR owns the remaining work.

## What This Changes

Document and expose multiline TUI composition with Enter-to-send and Shift+Enter newline, with an optional configurable submit-key preference.

## Best Possible Solution

Add accurate newline shortcuts and terminal fallback guidance to `/help` and `docs/web/tui.md`; keep Enter-to-send as the default, and add configurable submit bindings only after maintainers approve a narrow preference contract.
