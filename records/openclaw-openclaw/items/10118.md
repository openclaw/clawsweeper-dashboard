## Summary

Keep open: current main and the latest release have dependency-backed TUI newline insertion, but OpenClaw still does not document it in TUI docs or `/help`, and configurable TUI send/newline keybindings remain a maintainer product choice.

## What This Changes

The issue asks the TUI to keep Enter-to-send while supporting in-buffer multiline composition with Shift+Enter, documentation/help, and optionally configurable send/newline keybindings.

## Best Possible Solution

Document the existing dependency-backed newline shortcuts and fallback in TUI docs and `/help`, then add configurable TUI keybindings only if maintainers approve a public TUI config or CLI contract.
