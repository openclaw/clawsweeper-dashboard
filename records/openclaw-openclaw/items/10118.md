## Summary

Current main and the latest release already provide multiline TUI composition, but this issue remains necessary because the supported keys are still undiscoverable and the requested configurable send-key behavior remains an unresolved product choice.

## What This Changes

Document TUI multiline composition and consider a configurable preference for choosing newline and submit keybindings while preserving Enter-to-send by default.

## Best Possible Solution

Document the shipped Shift+Enter, Ctrl+J, and backslash-Enter behavior in TUI help and public docs; add configurable submit keys only if maintainers explicitly sponsor that public contract.
