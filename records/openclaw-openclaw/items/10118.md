## Summary

Keep open: current main already gets basic inline newline insertion from the pinned pi-tui editor, but OpenClaw still does not document the TUI newline keys in docs or `/help`, and configurable TUI send/newline keybindings remain a maintainer product/config decision.

## What This Changes

Request TUI multiline composition with Enter-to-send, Shift+Enter newline support, optional configurable send keybindings, and docs/help hints.

## Best Possible Solution

Document the existing TUI multiline keys and fallbacks now, then let maintainers decide whether a TUI send/newline preference should exist and where it should live.
