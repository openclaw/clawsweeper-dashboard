## Summary

Keep open: current main partially solves multiline composition through the pinned `pi-tui` editor defaults, but OpenClaw still does not expose or document the behavior in TUI docs or `/help`, and configurable send/newline keybindings remain a product/config decision.

## What This Changes

Request that `openclaw tui` keep Enter-to-send while supporting multiline composition with Shift+Enter or configurable send/newline keybindings, plus docs/help hints.

## Best Possible Solution

Document the current `pi-tui` newline behavior and terminal caveats in the TUI guide and `/help`, then make a maintainer-approved call on whether to bridge configurable send/newline keybindings into OpenClaw config or CLI.
