## Summary

Keep open: current main and the latest release already have dependency-backed multiline entry for the TUI, but OpenClaw still lacks user-facing TUI docs/help coverage and any configurable send/newline keybinding surface; the config part needs maintainer product direction.

## What This Changes

The issue requests TUI multiline composition support where Enter keeps sending by default and Shift+Enter inserts a newline, with optional configurable send/newline keybindings and visible help/docs.

## Best Possible Solution

Document the existing dependency-backed multiline behavior and terminal fallback, then have maintainers decide whether to expose a narrow TUI keybinding preference instead of adding a broad config surface by default.
