## Summary

Keep open: current main has dependency-backed Shift+Enter/Ctrl+J newline insertion in the TUI editor, but the user-facing TUI docs and /help still omit newline composition and fallback behavior, and OpenClaw still has no supported config or CLI bridge for send/newline keybinding preferences.

## What This Changes

Request TUI multiline composition with Enter-to-send, Shift+Enter newline insertion, optional configurable send/newline keybinding, and docs/help coverage.

## Best Possible Solution

Document current Shift+Enter/Ctrl+J/backslash-Enter behavior in TUI docs and /help, then add a supported TUI keybinding preference only if maintainers approve the public config or CLI surface.
