## Summary

Keep open: current main and the latest release have dependency-backed TUI newline support, but OpenClaw still does not document the shortcut in TUI docs or `/help`, and configurable send/newline behavior remains a maintainer-owned product/config decision.

## What This Changes

The issue requests TUI multiline composition with Enter kept as send, Shift+Enter or equivalent for newline, optional configurable send/newline keybindings, and docs/help coverage.

## Best Possible Solution

Document the current pi-tui Shift+Enter, Ctrl+J, and backslash-enter behavior in TUI docs and `/help`, then add a configurable TUI keybinding bridge only if maintainers approve that public surface.
