## Summary

Keep this issue open: current main already provides dependency-backed Shift+Enter and Ctrl+J newline insertion, but standalone TUI docs and `/help` do not expose it, and configurable submit/newline bindings remain an unresolved product decision.

## What This Changes

Add reliable multiline TUI composition with Enter-to-send, Shift+Enter newline, optional configurable bindings, and visible help.

## Best Possible Solution

Document Enter, Shift+Enter, Ctrl+J, and terminal limitations in the TUI guide and `/help`; if configurable bindings are approved, reuse the existing per-agent keybinding manager instead of adding a parallel `enterSends` option.
