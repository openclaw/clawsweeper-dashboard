## Summary

Keep open: current main partially satisfies inline multiline composition through the pinned pi-tui editor, but OpenClaw still does not document the newline shortcuts in TUI docs or /help and still has no maintainer-approved configurable send/newline keybinding surface.

## What This Changes

The issue requests TUI multiline composition with Enter remaining send by default and Shift+Enter or configurable keybindings for newline/send preferences.

## Best Possible Solution

Document the current pi-tui multiline shortcuts and fallback behavior in TUI docs and /help, then add a narrow TUI send/newline keybinding bridge only if maintainers approve that public surface.
