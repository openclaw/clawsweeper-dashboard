## Summary

Keep open: current main has dependency-backed TUI newline composition, but OpenClaw still does not document the shortcut in TUI docs or `/help`, and it exposes no supported configurable TUI send/newline keybinding surface.

## Best Possible Solution

Document the current Shift+Enter, Ctrl+J, and backslash-Enter behavior with terminal limitations in TUI docs and `/help`; add a supported TUI keybinding bridge only after maintainers approve the public config/API shape.
