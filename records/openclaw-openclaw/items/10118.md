## Summary

Keep this open: current main has dependency-backed multiline input, but the remaining OpenClaw-owned work is still real because docs and `/help` omit newline composition and there is no supported configurable send/newline keybinding surface.

## Best Possible Solution

Document the existing pi-tui multiline keybindings and fallback behavior in TUI docs and `/help`; add a configurable TUI keybinding bridge only after maintainers approve that product/config surface.
