## Summary

Keep open: current and shipped TUI editor behavior already has dependency-backed Shift+Enter newline support with Enter submit, but OpenClaw still lacks user-facing TUI docs/help coverage and a maintainer-approved config or CLI bridge for configurable send/newline keybindings.

## What This Changes

Request TUI multiline composition with Enter-to-send default, Shift+Enter newline, optional configurable keybinding, and docs/help hints.

## Best Possible Solution

Document the existing Shift+Enter/Ctrl+J/backslash fallback in TUI docs and /help, then add a configurable keybinding surface only if maintainers approve that config contract and its fresh-install and upgrade behavior.
