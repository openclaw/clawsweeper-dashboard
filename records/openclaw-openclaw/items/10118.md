## Summary

Keep open: current main and v2026.6.11 already have dependency-backed TUI newline insertion, but OpenClaw still lacks TUI docs/help coverage and no maintainer-approved configurable send/newline preference surface.

## What This Changes

The issue requests TUI multiline composition with Enter kept as send and Shift+Enter or a configurable keybinding inserting a newline.

## Best Possible Solution

Keep the pi-tui default newline behavior, document Shift+Enter/Ctrl+J/backslash fallback in docs and /help, and add configurable TUI send keys only after maintainers choose the public config/API shape.
