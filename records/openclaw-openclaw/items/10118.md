## Summary

Keep open: current main already gets inline TUI newline composition from pi-tui, and WebChat now has a send-shortcut setting, but the TUI still lacks docs/help coverage for the supported newline keys and has no maintainer-approved TUI send/newline preference surface.

## What This Changes

The issue requests TUI multiline composition with Enter-to-send, Shift+Enter newline, optional configurable send/newline keybindings, and TUI help/docs coverage.

## Best Possible Solution

Keep the current dependency-backed Enter-to-send default, document Shift+Enter/Ctrl+J and fallback behavior in TUI docs and /help, and add a TUI keybinding preference only after maintainers choose the public config/API shape.
