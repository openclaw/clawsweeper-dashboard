Keep open: current main has dependency-backed Shift+Enter/Ctrl+J newline support, but the TUI docs and /help still omit the behavior and OpenClaw has no supported CLI/config bridge for users who want a different send/newline keybinding.

## What This Changes

The issue requests TUI multiline composition with Shift+Enter while keeping Enter-to-send as the default, plus optional configurable send/newline keybindings and docs/help updates.

## Best Possible Solution

Document the current Shift+Enter/Ctrl+J/backslash-Enter behavior in TUI docs and /help, then add a supported TUI keybinding preference only if maintainers approve the public config or CLI surface.
