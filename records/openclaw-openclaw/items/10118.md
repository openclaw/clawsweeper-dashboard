## Summary

The issue requests TUI multiline composition via Shift+Enter while keeping Enter as send, with optional configurable send/newline keybindings and help/docs coverage.

## Best Possible Solution

Document the existing pi-tui newline keys and fallback in the TUI guide and `/help`, then add configurable TUI keybindings only if maintainers approve the public config or CLI contract.
