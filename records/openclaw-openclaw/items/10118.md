## Summary

Current main and the latest release already provide Enter-to-send with Shift+Enter/Ctrl+J newline insertion through the pinned editor, but OpenClaw still omits these bindings from TUI help/docs and exposes no configurable submit preference. A prior maintainer review explicitly retained this canonical issue for those remaining choices, and no later decision or viable PR supersedes it.

## What This Changes

Document and optionally make configurable the TUI send/newline keybindings while preserving Enter-to-send by default.

## Best Possible Solution

Document Shift+Enter, Ctrl+J, and backslash-Enter with terminal limitations in TUI help and public docs, then add configurable submit bindings only if maintainers explicitly approve a stable preference surface.
