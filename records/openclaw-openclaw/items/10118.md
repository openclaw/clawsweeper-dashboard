## What This Changes

Request TUI multiline composition where Enter still sends by default, Shift+Enter inserts a newline, optional send/newline keybinding configuration exists, and docs plus `/help` advertise the behavior.

## Best Possible Solution

Document the existing pi-tui newline keys and fallback in the TUI guide plus `/help`, then add a narrow TUI keybinding config bridge only if maintainers accept the new config contract.
