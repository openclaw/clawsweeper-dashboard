## What This Changes

## Best Possible Solution

Keep the existing pi-tui Enter-to-send and newline behavior, document Shift+Enter/Ctrl+J/backslash-Enter fallback in TUI docs and `/help`, and add a keybinding preference only after maintainers choose the public config shape.
