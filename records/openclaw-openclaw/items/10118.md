## Summary

Keep open: current main and the latest release have dependency-backed TUI newline insertion, but OpenClaw still lacks TUI docs/help coverage for the keybinding and no maintainer-approved configurable send/newline preference surface. ## What This Changes

The issue requests TUI multiline composition with Enter continuing to send by default, Shift+Enter inserting a newline, optional configurable send/newline keybindings, and help/docs coverage.

## Best Possible Solution

Document the existing pi-tui newline keys and fallback in the TUI guide and /help, then add configurable TUI keybindings only if maintainers approve the public config or CLI contract.
