## Summary

Keep open: current main already gets Shift+Enter/Ctrl+J newline insertion from pi-tui, but OpenClaw still does not document that behavior in TUI docs or `/help`, and configurable TUI send/newline keybindings remain an unresolved product/config decision.

## What This Changes

This issue requests TUI multiline composition where Enter sends, Shift+Enter inserts a newline, and docs/help plus an optional configurable send-key preference cover the behavior.

## Best Possible Solution

Document the existing pi-tui newline keys and fallback in the TUI guide and `/help`, then add configurable TUI keybindings only if maintainers approve that public config or CLI contract.
