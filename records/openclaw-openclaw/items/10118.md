## Summary

Keep open: current main and v2026.6.11 already have dependency-backed Shift+Enter newline insertion, but OpenClaw still does not document multiline composition in TUI docs or /help, and a configurable send/newline keybinding bridge remains a product/config decision.

## What This Changes

Request TUI multiline composition where Enter sends, Shift+Enter inserts a newline, optional configurable send-key behavior is supported, and help/docs explain the keybinding.

## Best Possible Solution

Keep the dependency-backed default behavior, document Shift+Enter/Ctrl+J and fallback behavior in TUI docs and /help, then let maintainers decide whether to expose configurable TUI send/newline keybindings.
