## What This Changes

Request to let `openclaw tui` compose multiline messages with Enter-to-send, Shift+Enter newline insertion, optional configurable send/newline keybindings, and docs/help updates.

## Best Possible Solution

Keep the dependency-backed pi-tui newline behavior, document Shift+Enter/Ctrl+J/backslash fallback in TUI docs and `/help`, and only expose configurable TUI send keys after maintainers approve the public config or keybindings bridge.
