## Summary

Keep open: current main has dependency-backed TUI multiline composition, but OpenClaw still does not expose or document the requested TUI send/newline keybinding policy in `/help` or the TUI docs, and configurable keybindings remain a maintainer product choice.

## What This Changes

Request multiline TUI input with Shift+Enter while keeping Enter as send, plus optional configurable send/newline keybindings and help/docs coverage.

## Best Possible Solution

Document the current multiline keybindings and fallback behavior in `docs/web/tui.md` and `/help`, then decide whether a TUI config/CLI bridge into pi-tui keybindings is worth adding.
