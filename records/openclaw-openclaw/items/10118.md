## Summary

Keep this issue open. Current main and v2026.6.11 already provide multiline composition through the pinned editor, but public TUI docs and `/help` still omit the supported newline keys, and a configurable submit-key preference remains an unresolved product decision.

## What This Changes

Document reliable multiline TUI composition while preserving Enter-to-send, with an optional configurable submit/newline key preference.

## Best Possible Solution

Document Shift+Enter, Ctrl+J, and backslash-Enter composition with terminal caveats in public docs and `/help`; add a persistent submit-shortcut preference only after maintainers define its exact scope and ownership.
