Keep open: current main has dependency-backed newline insertion in the TUI editor, but OpenClaw still does not document it in TUI docs or `/help`, and configurable send/newline keybindings remain a product/config decision.

## Best Possible Solution

Document the existing pi-tui newline shortcuts and fallback in TUI docs and `/help`, then add configurable TUI keybindings only if maintainers approve a public config or CLI contract.
