## Summary

Keep open: current main and the latest release cover the basic Shift+Enter newline path through pi-tui, but OpenClaw still lacks TUI docs/help for multiline composition and any supported configurable send/newline keybinding; the config surface choice needs maintainer product review.

## What This Changes

Request TUI multiline composition where Enter sends, Shift+Enter inserts a newline, with optional configurable send keys and docs/help hints.

## Best Possible Solution

Keep pi-tui's newline handling, document Shift+Enter, Ctrl+J, backslash-Enter, and terminal caveats in TUI docs and /help, and add configurable TUI send keys only after maintainers choose the config/API shape.
