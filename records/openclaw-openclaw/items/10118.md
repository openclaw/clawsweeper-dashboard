## Summary

Keep open: current main and v2026.6.11 already get inline newline insertion from pi-tui, but OpenClaw still does not document the TUI newline keys in docs or /help and still lacks a maintainer-approved configurable send/newline keybinding surface.

## What This Changes

Request support for multiline TUI composition with Shift+Enter while keeping Enter as send, plus docs/help coverage and possible configurable keybindings.

## Best Possible Solution

Document the existing pi-tui newline keys and fallback in the TUI guide and /help, then add configurable TUI keybindings only if maintainers approve the public config or CLI contract.
