## Summary

Keep open: current main and the latest release already have dependency-backed Shift+Enter/Ctrl+J multiline input, but OpenClaw still does not document that behavior in TUI docs or /help and still has no approved configurable send/newline keybinding surface.

## What This Changes

Requests TUI multiline composition with Enter-to-send, Shift+Enter newline, optional configurable send/newline keybinding, and docs/help coverage.

## Best Possible Solution

Document the current pi-tui multiline shortcuts and fallback behavior in TUI docs and /help, then add a narrow TUI send/newline keybinding bridge only if maintainers approve that public surface.
