## Best Possible Solution

Land the shared fetch-guard fix after maintainer/security signoff confirms proxy-owned DNS enforcement is the accepted boundary for active managed-proxy strict/default traffic.

## Solution Assessment

The remaining question is maintainer security acceptance, not an obvious better code location.
