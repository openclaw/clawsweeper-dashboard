## What This Changes

This PR changes `llm_input` and `llm_output` plugin hooks into sequential modifying hooks that can block or rewrite model input and replace assistant output.

## Best Possible Solution

Apply effective prompt and system-prompt decisions to the actual model-call state, evolve subsequent hooks from the accumulated merged result, and implement the same documented contract across every supported runner before provider execution and response delivery.
