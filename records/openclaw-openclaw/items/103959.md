## Summary

Keep open. The prior implementation findings were partly addressed, but the proposed public hook contract remains inconsistent across runtimes, contains a replacement-prompt validation defect, lacks required SDK documentation, and has no exact-head real behavior proof.

## What This Changes

This PR changes `llm_input` and `llm_output` from observational hooks into sequential modifying plugin hooks that can block or rewrite model input and replace assistant output.

## Best Possible Solution

Preserve the shipped observation hooks and design separate capability-specific interception hooks, exposing only mutations each runtime can faithfully implement through one validated effective-input/output path.
