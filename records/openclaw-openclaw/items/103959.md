## What This Changes

This PR converts the existing `llm_input` and `llm_output` plugin hooks into awaited modifiers that can block or rewrite model input and replace assistant output.

## Best Possible Solution

Preserve the observer hooks or introduce an explicitly versioned modifier contract, then apply validated results at every native request and final-delivery boundary with canonical post-hook output, public documentation, compatibility tests, and live cross-runner proof.
