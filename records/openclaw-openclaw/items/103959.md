## Summary

This PR remains relevant only if maintainers want a new LLM-interception capability, but the exact head is not mergeable: it replaces a shipped observer contract, leaves Codex and Copilot semantics inconsistent, and allows original output to bypass or survive redaction.

## What This Changes

The branch converts `llm_input` and `llm_output` from observe-only plugin hooks into awaited modifiers that can block or rewrite model input and replace assistant output.

## Best Possible Solution

Keep the observer hooks stable and add explicit modifier hooks that execute before model submission and before every delivery, persistence, diagnostic, transcript, and result-projection boundary across all supported runners.
