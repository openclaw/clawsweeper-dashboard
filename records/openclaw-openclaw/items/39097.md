## Summary

Keep open. Current main and v2026.6.11 still provide browser SSRF/private-network controls and hostname allow exceptions, but not the requested browser URL/path/domain denylist or warnlist, and this security/config surface needs maintainer policy direction before implementation.

## Best Possible Solution

Define one maintainer-approved browser navigation policy contract, then implement schema, guard integration, docs, and regression tests for host/path matching, redirects, proxy behavior, and warn-versus-block semantics.
