The issue requests a browser URL/domain denylist and optional warnlist so browser navigation can fail early with a clear message for known blocked sites.

## Best Possible Solution

Define a maintainer-approved browser navigation policy contract first, then implement schema, guard integration, docs, and regression coverage for block-versus-warn semantics across navigation paths.
