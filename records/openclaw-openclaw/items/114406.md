The revised placement addresses the earlier filtering defect by recording activity before hidden reasoning deltas can be discarded, but the external contribution still lacks redacted after-fix runtime evidence on an OpenAI-compatible reasoning stream; focused tests and CI are supplemental only.

## What This Changes

The PR records LLM-request activity for every raw OpenAI completions stream chunk so the idle watchdog treats hidden reasoning deltas as provider activity.

## System Context

OpenAI-compatible providers feed raw server-sent completion chunks into the AI transport. The transport filters and emits assistant output while the idle watchdog uses activity notifications to decide whether an agent run remains alive.
