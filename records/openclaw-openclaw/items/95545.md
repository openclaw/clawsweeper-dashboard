## What This Changes

The PR adds a service-level Skill Workshop update-apply validator and tests that reject delta/proposal-note, empty, and identity-swap update drafts before writing live `SKILL.md` while allowing complete rewrites.

## Best Possible Solution

Land the shared service-boundary guard if maintainers accept the fail-closed compatibility behavior, keeping the current positive and negative update-shape coverage without adding a config escape hatch.

## Reproduction Assessment

## Solution Assessment

Yes, with a maintainer-owned compatibility tradeoff. The shared service apply boundary is the narrowest maintainable place because CLI, Gateway, and agent surfaces all converge there before the live write.
