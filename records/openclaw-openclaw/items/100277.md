## Summary

The PR is the right general fix path and has strong simulator/unit proof, but it is not merge-ready because the iOS Watch chat paths still bypass the new selected-agent transport scope. That leaves non-default `global` Watch preview/send targeting the default global session.

Restores Apple chat ownership of Gateway in-flight runs across reconnect/foreground/session recovery, scopes selected-global routing, and preserves Gateway user-turn idempotency through Codex/Copilot mirrors.
