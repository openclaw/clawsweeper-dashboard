## What This Changes

This PR adds an optional `outcome: "message" | "none"` setting to shared exec and plugin approval forwarding so operators can suppress resolved approval echo messages.

## System Context

Approval requests are routed to configured chat targets and may use channel-native approval UI. When an approval resolves, the shared forwarding layer sends a result payload to the same targets; native channel clients can own separate prompt and outcome behavior.
