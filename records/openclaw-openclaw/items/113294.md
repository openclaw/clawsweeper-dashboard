## Summary

The reported mechanism is contradicted by the current and previously shipped managed-service contract: `OPENCLAW_GATEWAY_TOKEN` is a managed gateway value, while SecretRef-backed token configuration intentionally avoids persisting a resolved plaintext token. The report does not establish a remaining OpenClaw path that deletes a valid managed token during update, so this can close pending a fresh, redacted current-version reproduction that identifies the actual installed service configuration.

## What This Changes

Prevent `openclaw update` from removing `OPENCLAW_GATEWAY_TOKEN` from a managed macOS Gateway service and causing a subsequent authentication failure.

## System Context

The Gateway installer converts durable Gateway configuration and selected environment-backed secrets into a launchd service environment. An update re-stages that service, after which the Gateway resolves authentication and starts configured channels.

## Architecture Diagram

flowchart LR
  A[Gateway config and env refs] --> B[Service install or update]
  B --> C[Managed service environment]
  C --> D[launchd starts Gateway]
  D --> E[Gateway authentication]
  E --> F[Channel connections]

## Best Possible Solution

Keep the existing managed-service contract: use durable `gateway.auth` configuration or an explicit supported SecretRef/environment source, and reopen only with a redacted current-version service environment plus the exact update/install command showing a token loss.

## Evidence

- **Current gateway service contract:** The current Gateway CLI documentation states that when token authentication uses a resolvable SecretRef, installation validates it but does not persist the resolved token into managed service-environment metadata; an unresolved required SecretRef fails installation instead of silently writing fallback plaintext. This conflicts with the report's claimed regeneration rule.
  - file: [docs/cli/gateway.md:438](https://github.com/openclaw/openclaw/blob/187b604e50740acc3dd0818ebe208b8153c629fb/docs/cli/gateway.md#L438)
  - sha: [187b604e5074](https://github.com/openclaw/openclaw/commit/187b604e50740acc3dd0818ebe208b8153c629fb)

- **Shipped preservation behavior:** The v2026.5.4-beta.1 release notes describe a Gateway/install change that preserves `.env`-managed values in the macOS LaunchAgent environment across regeneration while continuing to track managed keys, specifically to prevent managed authentication/provider values from disappearing.
