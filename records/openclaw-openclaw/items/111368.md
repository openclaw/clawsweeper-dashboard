## What This Changes

The branch makes synchronous exec-approvals lock release verify its nonce-bearing sidecar with bounded file-content reads and stable pathname checks, adding regressions for identity drift, replacement safety, and partial-write cleanup.

## System Context

Exec approvals read persisted policy before OpenClaw permits or denies command execution. This PR changes the synchronous sidecar-lock release used around that policy store, affecting whether later policy reads can proceed or fail closed.
