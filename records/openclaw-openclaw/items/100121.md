## Best Possible Solution

Keep this issue open until the active placeholder PRs settle, then make one maintainer-approved terminal contract for no-reply tool failures: read-only exec-like failures should either show a compact warning when no user answer was delivered or allow the zero-payload incomplete-turn fallback.
