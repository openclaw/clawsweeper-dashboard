## Summary

Keep open: current main has addressed part of the bogus image-placeholder path, but source inspection still shows remaining exec-like warning suppression and incomplete-turn fallback suppression for tool-error turns, and an open adjacent PR only covers the narrower non-vision image-block downgrade gap.

## What This Changes

The issue asks OpenClaw to stop replacing empty non-image tool output with image placeholder text and to surface a useful response or warning when exec/tool failures leave no user-facing reply.

## Best Possible Solution

Define one terminal tool-error contract: non-media tool results must never become image placeholders, a failed exec/tool turn with no delivered answer must produce a useful channel-safe warning or incomplete-turn fallback, and recovered or acknowledged failures should not add stale warnings.
