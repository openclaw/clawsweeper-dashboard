The open image-downgrade PR only covers one adjacent placeholder path, so it is not a complete owner for this issue.

## What This Changes

Issue reports that exec/tool failures can leave channel users seeing “(see attached image)” or no useful model/error reply instead of a normal tool result or fallback response.

## Best Possible Solution

Define one terminal tool-error contract for failed exec/tool turns: empty non-media results must never become image placeholders, non-mutating exec-like failures need a compact user-visible outcome when no answer was delivered, and payloadCount=0 user-addressed turns should receive an incomplete-turn fallback or typed terminal failure instead of being suppressed by lastToolError.
