## Summary

Keep open: current main fixes the main empty non-media tool-result placeholder path, but it still contains explicit branches that suppress exec-like failure warnings and lastToolError incomplete-turn fallback. The v2026.6.11 reports and follow-up comments support a real channel-facing regression, but the remaining behavior needs maintainer policy confirmation before automation changes terminal-turn semantics.

## What This Changes

The issue asks OpenClaw to stop converting empty/text tool results into `(see attached image)` and to surface useful warning or fallback text when failed tool turns deliver no assistant reply.

## Best Possible Solution

Confirm one terminal tool-error contract, then implement it across provider replay and embedded-runner payloads with focused coverage for empty non-media tool output, no-reply exec-like failure, and payloadCount=0 incomplete turns.
