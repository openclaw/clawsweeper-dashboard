## Summary

## What This Changes

The issue reports that `openclaw agent --json` can expose pre-hook assistant text even though `before_message_write` rewrote or blocked the persisted transcript.

## Best Possible Solution

Make the live CLI JSON result consume the finalized assistant message accepted by the write-hook path, with explicit non-leaking behavior for hook-blocked replies and focused regression proof.
