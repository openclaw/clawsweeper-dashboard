## Summary

Keep open: current main and v2026.6.11 still preserve the reported ACP identity-state shape and there is no merged canonical fix for the restart-storm/channel-bound recovery gap, but the proposed “pending + ids equals resolved” shortcut conflicts with prior review history and needs maintainer-shaped repair.

## What This Changes

## Best Possible Solution

Implement status/liveness-backed ACP recovery for persistent bound sessions after gateway restart, keep ensure-sourced IDs provisional until runtime status or events confirm them, and add regression plus redacted live proof for configured channel dispatch.
