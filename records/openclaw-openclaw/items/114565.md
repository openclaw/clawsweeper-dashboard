## What This Changes

Add a native Feishu bot command menu that exposes OpenClaw’s registered slash commands in the Feishu chat interface.

## System Context

OpenClaw defines portable built-in commands and channel adapters decide how to present them on each messaging platform. A Feishu adapter would translate the registered command list into the platform’s bot-menu API, then users would select or discover commands from the Feishu chat UI.
