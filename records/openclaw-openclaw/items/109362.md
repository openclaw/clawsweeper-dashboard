The protected maintainer label and intentional operator-visible behavior change still require maintainer handling before merge.

## What This Changes

The PR makes `doctor --fix` preserve an unrecoverable unparseable config as a `.clobbered.*` snapshot and exit with an error instead of writing a partial best-effort replacement.

## Best Possible Solution

Doctor should never replace an unparseable configuration with a lossy best-effort projection; retain this shared bounded snapshot path, keep the original active file unchanged, and provide an explicit actionable failure to the operator.
