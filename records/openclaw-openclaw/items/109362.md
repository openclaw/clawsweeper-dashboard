## What This Changes

The PR makes `doctor --fix` preserve syntactically unparseable, unrecoverable config bytes in a bounded `.clobbered.*` snapshot and exit non-zero instead of continuing into a partial rewrite.

## Best Possible Solution

Doctor should preserve the exact malformed bytes and fail before any best-effort mutation, while leaving parseable schema-invalid repair and last-known-good restoration behavior unchanged.
