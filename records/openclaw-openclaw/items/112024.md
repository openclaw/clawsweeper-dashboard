This PR caps the PDF agent tool’s model-supplied `maxBytesMb` value at 100 MB, documents that maximum in its tool schema, logs clamping, and adds focused regression tests.

## System Context

The PDF agent tool accepts model-generated parameters, loads a PDF subject to a byte limit, and then routes it through native analysis or text extraction. This change constrains the model-provided size input before the PDF media-loading path receives its byte budget.
