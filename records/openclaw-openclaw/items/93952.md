## What This Changes

This PR adds hard deadlines and stale-write guards to runtime-auth refresh, cold-start auth preparation, and OAuth lock-held work so a hung credential operation cannot indefinitely block an embedded agent lane.

## System Context

Embedded agent runs obtain provider credentials before model turns and periodically refresh expiring runtime auth. The controller coordinates one in-flight refresh per runtime state, while the OAuth manager serializes shared credential refreshes and persists refreshed credentials for later requests.

  D --> E[OAuth lock-held refresh]

  C --> G[Prepared runtime credentials]
  G --> H[Provider model request]

## Best Possible Solution

Keep the bounded local deadlines and stale-write protections, then merge only after the auth owners explicitly accept the non-cancellable external-operation semantics or identify a provider contract that requires a different cancellation or serialization boundary.
