## Summary

Keep this issue open. Current main and the latest release still send from the WebChat/Control UI composer on plain Enter with no configurable send-shortcut setting, and the linked implementation PR remains open and needs maintainer product/settings-scope review before this tracker can close.

## What This Changes

The issue requests a configurable WebChat/Control UI send hotkey so users can choose Cmd/Ctrl+Enter instead of plain Enter, mainly to avoid accidental sends during IME or long-message composition.

## Best Possible Solution

Land a refreshed implementation that preserves Enter-to-send as the default, adds a maintainer-approved scoped preference or config surface, handles IME/Shift/Cmd/Ctrl-Enter behavior, routes visible copy through i18n, and updates focused tests and docs for the chosen surface.
