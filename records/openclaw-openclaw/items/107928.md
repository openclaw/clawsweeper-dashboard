## Summary

Keep this issue open. Current main still uses a compact model-and-reasoning trigger; its combined accessibility label helps screen readers but does not make the bare reasoning value or context percentage self-explanatory to sighted users. The linked message-footer request is related but does not own this narrower composer usability gap.

## What This Changes

Add self-describing labels or tooltips to the Control UI composer footer’s reasoning and context-usage values, with optional responsive labels and threshold coloring.

## Best Possible Solution

Preserve the compact composer layout while adding localized accessible names and hover/focus explanations for reasoning and context usage; treat responsive text and threshold colors as optional follow-up design work.
