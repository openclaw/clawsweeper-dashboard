- **[P1] Persist routes on the thread session entry:** `extensions/mattermost/src/mattermost/monitor.ts:1383-1386`
  - body: Once this block runs for non-DM Mattermost turns, it still writes through the shared route entry rather than the active thread session.   - confidence: 0.88
- **[P1] Avoid redirecting main-session deliveries into public threads:** `extensions/mattermost/src/mattermost/monitor.ts:1383-1386`
  - body: Broadening this write updates shared route context for channel/thread traffic, not only the thread-scoped session that needs cron recovery. Later main-session heartbeat or wake deliveries can reuse a public Mattermost thread as the last route, changing existing delivery behavior.
  - confidence: 0.82
- **[P2] Do not claim heartbeat routing is fixed here:** `extensions/mattermost/src/mattermost/monitor.ts:1384-1386`
  - body: The new comment says heartbeat wakeups keep thread context, but heartbeat-mode target resolution intentionally drops session-derived thread IDs unless the turn source supplies one. This patch is at most a partial cron route-persistence prerequisite unless the heartbeat path changes too.
  - confidence: 0.9
