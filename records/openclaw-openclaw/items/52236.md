  - body: This update still writes all non-DM Mattermost thread context to `route.mainSessionKey`. Cron delivery checks the targeted thread session before falling back, so two active threads can inherit the last shared `threadId` and send into the wrong thread.
  - confidence: 0.88
- **[P1] Avoid redirecting main-session deliveries into public threads:** `extensions/mattermost/src/mattermost/monitor.ts:1383-1398`
  - body: Removing the direct guard updates the shared main route after any channel/thread message. Main-session heartbeat or wake delivery can then reuse that public thread, changing existing delivery behavior for users whose main session previously resolved elsewhere.
  - confidence: 0.82

  - body: The new comment says heartbeat wakeups keep thread context after this write, but heartbeat-mode resolution deliberately ignores stored session threads unless a turn source supplies one. This is at most a partial cron prerequisite without a heartbeat-path change.
  - confidence: 0.9
