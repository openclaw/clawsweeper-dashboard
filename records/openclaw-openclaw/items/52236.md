  - body: This still broadens `updateLastRoute` while using the base route's last-route session key instead of the active thread `sessionKey`.   - confidence: 0.88

  - body: The widened write updates shared route context for channel/thread traffic, not only the thread-scoped session that needs recovery.   - confidence: 0.82
- **[P2] Stop claiming heartbeat routing is fixed here:** `extensions/mattermost/src/mattermost/monitor.ts:1381-1384`
  - body: The added comment and PR scope still frame heartbeat wakeups as fixed by saving `threadId`, but heartbeat-mode target resolution drops session-derived thread IDs unless the turn source supplies one. This patch is only a partial cron route-persistence prerequisite unless the heartbeat path is changed too.
  - confidence: 0.9
