## Risks / Open Questions

- Exposing `update.run` over bearer-authenticated HTTP would let any holder of the gateway operator secret orchestrate host package updates and restarts, so maintainers need to approve that boundary explicitly.
- The requested `target_version` parameter is not in the current `update.run` schema, and pinning semantics vary across git, package-manager, and supervised installs.
- Public health version metadata is additive, but commit/build metadata could fingerprint deployments; the field set needs a security-approved contract.
- The version metadata half is already tracked by https://github.com/openclaw/openclaw/issues/91795, so bundling it with update execution can slow the narrower observability decision.
