Options:

- **Split version from update authority (recommended):** Track health/version metadata in the narrower issue and require a separate maintainer-owned security/API design before exposing HTTP update execution.

- **Reject HTTP update execution:** Keep update execution on existing CLI/WebSocket/control-plane paths and document that fleet tools should use those or an external orchestrator.
