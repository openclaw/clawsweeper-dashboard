## What This Changes

Request to add version metadata to gateway health responses and add an authenticated HTTP admin update endpoint for fleet update orchestration.

## Best Possible Solution

Let https://github.com/openclaw/openclaw/issues/91795 carry the narrow version metadata contract, and separately decide whether the default-off Admin HTTP RPC plugin or another authenticated HTTP surface may expose `update.run` with explicit security docs and tests.

## Solution Assessment

No, not as one automatic combined change. Version reporting is a narrow additive public contract, but HTTP-triggered updates should reuse or wrap `update.run` only after maintainers approve the security boundary and API shape.
