## Summary

Keep open. The branch addresses a real P1 large-session gateway stall and now includes a plausible cross-process cache-coherence repair, but the light gateway path still appears to parse the full SQLite JSON payload before discarding the two dominant fields, so cold reads retain the central hot-path cost. The production-backport report is valuable evidence, but it does not inspectably prove the final head's projection and external-write behavior.

## What This Changes

This PR adds a process-local SQLite session-list cache with invalidation and coherence checks, lightweight gateway listings, pagination, and regression/benchmark coverage for gateways holding many sessions.

## System Context

Gateway session listing reads per-agent SQLite session metadata through the session accessor, then feeds Control UI and runtime combined views. The proposed cache and lightweight mode sit between SQLite rows and those gateway consumers, affecting response time and the freshness of returned session keys.
