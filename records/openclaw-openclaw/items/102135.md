## Summary

Keep open: current main still applies ACP media understanding and then forwards the same raw current image attachment into `acpManager.runTurn()`, and the live closing PR at https://github.com/openclaw/openclaw/pull/102145 is still open rather than merged.

## What This Changes

The issue requests that ACP dispatch stop passing raw current-turn image attachments after media understanding has already converted those images to text for a text-only session model.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/102145 or an equivalent narrow ACP parity fix that drops only described current image indexes while preserving inline images, extracted PDF page images, recent-history images, and undescribed current images.
