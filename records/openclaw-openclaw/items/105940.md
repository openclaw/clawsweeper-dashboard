## Summary

This is a well-grounded, still-necessary regression report: the merged Google Chat migration materializes only the named account’s flat streaming keys, while runtime resolution overlays that partial object over `accounts.default.streaming`, changing the account’s effective delivery behavior. The exact failure was also identified during review of the introducing pull request but remained in the merged implementation. Likely related people: @steipete has high-confidence relevance from authoring and merging the migration work.

## What This Changes

Preserve Google Chat `accounts.default` streaming inheritance when doctor migrates flat streaming keys for named accounts.

## Best Possible Solution

Add Google Chat plugin-local migration seeding that merges root streaming, `accounts.default` streaming, and the named account’s migrated keys in runtime precedence order, with focused tests proving the resolved account retains both inherited and account-specific settings.
