## Summary

Keep open: current main and the latest release still shallow-merge nested settings objects, while three open closing PRs already target the same root cause. This issue should remain open until one candidate lands rather than spawning another duplicate fix.

## What This Changes

The issue reports that split `retry.provider` fields across global, project, or runtime settings scopes are dropped because `deepMergeSettings` only shallow-merges nested objects.

## Best Possible Solution

Land one of the existing linked PRs that makes `deepMergeSettings` truly recursive and adds focused `SettingsManager` regression coverage for global, project, and runtime override scopes.
