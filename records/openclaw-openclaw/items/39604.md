Request to add a default-off `web_fetch` configuration option that lets operators allow private/internal network destinations.

## Best Possible Solution

Define one maintainer-approved nested `tools.web.fetch.ssrfPolicy` contract with explicit dangerous naming, default-off behavior, hard metadata/link-local rules, redirect/cache/provider/audit coverage, docs, and focused tests before landing a core config change.
