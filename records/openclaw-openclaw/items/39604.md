## What This Changes

The issue requests an opt-in private-network access configuration for arbitrary `web_fetch` targets.

## Best Possible Solution

Define one maintainer-approved, default-off `web_fetch` SSRF policy surface with dangerous naming, hard metadata/link-local semantics, cache/redirect/provider/audit coverage, docs, and focused tests before landing the core config change.

- **Fold into broader egress design:** Make this part of the larger web-tool egress firewall decision so private-network access, allowlists, deny rules, and per-agent authorization are designed together.
