## Summary

Keep open: current main and the latest release still do not expose broad private-network access for arbitrary `web_fetch`, and the remaining path is a security-sensitive product/config decision with an open draft implementation candidate.

## What This Changes

The issue requests an opt-in `tools.web.fetch.allowPrivateNetwork` style configuration surface so `web_fetch` can access localhost and private/internal network addresses.

## Best Possible Solution

Land a maintainer-approved SSRF policy that keeps default-deny behavior, scopes private-network exceptions to trusted agents or hosts, preserves metadata/link-local protections, covers redirects/cache/provider fallback, and documents the audit and upgrade contract.
