## Summary

Keep open: current main still leaves the reported yielded-parent wake problem active, with ACP completion still tied to heartbeat wake behavior and native subagent fixes split across narrower open PRs rather than a merged cross-runtime contract.

## What This Changes

The issue requests that ACP and native child completions reliably wake a parent session waiting via `sessions_yield` without requiring a manual refresh, poke, or restart.

## Best Possible Solution

Define one heartbeat-independent yielded-parent continuation contract, then land focused ACP and native fixes with regression proof for heartbeat-disabled ACP, active requester wake, announce give-up, and parent reply delivery.
