## Summary

Keep open: current main has partial wake/delivery improvements, but it still does not close the yielded-parent completion problem across ACP and native subagent paths. The old direct-resume root cause is stale, but the current source still has heartbeat-coupled ACP wake behavior and open PRs only cover narrower slices.

## What This Changes

The issue asks for yielded parent sessions to resume reliably when ACP or native child work completes, without requiring manual refresh, heartbeat availability, or a later user poke.

## Best Possible Solution

Define one durable parent-continuation/wake contract at the task or announce-delivery boundary, then land focused ACP and native regression fixes that satisfy that shared contract without relying on optional heartbeat availability.

Options:

- **Task/announce delivery owns wakeups (recommended):** Use task terminal or announce delivery as the durable parent-continuation source for both ACP and native child completions, with runtime relays limited to progress.
- **Runtime relays own wakeups:** Keep ACP/native-specific relays responsible for waking yielded parents, accepting separate code paths and regression coverage per runtime.
- **Add explicit yield-wait lifecycle:** Introduce persisted yield-wait state and formal lifecycle events before landing further partial wake patches.

## Reproduction Assessment

Yes, there is a high-confidence source-level reproduction for the heartbeat-disabled ACP path: ACP completion enqueues a system event, then relies on heartbeat wake machinery that can have no handler or return disabled. I did not run a live end-to-end reproduction in this read-only review, and the broader native path still needs maintainer-selected regression coverage.

## Solution Assessment

No, this is not solved on current main yet. The best path is to choose one durable cross-runtime wake boundary, then use the open or replacement PRs to cover ACP heartbeat-off completion and native `sessions_spawn`/`sessions_yield` completion or failure cases with regression proof.
