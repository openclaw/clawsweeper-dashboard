The issue asks OpenClaw to resume yielded ACP/native parent sessions automatically when child completion events arrive, instead of staying stuck until a manual refresh or user nudge.

Define one cross-runtime yielded-parent completion contract that covers ACP, native subagents, blocked/give-up outcomes, heartbeat-disabled or disabled-agent deployments, and requester consumption/ack semantics, then land the narrow PR slices that fit that contract.
