## Summary

Keep open: current main has partial wake and handoff machinery, but it does not yet prove a complete yielded-parent wake contract for ACP, native subagents, give-up delivery, and heartbeat-disabled deployments.

## What This Changes

The issue asks for parent sessions yielded after ACP or native child spawn to wake automatically on child completion instead of staying stuck until refresh or another manual poke.

## Best Possible Solution

Keep this as the broad yielded-parent wake tracker while maintainers review the narrow PRs and choose one durable wake/resume contract for ACP, native subagents, give-up delivery, and heartbeat-disabled deployments.
