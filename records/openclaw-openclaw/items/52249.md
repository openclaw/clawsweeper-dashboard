## Summary

Keep open: current main and v2026.6.11 still route ACP parent stream wake through the optional heartbeat handler, and the related open PRs cover narrow ACP task-terminal or native give-up slices rather than the full yielded-parent wake contract.

## What This Changes

Ensure yielded ACP and native parent sessions resume automatically when child work completes, without manual refresh, external poke, or heartbeat-dependent gaps.

## Best Possible Solution

Define one heartbeat-independent yielded-parent continuation contract, then land focused ACP and native fixes with regression proof for heartbeat-disabled ACP, active requester wake, announce give-up, and final parent reply delivery.
