## What This Changes

Change the Control UI working-claw indicator so ordinary runs use the dependable default loop while rare runs play one delayed special move once and then return to that loop.

## System Context

The Control UI chat page receives agent-run activity and displays a working indicator while a run is active. The indicator’s animation selection affects how often chat users see the default claw versus playful special moves.

## Architecture Diagram

## Best Possible Solution

Confirm the intended animation policy, then implement a deterministic default-loop path with at most one delayed special move per eligible run, preserving the existing reduced-motion contract and adding focused behavior coverage.
