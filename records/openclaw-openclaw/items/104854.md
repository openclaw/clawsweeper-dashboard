## What This Changes

Improve config validation diagnostics with source location, offending values, and bracketed array indices.

## Best Possible Solution

Extend the canonical config issue model with optional source file/line metadata, use bracket notation for numeric segments, and show sanitized offending values only when the path is not secret-bearing; derive locations during JSON/JSON5/include loading so every diagnostic consumer stays consistent.
