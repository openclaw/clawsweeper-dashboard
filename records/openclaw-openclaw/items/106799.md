## Summary

Keep this PR open for landing: current main still eagerly creates empty per-lease stderr files, while the patch removes that unnecessary write without changing non-empty stderr capture. The implementation is focused, regression-covered, and supported by convincing Linux gateway proof.

## What This Changes

The PR makes ACPX Codex per-lease stderr logs lazy and adds regression coverage showing quiet processes create no file.

## Best Possible Solution

Land the lazy first-stderr-write behavior with the quiet-process regression test while preserving the existing bounded, redacted non-empty diagnostic log path.
