## Summary

Keep open: current main and the latest release still support configured avatar strings, read-only avatar serving, workspace file editing, and a browser-local Quick Settings override, but they do not provide the requested Agents-tab image upload flow or an `agents.avatar.upload` RPC.

## What This Changes

The issue requests a Control UI Agents-tab avatar picker that uploads an image into the agent workspace and updates the agent identity metadata.

## Best Possible Solution

Approve a bounded workspace-persistent avatar upload design that reuses the existing avatar policy and identity mutation paths, then add the Agents-tab UI and admin RPC with explicit security validation and focused tests.
