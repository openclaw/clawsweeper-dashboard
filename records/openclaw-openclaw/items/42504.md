## Summary

## What This Changes

Request an Agents-tab file picker plus admin upload RPC that stores an avatar under the agent workspace and updates persistent agent identity metadata.

## Best Possible Solution

Approve a narrow workspace-persistent upload contract that reuses existing avatar policy and identity mutation paths, or explicitly defer server-side upload and keep the current manual/local override paths.
