## Summary

Keep open: current main and the latest release still lack a durable Agents-tab avatar upload path; existing code only supports avatar display, string identity updates, workspace file editing, and browser-local Quick Settings overrides. The remaining work needs maintainer approval because it would add authenticated image ingestion, workspace writes, and avatar-serving policy.

## What This Changes

Request an Agents-tab avatar picker plus a server-side upload path that stores an image under the agent workspace and updates agent identity metadata.

## Best Possible Solution

Approve a narrow workspace-persistent avatar upload design that reuses the existing avatar policy and identity mutation paths, then add the Agents-tab UI and admin upload endpoint with explicit security validation and focused tests.
