## What This Changes

Request an Agents-tab avatar picker that saves an uploaded image under the agent workspace, updates `IDENTITY.md`, and renders it through the Control UI avatar route.

## Best Possible Solution

Approve a narrow workspace-persistent avatar upload design that reuses the existing avatar policy and identity mutation paths, then add the Agents-tab UI and admin RPC with explicit security validation and focused tests.
