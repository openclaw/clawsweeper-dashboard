## Summary

Keep open: current main still has avatar display and identity update plumbing, plus a browser-local Quick Settings avatar override, but it does not provide the requested Agents-tab persistent avatar upload UI or `agents.avatar.upload` RPC. The remaining work is security- and product-sensitive because it would add a browser-to-workspace file upload/write path.

## What This Changes

Request an Agents-tab UI and admin RPC to upload per-agent avatar images, save them under the agent workspace, update `IDENTITY.md`, and render them in Control UI.

## Best Possible Solution

Add this only after maintainers choose the product/security shape: ideally reuse existing `agents.files.set`/`agents.update` semantics where possible, or add a narrowly scoped admin upload RPC with strict validation and Control UI proof.
