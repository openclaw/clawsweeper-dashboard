## Summary

Keep open: current main and v2026.6.11 support avatar metadata/rendering and editable agent files, but there is still no Agents-tab avatar picker or `agents.avatar.upload`/equivalent binary upload contract. The remaining work is a product/security decision because it would add browser-driven image upload, workspace file writes, and identity-state mutation.

## What This Changes

The issue requests a Control UI Agents-tab flow to upload an agent avatar, store it in the agent workspace, update `IDENTITY.md`, and render it through the avatar route.

## Best Possible Solution

Keep the current avatar rendering and identity-file support, and add a dedicated admin-only avatar upload contract only if maintainers approve a bounded design that reuses existing avatar validation and identity-write ownership.
