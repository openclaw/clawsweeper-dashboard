## Summary

Keep open: current main and v2026.6.11 still lack the requested Agents-tab workspace avatar upload path or an `agents.avatar.upload` RPC, while the existing avatar support only covers configured identity values, read-only avatar serving, and browser-local Quick Settings overrides.

## What This Changes

Request an Agents-tab avatar picker that uploads an image into the agent workspace, updates identity metadata, and renders the result through `/avatar/<agentId>`.

## Best Possible Solution

Approve a narrow authenticated upload design that reuses the shared avatar policy, writes canonical per-agent identity metadata, keeps `IDENTITY.md` in sync, and covers the Gateway RPC plus Agents-tab UI with security-focused tests.
