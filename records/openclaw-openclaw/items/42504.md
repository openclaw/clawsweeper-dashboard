Keep open: current main and the latest release still lack the requested Agents-tab workspace avatar upload path and `agents.avatar.upload` RPC. Add a Control UI Agents-tab picker and gateway upload path to store an agent avatar in the workspace and update identity metadata.

## Best Possible Solution

Approve a narrow authenticated workspace avatar upload design that reuses the existing avatar policy, writes canonical per-agent identity metadata, and covers both Gateway RPC and Agents-tab UI with security-focused tests.
