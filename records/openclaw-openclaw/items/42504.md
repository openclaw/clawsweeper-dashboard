## What This Changes

The issue requests a Control UI Agents-tab avatar picker backed by an admin RPC that stores an uploaded image under the agent workspace and updates agent avatar identity metadata.

## Best Possible Solution

Define and approve a narrow operator-admin avatar upload contract, then implement the Agents-tab UI against that contract with validated image storage, canonical config-backed identity updates, preserved `/avatar/<agentId>` read protections, and focused tests for upload rejection and rendered visibility.
