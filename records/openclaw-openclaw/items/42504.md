## Summary

Keep open: current main and v2026.6.11 still provide avatar serving, identity string updates, and a browser-local Quick Settings override, but they do not provide the requested Agents-tab workspace avatar upload UI or `agents.avatar.upload` RPC.

## What This Changes

The issue requests an Agents-tab UI flow and admin RPC for uploading per-agent avatar images, storing them in the workspace, and updating agent identity metadata.

## Best Possible Solution

Add a narrow, authenticated workspace-persistent avatar upload design only after maintainers approve storage, validation, and identity-source precedence; reuse existing avatar serving and identity mutation protections rather than adding an ad hoc file path.
