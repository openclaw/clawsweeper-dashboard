## Summary

Keep open: current main and the latest release still do not provide an Agents-tab workspace avatar upload or `agents.avatar.upload` RPC. Existing support covers read-only avatar serving, string identity updates, documented CLI/manual identity paths, and a browser-local Quick Settings override, but the requested persistent upload path needs maintainer product and security direction.

## What This Changes

The issue requests an Agents-tab avatar picker that uploads a local image, stores it under the agent workspace, and updates agent identity so Control UI renders it.

## Best Possible Solution

Approve a bounded workspace-persistent avatar-upload design that reuses the shared avatar policy and identity mutation paths, then add the Agents-tab UI and admin RPC with explicit security validation and focused Control UI/Gateway tests.
