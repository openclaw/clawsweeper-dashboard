## Summary

Keep open: current main still lacks an Agents-tab workspace-persistent avatar upload path, and the right fix needs maintainer product/security direction because it adds authenticated image ingestion and workspace writes.

## What This Changes

The issue requests an Agents-tab avatar picker plus admin upload path that stores selected images in the agent workspace and updates agent identity metadata.

## Best Possible Solution

Approve a bounded design before implementation: add an operator-admin upload path only if it reuses avatar policy, writes canonical per-agent identity metadata, preserves path containment, and includes Gateway plus Agents-tab UI tests.
