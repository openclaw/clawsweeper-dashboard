  - body: The handler awaits `engine.interceptCompaction()` directly inside `session_before_compact`.   - body: This zeroes `reserveTokensFloor` for every intercepting engine before knowing whether the intercept handled the event. When the engine declines, throws, lacks a session file, or is skipped by safeguard cancellation, fallback compaction can run without the configured safety floor and change next-turn headroom.
