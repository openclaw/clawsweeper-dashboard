## Summary

## What This Changes

The PR adds optional `ContextEngine.interceptCompaction()` and `info.interceptsCompaction`, re-exports the types through the plugin SDK, wires a `session_before_compact` extension, changes compaction settings, and updates docs/tests for context-engine plugins replacing automatic compaction summaries.

Port the feature to current `agent-*` and `agent-hooks` surfaces, bound the plugin callback like other plugin compaction work, preserve fallback headroom semantics, and require maintainer approval plus live handled-intercept proof before merge.
