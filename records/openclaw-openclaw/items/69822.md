## Summary

Keep this PR open, but do not merge it until the Gateway overflow and recovery contract is explicit. The happy-path routing is useful and well-proven, while the latest head still treats a non-droppable broadcast as reliable even though the documented transport may close a slow connection without replaying the eviction event.

## What This Changes

Adds `socket.drain` teardown events for matching session-event and session-message subscribers, registers the event and scope guard, extends Gateway request context access, and adds focused session-event tests and generated baselines.

## Best Possible Solution

Define `socket.drain` as best-effort with an authoritative `sessions.list` or state-version resync on sequence gaps and reconnects while preserving existing shedding behavior, or add durable bounded replay/ack semantics before describing the event as reliable.
