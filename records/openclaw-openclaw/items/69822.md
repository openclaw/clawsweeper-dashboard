## Summary

Keep this PR open for a bounded slow-subscriber design and fresh exact-head proof. The central `socket.drain` capability is not on current main, but this branch still routes the teardown through an unbounded existing-event path while the new drain itself retains the normal drop behavior.

## What This Changes

This PR advertises a new `socket.drain` gateway event, sends it to session-message subscribers during resets and deletes, and adds related gateway admission/error handling tests.

## System Context

Gateway session mutations publish lifecycle information to WebSocket event and session-message subscribers. The same gateway also admits OpenAI-compatible HTTP requests, so its delivery and draining rules affect both downstream client cleanup and in-flight agent work.
