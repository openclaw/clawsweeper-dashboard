## What This Changes

## Best Possible Solution

Treat `socket.drain` as advisory: preserve the existing slow-consumer safety boundary, document that reconnecting clients must resubscribe and reload authoritative session state, and add focused overflow/reconnect tests; pursue acknowledgement or durable replay separately only if maintainers require stronger guarantees.
