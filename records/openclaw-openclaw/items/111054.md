## What This Changes

The PR normalizes Nextcloud Talk `--base-url` input and rejects bare hosts or non-HTTP(S) schemes during non-interactive channel setup before account configuration is written.

## System Context

The Nextcloud Talk plugin receives interactive and non-interactive channel setup input, validates the instance base URL, and then writes the channel account configuration. This change places the non-interactive adapter on the same URL-validation path as the guided setup flow, preventing unusable account records from reaching later connection logic.
