## Summary

This PR remains necessary: current `main` validates the Nextcloud Talk URL in the guided wizard but the non-interactive setup adapter only checks that a value exists. The patch reuses the plugin’s existing normalization and HTTP(S)-scheme rule before config is written; its supplied redacted CLI proof and successful checks support a normal maintainer merge review after refreshing the behind branch.

## What This Changes

The branch makes non-interactive Nextcloud Talk channel setup normalize `baseUrl` and reject bare hosts or non-HTTP(S) schemes before it writes account configuration.

## System Context

The channel-add CLI delegates channel-specific input checking to the Nextcloud Talk plugin’s setup adapter, then writes the accepted values into the channel account configuration. The guided setup wizard already normalizes and validates the same URL field, while the configured channel later uses that base URL to contact the Nextcloud instance.
