## Summary

## What This Changes

The issue asks OpenClaw to replace or augment the documented static Browserbase `cdpUrl` workflow with Browserbase session lifecycle handling that creates or resolves a fresh connect URL before CDP attach.

## Best Possible Solution

Land a maintainer-approved Browserbase Sessions API driver or browser-backend/plugin seam with credential policy, signed-URL redaction, session cleanup, docs updates, and redacted live OpenClaw browser-tool proof; otherwise replace the static docs with a supported fallback if core integration is rejected.
