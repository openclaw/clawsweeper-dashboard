## Summary

Keep open: current main and v2026.6.11 still document Browserbase as a static `cdpUrl` profile and route it through generic remote-CDP handling, while the Sessions API driver candidate remains open with proof, security, product-direction, and mergeability blockers.

## What This Changes

The issue asks OpenClaw to replace the documented static Browserbase `cdpUrl` setup with Browserbase Sessions API lifecycle handling that creates or resolves a session `connectUrl` before CDP attach.

## Best Possible Solution

Land a maintainer-approved Browserbase lifecycle path or plugin/API seam that resolves fresh `connectUrl` values before every CDP/Playwright attach, handles session cleanup or stale sessions deliberately, redacts signed URLs, updates docs, and includes live redacted Browserbase proof.
