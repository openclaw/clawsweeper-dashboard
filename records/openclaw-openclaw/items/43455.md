## What This Changes

## Best Possible Solution

Land a maintainer-approved Browserbase Sessions API driver or generic browser-backend seam with credential policy, signed-URL redaction, session cleanup, docs, tests, and live browser-tool proof; otherwise stop recommending the static Browserbase URL.
