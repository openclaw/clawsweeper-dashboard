## Summary

The requested behavior is absent on current main, and no canonical issue or PR owns it. This is a legitimate new capability, but it would add configuration and alter credential-exfiltration and SSRF boundaries, so it should remain open for explicit maintainer security and product direction.

## What This Changes

Add opt-in exact-domain credential attachment to generic web fetch and image requests while stripping credentials on cross-host redirects.

## Best Possible Solution

Keep anonymous fetching as the default and, after maintainer approval, implement one shared guarded credential policy using exact HTTPS hosts, SecretRefs, existing cross-origin header stripping, redacted observability, and focused tests for both web_fetch and image loading; if that core contract is not desired, provide an explicit plugin-owned authenticated media tool instead.

## Solution Assessment
