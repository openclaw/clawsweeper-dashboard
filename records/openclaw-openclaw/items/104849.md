## Summary

Current main still fetches remote web and image URLs without host credentials. The request is valid, but it introduces a new configuration surface and materially expands SSRF, redirect, caching, and credential-exfiltration boundaries, so it needs explicit maintainer product and security direction.

## What This Changes

Add opt-in exact-domain credential attachment for web_fetch and remote image requests, stripping credentials when redirects leave the authorized host set.

## Best Possible Solution

Keep generic tools anonymous unless maintainers approve one restricted authenticated-fetch service with exact authorization hosts, SecretRef resolution, cross-host stripping, private-cache isolation, sandbox preservation, and shared coverage for both tools.
