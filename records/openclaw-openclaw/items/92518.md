## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Limit fallback to upload scope failures:** `extensions/googlechat/src/api.ts:278`
  - body: This helper treats any message containing `403` or `PERMISSION_DENIED` as the app-auth upload-scope case. The callers then downgrade that failure into a text-link send, so an ordinary upload authorization/policy denial, and in the monitor path even a broader media-send 403 string, can leak through as a URL instead of preserving the denial. Please match the upload error prefix plus the actual insufficient-scope signal, such as `insufficient authentication scopes` or `ACCESS_TOKEN_SCOPE_INSUFFICIENT`.
  - confidence: 0.91
- **[P2] Preserve action send metadata:** `extensions/googlechat/src/actions.ts:169`
  - body: The fallback sends the link but discards the `sendGoogleChatMessage` result and returns only `{ ok, to }`. Current main's Google Chat action media path returns `messageName` and `threadName`, so callers see different metadata only when the fallback path is taken; capture the send result and spread it into `jsonResult` like the normal action send path.
  - confidence: 0.88
