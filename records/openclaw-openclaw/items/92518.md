## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.97

Full review comments:

- **[P1] Limit fallback to upload scope failures:** `extensions/googlechat/src/api.ts:277`
  - body: This still treats any `403` or generic `PERMISSION_DENIED` as the app-auth scope limitation. Google Chat can return those signals for membership, policy, resource, or quota denials; sending the original URL in those cases changes failure semantics and may expose a signed URL. Match the upload error prefix plus the documented insufficient-scope signal, and add negative tests for unrelated 403 responses.
  - confidence: 0.98
- **[P2] Preserve action send metadata:** `extensions/googlechat/src/actions.ts:177`
  - body: The fallback awaits `sendGoogleChatMessage` but discards its `messageName` and `threadName`, returning only `{ ok, to }`. Current message actions return those identifiers, so callers lose the sent-message reference only on fallback; return the same metadata shape as the normal send path.
  - confidence: 0.98
