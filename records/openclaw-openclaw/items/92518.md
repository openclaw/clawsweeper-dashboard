Full review comments:

- **[P1] Limit fallback to upload scope failures:** `extensions/googlechat/src/api.ts:278`
  - body: This was raised in the earlier ClawSweeper cycle and is still present: the helper returns true for any bare `403` or `PERMISSION_DENIED`, and the monitor path catches more than just `uploadGoogleChatAttachment`. A private/expired media URL download 403 or a non-scope Google Chat permission failure can now be reported as successful link delivery instead of surfacing the real failure. Match the upload error prefix plus the documented insufficient-scope signal, and add negative controls for bare 403/PERMISSION_DENIED and download failures.
  - confidence: 0.93
- **[P2] Preserve action send metadata:** `extensions/googlechat/src/actions.ts:187`
  - body: This was also raised before and remains at the current head: media actions previously returned the `sendGoogleChatMessage` result via `...sent`, so callers could see `messageName` and `threadName`. The PR now awaits the send on both the normal upload path and the fallback path but returns only `{ ok, to }`, dropping existing send metadata for successful media sends. Store the send result and include it in the JSON response.
  - confidence: 0.89
