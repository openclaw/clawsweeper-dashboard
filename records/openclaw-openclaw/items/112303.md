## Summary

Keep this PR open. The patch is a focused extension of the endpoint-scoped cache-identity rule already merged for Ollama, and its source-level regression coverage is coherent; however, it adds a plugin-SDK export and changes persisted memory-cache identity for custom routes, so it needs maintainer review plus redacted after-fix runtime proof before merge.

## What This Changes

This PR makes Mistral and DeepInfra memory embeddings include a custom endpoint and non-secret custom-header digest in their cache identity, while preserving the existing identity for their shipped default endpoints.

## System Context

Memory search resolves an embedding client through a provider adapter, then uses that adapter’s cache-key data to identify the reusable embedding index. This PR changes the identity decision for Mistral and DeepInfra so cache/index data from one custom remote endpoint cannot be reused for another endpoint with the same provider and model.
