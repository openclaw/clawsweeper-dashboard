This PR adds caller-declared proof provenance, richer proof diagnostics, session-aware Workboard claims, and matching Workboard docs and tests while preserving manual operator acceptance of completed cards.

## System Context

Workboard tools create and update cards, claims, completion evidence, and diagnostics in the Workboard plugin’s SQLite store. The dashboard and agent-facing tool summaries then expose that stored state so operators can distinguish manual acceptance from worker-reported evidence.
