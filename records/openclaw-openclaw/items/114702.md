## What This Changes

This PR adds an optional pinned squash auto-merge mode to the repository PR-landing wrapper, controlled by `--auto-merge` or `OPENCLAW_PR_AUTO_MERGE=1`, and adds focused routing and shell tests for that behavior.

## System Context

The repository landing wrapper prepares a reviewed PR head, checks its required CI and drift state, then asks GitHub to merge it. This change adds an opt-in path that arms GitHub auto-merge for an already-verified head that is behind `main`, while preserving the existing immediate-merge path for other states.
