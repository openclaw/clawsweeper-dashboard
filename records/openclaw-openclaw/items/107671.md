## What This Changes

Adds `openclaw models auth clear-cooldown <profile-id>` to clear persisted cooldown, blocked, disabled, and failure-counter state for one auth profile, including inherited auth-store ownership handling, tests, and CLI documentation.

## System Context

Provider failures are recorded in each agent’s persisted auth-profile usage state, and model routing uses that state to skip temporarily blocked profiles and choose fallbacks. This command gives an operator a targeted recovery path after the upstream provider condition is fixed, then requires a safe Gateway restart so live bookkeeping is rebuilt.
