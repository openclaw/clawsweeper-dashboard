## What This Changes

This PR adds `openclaw models auth clear-cooldown <profile-id>` to clear persisted cooldown and failure metadata for one auth profile, then tells the operator to safely restart the Gateway before retrying the recovered provider.

## System Context

OpenClaw records provider failure and cooldown metadata alongside saved auth profiles so model routing can avoid repeatedly failing credentials. This command operates on that persisted state, while the running Gateway retains separate in-memory bookkeeping that must be refreshed by a safe restart before the next model request.
