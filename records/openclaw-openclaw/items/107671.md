## What This Changes

Adds `openclaw models auth clear-cooldown <profile-id>`, which clears persisted cooldown, blocked, disabled, and failure-counter state for one saved auth profile while preserving credentials and auth order.

## System Context

Provider failures are recorded in per-agent auth-profile state, which the model-routing loop uses to decide whether a profile is eligible or whether to fall back. This command updates that persisted state through the lock-protected store; a safe Gateway restart reloads the changed state before the next provider selection.
