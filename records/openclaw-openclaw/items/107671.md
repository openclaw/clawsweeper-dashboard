## What This Changes

Adds `openclaw models auth clear-cooldown <profile-id>` to clear one saved profile’s persisted cooldown and failure state, then direct operators to safely restart the Gateway before retrying the provider.

## System Context

Auth-profile usage state records provider failures and cooldown windows that the model router uses when selecting a profile or fallback. This PR adds a CLI recovery action that updates the authoritative persisted state and relies on a safe Gateway restart to discard in-memory bookkeeping before the next request.
