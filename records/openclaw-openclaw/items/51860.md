## Summary

Keep open. Current main and the latest release still manage macOS gateway install/status as a user LaunchAgent, while the requested boot-without-login LaunchDaemon mode remains a privileged product/security decision rather than a safe cleanup close.

## What This Changes

This issue requests macOS system LaunchDaemon install/status support for the gateway so it can start after reboot without a user login.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, doctor, stop, uninstall, docs, and tests, keeping the user LaunchAgent as the safe default and adding only an audited LaunchDaemon path or guidance flow.
