## Summary

Keep open. Current main still installs and manages the macOS gateway as a user LaunchAgent in the GUI launchd domain, while the reporter and follow-up comments give credible evidence that unattended boot needs an explicit system LaunchDaemon mode with security and lifecycle review.

## What This Changes

Request support for macOS system LaunchDaemon gateway install/status so the gateway can start after reboot before user login.

## Best Possible Solution

Design an explicit, security-reviewed macOS LaunchDaemon mode covering install, status, start, stop, uninstall, doctor repair, UserName/environment handling, and duplicate-manager upgrade behavior before implementing it.
