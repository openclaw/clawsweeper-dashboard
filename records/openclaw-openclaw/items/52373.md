## Summary

Keep open. Current main and the latest release still do not expose `configUrl`/`configButton` or an equivalent dashboard configuration action for skills, and the remaining work is a new public skill metadata plus URL trust contract that needs maintainer product and security direction.

## What This Changes

Add optional `configUrl` and `configButton` SKILL.md metadata so the dashboard can show a direct skill configuration entry point.

## Best Possible Solution

Define one typed skill configuration action contract with safe URL/opener rules, expose it through `skills.status`, render it consistently in the dashboard, and document whether ClawHub/Skill Card metadata or SKILL.md is the canonical source.
