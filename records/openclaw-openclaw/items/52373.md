Keep open. Current main and the latest release still do not expose `configUrl` or `configButton` from `SKILL.md`, and the requested dashboard action is a new public skill metadata and URL trust contract that needs maintainer product/security direction.

Add optional `configUrl` and `configButton` skill frontmatter fields so the Control UI Skills list can show a configuration button for skills with web configuration pages.

## Best Possible Solution

Define a typed skill configuration-action contract, validate links through the dashboard URL policy, and thread it through skill parsing, status/API types, UI rendering, docs, and focused tests.
