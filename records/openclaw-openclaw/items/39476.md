## Summary

Keep open: current main still exposes `sessions_send` to non-embedded A2A target turns that were themselves routed by `sessions_send`, and the closing implementation candidate is still open rather than merged.

## What This Changes

Prevent an A2A target session from reverse-calling `sessions_send` back to the requester during `sessions_send` processing to avoid duplicate requester-visible messages.

## Best Possible Solution

Review, prove, and land or replace https://github.com/openclaw/openclaw/pull/91161 with a provenance-scoped guard that hides only `sessions_send` during `sessions_send`-routed A2A target turns while preserving normal non-A2A availability.
