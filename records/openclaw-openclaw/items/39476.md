## Summary

Keep open: current main still marks A2A target turns as inter-session `sessions_send` input while the normal non-embedded tool surface still exposes `sessions_send`, and the linked closing PR is open rather than merged.

## What This Changes

Prevent an A2A target handling `sessions_send` from calling `sessions_send` back to the requester and duplicating requester-visible replies.

## Best Possible Solution

Land or replace the linked PR with a provenance-scoped guard that hides only `sessions_send` during `sessions_send`-routed A2A target turns, with real A2A proof showing one requester-visible delivery and normal non-A2A `sessions_send` availability.
