## Summary

Keep open: current main still marks A2A `sessions_send` target turns as inter-session `sessions_send` input while the normal OpenClaw tool surface still exposes `sessions_send`, and the direct fix candidate remains open rather than merged.

## What This Changes

The issue asks OpenClaw to prevent A2A `sessions_send` target agents from reverse-calling `sessions_send` back to the requester and producing duplicate requester-visible messages.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/91161 or an equivalent provenance-scoped guard after redacted real A2A proof shows one requester-visible delivery, no reverse duplicate, and normal non-A2A `sessions_send` availability unchanged.
