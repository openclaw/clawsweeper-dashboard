## Summary

Keep open: current `main` and latest release still expose the reverse-call surface for A2A `sessions_send`, and the direct closing fix candidate is open but not merged.

## What This Changes

The issue asks for A2A `sessions_send` target turns to stop exposing `sessions_send` back to the target agent so one logical response is not delivered twice.

## Best Possible Solution

Review and land or replace https://github.com/openclaw/openclaw/pull/91161 so `sessions_send` A2A target turns cannot expose `sessions_send` again while normal sends and non-send inter-session handoffs remain intact.

## Solution Assessment

Yes: the narrowest maintainable fix is to hide only `sessions_send` during turns that are themselves processing a `sessions_send` A2A message. The broader one-way dispatch semantic remains separately tracked in https://github.com/openclaw/openclaw/issues/44309.
