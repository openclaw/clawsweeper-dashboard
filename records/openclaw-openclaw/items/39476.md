## Summary

Keep open: current main and the latest release still route A2A target turns as `sourceTool: "sessions_send"` while the normal OpenClaw tool surface still exposes `sessions_send`; the linked closing PR is open and unmerged.

## What This Changes

Prevent a target agent handling an A2A `sessions_send` turn from reverse-calling `sessions_send` back to the requester and duplicating channel output.

## Best Possible Solution

Land or replace the linked provenance-scoped guard so only `sessions_send` is removed from `sessions_send`-routed A2A target turns, with focused unit coverage and redacted live multi-agent proof that normal top-level sends still work and duplicate requester delivery is gone.
