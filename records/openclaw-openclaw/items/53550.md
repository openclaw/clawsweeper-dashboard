Yes, at source level. Current main filters session hits through visibility and still denies mapped live owner-scoped QMD hits when no session-store key remains, with tests explicitly locking that behavior.

## Solution Assessment

No, current main is not the complete solution yet. The best path is a maintainer-reviewed, visibility-preserving live-orphan fix plus alignment with the default-off private recall product direction rather than broadening transcript visibility by default.
