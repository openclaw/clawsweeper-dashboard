## What This Changes

The branch moves the local, manual-redirect fetch invocation behind an internal one-hop dispatcher while leaving the guarded-fetch security and redirect loop in place.

## System Context

Guarded fetch performs SSRF checks, DNS/policy routing, and redirect handling for outbound HTTP requests. This change isolates the single physical HTTP exchange beneath that loop without creating a plugin, configuration, or external transport contract.
