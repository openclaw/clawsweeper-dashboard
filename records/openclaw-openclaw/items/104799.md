## Summary

This PR is still necessary because current `main` forwards full page URLs unchanged into Playwright’s origin-scoped permission call. The exact-head patch is the best bounded fix: it shares the existing permissions-route parser, validates before side effects, preserves clear behavior, has passing exact-head CI, and now includes convincing real Browser/Chrome/Playwright proof.

## What This Changes

The PR shares canonical HTTP(S) origin parsing between Browser permission and geolocation routes, rejects invalid geolocation set origins before mutation, and keeps clear requests independent of unused origin fields.

## Best Possible Solution

Land the shared HTTP(S) origin parser and clear-before-parse behavior, retaining the focused route tests and treating canonical origins plus early invalid-input rejection as the supported Browser contract.
