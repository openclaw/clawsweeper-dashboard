## What This Changes

## System Context

OpenClaw’s test-project router maps focused targets, broad test areas, full-suite projects, and CI shards to Vitest configurations. This change gives process-launching CLI coverage a single isolated execution path so child startup and shutdown are measured without contention from the shared CLI test graph.
