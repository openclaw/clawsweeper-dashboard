## Summary

Keep open: current main still rejects the reported Feishu `mediaLocalRoots` config shape and still treats Feishu media upload exceptions as fallback text delivery that looks successful to the caller.

## What This Changes

The issue asks Feishu CLI media sends to honor configured local media roots or fail clearly instead of reporting success when the attachment upload fails.

## Best Possible Solution

Adopt one security-reviewed outbound local-media root contract, then align Feishu schema/docs/tests and make allowlist upload failures surface as explicit failure or explicit partial success.
