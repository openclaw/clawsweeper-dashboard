## Summary

Keep this open: current main still lacks a supported Feishu `mediaLocalRoots` config surface and still converts Feishu media upload errors into a success-shaped fallback text send, while the related Feishu fix PRs are closed unmerged.

## What This Changes

The issue asks Feishu CLI media sends to honor configured local media roots or clearly reject unsupported paths, and to stop reporting success when media upload fails.

## Best Possible Solution

Define one security-reviewed outbound local-media root contract, update Feishu schema/docs/tests if accepted, and make allowlist upload failures surface as failed or explicit partial success instead of normal success.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence reproduction path: current Feishu config still rejects the requested local-root key, and Feishu outbound catches media upload failures and returns a fallback delivery result.

## Solution Assessment

Unclear without maintainer direction. The best fix is not just adding a schema key, because it also changes the local-file security boundary and the user-visible semantics for attachment upload failure.
