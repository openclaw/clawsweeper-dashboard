## Summary

Keep open: current main and v2026.6.11 still do not expose a Feishu `mediaLocalRoots` config contract, and Feishu media upload errors still fall back to a success-shaped text send. ## What This Changes

The issue asks OpenClaw to make Feishu CLI media sends honor configured local media roots or fail clearly instead of reporting success after media upload failure.

## Best Possible Solution

Define a security-reviewed outbound local-media root contract, then update Feishu schema/docs/tests and report media upload failure as either a real failure or explicit partial success.
