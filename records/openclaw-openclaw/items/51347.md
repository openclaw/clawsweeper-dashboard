## Summary

Keep open: current main still does not support the reported `channels.feishu.mediaLocalRoots` config key, and Feishu outbound still turns media-upload exceptions into fallback text delivery that looks successful to the caller. The direct Feishu fix PR was closed unmerged, and the broader filesystem-roots work does not settle Feishu's fallback-success behavior.

## What This Changes

The issue reports Feishu CLI media sends ignoring configured local media roots and reporting success when the requested media upload fails.

## Best Possible Solution

Adopt one security-reviewed outbound local-media root contract, then align Feishu schema/docs/tests and make allowlist upload failures surface as explicit failure or explicit partial success.
