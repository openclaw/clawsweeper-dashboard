## Summary

Keep open: current main and v2026.6.11 still lack a Feishu `mediaLocalRoots` config contract, and the Feishu media send path still turns upload errors into fallback text delivery rather than a clear failed or partial-failure result. The remaining work is real, but it needs maintainer security/product direction before widening host-local media roots or changing fallback semantics.

## What This Changes

The issue requests Feishu CLI media sends to honor configured local media roots or clearly fail/document the unsupported path, and to stop reporting success when media upload fails.

## Best Possible Solution

Define a security-reviewed outbound local-media root contract, then update Feishu schema/docs/tests and delivery reporting so approved media sends work and failed media uploads are reported as failures or explicit partial success.

## Reproduction Assessment

Yes at source level: current main still has no Feishu `mediaLocalRoots` config key and still converts `sendMediaFeishu` errors into fallback text delivery. I did not run a live Feishu credential send in this read-only review.

## Solution Assessment

No for an automatic Feishu-only patch: the safe fix needs a shared, security-reviewed local-root policy plus explicit Feishu media failure semantics instead of silently adding a parallel channel config path.
