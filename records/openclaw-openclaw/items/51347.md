## Summary

Keep open: current main still lacks a Feishu media-local-roots config contract and still converts Feishu media upload failures into a success-shaped fallback text send, so the central issue remains unresolved.

## What This Changes

The issue asks OpenClaw to honor or clearly reject Feishu local-media root configuration and to stop reporting a successful Feishu send when the requested media upload fails.

## Best Possible Solution

Define a security-reviewed outbound local-media-root contract, then align Feishu schema, docs, tests, and media failure reporting around explicit failure or partial-success semantics.

## Reproduction Assessment

Yes, source-level: the Feishu schema lacks mediaLocalRoots, the resolver does not merge Feishu channel roots, and current tests assert fallback success after media upload failure.

## Solution Assessment

No, not as an automatic Feishu-only patch; the durable fix needs maintainer-approved local-root security policy plus explicit Feishu delivery-result semantics.
