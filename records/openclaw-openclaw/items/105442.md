## Summary

Keep this PR open for revision: the prior absent-path probe defect is addressed, but the replacement still collapses an entire path using one directory’s child case behavior, which is unsafe across mixed mount or per-directory case-sensitivity boundaries and also affects trusted executable-directory checks.

## What This Changes

The PR replaces platform-wide agent-directory case folding with a shared filesystem case-sensitivity probe, uses it for safe-bin trust comparisons, and adds focused tests for duplicate agent directories and path probing.

## Best Possible Solution

Use component-aware path identity: preserve real identity for existing prefixes, apply case folding only to components whose parent lookup is case-insensitive, and keep safe-bin trust comparison fail-closed with dedicated mixed-boundary regression coverage.
