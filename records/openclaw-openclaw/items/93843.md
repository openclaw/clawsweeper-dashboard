- **[P2] Retry synthesis title reads before reusing the base slug:** `extensions/memory-wiki/src/apply.ts:256`
  - body: The new collision lookup turns any failed read of the existing base synthesis page into an empty title. Current main retries existing-page reads because one transient failure can otherwise lose user-authored wiki content; here the same transient failure would make a real colliding `syntheses/<slug>.md` look free, so the second title writes back to the bare slug and recreates the silent overwrite. Reuse the existing retry/missing-page semantics for this title lookup and cover a transient collision read failure.
  - confidence: 0.83

Keep the source path aligned with the existing retry behavior before treating the slug as unoccupied.
