## Summary

Keep this PR open for normal maintainer merge consideration. The scoped change uses the existing trusted environment-proxy preset for KiloCode’s pinned official catalog endpoint, matches four recently merged provider-local fixes, retains the hostname policy and fallback path, and has credible real before/after CLI proof plus green CI.

## What This Changes

This PR makes KiloCode’s live model-catalog request honor eligible `HTTPS_PROXY`/`HTTP_PROXY` settings, allowing proxy-only networks to receive the live Kilo Gateway model list rather than the static fallback catalog.

## System Context

The KiloCode extension contributes provider models to OpenClaw’s model-listing and runtime setup. Its live catalog request is guarded by an allowlisted HTTP policy; the resulting models are used when discovery succeeds and a bundled static catalog remains the fallback.
