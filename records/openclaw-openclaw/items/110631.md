## Summary

Keep this PR open: the proposed Quick Chat features are not already on current main, but the embedded reply view still renders a second disabled composer and the recent-session query can omit the most recently updated sessions when old sessions are pinned. The PR also needs the promised after-fix macOS interaction proof before merge; the `maintainer` label requires human handling rather than automated cleanup.

## What This Changes

The PR adds streamed replies to macOS Quick Chat and lets users target one of five recent sessions from a history menu.

## Best Possible Solution

Keep the shared chat reuse, add a composer-free display mode for the embedded transcript, request genuinely recency-ordered sessions from the gateway, and attach redacted macOS proof that shows a selected recent target and a streamed reply in the bar.
