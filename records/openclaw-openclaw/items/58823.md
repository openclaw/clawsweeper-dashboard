## Summary

Keep this PR open. Current main already applies the documented global-subagent-default precedence in the direct native spawn planner, but the shared `agent-scope` helper and isolated cron/fallback consumers still prefer the agent primary model before `agents.defaults.subagents.model`, so the branch still carries meaningful unique work rather than obsolete churn.

## What This Changes

The branch changes shared subagent model selection to prefer per-agent subagent model, then global `agents.defaults.subagents.model`, then the agent primary model, and updates agent/cron tests plus a proof script.

## Best Possible Solution

Land this focused helper/cron precedence fix after maintainers accept the documented global-default-before-agent-primary contract and coordinate it with the broader runtime/session persistence work.

## Solution Assessment

Yes, for the remaining helper/cron mismatch. Reordering the shared helper is the narrowest maintainable fix; the only safer alternative is a maintainer decision to keep agent-primary precedence and update docs/tests consistently instead.
