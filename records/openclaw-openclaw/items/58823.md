## Summary

Keep open: current main and the latest release still leave the shared agent-scope helper selecting an agent primary model before the global subagent default, while this PR is the focused candidate for that remaining helper and cron path.

## What This Changes

The branch reorders shared subagent model selection so per-agent subagent config wins first, global `agents.defaults.subagents.model` wins second, and the agent primary model is the fallback, with focused agent/cron tests and a proof script.

## Best Possible Solution

Land this PR or a narrow equivalent if maintainers accept the documented precedence; otherwise update source, tests, and docs to one canonical model-routing rule.

## Reproduction Assessment

## Solution Assessment

Yes, pending maintainer acceptance of the compatibility tradeoff. Reordering the shared helper is the narrowest maintainable fix for the remaining cron/fallback path because the direct native resolver is already aligned.
