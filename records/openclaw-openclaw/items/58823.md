## Summary

Keep this PR open: current `main` still has the shared `agent-scope` helper and isolated cron consumer using the agent primary before the global subagent default, while this PR directly targets that remaining mismatch. The native spawn resolver part is already fixed on `main`, so the remaining review question is compatibility-sensitive maintainer acceptance and sequencing, not cleanup closure.

## What This Changes

This PR reorders shared subagent model selection so per-agent subagent config wins first, `agents.defaults.subagents.model` wins second, and the agent primary is only the fallback, with matching agent/cron tests and a proof script.

## Best Possible Solution

Land this PR or a narrow equivalent if maintainers accept the documented precedence, and keep broader runtime/session persistence work tracked separately in https://github.com/openclaw/openclaw/pull/72984.

## Reproduction Assessment

Yes. Source inspection on current `main` shows `resolveSubagentModelConfigSelectionResult` places `agentConfig.model` before `agents.defaults.subagents.model`, and isolated cron calls that helper.

## Solution Assessment

Yes, pending maintainer acceptance of the compatibility tradeoff. Moving the shared helper and matching cron tests to the same precedence as the native resolver is the narrowest code fix; broader runtime persistence belongs to the related open PR.
