## Summary

Keep this PR open for maintainer review: current main still leaves the shared `agent-scope` helper using agent-primary-before-global-subagent precedence, and isolated cron consumes that helper, while this branch is the focused open fix with sufficient real behavior proof.

## What This Changes

The PR reorders shared subagent model selection so per-agent subagent config wins first, `agents.defaults.subagents.model` wins second, and the agent primary model is the fallback, with agent/cron regression tests and a proof script.

## Best Possible Solution

Land this focused helper and cron precedence change if maintainers accept the documented global-default-before-agent-primary contract; otherwise update docs and tests to the agent-primary contract and coordinate broader runtime persistence separately.

## Reproduction Assessment

Yes. Source inspection on current main shows `resolveSubagentModelConfigSelectionResult` evaluates `agentConfig.model` before `agents.defaults.subagents.model`, and isolated cron calls that helper.

## Solution Assessment

Yes, pending maintainer acceptance of the compatibility tradeoff. Moving the shared helper to per-agent subagent -> global subagent default -> agent primary is the narrowest fix for the remaining helper/cron mismatch, while broader runtime persistence belongs with https://github.com/openclaw/openclaw/pull/72984.
