## Summary

Keep this PR open: current main and the latest release still have the shared `agent-scope` helper, its cron consumer, and cron fallback tests using agent-primary-before-global-subagent-default ordering, while this PR directly targets that remaining mismatch with proof.

## What This Changes

This PR changes shared subagent model selection and cron-related coverage so per-agent subagent config wins first, the global subagent default second, and the agent primary last, with a proof script and regression tests.

## Best Possible Solution

Land this narrow helper and cron precedence fix if maintainers accept the docs-backed rule; otherwise update source tests and docs to make agent-primary precedence explicit, then close the linked report and PR with that product decision.
