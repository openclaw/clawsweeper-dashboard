## Summary

Keep open: current main and the latest release still leave the shared agent-scope helper and isolated cron consumer preferring the agent primary over the global subagent default, while this PR is the open narrow candidate for that remaining mismatch.

## What This Changes

The PR reorders shared subagent model config selection and cron-related tests so per-agent subagent config wins first, global subagent defaults second, and the agent primary last, with a proof script covering the resolver behavior.

## Best Possible Solution

Land this narrow helper/cron fix if maintainers accept the docs-backed precedence, and coordinate it with the broader runtime/session PR so the final model-routing contract stays consistent.

## Solution Assessment

Yes, pending maintainer acceptance of the compatibility tradeoff. Updating the shared helper and aligned cron tests is the narrowest maintainable fix for the remaining precedence mismatch, while broader runtime/session persistence belongs in https://github.com/openclaw/openclaw/pull/72984.
