## What This Changes

This PR adds an optional W3C `traceparent` field to authenticated Gateway WebSocket request frames, propagates valid values into request-scoped diagnostic tracing, updates native client models, and documents the protocol.

## System Context

Gateway WebSocket clients authenticate, then submit individual RPC request frames to the Gateway dispatcher. The dispatcher validates each frame and invokes agent or system handlers; this PR lets one authenticated request carry upstream trace context into the diagnostic spans produced by that request.
