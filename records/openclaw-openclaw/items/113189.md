## What This Changes

This PR adds an optional W3C `traceparent` field to authenticated Gateway WebSocket request frames, carries valid values into request-scoped diagnostic tracing, updates native request models, and documents the behavior.

## System Context

Gateway WebSocket clients authenticate once and then send independent RPC request frames. The Gateway validates each frame, dispatches the request into agent/provider work, and emits diagnostic traces around that work.

  Validate --> Trace[Request-scoped trace context]
  Trace --> Dispatch[Gateway request dispatch]
  Dispatch --> Runtime[Agent and provider work]
  Runtime --> Telemetry[Diagnostic trace output]
