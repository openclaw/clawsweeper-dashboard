  - body: This worker config leaves `tools.fs.workspaceOnly` unset, whose default permits absolute and parent-relative paths outside `assignment.workspaceDir`.   - body: The command writes one machine-readable JSON result to stdout, but its policy still does not declare protocol stdout ownership. Any startup or runtime diagnostic can corrupt the result consumed by the orchestrator; set `ownsProtocolStdout: true` as other protocol commands do.
  - confidence: 0.99

  - body: An abort while the socket is reconnecting makes `requestInferenceCancel()` reject before sending, and that rejection is suppressed while the gateway provider operation continues. Queue or retry the cancel after readiness, or otherwise cancel it gateway-side, before finalizing the worker abort.
  - confidence: 0.96
