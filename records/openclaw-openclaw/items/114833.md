## What This Changes

This PR adds bounded, five-second memoization for local Claude session discovery and JSON metadata parsing so repeated catalog polls avoid re-walking transcript files.

## System Context

The Anthropic extension reads Claude Desktop/CLI session files from the local home directory to populate OpenClaw's session catalog. Catalog polling feeds session-selection and transcript-opening flows, so cache invalidation must reduce filesystem work without hiding newly created or updated sessions.
