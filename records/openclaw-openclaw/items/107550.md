## Summary

Current main does not contain the reported hashing implementation: gateway password authentication compares the configured and supplied plaintext secrets with a bounded constant-time byte comparison, so the claimed CPU-bound hash and thread-pool starvation path is absent.

## What This Changes

Investigate and replace allegedly synchronous gateway password hashing with asynchronous validation to avoid event-loop stalls during login bursts.

## Best Possible Solution

Keep the existing constant-time shared-secret comparison; if gateway disconnects are observed under load, open a new report with a current SHA, reproducible load profile, event-loop-delay measurements, and a trace identifying the actual blocking call.
