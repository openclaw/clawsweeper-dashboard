## Summary

Keep open: current main and the latest release still return a usable shared GitHub Copilot API-token cache before the requesting GitHub credential affects the exchange, and the open linked repair PR should remain the fix path until it lands or is replaced.

## What This Changes

The issue reports that GitHub Copilot profile rotation reuses one shared cached Copilot API token across profiles, so a rate-limited account can keep blocking rotated profiles.

## Best Possible Solution

Keep this issue open until the linked PR lands, is adopted, or is replaced by an equivalent focused fix that scopes the Copilot API-token cache to the requesting GitHub credential and covers legacy cache refresh.
