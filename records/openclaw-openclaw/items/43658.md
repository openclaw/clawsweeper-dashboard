## Summary

Keep open: current main and the latest release still reuse a usable shared GitHub Copilot API-token cache before the selected GitHub credential affects token exchange, and the same-repository closing PR is still open rather than merged.

## What This Changes

The issue reports that GitHub Copilot auth-profile rotation is defeated because all profiles share one cached Copilot API token.

## Best Possible Solution

Land or replace `https://github.com/openclaw/openclaw/pull/43659` with an equivalent focused fix that binds the Copilot API-token cache to the requesting GitHub credential and covers legacy cache refresh.
