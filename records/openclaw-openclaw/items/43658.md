## Summary

Keep open: current main and the latest release still return a usable shared GitHub Copilot API-token cache entry before the selected GitHub credential affects token exchange, and the same-repository fix candidate remains open rather than merged.

## What This Changes

The issue reports that GitHub Copilot multi-profile rotation reuses a single cached Copilot API token across profiles after rate limits.

## Best Possible Solution

Bind cached Copilot API tokens to the source GitHub credential or auth profile in src/plugin-sdk/provider-auth.ts, add regression coverage for profile-switch cache misses, and resolve this issue through the linked PR or a narrow replacement.
