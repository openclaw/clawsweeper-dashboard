## Summary

Keep open: current main and v2026.6.11 still return a valid shared GitHub Copilot API-token cache entry before the rotated GitHub credential affects token exchange, and the same-repository fixing PR remains open rather than merged.

## What This Changes

The issue reports that GitHub Copilot profile rotation reuses one cached Copilot API token across distinct GitHub PAT auth profiles, defeating rate-limit failover.

## Best Possible Solution

Refresh or replace the linked fix so src/plugin-sdk/provider-auth.ts validates the cached Copilot API token against the source GitHub token/profile, preserves safe legacy-cache miss behavior, and adds regression coverage for same-token cache hit, different-token miss, and legacy no-fingerprint miss.
