## Summary

Keep open: current main and the latest release still return a usable shared GitHub Copilot API-token cache entry before the selected GitHub credential affects token exchange, and the linked same-repository fix PR remains open rather than merged.

## What This Changes

The issue reports that GitHub Copilot profile rotation can select a new auth profile while `resolveCopilotApiToken` still returns a shared cached Copilot API token from another profile.

## Best Possible Solution

Land or replace the linked PR with a focused fix that scopes the Copilot API-token cache to the requesting GitHub credential and covers legacy cache refresh.
