## What This Changes

Prevent message reads with invalid or unrecognized target-like input from silently reading the current-context channel, and make the effective read scope observable.

## Best Possible Solution

Fail reads when explicit target-like input cannot be resolved, retain context inference only when the caller supplied no target intent, and expose the effective read scope through one canonical result path if that can be additive across channels.
