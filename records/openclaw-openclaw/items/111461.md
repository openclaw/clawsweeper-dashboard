## Summary

Keep this issue open: current main exposes `cwd` but not the requested native child `workspace` boundary or workspace-only skill lineage, and the same author’s open draft PR is the active implementation candidate. The proposal crosses persisted session, bootstrap, skill-discovery, and least-privilege boundaries, so it needs explicit maintainer product and security direction before the PR can be treated as the best fix.

## What This Changes

Add a native-only `sessions_spawn` workspace parameter that confines a child to a validated descendant workspace and exposes only skills from that workspace.

## Best Possible Solution

Define one native-only, fail-closed workspace-isolation contract that validates a target-agent descendant, persists the effective workspace and skill-root policy together, leaves ordinary native and ACP behavior unchanged, and is proven in a real multi-turn child run before landing.
