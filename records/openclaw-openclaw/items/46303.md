- **[P1] Count summary backlog before declaring queues drained:** `src/auto-reply/reply/queue/drain-all.ts:21-22`
  - body: `waitForFollowupQueueDrain` only counts `items.length` plus a draining sentinel, but the real drain loop keeps working while `queue.droppedCount > 0` to deliver overflow summaries. During restart, a queue with only summarized backlog can return `drained: true`, allowing shutdown to drop those queued messages; mirror the drain predicate and add a summary-only regression test.
  - confidence: 0.91

  - confidence: 0.88
