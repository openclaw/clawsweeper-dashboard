  - body: `ChannelRunQueue` is exported through public plugin SDK subpaths, so adding `enqueueInternal` exposes the gateway-drain bypass to plugin code. Keep this restart-only authority behind a core-private wrapper or get an explicit SDK contract with compatibility tests before exposing it.
  - confidence: 0.88

Across in-process reloads that can retain stale channel closures and let future restart sweeps flush old handlers instead of only live ingress.
