Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Count summary backlog before declaring followups drained:** `src/auto-reply/reply/queue/drain-all.ts:21-22`
  - body: `waitForFollowupQueueDrain` only counts queued items plus the active-drain sentinel, but the actual drain loop continues while `queue.droppedCount > 0` to deliver overflow summaries. A restart with only summarized backlog can pass this wait and continue shutdown before that summary follow-up runs, so include summarized backlog in the pending count and test it.
  - confidence: 0.91
- **[P1] Keep restart-drain bypass out of the plugin SDK:** `src/plugin-sdk/channel-lifecycle.core.ts:33-36`
  - body: `ChannelRunQueue` is exported through public plugin SDK subpaths, so adding `enqueueInternal` exposes the gateway-drain bypass to plugins instead of keeping it core-owned. Third-party code could enqueue after draining starts and weaken the restart shutdown boundary; keep this as private core plumbing or an injected non-SDK runtime handle.
  - confidence: 0.88
