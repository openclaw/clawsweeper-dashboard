## Summary

This PR has strong real benchmark evidence for reducing startup work, but its new workspace alias-map cache omits a resolution input that can change alias targets. Keep it open for a narrow compatibility repair and regression test before merge.

## What This Changes

The branch reduces gateway startup memory by sharing plugin SDK alias maps, removing post-ready dashboard-handler prewarming, and adding heap-profile support to the startup benchmark.

## System Context

Gateway startup loads installed plugins through the Plugin SDK resolver, which constructs aliases for plugin imports. Gateway RPC methods are served through lazy handler families, affecting both headless startup cost and the first request from the Control UI.
