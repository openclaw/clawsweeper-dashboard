## Summary

Keep open: current main covers mechanical `/new` and `/reset` session-memory capture, startup loading of date-prefixed memory files, and shipped sanitization of saved excerpts, but the requested synthesis, durable-fact filtering, transcript anchoring, and default security policy are still unresolved product work.

## What This Changes

Request automatic session memory preservation across resets, with transcript export, synthesized summaries, durable facts, links back to full conversation records, and startup hydration.

## Best Possible Solution

Maintainers should decide the memory product boundary first, then either sponsor a bounded core/default memory path with sanitized synthesis and transcript receipts or route optional world-model/MCP implementations to ClawHub.
