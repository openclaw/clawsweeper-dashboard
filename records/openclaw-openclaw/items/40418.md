The issue requests automatic preservation, transcript linkage, and synthesis of session memory across `/new` resets.

## Best Possible Solution

Define a bounded, privacy-aware reset memory design that reuses existing memory flush and startup-context paths where appropriate, while keeping richer retention workflows plugin-friendly unless a core API gap is proven.
