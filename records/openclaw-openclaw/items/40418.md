## Summary

Keep open: current main now covers mechanical `/new` and `/reset` session-memory capture, startup loading of date-prefixed memory files, and shipped sanitization of saved excerpts, but it still does not synthesize durable facts, generate transcript anchors, or settle the default privacy/security policy for automatic reset memory. The posted `world-model-mcp` workaround is useful evidence that this can live outside core, but it does not close the OpenClaw product-boundary decision.

## What This Changes

The issue requests automatic session-memory preservation and synthesis across `/new` resets, including durable summaries and links back to full transcripts.

## Best Possible Solution

Maintainers should decide the memory product boundary first, then either sponsor a bounded core/default path with sanitized synthesis and transcript receipts or route optional world-model/MCP implementations to ClawHub/plugin distribution.
