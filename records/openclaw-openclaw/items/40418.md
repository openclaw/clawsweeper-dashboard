## Summary

Keep open: current main and v2026.6.11 already cover basic `/new` and `/reset` session-memory capture, but the requested synthesis, transcript-linking, storage shape, and privacy/security contract remain unresolved product work.

## What This Changes

The issue requests automatic preservation and synthesis of session memory when a session is reset, including durable summaries and links to full transcripts.

## Best Possible Solution

Keep this open for maintainer scoping of the synthesis/linking contract, using the existing session-memory hook and memory plugins for the already-shipped basic preservation behavior.
