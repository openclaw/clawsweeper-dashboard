## Label Justifications

- `P2`: The issue describes real memory/session continuity gaps in normal use, but the remaining work is a product/security design rather than an emergency runtime failure.

## Summary

Keep open: current main partially preserves sanitized recent transcript excerpts on `/new` and `/reset`, and an external MCP/plugin implementation covers some workflows, but OpenClaw still does not implement the requested structured synthesis, startup hydration, and linked transcript memory contract.

## What This Changes

Request automatic session memory preservation on reset, full transcript export, startup synthesis into daily memory, and links between summaries and transcripts.

## Best Possible Solution

Define one maintainer-approved memory-continuity contract that keeps core lean, uses plugin/MCP paths where sufficient, and adds only explicit opt-in reset/startup synthesis or hook APIs with privacy, timeout, dedupe, and tests.
