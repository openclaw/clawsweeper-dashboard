## Summary

Keep open: current main preserves sanitized recent-message excerpts for `/new` and `/reset`, loads recent memory files on the next model turn, and exposes reset hooks for plugins, but the requested durable-fact synthesis, transcript anchoring, and default privacy/security policy remain unresolved product work. The `world-model-mcp` comment shows an external MCP route is viable for some users, but it does not settle what OpenClaw should persist and re-inject by default.

## What This Changes

The issue requests automatic session memory preservation and synthesis around `/new` so useful context survives session resets.

## Best Possible Solution

Maintainers should decide the memory product boundary first, then either sponsor a bounded core/default memory path with sanitized synthesis and transcript receipts or route optional world-model/MCP implementations to ClawHub/plugin packaging.
