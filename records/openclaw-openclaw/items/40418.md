## Summary

Keep open: current main now captures sanitized recent transcript excerpts on manual `/new` and `/reset` and can hydrate recent memory files on reset/startup model runs, but it still does not implement the requested structured synthesis, durable-fact filtering, transcript anchoring, or privacy/security policy for automatic memory continuity.

## What This Changes

The issue requests automatic session memory preservation and synthesized continuity memory across `/new` resets, including durable summaries and links back to full transcripts.

## Best Possible Solution

Define a maintainer-approved memory-continuity contract: keep synthesis plugin/MCP-owned where current seams are enough, and add only explicit opt-in core lifecycle/API support with redaction, retention, dedupe, audit, startup-context limits, and focused tests where the plugin path cannot cover the workflow.
