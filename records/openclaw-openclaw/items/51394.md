Design this in the browser plugin as an explicit network-inspection capability with security review, redaction/permission policy, profile capability matrix, wrapped outputs, and reuse of the existing /requests and /response/body infrastructure where appropriate.

## Risks / Open Questions

- A model-facing network interception API can expose cookies, authorization headers, tokens, request bodies, response bodies, and private endpoints unless redaction, permissions, and output wrapping are designed first.
