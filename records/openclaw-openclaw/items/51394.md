## Summary

Keep open: current main and v2026.6.11 still lack a model-facing browser Network/CDP interception action. Existing lower-level request listing and bounded response-body capture are useful infrastructure, but the remaining model-facing API needs maintainer/security direction before implementation.

## What This Changes

Request to expose CDP Network-domain request listing, response monitoring, and request interception through the model-facing browser tool API.

## Best Possible Solution

Design this as a browser-plugin network-inspection capability with explicit sensitive-data policy, per-profile support, redaction, permissions, wrapped output, and reuse of existing `/requests` and `/response/body` paths where they fit.
