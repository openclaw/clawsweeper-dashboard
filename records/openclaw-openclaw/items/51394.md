## Summary

Keep open: current main and v2026.6.11 still expose request listing and bounded response-body capture only through the browser control/CLI layer, while the model-facing browser tool schema and act-kind parser have no network/intercept action. This remains a new security-sensitive browser capability, not conservative cleanup.

## What This Changes

Request to add a model-facing browser network action/API for CDP Network-style request capture/interception so agents can inspect SPA fetch/XHR traffic.

## Best Possible Solution

Design a browser-plugin network inspection API that reuses the current Playwright /requests and /response/body infrastructure where possible, returns bounded/redacted model-facing output, and puts active interception or mutation behind explicit maintainer-approved permissions and profile support.

## Reproduction Assessment

Yes. Source inspection reproduces the missing surface: the model-facing browser tool schema and act-kind parser do not expose network, requests, responsebody, or intercept actions, while lower control routes only expose passive request listing and bounded response-body capture.

## Solution Assessment

No, not as the raw proposed API yet. The maintainable path is a maintainer-designed browser plugin capability with explicit security boundaries, profile support, redaction, and bounded output rather than directly exposing broad CDP Network interception to agents.

## Risks / Open Questions

- A model-facing network interception API can expose cookies, authorization headers, tokens, private API endpoints, request bodies, and response bodies from authenticated browser sessions unless redaction, permission, and output-wrapping rules are designed first.
- Active interception or request mutation is stronger than the existing passive /requests listing and bounded /response/body capture, so it changes the browser tool security boundary.
- Managed, raw/remote CDP, node-hosted, sandbox, and existing-session profiles have different network/control capabilities; a single action shape could overexpose data or fail inconsistently without a profile capability matrix.
