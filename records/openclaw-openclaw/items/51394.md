## Summary

Keep open: current main and v2026.6.11 still lack a model-facing browser Network/CDP capture or interception action, while the existing lower-level routes only provide passive request listing and bounded response-body capture.

## What This Changes

Requested browser tool support for CDP Network-domain request capture/interception so automation can inspect SPA network traffic beyond fetch monkey-patching.

## Best Possible Solution

Design this as a browser-plugin network inspection capability with explicit sensitive-data policy, a profile capability matrix, permission/redaction rules, wrapped model-facing output, and reuse of existing request-listing and response-body paths where they fit.
