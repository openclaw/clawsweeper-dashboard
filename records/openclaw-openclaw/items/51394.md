Keep open: current main still lacks a model-facing Browser tool action for request listing, response-body access, or active interception. ## Best Possible Solution

Design a bounded Browser plugin network-inspection contract with explicit redaction, permissions, profile support, output wrapping, and tests, reusing the existing /requests and /response/body infrastructure where it fits before considering active interception.
