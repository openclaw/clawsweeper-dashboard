## Summary

Keep open: current main and v2026.6.11 still do not expose a model-facing browser Network/CDP request-listing or interception action, and the existing CLI/control routes only cover passive operator debugging paths.

## What This Changes

Expose Chrome DevTools Protocol Network-domain request capture and interception through the browser tool so agents can inspect SPA API traffic.

## Best Possible Solution

Design a browser-plugin network inspection capability that wraps existing passive routes where possible, defines redaction and permission policy, documents the profile support matrix, and treats active interception or mutation as an explicit maintainer-approved security boundary.
