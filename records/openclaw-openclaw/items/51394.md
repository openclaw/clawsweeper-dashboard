## Summary

Keep open: current main and v2026.6.11 still do not expose a model-facing browser Network/CDP request-interception action, while the existing lower-level request listing and response-body routes only cover part of the requested capability.

## What This Changes

The issue requests model-facing browser tool support for CDP Network-domain request capture, listing, and interception so agents can inspect SPA API traffic.

## Best Possible Solution

Design this as a browser-plugin network inspection capability with explicit sensitive-data policy, profile capability matrix, permission/redaction rules, wrapped model-facing output, and a passive-first path that reuses existing request and response-body infrastructure before considering active interception.
