## Summary

Keep this PR open for maintainer review: the patch appears technically sound and well proven, but it intentionally changes the shipped OpenAI batch-transcription auth contract from API-key-only to permitting selected Codex OAuth bearer credentials on native OpenAI endpoints; current provider documentation still describes non-agent OpenAI APIs as API-key-authenticated. ([github.com](https://github.com/openclaw/openclaw/blob/main/src/agents/model-auth.ts))

## What This Changes

Allows selected OpenAI OAuth profiles to authenticate native OpenAI batch audio transcription, preserves environment API-key precedence, keeps custom endpoints API-key-only, and expands auth/media regression coverage.

## Best Possible Solution

Accept the native-endpoint OAuth exception, preserve environment API-key precedence and the custom-endpoint deny boundary, document batch STT as the explicit non-agent OAuth exception, then rebase and repeat the focused tests plus OAuth-only CLI smoke proof.
