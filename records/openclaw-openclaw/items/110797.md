## Summary

Keep this PR open: the restart-safe ownership approach is plausible and has strong live proof, but the new CDP close path appears not to retire manually closed tabs because its real protocol error text is not classified as ignorable. That leaves durable rows retrying forever and is a merge blocker before the shared-browser cleanup semantics can be accepted.

## What This Changes

The PR persists ownership-verified browser-tool tabs in plugin SQLite and rehydrates them after Gateway restart so lifecycle and selected idle/cap cleanup can close only OpenClaw-created tabs.

## Best Possible Solution

Normalize the CDP absent-target response into the existing terminal not-found outcome, add regression coverage using the real protocol text, and choose a bounded retirement policy for durable records that cannot re-establish browser identity without ever adopting user tabs.
