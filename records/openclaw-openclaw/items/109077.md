## Summary

Keep this PR open. The file-first download is the right hardening direction, but the branch silently reduces the existing non-root runner deadline from 300 seconds to 120 seconds, which can turn a previously successful CI download into a failure; the supplied proof also remains a hermetic stalled-transfer test rather than a successful real non-root Docker run.

## What This Changes

The PR replaces the non-root installer runner’s timeout-bounded `curl | bash` pipeline with a temporary-file download before execution and refactors installer-runner regression coverage.

## Best Possible Solution

Keep the file-first, execute-only-after-success design, preserve the current 30-second connect and 300-second total limits unless a maintainer deliberately approves tighter limits, and add a redacted successful non-root Docker smoke transcript before merge.
