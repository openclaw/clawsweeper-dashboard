## Summary

The Help flyout is a coherent UI simplification, and the latest head appears to resolve the earlier click-toggle, narrow-viewport placement, and unrelated baseline concerns. One current-head layout blocker remains: the agent menu height is capped against the viewport rather than the space above its bottom-anchored trigger, so short desktop windows can still hide the menu’s top rows.

## What This Changes

The PR moves four agent-menu help links into a localized Help flyout and adjusts agent-list scrolling, responsive placement, menu styling, icons, and focused component tests.

## Best Possible Solution

Keep the flyout design, but derive the menu’s maximum height from the space above its actual footer anchor, retain the independently scrolling agent list, and add focused short-height coverage proving the title, filter, and first agent row remain reachable.
