The Help submenu is a focused, well-proven desktop improvement, but the final CSS still permits a long bottom-anchored agent menu to extend above a short viewport, leaving its upper controls unreachable. This concrete responsive regression should be fixed before merge.

## Best Possible Solution

Keep the compact Help flyout, but constrain the bottom-anchored menu to the actual vertical space above its trigger—preserving a safe root cap if necessary—while retaining scrolling in the agent list, then add short-height long-roster browser coverage.
