## Summary

Keep open: current main still persists `models auth login` profiles to the local agent store and only asks a running gateway to refresh status; the linked guard fix remains open and unmerged.

## What This Changes

The issue asks OpenClaw to prevent `openclaw models auth login` on a remote node host from silently writing OAuth credentials to the node-local auth store instead of the gateway.

## Best Possible Solution

Land a focused guard that blocks `models auth login` on non-loopback node-host configs using shared loopback semantics, with a clear gateway-host instruction and regression coverage.
