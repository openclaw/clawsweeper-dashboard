## Summary

Keep open: current main and v2026.6.11 still allow `models auth login` to persist provider OAuth profiles to the local agent store, while the only open closing PR is still unmerged and currently conflicting.

## What This Changes

The issue asks OpenClaw to stop node-host `models auth login` from silently writing OAuth credentials only on the node when model execution uses a remote gateway.

## Best Possible Solution

Land a focused fix that detects remote node-host context before provider auth writes and blocks with clear gateway-host instructions unless maintainers explicitly approve a gateway-owned credential-forwarding RPC.
