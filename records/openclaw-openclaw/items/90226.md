## What This Changes

The PR preserves the existing daily reset default for unconfigured thread sessions and adds a persisted `sessionClosedAt` marker so externally closed Discord threads roll into a new session even under no-expiry idle policies.

## System Context

OpenClaw stores the active transcript identity and lifecycle timestamps for each routed conversation in a session entry. Channel events such as Discord thread closure feed that state, while reply, Gateway, command, cron, and plugin-runtime paths decide whether to reuse or roll over the session.
