## Summary

Close as implemented: v2026.6.11 and current main include cooperative yielding in the OpenAI-compatible and Responses streaming loops, with bursty-stream regression coverage for the DeepSeek-style transport that this issue reported.

The issue reports that very long DeepSeek/OpenAI-compatible streaming responses can monopolize the Gateway event loop and delay timers, WebSocket RPCs, sidecars, and chat history.

## Best Possible Solution

Keep the shipped cooperative stream-yield implementation for OpenAI-compatible long responses, while leaving adjacent timeout-diagnostics and channel-deadline work to their narrower open items.
