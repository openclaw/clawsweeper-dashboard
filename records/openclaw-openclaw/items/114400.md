## What This Changes

This PR changes npm post-publish verification so every bundled extension required by the package artifact contract must have a manifest, including when the entire installed extensions directory is absent.

## System Context

OpenClaw’s release verification installs the published npm package and inspects its bundled extension artifacts before release publication is trusted. The verifier compares the installed `dist/extensions` tree with the canonical build artifact list and reports package omissions that would otherwise remove a bundled provider from an installed release.
