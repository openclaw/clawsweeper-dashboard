## Summary

Current main still violates the documented JSON5 editing contract: every normal config mutation prepares the correct semantic object, then replaces the authored document with plain JSON, deleting comments and commented-out settings. No active issue or pull request owns this core fix; the merged `oc-path` work is useful reference for patch-based editing but is plugin-local, JSONC-focused, and does not change canonical config persistence.

## What This Changes

Preserve user-authored JSON5 comments and commented-out settings when OpenClaw rewrites `openclaw.json`.

## Best Possible Solution

Add a JSON5-compatible lossless mutation stage inside the canonical config writer, preserving untouched authored text while retaining every existing semantic preparation and atomic-commit safeguard.
