  - body: The workspace schema now accepts `stream` and `computed`, but the agent tool schema used by `dashboard_widget_add` and `dashboard_widget_update` still only allows `rpc`, `file`, and `static`. Agents therefore cannot create or update widgets with the new binding kinds through the dashboard control plane, leaving the feature reachable only through lower-level/raw paths; add the new binding shapes here and cover the write tools with focused tests.   - confidence: 0.86
- **[P2] Do not depend on binding insertion order:** `ui/src/pages/plugin/dashboard-view.ts:290-292`
  - body: Computed bindings are evaluated only when `Object.values(widget.bindings)[0]` happens to be the computed binding. The schema allows multiple bindings without requiring that order, so a valid widget whose computed binding is declared after its inputs silently renders the first leaf binding and never computes the derived value; make the primary binding explicit or validate/enforce the order before accepting these bindings.
  - confidence: 0.74
