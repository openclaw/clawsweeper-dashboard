## Summary

## What This Changes

The branch marks ClickClack discussion embed URLs as host-theme aware, supplies Control UI theme tokens before iframe paint, and streams later palette updates to the authenticated cross-origin discussion iframe.

## System Context

The Control UI obtains a discussion embed URL from the ClickClack plugin and renders it in a session sidebar. This patch lets explicitly capable ClickClack embeds receive the host’s initial semantic palette and later updates while leaving other provider URLs opaque.
