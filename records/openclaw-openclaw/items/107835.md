## What This Changes

The PR configures Slack health probes with the probe deadline, no SDK retries, and immediate rate-limit rejection, and adds loopback transport regressions that verify sockets close on stalled and trickling responses.

## System Context

Slack health checks call Slack’s `auth.test` through the Slack Web API client, then convert that result into OpenClaw’s shared channel-probe result for diagnostics. This PR changes the Web API client transport policy so the same deadline that bounds the diagnostic also cancels the underlying request.
