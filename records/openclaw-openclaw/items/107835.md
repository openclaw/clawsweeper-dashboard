## System Context

Slack health checks call the Slack `auth.test` API through a dedicated read-only client and turn the result into channel diagnostics. The probe’s client timeout, retry, and rate-limit policy determines whether diagnostics return inside their deadline and whether network activity can continue after the result is reported.
