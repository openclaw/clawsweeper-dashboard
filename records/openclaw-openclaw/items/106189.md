## Summary

Keep open: npm 12’s documented array-only `npm view --json` output conflicts with the current object-only metadata parser, and the reported fallback escalates that compatibility failure by disabling healthy provider plugins and removing activation state.

## What This Changes

Make npm plugin metadata resolution compatible with npm 12 and keep existing plugins enabled when an update fails before modifying the installation.

## Best Possible Solution

Normalize npm 11 object and npm 12 array responses against the requested selector, then make metadata/pre-install failures skip the update while preserving the existing install, enabled entry, and allowlist membership.

Yes, with a narrow refinement: support both documented response shapes and preserve the last known-good plugin on read-only preflight failure; do not add a config switch or broadly suppress genuine post-install failures.

## Repair Work Prompt

Fix the npm 12 plugin lifecycle regression reported in https://github.com/openclaw/openclaw/issues/106189. Update `normalizeNpmViewMetadata`/`resolveNpmSpecMetadata` to accept npm 11 object output and npm 12 array output, selecting the entry that matches the requested exact version or dist-tag resolution deterministically and rejecting ambiguous or malformed multi-entry results with an actionable error. Then change plugin update/update-repair handling so failures occurring before any replacement artifact is installed leave the existing plugin files, `plugins.entries.<id>.enabled`, `plugins.allow`, and install record unchanged. Preserve current fail-closed behavior for failures after a mutation when the existing artifact cannot be proven healthy. Add focused regression tests for object output, one-element array output, relevant multi-entry output, malformed arrays, and an npm metadata preflight failure against an enabled allowlisted plugin. Do not add a config option, runtime compatibility shim, or CHANGELOG.md entry. Keep the repair generic for npm output contracts rather than hardcoding npm 12 or official plugin ids.
