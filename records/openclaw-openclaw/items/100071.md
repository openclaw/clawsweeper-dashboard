## Summary

## What This Changes

The issue requests warnings, visibility, optional fail-closed policy, and doctor linting for workspace skills that shadow same-named plugin or bundled skills.

## Best Possible Solution

Add first-class shadow metadata during skill loading, surface it in `openclaw skills list`, Control UI, and doctor lint, keep documented precedence as the default, and gate any fail-closed policy behind maintainer-approved config, docs, and tests.

Unclear as final implementation. Collision metadata and visibility are the right first step, but fail-closed shadow denial is a compatibility-sensitive config decision that maintainers should approve before implementation.
