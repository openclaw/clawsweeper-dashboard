## Risks / Open Questions

- The implementation must preserve operator.admin authorization, terminal-session ownership, and strict routing to the session's bound Gateway or paired node.

- Shell-path insertion must remain paste-only and safely handle POSIX, PowerShell, cmd.exe, Windows drive paths, UNC paths, and expansion characters without accidental execution.
- Paired-node capability negotiation must keep older nodes functional while clearly disabling uploads when the remote protocol does not support them.
