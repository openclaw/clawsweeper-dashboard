## What This Changes

The PR shares one skill-authoring prompt across four proposal-writing surfaces and replaces topic-bucket correction capture with generated names, trigger-first descriptions, imperative proposal bodies, and verification guidance.

## System Context

OpenClaw’s self-learning system converts corrections, session history, and the `/learn` command into pending reusable skill proposals. Proposal names and descriptions are used by the skill index to decide what the agent should load for a later task, while the proposal body supplies the procedure after selection.
