## Summary

Keep this PR open: the patch improves pre-open failure cleanup, but it clears the watchdog at the browser WebSocket `open` event, so an opened connection that never completes Google Live session setup can still leave Realtime Talk connecting indefinitely.

## What This Changes

The PR adds a 30-second Google Live WebSocket opening deadline, consolidates terminal cleanup, and adds timeout, error, and pre-open-close regression tests.

## Best Possible Solution

Use one startup watchdog from WebSocket construction through the Google `setupComplete` message, retain idempotent terminal cleanup for timeout/error/close, and prove both the timeout and resource release in a real Control UI session.

## Solution Assessment

No. A browser-opening timeout is too narrow because Google Live readiness is established by `setupComplete`; the watchdog should cover the entire setup phase.
