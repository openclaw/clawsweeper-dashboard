## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P1] Preserve non-manual reload stop semantics:** `src/gateway/server-reload-handlers.ts:122-123`
  - body: This new account restart path calls `stopChannel(name, accountId)` without the `{ manual: false }` option used by the current hot-reload whole-channel path. Because `stopChannel` defaults to manual stops, a stop timeout can leave the old task running without recovery scheduling and the immediate `startChannel` can return without actually restarting the account.
  - confidence: 0.87
- **[P1] Keep default account changes on wholesale restart:** `src/gateway/config-reload-plan.ts:153-157`
  - body: The parser treats `channels.<kind>.accounts.default.*` as a single-account restart, but current channel helpers allow `accounts.default` to act as the inherited base for other accounts. A default-account config edit can therefore affect every account on the channel and needs the same whole-channel fallback used by the newer candidate.
  - confidence: 0.82
- **[P1] Restart channels for account-scoped secret reloads:** `src/gateway/config-reload-plan.ts:16`
  - body: Adding `restartChannelAccounts` changes the plan shape, but the secrets.reload path only restarts `plan.restartChannels`. If a per-account credential change produces only the new bucket, the secret snapshot can update while the affected channel runtime keeps using the old credential until another restart.
  - confidence: 0.84
