## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Keep default-account changes on whole-channel restart:** `src/gateway/config-reload-plan.ts:158`
  - body: This parser treats `channels.<kind>.accounts.default.*` as safe for a single-account restart. Several channel helpers use `accounts.default` as shared defaults for named accounts, so changing that subtree can affect more than the default account; routing it to `restartChannelAccounts` can leave named accounts running with stale inherited policy/config. The replacement PR fixes this by keeping `default` on the wholesale restart path.
  - confidence: 0.88
- **[P1] Use non-manual stops for hot-reload restarts:** `src/gateway/server-reload-handlers.ts:125`
  - body: The account-scoped hot-reload path calls `stopChannel(name, accountId)` without `{ manual: false }`. `stopChannel` defaults to a manual stop, which records the account as manually stopped and does not set the recovery timeout state used by reload restarts; a stop timeout can therefore leave the account unrestarted or stale. Current whole-channel reloads use non-manual stops, and the replacement PR carries that through for account restarts.
  - confidence: 0.86
