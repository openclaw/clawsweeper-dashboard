  - confidence: 0.88

  - body: `accounts.default` is the base other channel accounts can inherit from, so treating `channels.<kind>.accounts.default.*` as a single-account restart can leave other accounts running with stale resolved config. The newer implementation keeps default-account changes on the wholesale path.
  - confidence: 0.82
