## What This Changes

The issue requests per-spawn tool restrictions for sub-agents, such as an allowlist or denylist on `sessions_spawn`, to enforce least privilege for untrusted-content workflows.

## Best Possible Solution

Keep this issue as the canonical tracker, then land or replace https://github.com/openclaw/openclaw/pull/78441 once maintainers accept the API shape, durable policy semantics, unsupported-runtime behavior, docs, tests, and security-boundary contract.

The exact shipped contract remains a maintainer product/security decision because allow-only, allow/deny, empty-list, persistence, ACP/CLI behavior, and docs/tests need to be accepted together.
