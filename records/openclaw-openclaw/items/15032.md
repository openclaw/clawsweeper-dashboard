## Summary

Keep open: current main and v2026.6.11 still lack a public per-spawn tool restriction for `sessions_spawn`, and the active candidate implementation at https://github.com/openclaw/openclaw/pull/78441 is not merged.

## What This Changes

The issue requests an enforced per-spawn tool restriction on sub-agents so callers can give each `sessions_spawn` child only the tools it needs.

## Best Possible Solution

Keep this issue as the canonical tracker and resolve it by landing or replacing https://github.com/openclaw/openclaw/pull/78441 after maintainers accept the API shape, durable policy semantics, unsupported-runtime behavior, docs, tests, and security boundary.
