## Summary

## What This Changes

The PR validates OpenAI Realtime voice audio-delta base64 before decoding, reports malformed frames through the bridge error callback, and adds a regression test for skipped corrupt audio followed by valid playback.

## System Context

The OpenAI extension consumes Realtime WebSocket audio-delta events and sends decoded assistant bytes to a voice playback callback. The changed logic is the validation step between the provider event payload and speaker output, with errors routed to the bridge callback instead of corrupt bytes reaching playback.
