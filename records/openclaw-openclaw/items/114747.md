## Summary

This PR addresses a real current-main failure mode: the OpenAI Realtime bridge passes unvalidated audio-delta text to Node’s permissive base64 decoder. The validation and skip-on-error behavior are appropriate, but the new direct internal-package import breaks the extension boundary and can leave a packaged provider with an undeclared runtime dependency; use the existing Plugin SDK facade instead. The supplied terminal proof validates the helper, not the bridge’s after-fix callback path, so real bridge-level evidence is still needed before merge.

## What This Changes

The PR rejects malformed base64 returned in OpenAI Realtime audio-delta events, reports an error, and continues the voice session without emitting corrupted audio.

## System Context

The bundled OpenAI plugin receives Realtime WebSocket events for Voice Call and Control UI Talk, then converts audio-delta text into speaker buffers. This change sits between the inbound provider event and the audio callback that drives user playback.
