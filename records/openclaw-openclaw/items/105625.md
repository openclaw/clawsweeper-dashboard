## Summary

Current main and the latest release retain individually bounded completed-process output in a count-unbounded map until TTL expiry, and gateway session cleanup does not purge matching finished records. The issue remains necessary, although tail-only retention would regress the documented completed `process log` contract.

## What This Changes

Bound retained completed bash sessions and purge their state when the owning gateway session is reset or deleted.

## Best Possible Solution

Add deterministic count-plus-byte retention and purge finished records for canonical session lifecycle keys, while preserving completed aggregate logs for entries that have not expired, been cleared, or been evicted.
