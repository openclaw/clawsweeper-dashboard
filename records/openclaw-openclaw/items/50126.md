## Summary

Keep open: current main has repaired important core and Telegram direct-delivery hook paths, but the umbrella problem is not fully solved because Gateway/OpenAI HTTP, TUI/webchat-style final broadcasts, Telegram preview-finalized replies, and plugin self-delivery paths still have documented or source-visible coverage gaps; the open related PRs cover slices rather than superseding the umbrella.

## What This Changes

The issue requests consistent internal `message:sent` and plugin `message_sent` / `message_sending` hook coverage across outbound dispatch paths.

## Best Possible Solution

Define one canonical outbound delivery observation/reporting contract, then land the existing slice fixes only where they preserve documented hook semantics across channel, Gateway, TUI, HTTP, and plugin self-delivery paths.
