## What This Changes

The issue asks OpenClaw to make internal `message:sent` and plugin `message_sending` / `message_sent` hook coverage consistent across outbound dispatch paths.

## Best Possible Solution

Keep this as the canonical umbrella and have maintainers approve one outbound lifecycle observer/reporting contract that covers shared delivery, Gateway/WebChat/TUI finals, configured dispatcher paths, Telegram streaming, and plugin-native self-delivery exactly once.
