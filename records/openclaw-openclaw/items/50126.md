## What This Changes

Request to make outbound `message:sent` / `message_sent` hook emission consistent across shared delivery, Telegram replies, plugin-handled sends, Gateway/WebChat/TUI final output, and related dispatch paths.

## Best Possible Solution

Define one shared exactly-once outbound lifecycle observer/reporting contract, or explicitly split the remaining Gateway/TUI/native-channel/plugin-action slices into canonical issues so every delivery path emits the applicable hooks once with stable session/run context.
