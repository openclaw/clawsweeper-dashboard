## Summary

Keep this PR open: the SQLite direction matches repository policy, but the branch also changes the global official-plugin trust predicate in a way that can disable existing plugin-state access, and its live evidence stops before exercising the changed Diffs flow.

## What This Changes

The PR adds a bounded trusted-plugin SQLite BLOB-store API, migrates Diffs viewer data and rendered-file expiry metadata from temporary sidecars, adjusts snapshot sanitization, and tightens official-plugin install trust detection.

## Best Possible Solution

Keep the SQLite-backed Diffs design, but separate the new BLOB capability’s eligibility from any global trust reclassification unless maintainers explicitly approve that break; then document the final privilege boundary and prove fresh-install plus upgrade behavior with a real Diffs create, HTTP fetch, file delivery, expiry, and restart scenario.
