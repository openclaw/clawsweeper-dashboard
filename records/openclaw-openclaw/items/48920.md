The issue asks for live docs to stay aligned with released OpenClaw versions, including version visibility or gating so users do not copy unsupported config into stable installs.

## Best Possible Solution

## Solution Assessment

Unclear as an implementation path. A one-off docs edit is not the best durable fix; maintainers need to choose a public docs versioning, release-gating, version-labeling, or validation-error policy.
