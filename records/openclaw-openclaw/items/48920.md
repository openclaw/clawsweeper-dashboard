## Summary

Keep open: the original isolatedSession example is now in the latest release, but the live-docs-versus-latest-release failure class still reproduces at source level because current main documents and accepts agents.defaults.utilityModel while v2026.6.11 rejects that key under the strict release schema.

## What This Changes

The issue asks OpenClaw to keep live docs aligned with released versions or show feature availability so released users do not apply unsupported config keys.

## Best Possible Solution

Define and enforce a public docs compatibility policy, then add version-aware docs/config validation or a Doctor/Fix recovery path so users are not left manually editing config after following official docs.
