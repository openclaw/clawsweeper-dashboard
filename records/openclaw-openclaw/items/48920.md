## Summary

Keep open: the original `isolatedSession` mismatch is fixed in the latest stable release, but the same live-docs-versus-stable-release failure class is still source-reproducible with `agents.defaults.utilityModel`, which live docs advertise while `v2026.6.11` rejects.

## What This Changes

The issue reports that live OpenClaw docs can document strict config keys before the latest stable release accepts them, causing config parsing failures for users who follow the docs.

## Best Possible Solution

Adopt a release-aware docs contract that either gates public config docs to stable availability or labels version requirements, and pair it with a user-facing recovery path for config copied from newer docs while leaving broader bundled-docs retrieval to https://github.com/openclaw/openclaw/issues/71301.
