The issue reports that docs.openclaw.ai can publish configuration guidance ahead of the latest stable OpenClaw release, causing strict config parsing to reject documented keys and break a Telegram workflow.

## Best Possible Solution

Define the docs.openclaw.ai compatibility policy, then implement version labels, release-pinned docs, or generated docs-vs-latest-stable config checks so stable users are not guided into unsupported config.
