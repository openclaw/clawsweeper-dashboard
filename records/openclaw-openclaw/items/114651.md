The branch replaces Code Mode’s character scanner with Acorn/TypeScript parser-based masking so harmless module-shaped text in literals, comments, and regular expressions can execute while real module access remains rejected.

## System Context

Code Mode prepares model-supplied JavaScript or TypeScript before starting an isolated QuickJS-WASI guest worker. This validation step must reject executable module access without rejecting literal data that happens to resemble module syntax.
