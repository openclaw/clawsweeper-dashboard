This PR trims trailing whitespace from the final chunk emitted by the shared reply-text chunker while preserving whitespace for messages that never need splitting.

## System Context

The shared text chunker divides long agent replies before auto-reply and channel delivery code sends them to users. Its output is consumed by multiple transports, so consistent final-chunk trimming prevents visibly padded last messages across those delivery paths.
