## What This Changes

This PR moves iOS gateway-approval readback, Watch chat presentation, and notification-operation timeout handling out of the node app model into focused lifecycle owners, with regression tests and targeted simulator CI coverage.

## System Context

The iOS node app model receives gateway approvals and chat events, then projects them to Apple Watch and notification-facing flows. This PR separates those projections and timeout coordination into dedicated owners while keeping the app model as the gateway orchestrator.
