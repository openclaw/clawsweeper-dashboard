## What This Changes

The PR canonicalizes plugin compatibility IDs for plugin enable/disable policy checks and configuration writes, merging alias settings into one canonical entry without dropping nested configuration.

## System Context

The plugin CLI accepts a plugin identifier, applies allow/deny policy, writes the `plugins.entries` configuration, and refreshes the registry used for later plugin loading. Compatibility aliases must resolve consistently across those policy, persistence, and runtime-projection steps to avoid duplicate entries or lost settings.
