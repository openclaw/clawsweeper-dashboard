## Summary

The prior recovery-state blocker is fixed: the branch now preserves the complete source config while pruning the startup assignment projection. However, only the fast-path snapshot preparer implements the new projection contract; the full runtime preparer still consumes `config` alone, so non-fast-path setups can continue resolving suppressed channel SecretRefs and remain in the restart loop.

## What This Changes

The PR propagates crash-loop channel-autostart suppression into Gateway SecretRef startup projection while preserving complete source configuration for credential reload.

## Best Possible Solution

Make source-versus-assignment projection a shared contract of both secrets snapshot preparers, preserve the complete source for reload, and prove breaker startup and recovery while explicitly forcing the non-fast-path runtime.
