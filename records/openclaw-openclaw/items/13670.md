## Summary

Keep open. Current main and latest release still do not provide an always-visible Control UI topbar display for active model plus token/provider usage; adjacent Debug, Usage, chat context, chat quota, and per-message metadata surfaces exist, but they do not satisfy the requested topbar placement.

## What This Changes

Add a Control UI topbar status display showing the active model and token or usage information at a glance.

## Best Possible Solution

Maintainers should either define a compact topbar status contract backed by canonical session/model/provider-usage state, with stale/unavailable and responsive states, or explicitly decline topbar placement in favor of the existing chat and Usage surfaces.

## Reproduction Assessment

Not applicable as a bug reproduction; this is a feature request. Source inspection gives high-confidence gap proof because current main and v2026.6.11 do not render active model or token/provider usage in the Control UI topbar.

## Solution Assessment

Unclear until maintainers choose the topbar UX and freshness semantics. If accepted, the maintainable path should reuse canonical session usage, model-auth/provider-usage, and session model state rather than debug-only polling.
