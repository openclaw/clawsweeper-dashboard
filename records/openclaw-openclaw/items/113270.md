## What This Changes

Add a persistent drag-and-keyboard resize control for the Control UI chat composer so users can see more or less of a long draft.

## System Context

The Control UI chat composer accepts a user's draft and passes it into the chat-send flow. This request changes only the browser-side composing experience by letting users control the visible text-entry height before sending.
