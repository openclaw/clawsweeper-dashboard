## What This Changes

Adds a `compat.disableBoundaryAwareCache` model option, defaults it on for DeepSeek completions, moves dynamic below-boundary instructions to a trailing system-role carrier, and updates schemas, catalog normalization, tests, generated API baselines, and prompt-caching documentation.

## Best Possible Solution

Adopt one owner-approved DeepSeek cache policy that preserves the stable prefix and instruction authority, default it automatically only if that upgrade behavior is intentional, retain a public override only when operators have a demonstrated need, and cover both default and explicit-opt-out paths with focused and live provider proof.
