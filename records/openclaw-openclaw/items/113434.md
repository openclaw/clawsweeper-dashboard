## What This Changes

Fix Codex session reset so it never reuses a retired generation identifier, and prevent repeated catalog and file-list scans from exhausting Gateway resources on large session stores.

## System Context

The Gateway exposes session catalog, file-list, and reset operations to the Control UI and other clients. Catalog and file requests can traverse stored session data, while reset coordinates durable session state with the Codex plugin's generation binding before the next agent turn runs.

Retain the reset-lifecycle repair and validate the current Gateway under concurrent large-store catalog requests; if provider scans still multiply across requests, land or replace the narrow per-provider in-flight-sharing approach from https://github.com/openclaw/openclaw/pull/114160 with exact-head proof rather than adding a broad TTL policy.
