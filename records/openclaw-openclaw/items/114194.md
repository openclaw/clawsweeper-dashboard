## Label Justifications

- `P1`: A parent agent is deterministically prevented from reading an older child transcript under the default tree visibility despite that child remaining visible in the same session tree.
- `merge-risk: 🚨 security-boundary`: The patch changes the authorization predicate for transcript reads, although its durable-row check and session-incarnation fence are covered by focused negative controls.

## Summary

This PR addresses a real current-main mismatch: session listing already applies durable ownership metadata, while direct history authorization reconstructs ownership from a recency-filtered Gateway listing. The proposed row-based check uses the existing visibility contract and preserves the session-incarnation fence; the submitted live Gateway evidence covers the intended allow case and two fail-closed controls. No discrete patch defect was established, so this PR should remain open for normal merge gating.

## What This Changes

The branch lets `sessions_history` authorize an older child session from the target’s durable Gateway session row, then binds that authorization to the row’s session incarnation before reading transcript history.

## System Context

Session tools resolve a requested session key, apply visibility policy, then call the Gateway for the requested operation. `sessions_history` reads a transcript only after the access layer confirms that the requester may see the target session and that any observed session incarnation is still current.
