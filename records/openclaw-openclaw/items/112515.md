## What This Changes

The PR makes plugin-hosted media resolve through the Gateway-pinned HTTP-route registry rather than the request-local active registry, with a regression test for an active-registry swap.

## System Context

OpenClaw plugins can register hosted-media resolvers alongside Gateway HTTP routes. `loadWebMedia()` receives a media path, asks the registry that owns the active Gateway route surface to resolve plugin-hosted paths, then loads the resolved local media for a web response.
