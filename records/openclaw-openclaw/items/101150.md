## Summary

Keep open: current main and the latest release do not include the modular dashboard binding substrate or the requested stream, command, and computed binding kinds. The command-binding part would add periodic command execution, so it needs maintainer product/security direction before implementation.

## What This Changes

Requests new dashboard data-binding kinds for push streams, allowlisted interval command output, and computed values derived from other bindings.

## Best Possible Solution

Land or reject the Wave 1 dashboard substrate first, then design stream and computed bindings separately from any command-execution binding unless maintainers approve that security model.
