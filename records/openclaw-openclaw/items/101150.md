## Summary

Keep open: current main and the latest release do not implement the dashboard binding substrate or the requested stream, command, and computed binding kinds. This is a roadmap feature under https://github.com/openclaw/openclaw/issues/101136, and the command-binding part crosses a command-execution security boundary that needs maintainer direction before implementation.

## What This Changes

The issue requests new dashboard binding kinds for live streams, allowlisted interval commands, and computed values derived from other bindings.

## Best Possible Solution

Land or reject the Wave 1 dashboard substrate first, then design stream and computed bindings separately from any command-execution binding unless maintainers approve that security model.
