## Summary

Keep open: current main and the latest release do not implement the requested dashboard `stream`, `command`, or computed binding kinds. The work is an active Modular Dashboard roadmap item, and the command-binding part needs maintainer product/security direction before implementation.

## What This Changes

Requests new dashboard data-binding kinds for push streams, allowlisted periodic commands, and computed values derived from other bindings.

## Best Possible Solution

Land or reject the Wave 1 dashboard substrate first, then design stream and computed bindings separately from any command-execution binding unless maintainers explicitly approve that security model.
