## Summary

Keep open: current main and the latest release still do not include the dashboard workspace/binding substrate, and the open dashboard stack only defines file, static, and rpc bindings. The requested command binding also crosses an execution-policy boundary, so this remains a maintainer product/security decision rather than cleanup-close material.

## What This Changes

The issue requests new Dashboard data-binding kinds for stream, command, and computed values.

## Best Possible Solution

Settle the Wave 1 dashboard substrate first, then design stream and computed bindings against that accepted schema while splitting command execution into a separate security-reviewed, operator-controlled proposal.
