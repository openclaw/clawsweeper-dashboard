## Summary

Keep this PR open, but do not merge the current head: the CLS goal is valid, yet the fixed `3 / 2` preferred ratio still prevents loaded square, portrait, and wide images from recovering their natural element ratio, and the submitted evidence remains a synthetic one-ratio harness rather than real Control UI proof.

## What This Changes

The PR adds a muted 3:2 CSS aspect-ratio placeholder to Control UI chat images to reserve space while image content loads.

## Best Possible Solution

Use `aspect-ratio: auto 3 / 2` as the unloaded fallback, preserve each image's natural ratio after loading, and demonstrate the result with delayed 3:2, square, portrait, and wide images in the real Control UI.
