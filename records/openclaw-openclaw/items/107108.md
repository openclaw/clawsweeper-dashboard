## Summary

Keep open: the reported layout shift still exists on current main, but this patch only reduces the initial jump rather than preventing it because a 40px placeholder can still grow to the image’s rendered height. The branch needs a stable sizing strategy and controlled browser proof before merge.

## What This Changes

The PR adds 40px minimum dimensions and a muted background to Control UI chat images as a loading placeholder.

## Best Possible Solution

Reserve a deterministic rendered box using available intrinsic dimensions plus an aspect-ratio or container fallback for unknown images, then verify that the following message’s offset remains unchanged during delayed loading.

## Maintainer Decision

Required: false

## Reproduction Assessment

Yes at source level: load an unsized chat image through a delayed response and observe the following message’s vertical position before and after image decode. The submitted patch still permits that position to change from a 40px placeholder to as much as 200px.

## Solution Assessment

No. A fixed 40px minimum mitigates the jump but cannot prevent CLS; stable intrinsic or fallback aspect-ratio sizing with a browser position assertion is the narrower complete fix.
