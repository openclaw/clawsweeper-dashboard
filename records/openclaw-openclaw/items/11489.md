## Summary

Keep open: current main and v2026.6.11 still keep pairing scoped to DMs, while group admission is limited to allowlist/open/disabled behavior. The linked Telegram and WhatsApp work overlaps, but none replaces this broader owner-notified group approval and pending read-only-mode request.

## What This Changes

The issue requests cross-channel group pairing with owner notification, approve/reject controls, and optional read-only routing for unconfigured groups.

## Best Possible Solution

Define a product/security-reviewed group admission contract that stores pending approvals by channel/account/group, sends redacted owner notifications, authorizes approve/reject operations, and treats read-only reader-agent observation as a separately explicit isolated mode.
