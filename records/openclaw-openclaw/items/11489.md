## Summary

Keep open: current main and v2026.6.11 still keep pairing scoped to DMs, while group admission remains open, disabled, or allowlist only. The related Telegram and WhatsApp items cover narrower warn/leave or auto-leave behavior, not the requested cross-channel owner-notified group approval and read-only pending-group mode.

## What This Changes

The issue requests a new cross-channel group pairing flow with owner notifications, approve/reject controls, and optional read-only handling for unconfigured groups.

## Best Possible Solution

Define a product/security-reviewed group admission contract that stores pending approvals by channel/account/group, sends redacted owner notifications, authorizes approve/reject operations, and treats read-only observation as a separate explicit isolated mode unless maintainers fold it into the same contract.
