## Summary

Keep open. Current main still lacks group pending-approval state, owner approve/reject operations, and a defined pre-approval content boundary. The merged pairing-request hook is DM-scoped, adjacent items cover narrower warn/leave or observation behavior, and recent maintainer review explicitly left this product and security decision open.

## What This Changes

Add cross-channel group pairing with owner notification, approve/reject controls, and an optional restricted read-only mode for groups awaiting approval.

## Best Possible Solution

Define an additive shared group-admission contract with channel/account/group-scoped pending state, metadata-only owner notification by default, authorized approve/reject operations, and channel-specific join detection; make pre-approval message observation a separate explicit opt-in with documented sandbox and retention limits.

## Solution Assessment
