## Summary

Keep open: current main and v2026.6.11 still keep pairing scoped to DMs while group admission is open, allowlist, or disabled. The related Telegram and WhatsApp items overlap, but none replaces the requested cross-channel owner-notified group approval flow with pending read-only semantics.

## What This Changes

Request a cross-channel group pairing mode that notifies an owner when the bot joins an unconfigured group and can keep that group in read-only or reader-agent mode pending approval.

## Best Possible Solution

Define a shared additive group admission contract that fails closed by default, persists pending approvals by channel/account/group, sends redacted owner notifications, authorizes approve/reject operations, and scopes reader-agent observation as a separate explicit mode.

## Reproduction Assessment

Yes at source level, not as a bug: current main keeps group policies to open, allowlist, or disabled and keeps pairing on the DM path only.

## Solution Assessment

No current implementation is best yet. The maintainable path is a product/security-reviewed group admission contract rather than stretching DM pairing or landing narrower channel-specific proposals independently.
