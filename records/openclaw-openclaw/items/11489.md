## Summary

Keep open: current main still keeps pairing on the DM path, while group handling is allowlist/open/disabled plus explicit group allowlists. The related Telegram, WhatsApp, and unauthorized-sender items overlap, but none replaces this broader owner-notified, cross-channel group admission and pending read-only-mode request.

## What This Changes

Request a cross-channel group pairing flow that notifies the owner when a bot joins an unconfigured group, allows approve/reject decisions, and optionally routes pending groups through a read-only reader mode.

## Best Possible Solution

Define a security-reviewed shared group admission contract with persisted pending approvals, owner-visible redacted notifications, authorized approve/reject operations, and a separately explicit isolated no-reply/no-tool reader mode if maintainers accept pending-group observation.
