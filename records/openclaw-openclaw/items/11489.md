## Summary

Current main still limits group access to explicit open, disabled, or allowlist policies; the merged pairing notification hook remains DM-only, and the related items cover narrower warn, leave, or unauthorized-message behavior. This issue should remain open for the existing product and security decision on group admission and pre-approval content handling.

## What This Changes

Add owner-approved group admission, group-join notifications, and an optional restricted observation mode for unconfigured groups.

## Best Possible Solution

Define an additive shared group-admission contract that notifies an authenticated owner and persists approve/reject state, keeps pending-group content fully unprocessed by default, and treats any observation-only agent mode as a separate security-reviewed capability.
