## Summary

Keep open: current main and v2026.6.11 still keep pairing scoped to DMs, while group admission remains open, disabled, or allowlist only. Related Telegram/WhatsApp work and the listen-only plugin path overlap, but none implements owner-notified group approval, pending group state, or a cross-channel read-only pending-group contract.

## What This Changes

Request adds cross-channel group pairing that notifies the owner on new group additions, stores pending approvals, and optionally routes unconfigured group messages through read-only mode.

## Best Possible Solution

Define a product/security-reviewed group admission contract that stores pending approvals by channel/account/group, sends redacted owner notifications, authorizes approve/reject operations, and treats read-only observation as a separate explicit isolated mode unless maintainers fold it into the same contract.
