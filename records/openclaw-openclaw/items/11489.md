## Summary

Keep open: current main still keeps pairing scoped to DMs while group admission remains allowlist/open/disabled, with no pending group approval state, owner notification path, group approve/reject CLI, or safe reader-agent mode. ## What This Changes

The issue requests a cross-channel group pairing flow with owner notification, approval/rejection, and optional read-only pending-group handling.

## Best Possible Solution

Define a product/security-reviewed shared group admission contract with canonical pending approval state, redacted owner notifications, authorized approve/reject operations, and a separately explicit no-reply/no-tool observation mode before wiring Telegram and WhatsApp.
