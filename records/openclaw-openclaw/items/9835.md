## Summary

Keep open: current main still has partial Telegram reaction support, but the requested separate `reactionGuidance` config, notification-gated incoming reaction prompt guidance, schema/docs coverage, and product contract remain unresolved.

## What This Changes

Request to add Telegram reaction prompt guidance for sending and interpreting reactions, controlled by a new `reactionGuidance` config option.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then align the bundled Telegram plugin, shared prompt composition, strict schema/generated metadata, public docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.
