## Summary

Keep open: current main and the latest release still have partial Telegram reaction support, but the requested separate `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA prompt guidance remain missing and need product direction.

## What This Changes

The issue requests configurable two-way Telegram reaction prompt guidance, including outbound etiquette and incoming reaction interpretation.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outgoing etiquette, incoming soft-CTA guidance, and notification gating compose predictably.
