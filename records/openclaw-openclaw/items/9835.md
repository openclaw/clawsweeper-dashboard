## Summary

Keep open: current main and v2026.6.11 still provide Telegram reaction notifications plus `reactionLevel`-driven outbound prompt guidance, but the requested separate `reactionGuidance` config, notification-gated prompt policy, and incoming reaction soft-CTA guidance remain missing.

## What This Changes

Request adds bidirectional Telegram reaction prompt guidance plus a new `reactionGuidance: off|minimal|full` config surface that composes with `reactionNotifications`.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outgoing etiquette, incoming soft-CTA guidance, and notification gating compose predictably.

## Reproduction Assessment

Not applicable as a bug reproduction. This is a feature/config request, and source inspection verifies the requested public config field and incoming soft-CTA prompt guidance are absent.

## Solution Assessment

Unclear. The direction is plausible, but a separate `reactionGuidance` config is not clearly the best fix while `reactionLevel` already controls Telegram reaction prompting; maintainers should choose the canonical policy and precedence first.
