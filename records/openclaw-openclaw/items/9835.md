## Summary

Current main provides outbound Telegram reaction guidance through `reactionLevel`, but the requested incoming-reaction interpretation, notification gating, and explicit product contract remain absent; the issue is still necessary and needs a maintainer choice before implementation.

## What This Changes

Add Telegram system-prompt guidance for sending and interpreting reactions, with configurable guidance levels composed with inbound reaction notifications.

## Best Possible Solution

Keep one canonical Telegram reaction prompt policy in the Telegram plugin, add incoming soft-CTA guidance only when inbound notifications are enabled, and align schema, generated metadata, docs, and focused prompt tests after the default and opt-in semantics are approved.
