## Summary

Keep open: current main and v2026.6.11 still provide only partial Telegram reaction support through `reactionNotifications` and `reactionLevel`; the requested separate `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA guidance remain missing and need product direction.

## What This Changes

Request to add Telegram reaction prompt guidance for sending and receiving reactions, gated by reaction notifications and configurable through a new `reactionGuidance` option.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the Telegram plugin, shared prompt composition, strict schema/metadata, docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.

## Reproduction Assessment

Not applicable. This is a feature/config request rather than a broken current behavior, and source inspection verifies the requested public config and incoming soft-CTA prompt guidance are absent.

## Solution Assessment

Unclear. The requested direction is plausible, but a separate `reactionGuidance` config is not clearly the best fix while `reactionLevel` already controls Telegram reaction prompting; maintainers should choose the canonical policy and precedence first.
