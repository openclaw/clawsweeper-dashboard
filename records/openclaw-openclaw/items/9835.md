## Summary

Keep open: current main and the latest release still provide only partial Telegram reaction support through `reactionNotifications` and `reactionLevel`; the requested separate `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA guidance remain missing and need a maintainer product decision.

## What This Changes

The issue requests bidirectional Telegram reaction prompt guidance plus a new `reactionGuidance: off|minimal|full` config option gated by Telegram reaction notifications.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.

## Reproduction Assessment

Not applicable. This is a feature/config request rather than broken current behavior, and source inspection verifies the requested public config plus incoming soft-CTA prompt guidance are absent.

## Solution Assessment

Unclear. The requested direction is plausible, but a separate `reactionGuidance` option is not clearly the best permanent fix while `reactionLevel` already controls Telegram reaction prompting; maintainers should choose the canonical policy and precedence first.
