## Summary

Keep open: current main and the latest release still only provide partial Telegram reaction prompting, while the requested public `reactionGuidance` config and incoming-reaction soft-CTA guidance remain absent; the remaining work needs maintainer product direction because it overlaps the existing `reactionLevel` prompt-control surface.

## What This Changes

The issue requests configurable two-way Telegram reaction guidance in the system prompt, including outbound reaction etiquette and incoming reaction interpretation when Telegram reaction notifications are enabled.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then align the bundled Telegram plugin, shared prompt composition, strict schema/generated metadata, public docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.
