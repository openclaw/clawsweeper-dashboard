## Summary

Keep open: current main and the latest release still only provide partial Telegram reaction support through `reactionNotifications` and `reactionLevel`; the requested separate `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA prompt guidance remain missing and need maintainer product direction.

## What This Changes

Request to add Telegram prompt guidance for sending and interpreting reactions, gated by `reactionNotifications`, with a new `reactionGuidance` config option.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outgoing etiquette, incoming soft-CTA guidance, and notification gating compose predictably.

## Reproduction Assessment

## Solution Assessment

Unclear. The requested direction is plausible, but a separate `reactionGuidance` config is not clearly the best fix while `reactionLevel` already controls Telegram reaction prompting; maintainers should choose the canonical policy and precedence first.
