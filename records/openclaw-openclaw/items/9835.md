## Summary

Keep open: current main still has partial Telegram reaction support, but the requested public `reactionGuidance` config and incoming-reaction soft-CTA prompt guidance are missing; the remaining work needs a product/config decision rather than cleanup closure.

## What This Changes

The issue requests bidirectional Telegram reaction prompt guidance plus a new `reactionGuidance: "off" | "minimal" | "full"` config option that composes with `reactionNotifications`.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.
