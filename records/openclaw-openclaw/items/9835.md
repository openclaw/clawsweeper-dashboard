## Summary

Keep open: current main and v2026.6.11 still expose Telegram reaction prompting through `reactionLevel` only, while the requested `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA guidance remain absent.

## What This Changes

Request to add two-way Telegram reaction prompt guidance, gated by `reactionNotifications`, plus a new `reactionGuidance: off|minimal|full` config option.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.

Unclear. The requested direction is plausible, but a separate `reactionGuidance` option overlaps existing `reactionLevel`, so maintainers should choose the canonical policy and precedence before implementation.
