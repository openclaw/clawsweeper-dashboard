Keep open: current main and v2026.6.11 still expose Telegram reaction prompt behavior through existing `reactionLevel` only, while the requested `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA reaction guidance remain absent.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.
