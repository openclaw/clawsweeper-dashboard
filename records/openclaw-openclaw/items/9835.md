## Summary

Keep open: current main and the latest release still only provide Telegram reaction prompt behavior through `reactionLevel`; the requested separate `reactionGuidance` config, notification-gated prompt policy, and incoming soft-CTA guidance remain missing and need maintainer product direction.

## What This Changes

The issue requests bidirectional Telegram reaction prompt guidance, including a new `reactionGuidance` config option and prompt text for sending reactions and interpreting incoming reactions.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then update the bundled Telegram plugin, shared prompt composition, config schema/metadata, docs, and focused tests so outgoing etiquette, incoming soft-CTA guidance, and notification gating compose predictably.

## Solution Assessment

Unclear. The requested direction is plausible, but a separate `reactionGuidance` config is not clearly the best fix while `reactionLevel` already controls Telegram reaction prompting; maintainers should choose the canonical policy and precedence first.
