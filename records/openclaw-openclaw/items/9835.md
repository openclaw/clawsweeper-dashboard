## Summary

Keep open: current main and v2026.6.11 still have partial Telegram reaction prompting, but they do not implement the requested public `reactionGuidance` config, `reactionNotifications`-gated soft-CTA guidance for incoming reactions, or matching schema/docs/tests.

## What This Changes

Requested Telegram reaction prompt guidance that can send reactions sparingly, interpret incoming reactions as soft CTAs, and expose a `reactionGuidance` config option.

## Best Possible Solution

Define one canonical Telegram reaction prompt policy, then align the bundled Telegram plugin, shared prompt composition, strict schema/generated metadata, public docs, and focused tests so outbound etiquette, incoming soft-CTA guidance, and notification gating compose predictably.
