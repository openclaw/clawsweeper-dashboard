## Summary

## What This Changes

The PR removes the start anchor from the Google transport multimodal functionResponse capability check, exports that helper for tests, and adds direct helper coverage for bare, provider-prefixed, Gemini 3, and non-Gemini ids.

## Best Possible Solution

Align both Google converter implementations on a segment-aware Gemini major-version parser such as `(?:^|/)gemini...`, and add regression coverage that proves provider-prefixed Gemini 2.x image tool results use the separate image turn in both surfaces.
