## Summary

Keep this PR open. Current main still performs repeated session-history image sanitization without result reuse, the refreshed branch cleanly applies to current main, and no line-level correctness defect remains from prior review cycles. Real behavior proof is sufficient; the remaining merge blocker is an owner decision about retaining session-derived image results in a process-wide cache.

## What This Changes

The branch adds a SHA-256-keyed, fixed 64 MiB process-local LRU for tool-image resize and no-op results, plus collision, eviction, MIME, repeated-call, and log-isolation regression tests.

## Best Possible Solution

Retain the full-payload-keyed, byte-bounded optimization, but default cache ownership to the agent/session replay lifecycle unless owners explicitly accept process-wide retention; preserve the refreshed sanitizer behavior and regression coverage.
