## What This Changes

Ensure `openai/gpt-5.6-terra` uses the Codex OAuth harness when an OpenAI OAuth profile is selected, or clearly identify it as requiring API-key authentication.

Verify the current-main selector and Codex model contract directly, then close as implemented if an OAuth profile routes every supported `openai/gpt-5.6-*` model through the existing Codex harness; retain an early, model-specific auth diagnostic for installations predating that support.
