## What This Changes

## Reproduction Assessment

Yes. From source inspection, current main builds snapshots without `skillKey` and then resolves snapshot env config by `skill.name`, so config under `skills.entries.<skillKey>` is missed when the display name differs.

## Solution Assessment

Yes. Persisting the resolved key into the snapshot and using `skillKey ?? name` is the narrow owner-boundary fix; the PR also handles the safer upgrade path by refreshing old persisted snapshots missing the field.
