## What This Changes

Fix Control UI WebChat so a live assistant reply cannot render above the optimistic user prompt when their browser and Gateway timestamps differ.

## System Context

Control UI WebChat combines an optimistic user bubble created in the browser with live Gateway reply events and persisted chat history. The chat-thread projection turns those sources into visible rows, so its ordering determines whether a just-completed turn matches the durable transcript.
