## What This Changes

The PR generates and persists a session title before opening a discussion for an untitled session, so the discussion provider can create the channel with a readable name.

## System Context

Gateway discussion opening resolves a stored session and asks the registered discussion provider to create its external channel. This change inserts a best-effort title-generation step so the provider receives a titled session rather than a hash-only fallback.
