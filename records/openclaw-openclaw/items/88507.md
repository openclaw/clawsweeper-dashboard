- `P2`: This is a bounded but cross-cutting plugin/config feature with normal backlog urgency rather than an emergency runtime regression.

## Summary

Keep open; this is useful groundwork, but it is not merge-ready because prior P1 blockers remain, exact-head proof is still stale, and the widened persisted config contract needs maintainer sponsorship.

## What This Changes

The PR widens `plugins.slots.memory` and `plugins.slots.contextEngine` to accept string ids or `{ owner }` records, adds a slot-owner resolver, and updates plugin, gateway, doctor, auth, status, memory, update, uninstall, docs, and tests around that shape.

## Best Possible Solution

Keep one canonical slot-owner read contract, normalize every raw `OpenClawConfig` slot reader including bundled plugin and CLI preflight paths, remove unsupported docs claims, and merge only after exact-head proof plus maintainer acceptance of the config contract.
