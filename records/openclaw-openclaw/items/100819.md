## Summary

Keep open: current main and v2026.6.11 still carry the source-reproducible browser/CDP SSRF policy mismatch, and the repair changes a browser SSRF control boundary that needs maintainer intent.

## What This Changes

Fix browser navigation/session CDP policy so a non-empty `browser.ssrfPolicy.hostnameAllowlist` does not self-block local loopback CDP control traffic while page navigation SSRF checks remain intact.

## Best Possible Solution

Route Playwright connection and target lookup through a scoped CDP-control policy while keeping requested URL, redirect, and final-page navigation checks on the original browser SSRF policy; add regression tests for local loopback and remote CDP preservation.
