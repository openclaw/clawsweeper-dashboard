## Summary

Keep open: current main still has the reported browser/CDP SSRF policy mismatch, and the failure is source-reproducible. The fix is narrow but security-sensitive because it changes how local CDP control traffic is separated from page navigation policy.

## What This Changes

The issue requests fixing browser navigation so a non-empty `browser.ssrfPolicy.hostnameAllowlist` does not make local loopback CDP control traffic fail with `browser endpoint blocked by policy`.

## Best Possible Solution

Route Playwright connection and target lookup through a scoped CDP-control policy while keeping the original browser navigation policy for requested URL, redirect, and final-page checks, with focused regressions for local loopback and remote-CDP guard preservation.
