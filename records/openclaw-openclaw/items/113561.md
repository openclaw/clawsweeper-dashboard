## System Context

OpenCode Zen and Go are provider plugins whose static model definitions feed offline catalog listing and constrain which live gateway model IDs can be surfaced. The Doctor registry selects relevant plugin migrations from saved configuration, then the OpenCode plugin rewrites retired saved model references before normal provider resolution uses the canonical catalog.
