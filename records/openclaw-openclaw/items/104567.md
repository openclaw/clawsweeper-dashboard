## Summary

The PR addresses a real Gemini schema rejection, and OpenClaw’s original-schema validator can restore stringified values to their numeric or boolean runtime types. It should remain open because the implementation is property-order dependent: a later `type` key can overwrite the coerced string type and leave the request invalid.

## What This Changes

The PR converts Gemini-facing numeric, boolean, and bigint `enum`/`const` values to strings, removes unsupported or duplicate entries, retypes affected schemas as strings, and adds seven unit tests.

## Best Possible Solution

Keep provider-boundary string serialization, but enforce the final `type: "string"` independently of object key order and add focused coverage proving the original schema restores numeric and boolean arguments before execution.
