## What This Changes

The PR preserves durable Control UI transcript row order and inserts live streamed, tool, terminal, and question rows within the user turn associated with their active run.

## System Context

Control UI builds one chat timeline from persisted history, locally queued user messages, and live Gateway updates. The timeline builder decides which rows remain stable and where active run output is inserted before the chat thread renders it.
