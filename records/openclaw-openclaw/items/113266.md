## What This Changes

The PR preserves insertion order for stable Control UI transcript rows while placing live streamed replies, tools, terminal results, and question summaries within their owning active run.

## System Context

Control UI combines the persisted/optimistic chat transcript with Gateway-delivered stream, tool, terminal, and question events into the visible chat thread. This change decides where transient live rows appear relative to stable conversation turns before the UI renders the conversation.
