## Summary

This PR addresses a concrete WebChat live-render ordering regression and remains necessary: it is open, unmerged, and the linked bug report remains open. The proposed boundary—preserve stable transcript insertion order while time-ordering only live tool and stream entries—matches the reported split between durable history and live optimistic rendering, but the external PR still needs after-fix evidence from a real Control UI session before merge.

## What This Changes

The PR changes Control UI chat-row construction so stable transcript rows keep their insertion order while only live tool cards and stream segments are sorted and placed by visible timestamp.

## System Context

Control UI WebChat merges durable session-history rows with optimistic local sends and live Gateway reply/tool events. The chat-row builder turns those inputs into the rendered conversation, so its ordering determines whether an active user turn and assistant response appear in their actual transcript order.
