## What This Changes

The PR changes Control UI chat-row construction so persisted and optimistic transcript rows retain insertion order while live stream and tool rows are sorted and inserted only within the active conversation turn.

## System Context

Control UI chat rendering merges durable Gateway history, browser-local optimistic sends, and live stream/tool updates into one visible transcript. The row builder decides where those inputs appear, so its ordering rules affect whether a user's prompt remains above the resulting assistant response.
