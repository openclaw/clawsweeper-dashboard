## What This Changes

The PR changes Control UI chat-row construction so persisted and optimistic transcript rows retain insertion order while live tool cards and stream segments are positioned by timestamp.

## System Context

Control UI combines the durable chat transcript, optimistic sends from the browser, and live Gateway reply/tool events into one chat thread. This change alters the final ordering step before those rows render in WebChat so differing client and Gateway clocks do not reverse a user turn and its assistant reply.

## Best Possible Solution

Keep stable transcript order as the canonical chat ordering rule, retain timestamp positioning only for genuinely live tool and stream rows, and add redacted before/after browser evidence from a real Gateway session that demonstrates both the fixed skew case and a live tool or stream case.
