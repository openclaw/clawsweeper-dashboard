## Summary

Keep open: current main and the latest release still do not auto-select DuckDuckGo for managed web_search, and the open linked PR is a candidate policy reversal that needs maintainer judgment rather than cleanup closure.

## What This Changes

The issue requests that enabled key-free DuckDuckGo become an implicit web_search provider for cron or agent runs without setting tools.web.search.provider, or that OpenClaw warn clearly when it is enabled but unselected.

## Best Possible Solution

Maintain explicit key-free provider selection unless maintainers deliberately approve reversing that policy; otherwise keep or improve diagnostics/setup guidance that tells users to select DuckDuckGo when provider resolution is empty.
