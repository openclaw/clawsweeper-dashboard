## Summary

Keep open: current main still intentionally keeps DuckDuckGo and other key-free managed web_search providers explicit-only, and the open linked PR is a product/security-boundary reversal rather than an already-merged fix.

## What This Changes

The issue requests that enabled key-free web_search providers such as DuckDuckGo be auto-selected, or at least surfaced more clearly when no active provider is selected.

## Best Possible Solution

Keep key-free managed web_search providers explicit unless maintainers approve a full policy reversal; otherwise narrow this to diagnostics/setup guidance for enabled-but-unselected keyless providers.
