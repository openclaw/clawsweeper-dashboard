## Summary

The requested auto-selection is still not implemented on current main, and it conflicts with the shipped explicit opt-in policy for key-free managed web_search providers. A linked open PR is the candidate implementation, so this issue should stay open for maintainer product/security-boundary review rather than be closed before that PR lands or is rejected.

## What This Changes

The issue asks OpenClaw to auto-select enabled keyless DuckDuckGo web_search when no explicit web_search provider is configured.

## Best Possible Solution

Keep this issue as the canonical maintainer decision: either reaffirm explicit key-free provider opt-in and close the linked PR, or approve a full policy reversal that updates runtime metadata, docs, setup behavior, tests, and real behavior proof together.
