## Summary

The global-install command is supported by npm and directly addresses the linked report, but the explanatory text overstates current npm 11 behavior: npm documents unreviewed install scripts as warnings that still run by default, not an unconditional npm 11+ requirement. Keep this PR open for a small wording correction before merge.

## What This Changes

The PR changes the manual npm install commands in the quick start and install guide to pass `--allow-scripts openclaw`, and explains why project-scoped script approval is not the right recovery path for global installs.

## System Context

The documentation quick start and install guide feed users into OpenClaw’s global npm installation and onboarding flow. The command controls whether npm permits OpenClaw’s package lifecycle hooks during that global install, before the installed CLI runs onboarding.
