The prior wording finding appears resolved: this revision no longer claims every npm 11+ global install requires script approval. The PR is a narrow, evidence-backed documentation remedy for the linked open npm global-install report and remains useful for normal maintainer review.

## What This Changes

This PR updates the manual npm global-install examples to pass `--allow-scripts openclaw` and explains why project-scoped `npm approve-scripts` is not the global-install recovery path.

## System Context

OpenClaw’s documentation home and installation guide provide copy-paste commands for users who install the CLI manually. Those commands invoke npm, which decides whether package lifecycle hooks are allowed, before OpenClaw’s onboarding command runs.
