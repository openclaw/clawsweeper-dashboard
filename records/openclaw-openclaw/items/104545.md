## Summary

Current main intentionally limits configured model views in replace mode, but the Control UI presents the resulting rows without identifying the active filter; no related issue or PR owns that explanation gap, so this useful UX improvement should remain open.

## What This Changes

Add a visible explanation when replace-mode configuration limits the Control UI model catalog to explicit configured rows.

## Best Possible Solution

Keep replace-mode filtering unchanged and show a localized, actionable hint beside configured model choices that explains only explicit provider rows are visible and points users to merge mode, explicit model rows, and the full-catalog view; reuse a generic diagnostic helper for doctor only if it avoids duplicating policy.
