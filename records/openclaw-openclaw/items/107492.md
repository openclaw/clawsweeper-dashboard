Keep this open: the optimization is plausible and bounded, but there is still no current-main benchmark or trace proving that certificate-file parsing occurs for each connection, and process-lifetime caching may change certificate refresh behavior.

## What This Changes

Avoid repeatedly reading and parsing the configured extra-CA certificate bundle by preparing its certificates once during process startup.

## Best Possible Solution

If profiling confirms repeated reads, prepare an immutable extra-CA certificate set during bootstrap, refresh it only on process restart, and add focused coverage for single-read behavior, default-root merging, empty input, and malformed certificate handling.
