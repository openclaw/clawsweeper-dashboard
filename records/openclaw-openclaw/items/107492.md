## Summary

Keep this issue open for verification: the proposed hotspot is plausible and narrowly scoped, but the report does not yet demonstrate that current main reads or parses the CA bundle once per HTTPS connection rather than during process startup.

## What This Changes

Avoid repeated synchronous loading and parsing of extra CA certificates by preparing process-stable certificate data during startup.

## Best Possible Solution

Add a focused current-main regression benchmark or unit probe that counts CA-file reads and parsing across multiple TLS context creations; only if the count grows per connection, cache immutable parsed certificate data at the earliest process-startup boundary while preserving existing error behavior.
