## Summary

Keep open. Current main has substantial HTTP/HTTPS managed-proxy support, but the issue still asks for first-class SOCKS, system/env precedence, per-agent/per-tool overrides, noProxy semantics, and browser/profile proxy behavior that remain product and security design work.

## What This Changes

Requested first-class proxy configuration for system/custom HTTP and SOCKS proxies across OpenClaw CLI/config, env fallback, agents, tools, and runtime network clients.

## Best Possible Solution

Keep this open for a maintainer-approved staged proxy design that extends the shipped managed proxy and trusted-env baseline without adding scattered ad hoc proxy knobs.
