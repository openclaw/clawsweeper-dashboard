## What This Changes

The PR makes agent hook HTTP responses wait for runner admission, returns pre-start failures as 409/502/503 responses, and caches run IDs only after successful admission.

## Best Possible Solution

Use one in-flight dispatch promise per replay key so concurrent duplicates share the same admission result, remove failed pending entries to permit retries, cache only successfully admitted run IDs, and demonstrate live 200, 409, and retry behavior.
