## Summary

Keep this PR open: the latest head resolves the previously reported remote-end lifecycle defects, but explicit leave can still omit final captions and bounded retirement can silently turn an older meeting into an apparently successful empty transcript. Live Google Meet proof and a feature-owner decision on transcript lifetime also remain required; likely routing is @steipete, with @Unayung and @vincentkoc as adjacent browser-transport contributors.

## What This Changes

The PR adds bounded per-session Google Meet caption accumulation with cursor-based retrieval through gateway, tool, and CLI surfaces, plus background draining, ended-session retention, tests, and documentation.

## Best Possible Solution

Before merge, capture and merge the final browser window on explicit leave, represent ended-transcript eviction as an explicit unavailable state across gateway/tool/CLI responses, document every retention boundary, and validate the owner-approved lifetime contract in a real captioned meeting.
