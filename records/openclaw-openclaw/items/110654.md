## Summary

Keep this PR open: the new Settings → MCP controls can build a merge patch from a stale configuration snapshot while the scoped MCP editor has a pending autosave, so a fast add/toggle/remove can overwrite or misclassify the editor’s latest MCP change. The protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The PR adds MCP-server management controls to Settings → MCP, shares the MCP form and config-patch helpers with Plugins, and removes the duplicate MCP config section from Infrastructure.

## Best Possible Solution

Make every Settings → MCP server mutation obtain or compose against the post-autosave authoritative config, or disable card mutations while the scoped MCP draft is dirty, then prove add/toggle/remove preserve a concurrently edited server definition.
