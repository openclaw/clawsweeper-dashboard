The branch changes Gateway startup update checks, config help, docs, and tests so stored extended-stable package installs can emit read-only availability hints on startup and every 24 hours without auto-applying updates.

## Best Possible Solution

Guarantee extended-stable startup discovery whenever there is no compatible cached extended-stable availability, keep auto-apply disabled, and back it with both focused regression coverage and redacted real startup proof.
