## What This Changes

The branch adds process-global, target-keyed coordination so concurrent browser shutdown and sweep requests close each tracked volatile tab once, preserve retries after failed closes, and return accurate cleanup counts.

## System Context

The bundled Browser plugin records active browser targets for agent sessions, then shutdown and idle-cleanup paths ask the registry to close them. This change sits in the volatile in-process registry and prevents concurrent callers, including duplicate loaded plugin bundles, from issuing duplicate browser-close requests before the tab record is removed.

  D -- No --> F[Reserve target-wide cleanup]
  F --> G[Close browser target]
  G --> H[Remove target on success or allow retry on failure]
