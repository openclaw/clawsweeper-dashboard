## Summary

Keep open: current main and the latest release still provide only raw editable workspace files, not the requested pinned key-value facts panel or a structured always-injected facts contract. ## What This Changes

Request a Control UI pinned-facts panel for creating and editing user-defined persistent facts that are guaranteed to enter future agent context.

## Best Possible Solution

Define a first-class pinned-facts contract before implementation: storage owner, always-injected versus last-seen semantics, safe save/audit UX, authorization rules, and bounded context-injection tests.
