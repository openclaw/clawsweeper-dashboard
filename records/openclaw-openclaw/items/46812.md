## Summary

Keep open: current main and v2026.6.11 have a generic allowlisted Agent Files editor for bootstrap files and MEMORY.md, but they still do not provide a structured pinned key-value facts panel, dedicated pinned-context storage, or an explicit always-injected/freshness contract. The useful comments from 1fanwang and icophy add concrete plugin-panel and stale-fact design context, so this should remain a maintainer product/security decision rather than conservative cleanup.

## What This Changes

Requested a Control UI pinned-context panel for user-defined persistent facts that users can edit without directly editing MEMORY.md or USER.md.

## Best Possible Solution

Keep this issue as the canonical pinned-facts design item until maintainers define storage, always-injected versus last-seen semantics, diff-preview/audit behavior, authorization, and context-injection tests coordinated with the memory panel and Control UI plugin-slot work.
