## Summary

Keep open. Current main and v2026.6.11 have a generic allowlisted Agent Files editor for USER.md and root MEMORY.md, but they still do not provide a structured pinned-facts panel, explicit always-injected versus last-seen semantics, or a decided storage/security model; the discussion usefully links a manifest-first panel prototype and production MEMORY.md/USER.md experience as design input.

## What This Changes

Add a Control UI panel for user-defined persistent facts that users can add, edit, delete, and have reliably injected into agent context.

## Best Possible Solution

Define one maintainer-approved pinned-context model with explicit storage, always-injected versus last-seen semantics, browser authorization, safe write/diff behavior, and a clear relationship to memory files, workspace file management, and plugin UI slots before implementation.
