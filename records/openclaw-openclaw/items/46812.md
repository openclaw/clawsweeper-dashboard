## Summary

Keep open. Current main provides a generic Agent Files editor for bootstrap files and root MEMORY.md, but there is still no pinned-facts data model, Control UI panel, or freshness/injection contract for user-defined facts that should always be present in agent context.

## What This Changes

Add a Control UI panel or sidebar widget for adding, editing, and deleting user-defined persistent facts that are injected into agent context on every turn.

## Best Possible Solution

Settle one secured pinned-context contract first, then implement the UI as either a first-party memory panel or a plugin contribution that records fact freshness, shows save diffs, and writes only through the approved memory/context boundary.
