## Summary

Keep open: current main and v2026.6.11 provide whole-file editing for allowed bootstrap files plus MEMORY.md, but not a structured pinned-facts panel, dedicated pinned-context storage, freshness labels, or a guaranteed fact-injection contract. The related open issues overlap on memory editing and Control UI contribution slots, but none supersedes this focused product/security decision.

## What This Changes

Add a pinned Control UI panel or sidebar for user-defined persistent facts backed by structured storage and injected into agent context every turn.

## Best Possible Solution

A maintainer-approved pinned-context design should integrate with the memory panel or plugin-slot plan and make storage, diff preview, freshness or expiry labels, and injection semantics explicit before code.
