## Summary

Keep open: current main has adjacent whole-file editing and read-only workspace browsing, but it does not provide a structured pinned-facts panel, freshness model, write-back UX, or guaranteed injection contract for user-defined persistent facts.

## What This Changes

The issue requests a Control UI panel for adding, editing, and guaranteeing injection of user-defined persistent context facts.

## Best Possible Solution

Define a host-owned pinned-context contract first, with freshness labels, auditable diff-preview writes, scoped storage, and explicit injection semantics before building the Control UI panel.
