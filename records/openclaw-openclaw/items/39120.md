## Summary

Keep open: current main and v2026.6.11 still reject configured extra bootstrap files whose basename is outside the recognized workspace bootstrap list, and the open closing PR remains the active implementation candidate rather than a merged fix.

## What This Changes

The issue requests support for injecting arbitrary workspace-relative files into bootstrap context without renaming them to one of the built-in bootstrap filenames.

## Best Possible Solution

Keep this as the canonical tracker and resolve it through a rebased, repaired https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace guards, budgets, diagnostics, docs, and session filtering.
