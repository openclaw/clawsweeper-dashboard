## What This Changes

Request to let `bootstrap-extra-files` inject explicitly configured arbitrary workspace files into startup Project Context, subject to existing workspace and size guards.

## Best Possible Solution

Keep this issue as the canonical tracker and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace containment, size budgets, deterministic ordering, and session filtering.
