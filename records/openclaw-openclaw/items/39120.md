## Summary

Keep open: current main and the latest release still reject explicitly configured extra bootstrap files whose basename is outside the recognized list, and https://github.com/openclaw/openclaw/pull/74735 is still the open candidate fix rather than a landed implementation.

## What This Changes

The issue requests support for injecting arbitrary workspace files into bootstrap context instead of limiting `bootstrap-extra-files` to recognized bootstrap basenames.

## Best Possible Solution

Keep this as the canonical issue until a maintainer-approved bootstrap-extra-files contract lands, preserving workspace containment, size budgets, diagnostics, deterministic ordering, session filtering, and docs.
