## What This Changes

The issue requests support for injecting arbitrary workspace files into bootstrap context instead of being limited to recognized bootstrap basenames.

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower replacement after it preserves workspace guards, budgets, session filtering, docs, and maintainer-approved scope.
