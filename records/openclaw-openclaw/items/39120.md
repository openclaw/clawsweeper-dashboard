## Summary

Keep open: current main and the latest release still reject configured `bootstrap-extra-files` paths whose basename is not recognized, and the open closing PR remains the active but conflicting product-decision path.

## What This Changes

The issue requests support for arbitrary workspace file paths in bootstrap context injection so users do not have to rename files or embed unrelated context in `AGENTS.md`.

## Best Possible Solution

Keep this as the canonical issue and resolve it through https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace containment, size budgets, diagnostics, deterministic ordering, and session filtering.
