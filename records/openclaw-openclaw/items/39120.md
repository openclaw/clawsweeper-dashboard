## Summary

Keep open: current main and the latest release still reject explicitly configured extra bootstrap files whose basename is outside the recognized bootstrap list, and the open linked pull request is the active implementation candidate rather than a landed fix.

## What This Changes

The issue requests support for injecting arbitrary workspace files into bootstrap context through `bootstrap-extra-files` or an equivalent first-class context-file configuration.

## Best Possible Solution

Keep this as the canonical issue and resolve it through a rebased, maintainer-approved https://github.com/openclaw/openclaw/pull/74735 or a narrower replacement that preserves workspace guards, size budgets, diagnostics, session filtering, and docs.
