Rationale: This expands deterministic system-prompt context and file-loading scope, which is a product and security-boundary choice rather than a mechanical bug fix.

Likely owner: steipete

Owner confidence: high

Options:

- **Approve guarded custom files (recommended):** Allow custom basenames only when explicitly configured and still protected by workspace containment, size budgets, ordering, diagnostics, and session filtering.
- **Keep recognized basenames only:** Reject arbitrary bootstrap-file injection and steer users toward first-class filename proposals or workspace convention docs instead.
- **Defer to broader context design:** Leave this issue open until maintainers settle a larger context-files or capability-discovery API.
