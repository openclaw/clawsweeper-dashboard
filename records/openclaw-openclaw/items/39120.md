## Summary

Keep open: current main and the latest release still reject explicitly configured extra bootstrap files with custom basenames, and the linked implementation PR is still open and dirty. This remains the canonical product-decision tracker for the bootstrap context contract.

## What This Changes

The issue requests support for injecting arbitrary workspace files into bootstrap context through `bootstrap-extra-files` or an equivalent first-class context-file configuration.

## Best Possible Solution

Keep this issue as the canonical tracker and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower replacement after it preserves workspace guards, budgets, session filtering, docs, tests, and maintainer-approved scope.
