## Summary

Keep open: current main and v2026.6.11 still reject explicitly configured extra bootstrap files with custom basenames, and the open closing PR is an implementation candidate rather than a landed fix.

## What This Changes

The issue requests support for injecting arbitrary workspace-relative files into bootstrap session context instead of limiting extra bootstrap files to recognized basenames.

## Best Possible Solution

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower replacement that preserves workspace containment, budgets, session filtering, and docs.
