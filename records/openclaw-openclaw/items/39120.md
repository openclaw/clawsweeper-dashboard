## Summary

Keep open: current main and v2026.6.11 still reject configured extra bootstrap files whose basename is not recognized, and the linked closing PR is open, unmerged, and conflicting.

## What This Changes

Request support for injecting arbitrary workspace-relative files into bootstrap context through `bootstrap-extra-files` or a first-class config surface while preserving workspace guards and bootstrap budgets.

## Best Possible Solution

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace guards, budgets, session filtering, and docs.
