## Summary

Keep open: current main and v2026.6.11 still reject configured extra bootstrap files with unrecognized basenames, and the open linked implementation PR remains the active candidate rather than a merged fix.

## What This Changes

The issue requests support for injecting arbitrary workspace files into bootstrap/session context instead of limiting `bootstrap-extra-files` to recognized bootstrap basenames.

## Best Possible Solution

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace guards, size budgets, session filtering, and docs.
