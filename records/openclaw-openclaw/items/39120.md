## What This Changes

The issue requests support for injecting arbitrary workspace-relative files into bootstrap context instead of only recognized bootstrap basenames.

Resolve this through the linked implementation PR or a narrower maintainer-approved replacement that preserves workspace containment, bootstrap budgets, session filtering, and docs.
