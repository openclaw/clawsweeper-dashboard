## Summary

Keep open: current main and v2026.6.11 still reject explicitly configured extra bootstrap files whose basename is not recognized, and https://github.com/openclaw/openclaw/pull/74735 remains the open implementation candidate rather than merged proof.

## What This Changes

The issue requests support for arbitrary workspace-relative files to be injected into bootstrap context without renaming them to recognized workspace bootstrap basenames or embedding them in AGENTS.md.

## Best Possible Solution

Keep this as the canonical tracking issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower approved replacement that preserves workspace containment, size budgets, deterministic ordering, duplicate handling, and session filtering.
