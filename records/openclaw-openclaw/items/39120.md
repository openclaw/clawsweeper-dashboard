## What This Changes

The issue requests support for injecting arbitrary workspace files into bootstrap context instead of limiting `bootstrap-extra-files` to recognized bootstrap basenames.

## Best Possible Solution

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace guards, budgets, ordering, session filtering, and docs.
