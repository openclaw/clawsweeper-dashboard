## Summary

Keep open: current main and v2026.6.11 still reject explicitly configured extra bootstrap files whose basename is not in the recognized bootstrap list, and the open linked implementation PR has not merged.

## What This Changes

Request to let `bootstrap-extra-files` inject explicitly configured arbitrary workspace files into startup context instead of only recognized bootstrap basenames.

## Best Possible Solution

Keep this as the canonical tracker and resolve it by landing `https://github.com/openclaw/openclaw/pull/74735` or a narrower maintainer-approved replacement that preserves workspace containment, size budgets, deterministic ordering, docs, and tests.
