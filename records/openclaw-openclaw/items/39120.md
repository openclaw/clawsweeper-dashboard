## Summary

Keep open: current main and v2026.6.11 still reject explicitly configured extra bootstrap files whose basename is outside the recognized bootstrap list, and https://github.com/openclaw/openclaw/pull/74735 is the open conflicting implementation candidate rather than a landed fix.

## What This Changes

The issue requests support for injecting explicitly configured arbitrary workspace files into bootstrap context instead of limiting extra files to recognized bootstrap basenames.

## Best Possible Solution

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower replacement that preserves workspace containment, bootstrap budgets, session filtering, and clear docs.
