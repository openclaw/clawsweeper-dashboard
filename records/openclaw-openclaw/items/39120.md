Keep open: current main and the latest stable release still reject explicitly configured extra bootstrap files whose basename is not recognized, while https://github.com/openclaw/openclaw/pull/74735 remains the open implementation candidate for this issue.

## What This Changes

Request support for injecting explicitly configured arbitrary workspace files into bootstrap context instead of limiting `bootstrap-extra-files` to recognized bootstrap basenames.

## Best Possible Solution

Keep this as the canonical issue and resolve it by landing https://github.com/openclaw/openclaw/pull/74735 or a narrower maintainer-approved replacement that preserves workspace guards, budgets, session filtering, and docs.
