## What This Changes

The issue requests support for explicitly configured arbitrary workspace files in bootstrap context instead of only recognized bootstrap basenames.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/74735 or a narrow replacement that lets explicitly configured in-workspace files pass existing realpath, size, budget, session-filtering, and docs/tests guardrails.
