## What This Changes

Fix OpenAI utility-model simple completions so API-key authentication uses the public Responses API while ChatGPT/Codex authentication uses the ChatGPT backend.

## Best Possible Solution

Materialize the OpenAI model route in shared simple-completion preparation after auth resolution, reusing provider auth-requirement route candidates so API keys select the public or authored Platform route and subscription credentials select the ChatGPT route; cover derived utility, explicit model, OAuth, API-key, and custom-endpoint cases.
