## Label Justifications

- `P2`: Transient OAuth refresh failures can interrupt OAuth-backed provider calls, but the impact is limited to affected auth/provider workflows and has restart or later-retry workarounds.
- `impact:auth-provider`: The issue directly concerns OAuth token refresh and continued provider authentication.

## Summary

Keep open: current main and the latest release still make one ordinary OAuth refresh attempt for transient provider/API failures; only the refresh-token-reuse recovery path retries, and the direct retry PRs are closed unmerged.

## What This Changes

Request a bounded retry policy for transient OAuth token refresh failures so agents do not fail immediately on temporary provider/network errors.

## Best Possible Solution

Add bounded retry at the centralized OAuth manager boundary using retryAsync, an auth-owner-approved transient classifier, and tests that preserve locking, adoption/fallback, plugin hooks, and refresh-token-reuse recovery.

## Reproduction Assessment

Yes, by source inspection rather than a live transient-provider failure. An expired or forced OAuth refresh invokes one provider refresh call, and current tests show HTTP 500 and network timeout do not enter the only specialized recovery branch.

## Solution Assessment

No, the proposed local withRetry wrapper around getOAuthApiKey is too narrow for the final design. The safer solution belongs at the centralized OAuth manager boundary with retryAsync, a transient-error classifier, and auth-owner timing semantics.

## Risks / Open Questions

- A retry policy needs a narrow transient-error classifier so invalid_grant, revoked refresh tokens, malformed token responses, and other permanent OAuth failures are not retried as temporary failures.
- The retry budget and backoff need to fit the existing hard refresh-call timeout and global refresh-lock budget so waiting agents are not stalled unexpectedly.
- Provider plugin refresh hooks may already own retries internally, so shared core retry could create double-retry semantics without a clear contract.
