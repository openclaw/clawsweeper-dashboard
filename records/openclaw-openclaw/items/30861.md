- `P2`: This is a normal-priority Control UI safety improvement for multi-agent users with meaningful workflow impact but no outage.

## Summary

Keep open: current main and the latest release still render only active-agent context in the persistent Dashboard header, while the focused workspace-context implementation is an open, conflicting PR rather than merged behavior.

## What This Changes

The issue requests a persistent Dashboard header indicator for active agent and workspace, with switch feedback, to reduce wrong-agent or wrong-workspace interactions in multi-agent web chat.

## Best Possible Solution

Land or replace the focused Control UI header workspace breadcrumb, then track optional quick-switch, color/icon, message-prefix, and deeper live-session proof separately if maintainers still want them.

## Reproduction Assessment

Yes. Source inspection of current main shows the persistent Dashboard header only projects and renders agentLabel, while workspace root is shown only inside the workspace rail when available.

## Solution Assessment

Yes for the focused slice. Extending the existing Dashboard header context with workspace/cwd is narrower than bundling a switcher, color system, or message-prefix setting, but maintainers still need to decide the linked PR and any follow-up scope.
