## What This Changes

Request clearer heartbeat skipped diagnostics when the default `target: "none"` configuration intentionally disables delivery.

## Best Possible Solution

Keep `target-none` stable as the machine reason and add a clearly human-facing disabled-delivery hint to heartbeat events and status/CLI presentation.
