## What This Changes

The issue asks OpenClaw to make default disabled-delivery heartbeat skips clearer by renaming `target-none`, adding a human-readable hint, or improving heartbeat/status presentation.

## Best Possible Solution

Keep `target-none` stable as the machine reason and add a human-facing disabled-delivery hint that heartbeat status and CLI output render clearly.
