## Summary

Keep open: current main and v2026.6.11 still expose disabled heartbeat delivery as `reason: "target-none"` without a disabled-delivery hint, and the two direct fix PRs closed unmerged. The remaining blocker is maintainer product direction on preserving the machine reason with an additive hint versus renaming the reason.

## What This Changes

The issue asks for heartbeat skips caused by default disabled delivery to expose clearer wording or hints instead of only `reason: "target-none"`.

## Best Possible Solution

Keep `reason: "target-none"` stable unless maintainers explicitly approve a rename, and add a disabled-delivery hint or display path that reaches heartbeat-last and deep status output with focused tests.
