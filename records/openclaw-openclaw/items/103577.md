## Summary

The PR remains necessary as the candidate fix for the open callback-semantics bug, but the current head still deprecates a shipped plugin callback field without an approved lifecycle and provides only mocked-callback proof.

## What This Changes

Adds zero-based `apiKeyIndex` and one-based `attemptNumber` to API-key rotation callback parameters, deprecates the existing `attempt` field, and adds regression assertions for the new values.

## Best Possible Solution

Keep the additive `apiKeyIndex` and `attemptNumber` fields, leave `attempt` fully supported unless maintainers explicitly approve a deprecation plan, document the counter semantics at the plugin boundary, and prove the values through a redacted real provider or installed-plugin retry.
