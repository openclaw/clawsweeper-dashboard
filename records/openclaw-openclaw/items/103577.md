## Summary

The source bug is real and the branch preserves the old runtime value, but this remains a public plugin-SDK contract change: deprecating the shipped `attempt` field has no approved removal plan, and the only after-fix evidence uses mocked callbacks.

## What This Changes

The PR adds zero-based `apiKeyIndex` and one-based per-key `attemptNumber` to API-key rotation callbacks, keeps `attempt` mapped to the key index with a deprecation annotation, and adds callback assertions.

## Best Possible Solution

Keep the two explicit fields, preserve `attempt` as a supported key-index alias unless an owner approves a documented deprecation window, and demonstrate the exported helper through an installed test plugin or equivalent real runtime retry.
