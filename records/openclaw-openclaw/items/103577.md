## What This Changes

The PR adds zero-based `apiKeyIndex` and one-based `attemptNumber` to API-key rotation callbacks, retains `attempt` as the key index, marks it deprecated, and adds mocked callback assertions.

## Best Possible Solution

Expose distinct key-index and per-key-attempt values through the existing callback, retain `attempt` under an explicitly approved compatibility policy, and prove the final contract with a redacted real provider or plugin retry transcript.
