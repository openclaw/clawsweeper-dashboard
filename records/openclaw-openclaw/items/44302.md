## Summary

Keep open. Current main preserves external route state in related paths, but WebChat-originated turns still require explicit delivery to route externally and the requested default-off mirroring config is not present.

## What This Changes

The issue requests an opt-in setting to mirror Control UI/WebChat replies to the session's last active external channel for multi-device workflows.

## Best Possible Solution

Have maintainers choose one explicit cross-surface delivery policy, then implement either this default-off mirror flag or fold the WebChat case into the broader origin-delivery model with security-reviewed safeguards and live Discord or Telegram proof.
