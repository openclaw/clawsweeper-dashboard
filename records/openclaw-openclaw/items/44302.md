## Summary

Keep open. Current main still lacks the requested opt-in WebChat-to-external-channel mirroring config, and the existing WebChat route guards intentionally keep normal Control UI sends internal unless a separate explicit delivery path is used.

## What This Changes

Add a default-off session configuration option that mirrors Control UI/WebChat replies to the session's last established external channel route for multi-device workflows.

## Best Possible Solution

Define a single explicit cross-surface delivery policy, then implement default-off WebChat mirroring only with route freshness, authorization, duplicate-delivery, failure-handling, schema, docs, and live-channel proof.
