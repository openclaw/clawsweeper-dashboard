## Summary

Keep open. Current main and v2026.6.11 still treat ordinary Control UI/WebChat turns as internal unless explicit delivery is set, the requested mirroring config is absent, and the remaining work needs maintainer product and security direction.

## What This Changes

The issue requests a default-off session setting that mirrors Control UI/WebChat replies to the session's last active external channel for multi-device workflows.

## Best Possible Solution

Define one explicit cross-surface delivery policy with stale-route, authorization, duplicate-delivery, and failure-handling rules, then implement the default-off mirroring config or fold it into the accepted origin-delivery model.
