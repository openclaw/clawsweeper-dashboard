## Summary

Keep open. Current main and v2026.6.11 still intentionally keep WebChat replies on WebChat unless an explicit delivery route is requested, and the requested default-off cross-channel mirroring feature remains a product and security-boundary decision.

## What This Changes

Request to add an opt-in session config that mirrors Control UI/WebChat replies to the session's last established external channel route.

## Best Possible Solution

Define a single cross-surface delivery policy with stale-route, authorization, duplicate-delivery, and failure-handling rules, then either add this default-off mirror config or fold the requirement into the accepted origin-delivery model.
