## Summary

Keep open. Current main preserves external route state in adjacent paths, but it still intentionally prevents WebChat/Control UI turns from implicitly inheriting or routing to external channels, and the requested default-off mirroring config is absent.

## What This Changes

Request to add a default-off session config option that mirrors Control UI/WebChat replies to the session's last active external channel.

## Best Possible Solution

Have maintainers choose one explicit cross-surface delivery policy, then implement either this default-off WebChat mirror flag or fold the WebChat case into the broader origin-delivery model with security-reviewed safeguards and live Discord or Telegram proof.
