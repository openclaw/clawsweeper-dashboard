## Summary

Keep open. Current main and latest release still block implicit WebChat-to-external delivery unless explicit delivery is set, the requested opt-in mirroring config is absent, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

The issue requests an opt-in config flag that mirrors Control UI/WebChat replies to the session's last active external channel for multi-device workflows.

## Best Possible Solution

Define one explicit cross-surface delivery policy with stale-route, authorization, duplicate-delivery, and failure-handling rules, then implement the default-off mirroring config or fold it into an accepted origin-delivery model with live channel proof.
