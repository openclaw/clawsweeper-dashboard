## Summary

Keep open. Current main and v2026.6.11 still keep WebChat replies in WebChat unless an explicit external delivery route is supplied, the requested opt-in mirroring config is absent, and the remaining change needs maintainer product and security direction.

## What This Changes

The issue requests a default-off config option that mirrors Control UI/WebChat-originated replies to the session's last established external channel route.

## Best Possible Solution

Define one cross-surface delivery policy with stale-route, authorization, duplicate-delivery, and failure-handling rules, then either implement this default-off mirroring option or fold it into the broader origin-delivery model.
