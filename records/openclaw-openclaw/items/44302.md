## Summary

Keep open. Current main still preserves external route metadata in related paths but intentionally prevents ordinary WebChat/Control UI turns from inheriting or mirroring that route, and the requested default-off session config does not exist.

## What This Changes

Add an opt-in setting that mirrors Control UI/WebChat replies to the session’s last active external channel for multi-device workflows.

## Best Possible Solution

Define one security-reviewed cross-surface delivery policy, then implement either a narrow default-off WebChat mirror flag or fold this case into the broader origin-delivery model with focused tests and live channel proof.
