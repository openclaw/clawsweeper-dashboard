## Summary

Keep open. Current main and the latest release still keep WebChat-originated Control UI sends internal unless an explicit delivery route is set, and the requested default-off mirroring config is absent, so this remains a product and security routing decision.

## What This Changes

The issue requests an optional config flag that mirrors Control UI/WebChat replies to the session's last active external channel for multi-device workflows.

## Best Possible Solution

Define one cross-surface delivery policy, then implement either a default-off WebChat-to-last-external mirror or fold this case into the broader origin-delivery model with schema, docs, regression tests, and live channel proof.
