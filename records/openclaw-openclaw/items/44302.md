## Summary

Keep open. Current main and v2026.6.11 still intentionally keep WebChat-originated Control UI sends internal unless explicit delivery is requested, and the requested default-off mirroring config is absent, so this remains a product and security routing decision.

## What This Changes

The issue requests an opt-in config setting that mirrors Control UI WebChat replies to the session's last active external channel for multi-device workflows.

## Best Possible Solution

Have maintainers choose one cross-surface delivery policy, then implement either a default-off WebChat-to-last-external mirror or fold this case into the broader origin-delivery model with explicit security safeguards, schema/docs, tests, and live channel proof.
