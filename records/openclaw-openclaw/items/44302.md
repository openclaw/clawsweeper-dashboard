## Summary

Keep open. Current main and v2026.6.11 still block implicit WebChat-to-external routing and do not expose the requested opt-in mirroring config, so this remains a real product/security decision rather than cleanup.

## What This Changes

Add a default-off config option that mirrors Control UI/WebChat replies to a session's last established external channel for multi-device workflows.

## Best Possible Solution

Define one explicit cross-surface delivery policy with stale-route, authorization, duplicate-delivery, and failure-handling rules, then implement either a default-off mirroring config or fold it into the accepted origin-delivery model.
