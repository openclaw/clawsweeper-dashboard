## What This Changes

Repair upgrades of existing agent SQLite databases so memory-index metadata columns are added before Gateway schema validation and Doctor can recover the database.

## System Context

OpenClaw stores each agent’s indexed-memory records in that agent’s SQLite database. Gateway startup and Doctor validate those databases against the canonical schema, so a newly required column must be migrated before either path can safely proceed.

## Best Possible Solution

Add idempotent additive migrations for `memory_index_chunks.importance` and `memory_index_chunks.triggers` in the agent-database schema ensure path, then cover both Gateway startup and `openclaw doctor --fix` against an old-shape database.
