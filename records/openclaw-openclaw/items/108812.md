## Summary

Keep this PR open for a narrow correction. The earlier partial-output separator finding is fixed and the live proof is strong, but the disconnect settlement still awaits ACP client update delivery before rejecting the prompt, so an unresponsive client can defeat the five-second grace deadline and leave the turn pending indefinitely.

## What This Changes

The PR adds acceptance-aware, replay-durable ACP interruption notices when an in-flight prompt is rejected after a prolonged Gateway outage.

## Best Possible Solution

Retire the prompt synchronously, persist the terminal interruption independently, and deliver the live update concurrently or with a strict bound so client backpressure cannot delay rejection; preserve exactly-once settlement, partial-output separation, replay equality, and acceptance-aware retry guidance.
