## Summary

This PR addresses the right retry path, but the production call site still permits only three attempts, so its 10s/20s rate-limit schedule gives up around 30 seconds—before the stated 60-second cooldown can clear. The supplied proxy trace confirms that outcome, so the patch is not ready to merge yet.

## Best Possible Solution
