## Summary

Keep open: the reported corruption is valid and the submitted proof is convincing, but the implementation covers only single-underscore emphasis while the sibling double-underscore path can still corrupt the same class of identifiers and URLs.

## What This Changes

The PR changes Twitch-local Markdown stripping to preserve single underscores inside Unicode words and adds regression coverage for identifiers, URLs, Cyrillic, CJK, and standalone emphasis.

## Best Possible Solution

Use one Twitch-local, delimiter-aware rule for both `_..._` and `__...__` so intraword Unicode identifiers remain byte-preserved while standalone italic and bold markers still normalize to plain text.
