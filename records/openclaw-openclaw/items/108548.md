## Summary

Keep this PR open: the Twitch corruption is valid and the supplied live output is useful, but the patch creates a second channel-local implementation of underscore-emphasis semantics that current `main` already exposes through the shared text runtime. That duplication is a merge blocker because the same Unicode delimiter behavior can drift across channels.

## What This Changes

The PR changes Twitch Markdown stripping to preserve underscores embedded in words and adds Latin, URL, Cyrillic, CJK, and standalone-emphasis regression cases.

## Best Possible Solution

Keep Twitch-specific chunk sizing and transport behavior, but delegate Markdown stripping or at least underscore-delimiter classification to the shared text-runtime implementation, with Twitch regressions proving identifiers, URLs, Unicode words, and standalone emphasis remain correct.
