## Summary

Keep open: the reported Twitch corruption is valid, but this patch creates a second implementation of intraword-underscore handling that current shared markdown normalization already owns, risking divergent channel behavior.

## What This Changes

Updates Twitch outbound Markdown stripping to preserve Unicode intraword underscores and adds regression coverage for identifiers, URLs, Cyrillic, CJK, and standalone emphasis.

## Best Possible Solution

Keep one canonical Unicode-aware underscore-emphasis rule in the shared text normalization surface, route Twitch through it or extract a focused reusable helper, and prove the resulting behavior with both regression tests and a real Twitch send.
