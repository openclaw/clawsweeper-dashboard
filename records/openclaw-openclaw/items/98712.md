## Best Possible Solution

Keep the provider-local fix, but derive a stable mock request key from request material, mark repeated requests as replay, add focused regression coverage, and include redacted real HTTP webhook proof before merge.

## Solution Assessment

No. Adding the field in the mock provider is the right layer, but a random UUID is not the best fix because the contract requires stable request identity and replay tracking.
