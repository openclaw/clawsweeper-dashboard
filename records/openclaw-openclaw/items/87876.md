## What This Changes

The issue reports long Bedrock Converse Streaming agent sessions aborting with `promptError` plus `aborted=true`, losing transcript output and bypassing configured model fallback.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99608, or replace it with an equivalent replay-safe provider-abort fallback; keep https://github.com/openclaw/openclaw/pull/99607 scoped to live-smoke harness validation.
