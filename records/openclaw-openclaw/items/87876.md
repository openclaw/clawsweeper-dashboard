Recover long Bedrock Converse Streaming agent runs that abort with provider-originated stream errors by retrying or falling back without losing session progress.

Review and land the narrow core fallback fix in https://github.com/openclaw/openclaw/pull/99608, with the Bedrock live-smoke harness from https://github.com/openclaw/openclaw/pull/99607 used as supporting validation rather than as the closing fix.

## Solution Assessment
