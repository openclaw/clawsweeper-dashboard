## What This Changes

Requested adding a Gateway receipt timestamp to inbound metadata so agents can distinguish source-channel delivery delay from OpenClaw processing latency.

## Best Possible Solution

Define one additive generic ingress timing contract, reuse existing internal receive-time sources where their semantics match, and expose it consistently through channel inbound context, TemplateContext, agent-visible metadata, docs, and focused tests.

## Reproduction Assessment

## Solution Assessment
