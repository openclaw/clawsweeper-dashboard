Request to add an agent-visible Gateway receipt timestamp to generic inbound metadata so latency can be measured separately from source-channel timestamps.

## Best Possible Solution

Define one additive generic ingress timing contract, then expose it consistently through inbound context, agent-visible metadata, SDK/docs, and focused cross-channel tests.
