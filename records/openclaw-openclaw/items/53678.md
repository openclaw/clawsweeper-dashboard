## What This Changes

Request adds a gateway-receive timestamp to inbound agent metadata so latency can separate channel delivery delay from processing time.

## Best Possible Solution

Define one additive generic ingress timing contract, then expose it consistently through inbound context, agent-visible metadata, SDK/docs, and cross-channel tests.
