## What This Changes

Request to add a Gateway-received timestamp to inbound metadata so agents can separate channel delivery delay from agent processing latency.

## Best Possible Solution

Define one additive generic ingress timing contract, then expose it consistently through inbound context, agent-visible metadata, SDK docs, and focused channel tests.
