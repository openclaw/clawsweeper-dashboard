## Summary

Keep open: current main and the latest release still expose the source-channel timestamp but no agent-visible Gateway receipt timestamp. The request is useful and source-proven, but it creates a cross-channel prompt/SDK metadata contract that needs maintainer product direction before implementation.

## What This Changes

Add an agent-visible Gateway receipt timestamp to inbound metadata so latency can be split between source-channel delivery and OpenClaw processing.

## Best Possible Solution

Define one generic Gateway receipt timestamp contract, then propagate it from channel ingress into inbound context formatting with focused cross-channel coverage.
