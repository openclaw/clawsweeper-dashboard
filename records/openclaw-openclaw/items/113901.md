## What This Changes

The draft PR forwards a stopped managed Gateway service’s profile, state/config paths, and port into post-update subprocesses so a shell using another profile cannot converge or restart the wrong Gateway.

## System Context

`openclaw update` stops a managed Gateway, updates the installation, then launches post-update plugin, doctor, validation, and restart work. Those child processes must use the stopped service’s owning profile and paths so they act on the same Gateway rather than the invoking shell’s profile.
