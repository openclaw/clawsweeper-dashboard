## What This Changes

The PR replaces separate ClawHub and Memory Core retry loops with the shared retry parser, retry runner, and abortable delay helper while adding regressions for cancellation, HTTP-date handling, and QMD lease-abort behavior.

## System Context

ClawHub uses bounded retries for idempotent registry reads, while Memory Core retries embedding queries and QMD synchronization operations. Both paths decide whether a failure is retryable, wait or abort, and then return a final HTTP response or memory-operation result to their callers.
