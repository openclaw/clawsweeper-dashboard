## Summary

Keep open: current main still has the mid-batch parallel-tool abort race, and the latest stable release shows the same deferred prepared-call execution path, so the paid-tool cancellation bug remains actionable.

## What This Changes

Prevent already-prepared parallel tool calls from starting `execute` after an agent run is aborted mid-batch, especially for paid media-generation tools.

## Best Possible Solution

Add a core agent-loop abort boundary before any prepared parallel tool starts execution, preserving ordered finalized results and keeping cancellation policy out of individual paid tools.
