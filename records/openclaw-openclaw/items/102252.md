## What This Changes

The issue requests that agent-core skip already prepared parallel tool calls when the run is aborted before their execute step starts.

## Best Possible Solution

Add a core agent-loop abort boundary before any prepared parallel tool starts execution, preserving ordered finalized results and keeping cancellation policy out of individual paid tools.
