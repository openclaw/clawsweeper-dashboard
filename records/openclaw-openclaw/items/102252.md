## Summary

Keep open: current main still has the parallel prepared-tool abort race, and two open PRs now explicitly close this issue, so the issue should stay open until one fix lands.

## What This Changes

The issue asks agent-core to skip already-prepared parallel tool executions after a run is aborted mid-batch, avoiding paid or side-effectful tool calls after cancel.

## Best Possible Solution

Land one narrow agent-core fix that re-checks abort before prepared execute, records skipped calls with executionStarted false, skips afterToolCall for work that never started, and keeps focused regression coverage.
