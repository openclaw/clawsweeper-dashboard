## What This Changes

This PR caches parsed SQLite session entries per opened agent database, validates normal reads with SQLite `data_version`, and publishes local write-through updates after committed session mutations.

## System Context

OpenClaw’s session accessor serves stored agent-session records to gateway APIs such as session listings and to Control UI projections. The PR places a process-local parsed snapshot between SQLite session-node rows and those read APIs, while committed writes are meant to refresh or invalidate the snapshot.
