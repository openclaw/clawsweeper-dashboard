## Summary

Keep open. Current main still batches the classic Voice Call STT to embedded-agent to telephony-TTS path, while realtime voice and general non-telephony TTS streaming are adjacent capabilities rather than the requested provider-generic sentence-level telephony pipeline.

## What This Changes

Requests a provider-generic sentence-level classic voice-call pipeline from LLM partial text through streaming telephony TTS to Twilio/Telnyx audio.

## Best Possible Solution

Implement an additive provider-generic telephony streaming contract plus voice-call sentence pipeline that preserves buffered fallback, barge-in cancellation, playback ordering, and realtime voice as a separate bypass mode.

- **Approve a provider-specific experiment:** Allow a Twilio/OpenAI or ElevenLabs-first implementation with follow-up API work before Telnyx and other providers share it.
