## What This Changes

The PR makes cron executions terminal when a provider has already classified an HTTP 429 failure as exhausted billing, while retaining retries for failures classified as transient rate limits.

## System Context

Cron job execution passes provider error text and its classified failure reason to the retry resolver. The resolver's decision controls whether the scheduler retries a job or records a terminal result and releases admission capacity.
