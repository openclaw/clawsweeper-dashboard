## Summary

Keep this PR open, but do not merge it as written. The isolation fix is valid; however, the patch also removes the documented operator-owned relocation migration and its fail-closed guard, so an upgrading installation can ignore an existing restrictive approval policy and initialize the custom state scope with permissive defaults. Current documentation explicitly presents direct Doctor migration as the upgrade path. citeturn9search0turn7view0turn13search6

## What This Changes

The PR removes cross-state exec-approval and plugin-binding approval migrations across the CLI, Doctor, update/watch flows, and macOS so custom state directories operate as independent trust scopes.

## Best Possible Solution

Keep custom scopes isolated by default, but preserve a clearly operator-directed Doctor import path for intentional primary-state relocation and prove both isolation and upgrade behavior across TypeScript and macOS.
