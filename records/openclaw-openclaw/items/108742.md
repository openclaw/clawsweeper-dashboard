## Summary

Keep this PR open, but do not merge it as written. It fixes a real isolation failure for named, automated, and macOS custom-state runs, yet it also removes the documented direct-doctor migration for bare `OPENCLAW_STATE_DIR` relocation and drops the runtime guard that kept an unmigrated restrictive policy fail-closed. That broadening can leave upgrading users on the permissive `full`/`off` defaults, so the trust-boundary and upgrade contract need explicit maintainer resolution.

## What This Changes

Removes cross-state exec and plugin-binding approval imports and fallback coupling across TypeScript and macOS, updates the associated docs and tests, and makes the APNs tombstone table `STRICT`.

## Best Possible Solution

Keep named profiles, automation, temporary instances, and the macOS app strictly state-scoped, while preserving a narrow operator-owned migration for bare primary-state relocation and retaining fail-closed behavior until that migration succeeds; if maintainers instead retire relocation compatibility, ship an explicit doctor recovery flow that never falls back to permissive defaults.
