## Summary

The patch is a focused, technically sound fix for the reproduced compaction-auth failure, and the earlier review blockers are resolved; it should remain open for auth-owner acceptance of the intentional inherited-profile credential fallback.

## What This Changes

The PR lets compaction fall through from an incompatible inherited OpenAI OAuth profile to the configured API-key auth order while keeping user-selected and unknown-source profiles strict.

## Best Possible Solution

Land the source-aware compaction-only fallback, retain fail-fast behavior for user-selected or unknown profiles, drop provenance on provider changes, and continue using the existing canonical auth order rather than creating a separate compaction credential path.
