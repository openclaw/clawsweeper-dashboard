## Summary

The PR remains necessary and the current head is a focused, compatibility-conscious fix: it resolves inherited-profile compaction fallback while preserving fail-fast behavior for user-selected and unknown-source profiles. The two earlier P1 findings are addressed, current main still reproduces the source-level failure, the exact head has green CI and accepted real-behavior proof, and no blocking correctness or security defect remains.

## What This Changes

The PR adds an opt-in incompatible-profile fallback to OpenAI credential resolution, propagates auth-profile source through embedded and harness compaction, and adds regression coverage for inherited versus user-locked profiles.

## Best Possible Solution

Merge the source-aware, compaction-only fallback as proposed, keeping default explicit-profile resolution strict and using the existing canonical auth order rather than adding a separate compaction credential stack.
