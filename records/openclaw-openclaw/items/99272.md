## What This Changes

## Best Possible Solution

Keep this as a maintainer-owned Codex watchdog bug: fix blocker-aware attempt-idle deferral and completed-id blocker tracking, let the projector diagnostics PR handle the unknown-method slice if it lands, and make the wall-clock ceiling/open-request policy explicit before changing broader liveness semantics.
