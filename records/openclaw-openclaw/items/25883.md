## Summary

Keep open: current main still does not implement Redis/BullMQ-style distributed job orchestration, shared worker claiming, dead-letter queues, or horizontal worker coordination. The linked ScalyClaw prototype is useful prior art, but this remains a broad product and architecture decision rather than cleanup-close material.

## What This Changes

The issue proposes adding a Redis/BullMQ-style distributed job orchestration layer for background work, delayed jobs, scheduled jobs, retries, observability, and horizontal scaling.

## Best Possible Solution

Keep this open as the broad horizontal-scaling architecture tracker and define a backend-neutral job ownership or plugin API contract before choosing Redis/BullMQ as an implementation detail.
