## Summary

Keep open: current main and v2026.6.11 still do not provide the requested distributed job orchestration, shared worker claiming, Redis/BullMQ backend, dead-letter handling, or horizontal worker coordination. The ScalyClaw prototype is useful prior art, but this remains a maintainer architecture decision rather than a closeable core cleanup item.

## What This Changes

The issue proposes adding Redis/BullMQ-style horizontal job orchestration with dedicated workers, delayed/scheduled jobs, retries, dead-letter handling, and queue observability.

## Best Possible Solution

Define a backend-neutral distributed scheduler/job ownership contract or plugin API first, then evaluate ScalyClaw-style Redis/BullMQ as one implementation and coordinate the cron HA and external session-storage trackers.
