## Summary

Keep open. Current main still appears to schedule first-run onboarding from the app-local onboarding marker even when a configured Gateway resolves to local or remote mode, and the protected maintainer label prevents conservative cleanup closure.

## What This Changes

The issue reports that the macOS app shows first-run onboarding instead of the dashboard for an existing configured Gateway when `openclaw.onboardingSeen` is false.

## Best Possible Solution

After a configured local or remote Gateway connects successfully, mark onboarding complete and open the dashboard; preserve onboarding when the configured Gateway cannot connect.
