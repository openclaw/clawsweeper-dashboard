## What This Changes

This PR exempts bug-labeled issues from Barnacle’s inactivity-close paths, adds a capped stale-label verification lane that dispatches ClawSweeper, and audits any improper Barnacle `not_planned` closures.

## System Context

Barnacle’s stale workflow labels inactive GitHub items, while ClawSweeper reviews a specific item and can apply an evidence-backed resolution. This PR changes the handoff for bug-labeled issues so inactivity no longer produces a terminal Barnacle closure before the review layer evaluates current `main`.
