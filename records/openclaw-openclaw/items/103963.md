## What This Changes

Adds `channels.slack.appHome.view` and account-level overrides so operators can publish a validated inline Slack Block Kit Home view, with built-in-view fallback, documentation, generated config metadata, and focused tests.

## System Context

The Slack extension handles `app_home_opened` events, merges the active account’s Slack configuration, and calls Slack’s `views.publish` API. This PR changes the Home-tab payload from always using OpenClaw’s built-in view to optionally using an operator-provided Block Kit view, while retaining a safe fallback.
