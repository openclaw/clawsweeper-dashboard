## Summary

Keep this PR open for revision: configurable Slack App Home content is independently useful, but the current implementation does not reliably deliver its documented safe fallback and introduces an unsettled request-time file-loading contract.

## What This Changes

The PR adds inline and file-backed Slack App Home view configuration with account overrides, validation, documentation, and focused tests.

## Best Possible Solution

Keep a single plugin-owned App Home override, retry the built-in view when custom publication fails, and resolve size-bounded file content during Slack account startup or an explicit reload lifecycle rather than on every event.
