## Summary

Keep open: current main and v2026.6.11 still do not expose `mediaLocalRoots` as a public Telegram or agent-defaults config key, while the runtime only consumes internal/policy-derived media roots. The remaining work is a security-sensitive config/product decision, not a conservative cleanup close.

## What This Changes

Expose or otherwise support a configurable local-media root policy for Telegram outbound media so trusted non-default host paths can be sent without config validation errors.

## Best Possible Solution

Choose one security-reviewed root policy, then align Telegram schema/types, shared outbound media access, docs, and focused channel/media tests around that single contract.
