## Summary

Keep open: current main and v2026.6.11 still do not expose a public Telegram or agent-defaults mediaLocalRoots config key, and fixing this changes a host-local file-read/upload boundary that needs maintainer product and security direction.

## What This Changes

Request to accept and honor configurable local media roots for Telegram outbound media instead of rejecting mediaLocalRoots in OpenClaw config.

## Best Possible Solution

Choose one canonical security-reviewed host media-root policy, then align schema, exported types, docs, Telegram/outbound delivery, and focused tests around that contract.
