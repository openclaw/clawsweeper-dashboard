## Summary

Keep open: current main and the latest release still do not accept `mediaLocalRoots` as a public Telegram or agent-defaults config key, while the downstream Telegram send path can consume internal media roots once supplied. The remaining work is a product/security decision about the canonical host-local media-root policy, not a conservative cleanup close.

## What This Changes

The issue requests an accepted configuration surface for additional local media roots so Telegram outbound media can send files outside OpenClaw-managed directories.

## Best Possible Solution

Choose one security-reviewed operator root policy, then align schema, runtime propagation, docs, and focused tests so Telegram outbound media and sibling media paths do not grow divergent config knobs.
