## Summary

Keep open: current main and v2026.6.11 still lack a public Telegram or agent-defaults `mediaLocalRoots` config key, and adding one would change the host-local file read/upload boundary that needs maintainer product and security direction.

## What This Changes

The issue requests accepting a configurable `mediaLocalRoots` allowlist for Telegram outbound media or agent defaults so trusted local paths outside built-in roots can be sent.

## Best Possible Solution

Choose one canonical operator-controlled media-root policy, then align schema, types, runtime propagation, docs, and focused security/message-delivery tests around that contract.
