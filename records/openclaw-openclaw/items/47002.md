## Summary

Keep open: current main and the latest release still do not expose `mediaLocalRoots` as a public Telegram or agent-defaults config key, and adding it would change an operator-controlled host file-read/upload boundary that needs maintainer product and security direction first.

## What This Changes

The issue asks OpenClaw to accept configurable outbound media local roots for Telegram, agent defaults, or a canonical media config surface so trusted local files outside built-in roots can be sent.

## Best Possible Solution

Choose one canonical operator-controlled media-root policy, then align config schema, types, runtime propagation, docs, and focused security/message-delivery tests around that single contract.
