## Summary

Keep open: current main still rejects `mediaLocalRoots` as public Telegram or agent-defaults config, and fixing it requires a security/product decision for host-local media roots rather than routine cleanup.

## What This Changes

The issue asks OpenClaw to accept and apply configurable outbound local media roots for Telegram and/or agent defaults instead of rejecting `mediaLocalRoots` as unknown config.

## Best Possible Solution

Choose one security-reviewed root policy, then update schema, types, runtime propagation, docs, and focused tests so outbound media reads only explicitly approved host paths.
