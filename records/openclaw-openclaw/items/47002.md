## Summary

Keep open: current main and v2026.6.11 still do not expose a public `mediaLocalRoots` config key under Telegram, agent defaults, or top-level media, and the right fix changes a host-local file-read/upload boundary that needs maintainer direction.

## What This Changes

The issue requests accepting configurable outbound media roots for Telegram or agent defaults so local media outside built-in OpenClaw roots can be sent without staging or symlinks.

## Best Possible Solution

Choose one canonical security-reviewed host media-root policy, then align schema, exported types, docs, Telegram/outbound delivery, and focused tests around that contract.
