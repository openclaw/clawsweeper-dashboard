## Summary

Keep open: current main still has only the generic Cron Control UI and cron schema/listing contract, so the requested Reminders tab and reminder-specific display/filtering behavior remain missing.

## What This Changes

The issue requests a dedicated Mission Control Reminders tab that separates reminder cron jobs from ordinary cron jobs and displays reminder text, fire time, recipient/channel, and delete controls.

## Best Possible Solution

Define one additive typed cron purpose/display metadata contract, have reminder-producing paths set it, expose typed reminder/non-reminder filters, and build a Reminders view on that shared contract.
