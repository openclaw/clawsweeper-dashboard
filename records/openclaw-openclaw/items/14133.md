## Summary

Keep open: current main and the latest release still lack a Reminders route/UI and a durable cron classification/display contract to separate one-shot reminders from ordinary cron jobs.

## What This Changes

Request a dedicated Mission Control Reminders tab that shows cleaned reminder cards and hides or filters reminder-created one-shot cron jobs from the generic Cron tab.

## Best Possible Solution

Define one additive cron purpose/display metadata contract, have reminder-producing paths set it, expose typed reminder/non-reminder filters, and build a Reminders view with cleaned text, fire time, recipient/channel, and delete actions.
