## Summary

Keep open: current main still lacks a Reminders route/UI and the durable cron classification/display contract needed to separate one-shot reminders from ordinary cron jobs.

## What This Changes

Request a dedicated Mission Control Reminders tab that separates one-shot reminder cron jobs from generic cron jobs and displays cleaned reminder details.

## Best Possible Solution

Define an additive cron purpose/display metadata contract, have reminder-producing paths set it, expose typed reminder/non-reminder filters, and build a Reminders view with cleaned text, fire time, recipient/channel, and delete actions.
