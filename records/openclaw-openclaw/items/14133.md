## Summary

Keep open: current main still lacks a dedicated Reminders route/UI and the cron purpose/display metadata needed to separate one-shot reminders from ordinary cron jobs. The broader cron tags issue overlaps on classification, but it does not cover the dedicated reminder cards or cleaned reminder display, and the earlier opaque metadata PR was closed unmerged.

## What This Changes

Request a dedicated Reminders tab in Mission Control that separates one-shot reminder cron jobs from ordinary cron jobs and shows cleaned reminder details.

## Best Possible Solution

Define one additive cron purpose/display metadata contract, have reminder-producing paths set it, expose typed reminder/non-reminder filters, and build a Reminders view with cleaned text, fire time, recipient/channel, and delete actions.
