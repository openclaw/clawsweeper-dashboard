## Summary

The new envelope check narrows the bypass to recognized subagents, but it still does not prove or preserve the parent’s resolved sender restriction; an exact sender deny can therefore be omitted in the child. The linked issue remains valid, and contributor-supplied proof is still limited to source-level tests rather than a spawned-agent run.

## What This Changes

The PR skips sender-scoped tool-policy resolution for recognized subagent sessions and adds focused tests for exact, wildcard, and subagent policy selection.

## Best Possible Solution

Carry the parent’s resolved sender policy through a trusted subagent capability envelope and apply it before normal subagent restrictions, with regression coverage for both permissive and restrictive exact overrides plus a redacted live spawned-agent inventory transcript.
