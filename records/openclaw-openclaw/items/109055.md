## Summary

The revised head addresses the prior overbroad identity-less-session concern by limiting the bypass to recognized subagent envelopes, but it still removes the entire sender-policy layer rather than inheriting the parent’s resolved restrictions, so restrictive exact sender policies can be lost in the child.

## What This Changes

The PR detects recognized spawned subagent sessions in the conversation capability resolver and skips sender-scoped tool-policy resolution for those sessions.

## Best Possible Solution

Carry the trusted parent’s resolved sender-policy restriction or effective tool ceiling through the recognized subagent capability envelope, intersect it with normal subagent restrictions, and cover permissive exact overrides, restrictive exact overrides, wildcard denies, and non-subagent identity-less sessions with focused tests plus a redacted real spawn transcript.

## Solution Assessment

No. Recognizing subagent envelopes is the correct predicate boundary, but skipping sender resolution is not equivalent to inheriting the parent’s resolved sender restrictions; the narrow maintainable fix must preserve that authorization ceiling.
