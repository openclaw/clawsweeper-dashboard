## Summary

This PR targets a valid delegated-tool regression, but the proposed guard equates every identity-less run with a trusted subagent and can bypass configured sender restrictions on other internal entry points. Keep it open for a narrower fix, regression coverage, and real behavior proof.

## What This Changes

The PR makes sender-scoped tool-policy resolution return early whenever all four sender identity fields are absent.

## Best Possible Solution

Recognize the affected inherited-policy lane from trusted session provenance such as the subagent envelope or spawnedBy relationship, skip sender re-resolution only there, preserve wildcard handling for every other identity-less run, and cover both outcomes with focused tests.
