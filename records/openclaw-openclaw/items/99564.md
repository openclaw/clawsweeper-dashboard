## Summary

Keep open: current main still allows surrogate-range numeric HTML entities through `String.fromCodePoint()` in the live tool-call argument decoder, while this PR fixes that boundary with focused regression coverage and sufficient terminal proof. I found no blocking review findings.

## What This Changes

The branch tightens the embedded agent tool-call HTML entity decoder to preserve surrogate-range numeric entities, adds regression coverage for surrogate preservation and valid astral decoding, and adds a changelog entry.

## Best Possible Solution

Land the scalar-value guard in the existing decoder after normal exact-head gates complete, keeping valid entity decoding unchanged and aligned with sibling HTML decoders.

## Solution Assessment

Yes. This is the best fix because it enforces Unicode scalar validity at the existing provider-to-tool decoder boundary, matching sibling decoders without adding a broader parser or lossy downstream sanitization.
