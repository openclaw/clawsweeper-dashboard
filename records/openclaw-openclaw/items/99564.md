## Summary

Keep open for normal maintainer review: current main and v2026.6.11 still allow surrogate numeric entities to become lone UTF-16 surrogates in tool-call arguments, while this PR adds the narrow scalar-value guard and focused regression coverage without introducing a concrete patch defect.

## What This Changes

The PR tightens embedded-agent-runner tool-call argument HTML entity decoding to preserve surrogate numeric references while still decoding valid numeric entities, and updates focused tests.

## Best Possible Solution

Land the narrow decoder guard and focused regression test after maintainer review, while keeping web_fetch/syntax HTML hardening in https://github.com/openclaw/openclaw/pull/99580 separate.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 pass surrogate numeric values to String.fromCodePoint, and a focused Node probe shows the resulting lone surrogate can break URI encoding.

## Solution Assessment

Yes. Rejecting surrogate numeric entities in the tool-call argument decoder is the narrowest maintainable fix for this runtime boundary and matches sibling HTML entity decoder invariants.
