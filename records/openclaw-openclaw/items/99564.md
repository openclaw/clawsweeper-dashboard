## What This Changes

The PR updates the embedded-agent-runner HTML entity decoder so surrogate numeric entities remain literal in tool-call arguments, and extends the focused unit tests for surrogate preservation plus valid astral decoding.

## Best Possible Solution

Land this focused scalar-value guard and regression tests after required CI and maintainer review; keep the adjacent web-fetch HTML utility fix in https://github.com/openclaw/openclaw/pull/99580 separate.

## Reproduction Assessment

## Solution Assessment

Yes. Rejecting surrogate code points in the shared numeric decoder is the narrowest maintainable fix and avoids broader provider-specific policy or downstream JSON/URI/transcript workarounds.
