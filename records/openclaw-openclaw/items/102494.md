## Summary

The branch adds an `aborted` Code Mode failure code, classifies direct worker signal aborts separately from timeouts, extends cron trigger failure codes, and adds headless tests for abort and wall-clock timeout paths.

## Best Possible Solution

Classify caller-driven cancellations as `aborted` while preserving all deadline-driven Code Mode and cron paths as `timeout`, with focused regression coverage and redacted live abort/timeout proof.
