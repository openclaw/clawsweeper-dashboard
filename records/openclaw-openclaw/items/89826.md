## What This Changes

The PR adds a 2px context/token usage progress meter to the chat composer, with CSS tiers, reduced-motion handling, and render tests for zero-token and per-session context windows.

## Best Possible Solution

Rebase the feature onto the current chat components and drive the meter through the same freshness-aware context usage model as the existing notice, with explicit stale-token tests and visual proof after the source blocker is fixed.
