  - body: Returning false here only enables OpenClaw's launch-lease wrapper. The pinned acpx delegate still loads a matching record by cwd, command, and resumeSessionId before starting a new client, so stale records must be hidden, reset, rewritten, or replaced before `delegate.ensureSession` runs.
