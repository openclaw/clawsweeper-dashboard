## Summary

Keep open: current main and shipped releases cover call-log search, SMS search, and node-scoped Android sessions, but Android device-control, ADB-style access, and dynamic Android execution are still absent and need maintainer product/security direction.

## What This Changes

## Best Possible Solution

Split the remaining work behind explicit maintainer design: narrow Android device-control commands with per-command permission and gateway policy first, and route ADB or dynamic execution through an accepted node-host/plugin security model unless maintainers approve a new Android boundary.
