## Summary

Keep open: current main and v2026.6.11 cover call-log search, SMS search, installed-app metadata, and Android node-scoped session keys, but device control, ADB-style access, and dynamic Android code execution remain absent and need maintainer product/security direction.

## What This Changes

The issue requests a broad Android node roadmap: additional phone tools such as device control, ADB-style access, dynamic code execution, and per-device session isolation.

## Best Possible Solution

Keep this issue open, preserve the shipped call-log/SMS/session work, and split the remaining roadmap into permission-gated Android device-control decisions plus a separate ADB/dynamic-execution decision through the generic node-tool or plugin contract.
