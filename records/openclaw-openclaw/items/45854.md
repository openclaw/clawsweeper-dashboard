## Summary

Keep open: current main and the latest release already cover call-log search, SMS search, and per-device Android session keys, but Android device control, ADB-style access, and dynamic Android execution remain absent and need maintainer security/product direction.

## What This Changes

The issue requests completing the Android node roadmap with device.control, ADB-style access, and dynamic Kotlin/script execution while noting that call-log search, SMS search, and per-device session isolation were already merged.

## Best Possible Solution

Keep this issue open, preserve the shipped call-log/SMS/session-isolation work, and split the remaining roadmap into maintainer-approved Android device-control commands plus a separate ADB/dynamic-execution decision tied to the generic node-tool/plugin contract.
