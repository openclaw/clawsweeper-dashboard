## Summary

Keep open: current main and v2026.6.11 cover Android call-log search, SMS search, and per-device Android chat session isolation, but device control, ADB-style access, and dynamic Android code execution remain absent and need maintainer security/product direction.

## What This Changes

## Best Possible Solution

Keep this issue open, preserve the shipped call-log/SMS/session-isolation work, and split the remaining Android authority into maintainer-approved, permission-gated device-control commands plus a separate decision on ADB or dynamic execution through the generic node-tool/plugin contract.
