## Summary

Keep this PR open, but do not merge the current head: the single-message fix is sound, while normal Signal debounce batching can still discard quoted context when the quoted message is not the final entry.

## What This Changes

The PR renders Signal quoted-reply context in the agent-facing body while preserving clean command bodies and suppressing an exactly matching duplicate reply-target metadata block.

## Best Possible Solution

Render each Signal entry's agent-facing text before debounce combination so every quote remains ordered with its message, while keeping structured reply metadata for native reply semantics and suppressing only byte-equivalent duplicate prompt context.

## Maintainer Decision

## Reproduction Assessment

Yes. A quoted Signal reply followed by a plain message within one debounce window deterministically loses the first message's quote because the batch retains reply metadata only from the final entry.

## Solution Assessment

No, not yet. Formatting one combined entry after debounce cannot preserve quotes belonging to earlier messages; per-entry rendering before combination is the narrower maintainable fix.
