## What This Changes

This PR makes the terminal gateway force-exit if shutdown leaves Node alive, uses a strict internal health probe to treat a draining gateway as unavailable during supervised lock recovery, and adds restart telemetry and regression tests.

## System Context

The Gateway daemon owns OpenClaw’s local control-plane HTTP listener and is restarted by launchd or similar supervisors. During startup it probes an already-bound listener; this PR changes how that probe distinguishes a live gateway from one that is closing and adds a final process-exit safeguard after close completes.
