## What This Changes

Add an optional loopback-only proxy base URL for ChatGPT/Codex OAuth routes in the bundled OpenAI provider, while keeping visible model references under `openai/<model>` and leaving API-key routes unchanged.

## System Context

OpenClaw model profiles select authentication and transport routes through the bundled OpenAI provider. This request would let a local credential sidecar serve model discovery and Responses calls while OpenClaw continues to normalize the catalog and present standard OpenAI model references.

Approve or reject the local-sidecar trust model first; if approved, add one narrowly scoped OpenAI-profile setting with strict loopback-only validation, preserve existing routes by default, and prove API-key coexistence plus catalog and Responses behavior through focused and live sidecar tests.
