## Summary

This PR remains useful but is not merge-ready: the latest head replaces explicit capability gating with broad Copilot model-name inference, which can remove working managed search from unknown or unsupported models, and the PR still lacks exact-head live Copilot proof. The shared wrapper is a plausible abstraction, but automatic fallback replacement and its new public Plugin SDK contract need provider-owner approval.

## What This Changes

The PR adds provider-native web search for eligible GitHub Copilot OpenAI Responses models, extracts the OpenAI Responses payload mutation into a shared Plugin SDK helper, and updates focused tests, docs, and SDK surface budgets.

## Best Possible Solution

Gate Copilot native search through explicit authoritative capability data mapped into the existing `nativeWebSearchTool` model contract, preserve managed search whenever capability is absent or false, and prove native plus managed-provider paths on the exact head before approving any public SDK commitment.
