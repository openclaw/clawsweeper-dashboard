## Summary

Keep this PR open because current main and v2026.6.11 still lack Copilot-hosted Responses web search, but the exact head is not merge-ready: it replaces managed search using model-name inference, exposes provider-specific policy as public Plugin SDK API, and has no live exact-head Copilot proof.

## What This Changes

The PR enables hosted `web_search` for inferred GitHub Copilot GPT-family Responses models, extracts the OpenAI Responses payload mutation into a shared Plugin SDK helper, and updates focused tests, documentation, and SDK surface budgets.

## Best Possible Solution

Propagate an explicit hosted-search capability from Copilot model discovery, preserve managed search whenever support is absent or unknown, keep the payload helper internal unless maintainers approve it as stable SDK API, and verify both routing paths in a redacted live run.
