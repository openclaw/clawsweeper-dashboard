## Summary

The timeout goal remains useful because current main still performs unbounded docs-agent fetches, but this branch places `timeout` before the shell `if` keyword, making both modified run blocks syntactically invalid and causing Docs Agent runs to fail before the fetch executes.

## What This Changes

Wraps the docs-agent workflow’s two retried `git fetch` operations with a 120-second timeout and 10-second termination grace period.

## Best Possible Solution

Keep the bounded-fetch behavior, but place `timeout ... git fetch` inside each existing `if` condition and add a regression that shell-parses the exact workflow run blocks before validating timeout and retry behavior.
