## Summary

Keep open: the macOS lifecycle hardening is substantial and well proven, but the current head still has a blocking first-install activation mismatch that can restart the Gateway despite promising immediate no-restart route publication.

## What This Changes

The PR serializes and generation-gates macOS managed Gateway startup and repair work, bounds startup probes, and changes verified inference activation to publish through automatic config reload.

## Best Possible Solution

Preserve the serialized macOS startup work, but separate restart-required plugin-install adoption from the hot-reloadable model, agent, and plugin-entry publication—or explicitly complete and prove the restart before reporting activation success.
