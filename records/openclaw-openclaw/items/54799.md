The issue asks OpenClaw to let skills declare scheduled or event triggers in SKILL.md frontmatter, register those triggers with automation, and expose trigger history in skill tooling.

## Best Possible Solution

Decide the permissioned trigger/routine contract first; if accepted, compile skill-declared triggers through one approved scheduler/routine path with operator approval, provenance, revocation, audit state, docs, and tests.
