## Summary

Keep open for maintainer product and security review: current main and the latest release still do not implement declarative scheduled/event SKILL.md trigger metadata, automatic cron registration from skill frontmatter, skill-level last-triggered state, or a settled trust boundary for autonomous skill execution.

## What This Changes

The issue requests optional SKILL.md frontmatter metadata for scheduled and event-based skill triggers, including cron registration, lifecycle event triggering, and last-triggered/audit output.

## Best Possible Solution

Define a permissioned automation contract first, then implement one coordinated path for metadata parsing, scheduler/event registration, audit state, CLI/docs output, and regression coverage.
