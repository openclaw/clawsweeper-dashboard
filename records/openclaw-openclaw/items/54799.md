## Summary

Keep open for maintainer product and security review: current main and v2026.6.11 still lack declarative schedule/event trigger metadata in SKILL.md, automatic cron registration from skill metadata, and last-triggered/audit output. The cron-operator comment adds useful real-world evidence that manual Gateway and skill scheduling is painful, but this is a new public automation and trust contract rather than a narrow bug fix.

## What This Changes

Add declarative SKILL.md trigger metadata for schedule/event skill execution, cron registration, last-triggered visibility, and never-triggered audits.

## Best Possible Solution

Define the permissioned automation contract first, then implement one canonical path covering SKILL metadata/schema, scheduler registration or event hooks, audit/last-triggered state, CLI/docs output, and regression proof.
