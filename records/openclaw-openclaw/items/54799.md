## Summary

Keep open for maintainer product and security review: current main and v2026.6.11 still lack declarative scheduled/event SKILL.md trigger metadata, automatic cron registration from skill frontmatter, skill-level last-triggered output, and a settled trust boundary. ## What This Changes

Request to add declarative schedule/event trigger metadata to SKILL.md, have OpenClaw register scheduled skills, emit event triggers, and show trigger history in skill listing/audit output.

## Best Possible Solution

Define the permissioned automation contract first, then implement one coordinated path for metadata parsing, scheduler registration, event/audit state, CLI/docs output, and regression tests.

## Reproduction Assessment

Yes for the source-level feature gap, not as a bug reproduction. Current main and v2026.6.11 omit trigger metadata from skill parsing, prompt rendering, cron registration, and skills list/audit output.

## Solution Assessment

Unclear until maintainers choose the product and security boundary. A SKILL.md field is plausible, but the safest path must decide whether autonomous scheduling belongs in skill metadata, explicit cron/standing orders, or a permissioned plugin API first.
