## Summary

Keep open. Current main and v2026.6.11 mitigate the original direct-Gemini tagged-mode trigger, but the shared strict sanitizer fallback can still return hidden reasoning plus answer text after an unclosed reasoning opener and a stripped final boundary, so the security-sensitive channel leak is not fully fixed.

## What This Changes

The issue asks OpenClaw to stop Gemini-style `<think>/<final>` reasoning text from leaking through WhatsApp and sibling channel delivery after an earlier Telegram-only fix.

## Best Possible Solution

Keep the native Gemini reasoning behavior, then land a maintainer-approved shared sanitizer or stream-parser fix for unclosed reasoning followed by final tags, with WhatsApp/Telegram and shared-sanitizer regression proof.
