- **[P1] Escape dynamic paths in copied recovery commands:** `ui/src/pages/chat/workspace-conflict.ts:94-101`
  - body: `isSafeWorkspaceConflictPath` permits `'`, but the command helper embeds the path inside single quotes. A conflicted filename such as `a'; command; #` therefore escapes the quoted Git revision when the operator clicks Copy and pastes it into the documented shell. This is a late finding: the unsafe interpolation was already present in the earlier reviewed head.
  - late: true

Even though navigation now supplies a positive `workspaceConflictCount`, that leaves `displayedPlacementState` undefined and returns no badge, so spawned sessions with a conflicted cloud result lose the sidebar warning. Preserve a displayable state for a child session when it has conflicts and cover that path.
  - confidence: 0.96
