## Summary

The PR addresses the intended Control UI recovery surface and fixes the prior visibility findings, but it still drops the structured notice for a valid conflicted filename containing terminal-control characters, and its supplied conflict proof is browser E2E against a mocked Gateway rather than an after-fix real cloud-conflict run.

## What This Changes

The branch projects cloud workspace conflicts into Control UI sidebar badges, a dismissible chat notice, durable transcript cards, copyable recovery guidance, styles, documentation, and focused browser coverage.

## Best Possible Solution

Keep the conflict visible for every producer-valid path by safely rendering escaped path text and withholding only an unsafe per-path copy command, then capture a redacted real Gateway-to-Control-UI conflict lifecycle run.
