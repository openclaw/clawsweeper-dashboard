## Summary

This PR completes a useful, already-established phase of the cloud-workspace recovery flow, but two visible recovery surfaces remain broken: durable transcript conflicts lose their structured details during Gateway history projection, and sidebar attention disappears after a conflicted worker is reclaimed. The protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The branch adds Control UI conflict badges, a dismissible chat notice, structured transcript cards, recovery-command guidance, docs, and focused rendering tests for cloud-worker workspace conflicts.

## Best Possible Solution

Preserve a bounded, explicitly allowlisted conflict-detail shape through `chat.history`, then render conflict attention independently of an active cloud-worker state so a reclaimed placement remains discoverable until the operator resolves it.
