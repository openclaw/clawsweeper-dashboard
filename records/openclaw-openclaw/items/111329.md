Full review comments:

- **[P1] Quote or reject apostrophes before copying shell commands:** `ui/src/pages/chat/workspace-conflict.ts:17-29`
  - body: `isSafeWorkspaceConflictPath` permits `'`, but the generated Git commands wrap the interpolated path in single quotes. A cloud result with a filename such as `x'; command #` can break out of the copied shell word and run trailing input when an operator pastes the guidance. Use a proven shell-quoting helper or reject shell metacharacters before rendering commands.
  - confidence: 0.98
- **[P2] Preserve conflict details through chat-history projection:** `src/gateway/chat-display-projection.ts:600-607`
  - body: The structured card only works for messages that still contain `details`, but Gateway history sanitization removes `details` from these custom messages. After a reload, normalization returns no conflict and the durable event falls back to its plain-text summary. Permit this known custom event’s bounded details through the projection and cover the history path.
  - confidence: 0.98
- **[P2] Show conflict attention after a placement is reclaimed:** `ui/src/components/session-row-badges.ts:35`
  - body: The new count reaches the renderer, but the badge is still conditioned on `isCloudWorkerPlacementState`, which excludes `reclaimed`. A conflict recorded when stopping or recovering a worker therefore has no sidebar badge even though the placement projection retains it. Render conflict attention when a positive count exists, regardless of whether the worker remains active.
  - confidence: 0.97
