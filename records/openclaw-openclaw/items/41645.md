## Summary

Keep open: current main and v2026.6.11 still expose usage by session, agent, provider, model, channel, and date, but not by a stable per-user accounting subject with authorized per-user views.

## What This Changes

Request per-user token accounting for input/output/total tokens by day/week/month, visible through `/usage` or the Dashboard.

## Best Possible Solution

Define one stable accounting-subject and viewer-authorization contract first, then extend the existing usage RPCs, storage/diagnostics, Dashboard, and command surfaces around that contract.
