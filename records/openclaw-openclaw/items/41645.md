Keep open: current main and the latest release still have session, agent, provider, model, channel, and date usage reporting, but no stable per-user accounting subject or authorized per-user usage view.

## What This Changes

The issue requests per-user token usage accounting with input/output/total token totals by day, week, or month and visibility through /usage or the Dashboard.

## Best Possible Solution
