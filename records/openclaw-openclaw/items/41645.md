## Summary

Keep open: current main and v2026.6.11 expose usage by session, agent, provider, model, channel, and date, but not by a stable per-user accounting subject or authorized per-user view. The request is useful, but it needs maintainer product and security-boundary decisions before implementation.

## What This Changes

Add per-user token usage accounting with input/output/total tokens over day/week/month windows, visible through `/usage` or the Dashboard.

## Best Possible Solution

Define a core accounting-subject and viewer-authorization contract first, then extend usage RPCs, Dashboard, and any `/usage` view from that contract.
