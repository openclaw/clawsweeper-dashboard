## Summary

Keep open: current main and v2026.6.11 still expose usage by session, agent, channel, model, provider, and date, but not by a first-class user bucket. The Pinchy/front-layer workaround discussed on the related Gateway identity issue is useful context, but it does not replace a core identity-attributed usage design.

## What This Changes

The issue requests per-user input/output/total token usage accounting with daily/weekly/monthly views through `/usage` or the Dashboard.

## Best Possible Solution

Define a canonical identity-attribution and authorization model first, then extend usage storage, Gateway RPC, Dashboard, and `/usage` surfaces to expose per-user totals safely.
