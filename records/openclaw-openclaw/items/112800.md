## What This Changes

The PR preserves the configured `publicUrl` path when constructing the Twilio signature-verification URL, while continuing to take the request query string from the received webhook.

## System Context

The voice-call plugin receives provider webhooks through the Gateway, often after a reverse proxy rewrites their local path. It reconstructs the provider-facing URL for HMAC verification, which determines whether an inbound call event is accepted or rejected.
