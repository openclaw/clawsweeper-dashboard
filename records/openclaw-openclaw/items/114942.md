## What This Changes

This PR makes agent message-action discovery reuse the active channel registry’s prepared catalog and loaded-channel ordering so action capabilities match the selected registry and account context.

## System Context

OpenClaw prepares a channel registry for the active plugin runtime, then agent tools discover channel message actions from that registry. This change routes discovery through the prepared registry view so channel ordering, duplicate precedence, pinned registries, and account-specific actions remain consistent before tool schemas and message operations are produced.
