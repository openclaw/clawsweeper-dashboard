## What This Changes

The branch carries a lifecycle revision through session reset/start/end hooks and uses it to distinguish retained-session Codex binding generations, preventing delayed cleanup from retiring a successor thread.

## System Context

OpenClaw retains a durable session ID across normal resets so its transcript remains continuous, while plugins receive lifecycle events to clean up provider-specific state. The Codex extension maps that session lifecycle to a persisted Codex thread binding; the revision is intended to let cleanup target the ended logical generation instead of every binding with the same physical session ID.
