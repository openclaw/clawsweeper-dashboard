## System Context

OpenClaw’s gateway and auto-reply paths reset or roll over durable chat sessions and notify registered harnesses and plugins. The Codex extension consumes those lifecycle events to own a persisted session-to-thread binding, which controls whether the next chat turn can start or resume a Codex thread.
