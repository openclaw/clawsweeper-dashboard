## What This Changes

The branch carries an optional lifecycle revision from OpenClaw session reset/end paths into the Codex binding store so delayed cleanup for an old logical session generation cannot retire a newer generation sharing the same durable session ID.

## System Context

OpenClaw’s gateway and auto-reply subsystems reset or end durable chat sessions and notify registered agent harnesses and plugins. The Codex plugin turns those lifecycle events into thread-binding ownership changes, which determine whether the next chat turn can resume or create a Codex thread.

  D --> E[Codex thread start or resume]
  E --> F[Next chat reply]
