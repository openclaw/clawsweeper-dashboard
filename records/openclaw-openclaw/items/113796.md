## What This Changes

Adds lifecycle-revision fencing to Codex thread bindings and session-end/reset events so delayed cleanup from an older logical session generation cannot retire the successor after a durable reset.

## System Context

OpenClaw’s session lifecycle retains a physical session ID across some resets while the Codex plugin maintains a separate thread binding for that session. Gateway and auto-reply lifecycle events tell the Codex harness which logical generation ended, allowing cleanup to preserve the active successor binding.
