## Summary

This PR remains necessary: it fixes a source-reproducible unbounded Reef guard response read at the correct plugin boundary, preserves strict parsing and fail-closed behavior, and has no blocking correctness or security finding. The related Reef relay PR covers a distinct caller and does not supersede this work.

## What This Changes

Routes Reef guard HTTP response bodies through the shared 256 KiB byte-limited provider text reader and adds regression tests for near-limit acceptance and early oversized-stream cancellation.

## Best Possible Solution

Land this narrow guard-path change using the existing plugin SDK bounded reader, keep strict parsing and fail-closed semantics unchanged, and review the relay sibling independently so each Reef HTTP body reader has an explicit byte budget.
