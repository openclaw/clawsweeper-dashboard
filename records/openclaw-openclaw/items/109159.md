## Summary

Close because current main accepts path-qualified wikilinks when the normalized path resolves to an indexed page; the report conflates valid Obsidian syntax with an unresolved target, which wiki lint intentionally warns about.

## What This Changes

Stop wiki lint from reporting path-qualified Obsidian wikilinks as broken solely because their targets contain a slash.

## Best Possible Solution

Keep exact path resolution and warnings for genuinely unresolved targets; a new report should include the precise link, existing target path, relevant frontmatter, and `openclaw wiki lint --json` output if a valid indexed page still fails.
