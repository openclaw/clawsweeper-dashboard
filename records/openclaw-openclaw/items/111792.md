## What This Changes

This PR adds a Tenki Cloud sandbox backend plugin that creates remote microVM sessions, uploads agent workspaces, and runs tool commands through the Tenki SDK and SSH gateway.

## System Context

OpenClaw reads an agent's sandbox backend selection, then loads a registered plugin backend to create and manage the execution environment used by agent tools. This change registers a Tenki-backed remote sandbox alongside other plugin-provided sandbox implementations.
