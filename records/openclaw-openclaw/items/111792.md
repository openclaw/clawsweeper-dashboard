## What This Changes

Adds a Tenki Cloud sandbox backend plugin that creates remote microVM sessions for OpenClaw agent tool execution, with plugin configuration, workspace upload, SDK-based SSH transport, docs, and focused tests.

## System Context

OpenClaw resolves an agent sandbox backend through the plugin SDK, then uses that backend to create a scoped runtime for command execution and filesystem operations. This PR adds a provider-specific remote backend that uploads local workspace content to Tenki Cloud and returns execution results through the existing sandbox interface.
