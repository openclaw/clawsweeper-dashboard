## What This Changes

Prevent the command-display layer from recursively wrapping suspicious `grep` or `rg` search patterns into another human-readable search summary.

## System Context

The agent tool-display subsystem converts executed shell commands into concise labels for browser and log output. It parses recognized `grep`/`rg` commands, extracts a pattern and target, then supplies that label to the surrounding tool-result/error display.

## Architecture Diagram

flowchart LR
  A[Shell command] --> B[Command summary parser]
  B --> C[Recognized grep or rg search]
  C --> D[Pattern and target extraction]
  D --> E[Safe concise display label]
  E --> F[Browser and log tool output]

## Best Possible Solution

Add a narrow display-only sanitization/fallback at the shared search-summary formatter: retain normal concise patterns, but render a neutral search label when the extracted text already resembles presentation output or cannot safely be shown as one concise pattern; cover direct and piped commands with regression tests.
