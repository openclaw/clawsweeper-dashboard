## Summary

Keep open. The latest branch preserves already-persisted legacy links, but it still changes the behavior of existing callers that omit a decomposition mode: new decompositions become non-blocking instead of retaining the established hard-dependency semantics. That is a P1 compatibility and session-lifecycle change requiring an explicit maintainer decision, plus real after-fix runtime proof before merge.

## What This Changes

This PR changes Workboard decomposition so aggregate-child provenance can be non-blocking while callers may explicitly request hard dependencies, adding diagnostics, repair tooling, tests, and documentation.

## System Context

Workboard is the bundled plugin that persists cards and dependency links in its own SQLite store, then uses those links to determine whether a card may be claimed, completed, or dispatched. Decomposition creates related aggregate and child cards; this change alters whether that relationship blocks child lifecycle progress.
