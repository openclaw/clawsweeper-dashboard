## Summary

The PR retains useful cleanup work, but its new body-less fallback still calls `response.text()` before any byte cap can take effect; that can allocate the whole undeclared error body. The supplied “real behavior proof” is prose about synthetic test harnesses rather than inspectable after-fix runtime output, so it remains a merge gate.

## What This Changes

The branch releases an Ollama stream reader lock, cancels a Firecrawl response after a successfully parsed cloned error payload, and replaces shared body-less HTTP error handling with a Content-Length pre-check plus a cancelable wrapper stream.

## Best Possible Solution

Keep bounded reads on an actual `ReadableStream`; when a response exposes no readable body, return an empty snippet or use a separately bounded source rather than wrapping an already-resolved `response.text()` result. Then add redacted real-runtime proof that demonstrates the capped path and cleanup behavior.
