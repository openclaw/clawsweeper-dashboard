## What This Changes

## Best Possible Solution

Use a reader-based bounded path wherever a readable body exists, define a safe no-stream fallback that does not materialize an unknown-size body, cancel the original Firecrawl body in a `finally` covering every clone-consumption outcome, and add focused regression coverage plus redacted live proof.
