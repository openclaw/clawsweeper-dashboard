## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.84

Full review comments:

- **[P2] Keep heredoc bodies with the declaring stage:** `src/agents/tool-display-exec-shell.ts:367-369`
  - body: When a command declares a heredoc and then has a top-level operator before the newline, for example `cat <<EOF && printf ok`, `splitTopLevelStages` moves `start` past the operator before this scanner skips the body. The final slice for the `printf ok` stage still includes the skipped body and terminator, so a later pipeline summary can treat body text like `body | secret` as a real pipe because that stage no longer contains the heredoc opener. Please precompute/compact heredoc body ranges before slicing, or teach the splitters to carry skipped ranges with the declaring stage, and add coverage for an operator on the heredoc declaration line.
  - confidence: 0.82
