## Summary

Keep open: the report describes a current, channel-independent message-delivery gap in which CLI mid-turn text is visible transiently but only the final CLI result becomes durable; current streaming documentation promises completed assistant blocks as normal channel messages, and no merged fix or open implementation PR is identified.

## What This Changes

Ensure completed mid-turn assistant text from CLI-backed runtimes reaches durable channel delivery rather than being replaced by the final CLI result.

## Best Possible Solution

Emit already-classified completed CLI text blocks through the same generic block-reply pipeline used by embedded runtimes when block streaming is enabled, preserve commentary metadata, and deduplicate only exact delivered content from the final result.
