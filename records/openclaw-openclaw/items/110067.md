The related Telegram report overlaps in symptoms but proposes a channel-specific renderer cause, so it should not replace this cross-channel CLI-runtime issue yet.

## What This Changes

Ensure CLI-backed agent runtimes durably deliver completed mid-turn assistant text instead of retaining only the final result block.

## Best Possible Solution

Give CLI runtimes the same completed-block delivery contract as the embedded runtime: emit classified text blocks through the existing block-reply pipeline when enabled, preserve commentary gating, and coalesce or deduplicate the final result against already delivered text.
