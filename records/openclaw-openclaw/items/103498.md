Overall correctness: patch is incorrect

Overall confidence: 0.98

Full review comments:

- **[P1] Merge legacy groups before deleting browser state:** `ui/src/lib/sessions/index.ts:839-848`
  - body: When the gateway already has any group, this skips importing the legacy browser catalog but still removes it. Existing browser-only empty groups and custom ordering are silently lost; merge the two catalogs before deleting the legacy key.
  - confidence: 0.99
- **[P1] Load the full catalog before replace-all writes:** `ui/src/lib/sessions/index.ts:860-876`
  - body: `groupsLoad()` marks the connection epoch loaded before its request finishes, while callers can immediately send a locally derived array to the replace-all `groupsPut`. Creating or reordering during that window can drop existing empty or out-of-window groups; await or freshly merge the canonical catalog before writing.
  - confidence: 0.97
- **[P1] Keep agent expansion out of global selection:** `ui/src/components/app-sidebar.ts:494-504`
  - body: Expanding a section is documented as browse-only, but this writes the expanded agent into shared `agentSelection`. For global or unqualified sessions that selection disambiguates ownership, so opening a section can change how the active chat and later actions are scoped before navigation.
  - confidence: 0.96
- **[P1] Do not combine node execution with gateway worktrees:** `ui/src/components/new-session-dialog.ts:46-61`
  - body: The create payload permits `execNode` together with worktree fields. The worktree is provisioned on the gateway, while node-host execution ignores the session default cwd unless a tool supplies an explicit workdir, so the session advertises one checkout while commands run elsewhere; disable this combination or provision the checkout on the node.
  - confidence: 0.99
- **[P2] Use the configured default agent for cached rows:** `ui/src/components/app-sidebar.ts:1608-1616`
  - body: Cached rows are filtered with `defaultAgentId` set to the currently selected agent. When browsing another agent from a non-default active chat, legacy unprefixed rows are attributed to the wrong agent and disappear; pass the configured gateway default agent instead.
  - confidence: 0.95
- **[P2] Hydrate unread state for collapsed agents:** `ui/src/components/app-sidebar.ts:1621-1624`
  - body: The unread badge only counts `sessionRowsByAgent`, which is populated for loaded or expanded agents. A collapsed agent not yet opened in this browser shows no unread indicator despite unread sessions; load a lightweight per-agent summary or seed the cache from an unscoped result.
  - confidence: 0.95
- **[P2] Handle every generated DM key shape in fallbacks:** `ui/src/lib/session-display.ts:20-35`
  - body: Late discovery: the fallback parser does not recognize supported keys such as `agent:<agent>:direct:<peer>` or `agent:<agent>:<channel>:<account>:direct:<peer>`. Unlabeled rows can therefore expose the full raw key or peer identifier, defeating the redesign's privacy-oriented shortening guarantee.
  - late: true
  - confidence: 0.99
