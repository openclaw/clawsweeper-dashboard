Full review comments:

- **[P1] Merge legacy groups before deleting browser state:** `ui/src/lib/sessions/index.ts:839-848`
  - body: When the gateway already has any group, this skips uploading the legacy browser catalog but still removes it. Existing browser-only empty groups and ordering are permanently lost; merge the normalized legacy names into the listed catalog before deleting localStorage.
  - confidence: 0.99
- **[P1] Load the catalog before issuing replace-all writes:** `ui/src/components/app-sidebar.ts:704-708`
  - body: `groupsLoad()` is asynchronous, but create/reorder actions can call `groupsPut()` first using an empty `state.groups` plus only visible rows. Because `sessions.groups.put` replaces the entire catalog, that race can drop existing empty or out-of-scope groups; await a successful list or merge against a fresh list before writing.
  - confidence: 0.99
- **[P2] Gate draft creation during session refreshes:** `ui/src/components/new-session-dialog.ts:481-482`
  - body: `SessionCapability.create` returns `null` while `state.loading` is true, but the dialog can still submit based only on connection and access state. A concurrent list refresh therefore reports a generic create failure without sending `sessions.create`; disable Start while loading or allow creation independently. This was equally visible on the earlier reviewed head and is a late discovery.
  - late: true
  - confidence: 0.98
- **[P2] Target the empty agent fallback at that agent:** `ui/src/components/app-sidebar.ts:1593-1595`
  - body: An expanded non-active agent with no visible rows renders this generic fallback, whose click navigates to chat without a session search. The host then reuses the active session, so the only row under the empty agent opens the wrong agent; construct the target agent's main-session URL and navigation payload.
  - confidence: 0.99
- **[P2] Hydrate unread state before rendering collapsed agents:** `ui/src/components/app-sidebar.ts:1664-1667`
  - body: The collapsed indicator counts only rows already cached in `sessionRowsByAgent`, but rows are fetched for the active or expanded agent. An agent not yet opened in this browser therefore shows no unread dot despite unread sessions; hydrate per-agent unread summaries or derive them from an unscoped result.
  - confidence: 0.97
- **[P1] Do not combine node execution with gateway worktrees:** `ui/src/components/new-session-dialog.ts:244-254`
  - body: The dialog sends `execNode` together with worktree or folder fields, but the gateway provisions that checkout locally while node execution ignores the session default cwd unless the model supplies an explicit tool workdir. The UI then labels the session as branch-backed while commands run elsewhere; disable the combination or implement remote checkout routing.
  - confidence: 0.99
- **[P2] Re-render when the shared group catalog changes:** `ui/src/pages/sessions/sessions-page.ts:667-676`
  - body: Creating an empty group here only calls `groupsPut`, which publishes `state.groups`; the page subscription schedules work only when `snapshot.result` changes. The new empty group therefore does not appear as a section or menu option until unrelated session churn; subscribe to catalog changes or request an update after the write completes.
  - confidence: 0.98
- **[P2] Cancel stale branch lookups when a target becomes invalid:** `ui/src/components/new-session-dialog.ts:181-187`
  - body: If a branch request is in flight and the user switches to a non-git agent, this early return leaves its token valid and retains the previous `baseRef`. The stale response can later populate branch state for the old checkout; invalidate the token and clear branch, base, and loading state whenever lookup is abandoned.
  - confidence: 0.97
