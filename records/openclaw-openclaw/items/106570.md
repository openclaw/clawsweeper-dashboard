In packages/ai, introduce or reuse a small non-throwing helper that converts unknown thrown values to an error message: preserve Error.message, safely stringify serializable non-Errors, and fall back to String(value) when serialization throws or produces no useful string. Apply it to the OpenAI Completions and Google sibling stream catch paths so each always emits its terminal error event and calls stream.end(). Add focused regression tests using a circular non-Error value and assert stopReason, errorMessage, and stream termination for both providers. Validate through the repository-approved remote test backend.
