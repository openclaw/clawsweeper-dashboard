## What This Changes

## Best Possible Solution

Implement a provider-owned Azure Foundry Realtime Gateway Relay path that keeps credentials server-side, uses the current Azure GA endpoint/auth contract, adds Azure-specific doctor diagnostics and docs, and lands only with focused regression tests plus live Azure proof when quota is available.
