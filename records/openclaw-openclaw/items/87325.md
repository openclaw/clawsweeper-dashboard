Keep open. ## What This Changes

Request first-class Azure Foundry/Azure OpenAI GPT Realtime Talk through the server-side Gateway Relay, with Azure-specific authentication, diagnostics, tests, documentation, and live proof.

## Best Possible Solution

Have the OpenAI/Talk owners define one supported Azure Foundry gateway-relay contract, initially limited to server-side API-key SecretRef handling if that is the validated path; add a live Azure deployment smoke, focused relay/diagnostic tests, and public Talk setup documentation, while leaving Entra or managed identity as separately approved follow-up work.
