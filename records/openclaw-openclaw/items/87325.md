## Best Possible Solution

Implement a bounded OpenAI-provider/Gateway-relay Azure Realtime path that keeps Azure credentials server-side, uses the current Azure endpoint/auth contract, adds diagnostics and regression coverage, updates Talk/OpenAI docs, and obtains live Azure proof when quota is available.
