## Summary

Keep open: current main has the gateway-relay surface and iOS now routes Azure-looking OpenAI realtime configs away from WebRTC, but the OpenAI provider still keeps Azure deployment bridges on the older deployment-compatible endpoint/session shape and lacks the requested first-class Azure Foundry GPT Realtime setup, diagnostics, docs, and live proof.

## What This Changes

The issue requests first-class Azure Foundry / Azure OpenAI GPT Realtime Talk support through the gateway relay with Azure-specific server-side auth, diagnostics, tests, and docs.

## Best Possible Solution

Implement the provider-owned Azure Realtime gateway-relay path against the current Azure endpoint/auth contract, keep Azure credentials server-side, add Azure-specific diagnostics and docs, and require focused regression plus live Azure proof before closing this issue.
