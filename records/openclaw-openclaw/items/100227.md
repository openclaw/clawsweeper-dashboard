## Review Findings

Overall confidence: 0.88

Full review comments:

- **[P1] Await cache purge before reconnecting:** `apps/android/app/src/main/java/ai/openclaw/app/NodeRuntime.kt:1278`
  - body: `resetGatewaySetupAuth()` launches the Room purge and returns, while the setup flow immediately writes the new endpoint/auth and reconnects. Re-pairing to another principal at the same stable id can load the old transcript before `clearAll()` runs, or keep it if the process dies first; make the reset path await the purge before reconnect/cache priming.
  - confidence: 0.9
- **[P2] Preserve deep transcripts during list refresh:** `apps/android/app/src/main/java/ai/openclaw/app/chat/ChatTranscriptCache.kt:236-238`
  - body: `saveTranscript()` creates a stub so a deep session outside the newest list stays reachable, but the next `saveSessions()` deletes all cached session rows and then evicts orphaned transcripts. That drops the active deep transcript if it is not in the refreshed top window, so the current session will disappear on the next offline cold open; preserve explicit transcript rows or their stubs across list replacement.
  - late: true
  - confidence: 0.88
