Keep open. ## What This Changes

Request a coordinated memory/context program: agent-facing metrics, semantic search across memory and workspace material, cross-session context handoff, and preloading context after gateway restart.

## System Context

OpenClaw indexes workspace memory and, when enabled, session transcripts so agent tools can retrieve relevant context before responding. Gateway usage telemetry and startup-context preparation feed the Control UI, CLI, and agent runtime, where privacy scope and default behavior affect every channel session.
