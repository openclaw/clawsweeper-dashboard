## What This Changes

The PR changes OpenClaw Doctor so it does not reinstall a plugin already found through configured plugin load paths merely because no managed-install record exists, and adds coverage for detection and repair behavior.

## System Context

OpenClaw's Doctor startup checks compare plugin configuration with discovered plugin metadata and managed install records. The result determines whether Gateway startup leaves a configured plugin alone or attempts a repair install before the plugin loader enables it.
