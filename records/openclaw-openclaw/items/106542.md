## Summary

The underlying Zalo cache-growth bug is real and plugin-local ownership is appropriate, but the current lease bookkeeping can release the wrong proxy generation and the disposed error can expose credential-bearing proxy URLs. Both block merge.

## What This Changes

Bounds the Zalo proxy-fetcher cache at 64 entries, disposes evicted ProxyAgents, and adds monitor-lifetime leases plus focused cache and production-path tests.

## Best Possible Solution

Keep lifecycle Zalo-local, but make acquisition return an opaque generation-bound lease containing the fetcher and an idempotent release callback, remove URL-keyed retired ownership, redact proxy identifiers from errors, and prove repeated same-URL retirement plus live request completion.
