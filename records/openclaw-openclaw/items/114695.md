## What This Changes

Adds `tools.codeMode: "auto"`, which chooses Code Mode only for models whose provider catalog declares `compat.codeMode: "preferred"`, and documents and tests that new tier.

## System Context

Code Mode replaces a run’s normal tool list with `exec` and `wait`; the code-mode run gates decide whether that surface is exposed. Provider plugin catalogs supply prepared model metadata, which the embedded runner and harness bridge use to select Code Mode or normal tool search for each run.

  Catalog[Provider model catalog] --> Gate
  Gate --> Embedded[Embedded agent runner]
  Gate --> Harness[Harness tool bridge]
  Embedded --> Surface[Code Mode or normal tools]
  Harness --> Surface
  Surface --> Provider[Provider request wrapper]
