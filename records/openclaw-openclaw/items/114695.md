## What This Changes

This PR adds `tools.codeMode: "auto"` and `compat.codeMode` model-catalog metadata so the compact Code Mode tool surface activates only for provider models marked as preferred, while existing `true` and `false` settings remain available.

## System Context

Code Mode replaces the normal model-facing tool list with `exec` and `wait`, backed by a QuickJS catalog bridge. This PR feeds provider-owned model capability metadata into the embedded-agent and harness engagement gates so each run chooses Code Mode or normal tool search before provider streaming begins.
