## What This Changes

Adds `tools.codeMode: "auto"` and model-catalog `compat.codeMode` metadata so OpenClaw chooses Code Mode only for provider models marked preferred, while preserving explicit on and off behavior.

## System Context

Code Mode changes the tool surface exposed to an agent run: normal tools are compacted behind `exec` and `wait`. The selected provider model’s catalog metadata now feeds the embedded-run and harness tool-surface gates, which determine whether a request receives Code Mode or normal tools.
