## Summary

This PR remains necessary because current main still exposes QMD transport envelopes as recalled content. ## What This Changes

## Best Possible Solution

Keep QMD transport parsing exclusively in the memory-core adapter, clean future results before truncation, and give historical persisted recalls one explicit memory-core-owned doctor, repair, or discard path rather than adding QMD parsing to the backend-agnostic recall normalizer.
