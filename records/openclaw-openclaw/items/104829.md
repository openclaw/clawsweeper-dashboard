## Summary

The prior mixed-credential blocker is fixed, but the latest head removes fail-closed handling for unavailable configured SecretRefs. A missing or unsupported explicit ref can now fall through to an unrelated ambient Ollama cloud credential, so this PR still needs changes before merge.

## What This Changes

The PR resolves Ollama web-search SecretRefs through the shared credential helper, independently preserves ambient cloud credentials, and adds focused SecretRef and mixed-credential tests.

## Best Possible Solution

Represent configured-unavailable SecretRefs separately from missing configuration, block ambient fallback for that state, and retain the independent ambient cloud attempt only when the configured credential is absent or usable.
