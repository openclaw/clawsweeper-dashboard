## What This Changes

The PR updates Ollama web search to resolve env-backed `models.providers.ollama.apiKey` SecretRefs and to stop before making a request when an explicitly configured SecretRef is unavailable.

## System Context

The Ollama extension turns provider configuration and environment credentials into web-search requests. This path selects configured-host attempts and may use an ambient cloud credential as a separate fallback, so credential-resolution precedence determines both authentication and request routing.
