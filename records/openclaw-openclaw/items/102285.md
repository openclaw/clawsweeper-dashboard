## Summary

Keep open: the previous P1 blocker is still present. The branch fixes the ready-then-close flap storm, but it also makes reconnect attempts cumulative for the whole user-initiated session, so long-lived stable sessions can stop reconnecting after unrelated drops.

## What This Changes

The PR deletes the raw WebSocket `open` reconnect-attempt reset in the shared realtime transcription session and adds a local `ws` regression test for ready-then-close flapping.

## Best Possible Solution

Keep the shared-helper fix, but reset the reconnect budget after a genuinely stable ready period and test both flap exhaustion and stable recovery past the cap.
