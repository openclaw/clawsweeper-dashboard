## What This Changes

The PR centralizes a 120-second Tlon response-header deadline and the existing 30-second body-idle deadline, then applies that policy to inbound media downloads and outbound URL-backed image uploads with matching assertions.

## Best Possible Solution

Land the shared header-only timeout policy once exact-head checks are green, preserving the 30-second body-idle limit and existing inbound omission and outbound original-URL fallbacks.
