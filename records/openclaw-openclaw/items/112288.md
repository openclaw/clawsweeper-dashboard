## Summary

Keep this PR open for security review. The branch applies a focused fail-closed guard that matches the existing explicit-origin and opt-in fallback model, but its claimed exploit and reverse-proxy upgrade behavior have only unit-test evidence, not after-fix behavior proof from a real gateway setup.

## What This Changes

The PR prevents non-local gateway clients from receiving implicit private-IP, `.local`, or `.ts.net` same-origin trust from matching attacker-controlled Host and Origin headers, with regression cases for the three hostname classes.

## System Context

The gateway checks browser WebSocket origins before completing a Control UI or webchat handshake. Request host, browser Origin, configured allowlists, and client locality feed that decision, which then permits or rejects access to the gateway control plane.
