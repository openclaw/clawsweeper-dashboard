## What This Changes

This PR changes the private QA channel and QA Lab bus so fetched events are acknowledged only after handling, aiming to preserve unhandled messages across gateway restarts while keeping native stop commands responsive.

## System Context

The repo-local QA channel polls the QA Lab bus for synthetic inbound events and dispatches them through a Gateway account. The bus stores each account’s acknowledged cursor, which determines which events are replayed after the channel reconnects or restarts.
