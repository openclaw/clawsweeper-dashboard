## Summary

Keep open: current main and v2026.6.11 still expose `/models` as provider/model/runtime selection, while account/profile switching is only available through typed `/model ...@profile` and auth-order/status flows. The open related PR is useful partial overlap for preserving an existing auth profile during model changes, but it does not add the requested account picker UX.

## What This Changes

Allow the `/models` chat picker/buttons to show and switch the provider account/auth profile for GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible auth profiles for the selected provider/model, shows the active profile, and persists through the existing session/auth helpers across supported channels.
