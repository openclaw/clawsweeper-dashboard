## Summary

Keep open: current main still has model/provider/runtime picker paths, plus typed `/model ...@profile` account pinning, but it does not expose first-class account/profile selection from the `/models` buttons for GPT/OpenAI or Claude/Anthropic accounts.

## What This Changes

The issue requests account/profile selection and active-account visibility directly in the `/models` chat picker for account-backed GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible auth profiles for the selected provider/model, shows the active profile, and persists through existing session/auth helpers across supported channels.
