## Summary

Keep open: current main and the latest shipped release still expose `/models` as provider/model/runtime selection only, while account/profile switching remains available through typed profile overrides and auth-order flows. The related open PR is useful partial overlap for preserving an existing auth-profile override during model picker changes, but it does not add the requested account picker UX or active-account display.

## What This Changes

Add `/models` button/menu support to choose and display the configured provider account or auth profile for GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible profiles for the selected provider/model, shows the active profile, and persists through the existing session/auth helpers across supported channel pickers.
