## Summary

Keep open: current main and v2026.6.11 still do not provide account/auth-profile choices in the interactive `/models` picker contract. Typed `/model ...@profile` support exists, and the related preservation PR only addresses retaining an existing profile override, so the requested picker UX still needs product direction.

## What This Changes

Request `/models` buttons/menu to let users choose and see the provider account/auth profile for GPT/OpenAI and Claude/Anthropic-backed models.

## Best Possible Solution

Define a shared channel picker contract that lists compatible auth profiles for the selected provider/model, displays the active profile, and persists through the existing session auth-profile override path across supported pickers.
