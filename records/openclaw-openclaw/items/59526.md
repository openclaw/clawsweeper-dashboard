## Summary

Keep open: current main and v2026.6.11 still expose model/runtime picker state separately from account/profile selection, and the open related PR only preserves an existing auth profile during model selection rather than adding account choices to `/models`.

## What This Changes

Request to add account/profile selection and active-account display to `/models` buttons for GPT/OpenAI and Claude/Anthropic-backed models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible auth profiles for the selected provider/model, shows the active profile, and persists through the existing session/auth helpers across supported channel pickers.
