## Summary

Keep open: current main and v2026.6.11 still do not expose account/profile choices in the `/models` picker, while typed `/model ...@<profileId>` remains the workaround. The related open pull request is useful partial overlap for preserving an existing auth profile during model-only picker changes, but it does not add first-class account selection or active-account display.

## What This Changes

Request account/profile selection and active-account display directly in `/models` buttons for GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible auth profiles, shows the active profile, and persists through the existing session/auth helpers across supported channel pickers.
