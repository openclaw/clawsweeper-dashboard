## Summary

Keep open: current main and v2026.6.11 still do not provide first-class account/profile selection in the `/models` button UI; typed `/model ...@profile` exists as a workaround, and the related open PR only preserves existing auth-profile state during model selection.

## What This Changes

Add account/profile selection and current-account display to `/models` buttons or menus for OpenAI/GPT and Anthropic/Claude model choices.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that lists compatible auth profiles for the selected provider/model, shows the active profile, and persists through the existing session auth-profile helpers across supported channels.
