## Summary

Keep open: current main still supports account/profile pinning through typed `/model ...@profile` and status/order flows, but the `/models` button pickers only carry provider/model/runtime state and do not expose account selection or active-account display.

## What This Changes

The issue requests account/profile switching and active-account visibility directly in the `/models` picker for OpenAI/GPT and Anthropic/Claude model choices.

## Best Possible Solution

Define one shared `/models` account/profile picker contract that lists compatible auth profiles for the selected provider/model, shows the active profile, and persists through existing session/auth helpers across supported channels.
