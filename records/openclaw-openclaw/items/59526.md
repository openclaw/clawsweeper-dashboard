Keep open: current main and v2026.6.11 still model `/models` picker state as provider/model/runtime selection, while account/profile switching remains available only through typed `/model ...@profile` and status/order flows. ## What This Changes

Request `/models` UI/buttons to choose and show the provider account or auth profile for GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible auth profiles for the selected provider/model, shows the active profile, and persists through the existing session/auth helpers across supported channels.
