## Summary

Keep open: current main and v2026.6.11 still expose `/models` as provider/model/runtime selection, while account/profile switching remains a typed `/model ...@profile` and auth-status/order workflow. The related open pull request preserves existing auth-profile state during picker model changes, but it does not add the requested account selector or account-choice UX.

## What This Changes

Request that `/models` buttons or menus let users choose and see the backing provider account/auth profile for GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible auth profiles for the selected provider/model, shows the active profile, and persists through existing session/auth helpers across supported channels.
