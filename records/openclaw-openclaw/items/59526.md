## Summary

Keep open: current main still supports typed per-session account/profile pinning, but the `/models` picker surfaces only provider/model/runtime choices and does not offer first-class account switching or active-account selection. The related open PR is useful partial overlap for preserving an existing auth profile during model selection, but it does not implement the requested picker UX.

## What This Changes

Request to let users choose and see the backing provider account/profile directly from `/models` buttons for GPT/OpenAI and Claude/Anthropic models.

## Best Possible Solution

Define a shared `/models` account/profile picker contract that enumerates compatible profiles for the selected provider/model, displays the active profile, and persists through the existing session/auth helpers across supported channel pickers.
