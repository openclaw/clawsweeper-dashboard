## System Context

Subagent registration records a run in the agent registry, durably writes that registry to SQLite, then creates detached task work and waits for completion through the gateway. Registry persistence notifications feed consumers such as wait-state handling, so the ordering and ownership of retained run metadata affect durable session state.
