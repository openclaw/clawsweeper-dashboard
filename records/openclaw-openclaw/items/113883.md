## What This Changes

The PR replaces Control UI query-based session links with readable `/chat/...` and `/dashboard/...` paths, migrates released query links, and updates session navigation plus ClickClack links to use the new grammar.

## System Context

Control UI navigation turns a browser location into a session target, then loads that session from the Gateway and renders either its chat or dashboard face. The PR changes the browser-facing route grammar while preserving old query links at application startup and propagating the canonical paths through internal navigation and the ClickClack plugin.
