## What This Changes

This PR replaces Control UI query-based session links with readable chat and dashboard path URLs, adds path resolution and canonicalization, and updates ClickClack and UI navigation to emit the new form.

## System Context

The Control UI turns session keys from navigation events, sidebar links, and external ClickClack discussion links into browser URLs, then resolves those URLs back into the active gateway session. This change affects bookmarking, shared links, dashboard presentation, native route restore, and every UI surface that opens a session.

## Architecture Diagram

flowchart LR

  B --> C[Chat or dashboard path]
  C --> D[Control UI route loader]
  D --> E[Gateway session lookup]
  E --> F[Active chat or dashboard session]
  D --> G[Canonical browser URL]

## Best Possible Solution

Keep the new path form, but preserve released query-form session links through a narrow compatibility redirect, then make the URL grammar consumable by both the UI and ClickClack through one supported contract or a deliberately versioned shared package.
