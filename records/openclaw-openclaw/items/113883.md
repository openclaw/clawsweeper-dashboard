## Summary

This PR still needs a maintainer compatibility decision before merge. It deliberately removes released `?session=` deep links, including links previously emitted into ClickClack discussion history, and the prior P1 finding remains unresolved; automated coverage does not replace a redirect or compatibility plan for existing bookmarks.

## What This Changes

The PR introduces readable `/chat/...` and `/dashboard/...` session URLs, a shared session-URL contract, and updates Control UI and ClickClack link generation to use the new paths.

## System Context

Control UI routes open a selected agent session and render it either as chat or as a dashboard. Links originate from navigation, session lists, and ClickClack discussions, then route parsing resolves a stable session key before the chat surface loads.

## Best Possible Solution

Keep the stable path URLs, but preserve released query-form deep links for a documented deprecation window and canonicalize them to the new path; then add redacted real-browser evidence for both legacy upgrade and new-link behavior.
