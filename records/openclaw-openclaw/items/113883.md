## What This Changes

This PR replaces Control UI query-based session selection with readable `/chat/...` and `/dashboard/...` paths, adds a session URL contract package, and updates UI and ClickClack link producers.

## System Context

Control UI navigation turns session keys into browser URLs used by bookmarks, internal links, ClickClack discussion links, and native-shell route restore. On load, the route loader parses the URL, resolves session references through the Gateway, and renders the selected chat or dashboard face.

  B --> C[Chat or dashboard path]
  C --> D[Route loader]
  D --> E[Gateway session lookup]
  E --> F[Selected session view]
  G[ClickClack discussion link] --> B

## Best Possible Solution

Preserve released query-form deep links through a narrow route-boundary translation to canonical paths, then make UI and ClickClack consume one publishable, versioned URL-contract implementation with focused upgrade and live-browser proof.
