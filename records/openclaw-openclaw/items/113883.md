## Summary

Keep this PR open for a maintainer compatibility decision and a narrow repair. The branch intentionally removes released `?session=` deep links without a transition, so existing bookmarks and ClickClack discussion links will no longer select their intended session; the prior P1 finding remains unresolved at the same reviewed head.

## What This Changes

The PR replaces Control UI query-based session links with readable `/chat/...` and `/dashboard/...` paths, adds a shared session-URL contract, and updates Control UI and ClickClack link generation.

## System Context

Control UI navigation turns browser URLs into a selected gateway session, then renders that session in chat or dashboard form. Session links are generated by Control UI surfaces and by the ClickClack plugin, so the URL grammar is a public cross-surface navigation contract.

## Architecture Diagram

  F --> G[Chat or dashboard view]

## Best Possible Solution

Keep readable path URLs as the canonical output, but add a bounded legacy query-form URL migration that resolves `?session=`/`?face=` once and replaces the address bar with the equivalent canonical path; retain it until maintainers explicitly retire the released link contract.
