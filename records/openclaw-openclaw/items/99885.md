## What This Changes

The issue reports `openclaw plugins install git:<repo>` failing with `EXDEV` when the temp clone directory and managed plugin repository live on different filesystems.

## Best Possible Solution

Make git plugin installation cross-device safe while preserving the existing install policy scan, npm install, rollback, and managed-repo cleanup semantics.
