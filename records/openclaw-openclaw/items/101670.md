## What This Changes

The issue asks OpenClaw to avoid treating active processing sessions with temporarily missing activity bookkeeping as recoverable stale session state during event-loop stalls.

## Best Possible Solution

Preserve idle stuck-session recovery while defining a tested processing/no-observed-work contract that cannot abort-drain healthy runs after event-loop stalls.
