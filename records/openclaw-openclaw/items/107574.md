## What This Changes

The PR changes Android’s shared segmented control to split option sets larger than four into balanced rows, adds partitioning unit tests, and refreshes generated native-i18n line metadata.

## Best Possible Solution

Make large-set wrapping an explicit ClawSegmentedControl parameter and enable it for Skill Workshop, unless an Android owner deliberately approves wrapping above four as the shared default after auditing every caller; then refresh onto current main and rerun exact-head Android and native-i18n checks.
