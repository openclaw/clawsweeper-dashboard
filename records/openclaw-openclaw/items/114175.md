## Summary

Keep this PR open for normal maintainer review: the patch appears to close the reported auto-approval bypass by applying the existing blocked-shell-wrapper rule at all three auto-review entry points, with focused regression coverage and reported after-fix SDK behavior proof.

## What This Changes

The PR prevents login and interactive shell wrappers from receiving model-based automatic exec approval, sending them to explicit human approval in gateway, node-host, and public SDK execution paths.

## System Context

OpenClaw’s exec approval pipeline parses agent-requested shell commands, determines whether the command can be safely bound to model review, and either authorizes execution or creates a human approval request. Gateway execution, node-host execution, and the public agent-harness helper must make the same eligibility decision.
