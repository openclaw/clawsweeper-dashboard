## What This Changes

The PR routes login-capable `bash`, `sh`, and `/bin/sh` wrapper commands to explicit human approval instead of model auto-review in gateway, node-host, and public agent-harness execution paths.

## System Context

OpenClaw’s exec approval flow parses a requested shell command into authorization segments, determines whether it may be model-reviewed, then either executes under the reviewed binding or creates a human approval request. This PR changes the eligibility decision for startup-capable shell wrappers before that model-review branch is entered.
