## Summary

Keep this PR open for a narrow repair. The shared classifier can treat a canonical startup shell such as `/bin/sh -lc "echo ok"` as payload-bound when passed `segment.raw`, leaving that login shell eligible for low-risk model approval; the same call pattern is present in the gateway, node-host, and public SDK paths. Likely related people: historical ownership could not be established confidently from the available read-only evidence, so route the mechanical repair through the agents execution area.

## What This Changes

The PR prevents login and interactive shell wrappers from being auto-approved in gateway execution, node-host execution, and the public agent-harness helper.

## System Context

OpenClaw's exec approval pipeline parses a shell command into authorization segments and may ask a model to approve one safely bound command. Gateway, node-host, and SDK callers consume that decision to either execute automatically or create an explicit human-approval request.

## Best Possible Solution

Use a strict startup-wrapper predicate that cannot take the legacy raw payload-binding exception in all three approval entry points, then add focused regression cases for canonical `sh`/`/bin/sh -lc` forms while preserving ordinary single-command auto-review.
