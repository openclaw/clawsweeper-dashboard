## What This Changes

The PR replaces unbounded synthesis body-file reads with a 1 MiB bounded file-handle reader, rejects oversized or non-regular files, and adds focused CLI tests.

## Best Possible Solution

Define an owner-approved maximum UTF-8 body size at the memory-wiki mutation boundary, enforce and test it consistently across public entry points, document the compatibility change, and reuse that shared limit in the bounded file reader; otherwise preserve the existing large-file contract with a streaming-oriented refactor.
