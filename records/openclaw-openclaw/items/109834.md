## Summary

Keep this PR open: it usefully addresses unbounded reads, but it changes the existing `--body-file` contract by rejecting valid files over 1 MiB without an approved compatibility policy, and its pre-open `stat` check can be bypassed by a path swap to a FIFO that blocks `open`.

## What This Changes

The branch replaces the unbounded synthesis `--body-file` read with a 1 MiB bounded file-handle reader and adds tests for valid, oversized, and non-regular inputs.

## Best Possible Solution

Have a memory-wiki owner choose the supported large-file policy first; then implement an approved bounded-read strategy that preserves the chosen compatibility contract and validates the opened descriptor without allowing FIFO blocking.
