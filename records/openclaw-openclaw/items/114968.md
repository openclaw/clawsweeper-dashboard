## What This Changes

This PR prevents Mattermost from posting streaming draft previews whenever registered outbound hooks may rewrite or cancel the final reply, while retaining previews when neither modifying hook is registered.

## System Context

Mattermost turns stream agent output into provider-side draft posts before the normal outbound delivery lifecycle completes. Outbound hooks can rewrite or cancel that final delivery, so the preview path must not expose content that the hook-controlled final path would suppress.

## Architecture Diagram

flowchart LR
  A[Mattermost inbound post] --> B[Agent reply stream]
  B --> C[Check outbound hook registration]
  C -->|No modifying hooks| D[Provider draft preview]
  D --> E[Finalize same Mattermost post]
  C -->|Reply or message hook present| F[Normal outbound delivery lifecycle]
  F --> G[Rewritten final reply or cancellation]

## Best Possible Solution

Retain the Mattermost-local safety gate if the owner accepts that potentially modifying outbound hooks take precedence over provider previews, then rebase and preserve explicit no-hook, rewrite, and both cancellation proofs.
