## What This Changes

The PR adds descriptor-allowlisted session actions and optional chat navigation for sandboxed plugin tabs through a parent-owned MessagePort bridge, while extending session-action context with session and context-window data.

## Best Possible Solution

Keep the descriptor-level action allowlist and independent navigation capability, but remove caller authority over context-window metadata by deriving it from Gateway-owned session/model state, cover direct spoof attempts, and demonstrate the final exact head in a real sandboxed plugin tab.
