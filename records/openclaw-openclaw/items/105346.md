## Summary

Keep open: the prior P1 cancellation race remains unchanged on the revised head, and the newly committed source-inspection script does not provide real behavior proof. Parent abort can start destructive cleanup while gateway dispatch continues, allowing the function to return an accepted child and register task state after its runtime and session were closed.

## What This Changes

The PR forwards the tool execution abort signal into ACP spawning, registers failed-spawn cleanup on parent cancellation, and adds a source-inspection proof script.

## Best Possible Solution

Implement one race-safe ownership handoff: if abort wins before acceptance, await complete spawn cleanup and never return accepted; once registered, dispose the spawn-phase listener and route cancellation through canonical ACP task/session cancellation, backed by timing tests and real process-tree proof.
