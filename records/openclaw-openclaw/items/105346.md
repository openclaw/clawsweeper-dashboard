## Summary

Keep this PR open for repair: the underlying ACP cancellation bug remains valid, but the current patch does not safely coordinate cancellation with dispatch and accepted-task registration.

## What This Changes

The PR forwards the parent tool abort signal into ACP spawning and invokes runtime, session, binding, and transcript cleanup when that signal aborts.

## Best Possible Solution

Implement one race-safe cancellation handoff: await spawn-phase cleanup when cancellation wins before acceptance, then use canonical ACP task or session cancellation after the child becomes registered.
