The patch is a small, additive CLI feature that consistently maps the opt-in flag to the existing lightweight bootstrap mode in both dispatch paths, but it still needs redacted after-fix real behavior proof and maintainer confirmation that this public CLI surface should be added.

## What This Changes

This PR adds `openclaw agent --light-context`, documents it, and forwards the option as lightweight bootstrap context for both Gateway-backed and explicit local agent turns.

## System Context

`openclaw agent` accepts a one-shot task and dispatches it either through the Gateway or an embedded local agent. Both routes pass run options into the agent runtime, where bootstrap-context mode determines whether workspace bootstrap files are included.
