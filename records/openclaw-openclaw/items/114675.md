The patch is a narrow, opt-in exposure of an existing lightweight bootstrap mode, and its supplied real-runtime proof covers both Gateway and explicit local dispatch; the remaining question is whether omitting workspace bootstrap instructions should be a supported public `openclaw agent` contract.

## What This Changes

The PR adds an opt-in `--light-context` flag to `openclaw agent`, passing the existing lightweight bootstrap mode through Gateway-backed and explicit local agent runs, with documentation and focused tests.

## System Context

The one-shot `openclaw agent` command converts CLI options into either a Gateway request or an embedded local agent run. Both paths eventually construct the agent prompt, where bootstrap context determines whether workspace files such as `AGENTS.md`, `SOUL.md`, and `USER.md` are injected.

## Best Possible Solution

If maintainers want bounded scripted tasks to opt out of workspace bootstrap files, retain this explicit flag, rebase it, and preserve the documented default of full context for ordinary turns.
