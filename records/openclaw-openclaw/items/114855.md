## What This Changes

This PR renames scheduler documentation to “Automations,” updates feature prose and headings, and makes `openclaw automations` the primary documented command while retaining `cron` terminology for protocol, configuration, and schedule syntax.

## System Context

OpenClaw’s Gateway scheduler persists and runs scheduled jobs, while the CLI exposes those jobs to operators and the documentation teaches users which command and scheduler concept to use. This PR changes the documentation-facing vocabulary and command examples that lead users into that CLI and scheduler path.
