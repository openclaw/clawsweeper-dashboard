## Summary

Keep this PR open. The page-scoped interception design is an appropriate bounded fix and the live proof is strong, but the current head has a confirmed result-propagation defect that can leave policy-denied wait actions pending until their ordinary timeout; the protected security surface also requires exact-head owner review after repair.

## What This Changes

The PR adds request-stage SSRF guards for interaction-triggered browser navigations, exposes `scrollIntoView` to agent browser calls, and disables managed-Chrome network prediction.

## Best Possible Solution

Race guarded actions against a guard-owned policy-denial signal, then drain the exact route handler before returning the policy error so denial is prompt without weakening source-preservation or quarantine guarantees; retain the page-scoped boundary and explicit Playwright limitation documentation.
