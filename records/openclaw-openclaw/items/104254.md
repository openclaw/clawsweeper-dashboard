## Summary

Keep this PR open for repair. The page-scoped request-interception design matches the pinned Playwright contract and the live proof strongly supports the bounded SSRF protection, but the unchanged denial path still waits for a long-running action to settle before returning the policy error.

## What This Changes

The PR adds page-scoped request interception for browser navigations triggered by hover, drag, scroll, wait, and batch actions, exposes `scrollIntoView`, disables network prediction for fresh managed Chrome launches, and updates related tests and documentation.

## Best Possible Solution

Race guarded actions against a guard-owned policy-denial signal, then remove and drain the exact page route before returning the policy error, while retaining the page-scoped ownership boundary, source-preservation logic, residual final-URL checks, and explicit Playwright limitation documentation.
