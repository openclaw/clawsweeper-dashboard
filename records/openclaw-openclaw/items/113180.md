## What This Changes

Fix WhatsApp inbound debouncing so a later same-conversation message can enter the active session’s documented `steer` path instead of waiting for the prior agent turn to finish.

## System Context

WhatsApp inbound messages are grouped by conversation through the shared inbound debouncer before they are dispatched into the session and agent-run queue. The queue’s `steer` mode should route a normal follow-up into an already-active run when supported, rather than unnecessarily waiting for the original turn to complete.
