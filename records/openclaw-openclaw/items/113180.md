## What This Changes

Repair WhatsApp inbound debounce so a later message in the same conversation can reach active-run steering instead of waiting for the prior agent turn to finish.

## System Context

WhatsApp inbound messages enter a keyed debounce layer before OpenClaw routes them into the session and agent-run queue. The debounce layer should batch bursts while allowing later messages to reach the active-run steering path; the downstream session lane remains responsible for turn ordering.
