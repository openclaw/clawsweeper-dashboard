## What This Changes

This PR adds `openclaw commands list` and `openclaw commands inspect` to inventory existing CLI descriptors, routes, registered commands, and opt-in plugin descriptors in JSON or Markdown.

## System Context

OpenClaw’s CLI registers lazy core and sub-CLI command groups, while plugins can contribute command descriptors through the plugin registry. This PR projects those existing declarations into a read-only operator/developer inventory without dispatching commands or changing their authorization path.
