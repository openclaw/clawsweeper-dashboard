The issue asks QQBot to honor `QQBOT_DATA_DIR` for its data directory instead of always using the user's home-based `.openclaw/qqbot` path.

## Best Possible Solution

Resolve the linked PR by either landing validated, documented `QQBOT_DATA_DIR` support with real diagnostic proof, or deliberately replacing the diagnostic with supported `OPENCLAW_HOME` or SQLite-state guidance.
