## What This Changes

The issue reports that QQBot diagnostics tell Windows users to set `QQBOT_DATA_DIR`, but the QQBot data helper still uses the default home-based `~/.openclaw/qqbot` path.

## Best Possible Solution

Resolve the contract in the linked PR: either safely implement and document a validated `QQBOT_DATA_DIR` override, or replace the diagnostic hint with the supported `OPENCLAW_HOME` or SQLite-state guidance.
