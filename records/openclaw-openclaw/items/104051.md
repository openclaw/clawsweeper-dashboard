## Summary

The patch fixes a source-confirmed macOS onboarding regression at the correct owner boundary: current `main` treats a compatible CLI executable as completing setup without starting its Gateway, while this branch keeps the CLI gate until the existing activation seam reports readiness. No blocking correctness or security finding is evident, but the protected `maintainer` label requires explicit maintainer handling and exact-head macOS CI is still running.

## What This Changes

The PR separates compatible CLI executable detection from Gateway readiness, starts and verifies the existing local CLI Gateway during macOS onboarding, and adds focused state-decision tests.

## Best Possible Solution

Keep executable readiness distinct from Gateway readiness, reuse the installer-owned activation seam, retain the CLI setup gate through activation failure, and land after exact-head macOS checks and protected-label review pass.
