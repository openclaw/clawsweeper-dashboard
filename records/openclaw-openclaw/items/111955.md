## What This Changes

Replaces Slack’s object-identity marker for rendered presentation segments with process-local HMAC provenance so cloned or JSON-round-tripped outbound payloads can still deliver native Slack table blocks.

## System Context

OpenClaw renders portable presentations into Slack-specific outbound segments, then hands those payloads through generic outbound hooks before Slack delivery. This change protects the rendered delivery plan across serialization while preserving text fallback for invalid or stale metadata.
