## What This Changes

The PR replaces Slack’s object-identity marker for rendered presentation segments with process-local HMAC provenance so cloned or JSON-round-tripped outbound payloads can retain native Slack table blocks without allowing altered metadata to authorize block delivery.

## System Context

The Slack plugin renders portable OpenClaw presentations into Slack-specific blocks, which travel through generic outbound hooks before the Slack Web API send. The changed adapter validates its private rendered delivery plan immediately before sending, selecting native blocks only when the plan remains authentic.
