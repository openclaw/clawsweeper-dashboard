## What This Changes

The PR signs Slack’s private rendered-presentation delivery plan so cloned or JSON-serialized outbound payloads can retain native `data_table` blocks while altered or stale metadata falls back to ordinary text.

## System Context

OpenClaw’s Slack plugin turns portable presentations into Slack Block Kit content before the generic outbound flow delivers it. This change preserves a trusted in-process rendering plan through payload reconstruction, then validates it immediately before Slack delivery so native blocks are sent only when the plan is intact.
