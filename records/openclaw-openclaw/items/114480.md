## What This Changes

The branch sums distinct Codex app-server provider-response usage for a turn, preserves the latest response as current context usage, and emits separate model-call diagnostics around tool phases.

## System Context

The Codex extension receives app-server notifications for provider responses and tool lifecycle events, projects them into attempt usage and assistant state, then passes trusted diagnostics to the OpenTelemetry extension. This change alters how multi-response turns become billing/context snapshots and request-level trace spans.
