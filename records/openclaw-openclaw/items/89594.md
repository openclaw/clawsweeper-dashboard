## What This Changes

Microsoft Teams inbound channel and group-chat messages with file attachments should make those files available to the agent via Graph-backed media retrieval.

## Best Possible Solution

Land one reviewed msteams plugin fix that uses the correct Graph identifiers, handles top-level channel messages, thread replies, and group chats, and preserves the mention-only protection by default or behind an explicit opt-in with tests and redacted live Teams proof.
