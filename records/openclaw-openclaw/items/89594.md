## Summary

Keep open: current main and v2026.6.11 still contain the Microsoft Teams inbound attachment failure, and the two linked implementation PRs are still open rather than merged. The latest group-chat evidence makes the remaining fallback gate clearer, but closure should wait for a reviewed fix that reconciles channel URL construction, thread replies, group-chat HTML payloads, and the earlier mention-only false-positive protection.

## What This Changes

The issue asks the Microsoft Teams plugin to make inbound Teams channel or group-chat file attachments available to OpenClaw by fetching the Graph message when Bot Framework payloads omit usable attachment data.

## Best Possible Solution

Land one reviewed msteams plugin fix that uses the correct Graph identifiers, handles top-level messages, thread replies, and group chats, preserves the mention-only protection by default or behind an explicit opt-in, and includes focused tests plus redacted live Teams proof.
