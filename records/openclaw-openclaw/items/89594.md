## What This Changes

The issue reports that Microsoft Teams inbound channel attachments are not recognized by OpenClaw when Graph lookup is needed for channel, thread-reply, or related group-chat messages.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/90738 or an equivalent Microsoft Teams plugin fix that uses the correct Graph team/chat message URL shapes, recovers markerless text/html attachment stubs, and preserves a narrow no-text/html skip path without adding config unless maintainers choose that policy.
