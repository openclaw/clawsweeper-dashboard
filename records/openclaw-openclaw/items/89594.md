## What This Changes

The issue reports that inbound Microsoft Teams channel or group-chat file attachments are not made available to the agent even after Graph permissions are configured.

## Best Possible Solution

Land one canonical Microsoft Teams plugin fix that covers channel top-level messages, channel thread replies, and the group-chat no-attachment-id case while preserving the prior mention-only protection through a maintainer-approved default/config policy and docs.
