Keep open: current main and v2026.6.11 still contain the Microsoft Teams inbound attachment failure, and the two related implementation PRs are open rather than merged. The issue remains the canonical tracker until maintainers choose and land the Graph fallback behavior for channel/thread and group-chat variants.

## What This Changes

The issue requests that the Microsoft Teams plugin make inbound channel and group-chat attachments available to OpenClaw by fetching the full message context from Microsoft Graph when Bot Framework payloads omit usable attachment data.

## Best Possible Solution

Land one reviewed msteams plugin fix, or coordinated pair of fixes, that covers channel team GUIDs, top-level messages, thread replies, and group-chat HTML stubs while preserving the mention-only protection by default or behind an accepted opt-in.
