## What This Changes

The issue reports that Microsoft Teams inbound channel and group attachments are not available to OpenClaw because the plugin does not reliably fetch the full Graph message context when Bot Framework omits attachment metadata.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/90738, or an equivalent plugin-local fix covering AAD group IDs, markerless text/html Graph fallback, and channel reply URL selection, then close this issue as implemented.
