## Summary

Keep open: current main now covers some inline media paths, including direct tool-result images and MEDIA image/audio/video attachments, but remote Markdown images, rich web previews, and autoplay/remote-fetch policy remain unresolved and security-sensitive.

## Best Possible Solution
