## Summary

This PR remains necessary: it directly targets the open gateway-crash report and changes the pinned lookup callback timing so the TLS socket owner can attach its error handling first. The focused diff preserves address selection and SSRF filtering, adds timing regression coverage, and shows no discrete blocking defect from the supplied patch and proof; confidence is moderated because the read-only sandbox prevented independent local source/history commands.

## What This Changes

The PR defers pinned DNS lookup callbacks with `process.nextTick` and adds tests confirming asynchronous delivery for ordinary, all-address, and family-specific lookups.

## System Context

OpenClaw’s network SSRF layer can pin an outbound hostname to validated IP addresses before a Telegram or other HTTP client opens a TLS connection. The lookup result feeds the socket connection path, whose error handling must be installed before an unreachable address can emit a connection error.
