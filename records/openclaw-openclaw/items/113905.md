## What This Changes

The PR makes pinned DNS lookups deliver their chosen addresses asynchronously and adds regression coverage so immediate HTTPS connection failures are handled by the socket owner instead of crashing the gateway.

## System Context

OpenClaw’s guarded network layer resolves pinned, SSRF-validated addresses for outbound requests such as Telegram polling and fallback calls. Its custom lookup function feeds the HTTPS/TLS connection path, whose normal error and retry owner must be attached before an unreachable address can fail.
