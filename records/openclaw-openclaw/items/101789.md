No viable duplicate PR owns the remaining work; the matching closed PR was marked accidental and bundled unrelated ACP dispatch changes.

## What This Changes

Add a Board dropdown filter to the Workboard Control UI so cards can be scoped to one board alongside the existing view, priority, agent, search, and archive filters.

## Best Possible Solution

Add a first-party board selector to the existing Workboard toolbar, backed by board summaries when available and card board ids as a fallback, with tests proving mixed-board cards can be scoped without changing storage or dispatch contracts.
