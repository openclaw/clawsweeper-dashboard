## Summary

Keep open: current main still lacks a board-scoped Workboard Control UI filter even though the backend, CLI, and card metadata already support board ids, so the remaining work is a narrow UI feature.

## What This Changes

Add a Board dropdown filter to the /workboard Control UI so operators can scope cards to one board alongside the existing search, view, priority, and agent filters.

## Best Possible Solution

Add a first-party Board selector to the existing Workboard toolbar/filter state, using workboard.boards.list when available and loaded card board ids as a fallback, without adding config or bundling unrelated agent/runtime changes.
