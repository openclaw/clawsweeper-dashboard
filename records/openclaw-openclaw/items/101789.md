## Summary

Keep open: current main already has Workboard board IDs and backend list support, but the /workboard Control UI still has no board-scoped toolbar state, fetch, or filter predicate.

## What This Changes

Add a Board dropdown filter to the /workboard Control UI so Workboard cards can be scoped to one board alongside the existing view, priority, and agent filters.

## Best Possible Solution

Add a narrow Board toolbar select backed by existing Workboard board/card APIs, update filtering state and tests, and avoid new config or unrelated dispatch behavior.
