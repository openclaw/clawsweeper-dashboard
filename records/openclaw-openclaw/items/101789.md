## Summary

Keep open: current main still has no board-scoped Workboard toolbar filter, while the Workboard backend and docs already expose board ids, board listing, and board-scoped list/stat methods.

## What This Changes

Add a Board dropdown filter to the `/workboard` Control UI so visible cards can be scoped to one Workboard board.

## Best Possible Solution

Add a first-party board selector to the existing Workboard toolbar, backed by `workboard.boards.list` or board summaries and covered by mixed-board visibility tests.
