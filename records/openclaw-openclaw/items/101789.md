## Summary

Keep open: current main still has no Workboard board-scoped toolbar filter, while cards, docs, gateway methods, and the store already support board ids, so this remains a narrow Control UI ergonomics task rather than a backend gap.

## What This Changes

Add a Board dropdown filter to the Control UI Workboard page so cards can be scoped to a single board alongside the existing view, priority, and agent filters.

## Best Possible Solution

Add a first-party board selector to the existing Workboard toolbar/state path, using server board summaries when available and falling back to card board ids, with i18n and mixed-board visibility tests.
