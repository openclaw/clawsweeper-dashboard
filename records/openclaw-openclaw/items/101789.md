## Summary

Keep open: current main still has no board-scoped Workboard UI filter, while the Workboard backend and docs already expose board ids, board-scoped list calls, and board summaries. The only same-topic PR I found, https://github.com/openclaw/openclaw/pull/100602, was closed unmerged as accidental and bundled unrelated agent/config changes, so it is not a canonical fix path.

## What This Changes

Requested addition of a Board dropdown filter to the Control UI Workboard so operators can scope visible cards to one board.

## Best Possible Solution

Add a first-party board selector to the existing Workboard toolbar, using board summaries when available and falling back to loaded card board ids, with regression coverage for mixed-board visibility.
