## Summary

Keep open: current main still has search, view, priority, and agent filters but no board-scoped state, selector, or board fetch, while the Workboard backend and docs already expose board ids, board listing, and board-scoped card listing.

## What This Changes

The issue requests a Board dropdown filter in the /workboard Control UI so operators can scope visible cards to a single Workboard board.

## Best Possible Solution

Add a default-all Board selector to the Workboard toolbar, populate it from existing board metadata or loaded card board ids, apply it before the existing filters, and cover no-board, empty-board, and archived-board behavior.
