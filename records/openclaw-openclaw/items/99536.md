## Summary

Keep open for maintainer review: the implementation appears correct and well covered, but it intentionally changes `message_tool_only` default visibility and diagnostic behavior, so it should not be auto-closed or auto-merged without delivery-policy signoff.

## What This Changes

The PR adds default guarded recovery for substantive `message_tool_only` finals by enqueueing one message-tool retry, adding a sanitized retry-failure diagnostic, updating queue priority handling, prompts, docs, and QA coverage.

## Best Possible Solution

Land this PR only after maintainer signoff on default-on recovery; after merge, close https://github.com/openclaw/openclaw/issues/85714 as fixed and close https://github.com/openclaw/openclaw/pull/88992 as superseded.

## Solution Assessment
