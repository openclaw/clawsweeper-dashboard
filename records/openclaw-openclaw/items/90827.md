## Summary

The settled-message diagnostic is bounded and useful, but the persistent fallback label is shared by every fallback path and therefore records an incorrect cause when narrative generation cannot start or ends unsuccessfully; the PR also still lacks after-fix real behavior proof.

## What This Changes

The PR returns the final settled narrative messages with extracted text, logs compact assistant-message diagnostics for unusable results, and visibly labels synthetic fallback entries in DREAMS.md.

## Best Possible Solution

Use a cause-neutral visible fallback marker, or pass a closed non-sensitive fallback kind for runtime-unavailable, terminal-failure, and no-text outcomes, while retaining the detailed structural diagnostic in logs and requiring redacted live proof from the corrected head.
