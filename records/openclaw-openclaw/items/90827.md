## What This Changes

This PR preserves the final settled dreaming-session messages so memory-core can log a compact no-text diagnostic and visibly mark synthetic fallback diary entries.

## System Context

Memory Core’s dreaming workflow runs a narrative subagent after memory promotion, then reads the subagent transcript to append a diary entry to `DREAMS.md`. When no usable assistant text is available, this path writes a synthetic fallback entry and emits gateway diagnostics for operators.
