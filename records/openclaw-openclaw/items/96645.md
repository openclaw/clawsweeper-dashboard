## What This Changes

The PR makes Mattermost private-channel outbound and isolated-cron routing reuse the authoritative `group` session namespace while retaining `channel:<id>` as the wire delivery target.

## System Context

Mattermost turns enter OpenClaw with an authoritative channel type, then outbound routing reconstructs a session key before a message or scheduled cron delivery is sent. The change carries that private-channel classification through target resolution and Mattermost-bound cron routing so the delivery path reaches the same conversation namespace as inbound processing.
