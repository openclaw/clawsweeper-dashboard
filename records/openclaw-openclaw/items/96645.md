## Summary

Keep this PR open, but it is not merge-ready: the patch is a useful Mattermost session-routing repair, yet the public-channel directory fix does not actually propagate through the shared target resolver, the new channel-kind fallback can cache a non-authoritative `channel` result, and the live proof still does not show the session-store invariant.

## What This Changes

This PR updates Mattermost outbound session routing, bare-id target resolution, directory channel typing, and isolated cron delivery route-key selection so private channels preserve the `group` session namespace.

## Best Possible Solution

Keep the plugin-owned route and cron-bound-session shape, but propagate authoritative directory entry kinds through target resolution, avoid caching non-authoritative channel fallbacks, and require redacted session-store or log proof before merge.
