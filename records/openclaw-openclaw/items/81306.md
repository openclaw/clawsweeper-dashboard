## Reproduction Assessment

## Solution Assessment

Yes, this appears to be the best narrow fix: the resolver owns loopback bind semantics, and the PR leaves `auto`, `tailnet`, `custom`, `lan`, listen-time binding, and the non-loopback runtime guard intact. Weakening the guard would be the wrong layer because it protects against accidental network exposure.
