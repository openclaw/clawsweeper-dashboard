## Summary

This PR remains necessary and the implementation appears directionally correct, but it should not merge until an actual Windows setup demonstrates that an unresolved 8.3 temp alias is expanded or bypassed and portable bootstrap succeeds; the submitted evidence exercises an injected mock resolver rather than the real Windows path behavior.

## What This Changes

Centralizes Windows installer temp-directory selection, normalizes short-path candidates, propagates the selected directory through `TEMP` and `TMP`, updates portable Node/Git and command execution to use it, and adds a focused PowerShell test script.

## Best Possible Solution

Keep the centralized installer-owned temp selection, then prove on a clean Windows VM or Sandbox that a stale short alias resolves or falls through to an existing long temp directory and that portable Node download, portable Git extraction, and child command execution all complete using the selected path.
