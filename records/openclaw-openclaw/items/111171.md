## What This Changes

This PR bounds the test helper’s `git ls-files` subprocess with a five-second SIGKILL timeout and adds direct regression coverage for ordinary and stalled Git behavior.

## System Context

`src/test-utils/repo-files.ts` helps tests identify files tracked by Git before callers use their filesystem fallback. The helper invokes Git synchronously, so a bounded failure path prevents one stalled subprocess from blocking the suite.
