Full review comments:

- **[P1] Derive the continuation session from trusted context:** `extensions/gateway-restart/index.ts:36-39`
  - body: sessionKey comes from tool arguments and is later used to enqueue an owner-trusted follow-up turn. The current gateway restart path intentionally prefers the trusted runtime session identity so model-supplied params cannot queue work into another session; this plugin needs the same boundary.
  - confidence: 0.92
- **[P1] Use the canonical gateway restart path:** `extensions/gateway-restart/index.ts:160-164`
  - body: Writing a plugin-owned JSON marker and calling process.exit(0) bypasses commands.restart, SIGUSR1 restart scheduling, the SQLite restart sentinel, and durable session-delivery continuation. This creates a second restart contract that can drift from current upgrade and session-ownership behavior.
  - confidence: 0.9
- **[P1] Preserve the full follow-up run context:** `src/auto-reply/reply/queue/build-followup-run.ts:107-119`
  - body: The builder reconstructs only a partial FollowupRun, but the runner consumes account, group, cwd, skills, channel, source-reply, and policy fields from that shape. Cold plugin follow-ups can therefore resume with the wrong workspace, account, tool policy, or delivery context.
  - confidence: 0.88
- **[P2] Keep Multipass concurrency forwarding:** `extensions/qa-lab/src/multipass.runtime.ts:367-368`
  - body: The CLI still accepts and passes --concurrency to runQaMultipass, but this diff removes the parameter and no longer adds --concurrency to the guest qa suite command. Existing Multipass QA runs that request bounded concurrency would silently fall back to the default.
  - confidence: 0.86
- **[P2] Declare the plugin runtime dependency:** `extensions/gateway-restart/package.json:1-15`
  - body: index.ts imports @sinclair/typebox, but the new gateway-restart package declares no dependency. If this plugin is installed or resolved as its own package, loading the tool can depend on root hoisting instead of the plugin's package contract.
  - confidence: 0.78
