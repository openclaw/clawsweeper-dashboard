## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Derive the restart session from trusted context:** `extensions/gateway-restart/index.ts:36-39`
  - body: `sessionKey` is model-supplied tool input, but the marker later uses it to enqueue an owner-trusted follow-up turn. This needs to come from trusted current session/tool context, or one session can target another session's continuation.
  - confidence: 0.93
- **[P1] Use the canonical gateway restart path:** `extensions/gateway-restart/index.ts:160-164`
  - body: This writes a plugin-owned marker and exits the process directly, bypassing `commands.restart`, the SIGUSR1 restart scheduler, the SQLite restart sentinel, and durable session-delivery continuation. That creates a second restart contract that can ignore operator policy and lose the callback after a second crash.
  - confidence: 0.91
- **[P1] Preserve the full follow-up run context:** `src/auto-reply/reply/queue/build-followup-run.ts:107-119`
  - body: The cold-run builder only restores a subset of `FollowupRun.run` and hardcodes `blockReplyBreak`, while current runs carry account, group, cwd, skills, elevation, and delivery-policy fields. Cold plugin follow-ups can therefore run in the wrong workspace or with the wrong policy/session context.
  - confidence: 0.88
- **[P2] Declare the runtime schema dependency:** `extensions/gateway-restart/index.ts:4-5`
  - body: The new plugin imports `@sinclair/typebox`, but its package manifest declares no dependency. External or package-isolated plugin loading can fail before registration unless the owning plugin package declares the runtime dependency or reuses the repo-supported schema package.
  - confidence: 0.9
- **[P2] Keep Multipass concurrency forwarding:** `extensions/qa-lab/src/multipass.runtime.ts:367-368`
  - body: The PR removes `concurrency` from the Multipass plan and no longer passes `--concurrency` to the guest QA command, while the CLI still parses and forwards that option. Users selecting a Multipass concurrency will silently get the default worker count instead.
  - confidence: 0.86
