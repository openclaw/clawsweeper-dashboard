  - body: The tool stores `parsed.sessionKey` in the restart marker, then the watcher enqueues an owner-trusted follow-up to that key.   - confidence: 0.92
- **[P1] Use the host-owned restart and sentinel path:** `extensions/gateway-restart/index.ts:160-164`
  - body: Writing a plugin-local JSON marker and calling `process.exit(0)` bypasses `commands.restart`, authorized SIGUSR1 scheduling, deferral/coalescing, the SQLite restart sentinel, and durable restart continuation delivery. This creates a second restart authority with weaker policy and durability than current main.
  - confidence: 0.9
- **[P1] Rehydrate the full queued run context:** `src/auto-reply/reply/queue/build-followup-run.ts:107-119`
  - body: The cold-session builder only fills a subset of `FollowupRun.run` and hardcodes `blockReplyBreak`; `followup-runner` uses omitted fields such as `agentAccountId`, group context, `cwd`, `skillsSnapshot`, `sourceReplyDeliveryMode`, and `bashElevated` for routing, policy, and execution.
