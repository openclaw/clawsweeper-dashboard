## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.79

Full review comments:

- **[P1] Gate gateway_restart to trusted restart policy:** `extensions/gateway-restart/index.ts:89-95`
  - body: Once this plugin is enabled, the agent-callable tool can run configured host commands and terminate the whole gateway, but it does not check the existing commands.restart policy or use the built-in gateway tool's trusted runtime session identity. Current main's gateway tool gates restarts and ignores model-supplied sessionKey, so this bypasses the established restart security boundary.
  - confidence: 0.86
- **[P1] Reconstruct the full session run context:** `src/auto-reply/reply/queue/build-followup-run.ts:107-119`
  - body: The cold follow-up builder only restores part of FollowupRun.run, leaving out persisted context current queue/runner paths use for account, group, cwd/workspace, elevated shell, and reply chunking behavior. That can resume a session under the wrong account/group policy or with different execution and message-delivery semantics.
  - confidence: 0.78
- **[P2] Reuse persisted workspace and normalized session file:** `src/auto-reply/reply/queue/build-followup-run.ts:57-85`
  - body: The builder falls back to the default agent workspace and trusts a stored sessionFile string directly when present. Spawned sessions persist their original workspace/cwd, and current resolveSessionFilePath tests protect unsafe or outside transcript paths, so cold follow-ups can run in the wrong repo or bypass transcript containment fallback.
  - confidence: 0.8
- **[P2] Keep the restart marker until continuation is durable:** `extensions/gateway-restart/index.ts:215-223`
  - body: enqueueFollowupTurn only proves an in-memory enqueue, but the watcher deletes the marker immediately after that result. A second crash or restart before the queued turn drains loses the callback, while current main's restart sentinel keeps restart continuation in SQLite and drains it through the startup path.
  - confidence: 0.74
