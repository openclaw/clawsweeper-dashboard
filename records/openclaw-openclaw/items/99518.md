## Summary

Keep open: current main still has no OpenClaw lifecycle-specific approval guard before durable allowlist or auto-review paths, and the linked fix PR is open but unmerged. The useful cleanup action is to review that PR’s security taxonomy and land or reject it, not close this issue yet.

## What This Changes

Request explicit approval for OpenClaw gateway/daemon lifecycle mutation commands in non-yolo exec modes before generic allowlist or auto-review, while keeping read-only status commands non-blocking.

## Best Possible Solution

Review and land or reject the linked PR after maintainer/security acceptance of the mutating-versus-read-only lifecycle taxonomy, keeping the classifier internal and ordered before durable allowlist or auto-review.

## Reproduction Assessment

Yes. Source inspection on current main shows the gateway-host, node-host, and direct system.run paths can reach durable approval or auto-review without an OpenClaw lifecycle hard guard.

## Solution Assessment

Yes, directionally. A shared internal lifecycle classifier ordered before durable allowlist and auto-review is the right fix shape, but maintainers still need to accept the exact lifecycle taxonomy in the linked PR.
