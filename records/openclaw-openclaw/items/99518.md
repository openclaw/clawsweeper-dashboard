## Summary

Keep open. Current main and the latest release still lack an OpenClaw lifecycle mutation guard before durable allowlist or auto-review decisions, and the linked fixing pull request is open with security/proof review still pending.

## What This Changes

Require explicit approval for OpenClaw gateway/daemon lifecycle mutations in non-yolo exec modes before durable allowlist or auto-review can allow them.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99530, or replace it with an equivalent shared lifecycle classifier that runs before durable allowlist or auto-review decisions and records classifier evidence.
