## What This Changes

The issue reports that OpenClaw gateway and daemon lifecycle commands can pass through generic exec allowlist or auto-review handling instead of requiring explicit approval in non-yolo modes.

## Best Possible Solution

Land the linked fix after maintainer/security acceptance, with a shared internal lifecycle classifier that gates before durable allowlist or auto-review while keeping read-only lifecycle inspection non-blocking.

## Reproduction Assessment

Yes. Source inspection of current main shows gateway, node-host, and direct system.run approval paths do not classify OpenClaw lifecycle mutations before durable allowlist or auto-review can participate.

## Solution Assessment

Yes, with maintainer/security acceptance still required. The best fix is a shared classifier at the exec approval boundary, not a new config option or a per-command workaround.
