## Summary

Keep open. Current main and the latest release still route gateway and node exec approval through generic allowlist, durable approval, and auto-review checks without a protected OpenClaw lifecycle mutation guard.

## What This Changes

The issue reports that OpenClaw gateway/daemon lifecycle mutation commands can pass through generic exec allowlist or auto-review handling instead of requiring explicit approval outside yolo mode.

## Best Possible Solution

Add a narrow shared lifecycle-mutation classifier used by both gateway and node exec approval paths before durable allowlist or auto-review can allow the command.

## Reproduction Assessment

Yes. Source inspection on current main shows no lifecycle mutation guard before generic durable approval or auto-review decisions in the gateway and node exec approval paths.

## Solution Assessment

Yes for the fix shape: a shared classifier in the approval policy path is the narrowest maintainable solution. Maintainers still need to approve the exact lifecycle command taxonomy and read-only exclusions.
