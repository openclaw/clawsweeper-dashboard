## What This Changes

The issue reports that OpenClaw gateway/daemon lifecycle mutation commands can pass through generic exec allowlist or auto-review approval paths instead of requiring explicit approval outside yolo mode.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99530 if maintainers accept the lifecycle mutation taxonomy, keeping the shared classifier internal and gating lifecycle mutations before durable allowlist or auto-review paths.

## Reproduction Assessment

Yes, source-level: current main shows the gateway, node-host, and direct system.run approval paths can reach durable approval or auto-review without a lifecycle mutation guard. I did not run a live lifecycle command in this read-only review.

## Solution Assessment

Yes in direction, but not complete until the linked PR lands: a shared classifier before allowlist and auto-review is the maintainable boundary. The remaining decision is maintainer/security acceptance of the mutating-versus-read-only lifecycle taxonomy.
