## Summary

Keep open: current main still has a source-backed MiMo v2.5/v2.5-pro gap. OpenClaw handles native reasoning lanes and legacy MiMo reasoning-only final text, but the current wrappers do not remove visible text duplicated from a simultaneous thinking block, which matches the reported repetition and reasoning exposure.

## What This Changes

The issue asks OpenClaw to stop MiMo v2.5 and MiMo v2.5-pro from leaking duplicated native thinking content into visible replies when using OpenAI-compatible completions with reasoning enabled.

## Best Possible Solution

Add a provider/stream-boundary sanitizer for MiMo v2.5 and MiMo v2.5-pro that removes visible text duplicated from native reasoning while preserving genuine final-answer text, with focused unit coverage and live MiMo proof; keep Feishu channel sanitization tracked separately in https://github.com/openclaw/openclaw/issues/88233.
