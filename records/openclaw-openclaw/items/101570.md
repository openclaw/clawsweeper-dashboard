## Summary

Keep open. Current main and latest v2026.6.11 still have the reported gap: MiMo v2.5/v2.5-pro are handled as reasoning-capable models, but the existing response-side cleanup only promotes thinking-only output and deliberately skips mixed thinking plus text, so mirrored reasoning can still reach visible replies.

## What This Changes

The issue requests fixing MiMo v2.5/v2.5-pro OpenAI-compatible replies that mirror thinking into visible text, causing repetition, hidden reasoning exposure, and occasional no-reply truncation.

## Best Possible Solution

Add Xiaomi/MiMo-owned or shared OpenAI-compatible stream normalization that removes only mirrored or prefix reasoning from v2.5/v2.5-pro visible text while preserving real answer text and tool calls, with regression coverage and redacted live proof when credentials are available.
