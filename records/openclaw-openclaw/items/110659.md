## Label Justifications

- `P1`: This fix addresses a real current-main configuration round-trip that can silently associate a retained entry with another entry’s stored value.
- `merge-risk: 🚨 compatibility`: The generic restore contract changes how existing id-keyed config arrays preserve redacted values across Control UI saves.

## Summary

The updated PR supplies credible live Control UI evidence and a focused fix for delete/reorder corruption, but it still intentionally permits reuse of a deleted row’s `id` to restore that row’s redacted value into a different retained row. That compatibility contract needs maintainer direction before merge.

## What This Changes

The branch replaces positional restoration of redacted values in object arrays with matching by visible unique `id`, adds fail-closed cases, and adds focused config regression coverage.

## Best Possible Solution

Preserve identity-based matching for unedited ids, but fail closed whenever an ambiguous id reuse could bind a placeholder to a different edited row unless maintainers explicitly define and document a supported rename/state-transfer contract for that array surface.
