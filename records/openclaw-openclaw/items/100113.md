Keep open: current main still routes model-call usage span attributes through a positive-only normalizer, so explicit zero output usage is omitted; the issue also has maintainer/protected handling signals.

## What This Changes

The issue asks for diagnostics OTEL model-call spans to preserve explicit zero token usage and expose a queryable context-utilization signal for near-limit zero-output completions.

## Best Possible Solution

Preserve finite non-negative usage values on model-call spans, including zero, and add a maintainer-approved bounded context-utilization attribute with focused diagnostics OTEL coverage.
