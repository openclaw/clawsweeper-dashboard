Keep this issue open: current main still appears to terminate only the direct host-hook child on timeout, while the repository already has shared cross-platform process-tree termination behavior that this executor does not use. No merged fix or canonical replacement owns this specific runtime path.

## What This Changes

## Best Possible Solution

Route host-hook timeout and abort cleanup through the existing cross-platform process-tree termination primitive, preserve one canonical cleanup path, and add Unix and Windows regression coverage proving descendants are reaped without changing hook configuration or lifecycle semantics.
