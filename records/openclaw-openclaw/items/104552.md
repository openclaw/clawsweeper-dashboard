## Summary

The fix remains necessary and correctly preserves structured 413 responses for finite oversized bodies, but the streamed-overflow path now discards the remainder without a byte or time bound, so one focused availability fix is needed before merge.

## What This Changes

The PR pre-rejects declared bodies over 1 MiB and changes streamed Admin HTTP RPC overflow handling to preserve structured HTTP 413 responses, with real Node HTTP regression coverage.

## Best Possible Solution

Keep the route-local structured 413 handling, but mark streamed overflow connections for closure and terminate the request socket after the response flushes, with a real HTTP regression where the client crosses the limit without ending the upload.
