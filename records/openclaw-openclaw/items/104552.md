## Summary

## What This Changes

The PR rejects oversized declared Admin HTTP RPC bodies before reading them and closes streamed-overflow requests after returning a structured HTTP 413 response.

## Best Possible Solution

Land the early declared-length guard and finish-ordered streamed-overflow shutdown with both real-socket regressions intact once the branch is current and the required test-type gate passes.

## Maintainer Decision

## Reproduction Assessment

Yes at source level: a client can keep streaming beyond the documented 1 MiB limit, and current main's default async iterator destroys the request on early exit. The PR's real-socket regression demonstrates the corrected 413-and-close behavior, though this review did not independently rerun current main.

## Solution Assessment

Yes. An early strict Content-Length check plus explicit finish-ordered shutdown for undeclared streamed overflow is the narrowest maintainable fix and follows Node's documented iterator lifecycle instead of adding a parallel body reader or new configuration.
