## What This Changes

The issue reports that Telegram polling receives a group/supergroup message from the Bot API but OpenClaw never logs or dispatches it to the agent while DMs still work.

## Best Possible Solution

Keep the secure sender-authorization default, make Telegram group admission self-explanatory in setup/doctor/gateway status, and only repair polling/spool/context dispatch if a live authorized group mention still drops.
