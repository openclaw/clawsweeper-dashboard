## What This Changes

This PR adds staged Context Profile controls in the Control UI that update three existing `agents.defaults` settings through `config.patch`, avoiding full-form submission of redacted SecretRef fields.

## System Context

Control UI settings read a gateway configuration snapshot, maintain editable Form or Raw JSON state, and submit configuration writes through gateway RPCs. The new profile path applies a small agent-default patch, refreshes the snapshot, and reconciles it with any editable settings state.
