The implementation has no supported blocking correctness finding, but the latest head is behind `main` and its required lint/type/i18n gates are currently failing, so it is not ready to merge. ## What This Changes

Changes Control UI Context Profile presets to patch three `agents.defaults` fields through `config.patch`, reconcile staged form state after the write, add inline preset status, and add focused tests and English localization.

## Best Possible Solution

Keep the preset write narrowly on `config.patch`, preserve unrelated staged edits while rebasing them onto the post-patch snapshot, and merge only after refreshing onto current `main` with the focused reconciliation tests and required UI/type/lint gates passing.
