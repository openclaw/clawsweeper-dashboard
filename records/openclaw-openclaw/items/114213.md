## What This Changes

This PR changes web-chat transcript memoization so usage-only run patches refresh the live output-token counter in standalone and assistant-embedded working-status rows, and adds a regression test for both presentations.

## System Context

The web chat view receives run usage independently from transcript items, then memoizes each rendered transcript row to avoid rerendering the whole conversation. Working-status rows display that live usage, so their per-row render signature must include the usage value while unrelated rows retain their existing cache behavior.
