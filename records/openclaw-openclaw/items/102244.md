## Label Justifications

## Summary

Keep this open: current main and the latest stable release still have the transcript-redaction gate that can reject preservation for credential-looking opaque provider signatures, and Bedrock still replays any nonblank stored thinking signature without an ellipsis/corruption guard.

## What This Changes

The issue reports transcript redaction corrupting Bedrock/Anthropic reasoning signatures when opaque base64 signatures match secret-pattern heuristics.

## Best Possible Solution

Preserve structurally valid provider-minted signatures only in scoped signed-thinking fields, keep ordinary credential redaction elsewhere, and add Bedrock/Anthropic guard or repair coverage for already-corrupted signatures.
