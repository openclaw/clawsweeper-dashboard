- `impact:session-state`: The corrupted signature is written into the on-disk session transcript and replayed on later turns.

## Summary

Keep this open: current main and v2026.6.11 still have the redaction-idempotency gate that can reject preservation for credential-looking opaque reasoning signatures, and Bedrock still forwards any nonblank signed thinking value without an ellipsis/corruption guard.

## What This Changes

The issue reports that transcript secret redaction can rewrite provider reasoning signatures containing vendor-key-like substrings, poisoning persisted Anthropic/Bedrock replay.

## Best Possible Solution

Preserve structurally valid provider-minted opaque signatures only in scoped signed-thinking transcript fields, keep ordinary credential redaction intact elsewhere, and add Bedrock/Anthropic whole-block drop or repair coverage for already-poisoned signatures.

Rationale: The current tests deliberately redact credential-shaped values in provider signature fields, but the issue shows that this policy can corrupt real opaque replay tokens; maintainer intent is needed for the redaction/security boundary.

Options:

- **Scoped Structural Preservation (recommended):** Preserve valid opaque signatures only in known provider signed-thinking fields while leaving arbitrary text, missing-route fields, and malformed payloads redacted.
- **Pattern-Only Hardening:** Make fixed-case vendor prefixes and boundaries stricter but keep the current redaction-idempotency requirement for provider signatures.
- **Send-Side Recovery Only:** Drop visibly corrupted Bedrock/Anthropic thinking blocks on send and rely on recovery without changing transcript-redaction preservation.

## Reproduction Assessment

Yes, source-level reproduction is high confidence: current main still rejects opaque replay-token preservation when `redactSensitiveText` would change the value, then persists the redacted message. I did not run a fresh live Bedrock request in this read-only pass.

## Solution Assessment

Unclear until the security boundary is chosen; the narrow maintainable direction appears to be scoped structural preservation plus Bedrock whole-block replay hardening, while pattern-only hardening would not cover every opaque-token false positive.
