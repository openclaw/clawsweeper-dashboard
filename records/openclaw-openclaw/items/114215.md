## What This Changes

The PR makes managed npm plugin-install failures report captured output or, when npm is silent, its exit code, signal, or termination reason, and adds coverage for the empty-output exit-code case.

## System Context

Managed plugin installation invokes npm in a generated plugin project and turns the child-process result into CLI-visible installation errors. This change affects the diagnostic text users receive when that npm subprocess fails without stdout or stderr.
