## Label Justifications

- `P1`: The report describes active subagent runs being terminated by the idle watchdog during real tool-heavy workflows.
- `impact:session-state`: The affected behavior can terminate an in-progress subagent session and lose the state needed to produce the final result.

## Summary

This issue should stay open: current main and the latest release still re-arm the LLM idle watchdog only from LLM/provider activity, while the proof-positive candidate fix at https://github.com/openclaw/openclaw/pull/95536 is open and currently conflicting rather than merged.

## What This Changes

The issue asks OpenClaw to keep subagent runs alive when tool calls are actively making progress instead of letting the LLM idle watchdog terminate them.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/95536 or an equivalent runId-scoped heartbeat covering shared visible and deferred tool execution, then close this issue from the merged fix with real subagent proof.
