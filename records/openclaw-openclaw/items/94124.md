## Label Justifications

- `P1`: The issue describes active subagent runs being killed during long-running tool work, which breaks a real agent workflow.
- `impact:session-state`: The failure can terminate an in-progress subagent session before it returns its collected work or final report.

## Summary

Keep this issue open: current main still has the LLM idle watchdog wired only to model/request activity, and the formal fix path is an open, unmerged PR rather than shipped or merged behavior.

## What This Changes

The issue asks OpenClaw to keep run-mode subagents alive by refreshing the LLM idle watchdog when tool activity proves the run is still making progress, without adding a new config option.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/95536 or an equivalent runId-scoped heartbeat fix, then close this issue once current main contains the merged implementation and regression proof.
