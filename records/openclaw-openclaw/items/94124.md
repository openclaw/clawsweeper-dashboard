## Summary

Keep this issue open: current main and the latest release still have the LLM idle watchdog wired only to stream/LLM activity, and the closing implementation candidate at https://github.com/openclaw/openclaw/pull/95536 is still open rather than merged.

## What This Changes

The issue requests resetting the subagent session idle watchdog from tool activity so long-running tool calls do not terminate active subagent runs.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/95536 or an equivalent runId-scoped tool-activity heartbeat with focused tests and real subagent proof, then close this issue from the merged fix.
