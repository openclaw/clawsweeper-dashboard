## Summary

This issue should stay open: current main and the latest release still wire the embedded-runner LLM idle watchdog to LLM request activity only, and the proof-positive fix candidate is open rather than merged.

## What This Changes

The issue asks OpenClaw to reset subagent LLM idle timeout from tool activity so long-running tool calls do not terminate active subagent sessions prematurely.

## Best Possible Solution

Refresh and land https://github.com/openclaw/openclaw/pull/95536 or an equivalent runId-scoped heartbeat covering shared visible and deferred tool execution, then close this issue from the merged fix with real subagent proof.
