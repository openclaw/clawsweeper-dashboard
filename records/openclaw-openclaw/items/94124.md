## Summary

Keep this open: current main and v2026.6.11 still wire the LLM idle watchdog to LLM/provider activity only, while the proof-positive candidate fix at https://github.com/openclaw/openclaw/pull/95536 is open and conflicting rather than merged.

## What This Changes

Request a tool-activity heartbeat so active `sessions_spawn` subagents are not terminated by the LLM idle watchdog during long-running tool calls.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/95536 or an equivalent runId-scoped heartbeat across shared visible and deferred tool execution, then close this issue from the merged fix with real subagent proof.
