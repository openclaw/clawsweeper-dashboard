## What This Changes

The PR changes WhatsApp voice-note handling so successful speech-to-text is framed as machine-generated, untrusted agent input while the raw transcript remains available as a separate context fact.

## System Context

WhatsApp inbound messages pass through an audio-transcription preflight before OpenClaw builds the agent-facing inbound context. This change alters only the text the agent receives for a successfully transcribed voice note, while preserving the audio and transcript facts used by later command, media, and reply handling.
