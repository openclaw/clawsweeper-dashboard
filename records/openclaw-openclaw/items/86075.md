## Summary

Keep open. Current main still preserves the AGENTS.md/TOOLS.md-only sub-agent boundary and the MiniMax image provider still deliberately avoids `api.minimax.chat`, while the later generated-media fix only covers a narrower cron-yield path; the Token Plan-specific provider behavior still needs live proof and a maintainer product decision.

## What This Changes

The issue reports that MiniMax Token Plan generated-media and office-generation workflows no longer work from sub-agents because sub-agent bootstrap no longer loads Token Plan skill files and the built-in image tool appears to use the wrong MiniMax endpoint for Token Plan keys.

## Best Possible Solution

Split the work: live-verify MiniMax Token Plan image/provider behavior, fix any confirmed provider or media-completion bug narrowly, and keep Token Plan office skills as a plugin/skill/ClawHub package unless maintainers approve a new sub-agent bootstrap contract.
