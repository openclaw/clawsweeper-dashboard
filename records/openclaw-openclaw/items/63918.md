## Summary

The issue reports cron `agentTurn` jobs against `openai/gpt-5-nano` failing because OpenClaw sent an unsupported `thinking=none`/reasoning effort despite `payload.thinking: "minimal"`.

## Best Possible Solution

Keep the shipped OpenAI reasoning compatibility path and close this report as resolved by v2026.4.9 and current main.
