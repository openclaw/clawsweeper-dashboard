## Summary

Keep this PR open for maintainer review: the session-scoped target is well supported, but opting the Control UI into discarding queued follow-up and lane work changes the durable meaning of `/stop`; its current-head real-behavior proof also predates the final three commits.

## What This Changes

The branch routes Control UI stop actions without a browser-local run ID through `sessions.abort` for the selected non-global session and adds opt-in `clearQueued` cleanup for that session’s queued work.

## Best Possible Solution

Decide whether selected-session `/stop` should cancel only active work or also discard queued user work; preserve the explicit opt-in protocol contract, then capture a redacted current-head scenario showing selected-session isolation, queued-work handling, and reconnect behavior.
