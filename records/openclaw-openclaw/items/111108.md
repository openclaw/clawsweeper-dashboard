## What This Changes

The branch makes Control UI use `sessions.abort` for a selected session without a browser-local run ID and makes non-global key-only aborts clear queued successors and abort persisted embedded/reply work.

## Best Possible Solution

Keep existing key-only `sessions.abort` behavior compatible and introduce an explicitly named, owner-approved full-session-stop contract for Control UI if queued-work cancellation is the intended product behavior, with exact-head proof for selected-session isolation and queued-work suppression.
