## Summary

The PR has credible real-behavior proof and no discrete source-level defect established in this review, but it introduces a shared Gateway queue-discarding contract that needs an explicit Gateway/session-owner decision before merge.

## What This Changes

The branch makes Control UI stop selected channel-backed sessions through `sessions.abort`, adds opt-in `clearQueued` cleanup for non-global key-only aborts, and updates active-run lifecycle projections and tests.

## Best Possible Solution

Have a Gateway/session owner explicitly approve the opt-in `clearQueued` contract, including authorization and intended user-message semantics; then retain this bounded UI-to-Gateway path with its focused protocol, queue, and lifecycle coverage.
