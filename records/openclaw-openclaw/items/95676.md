## What This Changes

The branch gives an ordinary assistant-stage timeout one bounded retry on the same model and auth profile before the existing rotation or fallback flow, and removes content-free aborted assistant leaves before replay repair.

## System Context

The embedded agent runner translates provider outcomes into retries, auth-profile rotation, or model fallback while preserving the conversation transcript between attempts. This PR changes the timeout decision before profile rotation and cleans the transcript state used by a replayed user prompt.
