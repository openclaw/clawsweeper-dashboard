## What This Changes

## System Context

The embedded agent runner turns provider outcomes into retry, auth-profile rotation, or model-fallback decisions. This PR changes the assistant-timeout branch and the session-boundary repair that prepares the transcript for a retry, affecting provider selection and the next model prompt.
