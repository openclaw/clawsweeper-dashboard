## What This Changes

This PR makes the lifecycle-prepared model catalog the shared source for CLI, Gateway, and picker model views, while migrating generated plugin catalogs from agent sidecar files into the existing per-agent SQLite cache with Doctor-owned recovery.

## System Context

Provider discovery and authentication information feed a prepared model catalog that is projected into CLI commands, Gateway `models.list` responses, and model selection. The PR changes where generated provider-catalog payloads persist and removes parallel list-planning paths so those projections use the same prepared generation.
