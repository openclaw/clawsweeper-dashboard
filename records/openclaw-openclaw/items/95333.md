## Summary

Keep open. ## What This Changes

Adds marker-gated trusted bare-body metadata for decorated inbound user turns and updates transcript persistence, UI, CLI dedupe, memory export, historical replay consumers, and tests to prefer it over sentinel stripping.

## Best Possible Solution

Land one maintainer-approved additive trusted inbound-decoration contract with legacy fallback and redaction coverage, and make any SDK-visible helper an intentional documented surface.

## Reproduction Assessment

Yes. Current main still decorates inbound content with literal sentinel headers and multiple user-role consumers strip or compare by those same strings, so the source-level failure path is clear even without rerunning a live channel repro.

## Solution Assessment

Unclear as a final merge decision. The out-of-band marker plus bare body is the right class of fix and the current patch addresses prior redaction/type blockers, but maintainers still need to accept the durable field shape and SDK exposure.
