## What This Changes

The PR adds top-level `inboundDecorated` and `bareBody` metadata for decorated user turns and updates transcript persistence, UI extraction/normalization, CLI import dedupe, memory-host export, and historical LLM replay to prefer that trusted body.

## Best Possible Solution

Land one maintainer-approved marker-gated bare-body contract, keep legacy fallback for unmarked rows, and preserve the redaction-hook boundary this PR now covers.

## Reproduction Assessment

Yes, source-level. Current main decorates inbound content as literal sentinel text and first-party consumers strip or compare user text by those same headers, so a user-authored sentinel-shaped body can be treated like host metadata.

## Solution Assessment

Yes, subject to maintainer acceptance of the field shape. Moving the trust decision to an explicit marker plus host-known bare body is the right layer, and this PR covers the central consumers while preserving legacy fallback and redaction behavior.
