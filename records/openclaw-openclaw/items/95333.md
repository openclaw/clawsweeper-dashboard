## Summary

Keep this PR open, but it is not ready to merge: the proposed producer can mark a decorated transcript copy as trusted when no independently sourced bare body exists, which would make every updated reader preserve host metadata instead of removing it. The linked issue remains open and this PR is its candidate fix; no merged current-main implementation was established from the provided evidence.

## What This Changes

The branch adds marker-gated `bareBody` metadata for decorated inbound user turns and makes transcript, UI, replay, memory, imported-history dedupe, and usage-log readers prefer it over legacy sentinel stripping.

## Best Possible Solution

Persist and trust a bare body only when it originates from the host-owned undecorated inbound value, retain legacy stripping otherwise, and confirm the durable metadata carrier before landing the cross-reader contract.
