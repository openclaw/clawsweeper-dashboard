## Summary

Keep open: current main and the latest release still preserve zero cache pricing in the active BytePlus and Volcengine/Doubao plugin manifests, and the remaining linked PRs are closed or dirty/out-of-repo rather than viable fixes.

## What This Changes

The issue asks for non-zero Doubao/BytePlus cacheRead and cacheWrite pricing so cached-token usage is not reported as free.

## Best Possible Solution

Land a narrow provider-plugin manifest update for both extensions/byteplus and extensions/volcengine with vendor-backed USD-per-million cache pricing, explicit cacheWrite/storage mapping, and focused regression tests.

## Reproduction Assessment

Yes, at source level: current plugin manifests still set cacheRead/cacheWrite fields to 0, the manifest loader preserves those values, and the estimator multiplies cached-token buckets by them. I did not run a live provider billing session in this read-only review.

Yes on the owner boundary, but unclear on exact values. The maintainable fix belongs in the current plugin manifests and tests, while the old src/agents path should not be revived and vendor pricing/mapping needs maintainer-confirmed proof.
