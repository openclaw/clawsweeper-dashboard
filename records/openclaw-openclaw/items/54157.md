The issue asks for Doubao/BytePlus cached-token pricing to be filled in so cost tracking does not treat context cache reads and writes as free.

## Best Possible Solution

Land a narrow provider-plugin manifest update for both extensions/byteplus and extensions/volcengine using vendor-backed USD-per-million cacheRead/cacheWrite values, with focused catalog and usage-cost regression coverage.
