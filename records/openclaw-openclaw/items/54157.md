## Summary

Keep open: current main and the latest release still preserve zero cached-token prices in the active BytePlus and Volcengine/Doubao plugin manifests. The same-repository fix attempts are closed unmerged, and the remaining open fork PR is conflicting and edits deleted core catalog files rather than the current plugin manifest path.

## What This Changes

The issue asks for non-zero context-cache pricing in the Doubao/BytePlus model catalog so usage-cost reporting does not undercount cached tokens.

## Best Possible Solution

Land a narrow provider-plugin manifest update for both extensions/byteplus and extensions/volcengine with vendor-backed USD-per-million cache pricing, focused regression tests, and a decision on cache storage/write mapping.

## Reproduction Assessment

Yes, at source level. Current main still contains zero cache prices in active BytePlus and Volcengine/Doubao manifests, and the runtime cost estimator directly multiplies cached-token usage by those fields.

## Solution Assessment

Yes on the owner boundary, but not yet on the exact values. The maintainable fix belongs in the current plugin manifests and tests, while vendor pricing and cacheWrite/storage mapping need maintainer-confirmed proof.
