## Summary

The socket-leak diagnosis and transport-timeout change are sound, but the patch removes the probe’s total-duration bound without disabling Slack’s separate automatic 429 retry path, so a rate-limited `auth.test` can outlive `timeoutMs`; keep this PR open for the narrow retry correction.

## What This Changes

This PR changes `probeSlack` to configure the Slack WebClient with a per-request timeout and zero ordinary retries, removes the outer promise timeout, and updates the probe unit tests.

## Best Possible Solution

Keep the transport-level timeout, also set `rejectRateLimitedCalls: true`, and add focused coverage proving both hanging requests and 429 responses complete within the probe budget without background retries.
