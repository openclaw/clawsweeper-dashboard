## Summary

Keep open: the reported macOS embedded dashboard flow is still broken on current main and in v2026.6.11 because the Control UI delete path depends on JavaScript confirm while DashboardWindowController does not implement the WKWebView JavaScript confirm delegate.

## What This Changes

The issue requests restoring session deletion from the macOS app's embedded dashboard Web UI so selecting sessions and clicking delete shows confirmation and deletes after approval.

## Best Possible Solution

Implement native WKUIDelegate JavaScript confirm handling for the macOS DashboardWindowController and prove selected-session deletion in the embedded dashboard after confirmation.

## Reproduction Assessment

Yes at source level: the delete path calls window.confirm, and the macOS embedded WKWebView lacks the JavaScript confirm delegate that WebKit needs to return true. I did not run a live packaged macOS app reproduction in this read-only review.

## Solution Assessment

Yes: handling JavaScript confirm in DashboardWindowController is the narrow owner-boundary fix because it restores the existing Control UI confirmation contract without changing session deletion semantics or gateway APIs.
