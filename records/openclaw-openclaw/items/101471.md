## Summary

Keep open: the intended ownsCompaction bypass is aligned with the successful context-engine assembly contract, but this patch disables the aggregate tool-loop guard even when the engine hook falls through after an engine failure, and the PR still lacks inspectable after-fix real behavior proof.

## What This Changes

The PR adds an ownsCompaction flag to the embedded tool-result context guard and passes it from the ownsCompaction context-engine path so the aggregate char-based overflow check is skipped for those sessions.

## Best Possible Solution

Preserve the false-positive fix for successful owning context-engine assembly, but keep overflow recovery active when the loop hook fails and require redacted after-fix runtime proof before merge.

The patch-introduced failure case is also source-reproducible from the existing fall-through tests and the prior assembly-succeeded precheck fix.

## Solution Assessment

No. The right shape is narrower: skip the aggregate heuristic only when the owning engine actually controlled the provider view, while preserving the fallback guard when afterTurn or assemble fails.
