## Summary

Keep this PR open, but it still needs changes before merge: the intended ownsCompaction false-positive fix is valid, yet the static skip also disables the aggregate guard after context-engine fallback or runtime quarantine routes the transform through raw legacy messages.

## What This Changes

The PR adds an `ownsCompaction` option to the embedded agent tool-result context guard and passes it from the context-engine-owned compaction path so the rough aggregate overflow heuristic is skipped.

## Best Possible Solution

Skip the rough aggregate heuristic only for a successfully engine-assembled current view; keep the aggregate guard active when the context-engine loop falls back, is quarantined, or returns raw legacy/provider messages.
