## Summary

Keep this PR open, but the prior blocker remains: the intended false-positive fix is valid, yet the branch still skips the aggregate overflow guard for every `ownsCompaction` install, including context-engine fallback to raw provider messages.

## What This Changes

The PR adds an `ownsCompaction` flag to the embedded tool-result context guard, passes it from the context-engine attempt path, and tests skipping the aggregate overflow throw under pressure.

## Best Possible Solution

Skip the rough aggregate heuristic only when the context engine successfully produced the current assembled view; keep the aggregate guard active on engine-loop fallback unless maintainers explicitly accept provider-overflow fallback.
