## Summary

Keep open: the false-positive overflow fix is still useful, but the patch still skips the fallback aggregate overflow guard for ownsCompaction tool loops even when the context engine hook has fallen back after an engine failure.

## What This Changes

The branch passes an ownsCompaction flag into the tool-result context guard, skips its aggregate char-based overflow throw when that flag is true, and adds focused unit coverage for that skip.

## Best Possible Solution

Skip the char-based aggregate overflow heuristic only for an ownsCompaction loop iteration that successfully produced an engine-owned assembled view; keep the existing guard or structured recovery path active on engine fallback.
