## Summary

Keep this PR open. Current main still aborts before stopped-state inspection when `launchctl bootout` throws, while this protected maintainer-routed patch correctly handles that narrow failure and is not yet implemented on main.

## What This Changes

## Best Possible Solution

Use one canonical stop-and-proof path that preserves the native-launchd-only exception, supports bounded teardown convergence if adopted, and covers immediate success, delayed success, and unproven failure with suspension recovery.
