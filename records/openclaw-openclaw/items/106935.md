## Summary

This PR addresses a real session-replay failure, but the unchanged prior blocker remains: it performs unconditional transcript repair inside the generic session manager instead of the provider-aware replay pipeline, so provider-specific policy and synthetic-result formatting can be bypassed. Unit coverage is useful but does not prove that an interrupted Anthropic session resumes successfully.

## What This Changes

The branch adds tool-use/result pairing repair to both session-context builders and adds regression tests for single, multiple, and already-paired tool calls.

## Best Possible Solution
