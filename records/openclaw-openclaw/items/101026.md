## Summary

Keep open: current main appears to have restored hook coverage for the durable `message` tool path, but the Feishu prebuilt auto-reply dispatcher still lacks `message_sending`, and expanding normal-channel `inbound_claim` remains a plugin API/security decision rather than an implemented fix.

## What This Changes

The issue requests uniform outbound plugin-hook coverage for Feishu auto-replies and `message` tool sends, plus normal-channel `inbound_claim` support for passive Feishu observer plugins.

## Best Possible Solution

Split the work: restore outbound hook parity for Feishu prebuilt auto-replies, and make a maintainer decision on whether passive inbound observation needs global `inbound_claim` or a narrower new hook.
