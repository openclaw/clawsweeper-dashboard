## Summary

Keep open: current main has fixed the durable `message` send path by routing it through shared outbound delivery hooks, but the Feishu prebuilt-dispatcher auto-reply path still appears to miss `message_sending`, and normal inbound handling still only runs `inbound_claim` for plugin-owned bindings.

## What This Changes

The issue reports inconsistent plugin hook coverage for Feishu auto-replies, Feishu `message` tool sends, and normal Feishu inbound handling.

## Best Possible Solution

Keep this issue as a focused Feishu/plugin-hook parity item: preserve the durable-send fix already on main, wire Feishu prebuilt dispatchers through the same outbound before-deliver hooks, and have maintainers decide whether normal inbound messages should become claimable or whether docs should narrow `inbound_claim` to plugin-owned bindings.
