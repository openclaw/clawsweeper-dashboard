## Summary

Keep open: the linked regression is valid, but this patch is not merge-ready because it weakens the generation-authority fence and provides only unit-level proof.

## What This Changes

The PR makes eligible stable-key Codex bindings adopt the incoming physical session ID during lease acquisition, updates binding tests, and documents the `sessionId`/`sessionKey` lifecycle.

## Best Possible Solution

Add an authority-checked compare-and-swap generation transfer inside the serialized lifecycle, preserving the thread binding only when the canonical session store identifies the incoming physical session as current, and cover predecessor reacquisition after successor completion.
