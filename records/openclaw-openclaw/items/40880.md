Keep open: current main and the latest release still retain the fixed 5 MiB media-store and sandbox-staging cap, while the linked open Telegram PR only covers a narrow outbound reply-media symptom.

## Best Possible Solution

Define one bounded, documented core media-store and sandbox-staging limit contract with secure defaults, an explicit hard maximum, schema/docs/help alignment, and regression coverage across store, gateway preflight, sandbox staging, and reply-media callers.
