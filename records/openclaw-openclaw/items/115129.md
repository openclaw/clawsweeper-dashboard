## What This Changes

This PR makes Control UI sidebar session switches render from the selected row immediately while avoiding repeated same-agent metadata, identity, avatar, and subscription work.

## System Context

The Control UI sidebar chooses a session and navigates the chat pane to that route. The route loader resolves the selected session, then the pane restores visible chat state, subscribes to live messages, and refreshes agent-scoped presentation data.
