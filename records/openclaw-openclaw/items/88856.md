## Summary

Keep open: current main still records, logs, suspends, or blocks failed subagent completion delivery without implementing the requested parent/model-visible terminal failure signal across orphaned tool_use, timeout/no-output, and announce give-up paths.

## What This Changes

The issue requests a first-class parent-visible signal when an Agent or sessions_spawn tool_use is orphaned, killed, or dropped without a matching tool_result.

## Best Possible Solution

Define and implement one durable parent-visible terminal failure contract that wakes yielded parents and closes tool_use/tool_result pairing across timeout, no-output, delivery give-up, restart, and active-run handoff cases.
