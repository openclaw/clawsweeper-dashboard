## Summary

Keep open: current main still has source-level paths where subagent timeout, no-output completion, and announce give-up state can be recorded or failed without a guaranteed parent/model-visible completion result, and related open work has not landed a broad durable contract.

## What This Changes

Requests a parent/model-visible failure signal when Agent or sessions_spawn emits a tool_use with no matching tool_result or delivered subagent completion event.

## Best Possible Solution

Define and implement one durable parent-visible subagent terminal contract that wakes yielded requesters and closes the tool_use/tool_result pairing across timeout, no-output, announce give-up, restart recovery, and active-run handoff failures.
