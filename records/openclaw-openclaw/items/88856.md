Keep open: current main has partial replay/transcript repair for orphaned tool calls, but it does not fully implement the requested parent-visible terminal failure contract for dropped, timed-out, or failed-handoff subagent work.

## What This Changes

## Best Possible Solution

Define one parent-visible terminal failure contract, then implement and test it across orphaned spawn calls, run timeouts, failed completion handoffs, restart recovery, and sessions_yield interactions.
