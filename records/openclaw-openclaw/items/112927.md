## What This Changes

This PR makes the LanceDB memory plugin’s automatic prompt-build recall use the same per-agent cooldown as the explicit memory recall tool when embedding requests time out or fail.

## System Context

The LanceDB memory plugin runs automatic recall while an agent prompt is being built, embedding the prompt and searching agent-scoped memories before context reaches the model. The explicit recall tool already has a per-agent outage cooldown; this change applies that guard to the hot prompt-build path as well.
