## Summary

Keep open: current main still calls the model-backed exec reviewer completion on each matching approval miss, and I found no duplicate issue or open fixing PR that owns the repeated-billing behavior.

## What This Changes

The issue requests memoizing byte-identical model-backed exec reviewer decisions so repeated approval-miss exec requests do not pay for a fresh reviewer completion every time.

## Best Possible Solution

Add a bounded, non-persistent exact-input memo at the shared reviewer boundary after maintainer approval, with tests proving identical requests reuse one completion while host, session, cwd, env, reason, and analysis differences do not share decisions.
