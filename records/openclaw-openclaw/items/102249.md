## Summary

Keep open: current main still performs a fresh model-backed exec reviewer completion for each approval-miss reviewer invocation, and exact GitHub searches did not find a duplicate issue or fixing PR that owns the repeated-billing problem.

## What This Changes

The issue requests reusing deterministic model-backed exec reviewer verdicts for byte-identical repeated exec requests within a run.

## Best Possible Solution

Add a bounded per-reviewer-instance verdict memo in the shared model-backed reviewer, keyed by the full security-relevant review input, with regression coverage proving node and gateway repeats reuse the completion without converting allow-once into durable approval.

Yes, source-reproducible: the current reviewer calls the model completion inside each returned reviewer invocation, and both exec hosts call that reviewer directly for approval misses. I did not run a live provider completion in this read-only cleanup review.

## Solution Assessment

Unclear without maintainer input: a shared per-instance memo in createModelExecAutoReviewer is the cleanest boundary, but the exact key, cache lifetime, and plugin-helper scope need security/product confirmation before automation changes approval semantics.
