Keep open: current main still runs a fresh model-backed exec reviewer completion for each identical approval miss, and no same-repository duplicate or fixing PR appears to own the repeated-billing problem.

## What This Changes

The issue requests per-run reuse of deterministic exec auto-reviewer verdicts for byte-identical exec approval requests.

## Best Possible Solution

Add a bounded, non-persistent exact-input memo in the shared reviewer after maintainer approval of the cache scope, with regression coverage proving repeated identical requests reuse one completion while preserving allow-once semantics.

Unclear until maintainers approve the cache boundary; the narrowest likely solution is a shared exact-input reviewer memo rather than per-host caches or durable approval reuse. The implementation should also decide whether plugin harness helper calls are in scope.
