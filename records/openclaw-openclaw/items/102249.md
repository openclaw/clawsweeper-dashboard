## Summary

Keep open: current main still calls the model-backed exec reviewer completion on every reviewer invocation, and no duplicate issue or fixing PR owns the repeated-billing behavior.

## What This Changes

The issue requests reusing deterministic model-backed exec auto-review decisions for byte-identical exec requests instead of billing a fresh reviewer completion each time.

## Best Possible Solution

Add a bounded, non-persistent exact-input memo at the shared reviewer boundary after maintainer approval, with regression coverage for repeated identical inputs and host/session-sensitive key separation.
