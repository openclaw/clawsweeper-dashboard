## Summary

Keep open: current main and the latest release still invoke the model-backed exec reviewer completion for each approval miss, with no verdict memo for repeated identical inputs. The report is source-reproducible, but the fix changes exec approval cache semantics and needs maintainer approval of cache lifetime and key shape.

## What This Changes

The issue asks OpenClaw to reuse deterministic model-backed exec reviewer verdicts for byte-identical repeated exec requests within the same run instead of billing a fresh completion each time.

## Best Possible Solution

Approve and implement a bounded in-memory memo inside createModelExecAutoReviewer keyed by the complete reviewed input or prompt, with regression tests for repeated identical node and gateway requests while preserving allow-once and human-fallback semantics.

Options:

- **Approve full-input per-run memo (recommended):** Cache parsed reviewer decisions only inside the shared reviewer instance, keyed by the complete ExecAutoReviewInput or generated prompt, without persisting or converting the result to durable approval.
- **Memoize allow-once only:** Cache only low-risk allow-once results and keep ask, timeout, and error outcomes uncached for a narrower behavior change.
- **Keep fresh review semantics:** Accept the repeated model cost to preserve one fresh reviewer completion per approval miss until stronger security or billing evidence changes the tradeoff.

## Reproduction Assessment

Yes, as a source-level reproduction: current main reaches prepareSimpleCompletionModelForAgent and completeWithPreparedSimpleCompletionModel on every createModelExecAutoReviewer invocation, and both node and gateway hosts call that reviewer on each approval miss. I did not run a live provider billing loop.

## Solution Assessment

Unclear until maintainer approval of cache semantics; the narrowest likely fix is a shared exact-input reviewer memo, not per-host durable approval reuse. The implementation also needs a scope decision for call paths that create a fresh reviewer per request.
