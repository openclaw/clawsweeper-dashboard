## Summary

Keep open: current main still calls the model-backed exec reviewer completion for each approval miss, and two open fixing PRs now reference this issue rather than a merged implementation on main.

## What This Changes

The issue asks OpenClaw to reuse deterministic model-backed exec auto-review decisions for byte-identical repeated exec requests within one run.

## Best Possible Solution

Accept one focused fix that adds a bounded, non-persistent exact-input memo in createModelExecAutoReviewer, with regression coverage proving identical requests reuse one completion while host, agent, session, reason, and changed argv still miss the cache.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: May OpenClaw reuse model-backed exec reviewer decisions for byte-identical requests, and must the cache be per-reviewer-instance with the full reviewed input as its key?

Rationale: The source-level cost bug is clear, but caching an exec approval reviewer result changes when a later request bypasses a fresh model review, so the approval-boundary intent cannot be chosen by cleanup automation alone.

Likely owner: Vincent Koc

Owner reason: Recent adjacent approval-reviewer security work makes this the best available route for the cache-boundary decision.

Owner confidence: medium

Options:

- **Approve full-input per-run memo (recommended):** Cache reviewer decisions only inside the shared reviewer instance, keyed by the full reviewed input or prompt, and never persist or convert them to durable approval.
- **Cache allow-once only:** Cache only low-risk allow-once decisions and keep ask, timeout, and error outcomes uncached for a narrower security-boundary change.
- **Keep fresh review semantics:** Accept the repeated reviewer completion cost to preserve one-request-one-review semantics until stronger live billing or security evidence is available.

## Reproduction Assessment

Yes, source-reproducible: current createModelExecAutoReviewer prepares and completes the reviewer call on every invocation, and both node and gateway hosts call it for each approval miss. I did not run a live provider billing loop, so this is not marked reproduced.

## Solution Assessment

Yes after maintainer cache-scope approval: the narrowest maintainable fix is a shared exact-input reviewer memo rather than per-host caches or durable approval reuse.
