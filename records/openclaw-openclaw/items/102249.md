## What This Changes

The issue requests per-run reuse of deterministic model-backed exec reviewer verdicts for byte-identical approval-miss exec requests to avoid repeated paid completions.

## Best Possible Solution

Add a bounded, non-persistent exact-input memo at the approved owner boundary, with regression coverage for node and gateway reuse while preserving allow-once semantics.
