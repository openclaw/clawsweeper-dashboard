## What This Changes

The issue reports that byte-identical repeated exec auto-review requests re-bill fresh model completions instead of reusing a deterministic per-run verdict.

Review and land one bounded exact-input shared-reviewer memo PR after maintainer approval of cache semantics and real configured-run proof, then close this issue from the merged fix.
