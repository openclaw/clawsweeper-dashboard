## Summary

Keep open: current main still calls the model-backed exec reviewer completion on every identical approval miss, and no merged or open fixing PR appears to own this repeated-billing bug.

## What This Changes

The issue requests reusing deterministic model-backed exec auto-reviewer verdicts for byte-identical exec requests within a run to avoid repeated paid completions.

## Best Possible Solution

Approve and implement a non-persistent exact-input memo at the shared reviewer boundary, with tests proving repeated identical inputs reuse one completion while preserving host/session-sensitive allow-once semantics.

- **Keep fresh review semantics:** Accept repeated model cost to preserve one-request-one-review semantics until stronger security or live billing evidence is available.

## Solution Assessment
