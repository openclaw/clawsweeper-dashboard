## What This Changes

The issue requests reusing deterministic model-backed exec reviewer verdicts for byte-identical exec requests within a run to avoid repeated paid completions.

## Best Possible Solution

Add a bounded, non-persistent exact-input memo at the shared reviewer boundary after maintainer approval of the cache scope, with regression coverage for repeated identical requests and distinct host/session-sensitive inputs.

## Solution Assessment

Yes after maintainer cache-scope approval: the narrowest maintainable fix is a shared exact-input reviewer memo rather than per-host caches or durable approval reuse. The sibling plugin harness helper should either reuse a reviewer or be documented as outside this issue’s fix boundary.
