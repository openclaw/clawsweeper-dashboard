## Summary

Keep open: current main and v2026.6.11 still treat WHAM `subscription_limit` blocks as profile-wide, and the open linked PR is the active fix candidate.

## What This Changes

The issue requests model-scoped Codex/OpenAI `subscription_limit` blocking so one model's quota block does not suppress sibling models sharing the same OAuth profile.

## Best Possible Solution

Review and land or replace https://github.com/openclaw/openclaw/pull/99810; close this issue after an equivalent fix reaches `main`.

## Reproduction Assessment

Yes at source level. Seeding or triggering a WHAM `subscription_limit` block on current main leaves `blockedModel` discarded or ignored, so `isProfileInCooldown` stays true for an unrelated `forModel` on the same profile.

## Solution Assessment

Yes. Reusing the existing `blockedModel` field and mirroring the established `cooldownModel` gate is the narrow owner-boundary fix; the active implementation candidate is https://github.com/openclaw/openclaw/pull/99810.
