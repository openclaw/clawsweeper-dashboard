## Summary

Keep open. Current main has useful narrow guards for idle timeouts, broad retry exhaustion, post-compaction loops, and tool loops, but it still lacks the requested first-class session-health circuit breaker with failure receipts, unhealthy-session state, recovery policy, auto-rotation, and operator/UI surfacing.

## What This Changes

The issue requests a gateway/runtime session-level circuit breaker that stops repeated retries on unhealthy sessions and exposes recovery state after consecutive failures.

## Best Possible Solution

Design one core session-health contract that composes with existing retry, failover, idle-timeout, tool-loop, and compaction guards, then add the minimal runtime, persistence, config, and operator surfaces behind upgrade-safe defaults.
