## Summary

Current main has bounded retry backstops, an idle-timeout-only cost breaker, tool-loop detection, and post-compaction loop guards, but it still does not provide the requested general session-health circuit breaker, persisted unhealthy-session receipt, recovery policy, or UI/operator surfacing. The issue should stay open for maintainer product design rather than a new automated fix PR.

## What This Changes

The issue requests a gateway/runtime session-level circuit breaker that bounds repeated unhealthy-session retries, records unhealthy state, and exposes recovery options to operators.

## Best Possible Solution

Define one maintainer-approved session-health contract that composes with retry limits, provider failover, idle-timeout, tool-loop, and compaction guards before adding minimal runtime, persistence, config, and operator surfaces.
