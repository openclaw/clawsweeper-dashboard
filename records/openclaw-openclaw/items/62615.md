## Summary

Keep open. Current main has narrower protections for idle timeouts, broad retry-loop exhaustion, post-compaction loops, and tool-call no-progress loops, but it still does not implement the requested first-class session-health breaker with failure receipts, retry admission state, recovery policy, UI/operator surfacing, or optional session rotation.

## What This Changes

The issue requests a gateway/runtime session circuit breaker that trips after consecutive unhealthy attempts, emits operator-visible health state, and optionally rotates or resumes sessions safely.

## Best Possible Solution

Define one core session-health contract that composes with existing retry, failover, idle-timeout, tool-loop, and compaction guards, then add the minimal runtime, persistence, config, and operator surfaces behind upgrade-safe defaults.

- **Defer to narrower guards:** Keep idle-timeout, compaction, tool-loop, provider, cron, and subagent breaker tracks separate and close or narrow this umbrella request later.
