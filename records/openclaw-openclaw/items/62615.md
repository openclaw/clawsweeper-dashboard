## Summary

Keep open. Current main has useful narrower guards for retry caps, idle timeouts, compaction loops, and tool loops, but it still lacks the requested first-class session-health breaker with failure receipts, unhealthy-session state, recovery policy, auto-rotation, and operator/UI surfacing.

## What This Changes

The issue requests a gateway/runtime session-level circuit breaker that trips after consecutive unhealthy session attempts, exposes operator-visible unhealthy-session state, and optionally supports recovery actions such as cooldown or session rotation.

## Best Possible Solution

Design one core session-health contract that composes with existing retry, failover, idle-timeout, tool-loop, and compaction guards, then add the minimal runtime, persistence, config, and operator surfaces behind upgrade-safe defaults.
