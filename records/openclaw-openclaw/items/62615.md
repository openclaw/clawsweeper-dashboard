## Summary

Keep open. Current main has narrower retry caps, an idle-timeout-only breaker, and tool-loop guards, but it still does not implement the requested general session-health breaker, first-class unhealthy-session receipt, recovery policy, or operator/UI surfacing.

## What This Changes

Add a gateway/runtime session-level circuit breaker that stops repeated unhealthy-session retries and surfaces recovery state after configurable thresholds.

## Best Possible Solution

Define one core session-health contract that composes with existing retry, failover, idle-timeout, tool-loop, and compaction guards, then implement the minimal runtime, persistence, config, and operator surfaces behind upgrade-safe defaults.
