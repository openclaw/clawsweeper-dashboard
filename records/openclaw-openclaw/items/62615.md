## Summary

Keep open. Current main and the latest release contain narrower retry guards, but they still do not provide the requested session-level unhealthy-state breaker with failure receipts, recovery policy, auto-rotation, and operator/UI surfacing.

## What This Changes

Request a gateway/runtime session circuit breaker that stops retrying unhealthy sessions after consecutive failures and exposes recovery state to operators.

## Best Possible Solution

Define one core session-health receipt and recovery contract, then compose it with existing retry, failover, idle-timeout, tool-loop, and compaction guards behind upgrade-safe defaults.

- **Keep narrower guard tracks:** Continue using separate idle-timeout, tool-loop, compaction, provider, cron, and subagent guards and narrow or close this umbrella later.
