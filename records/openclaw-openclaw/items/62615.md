## Summary

Keep open. Current main has narrower protections for idle-timeout retry cost, provider cooldown suspension, cron retry backoff, compaction loops, and tool-call loops, but it still does not provide the requested gateway/session-health circuit breaker for arbitrary consecutive unhealthy attempts with first-class recovery receipts and operator/UI semantics.

## What This Changes

Requested a gateway/runtime session-level circuit breaker that bounds retries on unhealthy sessions, marks session health, emits operator-visible recovery signals, and can optionally rotate to a fresh session.

## Best Possible Solution

Keep this as the canonical design track for a core session-health breaker that composes with existing idle-timeout, provider cooldown, cron, compaction, and tool-loop guards, with persistence, UI, and recovery semantics decided before implementation.
