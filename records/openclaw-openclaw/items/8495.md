## Summary

Keep open: current main and v2026.6.11 still block or drop unauthorized WhatsApp group traffic, but they do not auto-leave unapproved groups, emit a WhatsApp group-join hook/event, or expose a WhatsApp leave-group action. ## What This Changes

Add opt-in WhatsApp unauthorized-group auto-leave behavior, a group-join webhook/event, and a manual WhatsApp leave action.

## Best Possible Solution

Define a product/security-reviewed WhatsApp plugin contract that separates group admission from sender authorization, adds opt-in schema/docs/tests, authorizes any destructive leave action per account and target, and coordinates owner notification with the broader group-pairing design.
