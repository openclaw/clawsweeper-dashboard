## Summary

Keep open: current main and the latest release still only block or drop unauthorized WhatsApp group traffic; they do not leave unapproved groups, emit a WhatsApp group-join event, or expose a WhatsApp leave-group action. This is a valid security-hardening feature request, but it needs maintainer product/security direction before implementation.

## What This Changes

Request opt-in WhatsApp behavior to leave unauthorized groups, emit group-add or group-join events, and expose a manual leave action for group hygiene.

## Best Possible Solution

Keep this as a product/security-reviewed WhatsApp plugin feature: define opt-in group admission and leave semantics, add schema/docs/tests, authorize any destructive leave action per account and target, and coordinate owner notification with the broader group-pairing design.
