## Summary

Keep open: current main and the latest release still only block or drop unauthorized WhatsApp group traffic; they do not auto-leave groups, emit a WhatsApp group-join hook, or expose a WhatsApp leave action. The related group-pairing, Telegram, and WhatsApp authorization items overlap but do not replace this WhatsApp-specific security feature request.

## What This Changes

Request to add opt-in WhatsApp unauthorized-group auto-leave, a group-join hook/event, and a manual WhatsApp leave action.

## Best Possible Solution

Keep this as a product/security-reviewed WhatsApp plugin design that separates group admission from sender allowlists, adds opt-in auto-leave and owner notification semantics, and exposes any leave action only after authorization, account targeting, audit behavior, docs, and tests are defined.

## Reproduction Assessment

Yes, at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

No current implementation is best yet. The maintainable path should distinguish chat-level group admission from sender allowlists and design destructive leave authorization plus owner notification before adding config, hooks, or message actions.
