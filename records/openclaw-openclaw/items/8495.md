## Summary

Keep open: current main and the latest v2026.6.11 release still drop or block unauthorized WhatsApp group traffic, but they do not auto-leave the group, emit a WhatsApp group-join event, or expose a leave-group action. Related group-pairing and Telegram unknown-group items overlap, but none is a merged or safe canonical replacement for this WhatsApp-specific security feature.

## What This Changes

The issue requests an opt-in WhatsApp feature to leave unauthorized groups, expose a group-join hook/event, and optionally add a manual leave action.

## Best Possible Solution

Keep this open for product/security-reviewed WhatsApp plugin design: separate group admission from sender allowlists, add opt-in auto-leave and owner notification semantics, and expose any leave action only after authorization and audit behavior are defined.

## Reproduction Assessment

Yes, at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

No current implementation is best yet. The maintainable path should distinguish chat-level group admission from sender allowlists and design destructive leave authorization plus owner notification before adding config, hooks, or message actions.
