## Summary

Keep open: current main and v2026.6.11 still only block or drop unauthorized WhatsApp group traffic; they do not auto-leave groups, expose a WhatsApp group-join hook/event, or provide a WhatsApp leave action. The related broader group-pairing issue and adjacent Telegram/WhatsApp PRs overlap but do not replace this WhatsApp-specific security feature request.

## What This Changes

Request an opt-in WhatsApp feature to auto-leave unauthorized groups, notify or hook when the bot is added to a group, and expose a manual leave action.

## Best Possible Solution

Keep this open for a product/security-reviewed WhatsApp plugin design that separates group admission from sender allowlists, adds opt-in auto-leave and owner notification semantics, and exposes any leave action only after authorization and audit behavior are defined.

## Reproduction Assessment

Yes, at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

No current implementation is best yet. The maintainable path should distinguish chat-level group admission from sender allowlists and design destructive leave authorization plus owner notification before adding config, hooks, or message actions.
