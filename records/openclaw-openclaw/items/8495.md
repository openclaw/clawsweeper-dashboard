## Summary

Keep open: current main and the latest release still only block or drop unauthorized WhatsApp group traffic; they do not leave unapproved groups, emit a WhatsApp group-join hook/event, or expose a WhatsApp leave action. The related broader group-pairing and per-group sender-allowlist work overlaps but does not supersede this WhatsApp-specific security request.

## What This Changes

Request an opt-in WhatsApp feature to auto-leave unauthorized groups and expose group-add or leave handling through hooks, events, or message actions.

## Best Possible Solution

Keep this open for a product/security-reviewed WhatsApp plugin design that adds opt-in auto-leave, owner notification or hook semantics, and any leave action with account-scoped authorization and live WhatsApp proof.

Yes, at source level: current main and v2026.6.11 block or drop unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. This is a feature absence rather than a broken existing-behavior bug reproduction.
