## Summary

Keep open: current main and the latest release still block or drop unauthorized WhatsApp group traffic, but they do not auto-leave unapproved groups, emit a WhatsApp group-join hook/event, or expose a WhatsApp leave-group action. The overlapping group-pairing, Telegram, WhatsApp sender-allowlist, and WhatsApp admin-privacy items do not supersede this WhatsApp-specific request.

## What This Changes

Request an opt-in WhatsApp security feature that leaves unauthorized groups, exposes a group-join notification/hook, and adds a manual leave action.

## Best Possible Solution

Define a product/security-reviewed WhatsApp plugin contract that separates group admission from sender authorization, adds opt-in schema/docs/tests, authorizes any destructive leave action per account and target, and coordinates owner notification with the broader group-pairing design.
