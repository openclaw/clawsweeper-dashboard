## Summary

Keep open: current main and v2026.6.11 still block or drop unauthorized WhatsApp group traffic, but they do not auto-leave unapproved groups, emit a WhatsApp group-join hook/event, or expose a WhatsApp leave action. Related group-pairing, per-group sender allowlist, and admin-privacy work overlaps but is open, conflicting, or narrower than this WhatsApp-specific security request.

## What This Changes

Request an opt-in WhatsApp feature to leave unauthorized groups, surface group-join events, and optionally expose a manual leave action.

## Best Possible Solution

Design this as a product/security-reviewed WhatsApp plugin feature: opt-in auto-leave should key off approved group admission, group-join events should notify the owner without running assistant work, and any leave action should be narrowly authorized and proven live.

## Reproduction Assessment

Yes, at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

No current implementation is best yet. The maintainable path should separate chat-level group admission from sender allowlists and define destructive leave authorization plus owner notification before adding config, hooks, or message actions.
