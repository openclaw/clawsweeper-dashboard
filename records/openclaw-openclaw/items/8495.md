## Summary

Keep open: current main and v2026.6.11 still only block or drop unauthorized WhatsApp group traffic; they do not auto-leave groups, emit a WhatsApp group-join hook, or expose a WhatsApp leave action. The broader group-pairing and adjacent Telegram/WhatsApp authorization items overlap but do not replace this WhatsApp-specific security feature request.

## What This Changes

The issue requests opt-in WhatsApp auto-leave for unauthorized groups plus group-join notification/hook and manual leave-action surfaces.

## Best Possible Solution

Keep this open for a product/security-reviewed WhatsApp plugin design that separates group admission from sender allowlists, adds opt-in auto-leave and owner notification semantics, and only exposes a leave action after authorization and audit behavior are defined.

## Reproduction Assessment

Yes, at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

No current implementation is best yet. The maintainable path should distinguish chat-level group admission from sender allowlists and design destructive leave authorization plus owner notification before adding config, hooks, or message actions.
