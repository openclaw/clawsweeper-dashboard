## Summary

Keep open: current main still denies unauthorized WhatsApp group traffic without leaving the group or exposing a join-specific notification/action. The request is feasible in the bundled WhatsApp plugin, but destructive departure behavior, privacy-sensitive event payloads, and the permanent configuration/tool contract require explicit product and security direction.

## What This Changes

Add opt-in automatic departure from unauthorized WhatsApp groups, a group-join event or notification, and a manual leave-group action.

## Best Possible Solution

Implement a bounded WhatsApp-plugin policy keyed to the effective channels.whatsapp.groups admission result: optionally warn and leave before agent execution, deduplicate join events, require explicit authorization for manual leave, and route only redacted owner notifications; coordinate any cross-channel join-event contract with https://github.com/openclaw/openclaw/issues/11489.
