## Summary

Keep open: current main and the latest release still block or drop unauthorized WhatsApp group traffic, but they do not auto-leave unapproved groups, emit a WhatsApp group-join hook/event, or expose a WhatsApp leave-group action. Related group-pairing, Telegram, and WhatsApp per-group sender-allowlist work overlaps but does not supersede this WhatsApp-specific security feature.

## What This Changes

The issue requests opt-in WhatsApp behavior to leave unauthorized groups, expose a group-join hook/event, and optionally provide a manual leave action.

## Best Possible Solution

Define a product/security-reviewed WhatsApp plugin contract that separates group admission from sender authorization, adds opt-in schema/docs/tests, authorizes destructive leave behavior per account and target, and coordinates owner notification with the broader group-pairing design.

## Reproduction Assessment

## Solution Assessment

Not yet as written: the maintainable path should define group admission versus sender allowlist semantics and authorization/audit behavior for destructive leave operations before implementation. A direct groupAllowFrom-driven auto-leave would be too risky without that contract.
