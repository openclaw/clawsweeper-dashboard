Request an opt-in WhatsApp feature to leave unauthorized groups, expose group-add/join handling, and optionally provide a manual group leave action.

## Best Possible Solution

Define a WhatsApp plugin-owned, opt-in security feature that can leave unauthorized groups deterministically, emit a privacy-gated owner notification or hook, optionally expose a manual leave action, and ship with schema/docs/tests plus live WhatsApp proof.
