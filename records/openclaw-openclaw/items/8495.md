## Summary

Keep open: current main and v2026.6.11 still deny or drop unauthorized WhatsApp group traffic without leaving the group or emitting a join notification. Baileys and the existing WhatsApp listener make a narrow implementation feasible, but automatic departure is destructive and the proposed hook/tool expansion requires explicit product and security direction.

## What This Changes

Add opt-in WhatsApp unauthorized-group auto-leave, a group-join notification/event, and a manual leave action.

## Best Possible Solution

Implement an opt-in WhatsApp-owned unknown-group policy from the existing group event listener, acting only on a verified self-join to a group JID outside the configured group admission map; add a narrow owner notification and real throwaway-group proof, while deferring generic hook and message-tool APIs unless separately approved.
