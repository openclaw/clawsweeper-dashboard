## Summary

Keep open: current main and latest release still block or drop unauthorized WhatsApp group traffic without leaving the group, emitting a group-join hook, or exposing a WhatsApp leave action. The broader group-pairing issue and adjacent WhatsApp/Telegram authorization work overlap, but none supersede this WhatsApp-specific security feature request.

## What This Changes

Request opt-in WhatsApp behavior to auto-leave unauthorized groups, emit a group-join hook/event, and expose a manual leave action.

## Best Possible Solution

Keep this open for a deliberate WhatsApp plugin design that separates group admission from sender allowlists, adds opt-in unknown-group auto-leave and owner notification, and guards any leave action with account/target authorization plus live proof.

## Reproduction Assessment

Yes, at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving, notifying, or exposing a leave action. I did not run a live WhatsApp group-add scenario in this read-only review.

## Solution Assessment

No, not exactly as proposed: tying auto-leave to groupAllowFrom would mix sender allowlists with chat-level group admission. The best fix needs maintainer-defined group admission, notification, and leave authorization semantics before implementation.
