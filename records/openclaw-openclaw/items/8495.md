Keep open: current main still only blocks or drops unauthorized WhatsApp group traffic; it does not auto-leave groups, emit a WhatsApp group-join hook, or expose a WhatsApp leave action. ## What This Changes

The issue requests WhatsApp support for automatically leaving unauthorized groups, emitting a group-join event or webhook, and exposing an explicit leave action.

## Best Possible Solution

Keep this open for a product/security-reviewed WhatsApp plugin design that separates group admission from sender allowlists, adds opt-in unauthorized-group auto-leave and owner notification semantics, and exposes any leave action only after authorization and audit behavior are defined.

## Reproduction Assessment

Yes at source level: current main blocks or drops unauthorized WhatsApp group traffic without leaving the group, notifying the owner, or exposing a leave action. This is a feature request rather than a broken existing behavior reproduction.

## Solution Assessment

No current implementation is best yet. The maintainable path should distinguish chat-level group admission from sender allowlists and design destructive leave authorization plus owner notification before adding config, hooks, or message actions.
