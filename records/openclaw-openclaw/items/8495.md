## Summary

Keep open: current main blocks unauthorized WhatsApp group traffic and logs unregistered-group drops, but it does not leave the group, emit a group-join event, or expose a WhatsApp leave action. The remaining work is a security-sensitive bundled-channel feature whose membership boundary and event/tool contract need maintainer direction; the broader group-pairing proposal at https://github.com/openclaw/openclaw/issues/11489 overlaps but does not yet own this WhatsApp-specific behavior.

## What This Changes

Add opt-in handling for unauthorized WhatsApp group additions: automatically leave, notify through a join event or webhook, and optionally provide a manual group-leave message action.

## Best Possible Solution

Define an opt-in WhatsApp plugin feature keyed to unapproved group membership, with a narrowly authorized leave action and privacy-safe owner notification; defer the generic cross-channel pairing model to https://github.com/openclaw/openclaw/issues/11489.
