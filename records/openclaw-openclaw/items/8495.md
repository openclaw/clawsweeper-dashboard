## Summary

Keep open: current main and v2026.6.11 still drop or block unauthorized WhatsApp group traffic, but they do not auto-leave unapproved groups, emit a WhatsApp group-join hook/event, or expose a WhatsApp leave-group action. Related group-pairing, Telegram, and per-group WhatsApp allowlist items overlap but do not supersede this WhatsApp-specific security feature.

## What This Changes

Request to add opt-in WhatsApp unauthorized-group auto-leave, group-join notification or webhook behavior, and a manual WhatsApp leave-group action.

## Best Possible Solution

Define a product/security-reviewed WhatsApp plugin contract that separates group admission from sender authorization, adds opt-in schema/docs/tests, authorizes destructive leave behavior per account and target, and coordinates owner notification with the broader group-pairing design.
