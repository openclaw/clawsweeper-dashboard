## What This Changes

Prevent model-hallucinated `#session:<uuid>` conversation-context lines from being delivered to users as channel messages.

## System Context

OpenClaw formats prior conversation into an untrusted chronological prompt context, receives generated assistant text, then prepares and sends that text through channel adapters such as Telegram. Internal context delimiters must not be mistaken for user-visible assistant content at that delivery boundary.

## Best Possible Solution
