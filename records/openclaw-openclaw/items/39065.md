  - confidence: 0.88

  - body: This type exposes `channels.discord.unpairedResponse`, but the PR-head strict Discord schema still has no matching key; Slack and LINE show the same type/schema split.   - confidence: 0.9

  - body: The PR adds `unpairedResponse` to the IRC core schema, but this runtime call still omits `mode`, so IRC always builds the default branded reply and ignores `silent`/`code-only`. Either remove the advertised IRC config or pass the validated mode through the plugin-owned account config.
  - confidence: 0.87
- **[P2] Honor silent mode for pending Discord pairings:** `src/discord/monitor/agent-components.ts:533-540`

Gate this fallback on the same response mode or route the component path through the shared Discord DM decision helper.
  - confidence: 0.86
