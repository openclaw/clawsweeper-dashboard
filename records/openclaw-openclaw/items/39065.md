Full review comments:

- **[P1] Keep suppression out of the exported formatter:** `src/pairing/pairing-messages.ts:11`
  - body: `buildPairingReply` is exported through `openclaw/plugin-sdk/conversation-runtime`, so changing it from `string` to `string | null` makes existing plugin/runtime callers handle a new nullable result. Keep the formatter string-returning and put the silent decision in the challenge issuer or a new explicitly versioned API.
  - confidence: 0.9
- **[P1] Wire advertised config through current strict schemas:** `src/config/zod-schema.providers-core.ts:1078`
  - body: Adding `unpairedResponse` to the old/core schema is not enough now that channels have plugin-local strict schemas. IRC and LINE still reject undeclared keys, and current Discord/Slack/Telegram wrappers compose plugin schemas, so users can configure an advertised option that fails validation or never reaches runtime.
  - confidence: 0.88
- **[P1] Pass the response mode into IRC pairing replies:** `extensions/irc/src/inbound.ts:219`
  - body: This path only checks whether `buildPairingReply` returned text, but it never passes the configured response mode, so IRC still gets the default branded reply even when `silent` or `code-only` is configured. BlueBubbles has the same shape, so the advertised option is ignored on those paths.
  - confidence: 0.86
- **[P2] Honor silent mode for pending Discord pairings:** `src/discord/monitor/agent-components.ts:530-539`
  - body: For repeat pairing attempts, this branch still sends the hardcoded `Pairing already requested...` response instead of respecting `unpairedResponse: "silent"`. That leaves one Discord DM interaction path fingerprinting the bot after the first pending request.
  - confidence: 0.9
- **[P3] Record outbound activity only after sending:** `extensions/nextcloud-talk/src/inbound.ts:192`
  - body: `statusSink` remains outside the `if (replyText)` guard, so silent mode records `lastOutboundAt` even when no Nextcloud Talk message was sent. Move it inside the send branch to keep activity state truthful.
  - confidence: 0.83
