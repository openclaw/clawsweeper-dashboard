## Summary

The existing review comment identifies the same concrete P1 boundary; the later commits shown are test/lint follow-ups, not an indicated workflow hardening.

## What This Changes

The PR adds a scheduled GitHub Actions sweeper plus tested JavaScript logic to close and reopen recent qualifying pull requests whose pull_request CI run is missing or startup-failed.

## Best Possible Solution

Run the privileged job only from the repository default branch, check out that trusted revision before creating or exposing the App token, scope the generated token to the API permissions the sweeper needs, then attach a redacted dry-run or controlled live-dispatch transcript.
