## What This Changes

This PR claims new-session first-turn handoffs before chat-pane hydration, makes the Control UI mock Gateway expose newly created sessions to list requests, stabilizes route assertions, and makes the new-session Chromium suite part of the main CI gate.

## System Context

The changed browser harness and CI workflow verify that this handoff, route settlement, and Gateway session visibility continue to work before UI changes merge.
