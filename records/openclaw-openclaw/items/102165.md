## What This Changes

The PR adds Feishu recall handling that drops recalled inbound work, aborts source-bound agent dispatches, and suppresses replies after the source message is withdrawn.

## System Context

The Feishu plugin receives chat events, debounces and routes them into agent runs, then sends streamed or final replies back to Feishu. This change inserts recalled-source tracking across those ingress, dispatch, typing, and reply-delivery stages so a withdrawn message stops associated work.
