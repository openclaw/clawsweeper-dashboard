## Summary

Keep this PR open, but do not merge it yet. The reported duplicate-fallback bug is credible, while the patch introduces a competing success-classification path that can bypass cancellation handling, and the PR provides tests rather than after-fix runtime proof.

## What This Changes

The PR adds an optional result-success callback to the model-fallback runner and uses embedded-run delivery or visible-output evidence to stop further fallback attempts.

## Best Possible Solution

Keep one canonical decision in the embedded result classifier: add or correctly pass the missing source-reply delivery evidence there, leave generic fallback cancellation precedence intact, and prove success, genuine fallback, and cancellation with a real configured chain.
