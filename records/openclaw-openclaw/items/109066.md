## Summary

Keep this PR open but do not merge the current patch: the success override can suppress genuine fallback-worthy failures and changes the established cancellation precedence.

## What This Changes

The PR adds a generic success-evidence callback to model fallback, wires it to embedded delivery and visible-text fields, and adds two runner-level regression tests.

## Best Possible Solution

Keep one authoritative decision path by teaching the embedded classifier or its canonical delivery-evidence inputs to recognize completed delivery, while leaving generic fallback abort and classified-error handling unchanged.

  - body: This accepts any non-empty assistant or payload text after the classifier has already identified a fallback-worthy result.   - confidence: 0.96
