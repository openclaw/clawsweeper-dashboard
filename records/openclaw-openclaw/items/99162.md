The PR adds a Control UI startup polyfill module for missing `Array.prototype.toSorted` and `toReversed`, imports it before the app entrypoint, and adds regression tests for fallback behavior and import order.

## Best Possible Solution

Land this PR as the canonical fix once maintainers accept the narrow guarded prototype fallback, then resolve the competing same-issue PRs against that chosen path.

## Solution Assessment
