## What This Changes

The PR lets a browser-native context menu handle non-empty text selected within a Control UI chat bubble, while retaining OpenClaw’s message-action menu for unselected or unrelated bubbles.

## System Context

The Control UI chat transcript renders message bubbles and handles their right-click events to expose message actions such as Reply. The handler decides whether the event remains with the browser for selected text or is intercepted for OpenClaw’s message-level menu.
