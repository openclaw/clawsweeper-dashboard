## What This Changes

The PR makes a selected text range within a Control UI chat bubble defer its right-click menu to the browser, preserving OpenClaw’s message-action menu when no intersecting text is selected.

## System Context

The Control UI chat view receives browser context-menu events from rendered conversation bubbles and maps them to message actions such as Reply. This change decides whether a selected text range should stay in the browser’s native interaction path or continue to OpenClaw’s message-action menu.
