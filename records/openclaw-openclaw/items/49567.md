## Summary

Keep open. Current main and v2026.6.11 still reject `bindings[].tools`, and the current route/ACP/tool-policy paths have no binding-scoped policy layer to enforce the requested deny list.

## What This Changes

Add binding-scoped `tools.allow`/`tools.deny` policy for route and ACP bindings so selected conversations can receive a narrower tool set.

## Best Possible Solution

Either document existing group/sender policy as the supported answer, or implement binding-scoped policy end to end across schema/types, route and ACP resolution, enforcement, docs, and regression tests.
