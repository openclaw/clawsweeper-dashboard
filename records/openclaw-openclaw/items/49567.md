## Summary

Keep open: current main still has no route/ACP binding-level tool policy surface or enforcement path, and the remaining work is a security-sensitive product/config decision rather than stale cleanup.

## What This Changes

The issue requests per-binding `tools.allow`/`tools.deny` restrictions for route/ACP bindings so matched channel/group traffic can narrow available tools without MCP/proxy filtering.

## Best Possible Solution

Keep the schema closed until maintainers approve a complete binding-scoped policy design; if approved, implement schema/types, matched-binding propagation, embedded/gateway/ACP enforcement, docs, and regression tests together.

Unclear until maintainer intent is confirmed. A schema-only change is not the best fix; the maintainable path is either a complete binding-scoped enforcement layer or an explicit decision to use existing group/sender/session policy surfaces instead.
