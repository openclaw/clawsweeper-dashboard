## Summary

Keep open. Current main and v2026.6.11 still have strict route/ACP binding schemas with no binding-level tool policy, and the linked schema-only PR closed unmerged because accepting `bindings[].tools` without enforcement would create a false security boundary.

## What This Changes

Request to allow route and ACP bindings to declare per-binding `tools.allow`/`tools.deny` restrictions for matched conversations.

## Best Possible Solution

Define one maintainer-approved binding policy contract and implement schema, types, matched-binding propagation, runtime enforcement, docs, and regression proof together, or explicitly document existing group/sender/session policy as the supported boundary.
