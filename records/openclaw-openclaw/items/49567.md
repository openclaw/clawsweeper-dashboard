## Summary

Keep open. Current main and v2026.6.11 still do not accept or enforce `bindings[].tools`; the linked schema-only PR was closed in favor of this issue, and broader related issues do not replace this route/ACP binding-scoped security/config decision.

## What This Changes

Request binding-scoped `tools.allow`/`tools.deny` policy for route and ACP bindings so selected channel conversations can restrict tool access independently of the agent-wide policy.

## Best Possible Solution

Keep this as the canonical maintainer-owned design item, then either document existing group/channel/sender policy as the supported solution or implement binding-scoped policy end to end across schema/types, route and ACP propagation, tool-policy enforcement, docs, and regression tests.

## Solution Assessment

No for the schema-only proposal linked from the issue. The maintainable path needs a product/security decision first, then either documentation for existing group/sender policy or complete binding-scoped enforcement.
