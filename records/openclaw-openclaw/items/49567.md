## Summary

Keep open: current main still rejects `tools` on route/ACP bindings and does not carry a binding-scoped tool-policy layer, while the merged conversation capability profile is only a foundation and the linked schema-only PR closed unmerged.

## What This Changes

The issue requests optional per-binding tool allow/deny policy in route or ACP bindings so channel or group bindings can restrict tools without external MCP filtering.

## Best Possible Solution

Add binding-scoped tool policy only through a maintainer-approved design that updates schema, types, docs, the conversation capability profile or policy pipeline, and focused security regression tests; otherwise document the supported channel/group/direct alternatives.
