## What This Changes

This PR moves QA Lab dashboard run selection into a shared server-side planner, exposes profile/provider/channel/evidence/runtime controls, and routes mixed flow, Playwright, Vitest, and script selections through the canonical suite runner.

## System Context

QA Lab is an internal plugin used to select and run catalogued verification scenarios. The browser dashboard submits a run selection to the QA Lab server, which resolves eligible scenarios and then dispatches the shared suite runner that reports progress and evidence back to the dashboard.
