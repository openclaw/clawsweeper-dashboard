## What This Changes

This PR replaces QA Lab’s dashboard-specific flow-only launch path with a shared server-side resolved plan that exposes profile, model/provider, channel, evidence, runtime-pair, and mixed execution-kind controls.

## System Context

QA Lab receives an operator’s run selection from the browser, resolves it against taxonomy profiles and scenario constraints on the server, then launches the canonical mixed-kind suite runtime. The resulting plan, progress, errors, and artifacts are returned to the dashboard so operators can see what will actually run.
