## What This Changes

## System Context

QA Lab turns a browser operator’s runner selection into a server-owned scenario plan and then launches the appropriate flow, Playwright, Vitest, or script partitions. The resolved plan feeds the suite runner and is projected back to the dashboard as selected scenarios, exclusions, errors, and progress.
