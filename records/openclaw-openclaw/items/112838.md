## What This Changes

This PR routes QA Lab dashboard launches through a shared resolved suite plan, adds controls for profile/runtime/channel choices, and runs mixed flow, Playwright, Vitest, and script scenarios through the canonical suite runner.

## System Context

QA Lab’s browser dashboard sends an operator-selected suite request to the QA Lab server. The server resolves scenario membership and execution constraints, then passes the plan to the shared suite runner, which partitions scenario kinds and reports progress back to the dashboard.
