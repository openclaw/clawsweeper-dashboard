## What This Changes

## Best Possible Solution

Keep the current strict grammar and `Number.isFinite` check; if hostile input length is measurably problematic, use a narrow total-token-length guard that preserves valid exponent spellings and includes positive, negative, leading-zero, overflow, and underflow coverage.
