## Repair Work Prompt

Fix issue #101049 by adding a generic dependency-tree integrity check for managed npm plugin installs and doctor repair. After managed `npm install` succeeds for a plugin package, verify each required direct dependency declared by the installed plugin package resolves from the plugin root or managed project root; fail, rollback, retry, or rebuild rather than persisting a healthy install record when required dependencies are absent. Extend configured plugin install health and `openclaw doctor --fix` to detect an installed plugin record whose package payload exists but required dependencies are missing, then repair by rerunning the official managed npm install/update path. Keep production code generic with no msteams-specific literals beyond tests or fixtures, preserve plugin-owned dependency boundaries, avoid runtime shims or new config/env options, and add regression tests for a generated managed npm plugin project with present package metadata but missing declared dependencies.
