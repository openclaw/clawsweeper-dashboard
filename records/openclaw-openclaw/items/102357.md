## Summary

The shared-prefix calculation fixes the reported truncation, but the new rewrite fallback conflicts with the pinned Teams SDK: clearing all text and then closing with metadata only does not update the existing stream activity, so users can retain the stale preview and receive a second block-delivered reply. The protected `maintainer` label also requires explicit maintainer handling, and the exact after-fix Teams content has not been demonstrated live.

## What This Changes

The PR changes Microsoft Teams cumulative streaming from length-based to shared-prefix delta tracking, clears SDK stream text on non-whitespace rewrites, and adds focused controller mocks and tests.

## Best Possible Solution

Keep shared-prefix delta calculation, but make non-whitespace divergence replace and finalize the same Teams stream activity with the full current snapshot—or use another SDK-valid single-delivery path—and cover the pinned SDK’s empty-text close guard and flush timing with faithful tests plus redacted live Teams proof.
