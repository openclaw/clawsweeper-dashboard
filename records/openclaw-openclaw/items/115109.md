## What This Changes

Moves the shared five-character HTML escaping implementation into a small core utility, keeps the existing Plugin SDK export, and reuses it for OAuth callback and provider OAuth pages.

## System Context

Plugin SDK OAuth helpers render local callback and provider authorization pages from provider-supplied text. This change centralizes the text-and-quoted-attribute escaping primitive those pages use while leaving the public SDK utility export unchanged.
