## Summary

## What This Changes

The branch adds typed safety-timeout partial compaction results, a bounded settlement window, conditional AgentSession persistence after timeout cancellation, non-blocking post-commit notifications, timeout guidance, and focused regression coverage.

## Best Possible Solution

Land the bounded, reason-owned partial-result design only after the compaction owner confirms that a single post-timeout commit is the desired session-state contract, with all ordinary aborts, expired results, and unmarked results remaining fail-closed.
