## Summary

This PR should not merge as written: it converts the fallback name `main` into a mandatory agent ID despite the existing custom-default-agent contract, and its startup recovery test bypasses the invalid snapshot state that production would encounter.

## What This Changes

The PR adds config validation, gateway startup recovery, doctor repair, and tests intended to require and restore a literal `main` entry in `agents.list`.

## Best Possible Solution

Preserve the configured-default-agent contract, detect genuinely invalid or ambiguous default selection rather than requiring the literal ID `main`, and place any persistent repair in one canonical doctor migration with fresh-install and upgrade proof.
