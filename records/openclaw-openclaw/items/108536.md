## Summary

This PR should not merge as written: it turns the literal `main` agent into a new required invariant even though current routing intentionally supports another listed agent as the default, and the proposed startup recovery runs after invalid configuration has already been rejected. citeturn538514view0turn925508view0

## What This Changes

The PR adds a required-`main` validation rule, gateway startup recovery, a doctor repair check, and regression tests for configurations whose agent list omits `main`.

## Best Possible Solution

Preserve configurable default-agent selection, diagnose any genuinely unsafe or ambiguous state through validation plus `openclaw doctor --fix`, keep normal Gateway startup free of silent config rewrites, and prove fresh and upgrade behavior for implicit `main`, explicit `main`, and custom-default configurations.
