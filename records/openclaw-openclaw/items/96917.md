## Summary

Keep open: current main and v2026.6.11 still have the Anthropic OAuth callback-host versus redirect-URI mismatch, and this PR is the active candidate fix with no blocking code findings, but the loopback-only fail-closed behavior needs maintainer acceptance before merge.

## What This Changes

The PR updates Anthropic OAuth to allow only loopback callback hosts, derive the redirect URI from that resolved host, defer validation to the login path, and add regression tests.

## Best Possible Solution

Land the loopback allowlist and derived redirect URI after maintainer acceptance of the env compatibility and security tradeoff, or pause for a broader decision on whether to deprecate direct Anthropic OAuth.
