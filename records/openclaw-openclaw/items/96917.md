## Summary

Keep open for maintainer review: the patch is a focused and well-proven fix for the Anthropic OAuth callback-host mismatch, but it intentionally tightens an existing env-var behavior on an auth-provider path.

## What This Changes

This PR restricts Anthropic OAuth callback hosts to loopback values, derives the redirect URI from the resolved host, defers validation to the login path, and adds regression tests.

## Best Possible Solution

Land the loopback allowlist and derived redirect URI after maintainer acceptance of the env compatibility and security tradeoff, or pause if maintainers prefer deprecating direct Anthropic OAuth instead.
