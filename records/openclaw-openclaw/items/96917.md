## Summary

Keep open for maintainer review: the patch is a focused and well-proven fix for the Anthropic OAuth callback-host mismatch, but it intentionally tightens an existing env/config surface in an auth-provider flow and needs maintainer acceptance before merge.

## What This Changes

The PR restricts Anthropic OAuth callback hosts to loopback values, derives the redirect URI from the resolved host, threads that URI through login/token exchange, and adds callback-host regression tests.

## Best Possible Solution

Land the loopback allowlist and derived redirect URI after maintainer acceptance of the env compatibility and security tradeoff, or pause if maintainers prefer deprecating the direct Anthropic OAuth helper instead.
