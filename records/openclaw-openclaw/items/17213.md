## Summary

Keep open: current main has adjacent strict-agentic, liveness, and terminal snapshot safeguards, but it still lacks the requested typed begin, execution, mandatory commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue requests an atomic agent run lifecycle so announced execution intent cannot be left without explicit execution, commit, or abort state.

## Best Possible Solution

Define one additive lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients/plugin-visible surfaces, docs, and regression tests.
