## Summary

Keep open: current main still has narrower liveness, retry, and no-fake-progress safeguards, but it does not implement the requested atomic begin, execution, commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue asks for a transaction-style agent run lifecycle that prevents pre-action intent notices from being orphaned by requiring explicit commit or abort state.

## Best Possible Solution

Define one additive lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients, plugin-visible surfaces, docs, and regression tests.
