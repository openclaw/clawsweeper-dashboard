## Summary

Keep open: current main still has adjacent strict-agentic, liveness, retry, and terminal snapshot safeguards, but no public atomic begin/exec/commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue requests a transaction-style run lifecycle so action-intent notices cannot be orphaned by interruptions without a later execution, commit, or abort state.

## Best Possible Solution

Define one additive lifecycle or process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients, plugin-visible surfaces, docs, and regression tests.
