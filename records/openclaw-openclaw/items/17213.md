## Summary

Keep open: current main has adjacent strict-agentic, incomplete-turn, liveness, and terminal-outcome safeguards, but it still lacks the requested public atomic begin/exec/commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue requests a core run lifecycle contract so announced agent action intent always resolves to explicit execution, commit, or abort status.

## Best Possible Solution

Define an additive public run lifecycle contract at the Gateway protocol boundary, then propagate structured begin, execution evidence, commit, abort, and blocker semantics through runtime events, wait results, session projection, SDK/plugin-visible APIs, docs, and regression tests.

## Reproduction Assessment
