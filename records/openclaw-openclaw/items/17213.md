## Summary

Keep open: current main has adjacent strict-agentic, liveness, retry, and terminal snapshot safeguards, but it still lacks the requested atomic begin, execution, commit-or-abort lifecycle contract with structured abort blockers. ## What This Changes

The issue requests an atomic run lifecycle contract so announced action intent always reaches execution commit or a structured abort.

## Best Possible Solution

Define one additive lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients, plugin-visible surfaces, docs, and regression tests.
