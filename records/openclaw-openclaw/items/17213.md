## Summary

Keep open: current main and v2026.6.11 still have adjacent incomplete-turn, liveness, and wait safeguards, but they do not define the requested atomic begin, execution, commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

Request is to add a transaction-style agent run lifecycle so announced action intent must end in explicit execution commit or abort status.

## Best Possible Solution

Define one additive gateway lifecycle contract for begin intent, execution evidence, mandatory commit or abort, and structured blocker details, then wire it through runtime, session projection, agent.wait, plugin/client-visible surfaces, docs, and regression tests.
