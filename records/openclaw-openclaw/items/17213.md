## Summary

Keep open: current main and v2026.6.11 have narrower strict-agentic, liveness, and terminal snapshot safeguards, but they still do not define the requested atomic begin, execution, commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

Request an atomic run lifecycle contract so announced action intent must be followed by execution evidence and an explicit commit or abort state.

## Best Possible Solution

Define one additive lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, replay, authorization, and compatibility, then wire it through runtime, gateway protocol, session projection, clients, plugin-visible surfaces, docs, and regression tests.
