## Summary

Keep open: current main has adjacent strict-agentic, liveness, retry, and terminal snapshot safeguards, but it still does not define the requested atomic begin, execution, commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue requests an atomic run lifecycle contract where announced intent must proceed to execution and then an explicit commit or abort status with structured blocker details.

## Best Possible Solution

Define one additive lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients, plugin-visible surfaces, docs, and regression tests.
