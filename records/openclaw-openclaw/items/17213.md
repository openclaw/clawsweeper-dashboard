## Summary

Keep open: current main still has adjacent strict-agentic and terminal snapshot safeguards, but it does not define the requested begin, execution, commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue requests a core transaction-style run lifecycle so announced actions must end in an explicit commit or abort state.

## Best Possible Solution

Define one additive lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients/plugin-visible surfaces, docs, and regression tests.
