## Summary

Keep open: current main still has adjacent strict-agentic, liveness, retry, and terminal outcome safeguards, but it does not implement the requested atomic begin, execution, mandatory commit-or-abort lifecycle contract with structured abort blockers.

## What This Changes

The issue asks OpenClaw to guarantee that announced run intent always reaches explicit execution plus commit or abort status, so user-visible pre-action notices cannot be left orphaned.

## Best Possible Solution

Define one additive public lifecycle/process contract for begin intent, execution evidence, mandatory commit or abort, structured blocker details, ordering, and compatibility, then wire it through runtime, gateway protocol, session projection, clients, plugin-visible surfaces, docs, and regression tests.
