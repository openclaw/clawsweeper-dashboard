## Summary

Keep open: current main and v2026.6.11 still solve narrower GPT-5 false-start behavior with strict-agentic retries, but they do not provide the requested atomic begin, execution, commit-or-abort lifecycle contract with structured abort blockers across gateway events, runtime emitters, session projection, and agent.wait.

## What This Changes

The issue requests a transaction-style agent run lifecycle that distinguishes announced intent from execution and requires an explicit commit or abort state.

## Best Possible Solution

Define one additive gateway lifecycle contract for begin intent, execution evidence, mandatory commit or abort, and structured blocker details, then wire it through runtime, session projection, agent.wait, plugin/client-visible surfaces, docs, and regression tests.
