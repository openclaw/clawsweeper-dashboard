## Summary

Keep open for security review: current redaction is regex-based and does not clearly cover credentials inside escaped, stringified structures, while the public report lacks a complete diagnostic-export reproduction and names one path that is not the current canonical redactor.

## What This Changes

Prevent plaintext credentials embedded in complex serialized log structures from leaking into diagnostic export packages.

## Best Possible Solution

Establish a diagnostics-export invariant that all serialized content is boundedly decoded and recursively redacted before packaging, with depth and size limits, fail-safe handling, and regression tests covering escaped nested objects, arrays, malformed JSON, and representative credential keys.
