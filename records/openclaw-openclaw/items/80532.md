## What This Changes

This PR adds an opt-in `tools.exec.allowSymlinkPath` setting that permits approval-bound host commands from symlinked working directories while exposing both the requested path and canonical target to the approver.

## System Context

Node-host `system.run` requests are converted into an approval plan, then the approved cwd is revalidated immediately before host execution. This PR changes that path so a configured opt-in may canonicalize symlinked cwd paths instead of rejecting them, while retaining identity checks.
