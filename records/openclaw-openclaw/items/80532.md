## What This Changes

This PR adds an opt-in `tools.exec.allowSymlinkPath` setting so approval-bound `system.run` can use a symlinked working directory while displaying the requested path and canonical target.

## System Context

OpenClaw turns a host-command request and its configured exec policy into an approval plan, then revalidates the approved working directory before running the command. This PR changes the path-hardening decision for trusted symlinked working directories and exposes both path spellings to the approver.
