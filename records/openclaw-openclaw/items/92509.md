- **[P2] Inspect checkpoint results before proceeding:** `extensions/memory-core/src/memory/manager-sync-ops.ts:2802`
  - body: `wal_checkpoint(TRUNCATE)` returns a result row that indicates whether the checkpoint was blocked and how many frames were checkpointed. Calling it through `exec()` discards that row, so this path can continue after a busy/incomplete checkpoint and still leave the just-published meta vulnerable to a crash before close. Use a result-reading call and handle busy or remaining frames deliberately.
