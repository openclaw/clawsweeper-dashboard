Full review comments:

- **[P1] Inspect checkpoint completion before treating it as durable:** `extensions/memory-core/src/memory/manager-sync-ops.ts:2802`
  - body: `DatabaseSync.exec()` discards the row returned by `PRAGMA wal_checkpoint(TRUNCATE)`, but SQLite reports a busy flag when a TRUNCATE checkpoint is blocked or incomplete. A busy checkpoint would fall through here as success, so a crash before `closeMemoryDatabase()` can still leave the just-published metadata only in the WAL. Use `prepare(...).get()` or a shared helper and handle nonzero busy or incomplete counts before claiming the metadata is durable.
