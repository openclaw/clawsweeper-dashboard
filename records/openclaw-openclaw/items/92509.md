## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Checkpoint the live database publish path:** `extensions/memory-core/src/memory/manager-sync-ops.ts:2867`
  - body: On current main, `writeMeta()` is called while `this.db` is the shadow reindex database, then that handle is closed before `publishMemoryDatabaseTables()` copies metadata into the live per-agent DB. A hard kill before the close never publishes the shadow DB, and a hard kill after publish concerns `targetDb`, so this checkpoint does not protect the reported live metadata window. Move the durability checkpoint to the live publish/WAL maintenance path and prove that path.
  - confidence: 0.88
- **[P2] Check whether the checkpoint actually completed:** `extensions/memory-core/src/memory/manager-sync-ops.ts:2867-2872`
  - body: SQLite reports a blocked FULL/RESTART/TRUNCATE checkpoint through the result row, but `exec()` discards that row and the code still sets `lastMetaSerialized`. If the checkpoint is busy, a later identical metadata write can be skipped until close, recreating the crash window this patch is meant to close. Use a helper that reads the PRAGMA result or avoid caching the metadata as durable when checkpoint completion is unknown.
  - confidence: 0.82
