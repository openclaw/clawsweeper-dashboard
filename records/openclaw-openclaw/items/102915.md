## Repair Work Prompt

Fix the event-loop blocking in `stripDisallowedChatControlChars` for large chat messages. Keep the behavior contract unchanged: normalize input to NFC, reject null bytes with the existing error, preserve tab/newline/carriage return, drop the same disallowed C0/DEL characters, and leave valid Unicode text intact. Prefer a module-level precompiled regex plus a fast path for already-safe strings, following existing runtime-built regex patterns where useful so lint does not see literal control characters. Add focused regression coverage for safe large input and mixed disallowed control characters; include a small benchmark or timer-based test/proof in the PR evidence. Do not add a config option, protocol message-size cap, channel-specific behavior, or CHANGELOG.md edit; put any user-visible performance note in the PR body.
