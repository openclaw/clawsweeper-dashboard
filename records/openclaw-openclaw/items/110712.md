## Summary

Keep this PR open: the revised chunked loop prevents whole-buffer allocation but still synchronously hashes every byte of an arbitrarily large approval operand on the node-host hot path, so the reported event-loop availability problem remains; the posted evidence is unit/CI-only.

## What This Changes

The branch replaces whole-file approval-operand hashing with descriptor-based 64 KiB chunked synchronous hashing and adds 8 MiB boundary tests.

## Best Possible Solution

Keep approval binding, but move large-operand fingerprinting off the synchronous approval path or adopt an explicitly approved finite compatibility policy that cannot monopolize the node-host event loop.
