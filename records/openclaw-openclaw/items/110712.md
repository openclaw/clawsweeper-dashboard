## Summary

Keep this PR open for maintainer review: it removes the unbounded approval-path read using the repository’s regular-file helper, but the new unconditional 8 MiB denial changes approval behavior for existing large script operands and needs an explicit security/compatibility decision plus end-to-end after-fix evidence.

## What This Changes

The PR caps approval-time script operand reads at 8 MiB via `readRegularFileSync` and returns a `SYSTEM_RUN_DENIED` result when the operand cannot be safely fingerprinted.

## Best Possible Solution

Keep the bounded regular-file read, confirm that a global 8 MiB approval limit is the intended security policy, and add redacted end-to-end proof for both oversize denial and a successful in-limit approved script execution.
