## Label Justifications

## Summary

This PR remains necessary and appears to be a sound, narrowly scoped availability hardening: it removes the synchronous whole-file allocation from the approval path while retaining large-script approval binding and revalidation. No new discrete patch defect was identified; proceed through normal maintainer review and exact-head merge/check gating.

## What This Changes

The branch converts node-host approval-script operand hashing, snapshotting, and revalidation from synchronous whole-file reads to asynchronous streamed SHA-256 hashing, then awaits that boundary at the affected invoke callers and tests.

## Best Possible Solution

Land the streamed-hash implementation after normal exact-head maintainer and required-check gating, keeping the existing canonical approval-plan and pre-execution drift-denial contract intact.
