## What This Changes

The branch classifies the exact `openclaw config file` command as a read-only query so it returns the selected config path without validating config, loading plugins, creating CLI paths, or starting proxy setup.

## System Context

OpenClaw’s CLI resolves a command path before Commander runs the selected command, then applies startup policy such as config validation, plugin loading, state initialization, and proxy setup. `config file` only needs the profile-aware path resolver, so the change keeps the query outside side-effecting startup work.
