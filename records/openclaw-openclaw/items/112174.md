## Summary

Keep this PR open, but it is not ready to merge: the new broad Chinese patterns classify explicit weekly and monthly quota exhaustion as a short transient limit, so the retry path can keep retrying the same unavailable model instead of using the existing fallback. The reported provider case is useful, but the classifier needs to preserve long-window quota semantics first.

## What This Changes

The PR expands Chinese rate-limit text matching so localized provider errors use same-model retry, with a new focused classifier test file.

## Best Possible Solution

Recognize localized temporary throttling without treating quota-period exhaustion as transient: classify explicit weekly/monthly or distant-reset caps as long-window (or leave them eligible for fallback), and add boundary tests for both short and long localized messages.
