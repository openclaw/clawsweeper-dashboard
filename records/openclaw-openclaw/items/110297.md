## What This Changes

The branch removes heuristic aggregate, preflight, and tool-loop overflow short-circuits, then records final provider-request identities so retries stop only after a byte-identical payload has actually been context-rejected.

## Best Possible Solution

Adopt one provider-authoritative overflow policy for the embedded agent runner, retaining local estimates for shaping and diagnostics while preserving bounded recovery after an actual provider rejection and validating the final merge result on the Gateway scenario.
