## Summary

This PR has strong real-behavior evidence for the provider-authoritative recovery policy, but it still exposes caller-owned overflow recovery through the public session SDK without an established contract for non-embedded callers. The protected `maintainer` label and the unresolved API boundary require maintainer direction before merge.

The branch removes synthetic context-overflow recovery from heuristic prompt-pressure gates, adds provider-request replay protection, and routes bounded provider-rejection recovery through the embedded runner.
