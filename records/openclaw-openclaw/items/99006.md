## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Preserve date-qualified transcript identity:** `src/state/openclaw-state-schema.sql:1229`
  - body: Current transcript storage supports the same human session id on different days and requires `YYYY-MM-DD/<session>` selectors for disambiguation, but this schema makes `session_id` the sole primary key. A second `standup` session would overwrite or conflict with the first, so the SQLite path would lose the existing dated identity contract.
  - confidence: 0.95
- **[P1] Keep DB-backed summaries on the DB path:** `src/transcripts/store.ts:287`
  - body: For DB-backed sessions, `readSessionEntry` returns a computed `sessionDir`; existing summarize callers treat any `sessionDir` as a signal to read `transcript.jsonl`. A stored SQLite session would therefore summarize an empty or stale file path instead of the DB utterances.
  - confidence: 0.91
- **[P1] Wire SQLite through real transcript flows:** `src/transcripts/store.ts:143-147`
  - body: The backend only runs when a caller passes a `DatabaseSync`, but the production transcript tool and auto-start service still construct `TranscriptsStore` with only the state directory. Real start/import/stop/summarize flows continue using files, so the PR does not implement primary SQLite storage yet.
  - confidence: 0.93
- **[P2] Use the generated Kysely state database path:** `src/transcripts/store.ts:159-166`
  - body: These raw `DatabaseSync` helpers bypass the existing shared state DB lifecycle and generated Kysely query helpers, leaving the new generated table types unused and making schema drift or caller-supplied handles easier to miss.
  - confidence: 0.84
- **[P2] Remove or implement the summaries table:** `src/state/openclaw-state-schema.sql:1263-1264`
  - body: The PR adds a durable `transcript_summaries` table, but the store never writes or reads it and still persists summaries only as files. Either wire the table into the canonical read/write path or leave it out until the summary storage contract is chosen.
  - confidence: 0.87
