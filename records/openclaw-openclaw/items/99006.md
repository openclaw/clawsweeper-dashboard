## Summary

Keep this PR open: the current head still changes the runtime authority before a verified legacy import, and the Doctor importer does not fence concurrent legacy writers. The earlier migration-readiness concern therefore remains unresolved in a different form, while the submitted proof exercises only tests rather than the new SQLite upgrade path.

## What This Changes

The PR adds shared-state SQLite tables for meeting-capture transcripts, switches production transcript callers to SQLite when available, and adds a Doctor importer for legacy filesystem sessions.

## Best Possible Solution

Use one canonical SQLite runtime backed by a persistent pending-legacy check and a retry-safe, exclusive Doctor migration that claims, imports, verifies, and records completion before normal transcript reads or writes are enabled; keep only summary exports as named filesystem artifacts.
