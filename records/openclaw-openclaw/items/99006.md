## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.84

Full review comments:

- **[P2] Preserve original ids for directory-based SQLite reads:** `src/transcripts/store.ts:365-368`
  - body: `sessionDir()` stores a safe filesystem segment, but the SQLite rows keep the original `sessionId`. When a session id contains characters sanitized by `safeSegment`, `readUtterancesFromSessionDir()` queries with the directory basename and returns no rows, so summarize/stop flows can produce empty summaries for valid sessions. Resolve the row from metadata/session identity instead of treating the safe path segment as the database id.
  - confidence: 0.86
- **[P2] Use the shared typed state DB layer:** `src/transcripts/store.ts:159-171`
  - body: The new runtime CRUD path prepares raw SQL strings directly on `DatabaseSync`, bypassing the repository's typed Kysely/state DB helpers. Route these queries through the shared state DB layer so schema types, transactions, connection pragmas, and future migrations stay consistent.
  - confidence: 0.82
- **[P2] Do not ship an unwritten summary table:** `src/state/openclaw-state-schema.sql:1268-1280`
  - body: The PR adds a durable `transcript_summaries` table, but the store explicitly keeps summary writes file-only and never inserts rows. Either persist summaries through this table when a DB handle is supplied or remove the table until a real read/write path exists, otherwise the schema advertises a migration contract that runtime never honors.
  - confidence: 0.8
