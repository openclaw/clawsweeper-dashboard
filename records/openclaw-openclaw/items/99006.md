  - body: The production factory catches every shared-state database open failure and silently restores the legacy file store.   - confidence: 0.96

  - body: `sqliteReadReady` is set only on the temporary store used by Doctor and is lost when production constructs another store or the process restarts. Record verified migration completion durably and gate every runtime instance from that state.
