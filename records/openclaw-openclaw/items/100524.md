## Summary

Keep open. The PR is focused, but it is not merge-ready because it converts non-ENOENT transcript read failures into successful partial transcript reads, while current Node/readline behavior already rejects those failures cleanly instead of crashing the process.

## What This Changes

The PR refactors `TranscriptsStore.readUtterancesFromDir` bounded JSONL reading to event listeners that return parsed utterances on stream/readline errors and adds a mocked regression test.

## Best Possible Solution

Keep ENOENT-as-empty and robust cleanup, but reject or otherwise surface non-ENOENT stream/readline failures so stop/summarize does not persist a partial summary as success.
