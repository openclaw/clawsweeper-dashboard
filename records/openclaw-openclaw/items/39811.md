## Summary

Keep open: current main has model-fallback notices and static retired-model suppression checks, but arbitrary configured model refs that are absent from the runtime/provider catalog still are not generally validated by `openclaw config validate` or doctor.

## What This Changes

The issue requests provider/catalog validation and visible fallback diagnostics for configured model references that point to nonexistent or legacy model names.

## Best Possible Solution

Keep the issue open until a maintainer-approved advisory validation path lands for `openclaw config validate` and doctor, preserving forward-compatible/custom models as warnings unless maintainers explicitly choose fail-closed behavior.

- **Keep suppression-only checks:** Continue rejecting only known retired/suppressed models and rely on runtime fallback notices for other catalog misses.
