## Summary

Keep open. Current main still lacks a Discord autoThread starter-versus-follow-up mention gate, while the related closed PR explicitly left this autoThread bypass semantics unresolved.

## What This Changes

The issue requests Discord thread mention-gating behavior that admits the thread starter without a mention, then requires explicit mentions for follow-up replies in the auto-created thread.

## Best Possible Solution

Define an additive Discord-owned autoThread follow-up mention policy that preserves current defaults, documents the new config shape, and coordinates with the broader parent/thread override design.
