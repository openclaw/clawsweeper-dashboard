## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, the requested thread-reply gate is absent from the Discord config type/schema, and the related implementation PR was closed unmerged while the nearby open issue asks for different parent/thread semantics.

## What This Changes

Requests an opt-in Discord mention policy that can answer autoThread starter messages without a mention while requiring explicit mentions for later replies in the created thread.

## Best Possible Solution

Define an additive Discord-owned autoThread follow-up mention policy that preserves current defaults, documents the config shape, and coordinates with the separate parent/thread override design in https://github.com/openclaw/openclaw/issues/75938.
