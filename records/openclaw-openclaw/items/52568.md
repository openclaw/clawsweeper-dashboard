## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, lack the requested follow-up-reply mention gate, and the overlapping thread override work does not safely close this distinct API/default decision.

## What This Changes

Add a Discord per-channel option so autoThread starter messages can trigger without a mention while later replies in that thread require an explicit mention.

## Best Possible Solution

Add an additive, default-preserving Discord-owned thread-reply mention policy, ideally aligned with the Slack explicit-thread-mention pattern or a clearly documented per-channel equivalent, and coordinate it with the broader parent/thread override design.
