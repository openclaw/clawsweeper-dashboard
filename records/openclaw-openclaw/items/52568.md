## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, lack the requested thread-reply mention-gate config, and the closest implementation PR was closed unmerged while the remaining API shape needs maintainer direction.

## What This Changes

Request adds a Discord configuration policy so autoThread can respond to the starter without a mention but require explicit mentions for follow-up replies in that thread.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy, likely aligned with the existing Slack explicit-mention pattern or a clearly documented per-channel variant, while preserving current defaults and coordinating with the parent/thread override design.

- **Keep current autoThread continuation:** Decline a new Discord config surface and document that bot-owned autoThreads intentionally continue without mentions.
