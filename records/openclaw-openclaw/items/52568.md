## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, lack the requested thread-reply mention-gate config, and the remaining API shape needs maintainer direction.

## What This Changes

Request an opt-in Discord channel setting that lets autoThread starter messages run without a mention while requiring explicit mentions for later replies in the created thread.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy, likely aligned with the existing Slack explicit-mention pattern or a clearly documented per-channel variant, while preserving current defaults and coordinating with the parent/thread override design.
