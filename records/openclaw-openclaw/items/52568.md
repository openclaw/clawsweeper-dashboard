## Summary

Keep open. Current main and v2026.6.11 still preserve the Discord bot-owned autoThread mention bypass, lack the requested starter-versus-follow-up thread mention config, and the related parent/thread override work leaves this narrower policy decision unresolved.

## What This Changes

Add a Discord channel option that lets bot-created autoThread starter messages be handled without a mention while requiring explicit mentions for later replies in that thread.

## Best Possible Solution

Add an additive Discord-owned thread-reply mention policy, likely aligned with the existing Slack explicit-mention pattern or a clearly documented per-channel variant, while preserving current defaults and coordinating with https://github.com/openclaw/openclaw/issues/75938.
