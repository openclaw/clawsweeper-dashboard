## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass and do not expose a thread-reply-specific Discord mention gate, so the remaining work is a compatibility-sensitive config/API decision rather than cleanup closure.

## What This Changes

Request adds Discord per-channel behavior so bot-created autoThreads can answer the starter message without a mention while requiring explicit mentions for later thread replies.

## Best Possible Solution

Add an additive, default-off Discord-owned thread-reply mention policy aligned with the shipped Slack explicit-mention pattern or a clearly documented Discord variant, while preserving existing autoThread defaults.
