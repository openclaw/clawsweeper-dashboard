## Summary

Keep open: current main and v2026.6.11 still admit bot-owned Discord autoThread follow-up replies without a mention, and the missing opt-in thread-reply gate is a public config/product decision rather than cleanup.

## What This Changes

The issue requests a Discord per-channel option that lets autoThread starter messages run without a mention while requiring explicit mentions for later replies in the created thread.

## Best Possible Solution

Add an additive Discord-owned thread-reply mention policy, likely aligned with the existing Slack explicit-mention pattern or a clearly documented per-channel variant, while preserving current defaults and coordinating with the parent/thread override design.
