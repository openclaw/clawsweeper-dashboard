## Summary

Keep open. Current main and v2026.6.11 still lack a Discord thread-reply mention-gate config, and the closest related issue is broader parent/thread configuration work that does not settle bot-owned autoThread follow-up semantics.

## What This Changes

The issue requests an opt-in Discord channel config that allows autoThread starter messages without a mention but requires explicit mentions for later replies in the created thread.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy, aligned with the existing Slack explicit-mention pattern or a documented parent/thread override, while preserving current defaults and adding focused config, preflight, docs, and regression coverage.
