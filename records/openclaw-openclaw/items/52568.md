## Summary

Keep open. Current main and v2026.6.11 still preserve the bot-owned Discord autoThread mention bypass and expose no thread-reply-specific mention gate; related broader thread config work overlaps but does not replace this autoThread starter-versus-follow-up policy request.

## What This Changes

Request an opt-in Discord per-channel config option that lets an autoThread starter message trigger without a mention while requiring explicit mentions for later replies in that thread.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy that preserves current defaults, coordinates with the broader parent/thread override design, and includes config/schema/docs plus focused preflight regression coverage.
