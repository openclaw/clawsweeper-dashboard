## Summary

Keep open. Current main and v2026.6.11 still lack the requested Discord autoThread follow-up mention gate, and the open/closed related work covers overlapping but different parent-thread semantics rather than this starter-versus-follow-up policy.

## What This Changes

Request adds a Discord per-channel option so autoThread starter messages can trigger without a mention while later replies in that thread require an explicit mention.

## Best Possible Solution

Add an additive, default-off Discord-owned thread-reply mention policy that preserves existing autoThread defaults and coordinates with the broader parent/thread requireMention design.

- **Keep current continuation:** Decline new Discord config surface and document that bot-owned autoThreads intentionally continue without mentions after the starter message.
