Keep open. Current main and v2026.6.11 still preserve Discord's bot-owned autoThread mention bypass, and the related Discord thread override work only partially overlaps because it does not add this starter-versus-follow-up gate.

## What This Changes

Request to add Discord thread-reply mention gating so autoThread starter messages can be accepted without a mention while follow-up thread replies require an explicit mention.

## Best Possible Solution

Define an additive Discord-owned thread-reply mention policy that can opt bot-owned autoThread follow-ups into mention gating while preserving current defaults and coordinating with the general thread override request.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers choose the public API. The safest direction is an additive opt-in Discord policy, not an unconditional default change or the closed general thread override PR alone.
