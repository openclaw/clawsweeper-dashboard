## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, lack a thread-reply-specific Discord mention gate, and the closest implementation PR was closed unmerged while the public API/default behavior remains a maintainer product decision.

## What This Changes

The issue requests a Discord per-channel option that lets autoThread starter messages trigger without mention while requiring explicit mentions for later replies in the spawned thread.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy, likely aligned with the existing Slack explicit-mention pattern or a clearly documented per-channel variant, while preserving current defaults and coordinating with the parent/thread override design.
