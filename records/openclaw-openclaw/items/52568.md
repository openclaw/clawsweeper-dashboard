## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, lack the requested thread-reply mention-gate config, and the remaining API/default semantics need maintainer product direction.

## What This Changes

The issue requests Discord thread-specific mention gating so autoThread can answer a thread starter without responding to every follow-up unless explicitly mentioned.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy, likely aligned with the existing Slack explicit-mention pattern or a clearly documented per-channel variant, while preserving current defaults and coordinating with the parent/thread override design.
