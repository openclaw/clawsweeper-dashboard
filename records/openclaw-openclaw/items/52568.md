## Summary

Keep open. Current main and v2026.6.11 still preserve Discord's bot-owned autoThread mention bypass, and the related thread-override issue only partially overlaps because it does not settle this starter-versus-follow-up policy.

## What This Changes

Request a Discord mention policy that lets `autoThread` start from unmentioned parent-channel messages while requiring explicit mentions for later replies inside the created thread.

## Best Possible Solution

Define an additive Discord-owned thread-reply mention policy that can opt bot-owned autoThread follow-ups into mention gating while preserving current defaults and coordinating with the broader thread-specific configuration issue.

## Reproduction Assessment

Yes, source-level. Current main resolves bot-owned autoThread threads to no mention requirement before the no-mention drop path, so unmentioned follow-up replies are admitted.

## Solution Assessment

Unclear until maintainers choose the public API. The safest direction is an additive opt-in Discord policy, not an unconditional default change or the broader ordinary-thread override alone.
