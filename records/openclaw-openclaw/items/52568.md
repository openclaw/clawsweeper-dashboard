## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, there is no Discord thread-reply mention-gate config, and the closest related work is an open broader issue plus a closed unmerged PR rather than an implemented fix.

## What This Changes

Request an opt-in Discord channel config that lets an auto-thread starter message run without a mention while requiring explicit mentions for follow-up replies in the created thread.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy, aligned with the existing Slack explicit-mention pattern or a documented parent/thread override, while preserving current defaults and adding focused config, preflight, docs, and regression coverage.
