## Summary

Keep open. Current main and v2026.6.11 still preserve Discord bot-owned autoThread mention bypass, Discord has no thread-reply-specific mention gate, and the remaining choice is a compatibility-sensitive public config/API decision rather than a safe cleanup close.

## What This Changes

Request an additive Discord channel policy/config option so bot-created autoThread starter messages can pass without a mention while later thread replies require an explicit mention before model dispatch.

## Best Possible Solution

Add an opt-in Discord-owned thread-reply mention policy aligned with the shipped Slack explicit-mention pattern or a clearly documented per-channel variant, preserving current defaults and coordinating with the broader Discord thread override design.
