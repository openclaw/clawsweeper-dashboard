## What This Changes

Fix Responses streaming tool-call association so argument deltas remain attached when a provider rotates per-event item IDs but keeps the output index stable.

## Best Possible Solution

Treat a registered output index as authoritative when only item_id rotates, preserve rejection for conflicting call_id or genuine active-index reuse, and add focused regression coverage for rotated IDs, interleaved calls, and collision safety.
