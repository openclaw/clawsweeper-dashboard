## Summary

This issue should remain open: current main still rejects indexed argument events when their item identity changes, while the report provides a concrete provider capture showing that this drops every tool-call argument delta for an active GitHub Copilot model.

## What This Changes

Fix Responses streaming so tool-call argument events remain associated by their stable output index when a provider rotates per-event item IDs.

## Best Possible Solution

Treat an already-bound `output_index` as authoritative for indexed argument events, preserve identity conflict checks for unindexed candidate matching, and add regression coverage for rotating IDs, parallel calls, and mismatched omitted-index events.

## Solution Assessment

Yes, with a narrow boundary: trust an already-registered output index for indexed events while retaining identity checks for events without an index. Globally disabling identity conflict detection would be broader and less safe.
