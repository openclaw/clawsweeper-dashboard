## Summary

Keep open: current main still has source-level paths where legacy migration warnings can persist after a successful import, and gateway startup refuses readiness on any startup migration warning. The protected `maintainer` label also makes this a human-handled item rather than conservative cleanup.

## What This Changes

The issue asks for legacy state migration to converge when a legacy source remains beside an existing `.migrated` archive or an imported Codex binding sidecar has no resolvable owner.

## Best Possible Solution

Add a tested idempotent retirement rule for successfully imported legacy sources, including archive-collision and imported ownerless Codex sidecars, while keeping true conflicts as blocking warnings.
