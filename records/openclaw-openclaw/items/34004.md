## Summary

Keep open: current main and the latest release still expose Discord status/activity controls through `setPresence` and auto-presence, but they do not implement the requested bot self-only nickname/avatar self-profile action or `channels.discord.actions.selfProfile` gate. The remaining work is a security-sensitive product/API decision, not conservative cleanup.

## What This Changes

The issue requests a Discord-only, default-off `self-profile` action for bot self nickname, avatar, status, and activity updates with strict self-scope and account-routing safeguards.

## Best Possible Solution

Keep this as the canonical Discord self-profile decision item until maintainers approve or reject a Discord plugin-owned, default-off profile mutation contract with explicit account routing, self-only checks, media validation, docs, tests, and live Discord proof.
