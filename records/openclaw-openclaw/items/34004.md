## Summary

Keep open: current main and v2026.6.11 still lack a Discord bot self-profile action, `channels.discord.actions.selfProfile` gate, and nickname/avatar mutation path. Existing static presence, auto-presence, and gated `set-presence` cover only the status/activity subset, so this remains a Discord product and security-boundary decision.

## What This Changes

Request to add a gated Discord bot self-only profile update capability for nickname, avatar, and status/activity with validation, multi-account safeguards, and partial-result handling.

## Best Possible Solution

Approve or reject one Discord plugin-owned self-profile contract, preferably aligned with the existing `set-profile` action pattern if maintainers accept it, with a default-off gate, explicit account/guild handling, strict self-only and owner-scope checks, avatar validation, docs, focused tests, and live Discord proof.
