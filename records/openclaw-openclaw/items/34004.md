## Summary

Keep open: current main and v2026.6.11 still lack the requested Discord self-profile mutation path. Existing Discord support covers static config, auto-presence, and gated `set-presence`, while nickname/avatar mutation and a dedicated default-off self-profile/profile gate remain a product and security-boundary decision.

## What This Changes

The issue requests a gated Discord bot self-profile action for self-only nickname, avatar, status, and activity updates with validation, account scoping, and partial-result behavior.

## Best Possible Solution

If maintainers approve the capability, implement it in the Discord plugin using the existing `set-profile` action pattern or an explicitly approved `self-profile` alias, default it off, enforce owner/self/account checks, validate avatar inputs, document the config, and require focused tests plus live Discord proof.
