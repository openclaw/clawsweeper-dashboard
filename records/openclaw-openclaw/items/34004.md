## Summary

Keep open: current main and v2026.6.11 still lack the requested Discord `self-profile` action, `channels.discord.actions.selfProfile` gate, nickname/avatar mutation path, self-only target checks, and partial-result behavior. Existing static presence, auto-presence, and gated `set-presence` action only cover the status/activity subset, so this remains a product and security-boundary decision.

## What This Changes

Add a Discord-only `self-profile` message action for bot self-only nickname, avatar, status, and activity updates behind a default-off `channels.discord.actions.selfProfile` gate.

## Best Possible Solution

Keep this as the canonical Discord self-profile decision item until maintainers approve or reject a Discord plugin-owned, default-off, self-only action/API with account scoping, validation, docs, tests, and live Discord proof.
