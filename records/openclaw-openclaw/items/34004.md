## Summary

Keep open: current main and v2026.6.11 still lack the requested Discord self-profile capability for nickname/avatar mutation, `channels.discord.actions.selfProfile`, self-only target checks, and partial-result behavior. The shipped Discord work covers presence/status only, and the remaining work is a security-sensitive Discord identity mutation decision rather than a stale or implemented issue.

## What This Changes

Add a Discord bot self-only profile update action and config gate for nickname, avatar, status/activity, explicit account routing, validation, and optional partial results.

## Best Possible Solution

Keep this as the canonical Discord self-profile decision item until maintainers approve or reject a Discord plugin-owned, default-off, self-only profile contract, preferably aligned with the existing `set-profile` action pattern if that remains the canonical cross-channel shape.
