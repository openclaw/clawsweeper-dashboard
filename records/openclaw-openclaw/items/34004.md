## Summary

Keep open: current main and v2026.6.11 still lack the requested Discord `self-profile` action, `channels.discord.actions.selfProfile` gate, nickname/avatar mutation path, self-only target checks, and partial-result behavior. Existing static presence, auto-presence, Matrix self-profile precedent, and gated Discord `set-presence` cover related pieces, but this remains a Discord product and security-boundary decision.

## What This Changes

Request a Discord-only, bot-self-only profile action for nickname, avatar, status, and activity updates behind a default-off action gate.

## Best Possible Solution

Keep this as the canonical Discord self-profile decision item until maintainers approve or reject a Discord plugin-owned, default-off, self-only action/API with account scoping, validation, docs, tests, and live Discord proof.
