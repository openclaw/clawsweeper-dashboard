## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P2] Continue cleanup after webhook stop failures:** `extensions/telegram/src/webhook.ts:1001-1003`
  - body: Catching `shutdown()` at the abort listener logs the rejection, but `shutdown()` still awaits `bot.stop()` before `closeTransportOnce()`. If `bot.stop()` rejects, the new catch runs and the owned Telegram transport/status cleanup below is skipped, so the abort path can still leak the resource this PR is trying to protect. Make shutdown settle each cleanup step, or put transport/status cleanup in a `finally`.
  - confidence: 0.88
- **[P2] Fix the new iMessage child mock types:** `extensions/imessage/src/client.test.ts:20-30`
  - body: `check-test-types` fails on this new mock because `stdin.end` and `child.kill` are assigned plain `vi.fn()` values under overloaded Node stream/child-process types, and `stderr` is set to `null` even though `ChildProcessWithoutNullStreams.stderr` is a `Readable`. Type the fake as a narrow mock shape and cast once at `spawn` instead of mutating the Node interface members directly.
  - confidence: 0.97
- **[P2] Narrow the ClickClack test config before mutation:** `extensions/clickclack/src/gateway.test.ts:301`
  - body: The new test mutates `ctx.cfg.channels.clickclack`, but `ChannelGatewayContext["cfg"]` allows `channels` to be undefined, and CI fails with TS18048 on this line. Keep a typed local config object from the helper or explicitly narrow/non-null the channel config before setting `reconnectMs`.
  - confidence: 0.98
- **[P3] Remove the backoff abort listener after either settle path:** `extensions/clickclack/src/gateway.ts:236-243`
  - body: This adds a new abort listener for every reconnect backoff, but when the timer fires normally the listener is never removed. A long-running gateway with repeated reconnects will retain stale closures on the shared abort signal until shutdown; mirror the websocket cycle's cleanup pattern and unregister the listener once the wait resolves.
  - confidence: 0.82
