## Summary

Keep this PR open: current main still has the teardown sequence the PR addresses, but the new helper does not actually isolate every shutdown phase, so an earlier synchronous cleanup failure can still skip later owned cleanup.

## What This Changes

## Best Possible Solution

Make every ordered teardown phase independently fail-soft, preserve later cleanup after each synchronous or asynchronous failure, and add a regression case for a throwing drain-dispose or equivalent early-phase failure.
