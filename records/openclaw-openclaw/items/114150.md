## What This Changes

The issue requests that a shared-session context engine retain the active heartbeat instruction as the newest non-durable prompt input through preflight, reconstruction, and provider submission.

## System Context

Heartbeats append an active instruction to an agent session and prepare a model prompt before calling the provider. A shared-session context engine may rebuild durable history during that preparation, so the active run boundary must remain distinct from reconstructed durable context.
