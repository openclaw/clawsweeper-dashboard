## Summary

Keep this PR open: it addresses a valid recovery bug, but the timeout fallback can re-enter the same stuck close operation without a bound, and the submitted behavior evidence is mock-only.

## What This Changes

Adds manager-owned ACP runtime force-discard handling for session reset and deletion when bounded cancel or close cleanup times out.

## Best Possible Solution

Provide an atomic manager operation that detaches the cached handle immediately, then performs cancellation and process closing as bounded or fire-and-forget cleanup so reset can always reach fresh ACP state; cover both cancel-timeout and close-timeout paths.
