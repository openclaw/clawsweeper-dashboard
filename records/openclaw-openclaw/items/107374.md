## Summary

Keep open: the earlier bounded-close and stale-actor blockers appear repaired, but this external PR still provides only focused mock-based tests rather than after-fix evidence from a genuinely stuck ACP backend. Adds manager-owned forced ACP runtime detachment, per-session actor-generation retirement and stale-operation fencing, plus reset/delete timeout regression tests.

## Best Possible Solution
