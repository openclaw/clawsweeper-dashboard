## What This Changes

This PR shares concurrent identical Gateway session-catalog reads by request snapshot and replays host-progress events to each requesting connection, keeps Workboard dispatches independent, and also raises the root CLI help process-test timeout.

## System Context

Gateway clients request session catalogs from registered providers; each request builds a session-entry snapshot, streams discovered hosts to its connection, and returns the resulting catalog. This PR changes the shared in-flight read path while Workboard remains a separate gateway consumer whose dispatch commands must retain independent results.
