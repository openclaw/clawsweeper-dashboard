## What This Changes

Coalesces identical concurrent `sessions.catalog.list` Gateway reads by request snapshot, replays per-connection host progress, and leaves mutating Workboard dispatch calls independent.

## System Context

Gateway clients request session catalogs from registered providers; this path emits progressive host updates before returning the final catalog response. The PR shares only identical concurrent read work while preserving each connection’s progress stream and request-owned session-entry view.
