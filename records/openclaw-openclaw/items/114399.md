## Summary

Keep this PR open for maintainer product review. It changes the production-facing Node recommendation and launcher recovery hint from the LTS runtime that OpenClaw installs and tests to Node 26, which is currently an upstream Current release; the supplied benchmark summary does not establish that this is the right long-lived default.

## What This Changes

This PR changes install documentation and the unsupported-runtime `nvm` hint to recommend Node 26 instead of Node 24, while retaining the existing supported ranges and Node 24 installer, CI, and release defaults.

## System Context

OpenClaw’s launcher validates the active Node version and gives an installation hint when it is unsupported. The install documentation then guides users toward a runtime, while the installer and CI define the version that is actually provisioned and continuously exercised.
