## What This Changes

This PR changes OpenClaw’s recommended runtime and fresh macOS/Linux installer target from Node 24 to Node 26, while documenting Windows package-manager and portable-fallback behavior accurately and updating launcher, documentation, and installer tests.

## System Context

This PR aligns those entry points around Node 26 while preserving the supported Node 22, 24, and 25+ ranges and keeping Windows package-manager behavior explicit.
