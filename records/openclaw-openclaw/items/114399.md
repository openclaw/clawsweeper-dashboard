## Summary

Keep this PR open for maintainer review. It changes fresh-install defaults to Node 26 while Node 26 is still the upstream Current line, not LTS; the repository’s current policy and CI/release baseline remain Node 24. It also documents all installers as provisioning Node 26 even though the PR states that Windows package-manager paths still install LTS packages. The existing proof is descriptive rather than inspectable, so it does not yet demonstrate the claimed cross-platform production-default change.

## What This Changes

This PR changes launcher guidance, install documentation, shell and PowerShell installers, and installer tests so OpenClaw recommends or provisions Node 26 instead of Node 24.

## System Context

OpenClaw’s installer scripts choose a runtime for fresh command-line installs, while the launcher and install docs tell users which runtime to use. That selection feeds the CLI and Gateway process, so a default-version change affects fresh provisioning, support expectations, and release validation.
