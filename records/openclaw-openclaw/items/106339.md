The latest head fixes the prior include-target finding and provides convincing CLI proof, but the new warning still fires before final ownership and conflict guards, so an aborted write can falsely tell users that comments will be stripped; the current LOC-ratchet failure also remains unresolved.

## Best Possible Solution
