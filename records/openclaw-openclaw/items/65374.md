## Label Justifications

## Summary

Keep open: current main and v2026.6.11 still group all configured agent ids for a shared memory-core dreaming workspace, ingest those agents' sessions, and write a single workspace-level dreaming corpus; the newest open PR is only a partial candidate and has not landed.

## What This Changes

The issue asks memory-core dreaming to stop pooling transcript snippets across agents and generating first-person dream narratives from another agent's sessions.

## Best Possible Solution

Land or replace a focused memory-core fix that carries the current agent boundary through dreaming ingestion, corpus/recall, ranking, promotion, and repair of existing pooled artifacts, while keeping cross-agent recall as an explicit opt-in surface.
