## Summary

Keep open: current main and v2026.6.11 still resolve all configured agents for a shared memory-core dreaming workspace, ingest those agents' transcripts, and append them into one workspace-level corpus. An open PR now overlaps this bug, but it is conflicting and narrower than automatic shared-workspace isolation, so this issue should stay open until a reviewed fix lands.

## What This Changes

The issue asks for memory-core dreaming to isolate session corpus, recall, and first-person dream synthesis by agent so one agent's sessions cannot become another agent's memories.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/100057 with a reviewed memory-core fix that carries an agent boundary through workspace resolution, session ingestion, corpus reads/writes, recall/ranking, promotion, and cleanup proof.
