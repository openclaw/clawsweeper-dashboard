## Summary

Keep open: current main and the latest release still group agents by shared Dreaming workspace and ingest every resolved agent's session transcripts into one workspace-scoped corpus, while the newer candidate PR is still open and needs maintainer/security review.

## What This Changes

The issue asks OpenClaw to prevent memory-core Dreaming from mixing one agent's session snippets and first-person dream output into another agent's memory path in multi-agent setups.

## Best Possible Solution

Land or replace the open memory-core fix with a default current-agent boundary through Dreaming workspace resolution, session ingestion, recall/ranking, promotion, narrative output, and repair of previously pooled artifacts.
