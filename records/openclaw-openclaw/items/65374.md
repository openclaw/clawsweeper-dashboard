## Summary

Keep open: current main and v2026.6.11 still let memory-core dreaming group agent IDs by shared workspace, ingest every matched agent's sessions, and write them into a workspace-level dreaming corpus. The newer open PR is useful related work but does not yet close the narrowed shared-workspace isolation bug.

## What This Changes

The issue asks memory-core dreaming to stop pooling session snippets across agents and producing first-person dream output from another agent's history.

## Best Possible Solution

Land a security-reviewed memory-core fix that carries the current agent boundary through workspace resolution, session ingestion, corpus/recall, dream narrative, promotion, and repair of already pooled derived artifacts.
