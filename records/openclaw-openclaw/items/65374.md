## Summary

Keep open: current main and the latest release still allow memory-core dreaming to group all agents that resolve to the same workspace and ingest their session transcripts into one workspace-level corpus. An open fix candidate now targets the area, but it is conflicting and carries product/compatibility decisions, so this issue should stay open until that path lands or is replaced.

## What This Changes

The issue requests agent-level isolation for memory-core dreaming so one agent's session snippets cannot be synthesized as another agent's first-person memory.

## Best Possible Solution

Choose the intended isolation contract, then land PR https://github.com/openclaw/openclaw/pull/100057 or a narrower replacement that scopes dreaming session corpus and recall to the owning agent, with same-workspace multi-agent regression coverage and docs/doctor behavior aligned.
