## What This Changes

The branch records whether streamed block replies actually reached the channel, then skips an identical terminal text reply while retaining final fallback delivery after failed, cancelled, or non-text-equivalent block output.

## System Context

The auto-reply dispatcher accepts inbound channel turns, including commands that rewrite a turn into agent work, and sends streamed block output plus any terminal response. This change sits at the delivery-settlement boundary that decides whether the terminal response is still needed by the originating channel.
