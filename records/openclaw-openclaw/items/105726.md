## Summary

Keep open: rejecting cancelled executions is the correct contract, but waiting for process exit leaves abort settlement racing the existing foreground-to-background yield timer, so the patch is not merge-ready.

## What This Changes

The PR changes foreground bash tool cancellation to reject with an AbortError after the killed process exits and updates one test expectation.

## Best Possible Solution

Settle foreground cancellation atomically in the abort handler by clearing the yield timer and rejecting with AbortError before killing the process, while retaining the existing exemption for sessions that have already yielded or backgrounded.
