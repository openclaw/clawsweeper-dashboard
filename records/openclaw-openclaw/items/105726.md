## Summary

Keep this PR open for normal maintainer review: it targets the still-open cancellation bug and the provided current-head history does not show that its fix is already on `main` or superseded by a merged replacement. The branch supplies focused regression coverage and a production-path terminal transcript, but changing a foreground tool abort from a fulfilled result to a rejected `AbortError` warrants final review of the agent-run terminal-state contract and a clean CI head.

## What This Changes

Makes cancelled foreground bash-tool executions clear their pending yield timer and reject with `AbortError` after process finalization, while adding abort and ordinary-execution regression coverage.

## System Context

The agent bash tool starts and supervises shell commands for an agent turn. Its result feeds the agent loop, where a fulfilled tool result permits the next step while an abort rejection terminates the active run.
