## What This Changes

This PR makes a cancelled foreground bash tool call reject with an AbortError after its child process is stopped, and adds regression coverage for the armed yield-timer race.

## System Context

OpenClaw’s agent tool runner starts shell commands and returns either a completed foreground result or a yielded/background session. An agent-run AbortSignal reaches that runner; the resulting tool outcome determines whether the agent loop stops or can continue to later steps.
