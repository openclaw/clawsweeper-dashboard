## What This Changes

This PR makes a cancelled foreground bash-tool execution reject with `AbortError` after its process finalizes, clears the armed yield timer, and adds regression coverage for abort races and backgrounded sessions.

## System Context

The agent runtime passes a run-level `AbortSignal` into tool execution. The bash tool starts and supervises a child process, then returns either a foreground result or a yielded/background session; that outcome feeds the agent loop and determines whether later tool/model steps continue.
