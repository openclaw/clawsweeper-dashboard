## Summary

Keep open: the prior P1 blocker remains because the current head records the abort but does not clear the armed yield timer, so the timer can still resolve a running-session result before the killed process settles; the supplied evidence is also unit-test-only rather than real behavior proof.

## What This Changes

The PR changes foreground bash tool cancellation to reject with an AbortError after the killed process settles and updates an existing cancellation test to expect rejection.

## Best Possible Solution

Make foreground abort atomic by disabling updates, clearing and nulling the yield timer before killing the process, then reject with AbortError after process cleanup; add deterministic race coverage and a redacted live agent or CLI cancellation transcript.
