## Summary

Close: current main makes explicit `provider: "ollama"` calls only to the configured Ollama host or Ollama Cloud endpoint, not to OpenClaw’s DuckDuckGo provider. The remaining choice of any search engine behind Ollama’s own API is upstream-controlled, while OpenClaw now documents the route and lists independently selectable providers such as Brave and SearXNG.

## What This Changes

The issue asks for Ollama web-search selection not to imply a DuckDuckGo-free backend and requests clearer routing documentation or an alternative search-provider path.

## Best Possible Solution

Keep the explicit Ollama endpoint contract, direct users who require a controllable non-Ollama search backend to an independently selected provider such as Brave or SearXNG, and route evidence of Ollama’s internal backend behavior to Ollama upstream.
