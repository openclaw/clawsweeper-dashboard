## Summary

Keep open: current main and v2026.6.11 document reset and compaction controls, but cache-TTL pruning remains request-time, cache-age gated, in-memory, and tool-result-only; the requested conversation-history TTL and explicit prune API still need maintainer product/security direction.

## What This Changes

Request to define session boundaries, make TTL pruning apply during long-running sessions, and add explicit manual prune/reset session controls.

## Best Possible Solution

Define one typed session/context lifecycle contract separating tool-result pruning, conversation compaction, manual reset, TTL/rolling retention, authorization, persistence, recovery, and docs before adding transport endpoints.
