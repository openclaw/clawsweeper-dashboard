## Summary

Keep open: current main defines session lifecycle controls and manual reset/compaction, but `contextPruning.ttl` still only trims old tool results in the in-memory prompt view and there is no explicit prune-context API for normal conversation history.

## What This Changes

Request to define session boundaries and add TTL/manual controls to prune or reset session context without restarting OpenClaw.

## Best Possible Solution

Keep this open for a maintainer-owned session/context design that either adds a typed admin-gated prune contract or clearly documents TTL as tool-result-only and routes remaining control needs to narrower issues.
