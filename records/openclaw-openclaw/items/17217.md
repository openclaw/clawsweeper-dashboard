## Summary

Keep open: current main and v2026.6.11 define session lifecycle/reset controls and document cache-TTL pruning, but the requested wall-clock conversation-history TTL pruning, explicit prune-context contract, and authorized context/session mutation semantics remain unresolved product and security work.

## What This Changes

The issue requests explicit session-boundary documentation, wall-clock TTL pruning of old context, and manual prune/reset APIs for active sessions.

## Best Possible Solution

Define one canonical session/context contract that separates tool-result pruning, conversation compaction, manual reset, TTL or rolling retention, authorization, persistence, recovery, and docs before adding transport endpoints or changing TTL semantics.
