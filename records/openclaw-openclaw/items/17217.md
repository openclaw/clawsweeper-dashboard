## Summary

Keep open: current main and v2026.6.11 define session reset/compaction and document cache-TTL pruning, but the requested wall-clock conversation-history TTL, manual prune-context contract, and authorized session/context mutation semantics remain unresolved product and security work.

## What This Changes

## Best Possible Solution

Define one canonical session/context contract that separates tool-result pruning, conversation compaction, manual reset, TTL or rolling retention, authorization, persistence, recovery, and docs before adding transport endpoints or changing TTL semantics.
