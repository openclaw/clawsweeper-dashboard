## Summary

Keep open: current main and v2026.6.11 define session reset/compaction controls, but they still do not implement wall-clock conversation-history TTL pruning or an explicit prune-context session API; the remaining work is a product and security decision, not cleanup-safe closure.

## What This Changes

The issue requests explicit session boundary documentation, TTL pruning that removes old context mid-session, and manual/API controls to prune or reset session context without restarting OpenClaw.

## Best Possible Solution

Define one canonical session/context contract that separates tool-result pruning, conversation compaction, manual reset, TTL or rolling retention, authorization, persistence, recovery, and docs before adding transport endpoints.
