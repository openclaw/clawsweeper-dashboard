## Summary

Keep open for maintainer follow-up, but this PR should not merge as-is: it fixes the reported wedged-tool masking path by making every Claude active-tool heartbeat passive, which also removes the shipped heartbeat freshness that protects valid quiet Claude-native foreground tools from stuck-session recovery.

## What This Changes

This PR makes `cli_live:tool_running` passive in diagnostic run activity and updates Claude live-session regression tests to expect the heartbeat not to refresh session progress.

## Best Possible Solution

Rework the diagnostic path so wedged Claude tools can age and recover without removing heartbeat freshness for valid quiet foreground tools, then prove both cases with redacted live or packaged-runtime logs.
