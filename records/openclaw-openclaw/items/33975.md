## Summary

Keep open: current main covers the model-attribution half through responsePrefix template variables and fallback notices, but it still has no opt-in approval gate before executing configured model fallbacks.

## What This Changes

Request an opt-in fallback approval mode before configured model fallback, plus visible model attribution in messages.

## Best Possible Solution

Keep existing responsePrefix and fallback-notice visibility; if maintainers accept the control use case, design a default-off per-agent fallback approval policy with timeout and channel-delivery semantics before implementation.
