## Summary

Keep open: current main covers visible model attribution through `messages.responsePrefix` templates, but it still has no approval gate before executing the next configured model fallback, and that remaining behavior needs maintainer product direction.

## What This Changes

Request an opt-in fallback approval mode plus visible model attribution in user-facing messages.

## Best Possible Solution

Keep model disclosure on `messages.responsePrefix`, and define a default-off per-agent fallback approval policy only after maintainers choose the approval route, timeout, fail/proceed behavior, docs, and regression coverage.
