## Summary

Keep open: current main covers the disclosure half through fallback notices and `messages.responsePrefix` model templates, but it still has no approval gate before executing a configured fallback model, so the remaining request needs maintainer product direction.

## What This Changes

The issue requests two opt-in model transparency controls: confirmation before automatic model fallback and visible model attribution on responses.

## Best Possible Solution

Keep model disclosure on existing prefix/status surfaces, and only add fallback approval after maintainers define a default-off per-agent policy with delivery, timeout, resume, docs, and tests.
