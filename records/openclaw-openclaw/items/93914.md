## What This Changes

This PR changes the isolated cron agent watchdog so setup and context phase notifications after runner entry move the run from the fixed pre-execution timeout to its configured job timeout.

## System Context

Isolated cron `agentTurn` jobs start an embedded agent runner and report lifecycle phases to the cron service. The watchdog uses those phases to distinguish a runner that has made progress from one that should be aborted before execution begins.
