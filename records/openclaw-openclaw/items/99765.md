Full review comments:

- **[P1] Restrict transcript paths before reading:** `extensions/transcript-stats/index.ts:292-295`
  - body: This default-on tool lets the model pass `sessionsDir` or `workspaceDir` directly, then reads `.jsonl` files from that path and returns path/session metadata. Derive the transcript root from trusted runtime/session state or require explicit operator-configured roots before exposing this as a bundled tool.
  - confidence: 0.91
- **[P1] Stop exporting nonexistent SDK symbols:** `extensions/transcript-stats/api.ts:2`
  - body: `openclaw/plugin-sdk/plugin-entry` does not export `Type`, so this barrel makes the plugin import fail; the test also imports `PluginRuntime` from this barrel even though it is not re-exported. Import `Type` from `typebox` and export the actual SDK types used.
  - confidence: 0.97
- **[P2] Use the injected filesystem in recent mode:** `extensions/transcript-stats/index.ts:238`
  - body: `loadRecentSessions` accepts `params.filesystem` but calls `filesystem.readFile`, which is not in scope, so `scope: "recent"` cannot work. Use `params.filesystem.readFile` and add recent-scope coverage.
  - confidence: 0.98
- **[P1] Stream and cap transcript scans:** `extensions/transcript-stats/index.ts:367`
  - body: The workspace and agent paths load every selected `.jsonl` file with `Promise.all` and full-file `readFile`, so a large session directory can allocate all transcript bytes at once. Use streaming line readers plus file/count/byte limits before exposing this to agent calls.
  - confidence: 0.88
