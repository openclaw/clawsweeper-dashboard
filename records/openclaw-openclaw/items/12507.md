## Summary

Keep open: current main and v2026.6.11 provide ClawHub advisory verification and trust-card surfaces, but SKILL.md content is still loaded without a mandatory trusted signature/digest gate or settled unsigned capability policy.

## What This Changes

Request to add cryptographic integrity and signature verification for SKILL.md skills, including loader enforcement and unsigned-skill capability policy.

## Best Possible Solution

Define one canonical signed-skill trust model that binds ClawHub or publisher verification to exact loaded contents, persists and reverifies expected state, exposes status, and specifies unsigned, invalid, revoked, or unavailable capability policy with migration.
