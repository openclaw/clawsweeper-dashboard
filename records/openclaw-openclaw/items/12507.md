## Summary

Keep open: current main and v2026.6.11 have advisory ClawHub verification/provenance, but OpenClaw still does not enforce trusted SKILL.md signatures at runtime or define unsigned-skill capability policy.

## What This Changes

Request adds signed SKILL.md integrity verification and degraded capability behavior for unsigned skills across ClawHub distribution and skill loading.

## Best Possible Solution

Keep this as the canonical native skill trust-boundary issue and define a staged design that binds ClawHub verification, persisted expected integrity, loader-time signature checks, unsigned policy, status surfaces, and migration before enforcement.
