## Summary

Keep open: current main has ClawHub verification/provenance and installed artifact hashes, but loaded SKILL.md bytes are still not bound to trusted signatures and unsigned capability policy remains undecided.

## What This Changes

## Best Possible Solution

Define one canonical signed-skill trust model that binds ClawHub or publisher signatures to exact loaded skill contents, persists and reverifies state, exposes status, and specifies unsigned or revoked capability policy with migration.
