## Summary

Keep open: current main has the narrower one-line Telegram collapse summary, but it still does not preserve the completed multi-line progress draft/checklist or accept a `keepOnComplete`-style option. The related one-line-summary request was closed as implemented and explicitly leaves this broader lifecycle/config decision here.

## What This Changes

The issue requests an opt-in Telegram progress-mode setting that preserves the completed progress draft after final answer delivery while sending the final answer as a separate normal message.

## Best Possible Solution

Maintainers should choose the supported finalization shape first: keep the current one-line summary, add a default-off full-draft preservation mode, or design a structured progress-card/checklist contract with retention and redaction rules.
