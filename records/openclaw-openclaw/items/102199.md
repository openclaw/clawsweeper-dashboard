## Summary

Keep open: current main still lacks `streaming.progress.keepOnComplete` or an equivalent full completed-draft retention mode; the existing Telegram path collapses the draft into a compact summary after final delivery, so the remaining work is a Telegram UX/config product decision.

## What This Changes

The issue requests an opt-in Telegram progress-mode setting that preserves the completed progress draft with checklist-style state while sending the final assistant response as a separate normal message.

## Best Possible Solution

Have maintainers choose the Telegram finalization policy first; if accepted, implement a default-off full-draft retention mode with explicit checklist semantics while keeping the current collapse-summary behavior as the default.
