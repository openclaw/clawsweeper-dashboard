## Summary

Keep open: current main and the latest release do not implement the requested opt-in retention behavior. Telegram progress mode sends the final answer separately, but the progress draft is collapsed into a one-line summary or cleared, and the shared streaming config has no `keepOnComplete` option.

## What This Changes

Request to add an opt-in Telegram progress-mode setting that leaves the completed progress draft visible after completion while sending the final assistant response as a separate message, with checklist-style progress updates.

## Best Possible Solution

Have a Telegram owner approve a narrow opt-in progress-retention design that keeps the current default collapse behavior, defines retained content and checklist limits, then implement it in the Telegram plugin with schema, docs, tests, and live Telegram proof.

- **Fold into activity-card design:** Track this as part of a shared structured progress-card/activity API instead of adding a Telegram-only retention knob.

## Solution Assessment

Unclear. The requested opt-in is plausible, but the best fix needs maintainer direction on retention, checklist semantics, security/redaction, and whether this should stay Telegram-specific or become a shared progress-card surface.
