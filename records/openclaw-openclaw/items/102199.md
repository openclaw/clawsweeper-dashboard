## Summary

Keep open: current main now collapses Telegram progress mode to a one-line activity summary after the final answer, but it still lacks the requested default-off full completed progress draft, checklist-state preservation, and `streaming.progress.keepOnComplete` config. This remains a Telegram lifecycle/config product decision, not conservative cleanup.

## What This Changes

The issue requests an opt-in Telegram progress-mode setting that preserves the completed progress draft, including checklist-style state, while sending the final assistant answer as a separate normal message.

## Best Possible Solution

Have maintainers choose the Telegram finalization policy first; if accepted, implement a default-off option that preserves existing defaults and proves full draft/checklist retention plus separate final delivery.
