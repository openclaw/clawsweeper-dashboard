## Summary

Keep open: current main preserves a compact one-line Telegram progress summary after the final answer, but it still does not support an opt-in full completed progress draft/checklist lifecycle or accept `keepOnComplete` config. The remaining work is a Telegram streaming lifecycle/product decision, not conservative cleanup.

## What This Changes

The issue asks for an opt-in Telegram progress mode that leaves the completed progress draft/checklist visible and sends the final assistant reply as a separate normal message.

## Best Possible Solution

Have maintainers choose the Telegram finalization policy first; if accepted, implement a default-off Telegram-owned option that preserves current defaults and updates schema/types, UI hints, docs, tests, and live Telegram proof.
