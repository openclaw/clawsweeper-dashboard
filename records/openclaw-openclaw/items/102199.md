## Summary

Keep open: current main still lacks a Telegram `keepOnComplete` or equivalent progress-finalization option, and current docs/source/tests intentionally collapse the progress window into a compact summary after the final answer. The remaining work is a Telegram lifecycle/config product decision, not conservative cleanup.

## What This Changes

The issue requests an opt-in Telegram progress-mode setting that preserves the completed progress draft while sending the final assistant response as a separate normal message.

## Best Possible Solution

Have maintainers choose the Telegram finalization policy first; if accepted, implement a default-off option that preserves current defaults, updates schema/types/docs/UI hints, and proves the visible Telegram flow with focused tests plus real Telegram evidence.
