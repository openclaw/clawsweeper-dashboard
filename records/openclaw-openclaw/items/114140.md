## What This Changes

This PR adds bounded retry and a sender-facing failure notice for Feishu inbound messages whose reply-session initialization conflict would otherwise be logged and dropped.

## System Context

Feishu events enter `handleFeishuMessage`, which resolves routing and runs either a standard single-agent turn or one turn per configured broadcast agent. Each turn passes through OpenClaw’s channel-inbound runtime and then the Feishu reply dispatcher sends responses back to the originating chat or thread.
