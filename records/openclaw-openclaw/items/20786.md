## Summary

Keep this issue open as the canonical Telegram Business support tracker. Current main still receives/permits the update names only at the delivery layer, but it does not route `business_message` or `business_connection` through Telegram handlers, dedupe/sequencing, durable outbound authority, docs, or a maintainer-approved security model.

## What This Changes

Request to support Telegram Business bot updates so OpenClaw can receive and respond to Business-connected personal-chat messages.

## Best Possible Solution

Ship a refreshed Telegram plugin implementation with explicit Business handlers, Business-aware dedupe/sequencing, durable account-scoped `business_connection_id` authority, focused Telegram tests, docs, and maintainer-approved security behavior.
