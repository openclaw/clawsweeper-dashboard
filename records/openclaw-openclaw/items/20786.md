## Summary

Keep this issue open as the canonical Telegram Business support tracker: current main and the latest release still do not register Business update handlers or model Business payloads in update keys, and the linked implementation attempts are unmerged or need maintainer redesign.

## What This Changes

Request support for Telegram Business `business_connection` and `business_message` updates so Business-connected personal chats can be received and answered through the Telegram plugin.

## Best Possible Solution

Ship a refreshed Telegram plugin implementation that handles Business connect/message lifecycle with account-scoped connection state, DM authorization, dedupe/sequencing, outbound replies, focused tests, and docs.

Yes. Source inspection shows Business update types are present in grammY/default update coverage but current main has no Business update handlers or Business update key/sequencing support; no live Telegram Business probe was run in this read-only review.

## Solution Assessment

No. The issue body's minimal `allowed_updates` fix is too narrow because the current gap is handler routing, account-scoped Business reply state, dedupe/sequencing, access-control behavior, tests, and docs.
