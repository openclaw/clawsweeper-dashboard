## Summary

Keep this open as the canonical Telegram Business support tracker. Current main and the latest release still allow some Business update delivery through grammY defaults, but they do not register Business runtime handlers, model Business payloads in dedupe/sequencing, or define safe outbound business_connection_id authority.

## What This Changes

Requested support for Telegram Business Bot updates so business_message and business_connection updates can be received, routed, and replied to through the Telegram plugin.

## Best Possible Solution

Ship a maintainer-approved Telegram plugin implementation that handles Business connect/disconnect state per account, routes business_message through existing DM authorization and inbound processing, updates dedupe and sequential keys, applies business_connection_id only with correct authority, and documents setup with live Telegram proof.
