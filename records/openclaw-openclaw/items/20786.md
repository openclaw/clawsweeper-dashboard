## Summary

Keep this issue open as the canonical Telegram Business support tracker. Current main and the latest release still lack `business_message` / `business_connection` runtime handling, and the prior same-repo implementation was closed unmerged after security and routing concerns.

## What This Changes

Request support for Telegram Business `business_connection` and `business_message` updates so Business-connected personal chats can be received and answered by the Telegram plugin.

## Best Possible Solution

Ship a maintainer-approved Telegram plugin implementation with per-account durable Business connection state, disconnect cleanup, Business-aware dedupe and sequencing, safe `business_connection_id` injection for supported outbound methods, docs, focused tests, and live Telegram proof.
