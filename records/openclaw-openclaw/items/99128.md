Keep open: current main and the latest release still leave a real documented setup mismatch for Feishu account-id prompting, while the WeCom/Telegram setup portion overlaps an open canonical setup issue and the Telegram reply-target log overlaps a previously shipped fix.

## What This Changes

The issue asks OpenClaw to expose documented multi-account setup/configuration for Telegram, Feishu, and WeCom in the Docker channel setup flow and reports failed threaded replies.

## Best Possible Solution

## Solution Assessment

Unclear as one broad fix. The maintainable path is to keep shared selected-account setup behavior with https://github.com/openclaw/openclaw/issues/79553, decide Feishu setup/docs intentionally, and only reopen the Telegram reply-target path with current-main proof.
