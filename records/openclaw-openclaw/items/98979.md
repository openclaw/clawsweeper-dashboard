Full review comments:

- **[P1] Do not shadow the shared text sanitizer:** `src/shared/text/assistant-visible-text.js:1`
  - body: Adding this `.js` file next to the existing TypeScript module makes `../shared/text/assistant-visible-text.js` resolve to a partial implementation. Current SDK barrels re-export `sanitizeAssistantVisibleText`, `sanitizeAssistantVisibleTextWithProfile`, and `stripToolCallXmlTags` from that specifier, so those imports can fail or lose the canonical sanitizer behavior. Remove the JS shadow or make the build/test path resolve the existing TS module.
  - confidence: 0.94
- **[P2] Preserve the identity helper contract:** `src/shared/assistant-identity-values.js:9-11`
  - body: This branch also shadows `assistant-identity-values.ts`, but the new implementation returns the untruncated value for non-positive or invalid limits. Existing shared tests cover the canonical `slice(0, maxLength)` behavior, so source checkouts can diverge or fail once this file is present. Reuse the existing helper instead of duplicating it in JS.
  - confidence: 0.88
- **[P2] Use an existing Recent translation key:** `ui/src/ui/views/sessions.ts:271`
  - body: The new badge renders `t("sessions.recentShort")`, but the locale bundles only define `recentShort` under `usage.sessions`, and the translator returns the key string when a lookup is missing. Users would see `sessions.recentShort` in the Sessions table; use an existing key or add the proper English source key and regenerate locale output.
  - confidence: 0.9
- **[P3] Style the new row activity states:** `ui/src/ui/views/sessions.ts:926-927`
  - body: The PR adds `session-data-row--active` and `session-data-row--recent` classes, but no CSS selector in the Control UI styles matches them. That means the claimed active/recent row highlighting is not visible to users, and the test only proves a class was added. Add the row/badge styling or remove the unstyled state classes.
  - confidence: 0.82
