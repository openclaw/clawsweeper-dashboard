## Summary

Keep open: current main still has low-level supervisor and scoped process-tool primitives, but it does not expose the requested session-scoped Gateway/RPC/CLI operator surface to list and terminate all exec children for a stored session. The work needs maintainer agreement on the additive API, authorization boundary, and process-tree semantics before implementation.

## What This Changes

Request a session-scoped list/kill surface for exec child processes spawned by a stored OpenClaw session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves the canonical session scope, lists supervisor-owned active exec runs, cancels matching process trees with per-run outcomes and fallbacks, and documents isolation without silently changing sessions.abort/delete defaults.
