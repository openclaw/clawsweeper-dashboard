## Summary

Keep open: current main still lacks the requested session-scoped Gateway/RPC/CLI operator surface to list and terminate child exec processes, while the remaining work needs maintainer product/security design rather than stale cleanup.

## What This Changes

The issue requests a session-scoped command or abort enhancement that lists and terminates child exec processes spawned by a session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves the canonical session scope, lists supervisor-owned active exec runs, cancels matching scopes with per-run outcomes, and documents isolation and partial-failure behavior without changing sessions.abort or sessions.delete defaults.
