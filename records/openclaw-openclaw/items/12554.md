## Summary

Keep open: current main and v2026.6.11 still lack a session-scoped Gateway/RPC/CLI surface to list and terminate exec child processes for a stored session; existing abort, delete, HTTP kill, and agent process-tool paths cover narrower behavior.

## What This Changes

Request a session-scoped operator surface to list and terminate child exec processes spawned by a stored session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves canonical session scope, lists supervisor-owned active exec runs, cancels matching scopes with per-run outcomes and fallback behavior, and documents isolation without silently changing sessions.abort or sessions.delete defaults.
