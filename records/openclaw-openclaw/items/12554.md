## Summary

Keep open: current main and v2026.6.11 still lack a public session-scoped Gateway/RPC/CLI operator to list and terminate exec child processes for a stored session; existing abort, delete, HTTP kill, and process-tool paths cover narrower behavior.

## What This Changes

The issue requests a session-level command or abort enhancement that can list and terminate all active exec child processes spawned by a session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves canonical session scope, lists supervisor-owned active exec runs, cancels matching scopes with per-run outcomes and fallback behavior, and documents isolation without silently changing sessions.abort or sessions.delete defaults.
