## Summary

Keep open: current main still lacks a public session-scoped Gateway/RPC/CLI surface to list and terminate child exec processes for a stored session. Existing `sessions.abort`, `sessions.delete`, the HTTP session kill route, and the scoped agent `process` tool cover adjacent control paths but do not provide the requested operator contract.

## What This Changes

Add a session-scoped operator command or RPC that can list and terminate running child exec processes spawned by a session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves canonical session scope, lists supervisor-owned active exec runs, cancels matching scopes with per-run outcomes and fallback behavior, and documents isolation without silently changing current abort/delete defaults.
