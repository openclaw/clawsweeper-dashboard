## Summary

Keep open: current main still lacks a session-scoped Gateway/RPC/CLI operator surface to list and terminate exec child processes, and the remaining design is process-control and authorization sensitive.

## What This Changes

Request to add session-scoped operator commands or API behavior that lists and terminates exec/system.run child processes spawned by a session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves canonical session scope, lists supervisor-owned active exec runs, cancels matching scopes with per-run outcomes, and documents isolation and partial-failure behavior without changing sessions.abort or sessions.delete defaults.
