## Summary

Keep open: current main and v2026.6.11 still lack a session-scoped Gateway/RPC/CLI surface to list and terminate exec child processes for a stored session; the existing abort, delete, HTTP kill, and agent process-tool paths cover narrower behavior only.

## What This Changes

Add a session-level operator command or RPC that lists and terminates all active exec child processes associated with a session.

## Best Possible Solution

Define an additive, authorization-checked Gateway and CLI session exec-control contract that resolves canonical session scope, lists supervisor-owned active exec runs, cancels matching scopes with per-run outcomes and fallback behavior, and documents isolation without silently changing sessions.abort or sessions.delete defaults.

Likely owner: vincentkoc

Owner confidence: high

Options:

- **Add guarded session exec-control surface (recommended):** Create new additive Gateway/CLI methods for session exec list and kill with explicit operator scope, canonical session resolution, per-run outcomes, and tests for child, PTY, sandbox, and fallback behavior.
- **Extend existing abort/delete semantics:** Add explicit opt-in flags to existing session maintenance methods, preserving current defaults while documenting the stronger kill semantics and upgrade behavior.
- **Defer public operator surface:** Keep the existing agent-scoped process tool only and track orphan/restart cleanup in narrower lifecycle issues until a broader process-control design is ready.

## Reproduction Assessment

Yes, source-level: current main exposes sessions.abort/delete and internal process-control primitives, but no public session-wide exec process list/kill operation. I did not run a live orphan-process scenario in this read-only review.

## Solution Assessment

Unclear until maintainers choose the public API shape and authorization model. The existing supervisor and process-tool primitives are useful building blocks, but exposing them session-wide is a product/security decision rather than a strict bug patch.
