## What This Changes

Adds `min-height: 0` to the chat Markdown Preview sidebar so long preview content can shrink within its flex layout and scroll in the existing content region.

## System Context

The Control UI renders chat detail content, including Markdown previews, in a right-side sidebar shared by browser and native-client web surfaces. The sidebar panel bounds the scrollable content area; if the flex parent cannot shrink, long Markdown can expand the panel instead of producing a usable scrollbar.
