  - body: Current main's `status()` returns `storage: "sqlite"` and `sqlitePath` along with legacy `storePath`, but this branch adds `gatewayTimezone` on the older return shape.   - confidence: 0.92
- **[P1] Use the scheduler's deterministic stagger offset:** `ui/src/ui/helpers/cron-timeline.ts:384-386`
  - body: Runtime scheduling hashes `job.id` to pick a stable offset within `staggerMs`, but the timeline adds `staggerMs / 2` and this helper only receives the schedule. Jobs with default or explicit stagger can be plotted at a minute the gateway will never use.
  - confidence: 0.9
- **[P1] Derive marker state from real job state:** `ui/src/ui/helpers/cron-timeline.ts:536-543`
  - body: This classifies every past marker as `ok` and every future marker as `pending`, ignoring the job/run state already available elsewhere on the Cron page. A failed or skipped run earlier today would render as ok on the timeline.
  - confidence: 0.88
- **[P2] Regenerate translated locale output:** `ui/src/i18n/locales/de.ts:1240-1251`
  - body: The German locale adds English timeline strings while its metadata says there are no fallback keys and all keys are translated. Per the UI i18n guide, regenerate the locale bundles or mark the new keys as fallbacks instead of committing English as translated copy.
  - confidence: 0.86
