Full review comments:

- **[P2] Use real run state for timeline markers:** `ui/src/ui/helpers/cron-timeline.ts:542`
  - body: `getTimelineMarkers` labels every elapsed marker as `ok` from wall-clock position alone.   - confidence: 0.91
- **[P2] Use scheduler-compatible stagger placement:** `ui/src/ui/helpers/cron-timeline.ts:386`
  - body: This applies `schedule.staggerMs / 2` to every cron marker, but runtime scheduling uses a deterministic per-job hashed offset inside the stagger window. Top-of-hour cron jobs can be plotted minutes away from their actual execution slot and misclassified as past or pending.
  - confidence: 0.9
- **[P3] Regenerate non-English timeline labels:** `ui/src/i18n/locales/pt-BR.ts:1230-1240`
  - body: The generated non-English locale bundle adds English timeline strings while its metadata marks the locale fully translated. Regenerate the locale outputs or keep these keys as explicit fallbacks with matching metadata instead of shipping English copy as translated strings.
