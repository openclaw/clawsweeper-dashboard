  - body: This branch adds `gatewayTimezone` on top of the old status shape, but current main's `CronStatusSummary` and `status()` also expose `storage` and `sqlitePath`.   - body: The timeline still approximates cron staggering as `staggerMs / 2`, while runtime scheduling hashes the job id to a stable offset inside the stagger window. That means marker placement and past/pending state can disagree with the actual run time for any staggered cron job.
  - confidence: 0.94
- **[P1] Derive timeline colors from real job state:** `ui/src/ui/helpers/cron-timeline.ts:526-543`
  - body: The new timeline skips disabled jobs and labels every past marker as `ok`, so disabled jobs disappear and failed past runs can be painted green/ok. The requested timeline explicitly needs green/fail/disabled state coding, and current cron UI code already has job-state helpers that should drive this instead of time-of-day alone.
  - confidence: 0.92
- **[P2] Regenerate locale output instead of marking English translated:** `ui/src/i18n/locales/de.ts:1240-1251`
  - body: The generated German bundle now contains English timeline strings, while the matching metadata says there are no fallback keys and all keys are translated. Regenerate or mark these as fallbacks consistently so i18n checks and non-English users do not see incorrectly certified English copy.
