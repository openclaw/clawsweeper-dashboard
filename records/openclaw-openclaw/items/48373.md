## Summary

Keep open: current main and the latest release still route `feishu_doc` `create` through title-only document creation without writing or clearly rejecting supplied `content`, and the linked open implementation PR has not landed in the target repository.

## What This Changes

The issue asks for `feishu_doc` `create` calls that include `content` to avoid silently creating an empty document, either by writing the content or rejecting it clearly.

## Best Possible Solution

Adopt one Feishu plugin contract: preferably support create-time content through the existing write path with explicit partial-failure handling and live Feishu proof, or reject `content` on create with a clear error and matching tests/docs.
