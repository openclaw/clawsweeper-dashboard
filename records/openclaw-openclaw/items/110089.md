## Summary

Keep open for maintainer handling: the patch has focused regression coverage and no concrete correctness defect, but it changes shared microphone readiness from an established permissive fallback to fail-closed behavior that could stall existing talk-back sessions when an adapter cannot observe microphone state.

## What This Changes

The PR preserves transcript cursor continuity across retention gaps, ranks active meeting tabs ahead of sign-in tabs during recovery, and requires verified unmuted microphone state before talk-back becomes ready.

## Best Possible Solution

Keep the centralized cursor and recovery fixes, then land strict microphone readiness only after supported Google Meet and Teams talk-back flows are shown to reach an explicit unmuted state and a focused Teams tab-order test confirms the generic ranking contract.
