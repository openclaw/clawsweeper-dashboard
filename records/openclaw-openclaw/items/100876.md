  - body: This prior blocker remains at the current head. `chat.send` extracts and applies `/model` before `resolveReplyDirectives` can use `command.isAuthorizedSender` to clear unauthorized model directives, so an unauthorized origin can still choose a one-turn model and have the directive stripped instead of treated as plain text. Route this through the existing directive authorization boundary, or leave `oneTurnModelOverride` unset when the sender is not authorized.
  - confidence: 0.9
- **[P1] Keep one-turn overrides from clearing session auth profiles:** `src/auto-reply/reply/model-selection.ts:412-424`
  - body: This prior blocker remains at the current head. The new one-turn branch skips stored model overrides, but it still falls through to the existing auth-profile eligibility cleanup. If a session has an auth profile for its current model and a user sends a one-turn override to a different provider, `clearSessionAuthProfileOverride` can persistently delete that session auth profile, so a supposedly one-shot model switch leaks into later turns. Skip persistent auth-profile cleanup for one-turn overrides or isolate it to temporary run state, and add a regression with an existing `authProfileOverride`.
  - confidence: 0.86
