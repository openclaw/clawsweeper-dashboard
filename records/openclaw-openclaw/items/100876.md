If a session has an auth profile for its current model and a user sends a one-turn override to a different provider, `clearSessionAuthProfileOverride` can persistently delete that session auth profile, so a supposedly one-shot model switch leaks into later turns. Skip persistent auth-profile cleanup for one-turn overrides or isolate it to temporary run state, and add a regression with an existing `authProfileOverride`.
  - confidence: 0.86
