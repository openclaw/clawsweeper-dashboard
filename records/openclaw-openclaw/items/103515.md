  - body: The native `.explicitOnce` path only rejects a current `deny` policy and does not compare the captured policy snapshot used by `.explicitAlways`. A one-shot approval can therefore survive later security, ask, fallback, or allowlist tightening. Validate the same snapshot for explicit-once.
  - confidence: 0.99
- **[P1] Reject native auto-review after policy tightening:** `apps/macos/Sources/OpenClaw/ExecApprovalsStore.swift:945-951`
  - body: The native `.autoReview` path only checks for `deny` and `ask=always`, then returns. Changes from `full` to `allowlist`, `ask=off` to `on-miss`, or removal of the evaluated allowlist basis can still execute under stale automatic approval. Bind it to the evaluated snapshot.
  - confidence: 0.99
