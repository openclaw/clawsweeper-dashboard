## Review Findings

Full review comments:

- **[P1] Canonicalize Codex aliases before local matcher filtering:** `src/plugins/tool-hook-matcher.ts:40`
  - body: A matcher such as `Write`, `Edit`, or `Agent` can match Codex's alias table and launch the relay, but the relay event uses canonical `apply_patch` or `spawn_agent`; this comparison then rejects the event because OpenClaw normalization does not map those aliases. That can silently skip a covered hook or trusted policy, so use one shared canonical alias mapping for both relay installation and local dispatch.
  - confidence: 0.96
- **[P1] Preserve matcher scopes independently for each runtime:** `src/plugins/registry-registrars-tools-hooks.ts:229-232`
  - body: The repeated-registration repair merges every runtime and matcher into one entry. If the same handler is registered as Codex `message`-only and OpenClaw `exec`-only, it subsequently runs for both tools in both runtimes. Store matcher coverage per runtime, or otherwise merge only registrations with the same runtime scope.
  - confidence: 0.97
