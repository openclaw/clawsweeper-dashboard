## Summary

Keep open: this is a fresh, concrete current-main session-setting race, and the protected `maintainer` label requires explicit maintainer handling. Current Control UI state tracks in-flight model changes separately while thinking remains a distinct session patch, which is consistent with the reported stale-model validation failure.

## What This Changes

Ensure model changes complete before model-specific reasoning levels are validated or an immediate message is sent.

## Best Possible Solution

Enforce per-session ordering or atomicity for model-dependent setting mutations at the Gateway boundary, and make every client await pending model and reasoning updates before sending; cover rapid model-plus-reasoning selection and immediate-send behavior with focused regression tests.
