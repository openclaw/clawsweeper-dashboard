## Summary

The updated live-socket proof satisfies the previous proof gate, but merge should pause because the fixed 30-second default can override longer caller or provider deadlines across a public shared reader boundary.

## What This Changes

The PR adds a default 30-second per-chunk idle timeout to shared provider JSON, text, and binary response readers and adds stalled-stream regression tests.

## Best Possible Solution

Keep the shared helper responsible for abort mechanics, but derive or explicitly pass the idle budget from each operation's existing provider/request deadline and test both a stalled body and a legitimately slow body; adopt a universal 30-second ceiling only with explicit owner approval and upgrade documentation.
