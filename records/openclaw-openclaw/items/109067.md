## Summary

This PR has credible real-socket proof for the stalled-body bug, but it still changes every existing shared provider-reader call from unbounded body waiting to a fixed 30-second idle policy without an owner decision on whether that shared default is the intended provider deadline contract.

## What This Changes

The branch adds a default 30-second per-chunk idle timeout to shared provider JSON, text, and binary response readers, with regression coverage for post-header stalled streams.

## Best Possible Solution

Keep the stalled-read protection, but have the agents-area owner choose and document the deadline boundary: retain existing shared-reader behavior and apply idle limits at operation-specific callers, or explicitly adopt a shared timeout contract with caller classification and compatibility coverage.
