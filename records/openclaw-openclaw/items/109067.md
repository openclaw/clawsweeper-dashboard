## Summary

The patch is focused and no discrete correctness or security defect is evident, but this external PR still needs real behavior proof and an explicit owner decision on changing the default behavior of exported provider readers before merge.

## What This Changes

This PR adds a default 30-second idle chunk timeout, an optional timeout override, and stalled-stream regression coverage to the shared provider JSON, text, and binary response readers.

## Best Possible Solution

Keep the shared idle-bound implementation, but merge only after an owner confirms the exported-reader default and a controlled real HTTP proof shows both stalled-body failure and continued success when chunks arrive within the idle budget.
