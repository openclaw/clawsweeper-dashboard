## Summary

Keep open: current main and v2026.6.11 still compose the Claude CLI local credential epoch part alongside the selected auth-profile part, so a local credential source-presence flip can still invalidate live CLI sessions; the direct fix PR is closed unmerged and the broader open PR is conflicting and still product-boundary sensitive.

## What This Changes

The issue reports that `resolveCliAuthEpoch` invalidates live Claude CLI sessions when local credential storage presence changes even though the resolved auth identity is unchanged.

## Best Possible Solution

Land a focused Claude CLI auth/session policy fix that keeps unchanged identity from resetting live sessions across local source-presence flips while preserving resets for logout, real account changes, and unprovable identity changes.
