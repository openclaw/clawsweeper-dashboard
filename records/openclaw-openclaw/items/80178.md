## Summary

Keep open: current main and v2026.6.11 still let Claude CLI auth epochs change when the local credential fingerprint appears or disappears alongside the same selected auth profile, so the reported session invalidation remains possible and needs an auth identity policy decision.

## What This Changes

The issue requests stable CLI auth epochs when a local Claude CLI credential storage source appears or disappears without changing the underlying identity, so live CLI sessions are not invalidated.

## Best Possible Solution

Define and implement a Claude CLI-specific auth-epoch contract that keeps session reuse stable when credential identity is unchanged across storage-source flips, while failing closed on logout, real account changes, or unprovable identity changes.
