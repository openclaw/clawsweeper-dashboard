## Summary

Keep this PR open for maintainer review. The change is internally consistent and preserves pinned and retired Opus references, but it intentionally redirects every existing unversioned `opus` selection to a newer, differently priced/capable model generation; the author is a repository member and the PR carries the protected `maintainer` label, so this needs an explicit owner decision rather than automated cleanup.

## What This Changes

The PR changes the bare Anthropic `opus` alias to Claude Opus 5 in the Anthropic plugin, shared catalog normalizer, published plugin manifest, tests, and provider documentation while retaining explicit Opus 4.x mappings.

## System Context

OpenClaw accepts short Anthropic model references in configuration and model-selection paths, then normalizes them to a concrete provider model before agent and Claude CLI routing. This PR changes what the unversioned family reference selects, while explicit versioned model references continue to select their pinned targets.
