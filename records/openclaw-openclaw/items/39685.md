- **Define Shared Egress Policy (recommended):** Set a cross-tool contract for names, deny precedence, redirects, cache/provider fallback, search providers, browser, and proxy routing before implementation lands.

- **Use Managed Proxy Boundary:** Route application-owned egress policy through proxy.enabled and external operator policy instead of adding local domain firewall knobs to web tools.
