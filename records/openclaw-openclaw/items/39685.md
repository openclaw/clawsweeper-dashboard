Define one maintainer-approved web egress security contract, then land schema, runtime enforcement, cache/provider-fallback behavior, docs, audit output, and upgrade handling around that contract.

- **Use Managed Proxy Boundary:** Treat proxy.enabled and external operator policy as the egress-control owner instead of adding local domain firewall semantics to web tools.

## Solution Assessment

Unclear until maintainers set the boundary. SsrFPolicy.hostnameAllowlist is a good primitive for direct web_fetch, but deny semantics and coverage across search, redirects, cache, provider fallback, browser, and proxy paths need approval.
