The issue requests operator-configurable allowed/denied domain network egress controls for OpenClaw web tools, especially `web_fetch` and `web_search`.

## Best Possible Solution

Define one maintainer-approved web egress security contract, then land schema, runtime enforcement, cache/provider/proxy behavior, audit output, docs, and upgrade handling around that contract.
