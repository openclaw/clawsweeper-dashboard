The issue requests configurable outbound domain allow/deny controls for agent web tools using the existing SSRF policy machinery.

## Best Possible Solution

Define one maintainer-approved web egress security contract, then land schema, runtime enforcement, cache/provider-fallback behavior, docs, audit output, and upgrade handling around that contract.
