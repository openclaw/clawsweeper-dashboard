## What This Changes

Requests operator-configurable allowed and denied outbound domains for OpenClaw web tools, primarily web_fetch and web_search.

## Best Possible Solution

Define one maintainer-approved web egress security contract, then land schema, runtime enforcement, cache/provider-fallback handling, docs, audit output, and upgrade behavior around that contract.

Options:

- **Design Shared Egress Contract (recommended):** Define the cross-tool policy first so web_fetch, search, browser, redirects, cache, provider fallback, and proxy behavior do not ship conflicting guarantees.

- **Use Managed Proxy Boundary:** Make proxy.enabled plus operator-managed proxy policy the owner for app egress and avoid adding local domain-firewall config to web tools.
