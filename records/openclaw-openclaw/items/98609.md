Full review comments:

- **[P2] Handle prompt args before allowlisting Gemini:** `src/process/supervisor/adapters/child.ts:23`
  - body: Adding `gemini` here makes the Gemini backend enter `buildWindowsCmdExeCommandLine`, but that backend passes the user prompt as a `{prompt}` argv value and the Windows command helper throws on newline, `%`, `&`, `|`, `<`, or `>`. Common OpenClaw prompts can contain those characters, so this can still fail before spawning instead of launching the provider. Please route the prompt through a safe Windows-compatible transport or add equivalent handling and regression coverage before allowlisting this prompt-bearing CLI.
