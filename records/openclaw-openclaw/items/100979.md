Reports that Discord outbound messages attempted during a full network outage can be dropped on reconnect because `send_attempt_started` entries are not replayed without unknown-send reconciliation.

## Best Possible Solution

Land a narrow, proof-backed fix that keeps true unknown-after-send cases guarded while making provable pre-dispatch or connect-phase failures replayable, then close this issue from the merged PR.
