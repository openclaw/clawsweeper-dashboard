## Summary

Keep open: current main and v2026.6.11 have a default-off package auto-updater, but they still lack the requested schedule/timezone, confirm or notify-only modes, channel-targeted notifications, and post-restart old/new version plus changelog/health workflow.

## What This Changes

Request adds a first-class `update.auto` workflow with configurable schedule/timezone, confirm/notify-only/silent modes, and post-update notifications.

## Best Possible Solution

Keep this as the canonical updater workflow design item; if accepted, extend the existing `update.auto` and `update.run` path with a default-off schedule/consent/notification contract coordinated with https://github.com/openclaw/openclaw/issues/77511, https://github.com/openclaw/openclaw/issues/14526, and https://github.com/openclaw/openclaw/issues/79170.
