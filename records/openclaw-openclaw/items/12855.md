## Summary

Keep this issue open. Current main and v2026.6.11 ship a useful default-off package auto-updater, but the requested first-class workflow still lacks schedule/timezone selection, confirm or notify-only modes, channel-targeted notifications, and cross-restart old/new version plus changelog and health reporting.

## What This Changes

The issue requests a built-in, configurable auto-update workflow with scheduling, confirmation modes, silent or notify-only behavior, and post-update notifications.

## Best Possible Solution

Keep this as the canonical updater engine/workflow request and design a maintainer-approved, opt-in workflow on the safe update.run or external-updater path with schedule/timezone, confirm or notify-only modes, explicit silent mode, durable restart state, channel targeting, and old/new version plus changelog and health reporting.
