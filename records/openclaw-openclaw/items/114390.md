## Summary

Keep this PR open but do not merge it as written: it treats literal `\n` text as transport escaping and can silently change valid generated file content. The report still needs a fix at the boundary that introduced the regression rather than a global rewrite inside the write tool.

## What This Changes

The PR changes the agent write tool so literal backslash-n sequences in supplied file content become real newline characters before safety checks and writing.

## System Context

The agent write tool receives a model-supplied path and exact text content, checks whether the requested mutation is safe, and writes it to the workspace. The content value is a file-data payload, so changing it affects every generated source, configuration, and text file.
