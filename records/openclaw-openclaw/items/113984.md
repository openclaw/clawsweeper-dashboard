## Summary

This is a narrow correction to the lifecycle cleanup introduced by the merged isolated-run fix: stable `session:<id>` cron targets retain their browser tabs, while detached run-scoped targets still clean up. The branch has strong before/after live Chrome evidence and no concrete patch defect found; keep it open for normal exact-head check completion and maintainer merge review.

## What This Changes

The PR prevents cron lifecycle cleanup from closing browser tabs owned by a stable persistent session, while continuing to close tabs owned by a run-scoped cron invocation.

## System Context

Cron jobs resolve either a stable user session or a detached run session before invoking the agent. The browser plugin records tabs by that resolved session identity, and cron lifecycle cleanup removes tabs only when the invocation’s identity is ending.

## Architecture Diagram

flowchart TD

  E --> F[Browser tab registry]
  F --> G{Invocation identity ends?}

## Best Possible Solution

Keep one lifecycle owner in the isolated cron runner: retain cleanup for run-scoped identities and preserve tracked tabs for stable persistent session targets, with the browser idle sweep handling ordinary persistent-session cleanup.
