## Summary

Keep this PR open for normal merge review. It is a narrow regression repair for the lifecycle cleanup introduced by https://github.com/openclaw/openclaw/pull/113566, and the updated PR body now supplies credible live Chrome evidence that persistent sessions retain their tab while detached runs still clean up.

## What This Changes

The branch skips browser lifecycle cleanup when a cron invocation is using its stable persistent session key, while retaining cleanup for run-scoped cron executions.

## System Context

Cron jobs choose either a durable session identity or a detached run identity before starting an agent turn. The browser plugin records tabs under that exact identity, so cron lifecycle cleanup must remove only identities that end with the invocation and leave durable session tabs available to later runs.

## Architecture Diagram

  E -- Yes --> F[Lifecycle cleanup closes tracked tabs]
