## Summary

## What This Changes

Adds word boundaries around the fallback Gemini CLI OAuth client-ID and client-secret regex matches.

## Best Possible Solution

Replace word boundaries with lookarounds based on each token’s complete accepted alphabet, add focused regression cases for adjacent token characters and terminal `-`, then provide redacted terminal proof against an installed Gemini CLI package without printing credential values.
