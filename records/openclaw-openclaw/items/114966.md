## Summary

This issue is still necessary as a narrow operational-hardening task. Current main already keeps the live mirror clean and the deterministic updater uses frozen installs rather than linking, but the source-install documentation still presents `pnpm link --global` without separating one-time developer setup from unattended source-checkout updates; the reported improvised command therefore remains an avoidable failure path.

## What This Changes

Add explicit source-checkout update guidance that agents must not run `pnpm link` or otherwise mutate `package.json` or `pnpm-workspace.yaml` in a live deployment mirror.

## System Context

The live-updater skill maintains a clean source checkout that feeds the managed Gateway. Its deterministic update path fast-forwards code, installs locked dependencies, builds the checkout, and restarts the Gateway, while the public install documentation separately describes optional source-checkout CLI linking.
