## Summary

This PR addresses the linked failed-delete bug, but it moves an unconditional state clear across an awaited network call, which can erase ownership of a newer preview created while deletion is in flight. The patch also lacks visible after-fix Discord proof, so it is not merge-ready.

## What This Changes

The PR changes shared draft cleanup to retain a preview message ID when deletion fails and adds a unit test that retries the deletion successfully.

## Best Possible Solution

Use compare-and-clear semantics tied to the deleted message ID, add a regression test where the stored ID changes while DELETE is pending, and provide redacted live Discord evidence showing a transient preview-delete failure followed by successful cleanup.
