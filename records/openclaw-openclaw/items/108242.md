The PR adds synchronous and asynchronous bounded-range read helpers, applies them to seven gateway transcript window reads, and adds short-read regression coverage for titles, previews, recent history, and usage snapshots.

## Best Possible Solution

Land one canonical fill-until-EOF-or-window-complete path for every bounded positional transcript read, preserving existing byte budgets and exported contracts with the new short-read regression suite.
