I found no concrete correctness or security defect; the behind-base state and remaining checks require only routine exact-head refresh.

## What This Changes

Makes bounded gateway transcript readers continue across short positional reads until the requested window is filled or EOF, with regression coverage for title, preview, usage, tail, and async reads.

## Best Possible Solution

Land one canonical fill-until-window-or-EOF implementation for each Node filesystem API used here, decoding only the returned byte count and retaining focused short-read coverage across every bounded transcript reader.
