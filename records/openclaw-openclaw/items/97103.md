## What This Changes

The PR makes `openclaw sessions cleanup` preview and report retention-based removal of stale `.deleted.*` and `.reset.*` session archives, including SQLite target resolution and shared-directory coordination.

## System Context

The sessions-cleanup command gathers configured session-store targets, applies retention and disk-budget maintenance, then prints a dry-run or applied summary for operators. This PR connects archived transcript cleanup to that flow through the session-accessor boundary and returns archive counts to the command output.

  F --> G[Dry-run or applied CLI summary]

## Best Possible Solution

Adopt one documented shared-directory ownership policy: keep the conservative skip for single-agent cleanup and clean a shared directory only once when all owners are selected, or add a separately designed ownership-attribution mechanism before enabling selective deletion.
