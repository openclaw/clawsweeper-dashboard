## Summary

Keep open: current main still uses the generic `/plugin` route plus query state for plugin tabs, and the requested dashboard path-segment URL behavior remains a roadmap feature tied to the open modular-dashboard work.

## What This Changes

The issue requests path-segment dashboard URLs so operators can link directly to dashboard tabs and use browser back/forward history normally.

## Best Possible Solution

Coordinate the route shape with the modular-dashboard stack, then add explicit dashboard tab path routing with base-path-safe navigation, backward-compatible handling for existing query links if they ship, and focused routing/sidebar tests.
