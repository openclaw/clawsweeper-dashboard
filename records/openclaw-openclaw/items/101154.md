## Summary

Keep open. Current main only supports generic plugin tabs at `/plugin?plugin=<id>&id=<tab>` and explicitly rejects `/plugin/<tab>`-style path segments; the requested dashboard-tab URL contract is still future product work tied to the open modular-dashboard stack.

## What This Changes

Request to make modular dashboard tabs deep-linkable through path segments with bookmarkable links and browser back/forward history.

## Best Possible Solution

Decide the modular-dashboard product direction first; if accepted, add canonical dashboard-tab path routes in the plugin route/navigation layer with tests for base paths, direct reloads, history navigation, and any needed redirect from the query form used by the proposed UI stack.
