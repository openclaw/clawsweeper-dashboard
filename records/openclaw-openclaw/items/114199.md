## What This Changes

The PR makes ACP session cancellation claim turns during queued and runtime-initialization setup so cancelled turns cannot start backend provider work.

## System Context

ACP is OpenClaw’s control plane for agent-client sessions: prompt turns enter a per-session actor queue, prepare a runtime handle, then invoke the selected backend. This change adds cancellation ownership before a turn becomes active so cancellation can stop setup work and leave task and session state terminal and idle.
