## Summary

## What This Changes

The PR adds an `embeddedSteeredCount` diagnostic counter, subtracts it during idle reconciliation, and adds queue-depth regression tests for embedded-run and normal queued-message cases.

## Best Possible Solution

Use caller-owned accounting so only accepted active embedded-run steering is excluded from backlog, preserve reply-run and normal queue-depth behavior, then add focused regression coverage and redacted real behavior proof.
