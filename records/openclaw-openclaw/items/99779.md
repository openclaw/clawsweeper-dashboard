Full review comments:

- **[P2] Consume ripgrep's short replace operand:** `src/infra/exec-control-command-guard.ts:189`
  - body: This table still has `--replace` but not ripgrep's short `-r` value-taking alias. `rg -r repl token` from a protected cwd will consume `repl` as the replacement and search `.`, while the guard treats `token` as a narrowed path and lets the broad search run.
  - confidence: 0.9
- **[P2] Parse clustered ripgrep short options:** `src/infra/exec-control-command-guard.ts:1692`
  - body: The short-option parser still only checks the first two characters of a token. For `rg -nE utf-8 token`, ripgrep consumes `utf-8` as the `-E` value and searches `.`, but the guard leaves `token` as a fake path and misses the protected-root search.
  - confidence: 0.88
- **[P2] Expand braced variables before path suffixes:** `src/infra/exec-control-command-guard.ts:1938`
  - body: Shell variables are only expanded when followed by end-of-string or a slash. A protected env value used as `${SESSION_ROOT}_backup` is resolved by the shell before the suffix, but the guard keeps it literal and can miss protected suffixed state directories.
  - confidence: 0.86
- **[P2] Substitute xargs replacement placeholders:** `src/infra/exec-control-command-guard.ts:1259`
  - body: `xargs -I{}` substitutes the placeholder inside every initial argument, including shell-wrapper positional args. The current resolver only appends a dynamic sentinel and leaves `{}` in the nested wrapper, so protected paths passed through `$1` can be analyzed as safe literals.
  - confidence: 0.86
- **[P2] Split static shell payload pipelines:** `src/infra/exec-control-command-guard.ts:991`
  - body: Static shell payloads are split on semicolons, newlines, `&&`, and `||`, but not a top-level single `|`. A payload such as `cat /dev/null | rg token ~/.codex/sessions` is analyzed as one `cat` command, so the protected-root `rg` after the pipe is never inspected.
  - confidence: 0.88
- **[P2] Fail closed on alias-expanded payloads:** `src/infra/exec-control-command-guard.ts:1552`
  - body: The analyzer replays functions but not shell aliases. With alias expansion enabled, a static alias can expand `r` into `rg token ~/.codex/sessions`, while the guard only sees the literal `alias` and `r` commands and allows the hidden protected-root search.
  - confidence: 0.84
