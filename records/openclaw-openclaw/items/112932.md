## What This Changes

This PR adds a persisted dead-refresh marker for permanently rejected OAuth grants, allowing a different external Codex CLI credential to replace a wedged stored OpenAI profile while refusing to re-adopt the same dead grant.

## System Context

OpenClaw stores OAuth profiles per agent, refreshes them when needed, and can bootstrap OpenAI credentials from the external Codex CLI. This change connects refresh-failure classification to persisted profile state so a permanently invalid refresh grant can yield to a fresh CLI login without looping on the same token.
