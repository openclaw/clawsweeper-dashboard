## What This Changes

The PR tombstones a permanently rejected stored OpenAI OAuth refresh grant, then lets a different external Codex CLI grant re-seed the profile while refusing to re-adopt the same dead grant.

## System Context

OpenClaw’s agent auth-profile layer loads persisted OAuth credentials, refreshes access tokens, and can bootstrap OpenAI credentials from the external Codex CLI. This change affects the recovery path after a provider permanently rejects a refresh grant, before later model requests use the refreshed or re-seeded credential.
