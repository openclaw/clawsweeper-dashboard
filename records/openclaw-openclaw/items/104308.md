## Summary

The PR is still necessary and its core design is sound, but the latest eviction change does not fully bound the new generation map: an evicted target’s still-associated Page can recreate an orphan generation entry on its next navigation. Real Chrome/CDP proof is now sufficient, and the earlier target-scope finding is resolved, but this remaining lifecycle defect should be fixed before merge.

## What This Changes

The PR clears browser role refs on main-frame navigation and adds target-scoped navigation generations to prevent stale cache restoration across replacement Playwright Page objects.

## Best Possible Solution

Keep the target-scoped invalidation design, but only create or bump a generation while the matching roleRefsByTarget entry is live, and add a regression that evicts a target, navigates its old Page, and proves no orphan generation is recreated.
