## What This Changes

The PR invalidates page-local browser role references on main-frame navigation and adds a bounded target-scoped navigation generation to prevent stale target-cache restoration across replacement Playwright Page objects.

## Best Possible Solution

Land the target-scoped generation design with its bounded eviction and main-frame-only invalidation, preserving fresh same-document refs across replacement Page objects while rejecting every pre-navigation cache entry.

## Maintainer Decision

## Reproduction Assessment

Yes. The submitted real Chrome/CDP run exercises snapshots before and after main-frame navigation, observes stale refs rejected as Unknown, and verifies fresh refs across a replacement Page.

## Solution Assessment

Yes. The cache is already target-scoped across replacement Page objects, so a target-scoped document generation is the narrowest ownership boundary; per-Page state would reproduce the earlier stale/fresh mismatch, while clearing only local state would leave the cross-Page cache unsafe.
