## Summary

This is a focused fix that routes the OpenAI-compatible embedding adapter through the shared provider SSRF-policy resolver and supplies credible container proof. The remaining merge question is security-contract intent: the existing provider-level `request.allowPrivateNetwork` opt-in remains active when a remote base URL overrides the configured endpoint, so a human should explicitly confirm that broad authorization boundary before merge.

## What This Changes

The PR makes OpenAI-compatible memory embeddings honor the existing provider `request.allowPrivateNetwork` setting through the shared SSRF transport-policy resolver, with redirect and remote-override coverage.

## System Context

Memory indexing creates embeddings through the selected provider adapter. That adapter converts provider configuration and any runtime remote endpoint into an HTTP request policy, which the shared SSRF guard enforces before returning vectors to the memory index.
