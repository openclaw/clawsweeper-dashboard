## What This Changes

This PR makes OpenAI-compatible embedding requests honor the existing provider `request.allowPrivateNetwork` setting and adds focused policy-propagation plus local redirect coverage.

## System Context

The embedding-provider adapter reads configured model-provider settings, builds an SSRF policy for outbound embedding requests, and passes that policy to the guarded HTTP layer. The guarded layer re-evaluates policy on every redirect before an embedding endpoint response is returned to memory indexing or search.

## Best Possible Solution

Keep the existing default SSRF protections, merge the setting only when a redacted real configured embedding request proves the intended private-network redirect succeeds, and preserve the omitted-setting failure case.
