## Summary

Keep open: current main still lacks a startup-loaded immutable operator policy/defaults overlay with locked precedence and runtime write enforcement. Existing Policy plugin work is conformance-only, while Nix mode only blocks config writes for Nix-managed installs, so this remains a maintainer-owned security and product decision.

## What This Changes

The issue requests a core immutable operator defaults policy, similar to SYSTEM_TOOLS.md, that can override and lock user-editable OpenClaw configuration at runtime.

## Best Possible Solution

Define one maintainer-approved core security boundary for immutable operator policy, then implement it consistently across startup config loading, write validation, status/doctor visibility, docs, and upgrade handling, or explicitly document Policy/Nix as the supported alternatives.
