## What This Changes

Repair WhatsApp Cloud inbound voice-note transcription when the plugin has already saved a valid audio file to OpenClaw’s local media store.

## System Context

The WhatsApp Cloud plugin receives webhook messages, downloads Graph API media, and constructs the inbound attachment context. The shared media-understanding subsystem selects an audio model, reads the attachment, injects a transcript when successful, and then passes the enriched message to the agent.
