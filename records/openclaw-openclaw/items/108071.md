## Summary

Keep open: the report is recent, specific, and describes a severe session-level stall. Current main still sends file-backed generated-media attachments through the asynchronous session-wake boundary, and there is no concrete merged-fix or release evidence proving that this path no longer serializes inline image payloads.

## What This Changes

Prevent asynchronous image-generation completions from persisting file-backed generated media as inline Base64 in session history and slowing subsequent session replay.

## Best Possible Solution

Keep generated media reference-only in durable history, hydrate it transiently only when needed for the active completion turn, and add regression coverage proving that later text-only turns neither serialize nor reload the generated bytes.
