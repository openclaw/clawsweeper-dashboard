## Label Justifications

- `P1`: The PR targets a real broken agent/provider workflow where model-visible tool results can vanish or become misleading media placeholders.
- `merge-risk: 🚨 message-delivery`: The diff changes how tool-result content is converted for provider delivery and can still misdeliver Mistral text as text plus a false omitted-image note.
- `merge-risk: 🚨 session-state`: The new embedded-loop hook rewrites fresh tool-result content before it becomes session replay state, so incorrect sanitization would persist into later turns.

## Summary

Keep open: current main does not have the defense-in-depth media-payload guard and this PR is a useful candidate, but it should not merge as-is because Mistral can still advertise a payload-less image label as omitted media for text-only models.

## What This Changes

The PR adds shared media-block predicates, updates five provider converters to skip empty media payloads, and installs a fresh tool-result image sanitizer hook in the embedded agent loop.

## Best Possible Solution

Keep the shared helper and fresh-result hook direction, but align Mistral's text-building image predicate with payload-backed media and add the missing regression before merge.

## Solution Assessment

No, not quite. The shared boundary guard is the right shape, but the Mistral converter still has one type-label-only decision that should use the same payload-aware invariant.
