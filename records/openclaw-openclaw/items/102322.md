## Summary

Keep open: current main still has the reported ACP translator gap, because Gateway exposes replacement chat deltas but ACP derives outgoing chunks only by slicing cumulative snapshots. The older ACP truncation fixes are adjacent, not a duplicate resolution for this non-append revision case.

## What This Changes

The issue reports ACP assistant text corruption when Gateway sends a non-append in-progress revision and the translator slices by previously emitted length.

## Best Possible Solution

Honor Gateway replacement deltas in ACP translation for both text and thinking, with regression tests for divergent and shorter revised snapshots.
