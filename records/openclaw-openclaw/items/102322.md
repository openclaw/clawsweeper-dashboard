## Repair Work Prompt

Fix the ACP translator bug where non-append Gateway chat revisions corrupt ACP assistant/thinking output. In `src/acp/translator.ts`, make `handleChatEvent`/`handleDeltaEvent` honor Gateway chat `replace` and `deltaText` semantics instead of assuming cumulative `message.content` snapshots only append; handle both text and thinking chunks, reset/update `pending.sentText*` and `pending.sentThought*` consistently, and do not change Gateway producer behavior. Add focused tests that drive `AcpGatewayAgent.handleGatewayEvent` through public chat events for divergent replacement (`Hello world` -> `Goodbye world`) and shorter replacement (`Hello world!` -> `Hi`), including final frames that must not leave stale text. Preserve existing final-snapshot no-duplicate and append-tail behavior. Do not add config, protocol version bumps, or broad ACP/Gateway refactors.
