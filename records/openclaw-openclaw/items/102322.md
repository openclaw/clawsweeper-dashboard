## Summary

Keep open: current main still slices cumulative ACP snapshots by prior emitted length while Gateway explicitly sends replacement deltas for non-prefix revisions, and the linked fix PR is open but not yet merge-ready because the ACP replacement semantics need maintainer direction.

## What This Changes

The issue reports ACP translator corruption or stale output when Gateway sends non-append replacement assistant or thinking deltas.

## Best Possible Solution

Define an ACP-compatible replacement strategy for Gateway replace=true deltas, then update the ACP translator, the thinking path, and focused rendered-output tests before closing this issue through the linked PR or a revised successor.
