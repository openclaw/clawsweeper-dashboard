## Summary

Keep open. Current main has closed part of the reported failure by treating aborted isolated cron runs as errors and, on main only, capping explicit cloud-model cron stream stalls so configured fallback can run sooner; however the GitHub Copilot Claude `anthropic-messages` path still exists, live current-main Copilot proof is missing, and the remaining abort/no-output fallback policy overlaps an open protected follow-up.

## What This Changes

The issue asks OpenClaw to stop silent isolated-cron hangs and false-success history for GitHub Copilot Claude models using the `anthropic-messages` transport.

## Best Possible Solution

Prove a live isolated Copilot Claude cron on current main either completes, fails as a cron error, or falls back within the 60-second stall cap, then decide whether any remaining aborted/no-output result should enter model fallback.
