## Summary

Keep open: current main and v2026.6.11 fix the cron status misclassification for aborted isolated runs, but GitHub Copilot Claude still uses the active `anthropic-messages` path and aborted embedded results are still excluded from result fallback. The newer fallback issue only covers missing default fallback candidates, and its PR is closed unmerged, so it does not supersede this broader report.

## What This Changes

The issue reports that isolated cron runs using GitHub Copilot Claude over `anthropic-messages` hang for about six minutes, do not deliver or fall back, and used to record a successful cron history row.

## Best Possible Solution

Keep this issue open until live Copilot Claude isolated-cron proof drives a maintainer-approved fix that either makes the transport fail promptly or permits fallback only for replay-safe aborted no-output runs, while preserving the shipped cron error classification.
