## Summary

The central bug remains unaddressed on current `main`, and the branch’s narrow projection-state fix appears technically sound. Keep this PR open, but do not merge yet: the supplied live runtime proof is for head `889fd64628adce99b4d7d25729a53b684b50376f`, while the current head is `686be06c5b1074549616e6fa72e38351e5faaa7c` after a July 27 force-push, so exact-head behavior proof must be refreshed.

## What This Changes

The PR passes the session-owned tool-result projection state into the embedded agent’s mid-turn context guard so overflow routing estimates the same truncated tool-result view that provider dispatch sends.

## System Context

The embedded agent collects tool results in a session transcript, checks whether the next model prompt will fit, and then sends a provider-specific projected prompt. This change affects the pre-send guard so it evaluates the projected tool-result view before choosing destructive recovery or normal compaction.
