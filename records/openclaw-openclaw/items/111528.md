## What This Changes

The PR threads the session-owned tool-result prompt projection state into the embedded mid-turn guard, clones it for preflight estimation, and adds regression coverage so tool-heavy turns are measured after provider-equivalent truncation rather than from the raw transcript.

## System Context

Embedded agent runs append tool results to session messages, then run a mid-turn context guard before dispatching a provider request. Provider dispatch applies per-result and aggregate prompt projection; the guard decides whether to continue, truncate, or compact, so both paths must observe the same prompt view without mutating session state early.
