## What This Changes

The PR passes the session-owned tool-result projection state into the embedded agent’s mid-turn context guard and estimates overflow from the same capped tool-result view sent to the model.

## System Context

Embedded agent turns retain tool results in session state and use a mid-turn guard to decide whether to compact before another model request. Provider dispatch later applies per-result and aggregate tool-result projection; this change gives the guard that same projected view without letting the guard mutate the canonical state.
