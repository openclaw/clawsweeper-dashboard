## What This Changes

This PR passes the session-owned tool-result projection state into the embedded agent’s mid-turn overflow guard so the precheck estimates the truncated prompt view that provider dispatch will actually send.

## System Context

Embedded agent runs accumulate tool results in the session transcript before a mid-turn guard decides whether to compact or truncate context. Provider dispatch projects those results into a bounded prompt; this change makes the guard evaluate the equivalent projected view without mutating the session-owned projection state.

## Best Possible Solution

Keep the shared session projection as the single prompt-view contract for both precheck and dispatch, then land only after the failing current-head compact check is explained or green and the clone-versus-canonical-state invariant remains covered by regression tests.
