## Summary

Current main still exhibits the reported Control UI limitations: grouped tools use count-only summaries, expanded cards expose generic data blocks, and transcript coalescing cannot pair parallel call-call-result-result sequences. This fresh issue also has the protected `maintainer` label and combines concrete UI defects with a model-backed title feature requiring explicit product direction.

## What This Changes

Improve Control UI tool-call presentation with kind-aware summaries and inline diffs, fix result pairing for message-level IDs and parallel calls, and optionally generate cached purpose titles.

## Best Possible Solution

Pair results by call ID across the complete tool-activity turn, add deterministic kind-aware summaries and persisted edit-diff rendering in the existing Control UI pipeline, and consider generated titles separately by reusing shared utility-completion and SQLite cache seams under an explicit privacy, cost, routing, and invalidation contract.
