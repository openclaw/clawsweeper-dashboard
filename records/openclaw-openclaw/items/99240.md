The issue requests that `/thinking` levels work for dynamically discovered GitHub Copilot Claude models such as `github-copilot/claude-sonnet-4.6`.

## Best Possible Solution

Keep the issue open and fix the GitHub Copilot provider catalog metadata path so dynamic Claude rows expose supported thinking levels while preserving off-only behavior for truly non-reasoning models.
