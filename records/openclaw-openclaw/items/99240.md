## Best Possible Solution

Fix the provider-owned Copilot metadata path so dynamic or live Copilot Claude rows expose supported thinking levels, while preserving the core off-only behavior for explicit non-reasoning models.

## Solution Assessment

Yes, the likely best fix is provider-owned metadata/live-catalog correction, not a generic core bypass; core should continue honoring explicit non-reasoning catalog rows for providers where that is true.
