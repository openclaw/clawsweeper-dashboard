## Summary

Keep this PR open: the real gateway proof convincingly demonstrates the reported recovery, but the exact head still has the previously reported lifecycle-ownership defect. Clearing only the lock-holder registry can admit a new cache writer while pre-restart work remains active, and stale completion can remove current queue ownership.

## What This Changes

The PR makes usage-cost refreshes reclaim unowned same-process cache locks and clears in-memory lock-holder registrations during an in-process gateway restart.

## Best Possible Solution

Generation-scope or retire the lock holders, queued refresh state, timers, running work, and completion together at the restart boundary so stale work cannot overlap with or mutate the new lifecycle; cover both overlap and stale-completion cases with focused regressions.
