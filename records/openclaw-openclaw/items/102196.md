- `impact:ux-friction`: Feishu users can continue working, but streamed replies show avoidable progress noise and the documented hide-progress policy does not apply to Feishu.

## Summary

Keep open: current main still appends Feishu tool-progress status into streaming cards under the boolean streaming gate, Feishu still lacks the shared `streaming.preview.toolProgress` / `commandText` policy, and changing either Feishu config shape or gateway mutation access needs maintainer direction.

## What This Changes

The issue asks Feishu to stop noisy or misleading exec tool-progress streaming, add a Feishu progress/command-text preview toggle, and reconsider the protected streaming config toggle.

## Best Possible Solution

Make Feishu honor the shared streaming preview policy with backward-compatible schema, manifest, docs, and tests; keep gateway config mutation protection unchanged unless maintainers explicitly approve a narrow operator-boundary change.

Unclear until maintainers choose the Feishu config/API shape; reusing the shared preview policy is the narrowest maintainable direction found, while a one-off string filter or broad `config.patch` allowlist change would leave policy drift or operator-boundary risk.
