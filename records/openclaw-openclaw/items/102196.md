## Label Justifications

## Summary

Keep open: current main has removed the literal `Exec failed` wording from the shared command-output progress renderer, but Feishu still streams tool-status text into Card Kit previews through a boolean-only `channels.feishu.streaming` config with no `toolProgress` or `commandText` policy.

## What This Changes

Request to let Feishu keep streaming replies while suppressing or compacting tool-progress lines for benign non-zero exec outcomes, and to reconsider the protected config-patch boundary for that setting.

## Best Possible Solution

Maintainers should choose a Feishu streaming config contract, then implement the Feishu-owned schema, runtime, docs, and tests so users can keep Card Kit streaming while hiding or compacting tool progress.

Unclear pending maintainer direction. A Feishu-owned nested streaming preview policy is the maintainable fix shape; a one-off string filter or blanket unprotecting of `channels.feishu.streaming` would be too broad.
