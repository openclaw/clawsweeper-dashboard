## Summary

Keep open: current main still routes Feishu streaming tool-progress into the live card preview with a boolean-only streaming config, so the Feishu opt-out/status-only request remains unresolved even though shared command-output wording is now less misleading.

## What This Changes

Request to reduce misleading Feishu streaming tool-progress for benign exec exits and add a Feishu-supported way to keep streaming while hiding or reducing tool-progress lines.

## Best Possible Solution

Make Feishu honor the shared nested streaming preview policy with backward-compatible schema, manifest, docs, and focused tests; keep gateway config mutation protection unchanged unless maintainers explicitly approve a narrow allowlist change.
