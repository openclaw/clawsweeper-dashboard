## Summary

Keep open: current main and the latest release still use boolean-only Feishu streaming, append transient tool status into streamed CardKit text, and provide no Feishu `preview.toolProgress` or `commandText` control.

## What This Changes

Request a Feishu streaming policy that avoids misleading or noisy exec tool-progress lines while keeping answer streaming, plus a supported way to disable or reduce that progress surface.

## Best Possible Solution

Make Feishu honor the shared preview policy with backward-compatible schema, manifest, docs, and tests, while preserving the current boolean default and keeping gateway config mutation protection unless maintainers approve a narrow recovery control.
