## Summary

Keep open: current main still has Feishu streaming tied to a boolean-only `streaming` setting and still renders work-tool status lines into streaming cards, so the Feishu opt-out/status-only request remains unresolved.

## What This Changes

Request Feishu streaming to stop surfacing benign exec non-zero exits as disruptive tool-progress noise, add a Feishu tool-progress/status-only control, and reconsider the protected gateway config toggle path.

## Best Possible Solution

Make Feishu honor the shared streaming preview policy with backward-compatible schema, manifest, docs, and tests for default progress, hidden progress, and status-only command text; keep gateway config mutation protection unchanged unless maintainers explicitly approve a narrow allowlist change.
