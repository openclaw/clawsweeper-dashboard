## Summary

Keep open: current main still source-reproduces the Feishu-specific gap. The scary shared command-output wording is now less literal, but Feishu still streams tool-status lines into Card Kit previews and exposes only a boolean `streaming` config, so the opt-out/status-only behavior needs a maintainer product decision.

## What This Changes

The issue requests Feishu streaming-card behavior that can hide or soften tool-progress lines while preserving preview streaming, plus a decision on whether the gateway tool may toggle `channels.feishu.streaming`.

## Best Possible Solution

Make Feishu honor the shared streaming preview policy with backward-compatible schema, manifest, docs, and tests for default progress, hidden progress, and status-only command text; leave gateway mutation protection unchanged unless maintainers explicitly approve a narrow allowlist change.
