## Summary

Keep open: current main mitigates the broad non-mutating exec-warning path, but Feishu still appends tool-progress status into streaming cards whenever its boolean streaming mode is enabled and still has no Feishu `preview.toolProgress` or `commandText` policy.

## What This Changes

Request to make Feishu streaming avoid misleading or interrupting exec progress and add a Feishu-supported way to keep streaming while hiding or simplifying tool-progress lines.

## Best Possible Solution

Make Feishu honor the shared streaming preview policy with backward-compatible schema, manifest, docs, and tests for default progress, opt-out, and status-only command text; keep gateway config mutation protection unchanged unless a separate security review approves a narrow allowlist change.
