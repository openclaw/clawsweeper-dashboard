## What This Changes

The PR recognizes Azure Provisioned-Managed throughput-limit wording as a short-window throttle so the embedded agent retries the same model instead of immediately surfacing the error or rotating an auth profile.

## System Context

The embedded agent runner classifies provider failures before selecting either a bounded same-model retry or provider/auth failover. This PR changes the message-classification input for Azure Responses-compatible failures, which affects the retry decision emitted to the agent run.
