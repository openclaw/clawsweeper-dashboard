## What This Changes

The PR separates requester wake success from required visible-delivery failure and persists both outcomes through lifecycle cleanup, detached-task accounting, and SQLite restore.

## Best Possible Solution

Use one canonical state machine that credits requester continuation independently while keeping required visible delivery bounded and retryable until success or explicit exhaustion, with consistent detached-task, cleanup, and SQLite semantics.
