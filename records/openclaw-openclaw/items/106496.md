## Summary

This PR remains necessary: current main still passes only the abort signal on Slack’s presigned upload path, while the guarded dispatcher requires `timeoutMs` to apply its connect and headers floors. The focused patch, regression coverage, controlled hung-peer proof, and successful channel/CI checks support normal maintainer merge review with no blocking finding.

## What This Changes

Passes Slack’s existing 120-second upload budget into the guarded fetch dispatcher and adds assertions plus a hung-peer upload regression test.

## Best Possible Solution

Keep one canonical 120-second upload budget and apply it to both abort-signal cancellation and guarded-dispatcher connect/header floors, with the focused hung-peer regression retained.
