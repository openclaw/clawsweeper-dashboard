## Summary

This PR remains necessary: current main gives Slack uploads a 120-second AbortSignal but does not pass that budget to the guarded dispatcher, while the shared transport only installs connect and headers timeout floors when `timeoutMs` is supplied. The patch is narrow, the linked startup-timeout PR covers a distinct request path, and no actionable correctness or security defect was found.

## What This Changes

The PR passes Slack’s existing 120-second upload budget to `fetchWithSsrFGuard` and adds regression coverage for peers that accept an upload request but never return headers.

## Best Possible Solution

Land the narrow Slack-local propagation and regression test so the existing upload budget consistently governs both AbortSignal cancellation and guarded Undici connect/header floors.
