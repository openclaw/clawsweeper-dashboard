## Summary

Keep open: current main preserves structured tool media and `details.path` media, but it still has no current-main path for the reported pathless inline `read` image result, and open linked PRs are candidate fixes rather than merged implementations.

## What This Changes

The issue reports that Feishu auto-replies can lose image media from trusted `read` or `message` tool results before the final outbound payload is sent.

## Best Possible Solution

Land or reject a focused fix that turns trusted pathless `read` image results into safe outbound media URLs while preserving the existing structured-media and `details.path` paths.
