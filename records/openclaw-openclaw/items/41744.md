## Summary

Keep open: current main and v2026.6.11 still do not promote pathless inline `read` image blocks into outbound media, and open candidate fixes need maintainer selection before this issue can close.

## What This Changes

The issue reports that Feishu replies drop image media from `read` tool results before the final outbound payload is delivered.

## Best Possible Solution

Land or replace a single safe shared embedded-agent fix that promotes trusted `read` image results into outbound media, preserves local-media gates, and proves Feishu plus one shared channel delivery path.
