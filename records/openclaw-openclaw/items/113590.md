## What This Changes

This PR makes ZaloUser compile headings, lists, blockquotes, indentation, and code-block styles from shared CommonMark IR metadata instead of its former plugin-local Markdown scanner.

## System Context

Outgoing Markdown is parsed by `packages/markdown-core`, then channel formatters consume the resulting IR to generate channel-specific text and style ranges. This change adds parser-owned block and list ownership metadata for ZaloUser so its transport adapter can emit Zalo style ranges without independently re-parsing Markdown.

## Best Possible Solution
