## What This Changes

The PR replaces ZaloUser’s local Markdown block scanner with CommonMark parser metadata so headings, lists, containers, indentation, and code blocks render from one shared interpretation.

## System Context

`packages/markdown-core` parses Markdown into the IR consumed through the plugin SDK’s text-chunking surface. ZaloUser’s formatter then converts that parsed content into Zalo native range styles before outbound channel delivery.

## Architecture Diagram

  F --> G[Outbound Zalo message]

## Best Possible Solution

Keep the parser metadata owned by markdown-core, but expose ZaloUser’s required block/list view through an explicitly owned bundled-only facade or a deliberately approved typed SDK capability with focused contract coverage.
