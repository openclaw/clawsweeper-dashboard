## Summary

Keep open: current main and v2026.6.11 still compare Feishu mention identifiers to the receiving bot's botOpenId only, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The linked implementation PR remains open and unresolved, so this issue is still the canonical tracking point.

## What This Changes

The issue reports Feishu group @mentions being ignored when multiple bots share one group because mention open_id values are app-scoped and do not match the receiving bot identity.

## Best Possible Solution

Land one current-main Feishu identity fix that proves a stable bot identity across text mentions, post mentions, command stripping, mention-forward, debounce batching, focused tests, and redacted live multi-bot proof, then close this issue.
