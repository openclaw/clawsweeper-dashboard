## Summary

Keep open: current main and v2026.6.11 still use Feishu botOpenId-only mention admission, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot; the linked fix PR is open, dirty, and awaiting a Feishu identity-source decision.

## What This Changes

The issue asks OpenClaw to recognize the intended Feishu bot in multi-bot group @mentions even when Feishu delivers app-scoped open_id values that do not match that bot's self open_id.

## Best Possible Solution

Review, repair, or replace https://github.com/openclaw/openclaw/pull/40782 with a current-main Feishu identity fix that proves a stable mention identity across parsing, probing, command stripping, post mentions, mention-forward/debounce paths, and redacted live multi-bot Feishu behavior.
