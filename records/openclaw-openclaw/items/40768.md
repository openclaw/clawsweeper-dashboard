## What This Changes

Request to fix Feishu group @mention detection when multiple bot apps share one group and WebSocket mention `open_id` values do not match the receiving bot's app-scoped `botOpenId`.

## Best Possible Solution

Keep this issue as the canonical tracker and resolve it by landing or replacing the linked Feishu PR with a plugin-owned identity strategy backed by Feishu payload/API proof, focused tests, and redacted live multi-bot Feishu proof.
