## Summary

Keep open: current main still admits Feishu group mentions by comparing a single probed `botOpenId` to incoming mention `open_id`, so the reported app-scoped mismatch can still suppress an explicitly mentioned bot. The linked open PR uses closing syntax for this issue but remains unmerged, conflicting, and under requested-changes review for the Feishu identity strategy.

## What This Changes

The issue reports that Feishu multi-bot group @mentions can be ignored because WebSocket mention `open_id` values are app-scoped and do not match the receiving bot's probed `open_id`.

## Best Possible Solution

Keep this issue as the canonical tracker and resolve it by landing or replacing the linked Feishu PR with a plugin-owned identity strategy backed by Feishu payload/API proof for multi-bot group mentions.
