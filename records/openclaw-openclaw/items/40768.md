## Summary

Keep open: current main and v2026.6.11 still recognize Feishu group mentions by comparing the incoming mention `open_id` to one probed `botOpenId`, so the reported app-scoped `open_id` mismatch can still suppress a specifically mentioned bot. The linked implementation PR remains open, conflicting, and under maintainer-requested changes, so it is a candidate fix rather than an implemented resolution.

## What This Changes

The issue asks OpenClaw to recognize the correct Feishu bot in multi-bot group chats when Feishu mention `open_id` values are scoped differently per app.

## Best Possible Solution

Keep this issue as the canonical tracker until the linked Feishu PR is repaired or replaced with a proven plugin-owned identity strategy for app-scoped Feishu mention IDs.
