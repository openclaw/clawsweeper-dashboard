## Summary

Keep open: current main and v2026.6.11 still resolve Feishu bot identity to a single probed `botOpenId` and require `checkBotMentioned()` to match the incoming mention's `open_id`, so the reported app-scoped `open_id` mismatch can still suppress an explicitly mentioned bot. The open linked implementation candidate at https://github.com/openclaw/openclaw/pull/40782 uses closing syntax for this issue but is currently conflicting and still needs maintainer identity-strategy review.

## What This Changes

This issue requests a Feishu multi-bot group mention fix so explicitly mentioned bots are recognized even when Feishu mention `open_id` values are app-scoped.

## Best Possible Solution

Keep this issue as the canonical tracker and resolve it by landing or replacing the linked Feishu PR with a plugin-owned identity strategy backed by Feishu payload/API proof for multi-bot group mentions.
