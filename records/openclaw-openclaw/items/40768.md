## Summary

Keep open: current main and v2026.6.11 still gate Feishu group replies by comparing native mention `open_id` values to the receiving bot's own `botOpenId`, so the reported app-scoped mismatch can still suppress an explicitly mentioned bot. The linked closing PR is still open and conflicting, so it is an implementation candidate rather than a reason to close this issue.

## What This Changes

The issue asks OpenClaw to make Feishu multi-bot group @mention detection work when Feishu delivers app-scoped `open_id` values that do not match the receiving bot's own `open_id`.

## Best Possible Solution

Land or replace the linked Feishu PR with one verified identity strategy for multi-bot @mention admission, covering text and post mentions with focused tests and redacted live multi-bot Feishu proof.
