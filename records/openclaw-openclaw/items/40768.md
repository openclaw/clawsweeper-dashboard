## Summary

Keep open: current main and v2026.6.11 still check Feishu group mentions against the receiving account's botOpenId only, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The open linked PR is an implementation candidate but remains conflicting and under maintainer review, so this issue should stay as the canonical tracker until that PR lands or is replaced.

## What This Changes

The issue reports Feishu group @mention admission failing when multiple bot apps share a group because mention open_id values are app-scoped and do not match the receiving bot's botOpenId.

## Best Possible Solution

Land or replace the linked Feishu fix with a current-main identity strategy proven across text, post, command-stripping, mention-forward, and debounce paths, with focused tests and redacted live multi-bot Feishu proof.
