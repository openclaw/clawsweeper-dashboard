## Summary

Keep open: current main and v2026.6.11 still decide Feishu bot mentions by comparing the native mention open_id to the receiving botOpenId, so the reported app-scoped mismatch can still drop an explicitly addressed bot. The open linked fix PR is still conflicting and under maintainer review, so this issue should remain the canonical tracker.

## What This Changes

Feishu should recognize direct bot @mentions in multi-bot group chats even when WebSocket mention open_id values do not match the receiving app's botOpenId.

## Best Possible Solution

Land or replace the Feishu identity fix around a proven stable cross-app bot identity source, covering text, post, command stripping, mention-forward, debounce paths, and redacted live multi-bot proof before closing this issue.
