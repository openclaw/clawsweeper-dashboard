## Summary

Keep open: current main and the latest release still resolve Feishu bot admission with botOpenId/open_id matching only, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The linked fix candidate at https://github.com/openclaw/openclaw/pull/40782 remains open, conflicting, and under maintainer review, so this issue should stay open until that PR lands or is replaced.

## What This Changes

The issue reports Feishu group @mentions being ignored when multiple bot apps share a group because mention open_id values are app-scoped and do not match the receiving bot's botOpenId.

## Best Possible Solution

Land or replace the linked PR with a current-main Feishu identity fix using a proven stable bot identity across text, post, command stripping, mention-forward, and debounce paths, with focused tests and redacted live multi-bot proof.
