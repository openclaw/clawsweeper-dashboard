## Summary

Keep open: current main still decides Feishu group mention admission by comparing native mention `open_id` values to the receiving bot's `botOpenId`, so the reported app-scoped `open_id` mismatch can still suppress an explicitly mentioned bot. The linked implementation candidate at https://github.com/openclaw/openclaw/pull/40782 remains open, dirty, and under maintainer review, so this issue should stay as the canonical tracker until a correct identity-resolution fix lands.

## What This Changes

The issue asks OpenClaw to make Feishu group mention detection work when multiple Feishu bot apps share a group and mention `open_id` values are app-scoped.

## Best Possible Solution

Keep this issue open and land or replace the linked Feishu identity-resolution PR with a maintainer-approved strategy that proves targeted multi-app mentions dispatch to the addressed bot while non-addressed bots stay quiet.
