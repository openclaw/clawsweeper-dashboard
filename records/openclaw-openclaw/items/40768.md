## Summary

Keep open: current main and v2026.6.11 still use Feishu botOpenId-only mention matching, so the app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The active implementation candidate is https://github.com/openclaw/openclaw/pull/40782, but that PR is still open, conflicting, and blocked on a Feishu identity-source decision.

## What This Changes

Feishu group @mention detection should recognize the intended bot in multi-bot group chats even when Feishu emits app-scoped mention IDs that differ from the bot's self open_id.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/40782 with a current-main Feishu identity fix that proves a stable bot identity across parsing, probing, command stripping, mention-forward/debounce paths, and redacted live multi-bot Feishu proof.
