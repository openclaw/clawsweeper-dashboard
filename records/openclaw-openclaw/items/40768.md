## Summary

Keep open: current main and v2026.6.11 still gate Feishu group mentions by the receiving bot's stored open_id only, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The linked implementation PR remains open, conflicting, and paused for a maintainer identity-source decision rather than being a merged fix.

## What This Changes

The issue reports Feishu group @mentions being ignored when multiple bot apps share one group because mention open_id values can be app-scoped and fail to match the receiving bot identity.

## Best Possible Solution

Land or replace the active Feishu fix with a proven stable bot identity strategy covering text, post, command stripping, mention-forward, debounce, tests, and redacted live multi-bot proof.
