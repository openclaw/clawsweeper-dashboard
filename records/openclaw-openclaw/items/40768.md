## Summary

Keep open: current main and v2026.6.11 still compare Feishu mention identity to the receiving bot's `botOpenId` only, so the reported app-scoped `open_id` mismatch can still suppress an explicitly mentioned bot. The linked implementation candidate at https://github.com/openclaw/openclaw/pull/40782 remains open, conflicting, and under human review, so this issue should stay as the canonical tracker.

## What This Changes

The issue reports Feishu group @mentions being dropped when multiple bots share a group because Feishu mention `open_id` values can be scoped to a different app than the receiving bot.

## Best Possible Solution

Land or replace the linked Feishu identity fix with a proven stable bot identity strategy covering text mentions, post mentions, command stripping, mention-forward, debounce batching, and redacted live multi-bot proof.
