Keep open: current main and v2026.6.11 still compare Feishu mention identity to the receiving bot's botOpenId only, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The linked same-author implementation PR remains open, conflicted, and under maintainer review, so this issue should stay open as the canonical tracker.

## What This Changes

The issue reports Feishu multi-bot group @mention detection failing when app-scoped mention open_id values do not match the receiving bot's own open_id.

## Best Possible Solution

Land one current-main Feishu identity fix that proves a stable cross-app bot identity across text mentions, post mentions, command stripping, mention-forward, debounce batching, focused tests, and redacted live multi-bot proof, then close this issue.
