## Summary

Keep open: current main and v2026.6.11 still resolve Feishu bot identity to botOpenId and check group mentions by open_id only, so the reported app-scoped open_id mismatch can still suppress an explicitly mentioned bot. The linked implementation candidate at https://github.com/openclaw/openclaw/pull/40782 remains open, conflicting, and under maintainer review, so this issue should stay as the canonical tracker until that PR lands or is replaced.

## What This Changes

Feishu group @mention detection should recognize the specifically mentioned bot even when multiple bot apps in the same group receive app-scoped open_id values.

## Best Possible Solution

Land a current-main Feishu identity fix around a proven stable bot identity source across text, post, command-stripping, mention-forward, and debounce paths, with focused tests and redacted live multi-bot Feishu proof.
