## What This Changes

The issue reports Feishu group @mentions being ignored when multiple Feishu bot apps share one group because mention open_id values are app-scoped and do not match the receiving bot's stored open_id.

## Best Possible Solution

Land or replace the active Feishu fix with a proven stable bot identity strategy covering text, post, command stripping, mention-forward, debounce batching, tests, and redacted live multi-bot proof.
