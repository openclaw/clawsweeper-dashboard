## Summary

Keep open: current main still removes empty final payloads from delivery and filters empty assistant messages from Control UI rendering, while the documented direct-chat contract says clean empty turns should not silently succeed. The report therefore describes a still-relevant message-loss path, although session logs are needed to determine why the existing incomplete-turn guard did not recover it. ## What This Changes

Fix interactive tool-only turns that finish without assistant text so they produce a visible final reply or failure instead of silently disappearing from channel delivery and Control UI.

## Best Possible Solution

Enforce a shared terminal invariant for interactive turns: retry a replay-safe empty completion, then emit a visible structured failure if no user-facing text or media exists, while preserving intentional `NO_REPLY`, message-tool-only, and always-on-room silence; keep the resulting failure visible in Control UI and add cross-surface regression tests.
