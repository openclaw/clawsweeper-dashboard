This PR adds standalone composable termination conditions and a GSAR grounding scorer for agent loops, plus unit/live coverage and a scripted demonstration.

## System Context

OpenClaw’s agent-to-agent loop obtains model replies, applies its existing ping-pong turn budget, and either continues, announces, or exits. The proposed modules would add a separate reusable decision layer that scores reply text or grounding evidence to request an earlier exit.
