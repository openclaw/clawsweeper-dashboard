## Summary

Keep open: this is a distinct, low-risk product ergonomics request. Current documentation confirms that commentary and tool-progress controls apply only to the temporary progress draft; no existing setting independently suppresses Discord’s final activity receipt while preserving commentary.

## What This Changes

Add a per-channel progress setting to hide the final activity receipt without disabling live commentary or other progress-draft behavior.

## Best Possible Solution

Add one narrowly named shared progress-receipt visibility option with a backward-preserving default, wire it through the progress-draft completion compositor, and cover Discord’s commentary-on/receipt-off completion path plus unchanged failure handling.

## Solution Assessment
