## What This Changes

## Best Possible Solution

Return a typed mirror-read outcome that separates expected absence or inapplicability from unexpected read/parse failure, silently or debug-log the former, warn on the latter, and cover first-turn, non-Codex-provider, malformed-existing-file, and successful-mirror cases.
