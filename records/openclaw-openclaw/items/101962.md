## Summary

Keep open. Current main still exposes completed streaming tool-call blocks before the stream finishes, but the agent loop executes tools only after the final assistant message returns, so the requested latency feature remains real and needs maintainer design rather than cleanup.

## What This Changes

Request an opt-in agent-core mode that executes fully parsed streaming tool calls before the rest of the model response finishes streaming.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that starts only safe completed tool calls during streaming while preserving transcript validity, event ordering, hooks, approvals, cancellation, and a clear opt-in/default policy.
