## Summary

Keep open. Current main still parses streamed tool-call deltas but dispatches tools only after the assistant stream resolves, and changing that boundary would be a new core execution mode that needs maintainer design approval rather than conservative cleanup.

## What This Changes

The issue requests an opt-in execute-on-parse mode that starts individual tool calls as soon as their streamed arguments are fully parsed.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript ordering, hooks, approvals, cancellation, and a clear opt-in/default policy.
