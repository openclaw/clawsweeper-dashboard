## Summary

Keep open. Current main still parses streaming tool-call deltas but starts execution only after the assistant stream resolves into a completed tool-call batch, so the requested latency feature remains real and needs maintainer design direction rather than cleanup closure.

## What This Changes

Request an opt-in core agent mode that executes each fully parsed streamed tool call before the full assistant tool-call batch finishes streaming.

## Best Possible Solution

Design a maintainer-approved agent-core execution mode that can start only safe completed streamed tool calls while preserving transcript validity, source-order tool-result artifacts, hooks, approvals, cancellation, and a clear default policy.
