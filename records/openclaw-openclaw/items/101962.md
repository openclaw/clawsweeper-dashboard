## Summary

Keep open. Current main still parses streaming tool-call deltas but waits for the assistant stream to finish before dispatching the completed tool-call batch, so this remains a real performance feature request that needs maintainer design direction rather than conservative cleanup.

## What This Changes

Request an opt-in execute-on-parse mode that starts each fully parsed streamed tool call before the rest of the streamed batch finishes.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only fully parsed, concurrency-safe tool calls during streaming while preserving transcript order, hooks, approvals, cancellation, result pairing, and default compatibility.
