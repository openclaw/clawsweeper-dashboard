## Summary

Keep open. Current main still executes collected tool calls only after the assistant stream returns a final message, while provider streams can surface completed tool-call items earlier; this is a real performance feature request that needs maintainer design rather than cleanup.

## What This Changes

Request to add an opt-in execute-on-parse mode so fully parsed streaming tool calls can start before the full assistant response finishes.

## Best Possible Solution

Design a maintainer-approved opt-in core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and default compatibility.
