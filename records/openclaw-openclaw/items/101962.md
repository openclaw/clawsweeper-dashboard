## Summary

Keep open. Current main still turns streamed tool-call deltas into assistant message updates and starts tool execution only after the assistant stream completes; adding execute-on-parse changes core agent-loop semantics and needs maintainer design direction.

## What This Changes

Request an opt-in mode that executes each completed streamed tool call as soon as its arguments parse, instead of waiting for the whole assistant tool-call batch.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed streamed tool calls while preserving transcript validity, hooks, approvals, cancellation, ordering, and default compatibility.
