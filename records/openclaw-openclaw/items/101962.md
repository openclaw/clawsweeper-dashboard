## Summary

Keep open. Current main parses streaming tool-call deltas, but the core agent loop still waits for the final assistant message before executing the completed batch, so execute-on-parse remains a real feature request that needs maintainer design direction.

## What This Changes

Request an opt-in agent-loop mode that starts each fully parsed streaming tool call before the rest of the model tool-call batch finishes streaming.

## Best Possible Solution

Design a core agent-loop mode that can start safe completed tool calls on `toolcall_end` while preserving ordering, transcript validity, hooks, approvals, cancellation, and a clear opt-in/default policy.
