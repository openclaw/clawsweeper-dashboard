## Summary

Keep open. Current main still collects streamed tool calls into the assistant message and only executes them after the assistant response finishes, so the requested execute-on-parse behavior is not implemented and still needs maintainer design.

## What This Changes

Requested opt-in execution of streamed tool calls as soon as each call's arguments are fully parsed, instead of waiting for the entire streamed batch.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and a clear opt-in/default policy.
