## Summary

Keep open. Current main parses streaming tool-call deltas, but the agent loop still waits for the assistant stream to finish before executing the completed tool-call batch; the request fits performance priorities but needs maintainer product/design direction, not conservative cleanup.

## What This Changes

The issue requests an opt-in mode that starts independent tool execution as soon as each streamed tool call is fully parsed.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving tool ordering, transcript validity, hooks, approvals, cancellation, and a clear opt-in/default policy.
