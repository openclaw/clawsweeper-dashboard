## Summary

Keep open. Current main still finishes the assistant response before executing collected tool calls; execute-on-parse is a real performance feature request, but it changes core scheduling, transcript, approval, cancellation, and tool-safety semantics.

## What This Changes

Request an opt-in agent-core mode that starts each completed streamed tool call immediately instead of waiting for the full model response or tool-call batch.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and default compatibility.
