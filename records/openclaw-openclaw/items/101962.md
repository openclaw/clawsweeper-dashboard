## Summary

Keep open. Current main still exposes streaming tool-call completion events but only starts tool execution after the assistant response has fully returned, so the requested execute-on-parse behavior remains a real core scheduling feature that needs maintainer design.

## What This Changes

Request an opt-in mode that starts each fully parsed streamed tool call before the rest of the model response finishes streaming.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and default compatibility.
