## Summary

Keep open. Current main still exposes completed streamed tool-call events before final response completion, but agent-core only starts tool execution after the full assistant response returns, so this remains a real performance feature/design request rather than cleanup-close material.

## What This Changes

The issue requests an opt-in agent-loop mode that executes each streamed tool call as soon as its arguments finish parsing instead of waiting for the full assistant response batch.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and opt-in/default policy.
