## Summary

Keep open. Current main still finishes the assistant stream before dispatching any completed tool calls, and the requested execute-on-parse mode would change core agent-loop ordering and policy semantics rather than clean up an obsolete item.

## What This Changes

Request an opt-in agent-core mode that starts each completed streamed tool call as soon as its arguments parse instead of waiting for the full assistant response to finish.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can begin only safe completed tool calls during streaming while preserving transcript validity, lifecycle hooks, approvals, cancellation, ordering, and a clear opt-in/default policy.
