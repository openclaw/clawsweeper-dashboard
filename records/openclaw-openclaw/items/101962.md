## Summary

Keep open. Current main still emits completed streaming tool-call events before final response completion, but the core agent loop waits for the final assistant message before executing the collected tool batch; this is a real performance feature request that needs maintainer design rather than cleanup closure.

## What This Changes

Request an opt-in mode that executes each completed streamed tool call as soon as its arguments are parsed instead of waiting for the full streamed batch.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and a clear default policy.
