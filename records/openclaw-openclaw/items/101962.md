## Summary

Keep open. Current main still parses completed streaming tool calls before the final stream end, but the agent loop executes them only after the assistant response returns; this is a real performance feature request that needs maintainer design, not conservative cleanup.

## What This Changes

Add an opt-in mode that starts independent tool calls as soon as their streamed arguments are fully parsed instead of waiting for the full tool-call batch to finish streaming.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and a clear opt-in/default policy.
