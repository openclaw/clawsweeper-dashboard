## Summary

Keep open. Current main still emits completed streamed tool-call events before the final response, but the agent loop only executes tools after the assistant message returns, so this remains a real core runtime feature request that needs maintainer design.

## What This Changes

The issue requests an opt-in execute-on-parse mode that starts each fully parsed streaming tool call before the rest of the model response finishes.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that starts only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and opt-in defaults.
