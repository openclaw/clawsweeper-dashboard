## Summary

Keep open. Current main still exposes completed streamed tool-call events before final response completion, but the agent loop executes tools only after the final assistant message returns; this is a real performance feature request that needs maintainer design rather than cleanup closure.

## What This Changes

The issue requests an opt-in execute-on-parse mode that starts each completed streamed tool call before the rest of the assistant response finishes streaming.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and a clear opt-in/default policy.
