## Summary

Keep open. Current main still executes tool calls only after the assistant stream returns, while provider streams can surface completed tool-call events earlier; this is a real performance feature request that needs maintainer runtime and safety design rather than cleanup.

## What This Changes

The issue requests an opt-in agent-core mode that executes each completed streaming tool call as soon as its arguments parse, rather than waiting for the full assistant stream to finish.

## Best Possible Solution

Design a maintainer-approved opt-in agent-core scheduling mode that starts only safe completed tool calls during streaming while preserving source-ordered result messages, hooks, approvals, cancellation, transcript validity, and concurrency policy.
