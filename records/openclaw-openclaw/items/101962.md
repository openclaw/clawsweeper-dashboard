## Summary

Keep open. Current main still waits for the assistant stream to finish before dispatching collected tool calls, and execute-on-parse would be a core scheduling and safety-policy feature rather than conservative cleanup.

## What This Changes

The issue requests an opt-in execute-on-parse mode so completed streamed tool calls can start before the rest of a streamed tool-call batch finishes.

## Best Possible Solution

Design a maintainer-approved core agent-loop mode that can start only safe completed tool calls during streaming while preserving transcript validity, ordering, hooks, approvals, cancellation, and a clear opt-in/default policy.
