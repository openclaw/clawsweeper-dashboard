## Summary

Keep open. Current main still waits for the assistant stream to finish before starting tool execution; this remains a real performance feature request that needs maintainer design rather than conservative cleanup.

## What This Changes

Requests an opt-in core agent-loop mode that executes fully parsed streaming tool calls before the rest of the assistant response finishes streaming.

## Best Possible Solution

Design a maintainer-approved opt-in agent-core scheduling mode that starts only concurrency-safe completed tool calls during streaming while preserving transcript, hook, approval, cancellation, and ordering invariants.
