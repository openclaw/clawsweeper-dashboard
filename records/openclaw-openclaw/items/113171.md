## What This Changes

The PR adds a process-local coordinator for `sessions.catalog.list` that coalesces identical scans, briefly reuses successful results, and bounds concurrent distinct provider loads with a queue.

## System Context

Control UI and other Gateway clients request a session catalog, and the Gateway fans that request out to registered catalog providers such as Codex and Claude. The proposed coordinator sits before those provider scans to share duplicate work, cache recent results, and limit concurrent expensive loads before responding to each client.
