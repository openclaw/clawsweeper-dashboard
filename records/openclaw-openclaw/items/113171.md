## What This Changes

This PR adds a Gateway-local session catalog coordinator that coalesces identical `sessions.catalog.list` scans, briefly reuses results, and limits concurrent and queued provider loads to reduce refresh-driven pressure.

## System Context

Control UI and other Gateway clients request session catalogs over RPC. The Gateway handler calls external catalog providers, streams progress to the requester, and returns catalog rows; this PR inserts a process-local coordinator before those provider scans to share equivalent work and bound bursts.
