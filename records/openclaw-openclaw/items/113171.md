## What This Changes

The PR adds process-local coalescing, brief caching, and concurrency admission control for Gateway session-catalog requests so repeated Control UI refreshes do not multiply provider scans.

## System Context

The Gateway serves `sessions.catalog.list` to Control UI and other clients, then queries registered session-catalog providers such as Codex and Claude. This PR inserts a process-local coordinator between equivalent RPC requests and those provider scans.
