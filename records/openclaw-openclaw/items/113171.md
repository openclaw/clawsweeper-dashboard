## What This Changes

This PR adds a process-local coordinator for Gateway session-catalog requests that shares identical scans, briefly reuses successful results, limits concurrent provider loads, and changes the auth-migration isolation test setup.

## System Context

The Gateway answers `sessions.catalog.list` for Control UI and other clients by querying registered session-catalog providers such as Codex and Claude. The proposed coordinator sits before those provider calls to share duplicate work and bound overload, then returns catalog rows, stale rows under pressure, or an availability error.
