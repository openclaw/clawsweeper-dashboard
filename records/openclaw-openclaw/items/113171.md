## What This Changes

This PR adds a process-local coordinator for `sessions.catalog.list` that shares identical scans, briefly caches successful catalog results, caps concurrent provider loads, and uses stale results or an unavailable error during pressure.

## System Context

The Gateway serves `sessions.catalog.list` to the Control UI and other clients by querying configured session catalog providers. The new coordinator sits before those provider scans, deciding whether to return fresh cached data, join an in-flight scan, begin a bounded new scan, or reject overload.
