## What This Changes

This PR adds per-process coordination for Gateway session-catalog requests so identical refreshes share work, recent results can be reused briefly, and overloaded provider scans are bounded.

## System Context

Control UI and other Gateway clients call `sessions.catalog.list` to discover sessions from configured catalog providers. This handler fans out to provider catalog scans and returns catalog rows to the caller, so its admission behavior affects Gateway responsiveness under repeated refreshes.
