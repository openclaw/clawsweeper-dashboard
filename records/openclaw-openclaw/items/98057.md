## Best Possible Solution

## Reproduction Assessment

## Solution Assessment

Yes, with maintainer acceptance: reusing the existing Feishu tool-account resolver is the narrow maintainable fix for the chat subset and matches sibling tools. The remaining question is whether maintainers accept the deliberate multi-account compatibility and fail-closed behavior before merge.
