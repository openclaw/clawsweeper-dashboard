## Summary

The PR is still necessary and should stay open for maintainer review: current main and the latest release still route `feishu_chat` through the first enabled account, while this branch aligns chat with the existing Feishu contextual account resolver and adds focused coverage plus sufficient redacted live/staged proof. ## What This Changes

The branch changes `feishu_chat` registration and execution to use the shared Feishu tool-account resolver with contextual account routing, plus regression tests for contextual selection, explicit `accountId` override, later-account registration, and disabled contextual-account fail-closed behavior.

## Best Possible Solution

Land the narrow chat-tool resolver alignment if maintainers accept the multi-account compatibility and credential-boundary behavior, while keeping the broader Feishu non-inbound binding work separate.

## Solution Assessment
