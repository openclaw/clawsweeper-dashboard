## Summary

## What This Changes

The branch adds `/DISABLE` after Windows Scheduled Task stop and `/ENABLE` before Scheduled Task restart in `src/daemon/schtasks.ts`.

## Best Possible Solution

Yes. Source inspection shows current main stops the managed gateway service before update work while `stopScheduledTask()` uses `/End` without disabling repeated triggers; I did not run a native Windows update in this read-only review.

## Solution Assessment

No. The PR is a plausible mitigation, but the narrower maintainable fix is to suspend and restore Scheduled Task autostart inside the update lifecycle rather than changing generic gateway stop/restart behavior.
