Keep open: current main still has the reported landing-gate gap, and the protected `maintainer` label means this should stay with a human owner rather than be auto-closed or auto-queued.

## What This Changes

The issue reports that the native PR landing workflow can accept a draft CI run with skipped validation as land-ready proof, then merge before the ready-for-review CI result is known.

## Best Possible Solution

Make `OPENCLAW_TESTBOX=1 scripts/pr prepare-run` require a successful non-draft CI preflight/job cohort, and make `scripts/pr merge-run` refresh exact-head hosted CI evidence immediately before `gh pr merge`.
