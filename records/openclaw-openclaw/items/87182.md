## Summary

Keep open: current main still falls back when repeated post-run session reads yield no assistant text, and multiple July reports reproduce the loss on v2026.7.1. The linked trajectory-recovery PR is neither merged nor proof-ready, so it cannot resolve this issue yet.

## What This Changes

Fix Dreaming narrative extraction so completed subagent output is retained or recoverable instead of being replaced with a fallback diary entry after cleanup.

## Best Possible Solution

Define one supported post-completion transcript-read contract at the subagent/session boundary, then update memory-core to consume it and retain trajectory recovery only as a bounded last-resort safety net with focused regression and live multi-phase Dreaming proof.
