## Summary

## What This Changes

The PR clears inline keyboards before routing unclaimed Telegram callback values as synthetic messages and adds coverage for successful, permanent-failure, and transient-failure cleanup outcomes.

## Best Possible Solution

Keep specialized callback handlers unchanged and clear generic single-use keyboards before synthetic routing, while retaining the proposed permanent-error best-effort behavior only after Telegram owners explicitly accept retry-first delivery for transient edit failures.
