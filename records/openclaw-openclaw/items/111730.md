## Summary

Keep this PR open: its parse-failure direction is sound, but valid JSON values that are not argument objects still reach the handler as `{}`, preserving the unsafe empty-argument dispatch the change is intended to prevent. Real after-fix behavior proof is also not present in the PR body or supplied discussion.

## What This Changes

The branch makes xAI realtime tool calls return early on `JSON.parse` failure and coerces successfully parsed non-object values to an empty argument object.

## Best Possible Solution

Reject every parsed `rawArgs` value that is not a plain argument object, add focused coverage for malformed and non-object inputs, and attach redacted realtime evidence that malformed input produces no handler invocation while a valid object still dispatches.
