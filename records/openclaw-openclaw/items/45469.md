The issue requests a bounded reconnect policy for GatewayClient.scheduleReconnect so permanently unreachable gateways do not retry forever.

Keep this issue open while maintainers choose the retry policy, then land a refreshed package-level fix with regression coverage for default long-lived clients and any bounded opt-in mode.
