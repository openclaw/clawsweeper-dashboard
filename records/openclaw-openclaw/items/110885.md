## Summary

Keep open for maintainer product direction. Current TaskFlow already provides the durable managed-flow, child-task, state, retry/conflict, and blocked/waiting foundation, while Workboard already provides durable cards, dependencies, dispatch, and lifecycle visibility; the remaining request is a broad choice to add a bundled pipeline product layer rather than an unimplemented bug.

## What This Changes

Add durable, ordered Workboard pipeline templates that dispatch specialized sub-agents, carry stage context forward, and gate progression on automated, agent, or manual verification.

## Best Possible Solution

Prove the workflow first as a separate code plugin built on managed TaskFlow plus existing Workboard cards and links; only bring back a narrowly defined missing plugin or Workboard extension API if that experiment identifies a concrete seam that cannot support the desired visibility or progression behavior.
