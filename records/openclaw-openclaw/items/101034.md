## Summary

Keep this issue open: current main has the shipped split-view foundation, but the requested sidebar-to-split drag/drop placement preview is still missing, and the protected maintainer label plus new Control UI interaction model require human product direction before implementation.

## What This Changes

Request to make Control UI sidebar session rows draggable into chat split-view drop zones with animated placement preview, active-pane placement, reduced-motion handling, and narrow-viewport fallback.

## Best Possible Solution

Add this as a first-class Control UI split-view enhancement using the existing split-layout model, a typed session-drag payload, explicit chat drop zones, reduced-motion-safe preview styling, and focused tests for placement, active pane, attachment-drop separation, and narrow viewport no-op behavior.
