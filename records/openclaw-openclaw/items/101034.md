Add a focused Control UI drag-and-drop layer on top of the existing split-layout model: private session payloads from sidebar rows, explicit pane drop-zone calculation, reduced-motion-aware preview animation, narrow-viewport no-op behavior, and focused unit plus browser proof that attachment drops and keyboard/header controls still work.
