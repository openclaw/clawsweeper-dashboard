## Summary

## What This Changes

Request sidebar session rows to drag into Control UI chat split panes with animated drop previews for replacing a pane or inserting left/right/top/bottom panes.

## Best Possible Solution

Add a focused Control UI drag-and-drop layer on top of the existing split-layout model: private session MIME payloads from sidebar rows, explicit chat-pane drop-zone calculation, reduced-motion-aware preview animation, narrow-viewport no-op behavior, and focused unit plus browser proof that attachment drops and keyboard/header controls still work.
