## What This Changes

The PR gives gateway channel retries an independent cancellation lifecycle, cancels pending retry supervision on intentional stops, logs and reconciles failed restart work, and adds race-focused gateway tests.

## System Context

The gateway channel manager starts plugin channel accounts and observes their run completion. When a provider exits, it records runtime status, waits through backoff, and starts the account again unless an operator has intentionally stopped that account.
