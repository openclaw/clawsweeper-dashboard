## Summary

Keep open: current main and the latest release still send the implicit English audio prompt with explicit non-English audio language hints, and the two linked fixing PRs are open but not merged.

## What This Changes

The issue asks OpenClaw to avoid injecting the built-in English audio transcription prompt when an explicit non-English STT language hint is configured and no custom prompt is set.

## Best Possible Solution

Land one reviewed fix that suppresses only the implicit English audio prompt for explicit non-English language hints while preserving explicit prompts, then close this issue after merge.

## Reproduction Assessment

Yes, at source level: current main deterministically resolves the built-in English audio prompt and forwards it with explicit audio language hints. The exact Groq output bias was not re-run live in this read-only review.

## Solution Assessment
