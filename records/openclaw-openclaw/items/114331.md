## What This Changes

This PR makes compatible bundled provider plugins derive API-key setup and default/static catalog registration from their existing manifests, while retaining provider-specific overrides for onboarding, discovery, and streaming.

## System Context

Bundled provider plugins register authentication and model catalogs through the Plugin SDK, which feeds provider setup, configured model selection, and runtime catalog discovery. This refactor moves duplicated registration metadata into plugin-owned manifests while leaving provider-specific behavior in each plugin.
