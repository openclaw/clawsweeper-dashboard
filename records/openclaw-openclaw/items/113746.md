## Summary

This PR is still necessary if OpenClaw wants first-class, bounded Memory Wiki automation: current `main` has only the single-operation CLI paths, while the branch introduces shared-preparation batch paths. The patch and supplied terminal proof look credible, but merging creates two documented bundled-plugin CLI contracts, so explicit maintainer product sponsorship—not another mechanical repair—is the remaining gate.

## What This Changes

The branch adds versioned JSON `wiki apply-batch` and `wiki search-batch` commands that process bounded Memory Wiki write and verification workloads with shared setup and at most one compilation.

## System Context

Memory Wiki is OpenClaw’s bundled companion knowledge-vault plugin: CLI commands ingest source material, update wiki pages, compile derived indexes, and search the resulting vault. This PR adds a machine-oriented path between manifest input and those existing mutation/search operations so an automation can avoid repeatedly restarting and recompiling the same vault.
