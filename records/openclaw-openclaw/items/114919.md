## What This Changes

This PR separates stale and forced cron schedule preservation, centralizes FIFO cron run-slot release, and relocates watchdog regressions into their focused timer test suite.

## System Context

Cron runs load a scheduled job, evaluate whether it fires, and write the resulting scheduling state back to the cron store. This change controls how an operator edit made during a run is preserved, then ensures queued runs release their shared admission slot exactly once.
