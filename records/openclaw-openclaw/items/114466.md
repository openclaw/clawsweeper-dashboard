## What This Changes

The PR strips OpenClaw internal runtime-context wrappers from Discord content, embeds, component text, fallbacks, forwarded snapshots, and preflight audio-caption decisions before the message reaches session handling.

## System Context

Discord inbound events are converted into visible user text before preflight, media processing, and session dispatch. The resolver chooses between primary content and Discord-native fallbacks, so its sanitization determines what users and agents receive downstream.
