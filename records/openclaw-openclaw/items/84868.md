## What This Changes

The PR preserves nested provider request SecretRef markers in generated `models.json`, strips marker placeholders before outbound transport use, and audits generated catalogs for plaintext request credentials.

## Best Possible Solution

Keep one source-authoritative marker projection path for all documented request SecretInputs, strip only recognized reserved markers at the transport boundary, restrict audit findings to credential-bearing fields and sensitive header names, then rebase and prove both fresh generation and upgrade from an existing plaintext `models.json`.
