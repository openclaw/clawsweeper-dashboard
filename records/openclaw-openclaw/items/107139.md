## Summary

This PR remains necessary only as a partial hardening attempt, but it does not protect the compromised-ClawHub package-download boundary described in its threat model; the default workspace package flow remains outside the new limit.

## What This Changes

The PR adds a 256 MiB declared-length and streamed-byte limit to download installers for selected skill source classifications and adds focused regression tests.

## Best Possible Solution

Enforce a centrally owned byte limit on the actual ClawHub archive or resolved-download path, then separately define any metadata-installer limit from package provenance rather than workspace-versus-managed destination classification.
