## Summary

Keep this PR open: the streaming limiter is well-structured, but its source-class gate excludes default workspace ClawHub installs, so the stated registry-origin dependency-download threat remains reachable; the supplied evidence is also test-only.

## What This Changes

The PR adds a 256 MiB declared-length and streamed-byte limit to dependency downloads for bundled, managed, and extra-directory skills, with focused regression tests.

## Best Possible Solution

Carry verified ClawHub install provenance into the gateway dependency-installer policy and apply the 256 MiB declared/stream cap there while leaving genuinely local workspace installers unchanged, then prove the default ClawHub-to-dependency-install flow against an oversized response.
