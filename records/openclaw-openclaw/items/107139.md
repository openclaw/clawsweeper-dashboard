## Summary

Keep this PR open for a focused repair. The two-layer size-limit design is appropriate, but the streaming counter observes chunks through a `PassThrough` data event, so the boundary-crossing chunk can already be forwarded to disk before the stream is destroyed; the supplied test and proof cover only the declared Content-Length path.

## What This Changes

The PR adds a 256 MB Content-Length pre-check and streamed-byte counter to skill package downloads, plus a loopback test for oversized declared lengths.

## Best Possible Solution

Use a Transform that checks the prospective cumulative size before forwarding each chunk, reject the boundary-crossing chunk, and verify declared-length and undeclared streaming failures plus temporary-file cleanup.
