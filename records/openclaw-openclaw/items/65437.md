## What This Changes

## Best Possible Solution

Define a narrow, maintainer-approved elevated directive authorization rule that avoids silent Slack drops while preserving least privilege, then update Slack/Discord regression tests and docs for room/group and DM behavior.

- **Keep strict command auth:** Require Slack command authorization separately and document the prerequisite plus a visible denial path instead of letting elevated allowlists affect command ingress.
- **Unify channel fallback hooks:** Register channel-level elevated fallback adapters for Slack and Discord together, accepting the broader cross-channel semantics work before merge.

## Solution Assessment

Unclear until maintainer intent is set: the narrowest maintainable fix is probably an elevated-only command-gate exception or visible denial path, but the repository should not widen Slack command authorization without a security-boundary decision.
