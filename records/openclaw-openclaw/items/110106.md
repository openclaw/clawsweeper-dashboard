## Summary

Keep open: the branch correctly bounds the caller wait, but its timed-out 30/65-second node invocations can overlap on subsequent sidebar polls; the protected maintainer-routed PR needs an explicit single-flight decision before merge.

## What This Changes

Adds an eight-second fail-soft response deadline to passive paired-node Claude and Codex session catalog reads, with regression tests for hung node invocations.

## Best Possible Solution

Preserve the eight-second fail-soft response deadline, but coalesce an in-flight passive catalog request per node and catalog owner until it settles so repeated polls do not accumulate slow background invocations.
