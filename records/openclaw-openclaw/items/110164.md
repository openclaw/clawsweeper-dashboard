## Summary

## What This Changes

The branch changes QA Lab credential-payload loading to read at most the configured byte cap plus one byte from a single opened file handle and adds boundary and growth-race tests.

## Best Possible Solution

Keep the bounded same-handle read, but make FIFO handling nonblocking before validating the opened handle, add an unopened-FIFO regression test, then attach redacted real CLI/runtime evidence for boundary acceptance and oversize rejection.
