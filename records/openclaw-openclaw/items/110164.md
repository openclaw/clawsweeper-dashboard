## Summary

Keep this PR open: it still opens a supplied FIFO in blocking mode before it checks that the opened handle is a regular file, so a non-regular payload path can hang the QA Lab CLI. The previous review identified this same blocker and the current head still contains it; the reported real-behavior workflow supports the bounded-read paths but not this unresolved availability case.

## What This Changes

The PR replaces stat-then-read credential payload loading with a single opened-handle bounded read and adds boundary-size and growth-race coverage.

## Best Possible Solution

Open the payload handle without blocking, retain opened-handle regular-file and byte-cap checks, and add focused FIFO coverage so malformed payload paths fail promptly rather than hanging.
