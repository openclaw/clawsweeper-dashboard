## Summary

Keep open: the bounded read closes the growth race, but opening the path before validating its file type can block the credential CLI on a FIFO; it also still needs contributor-supplied real runtime proof. Likely related people: the QA Lab feature-history owner could not be established from the available read-only evidence, so routing confidence is low.

## What This Changes

The branch replaces a path-level stat plus full read with a single opened handle, validates that handle, reads at most the configured cap plus one byte, and adds boundary and growth-race tests.

## Best Possible Solution

Retain the bounded handle read, but make the pre-validation open nonblocking for special files, validate the opened handle is regular, and add a focused FIFO regression test plus redacted live CLI evidence for acceptance and rejection paths.
