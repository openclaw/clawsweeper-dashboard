## Summary

Keep open: the report describes a severe, release-current Telegram regression, and current main has a central sanitizer that should remove this exact delimiter, but the evidence does not yet isolate whether Telegram streaming previews, inbound replay, or another projection bypasses that sanitizer. ## What This Changes

Prevent internal runtime-context wrappers and accumulated session metadata from appearing in Telegram replies.

## Best Possible Solution

Keep runtime context structured and model-visible, but route every Telegram preview and final reply through one shared user-visible sanitizer; add mixed-wrapper and wrapper-only regression coverage, and provide an in-product chat reset action if contaminated session state survives the fix.
