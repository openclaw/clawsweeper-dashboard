## Summary

Keep open: current main and the latest release still drop flattened compact Tool Search arguments, and this PR targets the right parser layer, but the current head still drops legitimate flattened target `id`/`name` fields and has no real localModelLean runtime proof.

## What This Changes

The PR changes Tool Search `readCallArgs` to forward flattened top-level `tool_call` fields when `args`/`input` are absent and adds focused regression coverage.

## Best Possible Solution

Land one selector-aware Tool Search normalization that preserves explicit `args`/`input`, removes only consumed wrapper metadata, covers selector collisions, and includes redacted localModelLean proof.
