## Summary

Keep open. Current main still has adjacent generic agent/item/plan/tool/lifecycle events, `session.tool`, and `agent.wait`, but it does not implement the requested durable `process.*` / `step.*` session event contract with stable step identity and replay/reload semantics.

## What This Changes

The issue requests session-level structured process and step events with stable identity, sequencing, timestamps, and related message/tool/artifact ids so clients stop deriving progress from assistant text.

## Best Possible Solution

Define one additive, permission-checked core process-event contract with stable step identity, bounded replay/persistence, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
