## Summary

Keep open. Current main has adjacent agent item/tool/lifecycle/session streams, and upstream Codex has turn/item/todo events, but the requested durable session-level process/step contract with stable step identity and replay/reload semantics is still missing.

## What This Changes

Request to add session-level structured process and step events with stable identity, sequencing, timestamps, and related message/tool/artifact links so clients can render progress without parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded persistence/replay, redaction rules, and mappings from existing agent item, plan, tool, task, and upstream Codex event streams.
