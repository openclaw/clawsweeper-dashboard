## Summary

Keep open. Current main has adjacent agent item/plan/tool/lifecycle and session message/operation/tool streams, but it still lacks the requested stable session-level process/step event contract with replay/reload semantics and a settled security model.

## What This Changes

Request to add session-level `process.*` and `step.*` events with stable step identity, sequencing, timestamps, and related tool/message/artifact links.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay/reload semantics, redaction, ordering guarantees, and mappings from existing item, plan, tool, lifecycle, session, plugin, and artifact streams.
