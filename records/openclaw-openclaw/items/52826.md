## Summary

Keep open. Current main and the latest release still have adjacent agent, item, plan, tool, lifecycle, `session.tool`, and session operation events, but not the requested session-level `process.*` / `step.*` contract with stable step identity, related IDs, and replay/reload semantics.

## What This Changes

The issue requests structured session process events such as `process.started` and `step.completed`, carrying session/run ordering metadata and related tool, message, and artifact IDs.

## Best Possible Solution

Define one additive, permission-checked process-event contract with bounded persistence/replay, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
