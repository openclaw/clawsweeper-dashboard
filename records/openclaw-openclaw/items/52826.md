## Summary

Keep open. Current main has adjacent agent, item, plan, tool, lifecycle, session.tool, and agent.wait surfaces, but it still lacks the requested session-level process.* / step.* contract with stable step identity, related IDs, and replay/reload semantics.

## What This Changes

The issue requests structured session process events so clients can render run progress as source-of-truth state instead of parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked session process-event contract with stable step identity, bounded persistence/replay, ordering rules, and redaction before mapping existing agent/tool/lifecycle signals into it.
