## Summary

Keep open. Current main and the latest release have adjacent agent/item/plan/tool/session event streams, but they still do not define the requested session-level process.* / step.* contract with stable step identity, related ids, and reconnect/reload semantics.

## What This Changes

The issue requests structured session process and step events so clients can render progress as source-of-truth state instead of parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay or refresh semantics, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
