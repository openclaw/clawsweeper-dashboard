## Summary

Keep open. Current main still has adjacent agent, item, tool, lifecycle, `session.tool`, SDK-normalized, and `agent.wait` event paths, but not the requested session-level `process.*` / `step.*` contract with stable step identity, replay/reload semantics, and redaction rules.

## What This Changes

The issue requests session-level structured process and step events with stable identities so clients can render progress without parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step ids, bounded persistence/replay, redaction, and mappings from existing agent item/plan/tool/task streams before implementation.
