## Summary

Keep open. Current main and v2026.6.11 still expose adjacent lifecycle, item, plan, tool, and session.tool streams, but not the requested session-level process/step contract with stable step identity, replay/reload semantics, and a settled authorization/redaction model.

## What This Changes

Request to add session-level process and step events with stable IDs and linkage to runs, messages, tools, and artifacts.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay, redaction rules, and mappings from existing agent item, plan, tool, lifecycle, and task streams.
