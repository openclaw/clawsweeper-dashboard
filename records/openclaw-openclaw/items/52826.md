## Summary

Keep open. Current main still has adjacent agent, item, plan, tool, lifecycle, and session.tool streams, but not the requested session-level process.* and step.* event contract with stable step identity, related IDs, persistence, and reload semantics.

## What This Changes

The issue requests structured session process and step events so clients can render run progress as source-of-truth state instead of parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay/persistence, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
