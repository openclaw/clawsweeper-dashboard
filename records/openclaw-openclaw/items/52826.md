## Summary

Keep open. Current main still lacks the requested session-level process and step event contract with stable step identity, replay/reload semantics, and related tool/message/artifact ids; the remaining work needs product and security design before implementation.

## What This Changes

The issue requests structured session process events such as process and step lifecycle events so clients can render progress from a stable source of truth instead of parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay/persistence, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, artifact, and Codex turn streams.
