## Summary

Keep open. Current main still has generic agent/session/tool progress streams and SDK run-event replay, but it does not implement the requested session-level `process.*` / `step.*` contract with stable step identity, related ids, and reconnect/reload source-of-truth semantics.

## What This Changes

The issue requests session-level structured `process.*` and `step.*` events with stable step identity, ordering, timestamps, and related tool/message/artifact ids.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, ordering, bounded replay/persistence, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
