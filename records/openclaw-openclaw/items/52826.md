## Summary

Keep open. Current main still has adjacent generic agent, item, tool, lifecycle, and session.tool streams, but not the requested stable process/step event contract or replayable session-level source of truth.

## What This Changes

The issue requests session-level structured process and step events with stable step identity and linkage to run, tool, message, and artifact ids.

## Best Possible Solution

Define one additive, permission-checked process/step event contract with stable ids, bounded persistence/replay, redaction rules, and mappings from existing agent item, plan, tool, lifecycle, and task streams.
