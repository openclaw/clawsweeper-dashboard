## Summary

Keep open. Current main still has adjacent agent, item, plan, tool, lifecycle, session.message, session.operation, and session.tool streams, but it does not define the requested session-level process.* and step.* event contract with stable step identity, replay/reload semantics, and security boundaries.

## What This Changes

The issue requests a new session-level process/step event contract so clients can render progress without parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
