## Summary

Keep open. Current main has adjacent agent, item, plan, tool, lifecycle, session.message, session.operation, and session.tool streams, but it still lacks the requested session-level process.* and step.* contract with stable step identity and replay/reload semantics.

## What This Changes

Request session-level structured process and step events with stable identity so clients can render progress without parsing assistant markdown.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
