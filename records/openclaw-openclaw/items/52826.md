## Summary

Keep open. Current main has adjacent agent, item, tool, lifecycle, and session event streams, but it still does not provide the requested stable `process.*` / `step.*` session-level event contract; product and security design are still needed.

## What This Changes

Add session-level process and step events with stable identity, ordering, timestamps, session/run ids, and related tool/message/artifact ids so clients render progress without parsing assistant text.

## Best Possible Solution

Define an additive, permission-checked core process-event contract that maps existing agent/item/tool/lifecycle streams into stable step state with replay/reload, ordering, retention, and redaction rules.
