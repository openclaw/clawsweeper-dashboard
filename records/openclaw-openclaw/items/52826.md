## Summary

Keep open. Current main and the latest release have adjacent agent, item, tool, message, lifecycle, and compact-operation streams, but they still do not define the requested session-level process.* and step.* event family with stable step identity and replay/reload semantics.

## What This Changes

The issue requests durable session-level process and step events with stable identity so clients can render progress without parsing assistant text.

## Best Possible Solution

Define a narrow core Gateway/session process-event contract with stable IDs, replay semantics, redaction and authorization rules, and client mapping before implementing runtime-specific renderers.
