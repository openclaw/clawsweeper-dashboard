## Summary

Keep open. Current main still has adjacent agent/item/plan/tool/lifecycle streams plus session-scoped tool and operation events, but it does not provide the requested session-level process.* / step.* contract with stable step identity, related ids, and replay/reload semantics.

## What This Changes

The issue requests session-level structured process and step events with stable identity so clients can render run progress without parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
