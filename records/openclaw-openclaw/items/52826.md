## Summary

Keep open. Current main and latest release still provide adjacent lifecycle, item, plan, tool, session.tool, session.operation, task, and audit surfaces, but they do not implement the requested session-level process/step event taxonomy with stable step identity, replay/reload semantics, and explicit authorization/redaction rules.

## What This Changes

The issue requests stable session-level process and step events so clients can render session progress without parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay, explicit redaction, and clear mappings from existing agent item, plan, tool, lifecycle, task, and audit streams.
