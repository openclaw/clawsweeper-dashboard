## Summary

Keep open. Current main and the latest release expose adjacent generic agent/session event streams, but they do not provide the requested stable `process.*` and `step.*` session process contract; that remaining work needs product and security design before implementation.

## What This Changes

The issue requests stable session-level process and step events so clients can render progress as source-of-truth state without parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
