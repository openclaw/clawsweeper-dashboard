## Summary

Keep open. Current main still has adjacent agent `item`/`plan`/tool/lifecycle streams and `session.tool`, but it does not implement the requested stable session-level `process.*`/`step.*` contract, replay/reload semantics, or explicit redaction and authorization boundary.

## What This Changes

The issue requests stable session-level structured process and step events so clients can render progress as source-of-truth state instead of parsing assistant text.

## Best Possible Solution

Define one additive, permission-checked process-event contract with stable step identity, bounded replay/persistence, ordering guarantees, redaction rules, and mappings from existing item, plan, tool, lifecycle, task, and artifact streams.
