## Summary

Keep open: current `origin/main` still activates the newly selected file before a shared loading guard rejects its content request, leaving the editor inconsistent with the workspace file. The report has a deterministic real-Gateway reproduction, and no duplicate or fix PR was found.

Likely related people: `vincentkoc` introduced the current loading path; `steipete` recently maintained adjacent draft-preservation behavior.

## What This Changes

Fix rapid Agent Files tab switching so selecting a second file during an in-flight read cannot leave its active editor persistently blank.

## Best Possible Solution

Give file-content reads an active request identity or latest-selection queue, retain drafts keyed per file, and add same-client out-of-order response coverage at the controller boundary.
