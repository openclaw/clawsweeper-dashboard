## What This Changes

This PR records each embedded-agent command-lane wait so stale run-context cleanup does not treat scheduler delay as agent inactivity.

## System Context

Embedded-agent runs register a run context before entering global or session command lanes. The stale-context sweeper uses that context to detect lost work; this change carries queue-admission state into the sweeper so queued work survives until it can execute.

## Architecture Diagram

flowchart LR

  D --> E[Stale-context sweep]

  F --> G[Release final queue wait]
  G --> H[Normal inactivity cleanup]

## Best Possible Solution

Keep queue waiting as explicit, reference-counted lifecycle state on the exact registered context, then land only after a current-main rebase confirms both queued-run preservation and post-admission cleanup.
