## What This Changes

The PR records outstanding embedded-agent command-lane waits so stale-context cleanup does not mark a queued run as lost before its task is admitted.

## System Context

Embedded-agent runs register an in-memory run context before their work enters global or session command lanes. The agent-event subsystem later sweeps inactive contexts, and that cleanup affects lifecycle terminal handling and any orchestration that reacts to a lost execution context.
