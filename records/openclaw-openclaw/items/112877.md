## What This Changes

The PR adds reference-counted queue-wait tracking for embedded-agent run contexts so stale cleanup does not expire work before command-lane admission.

## System Context

Embedded-agent runs register a run context before command-lane admission, and stale cleanup later decides whether that work is still live. This change marks the intervening queue wait as active so a saturated scheduler can admit the run without a false lost-context terminal result.
