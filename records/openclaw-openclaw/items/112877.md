## What This Changes

This PR prevents queued embedded agent runs from expiring before command-lane admission by tracking active queue waits and restarting ordinary inactivity cleanup after the final wait ends.

## System Context

Embedded agent runs register in-memory run contexts before entering global and session command lanes. The stale-context sweep uses those contexts to protect live work; this change distinguishes scheduler waiting from actual agent inactivity.
