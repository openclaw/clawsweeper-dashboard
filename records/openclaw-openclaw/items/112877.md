## What This Changes

The PR tracks pending command-lane waits so queued embedded-agent runs are not removed by stale-context cleanup before their work is admitted.

## System Context

Embedded-agent runs register lifecycle context before they enter shared and session-specific command lanes. The event subsystem later sweeps inactive contexts, so the scheduler’s queued state must prevent a run from being classified as abandoned before execution begins.
