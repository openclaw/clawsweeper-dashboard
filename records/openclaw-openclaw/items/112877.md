## What This Changes

The PR keeps queued embedded-agent runs from expiring by preserving their event context until command-lane admission and restarting normal inactivity tracking after the final queued wait ends.

## System Context

Embedded agent runs register lifecycle context before entering global and session command lanes. The stale-context sweeper later uses that context to determine whether an agent run is still active; this patch makes queue admission count as active waiting rather than idle time.

## Architecture Diagram

flowchart TD
  A[Embedded agent run] --> B[Register run context]
  B --> C[Global and session command lanes]
  C --> D[Queue-wait claim]
  D --> E[Stale-context sweep]
  C --> F[Lane admission]
  F --> G[Release final wait and restart TTL]
  G --> H[Agent execution and terminal events]

## Best Possible Solution

Keep lifecycle ownership in the agent-event subsystem, retain queue waits only until the exact queued operation admits or settles, and add a redacted real load trace showing a run survives a TTL-length wait then returns to ordinary stale cleanup.
