## What This Changes

The PR preserves an embedded agent run context while its work waits in global or session command lanes, then resumes normal stale-context cleanup after the final queued operation is admitted or settles.

## System Context

Embedded-agent runs register an in-memory context before they enter shared command lanes. The stale-context sweeper uses that context to detect abandoned work; this PR makes queued-but-not-yet-admitted work distinguishable from inactive execution so the orchestrator does not false-terminal it.
