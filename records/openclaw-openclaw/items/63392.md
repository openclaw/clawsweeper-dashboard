## Summary

Keep open: current main and the latest release still expose whole-install `backup create` and `backup verify` only, while the requested per-agent `--agent` and `--as` restore/clone workflow remains missing. The request is useful, but it needs maintainer product and security direction before implementation.

## What This Changes

Add per-agent backup, restore, and clone support to the backup/restore CLI, including `--agent` scoping and restore-as-new-agent behavior.

## Best Possible Solution

Keep this as the narrow per-agent recovery tracker and design a maintainer-sponsored core extension that reuses the existing manifest/SQLite snapshot model, defines credential and transcript portability, and adds guarded `--agent`/`--as` tests plus docs.
