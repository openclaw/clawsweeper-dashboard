## Summary

Keep open: current main and v2026.6.11 still expose whole-install backup create/verify only, while the requested per-agent `--agent` and `--as` restore/clone workflow remains missing and needs product/security design before implementation.

## What This Changes

Request adds per-agent backup, restore, and clone CLI support through `--agent` and `--as` for agent workspaces, state, sessions, and config entries.

## Best Possible Solution

Keep this as the narrow per-agent recovery tracker and design a maintainer-sponsored core extension that reuses the backup manifest and SQLite snapshot model with explicit credential/session portability, safe extraction, rollback, path-rewrite tests, and docs.
