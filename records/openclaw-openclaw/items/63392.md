## Summary

Keep open: current `main` and the latest release still expose whole-install backup creation and verification only, while the requested per-agent `--agent` and `--as` restore/clone workflow remains missing and security-sensitive.

## What This Changes

Add per-agent backup, restore, and clone CLI support for copying one agent's workspace, persisted state, sessions, and config entry, optionally restoring under a new agent id.

## Best Possible Solution

Keep this as the narrow per-agent recovery tracker and design a maintainer-sponsored core backup/restore extension with explicit archive contents, credential/session portability rules, rollback safety, tests, and docs.
