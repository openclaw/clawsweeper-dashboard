## Summary

Keep open: current main and v2026.6.11 still expose whole-install backup create/verify only, while the requested per-agent backup, restore, and clone workflow remains missing. Related backup and migration items overlap, but none currently owns the per-agent `--agent`/`--as` clone contract.

## What This Changes

Request adding per-agent backup, restore, and clone support that archives one agent's workspace, state, sessions, and config entry, with optional restore under a new agent id.

## Best Possible Solution

Keep this as the narrow per-agent recovery tracker and design a maintainer-sponsored core backup/restore extension with explicit credential, transcript, path-rewrite, rollback, and archive-compatibility rules.
