## Summary

Keep open: current main still exposes whole-install backup creation and verification only, while the requested per-agent `--agent` and `--as` backup/restore/clone workflow remains missing and needs product plus security design before implementation.

## What This Changes

Request to add per-agent backup, restore, and clone support to the OpenClaw CLI, including `--agent` scoping and `--as` rename behavior.

## Best Possible Solution

Keep this as the narrow per-agent recovery tracker and have maintainers sponsor a core backup/restore design that defines archive scope, credential portability, transcript handling, rollback, and `--agent`/`--as` CLI behavior before implementation.
