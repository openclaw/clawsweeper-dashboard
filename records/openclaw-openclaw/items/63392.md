## Summary

Keep open: current `main` and the latest release still expose whole-install backup creation/verification only, while the requested per-agent `--agent` and `--as` backup/restore/clone workflow remains unimplemented and needs product/security design before any fix PR.

## What This Changes

Add per-agent backup, restore, and clone support so one agent can be recovered or duplicated without restoring the full OpenClaw instance.

## Best Possible Solution

Keep this as the narrow core tracker for a guarded per-agent archive/restore contract that reuses existing backup manifests, SQLite snapshotting, agent config helpers, and documented credential/session portability rules.
