## Summary

Keep open: current main and v2026.6.11 still expose whole-install backup creation and verification only, while the requested per-agent `--agent` backup plus restore/clone `--as` workflow remains missing and needs product/security scoping.

## What This Changes

Request per-agent backup, restore, and clone support for OpenClaw-owned workspaces, agent state, sessions, and config entries.

## Best Possible Solution

Keep this as the narrow per-agent recovery tracker and design a maintainer-sponsored core backup/restore extension that reuses the manifest/SQLite snapshot model while explicitly defining secret, transcript, path-rewrite, and rollback semantics.
