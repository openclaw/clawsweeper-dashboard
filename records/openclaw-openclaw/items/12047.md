## Summary

Keep open: current main and v2026.6.11 still download Telegram documents and can extract text/PDF-like files, but Office-style document contents are deliberately skipped before extraction and the prior DOCX implementation PR was closed unmerged after proof and security blockers.

## What This Changes

Request to extract readable text from Telegram document attachments such as DOCX, PDF, TXT, and Markdown and include that content in agent-visible message context.

## Best Possible Solution

Implement maintainer-approved Office document support through the shared document-extractor, media-understanding, and input_file paths with bounded MIME scope, resource limits, untrusted-content wrapping, Telegram coverage, and docs.
