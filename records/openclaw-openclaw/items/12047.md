## Summary

Close as plugin-scoped: current main already provides shared extraction for text and PDF attachments, while Office-format parsing is an optional, dependency-heavy capability that the public document-extractor plugin contract can supply without adding Telegram-specific policy to core.

## What This Changes

Add automatic extraction of text from Telegram document attachments so the agent receives readable document contents instead of only a media placeholder.

## Best Possible Solution

Publish an Office-capable code plugin through ClawHub using the existing document-extractor contract, with manifest metadata, an entrypoint, explicit MIME coverage, least-privilege permissions and secrets/config, bounded archive/CPU/memory limits, install/update documentation, example usage, and real attachment smoke proof; ClawSweeper should not open a ClawHub issue or PR, create a tracker, or publish the package for the contributor.

## Solution Assessment

Yes, but not as a Telegram-specific core option: the narrow maintainable solution is an Office document-extractor plugin using the existing shared contract, so every attachment source can benefit without duplicating channel policy.
