## Summary

Keep open: current main and v2026.6.11 handle Telegram document download plus text/PDF extraction, but Office-style document contents are still intentionally excluded before extraction and the prior DOCX PR was closed unmerged after proof and security blockers.

## What This Changes

Request to extract readable text from Telegram document attachments into agent context instead of leaving only media placeholders.

## Best Possible Solution

Implement maintainer-approved Office document support through the shared document-extractor, media-understanding, and input_file paths with bounded MIME scope, resource limits, untrusted-content wrapping, Telegram coverage, and docs.
