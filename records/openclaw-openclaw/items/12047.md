## Summary

Keep open: current main and v2026.6.11 cover Telegram document download plus text/PDF extraction, but Office-style Telegram document contents are still skipped before shared extraction and no merged related PR owns the remaining work.

## What This Changes

The issue requests text extraction for Telegram document attachments so the agent receives readable document contents instead of only a media placeholder.

## Best Possible Solution

Extend the shared document-extractor and media-understanding path, not Telegram-only code, with maintainer-approved Office MIME scope, parser/dependency ownership, archive/XML limits, untrusted-content wrapping, focused tests, docs, and live Telegram proof.
