## Summary

Keep open: current main and v2026.6.11 still download and surface Telegram document attachments, but Office-style document contents are intentionally excluded before extraction, so the core requested capability remains missing.

## What This Changes

Request to extract readable text from Telegram document attachments and include it in agent context instead of only showing a document media placeholder.

## Best Possible Solution

Implement maintainer-approved Office document support through the shared document-extractor and media-understanding/input_file paths, with bounded MIME scope, archive/XML limits, untrusted-content wrapping, Telegram coverage, docs, and any optional markitdown-style companion kept in ClawHub/MCP.
