## What This Changes

Adds a private 30-second handshake timeout to Mattermost’s default WebSocket client and regression coverage proving stalled upgrades return control to the reconnect loop.

## Best Possible Solution

Use the upstream `ws` timeout in the existing private factory, retain the reconnect regression proof, and merge once the Mattermost owner confirms that 30 seconds is the supported default rather than adding another configuration option.
