## What This Changes

The PR adds a plugin-local 30-second Mattermost WebSocket handshake deadline and regression coverage for stalled upgrades returning control to the reconnect loop.

## Best Possible Solution

Keep the deadline plugin-local and fixed at the established 30-second sibling value, retain the stalled-peer and reconnect regressions, and avoid adding configuration unless maintainers have concrete evidence of supported Mattermost deployments needing longer upgrades.
