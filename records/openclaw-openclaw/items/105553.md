## What This Changes

## Best Possible Solution

Land the private `ws` handshake bound and its regression coverage once a Mattermost reconnect owner accepts the 30-second threshold, retaining no new config surface unless real deployment evidence demonstrates that a fixed internal bound is inadequate.
