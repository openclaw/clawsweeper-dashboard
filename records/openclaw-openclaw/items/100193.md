## What This Changes

The PR makes Anthropic thinking-block recovery inspect string error details carried in `body`, `detail`, and `responseBody`, with positive and non-thinking regression coverage.

## System Context

The embedded agent runner wraps Anthropic streaming calls so it can repair a rejected thinking-block replay and retry once. Error details flow from provider wrappers into the recovery detector, which decides whether to rewrite the affected session history before retrying the provider call.
