## What This Changes

This PR adds an explicitly requested, durable `status_changed` Workboard notification by recording card status transitions in SQLite and returning them only to subscriptions that list that event kind.

## System Context

Workboard is the bundled, plugin-owned local board for one OpenClaw Gateway, storing cards and subscription state in a SQLite database. Card updates persist status changes, and notification reads filter those records into durable delivery events for subscribed downstream consumers.
