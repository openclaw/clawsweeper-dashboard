## What This Changes

This PR adds an opt-in Workboard `status_changed` notification kind, records status transitions with their run/session scope, exposes the kind through the subscription tool schema, and documents how subscribers receive it.

## System Context

Workboard persists cards and their lifecycle records in the plugin’s SQLite database, then reads matching records for notification subscriptions. The proposed transition table feeds a new opt-in notification stream that downstream consumers can route by card, session, or run.
