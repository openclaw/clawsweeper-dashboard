## What This Changes

This PR removes the ACP local-path-only attachment gate so URL-only images can be forwarded into agent turns, changes Synology Chat invalid-token throttling to lock at the configured threshold, clamps zero-budget pre-auth throttling, and adds focused regression tests.

## Best Possible Solution

## Reproduction Assessment

Yes at source level: current main normalizes URL-only media but the ACP resolver rejects image attachments without a local path, and the Synology limiter uses strict greater-than checks. I did not run tests because this is a read-only review.

## Solution Assessment

Yes: the PR delegates URL/local resolution to the existing MediaAttachmentCache and changes the Synology limiter at the decision point while preserving the zero-budget valid-token case. A custom ACP fetch path or separate limiter layer would duplicate existing owner boundaries.
