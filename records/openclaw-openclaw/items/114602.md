## What This Changes

Ensure that turns completed by a fallback model record the same `tool.call` and `tool.result` trajectory events as primary-model turns when tools actually run.

## System Context

OpenClaw dispatches an agent turn to a selected model and may switch to a fallback provider after a failure. Tool executions and model lifecycle events are written to the session trajectory JSONL, which downstream audit and receipt systems consume.

## Architecture Diagram

  E --> F
  F --> G[Trajectory event recorder]
  G --> H[Session audit JSONL]

## Best Possible Solution

Trace the primary, fallback, and Claude CLI execution paths to one canonical tool-event recording seam, then add regression coverage that verifies tool-call and tool-result events after a fallback-triggered tool run without changing provider fallback behavior.
