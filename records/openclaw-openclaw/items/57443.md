## What This Changes

The issue asks for unsupported JSON Schema keywords such as `patternProperties` to be stripped for BytePlus Ark/doubao tool schemas instead of only for Google/Gemini-style providers.

## Best Possible Solution

Add provider-owned BytePlus/Ark schema compatibility on the active model-compat path, with focused regression tests and live Ark proof; adopt universal non-Anthropic cleaning only if maintainers explicitly choose that broader policy.
