## Summary

This PR remains necessary because current `main` still has the unbounded installer fetch, but the revised cleanup introduces a blocking successful-run failure: the `EXIT` trap references a function-local variable after that function has returned. The added stalled-response transcript does not exercise that path.

## What This Changes

The PR replaces the install-smoke `curl | bash` pipeline with a bounded temporary-file download and direct execution, adds exit cleanup, and extends stalled-response regression coverage.

## Best Possible Solution

Run the temporary download and installer execution inside a subshell whose `EXIT` trap owns a variable that remains live until that subshell exits, then cover both stalled failure and successful cleanup/exit-zero behavior.

- **[P1] Keep the cleanup variable alive through the EXIT trap:** `scripts/docker/install-sh-smoke/run.sh:344`
  - body: `installer` is local to `run_install_smoke`, but this `EXIT` trap runs only when the shell exits, after a successful function return has removed that local scope.
