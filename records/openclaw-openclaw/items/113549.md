## What This Changes

The issue requests a static Zen/Go OpenCode catalog refresh plus a plugin-owned, in-memory hybrid catalog that combines live gateway availability with models.dev metadata and OpenClaw transport policy.

## System Context

The bundled OpenCode Zen and Go provider plugins turn catalog metadata into model-picker rows, routing settings, pricing, and context limits. Their static policy data and any live provider discovery feed model resolution and agent context management.

Land or replace the narrow static synchronization for verified current gateway gaps, then design a provider-plugin-only hybrid catalog contract with explicit source precedence, offline behavior, bounded process caching, fixtures, and upgrade-safe treatment of existing configured model rows.
