## What This Changes

The branch lets the Control UI preserve an explicitly entered `0` as an agent-turn cron job’s no-timeout value while continuing to omit blank timeout fields and reject invalid negative or non-finite values.

## System Context

The Control UI cron editor collects scheduled-job settings and sends `cron.add` or `cron.update` requests to the Gateway. The Gateway scheduler then interprets an agent-turn payload timeout, where zero already represents no timeout.
