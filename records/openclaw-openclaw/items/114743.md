## What This Changes

This PR shares matching Control UI chat startup, history, and fallback metadata requests across split panes, while preserving per-pane connection, session, agent, and refresh-version checks when applying results.

## System Context

The Control UI starts one or more chat panes through a shared Gateway browser client. Each pane fetches history and startup metadata, then updates its own chat and model state; this PR coalesces identical in-flight requests before those per-pane ownership checks run.
