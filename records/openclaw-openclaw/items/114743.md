## What This Changes

The branch shares identical in-flight Control UI chat startup and metadata requests across pane states, then treats metadata bundled in `chat.startup` as authoritative and uses `chat.metadata` only as a fallback.

## System Context

The Control UI creates chat-pane state for each mounted chat view and asks the Gateway for transcript history plus model and command metadata. This change sits between pane refreshes and Gateway RPC calls, reducing repeated same-session startup work before each pane applies results through its own freshness checks.
