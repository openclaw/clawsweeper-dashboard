## What This Changes

This PR adds bounded exponential retry delays and terminal exhaustion reporting when a macOS node-host worker crashes after becoming ready, preventing immediate respawn loops.

## System Context

The macOS app starts a node-host worker that supplies CLI-owned capabilities to the Gateway node. Worker readiness and failure notifications feed the macOS coordinator, which decides whether to reconnect, retry startup, or revoke an unusable route.
