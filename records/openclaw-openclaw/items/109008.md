## Summary

Keep open for normal merge review: current main still has an inconsistent QQBot target contract that can silently route accepted mixed-case group or channel targets through the C2C path, while this focused patch aligns validation, normalization, and parsing with direct runtime proof and no actionable correctness findings.

## What This Changes

The PR makes QQBot `c2c:`, `group:`, and `channel:` target type tags case-insensitive while preserving target ID casing, and adds focused parser consistency regression tests.

## Best Possible Solution

Maintain one canonical QQBot target grammar across validation, normalization, and delivery parsing, mapping case-insensitive type tags to documented lowercase forms while preserving identifier bytes exactly.
