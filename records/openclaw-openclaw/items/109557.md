Keep open: the per-method isolation is a credible fix for the reported cross-method throttling, but the current head leaves the documented external-client contract inconsistent with runtime behavior and broadens a protective control-plane budget without real workload evidence.

## What This Changes

The PR changes gateway control-plane write throttling from one shared 3-per-minute client bucket to separate 30-per-minute buckets for each method and client identity, with updated tests and release-note text.

## Best Possible Solution

Keep the per-method isolation, align the public external-app documentation with the exact identity and retry contract, leave CHANGELOG.md to the release process, and explicitly confirm or calibrate the 30-per-method budget against realistic Control UI and runaway-client behavior.
