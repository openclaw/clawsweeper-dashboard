## Summary

## What This Changes

The PR changes gateway control-plane write throttling from one shared three-per-minute client bucket to separate 30-per-minute buckets per method and client, expands limiter tests, and adds a changelog entry.

## Best Possible Solution

Use two-level throttling: isolate ordinary operations by method while retaining a tested client-wide aggregate ceiling that protects gateway availability without blocking normal Control UI use.
