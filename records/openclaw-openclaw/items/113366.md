## What This Changes

This PR normalizes invalid LINE carousel, buttons, and confirm templates, then sends their textual representation when no valid template remains so the reply is not silently lost.

## System Context

The LINE channel turns agent-provided `channelData.line.templateMessage` payloads into LINE Messaging API messages before the outbound adapter sends them to the user. The changed builder decides whether a template can remain interactive or must degrade to an ordinary text message.

## Best Possible Solution

Approve one documented degradation policy for inconsistent LINE carousels—prefer the smallest shared action count with title-to-text preservation if that product tradeoff is acceptable—and preserve the text fallback for templates with no renderable actions.
