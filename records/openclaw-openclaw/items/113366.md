## Label Justifications

- `P1`: The defect silently drops LINE channel replies whenever an agent emits an otherwise accepted carousel with inconsistent column fields.
- `merge-risk: 🚨 message-delivery`: The patch deliberately changes malformed carousel output by trimming actions and decoration to preserve delivery, so maintainers should review that user-visible trade-off.

## Summary

This PR remains necessary: current main still forwards LINE carousel columns without enforcing LINE’s cross-column constraints, while the proposed shared normalization prevents the documented HTTP 400 reply-loss path. No discrete correctness or security defect was identified in the patch; the remaining maintainer consideration is the intentional, documented choice to trim inconsistent carousel content rather than lose the entire reply.

## What This Changes

Normalizes LINE template-carousel columns in the shared builder so invalid actions, inconsistent action counts, and mixed title or thumbnail presence do not cause LINE to reject the whole reply.

## System Context

The bundled LINE channel converts agent-provided template payloads and product-card data into LINE Messaging API template messages. Carousel construction is a shared leaf used before the outbound reply path, so its output determines whether LINE accepts or rejects the message.
