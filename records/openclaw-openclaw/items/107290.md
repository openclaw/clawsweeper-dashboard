## What This Changes

Prevent automatic package updates from replacing a working OpenClaw install when the managed Gateway Node runtime does not satisfy the target release engine.

## Best Possible Solution

Ensure every Gateway automatic-update handoff uses the managed service Node for the shared pre-mutation engine check, add a focused regression test, and show a blocked-update card with a Fix or guided Node-upgrade action instead of leaving recovery to terminal diagnosis.
