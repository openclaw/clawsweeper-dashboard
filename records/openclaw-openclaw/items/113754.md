## What This Changes

The issue requests that OpenClaw remove internal runtime context markers from final user-facing text across Telegram, Discord, and the Control UI even when the markers are inline with prose.

## System Context

Agent runtimes assemble internal context and model output before delivery adapters send final text to chat surfaces. A final user-facing sanitizer should remove runtime-only artifacts before the Telegram, Discord, and Control UI render that text.
