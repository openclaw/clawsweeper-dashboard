## What This Changes

This PR adds model-facing descriptions explaining that gateway `path` is required for schema lookup and process `sessionId` is required for every process action except `list`.

## System Context

OpenClaw exposes TypeBox schemas to agent models for gateway configuration reads and background-process control. The model supplies a tool call, then the gateway tool or process tool validates action-specific arguments before returning a result or dispatching work.
