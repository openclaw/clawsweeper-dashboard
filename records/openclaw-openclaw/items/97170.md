Full review comments:

- **[P1] Preserve voice-model defaults during transcription scoping:** `src/gateway/server-methods/talk-shared.ts:276`
  - body: When `streaming.provider` is unset, this call scopes the provider list to `streaming.providers` before `resolveConfiguredVoiceModelDefaultRef` runs. A config with `streaming.providers.xai` plus `agents.defaults.voiceModel.primary` set to an OpenAI transcription model used to let the configured OpenAI voice-model default win; current head loads only xAI and auto-selects xAI instead. Include the voice-model provider in the requested set or resolve the default against an unscoped list before narrowing.
  - confidence: 0.86
- **[P1] Keep speech scopes when model-provider keys are not speech providers:** `src/plugins/capability-provider-runtime.ts:479-480`
  - body: This all-or-nothing fallback is useful for alias-only realtime requests, but speech requested sets also include `cfg.models.providers` keys that are not speech providers. With `messages.tts.providers.elevenlabs` plus a normal chat provider such as `models.providers.anthropic`, the unresolved `anthropic` id makes this return `undefined`, drops the resolved ElevenLabs scope, and loads every speech provider, so TTS auto-selection can pick another env-configured provider. Keep the resolved speech scope when non-speech model keys are present without regressing the alias fallback.
  - confidence: 0.84
