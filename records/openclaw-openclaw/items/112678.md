## What This Changes

The branch materializes legacy implicit `main` agents at configuration-load time, converts consumers toward roster/default resolution, and adds migration and regression coverage across setup, sessions, state, and channel paths.

## System Context

OpenClaw turns authored configuration into a runtime agent roster, then uses the selected default agent to resolve workspaces, session stores, auth state, tool policy, and channel context. This PR moves legacy `main` compatibility to that load boundary and changes downstream consumers to rely on the resolved roster.
