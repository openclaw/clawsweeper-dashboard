## What This Changes

The PR adds 16 MiB limits to Tlon SSE event buffering and JSON parsing, with regression coverage for oversized, boundary-sized, Unicode-split, normal, and high-event-count streams.

## Best Possible Solution

Keep the plugin-local bounded parser and explicitly accept the 16 MiB compatibility tradeoff; if Tlon can legitimately emit near-limit events, separate the retained-envelope and JSON-data budgets before merge.
