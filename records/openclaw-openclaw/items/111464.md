## What This Changes

The branch adds an opt-in durable runtime that records execution state, runs exact versioned operations with lease-fenced claims, and classifies expired claims as safely requeueable, owner-decision-required, or uncertain after possible side effects.

## System Context

The proposed durable runtime would sit beside existing task, agent, session, and delivery owners in the Gateway. It receives admitted work and restart facts, persists recovery evidence in the shared state database, then routes recovery decisions and attention back to the authoritative owner paths.
