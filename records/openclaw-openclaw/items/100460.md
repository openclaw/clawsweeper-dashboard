## Summary

Keep open. Current main still has a narrow Ollama stream-finalization fallback gap: the provider can emit the exact reported error, but the embedded-result fallback path does not classify that status-less provider error as fallback-worthy.

## What This Changes

Reclassify Ollama stream-finalization failures so configured model fallbacks are attempted instead of ending with `LLM request failed`.

## Best Possible Solution

Add a narrow replay-safe classification for this Ollama incomplete-stream failure at the provider/runtime fallback boundary, with embedded-run and model-fallback regression coverage.
