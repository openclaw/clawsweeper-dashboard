## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Split batched IRC lines before writing:** `extensions/irc/src/client.ts:249`
  - body: The multiline path writes each logical line as one tagged `PRIVMSG`. IRC still has a per-frame byte budget, so long URLs or code lines can be truncated or rejected; split overlong logical lines inside the batch and use `draft/multiline-concat` when preserving one logical line.
  - confidence: 0.93
- **[P2] Honor advertised multiline limits:** `extensions/irc/src/client.ts:325-333`
  - body: The CAP handler only checks whether the capability text contains `draft/multiline`, but servers advertise required `max-bytes` and may advertise `max-lines`. With the larger outbound cap, this can send batches that strict servers reject, so parse and enforce the advertised values.
  - confidence: 0.9
- **[P2] Preserve concat semantics when rebuilding batches:** `extensions/irc/src/client.ts:462`
  - body: Joining every buffered batch message with `\n` corrupts valid `draft/multiline-concat` splits, where the tagged line must be appended to the previous line without a separator. Parse that tag and rebuild the combined text according to the spec.
  - confidence: 0.88
- **[P2] Keep LF preservation local to multiline PRIVMSG sends:** `extensions/irc/src/protocol.ts:147-148`
  - body: `sanitizeIrcOutboundText` also feeds NickServ, USER, and QUIT commands that later pass through `sendRaw`. Preserving standalone LF here lets `sendRaw` remove it without a separator, so flatten non-message callers or use a PRIVMSG-specific sanitizer for multiline sends.
  - confidence: 0.82
- **[P2] Request batch before sending multiline batches:** `extensions/irc/src/client.ts:333`
  - body: Late discovery from this review cycle: the IRCv3 multiline spec depends on the `batch` capability being negotiated, but this PR only requests `draft/multiline` before sending `BATCH`. Request and require the dependent capability too, or keep the existing flattened fallback.
  - late: true
  - confidence: 0.86
