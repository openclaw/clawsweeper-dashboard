## Summary

Keep open: current main and shipped v2026.7.1 still generate the Windows gateway command and WScript launcher as UTF-8, matching the reported first-run failure under a CJK profile path; existing coverage proves launcher selection but not encoded bytes or execution from a non-ASCII user directory.

## What This Changes

Fix Windows gateway launcher generation so managed startup works when the user-profile path contains CJK characters.

## Best Possible Solution

Use a locale-independent Unicode-safe Windows startup chain for both Scheduled Task and Startup-folder paths, with byte-level regression tests and a real Windows install/start proof under a CJK profile; include an in-product repair path that regenerates affected launchers without requiring manual file edits.
