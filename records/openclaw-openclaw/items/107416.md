## Summary

Keep open: current main and v2026.7.1 still write both Windows gateway launcher files as UTF-8, matching the reported CJK-profile failure mechanism, while existing tests do not verify encoded bytes or execute the launchers from a non-ASCII profile path. citeturn472219turn297385turn657682

## What This Changes

Fix Windows gateway launcher generation so the scheduled gateway starts correctly when the user profile path contains CJK characters.

## Best Possible Solution

Use one explicitly documented Windows launcher encoding strategy that preserves Unicode paths without locale-dependent data loss, cover the generated byte representation, and prove install, task start, refresh, and uninstall on a clean Windows user profile containing CJK characters.
