## Summary

Keep open: current main has Apple Watch text/dictation input routed through the paired iPhone chat bridge, but it does not implement Watch-side reply speech or a turn-scoped voice action. The protected `maintainer` label and product/UX choice make this a maintainer-owned feature decision, not conservative cleanup.

## What This Changes

Requested behavior is two-way voice turns for Apple Watch chat: dictate on Watch, send through the existing chat bridge, and speak only the assistant reply for that turn.

## Best Possible Solution

Implement a turn-scoped Watch voice action in the iOS/watchOS app that reuses native Watch text input and existing WatchConnectivity `send-chat`, tracks the submitted turn by stable chat item IDs, speaks only the matching assistant reply on Watch, and includes a visible stop control plus focused Swift tests and paired Watch proof.
