## What This Changes

This PR adds an optional `announceTarget: "parent"` argument to native `sessions_spawn`, persisting that per-run choice so completed subagents wake the requester session without an automatic external-channel announcement.

## System Context

Native subagents are started from an agent session and later send a completion event through the subagent announce pipeline. This change adds a per-spawn routing choice that keeps the completion inside the requester session, affecting delivery behavior, durable pending-run state, and the model-facing spawn-tool schema.
