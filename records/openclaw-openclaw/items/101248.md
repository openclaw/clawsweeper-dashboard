## What This Changes

The PR adds an optional native `announceTarget: "parent"` argument to `sessions_spawn`, stores it with each subagent run, and uses it to wake the requester without automatically sending the completion to the external channel.

## System Context

Native subagents begin through `sessions_spawn`, retain their run metadata in the subagent registry and SQLite state database, and later take a completion-delivery path. This proposal adds a per-run routing choice that directs the completion to the requester session rather than a channel announcement.
