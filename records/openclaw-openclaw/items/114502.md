## What This Changes

The PR updates Slack inbound attachment rendering so agent messages and channel history include supplied MIME type and valid byte size with the existing filename and Slack file ID.

## System Context

Slack message events enter the Slack plugin, which formats file references before passing message bodies and media placeholders into agent context and channel/thread history. This change enriches that shared formatting point, affecting both downloaded attachments and fallback text when downloading is unavailable.
