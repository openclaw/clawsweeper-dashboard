## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Use the existing session label limit:** `ui/src/ui/app-render.ts:626`
  - body: The sidebar editor hard-caps and slices labels at 120 characters, but the gateway `SessionLabelString` contract and existing label paths allow 512 characters. Editing a valid longer label through this new path can silently shorten persisted session state, so the sidebar should reuse the established limit instead of introducing a second contract.
  - confidence: 0.94
- **[P2] Keep data-session-key on the clickable link:** `ui/src/ui/app-render.ts:704`
  - body: Moving `data-session-key` onto the wrapper means current browser coverage and callers that click `a.sidebar-recent-session[data-session-key=...]` no longer find the clickable row. Keep the attribute on the clickable element as well, or update and prove the affected selectors in the same change.
  - confidence: 0.9
- **[P2] Include the session name in the rename button label:** `ui/src/ui/app-render.ts:748-749`
  - body: Every icon-only rename button exposes the same accessible name, `Rename session`, so screen-reader users tabbing through multiple recent sessions cannot tell which session will be edited. Include the row label or key in the accessible name and add focused coverage.
  - confidence: 0.86
