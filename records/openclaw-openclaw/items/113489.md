## What This Changes

This PR changes Matrix storage-root selection so a canonical root with matching claimed token and device state is used immediately instead of synchronously scanning historical token-hash roots at gateway startup.

## System Context

The Matrix plugin selects a local per-account storage root from the current credentials and existing SQLite-backed state before the Matrix client starts. That decision controls whether gateway startup opens only the current account store or inspects historical token-rotation siblings first.
