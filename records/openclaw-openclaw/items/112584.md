## System Context

The voice-call plugin sends an assistant prompt to its carrier/TTS provider, then starts listening for the caller’s reply and waits for a matching transcript. The changed boundary is between prompt delivery and the listening-state transition, so a failed delivery should leave the call out of transcript collection.
