- **[P1] Return an agent-qualified activity identity:** `src/plugins/session-catalog.ts:45-50`
  - body: `SessionUpstreamProbe` includes `agentId`, but the provider result drops it and identifies activity only by `sessionKey`. Bare global-scope keys can exist for multiple agents, so the monitor can associate a result with the wrong persisted link; return an agent-qualified or opaque link identity and use it throughout result matching.
  - confidence: 0.99
- **[P1] Scope upstream event dedupe by agent and source:** `src/sessions/session-upstream-monitor.ts:188`
  - body: The provider-controlled `dedupeId` is used for a table-wide event dedupe path without guaranteed agent or upstream-source qualification. Two agents with the same bare global key and marker can collapse into one event while the second marker still advances; construct dedupe from agent and stable source identity in core.
  - confidence: 0.98
- **[P1] Make upstream source kinds plugin-defined:** `src/plugins/session-catalog.ts:28`
  - body: The generic Plugin SDK hard-codes `claude-cli` and `codex-app-server`, so adding another catalog provider requires a core SDK change and embeds bundled-plugin policy in core. Use a plugin-defined opaque source identifier and let the owning provider validate its own ref and marker payloads.
  - confidence: 0.99
- **[P1] Keep Claude transcript classification in the Anthropic plugin:** `src/plugin-sdk/session-catalog.ts:27-31`
  - body: Exporting Claude CLI history classifiers through the core Plugin SDK makes core own Anthropic-specific transcript and reseed semantics. Move the classification helper into the Anthropic plugin or expose only a provider-neutral primitive so Claude format changes remain owner-local.
  - confidence: 0.97
- **[P1] Scope watched-upstream joins by target agent:** `src/sessions/session-upstream-links.ts:201`
  - body: The watched-link query joins cursor demand to links using only the bare target session key even though links are keyed by session and agent. A watch for agent A can therefore activate agent B's same-key global link, causing cross-agent polling, notification, or marker advancement; include target-agent identity or suppress ambiguous targets.
  - confidence: 0.99
- **[P1] Do not advance incomplete remote Claude pages:** `extensions/anthropic/session-upstream-activity.ts:226`
  - body: When the prior UUID is absent from a full remote transcript page, the page may be only the newest fragment of the delta. Advancing to its newest UUID can permanently skip an older human prompt followed by many tool rows; page until the marker is found or leave the marker unchanged when completeness is unknown.
  - confidence: 0.99
