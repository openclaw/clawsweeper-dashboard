## Summary

The circular-object bug is real and this patch fixes the reported `JSON.stringify` failure, but the changed catch paths still perform fallible `instanceof` and property access before the guarded helper. The updated proof also runs a copied handler pattern with a mock stream rather than an affected provider lifecycle. The overlapping broader PR remains open and is not yet a safe superseding target, so this PR should stay open for a focused repair and real provider-path proof.

## What This Changes

Adds a shared non-throwing JSON/string fallback helper, uses it in Anthropic, Google, Mistral, and OpenAI Completions error formatting, and adds hostile-value unit coverage.

## Best Possible Solution

Use one package-internal total unknown-error formatter that safely owns Error detection, message extraction, JSON/string fallback, and provider-specific detail access; apply it consistently to sibling provider catch paths sharing the invariant; then prove an affected provider emits the terminal error event and closes its real stream.
