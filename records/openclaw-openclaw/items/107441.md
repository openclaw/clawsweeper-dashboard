## Summary

The shared helper is the right boundary, but the patch does not yet satisfy its no-throw contract because the fallback conversion can itself throw; merge should wait for a total fallback and regression coverage.

## What This Changes

Adds shared safe serialization for non-Error provider stream failures and applies it across OpenAI Completions, Google, Anthropic, and Mistral.

## Best Possible Solution

Keep one shared utility, but make every serialization and primitive-conversion branch non-throwing with a fixed final fallback, add hostile-value regression cases, and prove that an affected stream emits its error event and closes.
