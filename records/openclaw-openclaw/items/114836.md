## What This Changes

The PR adds a typed `eligibleTriggers` option for `before_agent_reply` plugin hooks, filters dispatch and recovery-safety checks by turn trigger, and limits memory-core dreaming hooks to scheduled heartbeat and cron turns.

## System Context

OpenClaw's plugin runtime lets registered hooks intercept agent-reply processing, while restart recovery checks the live hook registry before resuming interrupted sessions. The patch propagates the recovered turn's trigger into that registry so a hook that can only run on scheduled turns does not block a user-turn recovery.
