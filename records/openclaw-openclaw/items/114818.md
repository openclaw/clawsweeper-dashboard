## What This Changes

This PR makes the cloud-worker Zod validators the source of existing configuration labels and help text, then reuses that metadata when producing Control UI hints and JSON Schema without changing the accepted configuration.

## System Context

OpenClaw’s configuration schemas validate cloud-worker profiles and feed generated JSON Schema plus UI hints to the Gateway and Control UI. This change moves five existing presentation metadata families to the Zod fields that own the corresponding configuration paths, while the existing schema-generation layer still supplies the final API output.
