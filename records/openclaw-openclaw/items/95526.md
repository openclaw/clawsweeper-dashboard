## Summary

Keep open. Current main and the latest release still send QQBot Markdown chunks as separate outbound messages, while the open candidate fix and a recent member by-design comment disagree on the intended QQBot delivery policy.

## What This Changes

The issue asks for QQBot long Markdown replies to avoid appearing as multiple independent QQ message bubbles when the logical reply can fit safely in one message.

## Best Possible Solution

Decide the QQBot delivery policy first, then either keep intentional safe chunking and close the linked repair PRs, or land one bounded merge-safe QQBot change with live QQ proof and close this issue after merge.
