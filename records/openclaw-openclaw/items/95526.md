## Summary

Keep open. Current main and the latest release still split QQBot markdown into separate outbound sends, while an open closing PR and a maintainer comment now frame the remaining question as product direction rather than a cleanup-close candidate.

## What This Changes

The issue requests QQBot to render one logical long markdown reply as one visible QQ message instead of multiple independent chunk bubbles.

## Best Possible Solution

Make one QQBot product decision, then either land the bounded safe-size merge behavior or close this issue and the linked merge PRs as intentional split-by-limit behavior.
