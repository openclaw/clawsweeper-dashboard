## Summary

Keep open. Current main still chunks QQBot Markdown and sends each chunk through an independent QQ send loop, while open linked repair PRs and a recent member by-design comment leave the intended QQBot delivery policy unresolved.

## What This Changes

The issue asks QQBot to deliver a long Markdown reply as one logical QQ message or one collapsed reply chain instead of multiple independent chunk bubbles.

## Best Possible Solution

Maintainers should explicitly choose the QQBot delivery policy, then either document and keep intentional safe chunking or land one bounded merge-safe fix with live QQ proof before closing this issue.
