## Summary

Current main has a deterministic save-settlement race that silently overwrites newer agent-file edits. No duplicate or fix PR is visible, and the protected `maintainer` label requires explicit maintainer handling rather than cleanup closure.

## What This Changes

Fix the Agents file editor so edits typed during an in-flight save remain visible as an unsaved draft after the earlier save succeeds.

## Best Possible Solution

On successful save, update the saved baseline to the submitted snapshot and replace the draft only when it still equals that snapshot; otherwise preserve the newer draft as dirty, with a deferred-promise regression test and Control UI Playwright proof.
