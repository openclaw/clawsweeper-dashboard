## What This Changes

This PR makes SQLite usage-rollup cleanup conditional on the observed value and revision, and makes cron-run session retention cleanup resume immediately after retention is re-enabled while sharing a throttle across normalized targets.

## System Context

OpenClaw stores per-agent session usage rollups in SQLite for usage reporting, while the cron reaper removes expired cron-run session records. Both cleanup paths operate on persisted session state that is refreshed or retained by concurrent runtime work.
