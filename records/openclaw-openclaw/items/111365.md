## What This Changes

The PR adds a state-database regression test for a legacy SQLite file missing media-record columns and audit tables, asserting that Doctor and the following normal open restore the missing columns.

## System Context

OpenClaw’s shared SQLite state database is repaired by `openclaw doctor --fix` and then opened by the gateway/runtime. Both paths must migrate legacy media-record columns before executing canonical schema SQL that creates indexes using those columns, otherwise startup can remain blocked.
