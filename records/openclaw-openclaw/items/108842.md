## What This Changes

This PR changes both OpenGrep workflows to download the pinned installer into a temporary file with curl connection, transfer, and retry limits before executing it.

## Best Possible Solution

Keep the temporary-file download, add a step-level `timeout-minutes` bound to both OpenGrep install steps so the upstream installer's internal requests are covered, and attach a redacted successful install plus controlled-stall transcript.
