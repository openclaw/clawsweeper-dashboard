## Summary

Keep this PR open: the temporary-file change usefully hardens the initial installer-script fetch, but it does not yet deliver the claimed bounded install step because the invoked installer performs additional unbounded network requests; the protected security label also requires explicit maintainer handling.

## What This Changes

The PR adds connection and per-attempt deadlines, retries, and temporary-file execution for the pinned Opengrep installer script in both precise-scan workflows.

## Best Possible Solution

Download the pinned v1.22.0 runner asset directly with bounded curl options, verify it against the release-published SHA-256, install it in the expected path, and apply the same canonical step to both workflows.
