## What This Changes

This PR detects when a provider API key in `openclaw.json` differs from the SQLite auth profile used at runtime, warns during gateway startup and Doctor preview, and lets `openclaw doctor --fix` update the stored profile.

## System Context

Provider credentials can be represented both in OpenClaw configuration and in an agent-scoped SQLite auth-profile store. Gateway startup and Doctor inspect those sources; model authentication later resolves a credential for outbound provider requests.
