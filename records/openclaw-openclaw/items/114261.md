## What This Changes

This PR adds a Doctor warning and repair that updates a bound SQLite API-key auth profile when it differs from the provider API key configured in `openclaw.json`.

## System Context

Model requests resolve provider credentials from per-agent SQLite auth profiles as well as provider configuration. This PR adds a Doctor-time reconciliation step between configured API keys and the stored profile that the model-auth resolver will use next.
