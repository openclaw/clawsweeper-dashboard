## Summary

Keep open: current main partially masks the normal exec-summary display path, but source still shows the exported shell-stage splitter lacks heredoc state, and open closing PRs already own the remaining helper-level fix.

## What This Changes

The issue reports that exec tool-status summaries can treat heredoc body text as shell stage separators, leaking payload lines as phantom failed commands.

## Best Possible Solution

Land one canonical helper-level heredoc scanner fix with regression coverage for plain, quoted, escaped, and tab-stripping delimiters, then close this issue after the fix merges.

## Solution Assessment
