## Summary

Keep this PR open. The patch addresses a real duplicate-caption path, but its new suppression rule treats any non-empty message-tool text sent to the same destination as the generated-media caption; that can produce a bare fallback attachment after an unrelated status or conversational message. The PR also has no after-fix real behavior proof, so it is not ready to merge.

## What This Changes

The PR changes generated-media direct fallback so a generic ready caption is omitted when the requester agent previously sent non-empty message-tool text to the same channel, account, target, and thread.

## System Context

Subagent completion delivery turns agent results and generated-media paths into channel messages. When the normal agent output does not carry every generated attachment, the direct fallback sends missing media to the original conversation and currently supplies a generic readiness caption.

## Best Possible Solution

Record or derive caption evidence that is causally tied to the same generated-media completion, retain the generic caption when that linkage is absent, add the unrelated-same-target regression test, and provide a redacted real completion transcript or recording.
