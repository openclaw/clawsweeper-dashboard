## What This Changes

The PR replaces Memory Core’s 2,131-line doctor migration module with a small registry and six focused modules for dreaming state, host events, and legacy memory-sidecar imports.

## System Context

Memory Core’s doctor path repairs legacy workspace files and memory-sidecar databases during supported upgrades, then writes the canonical SQLite-backed state consumed by the Memory Core runtime. The changed registry selects those retained migrations, so a refactor error can affect upgrade repair rather than ordinary request-time behavior.
