## Summary

The linked availability bug remains valid, but this PR is not safe to merge because it can suppress the second phase of an already-started channel recovery.

## What This Changes

The PR makes pending channel restart continuations consume and obey the gateway health monitor's hourly restart budget.

## Best Possible Solution

Charge the hourly budget once per logical restart cycle, allow that cycle's pending completion pass through, and block only additional cycles after the configured limit.

## Solution Assessment

No. The goal is valid, but this implementation budgets individual monitor passes rather than logical restart cycles; cycle-level accounting is the narrow maintainable fix.
