## Summary

Keep open: the reported missing-target bug is plausible, but this patch is not merge-ready because it bypasses the existing channel/target ownership guard and can pair one channel's target with another channel. The external PR also has only unit-test evidence, not after-fix real behavior proof.

## What This Changes

The PR changes `deliveryContextFromSession` to derive missing `lastTo` from `deliveryContext.to` or `origin.to`, updates the session-source type, and adds unit coverage for those fallbacks.

## Best Possible Solution

Preserve the route-owner invariant: restore missing-target delivery only by inheriting targets whose channel/account owner matches, or by promoting the whole origin/deliveryContext pair together, with regression coverage for mismatched owners and redacted real runtime proof.
