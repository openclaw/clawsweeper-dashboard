Late catch: this path was visible on the earlier reviewed head as well.
  - late: true
  - confidence: 0.9
- **[P2] Refresh scoped rows after mutations settle:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatSheets.swift:266-268`
  - body: `refreshScopedSessionsSoon` sleeps for a fixed 400 ms and refetches independently of the rename/pin/archive patch task. If `sessions.patch` commits after that fetch, the searched or archived sheet can keep stale rows and never refresh again because the later success only refreshes `viewModel.sessions`; tie this refresh to mutation completion or update `scopedSessions` optimistically.
  - confidence: 0.92
