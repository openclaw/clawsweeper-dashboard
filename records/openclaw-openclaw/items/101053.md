- **[P1] Preserve existing transport list implementations:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatTransport.swift:237-245`
  - body: This default lets conformers that only implement the previous list-session methods compile, but `fetchSessions` now calls `listSessions(limit:search:archived:)` and will hit this throw.   - body: For a literal `global` row, the gateway only selects a non-default agent when `agentId` is present, and the iOS transport already passes that value. This macOS request sends only `key`, so rename/pin/archive from the sheet can mutate the default agent's global row instead of the active agent's row.
  - confidence: 0.9
- **[P2] Refresh scoped rows after mutations settle:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatSheets.swift:266-268`
  - body: `refreshScopedSessionsSoon` sleeps for a fixed 400 ms and refetches independently of the rename/pin/archive patch task. If `sessions.patch` commits after that fetch, the searched or archived sheet can keep stale rows because the later success only refreshes `viewModel.sessions`; tie this refresh to mutation completion or update `scopedSessions` optimistically.
  - confidence: 0.92
