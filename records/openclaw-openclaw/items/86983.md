Keep open: current main and v2026.6.11 still lack a Slack outbound DM recipient allowlist, and the remaining work is a security-hardening product/config decision rather than an already-implemented fix or a documented dmPolicy bug.

## What This Changes

Add an explicit Slack outbound DM recipient allowlist such as `allowTo`/`dmAllowTo` so `openclaw message send` cannot DM non-approved users.

## Best Possible Solution

Approve an explicit outbound target allowlist policy with default-compatible omitted/no-restriction behavior, shared enforcement after canonical target resolution, Slack support, docs, schema/help updates, and focused tests.
