Keep open: current main and v2026.6.11 still do not provide a Slack outbound DM recipient allowlist, and the remaining work is a security-sensitive public config/product decision rather than an already-implemented fix.

## What This Changes

The issue requests a Slack outbound DM allowlist such as `allowTo`/`dmAllowTo` so `openclaw message send` cannot DM non-approved users.

## Best Possible Solution

Design an explicit outbound target policy that preserves current behavior when unset, documents the config and migration story, and enforces the check before Slack/gateway sends from CLI, tool, and runtime paths.
