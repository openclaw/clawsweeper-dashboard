## Summary

Keep open: current main still lacks a Slack outbound DM recipient allowlist, and the remaining work is a security-sensitive feature/config decision rather than an already-implemented fix or a documented `dmPolicy` bug.

## What This Changes

The issue requests an outbound Slack DM recipient allowlist such as `allowTo` or `dmAllowTo` so `openclaw message send` cannot DM arbitrary users when inbound `allowFrom` is configured.

## Best Possible Solution

Design an explicit outbound recipient policy, likely at the shared outbound/channel boundary with Slack schema/docs/tests, while leaving inbound `allowFrom` semantics unchanged.
