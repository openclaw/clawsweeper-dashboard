## Summary

Keep open: current main and latest release still lack an outbound Slack DM recipient allowlist, and the remaining work is a security-sensitive product/config decision rather than an already-defined `dmPolicy` bug.

## What This Changes

The issue requests a Slack outbound DM recipient allowlist such as `dmAllowTo` or `allowTo` for `openclaw message send --target <user>`.

## Best Possible Solution

Design an explicit outbound recipient or target policy with shared enforcement semantics, Slack schema/docs/tests, and `allowFrom` kept inbound-only.
