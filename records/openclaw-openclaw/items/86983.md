## Summary

Keep open: current main and v2026.6.11 still lack a Slack outbound DM recipient allowlist, and the remaining work is a security-sensitive feature/config decision rather than an already-implemented fix or a documented dmPolicy bug.

## What This Changes

Add an explicit outbound Slack DM recipient allowlist, such as allowTo or dmAllowTo, so explicit Slack message sends can be blocked for non-allowlisted users.

## Best Possible Solution

Design an explicit outbound recipient/target policy with schema, docs, tests, and shared send-boundary enforcement rather than overloading inbound allowFrom semantics.
