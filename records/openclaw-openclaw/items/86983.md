## Summary

Keep open: current main still lacks a Slack outbound DM recipient allowlist, and the remaining work is a security-sensitive feature/config decision rather than an implemented fix or a documented `dmPolicy` bug.

## What This Changes

Add a channel outbound recipient allowlist such as `dmAllowTo`/`allowTo` so Slack DM sends to non-allowed users are blocked and logged.

## Best Possible Solution

Design one explicit outbound target policy, likely shared across message-capable channels and enforced before durable/gateway send dispatch, with Slack target normalization, docs, focused tests, and no reuse of inbound `allowFrom` semantics.
