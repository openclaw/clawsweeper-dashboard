## Summary

Keep open as a low-priority product/config decision: current main and v2026.6.11 still use collision-only provider suffixes in the Control UI picker and have no config flag for always-on provider display, while current TUI source already labels picker rows as provider/model.

## What This Changes

Request to add an opt-in config setting that makes model pickers always append provider labels instead of only after friendly-name collisions.

## Best Possible Solution

Choose one canonical model-picker visibility policy first, then implement it consistently across Control UI and TUI, adding schema/docs/tests only if maintainers accept a new config flag.
