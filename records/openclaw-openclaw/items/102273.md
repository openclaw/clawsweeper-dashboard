## Summary

Keep open as a low-urgency product/config decision: current main still uses collision-only provider suffixes in the Control UI picker and has no config knob, while current TUI source already labels rows as provider/model, so the remaining work is choosing the long-term picker display policy rather than cleanup-closing this issue.

## What This Changes

Request to add an opt-in model-picker setting that displays provider suffixes for every model row in TUI and Control UI, not only duplicate friendly names.

## Best Possible Solution

Choose one canonical model-picker provider-visibility policy first, then implement it consistently across Control UI and any TUI picker that uses friendly labels, with schema/docs/tests only if maintainers accept a new config flag.
