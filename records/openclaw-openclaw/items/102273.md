## Summary

Keep open as a low-priority feature/product decision: current main still uses collision-only provider suffixes in the Control UI model picker and has no provider-display config knob, while current TUI source already labels model rows as provider/model refs.

## What This Changes

The issue requests an opt-in configuration flag that makes TUI and Control UI model pickers always append the provider to every model label instead of only for duplicate display-name collisions.

## Best Possible Solution

Choose one canonical model-picker visibility policy first, then implement it consistently across Control UI and any TUI picker that uses friendly labels, adding schema/docs/tests only if maintainers accept a new config flag.
