## Summary

Keep open as a low-urgency feature/product decision: current Control UI source and v2026.6.11 use collision-only provider suffixes with no config knob, but current TUI source already labels rows as provider/model, so implementation should wait for a maintainer UX/config decision rather than going straight to an automated fix.

## What This Changes

The issue requests an opt-in config flag to render provider suffixes for every model-picker row in the TUI and Control UI instead of only on friendly-name collisions.

## Best Possible Solution

Choose one canonical model-picker visibility policy first, then implement it consistently across Control UI and any TUI picker that uses friendly labels, with schema/docs/tests only if maintainers accept a new config flag.
