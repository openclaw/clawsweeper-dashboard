## Summary

Keep open as a low-priority feature/product decision: current main still uses collision-only provider suffixes in the Control UI picker and has no config knob, while the TUI source already shows provider/model refs, so the requested cross-surface config flag should wait for maintainer UX and config-surface direction.

## What This Changes

Request an opt-in config flag that makes the TUI and Control UI model pickers always append provider names to model labels.

## Best Possible Solution

Choose one canonical model-picker visibility policy first, then implement it consistently across Control UI and any TUI picker that uses friendly labels, adding schema/docs/tests only if maintainers accept a new config flag.
