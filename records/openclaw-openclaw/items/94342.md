## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Move the internal event after the final pre-send decision:** `src/infra/outbound/deliver.ts:1634-1658`
  - body: The new `message:sending` notification fires before `applyMessageSendingHook`, so directory hooks observe content that may later be rewritten or cancelled by the typed `message_sending` policy gate. That makes the new hook report stale or blocked content as if it were about to be delivered, which is unsafe for audit/filter side effects.
  - confidence: 0.92
- **[P2] Guard metadata lookup when no reply payload exists:** `src/infra/heartbeat-runner.ts:1889`
  - body: `replyPayload` can be undefined, but `getReplyPayloadMetadata` takes an object and is backed by a WeakMap. In the empty-reply path this can throw before the suppression condition reaches the existing empty-heartbeat handling.
  - confidence: 0.88
- **[P2] Preserve reasoning payloads when suppressing raw heartbeat text:** `src/infra/heartbeat-runner.ts:1890-1893`
  - body: When `suppressRawReply` is true, this early return runs before the later `reasoningPayloads` send path. Heartbeats configured with `includeReasoning` can therefore drop the opted-in Thinking payloads instead of sending them without the raw final text.
  - confidence: 0.86
