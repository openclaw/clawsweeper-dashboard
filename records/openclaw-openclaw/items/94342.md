## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Move the internal event after the final pre-send decision:** `src/infra/outbound/deliver.ts:1639-1644`
  - body: The new `message:sending` block is scheduled before `applyMessageSendingHook` runs. If a typed plugin later rewrites or cancels the payload, user hooks have already observed content that is not the final delivered message, and fire-and-forget handlers are not guaranteed to finish before delivery.
  - confidence: 0.91
- **[P2] Guard metadata lookup when no reply payload exists:** `src/infra/heartbeat-runner.ts:1889`
  - body: `replyPayload` can be undefined when the model produced no deliverable reply, but this new line passes it to `getReplyPayloadMetadata`, whose contract accepts an object. Guard on `replyPayload` before reading metadata so strict TypeScript and the WeakMap-backed helper stay on the defined payload path.
  - confidence: 0.86
- **[P2] Preserve reasoning payloads when suppressing the main reply:** `src/infra/heartbeat-runner.ts:1890-1893`
  - body: This branch returns `ok-empty` for every raw `message_tool_only` reply before the existing `reasoningPayloads.length === 0` guard can keep opt-in reasoning delivery alive. A heartbeat configured with `includeReasoning` can lose the Thinking payloads that current main sends.
  - confidence: 0.78
