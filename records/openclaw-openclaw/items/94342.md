Full review comments:

- **[P1] Move the internal event after the final pre-send decision:** `src/infra/outbound/deliver.ts:1639-1644`
  - body: The new fire-and-forget event is scheduled before `applyMessageSendingHook` runs. If a typed plugin later rewrites or cancels the payload, user hooks have already observed content that is not the final delivered message, and async handlers are not guaranteed to finish before delivery.
  - confidence: 0.91
- **[P2] Guard metadata lookup when no reply payload exists:** `src/infra/heartbeat-runner.ts:1889`
  - body: `replyPayload` can be undefined here, but `getReplyPayloadMetadata` accepts an object. The heartbeat branch should avoid calling the metadata helper until a payload exists, otherwise strict type checking or the empty-reply path can fail.
  - confidence: 0.86
- **[P2] Preserve reasoning payload delivery in the suppression path:** `src/infra/heartbeat-runner.ts:1892-1893`
  - body: This suppression condition treats a suppressed main reply like an empty heartbeat without preserving current main's `reasoningPayloads.length === 0` guard. When the dirty branch is refreshed, opt-in reasoning payloads must still fall through to delivery instead of being returned as `ok-empty`.
  - confidence: 0.78
