## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Emit the internal hook after the policy gate:** `src/infra/outbound/deliver.ts:1634-1658`
  - body: The new `message:sending` notification fires before `applyMessageSendingHook`, so directory hooks observe content that may later be rewritten or cancelled by the typed `message_sending` policy gate. Move this observer after the final pre-send decision so audit/filter side effects do not see stale or blocked content as deliverable.
  - confidence: 0.92
- **[P1] Deduplicate underscore-alias hook handlers:** `src/hooks/internal-hooks.ts:287-318`
  - body: Adding a generic `type_action` lookup changes every internal hook event and will run the same side-effect handler twice when a hook pack registers both colon and underscore keys for compatibility. Either keep the bridge narrow or dedupe handlers before invoking them.
  - confidence: 0.86
- **[P2] Guard metadata lookup for absent reply payloads:** `src/infra/heartbeat-runner.ts:1889`
  - body: `replyPayload` is optional here, but `getReplyPayloadMetadata` is typed to accept an object. Narrow the payload before calling the helper so the PR remains type-checkable on the empty-reply path.
  - confidence: 0.82
- **[P2] Preserve reasoning payloads when suppressing raw heartbeat text:** `src/infra/heartbeat-runner.ts:1890-1893`
  - body: When `suppressRawReply` is true, this early return runs before the later `reasoningPayloads` send path. Heartbeats configured with `includeReasoning` can therefore drop opted-in Thinking payloads instead of sending them without the raw final text.
  - confidence: 0.86
