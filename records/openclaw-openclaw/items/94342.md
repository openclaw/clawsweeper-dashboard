## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.97

Full review comments:

- **[P1] Emit the observer after the policy hook:** `src/infra/outbound/deliver.ts:2191`
  - body: `fireAndForgetHook` runs before `applyMessageSendingHook`, so user hooks receive pre-rewrite content and also fire for sends the plugin hook cancels. Move the internal notification after a successful non-canceled policy result and build it from the final delivery payload.
  - confidence: 0.99
- **[P1] Guard metadata reads when the reply payload is absent:** `src/infra/heartbeat-runner.ts:2047`
  - body: `replyPayload` can be missing for empty or reasoning-only heartbeat results, but the new metadata lookup runs before the existing null guard. Check that a payload exists before calling `getReplyPayloadMetadata` so an empty heartbeat remains `ok-empty` instead of throwing.
  - confidence: 0.93
- **[P2] Suppress the raw final independently of reasoning payloads:** `src/infra/heartbeat-runner.ts:2050-2051`
  - body: When `reasoningPayloads.length > 0`, the new empty-reply branch is skipped even if `suppressRawReply` is true, allowing the raw final text to continue into delivery. Remove or replace the main reply independently while preserving any separately deliverable reasoning payloads.
  - confidence: 0.94
- **[P2] Normalize or deduplicate underscore hook keys:** `src/hooks/internal-hooks.ts:290`
  - body: Looking up both colon and underscore keys for every event can run the same handler twice when both spellings are registered and silently broadens compatibility beyond `message_sending`. Normalize the manifest key once at registration, or deduplicate handler identity and narrowly define the supported alias contract.
  - confidence: 0.97
