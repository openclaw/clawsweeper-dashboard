  - body: The new fire-and-forget event runs before `applyMessageSendingHook`, so internal handlers receive content that a typed hook may later redact or cancel and can record a send that never occurs.   - confidence: 0.99
- **[P1] Guard metadata lookup when no reply payload exists:** `src/infra/heartbeat-runner.ts:2047`
  - body: The empty-heartbeat path permits `replyPayload` to be absent, but the new metadata helper is called before that null check and accepts an object. Guard the lookup with `replyPayload` first so the empty path remains valid; this blocker remains from the previous review.
  - confidence: 0.96
- **[P2] Suppress raw replies even when reasoning exists:** `src/infra/heartbeat-runner.ts:2052`
  - body: The suppression flag is only consumed by the branch that also requires `reasoningPayloads.length === 0`. With reasoning enabled, the raw final reply can therefore continue to delivery despite message-tool-only mode; suppress the final payload independently while preserving the reasoning lane.
  - confidence: 0.98
- **[P2] De-duplicate colon and underscore registrations:** `src/hooks/internal-hooks.ts:317`
  - body: Appending both handler arrays invokes the same callback twice when it is registered through both spellings, which can duplicate audit writes and other side effects. Normalize aliases once or de-duplicate handler identities before dispatch; this blocker remains from the previous review.
  - confidence: 0.94
