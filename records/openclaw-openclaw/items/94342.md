Full review comments:

- **[P1] Move the internal event after the final pre-send decision:** `src/infra/outbound/deliver.ts:1639-1644`
  - body: The new fire-and-forget event is scheduled before `applyMessageSendingHook` runs. If a typed plugin later rewrites or cancels the payload, directory hooks have already observed content that is not the final delivered message, and async handlers are not guaranteed to finish before delivery.
  - confidence: 0.91
- **[P2] Dedupe colon and underscore handler dispatch:** `src/hooks/internal-hooks.ts:318`
  - body: A hook pack that registers the same handler for both `message:sending` and `message_sending` will now run it twice for one event. Normalize at registration or dedupe the collected handlers before dispatching the alias.
  - confidence: 0.83
- **[P2] Guard metadata lookup when no reply payload exists:** `src/infra/heartbeat-runner.ts:1889`
  - body: `replyPayload` can be undefined here, but `getReplyPayloadMetadata` is typed for objects. The suppression branch should only read metadata after a payload exists, otherwise strict type checking or the empty-reply path can fail.
  - confidence: 0.86
- **[P2] Preserve reasoning payload delivery in the suppression path:** `src/infra/heartbeat-runner.ts:1892-1893`
  - body: Current main treats an empty heartbeat as `ok-empty` only when there are no opt-in reasoning payloads to deliver. This new suppression branch returns early without that guard, so a refreshed branch can drop reasoning payloads that should still be sent.
  - confidence: 0.78
