  - body: `replyPayload` is `ReplyPayload | undefined`, but this call passes it to `getReplyPayloadMetadata(payload: object)`. The strict TypeScript lanes should reject the patch unless the code first checks `replyPayload` or handles the missing-payload case before reading metadata.
  - confidence: 0.78

  - body: This early empty-heartbeat return runs before the later `reasoningPayloads` delivery path. In `includeReasoning` mode, a raw final with separate Thinking payloads will skip the opted-in reasoning delivery instead of only suppressing the raw final text.
