## Summary

Keep this PR open for normal security-owner review. The current head addresses the earlier token-configured bypass, preserves the trusted same-origin download path, and includes credible real-runtime evidence that off-origin loopback URLs are rejected before connection or token disclosure; no new patch defect was identified.

## What This Changes

The PR treats ClawHub skill archive URLs outside the configured registry origin as untrusted, downloads them through the shared SSRF guard with bounded retries, and adds regression coverage for blocked internal targets and token handling.

## System Context

ClawHub skill installation resolves an archive URL from registry metadata, downloads the archive, validates and writes it locally, then hands it to the skills lifecycle. This PR changes the network trust decision between the registry-controlled URL and the archive downloader, while preserving the configured registry’s authenticated path.

Land the origin-based guarded downloader after a security-owner review confirms that off-origin private archive hosts are intentionally unsupported and that a rebase against the deadline work preserves both security and archive-transfer behavior.
