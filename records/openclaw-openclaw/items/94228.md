## What This Changes

Prevent native Anthropic sessions from becoming permanently unusable when replayed historical thinking blocks have signatures the provider rejects.

## System Context

The embedded agent runner rebuilds persisted session history before sending an Anthropic Messages request. Its thinking-replay hygiene determines whether signed reasoning is preserved, stripped, or retried after a provider rejection, which directly controls whether an active chat session can continue.
