## Summary

Keep open. Current main still allows nonblank signed Anthropic thinking from older assistant turns to survive normal replay in the reported Claude 4 path, the latest release has fresh live failure reports, and several open PRs are still competing to own the durable fix.

## What This Changes

The issue reports that native Anthropic sessions with extended thinking can permanently fail because historical `thinking` blocks with stale or corrupted signatures are replayed and Anthropic rejects them with `Invalid signature in thinking block` 400s.

## Best Possible Solution

Land a coordinated Anthropic replay fix that drops or strips non-replayable completed-turn thinking before native Anthropic requests, keeps active tool-use continuity intact, and includes live or fixture-backed proof for persisted poisoned sessions plus the SDK and managed transport paths.
