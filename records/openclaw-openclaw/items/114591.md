## What This Changes

This PR prevents media-less, unmentioned Telegram group messages from taking the media-download fast path, so they reach the normal mention gate and the ingress monitor logs an explicit diagnostic for completed updates with no recorded outcome.

## System Context

Telegram polling stores incoming updates in a durable ingress queue, then dispatches them to the Telegram inbound handler. The handler decides whether a group message is addressed to the bot; that decision controls history recording, internal hooks, processing outcome, and eventual queue settlement.
