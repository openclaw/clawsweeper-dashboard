## What This Changes

The PR changes model-parameter classification so native OpenAI reasoning and fast-mode controls do not count as opaque provider request overrides that disqualify the Codex runtime, and adds routing regressions.

## System Context

OpenClaw reads model-scoped configuration before selecting an agent runtime. The override detector decides whether configured values can be represented by a native runtime; that decision determines whether an OpenAI route may use Codex or must use the embedded runtime.
