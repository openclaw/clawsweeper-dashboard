## What This Changes

The PR treats OpenClaw’s model-scoped `thinking` and fast-mode controls as typed agent-runtime inputs rather than raw provider request overrides, allowing eligible OpenAI models to keep the Codex harness route while unknown parameters remain fail-closed.

## System Context

Model configuration feeds OpenClaw’s runtime-control resolution and harness-selection policy. That policy determines whether an OpenAI route can use the Codex app-server or must remain on the embedded OpenClaw runtime, then passes resolved reasoning and service-tier controls to the selected runtime.
