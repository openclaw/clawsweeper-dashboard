## What This Changes

This PR updates the Tlon channel monitor to use the shared abort-aware lifecycle wait after startup and adds a regression test for cleanup when shutdown begins before that wait is registered.

## System Context

The Tlon plugin monitor initializes Urbit SSE, ingress, settings, and channel discovery for a channel account. A gateway abort signal should end the monitor lifetime and drive its resource cleanup, so a late abort listener must not leave the monitor waiting forever.
