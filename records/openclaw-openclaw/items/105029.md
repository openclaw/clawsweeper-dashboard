## Summary

This PR remains necessary and appears correct: current main leaves attach bearers valid after session or agent deletion, while the branch centralizes revocation on committed lifecycle boundaries and has exact-head live proof. The previous two test-handler findings are fixed, and no actionable correctness or security regression remains.

## What This Changes

Canonicalizes MCP attach grants to resolved session keys and revokes session- or agent-owned grants after committed deletion while preserving reset behavior and unrelated grants.

## Best Possible Solution

Land the centralized committed-deletion revocation design, retaining reset/archive behavior and using the session identity mutation event as the single owner for all session deletion callers.
