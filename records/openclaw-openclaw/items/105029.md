## Summary

This PR remains necessary because current main does not revoke attach bearers after session or agent deletion. The patch uses the authoritative committed lifecycle boundary, has no actionable correctness or security findings, and has convincing exact-head live proof; it should stay open for ordinary maintainer review and remaining merge checks.

## What This Changes

Canonicalizes MCP attach grants to resolved logical session keys and revokes session- or agent-owned grants after successful deletion commits while preserving reset behavior and unrelated grants.

## Best Possible Solution

Land the canonical minting and committed-deletion observer design unchanged, retaining reset/archive semantics and explicit post-commit agent revocation.

## Solution Assessment

Yes. Reusing canonical session resolution and the authoritative committed identity-mutation event is narrower and more complete than scattering revocation calls across RPC deletion, cron cleanup, and initialization rollback callers.
