## Summary

This PR should remain open because the previously reported blocker survives the current head and GitHub’s three-way merge result: cron continuation cleanup and plugin initialization rollback can permanently delete sessions without invalidating their attach bearers. The RPC proof is strong, but it covers only one deletion owner.

## What This Changes

The PR canonicalizes MCP attach grants to logical session keys and revokes matching grants after gateway session or agent deletion.

## Best Possible Solution

Establish a gateway/runtime-owned post-success revocation invariant for every permanent logical-session deletion, either through an injected shared lifecycle seam or explicit calls from each owner, while preserving reset, archive, unrelated-grant, and agent-deletion ordering behavior.
