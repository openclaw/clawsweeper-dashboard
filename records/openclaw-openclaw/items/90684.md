## Label Justifications

- `P1`: The issue reports internal assistant/tool scaffolding leaking into real user-facing channel messages, which is an urgent channel workflow and privacy failure.
- `impact:security`: The leaked text can expose internal reasoning, memory context, tool-call XML, command labels, or diagnostic scaffolding to chat recipients.
- `impact:message-loss`: The intended assistant reply can be polluted by internal banners or scaffolding, making the delivered message confusing or functionally wrong.

## Summary

Keep open: current main and v2026.6.11 still leave Feishu without the assistant-visible outbound sanitizer hook, while merged sibling PRs only cover other channel slices and the open Feishu PR has not landed.

## What This Changes

Apply `sanitizeAssistantVisibleText()` to Feishu and other non-Discord outbound text so internal tool, reasoning, memory, and XML scaffolding does not reach chat users.

## Best Possible Solution

Land or adopt the narrow open Feishu hook and review the remaining channel-slice PRs, or approve a shared outbound sanitizer default with compatibility proof; keep this umbrella open until the remaining channel coverage is resolved or explicitly split.
