## Summary

Keep open. The latest maintainer-facing review found that the Control UI still exposes only Markdown copying, while this request adds a distinct user-facing copy mode whose interaction and conversion contract need product direction before implementation.

## What This Changes

Add a Control UI option to copy assistant-message content as plain text instead of only Markdown.

## Best Possible Solution

Add a compact per-message Markdown/plain-text copy menu in the Control UI after maintainers choose the conversion contract; keep Markdown as the existing action and add focused clipboard/UI coverage for both formats.

Rationale: Current behavior establishes Markdown copy only; choosing a new interaction model and defining user-visible conversion semantics are product and UX contract decisions, not a mechanical bug repair.

Owner confidence: high

Options:

- **Per-message copy menu (recommended):** Keep the existing Markdown action and add a compact menu that explicitly lets users copy the current assistant message as Markdown or normalized plain text.
- **Persisted copy preference:** Add a user preference that selects the default copy format, accepting a broader settings and upgrade surface.
- **Defer the feature:** Retain the current Markdown-only behavior until there is a clearer shared plain-text export contract for the Control UI.
