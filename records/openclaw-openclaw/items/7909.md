## Summary

Current main still has only the assistant-message `Copy as markdown` action and no plain-text selector or preference, so this remains a valid Control UI feature request that needs maintainer UX/product direction rather than cleanup closure.

## What This Changes

The issue requests a Control UI copy affordance that lets users choose plain text instead of only copying assistant messages as Markdown.

## Best Possible Solution

If maintainers accept the UX, add a compact per-message Markdown/plain-text copy menu in the Control UI action cluster, reuse an existing markdown-to-plain-text path with documented semantics, and add focused clipboard/UI tests for both formats without adding a persisted preference unless explicitly chosen.
