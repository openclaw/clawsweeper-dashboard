## Summary

Keep open: current main still exposes a single Control UI assistant-message action labeled “Copy as markdown” and does not provide a plain-text copy selector or preference. The remaining blocker is product/UX direction for the copy-format surface and conversion behavior, not missing evidence that the request exists.

## What This Changes

Request adding a Control UI assistant-message copy option that can copy plain text instead of only Markdown.

## Best Possible Solution

Add a compact Markdown/plain-text copy choice in the existing Control UI chat copy surface, keep Markdown as the current default, define the plain-text conversion contract, and cover both clipboard outputs with focused UI tests.
