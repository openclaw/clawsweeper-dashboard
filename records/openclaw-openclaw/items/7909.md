Keep open: current `origin/main` and v2026.6.11 still expose a single Control UI assistant-message action labeled `Copy as markdown`, and no merged or open related item owns the requested Markdown/plain-text copy selector.

## What This Changes

The issue requests a Control UI option to copy assistant message content as plain text instead of only Markdown.

## Best Possible Solution

Land a focused Control UI copy-format affordance, preferably a compact per-message Markdown/plain-text menu with explicit conversion semantics and targeted clipboard/UI coverage.
