## Summary

Keep open: current main and the latest release still expose one Markdown-only assistant-message copy action in the Control UI. The related native and Android copy items do not implement this Control UI plain-text copy option, and maintainers still need to choose the UX shape and plain-text conversion contract.

## What This Changes

The issue requests a Control UI assistant-message copy option that can copy message content as plain text instead of only Markdown.

## Best Possible Solution

Add a focused Control UI copy-format menu that preserves Markdown copy, adds tested plain-text output using an agreed existing conversion helper, and routes new labels through UI i18n.
