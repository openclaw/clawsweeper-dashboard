## Summary

Keep open: current main and the latest release still expose only the Control UI assistant-message copy action labeled “Copy as markdown,” with no plain-text copy selector or default-format preference. This remains a small but product-shaped Control UI feature because maintainers still need to choose the UX shape and plain-text conversion contract.

## What This Changes

Add a Control UI option to copy assistant message content as plain text instead of only copying the Markdown source.

## Best Possible Solution

Add a focused Control UI Markdown/plain-text copy selector that preserves existing Markdown copy, uses a defined display-normalized plain-text conversion, and adds targeted UI/clipboard tests plus English i18n source updates.
