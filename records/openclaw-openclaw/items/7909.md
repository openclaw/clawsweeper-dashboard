## Summary

Keep open. Current main and the latest release still expose only the Control UI assistant-message copy action labeled “Copy as markdown,” with no Markdown/plain-text selector or preference.

## What This Changes

The issue requests a Control UI option to copy assistant message content as plain text instead of only Markdown.

## Best Possible Solution

Add a focused Control UI copy-format affordance that preserves current Markdown copy, offers plain-text output with defined conversion behavior, and covers both formats with clipboard/UI tests.

Rationale: The source gap is clear, but the user-facing UX and conversion contract are product choices rather than a strict bug repair.

Likely owner: steipete

Options:

- **Add Per-Click Format Menu (recommended):** Keep the current Markdown behavior as one menu choice and add a plain-text choice without creating persisted settings surface.
- **Add Persisted Copy Preference:** Let users choose a default copy format, but require settings/i18n/test coverage and upgrade-safe preference behavior.
- **Keep Markdown-Only Copy:** Close or leave low-priority if maintainers do not want another chat action affordance.

## Solution Assessment

Unclear until maintainers choose the UX. A per-click copy-format menu looks like the narrowest maintainable path because it avoids a new persisted preference while preserving the current Markdown default.
