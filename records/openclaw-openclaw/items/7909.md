The issue requests a Control UI option to copy assistant message content as plain text instead of only copying Markdown.

Keep the issue open, decide the intended Control UI copy UX, then implement one focused change that adds a Markdown/plain-text choice using an existing markdown-to-text path plus targeted clipboard and chat-render tests.
