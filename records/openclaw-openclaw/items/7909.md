## Summary

## What This Changes

Add a Control UI option to copy assistant-message content as plain text in addition to the current Markdown copy behavior.

## Best Possible Solution

Add a compact secondary plain-text copy action with a defined conversion contract, reuse or adapt existing markdown conversion utilities where adequate, and keep Markdown copy as the default unless maintainers approve a persisted preference.

## Reproduction Assessment

Not applicable as a bug reproduction: this requests an additional clipboard format rather than reporting broken existing behavior. Source and release inspection give high confidence that current main and v2026.6.11 still have only the Markdown copy action.

## Solution Assessment

Unclear until maintainers choose the UI shape and plain-text conversion contract. The likely maintainable path is a secondary copy action around the existing copy helper and grouped-render action cluster, not a broad settings surface by default.
