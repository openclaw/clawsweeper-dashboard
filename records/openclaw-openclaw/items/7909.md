## Summary

Keep open. Current main and v2026.6.11 still provide only the Control UI assistant-message action labeled “Copy as markdown”; no selector, plain-text alternative, preference, or canonical replacement item now owns the request.

## What This Changes

Add a plain-text alternative to the Control UI assistant-message Markdown copy action.

## Best Possible Solution

Preserve Markdown as the default and add a compact per-click plain-text option at the existing assistant footer action, using the existing parser surface or an audited maintained library plus focused browser clipboard tests for code, links, lists, and tables.
