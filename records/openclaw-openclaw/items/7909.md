Add a Control UI option to copy assistant message content as plain text instead of only Markdown.

## Best Possible Solution

Land a focused Control UI copy-format affordance, preferably a compact per-message Markdown/plain-text menu with defined conversion behavior and targeted clipboard/UI coverage.
