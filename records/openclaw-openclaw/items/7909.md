## Summary

Keep open: current main and the latest release still expose only the Control UI assistant-message copy action labeled “Copy as markdown,” with no plain-text copy selector or default-format preference.

## What This Changes

Add a Control UI assistant-message copy option that writes plain text instead of Markdown, either through a copy menu or a default setting.

## Best Possible Solution

Add a focused Control UI copy-format selector that preserves Markdown copy, adds tested plain-text clipboard output, and routes new visible labels through the UI i18n source.
