## Summary

Keep open: current main and the latest release still expose only the Control UI assistant-message `Copy as markdown` action, with no Markdown/plain-text selector or preference. This remains a small, valid UX feature request, but it needs maintainer product direction before implementation should be queued.

## What This Changes

The issue requests a Control UI option to copy assistant message content as plain text instead of only Markdown.

## Best Possible Solution

Land a focused Control UI copy-format affordance, preferably a compact per-message Markdown/plain-text menu with clear conversion semantics and targeted clipboard/UI coverage.
