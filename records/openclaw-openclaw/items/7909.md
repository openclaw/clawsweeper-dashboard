## Summary

Current main and v2026.6.11 still provide only Markdown copying for Control UI assistant messages, with no plain-text selector, preference, or canonical related implementation. The feature remains valid, but the prior maintainer-side review and current discussion leave the interaction and conversion semantics awaiting a product decision.

## What This Changes

Add a plain-text copy choice alongside Markdown for assistant messages in the Control UI.

## Best Possible Solution

Preserve the existing Markdown output and clipboard fallback, add a compact per-copy format menu, and use a clipboard-specific Markdown-to-text conversion contract with focused interaction and conversion tests.
