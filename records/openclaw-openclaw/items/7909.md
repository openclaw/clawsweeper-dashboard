## Summary

Keep open: current main and the latest release still expose only the assistant-message `Copy as markdown` action, while this issue asks for a new plain-text copy option; the remaining work is a small but user-facing product decision around menu shape and plain-text conversion semantics.

## What This Changes

Request adding a Control UI option or preference so assistant messages can be copied as plain text instead of only Markdown.

## Best Possible Solution

Add a compact Control UI per-message copy-format menu with Markdown as the current default and Plain text as the new option, backed by explicit conversion rules and clipboard/UI tests; add a persisted preference only if maintainers choose that product direction.

Options:

- **Add Compact Copy Menu (recommended):** Keep the existing default behavior and add a small menu or split-button that lets each assistant message be copied as Markdown or converted plain text.
- **Add Persisted Preference:** Let users set a default copy format, which may be more convenient but adds preference surface and upgrade/test work for a low-priority UX feature.
- **Leave Markdown Only:** Close or defer the feature if maintainers decide the extra copy surface is not worth the UI complexity right now.
