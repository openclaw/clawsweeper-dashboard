## Summary

Keep open: the plain-text clipboard mode remains a distinct Control UI ergonomics feature, and the recent discussion correctly leaves the interaction and conversion contract for an explicit product decision rather than conservative cleanup.

## What This Changes

Add a Control UI option to copy assistant-message content as plain text instead of only Markdown.

## Best Possible Solution

Add a compact per-click Markdown/plain-text menu to the existing assistant-message action, retain Markdown as the stable default, define plain-text semantics with a purpose-built conversion helper, and test clipboard output plus keyboard and touch accessibility without adding persisted settings unless maintainers explicitly want them.
