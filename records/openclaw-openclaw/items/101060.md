## Summary

Close as cannot reproduce: current main does not silently drop `checkId` or `fixClass` at runtime, and the reported custom policy-metadata inheritance surface is internal rather than a documented plugin or doctor extension API.

## What This Changes

The issue reports that inherited policy doctor fix metadata cannot override `checkId` or `fixClass`, which can silently attach the wrong tracking and classification to policy fixes.

## Best Possible Solution

Keep policy fix recommendation metadata internal; if custom policy fix metadata is needed, design a typed policy/plugin API with tests instead of loosening this helper.
