## Summary

The reported silent metadata-drop bug does not reproduce on current main: the helper is an internal policy-plugin table helper, the runtime object spread does not drop override fields, and the supported custom health-check identifier contract is the public `HealthFinding.checkId` string.

## What This Changes

The issue asks for `PolicyFixMetadata` inheritance to preserve custom `checkId` and `fixClass` fields for custom policy tracking IDs.

## Best Possible Solution

Keep policy fix recommendation metadata internal; if custom policy fix metadata is needed later, design a typed policy/plugin SDK API with tests instead of loosening this helper.
