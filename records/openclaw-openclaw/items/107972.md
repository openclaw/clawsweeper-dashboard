## Summary

Keep this issue open: the supplied production-path reproduction shows a credible cross-agent file-authorization boundary violation, the explicit agent-scoped roots bypass the narrower default-roots check, and no merged fix currently owns the remaining sandbox exposure.

## What This Changes

Restrict agent-scoped media authorization so only the active agent or session sandbox is readable, not sibling sandboxes under the shared state directory.

## Best Possible Solution

Remove the shared sandboxes parent from baseline media roots and thread the exact active agent/session sandbox root through authorized call sites, with regression coverage proving active-sandbox reads succeed while sibling paths and symlink escapes fail on POSIX and Windows.
