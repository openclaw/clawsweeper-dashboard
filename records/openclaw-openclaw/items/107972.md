## Summary

Keep open: the reported cross-agent media authorization bypass remains present on current main, has a concrete production-path reproduction, and is not owned by an open fix PR.

## What This Changes

Prevent agent-scoped media authorization from permitting reads inside sibling agent or session sandbox workspaces.

## Best Possible Solution

Separate baseline generated-media roots from agent-scoped sandbox roots, authorize only the exact active agent or session sandbox workspace, and add cross-sandbox deny plus active-sandbox allow regression coverage across shared authorization and representative outbound, understanding, and preview callers.

Yes. The report provides a deterministic production-code path that creates sibling sandbox state, builds the real roots, passes them to `assertLocalMediaAllowed`, and observes authorization plus file contents; current main retains the decisive code.

## Solution Assessment

Yes, with care: narrowing agent-scoped authorization to the exact active sandbox is the appropriate owner-boundary fix, but globally deleting sandbox access without supplying that active root would risk breaking valid sandbox media.
