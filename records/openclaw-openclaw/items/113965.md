## What This Changes

This PR adds a macOS dashboard gateway picker for users with multiple configured gateways, allowing in-place switching, separate dashboard windows, and confirmed promotion of eligible saved profiles to the primary gateway.

## System Context

The macOS app embeds the web dashboard in a WKWebView and supplies its connection from the primary gateway or Keychain-backed gateway profiles. The PR builds a credential-free native gateway catalog, exposes it to the dashboard header, and routes picker actions back to native dashboard-window management.
