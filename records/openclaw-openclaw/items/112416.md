## What This Changes

Threads an agent’s provider-aware streaming function through safeguard-mode compaction so summarization can use the same provider egress path as normal agent turns.

## System Context

Safeguard compaction condenses older agent-session turns before the model receives its next context window. Its summarizer must use the selected provider’s request path so provider-specific routing and base URLs are preserved while producing the new session summary.
