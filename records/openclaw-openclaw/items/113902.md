## What This Changes

The PR updates the plugin install-record transaction so `openclaw plugins uninstall <id> --force --keep-files` retains the package files without allowing startup recovery to load the removed npm plugin again.

## System Context

The plugin installer persists install records and scans managed npm directories to recover valid packages at startup. The uninstall command changes those records, and the startup recovery path uses them to determine whether a retained package should become an active plugin again.
