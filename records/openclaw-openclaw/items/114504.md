## What This Changes

This PR splits TUI event handling into session matching, run-lifecycle, and session-run coordination components so terminal conversations do not receive another session’s events or lose streamed replies during concurrent and out-of-order Gateway activity.

## System Context

The terminal UI consumes Gateway chat, agent lifecycle, and session-persistence events for the currently selected conversation. The new routing and lifecycle layer decides whether an event belongs to that conversation, retains valid streamed output, and refreshes the visible transcript without reopening completed work.
