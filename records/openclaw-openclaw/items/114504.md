## What This Changes

This PR splits terminal UI event handling into session matching, run-lifecycle, and run-coordination components to prevent cross-session rendering, preserve concurrent streamed replies, and delay history refresh until visible replies persist.

## System Context

The terminal UI receives chat, lifecycle, and session-persistence events from the Gateway or embedded backend. It filters events to the selected conversation, assembles streamed assistant output, and reloads durable history so the terminal transcript remains synchronized with other clients.
