## Summary

Keep open: current main and v2026.6.11 still do not expose the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Existing static config, auto-presence, and gated `setPresence` message action partially cover Discord presence, and https://github.com/openclaw/openclaw/issues/34004 overlaps on status/activity, but none resolves the plugin runtime API and security-boundary decision requested here.

## What This Changes

Request to expose a plugin-runtime Discord `updatePresence` method so plugins can change bot status/activity without a gateway restart or provider internals.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses `gateway.updatePresence` through a narrow SDK/runtime seam with explicit gating, account scoping, and precedence against static config, auto-presence, and `setPresence`.
