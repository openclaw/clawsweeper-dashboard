## Summary

Keep open: current main and the latest release still do not expose the requested `api.runtime.channel.discord.updatePresence` plugin runtime API. Existing Discord support covers static config, auto-presence, and a default-off `setPresence` message action, but promoting presence mutation to plugins is still a public API and Discord credential security-boundary decision.

## What This Changes

Request to add a Discord plugin runtime API so plugins can update the bot's presence dynamically without relying on static config or restarts.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through an explicit gate, account scope, docs, focused tests, live Discord proof, and clear precedence rules.
