## Summary

Keep open: current main and v2026.6.11 still lack the requested `api.runtime.channel.discord.updatePresence` plugin-runtime API. Existing Discord support covers static config, auto-presence, and a gated `set-presence` message action, but exposing presence mutation to plugins remains a public API and bot-credential security-boundary decision.

## What This Changes

Request to expose a Discord plugin-runtime method for dynamic bot presence, status, and activity updates without direct gateway internals or restart.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through explicit gating, account scope, docs, focused tests, live Discord proof, and precedence rules.
