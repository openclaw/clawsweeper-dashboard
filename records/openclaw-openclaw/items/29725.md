## Summary

Keep open: current main still lacks the requested `api.runtime.channel.discord.updatePresence` plugin runtime API. Existing Discord support covers static configured presence, internal auto-presence, and a default-off `setPresence` message action, but exposing plugin-controlled presence mutation remains a public API and Discord bot-credential security-boundary decision.

## What This Changes

Request to add a Discord plugin runtime API for dynamically updating the bot's presence without restarting OpenClaw.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through explicit gating, account scope, docs, tests, live proof, and precedence rules.
