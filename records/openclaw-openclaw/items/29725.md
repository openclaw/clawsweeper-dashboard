## Summary

Keep open: current main and v2026.6.11 still do not expose the requested `api.runtime.channel.discord.updatePresence` plugin-runtime API. The adjacent Discord surfaces cover static config, auto-presence, and a gated `setPresence` message action, but promoting presence mutation to plugins remains a public API and bot-credential security-boundary decision.

## What This Changes

Expose a Discord-specific plugin runtime method so plugins can update bot status/activity dynamically without restarting.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through an explicit gate, account scope, docs, tests, live proof, and precedence rules.
