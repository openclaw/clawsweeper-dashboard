## Summary

Keep open: current main and v2026.6.11 still lack the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API, while existing static config, auto-presence, and `setPresence` only partially cover dynamic Discord presence.

## What This Changes

Request to add a Discord-specific plugin runtime method for dynamically updating the bot's Discord activity and status without restarting.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway path through a narrow, default-off, account-scoped seam with documented precedence against static config, auto-presence, and `setPresence`.
