## Summary

Keep open: current main and v2026.6.11 still lack the requested `api.runtime.channel.discord.updatePresence` plugin runtime API. Existing Discord support covers static config, auto-presence, and a gated `setPresence` message action, but exposing presence mutation to plugins remains a public API and bot-credential security-boundary decision.

## What This Changes

Request to expose a Discord plugin-runtime API that lets plugins update the bot's Discord status and activity without restarting.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through an explicit gate, account scope, docs, tests, live proof, and precedence rules.
