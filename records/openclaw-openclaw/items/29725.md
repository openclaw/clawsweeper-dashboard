## Summary

Keep open: current main and v2026.6.11 still lack the requested `api.runtime.channel.discord.updatePresence` plugin runtime API. Existing Discord support covers static config, auto-presence, and a default-off `setPresence` message action, but exposing presence mutation to plugins remains a public API and bot-credential security-boundary decision.

## What This Changes

The issue requests a new Discord plugin-runtime `updatePresence()` method so plugins can update bot status and activity without a restart.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through an explicit gate, account scope, docs, tests, live proof, and clear precedence rules.
