## Summary

Keep open: current main and v2026.6.11 still lack the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Existing static config, auto-presence, and the gated `setPresence` message action only partially cover Discord presence, while the remaining work is a public plugin API and security-boundary decision.

## What This Changes

Request to expose a Discord runtime `updatePresence` API so plugins can change the bot's Discord status and activity dynamically.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, default-off, account-scoped seam with documented precedence against static config, auto-presence, and `setPresence`.
