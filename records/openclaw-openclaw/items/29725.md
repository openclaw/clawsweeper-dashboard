## Summary

Keep open: current main and v2026.6.11 still lack the requested `api.runtime.channel.discord.updatePresence` plugin API. Static presence config, `autoPresence`, and the gated `setPresence` message action cover adjacent status/activity paths, but the remaining work is a public plugin API and Discord bot-credential security-boundary decision.

## What This Changes

Request to add a Discord plugin-runtime `updatePresence` API so plugins can change the bot status/activity at runtime without relying only on static config or message actions.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, gated, account-scoped seam with documented precedence against static config, `autoPresence`, and `setPresence`.
