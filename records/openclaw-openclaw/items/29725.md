## Summary

Keep open: current main and v2026.6.11 still do not expose the requested `api.runtime.channel.discord.updatePresence` plugin runtime API. Existing Discord support covers static config, auto-presence, and a default-off `setPresence` message action, but a plugin-facing presence mutation API remains a public contract and Discord bot-credential security-boundary decision.

## What This Changes

The issue requests a plugin runtime method for dynamically updating Discord bot presence without restarting the Discord channel.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path behind explicit gating, account scoping, precedence rules, docs, focused tests, and live Discord proof.
