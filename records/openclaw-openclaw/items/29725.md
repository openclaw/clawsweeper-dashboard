## Summary

Keep open: current main and v2026.6.11 still do not expose the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. The implemented static config, auto-presence, and gated `set-presence` message action cover adjacent presence updates, but the remaining request is a public plugin API and bot-credential security-boundary decision.

## What This Changes

Request to add a Discord plugin-runtime `updatePresence()` API so plugins can change bot status and activity without restarting.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, gated, account-scoped seam with documented precedence against static config, auto-presence, and `set-presence`.
