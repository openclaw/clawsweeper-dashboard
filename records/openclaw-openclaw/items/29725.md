## Summary

Keep open: current main and v2026.6.11 still lack the requested plugin-runtime Discord `updatePresence` API. Existing static config, auto-presence, and the gated `setPresence` message action are adjacent, but this remains a public plugin API and security-boundary decision.

## What This Changes

Request to expose dynamic Discord bot presence updates through the plugin runtime channel API.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, gated, account-scoped seam with documented precedence against static config, auto-presence, and `setPresence`.
