## Summary

Keep open: current main and v2026.6.11 still do not expose the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Existing static config, auto-presence, and the default-off `setPresence` message action partially cover Discord presence, while the remaining work is a public plugin API and security-boundary decision.

## What This Changes

The issue requests a Discord plugin runtime API that lets plugins dynamically update Discord bot presence without a restart.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, default-off, account-scoped SDK/runtime seam with documented precedence against static config, auto-presence, and `setPresence`.
