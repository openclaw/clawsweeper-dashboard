## Summary

Keep open: current main and v2026.6.11 still lack the requested `api.runtime.channel.discord.updatePresence` plugin-runtime API. Existing Discord support covers static config, auto-presence, and a default-off `setPresence` message action, but exposing presence mutation directly to plugins remains a public API and security-boundary decision.

## What This Changes

Add a plugin-runtime `api.runtime.channel.discord.updatePresence()` method so plugins can dynamically update Discord bot status/activity without restarting.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path with explicit gating, account scoping, precedence rules, docs, focused tests, and live Discord proof.
