## Summary

Keep open: current main and v2026.6.11 still do not expose the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Adjacent Discord presence support exists through static config, auto-presence, and a default-off `setPresence` message action, but promoting Discord presence mutation to plugin runtime remains a public API and bot-credential security-boundary decision.

## What This Changes

Request to add a Discord plugin-runtime method so plugins can update the bot's Discord presence dynamically without restarting.

## Best Possible Solution

Approve or reject a Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through a narrow, gated, account-scoped seam with documented precedence against static config, auto-presence, and `setPresence`.
