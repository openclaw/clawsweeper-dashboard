## What This Changes

The issue requests a supported plugin-facing API for dynamically updating Discord bot presence at runtime.

## Best Possible Solution

Keep this open until maintainers choose a narrow Discord-owned dynamic presence contract that reuses the existing gateway machinery, preserves a default-off security gate, documents `autoPresence` interaction, and includes focused tests plus live Discord proof.
