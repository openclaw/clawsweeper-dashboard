## Summary

Keep open: current main and v2026.6.11 still provide static Discord presence, auto-presence, and a gated `setPresence` message action, but not the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. The remaining work is a Discord/plugin-SDK product and security-boundary decision rather than conservative cleanup.

## What This Changes

Request a plugin-runtime Discord presence API so plugins can update the bot's Discord status/activity dynamically without a restart.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway update path through a narrow SDK/runtime seam with explicit authorization, account scoping, and precedence against static config, auto-presence, and `setPresence`.
