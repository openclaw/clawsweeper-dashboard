## Summary

Keep open: current main and v2026.6.11 still do not expose the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Static config, auto-presence, and the default-off Discord `setPresence` message action cover adjacent presence paths, but the remaining request is a public plugin API and bot-credential security-boundary decision.

## What This Changes

The issue asks for a Discord plugin runtime API that lets plugins update the bot's status/activity dynamically without restarting OpenClaw.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, default-off, account-scoped SDK/runtime seam with documented precedence, tests, and operator-facing docs.
