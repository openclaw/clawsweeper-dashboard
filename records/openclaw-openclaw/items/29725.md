## Summary

Keep open: current main and v2026.6.11 still lack the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Existing Discord support covers static presence config, auto-presence, and a gated `setPresence` message action, but exposing presence mutation to plugins remains a public API and Discord bot-credential security-boundary decision.

## What This Changes

Request to expose a Discord plugin-runtime `updatePresence` method so plugins can dynamically change bot status/activity without a gateway restart.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway presence path through an explicit gate, account scope, precedence rules, docs, tests, and live Discord proof.
