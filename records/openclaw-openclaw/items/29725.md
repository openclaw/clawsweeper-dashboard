## Summary

Keep open: current main and v2026.6.11 still do not expose the requested plugin-runtime Discord `updatePresence` API. Static config, auto-presence, and the gated `set-presence` message action partially cover Discord presence, and https://github.com/openclaw/openclaw/issues/34004 overlaps on status/activity, but the public plugin API and security-boundary decision remain unresolved.

## What This Changes

Request to expose a Discord plugin-runtime method so plugins can dynamically update the bot's Discord activity and status without restarting.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that wraps `gateway.updatePresence` through a narrow, gated, account-scoped SDK/runtime seam with explicit precedence against static config, auto-presence, and `set-presence`.
