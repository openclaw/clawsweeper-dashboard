## Summary

Keep open: current main still lacks the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. Existing static config, auto-presence, and the gated `setPresence` message action only partially cover Discord presence, while the remaining work is a public plugin API and security-boundary decision.

## What This Changes

Request to add a plugin-facing Discord runtime method for dynamically updating bot presence without restarting the Discord channel.

## Best Possible Solution

Approve or reject a Discord-owned plugin runtime presence contract that reuses the existing gateway presence path through a narrow, default-off, account-scoped seam with documented precedence against static config, auto-presence, and `setPresence`.
