## Summary

Keep open: current main and v2026.6.11 still do not expose the requested `api.runtime.channel.discord.updatePresence` plugin runtime API. Existing Discord support covers static presence config, auto-presence, and a gated `setPresence` message action, so the remaining work is a public plugin API and bot-credential security-boundary decision.

## What This Changes

The issue requests a plugin-facing Discord runtime method for changing bot status/activity without restarting OpenClaw.

## Best Possible Solution

Approve or reject a narrow Discord-owned plugin-runtime presence contract that reuses the existing gateway path through an explicit gate, account scope, docs, tests, live Discord proof, and precedence rules.
