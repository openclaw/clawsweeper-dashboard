## Summary

Keep open: current main and the latest release still provide static Discord presence, auto-presence, and the gated `set-presence` message action, but not the requested plugin-runtime `api.runtime.channel.discord.updatePresence` API. This remains a Discord/plugin SDK and security-boundary product decision rather than conservative cleanup.

## What This Changes

The issue requests a new Discord runtime channel API that lets plugins update bot presence dynamically without restarting.

## Best Possible Solution

Approve or reject a Discord-owned, account-scoped plugin runtime presence contract that reuses the existing gateway update path without exposing provider internals, then add focused docs and tests for authorization and precedence.
