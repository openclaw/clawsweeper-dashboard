## Summary

Keep open: the current-main session-state bug remains and this PR is a useful candidate fix, but the queued follow-up path still suppresses its marker after any successful source-route send, even when that send did not contain the final text. ## What This Changes

The PR records undelivered `message_tool_only` finals in session transcripts, preserves those markers during replay, aligns direct and queued recovery behavior, and standardizes the QA channel send receipt.

## Best Possible Solution

Use one shared exact-final-text delivery classifier for both direct and queued runners, persist the hidden marker only when that final was not delivered to the source route, preserve it with its assistant turn during rotation, and retain the existing one-shot recovery ordering.
