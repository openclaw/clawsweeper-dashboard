## Summary

Keep this issue open: current main has useful session primitives, but it still does not provide the requested public stop/kill/pause/resume/resource-management contract across CLI, Gateway, and UI.

## What This Changes

The issue requests complete session lifecycle management commands, UI controls, and resource limits for stopping, killing, pausing, resuming, and managing OpenClaw sessions.

## Best Possible Solution

Define an additive, authorization-aware lifecycle contract for Gateway, CLI, and UI, then split implementation into narrower tracked slices for hard-kill, UI controls, resume/fork behavior, diagnostics, and resource policy.
