## Summary

Issue #63118 should stay open because current main has useful session primitives, including Gateway abort/delete/cleanup/reset/compact and CLI list/cleanup/tail/export/compact, but it still lacks the requested public stop/kill/pause/resume/resource-management lifecycle contract across Gateway, CLI, and UI.

## What This Changes

Request a broader session management surface with stop, kill, pause, resume, listing, resource controls, cleanup, and UI exposure for active and historical sessions.

## Best Possible Solution

Keep #63118 open as the product umbrella and use it to define an additive, authorization-aware lifecycle contract while narrower linked issues handle scoped slices such as process kill, topic UI, resume/fork, and diagnostics.
