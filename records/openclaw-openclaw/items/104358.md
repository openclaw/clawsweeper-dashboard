## Summary

This cleanup remains necessary: current main creates UUID-scoped host staging directories without carrying cleanup ownership to either consuming execution path. The request is bounded, but cleanup must occur after media consumption and should remove only directories that are empty rather than recursively deleting staged files.

## What This Changes

Remove empty `openclaw-staged-*` directories after host-workspace inbound-media staging no longer needs them.

## Best Possible Solution

Return the host-only staging directory identity with the staging result and attempt non-recursive removal from each consuming lifecycle’s `finally` path, so empty directories disappear while non-empty or active directories remain untouched; also remove a newly created directory immediately when staging produced no files.
