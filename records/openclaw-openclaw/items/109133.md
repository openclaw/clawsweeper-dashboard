## Label Justifications

- `P1`: Interrupted agent streams can currently become empty successful final turns, suppressing the user-visible answer and failure signal.
- `merge-risk: 🚨 compatibility`: The new EOF rule can reject custom OpenAI-compatible Responses streams that previously completed without a documented terminal event.

## Summary

This is the stronger candidate for the linked bug because it validates termination at the Responses transport boundary and preserves legitimate incomplete responses. Keep it open pending real transport proof and explicit acceptance of the custom-provider compatibility impact.

## What This Changes

The PR makes Responses streams throw when EOF arrives without a terminal event, recognizes `response.incomplete` as terminal, and updates focused stream tests.

## Best Possible Solution

The Responses parser should require a documented completed, incomplete, or failed outcome before success, preserve incomplete-response stop and usage semantics, and apply that rule consistently after native, Azure, and compatible-provider paths are proven.
