## What This Changes

The branch makes agent `edit` and `apply_patch` reject invalid UTF-8 before rewriting existing files, while preserving a valid leading UTF-8 BOM and adding coverage across filesystem backends.

## System Context

OpenClaw’s agent editing tools read an existing file, apply a requested text edit or patch, and write the resulting content through host, workspace-confined, sandbox, or remote filesystem operations. This PR changes the shared bytes-to-text boundary before those tools compute and persist an update.
