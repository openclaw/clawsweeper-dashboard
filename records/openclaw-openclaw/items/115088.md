## What This Changes

The PR replaces lossy decoding in agent `edit` and `apply_patch` reads with strict UTF-8 decoding so invalid existing files fail before rewrite while valid leading BOM bytes survive edits.

## System Context

OpenClaw agent coding tools read an existing file through host, workspace-confined, sandbox, or injected filesystem operations, apply a text edit or patch, then write the transformed content. The changed decoder is the common byte-to-text boundary that determines whether an existing file can safely enter that mutation pipeline.
