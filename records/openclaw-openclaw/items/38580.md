## Summary

Keep open: current main and v2026.6.11 still do not expose a Telegram pinned-message read action or native command, and the closed implementation attempts did not merge. This remains a useful Telegram feature request, but it needs maintainer product/security direction before implementation because it would expose persistent chat content to agent tooling.

## What This Changes

The issue requests an on-demand command or automatic session-start behavior that fetches the current Telegram pinned message through the Bot API.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow on-demand pinned-message read in the Telegram plugin with an explicit action/config gate, docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved opt-in behavior.
