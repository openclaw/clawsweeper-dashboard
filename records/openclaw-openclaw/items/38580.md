## Summary

Keep open: current main and the latest release still do not expose Telegram pinned-message reads, and the remaining work needs maintainer product/security direction because pinned chat context can become agent prompt/session context.

## What This Changes

## Best Possible Solution

Add a Telegram-plugin-owned on-demand pinned-message read action behind an explicit gate, document current-pin semantics, and defer automatic session-start prompt injection unless maintainers approve that policy.
