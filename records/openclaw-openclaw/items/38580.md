## What This Changes

Request to let OpenClaw fetch the current Telegram chat pinned message via the Telegram Bot API for on-demand or session-start context.

## Best Possible Solution

Decide the policy first, then implement a narrow Telegram-plugin-owned on-demand pinned-message read using Bot API getChat.pinned_message behind an explicit gate, with docs, focused tests, and live Telegram proof; automatic session-start context should remain separate opt-in work.
