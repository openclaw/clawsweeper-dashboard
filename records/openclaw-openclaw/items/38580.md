## Summary

Keep open: current main and v2026.6.11 still do not expose Telegram pinned-message reads, while the two linked implementation PRs are closed unmerged. This remains a useful Telegram feature request, but it needs maintainer product and security direction before implementation.

## What This Changes

Add an on-demand or session-start way for OpenClaw to fetch a Telegram chat's pinned message through the Telegram Bot API and make it available to agents as context.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow Telegram-plugin-owned on-demand pinned-message read with an explicit gate, docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved opt-in behavior.
