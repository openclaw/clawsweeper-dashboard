## Summary

Keep open: current main and v2026.6.11 still do not expose Telegram pinned-message reads, and the remaining work needs a maintainer product/security decision because pinned messages are persistent chat context that would become available to agents.

## What This Changes

The issue asks for Telegram support to read a chat's current pinned message so agents can use pinned content as persistent context.

## Best Possible Solution

Add a Telegram-plugin-owned on-demand pinned-message read action behind an explicit gate, document the current-pin semantics, and defer automatic session-start prompt injection until maintainers approve that policy.
