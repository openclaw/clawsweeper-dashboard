## Summary

Keep open: current main and v2026.6.11 still do not expose Telegram pinned-message reads, and the remaining work is a new Telegram data-access capability that needs product and security direction before implementation.

## What This Changes

The issue requests a Telegram capability for agents to fetch the current pinned chat message through the bot API, either on demand or at session start.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow Telegram-owned on-demand pinned-message read action or command behind an explicit gate, with docs, focused tests, and live Telegram proof; automatic session-start context should remain a separately approved opt-in behavior.
