## Summary

Keep open: current main and v2026.6.11 still do not expose Telegram pinned-message reads, and the remaining work needs maintainer product/security direction because it would expose persistent chat context to agents.

## What This Changes

Request to let Telegram agents fetch a chat's current pinned message on demand or at session start via the Telegram Bot API.

## Best Possible Solution

Add a Telegram-plugin-owned on-demand pinned-message read action behind an explicit gate, document current-pin semantics, and defer automatic session-start injection until maintainers approve the context policy.
