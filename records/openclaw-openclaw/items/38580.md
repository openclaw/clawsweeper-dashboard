## Summary

Keep open: current main and v2026.6.11 still do not expose Telegram pinned-message reads, and the closed implementation PRs were not merged. This remains a useful but security-sensitive Telegram feature that needs maintainer product direction before implementation.

## What This Changes

Request to let the Telegram assistant fetch the current pinned chat message on demand or at session start via the Telegram Bot API.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow on-demand pinned-message read in the Telegram plugin with an explicit gate, docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved opt-in behavior.
