## Summary

Keep open: current main and v2026.6.11 still do not expose a Telegram pinned-message read action, list-pins action, or native get-pinned command, and both linked implementation PRs are closed unmerged. This remains a useful but security-sensitive Telegram feature that needs maintainer product direction before implementation.

## What This Changes

Request to let the assistant fetch the current pinned Telegram chat message through the Telegram Bot API, either on demand or at session start.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow on-demand pinned-message read in the Telegram plugin behind an explicit gate, with docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved.
