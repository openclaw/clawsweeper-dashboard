## Summary

Keep open: current main still does not expose Telegram pinned-message reads. The gap is source-reproducible, but adding it would expose durable room context to agents, so the default, gate, and context-injection behavior need maintainer product and security direction before implementation.

## What This Changes

Request to let the Telegram integration read the current pinned chat message through the bot API, either on demand or at session start.

## Best Possible Solution

Decide the Telegram pinned-context access policy first, then implement a Telegram-owned on-demand pinned-message read action or command with an explicit gate, docs, focused tests, and live Telegram proof.
