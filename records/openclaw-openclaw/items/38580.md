## Summary

Keep open: current main and the latest release still do not expose Telegram pinned-message reads. The gap is clear, but the right default, gate, and context-injection behavior need maintainer product and security direction before implementation.

## What This Changes

Request to let Telegram agents fetch the current pinned Telegram chat message through the bot API, either on demand or at session start.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow Telegram-plugin pinned-message read action or command behind an explicit gate, with docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved opt-in behavior.
