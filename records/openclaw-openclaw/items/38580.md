## Summary

Keep open: current main and v2026.6.11 still do not expose a Telegram pinned-message read action or native command, and the two linked implementation PRs are closed unmerged. This remains a useful Telegram feature request, but it needs maintainer product and security-default direction before implementation.

## What This Changes

The issue requests a Telegram capability for an agent or command to read the current pinned message from a chat through the Bot API.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow on-demand pinned-message read in the Telegram plugin with an explicit action/config gate, docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved opt-in behavior.
