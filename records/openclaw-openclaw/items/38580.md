## What This Changes

Request a Telegram bot/API path for the assistant to fetch the current pinned message from a chat on demand or at session start.

## Best Possible Solution

Approve a narrow Telegram-owned on-demand pinned-message read first, behind an explicit action/config gate with docs, focused tests, and live Telegram proof; keep automatic session-start context as a separate opt-in decision.
