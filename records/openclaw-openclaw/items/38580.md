## What This Changes

Request Telegram support for reading the current pinned chat message as persistent agent context, either on demand or at session start.

## Best Possible Solution

Add a Telegram-plugin-owned on-demand pinned-message read/list-pins action behind an explicit gate, document the one-current-pin scope, and defer automatic session-start prompt injection until maintainers approve the context policy.
