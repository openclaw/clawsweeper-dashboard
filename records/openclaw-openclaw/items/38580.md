## Summary

Keep open: current main and v2026.6.11 still do not expose a Telegram pinned-message read action or native command, while the closed related PRs did not merge. This remains a useful but security-sensitive Telegram feature that needs maintainer product direction before implementation.

## What This Changes

The issue requests a Telegram capability to fetch the current pinned chat message through the bot/API so pinned context can be used on demand or at session start.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow on-demand pinned-message read in the Telegram plugin with an explicit action/config gate, docs, focused tests, and live Telegram proof; automatic session-start context should remain a separately approved opt-in behavior.
