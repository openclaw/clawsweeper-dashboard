## Summary

Keep open: current main and v2026.6.11 still do not expose a Telegram pinned-message read action, native command, or config gate, and both related implementation PRs were closed unmerged. The request is useful, but it expands Telegram chat-content access and needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a Telegram bot capability to fetch the current pinned chat message on demand or at session start so pinned context can be used by the assistant.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow on-demand pinned-message read in the Telegram plugin with an explicit action/config gate, docs, focused tests, and live Telegram proof; automatic session-start context should stay separately opt-in.
