## Summary

Keep open: current main and the latest release still do not expose Telegram pinned-message reads, and the remaining work needs a maintainer product/security decision because it would expose persistent Telegram room context to agents.

## What This Changes

Allow the Telegram plugin to fetch a chat's current pinned message for agents, either on demand or at session start.

## Best Possible Solution

Add a Telegram-plugin-owned on-demand pinned-message read action behind an explicit gate, document the current-pin semantics, and defer automatic session-start injection until maintainers approve the context policy.
