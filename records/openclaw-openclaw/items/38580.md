## What This Changes

The issue requests an on-demand or session-start Telegram Bot API read of a chat's pinned message so agents can use pinned chat context.

## Best Possible Solution

Decide the Telegram data-access policy first, then implement a narrow Telegram-plugin pinned-message read action or command behind an explicit gate, with docs, focused tests, and live Telegram proof; automatic session-start context should remain separately approved opt-in behavior.
