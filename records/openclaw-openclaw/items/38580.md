## Summary

Keep open: current main and v2026.6.11 still do not expose Telegram pinned-message reads, and the remaining work needs maintainer product/security direction because it would let agents fetch persistent Telegram room context through bot credentials.

## What This Changes

Request to let OpenClaw fetch the current pinned Telegram chat message on demand or at session start, likely via Telegram Bot API `getChat.pinned_message`.

## Best Possible Solution

Implement a Telegram-plugin-owned, explicitly gated on-demand pinned-message read action backed by `getChat.pinned_message`, and defer automatic session-start injection until maintainers approve the prompt/context policy.
