## Summary

Keep this PR open for normal merge handling: current main still expands `$` substitution tokens in transcript echoes, the patch covers both production formatter sites, and I found no blocking functional or security finding.

## What This Changes

The PR changes the shared media transcript echo and Matrix preflight echo formatters to use function replacers, with regression tests preserving literal dollar sequences.

## Best Possible Solution

Land the narrow function-replacer fix with both regression tests once required checks finish cleanly, keeping the existing config and first-placeholder semantics unchanged.

## Reproduction Assessment

Yes, at source level: current main uses a string replacement in both echo formatters, and a local Node check demonstrates that `$&` and `$$` are interpreted instead of echoed literally. I did not run a full voice-note channel E2E in this read-only review.

## Solution Assessment

Yes, this is the best narrow fix: a function replacer preserves literal transcript text and existing first-placeholder semantics without changing config, channel delivery, or plugin API boundaries. Replacing all placeholders or sanitizing `$` manually would either change behavior or add unnecessary special-case logic.
