## Summary

Current main still leaves Active Memory timeout-breaker state unbounded, so this PR remains useful, but the patch cannot merge as written because its new cleanup ignores the existing configured cooldown and the submitted proof only exercises test helpers.

## What This Changes

The PR bounds Active Memory's process-local timeout circuit-breaker map by purging expired entries and evicting oldest entries at 1,000 keys, with two focused tests.

## Best Possible Solution

Keep the plugin-local mutation-time sweep and hard cap, but pass the normalized configured cooldown through timeout recording, test values below and above 60 seconds, and demonstrate the repaired path with redacted live gateway or plugin output.
