## What This Changes

The PR widens the sandbox browser audit publish-host loopback check from exact `127.0.0.1` to any normalized host string starting with `127.`.

## Best Possible Solution

Use the shared `isLoopbackIpAddress` helper for parsed Docker publish hosts, keep `localhost`, add focused audit regression coverage, and require redacted Docker/sandbox proof before merge.

## Reproduction Assessment

Yes. Source inspection shows current main parses Docker port output and treats any parsed host not accepted by `isLoopbackPublishHost` as exposed; that helper currently only accepts exact `127.0.0.1`, `::1`, and `localhost`.

## Solution Assessment

No, not in its current shape. The intended 127/8 fix belongs in this audit helper, but the best implementation should reuse the canonical parsed loopback helper instead of adding a parallel string-prefix classifier.
