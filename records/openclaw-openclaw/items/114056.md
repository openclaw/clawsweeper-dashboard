## What This Changes

The PR distinguishes ordinary in-place session resets from deletion in the Codex extension so a reset can clear and recreate its binding while a deleted session remains durably fenced.

## System Context

OpenClaw’s agent runner owns a stable chat session while the Codex plugin stores the thread binding for that session. Reset and session-end events update the binding state before later turns choose whether to resume, reclaim, or start a Codex thread.
