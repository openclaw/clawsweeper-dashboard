## What This Changes

The issue requests configurable bare `/new` or `/reset` greeting behavior, either by routing the greeting through a cheaper model or suppressing the greeting/model turn entirely.

## Best Possible Solution

Define one maintainer-approved reset-start policy across auto-reply, Gateway, config schema/help/docs, and tests that covers acknowledgement-only reset, startup-turn greeting, suppression, prompt customization, and optional cheaper model routing without competing ad hoc keys.
