## Summary

Keep open: current main and v2026.6.11 still do not provide a public reset-greeting model, suppression flag, or unified reset-start policy; related items cover prompt text or startup fallthrough but do not fully own this broader model/suppression decision.

## What This Changes

Request to add public reset-start configuration so bare `/new` and `/reset` can either avoid a model greeting or run that greeting on a cheaper model.

## Best Possible Solution

Define one maintainer-approved reset-start policy that covers acknowledgements, startup/model turns, prompt text, greeting suppression, and optional greeting-model routing across auto-reply, Gateway, schema, docs, and tests.
