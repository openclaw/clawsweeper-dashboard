## Summary

Keep open: current main and v2026.6.11 still lack a public reset-greeting model, suppression flag, or unified reset-start policy; related items cover prompt text or fallthrough behavior but do not fully own this model-routing and suppression request.

## What This Changes

## Best Possible Solution

Define one maintainer-approved reset-start policy covering acknowledgements, startup/model turns, prompt text, greeting suppression, and optional greeting-model routing across auto-reply, Gateway, schema, docs, and tests.
