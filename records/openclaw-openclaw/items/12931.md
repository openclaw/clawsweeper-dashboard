## Summary

Keep open: current main and v2026.6.11 avoid the original expensive bare-reset greeting for ordinary acknowledgement paths, but OpenClaw still lacks a supported reset-start policy for opting into a cheaper greeting model, suppressing/acknowledging consistently, or aligning the prompt/fallthrough behavior tracked by related items.

## What This Changes

The issue requests a configurable cheaper model for bare `/new` and `/reset` greeting turns and/or a way to suppress that greeting entirely.

## Best Possible Solution

Define one maintainer-approved reset-start policy that covers acknowledgements, startup/model turns, prompt text, suppression, and optional greeting-model routing across auto-reply, Gateway, schema, docs, and tests.
