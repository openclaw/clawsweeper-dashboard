## Summary

Keep open: current main and v2026.6.11 avoid the original bare-reset token burn with static acknowledgements, but OpenClaw still has no configurable reset-greeting model, suppression policy, or unified reset-start contract.

## What This Changes

The issue requests configurable bare `/new` and `/reset` greeting behavior, either by choosing a cheaper greeting model or suppressing the model-generated greeting.

## Best Possible Solution

Define one typed reset-start policy covering acknowledgement-only resets, startup/model turns, prompt text, optional greeting model routing, bootstrap safeguards, schema, docs, and focused tests.
