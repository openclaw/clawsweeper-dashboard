## Summary

Keep open: current main and v2026.6.11 remove the original ordinary bare-reset token burn with static acknowledgements, but the requested configurable reset-greeting policy, cheaper reset model routing, and restore/suppress choice remain missing.

## What This Changes

Request to make bare `/new` and `/reset` greeting behavior configurable, including a cheaper greeting model or suppressing the model-generated greeting.

## Best Possible Solution

Define one typed reset-greeting policy shared by chat commands, reply-producing reset turns, Gateway agent resets, schema/help/docs, and tests, with maintainer-approved defaults for static ack, startup turn, and optional model override.
