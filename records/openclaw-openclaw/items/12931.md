## Summary

Keep open: current main and v2026.6.11 avoid the expensive model turn for ordinary bare resets, but they still do not expose a public reset-greeting model, suppression, startup-turn, or prompt policy; the related open items only cover narrower prompt text or fallthrough behavior.

## What This Changes

The issue asks for configurable bare `/new` and `/reset` greeting behavior, either by routing the greeting to a cheaper model or suppressing it entirely.

## Best Possible Solution

Define one maintainer-approved reset-start policy covering acknowledgements, startup/model turns, prompt text, greeting suppression, and optional greeting-model routing across schema, docs, auto-reply, Gateway, and tests.
