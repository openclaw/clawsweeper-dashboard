## What This Changes

The issue requests configurable bare `/new` and `/reset` greeting behavior, either by routing the greeting through a cheaper model or suppressing the model-run greeting entirely.

## Best Possible Solution

Define one typed reset-start policy covering acknowledgement-only resets, startup/model turns, prompt text, optional greeting model routing, bootstrap safeguards, schema, docs, and focused tests.
