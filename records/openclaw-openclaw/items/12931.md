## Summary

Keep open: current main and v2026.6.11 avoid the original expensive bare-reset greeting for ordinary acknowledgement paths, but OpenClaw still lacks a supported reset-start policy for choosing a cheaper greeting model, suppressing or restoring greeting turns consistently, and aligning related prompt/fallthrough behavior.

## What This Changes

Request to add supported configuration for bare `/new` and `/reset` greeting behavior, including suppressing the greeting or routing it to a cheaper model.

## Best Possible Solution

Define one maintainer-approved reset-start policy that covers acknowledgements, startup/model turns, prompt text, suppression, and optional greeting-model routing across auto-reply, Gateway, schema, docs, and tests.
