## Summary

Keep open: current main and v2026.6.11 already suppress the ordinary bare reset model call with fixed acknowledgements, but the requested typed reset-greeting policy, cheaper greeting model routing, and configurable restore/suppress semantics are still missing.

## What This Changes

The issue requests configurable bare `/new` and `/reset` greeting behavior, either by using a cheaper greeting model or suppressing the greeting/model turn entirely.

## Best Possible Solution

Define one maintainer-approved reset-start policy across auto-reply, Gateway, schema, docs, and tests that covers ack-only reset, startup-turn greeting, suppression, and optional cheaper model routing without adding ad hoc competing keys.
