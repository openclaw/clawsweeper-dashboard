## What This Changes

## Best Possible Solution

Define one maintainer-approved reset-start policy covering acknowledgements, startup/model turns, prompt text, suppression, and optional greeting-model routing across auto-reply, Gateway, schema, docs, and tests.

Options:

- **Restore Startup Turns By Default:** Make bare resets run the startup/model turn again and explicitly accept the token-cost, latency, and upgrade behavior change.
- **Defer New Reset Controls:** Keep current ack-only behavior and use `/new <message>` plus the narrower prompt-text tracker until a broader reset policy is approved.
