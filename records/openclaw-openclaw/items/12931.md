Keep open: current main and the latest release cover the cheap static acknowledgement path for ordinary bare resets, but the requested supported reset-start policy for cheaper greeting models, suppression, or consistent startup-turn behavior is still missing and needs maintainer product direction.

## What This Changes

## Best Possible Solution

Define one maintainer-approved reset-start policy that covers acknowledgements, startup/model turns, prompt text, suppression, and optional greeting-model routing across auto-reply, Gateway, schema, docs, and tests.
