Keep open: current main and v2026.6.11 remove the original ordinary bare-reset token burn with static acknowledgements, but the requested configurable reset-greeting policy, cheaper reset model routing, and restore/suppress choice remain missing.

## What This Changes

Request a configurable bare `/new`/`/reset` greeting policy, including either a cheaper reset-greeting model or an option to suppress the greeting model turn.

## Best Possible Solution

Define one typed reset-greeting policy shared by chat commands, reply-producing reset turns, Gateway agent resets, schema/help/docs, and tests, with maintainer-approved defaults for static acknowledgement, startup turn, and optional model override.
