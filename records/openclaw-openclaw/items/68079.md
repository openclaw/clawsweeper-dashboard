Full review comments:

- **[P2] Reject header-invalid session IDs before injection:** `extensions/zai/stream.ts:21`
  - body: `isInjectableSessionId` currently accepts any non-empty trimmed string up to 256 chars, so values containing `\r`/`\n` are copied into `X-Session-Id`. Fetch/Undici `Headers` rejects those values, which turns a ZAI request with a caller-supplied invalid `sessionId` into a local transport failure before dispatch.
  - confidence: 0.93
- **[P2] Replace existing session headers case-insensitively:** `extensions/zai/stream.ts:40-42`
  - body: This merge can leave both `x-session-id` and `X-Session-Id` in `options.headers`. Header normalization is case-insensitive and combines those into a comma-joined value, so ZAI can receive `old, new` instead of the intended sticky-routing key; remove existing `x-session-id` variants before setting the new value.
  - confidence: 0.91
- **[P3] Drop the release-owned changelog edit:** `CHANGELOG.md:18`
  - body: `CHANGELOG.md` is release-generated in this repo, so normal PRs should not edit it directly. Keep the release-note context in the PR body or eventual squash/merge message instead of adding this entry to the release-owned file.
