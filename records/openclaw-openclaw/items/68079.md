## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Use an opaque affinity value for the provider header:** `extensions/zai/stream.ts:42`
  - body: This copies OpenClaw’s raw `options.sessionId` into a third-party ZAI request header. That creates a stable provider-visible identifier before maintainers have approved the privacy/affinity contract; use an opaque provider-affinity key instead of forwarding the internal session id verbatim.
  - confidence: 0.88
- **[P2] Replace existing session headers case-insensitively:** `extensions/zai/stream.ts:40-43`
  - body: If `options.headers` already contains `x-session-id`, adding `X-Session-Id` leaves both keys in the object; Fetch/Headers normalizes them into a single comma-joined value such as `old, new`. That can break sticky routing or trigger provider rejection, so remove any existing `x-session-id` variant before setting the generated value.
  - confidence: 0.9
- **[P2] Reject header-invalid session ids before injection:** `extensions/zai/stream.ts:21`
  - body: `isInjectableSessionId` accepts any nonblank string under 257 characters, including values with `\r` or `\n`. Fetch/Undici rejects those as invalid header values, so a caller-provided session id with control characters can make otherwise valid ZAI requests fail before dispatch.
  - confidence: 0.9
- **[P1] Rebase over current ZAI GLM-5.2 reasoning support:** `extensions/zai/index.ts:137-154`
  - body: GitHub reports this PR as dirty, and the PR head’s `wrapZaiStreamFn` predates current main’s GLM-5.2 `reasoning_effort` mapping. Rebase the branch and keep the current reasoning wrapper behavior while adding the session header wrapper.
  - confidence: 0.83
- **[P3] Drop the release-owned changelog edit:** `CHANGELOG.md:21`
  - body: Normal PRs should not edit `CHANGELOG.md`; release generation derives entries from merged PR context. Keep this release-note text in the PR body or squash message and remove the direct changelog line.
  - confidence: 0.95
