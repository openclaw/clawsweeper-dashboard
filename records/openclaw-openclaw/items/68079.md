## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Use an approved opaque affinity value:** `extensions/zai/stream.ts:36-43`
  - body: This copies the raw OpenClaw `sessionId` into a third-party ZAI request header for every sessioned call. Session IDs can include user or workflow labels, so this needs either explicit maintainer acceptance for raw egress or a stable opaque affinity key before merge.
  - confidence: 0.9
- **[P2] Reject invalid header values before dispatch:** `extensions/zai/stream.ts:15-23`
  - body: `isInjectableSessionId` accepts any non-empty trimmed string, including `\r`, `\n`, and other header-invalid control bytes. Once copied into `X-Session-Id`, Fetch/Undici header normalization can throw before the ZAI request is sent, so add an HTTP header-value guard with regression coverage.
  - confidence: 0.89
- **[P2] Replace existing session header before injecting:** `extensions/zai/stream.ts:40-43`
  - body: The wrapper spreads existing headers and then adds `X-Session-Id`, so a preexisting `x-session-id` key with different casing can survive and normalize into a combined value such as `old, new`. Remove any existing session header case-insensitively before setting the canonical ZAI value.
  - confidence: 0.86
