## What This Changes

The PR replaces unbounded OpenAI Codex image-generation SSE reads with a fixed 30-second idle timeout and adds a stalled-stream regression test.

## Best Possible Solution

Keep the shared idle-reader integration, derive its deadline from the established image request or Codex stream budget, and cover both a permanently stalled stream and a slow-but-valid stream whose silent gap exceeds 30 seconds.
