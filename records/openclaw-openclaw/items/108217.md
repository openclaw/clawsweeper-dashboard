## Summary

This PR remains necessary, but the proposed patch does not deliver its stated restart-drain benefit: it adds an optional signal that no production caller passes, and its polling implementation retains one abort listener per completed 25 ms poll. The direct helper timing output is useful, but it does not prove the actual restart lifecycle now cancels the wait.

## What This Changes

The PR adds an optional `AbortSignal` parameter to cron-drain polling and tests pre-aborted, mid-wait-aborted, and timeout-only behavior.

## Best Possible Solution

Thread the existing restart-lifecycle abort signal into the real drain call, implement an abortable poll wait that removes its listener when either the timer or abort wins, and prove both an ordinary timeout and a superseded restart through the production lifecycle.
