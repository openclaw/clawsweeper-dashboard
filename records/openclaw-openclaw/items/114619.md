## What This Changes

This PR routes a late Mattermost final-style verbose payload to normal delivery after a single-chunk answer has already finalized the shared streaming preview post, preserving the visible answer.

## System Context

Mattermost preview streaming creates one draft post during an agent turn, then may finalize a single-chunk answer by editing that post in place. Later delivery payloads pass through the same channel path; this change separates late final-style status output so it cannot replace the finalized answer.
