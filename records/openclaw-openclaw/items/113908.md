## What This Changes

The branch replaces Android’s compact bottom navigation with an adaptive Compose shell: an overlay drawer below 980 dp and a persistent, scrollable sidebar on wider layouts.

## System Context

Android’s app shell chooses a top-level destination such as chat, sessions, or settings and passes control to the existing navigation and view-model owners. This PR inserts an adaptive navigation container before those destination screens, changing how users reach the same existing flows across portrait and landscape layouts.
