## What This Changes

This PR replaces the Android app’s custom width-threshold sidebar with Material3 adaptive bottom-bar, navigation-rail, and drawer presentations, while preserving existing destination and session callbacks.

## System Context

The Android shell receives the active destination, agent, and session state from the app view model and renders the primary navigation plus the selected screen. This PR changes that presentation layer so window width, height, and tabletop posture choose a Material navigation pattern while the existing destination content continues downstream unchanged.
