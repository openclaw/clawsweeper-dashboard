## Summary

Keep open: current main and v2026.6.11 still provide only a run-level heartbeat model override, while task-mode heartbeats parse only name/interval/prompt and batch all due tasks into one turn. The remaining work is a public heartbeat task metadata and model-routing design, not conservative cleanup.

## What This Changes

Request to add HEARTBEAT.md task-level model hints so individual heartbeat tasks can use a different model than the run-level heartbeat model.

## Best Possible Solution

Define one canonical heartbeat task model-routing contract that preserves run-level heartbeat.model, including syntax, split-or-grouped execution semantics, alias/fallback/auth behavior, docs, and focused tests.
