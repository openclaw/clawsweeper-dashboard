## Label Justifications

- `P2`: This is a useful but non-urgent model-cost and quality-control feature for heartbeat automation, not a production outage or first-run blocker.
- `impact:session-state`: The motivating workaround is sub-agent delegation losing shared memory context, and any native fix must preserve shared session state across model changes.
- `impact:auth-provider`: The request directly changes provider/model selection and validation for heartbeat runs.

## Summary

Keep open: current main still supports only a single heartbeat-level model override and batches due HEARTBEAT.md tasks into one agent turn, while the exact per-task split requested here remains a product/API decision rather than cleanup. The open cron model-override issue at https://github.com/openclaw/openclaw/issues/42631 overlaps on scheduled model selection, but it does not own HEARTBEAT.md task syntax.

## What This Changes

The issue requests a per-task model hint in HEARTBEAT.md so selected heartbeat tasks can run on a different or primary model while routine heartbeat work stays on a cheaper model.

## Best Possible Solution

Choose the permanent contract first: either document plugin/per-turn routing as the supported path, or add a narrow native HEARTBEAT.md task model/provider field that groups or splits due tasks by effective model with explicit session-state and docs/test coverage.

Options:

- **Keep routing per-turn and plugin-owned (recommended):** Document that heartbeat ticks run as one model-routed turn and use heartbeat.model or before_model_resolve/ClawHub plugins for routing policy unless a missing generic seam is proven.
- **Add native HEARTBEAT.md task hints:** Define model/provider fields on task entries, fix parser handling for unknown indented fields, and split or group due tasks by effective model with regression coverage.
- **Fold into scheduled-job routing:** Treat https://github.com/openclaw/openclaw/issues/42631 as the canonical scheduled model override track and avoid a heartbeat-specific syntax until cron and heartbeat semantics converge.
