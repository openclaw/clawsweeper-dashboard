## Summary

Keep open: current main and the latest release still support only a run-level heartbeat model override, while structured HEARTBEAT.md tasks are parsed and executed as one batched heartbeat turn. ## What This Changes

Add a per-task model hint or escalation mechanism for structured tasks in HEARTBEAT.md.

## Best Possible Solution

Define one canonical heartbeat task model-routing contract that preserves run-level heartbeat.model while specifying syntax, split-or-group execution, alias/fallback/auth behavior, docs, and focused tests.
