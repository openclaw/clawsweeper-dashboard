## Summary

This PR remains necessary: current `main` still recomputes every remaining candidate’s similarity against all selected items on each MMR round. The running-maximum update preserves that maximum exactly while avoiding repeated comparisons, and the PR includes an equivalence regression plus credible after-fix benchmark and deployment evidence. No patch defect was identified; it is ready for maintainer review and merge after the normal merge-head refresh.

## What This Changes

The PR changes Memory Core’s maximal marginal relevance reranker to retain each candidate’s largest similarity to selected chunks, replacing repeated rescans with one comparison per newly selected chunk, and adds a reference-ranking equivalence test.

## System Context

Memory Core receives hybrid retrieval candidates during `memory_search` and applies maximal marginal relevance (MMR) to balance relevance against duplicate-like chunks. The reranker’s ordered results feed the memory-search response used by the agent, so synchronous work there runs on the gateway’s event loop.
