## What This Changes

The PR changes Memory Core’s maximal marginal relevance reranker to cache each candidate’s largest similarity to selected chunks, reducing repeated similarity work while adding a reference-ranking equivalence test.

## System Context

Memory Core collects candidate chunks for a memory search, then uses maximal marginal relevance (MMR) to order relevant but diverse results before returning them to the agent. The reranker runs synchronously in the gateway-facing search path, so excessive candidate comparisons can delay unrelated gateway work.
