## Summary

Keep this PR open for normal maintainer merge review. The patch is a focused Memory Core liveness fix: current `main` still recomputes each remaining candidate’s maximum Jaccard similarity against all previously selected candidates, while this branch maintains the equivalent running maximum and adds direct ranking-equivalence coverage. The supplied reproducible benchmark and reported live deployment evidence meet the real-behavior proof gate; no concrete correctness or security defect was identified in the patch.

## What This Changes

This PR changes Memory Core’s maximal marginal relevance reranker to cache each candidate’s greatest similarity to selected chunks, avoiding repeated rescans, and adds a regression test that compares its output with the previous reference algorithm.

## System Context

Memory Core receives hybrid memory-search candidates and applies maximal marginal relevance (MMR) to balance result relevance against duplicate content. The reranked chunks then become the memory-search response returned to the requesting agent or tool.
