## What This Changes

The branch prevents embedded agent runs from delivering or persisting partial assistant answer or reasoning text as a successful reply when the terminal assistant ended in an error or abort.

## System Context

Embedded agent runs collect streamed provider messages, determine the terminal assistant state, and turn that state into reply payloads and session metadata. This change filters terminal error/abort artifacts before downstream callers receive a final answer or the existing concise error response.

## Best Possible Solution

Keep one shared terminal error/abort predicate for answer and reasoning delivery, retain the focused success-versus-error regressions, and merge once the exact-head required checks complete.
