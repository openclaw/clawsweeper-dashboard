## Summary

This PR has a focused, plausible fix for an embedded-agent delivery path, but it still lacks after-fix evidence from a real failed or aborted run. The supplied tests cover the intended payload and terminal-metadata behavior, while the missing runtime proof remains the merge blocker.

## What This Changes

The branch prevents an errored or aborted embedded agent attempt from publishing partial assistant text as final metadata or as a normal reply alongside the concise error payload.

## System Context

OpenClaw’s embedded agent runner collects the terminal assistant message and streamed text from an attempt, then turns that result into channel reply payloads. This PR changes the terminal-preparation and payload-building boundary so failure-state assistant text does not reach downstream message delivery as a successful answer.
