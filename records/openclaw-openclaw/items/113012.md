## Summary

This active PR addresses a real embedded-agent delivery bug with a narrow terminal-state guard: errored or aborted assistant content should not become a successful final reply. The previous reasoning-payload concern is addressed on the current head, and the discussion supplies focused tests plus redacted runtime proof; it is ready for normal maintainer merge review once the exact-head CI completes.

## What This Changes

The PR suppresses visible assistant text and hidden reasoning from embedded-agent terminal payloads when the final assistant message ended in an error or abort, while retaining the concise error response.

## System Context

Embedded agent runs collect provider output, determine the terminal outcome, and build reply payloads for channels and API callers. Terminal preparation selects final-answer metadata, while payload construction decides whether answer text, reasoning, or an error payload is delivered.
