## Summary

## What This Changes

The PR prevents errored or aborted embedded agent runs from treating assistant text as a final answer and from emitting that text beside the existing concise error payload.

## System Context

Embedded agent runs collect the terminal assistant message and streamed assistant text, then prepare metadata and outbound reply payloads for the caller. This PR changes the terminal-preparation and payload-selection boundary so failed attempts surface the normal error response rather than provider-generated text as an answer.
