## What This Changes

Improve the shared plain-text Markdown projection by collapsing redundant URL labels, preserving visible heading structure without attributed styling, and moving list separation after an introductory list.

## System Context

Markdown-core converts agent Markdown into a capability-aware projection used by channels that can only display plain text or cannot apply attributed formatting. Its fallback text and spacing rules feed iMessage and other plain-mechanism channel renderers before delivery to recipients.
