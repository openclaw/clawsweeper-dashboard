Keep open. Current main and v2026.6.11 still lack a first-class `openclaw models auth remove` command, and the open closing pull request is the active implementation candidate rather than a reason to close before merge.

## What This Changes

Request adds a CLI command for safely removing saved model auth profiles, including per-profile deletion, guarded provider-wide deletion, dry-run, confirmation, JSON output, agent scoping, and related auth-state pruning.

## Best Possible Solution

Review and either land or deliberately close the linked PR; the desired end state is a maintainer-approved `models auth remove` command that uses locked local persisted-store deletion, avoids secret output, and documents how it differs from provider-wide logout and `login --force`.

## Solution Assessment
