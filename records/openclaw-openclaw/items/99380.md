## What This Changes

The issue requests a first-class `openclaw models auth remove` command for deleting saved local model auth profiles by profile id or by provider with explicit `--all` confirmation controls.

## Best Possible Solution

Add a first-class `models auth remove` command after maintainer/security review confirms destructive semantics; implement it through auth-profile store helpers that delete only local persisted profiles and safely prune order, lastGood, usage stats, and secret references.
