Keep open. ## What This Changes

Add an interactive agent activity timeline across CLI, chat slash command, TUI/UI monitoring, and JSON export with filters for time, agent, and lifecycle event type.

## Best Possible Solution

Define one maintainer-approved metadata-only lifecycle/audit contract first, then layer the CLI/chat/TUI/UI timeline views on that contract while reusing Activity, trajectory, task, and subagent primitives instead of adding a parallel event store.
