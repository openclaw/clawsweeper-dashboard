## Summary

Keep open: current main has partial observability through the browser-local Activity tab and per-session trajectory tail/export, but it still lacks the requested first-class `openclaw timeline`, `/timeline`, TUI timeline panel, and JSON-exportable cross-agent lifecycle view. The remaining work is product/security-sensitive because it would expose lifecycle, session, tool, error, and export data across operator surfaces.

## What This Changes

The issue requests an interactive agent activity timeline with CLI filters, chat and TUI integration, lifecycle event storage, and JSON export.

## Best Possible Solution

Define one maintainer-approved lifecycle/audit contract first, then build the CLI, chat, TUI, Control UI, and JSON timeline views over that shared redacted source rather than adding a parallel event store.
