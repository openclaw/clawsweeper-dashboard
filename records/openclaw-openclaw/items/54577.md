## Summary

Keep open. Current main has partial observability through the browser-local Activity tab, session trajectory tail/export, and task summaries, but it still does not provide the requested first-class `openclaw timeline`, `/timeline`, TUI panel, or JSON-exportable cross-agent lifecycle timeline; the remaining scope needs maintainer product and security direction, especially alongside https://github.com/openclaw/openclaw/issues/38626 and https://github.com/openclaw/openclaw/issues/98521.

## What This Changes

The issue requests an agent activity timeline command/view with filters, chat/TUI integration, JSON export, and lifecycle event storage.

## Best Possible Solution

Define a metadata-only lifecycle/audit contract first, then build the CLI, slash-command, TUI, and Control UI timeline views over that bounded redacted source rather than adding a parallel event store.
