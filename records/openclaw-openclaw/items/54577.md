## Summary

Keep open. ## What This Changes

The issue requests an interactive agent activity timeline with lifecycle timing, idle/error visibility, `openclaw timeline`, `/timeline`, TUI monitoring, filters, and JSON export.

## Best Possible Solution

Use the metadata-only audit ledger and subagent lifecycle design as the foundation, then add a scoped CLI/chat/TUI or Control UI timeline surface with explicit redaction, authorization, retention, and JSON export contracts instead of adding a parallel event store.

No, not as a direct standalone timeline patch. The maintainable solution needs a maintainer-approved lifecycle/audit contract that reuses existing agent events, `session.tool`, trajectory, task, and subagent state without creating a competing activity store.
