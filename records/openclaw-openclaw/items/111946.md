## What This Changes

The PR makes source-install update status return unknown ahead/behind counts when Git cannot find a visible common ancestor between `HEAD` and its configured upstream, with regression coverage using real temporary Git repositories.

## System Context

The source-install update checker reads repository metadata and Git graph state to produce update diagnostics for operators. Its Git result feeds the update-status output, including whether the checkout is ahead of or behind its upstream.
