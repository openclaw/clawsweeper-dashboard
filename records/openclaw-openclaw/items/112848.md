## Summary

Keep this issue open while its linked implementation candidate is reviewed. The report has two independent environment reports and the open PR explicitly targets the same expired external-CLI OAuth snapshot path, so closing before that PR lands would be premature.

## What This Changes

Prevent configured external-CLI OAuth providers such as Anthropic via Claude CLI from disappearing from the model selector when an OpenClaw auth-profile snapshot expires while the CLI-managed credential is still valid.

## System Context

The gateway builds model-selector results from configured models and their read-only credential availability. External CLIs own OAuth refresh, while the Control UI consumes the gateway's model list and may hide entries marked unavailable.
