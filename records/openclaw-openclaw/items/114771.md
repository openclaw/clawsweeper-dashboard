## What This Changes

The branch replaces realtime Talk’s fixed 500 ms empty-final fallback with a 60-second configurable grace period so late real text can be spoken instead of an immediate no-text placeholder.

## System Context

Control UI realtime Talk submits an agent consult through the Gateway, listens for final chat events, and passes the chosen response to the realtime voice session. The changed path decides how long to wait after an empty final before speaking a fallback response.

## Best Possible Solution
