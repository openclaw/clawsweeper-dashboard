The issue reports that `agents.defaults.sandbox.mode: "non-main"` causes `sessions_spawn` child sessions to be accepted but never initialize or report useful errors.

Keep this issue open as the canonical sandbox-specific tracker and make the eventual fix cover Docker startup failure visibility, child session terminal state, and regression proof for `non-main` sandboxed `sessions_spawn`.
