## What This Changes

The issue asks OpenClaw to stop `agents.defaults.sandbox.mode: "non-main"` from leaving native `sessions_spawn` subagents accepted but never initialized, logged, or terminalized.

## Best Possible Solution

Keep this as the sandbox-specific canonical tracker, choose the startup-failure contract, then prove both normal and forced-failure Docker `non-main` `sessions_spawn` behavior on current main.
