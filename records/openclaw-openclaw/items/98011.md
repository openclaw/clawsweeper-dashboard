## Summary

Close: current main and v2026.6.11 route isolated cron announce delivery through durable outbound delivery instead of `message.action`, so plugins that implement `outbound.sendText` are no longer blocked by missing action handlers.

## What This Changes

The issue asks for isolated cron `delivery.mode=announce` to deliver WeChat output via the outbound send contract instead of failing through `message.action=send`.

## Best Possible Solution

Keep the shipped durable outbound cron delivery path, and ask for a fresh issue with redacted current-release logs if WeChat announce delivery still fails after v2026.6.11.
