## Summary

Keep open: current main and latest stable release still define the three Feishu bitable write-tool map values with `Type.Any()`, which TypeBox serializes as an empty `patternProperties` sub-schema. Open linked PRs are candidate fixes, so the issue should close only after one canonical repair lands.

## What This Changes

Fix Feishu bitable write-tool JSON Schemas so strict Anthropic-through-Bedrock validation no longer rejects the whole tool list.

## Best Possible Solution

Land one Feishu-local non-empty JSON-value schema repair with registered-tool regression coverage, then close this issue from the merged PR and close duplicate sibling PRs as superseded.

## Reproduction Assessment

I did not run a live Bedrock-backed Anthropic request in this read-only review.
