## Summary

Keep open: current main and the latest release still ship the bundled summarize skill with a single Homebrew installer that points at a deleted upstream formula, and the remaining repair needs a maintainer decision about installer source, platform support, or de-bundling.

## What This Changes

The issue asks OpenClaw to make the bundled summarize skill installable or explicitly unsupported on Linux/Docker and to show clear feedback when enable/install cannot satisfy its binary requirement.

## Best Possible Solution

Make the bundled summarize entry truthful by using a verified maintained installer, explicit platform gating, or removal/de-bundling, with matching Skills UI/status feedback and regression coverage.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 still require the `summarize` binary and list only the deleted `steipete/tap/summarize` installer. I did not live-run the Docker Control UI toggle path in this read-only review.

## Solution Assessment

No final fix shape is proven yet. A speculative installer swap would not be the best fix until maintainers choose whether summarize remains bundled, becomes platform-gated, moves out of core, or uses a verified maintained installer.
