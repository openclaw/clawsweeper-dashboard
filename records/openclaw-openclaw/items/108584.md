## Summary

The patch appears correct and has strong live Discord proof, but this PR must remain open for explicit maintainer review because it carries the protected `maintainer` label, overlaps an alternative open implementation, and intentionally extends strict preflight target resolution across plugin-backed agent delivery.

## What This Changes

The PR resolves agent-delivery targets through the shared outbound resolver before model execution, persists canonical destinations for recovery, preserves best-effort session-only fallback, and tightens Discord ID detection and fallback resolution.

## Best Possible Solution

Use one shared pre-run resolver that produces a canonical target for execution, final delivery, and recovery; retain normalized fallback only for plugins without authoritative resolution, preserve explicit best-effort session-only behavior, and land one canonical implementation with focused fresh-install and upgrade-compatibility coverage.
