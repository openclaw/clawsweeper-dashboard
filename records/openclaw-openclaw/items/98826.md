## Summary

## What This Changes

The PR widens provider replay helpers to accept non-array tool-result content and updates provider/media callers and tests to preserve string, object, and single-image tool results.

## Best Possible Solution

Normalize non-array tool-result content at the session/transcript boundary or before transformMessages image downgrade, keep provider replay contracts array-shaped where possible, and add focused text-only provider replay proof.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: replay a text-only model context with a raw string toolResult content value, and transformMessages can turn it into one-character blocks before provider conversion.

## Solution Assessment

No. Provider-boundary normalization is useful but not sufficient because the pre-provider transform path can corrupt raw string tool results first; the safer fix is to normalize loaded/session toolResult content before provider replay.
