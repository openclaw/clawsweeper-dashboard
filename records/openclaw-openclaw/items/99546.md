## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Bound assistant dedupe to the matched reply:** `extensions/telegram/src/bot-handlers.runtime.ts:207-208`
  - body: Returning only stripped text for every assistant row means any cache assistant message with the same visible text filters every session assistant row with that text, regardless of timestamp or whether a directive tag changed. In a DM where an older assistant reply repeats `ok` but only a newer cache row is in the cache window, the older session row can disappear from model-visible context; keep exact timestamp/body for ordinary rows and add a bounded directive-tag/near-time assistant-cache match instead.
  - confidence: 0.9
- **[P2] Declare the transcript role field:** `extensions/telegram/src/session-transcript-context.ts:32`
  - body: `TelegramSessionTranscriptPromptMessage` still declares only the old prompt row fields, but this return now adds `role`. CI is already failing with TS2353 here, and the dedupe code depends on this value being part of the helper contract; add the role field to the type or avoid depending on an undeclared property.
  - confidence: 0.94
