## Summary

This PR should remain open but cannot merge as written: the new item-ID equality guard reverses the existing regression contract for providers that emit cumulative snapshots as separate message items with different IDs, so it would restore duplicated replies and transcript state. The current tests explicitly model that cross-ID wire shape. ([codefactor.io](https://www.codefactor.io/repository/github/openclaw/openclaw/source/main/src/agents/openai-transport-stream.test.ts?utm_source=openai))

## What This Changes

The PR passes message item IDs into both Responses stream consumers and prevents prefix-based snapshot collapse when consecutive IDs differ.

## Best Possible Solution

Preserve cross-ID cumulative collapse and derive a stronger discriminator from a captured provider stream or replay fixture that separates genuine sequential messages without reintroducing duplicated replies; cover streaming, completed-response backfill, and both consumers, then demonstrate the result through a redacted real agent run.
