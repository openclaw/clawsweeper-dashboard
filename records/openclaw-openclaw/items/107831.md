## Summary

This PR addresses a plausible message-boundary bug, but the proposed identity guard conflicts with the existing cumulative-snapshot contract: current regression fixtures intentionally use different item IDs for successive snapshots. As written, the patch can restore the severe duplicated-reply and transcript corruption fixed by the earlier collapse work, so it needs redesign and real stream proof before merge.

## What This Changes

The PR adds item-ID comparison to OpenAI Responses message snapshot collapse, passes IDs through both stream consumers, and changes tests to distinguish same-ID snapshots from different-ID messages.

## Best Possible Solution
