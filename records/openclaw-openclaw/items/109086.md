## Summary

Current main still hardcodes both values, so the linked bug remains real and this PR is still necessary; however, the patch adds recurring inventory RPCs on the Simple settings page and provides only mocked/source proof, so it is not ready to merge as submitted.

## What This Changes

The PR polls `cron.list` and `skills.status` from the Config page, passes nullable Cron and Skills counts into Quick Settings, adds an unavailable state, and updates UI tests and English i18n metadata.

## Best Possible Solution

Load the inventory snapshot on entry or reconnect, refresh Cron through its existing change signal and Skills only after known skill mutations or explicit refresh, then demonstrate non-zero, loading/offline, and unavailable states in a connected Control UI.
