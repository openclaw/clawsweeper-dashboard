## Summary

Keep open. Current main and the latest release still render native mobile chat bubble bodies without a bounded per-bubble scroll container, and the related WebChat full-message reader fix is adjacent browser/Gateway work rather than this native bubble interaction.

## What This Changes

The issue requests consistent inner scrolling for large native chat bubbles, even when content has not crossed a truncation threshold.

## Best Possible Solution

Define the current native tall-bubble rule, then implement one bounded body-reading behavior for completed and streaming bubbles across SwiftUI and Android while preserving transcript scrolling, text selection, accessibility, and streaming layout.

## Reproduction Assessment

No high-confidence live reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the old `.large` terminology and mobile gesture behavior still need device-level confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should choose the current iOS/Android interaction model because nested scrolling can affect transcript scroll, selection, accessibility, and streaming layout.
