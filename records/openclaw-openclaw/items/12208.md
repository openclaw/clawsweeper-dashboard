## What This Changes

Request all native chat bubbles classified as large to use a bounded, scrollable body even when content does not cross the truncation threshold.

## Best Possible Solution

Adopt one cross-platform long-message interaction contract—preferably an explicit full-message reader or carefully bounded body that preserves transcript gestures—and validate completed, streaming, attachment-heavy, and tool-output messages on iOS and Android.
