## Summary

Keep open. Current main still has transcript/list scrolling and reader-managed Jump to latest behavior, but completed and streaming native bubble bodies remain plain SwiftUI/Compose stacks without the requested bounded per-bubble body scroll area.

## What This Changes

Requests that native large or tall chat bubble bodies become scrollable even when they do not hit the current truncation threshold.

## Best Possible Solution

Define a cross-native tall-bubble body-reader rule, then implement bounded body reading or an explicit reader affordance for completed and streaming bubbles across SwiftUI and Android with live device or emulator proof.
