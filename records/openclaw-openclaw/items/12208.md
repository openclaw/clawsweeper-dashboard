## Summary

Keep open. Current main still has transcript/list-level scrolling and Jump to latest behavior, but completed and streaming native bubble bodies remain plain SwiftUI/Compose content without the requested bounded per-bubble body scroll area.

## What This Changes

The issue requests always enabling scrollable body content for large native chat bubbles instead of only when truncation triggers.

## Best Possible Solution

Define a cross-native tall-bubble body-reader rule, then implement bounded body reading or an explicit reader affordance for completed and streaming bubbles across SwiftUI and Android with live device or emulator proof.
