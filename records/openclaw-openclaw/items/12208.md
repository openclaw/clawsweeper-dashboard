## Summary

Keep open. Current main and the latest release still provide transcript/list-level scrolling, but completed and streaming native bubble bodies remain plain SwiftUI/Compose stacks without the requested bounded per-bubble body scroll behavior.

## What This Changes

The issue requests always-scrollable body content for large native chat bubbles instead of enabling inner scrolling only after truncation.

## Best Possible Solution

Define a cross-native tall-bubble body-reader rule, then implement bounded body scrolling or an explicit reader affordance for completed and streaming bubbles across SwiftUI and Android with live native proof.
