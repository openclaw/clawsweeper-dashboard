## Summary

Keep open. Current main and the latest release still only provide transcript/list scrolling; completed and streaming native bubble bodies remain plain SwiftUI/Compose stacks without the requested bounded per-bubble body scroll area, and the merged reader-managed scrolling work is adjacent rather than a fix.

## What This Changes

The issue requests that every native `.large` chat bubble body use an inner scroll view, even when the content has not crossed a truncation threshold.

## Best Possible Solution

Define a cross-native tall-bubble body-reader rule, then implement bounded body reading or an explicit reader affordance for completed and streaming bubbles across SwiftUI and Android with live device or emulator proof.
