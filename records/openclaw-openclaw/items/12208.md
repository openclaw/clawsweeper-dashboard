## Summary

Keep open. Current main and the latest release still render native mobile chat bubble bodies as plain SwiftUI/Compose content with transcript-level scrolling only; the merged WebChat full-message reader is adjacent browser/Gateway work, not the requested native mobile bubble interaction.

## What This Changes

The issue requests that every native large chat bubble wrap its body in a scrollable area, even when the content has not crossed the truncation threshold.

## Best Possible Solution

Define the current native tall-bubble reader interaction, then implement one bounded body-scrolling behavior for completed and streaming bubbles across SwiftUI and Android while preserving transcript scrolling, selection, and accessibility.

## Reproduction Assessment

No high-confidence live reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the mobile gesture behavior needs device-level confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should first choose the current iOS/Android tall-bubble interaction because nested scroll can affect transcript scroll, selection, accessibility, and streaming layout.
