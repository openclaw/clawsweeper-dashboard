## Summary

Keep open for a maintainer product decision. Current native chat has reader-managed transcript scrolling, but neither the merged reader-scroll work nor the prior current-main review establishes a bounded, independently scrollable body for every large bubble; that is a distinct interaction model rather than a confirmed bug fix.

## What This Changes

The issue requests a consistent inner scroll container for every large native chat bubble, including content that is tall but not truncated.

## Best Possible Solution

Choose one native long-content interaction model, then either retain reader-managed transcript scrolling or implement a shared, bounded per-bubble reader with iOS/Android parity and live device proof for tall, streaming, and accessibility cases.
