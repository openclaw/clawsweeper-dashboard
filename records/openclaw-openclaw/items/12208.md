## Summary

Keep open: current main still lacks bounded per-bubble body scrolling in native chat, while the merged reader-managed scrolling work only changes transcript/list behavior.

## What This Changes

The issue requests always-on scrollable body content for native large/tall chat bubbles instead of only when truncation detection fires.

## Best Possible Solution

Define a cross-native tall-bubble body-reader rule, then implement the chosen bounded body scrolling or full-reader affordance across SwiftUI and Android while preserving transcript-level scrolling.
