## Summary

Keep open. Current main and the latest release still lack a bounded inner body scroll path for native mobile chat bubbles; the related WebChat full-message reader is useful adjacent work, but it explicitly did not change inline bubble size policy or native mobile rendering.

## What This Changes

The issue requests that large chat bubbles use a scrollable body area even when content has not crossed the truncation threshold.

## Best Possible Solution

Define the current native tall-bubble reader interaction, then implement one bounded body-reading behavior for completed and streaming bubbles across SwiftUI and Android while preserving transcript scrolling and accessibility.

## Reproduction Assessment

No high-confidence live reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the mobile gesture behavior needs device-level confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should first choose the current iOS/Android tall-bubble interaction because nested scroll can affect transcript scroll, selection, accessibility, and streaming layout.
