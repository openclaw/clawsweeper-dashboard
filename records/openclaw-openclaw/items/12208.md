## Summary

Keep open. Current main and the latest release still lack an inner scroll container for native mobile chat bubble bodies; the closed WebChat full-message reader is adjacent browser/Gateway work and explicitly did not change inline chat bubble size policy.

## What This Changes

The issue requests making every large native chat bubble body independently scrollable, even when content has not crossed a truncation threshold.

## Best Possible Solution

Define one native tall-bubble reader interaction, then implement a bounded body-reading behavior for completed and streaming bubbles across SwiftUI and Android while preserving transcript scrolling and accessibility.

## Reproduction Assessment

No high-confidence live reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the mobile gesture behavior needs device or simulator confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should first choose the current iOS/Android tall-bubble interaction because nested scroll can affect transcript scroll, selection, accessibility, and streaming layout.
