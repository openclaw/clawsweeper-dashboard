## Summary

Keep open. Current main still lacks a bounded inner scroll container for native mobile chat bubble bodies, and the merged WebChat full-message reader is adjacent browser/Gateway work rather than the requested native `.large` bubble interaction.

## What This Changes

Request that native large chat bubbles always wrap their body content in a bounded scroll view instead of only scrolling when truncation triggers.

## Best Possible Solution

Define the current native tall-bubble reader interaction, then implement one bounded body-reading behavior for completed and streaming bubbles across SwiftUI and Android while preserving transcript scrolling, text selection, and accessibility.

## Reproduction Assessment

No high-confidence live reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the mobile gesture behavior still needs iPhone/Android confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should first choose the current iOS/Android tall-bubble interaction because nested scroll can affect transcript scroll, selection, accessibility, and streaming layout.
