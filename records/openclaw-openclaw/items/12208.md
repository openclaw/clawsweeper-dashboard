## Summary

Keep open. Current main still renders the native SwiftUI and Android chat bubble bodies as plain vertical stacks/columns with scrolling owned by the transcript, while the related WebChat reader work is a closed adjacent web-surface fix rather than this native mobile interaction.

## What This Changes

Request that all large native chat bubbles wrap their body content in a bounded scroll view even when the content is not truncated.

## Best Possible Solution

Define the current native tall-bubble rule, then implement one bounded body-reading behavior for completed and streaming bubbles across SwiftUI and Android with device-level proof and focused render or interaction coverage.

No high-confidence live reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the old .large terminology and mobile gesture behavior still need device-level confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should choose the current iOS/Android tall-bubble rule and nested-scroll interaction before implementation.
