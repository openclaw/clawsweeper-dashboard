## Summary

Keep open for product review. Current-main evidence still shows transcript-level scrolling without a bounded scroll or reader inside native message bodies, and the related WebChat reader work explicitly leaves native inline-bubble policy unchanged.

## What This Changes

Make every large native chat bubble body scrollable, even when its content remains below the truncation threshold.

## Best Possible Solution

Define one cross-platform native long-message interaction—preferably a bounded preview with an explicit full-message reader—while preserving transcript scrolling, accessibility, streaming behavior, attachments, and tool-result rendering; use unconditional nested scrolling only if device proof shows it is the better interaction.

Kind: product_direction

Question: Should large native message bodies use nested scrolling, or should iOS and Android adopt an explicit full-message reader similar to the WebChat direction?

Rationale: Both approaches address tall messages, but they have materially different gesture, accessibility, discoverability, and cross-platform behavior that source inspection cannot resolve.

Likely owner: steipete

Owner reason: Already provided the product-facing review on this issue and has relevant native release history.

Owner confidence: high

Options:

- **Add a full-message reader (recommended):** Keep transcript scrolling primary and give tall or truncated native messages a clear action that opens their complete content in a dedicated bounded surface.
- **Use nested body scrolling:** Make every large native bubble body independently scrollable and validate gesture handoff, accessibility, streaming, attachments, and tool results on both platforms.

## Reproduction Assessment

No live high-confidence reproduction is available. Source-level inspection supports the absence of per-bubble scrolling, but current iPhone and Android recordings are still needed to characterize the actual interaction problem.

## Solution Assessment

No, unconditional nested scrolling is not yet established as the best solution. A dedicated full-message reader better preserves the transcript interaction model unless device testing demonstrates that nested scrolling is clearer and accessible.
