## Summary

Keep open. Current main and the latest release still render native iOS/Android chat bubble content as plain layout under transcript-level scrolling; the closed WebChat full-message reader is adjacent work, and this native mobile interaction still needs maintainer UX direction and live repro before implementation.

## What This Changes

Request all native large chat bubbles to use an inner scrollable body even when content has not crossed a truncation threshold.

## Best Possible Solution

Define the current tall-bubble rule, then implement one bounded body-reader or inner-scroll behavior for completed and streaming native bubbles on SwiftUI and Android while preserving transcript scroll, selection, and accessibility.

## Reproduction Assessment

No high-confidence live device reproduction was established. Source inspection on current main shows native bubble bodies lack bounded inner scroll containers, but the mobile gesture behavior needs device-level confirmation.

## Solution Assessment

Unclear as specified. Always-on inner scrolling is plausible, but maintainers should first choose the current iOS/Android tall-bubble interaction because nested scroll can affect transcript scroll, selection, accessibility, and streaming layout.
