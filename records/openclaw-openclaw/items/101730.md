## What This Changes

This PR updates the MCP loopback HTTP server to treat id-less JSON-RPC messages as notifications, suppress their response bodies, fast-path notification-only pre-resolution methods, and add focused regression coverage.

## Best Possible Solution

Land the spec-aligned notification suppression after Gateway/MCP owner acceptance, preserving id-bearing request responses and tools/call notification side effects.
