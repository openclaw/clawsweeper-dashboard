## What This Changes

The PR adds a Gateway MCP loopback notification check that suppresses JSON-RPC responses for valid messages without an `id` and adds a regression test expecting `202` with an empty body for a no-id `tools/list` notification.

## Best Possible Solution

Land the narrow HTTP aggregation fix after live loopback proof shows a no-id notification returns `202` with an empty body and maintainers accept that id-less calls no longer behave as requests.
