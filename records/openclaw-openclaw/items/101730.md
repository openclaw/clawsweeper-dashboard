## What This Changes

The PR changes the MCP loopback HTTP server to treat id-less JSON-RPC messages as notifications, return 202 empty bodies for notification-only `tools/list` and lifecycle notifications, suppress normal responses for other notifications, and add regression tests.

## Best Possible Solution

Finish the notification response contract across normal and internal-error paths, keep `tools/call` notifications dispatching, and have a Gateway/MCP owner accept the 202 empty-body compatibility change before merge.
