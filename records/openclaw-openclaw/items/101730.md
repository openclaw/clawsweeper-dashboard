The branch updates the Gateway MCP loopback HTTP POST handler and regression tests so id-less JSON-RPC notifications do not produce response bodies while id-bearing requests and tools/call side effects remain handled.

## Best Possible Solution

Land the spec-aligned notification suppression after Gateway/MCP owner acceptance, while preserving id-bearing request responses, malformed-entry errors, and tools/call notification side effects.
