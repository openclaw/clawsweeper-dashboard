## What This Changes

Updates spawned-agent tool inheritance so a parent configured only with additive `tools.alsoAllow` entries does not impose a concrete inherited allowlist on the child.

## System Context

Agent tool policy turns configured allow and deny rules into the tool surface exposed to an agent. When that agent spawns a child session, the inheritance layer carries only genuine parent restrictions forward so target-agent-specific authorized tools can still be resolved.
