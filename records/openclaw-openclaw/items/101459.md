## What This Changes

The issue asks OpenClaw to avoid sending a `system` role in `openai-responses` input for configured reasoning models that are routed through strict OpenAI-compatible relays.

## Best Possible Solution

Settle one default-preserving Responses compatibility path, likely the open opt-in instructions-placement approach or an equivalent existing-compat-key route, with coverage for both the package provider and legacy agent transport.
