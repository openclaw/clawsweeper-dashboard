## What This Changes

The issue reports that `openai-responses` sends a strict relay an unsupported system-prompt role/placement for reasoning models, causing 400 responses from OpenAI-compatible Responses gateways.

## Best Possible Solution

Settle one default-preserving Responses compatibility path, then land or replace PR #92147 with coverage for both the new strict relay mode and the existing default behavior.
