## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.94

Full review comments:

- **[P1] Reject private OpenClaw imports before package allowlists:** `src/plugins/import-policy.ts:371-372`
  - body: The private-path guard still runs after `allowedPackages.has(barePackage)`, so a plugin can declare `openclaw` in its package manifest and import `openclaw/runtime` while passing the new policy. That defeats the exact boundary this PR is adding.
  - confidence: 0.98
- **[P1] Block nonliteral module specifiers before execution:** `src/plugins/import-policy.ts:256-279`
  - body: The policy only collects literal specifiers with regexes, then the loader executes the plugin module. Computed calls such as `require("openclaw/" + "runtime")` or `import(getSpecifier())` are not denied before execution, so this is not a reliable security boundary.
  - confidence: 0.96
- **[P1] Validate plugin-local dependency entrypoints before execution:** `src/plugins/import-policy.ts:439-455`
  - body: Declared bare imports are allowed and then skipped without resolving or checking the dependency code. A plugin-local dependency can import private OpenClaw internals or escape its own files before the policy ever inspects that module graph.
  - confidence: 0.95
- **[P1] Reject traversal inside bare specifiers before allowlists:** `src/plugins/import-policy.ts:355-359`
  - body: The raw `openclaw/plugin-sdk/` prefix and package-name allowlist accept specifiers before rejecting `.` or `..` path segments. Requests like `openclaw/plugin-sdk/../../runtime` or `left-pad/../other-package` can reach resolution paths outside the intended allowed package subpath.
  - confidence: 0.9
- **[P1] Normalize overlay forwards before allowing them:** `src/plugins/import-policy.ts:389-396`
  - body: The runtime-overlay exception returns allowed for any specifier starting with `../../../dist/`, before resolving the rest of the path against the canonical dist root. A suffix containing more traversal can escape the intended overlay target while bypassing the later containment checks.
  - confidence: 0.93
- **[P2] Preserve Node-compatible local directory resolution:** `src/plugins/import-policy.ts:318-324`
  - body: Local resolution only tries direct files and `index.*` fallbacks. Valid plugin code that imports a local directory whose entrypoint is defined by its package metadata can be rejected as unresolved even though the normal plugin runtime can load it.
  - confidence: 0.84
