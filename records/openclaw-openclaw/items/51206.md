## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Reject private OpenClaw imports before allowlists:** `src/plugins/import-policy.ts:371-376`
  - body: `allowedPackages.has(barePackage)` runs before the private `openclaw/*` rejection, so a plugin can declare `openclaw` and then import `openclaw/runtime` while passing the policy. Move the private OpenClaw guard ahead of package allowlists and add a regression test.
  - confidence: 0.96
- **[P1] Reject computed specifiers or enforce at runtime:** `src/plugins/import-policy.ts:256-279`
  - body: The policy only collects string-literal imports with regexes, so computed `require()` or `import()` specifiers can reach module execution without validation. Either reject non-literal module specifiers with a real parser or enforce the boundary during resolution/runtime.
  - confidence: 0.92
- **[P1] Validate plugin-local dependency entrypoints:** `src/plugins/import-policy.ts:439-455`
  - body: Declared bare packages are allowed and then skipped, so a plugin-local dependency under `node_modules` can import private OpenClaw internals or escape the plugin root without being scanned before execution.
  - confidence: 0.91
- **[P1] Add an upgrade-safe enforcement path:** `src/plugins/loader.ts:1154-1160`
  - body: This turns any policy violation into an immediate plugin load error, while the PR body acknowledges existing plugins may rely on those imports. Add a staged/warn-only/default-compatible path or explicit maintainer-approved migration proof before hard-failing upgrades.
  - confidence: 0.88
- **[P2] Resolve package.json directory entries:** `src/plugins/import-policy.ts:318-324`
  - body: Node resolves `require("./dir")` through `dir/package.json` `main` or `exports`, but this resolver only tries direct files and `index.*`, so valid in-package imports can be rejected as unresolved policy violations.
  - confidence: 0.82
- **[P2] Resolve overlay imports before allowing them:** `src/plugins/import-policy.ts:389-396`
  - body: The runtime-overlay special case allows any raw specifier beginning with `../../../dist/` before normalizing the rest of the path, so traversal after that prefix can escape the intended canonical dist root. Resolve the final path and check it against the canonical dist root before allowing it.
  - confidence: 0.84
