## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Reject private OpenClaw imports before dependency allowlists:** `src/plugins/import-policy.ts:371-372`
  - body: A plugin can declare `openclaw` in its package manifest, making `allowedPackages.has("openclaw")` return early before the private `openclaw/*` guard runs. That allows the exact private imports this boundary is meant to reject, so the guard needs to run before package/self allowlists and have regression coverage.
  - confidence: 0.95
- **[P1] Block nonliteral module specifiers before execution:** `src/plugins/import-policy.ts:273-274`
  - body: The policy only scans literal regex matches like `require("...")` and `import("...")`. Computed values such as `require(["..", "outside.cjs"].join("/"))` are not reported and then execute through the normal plugin loader, bypassing root and private-import checks.
  - confidence: 0.9
- **[P1] Validate plugin-local dependency entrypoints before execution:** `src/plugins/import-policy.ts:455`
  - body: After a bare specifier is allowed, validation continues without resolving or scanning the dependency code. A plugin can declare a local package whose entrypoint imports private OpenClaw modules or escapes the root, and that code will run when the plugin is loaded.
  - confidence: 0.88
- **[P1] Constrain the runtime overlay allowlist by resolved path:** `src/plugins/import-policy.ts:75`
  - body: The overlay exception accepts any specifier starting with `../../../dist/` and returns before the normalized target is checked. A path with traversal after that prefix can widen the exception beyond the intended canonical dist root.
  - confidence: 0.84
- **[P2] Preserve Node-compatible local directory resolution:** `src/plugins/import-policy.ts:318-324`
  - body: Local resolution only tries files and index fallbacks, but Node also resolves `require("./dir")` through `dir/package.json` main/exports. Valid in-package imports using that pattern will be rejected as unresolved, creating avoidable plugin compatibility breaks.
  - confidence: 0.82
