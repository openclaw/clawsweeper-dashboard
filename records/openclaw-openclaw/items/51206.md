## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Reject private OpenClaw imports before dependency allowlists:** `src/plugins/import-policy.ts:371-372`
  - body: The private `openclaw/*` guard runs after the package-name and dependency allowlists. A plugin can declare `openclaw` in its package metadata and then import `openclaw/runtime`, which defeats the boundary this PR is adding.
  - confidence: 0.98
- **[P1] Enforce non-literal imports at runtime or with a parser:** `src/plugins/import-policy.ts:256-279`
  - body: The scanner only records literal specifiers matched by regexes, so `require("openclaw/" + "runtime")` or `import(getSpecifier())` is not checked before the plugin is executed. A security boundary should either reject computed specifiers or enforce resolution at runtime.
  - confidence: 0.93
- **[P1] Validate plugin-local dependency entrypoints before execution:** `src/plugins/import-policy.ts:440-455`
  - body: Allowed bare package imports stop at the dependency allowlist and are never resolved or traversed. A plugin can ship a declared local dependency whose entrypoint imports private OpenClaw internals, and that code will execute through the module loader without policy validation.
  - confidence: 0.91
- **[P2] Normalize runtime-overlay forwards before allowing them:** `src/plugins/import-policy.ts:389-396`
  - body: The runtime-overlay exception returns success based only on the raw `../../../dist/` prefix. A specifier with traversal after that prefix can skip the normal root checks, so the allowlist should be based on the normalized resolved path inside the canonical dist root.
  - confidence: 0.86
- **[P3] Remove the release-owned changelog entry:** `CHANGELOG.md:55`
  - body: Normal PRs should keep release-note context in the PR body or squash message; `CHANGELOG.md` is generated during release work. Leaving this entry in the branch creates release-owned churn unrelated to the code review.
  - confidence: 0.9

## Security Review
