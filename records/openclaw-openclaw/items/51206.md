- **[P1] Reject private OpenClaw imports before package allowlists:** `src/plugins/import-policy.ts:371-375`
  - body: This prior blocker is still present at the same head: a plugin that declares `openclaw` as a dependency reaches the `allowedPackages` return before the private `openclaw/*` rejection, so `openclaw/runtime` is allowed despite the policy's stated goal.
  - confidence: 0.96
- **[P1] Block nonliteral module specifiers before execution:** `src/plugins/import-policy.ts:256-279`
  - body: The scanner only records literal specifiers matched by regex, but the loader executes the plugin after validation. Computed `require()` or dynamic `import()` values can still load private OpenClaw paths or root escapes without any violation.
  - confidence: 0.93
- **[P1] Validate plugin-local dependency entrypoints before execution:** `src/plugins/import-policy.ts:439-455`
  - body: After a declared bare specifier passes validation, the code continues without resolving or scanning the dependency entrypoint. A plugin-local dependency can therefore import private OpenClaw internals before the loader sees it.
  - confidence: 0.92
- **[P1] Reject traversal inside bare specifiers before allowlists:** `src/plugins/import-policy.ts:355-359`
  - body: The allowlist accepts `openclaw/plugin-sdk/` and declared-package subpaths before rejecting normalized traversal segments, so requests like SDK or dependency subpaths containing `..` can escape the intended package prefix under Node-style resolution.
  - confidence: 0.88
- **[P1] Normalize overlay forwards before allowing them:** `src/plugins/import-policy.ts:63-75`
  - body: The dist-runtime overlay exception returns true from a raw `../../../dist/` prefix check, and `classifyLocalSpecifierViolation` then skips the boundary checks. A suffix with additional traversal can widen the allowlist beyond the canonical dist root.
  - confidence: 0.9
- **[P2] Preserve Node-compatible local directory resolution:** `src/plugins/import-policy.ts:303-326`
  - body: Local resolution checks files and `index.*`, but not a directory package.json `main` or exports entry. Valid in-plugin imports that Node can load through `require("./dir")` can be rejected as unresolved, which is a compatibility break for plugin authors.
  - confidence: 0.84
