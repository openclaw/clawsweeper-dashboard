Full review comments:

- **[P1] Reject private OpenClaw imports before dependency allowlists:** `src/plugins/import-policy.ts:371-375`
  - body: `validateBareSpecifier` returns success for any declared package before it checks for private `openclaw/*` paths. A plugin can declare `openclaw` as a dependency and import `openclaw/runtime`, bypassing the boundary this PR is trying to enforce.
  - confidence: 0.96
- **[P1] Block nonliteral module specifiers before execution:** `src/plugins/import-policy.ts:256-279`
  - body: The scanner only matches literal specifiers with regexes, so computed calls like `require("openclaw/" + "runtime")` or `import(getSpecifier())` are invisible to the policy and still reach module execution.
  - confidence: 0.9
- **[P1] Validate plugin-local dependency code before execution:** `src/plugins/import-policy.ts:439-455`
  - body: Allowed bare imports are checked and then skipped with `continue`, so a declared package under the plugin root can import private OpenClaw modules or escape paths without being scanned by this policy.
  - confidence: 0.88
- **[P1] Normalize overlay forwards before allowing them:** `src/plugins/import-policy.ts:390-396`
  - body: The runtime-overlay special case allows raw `../../../dist/` prefixes before resolving and checking the final path. A traversal segment after that prefix can skip the normal inside-root checks.
  - confidence: 0.84
- **[P2] Preserve Node directory package resolution:** `src/plugins/import-policy.ts:318-324`
  - body: Local path resolution only tries direct files and `index.*`, but Node also resolves `require("./dir")` through `dir/package.json` `main` or `exports`. Valid in-package imports using that standard pattern would fail policy validation before runtime.
  - confidence: 0.84
- **[P1] Add rollout proof before hard-failing plugin loads:** `src/plugins/loader.ts:1150-1160`
  - body: This turns import-policy violations into unconditional plugin load failures, but the PR body says real third-party plugins were not verified and migration may be needed. Maintainers need upgrade proof before landing a fail-closed loader change.
  - confidence: 0.86
- **[P3] Drop the release-owned changelog edit:** `CHANGELOG.md:55`
  - body: OpenClaw release generation owns `CHANGELOG.md` for normal PRs. Keep this release-note context in the PR body or squash message instead of landing a changelog line from this branch.
  - confidence: 0.91
