## What This Changes

Adds a hidden `openclaw backup capture-final` command that validates host-supplied closed-writer evidence, captures global and selected-agent SQLite recovery points, and journals an exact replayable result.

## System Context

The backup command receives a host-fenced recovery request and coordinates existing SQLite snapshot inputs into one final recovery point. Its result is persisted in an operation-scoped recovery journal for the following restore/admission flow to consume.
