## What This Changes

Improve recovery from a model authentication failure by showing actionable diagnostics, handling configured fallback appropriately, and avoiding repeated failure from a pinned session model.

## System Context

Embedded agent runs select a session or configured model, call the provider, and route failures through failover and terminal-resolution code before sending a user-visible response. Authentication failures also interact with persisted session model selection and the Doctor/setup surfaces that help users recover provider configuration.

## Best Possible Solution

Preserve explicit configured fallback chains, surface a safe provider/model-specific authentication recovery message on every terminal path, and require a maintainer-approved policy before resetting persisted session model selection or probing provider authentication in Doctor.

Options:

- **Add opt-in recovery policy:** Offer an explicit configuration or UI choice for automatic fallback/reset while preserving current session-pinning behavior by default.
