The PR replaces locale-sensitive sandbox stat parsing with a missing-path sentinel and raw mode, size, and nanosecond mtime metadata in the local and remote sandbox filesystem bridges.

## Best Possible Solution

Keep the sentinel and raw-mode design, but implement metadata collection using an already-supported sandbox dependency or explicitly establish and validate the Python runtime contract across both bridge backends; then add a redacted live non-English-locale transcript that shows a missing path returns `null`.
