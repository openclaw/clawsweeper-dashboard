## Summary

This PR addresses the localized-error root cause, but its switch from `%y` to GNU `stat` `%Y` regresses `mtimeMs` from millisecond precision to whole seconds. The supplied current-head evidence is a focused automated E2E run, not a live localized-shell demonstration, so real behavior proof is still needed before merge.

## What This Changes

The branch replaces locale-sensitive sandbox `stat` parsing with a missing-path sentinel and raw GNU mode, size, and timestamp fields in local and remote filesystem bridges.

## Best Possible Solution

Keep the sentinel and raw mode-bit approach, restore a locale-independent fractional timestamp representation that preserves the existing millisecond `mtimeMs` contract in both bridges, add regression coverage for sub-second mtimes, and attach a redacted current-head localized-shell transcript showing a missing path returns null.
