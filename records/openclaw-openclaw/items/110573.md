## Summary

Keep this PR open for a focused correction: its locale-independent missing-path handling is useful, but the new `%Y` protocol rounds `mtimeMs` down to whole seconds and can regress callers that use sub-second modification times. The PR replaces locale-sensitive sandbox `stat` parsing with a missing-path sentinel and raw GNU mode, size, and timestamp fields in the local and remote filesystem bridges.

## Best Possible Solution

Keep the sentinel-based missing-path behavior, but use a locale-safe stat representation that preserves sub-second modification time and add focused local/remote regression coverage plus redacted current-head terminal proof for both the locale case and the parent-disappearance race.
