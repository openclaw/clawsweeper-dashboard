## Summary

Keep this PR open for one bounded regression: its locale-independent sentinel design is sound and the contributor now supplies convincing `zh_CN` runtime proof, but an anchored parent directory disappearing before `cd` changes a missing-path `stat()` from `null` to an exception.

## What This Changes

The PR replaces locale-sensitive sandbox `stat` parsing with a fixed missing-path sentinel and raw GNU mode, size, and epoch-time fields in both local and remote filesystem bridges.

## Best Possible Solution

Keep the raw numeric GNU `stat` protocol, but make the anchored command classify an absent canonical parent as the same missing sentinel while preserving permission and tool failures; add a focused regression test for parent removal after anchoring.
