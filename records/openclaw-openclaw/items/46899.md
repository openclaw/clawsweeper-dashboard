## What This Changes

The issue reports that cron jobs configured for Telegram delivery can be routed through Feishu when the configured delivery channel is not preserved.

## Best Possible Solution

Review, refresh, prove, and land the linked parser-boundary fix or a narrow replacement that recovers `{ id }` to the canonical string before cron delivery planning, with regression coverage for the Telegram-to-Feishu misroute path.
