## Summary

Keep open: current main and the latest release still store config backups beside the active config as a numbered `.bak` ring, while the open related work only covers adjacent timestamp suffixes and does not implement the requested dedicated backup directory.

## What This Changes

Request to move OpenClaw config backup files into a dedicated directory and name them with datetimes instead of numeric suffixes.

## Best Possible Solution

Define one canonical config-backup layout, then implement directory placement and collision-safe datetime naming with upgrade-safe legacy handling, recovery selection, audit output, doctor docs, permissions, retention, and focused tests.
