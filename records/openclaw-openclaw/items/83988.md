## What This Changes

Adds a captioned-final-text channel capability and changes ACP and non-ACP final-mode TTS delivery so Telegram defers text into voice captions, preserves media blocks, and recovers text after failed or cancelled voice sends.

## Best Possible Solution

Use one generic caption-support capability and enable it for Telegram only after maintainers accept bundled captions as the default and exact-head live proof shows always mode, tagged directives, media preservation, and reliable text fallback.
