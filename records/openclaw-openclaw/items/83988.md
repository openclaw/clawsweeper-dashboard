## What This Changes

The PR adds a captioned-final-text channel capability and changes ACP and non-ACP final-mode TTS delivery to defer Telegram text, caption voice notes, preserve media, and recover text after failed or cancelled voice delivery.

## Best Possible Solution

Use one generic, documented channel capability enabled only for transports with verified voice-caption support, retain per-payload delivery-outcome recovery on both dispatch paths, and land only with exact-head Telegram proof covering always mode, tagged directives, media preservation, cancellation, and failed-voice text fallback.
