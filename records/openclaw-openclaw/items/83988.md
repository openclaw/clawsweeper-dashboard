The PR adds a `captionedFinalText` channel TTS capability, opts Telegram into it, and changes ACP plus generic final-mode TTS dispatch so caption-capable voice replies can defer visible text and recover fallback text on failures.

## Best Possible Solution

Land this PR only after maintainers accept the new channel capability contract and current-head Telegram proof covers both always-mode and tagged-mode visible behavior.
