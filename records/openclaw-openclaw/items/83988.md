## Summary

Keep open: the PR targets the right dispatcher layer for #83511, but the ACP direct captioned-final path can still lose suppressed text when the queued voice final is cancelled, and current-head Telegram tagged/fallback proof remains incomplete.

## What This Changes

The PR adds a `captionedFinalText` channel TTS capability, opts Telegram into it, and changes ACP and generic final-mode TTS dispatch to defer or suppress live text so caption-capable voice notes carry the final text.

## Best Possible Solution

Land the capability-gated dispatcher fix only after ACP cancellation recovery is covered, maintainers accept the SDK/Telegram default, and current-head Telegram proof covers always, tagged, media, and fallback paths.
