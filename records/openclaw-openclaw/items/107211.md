## What This Changes

Requests a configurable footer that follows the newest intermediate channel message during an active agent run and disappears when that run terminates.

## Best Possible Solution

Provide one generic active-run status lifecycle that reuses existing progress semantics, decorates only receipt-backed intermediate messages on edit-capable transports, never enters transcripts, reliably restores exact text at termination, and adopts a new default or config key only after maintainers explicitly approve that product surface.
