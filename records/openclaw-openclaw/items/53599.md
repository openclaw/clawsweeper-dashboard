## Summary

Keep open: current main and the latest release still reject the legacy extension driver and migrate old relay config to host-local existing-session, so the cross-machine Chrome extension relay workflow remains missing and needs maintainer product/security direction.

## What This Changes

Requests restoration or replacement of the removed Chrome extension browser relay for cross-machine remote browser control.

## Best Possible Solution

Maintainers should choose a browser-control strategy: either keep the relay retired with a documented remote-browser alternative, or design a vetted Plugin SDK/backend registration path plus an optional relay package with security review and migration tests.
