## Summary

Keep open: current main and v2026.6.11 still reject the legacy extension driver, migrate legacy relay config to `existing-session`, and do not provide the one-click cross-machine Chrome extension relay workflow reported here. Related external relay projects and the open My Browser bridge PR are useful context, but none is a merged replacement for this relay-specific regression.

## What This Changes

The issue requests restoring or replacing the removed cross-machine Chrome extension browser relay for managed remote OpenClaw deployments.

## Best Possible Solution

Keep this issue open until maintainers either land a vetted browser-backend or extension-bridge replacement with migration, docs, tests, and security review, or explicitly decide to keep the legacy relay retired and document supported alternatives.
