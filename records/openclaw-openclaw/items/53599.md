## Summary

Keep open: current main and v2026.6.11 still reject the legacy extension browser driver, migrate old relay config to `existing-session`, and do not provide the one-click cross-machine Chrome extension relay workflow described by the reporter and follow-up users.

## What This Changes

The issue asks OpenClaw to restore or replace the removed Chrome extension browser relay so remote hosts can control a user's local Chrome across machines without local CLI/CDP setup.

## Best Possible Solution

Keep this open until maintainers choose a browser relay strategy: a versioned browser-backend/plugin API with a vetted relay implementation, an explicitly restored first-party relay, or a documented decision to keep the workflow retired.
