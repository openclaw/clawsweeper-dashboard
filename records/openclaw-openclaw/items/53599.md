## Label Justifications

- `P1`: This is a shipped regression blocking remote browser control for managed-hosting and cross-machine users, but the fix requires product and security direction rather than emergency repair.
- `impact:security`: A restored or replacement relay would control authenticated browser sessions across extension, Gateway, node, and network boundaries.

## Summary

Keep open: current main and v2026.6.11 still reject the legacy extension browser driver and route users to host-local Chrome MCP, remote CDP, or node-host paths; the open My Browser bridge work is relevant but not merged and not yet a proven canonical replacement for this managed-hosting relay regression.

## What This Changes

The issue requests restoration or replacement of the removed Chrome extension browser relay so remote OpenClaw hosts can control a user’s browser across machines without local CLI/CDP setup.

## Best Possible Solution

Keep this issue open until maintainers either land a vetted browser-backend or extension-bridge replacement with migration, docs, tests, and security review, or explicitly decide to keep the legacy relay retired and document the supported alternatives.
