## Summary

Keep open: current main and the latest release still reject the legacy Chrome extension relay driver and migrate old relay config to host-local Chrome MCP, while the reported cross-machine one-click extension relay workflow remains unresolved and security-sensitive.

## What This Changes

The issue requests restoring or replacing the removed Chrome extension browser relay for cross-machine managed-hosting browser control.

## Best Possible Solution

Keep this issue open until maintainers either land a vetted browser-backend or extension-bridge replacement with migration, docs, tests, and security review, or explicitly decide to keep the legacy relay retired and document supported alternatives.
