## Summary

Keep open: current main and v2026.6.11 still reject the legacy Chrome extension relay driver and migrate old relay config to `existing-session`; the open browser-backend issue and My Browser PR are related, but not a merged drop-in replacement for the managed-hosting cross-machine relay workflow.

## What This Changes

Request to restore or replace the removed Chrome extension relay so remote OpenClaw instances can control a user's local Chrome across machines without client-side Node or CLI setup.

## Best Possible Solution

Keep this issue open until maintainers either land a vetted browser-backend or extension-bridge replacement with migration, docs, tests, and security review, or explicitly decide to keep the legacy relay retired and document supported alternatives.
