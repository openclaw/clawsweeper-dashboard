## Summary

Keep open: current main and v2026.6.11 still reject the legacy Chrome extension relay driver and migrate it to host-local Chrome MCP existing-session, while the reported one-click cross-machine browser relay workflow remains unavailable and security-sensitive.

## What This Changes

The issue requests restoring or replacing the removed Chrome extension browser relay so remote OpenClaw hosts can control a user's local Chrome without requiring Node, open ports, or manual Chrome flags on the user's machine.

## Best Possible Solution

Maintainers should choose a browser strategy: either keep the legacy relay retired and document the cross-machine limits clearly, or design a vetted browser backend/plugin API and optional Chrome extension relay implementation with security review, tests, docs, and migration behavior.
