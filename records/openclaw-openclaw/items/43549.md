## Best Possible Solution

Add a Telegram-aware status/doctor diagnosis for bad session state, then offer an explicit backup-and-quarantine repair path; make automatic startup quarantine a deliberate maintainer choice rather than implicit runtime fallback.

## Solution Assessment

Unclear until maintainers choose the recovery contract; diagnostics plus explicit backed-up repair looks safer than unconditional auto-delete/quarantine in the runtime load path.
