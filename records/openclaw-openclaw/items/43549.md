## Summary

Keep open: current main and the latest release still swallow malformed or unreadable session-store JSON into an empty store, and Telegram status does not yet surface session-state diagnostics or safe reset guidance. The related generic sessions.json PR overlaps but does not resolve the Telegram-facing recovery UX.

## What This Changes

The issue asks for Telegram status/doctor diagnostics and safer recovery when persisted Telegram-related session JSON is oversized, malformed, unreadable, or otherwise wedging the channel.

## Best Possible Solution

Add shared, read-only session-store health diagnostics that status/doctor and Telegram status can surface, then add backed-up reset or quarantine only after recovery semantics are approved.
