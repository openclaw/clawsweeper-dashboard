Add read-only Telegram/session-store health diagnostics in status and doctor, then provide a guarded backup-and-reset or doctor repair path without silently destroying session continuity.

- **Diagnostic plus explicit repair (recommended):** Status and doctor would report file path, size, parse/schema status, and offer a backed-up reset or doctor repair command that the operator explicitly runs.

- **Automatic quarantine:** Gateway load would move invalid state aside and recreate clean state automatically, accepting the risk of surprising session continuity loss.

## Solution Assessment

Partly: explicit status/doctor detection with a backed-up repair path is the safest direction, while automatic quarantine or reset needs maintainer approval because it changes persisted session continuity behavior.
