## Summary

Keep open: current main and v2026.6.11 still collapse malformed or empty session-store JSON into an empty store and Telegram/channel status does not surface session-file health or a safe reset path; PR #79910 only partially overlaps by targeting generic stale temp-artifact recovery.

## What This Changes

The issue asks for Telegram status/doctor to detect oversized or malformed persisted session JSON and offer a safe backed-up recovery path.

## Best Possible Solution

Add a core session-store health diagnostic surfaced through channel status and doctor, then provide an explicit backed-up repair/reset path; automatic runtime quarantine should wait for maintainer approval.
