## Label Justifications

- `merge-risk: 🚨 message-delivery`: A replacement spool can reclaim and redeliver an event while the original unresolved handler continues running.

## Summary

Keep this PR open for maintainer review: its timeout disposes the LINE ingress claim while the original delivery can still be executing, which conflicts with the existing ownership invariant and can produce concurrent duplicate side effects after reload.

## What This Changes

This PR adds a five-second LINE active-delivery shutdown deadline with recovery tests, plus ingress, Teams, session-visibility, and parser-contract documentation updates.

## Best Possible Solution

Keep exclusive delivery ownership until the active handler has terminated, or first add a core-supported cancellation or fencing contract that prevents an abandoned handler from producing effects after replacement ownership begins.
