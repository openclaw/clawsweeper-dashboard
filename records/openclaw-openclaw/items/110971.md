## Summary

Keep this PR open for human review: the new timeout releases durable-ingress ownership while the original LINE delivery can still produce a reply, recreating the duplicate-side-effect race that the merged adjacent work intentionally avoided. The existing proof is test/CI-only rather than a real after-fix runtime artifact.

## What This Changes

The branch adds a five-second LINE webhook-spool shutdown grace period, a recovery test, and documentation corrections for ingress retention, session visibility, and Teams acknowledgement behavior.

## Best Possible Solution

Keep the claim owner alive until the active handler settles, or first add a core-supported cancellation/acknowledgement contract that proves the old handler cannot emit side effects before reclaiming its row.
