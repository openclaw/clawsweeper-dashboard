Options:

- **Document and preserve public-client PKCE (recommended):** Keep client_secret optional where Google public/native OAuth supports it, but add explicit docs or diagnostics so omission is intentional rather than silent.
- **Fail closed for configured confidential clients:** Require client_secret only when the selected OAuth client type or plugin config declares a confidential/web-client flow, with tests for public-client compatibility.
- **Warn without changing behavior:** Emit a clear setup warning when only client_id is configured, preserving current compatibility while surfacing the tradeoff.
