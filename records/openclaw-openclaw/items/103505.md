## Summary

Current main still keeps approvals in process-local managers with short-lived resolved records and only pending-list replay, so the durable cross-surface lifecycle remains necessary. The issue must stay open because it has the protected `maintainer` label and is paired with an active draft implementation; the main unresolved question is approval of the canonical architecture and compatibility policy.

## What This Changes

Add a gateway-owned durable approval lifecycle with authenticated deep links, atomic cross-surface resolution, typed actions, and ancestor-session visibility.

## Best Possible Solution

Adopt one gateway-owned SQLite approval record and atomic resolution contract, then deliver authenticated deep links, typed portable actions, and channel/ancestor projections as separate focused increments with explicit authorization, compatibility, and real-surface proof.
