## What This Changes

This PR adds exponential backoff, a default ten-attempt cap with full recovery-state cleanup, and same-process follow-up scheduling for deferred pending-final restart recovery.

## Best Possible Solution

Keep the single lifecycle-owned startup recovery path with bounded backoff, canonical cleanup, and same-process deferred wakeups, while making the ten-attempt irreversible retirement policy an explicit maintainer-approved contract.
