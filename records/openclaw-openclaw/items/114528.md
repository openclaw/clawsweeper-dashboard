## What This Changes

This PR passes cron’s optional-terminal-reply contract into embedded agent terminal resolution so a successful tool-only run can finish as intentional silence instead of a failed incomplete turn.

## System Context

Cron schedules isolated agent turns and declares whether a terminal user-facing reply is required. The embedded runner converts the agent’s final tool and assistant state into a reply payload and cron diagnostic outcome, so this change affects whether a completed no-delivery run is reported as silent or erroneous.
