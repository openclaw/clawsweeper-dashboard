## What This Changes

The issue requests that hybrid memory search stop treating a LIKE-based FTS fallback as a perfect text-relevance match when combining keyword and vector scores.

## System Context

Memory Core indexes agent memories in SQLite and retrieves candidates through vector and FTS keyword searches. It merges those relevance signals into the score used to rank context returned to the agent, so fallback-score semantics affect which memories enter an agent run.

## Best Possible Solution

Define and test the fallback-scoring contract in Memory Core, then add a deterministic fixture that forces the MATCH-to-LIKE path and proves the merged ranking cannot advertise a binary substring hit as perfect relevance unless that is explicitly intended.
