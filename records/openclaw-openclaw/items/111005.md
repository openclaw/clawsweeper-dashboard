## Summary

## What This Changes

The PR caps extension source inspection at 10 MiB through `readRegularFileSync` and adds a valid oversized-JavaScript regression test that loads through Jiti.

## Best Possible Solution

Retain the descriptor-level 10 MiB cap, but first define and test the supported symlinked-extension contract; preserve native loading if that behavior is required, otherwise explicitly accept and cover the Jiti fallback.
