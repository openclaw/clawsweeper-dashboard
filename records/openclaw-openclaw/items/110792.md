## Label Justifications

## Summary

Keep this PR open: the targeted regression is real and the no-adapter path preserves a preview that was already finalized, but the new unconditional `isError` branch also skips the existing cleanup when an error final is the first or only final for an active draft. That can leave an incomplete preview post visible alongside the error warning, so the branch needs a narrow state guard before merge.

## What This Changes

The PR sends Mattermost `isError` final payloads through normal delivery without a live-preview adapter so an already-finalized assistant preview is not deleted.

## Best Possible Solution

Preserve the standalone-error path only after `previewState.finalizedViaPreviewPost` is true; otherwise retain the existing adapter cleanup, with regression coverage for both finalized-preview and unfinished-preview error finals.

## Solution Assessment

No: the branch correctly identifies that a finalized preview must survive a later tool warning, but it should key that behavior to the recorded finalization state rather than all error finals.
