## What This Changes

The PR rejects malformed UTF-8 in the ClawHub promotions feed before the decoded payload can be parsed and cached, with a regression test for an invalid response byte.

## System Context

OpenClaw periodically downloads a ClawHub promotions JSON feed, validates it, and stores the raw payload with its HTTP ETag for later revalidation. This change sits at the byte-to-text boundary before JSON parsing, preventing corrupted text from entering the promotions cache and later user-facing promotion output.
