## Summary

Keep this issue open as the canonical regression follow-up: current main and the latest release retain clickable approvals through command-valued buttons, while the open typed-actions stack removes that inference without replacement adapters for these three channels.

## What This Changes

Preserve native one-click approvals for Feishu, Microsoft Teams, and Mattermost when approvals move from slash-command button values to typed private callback envelopes.

## Best Possible Solution

Add plugin-owned approval token encoding, actor authorization, canonical resolver calls, and terminal card/message updates for all three channels before the typed-actions stack ships, while retaining the manual command only as fallback.
