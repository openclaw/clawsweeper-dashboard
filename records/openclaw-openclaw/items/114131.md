## What This Changes

This PR gives Browser actions, node invocation, and Gateway RPC separate bounded timeout budgets, and carries each Browser tool invocation’s abort signal into its remote node-proxy request.

## System Context

The Browser plugin routes a Browser tool action either to local host control or through a selected remote Browser node via Gateway RPC. This change adjusts the timeout and cancellation handoff around that remote-node path so the tool receives the relevant inner failure and cancellation reaches only its own request.
