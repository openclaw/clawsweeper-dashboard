## What This Changes

This PR forwards Telegram configuration into automatic reply delivery and records each successfully delivered reply message ID in the scoped sent-message ledger.

## System Context

Telegram automatic source delivery sends agent replies through the delivery bundle, then downstream reaction filtering and reply routing consult the sent-message ledger to determine whether a message was sent by the bot. This change connects successful delivery results to that existing ledger while preserving the caller's configuration scope.
