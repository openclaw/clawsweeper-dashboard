Full review comments:

- **[P2] Keep task timing separate from activity identity:** `apps/ios/Sources/LiveActivity/LiveActivityManager.swift:237`
  - body: `hydrateCurrentAndPruneDuplicates()` keeps the activity with the maximum `content.state.startedAt`, but `workingState` now sets that same field to `.now` when a task starts. If an older duplicate activity enters a task after a newer identity was created, hydration can keep the stale attributes/session and end the newer activity. Keep a stable activity-created timestamp for pruning and store task elapsed timing separately.
  - confidence: 0.88
- **[P2] Guard HUD cleanup before clearing active tasks:** `apps/ios/Sources/Model/NodeAppModel.swift:1753`
  - body: The camera HUD auto-hide task still calls `handleWorking(task: nil)` after its sleep without checking whether a newer operation now owns the Live Activity. A prior camera success timer can therefore reset the Dynamic Island while screen recording or another task is still running; track the current task/token before clearing.
  - confidence: 0.9
- **[P2] Refresh identity after gateway metadata changes:** `apps/ios/Sources/Model/NodeAppModel.swift:689-695`
  - body: The new `refreshIdentity` call only runs from `setSelectedAgentId`, but `refreshAgentsFromGateway()` can later resolve the default agent name and main session without a selection change. Since the widget renders immutable `context.attributes.agentName`, the lock-screen and Dynamic Island label can remain `Main` or a raw id until reconnect; refresh when gateway metadata changes the resolved identity too.
  - confidence: 0.84
