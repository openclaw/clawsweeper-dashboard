Full review comments:

- **[P1] Move intent consumption into the current root:** `apps/ios/Sources/RootCanvas.swift:200-208`
  - body: `OpenTalkModeIntent.perform()` only writes a UserDefaults flag, but this branch consumes that flag from `RootCanvas`; current main mounts `RootTabs()` and no longer has that root file. Port the cold/warm launch consumer into the current shell when rebasing, or the Action Button/Siri shortcut can set a flag no mounted view consumes.
  - confidence: 0.95
- **[P2] Preserve Live Activity stale filtering:** `apps/ios/Sources/LiveActivity/LiveActivityManager.swift:130-132`
  - body: `hydrateCurrentAndPruneDuplicates()` selects the keeper from every ActivityKit activity by `startedAt` before filtering out terminal or stale activities. Current main filters to active, non-idle, non-disconnected, fresh candidates first; keep that invariant or an old terminal Live Activity can be adopted as current and suppress the new connection state.
  - confidence: 0.88
- **[P2] Refresh identity when gateway metadata changes:** `apps/ios/Sources/Model/NodeAppModel.swift:689-694`
  - body: This refresh only runs from `setSelectedAgentId`, but reconnect starts the activity before gateway metadata can resolve default agent identity. Because ActivityKit attributes are immutable, the Dynamic Island or lock-screen label can stay stuck on fallback identity unless metadata-driven effective identity changes also recreate the activity.
  - confidence: 0.86
- **[P2] Guard task cleanup by the active task:** `apps/ios/Sources/Model/NodeAppModel.swift:1752-1753`
  - body: The camera HUD auto-hide task always calls `handleWorking(task: nil)` after its sleep, even if another operation such as screen recording has since published a different working task. Track the task being cleared or compare the current task before resetting, so an older HUD timer cannot hide a newer Dynamic Island working state.
  - confidence: 0.84
