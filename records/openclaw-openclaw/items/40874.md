Full review comments:

- **[P1] Move the intent consumer onto RootTabs:** `apps/ios/Sources/RootCanvas.swift:21-22`
  - body: `OpenTalkModeIntent.perform()` only sets this UserDefaults flag, but the branch consumes it in `RootCanvas`. Current main mounts `RootTabs()` from `OpenClawApp` and no longer has this root file, so after the required rebase the Action Button/Siri shortcut would either remain conflicted or lose its consumer unless the cold/warm launch handling is moved into the current RootTabs navigation model.
  - confidence: 0.93
- **[P2] Preserve current-main Live Activity hydration filters:** `apps/ios/Sources/LiveActivity/LiveActivityManager.swift:123-132`
  - body: This older hydration path accepts every ActivityKit activity and keeps the newest `startedAt`, but current main first filters to active, non-idle, non-disconnected activities younger than the hydration stale window. Dropping that filter can resurrect stale/disconnected activities and suppress the new activity identity the PR is trying to show on the lock screen.
  - confidence: 0.86
- **[P2] Refresh identity after gateway metadata changes:** `apps/ios/Sources/Model/NodeAppModel.swift:689-695`
  - body: The branch recreates the Live Activity only from `setSelectedAgentId`, but `refreshAgentsFromGateway()` can later change `gatewayDefaultAgentId`, `gatewayAgents`, and `mainSessionKey` after the reconnect loop has already started the activity. That leaves the Dynamic Island and lock-screen attributes stuck on a fallback or old agent/session until a manual selection change or reconnect.
  - confidence: 0.84
- **[P2] Guard cleanup by the task that started it:** `apps/ios/Sources/Model/NodeAppModel.swift:1752-1753`
  - body: The camera HUD auto-hide task always calls `handleWorking(task: nil)` after its sleep. If a screen recording or another long-running operation starts before that timer fires, the older HUD timer can clear the newer working state and make the Dynamic Island return to idle while work is still in progress.
  - confidence: 0.82
