Full review comments:

- **[P2] Tie Live Activity clears to the active task:** `apps/ios/Sources/Model/NodeAppModel.swift:1753`
  - body: This auto-hide path always calls `handleWorking(task: nil)` after the timer fires. If a camera HUD success is waiting and a screen recording or another Live Activity task starts before the timer expires, the old timer clears the newer task and the Dynamic Island falls back to the connection state while work is still running. Please track task ownership and only clear when the completion still matches the active task.
  - confidence: 0.86
- **[P2] Refresh Live Activity after agent metadata changes:** `apps/ios/Sources/Model/NodeAppModel.swift:689-694`
  - body: The new immutable Live Activity attributes display `activeAgentName`, but `refreshIdentity` is only called from explicit agent selection changes. On connect, `refreshAgentsFromGateway()` can replace a fallback id or `Main` with the gateway's resolved default agent name without calling this path, leaving the Dynamic Island and lock screen label stale until the activity is recreated for some other reason.
  - confidence: 0.8
