  - body: The PR hydrates the keeper from every ActivityKit record by `startedAt`, dropping current main's active/non-idle/non-disconnected/staleness filters.   - confidence: 0.9
- **[P2] Refresh identity after gateway metadata changes:** `apps/ios/Sources/Model/NodeAppModel.swift:689-694`
  - body: This refresh only runs when the user explicitly changes the selected agent, but `refreshAgentsFromGateway()` can also change `activeAgentName` and `mainSessionKey` when default-agent metadata arrives after connect. Because ActivityKit attributes are immutable, the lock-screen label can remain stuck on the fallback agent until reconnect or manual selection.
  - confidence: 0.86
- **[P2] Pair working updates with the active operation:** `apps/ios/Sources/Model/NodeAppModel.swift:1736-1740`
  - body: Photo/video HUD paths start Live Activity working state with `autoHideSeconds == nil`, and failures switch to an error HUD without clearing that state; separately, any old HUD timer can call the global `handleWorking(task: nil)` while screen recording is still active. Track the operation that owns the task state before clearing it, and clear non-error starts on failure.
  - confidence: 0.88
