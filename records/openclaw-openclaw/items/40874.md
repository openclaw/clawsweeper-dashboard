Refresh after metadata changes too, or Dynamic Island can show the fallback/old agent for the activity lifetime.
  - confidence: 0.88

  - body: The HUD auto-hide path always calls `handleWorking(task: nil)` after its timer, even if another operation such as screen recording has since set a newer working task. Track the task owner/description before clearing so an older timer cannot reset a newer Dynamic Island status.
