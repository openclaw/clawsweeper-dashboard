- **[P2] Keep stale HUD timers from clearing newer tasks:** `apps/ios/Sources/Model/NodeAppModel.swift:1753`
  - body: `showCameraHUD` still schedules an auto-hide task that unconditionally calls `handleWorking(task: nil)`. If a camera HUD is visible and screen recording starts before that timer fires, the old timer can reset the Live Activity to idle while recording is still in progress, so the Dynamic Island stops showing the active task. Track the current task/token or cancel the HUD dismiss task when another working source starts before clearing it.
  - confidence: 0.88
- **[P2] Refresh activity labels after agent metadata arrives:** `apps/ios/ActivityWidget/OpenClawLiveActivity.swift:13`
  - body: The widget now renders `context.attributes.agentName`, but the activity is started before `refreshAgentsFromGateway()` resolves the default agent name and the new `refreshIdentity` hook only runs from `setSelectedAgentId`. Because the update path only changes `ContentState`, the lock screen/Dynamic Island can stay on `Main` or a raw id after gateway metadata arrives; refresh the activity when the resolved agent identity changes during metadata refresh too.
  - confidence: 0.84
