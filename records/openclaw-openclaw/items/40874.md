  - confidence: 0.87
- **[P2] Tie working-state cleanup to the owning operation:** `apps/ios/Sources/Model/NodeAppModel.swift:1737-1753`
  - body: Non-error camera HUD starts a global Live Activity working state, but a later error HUD does not clear it and any older auto-hide timer can clear a newer screen-recording or camera operation. Track the operation that owns the task state before clearing it, and clear non-error starts on failure.
