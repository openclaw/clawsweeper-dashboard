## What This Changes

This PR adds an optional persisted `precheck` command for cron jobs so a governed host-shell check can skip the scheduled payload before an agent/model turn, with CLI, protocol, docs, cost statistics, and focused tests.

## System Context

Cron job definitions move from CLI and Gateway protocol validation into persisted scheduler records, then the cron timer decides whether to execute a payload. This change adds a pre-payload host-shell decision whose result either starts the existing payload path or records a skipped run without an agent turn.
