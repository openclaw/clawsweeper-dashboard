## What This Changes

The PR adds an optional persisted `precheck` shell command to cron jobs, plus CLI, protocol, documentation, history-statistics, and test support so no-work runs can skip a payload and its model turn.

## System Context

OpenClaw cron persists jobs, schedules them in the Gateway, and records each outcome for retries, delivery, and history. This change inserts a governed shell-command decision before the scheduler executes a command, system event, script, or agent payload.
