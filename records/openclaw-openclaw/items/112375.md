## What This Changes

This PR adds an optional `precheck` shell command to cron jobs so a scheduled payload can be skipped before an agent/model turn, with protocol, CLI, run-history statistics, documentation, and tests.

## System Context

OpenClaw’s cron scheduler reads persisted job definitions, decides whether a due job should proceed, then runs a command, system event, or agent payload and records the outcome. This PR inserts a host-shell admission step before that payload path and exposes it through the Gateway protocol and CLI.
