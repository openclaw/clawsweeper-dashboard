## What This Changes

Adds an optional persisted cron shell precheck that can skip a job before its payload starts, along with Gateway protocol, CLI, docs, run-cost statistics, and focused tests.

## System Context

OpenClaw's Gateway owns persisted cron jobs and dispatches their payloads into system events, agent turns, commands, or scripts. This PR inserts a shell-based decision gate before that payload dispatch and exposes the gate through the Gateway protocol and cron CLI.

## Architecture Diagram

flowchart TD

  D --> E{Work detected?}
  E -->|No work| F[Skipped run history]
  E -->|Work exists| G[Cron payload]
  G --> H[Agent, command, or event output]

## Best Possible Solution

Obtain explicit ownership for a durable cron precheck API, then prove a real persisted job through the Gateway scheduler for allowed, no-work, denied, and existing-job upgrade paths; keep auxiliary statistics as a separately justified follow-up if it is not required for that core contract.
