## What This Changes

The PR retries stale direct native-hook bridges through gateway RPC, falls back from Codex approval relay errors to normal before-tool-call evaluation, and updates focused tests for both paths.

## Best Possible Solution

Keep the gateway retry, but restrict approval fallback to explicitly classified missing or stale relay transport errors and execute an equivalent full native policy path—including loop detection and deferred approvals—while failing closed on every other error; then prove a real restart/resume cycle with both allowed and denied commands.
