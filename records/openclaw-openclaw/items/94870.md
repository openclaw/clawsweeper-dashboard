## Summary

The underlying restart bug is credible, but this head is not merge-ready: the gateway retry still cannot recover the current relay registration, the new failure classifier is not scoped to the current tool call, and no exact-head live restart proof demonstrates preserved enforcement.

## What This Changes

The PR retries stale direct native-hook bridges through gateway RPC and lets pre-invocation Codex relay failures fall through to normal before-tool policy while keeping post-invocation failures fail-closed.

## Best Possible Solution

Make stale descriptors self-heal by acquiring or regenerating the current relay generation, classify failures using the current invocation identity, and retain fail-closed behavior for any failure after that invocation begins.
