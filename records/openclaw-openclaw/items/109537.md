## Summary

This PR addresses a real hang risk, but the shared 30-second budget also covers legitimate long-running Homebrew mutations, while Node’s synchronous timeout does not guarantee hard termination; it needs revision and real macOS behavior proof before merge.

## What This Changes

The PR adds a 30-second timeout to the DNS CLI’s shared subprocess helper and a 5-second timeout to its privileged file-write fallback.

## Best Possible Solution

Give quick discovery probes short deadlines, assign installation and service mutations separate realistic budgets or explicit cancellation handling, and prove both successful setup and forced-timeout behavior on macOS.
