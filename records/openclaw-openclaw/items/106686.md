## Summary

Keep this issue open for focused security triage, but the current report does not yet establish the alleged public fallback: the shared direct-DM helper delegates outbound delivery to a caller-supplied callback, while its `OriginatingChannel` and `OriginatingTo` fallbacks populate message context rather than selecting the transport destination. The reporter should identify the affected channel/plugin and provide a concrete private-target-to-public-destination trace before a fix is designed.

## What This Changes

Investigate and prevent ambiguous direct-message reply routing from exposing private content on a broader channel surface.

## Best Possible Solution

Reproduce one named channel flow while recording the inbound private target, finalized context, resolved session route, and channel-owned delivery destination; if the audience broadens, enforce the invariant in that channel's target-normalization or delivery boundary and add a regression test proving no public send occurs.
