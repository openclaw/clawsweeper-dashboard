## Summary

Keep open: current main and the latest release still have a Slack room-history path that records always-on room messages into the prompt history window but only wires the shared post-dispatch clear for mention-required rooms. The related search did not find another canonical issue or PR for this exact Slack history reset bug.

## What This Changes

The issue requests that Slack clear its per-channel prompt history window after an agent reply so the "since last reply" context block does not keep stale answered messages.

## Best Possible Solution

Clear Slack's rendered room history window for the relevant history key only after confirmed visible reply delivery, while preserving quiet ambient room events when no visible reply is sent and avoiding any new config surface.
