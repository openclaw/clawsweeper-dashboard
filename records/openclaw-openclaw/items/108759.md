## Summary

Keep open: the linked problem remains real, but the prior blocker is still present because the new public contract admits `ultra` while the generic completion layer only supports model reasoning through `max`; after-fix real behavior proof is also still missing.

## What This Changes

Adds an optional reasoning-effort parameter to plugin runtime LLM completions, forwards it to the prepared completion path, documents the parameter, and adds a forwarding assertion.

## Best Possible Solution

Expose a dedicated completion-reasoning type containing only values the prepared completion path explicitly normalizes or validates, add coverage for every admitted exceptional level, and show a redacted live plugin completion using a reasoning-capable model.
