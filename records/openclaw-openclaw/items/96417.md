## What This Changes

The PR validates `maxBytes` in the shared response prefix reader and adds regression tests for invalid response-body and text-snippet limits.

## Best Possible Solution

## Reproduction Assessment

## Solution Assessment

Yes, with compatibility acceptance. Validating once in the shared prefix reader covers both response APIs and matches sibling bounded-stream contracts better than caller-by-caller checks.
