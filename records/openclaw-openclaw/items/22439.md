## Best Possible Solution

The broader request is a feature/config addition rather than a broken current-main contract.

## Solution Assessment

No as currently shaped; the opt-in tier idea is plausible, but the resolver must not describe no-override behavior differently from the runtime filter, and the public config docs need to be aligned before maintainers judge the product direction.
