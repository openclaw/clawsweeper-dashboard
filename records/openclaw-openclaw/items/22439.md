## Summary

This PR remains necessary if maintainers want a product-supported bootstrap-context policy: current `main` still has only session-type allowlists and no configurable tier. The branch has credible real-behavior proof and preserves the existing no-config defaults, but its exported default tier resolver says subagent and cron sessions are `minimal` while the actual no-override filters load different file sets; that semantic mismatch should be fixed before a maintainer decides whether to add this new public configuration surface.

## What This Changes

The PR adds `agents.defaults.bootstrapTier` with `minimal`, `standard`, and `full` modes to control which workspace bootstrap files are injected into main, subagent, and cron sessions, including how hook-loaded extra files are handled.

## System Context

Workspace bootstrap files such as `AGENTS.md`, `SOUL.md`, and `TOOLS.md` are loaded before an agent run and become model context. The bootstrap resolver filters those files by session type, then bundled hooks may append configured extras before the final context is built.
