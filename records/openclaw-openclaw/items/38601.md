## Summary

## What This Changes

The issue requests warning or error feedback when `pty: true` is requested for the exec tool while sandbox mode disables PTY.

## Best Possible Solution

Keep PTY disabled under sandbox by default, add clear feedback through the existing exec result path for explicit sandboxed PTY requests, document the limitation, and cover the behavior with a focused regression test.
