## Summary

Keep open: current main and the latest release still turn explicit sandboxed `pty: true` exec calls into non-PTY execution without a sandbox-specific warning, and the only open closing candidate is an unmerged fork PR rather than an OpenClaw fix.

## What This Changes

The issue asks OpenClaw to warn or fail when sandbox mode disables an explicit `pty: true` exec request.

## Best Possible Solution

Keep PTY disabled under sandbox by default, then add a clear warning through the existing exec warning channel, update the exec docs, and cover the sandboxed explicit-PTY path with focused regression proof once maintainers choose warning over failure.
