## Summary

Keep open: current main and the latest release still downgrade explicit sandboxed `pty: true` exec calls to non-PTY execution without a sandbox-specific warning, and the warning-versus-fail-closed behavior remains a maintainer security-boundary choice.

## What This Changes

The issue asks for explicit `pty: true` exec requests in sandbox mode to warn or fail instead of being silently downgraded to non-PTY execution.

## Best Possible Solution

Keep PTY disabled in sandbox by default, add a clear exec warning when explicit `pty: true` is ignored, document the sandbox limitation, and add focused regression coverage; choose fail-closed only if maintainers want stricter sandbox semantics.
