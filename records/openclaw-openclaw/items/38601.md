## Summary

Keep open: current main and the latest release still turn explicit sandboxed `pty: true` requests into non-PTY execution without a sandbox-specific warning, and the remaining open closing reference is an unmerged fork PR rather than a merged OpenClaw fix.

## What This Changes

The issue asks OpenClaw to warn or fail when `exec` receives `pty: true` but sandbox routing prevents PTY execution.

## Best Possible Solution

Keep PTY disabled under sandbox by default, make the warn-vs-fail behavior explicit, document the limitation, and add focused regression coverage for the user-visible exec result.
