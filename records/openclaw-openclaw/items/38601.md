## Summary

## What This Changes

The issue asks OpenClaw to warn or fail when `exec` receives `pty: true` but sandbox routing prevents PTY execution.

## Best Possible Solution

Keep PTY disabled under sandbox by default, then add the maintainer-approved warning or failure through the existing exec result path, update the exec docs, and cover direct plus gateway execution paths with focused tests.
