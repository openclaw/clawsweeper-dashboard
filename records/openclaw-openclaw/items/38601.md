## Summary

Keep open: current main and the latest release still turn an explicit sandboxed `pty: true` request into non-PTY execution without a sandbox-specific warning, and the remaining choice is whether maintainers want warning-and-continue or fail-fast behavior.

## What This Changes

The issue asks OpenClaw to warn or fail when sandboxed exec ignores an explicit `pty: true` request, and to document that sandbox limitation.

## Best Possible Solution

Keep PTY disabled under sandbox by default, then add a clear warning or fail-fast path after maintainer choice, update the exec docs, and add focused regression coverage.
