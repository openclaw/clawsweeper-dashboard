## Summary

Keep open: current main and v2026.6.11 still convert explicit sandboxed `pty: true` to non-PTY execution without a sandbox-specific warning, and the remaining choice is security-sensitive warning-versus-fail-closed behavior rather than cleanup closure.

## What This Changes

The issue asks OpenClaw to warn or fail explicitly when `exec` receives `pty: true` while sandbox mode forces non-PTY execution.

## Best Possible Solution

Keep PTY disabled under sandbox, surface explicit PTY suppression through a maintainer-approved warning or rejection path, document the limitation, and add focused regression coverage.
