## Summary

Keep open: current main and v2026.6.11 still convert explicit sandboxed `pty: true` into non-PTY execution without a sandbox-specific warning, and the remaining choice is warning-versus-fail-closed behavior at a sandbox boundary.

## What This Changes

The issue asks OpenClaw to warn or reject when `exec` receives `pty: true` while sandbox mode prevents PTY execution.

## Best Possible Solution

Keep sandbox isolation unchanged, then add the maintainer-approved warning or rejection path with focused docs and regression coverage for sandboxed and non-sandboxed `pty:true`.
