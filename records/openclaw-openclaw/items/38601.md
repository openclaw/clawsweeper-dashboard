## Summary

Keep open: current main and v2026.6.11 still turn sandboxed explicit `pty: true` into non-PTY execution without a sandbox-specific warning, and an open fork PR references this issue but is not a merged OpenClaw fix. ## What This Changes

The issue asks OpenClaw to warn or reject when `exec` is called with `pty: true` but sandbox mode forces non-PTY execution.

## Best Possible Solution

Keep PTY disabled under sandbox, surface explicit PTY suppression through a maintainer-approved warning or rejection path, document the limitation, and add focused regression coverage.
