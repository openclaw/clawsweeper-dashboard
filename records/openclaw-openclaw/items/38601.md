## Summary

Keep open: current main and the latest release still silently downgrade explicit sandboxed `pty: true` to non-PTY execution, and the remaining blocker is a maintainer security/product decision about warning versus fail-closed behavior.

## What This Changes

The issue requests a warning or error when `pty: true` is requested for the exec tool but sandbox mode prevents PTY allocation.

## Best Possible Solution

Keep PTY disabled under sandbox, surface explicit PTY suppression through a maintainer-approved warning or rejection path, document the limitation, and add focused regression coverage.
