## Summary

## What This Changes

The issue requests a warning or explicit failure when `exec` receives `pty: true` while sandbox mode prevents PTY execution, plus user-facing docs for that limitation.

## Best Possible Solution

Keep PTY disabled under sandbox by default, add a clear warning through the existing exec warning channel when explicit `pty: true` is ignored, document the sandbox limitation, and add focused regression coverage.
