## Summary

Keep open: current main and v2026.6.11 still turn explicit sandboxed `pty: true` into non-PTY execution without a sandbox-specific warning, and the related in-repo fix attempts are closed unmerged while the remaining open fork PR is only a candidate.

## What This Changes

The issue asks OpenClaw to warn or fail when an explicit exec `pty: true` request is ignored because sandbox mode disables PTY.

## Best Possible Solution

Keep PTY disabled in sandbox; after the sandbox-boundary choice is confirmed, land a narrow fix that surfaces explicit PTY suppression, updates exec docs, and adds regression coverage.
