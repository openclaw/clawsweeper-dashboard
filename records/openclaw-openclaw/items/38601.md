## What This Changes

The issue reports that `pty:true` on exec is silently ignored when sandboxing is active, leaving users without a warning or error.

## Best Possible Solution

Keep sandbox isolation unchanged, then implement the maintainer-approved warning or rejection path with focused runtime, docs, and regression coverage.
