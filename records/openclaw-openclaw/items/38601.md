## Summary

Keep open: current main and the latest release still suppress explicit sandboxed `pty:true` to non-PTY execution without a sandbox-specific warning, and the same-repo fix attempts are closed unmerged while the fork candidate is not adopted into this repository.

## What This Changes

The issue requests visible feedback when `pty: true` is requested for the exec tool but sandbox mode prevents PTY execution.

## Best Possible Solution

Keep PTY disabled in sandbox by default, surface an explicit warning through the existing exec warnings path, document the sandbox limitation, and add focused regression coverage; fail the call only if maintainers choose that stricter boundary.
