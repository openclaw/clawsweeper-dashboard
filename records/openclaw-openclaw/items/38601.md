## Summary

Keep open: current main and the latest release still suppress explicit sandboxed `pty: true` by converting it to non-PTY execution without a sandbox-specific warning, and the remaining choice is warning-versus-rejection semantics for a sandbox boundary.

## What This Changes

The issue asks OpenClaw to warn or reject when `exec` is called with `pty: true` but sandbox mode prevents PTY, and to clarify the user-facing exec docs.

## Best Possible Solution

Keep PTY disabled under sandbox, then add a maintainer-approved warning or explicit rejection path with docs and focused regression coverage.
