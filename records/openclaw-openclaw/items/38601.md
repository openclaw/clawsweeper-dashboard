## Summary

Keep open: current main and the latest release still suppress explicit sandboxed `pty: true` without a sandbox-specific warning, and the remaining choice is security-sensitive warning-versus-fail-closed behavior rather than cleanup closure.

## What This Changes

The issue asks OpenClaw to warn or error when `pty: true` is requested for the exec tool while sandbox mode disables PTY.

## Best Possible Solution

Keep PTY disabled under sandbox, surface explicit PTY suppression through a maintainer-approved warning or rejection path, document the limitation, and add focused regression coverage.
