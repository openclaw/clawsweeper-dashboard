## Summary

The evidence does not yet isolate a current-version, sanitised reproduction that distinguishes outbound suppression, bot ingress, and session replay, so it should remain open for scoped maintainer triage rather than be closed as already implemented.

## What This Changes

Report that Matrix room agents can expose silent/meta output and replay stale room state after gateway restarts, causing bot-to-bot reply loops.

## System Context

Matrix converts room events into OpenClaw channel turns, which route through reply gating and session state before outbound delivery. The reported failure spans Matrix bot-message admission, silent-reply delivery policy, durable session recovery, and gateway readiness.
