## What This Changes

This PR extracts browser-extension configuration and tab-group helpers from the background service worker, then catches rejected popup or side-panel message actions and sends an error result to the caller.

## System Context

The Chrome extension popup and side panel send asynchronous actions to a background service worker. That worker reads extension configuration and performs relay, tab, debugger, and gateway actions before returning a response that drives the visible UI state.
