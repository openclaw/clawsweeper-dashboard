## What This Changes

Consolidate exact FIFO per-key async queue implementations onto the existing `enqueueKeyedTask` helper while leaving specialized scheduling, cancellation, timeout, debounce, and drain/reset queues local.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99691 if each migrated caller matches the exact keyed FIFO contract, then close this issue after the merge.

## Reproduction Assessment

Yes for the maintenance concern: current main has the canonical queue helper and still has local promise-tail queues in Slack, config mutation, cron run logs, Telegram thread binding persistence, and other paths. This is not a runtime bug with a user-facing reproduction path.

## Solution Assessment

Yes, the requested direction is the narrow maintainable solution when limited to exact FIFO per-key serialization and final-tail cleanup. The safer alternative is to leave specialized cancellation, timeout, debounce, single-flight, and drain/reset queues local.
