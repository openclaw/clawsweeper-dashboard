## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Bind approvals to validated widget content:** `extensions/dashboard/src/gateway.ts:677-684`
  - body: `dashboard.widget.approve` records only a status for the widget name. Since the server later serves whatever files currently exist for an approved name and the UI trusts the served `widget.json` capabilities, an approved widget can drift to different HTML/capabilities without a fresh operator approval. Validate the manifest at approval time and store/check a content digest or version, or reset the widget to pending when its files change.
  - confidence: 0.89
- **[P1] Protect custom-widget assets with an auth capability:** `extensions/dashboard/index.ts:70-73`
  - body: Registering `/plugins/dashboard/widgets` as `auth: "plugin"` leaves approved widget files reachable without gateway auth. These files are agent-authored dashboard source/assets, so anyone who can reach the gateway and knows or guesses a widget name can fetch `index.html`, JS, and `widget.json`. Use gateway auth, a node-capability/scoped URL, or another unguessable approved-asset token that the sandboxed iframe can load.
  - confidence: 0.84
- **[P2] Keep dashboard state in SQLite plugin state:** `extensions/dashboard/src/store.ts:48-50`
  - body: `DashboardStore` makes `workspace.json` and undo JSON files the canonical runtime store for tabs, widgets, approval registry, and undo. Root policy requires OpenClaw-owned runtime state and plugin scratch data to live in SQLite/shared plugin state, with file sidecars only for named product artifacts or doctor migrations. Move this state into plugin-state SQLite before enabling the plugin by default.
  - confidence: 0.9
- **[P2] Reject symlink escapes when reading file bindings:** `extensions/dashboard/src/data-read.ts:106-122`
  - body: `resolveFileBinding` reads the lexically-contained path directly, but `fs.stat` follows symlinks. A symlink under `dashboard/data` can therefore point outside the data jail and still be read by an approved widget binding. Mirror the static asset server's realpath containment check before reading, and add a symlink escape regression test.
  - confidence: 0.86
