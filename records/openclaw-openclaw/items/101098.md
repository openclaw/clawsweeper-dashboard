Full review comments:

- **[P1] Persist dashboard state in SQLite-backed plugin state:** `extensions/dashboard/src/store.ts:49-50`
  - body: This enabled-by-default plugin writes durable `workspace.json` and undo JSON sidecars under `stateDir/dashboard`. OpenClaw runtime/plugin state is expected to use SQLite/plugin state unless maintainers approve a named file artifact contract, so this creates migration debt before the feature ships. Move workspace and undo state into the existing SQLite-backed plugin state seam, while keeping actual widget asset files as named product artifacts if needed.
  - confidence: 0.93
- **[P2] Use the approved widget manifest entrypoint:** `ui/src/components/dashboard-custom-widget.ts:230-243`
  - body: The server validates `widget.json.entrypoint`, but the UI manifest view drops that field and the iframe always loads `index.html`. A widget approved for a different entrypoint will fail to mount or run a file different from the reviewed manifest contract. Carry the validated entrypoint into `WidgetManifestView` and build the iframe URL from it.
  - confidence: 0.91
