## Summary

The previous fallback-flag propagation blocker is fixed, but the current guard is broader than the reported invariant: it disables every embedded spawn for the whole fallback completion turn, including legitimate remaining work that the announcement contract still permits. The PR also intentionally leaves equivalent OpenClaw delegation surfaces unguarded, so it needs a maintainer-approved policy boundary before merge.

## What This Changes

The PR marks completion announcements as completed-work evidence, propagates fallback-attempt context into embedded runs, and rejects embedded subagent or ACP spawns when a fallback turn originates from a completion announcement.

## Best Possible Solution

Define one explicit OpenClaw work-delegation policy that blocks treating completed reports as new directives while preserving legitimate remaining-step orchestration, apply it consistently to OpenClaw-owned spawn/send/scheduling surfaces, and keep Codex-native enforcement as an upstream follow-up.
