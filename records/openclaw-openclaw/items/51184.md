## Best Possible Solution

Propagate sanitized `label`/`displayName` through the shared status contract, render the friendly name as the primary CLI/TUI identifier with raw-key fallback/detail, and leave stable JSON attribution fields to https://github.com/openclaw/openclaw/issues/85688.

## Solution Assessment
