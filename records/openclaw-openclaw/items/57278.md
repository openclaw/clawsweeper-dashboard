## Summary

Keep open for a Telegram reply-media contract decision. Current main still hydrates reply-chain media without excluding the bot's own messages, but a blanket guard would reverse the recently expanded behavior that makes reply-target media available to the model.

## What This Changes

The issue requests that Telegram reply-chain media authored by the bot not be hydrated as an inbound user attachment.

## Best Possible Solution

Define the reply-chain contract explicitly: preserve bot-authored reply text and metadata, then decide whether its media is excluded from model attachments; implement the chosen rule in the shared chain resolver with focused DM and group regression coverage.
