## What This Changes

The PR collects captions from Telegram media-group entries and replaces the primary message caption with a labeled combined string before the album is dispatched to the agent.

## Best Possible Solution

Build labeled caption lines from each original media-group entry’s index, preserve empty-item gaps, add focused regression coverage for non-contiguous captions, and attach redacted live Telegram proof showing all captions reach the agent correctly.
