## Summary

Keep this open for security-owner triage as concrete defense-in-depth hardening, not yet as a confirmed OpenClaw boundary-bypass vulnerability: current `main` embeds the raw Anthropic SSE payload in the parse exception, but the report does not demonstrate the exception reaching a real log sink or exposing OpenClaw-owned credentials.

## What This Changes

Stop Anthropic SSE parse errors from embedding unredacted event data and raw stream lines in exception messages.

## Best Possible Solution

Remove raw payload and raw-line content from provider exceptions, retain only structural metadata such as event type, payload length, and a non-reversible digest, add a sentinel-secret regression test across sibling SSE parsers, and synchronize the canonical fix with the Pi provider owner; do not create full-payload debug dumps without an explicit secure storage and retention design.
