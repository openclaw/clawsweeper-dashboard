## Summary

Keep open. Current main already supplies Slack sessions with shared workspace Project Context, but Slack still lacks an account-level prompt contract that consistently covers rooms, DMs, MPIMs, and native command paths; choosing that public config and precedence model requires maintainer direction.

## What This Changes

Add a Slack account/global `systemPrompt` inherited by all Slack conversations while preserving per-room overrides and shared workspace context injection.

## Best Possible Solution

Establish one documented inheritance contract where shared Project Context remains the workspace-file mechanism and an approved Slack account prompt, if adopted, appends consistently before more-specific room overrides across every Slack entry path.
