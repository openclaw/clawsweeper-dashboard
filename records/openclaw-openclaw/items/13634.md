## Summary

Keep open. Current main and v2026.6.11 cover the workspace-file half through shared Project Context, but Slack still lacks a typed, documented, and runtime-applied account/global `systemPrompt` inheritance contract.

## What This Changes

Issue #13634 requests Slack-wide prompt context via `channels.slack.systemPrompt` plus Slack workspace-file injection parity with Telegram.

## Best Possible Solution

Keep shared Project Context as the workspace-file mechanism, then define or reject a documented Slack account/global prompt inheritance contract across rooms, DMs, MPIMs, wildcard defaults, and slash commands.
