## Summary

Keep open. Current main still treats disabled skills as an eligibility and visibility state, while generic file reads and host execution are governed by filesystem, sandbox, approval, and exec policy rather than a disabled-skill directory boundary; the related filesystem-roots work remains open and explicitly does not solve `exec`.

## What This Changes

Request hard runtime enforcement so skills configured with `enabled: false` cannot be read or executed by an agent, not only hidden from auto-matching and prompts.

## Best Possible Solution

Define a central skill-access contract, likely coordinated with the broader capability policy work, and enforce it consistently across skill discovery, filesystem tools, exec/sandbox materialization, UI/status, and docs.
