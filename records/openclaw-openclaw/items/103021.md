## Summary

Keep open: current main still omits `auto_archive_duration` when `message action=send` auto-creates a Discord forum/media thread, while Discord documents the forum thread create parameter and channel default field. This is a narrow stable Discord bug with a clear source-level reproduction and no canonical open fix found.

## What This Changes

The issue asks Discord forum-parent `message action=send` thread creation to inherit or explicitly set the forum thread auto-archive duration instead of falling back to Discord's API default.

## Best Possible Solution

Keep the fix inside the Discord plugin send path: fetch or carry the forum/media parent channel's `default_auto_archive_duration` into the create-thread body when no explicit archive duration is set, with focused regression tests for forum sends.
