## Summary

Keep this PR open for normal maintainer review. The current-main formatter still interpolates every `rg`/`grep` pattern into a `search "…"` label, while this patch adds a narrowly scoped display-only guard; the prior literal-`search` concern is covered by the updated predicate and regression test.

## What This Changes

The PR makes exec-tool search summaries fall back to `search text` when a grep or ripgrep pattern resembles previously rendered or unsafe display text, while preserving normal pattern summaries.

## System Context

The agent exec display layer converts shell commands into compact labels for tool timelines and transcript cards. It receives parsed command stages and emits presentation text without changing the command that the exec tool runs.
