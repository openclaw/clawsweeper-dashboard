## Summary

Keep open. Current main has closed the dangerous partial tool-call execution path and now treats length-limited embedded turns as incomplete, but the requested configurable mode:"run" hard-fail/continue policy and continuation budget are still absent and need maintainer runtime-policy design.

## What This Changes

Request configurable per-agent handling for mode:"run" stopReason:"length" sessions, including hard-fail and bounded catch-and-continue behavior.

## Best Possible Solution

Keep the current generic safety guards, then have maintainers decide whether to add a narrow hard-fail mode first and only add bounded continue after replay and side-effect semantics are specified.
