## What This Changes

The issue requests configurable multiple or contextual ack reaction emojis instead of the current single ack reaction value.

Preserve the shipped ackReaction string contract and add one maintainer-approved shared array or selector strategy across config, schema, docs, SDK/channel seams if needed, and bundled-channel tests.
