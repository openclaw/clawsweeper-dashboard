## Summary

Keep this issue open for a maintainer product decision. Current main still exposes one pre-processing acknowledgement reaction, not a configurable pool or contextual selector; the related text-acknowledgement request overlaps in timing but does not replace this emoji-selection request.

## What This Changes

Add configurable or contextual acknowledgement-reaction emoji selection instead of using one fixed pre-processing reaction.

## System Context

Inbound channel messages are classified and may receive an immediate acknowledgement reaction before agent processing begins. Shared configuration resolves that reaction and each channel adapter translates it into its own native reaction format.

## Architecture Diagram

flowchart LR

  B --> G[Agent processing]

## Best Possible Solution

Choose a deterministic compatibility contract first—prefer a configured ordered or random pool while retaining the existing singular value—then add shared selection and channel-valid fallback behavior with focused bundled-channel coverage.

Required: true

Kind: product_direction

Question: Should OpenClaw add a configurable acknowledgement-reaction pool, and if so should selection be deterministic/random rather than model-driven before acknowledgement is sent?

Rationale: The existing acknowledgement is intentionally sent before normal agent processing, so selection semantics determine latency, predictability, configuration shape, and channel fallback guarantees.

Likely owner: Chris Zhang

Owner reason: Current feature-history evidence ties this person to the central acknowledgement configuration and runtime path.

Owner confidence: medium

Options:

- **Keep one fixed reaction:** Retain the current low-latency, predictable singular acknowledgement contract and close the feature request as not planned.
- **Add a deterministic reaction pool (recommended):** Preserve `ackReaction` compatibility and add a bounded configured pool with documented selection and per-channel fallback rules.
- **Add model-driven selection:** Let the agent choose an emoji per message, accepting added latency and a new pre-ack model-policy contract.

## Solution Assessment

Unclear until maintainers choose selection semantics. A bounded deterministic pool is the narrowest maintainable direction because model-driven selection would delay a reaction that is currently sent before agent processing.
