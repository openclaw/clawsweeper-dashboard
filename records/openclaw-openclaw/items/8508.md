## Summary

Keep open: current `main` and the latest release still expose one preselected ack reaction value, while array/random/contextual selection would add a cross-channel config or SDK contract that needs maintainer product direction.

## What This Changes

This issue requests configurable arrays or contextual selection for automatic ack reaction emojis instead of one fixed reaction.

## Best Possible Solution

Preserve the shipped `ackReaction` string contract and add one maintainer-approved shared array or selector strategy across config types, schemas, docs, SDK/channel seams if needed, and bundled-channel tests.
