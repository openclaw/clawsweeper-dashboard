## Summary

Keep open for maintainer product direction: current main still resolves one preconfigured acknowledgment reaction, and neither the merged per-channel override work nor lifecycle status reactions implement content-aware or pool-based pre-processing selection.

## What This Changes

Requests configurable pools or context-aware selection of acknowledgment reaction emojis instead of one fixed reaction.

## Best Possible Solution

Preserve the existing singular `ackReaction` contract, then add one shared deterministic selector or strategy contract with channel validation, stable fallback behavior, aligned schemas/docs, and focused bundled-channel coverage after maintainers approve the semantics.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should pre-processing acknowledgment reactions use a deterministic configured pool, random selection, rule-based message classification, or a model-driven contextual choice?

Rationale: This introduces public configuration and cross-channel runtime policy; implementation cannot safely choose the latency, determinism, fallback, and unsupported-emoji semantics without maintainer intent.

Likely owner: steipete

Owner reason: The existing discussion records this person making the clearest product-direction assessment for this exact request.

Owner confidence: high

Options:

- **Deterministic pool (recommended):** Add a backward-compatible reaction pool with a documented stable selection algorithm and per-channel fallback behavior.
- **Rule-based selector:** Select reactions from inexpensive explicit message attributes, requiring a maintained classification contract but no extra model call.
- **Model-driven selector:** Run a pre-ack model decision, accepting additional latency, cost, nondeterminism, and failure handling before processing.

## Reproduction Assessment

Not applicable: this is a request for a new selection capability, not a failure of defined behavior; current source and documentation clearly establish the existing singular contract.

## Solution Assessment

Unclear until maintainers choose the selector semantics. A raw array alone is not the best complete solution because it leaves selection order, persistence, unsupported reactions, channel differences, and failure fallback undefined.
