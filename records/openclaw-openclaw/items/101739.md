## Reproduction Assessment

Yes from source inspection. Current main uses prototype-aware membership against exec response maps, and a valid exec id like `toString` can be treated as inherited rather than missing when the provider returns empty `values`.

## Solution Assessment

Yes. The membership decision belongs in `parseExecValues`, and `Object.hasOwn` fixes both `values` and `errors` without changing the exec provider protocol or adding compatibility surface.
