The branch adds a persisted Goal token cursor so token budgets begin at the first fresh post-creation usage snapshot and subsequently charge only positive session-token deltas.

## System Context

Goal is OpenClaw’s persisted per-session objective state, including optional token and continuation budgets. Agent-run metadata updates the session record at finalization; Goal accounting then derives budget status for CLI, TUI, and agent-tool status views.
