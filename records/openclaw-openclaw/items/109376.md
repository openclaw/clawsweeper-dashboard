## Summary

Keep this PR open, but do not merge it yet: the voice-confirmation hook is scoped only by the shared agent session key, so enabling a Talk voice session can affect unrelated tool runs and concurrent Talk clients. The new core configuration and protocol surface also needs explicit product sponsorship, an iOS build, and inspectable Browser/iPhone behavior proof.

## What This Changes

This PR adds durable logical Talk voice sessions, cached realtime context packs, transcript persistence, spoken action confirmation, new Gateway protocol methods, configuration options, and Browser/iPhone client integration.

Keep the durable ledger in the per-agent SQLite database, but bind confirmation and tool-effect tracking to an explicit voiceSessionId plus registered consult run identity, leave unrelated agent runs untouched, obtain maintainer approval for the reduced configuration/protocol surface, remove the release-owned changelog edit, and prove Browser and iPhone reconnect, transcript import, and confirmation flows end to end.
