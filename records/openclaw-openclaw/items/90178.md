## Summary

Keep open: current main still has retry-limit/expiry give-up paths, and the fallback task terminal delivery path is still suppressed for non-cancelled subagent tasks, while the direct candidate fix remains open and unmerged.

## What This Changes

The issue asks OpenClaw to wake a parent waiting in `sessions_yield` when subagent completion announce delivery gives up after retry-limit or expiry, with a separate request to make announce retry/expiry settings configurable.

## Best Possible Solution

Land a narrow requester-visible failure/completion wake path such as https://github.com/openclaw/openclaw/pull/95080 or an equivalent durable-queue alternative, while tracking retry/expiry configurability separately.
