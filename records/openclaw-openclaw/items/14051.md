## What This Changes

## Best Possible Solution

Keep this as the canonical heartbeat activity idle-timeout tracker until maintainers approve the public config and activity boundary, then implement one cohesive runtime path across schema, types, docs, config-honor inventory, scheduler/run gating, and focused regression coverage.
