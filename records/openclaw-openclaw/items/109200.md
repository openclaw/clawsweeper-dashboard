## Summary

The patch appears correct and well proven for the reported Android cross-chat media leak, but it also changes persistent cache and outbox upgrade semantics; the remaining blocker is maintainer acceptance of that compatibility contract plus exact-head Android validation, not a discrete code defect.

## What This Changes

The PR keys Android composer drafts, media, asynchronous sends, cached sessions and transcripts, and durable outbox rows to a gateway-agent-session owner, while adding resolved agent ownership to session-deletion events.

## Best Possible Solution

Keep one canonical owner identity across all composer and durable chat state, retain fail-closed manual recovery for rows whose owner cannot be proven, and merge only after a maintainer explicitly accepts that upgrade behavior and exact-head Android lanes pass.
