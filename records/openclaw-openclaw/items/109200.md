## Summary

Keep open: the current head addresses a reproduced Android chat-ownership leak, the earlier sibling-surface blocker is fixed, and no discrete correctness defect remains; the compatibility-sensitive storage migration still belongs in human merge review rather than cleanup.

## What This Changes

The PR keys Android composer drafts, media, voice notes, sends, cached sessions, and durable outbox rows to an explicit gateway/agent/session owner and includes that resolved owner in session-deletion events.

## Best Possible Solution

Use one gateway/agent/session owner identity across every composer and chat-state surface, with a release-upgrade migration that never replays ambiguous rows while keeping them visible for explicit recovery.
