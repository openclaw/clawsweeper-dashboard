## Summary

Keep open for maintainer review: the explicit owner invariant is a coherent fix and no discrete correctness defect remains, but the Android Room v4-to-v8 migration deliberately parks ambiguous legacy outbox rows and requires explicit upgrade-policy acceptance plus exact-head migration proof before merge.

## What This Changes

The PR binds Android drafts, media, voice notes, sends, cached sessions, and durable outbox rows to explicit gateway/agent/session ownership and adds the resolved agent owner to session-deletion events.

## Best Possible Solution

Keep one explicit gateway/agent/session owner across transient and persisted Android chat state, fail closed for genuinely ambiguous legacy rows, and merge only after the Android owner approves that recovery contract and exact-head v4-to-v8 upgrade proof succeeds.
