## Summary

Keep open: the PR addresses a real Mattermost interaction-token security bug, but the current patch can break valid button clicks when no configured secret is present and leaves the new signing credential outside supported setup/docs surfaces.

## What This Changes

The PR changes Mattermost interaction signing to use configured or generated per-account secrets instead of deriving the signing secret from the bot token, and adds related schema/tests.

## Best Possible Solution

Land a refreshed security fix, or a narrow replacement, that removes bot-token-derived Mattermost interaction signing while making the replacement secret durable or explicitly fail-closed through supported setup, docs, tests, and restart or split-process proof.
