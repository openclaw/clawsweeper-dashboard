## Summary

Keep this PR open, but it is not ready to merge: removing the current malformed-Windows-path recovery trades one reported regression for another reachable parsing regression. The claimed `partial-json` safety net does not run after `repairJson` has produced valid JSON containing a newline, and the branch still lacks an after-fix OpenClaw write-tool demonstration.

## What This Changes

The PR removes Windows-path-specific escape handling from streamed JSON repair and adds focused tests intended to preserve newline escapes in tool arguments.

## System Context

The AI utilities package repairs and parses JSON emitted while model tool arguments stream in. The resulting object feeds tool execution, including file-writing content where an escaped newline must become a real line break without corrupting path-like text.
