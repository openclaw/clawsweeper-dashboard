## Summary

Keep this PR open, but do not merge yet: the new continuation predicate still turns malformed Windows paths such as `C:\nFOO` into a newline because it rejects uppercase path characters after a valid control-escape letter. The existing real-write-tool regression also still needs redacted after-fix proof, not parser-only checks.

## What This Changes

The PR narrows malformed Windows-path recovery in streaming JSON repair so valid escaped newlines in tool arguments remain real newlines.

## System Context

The AI package repairs streamed JSON before tool arguments are parsed. Its escape-repair decision affects the content passed downstream to tools such as file writing, where a repaired newline becomes file content.
