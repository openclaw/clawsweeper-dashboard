## What This Changes

The issue reports that standalone final MEDIA directives in Weixin replies can reach channel delivery as text without normalized mediaUrl/mediaUrls.

## Best Possible Solution

Keep this as the canonical bug and resolve it by porting the useful final MEDIA text_end handling into the current embedded-agent subscriber path without regressing message_end and tool-media delivery.
