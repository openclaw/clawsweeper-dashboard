## What This Changes

The PR accepts validated content-addressed ClawHub skill-icon URLs and renders them in Control UI search results and skill details, retaining the publisher avatar as the detail-view fallback.

## System Context

ClawHub search and detail responses are fetched by OpenClaw’s infrastructure layer and forwarded through the Gateway-facing UI model. The Control UI then renders those results in its Skills page, where this change adds an optional skill-owned image without replacing the existing publisher identity fallback.
