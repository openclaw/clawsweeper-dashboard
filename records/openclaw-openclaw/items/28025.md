## Summary

## What This Changes

Add a default-off Slack config option that threads agent replies after tool use while leaving purely conversational replies top-level.

## Best Possible Solution

Define one maintainer-approved Slack reply-policy contract for tool-sensitive threading, then update the Slack plugin schema, docs, reply planning/streaming behavior, and focused regression tests together.
