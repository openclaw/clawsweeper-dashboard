## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent transcript-retention mode, and the remaining work is a product/security decision rather than a strict bug fix.

## What This Changes

The issue requests a default-off Discord guild/channel option that transcribes unmentioned audio in requireMention channels, stores the transcript in history, and suppresses any immediate bot reply.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
