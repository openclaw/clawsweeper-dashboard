## Summary

Keep open: current main still only uses Discord audio preflight for mention detection, not silent transcript retention for later mentioned turns, and the requested default-off mode needs maintainer product/security approval before implementation.

## What This Changes

Request a Discord guild/channel `preflightTranscribe` option that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later context.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost, inheritance, schema/docs, and focused requireMention history tests before wiring it into preflight history.
