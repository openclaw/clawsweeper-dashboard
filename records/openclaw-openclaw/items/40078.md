## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent retained-transcript mode for mention-gated skipped audio, and the remaining decision is product/security policy rather than a strict bug fix.

## What This Changes

Add a default-off Discord guild/channel option that silently transcribes unmentioned audio in `requireMention` channels and retains the transcript for later mentioned history context.

## Best Possible Solution

Define a default-off Discord-owned silent transcription policy with explicit consent, retention, cost bounds, inheritance, schema/docs, and focused `requireMention` history tests before implementation.
