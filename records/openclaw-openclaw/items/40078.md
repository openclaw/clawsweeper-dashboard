## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent retained-transcript mode for mention-gated skipped history, and the remaining work needs maintainer product/security direction.

## What This Changes

Issue requests silent Discord audio transcription for unmentioned messages in mention-gated channels so later mentioned turns can use transcripts from history.

## Best Possible Solution

Define a default-off, Discord-owned silent transcription policy with explicit consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring transcripts into skipped-message history.
