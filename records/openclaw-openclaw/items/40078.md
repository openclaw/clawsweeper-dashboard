## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent requireMention-safe silent transcript-retention mode, and the remaining work needs product/security direction before implementation.

## What This Changes

The issue requests a default-off Discord guild/channel option that silently transcribes unmentioned audio in requireMention channels and retains the transcript for later mentioned history context.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance semantics, schema/docs, and focused requireMention history tests before wiring it into the existing preflight/history path.
