## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent history-enrichment mode, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a default-off Discord channel or guild option that silently transcribes unmentioned audio in `requireMention` channels so later mentioned turns can use the transcript from history.

## Best Possible Solution

Define a Discord-owned, default-off silent STT history-enrichment policy that reuses `tools.media.audio`, records bounded transcript provenance for skipped history, and never enqueues an assistant reply unless mention gating passes.

Unclear until maintainers approve the boundary. The narrow maintainable shape is a Discord plugin-owned, schema-backed opt-in that reuses shared STT and bounded history metadata, not an unconditional always-transcribe path.
