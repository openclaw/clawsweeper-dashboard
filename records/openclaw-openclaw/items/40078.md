## Summary

Keep open: current main and v2026.6.11 still do not provide a Discord `preflightTranscribe` or equivalent silent retained-transcript mode for mention-gated history, and the remaining work needs maintainer product/security direction.

## What This Changes

Request a default-off Discord guild/channel option that silently transcribes unmentioned audio in `requireMention` channels, stores the transcript in history, and suppresses agent replies until a later mention.

## Best Possible Solution

Define a default-off Discord-owned history-enrichment policy that runs only after allowlist and size checks, stores bounded transcript provenance or failure state, suppresses replies, and ships with schema, docs, and focused tests.
