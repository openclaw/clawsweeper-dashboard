## Summary

Keep open: current main and v2026.6.11 still lack a default-off silent Discord transcription mode for unmentioned audio in requireMention channels, and the remaining work needs maintainer product/security approval before implementation.

## What This Changes

Add a per-Discord guild/channel `preflightTranscribe` option that silently transcribes unmentioned audio and retains the transcript in history for a later mentioned turn.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with privacy, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring it into the existing preflight/history paths.

## Reproduction Assessment

Yes, at source level: current Discord preflight can transcribe audio for mention detection, but if no mention is found it records pending history from placeholder text and returns. I did not run a live Discord plus STT reproduction in this read-only review.

## Solution Assessment

No, not as a bare boolean alone. The maintainable solution needs a default-off Discord policy with consent, retention, cost, inheritance, schema, docs, and tests rather than only wiring transcription before the skip return.
