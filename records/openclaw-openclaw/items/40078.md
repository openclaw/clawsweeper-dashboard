## Summary

Keep open: current main and v2026.6.11 still only preflight Discord audio for mention detection, not for silent transcript retention in skipped `requireMention` messages, and the requested default-off config needs product/security approval before implementation.

## What This Changes

The issue requests a Discord guild/channel `preflightTranscribe` option that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later mentioned turns.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance semantics, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
