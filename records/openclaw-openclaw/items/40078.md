## Summary

Keep open: current main has Discord audio preflight for direct/mention detection, but it still does not provide the requested opt-in silent retained-transcript mode for unmentioned requireMention channel audio.

## What This Changes

The issue requests silent preflight transcription for unmentioned Discord audio in requireMention channels so later mentioned prompts can use transcript history.

## Best Possible Solution

Define a default-off Discord or shared channel history-enrichment policy that runs only after allowlist and attachment-size checks, stores transcript/error provenance in pending history, never enqueues an assistant reply, and documents the privacy/security behavior.
