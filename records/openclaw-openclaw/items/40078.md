## Summary

Keep open: current main and v2026.6.11 still do not provide a Discord `preflightTranscribe` or equivalent silent transcript-retention mode for unmentioned audio in `requireMention` channels, and the requested fix needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a default-off Discord guild/channel option that transcribes unmentioned audio in `requireMention` channels for later history context without triggering a bot reply.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance semantics, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
