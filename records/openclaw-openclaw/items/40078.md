## Summary

Keep open: current main and the latest release still only use Discord audio preflight for mention detection, while the requested silent transcript retention mode remains a product and security decision.

## What This Changes

Request a Discord guild/channel option that silently transcribes unmentioned audio in requireMention channels and stores transcripts for later mentioned turns.

## Best Possible Solution

Define a Discord-owned, default-off silent audio preflight policy with consent, retention, cost bounds, inheritance rules, docs, and focused requireMention history tests before implementation.
