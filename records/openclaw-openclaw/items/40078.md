## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent no-mention transcript-retention mode, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

Request a default-off per-guild/channel Discord option that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later history context.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
