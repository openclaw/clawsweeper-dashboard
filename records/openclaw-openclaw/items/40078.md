## Summary

Keep open: current main still lacks a Discord `preflightTranscribe` or equivalent silent no-mention transcript-retention mode, and the remaining work is a product/security decision rather than a strict bug fix.

## What This Changes

Request to add an opt-in Discord guild/channel setting that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later mentioned turns without sending a reply.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring it into the existing preflight/history paths.
