## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent transcript-retention mode for unmentioned audio in `requireMention` channels, and the remaining work needs maintainer privacy/security/product direction before implementation.

## What This Changes

Request to add a default-off Discord guild/channel option that silently transcribes unmentioned audio in `requireMention` channels and stores transcripts for later mentioned history context.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance semantics, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
