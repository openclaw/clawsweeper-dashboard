## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent retained-transcript mode for mention-gated history, and the remaining work needs maintainer product/security direction.

## What This Changes

Add a safe, opt-in Discord preflight transcription path that enriches history for unmentioned audio without enqueueing a reply.

## Best Possible Solution

Define a default-off, Discord-owned silent transcription policy with explicit consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before implementation.
