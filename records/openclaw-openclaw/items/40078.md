## Summary

Keep open: current main and v2026.6.11 still lack an opt-in silent retained-transcript mode for unmentioned Discord audio in requireMention channels, and the remaining work is a product/security/config decision rather than conservative cleanup.

## What This Changes

Add a default-off per-guild or per-channel Discord preflight transcription mode that enriches later history context without triggering an agent reply.

## Best Possible Solution

Define a default-off Discord or shared channel history-enrichment policy that runs only after allowlist and attachment-size checks, stores transcript/error provenance in pending history, never enqueues an assistant reply, and documents the privacy/security behavior.
