## Summary

Keep open: current main and v2026.6.11 still only use Discord audio preflight to detect mentions, not to retain transcripts for skipped mention-gated messages, and the requested silent transcription mode needs product/security direction before implementation.

## What This Changes

The issue requests a per-channel silent audio transcription mode for mention-gated Discord channels so later mentioned turns can use transcripts from earlier unmentioned voice messages.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance semantics, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
