## Summary

Keep open: current main and the latest release still only use Discord audio preflight for mention detection/current dispatch, not the requested opt-in silent retained-transcript mode for unmentioned requireMention audio.

## What This Changes

The issue requests a default-off Discord guild/channel option to transcribe unmentioned audio silently, retain the transcript in history, and avoid enqueueing an assistant reply until a later mention.

## Best Possible Solution

Define a default-off Discord or shared channel history-enrichment policy that runs only after allowlist and attachment-size checks, stores transcript/error provenance in pending history, never enqueues an assistant reply, and documents the privacy/security behavior.
