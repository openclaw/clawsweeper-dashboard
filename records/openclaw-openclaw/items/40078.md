## Summary

Keep open: current main and v2026.6.11 still lack a Discord silent no-mention transcript-retention mode, and implementing it needs maintainer product/security direction before code work.

## What This Changes

The issue requests a per-guild or per-channel Discord `preflightTranscribe` mode that silently transcribes unmentioned audio messages when `requireMention` is enabled, then stores transcripts for later mentioned turns.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring it into the existing preflight/history paths.
