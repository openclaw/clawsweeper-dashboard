## Label Justifications

- `P2`: The issue blocks a bounded Discord voice-memo workflow, but it is an opt-in feature/config decision rather than a core outage.
- `impact:message-loss`: Later mentioned turns currently get audio placeholders instead of usable spoken content for earlier unmentioned Discord voice messages.
- `impact:session-state`: The requested behavior changes what derived transcript state is retained in channel history and replayed into a later turn.

- `maturity:stable`: The affected Discord channel surface is scored M4 Stable in `qa/maturity-scores.yaml`.

## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent history-enrichment mode for mention-gated voice notes, and the remaining work needs product/security direction before implementation.

## What This Changes

Add a Discord guild/channel `preflightTranscribe` option that silently transcribes audio-only messages in `requireMention` channels and stores transcripts for later mentioned turns without triggering a bot reply.

## Best Possible Solution

Approve a default-off Discord history-enrichment policy, then implement it in the Discord preflight/history path with explicit consent, retention, provenance, failure placeholders, schema/docs, and focused tests.
