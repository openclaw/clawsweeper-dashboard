## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent retained-transcript mode, and the remaining work needs maintainer product/security direction because it would process unmentioned speech into later history context.

## What This Changes

The issue requests a Discord guild/channel option to silently transcribe unmentioned audio in `requireMention` channels so later mentioned turns can use the transcript from history.

## Best Possible Solution

Define a default-off Discord-owned silent transcription policy with explicit consent, retention, provenance, failure placeholders, schema, docs, and focused `requireMention` history tests before implementation.
