## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent transcript-retention mode for unmentioned audio in requireMention channels, and the remaining work needs product/security direction.

## What This Changes

The issue requests silent preflight transcription for Discord audio messages in requireMention channels so later mentioned turns can use transcripts from prior unmentioned voice messages.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before implementation.
