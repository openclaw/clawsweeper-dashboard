## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent retained-transcript mode for mention-gated history, and the remaining work needs maintainer product/security direction.

## What This Changes

Add a default-off Discord guild/channel preflight transcription mode that silently transcribes unmentioned audio in `requireMention` channels for later history context.

## Best Possible Solution

Define a default-off, Discord-owned silent transcription policy with explicit consent, retention, cost, inheritance, schema, docs, and focused `requireMention` history tests before wiring it into preflight/history.
