## Summary

Keep open: current main and latest release still lack a Discord `preflightTranscribe` or equivalent silent transcript-retention mode for unmentioned audio in `requireMention` guild channels. The source gap is clear, but the requested behavior needs maintainer product/security direction before implementation because it silently processes and retains speech that did not explicitly invoke the bot.

## What This Changes

Add an opt-in Discord guild/channel mode that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later mentioned turns.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost bounds, inheritance semantics, schema/docs, and focused requireMention history tests before wiring it into preflight/history.
