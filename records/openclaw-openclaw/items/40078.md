## Summary

Keep open: current main and v2026.6.11 still lack a Discord opt-in silent transcript-retention mode; the current source only uses audio preflight to detect mentions and records skipped history as placeholder text, so the requested new config/privacy boundary needs maintainer product and security direction.

## What This Changes

The issue requests a per-guild or per-channel Discord `preflightTranscribe` option that silently transcribes unmentioned voice messages and stores transcripts in history for later mentioned turns.

## Best Possible Solution

Define an opt-in Discord guild/channel silent STT mode that stores bounded untrusted transcripts for later mentioned turns without visible replies, with explicit privacy, retention, cost, docs, and regression proof; otherwise document that this workflow is unsupported.
