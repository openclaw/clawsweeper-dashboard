## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent retained-transcript mode for mention-gated history, and the remaining work needs maintainer product/security direction.

## What This Changes

Request a default-off per-guild/channel Discord option that silently transcribes unmentioned audio messages in `requireMention` channels and stores the transcript for later mentioned turns.

## Best Possible Solution

Define a default-off Discord-owned silent transcription policy with explicit consent, visibility, retention, cost, inheritance, schema, docs, and focused `requireMention` history tests before wiring it into preflight/history.
