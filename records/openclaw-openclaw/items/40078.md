## Summary

Keep open: current `main` and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent no-mention transcript-retention mode, and the remaining work needs maintainer product/security direction.

## What This Changes

The issue requests a Discord guild/channel mode that silently transcribes unmentioned audio in `requireMention` channels so later mentioned turns can use transcript history without triggering an immediate bot reply.

## Best Possible Solution

Define a default-off, Discord-owned silent transcription policy with explicit consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring it into the preflight/history paths.
