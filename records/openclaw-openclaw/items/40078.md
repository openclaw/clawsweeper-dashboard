## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent no-mention transcript-retention mode, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

Request to add a per-guild/channel Discord option that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later mentioned turns.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring it into preflight/history.

## Reproduction Assessment

Yes, at source level: current Discord preflight can transcribe audio for mention detection, but if no mention is found it records pending history from placeholder text and returns. I did not run a live Discord plus STT scenario in this read-only review.

## Solution Assessment

No, not as a bare boolean alone. The maintainable solution needs a default-off Discord policy with consent, retention, cost, inheritance, schema, docs, and tests rather than only wiring transcription before the skip return.
