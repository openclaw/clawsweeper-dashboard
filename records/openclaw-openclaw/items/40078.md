## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent no-mention transcript-retention mode, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

The issue requests an opt-in Discord guild/channel setting that transcribes unmentioned audio in `requireMention` channels, stores the transcript for later history context, and suppresses an immediate bot reply.

## Best Possible Solution

Define a default-off, Discord-owned silent transcription policy with explicit consent, retention, cost, inheritance, schema, docs, and focused requireMention history tests before wiring it into preflight/history recording.
