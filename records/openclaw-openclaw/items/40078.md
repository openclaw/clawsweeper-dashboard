## Summary

Keep open: current main and the latest release only use Discord audio preflight to detect mentions or accepted direct audio turns; they still do not provide the requested opt-in silent transcript retention for unmentioned requireMention channel audio.

## What This Changes

Add an opt-in Discord guild/channel preflight transcription mode that enriches later history context for unmentioned audio without starting an agent reply.

## Best Possible Solution

Add a default-off, owner-approved Discord or shared channel history-enrichment policy that runs only after allowlist and media-size checks, stores transcript/error provenance in pending history, and never queues an assistant reply.
