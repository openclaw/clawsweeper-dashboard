## Summary

Keep open: current main and v2026.6.11 still lack a Discord `preflightTranscribe` or equivalent silent no-mention transcript-retention mode, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

Add a per-channel or guild-level option to silently transcribe Discord audio messages before a later mention-gated response.

## Best Possible Solution

Define a Discord-owned, default-off silent transcription policy with explicit allowlist, size, retention, provenance, cost, docs, and focused requireMention history tests before implementation.
