## Summary

Keep open: current main and v2026.6.11 still do not provide a Discord `preflightTranscribe` or equivalent silent retained-transcript mode for mention-gated history; the remaining work is a real but product/security-sensitive new config surface.

## What This Changes

Add an opt-in Discord guild/channel mode that silently transcribes unmentioned audio in `requireMention` channels and stores the transcript for later mention-gated context without sending a bot reply.

## Best Possible Solution

Design this as an explicit Discord-owned opt-in that runs only after the same allowlist, media-size, SSRF, and provider checks as normal audio requests, stores bounded transcript provenance/error state for later history, and keeps assistant replies mention-gated.
