## Summary

Keep open: current main and v2026.6.11 still do not store preflight transcripts for skipped Discord `requireMention` messages, and the remaining change needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a default-off Discord guild/channel `preflightTranscribe` mode that transcribes unmentioned audio messages into history while keeping replies mention-gated.

## Best Possible Solution

Define a Discord-owned, default-off history-enrichment policy, then store bounded transcript/provenance for skipped mention-gated audio without enqueuing replies.
