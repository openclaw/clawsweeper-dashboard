## What This Changes

The PR adds Android session search UI backed by `sessions.list`, controller fallback filtering, runtime/view-model pass-through methods, regenerated native i18n metadata, and new controller tests.

## Best Possible Solution

Keep the server-backed search shape, but make session actions and dialogs resolve from the same visible result source, filter cached archived rows when that is the current offline window, and then add real Android proof for Recent and Archived search.
