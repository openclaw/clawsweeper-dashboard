## What This Changes

This PR updates the GitHub Copilot provider to retain complete encrypted reasoning for an active OpenAI Responses tool continuation while removing session-bound reasoning from restored replay history.

## System Context

The GitHub Copilot plugin receives conversation history and live tool-loop output, sanitizes replayed content, and then prepares the outbound OpenAI Responses payload. The changed boundary determines which reasoning state reaches Copilot, affecting tool-call continuity and resumed-session reliability.
