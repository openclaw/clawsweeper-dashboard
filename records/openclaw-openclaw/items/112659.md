## What This Changes

This PR changes the GitHub Copilot Responses payload path to retain complete encrypted reasoning during an active tool loop while removing reasoning from restored session history.

## System Context

The GitHub Copilot plugin receives agent history and turns it into an OpenAI Responses request. Restored history is sanitized before reuse, while the stream wrapper performs final Copilot-specific payload normalization immediately before the provider request is sent.

## Best Possible Solution

Keep cold-session sanitation and active-loop ciphertext preservation in the GitHub Copilot plugin, but replace mutation-during-iteration with an index-safe filter or decrementing index loop and add coverage for adjacent invalid reasoning items plus their signed assistant-message dependency.
