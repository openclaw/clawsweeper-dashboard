## Summary

Keep open: current main has subagent depth, active-child, timeout, stale-run, provider cooldown, and tool-loop guards, but it still lacks the requested persisted subagent cascade circuit breaker with failure classification, cooldown or half-open state, override, notification, and status surfacing.

## What This Changes

The issue requests a native, configurable subagent spawn circuit breaker that tracks repeated failures by agent or task signature and blocks or cools down further spawns.

## Best Possible Solution

Design one owner-approved subagent health path that persists per-agent/task failure receipts in the canonical state store, classifies failures, gates `sessions_spawn` with structured breaker state, and exposes explicit status/reset/override controls without duplicating provider/session/tool guards.
