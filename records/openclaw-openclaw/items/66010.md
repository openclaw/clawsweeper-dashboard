## Summary

Keep open: current main still has subagent spawn depth, active-child, timeout, outcome, status, provider cooldown, and tool-loop guards, but not the requested persisted subagent/task-signature circuit breaker with classification, cooldown or half-open probing, forced override, notification, and operator-visible breaker state.

## What This Changes

The issue requests a native sub-agent spawn circuit breaker that tracks repeated sub-agent failures, blocks further spawns after a threshold, cools down or resets, allows explicit override, and surfaces state in config, CLI, and Control UI.

## Best Possible Solution

Approve one bounded core-owned subagent health design that persists classified failure receipts, gates sessions_spawn with structured breaker state, and exposes clear reset/override/status controls without duplicating provider, session, or tool-loop guards.
