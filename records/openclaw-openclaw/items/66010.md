## Summary

Keep open: current main and v2026.6.11 have adjacent depth, active-child, timeout, provider-cooldown, and tool-loop guards, but not the requested persisted subagent failure circuit breaker; the production comments make this a maintainer product-design item rather than cleanup-close material.

## What This Changes

The issue requests a native sub-agent circuit breaker with failure tracking, cooldown, override, notification, and status surfacing for repeated sub-agent cascade failures.

## Best Possible Solution

Design one owner-approved subagent health path that persists scoped failure receipts, classifies failures, gates sessions_spawn with structured breaker state, and exposes recovery controls without duplicating provider/session/tool guards.
