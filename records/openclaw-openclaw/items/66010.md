## Summary

Keep open: current main and v2026.6.11 have subagent depth, active-child, timeout, liveness, and adjacent tool-loop guards, but no persisted subagent cascade breaker; issue comments add production cost and failure-classification evidence, so this needs maintainer product design rather than cleanup closure.

## What This Changes

Add a native subagent cascade circuit breaker that tracks repeated subagent failures, blocks further spawns after a threshold, supports cooldown or reset, and surfaces operator recovery state.

## Best Possible Solution

Design one owner-approved subagent health path that persists per-agent/task failure receipts, classifies failures, gates sessions_spawn with structured breaker state, and exposes recovery controls without duplicating provider, session, or tool guards.
