## Summary

Keep open: current main has subagent depth, active-child, timeout, stale-run, orphan-recovery, and announce retry guards, but it still lacks the requested persisted subagent failure circuit breaker with cooldown, override, notification, and status surfacing.

## What This Changes

Add a native circuit breaker for repeated subagent spawn failures, with per-subagent or task-signature counters, configurable thresholds, cooldown/reset behavior, override, and operator visibility.

## Best Possible Solution

Define one core subagent/session-health breaker contract that composes with current depth, concurrency, timeout, task-registry, provider cooldown, and status surfaces before adding persistence and defaults.
