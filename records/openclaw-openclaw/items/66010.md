## Summary

Keep open: current main and v2026.6.11 have subagent depth, active-child, timeout, stale-run, and restart-recovery guards, but they still do not provide the requested persisted sub-agent cascade circuit breaker with failure classification, cooldown or half-open state, override, notification, and status surfacing.

## What This Changes

The issue requests a native sub-agent spawn circuit breaker with consecutive-failure tracking, configurable thresholds and cooldowns, manual override, notification, config schema support, and Control UI or CLI status visibility.

## Best Possible Solution

Define one maintainer-approved subagent health contract that persists per-agent/task failure receipts, classifies failure types, gates sessions_spawn with structured breaker state, and surfaces recovery controls without duplicating existing provider, session, cron, or tool-loop guards.
