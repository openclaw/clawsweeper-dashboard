## Summary

Keep open: current main and the latest release have adjacent subagent depth, active-child, timeout, orphan-recovery, and tool-loop guardrails, but they still lack the requested persisted per-subagent or task-signature circuit breaker with failure classification, cooldown or half-open state, forced override, notification, and CLI/UI state surfacing.

## What This Changes

Request to add a native configurable sub-agent circuit breaker that persists failure counts and cooldowns, blocks repeated `sessions_spawn` attempts, supports override and notification, and exposes breaker state in operator surfaces.

## Best Possible Solution

Define one core subagent health contract for failure receipts, scope, cooldown/half-open behavior, override/reset, and operator surfacing, then implement it through the spawn admission and registry state paths without duplicating provider/session/tool guards.
