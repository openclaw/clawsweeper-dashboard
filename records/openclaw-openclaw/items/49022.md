- **[P1] Keep MEDIA image reads behind trusted provenance:** `src/tui/components/tool-execution.ts:97`
  - body: `mediaPath` comes from `splitMediaFromOutput(entry.text)`, so plain tool-result text can cause the host TUI to read any absolute image-looking local path that passes extension/size checks. Current media delivery avoids this by ignoring media-looking text without structured media and filtering local paths through trusted tool names; this renderer should use that trusted provenance or inline image blocks instead of raw MEDIA text.
  - confidence: 0.86

  - body: Entries are added to the shared `globalRendered` set, but `detachImages()`, `setPartialResult()`, replacement results, and ChatLog pruning never remove them. A retry or updated final result for the same path/fingerprint can then skip the image and show only fallback text or nothing, matching the existing unresolved review thread.
  - confidence: 0.93
