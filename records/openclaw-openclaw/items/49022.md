## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Release dedupe entries when images are detached:** `src/tui/components/tool-execution.ts:96-103`
  - body: This PR records media paths and fingerprints in the ChatLog-wide `globalRendered` set, but `detachImages()`, `setPartialResult()`, and pruning never remove them. Once a result is replaced or a component is pruned, a retry or later delivery of the same image will be skipped even though no cached image is still visible, so supported terminals can lose the inline image and fall back to text/no image. This matches the existing unresolved review thread and still needs a scoped or reversible owner.
  - confidence: 0.91
- **[P1] Constrain MEDIA file reads to trusted media:** `src/tui/components/inline-image.ts:44-69`
  - body: `readMediaImageAsBase64()` reads any absolute path with an image extension in the host TUI process. In a host TUI connected to a container or remote gateway, tool/model output can therefore cause host-local image reads outside the media store; please limit rendering to trusted media payloads/references or add an explicit maintainer-approved boundary before rendering local paths.
  - confidence: 0.78
