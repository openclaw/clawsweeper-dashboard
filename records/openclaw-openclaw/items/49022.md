Full review comments:

- **[P2] Release dedupe keys when images detach:** `src/tui/components/tool-execution.ts:125`
  - body: The shared set lives for the whole ChatLog and entries are only added, while setResult()/setPartialResult() detach cached images and pruning can remove tool components without removing the path/fingerprint. A retry or later result for the same image will hit a stale key and skip rendering, so supported terminals can lose the image or fall back to leftover text. Please scope dedupe to one processed result or make each component release the keys it owns when detached/pruned.
