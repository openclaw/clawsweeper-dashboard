## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Constrain MEDIA reads to trusted artifacts:** `src/tui/components/inline-image.ts:44-61`
  - body: This accepts any absolute MEDIA path and then reads it from the TUI host. Because MEDIA lines come from tool/model output, a plugin or tool result can make the TUI read and inline-render any user-readable image file under the host account, not just images the media pipeline produced; bind this to an OpenClaw-owned media/workspace artifact or another explicit trusted root before reading.
  - confidence: 0.82
- **[P2] Scope image dedupe to live cached images:** `src/tui/components/tool-execution.ts:96-103`
  - body: The ChatLog-wide `globalRendered` set is never released when a component detaches images, receives a new result, or gets pruned. Once a path or fingerprint is recorded, a retry or updated result for the same image skips loading it and can show the MEDIA line or no image on supported terminals; make the entry reversible or keep dedupe local to one processed result.
  - confidence: 0.9
