## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Constrain MEDIA reads to trusted roots:** `src/tui/components/inline-image.ts:69`
  - body: `readMediaImageAsBase64` reads any absolute image path extracted from tool output as long as it has an allowed extension and size. That is broader than the existing media-root contract, so a model/tool result could make the host TUI read and render a local image outside OpenClaw-managed media roots; route this through the existing local media access policy or only render trusted inline image payloads.
  - confidence: 0.84
- **[P2] Make image dedupe ownership reversible:** `src/tui/components/tool-execution.ts:96`
  - body: Adding paths/fingerprints to the shared `globalRendered` set is permanent for the ChatLog lifetime. After a component detaches images, retries, updates, or pruning can leave a stale entry that makes the next result skip the image and fall back to raw MEDIA text or no image, so dedupe needs to be scoped to the active processed result or remove entries when their cached image is no longer live.
  - confidence: 0.91
- **[P3] Drop the release-owned changelog edit:** `CHANGELOG.md:45`
  - body: OpenClaw's changelog is release-generated, so normal feature PRs should not edit `CHANGELOG.md` directly. Keep the release-note context in the PR body or eventual squash message and let the release workflow generate the changelog entry.
  - confidence: 0.88
