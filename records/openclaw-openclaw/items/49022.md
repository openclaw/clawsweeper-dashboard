  - body: Current main depends on and imports `@earendil-works/pi-tui`, but this branch still imports `@mariozechner/pi-tui` without adding that package to the manifest. - **[P2] Keep dedupe entries tied to live images:** `src/tui/components/tool-execution.ts:96`
  - body: `globalRendered` is shared for the ChatLog lifetime and entries are added here without being removed when this component detaches cached images, receives a retry, or is pruned. After one render, a later result with the same path or fingerprint can be skipped and show the MEDIA text or no image even though it should render, so the dedupe needs to be result-scoped or reversible.
  - confidence: 0.9
- **[P1] Do not read host files from MEDIA text:** `src/tui/components/tool-execution.ts:97`
  - body: This path parses MEDIA directives out of tool-result text and reads the referenced absolute path from the TUI host. In Docker or remote-gateway setups, model/tool-controlled text can point at unrelated local host images and cause them to be read and rendered; route this through trusted media payloads or an OpenClaw-owned media root instead of arbitrary output text.
  - confidence: 0.84
