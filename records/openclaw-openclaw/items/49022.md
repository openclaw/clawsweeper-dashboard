## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Preserve fallback text when images cannot render:** `src/tui/components/tool-execution.ts:115-130`
  - body: In the `canRender` branch, image blocks that are omitted, lack `data`, or otherwise cannot produce an `Image` component never reach the existing placeholder path. On an image-capable terminal this can turn the current `[image/png ...]` fallback into blank output, so please emit the placeholder whenever a block is not actually rendered.
  - confidence: 0.86
- **[P2] Make image dedupe reversible:** `src/tui/components/tool-execution.ts:92-96`
  - body: The shared `globalRendered` set is append-only for the ChatLog lifetime, but `setPartialResult`, replacement `setResult`, and pruning detach cached image components without removing their path/fingerprint keys. A retry or updated result for the same image can therefore be skipped even though no live image remains; scope dedupe to one processed result or release keys when images detach.
  - confidence: 0.88
