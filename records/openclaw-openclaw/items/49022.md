  - body: This path parses `MEDIA:` directives from tool-result text and then reads the referenced absolute path from the TUI host.   - confidence: 0.84

  - body: `globalRendered` is append-only for the ChatLog lifetime, but `setPartialResult()`, `setResult()`, and pruning detach or replace the cached image components without removing the path/fingerprint.
