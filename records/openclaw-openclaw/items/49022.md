  - confidence: 0.92

  - body: The PR feeds media paths parsed from tool text into a local file reader with size/extension/symlink checks but no trusted-root or structured-source check. Because `MEDIA:` directives can originate in model/tool text, a forged directive can make the TUI read and render arbitrary host image files that match the allowlist; use structured generated attachments or trusted media roots before reading.
