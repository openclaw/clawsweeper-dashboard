  - body: `splitMediaFromOutput()` accepts local MEDIA directives from tool-result text, and this PR then reads each parsed image path with only extension/size/symlink checks.   - confidence: 0.9
- **[P2] Make cross-result image dedupe reversible:** `src/tui/components/tool-execution.ts:96`
  - body: The shared `globalRendered` set is append-only for the ChatLog lifetime, so once a path or fingerprint is recorded, later retries, replacement results, or pruned components can skip loading the image even though the current result should render it. Scope dedupe to one processed result or remove entries when cached images are detached/pruned.
  - confidence: 0.91
