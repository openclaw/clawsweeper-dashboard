## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Restrict MEDIA image reads to trusted media roots:** `src/tui/components/tool-execution.ts:97`
  - body: `splitMediaFromOutput()` accepts local MEDIA paths from tool-result text, and this line then reads that path on the TUI host. In a host TUI connected to a Docker or remote gateway, a crafted `MEDIA:/.../secret.png` can make the client read a host-local image outside the agent media store; keep the text fallback unless the media came from a trusted attachment/generated-media source or use the existing base64 image block.
  - confidence: 0.84
- **[P2] Make image dedupe entries reversible:** `src/tui/components/tool-execution.ts:96-103`
  - body: The shared `globalRendered` set is never cleared when `setPartialResult()`, a replacement `setResult()`, or ChatLog pruning detaches the component that owned an image. After a path or fingerprint is recorded once, a retry or updated result for the same image can skip rendering and leave users with no current image; scope dedupe to one processed result or remove entries when their cached image is detached/pruned.
  - confidence: 0.92
