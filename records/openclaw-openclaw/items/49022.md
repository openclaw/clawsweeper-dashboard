- **[P1] Gate MEDIA reads through trusted media policy:** `src/tui/components/tool-execution.ts:97`
  - body: This reads every parsed local `MEDIA:` path from tool-result text in the host TUI. Current media parsing treats local-looking paths as structure while approval happens downstream, so this can make a tool result read and render any readable host image path; route it through the existing trusted local-media/allowed-root boundary or require trusted inline image blocks before stripping fallback text.
  - confidence: 0.9
- **[P2] Make image dedupe reversible:** `src/tui/components/tool-execution.ts:96`
  - body: The shared `globalRendered` set is append-only for the `ChatLog` lifetime, but `setResult()`, `setPartialResult()`, and pruning can detach the only component that owns that image. A retry or updated result with the same path/fingerprint will then skip rendering and may leave users with only stripped text or no image, matching the unresolved review thread.
  - confidence: 0.92
