## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Restrict MEDIA reads to trusted media roots:** `src/tui/components/inline-image.ts:44`
  - body: `processResult` feeds `MEDIA:` payloads from tool output into this helper, and this helper accepts any absolute local path. In host TUI plus Docker or remote gateway setups, a crafted tool/model result can cause the TUI process to read and render a host-local image outside OpenClaw media storage. Please gate this through canonical media references, the media store, or an explicit trusted root before rendering.
  - confidence: 0.78
- **[P2] Make image dedupe ownership reversible:** `src/tui/components/tool-execution.ts:96`
  - body: The shared `globalRendered` set only grows, while `setResult`, `setPartialResult`, and chat-log pruning can detach the component that owned the image. A retry or updated final result for the same path/fingerprint then skips rendering and can show the `MEDIA:` line or no image even though the current result should render. Scope dedupe to one processed result or remove keys when cached images are detached/pruned.
  - confidence: 0.9
