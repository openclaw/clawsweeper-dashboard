- **[P2] Scope image dedupe to live rendered images:** `src/tui/components/tool-execution.ts:92-96`
  - body: `globalRendered` is shared for the whole ChatLog and entries are never removed when this component detaches cached images, receives a partial retry, replaces a final result, or is pruned. After one render records a path/fingerprint, the next valid result for the same image can skip loading and show the MEDIA line or no image; make the dedupe per processed result or release entries when the owning cached image is detached/pruned.
  - confidence: 0.92

  - body: This reads any parsed MEDIA path from tool-result text as a host-local image file. `splitMediaFromOutput` validates path shape, not that the path was produced by the current tool or lives under a managed media root, so less-trusted tool output can trigger local image reads; constrain this to trusted generated-media provenance or render only already-supplied image blocks.
  - confidence: 0.78
