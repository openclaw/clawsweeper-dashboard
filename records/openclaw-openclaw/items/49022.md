## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Constrain MEDIA image reads to trusted roots:** `src/tui/components/inline-image.ts:44`
  - body: `readMediaImageAsBase64` accepts any absolute path from tool-result text and reads it in the host TUI process when the terminal supports images. In remote/Docker or untrusted-tool setups, tool output can make the host read and encode local image files that merely match extension and size checks; this should be limited to trusted media-store references or structured image blocks instead of arbitrary absolute paths.
  - confidence: 0.82
- **[P2] Make image dedupe reversible:** `src/tui/components/tool-execution.ts:125`
  - body: The shared `globalRendered` set is append-only for the ChatLog lifetime, but `setPartialResult`, `detachImages`, and chat-log pruning remove image components without deleting the corresponding fingerprint. A retry or updated final result for the same image can then skip rendering and leave users with only the fallback text or no image, so dedupe ownership needs to be per processed result or reversible when images detach.
  - confidence: 0.9
- **[P3] Remove the release-owned changelog entry:** `CHANGELOG.md:45`
  - body: OpenClaw release generation owns `CHANGELOG.md` for normal PRs. Please keep the user-visible release-note context in the PR body or squash message and drop this direct changelog edit so the release process can generate the final entry.
  - confidence: 0.93
