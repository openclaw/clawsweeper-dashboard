## Summary

Keep open: current main and the latest release still expose generic context-overflow copy to users, while the token/model/session facts are only logged or kept in metadata. ## What This Changes

The issue asks OpenClaw to replace generic context-overflow messages with actionable session, token-count, model-limit, overage, and recovery guidance.

## Best Possible Solution

Add one shared, redaction-aware overflow diagnostic formatter and wire it through the runner, precheck result handling, shared formatter/sanitizer, and auto-reply fallbacks with focused regression coverage.
