## Summary

Keep open: current main and the latest release still surface generic context-overflow text in the runner, precheck, shared formatter/sanitizer, and auto-reply fallback paths; existing merged work adds logs/session status but not the requested user-visible session, model, token-count, limit, and overage details.

## What This Changes

The issue asks for context overflow errors to include session/channel identity, token counts, model limit, overage, and actionable recovery guidance.

## Best Possible Solution

Add a shared, redaction-aware context-overflow diagnostic formatter and wire it through runner terminal errors, precheck/attempt handling, shared formatting/sanitization, and auto-reply fallbacks with focused regression tests.
