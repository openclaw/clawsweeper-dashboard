## What This Changes

Improve context-overflow failures with actionable session, model-limit, usage, and overage diagnostics.

## Best Possible Solution

Add one shared overflow-diagnostic formatter that receives a redacted human-facing session label, provider/model, effective context budget, and explicitly observed or estimated usage; show overage only when comparable values are available, wire every terminal overflow path through it, and cover sanitization plus unknown-data fallbacks without filesystem polling.
