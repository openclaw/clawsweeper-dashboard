## Summary

Keep open: current main and v2026.6.11 still surface generic user-visible context-overflow messages, while related work covers logs, recovery, measured counts, or telemetry rather than the requested safe visible diagnostics.

## What This Changes

The issue asks OpenClaw to replace generic context-overflow copy with user-visible diagnostics including session/channel identity, token size, model limit, overage, and concrete recovery actions.

## Best Possible Solution

Define one shared redaction-aware context-overflow diagnostic formatter and wire it through the runner, precheck, shared formatter/sanitizer, and auto-reply fallback paths with focused visible-text and metadata tests.
