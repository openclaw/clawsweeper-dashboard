## Summary

Keep open: current main and v2026.6.11 provide typing, acknowledgment reactions, and opt-in lifecycle status reactions, but they still do not send, track, delete, or edit the requested standalone Telegram processing message. The related open presence PR uses reactions and typing, is currently conflicting, and does not safely supersede this distinct product choice.

## What This Changes

Add an opt-in Telegram processing message that appears while a turn runs, is deleted after a successful reply, and is edited or replaced on failure.

## Best Possible Solution

Decide whether reactions provide sufficient visibility; if not, add a disabled-by-default Telegram-owned placeholder with explicit rules for concurrency, typing and reaction coexistence, successful cleanup, failure replacement, and upgrade-safe defaults.
