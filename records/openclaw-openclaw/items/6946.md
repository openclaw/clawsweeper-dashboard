- `impact:ux-friction`: Subtle typing and reaction feedback can leave users uncertain whether a long Telegram turn is still processing.

## Summary

Keep open: current main still lacks the requested standalone Telegram placeholder lifecycle, and the related typing, acknowledgment-reaction, and phased-presence work does not clearly replace it. The remaining blocker is a product decision about whether another visible feedback mode and configuration contract should exist.

## What This Changes

Add an opt-in Telegram processing placeholder that appears while a turn runs and is deleted or changed when processing finishes.

## Best Possible Solution

Adopt one Telegram-owned presence contract; if a standalone placeholder is chosen, make it opt-in and delayed, track it per accepted inbound turn and topic, remove it after successful final delivery, apply bounded failure and cancellation behavior, and document its interaction with typing, reactions, and streaming.
