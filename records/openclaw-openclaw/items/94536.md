## What This Changes

Fix the commitment workflow so a heartbeat does not mark a due Telegram reminder sent unless the user actually receives the reminder.

## System Context

An agent reply can create an inferred commitment stored with a target session and due window. The heartbeat scheduler selects due records, prepares durable outbound delivery, updates commitment state, and relies on the channel path to make the reminder visible to the user.

Confirm whether inferred commitments remain a supported core workflow; if they do, trace every durable-delivery result to make state transition to `sent` contingent on visible delivery and add an end-to-end regression covering this second outcome, otherwise provide a documented migration that prevents stale commitment records from silently claiming delivery.
