## What This Changes

Report that `runWithModelFallback` reuses one caller abort signal across fallback attempts, causing already-expired deadlines to be reported as provider timeouts.

## Best Possible Solution

Define and test one cancellation contract: preserve caller-wide cancellation and total-budget limits, create only bounded attempt-local timing where appropriate, and emit a distinct exhausted-deadline outcome instead of attributing pre-expired attempts to individual providers.
