## What This Changes

The PR adds a bounded, second-use-admitted cache of synchronous SQLite prepared statements for shared and file-backed agent state databases, and updates tests to measure query execution rather than statement preparation.

## System Context

OpenClaw’s synchronous Kysely facade compiles state and agent database queries into `node:sqlite` statements used by gateway, CLI, and session flows. The proposed cache sits between compiled Kysely queries and SQLite execution, retaining hot statements until the database owner clears them during its lifecycle.
