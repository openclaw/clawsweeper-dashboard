## What This Changes

This PR adds a bounded, second-use prepared-statement cache for repeated synchronous Kysely queries on OpenClaw’s shared and per-agent SQLite state databases.

## System Context

OpenClaw compiles synchronous state queries through a Kysely adapter and executes them using Node’s `node:sqlite` database handles. The adapter feeds shared state and per-agent state callers, so statement preparation, invalidation, and handle closure affect gateway-side state operations.
