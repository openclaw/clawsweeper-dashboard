## What This Changes

This PR caches repeatedly used synchronous `node:sqlite` prepared statements for OpenClaw’s file-backed shared and per-agent state databases, reducing repeated native SQL compilation.

## System Context

OpenClaw’s shared state database and per-agent databases use synchronous Kysely helpers to execute SQLite queries. The PR adds a bounded cache below those helpers, so database open/close, repair, rollback, and eviction paths must release cached native statements before a handle is discarded.
