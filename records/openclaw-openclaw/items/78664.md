## What This Changes

This PR adds an internal cache for cloned provider-normalized tool-schema parameters during repeated embedded-agent turns, using it only for recognized bundled compatibility normalizers and bypassing custom provider hooks.

## System Context

Embedded-agent turns build provider-facing tool schemas before calling a model. This change sits between prepared provider runtime resolution and the agent tool payload, attempting to reuse normalized schema parameters while rebuilding each turn’s executable tool objects and policy state.

## Architecture Diagram

  D -->|No| F[Run custom normalizer]

## Best Possible Solution

Keep cache-key classification in a core-internal provider-runtime module, remove the public facade export, and retain the documented behavior that third-party provider normalizers participate only through the existing normalization hook.
