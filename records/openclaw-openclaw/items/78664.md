## What This Changes

This PR adds an internal cache for cloned provider-normalized tool-schema parameters during repeated embedded-agent turns, reusing it only for recognized bundled compatibility normalizers.

## System Context

Embedded agents build tools for each turn, then pass provider-facing schema parameters through provider compatibility normalizers before an LLM request. This change sits between tool construction and provider transport, attempting to reuse only schema data while preserving fresh execute closures, policy, approvals, and tool objects.
