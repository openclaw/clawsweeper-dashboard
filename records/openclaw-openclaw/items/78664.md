## Summary

Keep this PR open for maintainer review. It has credible terminal proof and a bounded performance goal, but it currently turns an internal cache-classification helper into a new public plugin-SDK callable without an established or maintainer-approved long-term contract.

## What This Changes

This PR caches cloned provider-normalized tool-schema parameters for repeated embedded-agent turns when a bundled DeepSeek, Gemini, or OpenAI compatibility normalizer is used, while custom provider normalizers bypass the cache.

## System Context

Embedded agent turns construct tools and normalize their schemas for the selected provider before model transport. The proposed cache sits in that normalization path and reuses only schema parameters, while preserving fresh tool execution closures and per-turn policy state.

## Best Possible Solution

Keep the optimization private to the bundled provider-compatibility implementation, or obtain explicit owner approval for a documented provider cache-key contract with compatibility tests before exposing any plugin SDK API.
