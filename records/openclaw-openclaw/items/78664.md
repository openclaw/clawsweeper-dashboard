## Best Possible Solution

Land the keyed internal cache once CI is clean, keeping custom provider normalizers uncached and avoiding any new public provider hook or operator flag.

## Solution Assessment

Yes; this is the narrowest maintainable shape I saw because it caches only cloned schema parameters behind known pure tool-compat normalizers instead of caching full tools or adding a provider plugin API.
