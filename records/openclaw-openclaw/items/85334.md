## Summary

Keep open: current main and the latest release still contain the bundled plugin load-path writers and doctor repair ordering behind the reported loop, while the linked closing PR remains open and unmerged.

## What This Changes

This issue asks OpenClaw to stop update and doctor repair from writing current bundled plugin directories into `plugins.load.paths` and then warning on those same paths.

## Best Possible Solution

Review and land or explicitly supersede https://github.com/openclaw/openclaw/pull/85358 with proof that bundled path writers skip current packaged bundled roots and doctor cleanup runs after any repair step that could re-add them.
