## Summary

Keep this PR open: the missing reset boundary is real, but the current head still exposes reset capability to non-compaction hooks, flushes a queued reset before context-engine native follow-up compaction finishes, and provides only pre-fix runtime logs rather than after-fix behavior proof.

## What This Changes

The PR adds a deferred, current-session-scoped `resetSession(reason?)` API to embedded-agent hook contexts and drains requested resets from run, direct-compaction, and context-engine compaction lifecycles.

## Best Possible Solution

Expose the reset request only to `after_compaction` contexts, drain it once after the complete owning lifecycle—including any native follow-up compaction—then add a dual-compaction regression and redacted live logs showing reset rotation plus a successful next turn.
