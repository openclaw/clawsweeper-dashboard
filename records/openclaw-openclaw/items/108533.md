## Summary

Keep open: the current head addresses several earlier lifecycle findings, but it still exposes reset capability to non-compaction hooks, retains an early subscription-path flush, and expands the ordinary-run import graph; the rollout evidence also does not demonstrate an actual deferred reset followed by a successful next turn.

## What This Changes

The PR adds a current-session-scoped deferred reset API to embedded compaction hooks and threads reset queue ownership through run, compaction, subscription, and native harness paths.

## Best Possible Solution

Expose the reset method only on after-compaction hook contexts from a small leaf module, route every active-run emitter through one lifecycle-owned queue that drains after all run and native-compaction cleanup, and prove session rotation plus a successful next turn on a real gateway.
