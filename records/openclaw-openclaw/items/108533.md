## Summary

Keep this PR open: the core lifecycle approach is promising, but the current head still exposes a reset that cannot succeed for model-locked sessions, adds a heavy compaction dependency graph to every embedded run, and lacks proof of an actual post-compaction session rotation and successful next turn.

## What This Changes

Adds a deferred, current-session-scoped reset API to successful embedded after-compaction hook contexts and threads its queue through run, direct compaction, harness, and subscription paths.

## Best Possible Solution

Define the after-compaction reset capability in a small leaf module, expose it only when the current session can actually be reset, preserve lifecycle-owned deferred draining, and prove real session rotation plus next-turn continuity.

## Solution Assessment
