## Summary

## What This Changes

Adds a current-session-scoped deferred `resetSession` API to after-compaction hook contexts and propagates reset commits through embedded, harness, gateway, reply, memory, follow-up, and cron lifecycles, with regression tests and a startup-memory CI ceiling.

## Best Possible Solution

Expose `resetSession` only for successful after-compaction dispatches backed by a caller-owned post-run reset queue, preserve that queue across all trusted built-in harness paths, withhold the API from legacy direct delegates unless ownership is explicitly threaded, refresh every caller from the committed session row, and prove the complete lifecycle on the latest head.
