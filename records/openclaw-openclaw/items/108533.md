## Summary

This PR should remain open: the current head still strips the lifecycle reset queue from the bundled Codex harness, so production Codex compaction hooks cannot use the new API, and the permanent plugin API authority boundary still needs maintainer approval. The available live rollout evidence covers earlier patch heads rather than the current head.

## What This Changes

Adds a deferred current-session reset API for after-compaction hooks, propagates reset commits through embedded, harness, reply, cron, command, and gateway lifecycles, and adds a deterministic live tool-failure abort guard.

## Best Possible Solution

Define one host-owned, current-session-scoped reset capability for successful, resettable after-compaction contexts; keep the raw queue private, bridge every supported bundled harness including Codex through the same typed host seam, and separate the independent live tool-failure guard into its own reviewed change.
