The PR adds a deferred, current-session-scoped reset API for after-compaction hooks and threads reset lifecycle handling across embedded runs, compaction callers, Codex, Copilot, session notifications, and follow-up bookkeeping.

Land a narrow after-compaction-only, reason-scoped API with caller-owned deferred flushing, authoritative state reload or bookkeeping suppression after every reset commit, no raw lifecycle queue crossing plugin or context-engine boundaries, focused compatibility tests, and live reset-rotation proof.
