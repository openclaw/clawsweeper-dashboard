## Summary

Keep open: current main still lacks the requested hook capability, but the latest patch exposes session reset outside the compaction lifecycle, expands the ordinary run import graph, and does not yet prove a successful deferred reset and next turn in a real runtime.

## What This Changes

Adds a current-session-scoped deferred `resetSession(reason?)` API to embedded hook contexts, threads reset queues through compaction lifecycles, and adds regression coverage.

## Best Possible Solution

Expose the reset capability only on `after_compaction` contexts from a small leaf module, keep the queue owned by the outermost active lifecycle, flush after all run and compaction handles clear, and document and prove the supported plugin contract with a successful reset and next turn.
