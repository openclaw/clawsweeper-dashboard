## Summary

Keep open: the current head retains the unsupported schema-12 compatibility shim and an undocumented public plugin-hook API, while its privileged reset-authority contract and exact-head runtime behavior remain unapproved and insufficiently proven.

## What This Changes

The branch adds a deferred current-session reset API for after-compaction hooks and threads reset lifecycle handling across embedded runs, Codex and Copilot harnesses, reply and cron persistence, gateway compaction, loop detection, and agent database compatibility.

## Best Possible Solution

Land a narrowly owned after-compaction reset contract only after removing the schema-12 shim and unrelated behavior, documenting exact availability and deferred semantics, preserving host-owned reset authority, and proving the exact head through a real compaction-reset-follow-up lifecycle.
