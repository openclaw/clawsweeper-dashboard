## Summary

## What This Changes

The PR adds a current-session-scoped deferred `resetSession(reason?)` hook API and threads reset queues through embedded-run and compaction lifecycle paths with regression tests.

## Best Possible Solution

Use one queue owned by the outermost run or manual-compaction lifecycle, thread it through context-engine delegation and every direct/native compaction emitter, flush only after active handles and native follow-up work are complete, and expose the API only on the maintainer-approved hook contexts.
