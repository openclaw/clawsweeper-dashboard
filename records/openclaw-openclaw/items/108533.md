## Summary

Keep this PR open: the missing post-compaction recovery capability is real, but the current patch passes raw reset authority through Copilot-specific core exceptions, expands the public plugin contract without matching docs/surface proof, and still lacks live evidence of a completed deferred reset followed by a successful next turn. The scoped plugin policies require public contract changes to remain generic and documented. ([github.com](https://github.com/openclaw/openclaw/blob/main/extensions/AGENTS.md))

## What This Changes

Adds a deferred, current-session-scoped `resetSession(reason?)` API to successful after-compaction hook contexts across core, Codex, and Copilot lifecycle paths.

## Best Possible Solution

Use a generic host-owned after-compaction callback that constructs the bound reset API inside core, never hand raw reset requests to a harness plugin, document the exact plugin contract, add a published-SDK surface test, and prove reset completion plus a successful next turn on a real runtime.
