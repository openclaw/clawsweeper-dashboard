## Summary

Keep this PR open but do not merge the current head. Most earlier lifecycle defects were repaired, but the subscription compaction path still advertises a reset that cannot succeed for model-locked sessions; the permanent plugin API also needs owner approval and stronger after-fix lifecycle proof.

## What This Changes

The PR adds a deferred, current-session-scoped `resetSession(reason?)` API to embedded after-compaction hook contexts and threads its reset queue through direct, queued, run-owned, native-harness, and subscription compaction paths.

## Best Possible Solution

Support the method only on successful, resettable after-compaction contexts; propagate the model-lock fact through the subscription lifecycle, keep one lifecycle-owned deferred queue, and require live evidence of post-run rotation and continuation before landing the owner-approved contract.
