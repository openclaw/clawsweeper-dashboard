## Summary

Keep open: the current head retains the prior hook-scope blocker and adds a native-harness drain path that can reset while its own run is still active; the posted rollout evidence also does not demonstrate successful deferred session rotation.

## What This Changes

The PR adds a current-session-scoped deferred `resetSession(reason?)` API to embedded hook contexts, wires reset queues through compaction paths, and adds focused regression coverage.

## Best Possible Solution

Expose the capability only on successful `after_compaction` contexts, bind it to the current session, and carry every request to the outermost lifecycle owner for draining only after active run and compaction handles are released.
