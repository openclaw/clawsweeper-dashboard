## Summary

Keep open. Current main supports Control UI file selection, pasted images/data URLs, drag-and-drop attachments, previews, removal, and `chat.send` attachment serialization, but it still has no screenshot/scissors capture entry point; adding one remains a product and security decision rather than conservative cleanup.

## What This Changes

Requests a Control UI chat composer screenshot button that captures a screen region, previews it as an attachment, and sends it through `chat.send.attachments`.

## Best Possible Solution

If accepted, add a narrow static screenshot-capture composer flow that reuses the existing attachment payload store, preview/removal tray, and `chat.send` serialization, with explicit permission, cancel, privacy, and failure-state behavior.
