## Summary

## What This Changes

The PR adds `memory.qmd.limits.candidateLimit`, validates it as a positive integer, and forwards it to QMD query reranking through both the direct CLI and mcporter-backed query path.

## System Context

Memory Core is OpenClaw’s bundled memory plugin: it resolves `memory.qmd` settings, runs QMD searches, and returns recalled Markdown snippets to the agent loop. This setting sits between persisted OpenClaw configuration and QMD’s query API, affecting the latency and recall breadth of opt-in query-mode searches.
