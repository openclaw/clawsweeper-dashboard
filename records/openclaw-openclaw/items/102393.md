## What This Changes

The issue reports that malformed managed outgoing image data URLs can trigger catastrophic regex backtracking and stall gateway reply handling.

## Best Possible Solution

Replace the gateway data URL regex with linear parsing, preferably reusing the existing media-core inline image validation contract where semantics fit, then add regression coverage for semicolon-heavy malformed data URLs and separately prove or split any sibling regex fixes.
