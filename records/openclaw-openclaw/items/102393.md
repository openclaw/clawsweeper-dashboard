## Summary

Keep open: current main and the latest release still contain the nested-repeat managed-image data URL regex on the gateway reply path, and the report is a source-backed gateway availability/security bug. The fix shape is narrow, but maintainer security handling should be decided before public repair automation runs.

## What This Changes

The issue reports that malformed managed image data URLs can trigger catastrophic regex backtracking during gateway reply image preparation.

## Best Possible Solution

Replace the managed-image data URL regex with linear parsing, preferably reusing the media-core inline image validation contract where semantics fit, then add a bounded malformed-data-url regression and split sibling regex fixes unless they have matching repro proof.
