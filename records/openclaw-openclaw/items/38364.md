## Summary

Keep open: current main has partial mitigations, but it still lacks a typed Control UI/Gateway reply-to metadata contract, and the no-output completion behavior belongs to a broader open final-delivery decision.

## What This Changes

The issue requests structured reply-to metadata from Control UI/chat surfaces to agent sessions and less misleading user-visible completion text when a run has no meaningful assistant output.

## Best Possible Solution

Define one typed Control UI/Gateway inbound reply metadata contract that reaches agent runtime context without polluting persisted user text, and let the durable final-fallback delivery rules be owned by https://github.com/openclaw/openclaw/issues/87561.
