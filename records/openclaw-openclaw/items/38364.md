## Summary

Keep open: current main has the Control UI reply affordance and a generic hidden runtime-context carrier, but it still does not expose structured reply-target metadata to agent sessions, and the no-output terminal-state behavior remains tied to a broader delivery contract decision.

## What This Changes

The issue asks OpenClaw to preserve structured reply-to metadata from Control UI/chat surfaces into agent sessions and replace misleading no-output completion notices with clearer terminal-state semantics.

## Best Possible Solution

Keep this as a manual umbrella until maintainers accept or replace the structured reply-metadata contract and settle the durable final-fallback/no-output delivery semantics.
