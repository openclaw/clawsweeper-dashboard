## Summary

Keep open: current main has useful mitigations, but it still lacks a typed Control UI/Gateway reply-to contract and the no-output completion half is still owned by broader final-delivery work.

## What This Changes

The issue asks for Control UI/WebChat replies to carry structured reply-to metadata into agent sessions and for no-output completions to show a clearer user-facing terminal state.

## Best Possible Solution

Define one typed Control UI/Gateway inbound reply metadata contract that reaches the agent as runtime context without polluting persisted user text, and route final no-output delivery semantics through https://github.com/openclaw/openclaw/issues/87561.
