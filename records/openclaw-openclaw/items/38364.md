## Summary

Keep open: current main has quote-style Control UI reply UX and a hidden text runtime-context carrier, but it still lacks a structured Control UI/Gateway reply-to contract and the no-output completion UX is covered by a separate unresolved final-fallback contract.

## What This Changes

The issue asks for structured reply-to metadata to reach agent sessions and for Control UI no-output terminal notices to avoid looking like successful empty replies.

## Best Possible Solution

Choose one structured current-turn reply metadata contract for the Control UI, Gateway, and agent boundary, and keep no-output/final fallback semantics under the durable delivery contract rather than solving both as one ad hoc UI patch.
