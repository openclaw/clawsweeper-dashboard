## Summary

Keep open: current main has the Control UI right-click Reply affordance and the hidden runtime-context carrier from https://github.com/openclaw/openclaw/pull/100272, but `chat.send` and `CurrentInboundPromptContext` still do not carry a structured reply-to metadata contract, and final/no-output delivery semantics remain product-owned by https://github.com/openclaw/openclaw/issues/87561.

## What This Changes

The issue requests structured reply-to metadata from Control UI/chat surfaces into agent sessions and clearer user-facing handling for runs that complete without meaningful assistant text.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/90745 for structured current-turn reply metadata, keep durable final/no-output semantics in https://github.com/openclaw/openclaw/issues/87561, then close this issue once both halves are implemented or explicitly split.
