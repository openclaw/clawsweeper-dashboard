## Summary

Keep open: current main has useful partial progress, but it does not finish the central request. Control UI right-click Reply currently turns the target into a Markdown quote, and https://github.com/openclaw/openclaw/pull/100272 routes existing inbound context through hidden runtime context, but `chat.send` still has no structured reply target field and the no-output/final-fallback behavior is still covered by the open maintainer contract item at https://github.com/openclaw/openclaw/issues/87561.

## What This Changes

Expose Control UI reply-to metadata as structured agent-session context and make no-output completion states clearer to users.

## Best Possible Solution

Define one structured reply metadata contract from Control UI `chat.send` into runtime context, then resolve misleading no-output/final fallback wording through the durable final fallback delivery contract.
