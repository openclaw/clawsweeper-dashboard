## Summary

Keep open: current main has shipped useful pieces, but it still lacks a structured Control UI reply-target contract, and the no-output/final-fallback half remains owned by broader open delivery semantics work.

## What This Changes

The issue asks for structured reply-target metadata from Control UI chat turns and clearer user-facing handling when a run completes with no meaningful assistant output.

## Best Possible Solution

Keep this open until maintainers either land or replace the structured reply metadata contract and explicitly route the no-output half to the durable final-fallback delivery issue.
