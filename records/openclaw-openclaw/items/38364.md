## Summary

Keep open: current main has the Control UI right-click quote affordance and a generic hidden runtime-context carrier, but it still lacks a structured reply-target field for the agent handoff, and the no-output/final-fallback behavior is still owned by an open delivery-contract issue.

## What This Changes

The issue asks OpenClaw to expose structured reply-to metadata from chat surfaces to agent sessions and avoid misleading completion notices when no useful assistant reply is produced.

## Best Possible Solution

Keep this open as a maintainer-tracked contract item until the reply metadata direction is resolved through https://github.com/openclaw/openclaw/pull/90745 and final fallback delivery semantics are resolved through https://github.com/openclaw/openclaw/issues/87561.
