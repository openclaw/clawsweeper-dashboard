## What This Changes

The issue reports LINE mixed text plus Markdown-table replies delivering only text while the table Flex message is dropped when Push quota is exhausted.

## Best Possible Solution

## Solution Assessment

Yes. The narrow maintainable fix is to batch eligible rich/media with text into the same Reply API call before the reply token is consumed, then push only overflow; the open focused PR owns that direction.
