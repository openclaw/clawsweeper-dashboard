## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions, and adding them needs maintainer product/security direction because agents would mutate persistent Telegram chat state through bot credentials.

## What This Changes

Request to add standalone Telegram `pin` and `unpin` message-tool actions so agents can programmatically maintain pinned Telegram status messages.

## Best Possible Solution

Implement Telegram-plugin-owned `pin` and `unpin` actions only after maintainer approval, with a dedicated action gate, explicit message-id semantics, docs, focused tests, and live Telegram proof.
