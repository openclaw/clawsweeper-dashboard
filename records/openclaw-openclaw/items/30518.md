## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions. Lower-level Telegram pin helpers and pinned-delivery support exist, but the requested agent-facing action surface still needs maintainer product/security direction.

## What This Changes

Request to expose Telegram message-tool pin and unpin actions so agents can programmatically manage pinned Telegram status or dashboard messages.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions only after maintainers approve the privileged action contract, with an explicit action gate, conservative target semantics, docs, focused tests, and live Telegram proof.
