## Summary

Keep open: current main and the latest release still do not expose standalone Telegram `pin`/`unpin` message actions; existing support only covers delivery-pin for messages OpenClaw sends, and broader pin mutations need maintainer product/security direction.

## What This Changes

The issue requests standalone Telegram pin/unpin message-tool actions so agents can programmatically pin existing Telegram status messages.

## Best Possible Solution

If approved, implement Telegram-plugin-owned `pin` and `unpin` actions behind a pin-specific action gate, require explicit message ids unless maintainers approve otherwise, update docs/tests, and prove it with a live Telegram run.
