## Summary

Keep open: current main and the latest release still do not expose standalone Telegram `pin` or `unpin` message actions for existing messages, even though lower-level Telegram pin helpers exist for delivery pinning. The remaining work needs maintainer product/security approval because it would let agents mutate persistent Telegram chat state through bot credentials.

## What This Changes

Request to expose Telegram message-tool `pin` and `unpin` actions so agents can manage existing pinned messages in Telegram chats.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions only with a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.
