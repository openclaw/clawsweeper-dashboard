## Summary

Keep open: current main and v2026.6.11 still have Telegram delivery pinning for newly sent messages and lower-level pin helpers, but they do not expose standalone Telegram `pin` or `unpin` message actions for existing messages; adding them needs maintainer product/security direction.

## What This Changes

The issue requests standalone Telegram message-tool `pin` and `unpin` actions so agents can manage pinned status/dashboard messages without manual intervention.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions behind a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.
