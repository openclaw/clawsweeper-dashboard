## Summary

Keep open: current main and the latest release still expose Telegram delivery pinning and lower-level helpers, but not standalone Telegram `pin` or `unpin` message-tool actions. The remaining work needs maintainer product/security direction before a fix PR because it would let agents mutate persistent pinned-message state through bot credentials.

## What This Changes

Request to expose Telegram `pin` and `unpin` message-tool actions so agents can programmatically maintain pinned status dashboards.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions with explicit message-target semantics, a maintainer-approved per-account action gate, docs/tests, and live Telegram proof.
