## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions. The lower-level Telegram pin helpers and delivery-pin support exist, but a user-facing action surface still needs maintainer product/security direction because it would let agents mutate persistent pinned chat state through bot credentials.

## What This Changes

Request to expose Telegram message-tool `pin` and `unpin` actions so agents can programmatically manage pinned Telegram status messages.

## Best Possible Solution

Add Telegram-plugin-owned standalone `pin` and `unpin` actions behind a maintainer-approved gate with explicit message-id semantics, docs, focused tests, and live Telegram proof while keeping existing delivery pin behavior separate.
