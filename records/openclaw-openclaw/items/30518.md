## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions. The gap is source-reproducible, but adding it needs maintainer product/security direction because agents would mutate persistent Telegram pinned state through bot credentials.

## What This Changes

Request to expose Telegram pin/unpin message actions so agents can programmatically maintain pinned status or dashboard messages.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions only after maintainer approval, with an explicit action gate, conservative `messageId` semantics, docs, focused tests, and live Telegram proof.
