## Summary

Keep open: current main and the latest release still do not expose standalone Telegram `pin` or `unpin` message actions. The gap is source-reproducible, but adding it needs maintainer product/security direction because it lets agents mutate persistent Telegram pinned-message state through bot credentials.

## What This Changes

The issue requests Telegram message-tool actions to pin and unpin existing Telegram messages through the Telegram Bot API.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions only after maintainer approval, with an explicit action gate, conservative message-id semantics, docs, focused tests, and live Telegram proof.
