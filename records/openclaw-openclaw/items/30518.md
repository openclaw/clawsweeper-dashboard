## Summary

Keep open: current main and the latest release have Telegram delivery pinning and low-level Bot API helpers, but Telegram message-tool discovery and dispatch still do not expose standalone pin/unpin actions. The remaining work needs maintainer product/security direction because it would let agents mutate persistent Telegram chat state through bot credentials.

## What This Changes

Expose Telegram message-tool pin and unpin actions so agents can programmatically manage pinned messages.

## Best Possible Solution

Add Telegram-plugin-owned pin/unpin message actions only after approving the security gate, explicit target semantics, docs, focused tests, and live Telegram proof.
