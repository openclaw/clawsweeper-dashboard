## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions. The gap is source-reproducible, but exposing persistent pinned-message mutations through bot credentials needs maintainer product/security direction before a fix PR should be queued.

## What This Changes

The issue requests Telegram message-tool actions that can pin and unpin Telegram messages through the Telegram Bot API.

## Best Possible Solution

Add Telegram-plugin-owned explicit `pin` and `unpin` message actions with maintainer-approved target semantics, a pin-specific action gate, docs, focused tests, and live Telegram proof; otherwise document that Telegram only supports delivery pinning for newly sent messages.
