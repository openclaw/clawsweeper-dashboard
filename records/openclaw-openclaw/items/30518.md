## Summary

Keep open: current main and v2026.6.11 support pinned delivery for newly sent Telegram messages, but they still do not expose standalone Telegram `pin` or `unpin` message actions for existing messages. The remaining work needs maintainer product/security direction because it would let agents mutate persistent Telegram chat state through bot credentials.

## What This Changes

Expose Telegram `pin` and `unpin` as message tool actions so agents can programmatically pin or unpin existing Telegram messages.

## Best Possible Solution

Expose standalone Telegram pin/unpin only after maintainer approval of the security boundary, then implement it in the Telegram plugin action discovery/runtime with a dedicated gate, docs, focused tests, and live Telegram proof.
