## Summary

Keep open: current main and the latest release still omit standalone Telegram `pin`/`unpin` message actions. The remaining work is a feature/security decision because it would let agents mutate persistent Telegram chat state through bot credentials.

## What This Changes

Expose Telegram `pin` and `unpin` as message-tool actions so agents can programmatically manage pinned status-dashboard messages.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions with a dedicated action gate, explicit message-id semantics, docs, focused tests, and live Telegram proof.
