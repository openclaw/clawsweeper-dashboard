## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin`/`unpin` message actions; existing support is limited to delivery pinning for messages OpenClaw sends and lower-level helpers that are not wired into the action surface.

## What This Changes

Expose Telegram message-tool `pin` and `unpin` actions so agents can programmatically pin existing Telegram messages for status dashboards.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions behind a dedicated gate with explicit target semantics, focused docs/tests, and live Telegram proof before merge.
