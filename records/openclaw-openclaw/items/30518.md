## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions, and the remaining work needs maintainer product/security direction because it lets agents mutate persistent pinned chat state through bot credentials.

## What This Changes

The issue requests Telegram message-tool `pin` and `unpin` actions backed by Telegram Bot API pin/unpin support.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions only with a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.
