## Summary

Keep open: current main and v2026.6.11 have lower-level Telegram pin helpers and delivery-pin support, but Telegram still does not advertise or dispatch standalone `pin` and `unpin` message actions. The remaining request is real and bounded, but exposing persistent Telegram chat-state mutation needs maintainer product/security direction before implementation.

## What This Changes

The issue requests Telegram message-tool support for pinning and unpinning existing messages through Telegram Bot API actions.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions with explicit target semantics, a maintainer-approved action gate/default, docs, focused tests, and live Telegram proof.

## Reproduction Assessment

Yes. Source inspection shows current Telegram discovery, dispatch, and runtime aliases omit standalone `pin` and `unpin`, while lower-level helpers and delivery-pin support exist.

## Solution Assessment

Unclear until maintainers approve the privileged action contract. The likely best fix is a Telegram-plugin-owned action surface with explicit target semantics and a dedicated gate, not a core workaround or delivery-pin-only behavior.
