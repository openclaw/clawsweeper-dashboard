## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions, and adding them needs maintainer product/security direction because agents would mutate persistent Telegram chat state through bot credentials.

## What This Changes

Request to add Telegram message-tool `pin` and `unpin` actions backed by Telegram Bot API pin/unpin operations.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions only with a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.

Unclear until maintainers choose the privileged action contract. The likely best fix is a Telegram-plugin-owned action surface with a dedicated gate and conservative explicit unpin semantics, not a core workaround or delivery-pin-only behavior.
