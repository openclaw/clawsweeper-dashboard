## Summary

Keep open: current main still has Telegram pin/unpin Bot API helpers and pinned-delivery support, but it does not expose standalone Telegram `pin` or `unpin` message actions through discovery or dispatch. The remaining work is real and bounded, but it mutates persistent Telegram chat state and should wait for maintainer product/security direction.

## What This Changes

Request to add Telegram message-tool `pin` and `unpin` actions for existing messages using Telegram Bot API pin/unpin operations.

## Best Possible Solution

Add Telegram-plugin-owned `pin` and `unpin` message actions with explicit gating, conservative unpin semantics, docs, focused tests, and live Telegram proof after maintainer product/security approval.

## Solution Assessment

Unclear until maintainers choose the privileged action contract. The likely best fix is a Telegram-plugin-owned action surface with an explicit action gate and conservative unpin semantics, not a core workaround or delivery-pin-only behavior.
