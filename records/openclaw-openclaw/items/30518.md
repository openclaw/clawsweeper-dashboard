## Summary

Keep open: current main and v2026.6.11 still do not expose standalone Telegram `pin` or `unpin` message actions. The issue remains valid, but the remaining work needs maintainer product/security direction because it would let agents mutate persistent Telegram pinned-message state through bot credentials.

## What This Changes

Request standalone Telegram message-tool `pin` and `unpin` actions so agents can manage pinned Telegram status messages without manual intervention.

## Best Possible Solution

Approve and implement Telegram-plugin-owned standalone `pin` and `unpin` actions with a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.
