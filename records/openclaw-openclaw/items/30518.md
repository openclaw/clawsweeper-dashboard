## Summary

Keep open: current main and v2026.6.11 still expose Telegram delivery pinning for newly sent messages, but they do not expose standalone Telegram `pin` or `unpin` message actions for existing messages; adding them needs maintainer product/security direction because agents would mutate persistent Telegram chat state through bot credentials.

## What This Changes

Request to add Telegram `pin` and `unpin` message-tool actions backed by Telegram Bot API pin/unpin operations.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions only with a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.
