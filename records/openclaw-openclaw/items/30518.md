## Summary

Keep open: current main and the latest release still omit standalone Telegram `pin` and `unpin` message actions, while the lower-level Telegram pin helpers only support delivery pinning today. The request is valid, but exposing persistent chat pin mutation needs maintainer product/security direction before implementation.

## What This Changes

Expose Telegram message-tool actions that can pin and unpin existing chat messages through the Telegram Bot API.

## Best Possible Solution

Approve and implement Telegram-plugin-owned `pin` and `unpin` message actions only with a dedicated action gate, conservative explicit message-id semantics, docs, focused tests, and live Telegram proof.
