## What This Changes

Preserve owner-qualified ClawHub skill identity through security-verdict lookup so Control UI shows the valid clean verdict instead of Unavailable.

Add owner-qualified identity to the canonical ClawHub bulk verdict contract, pass `ownerHandle` from installed origin metadata, and cover both owner-collision and ordinary bare-slug cases in gateway and Control UI tests; use bounded single-verification fallback only as a temporary compatibility bridge.
