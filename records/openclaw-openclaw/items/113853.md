This PR makes macOS onboarding request the next Gateway wizard result after a Gateway-executed progress step, so local-model setup progress continues until terminal completion.

## System Context

macOS onboarding starts a setup wizard through the Gateway and presents each returned step in the setup sheet. For Gateway-owned download or pull progress, the client must issue the next long-poll request so updated progress and the terminal result reach the UI.
