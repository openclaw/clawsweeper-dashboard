## What This Changes

The PR makes macOS onboarding request the next Gateway wizard result after a Gateway-executed progress frame, then extends the IPC test to verify several progress updates and terminal completion.

## System Context

macOS onboarding drives a Gateway-hosted setup wizard for local-model preparation. The Gateway returns client-input steps or Gateway-executed progress steps; the app renders each result and must request the next result until the wizard reaches a terminal state.
