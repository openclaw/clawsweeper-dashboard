## What This Changes

This PR makes the macOS onboarding sheet immediately request the next Gateway wizard result after a Gateway-executed progress step, then updates the IPC test to consume multiple progress frames and the terminal result.

## System Context

The macOS onboarding app drives provider and local-model setup through the Gateway wizard protocol. The Gateway returns either user-answerable steps or Gateway-executed progress frames; the macOS sheet must continue requesting results for the latter so the visible progress and terminal state reach the user.
