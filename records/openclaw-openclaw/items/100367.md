## Summary

Keep open: current main still has one per-turn `message_tool_only` delivery hint plus warning-only private-final suppression, and I did not find periodic reminder refresh or a merged recovery path for long tool chains that end with a plain assistant final.

## What This Changes

The issue asks OpenClaw to prevent long `message_tool_only` turns from losing the delivery contract and ending with a withheld private final instead of a visible message-tool send.

## Best Possible Solution

Preserve the privacy rule that plain finals are not auto-published, then add a maintainer-approved compact reminder refresh and/or bounded stranded-final recovery with regression coverage for long tool chains.
