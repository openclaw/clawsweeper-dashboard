## Summary

Keep open: the added runtime signature strengthens the report, and current main still has one per-turn `message_tool_only` directive plus warning-only suppression when a long private final misses `message(action=send)`.

## What This Changes

The issue asks OpenClaw to prevent long `message_tool_only` turns from silently ending with withheld plain finals by refreshing the delivery contract, recovering after withhold, and keeping reminder text stable.

## Best Possible Solution

Preserve the rule that plain finals are private, then implement a maintainer-approved fixed-size reminder refresh and bounded stranded-final recovery with direct, queued, and long-tool-chain regression proof.
