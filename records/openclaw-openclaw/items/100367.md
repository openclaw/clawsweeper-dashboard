## Summary

Keep open: current main still has a one-shot `message_tool_only` delivery hint plus warning-only suppression for substantive private finals, and the reporter's follow-up provides the exact warning signature for the missed-delivery path. The open recovery PR partially overlaps, but it does not settle whether long tool chains should also refresh the delivery contract during the turn.

## What This Changes

Request a fix for `message_tool_only` turns where one-shot delivery guidance falls out of recent context during long tool chains, causing substantive plain finals to be withheld instead of sent.

## Best Possible Solution

Preserve the rule that plain finals are not auto-published, then choose a maintainer-approved mix of compact in-turn delivery reminders and bounded stranded-final recovery with regression coverage for long tool chains.
