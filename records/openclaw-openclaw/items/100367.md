## Summary

Keep open: current main still has a one-shot `message_tool_only` delivery hint plus warning-only suppression for substantive private finals, and the related recovery PRs do not fully settle whether long tool chains also need reminder refresh during the turn.

## What This Changes

The issue requests a more reliable `message_tool_only` delivery contract for long tool-heavy turns so final answers are not withheld after the model forgets to use `message(action=send)`.

## Best Possible Solution

Preserve the no-auto-publish privacy rule, then add a maintainer-approved combination of compact in-turn delivery-contract refresh and bounded stranded-final recovery with regression coverage for long tool chains.
