## Summary

Keep open: current main still has a bounded per-turn `message_tool_only` reminder and private-final warning/suppression behavior, but I did not find an in-turn reminder refresh or same-turn correction path for a long tool chain that ends with a plain assistant final.

## What This Changes

The issue reports that `message_tool_only` delivery guidance can lose recency during long tool chains, causing the model to produce a plain final that OpenClaw withholds instead of delivering to the source channel.

## Best Possible Solution

Preserve the privacy rule that plain finals are not auto-published, then add a maintainer-approved combination of compact in-turn contract refresh and bounded stranded-final recovery with regression coverage for long tool chains.
