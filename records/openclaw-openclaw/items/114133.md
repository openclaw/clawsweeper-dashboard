## System Context

OpenClaw reads a repository-local `.env` file during startup, then supplies allowed values to the runtime. The workspace safety filter is the trust boundary that prevents an untrusted checkout from changing operator-controlled routing, authentication, or access settings while preserving trusted shell and global configuration.
