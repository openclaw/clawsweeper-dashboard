## What This Changes

This PR expands the workspace dotenv denylist so untrusted project-local `.env` files cannot set additional AWS, endpoint-routing, channel, relay, or unsafe runtime-control variables, and moves the corresponding coverage into a dedicated blocklist test file.

## System Context

OpenClaw loads workspace dotenv files before running from a repository, while shell and global dotenv sources represent operator-controlled inputs. The dotenv ingestion filter decides which workspace variables reach provider, channel, and runtime initialization, so it forms a trust boundary before those subsystems consume environment configuration.
