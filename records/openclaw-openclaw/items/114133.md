## What This Changes

## System Context

OpenClaw loads a workspace `.env` before its trusted global dotenv fallback, so this ingestion boundary decides which repository-controlled variables may enter the runtime environment. Accepted values influence later provider, channel, and runtime initialization; blocked values must leave shell and global operator configuration unaffected.
