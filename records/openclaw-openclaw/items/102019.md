## Summary

Keep open. Current main and the latest release still emit `session.ended` trajectory data without a stable `openclaw.end_reason`, and the documented OTel surface uses `openclaw.run` outcome/error fields instead, so this needs a maintainer telemetry-contract decision rather than cleanup close.

## Best Possible Solution

Define one additive, low-cardinality session-terminal reason contract and emit it from the canonical terminal outcome path to the maintainer-approved trajectory and/or OTel surfaces with docs and focused tests.
