## Summary

Keep open. Current main still has no `openclaw.end_reason` or `end_reason` telemetry attribute, and adding one would define a new operator-facing low-cardinality telemetry contract rather than close a stale cleanup item.

## What This Changes

The issue requests a populated `openclaw.end_reason` value on `session.ended` telemetry so operators can distinguish completed, interrupted, timed-out, and error terminal sessions.

## Best Possible Solution

Define one additive, low-cardinality terminal reason contract and emit it from the canonical terminal outcome path to the maintainer-approved trajectory and/or OTel surfaces with docs and focused regression coverage.
