## Summary

## What This Changes

## Best Possible Solution

Keep the canonical Feishu DM ingress and internal synthetic metadata design, treating the combination of explicit event subscription and an authorized inviter's meeting invitation as consent only if the Feishu owner confirms that contract and the setup documentation clearly states activation and rollback behavior.
