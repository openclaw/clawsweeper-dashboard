## What This Changes

The PR keeps an already-selected Worktree toggle actionable after Git rediscovery becomes unavailable, allowing a user to clear it and start a normal session in the selected custom folder.

## System Context

The Control UI new-session page discovers Git/worktree availability for a selected folder, then uses that state to control the Worktree option and session submission. This change affects the recovery path from an unavailable Git lookup before the page sends `sessions.create` to the Gateway.
