## Summary

Keep this PR open for a narrower correction: the added `execFileSync` timeout improves ordinary stalled-Git handling, but it does not guarantee a bounded lease-freshness check because Node waits for the child process to exit after timing out. Real after-fix behavior proof is also absent from the PR body and visible discussion.

## Best Possible Solution
