## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P1] Filter voice adapter state by bot account:** `extensions/discord/src/voice/manager.ts:576`
  - body: Adding `group` separates the `@discordjs/voice` connection registry, but the gateway adapter is still stored by guild and `dispatchVoiceGatewayEvent` forwards every guild `VOICE_STATE_UPDATE` to it. The dependency stores whichever state packet arrives as this connection's state, so two bot accounts in the same guild can still cross-feed session/user state before Ready; pass the bot user/account into the adapter path or filter state packets before `onVoiceStateUpdate`.
  - confidence: 0.87
- **[P2] Await or cancel lifecycle-started auto-join:** `extensions/discord/src/monitor/provider.lifecycle.ts:523-524`
  - body: This starts `autoJoin()` fire-and-forget, but the lifecycle `finally` destroys the manager without waiting for that join task. Since `joinUnlocked` can call `joinVoiceChannel` before it checks `destroyed`, shutdown or immediate startup failure can still create a voice connection until the Ready wait settles; track the task and await/cancel it before cleanup completes.
  - confidence: 0.82
