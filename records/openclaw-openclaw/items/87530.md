## Summary

Keep open: the refreshed PR fixes the previous test blockers and uses the right @discordjs/voice group boundary, but the new already-ready autoJoin path starts before pre-lifecycle startup cleanup owns the voice manager, leaving a concrete merge blocker.

## What This Changes

This PR scopes Discord voice connections by account ID, starts voice autoJoin when the gateway is already connected before listener registration, and adds focused Discord provider/voice tests plus a changelog entry.

## Best Possible Solution

Keep the account-scoped group fix, but move the already-ready autoJoin trigger until lifecycle cleanup owns the voice manager or extend startup cleanup to destroy and unregister the manager on pre-lifecycle failure, with focused regression coverage.
