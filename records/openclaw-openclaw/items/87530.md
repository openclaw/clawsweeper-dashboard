## Summary

Keep open: current main and the latest release still use the @discordjs/voice default connection group and only listener-driven voice auto-join, so the reported Discord voice bug remains. The PR is close to the right fix, but the current head still starts immediate autoJoin before lifecycle cleanup owns the voice manager and still lacks after-fix real Discord proof.

## What This Changes

The PR scopes Discord voice connection lookup/join cleanup by account ID and starts voice auto-join immediately when the Discord gateway is already connected.

## Best Possible Solution

Land the account-scoped group fix with the already-ready autoJoin check moved under lifecycle-owned cleanup or explicit pre-lifecycle voiceManager destruction, then add redacted live Discord proof for the two-account and already-ready paths.
