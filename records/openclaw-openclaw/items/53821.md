## Summary

Keep open: current main still accepts the sandbox visibility field but applies only the default clamp at runtime, while this PR is a focused and proven candidate. The remaining blocker is maintainer acceptance of the access-control behavior and landing order with broader per-agent visibility work.

## What This Changes

This PR threads requester agent identity into sandboxed session list, history, send, and status tools and documents `agents.list[].sandbox.sessionToolsVisibility` precedence.

## Best Possible Solution

Land this narrow sandbox override only after maintainers accept the explicit access expansion and landing order; otherwise fold the same behavior, tests, and docs into the broader per-agent visibility design.
