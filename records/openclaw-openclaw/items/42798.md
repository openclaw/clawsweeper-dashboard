## Best Possible Solution

Resolve this through https://github.com/openclaw/openclaw/pull/91553 or a narrow replacement that retries the existing status JSON read, suppresses non-final retry noise, preserves fast missing-binary fallback, and avoids adding new Tailscale config surface.
