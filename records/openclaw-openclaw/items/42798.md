## Summary

## What This Changes

The issue requests retry/backoff for Tailscale Serve startup hostname discovery so transient `tailscale status --json` failures do not produce confusing startup logs.

## Best Possible Solution

Land a narrow same-binary retry in `getTailnetHostname` that avoids intermediate verbose failure noise and preserves fast fallback to alternate binaries.
