## Summary

## What This Changes

This PR adds an iOS/shared SQLite-backed read-only chat transcript/session cache, wires it into iOS chat and session surfaces, updates docs/i18n/scripts, and adds Swift cache and view-model tests.

## Best Possible Solution

Capture the cache identity or cache actor at the start of each visible iOS session-list refresh, revalidate it after the await before applying or storing rows, keep the bounded per-gateway purge/protection contract, and land only with redacted simulator or device proof.
