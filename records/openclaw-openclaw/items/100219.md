## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P2] Keep session cache writes scoped to the request gateway:** `apps/ios/Sources/Design/CommandCenterTab.swift:412`
  - body: `refreshRecentSessionsIfNeeded` starts `sessions.list` against the current transport, but after the await it calls `appModel.storeCachedChatSessions`, which re-resolves the current cache identity. If the user switches paired gateways while that request is in flight, gateway A's rows can be applied and written into gateway B's offline cache; the same pattern exists in `IPadActivityScreen.refreshSessions`. Capture the gateway/cache identity before the request and guard it after the await, matching the Android `ChatCacheScope` pattern.
  - confidence: 0.9
