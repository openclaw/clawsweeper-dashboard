## Summary

The linked bug remains on current `main`, and this PR addresses the correct runner boundary: both embedded and CLI paths currently restrict the documented pre-model claiming hook to cron turns. The implementation appears correct and useful, with relevant tests and live installed-build evidence; it should remain open for rebase and normal compatibility review rather than cleanup.

## What This Changes

The PR makes embedded and CLI runners invoke `before_agent_reply` for user, heartbeat, and cron turns, removes the earlier auto-reply invocation, preserves channel identity, and excludes internal manual runs.
