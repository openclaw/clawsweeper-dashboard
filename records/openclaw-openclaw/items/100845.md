## Summary

Keep open: current head still has a P1 compatibility blocker because JSON-mode embedded agent runs can start the existing diagnostics-otel stdout log exporter, which writes directly to stdout and can corrupt `openclaw agent --json` output.

## What This Changes

This PR starts and flushes the diagnostics-otel plugin service around embedded `openclaw agent --local` and Gateway-fallback runs, documents which processes export OTel data, and strips inherited `npm_execpath` from local build child environments.

## Best Possible Solution

Keep the scoped one-shot exporter lifecycle, but make JSON-mode embedded runs suppress or reroute stdout OTel log export while preserving OTLP export and bounded shutdown.
