## Summary

Keep this PR open but do not merge it as-is: current main already resolves missing delivery for `current` and `session:*` targets at runtime, while this patch converts that implicit behavior into persisted explicit delivery state without demonstrating an actual missed announcement or proving the downstream compatibility effects.

## What This Changes

The PR expands initial cron creation to persist `{ mode: "announce" }` for `current` and `session:*` agent-turn or command targets and adds focused unit tests for the initializer.

## Best Possible Solution

Keep runtime delivery resolution as the canonical source for implicit `current` and `session:*` behavior; only expand persisted defaults after an end-to-end failing reproduction proves the need and focused tests cover explicit-versus-implicit delivery ownership and upgrade behavior.
