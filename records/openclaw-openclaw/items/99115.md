## Summary

Keep this PR open but do not merge yet. The patch changes the implicit delivery contract for direct-service and declarative cron callers, while supported CLI, gateway, and agent-tool creation already receives announce delivery through normalization; the new exact-head runtime evidence therefore proves the existing normalized path rather than the branch changed by this PR. The previous ownership-boundary blocker remains unresolved and needs a cron contract decision plus changed-path proof.

## What This Changes

The PR makes direct-service cron creation default omitted delivery to announce for `current` and `session:*` agent-turn or command targets, with helper and service-level regression tests.

## Best Possible Solution

Use one owner-approved creation-time delivery policy: preferably normalize every supported creation path before persistence and keep direct callers explicit, or deliberately make the service helper canonical for all callers with focused compatibility tests and live declarative/direct-service proof.
