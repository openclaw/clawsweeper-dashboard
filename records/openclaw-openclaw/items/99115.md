## Label Justifications

- `P2`: This is a bounded cron delivery-contract change with meaningful but limited blast radius for newly created persistent-session jobs.

- `merge-risk: 🚨 message-delivery`: Persisting implicit announce for additional target classes can cause unexpected or wrongly routed cron announcements after merge.

## Summary

The prior blocking finding remains valid on the unchanged head: `current` and `session:*` are persistent-session targets, while current source, documentation, and the merged persistence restoration define implicit announce initialization for isolated jobs only. This PR therefore changes the delivery contract rather than fixing an inconsistency, and its helper-level evidence does not demonstrate a real cron run or delivery.

## What This Changes

The PR makes newly created `current` and `session:*` agent-turn or command cron jobs persist an implicit announce delivery and adds a target/payload test matrix for initial delivery resolution.

## Best Possible Solution

Keep implicit announce initialization isolated-only, preserve `current` and `session:*` on the canonical persistent-session path, and pursue any broader default-delivery policy explicitly through https://github.com/openclaw/openclaw/issues/9155 with documented fresh-install and upgrade behavior.
