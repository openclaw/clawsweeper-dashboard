## Summary

The patch is a focused, correct fix for a current-main inconsistency: typed cron create/replace omits delivery for `current` and `session:` output jobs, while normalization and runtime planning already default those targets to announce. No actionable code or security defect remains, but the persisted-shape compatibility change merits cron-owner confirmation before merge.

- `xingzhou` — medium confidence; most recently refactored the current cron delivery paths containing this helper and its sibling predicates.
- Tyler Yust — medium confidence; substantial contributor across the central cron service and delivery files.

## What This Changes

The PR makes typed cron create and replacement default delivery to announce for `current` and `session:` agent-turn or command jobs, and adds focused tests for explicit delivery, payload kinds, and all target forms.

## Best Possible Solution

Merge the focused alignment after confirming that explicit announce is the canonical persisted form for every output-capable session target; keep the separate announce-versus-none policy and configurable global delivery defaults out of this PR.
