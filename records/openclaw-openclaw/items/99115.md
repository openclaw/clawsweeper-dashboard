## Summary

Keep open but do not merge as written: the documented and recently restored contract treats `current` and `session:*` as persistent conversation targets, so the missing isolated-style implicit announce is intentional rather than an inconsistency; the PR also lacks a real run proving user-visible message loss.

## What This Changes

The branch makes cron creation persist implicit announce delivery for `current` and `session:*` agent-turn or command jobs and adds a helper-level target/payload test matrix.

## Best Possible Solution

Keep implicit announce creation limited to isolated jobs; persistent-session jobs should use their canonical session output path or explicit delivery settings, with any remaining delivery bug reproduced and fixed at the actual runtime routing boundary.
