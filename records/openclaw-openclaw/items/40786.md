## Summary

Keep open: current main and v2026.6.11 still lack native backup exclude-pattern controls, and the same-repo implementation candidate is still open, conflicting, and product/security gated. Keep My Claw is a useful ClawHub workaround mentioned in the discussion, but it does not replace the requested built-in backup CLI behavior.

## What This Changes

Request to add `.gitignore`-style exclude patterns and exclude-file support to `openclaw backup create` so large, noisy, or sensitive paths can be omitted from backups.

## Best Possible Solution

Land a maintainer-approved native backup exclude design that is opt-in, predictable across backup assets, protects restore-critical paths by default, avoids sensitive manifest leakage, and has real create/verify proof.
