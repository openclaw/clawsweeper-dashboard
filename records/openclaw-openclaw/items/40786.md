## What This Changes

The issue requests `.gitignore`-like exclusions for `openclaw backup create`, including repeatable `--exclude` patterns, an `--exclude-file` option, and possible safe default exclusions.

## Best Possible Solution

Define one native backup exclusion contract through https://github.com/openclaw/openclaw/pull/44288 or a narrower replacement: repeatable patterns, exclude-file handling, protected recovery paths, safe defaults, manifest/JSON behavior, docs, and real backup/verify proof.
