## Summary

Keep open: current main and the latest release still lack native backup exclude-pattern controls, and the open same-repo implementation PR is conflicting and still product/security/proof-gated. Keep My Claw is a useful ClawHub workaround discussed on the issue, but it does not replace the built-in backup CLI contract requested here.

## What This Changes

The issue requests gitignore-style exclude controls for `openclaw backup create`, including repeatable patterns, an exclude file, and default sensitive/large-directory exclusions.

## Best Possible Solution

Land a maintainer-approved native backup exclude design that is opt-in, applies predictably across state/workspace/config assets, protects restore-critical paths by default, records non-sensitive manifest stats, and has real archive create/verify proof; keep Keep My Claw as a useful ClawHub workaround, not the replacement for the core CLI request.
