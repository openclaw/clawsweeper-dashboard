## Summary

## What This Changes

The issue requests repeatable `.gitignore`-style backup exclude patterns, an exclude-file option, and possible default exclusions for `openclaw backup create`.

## Best Possible Solution

Define one native backup exclusion contract through the linked PR or a replacement: explicit pattern flags, exclude-file behavior, safe default/protected-path semantics, manifest/JSON compatibility, docs, and real backup/verify proof.
