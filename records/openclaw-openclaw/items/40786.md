## Summary

Keep open: current main and v2026.6.11 still lack native `.gitignore`-style backup exclude controls. A KeepMyClaw/ClawHub workaround was linked in discussion, but it does not replace the native backup CLI request, and the open linked implementation PR still needs maintainer product/security review.

## What This Changes

Request to add `.gitignore`-style exclude controls such as `--exclude` and `--exclude-file` to `openclaw backup create` so users can omit large, noisy, or sensitive files from archives.

## Best Possible Solution

Define and land one native backup exclusion contract through the linked PR or a narrowed replacement, covering repeatable patterns, exclude-file handling, protected recovery paths, manifest/JSON behavior, docs, and real backup/verify proof.
