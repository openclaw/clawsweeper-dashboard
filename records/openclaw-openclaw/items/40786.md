## Summary

Keep open: current main and v2026.6.11 still lack native backup exclude-pattern controls, while https://github.com/openclaw/openclaw/pull/44288 is the active same-repo implementation candidate and remains open/conflicting. The Keep My Claw ClawHub plugin mentioned in the discussion is a useful workaround for focused encrypted backups, but it does not replace the requested built-in backup CLI behavior.

## What This Changes

Request adds .gitignore-style `--exclude` and `--exclude-file` controls, suggested default exclusions, and safer backup scope for large or sensitive files.

## Best Possible Solution

Define a native, guarded backup exclusion design that preserves restore-critical state by default, records only non-sensitive exclusion stats, and lands through the active or replacement PR with docs plus real backup/restore proof.
