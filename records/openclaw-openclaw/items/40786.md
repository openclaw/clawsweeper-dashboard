## Summary

Keep open: current main and the latest release still do not provide native `.gitignore`-style backup exclude controls, and the active same-repo PR is still open, conflicting, and product/security/proof-gated. Keep My Claw is useful workaround context from the discussion, but it does not replace the built-in backup CLI behavior requested here.

## What This Changes

Request adds gitignore-style `--exclude` and `--exclude-file` controls, with possible default exclusions, to `openclaw backup create`.

## Best Possible Solution

Land a maintainer-approved native backup exclude design that is opt-in, protects restore-critical paths by default, avoids leaking sensitive filenames in manifests, and includes real create/verify archive proof; keep Keep My Claw as a workaround rather than the core CLI replacement.
