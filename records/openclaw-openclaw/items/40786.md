## Summary

Keep open: current main and v2026.6.11 still lack native `.gitignore`-style backup exclusions, while https://github.com/openclaw/openclaw/pull/44288 is the open candidate that explicitly closes this issue. The Keep My Claw ClawHub plugin is a useful workaround for focused/encrypted backups, but it does not replace deciding the native backup CLI contract.

## What This Changes

The issue requests `.gitignore`-style exclusions for `openclaw backup create`, including repeatable `--exclude`, `--exclude-file`, and suggested defaults for bulky or sensitive files.

## Best Possible Solution

Define one native backup exclusion contract through the linked PR or a replacement: repeatable patterns, exclude-file handling, protected recovery paths, safe defaults, manifest/JSON behavior, docs, and real backup/verify proof.
