## Summary

Keep open: current main and v2026.6.11 still lack user-controlled `.gitignore`-style backup excludes. Current code has narrow volatile-file and extension `node_modules` skips, but the open native candidate at https://github.com/openclaw/openclaw/pull/44288 is still proof-gated and needs maintainer product/security review; the linked `keepmyclaw` plugin is useful workaround context, not a replacement for native CLI scope.

## What This Changes

The issue requests gitignore-style exclusion controls for `openclaw backup create`, including repeatable patterns, exclude files, and sensible default omissions for large or sensitive files.

## Best Possible Solution

Review or replace https://github.com/openclaw/openclaw/pull/44288 as the native path: restore-safe exclude defaults, explicit CLI flags, protected-path behavior, docs, focused tests, and live large-state backup proof; keep `keepmyclaw` as an optional ClawHub workaround.
