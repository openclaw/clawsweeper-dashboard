## What This Changes

Request native `.gitignore`-style exclude patterns and exclude-file controls for `openclaw backup create` to reduce backup bloat and avoid archiving sensitive files.

## Best Possible Solution

Define and ship one native backup exclusion contract through the linked PR or a narrower replacement: explicit patterns, exclude-file handling, protected recovery paths, safe defaults, manifest/docs behavior, and backup/verify proof.
