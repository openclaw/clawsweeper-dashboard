The issue requests gitignore-style `openclaw backup create` exclude patterns, optional exclude files, and sensible defaults for large or sensitive paths.

## Best Possible Solution

Land a maintainer-approved native backup exclude design that is opt-in, predictable across all backup assets, protects restore-critical paths by default, avoids sensitive manifest leakage, and has real create/verify proof.
