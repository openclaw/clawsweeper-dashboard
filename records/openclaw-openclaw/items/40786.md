## Summary

Keep open: current main and v2026.6.11 still lack native `.gitignore`-style `--exclude` / `--exclude-file` backup controls. ## What This Changes

Request adds user-controllable `.gitignore`-style exclude patterns and exclude-file support to `openclaw backup create`, with possible default exclusions for bulky or sensitive paths.

## Best Possible Solution

Define and ship one native backup exclusion contract through the linked PR or a replacement: repeatable patterns, exclude-file handling, protected recovery paths, safe defaults, manifest/JSON behavior, docs, and real backup/verify proof.
