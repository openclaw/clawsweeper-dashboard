## Summary

Keep open: current main and the latest release still lack native `--exclude` / `--exclude-file` backup controls. Keep My Claw is a useful external workaround from the discussion, but the native backup CLI request remains open and is already paired with a conflicting, proof-blocked implementation PR that needs maintainer product/security review.

## What This Changes

The issue requests `.gitignore`-style exclude controls for `openclaw backup create`, including repeatable patterns, an exclude file, and safe defaults for large or sensitive files.

## Best Possible Solution

Keep this issue open until maintainers either land or reject the native backup exclude design, with additive CLI flags, protected restore-critical paths, focused docs, and proof for fresh and existing backup flows.
