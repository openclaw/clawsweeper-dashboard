## Summary

Keep open: current main and the latest release still lack native `--exclude` or `--exclude-file` controls for `openclaw backup create`. Keep My Claw is a useful ClawHub workaround mentioned in the discussion, but it does not replace the requested built-in backup CLI behavior; the active same-repo implementation PR is still open and needs maintainer product/security review before this issue can close.

## What This Changes

The issue requests `.gitignore`-style exclude controls for `openclaw backup create`, including repeatable patterns and an exclude-file option.

## Best Possible Solution

Native backup should either gain guarded exclude support with protected recovery paths, tests, docs, and real archive proof, or maintainers should explicitly choose a different backup-scope policy.
