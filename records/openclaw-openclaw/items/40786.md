## Summary

Keep open: current main and the latest release still lack user-controlled `.gitignore`-style backup excludes. The KeepMyClaw ClawHub plugin mentioned in discussion is a useful workaround, but it does not resolve the native `openclaw backup create` gap; the open candidate implementation at https://github.com/openclaw/openclaw/pull/44288 still needs maintainer product/security review and proof before this issue can close.

## What This Changes

The issue requests `.gitignore`-style exclude patterns and exclude-file support for `openclaw backup create` to reduce backup size and avoid archiving sensitive or rebuildable files.

## Best Possible Solution

Keep the native backup request open and review a narrowed implementation that adds opt-in excludes, protected recovery-critical path handling, pattern validation, privacy-preserving manifest stats, docs, and real backup/restore proof.
