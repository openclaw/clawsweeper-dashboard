## Summary

Keep open: current main and v2026.6.11 still lack user-controlled backup exclude patterns. The linked Keep My Claw plugin is a useful workaround and https://github.com/openclaw/openclaw/pull/44288 is the active native candidate, but that PR still needs maintainer product/security review and real behavior proof before this issue can close.

## What This Changes

The issue requests `.gitignore`-style `--exclude` and `--exclude-file` support for `openclaw backup create`, with suggested defaults for large, noisy, and sensitive files.

## Best Possible Solution

Land a maintainer-approved native backup exclude design with explicit CLI semantics, protected restore-critical paths, manifest/docs updates, and real backup/restore proof; keep this issue paired with https://github.com/openclaw/openclaw/pull/44288 until then.
