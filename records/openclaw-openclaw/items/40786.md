## Summary

Keep open: current `main` and the latest release still lack native backup exclude-pattern controls, and the active same-repo implementation PR is open, conflicting, and still product/security/proof-gated. Keep My Claw is a useful ClawHub workaround discussed on the issue, but it does not replace the requested built-in backup CLI behavior.

## What This Changes

The issue requests `.gitignore`-style `--exclude` and `--exclude-file` controls, plus sensible defaults, for `openclaw backup create`.

## Best Possible Solution

Land a maintainer-approved native backup exclude design that is opt-in, predictable across backup assets, protects restore-critical paths by default, avoids sensitive manifest leakage, and has real archive create/verify proof; keep Keep My Claw as a workaround rather than the core CLI answer.
