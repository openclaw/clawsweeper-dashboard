## Summary

Keep open: current main and the latest release still do not provide native backup exclude-pattern controls, and the issue is paired with an open same-repo implementation PR that needs maintainer product/security review rather than cleanup closure. Keep My Claw is a useful ClawHub workaround mentioned in the discussion, but it does not replace the built-in backup CLI contract requested here.

## What This Changes

The issue requests gitignore-style exclude controls for `openclaw backup create`, including repeatable exclude patterns, exclude-file support, and suggested default exclusions for bulky or sensitive files.

## Best Possible Solution

Settle one native backup exclusion contract through the linked PR or a maintainer replacement: explicit pattern flags, exclude-file behavior, safe default/protected-path semantics, manifest/JSON compatibility, docs, and real backup/verify proof.
