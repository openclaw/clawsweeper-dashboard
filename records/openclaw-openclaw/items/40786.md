## Summary

Keep open. Current `main` and the latest release still lack the requested `--exclude` / `--exclude-file` backup controls; current code only has narrow hard-coded filtering for volatile files and extension `node_modules`, while the linked implementation candidate remains open and needs maintainer review.

## What This Changes

The issue requests `.gitignore`-style exclude patterns, exclude-file support, and possible default exclusions for `openclaw backup create`.

## Best Possible Solution

Land, narrow, or replace the linked native-backup implementation so `openclaw backup create` has restore-safe pattern exclusions, documented protected-path behavior, manifest/verify coverage, and real large-state proof.
