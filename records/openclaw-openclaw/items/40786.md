## Summary

Keep open: current main and v2026.6.11 still expose only coarse backup scope controls, not `.gitignore`-style `--exclude` or `--exclude-file` support. The open implementation candidate is https://github.com/openclaw/openclaw/pull/44288, but that PR still needs maintainer product/security review and proof before this issue can close.

## What This Changes

Request to add repeatable exclude patterns and exclude-file support to `openclaw backup create` so large, noisy, or sensitive files can be omitted from backups.

## Best Possible Solution

Land a maintainer-approved core backup implementation with explicit exclude controls, safe defaults or opt-in semantics, protected restore-critical paths, manifest/docs updates, and real backup/restore proof; keep this issue paired with https://github.com/openclaw/openclaw/pull/44288 until then.
