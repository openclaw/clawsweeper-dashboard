## Reproduction Assessment

Yes from source inspection, though I did not execute a failing run in this read-only review. Current main and the latest release use exact `obj[key]` value lookup while treating supported keys case-insensitively for unknown-key reporting, so a line like `{"Voice":"..."}` is recognized as known but does not populate `voiceId`.

## Solution Assessment
