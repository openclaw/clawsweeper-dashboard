## Summary

Current main still rejects `model: null` at the Gateway protocol boundary and drops empty model values before config mutation, so the requested clear operation remains necessary and is a narrow, maintainable API improvement.

## What This Changes

Allow `agents.update` callers to pass `model: null` to remove an agent-level model override and resume inherited model selection.

## Best Possible Solution

Treat omitted `model` as no change and explicit `model: null` as deletion of `agents.list[].model`, then verify the agent inherits the configured default without changing unrelated identity or workspace fields.
