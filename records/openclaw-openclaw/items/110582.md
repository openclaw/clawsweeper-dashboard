## Summary

Keep this PR open for a gateway/security owner decision and two P1 corrections: the pre-upgrade hook currently broadens the existing Control UI origin policy to every Origin-bearing client, and it replaces the established trusted-proxy locality decision with a raw-header heuristic. The contributor’s live proof is useful and specifically exposes both compatibility-sensitive cases, but it cannot establish that the broader boundary is the intended product contract.

## What This Changes

## Best Possible Solution
