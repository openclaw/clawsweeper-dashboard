## What This Changes

The PR adds a Gateway WebSocket handshake hook that rejects disallowed browser Origins with HTTP 403 before a live socket is created, with focused tests and Gateway security documentation.

## System Context

The Gateway turns HTTP upgrade requests into WebSocket sessions, then validates browser-origin policy and authenticates the client’s `connect` frame. This PR moves an Origin-policy decision before the upgrade while still relying on the Gateway’s existing origin configuration and locality rules.
