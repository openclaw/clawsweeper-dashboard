## What This Changes

This PR rejects Discord nested reply data whose message ID differs from the canonical reply reference, refetches the canonical target, and clears unsafe reply context if that refetch fails.

## System Context

The Discord plugin turns incoming Discord messages into agent-readable context. For native replies, its hydration layer decides whether the nested referenced-message payload can be trusted or whether it must fetch the canonical reply target before agent context is assembled.
