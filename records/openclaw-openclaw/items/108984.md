## Summary

This remains necessary: current main still gates destructive transcript-byte compaction on inferred CLI identity, while the documented backend contract says native-compaction-owning backends must bypass OpenClaw compaction. The production evidence is credible, although the exact current-main session shape that loses its runtime identity still needs a focused regression test. 

## What This Changes

Prevent transcript-byte preflight compaction from summarizing and rotating sessions that execute through a native-compaction-owning CLI backend.

## Best Possible Solution

Resolve the effective backend once for each turn and make preflight defer whenever that backend declares native compaction ownership, with regression tests for canonical Anthropic-to-Claude-CLI routing and unchanged embedded and Codex behavior.

## Solution Assessment

Yes in direction, but the best implementation is broader than another provider-string check: preflight should consume the same resolved backend ownership fact as execution and honor `ownsNativeCompaction` before any token or byte trigger.
