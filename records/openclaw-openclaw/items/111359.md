## Summary

Current source requires an actual active or completed descendant before the interim-message guard can suppress output, so the reported plain text-only/no-subagent scenario cannot reach that return. The requested best-effort exemption would also undo an intentional regression-tested behavior that avoids delivering stale “working on it” text while descendants are still running.

## What This Changes

The issue asks to exempt isolated cron interim-message suppression from `delivery.bestEffort` so a short acknowledgment-style reply is delivered.

## Best Possible Solution

Keep the existing descendant-aware stale-interim suppression; if a future report captures delivery suppression without active or completed descendants, investigate the run-scoped registry and fallback evidence rather than broadly changing `delivery.bestEffort` semantics.
