## Summary

Keep open: current main has chat-first CLI onboarding and the macOS verified setup engine, but default CLI onboarding still lacks guided live verification, masked manual-key entry, and candidate fall-through; the protected maintainer/product-decision state makes this a maintainer-owned UX/API choice rather than an automation close.

## What This Changes

Request guided default CLI onboarding that live-tests AI access with macOS parity while preserving classic, explicit-flag, non-interactive, and modern escape hatches.

## Best Possible Solution

Reuse detectSetupInference and activateSetupInference for a deterministic guided CLI verifier with masked manual-key entry, candidate fall-through, classic/Crestodian escape hatches, and focused docs/tests for fresh and upgrade behavior.
