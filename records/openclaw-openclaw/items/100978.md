## Summary

Keep open: current `origin/main` and the latest release do not provide a core `sessions_search` agent tool or `sessions.search` gateway method, and this maintainer-labeled request needs product/security direction before implementation. Existing `sessions_list`, `sessions_history`, and opt-in memory session search cover adjacent behavior but not the requested default lexical transcript-search seam.

## What This Changes

Add a core `sessions_search` agent tool and gateway-backed full-text search over visible agent session transcripts.

## Best Possible Solution

Approve a maintainer-owned design for a shared, visibility-safe `sessions.search` gateway contract and `sessions_search` tool, with sanitized snippets, bounded indexing/backfill, lifecycle pruning, protocol/docs updates, and focused gateway/agent tests.
