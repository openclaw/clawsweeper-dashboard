## Summary

Keep open. Current main and the latest release still lack a mobile offline transcript cache, and the linked iOS/Android implementation PRs are open, unmerged, and still behind maintainer/security review rather than evidence for cleanup closure.

## What This Changes

Request a bounded, per-gateway, read-only local cache of recent mobile sessions and messages on iOS and Android so chat cold opens instantly and remains browsable while offline.

## Best Possible Solution

Approve a shared mobile cache and security contract, then land reviewed platform-native iOS and Android implementations that are bounded, per-gateway, text-only, disposable, resettable, and visibly read-only when offline.
