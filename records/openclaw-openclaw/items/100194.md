## Summary

Keep open. Current main and v2026.6.11 still use gateway-backed in-memory mobile chat/session state, while the protected `maintainer` label, open platform PRs, and security-sensitive local transcript persistence make this unsafe to close as cleanup.

## What This Changes

The issue requests a bounded read-only iOS and Android cache that renders recent sessions and transcripts immediately on cold open and keeps them browsable while the gateway is unreachable.

## Best Possible Solution

Define one shared mobile transcript-cache and security contract, then review and land or close the linked iOS and Android platform PRs against that contract.
