## Summary

Keep this PR open but do not merge the current head: three source-confirmed P1 defects can cause delayed credential/config mutation, false onboarding failure after successful inference setup, and permanent routing to the wrong local Gateway endpoint.

## What This Changes

The PR makes configured Gateways authoritative during onboarding, requires verified inference before Crestodian handoff, and adds route-bound credential and state isolation across macOS, CLI/TUI, Gateway, plugins, migrations, and packaging.

## Best Possible Solution

Reject activation before shared queue admission, use a verification timeout at least as long as the server probe window, retain the configured local bind as the all-probes-failed fallback, add focused regressions for all three paths, then resolve conflicts and capture exact-head fresh-install, upgrade, restart, routing, and security proof.
