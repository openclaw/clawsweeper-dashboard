## What This Changes

The PR makes `grep` and `rg` tool-display summaries replace recursive, control-character-containing, backtick-containing, or overly long search patterns with neutral `search text` labels while retaining the parsed search target when available.

## System Context

The agent tool-display layer turns shell commands into concise status text shown in browser and log surfaces. For known `grep` and `rg` commands, it parses the pattern and target, then emits a readable search summary without changing command execution.
