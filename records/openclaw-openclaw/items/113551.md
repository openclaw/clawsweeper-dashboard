## What This Changes

This PR makes `grep` and `rg` tool summaries replace recursive, control-character-containing, backtick-containing, or overly long search patterns with a neutral `search text` label while retaining a parsed target when available.

## System Context

Agent shell commands pass through the tool-display formatter before they are shown in chat and logs. The formatter extracts common command details and emits a compact human-readable summary without changing command execution.
