## What This Changes

This PR makes `grep` and `rg` tool summaries fall back to neutral search text when their extracted pattern is recursive, malformed, or contains unsafe display characters.

## System Context

The agent tool-display subsystem converts shell tool arguments into concise browser and log summaries. `grep` and `rg` commands pass through command parsing and summary selection before the resulting detail text is rendered to users.
