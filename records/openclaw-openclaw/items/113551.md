## What This Changes

The branch prevents unsafe `grep` and `rg` patterns from being interpolated into tool-display search summaries, using a neutral summary while retaining the parsed search target when available.

## System Context

The agent tool-display subsystem turns shell command arguments into concise descriptions shown in OpenClaw browser and log surfaces. For `grep` and `rg`, it parses the search pattern and optional target, then emits a readable search summary.
