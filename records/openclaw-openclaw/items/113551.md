## What This Changes

Sanitizes `grep`/`rg` search patterns before rendering tool-display summaries, falling back to neutral search text when a pattern appears recursive or malformed.

## System Context

OpenClaw converts shell-tool commands into concise explain-mode details for browser and log output. This PR changes the search-command branch of that display-only formatter, after command parsing and before presentation.
