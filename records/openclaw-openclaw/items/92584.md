## Summary

Keep open for maintainer review: the PR is a focused hardening change with no blocking code finding, but it intentionally removes a shipped assistant-media query-token fallback that existing clients or saved URLs may still use.

## What This Changes

This PR removes assistant-media query-string token auth from Control UI read authorization, updates gateway media tests to bearer headers, and adds an e2e regression for query-token rejection with bearer/mediaTicket success.

## Best Possible Solution

Land the narrow fallback removal after maintainer acceptance, with release-note context naming bearer auth and scoped mediaTicket URLs as the supported assistant-media paths.
