Keep open for maintainer review: the patch is focused, source-backed, and has sufficient live-output proof, but it intentionally removes shipped assistant-media query-token auth and needs maintainer acceptance of that compatibility break.

## What This Changes

The branch removes Control UI assistant-media `?token=` auth, updates media tests to use bearer headers, and adds an e2e regression proving `?token=` is rejected while bearer and mediaTicket access still work.

## Best Possible Solution

Land the narrow fallback removal after maintainer acceptance, with release-note context naming bearer auth and scoped mediaTicket URLs as the supported assistant-media paths.
