## Summary

Keep this PR open for maintainer review. The patch looks correct and well proven, but it intentionally removes a shipped assistant-media query-token fallback, so maintainer acceptance of the security and compatibility tradeoff is the remaining blocker.

## What This Changes

The branch makes Control UI assistant-media read auth header-or-mediaTicket only, updates gateway media tests to bearer headers, and adds a live-route regression rejecting a correct `?token=` secret.

## Best Possible Solution

Land the narrow fallback removal after maintainer acceptance, with bearer auth and scoped mediaTicket URLs as the supported assistant-media paths.
