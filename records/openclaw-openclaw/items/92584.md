## Summary

Keep open for maintainer merge-risk acceptance: the patch is a narrow security hardening that removes the remaining assistant-media query-token auth path, but that path is shipped compatibility for existing media links and paired-device query-token clients.

## What This Changes

The PR removes Control UI assistant-media query-token auth, updates gateway media tests to use bearer headers, and adds an e2e regression that rejects `?token=` while preserving bearer and `mediaTicket` access.

## Best Possible Solution

Land the narrow removal once maintainers accept the compatibility break, with release-note or upgrade text that bearer headers and scoped `mediaTicket` URLs are the supported assistant-media auth paths.
