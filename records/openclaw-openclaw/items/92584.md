## What This Changes

The PR removes Control UI assistant-media `?token=` auth, switches existing media tests to bearer auth, and adds an e2e regression proving query tokens are rejected while bearer and mediaTicket access still work.

## Best Possible Solution

Land the narrow fallback removal after explicit maintainer acceptance, with release-note context naming bearer auth and scoped mediaTicket URLs as the supported assistant-media paths.
