## Summary

Keep open: current main implements skill readiness checks and provides several adjacent plugin-health diagnostics, but the requested CLI status integration and operator-visible signal for model-routed skill commands remain unresolved.

## What This Changes

Requests skill requirement validation, plugin registry diagnostics in CLI status, and an operator-visible signal when a skill command is rewritten for model-directed execution.

## Best Possible Solution

Narrow or split the issue into two decisions: define whether CLI status should summarize existing plugin diagnostics without duplicating discovery, and expose model-routed skill invocation through a structured debug or trace signal rather than an unconditional warning.
