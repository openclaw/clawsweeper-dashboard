## Summary

Keep this issue open but narrow it to the remaining product decision: skill requirement checks and plugin-health status diagnostics now exist, while model-routed skill commands still lack a dedicated operator-visible routing signal. The recent maintainer-context review also explicitly retained that remaining work.

## What This Changes

Add skill requirement validation, expose plugin-loading diagnostics in status output, and identify when a skill command is rewritten for model-directed execution.

## Best Possible Solution

Retain the existing `skills check` and plugin-health implementations, narrow this issue to skill-routing observability, and emit a structured debug or trace event when an explicit skill command takes the model-routed path, with focused routing tests and concise public documentation.
