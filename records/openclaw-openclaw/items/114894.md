## What This Changes

Adds `skills.list()` and `skills.read(name)` to Code Mode so a Code Mode guest can discover the skills shown in its prompt and load an eligible skill’s instructions on demand.

## System Context

Code Mode runs user-directed JavaScript in an isolated worker and sends approved bridge requests back to the agent runtime. Skills are assembled for the system prompt during attempt startup; this change carries that eligible catalog into Code Mode and returns selected instruction bodies through the bridge.

  F --> G[Code Mode result]
