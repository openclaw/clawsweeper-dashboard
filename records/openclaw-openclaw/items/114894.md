## What This Changes

This PR gives Code Mode runs a `skills` global so they can list skills shown in the system prompt and load an eligible skill’s instructions on demand without granting general filesystem access.

## System Context

Code Mode is OpenClaw’s sandboxed JavaScript/TypeScript execution path for an agent run. The embedded-run startup path builds the skills prompt and tool catalog, then Code Mode bridge requests expose selected skill metadata and bodies to the guest.

## Architecture Diagram

flowchart LR
  A[Resolved skills] --> B[Skills prompt catalog]
  B --> C[Embedded run preparation]
  C --> D[Code Mode tool catalog]
  D --> E[Sandboxed Code Mode guest]
  E --> F[skills.list and skills.read]
  F --> G[Bridge validates and reads skill body]

## Best Possible Solution

Derive one effective skill set after all run-level restrictions are applied, use that same set both to render the skills prompt and to authorize `skills.list()`/`skills.read()`, then add focused regression coverage for an allowlisted Code Mode run.
