Keep open. ## Best Possible Solution

Capture a current-main WhatsApp reproduction with the saved path, emitted `media://inbound` ID, `media.ttlHours`, active state dir, and gateway logs; then fix the exact media lifetime or state-root mismatch without adding broad path fallbacks.

## Reproduction Assessment

Unclear/no: we do not have a high-confidence current-main reproduction. Source inspection disproves the reported double-save route, but a live WhatsApp run or logs are still needed to verify whether the second-read failure persists through cleanup, TTL, or state-root drift.
