## Summary

Keep this PR open: the mobile drawer fallback shape is useful, but the current head still leaves the focus-ring compatibility fix broken and lacks inspectable real-browser proof.

## What This Changes

The PR adds CSS fallbacks for Control UI focus rings, mobile drawer shadow/backdrop, and the collapsed sidebar accent when color-mix() is unsupported.

## Best Possible Solution

Keep solid --focus-ring values as the default, apply blended focus-ring values only inside @supports or at use sites, retain the ordinary-property mobile drawer fallbacks, and require redacted older-browser proof before merge.

## Solution Assessment

No. The layout.mobile.css fallbacks use the right ordinary-property shape, but base.css needs @supports-guarded custom-property values or use-site fallbacks so the solid ring actually wins without color-mix().
