## What This Changes

The PR adds CSS fallback declarations for Control UI focus rings, mobile drawer shadow/backdrop, and collapsed-sidebar active accents when color-mix() is unsupported.

## Best Possible Solution

Keep the ordinary-property drawer fallbacks, make the solid focus ring the default by moving blended --focus-ring values behind @supports or to use-site fallbacks, then require redacted old-browser visual or live-output proof before merge.
