## Summary

## What This Changes

The branch adds CSS fallback declarations for Control UI focus rings, mobile drawer shadow/backdrop, and collapsed sidebar active accents when color-mix is unsupported.

## Best Possible Solution

Keep solid focus-ring values as the default, move color-mix focus-ring enhancements behind @supports or to use-site fallbacks, retain the ordinary-property mobile fallbacks, refresh the branch, and add redacted browser proof.
