## Summary

Keep this PR open, but it is not merge-ready: the mobile drawer fallbacks use the right ordinary-property cascade shape, while the latest focus-ring change still overrides the solid custom-property fallback with an unguarded color-mix() value, lacks inspectable real behavior proof, and is currently conflicting with main.

## What This Changes

Adds CSS fallback declarations for Control UI focus rings, mobile drawer shadow/backdrop, and collapsed sidebar accent styles on browsers without color-mix() support.

## Best Possible Solution

Keep the solid focus-ring value as the default, move the blended per-theme color-mix() focus-ring values behind @supports or to use-site fallbacks, preserve the ordinary-property mobile drawer fallbacks, refresh the branch against main, and require inspectable older-browser proof.

## Solution Assessment

No, not as-is. The mobile drawer ordinary-property fallbacks are the right approach, but base.css needs @supports-guarded custom-property values or use-site fallbacks so the solid focus ring actually wins in no-color-mix browsers.
