## Summary

This issue remains necessary: its report identifies a complete xAI OAuth inference failure, and the linked open pull request is the concrete candidate fix. Keep the issue open until https://github.com/openclaw/openclaw/pull/113663 receives review and merges; its redacted live HTTP comparison is useful evidence that the proxy specifically requires `x-grok-client-version`.

## What This Changes

Fix xAI OAuth/Grok subscription inference so requests sent through `cli-chat-proxy.grok.com` include the client-version header required by that proxy.

## System Context

The bundled xAI plugin turns OAuth credentials and model discovery into provider configuration for the agent runtime. That configuration is carried through the model registry into outbound responses requests, where the Grok subscription proxy can accept or reject inference based on request headers.
