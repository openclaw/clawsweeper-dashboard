## What This Changes

The PR changes session-listing read helpers to reuse safe process-held SQLite handles rather than opening read-only connections repeatedly for each session row.

## System Context

Gateway `sessions.list` composes session records with agent and shared-state metadata for RPC consumers and the Control UI sidebar. Its state helpers select either a safe process-owned SQLite handle or a fresh read-only connection before returning the session list.
