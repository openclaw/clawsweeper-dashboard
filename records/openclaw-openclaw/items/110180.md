## Summary

Keep open: current Talk Mode has a realtime PCM playback path, but ordinary assistant-response TTS is still invoked only after a final chat event; the requested first-audio latency work therefore remains meaningful and needs an Android/gateway design decision.

## What This Changes

Measure and reduce Android Vera Talk Mode time from wake-word or end-of-turn to first audible TTS audio, with streamed playback and first-byte telemetry.

## Best Possible Solution

Add device-side end-of-utterance-to-first-audio instrumentation, establish a baseline for the existing realtime relay, and only then extend the canonical relay/output contract to emit cancellable partial audio if the measured path still waits for final text.
