## Summary

This PR addresses a real Anthropic Vertex OAuth-stall path and has credible terminal proof, but its new fetch wrapper drops cancellation carried by a `Request` input when no `init.signal` is supplied. That is a narrow P2 compatibility regression in the generic `fetch` contract, so it needs one mechanical repair before merge.

## What This Changes

The branch adds a 30-second request timeout, a 10-second proxy connection timeout, and abort propagation/cleanup to the Anthropic Vertex Google-auth fetch implementation, with focused tests.

## Best Possible Solution

Preserve every caller-provided fetch cancellation source—at minimum the input `Request` signal when `init.signal` is absent—while retaining the PR’s bounded timeout, abort reason propagation, and listener cleanup.
