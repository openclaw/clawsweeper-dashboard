## What This Changes

This PR adds a default-off `commands.showRuntimeStatusOnReset` setting that appends the resolved model and thinking level to successful bare `/new` and `/reset` responses from chat commands and Gateway requests.

## System Context

OpenClaw accepts reset commands through channel command handling and the Gateway agent API, resets the target session, then returns an acknowledgement to the caller. This PR changes that final acknowledgement so an opt-in setting can include the reset target's resolved model and thinking level.
