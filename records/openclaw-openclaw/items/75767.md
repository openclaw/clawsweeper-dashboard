## Summary

Keep open: current main still relies on targeted `lsof` for single-port ownership and restart checks; the merged missing-command repair does not address an installed `lsof` blocking on SMB, and the related open PR explicitly leaves this central path unchanged.

## What This Changes

Prevent macOS Gateway restart, force, and status operations from hanging when `lsof` blocks while inspecting SMB-mounted volumes.

## Best Possible Solution

Separate cheap port availability from process ownership: use a bounded non-spawning probe for ordinary health and release waits, invoke a hard-time-limited ownership diagnostic only after a real conflict, preserve PID-safe stale-process cleanup, update every restart/force/status caller consistently, and validate the result on macOS with an SMB mount under load.

Rationale: The observable bug is clear, but the replacement must balance non-blocking health checks against PID ownership, stale-process safety, diagnostics, and consistent behavior across restart, force, and status paths.

Options:

- **Layer availability and ownership (recommended):** Use a non-spawning bounded probe for routine availability, then run time-limited `lsof` only when process identity is actually needed.
- **Harden lsof everywhere:** Keep `lsof` as the primary mechanism but batch calls where possible and enforce strict timeouts and consistent failure handling across every caller.
- **Wait for stronger live evidence:** Keep the current implementation until the SMB hang is independently reproduced on current main, accepting the reported restart delay in the meantime.

## Reproduction Assessment

No independent current-main live reproduction is available, but the reporter supplied consistent macOS SMB results across releases 2026.4.26 and 2026.5.22, and the relevant `lsof`-dependent source paths remain present.

## Solution Assessment

No, replacing every `lsof` call with a bind probe alone is not the best fix because stale-process cleanup and restart verification need listener ownership; a layered availability-first design with bounded ownership diagnostics is safer and more maintainable.
