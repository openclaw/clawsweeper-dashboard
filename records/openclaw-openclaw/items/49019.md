## What This Changes

Request an opt-in result-return mode for `POST /hooks/agent` that waits for an isolated agent turn, returns a machine-readable result, and can suppress the main-session announcement for machine-callback flows.

## Best Possible Solution

Resolve the hook result contract and audit/security boundary on the linked implementation PR, then either land that PR as the canonical fix or close it with the chosen supported alternative.
