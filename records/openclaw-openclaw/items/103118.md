## Summary

The previous P1 blocker remains on the current head: bundled-origin filtering is applied before selected-provider ownership is derived, so the security audit can omit a policy-eligible external provider credential that runtime can use.

## What This Changes

The PR rewrites web-search credential-presence auditing and expands regression coverage for plugin policy, provider-specific config, SecretRefs, environment variables, auth profiles, keyless providers, and credential fallbacks.

## Best Possible Solution

Derive selected-provider ownership from all policy-eligible manifests, retain bundled-only scope solely for public-artifact and manifest-environment probes, and prove an installed external provider has matching audit and runtime results.
