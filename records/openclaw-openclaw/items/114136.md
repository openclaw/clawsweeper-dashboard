## What This Changes

The PR makes QQBot apply OpenClaw’s shared context-visibility setting to quoted-message text, adding QQBot configuration validation, tests, metadata, and documentation for restricted conversations.

## System Context

QQBot receives an inbound message and may attach a referenced message as supplemental context before OpenClaw sends the prompt to an agent. This PR places the shared visibility decision between quote resolution and prompt construction so channel allowlist policy can omit a quoted body while retaining reply identity.
