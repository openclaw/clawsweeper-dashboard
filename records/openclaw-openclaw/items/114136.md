## What This Changes

The PR makes QQBot filter quoted-message text before it is added to an agent prompt under `contextVisibility`, adds focused quote-policy tests, and documents QQBot support for that existing setting.

## System Context

QQBot converts inbound messages and referenced quotes into supplemental context for an agent prompt. The quote stage receives a cached quote author when available, evaluates the channel visibility policy against QQBot sender access rules, then emits either the quote body or an ID-only reference.
