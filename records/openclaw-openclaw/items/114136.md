## What This Changes

The PR changes QQBot quote handling so cached quote authors pass the existing supplemental-context visibility policy before their quoted text is added to agent input, while unidentified cache-miss quotes are hidden only in restricted conversations.

## System Context

QQBot inbound events pass through access-policy evaluation and message-context assembly before their text is supplied to an agent. Quote resolution enriches a reply with referenced-message content, so it must preserve the same sender-visibility boundary as the primary inbound message.
