## What This Changes

The PR changes QQBot quote resolution so cached and inline quoted message text is withheld from agent context when the quoted sender does not pass the existing visibility policy in a restricted conversation.

## System Context

QQBot turns incoming messages into agent input through its inbound gateway. When a message is a reply, the quote stage resolves cached or inline quoted text, decides whether that supplemental context is visible to the sender, and passes either rendered text or an id-only reply marker into the agent context.
