## What This Changes

This PR adds QQBot support for OpenClaw’s context-visibility setting so quoted-message bodies are filtered before being added to agent input in restricted conversations.

## System Context

QQBot receives inbound messages and resolves reply/quote context before composing the prompt delivered to the agent. This change decides whether quote text may cross that channel boundary using the configured sender-visibility policy, while retaining only a reply identifier when the text is not allowed.
