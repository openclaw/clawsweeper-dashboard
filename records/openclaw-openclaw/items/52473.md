## Summary

Keep open: current main and the latest release still turn explicit non-tool skill slash invocations into advisory model text instead of injecting SKILL.md, and the remaining fix needs a maintainer-defined prompt authority and security boundary.

## What This Changes

Request deterministic loading of a slash-invoked skill's SKILL.md content before the model handles the user's arguments.

## Best Possible Solution

Define one shared skill-invocation trust contract, then implement deterministic SKILL.md loading for explicit non-tool slash invocations through the common command/session path with security, docs, and regression coverage.
