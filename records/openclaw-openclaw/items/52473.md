## Summary

Keep open: current main and v2026.6.11 still route explicit non-tool skill slash commands by rewriting the request into advisory model text rather than injecting SKILL.md, and the remaining work needs a maintainer product/security contract.

## What This Changes

Requested behavior is deterministic loading of a slash-invoked skill's SKILL.md into model context instead of relying on the model to voluntarily read it.

## Best Possible Solution

Define one explicit skill-invocation trust contract, then implement deterministic SKILL.md loading for non-tool slash-invoked skills through the shared command/session path with focused security, prompt, docs, and regression coverage.
