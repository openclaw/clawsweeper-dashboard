The issue requests deterministic SKILL.md loading when a user explicitly invokes a skill with a slash command.

## Best Possible Solution

Define one shared guarded skill-invocation contract, then implement deterministic SKILL.md loading for non-tool slash-invoked skills across the shared command/session path with security, docs, and regression coverage.
