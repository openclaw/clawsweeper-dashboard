## Summary

Keep open: current main and v2026.6.11 still route explicit non-tool skill slash commands by rewriting the turn into advisory model text rather than injecting SKILL.md, and the remaining choice is a prompt-authority/security contract.

## What This Changes

Request deterministic loading or injection of SKILL.md content when a user invokes a non-tool skill via `/skill <name>` or a direct skill slash command.

## Best Possible Solution

Define one explicit trust contract for slash-invoked skills, then implement deterministic SKILL.md loading in the shared command/session path with prompt-boundary, docs, and regression coverage.
