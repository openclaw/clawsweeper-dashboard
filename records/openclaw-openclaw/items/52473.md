## Summary

Keep open: current main still resolves explicit skill slash commands but non-tool skill invocations are rewritten into advisory model text, not guaranteed SKILL.md context, and the remaining fix needs a maintainer-owned security and instruction-authority decision.

## What This Changes

Request deterministic SKILL.md loading when a user explicitly invokes a non-tool skill slash command such as `/skill-name args`.

## Best Possible Solution

Define one explicit trust and invocation contract for slash-invoked skills, then implement deterministic non-tool SKILL.md loading in the shared command/session path with security, docs, and regression coverage.
