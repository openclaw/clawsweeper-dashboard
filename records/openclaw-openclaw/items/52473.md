## What This Changes

The issue requests deterministic loading of a skill's SKILL.md when a user explicitly invokes the skill by slash command.

## Best Possible Solution

Define one explicit skill-invocation and trust-boundary contract, then implement deterministic SKILL.md loading for non-tool slash-invoked skills across the shared command/session path with focused security and regression coverage.
