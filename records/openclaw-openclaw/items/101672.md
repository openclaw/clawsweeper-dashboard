## What This Changes

The issue asks OpenClaw to make doctor session-route repair recognize persisted literal `openai` auto overrides so drifted sessions can be repaired.

## Best Possible Solution

Choose one canonical owner for literal `openai` auto session-route state, then add focused doctor repair coverage that clears stale auto fallback pins while preserving explicit/user OpenAI selections.
