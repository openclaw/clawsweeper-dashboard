Full review comments:

- **[P1] Preserve realtime WebSocket base URLs:** `extensions/elevenlabs/shared.ts:21`
  - body: `normalizeElevenLabsRealtimeBaseUrl` calls this shared helper before it constructs or maps the WebSocket URL, so restricting the helper to HTTP(S) makes direct `wss://` configuration throw and also contradicts the PR body's claim that direct WS(S) endpoints are supported.   - confidence: 0.99
- **[P2] Reject query and fragment components:** `extensions/elevenlabs/shared.ts:27`
  - body: The parsed URL is used only for its scheme and the original string is returned. Callers then append `/v1/...` by string interpolation, so a value such as `https://host?token=x` requests `/` with the API path embedded in the query, while a fragment prevents the appended path from reaching the server at all. Reject unsupported search/hash components or switch all callers to pathname-aware URL construction, with regression cases for both forms.
  - confidence: 0.98
