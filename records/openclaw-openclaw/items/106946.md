## Summary

Keep this PR open, but do not merge the current head: validation belongs at the ElevenLabs provider boundary, yet both URL serializers regress the established slash-free base URL contract and contradict the added root-URL test expectations.

## What This Changes

Adds HTTP(S) validation and user-friendly errors to the shared ElevenLabs base URL normalizer, reuses it for realtime WebSocket URLs, and adds normalization tests.

## Best Possible Solution

Keep validation and secret-safe errors in the shared provider helper, but serialize both HTTP and realtime base URLs without trailing slashes and assert the final HTTP and WebSocket endpoint strings, not only the intermediate values.
