## Label Justifications

- `P2`: The issue affects agent capability visibility for users with large skill catalogs, but it is bounded to skills prompt construction and has technical workarounds.
- `impact:session-state`: The agent-visible skill snapshot can omit eligible installed skills, so the model's session context can drift from actual user state.

## Summary

Keep open. Current main still truncates the prompt-visible skills list to a budget-fitting alphabetical prefix with a count-only model-facing note, while the narrow omitted-key fix remains an open PR and priority/pinning needs product/API direction.

## What This Changes

The issue asks OpenClaw to make skills prompt truncation visible and configurable so user-created or critical skills are not silently omitted from the agent-visible skill list.

## Best Possible Solution

Stage the narrow omitted-skill visibility fix first, then make an explicit maintainer decision on whether priority/pinning or smart skill indexing belongs in the core skills config contract.
