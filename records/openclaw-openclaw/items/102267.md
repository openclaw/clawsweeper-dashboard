## Summary

Keep open: current main still sends Telegram cached bot-authored messages into the chat-window recap with the raw Telegram sender string, and the reporter has now supplied live Telegram DM evidence that the agent can misread its own prior reply as a separate participant.

## What This Changes

The issue asks for Telegram chat-window context to label an agent's own prior direct-message replies with the configured self identity or an explicit self marker instead of the raw bot profile name.

## Best Possible Solution

Normalize Telegram self-authored cached messages at the shared Telegram cache or cache-to-prompt boundary so both direct-message and group chat-window recaps use the configured account identity plus a clear self marker.
