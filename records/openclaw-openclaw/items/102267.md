## Summary

Keep open: current main still records Telegram outbound/cache sender labels from raw Telegram `from` profile data and passes that sender string through to the chat-window recap, while the existing configured self-marker path is group-history-only.

## What This Changes

The issue asks for Telegram direct-message chat-window recap entries for the agent's own prior messages to use a configured self/persona identity or explicit self marker instead of the raw Telegram bot profile name.

## Best Possible Solution

Normalize bot-authored Telegram sender identity in the Telegram-owned cache-to-prompt path so direct-message and group chat-window context agree on a configured self label without changing the generic core formatter.
