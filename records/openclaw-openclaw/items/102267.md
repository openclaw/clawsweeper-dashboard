## Summary

Keep open: current main and the latest release still cache Telegram bot-authored messages with the raw Telegram `from` sender and pass that string into chat-window recap, while the configured ` (you)` self label remains group-history-only; the new live reproduction comment removes the prior proof gap.

## What This Changes

The issue asks OpenClaw to label self-authored Telegram DM messages in chat-window recap context with the agent/self identity instead of the raw bot profile sender.

## Best Possible Solution

Normalize bot-authored Telegram sender identity in the Telegram-owned outbound cache or cache-to-prompt projection so direct-message and group chat-window context consistently use the configured self label without teaching the generic core formatter Telegram-specific rules.
