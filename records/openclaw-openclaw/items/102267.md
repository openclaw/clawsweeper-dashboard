## Summary

Keep open: current main still records Telegram bot-authored cached messages with the raw Telegram `from` sender string and the core chat-window formatter prints that string unchanged, while the configured ` (you)` self-marker remains group-history-only.

## What This Changes

The issue asks OpenClaw to label an agent's own prior Telegram chat-window recap messages with a configured self identity instead of the raw Telegram bot profile name.

## Best Possible Solution

Normalize bot-authored Telegram sender identity in the Telegram-owned cache or cache-to-prompt projection so direct-message and group chat-window context use the configured self label consistently.
