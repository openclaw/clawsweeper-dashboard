## Summary

## Best Possible Solution

Implement prompt metadata parity only in `resolveCommandsSystemPromptBundle()`, using the embedded-runner pattern with account-aware capabilities and channel action/message guidance, while leaving channel-selective delivery to existing message-tool configuration or a separate maintainer-approved API follow-up.
