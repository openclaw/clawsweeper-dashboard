## Summary

Keep open. Current main still has the same command prompt reconstruction gap: normal inbound/runtime prompts carry channel metadata, but `/context` and `/export-session` rebuild their prompt through a bundle that still omits channel, shell, capabilities, and channel action hints.

## What This Changes

The issue requests agent-visible communication-channel context and optional selective reply routing for messages received through dashboard, Telegram, and other channels.

## Best Possible Solution

Implement prompt metadata parity in `resolveCommandsSystemPromptBundle()` using the embedded-runner pattern with account-aware capabilities and channel action/message guidance, while keeping model-selected delivery policy separate.
