## Summary

Keep open. Current main exposes channel metadata in normal inbound/runtime paths, but slash-command prompt reconstruction still omits channel/capability/shell metadata, and the request also includes broader selective reply routing that needs maintainer scoping.

## What This Changes

The issue requests agent context for the incoming communication channel and optionally channel-selective reply behavior.

## Best Possible Solution

Implement command/export prompt metadata parity in resolveCommandsSystemPromptBundle only, including account-aware channel capabilities/actions and runtime shell/host fields, then split prompt-driven selective channel routing into a separate maintainer-approved design.
