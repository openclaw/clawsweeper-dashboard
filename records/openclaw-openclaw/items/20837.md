## What This Changes

The issue asks for agents to know which communication channel delivered a message and, optionally, to control which channel receives replies.

## Best Possible Solution

Implement prompt metadata parity only in `resolveCommandsSystemPromptBundle()`, using the embedded-runner pattern with account-aware capabilities and channel action/message guidance, while leaving selective delivery policy to existing message-tool configuration or a separate API follow-up.
