## Summary

Keep open. Current main still exposes channel metadata in normal inbound/agent-run prompts, but slash-command prompt reconstruction for `/context` and `/export-session` still omits channel/capabilities/shell/action metadata; the only linked candidate fix is closed unmerged.

## What This Changes

The issue requests exposing the incoming communication channel to the agent and, optionally, allowing replies to be constrained to selected channels.

## Best Possible Solution

Implement command prompt metadata parity in `resolveCommandsSystemPromptBundle()` while keeping model-directed selective delivery under existing host-controlled routing or a separate maintainer-approved API follow-up.
