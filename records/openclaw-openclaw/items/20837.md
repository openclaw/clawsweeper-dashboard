## Summary

Keep open. Current main still solves normal inbound channel awareness, but slash-command prompt reconstruction continues to drop runtime channel metadata, and the optional selective-routing part needs maintainer product scoping rather than cleanup closure.

## What This Changes

The issue asks for agent prompts to include the incoming communication channel and optionally let replies be limited to selected channels.

## Best Possible Solution

Implement prompt metadata parity in `resolveCommandsSystemPromptBundle()` using the embedded-runner pattern with account-aware capabilities and channel guidance, while treating selective reply routing as a separate maintainer-approved API or documented non-goal.
