## Summary

Keep open. Current main and the latest release still omit channel/capability/shell/action metadata when slash-command prompt reconstruction calls `resolveCommandsSystemPromptBundle()`, while the normal run path already has the needed metadata; the related fix PR is closed unmerged.

## What This Changes

The issue requests channel-origin context in agent prompts and, optionally, channel-selective replies.

## Best Possible Solution

Implement command prompt runtime metadata parity in `resolveCommandsSystemPromptBundle()`, then split prompt-driven channel-selective routing into a separate maintainer-approved API or policy item.
