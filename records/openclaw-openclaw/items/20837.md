## Summary

Keep open. Current main and the latest release still omit channel/capabilities/shell runtime metadata from slash-command prompt reconstruction, while the normal inbound and embedded-runner paths already carry the channel metadata; the remaining selective reply-routing part needs maintainer product scoping.

Request to expose the originating communication channel to the agent and optionally let replies be limited to selected channels.

## Best Possible Solution

Implement command prompt runtime metadata parity in resolveCommandsSystemPromptBundle(), then split prompt-driven channel-selective routing into a maintainer-approved API or policy follow-up.
