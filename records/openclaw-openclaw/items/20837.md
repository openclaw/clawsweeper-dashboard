## Summary

Keep open: current main still has a source-confirmed gap where `/context` and `/export-session` rebuild the command system prompt without the channel, capabilities, shell, or channel-action metadata that normal agent runs already receive.

## What This Changes

The issue requests agent awareness of the originating communication channel, with optional channel-selective reply behavior.

## Best Possible Solution

Implement prompt metadata parity in `resolveCommandsSystemPromptBundle()` and leave channel-selective delivery under existing message-tool policy or a separate maintainer-approved API follow-up.
