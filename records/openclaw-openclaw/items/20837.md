## Summary

Keep open. Current main and the latest release still drop runtime channel/capability/shell/action metadata in slash-command prompt reconstruction, the direct fix PR https://github.com/openclaw/openclaw/pull/21271 is closed unmerged, and prompt-driven selective reply routing still needs product scoping.

## What This Changes

The issue requests exposing the inbound communication channel to the agent and optionally allowing replies to be limited to specific channels.

## Best Possible Solution

Implement command prompt runtime metadata parity in resolveCommandsSystemPromptBundle(), then track prompt-driven channel-selective replies as a separate maintainer-approved API or policy item.
