## Summary

Keep open: current main already carries channel metadata in normal inbound runs, but the slash-command prompt reconstruction path still omits channel/capability/shell/action runtime metadata and the direct fix PR closed unmerged.

## What This Changes

Request to expose the inbound communication channel to the agent and potentially let replies be limited to selected channels.

## Best Possible Solution

Implement command prompt runtime metadata parity in `resolveCommandsSystemPromptBundle()`, then split prompt-driven channel-selective delivery into a separate maintainer-approved API or policy item.
