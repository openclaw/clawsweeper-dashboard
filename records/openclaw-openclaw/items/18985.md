## Summary

## What This Changes

Request support for installing and running OpenClaw from Windows 11 MSYS2/MINGW Unix-like shells, including fish-aware PATH guidance.

## Best Possible Solution

Maintain one explicit Windows Unix-shell policy: either support MSYS2/MINGW and fish in install.sh with docs, tests, and Windows smoke proof, or document PowerShell and WSL2 as the supported Windows paths.

## Reproduction Assessment

Yes, at source level: current scripts/install.sh sends MSYS/MINGW-style OSTYPE values to the unsupported-OS branch, and the fish PATH concern is visible in bash/zsh-only code paths. I did not run a real Windows 11 MSYS2 smoke test in this read-only review.

## Solution Assessment

Unclear until maintainers decide the support boundary. The maintainable solution is either tested MSYS2/MINGW plus fish support in installer/docs/tests, or explicit documentation that Windows users should use PowerShell or WSL2 instead.
