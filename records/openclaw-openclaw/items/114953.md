## What This Changes

Adds `--delete-resources` to remove OpenClaw-managed Kubernetes resources from a shared namespace while retaining full namespace deletion through `--delete` and `--delete-namespace`.

## System Context

The Kubernetes deployment script turns operator flags and `OPENCLAW_NAMESPACE` into `kubectl` operations. Its teardown mode determines whether OpenClaw removes only Kustomize-managed resources or the entire selected namespace.
