- **[P2] Derive the Bedrock fallback region from AWS config:** `src/gateway/gateway-models.profiles.live.test.ts:2716`
  - body: When the explicit fallback path writes a Bedrock provider config with no existing `baseUrl`, this fallback pins `https://bedrock-runtime.us-east-1.amazonaws.com`. Please derive the endpoint from the same config/env source, or avoid setting a standard endpoint when AWS config should decide.
