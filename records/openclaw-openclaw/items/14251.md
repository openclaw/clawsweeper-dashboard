## Summary

Keep open. Current main and v2026.6.11 still route macOS gateway stop/uninstall through the user LaunchAgent path and gui launchd domain, so system LaunchDaemon lifecycle handling remains unresolved and security-sensitive.

## What This Changes

Request support for detecting and managing macOS system-level gateway LaunchDaemons during stop, uninstall, and status flows.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping the user LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
