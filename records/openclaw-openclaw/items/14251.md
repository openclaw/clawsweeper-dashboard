## Summary

Keep open. Current main and v2026.6.11 still manage macOS gateway stop/uninstall through the user LaunchAgent path and gui/<uid> launchd domain; system LaunchDaemon discovery is diagnostic-only, and the open duplicate-manager PRs intentionally do not settle full system stop/uninstall lifecycle support.

## What This Changes

Request to make gateway stop, uninstall, and status detect system-level macOS LaunchDaemons and either manage them safely or guide operators to the correct elevated action.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping user LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
