## Summary

Keep open. Current main and v2026.6.11 still manage macOS gateway stop/uninstall through the user LaunchAgent path and gui launchd domain, while system LaunchDaemon discovery is diagnostic-only, so the requested lifecycle support remains unresolved and security-sensitive.

## What This Changes

Issue requests macOS gateway stop, uninstall, and status lifecycle support for system-level LaunchDaemons alongside user LaunchAgents.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping the user LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
