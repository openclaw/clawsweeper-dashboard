## Summary

Keep open. Current main and v2026.6.11 still manage macOS gateway stop/uninstall through the user LaunchAgent path and gui launchd domain; `gateway status --deep` can discover LaunchDaemons diagnostically, but it does not provide system LaunchDaemon lifecycle control.

## What This Changes

The issue requests macOS gateway lifecycle commands that detect system-level LaunchDaemons and either manage them safely or give accurate elevated-command guidance.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping the user LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
