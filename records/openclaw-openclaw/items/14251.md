## Summary

Keep open. Current main and v2026.6.11 still route macOS gateway stop/uninstall through the user LaunchAgent path and gui launchd domain, while system LaunchDaemon discovery is diagnostic-only; the remaining work needs a privileged launchd scope decision.

## What This Changes

Request to make gateway stop, uninstall, and status detect and safely handle macOS system-level LaunchDaemons under /Library/LaunchDaemons.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping the user LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
