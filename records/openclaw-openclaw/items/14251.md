## Summary

Keep open. Current main and v2026.6.11 still route macOS gateway stop/uninstall through the user LaunchAgent path and gui launchd domain, while system LaunchDaemon discovery is diagnostic-only and the remaining privileged lifecycle contract needs maintainer direction.

## What This Changes

Request system-level macOS LaunchDaemon detection and lifecycle handling for gateway stop/uninstall, with accurate status/guidance when a root-owned daemon remains active.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
