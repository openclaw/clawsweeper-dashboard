## Summary

Keep open. Current main and v2026.6.11 still manage macOS gateway stop/uninstall through the user LaunchAgent path and gui launchd domain; `gateway status --deep` can discover system LaunchDaemons diagnostically, but that does not provide lifecycle control.

## What This Changes

Request to make gateway stop/uninstall detect and handle system-level macOS LaunchDaemons instead of reporting user LaunchAgent success while a system daemon remains running.

## Best Possible Solution

Define one explicit macOS launchd user/system scope contract across install, status, stop, uninstall, doctor, docs, and tests, keeping the user LaunchAgent as the safe default and adding only an audited explicit LaunchDaemon path or guidance flow.
