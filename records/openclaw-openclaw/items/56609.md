## Summary

Keep open: current main still uses `.jsonl.deleted.*` and `.jsonl.reset.*`, and retention plus disk-budget paths can physically remove retained transcript artifacts. The merged role-ordering reset fix addressed one hard-delete path, but the broader durable archive naming and no-delete policy requested here is still unresolved.

## What This Changes

The issue requests changing session archive naming/storage from `.deleted.*` and `.reset.*` toward permanent archive semantics, with no OpenClaw code path physically deleting session transcript files.

## Best Possible Solution

Define a canonical durable session-archive contract, add any needed doctor migration for existing suffixes, update cleanup/disk-budget behavior to match that contract, and align docs/tests around explicit retention and purge semantics.
