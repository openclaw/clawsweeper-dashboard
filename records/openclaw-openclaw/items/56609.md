## Label Justifications

- `impact:data-loss`: The reported impact is retained transcript artifacts being treated as disposable and later lost or physically removed.

## Summary

Keep open: current main and the latest release still use `.jsonl.deleted.*` and `.jsonl.reset.*` archive names and still have retention and disk-budget paths that can physically remove transcript archives. The merged role-ordering reset fix resolved one hard-delete path, but it did not settle the broader durable archive naming and never-delete policy requested here.

## What This Changes

The issue asks OpenClaw to rename retained session transcript archive suffixes away from `.deleted.*`/`.reset.*` and adopt a durable archive policy where session transcripts are moved or renamed rather than removed.

## Best Possible Solution

Define a maintainer-approved durable transcript archive contract, keep existing `.deleted.*` and `.reset.*` files readable or migratable, then update new archive naming, cleanup defaults, disk-budget behavior, docs, and tests together.

## Reproduction Assessment

Yes, at source level. Current main still produces `.jsonl.deleted.*` and `.jsonl.reset.*` archive names and still has retention and disk-budget paths that physically remove archive artifacts.

## Solution Assessment

No final implementation is selected yet. A rename-only patch would be too narrow because suffixes, parsers, retention config, disk-budget cleanup, docs, tests, and migration expectations all need one coherent contract.
