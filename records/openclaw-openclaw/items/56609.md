## Summary

Keep open: current main still creates `.jsonl.deleted.*` and `.jsonl.reset.*` transcript archives, and current retention plus disk-budget paths can physically remove retained session artifacts. The merged role-ordering reset fix addressed one concrete hard-delete path, but the broader archive naming, migration, and no-delete policy requested here is still unresolved.

## What This Changes

The issue requests replacing destructive-sounding session transcript archive names with archive-oriented retention semantics and preventing OpenClaw session code from physically deleting transcript files.

## Best Possible Solution

Define one durable transcript lifecycle contract: retained transcripts should use archive-oriented names or storage, old suffixes should migrate through doctor/backfill rather than runtime shims, and any physical purge should be explicit, documented, and upgrade-tested.
