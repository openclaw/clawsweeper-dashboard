## Summary

Keep open: current main and latest release still create `.jsonl.deleted.*` / `.jsonl.reset.*` archive names and still have retention and disk-budget paths that physically remove session transcript archive artifacts. The merged role-ordering reset fix only repaired one hard-delete path; the broader durable archive naming and never-delete contract remains a maintainer product decision.

## What This Changes

The issue requests renaming retained session transcript artifacts away from `.deleted.*`/`.reset.*` and preventing OpenClaw from physically deleting session transcript files.

## Best Possible Solution

Define a maintainer-approved durable transcript archive contract, then update archive naming, retention defaults, cleanup behavior, docs, tests, and migration or compatibility handling together.

## Solution Assessment

Unclear as a concrete implementation: the direction is valid, but a rename-only patch would be too narrow because shipped file suffixes, retention settings, parsers, docs, tests, and operator expectations all need one maintainer-approved lifecycle contract.
