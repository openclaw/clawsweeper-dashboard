## Summary

Keep open: current main still uses the shipped `.jsonl.deleted.*` and `.jsonl.reset.*` archive naming, and current retention/disk-budget paths can still physically remove retained session artifacts. A merged reset fix handled one hard-delete path, but the broader rename/no-delete storage contract remains unresolved and needs maintainer product direction.

## What This Changes

The issue requests renaming retained session transcript suffixes from `.deleted.*`/`.reset.*` to archival terminology and preventing OpenClaw from physically deleting session files.

## Best Possible Solution

Define one durable transcript lifecycle contract: archive-oriented names or storage for retained transcripts, doctor/backfill handling for existing suffixes, and explicit documented purge behavior with upgrade proof.
