## Summary

Keep open: current main and v2026.6.11 still use `.jsonl.deleted.*` / `.jsonl.reset.*` archive names and still physically remove retained transcript artifacts through retention and disk-budget paths. The merged role-ordering reset fix addressed one hard-delete bug, but the broader archive naming and no-delete storage contract remains unresolved.

## What This Changes

Request to replace destructive-looking session transcript archive names and prevent session transcript files from being physically removed.

## Best Possible Solution

Define one durable transcript lifecycle contract: archive-oriented names or storage for retained transcripts, doctor/backfill handling for old suffixes, and an explicit documented purge policy with upgrade tests.

- **Split policy from terminology:** Use the narrower retention-semantics issue for naming/config clarity and track no-physical-delete behavior as a separate durability decision.
