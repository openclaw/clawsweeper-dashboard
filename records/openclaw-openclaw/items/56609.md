## Summary

Keep open: current main still uses `.jsonl.deleted.*` and `.jsonl.reset.*` archive suffixes, and retention plus disk-budget paths can physically remove those retained transcript artifacts. The merged role-ordering reset fix covered one hard-delete path, but the broader archive naming and no-delete storage contract is still unresolved.

## What This Changes

Request archive-oriented session transcript naming or storage and a policy that OpenClaw never physically deletes session files.

## Best Possible Solution

Define one durable transcript lifecycle contract: future retained transcripts use archive-oriented names or storage, old suffixes migrate through doctor/backfill, and physical purge is explicit, documented, and upgrade-tested.

Options:

- **Adopt archive terminology with explicit purge (recommended):** Rename or move future retained transcripts, add doctor/backfill handling for old `.deleted.*` and `.reset.*` artifacts, and make physical purge an explicit documented retention policy.

- **Split policy from terminology:** Use https://github.com/openclaw/openclaw/issues/80263 for naming/config clarity and track the no-physical-delete policy as a separate durability decision.
