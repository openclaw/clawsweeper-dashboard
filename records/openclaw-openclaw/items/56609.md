## Summary

Keep open: current main still creates `.jsonl.deleted.*` and `.jsonl.reset.*` transcript archives and still has retention and disk-budget paths that physically remove session artifacts. The merged role-ordering reset fix only removed one hard-delete path, while the broader naming, archive storage, migration, and no-physical-delete policy remains a maintainer product decision.

## What This Changes

Request to replace destructive-looking session archive suffixes with archive-oriented naming or storage and prevent OpenClaw from physically deleting session transcript files.

## Best Possible Solution

Define one durable transcript lifecycle contract with archive-oriented names/storage, doctor or migration handling for old suffixes, and explicit upgrade-tested physical purge semantics.
