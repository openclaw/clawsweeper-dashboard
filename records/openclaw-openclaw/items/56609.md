## Summary

Keep open: current main still uses `.jsonl.deleted.*` and `.jsonl.reset.*` archive names, and retention plus disk-budget paths can still physically remove retained session transcript artifacts. The merged role-ordering reset fix at https://github.com/openclaw/openclaw/pull/97544 closed one hard-delete path, but the broader naming, migration, and no-delete policy requested here remains unresolved.

## What This Changes

The issue asks OpenClaw to stop using destructive-looking session archive suffixes like `.deleted.*` and `.reset.*`, and to avoid deleting session transcript files.

## Best Possible Solution

Define one durable transcript lifecycle contract: retained transcripts should use archive-oriented names or storage, old suffixes should migrate through doctor/backfill rather than runtime shims, and any physical purge should be explicit, documented, and upgrade-tested.
