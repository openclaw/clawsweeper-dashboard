## What This Changes

The PR adds a final manager-signal abort check before spawning a local provider sidecar and regression coverage for cancellation during cold start.

## Best Possible Solution

The manager should reject an abandoned startup at the final spawn boundary while continuing shared startup whenever at least one caller lease remains.
