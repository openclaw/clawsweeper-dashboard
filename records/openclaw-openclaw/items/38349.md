## Summary

Keep open: current main and v2026.6.11 still only provide static mention/always group activation plus ambient-room adjacent behavior, not the requested LLM-driven peeking/engaged state machine. The remaining work is a product and security-boundary decision, not conservative cleanup.

## What This Changes

Request to add a default-off contextual group activation mode for Telegram and WhatsApp that uses a lightweight decision model, peeking/engaged state, fallback models, scheduling, decision history, and decision logs to decide when to participate without explicit mentions.

## Best Possible Solution

Define a default-off, consent-aware design that chooses core versus plugin/API ownership, reuses ambient room primitives where possible, and specifies provider exposure, retention/logging, config migration, channel coverage, and proof requirements before implementation.
