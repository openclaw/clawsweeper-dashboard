## Summary

Keep open: current main and v2026.6.11 still expose only `mention` and `always` group activation, while the requested LLM peeking/engaged mode remains a broad product and security decision. Adjacent ambient-room and passive-hook work helps nearby use cases, but it does not supersede this feature request.

## What This Changes

The issue requests an opt-in contextual activation mode for group chats where a lightweight LLM observes messages, decides when to engage without explicit mentions, and logs/configures that decision flow.

## Best Possible Solution

Define a default-off, consent-aware group activation design that settles privacy, provider exposure, logging, config shape, and core-vs-plugin/API ownership before implementation.
