## Summary

Keep open: current main and v2026.6.11 still only support static mention/always group activation, while this request needs a maintainer product and security decision before any implementation.

## What This Changes

The issue requests an opt-in LLM-driven contextual activation mode for group chats that can peek at unmentioned messages, enter an engaged state, disengage over time, log decisions, and support Telegram plus WhatsApp.

## Best Possible Solution

Define a default-off, consent-aware design that chooses core versus plugin/API ownership and specifies provider exposure, retention/logging, config migration, channel coverage, and proof requirements before implementation.
