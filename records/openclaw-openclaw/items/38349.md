## Summary

Keep open: current main and v2026.6.11 still provide static mention/always group activation plus adjacent ambient-room and passive-observation work, but not the requested LLM-driven peeking/engaged contextual activation mode. The remaining work is a product, privacy, provider, config, logging, and channel/plugin API decision rather than conservative cleanup.

## What This Changes

The issue requests an LLM-driven contextual activation mode for Telegram and WhatsApp group chats that can peek at unmentioned messages, engage when relevant, disengage naturally, and expose configuration plus decision logs.

## Best Possible Solution

Define a maintainer-sponsored, default-off group activation contract that preserves group allowlists and mention-gating safety, then implement it through a shared channel/plugin SDK seam or explicitly keep LLM peeking out of core.
