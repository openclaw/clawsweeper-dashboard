## Summary

Keep open: current main and the latest release still do not implement the requested LLM-driven peeking/engaged group activation mode, and the remaining work is a product and security boundary decision rather than conservative cleanup.

## What This Changes

Request a default-off contextual group activation mode for Telegram and WhatsApp that uses a decision model to decide when unmentioned group traffic should activate or disengage the agent.

## Best Possible Solution

Define a default-off, consent-aware design that decides core versus plugin/API ownership, reuses ambient room primitives where possible, and specifies provider exposure, retention/logging, config migration, channel coverage, and proof requirements before implementation.
