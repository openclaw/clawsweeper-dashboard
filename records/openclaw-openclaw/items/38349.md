## Summary

Keep open: current main and v2026.6.11 still only support static mention/always group activation, while this issue asks for a new LLM-driven peeking/engaged mode that needs maintainer product and security direction.

## What This Changes

The issue requests contextual group activation for WhatsApp and Telegram using a lightweight decision model, peeking and engaged states, fallback models, decision history, schedules, logs, and a CLI viewer.

## Best Possible Solution
