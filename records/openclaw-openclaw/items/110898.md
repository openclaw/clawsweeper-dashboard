## Summary

The added live gateway logs resolve the prior real-behavior-proof gap, but the branch still needs an explicit owner decision before merge because its fixed 25,000-character cap silently changes recall context behavior for every query mode, including existing `full` configurations.

The branch caps Active Memory recall context at 25,000 UTF-16 characters, preserves the extracted current request and bounded recent context, changes search-query seeding and diagnostics, and adds regression tests and documentation.

## Best Possible Solution
