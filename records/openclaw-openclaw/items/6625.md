## Summary

Keep open: current main still has hard sub-agent run timeouts and post-timeout handling, but no child-visible pre-timeout warning or grace contract.

## What This Changes

The issue requests a configurable warning/grace period that lets sub-agents checkpoint shortly before `runTimeoutSeconds` terminates the child run.

## Best Possible Solution

Define a maintainer-approved core pre-timeout warning contract, then implement native and ACP delivery with focused lifecycle tests and docs while preserving existing post-timeout recovery.
