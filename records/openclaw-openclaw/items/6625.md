## Summary

Keep open: current main and v2026.6.11 still enforce a hard sub-agent run deadline without warning the child first, while the related reports address inactivity recovery, idle-heartbeat handling, or parent notification after timeout. The remaining work needs product direction because OpenClaw lacks a portable in-flight warning contract across native and ACP runtimes.

## What This Changes

Add a child-visible warning shortly before a sub-agent’s hard run timeout so it can checkpoint unfinished work.

## Best Possible Solution

Define one runtime-neutral child-control capability for safe in-flight notices, use it for fixed-deadline and inactivity triggers where supported, and add only the minimal maintainer-approved configuration with deterministic timer cleanup and native/ACP coverage.
