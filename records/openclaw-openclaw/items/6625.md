## Summary

Keep open: current main and the latest release still have hard sub-agent run timeouts plus post-timeout recovery paths, but no child-visible pre-timeout warning, grace-period config, or warning delivery contract for native or ACP sub-agent runs.

## What This Changes

Request a configurable pre-timeout warning/grace period for sub-agent runs so child agents can checkpoint before `runTimeoutSeconds` termination.

## Best Possible Solution

Define a maintainer-approved core sub-agent pre-timeout warning contract, then implement native and ACP delivery with focused tests and docs while preserving existing post-timeout recovery paths.
