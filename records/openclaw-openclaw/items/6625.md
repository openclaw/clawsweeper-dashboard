## Summary

Keep open: current main still has hard sub-agent run timeouts and post-timeout recovery, but it does not implement a child-visible pre-timeout warning or grace contract.

## What This Changes

The issue requests a configurable warning/grace period that lets sub-agents checkpoint before `runTimeoutSeconds` force-terminates them.

## Best Possible Solution

Define a maintainer-approved core pre-timeout warning contract, then implement native and ACP delivery with focused tests and docs while preserving existing post-timeout recovery.
