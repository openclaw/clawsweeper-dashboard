## Summary

Keep open: current main still has hard sub-agent run timeouts and post-timeout recovery, but no child-visible pre-timeout warning or grace-period contract.

## What This Changes

The issue requests a configurable warning delivered to sub-agents shortly before `runTimeoutSeconds` kills the run so they can checkpoint progress.

## Best Possible Solution

Define a maintainer-approved core sub-agent pre-timeout warning contract, then implement native and ACP delivery with focused tests and docs while preserving existing post-timeout recovery.
