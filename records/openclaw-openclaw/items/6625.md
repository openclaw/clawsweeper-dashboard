The issue requests a configurable child-visible warning or grace period before `runTimeoutSeconds` terminates a long-running sub-agent.

Define a maintainer-approved core pre-timeout warning contract, then implement native and ACP delivery with focused tests and docs while preserving current post-timeout recovery.
