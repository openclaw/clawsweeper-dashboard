## Summary

Keep open. Current main still has hard sub-agent run timeouts and post-timeout recovery, but no configurable pre-timeout child warning or checkpoint grace path.

## What This Changes

Request a configurable warning before sub-agent `runTimeoutSeconds` expires so the child can checkpoint progress before hard termination.

## Best Possible Solution

Keep this open for a maintainer-approved core sub-agent lifecycle contract that defines the grace setting, child warning delivery path, native/ACP behavior, tests, and docs while preserving current post-timeout recovery.
