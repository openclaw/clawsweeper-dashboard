## Summary

Keep open. Current main and the latest release still provide hard sub-agent run timeouts plus post-timeout recovery, but no configurable pre-timeout child warning or checkpoint grace path; the merged timeout-schema PR is adjacent, not a fix for this request.

Request a configurable sub-agent grace period that warns a child agent before `runTimeoutSeconds` so it can checkpoint progress before termination.

## Best Possible Solution

Define a maintainer-approved core sub-agent lifecycle contract for a grace setting, native/ACP child warning delivery, focused tests, and docs while preserving current post-timeout recovery.
