## Summary

Keep open: current `main` still has hard sub-agent run timeouts plus post-timeout recovery/announce behavior, but no child-visible pre-timeout warning or configurable grace-period contract.

## What This Changes

Request a configurable warning delivered to a sub-agent shortly before `runTimeoutSeconds` expires so the child can checkpoint work before termination.

## Best Possible Solution

Define a maintainer-approved core sub-agent pre-timeout warning contract, then implement native and ACP delivery with focused tests and docs while preserving existing post-timeout recovery paths.
