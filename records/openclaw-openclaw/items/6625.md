## Summary

Keep open: current main still supports hard sub-agent run timeouts and post-timeout recovery, but it does not implement a child-visible pre-timeout warning/grace contract.

## What This Changes

Add a configurable pre-timeout warning for sub-agent runs so child agents can checkpoint before `runTimeoutSeconds` kills them.

## Best Possible Solution

Define a maintainer-approved core sub-agent pre-timeout warning contract, then implement native and ACP delivery with focused tests and docs while preserving existing post-timeout recovery paths.
