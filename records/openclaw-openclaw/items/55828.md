  - body: This always writes `graphChannelId` from `activity.channelData?.channel?.id`; when a later activity omits that nested channel object, the merge helper spreads `undefined` over the existing record.   - confidence: 0.87

  - body: These static imports pull private bundled extension `src` modules into a core command/binding helper. That crosses the plugin boundary and can eagerly load optional channel code from hot core paths; use registered channel parsing contracts or a lightweight public artifact instead.
  - confidence: 0.86

  - body: These exports promote Teams send/edit/delete/channel operations into a public SDK facade without a settled API/security decision and full contract alignment.
