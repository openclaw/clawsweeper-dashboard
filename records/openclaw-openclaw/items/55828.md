- **[P1] Migrate channel metadata before requiring it:** `extensions/msteams/src/graph-messages.ts:139-143`
  - body: This makes Graph-backed channel operations require `graphChannelId`, but existing stored Teams channel conversations will not have that newly added field.   - body: This always writes `graphChannelId` from `activity.channelData?.channel?.id`; when a later activity omits that nested channel object, the store merge can spread `undefined` over the existing record.   - confidence: 0.87
- **[P1] Keep target parsing behind channel contracts:** `src/channels/plugins/target-parsing.ts:5-7`
  - body: These static imports pull private bundled extension `src` modules into a core command/binding helper. That crosses the plugin boundary and can eagerly load optional channel code from hot core paths; use registered channel parsing contracts or a lightweight public artifact instead.
  - confidence: 0.86

  - body: These exports promote Teams send, edit, delete, typing, adaptive-card, and channel-edit operations into a plugin SDK facade without a settled API/security decision and current-main contract alignment.
