Full review comments:

- **[P1] Purge jobs through the live cron service:** `src/gateway/server-methods/agents-config-mutations.ts:120`
  - body: During Gateway deletion, this call removes only SQLite rows while the scheduler still retains the jobs in its loaded store. The next full cron persistence replaces the store rows from that snapshot and can recreate the deleted jobs, and they may execute in the meantime. Add a cron-service removal operation that updates memory and persistence together; keep direct database maintenance limited to an offline fallback.
  - confidence: 0.97
- **[P1] Remove the unsupported owner_agent_id predicate:** `src/cron/store/purge-agent-cron-jobs.ts:14`
  - body: Current main's cron row codec stores the agent association as `agent_id` and does not expose `owner_agent_id`. Referencing the latter breaks the typed Kysely query or produces a SQLite error that this helper silently swallows, preventing even the valid `agent_id` deletion. Remove this predicate unless a complete schema, generated-type, codec, and migration change establishes the column; the test must execute the expression against real Kysely/SQLite rather than only assert that a callback was passed.
  - confidence: 0.93
