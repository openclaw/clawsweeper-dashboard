## What This Changes

The PR changes transient npm lock generation so official plugin packaging preserves parent-scoped multi-version dependency forks instead of globally overriding them to one patch version.

## System Context

OpenClaw’s release tooling derives an npm-compatible lockfile from the repository pnpm lock before it packages an official plugin. The generated override choices feed npm installation and ultimately determine whether a plugin tarball can be built reproducibly.
