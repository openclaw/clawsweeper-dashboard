## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Bound awaited LLM hooks with default timeouts:** `src/plugins/hooks.ts:967`
  - body: This switches `llm_input`/`llm_output` into awaited modifying hooks, but the default modifying timeout map still only covers `before_agent_run`, `before_agent_start`, `before_prompt_build`, and `resolve_exec_env`. An installed plugin that never resolves either LLM hook can now stall the model call path instead of behaving like the previous fire-and-forget observer.
  - confidence: 0.9
- **[P1] Apply systemPrompt overrides to the model call:** `src/agents/embedded-agent-runner/run/attempt.ts:4148`
  - body: Assigning `systemPromptForHook` here does not update the active session system prompt or rebuild the Google prompt-cache wrapper, and `promptActiveSession` later receives only the prompt/images options. A plugin returning `systemPrompt` will affect diagnostics/precheck, but the provider can still see the original system prompt.
  - confidence: 0.9
- **[P1] Re-run prompt image and skip checks after rewrites:** `src/agents/embedded-agent-runner/run/attempt.ts:4145`
  - body: `promptForModel` is rewritten after prompt-local image loading and prompt skip checks have already run against the original prompt. A hook can add image references that are never loaded, remove image references while stale images are still sent, or replace the prompt with an empty string after the blank-prompt guard already passed.
  - confidence: 0.88
- **[P1] Rewrite transcript state before downstream consumers:** `src/agents/embedded-agent-runner/run/attempt.ts:5141`
  - body: The output override is only substituted into the returned `assistantTexts`; `messagesSnapshot`, `lastAssistant`, context-engine after-turn handling, `agent_end`, and trajectory events have already consumed the original assistant message. A redaction plugin can therefore change the immediate payload while sensitive text remains in transcript/state and downstream hooks.
  - confidence: 0.92
- **[P2] Track plugin-suppressed output before live-model restart:** `src/agents/embedded-agent-runner/run/attempt.ts:5141`
  - body: Returning `assistantTexts: []` makes the attempt look like it produced no output, but the runner's live-model restart guard still checks only `attempt.assistantTexts.length === 0`. A plugin that deliberately suppresses a response can be defeated by a pending live model switch restart unless the attempt records that output was intentionally modified.
  - confidence: 0.82
