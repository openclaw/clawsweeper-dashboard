## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Apply system prompt overrides to the model call:** `src/agents/embedded-agent-runner/run/attempt.ts:4149`
  - body: The PR advertises `{ systemPrompt }` as an `llm_input` result, but this assignment only changes the local hook/precheck value. The actual model call still goes through `promptActiveSession(promptForSession, ...)` using the active session system prompt prepared earlier from `systemPromptText`, so a plugin can appear to override the system prompt while the provider still receives the old one. Apply the override to the active session and prompt-cache path before submission, or remove the field from the public contract.
  - confidence: 0.88
- **[P1] Re-detect images after prompt rewrites:** `src/agents/embedded-agent-runner/run/attempt.ts:4146`
  - body: When `llm_input` returns a new `prompt`, the patch replaces `promptForModel` after prompt-local images were detected from the original prompt. A plugin that removes an image reference can still send the old image, and a plugin that adds an image reference will not load it. Move the hook before image detection or re-run image detection and rollback consistently on failure.
  - confidence: 0.9
- **[P1] Give awaited LLM hooks default timeouts:** `src/plugins/hooks.ts:968`
  - body: This turns `llm_input` and `llm_output` into awaited sequential hooks, but the default modifying-hook timeout table still has no entries for either hook. Unless every plugin opts into a timeout, a never-settling handler can block an agent turn. Add bounded defaults and regression coverage for hung handlers before making these hooks awaited.
  - confidence: 0.91
- **[P2] Document the new LLM hook result contract:** `src/plugins/hook-types.ts:277-286`
  - body: The diff adds public return types for two plugin hooks, but the public plugin docs still describe both hooks as observation-only and the prompt-injection policy docs do not include the new `llm_input` mutation behavior. Update the plugin docs/contract coverage with the final maintainer-approved result fields and policy semantics so plugin authors do not implement against an undocumented API.
  - confidence: 0.82
