## What This Changes

The branch adjusts automatic compaction’s retained-tail budget using current provider context usage so an overflowed session can select a real history boundary instead of repeatedly keeping the first entry.

## System Context

Agent sessions retain transcript entries and periodically compact older history into a summary when context pressure rises. Provider-reported context usage triggers compaction, while the compaction planner selects a safe transcript cut and returns the retained tail to the agent runtime.

## Architecture Diagram

flowchart LR

  A --> D[Safe cut-point planner]
  C --> E[Normalize retained-tail budget]
  E --> D
  D --> F[History selected for summary]
  F --> G[Updated session boundary]

## Best Possible Solution

Keep the estimator-based fallback for missing, stale, or invalid usage, land the narrow normalization only after a redacted production-function or real-session proof shows the boundary advances and the retained tail remains provider-valid.
