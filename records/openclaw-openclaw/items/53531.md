## Summary

Keep open: current main and the latest release still carry compaction through one auth profile instead of rotating same-provider backup profiles, and the linked fixing PR is open but unmerged.

## What This Changes

Compaction should retry or fail over across backup auth profiles for the same provider when an auto-selected profile is rate-limited or in cooldown.

## Best Possible Solution

Land or replace the linked fixing PR with same-provider auto-profile rotation that preserves user-locked profiles and applies at most one compaction result to a stable transcript snapshot.
