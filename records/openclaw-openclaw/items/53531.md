## Summary

Keep open: current main and the latest release still lack same-provider auth-profile rotation inside compaction, and the open linked PR is the candidate implementation rather than a reason to close the issue before merge.

## What This Changes

The issue asks for transcript compaction to use same-provider auth-profile rotation and failover when an auto-selected profile is rate-limited or in cooldown.

## Best Possible Solution

Land or replace the linked fixing PR with same-provider auto-profile rotation that preserves user-locked profiles and applies at most one compaction result from a stable transcript snapshot.
