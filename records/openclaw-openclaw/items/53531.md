## Summary

Keep open: current main and the latest release still pass a single auth profile into compaction and lack same-provider profile failover; the open linked PR is the candidate fix and has not merged.

## What This Changes

The issue asks compaction to retry auto-selected same-provider auth profiles when the current profile is rate-limited or in cooldown, while keeping user-selected profiles locked.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/95650 with same-provider auto-profile rotation that preserves user-locked profiles and applies at most one compaction result from a stable transcript snapshot.
