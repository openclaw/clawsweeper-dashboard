## Summary

Keep open: current main and the latest release still lack same-provider auth-profile failover inside compaction, and https://github.com/openclaw/openclaw/pull/95650 is an open unmerged candidate fix using closing references, so this issue should remain the canonical tracker.

## What This Changes

The issue asks compaction to retry auto-selected auth profiles within the same provider when the current profile is rate-limited, overloaded, or in cooldown.

## Best Possible Solution

Land or replace the linked fixing PR with same-provider auto-profile rotation that preserves user-locked profiles and applies at most one compaction result from a stable transcript snapshot.
