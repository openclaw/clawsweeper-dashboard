## Summary

## What This Changes

The PR caps cron quarantine sidecar reads and serialized writes at 8 MiB and adds regression tests for oversized reads and writes.

## Best Possible Solution

Keep the bounded regular-file read, then use deterministic bounded quarantine retention or canonical SQLite storage so overflow never prevents authoritative cron mutations from committing.
