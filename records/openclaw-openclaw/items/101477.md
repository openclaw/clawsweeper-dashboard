## What This Changes

The PR replaces unbounded cron quarantine-sidecar reads with an 8 MiB bounded reader, adds write-cap recovery by archiving and restarting the sidecar, and adds cron store/service tests.

## Best Possible Solution

Keep the 8 MiB read bound, but land recovery only after maintainers choose one durable, bounded preservation contract for quarantined cron records; do not silently replace previously archived user recovery data.
