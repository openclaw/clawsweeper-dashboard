## Best Possible Solution

Land the narrow provider-local hardening after maintainers accept the fail-closed no-body fallback tradeoff and required checks are green.

## Reproduction Assessment

## Solution Assessment

Yes. The pre-read `Content-Length` gate is the narrowest owner-local fix for this edge because changing `readResponseWithLimit` globally would alter every plugin caller that relies on its current fallback behavior.
