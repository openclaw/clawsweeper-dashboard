## Summary

The reported race does not match current or shipped ACP persistence behavior: replay events are stored transactionally in SQLite, and the former JSON ledger is only consumed by migration code, so there is no active log-rotation path to mutex or buffer.

## What This Changes

Investigate and prevent overlapping ACP event-ledger file rotations that allegedly leak descriptors or corrupt traces under concurrent load.

## Best Possible Solution

Keep the transactional SQLite ledger and migration-only legacy reader unchanged; if trace corruption is observed, open a new report identifying the current SQLite-backed call path with versions, concurrency steps, logs, and resulting database or descriptor evidence.
