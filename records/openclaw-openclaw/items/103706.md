## What This Changes

The PR adds a bounded incremental ANSI/OSC sanitizer, preserves one sanitizer instance across bash output callbacks, flushes stateful output transforms, and adds chunk-boundary and spill-file regressions.

## Best Possible Solution

Land the bounded terminal-core state machine and stateful accumulator lifecycle together so streamed, final, and spilled bash output share one chunk-invariant sanitization path while legacy one-shot stripping remains unchanged.
