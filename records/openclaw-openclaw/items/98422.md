## What This Changes

The branch makes install-record-only plugin updates persist the SQLite install index without rewriting authored config, then signals a local gateway through a new authenticated `plugins.refresh` protocol method and refreshes generated native clients.

## Best Possible Solution

Land the records-only SQLite commit with its freshness and validation rollback checks plus the authenticated local refresh signal, while preserving the explicit restart fallback for offline or older gateways.
