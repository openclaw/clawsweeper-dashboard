## What This Changes

The branch modifies the GitHub Copilot token helper/tests to store a GitHub-token fingerprint in the token cache and bypass cached Copilot API tokens when the requesting GitHub PAT differs.

## Best Possible Solution

Port the fingerprint-bound cache ownership into `src/plugin-sdk/provider-auth.ts`, keep `extensions/github-copilot/token.ts` as a re-export, preserve the current integration-id and bounded-response safeguards, add provider-auth regression tests, then attach redacted real behavior proof.
