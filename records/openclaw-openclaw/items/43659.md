## What This Changes

The PR adds a GitHub-token fingerprint to Copilot token cache entries in the bundled Copilot token helper, a legacy agent helper, and related tests so profile rotation bypasses cache entries from another GitHub PAT.

## Best Possible Solution

Retarget the fingerprint or profile-owner check to src/plugin-sdk/provider-auth.ts, keep extensions/github-copilot/token.ts as a re-export, add provider-auth regression coverage for same-token hit, different-token miss, and legacy-cache miss, then post redacted real behavior proof before merge.
