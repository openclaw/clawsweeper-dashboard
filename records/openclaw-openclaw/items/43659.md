## Summary

Keep open: the underlying Copilot multi-profile cache bug still exists on current main, but this PR is not merge-ready because it is conflicting and applies the fix to token-helper paths that current main no longer owns.

## What This Changes

The PR adds a GitHub-token fingerprint to the Copilot API-token cache so a rotated GitHub Copilot profile forces a fresh token exchange instead of reusing another profile's cached token.

## Best Possible Solution

Port the cache-ownership check into `src/plugin-sdk/provider-auth.ts`, preserve the existing integration-id and domain guards, add SDK-level regression tests for same-profile hit, different-token miss, and legacy cache behavior, then provide redacted real behavior proof before merge.
