## What This Changes

This PR makes Anthropic live model discovery send Claude subscription OAuth tokens as `Authorization: Bearer` while retaining `x-api-key` for ordinary API keys, and adds focused request-header tests.

## System Context

The Anthropic plugin supplies credentials and a `/v1/models` discovery request to OpenClaw's shared provider-catalog runtime. The runtime turns live rows into the provider listing used by model selection, with shipped manifest rows serving as the offline baseline.
