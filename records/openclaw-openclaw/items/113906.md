## Summary

Keep this PR open for explicit maintainer review. The OAuth-header repair is narrow and has credible live and gateway proof, but it also enables a pre-existing catalog-replacement path for subscription users that can remove shipped Anthropic entries from their provider listing; that compatibility decision should be resolved before merge.

## What This Changes

This PR makes Anthropic live model discovery send Claude subscription OAuth credentials as `Authorization: Bearer` while preserving `x-api-key` authentication for API keys, with focused discovery-pipeline tests.

## System Context

The Anthropic plugin supplies a live catalog hook to the shared provider-catalog runtime. That runtime fetches Anthropic’s Models API, normalizes returned model rows, and feeds them into the provider listing used by model selection and discovery.
