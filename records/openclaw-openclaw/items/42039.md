The issue requests public cron configuration for `maxMissedJobsPerRestart` and `missedJobStaggerMs`, plus possible per-job catch-up skipping, to reduce duplicate/out-of-window cron deliveries after Gateway restart.

## Best Possible Solution

Maintainers should choose an explicit missed-run policy first, then update CronConfig, strict schema, gateway wiring, docs, and restart-catch-up tests together.
