## Summary

Keep open: current main and the latest release still keep these restart catch-up controls as internal CronService dependencies, while public cron config, strict validation, help text, docs, and Gateway construction do not expose or wire them.

## What This Changes

Request to add public cron configuration for restart missed-job limits and staggering so operators can disable or slow startup catch-up.

## Best Possible Solution

Maintainers should choose one supported missed-run policy, then wire config types, strict schema, config help, docs, Gateway CronService construction, and restart-catch-up tests while preserving current defaults unless a migration is approved.
