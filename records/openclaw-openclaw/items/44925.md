## Summary

Keep this open: current main still has bounded subagent announce give-up and best-effort restart-loss semantics, while the linked closing PR is open, conflicting, and only a partial retry/error-handling fix for the broader delivery, timeout, dedupe, and verification problem.

## What This Changes

This issue asks OpenClaw to stop silently losing subagent completions by retrying or surfacing announce failures, notifying or restarting on timeout, and verifying claimed file outputs.

## Best Possible Solution

Keep this as the umbrella until maintainers land or explicitly split a durable completion-delivery design that preserves pending results through retry, restart, timeout, and orphan handling while proving exactly-once user-visible delivery or a visible failure.
