Keep this open: current main and the latest release still have finite subagent announce retry/give-up behavior, docs still describe announce as best-effort, and the linked fixing pull request is open rather than merged.

## What This Changes

The issue asks OpenClaw to make subagent completion delivery reliable instead of silently losing completed work, timed-out children, or claimed artifacts.

## Best Possible Solution

Define and implement a durable single-path subagent completion delivery and recovery contract that preserves completion payloads, updates parent/session state, surfaces visible failure, and proves live multi-channel behavior.
