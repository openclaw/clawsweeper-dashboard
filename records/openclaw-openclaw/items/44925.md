## Summary

Keep this open: current main still has bounded retry/give-up and suspended/failed delivery paths for subagent completion announces, docs still call announce-back best-effort, and the linked closing PR is open rather than merged.

## What This Changes

The issue asks OpenClaw to stop silently losing subagent completions by retrying or surfacing failed announces, notifying or recovering on timeout/prune, and verifying claimed outputs before reporting completion.

## Best Possible Solution

Keep this umbrella open until maintainers land or replace the linked work with one proof-positive completion-delivery design: persisted completion state, explicit terminal notifications on give-up/prune/timeout, duplicate-safe acknowledged delivery, task-ledger alignment, docs, and live channel proof.
