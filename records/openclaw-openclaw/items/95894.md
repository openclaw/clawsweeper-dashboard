- `impact:crash-loop`: Affected plugin HTTP route startup can throw before the plugin's tool routes become usable.

## Summary

Keep open: current main and the latest release still propagate OpenClaw host overrides, including `path-to-regexp@8.4.0`, into managed npm plugin roots, while Express 4.x plugin dependency metadata requires `path-to-regexp` 0.1.x. The issue is valid, but the fix needs a maintainer dependency-policy choice because a blanket downgrade would conflict with OpenClaw's Express 5/router stack.

## What This Changes

The issue requests central handling for Express 4.x plugin dependency graphs so OpenClaw's host `path-to-regexp` 8.x override does not crash plugin routes or require per-plugin overrides.

## Best Possible Solution

Define a scoped managed-npm-root dependency policy that preserves plugin-owned dependency graphs while retaining necessary host security pins, then cover Express 4.x and Express 5/router behavior with install tests and docs.
