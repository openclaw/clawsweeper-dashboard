## Summary

Keep open: this is a plausible fix direction for the Composer lockout, but the new hand-rolled 429 billing filter misses existing terminal provider entitlement/billing strings, and the PR still has only test/proof-script evidence rather than real behavior proof.

## What This Changes

The PR splits preflight compaction 429 classification from other 4xx failures, expands the preflight skip predicate to timeout/429/5xx, and adds regression tests plus a proof script.

## Best Possible Solution

Use the shared provider billing/error contract, or a fully equivalent helper, to separate true retryable 429s from terminal billing/auth/request-shape failures, keep timeout/5xx skip tests and 400/401/403 plus billing-429 negative controls, then add redacted real behavior proof.
