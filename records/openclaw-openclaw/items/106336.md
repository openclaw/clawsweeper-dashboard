## Summary

The bug remains on current main, while this exact-head patch cleanly separates reply-token failure from later push failure, reuses the established visible-partial-delivery contract, resolves the earlier import-cycle finding, and includes convincing live LINE before/after proof. No actionable correctness or security defect remains; this PR should stay open for normal maintainer review.

## What This Changes

The PR refactors LINE chunked replies so post-reply push failures do not resend delivered chunks, marks those failures as visible partial delivery, extracts the shared marker into a leaf module, and adds regression coverage.

## Best Possible Solution

Land a refreshed version that preserves push-all fallback for genuine reply-token failure, never retries reply-delivered chunks after a later push failure, and consistently marks post-visible-delivery errors for core fallback suppression.
