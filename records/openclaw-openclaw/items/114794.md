## What This Changes

The branch makes Control UI question prompts belong to the active Gateway client, ignores stale answer/cancel completions after a client change, and recognizes the browser’s real `QUESTION_NOT_FOUND` error so expired prompts restore the composer.

## System Context

The Control UI receives operator-question events and recovery responses from a browser Gateway client, then projects them into chat cards and composer availability. This change sits in that transient question-state layer, separating a Gateway client’s authoritative prompt records from asynchronous operations started during a connection generation.
