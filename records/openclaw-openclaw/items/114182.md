## What This Changes

This PR sends budget-triggered Codex harness sessions through the existing native app-server compaction request and updates the CLI lifecycle regression tests so the context engine is not used as a fallback.

## System Context

The agent CLI monitors a session’s context budget after a turn and chooses either native harness compaction or OpenClaw’s context engine. For Codex OAuth sessions, the chosen route determines whether compaction stays on the authenticated app-server connection or incorrectly requires a separate OpenAI API key.
