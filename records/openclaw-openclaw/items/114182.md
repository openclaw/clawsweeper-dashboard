## What This Changes

Routes Codex budget-triggered CLI compaction to the authenticated app-server request, resumes the persisted thread for post-run compaction, and adds lifecycle coverage that prevents API-key-backed context-engine fallback.

## System Context

The CLI compaction lifecycle runs after an agent turn when its context budget is exceeded. For a Codex OAuth session, the agent harness and bundled Codex extension must keep compaction on the authenticated app-server connection rather than handing it to OpenClaw’s direct OpenAI context engine.
