## What This Changes

Adds capability-gated `append: true` support to the built-in write tool, with native append implementations for host, Docker-style, and remote-shell filesystems while leaving OpenShell mirror mode unsupported.

## Best Possible Solution

Adopt one optional native EOF-append capability at the authoritative filesystem bridge, expose `write.append` only for capable backends, retain fail-closed non-retryable uncertain outcomes, explicitly document the non-record-atomic boundary, and require exact-head redacted Docker/Crabbox output before merge.
