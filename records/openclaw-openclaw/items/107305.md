## Summary

This remains a current, well-supported Codex compatibility bug: the documented curated-plugin activation path can prevent the entire model turn from replying, while neither of the related merged PRs addressed the reported Codex 0.144.x marketplace and install-selector drift. The issue is narrowly actionable after the Codex area owner confirms the version-specific installation contract.

## What This Changes

Prevent configured native Codex plugin activation from stalling embedded-Codex turns when marketplace discovery or installation contracts differ across Codex CLI versions.

## Best Possible Solution

Resolve marketplace and install parameters from the initialized app-server's versioned capabilities, keep unavailable plugin apps excluded, and allow the base Codex turn to continue with a clear bounded diagnostic and regression coverage for legacy-local and current-remote catalogs.
