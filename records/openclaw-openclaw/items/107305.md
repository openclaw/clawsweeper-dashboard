## Summary

This is a fresh, well-supported Codex harness bug that remains necessary: current OpenClaw still documents the legacy curated marketplace and activation flow, while the reporter demonstrates that Codex 0.144.x responds quickly to direct requests but OpenClaw stalls and suppresses the entire agent reply. The narrower marketplace/install compatibility repair is actionable, but whether optional plugin activation should degrade to a plugin-free turn needs explicit owner direction.

## What This Changes

Fix native codexPlugins activation so current Codex marketplace and install contracts do not stall or cancel embedded Codex turns.

## Best Possible Solution

Resolve curated plugins from the connected server's live inventory, select the correct local or remote install argument while retaining tested compatibility with older bundled Codex versions, and isolate optional activation failures from the base model turn with structured diagnostics and focused regression coverage.
