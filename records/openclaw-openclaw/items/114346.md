## What This Changes

This PR changes the bundled 1Password secret-reference resolver to use execa’s normal UTF-8 output instead of requesting buffer output, allowing `op://` reads to start under Bun.

## System Context

The 1Password extension resolves `op://` SecretRefs by invoking the local `op` CLI and returns the resulting text to OpenClaw’s secret-resolution flow. This change sits at that CLI subprocess boundary and affects whether Bun-hosted gateways can obtain configured secrets.
