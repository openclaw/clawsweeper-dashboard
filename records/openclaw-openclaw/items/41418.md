## Summary

Keep open: current main and v2026.6.11 still lack a global `openclaw agent --dry-run`, and the remaining work is a security-sensitive product contract rather than stale cleanup.

## What This Changes

Request adds a global `openclaw agent --dry-run` mode that exposes tools but returns preview results instead of executing core, plugin, channel, and client tool calls.

## Best Possible Solution

Define the product and security contract first, then implement accepted dry-run behavior as run-scoped context through the Gateway/embedded tool pipeline with hook ordering, redacted previews, client-tool semantics, docs, and focused regression tests.
