## Summary

Keep open: current main and the latest release still do not provide a global `openclaw agent --dry-run` mode, and the request is a security-sensitive product contract rather than a narrow bug fix.

## What This Changes

Add a global `openclaw agent --dry-run` mode that keeps tools visible to the model while intercepting every tool execution and returning/logging preview payloads without side effects.

## Best Possible Solution

Define a maintainer-approved core execution-mode contract first, then implement a narrow CLI-first dry-run only if it can cover Gateway-backed, embedded, runtime, plugin, channel, and client-tool paths with focused safety tests.
