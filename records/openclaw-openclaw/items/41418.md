## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and the requested no-side-effects behavior is a security-sensitive product contract that should be specified before implementation.

## What This Changes

The issue requests an `openclaw agent --dry-run` mode that keeps tools visible to the model but returns preview payloads instead of executing built-in, plugin, channel, client, browser, web, filesystem, and shell tools.

## Best Possible Solution

Define an additive request-scoped no-side-effects contract first, then implement it across CLI, Gateway-backed and embedded agent runs, direct tool invocation, built-in/plugin/client tools, hook ordering, stderr/JSON output, docs, and regression proof.
