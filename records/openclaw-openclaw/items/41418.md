## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and the existing scoped dry-runs, tool policy, and plugin hook paths do not replace the requested user-trusted no-side-effects mode.

## What This Changes

Request a global `openclaw agent --dry-run` mode that previews all agent tool calls instead of executing built-in, plugin, channel, and client tools.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract across CLI, Gateway and embedded runs, built-in/plugin/client tools, hook ordering, output shape, logging, docs, and regression proof.
