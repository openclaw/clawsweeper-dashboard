## Summary

Keep open: current main and latest stable release still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for trusted tool-execution previews rather than conservative cleanup.

## What This Changes

Request a global `openclaw agent --dry-run` mode that intercepts all agent tool execution and returns/logs preview payloads instead of running tools.

## Best Possible Solution

Define the global dry-run safety contract first, then implement only the covered agent preview mode with tests and docs proving side-effecting tool paths are intercepted or explicitly unsupported.
