## Summary

Keep open: current main still lacks a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for a trusted no-side-effects tool-execution boundary rather than conservative cleanup.

## What This Changes

## Best Possible Solution

Define a request-scoped no-side-effects contract across CLI, Gateway, embedded, native-runtime, plugin, bundle, and client-tool surfaces, then implement only the covered dry-run mode with docs and tests that prove every unsupported path is explicit.
