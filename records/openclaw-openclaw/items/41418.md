## Summary

Keep open: current main and the latest release still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for tool execution previews rather than conservative cleanup.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that previews agent tool calls without executing them.

## Best Possible Solution

Define a maintainer-approved run-level dry-run contract that covers Gateway and embedded agent execution, plugin/client/deferred tools, structured output, logging, and security expectations before implementing the CLI flag.
