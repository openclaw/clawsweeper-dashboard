## Summary

Keep open: current main and v2026.6.11 still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for tool execution rather than conservative cleanup.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that exposes tools to the model but intercepts every tool execution with structured previews instead of side effects.

## Best Possible Solution

Define a core-owned dry-run safety contract first, then implement only the covered global agent preview mode across the agreed CLI, Gateway, embedded, backend, and client-tool surfaces with tests proving no side effects.
