## Summary

Keep open: current main and the latest stable release still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for tool execution rather than conservative cleanup.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that previews all agent tool calls instead of executing side-effecting tools.

## Best Possible Solution

Define the dry-run safety contract first, then implement only the covered global agent preview mode across CLI, Gateway, embedded, client-tool, backend, and Codex-native surfaces with tests proving no side effects through those paths.
