## Summary

Keep open: current main and the latest release still lack a global agent tool-execution dry-run, and the existing scoped dry-runs, `disableTools`, and hook/policy paths do not replace the requested no-side-effects preview mode.

## What This Changes

Request to add a global `openclaw agent --dry-run` mode that intercepts agent tool calls and returns/logs structured previews instead of executing tools.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract across CLI, Gateway and embedded runs, built-in/plugin/client tools, hook ordering, output shape, logging, docs, and regression proof.
