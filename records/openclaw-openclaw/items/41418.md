## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and implementing one safely needs a maintainer-defined security/product contract across the request-scoped agent and tool surfaces.

## What This Changes

Requests a global `openclaw agent --dry-run` mode that intercepts every agent tool call and returns/logs preview payloads instead of executing tools.

## Best Possible Solution

Define an additive request-scoped no-side-effects contract across CLI, Gateway/embedded runs, direct tool invocation, built-in/plugin/client tools, hook ordering, logging, docs, and regression proof.
