## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that exposes tools to the model while returning non-executing structured previews for all tool calls.

Keep this issue open for a maintainer-owned global safe-preview design that defines the cross-tool execution contract, then implement it across the CLI entrypoint, OpenClaw tool adapter, agent-core loop, native harness paths, docs, and regression tests.
