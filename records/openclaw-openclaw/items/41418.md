## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that previews all agent tool calls without executing them.

## Best Possible Solution

Define a core-owned dry-run safety contract first, then implement only the covered global agent preview mode with tests proving no side effects across those covered execution surfaces.
