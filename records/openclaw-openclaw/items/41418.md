## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and this is a security/product authority contract rather than a stale or duplicate cleanup item.

## What This Changes

Add a global `openclaw agent --dry-run` mode that previews every agent tool call instead of executing it.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract across CLI, Gateway/embedded runs, built-in/plugin/client tools, hook ordering, structured result/logging, docs, and regression proof.
