## Summary

Keep open: current main and the latest release still lack a global agent tool-execution dry-run, and the request is a security-sensitive product contract that needs maintainer direction before implementation.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that previews all tool calls without executing built-in, plugin, channel, or client tools.

## Best Possible Solution

Define an additive request-scoped dry-run contract first, then implement one canonical path across CLI, Gateway/embedded runs, direct invokes, built-in/plugin/client tools, hooks, docs, and regression tests.
