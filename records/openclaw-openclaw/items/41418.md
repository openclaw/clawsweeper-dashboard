## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and the related dry-run work covers narrower command scopes or broader workflow modes rather than replacing this request.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that intercepts all agent tool execution and returns preview payloads instead of running tools.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract across CLI, Gateway and embedded runs, built-in/plugin/client tools, hook ordering, output shape, logging, docs, and regression proof before implementation.
