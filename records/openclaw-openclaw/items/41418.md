## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and the remaining work is a security-sensitive product contract rather than a stale implementation cleanup.

## What This Changes

Request a global `openclaw agent --dry-run` mode that previews every agent tool call without executing built-in, plugin, channel, or client tools.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract covering CLI, Gateway/embedded runs, built-in/plugin/client tools, hook ordering, stderr/stdout shape, docs, and regression proof before implementation.
