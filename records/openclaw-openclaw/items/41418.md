## Summary

Keep open: current main and the latest release still lack a global agent tool-execution dry-run, and the request needs maintainer security/product direction before implementation because users would treat it as a no-side-effects boundary.

## What This Changes

Request a global `openclaw agent --dry-run` mode that previews all agent tool calls instead of executing built-in, plugin, channel, and client tools.

## Best Possible Solution

Define an additive request-scoped dry-run contract first, then implement one canonical preview path across CLI, Gateway/embedded runs, built-in/plugin/client tools, hooks, direct invoke, docs, and regression tests.
