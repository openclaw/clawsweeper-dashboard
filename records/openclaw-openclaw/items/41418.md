## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and the related dry-run/workflow items cover narrower command scopes or broader planning modes rather than replacing this request.

## What This Changes

Request to add a global `openclaw agent --dry-run` mode that lets the model plan tool calls while returning preview payloads instead of executing any tool side effects.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract across CLI, Gateway/embedded runs, built-in/plugin/client tools, hook ordering, output shape, logging, docs, and regression proof.

- **Reject global dry-run:** Close the direction after deciding that scoped command-level dry-runs are safer than a global preview mode that users may mistake for a sandbox guarantee.
