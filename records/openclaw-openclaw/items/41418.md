## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and the remaining work is a security/product contract rather than stale cleanup.

## What This Changes

The issue requests an `openclaw agent --dry-run` mode that previews every agent tool call instead of executing built-in, plugin, channel, or client tools.

## Best Possible Solution

Define an additive request-scoped no-side-effects contract across CLI, Gateway, embedded fallback, direct tool invocation, built-in/plugin/client tools, hook ordering, logging, docs, and regression proof.

## Solution Assessment

No, not as narrowly proposed. The safety goal is aligned, but the process-global adapter flag should become a request-scoped contract that covers all agent/tool execution surfaces rather than only one wrapper path.
