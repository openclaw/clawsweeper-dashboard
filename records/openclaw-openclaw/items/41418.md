## Summary

Keep open: current main and the latest release still lack a global agent tool dry-run, and the requested no-side-effects guarantee needs maintainer product/security direction before implementation.

## What This Changes

The issue requests an agent-level `--dry-run` mode that leaves tools visible to the model but previews every tool call instead of executing it.

## Best Possible Solution

Define an additive request-scoped global agent dry-run contract across CLI, Gateway/embedded runs, built-in/plugin/client tools, hook ordering, output shape, logging, docs, and regression proof.
