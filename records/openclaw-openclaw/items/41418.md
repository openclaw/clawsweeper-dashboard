## Summary

Keep open: current main and the latest release still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for tool execution rather than conservative cleanup.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that keeps tools visible to the model but returns preview payloads instead of executing real tool calls.

## Best Possible Solution

Define a core-owned dry-run safety contract first, then implement only the covered global agent preview mode with docs and tests proving those tool paths do not execute side effects.
