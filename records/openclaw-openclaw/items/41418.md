## Summary

Keep open: current main and the latest release still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security boundary decision rather than stale cleanup.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that intercepts agent tool calls and returns preview payloads instead of executing tools.

## Best Possible Solution

Define a core-owned safety contract first, then implement the narrowest global agent preview mode with explicit coverage for CLI/Gateway/embedded/backend surfaces, structured preview output, and no false-safety bypasses.
