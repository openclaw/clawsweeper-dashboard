## Summary

Keep open: current main still lacks a global agent dry-run mode, and the request is a security-sensitive feature rather than a stale or already-implemented cleanup item.

## What This Changes

Request to add an `openclaw agent --dry-run` mode that lets the model plan tool calls while returning structured previews instead of executing tools.

## Best Possible Solution

Design this as an explicit run-scoped safe preview or plan mode that covers Gateway and embedded execution paths, preserves hooks and approval policy, redacts preview payloads, and documents read-only versus mutating behavior.

## Reproduction Assessment

Yes, source-level: current main has no `openclaw agent --dry-run` option, the agent docs do not list one, and the current tool execution paths still call `tool.execute(...)`. This is a feature gap rather than a failing existing contract.

## Solution Assessment

Unclear as proposed: the requested problem is real, but a process-global flag in one adapter is probably too narrow for the current Gateway-first CLI, embedded fallback, client-tool, and agent-core execution paths. A run-scoped execution contract with redaction and parity tests is safer.
