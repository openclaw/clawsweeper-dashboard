## Summary

Keep open: current main and the latest release still lack a global `openclaw agent --dry-run` mode, and the overlapping issues cover broader or scoped dry-run work rather than this specific agent tool-execution contract.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that lets the model see tools while replacing all tool execution with structured previews.

## Best Possible Solution

Define a core-owned dry-run contract that preserves tool visibility, carries per-run context through Gateway and embedded execution, intercepts runtime and client/deferred tool surfaces, and returns redacted structured previews with focused regression coverage.
