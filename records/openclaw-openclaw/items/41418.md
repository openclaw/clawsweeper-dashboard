## Summary

Keep open: current main and `v2026.6.11` still lack a global `openclaw agent --dry-run` mode, and the remaining work is a product/security contract for tool execution rather than conservative cleanup.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that previews all agent tool calls without executing them.

## Best Possible Solution

Define a core-owned, request-scoped dry-run safety contract first, then implement only the covered CLI/Gateway/embedded/client-tool surfaces with docs and tests proving no side effects through those paths.
