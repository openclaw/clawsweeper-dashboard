## Summary

Keep open: current main and the latest release still lack a global agent tool-execution dry-run, and existing safeguards are scoped to tool policy, approvals, sandboxing, or individual commands rather than previewing every tool call while keeping tools visible to the model.

## What This Changes

The issue requests a global `openclaw agent --dry-run` mode that intercepts all agent tool execution and returns preview payloads instead of executing tools.

## Best Possible Solution

Define a core tool-execution preview contract first, then implement the chosen CLI-visible dry-run through the agent execution context with tests proving no side-effecting core, plugin, channel, client, tool-search, or gateway path executes.
