## Summary

Keep open: current main still lacks a global `openclaw agent --dry-run` mode, and the requested behavior would define a security-sensitive no-side-effects contract across agent, Gateway, embedded, built-in, plugin, and client tool paths.

## What This Changes

The issue requests a global agent CLI dry-run flag that previews every tool call instead of executing tools with side effects.

## Best Possible Solution

Define an additive request-scoped dry-run contract first, then implement one canonical preview path across CLI, Gateway/embedded runs, direct invoke, built-in/plugin/client tools, hooks, docs, and regression tests.
