## Summary

Keep open: current main and v2026.6.11 still lack a global agent tool-execution dry-run, and this is a security-sensitive feature that needs maintainer agreement on the no-side-effects contract before implementation.

## What This Changes

Add a global `openclaw agent --dry-run` mode that intercepts agent tool calls and returns preview payloads instead of executing tools.

## Best Possible Solution

Define an additive, request-scoped global agent dry-run contract across CLI, Gateway/embedded runs, built-in/plugin/client tools, hook ordering, output shape, logging, docs, and regression proof before implementation.
