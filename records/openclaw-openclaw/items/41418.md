## Summary

Keep open: current main and the latest release still lack a global agent tool-execution dry-run, and the existing scoped dry-runs, `disableTools`, policy hooks, and gateway tool-invoke placeholder do not provide the requested trusted no-side-effects preview mode.

## What This Changes

Request a global `openclaw agent --dry-run` mode that keeps tools visible to the model but intercepts all tool execution and returns/logs structured previews instead of running real tools.

## Best Possible Solution

Define a request-scoped core dry-run contract for Gateway and embedded agent turns, covering hooks, client/delegated/MCP tools, redacted previews, docs, and regression tests before exposing a public CLI flag.
