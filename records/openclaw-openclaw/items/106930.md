## Summary

The patch addresses the linked Copilot premature-compaction bug with a focused provenance split, but it changes the shared authority rule for every provider-discovery implementation. Keep this PR open for a provider/context owner to confirm that provider-discovered context windows are authoritative over prepared manifest/config/static rows, then refresh it against current `main`.

## What This Changes

The PR records pre-overlay discovered catalog rows and makes final/static catalog context limits fallback-only so they cannot lower provider-discovered limits.

## Best Possible Solution

Adopt one explicit prepared-catalog contract: verified provider discovery owns existing provider-qualified context limits, while final manifest/config rows and static catalogs only populate keys discovery did not provide.
