## Summary

Keep open. Current main has meaningful backup hardening for streaming, volatile-file filtering, SQLite snapshots, and normal error cleanup, but it still lacks the requested restore-safe large-install scope controls, size/progress policy, and live proof that the reported 4GB macOS backup path now completes or fails clearly; the linked implementation path remains open and conflicting.

## What This Changes

The issue reports that full `openclaw backup create` stalls or exits silently on large `.openclaw` directories, leaving only a small temporary archive instead of a completed backup or clear error.

## Best Possible Solution

Keep this issue open until maintainers land, narrow, or replace the linked backup-scope implementation so large state backups either complete or fail with clear progress, size, and restore-safe exclusion behavior.
