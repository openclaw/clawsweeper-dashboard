## What This Changes

The issue requests that `openclaw backup create` handle multi-GB `.openclaw` directories by completing reliably or failing clearly, with possible exclusions, size warnings, progress, or streaming behavior.

## Best Possible Solution

Keep this issue open until maintainers land, narrow, or replace the linked backup-scope implementation so large state backups either complete or fail with clear progress, size, and restore-safe exclusion behavior.
