## Summary

Keep open. Current main has partial backup hardening for volatile files, SQLite snapshots, and tar EOF retries, but it still lacks a proven restore-safe large-backup policy for browser/media/session-index payloads, max-size/progress handling, or a landed exclusion implementation; the closing implementation PR is still open and conflicting.

## What This Changes

Issue reports `openclaw backup create` stalling or exiting silently on large `.openclaw` directories, leaving only a small temporary archive instead of completing or failing clearly.

## Best Possible Solution

Land, narrow, or replace the linked backup-scope PR so large state backups either complete or fail with actionable progress/size guidance and restore-safe exclusion semantics.
