## What This Changes

Adds SenseAudio web search to the existing bundled SenseAudio plugin, including provider registration, scoped credentials and configuration, grounded-response handling, tests, and user documentation.

## System Context

OpenClaw discovers web-search providers from bundled plugin manifests, then creates the selected provider tool for agent web-search calls. This change extends the existing SenseAudio media plugin so its API key and plugin configuration can also supply an AI-synthesized, cited web-search result.

## Best Possible Solution
