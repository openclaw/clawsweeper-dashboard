## What This Changes

The PR wraps the Matrix client’s Rust-crypto to-device preprocessor so malformed SAS verification accept events with a missing or blank `method` are copied with `m.sas.v1` before crypto processing.

## System Context

The bundled Matrix plugin receives `/sync` to-device events and hands them to matrix-js-sdk’s Rust crypto backend before OpenClaw can expose verification progress. This PR inserts a narrowly scoped normalization step between crypto initialization and that backend so SAS device verification can continue.
