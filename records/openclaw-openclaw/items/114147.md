## What This Changes

The PR raises the Buzz plugin’s minimum compatible OpenClaw host from `2026.7.2` to `2026.7.2-beta.3` in npm peer metadata, installer and Plugin API compatibility metadata, shrinkwrap metadata, and the package README.

## System Context

Buzz is a bundled channel plugin whose package and installer metadata determine whether an OpenClaw host may install and load it. Once accepted, the plugin uses Plugin SDK channel-routing helpers during message handling, so an overly broad host range can allow a host that lacks required SDK exports.
