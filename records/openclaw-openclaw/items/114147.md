## System Context

Buzz is an externally installable channel plugin whose package metadata is read by npm, the OpenClaw installer, and the plugin API compatibility gate. Those checks decide whether a host version may install and load Buzz, preventing an unsupported beta host from reaching a missing SDK export at runtime.
