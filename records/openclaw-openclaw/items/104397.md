## What This Changes

The PR tracks delayed cron-continuation settlement recovery as independent Gateway root work so suspend preparation remains blocked until recovery succeeds, exhausts retries, or is retired by lifecycle rotation.

## Best Possible Solution

Land this bounded owner-boundary fix after the remaining exact-head checks complete, preserving focused coverage that suspend stays busy during retry and returns ready after every terminal recovery path.
