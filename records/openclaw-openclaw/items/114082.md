## What This Changes

Repair the iOS Paired Gateways confirmation flow so Forget Gateway removes the selected saved gateway instead of dismissing the dialog and restoring its row.

## System Context

The iOS settings screen presents saved gateway registry entries and routes a selected entry through a confirmation dialog to the gateway connection controller. A successful removal must delete that gateway's local credentials, trust, device access, and cached state, then refresh the paired-gateways list.
