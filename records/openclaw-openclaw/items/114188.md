## Summary

Keep this PR open for a maintainer decision and repair. The proposed public timeout override may be useful, but the patch makes arbitrary `HANDOFF_TIMEOUT_SECONDS` text inside the model-visible task a fail-closed contract; that can reject otherwise valid existing tasks and creates a competing source of truth for the same timeout.

## What This Changes

This PR adds `sessions_spawn.timeoutSeconds`, forwards it to native and ACP child-run timeout handling, rejects it for visible sessions, and updates documentation, tests, and prompt snapshots.

## System Context

`sessions_spawn` is the agent-facing delegation tool that turns a coordinator request into either a native OpenClaw child run or an ACP-backed child session. The requested timeout flows from the tool input into child-run creation, registry tracking, and the completion wait so each delegated task can have a bounded runtime budget.
