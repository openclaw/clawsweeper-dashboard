## What This Changes

This PR removes the final text-based redaction pass from trajectory support-bundle files and adds regression tests for JSON values that contain escaped quotes.

## System Context

Trajectory export collects diagnostic data, redacts it, serializes it into support-bundle files, and writes those files with a manifest. The changed path sits between structured secret masking and bundle-file output, where an additional text regex pass can corrupt JSON.
