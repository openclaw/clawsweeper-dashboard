## What This Changes

Adds a Control UI action that clears an unretryable, outcome-unknown cloud-session recovery record so a user can discard the stuck draft and start a new cloud session.

## System Context

The Control UI's new-session page persists cloud-create recovery state in browser session storage when a Gateway change interrupts a request. That recovery state determines whether the draft and cloud target selector remain locked or are returned to a usable new-session state.
