## Summary

Keep this PR open for normal merge review. Current `main` still removes only the synthetic yield-abort artifacts, while this branch also removes the trailing assistant suffix that blocks continuation; the branch’s count-capped persistence cleanup is a materially safer candidate than the overlapping open PR at https://github.com/openclaw/openclaw/pull/109806. Likely related people: samrrr (high confidence as the production reporter) and kagura-agent (medium confidence as the author of the overlapping alternative implementation).

## What This Changes

This PR extends yielded-session cleanup to remove trailing regular assistant transcript messages and caps the matching persisted-session removals so subagent completion can resume the parent session.

## System Context

The embedded agent runner turns `sessions_yield` into an intentional abort, then removes temporary transcript artifacts before a child agent’s completion is delivered back to the parent. The cleaned live and persisted transcript tails must leave a continuable role so the next agent turn can be injected safely.

## Architecture Diagram

flowchart TD

  B --> C[Yield abort cleanup]

  D --> F[Subagent completion delivery]
  E --> F
  F --> G[Parent continuation turn]

## Best Possible Solution

Land one focused fix for the canonical deadlock: retain the two-phase live cleanup and count-capped persisted cleanup, with the accompanying regression coverage, rather than merging two competing implementations of the same transcript invariant.
