## Summary

Current main already prevents the reported permanent no-reply wedge through the canonical visible-reply admission path. The legacy diagnostic helper can still emit `keep_lane`, but merged reply-run registry changes bound terminal-owner release and allow a waiting visible message to reclaim evidence-stale work, so busy-channel activity no longer leaves the session unusable.

## What This Changes

## Best Possible Solution
