## Summary

## What This Changes

Adds an `openclaw sessions link` CLI helper with TSV/JSON output, ACPx docs, tests, and a changelog entry for correlating OpenClaw ACP session keys to Copilot state directories.

## Best Possible Solution

Rebase the helper onto `listAcpSessionEntries` or an equivalent SQLite-backed ACP accessor, align TSV/JSON/docs around one status field, remove the release-owned changelog change, and require redacted after-fix terminal proof for both modes.

## Solution Assessment

No. A diagnostic command may be useful, but this implementation reads the wrong storage source; the maintainable path is to build on the existing SQLite-backed ACP metadata accessor and keep the output contracts aligned.
