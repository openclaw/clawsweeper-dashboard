## Summary

Keep open: the regression is built against an older Feishu registration contract. Current main no longer exposes `timeoutMs` through the registration options and only places an abort signal in `RequestInit`, while guarded DNS/proxy preflight cancellation is driven by the guard's top-level timeout or signal. The added test therefore cannot validate or cleanly land on current main.
