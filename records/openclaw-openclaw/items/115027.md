## Summary

Keep this PR open: current `main` still sends `chat.update` text through the 8,000-character send limit, while Slack documents a 4,000-character maximum for `chat.update`. The production change is a narrow, consistent repair, but the supplied evidence is a mocked unit test rather than real after-fix Slack behavior proof.

## What This Changes

The PR changes Slack message updates to truncate at the 4,000-character `chat.update` limit and adds a regression test for a 6,000-character edit.

## System Context

The Slack plugin turns OpenClaw outbound and status-update requests into Slack Web API calls. This path uses `chat.update` for an already-posted message, so its text must obey Slack's edit-specific limit before Slack receives the update.
