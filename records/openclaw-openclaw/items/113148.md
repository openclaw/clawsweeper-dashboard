## What This Changes

Prevent unequal inline backtick runs from being treated as code regions that preserve hidden reasoning tags in assistant-visible output.

## System Context

Shared text utilities identify code-like regions in model output before downstream reasoning-tag and assistant-visible-text sanitizers process it. A region classified as literal code is intentionally preserved, so delimiter parsing controls whether hidden reasoning can reach rendered output.

## Best Possible Solution

Land one shared `findCodeRegions` implementation that pairs only equal-length maximal backtick runs, preserves genuine quoted code spans, and adds regression coverage for both delimiter directions and downstream assistant-visible sanitization.
