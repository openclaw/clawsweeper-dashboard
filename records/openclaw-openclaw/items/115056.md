## What This Changes

This PR makes shared Slack channel and user directory pagination reject repeated cursors and stop after 10,000 non-terminating pages, while updating Slack test runtime setup for the newer read-client path.

## System Context

The bundled Slack plugin resolves channel and user directories before applying allowlist and lookup behavior. Both resolution paths use a shared cursor collector, so its termination rules determine whether malformed Slack pagination finishes, fails, or hangs.
