## What This Changes

The issue asks OpenClaw to return internal agent tool-call information through the OpenAI-compatible Chat Completions API when integrating with a base URL, API key, and model.

## Best Possible Solution

Keep `/v1/chat/completions` client-tool behavior unchanged until maintainers explicitly choose a default-off, redacted diagnostic or trace contract for internal tool telemetry, preferably without making already-executed internal tools indistinguishable from caller-executable `tool_calls`.
