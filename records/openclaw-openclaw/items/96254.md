## Summary

Keep open: current main and v2026.6.11 intentionally return Chat Completions `tool_calls` only for caller-supplied client tools, while exposing OpenClaw internal tool telemetry would be a new security-sensitive API contract rather than a confirmed regression.

## What This Changes

Request that `/v1/chat/completions` return tool-call information for OpenClaw internal tools when using a supplied base URL, API key, and model name.

## Best Possible Solution

Keep `tool_calls` limited to caller-supplied client tools unless maintainers design a separate redacted, scope-gated diagnostic or observability surface for internal OpenClaw tool telemetry.
