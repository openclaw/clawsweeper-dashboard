## What This Changes

This PR changes session-compaction token estimates so CJK-heavy transcript text consumes more of the `keepRecentTokens` budget before the retained tail is selected.

## System Context

Compaction walks a session transcript backward, estimates the size of each message, and chooses the recent tail that stays within the configured token budget. That tail is then preserved while older conversation state is summarized, so estimate accuracy affects how much usable context reaches the next model turn.

## Best Possible Solution

Move the CJK weighting into a package-safe canonical helper shared by compaction and the existing context-budgeting callers, remove the local regex fork, and attach redacted before/after evidence from a real CJK-heavy compaction run.
