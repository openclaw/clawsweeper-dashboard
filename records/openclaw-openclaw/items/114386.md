## What This Changes

This PR moves CJK-aware character weighting into Normalization Core and uses it when Agent Core estimates the transcript tail retained during session compaction, with focused regressions for CJK and supplementary-plane characters.

## System Context

Agent Core compaction walks a session transcript backwards, estimates each entry’s token cost, and retains the newest entries within `keepRecentTokens`. Its cut point determines which entries remain available to the next agent turn and which older entries are summarized.
