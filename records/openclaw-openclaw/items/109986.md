## Summary

## What This Changes

The PR adds guarded URL parsing for provider catalog pagination and redirect metadata, with regression tests for malformed URL responses.

## Best Possible Solution

Retain defensive parsing and same-origin header sanitization, use a valid cursor when available, and otherwise report controlled incomplete pagination whenever a supplied next-page link cannot be parsed.
