Keep the branch open for a narrow owner-level timeout repair and real-runtime proof.

## What This Changes

The PR adds a fixed 30-second timeout around the reply dispatcher’s complete `beforeDeliver` chain, treats timeout as cancellation, and adds a never-resolving-hook regression test.

## Best Possible Solution

Add bounded execution at the actual hook owner—most likely default budgets for the currently unbounded modifying message hooks—while honoring registration/config overrides and existing fail-open logging; keep timeout distinct from intentional cancellation, use fake-timer regression coverage, and verify lane recovery in a real channel runtime.
