## What This Changes

This PR adds an opt-in Mattermost `message read` action that retrieves recent accessible channel posts with bounded pagination, normalized timestamps, and guarded delegated-read authorization.

## System Context

Mattermost is a bundled channel plugin that implements shared message actions for the gateway, agent tool, and CLI. The core dispatcher decides whether a delegated read may use a provider-owned gate; the plugin then enforces account and group policy before calling Mattermost's posts API.

  AccountPolicy --> MattermostAPI[Mattermost posts API]
  MattermostAPI --> HistoryResult[Normalized channel history]
