## Label Justifications

## Summary

Keep this PR open for maintainer review. The patch is a focused, opt-in implementation of Mattermost channel-history reads with a deliberately narrow host authorization exception; the remaining question is whether its new public capability setting and core-reviewed provider gate are the permanent product contract.

## What This Changes

Adds an explicitly enabled Mattermost `message read` action that retrieves bounded channel history with pagination, normalized timestamps, provider permission errors, and guarded delegated cross-channel access.

## System Context

OpenClaw's shared message tool dispatches channel actions to bundled channel plugins. This change lets the Mattermost plugin fetch readable channel posts while the core dispatcher grants that plugin—and only its `read` action—ownership of selected target-authorization checks.
