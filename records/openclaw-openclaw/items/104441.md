## Summary

This PR remains necessary because current `main` still permits forced block splits inside UTF-16 surrogate pairs. The proposed fix corrects the canonical boundary before fence and buffer handling, has convincing production-class proof, and introduces no actionable correctness or security finding.

## What This Changes

This PR makes forced `EmbeddedBlockChunker` split indices UTF-16-safe and adds regressions for plain text, fenced text, and a one-code-unit budget.

## Best Possible Solution

Use one surrogate-safe forced index before fence lookup, emission, and buffered-remainder reconstruction, preserving forward progress when a configured budget cannot contain even one complete code point.

## Solution Assessment

Yes. Normalizing the single source-of-truth split index is narrower and more maintainable than repairing malformed strings downstream, and it keeps fence metadata, emitted text, and remainder state aligned.
