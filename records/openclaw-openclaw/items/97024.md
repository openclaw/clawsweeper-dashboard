## What This Changes

This PR rethrows non-ENOENT errors while saving a failed session-delivery retry and adds a SQLite-backed regression proving startup and targeted recovery surface a real read-only write failure.

## System Context

Session-delivery recovery retries durable messages after a gateway restart or targeted drain. A delivery failure is recorded in the state database before the recovery caller decides whether to continue, retry later, or stop the drain cycle.
