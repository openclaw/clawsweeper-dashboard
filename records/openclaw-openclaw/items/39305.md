## Summary

Keep open: current main has runTimeoutSeconds enforcement and diagnostics-driven abort recovery, but it still lacks the requested subagent tool-inactivity nudge, two-stage kill escalation, stall config policy, and parent/channel-visible recovery contract.

## What This Changes

The issue requests two-stage sub-agent stall recovery based on tool-call inactivity, with a nudge followed by automatic kill and parent/channel-visible recovery.

## Best Possible Solution

Define one maintainer-approved subagent recovery contract that reuses existing timeout, diagnostics, and kill primitives while specifying activity tracking, defaults, nudge delivery, kill escalation, parent wakeup, and a user-visible non-terminal recovery path.
