## Summary

Keep open: current main and v2026.6.11 still provide only runTimeoutSeconds, stale-run hiding, diagnostic active-abort mitigation, and internal/admin kill paths; the requested subagent last-tool-activity nudge-to-kill contract with parent/channel-visible recovery is still missing, and #101863 is adjacent umbrella work rather than an explicit superseding close path.

## What This Changes

Request automatic two-stage stalled-subagent recovery that nudges after inactivity, kills after continued inactivity, and reports the terminal outcome to the parent session.

## Best Possible Solution

Approve one runtime-owned recovery contract that reuses deterministic activity evidence, applies conservative default-safe thresholds, reports terminal outcomes to the parent/channel, and keeps config/API changes behind maintainer-approved semantics.
