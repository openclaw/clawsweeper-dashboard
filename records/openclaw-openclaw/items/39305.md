## Summary

Keep open: current main has hard subagent runTimeoutSeconds enforcement, stale/lost-context cleanup, internal kill controls, and generic stuck-session diagnostics recovery, but it still lacks the requested subagent tool-inactivity nudge, configured kill escalation, per-spawn stall policy, and parent/channel-visible recovery semantics.

## What This Changes

Request to add subagent tool-inactivity monitoring with a nudge stage followed by automatic kill and parent/channel notification.

## Best Possible Solution

Define one core subagent liveness contract that reuses existing diagnostic/session activity, adds conservative nudge and abort states with focused tests, and guarantees a non-sensitive parent/channel terminal signal without creating a second source of session truth.
