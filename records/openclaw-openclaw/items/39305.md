## Summary

Keep open: current main has wall-clock subagent timeout enforcement and adjacent stale-run/manual-control work, but it still lacks the requested two-stage tool-inactivity watchdog, default recovery policy, nudge injection, automatic kill escalation, and user-visible parent/channel recovery semantics.

## What This Changes

Request to add escalating subagent stall recovery that nudges an inactive child after a tool-call idle window, then kills it and notifies the parent if it remains stalled.

## Best Possible Solution

Keep this as the canonical design item until maintainers choose a single subagent recovery contract that reuses existing timeout/control primitives and clearly defines activity tracking, nudge delivery, kill escalation, parent wakeup, and channel-visible recovery behavior.
