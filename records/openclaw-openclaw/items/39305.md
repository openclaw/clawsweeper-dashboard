## Summary

Keep open: current main has wall-clock subagent timeout enforcement, stale-run aging, and manual/admin kill paths, but not the requested automatic tool-inactivity nudge followed by kill escalation and parent/channel recovery.

## What This Changes

The issue requests two-stage subagent stall recovery based on tool-call inactivity, with a nudge before automatic kill and parent/channel notification.

## Best Possible Solution

Define one core subagent recovery contract that reuses existing registry/control primitives, names the activity signal, nudge delivery, kill escalation, parent wakeup, and channel-visible recovery behavior, then implement it with upgrade-safe defaults and focused live chat proof.
