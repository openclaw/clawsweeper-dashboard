## Summary

Keep open: current main and the latest release still do not provide the requested sub-agent tool-inactivity nudge, automatic kill escalation, per-spawn/config policy, or parent/channel-visible recovery contract, even though adjacent timeout and diagnostic recovery work now exists.

## What This Changes

Request to add two-stage sub-agent stall recovery that nudges after tool-call inactivity, kills after continued inactivity, and supports default plus per-spawn policy configuration.

## Best Possible Solution

Define one maintainer-approved sub-agent recovery contract that reuses existing timeout, diagnostics, and kill primitives while specifying activity tracking, defaults, nudge delivery, kill escalation, parent wakeup, and channel-visible notification.
