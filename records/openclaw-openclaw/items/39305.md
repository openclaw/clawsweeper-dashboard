- `P1`: The production report shows Telegram group sessions blocked behind stuck sessions_spawn calls for minutes to hours, making the channel appear dead to users.

## Summary

Keep open: current main still has wall-clock subagent timeout handling, stale-run projection, and manual/control-adjacent work, but it does not implement the requested tool-inactivity nudge, automatic kill escalation, default recovery policy, or channel-visible parent recovery semantics.

## What This Changes

The issue requests a two-stage sub-agent stall recovery system that nudges inactive sub-agents and then kills them if they remain stalled.

## Best Possible Solution

Keep this as the canonical design item until maintainers choose one subagent recovery contract that reuses existing timeout/control primitives and clearly defines activity tracking, nudge delivery, kill escalation, parent wakeup, and channel-visible recovery behavior.
