## Summary

Keep open: current main and the latest release have wall-clock timeout enforcement, diagnostics abort recovery, and internal kill primitives, but they still do not implement the requested two-stage subagent tool-inactivity nudge, automatic kill escalation, config/per-spawn policy, or parent/channel-visible recovery contract.

## What This Changes

Request adds escalating subagent stall recovery that nudges after tool-call inactivity and kills/notifies after a further timeout.

## Best Possible Solution

Define one maintainer-approved subagent recovery contract that reuses existing timeout, diagnostics, and kill primitives while specifying activity tracking, defaults, nudge delivery, kill escalation, parent wakeup, and channel-visible notification.
