## Summary

Keep open: current main and v2026.6.11 provide wall-clock run timeouts, stale-run visibility cleanup, diagnostics, and manual/admin kill paths, but they still do not implement the requested last-tool-activity nudge-to-kill recovery or default parent/channel-visible stall notification.

## What This Changes

Add configurable two-stage stalled subagent recovery that nudges after inactivity, then kills and notifies the parent/channel if the subagent remains stalled.

## Best Possible Solution

Define one runtime-owned subagent stall recovery contract with deterministic activity tracking, conservative thresholds or opt-out semantics, parent/channel-visible terminal delivery, and tests/docs coordinated with sessions.activity/watchdog work.
