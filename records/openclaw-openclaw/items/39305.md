## Summary

Keep open: current main has adjacent wall-clock timeout enforcement, manual/internal kill plumbing, and diagnostics abort recovery, but it still lacks the requested two-stage subagent tool-inactivity nudge, automatic kill escalation, config/per-spawn policy, and parent/channel-visible recovery contract.

## What This Changes

The issue requests default/configurable escalating stall recovery for subagents: nudge after tool-call inactivity, then kill and notify the parent if inactivity continues.

## Best Possible Solution

Define one maintainer-approved subagent recovery contract that reuses existing timeout, diagnostics, and kill primitives while specifying activity tracking, defaults, nudge delivery, kill escalation, parent wakeup, and channel-visible notification.
