## Summary

Keep open: current main and the latest stable release have wall-clock subagent timeout enforcement, diagnostics recovery, and internal kill primitives, but they still lack the requested tool-inactivity nudge, automatic kill escalation, per-spawn/config policy, and parent/channel-visible recovery contract.

## What This Changes

Request a two-stage subagent stall watchdog that nudges after tool-call inactivity, then kills and notifies the parent/channel if inactivity continues.

## Best Possible Solution

Define one maintainer-approved subagent recovery contract that reuses existing timeout, diagnostics, and kill primitives while specifying activity tracking, defaults, nudge delivery, kill escalation, parent wakeup, and channel-visible notification.
