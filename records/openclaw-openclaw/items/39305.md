## Summary

Keep open: current main has generic blocked-tool-call diagnostic recovery, but it still does not implement the requested sub-agent-specific nudge stage, new stall threshold config, or parent/channel notification policy; the production Telegram report keeps the impact concrete.

## What This Changes

The issue requests default-on two-stage sub-agent stall recovery that nudges an inactive child and then kills it while notifying the parent/channel when tool-call activity stops.

## Best Possible Solution

Use the existing diagnostic/session recovery primitives as the backstop, then make a maintainer-approved design for sub-agent nudge/kill thresholds, parent wake behavior, and user-visible channel messaging with upgrade-safe defaults.
