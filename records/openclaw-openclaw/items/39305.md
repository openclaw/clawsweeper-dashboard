## Summary

Keep open: current main and the latest release still have runTimeoutSeconds, diagnostics recovery, and internal/manual kill primitives, but not the requested two-stage subagent inactivity nudge, automatic kill escalation, per-spawn/config policy, or parent/channel-visible recovery contract.

## What This Changes

The issue requests a two-stage stalled subagent recovery policy that nudges after tool-call inactivity, then kills and notifies the parent if the child remains stalled.

## Best Possible Solution

Define one maintainer-approved subagent recovery contract that reuses existing timeout, diagnostics, and kill primitives while specifying activity tracking, defaults, nudge delivery, kill escalation, parent wakeup, and channel-visible notification.
