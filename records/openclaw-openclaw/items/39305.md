## Summary

Keep open: current main enforces explicit wall-clock subagent run timeouts and has internal/manual kill plumbing, but it still lacks the requested default-on tool-inactivity watchdog, nudge injection, kill escalation policy, and user-visible parent/channel recovery behavior.

## What This Changes

Request default-on two-stage subagent stall recovery based on tool-call inactivity, with nudge-before-kill thresholds, config or per-spawn overrides, parent notification, and chat-channel recovery.

## Best Possible Solution

Keep this as the canonical design item until maintainers define one subagent recovery contract that reuses existing timeout/control primitives and provides a visible non-terminal recovery path for stuck chat-channel sessions.
