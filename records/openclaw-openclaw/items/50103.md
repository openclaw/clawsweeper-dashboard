Keep open. Current main and the latest release still do not expose the requested agent-level `systemPrompt` / `rules` config contract, and the direct implementation PR is closed unmerged; the remaining work needs maintainer product and security direction before implementation.

## What This Changes

Add config-injectable agent rules via `agents.defaults.systemPrompt` / `rules` and per-agent prompt-rule overrides, applied across sessions instead of only through workspace bootstrap files.

## Best Possible Solution

Adopt a maintainer-approved, operator-owned prompt/rules overlay contract only if it defines merge order, defaults-plus-per-agent behavior, session-creation timing, write permissions, docs, and cross-runtime tests.
