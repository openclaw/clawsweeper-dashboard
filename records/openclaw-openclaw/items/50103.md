## Summary

Request to add global and per-agent config fields for injecting system-prompt rules instead of relying on workspace bootstrap files.

## Best Possible Solution

Define one maintainer-approved agent-level prompt/rules contract with explicit precedence, defaults-plus-per-agent merge behavior, session-creation coverage, docs, schema/help metadata, and security limits; keep raw includes and hard enforcement in their narrower tracks.
