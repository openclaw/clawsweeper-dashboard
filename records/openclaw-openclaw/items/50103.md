## Summary

Keep open. Current main still lacks a durable `agents.defaults.systemPrompt` / `agents.defaults.rules` and per-agent prompt/rules config contract, while the existing `extraSystemPrompt` path is caller-provided channel/session context rather than an agent-level configuration surface. The request remains useful but needs maintainer product and security review because it adds model-facing config that can change agent guardrails.

## What This Changes

Request to add config-injectable agent-level system prompt text and rules under agent defaults and per-agent configuration.

## Best Possible Solution

Define one canonical agent-level prompt/rules contract with schema, types, docs, precedence rules, security notes, and consistent runtime injection across session entry points; keep file includes and hard response gates in their separate canonical items.

## Solution Assessment

Unclear as an implementation path until maintainers decide the config contract, precedence, and security model; the issue should remain the canonical product tracker rather than close as implemented.
