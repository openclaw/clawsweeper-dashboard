## Summary

## What This Changes

The issue requests config-managed agent prompt rules under `agents.defaults` and per-agent config, including optional structured rules and include-file support.

## Best Possible Solution

Define one canonical, maintainer-approved agent-level prompt/rules contract with explicit precedence, defaults-plus-per-agent merge behavior, all-session coverage, schema/help/docs alignment, and security limits; keep raw includes and hard enforcement coordinated through their narrower related items.
