## What This Changes

This PR stops a child or PTY replacement that was cancelled while waiting in a scope queue from starting, producing side effects, or replacing the currently running process.

## System Context

OpenClaw’s process supervisor coordinates agent background commands across child-process and PTY backends. It serializes scoped replacements, records cancellation lifecycle state, starts operating-system adapters only for admitted runs, and returns the managed exit result to callers.

## Architecture Diagram

  Check -->|Cancelled| Finalize[Finalize no-process run]
  Check -->|Active| Replace[Cancel active scoped predecessor]
  Replace --> Adapter[Start child or PTY adapter]
  Adapter --> Result[Managed exit result]
