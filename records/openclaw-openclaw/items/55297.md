## Summary

Keep open: current main and the latest release still provide manual skill/plugin update flows and package auto-update, but not unattended ClawHub skill/plugin auto-update. The remaining work needs maintainer product and supply-chain policy decisions before implementation.

## What This Changes

Request to add opt-in automatic updates for installed ClawHub skills and OpenClaw plugins, likely through config and gateway startup or scheduled background checks.

## Best Possible Solution

Define a maintainer-approved, default-off updater design that reuses the explicit skill/plugin update primitives while gating them through ClawHub trust, installPolicy, pinning, rollback, audit logging, and clear failure behavior.
