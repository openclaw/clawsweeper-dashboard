## Summary

Keep open: current main and v2026.6.11 support explicit `openclaw skills update` and `openclaw plugins update` flows plus package auto-update, but not the requested unattended ClawHub skill/plugin auto-updater. The remaining work crosses product, config, gateway lifecycle, and supply-chain policy boundaries that need maintainer direction.

## What This Changes

Request to add opt-in automatic updates for installed ClawHub skills and OpenClaw plugins, likely on gateway start or a configured interval.

## Best Possible Solution

Define a maintainer-approved, default-off design that reuses the explicit skill/plugin update primitives while gating background execution on ClawHub trust, `security.installPolicy`, pinning or rollback semantics, audit logs, restart/reload behavior, and clear operator controls.
