## Summary

Keep open: current main has explicit manual skill/plugin update flows and a separate package auto-updater, but not the requested unattended ClawHub skill/plugin updater. The remaining work needs maintainer product and supply-chain policy decisions before implementation.

## What This Changes

The issue requests an opt-in background auto-update mechanism for installed ClawHub skills and OpenClaw plugins.

## Best Possible Solution

A maintainer-owned default-off design should reuse the existing explicit update primitives while gating unattended updates on ClawHub trust/provenance, installPolicy, pinning, rollback, audit logs, and clear failure handling.
