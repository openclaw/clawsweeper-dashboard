## Summary

Keep open: current main and the latest release still provide manual skill/plugin update commands and package auto-update, but not the requested unattended update flow for installed ClawHub skills and plugins. The remaining work is a product and supply-chain security design question, not conservative cleanup.

## What This Changes

The issue requests opt-in automatic updates for installed ClawHub skills and OpenClaw plugins instead of relying on manual update commands.

## Best Possible Solution

Keep this open for a maintainer-owned opt-in design that reuses the existing manual update primitives while preserving ClawHub trust, install policy, pinning, rollback, audit, and operator-control semantics.
