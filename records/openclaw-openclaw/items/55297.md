## Summary

Keep open: current main has explicit manual skill/plugin update flows and a package-only `update.auto` path, but not the requested unattended ClawHub skill/plugin updater. The remaining work is a product and supply-chain policy decision, not a conservative cleanup close.

## What This Changes

Request an opt-in unattended auto-update mechanism for installed ClawHub skills and OpenClaw plugins.

## Best Possible Solution

Define a maintainer-approved, opt-in skill/plugin update policy that reuses explicit install/update trust checks and specifies version pinning, provenance, audit, rollback, and user controls before implementation.
