## Summary

Keep open: current main has explicit manual skill and plugin update flows plus package auto-update, but not the requested unattended ClawHub skill/plugin updater. The remaining work crosses product, public config, gateway lifecycle, and third-party code supply-chain policy boundaries.

## What This Changes

Request to add opt-in automatic updates for installed ClawHub skills and plugins, either at gateway startup or on an interval.

## Best Possible Solution

A maintainer-owned, default-off design should reuse the existing explicit update primitives while gating background updates on ClawHub trust/provenance, security.installPolicy, pinning, rollback, audit logs, and clear failure behavior.
