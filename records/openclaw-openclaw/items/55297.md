## Summary

Keep open: current main has manual skill/plugin update commands and a separate package-only auto-updater, but it still does not implement unattended updates for installed ClawHub skills and plugins. The remaining work is a product and security design for third-party code update policy, not conservative cleanup.

## What This Changes

Request opt-in background auto-updates for ClawHub skills and installed plugins so published fixes reach existing installs without manual commands.

## Best Possible Solution

Define a maintainer-approved, opt-in updater that reuses existing explicit update primitives while enforcing ClawHub trust, install policy, pinning, rollback, audit, and clear failure behavior, or intentionally keep updates manual.
