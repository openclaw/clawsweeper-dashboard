## Summary

Keep open: current main has explicit skill/plugin update commands and package auto-update, but it does not implement unattended auto-update for installed ClawHub skills or plugins. The remaining work needs maintainer product and supply-chain policy decisions before implementation.

## What This Changes

The issue requests opt-in automatic background updates for installed ClawHub skills and OpenClaw plugins.

## Best Possible Solution

A maintainer-owned, default-off design should reuse the existing explicit update primitives while defining provenance checks, installPolicy integration, pinning or rollback semantics, audit logs, and clear failure behavior before any implementation.
