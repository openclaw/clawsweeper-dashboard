## Summary

Keep open: current main still provides explicit manual skill/plugin update flows and package auto-update, but not the requested unattended ClawHub skill/plugin updater. The remaining work needs maintainer product and supply-chain policy decisions before implementation.

## What This Changes

Request an opt-in auto-update mechanism for installed ClawHub skills and OpenClaw plugins, likely through config and gateway-startup or interval checks.

## Best Possible Solution

A maintainer-owned opt-in design should reuse the existing explicit update primitives while gating them on ClawHub trust/provenance, installPolicy, pinning, rollback, audit, and clear failure behavior.
