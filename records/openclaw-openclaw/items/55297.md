## Summary

Keep open: current main supports explicit ClawHub skill/plugin update commands and package-only auto-update, but not unattended skill/plugin auto-update. The remaining work is a product and supply-chain policy decision rather than a narrow bug fix.

## What This Changes

Request an opt-in unattended updater for ClawHub-installed skills and installed plugins instead of requiring explicit update commands.

## Best Possible Solution

Define a maintainer-owned, default-off updater design that reuses existing update primitives while preserving ClawHub trust checks, security.installPolicy, pinning or rollback, audit logs, restart behavior, and clear failure handling.
