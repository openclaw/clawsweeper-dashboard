## Summary

Keep open: current main and v2026.6.11 still provide manual skill/plugin update flows plus package-only auto-update, but not the requested unattended ClawHub skill/plugin updater. The remaining work needs maintainer product and supply-chain policy decisions before implementation.

## What This Changes

The issue requests opt-in unattended auto-update support for ClawHub-installed skills and OpenClaw plugins.

## Best Possible Solution

A maintainer-owned opt-in design should reuse the existing explicit update primitives while gating them on ClawHub trust/provenance, installPolicy, pinning, rollback, audit, and clear failure behavior.
