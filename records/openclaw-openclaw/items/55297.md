## Summary

Keep open: current main and v2026.6.11 have explicit manual skill/plugin update flows plus package auto-update, but not unattended auto-update for installed ClawHub skills or plugins; the remaining work needs maintainer product and supply-chain policy decisions.

## What This Changes

The issue requests opt-in background auto-update for ClawHub-installed skills and OpenClaw-installed plugins.

## Best Possible Solution

Design a default-off updater that reuses the explicit update primitives while enforcing ClawHub trust/provenance, installPolicy, pinning, rollback, audit logs, and clear failure handling.
