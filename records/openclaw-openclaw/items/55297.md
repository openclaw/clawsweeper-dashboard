## Summary

Keep open: current main has explicit manual skill/plugin update flows and package auto-update only; unattended ClawHub skill/plugin updates remain missing and need product and supply-chain policy decisions.

## What This Changes

Request to add opt-in auto-update config and gateway-start or interval checks for ClawHub-installed skills and OpenClaw-installed plugins.

## Best Possible Solution

Design a default-off maintainer-approved updater that reuses explicit update primitives while preserving ClawHub trust checks, installPolicy, pinning or rollback, audit logging, and clear failure handling.
