## Summary

Keep open: current main has explicit manual ClawHub skill/plugin update paths and package-only auto-update, but not the requested unattended skill/plugin auto-update flow. The remaining work is useful but needs maintainer product and supply-chain policy decisions before implementation.

## What This Changes

Request an opt-in background auto-update mechanism for ClawHub-installed skills and plugins, likely through new `openclaw.json` configuration and startup or interval checks.

## Best Possible Solution

Design an opt-in updater that reuses the existing explicit update primitives while preserving ClawHub trust checks, install policy, pinning, rollback, auditability, and operator control before adding config or startup behavior.

## Reproduction Assessment

Not applicable as a bug reproduction; this is a feature request. Source and docs show manual skill/plugin update commands plus separate package-only auto-update, with no current skill/plugin background updater.

## Solution Assessment

Unclear. The requested config booleans are not enough by themselves; the maintainable solution needs an approved trust, pinning, rollback, audit, install-policy, and failure model first.
