## Summary

Keep open: current main has explicit manual skill/plugin update flows and a separate package auto-updater, but not the requested unattended auto-update mechanism for installed ClawHub skills and OpenClaw plugins. The remaining work is product and supply-chain policy, not conservative cleanup.

## What This Changes

The issue requests an opt-in background auto-update mechanism for installed ClawHub skills and OpenClaw plugins.

## Best Possible Solution

Define a maintainer-approved, policy-gated updater that reuses the existing explicit skill and plugin update machinery, preserves pinning and trust checks, and only runs in the background when the operator has clearly opted into the supply-chain risk.

## Reproduction Assessment

Not applicable; this is a feature request, not a broken existing behavior report. Source and docs show the current behavior is manual skill/plugin updates plus a separate package-only auto-updater.

## Solution Assessment

Unclear as proposed. An opt-in updater may be the right product direction, but a gateway-start/background implementation should wait for maintainer supply-chain, restart, pinning, and rollback policy instead of being treated as a narrow bug fix.
