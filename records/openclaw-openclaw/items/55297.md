## Summary

Keep open: current main and v2026.6.11 still expose explicit manual skill/plugin update commands and package auto-update only, not unattended ClawHub skill/plugin updates. The remaining work adds config, gateway lifecycle, and third-party code supply-chain policy, so it needs maintainer product/security direction.

## What This Changes

Request an opt-in native auto-update mechanism for ClawHub-installed skills and OpenClaw-installed plugins, likely configured in openclaw.json and run at gateway startup or on an interval.

## Best Possible Solution

Add this only as a maintainer-approved, default-off updater that reuses the manual update primitives and gates ClawHub/plugin updates on provenance, installPolicy, pinning, rollback, audit logging, and clear failure behavior.

Options:

- **Split trust prerequisites first:** Track signing, rollback, ClawHub review state, and update safety as prerequisite work before deciding on background automation.
