## Summary

Keep this PR open for revision: the shared validation boundary is appropriate, but the implementation misses non-finite values produced by an already-supported custom `toJSON()` serializer, leaving the reported silent `null` conversion possible.

## What This Changes

The PR recursively rejects non-finite numeric tool-schema values before JSON serialization and adds quarantine coverage for the shared, OpenAI, and Anthropic projection paths.

## Best Possible Solution

Reject non-finite numbers within the effective single serialization path, including values returned by custom `toJSON()`, while preserving exact-path diagnostics, one serialization call, invalid-tool quarantine, and healthy sibling retention.
