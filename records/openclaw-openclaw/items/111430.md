## Summary

Keep this PR open for human review: the current branch still appears to allow an event nudge to answer hosted-wizard steps that have no structured card, so the central safety invariant is incomplete; its supplied Chromium proof also uses a deterministic Gateway rather than a completed live hosted-wizard flow.

## What This Changes

The branch separates Custodian event nudges from hosted-wizard replies, tracks request delivery before consuming nudges, reconciles health incidents, and sends `cancel` for Skip on closed structured questions.

## Best Possible Solution

Track the hosted wizard’s awaiting-input state independently of structured-card rendering, disable event nudges for every awaiting wizard step, add regression coverage for a non-card step, and capture redacted live hosted-wizard proof before merge.
