## Label Justifications

- `P1`: The newly bundled 1Password plugin reportedly fails every real gateway get call, and the proposed repair still fails when another hook rewrites parameters.
- `merge-risk: 🚨 security-boundary`: Whole-object parameter replacement can discard higher-priority hook policy transformations or restore an untrusted nonce value on a secret-access tool.
- `merge-risk: 🚨 availability`: A later parameter-modifying hook can remove the nonce and make authorized 1Password gets continue failing closed with POLICY_NOT_EVALUATED.

## Summary

This PR addresses a confirmed fail-closed regression, but the nonce is carried through a whole-object hook parameter replacement that does not survive OpenClaw’s multi-hook composition contract. The earlier tool-call-ID collision concern was fixed by the nonce revision; the remaining composition defect blocks merge and needs a core hook-contract decision because this is a secret-authorization boundary.

## What This Changes

The branch replaces session-based 1Password authorization correlation with a hook-issued UUID passed through tool parameters, adds adversarial broker tests, and includes audit error codes in CLI output.

## Best Possible Solution

Provide a host-authoritative per-invocation correlation value that survives all hook composition and approval-resolution paths without exposing a writable model parameter, with multi-hook regression coverage and a redacted after-fix live gateway run.
