## What This Changes

The PR changes QQBot account discovery so blank or whitespace-only application IDs from configuration or `QQBOT_APP_ID` do not create default or named selectable accounts, and adds resolver tests for blank and valid environment values.

## System Context

QQBot configuration is read from the channel section and environment fallback, then normalized into account IDs and account settings used by channel startup and selection. This PR changes the configured-account decision so only a meaningful application ID produces a selectable QQBot account.
