## What This Changes

The PR updates QQBot account resolution so whitespace-only configured or environment application IDs do not create selectable accounts, and adds focused coverage for blank and valid environment fallbacks.

## System Context

QQBot reads channel configuration and `QQBOT_APP_ID` to discover available bot accounts and choose a default account. That resolved account list feeds later QQBot startup and message-delivery configuration, so blank credentials must not be represented as configured accounts.
