## Summary

Keep open: the prior P1 finding remains on the unchanged head. An open direct-message policy does not make every C2C sender the bot owner, so unconditional direct-callback authorization reopens the configured-approver security boundary; the supplied evidence is still test-only.

## What This Changes

This PR makes QQBot fallback approval buttons bypass command authorization in direct C2C conversations and adds positive tests for absent and wildcard allowlists.

## Best Possible Solution

Bind each fallback approval callback to a trusted actor established from active configuration and the approval request or delivery context, preserve the group gate, and cover both authorized-owner success and unrelated open-DM rejection with focused tests and redacted live QQBot callback proof.
