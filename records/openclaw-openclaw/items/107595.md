## Summary

Keep open: the prior security blocker remains unchanged at the same head. The proposed trust rule is broader than the demonstrated QQBot guarantee, and neither the tests nor contributor evidence prove that an unrelated sender cannot resolve an approval under an open DM policy.

## What This Changes

The PR bypasses command authorization for fallback approval buttons in direct QQBot conversations and adds unit cases for absent and wildcard DM allowlists.

## Best Possible Solution

Authorize direct callbacks by an authoritative identity tied to the approval recipient or configured owner, retain denial for unrelated open-DM senders, and cover both outcomes with focused tests plus redacted runtime proof.
