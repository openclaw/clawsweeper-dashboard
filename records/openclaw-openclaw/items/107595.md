## Label Justifications

- `P0`: The PR changes who may authorize privileged plugin operations through QQBot approval callbacks and can create a security bypass.
- `merge-risk: 🚨 security-boundary`: The new direct-conversation early return removes the actor-authorization gate from a privileged approval callback path.

## Summary

Keep this PR open, but do not merge the current head: it fixes a real C2C denial by removing the trusted-actor check, allowing any sender admitted by an open DM policy to approve their own privileged request. The unchanged head still has the blocker raised in every previous review cycle, and no real QQBot proof establishes a safer platform-enforced identity boundary.

## What This Changes

The PR makes QQBot fallback approval callbacks automatically authorized in direct C2C conversations and adds unit cases for missing and wildcard DM allowlists.

## Best Possible Solution

Authorize direct callbacks against a recorded approval recipient, paired owner, or another explicit trusted identity, while retaining the existing group authorization gate and negative coverage for a different C2C sender.
