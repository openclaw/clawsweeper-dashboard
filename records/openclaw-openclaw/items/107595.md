## Summary

The prior blocker remains on the unchanged PR head: a QQBot C2C chat identifies the sender, not the bot owner, and open or wildcard DM policy can admit non-approvers. The unconditional direct-message return would remove the configured approver check from privileged approval callbacks and regress the established security boundary.

The PR makes fallback QQBot approval callbacks in direct C2C conversations skip command authorization and adds unit cases for absent and wildcard DM allowlists.

## Best Possible Solution
