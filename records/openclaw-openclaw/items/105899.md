## Summary

The reported marker leak is plausible and the shared sanitizer is an appropriate defense boundary, but this patch also deletes ordinary user-authored text and lacks after-fix evidence from a real delivery path, so it is not merge-ready.

## What This Changes

This PR adds three sanitizer patterns and unit coverage to remove `[e~[`, `[e[`, trailing `[1]`, and a trailing lone bracket from user-visible assistant text.

## Best Possible Solution

Trace the actual marker producer, strip the delimiter at that provider or stream-decoding boundary, and retain only an exact terminal `[e~?\[` defense in the shared sanitizer if cross-provider evidence justifies it; do not treat standalone `[1]` or `[` endings as internal scaffolding.
