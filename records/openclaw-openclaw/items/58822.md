## Summary

Keep open: current main still has the shared agent-scope helper and isolated cron consumer using the agent primary before the global subagent default, and the focused linked PR remains the direct candidate fix.

## What This Changes

The issue asks OpenClaw to make global `agents.defaults.subagents.model` outrank an agent's own primary model for subagent model selection when no per-agent subagent model is set.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/58823 after maintainers explicitly choose the global-subagent-default versus agent-primary precedence contract, then keep source, tests, and docs on one canonical rule.
