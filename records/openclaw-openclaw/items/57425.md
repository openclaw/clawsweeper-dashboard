## Summary

Keep open: current main and the latest release include meaningful partial restart protection, main-session recovery, subagent recovery, and cron interruption recording, but the requested umbrella still has unresolved durable message replay, drain-window queueing, cron retry semantics, restart continuation, and config/default policy work.

## What This Changes

Request graceful gateway restart behavior that preserves or recovers active sessions, subagents, cron runs, and drain-window messages across restarts.

## Best Possible Solution

Keep this as the graceful-restart umbrella and land or split maintainer-approved designs for durable message replay, cron retry policy, restart readiness/defaults, and recovery-through-delivery proof.

## Reproduction Assessment

No high-confidence live reproduction covers the full umbrella in this review; source inspection and live field reports support central remaining slices such as drain-window rejection, in-memory followup queues, and interrupted cron runs being marked failed instead of retried.

## Solution Assessment

No single current implementation is the complete best fix yet; current main's safe restart, main-session recovery, subagent recovery, and cron failure recording are useful partial fixes, but durable queue replay, restart continuation, cron retry, and config/default policy still need maintainer alignment.
