## Summary

Keep open: the reported upgrade failure is valid, but the current PR still implements recovery by making normal runtime auth loads read and persist retired `auth-profiles.json`, which conflicts with the current SQLite-only runtime contract, docs, and existing invariant test.

## What This Changes

The branch adds a runtime lazy import from legacy per-agent `auth-profiles.json` into the SQLite auth-profile store, skips unresolved `oauthRef`-only entries, and adds focused auth-profile tests.

## Best Possible Solution

Keep runtime auth reads SQLite-only and recover upgraded installs through doctor or a maintainer-approved one-shot startup/update migration with backup, verification, and clear warnings; update docs and invariant tests only if maintainers choose a different boundary.
