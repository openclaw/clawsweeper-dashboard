## What This Changes

The PR rechecks SQLite integrity against the live database generation and binds runtime and persisted quarantine failures to that generation, preventing a repaired or replaced database from inheriting a stale verifier failure.

## System Context

OpenClaw’s background SQLite verifier scans the shared state database and agent databases, then reports failures to the in-process database owners. Those owners can close connections, latch terminal failures, and persist quarantine records that affect later database opens.
