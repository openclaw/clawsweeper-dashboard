## What This Changes

The issue asks OpenClaw core to make macOS multi-profile homes and gateway/status/restart targeting authoritative across mixed state directories, profile casing, LaunchAgent identity, and config/load state truth.

Maintainers should define one authoritative profile-resolution contract, then align CLI env projection, launchd service targeting, `status --deep` output, doctor diagnostics, tests, and docs around that contract.
