## Summary

Keep open: current main and the latest release still allow mirrored transcript header creation to fall back to ambient `process.cwd()` when no explicit cwd is supplied, and the open linked fix PR has not merged.

## What This Changes

The issue asks OpenClaw to write mirrored session transcript header `cwd` from the target agent workspace rather than ambient `process.cwd()`.

## Best Possible Solution

Land, rebase, or replace https://github.com/openclaw/openclaw/pull/50454 with a current-main patch that resolves the target workspace from agent/session context and passes explicit cwd into transcript header creation, while leaving broader `process.chdir()` cleanup as separate work.
