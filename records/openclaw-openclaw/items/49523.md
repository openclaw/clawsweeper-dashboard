## Summary

Keep open: current main still falls back to ambient `process.cwd()` when a mirrored transcript append lacks `spawnedCwd`, and the open closing PR is conflicting rather than merged.

## What This Changes

The issue asks for session transcript mirror header `cwd` to be derived from the target agent workspace instead of `process.cwd()`.

## Best Possible Solution

Rebase, review, and land or replace https://github.com/openclaw/openclaw/pull/50454 with a current-main fix that passes explicit target workspace cwd into transcript header creation while keeping broader `process.chdir()` cleanup separate.

## Reproduction Assessment

Yes. By source inspection, create a stored session entry without `spawnedCwd`, call `appendAssistantMessageToSessionTranscript()` while ambient cwd differs from the target workspace, and header creation reaches `process.cwd()`.

## Solution Assessment

Yes. Passing an explicit target workspace into header creation is the narrow maintainable fix for this path; current main's `spawnedCwd` handling is useful but insufficient for ordinary mirror entries.
