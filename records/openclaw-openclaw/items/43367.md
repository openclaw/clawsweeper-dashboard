## What This Changes

The issue reports unstable multi-agent orchestration across concurrent agent creation, session write-lock failures, provider auth failover noise, and detached child work.

## Best Possible Solution

Keep this umbrella open while maintainers converge the narrower fixes into a durable multi-agent contract: serialized config mutation stays, subagent completion becomes recoverable/idempotent, session locks gain safe recovery semantics, and operator-visible cancellation/recovery is defined without masking failures behind provider failover.
