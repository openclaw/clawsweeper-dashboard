## Summary

Keep open. Current main and v2026.6.11 still compute Feishu group admission from config-derived `requireMention` while `/activation` persists `groupActivation`, and the direct fix candidate remains open and unmerged.

## What This Changes

Feishu group chats should honor `/activation mention` by stopping non-mentioned group messages from entering the agent path after the session activation mode is switched.

## Best Possible Solution

Review, repair, and land or replace https://github.com/openclaw/openclaw/pull/87709 so Feishu ingress enforces persisted group activation before ordinary group messages reach the agent, while preserving command recovery, config fallback, and docs alignment.
