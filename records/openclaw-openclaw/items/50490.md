## Summary

Keep open. Current main and the latest release still have the Feishu-specific admission gap: `/activation mention` persists session activation state, but Feishu group gating still derives `requireMention` from static config; the linked open PR is the candidate fix and should be reviewed or replaced before this issue closes.

## What This Changes

The issue reports that Feishu group chats keep responding to ordinary non-mention messages after `/activation mention` confirms the activation-mode change.

## Best Possible Solution

Land or replace the Feishu-plugin fix so group admission resolves the effective activation mode from persisted session state before the mention gate, while preserving config fallback when no session override exists.
