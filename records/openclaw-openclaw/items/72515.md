## Best Possible Solution

Align runtime and config validation so mixed `command`+`url` MCP entries are rejected consistently with the documented contract, then require redacted real behavior proof before merge.

## Reproduction Assessment

Yes. Source-level reproduction is clear: current `resolveMcpTransportConfig` resolves a non-empty `command` before considering `url` or `transport`, so the linked mixed streamable-http config takes the stdio path; I did not run the external OpenSpace setup.
