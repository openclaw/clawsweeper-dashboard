## What This Changes

The PR replaces the fixed set of accepted persisted workspace-attestation filenames with a structural safe-markdown-basename check, updates the legacy migration parser, and adds regression coverage for retired and unsafe names.

## System Context

Workspace setup stores hashes for generated bootstrap files in the shared SQLite state database. Snapshot reads validate those rows before downstream workspace-survival and customization checks consume the attestation state.
