## What This Changes

The branch replaces the fixed allowlist for persisted workspace-attestation filenames with one structural safe-Markdown-basename validator in runtime reads, attestation writes, and legacy JSON-to-SQLite migration parsing.

## System Context

OpenClaw stores generated workspace bootstrap-file hashes in its shared SQLite state database, then validates those rows when reconstructing an agent workspace snapshot. The validated snapshot feeds workspace recovery, migration, and agent bootstrap behavior; a stale filename rule can therefore make an otherwise valid upgraded workspace state unreadable.
