## Summary

Keep open for explicit maintainer direction. Current main implements the bounded read-only session workspace viewer and the separate allowlisted Agents file editor, but it does not provide general session-file writes, hash CAS, edit mode, or tool-card path navigation; the protected `maintainer` label and new remote filesystem authority make this a product/security decision rather than an automatic implementation or cleanup close.

## What This Changes

Add an admin-scoped, hash-CAS write method for existing session workspace files, upgrade the Control UI file panel to a CodeMirror viewer/editor, and make expanded tool-card file paths open that panel.

## Best Possible Solution

Approve one additive `operator.admin` `sessions.files.set` contract for existing contained UTF-8 regular files, implement race-safe content-hash CAS through the canonical fs-safe workspace owner, and reuse `openSessionWorkspaceFile` plus the existing detail panel as the sole viewer/editor and tool-card navigation path.
