## Summary

The patch is a focused, plausible repair for the phone app’s stale reduced-motion state and reuses the existing chat implementation pattern, but it needs an after-fix Android runtime capture before merge because the submitted evidence is Robolectric and CI only.

## What This Changes

This PR moves Android’s system-animation-scale observer into a shared Compose helper and makes the mascot, talk waveform, and chat working indicator update when the OS “Remove animations” setting changes.

## System Context

The Android app reads the operating system’s animator-duration setting to decide whether custom Compose animations should run. The shared UI helper converts setting changes into Compose state so animated phone surfaces can stop or resume motion while they remain on screen.
