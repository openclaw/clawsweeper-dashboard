## What This Changes

The branch extracts a shared reactive reader for Android’s system animation scale, then uses it so the phone mascot, talk waveform, and chat working indicator update when the user changes Remove animations.

## System Context

The Android phone UI renders animated mascot and voice-waveform composables alongside a chat working indicator. These surfaces read the operating system’s animator-duration setting to decide whether their local frame-driven animations should run, so a setting change must propagate through a Compose state update to stop or resume rendering.
