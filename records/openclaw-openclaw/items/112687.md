## What This Changes

This PR centralizes Android’s system animation-scale observation so the mascot, talk waveform, and chat working indicator stop or resume while mounted when Remove animations changes, and it extends the root CLI help test’s deadlock guard.

## System Context

Android UI composables read the operating system’s animator-duration setting before driving custom frame loops. The shared observer now turns system-setting changes into Compose state that controls the mascot, waveform, and chat activity animation without recreating the screen.
