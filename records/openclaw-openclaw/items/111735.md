## Summary

This PR is not ready to merge: it removes a validation limit that matches Discord’s current Checkbox Group contract, so configurations with 11–25 checkbox values would pass OpenClaw parsing but be rejected by Discord.

## What This Changes

The branch changes Discord modal checkbox `maxValues` validation from 10 to 25 in `extensions/discord/src/components.parse.ts`.

## Best Possible Solution

Keep checkbox fields capped at 10, add focused coverage for accepting 10 and rejecting 11, and direct 11–25 option workflows to the `select` field type when that UI is appropriate.
