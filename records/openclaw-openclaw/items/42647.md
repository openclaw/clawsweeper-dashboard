## Summary

Keep open: current main has source buckets, path/line citations, short-term promotion metadata, and a provenance-rich Memory Wiki layer, but it still lacks the requested durable multi-source provenance model with source-required promotion and merge/edit lineage.

## What This Changes

Request to add source attribution and provenance as a required durable-memory model covering session/message/file origins, multiple supporting sources, merge/edit preservation, retrieval output, and promotion gating.

## Best Possible Solution

Define a maintainer-approved v1 provenance contract in the active memory backend/schema, then wire promotion, merge/edit, retrieval/review, and the Memory Wiki bridge around that single contract.
