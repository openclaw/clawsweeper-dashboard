## Summary

Keep open: current main and v2026.6.11 still provide source buckets, path#line citations, promotion annotations, and Memory Wiki provenance, but not the requested durable multi-source provenance model, merge/edit lineage, or source-required promotion contract.

## What This Changes

The issue requests a durable memory provenance model with required source references, multi-source support, merge/edit lineage retention, and provenance exposure in retrieval/review flows.

## Best Possible Solution

Adopt one memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage, write, and review surfaces.
