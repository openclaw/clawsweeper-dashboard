## Summary

Keep open: current main has citation-level source buckets, path#line retrieval citations, single-source promotion annotations, and Memory Wiki provenance, but it still lacks the requested durable multi-source provenance model, source-required promotion contract, and merge/edit lineage for durable memories.

## What This Changes

Add a durable memory provenance model with source references, multi-source support, merge/edit lineage, retrieval attribution, and a rule that source-less memories cannot be promoted.

## Best Possible Solution

Define one active-memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and write surfaces.
