## Summary

Keep open: current main still has source buckets, path/line citations, short-term promotion metadata, and Memory Wiki provenance, but it does not implement the requested durable multi-source provenance model with source-required promotion and merge/edit lineage.

## What This Changes

The issue asks for durable memory provenance: source references for session/message/file origins, multi-source lineage, preserved attribution through merges/edits, and attribution in retrieval/review flows.

## Best Possible Solution

Define a maintainer-approved v1 provenance contract in the active memory backend/schema, then wire promotion, merge/edit, retrieval/review, and the Memory Wiki bridge around that single contract.
