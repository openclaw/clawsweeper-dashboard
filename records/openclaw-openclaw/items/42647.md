## Summary

Keep open: current main has useful memory citations, path-line promotion annotations, and Memory Wiki provenance, but it still does not provide the requested durable multi-source provenance contract, merge/edit lineage, or source-required promotion gate.

## What This Changes

Requested a durable memory provenance model with session/message/file source refs, multiple supporting sources, lineage across merges and edits, and source attribution in retrieval and review flows.

## Best Possible Solution

Define one shared memory host/plugin provenance contract, then implement structured source refs, lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and workflow surfaces.
