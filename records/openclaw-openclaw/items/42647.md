## Summary

Keep open: current main and the latest release still provide source buckets, path-line citations, promotion annotations, and Memory Wiki provenance, but not the requested durable multi-source provenance model with merge/edit lineage and source-required promotion.

## What This Changes

Request a Memory MVP provenance model that makes every durable memory carry source references, preserve attribution through merges/edits, and expose attribution in retrieval and review flows.

## Best Possible Solution

Adopt one memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across Memory MVP storage, write, and review surfaces.
