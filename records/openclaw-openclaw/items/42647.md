## Summary

Keep open: current main has source buckets, path#line citations, one-source promotion annotations, and Memory Wiki provenance, but it still does not implement the requested durable multi-source provenance model, source-required promotion contract, or merge/edit lineage for durable memories.

## What This Changes

Add a durable memory provenance model so every promoted memory carries source references, preserves provenance through merges/edits, and exposes attribution during retrieval and review.

## Best Possible Solution

Define one active-memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and write surfaces.
