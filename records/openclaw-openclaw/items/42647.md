## Summary

Keep open: current main and v2026.6.11 still provide source buckets, citations, promotion source text, and Memory Wiki provenance, but they do not implement the requested durable multi-source provenance model, merge/edit lineage, or source-required promotion contract.

## What This Changes

Request to add Memory MVP source attribution so durable memories carry source refs, preserve multi-source lineage across merges/edits, expose retrieval/review attribution, and block source-less durable promotion.

## Best Possible Solution

Adopt one maintainer-approved active-memory provenance contract, then implement required source refs, multi-source lineage, merge/edit preservation, retrieval attribution, and review/promotion gates across the storage, write, retrieval, and review boundaries.
