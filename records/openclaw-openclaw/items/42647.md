## Summary

Keep open: current main and v2026.6.11 still have citation/source buckets and Memory Wiki provenance, but not the requested durable multi-source provenance model, merge/edit lineage, or source-required promotion contract.

## What This Changes

Add a Memory MVP provenance model requiring durable memories to carry source references, preserve lineage across edits/merges, and expose attribution in retrieval and review flows.

## Best Possible Solution

Adopt one maintainer-approved active-memory provenance contract, then implement required source refs, multi-source lineage, merge/edit preservation, retrieval attribution, and review/promotion gates across storage, write, retrieval, and review boundaries.
