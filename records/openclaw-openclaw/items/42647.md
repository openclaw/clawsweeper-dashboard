## Summary

Keep open: current main has citation-style source buckets and Memory Wiki provenance, but it still lacks the requested durable multi-source provenance model, source-required promotion contract, and merge/edit lineage for durable memories.

## What This Changes

The issue requests a Memory MVP provenance model so durable memories retain source references across session/message/file origins, merges, edits, retrieval, and review flows.

## Best Possible Solution

Define one active-memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and write surfaces.
