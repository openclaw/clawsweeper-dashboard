## Summary

Keep open: current main and v2026.6.11 have source buckets, citations, promotion source text, and Memory Wiki provenance, but they still do not implement the requested durable multi-source provenance model, merge/edit lineage, or source-required promotion contract.

## What This Changes

The issue requests a durable memory provenance model with source refs for session/message/file origins, multi-source support, merge/edit lineage, and provenance-visible retrieval/review output.

## Best Possible Solution

Adopt one maintainer-approved active-memory provenance contract, then implement required source refs, multi-source lineage, merge/edit preservation, retrieval attribution, and review/promotion gates across the storage, write, retrieval, and review boundaries.
