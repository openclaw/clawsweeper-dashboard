## Summary

Keep open: current main still has citation/path metadata, a memory index source bucket, single-source promotion annotations, and Memory Wiki provenance, but not the requested durable multi-source provenance model with source-required promotion and merge/edit lineage.

## What This Changes

Add a durable source-attribution and provenance model so promoted memories retain source refs across storage, retrieval, merges, edits, and review flows.

## Best Possible Solution

Define one active-memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and write surfaces.
