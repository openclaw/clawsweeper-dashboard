## Summary

Keep open: current main has source buckets, path citations, short-term promotion source text, and Memory Wiki evidence metadata, but it still lacks the requested durable multi-source provenance model, merge/edit lineage, and source-required promotion contract.

## What This Changes

Add a durable memory provenance model with source refs, multi-source support, merge/edit lineage, retrieval attribution, and a gate against promoting source-less memories.

## Best Possible Solution

Define one maintainer-approved active-memory provenance contract, then implement required source refs, multi-source lineage, merge/edit preservation, retrieval attribution, and promotion/review gates across storage, write, retrieval, and review boundaries.
