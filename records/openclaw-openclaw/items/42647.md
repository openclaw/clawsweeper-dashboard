## Summary

Keep open: current main has coarse memory source buckets, path/line citations, short-term promotion metadata, and Memory Wiki claim evidence, but it still does not implement a durable multi-source provenance model with source-required promotion and merge/edit lineage.

## What This Changes

Request to add schema-level source attribution and provenance for durable memories, including multiple supporting sources, merge/edit lineage, and provenance-aware retrieval/review output.

## Best Possible Solution

Define a maintainer-approved v1 provenance contract in the active memory backend/schema, then wire promotion, merge/edit, retrieval/review, and the Memory Wiki bridge around that contract.
