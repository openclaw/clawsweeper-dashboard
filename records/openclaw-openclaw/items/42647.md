## Summary

Keep open: current main has source buckets, path#line citations, promotion annotations, and a provenance-rich Memory Wiki layer, but it still does not provide the requested durable multi-source provenance model, source-required promotion contract, or merge/edit lineage for durable memories.

## What This Changes

Request a durable memory source-attribution and provenance model with source refs, multi-source support, lineage across merges/edits, retrieval/review attribution, and promotion blocking for source-less memories.

## Best Possible Solution

Define one active-memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and write surfaces.
