## Summary

Keep open: current main has memory source buckets, path citations, short-term promotion source text, and optional Memory Wiki evidence metadata, but it still does not provide the requested required durable multi-source provenance model, merge/edit lineage, or source-less promotion gate.

## What This Changes

Add a Memory MVP provenance model so every durable memory carries source attribution, preserves source history across edits/merges, and exposes attribution in retrieval and review flows.

## Best Possible Solution

Define one maintainer-approved active-memory provenance contract, then implement required source refs, multi-source lineage, merge/edit preservation, retrieval attribution, and promotion/review gates across storage, promotion, retrieval, and review boundaries.
