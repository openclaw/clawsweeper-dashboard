## Summary

Keep open: current main has source buckets, path citations, short-term promotion source text, and Memory Wiki evidence metadata, but it still lacks the requested required durable multi-source provenance model, merge/edit lineage, and source-less promotion gate.

## What This Changes

Request to add required source attribution and provenance for durable memories, including multiple sources, merge/edit preservation, and retrieval/review display.

## Best Possible Solution

Define one maintainer-approved active-memory provenance contract, then implement required source refs, multi-source lineage, merge/edit preservation, retrieval attribution, and promotion/review gates across storage, promotion, retrieval, and review boundaries.
