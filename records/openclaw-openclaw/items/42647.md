## Summary

Keep open: current main and the latest release still provide citation-style attribution, source buckets, and a separate Memory Wiki provenance layer, but not the requested durable multi-source provenance model, source-required promotion contract, or merge/edit lineage for durable memory.

## What This Changes

The issue requests a durable memory provenance model with source refs, multi-source support, lineage across merges/edits, and source attribution in retrieval/review flows.

## Best Possible Solution

Adopt one shared memory provenance contract at the memory host/plugin boundary, then implement structured source refs, lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and workflow surfaces.
