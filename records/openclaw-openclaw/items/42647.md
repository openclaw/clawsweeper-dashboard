## Summary

Keep open: current main and v2026.6.11 still have source buckets, path#line citations, promotion annotations, and a separate Memory Wiki provenance layer, but not the requested durable multi-source provenance model, merge/edit lineage, or source-required promotion contract.

## What This Changes

The issue requests durable memory source references, multi-source provenance, lineage retention across merges/edits, and visible attribution in retrieval and review flows.

## Best Possible Solution

Define one memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the active memory stack.
