## Summary

Keep open: current main has source buckets, path#line citations, single-source promotion annotations, LanceDB timestamps, and a provenance-rich Memory Wiki layer, but it still does not implement the requested durable multi-source provenance model, source-required promotion contract, or merge/edit lineage for durable memories.

## What This Changes

Requests a durable memory provenance model with source references, multi-source support, lineage through merges and edits, and attribution in retrieval and review flows.

## Best Possible Solution

Define one active-memory provenance contract at the memory host/plugin boundary, then implement structured source refs, multi-source lineage, source-required promotion, and retrieval/review attribution across the Memory MVP storage and write surfaces.
