## Summary

Keep open. Current main and latest release v2026.6.11 still reject a generic request-body `model` after resolving a valid agent header, and changing that is a public OpenAI-compatible API precedence decision rather than conservative cleanup.

## What This Changes

Request that `/v1/chat/completions` ignore or tolerate the request-body `model` when a valid `x-openclaw-agent-id` header selects an agent.

## Best Possible Solution

Gateway owners should choose one OpenAI-compatible model/header precedence rule, then update the shared resolver, docs, and focused endpoint tests consistently for the endpoints they want covered.
