## Summary

Keep open. Current main and the latest release still reject a generic body `model` after a valid `x-openclaw-agent-id`, while the requested behavior would change the documented OpenAI-compatible model/header precedence contract.

## What This Changes

Request `/v1/chat/completions` to ignore or tolerate the request body `model` and use the selected agent's configured model when a valid `x-openclaw-agent-id` header is present.

## Best Possible Solution

Gateway owners should choose one OpenAI-compatible model/header precedence rule, then update the shared resolver, sibling endpoint behavior, docs, and focused tests consistently.
