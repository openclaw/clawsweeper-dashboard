## Summary

Keep open. Current main and the latest release still reject a generic body `model` after a valid `x-openclaw-agent-id`, while the docs define `model` as an agent target, so this remains a maintainer API-precedence decision rather than cleanup closure.

## What This Changes

Request `/v1/chat/completions` to ignore or tolerate the request body `model` when a valid `x-openclaw-agent-id` header selects the agent.

## Best Possible Solution

Gateway owners should define one precedence rule for agent header versus body model; if header precedence is adopted, implement it in the shared resolver with docs and focused tests for the chosen endpoint set.
