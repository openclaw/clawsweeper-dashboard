## Summary

Keep open for maintainer review: the patch is focused, source-consistent, and has no blocking code findings, but merging it intentionally changes cron delivery-only failures from execution `error` to execution `ok` plus delivery metadata.

## What This Changes

This PR reclassifies nonfatal isolated cron delivery-dispatch failures from run `error` to `ok` while carrying `deliveryError` through cron state, finished events, and run-log readback tests.

## Best Possible Solution

Land one maintainer-approved cron contract: either accept this narrow `ok` plus `deliveryStatus:not-delivered` split with the added delivery diagnostics, or supersede it with the broader warning-status design before changing shipped semantics.
