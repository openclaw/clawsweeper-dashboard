## What This Changes

Add support for `openclaw message read --channel telegram` so agents can read recent Telegram chat messages for monitoring and context workflows.

## Best Possible Solution

Define Telegram `message read` in the Telegram plugin with an explicit retained-message contract, privacy/config gate, target/topic semantics, docs, focused tests, and live Telegram proof.

## Solution Assessment
