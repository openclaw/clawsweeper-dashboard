## Summary

Request to add Telegram support for `openclaw message read` so agents can read recent Telegram group/chat messages for monitoring workflows.

## Best Possible Solution

Define Telegram `message read` inside the Telegram plugin with an explicit observed-message contract, privacy/config gate, target/topic authorization, docs, focused tests, and live Telegram proof; avoid a second `getUpdates` poller.

## Reproduction Assessment

## Solution Assessment
