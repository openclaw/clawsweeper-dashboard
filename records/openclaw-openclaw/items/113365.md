## What This Changes

Normalize invalid LINE template-carousel columns so one missing action, label, title, or thumbnail does not make LINE reject the entire reply.

## System Context

The LINE plugin converts agent reply payloads and product data into Messaging API template messages. Carousel builders feed those columns to LINE, which either accepts the whole template or rejects the complete reply with HTTP 400.

Review and, if its shared-boundary tests and LINE validation evidence hold, land https://github.com/openclaw/openclaw/pull/113366 so invalid carousel input degrades to a deliverable normalized template or no template rather than dropping the whole reply.
