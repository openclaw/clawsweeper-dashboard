## What This Changes

The PR extracts shared helpers for subagent payload visibility, delivery outcome evidence, media accounting, and completion-origin routing, then uses them from announcement delivery and restart recovery.

## System Context

Embedded subagents produce completion payloads and delivery-status records. Announcement delivery and restart recovery inspect those records with session context to determine whether a completed result still needs to be delivered and where that delivery should go.
