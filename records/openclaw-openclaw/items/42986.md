## Summary

Keep open: current main and the latest release have the Telegram binding primitives, but they still do not expose the requested Telegram child-topic `sessions_spawn(thread:true, mode:"session")` capability; this remains a maintainer product/API decision with an open conflicting implementation candidate.

## What This Changes

The issue requests Telegram support for persistent subagent sessions bound to Telegram conversations or forum topics via `sessions_spawn(thread:true, mode:"session")`.

## Best Possible Solution

Approve a narrow Telegram child-topic subagent capability on the current core session-binding path, keep ordinary Telegram placement current-topic by default, and require focused tests plus redacted live Telegram proof before closing this issue.
