## Summary

Keep open. Current main has core session-binding adapters and Telegram current-conversation binding, but the requested Telegram child-topic subagent session behavior remains unresolved and is already tied to open product/API review.

## What This Changes

## Best Possible Solution

Land or replace the active Telegram candidate with a maintainer-approved core session-binding adapter capability that preserves current-topic defaults, avoids deprecated hook routing, and includes final-head live Telegram proof.
