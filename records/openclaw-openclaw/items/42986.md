## Summary

Keep open. Current main has core session-binding adapter support and Telegram current-conversation bindings, but it still does not expose Telegram child-topic native subagent session spawning; the direct implementation candidate at https://github.com/openclaw/openclaw/pull/82023 remains open, conflicting, and blocked on maintainer API/product review.

## What This Changes

Request support for Telegram persistent thread-bound native subagent sessions via `sessions_spawn(mode="session", thread=true)`, including binding child sessions to Telegram conversations/topics and lifecycle cleanup.

## Best Possible Solution

Land or replace the active Telegram candidate with maintainer-approved child-topic subagent binding through the current core session-binding adapter path, preserving Telegram's normal current-topic default and requiring final-head live Telegram proof.
