## Summary

Keep this issue open. Current main still has no global primary cron delivery destination, and the closed broader requests plus open adjacent PRs do not replace this focused product decision.

## What This Changes

Add a global cron delivery default that applies when individual jobs omit channel and target settings.

## Best Possible Solution

Define one supported precedence for explicit job delivery, optional global defaults, and omitted delivery, then implement it consistently across config validation, stored-job creation, runtime resolution, CLI and Control UI, public docs, and regression tests.
