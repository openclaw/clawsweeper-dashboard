## Summary

Keep open. Request to add a `cron.defaults.delivery` configuration default so cron jobs can inherit a stable delivery channel and target instead of repeating per-job delivery fields or falling back to the last session target.

Keep this focused tracker open and implement a maintainer-approved cron delivery default across config types/schema, service normalization, CLI/UI, docs, and regression tests with explicit per-job delivery taking precedence.
