## What This Changes

The issue requests a `cron.defaults.delivery` config option that supplies a default primary cron delivery mode, channel, and target when individual jobs omit delivery fields.

## Best Possible Solution

Keep this focused tracker open and define a maintainer-approved `cron.defaults.delivery` contract that preserves explicit per-job precedence, separates failure-notification defaults, validates recipients, and updates config schema, CLI/UI surfaces, docs, and regression tests together.
