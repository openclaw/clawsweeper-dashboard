## Summary

Keep open: current main and v2026.6.11 still have the Remote-mode launchd disable short-circuit, and https://github.com/openclaw/openclaw/pull/98538 is an open draft fix candidate using closing syntax. This issue should close only after that PR or an equivalent fix lands.

## What This Changes

Switching the macOS GUI to Remote mode should disable any previously installed local gateway launchd job instead of leaving it loaded or running.

## Best Possible Solution

Land the linked candidate fix or an equivalent narrow fix after macOS proof shows Remote mode uninstalls the local gateway job without regressing Local-mode launchd enablement.

## Reproduction Assessment

Yes. Current main is source-reproducible: Remote mode calls the stop path, and the stop path returns before issuing the launchd disable request; I did not run a live macOS launchd repro in this Linux review environment.

## Solution Assessment

Yes. The narrow solution is to let Remote-mode disable/uninstall reach the local launchd manager while still preventing Remote-mode enables, and the linked PR is the active candidate for that shape.
