## Summary

Keep open: current main and the latest release still have the Remote-mode launchd disable short-circuit, and the issue is paired with an open draft fixing PR that uses closing syntax. The issue should close only after that PR or an equivalent fix lands.

## What This Changes

The issue reports that switching the macOS GUI to Remote mode can leave the local gateway LaunchAgent installed or running because the stop/disable paths short-circuit in Remote mode.

## Best Possible Solution

Land a focused fix that allows Remote-mode transitions to disable/uninstall the local gateway LaunchAgent while still preventing Remote mode from enabling or spawning a local gateway.

## Reproduction Assessment

Yes from source inspection, though I did not run a live macOS launchd repro. The Remote-mode transition calls `ConnectionModeCoordinator.apply`, then `GatewayProcessManager.stop()`, and current main returns before the launch-agent uninstall path.

## Solution Assessment

Yes, the best fix shape is narrow: allow disable/uninstall in Remote mode while continuing to block local gateway enable/start in Remote mode. The linked draft PR is the active candidate, so the issue should stay open until that path is reviewed and merged or replaced.
