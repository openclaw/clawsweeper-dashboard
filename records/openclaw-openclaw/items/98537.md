## Summary

Keep open: current main and v2026.6.11 still skip the local launchd disable path in Remote mode, and the linked open draft PR is the active fix candidate. This issue should close only after that or an equivalent fix merges.

## What This Changes

The issue asks for macOS Remote mode to unload or disable any previously enabled local gateway LaunchAgent when switching away from Local mode.

## Best Possible Solution

Land a focused fix that lets Remote-mode stop disable the local LaunchAgent while still preventing Remote-mode launchd enable, with Swift regression coverage and macOS launchd proof.

## Reproduction Assessment

Yes, at source level: Remote mode calls GatewayProcessManager.stop(), but stop returns before disabling launchd and GatewayLaunchAgentManager.set() also skips all changes in Remote mode. I did not run a live macOS launchd repro in this read-only review.

## Solution Assessment

Yes, the narrow fix is to allow the disable/uninstall path while keeping Remote-mode launchd enable blocked. The linked draft PR follows that shape, but the issue should stay open until the fix is reviewed, proven, and merged.
