## What This Changes

The PR computes optional image, video, and music tool availability once during agent-tool preparation and passes that decision into media-generation factories so they do not repeat registration-time checks.

## System Context

OpenClaw prepares an agent's available tools from configuration, workspace/plugin capability metadata, policy, and authenticated provider profiles. This PR changes the optional-media planning layer that gates image and media-generation tools before the finished tool set reaches the agent runtime.
