## Summary

Keep this PR open for maintainer review. It has credible after-fix performance proof and focused regression coverage, but it deliberately makes a shared planning result authoritative for four media-tool registrations, so an owner should confirm that its availability predicates remain equivalent to each factory’s registration contract.

## What This Changes

The branch computes optional media-tool availability once during agent tool preparation and passes that result to image, image-generation, video-generation, and music-generation factories to avoid repeated registration-time availability scans.

## System Context

Agent tool preparation builds the set of tools available to an agent turn from configuration, plugin capability metadata, workspace state, and authentication. The resulting tool set is then exposed to the model and invokes provider-specific media behavior only when a tool is used.
