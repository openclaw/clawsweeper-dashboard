## What This Changes

This PR computes optional media-tool availability once during agent tool preparation and reuses that result when registering image, image-generation, video-generation, and music-generation tools.

## System Context

OpenClaw prepares an agent-specific tool set from configuration, workspace metadata, plugin capabilities, and authentication profiles. This PR changes the optional-media decision made during preparation, then feeds it to individual media tool factories so they do not repeat registration-time availability scans.

## Architecture Diagram

flowchart LR

  B --> C[Media capability planning]
  C --> D[Shared optional-media plan]
  D --> E[Image and generation tool factories]
  E --> F[Registered agent tool set]
  F --> G[Execution-time provider resolution]

## Best Possible Solution

Adopt one documented optional-media registration decision in the agent tool-preparation layer, retain execution-time provider resolution in each tool, and keep focused equivalence tests whenever a media factory changes its availability predicate.
