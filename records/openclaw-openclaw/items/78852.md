## Summary

This remains a useful, currently active performance PR rather than a cleanup-close candidate. The branch has fresh real benchmark evidence and focused regression coverage, but it deliberately moves image, video, and music registration onto one shared availability decision; a maintainer should confirm that decision remains equivalent to each factory’s former config, workspace, auth, and prepared-runtime predicate before merge.

## What This Changes

The branch computes optional media-tool availability once during agent-tool preparation and passes that result to image, video, and music factories so they skip duplicate registration-time availability scans.

## System Context

Agent tool preparation assembles the tools exposed for each agent turn from configuration, workspace capability metadata, authentication profiles, and prepared model-runtime facts. The optional media plan decides which image-understanding and media-generation tools enter that list before tool execution later resolves the selected provider.

## Best Possible Solution

Keep one canonical availability plan, but establish and preserve predicate-equivalence tests for every factory it authorizes, including fresh configuration, explicit workspaces, disabled plugins, auth-only providers, and prepared-runtime capability inputs.
