## What This Changes

The PR computes optional image, video, and music tool availability once during agent-tool preparation and passes that result to media-generation factories so they do not repeat registration-time availability checks.

## System Context

Agent-tool preparation builds the tools available for each OpenClaw agent run from configuration, workspace plugin metadata, model capabilities, and auth profiles. The optional-media plan controls registration of image and media-generation tools before their execution-time provider resolution runs.
