## What This Changes

The PR adds Feishu historical message media recovery to `getMessageFeishu`, returns `media` and `mediaUnavailableCount` from read results, extracts image keys from interactive cards, and adds helper/action tests.

## Best Possible Solution

Keep historical media recovery Feishu-owned but make it explicit and bounded, such as an opt-in `getMessageFeishu` mode used by `message.read`, while preserving metadata-only internal lookups.
