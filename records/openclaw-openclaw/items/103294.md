Full review comments:

- **[P1] Fail closed when legacy state cannot be read:** `src/infra/push-web-migration.ts:8-12`
  - body: `readJsonSync` catches missing-file, permission, I/O, and JSON parse failures alike and returns `undefined`, so startup treats an unreadable subscription or VAPID file as if it never existed. That can start with no subscriptions or generate a new signing identity; distinguish absence from read/parse failure and leave failed input for a visible retry.
  - confidence: 0.99
- **[P1] Prevent archive failures from restoring cleared subscriptions:** `src/infra/push-web-migration.ts:78-84`
  - body: If `renameSync` fails, the legacy JSON stays in place and later startups import every hash missing from SQLite. Clearing an imported subscription and restarting therefore restores it from stale state; make archival failure retry-safe without replaying records that users intentionally removed.
  - confidence: 0.99
- **[P1] Align the migration with the startup task contract:** `src/infra/push-web-migration.ts:124-126`
  - body: This function is typed as `Promise<void>` but returns nothing, while the startup caller pushes its `void` result into a promise task list. Exact-head CI fails at both lines; either use a synchronous `void` migration outside that list or return and await a real promise.
  - confidence: 1
