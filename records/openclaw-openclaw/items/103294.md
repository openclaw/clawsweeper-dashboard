## Summary

## What This Changes

The PR replaces JSON-backed web push subscription and VAPID key storage with shared SQLite tables and adds inline legacy-file import and archival.

## Best Possible Solution

Use one explicit, observable migration owner that verifies import and archival before runtime switches to SQLite-only reads, with regression coverage proving unsubscribe remains durable under migration failures.
