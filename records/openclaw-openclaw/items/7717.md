## Summary

Keep open: current main still records Discord role mentions but does not let configured role IDs satisfy mention gating, and the intended multi-agent fan-out policy requires maintainer approval before implementation.

## What This Changes

Add configurable Discord role IDs that count as wake mentions for mention-gated guild or channel messages.

## Best Possible Solution

After approving the fan-out contract, add an opt-in guild/channel wake-role ID list in the Discord plugin, wire it through schema/help/docs, and cover matched, unmatched, other-mention, reply, and bot-loop cases.
