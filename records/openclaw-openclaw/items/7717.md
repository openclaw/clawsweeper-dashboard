## Summary

Keep open: current main and the latest release still do not provide a Discord role-mention trigger config or a preflight path that turns mentioned role IDs into a wake mention, so this remains valid Discord channel/product work rather than cleanup-close material.

## What This Changes

Request support for Discord role mentions, such as a configured role-ID list, to wake bots in mention-gated guild channels.

## Best Possible Solution

Approve a narrow Discord-owned trigger-role contract, then wire it through config types, strict schema, metadata/docs, preflight, and focused source plus live Discord proof while preserving sender role allowlists and current @everyone/@here behavior.
