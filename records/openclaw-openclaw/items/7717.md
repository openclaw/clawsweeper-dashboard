## What This Changes

Add an opt-in Discord guild or channel setting that treats configured role mentions as wake signals for mention-gated agents.

## System Context

Discord inbound preflight receives a guild message and its user, role, and mass-mention metadata, then decides whether an agent should process it. This request would add configured role IDs to that activation decision, affecting mention-gated routing and potential multi-agent responses.

## Architecture Diagram

## Best Possible Solution

Choose the role-trigger and multi-agent fan-out contract first, then add a distinct opt-in Discord configuration field owned by the Discord plugin, with schema/help/docs and focused preflight coverage for matching, non-matching, and mixed mention cases.
