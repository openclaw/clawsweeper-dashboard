## Summary

Keep open: current main and v2026.6.11 still lack a Discord role-mention trigger config or preflight path, and this remains the narrow tracker rather than cleanup-close material.

## What This Changes

Request support for Discord role mentions to wake Discord-bound agents, likely through a new per-guild or per-channel role-trigger configuration.

## Best Possible Solution

Add an explicit Discord role-mention trigger surface in the bundled Discord plugin, with schema/docs/tests that preserve current sender `roles`, `requireMention`, `ignoreOtherMentions`, @everyone/@here, and reply behavior.

## Reproduction Assessment

Yes, at source level: a role-only Discord guild message can populate `mentionedRoles`, but current mention gating has no configured role-trigger input to turn that into `wasMentioned`. I did not run a live Discord replay in this read-only review.

## Solution Assessment

Unclear until maintainers choose the config shape. A distinct additive role-trigger field is safer than reusing `roles`, because `roles` already means sender allowlist.
