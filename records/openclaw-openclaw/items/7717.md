## Summary

Keep open: current main and v2026.6.11 still lack a Discord role-mention trigger config or preflight path, so this remains the narrow canonical tracker; implementation needs maintainer product direction because it adds shipped Discord config and multi-agent fan-out semantics.

## What This Changes

Request adding a Discord guild/channel role-mention trigger so messages mentioning configured role IDs wake matching bots instead of requiring individual bot mentions.

## Best Possible Solution

Approve a narrow Discord-owned trigger-role contract, then wire it through config types, strict schema, generated metadata/docs, preflight, focused role-mention tests, and live Discord proof while preserving sender role allowlists and @everyone/@here behavior.
