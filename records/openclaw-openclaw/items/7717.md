## Best Possible Solution

Keep this issue as the focused configured role-target contract unless maintainers explicitly consolidate it, then implement precise guild/channel role-ID matching inside the Discord plugin while preserving sender authorization, unrelated-role filtering, mass-mention behavior, replies, and loop suppression.
