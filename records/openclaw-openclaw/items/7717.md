## What This Changes

Add Discord role-mention triggers so configured role IDs can wake bots in mention-gated guild channels.

## Best Possible Solution

Approve a narrow Discord-owned trigger-role contract, then wire it through config types, strict schema, docs, preflight, and focused source/live proof while preserving sender role allowlists and current @everyone/@here behavior.

## Reproduction Assessment

Yes, at source level: with `requireMention` true and only `mentionedRoles` present, current preflight has no path that compares mentioned role IDs with configured trigger roles, so it can drop as no-mention or other-mention. I did not run a live Discord replay in this read-only review.

## Solution Assessment

Unclear as a final product contract: configured role IDs look safer than treating every bot-held role as a wake signal, but maintainers still need to choose the config name, inheritance, and fan-out behavior.
