## Summary

Keep open: current main and v2026.6.11 still lack a Discord role-mention trigger config or preflight path, while related GitHub search confirms this issue remains the narrow canonical tracker for the missing role-trigger behavior.

## What This Changes

Requested support for Discord role mentions to wake agents, likely through an additive role-trigger configuration for Discord guild/channel mention gating.

## Best Possible Solution

Approve a narrow Discord-owned trigger-role contract, then wire it through config types, strict schema, docs, preflight, and focused source/live proof while preserving current sender role allowlists and @everyone/@here behavior.

## Reproduction Assessment

Yes, at source level: with `requireMention` true and only `mentionedRoles` present, current preflight has no path that compares mentioned role IDs with configured trigger roles, so it can drop as no-mention or other-mention. I did not run a live Discord replay in this read-only review.

## Solution Assessment

Unclear as a final product contract: selected configured role IDs look safer than treating every bot-held role as a wake signal, but maintainers still need to choose the config name, inheritance, and fan-out behavior.
