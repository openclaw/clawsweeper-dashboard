## Summary

Current main and the latest release still do not support configured Discord role-mention wake triggers, and no open or merged replacement owns the work. Keep this issue as the canonical tracker, but require maintainer direction because the change adds config and multi-agent fan-out semantics to an intentionally scoped mention policy.

## What This Changes

Add a Discord guild/channel role-ID list whose matching role mentions count as explicit agent wake signals.

## Best Possible Solution

Define one Discord plugin attention policy that keeps sender-role authorization separate from mentioned-role wake targets, then add selected role triggers with explicit precedence, documentation, and fan-out coverage if approved.
