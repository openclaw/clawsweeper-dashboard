## Summary

Keep open: current main and v2026.6.11 still do not provide a Discord role-mention trigger surface, and role mentions are only generic mention metadata unless they also match a bot user mention or configured text pattern.

## What This Changes

Add Discord role-mention triggers so configured role IDs can wake mention-gated Discord agents.

## Best Possible Solution

Approve a narrow Discord-owned role-trigger config contract, then wire it through config types, strict schema, metadata/docs, preflight, and focused tests while preserving sender roles allowlists, requireMention, ignoreOtherMentions, @everyone/@here, and reply-to-bot behavior.

## Reproduction Assessment

Yes, at source level: a role-only Discord mention sets mentionedRoles/mention_roles but does not become wasMentioned, so requireMention can drop it as no-mention. I did not run a live Discord guild replay in this read-only review.

## Solution Assessment

Unclear as a finalized product path: adding a dedicated triggerOnRoles-style key is plausible and avoids overloading sender roles, but maintainers still need to approve the config name, inheritance scope, and default behavior.
