## Summary

Keep open: current main still lacks a Discord role-mention trigger config or preflight path, so the requested role-addressed wake behavior remains a valid Discord delivery/product decision rather than cleanup-close material.

## What This Changes

Add Discord role-mention triggers so configured role mentions such as @AI can wake bots, instead of only direct bot mentions.

## Best Possible Solution

Approve a narrow Discord-owned trigger-role contract, then wire it through config types, strict schema, metadata/docs, preflight, and focused source plus live Discord proof while preserving sender role allowlists and current @everyone/@here behavior.
