## Summary

Keep open: current main and v2026.6.11 still lack a Discord selected-role trigger config and preflight path, while this issue remains the narrow canonical tracker for role-mention wake behavior.

## What This Changes

Request to add Discord role-mention triggers, likely configured by role IDs, so role mentions can wake bots like direct bot mentions.

## Best Possible Solution

Approve a narrow Discord-owned selected-role trigger contract, then implement it through config types, strict schema, generated metadata/docs, preflight, and focused regression coverage without reusing sender `roles`.

## Reproduction Assessment

Yes, at source level: current main has no role-trigger config and role-only mentions set generic mention metadata without making `wasMentioned` true. I did not run a live Discord replay in this read-only review.

## Solution Assessment

Unclear as a final product contract: selected role IDs appear safer than auto-triggering on every bot-held role, but maintainers still need to decide the config name, inheritance, and fan-out behavior.
