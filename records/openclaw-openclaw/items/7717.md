## Summary

Keep open: current main still lacks selected Discord role-mention wake triggers, and the remaining question is a deliberate multi-agent activation policy that needs maintainer approval.

## What This Changes

Add an opt-in Discord guild/channel setting that treats selected role IDs as explicit wake mentions for mention-gated agents.

## Best Possible Solution

Implement a separate additive Discord guild/channel role-ID wake setting, match it against inbound mentioned-role IDs before mention gating, preserve existing authorization and routing semantics, and cover matched, unmatched, reply, mass-mention, other-mention, and bot-loop cases with focused tests and redacted live Discord proof.
