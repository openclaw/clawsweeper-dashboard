## What This Changes

Request Discord role mentions such as a shared bot role to wake agents in mention-gated guild channels through a configured role-ID trigger surface.

## Best Possible Solution

Approve a narrow Discord-owned trigger-role contract, then wire it through config types, strict schema, generated metadata/docs, preflight, focused tests, and live Discord proof while preserving sender role allowlists and current @everyone/@here behavior.
