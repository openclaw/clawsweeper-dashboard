## Summary

This PR should not merge in its current form: the shipped `before_agent_run` hook already provides a fail-closed prompt gate, while converting the documented observation-only `llm_input` hook creates a competing policy surface and breaks existing observer compatibility.

## What This Changes

Changes `llm_input` from a fire-and-forget observation hook into an awaited fail-closed gate, adds an abort result type, and exposes `sessionFile` on the public agent hook context.

## Best Possible Solution

Keep `llm_input` observation-only and implement guardrails through `before_agent_run`, extending that established gate narrowly only if a concrete required context field is missing while preserving its timeout, sanitization, persistence, and fail-closed contracts.
