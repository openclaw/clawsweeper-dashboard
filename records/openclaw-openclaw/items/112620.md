## Summary

Keep this PR open. It targets the live argument-variation loop report, but the final execution-parameter reconciliation starts the churn liveness signal at the fixed default of 10 calls rather than the user-configured loop-warning threshold; configurations that intentionally lower the threshold therefore do not receive the promised earlier recovery behavior. The PR body now gives credible deterministic runtime transcripts, but the threshold regression remains a merge-blocking correctness issue.

## What This Changes

This PR adds warning-only detection for repeated same-tool argument variants that return one stable result, and connects that semantic stall signal to existing embedded-run recovery and command-lane draining.

## System Context

OpenClaw wraps agent tool calls with policy and loop detection before executing them, then records diagnostic activity for the embedded run. Stuck-session recovery reads that activity to decide whether a stalled owner-bound run should be aborted and its queued lane drained.
