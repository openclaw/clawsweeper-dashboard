## What This Changes

The PR classifies sustained same-tool calls with several stable argument variants as no-progress churn, allowing the existing global circuit breaker to veto the next call.

## System Context

Agent tool calls are recorded in per-session diagnostic state, then checked immediately before another tool executes. The detector emits a critical loop result that the wrapped tool runtime turns into a pre-execution veto and diagnostic event.
