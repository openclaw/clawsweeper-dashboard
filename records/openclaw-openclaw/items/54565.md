## What This Changes

The issue requests a per-group inbound debounce override, primarily for `channels.whatsapp.groups.<jid>.debounceMs`, so selected groups can batch rapid messages without slowing every WhatsApp group/account.

## Best Possible Solution

Approve a narrow WhatsApp group-scoped debounce override only after maintainers choose precedence, then wire it through the existing per-item debouncer seam with schema, docs, and regression tests.
