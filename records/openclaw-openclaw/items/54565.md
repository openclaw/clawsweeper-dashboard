## Summary

Keep open. Current main and v2026.6.11 still lack the requested WhatsApp group-level `debounceMs`; the issue is source-reproducible, but adding a new public config key needs maintainer direction on scope and precedence.

## What This Changes

The issue requests a per-group `debounceMs` override for WhatsApp, and possibly other channel group configs, so selected chats can batch rapid messages without changing the whole channel/account debounce window.

## Best Possible Solution

Approve a narrow WhatsApp-owned group-level debounce override only if maintainers want the new config contract, then reuse the existing per-item debouncer seam with schema, docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level. Current schema and types reject `channels.whatsapp.groups.<jid>.debounceMs`, and the runtime resolves WhatsApp debounce only from account, default-account, channel, and global inbound scopes.

## Solution Assessment

Unclear until maintainers choose the config contract. The narrowest maintainable path appears to be a WhatsApp-owned per-group override that reuses the existing debouncer seam, not a broad cross-channel rollout in one change.
