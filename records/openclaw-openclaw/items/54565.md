## Summary

Keep open. Current main and v2026.6.11 still lack the requested WhatsApp group-level `debounceMs`; the source gap is clear, but adding a new public config key needs maintainer direction on scope and precedence.

## What This Changes

Allow selected WhatsApp group config blocks, and possibly other channels, to override inbound `debounceMs` so one noisy group can batch messages without delaying every group.

## Best Possible Solution

Have maintainers decide the config contract; if approved, implement a narrow WhatsApp-owned group override through schema/types/docs and the existing per-item debouncer seam, leaving cross-channel rollout separate.

## Reproduction Assessment

Yes, at source level. Current schema and types exclude `channels.whatsapp.groups.<jid>.debounceMs`, and the runtime resolves WhatsApp debounce only from account, default-account, channel, and global inbound scopes.

## Solution Assessment

Unclear until maintainers choose the config contract. The narrowest maintainable path appears to be a WhatsApp-owned per-group override that reuses the existing debouncer seam rather than a broad cross-channel change.
