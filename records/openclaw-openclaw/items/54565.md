## Summary

Keep open. Current main and v2026.6.11 still do not accept or resolve WhatsApp group-level `debounceMs`; the remaining work is real, but adding a new public per-group config key needs maintainer direction on scope and precedence before a fix PR should be queued.

## What This Changes

Request to allow WhatsApp `groups.<jid>.debounceMs`, and possibly similar per-group channel overrides, so specific group chats can batch rapid messages without changing the whole channel or account debounce window.

## Best Possible Solution

Approve a narrow WhatsApp-owned per-group debounce override with explicit precedence, then wire it through the existing per-item debouncer seam with schema/types/docs and focused regression coverage; track any cross-channel rollout separately.

## Reproduction Assessment

Yes, at source level. Current schema and types reject `channels.whatsapp.groups.<jid>.debounceMs`, and the runtime resolves WhatsApp debounce only from account, default-account, channel, and global inbound scopes.

## Solution Assessment

Unclear until maintainers choose the config contract. The likely narrow solution is a WhatsApp-owned per-group override using the existing debouncer seam, not a broad cross-channel rollout in the same change.
