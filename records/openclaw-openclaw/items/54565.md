Keep open. Current main and v2026.6.11 still lack the requested WhatsApp group-level `debounceMs`; the gap is source-reproducible, but adding this public config key needs maintainer direction on scope and precedence.

## What This Changes

Request adding `debounceMs` overrides under WhatsApp per-group config, and possibly other channels, so selected groups can batch rapid messages without raising the whole account or channel debounce.

## Best Possible Solution

Approve a narrow WhatsApp-owned group-level debounce override only if maintainers want the new config contract, then wire it through the existing debouncer seam with focused schema, docs, and regression tests.
