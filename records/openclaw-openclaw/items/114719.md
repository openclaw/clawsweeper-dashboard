## What This Changes

The PR centralizes Codex app-server home-scope selection, rejects API-key routes when a user-scoped native Codex home is signed in with ChatGPT, expands the auth-requirement matrix, and corrects the user-home documentation.

## System Context

The Codex plugin starts an app-server either in an isolated agent home or the operator’s native Codex home. Model routing and stored OpenClaw credentials feed the auth handoff, which must preserve native-home credentials while ensuring the selected route uses a compatible native account.
