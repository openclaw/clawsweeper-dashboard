## What This Changes

Adds a Mac-only subtitle to the sidebar footer identity card that shows the active gateway, health state, and primary status when two or more gateways are configured.

## System Context

The Mac app injects a credential-free snapshot of configured gateways into the Web UI, which renders the dashboard and sidebar. This change reads that snapshot in the persistent sidebar footer so a multi-gateway user can identify the active gateway even when the header picker is out of view.
