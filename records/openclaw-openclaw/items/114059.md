## What This Changes

Adds a Mac-only subtitle to the sidebar footer identity card that shows the viewed gateway’s health, name, and primary status when at least two gateways are configured.

## System Context

The Mac app publishes a credential-free snapshot of configured gateways into the web dashboard and emits an update event when that snapshot changes. The sidebar reads that display-only snapshot to keep the persistent identity footer synchronized with the selected gateway without loading the heavier gateway capability path.
