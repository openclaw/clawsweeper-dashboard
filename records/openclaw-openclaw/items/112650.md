## Label Justifications

- `P1`: A Discord native reply can deliver incorrect or missing context to the agent, producing wrong-context responses in an active channel workflow.
- `impact:session-state`: The defect corrupts the per-turn context associated with an otherwise valid Discord conversation and reply relationship.

## Summary

Keep this issue open while the linked Discord hardening PR is reviewed and landed. The report and an independent guild-channel reproduction both describe the same unsafe invariant—agent context must contain the exact native reply target or no reply quote at all—and the open candidate PR is the active repair path.

## What This Changes

Restore reliable Discord native-reply context so the agent receives the exact referenced message body rather than an absent or unrelated nearby message.

## System Context

Discord inbound events are hydrated before OpenClaw builds the per-turn message context consumed by the agent. A native reply reference must resolve to the canonical Discord message before its text is added to the agent transcript.

## Architecture Diagram

flowchart LR

  B --> C[Reply target hydration]
  C --> D[Canonical target validation]
  D --> E[Agent turn context]
  E --> F[Session transcript and response]

## Best Possible Solution

Land a narrowly scoped Discord hydration fix that verifies the referenced-message ID against the native reply reference, fetches the canonical target when needed, and omits quote text rather than substituting unrelated history when it cannot be resolved.
