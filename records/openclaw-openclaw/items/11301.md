## Summary

Keep open. Current `origin/main` and v2026.6.11 still expose Docker and Podman runtime workspaces at `/home/node/.openclaw/workspace`, while `/workspace` remains a sandbox container path; the direct symlink PR was closed unmerged and no canonical replacement has landed.

## What This Changes

Request runtime container configuration to provide `/workspace` as an alias or symlink to `/home/node/.openclaw/workspace`.

## Best Possible Solution

Maintainers should choose the runtime container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.
