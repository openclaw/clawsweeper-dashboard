## Summary

Keep open. Current main still exposes the runtime Docker and Podman workspace only at `/home/node/.openclaw/workspace`; `/workspace` remains sandbox-specific, and the direct symlink PR was closed unmerged.

## What This Changes

The issue asks for runtime containers to expose `/workspace` as an alias to `/home/node/.openclaw/workspace` so workspace paths match documented agent conventions.

## Best Possible Solution

Maintainers should choose one runtime workspace contract, then either add `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.
