The issue requests adding a `/workspace` alias in container configuration so documented agent workspace paths work without spelling `/home/node/.openclaw/workspace`.

## Best Possible Solution

Maintainers should choose the runtime workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.

Unclear. The requested one-line symlink is plausible prior art, but the best fix needs a maintainer decision on image symlink versus parallel bind mount versus documenting `/workspace` as sandbox-only across all container surfaces.
