Add a supported `/workspace` alias for the canonical OpenClaw workspace path inside Docker/Podman runtime containers.

## Best Possible Solution

Make an explicit maintainer decision: either support `/workspace` as a runtime-container alias consistently across container entry points with focused smoke coverage, or keep it sandbox-only and document that custom agent files must use the canonical runtime path.
