## Summary

Keep open. Current main still exposes the Docker/Podman runtime workspace only at `/home/node/.openclaw/workspace`; `/workspace` remains a sandbox workdir/mount convention, and the direct symlink PR was closed unmerged.

## What This Changes

Request adding a `/workspace` alias or symlink in container runtime configuration so documented workspace paths work inside agent containers.

## Best Possible Solution

Maintainers should choose the runtime container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.
