## Summary

Keep open. Current main and v2026.6.11 still expose Docker/Podman runtime workspaces at `/home/node/.openclaw/workspace` only; the direct symlink PR was closed unmerged, and the remaining choice is a cross-surface container workspace contract.

## What This Changes

The issue requests a runtime-container `/workspace` alias to `/home/node/.openclaw/workspace` so agent documentation paths work inside Docker/Podman containers.

## Best Possible Solution

Maintainers should choose one runtime container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.
