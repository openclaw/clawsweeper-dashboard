Keep open. Current main still exposes Docker and Podman runtime workspaces at `/home/node/.openclaw/workspace`, while `/workspace` remains a sandbox-container convention, so this still needs a maintainer workspace-contract decision.

## What This Changes

Request to expose `/workspace` in OpenClaw runtime containers as a symlink or equivalent alias to `/home/node/.openclaw/workspace`.

## Best Possible Solution

Maintainers should choose one runtime-container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke proof, or document `/workspace` as sandbox-only.
