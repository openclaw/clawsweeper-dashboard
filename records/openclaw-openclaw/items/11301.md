## Summary

Keep open. Current main still lacks a runtime-container `/workspace` alias across Docker Compose, generated Docker setup, Podman, and Quadlet, while `/workspace` remains an intentional sandbox-container path; the direct fix PR was closed unmerged and the open Docker sandbox issue is adjacent rather than a replacement.

## What This Changes

The issue requests exposing the agent workspace at `/workspace` inside containerized OpenClaw runtimes, likely by linking it to `/home/node/.openclaw/workspace`.

## Best Possible Solution

Maintainers should choose the runtime container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.
