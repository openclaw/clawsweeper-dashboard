## Summary

Keep open. Current main and v2026.6.11 still expose Docker/Podman runtime workspaces at `/home/node/.openclaw/workspace` while `/workspace` remains a sandbox-container convention; the earlier direct symlink pull request closed unmerged, so this needs an explicit container workspace contract decision.

## What This Changes

The issue requests a runtime container `/workspace` alias to `/home/node/.openclaw/workspace` so agent/container docs paths work without full absolute paths.

## Best Possible Solution

Maintainers should choose one container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke coverage, or document `/workspace` as sandbox-only.
