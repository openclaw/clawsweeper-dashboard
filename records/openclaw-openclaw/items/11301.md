## Summary

Keep open: current main and v2026.6.11 still expose Docker and Podman runtime container workspaces only at `/home/node/.openclaw/workspace`, while `/workspace` remains a sandbox-container convention and the direct symlink PR was closed unmerged.

## What This Changes

Request to expose the agent workspace inside Docker/Podman runtime containers at `/workspace` instead of only `/home/node/.openclaw/workspace`.

## Best Possible Solution

Maintainers should choose one container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke proof, or document `/workspace` as sandbox-only.
