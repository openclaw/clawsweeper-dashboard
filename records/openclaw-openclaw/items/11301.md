## Summary

Keep open. Current main and v2026.6.11 still expose Docker/Podman runtime workspaces only at `/home/node/.openclaw/workspace`; `/workspace` remains a sandbox convention, and the direct symlink PR was closed unmerged.

## What This Changes

Request to expose the runtime container workspace at `/workspace` so documented agent paths work without using `/home/node/.openclaw/workspace`.

## Best Possible Solution

Maintainers should choose one runtime container workspace contract, then either implement `/workspace` consistently across Dockerfile, Compose, Docker setup, Podman/Quadlet, docs, and smoke proof, or document `/workspace` as sandbox-only.
