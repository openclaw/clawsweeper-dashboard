## What This Changes

The PR validates non-interactive provider and Gateway setup before creating agent state, routes config persistence through the shared wizard writer, and resolves provider environment credentials using the staged workspace configuration.

## System Context

Non-interactive onboarding combines CLI flags with existing configuration to choose a workspace, configure provider authentication, persist configuration, and create the first agent. Its persisted configuration is then used by provider runtime resolution and Gateway startup.
