## What This Changes

Requests a unified settings-page design language and shared Lit/CSS primitives across the Control UI settings and management surfaces.

## Best Possible Solution

Approve a canonical settings anatomy and token contract first, then land shared primitives and migrate one representative settings surface with dark/light, responsive, keyboard, and visual proof before converting the remaining pages in bounded follow-up PRs.
