## Summary

Keep this issue open for maintainer product direction. Current main still contains the reported parallel settings vocabularies, and the existing design-system guidance does not establish a canonical settings composition; the protected maintainer label also rules out automated cleanup.

## What This Changes

Unify Control UI settings and settings-adjacent pages around shared Lit primitives, one stylesheet and spacing scale, and a consistent flat section-row anatomy.

## Best Possible Solution

Approve a canonical settings anatomy and shared primitive boundary, then migrate related page families through bounded screenshot-tested PRs while deleting each superseded class family as its consumers move.

Unclear pending maintainer approval of the canonical anatomy and exceptions. Shared primitives and tokens are the maintainable direction, but the proposed all-surface migration should be delivered as bounded page-family changes rather than one sweeping patch.
