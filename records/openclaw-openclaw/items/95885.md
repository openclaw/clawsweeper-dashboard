## Summary

The fix is coherent and well-proven, with no actionable correctness defect found. It should remain open until an owner accepts the durable retry policy because the chosen hysteresis intentionally permits an oversized post-compaction transcript to remain above its configured threshold for multiple turns.

## What This Changes

The PR persists byte-triggered compaction retry state on session entries and suppresses another byte-triggered preflight compaction for the same active transcript until its file, threshold, or material byte growth changes.

## Best Possible Solution

Land the guard only after owners accept the additive SessionEntry metadata and the 1 MiB/10% material-growth rule as the supported byte-compaction retry policy, retaining the focused regression coverage.
