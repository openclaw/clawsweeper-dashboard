## Summary

Keep open: the underlying bug is still present on current main and in the latest release, but this PR is not merge-ready because the new current-attempt metadata can forget side effects across a compaction retry and then allow an unsafe silent provider-error retry.

## What This Changes

The PR adds optional current-attempt replay metadata to embedded run attempts, uses it to gate silent provider-error retries, includes `server_error` in that retry path, and adds focused regression tests.

## Best Possible Solution

Track current-attempt replay side effects monotonically across compaction retries, use that signal for silent-error retry gating, keep `server_error` coverage, and prove clean-prior, dirty-same-attempt, and dirty-before-compaction cases.
