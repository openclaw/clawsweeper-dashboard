## Summary

Keep open: this PR is a plausible fix for the linked P1 empty-error-retry bug, but the current patch can still treat a compaction-retried outer attempt as side-effect-free after reset-cleared side-effect evidence, so it is not merge-ready.

## What This Changes

The PR adds per-attempt replay metadata to embedded run results, routes `server_error` through empty-error retry, and expands retry safety tests for prior-session versus same-attempt side effects.

## Best Possible Solution

Make current-attempt replay metadata monotonic across compaction retries, including side effects folded into `hadDeterministicSideEffect`, while preserving prior-turn clean retry and the legacy conservative fallback.
