  - body: This change replaces the existing `context_overflow` exemption with `refusal`. On current main, context-window failures return `null` here so transcript-size problems do not cool down or mark shared auth profiles; after this diff they fall through as profile failures, which can block healthy credentials for unrelated sessions. Add `refusal` without deleting `context_overflow` and cover both cases.
  - confidence: 0.94
- **[P1] Preserve upstream and overload result fallback:** `src/agents/embedded-agent-runner/result-fallback-classifier.ts:167`
  - body: The result-payload classifier currently returns `server_error` and `overloaded` for structured `upstream_error` / `overloaded_error` payloads, and `runFallbackAttempt` treats a null classification as candidate success. Removing those cases makes runs whose only output is one of those provider error payloads stop walking the fallback chain, regressing the behavior added for upstream provider failures.
  - confidence: 0.93
