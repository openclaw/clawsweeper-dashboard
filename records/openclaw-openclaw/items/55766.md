## Summary

Keep open: current main still drops ACP tool-result images, and this branch contains a meaningful focused fix, so it is not a cleanup close. ## What This Changes

The PR changes `extractToolCallContent()` to emit ACP image content blocks from tool results and adds focused mapper unit tests for text, image, mixed, malformed, empty, and string fallback cases.

## Best Possible Solution

Normalize both supported current image result shapes at the ACP mapper boundary, converting data URLs to ACP `data`/`mimeType` content where valid, keep the base64 read-tool path covered, and require redacted real ACP client proof before merge.

## Reproduction Assessment
