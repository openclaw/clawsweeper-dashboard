## Summary

Keep this PR open for normal maintainer merge review. The updated patch fixes the permissive `Number()` boundary through one shared helper, preserves standard scientific notation as required by the prior review, and has credible real browser evidence; the remaining consideration is the intentional compatibility change for JavaScript-only numeric spellings.

## What This Changes

The branch centralizes Control UI numeric-string coercion, leaving radix and JavaScript-only spellings as text while continuing to coerce finite decimal and scientific spellings before config submission.

## Best Possible Solution

Land the shared coercion boundary with the explicit contract that finite HTML-style decimal and scientific input becomes numeric, while JavaScript-only spellings remain verbatim for the receiving schema to accept or reject.
