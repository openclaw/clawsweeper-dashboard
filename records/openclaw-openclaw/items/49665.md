## Summary

Current main and shipped releases already cover the reported silent lazy-load blank page: the old app-render-local lazy helper is gone on main, routed panels now surface load errors with retry, and the shipped lazy-view helper records import failures instead of returning a permanent blank view.

## What This Changes

The issue reports that the Control UI Channels page can render blank when a lazy-loaded view import fails silently.

## Best Possible Solution

Keep the current routed error-state implementation and the shipped lazy-view retry behavior; the earlier one-file catch/retry PRs are superseded by the safer visible error panel path.

Yes. The current implementation is better than the suggested direct `.catch()` loop because it records the failure, shows an operator-visible error and Retry control, and avoids immediate automatic retry storms on persistent module failures.
