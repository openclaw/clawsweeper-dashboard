## Summary

Keep open. Current main and the latest release still route empty Telegram native command invocations into the normal `/btw` and `/steer` usage replies; `ForceReply` is only present as a rich-message reply-markup type, not as missing-argument command prompting. This is a valid Telegram UX feature request, but it needs maintainer direction for the command metadata/API shape before a safe repair PR.

## What This Changes

The issue requests a Telegram ForceReply prompt when a Telegram command-menu tap sends an args-requiring command without arguments.

## Best Possible Solution

Define an opt-in command metadata and placeholder contract, then wire Telegram to send ForceReply only for those missing free-text arguments while preserving existing usage replies elsewhere.
