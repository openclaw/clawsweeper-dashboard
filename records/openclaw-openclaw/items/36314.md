## Summary

Keep open. Current main now has a useful main-only crash-loop breaker for repeated unclean Gateway boots, but that is still only a partial slice: the requested built-in watchdog, configurable recovery strategies, operator notification policy, richer health contract, and general degraded startup design are not complete, and related implementation PRs remain open or unmerged.

## What This Changes

The issue requests built-in Gateway robustness mechanisms: a watchdog, global error handling, restart-loop limits, health detail, automatic recovery, and degraded startup behavior.

## Best Possible Solution

Keep this as the Gateway resilience umbrella until maintainers define an opt-in core recovery design, then split implementation into reviewable slices that reuse the existing supervisor, diagnostics, doctor, readiness, and crash-loop breaker paths.
