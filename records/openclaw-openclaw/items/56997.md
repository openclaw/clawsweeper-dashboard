## Summary

Keep this open: current main still has a Sessions table, source/global/unknown filters, channel metadata on rows, and a chat workspace rail, but it does not provide the requested separated channel tabs or merged all-channel timeline toggle. The related sidebar grouping PR is narrower and conflicting, while the broader sessions-workspace issue overlaps but does not replace this channel-view request.

## What This Changes

Add a Control UI mode that lets users switch between separated per-channel session views and a merged all-channel conversation timeline.

## Best Possible Solution

Keep this as the canonical Control UI channel-view thread, define separated-view and merged-timeline semantics first, then reuse existing session row channel metadata and add Gateway/protocol support only where the chosen UX requires it.

## Solution Assessment

Unclear until maintainers choose the UX and data boundary. A separated view over existing session rows is narrower, while a true merged timeline needs explicit cross-session transcript aggregation, privacy, and protocol semantics.
