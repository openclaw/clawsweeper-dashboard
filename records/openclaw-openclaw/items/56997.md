## Summary

Keep open: current main and the latest release still expose session listing plus per-row channel metadata, but not separated channel tabs, a channel view-mode toggle, or a merged all-channel timeline. This remains a product/API decision because merged views affect session-state, privacy, and Gateway protocol semantics.

## What This Changes

The issue requests Control UI modes for viewing channel conversations separately by channel or merged into one unified timeline.

## Best Possible Solution

Keep this as the canonical Control UI channel-view thread, decide separated-tabs versus merged-timeline semantics first, then reuse existing session channel metadata and add Gateway/protocol support only where the chosen UX requires it.
