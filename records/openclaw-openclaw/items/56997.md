## Summary

Keep open: current main now has channel grouping in the Sessions table, but that only buckets session rows and still does not provide separated channel tabs, a separated/merged view-mode toggle, or a unified all-channel transcript timeline. The remaining work is product/API design, and #56997 remains the canonical thread for that channel-view behavior.

## What This Changes

The issue requests a Control UI mode that can toggle between separated per-channel sessions and a merged all-channel conversation timeline.

## Best Possible Solution

Keep this as the canonical channel-view thread, preserve current channel grouping as partial groundwork, and have maintainers choose whether to implement separated session navigation first or design a Gateway-backed merged timeline before UI work.
