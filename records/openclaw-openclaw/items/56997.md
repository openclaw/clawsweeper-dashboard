## Summary

Keep this open: current main still has session listing, per-row channel metadata, and single-session chat navigation, but it does not provide channel-separated tabs, a channel view-mode toggle, or a merged all-channel timeline. The closed related reports point back here, while the open sessions-workspace issue and sidebar grouping PR only partially overlap.

## What This Changes

Add a Control UI mode that can show channel conversations separately and optionally merge all channel conversations into one timeline.

## Best Possible Solution

Keep this as the canonical Control UI channel-view thread, define separated-view and merged-timeline semantics first, then implement the narrowest UI and Gateway contract needed on top of existing session channel metadata.

## Reproduction Assessment

Not applicable: this is a feature request, not a broken existing behavior report. Source inspection gives high confidence that current main has session listing and channel metadata but not the requested separated/merged channel view.

## Solution Assessment

Unclear until maintainers choose the UX and data boundary. A separated view over existing session rows is narrower, while a true merged timeline needs explicit cross-session transcript aggregation, privacy, and protocol semantics.
