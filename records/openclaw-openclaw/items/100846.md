## What This Changes

The PR changes cron edit patch construction so payload edits with `--no-best-effort-deliver` set `delivery.bestEffort=false` without adding `delivery.mode`, updates cron CLI tests, and removes duplicate gateway-protocol type exports.

## Best Possible Solution

Accept explicit-false semantics at the CLI patch boundary, keep `--best-effort-deliver=true` as the only implicit-announce best-effort path, and leave gateway merge semantics unchanged.
