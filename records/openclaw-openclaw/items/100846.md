## What This Changes

The PR narrows cron edit patch construction so `--no-best-effort-deliver` with payload edits sends `delivery.bestEffort=false` without forcing `delivery.mode="announce"`, updates cron CLI tests, and removes duplicate gateway-protocol type re-exports.

## Best Possible Solution

Land the narrow CLI condition and regression tests after maintainer acceptance that the false best-effort flag no longer implies announce mode during payload edits.
