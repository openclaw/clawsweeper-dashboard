## What This Changes

This PR refactors Ask OpenClaw into a reusable Control UI chat surface, adds a dockable right-or-bottom panel that persists its layout, and updates mock-gateway support and tests for the cross-page conversation flow.

## System Context

Ask OpenClaw is the Control UI surface for a system-agent chat session. This change takes gateway chat availability and route transitions into a shared session store, then renders that same conversation either on the Settings page or in a docked workspace panel.
