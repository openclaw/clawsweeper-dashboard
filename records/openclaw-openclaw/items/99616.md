## Summary

Close as ClawHub/plugin scope: this is a new optional privacy dictionary and native config surface, while current main already has provider text-transform, tool-argument, and pre-persistence hook seams that make an external code plugin the right first implementation path.

## What This Changes

The issue requests a native `privacy.entityDictionary` config and bidirectional dictionary replacement before and after LLM provider calls, including tool arguments and memory writes.

## Best Possible Solution

Publish this as a ClawHub code plugin using current text-transform, `before_tool_call`, `tool_result_persist`, and `before_message_write` seams; open a narrow SDK/API issue only if that implementation proves a specific missing hook.
