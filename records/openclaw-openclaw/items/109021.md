## Summary

Keep open: the parse-failure discriminator examines parsed command data, so syntactically valid objects can be mistaken for parser errors, and the claimed node-host behavior has not been demonstrated in a real run.

## What This Changes

The PR catches malformed JSON for four file-transfer node commands, returns a flat `INVALID_PARAMS` response before loading the handler, and adds parameterized unit coverage.

## Best Possible Solution

Return an explicit parser result that keeps status separate from parsed data, unwrap it before dynamic import and dispatch, and demonstrate malformed JSON through a redacted real node-host invocation.
