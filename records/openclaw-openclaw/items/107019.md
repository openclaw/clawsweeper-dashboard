## Summary

The previous containment findings remain valid on the unchanged head: the 100-backtick ceiling contradicts both helpers’ documented longer-than-content invariant, so oversized payloads can escape code formatting even though the tests and terminal transcript show bounded delimiter length.

## What This Changes

The PR caps shared inline-code and fenced-code backtick delimiters at 100 characters and adds regression tests for capped length, large inputs, and normal formatting.

## Best Possible Solution

Keep the exact-content containment invariant, and bound resource use at a named input-size boundary or return a typed oversized-content outcome rather than emitting a delimiter that the payload can close.
