## Summary

Keep this PR open but do not merge the current head. The three previously reported P1 defects remain unchanged: the patch converts detectable canonical transcript corruption into silent event loss, breaks the snapshot event-to-row invariant, and conflates a corrupted identity-backed event with an absent event. The submitted output demonstrates isolated `JSON.parse` behavior but not the real SQLite session workflow or its repair, snapshot, and idempotency consequences.

## What This Changes

The PR catches malformed JSON at three SQLite transcript read sites, skipping malformed list entries and returning no identity result for a malformed matched event.

## Best Possible Solution

Use one explicit transcript-corruption outcome across the accessor: preserve event/row pairing, fail identity-backed reads closed without reporting false absence, surface actionable diagnostics, and provide a Doctor repair or quarantine path with focused tests and live SQLite proof.
