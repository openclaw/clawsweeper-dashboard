## Summary

Keep open: the unchanged head still breaks the helpers’ code-containment invariant. A fixed 100-backtick opener can be terminated by payload content, causing later text to render outside the intended inline span or fenced block.

## What This Changes

The PR caps inline-code and fenced-code Markdown delimiters at 100 backticks and adds long-run regression tests.

## Best Possible Solution

Select an unused inline delimiter length within the bound and a fence character/length that cannot close inside the payload; if no safe bounded delimiter exists, use an explicitly approved reject, sanitize, or non-Markdown fallback path, with parser-backed containment tests.
