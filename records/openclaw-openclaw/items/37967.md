## Summary

Keep open: current main has Feishu group sender/topic session scoping, DM-only dynamic agent creation, and Feishu thread-bound subagent support, but it still does not implement automatic per-sender group subagents with isolated skills, config, memory, and lifecycle.

## What This Changes

Request automatic user-specific Feishu group-chat subagents with isolated memory, skills, configuration, lifecycle, and group reply routing.

## Best Possible Solution

Define an opt-in Feishu-owned group-sender agent mode that composes with groupSessionScope, bindings, subagent APIs, memory/skill policy, lifecycle limits, authorization, audit, docs, and live Feishu proof.
