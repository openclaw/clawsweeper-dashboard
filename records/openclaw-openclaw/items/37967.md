## Summary

Keep open: current main and the latest release have Feishu sender/topic session scopes, DM-only dynamic agents, and lower-level subagent thread bindings, but they do not implement automatic per-sender Feishu group subagents with isolated skills, memory, config, lifecycle, and admin controls.

## What This Changes

The issue requests Feishu group chat routing that dynamically creates and routes per-sender subagents with isolated skills, configuration, memory, lifecycle, and admin controls.

## Best Possible Solution

Define a Feishu-owned isolation design for sender-scoped routing, memory namespace, subagent lifecycle, skill/config policy, cleanup quotas, and admin controls, then implement the approved plugin or SDK seam with live Feishu group proof.
