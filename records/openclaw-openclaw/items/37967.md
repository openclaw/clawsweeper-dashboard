## Summary

Keep open: current main has Feishu per-sender group session scopes and DM-only dynamic agents, but the requested automatic group-sender subagent creation with isolated skills, memory, config, and admin policy remains unimplemented and needs product/security direction.

## What This Changes

Request dynamic Feishu group-chat routing to per-sender subagents with isolated skills, configuration, memory, and admin controls.

## Best Possible Solution

Define an opt-in Feishu plugin-owned group dynamic-agent mode with caps, lifecycle cleanup, sender authorization, memory/tool isolation, docs, and security proof; otherwise document groupSessionScope as the supported session-only alternative.
