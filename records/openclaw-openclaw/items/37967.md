## Summary

Keep open. Current main and the latest tagged release only partially cover this with Feishu group sender/topic session scopes, DM-only dynamic agent creation, and thread-bound subagent session bindings; the requested automatic per-user Feishu group subagents with isolated skills, config, memory, permissions, and lifecycle remains a product/security decision.

## What This Changes

Add Feishu group-chat routing that automatically creates or routes each sender to an isolated subagent with separate workspace, skills/config, memory, and admin-managed lifecycle.

## Best Possible Solution
