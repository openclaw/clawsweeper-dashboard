## Summary

Keep open: current main has Feishu sender/topic session scopes, DM-only dynamic agent creation, and Feishu subagent thread bindings, but it still lacks the requested group-chat per-sender subagent lifecycle with isolated skills, memory, config, admin controls, and cleanup policy.

## What This Changes

The issue requests Feishu group-chat routing that dynamically creates per-sender subagents with isolated skills, configuration, memory, and admin controls.

## Best Possible Solution

Define a Feishu-owned isolation contract for sender/topic routing, shared/private memory namespaces, subagent lifecycle and quotas, skill/config/admin policy, and reply routing before implementing a plugin or SDK seam.
