- `P2`: This is a substantial Feishu group-chat capability and isolation design gap, but it is not a current release-blocking outage for all users.

## Summary

Keep open: current main and v2026.6.11 provide adjacent Feishu group session scoping, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but they do not provide automatic durable group-sender subagents with isolated workspaces, skills, config, memory, lifecycle, quotas, and authorization.

## What This Changes

Request automatic Feishu group-chat routing that creates or reuses one isolated user-specific subagent per sender and relays each sender's group messages through that subagent.

## Best Possible Solution

Define an admin-authorized identity-to-agent lifecycle, quota/TTL, shared/private memory, and per-agent skill/config contract first, then implement opt-in Feishu group-sender provisioning through channel routing seams.
