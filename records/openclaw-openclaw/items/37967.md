## Summary

Keep open: current main and v2026.6.11 support Feishu group sender/topic session scoping, DM-only dynamic agents, and explicit thread-bound subagent bindings, but not automatic Feishu group-sender agent provisioning with isolated workspaces, skills, config, memory, lifecycle, quota, and authorization.

## What This Changes

Request automatic Feishu group-chat subAgents keyed by sender or role, with isolated skills, config, memory, lifecycle controls, and group reply routing.

## Best Possible Solution

Define a maintainer-approved identity-to-agent lifecycle, authorization/quota/cleanup model, and shared/private memory contract first, then implement optional Feishu group-sender provisioning through channel-owned routing and generic agent-binding seams.

## Maintainer Decision

Rationale: The request creates durable agents, workspaces, skills, config, memory, and routing authority from group-chat senders, which cannot be inferred safely from existing DM dynamic agents or thread-bound subagent bindings.

Owner confidence: medium

Options:

- **Design Generic Contract First (recommended):** Define admin-authorized identity-to-agent lifecycle, private/shared memory tiers, quotas, and cleanup as reusable channel/plugin contracts before adding Feishu behavior.
- **Keep Current Supported Paths:** Document groupSessionScope, static bindings, and explicit thread-bound subagents as the supported Feishu group-chat model for now.
- **Route To External Plugin:** Reject automatic provisioning in core and let a Feishu-specific external plugin own durable group identity policy if current plugin seams are sufficient.

## Reproduction Assessment

Yes. Source inspection shows current Feishu group turns can be sender/topic session-scoped, but the dynamic-agent path is gated to non-group direct messages and binds direct peers only.

## Solution Assessment

No. An implicit Feishu-only subagent factory is not yet the best fix; the maintainable path needs a reusable or Feishu-owned lifecycle, authorization, memory, quota, and cleanup contract first.
