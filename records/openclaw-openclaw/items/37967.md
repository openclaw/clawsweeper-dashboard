## Summary

Keep open. Current main and latest release only partially cover this with Feishu group sender/topic session scopes, DM-only dynamic agent creation, and Feishu subagent thread bindings; the requested automatic per-user group subagents with isolated skills, config, memory, and permissions remains a product/security design decision.

## What This Changes

Requests Feishu group-chat routing that creates user-specific subagents with isolated skills, configuration, memory, and replies.

## Best Possible Solution

Decide a Feishu-owned product contract for group sender isolation first, then either extend the existing `groupSessionScope` and subagent binding model or split the remaining work into explicit Feishu plugin, channel SDK, and skill preference issues.
