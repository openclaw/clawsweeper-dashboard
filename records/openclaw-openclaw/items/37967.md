## Summary

Keep open: current main has Feishu group sender/topic session scoping, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but it still does not automatically provision durable per-sender group agents with isolated workspaces, skills/config, memory, lifecycle, quotas, and authorization.

## What This Changes

The issue requests automatic Feishu group-chat per-sender subagents with isolated workspaces, skills, config, memory, lifecycle/admin controls, and orchestrated replies.

## Best Possible Solution

Define a maintainer-approved identity-to-agent lifecycle with authorization, quota/TTL, and shared/private memory contracts first, then implement optional Feishu group-sender provisioning through plugin/channel seams.
