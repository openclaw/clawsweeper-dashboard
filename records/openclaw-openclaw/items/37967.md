## Summary

Keep open: current main and v2026.6.11 support Feishu group sender/topic session scoping, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but they still do not provide automatic durable per-sender group agents with isolated workspaces, skills, config, memory, lifecycle, quotas, and authorization.

## What This Changes

The issue requests Feishu group-chat routing that automatically creates and routes per-user or per-role subagents with isolated skills, configuration, memory, and sessions.

## Best Possible Solution

Define a maintainer-approved identity-to-agent binding plus authorization, quota/lifecycle, and shared/private memory contract first, then implement optional Feishu group-sender provisioning through channel/plugin routing seams.
