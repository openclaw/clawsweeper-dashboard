## Summary

Keep open: current main covers Feishu per-sender group sessions and DM-only dynamic agents, but it does not implement automatic per-user Feishu group subagents with isolated workspaces, skills, config, memory, lifecycle, and admin controls; this is a product/security design decision rather than cleanup-closeable work.

## What This Changes

Request dynamic Feishu group-chat subagents per sender so each user gets isolated memory, skills, configuration, routing, and replies through the main bot.

## Best Possible Solution

Define a maintainer-approved, opt-in Feishu plugin contract for per-sender or per-topic isolation that reuses existing groupSessionScope, dynamic-agent, and session-binding pieces where possible, with explicit lifecycle cleanup, security review, tests, docs, and live Feishu proof before adding automatic group subagents.
