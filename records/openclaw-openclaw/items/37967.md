## Summary

Keep open: current main has Feishu group sender/topic session scoping, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but it still does not provide automatic durable per-sender Feishu group agents with isolated workspace, skills/config, memory, lifecycle, quotas, and authorization.

## What This Changes

Request automatic Feishu group-chat provisioning and routing of per-user or per-role subAgents with isolated sessions, memory, skills, config, and lifecycle controls.

## Best Possible Solution

Define a generic, admin-authorized identity-to-agent lifecycle with shared/private memory, quota, retention, and security contracts, then let Feishu opt into it through channel/plugin seams rather than adding an implicit Feishu-only group factory.
