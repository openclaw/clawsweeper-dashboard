## Summary

Keep open: current main has Feishu group sender/topic session scopes and DM-only dynamic agent creation, but it does not automatically create or route per-sender group subagents with isolated skills, config, and memory; the KinthAI comments add useful prior art for the product design rather than making the core request obsolete.

## What This Changes

Request automatic Feishu group-chat per-user subagents with isolated skills, configuration, memory, lifecycle management, and relay routing through the main bot.

## Best Possible Solution

Define an opt-in Feishu-owned group sender isolation contract that composes existing groupSessionScope, bindings, and dynamic agent creation with explicit lifecycle, security defaults, docs, tests, and live Feishu proof.
