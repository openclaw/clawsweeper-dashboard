## Summary

Keep open: current main has Feishu sender/topic group session scopes, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but it still lacks automatic per-sender Feishu group subagents with isolated skills, config, memory, lifecycle, and admin controls.

## What This Changes

Request automatic Feishu group-chat per-sender subagents with isolated workspace, skills, config, memory/session state, lifecycle controls, and group reply routing.

## Best Possible Solution

Define a maintainer-approved Feishu-owned per-sender group isolation contract first, including session versus agent boundaries, memory/skill/config isolation, admin authorization, lifecycle/quotas, and live Feishu proof requirements.
