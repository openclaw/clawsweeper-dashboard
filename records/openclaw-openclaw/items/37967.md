## Summary

Keep open: current main and the latest release have Feishu group session scopes, DM-only dynamic agent creation, and thread-bound subagent primitives, but not the requested Feishu group per-sender subagent lifecycle with isolated skills, memory, config, admin controls, and cleanup.

## What This Changes

The issue requests automatic Feishu group-chat subagents keyed by sender or role, with per-user skills, configuration, memory, lifecycle management, and reply routing back to the group.

## Best Possible Solution

Define a Feishu-owned isolation design for sender-scoped routing, shared/private memory namespace, subagent lifecycle, skill/config policy, cleanup quotas, and admin controls, then implement the approved plugin or SDK seam with live Feishu group proof.
