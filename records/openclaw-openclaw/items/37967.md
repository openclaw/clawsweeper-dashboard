## Summary

Keep open: current main has partial Feishu per-sender session routing and DM dynamic-agent creation, but it does not implement group-message-driven per-user subagents with isolated skills, config, memory, lifecycle, and admin controls.

## What This Changes

Request dynamic Feishu group-chat routing that creates per-sender subagents with isolated skills, configuration, memory, and replies.

## Best Possible Solution

Design an opt-in Feishu plugin/API contract for per-sender group isolation that reuses groupSessionScope, dynamic-agent provisioning, session binding, quotas, cleanup, and security review instead of spawning ad hoc agents on every group message.
