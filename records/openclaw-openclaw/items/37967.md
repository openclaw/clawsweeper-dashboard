## Summary

## What This Changes

Request automatic Feishu group-chat routing that creates or reuses a per-sender subagent with isolated workspace, skills, config, memory, and replies relayed back through the group.

## Best Possible Solution

Define a Feishu-owned, default-off isolation contract for group sender/topic routing, shared/private memory namespaces, lifecycle/TTL/quota, per-user skill/config/admin policy, and reply routing before implementation.
