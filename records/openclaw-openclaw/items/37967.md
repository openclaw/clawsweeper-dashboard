## Summary

Keep open: current main has Feishu group sender/topic session scoping, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but it still does not automatically provision durable per-sender group agents with isolated workspaces, skills, config, memory, lifecycle, quotas, and authorization.

## What This Changes

Request automatic Feishu group-chat per-sender subagents with isolated skills, configuration, memory/session state, lifecycle management, and replies routed back through the main bot.

## Best Possible Solution

Define a maintainer-approved identity-to-agent binding plus authorization, quota/lifecycle, and shared/private memory contract first, then implement optional Feishu group-sender provisioning through the channel/plugin routing seams.
