## Summary

Keep open: current main and v2026.6.11 cover Feishu group/sender session scoping, DM-only dynamic agent creation, and explicit Feishu DM/topic subagent binding, but they do not implement automatic durable group-sender subAgents with isolated workspaces, skills, config, memory, lifecycle, quotas, and authorization.

## What This Changes

Request automatic Feishu group-message routing to per-sender subAgents with isolated workspace, skills, config, memory, lifecycle, and admin controls.

## Best Possible Solution

Define an explicit opt-in Feishu group per-sender agent model with approved auth, memory namespace, lifecycle, quota, and routing semantics, reusing current groupSessionScope, DM dynamic-agent, and Feishu subagent binding primitives instead of silently spawning agents for every group sender.
