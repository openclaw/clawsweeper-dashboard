## Summary

Keep open: current main has Feishu sender-scoped group sessions and DM-only dynamic agent creation, but it still does not provide the requested opt-in Feishu group mode that creates per-sender agents with isolated workspace, skills, config, memory, lifecycle, and admin controls.

## What This Changes

Request Feishu group chat routing that dynamically creates per-sender subagents with isolated skills, configuration, memory, and group reply routing.

## Best Possible Solution

Define an opt-in Feishu/plugin-owned group dynamic-agent design that reuses existing group_sender/group_topic_sender routing and dynamic-agent machinery, with lifecycle limits, config-write safety, security documentation, migration behavior, and focused Feishu proof before implementation.
