## Summary

Keep open: current main and v2026.6.11 provide Feishu sender-scoped group sessions, DM-only dynamic agents, and topic/direct subagent binding primitives, but not the requested Feishu group-chat per-sender subagent lifecycle with isolated skills, config, memory, admin controls, cleanup, and routing policy.

## What This Changes

Request Feishu group chats to auto-create and route each sender or role to an isolated subagent with its own skills, config, memory, lifecycle, and admin controls.

## Best Possible Solution

Define a Feishu-owned isolation design for sender-scoped routing, memory namespace, subagent lifecycle, skill/config policy, cleanup quotas, and admin controls, then implement the approved plugin or SDK seam with live Feishu proof.
