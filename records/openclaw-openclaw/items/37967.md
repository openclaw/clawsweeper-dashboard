## Summary

Keep open: current main still has Feishu group sender/topic session scoping, DM-only dynamic agent creation, and explicit thread-bound subagent hooks, but not automatic durable per-sender group agents with isolated workspaces, skills, config, memory, lifecycle, quotas, and authorization.

## What This Changes

The issue requests Feishu group-chat routing that creates durable per-sender subagents with isolated skills, config, memory, and lifecycle management.

## Best Possible Solution

Define a maintainer-approved identity-to-agent binding plus authorization, quota/lifecycle, and shared/private memory contract first, then implement optional Feishu group-sender provisioning through the channel/plugin routing seams.
