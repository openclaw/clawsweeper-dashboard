## Summary

Keep open: current main and v2026.6.11 provide adjacent Feishu group session scoping, DM-only dynamic agent creation, and explicit Feishu thread-bound subagent hooks, but not automatic durable group-sender subagents with isolated workspaces, skills, config, memory, lifecycle, quotas, and authorization.

## What This Changes

The issue requests automatic per-sender Feishu group subagents with isolated skills, configuration, memory, workspace, and lifecycle management.

## Best Possible Solution

Define an admin-authorized identity-to-agent lifecycle, quota/TTL, shared/private memory, and per-agent skill/config contract first, then implement opt-in Feishu group-sender provisioning through channel routing seams.
