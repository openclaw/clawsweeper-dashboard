## Summary

Keep open: current main and v2026.6.11 have Feishu per-sender group session scopes, DM-only dynamic agent creation, and Feishu ACP/thread binding, but they do not implement automatic durable Feishu group-sender subAgents with isolated workspaces, skills, config, memory, lifecycle, quotas, and admin controls.

## What This Changes

Request Feishu group chats automatically create and route each sender to an isolated subAgent with its own workspace, skills, config, memory, lifecycle controls, and admin adjustment commands.

## Best Possible Solution

Keep this as a product/security design item and, if approved, implement it inside the Feishu plugin with explicit group sender identity, binding, memory/tool/skill isolation, lifecycle/quota cleanup, migration/docs, and live Feishu proof.
