## Summary

Keep open: current main has Feishu sender/topic-scoped group sessions, DM-only dynamic agent creation, and Feishu subagent conversation binding, but it does not implement automatic per-sender group subagents with isolated skills, config, memory, and lifecycle. The KinthAI comments add useful prior art around sender-keyed sessions, private/shared memory tiers, TTLs, warm pools, and cost governance, so this is product/security design work rather than cleanup closure.

## What This Changes

Request Feishu group-chat support for dynamically creating and routing per-sender subagents with isolated skills, config, memory, and lifecycle.

## Best Possible Solution

Design an opt-in Feishu-owned group-sender agent mode that composes with groupSessionScope, dynamicAgentCreation, and subagent bindings, with explicit memory visibility, authorization, lifecycle limits, docs, tests, and live Feishu proof.
