## Summary

Keep open: current main partially supports Feishu sender-scoped group sessions and subagent delivery bindings, but it does not implement automatic per-sender group-chat subagents with isolated skills, config, memory, lifecycle, and admin controls.

## What This Changes

The issue requests Feishu group chat routing that dynamically creates per-sender subagents with isolated skills, configuration, and conversation memory.

## Best Possible Solution

Keep the existing plugin-owned Feishu sender-session and subagent-binding support, then design any automatic group per-user subagent lifecycle as an explicit Feishu/plugin feature with security review, lifecycle limits, config defaults, docs, and live Feishu proof.
