## Summary

Keep open: current main still has Feishu group sender/topic session scopes, DM-only dynamic agent creation, and explicit Feishu subagent thread binding, but it does not implement automatic per-sender group subagents with isolated skills, config, memory, and lifecycle.

## What This Changes

The issue requests Feishu group chat routing that creates per-sender subagents with isolated skills, configuration, memory, and lifecycle management.

## Best Possible Solution

Define an opt-in Feishu-owned group-sender agent mode that composes with existing groupSessionScope, bindings, and subagent APIs, with lifecycle limits, memory visibility, authorization, audit, docs, and tests before implementation.
