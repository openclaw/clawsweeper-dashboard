- **[P1] Wait for Gradium finalization before committing transcripts:** `extensions/gradium/realtime-transcription-provider.ts:152`
  - body: The provider calls `onTranscript` for every Gradium `text` event, but Voice Call treats `onTranscript` as a final committed user turn.   - confidence: 0.9

  - body: `isConfigured` returns true from `GRADIUM_API_KEY` alone. Because Voice Call can auto-select the first configured realtime transcription provider when `streaming.provider` is unset, existing Gradium TTS users with streaming enabled can start routing live call audio to Gradium without selecting Gradium STT or adding STT provider config.
  - confidence: 0.9
- **[P2] Remove the hidden Gradium endpoint fallback:** `extensions/gradium/realtime-transcription-provider.ts:93-94`
  - body: `GRADIUM_BASE_URL` is not declared in the Gradium manifest or STT docs, but this fallback can change the WebSocket origin for live audio and the `x-api-key` header. Keep endpoint override in explicit provider config, or deliberately declare, document, and test the env surface.
  - confidence: 0.88
- **[P3] Update the generated Gradium plugin reference:** `extensions/gradium/openclaw.plugin.json:11`
  - body: The manifest now declares `realtimeTranscriptionProviders`, but the generated plugin reference and inventory on current main still describe Gradium as text-to-speech only. Regenerate or update the plugin inventory docs so public reference docs match discovery metadata.
  - confidence: 0.82
