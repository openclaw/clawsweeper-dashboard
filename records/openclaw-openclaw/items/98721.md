- **[P2] Preserve under-cap node follow-up output:** `src/agents/bash-tools.exec-host-node.ts:435`
  - body: This changes the old `combined.slice(-DEFAULT_NOTIFY_TAIL_CHARS)` semantics for outputs below the cap. For example, with a 399-code-unit combined output and the 400-character cap, `combined.length - DEFAULT_NOTIFY_TAIL_CHARS` is `-1`; `sliceUtf16Safe` treats that as a relative start and returns only the final code unit, so the follow-up drops almost all output that current main would send in full. Use `sliceUtf16Safe(combined, -DEFAULT_NOTIFY_TAIL_CHARS)` or keep the same under-cap guard used by `tail()` before calling the helper.
  - confidence: 0.98
