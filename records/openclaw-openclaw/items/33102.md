## What This Changes

The issue requests an OpenClaw config option that sets the default value for `openclaw tui --deliver` so users do not need to pass the flag on every TUI launch.

## Best Possible Solution

Decide one persistent TUI delivery-default contract; if approved, add it through the canonical config type, zod schema, help/docs, and focused tests while preserving explicit CLI flag precedence.
