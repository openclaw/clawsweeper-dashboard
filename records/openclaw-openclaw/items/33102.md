## Summary

Keep open: current main and the latest release still lack a persistent config default for TUI delivery. The adjacent stuck-spinner/abort path was fixed separately, but the requested `--deliver` default remains a product/config-surface decision.

## What This Changes

The issue requests a persistent OpenClaw config setting that can supply the default for `openclaw tui --deliver`.

## Best Possible Solution

If maintainers accept the new preference, add one canonical `tui.deliver` config field with schema/types/docs and focused TUI CLI tests that preserve explicit flag precedence; otherwise keep the explicit flag-only contract.
