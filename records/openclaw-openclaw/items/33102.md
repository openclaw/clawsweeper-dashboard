## Best Possible Solution

Decide the intended product contract for persistent TUI delivery defaults; if approved, add one canonical config/schema/docs/test path for `tui.deliver` while preserving explicit CLI and `/deliver` overrides.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers choose the product direction: `tui.deliver` is a plausible narrow fix, but OpenClaw's config bar is high and current docs frame delivery as an explicit runtime/flag setting.
