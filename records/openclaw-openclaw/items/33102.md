## What This Changes

Add a persistent OpenClaw config default for `openclaw tui --deliver` so users do not need to pass the flag on every launch.

## Best Possible Solution

Have a maintainer choose one persistent TUI delivery-default contract; if approved, implement it through the canonical config type, schema, help/docs, CLI precedence, and focused tests while preserving explicit flag overrides.
