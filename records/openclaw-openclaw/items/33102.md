## Summary

Keep open: current main and the latest release still lack a persistent config default for TUI delivery. The adjacent stuck-spinner/abort work was fixed separately, but this request remains a product/config-surface decision.

## What This Changes

Request adding an `openclaw.json` config option that sets the default for `openclaw tui --deliver` so users do not need to pass the flag every launch.

## Best Possible Solution

If maintainers accept the preference, add one canonical `tui.deliver` boolean with schema/types/help/docs and focused tests that preserve explicit CLI flag precedence; otherwise keep the documented flag-only contract.
