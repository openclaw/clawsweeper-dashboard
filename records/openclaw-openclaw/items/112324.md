## What This Changes

This PR adds a browser gateway watchdog that recycles a WebSocket after prolonged inbound silence while an unbounded Control UI request is pending, and makes the Control UI E2E mock emit the keepalive policy it advertises.

## System Context

Control UI sends requests through `GatewayBrowserClient`, which delegates pending-request handling to the gateway protocol client over a WebSocket. Gateway `hello-ok` policy and subsequent inbound frames establish liveness; on a dead transport, the browser client should reject stranded work so its reconnect supervisor can restore the session.
