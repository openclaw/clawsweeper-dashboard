## What This Changes

Adds a browser-side Gateway tick watchdog so an unbounded Control UI request is rejected and reconnects when the Gateway connection goes silent beyond its advertised tick interval.

## System Context

The Control UI sends requests through GatewayBrowserClient, which delegates request tracking to the shared gateway protocol client over a browser WebSocket. A successful Gateway hello supplies liveness policy; this change uses that policy to close a silent transport so the existing reconnect path can recover pending UI work.
