## What This Changes

The branch changes the shared agent tool-result classifier so a result explicitly marked `completed` remains nonfatal even when it carries a nonzero exit code, and adds regression coverage for completed, failed, and statusless outcomes.

## System Context

The exec runtime emits structured terminal details for agent tools; a shared classifier converts those details into error state. That error state feeds embedded-agent warning payloads and isolated cron diagnostics/outcomes, which then affect channel messages and scheduled delivery handling.
