## What This Changes

This PR retains a configured provider request timeout after a provider plugin rebuilds the resolved model or transport, with regression coverage for first-event and idle stream watchdogs.

## System Context

Provider configuration is converted into a request timeout while OpenClaw resolves a model for an agent run. Provider hooks can replace that model before the stream watchdogs consume its timeout, so the final normalized model determines whether slow streams receive the configured ceiling.
