## What This Changes

This PR restores a configured provider timeout after model- or transport-normalization hooks rebuild the resolved model, while preserving an explicit timeout supplied by the plugin.

## System Context

Agent model resolution converts provider configuration into a prepared runtime model before provider hooks can normalize its model or transport. First-event and idle watchdogs then use the final model’s request timeout to bound streamed responses.
