## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Reject headless build stamps before restarting:** `scripts/watch-node.mjs:109`
  - body: `run-node` treats a build stamp without `head` as stale whenever Git HEAD is available, but this helper only rejects mismatches when both values exist. A source checkout with an older headless stamp can still pass the guard, SIGTERM the healthy gateway, and rebuild after the stop.
  - confidence: 0.9
- **[P2] Trigger the deferred restart when output becomes ready:** `scripts/watch-node.mjs:554-560`
  - body: When the guard returns false, `requestRestart()` only logs and returns. Since `dist` is ignored by the watcher, a rebuild completing under `dist/` will not necessarily emit another relevant event, leaving the old child running indefinitely after a checkout update.
  - confidence: 0.84
- **[P3] Format the helper so required script lint passes:** `scripts/watch-node.mjs:94-109`
  - body: The merge-ref `check-lint` job fails on the new helper with `no-shadow` for the `fs` parameter and missing-curly errors on the one-line `if` statements. Rename the parameter and add braces so the required script lint lane can pass.
  - confidence: 0.95
