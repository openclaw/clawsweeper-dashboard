## What This Changes

The PR caches lazily loaded plugin HTTP and WebSocket handlers so later Gateway requests bypass wrapper-level route-presence checks while the handlers continue to resolve the active plugin route registry.

## System Context

The Gateway receives plugin HTTP requests and WebSocket upgrades through lazy wrappers that avoid importing plugin routing code when no plugin routes exist. Once loaded, the routing handlers consult the active registry to choose a current route and return an HTTP response or upgrade result.
