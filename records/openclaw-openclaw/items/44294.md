## Summary

Keep open: current main and the latest release still map non-refusal ACP backend error kinds to normal `end_turn`, while https://github.com/openclaw/openclaw/pull/91603 remains the open implementation candidate and needs maintainer contract review.

## What This Changes

The issue asks the ACP translator to preserve structured Gateway backend error kinds so clients can distinguish refusals, context-length failures, timeouts, rate limits, and server errors from normal turn completion.

## Best Possible Solution

Keep this issue open behind https://github.com/openclaw/openclaw/pull/91603 or a replacement that chooses the ACP prompt error contract, preserves structured backend failure data, and proves the behavior with focused tests plus real ACP evidence.
