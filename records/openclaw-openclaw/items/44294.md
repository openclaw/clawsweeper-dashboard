## Summary

Keep open: current main and the latest release still collapse non-refusal ACP backend error kinds into normal `end_turn` completion, while the open linked PR is the active candidate fix and still needs maintainer contract review.

## What This Changes

The issue asks OpenClaw to preserve structured ACP backend error classes such as refusal, timeout, rate limit, context length, and server error instead of mapping most ACP error events to `end_turn`.

## Best Possible Solution

Review, land, or replace https://github.com/openclaw/openclaw/pull/91603 after maintainers choose the ACP prompt error contract and require focused tests plus real ACP proof.
