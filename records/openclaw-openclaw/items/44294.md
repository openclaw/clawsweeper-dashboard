## Summary

Keep open: current main and v2026.6.11 still map non-refusal ACP backend error kinds such as `timeout` and `unknown` to normal `end_turn`; the linked closing PR is open and remains the candidate implementation path rather than merged behavior.

## What This Changes

Request structured ACP backend error-kind preservation so clients can distinguish refusals, timeouts, rate limits, server errors, and normal end-of-turn completion.

## Best Possible Solution

Keep this issue open behind https://github.com/openclaw/openclaw/pull/91603 or a refreshed replacement that settles the ACP error contract, preserves structured backend error information, and updates focused tests.
