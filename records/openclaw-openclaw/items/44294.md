Keep open: current main and the latest release still map non-refusal ACP backend error kinds to `end_turn`, and the open linked PR remains the implementation candidate rather than a merged fix.

## What This Changes

The issue asks OpenClaw to preserve structured ACP backend error classes so clients can distinguish failures such as timeouts, rate limits, refusals, and server errors from normal turn completion.

## Best Possible Solution

Keep this issue open behind the linked PR or a replacement that chooses the ACP prompt error contract, preserves structured backend failure data, and proves the behavior with focused tests plus real ACP evidence.
