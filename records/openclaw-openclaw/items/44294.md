## Summary

Keep open: current main and the latest release still collapse non-refusal ACP backend error kinds to normal `end_turn` completion, and the open linked implementation candidate still needs maintainer contract review before this issue can close.

## What This Changes

The issue asks OpenClaw to preserve structured ACP backend error classes so clients can distinguish failures such as timeout, rate limit, context length, server error, and refusal from normal end-of-turn completion.

## Best Possible Solution

Review, land, or replace https://github.com/openclaw/openclaw/pull/91603 after maintainers choose the ACP prompt error contract and require focused tests plus real ACP behavior proof.
