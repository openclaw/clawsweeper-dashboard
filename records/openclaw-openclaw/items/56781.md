## Summary

Keep open. Current main and the latest release still lack a public `agents.defaults.compaction.fallbacks` field, explicit `agents.defaults.compaction.model` remains exact, and the Lossless `summaryModel` fallback half still needs a plugin/context-engine boundary decision.

## What This Changes

The issue requests optional fallback model arrays for core compaction and Lossless/LCM summary-model generation when the primary summarizer is unavailable.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
