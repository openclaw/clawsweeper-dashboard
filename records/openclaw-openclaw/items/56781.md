## Summary

Keep open. Current main and v2026.6.11 still lack a public compaction fallback config field, explicit `agents.defaults.compaction.model` remains exact, and the Lossless/LCM `summaryModel` fallback half still needs a product/ownership decision rather than cleanup closure.

## What This Changes

Request an optional fallback model chain for OpenClaw compaction and Lossless/LCM summary-model generation when the primary summarizer is rate-limited, unavailable, or times out.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while keeping Lossless summary fallback in the Lossless plugin or adding a generic context-engine SDK seam only if that gap is proven.
