## Summary

Keep open. Current main has fallback retry support only when compaction uses the active session model path; it still has no public `agents.defaults.compaction.fallbacks` or Lossless/LCM `summaryModel` fallback surface, and the related implementation PRs are closed unmerged or partial.

## What This Changes

The issue requests optional ordered fallback model arrays for embedded compaction and Lossless/LCM summary-model configuration, using agent model failover-like semantics.

## Best Possible Solution

Have maintainers define a narrow public fallback contract first; if approved, add embedded compaction fallback config in core with schema, docs, model-ref collection, doctor/diagnostic behavior, and focused tests, while keeping Lossless summary fallback in the plugin or a generic context-engine SDK seam if that seam is missing.
