## Summary

Keep open. Current main only covers implicit compaction through the session model fallback chain; the requested public `agents.defaults.compaction.fallbacks` surface is still absent, explicit `compaction.model` remains exact, and the Lossless `summaryModel` fallback half remains plugin/context-engine owned with no merged implementation.

## What This Changes

Request an ordered fallback model chain for explicit compaction summarization and Lossless/LCM `summaryModel` summaries.

## Best Possible Solution

Have maintainers define the public fallback contract, implement embedded compaction in core if approved, and keep Lossless `summaryModel` fallback in the Lossless/context-engine plugin or a generic Plugin SDK seam if that seam is missing.

## Reproduction Assessment

Yes for the source-level gap: current main lacks the requested fallback fields, and explicit compaction models bypass the fallback wrapper. A live 429/timeout repro is not required to show that the requested capability is missing.

## Solution Assessment

Unclear. An explicit fallback list is plausible for embedded compaction, but the Lossless half crosses plugin/context-engine ownership and needs maintainer API direction before a repair PR should choose the contract.
