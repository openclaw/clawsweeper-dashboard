- `impact:session-state`: The request is about preserving usable session/context state when compaction or summary generation cannot use the primary model.

## Summary

Keep open. Current main and v2026.6.11 still expose only an exact single `agents.defaults.compaction.model`, and no public `agents.defaults.compaction.fallbacks` or Lossless `summaryModel` fallback field exists; the remaining work crosses core config, provider/auth routing, and plugin/context-engine ownership.

## What This Changes

Add public fallback chains for embedded compaction and Lossless/LCM `summaryModel` so summarization can retry alternate models after primary failures.

## Best Possible Solution

Define the public fallback semantics first, then implement embedded compaction in core if approved while routing Lossless summary fallback to the Lossless plugin or a generic context-engine SDK seam with docs, model-ref collection, doctor, and provider/auth regression coverage.
