## Summary

Keep open. Current main and the latest release still lack the requested public fallback surfaces: explicit embedded compaction models remain exact, `agents.defaults.compaction.fallbacks` is not in the schema, and Lossless is still exposed as a plugin/context-engine `summaryModel` without a fallback chain; the related PRs are closed unmerged or only cover part of the request.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless/LCM summary generation when the primary summarization model is unavailable.

## Best Possible Solution

Have maintainers decide the public fallback contract, implement embedded compaction in core only if that contract is approved, and keep Lossless `summaryModel` fallback in the Lossless/context-engine plugin or a generic plugin SDK seam if current seams are insufficient.
