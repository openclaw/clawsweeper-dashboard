## Summary

Keep open. Current main still lacks the requested public fallback surfaces for explicit compaction models and Lossless/context-engine `summaryModel`; the only implemented fallback path applies when no explicit `agents.defaults.compaction.model` is set, and related implementation attempts are closed unmerged or intentionally partial.

## What This Changes

Add fallback model chains for embedded compaction and Lossless/context-engine summaries so failed summarization can retry configured models before degrading.

## Best Possible Solution

Define one product contract first: add embedded compaction fallback support in core only if maintainers approve that public config surface, and keep Lossless `summaryModel` fallback plugin-owned unless a generic context-engine SDK seam is needed.
