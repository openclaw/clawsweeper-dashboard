## Summary

Keep open. Current main and the latest release still lack the requested public `agents.defaults.compaction.fallbacks` and Lossless/LCM summary-model fallback surfaces, and the remaining work crosses core config, provider/auth routing, and context-engine plugin ownership.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless/LCM `summaryModel` summarization when the primary summarizer is unavailable or rate-limited.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
