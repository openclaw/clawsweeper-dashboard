## Summary

Keep open. Current main and v2026.6.11 still lack the requested explicit `agents.defaults.compaction.fallbacks` and Lossless `summaryModel` fallback surfaces; existing code only uses the session model fallback chain when no explicit compaction model is configured.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless/LCM summary-model generation.

## Best Possible Solution

Define the fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
