## Summary

Keep open. Current main and v2026.6.11 still lack `agents.defaults.compaction.fallbacks`, and explicit `compaction.model` remains exact; Lossless now has an external plugin-owned `fallbackProviders` surface, so the remaining OpenClaw work is a product/API direction decision rather than cleanup-closeable.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless LCM summary-model calls.

## Best Possible Solution

Define the public fallback contract first, then implement only the approved embedded compaction surface in core while leaving Lossless fallback behavior to its plugin contract unless a missing SDK seam is proven.
