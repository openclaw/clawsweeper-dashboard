## Summary

Keep open. Current main and the latest release still lack a public `agents.defaults.compaction.fallbacks` field, explicit `compaction.model` remains exact, and the Lossless `summaryModel` fallback half still needs a plugin/context-engine ownership decision.

## What This Changes

Request adds ordered fallback model chains for core compaction and Lossless/LCM `summaryModel` when the primary summarizer is rate-limited, unavailable, or times out.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
