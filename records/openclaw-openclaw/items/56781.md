## Summary

Keep open: current main and the latest checked release still expose only a single exact embedded compaction model and no public fallback chain for embedded compaction or Lossless/context-engine summary models; prior PRs were closed unmerged or intentionally left this issue open.

## What This Changes

The issue requests ordered fallback model configuration for embedded compaction and Lossless/LCM `summaryModel` behavior when the primary summarizer fails.

## Best Possible Solution

Define the public fallback contract first: embedded compaction can add an opt-in core config surface, while Lossless/context-engine fallback should live in the owning plugin or a generic SDK seam if the current plugin API is insufficient.
