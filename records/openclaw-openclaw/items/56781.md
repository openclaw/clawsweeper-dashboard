## Summary

Keep open: current main still lacks the requested public fallback surfaces for explicit compaction models and Lossless/LCM summary models, and the related implementation attempts are closed partial overlaps rather than a merged canonical fix.

## What This Changes

Request adds ordered fallback model chains for embedded compaction and Lossless/LCM `summaryModel` so summarization can retry on retryable provider failures.

## Best Possible Solution

Maintainers should decide one public fallback contract, implement embedded compaction in core only if approved, and keep Lossless fallback behavior in the Lossless/context-engine plugin or a generic SDK seam if that seam is missing.
