## Summary

Keep open. Current main still lacks the requested public `agents.defaults.compaction.fallbacks` field, explicit `compaction.model` remains an exact single-model override, and the Lossless/context-engine `summaryModel` fallback half is still a product/API ownership decision rather than implemented behavior.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless/LCM `summaryModel` summarization.

## Best Possible Solution

Decide the public fallback contract first, then implement embedded compaction in core only if approved while routing Lossless `summaryModel` fallback to the Lossless plugin or a generic context-engine SDK seam if core lacks one.
