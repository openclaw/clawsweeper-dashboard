## Summary

Keep open. Current main and the latest release still lack the requested public `agents.defaults.compaction.fallbacks` field, explicit `compaction.model` remains exact, and Lossless `summaryModel` fallback is still plugin/context-engine-owned rather than implemented in core.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless/LCM summary models.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
