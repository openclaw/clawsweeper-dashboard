## Summary

Keep open. Current main and the latest release still lack `agents.defaults.compaction.fallbacks`, explicit `compaction.model` still bypasses fallback routing, and the Lossless `summaryModel` fallback half remains a plugin/context-engine ownership decision rather than an implemented core feature.

## What This Changes

Request adds ordered fallback model chains for embedded compaction and Lossless/LCM summary-model compaction.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
