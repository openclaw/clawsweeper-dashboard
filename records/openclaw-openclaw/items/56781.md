## Summary

Keep open. Current main still lacks the requested public `agents.defaults.compaction.fallbacks` field and keeps explicit `compaction.model` exact, while the Lossless `summaryModel` fallback remains a plugin/context-engine boundary decision rather than implemented behavior.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and the Lossless/LCM summary model when the primary summarizer is unavailable.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
