- `impact:session-state`: The report concerns failed compaction summaries causing long sessions to keep growing or degrade to truncate-only behavior.

## Summary

Keep open. Current main and the latest release still lack the requested public fallback-chain config for explicit compaction models and Lossless `summaryModel`, and current tests intentionally preserve exact `compaction.model` behavior without inheriting the session fallback chain.

## What This Changes

Request adds opt-in fallback model chains for embedded compaction and Lossless/LCM summary model summarization when the primary model is rate-limited, unavailable, or times out.

## Best Possible Solution

Define one canonical opt-in fallback contract, then either implement `agents.defaults.compaction.fallbacks` with focused runtime/config/docs/tests and split Lossless `summaryModel` fallback to the plugin owner, or explicitly approve a shared plugin/runtime API for both.
