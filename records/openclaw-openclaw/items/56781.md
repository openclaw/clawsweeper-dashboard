## Summary

Keep open. Current main and the latest release still lack a public `agents.defaults.compaction.fallbacks` field and still keep explicit `compaction.model` exact, while the Lossless `summaryModel` fallback remains plugin/context-engine owned and unimplemented in this repo.

## What This Changes

The issue requests ordered fallback model chains for embedded compaction and Lossless/LCM summary-model compaction when the primary summarizer fails.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
