## Summary

Keep open. Current main and the latest release still lack the requested public fallback chain for explicit compaction models, and Lossless/LCM `summaryModel` fallback remains a plugin/context-engine product-boundary decision rather than implemented core behavior.

## What This Changes

Request to add ordered fallback model chains for `agents.defaults.compaction.model` and Lossless/LCM `summaryModel` so summarization can retry another provider/model on retryable failures.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core if approved while routing Lossless `summaryModel` fallback to the Lossless plugin or a generic context-engine SDK seam.
