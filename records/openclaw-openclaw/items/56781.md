## Summary

Keep open. Current main and v2026.6.11 still expose only exact `agents.defaults.compaction.model`; tests and docs preserve that behavior, related PRs are closed unmerged, and the Lossless `summaryModel` fallback remains a plugin/context-engine boundary question.

## What This Changes

Request optional ordered fallback chains for embedded compaction and the Lossless/LCM summary model when the primary summarizer model is unavailable, rate-limited, or times out.

## Best Possible Solution

Define the public fallback contract and owner boundary first, then implement embedded compaction in core if approved while routing Lossless summary-model fallback to the Lossless plugin or a generic context-engine SDK seam.
