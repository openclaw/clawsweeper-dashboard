## Summary

Keep open. Current main and the latest release still lack the requested public compaction fallback config, and the Lossless `summaryModel` fallback remains a plugin/context-engine boundary that needs maintainer product/API direction.

## What This Changes

Request adds ordered fallback model chains for embedded compaction and Lossless/LCM `summaryModel` when the primary summarizer model is unavailable.

## Best Possible Solution

Define the public fallback contract first, then implement embedded compaction in core only if accepted while routing Lossless summary fallback to the Lossless plugin or a generic context-engine SDK seam.
