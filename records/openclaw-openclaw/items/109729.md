## Summary

## What This Changes

The PR catches URL-constructor failures in the public plugin-SDK SSRF helper, converts them to a generic application error, and adds a malformed-input regression test.

## Best Possible Solution

Catch the URL parse failure but throw a stable non-sensitive message such as `Invalid URL`, optionally retaining the native exception as `cause`, and add coverage proving secret-like malformed input is not reflected.
