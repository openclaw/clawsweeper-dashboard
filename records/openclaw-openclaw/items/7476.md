## Summary

Keep open: current main and v2026.6.11 still lack a user-facing outbound WhatsApp sticker-send path; the code has only a lower-level `sendSticker` helper for structured runtime/QA use, and the related implementation PRs are closed unmerged.

## What This Changes

Request outbound WhatsApp sticker support, either through a dedicated sticker action, explicit send option, or safe WebP sticker detection.

## Best Possible Solution

Add first-class WhatsApp plugin sticker sending with explicit user-facing sticker intent, scoped media preservation or encoding, Baileys `{ sticker: buffer }` routing, docs, and focused tests for action discovery and payload selection.
