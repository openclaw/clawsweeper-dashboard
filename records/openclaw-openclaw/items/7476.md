## Summary

Keep open: current main and the latest release still lack a public outbound WhatsApp sticker-send path; the low-level helper can emit a sticker payload, but normal WebP sends, action discovery, and docs still do not expose sticker sending.

## What This Changes

The issue requests outbound WhatsApp sticker sending support instead of treating qualifying WebP files as regular image attachments.

## Best Possible Solution

Add first-class WhatsApp plugin sticker sending with explicit user-facing sticker intent, scoped media preservation or encoding, Baileys sticker payload routing, focused docs, and tests for action dispatch plus payload selection.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Which public WhatsApp sticker-send contract and sticker asset policy should OpenClaw support before implementation?

Rationale: The source gap is clear, but choosing between `action=sticker`, an `asSticker` option, automatic WebP detection, and optional re-encoding affects user-visible behavior and compatibility for normal WebP image sends.

Likely owner: mcaxtr

Owner reason: mcaxtr has the strongest recent history on the structured WhatsApp send helper that already emits a sticker payload.

Owner confidence: high

Options:

- **Use Explicit Sticker Intent (recommended):** Expose `action=sticker` or a WhatsApp send option and route media as stickers only when that intent is present.
- **Use WebP Heuristics:** Treat qualifying WebP media as stickers automatically, accepting misclassification and encoding-policy risk for ordinary WebP images.
- **Defer Until Cross-Channel Contract:** Keep the low-level helper and inbound sticker handling while waiting for a broader sticker contract across message channels.

## Reproduction Assessment

Yes, at source level: current main still routes normal `image/*` sends through the generic image branch and the active listener/action contracts do not expose a public sticker send path. I did not run a live WhatsApp send in this read-only review.

## Solution Assessment

Unclear until maintainers choose the public contract. The implementation belongs in the WhatsApp plugin, and explicit sticker intent plus scoped media handling is safer than silent WebP heuristics alone.
