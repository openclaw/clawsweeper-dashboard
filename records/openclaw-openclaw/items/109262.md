## Summary

## What This Changes

This PR replaces Node readline scanning in the Docker E2E resource-ceiling checker with a 1 MiB UTF-8 sample-line limit and adds delimiter and boundary regression tests.

## Best Possible Solution

Add a byte-cap facility to the shared incremental line-reader abstraction, consume it from the Docker resource checker, retain focused UTF-8 and delimiter boundary tests, and demonstrate one redacted live Docker stats run showing both accepted normal samples and prompt oversized-line rejection.
