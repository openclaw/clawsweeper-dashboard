- **[P3] Exclude the CRLF delimiter from the line-size cap:** `scripts/e2e/lib/docker-stats/assert-resource-ceiling.mjs:103`
  - body: The size check runs while a terminal `\r` is still in `pending`, and only strips it afterward in `emitPendingLine`. Strip or account for the terminal carriage return before the limit check and add an exact-cap CRLF case.
