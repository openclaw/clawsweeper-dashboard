## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.96

Full review comments:

- **[P1] Bypass command parsing for widget prompts:** `ui/src/pages/chat/chat-pane.ts:1564`
  - body: Passing accepted widget text to `handleSendChat` keeps command recognition enabled. During an abortable run, a widget can send `stop`, `abort`, `wait`, `exit`, or `esc` and abort it even though this bridge promises conversational text only; inline directives and enabled `!` host commands also fall outside the leading-slash check. Route widget prompts through a command-disabled send API rather than attempting a partial denylist. ([docs.openclaw.ai](https://docs.openclaw.ai/tools/slash-commands))
  - confidence: 0.98
