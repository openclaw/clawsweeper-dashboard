## Summary

The branch still contains meaningful unique work, but it is not merge-ready: the model-facing lazy descriptor remains stale, one user activation can authorize a multi-prompt burst, and the supplied live check bypasses the actual click-to-send bridge.

## What This Changes

The PR adds a sandboxed Canvas `sendPrompt(text)` bridge, host-side prompt validation and chat dispatch, regression tests, and updated `show_widget` documentation.

## Best Possible Solution

Bind each accepted prompt to one non-replayable trusted interaction, synchronize the registered lazy `show_widget` descriptor with focused descriptor coverage, then record a real hosted-widget button click producing one normal user message and agent reply.
