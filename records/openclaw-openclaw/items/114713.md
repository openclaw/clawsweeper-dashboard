## What This Changes

The PR updates npm plugin reinstall and update persistence so an exact explicit load path for the previous managed install root is replaced with the new managed root.

## System Context

The plugin installer keeps an npm install record and persists plugin configuration, while plugin discovery gives explicit `plugins.load.paths` entries precedence. A replacement install must update both the managed install record and any exact matching managed load path before the registry refresh selects the active plugin.
