The underlying bug is not already fixed on current `main`, so the contribution remains useful.

**Likely related people**
- @steipete — high confidence; introduced the yielded-subagent pause behavior and recently changed the central agent, cron task-ledger, and Discord lifecycle paths.

## What This Changes

The PR adds shared yielded-parent lifecycle classification, a public `deferred` cron status, descendant wake handling, and Discord progress preservation across runtime, protocol, CLI, UI, plugin SDK, tests, and docs.

## Best Possible Solution

Keep yielded handoff nonterminal in the task ledger, give descendant reconciliation one owner that publishes the eventual terminal cron outcome, and have Discord settlement explicitly finalize or clear the preserved parent progress; expose `deferred` publicly only if maintainers intentionally accept and document that contract.
