  - body: `resolveBundledNodePath` only checks `resolveGatewayStateDir(...)/tools`, but documented local-prefix installs store managed Node under `<prefix>/tools/node-v...` and support custom prefixes.   - confidence: 0.93

  - body: Calling `resolveBundledNodePath` before the current/system Node logic makes any supported state-dir `node-v*` artifact silently win on reinstall.
