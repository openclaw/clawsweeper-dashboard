## Label Justifications

- `P0`: The issue reports a network-reachable authentication bypass on a voice-call WebSocket that can accept forged media for an active call.
- `impact:security`: The affected behavior is an unauthenticated media-stream WebSocket boundary with possible call audio injection or transcript exposure.

## Summary

Keep open: current main still validates `/voice/stream` start frames with a Twilio-only token check and then accepts active non-Twilio provider call ids, so this remains a live security-boundary report.

## What This Changes

The issue asks OpenClaw to reject unauthenticated voice-call media-stream WebSocket start frames for non-Twilio providers such as Plivo and Telnyx.

## Best Possible Solution

Fail closed for `/voice/stream` unless the active provider has a per-call stream credential verifier; if non-Twilio media-stream support is intended, add provider-owned token generation, validation, and regression coverage before accepting starts.
