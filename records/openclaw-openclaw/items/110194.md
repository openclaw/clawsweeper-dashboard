## Summary

Keep this PR open, but do not merge it yet: the new reload recovery still gives launchd only about three additional seconds to finish a documented drain that can last 300 seconds, so it can still leave the gateway unloaded.

## What This Changes

The branch replaces reload-mode `launchctl kickstart -k` recovery with bounded `launchctl bootstrap` retries followed by `launchctl print` verification.

## Best Possible Solution

Make reload recovery remain retryable through the actual drain lifecycle or otherwise guarantee that a failed handoff restores a bootstrapped LaunchAgent before the script exits, with a regression test for a delay beyond the present retry budget.
