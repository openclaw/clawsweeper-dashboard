## What This Changes

The PR resolves active allowed exec-backed command SecretRefs locally, sends remaining paths through the gateway snapshot, and reconciles per-path recovery states and diagnostics.

## Best Possible Solution

Approve and land the split per-path design if the secret/auth owner confirms local command execution is the intended owner for active exec refs, while keeping all non-exec and locally failed paths gateway snapshot-owned.
