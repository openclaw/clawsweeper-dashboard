## Summary

This PR is still necessary and should remain open: it improves on the older candidate by resolving only active exec-backed paths locally while preserving gateway snapshot resolution for mixed non-exec targets. The patch appears correct and cleanly applies to current main, but the execution-boundary choice needs owner confirmation and the external contributor has not provided required after-fix real behavior proof.

## What This Changes

The PR resolves active exec-backed command SecretRefs locally before gateway RPC, delegates remaining paths to the gateway, falls back to gateway resolution after local exec failure, and adds focused regression tests.

## Best Possible Solution

Adopt one canonical per-path resolver that executes only active allowed exec refs locally, keeps other credentials on the gateway snapshot path, preserves gateway fallback after local exec failure, and is demonstrated with a real mixed-target reply run.
