## What This Changes

The PR centralizes live-session model selection behind a shared service, adds typed model-picker presentation and capability contracts, and routes model-only inline directives through the shared apply path.

## System Context

Inline model directives resolve a provider, model, and runtime before writing the live session record and emitting post-commit effects. Channel plugins may render typed model-picker actions, but each channel must explicitly opt in before it can decode such actions from its private callback envelope.
