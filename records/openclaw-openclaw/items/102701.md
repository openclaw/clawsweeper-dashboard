## Summary

Keep open, but do not merge as-is: making `auth` a built-in root causes CLI bootstrap to skip plugin command registration for that namespace, breaking installed plugins that already expose commands such as `openclaw auth login antigravity`. The contributor has also not supplied a redacted real terminal run of the changed command.

## What This Changes

Adds a top-level `openclaw auth list` alias that delegates to the existing model-auth profile listing command, with lazy CLI registration, tests, and documentation.

## Best Possible Solution

Keep model-profile inspection under the established `openclaw models auth list` owner unless maintainers first design a composable shared `auth` namespace that preserves existing plugin subcommands and includes explicit upgrade compatibility coverage.
