## Summary

The shortcut is not merge-ready because it converts a plugin-visible root command name into a built-in namespace, causing installed plugins that own `auth` to be skipped; the repeated prior blocker remains unresolved, and contributor-supplied real behavior proof is still absent.

## What This Changes

Adds a top-level `openclaw auth list` shortcut that delegates to the existing model-auth listing command, with lazy CLI registration, routing tests, and documentation.

## Best Possible Solution

Keep `openclaw models auth list` canonical unless CLI/plugin ownership explicitly approves reserving `auth`; if approved, define and test a documented collision and upgrade policy before adding the alias.
