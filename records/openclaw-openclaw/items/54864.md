## Best Possible Solution

Choose one backward-compatible fresh-session contract across this issue and https://github.com/openclaw/openclaw/issues/71417, then implement CLI parsing, Gateway/local dispatch, JSON output, docs, and focused tests consistently.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers choose the public contract. A native fresh-session flag is plausible, but it should be decided with the broader silent-resume UX so OpenClaw does not grow overlapping session controls.
