## Summary

Keep open: current main and v2026.6.11 still force hook-agent dispatch through isolated cron sessions, so a stable hook `sessionKey` cannot preserve multi-turn transcript state. The open linked implementation PR https://github.com/openclaw/openclaw/pull/75918 has closing syntax and should own the active review path before this issue is closed.

## What This Changes

The issue requests persistent multi-turn webhook hook sessions when callers provide a stable `sessionKey`, preferably through an explicit hook `sessionMode` option.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/75918; the maintainable end state is an explicit `sessionMode: "isolated" | "persistent"` hook option with isolated default behavior, documented security guidance, and regression coverage for direct payloads, mappings, transforms, schema/docs, and session reuse.
