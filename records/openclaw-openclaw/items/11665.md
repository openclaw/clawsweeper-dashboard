## Summary

Keep open: current main and the latest release still route hook-agent requests through isolated cron-style sessions, so stable hook session keys cannot preserve multi-turn transcript state; the linked implementation PR remains open and should own the active fix review.

## What This Changes

The issue requests persistent multi-turn webhook hook-agent sessions when callers provide a stable sessionKey.

Review and either land or reject https://github.com/openclaw/openclaw/pull/75918 as the canonical fix, preserving isolated defaults while adding a documented persistent hook-session opt-in with schema, docs, tests, and trust-boundary proof.
