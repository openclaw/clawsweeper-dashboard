## Summary

Keep open: current main and the latest release still route hook-agent requests through isolated cron sessions, so stable hook session keys cannot preserve multi-turn transcript state; the linked implementation PR is open and not merged.

## What This Changes

Request persistent multi-turn webhook hook sessions when callers provide a stable `sessionKey`, preferably through an explicit default-isolated `sessionMode` opt-in.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/75918 as the canonical fix, preserving isolated defaults while adding a documented persistent hook-session opt-in with schema, docs, tests, and trust-boundary proof.
