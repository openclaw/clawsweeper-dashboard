## Summary

Keep open: current main and v2026.6.11 still route hook-agent requests through isolated cron sessions, so stable hook session keys cannot preserve transcript continuity. The open linked implementation PR https://github.com/openclaw/openclaw/pull/75918 has closing syntax and should remain the active review path before this issue closes.

## What This Changes

The issue requests multi-turn webhook hook sessions by reusing an existing session when a trusted hook supplies a consistent session key.

## Best Possible Solution

Review and either land or reject https://github.com/openclaw/openclaw/pull/75918; the desired end state is an explicit isolated-by-default persistent hook mode with security guidance and regression coverage across direct payloads, mappings, transforms, schema, docs, and session reuse.
