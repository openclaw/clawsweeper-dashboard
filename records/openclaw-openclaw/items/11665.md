## Summary

Issue #11665 should stay open: current main and the latest release still force `/hooks/agent` requests into isolated sessions, while open PR #75918 is the active linked fix path for adding an explicit persistent hook-session mode.

## What This Changes

Request persistent multi-turn `/hooks/agent` sessions keyed by a stable hook `sessionKey`, preferably through an explicit isolated-versus-persistent session mode.

## Best Possible Solution

Use PR #75918 or an equivalent implementation to add an explicit persistent hook-session mode with isolated as the default, aligned schema/docs/tests, and trusted-hook security gates.
