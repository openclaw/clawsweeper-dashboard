  - confidence: 0.98

  - confidence: 0.95
- **[P1] Avoid a parallel persisted goal-plan authority:** `src/config/sessions/types.ts:215-217`
  - body: This expands the durable `SessionGoal` contract while the runtime already exposes `update_plan`.   - confidence: 0.9
- **[P2] Keep goal progress below the stable cache boundary:** `src/agents/system-prompt.ts:973-983`
  - body: The added section is derived from mutable goal/step state but is prepared before the stable-prefix cache construction. Including that data in the cached prefix churns cache keys across turns; render it after `SYSTEM_PROMPT_CACHE_BOUNDARY` and exclude it from the stable input.
  - confidence: 0.93

  - body: The feature's prompt and persisted session shape frame the output as chain-of-thought. Persist only concise, user-safe execution steps, dependencies, and checkpoints; do not request or retain private model reasoning across compaction.
  - confidence: 0.92

  - body: The planning prompt must demonstrate the same snake_case fields accepted by `update_goal_plan` and `create_goal(plan)`. Otherwise a model copying the prompt can lose dependencies or token estimates when it calls the tool.
