## Summary

Keep this PR open: its timeout proves the simple single-process hook case, but the runner still executes arbitrary hook commands through a shell, so timing out the shell does not reliably terminate hook descendants and the central “builds stop hanging” guarantee is incomplete.

## What This Changes

The branch adds a ten-minute timeout with `SIGKILL` to bundled plugin asset-hook commands and adds a regression test for a Node hook that ignores `SIGTERM`.

## Best Possible Solution

Use a process-tree-aware execution path for asset hooks, preserve the bounded timeout error, and add a regression case that starts a child below the shell and verifies no descendant survives on supported platforms.
