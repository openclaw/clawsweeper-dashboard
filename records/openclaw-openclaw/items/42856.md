Close as implemented: current main and the stable v2026.6.1 release convert unknown `config.schema.lookup` misses into an in-band agent gateway-tool result, preventing the user-facing warning path while preserving direct Gateway RPC error semantics.

## What This Changes

## Best Possible Solution

Keep the shipped agent gateway-tool boundary behavior: direct Gateway RPC misses remain `INVALID_REQUEST`, while agent-facing lookup misses return an in-band `schema_path_not_found` result that channels do not warn about.

## Solution Assessment
