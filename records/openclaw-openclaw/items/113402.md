## What This Changes

Fix embedded Automation runs so an explicit `toolsAllow: []` means an intentional zero-tools request even when inherited `tools.allow` configuration is non-empty.

## System Context

Automation `agentTurn` payloads enter the embedded agent runner, which resolves the effective tool set before sending a request to the model. The empty-allowlist guard must distinguish a deliberately tool-free run from an accidental allowlist mismatch while retaining fail-closed policy sources.
