## Summary

The reported file names are outdated, but the central bug remains actionable. citeturn26view0turn24view0

## What This Changes

Correct media-understanding MIME inference so valid attachment bytes take precedence over conflicting declared or fetched MIME metadata.

## Best Possible Solution

Route local and remote attachment bytes through the existing detectMime buffer/header/path contract, add conflicting-MIME regression fixtures, and leave gateway protocol validation unchanged unless a separate failing schema case proves it necessary.
