## What This Changes

Investigate and prevent a claimed false generic no-response error when Xiaomi MiMo v2.5 uses an 8,192-token maximum during complex agentic tasks.

## System Context

OpenClaw's embedded agent runner sends an assembled agent prompt to the selected provider and turns the resulting assistant payload into a channel-visible reply. When an OpenAI-compatible backend ends a replay-safe turn without user-visible text, the runtime retries once before surfacing the generic no-response outcome.
