## Summary

Keep this PR open: it remains a useful, well-proven candidate for the linked TTS delivery bug, with no concrete correctness finding on the current head. Merge should pause for owner confirmation because the implementation intentionally lets any runtime-marked trusted local media cross a room-event suppression boundary, not only TTS audio.

## What This Changes

The branch separates trusted local tool media from message-tool transcript mirrors and delivers stripped media-only payloads through suppressed block and final reply paths.

## Best Possible Solution

Use one owner-approved, centrally tested suppression exception for runtime-authenticated trusted media-only payloads, preserving text stripping, send-policy denial, room-event guards, and rejection of untrusted, reasoning, commentary, and status payloads across both block and final dispatch.
