## What This Changes

The PR replaces the scheduled SQLite verifier’s shared-process worker thread with a forked Node process so snapshot descriptor closes cannot release the live Gateway process’s POSIX SQLite locks.

## System Context

The Gateway periodically verifies its SQLite state databases after startup and on a recurring schedule. The verifier receives database targets, checks integrity in an isolated execution context, then returns results for normal logging and quarantine handling.
