## What This Changes

The PR replaces the in-process database-verification worker with a forked Node process so snapshot file-descriptor closes cannot release the Gateway process’s POSIX SQLite WAL locks.

## System Context

The state verifier periodically snapshots OpenClaw’s live SQLite databases and checks their integrity while the Gateway continues to own the active databases. Verification results flow back to the Gateway, which applies quarantine or logging behavior without changing the database schema or verifier schedule.
