## Summary

Keep this PR open, but do not merge the current head: the prior P2 finding remains because the error path queues the response with `res.end()` and immediately destroys the request’s shared socket, so overflow or timeout responses can still become `ECONNRESET`; the new public plugin-SDK teardown option also needs explicit contract approval.

## What This Changes

The PR bounds Copilot BYOK proxy request bodies at 16 MiB with a 30-second timeout and adds a shared body-reader option allowing callers to defer request destruction while returning HTTP errors.

## Best Possible Solution

Adopt one explicitly approved ingress teardown contract, then ensure the Copilot proxy waits for response completion or close before destroying the request and cover that invariant with a delayed/backpressured socket regression test.
