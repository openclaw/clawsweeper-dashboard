## Summary

The branch supplies focused overflow regression coverage and terminal proof, but the unconditional 16 MiB / 30 second request contract still needs a Copilot or shared-ingress owner to confirm that slow or legitimately large local SDK requests should fail this way.

## What This Changes

The PR limits Copilot BYOK loopback-proxy request bodies, returning deterministic 413 responses for declared and streamed overflows instead of buffering indefinitely or resetting the connection.

## System Context

The Copilot plugin starts a loopback proxy for SDK requests directed at a user-selected BYOK provider. Requests pass the proxy’s route and nonce checks, body handling, and SSRF-protected upstream fetch before reaching the configured provider.

## Best Possible Solution

Adopt the bounded reader only after an owner confirms that these limits match the supported Copilot BYOK workload, or replace the hard-coded policy with the repository’s accepted shared-ingress contract and retain both overflow regressions.
