## What This Changes

Adds fixed 16 MiB and 30-second body guards to the Copilot BYOK loopback proxy, returns deterministic HTTP errors for declared-length and streaming overflow, and adds focused regression coverage.

## Best Possible Solution

Keep the shared plugin-SDK guard and deterministic HTTP responses, but merge only after the Copilot owner confirms that 16 MiB and 30 seconds exceed the largest supported SDK request envelope or adjusts the constants to a documented, evidence-backed ceiling.
