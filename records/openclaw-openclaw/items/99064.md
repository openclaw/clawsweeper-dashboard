## Summary

Keep this PR open: the hardening remains useful, but the latest head still destroys the request immediately after ending the error response, so the promised deterministic 413 can regress to a connection reset under backpressure. The new caller-owned teardown mode also changes a public plugin SDK contract and needs explicit owner acceptance.

## What This Changes

Adds 16 MiB and 30-second request-body limits to the Copilot BYOK proxy, an optional shared-reader teardown mode, and declared-length and chunked-overflow coverage.

## Best Possible Solution

Keep the shared helper fail-closed by default; if the additive SDK option is approved, document caller-owned cleanup, wait for the 413/408 response to finish before destroying the request, and cover both overflow and timeout under forced response backpressure.
