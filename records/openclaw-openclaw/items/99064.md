## Summary

Keep this PR open: current main still buffers Copilot BYOK request bodies without a bound, and the current head provides convincing deterministic-response proof, but the fixed transport limits need Copilot-area ownership confirmation before merge.

## What This Changes

Adds a 16 MiB request-body cap and 30-second read timeout to the Copilot BYOK loopback proxy, with declared-length and chunked-overflow regression coverage.

## Best Possible Solution

Keep the bound inside the Copilot plugin and reuse the public SDK guard, but land only after the Copilot owner confirms a payload envelope that returns 413 for oversize, 408 for timeout, preserves complete responses, and never forwards rejected bodies.
