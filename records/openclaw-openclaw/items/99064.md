## Summary

The request-body bound is useful and the shared-reader approach is plausible, but the current head still destroys the request immediately after queuing the 413/408 response, so streamed failures can still surface as `ECONNRESET`; the new public plugin SDK teardown option also needs explicit maintainer approval.

## What This Changes

Adds a 16 MiB and 30-second request-body guard to the Copilot BYOK proxy, exposes an optional shared-reader teardown mode, and adds overflow regression coverage.

## Best Possible Solution

Approve a narrow shared SDK contract only if caller-owned teardown is intentional, then make the BYOK handler destroy the request from the response completion callback or after `finished(res)`, with regression coverage for both chunked overflow and timeout.
