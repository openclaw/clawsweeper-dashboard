## Summary

## What This Changes

The PR bounds Copilot BYOK proxy request buffering, returns deterministic HTTP errors for oversized or timed-out streamed bodies, and adds caller-controlled teardown to the shared request-body reader.

## Best Possible Solution

Land bounded buffering after a Copilot feature owner confirms the 16 MiB/30-second envelope and shared helper lifecycle contract, retaining focused tests for default destruction and deterministic proxy 413/408 responses.
