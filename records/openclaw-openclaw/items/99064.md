## Summary

This PR still addresses a real Copilot BYOK ingress defect and includes after-fix runtime output for declared-length and chunked overflow handling. The remaining merge question is compatibility: it makes a 16 MiB body cap and 30-second read deadline unconditional for existing local BYOK clients, without current-main contract evidence that those thresholds are established for Copilot traffic.

## What This Changes

The PR bounds Copilot BYOK loopback-proxy request bodies and returns deterministic 413 responses for oversized streamed requests instead of forwarding unbounded data or resetting the connection.

## System Context

Copilot BYOK uses a local loopback proxy to receive SDK requests and forward them to a configured provider through the plugin SDK’s SSRF-protected fetch path. The changed ingress step reads request bodies before that upstream forwarding occurs.
