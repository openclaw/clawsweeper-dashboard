## Summary

The patch now appears functionally correct and well-proven, including the previously reported response-teardown defect, but merging still needs owner confirmation that rejecting every Copilot BYOK request above 16 MiB or taking longer than 30 seconds is an acceptable compatibility contract.

## What This Changes

The PR bounds Copilot BYOK proxy request bodies, returns deterministic errors for declared-length, streaming, and timeout failures, and adds focused regression coverage.

## Best Possible Solution

Keep the shared bounded-reader design, but calibrate or explicitly approve the internal size and timeout constants against the largest supported Copilot BYOK request shape, with threshold and normal large-request coverage before landing; avoid adding user configuration unless a real supported workload requires it.
