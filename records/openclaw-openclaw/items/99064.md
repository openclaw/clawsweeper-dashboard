## Summary

This remains a focused, useful bug-fix PR, but the current head should not merge until the response-completion race is fixed and the public webhook-ingress API expansion is explicitly accepted.

## What This Changes

The PR bounds Copilot BYOK proxy request bodies, maps oversized or timed-out bodies to HTTP errors, and adds an optional shared body-reader mode that leaves request teardown to the caller.

## Best Possible Solution

Keep the shared bounded reader with backward-compatible default teardown only if owners accept the SDK option, and make the Copilot caller destroy or close the request only from the response completion callback after the HTTP error has been handed off.
