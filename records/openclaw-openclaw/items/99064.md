## What This Changes

The branch adds a 16 MiB request-body cap and 30 second read timeout to the Copilot BYOK proxy, plus an oversized-request regression test.

## Best Possible Solution

Merge the owner-local SDK-helper cap once maintainers accept 16 MiB/30s as the Copilot BYOK local proxy request-body contract.

## Reproduction Assessment

Yes from source inspection: current main accumulates every non-GET/HEAD Copilot BYOK proxy request before forwarding. I did not run a live failing request in this read-only review, but the PR body includes after-fix terminal proof for normal forwarding and oversized 413 behavior.

## Solution Assessment

Yes, this is the best code shape if maintainers accept the cap: it stays in the Copilot proxy owner and reuses the public plugin SDK body limiter instead of adding a parallel reader or broad core behavior. A config knob would add surface area and is not warranted unless maintainers need a different payload contract.
