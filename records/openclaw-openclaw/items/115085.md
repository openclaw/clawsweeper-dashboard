## What This Changes

This PR makes Gateway authentication rate-limit `maxAttempts` require a positive integer in configuration and normalizes invalid direct limiter inputs to a safe positive value.

## System Context

Gateway configuration is parsed before the Gateway starts, then feeds the authentication rate limiter that decides whether a client IP may continue attempting authentication. This change affects both configuration-load failures and the limiter’s allow-versus-lock decision after failed logins.
