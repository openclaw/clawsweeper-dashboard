## Summary

This PR is a narrow, well-proven fix with no discrete correctness defect found in the current-head patch. It deliberately makes an explicit empty `selectionDocsPrefix` distinct from an omitted value across plugin manifest, persisted package metadata, and setup output, so a maintainer should confirm that this is the durable channel-plugin metadata contract before merge; exact-head CI is still running.

## What This Changes

The PR preserves explicitly empty channel documentation prefixes through catalog and installed-plugin metadata so setup selection notes omit the default `Docs:` label when a plugin requests that behavior.

## System Context

Channel plugins declare catalog metadata in their package manifests or installed-package records. OpenClaw turns that metadata into channel setup entries and terminal-safe selection notes, which guide users toward channel documentation during setup.
