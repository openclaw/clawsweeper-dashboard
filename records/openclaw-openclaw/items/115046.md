## What This Changes

This PR moves QA Lab infrastructure retry handling from the CLI’s whole-suite call into the suite launcher so a retryable failure reruns only the failed channel partition.

## System Context

QA Lab turns a requested profile into flow and channel-specific partitions, then executes them through the suite launcher. The CLI and QA HTTP/runtime entry points consume the launcher’s results, so the retry boundary determines whether completed channel work is replayed after a late infrastructure failure.
