## Summary

## What This Changes

The issue requests Slack handling for user-authorized DM events and replies sent through a configured Slack user token.

## Best Possible Solution

Add a maintainer-approved, explicit Slack user-identity mode in the Slack plugin that keeps bot-token behavior as the default, routes inbound events by authorizing user/team, selects the matching user token for replies, documents the security boundary, and includes live Slack proof.
