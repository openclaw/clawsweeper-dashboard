## What This Changes

The PR audits short-term recall rows whose source is missing or not a regular file, reports them through Memory Core status and Doctor, and removes those rows with their associated phase signals during repair.

## System Context

Memory Core records short-term recall signals from workspace memory files, then dreaming and promotion consume that state. Its audit-and-repair path is shared by CLI status, Doctor, and managed dreaming, so a repair result affects the persisted recall store before those callers report health.
