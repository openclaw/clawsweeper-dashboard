## What This Changes

This PR extends Memory Core’s existing recall-artifact audit and repair flow to report and delete short-term recall rows whose source is missing or not a regular file, while deleting the matching phase-signal rows and showing the result in CLI and Doctor output.

## System Context

Memory Core keeps short-term recall records in plugin state for dreaming and durable promotion. The audit path reports unhealthy retained data to `memory status` and Doctor, while the repair path rewrites only invalid, stale, over-limit, or now-dangling records before dreaming continues.
