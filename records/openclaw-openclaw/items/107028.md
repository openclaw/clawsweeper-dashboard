## What This Changes

Makes plugin run-context set, get, and clear methods callable after registration and prevents inactive plugin registries from reading active-registry run-context state.

## Best Possible Solution

Keep run-context operations available to loaded active plugins after registration, deny all access from retired registries, preserve registration-only blocking for unrelated methods, and document or otherwise explicitly confirm this lifetime as the supported plugin contract.
