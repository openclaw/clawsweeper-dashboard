## Summary

Keep open: current main and v2026.6.11 still do not implement Telegram inline-query handling. The open Guest Mode PR overlaps on arbitrary-chat Telegram ingress, but it uses a different update and answer contract, so this remains a product/security design item rather than conservative cleanup.

## What This Changes

Add opt-in Telegram inline-query support so users can invoke an OpenClaw Telegram bot from any chat with `@botname query` and receive inline results.

## Best Possible Solution

Keep this as the canonical Telegram inline-query tracker until maintainers approve an opt-in Telegram plugin design with explicit authorization, privacy/cache defaults, session semantics, bounded execution, docs, tests, and live Telegram proof.
