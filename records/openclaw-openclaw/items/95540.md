## What This Changes

The branch makes doctor’s group allowFrom fallback migration skip channel/account `groupAllowFrom` writes when core has no bundled schema for the channel and adds an email-channel regression test.

## Best Possible Solution

Land the schema-verified doctor guard after maintainer acceptance of external-plugin repair ownership, or add an explicit plugin doctor/schema opt-in if maintainers want schemaless external channels migrated.

## Reproduction Assessment

Yes for source-level reproduction: current main permits missing-schema writes and then assigns `groupAllowFrom` onto channel/account records. The linked issue adds concrete upgrade and separate external-channel reproductions, but this read-only review did not run the packaged upgrade path.

## Solution Assessment

Yes, subject to maintainer acceptance: the changed guard is the exact write decision point and avoids mutating external plugin config that core cannot validate. The alternative is an explicit plugin doctor or schema opt-in if maintainers want external plugins to receive this migration.
