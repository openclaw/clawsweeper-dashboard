## What This Changes

This PR adds an optional `appServer.workspaceWriteNetworkAccess` setting intended to let Codex turns use network access while retaining the workspace-write filesystem sandbox.

## System Context

OpenClaw validates bundled plugin configuration against each plugin manifest before the Codex extension parses its own app-server settings. The resolved Codex runtime options then determine the sandbox policy passed to ordinary turns and conversation-bound turns.
