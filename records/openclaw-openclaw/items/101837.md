## What This Changes

The issue reports that `readResponseText` treats a response body exactly equal to `maxResponseBytes` as truncated, causing `web_fetch` to emit a false truncation warning.

## Best Possible Solution

Review and land or close https://github.com/openclaw/openclaw/pull/101845; once merged, this issue can close through that PR as the canonical fix.
