## Summary

Current `main` and the latest release still lack the requested injected-context provenance tags, and the same-author Phase 1 PR remains open. This should stay open as the canonical RFC until maintainers decide between the linked inline-tag path and a more runtime-owned structured provenance design.

## What This Changes

The issue requests source, injection-time, and volatility metadata on injected prompt context segments so agents can distinguish stale bootstrap/context data from fresh or authoritative sources.

## Best Possible Solution

Keep this issue as the canonical RFC while maintainers review the linked Phase 1 PR; if the direction is accepted, land a focused first phase and split memory freshness plus deterministic refresh into narrower follow-ups.
