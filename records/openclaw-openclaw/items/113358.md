## What This Changes

Fix memory-core’s MMR diversity reranking so broad searches over large corpora do not synchronously block the gateway event loop.

## System Context

Memory search retrieves a candidate pool, combines retrieval results, and applies MMR diversity reranking before returning results to the agent tool. Because this work runs in the gateway process, long synchronous reranking can delay channel delivery, heartbeats, RPC, and search timeouts.
