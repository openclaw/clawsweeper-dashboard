## Summary

The revised head resolves the previous broad-scope blocker, but it still has a provider-routing defect: catalog creation can be reconstructed from arbitrary or stale URL values instead of the currently advertised capability.

## What This Changes

The PR adds agent- and catalog-scoped session creation from the web sidebar, carries a catalog-selected model into `sessions.create`, and suppresses duplicate OpenClaw rows linked to catalog sessions.

## Best Possible Solution

Carry a stable catalog id through navigation, resolve its current `createSession` capability and label from `sessions.catalog.list` at render or submission time, reject missing or stale targets, and retain the protocol addition only after owner approval.
