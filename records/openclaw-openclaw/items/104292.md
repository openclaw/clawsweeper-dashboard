## Summary

The current head still emits the breaker warning from the open-state early return, so it can repeat for every eligible prompt during the default cooldown instead of identifying the single breaker transition. The observability goal is valid, but this correctness blocker and missing live runtime proof keep the PR open.

## What This Changes

The PR changes active-memory recall timeouts, circuit-breaker skips, and prompt-build deadline aborts to emit warning logs and updates the breaker log-severity assertion.

## Best Possible Solution

Emit the breaker warning once when consecutive timeouts transition the breaker to open, or apply an equivalent once-per-trip/cooldown bound, then add exact-count regression coverage and redacted live Gateway logs.
