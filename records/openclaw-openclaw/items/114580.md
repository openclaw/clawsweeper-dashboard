## What This Changes

This PR makes Tlon’s in-memory channel-history cache belong to each running monitor so a restarted or concurrent account fetches fresh history instead of reusing another monitor’s cached messages.

## System Context

The Tlon channel monitor receives inbound messages and serves channel-summary requests. It keeps recent messages in memory for summaries, then falls back to the Urbit history endpoint when the monitor-local cache lacks enough messages.
