## Summary

Keep this PR open for normal merge review. The monitor-owned cache is a bounded fix for the demonstrated stale-history bug, and the supplied terminal proof plus focused tests support the intended behavior.

## What This Changes

The PR moves Tlon channel-history caching from module scope into each monitor instance so a restarted account fetches fresh history rather than reusing another monitor's entries.

## System Context

The Tlon monitor receives channel messages and saves a short in-memory history for summary requests. When a summary arrives, it either uses enough recent messages from that monitor or requests history from Tlon, then passes the result into the summary flow.
