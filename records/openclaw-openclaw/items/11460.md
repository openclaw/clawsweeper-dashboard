## Summary

Keep open: current main and the latest release still lack generic WhatsApp reaction queries, historical reaction retrieval, and ordinary inbound reaction exposure; only outbound `react` plus approval-specific reaction handling are present, while related implementation attempts are closed unmerged and narrower follow-up issues remain open.

## What This Changes

Request to add WhatsApp support for listing/querying message reactions, exposing inbound reaction events, and retrieving historical reaction feedback.

## Best Possible Solution

Define a WhatsApp-owned reaction read surface that covers action discovery/dispatch, inbound add/remove events, historical persistence or query semantics, privacy gates, focused WhatsApp tests, and docs.
