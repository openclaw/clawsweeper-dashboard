## Summary

Keep open: current `main` and `v2026.6.11` still lack the generic WhatsApp reaction query/history path, and current reaction handling is limited to outbound `react`, status/ack behavior, and approval-specific reaction resolution. Related open items cover plugin hooks or listen-only behavior, but none is a merged or complete replacement for this broader request.

## What This Changes

The issue requests WhatsApp support for listing/querying message reactions, exposing reaction events, and retrieving historical reaction feedback for agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch still omit the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
