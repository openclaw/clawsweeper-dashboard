## Summary

Keep open. Current main supports outbound WhatsApp reactions and approval-specific inbound reaction consumption, but still lacks generic reaction listing, historical retrieval, and ordinary add/remove reaction exposure. The feature is viable through the existing channel-owned socket, but maintainers must choose the public event, session, privacy, and persistence contract first.

## What This Changes

Add WhatsApp reaction lookup, historical retrieval, and inbound reaction accessibility for agents or plugins.

## Best Possible Solution

Emit typed passive add/remove reaction events from the existing WhatsApp socket first; separately approve and design SQLite-backed historical lookup before adding generic `message reactions` support.
