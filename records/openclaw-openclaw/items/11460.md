## Summary

Keep this open: current main and v2026.6.11 still support WhatsApp outbound `react` plus approval-specific reaction consumption, but not the generic `message reactions` query, historical reaction retrieval, or ordinary WhatsApp reaction-event exposure.

## What This Changes

The issue requests WhatsApp support for querying message reactions, surfacing reaction events, and retrieving historical reaction data for agent feedback.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement generic `reactions` action support, reaction persistence or retrieval where feasible, and add/remove event observation inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: WhatsApp action discovery and dispatch still omit the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
