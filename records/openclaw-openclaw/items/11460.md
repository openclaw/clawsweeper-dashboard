## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` and approval-specific reaction handling, but not generic `message reactions`, historical reaction retrieval, or ordinary reaction add/remove exposure.

## What This Changes

Request to add WhatsApp support for querying message reactions, retrieving historical reaction state, and exposing reaction events to agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement `message reactions`, reaction persistence or provider retrieval, and reaction add/remove hooks inside the WhatsApp plugin with focused tests, docs, and live WhatsApp proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-event semantics before surfacing reactions broadly.
