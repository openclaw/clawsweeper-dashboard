## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` plus approval-specific reaction handling, but they do not support the generic WhatsApp `message reactions` query, historical reaction retrieval, or ordinary reaction-event exposure.

## What This Changes

Request to add WhatsApp support for querying and retrieving message reactions and exposing reaction events to agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event model, then implement the generic `reactions` action, persistence or provider retrieval, and observation hooks inside the official WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: WhatsApp action discovery and dispatch omit the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the public reaction read model. A maintainable fix should settle query, persistence, hook, privacy, access-control, and agent-turn semantics before exposing reactions broadly.
