## Summary

Keep open: current main and the latest release still support outbound WhatsApp `react` plus approval/status-specific reaction handling, but not the requested generic reaction query, historical reaction retrieval, or ordinary reaction event exposure.

## What This Changes

The issue requests WhatsApp support for querying message reactions, retrieving historical reaction state, and surfacing reaction feedback to agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement generic `reactions` query support, reaction persistence or retrieval, and plugin/agent event exposure inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery, dispatch, runtime handling, and hook surfaces do not support the generic `reactions` query or ordinary reaction event exposure. No live WhatsApp account was used in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence/history, hook/event, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
