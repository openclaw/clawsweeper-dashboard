Keep open: current main and the latest release still lack WhatsApp support for the generic `message reactions` query, historical reaction retrieval, and ordinary reaction event exposure; the open related issue is only a narrower hook slice, while the implementation PRs were closed unmerged.

## What This Changes

The issue requests WhatsApp support for querying, storing, and surfacing message reactions.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement generic reaction listing, historical persistence or retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Solution Assessment
