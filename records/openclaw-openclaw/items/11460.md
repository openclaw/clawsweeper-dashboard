## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` plus approval-specific reaction handling, but not generic WhatsApp reaction queries, historical reaction retrieval, or ordinary add/remove reaction event exposure.

## What This Changes

Add WhatsApp support for querying and surfacing message reactions, including historical/read access and event visibility for agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event contract, then implement generic `reactions` action support, reaction persistence or provider retrieval, plugin/agent event exposure, focused WhatsApp tests, docs, and live WhatsApp proof inside the plugin boundary.
