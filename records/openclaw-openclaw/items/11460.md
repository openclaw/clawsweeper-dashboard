## Summary

Keep open: current main and v2026.6.11 still lack a generic WhatsApp reaction query or historical read path; the shipped code only supports outbound `react` plus approval-specific reaction handling, while the narrower open hook request does not cover the full query/history request.

## What This Changes

Request to add WhatsApp support for querying, storing, and surfacing message reactions for agents and plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model in the WhatsApp plugin, then add the generic `reactions` action, reaction persistence or retrieval, hook/event semantics, focused tests, docs, and live/soak proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before broadly surfacing reactions.
