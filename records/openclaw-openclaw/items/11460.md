## Summary

Keep open: current main and v2026.6.11 still lack the generic WhatsApp reaction-list/query action, historical reaction retrieval, and public ordinary reaction event exposure; the remaining work is a WhatsApp plugin/API product decision, not cleanup-closeable.

## What This Changes

The issue requests WhatsApp support for querying message reactions, surfacing reaction events, and retrieving historical reaction feedback for agent use.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
