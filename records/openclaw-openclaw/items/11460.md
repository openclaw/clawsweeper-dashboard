## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` plus approval-specific reaction handling, but not the requested generic `message reactions` query, historical reaction retrieval, or ordinary WhatsApp reaction-event exposure. The related implementation PRs are closed unmerged, and the remaining open hook issue covers only one narrower slice of this broader request.

## What This Changes

The issue requests WhatsApp support for querying message reactions, making reaction events searchable or agent-accessible, and retrieving historical reactions.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event model, then implement the generic `reactions` action, persistence or provider retrieval, and observation hooks inside the official WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch omit the generic `reactions` action, ordinary reaction events are not exposed beyond approval-specific handling, and v2026.6.11 shows the same gap. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the public reaction read model. A maintainable fix should settle query, persistence, hook, privacy, access-control, and agent-turn semantics before exposing reactions broadly.
