## Summary

Keep open: current main and v2026.6.11 still support WhatsApp outbound `react` plus approval-specific reaction handling, but not the generic `message reactions` query, historical reaction retrieval, or ordinary WhatsApp reaction-event exposure.

## What This Changes

Request support for WhatsApp reaction querying, historical reaction retrieval, and agent/plugin-visible WhatsApp reaction events.

## Best Possible Solution

Define privacy-gated WhatsApp reaction read/event semantics, then implement the generic `reactions` action plus persistence or retrieval and plugin/agent observation in the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: WhatsApp action discovery and dispatch still omit the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
