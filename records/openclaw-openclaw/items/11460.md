## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` plus approval-specific reaction handling, but not the generic `message reactions` query, historical reaction retrieval, or ordinary WhatsApp reaction-event exposure.

## What This Changes

The issue requests WhatsApp support for querying historical message reactions, surfacing/querying reaction events, and making reaction feedback available to agents.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, ordinary add/remove event exposure, focused tests, docs, and live WhatsApp proof inside the WhatsApp plugin boundary.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
