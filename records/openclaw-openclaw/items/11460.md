## Summary

Keep open: current main and v2026.6.11 still support WhatsApp outbound reactions and approval-specific reaction handling, but not the requested generic WhatsApp reaction query/history surface or ordinary reaction event exposure.

## What This Changes

Request to add WhatsApp support for listing message reactions, making reaction events queryable/searchable, and retrieving historical reaction feedback.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, ordinary reaction observation hooks/events, focused tests, docs, and live WhatsApp proof inside the WhatsApp plugin boundary.

## Reproduction Assessment

Yes, source-level reproduction is high-confidence: the generic `reactions` command exists, but WhatsApp does not advertise or handle that action and ordinary reaction events are not exposed beyond approval-specific handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the public API and privacy model. A maintainable fix should settle query, persistence, hook payload, access-control, and agent-event semantics rather than forwarding every reaction as a normal message by default.
