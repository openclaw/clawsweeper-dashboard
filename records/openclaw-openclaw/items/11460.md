## Summary

Keep open: current main and v2026.6.11 still support WhatsApp outbound `react` plus approval-specific reaction handling, but not generic WhatsApp `message reactions` queries, historical reaction retrieval, or ordinary reaction add/remove event exposure.

## What This Changes

Request to add WhatsApp support for querying message reactions, retrieving historical reaction state, and exposing reaction events to agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event contract, then implement the generic `reactions` action, reaction persistence or retrieval, plugin/agent event exposure, focused tests, docs, and live WhatsApp proof inside the WhatsApp plugin boundary.

## Reproduction Assessment

Yes, at source level: WhatsApp action discovery and dispatch still omit the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the public reaction read model. The maintainable path should settle query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
