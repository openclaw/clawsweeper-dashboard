## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` and approval-specific reaction handling, but not the generic `message reactions` query, historical reaction retrieval, or ordinary reaction-event exposure.

## What This Changes

Request WhatsApp support for querying and surfacing message reactions, including historical retrieval and agent/plugin-readable reaction events.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, history or persistence, and plugin/agent exposure inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence or retrieval, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
