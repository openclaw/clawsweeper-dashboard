## Summary

Keep open: current main and v2026.6.11 still support WhatsApp outbound `react` plus approval-specific reaction handling, but they do not implement generic WhatsApp reaction queries, historical reaction retrieval, or ordinary reaction event exposure.

## What This Changes

Request WhatsApp support for listing/querying message reactions, retrieving historical reaction data, and exposing inbound reaction events to agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event contract, then implement `message reactions`, persistence or provider retrieval, event/hook exposure, focused tests, docs, and live proof in the WhatsApp plugin.
