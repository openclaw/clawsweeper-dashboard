Add WhatsApp support for querying message reactions, surfacing reaction events, and retrieving historical reaction state.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or provider retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.
