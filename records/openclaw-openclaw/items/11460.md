## Summary

Keep open: current main and v2026.6.11 still lack WhatsApp support for the generic `message reactions` query, historical reaction retrieval, and ordinary reaction-event exposure beyond approval-specific handling.

## What This Changes

Request to add WhatsApp support for querying message reactions, retrieving or storing historical reactions, and surfacing reaction events to agents or plugins.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, historical retrieval or persistence, and reaction observation hooks in the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes. At source level, current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence or retrieval, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
