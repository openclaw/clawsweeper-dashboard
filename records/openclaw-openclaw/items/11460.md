## Summary

Keep open: current main and v2026.6.11 still lack WhatsApp support for the generic reaction-list action, historical reaction retrieval, and broad reaction event exposure; the open hook issue covers only one narrower slice.

## What This Changes

Request adding WhatsApp support for listing/querying message reactions, exposing reaction events, and retrieving historical reaction state.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic reactions action, persistence or retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic reactions action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
