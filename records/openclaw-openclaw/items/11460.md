## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp `react` and approval-specific reaction resolution, but not generic WhatsApp `message reactions` querying, historical reaction retrieval, or ordinary reaction-event exposure.

## What This Changes

The issue requests WhatsApp support for querying, storing, or surfacing message reactions so agents and users can inspect reaction feedback.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action plus reaction persistence or retrieval and plugin/agent observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch omit the generic `reactions` query action, and current reaction consumption is approval-specific. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence/history, privacy, access-control, hook payload, and agent-turn semantics before surfacing reactions broadly.
