## Summary

Keep open: current main and the latest release still do not implement WhatsApp reaction queries, historical reaction retrieval, or general inbound reaction exposure; related open issues cover narrower hook/listen-only pieces rather than superseding this broader tracker.

## What This Changes

The issue requests WhatsApp support for querying, storing, and surfacing message reactions beyond the existing outbound reaction action.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, durable reaction storage or retrieval, and reaction event/hook exposure in the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp discovery and dispatch omit the generic `reactions` action, and ordinary inbound reactions are not stored or emitted beyond approval handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. The maintainable path should keep ownership in the WhatsApp plugin and define query, persistence, privacy, access-control, hook, and agent-turn semantics before implementation.
