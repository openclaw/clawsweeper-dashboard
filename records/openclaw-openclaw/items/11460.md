## Summary

The requested capability is still necessary: current main and the latest release expose outbound WhatsApp reactions and approval-specific inbound reaction handling, but not generic reaction listing, historical retrieval, or ordinary passive reaction events. Keep the issue open for a maintainer product decision because query/history, passive hooks, and reaction-triggered agent turns are distinct contracts; the related implementation PRs are all closed unmerged, while narrower open issues cover only parts of the request.

## What This Changes

Add WhatsApp support for listing message reactions, retrieving historical reaction feedback, and exposing incoming reaction add/remove events to agents or plugins.

## Best Possible Solution

Keep reaction lookup/history in this issue, let https://github.com/openclaw/openclaw/issues/79996 own passive add/remove plugin events, and leave opt-in agent turns to https://github.com/openclaw/openclaw/issues/17840; implement each through typed WhatsApp plugin contracts with real-account proof.
