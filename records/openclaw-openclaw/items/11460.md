## What This Changes

Add WhatsApp support for querying message reactions and making inbound reaction events accessible to agents or plugins, including historical context where feasible.

## System Context

The bundled WhatsApp plugin receives Baileys transport events, normalizes inbound content, and routes supported channel data to agents and plugin hooks. Message-action discovery separately determines which CLI and tool actions WhatsApp can perform; this request spans both reaction retrieval and inbound reaction-event exposure.
