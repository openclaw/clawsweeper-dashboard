## Summary

Keep open: current main and v2026.6.11 still lack the WhatsApp `message reactions` query and general reaction event/history exposure; existing WhatsApp support is limited to outbound, approval-specific, and status/ack reactions. The open related hook issue covers only one subset of this broader query/history request.

## What This Changes

The issue requests WhatsApp support for querying message reactions, exposing reaction events to agents or plugins, and retrieving historical reactions.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event model, then implement the generic `reactions` action, reaction persistence or retrieval, plugin/agent event exposure, focused tests, docs, and live WhatsApp proof inside the WhatsApp plugin.

## Reproduction Assessment

Yes, at source level: WhatsApp action discovery and dispatch still omit `reactions`, and ordinary reaction events are not exposed beyond approval-specific handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence/history, hook, privacy, access-control, and agent-turn semantics before exposing reactions broadly.
