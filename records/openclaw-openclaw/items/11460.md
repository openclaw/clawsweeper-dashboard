## Summary

Keep open: current main and the latest release still only cover outbound WhatsApp reactions plus approval-specific reaction consumption; the requested generic query, history, and ordinary event exposure remains unimplemented product/API work.

## What This Changes

The issue requests WhatsApp support for listing message reactions, making reaction events accessible, and retrieving historical reaction data.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, and event/hook exposure inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the read model and privacy gate. The maintainable fix should be WhatsApp-plugin-owned, but query, persistence, hook payload, access-control, and agent-turn semantics need product/API agreement first.
