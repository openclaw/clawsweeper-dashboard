## Summary

Keep open: current main and the latest release still support WhatsApp outbound reaction sending plus approval-specific reaction handling, but not the generic WhatsApp `reactions` query, historical reaction retrieval, or ordinary reaction event exposure requested here.

## What This Changes

The issue requests WhatsApp support for reading/querying message reactions, surfacing reaction events, and retrieving historical reaction feedback.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current main still omits the generic WhatsApp `reactions` action, does not store/query historical reactions, and only handles inbound `reactionMessage` for approval targets. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable solution should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
