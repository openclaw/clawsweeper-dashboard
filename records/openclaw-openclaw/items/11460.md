## Summary

Keep open: current main and v2026.6.11 still lack a generic WhatsApp `reactions` query/history path, while existing reaction handling is limited to outbound `react` plus approval-specific reaction resolution.

## What This Changes

Request support for WhatsApp message-reaction querying, searchable/stored reaction events, and historical reaction retrieval.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement generic `reactions` action support, persistence or retrieval, and hook/event exposure inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: WhatsApp action discovery and dispatch do not support the generic `reactions` action, and ordinary WhatsApp reaction events are not exposed beyond approval-target handling. I did not run a live WhatsApp account in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
