## What This Changes

Add WhatsApp support for querying current and historical message reactions and exposing ordinary inbound reaction events.

## Best Possible Solution

Keep this issue focused on generic and historical WhatsApp reaction lookup, let https://github.com/openclaw/openclaw/issues/79996 own passive add/remove hooks, and leave opt-in reaction-triggered turns to https://github.com/openclaw/openclaw/issues/17840; implement storage only after selecting a canonical upstream or SQLite-backed source.
