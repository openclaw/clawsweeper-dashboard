## Summary

Keep open: current main and v2026.6.11 still support outbound WhatsApp reactions and approval-specific reaction handling, but not generic WhatsApp reaction lookup, historical reaction retrieval, or ordinary add/remove reaction event exposure.

## What This Changes

Request support for querying, storing, and surfacing WhatsApp message reactions so agents or plugins can consume reaction feedback.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read/event contract, then implement generic `reactions` action support, reaction persistence or provider retrieval, plugin/agent event exposure, focused tests, docs, and live WhatsApp proof inside the plugin boundary.
