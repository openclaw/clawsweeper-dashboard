## Summary

Keep open: current `main` and v2026.6.11 still support WhatsApp outbound `react` plus approval-specific reaction handling, but they do not support the generic WhatsApp `message reactions` query, historical reaction retrieval, or ordinary WhatsApp reaction-event exposure.

## What This Changes

Request to add WhatsApp support for listing/querying message reactions, exposing reaction events to agents or plugins, and retrieving historical reaction feedback.

## Best Possible Solution

Define a privacy-gated WhatsApp reaction read model, then implement the generic `reactions` action, reaction persistence or retrieval, and observation hooks inside the WhatsApp plugin with focused tests, docs, and live proof.

## Reproduction Assessment

Yes, at source level: current WhatsApp action discovery and dispatch omit the generic `reactions` action, and ordinary reaction events are not exposed beyond approval-target handling. No live WhatsApp account was exercised in this read-only review.

## Solution Assessment

Unclear until maintainers choose the reaction read model. A maintainable fix should define query, persistence, hook, privacy, access-control, and agent-turn semantics before surfacing reactions broadly.
