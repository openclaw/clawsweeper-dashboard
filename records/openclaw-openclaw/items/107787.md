## Summary

Keep open: current code provides a plausible path for MiniMax-M3 reasoning to reach visible text, but the report lacks sanitized raw model/session evidence needed to distinguish structured thinking, tagged reasoning text, and ordinary assistant text. The older Telegram thinking reports overlap in symptom but do not yet establish one canonical root cause.

## What This Changes

Prevent MiniMax-M3 thinking content from appearing as user-visible Telegram messages when no explicit thinking default is configured.

## Best Possible Solution

Normalize MiniMax-M3 reasoning at the MiniMax provider boundary into structured thinking content, keep ordinary channel delivery provider-agnostic, and prove both hidden-default and explicitly visible reasoning behavior across Telegram and a non-Telegram surface.
