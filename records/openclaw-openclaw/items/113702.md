## What This Changes

The PR makes the Control UI renew its Gateway-issued Canvas capability URL and keeps existing agent-widget iframes stable while newly mounted widgets use the rotated URL.

## System Context

The Gateway advertises a short-lived Canvas capability URL in the Control UI connection hello message; sandboxed widget iframes use that URL because they cannot attach a bearer token. The Control UI lease refreshes that URL through the existing Gateway RPC and supplies the current value to chat widget rendering.
