## What This Changes

The PR adds a Control UI lease that renews the Gateway-provided Canvas capability URL and keeps existing widget iframes stable while newly mounted widgets use the rotated URL.

## System Context

The Gateway advertises a scoped Canvas capability URL in its hello response, and Control UI chat widgets use that URL to load Canvas documents inside sandboxed iframes. This change renews that connection-scoped authorization lease through the existing Gateway RPC and publishes the current URL to the chat widget renderer.
