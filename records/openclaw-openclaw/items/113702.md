## Summary

## What This Changes

The PR makes the Control UI renew the Gateway-issued Canvas URL capability so newly created chat widgets continue loading after a long-lived tab’s original capability expires.

## System Context

The Control UI receives a Canvas capability URL in the Gateway hello response and embeds it in sandboxed widget iframes that cannot send bearer authentication. The proposed lease refreshes that URL through the existing Gateway RPC, publishes the current URL to chat rendering, and preserves mounted iframe identity across rotations.
