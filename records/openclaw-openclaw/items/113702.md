## What This Changes

The branch renews the Control UI’s Gateway-issued Canvas capability lease and preserves mounted iframe identity so agent-created widgets continue rendering after a long-lived chat session’s original capability expires.

## System Context

The Control UI receives a Canvas capability URL in the Gateway hello response and uses it to load sandboxed agent-created widget documents. This change adds a connection-scoped renewal lease, publishes its current URL to chat rendering, and keeps already-mounted widget frames stable while new or remounted frames use the renewed capability.
