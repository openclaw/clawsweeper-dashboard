## What This Changes

The PR makes the Control UI renew its Gateway-issued Canvas capability URL and keeps mounted chat-widget frames stable while newly mounted frames use the rotated capability.

## System Context

The Control UI receives a Canvas capability URL in the Gateway hello message and uses it to load agent-created widgets inside sandboxed chat iframes. This change places a renewal lease between the Gateway connection and chat rendering so new widget frames receive a current URL without reloading already-mounted widgets.
