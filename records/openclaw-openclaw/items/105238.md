## Summary

Current source confirms this is a mixed, still-relevant feature request: OpenClaw already ships a native iOS chat and rich Markdown rendering, but the iOS chat explicitly disables the shared session switcher and exposes no in-chat model or agent picker. The remaining work should stay open for native-app product scoping, but it should be narrowed into focused switcher topics rather than implemented as one broad app redesign.

## What This Changes

Requests in-chat model, session, and agent switching in the native iOS chat, together with Markdown rendering and broader mobile-app UX improvements.

## Best Possible Solution

Retain the existing native iOS app and Markdown renderer, then split model, session, and agent switching into focused native-chat scopes that reuse the shared session/model infrastructure and define routing behavior before UI implementation.
