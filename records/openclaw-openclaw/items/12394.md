## Summary

Keep open: current main and the latest release still only support channel heartbeat visibility flags, while HEARTBEAT_OK acknowledgments and alerts share the agent-level delivery target. Per-user OK-only WhatsApp heartbeat routing remains missing and needs maintainer product direction for the new config contract.

## What This Changes

Request adding optional channel-level WhatsApp heartbeat recipient targeting so visible HEARTBEAT_OK acknowledgments can go only to admins without changing alert routing.

## Best Possible Solution

Define one additive WhatsApp/channel heartbeat recipient contract for visible OK acknowledgments, validate recipients through the existing channel/account policy, preserve current alert delivery, and update schema, docs, and focused routing tests together.
