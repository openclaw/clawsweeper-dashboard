## Summary

Keep open: current main still lacks an OK-only WhatsApp/channel heartbeat recipient contract, so this remains a valid feature/product decision rather than stale or implemented.

## What This Changes

The issue requests optional channel/account heartbeat recipients so WhatsApp `HEARTBEAT_OK` messages can go only to admins while alert/content delivery keeps its existing routing.

## Best Possible Solution

Define or reject a narrow WhatsApp/channel heartbeat OK-recipient contract; if accepted, validate targets against account/allowlist policy and apply it only to OK acknowledgments, with schema, docs, and focused tests updated.
