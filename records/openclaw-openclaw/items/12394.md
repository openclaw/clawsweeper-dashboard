## Summary

Keep open: current main and the latest release still lack OK-only per-user WhatsApp heartbeat routing, and adding it is a compatibility-sensitive channel config/product decision rather than conservative cleanup.

## What This Changes

The issue requests optional channel-level heartbeat recipients so WhatsApp HEARTBEAT_OK messages can go only to admin users instead of every allowed sender.

## Best Possible Solution

Keep this issue open until maintainers accept or reject an additive WhatsApp channel heartbeat recipient contract that applies only to OK acknowledgments, preserves alert routing, validates recipients through WhatsApp account/allowlist policy, and updates schema, docs, and focused tests together.
