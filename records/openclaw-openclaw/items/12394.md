## Summary

Keep open: current main and the latest release still expose channel heartbeat settings as visibility-only, so OK-only per-recipient WhatsApp heartbeat routing remains missing and needs a compatibility-sensitive product/config decision.

## What This Changes

Request optional WhatsApp/channel heartbeat target(s) so routine HEARTBEAT_OK messages go only to selected admin recipients while alert routing remains unchanged.

## Best Possible Solution

Decide the channel heartbeat recipient contract first; if accepted, add an additive WhatsApp/channel OK-recipient field with docs, schema/types, allowlist validation, and tests that keep alert routing on the existing delivery path.
