## Summary

Keep open: current main and the latest release still expose channel heartbeat config as visibility-only, and visible HEARTBEAT_OK delivery uses the already-resolved heartbeat delivery target rather than an OK-only recipient list.

## What This Changes

Request optional WhatsApp/channel heartbeat target or targets so visible HEARTBEAT_OK acknowledgments go only to selected admin recipients while alert/content routing remains unchanged.

## Best Possible Solution

Define or reject a narrow WhatsApp/channel heartbeat OK-recipient contract; if accepted, validate targets against account/allowlist policy, apply it only to OK acknowledgments, and update schema, docs, and focused tests.
