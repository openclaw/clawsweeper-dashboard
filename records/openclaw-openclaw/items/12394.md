## Summary

Keep open: current main still lacks channel-level WhatsApp heartbeat recipient routing for OK acknowledgments, and the existing supported knobs either control visibility only or route the whole heartbeat delivery target.

## What This Changes

The issue requests an additive `channels.whatsapp.heartbeat.target` or `targets` config so `HEARTBEAT_OK` messages can go only to admin recipients while alert delivery stays routed to relevant users.

## Best Possible Solution

Define an additive channel-owned heartbeat recipient contract that routes only OK acknowledgments to validated WhatsApp admin recipients while preserving existing alert/content delivery behavior and default compatibility.

Unclear until maintainers choose the contract; the narrow maintainable shape is additive OK-only recipient routing in the WhatsApp/channel heartbeat config with validation against account and allowlist policy, not reusing `agents.defaults.heartbeat.target` because that changes alert delivery too.
