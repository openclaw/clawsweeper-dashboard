## Summary

Keep open: current main still lacks OK-only per-user WhatsApp heartbeat routing, and the existing agent-level `target`/`to` settings route the whole heartbeat delivery rather than only visible healthy acknowledgments.

## What This Changes

Request to add channel-level WhatsApp heartbeat recipient targeting so visible `HEARTBEAT_OK` acknowledgments can go only to admin users while alert routing remains unchanged.

## Best Possible Solution

Define or reject a narrow WhatsApp/channel heartbeat OK-recipient contract; if accepted, validate targets against account/allowlist policy, apply it only to OK acknowledgments, and update schema, docs, and focused tests.
