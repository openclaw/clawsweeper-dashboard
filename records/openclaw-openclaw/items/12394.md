## Summary

Keep open: current main and v2026.6.11 still expose channel heartbeat config as visibility-only, and OK acknowledgments share the same agent-level delivery target as alerts; the remaining decision is the public config/API shape.

## What This Changes

Requests additive WhatsApp/channel heartbeat recipient config so `HEARTBEAT_OK` acknowledgments can go only to admin targets while alert delivery keeps its current routing.

## Best Possible Solution

Define or reject a narrow WhatsApp/channel heartbeat OK-recipient contract; if accepted, validate targets against account/allowlist policy, apply it only to OK acknowledgments, and update schema, docs, generated metadata, and tests.
