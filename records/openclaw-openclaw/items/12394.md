## Summary

Keep open: current main still lacks OK-only per-user WhatsApp heartbeat routing, and the existing heartbeat config only controls visibility rather than recipients. The requested behavior is a compatibility-sensitive config/product decision, not a stale or already-implemented cleanup item.

## What This Changes

Request optional WhatsApp/channel heartbeat target recipients so visible HEARTBEAT_OK acknowledgments can go only to admin users while alert routing stays unchanged.

## Best Possible Solution

Keep this issue open until maintainers accept or reject an additive WhatsApp heartbeat recipient contract that applies only to OK acknowledgments, preserves alert routing, validates recipients against account/allowlist policy, and includes schema, docs, and focused tests.
