## Label Justifications

- `P3`: This is a low-urgency enhancement to reduce routine heartbeat OK noise in shared WhatsApp setups, not a blocked setup path or regression.
- `impact:message-loss`: The requested behavior changes which WhatsApp recipients receive heartbeat status messages and must avoid misrouting or suppressing alert delivery.
- `impact:ux-friction`: Shared WhatsApp users currently choose between disabling OK visibility entirely or sending routine technical OK messages to non-admin users.

## Summary

Keep open: current `main` and the latest release still only support visibility toggles for channel heartbeat config, while OK acknowledgments and alert/content delivery share the same resolved heartbeat destination. The requested OK-only WhatsApp recipient contract remains a useful feature but needs maintainer product/config direction before implementation.

## What This Changes

Issue requests optional WhatsApp channel heartbeat recipient targeting so `HEARTBEAT_OK` messages can go only to admin users while alert delivery keeps going to the relevant user.

## Best Possible Solution

Define or explicitly reject a narrow WhatsApp/channel-account heartbeat recipient contract that applies only to OK acknowledgments, validates recipients against account and allowlist/pairing policy, updates docs/schema/types, and preserves alert/content delivery.
