## Summary

Keep open: current main still lacks OK-only per-user WhatsApp heartbeat routing, and solving it adds a new compatibility-sensitive channel config surface that needs maintainer product direction.

## What This Changes

The issue requests optional WhatsApp channel heartbeat targets so HEARTBEAT_OK messages can go only to admins instead of every allowlisted user.

## Best Possible Solution

Keep this issue open until maintainers accept or reject an additive WhatsApp channel heartbeat recipient contract that applies only to OK acknowledgments, preserves alert routing, validates recipients through WhatsApp account/allowlist policy, and updates schema, docs, and focused tests together.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: `channels.whatsapp.heartbeat.target` or `targets` is outside the strict channel heartbeat schema, and OK acknowledgments use the same resolved heartbeat delivery target as alert delivery.

## Solution Assessment

Unclear until maintainers choose the product contract. The requested additive config is plausible, but the best fix needs an explicit decision on field shape, per-account precedence, allowlist validation, and OK-only semantics.
