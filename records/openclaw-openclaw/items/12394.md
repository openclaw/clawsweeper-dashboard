## Summary

Keep open: current main still lacks a channel/account-level recipient contract for WhatsApp `HEARTBEAT_OK` acknowledgments, and existing agent-level heartbeat `target`/`to` routes the whole heartbeat delivery rather than OK-only admin visibility.

## What This Changes

The issue requests optional per-user WhatsApp heartbeat recipients so `HEARTBEAT_OK` messages can go to admins without broadcasting to every `allowFrom` user.

## Best Possible Solution

Define or explicitly reject a narrow WhatsApp/channel heartbeat OK-recipient contract; if accepted, validate recipients against account and allowlist policy, apply it only to OK acknowledgments, and update schema, docs, and focused tests.
