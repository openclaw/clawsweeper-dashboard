## Summary

Keep open: current main still lacks a WhatsApp/channel heartbeat recipient contract that routes only visible OK acknowledgments to selected admins while preserving normal alert delivery routing.

## What This Changes

The issue requests optional per-user or per-target routing for WhatsApp channel heartbeat OK messages in shared `allowFrom` setups.

## Best Possible Solution

Keep the issue open until maintainers accept or reject an additive WhatsApp channel heartbeat recipient contract that applies only to OK acknowledgments, preserves alert routing, and includes schema, docs, and compatibility coverage.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence capability-gap reproduction: `channels.whatsapp.heartbeat.target` or `targets` is outside the strict channel heartbeat schema, and OK acknowledgments use the same delivery target as alert delivery.

## Solution Assessment

Unclear until maintainers choose the product contract. The requested additive config is plausible, but the best fix needs an explicit decision on field name, per-account precedence, allowlist validation, and OK-only semantics.
