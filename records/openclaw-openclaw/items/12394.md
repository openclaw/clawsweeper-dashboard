## Summary

Keep open: current main and the latest release still only support heartbeat visibility toggles for channel config, while OK acknowledgment delivery uses the resolved heartbeat delivery target rather than a separate WhatsApp admin-recipient contract.

## What This Changes

Request to add channel-level WhatsApp heartbeat recipient routing so `HEARTBEAT_OK` messages can go only to selected admin users while preserving alert routing.

## Best Possible Solution

Keep this open until maintainers decide on an additive WhatsApp channel heartbeat recipient contract that applies only to OK acknowledgments, preserves alert routing, validates targets against account/allowlist policy, and updates schema, types, docs, and focused tests.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: `channels.whatsapp.heartbeat.target` or `targets` is outside the strict schema, and OK acknowledgment sending uses the shared resolved heartbeat delivery target.

## Solution Assessment

Unclear until maintainers choose the product contract. The requested additive config is plausible, but the best implementation needs an explicit field shape, precedence rule, allowlist validation policy, and OK-only routing semantics.
