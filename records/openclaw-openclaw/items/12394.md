## Summary

Keep open: current main and the latest release still lack OK-only per-user WhatsApp heartbeat routing; the channel heartbeat contract is visibility-only, while agent-level `target`/`to` routes the whole heartbeat delivery.

## What This Changes

Request to add channel-level WhatsApp heartbeat `target` or `targets` so `HEARTBEAT_OK` acknowledgments can go only to admins without changing alert routing.

## Best Possible Solution

Add one maintainer-approved WhatsApp/channel heartbeat OK-recipient contract in plugin-owned config, validate targets against account and allowlist policy, apply it only to OK acknowledgments, and update schema, docs, generated config help, and focused tests.
