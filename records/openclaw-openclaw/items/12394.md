## Summary

Keep open: current main and v2026.6.11 still lack OK-only per-user WhatsApp heartbeat routing; source shows channel heartbeat config only controls visibility, and adding recipient config needs a maintainer product/config decision.

## What This Changes

The issue requests optional `target` or `targets` fields for WhatsApp channel-level heartbeat OK messages so admin users can receive OK acknowledgments without alert/content rerouting.

## Best Possible Solution

Define or explicitly reject a narrow WhatsApp/channel account heartbeat recipient contract that applies only to OK acknowledgments, validates against account/allowlist policy, and preserves alert/content delivery.
