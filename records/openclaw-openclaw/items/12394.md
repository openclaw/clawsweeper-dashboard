## Summary

Keep open: current main and the latest release still do not have OK-only per-user WhatsApp heartbeat recipient routing, and adding it is a compatibility-sensitive channel config/product decision.

## What This Changes

The issue requests optional WhatsApp/channel heartbeat recipients so visible HEARTBEAT_OK acknowledgments can go only to admins while alert/content routing remains unchanged.

## Best Possible Solution

Accept or reject an additive WhatsApp/channel heartbeat recipient contract; if accepted, implement OK-only recipient routing with schema/types/docs and focused compatibility tests while preserving alert routing.
