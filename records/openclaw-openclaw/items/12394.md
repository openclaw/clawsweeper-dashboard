## Summary

Keep open: current main and the latest release still have channel heartbeat config as visibility-only, and HEARTBEAT_OK delivery still uses the same resolved heartbeat delivery target as alert/content delivery. The remaining blocker is choosing the public config/API shape for OK-only admin recipients.

## What This Changes

Request to add per-user or per-recipient WhatsApp channel heartbeat routing so HEARTBEAT_OK messages can go only to admins while alert routing remains unchanged.

## Best Possible Solution

Define or reject a narrow WhatsApp/channel heartbeat OK-recipient contract; if accepted, validate recipients through WhatsApp account and allowlist policy, apply it only to OK acknowledgments, and update schema, docs, generated metadata, and focused tests.
