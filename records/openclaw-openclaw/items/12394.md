## Summary

Keep open: current main still lacks an OK-only channel recipient contract, and the prior review discussion explicitly leaves the configuration shape and routing policy for maintainer decision.

## What This Changes

Add per-user or per-admin routing for channel heartbeat OK messages without changing delivery of heartbeat alerts or other content.

## Best Possible Solution

Define one additive OK-only recipient-list contract at the correct channel-owner boundary, with account precedence, normalized allowlisted targets, unchanged alert/content routing, generated configuration documentation, and focused compatibility tests.
