## Summary

Keep open: current main still lacks OK-only per-user WhatsApp heartbeat routing, and adding it would create a compatibility-sensitive channel config contract that needs maintainer direction.

## What This Changes

Request to add optional WhatsApp channel heartbeat `target` or `targets` recipients so visible `HEARTBEAT_OK` acknowledgments can go only to admins while alert routing stays unchanged.

## Best Possible Solution

Define an additive WhatsApp/channel heartbeat recipient contract for OK acknowledgments only, validate recipients against account and allowlist policy, preserve alert delivery semantics, and update schema, docs, and focused tests together.
