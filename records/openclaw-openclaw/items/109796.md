- **[P1] Preserve the unset Anthropic retry contract:** `packages/ai/src/providers/anthropic.ts:458`
  - body: `streamAnthropic` now sends `maxRetries: 0` even when its caller omitted the option, so direct and plugin consumers silently lose the Anthropic SDK's existing retry behavior. Pass zero from the outer agent caller that owns retries, or obtain explicit approval and compatibility coverage for redefining this provider primitive.
  - confidence: 0.99
- **[P1] Do not clamp token budgets from UTF-8 byte counts:** `packages/ai/src/providers/simple-options.ts:53-54`
  - body: This byte count is subtracted from a context window measured in tokens. Large ASCII or code prompts can be several times smaller in tokens than bytes, so valid requests collapse to the one-token floor and return effectively empty answers; use actual token counts or a non-destructive conservative estimate.
  - confidence: 0.99
- **[P2] Preserve tool quarantine before estimating context:** `packages/ai/src/providers/simple-options.ts:73`
  - body: The estimator runs before the provider's guarded tool projection and reads raw tool descriptors. A custom tool with a throwing `parameters` accessor can therefore fail synchronously instead of being quarantined while healthy tools continue; estimate only projected tools or guard descriptor access identically.
  - confidence: 0.97
- **[P2] Expose allowEmptySignature through model loading:** `packages/llm-core/src/types.ts:517-518`
  - body: Adding this field only to `AnthropicMessagesCompat` does not make it usable from configured or catalog models because the runtime schema and normalizers are unchanged. Thread the option through the supported model-loading surfaces and add a configuration round-trip test.
  - confidence: 0.99
- **[P2] Mirror the omitted-usage guard in the transport stream:** `packages/ai/src/providers/anthropic.ts:502`
  - body: The package provider now retains the valid `message_start` usage snapshot when `message_delta.usage` is absent, but the boundary-aware Anthropic transport remains unchanged and can still replace that snapshot with unavailable state. Apply the same invariant and regression coverage to the transport implementation.
  - confidence: 0.98
- **[P2] Populate one-hour cache writes on the transport path:** `packages/llm-core/src/types.ts:271`
  - body: The new cost calculation depends on `usage.cacheWrite1h`, but the boundary-aware Anthropic stream still records only aggregate cache creation tokens. Transported and proxied Anthropic requests therefore continue pricing one-hour writes at the five-minute rate; parse and preserve the bucket there too.
  - confidence: 0.99
- **[P1] Carry cacheWrite1h through worker protocol:** `packages/llm-core/src/types.ts:271`
  - body: The additive usage field is not accepted by the closed worker usage schemas and is omitted by the terminal projection. Worker contexts can reject transcripts containing the field, or worker outcomes can silently lose it; update both schemas, projections, and protocol round-trip tests before exposing the field.
  - confidence: 0.98
