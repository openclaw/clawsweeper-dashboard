## Summary

The provider accounting, retry, overflow, and replay fixes are well-supported, but this PR is not merge-ready because the new shared output clamp is only activated for Anthropic and Mistral while sibling simple-provider adapters still bypass it; the two exported SDK additions also need explicit owner confirmation.

## What This Changes

This PR corrects Anthropic and Mistral usage and caching behavior, expands retry and context-overflow classification, adds optional empty-signature replay compatibility, disables hidden Anthropic SDK retries by default, and introduces context-aware output-token clamping.

## Best Possible Solution
