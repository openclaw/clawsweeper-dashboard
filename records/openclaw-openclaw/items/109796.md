- **[P1] Preserve the unset Anthropic retry contract:** `packages/ai/src/providers/anthropic.ts:458`
  - body: Setting `maxRetries` to zero when the caller omits it changes the provider API's existing Anthropic SDK behavior for every direct stream caller.   - confidence: 0.97
- **[P1] Do not clamp token budgets from UTF-8 byte counts:** `packages/ai/src/providers/simple-options.ts:55`
  - body: This subtracts byte length from a token-denominated context window. Large ASCII and code prompts can be several times smaller in tokens, so valid requests are clamped to the one-token floor and return effectively empty replies; use canonical token accounting or a non-destructive recovery strategy.
  - confidence: 0.99

  - body: The estimator runs before provider tool projection and reads raw descriptors, so an unreadable `parameters` getter throws before the existing quarantine path can skip the bad tool and retain healthy siblings. Estimate only from a guarded projection or snapshot descriptor fields safely.
  - confidence: 0.96

  - body: Adding the interface field alone does not make the option usable by configured or catalog models: their schema and normalization paths still reject or drop it. Update those loading surfaces and add a configuration round-trip test, or remove the unusable compatibility knob.
