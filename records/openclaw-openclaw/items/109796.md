- **[P1] Do not clamp token budgets from UTF-8 byte counts:** `packages/ai/src/providers/simple-options.ts:52`
  - body: This subtracts byte length from a context window measured in tokens, so large ASCII or code prompts that still fit can be forced to the one-token output floor. Use actual token counts, a calibrated estimate, or a fallback that does not destructively clamp uncertain inputs.
  - confidence: 0.99
- **[P2] Preserve tool quarantine before estimating context:** `packages/ai/src/providers/simple-options.ts:71`
  - body: The new estimator reads raw tool descriptors before Anthropic and Mistral apply their guarded tool projection. A throwing `parameters` getter now aborts the stream instead of quarantining only the malformed tool; estimate from the safe projection or guard descriptor reads identically.
  - confidence: 0.96

  - body: Adding the compatibility field only to the shared model type does not make it usable by configured or catalog models when the config schema and normalizer still reject or strip it. Thread the field through every supported model-loading surface and add a configured-model regression test.
