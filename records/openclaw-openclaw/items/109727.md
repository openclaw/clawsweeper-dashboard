## Summary

Keep open: the shutdown delay is real and the supplied timing proof is strong, but the patch lets the owning abort signal cancel the cleanup barrier that protects orderly Telegram polling handoff.

## What This Changes

The PR threads the Telegram polling session abort signal into three graceful-stop waits and adds direct regression coverage for pre-aborted and mid-grace cancellation.

## Best Possible Solution

Start runner and bot shutdown concurrently, then retain the polling lease until both stop promises settle or one shared non-abortable cleanup deadline expires; cover an aborted old session followed by replacement lease acquisition.
