## Summary

Keep open: current main and v2026.6.11 still hardcode the main-agent identity opener before SOUL.md context, and the active implementation PR remains open while maintainers settle the public prompt-identity config contract.

## What This Changes

Make the main-agent system prompt identity opener configurable or suppressible so SOUL.md and per-agent identity guidance are not overridden by the hardcoded personal-assistant line.

## Best Possible Solution

Settle the prompt-identity config contract, then land a refreshed narrow opt-in implementation with unchanged defaults, schema metadata, docs, focused prompt/cache tests, and upgrade-safe behavior.
