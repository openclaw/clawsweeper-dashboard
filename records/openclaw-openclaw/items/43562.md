The issue requests a narrow way to replace or suppress the main-agent system prompt identity preamble so SOUL.md/persona identities are not overridden by the default personal-assistant line.

## Best Possible Solution

Adopt a maintainer-approved opt-in identity-line policy that preserves default prompt bytes, updates schema/docs/tests/cache-key coverage, and either lands or supersedes the open candidate PR.
