## What This Changes

The PR preserves managed MCP request and connection timeouts by translating portable Claw manifest seconds to canonical configuration milliseconds during install and update, and translating them back during export.

## System Context

A Claw package declares managed MCP servers in a portable manifest, while the running OpenClaw installation stores those servers in canonical configuration fields. The add, update, collision-digest, and export paths must preserve the same timeout meaning as data crosses that boundary.
