## What This Changes

The branch turns on agent tool-loop detection by default and adds a documented macOS script that monitors Anthropic billed usage and stops a gateway after a configured spend cap.

## System Context

Agent runs invoke tools during normal conversations and scheduled heartbeats; the loop detector observes repeated calls and can warn or stop an agent run. Separately, the proposed shell workflow polls an external provider’s billing API and controls a locally installed gateway service.
