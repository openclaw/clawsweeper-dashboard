## What This Changes

The branch makes `config file` and config dry-run JSON results emit resolved config paths instead of `~` or `$OPENCLAW_HOME` abbreviations.

## Best Possible Solution

Keep resolved absolute paths in machine-facing output and home abbreviations only in human-readable diagnostics, while updating the CLI reference examples and wording to make that boundary explicit.
