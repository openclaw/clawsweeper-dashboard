## Summary

Keep this PR open, but do not merge it yet: it addresses a valid credential-redaction gap, while the new token-oriented expressions still leave portions of structured authentication headers visible and the external contribution provides only test-based proof.

## What This Changes

The PR adds default patterns and regression tests to redact unquoted Authorization, Proxy-Authorization, and API-key-style HTTP headers in the shared logging and ACP fallback redactors.

## Best Possible Solution

Redact the complete header field value through its line boundary while preserving only the header name and, when useful, the authentication scheme; apply the same rule to both redactors and cover Digest, AWS-style, quoted, comma-separated, opaque-token, and ordinary-prose cases.
