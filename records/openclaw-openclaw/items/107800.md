## What This Changes

The PR sends Anthropic stream errors through the shared provider-error formatter and changes that formatter to serialize circular error objects without throwing.

## System Context

OpenClaw AI provider adapters turn transport failures into terminal stream events consumed by the agent runner. The shared provider-error formatter supplies diagnostic text to multiple adapters, while each adapter owns its own stream shutdown and completion result.

## Architecture Diagram

flowchart LR
  Transport[Transport rejection] --> Formatter[Shared provider error formatter]
  Formatter --> Anthropic[Anthropic stream adapter]
  Formatter --> OtherProviders[Google and OpenAI adapters]
  Anthropic --> Terminal[Terminal error event]
  OtherProviders --> Terminal
  Terminal --> Runner[Agent runner completion]

## Best Possible Solution

Keep the shared formatter as the single provider-error boundary, replace the global-seen-object logic with ancestor-stack cycle detection that preserves repeated acyclic references, add regression coverage for that distinction, and attach redacted evidence of the Anthropic circular-error terminal event and completion.
