## What This Changes

This PR changes Anthropic stream failure handling to use OpenClaw’s shared provider-error formatter and adds regression coverage for circular transport objects and ordinary errors without HTTP bodies.

## System Context

OpenClaw’s AI package turns provider streaming responses into terminal events consumed by the agent runner. When an Anthropic transport request fails, the provider must format the failure, emit an error event, and close the stream so the agent run does not remain open.
