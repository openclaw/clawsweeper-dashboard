## Summary

This PR addresses a real remaining Anthropic stream-teardown gap, but its shared serializer still mistakes repeated non-circular object references for cycles. Keep it open for that narrow correction and for direct after-fix proof of the circular Anthropic stream path.

## What This Changes

The branch routes Anthropic terminal stream errors through the shared provider formatter and changes that formatter to serialize circular plain-object diagnostics without throwing.

## System Context

AI provider adapters turn transport failures into terminal stream events for the agent runtime. Anthropic now delegates its diagnostic text to the shared formatter that is also used by other provider paths, then emits an error event and closes the stream.

## Best Possible Solution

Keep Anthropic on the shared formatter, but implement cycle detection with the active ancestor path so shared references serialize normally; add a regression test for two properties pointing to the same non-circular child and attach direct redacted output from the circular Anthropic terminal-event path.
