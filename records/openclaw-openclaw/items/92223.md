Overall correctness: patch is incorrect

Full review comments:

- **[P1] Avoid rebuilding large pasted data URLs with +=:** `ui/src/ui/views/chat.ts:956`
  - body: The new parser avoids the regex, but then reconstructs the payload with `base64 += trimmed[i]` for every base64 character. Current main's merged hardening at https://github.com/openclaw/openclaw/pull/99213 fixed this same V8 large-string failure class by chunking before `join("")`; this loop can still create a deep cons-string before `atob(base64)` and defeats the stack-safe guarantee for large pasted image data URLs. Accumulate bounded chunks or use a slice-based no-whitespace fast path instead.
