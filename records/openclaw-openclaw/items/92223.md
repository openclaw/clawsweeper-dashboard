Full review comments:

- **[P2] Build pasted data URLs without repeated concatenation:** `ui/src/ui/views/chat.ts:956`
  - body: `dataImageClipboardFile` is meant to handle multi-megabyte pasted data URLs, but this loop rebuilds the base64 payload one character at a time and then immediately calls `atob(base64)`. The merged sibling fix for this RangeError class avoided that cons-string pattern because flattening large payload strings can overflow V8's stack, so a large pasted image can still hit the failure this PR is trying to remove. Please accumulate chunks and `join` them, or reuse a shared stack-safe canonicalizer, and cover a truly multi-megabyte paste.
