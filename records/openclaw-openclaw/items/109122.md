## Summary

Keep open: the consolidation is directionally sound, but the new error-body handling starts a separate idle timeout after the request returns headers, so it does not enforce the claimed single 30-second wall-clock budget and remains vulnerable to slow-drip responses. The supplied proof is automated test output rather than an after-fix run against a real Urbit setup.

## What This Changes

The PR routes outbound Tlon channel pokes through the shared timed Urbit channel helper, normalizes connection context, bounds stalled error-body reads, and adds focused timeout tests.

## Best Possible Solution

Use one monotonic deadline or shared abort signal for the complete PUT operation, pass only the remaining budget into error-body reads, add a slow-drip regression test that proves the total deadline, and then provide redacted live Urbit terminal or log evidence.
