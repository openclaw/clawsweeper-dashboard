## What This Changes

Enable the existing cache-TTL idle-gap pruning path for direct OpenAI model sessions so stale tool results can be cleared after configured inactivity.

## System Context

The embedded agent runner selects a provider/model, decides whether cache-TTL pruning is eligible, and installs the context-pruning extension for the run. That extension records cache-TTL activity and, after an idle gap, clears stale tool-result content from the model prompt while retaining the persisted transcript.

  F --> G[Smaller model prompt]

## Best Possible Solution

Land a rebased, narrow repair that gives direct OpenAI models cache-TTL pruning eligibility without enabling Anthropic-style cache-control injection, with focused eligibility/extension coverage and redacted after-fix runtime evidence for an idle-gap OpenAI session.
