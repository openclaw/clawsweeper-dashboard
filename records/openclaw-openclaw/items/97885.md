## Summary

Keep open: current main still has manual agent CRUD, workspace-file editing, plugin bundle, backup, and provider migration surfaces, but no portable whole-agent bundle manifest or export/import command. The request remains useful, but it needs maintainer product and security design before implementation.

## What This Changes

Request portable Agent Bundle export/import so non-secret agent configuration, workspace files, skills, bindings, model/context settings, and environment requirements can move between OpenClaw instances.

## Best Possible Solution

Define a preview-first scoped Agent Bundle contract, coordinated with same-product migration and per-agent restore work, with an explicit portable allowlist, manifest schema, secret/runtime-artifact exclusions, conflict handling, skill-install policy, docs, and tests.
