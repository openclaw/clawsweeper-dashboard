## Summary

Keep open: current main still has manual agent CRUD, workspace-file, skill-install, and plugin-bundle primitives, but no whole-agent portable bundle schema or CLI/RPC import/export path. The remaining work is useful but needs maintainer product and security scoping before implementation.

## What This Changes

Add a portable, non-secret agent bundle export/import workflow for moving tested agents, workspace files, skills, bindings, and environment requirements between OpenClaw instances.

## Best Possible Solution

Define a maintainer-sponsored portable agent bundle contract with dry-run validation, explicit non-secret allowlists, conflict/overwrite behavior, and focused CLI/RPC tests before adding import/export code.
