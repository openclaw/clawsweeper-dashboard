## Summary

Keep open: current main and the latest release still lack a portable non-secret agent bundle export/import contract, and the remaining work crosses core config, workspace, skills, channel bindings, and security policy rather than being a narrow bug fix.

## What This Changes

Request a first-class portable Agent Bundle export/import workflow for moving a tested agent between OpenClaw instances without manually rebuilding config, workspace files, skills, bindings, and environment requirements.

## Best Possible Solution

Define a maintainer-sponsored portable, non-secret agent bundle contract with manifest schema, dry-run validation, explicit overwrite and conflict behavior, skill/env dependency checks, and clear coordination with backup/restore and migration trackers before implementation.
