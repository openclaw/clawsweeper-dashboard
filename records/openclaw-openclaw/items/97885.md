## Summary

Keep open: current main still has manual agent CRUD, workspace-file, skill-install, and plugin-bundle surfaces, but no portable whole-agent export/import contract. The request is useful, but it crosses config, workspace, auth, skills, bindings, and runtime-state boundaries, so it needs maintainer product and security design before implementation.

## What This Changes

Add a first-class portable Agent Bundle export/import mechanism for moving tested agents, non-secret configuration, workspace files, skills, bindings, and environment requirements between OpenClaw instances.

## Best Possible Solution

Define one portable, non-secret agent bundle contract with dry-run, conflict, overwrite, skills, environment, and secret-exclusion semantics, then implement it at the approved core or plugin/API boundary.
