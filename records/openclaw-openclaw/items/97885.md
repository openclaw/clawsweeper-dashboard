## Summary

Keep open: current main and the latest release still lack a portable whole-agent bundle export/import contract, and the request crosses product, config, workspace, skills, bindings, and security boundaries that need maintainer design before implementation.

## What This Changes

The issue requests first-class portable agent bundle export/import commands for moving non-secret agent configuration, workspace files, skills, bindings, and environment requirements between OpenClaw instances.

## Best Possible Solution

Define a portable agent bundle contract first: manifest schema, allowed non-secret fields, dry-run validation, overwrite/conflict rules, core-versus-plugin ownership, skill install behavior, env checks, and explicit exclusions for credentials, sessions, logs, caches, and runtime artifacts.
