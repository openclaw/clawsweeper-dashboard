## Summary

Keep open: current main and v2026.6.11 still lack portable whole-agent bundle export/import, and the adjacent plugin-bundle, workspace-file, backup, and migration surfaces do not define the requested non-secret agent package contract. The feature is useful but needs maintainer product and security design before implementation.

## What This Changes

Add a first-class portable agent bundle export/import workflow for moving tested agents, workspace files, skills, bindings, model/context settings, and environment requirements between OpenClaw instances without copying secrets or runtime artifacts.

## Best Possible Solution

Define a maintainer-sponsored agent bundle contract with manifest schema, dry-run validation, explicit non-secret allowlists, merge/overwrite rules, skill and env checks, binding policy, and coordination with backup/migration/plugin-bundle surfaces.
