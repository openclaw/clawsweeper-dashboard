## Summary

Keep open: current main and v2026.6.11 still have manual agent CRUD, workspace-file, skill-install, and plugin-bundle pieces, but no portable whole-agent export/import contract. The adjacent migration, backup, and per-agent clone issues overlap rather than replace this non-secret Agent Bundle request, so the remaining work needs maintainer product and security scoping.

## What This Changes

Request a portable Agent Bundle export/import mechanism for moving one tested agent across OpenClaw instances without manually rebuilding config, workspace files, skills, bindings, and environment requirements.

## Best Possible Solution

Define a maintainer-sponsored non-secret Agent Bundle contract with a manifest, export/import dry-run, explicit file and config allowlists, overwrite rules, skill and environment checks, and hard exclusions for secrets and runtime artifacts, coordinated with backup/restore and plugin-bundle surfaces.
