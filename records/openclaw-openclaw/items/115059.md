## What This Changes

Retains bounded per-session chat item, virtualizer, markdown, and scroll state so switching back to a Control UI session avoids transcript reflow and restores the prior reading position.

## System Context

The Control UI loads a session transcript, projects it into chat items, and renders it through a virtualized transcript. Session navigation currently resets transient presentation state; this PR retains selected per-session render and viewport state before the transcript is shown again.
