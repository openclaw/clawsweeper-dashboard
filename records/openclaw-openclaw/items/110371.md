## Summary

Keep this PR open for maintainer review: it has a concrete cleanup fix, but its UI preflight currently rejects valid Cloud sessions whose runtime is reported as the default `auto`/`default` value even though the server normalizes that value to `openclaw` before dispatch validation.

## What This Changes

The PR snapshots and removes session-owned managed worktrees during session deletion, and disables New Session Cloud targets when the resolved agent runtime is not OpenClaw.

## Best Possible Solution

Use the same default-runtime normalization contract as the server for the Cloud preflight, retaining the server dispatch check as authority; add focused coverage for `auto`/`default` plus a redacted after-fix gateway/UI proof covering rejected-dispatch cleanup and a valid default-runtime Cloud submission.
