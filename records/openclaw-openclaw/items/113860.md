## What This Changes

This PR makes task and process-control liveness checks retain a removed background process as active until its supervisor confirms that the child process has exited.

## System Context

The agent process registry tracks background command sessions, while the process supervisor owns the child lifecycle. Task maintenance and Gateway safety decisions consume a liveness predicate; removal hides a session from the user-facing registry but should not declare its child process finished.
