## Summary

Keep this PR open: the commentary-tagging direction matches the established phase contract, but the new subscriber gate regresses ordinary Chat Completions final-answer delivery at the configured `text_end` boundary, and the submitted proof is test-harness-only rather than a live provider/channel run.

## What This Changes

Tags text in Chat Completions tool-use turns as commentary, buffers unclassified Completions stream deltas, and adds transport and subscriber regression tests.

## Best Possible Solution

Keep the tool-use commentary tagging, but release buffered unphased Completions text into the durable reply buffer when `text_end` classifies the turn as a normal final answer; cover both suppression and final-answer delivery, then demonstrate the behavior with a live Grok or DeepSeek channel turn.
