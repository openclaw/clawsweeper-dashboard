## Summary

## What This Changes

The PR records a killed terminal session state after heartbeat or cron force-clears an embedded agent run, with tests covering persistence, replacement-session safety, and immediate recovery of the next reply.

## System Context

Embedded agent runs are tracked in memory while their session metadata is persisted for later routing and diagnostics. Force-clear recovery removes a stuck run; this change also updates the matching persisted session so the next incoming message can recognize it as terminal and recover promptly.
