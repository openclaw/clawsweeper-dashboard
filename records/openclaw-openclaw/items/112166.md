The contributor has supplied credible terminal-based real-behavior proof for the intended persistence path, so the remaining blocker is a concrete repair rather than missing proof.

## What This Changes

The branch records a killed terminal state in the session store after force-clearing a stuck embedded-agent run and adds regression coverage for persistence and fast reply recovery.

## System Context

Embedded-agent runs are tracked in memory while session records preserve their lifecycle state for later message dispatch and session listings. Heartbeat and cron recovery can force-clear a stuck run; the persisted terminal state then informs whether the next incoming message can safely reclaim the session.
