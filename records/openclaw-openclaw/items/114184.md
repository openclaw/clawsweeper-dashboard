## What This Changes

Fix Slack durable ingress so separate threads in the same channel can run concurrently while messages within each individual thread retain ordering.

## System Context

Slack events enter the Slack plugin and are assigned a durable ingress lane before they are admitted to the shared channel delivery and agent-run pipeline. The lane identity determines which events must wait behind one another, so omitting the Slack thread identity can serialize otherwise independent conversations.
