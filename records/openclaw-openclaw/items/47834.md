## Summary

Keep open: current main still lacks a hook-time current browser URL or supported query seam for browser act/type hooks, and the reporter's fail-secure credential-vault workaround confirms a real security-sensitive plugin API gap remains.

## What This Changes

Request to expose the current browser page URL to browser before_tool_call handlers for act/type so credential plugins can enforce domain pinning before injection.

## Best Possible Solution

Add a narrow, additive browser/plugin contract that gives before_tool_call handlers a policy-safe current tab URL for act/type, or an equivalent supported query seam, with docs and regression coverage for redacted or blocked URLs.

- **Keep Plugin Workarounds:** Leave URL caching and fail-secure cold-cache behavior to credential plugins, accepting duplicated complexity and restart limitations.
