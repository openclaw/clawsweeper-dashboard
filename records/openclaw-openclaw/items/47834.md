## Summary

Keep open: current main still does not provide a browser tab URL at the `before_tool_call` decision point for browser `act`/`type`, and the reporter's credential-vault workaround confirms the remaining security-sensitive plugin API gap.

## What This Changes

Request to expose the current browser page URL, or an equivalent query seam, to `before_tool_call` hooks for browser `act`/`type` actions so credential plugins can enforce domain pinning before injection.

## Best Possible Solution

Add a narrow, additive browser/plugin contract that gives pre-action browser policy hooks a policy-safe current tab URL for `act`/`type`, or an equivalent supported query seam, with docs and tests for blocked/private URLs and supported profiles.
