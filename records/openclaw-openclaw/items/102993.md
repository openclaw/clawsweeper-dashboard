## Summary

## What This Changes

The PR updates OpenAI reasoning-effort normalization to fold canonical effort names case-insensitively while preserving provider-native supported and mapped values, with focused resolver tests.

## Best Possible Solution

Keep canonical user input matching case-insensitive, but resolve fallback maps against preserved config/catalog key casing before falling back, while still returning mapped provider payload values exactly as configured.
