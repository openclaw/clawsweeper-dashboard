## Summary

Keep open: current main has isolated multi-agent routing, subagent spawn/fork, bounded A2A sends, session visibility controls, QMD filtering, and token/cost stats, but it does not implement durable learned capability profiles, shared blackboard state/tools, private/team/global memory tiers, or budget admission/enforcement. The remaining work is a broad product and security architecture decision, not a cleanup close.

## What This Changes

The issue requests a four-layer multi-agent collaboration stack: learned capability profiles, shared blackboard state, layered memory visibility, and token cost governance.

## Best Possible Solution

Keep this RFC as the umbrella design anchor and split it into staged decisions before implementation, starting with security/storage boundaries and one narrow collaboration primitive.
