## What This Changes

The branch passes each embedded agent attempt’s trajectory recorder into tool-event handling so executed tools add sanitized `tool.call` and `tool.result` records to the session audit trail.

## System Context

Embedded agent attempts subscribe to tool lifecycle events while producing a reply; the same attempt also writes an optional trajectory JSONL audit trail. Model fallback creates another attempt, so passing the attempt-scoped recorder through the shared subscription path determines whether fallback-side tool effects are recorded.
