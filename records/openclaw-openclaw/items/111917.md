## Summary

This PR has a focused, useful fix, but its cron-tool schema still advertises an unsupported timeout-clear operation for script payloads; it also needs an after-fix real CLI/runtime proof before merge.

## What This Changes

Adds `openclaw cron edit <job> --clear-timeout-seconds` and allows `timeoutSeconds: null` in agent-turn and command cron update patches so stored timeout overrides can be removed.

## Best Possible Solution

Keep timeout clearing update-only and either restrict the cron-tool nullable schema to agent-turn and command payloads or deliberately extend the protocol, types, merge path, CLI behavior, and proof to support script payloads too; then add a redacted live CLI/runtime transcript.
