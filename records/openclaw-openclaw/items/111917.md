## Summary

Keep this PR open: the main cron CLI path is coherent, but the newly nullable agent-tool patch schema advertises a script-payload clear that the Gateway and merge layers do not accept, so a valid-looking tool call can fail with `INVALID_REQUEST`.

## What This Changes

Adds `cron edit --clear-timeout-seconds`, carries `timeoutSeconds: null` through update patches, removes stored agent-turn or command payload timeouts, and documents/tests the behavior.

## Best Possible Solution

Make the agent-tool patch schema match the supported Gateway contract—either reject script `timeoutSeconds: null` or implement script clearing end to end—then add a redacted real CLI/Gateway proof of clearing a persisted timeout.
