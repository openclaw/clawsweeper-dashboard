## Summary

Keep open: the bounded-cache direction is reasonable, but the patch records a key before confirming that it has a loggable value, so a blank first call can suppress a later valid diagnostic. The supplied proof exercises a standalone cache rather than the changed helper.

## What This Changes

The PR replaces the process-lifetime environment-log key Set with a 1,024-entry bounded dedupe cache.

## Best Possible Solution

Use a bounded cache but validate that the resolved value is nonblank before calling its check-and-record operation, then add regression coverage for blank-then-populated calls and eviction through the actual helper.
