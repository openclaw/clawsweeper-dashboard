## Summary

Keep open: the bounded cache is reasonable, but the proposed ordering records an environment key before its value is accepted, so a blank first call can suppress a later valid acceptance log; the tests and proof do not exercise that changed path.

## What This Changes

The PR replaces the process-lifetime environment-log Set with a 1024-entry bounded dedupe cache and adds eviction-focused tests.

## Best Possible Solution

Use the bounded cache while preserving the existing invariant that only a nonblank accepted environment option becomes recorded as logged, with regression coverage for a blank-then-valid call sequence.
