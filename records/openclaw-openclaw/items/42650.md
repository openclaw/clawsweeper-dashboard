## Summary

Keep open: current main still lacks the requested first-class memory review, edit, non-destructive forget, tombstone/supersede, and conflict-resolution flows; existing memory-core behavior covers search, exact reads, indexing, promotion, dreaming review artifacts, and backfill previews, but not the durable lifecycle contract described here.

## What This Changes

The issue requests operator-facing memory lifecycle flows for reviewing, editing, forgetting without destructive deletion, and resolving conflicting memories.

## Best Possible Solution

Define a memory-plugin-owned lifecycle contract with SQLite-backed review state, provenance, explicit status transitions, safe forget/tombstone behavior, conflict resolution, operator CLI or UI flows, docs, and regression coverage before implementation lands.
