## Summary

Keep open: current main and v2026.6.11 still provide memory search/get, indexing, Dreaming promotion, and review artifacts, but not the requested first-class review, edit, safe forget, tombstone/supersede, or conflict-resolution lifecycle flows.

## Best Possible Solution

Define a memory-plugin-owned lifecycle contract with SQLite-backed statuses, revisions, provenance, safe tombstones, conflict records, and operator CLI/UI review/edit/forget flows before implementation lands.
