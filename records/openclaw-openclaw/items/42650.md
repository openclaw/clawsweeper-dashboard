## Summary

Keep open: current main and v2026.6.11 still provide memory search/get, promotion, and Dreaming review artifacts, but not first-class review, edit, non-destructive forget, tombstone/supersede, or conflict-resolution flows.

## What This Changes

The issue requests operator-facing durable memory lifecycle flows for reviewing, editing, forgetting, tombstoning/superseding, and resolving conflicts without direct database access.

## Best Possible Solution

Define a memory-plugin-owned lifecycle contract with SQLite-backed review state, provenance, explicit status transitions, safe tombstone/forget behavior, conflict resolution, operator CLI/UI flows, docs, and regression coverage before implementation lands.
