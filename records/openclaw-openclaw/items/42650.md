## Summary

Keep open: current main still lacks first-class review, edit, tombstone/forget, supersede, and conflict-resolution flows for durable memory, and the open Memory Audit PR is draft and only a partial candidate.

## What This Changes

Add operator-facing memory lifecycle flows for reviewing, editing, non-destructively forgetting, and resolving conflicting durable memories.

## Best Possible Solution

Define a plugin-owned memory lifecycle contract first, then implement SQLite-backed status/provenance/review state plus operator CLI/UI flows and focused upgrade proof in the recommended memory path.
