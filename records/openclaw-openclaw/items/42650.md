## Summary

Keep open: current main still has memory search/get, promotion, Dreaming review artifacts, Memory Wiki claim tooling, and LanceDB delete-by-id, but not the requested first-class review, edit, non-destructive forget, tombstone/supersede, or conflict-resolution lifecycle contract for the default memory path.

## What This Changes

The issue requests operator-facing memory lifecycle flows for review, edit, safe forget, tombstone/supersede states, and conflict resolution without direct database access.

## Best Possible Solution

Define a plugin-owned memory lifecycle contract with SQLite-backed status/revision state, provenance, safe tombstones, conflict resolution, operator CLI/UI flows, docs, and regression coverage before implementation lands.
