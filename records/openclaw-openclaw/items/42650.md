## Summary

Keep open: current main and v2026.6.11 still provide memory search/get, indexing, promotion, and Dreaming review artifacts, but not the requested review, edit, safe forget, tombstone/supersede, or conflict-resolution lifecycle flows. This remains a product/API/storage design item rather than a narrow bug fix.

## What This Changes

Add first-class memory lifecycle flows so operators can review, edit, safely forget or tombstone, and resolve conflicting memories without direct DB access.

## Best Possible Solution

Define a memory-plugin-owned lifecycle contract with SQLite-backed review state, provenance, explicit status transitions, safe forget/tombstone behavior, conflict resolution, operator CLI/UI flows, docs, and regression coverage before implementation lands.
