## What This Changes

The issue reports a Claude CLI live-session timeout crash caused by an unhandled rejection while stdin write is still pending.

## Best Possible Solution

Fix the live-session promise ownership so timeout rejection is observed before any awaited stdin write, then add regression coverage for a stdin write callback that never fires across watchdog expiry.

## Reproduction Assessment

Yes, at source level: use a claude-stdio ManagedRun whose stdin.write callback never fires, let the no-output timer expire, and `failTurn` rejects `outputPromise` before it is awaited. I did not run a live stuck-child gateway repro in this read-only review.

## Solution Assessment

Yes. The narrow fix belongs in live-session promise ownership and regression coverage; globally suppressing `FailoverError` in the unhandled-rejection handler would mask the promise-lifecycle bug.
