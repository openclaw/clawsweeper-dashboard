## Summary

Keep open: current main and v2026.6.11 still have loop detection, per-channel allow/deny tool policy, and explicit `sessions_spawn`, but not the requested channel-scoped max-per-turn budget or `warn`/`block`/`auto-delegate` overflow behavior. The related global iteration-budget PR does not cover per-channel precedence or automatic delegation handoff, so this remains useful maintainer design work.

## What This Changes

Request a per-channel tool-call budget config with warn, block, and auto-delegate overflow behavior for channel-originated agent turns.

## Best Possible Solution

Define a generic scoped tool-budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement first in the trusted before-tool path, then separately design opt-in auto-delegation around `sessions_spawn` inheritance, audit, child-run tracking, and completion handoff.

## Reproduction Assessment

Yes for the source-level feature gap, not as a broken-behavior runtime repro: current main and v2026.6.11 lack the channel-scoped budget config, before-tool budget state, and overflow handling. The reported Discord instability remains production-context evidence rather than a live reproduction in this review.

## Solution Assessment

No for landing the literal config plus auto-delegation as one step; the safer maintainable path is staged budget enforcement first, with automatic delegation designed separately around existing spawn and security boundaries.
