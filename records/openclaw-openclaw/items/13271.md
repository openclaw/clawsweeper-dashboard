## Summary

Keep open: current main and v2026.6.11 still lack the requested channel-scoped per-turn tool-call budget and warn/block/auto-delegate overflow behavior. The request is valid, but it adds config, channel policy, session-state, message-delivery, and delegated-authority semantics that need maintainer product and security design before implementation.

## What This Changes

Request a per-channel tool-call budget that can warn, block, or automatically delegate overflow work to a sub-agent.

## Best Possible Solution

Define a generic scoped tool-budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement first in the trusted before-tool path, then design auto-delegation separately around sessions_spawn, sandbox/tool inheritance, child-run tracking, and completion handoff.

## Reproduction Assessment

Yes for the source-level feature gap: current main and v2026.6.11 have no channel-scoped per-turn tool budget or warn/block/auto-delegate overflow handling. This is not a broken-behavior runtime repro because the item requests new capability.

## Solution Assessment

No for the literal all-in-one config plus automatic delegation sketch; it is too security- and routing-sensitive to implement as a one-shot feature. The maintainable path is staged scoped budget enforcement first, with separately approved auto-delegation semantics.
