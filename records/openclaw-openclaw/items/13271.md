## Summary

Keep open: current main still has loop detection, channel/group allow-deny policy, and explicit subagent spawning, but not a channel-scoped max-per-turn tool budget or warn/block/auto-delegate overflow behavior. This remains a valid product and security design item, not a conservative cleanup close.

## What This Changes

Request per-channel tool-call budgets with warn, block, and auto-delegation overflow behavior.

## Best Possible Solution

Define a generic scoped tool-budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement first in the trusted before-tool path, then separately design auto-delegation around sessions_spawn authority, child-run tracking, and completion handoff.

## Reproduction Assessment

## Solution Assessment

No for the literal all-in-one config plus immediate auto-delegation shape; the combined gateway interception and child-session behavior is security- and routing-sensitive. The maintainable path is staged generic budget enforcement first, then separately approved auto-delegation semantics.
