## Summary

Keep open: current main and v2026.6.11 still have adjacent loop detection, channel/guild tool allow-deny policy, and `sessions_spawn`, but not the requested per-channel max-per-turn tool budget or warn/block/auto-delegate overflow behavior. ## What This Changes

Request adds a per-channel tool-call budget with warn, block, and auto-delegate overflow behavior after a channel-specific max-per-turn limit.

## Best Possible Solution

Define a generic scoped tool-budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement first in the trusted before-tool path, then separately approve auto-delegation around `sessions_spawn` authority, state, and handoff.

## Solution Assessment

No, the literal single-step config plus automatic delegation sketch is not yet the safest complete solution. The maintainable path is staged: generic scoped budget enforcement first, then separately designed automatic delegation semantics with security and delivery guarantees.
