## Summary

Keep open: current main still lacks the requested per-channel max-per-turn tool budget and the warn/block/auto-delegate overflow behavior. Existing loop detection, channel/group tool allow-deny policy, and `sessions_spawn` are adjacent primitives, but this still needs product and security design before implementation.

## What This Changes

Request a per-channel tool-call budget config that can warn, block, or automatically delegate overflow work to a sub-agent.

## Best Possible Solution

Define a generic scoped budget model that composes with existing tool policy, implement deterministic warn/block enforcement first, and treat automatic delegation as a separately reviewed sessions_spawn design.
