## Summary

Keep open: current main and the latest release still lack the requested channel-scoped per-turn tool-call budget and warn/block/auto-delegate overflow behavior. This remains a valid but security-sensitive product/API design item rather than conservative cleanup closure.

## What This Changes

Requested channel-scoped per-turn tool-call budgets with warn, block, and auto-delegate overflow behavior for multi-channel agents.

## Best Possible Solution

Define a generic scoped tool-budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement first in the trusted before-tool path, then separately design auto-delegation around sessions_spawn, sandbox/tool inheritance, child-run tracking, and completion handoff.

## Reproduction Assessment

Yes for the source-level feature gap: current config, before-tool, Discord channel, and subagent code show no channel-scoped per-turn budget or overflow handling. This is not an executable broken-behavior repro because the item is a feature request.

## Solution Assessment

Unclear for the literal proposed config plus immediate auto-delegate behavior: the goal is sound, but gateway interception and child-session authority need maintainer product and security design. A safer path is staged warn/block enforcement first, then a separately approved auto-delegation contract.
