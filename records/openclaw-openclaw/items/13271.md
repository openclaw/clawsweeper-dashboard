## Summary

Keep open: current main still lacks a channel-scoped max-per-turn tool-call budget and the requested warn, block, or auto-delegate overflow behavior; this remains a product and security design item, not conservative cleanup.

## What This Changes

Request a per-channel tool-call budget that can warn, block, or automatically delegate overflow work to a subagent.

## Best Possible Solution

Define a generic scoped tool-call budget model that composes with existing tool, channel, sandbox, and subagent policy; ship deterministic warn/block enforcement first, then design automatic delegation around sessions_spawn authority and completion handoff.
