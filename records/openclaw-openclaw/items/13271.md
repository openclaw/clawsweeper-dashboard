## Summary

Keep open: current main still has adjacent loop detection, channel/group tool policy, trusted before-tool policy, and `sessions_spawn`, but not the requested channel-scoped max-per-turn tool-call budget or `warn`/`block`/`auto-delegate` overflow behavior. The remaining work is a product and security design decision rather than conservative cleanup closure.

## What This Changes

Request a per-channel tool-call budget with configurable warn, block, or automatic subagent delegation behavior when a turn exceeds the limit.

## Best Possible Solution

Define a generic scoped tool-call budget model that composes with tool, channel, sandbox, provider, and subagent policy; ship deterministic warn/block enforcement first, then design automatic delegation around explicit `sessions_spawn` authority and completion handoff.
