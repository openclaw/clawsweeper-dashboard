## Summary

Keep open. Current main still has loop detection, per-channel allow/deny policy, and explicit subagent spawning, but it does not implement the requested channel-scoped per-turn tool-call budget or warn/block/auto-delegate overflow behavior.

## What This Changes

The issue requests configurable per-channel tool-call budgets with hard warn, block, or automatic subagent delegation when a channel exceeds its per-turn limit.

## Best Possible Solution

Define a generic scoped tool-call budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement first in the trusted before-tool path, then separately design auto-delegation around sessions_spawn, sandbox/tool inheritance, child-run tracking, and completion handoff.

## Reproduction Assessment

Yes for the source-level feature gap, not as a broken-behavior runtime repro: current strict config and before-tool/subagent code show no channel-scoped per-turn budget or overflow handling. The reported Discord stability motivation remains production-context evidence rather than a live repro in this review.

## Solution Assessment

No for the literal single-step config plus auto-delegate implementation. The maintainable path is staged generic budget enforcement first, then separately approved auto-delegation semantics with explicit authority and handoff rules.
