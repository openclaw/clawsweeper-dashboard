## What This Changes

Define a generic scoped tool-call budget model with explicit precedence and per-turn accounting; ship deterministic warn/block enforcement in the trusted before-tool path first, then separately approve auto-delegation semantics around sessions_spawn authority, child-run tracking, sandbox/tool inheritance, and completion handoff.
