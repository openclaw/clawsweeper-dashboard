## Summary

Keep open: current main and the latest release have adjacent loop detection, channel tool allow/deny policy, and `sessions_spawn`, but no channel-scoped max-per-turn tool budget or `warn`/`block`/`auto-delegate` overflow behavior. The remaining work needs product and security design before implementation.

## What This Changes

Add a per-channel tool-call budget with warn, block, and automatic subagent delegation overflow behavior for multi-channel agent sessions.

## Best Possible Solution

Define a generic scoped tool-call budget model that composes with existing tool, channel, sandbox, and subagent policy; ship deterministic warn/block enforcement first, then design automatic delegation around `sessions_spawn` authority and completion handoff.
