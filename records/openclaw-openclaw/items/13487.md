## Summary

Keep open: current main and the latest release still route Discord messages before cross-bot mention/reply target selection, compare reply metadata only to the running handler bot ID, and lack a default-owner suppression result for messages targeting another configured bot.

## What This Changes

The issue requests deterministic Discord multi-bot routing precedence where explicit bot mentions beat reply targets, reply targets beat the per-channel default owner, and the default owner is suppressed for targeted messages.

## Best Possible Solution

Define the Discord-owned target-selection contract, then implement target precedence in preflight before shared default routing with focused tests for explicit mention, reply target, and untagged default-owner cases.
