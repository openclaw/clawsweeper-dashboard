- `impact:message-loss`: The targeted Discord bot may not produce the visible response when explicit mention or reply-target routing is not honored.

## Summary

Keep open: current main still resolves Discord routing before cross-bot mention or reply-target selection, so the requested single-target precedence remains necessary and needs maintainer direction because suppressing the default owner changes existing multi-bot channel behavior.

## What This Changes

The issue requests deterministic Discord multi-bot routing where explicit bot mentions win first, replies to a bot win second, and the default owner responds only when no targeted signal exists.

## Best Possible Solution

After maintainer confirmation, implement one Discord-owned target-selection rule: configured Discord bot mentions first, referenced bot authors second, and default owner only when no targeted signal exists, with focused tests and redacted live Discord proof.
