## Summary

Keep open: current main and the latest release still resolve Discord routing before cross-bot mention/reply-target selection, so this issue remains necessary and needs maintainer direction because suppressing the default owner changes existing multi-bot channel behavior.

## What This Changes

The issue requests Discord multi-bot inbound routing that chooses explicitly mentioned bot accounts first, replied-to bot authors second, and the per-channel default owner only when no targeted signal exists.

## Best Possible Solution

After maintainer confirmation, implement one Discord-owned target-selection rule: resolve configured Discord bot mentions first, referenced bot authors second, and use the default owner only when no targeted signal exists, with focused preflight/routing tests and redacted live Discord proof on the resulting PR.
