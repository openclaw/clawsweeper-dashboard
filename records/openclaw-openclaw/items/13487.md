## Summary

Keep open: current main and v2026.6.11 still resolve Discord routing before cross-bot mention or reply-target selection, so this issue remains necessary; the source gap is clear, but default-owner suppression is a Discord multi-bot routing product decision.

## What This Changes

Request deterministic Discord multi-bot routing where explicit Discord bot mentions, then native reply targets, select eligible responders and suppress the default owner when a target exists.

## Best Possible Solution

Define one Discord-owned target-selection rule: resolve configured bot mentions first, referenced bot authors second, and use the default owner only when no targeted signal exists, with focused preflight/routing tests and redacted live Discord proof on the resulting PR.
