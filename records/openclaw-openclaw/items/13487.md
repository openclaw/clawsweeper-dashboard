## Summary

Keep open: current main still does not implement the requested Discord mention > reply-target > default-owner precedence, and the remaining behavior changes who receives existing multi-bot channel traffic, so it needs maintainer product direction before a fix PR.

## What This Changes

The issue requests deterministic Discord multi-bot routing where explicit bot mentions win first, native replies to a bot win second, and the per-channel default owner responds only when no target signal exists.

## Best Possible Solution

Adopt one Discord-owned target-selection rule after maintainer confirmation: resolve configured bot mentions first, referenced bot authors second, and use the default owner only with no targeted signal, with focused preflight/routing tests and live or redacted Discord proof on the resulting PR.
