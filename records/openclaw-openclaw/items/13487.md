## Summary

Keep open: current main still lacks strict Discord active-target precedence; routing is resolved before cross-bot mention/reply target selection, and the existing mention decision has no default-owner suppression result for messages targeting another configured bot.

## What This Changes

Issue requests Discord multi-bot routing precedence where explicit bot mentions beat native reply targets and both suppress the per-channel default owner.

## Best Possible Solution

Maintainers should confirm the Discord active-target contract, then implement Discord-owned target selection before shared default routing using configured bot-user-id to account/agent mapping, with untagged messages preserving the default-owner path.
