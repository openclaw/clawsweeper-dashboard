## Summary

Keep open: current main and v2026.6.11 still expose Telegram topic names only after a numeric topic/thread id is known, so reliable name-to-topic_id routing remains a product/API decision rather than implemented cleanup.

## What This Changes

The issue requests first-class Telegram forum topic-name to topic_id resolution so agents can route messages by human-readable topic names.

## Best Possible Solution

Design a Telegram-owned observed-topic catalog, list action, or resolver that returns topic ids, names, closed state, freshness, and explicit ambiguity/staleness errors before agents route by name.
