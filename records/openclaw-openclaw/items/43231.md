## Summary

Keep open: current main still does not provide a reliable Telegram forum topic-name to topic_id resolver/list/catalog for agent routing; existing and related work only exposes or displays topic names after a numeric chat/topic is already known.

## What This Changes

Request first-class Telegram forum topic-name to topic_id resolution, listing, or catalog metadata so agents can route messages by human-readable topic name.

## Best Possible Solution

Keep this as the canonical product/API decision and add a Telegram-owned observed-topic catalog or resolver with explicit ambiguity, freshness, closed-topic, and unknown-topic behavior before allowing agents to route by name.
