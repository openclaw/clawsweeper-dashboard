## Summary

Keep open: current main and the latest release still only resolve Telegram forum topic names after a numeric topic/thread id is already known, so name-to-topic_id routing remains unresolved and needs a maintainer API/product choice.

## What This Changes

Request first-class Telegram forum topic-name to topic_id resolution for agent routing, such as a topic map, list action, resolver, or metadata endpoint.

## Best Possible Solution

Design a Telegram-owned observed-topic catalog or resolver action that returns known topic ids, names, closed/freshness state, and ambiguity errors before routing by name.
