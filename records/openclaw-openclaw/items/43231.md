## Summary

Keep open: current main and v2026.6.11 still route Telegram forum targets by numeric topic/thread ID, while the implemented topic-name cache only exposes names after the chat and thread ID are already known. The remaining name-to-ID resolver, list, or catalog surface needs maintainer product direction.

## What This Changes

The issue requests first-class Telegram forum topic-name to topic_id resolution so agents can route messages by human-readable topic name.

## Best Possible Solution

Keep this as the canonical tracker and design a Telegram-owned observed-topic catalog, list action, or resolver that maps known topic names to IDs with explicit stale, duplicate, renamed, closed, and unknown-topic behavior.
