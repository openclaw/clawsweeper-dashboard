## Summary

Keep open: current main and the latest release still expose Telegram forum topic names only after a numeric topic/thread id is already known, and the remaining name-to-topic_id routing surface needs a maintainer product/API decision.

## What This Changes

Request first-class Telegram forum topic-name to topic_id resolution for agent routing, via a context map, list action, or metadata/catalog surface.

## Best Possible Solution

Design a Telegram-owned observed-topic catalog, list action, or resolver that maps known topic names to IDs with explicit stale, duplicate, renamed, and closed-topic behavior.
