## Summary

Keep open: current main still supports numeric Telegram forum topic routing and observed id-to-name topic metadata, but it does not provide the requested forward topic-name to topic_id resolver or catalog for agent routing.

## What This Changes

Request a first-class Telegram forum topic catalog or resolver so agents can route by human-readable topic name instead of requiring numeric topic_id values.

## Best Possible Solution

Keep this as the canonical tracker and design a Telegram-owned observed-topic catalog, list action, or resolver with explicit duplicate-name, stale-data, rename, and closed-topic behavior.
