## Summary

Keep open: current main and the latest release still require numeric Telegram topic/thread ids for routing; merged work now exposes topic names after an id is known, but it does not provide the requested name-to-topic_id resolver, topic-list action, or catalog surface.

## What This Changes

The issue requests reliable Telegram forum topic-name to topic_id resolution for agent routing.

## Best Possible Solution

Add a Telegram-owned, agent-visible topic catalog or lookup surface backed by the existing topic-name cache and create/edit observations, with explicit ambiguity, freshness, and numeric-id fallback semantics.
