## Summary

Keep open: current main and the latest release still expose Telegram forum topic names only after a numeric topic/thread id is already known; they do not provide the requested name-to-topic_id resolver, topic list action, or catalog surface for agent routing.

## What This Changes

The issue requests reliable Telegram forum topic-name to topic_id resolution for agent message routing.

## Best Possible Solution

Keep this as the canonical tracker and design a Telegram-owned observed-topic catalog, list action, or resolver that maps known topic names to IDs with explicit stale, duplicate, renamed, and closed-topic behavior.
