## Summary

Keep open: current main and the latest release still provide numeric Telegram topic routing plus observed id-to-name metadata, but they do not provide the requested topic-title-to-topic_id resolver or topic catalog for agent routing.

## What This Changes

The issue requests first-class Telegram forum topic name resolution for agent routing, either through session context, a list/topics action, or a channel metadata endpoint.

## Best Possible Solution

Keep this as the canonical tracker and design a Telegram-owned observed-topic catalog, list action, or resolver with explicit freshness, duplicate-name, closed-topic, and numeric-ID fallback behavior.
