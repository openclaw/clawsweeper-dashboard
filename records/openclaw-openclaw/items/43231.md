## Summary

Keep open: current main and the latest release still expose Telegram topic names only after a numeric topic/thread id is already known, while this issue asks for reliable name-to-topic_id routing.

## What This Changes

Requested first-class Telegram forum topic name-to-topic_id resolution for agent routing without manual numeric topic maps.

## Best Possible Solution

Add a Telegram-owned observed-topic catalog, list action, or resolver that maps known topic names to IDs with explicit stale, duplicate, renamed, and closed-topic behavior.
