Keep open: current main and v2026.6.11 still support Telegram forum topic routing only by numeric topic/thread id, while the merged topic-name work exposes id-to-name metadata after the id is already known. ## What This Changes

The issue asks for first-class Telegram forum topic-name to topic_id resolution so agents can route messages to Telegram forum topics by human-readable title.

## Best Possible Solution

Add a Telegram-owned observed-topic catalog, list action, or resolver backed by the existing cache, returning structured ambiguity and freshness so routing never guesses the wrong topic.
