## Summary

Keep open: current main still only resolves Telegram forum topic names after a numeric topic/thread id is already known, while this issue asks for a first-class name-to-topic_id routing surface.

## What This Changes

Request first-class Telegram forum topic-name to topic_id resolution for agent routing, such as a topic catalog, resolver, or forum_topics context map.

## Best Possible Solution

Design a Telegram-owned observed-topic catalog, list action, or resolver that maps known topic names to IDs with explicit stale, duplicate, renamed, and closed-topic behavior.
