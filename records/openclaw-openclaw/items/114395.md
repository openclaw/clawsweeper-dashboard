## What This Changes

This PR extends existing channel account/setup SDK helpers and migrates bundled channel plugins so runtime, status, and onboarding resolve selected accounts and replace conflicting credentials consistently.

## System Context

Bundled channel plugins read root and named channel configuration to choose an account for runtime, status, and setup. This refactor moves common account-listing, merged-config, and scoped credential-clearing behavior into plugin-SDK helpers, then returns the selected account data to each channel owner.
