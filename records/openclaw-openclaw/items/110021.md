## Summary

This PR fixes an important Matrix DM isolation bug, but its new identity-link key encoding is neither injective nor upgrade-safe: distinct opaque labels can still share a session, and existing `@`-prefixed linked-label sessions are not adopted. Likely related people: `lukeboyett` (medium confidence), who introduced the shared case-preservation registry that this PR extends.

## What This Changes

The branch preserves Matrix MXID case for channel-bearing DM session keys, extends store alias proof to direct/`dm` shapes, and percent-escapes leading `@` characters in identity-link canonical labels.

## Best Possible Solution

Use a collision-free linked-label encoding and add a safe, origin-verified migration or legacy-adoption path for pre-existing raw `@` identity-link session keys; cover fresh keys, `%`-prefixed labels, and upgrade continuity without cross-peer adoption.
