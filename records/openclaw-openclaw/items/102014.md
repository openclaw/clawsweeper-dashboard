## Summary

Keep open: current main still records `session.ended` immediately after `model.completed`/`trace.artifacts` and before embedded attempt cleanup. The open candidate https://github.com/openclaw/openclaw/pull/102063 is linked with closing syntax, so this issue should remain open until that PR lands or maintainers choose a different fix path.

## What This Changes

The issue requests that trajectory `session.ended` timestamps reflect the actual post-cleanup session lifecycle end instead of the final model completion time.

## Best Possible Solution

Land one focused embedded-runner fix that records `session.ended` after attempt cleanup and flushes after that final event, then close this issue from the merged PR.
