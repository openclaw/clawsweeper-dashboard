## Summary

Keep open: the report identifies a concrete current-main regression where foreground Gateway initialization is serialized behind a decorative animation. The issue is protected by the `maintainer` label and was filed immediately after the introducing merge, with no linked fix. Likely related people: @steipete has high-confidence provenance from introducing the banner behavior and taking the issue assignment.

## What This Changes

Remove the foreground Gateway readiness delay caused by awaiting the animated claw banner before startup initialization.

## Best Possible Solution

Start Gateway tracing and runtime initialization immediately, run the banner concurrently only for eligible foreground terminals, and give normal startup output a way to settle the animation and restore terminal state; keep wizard callers fully awaited and add ordering plus terminal-cleanup regression coverage.
