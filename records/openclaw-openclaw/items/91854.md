## Summary

Keep open: current main and the latest release still route memory-core Dream Diary narrative runs through the generic plugin subagent runtime with no no-tools or allowlist field, so the reported mutating-tool exposure remains unresolved.

## What This Changes

## Best Possible Solution

Add a typed plugin-subagent no-tools or explicit allowlist contract through PluginRuntime, the gateway agent protocol, and the embedded runner, then use it for memory-core diary lanes with focused regression coverage.
