## Summary

Keep open: current main still runs memory-core Dream Diary narrative subagents without a tool restriction, and the plugin runtime plus gateway bridge still cannot carry a no-tools or `toolsAllow` policy for that prose-only lane.

## What This Changes

The issue asks to prevent memory-core dreaming narrative and REM prose subagents from receiving `apply_patch` or other file-mutation tools.

## Best Possible Solution

Add a typed plugin subagent tool restriction and use an explicit no-tools policy for memory-core narrative runs, coordinated with the broader subagent `toolsAllow` design rather than relying on prompt wording alone.
