## Summary

Keep open: current main and the latest release still start memory-core Dream Diary narrative runs through the generic plugin subagent path without a tool restriction, while `apply_patch` remains enabled by default when shell tools are available. The reported fallback limits observed impact to log noise, but the unnecessary mutation-tool exposure remains.

## What This Changes

The issue asks OpenClaw to keep memory-core Dream Diary narrative and REM subagent runs prose-only so they cannot call `apply_patch` while generating diary text.

## Best Possible Solution

Add a maintainer-approved plugin subagent tool-scoping contract, then make memory-core narrative runs request a text-only or mutation-denied tool surface with regression coverage.
