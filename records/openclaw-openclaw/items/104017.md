## What This Changes

The PR intends to give ordinary Zalo Bot API requests a 30-second abort deadline while preserving explicit per-call and long-poll deadlines.

## System Context

The Zalo plugin converts outgoing messages, media, chat actions, and webhook setup into Bot API HTTP calls. Its API client selects a deadline, performs `fetch`, reads the response body, and returns either the parsed result or an abort error to the channel runtime.
