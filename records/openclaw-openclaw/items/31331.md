## What This Changes

This issue requests Docker Gateway/DooD sandbox workspaceAccess binds to use host-resolvable paths instead of Gateway-container-internal paths.

Keep this as the canonical broader issue until maintainers choose and land one security-reviewed DooD host-path contract for workspaceAccess, managed skill mounts, browser mounts, docs, and live Docker proof.
