## What This Changes

Make Docker-installed Gateway sandbox workspaceAccess use host-resolvable workspace bind sources in Docker-outside-of-Docker setups instead of container-internal paths.

## Best Possible Solution

Define one security-reviewed Docker Gateway/DooD path contract for managed workspace, agent workspace, materialized skills, and browser mounts, document it, and close this cluster only after live DooD proof.
