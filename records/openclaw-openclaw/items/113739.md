## Summary

Keep this PR open: the latest branch adds useful ordering coverage, but the new 10-second handoff timeout can reject before DTMF is sent, turning a late-tone problem into a dropped-tone failure when stream termination is not observed. It also still needs inspectable, redacted real-call evidence; likely related person: zeno-codebot (low confidence, authored the proposed Twilio handoff changes).

## What This Changes

The PR changes Twilio realtime-call handling so buffered stream audio is cleared and the media stream ends before a DTMF redirect, then resumes the realtime stream through a signed callback URL.

## System Context

The voice-call plugin receives a DTMF request during an active Twilio Media Stream. It must stop or flush realtime audio, switch Twilio to DTMF playback, and then restore the realtime stream without treating the signed callback as a replay.
