## What This Changes

The PR flushes queued Twilio Media Stream audio and waits for the realtime stream to end before redirecting a live voice call to emit DTMF digits.

## System Context

The voice-call extension receives a DTMF request for a live Twilio call, maps that call to its active Media Stream, and updates TwiML to move the call into the IVR action. The realtime WebSocket handler reports stream termination back to the Twilio provider so the provider can sequence that transition.
