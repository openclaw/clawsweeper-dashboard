## What This Changes

Adds a one-second deadline to SQLite’s fallback `mount` classification probe and selects rollback journaling when that probe times out.

## Best Possible Solution

Land the bounded probe and conservative timeout fallback after exact-head checks complete, while retaining the existing classification behavior for successful probes and ordinary command failures.
