## Summary

Keep this PR open: it usefully bounds the fallback probe, but the database-open path still synchronously waits on an external command, and the latest head lacks supported-host proof for the resulting startup and journal-mode behavior.

## What This Changes

Adds a one-second timeout to fallback SQLite mount classification, selects rollback journaling on timeout, and expands the associated WAL-policy tests.

## Best Possible Solution

Move filesystem classification outside synchronous database opening, carry or cache the prepared classification result, retain conservative rollback behavior when classification is unavailable, and prove local and network-backed behavior on a supported macOS/BSD host.
