## Summary

The PR addresses a real current-main startup hang, but the latest head still performs the external mount probe synchronously during database open, so the prior P1 blocker remains; the supplied evidence also uses a test-only stalled-command fixture rather than a supported host.

## What This Changes

Adds a one-second timeout to fallback mount classification, chooses rollback journaling on timeout, and expands SQLite WAL-policy regression coverage.

## Best Possible Solution

Prepare filesystem classification once outside the synchronous database-open critical path, reuse the process-stable result for subsequent databases, and conservatively select rollback journaling when no prepared classification is available.
