## What This Changes

The PR replaces the earlier `toolsAllow` proposal with a `sessions_spawn.tools` policy (`"none"` or allow/deny rules) that is persisted on native child sessions and filters the tools exposed to each child turn.

## System Context

`sessions_spawn` creates native child-agent sessions from an agent turn. This change stores a tool restriction on the child session, resolves it during later runs, and applies it as a final filter before tool schemas are sent to the child model or a CLI harness.
