## What This Changes

This PR replaces the proposed per-spawn `toolsAllow` list with an immutable `sessions_spawn.tools` policy (`"none"` or allow/deny rules), stores it on the child session, and filters the child’s model-facing tools on initial and follow-up runs.

## System Context

`sessions_spawn` creates native child-agent sessions. This change carries a requested capability restriction into the child session record, resolves it during later agent turns, and applies it to the tool list supplied to the model and inherited by descendant subagents.
