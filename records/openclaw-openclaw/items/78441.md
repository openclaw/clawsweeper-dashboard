## What This Changes

This PR adds an immutable `sessions_spawn.tools` policy (`"none"` or allow/deny rules) that persists on native child sessions and restricts the tools exposed on subsequent child turns.

## System Context

`sessions_spawn` creates native child-agent sessions, whose persisted session entry is later read while OpenClaw assembles the child model's tool list. This change carries a per-spawn policy from the spawn request into that session state, the tool-policy pipeline, and the embedded or CLI runtime boundary.
