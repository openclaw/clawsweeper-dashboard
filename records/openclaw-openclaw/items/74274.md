  - body: `buildAssistantAttachmentDownloadUrl` appends `download=1` to every non-image attachment URL. When `buildAssistantAttachmentUrl` returns a documented remote or signed URL, this changes the URL and can invalidate the download; keep external hrefs unchanged and only add server download parameters to the local assistant-media route.

  - body: The new `filename="..."` header interpolates `path.basename(localPath)` directly. Non-ASCII names can make Node reject the header and the surrounding catch will turn the download into a 404, so use an ASCII fallback plus `filename*` and cover Unicode filenames.
  - confidence: 0.84
