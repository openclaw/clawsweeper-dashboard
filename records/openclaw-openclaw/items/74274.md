Full review comments:

- **[P2] Do not mutate external attachment URLs:** `ui/src/ui/chat/grouped-render.ts:963-964`
  - body: `buildAssistantAttachmentDownloadUrl` appends `download=1` to every non-image attachment URL, including remote URLs returned unchanged by `buildAssistantAttachmentUrl`. That can break signed or cache-keyed document/audio/video links; keep the URL stable and rely on the `download` attribute or same-origin gateway headers for local media.
  - confidence: 0.84
- **[P2] Encode filenames before setting Content-Disposition:** `src/gateway/control-ui.ts:521-522`
  - body: The new header interpolates the basename directly after stripping only quotes and newlines. Node rejects non-Latin1 header values, so a file such as `価格.md` will throw inside this route and fall through to the 404 handler; use an ASCII fallback plus `filename*` encoding before setting the header.
  - confidence: 0.88
