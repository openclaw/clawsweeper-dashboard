## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Keep external attachment URLs unchanged:** `ui/src/ui/chat/grouped-render.ts:964`
  - body: `buildAssistantAttachmentDownloadUrl` appends `download=1` to every non-image attachment URL. Because `buildAssistantAttachmentUrl` returns remote and other non-local sources unchanged, this mutates signed URLs, data URLs, and third-party file links before the user clicks them, which can turn a working assistant attachment into a 404 or invalid download. Only add route-specific query parameters to OpenClaw-owned assistant-media URLs, and leave external sources unchanged.
  - confidence: 0.88
- **[P1] Encode Content-Disposition filenames:** `src/gateway/control-ui.ts:522`
  - body: This writes the raw basename into `Content-Disposition` after only stripping quotes and newlines. Node rejects header values containing characters like `報告.md`, so a valid local markdown/download attachment with a non-ASCII filename falls into the handler catch path and is returned as not found. Use an ASCII fallback plus `filename*` encoding, or an existing safe disposition helper, before setting the header.
  - confidence: 0.9
