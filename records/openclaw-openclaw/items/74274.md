## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Preserve remote attachment URLs when adding downloads:** `ui/src/ui/chat/grouped-render.ts:963-964`
  - body: `buildAssistantAttachmentUrl` returns remote sources unchanged, but this helper appends `download=1` to every non-image attachment URL. That can invalidate signed URLs or change external resources, and cross-origin `download` attributes are not a reliable replacement for the existing link behavior. Only add the query/download handling for same-origin routes that honor it, and keep remote hrefs unchanged.
  - confidence: 0.88
- **[P1] Encode Content-Disposition filenames:** `src/gateway/control-ui.ts:522`
  - body: This interpolates the raw basename into an HTTP header. Node rejects non-Latin-1 header values such as Chinese filenames with `ERR_INVALID_CHAR`; because this runs inside the route's catch block, a valid markdown/download file can become a 404. Use a safe ASCII fallback plus `filename*` encoding or an existing disposition helper.
  - confidence: 0.9
