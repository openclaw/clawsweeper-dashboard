This PR adds `/stream` and `/streaming` commands that persist a per-session preview-streaming mode and apply it to Telegram, Discord, and Slack preview and progress delivery.

## System Context

OpenClaw receives an authorized chat command, stores a session-level streaming override, and the supported channel plugins read that override before constructing preview and progress messages. The result changes preview transport, tool-progress rendering, and final-message behavior for the active conversation without changing the channel’s saved configuration.
