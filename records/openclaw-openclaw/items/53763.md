## Summary

Keep open. Current main has a managed browser, Chrome extension relay, and cookie-persistence improvements, but the central request is still missing because `web_fetch` and `web_search` remain non-rendering HTTP/provider tools while JS-heavy and logged-in pages are routed to the separate browser tool.

## What This Changes

The issue requests built-in browser-backed web access so web research works reliably on JavaScript-heavy, logged-in, bot-protected, or proxy-sensitive pages without separate external setup.
