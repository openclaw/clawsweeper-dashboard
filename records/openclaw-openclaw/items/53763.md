## Summary

Keep open. Current main and v2026.6.11 already ship a Playwright-backed browser plugin, but the central request is still missing: `web_fetch` and `web_search` remain HTTP/provider paths, while browser-rendered extraction with session, proxy, packaging, and security semantics still needs maintainer design.

## What This Changes

The issue requests a bundled headless Chromium-backed web access layer for JS-rendered, login-required, and headless/server pages without depending on user Chrome, Tavily, or other external services.

## Best Possible Solution

Keep this as the canonical browser-backed web-access design tracker, then split approved work into plugin-owned rendered extraction, benchmarked fallback semantics, session/proxy policy, and security acceptance criteria.
