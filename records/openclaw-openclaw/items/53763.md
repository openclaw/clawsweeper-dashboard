## Summary

Keep open. Current main and v2026.6.11 have a bundled Playwright/CDP browser plugin, but the requested browser-backed web-access layer is still missing: `web_fetch` remains HTTP/provider extraction, `web_search` remains provider-backed, and browser automation is a separate tool with security/session/proxy decisions still unresolved.

## What This Changes

Request to make headless Chromium a first-class OpenClaw web-access path for JS-rendered, login-required, and headless/server pages without relying on a user's Chrome or third-party APIs.

## Best Possible Solution

Keep this as the canonical product/security design tracker, then split any approved direction into narrow work for rendered extraction semantics, browser runtime packaging, session persistence, proxy policy, and benchmarked acceptance criteria.

- **Move extraction to plugins:** Require browser-backed extraction to be provided by a plugin or external provider unless core/plugin APIs are proven insufficient.
