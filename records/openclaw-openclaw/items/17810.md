## Summary

Keep open: current main and the latest release still render SOUL/IDENTITY/USER/MEMORY-style bootstrap files as Project Context entries without a configurable elevation/exclusion surface, and the remaining choice is a prompt/config/plugin API product decision rather than a stale cleanup target.

## What This Changes

The issue requests configurable elevation of selected bootstrap files such as SOUL.md, IDENTITY.md, USER.md, and MEMORY.md into dedicated prompt sections with optional exclusion from the flat Project Context block.

## Best Possible Solution

A maintainer should choose the durable prompt/context contract first, then land one narrow implementation with schema/types, docs, tests, and cache-ordering behavior aligned to that contract.
