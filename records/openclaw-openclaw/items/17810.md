## Summary

Keep open. Current main and the latest release still render SOUL.md, IDENTITY.md, USER.md, and MEMORY.md as ordinary Project Context entries with no configurable elevation or exclusion surface, and the remaining blocker is a maintainer product/API decision rather than missing source evidence.

## What This Changes

The issue requests configurable elevation of selected bootstrap/context files into dedicated prompt sections instead of rendering them as ordinary Project Context files.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole system prompt.

## Reproduction Assessment

Yes at source level: current main still renders the relevant files as Project Context entries and exposes no elevation/exclusion config. The reported long-session persona drift itself was not live-reproduced in this read-only review.
