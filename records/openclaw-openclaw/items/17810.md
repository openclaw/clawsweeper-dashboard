## Summary

Keep open: current main and v2026.6.11 still lack configurable per-file elevation/exclusion for SOUL.md, IDENTITY.md, USER.md, and MEMORY.md; the direct implementation PR is closed unmerged, and the remaining blocker is product/API direction rather than conservative cleanup.

## What This Changes

The issue requests a configurable prompt/context surface that can elevate selected bootstrap files into dedicated sections and optionally exclude them from flat Project Context rendering.

## Best Possible Solution

Maintainers should choose one supported context-customization surface, then either add a narrow typed elevation/exclusion config with schema/docs/tests or extend the plugin/context-engine contract so external code can implement it cleanly.
