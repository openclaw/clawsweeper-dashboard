## Summary

Keep open. Current main and latest release still render the requested SOUL/IDENTITY/USER/MEMORY-style files as ordered Project Context entries, with no typed elevation/exclusion config; the remaining blocker is a maintainer product/API decision, not missing source evidence.

## What This Changes

Request to make selected workspace context files render as dedicated prompt sections and optionally exclude them from the flat Project Context block.

## Best Possible Solution

Define one supported context customization contract: either typed core config for deterministic per-file elevation/exclusion, or a plugin/context-engine API that can do that without replacing the whole OpenClaw system prompt.

## Reproduction Assessment

Yes. Source inspection is enough to verify the gap: current main renders the relevant bootstrap files as flat Project Context entries and exposes no elevation config.

## Solution Assessment

Unclear. The requested behavior is plausible, but the best maintainable solution still depends on maintainer direction for typed core config versus a plugin/context-engine API extension.
