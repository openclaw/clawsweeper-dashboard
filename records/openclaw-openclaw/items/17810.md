## Summary

Keep open. Current main and v2026.6.11 still do not expose configurable per-file prompt-section elevation or Project Context exclusion for SOUL.md, IDENTITY.md, USER.md, and MEMORY.md; the exact implementation PR is closed unmerged, and the remaining blocker is maintainer product/API direction.

## What This Changes

Request configurable elevation and optional exclusion of selected bootstrap context files into named system-prompt sections instead of rendering them as flat Project Context entries.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole system prompt.

## Reproduction Assessment

Yes, at source level: current main still renders the relevant files as Project Context entries and exposes no elevation or exclusion config. The long-session persona drift itself was not live-reproduced in this read-only review.

## Solution Assessment

Unclear as proposed. The requested context.elevation shape is plausible, but the best maintainable solution needs maintainer agreement on core config versus plugin/context-engine ownership.
