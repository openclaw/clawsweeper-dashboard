## Summary

Keep open. Current main and the latest release still render SOUL/IDENTITY/USER/MEMORY-style bootstrap files as ordered Project Context entries rather than configurable elevated sections, and the exact implementation attempt is closed unmerged, leaving a real prompt/config product decision.

## What This Changes

Requests configurable elevation and optional exclusion of selected bootstrap files into named system-prompt sections.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole system prompt.

## Reproduction Assessment

Yes at source level: current main and v2026.6.11 render the relevant bootstrap files as Project Context entries and expose no elevation/exclusion config. The long-session persona drift itself was not live-reproduced in this read-only review.

## Solution Assessment

Unclear as proposed. The requested context.elevation shape is plausible, but the best maintainable solution needs maintainer agreement on core config versus plugin/context-engine ownership.
