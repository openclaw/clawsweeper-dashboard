## Summary

Keep open: current main and latest release still do not provide configurable per-file elevation or Project Context exclusion for SOUL/IDENTITY/USER/MEMORY-style files, and the remaining question is the accepted prompt/config/plugin API boundary rather than conservative cleanup.

## What This Changes

Request configurable elevation of selected bootstrap/context files into dedicated prompt sections, with optional exclusion from the flat Project Context rendering.

## Best Possible Solution

Maintainers should choose one supported context-customization surface, then either add a narrow typed elevation/exclusion config with schema/docs/tests or document and extend the plugin/context-engine contract so external code can implement it cleanly.
