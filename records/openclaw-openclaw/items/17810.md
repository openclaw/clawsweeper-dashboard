## Summary

Keep open. Current main and v2026.6.11 still do not provide configurable per-file elevation or Project Context exclusion for SOUL.md, IDENTITY.md, USER.md, and MEMORY.md; the closed implementation PR is not a viable landing path, so the remaining blocker is maintainer product/API direction.

## What This Changes

The issue requests a configurable prompt-context elevation surface that can render selected bootstrap files as named prompt sections and optionally exclude them from flat Project Context.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole system prompt.

## Reproduction Assessment

Yes at source level: current main renders the relevant files as Project Context entries and exposes no elevation/exclusion config. The reported long-session persona drift itself was not live-reproduced in this read-only review.

## Solution Assessment

Unclear as proposed. The requested `context.elevation` shape is plausible, but the best maintainable solution needs maintainer agreement on core config versus plugin/context-engine ownership.
