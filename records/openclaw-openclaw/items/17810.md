## Summary

Keep open. Current main and v2026.6.11 still render these bootstrap files as ordered but flat Project Context entries and expose no configurable elevation/exclusion surface; the remaining blocker is maintainer product/API direction rather than missing source evidence.

## What This Changes

The issue requests configurable elevation of selected bootstrap/context files into dedicated system-prompt sections instead of rendering them only as flat Project Context entries.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole system prompt.

## Reproduction Assessment

Yes at source level: current main still renders the relevant files as Project Context entries and exposes no elevation/exclusion config. The long-session persona drift itself was not live-reproduced in this read-only review.
