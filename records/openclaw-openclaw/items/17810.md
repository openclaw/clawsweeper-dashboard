## Summary

Keep open. Current main still lacks configurable per-file prompt-section elevation or Project Context exclusion for SOUL.md, IDENTITY.md, USER.md, and MEMORY.md; adjacent Codex-specific handling and SOUL.md guidance help some paths but do not implement the requested OpenClaw prompt/config contract.

## What This Changes

The issue requests configurable elevation of selected bootstrap/context files into dedicated system-prompt sections instead of rendering them as ordinary Project Context files.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole system prompt.

## Reproduction Assessment

Yes at source level: current main still renders the relevant non-Codex bootstrap files as Project Context entries and exposes no elevation/exclusion config. The long-session persona drift itself was not live-reproduced in this read-only review.

## Solution Assessment

Unclear as proposed. The requested context.elevation shape is plausible, but the best maintainable solution needs maintainer agreement on core config versus plugin/context-engine ownership.
