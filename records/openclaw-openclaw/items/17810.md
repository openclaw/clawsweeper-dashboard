## Summary

Keep open. Current main and the latest release still render these bootstrap files as ordered but flat Project Context entries, with no configurable per-file elevation or exclusion surface; the linked implementation PR is closed unmerged and the remaining decision is the accepted prompt/config or plugin/context-engine API shape.

## What This Changes

The issue requests configurable elevation of selected bootstrap/context files into dedicated system-prompt sections instead of rendering them only as flat Project Context entries.

## Best Possible Solution

Maintainers should choose one supported context customization surface: either a documented typed core config for deterministic per-file elevation/exclusion, or a plugin/context-engine API that can map bootstrap files into dedicated prompt sections without replacing the whole OpenClaw system prompt.

## Reproduction Assessment

Yes. Source inspection is enough to reproduce the gap: current main renders SOUL.md, IDENTITY.md, USER.md, and MEMORY.md as flat Project Context files and exposes no elevation config.
