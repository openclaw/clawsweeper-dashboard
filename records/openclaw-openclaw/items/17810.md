## Summary

Keep open: current main and v2026.6.11 still lack the requested per-file elevation/exclusion surface, and the remaining blocker is a prompt/config API product decision rather than conservative cleanup.

## What This Changes

The issue requests configurable elevation of SOUL.md, IDENTITY.md, USER.md, and MEMORY.md into dedicated prompt sections outside the flat Project Context block.

## Best Possible Solution

Maintainers should choose one supported context customization surface, then either add a documented typed core config for deterministic per-file elevation/exclusion or extend the context-engine/plugin contract so external code can map bootstrap files into canonical prompt sections.

- **Reject elevation as core behavior:** Leave Project Context flat and direct users to context-engine plugins or manual prompt additions for persona-specific weighting.
