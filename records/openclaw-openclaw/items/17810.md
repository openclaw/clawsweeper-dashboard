## What This Changes

Request configurable prompt-section elevation and Project Context exclusion for selected bootstrap context files such as SOUL.md, IDENTITY.md, USER.md, and MEMORY.md.

## Best Possible Solution

Maintainers should choose one supported context customization surface: either a documented typed core config for deterministic per-file elevation/exclusion, or a plugin/context-engine API that can map bootstrap files into dedicated prompt sections without replacing the whole OpenClaw system prompt.

## Reproduction Assessment

Yes at source level: current main still renders the relevant files as Project Context entries and exposes no elevation/exclusion config. The reported long-session persona drift itself was not live-reproduced in this read-only review.

## Solution Assessment

Unclear as proposed. The requested `context.elevation` shape is plausible, but the best maintainable solution needs maintainer agreement on core config versus plugin/context-engine ownership and native/non-Codex prompt parity.
