## Summary

Keep open. Current main and v2026.6.11 still render SOUL/IDENTITY/USER/MEMORY-style files as ordered but flat Project Context entries, the requested elevation/exclusion config is absent, and the direct implementation PR is closed unmerged; the remaining blocker is maintainer product/API direction.

## What This Changes

The issue requests configurable elevation of selected bootstrap/context files into dedicated prompt sections instead of rendering them as ordinary Project Context entries.

## Best Possible Solution

Maintainers should choose one prompt/context contract, then implement either documented typed elevation/exclusion config or a narrower plugin/context-engine API that can place selected bootstrap files into named sections without replacing the whole OpenClaw prompt.

## Reproduction Assessment

Yes at source level: current main still renders the relevant files as Project Context entries and exposes no elevation/exclusion config. The long-session persona drift itself was not live-reproduced in this read-only review.

## Solution Assessment

Unclear as proposed. The requested context.elevation shape is plausible, but the best maintainable solution needs maintainer agreement on core config versus plugin/context-engine ownership.
