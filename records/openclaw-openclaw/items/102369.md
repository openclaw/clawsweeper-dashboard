## Summary

This PR remains open because its memo identity can reuse an exec authorization after the resolved executable changes, and its unchanged head still lacks real configured proof. Current main explicitly binds gateway review to a canonical executable, while node review has no equivalent identity.

**Likely related people:** @samzong is a recent exec-approval contributor (medium confidence); @HOYALIM explored the narrower gateway-only, resolved-path-bound design in the related PR (medium confidence).

## What This Changes

Adds a bounded per-reviewer FIFO memo for low-risk `allow-once` exec-review verdicts, with tests for cache hits, context changes, and eviction.

## Best Possible Solution

Memoize only low-risk gateway verdicts with a non-empty canonical `resolvedPath`, include that path in the key, never reuse node-host verdicts, and prove same-path hits plus changed-path misses in a configured runtime.
