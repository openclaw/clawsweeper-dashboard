The contributor’s evidence exercises the real parser and memo with mocked model preparation/completion, so real configured behavior proof is still required before merge.

The PR adds a bounded per-reviewer memo for low-risk `allow-once` exec verdicts and regression tests for identical requests, context changes, and FIFO eviction.
