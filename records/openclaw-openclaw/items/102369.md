## Summary

This PR remains necessary because current main still performs a fresh model review per request, but the proposed reuse is not merge-ready: the memo identity shown on the latest hydrated patch omits the canonical resolved executable, applies across node and gateway hosts, and the supplied runtime evidence still mocks the completion boundary.

## What This Changes

The PR adds a bounded per-reviewer memo for low-risk `allow-once` exec-review verdicts and regression tests for repeated requests, context changes, and FIFO eviction.

## Best Possible Solution

Restrict memoization to completed low-risk gateway `allow-once` verdicts with a non-empty canonical `resolvedPath` included in the key, leave node requests uncached until their protocol exposes equivalent identity, retain a bounded cache, and provide configured runtime proof for an identical-path hit, changed-path miss, and node non-reuse.
