## Summary

The indefinite-hang bug is valid and the real hung-socket proof is strong, but this head is not merge-ready because its fixed 120-second batch cap undercuts the provider’s existing 10-minute inline batch contract and can break slow unsignaled gateway or capability callers.

## What This Changes

The branch adds query and batch timeout defaults for unsignaled OpenAI-compatible embedding requests, moves related header helpers into a new module, and adds hung-socket regression coverage plus test-only timeout overrides.

## Best Possible Solution

Make the generic gateway and capability runtime own query and batch AbortSignals from the provider’s declared operation budgets, while keeping any provider-level transport failsafe no shorter than the outer supported contract.
