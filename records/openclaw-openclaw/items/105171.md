## Summary

Keep this PR open for a provider-runtime owner decision: the hang fix is coherent and well proven, but it creates a provider-wide latency contract for a surface intentionally used by potentially slow self-hosted embedding servers.

## What This Changes

Adds 60-second query and 120-second batch transport timeouts for unsignaled OpenAI-compatible embedding calls, preserves caller-provided signals, and adds hung-socket regression coverage.

## Best Possible Solution

Make deadline ownership explicit at the gateway and capability-CLI callers or derive it from an existing embedding budget, preserve caller-owned signals, and validate both a hung upstream and a slow successful self-hosted endpoint.
