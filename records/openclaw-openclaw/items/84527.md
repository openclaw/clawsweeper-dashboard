## Summary

Keep this issue open: current main still exposes only the legacy `google-gemini-cli` local backend, while the concrete end-to-end Antigravity implementation is tracked by the open linked PR at https://github.com/openclaw/openclaw/pull/90975. ## What This Changes

Add an Antigravity `agy` CLI backend for Google-family agent execution while retaining the legacy Gemini CLI path for users who still have access.
