## Summary

This maintainer-authored PR addresses a reproduced Z.AI gateway regression with strong live proof and an appropriate provider-owned artifact seam, but the current head still collapses supported multi-plugin ownership into alphabetical first-match selection. Cold validation could therefore use a different official plugin’s thinking policy than the runtime provider, so the prior P1 remains merge-blocking.

## Best Possible Solution
