Land a narrow docs and diagnostic wording update that tells users how to distinguish the stale self-loop portproxy case from the observed IPv4/IPv6 CDP split and when to use `v4tov6`, without adding a misleading WSL-side `[::1]` auto-probe.

## Solution Assessment
