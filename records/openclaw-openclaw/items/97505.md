## Summary

Keep this PR open for maintainer review. The requested OpenRouter `/images` support and current-model catalog are still absent from current main, but this branch is conflicted and its new shared capability path must be reconciled with the current image-generation runtime before it can land.

## What This Changes

The PR adds six curated OpenRouter image models, routes those models through the `/images` API, and validates per-model image count, geometry, and reference-image limits.

## System Context

OpenClaw’s `image_generate` tool resolves configured provider/model candidates, normalizes supported overrides, and hands each request to a provider plugin. The OpenRouter plugin currently uses its chat-completions image route; this PR adds a second provider transport for newer OpenRouter image models.
