## What This Changes

This PR starts Control UI chat metadata alongside transcript startup and defers branches, discussion, companion, and pull-request hydration until the transcript has committed, aiming to make session switching responsive sooner.

## System Context

When a user switches sessions in the Control UI, the chat pane loads the transcript and then refreshes optional session-specific panels. This PR keeps transcript-critical startup on the first-render path while scheduling optional panels after the render commit and rejecting stale responses from prior sessions or connections.
