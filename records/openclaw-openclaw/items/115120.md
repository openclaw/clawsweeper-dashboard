## Summary

Keep this maintainer-authored PR open for normal review and merge gating. The patch is a focused repair for the linked sparse-worktree regression: it turns the script-owned PR worktree into a full checkout after containment is verified and before fetch/reset/gates, with coverage for both creation and reuse paths.

## What This Changes

The PR disables sparse checkout in contained script-owned PR worktrees before preparation gates run, and adds regressions for newly created and reused worktrees.

## System Context

`scripts/pr` prepares an isolated worktree for a pull request and then runs repository gates there. A sparse canonical checkout can otherwise leave tracked build inputs absent in that derived worktree, causing preparation failures before the actual PR is evaluated.
