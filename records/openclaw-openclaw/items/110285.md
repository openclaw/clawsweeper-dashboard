## Summary

This PR remains necessary as a feature-parity expansion of the merged Linux Quick Chat baseline, but it needs an explicit maintainer decision on whether agent-provided remote avatar URLs may broaden the Linux webview’s image-fetch trust boundary before merge.

## What This Changes

The branch adds Linux Quick Chat agent selection, avatar display, per-agent CLI routing, configurable and toggleable shortcuts, animation, supporting permissions/UI/docs, and an additive `identityAvatarUrl` field in agent summaries.

## Best Possible Solution

Define and document the Linux companion avatar-source policy, then enforce the approved boundary in avatar resolution and CSP while preserving the current additive summary field and the proven Quick Chat routing/shortcut behavior.
