## Summary

The linked sandbox bug is credible, but this PR is not merge-ready because the proposed fallback assumes Docker’s container root across a backend-generic path, while the current sandbox architecture treats each backend’s reported workdir as authoritative. The contributor also provides test results only, not a real full-sandbox run showing skill access succeeds.

## What This Changes

The PR resolves sandbox container workdirs earlier, changes missing skill-path workdirs to `/workspace`, and adds focused tests for full-sandbox skill path selection.

## Best Possible Solution

Carry one backend-authoritative container workdir through session preparation, skill materialization, and prompt-path mapping; avoid a generic Docker fallback, add non-Docker/custom-workdir regression coverage, and prove the original Docker full-sandbox workflow in a real container.
