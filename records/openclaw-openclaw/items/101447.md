## Summary

The patch is narrow, correct, and backed by standalone runtime proof, but it intentionally changes existing workspace behavior: identity files over 1 MiB and symlinked or non-regular `IDENTITY.md` paths become silently absent. That compatibility policy needs explicit maintainer acceptance before merge.

## What This Changes

The PR changes workspace `IDENTITY.md` loading to a 1 MiB bounded regular-file read and adds normal and oversized-file regression coverage.

## Best Possible Solution

Keep the bounded read, but merge only after maintainers explicitly choose whether silent rejection of oversized and non-regular identity files is the intended workspace contract; add a visible diagnostic if discoverability is required.
