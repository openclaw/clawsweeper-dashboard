## What This Changes

Add configurable outbound request throttling, pre-dispatch queueing, 429 backoff, usage and cost budgets, limit visibility, and management commands across external API calls.

## Best Possible Solution

Adopt an opt-in model-provider policy as a narrow first phase, with pre-dispatch request/token windows, bounded queue-or-fail behavior, reactive 429 handling, SQLite-backed accounting when persistence is required, and status visibility; retain transport-specific pacing in owning plugins and track monetary budgets plus broader tool/channel coverage separately.
