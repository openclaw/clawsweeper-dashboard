## Summary

Keep open: current main and the latest release only partly address this. Pre-compaction memory flush uses `agents.defaults.userTimezone`, but the bundled `session-memory` hook still formats filenames and `# Session` headers from host/TZ-local time and the docs describe that as the shipped behavior.

## What This Changes

The issue requests that generated memory filenames and `# Session` headers use `agents.defaults.userTimezone` instead of UTC or host-local time.

## Best Possible Solution

Have a maintainer decide the memory-artifact timezone contract; if alignment is accepted, update bundled session-memory to use the existing resolved user timezone helper, refresh tests/docs, and avoid adding a new config key.
