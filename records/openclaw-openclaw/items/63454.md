## Summary

Keep open: current main and the latest release still only partially address the report. Pre-compaction memory flush uses the configured `userTimezone`, but the bundled `session-memory` hook still formats filenames and `# Session` headers from host or `TZ` local time, so changing that shipped artifact contract needs maintainer product approval.

## What This Changes

The issue asks memory file dates and `# Session` headers to use `agents.defaults.userTimezone` or a dedicated memory timezone instead of UTC.

## Best Possible Solution

Define one memory-artifact timezone contract; if accepted, make `session-memory` reuse the existing configured-timezone helpers and update focused docs/tests without adding a new config knob unless maintainers explicitly approve it.
