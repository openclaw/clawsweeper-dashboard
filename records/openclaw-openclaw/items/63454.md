## Summary

Keep open: current main and the latest release still only partly address the request. The memory-core pre-compaction flush path uses `agents.defaults.userTimezone`, but the bundled session-memory hook still formats filenames, fallback slugs, and `# Session` headers from the host/`TZ` timezone, so the remaining behavior needs a maintainer product and compatibility decision.

## What This Changes

Respect `agents.defaults.userTimezone` for memory artifact filename dates and header timestamps instead of leaving memory files on UTC or host-local time.

## Best Possible Solution

Decide whether memory artifacts are part of the `userTimezone` contract; if yes, update bundled session-memory to reuse the existing configured-timezone helpers and align focused tests/docs without adding a new config key unless maintainers explicitly approve one.
