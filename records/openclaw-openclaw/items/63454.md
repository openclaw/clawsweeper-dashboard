## Summary

Keep open: current main still only partially satisfies the request. Memory-core auto-flush uses the configured user timezone for the canonical daily path, but the bundled session-memory hook still formats filenames and `# Session` headers from host or `TZ` local time, so changing that shipped behavior needs maintainer product approval.

## What This Changes

Request memory file filenames and header timestamps to follow `agents.defaults.userTimezone` instead of UTC or host-local time.

## Best Possible Solution

Maintainers should decide whether memory artifacts join the existing `userTimezone` contract; if accepted, reuse the configured-timezone helpers in session-memory and update focused tests/docs without adding a new timezone knob unless explicitly approved.
