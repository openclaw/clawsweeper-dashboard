## Summary

Keep open: current main and v2026.6.11 still only partly satisfy the request. The memory-core auto-flush path uses `agents.defaults.userTimezone`, but the bundled `session-memory` hook still formats filenames and `# Session` headers from `TZ` or the host timezone, so the remaining change needs a maintainer product decision.

## What This Changes

Request memory file filenames and header timestamps to respect `agents.defaults.userTimezone` instead of always using UTC or host-local time.

## Best Possible Solution

Maintainers should decide whether session-memory artifacts join the existing `userTimezone` contract; if accepted, reuse the configured-timezone helper path in the hook and update focused tests/docs without adding a new timezone knob unless explicitly approved.
