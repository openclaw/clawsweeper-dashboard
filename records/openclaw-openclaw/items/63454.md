## Summary

Keep open: current main and the latest release still only partly satisfy the request. Auto-flush memory uses the configured user timezone, but the bundled session-memory hook still formats filenames and `# Session` headers from host or `TZ` local time, so changing that shipped artifact contract needs maintainer product approval.

## What This Changes

The issue requests that memory artifact filenames and header timestamps respect `agents.defaults.userTimezone` or an explicit memory timezone setting.

## Best Possible Solution

Maintainers should decide whether memory artifacts join the `userTimezone` contract; if accepted, reuse the existing configured-timezone helpers in session-memory and update focused tests/docs without adding a new timezone knob unless explicitly approved.
