## Summary

Keep open: current main and v2026.6.11 only partly satisfy the request. Pre-compaction memory flush paths now use `agents.defaults.userTimezone`, but the bundled `session-memory` hook still formats filenames and `# Session` headers from the gateway host or `TZ` timezone, so the remaining behavior needs maintainer product approval rather than cleanup closure.

## What This Changes

The issue requests memory file names and memory headers to respect `agents.defaults.userTimezone` instead of UTC or host-local time.

## Best Possible Solution

Maintainers should decide whether memory artifacts join the existing `userTimezone` contract; if accepted, update session-memory to reuse configured-timezone helpers and focused tests/docs without adding a new timezone knob unless explicitly approved.
