## Summary

Keep open: current main and the latest release still leave the bundled session-memory hook on host or `TZ` local time, while the auto-flush path already uses `agents.defaults.userTimezone`; changing the remaining memory artifact contract needs maintainer product approval.

## What This Changes

The issue requests that generated memory-file names and session headers use the configured user timezone rather than UTC or host-local time.

## Best Possible Solution

Maintainers should first decide whether memory artifacts join the existing `userTimezone` contract; if accepted, update the bundled session-memory hook to reuse the existing configured-timezone helpers and add focused tests/docs without adding a new config key unless explicitly approved.
