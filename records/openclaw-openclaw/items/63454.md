## Summary

Keep open: current main and the latest release only partially address the report. Auto-flush now derives `memory/YYYY-MM-DD.md` from `agents.defaults.userTimezone`, but the bundled session-memory hook still formats slugged filenames and `# Session` headers from the host or `TZ` timezone.

## What This Changes

Request session-memory and memory-flush artifact filenames and header timestamps to use the configured `agents.defaults.userTimezone` or an explicit memory timezone setting.

## Best Possible Solution

Maintainers should decide whether memory artifacts join the `userTimezone` contract; if accepted, reuse the existing configured-timezone helpers in session-memory and update focused tests/docs without adding a new timezone knob unless explicitly approved.
