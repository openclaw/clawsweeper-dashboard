## What This Changes

This PR keys cron task-ledger rows to each run’s durable execution start time rather than its earlier scheduling reservation time, with recovery tests for scheduled and startup runs after a Gateway restart.

## System Context

The cron service reserves jobs, admits them for execution, writes a task-ledger row and cron history, and later uses those durable records during Gateway restart recovery. This change aligns the ledger identity with the actual execution start so recovery can distinguish completed work from a stale active marker.
