- **[P1] Guard inferred image input against custom endpoints:** `src/agents/models-config.merge.ts:164-167`
  - body: This gate treats any built-in provider key as provider-owned, but users can keep keys like `anthropic` or `openai` while preserving a custom `baseUrl` or transport config.   - confidence: 0.88

  - confidence: 0.84

  - body: The helper now defaults only when `opts.providerKey` names a built-in provider, but these new tests call `mergeProviderModels` without opts and still expect defaults; the `custom-anthropic` `mergeProviders` test also expects the opposite of the current built-in gate.
