## Summary

Keep this PR open: the runtime SQLite-only direction is valid, but the patch is not merge-ready because QQBot credential migration is not wired through the external plugin doctor contract and the detector can import HOME-global credentials across state roots.

## What This Changes

The PR removes QQBot legacy runtime JSON/JSONL imports, adds credential-backup migration through QQBot setup-entry metadata, updates startup preflight detection, and adjusts docs/tests around SQLite KV state.

## Best Possible Solution

Keep the runtime SQLite-only cleanup, but expose QQBot credential-backup migration through the external plugin doctor contract and keep automatic imports scoped to the active state root unless maintainers explicitly approve cross-root recovery.

## Reproduction Assessment

Yes. Source inspection shows the PR removes runtime JSON fallback while wiring credential migration only through a bundled setup-entry path that external packaged QQBot installs do not use.

## Solution Assessment

No. Moving imports out of runtime is the right boundary, but the migration has to be reachable through QQBot’s external doctor contract and should avoid automatic cross-state-root credential import.
