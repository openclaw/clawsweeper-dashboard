## Summary

Keep this PR open: bounding the six process probes is useful, but at least the watchdog identity helper rethrows timeout failures rather than following the claimed null-return path, and the PR provides no real behavior proof that quiescence and lease cleanup remain operational when `ps` stalls.

## What This Changes

Adds five-second SIGKILL timeouts to six synchronous `ps` probes in the workspace quiescence and renewal worker scripts.

## Best Possible Solution

Centralize the six probes behind one bounded helper that distinguishes process absence from timeout/unavailable state, keeps watchdog cleanup retryable, and includes focused generated-script coverage plus a redacted terminal run using a deliberately blocking `ps` shim.
