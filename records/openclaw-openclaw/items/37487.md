## Summary

Keep open: current main supports named browser profiles and isolated managed profile directories, but it still lacks first-class per-profile browser proxy config and agent/subagent browser-profile binding. The prior implementation PR was closed unmerged, and the open proxy and subagent-browser issues remain narrower overlapping design slices rather than replacements.

## What This Changes

Request first-class browser profile proxy configuration plus per-agent and subagent default browser-profile routing for isolated, concurrent browser sessions.

## Best Possible Solution

Define a maintainer-approved browser ownership and proxy contract covering SecretRef/env handling, SSRF/proxy trust semantics, process-argv and status redaction, per-agent and subagent inheritance/override, resource limits, diagnostics, docs, and focused upgrade tests.
