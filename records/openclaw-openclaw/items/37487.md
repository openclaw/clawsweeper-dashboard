## Summary

Keep open: current main still lacks first-class per-profile browser proxy config and per-agent/subagent browser-profile binding. The linked external projects and the closed unmerged implementation PR are useful design evidence, but this remains a product and security-boundary decision rather than conservative cleanup.

## What This Changes

The issue requests concurrent per-agent isolated browser instances with per-profile proxy support, agent/subagent profile binding, isolation diagnostics, and docs/examples.

## Best Possible Solution

Define a maintainer-approved browser ownership and proxy contract covering SecretRef/env handling, SSRF trust semantics, per-agent/subagent inheritance, resource limits, tab ownership, diagnostics, docs, and focused security tests.
