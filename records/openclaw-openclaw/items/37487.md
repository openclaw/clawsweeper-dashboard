## Summary

Keep open: current main and v2026.6.11 still lack first-class per-profile proxy config and `agents.*.browser.profile` binding, while existing support covers named profiles, explicit per-call profile selection, session tab cleanup, and global `browser.extraArgs` proxy flags. This remains a product/security design item because proxy credentials, SSRF behavior, logged-in browser ownership, subagent inheritance, and resource limits need maintainer direction.

## What This Changes

Request to add first-class per-agent browser isolation, per-profile outbound proxy configuration, and reliable concurrent browser execution semantics.

## Best Possible Solution

Keep this as the combined product/security tracker until maintainers approve a staged contract for browser profile proxying, proxy credentials, SSRF policy, agent/subagent browser ownership, inheritance, resource limits, diagnostics, docs, and tests.
