## Summary

Keep open: current main and v2026.6.11 still have named browser profiles and a global Chrome `extraArgs` proxy workaround, but they do not provide first-class per-profile proxy config or per-agent/subagent browser-profile binding. The linked browser-lock and FSB examples are useful prior art, but they reinforce that this needs a maintained product and security design rather than automatic cleanup.

## What This Changes

Request first-class per-agent and subagent browser isolation with per-profile proxy configuration, concurrent managed-browser guarantees, diagnostics, and examples.

## Best Possible Solution

Keep this as the canonical design item for a maintainer-approved browser-profile contract covering per-profile proxy routing, agent/subagent profile selection, credential-safe proxy auth, SSRF trust gates, launch concurrency, resource limits, diagnostics, and docs/tests together.
