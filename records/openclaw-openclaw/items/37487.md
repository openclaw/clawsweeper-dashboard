## Summary

Keep open: current main and the latest release still lack first-class `browser.profiles.*.proxy` and per-agent/subagent browser-profile binding, and the remaining design is security-sensitive product surface rather than a small bug fix.

## What This Changes

Request first-class per-agent isolated browser profile/instance routing with per-profile proxy support for concurrent agents and subagents.

## Best Possible Solution

Define a maintainer-approved browser-profile contract in the bundled browser plugin and core config schema covering per-profile proxy routing, per-agent/subagent selection, credential-safe proxy auth, SSRF trust gates, ownership visibility, resource limits, docs, and focused tests.
