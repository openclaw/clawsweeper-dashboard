## Summary

Keep open: current main still has named browser profiles and a global Chrome proxy-argument workaround, but it does not provide first-class per-profile proxy config or per-agent/subagent default browser-profile binding; the remaining work is a product/security design around public config, proxy credentials, egress policy, and browser-session ownership.

## What This Changes

Request first-class per-agent browser isolation, per-profile proxy support, agent/subagent browser-profile defaults, and matching diagnostics/docs.

## Best Possible Solution

Design a browser-owned profile binding/proxy contract that preserves current explicit profile behavior, supports SecretRef-safe per-profile proxy configuration for managed profiles, defines subagent inheritance/override semantics, and adds diagnostics/tests/docs for concurrency and SSRF boundaries.
