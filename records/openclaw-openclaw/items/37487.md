## Summary

Keep open: current main and v2026.6.11 still provide explicit browser profile selection plus a global `browser.extraArgs` proxy-flag workaround, but they do not implement typed per-profile proxy/SecretRef config or per-agent/subagent default browser-profile binding. The linked external browser-lock/FSB examples and the closed unmerged implementation attempt reinforce that the remaining work is a product and security design item, not conservative cleanup.

## What This Changes

The issue requests first-class per-agent browser isolation, per-profile proxy configuration, and concurrent browser execution semantics.

## Best Possible Solution

Design this in the bundled browser plugin/core config boundary with typed SecretRef-aware per-profile proxy settings, explicit agent/subagent browser-profile routing or inheritance semantics, diagnostics for proxy/auth failures, and upgrade/security proof.
