## Summary

Keep open: current main and v2026.6.11 still have named browser profiles and isolated managed profile directories, but they do not provide first-class per-profile proxy config, per-agent browser-profile binding, or subagent inheritance/attachment semantics. The closed implementation attempt at https://github.com/openclaw/openclaw/pull/42806 was not merged and raised the same proxy-credential and SSRF design concerns that make this maintainer product/security work rather than a cleanup close.

## What This Changes

This issue requests per-agent isolated browser instances, per-profile outbound proxy configuration, and reliable concurrent agent/subagent binding to those browser profiles.

## Best Possible Solution

Define a maintainer-approved browser ownership and proxy contract covering SecretRef/env handling, SSRF trust semantics, per-agent and subagent inheritance, concurrency limits, tab ownership, diagnostics, docs, and security tests.
