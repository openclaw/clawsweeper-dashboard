## Summary

Keep open: current main and v2026.6.11 still lack first-class per-profile browser proxy config, per-agent browser-profile binding, and subagent browser inheritance or attachment semantics. The prior implementation attempt is closed unmerged, and its review discussion exposed proxy-credential and SSRF concerns that make this maintainer product/security design work rather than cleanup.

## What This Changes

The issue requests concurrent per-agent isolated browser profiles with per-profile HTTP/SOCKS proxy support, agent/subagent browser-profile binding, diagnostics, and docs.

## Best Possible Solution

Define a maintainer-approved browser ownership and proxy contract covering SecretRef/env handling, SSRF semantics, per-agent and subagent binding or inheritance, concurrency limits, tab ownership, diagnostics, docs, and focused security tests.
