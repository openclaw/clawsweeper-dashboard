## Summary

Keep open: current main and the latest release have named isolated browser profiles and a global Chrome `extraArgs` proxy workaround, but they still lack first-class per-profile proxy config, per-agent/subagent browser-profile binding, and ownership diagnostics. The linked open proxy and subagent-browser issues cover narrower slices rather than replacing this umbrella.

## What This Changes

Request first-class per-profile browser proxy configuration plus per-agent and subagent browser profile binding for concurrent isolated browser automation.

## Best Possible Solution

Define a maintainer-approved browser ownership and proxy contract covering SecretRef/env handling, SSRF trust semantics, per-agent and subagent inheritance, concurrency limits, tab ownership, diagnostics, docs, and focused security tests.
