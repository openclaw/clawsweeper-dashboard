Status: needs_attention

Summary: The issue is security-sensitive because it asks OpenClaw to route browser egress through per-profile proxies and bind agents to cookie-bearing browser profiles.

  - body: A first-class browser proxy setting must not casually place proxy credentials in Chrome argv or status output; the prior implementation attempt was flagged for this exact risk.
