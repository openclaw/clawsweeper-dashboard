## Risks / Open Questions

- A first-class browser proxy setting could expose proxy credentials through Chrome argv, process listings, status output, logs, or config snapshots unless SecretRef and redaction behavior are defined end to end.
- Proxy-routed browser traffic can weaken current browser SSRF assumptions because the proxy may resolve and reach the final destination outside OpenClaw's process.
- Per-agent and subagent browser defaults affect cookie/session isolation and logged-in browser access, so inheritance, override, and authorization rules need explicit maintainer direction.
- Concurrent local Chromium instances need launch serialization, tab ownership cleanup, and resource limits; linked prior art reports 2-3 GB RAM for five browsers.
