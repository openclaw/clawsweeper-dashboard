## Summary

Keep open: the patch is a useful fresh-create fix, but it is still not merge-ready because existing persisted isolated recurring jobs that omitted `deleteAfterRun` can keep loading without cleanup, and the conflicting lifecycle contract in https://github.com/openclaw/openclaw/pull/96045 needs maintainer direction.

## What This Changes

The branch changes cron create normalization and tests so recurring isolated cron jobs default `deleteAfterRun` to `true` while explicit `false` and recurring main jobs remain unchanged.

## Best Possible Solution

Land one reconciled cron lifecycle contract: either make recurring isolated jobs cleanup-safe for new and already-persisted omitted rows, or reject recurring delete-after-run with a compatible recovery path and close this direction.
