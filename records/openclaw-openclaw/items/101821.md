## Summary

Keep open: current main does not implement an action-form/widget prompt-dispatch surface, and the related dashboard substrate is still open and security/product-gated rather than merged. This is a feature direction item, not conservative cleanup or an already-fixed issue.

## What This Changes

The issue requests a first-party dashboard action-form widget that renders buttons or typed forms and dispatches parameterized prompts through the dashboard prompt-send confirmation path.

## Best Possible Solution

Land or reject the dashboard substrate first, then implement action-form as a dashboard plugin builtin with schema-validated templates and fields, explicit operator confirmation/rate limits, interpolation caps, provenance, and adversarial prompt-injection tests.
