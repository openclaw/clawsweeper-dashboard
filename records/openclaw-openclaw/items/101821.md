## Summary

Keep open: current main has the generic plugin-tab and `chat.send` surfaces, but it does not have the dashboard workspace/action-form widget, and the request is a new security-sensitive product surface rather than conservative cleanup.

## What This Changes

The issue requests a trusted dashboard `builtin:action-form` widget that renders buttons or typed forms and dispatches parameterized prompts back to the agent through the existing confirmed dispatch path.

## Best Possible Solution

After the dashboard substrate is accepted, implement action-form as a first-party dashboard plugin builtin that reuses `chat.send` authorization, explicit confirmation, rate limits, and schema-validated field interpolation with adversarial tests.
