## Summary

Keep this PR open: the performance goal is sound, but the proposed check-suite comparison does not establish the claimed workflow-attempt binding, and the evidence is limited to mocked tests rather than a real rerun.

## What This Changes

The PR allows landing verification to accept an in-progress or queued CI workflow when that workflow’s successful `openclaw/ci-gate` check appears to belong to the same check suite.

## Best Possible Solution

Resolve the gate through the exact workflow run ID and `run_attempt`, require that attempt’s `openclaw/ci-gate` job to have completed successfully, add a shared-suite cross-attempt regression test, and demonstrate the path with a real rerun.
