## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Require exact member matches before using DM names:** `extensions/feishu/src/bot-sender-name.ts:141-143`
  - body: For p2p/private chats, this falls back to the only returned member even when `member_id` does not match `senderId`. Feishu chat member listing is paginated and current helpers expose `has_more`/`page_token`, so a partial or permission-scoped response can attribute the message to the wrong person in agent context and session metadata; only accept an exact match or page until the sender is found.
  - confidence: 0.88
- **[P1] Bound and prune sender-name caches:** `extensions/feishu/src/bot-sender-name.ts:31`
  - body: The new direct-member cache and widened account-scoped sender cache store event-derived account/chat/sender keys but never delete expired entries or cap size. Current-main cache code deletes expired sender entries on read and nearby Feishu caches use hard caps, so a long-running Feishu process can grow with high-cardinality chats or users.
  - confidence: 0.86
- **[P1] Validate grant URLs before surfacing them to the agent:** `extensions/feishu/src/bot-sender-name.ts:61-65`
  - body: This extracts the first `https://*/app/*` URL from a Feishu error object, and the new direct-member path sends that URL into System text as an admin grant URL. Restrict grant URLs to the account's Feishu/Lark host, or omit them, before agent-visible text to avoid phishing or prompt-format injection from malformed upstream errors.
  - confidence: 0.84
