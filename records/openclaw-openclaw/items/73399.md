Full review comments:

- **[P1] Require exact member matches before using DM names:** `extensions/feishu/src/bot-sender-name.ts:141-143`
  - body: The new DM lookup accepts `members[0]` whenever the page contains one item but no `member_id` matches `senderId`. If Feishu returns a partial, paginated, or permission-scoped page, the agent context and session metadata can attribute the message to the wrong person; only use an exact `member_id` match or paginate until the sender is found.
  - confidence: 0.91
- **[P1] Bound Feishu sender-name caches:** `extensions/feishu/src/bot-sender-name.ts:30-31`
  - body: The PR adds `directMemberNameCache` and widens `senderNameCache` to account/chat/sender keys without a max size, and the PR-head code does not delete expired entries on stale reads. In a long-running Feishu process, high-cardinality chats or senders can grow these maps without bound, so mirror the current group-name cache's bounded/pruned pattern and preserve main's expiry guards.
  - confidence: 0.9
- **[P1] Validate grant URLs before agent text:** `extensions/feishu/src/bot-sender-name.ts:60-65`
  - body: `extractPermissionError` now accepts raw response objects from the new DM path, but still extracts the first `https://.../app/...` URL from untrusted error text.   - confidence: 0.87
- **[P3] Drop the release-owned changelog edit:** `CHANGELOG.md:15`
  - body: OpenClaw's changelog is release-generated, so a normal feature/fix PR should carry release-note context in the PR body or squash message instead of editing `CHANGELOG.md` directly. Please remove this entry when refreshing the branch.
