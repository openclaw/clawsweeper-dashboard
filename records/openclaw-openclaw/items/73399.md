  - body: `resolveFeishuDirectMemberName` accepts the sole returned member when no `member_id` matches `senderId`.   - confidence: 0.88

  - body: The PR adds `directMemberNameCache` and widens sender cache keys to account/chat/sender identifiers, but neither cache has a max size and PR-head reads do not delete expired entries. Long-running Feishu processes can grow with distinct chats and senders; preserve current-main expiry deletion and add bounded pruning or an LRU-style cap for both caches.
  - confidence: 0.86

  - body: The new direct-member path passes `extractPermissionError(res)` into agent-visible permission guidance, while extracted grant URLs still accept any `https://.../app/...` host from the Feishu error payload. Validate allowed Feishu/Lark hosts or omit the URL before surfacing it to the agent/user.
