Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Require exact member matches before using DM names:** `extensions/feishu/src/bot-sender-name.ts:141-143`
  - body: `chatMembers.get` is a paginated member-list API, but this code accepts the only returned member when no `member_id` matches the sender. A partial or permission-scoped response can therefore attribute a message to the wrong Feishu user in the agent prompt and session metadata; require an exact match or page until the sender is found before using the name.
  - confidence: 0.89
- **[P1] Bound Feishu sender-name caches:** `extensions/feishu/src/bot-sender-name.ts:30-31`
  - body: This PR adds `directMemberNameCache` and widens the sender cache key to include account data, but expired entries are never globally pruned and there is no max size. A busy or adversarial Feishu deployment can accumulate account/chat/sender keys for the life of the process, so add bounded TTL eviction for both caches.
  - confidence: 0.85
- **[P1] Validate grant URLs before agent text:** `extensions/feishu/src/bot-sender-name.ts:52-61`
  - body: By treating raw API result objects as permission errors, the new direct-member path can surface an arbitrary `https://.../app/...` string into the agent-visible permission notice. Constrain grant URLs to trusted Feishu/Lark hosts, or omit the URL when it cannot be validated.
  - confidence: 0.86
- **[P3] Drop the release-owned changelog edit:** `CHANGELOG.md:12`
  - body: `CHANGELOG.md` is generated during release work, so normal fix PRs should keep release-note context in the PR body or squash message instead. Remove this entry to avoid release-generation churn.
  - confidence: 0.93
