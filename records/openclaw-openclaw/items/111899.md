## Summary

This PR addresses a real current-main duplicate-execution hazard, but it needs maintainer confirmation of the new post-acceptance timeout contract and direct `openclaw agent` behavior proof before merge.

## What This Changes

The branch prevents embedded fallback from rerunning an agent prompt after the Gateway has accepted it and a later timeout or connection close occurs.

## Best Possible Solution

Make the accepted Gateway run the sole execution authority, with a stable in-flight CLI result and reattachment guidance after acceptance, while retaining fallback only before acceptance and proving both paths through the real CLI.
