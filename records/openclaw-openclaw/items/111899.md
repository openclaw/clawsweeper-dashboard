## What This Changes

The PR changes Gateway-backed `openclaw agent` so a timeout or closed connection after Gateway acceptance reports an in-flight `accepted_timeout` result with the run ID instead of starting the same prompt through the embedded runner.

## System Context

`openclaw agent` normally sends a request to the Gateway, which owns agent execution and session routing. If the client loses its transport after the Gateway accepts the turn, this path decides whether to launch a local runner or return enough information for the caller to follow the existing Gateway run.
