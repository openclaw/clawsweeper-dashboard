Keep open: current main and the latest release still lack a stream-level assistant text repetition detector, alert/recovery path, or resume/cancel contract, and the only direct implementation PR closed unmerged. ## What This Changes

Requests a core safeguard that detects repeated assistant stream output, halts the stream, alerts the user, and requires approve/cancel before continuing.

## Best Possible Solution

Define a core stream-content repetition circuit breaker with maintainer-approved thresholds, alert/recovery semantics, buffered-output discard, and session cleanup, while keeping timeout configuration tracked separately.
