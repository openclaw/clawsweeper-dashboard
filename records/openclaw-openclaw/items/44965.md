## Summary

Keep open: current main still lacks a semantic assistant-text stream repetition guard, and the prior implementation PR closed unmerged with proof and merge-risk blockers. Existing idle-timeout and tool-loop protections are adjacent, but they do not halt active repeated text or define the requested alert/confirm recovery flow.

## What This Changes

Add a core stream-level safeguard that detects repeated assistant text, halts the stream, alerts the user, and requires approval or cancel before continuing.

## Best Possible Solution

Define a core stream-content repetition circuit breaker in the agent streaming path with maintainer-approved thresholds, alert/recovery semantics, buffered-output discard, and session quarantine, while keeping generation-timeout configuration tracked separately.
