## Summary

Keep open: current main and v2026.6.11 still lack a stream-level assistant text repetition guard, and the only direct implementation PR closed unmerged. The remaining work is product-sensitive because thresholds, alerting, abort/resume semantics, buffered-output discard, and session cleanup need maintainer direction.

## What This Changes

The issue requests a core streaming safeguard that detects repeated assistant text, halts output, alerts the user, and requires manual resume/cancel confirmation.

## Best Possible Solution

Define a core stream-content repetition circuit breaker with maintainer-approved thresholds, alert/recovery semantics, buffered-output discard, and session cleanup, while keeping timeout configuration tracked separately.
