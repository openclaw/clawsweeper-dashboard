## What This Changes

The PR updates `openclaw devices list` to display a sanitized device-ID column and a copyable full-ID index so operators can distinguish identically named paired devices and use existing management commands.

## System Context

The devices CLI requests pending and paired device records from the gateway or a guarded loopback fallback, then renders a human-readable terminal view or the unchanged JSON payload. Operators use the paired-device identifier from this view in existing remove, rename, rotate, and revoke workflows.
