## What This Changes

The issue asks OpenClaw to handle a Volcengine Lite/Coding Plan UUID-like API key that passes setup but later fails with a 401 key-format error on a Volcengine DeepSeek route.

## Best Possible Solution

Confirm Lite key entitlement against both Volcengine endpoints, then either route Lite users to `volcengine-plan` with clear diagnostics or support shared keys across both namespaces in the Volcengine plugin.
