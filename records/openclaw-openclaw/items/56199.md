## What This Changes

The issue reports that a Volcano Engine Lite plan key with UUID-like format passes OpenClaw setup validation but fails at runtime with `401 The API key format is incorrect` when using the Volcengine DeepSeek route.

## Best Possible Solution

Confirm the Volcengine Lite/Coding Plan contract with a live entitled key, then align the Volcengine plugin catalog route, setup diagnostics, docs, and focused tests around the confirmed provider behavior.

## Reproduction Assessment

## Solution Assessment
