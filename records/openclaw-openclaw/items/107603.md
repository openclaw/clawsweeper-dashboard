## Summary

This useful feature PR should remain open, but the current head still has both previously reported session-lifecycle blockers: reset drops mark provenance, and existing label writers can leave stale provenance that later restores an obsolete label. The new screenshots demonstrate basic visible commands but do not establish those state transitions, and adding a fixed-preset core command still needs product sponsorship.

Adds a `/mark` slash command with six preset symbols, autocomplete, persistent session-mark metadata, focused tests, documentation, and runtime-proof screenshots.

## Best Possible Solution

Represent a mark as independent typed presentation metadata rather than rewriting and shadowing `label`, render it consistently across session-list surfaces, and add fixed core presets only if maintainers explicitly sponsor that product direction.
