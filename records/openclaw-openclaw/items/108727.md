## Summary

## What This Changes

The PR bounds Slack thread-ownership HTTP 409 response bodies with the shared Plugin SDK reader while preserving conflict-driven send cancellation and adding oversized-response coverage.

## Best Possible Solution

Land one canonical implementation that uses the shared bounded response reader only for 409 diagnostics, always cancels on an ownership conflict, keeps non-conflict transport failures fail-open, and includes redacted real-environment evidence that the Slack send is actually suppressed.
