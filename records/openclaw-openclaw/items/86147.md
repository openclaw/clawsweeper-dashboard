## What This Changes

The issue requests an opt-in TUI notification when an agent run completes, such as a terminal bell, desktop alert, sound, status highlight, or macOS desktop notification.

## Best Possible Solution

Choose one minimal default-off completion notification contract first, then implement it in the TUI finalization path with schema/help/docs and PTY plus platform-specific proof.
