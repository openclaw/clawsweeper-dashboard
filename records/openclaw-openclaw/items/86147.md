## Summary

## What This Changes

The issue requests an opt-in TUI completion notification, such as a desktop alert, terminal bell, or configurable sound when an agent run finishes.

## Best Possible Solution

Define a narrow default-off TUI completion-notification contract, then implement it in the active-run finalization/status path with config schema/help/docs and PTY plus local-mode coverage for active, inactive, concurrent, and stale-final cases.
