Request an opt-in TUI completion notification, such as desktop alert, terminal bell, configurable sound, or status highlight, when an agent run finishes.

## Best Possible Solution

Define a narrow default-off TUI completion-notification contract, then implement it in the active-run finalization path with schema/help/docs and PTY coverage for local, Gateway, concurrent-run, and stale-final cases.
