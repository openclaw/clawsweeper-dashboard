Request to add an opt-in TUI notification when an agent run completes, potentially using desktop notifications, terminal bell, sound, or status highlighting.

## Best Possible Solution

Define a narrow default-off TUI completion-notification contract, then implement it in the run-finalization/status path with schema/help/docs and PTY plus local-mode coverage for active, inactive, concurrent, and stale-final cases.
