## What This Changes

This PR replaces the Gateway channel-health monitor’s repeating interval with a timeout that first runs when startup grace expires and only schedules the next evaluation after the previous health check finishes.

## System Context

The Gateway’s channel-health monitor reads channel runtime snapshots and restarts unhealthy accounts under cooldown and restart-rate limits. Its scheduling lifecycle controls how quickly recovery can begin after Gateway startup and whether slow recovery work overlaps later evaluations.
