## What This Changes

This PR replaces the Gateway channel-health monitor’s repeating timer with a timeout that first checks at startup-grace expiry, then schedules each later check only after the previous one settles.

## System Context

Gateway starts channel runtimes and a channel-health monitor observes their runtime snapshots for stale or failed accounts. The monitor can trigger recovery work, so its timer must honor startup grace and stop cleanly when Gateway shuts down or aborts.
