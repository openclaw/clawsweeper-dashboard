## Summary

Keep open. Current main and v2026.6.11 still expose only global, chat-type, and channel-scoped reset policy, so per-agent or per-binding reset remains a real config and precedence decision.

## What This Changes

Request per-agent or per-binding session reset policy so one-shot workflow agents can reset independently of long-lived conversational agents.

## Best Possible Solution

Define one additive scoped reset-policy model with explicit precedence and aligned types, schema, help text, docs, and regression coverage.
