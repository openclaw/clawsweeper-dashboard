## What This Changes

The PR adds an optional `YYYY-MM-DD_` local-date prefix to reset/deleted session archive filenames when `agents.defaults.userTimezone` is configured while preserving the UTC timestamp suffix.

## Best Possible Solution

Land the local-date-prefix plus UTC-suffix design only after QMD/memory archive consumers accept the prefixed shape, old-format readers remain covered, and real reset/delete proof is posted.

## Solution Assessment

No, not merge-ready yet: the local-date prefix is a plausible compatibility-preserving shape, but this branch misses a sibling QMD archive reader and lacks real reset/delete upgrade proof.
