## What This Changes

The PR adds an optional `YYYY-MM-DD_` local-date prefix to reset/deleted session archive filenames when `agents.defaults.userTimezone` is configured, while preserving the UTC timestamp suffix and parser compatibility.

## Best Possible Solution

Land the UTC-suffix/local-date-prefix design only after QMD/memory archive consumers accept the prefixed shape, old-format readers remain covered, and real reset/delete proof is posted.
