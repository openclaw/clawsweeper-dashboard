## Summary

Keep open: current main and v2026.6.11 provide Telegram preview/progress, verbose/reasoning paths, and browser-local Control UI Activity, but not the requested persistent per-step Telegram activity history with Web UI parity.

## What This Changes

Request a Telegram mode or config that renders reasoning, tool and memory activity, and the final answer as persistent separate messages instead of only preview or final output.

## Best Possible Solution

Design a default-off Telegram activity mode with explicit audience, redaction, retention, message-volume, internal-turn/NO_REPLY, and privacy rules before implementation.
