## Summary

Keep open: current main and v2026.6.11 support Telegram preview/progress visibility and current main has a browser-local Activity tab, but neither implements the requested persistent per-step Telegram activity-message mode; the remaining work needs product and security policy.

## What This Changes

Requests a Telegram mode or config that renders each agent activity step as separate persistent messages for Web UI-like visibility.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
