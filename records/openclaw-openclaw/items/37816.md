## Summary

Keep open: current main still lacks the requested persistent per-step Telegram activity messages; it has Telegram preview/progress visibility and browser-local Control UI Activity, but the remaining Telegram mode needs maintainer product and security direction.

## What This Changes

Request a Telegram mode that persists each agent thinking, tool, memory, and activity step as separate messages for Web UI parity.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
