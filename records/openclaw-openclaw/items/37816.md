## Summary

Keep open: current main has Telegram preview/progress, /verbose tool bubbles, durable reasoning when explicitly enabled, browser-local Control UI Activity, and ClickClack durable activity rows, but not the requested persistent per-step Telegram activity mode. The remaining work is a product and security decision because it would retain reasoning/tool telemetry in third-party chat history.

## What This Changes

Request a Telegram mode or config that renders each agent activity step as a persistent separate message, with NO_REPLY/internal housekeeping excluded.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement bounded redacted activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
