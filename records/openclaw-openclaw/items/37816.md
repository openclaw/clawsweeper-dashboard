## Summary

Keep open: current main has Telegram preview/progress, durable verbose/reasoning pieces, and browser-local Control UI Activity, but it still does not provide the requested persistent per-step Telegram activity mode; the remaining work needs product and security policy.

## What This Changes

The issue requests a Telegram mode that renders agent activity steps as persistent, separate messages with Web UI-style transparency.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, focused tests, and live Telegram proof.
