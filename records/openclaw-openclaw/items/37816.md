## Summary

Keep open: current main and the latest stable release still provide Telegram preview/progress and verbose/reasoning controls, plus browser-local Control UI Activity, but not the requested default-off persistent per-step Telegram activity mode; implementation needs maintainer product and security policy first.

## What This Changes

The issue requests a Telegram mode that renders agent activity steps such as tool calls, reasoning, and memory operations as persistent separate messages with Web UI-style visibility.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
