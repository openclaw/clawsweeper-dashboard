## Summary

Keep open: current main and v2026.6.11 provide Telegram preview/progress drafts, verbose/reasoning controls, and browser-local Control UI Activity, but they still do not implement the requested persistent per-step Telegram activity mode; the remaining work needs explicit product and security policy.

## What This Changes

The issue requests a Telegram mode that renders each visible agent activity step as its own persistent message for Web UI-like transparency.

## Best Possible Solution

Adopt a maintainer-approved, default-off Telegram activity policy with redacted bounded messages, NO_REPLY/internal-turn exclusions, docs, focused tests, and live Telegram proof.
