## Summary

Keep open: current main and v2026.6.11 have Telegram preview/progress visibility and a browser-local Control UI Activity tab, but they still do not implement the requested persistent per-step Telegram activity-message mode. The remaining work is a product and security policy decision, not a narrow bug repair.

## What This Changes

Request a Telegram mode that renders agent reasoning, tool, and memory activity as persistent per-step messages for Web UI parity.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
