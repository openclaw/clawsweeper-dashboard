## Summary

Keep open: current main and v2026.6.11 have Telegram preview/progress, durable verbose progress, and browser-local Control UI Activity, but not the requested persistent per-step Telegram activity history with Web UI parity.

## What This Changes

The issue requests a Telegram mode that renders each agent activity step as a persistent separate message, similar to the Web UI activity view.

## Best Possible Solution

Design a default-off Telegram activity mode with explicit redaction, retention, message-volume, NO_REPLY/internal-turn, audience, and docs/test requirements before implementation.

Owner confidence: medium

Options:

- **Add guarded Telegram activity mode (recommended):** Implement a default-off mode with redacted summaries, bounded message volume, clear NO_REPLY/internal-turn exclusions, and tests/docs for sensitive output handling.
- **Keep current Telegram visibility model:** Document preview/progress plus /verbose and /reasoning as the intended Telegram behavior and close this direction as not planned.
- **Keep detailed activity outside Telegram:** Use Control UI or another observer surface for durable activity inspection and avoid retaining detailed tool telemetry in chat history.
