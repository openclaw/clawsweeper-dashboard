- `impact:security`: The requested persistent activity stream would alter sensitive-data disclosure boundaries for reasoning, tools, memory operations, paths, URLs, credentials, and plugin diagnostics.

## Summary

Keep open: current main has Telegram preview/progress modes, durable verbose/reasoning paths, and browser-local Control UI Activity, but it still does not provide the requested persistent per-step Telegram activity mode with Web UI parity.

## What This Changes

Request a Telegram mode that persists each agent activity step as its own visible message instead of only showing typing, previews, or a final reply.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement bounded redacted activity messages with NO_REPLY/internal-turn exclusions, docs, focused tests, and live Telegram proof.
