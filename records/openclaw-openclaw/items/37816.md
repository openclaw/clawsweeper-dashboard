## Summary

Keep open: current main and v2026.6.11 have Telegram preview/progress, verbose/reasoning paths, browser-local Control UI Activity, and ClickClack durable activity patterns, but not the requested persistent per-step Telegram activity mode with Web UI parity.

## What This Changes

Request a Telegram mode or config option that renders every agent activity step as persistent separate messages, excluding internal NO_REPLY housekeeping turns.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement redacted persistent activity messages with limits, internal-turn exclusions, docs, tests, and live Telegram proof.
