## Summary

Keep open: current main has Telegram preview/progress drafts and Web UI Activity, but not the requested persistent per-step Telegram activity-message mode. The remaining work is a product and security decision because it would change what reasoning/tool telemetry is retained in Telegram chat history.

## What This Changes

The issue requests a Telegram mode or config flag that renders agent thinking, tool, memory, and progress activity as persistent separate messages with Web UI-like visibility.

## Best Possible Solution

Define a default-off Telegram activity policy first; if accepted, implement bounded redacted activity messages with internal-turn/NO_REPLY exclusions, docs, tests, and live Telegram proof.
