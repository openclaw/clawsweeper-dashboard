## Summary

Keep open: current main and v2026.6.11 still do not provide the requested persistent per-step Telegram activity-message mode; existing Telegram visibility is preview/progress or verbose-oriented, and the remaining gap needs product and security policy.

## What This Changes

Requests an opt-in Telegram mode that renders persistent per-step agent activity messages comparable to the Web UI activity visibility.

## Best Possible Solution

Define an explicit default-off Telegram activity policy; if accepted, implement redacted, bounded persistent activity messages with internal-turn exclusions, docs, focused tests, and live Telegram proof.
