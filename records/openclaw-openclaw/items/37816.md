## Summary

Keep open: current main still lacks the requested persistent per-step Telegram activity-message mode; existing Telegram behavior is editable preview/progress plus compact summaries, while the Web UI Activity observer remains browser-local and intentionally non-durable. The remaining work is product and security policy, not conservative cleanup closure.

## What This Changes

The issue requests a Telegram mode that renders Web UI-style agent activity as persistent separate chat messages for thinking, tool calls, intermediate results, and final answers.

## Best Possible Solution

Maintainers should define a default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
