## Summary

Keep open: current main and v2026.6.11 still provide Telegram preview/progress drafts, `/verbose` standalone tool summaries, and browser-local Control UI Activity, but not the requested persistent per-step Telegram activity-message mode; the remaining work needs product and security policy.

## What This Changes

Request a Telegram mode or config that renders agent thinking, tool, memory, and progress activity as persistent per-step messages with Web UI-like visibility.

## Best Possible Solution

Maintainers should define an explicit default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
