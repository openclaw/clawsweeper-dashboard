## Summary

Keep open: current main has Telegram preview/progress drafts, durable verbose/debug paths, Control UI Activity, and an opt-in ClickClack durable activity pattern, but not the requested first-class persistent per-step Telegram activity mode with Web UI parity; the next step is a maintainer product/security decision.

## What This Changes

Request a Telegram mode or flag that renders each agent activity step as a persistent separate message, mirroring Web UI activity visibility.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement redacted persistent activity messages with limits, docs, tests, and live Telegram proof.
