## Summary

Keep open: current main and the latest release still provide Telegram editable preview/progress behavior and browser-local Control UI Activity, but not the requested persistent per-step Telegram activity-message mode; the remaining work needs product and security policy.

## What This Changes

Requests a Telegram mode that renders each agent activity step as persistent separate messages with Web UI-like visibility.

## Best Possible Solution

Maintainers should define an explicit default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.

## Solution Assessment
