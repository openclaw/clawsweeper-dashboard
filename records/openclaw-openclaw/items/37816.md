## Summary

Keep open: current main has Telegram preview/progress, verbose/reasoning controls, and browser-local Control UI Activity, but it still lacks the requested persistent per-step Telegram activity mode; the remaining work needs product and security policy before implementation.

## What This Changes

Request a Telegram mode or flag that renders persistent per-step agent activity messages comparable to Web UI visibility, excluding NO_REPLY/internal housekeeping turns.

## Best Possible Solution

Maintainers should choose an explicit default-off Telegram activity policy and, if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
