## Summary

Keep open: current main and v2026.6.11 still provide Telegram editable preview/progress behavior and browser-local Control UI Activity, but not the requested persistent per-step Telegram activity-message mode; the remaining work needs product and security policy.

## What This Changes

Requests a Telegram mode or config option that renders each agent activity step as persistent separate messages for Web UI-style visibility.

## Best Possible Solution

Maintainers should define an explicit default-off Telegram activity policy; if accepted, implement redacted bounded activity messages with internal-turn exclusions, docs, tests, and live Telegram proof.
