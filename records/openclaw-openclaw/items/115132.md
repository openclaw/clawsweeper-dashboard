## What This Changes

The PR preserves a status-less `response.incomplete` event through the OpenAI Responses stream finalizer so compatible OpenAI and Azure Responses streams retain safe terminal partial text and report `length` rather than `stop`.

## System Context

The OpenAI Responses transport consumes SSE events from OpenAI-compatible endpoints and normalizes them into assistant output, usage, tool calls, and a terminal stop reason. The changed fallback affects terminal classification before the shared finalizer decides whether terminal-only text can be recovered.
