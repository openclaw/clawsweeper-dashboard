## What This Changes

The issue reports that an SSRF-wrapped outbound fetch to an IPv6-only DNS target on a host without IPv6 routing can emit an unhandled TLSSocket error and terminate the gateway process.

## Best Possible Solution

Repair or replace the linked PR with a narrow shared SSRF/Undici dispatcher fix that turns IPv6-only connection failures into rejected fetch/tool errors while preserving DNS pinning and private-network blocking.
