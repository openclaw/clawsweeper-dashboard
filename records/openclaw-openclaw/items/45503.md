## Summary

Keep open: current main and v2026.6.11 still provide automatic TTL/pressure pruning, truncation, compaction, reset, and delete paths, but no caller-directed clear/archive/recover operation for a stable tool-result entry.

## What This Changes

Requests a way to manually purge or archive tool results from active context once they are no longer needed.

## Best Possible Solution

Define one canonical session/context lifecycle contract for stable tool-result release or archival, then expose approved CLI, agent, and tool-call adapters over that contract.
