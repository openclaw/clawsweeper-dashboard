## Summary

Keep open: current main and v2026.6.11 still only provide automatic pruning/truncation plus session compact/reset/delete paths, not caller-directed clear/archive/recover for a stable tool-result entry.

## What This Changes

Request a caller-directed way to purge or archive individual tool results from active context after they are no longer needed.

## Best Possible Solution

Define one canonical session/context lifecycle operation for stable tool-result release or archival, then expose approved CLI, agent, and tool-call adapters over that contract.
