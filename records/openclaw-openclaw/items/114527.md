## Summary

Keep this PR open. The queue-level cancellation implementation has a race: an already-aborted signal, or one aborted between listener registration and queue insertion, can leave the entry queued and later consume a lane slot; the PR also needs real gateway behavior proof before merge.

## What This Changes

This PR bounds normal `sessions_spawn` preparation through a new command-queue lane using the existing subagent concurrency setting, while forwarding tool cancellation to queued preparation.

## System Context

The agent tool layer turns `sessions_spawn` calls into gateway requests that create child-agent sessions. This PR inserts a command-queue admission step before normal spawn preparation, then dispatches the prepared child request to the gateway while leaving collect-mode scheduling with the swarm scheduler.

## Best Possible Solution

Make queue-wait cancellation race-safe by checking and removing an already-aborted entry after it is enrolled, add focused regressions for pre-aborted and registration-to-enqueue cancellation, then capture a redacted live gateway burst showing the configured limit and aborted waiter behavior.
