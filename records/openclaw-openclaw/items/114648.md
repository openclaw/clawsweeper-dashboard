## What This Changes

This PR updates the macOS app packaging script to redirect selected SwiftPM resource-bundle lookups into signed `Contents/Resources`, copy and validate five required bundles, and test cleanup of temporary source edits.

## System Context

The macOS packager builds the native Swift product and assembles the signed `.app` bundle consumed by Settings. Swift dependencies load shortcut-recorder strings and math fonts from resource bundles, so the packager must place those bundles at a signed-app path the compiled accessors can resolve.
