## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Encrypt existing plaintext rows when the key is enabled:** `src/agents/auth-profiles/sqlite.ts:179`
  - body: This only encrypts inside `writePersistedAuthProfileStoreRaw`, but `saveAuthProfileStore` first compares the decrypted existing payload with the next payload and skips the write when they match. If an operator sets `OPENCLAW_AUTH_PROFILE_SECRET_KEY` after credentials already exist, the row remains plaintext until some unrelated auth-store mutation happens, so the central at-rest protection claim is false for existing installs.
  - confidence: 0.91
- **[P1] Fail closed on unreadable encrypted stores:** `src/agents/auth-profiles/crypto.ts:104`
  - body: Returning the raw `{ encrypted }` envelope when decryption fails makes a missing or wrong key look like an absent/malformed store to the existing loaders. From there the legacy OAuth and external CLI sync write paths can save an empty or partial replacement, and with the key absent that replacement is plaintext; distinguish encrypted-but-unreadable from legacy plaintext and block writes until the key problem is resolved.
  - confidence: 0.9

## Security Review
