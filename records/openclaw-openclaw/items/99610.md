## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Start the replacement build before polling for its stamp:** `scripts/watch-node.mjs:570-579`
  - body: When `dist/.buildstamp` is missing or its HEAD does not match, this branch sets a timer and returns while the old child keeps running. In the normal watch flow, the replacement `scripts/run-node.mjs` process is what detects `git_head_changed` or a missing stamp, rebuilds, and writes the fresh stamp, so no fresh stamp may ever appear and hot reload can stall on the old child.
  - confidence: 0.9
- **[P2] Reject headless build stamps before restarting:** `scripts/watch-node.mjs:106`
  - body: `isBuildReadyForRestart` only rejects mismatched non-empty `stamp.head`, so a stamp with no HEAD is treated as ready even though `run-node` treats `build_stamp_missing_head` as stale and rebuilds before launch. That can still stop the healthy child and then clean `dist` during the rebuild window this PR is trying to avoid.
  - confidence: 0.86
