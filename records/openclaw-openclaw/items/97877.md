## Summary

Keep open: current main and the latest release still gate the silent provider-error retry on cumulative replay metadata, and the runner still excludes classified `server_error` from the empty-error retry reason set. Three live PRs already reference this issue with closing syntax, so the right cleanup action is to review and land or close those candidate fixes, not close this issue now.

## What This Changes

The issue asks OpenClaw to retry transient clean provider-error turns after prior session tool calls without replaying side effects from the failed turn itself.

## Best Possible Solution

Review and land one candidate PR that separates current-attempt replay safety from cumulative session replay metadata, covers classified 5xx/server_error errors, and preserves same-attempt side-effect blocking.
