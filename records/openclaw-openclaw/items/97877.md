## Summary

Keep open: current main and the latest stable tag still gate silent provider-error retry on cumulative replay metadata, and this issue is already paired with open candidate fix PRs rather than being implemented on main.

## What This Changes

The issue reports that empty provider-error retry is blocked after any prior session tool side effect, causing silent terminal agent failures on transient 5xx responses.

## Best Possible Solution

Review and land one focused linked PR that adds current-attempt replay metadata or an equivalent delta, retries empty transient server errors only when the failed attempt itself is side-effect-free, and adds regression coverage for prior-session side effects plus same-attempt unsafe side effects.

Yes, at source level: current main still passes accumulated replay state into later attempts and the silent-error retry rejects attempts whose replay metadata reports side effects. I did not run a live OpenRouter 5xx reproduction in this read-only review.

## Solution Assessment

Yes, the narrow maintainable fix is to split current-attempt side-effect evidence from accumulated replay history for this retry path while preserving the existing safety guard for side effects in the failed turn itself.
