## Summary

Keep open: current main and the latest release still gate empty-error retry on cumulative replay metadata and still exclude classified server_error turns, while the linked implementation PRs remain open and unmerged.

## What This Changes

The issue asks OpenClaw to retry or visibly fail empty transient provider-error turns after earlier session tool calls instead of silently ending the session.

## Best Possible Solution

Land one narrow fix that distinguishes current-attempt side effects from prior session replay metadata and routes transient server_error empty turns through the bounded retry path, then close this issue and retire duplicate PR attempts.
