## Label Justifications

- `impact:security`: Safety, DLP, compliance, and audit plugins using `message_sending` can silently fail open on outbound agent replies.

## Summary

Keep this open: current main and the latest release still have the configured `beforeDeliver` branch that skips the documented `message_sending` hook, and the linked PRs are open candidate fixes rather than merged replacements.

## What This Changes

The issue asks OpenClaw to make plugin `message_sending` hooks run on channel agent-reply delivery paths, including Telegram configured-dispatch and streamed-final replies.

## Best Possible Solution

Land or repair one canonical fix that runs `message_sending` exactly once per visible outbound agent reply across shared dispatcher delivery and Telegram preview-finalized streaming, with focused regression tests and Telegram-visible proof.
