## Label Justifications

- `P1`: The issue affects the primary outbound interception path for real Telegram agent replies and can silently disable safety or delivery-policy plugins.

## Summary

Keep this open: current main still bypasses the documented `message_sending` hook when a channel supplies `beforeDeliver`, and the linked PRs are open candidate fixes rather than merged replacements.

## What This Changes

The issue reports that documented plugin `message_sending` rewrite/cancel hooks are skipped on channel agent-reply delivery paths, especially Telegram paths with channel-supplied `beforeDeliver`.

## Best Possible Solution

Select or repair one canonical branch that composes `message_sending` with configured dispatcher hooks and covers Telegram preview-finalized replies exactly once, with focused regression tests and refreshed live Telegram proof.
