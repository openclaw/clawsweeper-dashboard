## Summary

Keep this open: current main and the latest release still skip the documented `message_sending` gate when a channel supplies `beforeDeliver`, and the linked pull requests are unmerged candidate fixes rather than a safe replacement.

## What This Changes

The issue reports that documented `message_sending` plugin hooks are silently bypassed on channel agent-reply delivery paths, especially Telegram paths with configured `beforeDeliver` and streamed preview finals.

## Best Possible Solution

Land one canonical fix that composes `message_sending` with configured `beforeDeliver` and covers Telegram preview-finalized streaming exactly once, with focused regression tests and Telegram-equivalent proof.
