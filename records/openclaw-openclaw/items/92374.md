## Label Justifications

- `P1`: The issue affects a documented outbound safety/rewrite/cancel hook on high-volume channel agent replies and has production confirmation on recent releases.
- `impact:security`: Bypassing `message_sending` can make DLP, compliance, and content-safety plugins silently inert before outbound delivery.
