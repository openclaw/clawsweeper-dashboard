## Summary

Keep this open: current main and the latest shipped release still omit the documented `message_sending` gate when a channel supplies `beforeDeliver`, and Telegram still supplies that configured path while streamed preview-finalized replies do not run the hook either. Several open pull requests are candidate fixes, so the issue should stay open until maintainers select and land one canonical branch.

## What This Changes

Ensure plugin `message_sending` hooks run on channel agent-reply delivery paths, including Telegram configured `beforeDeliver` and streamed preview-finalized replies, instead of being silently bypassed.

## Best Possible Solution

Select or repair one canonical fix that preserves exactly-once `message_sending` semantics across configured dispatcher hooks and Telegram preview-finalized replies, then land it with focused auto-reply and Telegram regression coverage plus real Telegram proof.
