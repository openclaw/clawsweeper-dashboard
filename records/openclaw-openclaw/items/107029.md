## Summary

Keep this issue open for a focused plugin-state API and security-boundary decision. Current main already provides restart-safe SQLite keyed storage, but it is plugin-global and restricted to bundled or trusted official plugins; the requested agent-scoped third-party surface remains missing. Likely related people: @vincentkoc (medium confidence), @alex-xuweilong (medium confidence), and @amknight (medium confidence).

## What This Changes

Add an agent-scoped SQLite cache API for plugin transient state and discourage restart-sensitive in-memory or JSON sidecar retention.

## Best Possible Solution

Extend the existing keyed-store contract only after defining storage ownership: retain plugin-global storage for shared state, add an explicit agent-bound variant or required agent identity for genuinely agent-local cache data, and specify trust, quotas, TTL, cleanup, migration, and tests rather than introducing a parallel `context.cache` source of truth.
