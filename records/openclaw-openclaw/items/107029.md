## Summary

Keep this issue open because current main has durable SQLite-backed plugin storage, but not the requested agent-scoped third-party cache contract; the remaining work requires an explicit storage-ownership and trust-boundary decision. Likely related people: @vincentkoc, @alex-xuweilong, and @amknight, all with medium confidence based on prior routing and the current storage/runtime surfaces.

## What This Changes

Add an agent-scoped, TTL-aware SQLite cache API for plugin transient state and document it as the required inter-turn storage path.

## Best Possible Solution

Define a capability-gated Plugin SDK store keyed by plugin and agent identity, with bounded values, quotas, TTL cleanup, lifecycle semantics, cross-agent isolation tests, and no raw database access before implementing the backing schema.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should OpenClaw expose agent-scoped persistent cache storage to third-party plugins, and if so, under which capability and agent-isolation rules?

Rationale: The current API is deliberately plugin-global and trusted-only; changing that contract affects third-party permissions, agent data isolation, database lifecycle ownership, and the shipped Plugin SDK surface.

Likely owner: vincentkoc

Owner reason: The existing plugin-state runtime is the central contract that would need to own or delegate this new capability.

Owner confidence: medium

Options:

- **Design a constrained agent store (recommended):** Add a capability-gated SDK abstraction scoped by plugin and agent identity, with quotas, TTL cleanup, lifecycle rules, and isolation tests before exposing it externally.
- **Keep plugin-global storage:** Retain the existing trusted-only keyed store and require plugins to encode agent identity within their namespace when that ownership model is acceptable.
- **Defer third-party persistence:** Keep the external API unavailable until the broader third-party plugin permissions model is settled.

## Reproduction Assessment

No; this is an architecture and SDK feature request, and the report does not identify a concrete plugin or current-main sequence that demonstrably loses required state.

## Solution Assessment

Unclear; agent-scoped SQLite storage may be appropriate, but selecting the table and facade before defining trust, isolation, quotas, and lifecycle ownership is not yet the safest solution.
