## Summary

Keep this issue open for a focused maintainer API decision. Current main already offers restart-safe SQLite keyed storage and durable session-extension state, but the keyed store is global rather than agent-scoped and remains restricted to bundled or trusted official plugins, so the external-plugin use case is not fully implemented.

## What This Changes

Add a public agent-scoped, TTL-capable SQLite cache contract for plugin-owned transient state and document its intended use.

## Best Possible Solution

Extend the existing `api.runtime.state` keyed-store contract with an explicit, host-validated agent scope only if a real external-plugin use case proves that global keyed storage and session extensions are insufficient; preserve one storage abstraction with clear trust, quota, cleanup, and lifecycle rules.
