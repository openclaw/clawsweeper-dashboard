## What This Changes

## Best Possible Solution

Keep signal ownership in `src/cli/gateway-cli/run-loop.ts`; if duplication is reproduced, make that lifecycle installation idempotent and add a regression test asserting listener counts and exactly-once cleanup before and after loop teardown.
