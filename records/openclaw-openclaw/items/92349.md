## What This Changes

This PR adds Feishu reply-dispatcher heuristics that suppress apparent SOP/tool noise and exempt short memory-governance probe replies from that suppression.

## System Context

Feishu receives completed agent replies through its reply dispatcher, which chooses a text message or card and reports delivered-final counts to the channel fallback logic. A false suppression here can make a real final reply disappear while downstream state still treats it as delivered.

## Best Possible Solution
