## What This Changes

The PR prevents canceled cron triggers from starting payload work, keeps failure-alert recipients and accounts scoped to their selected channel, preserves cron tool restrictions, and makes Workboard dispatch and active-card projections ignore invalid or archived state correctly.

## System Context

Cron evaluates scheduled triggers, executes payloads, and emits failure alerts through a channel-aware delivery plan. The bundled Workboard plugin stores cards, dispatches eligible cards to workers, then projects queue, notification, and captured-session state into the web UI.
