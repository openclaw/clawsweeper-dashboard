The issue asks OpenClaw to classify repeated Codex/OpenAI OAuth refresh failures as auth-profile incidents, alert operators clearly, quarantine or rotate bad profiles sooner, and avoid wedging channel or cron agent runs.

## Best Possible Solution

## Solution Assessment
