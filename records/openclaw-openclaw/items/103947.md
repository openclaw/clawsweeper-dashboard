## Summary

The branch addresses the correct current-main Slack failure path, but it still confirms a persisted control concurrently with a void-returning inbound dispatch. A normal authorization or policy rejection can therefore leave the control looking successfully selected although no agent turn started; exact-head real Slack proof is also still pending.

## What This Changes
