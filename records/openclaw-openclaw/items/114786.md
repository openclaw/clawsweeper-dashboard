## What This Changes

This PR makes recovered subagent completions publish the terminal session update once so subscribed Control UI clients stop showing a completed dashboard child as running.

## System Context

Subagent lifecycle completion persists a child session’s terminal state and emits lifecycle events consumed by the gateway’s subscribed clients. The Control UI uses those events to refresh its session list, so a missed terminal event can leave a row visually stale even when stored session state is correct.
