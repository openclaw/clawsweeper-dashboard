## What This Changes

This PR publishes one terminal session-status update for an interrupted-recovery subagent callback so subscribed Control UI clients replace a completed child’s running state without producing ordinary duplicate completion events.

## System Context

Subagent lifecycle completion persists each child run’s terminal state and emits session lifecycle events. The gateway broadcasts those events to subscribed Control UI clients, whose session rows use them to refresh a child from running to terminal status.
