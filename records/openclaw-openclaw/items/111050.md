## Summary

Keep this issue open for maintainer review. Current OpenClaw already has the bundled, opt-in Policy plugin and the public routing SDK seam the proposal needs, but it does not document a routing-policy namespace or authored route-probe checks; the protected `maintainer` label also requires an explicit human product and contract decision.

## What This Changes

Add opt-in routing-binding conformance rules to the bundled Policy plugin so authored probes can validate route outcomes through `openclaw policy check` and `openclaw doctor --lint`.

## Best Possible Solution

Extend the existing Policy plugin with a narrow, absent-by-default `routing` namespace that evaluates redacted authored probes through `plugin-sdk/routing`; preserve all runtime routing behavior and add parity coverage for healthy binding, empty bindings, retired channel configuration, and unintended default-agent fallback.
