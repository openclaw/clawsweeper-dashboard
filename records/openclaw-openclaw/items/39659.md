Keep open. Request first-class Docker instance lifecycle commands for creating, listing, deleting, and updating isolated named OpenClaw Docker instances on one host.

## Best Possible Solution

Define a maintainer-approved Docker instance lifecycle, or explicitly keep Docker multi-instance operation as documented manual Compose/profile workflow, while keeping security and isolation choices visible to operators.
