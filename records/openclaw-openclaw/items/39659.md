## Summary

Keep open. Current main and v2026.6.11 still provide manual profile, port, Compose, Docker setup, and ClawDock helper primitives, but not the requested first-class Docker instance create/list/delete/update lifecycle; related open work is narrower or adjacent rather than a full replacement.

## What This Changes

The issue requests first-class Docker install commands to create, list, update, and delete multiple isolated OpenClaw instances on one host.

## Best Possible Solution

Define a minimal maintainer-approved Docker instance lifecycle that keeps security decisions explicit while standardizing named instance identity, ports, persistence, update/delete cleanup, docs, and coordination with sandbox isolation.
