## Summary

Keep open. Current main and v2026.6.11 still provide manual profile/env/Compose/ClawDock primitives, not first-class Docker instance create/list/delete/update lifecycle management, and the related open sandbox PR only covers a narrower isolation bug.

## What This Changes

Request first-class Docker instance create/list/delete/update commands with isolated persistent directories, compose/container names, host ports, update flow, and cleanup.

## Best Possible Solution

Define a maintainer-approved minimal Docker instance lifecycle that keeps security choices explicit while standardizing instance identity, ports, persistence, update/delete behavior, docs, and coordination with the sandbox-isolation fix path.
