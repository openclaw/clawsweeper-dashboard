## Summary

Keep open. Current main still provides manual Docker/Compose, profile, port, container-targeting, and ClawDock primitives, but it does not provide the requested first-class named Docker instance create/list/delete/update lifecycle; related open items cover narrower config-schema, sandbox-collision, or non-Docker profile-targeting work.

## What This Changes

The issue requests first-class create/list/delete/update lifecycle commands for managing multiple Docker-installed OpenClaw instances on one host.

## Best Possible Solution

A maintainer-owned design should either keep Docker multi-instance operation as documented profile/port/Compose primitives plus helper scripts, or define a minimal core lifecycle with explicit state, cleanup, update, port, Compose, and security contracts before implementation.
