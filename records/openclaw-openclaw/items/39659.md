## What This Changes

Define a maintainer-approved minimal Docker instance lifecycle that keeps security decisions explicit, or explicitly keep multi-instance Docker operation as documented manual Compose/profile workflow plus external wrappers.

Options:

- **Sponsor minimal core lifecycle (recommended):** Approve a small explicit core design for named Docker instances, with identity, ports, persistence, update/delete, docs, and sandbox-isolation contracts before implementation.

- **Route to external wrapper:** Decline core ownership unless a missing core API is identified, and ask contributors to maintain a wrapper or ClawHub package around the current primitives.
