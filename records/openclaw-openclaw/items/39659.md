## What This Changes

Requests first-class Docker multi-instance lifecycle commands for creating, listing, deleting, and updating isolated named OpenClaw instances on one host.

## Best Possible Solution

Define a maintainer-approved Docker instance lifecycle that keeps security choices explicit while standardizing instance identity, ports, state/workspace roots, Compose naming, update/delete cleanup, docs, and sandbox coordination.
