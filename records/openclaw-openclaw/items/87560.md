## Summary

Keep this PR open, but it still needs changes before merge because the shared delivery-profile RTL isolation can run before Discord's internal-line scrub and mask lines that should not be delivered.

## What This Changes

The PR extracts TUI RTL isolation into a shared text helper, enables it for assistant-visible delivery text, updates the TUI formatter to reuse it, and adds focused sanitizer tests.

## Best Possible Solution

Preserve the shared delivery-profile RTL isolation, but make Discord strip its private internal channel lines before RTL controls are inserted and add an RTL regression for that path.
