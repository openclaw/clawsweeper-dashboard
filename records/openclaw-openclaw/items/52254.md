The issue requests more complete Simplified Chinese localization for Control UI tab interiors that still render English after selecting zh-CN.

Sequence the existing per-surface i18n PRs or replace them with focused slices that add English source keys, regenerate locale bundles through the UI pipeline, run i18n checks, and provide zh-CN Control UI proof for the listed tabs.

## Solution Assessment

No single broad automated fix is the best path right now. The maintainable solution is reviewed per-surface localization work that updates English source keys, regenerates non-English bundles, and proves the zh-CN UI behavior.
