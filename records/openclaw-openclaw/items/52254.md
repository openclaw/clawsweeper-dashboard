## Summary

Keep open: current main still has hardcoded English in several reported Control UI zh-CN tab interiors, and the related PRs are open, conflicting, and only cover partial slices rather than a merged canonical fix.

## What This Changes

Requests full Simplified Chinese localization for internal Control UI tab content in Agents, Skills, Channels, Sessions, Nodes, and Debug when zh-CN is selected.

## Best Possible Solution

Review and sequence the existing partial i18n PRs through the generated locale pipeline, require focused zh-CN Control UI proof per surface, and close this issue only after the listed tabs no longer render hardcoded English internals.

## Reproduction Assessment

Yes. Source inspection on current main shows multiple reported tab internals still render hardcoded English strings without locale lookups, even though zh-CN locale support exists.

## Solution Assessment

No single broad automated fix is the best path right now. The maintainable solution is per-surface localization that updates English source keys, regenerates locale bundles, and avoids conflicts with the already-open partial PRs.
