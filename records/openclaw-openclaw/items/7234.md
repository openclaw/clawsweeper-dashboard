## What This Changes

Add independent Discord permissions for sending, reading, editing, and deleting messages instead of one combined `actions.messages` switch.

## System Context

Discord message tools are surfaced to OpenClaw agents by the Discord plugin. Its action configuration determines both which operations are advertised to an agent and which message requests the runtime permits before calling Discord.

## Architecture Diagram

flowchart LR

  B --> C[Action discovery]
  C --> D[Agent message tool]
  D --> E[Discord runtime checks]
  E --> F[Discord API operations]

## Best Possible Solution

Define one documented Discord-plugin permission model that preserves existing boolean behavior, makes destructive operations independently denyable, validates configuration and metadata consistently, and covers discovery plus every runtime action with focused compatibility tests.
