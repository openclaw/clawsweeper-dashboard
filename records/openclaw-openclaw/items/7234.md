## Summary

Keep open: current main and v2026.6.11 still use one coarse Discord `actions.messages` boolean for send/read/edit/delete, so the requested least-privilege message-action gates remain missing.

## What This Changes

## Best Possible Solution

Choose one maintainer-approved least-privilege Discord message-gate contract, then update config/schema metadata, account inheritance, discovery, runtime enforcement, docs, and focused tests while preserving existing boolean behavior.
