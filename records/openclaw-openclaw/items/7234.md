## Summary

Keep open: current main and v2026.6.11 still expose Discord `actions.messages` as one coarse boolean, so the requested least-privilege split for send/read/edit/delete remains unimplemented and needs maintainer product/security direction.

## What This Changes

Request granular Discord message action gates so send, read, edit, and delete can be enabled independently instead of all sharing `channels.discord.actions.messages`.

## Best Possible Solution

Choose a maintainer-approved least-privilege Discord message-gate contract, then update config/schema metadata, account inheritance, discovery, runtime enforcement, docs, and focused tests while preserving existing boolean behavior.
