## Summary

Keep open: current main and the latest release still read fixed workspace bootstrap files through a workspace-root fs-safe boundary, while the requested `.openclaw` sibling symlink allowance remains an explicit security/product decision with an overlapping but non-canonical open PR.

## What This Changes

The issue asks OpenClaw to allow workspace bootstrap symlinks whose targets are under the user’s `.openclaw` tree but outside the workspace root, instead of rendering those bootstrap files as missing.

## Best Possible Solution

Land a maintainer-approved, narrow external-bootstrap symlink policy in the active fs-safe/OpenClaw reader path, with positive tests for fixed bootstrap symlink hops and negative tests for arbitrary `.openclaw` state paths.

Rationale: The behavior is source-reproducible, but the fix changes which local filesystem roots can feed startup prompt authority, so automation should not choose the trust boundary alone.

Owner confidence: high

Options:

- **Narrow Bootstrap Policy (recommended):** Allow only fixed bootstrap-file symlink hops through the workspace bootstrap reader, with explicit denial of credentials, sessions, state, caches, logs, and direct arbitrary `.openclaw` reads.
- **Keep Current Rejection:** Continue rejecting out-of-workspace symlink targets and improve diagnostics so users see why bootstrap files are missing.
- **Broader `.openclaw` Allowance:** Allow any target under `.openclaw`, accepting higher prompt-injection and private-state exposure risk for sync ergonomics.

## Reproduction Assessment

Yes, at source level. Current main reads fixed bootstrap files through `openRootFile` bounded to the workspace root, fs-safe rejects symlink hops outside that root, and non-ok reads are rendered as missing.

## Solution Assessment

No, the broad proposed allowance for any target inside `.openclaw` is not the best fix by itself. The safer solution is a narrow maintainer-approved allow/deny policy in the active reader layer with regression coverage for private OpenClaw state roots.
