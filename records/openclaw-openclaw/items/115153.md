## What This Changes

This PR replaces fixed 1 GiB/2 GiB default heap-pressure thresholds with V8 heap-limit-relative defaults, capped at 4 GiB for warnings and 6 GiB for critical events, and adds enlarged- and constrained-heap coverage.

## System Context

The gateway’s diagnostic memory sampler compares process heap and RSS measurements with pressure thresholds, then emits events that stability handling can use to drain or restart an unhealthy process. This PR changes only the default heap-threshold calculation, using Node V8’s effective heap limit while leaving explicit overrides and RSS handling intact.
