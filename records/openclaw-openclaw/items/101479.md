## Summary

Keep this PR open, but not merge-ready: it fixes the unbounded read shape, yet still changes plugin-visible `before_reset` behavior by sending an empty message payload for valid transcripts over 16 MiB.

## What This Changes

The PR replaces command reset-hook transcript `fs.readFile` calls with a 16 MiB capped `readRegularFile` path and adds reset-hook regression coverage.

## Best Possible Solution

Use the existing async session transcript reader/index for command reset hooks, preserving reset-archive behavior and large-session hook payloads without whole-file buffering.
