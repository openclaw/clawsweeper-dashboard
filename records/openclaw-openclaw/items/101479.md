## Summary

Keep open. The OOM hardening target is real, but this patch is not merge-ready because it changes the plugin-visible `before_reset` payload for valid large transcripts to `messages: []` instead of using the existing chunked transcript-reader path.

## What This Changes

The PR changes command reset-hook transcript loading to use a 16 MiB bounded regular-file read and adds regression coverage for archived and oversized reset transcripts.

## Best Possible Solution

Route command reset-hook payload loading through the existing transcript-reader/index seam with reset-archive fallback, preserving large valid transcript messages without whole-file buffering, then add redacted actual reset-command path proof.
