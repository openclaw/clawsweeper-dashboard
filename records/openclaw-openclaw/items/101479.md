## Summary

Keep this PR open, but it is not merge-ready: it addresses a real current-main OOM risk in command reset hooks, yet the patch silently turns any transcript over 16 MiB into an empty `before_reset` payload and only provides unit-test proof.

## What This Changes

The branch replaces command reset-hook transcript `fs.readFile` calls with a 16 MiB capped `readRegularFile` helper, updates affected mocks, and adds oversized-transcript coverage.

## Best Possible Solution

Use the existing session transcript reader seam for command reset hooks so oversized transcripts do not OOM and valid large histories are not silently replaced with an empty payload; then require redacted real behavior proof before merge.
