## Best Possible Solution

Patch the compaction content accounting path to count nested `toolResult` and `tool_result` text/content payloads, and add regression coverage using the current Codex app-server transcript shape.

## Solution Assessment

Yes. The narrowest maintainable solution is to teach the existing block-counting path to account for nested `toolResult`/`tool_result` text or content, then keep summary rendering aligned if it uses the same content extraction.
