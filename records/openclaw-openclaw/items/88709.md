## Summary

## What This Changes

Adds provider-scoped cooldown tracking for inline `models.providers.<id>.apiKey` credentials so auth or billing failures stop immediate reuse while healthy stored profiles remain available as fallback.

## System Context

OpenClaw resolves model credentials from configured inline API keys, environment-backed secrets, and stored auth profiles before an agent run or model browse operation. This PR records provider-level failures for inline keys and feeds that cooldown state back into credential resolution, model availability, tools, and failover behavior.
