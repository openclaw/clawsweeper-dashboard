## What This Changes

This PR records provider-level cooldowns for inline `models.providers.<id>.apiKey` credentials after auth or billing failures, blocks cooled keys across resolution and availability checks, and preserves healthy stored-profile fallback.

## System Context

OpenClaw resolves provider credentials for embedded agent runs, model browsing, and model-backed tools. The change adds a provider-scoped usage-state entry for inline configuration keys so an auth or billing failure can temporarily remove that key from all of those paths while leaving a stored profile usable.
