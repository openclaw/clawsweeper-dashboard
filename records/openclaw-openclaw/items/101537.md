## Summary

Keep open. Current main still has a source-visible path where a recurring main-session systemEvent cron job with the default wakeMode="now" enqueues the event, receives runHeartbeatOnce status=skipped/reason=disabled, removes the queued event, and records the same skipped/disabled outcome reported here.

## What This Changes

The issue reports that recurring cron jobs targeting the main session with a systemEvent are skipped as disabled, so the main agent is never woken.

## Best Possible Solution

Align runtime with the documented cron contract so recurring main-session systemEvent jobs do not silently delete their queued event and report disabled forever under the default wake-now path.
