## Summary

Keep open: current main and v2026.6.11 partially address session artifact cleanup, but the full disk-bloat report is still not resolved because normal retention still preserves `.bak.*` archives, startup reads do not run full cleanup, stale temp cleanup is mostly tied to explicit cleanup paths, and an open linked cleanup PR still needs maintainer handling.

## What This Changes

The issue asks for automatic cleanup of stale session artifacts such as `.reset.*`, `.deleted.*`, `.tmp`, and `.bak.*` files that accumulate under agent session directories.

## Best Possible Solution

Define one maintainer-approved cleanup contract that covers deleted/reset archives, stale store temps, and `.bak.*` recovery archives, then land it with dry-run/apply reporting and regression coverage for both runtime maintenance and `openclaw sessions cleanup`.
