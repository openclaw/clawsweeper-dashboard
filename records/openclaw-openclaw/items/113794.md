## Summary

Keep this PR open. The manifest and shared-preset direction is consistent with the provider-boundary cleanup, but the Chutes public plugin barrel removes `CHUTES_DEFAULT_MODEL_ID`; retaining an additive, manifest-derived export avoids breaking consumers while keeping the new single source of truth. ## What This Changes

This PR adds manifest-declared primary default models for eleven provider catalog entries and migrates several provider onboarding flows to the shared catalog preset appliers.

## System Context

Bundled provider plugins declare model catalogs in their manifests, then onboarding helpers turn those declarations into provider configuration, default agent models, and aliases. The shared plugin SDK sits between manifest normalization and the extension-specific onboarding code.
