## What This Changes

The PR tells Gemini CLI OAuth users when an environment-provided client ID is running in public-client PKCE mode and appends the relevant secret-variable guidance only when Google rejects a token request for a missing client secret.

## System Context

The bundled Google plugin builds Gemini CLI OAuth login requests from environment credentials or installed Gemini CLI credentials, then exchanges the authorization code with Google. This change affects the terminal notices and token-exchange errors seen by operators, without changing the OAuth request contract or stored credentials.
