## Summary

This looks like a current npm 12 compatibility regression, not cleanup material: npm 12 changed `npm view --json` to always return an array, while OpenClaw’s documented plugin-update path reads npm registry metadata before updating. The report lacks the exact error output, so the precise failing parser still needs confirmation before implementation. ([github.com](https://github.com/npm/cli/releases?utm_source=openai))

## What This Changes

Make plugin metadata resolution during `openclaw update` compatible with npm 12.x so installed plugins can still be updated.

## Best Possible Solution

Normalize the shared npm metadata result to accept npm 11 object output and npm 12 single-item array output, reject ambiguous multi-item results, and add focused regression coverage for both shapes without changing plugin selection or pinning semantics.
