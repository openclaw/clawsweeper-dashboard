## Summary

Keep open: the latest commit fixes the earlier run-key lookup gap and the in-process model-override authorization, but the branch still does not restore the original cron task prompt/session context and remains blocked on real behavior proof.

## What This Changes

The PR stores a cron run-kind marker, falls back from cron run-session keys to the base cron session entry, restores provider/model/thinking on async completion wakes, and authorizes the trusted in-process model override.

## Best Possible Solution
