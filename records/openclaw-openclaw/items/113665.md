## Summary

Keep this PR open for normal maintainer review. Its parent-session routing fix is distinct from the configuration-override invariant addressed by the related PR, and the supplied current state does not establish that current main already contains this behavior. The focused patch preserves explicit-agent precedence and default routing while correcting the wrong-agent session-store path for dashboard children.

## What This Changes

The branch makes dashboard-created child sessions inherit the agent encoded in an agent-qualified parent session key when the dashboard did not explicitly select an agent.

## System Context

The Control UI asks the Gateway to create or fork sessions, optionally supplying a parent session key. The Gateway selects an agent, resolves the parent/store context, and returns a new agent-qualified session key that determines where the child session state lives.
