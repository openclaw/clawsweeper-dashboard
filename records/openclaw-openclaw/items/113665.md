## What This Changes

This PR makes dashboard-created child sessions inherit the agent encoded in their parent session key when no explicit agent is supplied, while preserving explicit selections and default-agent behavior.

## System Context

The Control UI requests a new session from the Gateway, which chooses an agent and creates a session in that agent's scope. The chosen session key determines where dashboard child-session state is associated and subsequently loaded.
