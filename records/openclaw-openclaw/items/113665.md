## Summary

Keep this PR open for normal maintainer review: its focused precedence rule—explicit agent, then agent-qualified parent, then configured default—addresses a distinct dashboard session-routing failure and is not superseded by the related open configuration-override PR.

## What This Changes

The branch makes dashboard-created sessions inherit the agent encoded in an agent-qualified parent session key when no explicit agent is supplied, with Gateway and Control UI regression coverage.

## System Context

The Control UI asks the Gateway to create dashboard sessions. The Gateway selects an agent before constructing the session key and opening the corresponding agent-owned session store, so the selection determines where child session state is associated.
