## What This Changes

This PR makes dashboard-created sessions inherit the agent encoded in an agent-qualified parent session key when no explicit agent is selected, with regression coverage in the Gateway and Control UI.

## System Context

The Control UI sends a session-create request to the Gateway when a user starts or branches a dashboard session. The Gateway selects an agent, loads the parent session, and writes the new session to that agent’s session store, which determines subsequent agent routing and state ownership.
