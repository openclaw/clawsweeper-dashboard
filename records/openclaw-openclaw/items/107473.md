## Summary

Keep this PR open for merge review: current main still permits an unterminated Ollama record to grow without a bound, the supplied production-path proof demonstrates the failure and fix, and no blocking patch defect was found.

## What This Changes

The PR adds a 16 MiB byte-level limit for each Ollama NDJSON record, cancels overflowing streams, and adds regression coverage for overflow and newline resets.

## Best Possible Solution

Keep the limit in the Ollama-owned parser, count encoded bytes before decoding, cancel the response on overflow, and reset only at NDJSON newline boundaries so valid long streams remain unlimited.
