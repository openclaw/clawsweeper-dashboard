## What This Changes

This PR adds an opt-in Beam plugin service that reads explicitly selected local coding-session catalogs, redacts and bounds their transcripts, and mirrors live or completed snapshots to a remote Beam receiver.

## System Context

Beam is OpenClaw's read-only coding-session catalog: local catalog providers supply session lists and transcripts, and the Beam receiver makes normalized uploads visible to authorized Gateway viewers. This PR adds the sender side, transforming selected local sessions into bounded remote uploads without granting the receiver control over the source machine.
