## What This Changes

Adds an opt-in Beam plugin mirror that reads active local coding-session catalogs, redacts and bounds their transcripts, and periodically uploads them to an authenticated remote Beam receiver.

## System Context

Beam is OpenClaw's read-only coding-session sharing plugin: local session catalogs feed the sender, which redacts and uploads snapshots to a remote Gateway. The remote Beam receiver stores those snapshots as a read-only catalog that team users can inspect through the existing session experience.
