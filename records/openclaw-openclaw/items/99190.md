## What This Changes

The issue requests bounded transcript tail/header reads and cached AGENTS.md policy digests to avoid per-turn cost growing with long-lived session JSONL files.

## Best Possible Solution

Keep this issue as the canonical tracker until the linked candidate lands and any remaining full-read hot paths get bounded readers or an indexed design that preserves full-state mutation and migration behavior.

## Reproduction Assessment

Yes at source level: current main reads and parses full transcript JSONL in readTranscriptFileState and SessionManager cold-open paths, and scans AGENTS.md content when building policy digests. I did not run a long-session performance benchmark in this read-only review.

## Solution Assessment

Yes for the direction, but not as a blanket replacement of shared full-state readers. The maintainable solution is bounded or indexed read-only hot-path helpers while preserving full parsing for mutation, migration, rewrite, compaction, and repair paths.
