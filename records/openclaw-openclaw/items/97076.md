## What This Changes

The branch adds tests for heartbeat, cron-event, and exec-event metadata suppression and changes `buildInboundUserContextPrefix` to skip the `Conversation info` block when `ctx.Provider` is `heartbeat`, `cron-event`, or `exec-event`.

## Best Possible Solution
