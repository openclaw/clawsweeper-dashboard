## Summary

Current main implements the central recovery path: a pure 429-silent Codex app-server turn is no longer treated as an active server-request wait, it times out through the per-turn liveness path, and suspect shared clients now have a retirement path that prevents co-leased sessions from staying wedged indefinitely.

## What This Changes

The issue requests a fix for Codex app-server turns wedging indefinitely after a rate-limit burst, especially when shared-client liveness was suppressed by active app-server request accounting.
