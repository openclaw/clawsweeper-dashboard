## Summary

Current main now retires the central 429-silent Codex app-server wedge path: outbound-silent turns are no longer dependent on the active server-request counter, timed-out turns remove the shared client from reuse, and suspect physical-client retirement can fail co-leases onto the retry path. ## What This Changes

The issue reports Codex app-server sessions wedging indefinitely after a 429 burst because idle watchdog recovery appeared gated by a stuck active app-server request counter.
