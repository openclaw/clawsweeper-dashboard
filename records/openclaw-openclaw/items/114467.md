## What This Changes

The PR adds CLI-runner recovery callbacks that compare and clear a stale persisted Claude CLI session binding before a fresh retry and after terminal failover or abort errors, with targeted session-store and runner coverage.

## System Context

Inbound channel messages enter the agent-turn and follow-up runners, which may resume a provider-specific CLI session stored with the OpenClaw conversation. The proposed recovery callbacks decide whether a failed CLI run may replay, then conditionally update that persisted session binding so a later turn can establish a fresh CLI session.
