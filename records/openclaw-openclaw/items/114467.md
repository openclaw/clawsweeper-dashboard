## What This Changes

This PR adds guarded persisted-session cleanup and fresh-retry callbacks so an inbound CLI conversation can recover from a stale Claude CLI session without deleting a newer concurrent binding.

## System Context

Inbound channel turns enter the unified CLI candidate runner with a persisted CLI session binding. On terminal CLI failure, the proposed recovery callbacks compare the observed binding with current session state, clear only a matching stale binding, and allow a later turn or safe retry to create a fresh CLI session.
