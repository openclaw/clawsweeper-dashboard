## Summary

Keep this PR open as the candidate fix for the reported stale Claude CLI binding loop. The compare-and-clear approach and targeted coverage address the linked failure mode, but the updated PR body still contains only test/static-check claims rather than after-fix evidence from a real Gateway and Claude CLI run; that proof remains required before merge.

## What This Changes

The PR clears the exact persisted Claude CLI session binding observed by a failing channel turn before a safe fresh retry and after terminal failover or abort errors, while preserving newer concurrent bindings.

## System Context

Inbound messages enter the auto-reply runners, which reuse a saved CLI session binding when available and persist session state for later turns. This change adds recovery callbacks between CLI execution failures and the session store so a dead Claude CLI session does not pin future channel messages to the same unusable binding.
