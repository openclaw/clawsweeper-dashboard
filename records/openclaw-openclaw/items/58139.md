The issue reports that the bundled memory-lancedb plugin fails on Windows Docker Desktop when its LanceDB directory is backed by a host bind mount.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/80683 with adequate retry-path proof, or explicitly document named Docker volumes as the supported workaround if maintainers decline runtime retry.

## Reproduction Assessment

No high-confidence live Windows Docker Desktop bind-mount reproduction was run. The issue is source-reproducible at medium confidence from the reporter logs plus current main's one-shot LanceDB table metadata initialization path.

## Solution Assessment
