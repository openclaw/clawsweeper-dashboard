## What This Changes

Expose an optional session key when creating a Workboard card through the `openclaw workboard create` command and the `workboard_create` agent tool.

## System Context

Workboard cards can be created by operators, automations, and agent tools, then stored for later dispatch. A creation-time session key would associate a card with a known peer session before any worker run begins.
