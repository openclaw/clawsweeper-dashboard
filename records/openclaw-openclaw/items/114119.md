## What This Changes

This PR converts a final simple `Options:` line in Telegram outbound text into two-column inline callback buttons when the outbound payload does not already include explicit buttons.

## System Context

OpenClaw sends agent-produced outbound payloads through channel adapters such as Telegram. The adapter turns an explicit presentation payload into Telegram messages and callback updates that return to the agent; this PR adds a text-parsing decision inside that adapter.
