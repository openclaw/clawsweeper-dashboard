## What This Changes

Allow an agent to trigger context compaction for its own active session without a sender-issued `/compact`, preferably through `session_status(action="compact")` or an equivalent agent tool.

## Best Possible Solution

Review, repair, land, or explicitly reject the narrow current-session-only self-compaction path in https://github.com/openclaw/openclaw/pull/95272, preserving visibility checks, mutation tracking, audit/security semantics, and active-run recovery behavior.

## Reproduction Assessment

Yes. Source inspection on current main and `v2026.6.11` shows no `session_status` compact action, no agent-facing gateway compact action, and only an admin-scoped compact RPC.

## Solution Assessment

Unclear until maintainers approve the model-callable mutation boundary. The narrow open PR is a better fit than exposing the admin RPC directly, but it still needs product/security review and conflict resolution before this issue can close.
