## Summary

Keep open: this remains a requested core agent-lifecycle capability, and the focused implementation candidate at https://github.com/openclaw/openclaw/pull/95272 explicitly targets it but is still open, draft, and not cleanly mergeable. The remaining question is the intended security and recovery boundary for a model-triggered mutation of its own active session, so this should not be closed or sent to another repair lane.

## What This Changes

Add a first-class, model-callable action that lets an agent request compaction of its own active session while it is running.

## Best Possible Solution

Maintain a narrow current-session-only agent action, if maintainers approve the capability, that requests compaction through the established abort-and-recovery path with explicit mutation tracking and regression coverage for transcript cleanup, recovery, and session visibility.
