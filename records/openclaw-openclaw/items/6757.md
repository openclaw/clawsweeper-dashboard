## Summary

Keep open: current main and v2026.6.11 still lack a model-callable in-run self-compaction action, and the direct fixing PR remains open while maintainers decide whether agents may initiate this session mutation.

## What This Changes

Add a first-class agent-facing action that lets an agent compact its own active session without an authorized user command.

## Best Possible Solution

Adopt a narrow current-session-only agent action that requests compaction through the existing embedded recovery lifecycle, fails closed outside an active run, cleans abort artifacts, updates canonical compaction metadata, and preserves all existing status and model-override behavior.

- **Keep compaction operator-controlled:** Decline model-originated compaction and retain automatic, user-command, plugin-hook, and operator RPC paths only.
