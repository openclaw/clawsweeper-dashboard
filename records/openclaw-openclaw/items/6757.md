## Summary

Keep open: current main provides automatic and manual compaction, an operator-facing `openclaw sessions compact` command, and an opt-in mid-turn pressure precheck, but still does not document or expose a model-callable current-session self-compaction action. The focused linked implementation remains open, so this issue should stay open until maintainers approve or reject that session-mutation boundary. ([docs.openclaw.ai](https://docs.openclaw.ai/cli/sessions?utm_source=openai))

## What This Changes

Add a first-class action allowing an agent to request compaction of its own active session without user intervention.

## Best Possible Solution

Land a narrow current-session-only agent action that requests compaction through the outer run-recovery path, fails closed outside an active run, forbids cross-session targets and simultaneous model changes, records the mutation, cleans abort artifacts, and proves counter/transcript/resume behavior across built-in and context-engine paths.
