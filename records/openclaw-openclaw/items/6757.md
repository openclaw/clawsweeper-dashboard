## Summary

Keep open: current main and latest release still lack an in-run model-callable self-compaction action; manual/admin CLI and RPC compaction do not satisfy agent self-triggering, and the direct fixing PR remains open, draft, conflicting, and unmerged.

## What This Changes

Request an agent-callable way for an active session to trigger its own compaction, preferably through `session_status(action: "compact")` or an equivalent current-session tool.

## Best Possible Solution

Review and either land or explicitly reject the narrow current-session-only `session_status` self-compaction path while preserving visibility checks, mutation tracking, audit/security semantics, and active-run recovery behavior.

- **Defer To Continuation Design:** Do not land the narrow path and decide self-compaction only as part of the broader continuation API.
