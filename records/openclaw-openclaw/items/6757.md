## Summary

Keep open: current main and v2026.6.11 still lack a model-callable in-run self-compaction action, while the direct fixing PR remains open and awaits maintainer approval of the session-mutation boundary.

## What This Changes

Requests a model-callable action that lets an agent compact its own active session without user intervention.

## Best Possible Solution

Provide a current-session-only, fail-closed self-compaction action that delegates abort, transcript cleanup, compaction, counters, and resume to the existing embedded recovery path, without exposing arbitrary cross-session RPC access.
