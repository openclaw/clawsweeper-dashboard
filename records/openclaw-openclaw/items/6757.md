## Summary

Keep open: current main and v2026.6.11 still lack an in-run agent self-compaction action, and https://github.com/openclaw/openclaw/pull/95272 is an open unmerged closing PR for the same narrow request. Existing auto-compaction, manual `/compact`, CLI `sessions compact`, and admin `sessions.compact` are adjacent paths, not a current-session model-callable tool action.

## What This Changes

This issue requests an agent-triggered self-compaction surface for the active session, such as `session_status(action: "compact")`, an equivalent gateway RPC, or a dedicated CLI command.

## Best Possible Solution

Review, repair, land, or explicitly reject the narrow current-session-only self-compaction path in https://github.com/openclaw/openclaw/pull/95272 while preserving visibility checks, mutation tracking, audit/security semantics, and active-run recovery behavior.
