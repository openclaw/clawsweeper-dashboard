## Label Justifications

## Summary

Keep open: current main and v2026.7.1 still provide automatic compaction, manual `/compact`, and operator-facing `sessions.compact`, but no in-run model-callable self-compaction action; the focused linked PR remains open and requires an explicit decision on the model-controlled session-mutation boundary.

## What This Changes

Add a first-class way for an agent to request compaction of its own active session from inside a run.

## Best Possible Solution

Ship a narrow current-session-only agent action owned by the embedded runner: fail closed outside an active run, reject cross-session targets and simultaneous model changes, abort and clean the tool turn, reuse the canonical compact-and-resume path, update session accounting, and cover authorization, mutation classification, transcript cleanup, and recovery behavior.
