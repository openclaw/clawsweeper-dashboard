## Summary

Keep open: current main and the latest stable release still lack an in-run agent self-compaction action, and the direct fixing PR is open, draft, and conflicting rather than merged. Existing auto-compaction, manual `/compact`, CLI `sessions compact`, and admin `sessions.compact` paths are adjacent but not equivalent to a current-session model-callable tool action.

## What This Changes

Request an agent-callable way to compact its own active session, preferably through `session_status(action: "compact")` or an equivalent first-class self-compaction surface.

## Best Possible Solution

Review, repair, land, or explicitly reject the narrow current-session-only self-compaction path in https://github.com/openclaw/openclaw/pull/95272 while preserving visibility checks, mutation tracking, audit/security semantics, and active-run recovery behavior.
