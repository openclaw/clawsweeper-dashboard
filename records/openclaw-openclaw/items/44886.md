## Summary

Keep open: current main still advertises Telegram direct tool policy in config/schema and applies direct config to prompts, while the tool-policy resolver only reaches group/channel session context and group maps; v2026.6.11 has the same mismatch.

## What This Changes

Issue asks whether Telegram DM `direct.<peer>.tools` is intended to enforce per-user tool permissions and, if so, to fix the Telegram DM policy path.

## Best Possible Solution

Keep this issue open until maintainers either enforce Telegram direct-session tool policy through a shared direct-aware resolver with regression coverage or deliberately retire/diagnose the schema surface with doctor/docs.
