## What This Changes

This PR adds an optional `CliBackendPlugin.parseJsonlEvent` callback that lets plugin-owned CLI backends normalize custom JSONL stdout into OpenClaw text, thinking, result, session, and display-only tool-card events.

## System Context

CLI backend plugins supply provider-specific command and output behavior, while the core CLI runner resolves the selected backend and projects its stdout into agent-stream events. This change inserts a plugin-owned JSONL parsing seam before the built-in dialect parsers, feeding existing terminal and Control UI event consumers.
