## Summary

Keep open: the report describes a severe, repeatable WebChat output-visibility failure on the latest release, while current source inspection does not prove the central problem fixed or establish that either related report has the same root cause. The exact “(see attached image)” phrase is consistent with a tool-result media conversion path, so treating this as a frontend-only or Braille-character defect would be premature.

## What This Changes

Ensure text-based tool results remain visible as inline text in WebChat instead of being replaced by an image placeholder or hidden attachment.

## Best Possible Solution

Preserve text blocks as the authoritative tool output through materialization and WebChat projection, render real image blocks separately, add mixed text/image regression coverage, and provide an inline “show raw tool result” recovery action when rich rendering cannot classify a payload safely.
