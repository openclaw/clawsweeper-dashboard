## What This Changes

The PR keeps ClawHub request deadlines active through response-body consumption and adds stalled and continuously dripping body regression coverage.

## Best Possible Solution

Use a total deadline for bounded JSON and small response bodies, while large archives retain a separate transfer policy—such as a longer or throughput-aware deadline—with tests proving both drip termination and successful progressing downloads beyond the header budget.
