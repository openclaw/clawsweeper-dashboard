## Summary

The new exact-head loopback output is sufficient real behavior proof and the prior progressing-archive blocker is fixed, but this PR still releases archive deadlines before classifying the HTTP status, so a continuously dripping non-2xx archive error body can remain unbounded.

## What This Changes

The PR keeps ClawHub request deadlines active through metadata, JSON, error, and skill-card body reads while releasing the wall-clock deadline after headers for archive downloads protected by chunk-idle limits.

## Best Possible Solution

Retain the full-body wall-clock for metadata and every non-2xx response, release it only after an archive response is confirmed successful, and add a non-2xx archive-drip regression alongside the existing loopback proof.
