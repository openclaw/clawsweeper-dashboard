## What This Changes

Request to change Discord exec directive persistence or precedence so global `tools.exec` policy changes can revoke stale per-session exec overrides.

## Best Possible Solution

Define an explicit maintainer-approved revocation path for session exec defaults, such as clearing or invalidating stored exec overrides when operator policy changes, while preserving intentional `/exec` session defaults unless maintainers choose a breaking precedence change.

- **Keep current contract:** Leave persisted session exec defaults authoritative and improve documentation or diagnostics for clearing stale session state.
