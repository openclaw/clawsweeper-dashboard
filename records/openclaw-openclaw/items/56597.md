## Summary

Keep open. Current main and latest release v2026.6.11 still persist authorized `/exec` fields in session state and resolve stored session fields before config-derived defaults; the related ACP cache fix does not settle this security/session-precedence contract.

## What This Changes

The issue asks OpenClaw to stop persisted per-session Discord `/exec` directives from overriding later global `tools.exec` security configuration changes.

## Best Possible Solution

Define the canonical `/exec` versus operator-config precedence, then implement a tested reset or migration path so stricter global exec policy can take effect without accidentally breaking intended session defaults.
