## Summary

Keep open. Current main and latest release v2026.6.11 still preserve stored per-session exec overrides ahead of config-derived defaults, while the merged ACP cache fix only addressed a related runtime-handle freshness path.

## What This Changes

The issue asks OpenClaw to stop Discord session-stored exec directive values from shadowing later global exec security config changes.

## Best Possible Solution

Define the canonical /exec session precedence and reset policy, then implement a tested migration, doctor repair, reset path, or precedence change so operator security config can be enforced without silently breaking intentional session defaults.
