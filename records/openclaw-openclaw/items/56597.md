## Summary

Keep open. Current main and latest release v2026.6.11 still persist authorized `/exec` session fields and resolve stored session exec values before config-derived defaults, while the merged ACP fix only addressed a separate runtime-handle cache path.

## What This Changes

The issue asks OpenClaw to stop persisted Discord/session `/exec` directive fields from overriding later global `tools.exec` security config after session resume or gateway restart.

## Best Possible Solution

Define the canonical `/exec` session precedence and reset policy, then implement a tested clamp, clear, migration, doctor repair, or reset path so operator security config can be enforced without silently breaking intentional per-session defaults.
