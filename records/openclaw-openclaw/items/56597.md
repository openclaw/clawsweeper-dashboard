## Summary

Keep open. ## What This Changes

The issue requests changing `/exec` session directive persistence or precedence so Discord sessions cannot keep older exec settings after operator config changes.

## Best Possible Solution

Define the canonical `/exec` precedence and reset semantics, then implement tested resolver, persistence, doctor or reset, and docs changes so stricter operator exec policy cannot be shadowed by old session state.
