## Summary

Keep open. ## What This Changes

The issue asks OpenClaw to stop Discord session-stored exec directives from overriding later global exec security configuration changes.

## Best Possible Solution

Define the canonical `/exec` precedence and reset policy, then implement a tested session-state migration or recovery path so operator security policy can take effect without silently breaking documented session defaults.
