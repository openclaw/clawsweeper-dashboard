## Summary

Keep open. Current main and v2026.6.11 still make stored `/exec` session overrides outrank agent/global exec defaults, and changing that documented session-state/security contract needs maintainer direction.

## What This Changes

The issue asks OpenClaw to stop Discord sessions from indefinitely preserving per-session exec directive values after global `tools.exec` policy changes.

## Best Possible Solution

Define an explicit exec policy lifecycle: either invalidate or clear stored session exec overrides when operator policy changes, or provide a visible reset/doctor path and document that durable `/exec` overrides intentionally survive config changes.
