## Summary

Keep this PR open for maintainer review. It deliberately removes the documented prompt-selected direct schemas from the existing `tools.toolSearch.mode: "directory"` behavior, so current users can see a different tool surface after upgrade even though no configuration key changes. The cache-stability goal is well scoped, but the compatibility decision needs explicit approval and upgrade proof.

Likely related people: steipete is the likely follow-up owner from the maintainer-owned branch and the current implementation work (low-confidence routing signal).

## What This Changes

This PR removes prompt-dependent schema hydration from Tool Search directory mode, canonicalizes provider-visible tool ordering for OpenAI, Anthropic, and Gemini, and makes cache diagnostics compare bounded tool-schema digests.

## System Context

The embedded agent runner and agent harness assemble a provider-facing prompt from system instructions, plugin guidance, and a tool catalog. Tool Search directory mode controls which tools enter that prompt, while provider projections turn the selected tools into cacheable OpenAI, Anthropic, and Gemini requests.
