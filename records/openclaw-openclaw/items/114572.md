## Summary

Keep this PR open for explicit maintainer review. It has credible after-fix gateway proof and a coherent cache-stability goal, but it also deliberately changes the documented behavior of existing opted-in Tool Search directory mode: prompt-selected direct tool schemas are removed rather than made deterministic. That can change how existing agents discover and invoke tools, so the protected `maintainer` and `security` labels appropriately require a human compatibility decision before merge.

## What This Changes

The PR removes prompt-dependent Tool Search directory schema hydration, canonicalizes provider-visible tool ordering for OpenAI, Anthropic, and Gemini, strengthens cache-break diagnostics, and replaces the OpenGrep CI installer with a checksum-pinned release-asset action.

## System Context

Tool Search compacts a large plugin tool catalog into a model-facing directory plus a small set of directly visible tools. That surface is transformed into provider-specific request payloads, where stable system-prompt and tool bytes allow OpenAI, Anthropic, and Gemini prompt caches to be reused across agent turns.
