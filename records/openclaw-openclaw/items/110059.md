## Summary

Keep this PR open: its lineage fix is directionally sound, but the new cross-item-collapse switch is exposed through general model configuration rather than remaining provider-owned, so arbitrary Responses routes can opt into a transcript-merging behavior intended only for Bedrock Mantle. The supplied terminal proof exercises real production functions, but it does not yet show an end-to-end agent run with the persisted transcript outcome.

## What This Changes

The branch preserves ordinary OpenAI Responses message boundaries by requiring message ID or output-index lineage for snapshot collapse and has Bedrock Mantle set a rotating-snapshot compatibility flag during model normalization.

## Best Possible Solution

Keep rotating-snapshot collapse as an internal provider-normalized runtime fact for Amazon Bedrock Mantle, remove the generic config/catalog admission of the flag, and add an end-to-end agent proof that verifies both final visible text and stored transcript boundaries.
