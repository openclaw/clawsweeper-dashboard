## Summary

Keep open: the lineage checks and Bedrock Mantle provider hook address the reported boundary corruption, but the patch still exposes the provider-specific cross-item collapse escape hatch through normal model configuration and catalog inputs. That can re-enable false message merging for arbitrary Responses routes, so it needs a narrow boundary repair before merge.

## What This Changes

The PR adds item-ID/output-index lineage checks for OpenAI Responses snapshot collapse and lets the Amazon Bedrock Mantle provider enable rotating-snapshot collapse through model compatibility metadata.

## Best Possible Solution

Keep cross-item rotating-snapshot collapse as provider-set runtime metadata in the Bedrock Mantle plugin, while all other Responses routes require same-item or same-output-index lineage; remove user-config and catalog acceptance of the flag.
