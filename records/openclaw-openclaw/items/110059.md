## Summary

Keep this PR open, but do not merge it in its current form. The identity check fixes the reported false merge, yet it also removes the shipped compatibility behavior for providers that emit cumulative snapshots under different item IDs, which can restore repeated replies and corrupted transcript boundaries.

## What This Changes

The PR requires matching normalized message item IDs and phases before collapsing cumulative OpenAI Responses text in the shared stream processor and agent transport, and updates the associated regression coverage.

## Best Possible Solution

Retain the distinct-ID cumulative-snapshot regression, add the new separate-message prefix case, and distinguish the two using an event or lineage invariant demonstrated by captured provider streams rather than requiring item-ID equality alone; apply the same rule to both stream processors.
