## Summary

Keep this PR open: it fixes a real transcript-boundary bug, but the proposed provider-owned exception is still exposed as a generic user-configurable compatibility switch, which can re-enable cross-item merges for arbitrary Responses routes; the supplied processor-level terminal proof also does not yet demonstrate persisted transcript behavior through `openclaw agent`.

## What This Changes

The branch adds item-ID/output-index lineage checks to OpenAI Responses snapshot collapse and moves Bedrock Mantle rotating-snapshot handling to a model compatibility flag set during provider normalization.

## Best Possible Solution

Keep cross-item rotating-snapshot collapse as a Bedrock Mantle runtime-normalization fact only, remove the public model-config/catalog exposure, and add a redacted end-to-end agent proof that verifies both final output and persisted transcript boundaries.
