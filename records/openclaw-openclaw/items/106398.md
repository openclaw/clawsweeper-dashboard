## Summary

Keep this PR open for an explicit Discord owner decision. The patch has no actionable correctness finding and its production-path proof is sufficient, but it intentionally trades queue progress for a strict active-listener bound when listeners never settle.

## What This Changes

The PR makes timed-out Discord listeners retain concurrency slots until their underlying promises settle, logs late rejection, and adds regression coverage for slot retention and recovery.

## Best Possible Solution

Keep the strict active-work bound implemented by this patch, with explicit owner acceptance that permanently hung listeners may saturate the queue; cancellation or long-held-slot diagnostics can be separate follow-up work if operational evidence warrants them.
