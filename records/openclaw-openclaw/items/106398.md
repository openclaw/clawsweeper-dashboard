## What This Changes

The PR changes Discord event-queue accounting so timed-out listeners retain their concurrency slots until their underlying promises settle, with regression tests for timeout, queueing, late rejection, and recovery.

## Best Possible Solution

Discord listener timeouts should settle dispatch reporting without releasing actual-work capacity, while saturation remains bounded, observable, documented, and proven against a real gateway workload.
