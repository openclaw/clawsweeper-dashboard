## What This Changes

This PR builds multi-line failure and overdue-job detail for sidebar cron attention chips, displays it in the existing tooltip, adds an English fallback string, and changes the chips from hyperlink-style to default button cursors.

## System Context

The Control UI receives cron-job state from the Gateway and turns failed or overdue jobs into sidebar attention chips. This change enriches those chips with diagnostic text before the existing tooltip component presents it and the user can navigate to the Cron page.
