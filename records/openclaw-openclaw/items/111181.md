## What This Changes

The PR caps Canvas A2UI JSONL file reads at 25 MiB and rejects outgoing Gateway requests whose serialized frame exceeds the server-negotiated payload limit.

## System Context

Canvas accepts A2UI JSONL either from a CLI file or an agent-tool workspace path, validates it, and sends it to a paired node through the Gateway. The shared Gateway client serializes that node command into a WebSocket request, where the server's negotiated payload policy limits what can be delivered.
