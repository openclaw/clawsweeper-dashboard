## Summary

The earlier documentation blocker is resolved and the patch appears technically sound, but current main deliberately fails closed for unbound interpreter eval; merging now requires explicit owner acceptance of generated launchers as a new exec-approval trust boundary.

## What This Changes

The PR materializes four exact direct Node/Python inline-eval forms into private non-Windows launchers, binds and revalidates those launchers for node-host approval, preserves original command previews, adds lifecycle and dispatch coverage, documents the behavior, and updates one Knip command.

## Best Possible Solution

Explicitly adopt generated launchers as a narrow, owner-reviewed exec-approval contract with the documented fail-closed limits, or preserve current denial and direct operators to sandbox or explicit full-trust node execution.
