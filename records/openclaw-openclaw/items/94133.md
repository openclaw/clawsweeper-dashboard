Full review comments:

- **[P1] Use one lifecycle key for tool heartbeats:** `src/agents/embedded-agent-runner/run/llm-idle-timeout.ts:299`
  - body: `onToolActivity` is registered with `streamAbortController.signal`, but `notifyToolActivity` is called with `runAbortController.signal`. Because the listener map is keyed by `AbortSignal`, this notification will not reach `armTimer()` on the reported path.
  - confidence: 0.95
- **[P1] Persist tool activity across provider waits:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: The notifier fires after a cataloged tool finishes, but the previous provider stream listener can already be cleaned up and the next provider wait has not registered its listener yet. Store run-scoped activity so the next idle watchdog arm can see the tool completion.
  - confidence: 0.88
- **[P2] Emit heartbeats from shared tool execution:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: This adds the heartbeat only inside the Tool Search catalog executor, but normal direct tools execute through agent-core's shared `executePreparedToolCall` path. The reported read and exec style tools can bypass this hook.
  - confidence: 0.84
