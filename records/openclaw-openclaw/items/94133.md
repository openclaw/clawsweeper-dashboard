Full review comments:

- **[P1] Use one lifecycle key for tool heartbeats:** `src/agents/embedded-agent-runner/run/llm-idle-timeout.ts:297`
  - body: `onToolActivity` is registered with `streamAbortController.signal`, but `notifyToolActivity` is called with `runAbortController.signal`. Because the new listener map is keyed by `AbortSignal`, this notification will not reach `armTimer()` for the reported path.
  - confidence: 0.95
- **[P1] Persist tool activity across provider waits:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: The notifier fires only after a cataloged tool finishes, but stream iterator cleanup unregisters the listener when the provider wait ends. Without a run-scoped timestamp or equivalent persisted state, the activity can be dropped before the next provider wait arms its timeout.
  - confidence: 0.88
- **[P1] Emit heartbeats from shared tool execution:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: This adds the heartbeat inside the Tool Search catalog executor, while normal direct tools such as read and exec execute through agent-core's shared `executePreparedToolCall` path. The reported direct-tool workflows can bypass this hook.
  - confidence: 0.84
