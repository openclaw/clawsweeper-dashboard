## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Use one heartbeat key across listener and notifier:** `src/agents/embedded-agent-runner/run/llm-idle-timeout.ts:299`
  - body: `onToolActivity` is registered with `streamAbortController.signal`, but `notifyToolActivity` is called with `runAbortController.signal`. Because the new listener map is keyed by `AbortSignal`, the notification will not reach `armTimer()` on the reported path.
  - confidence: 0.95
- **[P1] Persist tool activity across provider waits:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: The notifier fires after a cataloged tool finishes, but the stream iterator listener is cleaned up when the previous provider wait ends and the next wait has not registered yet. Store run-scoped activity so the first post-tool provider wait sees it instead of dropping the event.
  - confidence: 0.88
- **[P1] Emit heartbeats from shared tool execution:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: This hook only covers the Tool Search catalog executor, while normal direct tools execute through agent-core's shared `executePreparedToolCall` path. The reported read/exec style tools can bypass the heartbeat unless the shared path is wired or proved irrelevant.
  - confidence: 0.84
