## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.94

Full review comments:

- **[P1] Use one activity key for the heartbeat:** `src/agents/embedded-agent-runner/run/llm-idle-timeout.ts:300`
  - body: `onToolActivity` is registered with `streamAbortController.signal`, but `notifyToolActivity` is called with `runAbortController.signal`. Because the listener map is keyed by `AbortSignal`, the notification will not reach `armTimer()` on the reported path.
  - confidence: 0.95
- **[P1] Persist tool activity across provider waits:** `src/agents/embedded-agent-runner/run/attempt.ts:3681`
  - body: The notifier fires after the cataloged tool finishes, but the previous stream listener can already be cleaned up and the next provider wait has not registered yet. A one-shot event can be dropped unless activity is stored as run-scoped state.
  - confidence: 0.9
- **[P2] Emit heartbeats from shared tool execution:** `src/agents/embedded-agent-runner/run/attempt.ts:3681`
  - body: This hook is inside the Tool Search catalog executor, while normal direct tools such as read and exec execute through agent-core's shared `executePreparedToolCall` path. The reported direct-tool cases can bypass this heartbeat.
  - confidence: 0.86
