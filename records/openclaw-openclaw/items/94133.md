Overall correctness: patch is incorrect

Full review comments:

- **[P1] Use one signal key for tool heartbeats:** `src/agents/embedded-agent-runner/run/llm-idle-timeout.ts:299`
  - body: `onToolActivity` is registered with `streamAbortController.signal`, but `notifyToolActivity` is called with `runAbortController.signal`. Because the new listener map is keyed by `AbortSignal`, this notification will not reach `armTimer()` on the reported path.
  - confidence: 0.95
- **[P1] Persist tool activity across provider waits:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: The notifier fires after a cataloged tool finishes, but the provider stream listener has already been cleaned up and the next provider wait has not registered its listener yet. A one-shot event is dropped instead of giving the next wait a fresh idle budget.
  - confidence: 0.88
- **[P2] Emit heartbeats from shared tool execution:** `src/agents/embedded-agent-runner/run/attempt.ts:3678`
  - body: This adds the heartbeat only inside the Tool Search catalog executor, but normal direct tools such as read and exec execute through agent-core's shared `executePreparedToolCall` path. The reported direct-tool workflows can bypass the heartbeat.
  - confidence: 0.84
