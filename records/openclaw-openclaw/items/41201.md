## What This Changes

The issue reports that agent avatars set with `openclaw agents set-identity --avatar` render as broken images in Control UI for remote URLs and local workspace paths.

## Best Possible Solution

Decide the avatar contract, keep the browser remote-image CSP unless maintainers approve a server-mediated proxy, and align docs plus UI diagnostics so local oversized or missing avatars give clear feedback.
