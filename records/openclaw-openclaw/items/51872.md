- `impact:security`: The requested behavior would store and replay proxy credentials before OpenClaw's normal Gateway authentication boundary.

## Summary

Keep open: current main and the latest release still lack a shared Android/iOS transport-auth contract, setup-code metadata, and native WebSocket upgrade-header support for authenticated reverse proxies; the Android PR is closed unmerged and the open iOS PR covers only a Basic-auth subset with unresolved blockers.

## What This Changes

Request support for mobile clients to send reverse-proxy transport authentication such as bearer/basic/static headers, cookies, or OIDC before the Gateway WebSocket upgrade.

## Best Possible Solution

Define a shared Android/iOS transport-auth contract for setup-code and manual Gateway connections, split static header support from OIDC if needed, and land platform slices only after credential storage, clearing, redaction, secure transport, endpoint-change, and real proxy proof requirements are approved.
