## Summary

Keep open: current main and v2026.6.11 still lack shared Android/iOS transport-auth metadata and WebSocket upgrade-header support for authenticated reverse proxies; the Android PR closed unmerged, and the open iOS PR covers only a Basic-auth subset with blockers.

## What This Changes

Request support for HTTP transport-level proxy authentication, including Basic, bearer, fixed headers, cookies, and OIDC, in Android/iOS gateway setup and connections.

## Best Possible Solution

Define a shared Android/iOS transport-auth contract for setup-code and manual Gateway connections, split static-header support from OIDC if needed, and land platform slices only after credential storage, clearing, redaction, TLS, endpoint-change, and real proxy proof requirements are approved.
