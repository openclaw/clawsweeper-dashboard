## Summary

Keep open: current main and the latest release still lack a shared mobile transport-auth contract, setup-code metadata, and Android/iOS WebSocket upgrade-header support for authenticated reverse proxies; the Android attempt closed unmerged and the open iOS PR covers only a Basic-auth subset with unresolved proof/security blockers.

## What This Changes

Request mobile clients and setup QR payloads support transport-level proxy authentication such as bearer/basic/static headers/cookies/OIDC before the Gateway WebSocket upgrade.

## Best Possible Solution

Define a shared mobile transport-auth contract, split static header support from OIDC if needed, and land Android/iOS/setup-code slices only after credential storage, clearing, redaction, TLS, endpoint-change, and real proxy proof requirements are approved.
