## What This Changes

Add mobile support for transport-level reverse-proxy authentication through QR/setup metadata, manual connection fields, and pre-upgrade client headers for bearer/basic/fixed-header/cookie/OIDC proxy environments.

## Best Possible Solution

Define a shared mobile transport-auth contract for setup-code and manual connect, including storage, clearing, redaction, secure-transport, endpoint-change, fixed-header/cookie, and OIDC browser-return rules, then land proof-backed slices against that contract.
