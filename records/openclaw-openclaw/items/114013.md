## What This Changes

This PR decomposes Memory Core’s lazy CLI implementation into separate status, index/search, REM, and shared-support modules while keeping the existing lazy CLI entry boundary.

## System Context

Memory Core’s CLI accepts operator commands for status, indexing, search, promotion, and REM workflows. The lazy runtime loads command handlers, resolves configuration and secrets, acquires the memory manager, and emits command output or diagnostics.
