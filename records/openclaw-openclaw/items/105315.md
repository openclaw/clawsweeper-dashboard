The PR makes PDF page tokens and range endpoints require safe positive integers before PDF loading or analysis, with helper- and tool-level regression coverage.

## Best Possible Solution

Keep validation at the shared parser boundary, change the unsafe-range regression to use a small `maxPages` so the pre-fix behavior fails promptly, and preserve fail-before-I/O behavior plus existing valid-page clamping, sorting, and deduplication.
