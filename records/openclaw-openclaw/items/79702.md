## Summary

The PR remains useful and has convincing live proof for its tested Qwen path, but the advertised Nomic support is incorrect: Nomic requires task preprocessing for indexed documents as well as queries, while this patch deliberately leaves document batches raw. Likely related people: steipete is the strongest routing candidate from the memory-provider, SDK-boundary, and reindex history.

## What This Changes

The PR adds an opt-in `memorySearch.queryInstructionTemplate` setting, propagates it through memory and plugin/provider contracts, applies model-specific query prefixes for Qwen3, Nomic, and Mixedbread on OpenAI/OpenAI-compatible embeddings, and adds documentation and regression coverage.

## Best Possible Solution

Remove Nomic from this query-only option for the narrow repair, retain the verified Qwen3 and Mixedbread behavior, and separately design a family-specific query/document preprocessing contract with index-rebuild semantics if maintainers want full Nomic support.
