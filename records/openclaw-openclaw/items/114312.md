## What This Changes

The branch changes the Linux desktop updater so a manually requested update check also sends a native notification when the main webview is displaying the remote Gateway dashboard, preventing successful no-update results and check failures from disappearing silently.

## System Context

The Linux desktop app receives update checks from the tray and runs them through the native updater. Terminal results currently go to the main webview; this change chooses between that in-page path and the existing native-notification path based on whether the window is still showing local UI or remote Gateway content.
