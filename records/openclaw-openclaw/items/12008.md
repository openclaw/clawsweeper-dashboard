## Summary

Keep open: current main still lacks a typed Gemini safety-settings config surface and the Google GenerateContent request builder still returns payloads without `safetySettings`; the duplicate issues are closed and the prior implementation PR is closed unmerged, so this remains the canonical tracker.

## What This Changes

Request to add configurable Gemini safety thresholds under provider or model config and pass them to Google Gemini requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category and threshold validation, schema/help/docs/test coverage, Google-only request injection, and explicit precedence for per-request payload values after maintainer approval.
