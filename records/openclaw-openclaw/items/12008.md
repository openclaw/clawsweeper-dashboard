## Summary

Keep open: current main still lacks a typed Gemini safety-settings config field and the Google GenerateContent request builder still omits `safetySettings`; the earlier implementation PR is closed unmerged, so this remains the canonical tracker and needs maintainer product direction.

## What This Changes

Allow users to configure Gemini safety thresholds for Google/Gemini providers or models and pass them as `safetySettings` in outgoing Gemini requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category/threshold validation, schema/help/docs/test coverage, Google-only request injection, and explicit precedence for per-request payload values after maintainer approval.
