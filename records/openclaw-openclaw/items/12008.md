Keep open: current main and the latest release still lack a typed Gemini safety-settings config surface, the Google GenerateContent request path still omits `safetySettings`, and the earlier implementation PR is closed unmerged, so this remains the canonical tracker.

## What This Changes

Request configurable Gemini safety thresholds at provider or model level and map them into Google Gemini API requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category/threshold validation, schema/help/docs/test coverage, Google-only request injection, and explicit precedence for per-request payload values after maintainer approval.
