## Summary

Keep open: current main and the latest checked release still lack a typed Gemini safety-settings config field and do not emit `safetySettings` in Google GenerateContent payloads; the duplicate issues are closed and the prior implementation PR is closed unmerged.

## What This Changes

The issue requests configurable Gemini safety settings at the provider and/or model level so OpenClaw can pass thresholds into Google Gemini requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category/threshold validation, schema/help/docs/test coverage, Google-only request injection, and explicit precedence for per-request payload values after maintainer approval.
