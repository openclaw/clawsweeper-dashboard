## Summary

Keep open: current main and the latest release still lack a typed Gemini safety-settings config surface and the Google GenerateContent request builder still omits `safetySettings`; the prior implementation PR is closed unmerged, so this remains the canonical tracker for a maintainer-approved provider/config change.

## What This Changes

The issue requests configurable Gemini safety thresholds at provider or model level so OpenClaw can pass Google Gemini `safetySettings` in model requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category and threshold validation, schema/help/docs/test coverage, Google-only request injection, and explicit precedence for per-request payload values after maintainer approval.
