## Summary

Keep open: current main still has no typed Gemini safety-settings config key, no docs for that setting, and the direct Google GenerateContent payload builder still returns requests without `safetySettings`; the prior implementation PR is closed unmerged, so this issue remains the canonical tracker.

## What This Changes

Request to let users configure Google Gemini safety thresholds per provider or model and map them into Gemini API requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category and threshold validation, Google-only request injection, generated schema/help/docs coverage, request-precedence tests, and maintainer-approved safety wording.
