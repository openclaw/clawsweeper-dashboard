## Summary

Keep open: current main still lacks a typed Gemini safety-settings config field, the strict provider schema/help do not expose it, and the direct Google GenerateContent request builder still returns payloads without `safetySettings`; the earlier implementation PR is closed unmerged, so this remains the canonical tracker.

## What This Changes

Request to expose configurable Gemini safety thresholds for Google/Gemini model requests, likely under provider or model configuration.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category/threshold validation, schema/help/docs/test coverage, Google-only request injection, and explicit precedence for per-request payload values after maintainer approval.
