## Summary

Keep open: current main still lacks a typed Gemini safety-settings config surface and the direct Google Gemini request builder still returns payloads without `safetySettings`; the only implementation PR is closed unmerged, so this remains the canonical tracker.

## What This Changes

The issue requests configurable Gemini safety settings at provider and/or model level so OpenClaw can tune Google Gemini safety thresholds in outgoing requests.

## Best Possible Solution

Add a narrow, documented Google Gemini provider configuration contract with strict category/threshold validation, schema/help/docs/test coverage, Google-only request injection, explicit precedence for per-request payload values, and live Gemini proof after maintainer approval.
