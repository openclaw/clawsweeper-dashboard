## Summary

Current main still has no supported Gemini safety-settings configuration or request injection, while the prior implementation PR closed unmerged. The request remains valid, but relaxing provider safety filters and choosing the permanent configuration owner require maintainer product direction.

## What This Changes

Add configurable Gemini safety thresholds at provider or model scope and pass them to Google Generative AI requests.

## Best Possible Solution

Use one typed, provider-owned Gemini safety contract with validated categories and thresholds, explicit per-model override and payload-precedence rules, clear warnings, docs, and live Google request proof without adding parallel generic configuration paths.

Rationale: The capability intentionally changes provider safety policy and adds a compatibility-sensitive public configuration surface; repository policy cannot determine that product choice automatically.

Likely owner: steipete

Options:

- **Google-owned typed config (recommended):** Add a validated Google plugin-owned setting with optional per-model overrides, documented safety implications, and narrowly scoped request injection.
- **Generic provider field:** Add safetySettings to models.providers entries and define which google-generative-ai-compatible providers receive it, accepting the broader compatibility contract.
- **Do not expose overrides:** Keep provider defaults and explicit application-level request behavior as the safety boundary, then close the feature request.

## Reproduction Assessment

Yes for the missing capability: current source shows that the strict provider schema rejects the proposed setting and the Google request path does not emit safetySettings. This is a feature absence rather than a failing existing contract.

## Solution Assessment

Unclear until maintainers choose the public configuration owner and safety policy. The closed PR demonstrated a plausible implementation, but a Google-owned typed surface is more consistent with OpenClaw's provider-ownership rules than an unqualified generic provider field.
