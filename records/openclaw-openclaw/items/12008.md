## Summary

Keep open: current main still has no validated Gemini safety-settings surface or outbound `safetySettings` injection, the exact implementation PR closed unmerged, and a maintainer explicitly retained this issue for a product decision.

## What This Changes

Requests configurable Gemini safety thresholds at provider or model scope and forwarding them into Google Generative AI requests.

## Best Possible Solution

Use a Google-owned, typed safety-settings contract on the existing provider/model parameter seam, validate only supported Gemini categories and thresholds, inject it only for the intended Google transport, preserve explicit request-level values, and document policy and custom-endpoint behavior.
