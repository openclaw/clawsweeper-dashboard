## What This Changes

The branch lets the gateway accept narrowly scoped hash-free last-writer-wins updates under `ui.prefs` and changes the Control UI to retain and replay pending preference edits across reconnects and concurrent tabs.

## System Context

Control UI settings are mirrored between browser-local state and the gateway’s persisted `ui.prefs` configuration. Browser edits travel through `config.patch`; the gateway validates and writes configuration, then refreshed runtime configuration reconciles the UI.

## Architecture Diagram

flowchart LR

  B --> C[Gateway connection or reconnect]
  C --> D[Scoped config patch]
  D --> E[Gateway config validation and write]
  E --> F[Persisted ui.prefs]
  F --> G[Runtime config refresh]
  G --> H[UI reconciliation]

## Best Possible Solution

Keep a gateway-owned, leaf-only last-writer-wins path for `ui.prefs`, retain strict CAS everywhere else, and land only after maintainers accept that contract and visible redacted runtime proof demonstrates offline replay, concurrent tabs, and persisted post-reconnect state on the rebased head.
