## Summary

Keep this PR open. It addresses a plausible P1 regression at the correct gateway/UI ownership boundary, but the proposed hash-free `config.patch` exception needs maintainer acceptance and the PR still lacks inspectable after-fix real-gateway evidence.

## What This Changes

The branch lets the gateway accept narrowly constrained hash-free last-writer-wins writes for `ui.prefs` and makes the Control UI retain, reconcile, and replay pending settings edits after reconnects.

## System Context

Control UI settings are mirrored locally in the browser and synchronized to gateway configuration. Browser edits pass through the gateway’s configuration write path, then flow back through runtime configuration snapshots to update connected tabs and devices.
