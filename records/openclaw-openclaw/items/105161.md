## Summary

## What This Changes

The PR adds an optional abort signal to memory corpus supplement searches, forwards the `memory_search` deadline into memory-wiki, and reads exhaustive wiki pages in cancellation-aware batches that can return partial results.

## Best Possible Solution

Keep this cancellation-only design, but abort before vault initialization, document the public supplement contract, fix exact-head lint, preserve non-aborted exhaustive recall, and prove bounded post-deadline I/O through the real Gateway path.
