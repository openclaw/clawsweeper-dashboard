## Summary

Keep this PR open for repair. The previous partial-delivery and recursive-enumeration blockers were addressed, but the new soft deadline aborts the shared memory-search signal about one second early, so cooperative primary memory backends can now return the advertised 15-second timeout before 15 seconds have elapsed; exact-head real Gateway proof also does not yet demonstrate successful partial wiki recall.

## What This Changes

The PR adds deadline propagation to memory corpus supplements, introduces an early abort window for partial wiki results, and makes memory-wiki vault enumeration and page reads cancellation-aware.

## Best Possible Solution

Use separate hard-deadline and supplement-grace signals so primary memory retains the full 15-second budget while wiki supplements can return completed partial results and stop scheduling new vault I/O.
