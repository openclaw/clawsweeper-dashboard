## Summary

This PR usefully reduces post-timeout page reads, but it does not yet solve the linked user-visible timeout: the outer deadline commits to the timeout result before abort-aware wiki search can return completed partial pages. Recursive vault enumeration also remains uncancellable once started, and representative Gateway proof is still missing.

## What This Changes

The PR threads an optional AbortSignal from memory_search through the memory supplement API into memory-wiki and reads exhaustive fallback pages in cancellation-aware batches.

## Best Possible Solution

Add a supplement soft deadline before the stable outer hard timeout, or an equivalent bounded-result protocol, so completed wiki results reach memory_search in time; make vault enumeration and page reads cancellation-aware while preserving non-aborted exhaustive recall and direct wiki_search behavior.
