## Summary

This PR remains necessary because current main leaves in-flight bundle LSP requests pending after agent cancellation. Exact-head review found no blocking correctness or security defect, and the strong live proof plus green checks support landing rather than cleanup closure.

## What This Changes

Adds abort-signal handling to bundle LSP requests, sends `$/cancelRequest`, centralizes pending-request cleanup, and covers hover, definition, and references cancellation.

## Best Possible Solution

Land the exact-head request-scoped cancellation path after normal maintainer gating, keeping server initialization, shutdown, and unrelated shared-session requests independent from a single tool abort.
