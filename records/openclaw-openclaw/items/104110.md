## Summary

The PR makes bundle LSP hover, definition, and references requests honor tool abort signals, emit `$/cancelRequest`, clean pending request state, and adds focused cancellation coverage.

## Best Possible Solution

Land the request-scoped cancellation path after normal exact-head checks, keeping initialization, shutdown, and the shared LSP process independent from individual tool-call aborts.
