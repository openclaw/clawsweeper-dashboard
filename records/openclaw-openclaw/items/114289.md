## Summary

## What This Changes

This PR removes filesystem and SQLite polling from reusable plugin registry snapshots, making supported install, reload, and persisted-index write lifecycle events the way metadata changes become visible.

## System Context

Plugin discovery produces registry metadata consumed by Gateway and control-plane lookups. A bounded process memo reuses that metadata until plugin installation, reload, or persisted-index writes explicitly clear the lifecycle cache.
