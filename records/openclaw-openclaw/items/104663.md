## What This Changes

The branch applies the selected Feishu account HTTP timeout as response-header and body-idle deadlines for remote docx image reads, preserves existing remote file reads, and adds focused regression coverage.

## Best Possible Solution

Land the Feishu-local adapter that reuses the shared media reader with header and idle deadlines from the selected account, while keeping remote file uploads on their existing behavior and avoiding any total-transfer deadline.
