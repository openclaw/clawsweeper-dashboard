## Summary

Current main still exhibits both reported behaviors. The issue is fresh, aligned with current web-frontend priorities, and carries the protected `maintainer` label, so it should remain open for explicit maintainer handling.

## What This Changes

Add automatic older-page loading with stable viewport anchoring and better rendering or omission of structured-only items in read-only external catalog transcripts.

## Best Possible Solution

Reuse the existing Chat scroll lifecycle for a top sentinel, inline loading state, failure fallback, and measured viewport anchoring, while provider adapters normalize a narrow set of structured items into portable presentation data and unknown shapes are skipped cleanly.

## Reproduction Assessment

Yes. Current-main source shows that older catalog pages are invoked only through the manual callback and that textless items deterministically receive the unsupported placeholder; the existing Claude Playwright scenario also encodes the manual-button behavior.

## Solution Assessment

Yes, with one boundary refinement. Automatic sentinel loading and viewport anchoring are the narrow maintainable UX fix, but structured items should be normalized by provider adapters into portable presentation data rather than parsed ad hoc from opaque `raw` records in the UI.
