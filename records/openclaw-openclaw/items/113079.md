## What This Changes

Prevent the LINE channel from sending oversized postback data or URL actions that cause LINE to reject the complete reply with HTTP 400.

## System Context

The LINE extension transforms agent directives and structured channel data into Flex, template, imagemap, and quick-reply payloads before sending them through LINE’s Messaging API. If any action violates LINE’s per-field limits, LINE rejects the whole outbound message, so valid reply text and cards are lost too.
