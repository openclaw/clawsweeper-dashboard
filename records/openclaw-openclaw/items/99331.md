## Summary

Keep this PR open for repair: the one-line change is not mergeable because it breaks the Tool Search code-mode bridge inside the isolated VM context, where `structuredClone` is not available and bridge argument arrays collapse to strings before reaching the parent runtime.

## What This Changes

This PR replaces the JSON round-trip inside the Tool Search code-mode child helper with `structuredClone`.

## Best Possible Solution

Keep the bridge JSON-safe with a serializer that works inside the VM context, preserves plain JSON arrays/objects for args and results, degrades unsupported native values deterministically, and has focused Tool Search code-mode coverage.

## Reproduction Assessment

Yes. A Node 24 VM probe reproduces the PR-introduced failure: `structuredClone` is unavailable in the sandbox and the patched helper returns `[object Array]` for bridge args instead of an array.

## Solution Assessment

No. Replacing the JSON-safe bridge serializer with `structuredClone` is the wrong layer because the data must survive the VM realm, child-process IPC, JSON parsing, and transcript projection.
