## Summary

Keep open for explicit maintainer merge review. Current main still excludes runtime-discovered providers from the supplemental manifest list, while this PR narrowly admits only validated `runtime-refresh` rows and preserves live runtime rows as the deduplication authority; the submitted production Gateway evidence is strong, and the `maintainer` label requires human handling.

## What This Changes

Adds refreshed hosted-catalog models to provider-filtered lists for runtime-owned providers such as OpenAI without replacing live runtime discovery results.

## System Context

`openclaw models list` combines configured models, live provider discovery, and manifest-backed catalog rows into CLI output. The hosted refresh overlay persists validated model metadata, and this change lets provider-filtered runtime lists display those refreshed rows after they pass through the existing source-selection and deduplication path.
