## Summary

Keep this PR open for revision: the cache bound is worthwhile, but the eviction branch removes an unrelated entry when an already-cached session receives a changed warning context, and the external PR has no after-fix real behavior proof.

## What This Changes

The PR adds a 512-entry FIFO bound to the in-memory session-maintenance warning deduplication map.

## Best Possible Solution

Evict the oldest entry only when the incoming `sessionKey` is absent, preserve existing-key context updates without shrinking the cache, and cover both existing-key and 513th-distinct-key behavior with focused tests and redacted runtime proof.
