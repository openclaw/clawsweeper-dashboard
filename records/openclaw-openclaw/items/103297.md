## Summary

## Best Possible Solution

Make loss of either non-PTY command output stream record a managed execution failure and terminate through the existing close-owned finalization path, add stderr regression coverage for failed finalization and notification order, then provide redacted process-level proof from the actual sandbox exec-server path.
