## Summary

Keep this PR open, but it is not merge-ready: the reported crash class is valid, while the proposed fatal path violates the managed-process lifecycle by reporting closure and finalizing before the child has actually terminated. The contributor must also provide real after-fix behavior proof.

## What This Changes

The PR adds fatal stdout-stream error handling and warning-only stderr-stream error handling to Codex sandbox child-process execution.

## Best Possible Solution

On stdout failure, preserve the failure message and terminate the child, but leave terminal notifications, waiter release, eviction, and backend finalization to the existing child `close` path; keep stderr failure warning-only and add direct regression and runtime proof.
