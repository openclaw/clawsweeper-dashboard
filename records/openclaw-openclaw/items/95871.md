Fix issue #95871. In isolated cron agent runs, preserve the underlying embedded Codex incomplete-turn or `missing_tool_result` cause when the cron timeout cleanup/drain path has already observed or can obtain structured agent diagnostics, instead of returning only `cron: job execution timed out (last phase: ...)`. Keep the #95943 provider/model/session attribution behavior, keep true pre-runner setup timeouts as setup timeouts, and do not add config/env knobs or broaden timeout budgets. Add deterministic regression coverage where a mocked embedded/Codex run records `missing_tool_result` and then loses the timer race, asserting cron-visible error/diagnostics preserve that cause. If proving native web_search itself requires live Codex credentials, stop and report the proof gap.
