## What This Changes

The branch records exact `$include` ownership while resolving configuration so config mutation can write through only to an isolated, unambiguous top-level included file.

## System Context

OpenClaw expands `$include` directives into an effective configuration snapshot, then config mutation code chooses whether a changed top-level section can be persisted back into an included file. This change carries structured ownership facts from include resolution into that write-routing decision and preserves root-file writes when ownership is ambiguous.
