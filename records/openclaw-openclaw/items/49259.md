## Summary

Keep open: current main still lacks the requested Dashboard prune flow for old Telegram/Discord orphan sessions. The existing implementation supports explicit selected-session deletion and generic maintenance cleanup, but durable external conversation pointers are intentionally preserved, so this needs a maintainer product and ownership decision before destructive pruning is added.

## What This Changes

Request a Dashboard Sessions feature that previews and deletes stale Telegram/Discord orphan sessions older than a configurable age, with a 48-hour default and optional automatic pruning.

## Best Possible Solution

Add a maintainer-approved Dashboard preview/apply prune flow backed by plugin-owned Telegram/Discord reachability checks, fresh revalidation before deletion, explicit transcript-retention behavior, and a clear age/config or auto-prune policy.
