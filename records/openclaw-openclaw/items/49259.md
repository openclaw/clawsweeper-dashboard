Keep open: current main has manual selected-session delete and generic session cleanup, but not the requested Dashboard preview/prune flow for stale orphaned Telegram or Discord sessions. The remaining work is destructive cross-channel session-state behavior, so it needs maintainer product direction before implementation.

## What This Changes

Add a Dashboard Sessions workflow to preview and prune stale session rows whose backing Telegram topic/channel or Discord channel/thread no longer exists, with configurable age and optional auto-prune behavior.

## Best Possible Solution

Define a preview-first Dashboard prune design that uses channel-owned reachability adapters, preserves or archives transcripts, requires operator confirmation, and only then adds any age/default or auto-prune setting.
