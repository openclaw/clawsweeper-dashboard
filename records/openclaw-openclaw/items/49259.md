## Summary

Keep open: current main and the latest release still provide manual selected-session deletion and generic session cleanup, but no Dashboard flow that previews and prunes old Telegram/Discord sessions after channel/topic reachability checks.

## What This Changes

Add a Dashboard Sessions prune flow that detects old orphaned Telegram/Discord-backed sessions, previews eligible rows, and deletes them with a configurable age threshold.

## Best Possible Solution

Define a preview-first Dashboard prune flow backed by plugin-owned Telegram/Discord reachability checks, revalidation immediately before deletion, and explicit transcript-retention/default-age policy.
