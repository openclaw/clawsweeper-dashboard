## Summary

Keep this PR open: current main and the latest release still have the omitted-cap Google Chat media path, and the branch fixes it with focused tests and sufficient proof. Merge should stay maintainer-gated because omitted `maxBytes` changes from uncapped buffering to a 20 MiB fail-closed default.

## What This Changes

The branch adds a 20 MiB default byte cap to Google Chat media downloads when `maxBytes` is omitted and expands target tests for content-length fast-fail, chunked overflow cancellation, and explicit-cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit `maxBytes` caller choice.
