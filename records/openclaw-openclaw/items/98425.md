The PR changes Google Chat media downloads so omitted `maxBytes` uses a 20 MiB default cap and adds regression tests for content-length fast-fail, chunked overflow cancellation, guard release, and explicit-cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit `maxBytes` caller choice.
