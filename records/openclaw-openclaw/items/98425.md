## What This Changes

The PR makes direct Google Chat media downloads use a 20 MiB response limit when a caller omits `maxBytes`, while retaining stricter explicit limits.

## System Context

The Google Chat plugin downloads attachment media through a helper that turns an HTTP response into a buffer for inbound message targets. The helper sits between guarded network fetching and attachment handling, so its byte limit determines whether oversized media can consume gateway memory.
