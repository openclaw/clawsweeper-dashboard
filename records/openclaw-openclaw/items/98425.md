## Summary

Keep open: the PR is a focused Google Chat media resource-safety fix with no blocking code findings, but it still needs normal maintainer landing because it intentionally changes omitted-`maxBytes` helper calls from uncapped buffering to fail-closed behavior.

## What This Changes

The PR defaults omitted Google Chat media download caps to 20 MiB, removes the uncapped `arrayBuffer()` branch, and adds regression coverage for content-length and chunked overflow paths.

## Best Possible Solution

Land the bounded 20 MiB helper default after maintainers accept the fail-closed compatibility behavior and clear the normal landing checks, while preserving stricter explicit `maxBytes` callers.

Yes. The best fix is at the Google Chat helper boundary: default omitted caps to the established 20 MiB media limit and use the shared bounded response reader while preserving explicit stricter caps.
