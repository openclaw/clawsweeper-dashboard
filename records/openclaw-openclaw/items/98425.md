## Summary

Keep this PR open for maintainer review: the patch is a correct, focused fix for a current-main and latest-release Google Chat media-download bug, but it intentionally changes exported helper behavior from uncapped omitted `maxBytes` to a 20 MiB fail-closed default.

## What This Changes

The branch changes Google Chat media downloads so omitted `maxBytes` uses a 20 MiB default cap, removes the uncapped `arrayBuffer()` branch, and adds regression tests for content-length, streamed overflow, and explicit-cap behavior.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests after maintainers accept the direct-helper compatibility tradeoff and exact-head landing checks pass.
