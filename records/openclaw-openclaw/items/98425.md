## Summary

Keep this PR open: current main and the latest release still have the uncapped omitted-`maxBytes` Google Chat media path, while the PR is a focused fix with integrated proof. The remaining maintainer-visible point is the intentional fail-closed helper default for direct callers that previously omitted a cap.

## What This Changes

This PR adds a 20 MiB default cap to Google Chat media downloads when `maxBytes` is omitted and extends target tests for content-length fast-fail, streamed overflow cancellation, and explicit-cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit `maxBytes` caller choice.
