## What This Changes

The branch makes Google Chat media downloads use a 20 MiB response limit when a direct caller omits `maxBytes`, while preserving stricter explicit limits and adding declared-length and chunked-stream overflow tests.

## System Context

The Google Chat extension downloads remote media for inbound attachments through a shared helper before attachment processing. This PR changes the helper’s unbounded successful-response path so oversized remote bodies fail before they can grow gateway memory without a limit.
