## Summary

Keep open: this PR remains necessary because current main and the latest release still have the omitted-`maxBytes` Google Chat media path that can reach an uncapped `arrayBuffer()` read. The patch looks correct with no blocking findings, but the 20 MiB fail-closed fallback is an upgrade-visible helper-contract change that should be accepted by a maintainer before landing.

## What This Changes

This PR defaults omitted Google Chat media `maxBytes` to the existing 20 MiB Google Chat media cap and adds regression coverage for content-length fast-fail, streamed overflow cancellation, guard release, and explicit cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit `maxBytes` caller choice.
