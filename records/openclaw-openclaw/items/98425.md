## What This Changes

This PR changes Google Chat media downloads so omitted `maxBytes` uses a 20 MiB bounded read and adds regression tests for content-length rejection, streamed overflow cancellation, and explicit-cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit `maxBytes` caller choice.
