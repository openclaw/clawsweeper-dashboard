## Summary

Keep open: this is a valid Google Chat media resource-safety fix, but it intentionally changes the exported helper's omitted-`maxBytes` behavior from uncapped to a 20 MiB failure, so maintainer acceptance is still needed before landing.

## What This Changes

The branch defaults omitted Google Chat media download `maxBytes` to 20 MiB, removes the uncapped successful-response `arrayBuffer()` path, and adds regression coverage for content-length and streamed overflow cases.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit caller-supplied `maxBytes` choice.
