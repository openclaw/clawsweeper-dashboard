## Summary

Keep open for maintainer review: the patch fixes a real Google Chat media resource-safety bug and has no blocking code findings, but the exported helper's omitted-`maxBytes` behavior changes from uncapped to fail-closed at 20 MiB, so maintainers should explicitly accept that compatibility tradeoff before landing.

## What This Changes

This PR adds a 20 MiB default cap to Google Chat media downloads when `maxBytes` is omitted and extends Google Chat target tests for content-length and streamed overflow behavior.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit `maxBytes` caller choice.
