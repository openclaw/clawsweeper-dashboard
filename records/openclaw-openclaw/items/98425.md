## Summary

This PR remains useful and should stay open for maintainer landing: the branch removes the uncapped Google Chat media `arrayBuffer()` fallback, preserves explicit caller caps, and includes strong loopback proof for bounded reads. The only remaining gate is the deliberate compatibility tradeoff for direct helper callers that omit `maxBytes`.

## What This Changes

The PR changes Google Chat media downloads so omitted `maxBytes` uses the existing 20 MiB media cap and adds regression tests for content-length fast-fail, streamed overflow cancellation, and explicit-cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests, while treating larger direct-helper downloads as an explicit caller choice through `maxBytes`.
