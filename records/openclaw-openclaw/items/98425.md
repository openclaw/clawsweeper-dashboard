## Summary

The patch is correct and well-proven, so this PR should stay open for maintainer landing rather than cleanup closure. The remaining maintainer decision is accepting the compatibility change from uncapped omitted-`maxBytes` Google Chat media downloads to a 20 MiB fail-closed default.

## What This Changes

The branch changes Google Chat media downloads so omitted `maxBytes` defaults to a 20 MiB bounded read and adds target tests for content-length and chunked overflow behavior.

## Best Possible Solution

Land the bounded 20 MiB helper default after maintainers accept the fail-closed compatibility behavior, while preserving stricter explicit `maxBytes` callers.

## Reproduction Assessment

Yes. Source inspection on current main shows omitted `maxBytes` reaches the unbounded `res.arrayBuffer()` branch in `fetchBuffer`; this read-only review did not run the test suite.

## Solution Assessment

Yes. The best fix is at the Google Chat helper boundary: default omitted caps to the established 20 MiB media limit and use the shared bounded response reader while preserving explicit stricter caps.
