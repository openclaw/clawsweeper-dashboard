## Summary

This remains a necessary, focused bug fix: current main still permits an omitted `maxBytes` to buffer an unbounded successful Google Chat media response, while this PR adds the channel’s established 20 MiB default with strong streamed-response proof and no blocking findings. The intentional compatibility change has already received maintainer-authored direction, so the remaining work is ordinary synchronization and landing review.

## What This Changes

Adds a 20 MiB default response limit when Google Chat media callers omit `maxBytes` and expands regression coverage for header and streamed-body overflow, cancellation, cleanup, and explicit stricter limits.

## Best Possible Solution

Land the helper-boundary 20 MiB default while preserving explicit stricter limits, streamed cancellation, the established error text, and the configured inbound attachment cap.
