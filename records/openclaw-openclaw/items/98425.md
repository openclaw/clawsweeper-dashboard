## Summary

Keep this PR open: the patch is a focused, well-proven fix for a real Google Chat media resource-safety bug, but the omitted-`maxBytes` helper behavior changes from uncapped to fail-closed at 20 MiB, so maintainer acceptance of that compatibility tradeoff is still the right merge gate.

## What This Changes

This PR defaults omitted Google Chat media `maxBytes` to a 20 MiB bounded read and adds regression coverage for content-length fast-fail, chunked overflow cancellation, and explicit cap preservation.

## Best Possible Solution

Land the 20 MiB fail-closed helper default with the integrated regression tests after maintainer acceptance, leaving larger direct-helper downloads as an explicit `maxBytes` caller choice.
