## Summary

Keep open. Current main still preserves the Slack DM/channel self-activity blind spot: Slack DMs and channels use separate session buckets, outbound message-tool sends are mirrored only to the destination route, and the merged Slack `message_sent` hook work is an adjacent signal rather than a DM-visible recall mechanism.

## What This Changes

The issue requests Slack behavior that lets an agent in a DM/main session recall and reference its own outbound Slack channel messages without losing cross-context continuity.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack team/account, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
