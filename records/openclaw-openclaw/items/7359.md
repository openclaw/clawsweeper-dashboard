## Summary

Keep open. Current main still has the Slack DM/channel self-activity blind spot: Slack DMs and Slack channels resolve to separate session keys, outbound message-tool sends mirror only to the destination session, and the merged Slack `message_sent` hook work provides observer signals but not a DM-visible recall path.

## What This Changes

The issue requests a Slack mechanism for an agent in a DM session to recall its own outbound channel messages and related cross-session activity.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
