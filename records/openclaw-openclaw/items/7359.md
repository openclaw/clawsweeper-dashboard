## Summary

Keep open. Current main still has the reported Slack DM/channel self-activity blind spot: Slack DMs and channel sends remain separate session buckets, outbound message-tool sends mirror only to the destination session, and the merged Slack sent-hook work does not provide a DM-visible recall surface.

## What This Changes

The issue requests Slack-aware self-activity recall so an agent asked in a DM can know about its own prior outbound messages sent to Slack channels.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
