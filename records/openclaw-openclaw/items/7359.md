## Summary

Keep open. This is a distinct request to expose an agent’s own Slack channel activity from a DM session, not the already-closed DM-history defect; it needs an explicit privacy, authorization, and retention contract before implementation can be safely scoped.

## What This Changes

Add a safe way for an agent in a Slack DM session to recall its own messages sent to Slack channels or threads.

## System Context

Slack inbound events and outbound message-tool sends are assigned to session-specific transcripts. The requested behavior would bridge selected outbound channel activity into a DM-facing recall surface without broadly merging independent conversations.

## Architecture Diagram

## Best Possible Solution

Define a narrowly scoped Slack self-activity recall contract keyed to agent and workspace identity, destination channel/thread, and message identity, exposing only the agent’s own outbound records after authorization and retention rules are approved.
