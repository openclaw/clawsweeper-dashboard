## Summary

Keep open. Current main still has the Slack DM/channel self-activity blind spot: Slack DMs and Slack channels use separate session buckets, outbound sends are mirrored only to the destination session, and default session-tool visibility does not expose sibling channel history back to a DM turn.

## What This Changes

The issue requests Slack DM visibility into the agent's own outbound Slack channel messages so the agent can recall and follow up on channel activity from a DM session.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
