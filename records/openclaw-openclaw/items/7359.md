## Summary

Keep open: current main still mirrors outbound Slack channel sends into the destination channel session while default session-tool visibility keeps sibling channel sessions hidden from a DM/main turn. The remaining fix is a security-sensitive product design, not conservative cleanup.

## What This Changes

The issue requests a Slack-scoped way for an agent in a DM session to recall its own outbound messages sent to Slack channels so cross-context follow-up remains coherent.

## Best Possible Solution

Add an opt-in Slack self-activity recall path, such as a scoped outbound activity ledger keyed by agent id, Slack team/account, destination channel/thread, and Slack message id/timestamp, and expose only the agent's own outbound channel messages to DM/main sessions without merging full channel transcripts.
