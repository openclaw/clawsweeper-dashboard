## Summary

Keep open: current main still routes Slack DMs and Slack channel sends into separate session buckets, mirrors outbound sends only into the destination session, and lacks a DM-visible self-activity recall boundary.

## What This Changes

The issue requests Slack DM/main-session visibility into the agent's own outbound channel messages without losing conversational coherence across Slack contexts.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
