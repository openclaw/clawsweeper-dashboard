## Summary

Keep open. Current main still has the Slack DM/channel self-activity blind spot: outbound channel sends are routed and mirrored to the destination Slack session, while default session-tool visibility does not expose that sibling channel session back to the DM/main turn.

## What This Changes

Request Slack DM/main sessions to recall the agent's own outbound Slack channel messages and maintain coherent self-activity context across Slack conversations.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts.

## Reproduction Assessment

Yes, at source level. Current main routes Slack DMs and Slack channel sends to distinct session keys, mirrors outbound sends only to the destination session, and default tree session visibility denies sibling channel history from the DM/main turn.

## Solution Assessment

No for the broad unified-session or generic cross-session-history options in the discussion. The safer path is a narrow authorization-aware self-activity recall mechanism, potentially fed by message_sent signals, rather than merging full Slack DM and channel transcripts.
