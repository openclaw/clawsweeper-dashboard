## What This Changes

The issue requests Slack-aware recall of an agent's own outbound channel messages from a DM session without losing cross-context conversation coherence.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts.

## Solution Assessment

No for the broad unified-session or generic cross-session-history options in the discussion. The safer solution is a narrow authorization-aware self-activity recall mechanism, potentially fed by message_sent signals, rather than merging full Slack DM and channel transcripts.
