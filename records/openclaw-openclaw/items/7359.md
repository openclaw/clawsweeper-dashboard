## Summary

Keep open. Current main still keeps Slack DM/main sessions and Slack channel sessions in separate session buckets, mirrors message-tool sends only into the destination session, and does not expose sibling channel history back to a DM turn by default.

## What This Changes

Request Slack DM sessions be able to recall the agent's own outbound Slack channel messages and follow up coherently across Slack session boundaries.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
