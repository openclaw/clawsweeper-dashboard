## Summary

Keep open. Current main still keeps Slack DM/main and channel sessions separate, mirrors message-tool sends only into the destination Slack session, and the merged Slack sent-hook work is adjacent plumbing rather than a DM-visible self-activity recall path.

## What This Changes

The issue asks for Slack DM/main sessions to recall the agent's own outbound messages sent to Slack channels.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.

Yes, at source level. Current main routes Slack DMs and Slack channel sends to distinct session keys, mirrors outbound sends only to the destination session, and default tree session visibility denies sibling channel history from the DM/main turn.

## Solution Assessment

No for the broad unified-session or generic cross-session-history options in the discussion. The safer solution is a narrow authorization-aware self-activity recall mechanism, potentially fed by message_sent signals, rather than merging full Slack DM and channel transcripts.
