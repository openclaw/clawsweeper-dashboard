## Summary

Keep open. Current main still separates Slack DM/main and channel sessions, mirrors outbound sends only into the destination session, and the Slack sent-hook work is adjacent plumbing rather than a DM-visible self-activity recall path.

## What This Changes

The issue requests Slack DM/main sessions to recall the agent's own outbound messages sent to Slack channels.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
