## Summary

Keep open. Current main still has the Slack cross-session blind spot: Slack DMs and channels resolve to separate session keys, message-tool sends are mirrored only into the destination session, and default session-tool visibility does not expose sibling channel sessions back to a DM turn.

## What This Changes

The issue requests Slack DM sessions to recall the agent’s own outbound Slack channel messages and maintain coherent self-activity context across Slack sessions.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized outbound messages without merging full transcripts or widening general session visibility.

## Reproduction Assessment

Yes, at source level. Current main routes Slack DMs and Slack channels into separate session keys, mirrors outbound sends to the destination session, and default tree session visibility denies the sibling channel session.

## Solution Assessment

No for the broad unified-session options in the discussion. A narrow, authorization-aware self-activity recall path is safer than merging full Slack DM and channel transcripts or globally widening session visibility.
