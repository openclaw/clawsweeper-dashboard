## Summary

Keep open. The reported behavior remains a distinct Slack cross-session recall problem: same-agent DM and channel sessions are intentionally isolated, while the broad same-agent visibility path would expose more sibling-session history than the requested self-activity recall. A maintainer must first define the privacy and authorization contract before implementation can safely proceed.

## What This Changes

Add a privacy-scoped way for a Slack DM session to recall the agent’s own outbound messages sent to Slack channels or threads.

## Best Possible Solution

Define and implement an opt-in, Slack-scoped outbound self-activity ledger keyed by agent, Slack account/workspace, destination, and message identity; expose only the agent’s own eligible outbound records to a requesting DM instead of merging full sibling transcripts.
