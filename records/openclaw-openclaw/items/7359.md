## Summary

Keep open. Current main preserves separate Slack DM/main and channel sessions; outbound content can be persisted in the destination session, but default session-tool visibility remains limited to the current session and spawned descendants. The existing broader `tools.sessions.visibility: "agent"` setting can expose same-agent transcripts, but making that the answer would widen access beyond the requested self-authored Slack activity. The June Slack transcript-mirroring work improves destination transcript durability but does not create privacy-scoped recall from a DM. ([openclaw-openclaw.mintlify.app](https://openclaw-openclaw.mintlify.app/concepts/sessions))

## What This Changes

Add a privacy-scoped way for an agent operating in a Slack DM to recall its own outbound messages and conversations in Slack channels.

## Best Possible Solution

Add a generic, SQLite-backed self-authored activity index keyed by agent, channel account/workspace, destination, thread, and transport message ID; expose a bounded query surface that returns only successfully delivered agent-authored messages, honors edits/deletions and retention, and does not grant general sibling-transcript access.

Options:

- **Document agent visibility:** Treat `tools.sessions.visibility: "agent"` plus session tools as the supported opt-in, accepting that it exposes broader same-agent transcript content.
- **Unify selected sessions:** Pursue the broader shared-session grouping direction tracked by https://github.com/openclaw/openclaw/issues/19929, accepting larger routing and privacy changes.

## Reproduction Assessment

Yes, source-level: with default `tree` visibility, send from a DM session to a Slack channel and then ask the DM session to inspect that sibling channel activity; the destination session may contain the send, but the DM cannot list or read that sibling by default.

## Solution Assessment

No single proposed option in the issue is yet the best fix. Full session merging is too broad, while a shared message log needs explicit authorization and lifecycle semantics; a scoped self-authored activity index is the narrowest maintainable direction.
