## Summary

Keep open. Current main still has the Slack DM/channel self-activity blind spot: Slack DMs and channels use separate session buckets, outbound sends are mirrored only to the destination session, and default session-tool visibility does not expose sibling channel history back to a DM turn.

## What This Changes

Requests a Slack self-activity recall path so a DM/main session can answer questions about the agent's own outbound Slack channel messages.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only authorized agent-authored outbound messages without merging full transcripts or widening general session visibility.
