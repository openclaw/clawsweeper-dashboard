## Summary

Keep open. Current main still has the Slack self-activity blind spot: Slack DM/channel routes remain separate, outbound message sends mirror only into the destination session, and default session-tool visibility does not expose sibling channel sessions back to a DM turn.

## What This Changes

The issue asks for Slack DM sessions to recall the agent's own outbound messages sent to Slack channels so cross-context follow-up remains coherent.

## Best Possible Solution

Add a bounded Slack self-activity recall path keyed by agent, Slack account/team, destination channel/thread, and Slack message id/timestamp, exposing only the agent's own authorized outbound messages without merging full transcripts or widening general session visibility.

## Reproduction Assessment

Yes, at source level. Current main routes Slack DMs and channels into separate session keys, mirrors outbound sends to the destination session, and default tree session visibility denies sibling sessions.

## Solution Assessment

No for the broad unified-session options proposed in the discussion. A narrow, authorization-aware self-activity recall path is safer than merging full Slack DM and channel transcripts or globally widening session visibility.
