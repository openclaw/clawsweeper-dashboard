## Summary

This PR remains necessary because current main and the latest release still leave workspace-loaded Cloud SDK controls beyond `CLOUDSDK_PYTHON` able to affect Gmail setup. The patch is technically correct and well-proven, but its intentionally broader compatibility boundary needs explicit owner approval before merge.

## What This Changes

The PR blocks all workspace-loaded `CLOUDSDK_*` variables, clears inherited `CLOUDSDK_PYTHON_ARGS` for Gmail `gcloud` launches, and makes explicit `undefined` child-environment overrides remove inherited keys.

## Best Possible Solution

Adopt the fail-closed workspace `CLOUDSDK_*` boundary and explicit child-environment removal contract, while retaining trusted shell and global dotenv sources for intentional Cloud SDK configuration.
