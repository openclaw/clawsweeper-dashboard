## What This Changes

Make the native Control UI sidebar request and append later Gateway session pages when Show more is used, so sessions beyond the initial page remain reachable.

## System Context

The Control UI sidebar renders session lists returned by the Gateway. The Gateway supplies page rows plus continuation metadata, and the sidebar must carry the selected agent, active/archive filter, and connection generation into each subsequent request before appending results.

## Architecture Diagram

## Best Possible Solution

Confirm the current sidebar continuation path, then make Show more request the next authoritative Gateway page and append it only when the request still matches the active agent, filter, and connection generation; add focused regression coverage for multiple active, selected-agent, and archived pages.
