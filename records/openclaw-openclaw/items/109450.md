## Summary

Keep this PR open for revision: the intended availability fix is useful, but the synchronous timeout does not bound the reported stuck-filesystem case because Node waits for the child to exit after signaling it, and no real after-fix behavior proof is provided.

## What This Changes

Adds a two-second timeout to the synchronous `git symbolic-ref` probe used when resolving branch data for the session footer.

## Best Possible Solution

Remove the synchronous Git subprocess from the footer render path where the existing HEAD/worktree metadata parser is sufficient; otherwise resolve Git asynchronously outside rendering with a true outer deadline and cached fallback, backed by a controlled stalled-child regression test.
