## What This Changes

Issue reports that npm-managed Gateway self-update can fail with `managed-service-handoff-parent-timeout` before active Gateway work finishes draining.

## Best Possible Solution

Land or deliberately replace the linked helper-level fix so the parent-exit wait aligns with the Gateway restart drain budget and is covered by focused regression tests.
