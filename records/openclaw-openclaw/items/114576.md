## What This Changes

The PR snapshots an active Gateway preamble after a session message subscription is installed, then reconciles that snapshot into the Control UI chat stream so progress remains visible when opening a running session.

## System Context

The Gateway session observer receives in-progress agent preamble events and exposes session data to connected clients. Control UI subscribes to the selected session, receives the authoritative preamble snapshot, and combines it with later live stream events in the chat transcript.
