## Summary

Keep this issue open: current main still sends active-memory recall through the embedded OpenClaw harness when the configured runtime resolves to `claude-cli`, and the linked candidate fix remains open and unmerged. citeturn316770view0turn340857view0turn758244view0

## What This Changes

Make embedded active-memory recall honor subscription-authenticated Claude CLI runtime routing instead of performing a direct metered Anthropic API call.

## Best Possible Solution

Land a generic runtime-owned dispatch path that routes OAuth-only `claude-cli` embedded helpers through the CLI backend, preserves embedded-run contracts, leaves API-key routes unchanged, and includes focused fresh-install and real OAuth-only runtime proof for active-memory and another one-shot caller.
