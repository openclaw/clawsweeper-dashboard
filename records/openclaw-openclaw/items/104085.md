## Summary

The heartbeat-noise bug remains valid, but this patch violates the existing anti-spoofing invariant: it treats user-visible marker text as trusted runtime provenance and can suppress a genuine assistant turn from the dream corpus. The linked issue should remain open while this PR is repaired or replaced, and after-fix real behavior proof is still required.

## What This Changes

The PR changes session-corpus ingestion to skip the assistant message immediately following a filtered heartbeat-marker user message.

## Best Possible Solution

Persist or carry trustworthy internal heartbeat-turn provenance into the transcript boundary, use that closed fact to exclude the paired acknowledgment, and cover both genuine heartbeat and user-spoofed marker sequences with regression tests.
