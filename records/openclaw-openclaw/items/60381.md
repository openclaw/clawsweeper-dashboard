## Summary

Keep open: current main and v2026.6.11 already implement gated browser `act:evaluate`, but the requested `force` click parameter is still absent from the browser tool schema, action type, normalizer, and Playwright click execution. The remaining work is small but needs maintainer product/security approval because force click deliberately bypasses Playwright actionability checks.

## What This Changes

Request to add an optional `force` flag to browser click actions and expose page/ref JavaScript evaluation through the browser act tool.

## Best Possible Solution

Keep the existing gated evaluate implementation, then add force click only if maintainers approve it as an explicit last-resort browser action with schema/types/normalization/runtime/CLI/docs/tests and live overlay-click proof.
