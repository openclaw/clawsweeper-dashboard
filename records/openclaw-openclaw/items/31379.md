## Summary

Keep open: current main and the latest release still let a custom-only channel snapshot become the entire Channels settings card list, and the linked open fork PR is the existing implementation candidate rather than a reason to close this issue.

## What This Changes

## Best Possible Solution

Land or replace the focused UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
