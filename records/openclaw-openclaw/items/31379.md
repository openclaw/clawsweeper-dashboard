- `impact:ux-friction`: The Channels settings page can hide built-in setup options after adding a custom channel, creating avoidable discovery and setup confusion.

## Summary

Keep this issue open: current main still treats backend `channelMeta` or `channelOrder` as the complete Channels settings render list, so a custom-only snapshot can still hide the built-in cards. The open cross-repo PR is a candidate fix, but it is unmerged and targets the old UI path, so it should be reviewed, ported, or closed before this issue is resolved.

## What This Changes

The issue requests that the Control UI Channels settings page always show built-in channel cards alongside custom channel plugins.

## Best Possible Solution

Land a small Control UI fix in `ui/src/pages/channels/view.ts` that dedupes snapshot-provided custom channels with the built-in card order, with focused regression coverage and real Control UI proof; then resolve or close the existing candidate PR accordingly.
