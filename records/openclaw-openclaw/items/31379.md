## Label Justifications

- `P2`: This is a normal-priority Control UI discovery bug with limited blast radius and no evidence of broken runtime or message delivery.
- `impact:ux-friction`: Users can lose visible setup and discovery cards for built-in channels after enabling only a custom channel plugin, creating avoidable setup confusion without fully blocking progress.

## Summary

Keep open: current main and v2026.6.11 still treat `channelMeta` or `channelOrder` as the complete Channels card list, so a custom-only snapshot can hide built-in channel discovery cards. The open linked implementation candidate at https://github.com/BingqingLyu/openclaw/pull/544 already owns the fix path for maintainer review.

## What This Changes

The issue requests that the Control UI Channels settings page show built-in channel cards alongside custom channel plugin cards instead of replacing the built-in list with the loaded-plugin snapshot.

## Best Possible Solution

Land or replace the linked UI-only resolver fix so snapshot-provided channel ids are merged with the built-in channel order, de-duplicated, and backend `channels.status` loaded-plugin semantics stay unchanged.
