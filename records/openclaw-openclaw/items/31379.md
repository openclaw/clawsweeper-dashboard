- `impact:ux-friction`: Users can lose visible setup/discovery cards for built-in channels after enabling only a custom channel plugin, creating avoidable setup confusion without fully blocking progress.

## Summary

Keep open: current main and the latest release still render the Channels card grid from the snapshot-provided IDs only, so a custom-only channel snapshot can hide built-in discovery cards; the linked fork PR is the active implementation candidate and needs maintainer review/adoption or replacement.

## What This Changes

The issue requests that the Control UI Channels settings page render built-in channel cards even when `channels.status` reports only custom channel plugins.

## Best Possible Solution

Land or replace a UI-only resolver fix that appends missing built-in channel IDs after snapshot IDs, preserves custom-first order and backend status semantics, and adds regression coverage for custom-only and mixed snapshots.
