## Summary

Keep open: current main still lets a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can disappear. The issue should stay open while the linked fork PR is reviewed, adopted, or replaced.

## What This Changes

The request is to keep built-in Channels settings cards visible in the Control UI when custom channel plugins are the only loaded channels in the backend snapshot.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
