## Summary

Keep open: current main and the latest release still let a custom-only channel snapshot become the entire Channels settings card list, and an open linked fork PR already carries the focused resolver/test candidate fix.

## What This Changes

Request to keep built-in channel discovery cards visible on the Control UI Channels page when custom channel plugins are present.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
