## Summary

Keep open: current main still treats a custom-only Channels status snapshot as the complete card list, so built-in discovery cards can disappear. The issue should stay open because an open linked PR already uses closing syntax for the same fix path, so maintainers should review, adopt, or replace that PR rather than start duplicate work.

## What This Changes

Request that the Control UI Channels settings page render built-in channel discovery cards alongside loaded custom channel cards instead of treating the gateway snapshot order as complete.

## Best Possible Solution

Land or replace the linked UI-only resolver fix so snapshot-provided channel ids are merged with the built-in channel order, de-duplicated, and still leave backend channels.status/plugin-loading semantics unchanged.
