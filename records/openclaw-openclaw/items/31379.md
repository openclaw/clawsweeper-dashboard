The issue requests that the Control UI Channels settings page keep built-in channel cards visible when a custom channel plugin is present.

## Best Possible Solution

Land or replace a current-main UI-only resolver fix that appends missing built-in discovery cards after snapshot-provided custom channels, de-duplicates the list, and adds regression coverage without changing backend status semantics.
