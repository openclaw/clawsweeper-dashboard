## Label Justifications

- `P2`: This is a normal-priority Control UI discovery bug with limited blast radius and no evidence of broken runtime or message delivery.
- `impact:ux-friction`: Users can lose visible setup and discovery cards for built-in channels after enabling only a custom channel plugin, creating avoidable setup confusion without fully blocking progress.

## Summary

Keep open: current main and v2026.6.11 still allow a custom-only channelMeta/channelOrder snapshot to become the entire Channels card list, so built-in discovery cards can disappear.

## What This Changes

The issue requests that the Control UI Channels settings page render built-in channel cards alongside custom channel plugin cards even when the gateway snapshot lists only custom channels.

## Best Possible Solution

Land or replace the linked UI-only resolver fix so snapshot-provided channel IDs are merged with the built-in channel order, de-duplicated, and backend channels.status semantics stay unchanged.
