## Summary

Keep open: current main and the latest release still treat snapshot-provided channel metadata/order as the complete Channels card list, so built-in discovery cards can disappear when the snapshot only includes a custom channel. The open linked fork PR at https://github.com/BingqingLyu/openclaw/pull/544 remains the active implementation candidate, so this issue should wait for maintainer review, adoption, or replacement of that PR rather than closing now.

## What This Changes

Request that the Channels settings page merge snapshot-provided custom channels with the built-in channel list so built-in discovery cards remain visible.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
