## Summary

Keep open: current main and the latest release still treat a custom-only `channelMeta` or `channelOrder` as the complete Channels card list, so built-in discovery cards can disappear. An open cross-repository PR with closing syntax already proposes the focused fix, so maintainers should adopt, port, or replace that path rather than start duplicate repair work.

## What This Changes

The issue asks the Control UI Channels page to keep built-in channel cards visible alongside custom channel plugins.

## Best Possible Solution

Land or replace a UI-only resolver fix in the current Channels page path that appends missing built-in IDs after snapshot-provided channels, de-duplicates them, and adds focused regression coverage without changing backend `channels.status` semantics.
