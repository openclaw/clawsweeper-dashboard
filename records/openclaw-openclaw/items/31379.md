## Summary

Keep open: current main and the latest release still allow a custom-only `channelMeta` or `channelOrder` snapshot to become the entire Channels card list, so built-in discovery cards can still disappear. The issue is already paired with an open fork PR carrying the focused candidate fix, so maintainers should review, adopt, or replace that path rather than start another repair job.

## What This Changes

The issue requests that the Control UI Channels settings page merge built-in channel cards with custom channel plugins instead of rendering only backend-provided loaded channels.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
