## Summary

Keep open: current main and the latest release still treat snapshot-provided channel metadata/order as the complete Channels card list, so built-in discovery cards can disappear when the snapshot only includes a custom channel. The open linked fork PR at https://github.com/BingqingLyu/openclaw/pull/544 remains the active implementation candidate, so maintainers should adopt, refresh, or replace that path rather than close this issue now.

## What This Changes

Show built-in Channels settings cards alongside custom channel plugins even when the backend status snapshot only reports loaded custom channels.

## Best Possible Solution

Land or replace the focused UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
