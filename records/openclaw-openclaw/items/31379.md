- `impact:ux-friction`: Users can lose visible setup and discovery cards for built-in channels after enabling only a custom channel plugin, creating avoidable setup confusion.

## Summary

Keep open: current main and the latest release still render only the IDs returned by a custom-only `channelMeta` or `channelOrder`, so built-in channel discovery cards can disappear. An open cross-repository PR with closing syntax already proposes the focused fix, so maintainer review should adopt, port, or replace that path before starting duplicate repair work.

## What This Changes

The issue requests that the Control UI Channels settings page merge built-in channel cards with custom channel plugins instead of treating backend snapshot order as the complete card list.

## Best Possible Solution

Land or replace a UI-only resolver fix in the current Channels page path that appends missing built-in IDs after snapshot-provided channels, de-duplicates, and adds focused regression coverage without changing backend `channels.status` semantics.
