## What This Changes

The issue requests that the Control UI Channels settings page keep bundled channel cards visible when the backend snapshot only lists custom channel plugins.

## Best Possible Solution

Land the linked UI-only resolver fix, or an equivalent target-repo replacement, with focused Control UI proof that custom-only channel metadata still renders the bundled channel cards.

Yes from source inspection: a custom-only `channelMeta` snapshot makes `resolveChannelOrder()` return only that custom id, and `renderChannels()` renders only that resulting list. I did not run the browser UI in this read-only review.

Yes, the best fix shape is the narrow frontend resolver merge: preserve backend `channels.status` semantics, dedupe snapshot ids with bundled channel ids, and cover custom-only and mixed snapshots in the Channels view tests.
