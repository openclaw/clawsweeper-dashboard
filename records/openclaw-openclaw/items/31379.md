## Summary

Keep open: current main and the latest release still let a custom-only Channels snapshot become the complete card list, so built-in discovery cards can disappear. The open cross-repository fix PR already has closing syntax for this issue, so maintainers should review, adopt, or replace that path instead of starting duplicate work.

## What This Changes

The issue requests that the Control UI Channels page merge custom snapshot-provided channels with built-in channel discovery cards instead of rendering only the loaded custom channels.

## Best Possible Solution

Land or replace the linked UI-only resolver fix so snapshot-provided channel ids are merged with the built-in channel order, de-duplicated, and still leave backend channels.status semantics unchanged.
