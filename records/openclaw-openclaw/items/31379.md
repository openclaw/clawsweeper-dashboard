## Label Justifications

- `P2`: This is a normal-priority Control UI channel-discovery issue with limited blast radius and no evidence of broken message delivery.
- `impact:ux-friction`: Users who enable only a custom channel plugin can lose visible setup/discovery cards for built-in channels and need workaround knowledge to find them again.

## Summary

Keep open: current main and the latest release still allow a custom-only `channelMeta` or `channelOrder` snapshot to become the full Channels settings card list, so built-in discovery cards can still disappear. An open fork PR already carries the focused candidate fix with closing syntax, so maintainers should review, adopt, or replace that path rather than start another repair lane.

## What This Changes

The issue requests that the Control UI Channels settings page show built-in channel cards alongside custom channel entries instead of treating backend `channelMeta` or `channelOrder` as the complete render list.

## Best Possible Solution

Land, adopt, or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend `channels.status` semantics.
