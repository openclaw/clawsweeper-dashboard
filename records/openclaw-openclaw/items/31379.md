## Summary

Keep open: current main and the latest release still let a custom-only Channels snapshot become the complete card list, so built-in discovery cards can disappear. The remaining work is still valid, but an open fork PR already carries the focused candidate fix and should be reviewed, adopted, or replaced before starting a new repair lane.

## What This Changes

The issue requests that the Control UI Channels settings page always include built-in channel cards alongside custom channel plugins.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
