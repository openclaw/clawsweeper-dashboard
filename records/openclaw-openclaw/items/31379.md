## Summary

Keep open: current main and the latest release still treat snapshot-provided `channelMeta` or `channelOrder` as the complete Channels card list, so built-in discovery cards can disappear when only a custom channel plugin is loaded. The open fork PR at https://github.com/BingqingLyu/openclaw/pull/544 remains the active implementation candidate, so this issue should stay open for maintainer adoption, refresh, or replacement of that path.

## What This Changes

The issue requests that the Control UI Channels settings page render built-in channel cards alongside custom channel plugin cards even when the gateway snapshot only lists the custom plugin.

## Best Possible Solution

Land or replace the focused UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.

Yes, source-level. A snapshot whose `channelMeta` or `channelOrder` contains only a custom channel becomes the complete render list because `renderChannels()` maps only the IDs returned by `resolveChannelOrder()`.
