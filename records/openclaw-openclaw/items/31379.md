## Summary

Keep open: current main and the latest release still let a custom-only Channels snapshot become the complete card list, so built-in discovery cards can disappear. An open cross-repository PR already uses closing syntax for this issue, so maintainers should review, adopt, or replace that path instead of starting duplicate work.

## What This Changes

Requests that the Control UI Channels settings page merge snapshot-provided custom channel IDs with the built-in channel card order so built-ins remain discoverable.

## Best Possible Solution

Land or replace the linked UI-only resolver fix so snapshot-provided channel ids are de-duplicated with the built-in channel order while backend channels.status remains loaded-plugin-only.
