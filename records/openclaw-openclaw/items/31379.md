- `impact:ux-friction`: Users can lose visible setup/discovery cards for built-in channels after enabling only a custom channel plugin, forcing workaround knowledge without fully blocking progress.

## Summary

Keep open: current main and the latest release still treat a snapshot-provided `channelMeta` or `channelOrder` as the complete Channels card list, so built-in discovery cards can disappear after a custom-only channel snapshot. The open cross-repository PR at https://github.com/BingqingLyu/openclaw/pull/544 already carries the focused candidate fix, so maintainers should review, adopt, or replace that path rather than start a second repair job.

## What This Changes

The issue asks the Channels settings page to render built-in channel cards alongside custom channel plugins even when the backend snapshot only lists custom channels.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
