## Summary

Keep open: current main and the latest release still treat `channelMeta` or `channelOrder` as the complete Channels settings render list, so a custom-only channel snapshot can hide built-in channel cards. The linked fork PR at https://github.com/BingqingLyu/openclaw/pull/544 is the current candidate fix path, so this should stay open for maintainer review rather than starting a duplicate repair.

## What This Changes

The issue asks the Channels settings page to show built-in channel cards alongside custom channel plugins instead of rendering only the backend-loaded custom channels.

## Best Possible Solution

Land or replace the linked UI resolver fix so custom channels remain first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed snapshots without changing backend status semantics.

Yes, source-level. Current main maps only `resolveChannelOrder()` IDs into cards, and a custom-only `channelMeta` or `channelOrder` snapshot returns only that custom channel while backend status builds those arrays from loaded plugins.
