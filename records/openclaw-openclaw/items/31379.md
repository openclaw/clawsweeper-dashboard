## Summary

Keep open: current main and the latest release still render only the IDs returned by `channelMeta` or `channelOrder`, so a custom-only channel snapshot can hide built-in channel cards. The open fork PR already carries the focused UI resolver/test candidate, so this issue should stay open until maintainers land, adopt, or replace that fix.

## What This Changes

The issue asks the Channels settings page to show built-in channel cards alongside custom channel plugins even when the backend snapshot only lists loaded custom channels.

## Best Possible Solution

End with the UI resolver merging snapshot-provided custom IDs with the built-in channel order, preserving custom-first ordering and backend loaded-plugin semantics, with regression coverage for custom-only and mixed snapshots.
