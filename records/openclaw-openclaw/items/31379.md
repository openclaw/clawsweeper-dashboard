## Summary

Keep open: current main and the latest release still treat a custom-only `channelMeta` or `channelOrder` as the complete Channels card list, so built-in discovery cards can still disappear. The issue already has an open fork PR with closing syntax and a focused resolver/test patch, so maintainers should review, adopt, or replace that path rather than close the issue now.

## What This Changes

The issue requests that the Control UI Channels settings page keep built-in channel cards visible when a custom channel plugin is the only loaded channel.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
