## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can still disappear. An open fork PR already carries the focused candidate fix, so maintainers should review, adopt, or replace that path rather than start a new repair job.

## What This Changes

Show built-in channel cards on the Channels settings page even when the gateway snapshot only contains custom channel plugins.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
