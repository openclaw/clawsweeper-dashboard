## Summary

Keep open: current main still lets a custom-only `channelMeta` or `channelOrder` become the complete Channels settings card list, so built-in discovery cards can disappear. The remaining work is already paired with an open fork PR that uses closing syntax, so maintainers should review, adopt, or replace that implementation path instead of starting a new repair PR.

## What This Changes

The issue asks for the Channels settings page to render built-in channel cards alongside enabled custom channel plugins, preserving custom channels first.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
