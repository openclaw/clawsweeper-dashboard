## Summary

Keep open: current main and the latest release still treat a non-empty `channelMeta` or `channelOrder` snapshot as the complete Channels page render list, so a custom-only snapshot still hides the built-in channel cards. An open linked fork PR references this issue as its fix candidate, so this issue should remain the canonical tracker until that candidate is reviewed, adopted, merged, or replaced.

## What This Changes

The issue asks for the Control UI Channels settings page to show built-in channel cards even when a custom channel plugin is the only loaded channel in the gateway snapshot.

## Best Possible Solution

Land or adopt a narrow UI resolver fix that appends missing built-in channel IDs after snapshot-provided IDs, with focused unit coverage and real Control UI proof.

## Maintainer Decision

Required: false

## Reproduction Assessment

Yes, source-level: a non-empty custom-only `channelMeta` snapshot makes `resolveChannelOrder()` return only that custom ID, and `renderChannels()` renders exactly that list. I did not run a live Control UI scenario in this read-only review.

## Solution Assessment

Yes, a frontend-only deduped merge of snapshot channel IDs with the built-in channel list is the narrow maintainable fix; backend plugin loading can remain unchanged.
