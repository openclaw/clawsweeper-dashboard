## Summary

Keep open: current main and v2026.6.11 still treat a custom-only Channels snapshot as the complete card list, so built-in discovery cards can disappear. The open cross-repository candidate at https://github.com/BingqingLyu/openclaw/pull/544 uses closing syntax for this issue, so maintainers should review, adopt, or replace that path before queueing duplicate repair work.

## What This Changes

The issue asks for the Control UI Channels settings page to keep built-in channel cards visible when a custom channel plugin is the only loaded channel in the backend snapshot.

## Best Possible Solution

Land or replace a narrow UI resolver change that appends missing built-in discovery cards after snapshot-provided custom channels, de-duplicates the order, and adds regression coverage without changing backend status semantics.
