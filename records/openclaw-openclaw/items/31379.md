- `impact:ux-friction`: Users can lose visible setup/discovery cards for built-in channels after enabling only a custom channel plugin, forcing workaround knowledge without fully blocking progress.

## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can disappear. The open linked fix candidate at https://github.com/BingqingLyu/openclaw/pull/544 uses closing syntax for this issue, so maintainers should review, adopt, or replace that PR rather than close this issue or start a second repair lane.

## What This Changes

The issue asks the Control UI Channels page to merge snapshot custom channel IDs with the built-in channel list so built-in discovery cards remain visible.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
