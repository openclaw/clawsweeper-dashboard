## Summary

Keep open: current main and v2026.6.11 still let a custom-only `channelMeta` or `channelOrder` snapshot define the complete Channels card list, so built-in cards can disappear. The linked open cross-repo PR with closing syntax is the live fix path.

## What This Changes

The issue asks the Control UI Channels page to keep built-in channel cards visible when the backend status snapshot only lists custom or currently loaded channel plugins.

## Best Possible Solution

Review and land the linked candidate or an equivalent narrow Control UI change that preserves custom snapshot order, appends missing built-in channel cards, and leaves backend plugin loading unchanged.

## Reproduction Assessment

Yes. A `ChannelsStatusSnapshot` with only `channelMeta: [{ id: "icenter" }]` or `channelOrder: ["icenter"]` follows the current source path that returns only that custom id, so built-in cards are not rendered.

## Solution Assessment

Yes, the proposed frontend-only direction is the narrowest fix: backend `channels.status` can continue reporting loaded plugins while the Control UI appends built-in discovery cards for display.
