## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can disappear. An open fork PR at https://github.com/BingqingLyu/openclaw/pull/544 already carries the focused resolver/test candidate and should be reviewed, adopted, or replaced before starting new repair work.

## What This Changes

Request that the Control UI Channels settings page merge snapshot-provided custom channels with built-in channel cards so built-ins remain visible when only a custom channel plugin is loaded.

## Best Possible Solution

Land or replace the linked UI-only resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage plus real Control UI proof confirms the mixed list.
