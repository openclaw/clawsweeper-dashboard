- `impact:ux-friction`: Users can lose visible setup and discovery cards for built-in channels after enabling only a custom channel plugin, creating avoidable confusion and workaround pressure.

## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can disappear. An open cross-repository PR with closing syntax already exists, so maintainers should review, adopt, or replace that path instead of starting a duplicate fix.

## What This Changes

The issue requests that the Control UI Channels settings page show built-in channel cards even when the gateway snapshot only contains custom channel plugins.

## Best Possible Solution

Land or replace a UI-only resolver fix that appends missing built-in discovery cards after snapshot-provided custom channels, de-duplicates IDs, preserves backend loaded-plugin semantics, and adds focused coverage for custom-only and mixed-order snapshots.
