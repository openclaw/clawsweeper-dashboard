- `impact:ux-friction`: A user who enables a custom channel can lose visible discovery and configuration cards for built-in channels in the Channels settings page.

## Summary

Keep open: current main and the latest release still treat `channelMeta` or `channelOrder` as the complete Channels settings render list, so a custom-only channel snapshot can still hide built-in cards. There is an open fork PR with closing syntax, but no live upstream OpenClaw PR to land yet.

## What This Changes

The issue requests that the Control UI Channels settings page keep built-in channel cards visible when a custom channel plugin is the only loaded channel.

## Best Possible Solution

Land an upstream UI-only resolver fix that de-duplicates snapshot-provided custom channel IDs with the built-in channel list, preserving custom-first order and adding focused Control UI proof.
