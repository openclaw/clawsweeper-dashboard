## Label Justifications

- `P2`: This is a normal-priority Control UI discovery bug with limited blast radius and no evidence of broken runtime or message delivery.
- `impact:ux-friction`: Users can lose visible setup and discovery cards for built-in channels after enabling only a custom channel plugin, creating avoidable setup confusion without fully blocking progress.

## Summary

Keep open: current main and the latest release still treat a custom-only Channels snapshot as the complete card list, so built-in discovery cards can disappear. An open linked fork PR already uses closing syntax for this issue, so maintainers should adopt, refresh, or replace that path instead of starting duplicate work.

## What This Changes

The issue asks the Control UI Channels page to show built-in channel cards alongside custom channel plugins instead of rendering only the loaded plugin list.

## Best Possible Solution

Land an adopted or replacement UI-only resolver fix in the current Channels page that de-duplicates snapshot-provided channels with the built-in channel order, with focused regression coverage and real Control UI proof.
