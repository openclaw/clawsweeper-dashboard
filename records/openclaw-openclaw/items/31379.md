## Summary

Keep open: current main and the latest release still let a custom-only Channels status snapshot become the complete rendered card list, so built-in discovery cards can disappear. An open cross-repository PR already has closing syntax for this issue, so the next step is maintainer adoption, review, or replacement of that implementation path.

## What This Changes

The issue requests that the Control UI Channels settings page merge built-in channel cards with custom channel cards instead of rendering only the channels returned by the gateway snapshot.

## Best Possible Solution

Land or replace a UI-only resolver fix that appends missing built-in discovery cards after snapshot-provided custom channels, de-duplicates IDs, and adds regression coverage for custom-only and mixed-order snapshots without changing backend status semantics.
