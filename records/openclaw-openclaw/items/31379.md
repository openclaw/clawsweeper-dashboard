## Summary

Keep open: current main and the latest release still treat snapshot-provided `channelMeta` or `channelOrder` as the complete Channels page card list, so built-in discovery cards can disappear. An open fork PR already carries a focused candidate fix, so this issue should track maintainer review, adoption, or replacement of that path rather than be auto-closed.

## What This Changes

The issue requests that the Control UI Channels settings page show built-in channel cards alongside custom channel-plugin entries.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
