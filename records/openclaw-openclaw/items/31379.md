## Summary

Keep open: current main and the latest release still treat a custom-only `channelMeta` or `channelOrder` snapshot as the complete Channels card list, so built-in discovery cards can disappear. The open cross-repository PR at https://github.com/BingqingLyu/openclaw/pull/544 has closing syntax and a focused candidate patch, so maintainers should review, adopt, or replace that path rather than closing this issue or queueing a duplicate fix.

## What This Changes

The issue requests that the Control UI Channels settings page always show built-in channel cards alongside custom channel plugins.

## Best Possible Solution

Land or replace a narrow UI resolver change that appends missing built-in discovery cards after snapshot-provided custom channels, de-duplicates the order, and adds regression coverage for custom-only and mixed snapshots without changing backend status semantics.
