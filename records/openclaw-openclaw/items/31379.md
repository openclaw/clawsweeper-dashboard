- `impact:ux-friction`: Users can lose visible setup and discovery cards for built-in channels after enabling only a custom channel plugin, forcing workaround knowledge without fully blocking progress.

## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can disappear. The open cross-repository PR at https://github.com/BingqingLyu/openclaw/pull/544 has closing syntax for this issue, so maintainers should review, adopt, or replace that path instead of starting a duplicate fix.

## What This Changes

The issue requests that the Control UI Channels settings page render built-in channel cards alongside custom channel plugins, preserving custom-first ordering.

## Best Possible Solution

Land or replace a UI-only resolver fix that appends missing built-in discovery cards once after snapshot-provided custom channels, with regression coverage for custom-only and mixed-order snapshots and no backend status semantics change.
