- `impact:ux-friction`: Users can lose visible setup/discovery cards for built-in channels after enabling only a custom channel plugin, forcing workaround knowledge without fully blocking progress.

## Summary

Keep open: current main and the latest release still treat a custom-only `channelMeta` or `channelOrder` snapshot as the complete Channels card list, so built-in discovery cards can still disappear. The issue already has an open fork PR with closing syntax carrying the focused resolver/test patch, so maintainers should review, adopt, or replace that path instead of starting a duplicate repair job.

## What This Changes

Requests that the Control UI Channels page merge snapshot-provided custom channel IDs with the built-in channel list so built-in discovery cards stay visible.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
