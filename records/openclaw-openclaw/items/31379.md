## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` become the complete Channels card list, so built-in discovery cards can disappear. An open fork PR already carries the focused candidate fix, so maintainers should review, adopt, or replace that path rather than start another repair lane.

## What This Changes

The issue asks the Channels settings page to show built-in channel cards alongside custom channel plugins even when the custom plugin is the only loaded channel.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
