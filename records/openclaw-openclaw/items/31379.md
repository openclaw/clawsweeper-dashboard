## Summary

Keep open: current main and the latest release still treat a custom-only `channelMeta` or `channelOrder` snapshot as the complete Channels card list, so built-in discovery cards can still disappear. The issue already has an open fork PR carrying the focused resolver/test candidate, so maintainers should review, adopt, or replace that path rather than start a new repair lane.

## What This Changes

The issue asks for the Control UI Channels settings page to render built-in channel cards alongside custom channel plugins when the backend snapshot only lists loaded custom channels.

## Best Possible Solution

Land or replace the linked UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend status semantics.
