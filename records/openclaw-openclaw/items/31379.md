## Summary

Keep open: current main and the latest release still treat a custom-only `channelMeta` or `channelOrder` snapshot as the complete Channels card list, so built-in discovery cards can disappear. An open linked implementation candidate at https://github.com/BingqingLyu/openclaw/pull/544 has closing syntax for this issue, so maintainers should review, adopt, or replace that path before starting duplicate repair work.

## What This Changes

The issue requests that the Control UI Channels settings page render built-in channel cards alongside custom channel cards when the backend snapshot only lists loaded custom channel plugins.

## Best Possible Solution

Land or replace a UI-only resolver fix that appends missing built-in discovery cards after snapshot-provided custom channels, de-duplicates IDs, adds focused regression coverage, and leaves backend loaded-plugin status semantics unchanged.
