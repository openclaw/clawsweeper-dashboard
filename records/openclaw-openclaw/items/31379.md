## Summary

Keep open: current main and the latest release still let a custom-only `channelMeta` or `channelOrder` snapshot become the complete Channels card list, so built-in channel discovery cards can disappear. The open linked cross-repository PR at https://github.com/BingqingLyu/openclaw/pull/544 remains the active implementation candidate, so this issue should wait for maintainer adoption, review, or replacement rather than being closed or duplicated.

## What This Changes

The issue asks for the Control UI Channels settings page to show built-in channel cards alongside custom plugin channel cards when the backend snapshot only lists loaded custom channels.

## Best Possible Solution

Merge or replace the UI resolver fix so snapshot-provided custom channels stay first, missing built-in discovery cards are appended once, and regression coverage proves custom-only and mixed-order snapshots without changing backend loaded-plugin status semantics.
