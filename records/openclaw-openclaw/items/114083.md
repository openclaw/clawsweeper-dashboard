## What This Changes

The PR changes the iOS Forget Gateway confirmation dialog to pass the selected paired-gateway entry into asynchronous cleanup and adds a source-level regression guard for that handoff.

## System Context

The iOS Settings screen presents paired gateways from its local registry and asks for confirmation before a destructive removal. The selected entry must reach the gateway controller’s cleanup path, which removes the registry record and related local credentials, access, trust, and cache state.
