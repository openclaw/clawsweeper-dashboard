## What This Changes

This PR passes the selected paired-gateway entry through the iOS Forget Gateway confirmation dialog into the existing asynchronous cleanup path, preventing dialog dismissal from clearing the entry before removal starts.

## System Context

The iOS Settings screen presents paired gateways from local registry state and lets users remove one through a destructive confirmation dialog. The selected entry is passed to the gateway controller, which owns removal of the registry entry and associated device-local credentials, authorization, TLS trust, and chat-cache state.
