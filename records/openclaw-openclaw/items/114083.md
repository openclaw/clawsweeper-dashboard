## What This Changes

The PR passes the selected paired gateway from the iOS Forget Gateway confirmation dialog into the asynchronous cleanup action, so confirming the dialog invokes the existing gateway cleanup path.

## System Context

The iOS Settings screen lists paired Gateways and asks for confirmation before removing one. The dialog hands a selected registry entry to the gateway controller, which removes the registry record and associated local credentials, device access, TLS trust, and chat cache.
