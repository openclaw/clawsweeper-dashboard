## Summary

The patch has a sound, narrowly scoped handoff: the confirmation dialog supplies the selected gateway entry directly to the existing asynchronous cleanup path. It remains necessary because the linked bug is still open and current main does not contain this branch’s fix; however, the contributor has explicitly not captured after-fix OpenClaw behavior on a physical device or equivalent live runtime, so it needs real behavior proof before merge.

## What This Changes

This PR changes the iOS Forget Gateway confirmation so the selected paired gateway is passed into the asynchronous cleanup action, preventing dialog dismissal from clearing the entry before removal starts.

## System Context

The iOS Settings connection screen lets users remove a paired gateway. The confirmation dialog must retain the chosen registry entry long enough to invoke the gateway controller, which then removes credentials, device authorization, TLS trust, and cached chat state.
