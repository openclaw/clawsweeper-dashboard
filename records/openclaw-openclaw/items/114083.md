## What This Changes

The PR changes the iOS Forget Gateway confirmation dialog to pass the selected paired-gateway entry directly to the destructive action instead of retrieving it from state after dismissal.

## System Context

The iOS Settings screen shows paired gateways whose registry, credentials, trust, and offline data are owned by the gateway connection layer. Confirming Forget Gateway must carry the selected entry through the dialog into that removal layer so the list and associated local state can be updated.
