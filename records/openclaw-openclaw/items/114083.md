## Summary

Keep this PR open. The SwiftUI payload handoff is a focused, contract-aligned fix for the reported iOS cleanup race, but the linked evidence still does not inspectably demonstrate OpenClaw removing a paired gateway after confirmation on the reviewed head.

## What This Changes

Updates the iOS Forget Gateway confirmation dialog to pass the selected gateway entry into asynchronous cleanup, with a source guard and refreshed native localization inventory.

## System Context

The iOS Settings screen stores the gateway selected for removal, presents a destructive confirmation dialog, and then calls the gateway controller to remove that gateway's registry entry and local credentials. This change sits between dialog dismissal and controller cleanup, where the selected entry must survive long enough to identify the intended gateway.
