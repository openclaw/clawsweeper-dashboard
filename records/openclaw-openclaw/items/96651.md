## Summary

Keep open: the previous P1 blocker is still present because the recovery guard requires a timestamp that is only set for later fallback activation, while initial provider resolution can also create fallback-active state. ## What This Changes

The branch adds a 60-second memory-core search-time probe that tries to restore the configured primary embedding provider after fallback activation, plus focused recovery tests.

## Best Possible Solution

Land one maintainer-chosen recovery implementation only after every fallback-active entry path is recoverable, index-identity safety is preserved, and redacted real Gateway outage/recovery proof is supplied.

## Solution Assessment
