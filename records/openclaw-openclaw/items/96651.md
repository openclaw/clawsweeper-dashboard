- **[P1] Timestamp every fallback-active entry path:** `extensions/memory-core/src/memory/manager-sync-ops.ts:2676-2677`
  - body: The recovery probe exits whenever `fallbackActivatedAtMs` is unset, but `applyProviderResult()` can put the manager into `fallback-active` when initial provider resolution falls back. A manager created while the primary is down will therefore never probe the recovered primary; record recoverable timing/state on that path or make the probe eligible from the lifecycle state, and add a regression test.
  - confidence: 0.91
- **[P1] Gate recovery on the index identity state:** `extensions/memory-core/src/memory/manager.ts:670-672`
  - body: This runs primary-provider recovery for every `fallback-active` search before checking whether the current index is already valid for the fallback provider. If an operator explicitly repaired or rebuilt the index for the fallback provider, switching back to the primary makes the identity mismatched and search returns empty until another repair path runs; only recover when the identity is mismatched for the active fallback, or force the matching reindex/repair as part of recovery.
  - confidence: 0.84
