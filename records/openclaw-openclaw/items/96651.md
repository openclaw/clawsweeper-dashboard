- **[P1] Timestamp fallback states from provider initialization:** `extensions/memory-core/src/memory/manager-sync-ops.ts:2676-2677`
  - body: The recovery probe returns immediately when `fallbackActivatedAtMs` is unset, but `ensureProviderInitialized()` can still call `applyProviderResult()` with a `fallbackFrom` result and put the manager into fallback-active without setting that timestamp.   - confidence: 0.91
- **[P1] Gate recovery on the current index identity:** `extensions/memory-core/src/memory/manager.ts:669-672`
  - body: This runs recovery for every fallback-active search before checking whether the on-disk index is already valid for the fallback provider. If an explicit identity repair rebuilt the index under the fallback, the 60s probe can switch back to the primary and then the refreshed identity becomes mismatched, turning a working fallback index into empty search results.
  - confidence: 0.86
