## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Validate xcode_path before selecting Xcode:** `.github/workflows/build-ios-unsigned.yml:50`
  - body: `xcode_path` is expanded into the generated shell script before bash runs it, so a crafted manual-dispatch value can break out of the quoted argument and execute commands on the macOS runner. Pass it through `env`, validate an allowlisted Xcode path in bash, then quote the variable.
  - confidence: 0.9
- **[P1] Build build_number arguments after validation:** `.github/workflows/build-ios-unsigned.yml:68`
  - body: The digits-only check in `scripts/ios-write-version-xcconfig.sh` happens too late because the workflow interpolates `build_number` into the shell command first. Pass the raw input through an environment variable and construct `--build-number` only after validation.
  - confidence: 0.91
- **[P2] Limit the workflow token before running build scripts:** `.github/workflows/build-ios-unsigned.yml:36`
  - body: This job runs dependency install and build scripts after checkout, but it has no explicit read-only `permissions` block and `actions/checkout@v4` persists credentials by default. Add `permissions: contents: read` and `persist-credentials: false` before merge.
  - confidence: 0.84
