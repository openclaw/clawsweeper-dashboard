## Summary

This PR addresses a valid source-level failure mode, but it is not merge-ready: the static formatter import breaks the repository’s cycle boundary, the new fallback exposes raw exception text, the supplied screenshot does not exercise any changed failure path, and the repository-wide timeout needs maintainer approval.

The PR makes status lazy loaders retry after rejection, adds a 10-second status-render fallback, replaces two lazy runtime wrappers with direct imports, updates focused tests, and removes the obsolete built-runtime smoke script.

## Best Possible Solution

Keep a cycle-breaking lazy status-message seam, make rejected loader caches retryable, return generic user-safe failure text while logging details internally, and apply a deadline only at the narrowest maintainer-approved boundary.
