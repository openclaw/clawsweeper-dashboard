## Summary

Close: current main already addresses the observable problem by separating exec failure labels from literal shell commands and preferring the raw command when available. The fix is on main but not proven in the latest release tag.

## What This Changes

The issue asks OpenClaw to prevent display-style natural language exec summaries from being mistaken for or used as shell commands.

## Best Possible Solution

Keep the current-main exec failure rendering; if actual natural-language `cmd` values still happen on current main, handle that only from a fresh raw tool-call repro rather than adding heuristic command translation.
