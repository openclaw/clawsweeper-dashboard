## Summary

Keep this PR open for maintainer review. It addresses a concrete regression from the SQLite transcript refactor: a headerless but otherwise canonical persisted transcript is currently classified as legacy and prevents the agent from replying; the proposed shared codec predicate avoids both the hard failure and repeated ID remapping while preserving the doctor path for genuinely legacy shapes.

## What This Changes

The PR classifies headerless SQLite transcripts containing only current canonical session entries as current, restores their session header in memory, and adds regression coverage that entry IDs and parent links remain stable across reopen and append.

## System Context

Before an embedded agent answers a channel message, OpenClaw loads that agent's persisted SQLite transcript through the session manager. The codec decides whether the stored rows are current or need doctor/import migration, then the loaded transcript supplies stable state to agent execution and subsequent message persistence.
