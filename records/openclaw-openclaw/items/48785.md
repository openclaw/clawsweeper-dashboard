## Summary

Keep open. Current main and v2026.6.11 still use one string-valued `tools.sessions.visibility` scope for list, history, send, and status, and the open related PRs cover adjacent per-agent/allowlist/A2A axes rather than the requested per-capability object model.

## What This Changes

Request adds a structured per-capability session visibility model so cross-agent sends can be allowed without also granting transcript read/list/status access.

## Best Possible Solution

Define one maintainer-approved, backward-compatible session-tool authorization model that preserves string shorthands, adds only approved capability controls, keeps sandbox and A2A gates intact, and updates schema, docs, and tests together.
