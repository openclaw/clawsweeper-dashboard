## Summary

The PR remains useful: current main still streams the pinned OpenShell installer into the shell, while this bounded download-before-execution change cleanly prevents partial-script execution and limits a stalled fetch. No actionable correctness or security defect was found.

## What This Changes

The PR downloads the pinned OpenShell installer into a temporary runner file with connection and total-transfer timeouts, executes it only after a successful fetch, removes it on exit, and adds a workflow-shape regression test.

## Best Possible Solution

Keep the existing commit and version pin while landing the bounded temporary-file fetch so the E2E lane executes only a completely downloaded installer and fails promptly on network stalls.

## Solution Assessment

Yes. A unique runner-temporary file, bounded curl operation, success-gated shell invocation, and EXIT cleanup are a narrow and maintainable fix that preserves the existing pinned upstream installer contract.
