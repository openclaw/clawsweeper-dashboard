## Summary

Keep open: current main fixes important pieces of active steering, but ordinary same-session visible messages can still be admitted only after the active reply operation clears, so the documented steer-mode behavior is not fully implemented. Open PR #89238 is the candidate path for the remaining admission-layer fix, but its latest ClawSweeper review still requires a semantic refresh before merge.

## What This Changes

The issue asks for steer-mode messages sent mid-turn to inject into the active main/Codex session instead of silently degrading to a later follow-up turn.

## Best Possible Solution

Refresh and land a single admission-layer fix that lets same-session visible turns reach queue policy while preserving terminal-session recovery and suppressing empty visible fallbacks for accepted queued or steered turns.
