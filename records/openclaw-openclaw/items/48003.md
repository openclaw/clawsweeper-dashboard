## Summary

Keep open: current main contains important partial fixes for command-lane and active non-streaming steering, but ordinary same-session visible messages can still be admitted too late to reach active-run queue policy before the running turn completes.

## What This Changes

The issue asks for `messages.queue.mode: "steer"` to inject normal mid-turn messages into active main-session runs instead of queuing them until turn completion.

## Best Possible Solution

Land a current-main admission-layer fix that lets ordinary same-session channel messages reach active queue policy while preserving terminal-session recovery, route/thread safety, and no-visible fallback semantics.
