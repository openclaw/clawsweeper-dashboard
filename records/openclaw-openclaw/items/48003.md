## Summary

Keep open: current main has the active-run steering fixes for the explicit steer command paths, but the ordinary same-session message path can still be serialized before active-run queue policy can accept it, and the remaining admission-layer work is already represented by open PR #89238 rather than by a completed fix.

## What This Changes

The issue asks for main-session steer mode to inject user messages into an active agent turn instead of waiting until the current turn finishes.

## Best Possible Solution

Resolve the remaining admission layer through #89238 or a refreshed successor that lets same-session visible turns reach active-run queue policy while preserving channel ordering and no-visible-fallback semantics.
