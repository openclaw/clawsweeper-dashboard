## Summary

Keep open: current main and v2026.6.11 still skip the non-visible retry path when tool metadata makes the attempt replay-unsafe, then log and surface the incomplete-turn error. The new field evidence makes this more actionable, but the remaining fix is a replay/fallback/quarantine policy decision rather than a safe one-shot cleanup close.

## What This Changes

The issue asks OpenClaw to prevent replay-unsafe incomplete assistant/tool turns with zero payloads from poisoning later session state or bypassing recovery.

## Best Possible Solution

Define a maintainer-approved policy for replay-unsafe post-tool empty turns, then add focused runner/fallback/quarantine coverage that retries only provably safe current attempts and records unsafe failures durably.
