## What This Changes

The issue asks OpenClaw to safely handle replay-unsafe incomplete embedded turns with tool metadata but zero payloads so malformed assistant/tool state does not poison later replay or bypass recovery.

## Best Possible Solution

Define a maintainer-approved recovery policy that retries or falls back only for provably current-attempt-safe cases, persists explicit quarantine or repair metadata for unsafe attempts, and adds focused embedded-runner plus cron coverage.
