## Summary

Keep open: current main and v2026.6.11 still skip the empty/non-visible recovery path when replay metadata is unsafe, then surface the reported incomplete-turn error. The new field report strengthens this from a one-off session-poisoning concern into a provider-agnostic recovery-policy gap, while related open PRs only cover adjacent 5xx or cron fallback layers.

## What This Changes

The issue asks OpenClaw to recover or quarantine replay-unsafe incomplete embedded-agent turns where tool activity exists but no payload is produced.

## Best Possible Solution

Define a maintainer-approved recovery policy that retries or falls back only for current-attempt-safe empty tool turns, and records or quarantines unsafe incomplete attempts so malformed state is not replayed silently.
