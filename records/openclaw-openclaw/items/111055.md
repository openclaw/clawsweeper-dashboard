Adds shared runtime validation for explicit gateway approval IDs and maps invalid request IDs to `INVALID_REQUEST`, with focused gateway tests.

## Best Possible Solution

Use one approval-ID contract that rejects `.` and `..` before persistence and make the exported gateway request schema enforce the same character and length bounds as the runtime.
