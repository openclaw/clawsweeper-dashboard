## Summary

## What This Changes

The issue reports that Chrome MCP existing-session promises can remain pending after the target browser crashes during paused-breakpoint handling.

## Best Possible Solution

Centralize Chrome MCP existing-session cancellation in the browser plugin so route-backed actions reject on route abort, timeout, transport close, or simulated target crash, with focused regression coverage.
