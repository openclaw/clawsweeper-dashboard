## Summary

The low-speed timeout primitive is appropriate, but this branch still overrides the current 30-second cURL stall grace with 20 seconds in both installer paths, so it can newly abort slow transfers that current main permits. The proposed 10-second connection deadline also needs explicit maintainer approval because curl applies it to DNS plus TCP/TLS/QUIC connection setup; the supplied evidence does not exercise either changed failure boundary.

## What This Changes

The PR adds a 10-second curl connection timeout plus 20-second low-speed abort settings to both installer download helpers and adds a shell test that asserts those arguments.

## Best Possible Solution

Rebase onto current main, preserve the established 30-second low-speed grace unless maintainers intentionally choose a new policy, and add redacted terminal proof for a rate-limited successful transfer plus a controlled stalled-transfer failure using the exact installer curl flags.
