## What This Changes

This PR adds `--connect-timeout 20` to every curl download path in the two shell installers and updates their command-output tests to require that timeout.

## System Context

The shell installers select curl or wget to fetch release assets during initial installation and upgrades. This change affects curl’s connection-setup phase before the existing low-speed transfer timeout and retry handling determine whether the installer proceeds or fails.
