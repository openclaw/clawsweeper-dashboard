## What This Changes

The branch makes temporary-session restoration delete only legacy `agent:<id>:boot` entries without `lifecycleRevision`, allowing a later boot hook run to recover from stale pre-7.1 session state.

## System Context

BOOT.md startup hooks run through the session lifecycle system, which temporarily maps an agent’s boot session while it starts work. The snapshot-and-restore layer determines whether the old session record is put back or removed after the run, affecting whether subsequent gateway boots can claim the boot session.
