## Summary

Keep this maintainer-labeled PR open. It consolidates the reported cross-agent selection fix and supersedes the detached predecessor, but the optional protocol field is treated as mandatory by updated native clients for canonical global sessions, which can suppress observer status during a client-ahead-of-Gateway upgrade; the submitted evidence is also mock/test-only rather than a real multi-agent run.

## What This Changes

The branch centralizes agent-before-session selection and carries global observer ownership through Gateway fanout, the Control UI, Android, and Apple clients so cross-agent navigation and reconnects keep the selected agent, chat session, and observer status aligned.

## System Context

OpenClaw clients select an agent and chat session while the Gateway broadcasts observer summaries for active sessions. Canonical global sessions share the same key across agents, so the selection and observer paths need an explicit owner before clients render cached or live status.
