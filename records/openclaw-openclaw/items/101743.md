## Summary

Keep open: the mention-cache cap is a plausible bounded hardening, but the 409 conflict path still parses before returning `cancel`, so malformed or oversized conflict bodies can fail open and allow a Slack reply into a thread owned by another agent.

## What This Changes

The branch caps the thread-ownership mention map at 1000 entries, switches the 409 ownership-conflict body to the shared bounded JSON reader, and adds a mention-cache eviction test.

## Best Possible Solution

Land a version that preserves 409 cancellation on bounded-reader failures, keeps an accepted mention-cache threshold, reconciles the overlapping 409 work with https://github.com/openclaw/openclaw/pull/98941, and includes redacted Slack/forwarder runtime proof.
