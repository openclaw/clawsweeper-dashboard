## What This Changes

The PR adds a deterministic hashed Telegram callback for model names that exceed the existing 64-byte callback encodings, then resolves it against the live model catalog when the user selects the button.

## System Context

Telegram’s `/model` picker turns configured provider/model entries into inline-keyboard callbacks and sends the selected callback to the Telegram bot handler. The handler resolves that callback to a current catalog entry, then updates the requesting session’s model selection and edits the picker message.
