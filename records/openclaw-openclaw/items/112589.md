## What This Changes

Adds lease-authorized Gateway RPC methods for external orchestrators to spawn subagents and read lease-bound session metadata through list, status, and history responses.

## System Context

External orchestrators call Gateway RPC methods to acquire a scoped lease, start a child session, and query its result. The proposed implementation validates the lease before delegating to the existing child-session runner, then persists a projection in the shared state database for later reads.
