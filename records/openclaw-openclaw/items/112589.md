## What This Changes

The PR adds lease-authorized Gateway methods that let an external orchestrator spawn child sessions with metadata and read the resulting session identity, status, history, and lease lifecycle.

## System Context

Gateway clients call session and subagent methods that ultimately create and track child-agent runs. This PR adds lease validation and persisted metadata around that existing runner so an external orchestrator can reconcile a spawned child across later read operations.
