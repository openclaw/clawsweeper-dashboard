## What This Changes

This PR adds a lease-bound Gateway API for external orchestrators to authorize, launch, persist, discover, and read back child-session spawns with stable metadata and replay identities.

## System Context

Gateway RPC methods receive authenticated client requests and invoke the child-session runner, which creates agent work and session state. The PR inserts an Agentic OS lease and replay layer before that runner, stores its state in OpenClaw's shared SQLite database, and projects it through session read methods.
