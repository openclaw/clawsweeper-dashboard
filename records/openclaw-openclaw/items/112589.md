## What This Changes

This branch adds lease-bound metadata, replay handling, persistence, discovery, documentation, and Gateway RPCs so external orchestrators can authorize, launch, and read back subagent sessions with stable identities.

## System Context

Gateway clients invoke session and subagent control methods, which pass through authorization and the child-session runner before session state is exposed back through list, status, and history reads. This PR inserts a lease and replay layer ahead of that runner and stores its lifecycle records in the shared state database.
