## Summary

## What This Changes

This PR adds lease-bound metadata and idempotent readback for externally orchestrated child-session spawns through new Gateway RPC methods, persisted state, catalog metadata, and tests.

## System Context

Gateway clients request child-session spawns and then inspect their state through list, status, and history methods. The proposed contract sits between those clients and the existing subagent runner, adding lease authorization, replay identity, and persisted metadata before returning session projections.
