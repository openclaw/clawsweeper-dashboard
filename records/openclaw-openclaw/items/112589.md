## What This Changes

This PR adds lease-authorized Gateway methods and persistent metadata so an external orchestrator can spawn, replay, list, inspect, and release child sessions through a proposed Agentic OS v1 contract.

## System Context

External orchestrators call Gateway session APIs to create child-agent work. This change adds a lease check before the child-session runner, stores contract metadata in OpenClaw state, and exposes the resulting session through list, status, and history reads.
