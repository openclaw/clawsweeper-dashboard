## What This Changes

This PR adds lease-authorized Gateway methods and persisted metadata for externally orchestrated child-session spawns, plus discovery and readback fields for their list, status, and history.

## System Context

Gateway clients invoke authenticated RPC methods that authorize and start child-agent sessions through the shared subagent runner. This PR inserts a lease and metadata layer between the client and runner, then persists and projects the resulting session identity through catalog and read APIs.
