## What This Changes

This branch adds seven lease-aware Gateway RPC methods, persistent session/lease metadata, and catalog discovery so an external orchestrator can authorize, spawn, and read back child sessions through a proposed Agentic OS v1 contract.

## System Context

Gateway clients invoke RPC methods that check operator scope, authorize subagent admission, start child sessions, and read their session state. This PR inserts a lease-and-metadata contract between external orchestrators and the existing child-session runner, then persists and projects the resulting state through list, status, and history reads.
