## What This Changes

This PR adds lease-authorized Gateway methods and durable metadata so an external orchestrator can spawn, replay, list, inspect, and release child sessions through a proposed Agentic OS v1 contract.

## System Context

External clients call Gateway methods to obtain a short-lived authorization lease and request a child session spawn.
