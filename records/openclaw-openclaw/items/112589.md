## What This Changes

This PR adds lease-authorized metadata and readback endpoints for externally orchestrated child-session spawns, including Gateway method discovery, session projections, and persistent replay state.

## System Context

Gateway clients would acquire a scoped lease, use it to launch a child session, then query list, status, and history projections. The new contract forwards accepted launches into the existing subagent runner and records lease/session replay metadata in OpenClaw’s shared SQLite state database.

  Spawn --> State[Shared SQLite replay state]

  Reads --> Client

First decide whether external orchestration belongs behind a generic core lease/session seam plus an owner plugin; if it does, implement only the generic seam, add the required additive SQLite lazy ensure and upgrade coverage, then supply current-head end-to-end proof with redacted runtime output.
