## What This Changes

This branch adds lease-authorized Gateway RPC methods, persisted metadata, and catalog discovery so an external orchestrator can spawn child sessions and read their lease, identity, status, and history.

## System Context

The Gateway accepts authenticated RPC calls and routes permitted session-spawn requests into the child-session runner, which records session state for later status and history reads. This PR adds a lease and metadata layer around that path, plus protocol/catalog discovery for external callers.
