## What This Changes

This branch adds lease-authorized Gateway methods and persisted metadata so external orchestrators can start child sessions and read their identity, status, and history through a new session contract.

## System Context

External orchestrators call Gateway RPC methods to obtain an allow lease and request a child session. The proposed contract authorizes the spawn, persists lease/session metadata in the shared state database, then projects the child’s runtime and transcript status back through Gateway reads.
