## Summary

Keep this PR open, but do not merge it yet. The current branch still embeds an Agentic OS-specific, lease-authorized session API in core Gateway policy rather than a generic core seam owned by the external integration, and it also contains two concrete regressions in catalog metadata and cache-only cost reads. ## What This Changes

The branch adds lease-bound Gateway methods and durable metadata so an external orchestrator can authorize a child-session spawn and read the resulting session through list, status, and history calls.

## System Context

OpenClaw's Gateway accepts authenticated control-plane requests and dispatches child-session work to the subagent runner. This PR inserts a lease authorization and persistence layer ahead of that runner, then projects the spawned session back through Gateway discovery and read APIs.

## Best Possible Solution

Keep generic child-session authorization and readback capabilities in core only where necessary, then move Agentic OS-specific method names, metadata semantics, and downstream orchestration policy into its owner plugin or an approved generic extension contract; correct catalog/cache behavior and attach redacted current-head live evidence before merge.
