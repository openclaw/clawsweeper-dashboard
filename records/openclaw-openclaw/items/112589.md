## What This Changes

Adds lease-authorized Gateway methods for external orchestrators to spawn child sessions with metadata, persist their lease/session records, and read back status and history.

## System Context

The Gateway accepts authenticated operator requests, authorizes a child-session spawn, and invokes the subagent runner. The proposed contract then persists lease and session metadata so external orchestrators can list, inspect, replay, and release that lifecycle.
