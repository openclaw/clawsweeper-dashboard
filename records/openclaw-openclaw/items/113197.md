## What This Changes

The branch makes `openclaw channels add <channel>` and `openclaw channels add --channel <channel>` enter that channel’s guided setup immediately, while preserving the picker when no channel is supplied and returning to it on Back.

## System Context

The channel-add CLI resolves an optional channel identifier, then invokes the shared interactive channel setup flow. That flow either asks for general setup confirmation and channel selection or hands control to a channel plugin’s guided configuration, which writes the selected channel’s configuration.
