## Summary

Keep this PR open for explicit maintainer direction. It intentionally changes the documented selected-channel wizard contract from preselection with guidance to immediate entry that skips the generic confirmation and picker; the existing Back path does not establish that this public CLI behavior change is accepted.

## What This Changes

The branch makes `openclaw channels add <channel>` and `openclaw channels add --channel <channel>` enter the selected channel’s guided setup immediately, while retaining picker-first setup when no channel is supplied.

## System Context

The channels CLI resolves an optional channel selector and routes either into guided channel setup or non-interactive flag-driven configuration. Guided setup then invokes the selected channel plugin’s prompts and writes the resulting channel account configuration.

## Best Possible Solution

Preserve selected-channel picker-first guidance, or add immediate entry as an explicitly named opt-in only after a maintainer confirms that changing the established CLI workflow is the desired product direction.
