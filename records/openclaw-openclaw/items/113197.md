## Summary

Keep this PR open for maintainer review. The current branch is a bounded CLI behavior correction that routes an explicitly selected channel into the existing setup flow, but it intentionally changes the interactive contract by skipping the generic confirmation and picker for explicit selections; the PR is also member-authored and carries the protected `maintainer` label.

## What This Changes

The branch makes `openclaw channels add <channel>` and `openclaw channels add --channel <channel>` open the selected channel’s guided setup immediately, while retaining picker-first behavior for callers that do not opt into direct entry.

## System Context

The Channels CLI resolves an explicit channel selection and delegates configuration to the shared guided setup flow. That flow discovers channel plugins, runs the selected plugin’s setup handler, and returns to the channel picker when the user navigates back.
