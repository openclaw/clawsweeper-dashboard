## Summary

Keep open: current main still drops the documented global thinking default whenever an agent has a list entry without its own override, and existing resolver tests do not cover that inheritance case.

## What This Changes

Make per-agent config resolution inherit `agents.defaults.thinkingDefault` when `agents.list[].thinkingDefault` is unset.

## Best Possible Solution

Apply the documented precedence directly in `resolveAgentConfig()` and add focused coverage proving that an explicit per-agent value wins while an omitted value inherits the global default.
