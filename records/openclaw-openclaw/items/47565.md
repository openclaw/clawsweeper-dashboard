## Summary

Keep open. Current main and v2026.6.11 partially address the examples by allowing same-origin microphone access and fixed CSP origins, but there is still no supported configurable Control UI CSP or Permissions-Policy surface; the remaining work needs maintainer security and product direction.

## What This Changes

The issue requests configurable Control UI Permissions-Policy and CSP options so custom Control UI roots can opt into browser permissions and additional connect-src origins.

## Best Possible Solution

Keep hardened defaults and, if maintainers approve the direction, add a narrow typed Control UI header policy with directive validation, docs, schema/help updates, audit guidance, and focused HTTP/header tests.
