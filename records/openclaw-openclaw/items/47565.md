## Summary

Keep open. Current main and v2026.6.11 only partially address the report by allowing same-origin microphone access and adding fixed CSP origins; the requested configurable Control UI CSP and Permissions-Policy surface is still absent and needs a security/product decision.

## What This Changes

Request configurable Control UI CSP and Permissions-Policy headers so custom Control UI roots can opt into microphone access and local `connect-src` origins without patching installed bundles.

## Best Possible Solution

Keep hardened defaults, then add a maintainer-approved typed Control UI header policy with strict directive validation, docs, schema/help updates, and focused HTTP/header tests if the security contract is approved.
