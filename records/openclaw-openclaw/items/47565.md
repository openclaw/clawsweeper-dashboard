## Summary

Keep open. Current main and the latest release partially cover the reported examples by allowing same-origin microphone access and fixed built-in CSP origins, but OpenClaw still has no supported configurable Control UI CSP or Permissions-Policy surface; the remaining work needs maintainer security/product direction.

## What This Changes

The issue requests configurable Control UI Permissions-Policy and CSP header options so custom Control UI roots can use browser permissions and local network endpoints without patching installed dist files.

## Best Possible Solution

Keep hardened defaults and, if maintainers approve the direction, add a narrow typed Control UI header policy with directive validation, docs, schema/help updates, audit guidance, and focused HTTP/header tests.
