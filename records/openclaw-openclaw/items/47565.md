## Summary

Keep open. Current main and v2026.6.11 partially cover the examples by allowing same-origin microphone access and fixed built-in CSP origins, but there is still no supported configurable Control UI CSP or Permissions-Policy surface; the remaining work needs maintainer security/product direction.

## What This Changes

Request configurable Control UI Permissions-Policy and CSP header controls in `openclaw.json` for custom UI roots that need microphone and local `connect-src` access.

## Best Possible Solution

Keep hardened defaults and, if maintainers approve the direction, add a narrow typed Control UI header policy with directive validation, docs, schema/help updates, audit guidance, and focused HTTP/header tests.
