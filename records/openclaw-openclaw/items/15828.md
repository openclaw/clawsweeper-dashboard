## Summary

Keep open. Current main and v2026.6.11 still keep bundled session-memory scoped to explicit command hooks, while the requested idle, shutdown, periodic checkpoint, trigger config, and summary-output behavior remains unresolved and requires maintainer product/security direction.

## What This Changes

Request automatic session-memory checkpoints for idle, shutdown, periodic/message-count, and explicit command triggers, with optional LLM-generated summaries and new hook configuration.

## Best Possible Solution

Keep this as the broad session-memory automation tracker while maintainers choose one lifecycle contract: land or replace the daily/idle path, then separately scope bounded shutdown capture, periodic checkpoints, and opt-in summary output with privacy docs and regression coverage.
