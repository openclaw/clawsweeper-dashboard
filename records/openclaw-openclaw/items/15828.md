## Summary

Keep open: current main still leaves the bundled session-memory hook on the manual command path only, while this issue asks for broader idle, shutdown, periodic checkpoint, and summary-output behavior that remains product- and security-sensitive.

## What This Changes

Request auto-triggered session-memory persistence on idle, shutdown, periodic message checkpoints, and optional LLM summary output beyond the existing manual reset commands.

## Best Possible Solution

Keep this as the broad tracker, land or replace the daily/idle slice through the active related work, then define one maintainer-approved memory finalization contract for shutdown, periodic checkpoints, summaries, dedupe, docs, tests, and privacy behavior.
