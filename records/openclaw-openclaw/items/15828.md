## Summary

Keep open. Current main and the latest release still keep bundled session-memory capture scoped to explicit command hooks, while the requested idle/shutdown/periodic triggers and summary-output config remain a broader lifecycle, plugin-contract, and privacy decision.

## What This Changes

Request automatic session-memory checkpoints on idle, shutdown, periodic message-count boundaries, and optional LLM summary output instead of only manual reset commands.

## Best Possible Solution

Keep this as the broad automatic session-memory tracker while maintainers choose the lifecycle contract, land or replace the daily/idle subset, and then separately scope bounded shutdown capture, periodic checkpoints, and opt-in summary output with privacy docs and regression coverage.
