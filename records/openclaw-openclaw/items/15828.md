## Summary

Keep open. Current main still keeps bundled session-memory persistence scoped to explicit command hooks, and the active related PR only covers the daily/idle subset while shutdown, periodic checkpoints, and summary-output behavior remain unresolved product/security work.

## What This Changes

The issue requests automatic session-memory checkpoints on idle, shutdown, and periodic message-count triggers, plus an optional summarized-memory output mode.

## Best Possible Solution

Keep this as the broad session-memory automation tracker while maintainers choose one lifecycle contract: land or replace the daily/idle path, then separately scope bounded shutdown capture, periodic checkpoints, and opt-in summary output with privacy docs and regression coverage.
