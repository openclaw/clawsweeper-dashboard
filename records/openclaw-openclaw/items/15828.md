Keep open. Current main and v2026.6.11 still leave the bundled session-memory hook command-only, while the requested idle, shutdown, message-count, and summary checkpoint behavior remains unimplemented and still needs maintainer product/security scoping.

## Best Possible Solution

Use this as the broad tracker: resolve the daily/idle reset hook path first, then design bounded shutdown and periodic checkpoint semantics plus opt-in summary/privacy config with docs and targeted tests.
