## Summary

Keep open. Current main and latest release still implement bundled session-memory as command-only persistence, while idle/daily rollover, shutdown checkpointing, message-count checkpoints, and summary-output behavior remain unimplemented or covered only by related open work.

## What This Changes

Request automatic session-memory checkpoints on idle, shutdown, periodic message-count, and command triggers, plus optional LLM summary output and trigger config.

## Best Possible Solution

Keep this as the broad session-memory automation tracker, consolidate the daily/idle candidate first, then explicitly scope shutdown checkpointing, periodic checkpoints, and opt-in summary output with privacy and dedupe rules.
