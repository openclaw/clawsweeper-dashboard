## Summary

Keep open. Current main and v2026.6.11 still keep bundled session-memory persistence scoped to explicit command hooks, while the requested idle, shutdown, periodic checkpoint, trigger config, and summary-output behavior remains broader than the active daily/idle PR.

## What This Changes

Request automatic session-memory capture on idle, shutdown, message-count checkpoints, and optional LLM summaries instead of only explicit session commands.

## Best Possible Solution

Keep this as the broad session-memory automation tracker while maintainers choose a lifecycle contract: land or replace the daily/idle PR path, then separately scope bounded shutdown capture, periodic checkpoints, and opt-in summary output with privacy docs and regression coverage.
