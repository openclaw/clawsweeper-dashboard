## Summary

Keep open. Current main still keeps bundled session-memory persistence scoped to explicit command hooks, while idle/daily rollover, shutdown, periodic checkpointing, trigger config, and summary-output semantics remain unresolved product and security work.

## What This Changes

The issue requests automatic session-memory checkpoints for idle, shutdown, message-count, and command boundaries, plus optional LLM summary output and trigger configuration.

## Best Possible Solution

Keep this as the broad session-memory automation tracker while maintainers choose one lifecycle contract: land or replace the daily/idle path, then separately scope bounded shutdown capture, periodic checkpoints, and opt-in summary output with privacy docs and regression coverage.
