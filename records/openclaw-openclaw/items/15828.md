## Summary

Keep open. Current main and v2026.6.11 still keep bundled session-memory persistence scoped to explicit command hooks, while idle/shutdown/message-count checkpoints and summary-output behavior remain unresolved product, lifecycle, and security work.

## What This Changes

Request automatic session-memory capture on idle, shutdown, and periodic checkpoints, plus an optional LLM summary mode and trigger configuration.

## Best Possible Solution

Keep this as the broad session-memory automation tracker while maintainers choose one lifecycle contract: land or replace the daily/idle path, then separately scope bounded shutdown capture, periodic checkpoints, and opt-in summary output with privacy docs and regression coverage.
