The PR addresses the correct shipped upgrade regression and has strong live proof, but the compatibility predicate still accepts internally inconsistent vectors when both rows declare the same `dims` and both JSON arrays have the same different length. That can archive the legacy sidecar while retaining a canonical cache entry the runtime consumes without dimension validation, so one focused predicate and test repair is needed before merge.

## What This Changes

The PR changes Memory Core legacy embedding-cache migration to preserve compatible canonical same-key rows and adds regression coverage for successful convergence and unsafe collision rollback.
