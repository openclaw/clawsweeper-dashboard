## Summary

## What This Changes

Adds a 30s default Mattermost REST request timeout with per-request override support and loopback tests for hangs, caller aborts, and DM retry timeout preservation.

## Best Possible Solution

Land the shared Mattermost client timeout once maintainers accept the 30s default, keeping SSRF policy, caller aborts, and per-request DM retry overrides intact.
