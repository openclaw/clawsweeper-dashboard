## What This Changes

The PR adds a 30s default timeout and per-request timeout override to the Mattermost REST client, preserving longer DM retry timeouts and adding loopback regression coverage.

## Best Possible Solution

Land the shared Mattermost client timeout after maintainers accept the 30s default runtime contract, keeping SSRF policy, caller aborts, and DM retry overrides intact.
