## Summary

Keep this PR open for a focused repair and owner review: the Copilot-specific fix and live proof are strong, but the patch makes runtime credential retrieval eager across the shared embedded-agent transport path, so unrelated providers can now fail before their selected stream transport runs.

## What This Changes

The PR restores GitHub Copilot managed transport routing, scopes exchanged-token and live-model metadata to credentials/profiles, and rematerializes account-specific model limits during fallback and compaction.

## Best Possible Solution

Keep credential acquisition lazy and provider-owned: let GitHub Copilot opt into the managed boundary transport through its existing runtime-model ownership hook or carry a prepared auth-availability fact forward, while preserving unchanged transport initialization for unrelated providers and proving fresh, upgrade, rotation, fallback, and compaction cases.
