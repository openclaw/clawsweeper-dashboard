## Summary

## What This Changes

## Best Possible Solution

Preserve the single successful-download deadline, but classify retryable HTTP statuses before reading their bodies, cancel those bodies, retry with a meaningful remaining budget, and retain bounded diagnostic reads for non-retryable responses.
