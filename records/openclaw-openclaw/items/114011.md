## What This Changes

The PR changes plugin installer tests so their temporary policy fixtures are created beneath the operating system temporary directory instead of the checkout-local `.tmp` directory.

## System Context

Plugin installer tests create temporary plugin packages and run the same policy/security checks used to validate installation inputs. The fixture root feeds those checks; moving it outside the repository checkout prevents filesystem permissions on checkout ancestors from changing the intended test result.
