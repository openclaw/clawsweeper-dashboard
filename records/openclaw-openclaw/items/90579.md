## Summary

Keep open: current main still only trusts generated HTML when the loaded file is under the OpenClaw temp root, while this PR carries that trust through outbound staging with content-bound SQLite provenance. ## What This Changes

The PR adds SQLite-backed sha256/size provenance for trusted generated HTML after outbound media staging and verifies that provenance on later host-read reloads.

Merge this PR after explicit maintainer/security acceptance of the provenance-gated trust lifecycle and an exact-head update; keep row TTL/chunking and send-stage degradation as follow-up hardening.
