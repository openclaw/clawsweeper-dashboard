## Summary

## Best Possible Solution

Land this PR or an equivalent content-bound provenance fix after maintainer/security acceptance, while keeping arbitrary host-local or unmarked outbound HTML blocked and closing https://github.com/openclaw/openclaw/issues/90557 on merge.
