## What This Changes

This PR changes Codex app-server startup to retry classified connection-close failures up to five times with bounded abortable backoff, then raises a distinct exhaustion error while preserving the original cause.

## System Context

The bundled Codex plugin creates or leases a local Codex app-server client before it can start or resume an embedded agent thread. A close during that startup path currently clears the shared client and immediately retries, so repeated short-lived process failures can fail a scheduled turn before its work begins.
