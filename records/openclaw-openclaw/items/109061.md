## Summary

The current head still has the prior P1 caption regression: it forbids the message tool and tells every resumed agent to emit a normal final caption, but message-tool-only requester routes do not deliver that normal final reply. The media-ownership direction is otherwise appropriate, and live exactly-once Telegram proof remains missing.

The PR changes shared image, video, and music completion guidance so durable handoff owns generated-media delivery, forbids agent media reattachment and message-tool sends, and adds instruction-level regression tests.

## Best Possible Solution

Keep completion handoff as the sole media owner, but route caption text through the actual source-channel delivery contract for both normal-reply and message-tool-only origins, with regression coverage for each and a redacted live Telegram exactly-once run.
