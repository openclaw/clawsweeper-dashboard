## Summary

Keep open: current main still has subagent lost-context and killed terminal paths, plus diagnostics and OTel export surfaces, but no stable subagent-death event or exporter mapping for downstream trace consumers.

## What This Changes

The issue requests a stable telemetry marker or span when a spawned subagent dies or is terminated so downstream trace exporters can detect the failed session and reason.

## Best Possible Solution

Add a maintainer-approved trusted diagnostic event for spawned subagent terminal states and map it to OTel with stable kind/reason fields, redacted identifiers, and focused registry/exporter coverage.
