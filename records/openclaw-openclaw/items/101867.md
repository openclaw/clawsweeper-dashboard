## Summary

Keep open: current main still completes subagent lost-context and termination paths without a stable subagent-death diagnostic event or diagnostics-otel mapping, so downstream trace consumers remain blind to this failure class.

## What This Changes

The issue requests a stable telemetry/span marker for spawned subagent death or termination, including child identity, termination reason, and a detectable event kind.

## Best Possible Solution

Add a maintainer-approved trusted subagent terminal diagnostic event from the registry terminal paths and map it to OTel with redacted identifiers, stable reason fields, and focused registry/exporter tests.
