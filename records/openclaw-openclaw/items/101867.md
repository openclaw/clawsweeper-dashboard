## Summary

Keep open: current main has diagnostics and OpenTelemetry export for run and tool events, but the subagent terminal paths that mark killed, errored, or lost execution context still lack a stable diagnostic marker that downstream trace consumers can count.

## What This Changes

Request emission of a stable telemetry span or annotation when a spawned subagent dies or is terminated.

## Best Possible Solution

Add a maintainer-approved trusted diagnostic event on the existing diagnostics/OTel plane for subagent terminal states, with stable kind/reason fields, redacted identifiers, exporter mapping, and focused registry/exporter tests.
