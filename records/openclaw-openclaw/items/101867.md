## Summary

Keep open: current main still has structured diagnostics and OTel export, plus subagent lifecycle bookkeeping, but the lost-context and terminated subagent paths do not emit a stable subagent-death diagnostic event or exported span for downstream trace consumers.

## What This Changes

Request emission of a stable telemetry marker or span when a spawned subagent dies or is terminated, including identity and reason fields.

## Best Possible Solution

Create a core-owned trusted diagnostic event for spawned subagent terminal states, then map it through diagnostics-otel with low-cardinality reason fields, redacted identifiers, and focused registry/exporter tests.
