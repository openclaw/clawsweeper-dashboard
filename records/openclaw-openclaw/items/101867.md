## Summary

Keep open: current main still exposes run/tool/session diagnostics and OTel export, but the subagent lost-context and killed terminal paths do not emit a stable subagent-death diagnostic marker for downstream trace consumers.

## What This Changes

The issue asks OpenClaw to emit or annotate telemetry for spawned subagent death or termination, including a stable marker, session/process identity, and termination reason.

## Best Possible Solution

Add a maintainer-approved trusted diagnostic event for subagent terminal states and map it to OTel with stable kind/reason fields, redacted identifiers, and focused registry/exporter tests.
