## Summary

Keep open: current main still records subagent lost-context and killed terminal states internally, but there is no stable diagnostic event or diagnostics-otel exporter case for spawned subagent death/termination.

## What This Changes

The issue requests a stable telemetry signal when a spawned subagent process dies or is terminated.

## Best Possible Solution

Add a maintainer-approved trusted diagnostic event for spawned subagent terminal states and map it to diagnostics-otel with redacted identifiers, stable reason fields, and regression coverage.
