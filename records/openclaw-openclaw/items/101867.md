## Summary

Keep open: current main has general run/tool diagnostics and OTel export, but subagent lost-context and killed/terminated paths still have no stable diagnostic event or OTel span marker for downstream trace consumers.

## What This Changes

The issue asks OpenClaw to emit stable telemetry for spawned subagent death or termination, including child identity, reason, and a detectable marker.

## Best Possible Solution

Add a maintainer-approved trusted diagnostic event for subagent terminal states and map it to OTel with stable kind/reason fields, redacted identifiers, and registry/exporter tests.
