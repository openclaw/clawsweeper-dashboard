## Summary

Keep open: current main still records subagent terminal state and exposes a plugin hook, but it does not emit a stable diagnostics/OTel marker for spawned subagent death or termination.

## What This Changes

The issue requests a stable telemetry signal for spawned subagent death or termination so downstream trace exporters can detect failed sessions_spawn children.

## Best Possible Solution

Add a maintainer-approved trusted subagent terminal diagnostic event and OTel mapping with redacted identifiers, stable reason/outcome fields, and registry/exporter tests.

## Solution Assessment

Unclear until maintainers choose the public contract; the best direction appears to be a trusted diagnostic terminal event rather than ad hoc empty-error handling. The existing subagent_ended hook is useful but does not solve the diagnostics/OTel trace gap by itself.
