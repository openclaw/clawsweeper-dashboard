## Summary

Keep open: current main and the latest release still complete subagent lost-context and killed paths without emitting a stable subagent-death diagnostic event or OTel span, so downstream trace consumers remain blind to this failure class.

## What This Changes

The issue requests a stable telemetry marker or span annotation for spawned subagent death or termination, including the child identity and exit reason.

## Best Possible Solution

Add a maintainer-approved trusted diagnostic event for spawned subagent terminal states and map it to OTel with stable kind/reason fields, redacted identifiers, and focused registry/exporter tests.
