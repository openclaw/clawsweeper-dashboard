## Summary

Keep open: current main still records subagent terminal state and exposes a plugin lifecycle hook, but it does not emit a trusted diagnostics event or diagnostics-otel span for subagent death/termination, so the observable telemetry gap remains.

## What This Changes

## Best Possible Solution

Add a maintainer-approved trusted diagnostic/OTel representation for subagent terminal states, preferably reusing `subagent_ended` semantics with redacted target identity, stable reason/outcome fields, and registry/exporter tests.
