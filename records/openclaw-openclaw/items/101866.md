## What This Changes

Adds an assistant-only session-replay guard that replaces nonexistent or unsafe managed-media file paths in replayed transcript text while preserving valid file references, prose, and all user text.

## System Context

Session transcript readers turn persisted user and assistant turns into recent context for later agent prompts. This change intercepts assistant-visible text immediately before that replay path, checks managed-media references against the local media store, and prevents unverified references from becoming self-reinforcing prompt context.
