## Summary

This maintainer-authored draft must stay open, and the prior P1 remains valid: Crabbox merges repository config over user config, so reading `config show --json` still selects this repository’s Testbox provider rather than implementing the advertised persistent local-provider preference. The proposed policy needs explicit maintainer direction before revision or merge.

## What This Changes

The PR changes the Crabbox wrapper to derive implicit provider selection from merged CLI configuration, fail closed when that configuration cannot be resolved, revise provider-selection guidance, and add focused tests.

## Best Possible Solution

Preserve Testbox as the repository default and use existing explicit `--provider` or `CRABBOX_PROVIDER` overrides, unless maintainers first approve and implement a distinct higher-precedence operator-preference contract in Crabbox with layered precedence and upgrade coverage.
