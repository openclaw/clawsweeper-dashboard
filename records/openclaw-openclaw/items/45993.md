## Summary

Request to add `openclaw migrate export` and `openclaw migrate import` for selective cross-platform OpenClaw state migration with path remapping, secret handling, memory merge, and dependency checks.

## Best Possible Solution

Choose the recovery model first: either evolve `openclaw backup` with selective/platform-targeted export or conversion plus clear user-driven restore docs, or approve an automated import design with preview-first UX, strict archive validation, canonical target checks, rollback, and security-focused tests.
