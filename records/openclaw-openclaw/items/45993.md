## Summary

Keep open: current main and v2026.6.11 still provide provider-based imports plus local backup create/verify, not the requested same-product cross-platform export/import workflow, and the remaining scope needs maintainer product/security direction.

## What This Changes

Add `openclaw migrate export` and `openclaw migrate import` for selective, cross-platform OpenClaw workspace/state migration with path remapping and explicit secret handling.

## Best Possible Solution

Keep this as the canonical same-product cross-platform migration tracker until maintainers define a safe core export/import or backup-restore contract that covers path remapping, secrets, state portability, dry-run/conflict behavior, rollback, and docs.
