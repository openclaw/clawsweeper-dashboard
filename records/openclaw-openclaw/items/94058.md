## Summary

Keep open: current main and the latest release still contain the cron finalization path that can let a delivery error-shaped result overwrite a successful isolated execution result, and the direct fixes are still open PRs rather than merged code.

## What This Changes

The issue reports scheduled isolated cron `agentTurn` runs whose isolated session succeeds and produces a final assistant report, while the parent cron run is persisted as `error`/`not-delivered`.

## Best Possible Solution

Cron finalization should persist isolated agent execution success separately from delivery or finalization failure, keep delivery diagnostics operator-visible, and include regression coverage for the scheduler persistence boundary.
