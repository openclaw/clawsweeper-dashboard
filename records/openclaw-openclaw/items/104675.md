Because this is a maintainer-owned, protected-label PR, it should remain open for the narrow repair and normal review rather than cleanup closure.

## What This Changes

The PR adds nested Settings search results that navigate to and scroll to matching Quick Settings blocks, virtual sections, and advanced config sections.

## Best Possible Solution

Make fragment parsing total with focused malformed-hash coverage while preserving the existing canonical navigation, schema matcher, and delayed-scroll behavior.
