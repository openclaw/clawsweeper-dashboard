## Summary

Keep this issue open: current main has authenticated Gateway WebSocket WebChat, device pairing, Matrix E2EE as a third-party channel, and browser Talk/WebRTC, but not the requested native no-third-party browser-held E2EE chat transport with encrypted browser message envelopes and per-device/per-agent keys.

## What This Changes

Request to add native no-third-party browser-held E2EE chat with per-device and per-agent encrypted browser channels.

## Best Possible Solution

Define a maintainer-approved encrypted browser-channel threat model first, then implement protocol/key lifecycle, per-device and per-agent routing isolation, transcript semantics, relay/recovery behavior, docs, and contract tests under the chosen core or plugin boundary.

- **Defer Native Transport:** Keep WebChat, Tailscale, Matrix E2EE, Signal, and dmScope isolation as supported paths unless maintainers later sponsor this direction.
