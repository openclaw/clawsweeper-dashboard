## What This Changes

Request native browser-held E2EE browser chat with QR/device pairing and per-device/per-agent encrypted channels, avoiding third-party chat apps.

## Best Possible Solution

Define a maintainer-approved encrypted browser-channel threat model and capability first, then implement the chosen core or plugin-seam path with key lifecycle, encrypted envelopes, per-device/per-agent routing, transcript semantics, relay/recovery behavior, docs, and contract tests.
