## What This Changes

The issue asks for the Control UI composer to show an in-progress indicator and Stop button whenever the selected session has actively running tool execution shown in Activity.

## Best Possible Solution

Review and land a selected-session-safe fix through https://github.com/openclaw/openclaw/pull/98544, or replace it with an equivalent narrow PR, then close this issue when composer progress and abort controls follow active tool execution.

## Reproduction Assessment

Yes, we have a high-confidence source-backed reproduction path: the screenshot shows Activity running while the composer is idle, and current main has separate Activity/tool-event and composer-abort state paths. I did not run a live browser repro in this read-only pass.

## Solution Assessment
