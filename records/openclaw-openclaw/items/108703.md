## Summary

This PR should not merge as written: SQLite documents the WAL-reset corruption bug as present through 3.51.2, with only specific backports such as 3.44.6 and 3.50.7, so accepting every 3.45.x–3.49.x build defeats the corruption guard. The linked alternative at https://github.com/openclaw/openclaw/pull/108287 follows a safer verified-backport approach, but it lacks sufficient real-environment proof to justify closing this PR as superseded yet. ([sqlite.org](https://www.sqlite.org/wal.html?utm_source=openai))

## What This Changes

The PR changes the SQLite WAL-safety predicate and tests so every upstream version from 3.45.0 through 3.49.x is accepted.

## Best Possible Solution

Keep embedded and ordinary upstream 3.45–3.49 builds blocked; support verified distribution backports only through a narrowly scoped shared-library signal or explicit operator opt-in, with live UBI Node 24.18.0 proof and coverage that an embedded 3.46.1 build remains rejected.
