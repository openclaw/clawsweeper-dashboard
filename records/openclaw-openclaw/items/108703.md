## Summary

Keep this PR open for revision, but do not merge it: the proposed range contradicts SQLite’s authoritative WAL-reset guidance and would weaken OpenClaw’s database-corruption safety gate. The linked regression is real, but its misleading version message does not establish that SQLite 3.45.x–3.49.x is safe.

## What This Changes

The PR changes the SQLite runtime safety predicate and tests to accept every SQLite 3.45.x through 3.49.x release.

## Best Possible Solution

Preserve the explicit upstream-confirmed allowlist, correct diagnostics so “3.44.6+” cannot be misread as every later 3.x release, and evaluate any distro-specific backport through a narrowly verified override rather than a blanket minor-version range.
