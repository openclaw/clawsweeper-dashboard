## Summary

Keep open: current main has adjacent OpenRouter billed-total reconciliation and estimate-based usage surfaces, but agents still do not get an explicit provider-reported OpenRouter cost contract with source, units, raw details, or session/runtime exposure.

## What This Changes

Expose OpenRouter provider-reported per-response cost fields to agent runtime or session tools so agents can report exact reply costs.

## Best Possible Solution

Define additive provider-reported cost metadata with source and units, preserve it separately from local estimates, and thread it through transcript, session, runtime, and status surfaces before channel footers render it.

## Solution Assessment

No current implementation fully solves it; the best path is an additive exact-cost metadata contract with fallback to existing estimates, not relabeling existing estimated fields.
