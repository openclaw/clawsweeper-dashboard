## Summary

Keep this issue open. Current main captures and aggregates OpenRouter’s provider-reported billed total, including authoritative zero-cost responses, but the exact amount is still not exposed through the agent-callable `session_status` surface; user-facing status remains estimate-oriented.

**Likely related people**
- `snowzlmbot` — introduced provider-billed cost accounting; high confidence.
- `steipete` — recent session-status contributor and prior reviewer; high confidence.
- `Lellansin` — introduced the OpenAI-compatible real-usage path; medium confidence.

## What This Changes

Expose OpenRouter’s provider-reported per-response cost to agents as per-turn and cumulative runtime/session usage metadata.

## Best Possible Solution

Extend the existing `provider-billed` accounting path with source-tagged last-turn and cumulative cost fields in an agent-callable usage/status contract, while retaining `estimatedCostUsd` as a separately labeled fallback for responses without authoritative billing.
