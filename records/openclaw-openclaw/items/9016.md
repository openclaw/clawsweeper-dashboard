## Summary

Keep open: current main has OpenRouter billed-total reconciliation and estimate-based usage surfaces, but it still does not expose OpenRouter provider-reported `usage.cost` / `cost_details.upstream_inference_cost` through agent runtime or `session_status`; the remaining work is a product/API contract decision.

## What This Changes

Expose OpenRouter per-response cost data to agents so replies, session metadata, or tools can show exact provider-reported costs.

## Best Possible Solution

Define additive provider-reported cost metadata with source and units, preserve it separately from local estimates, and thread it through transcript, session, runtime, status, and response-usage surfaces before channels render it.
