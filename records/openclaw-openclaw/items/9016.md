## Summary

Current main still lacks the central requested OpenRouter exact-cost contract: it has estimate-based cost surfaces and a partial OpenRouter generation-total reconciliation, but it does not carry provider-reported cost metadata through runtime/session/status/tool consumers.

## What This Changes

Expose OpenRouter provider-reported response cost metadata, including upstream inference cost details, to the agent runtime and session/status surfaces.

## Best Possible Solution

Define an additive provider-reported cost metadata contract at the OpenRouter/OpenAI-compatible boundary, keep it distinct from local estimates, and thread per-turn and cumulative values through transcript, runtime, session, status, and tool consumers.
