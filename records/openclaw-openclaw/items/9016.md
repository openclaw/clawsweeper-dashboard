## Summary

Keep open: current main has OpenRouter billed-total reconciliation and estimate-based usage surfaces, but it still does not expose OpenRouter provider-reported `usage.cost` / `cost_details.upstream_inference_cost` through agent runtime or `session_status`; the remaining work is choosing and implementing the metadata contract.

## What This Changes

Expose OpenRouter provider-reported per-response cost data to agents through runtime/session metadata or a usage tool so replies can show exact costs.

## Best Possible Solution

Define additive provider-reported cost metadata with source and units, preserve it separately from local estimates, and thread it through transcript, session, runtime, and status surfaces before channel footers render it.
