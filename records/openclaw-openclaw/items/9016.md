## Summary

Keep this issue open. Current main has adjacent estimated-cost and OpenRouter billed-total plumbing, but it still does not expose OpenRouter provider-reported per-response cost metadata to agent runtime, session status, or tool consumers.

## What This Changes

Expose OpenRouter per-response `usage.cost` and related cost details to agent runtime/session surfaces so agents can report exact per-turn costs.

## Best Possible Solution

Define an additive provider-reported cost metadata contract at the OpenRouter/OpenAI-compatible boundary, keep it distinct from local estimates, and thread per-turn and cumulative values through transcript, runtime, session status, and tool consumers.
