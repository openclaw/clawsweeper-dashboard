## What This Changes

This PR strips streamed `MEDIA:` directives from visible replies, probes video dimensions from a seekable temporary file, and prevents steered webchat follow-ups from re-finalizing a turn already owned by an active run.

## System Context

OpenClaw turns agent output into streamed webchat replies and channel attachments, including Telegram videos. Separately, gateway `chat.send` dispatch can steer or queue a second user message while an agent run owns the session transcript; the post-dispatch path must not write that turn a second time.
