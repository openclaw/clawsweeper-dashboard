## What This Changes

This PR removes visible streamed `MEDIA:` directives, probes video dimensions from a seekable temporary file, and prevents steered webchat turns from writing fallback state after an active runtime has adopted them.

## System Context

`chat.send` accepts a webchat turn, hands it to the agent runtime, and later finalizes delivery and transcript state; concurrent steer/follow-up paths must not create a second state owner. Reply delivery also parses model-produced media directives before channels such as Telegram receive the attachment and its video metadata.
