## What This Changes

This PR strips streamed MEDIA directives from visible replies, probes video dimensions from a seekable temporary file, and prevents steered webchat follow-ups from re-owning an active run’s transcript work.

## System Context

Agent replies pass through reply parsing and channel delivery, while webchat requests pass through the Gateway’s chat.send lifecycle. This PR changes how reply directives become visible text or attachments, how video metadata is derived before delivery, and who owns post-dispatch transcript finalization for an active agent run.
