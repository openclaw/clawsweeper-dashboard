## Summary

The patch addresses a real misleading update result, but its condition is broader than OpenClaw’s existing official-plugin version contract. It treats every exact official package/core mismatch as stale, including independently versioned catalog packages and pins newer than core, so the recovery command can be invalid or become downgrade advice. The useful lockstep Codex case should remain, but the helper needs a catalog lockstep gate, direction-aware comparison, and direct after-fix terminal proof before merge.

## What This Changes

The PR changes targeted plugin updates so an unchanged exact-pinned trusted official npm plugin can report core-version drift and print an explicit package-version update command, with regular and dry-run tests.

## Best Possible Solution

Reuse the existing official catalog lockstep-versus-independent contract, emit the hint only when an exact lockstep pin is older than a valid core target, and prove the resulting terminal message and command in a real dry run.
