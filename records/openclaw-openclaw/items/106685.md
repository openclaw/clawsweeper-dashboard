## What This Changes

Prevent gateway shutdown from leaving unreaped plugin or bash subprocesses that could exhaust the operating-system process table.

## Best Possible Solution

First reproduce on current Linux `main` with PID/PPID and process-state evidence; if gateway close leaves owned runs active, add one bounded process-supervisor `cancelAllAndWait` operation and invoke it from gateway shutdown, with SIGTERM grace, SIGKILL escalation, and regression coverage proving both promise settlement and absence of surviving or defunct owned children.
