## Summary

Keep open: the gateway-auth seam change is the right direction for the Mattermost regression, but the current head still adds the broad installed-root fallback to the shared bundled public-surface loader, which reintroduces the trust-boundary problem the PR body says was reverted.

## Best Possible Solution

Yes. Source inspection plus the PR's packaged-install and live Mattermost output show v2026.6.11 loses the bundled Mattermost gateway-auth artifact, leaving protected channel callbacks to hit gateway bearer auth before plugin code runs.
