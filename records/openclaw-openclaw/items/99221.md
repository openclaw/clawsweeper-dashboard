## Summary

## What This Changes

The branch adds allowlisted GitHub Enterprise `*.ghe.com` domain routing to the bundled `github-copilot` provider across auth, token exchange/cache, runtime auth, usage, embeddings, docs, and tests.

## Best Possible Solution

The best end state is one provider-owned GHE tenant-routing path that persists the chosen domain consistently across interactive and headless auth, keeps public `github.com` as the no-config default, and preserves fail-closed host/token scoping.
