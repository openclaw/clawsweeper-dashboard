## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Restrict Enterprise Copilot domains before token exchange:** `src/plugin-sdk/provider-auth.ts:153-154`
  - body: The new normalizer treats any bare hostname as trusted, and `resolveCopilotApiToken` sends the GitHub OAuth token to `https://api.${domain}/copilot_internal/v2/token`. A typo or config/env injection such as `evil.com` would exfiltrate the OAuth token to `api.evil.com` instead of failing closed, so reject non-tenant domains before constructing auth/token URLs.
  - confidence: 0.92
- **[P1] Scope the Copilot token cache by GitHub domain:** `src/plugin-sdk/provider-auth.ts:369-383`
  - body: `resolveCopilotApiToken` still accepts the single `credentials/github-copilot.token.json` token before exchanging against the requested domain. Switching from public GitHub to `acme.ghe.com` can return a cached public Copilot API token and then use it with `https://copilot-api.acme.ghe.com`; include the domain in the cache key or cached payload validation.
  - confidence: 0.88
