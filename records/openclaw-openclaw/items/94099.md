## What This Changes

This PR adds an optional `onHiddenDiagnostic` callback to `BuildToolPlanOptions`, invokes it for hidden availability diagnostics, guards non-array availability groups, and adds focused tests.

## Best Possible Solution

Land one canonical fix that keeps the evaluator pure and surfaces malformed availability diagnostics once at the plugin descriptor registration or resolver boundary; keep the planner callback only if maintainers accept that public API.

## Reproduction Assessment

## Solution Assessment

No. The callback is a plausible helper, but without a production caller or registration sink it is not the complete fix for the linked runtime diagnostic issue.
