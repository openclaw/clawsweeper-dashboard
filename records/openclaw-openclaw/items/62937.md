  - confidence: 0.98
- **[P1] Make the default sandbox profile deny by default:** `src/agents/bash-tools.exec-runtime.ts:130`
  - body: The `default` profile starts with `(allow default)` while the PR advertises filesystem access limited to `/tmp` and the workspace. That makes the allowlist misleading as a security boundary; start from a deny-default profile and add only the required reads/writes.
  - confidence: 0.86
- **[P1] Use the provider-friendly enum schema:** `src/agents/bash-tools.exec-runtime.ts:190`
  - body: This adds `sandboxProfile` as a `Type.Union` of literals. Current exec schemas use flat string enum helpers because some providers reject `anyOf`-style tool parameters, so this can break provider tool registration before exec runs.
  - confidence: 0.84
