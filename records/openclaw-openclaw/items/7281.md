## Summary

Keep open: current main and the latest release still model hook mapping delivery as a single channel/target, so the requested post-failure fallback chain remains unimplemented and needs a maintainer product decision before repair work.

## What This Changes

Requests a `fallbackChannel` or `fallbackChannels` hook mapping option so delivered hook agent results can try alternate channels after primary delivery fails.

## Best Possible Solution

Define a typed hook fallback delivery contract, then carry an ordered fallback list through hook config/schema, mapping resolution, hook dispatch, cron delivery, docs, and regression tests for primary-fails, fallback-succeeds, and all-targets-failed outcomes.
