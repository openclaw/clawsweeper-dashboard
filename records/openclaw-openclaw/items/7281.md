## Summary

Keep open. The requested post-failure hook delivery failover remains a product and compatibility decision: current review evidence shows hook mappings model one target, while existing outbound fallback helpers do not establish safe cross-channel retry semantics. A maintainer should choose the recipient, privacy, retry, and duplicate-prevention contract before implementation.

## What This Changes

Add an opt-in ordered fallback channel or target chain for `deliver: true` hook mappings when the primary outbound delivery fails.

## System Context

Hook mappings turn an inbound event into an agent run and a cron-style outbound delivery request. That request currently selects one channel and recipient, then hands it to outbound delivery; the requested change would add a policy-controlled alternate-target step after a failed send.

## Architecture Diagram

flowchart LR
  A[Incoming hook event] --> B[Hook mapping]
  B --> C[Agent response]
  C --> D[Primary delivery target]
  D --> E{Send outcome}
  E -->|Accepted| F[Delivery recorded]
  E -->|Definite failure| G[Policy-controlled fallback target]
  G --> F

## Best Possible Solution

Define an opt-in typed delivery-target chain with explicit recipient/account ownership and retry eligibility, persist it through the hook-to-cron path, retry only on definite pre-acceptance failures, and add focused primary-success, fallback-success, ambiguous-send, and exhaustion coverage.

## Risks / Open Questions

- A cross-channel retry can deliver Gmail or other hook content to a different recipient, account, or session unless fallback targets and authorization are explicit.
- An ambiguous primary send failure may occur after the provider accepted the message; automatic retry can therefore duplicate a notification unless the contract distinguishes definite failure from uncertain delivery.
- Adding fallback targets changes hook configuration and persisted cron-delivery behavior, so upgrade, validation, and all-targets-failed reporting need a deliberate compatibility design.
