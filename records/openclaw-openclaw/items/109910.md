## What This Changes

The PR moves Slack Socket Mode, HTTP Events API, and relay delivery onto the core durable ingress drain, replacing prior inbound caches and mention-race handling with durable admission and a logical dispatch replay guard.

## Best Possible Solution

Retain the core ingress-drain architecture, serialize relay identity with each durable frame, restore mention-twin dropped-history suppression under the new claim lifecycle, and prove acknowledgement plus post-restart single dispatch on real Slack transports before merge.
