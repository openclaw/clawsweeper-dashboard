## Summary

Keep this PR open for plugin-hook owner review: the bounded fail-closed behavior addresses the reported wedge and has credible real-run proof, but it deliberately changes the runtime contract for existing slow `before_tool_call` handlers.

## What This Changes

Adds a 15-second default timeout for `before_tool_call` plugin hooks and a regression test that a hung fail-closed handler denies the tool call.

## Best Possible Solution

Confirm a documented global timeout contract for gating hooks—accepting the 15-second fail-closed default only if slow existing handlers are intentionally unsupported—and keep the regression coverage for hung handlers.
