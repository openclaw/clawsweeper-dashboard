## What This Changes

Request heading-aware memory-search chunking and a broader entity extraction or graph-memory layer to improve recall precision from Markdown memory files.

## Best Possible Solution

Keep this issue as the canonical tracker, split the narrow heading-aware chunking design from entity/graph-memory work, and have maintainers choose the memory-core API/default plus reindex contract before implementation.
