Request heading-aware Markdown memory chunking plus entity extraction and graph-memory improvements for `memory_search` recall.

## Best Possible Solution

Split heading-aware chunking into a maintainer-approved memory-core chunking/index-identity design, and track entity/graph consolidation as separate Memory Wiki or Memory MVP/plugin-API work.

## Reproduction Assessment

Yes by source inspection. Indexing a Markdown memory file with several short headed sections under the current token/overlap chunker can place unrelated sections in one embedding chunk until the size budget flushes.

## Solution Assessment

Unclear. Heading-aware chunking is a plausible narrow slice, but the issue bundles broader entity extraction and still needs maintainer decisions on defaults, index identity/reindexing, and the Memory Wiki boundary.
