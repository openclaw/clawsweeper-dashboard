## Summary

Keep open: current main still chunks memory markdown by fixed token/character windows, not heading boundaries, and the broader entity/wiki synthesis pieces remain product-scoped work rather than a merged implementation.

## What This Changes

The issue requests heading-aware markdown chunking for memory search, with entity extraction and graph-style memory as broader follow-up scope.

## Best Possible Solution

Approve a narrow memory-core heading-aware markdown chunking policy with index-identity/reindex coverage, while keeping entity extraction and wiki synthesis as separate Memory MVP work.
