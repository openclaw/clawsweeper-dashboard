## Summary

Keep this PR open, but do not merge it as written: it turns warnings that explicitly describe conflicting state or an unmerged legacy directory into a successful migration checkpoint, which can permanently suppress the repair path.

## What This Changes

The branch filters four text-matched startup migration warnings before the checkpoint refusal so startup can record migrations as successful when only those warnings remain.

## Best Possible Solution

Classify migration results at their producers with an explicit completed-versus-blocking outcome, preserve fail-closed behavior for conflicts and unmerged directories, and add focused coverage for each checkpointable and blocking state.
