## What This Changes

Fix Workboard so a card created while a named agent scope or validated named-agent filter is active carries that agent ID, remains visible on the selected board, and does not reopen the shared agent picker after selection.

## System Context

The Control UI turns the selected page or filter agent scope into a Workboard card draft, then sends `workboard.cards.create` to the Gateway. The returned card is rendered through the active board filter, so a missing or incorrect agent ID makes a newly created card disappear from a named-agent view.

  E --> F[Selected-agent board filter]
  B --> G[Shared agent picker]
