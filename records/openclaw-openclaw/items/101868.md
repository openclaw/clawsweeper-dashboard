- `maturity:stable`: The operator-visible gateway session recovery and diagnostics surface maps to the M4 Stable gateway-runtime maturity area.

## Summary

Keep open: current main and v2026.6.11 still end exhausted embedded-agent overflow recovery with a transient blocked result and manual `/reset` or `/new` guidance, while auto-rotation or a durable blocked marker remains a core recovery-policy decision.

## What This Changes

The issue requests automatic one-time embedded-agent session rotation, or at least a persisted blocked-overflow marker, when context-overflow recovery reaches the give_up branch.

## Best Possible Solution

Define one explicit overflow give_up recovery contract: persist an operator-visible blocked-overflow state first, and add guarded one-shot rotation only if replay safety, loop caps, and docs/tests are settled.
