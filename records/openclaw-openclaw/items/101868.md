## Summary

Keep open: current main and the latest release still end exhausted embedded-agent overflow recovery with a blocked result and manual `/reset` or `/new` guidance, and the requested durable marker or auto-rotation remains a core session-recovery product decision.

## What This Changes

The issue requests either a one-shot automatic session rotation/replay or a durable overflow-blocked marker when embedded-agent context-overflow recovery reaches the give-up branch.

## Best Possible Solution

Adopt one maintainer-approved recovery contract: persist an explicit overflow-blocked state with a visible recovery surface first, and add guarded one-shot rotation only if replay safety, loop caps, and docs are settled.
