## Summary

Keep open: current main and v2026.6.11 still exhaust embedded-agent overflow recovery into a blocked result with manual `/reset` or `/new` guidance; the requested auto-rotation or durable overflow-blocked marker needs an explicit core session-recovery product decision.

## What This Changes

The issue requests automatic one-shot session rotation, or at least a durable marker, when embedded-agent context-overflow recovery reaches the give-up branch.

## Best Possible Solution

Adopt one maintainer-approved recovery policy: persist an explicit overflow-blocked state with an operator-visible recovery surface first, and add guarded one-shot rotation only if replay safety, loop caps, and docs are settled.
