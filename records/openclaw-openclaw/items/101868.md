- `maturity:stable`: The affected embedded-agent long-context runtime path maps to the M4 Stable Gateway runtime surface.

## Summary

Keep open: current main and v2026.6.11 still end exhausted embedded-agent overflow recovery with a transient blocked result and manual `/reset` or `/new` guidance, and the requested durable marker or auto-rotation changes core session recovery policy.

## What This Changes

Request automatic recovery or a durable blocked-overflow marker when embedded-agent context-overflow recovery gives up, instead of leaving sessions recoverable only through manual reset/new.

## Best Possible Solution

Choose one maintainer-approved recovery policy: persist an explicit overflow-blocked state with visible operator recovery first, and add guarded one-shot rotation only if replay safety, loop caps, and docs are settled.

Unclear until maintainers choose the recovery policy. A persisted blocked marker is the least disruptive path; automatic rotation is plausible but must prove replay safety and preserve bounded recovery semantics.
