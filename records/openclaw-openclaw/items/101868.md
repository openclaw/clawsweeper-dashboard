## Label Justifications

- `P1`: A long-running embedded-agent session can remain blocked after context overflow until a human notices and resets or starts a new session.
- `impact:session-state`: The issue concerns session continuity, compaction state, transient liveness metadata, and whether recovery state is durable.

## Summary

Keep open: current main and v2026.6.11 still end exhausted embedded-agent overflow recovery with a blocked result and manual `/reset` or `/new` guidance, and the requested recovery path changes core session/replay semantics that need maintainer direction.

## What This Changes

The issue requests automatic one-time session rotation or a durable blocked-overflow marker when embedded-agent context-overflow recovery gives up.

## Best Possible Solution

Adopt one maintainer-approved recovery policy: persist an explicit overflow-blocked state with an operator-visible recovery affordance first, and add guarded one-shot rotation only if replay safety, loop caps, and docs are settled.

Options:

- **Persist blocked state first (recommended):** Add a durable overflow-blocked marker plus operator-visible recovery affordance without silently replaying a turn on a new session.
- **Guarded one-shot rotation:** Rotate and replay once only after compaction and truncation are exhausted, with replay-safety gates and a per-session loop cap.
- **Keep manual recovery:** Keep the documented `/reset` or `/new` contract and improve only visibility, diagnostics, or docs.

## Reproduction Assessment

Yes, at source level: current main still returns a blocked context-overflow result with `/reset` or `/new` guidance after overflow recovery is exhausted, and focused tests assert that behavior. I did not run a live oversized-session reproduction in this read-only review.

## Solution Assessment

Unclear until maintainers choose the recovery policy. A persisted blocked marker is the least disruptive path; automatic rotation is plausible but must prove replay safety and avoid competing with model fallback or compaction-timeout repairs.
