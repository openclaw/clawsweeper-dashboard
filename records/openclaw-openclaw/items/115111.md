## What This Changes

Centralizes the structured SQLite session identity passed from Memory Core’s transcript corpus into dreaming, startup catch-up, and QMD export, and updates fixtures that still modeled retired file-path identity.

## System Context

Memory Core turns stored conversation transcripts into searchable and dreamable memory. Its consumers receive corpus entries from the canonical SQLite session store, resolve each transcript with its agent/session/store identity, then feed the resulting text into dreaming, synchronization, and QMD export.
