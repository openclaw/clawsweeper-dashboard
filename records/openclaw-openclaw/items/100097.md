## What This Changes

Capture GitHub Copilot's server-reported per-request AI Credits from completion responses and expose them distinctly from estimated session cost.

## Best Possible Solution

Define a provider-owned parser for the server-reported AIC value, then add a clearly named generic per-turn billing field only if maintainers approve its persistence, exports, retention, and distinction from estimated USD.
