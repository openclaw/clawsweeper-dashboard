## Summary

Keep open: current `main` and the latest release still only expose Copilot quota-window usage and token-derived estimated costs, but implementing billed Copilot AIC needs maintainer direction on the upstream billing contract and the permanent usage/status schema.

## What This Changes

The issue requests capturing GitHub Copilot response-body `copilot_usage.total_nano_aiu` billed AI Credits and surfacing it through OpenClaw usage reporting instead of relying only on token-derived estimates.

## Best Possible Solution

Confirm the GitHub Copilot response contract, then add a provider-owned actual-AIC usage field through the existing usage/session/status pipeline while preserving token counts and estimated USD as separate fallback context.

## Reproduction Assessment

Not applicable as a bug reproduction: this asks for a new billing signal, not a failing existing command. Source inspection confirms the current gap: current `main` and `v2026.6.11` expose quota windows and estimated costs, not actual per-request Copilot AIC.

## Solution Assessment

Unclear until maintainers approve the billing contract and schema. The provider-owned hook is the right boundary, but the best implementation depends on the permanent usage/status field shape and whether transcript/session persistence should store actual AIC, USD estimates, or both.
