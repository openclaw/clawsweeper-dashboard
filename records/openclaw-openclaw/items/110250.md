## What This Changes

This PR lets OpenClaw consume a DSSE-signed sharded hosted plugin catalog, verify each origin-constrained shard, and persist verified root and shard bytes for offline replay.

## System Context

OpenClaw's hosted plugin catalog loader fetches external plugin metadata and decides whether entries have trusted install authority. This PR extends that loader from one signed catalog document to a signed root that describes integrity-checked shards, then stores the accepted representation for later offline use.
