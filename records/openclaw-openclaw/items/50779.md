## Summary

Keep open. Current main and latest release still emit direct tool-result image blocks but the Control UI grouped renderer only extracts source-wrapped or URL image blocks, and the focused fix PRs are closed unmerged.

## What This Changes

The issue asks for Control UI chat to render images returned by tools inline or as an obvious preview instead of showing only text like `Read image file [image/png]`.

## Best Possible Solution

Add the narrow direct `{ type: "image", data, mimeType }` branch to the existing Control UI `extractImages()` path with focused grouped-render regression coverage, while leaving broader media previews to the separate inline-media issue.

## Reproduction Assessment

Yes, source-level: direct image tool results are emitted by `imageResult()` and the read tool but ignored by the current Control UI grouped renderer's `extractImages()` path. I did not run a live browser/Gateway reproduction in this read-only review.

## Solution Assessment

Yes, the best narrow fix is to preserve the existing renderer contract and add direct `{ data, mimeType }` handling in the Control UI image extraction path, not broaden into the full inline media feature request.
