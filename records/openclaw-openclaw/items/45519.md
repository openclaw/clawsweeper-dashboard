## Summary

Keep open. Current main has side-reader recovery for truncated assistant history plus tool, JSON, and duplicate-message disclosure paths, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the earlier progressive-disclosure PR was closed unmerged.

## What This Changes

Request to add collapsible/foldable assistant messages in Control UI chat so long responses can be expanded and collapsed inline.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with accessible toggles, latest-message behavior, and focused UI coverage.
