## What This Changes

Request collapsible or foldable assistant messages in Control UI chat so long responses take less vertical space.

## Best Possible Solution

Have maintainers choose the Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with focused UI tests and docs if the behavior becomes user-visible contract.
