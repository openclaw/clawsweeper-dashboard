## Summary

Keep open. Current main still lacks inline collapsible/foldable assistant-message behavior for ordinary long Markdown; related work only added side-reader recovery for truncated history, and the earlier progressive-disclosure PR was closed unmerged.

## What This Changes

Request adding collapsible/foldable Control UI chat assistant messages for long responses, with optional bulk expand/collapse controls.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement inline long-message collapse in the current chat renderer with accessible toggles, newest-message behavior, focused UI tests, and docs only if this becomes supported user-facing behavior.
