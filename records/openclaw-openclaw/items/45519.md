## Summary

Keep open. Current main has side-reader recovery for truncated assistant history plus JSON/tool/duplicate disclosure paths, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the earlier progressive-disclosure PR was closed unmerged.

## What This Changes

The issue requests inline collapse and expand controls for long assistant responses in Control UI chat.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with accessible per-message toggles, latest-message behavior, and focused UI coverage.
