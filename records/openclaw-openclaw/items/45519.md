## Summary

Keep open. Current main and the latest release have side-reader recovery for truncated assistant history plus JSON/tool/duplicate-message disclosures, but ordinary long assistant Markdown still renders inline without the requested Show more/Show less collapse; this remains a product-direction decision for Control UI UX.

## What This Changes

The issue requests collapsible or foldable assistant messages in the Control UI chat to reduce scrolling through long conversations.

## Best Possible Solution

Have maintainers choose the Control UI long-message disclosure policy, then implement inline collapse in the chat message renderer while preserving the existing side-reader recovery for truncated history.
