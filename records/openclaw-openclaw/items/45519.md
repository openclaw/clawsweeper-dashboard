## Summary

Keep open. Current main has side-reader recovery for truncated assistant history, JSON disclosure, tool disclosure, and duplicate-message collapse, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse.

## What This Changes

Request to add collapsible or foldable assistant messages in Control UI chat to reduce scrolling in long conversations.

## Best Possible Solution

Define one Control UI disclosure policy, then implement bounded inline collapse for long assistant Markdown with accessible toggles, coherent newest-message behavior, and focused UI tests.
