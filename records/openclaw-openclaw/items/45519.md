## Summary

Keep open. Current main has side-reader recovery for truncated assistant history plus JSON/tool/duplicate-message disclosures, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the closest progressive-disclosure PR was closed unmerged.

## What This Changes

The issue requests collapsible or foldable assistant messages in Control UI chat for long responses.

## Best Possible Solution

Have maintainers choose the Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with focused UI tests and docs if it becomes a supported behavior.

## Reproduction Assessment

Not applicable: this is a feature request for a new Control UI interaction pattern, not a broken existing behavior report. Source inspection confirms current main lacks inline long-message collapse for ordinary assistant Markdown.

## Solution Assessment

Unclear: inline collapse is a plausible solution, but the best thresholds, default-expanded behavior, and global controls need maintainer UX direction. The existing side reader solves truncated-history recovery but does not replace the requested inline collapse.
