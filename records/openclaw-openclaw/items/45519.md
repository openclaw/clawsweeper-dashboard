## Summary

Keep open. Current main and the latest release still render ordinary assistant Markdown directly in the Control UI chat bubble; the merged adjacent work only upgrades truncated history through the side reader, and tool/duplicate collapse does not satisfy inline show-more/show-less behavior.

## What This Changes

Request to add inline collapsible/foldable assistant responses in Control UI chat, with show-more/show-less and optional collapse/expand-all controls for long messages.

## Best Possible Solution

Keep the issue open for a Control UI product decision, then implement a narrow assistant-message disclosure pattern in the chat renderer with CSS/i18n/test coverage that coexists with side-reader and tool collapse behavior.
