## Summary

Keep open. Current main has side-reader recovery for truncated history, JSON disclosure, tool-row disclosure, and duplicate-message collapsing, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the direct progressive-disclosure PR was closed unmerged.

## What This Changes

The issue requests collapsible or foldable assistant messages in Control UI chat so long conversations are easier to scan.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement accessible inline collapse for older long assistant messages while keeping the side reader as the full-content path for truncated history.
