## Summary

Keep open. Current main and the latest release have adjacent side-reader, JSON, tool-card, duplicate-message, and control-row disclosure behavior, but they still do not implement inline show-more/show-less collapse for normal long assistant chat bubbles; the directly matching progressive-disclosure PR closed unmerged.

## What This Changes

The issue requests collapsible or foldable assistant messages in the Control UI chat to reduce scrolling in long conversations.

## Best Possible Solution

Have maintainers choose the Control UI disclosure policy, then implement inline long-message collapse in the chat renderer using the existing disclosure primitives with focused UI tests.
