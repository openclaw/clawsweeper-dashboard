## Summary

Keep open. Current main has side-reader recovery for truncated assistant history plus tool, JSON, and duplicate-message disclosure paths, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the earlier progressive-disclosure PR at https://github.com/openclaw/openclaw/pull/51546 was closed unmerged.

## What This Changes

The issue requests a Control UI chat affordance to collapse or expand long assistant responses so long conversations remain easier to scan.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with accessible toggles, newest-message behavior, focused UI tests, and docs only if it becomes a supported user-facing behavior.
