## Summary

Keep open. Current main has side-reader recovery for truncated assistant history, JSON and tool disclosure paths, and duplicate-message collapsing, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the earlier progressive-disclosure PR at https://github.com/openclaw/openclaw/pull/51546 was closed unmerged.

## What This Changes

Request inline collapsible assistant responses in Control UI chat for long messages, with optional collapse-all and expand-all controls.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with accessible toggles, clear newest-message behavior, and focused UI tests.
