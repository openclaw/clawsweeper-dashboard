## Summary

Keep open. Current main still lacks inline show-more/show-less collapse for ordinary long assistant Markdown in Control UI chat; the merged full-message reader work only solves truncated-history side-reader recovery.

## What This Changes

The issue requests collapsible or foldable assistant messages in Control UI chat so long responses do not dominate the conversation view.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement accessible inline collapse for long assistant Markdown while preserving the existing side-reader recovery path for truncated history.
