## Summary

Keep open. Current main has side-reader recovery for already-truncated assistant history, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse, and the only progressive-disclosure PR was closed unmerged.

## What This Changes

The issue requests collapsible or foldable assistant messages in Control UI chat so long responses take less vertical space.

## Best Possible Solution

Define one Control UI disclosure policy, then implement accessible inline long-message collapse in the chat renderer while keeping truncated-history side-reader recovery intact.
