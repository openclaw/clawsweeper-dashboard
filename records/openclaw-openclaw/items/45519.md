## Summary

Keep open. Current main has adjacent disclosure behavior for JSON, tool messages, duplicate text, and truncated-history side-reader recovery, but it still does not implement inline show-more/show-less collapsing for ordinary long assistant chat bubbles.

## What This Changes

The issue requests collapsible or foldable assistant messages in the Control UI chat to reduce scrolling in long conversations.

## Best Possible Solution

Have maintainers define the Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with focused UI tests and docs if the behavior becomes a user-visible contract.

## Reproduction Assessment

Not applicable: this is a feature request for a new Control UI interaction, not a broken existing behavior. Source inspection confirms current main lacks the requested inline collapse behavior.

## Solution Assessment
