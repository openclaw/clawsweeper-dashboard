## Summary

Keep open. Current main still lacks inline show-more/show-less collapse for ordinary long assistant Markdown in Control UI chat; the related merged work solves truncated-history side-reader recovery, which is adjacent but not the requested default chat-bubble disclosure behavior.

## What This Changes

Request add collapsible or foldable assistant responses in Control UI chat so long messages can be collapsed and expanded inline.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement accessible inline collapse for long assistant Markdown while preserving the existing side-reader recovery path for truncated history.
