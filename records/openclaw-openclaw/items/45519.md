## Summary

Keep open. Current main has side-reader recovery for truncated assistant history plus tool, JSON, and duplicate-message disclosure paths, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse.

## What This Changes

The issue requests collapsible/foldable assistant responses in Control UI chat, with long messages collapsed by default and optional per-message or global expand controls.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement accessible inline long-message collapse that coordinates with the existing side reader, tool, JSON, and duplicate-message disclosure patterns.
