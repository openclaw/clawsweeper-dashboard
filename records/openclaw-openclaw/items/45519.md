## Summary

Keep open. Current main and the latest release have adjacent side-reader recovery for truncated assistant history, JSON/tool disclosures, and duplicate-message collapse, but normal long assistant markdown still renders inline without a show-more/show-less threshold; the directly matching progressive-disclosure PR closed unmerged.

## What This Changes

The issue requests inline collapsible/foldable assistant messages in Control UI chat to reduce scrolling through long responses.

## Best Possible Solution

Have maintainers choose the Control UI disclosure policy, then implement inline long-message collapse in the chat message renderer with focused UI tests and docs if it becomes a supported user-visible behavior.

## Reproduction Assessment

Not applicable: this is a feature request for a new Control UI interaction pattern, not a broken existing behavior. Source inspection confirms current main lacks the requested inline collapse behavior.

## Solution Assessment

Unclear: inline collapse is plausible, but the best threshold, default-expanded behavior, and global controls need maintainer UX direction before implementation.
