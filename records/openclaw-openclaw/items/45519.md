## Summary

Keep open. Current main has a side reader for truncated assistant history and narrow JSON/tool/duplicate disclosures, but ordinary long assistant markdown still renders inline without a show-more/show-less collapse path; the directly matching progressive-disclosure PR is closed unmerged.

## What This Changes

Request collapsible or foldable long assistant responses in the Control UI chat, with per-message toggles and optional global expand/collapse controls.

## Best Possible Solution

Have maintainers choose the Control UI disclosure policy, then implement inline long-message collapse in the chat renderer while keeping the side reader as the full-content recovery path for truncated history.

## Reproduction Assessment

Not applicable: this is a feature request for a new Control UI interaction pattern, not a broken existing behavior. Source inspection confirms current main lacks the requested inline collapse behavior.

## Solution Assessment

Unclear: inline collapse is plausible, but maintainers need to choose thresholds, newest-message behavior, global controls, and how it should compose with existing disclosure surfaces.
