## Summary

Keep open. Current main and the latest release have side-reader full-message recovery plus JSON, tool, and duplicate-message disclosures, but they still do not provide inline Show more/Show less collapsing for normal long assistant chat bubbles; the directly matching progressive-disclosure PR closed unmerged.

## What This Changes

The issue requests collapsible or foldable assistant messages in Control UI chat so long responses take less vertical space.

## Best Possible Solution

Have maintainers choose the Control UI disclosure policy, then implement inline long-message collapse in the chat renderer with focused UI tests while preserving the existing side-reader full-message recovery path.

## Reproduction Assessment

Not applicable as a bug reproduction: this is a feature request for a new Control UI interaction pattern, not broken existing documented behavior. Source inspection confirms current main lacks the requested inline collapse behavior.

## Solution Assessment

Unclear as proposed: inline collapse is plausible, but the best thresholds, default-expanded behavior, and global controls need maintainer UX direction before implementation.
