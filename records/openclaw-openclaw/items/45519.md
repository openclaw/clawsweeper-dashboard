## Summary

Keep open. Current main and the latest release still have the side-reader/full-message recovery path and duplicate/tool/JSON disclosures, but not the requested inline show-more collapse for ordinary long assistant chat bubbles.

## What This Changes

The issue requests collapsible or foldable assistant messages in the Control UI chat so long responses take less vertical space.

## Best Possible Solution

Ship a Control UI-owned progressive-disclosure design that preserves the side-reader path, avoids expensive long-markdown work before collapse, localizes new copy, and proves long markdown/code-block behavior with focused UI tests plus browser proof.

## Reproduction Assessment

Not applicable as a bug reproduction. Source inspection gives a high-confidence current behavior check: long assistant markdown still renders inline without a show-more threshold or per-message collapse state.

## Solution Assessment

Yes, keeping this open is the best current path. The existing side reader and duplicate/tool/JSON disclosures are complementary, but they do not solve the main chat scrolling problem this request targets.
