## Summary

Keep open. Current main has truncated-history side-reader recovery and several adjacent disclosure paths, but ordinary long assistant Markdown still renders inline without the requested show-more/show-less collapse; the earlier progressive-disclosure PR was closed unmerged.

## What This Changes

Request to add collapsible or foldable assistant response messages in Control UI chat, with per-message show-more/show-less controls and optional bulk expand/collapse controls.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement accessible inline long-message collapse in the chat renderer with focused UI coverage and coherent interaction with the existing side reader.
