## Summary

Keep open. Current main and the latest release still lack inline show-more/show-less collapse for ordinary long assistant Markdown in Control UI chat; the merged related work covers truncated-history side-reader recovery, not the requested default chat-bubble disclosure behavior.

## What This Changes

The issue requests collapsible assistant messages in Control UI chat for long responses, with per-message show-more toggles and optional global expand/collapse controls.

## Best Possible Solution

Choose one Control UI disclosure policy, then implement accessible inline collapse for long assistant Markdown that preserves the side-reader recovery path and keeps the active response readable.
