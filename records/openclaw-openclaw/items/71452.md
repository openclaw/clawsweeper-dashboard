## Summary

Keep open: current main includes https://github.com/openclaw/openclaw/pull/99089's display-limit fix, but source and the latest member comment show end-to-end cursor/page iteration is still missing, especially for Discord search and Teams list surfaces.

## What This Changes

Support paginated message/chat listing by honoring requested limits and exposing cursors instead of limiting list chat/list messages output to the first page or 25 rows.

## Best Possible Solution

Define a shared message pagination contract that preserves the merged display-limit fix, exposes provider cursors/page metadata consistently, and implements focused provider follow-through for Discord search and Teams list/list-pins where supported.
