## What This Changes

Adds a default 15-second abort signal to the Control UI runtime-configuration fetch and tests signal propagation plus stalled-request fallback.

## Best Possible Solution

Adopt an owner-approved finite bootstrap deadline that preserves caller cancellation, defines whether the budget is per candidate or operation-wide, and explicitly accepts the fallback behavior for slow reverse-proxy and authenticated deployments.
