## Summary

The report identifies a real, deterministic authorization bug present in both v2026.6.11 and current main: ordinary Gateway-backed agent calls use non-admin CLI identity, while an unrelated model override selects the admin identity required for owner-only tools. The issue has the protected `maintainer` label, and the repair must preserve the deliberate least-privilege boundary for configured remote and explicit non-owner callers.

## What This Changes

Restore owner-only tools for configured local-Gateway `openclaw agent` turns without requiring a redundant model override, while preserving least privilege for remote calls.

## Best Possible Solution

Introduce one verified trusted-local Gateway fact, use it to grant owner identity only for configured local calls, preserve remote and explicit non-owner filtering, and add regression coverage that compares the actual agent tool surface for local and remote paths.
