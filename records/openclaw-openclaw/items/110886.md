Overall confidence: 0.91

Full review comments:

- **[P1] Replace rewind history canonically:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+SessionActions.swift:386-387`
  - body: `refreshHistoryAfterRun` is reconciliation for incremental run updates, not a destructive transcript cut: it can preserve user messages absent from fetched history. Rewind must replace the visible history canonically so the removed suffix cannot remain as stale bubbles.
  - confidence: 0.96
- **[P1] Confirm before dispatching rewind:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatView.swift:1116`
  - body: This menu action immediately mutates the session to remove the selected turn and suffix. The merged web implementation confirms the same operation, so native needs an equivalent confirmation before calling `rewindToMessage`.
  - confidence: 0.95
- **[P2] Do not offer rewind without admin authorization:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatView.swift:1110-1127`
  - body: The button is eligible solely from local message/activity state, but `sessions.rewind` requires `operator.admin`. Connections without that scope receive a guaranteed authorization failure; hide or disable it with an upgrade path when the capability is unavailable.
  - confidence: 0.91
- **[P1] Persist the rewound draft before returning on staleness:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+SessionActions.swift:382`
  - body: The gateway mutation completes before this current-session guard. If navigation wins the race, returning here discards `editorText`, leaving the rewound source session without the message text users need to edit and resend.
  - confidence: 0.94
- **[P2] Preserve the fork draft on stale navigation:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+SessionActions.swift:407-411`
  - body: When the response creates a fork but the initiating session is no longer current, the fallback refresh exposes the new session without retaining `editorText`. Store the returned draft against the created session before rejecting stale navigation.
  - confidence: 0.93
- **[P2] Serialize pending message mutations:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+SessionActions.swift:374-377`
  - body: Neither action tracks an in-flight rewind/fork request, so reopening the context menu can dispatch duplicate operations. A repeated fork can create multiple sessions and the last response can win navigation; disable both actions until the active mutation completes.
  - confidence: 0.9
