  - confidence: 0.98

  - confidence: 0.98
- **[P2] Gate rewind on available admin authorization:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatView.swift:1111-1123`
  - body: Do not advertise a usable rewind action solely from message eligibility. The gateway requires `operator.admin`, while ordinary iOS connections may lack that scope and will receive an authorization error after selection.
  - confidence: 0.94
- **[P1] Persist the rewound draft before returning stale:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+SessionActions.swift:379-380`
  - body: The server has already rewound the source session when this staleness guard returns. Store the returned `editorText` for the initiating session before returning so navigating back does not expose a rewound transcript with the recoverable user text lost from the composer.
  - confidence: 0.96
- **[P2] Preserve the fork draft on stale navigation:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+SessionActions.swift:408-414`
  - body: A late fork response has already created a session. Save its returned editor text under the created session before the stale-navigation fallback, otherwise opening the newly listed fork later drops the user message that should be ready to edit.
  - confidence: 0.95
- **[P2] Serialize pending message mutations:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatView.swift:1117-1159`
  - body: The menu stays eligible while a rewind or fork request is in flight, allowing repeated selections to dispatch concurrent mutations. Track one pending message mutation and disable both actions until it completes to prevent duplicate forks and response-order-dependent navigation.
  - confidence: 0.97
- **[P2] Refresh the session list for remote forks:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatViewModel+TransportEvents.swift:43-53`
  - body: The new event branch handles only `rewind`; a remote `fork` event falls through the existing reason guard and leaves connected native clients' session lists stale until another refresh.
  - confidence: 0.97
