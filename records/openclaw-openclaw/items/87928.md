## Summary

Keep open. Current main and the latest shipped release still miss the reported unhyphenated macOS updater job family, and same-version package updates still flow through managed-service stop/refresh behavior, so this is not implemented-on-main or stale cleanup.

## What This Changes

The issue requests a coherent macOS update lifecycle that removes lingering manual updater jobs, keeps the launchd Gateway bootstrapped and running, restarts stale node hosts, and diagnoses gateway/node version skew without a restart storm.

## Best Possible Solution

Land or sponsor a focused macOS update lifecycle fix that covers all observed updater job label families, avoids or explicitly dedupes same-version package refreshes, restarts stale node hosts coherently, and verifies launchd Gateway health before update completion.

Options:

- **No-op same-version package updates (recommended):** Exit before package refresh and managed service restart when the installed package already matches the target version and no channel or config change requires mutation.
- **Refresh with dedupe and recovery:** Keep same-version package refresh behavior but add per-install update locking, stale job cleanup, node-host restart, and launchd health verification before success.
- **Docs-only for now:** Document detection and manual recovery while accepting continued manual intervention for some macOS update loops.
