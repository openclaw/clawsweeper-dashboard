## Summary

Keep open. Current main and v2026.6.11 still only partially cover the report: local node-host mismatch now exits for supervisor restart, but stale updater detection misses the live `ai.openclaw.manualupdate.*` job family and same-version package refreshes can still reach restart work if a launchd job keeps relaunching.

## What This Changes

The issue reports that macOS self-update can leave repeated launchd updater jobs, stale node host code, and Gateway restart loops after an OpenClaw version upgrade.

## Best Possible Solution

Make macOS update handoff single-owner and self-cleaning: recognize every shipped updater label family, dedupe or reject concurrent updater jobs before service stop/restart, verify Gateway and local node host recovery after package refresh, and add launchd-focused regression plus live macOS proof.
