## Summary

Current main has partial macOS launchd/update recovery hardening and local node version-skew handling, but it still misses the updater job labels shown in the live 2026.6.1 report and leaves same-version/no-op restart behavior as a maintainer decision, so #87928 remains necessary.

## What This Changes

Issue #87928 requests a reliable macOS update path that prevents relaunching manual updater jobs, avoids no-op Gateway restart storms, recovers launchd registration, and resolves stale node-host version skew after npm updates.

## Best Possible Solution

Keep #87928 open until a narrow macOS launchd update fix covers the observed updater label families, defines no-op restart behavior, and proves recovery on a real npm-global LaunchAgent install.
