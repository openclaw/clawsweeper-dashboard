## Summary

Keep open: the linked bug is valid, but this PR should not merge yet because customized Slack messages cannot reliably use the draft lifecycle’s deletion-based fallback cleanup, and the branch lacks exact-head live proof for those fallback cases.

## What This Changes

Removes the Slack custom-identity exclusion from portable draft preview selection and updates regression expectations so the resolved identity is passed into the draft stream.

## Best Possible Solution

Support custom-identity previews only with a lifecycle that never depends on deleting customized Slack messages: finalize or neutralize the preview in place across fallback paths, or retain the current guard, then prove text, media/error fallback, and final-edit failure in a real Slack workspace.
