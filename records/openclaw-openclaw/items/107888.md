## Summary

Keep open, but the patch is not merge-ready: the happy path is proven, yet enabling custom-authored previews exposes a Slack cleanup limitation that can leave stale or duplicate messages when final editing fails.

## What This Changes

Removes the custom-identity exclusion from Slack portable draft-preview initialization and updates regression expectations for identity-aware draft creation and in-place finalization.

## Best Possible Solution

Keep portable drafts with custom identity, but finalize or abandon them without relying on `chat.delete`; cover edit failure and non-editable final payloads while preserving exactly one visible final message.
