## Summary

Keep open: the core fix is valid, but enabling customized draft messages exposes non-finalizable replies to a cleanup path that Slack does not support for customized authorship.

## What This Changes

Removes Slack’s custom-identity exclusion from portable draft initialization and updates regression expectations for identity-aware preview creation and in-place finalization.

## Best Possible Solution

Use a preview/final strategy that preserves live progress and the configured final identity while guaranteeing cleanup for non-finalizable payloads, such as a disposable default-identity preview followed by normal custom-identity final delivery, unless live Slack proof establishes another safe cleanup path.
