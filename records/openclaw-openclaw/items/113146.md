## Summary

This remains a useful, bounded fix: it repairs the projection at the copy-on-write owner rather than papering over selected gateway readers. The current exact-head checks are still completing, so it should stay open for normal maintainer merge review rather than cleanup closure.

## What This Changes

The PR restores the internal non-enumerable `agents.list` projection after live or captured runtime overrides copy a validated keyed-agent configuration.

## System Context

OpenClaw validates authored keyed agent entries into a runtime configuration snapshot, then applies process-local runtime overrides before gateway, session, and workspace code consume it. This PR keeps the legacy non-serialized list projection consistent with the keyed source after that override step.
