## Summary

Keep open: current main and v2026.6.11 still lack direct Windows Scheduled Task probing, but this PR still probes only the fixed default task name while the restart handoff supports profile/custom task names, and external real Windows behavior proof is still missing.

## What This Changes

## Best Possible Solution
