## Summary

Keep open: this is still the linked candidate fix for the Windows restart issue, but the prior blocker remains because the fallback probes only the default Scheduled Task while the handoff can run profile-specific or custom task names; real Windows behavior proof is also still missing.

## What This Changes

## Best Possible Solution
