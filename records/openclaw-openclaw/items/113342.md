## What This Changes

The PR makes the shared exec-approval test fixture track its own temporary directories and delete them after each test, preventing repeated test runs from leaving `/tmp/openclaw-exec-approvals-*` roots.

## System Context

Exec-approval tests create real temporary executable directories to exercise command-resolution and approval behavior. The shared test helper supplies those paths to many suites, and the proposed cleanup runs after each test to remove only directories that helper created.
