## Summary

Keep open. The issue remains necessary because current main and the latest shipped release only cover slices of the silent final-delivery problem: empty identity accounting was fixed on main, but the broader cross-channel contract for visible sanitized final fallback delivery is still unresolved.

## What This Changes

Define and enforce durable, observable delivery semantics for sanitized final fallback text across text-capable channels.

## Best Possible Solution

Keep this as the canonical maintainer-owned delivery contract, land focused channel slices with live proof, and add shared SDK/core conformance and diagnostics coverage for all durable text-capable channels.
