## What This Changes

This PR adds repeatable `--config-layer <id=path>` inputs so a Gateway can compose ordered JSON5 configurations into one immutable startup snapshot.

## System Context

Gateway startup normally reads one canonical OpenClaw configuration, validates it with plugins, and exposes it to server methods. This change feeds several ordered config documents through the existing parsing and validation pipeline, then gives the Gateway a read-only snapshot and rejects config-changing operations for that server lifetime.
