## Summary

This PR remains useful, but it is not merge-ready: the opt-in TUI preservation mode still has source-backed lifecycle and history-budget defects that can leave misleading partial assistant output visible or evict unrelated conversation rows during long streams.

## What This Changes

The branch adds an opt-in `openclaw tui --preserve-intermediate` flag, threads it through TUI options into `ChatLog`, preserves assistant streaming snapshots as separate entries, adds focused tests, and adds a CLI docs example.

## Best Possible Solution

Adopt the feature only after rebasing, tracking preserved chunks per run, dropping all chunks on suppressed finals, avoiding duplicate unchanged finals, bounding retention, and updating the option references with focused tests.

## Reproduction Assessment
