## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Drop all preserved chunks for suppressed finals:** `src/tui/components/chat-log.ts:141-143`
  - body: With `preserveIntermediate`, every streamed update becomes a separate component, but `streamingRuns` only points at the latest one. Existing final/no-output paths call `dropAssistant()` to suppress visible assistant output; this implementation removes only the latest chunk and intentionally leaves earlier chunks visible as phantom replies. Track the preserved components per run and remove the whole run when final output is absent or suppressed.
  - confidence: 0.91
- **[P3] Avoid duplicating the final preserved chunk:** `src/tui/components/chat-log.ts:115-118`
  - body: `finalizeAssistant()` always appends a new component in preserve mode. When the final text matches the most recent streamed update, the TUI renders the same assistant content twice and consumes the fixed chat-log budget faster; reuse the latest preserved component or skip the append when unchanged.
  - confidence: 0.84
- **[P3] Document the new flag in the options table:** `docs/cli/tui.md:28-29`
  - body: The PR adds `--preserve-intermediate` as an example, but the CLI reference has an options table that enumerates supported flags. Add the new flag there too so docs match the command help surface.
  - confidence: 0.8
