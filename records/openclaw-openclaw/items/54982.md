  - body: With preservation enabled, every displayed delta becomes its own component, but `streamingRuns` only remembers the newest one.   - confidence: 0.84

  - body: Every changed display text from the stream assembler becomes a full chat-log component under this flag. A verbose response can spend the shared component cap on one run and evict earlier conversation rows, so preserve mode needs a per-run cap or compaction policy.
