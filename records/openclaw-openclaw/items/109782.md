## Summary

Keep this PR open, but do not merge it as written. Isolating Codex credentials is the right fix direction, and the linked live reproduction supports it, but the proposed path places authentication and session state inside the Git worktree where a coding worker can accidentally stage or commit it.

## What This Changes

## Best Possible Solution

Keep a separately authorized, mode-700 Codex home outside every Git checkout, use that external path in both launch forms, and explicitly warn that Codex credentials and state must never be staged or committed.
