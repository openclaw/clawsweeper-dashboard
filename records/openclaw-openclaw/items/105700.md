## Summary

Keep open and route to private security handling: current main deliberately evicts older registered values, existing tests confirm that eviction removes exact-value masking, and no merged fix covers active long-lived credentials under transient registry churn.

## What This Changes

Prevent active long-lived credentials from being evicted from the bounded exact-value log-redaction registry by transient secret registrations.

## Best Possible Solution

Privately validate realistic Gateway churn, then implement bounded durable-versus-transient lifetime semantics so active credentials remain masked without retaining every historical plaintext secret.
