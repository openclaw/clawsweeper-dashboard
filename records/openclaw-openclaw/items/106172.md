## Summary

The experiment is useful, but current main already provides typed plugin hooks for observing, rewriting, gating, or cancelling agent replies and outbound messages; OpenClaw’s vision routes optional policy middleware to external plugins rather than a universal core subsystem.

## What This Changes

Add a configurable AI-based guardian that checks generated responses for factuality, security concerns, and noise before publication.

## Best Possible Solution

Publish this as an external native code plugin with a manifest, compiled entrypoint, schema-backed provider configuration and secrets, explicit conversation-access permissions, documented fail-open or fail-closed behavior, install/update instructions, example usage, and smoke evidence measuring accuracy, false positives, latency, cost, and verifier outages; open a narrow core issue only if the prototype proves a specific missing typed hook, and ClawSweeper should not create or publish the package for the contributor.
