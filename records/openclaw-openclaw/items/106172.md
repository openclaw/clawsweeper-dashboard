## Risks / Open Questions

- A guardian model cannot establish factual truth by itself and may reproduce the same hallucinations or suppress correct but unusual responses; results should be advisory or bounded revision requests rather than a security guarantee.
- Reviewing complete outputs may disclose sensitive conversation content to another model or service, so a plugin must require explicit permissions, document data handling, and avoid silently exporting transcripts.
- An unconditional second-model pass can add latency, cost, and recursive failure modes; the plugin should enforce bounded retries, clear timeouts, and fail-safe behavior.
