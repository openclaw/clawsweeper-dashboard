## Label Justifications

- `P1`: The issue affects real CLI-backed agent turns by terminating long silent work mid-run and surfacing failed model/session workflows.
- `impact:session-state`: The watchdog kill can end an in-flight CLI session before the agent completes or preserves the turn state.

## Summary

Keep open: current main and v2026.6.11 still preserve the 180-second no-output watchdog ceiling for ordinary inherited resumed CLI user runs, while https://github.com/openclaw/openclaw/pull/90912 only fixed configured or explicit timeout intent and https://github.com/openclaw/openclaw/pull/79997 remains unmerged and review-blocked.

## What This Changes

The issue asks OpenClaw to raise, remove, or make configurable the hard 180-second CLI no-output watchdog cap for long-running CLI-backed requests.

## Best Possible Solution

Keep this issue as the canonical CLI no-output watchdog policy tracker until maintainers land a narrow, proof-backed change through the existing watchdog default/config surface, or explicitly approve the broader direction in https://github.com/openclaw/openclaw/pull/79997.
