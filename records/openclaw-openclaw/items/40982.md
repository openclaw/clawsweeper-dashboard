## Summary

Keep open: current main still caps ordinary inherited resumed CLI-backed user runs at 180 seconds, while the merged timeout work only lifts configured or explicit timeout paths and the open candidate PR is still conflicting and proof-blocked.

## What This Changes

The issue asks OpenClaw to raise, remove, or make tunable the 3-minute no-output watchdog cap for long-running CLI-backed agent requests.

## Best Possible Solution

Make an explicit maintainer policy choice, then land a focused CLI watchdog change that preserves bounded failure recovery, documents the existing per-backend override path, and proves long silent CLI work respects the outer run timeout.

- **Add explicit disable/tuning mode:** Add a documented opt-in 0/null or equivalent disable mode with schema, docs, and tests for both enabled and disabled watchdog behavior.
- **Keep 180-second guard:** Leave the current safety default in place and close or redirect requests to use existing per-backend watchdog overrides.
