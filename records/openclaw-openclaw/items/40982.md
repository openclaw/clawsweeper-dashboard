## Summary

Keep open: current main and the latest release still preserve the 180-second no-output watchdog ceiling for ordinary inherited resumed CLI user runs, while the open candidate PR is broader and still needs maintainer policy review.

## What This Changes

The issue asks OpenClaw to raise, remove, or make configurable the 3-minute no-output watchdog cap for resumed CLI requests so long silent agent work can complete.

## Best Possible Solution

Keep this as the canonical CLI no-output watchdog policy issue until maintainers land a narrow, proof-backed change through the existing watchdog default/config surface, with explicit approval for any disable semantics.
