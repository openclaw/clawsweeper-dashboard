## Summary

Keep open: current main and v2026.6.11 still keep the 180-second no-output ceiling for ordinary inherited resumed CLI-backed user runs, while merged work only fixes configured or explicit timeout intent and the remaining raise/disable behavior needs maintainer policy review.

## What This Changes

Request to raise, remove, or make configurable the CLI no-output watchdog ceiling that can terminate long silent resumed CLI-backed agent runs after 180 seconds.

## Best Possible Solution

Land a narrow maintainer-approved CLI watchdog policy change through the existing defaults/config surface, with focused resolver coverage and real long-silent CLI proof; keep TUI watchdog configuration on its separate tracker.
