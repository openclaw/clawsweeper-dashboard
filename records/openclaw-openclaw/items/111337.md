## Summary

Keep this PR open for human contract review: it has convincing Control UI proof, but the public session-discussion seam still collapses agent-qualified sessions to an unscoped key and is not integrated with plugin registration rollback/clear lifecycle.

## What This Changes

The branch introduces a public session-discussion provider registration API, two gateway methods and protocol models, native client models, and a Control UI panel that opens or embeds an external discussion for a session.

## Best Possible Solution

Define one agent-qualified session identity for the provider API, carry it through both gateway methods and the Control UI, and make provider registration participate in plugin transaction snapshot/restore/clear before publishing the new SDK and protocol contract.
