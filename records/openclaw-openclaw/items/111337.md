## Summary

Keep this PR open for maintainer review: it introduces a new public plugin SDK/gateway contract, and its process-global provider registry is not integrated with the plugin loader’s rollback and cleanup lifecycle, so failed, snapshot, or removed plugins can leave a stale provider active.

## What This Changes

The branch adds a public session-discussion plugin SDK seam, two gateway methods, and a Control UI rail for an external per-session discussion surface.

## Best Possible Solution

Make the provider registry participate in the existing plugin registration transaction and activated-runtime reset lifecycle, then accept or narrow the public SDK/gateway contract through explicit maintainer product review.
