## Summary

This PR must not merge as written: its new default-on resolver misses channel-provided runtime DM isolation, so a default Zalouser private conversation can retrieve another sender's private transcript through same-agent recall. The existing merged feature deliberately kept this setting default-off; changing that privacy default needs a runtime-scope-aware gate and feature-owner approval.

## What This Changes

The PR changes `memorySearch.rememberAcrossConversations` from default-off to default-on for installs inferred to be personal, while preserving explicit values and configured DM-isolation opt-outs.

## Best Possible Solution

Keep automatic recall default-off whenever the effective per-invocation DM isolation cannot be proved personal; pass the resolved runtime DM scope into recall eligibility, add a Zalouser regression covering two senders, and preserve explicit `true`/`false` as authoritative.
