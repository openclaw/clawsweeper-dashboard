## Summary

Keep this PR open, but do not merge yet: the proposed default can enable same-agent transcript recall when a channel supplies DM isolation dynamically rather than through `session.dmScope` or `bindings`, leaving a cross-sender privacy boundary unprotected. The branch also has CI/test evidence only, not after-fix runtime proof of the isolation behavior.

## What This Changes

The PR makes `memorySearch.rememberAcrossConversations` default on for installations inferred to be personal, while preserving explicit settings and configured DM-isolation opt-outs.

## Best Possible Solution

Make recall eligibility consume the effective runtime DM-scope contract before defaulting on, retain explicit `true` and `false` precedence, add focused coverage for a dynamically isolated channel, and publish redacted after-fix runtime evidence showing that separate senders cannot cross-recall.
