## Summary

Keep open: current main and latest release still skip enabled-only legacy non-bundled hook plugins unless they declare hook activation metadata or explicit hook policy config, and the linked runtime fix PR remains open/unmerged with security-boundary proof concerns.

## What This Changes

The issue asks OpenClaw to load explicitly enabled extension plugins from `plugins.load.paths` into the long-running Gateway daemon and warn clearly when a configured plugin is rejected.
