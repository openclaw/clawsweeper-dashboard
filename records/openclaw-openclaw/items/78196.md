## Summary

Keep open: current main and latest release still exclude enabled-only legacy external hook plugins from Gateway startup unless they declare hook activation metadata or explicit hook policy config, and the open linked PR has not landed.

## What This Changes

Fix the regression where enabled external hook plugins from `plugins.load.paths` load in CLI commands but are skipped by the long-running Gateway daemon.

## Best Possible Solution

Land or replace the linked PR with a narrow startup-planner fix that loads explicitly enabled non-bundled legacy hook plugins, preserves allowlist and ambient-load negative cases, and proves live Gateway hooks fire with useful diagnostics.
