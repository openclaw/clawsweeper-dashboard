## Summary

Keep open: current main and the latest release still gate Gateway hook startup on manifest hook activation or explicit hook policy, the reporter added a v2026.6.11 A/B confirmation, and the linked implementation PR remains open.

## What This Changes

The issue reports that enabled external plugins from `plugins.load.paths` can load in CLI commands but be silently skipped by the long-running Gateway daemon, leaving runtime hooks inactive.
