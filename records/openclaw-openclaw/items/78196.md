## Summary

Keep open: current main and the latest release still omit enabled-only external hook plugins from Gateway startup unless they declare hook activation metadata or explicit hook policy config, and the open linked fix PR has not landed.

## What This Changes

The issue asks OpenClaw to restore or loudly diagnose Gateway daemon loading for explicitly enabled external plugins that load in CLI processes but are skipped by the long-running Gateway.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/78229 with a narrow startup-planner fix that preserves deny rules and `activation.onStartup: false`, adds focused regression coverage, and includes real Gateway proof plus clear diagnostics for skipped configured plugins.
