## Summary

Keep this issue open while the linked fix PR is reviewed and either landed or closed. The report provides a concrete Docker regression path, and the open PR explicitly targets the same missing load-path discovery behavior; an open implementation candidate is not evidence that the issue is already fixed.

## What This Changes

OpenClaw should detect a provider plugin already supplied through `plugins.load.paths` before Doctor attempts to install that provider from npm.

## System Context

Gateway startup runs Doctor checks over configured plugins. Those checks decide whether a plugin is already discoverable or needs repair, then may invoke the managed plugin installer before the Gateway becomes ready.

## Best Possible Solution

Land a narrow Doctor discovery fix that recognizes a valid configured load-path plugin before managed installation, while preserving the existing repair path for missing or broken managed plugin records.
