## Summary

Keep this PR open for explicit auth-boundary review. The branch has focused regression coverage and credible fresh-state CLI proof for the reported readiness race, but it adds an automatic persistent admin-capable device credential on loopback startup and carries the protected `maintainer` label; that intent should be confirmed before merge. The release-owned changelog edit should also be removed from the PR.

## What This Changes

The PR makes a runtime-token loopback Gateway prepare the canonical same-user CLI device credential before readiness, allowing an immediate local `openclaw agent` call to authenticate without persisting the generated shared token in configuration.

## System Context

Gateway startup resolves authentication and prepares runtime state before it reports ready. Local CLI clients then connect over the Gateway WebSocket using either shared credentials or a device token stored in OpenClaw's existing pairing and device-token state.
