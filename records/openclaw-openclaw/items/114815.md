## What This Changes

The PR makes cron re-arm its 60-second pre-execution watchdog whenever any execution phase falls back into setup, and adds a matrix test for those transitions.

## System Context

Cron jobs run isolated agent work through setup and execution phases while a watchdog prevents setup stalls from consuming a job slot. Phase notifications feed the watchdog, which decides whether to preserve the normal execution timeout or re-arm the shorter setup timeout.
