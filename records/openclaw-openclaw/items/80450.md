## Summary

Keep open: current main still lacks an explicit one-full-final-owner contract for detached or migrated longwork; the existing `completionOwnerKey` path only selects the requester session, and the linked implementation PR closed unmerged after being judged too broad.

## What This Changes

Request a first-class final-delivery ownership contract for detached or migrated longwork so only one surface publishes the complete final summary while child identity and delivery obligation remain durable.

## Best Possible Solution

Keep this as the canonical design thread until maintainers choose the owner/substrate boundary, then recut narrow PRs that extend the existing subagent delivery state or task/outbox substrate with docs and live channel proof.
