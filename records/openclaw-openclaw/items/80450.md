## Summary

Keep open: current main has requester-key routing and durable delivery pieces, but it still lacks the requested explicit final-summary owner-mode or durable owner-obligation contract. The linked implementation PR closed unmerged, and the latest issue update correctly asks for maintainer API/product direction before another broad PR.

## What This Changes

Request a first-class contract for detached or migrated long-running work so exactly one surface owns the full final summary while other observers receive only pointer/status delivery.

## Best Possible Solution

Settle the final-delivery owner or durable-obligation contract first, then land small PRs that extend the existing subagent delivery/outbound substrate, document the API, and prove only the selected owner gets the full final summary.
