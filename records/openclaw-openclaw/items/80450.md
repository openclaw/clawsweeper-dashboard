## Summary

Close as implemented: current main now has explicit subagent completion ownership separate from controller/thread ownership, durable pending final-delivery state, and a single ordered direct-or-steered completion dispatch path, so the central final-summary ownership invariant is covered by smaller merged changes rather than the earlier broad PR.

The issue requests a first-class owner for detached or migrated longwork final summaries so a child completion is not accidentally published as a full final summary on multiple surfaces.
