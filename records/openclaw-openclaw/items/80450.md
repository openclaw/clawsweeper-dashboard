## Summary

Keep open: current main has partial requester/completion-owner key routing and durable delivery state, but it still lacks the explicit final-summary owner-mode contract and maintainer API decision this issue requests.

## What This Changes

Request an explicit owner contract for detached or migrated longwork so only one surface publishes the full final user-visible summary while non-owners get at most pointer/status delivery.

## Best Possible Solution

Settle the owner-mode contract first, then land a focused implementation on the existing subagent registry, delivery outbox, and route-projection paths with docs and live proof that only the selected owner receives the full final summary.
