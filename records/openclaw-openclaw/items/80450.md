## Summary

Keep open: current main has requester-key completion routing and durable pending-delivery state, but it still does not expose the requested explicit owner-mode contract that guarantees one full final summary owner across migrated longwork surfaces.

## What This Changes

The issue requests an explicit detached-longwork final-delivery ownership model so origin, work, and update surfaces cannot accidentally publish duplicate full final summaries.

## Best Possible Solution

Settle the ownership substrate and public contract first, then land a narrow implementation that preserves current default routing, records one durable final-delivery owner, and proves non-owner surfaces cannot publish a duplicate full summary.
