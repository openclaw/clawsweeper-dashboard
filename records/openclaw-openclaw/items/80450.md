## Summary

Keep open: current main has partial adjacent ownership plumbing through `completionOwnerKey` and durable subagent delivery state, but it still lacks the requested explicit final-summary owner-mode or durable final-delivery obligation contract, and the linked implementation PR closed unmerged.

## What This Changes

The issue requests a first-class final-delivery ownership contract for detached or migrated longwork so only one surface publishes the full final summary and child identity survives migration.

## Best Possible Solution

Keep this as the canonical design thread, decide whether to promote the existing `completionOwnerKey` plus delivery-state substrate into a documented owner/obligation contract, then land small PRs with live channel proof.
