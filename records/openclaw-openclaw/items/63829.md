## Summary

Keep open: current main and the latest checked release still use one global memory-wiki plugin config/vault path, while the issue reports a real multi-agent memory isolation/security gap that is only partially covered by broader trackers and no merged fix owns the memory-wiki vault-routing decision.

## What This Changes

Request per-agent memory-wiki vault configuration so agents can use isolated vault paths instead of sharing the single global plugin vault.

## Best Possible Solution

Define a maintainer-approved agent-scoped memory-wiki vault contract, align the plugin config/schema/docs with it, and include upgrade-safe tests for global default behavior plus isolated per-agent routing.
