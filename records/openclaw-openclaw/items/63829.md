## Summary

Keep open: current main and the latest checked release still resolve memory-wiki from one global plugin config and one vault path, while related issues and the closed implementation PR do not provide a merged canonical fix for the multi-agent isolation problem.

## What This Changes

The issue requests per-agent or per-context memory-wiki vault isolation so multiple agents on one gateway do not share one configured vault.

## Best Possible Solution

Define a maintainer-approved memory-wiki isolation contract covering config precedence, per-agent/per-context vault routing, no-agent-context behavior, doctor/upgrade docs, and two-agent regression coverage.
