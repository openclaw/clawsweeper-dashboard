## Summary

Keep open. The reported timeout-recovery failure remains source-reproducible in the linked review evidence, has recent production corroboration, and an open PR already targets the central repair. The remaining question is whether OpenClaw should permit a timeout-cancelled native compaction result to commit within a narrowly bounded acceptance window; that requires maintainer judgment before the linked PR can land.

## What This Changes

Fix long safeguard compactions so completed summary work survives timeout recovery and user-facing failures identify the compaction timeout setting.

## System Context

Embedded-agent compaction condenses a long session when it approaches the model context limit. It runs sequential summary chunks under a safety timeout, then commits the resulting summary back to session state so the next agent turn can continue.
