## Summary

Keep open. Current main still lets the compaction safety timeout abort a safeguard chunk run before its local partial summary can become a reusable recovery result, and the issue is explicitly paired with the open multi-pass implementation candidate. The reported stuck-session outcome therefore remains necessary to track until that candidate is reviewed and landed or a narrower replacement is chosen.

## What This Changes

Fix long safeguard compactions so timeout-bound attempts preserve usable progress or otherwise recover without repeatedly blocking the same session, while explaining timeout recovery to the user.

## System Context

Embedded agent runs compact long conversation history before a model call exceeds its context budget. Safeguard compaction summarizes sequential chunks, then overflow recovery either continues the session with the compacted transcript or returns a blocked-session failure to the user.

## Best Possible Solution

Review and land the linked multi-pass recovery work only if it preserves or safely commits the last usable summary across timeout/quality-retry exits, gives the user an actionable recovery message, and includes focused regressions for default and explicitly raised compaction timeouts.
