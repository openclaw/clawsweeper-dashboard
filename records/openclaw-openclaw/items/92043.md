## Summary

Keep open: current main and v2026.6.11 still contain the aggregate 180s compaction wrapper, timeout-shaped chunk progress discard, and default failure-copy gap, while https://github.com/openclaw/openclaw/pull/92899 is the open closing PR for the central fix.

## What This Changes

The issue asks OpenClaw to make long compactions either reuse completed chunk progress or avoid a single whole-pipeline timeout loop, and to show timeout guidance with the existing compaction timeout knob.
