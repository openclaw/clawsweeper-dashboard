## What This Changes

Fix cron announce delivery so a configured Telegram forum thread ID is forwarded to the outbound Telegram message, including failure alerts.

## System Context

Cron jobs resolve their configured delivery destination before handing a final message to durable outbound delivery. For Telegram forum chats, that destination must retain the configured thread ID so the adapter sends the message into the intended topic rather than General.
