## Reproduction Assessment

## Solution Assessment

Yes, this is the narrowest maintainable fix: `fromSetupInput` already routes gateway deep links through `DeepLinkParser.parse`, and the sibling setup-payload/raw-URL helpers already use the TLS-aware 443 default. Changing app callers instead would duplicate parser policy.
