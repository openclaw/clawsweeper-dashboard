## What This Changes

The PR changes the OpenClawKit gateway deep-link query parser so `tls=1` without `port` defaults to 443 and adds a Swift regression test.

## Best Possible Solution

Mostly yes. For the OpenClawKit/iOS parser path, changing the shared parser is the narrowest maintainable fix; for the PR’s macOS claim, the current macOS handler does not apply `.gateway` routes, so proof or scoping is still needed.
