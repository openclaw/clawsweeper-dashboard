## Label Justifications

- `P2`: Linux companion support is an important platform improvement, but Linux users can already run the Gateway and browser Control UI.
- `impact:security`: A native companion controls credentials, device identity, pairing, exec approvals, Gateway lifecycle, and local command capabilities.
- `impact:ux-friction`: Linux users lack the native tray, guided onboarding, diagnostics, and node-control experience available on macOS and Windows.

## Summary

Keep open: Windows is now delivered through the official Windows Hub, but current main still lacks a native Linux companion, and multiple Linux implementations require a maintainer architecture, ownership, and security decision.

## What This Changes

Request official Linux and Windows desktop companion applications with capabilities comparable to the macOS app.

## Best Possible Solution

Record Windows Hub as delivered, re-scope this tracker to Linux, and select one native GTK candidate only after comparative security, Gateway-contract, packaging, upgrade, and long-term ownership review.
