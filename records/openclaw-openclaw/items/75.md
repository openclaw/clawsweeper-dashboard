## Summary

Keep open. Windows is now covered by Windows Hub docs, release assets, and release promotion gates, but current main and the latest release still do not contain a native Linux companion app; the open Linux app PRs are implementation candidates rather than a merged fix.

## What This Changes

The issue requests Linux and Windows desktop companion apps with a feature set similar to the existing macOS app.

## Best Possible Solution

Keep Windows Hub as the shipped Windows path, keep this as the canonical Linux/desktop-app tracker, and have maintainers choose or narrow the Linux companion architecture before landing one reviewed implementation and splitting leftover parity gaps into focused follow-ups.
