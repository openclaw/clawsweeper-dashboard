## Summary

## What This Changes

The issue asks OpenClaw to expose or explicitly retire the private `openclaw/plugin-sdk/simple-completion-runtime` subpath after an external plugin failed to resolve it.

## Best Possible Solution

Keep `simple-completion-runtime` private and have the affected external plugin use `api.runtime.llm.complete` or request a narrowly designed public SDK contract if that injected capability is insufficient.
