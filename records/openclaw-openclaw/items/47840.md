## Summary

Keep open. Current main still has provider alias metadata, but the affected Sessions and Usage UI/API paths render, filter, export, and aggregate raw provider strings, and the direct fix PR is closed unmerged.

## What This Changes

The issue requests consistent normalized provider display in Control UI Sessions and Usage surfaces when configured provider aliases such as Z.AI aliases are present.

## Best Possible Solution

Define one provider-display and usage-aggregation contract, then reuse it across Sessions details, Usage filters, suggestions, CSV export, badges, and aggregate keys while preserving raw stored provider fields.
