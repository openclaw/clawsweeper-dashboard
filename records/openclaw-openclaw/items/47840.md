## Summary

Keep open. Current main and v2026.6.11 still expose raw provider strings in the Control UI Usage/Sessions display and aggregate paths, and the direct implementation PR is closed unmerged, so the remaining work needs a maintainer decision on the provider-alias display and grouping contract.

## What This Changes

The issue asks the Control UI to show normalized or canonical provider names instead of raw configured provider aliases across Sessions, Usage, model selection, and agent configuration views.

## Best Possible Solution

Define the provider-alias display contract, then normalize only derived Control UI Usage/Sessions display, filter, query, export, and aggregate surfaces while preserving raw stored config and session values.
