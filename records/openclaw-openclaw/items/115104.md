## Summary

Keep this PR open. It addresses the remaining case from the open regression report: a restricted, post-tool finalization can stop normally with no visible text, which current main still treats as a failed terminal result. The patch keeps failed, aborted, timed-out, tool-using, and intentional-silence finalizers on their existing paths while ensuring progress updates do not suppress the actual final reply.

## What This Changes

The branch classifies a normal, empty post-tool finalization separately from real failures, sends a truthful completion message when no summary is available, and distinguishes progress updates from completed reply delivery.

## System Context

The embedded-agent runner executes tool work, determines whether the user request already has a final reply, and can ask a harness for one capability-free finalization turn. Terminal resolution then turns that outcome into channel payloads, so users receive a final response, a safe completion notice, or the existing failure/silence result.
