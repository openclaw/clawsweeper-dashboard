## Summary

Keep open. Current main and the latest release still lack a shared source-message edit/delete/recall lifecycle or a native message-id to active-run cancellation mapping; the related Discord and Feishu PRs are useful channel slices but do not close the cross-channel product/API question.

## What This Changes

The issue requests channel message recall/delete/edit events that cancel or supersede active agent tasks and let users correct mistaken messages without waiting for the original run.

## Best Possible Solution

Define a minimal source-message lifecycle contract for channel plugins, then implement channel-specific edit/delete/recall adapters and regression proof while keeping outbound message actions separate.
