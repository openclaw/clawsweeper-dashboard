## Summary

Keep open. Current main still has run/session abort primitives and source message ids, but it does not expose a shared source-message edit/delete/recall lifecycle or a native-message-id to active-run cancellation map; the related work remains channel-specific, open, or adjacent.

## What This Changes

Request support for channel message recall/delete and edit events so source-message corrections can cancel or supersede running agent tasks.

## Best Possible Solution

Define a minimal maintainer-approved source-message lifecycle contract, then implement channel-specific edit/delete/recall adapters and tests while keeping outbound message actions separate.
