## What This Changes

The branch exports the QQBot markdown safe byte limit, merges safe-size QQBot text chunks across the outbound send paths, gates fallback retries to 4xx ApiError rejections, and adds focused outbound delivery tests.

## Best Possible Solution

QQBot should merge safe-size chunks at the send boundary, keep oversized chunks on the existing split path, and preserve the 4xx-only fallback guard for rejected merged sends.

Yes. The send-boundary merge is narrower than rewriting the chunker, covers the implicated outbound paths, and keeps the table/fence chunker protections intact while only falling back on deterministic 4xx rejections.
