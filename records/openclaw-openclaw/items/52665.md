## What This Changes

The issue requests adding APT retry options and `--fix-missing` to sandbox image Dockerfile commands so transient package mirror failures are less likely to break sandbox image builds.

## Best Possible Solution

Land a retry-only Dockerfile change through the linked PR or a replacement, preserve fail-closed package installation, and prove both base and common sandbox images build with required packages.
