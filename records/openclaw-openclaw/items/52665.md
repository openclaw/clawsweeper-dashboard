## Best Possible Solution

Land a retry-only or explicitly maintainer-approved Dockerfile change through the linked PR or a replacement, preserving fail-closed package installation and adding inspectable build plus package-presence proof for the sandbox images.

## Reproduction Assessment

## Solution Assessment
