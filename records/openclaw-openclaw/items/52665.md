## What This Changes

The issue requests adding APT retries and `--fix-missing` to the sandbox-common Docker image build to make source-checkout sandbox image builds more resilient to transient network failures.

## Best Possible Solution

Land a retry-only Dockerfile change through the linked PR or a replacement, preserve fail-closed package installation, and include inspectable build plus package-presence proof for both sandbox images.
