## Summary

Keep open: the latest head discards the existing outer-deadline and head-start contract, allowing the generic startup watchdog to mask an initialize or authentication stall despite strong proof and otherwise careful ownership handling.

## What This Changes

The PR splits shared Codex app-server startup into initialize and authentication phases with per-caller waits, preserves startup for longer peer callers, and changes abandonment cleanup and retry termination.

## Best Possible Solution

Restore one absolute startup deadline with deterministic inner headroom, consume only its remaining duration across initialize and authentication, and retain the new peer-acquirer ownership and abandonment cleanup model.
