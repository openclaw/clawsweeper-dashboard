## Summary

The patch is a focused and apparently correct fix for a current-main reload failure: the loader clears active plugin runtime registrations before fallible manifest loading, and the proposed rollback restores the exact cleared state if replacement never completes. The PR has direct real-entry-point before/after proof and green focused CI; it should remain open for ordinary maintainer review rather than cleanup.

## What This Changes

The PR snapshots all activated plugin runtime registrations before an activating reload clears them, restores that snapshot if the load throws before activation completes, and adds a regression test for manifest-load failure.

## Best Possible Solution

Keep rollback owned by loadOpenClawPlugins, preserve exact snapshot/clear/restore symmetry, and land the focused regression so a failed reload leaves the prior active registry and its runtime registrations consistent.
