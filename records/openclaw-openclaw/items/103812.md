## Summary

This PR remains necessary: it adds a narrow rollback for the activating plugin-load path when discovery or manifest loading aborts, preserving the previous runtime registrations instead of leaving the active registry inconsistent. The submitted regression case and before/after Node-process evidence are directly relevant; refresh the branch against current `main` and complete normal landing review.

## What This Changes

The branch snapshots activated plugin runtime registrations before an activating reload and restores them when loading throws before the new registry is activated.

## Best Possible Solution
