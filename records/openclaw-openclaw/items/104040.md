## What This Changes

Add a unified Model Providers Settings experience showing each configured provider’s authentication state, model availability, live quota and billing data, provider-reported cost history, and recent local session spend.

## Best Possible Solution

Create one canonical Models/Providers hub backed by shared provider-summary primitives extracted from the existing Overview, chat, and Usage implementations; include status and management there while retaining Usage as the detailed analytics destination.
