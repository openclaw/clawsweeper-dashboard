- **[P1] Use a valid close invocation for handshake timeout:** `packages/ai/src/providers/openai-chatgpt-responses.ts:1080`
  - body: `1009` is a reserved received-message status, not a code that callers may pass to the browser-compatible `WebSocket.close()` API.
