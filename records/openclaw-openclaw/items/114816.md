## What This Changes

The branch hardens OpenClaw’s terminal UI so streamed and aborted replies remain visible, delayed session updates do not affect a newly selected conversation, multiline input is safe and documented, and compact terminal controls render correctly.

## System Context

OpenClaw’s terminal UI accepts editor input, sends commands through the Gateway or embedded backend, then merges chat/session events into local TUI state and terminal output. This PR changes the handoff points that determine which session receives an asynchronous result and what reply text the user ultimately sees.
