## What This Changes

Fix Slack direct-message and group-DM thread routing so a top-level exchange seeds the thread session that later in-thread replies use.

## System Context

The Slack channel plugin converts incoming Slack messages into OpenClaw agent-session keys before the agent reads conversation history. Top-level DM, MPIM, and channel messages can lead to threaded replies, so their routing must place the root exchange in the same session as follow-up thread messages.
