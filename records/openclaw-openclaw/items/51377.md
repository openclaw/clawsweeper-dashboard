## Summary

Keep open: current main and the latest release still do not provide durable Excel or generic binary `input_file` workspace receipts; recent work only partially covers adjacent `chat.send` and file-only extraction behavior.

## What This Changes

Request to support Excel spreadsheets and generic binary uploads through Gateway `input_file`, with clear MIME limits, persistence metadata, tool access, and documentation.

## Best Possible Solution

Define a maintainer-approved Gateway binary `input_file` contract that stages allowed binary payloads as sanitized workspace artifacts with metadata and explicit unsupported errors, while keeping read-tool parsing and provider-native forwarding in their narrower linked tracks.
