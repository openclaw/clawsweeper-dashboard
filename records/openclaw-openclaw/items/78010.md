Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Stage sensitive restores in a private temp dir:** `docs/cli/backup.md:155-156`
  - body: The new restore example extracts backup contents into a predictable shared `/tmp/openclaw-restore` path and never removes it. Backup archives may contain credentials, auth profiles, sessions, and workspace data, so the docs should use a private `mktemp -d` directory with cleanup before publishing this flow.
  - confidence: 0.92
- **[P2] Use manifest archivePath instead of the tarball filename:** `docs/cli/backup.md:122`
  - body: The docs say `<archive-root>` matches the archive basename, but `openclaw backup create --output` can write a custom filename while the manifest carries the real `archiveRoot` and each asset's `archivePath`. Restore examples should read those manifest fields instead of reconstructing paths from the filename.
  - confidence: 0.86
