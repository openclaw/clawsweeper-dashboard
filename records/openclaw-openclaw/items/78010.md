Full review comments:

- **[P1] Stage sensitive restores in a private temp directory:** `docs/cli/backup.md:155-156`
  - body: Backup archives can include credentials, auth profiles, sessions, and workspace data, but this example extracts into a predictable shared `/tmp/openclaw-restore` path and never cleans it up. That publishes an unsafe restore pattern; use `mktemp -d`, verify before extraction, trap cleanup, and warn that staged contents are sensitive.
  - confidence: 0.92
- **[P2] Read the archive root from the manifest:** `docs/cli/backup.md:122`
  - body: The docs say the archive root matches the archive basename, but `openclaw backup create --output custom.tar.gz` can write a custom filename while the embedded `archiveRoot` and each asset `archivePath` remain timestamp-derived. Readers following this guidance can look under the wrong root and fail to restore.
  - confidence: 0.88
