Overall correctness: patch is incorrect

Full review comments:

- **[P1] Stage restore archives in a private temp directory:** `docs/cli/backup.md:155-156`
  - body: The new-machine example extracts backup contents into a predictable `/tmp/openclaw-restore` path and never removes it. Backup archives can contain credentials, auth profiles, sessions, and workspace data, so the docs should use a private `mktemp -d` directory with cleanup before telling operators to unpack archives.
  - confidence: 0.92
- **[P2] Read archive paths from the manifest:** `docs/cli/backup.md:122`
  - body: This says the archive root matches the archive basename, but `openclaw backup create --output` can write to a custom filename while the manifest still carries the actual `archiveRoot` and asset `archivePath` values. Restore docs should make those manifest fields the source of truth to avoid copying from the wrong path.
  - confidence: 0.86
