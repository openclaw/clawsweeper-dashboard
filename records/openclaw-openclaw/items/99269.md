## What This Changes

The issue asks to make the Codex app-server event projector fail closed on unknown item statuses and emit diagnostics for unknown or mismatched notifications.

## Best Possible Solution

Keep the fix in the Codex plugin projector boundary: map unknown statuses to a non-success diagnostic outcome, warn on unknown current-turn methods and relevant correlation mismatches, and add focused regression coverage without new config surface.

## Reproduction Assessment

Yes. The narrow maintainable fix is to fail closed and add rate-limited diagnostics at the Codex projector boundary, while preserving the existing run-attempt mismatch logging for cases it already covers.
