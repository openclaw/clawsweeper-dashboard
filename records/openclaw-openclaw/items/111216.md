  - body: Two concurrent `talk.client.toolCall` requests can authorize the same confirmation before either callback binds it to a run, so one spoken approval can permit duplicate high-impact effects.   - confidence: 0.96

  - body: Appending directly through the transcript storage helper persists an event but does not by itself publish a transcript update or refresh the session entry. Open WebChat and other session subscribers can miss the promised live history, while voice-only activity leaves recency stale.
  - confidence: 0.92
