## Summary

Keep open: this maintainer-labeled feature PR is not implemented on current main and has useful end-to-end coverage, but the new category drag/drop path trusts arbitrary text drops and can persist bogus session entries through `sessions.patch`, so it needs a small fix before merge.

## What This Changes

The PR adds a persisted per-session `category` field through `sessions.patch`, session rows, live session events, and a Control UI Sessions table grouping UI with custom groups, drag/drop assignment, docs, and tests.

## Best Possible Solution

Keep the additive protocol/store/UI grouping shape, but guard drag/drop with an OpenClaw-specific payload and current-row key validation before allowing category assignment.
