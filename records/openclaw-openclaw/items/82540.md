## What This Changes

The branch adds plugin-declared account-index reload metadata and Gateway handoff logic so a WeChat account-index refresh can restart existing live accounts without reviving removed accounts during ordinary configuration reloads.

## System Context

Gateway watches configuration changes, plans channel restarts, and delegates account lifecycle work to channel plugins. This PR introduces a plugin-declared account-index marker so an external account store refresh can retain live account runtimes through the paired stop/start handoff.
