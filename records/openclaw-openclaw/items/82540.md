## What This Changes

The branch changes Gateway channel stop/start reload handling so existing WeChat accounts remain online while a second account login refreshes the channel account index, while trying not to revive removed or disabled accounts.

## System Context

Gateway hot reload converts changed channel or plugin configuration into stop/start operations. The channel manager records account lifecycle state, the reload handler chooses a restart set, and the health monitor can independently observe that state while the handoff is in progress.

Refactor the stop-to-paired-start handoff so it carries explicit ownership through manual-stop and health-snapshot boundaries, add regressions for both races, then attach redacted exact-head WeChat A+B evidence or obtain an explicit gateway-owner waiver for gateway-level proof.
