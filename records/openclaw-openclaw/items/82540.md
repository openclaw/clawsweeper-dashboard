## What This Changes

This PR adds a plugin-declared account-index reload path so Gateway hot reload can retain active WeChat accounts while a new account login refreshes the plugin’s external account index.

## System Context

Gateway watches configuration changes, builds a reload plan, stops affected channel runtimes, and starts them again through the channel manager. This change adds plugin metadata for account-index updates so the restart path can preserve a live account during an external account-list refresh without applying that preservation to ordinary configuration edits.
