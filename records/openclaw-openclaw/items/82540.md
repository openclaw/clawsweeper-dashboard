## What This Changes

The PR adds a plugin-declared account-index reload path so Gateway hot reload can preserve active WeChat account runtimes while avoiding revival of removed or manually stopped accounts.

## System Context

Gateway configuration changes are planned into channel restart actions, then passed to the channel manager that stops and starts account runtimes. This PR changes the handoff between that planner and manager so an external channel account index can refresh without dropping an already-running account.
