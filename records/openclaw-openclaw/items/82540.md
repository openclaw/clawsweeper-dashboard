## What This Changes

This PR changes Gateway channel reload handoffs so an account-index refresh during WeChat multi-account login can retain already-running accounts without reviving accounts removed, disabled, or manually stopped during the same reload.

## System Context

The Gateway owns channel lifecycle state and restarts channel plugins after configuration or plugin changes. A channel account-index update feeds the reload planner, which stops affected runtime accounts and starts the refreshed channel set while health monitoring observes lifecycle snapshots.
