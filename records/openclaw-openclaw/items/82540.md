## Summary

Keep open: this is a focused gateway/channel bug-fix PR, but the current head still has a startup-gate race that can leave the account it is trying to preserve stopped, and the PR still lacks live WeChat A+B behavior proof.

## What This Changes

This PR adds a Gateway channel start option to include manager-known accounts during selected hot-reload paths, updates WeChat docs, and adjusts gateway and agent regression tests.
