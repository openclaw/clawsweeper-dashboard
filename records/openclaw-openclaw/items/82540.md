## What This Changes

This PR changes Gateway channel reload and restart handling so a WeChat account-index refresh preserves already-running accounts while ordinary configuration edits, disabled accounts, and stale runtime entries do not restart unexpectedly.

## System Context

Gateway hot reload turns configuration or plugin changes into channel stop/start handoffs. The shared channel manager records each account’s runtime state, while health monitoring and channel plugins consume that state to restart or expose connected accounts.
