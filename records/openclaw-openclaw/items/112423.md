## What This Changes

Prevent large SQLite session-transcript archival during cleanup from monopolizing the Gateway event loop while preserving durable archive-before-delete behavior.

## System Context

SQLite session lifecycle cleanup archives transcript generations before deleting their rows. That archival work runs alongside Gateway RPC and liveness processing, so large synchronous reads, compression, and filesystem publication can delay unrelated Gateway requests.
