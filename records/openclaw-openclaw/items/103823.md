## Summary

Keep open: the reported double-resume race is valid, but the patch still permits a later scan to resume the same child after an accepted resume if persisting the cleared abort marker fails; the external PR also lacks after-fix real gateway proof.

## What This Changes

The PR adds a process-wide per-session in-flight guard and latest-consistency store recheck to subagent orphan recovery, with regression coverage for two overlapping scans.

## Best Possible Solution

Make an accepted resume remain deduplicated when persisting the cleared abort marker fails, while keeping rejected dispatches retryable and allowing genuinely later re-orphaned sessions to recover.
