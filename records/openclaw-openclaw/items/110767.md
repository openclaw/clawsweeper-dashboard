## Summary

Keep open. The descriptor binding removes pathname substitution, but the helper still calls an unbounded `FileHandle.readFile()` after the descriptor stat, so a regular file that grows can exceed both claimed budgets; the PR also still lacks contributor-side real CLI proof.

## What This Changes

The PR adds descriptor-bound model-run image reads with a 100 MiB per-file limit and 500 MiB aggregate limit in `src/cli/capability-cli/model.ts`.

## Best Possible Solution

Keep the descriptor-bound open/stat flow, replace `FileHandle.readFile()` with a descriptor-bound bounded read that rejects data beyond the per-file or remaining aggregate limit, add focused regression coverage, then provide redacted real CLI output for normal and rejected inputs.
