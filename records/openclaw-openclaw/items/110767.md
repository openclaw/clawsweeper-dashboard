## Summary

Keep this PR open: the latest patch still performs an unrestricted `fs.readFile` after its size pre-check, so a file that grows or is replaced after `statSync` can bypass both advertised caps. It also still needs redacted after-fix CLI proof.

## What This Changes

The branch changes model-run image loading to process files sequentially with a 100 MiB per-file budget and 500 MiB aggregate budget.

## Best Possible Solution

Read from a single opened descriptor with an enforced byte limit based on bytes actually read, preserve the aggregate limit from actual bytes, add focused regression coverage, and attach redacted live CLI evidence.
