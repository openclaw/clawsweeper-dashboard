## Summary

Keep this PR open: the descriptor-bound POSIX path materially improves the size-bound and FIFO behavior, but the Windows fallback still opens with ordinary read flags and the supplied proof does not establish that a substituted Windows pipe cannot block before descriptor validation.

## What This Changes

The branch replaces path-based model-run image reads with descriptor-bound reads, adds 100 MiB per-file and 500 MiB aggregate limits, and uses nonblocking POSIX opens before validating regular files.

## Best Possible Solution

Define and implement a supported Windows-safe acquisition contract for model-run image paths, then provide a redacted Windows after-fix run proving that a pipe-like or equivalent non-regular input returns promptly while ordinary image files still work.
