## Summary

This PR is not ready to merge: it fixes the post-`stat()` growth bypass, but opening the path before determining whether it is a regular file can block indefinitely on a FIFO, where current main rejects that input before attempting a read.

## What This Changes

The PR replaces path-based model-run image reads with descriptor-bound, size-limited reads and retains 100 MiB per-file and 500 MiB aggregate budgets.

## Best Possible Solution

Keep descriptor-bound validation and bounded reads, but make opening an untrusted path non-blocking or otherwise reject non-regular inputs before a blocking open, then add a focused FIFO regression test on supported POSIX platforms.
