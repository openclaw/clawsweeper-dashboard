## Summary

The current head appears to be a focused, correct hardening of model-run image acquisition: it pins validation and reads to one descriptor, bounds allocation/read length, and explicitly limits the nonblocking guarantee to POSIX. The supplied terminal proof covers accepted, per-file-rejected, aggregate-rejected, and FIFO inputs; no remaining patch defect is supported. This PR is still necessary because current `main` does not contain the proposed descriptor-bound implementation, so it should remain open for ordinary maintainer review and the required CI gate resolution.

## What This Changes

The PR replaces path-based model-run image reads with descriptor-bound bounded reads while retaining the 100 MiB per-file and 500 MiB aggregate budgets.

## Best Possible Solution

Keep the descriptor-bound POSIX acquisition path, preserve Windows’ existing ordinary-open semantics until there is a reviewed Windows-specific primitive, and merge after the required CI gate is green or its failure is resolved by the normal maintainer process.
