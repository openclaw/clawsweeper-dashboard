## Summary

Keep this PR open for a narrow repair: its final stat-before-open change still leaves a path-substitution window in which a checked regular file can be replaced with a FIFO, causing the CLI to block during `open()`. The submitted terminal evidence covers normal inputs and size rejections, but not this critical race path.

## What This Changes

The PR changes model-run image ingestion to use descriptor-bound, explicitly bounded reads with 100 MiB per-file and 500 MiB aggregate budgets.

## Best Possible Solution

Use a platform-safe nonblocking descriptor acquisition strategy, validate the opened descriptor as a regular file, preserve the bounded descriptor read, and add a focused race/FIFO regression test plus redacted timeout-backed CLI proof.

## Solution Assessment

No. Descriptor-bound reads are the right direction, but placing a path-based `stat()` before opening restores a race; the fix must make descriptor acquisition itself safe from FIFO blocking before descriptor validation.
