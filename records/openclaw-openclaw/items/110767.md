## Summary

The POSIX descriptor-bound path is a meaningful improvement, but the new Windows pre-stat still leaves the path replaceable before `fs.open("r")`; the PR therefore does not yet meet its claimed no-blocking guarantee on Windows.

## What This Changes

The PR replaces path-based model-run image reads with descriptor-bound bounded reads, adds 100 MiB per-file and 500 MiB aggregate budgets, and uses platform-specific acquisition checks for non-regular paths.

## Best Possible Solution

Keep the descriptor-bound POSIX read, but choose and prove a Windows acquisition design whose open-time behavior is safe against replacement, or narrow the PR so it does not claim a Windows no-blocking guarantee it cannot enforce.
