## Summary

Keep open: current `main` still has a source-supported path where managed-service durable environment values can keep sensitive raw-stream logging enabled after an operator disables the launchd value, and no merged fix or canonical successor owns the remaining precedence contract.

## What This Changes

The issue asks for `OPENCLAW_RAW_STREAM` disable semantics to stop appending raw-stream logs after the variable is unset or set to `0` under a macOS LaunchAgent restart.

## Best Possible Solution

Define one raw-stream disable contract where an explicit managed-service disable cannot be overridden by stale persisted service env, then cover it with LaunchAgent/service-env tests, public disable-precedence docs, doctor/status guidance, and macOS proof.

- **Doctor-Guided Repair Only:** Leave runtime precedence mostly unchanged, but add status or doctor checks that warn and repair stale raw-stream service-env values before operators believe logging is off.
