## Summary

Keep open: current main has source-level parsing that makes `OPENCLAW_RAW_STREAM=0` false, but the macOS LaunchAgent service-env path can still source durable raw-stream values before the gateway starts, and docs do not define the supported disable or cleanup contract for this sensitive log.

## What This Changes

The issue asks for clear and reliable raw-stream disable semantics for macOS LaunchAgent-managed gateways after `OPENCLAW_RAW_STREAM` is unset or set to `0`.

## Best Possible Solution

Define one security-aware raw-stream disable contract across launchd, generated service env, state-dir `.env`, and config env, then update docs and doctor/service repair so stale durable enables cannot silently keep sensitive stream logging active after disable.
