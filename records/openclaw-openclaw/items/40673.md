## Summary

Keep open: current main still leaves a source-supported macOS LaunchAgent path where durable service environment sources can re-enable sensitive raw-stream logging after an operator believes `OPENCLAW_RAW_STREAM` is disabled, and no merged related item owns the remaining precedence contract.

## What This Changes

The issue asks OpenClaw to make `OPENCLAW_RAW_STREAM` disable semantics reliable and documented for macOS LaunchAgent-managed gateways.

## Best Possible Solution

Define one documented raw-stream disable contract where false or unset values reliably stop writes after restart, and make doctor/status repair any stale durable service-env source that would silently re-enable logging.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: When a macOS managed gateway has conflicting raw-stream env sources, should explicit disable intent from `launchctl unsetenv`, `OPENCLAW_RAW_STREAM=0`, or `off/false` override persisted state-dir `.env`, config env, and generated service-env values?

Rationale: Raw-stream logs can contain prompts, tool output, and user data, so automation should not choose the precedence contract for conflicting operator-controlled sources without maintainer security intent.

Likely owner: Peter Steinberger

Owner reason: The raw-stream feature and durable service-env helper history make this the best available owner for the precedence decision.

Owner confidence: high

Options:

- **Explicit Disable Wins (recommended):** Treat unset and false-like raw-stream values as authoritative for managed services, clear or override stale generated service-env entries, and document the precedence.
- **Persisted Env Remains Authoritative:** Keep state-dir `.env` and config env as the durable source of truth and document that operators must remove or edit those values before restart disables raw-stream logging.
- **Doctor-Guided Recovery Only:** Leave runtime precedence mostly unchanged but add status/doctor checks that warn and repair stale raw-stream service-env values before operators believe logging is off.

## Reproduction Assessment

Yes, we have a high-confidence source-level reproduction path: current runtime false semantics are correct, but LaunchAgent and durable service-env sources can repopulate `OPENCLAW_RAW_STREAM=1` before raw-stream append calls run. No live macOS LaunchAgent proof was run in this read-only review.

## Solution Assessment

Unclear: the current implementation is not the best final state because it lacks a documented managed-service disable precedence contract. The best repair depends on maintainer intent for explicit false launchd env versus persisted `.env`/config/service env sources.
