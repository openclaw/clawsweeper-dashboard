## Summary

Keep open: current main and v2026.6.11 define raw-stream enable/falsy parsing, but they do not settle the LaunchAgent disable-precedence contract for hidden service-env/config sources, and the affected log can contain sensitive prompts and tool output.

## What This Changes

The issue asks OpenClaw to make `OPENCLAW_RAW_STREAM` disable semantics reliable and documented for LaunchAgent-managed gateways after unset, `0`, or `off`.

## Best Possible Solution

Define one authoritative raw-stream disable contract for managed services: explicit false/unset should either fail closed across LaunchAgent wrapper/config sources or Doctor/status should surface the remaining source and provide a clear non-technical cleanup path, with docs naming supported false values.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should LaunchAgent-managed raw-stream logging fail closed when an operator sets `OPENCLAW_RAW_STREAM=0` or unsets it via `launchctl`, even if a generated service env file or config env source still contains `OPENCLAW_RAW_STREAM=1`?

Rationale: This changes precedence for sensitive diagnostic logging across launchd inherited env, generated service env files, state-dir `.env`, and config env; automation should not choose that security boundary silently.

Likely owner: Peter Steinberger

Owner reason: The current implementation and docs for the affected paths are carried by Peter Steinberger's recent current-main commit.

Owner confidence: medium

Options:

- **Fail Closed On Explicit False (recommended):** Treat an explicit operator false/unset path as disabling raw-stream writes and add Doctor/status/docs proof for hidden service-env cleanup.
- **Document Durable Source Precedence:** Keep durable service env/config values authoritative but make Doctor/status identify the active source and document how to remove it.
- **Require Maintainer Repro First:** Hold implementation until a macOS LaunchAgent live repro captures the process env, generated service env file, and append behavior in one trace.

## Reproduction Assessment

No live high-confidence macOS reproduction was run in this read-only review. Source inspection does support the likely class: raw-stream writes follow process env, while LaunchAgent wrappers can inject generated service env values that are not visible as plist `EnvironmentVariables`.

## Solution Assessment

Unclear until maintainers choose the precedence contract. A narrow code fix is possible only after deciding whether explicit false values override durable service/config sources or whether Doctor/docs should make those sources explicit instead.
