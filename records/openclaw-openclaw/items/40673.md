## Summary

Keep open: current main still has a source-supported managed LaunchAgent path where generated service environment can make sensitive raw-stream logging active despite an operator expecting `launchctl` unset or `0` to disable it, and no merged fix or canonical successor owns that precedence contract.

## What This Changes

The issue asks OpenClaw to make `OPENCLAW_RAW_STREAM` disable behavior clear and reliable for macOS LaunchAgent-managed gateways.

## Best Possible Solution

Define and test one raw-stream disable contract for managed services, then update LaunchAgent/service-env behavior, doctor/status guidance, and public docs so operators can reliably stop sensitive diagnostic logging.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should an explicit managed-service disable for `OPENCLAW_RAW_STREAM` override generated service-env and state-dir `.env` values, or should those persisted sources remain authoritative until edited?

Rationale: This decides a sensitive diagnostic logging boundary across multiple operator-controlled env sources, and automation should not encode that precedence without maintainer intent.

Likely owner: steipete

Owner reason: The raw-stream runtime and service-env precedence surfaces both route through recent work and committer history tied to this area.

Owner confidence: high

Options:

- **Explicit Disable Wins (recommended):** Treat `unset`, `0`, `off`, and `false` as authoritative for managed-service disable, clear or override stale generated service-env entries, and document the precedence.
- **Persisted Env Wins:** Keep state-dir `.env` and generated service env authoritative, and document that operators must remove or edit those persisted values before restart disables raw-stream logging.
- **Doctor-Guided Repair:** Leave runtime precedence mostly unchanged but add status/doctor checks that warn and repair stale raw-stream service-env values before operators believe logging is off.

## Reproduction Assessment

Yes for a source-level path, but not as a live macOS run in this review. The raw-stream writer disables on final false env values, while the LaunchAgent wrapper can source persisted service env before gateway startup.

## Solution Assessment

No current close path is proven best. The maintainable fix needs an explicit sensitive-logging precedence contract across LaunchAgent wrapper env, state-dir `.env`, config env, CLI flags, docs, and doctor/status guidance.
