## Summary

Keep open: current main still has a source-supported LaunchAgent/env-file path where a persisted raw-stream enable value can override an operator's apparent launchctl disable before the gateway process execs, and no merged PR now owns that disable-precedence contract.

## What This Changes

The issue reports that disabling `OPENCLAW_RAW_STREAM` for a macOS LaunchAgent can still leave sensitive raw stream logs appending after gateway restart.

## Best Possible Solution

Define one raw-stream disable contract where explicit managed-service disable cannot be overridden by stale persisted service env, then cover it with focused LaunchAgent/service-env tests, public docs, doctor/status guidance, and macOS proof.

Question: Should an explicit managed-service disable for `OPENCLAW_RAW_STREAM` override persisted state-dir `.env` or config service-env values, or should those persisted sources remain authoritative until edited?

Rationale: This decides a sensitive diagnostic logging precedence boundary across multiple operator-controlled env sources; automation should not encode that policy without maintainer intent.

Options:

- **Explicit Disable Wins (recommended):** Treat unset, `0`, `off`, and `false` disable intent as authoritative for managed services, clear or override stale generated service-env entries, and document the precedence.
- **Persisted Env Remains Authoritative:** Keep state-dir `.env` and config service env as the durable source and document that operators must remove or edit those values before restart disables raw-stream logging.
- **Doctor-Guided Repair Only:** Leave runtime precedence mostly unchanged but add status or doctor checks that warn and repair stale raw-stream service-env values before operators believe logging is off.

## Reproduction Assessment

Yes for a source-level path, but not as a live macOS run in this review. The writer disables on final false env values, while the LaunchAgent wrapper can source a persisted service env file before gateway startup and reintroduce `OPENCLAW_RAW_STREAM=1`.

## Solution Assessment

No close path is proven best. The maintainable fix needs an explicit sensitive-logging precedence contract across LaunchAgent wrapper env, state-dir `.env`, config env, CLI flags, docs, and doctor/status guidance.
