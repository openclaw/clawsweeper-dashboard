## Summary

Keep open: current main still supports a source-level path where LaunchAgent generated env files or durable service env can keep `OPENCLAW_RAW_STREAM=1` active after an operator unsets it or sets `0`, and no merged fix or canonical successor owns the sensitive logging precedence contract.

## What This Changes

The issue asks for LaunchAgent-managed raw-stream logging to stop after `OPENCLAW_RAW_STREAM` is unset or set to `0`, and for disable semantics to be documented.

## Best Possible Solution

Define one raw-stream disable precedence contract so an explicit managed-service disable cannot be hidden by stale generated env, then cover LaunchAgent tests, status/doctor guidance, and docs.
