## Summary

Keep open: current main still has a source-supported LaunchAgent path where durable service env can re-enable sensitive raw-stream logging after an operator disables only the launchd-inherited value, and no merged related item owns the disable-precedence contract.

## What This Changes

The issue requests enforceable and documented disable semantics for `OPENCLAW_RAW_STREAM` on macOS LaunchAgent restarts, including `unsetenv`, `0`, and `off` behavior.

## Best Possible Solution

Define one raw-stream disable-precedence contract, make LaunchAgent/generated env/config obey it, and document the disable path with doctor or status guidance for stale durable env entries.

- **Docs-only clarification:** Document the current behavior without changing precedence, accepting that `launchctl unsetenv` or `0` alone may not disable a wrapper-sourced raw-stream env value.
