## Summary

Keep open: current main still leaves the LaunchAgent raw-stream disable contract unresolved; `0` is falsy in the low-level parser, but durable service/env-file sources can still feed the gateway process and the docs do not define the disable/cleanup path for sensitive raw stream logs.

## What This Changes

The issue asks OpenClaw to stop appending raw-stream logs after `OPENCLAW_RAW_STREAM` is unset or set to `0` under a macOS LaunchAgent, and to document supported disable values.

## Best Possible Solution

Define one authoritative managed-service raw-stream disable contract, then update Doctor/status/docs and tests so operators can see and remove any active service-env source that would keep sensitive raw logging enabled.
