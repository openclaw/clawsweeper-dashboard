## Summary

Keep open: current main still lacks a merged fix or canonical successor for the LaunchAgent raw-stream disable contract. The final raw-stream gate rejects `0` and unset values, but the managed LaunchAgent service-env path can still source durable `.env` or generated env-file values before executing the gateway, and the docs do not define disable precedence for this sensitive log.

## What This Changes

The issue asks OpenClaw to stop appending raw-stream logs after `OPENCLAW_RAW_STREAM` is unset or set to `0` for a LaunchAgent-managed gateway, and to document disable semantics.

## Best Possible Solution

Define one raw-stream disable precedence contract for managed services, cover it with LaunchAgent/service-env tests, and document the supported disable path plus any doctor/status repair guidance.
