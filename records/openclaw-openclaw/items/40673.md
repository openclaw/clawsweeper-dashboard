## Summary

Keep open: current main still leaves a source-supported managed LaunchAgent path where generated service environment can re-enable sensitive raw-stream logging after an operator believes it is disabled, and no merged fix or canonical successor owns the remaining precedence contract.

## What This Changes

The issue requests clear disable semantics and a fix so `OPENCLAW_RAW_STREAM` unset, `0`, or other false values stop LaunchAgent-managed raw-stream logging after restart.

## Best Possible Solution

Define one raw-stream disable contract where explicit managed-service disable cannot be overridden by stale persisted service env, then add focused LaunchAgent/service-env tests, public docs, doctor/status guidance, and macOS proof.
