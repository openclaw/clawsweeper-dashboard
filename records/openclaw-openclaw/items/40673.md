## Summary

Keep open: current main still has a source-level path where LaunchAgent/durable service environment values can make raw-stream logging truthy after an operator believes it was disabled, and no merged fix or canonical successor owns the sensitive logging precedence contract.

## What This Changes

The issue asks OpenClaw to make `OPENCLAW_RAW_STREAM` disable semantics reliable and documented for LaunchAgent-managed gateway restarts.

## Best Possible Solution

Define one raw-stream disable precedence contract so explicit managed-service disables cannot be hidden by stale generated env, then cover LaunchAgent tests, status or doctor guidance, and public docs.
