## Summary

Keep open: current main still supports a source-level LaunchAgent/service-env path where durable service environment can keep sensitive raw-stream logging enabled after an operator believes it was disabled, and no merged PR or canonical successor owns that disable-precedence contract.

## What This Changes

The issue asks OpenClaw to make raw-stream logging stop after `OPENCLAW_RAW_STREAM` is unset or set to `0` for a restarted macOS LaunchAgent, and to document the disable values and LaunchAgent interaction.

## Best Possible Solution

Define one raw-stream disable contract where explicit managed-service disable cannot be overridden by stale persisted service env, then add focused LaunchAgent/service-env tests, public disable-precedence docs, doctor/status guidance, and macOS proof.

Options:

- **Explicit Disable Wins (recommended):** Treat unset, `0`, `off`, and `false` disable intent as authoritative for managed services, clear or override stale generated service-env entries, and document the precedence.

- **Doctor-Guided Repair Only:** Leave runtime precedence mostly unchanged but add status/doctor checks that warn and repair stale raw-stream service-env values before operators believe logging is off.
