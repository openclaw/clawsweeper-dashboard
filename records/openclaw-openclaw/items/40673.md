## Summary

Keep open: current main still leaves a source-reproducible LaunchAgent/service-env path where a generated env file can re-enable sensitive raw-stream logging after an operator disables the launchd inherited value, and no merged fix or canonical successor owns the remaining disable-precedence contract.

## What This Changes

The issue asks OpenClaw to stop appending raw-stream logs after `OPENCLAW_RAW_STREAM` is unset or set to `0` under macOS LaunchAgent, and to document supported disable values and precedence.

## Best Possible Solution

Define a single raw-stream disable contract where explicit disable wins for managed services, then add focused LaunchAgent/service-env tests, public docs for disable values and precedence, doctor/status guidance, and macOS proof.

## Reproduction Assessment

Yes for a source-level path, but not as a live macOS run in this review. The writer honors only truthy final env values, while the LaunchAgent wrapper can source a generated env file after launchd inheritance and before gateway startup.

## Solution Assessment

No current close path is proven best. The maintainable solution needs an explicit sensitive-logging precedence contract across LaunchAgent wrapper env, state-dir `.env`, config env, CLI flags, and docs.
