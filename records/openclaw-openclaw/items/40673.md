## Summary

Keep open: current main still leaves the macOS LaunchAgent raw-stream disable precedence unresolved, and the live issue search found no merged or open fix that now owns this exact disable-after-restart behavior.

## What This Changes

The issue reports that `OPENCLAW_RAW_STREAM` can keep appending sensitive raw-stream JSONL logs after a LaunchAgent-managed gateway is restarted with the variable unset or set to `0`.

## Best Possible Solution

Define one raw-stream disable precedence contract, cover LaunchAgent/service-env restart behavior with focused tests, and update public debugging/environment docs plus doctor/status guidance if stale service env needs repair.

Rationale: Raw-stream logs can contain private prompts and tool output, so automation should not choose whether an explicit false/unset launchd signal or durable service configuration is the authoritative operator intent.

Owner confidence: high

Options:

- **Explicit Disable Wins (recommended):** Treat unset, `0`, `off`, and `false` as authoritative disable intent for managed services, clear or override stale generated raw-stream service-env entries, and document that precedence.
- **Durable Env Wins:** Keep state-dir `.env` and config env authoritative, and document that operators must remove those durable values before restart disables raw-stream logging.
- **Doctor-Guided Repair:** Leave runtime precedence mostly unchanged but add doctor/status detection and repair for stale raw-stream service env before operators believe logging is off.

## Reproduction Assessment

Yes for a source-level path, but not as a live macOS run in this read-only review. Current main disables raw-stream only after final env resolution, while LaunchAgent/service-env paths can still source durable raw-stream values before gateway startup.

## Solution Assessment

Unclear: the source points to a valid bug boundary, but the best fix depends on the maintainer-chosen precedence for explicit false/unset launchd env versus persisted service-env sources. The safer end state is an explicit disable contract with tests and docs.
