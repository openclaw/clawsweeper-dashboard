## Summary

Keep open. Current main and v2026.6.11 still do not provide optional secondary token/password authentication on top of verified Tailscale Serve identity, while the related no-auth Tailscale exposure bug is already fixed separately.

## What This Changes

The issue requests opt-in layered Gateway auth, warning output, and docs for Tailscale Serve deployments that currently trust verified tailnet identity without a token/password.

## Best Possible Solution

Define a maintainer-approved layered Gateway auth contract, then update config types/schema/help, WebSocket auth enforcement, warning or audit messaging, public docs, and focused auth tests together.
