## Summary

Keep open. Current main and v2026.6.11 still support tokenless verified Tailscale Serve identity for Control UI/WebSocket without a secondary shared-secret path; the related no-auth exposure fix closed a different bug, so this remains a maintainer/security design item.

## What This Changes

## Best Possible Solution

Define one maintainer-approved layered Gateway auth contract, then align config schema/types/help, auth enforcement, warning or audit output, docs, and focused tests together.
