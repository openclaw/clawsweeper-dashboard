## What This Changes

Request an automatic browser lifecycle policy that stops a Chrome/CDP browser after an agent finishes using it, optionally through an auto-close setting or timeout.

## System Context

Agents invoke browser tools against a Chrome process through CDP, and the browser lifecycle determines whether later agent actions can reuse that process or must start a new one. A lifecycle policy would affect resource cleanup after browser work and the continuity of later browser actions.

## Architecture Diagram

flowchart LR
  A[Agent task] --> B[Browser tool calls]
  B --> C[Chrome via CDP]
  C --> D[Browser lifecycle policy]
  D --> E[Reusable browser session]
  D --> F[Stopped browser process]

## Best Possible Solution

Define a browser-session ownership contract first: preserve intentional reuse during an agent task, then add bounded cleanup at the appropriate task/session teardown boundary or a documented idle-timeout policy only if current controls cannot satisfy the resource-cleanup need.
