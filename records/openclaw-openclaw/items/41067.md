  - body: This close-handler path aborts every active chat run and writes restart-style interruption notices during any shutdown/close, while current main gates restart drain/abort behavior on `restartExpectedMs`.   - confidence: 0.9

  - body: The new hello snapshot lists every abort-controller entry, bypassing current `resolveInFlightRunSnapshot`/sessions.list filters for hidden, aborted, inactive, and agent-owned runs. That can recover the UI to the wrong run and make it ignore the real run's events.
  - confidence: 0.88
- **[P2] Return false when restart transcript injection fails:** `src/gateway/server-restart-sentinel.ts:32-39`
  - body: `injectRestartNoticeIntoSession` can throw while preparing or appending the transcript, but callers only enqueue the fallback system event when it returns `false`. Catch setup/append failures so a consumed sentinel notice is not dropped.
  - confidence: 0.84

  - body: The UI returns the first matching active run for a session. If multiple entries exist, it can recover an older run and then drop newer run events due run-id mismatch; choose the newest matching run or preserve an existing matching run deterministically.
  - confidence: 0.82
