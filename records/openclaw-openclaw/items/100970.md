## What This Changes

This PR lets WhatsApp operators set `debounceMs` per direct conversation or group, with specific entries taking precedence over wildcards and the existing inbound channel default.

## System Context

WhatsApp Web admits inbound direct-chat and group messages, then sends them through the shared inbound debouncer before an agent turn begins. This change resolves a conversation-specific delay from the selected WhatsApp account configuration while preserving the first message's delay for an already buffered batch.
