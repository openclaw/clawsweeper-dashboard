## What This Changes

This PR adds optional `debounceMs` values to WhatsApp direct-chat and group configuration entries, resolves them per admitted conversation, and documents precedence over the existing inbound debounce default.

## System Context

WhatsApp inbound messages enter the web listener after admission, where the channel selects an inbound debounce window before messages are batched for an agent turn. This change lets the WhatsApp configuration choose that window per direct chat or group while retaining the shared core debouncer for keyed batching and flush ordering.
