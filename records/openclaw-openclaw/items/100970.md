## What This Changes

This PR adds optional per-conversation `debounceMs` settings to WhatsApp direct-chat and group entries, resolves specific and wildcard overrides before the existing inbound default, and preserves the first delay selected for an active batch.

## System Context

WhatsApp inbound messages pass admission and conversation identity into the WhatsApp listener, which chooses a batching delay before using the shared inbound debouncer. The debouncer then holds same-conversation messages and supplies the completed batch to the agent turn.
