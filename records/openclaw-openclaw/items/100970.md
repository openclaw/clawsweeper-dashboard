## What This Changes

This PR adds optional `debounceMs` overrides to WhatsApp direct-chat and group configuration entries so each admitted conversation can use a different inbound batching delay.

## System Context

WhatsApp inbound messages pass admission and conversation identification before entering OpenClaw’s shared keyed inbound debouncer. This PR lets the WhatsApp channel select a conversation-specific delay while the shared debouncer preserves ordering and flush behavior for the resulting batch.
