## Summary

This remains a useful, proof-backed repair for the reported ACP regression, but it deliberately changes the terminal contract for selected parent-owned run-mode one-shots: they remain resumable after completion and gateway restart. That operational lifecycle needs explicit maintainer acceptance before merge; no discrete patch defect is established in this review.

## What This Changes

The branch preserves verified resume identity for completed parent-owned ACP run-mode children so a later `sessions_send` can reconnect to the same Codex or Claude backend conversation instead of starting a fresh one.

## System Context

ACP run-mode children are created by a parent agent and execute through the ACPX runtime. Their persisted ACP metadata, task cleanup, and `sessions_send` routing determine whether a completed child is discarded or can be reopened against the same backend conversation.
