## What This Changes

The branch retains confirmed resumable ACP run-mode session metadata and routes later parent follow-ups into the original backend conversation while rejecting active, unsupported, unready, or invalid resume states.

## Best Possible Solution

Completed ACP one-shots should remain resumable only when a resolved stable protocol session ID, advertised resume capability, persisted completion readiness, backend ownership, and inactive-turn state all agree; every unsupported, provisional, active, missing, or invalid state should fail closed and remain eligible for cleanup.
