## Label Justifications

## Summary

Keep this PR open for landing. Current main still reproduces the completed-one-shot continuity bug, while the branch implements a capability-gated, stable-ID-only, fail-closed resume path with strong live proof and broad lifecycle coverage; no concrete patch defect was found.

## What This Changes

The branch preserves confirmed resumable ACP run-mode session metadata and routes later parent follow-ups through the original backend conversation while rejecting active, unsupported, or invalid resume cases.

## Best Possible Solution

Land the capability-gated, stable-ID-only, fail-closed resume design while retaining regression coverage for upgrades, restarts, unsupported agents, active turns, stale targets, persistence failures, backend ownership, and task cleanup.

## Solution Assessment

Yes. Reusing the protocol session only after capability advertisement, stable-ID capture, successful-turn readiness, and durable persistence is narrower and safer than either silently starting fresh or making all one-shots persistent.
