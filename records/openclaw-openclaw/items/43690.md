## What This Changes

The issue requests that Feishu replies with too many Markdown tables avoid silent card delivery failure by falling back to text/post mode or another table-safe rendering.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/86901 with a narrow Feishu plugin fix that keeps cards for safe content and falls back to the existing post/plain-text path when Markdown table count exceeds Feishu's card limit.
