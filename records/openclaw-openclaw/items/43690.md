## What This Changes

Request Feishu to avoid dropping replies when interactive cards exceed the markdown-table limit, preferably by falling back to post/raw text or another safe rendering path.

## Best Possible Solution

Land or replace the narrow Feishu static interactive-card table-limit fallback against current main, with tests for six-table post fallback and five-table card behavior; validate CardKit streaming separately if it still reproduces.
