## Summary

Keep open: current main and the latest release still route Feishu markdown-table replies through interactive-card sends without a five-table/table-limit fallback, and https://github.com/openclaw/openclaw/pull/86901 is the open same-repository implementation candidate that has not landed.

## What This Changes

The issue requests a Feishu fallback or alternate rendering path when markdown-table-heavy replies exceed the platform's interactive-card table limit.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/86901 with a narrow Feishu plugin fix that keeps cards for safe content and falls back to the existing post/plain-text path when markdown tables exceed Feishu's card limit.
