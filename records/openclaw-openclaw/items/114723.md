## What This Changes

The PR makes all landing-script branch mutations enter and verify a dedicated per-PR Git worktree, rebuilding stale or unsafe worktree paths instead of falling back to the shared checkout.

## System Context

OpenClaw’s `scripts/pr` landing commands prepare, review, and merge pull requests through a per-PR linked Git worktree. The shared checkout supplies repository metadata and fetches, while branch resets, rebases, and checkouts must occur only in the dedicated worktree so concurrent sessions remain untouched.
