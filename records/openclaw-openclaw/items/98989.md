## Summary

Keep this PR open: the capability is not present on current `main`, but the current patch has a high-confidence CLI redaction bypass because it locates the current turn by scanning the first unescaped envelope markers in rendered history. The new public plugin and durable-transcript contract also lacks confirmed maintainer direction and current-head real behavior proof.

## What This Changes

The PR adds a `transform` outcome to `before_agent_run` and propagates the replacement prompt through embedded and CLI model input, persistent session history, lifecycle hooks, documentation, and tests.

## Best Possible Solution

Adopt one explicit maintainer-approved transform contract, carry the current turn structurally through CLI preparation instead of scanning rendered history, preserve receipt-backed import semantics, and prove adversarial-marker, fresh-session, resumed-session, embedded, and CLI behavior with redacted live evidence.
