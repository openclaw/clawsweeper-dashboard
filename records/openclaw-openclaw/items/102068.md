## Summary

## What This Changes

Adds a Workboard Board dropdown, in-memory `boardFilter` UI state, client-side filtering by `metadata.automation.boardId`, and synced Workboard locale strings.

## Best Possible Solution

Keep the Board dropdown direction, but encode filter state as closed modes or prefixed board values, add collision coverage for `all` and `none`, keep generated locales synced, and collect redacted Workboard UI proof.
