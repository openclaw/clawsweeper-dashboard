## What This Changes

The branch keeps credentials for web-provider plugins with standalone tools active when another search or fetch provider is selected, while also adding `runId` to gateway question records and changing Control UI chat ordering.

## System Context

OpenClaw resolves configured SecretRefs before web search and fetch providers are used at runtime. That resolved configuration supplies both the selected generic web tool and any provider-owned standalone tools, so an incorrect inactive-provider decision can leave a standalone tool without its configured credential.
