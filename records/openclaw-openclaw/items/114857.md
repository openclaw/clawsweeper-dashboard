## What This Changes

The branch centralizes node gateway option resolution, preserves saved secure connection settings for an unchanged endpoint, clears removed node tools, and limits paired-node Ollama inference to authorized local models.

## System Context

The node CLI starts or installs paired node hosts that connect to a Gateway using saved endpoint, TLS, fingerprint, and reverse-proxy path settings. Those node hosts publish commands and dynamic tools to the Gateway, while the Ollama plugin uses an authorized paired node to discover and run local inference models.
