## Summary

Keep this protected security issue open for targeted security-owner review. The cited ACP servers are stdio/WebSocket bridge components rather than HTTP mutation routes, but the separate default-off Admin HTTP RPC plugin exposes configuration-changing methods and documents an explicit no-auth private-ingress mode whose browser-origin behavior still needs current-main validation.

## What This Changes

Evaluate and harden cross-origin request protection for browser-reachable local control-plane configuration mutations.

## Best Possible Solution

Reproduce the Admin HTTP RPC route from a hostile browser origin across token, password, trusted-proxy, and no-auth modes, then add the narrowest plugin-owned Origin and content-type guard that rejects browser CSRF while preserving authenticated and origin-less host automation.
