## Summary

Keep this protected security issue open for security-owner validation. The reported ACP files implement a stdio-to-Gateway WebSocket bridge, while the relevant browser-reachable mutation surface is the optional `admin-http-rpc` plugin; current documentation establishes origin enforcement for trusted-proxy browser requests but does not resolve whether cross-site simple POST requests can reach dispatch under every supported auth mode.

## What This Changes

Validate and harden browser-origin request protection for privileged local HTTP control-plane mutations.

## Best Possible Solution

Apply shared Gateway browser-origin validation to the actual Admin HTTP RPC route before authentication or dispatch, preserve Origin-less trusted host automation, and add focused tests covering cross-site simple POSTs, JSON preflight behavior, allowed same-origin requests, and token, trusted-proxy, and explicit no-auth modes.
