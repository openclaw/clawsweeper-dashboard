## What This Changes

Audit local state-changing control-plane HTTP routes for missing browser-origin or anti-CSRF enforcement.

## Best Possible Solution

Inventory every browser-reachable state-changing Gateway HTTP route and its authentication mode, then centralize Origin/Fetch-Metadata enforcement where ambient browser credentials or no-auth private ingress make cross-site requests meaningful, with regression coverage for hostile origins, permitted same-origin/loopback callers, and native clients without an Origin header.
