Keep this protected security issue open for a controlled security-owner review. ([github.com](https://github.com/openclaw/openclaw/raw/refs/heads/main/src/acp/server.ts))

## What This Changes

Determine whether cross-site browser requests can mutate local Gateway control-plane state, then add origin or anti-CSRF enforcement at the correct shared HTTP boundary if confirmed.

## Best Possible Solution

Reproduce a cross-site simple state-changing request against each supported Gateway HTTP authentication mode, then place one fail-closed browser-origin gate before privileged Gateway-authenticated HTTP dispatch while preserving documented native and plugin-managed ingress, with focused acceptance and rejection tests.
