## Summary

Close as implemented: OpenClaw now supports zero-touch first-time node enrollment from explicitly trusted CIDRs, so autoscaled Kubernetes nodes can authenticate with normal gateway credentials and pair without per-pod intervention; the exact ServiceAccount TokenReview design is no longer required to solve the central problem.

## What This Changes

Add Kubernetes ServiceAccount TokenReview authentication so autoscaled worker pods can connect without interactive pairing, together with Kubernetes manifests and a Helm chart.

## Best Possible Solution

Keep the shipped generic trusted-CIDR enrollment policy as the core solution, distribute the gateway credential through a narrowly scoped Kubernetes Secret, and use external operator or Helm packaging; open a new focused security proposal only if a concrete deployment requires pod-level ServiceAccount identity beyond this documented trust model.
