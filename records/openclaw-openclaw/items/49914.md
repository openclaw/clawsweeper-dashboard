  - body: The command builds targets from persisted `sessionHistory` before enforcing `session.historyLimit`. If an operator changes the limit to `0` while old history is present, `/sessions` can still show and switch those entries, then this block pushes the current session and immediately evicts/archives it even though history is supposed to be disabled.
  - confidence: 0.88
