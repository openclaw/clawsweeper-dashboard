## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Restore or clear the full session boundary:** `src/auto-reply/reply/commands-sessions.ts:280`
  - body: This switches `sessionId`/`sessionFile` and then reapplies only `SessionHistoryItem.metadata`, leaving many session-scoped fields from the outgoing conversation in place. Fields such as auth profile overrides, CLI/ACP bindings, exec/elevated policy, abort state, fallback notices, runtime model fields, cost, delivery context, and prompt reports can carry into the resumed transcript and make the next turn run in the wrong backend or policy context.
  - confidence: 0.91
- **[P1] Keep retained history transcripts referenced:** `src/auto-reply/reply/session.ts:649`
  - body: The PR intentionally keeps old transcripts switchable by storing them in `sessionHistory`, but current disk-budget cleanup only treats active store entries and compaction checkpoints as referenced. A deployment with session maintenance can therefore delete a retained transcript while `/sessions` still lists it, causing a switch back to reopen an empty or missing conversation.
  - confidence: 0.88
- **[P2] Honor disabled history before resolving switches:** `src/auto-reply/reply/commands-sessions.ts:258-264`
  - body: `historyLimit` is read only after the command has already built switch targets from persisted history. If an operator sets `session.historyLimit` to `0` while stale history exists, `/sessions <n>` can still switch to it and then immediately evict/archive the current session, even though the configured contract says history is disabled.
  - confidence: 0.86
- **[P2] Archive retained entries when disabling history:** `src/auto-reply/reply/session.ts:650-651`
  - body: When `historyLimit` is `0`, this branch clears the whole inherited `sessionHistory` array but later archives only the immediately previous session. Older retained history entries are dropped from state without going through the reset archive path, leaving their transcript files orphaned outside the normal retention flow.
  - confidence: 0.82
