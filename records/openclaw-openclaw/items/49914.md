  - body: `allItems` is built from persisted `sessionHistory` before `historyLimit` is read.   - confidence: 0.88

  - body: This PR deliberately leaves prior transcripts switchable by assigning `sessionHistory`, but current disk-budget cleanup only protects active entry artifacts and compaction checkpoints.   - confidence: 0.86
- **[P1] Restore or clear the full session boundary:** `src/auto-reply/reply/commands-sessions.ts:280`
  - body: The switch mutates the live `SessionEntry` and reapplies only the small history metadata subset. Fields such as `authProfileOverride`, CLI/ACP handles, exec/elevated policy, abort/fallback/runtime model, response usage, and cost are neither restored nor cleared, so the target session can inherit credentials or tool policy from the outgoing session.
  - confidence: 0.9
