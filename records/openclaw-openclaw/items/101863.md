## Summary

Keep open: current main has partial diagnostic stale-run and lane recovery, but the broader lifecycle umbrella remains unresolved across in-memory follow-up queues, process-fatal unhandled rejections, unlimited-run idle-watchdog disablement, queue poison retries, and Codex-wrapper idle guards gated by active app-server requests.

## What This Changes

The issue requests a maintainer-owned run lifecycle reliability design covering bounded liveness, abort-to-release, restart-safe queued turns, and completion drive.

## Best Possible Solution

Adopt the invariants as a maintainer-owned umbrella, then split Track A-D into focused PRs that extend existing terminal-outcome and diagnostic-recovery paths while persisting durable queue/turn state in SQLite.
