## What This Changes

This PR makes Ollama and LM Studio onboarding validate usable local models before persisting setup, preserve LM Studio model compatibility metadata, and apply automatic compact-tool settings only to verified local models.

## System Context

Provider plugins own local Ollama and LM Studio setup, discovery, and model metadata, while the core non-interactive onboarding command enables the selected plugin and persists the resulting default model. The changed flow validates provider state before reset or credential writes, then records a model selection and any onboarding-owned local-tool setting for later runs.
