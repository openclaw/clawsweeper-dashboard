## Summary

Keep open: the PR has the right ledger-owned direction and useful proof, but the new path-scoped byte cache can trust `PRAGMA data_version` across reopened SQLite connections even though that value is only comparable on the same connection.

## What This Changes

Caches the ACP SQLite replay byte estimate per resolved state database path, maintains it with row-level deltas, invalidates it with `PRAGMA data_version`, and adds ACP ledger regression tests.

## Best Possible Solution

Keep the ledger-scoped cached accounting design, but make invalidation connection-aware and add a close/reopen plus external-write regression test before merge.
