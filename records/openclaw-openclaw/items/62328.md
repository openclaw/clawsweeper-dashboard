## Summary

Keep open: current main and the latest release still lose keyword/BM25 recall when `node:sqlite` cannot create the FTS5 table, while the linked open PRs cover diagnostics or adjacent missing-`node:sqlite` fallback behavior rather than a merged recall fix.

## What This Changes

The issue reports that builtin memory search degrades from documented hybrid keyword/vector recall to vector-only or empty results when the active `node:sqlite` runtime lacks FTS5, and asks for a fallback, documentation, or louder doctor warning.

## Best Possible Solution

Keep this as the canonical FTS5-unavailable memory recall tracker until maintainers either land a recall-restoring implementation or explicitly choose diagnostic-only degraded behavior.
