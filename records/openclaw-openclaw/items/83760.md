- **[P1] Advertise geometry only when the workflow supports it:** `extensions/comfy/image-generation-provider.ts:27-40`
  - body: `supportsSize` and `supportsAspectRatio` become true for every Comfy provider, but `runComfyWorkflow` only applies them when the selected config contains a valid `dimensions` block. An unmapped existing workflow can therefore be selected for a geometry request and silently return its hard-coded size; post-run `dimensionsApplied: false` cannot repair the false pre-run capability signal. Use an owner-approved configuration-aware capability contract or keep these capabilities disabled until that contract exists.
  - confidence: 0.97
- **[P2] Return the dimensions that the workflow received:** `extensions/comfy/image-generation-provider.ts:72-77`
  - body: The new metadata reports only a boolean after mutating width/height inputs. Callers cannot determine the concrete geometry injected into the workflow—especially for aspect-ratio rounding—or distinguish that from the generated asset's geometry. Return structured requested and injected dimensions under the approved result contract so callers have a usable, testable outcome.
  - confidence: 0.87
