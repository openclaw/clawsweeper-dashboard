## Summary

The central bug remains on current main, and the PR now has strong runtime proof with no remaining discrete correctness finding from the completed review cycles. It should stay open because the permanent core contract still needs explicit owner approval: this adds a public configuration knob, a generic queue timeout callback, and host-side abandonment semantics for plugin work that may continue running after its lane is released.

## What This Changes

Adds an opt-in deferred context-engine maintenance timeout, synchronous late-side-effect fencing, file and SQLite persistence checkpoints, stalled-session warning backoff, configuration documentation, and regression coverage.

## Best Possible Solution

Adopt one documented canonical maintenance-abandonment contract that bounds the host wait, fences every OpenClaw-owned persistent side effect, preserves a same-session read checkpoint for admitted writes, states what non-cooperative plugins may still do, and has fresh-install, upgrade, file-store, and SQLite proof.
