Keep this PR open for owner review: the patch and runtime proof are strong with no discrete correctness finding, but it leaves the reported stall unchanged by default while adding a permanent config surface and generic queue-timeout callback that require an explicit context-engine policy decision.

## What This Changes

The PR adds an opt-in timeout for deferred context-engine maintenance, fences late task and transcript side effects, coordinates in-flight persistence, throttles repeated stalled-session warnings, documents the setting, and adds regression coverage.

## Best Possible Solution

Define one context-engine-owner-approved host timeout and cancellation contract for deferred maintenance—prefer deriving it from the existing compaction safety policy unless separate tuning is demonstrably necessary—then retain the branch’s late-side-effect fencing, persistence ordering, diagnostics backoff, upgrade tests, and real runtime proof.
