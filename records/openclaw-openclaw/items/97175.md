## Summary

Keep open: the patch appears technically correct and proof-positive, but it creates a new configuration surface and shared timeout/cancellation contract that a context-engine owner should explicitly approve before merge.

## What This Changes

The PR adds an opt-in timeout and late-side-effect fence for deferred context-engine maintenance, coordinates transcript persistence after timeout, throttles repeated stalled-session warnings, documents the configuration, and adds regression coverage.

## Best Possible Solution

Adopt one explicit host-owned maintenance timeout and cancellation contract that preserves existing plugin behavior by default, fences every OpenClaw-owned late mutation, documents the limits for non-cooperative plugins, and has owner-approved fresh-install and upgrade semantics.
