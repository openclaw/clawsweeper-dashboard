## Label Justifications

- `P1`: A wedged maintenance run can delay a queued interactive same-session turn for minutes, making the session effectively unavailable.
- `merge-risk: 🚨 compatibility`: The PR introduces a new compaction configuration key and an opt-in behavior contract that operators may rely on.

## Summary

This remains a useful candidate fix for the active session-stall report, but automatic merge should pause for a maintainer decision on the post-timeout lifecycle of a still-running plugin maintenance call. The branch has credible runtime-log proof and focused coverage, yet releasing the lane while the plugin continues cannot be treated as a purely mechanical timeout policy.

## What This Changes

The PR adds an opt-in per-task timeout and safety fence for deferred context-engine turn maintenance, documents the new compaction setting, and throttles repeated `session.stalled` warnings.

## Best Possible Solution

Choose and document the post-timeout plugin-maintenance contract, then retain the opt-in disabled-by-default setting only if maintainers want operators to control this liveness bound; otherwise rework the fix around an existing approved safety-timeout policy.
