## What This Changes

The PR adds an opt-in timeout and late-side-effect fence for deferred context-engine maintenance, documents the resulting engine concurrency contract, and throttles repeated stalled-session warnings.

## System Context

After an agent turn, a context-engine plugin may run deferred maintenance on a per-session command lane before the next same-session work proceeds. This PR adds a timeout path that releases that lane for liveness while fencing host-owned transcript and task-state writes from an abandoned maintenance worker.
