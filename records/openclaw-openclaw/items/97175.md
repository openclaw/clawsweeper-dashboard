## Summary

This PR is still necessary because current main still enqueues deferred turn maintenance without a task timeout, and no related PR has merged as a safe replacement. The patch has no blocking correctness finding, but the new config surface and timeout/fence semantics need maintainer acceptance before merge.

## What This Changes

The PR adds an opt-in `agents.defaults.compaction.turnMaintenanceTaskTimeoutMs` setting, wires deferred context-engine turn maintenance through command-queue timeout hooks, fences late transcript/task side effects after timeout, throttles repeated `session.stalled` diagnostics, and adds docs plus regression tests.

## Best Possible Solution

Land a maintainer-approved timeout-and-fence policy for deferred turn maintenance, either this opt-in config shape or a replacement that reuses an existing compaction safety budget without adding a separate knob.
