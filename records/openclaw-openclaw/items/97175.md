## What This Changes

The branch adds an opt-in timeout for deferred context-engine maintenance, fences late host-owned side effects, preserves a same-session persistence checkpoint, fences file and SQLite transcript rewrites, throttles repeated stalled-session warnings, and adds configuration, documentation, and regression coverage.

## Best Possible Solution

Adopt one explicitly owner-approved host policy for bounded maintenance: retain the write fence and read checkpoint, document that non-cooperative plugin work may continue after host abandonment, and expose the dedicated opt-in setting only if maintainers prefer upgrade compatibility over automatic recovery through an existing safety budget.
