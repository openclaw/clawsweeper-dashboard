## Summary

Keep open for maintainer review. The patch has convincing proof and no discrete correctness finding, but it creates a permanent configuration surface and defines partial cancellation and shutdown semantics that require explicit product and compatibility approval.

## What This Changes

Adds an opt-in deferred context-engine maintenance timeout, synchronous queue-timeout fencing, transcript and task-write guards, shutdown abort coordination, stalled-warning backoff, configuration documentation, and regression coverage.

## Best Possible Solution

Approve a clear host/plugin cancellation contract before landing: the timeout should bound OpenClaw's lane and core-owned state, documentation must state that plugin-internal work is not forcibly cancelled, and maintainers should explicitly accept the opt-in configuration and shared shutdown behavior or select a host-owned default instead.
