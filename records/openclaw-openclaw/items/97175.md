## Summary

Keep open: the implementation, regression coverage, live runtime evidence, and exact-head checks support the fix, but the permanent operator configuration and shared queue-timeout callback contract still require context-engine owner approval before merge.

## What This Changes

The PR adds an opt-in timeout and late-side-effect fence for deferred context-engine maintenance, coordinates transcript persistence after timeout, throttles stalled-session warnings, documents the new setting, and adds regression coverage.

## Best Possible Solution

Adopt one explicitly approved host-owned cancellation contract that preserves the disabled-by-default upgrade behavior, defines which OpenClaw and plugin side effects are abandoned after timeout, and keeps transcript reads and writes serialized across the release point.
