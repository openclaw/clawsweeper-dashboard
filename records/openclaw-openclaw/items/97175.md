## What This Changes

The PR adds an opt-in timeout and fencing lifecycle for deferred context-engine maintenance, guards late transcript and task writes, coordinates shutdown aborts, throttles stalled-session warnings, documents the config, and adds regression coverage.

## Best Possible Solution

Adopt one owner-approved deferred-maintenance contract: a documented timeout policy, a single late-side-effect fence and persistence barrier, and explicit acceptance of either cooperative plugin cancellation or the bounded non-cooperative-worker model, with clear operator recovery guidance.
