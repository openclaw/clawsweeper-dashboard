## What This Changes

The PR returns image attachments from a rewound or forked prompt through the gateway and restores validated images into the web, iOS/macOS, and Android chat composers.

## System Context

A session rewind or fork cuts the stored transcript at a chosen user message and returns editable prompt state through the gateway. The web and native chat clients consume that result to replace the destination composer before the user edits and resends the prompt.

## Best Possible Solution

Keep a single bounded rewind/fork restoration contract: return only validated, size-bounded image payloads, restore them as in-memory composer state, and explicitly accept whole-composer replacement rather than adding cross-platform draft revision tracking for the request window.
