Full review comments:

- **[P2] Make source fingerprint reads asynchronous:** `src/agents/cli-credentials.ts:247`
  - body: The async cache helper still calls `readSourceFingerprint` synchronously before and after every miss. Those callbacks perform filesystem metadata work, so the new gateway path can still block the event loop; make the fingerprint contract awaitable and use async filesystem APIs.
  - confidence: 0.96
- **[P2] Coalesce concurrent credential cache misses:** `src/agents/cli-credentials.ts:258`
  - body: Each caller that observes an expired cache independently starts `read()`, so simultaneous agent starts can launch duplicate Keychain processes and prompts before any result is stored. Cache an in-flight promise per cache key and clear it after settlement.
  - confidence: 0.95
- **[P2] Use a child-process API that closes stdin:** `src/agents/sessions/resolve-config-value.ts:137`
  - body: `child_process.exec` does not honor this `stdio` option, so command-backed config resolvers that read stdin can remain open until the 10-second timeout. Use `execFile` or `spawn` with explicitly ignored stdin, or explicitly close the child's stdin.
  - confidence: 0.94
- **[P2] Make the configured Windows shell path asynchronous:** `src/agents/sessions/resolve-config-value.ts:151`
  - body: The Windows branch still invokes the existing synchronous configured-shell helper before falling back to async execution. Users with a configured PowerShell or bash path therefore retain the event-loop blocking this PR is intended to remove; add and await an async configured-shell implementation.
  - confidence: 0.98
