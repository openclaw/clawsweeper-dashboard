## Summary

This PR remains necessary because current main still performs blocking credential I/O, but the branch is not merge-ready: several nominally async paths retain synchronous work, Windows command resolution remains blocking, command-backed model configuration is not fully migrated, and the evidence is mock-only rather than a live macOS gateway run.

Overall correctness: patch is incorrect

Overall confidence: 0.97

Full review comments:

- **[P2] Remove synchronous work from async credential readers:** `src/agents/cli-credentials.ts:250`
  - body: The async cache still calls synchronous source-fingerprint functions, and the credential implementations continue through synchronous realpath, stat, JSON, and account-file helpers. A slow filesystem can therefore still block the gateway; convert the complete read and fingerprint boundary to `node:fs/promises`.
  - confidence: 0.98
- **[P2] Make the configured Windows shell path asynchronous:** `src/agents/sessions/resolve-config-value.ts:150`
  - body: This async function calls `executeWithConfiguredShell`, which retains the synchronous child-process path on Windows. Command-backed credentials can still block the event loop; add and await an async configured-shell implementation.
  - confidence: 0.99
- **[P2] Use a child-process API that can close stdin:** `src/agents/sessions/resolve-config-value.ts:136`
  - body: `child_process.exec` does not support the supplied `stdio` option, so it may fail type checking or silently retain a piped stdin. Use an async spawn or execFile helper that explicitly ignores stdin while preserving timeout and output handling.
  - confidence: 0.96
- **[P2] Migrate model resolution to the async helper:** `src/agents/sessions/resolve-config-value.ts:176`
  - body: Using `resolveConfigValueAsync` only from `AuthStorage.getApiKey` leaves model configuration and status callers on the synchronous resolver. Those callers can still execute `!command` values on the blocking path during provider resolution; migrate the complete gateway-facing call chain.
  - confidence: 0.94
- **[P2] Deduplicate concurrent credential cache misses:** `src/agents/cli-credentials.ts:250`
  - body: The async cache stores only completed values, so concurrent agent starts with an empty or expired cache each launch their own Keychain or file read. Keep an in-flight promise per cache key and verify failures clear it without poisoning the value cache.
  - confidence: 0.88
