## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Remove the unrelated root files:** `HEARTBEAT.md:1`
  - body: The current final diff still adds `HEARTBEAT.md`, `SOUL.md`, `TOOLS.md`, `openclaw-workspace-state.json`, and `xiugaiyijian.md`. These are workspace/agent notes and copied review output, not part of a launcher feature, and would publish local state/noise at repo root.
  - confidence: 0.98
- **[P2] Delegate readiness instead of hard-coding Gateway health:** `launcher/src/main.rs:103-104`
  - body: `is_gateway_running` probes only `http://127.0.0.1:18789/health` with `curl`, bypassing the existing gateway status/readiness code that knows configured ports, remote URLs, service status, and probe semantics. Users with a non-default or remote Gateway can be shown as down and have the launcher try to start a different managed Gateway.
  - confidence: 0.94
- **[P2] Forward arguments for known commands:** `launcher/src/main.rs:286-292`
  - body: For known commands like `tui`, `webui`/`dashboard`, and `update`, the launcher discards all arguments after the first token. That means `openclaw-launcher update --dry-run`, `tui --local`, or `dashboard --no-open` silently runs a different command than the canonical CLI supports.
  - confidence: 0.95
- **[P2] Add or remove the documented build command:** `launcher/README.md:19`
  - body: The README tells users to run `pnpm launcher:build`, but the current final diff no longer adds that package script and current `package.json` has no such script. A user following the launcher docs will hit a missing script instead of building the launcher.
  - confidence: 0.97
- **[P2] Use cross-platform CLI discovery:** `launcher/src/main.rs:19-21`
  - body: The launcher first shells out to `which openclaw`, which is Unix-specific, while the README advertises Windows `.exe` usage and global npm installs. On Windows global installs, this can fail to find the canonical CLI unless one of the narrow fallbacks happens to apply.
  - confidence: 0.88
- **[P3] Resolve the displayed version through the chosen CLI path:** `launcher/src/main.rs:264-266`
  - body: Version lookup always runs `node <cli_path> --version`, even when `cli_path` is a native executable, shell shim, or `.cmd`; the submitted screenshot already shows `版本: unknown`. Use the same command-shape logic as normal delegation so the launcher displays the actual OpenClaw version.
  - confidence: 0.9
