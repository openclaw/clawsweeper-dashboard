  - confidence: 0.88

  - body: The README tells users to run `pnpm launcher:build`, but the PR head does not add that script to `package.json` or wire the launcher into the package file list. As written, the documented build path fails for reviewers and users.
  - confidence: 0.93
- **[P2] Use cross-platform CLI discovery:** `launcher/src/main.rs:19-20`

A Windows launcher outside the source tree can fail to find a normal npm-installed CLI, so discovery needs to support the documented platform or the docs should narrow the claim.
  - confidence: 0.82
- **[P3] Resolve version through the selected CLI:** `launcher/src/main.rs:264-265`
  - body: The screenshot shows `OpenClaw: unknown`, and the source always runs `node <cli_path> --version` even when the resolved CLI path is a bin shim or executable.   - confidence: 0.86
