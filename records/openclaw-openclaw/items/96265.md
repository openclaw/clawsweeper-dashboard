  - confidence: 0.93

  - confidence: 0.82
- **[P3] Resolve version through the selected CLI:** `launcher/src/main.rs:264-265`
  - body: The screenshot shows `OpenClaw: unknown`, and the source always runs `node <cli_path> --version` even when the resolved CLI path is a bin shim or executable.   - confidence: 0.86
