## What This Changes

The PR moves Chrome MCP and CDP sticky-target assignment after post-navigation policy validation and adds unit plus live Chrome regression coverage.

## Best Possible Solution

Preserve the previous sticky target when CDP discovery times out, adopt only after an observed final URL passes policy, and add a regression where the target appears with a blocked URL only after the discovery window.
