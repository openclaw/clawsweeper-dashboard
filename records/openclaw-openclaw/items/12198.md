Keep open: current main and v2026.6.11 still have adjacent boundary checks and skill scanner rules, but no shared prompt-bearing Markdown validation contract across workspace bootstrap files, runtime SKILL.md loading, active install/audit scanning, and ClawHub install/publish policy. ## What This Changes

The issue requests Markdown validation for prompt-bearing files such as skills and workspace bootstrap Markdown to reduce prompt-injection and security risk.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to workspace bootstrap ingestion, extra bootstrap files, runtime SKILL.md discovery/read paths, source and ClawHub skill install/update, and ClawHub publish/verification tagging with explicit docs and tests.
