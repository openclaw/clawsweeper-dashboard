## Summary

Keep open: current main and the latest locally available stable release still lack a shared prompt-bearing Markdown validation contract, and the open scanner PR is a useful partial candidate but is conflicting and too narrow to supersede this issue.

## What This Changes

The issue requests validation of prompt-bearing Markdown files, including skill definitions, to catch unsafe or prompt-injection content before it reaches model-visible or install/publish paths.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to bootstrap ingestion, extra bootstrap files, runtime SKILL.md discovery/read paths, source and ClawHub install/update, and ClawHub publish/tag behavior with explicit docs and tests.
