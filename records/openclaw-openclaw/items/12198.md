## Summary

Keep open: current main and v2026.6.11 still lack one shared prompt-bearing Markdown validation contract across workspace bootstrap files, model-visible SKILL.md reads, skill install/update, and ClawHub publish/tag policy.

## What This Changes

Request to add validation or linting for Markdown files that can become prompt-visible, especially skill definitions and workspace bootstrap files, to reduce prompt-injection and unsafe-content risk.

## Best Possible Solution

Approve one shared prompt-bearing Markdown validation contract, then implement it consistently across bootstrap ingestion, SKILL.md loading, source and ClawHub skill install/update, and ClawHub publish/tag behavior with explicit docs and tests.
