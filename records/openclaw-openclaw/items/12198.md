## Summary

Keep open. Current main still reads workspace bootstrap Markdown and inserts prompt-context file contents without a shared Markdown safety-validation contract, while the related scanner PR closed unmerged and the remaining enforcement scope requires a maintainer security/product decision.

## What This Changes

The issue requests configurable validation of prompt-bearing Markdown, including skill definitions and workspace files, to detect or reject potentially harmful hidden or injection-oriented content.

## Best Possible Solution

Define one documented prompt-bearing Markdown policy with explicit source trust levels, findings/severity, user-visible warnings or blocks, upgrade handling, and tests; then apply it consistently at the workspace, skill-loader, and native ClawHub boundaries that actually feed model context.
