## Summary

Keep open: current main and v2026.6.11 still only have partial skill-content scanning and Skill Workshop proposal scanning, not a shared prompt-bearing Markdown validation contract for bootstrap prompt files, runtime SKILL.md loading, ClawHub install/update, and publish-side policy. ## What This Changes

Request prompt-bearing Markdown validation for skills, bootstrap prompt files, and ClawHub publishing/install so suspicious prompt-injection patterns can be blocked, warned, or tagged.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior with explicit docs and tests.

## Reproduction Assessment

Yes, at source level: current main still appends bootstrap context and loads valid SKILL.md content without a shared prompt-bearing Markdown validator. This is a feature/security gap rather than a broken existing documented validator, and no live user-path repro was run in this read-only review.

## Solution Assessment

No, not as a scanner-only change or the full raw proposal. The maintainable solution is a shared security contract with maintainer-decided rules, severity, override/config behavior, workspace-write scope, and ClawHub policy.
