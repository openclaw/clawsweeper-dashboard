## Summary

Keep open: current main still has only partial hardening and lacks one shared prompt-bearing Markdown validation contract across bootstrap prompt files, normal SKILL.md loading, ClawHub install/update, and publish policy. The open scanner PR is a useful partial candidate but is unmerged, conflicting, and narrower than the issue.

## What This Changes

Add Markdown validation for prompt-bearing files such as SKILL.md and workspace bootstrap Markdown to reduce prompt-injection and security risks.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior with explicit docs and tests.

## Solution Assessment

No, not as the full proposal or as a scanner-only change. The maintainable path is a shared security contract with maintainer-decided rules, severity, override behavior, workspace-write scope, and ClawHub policy.
