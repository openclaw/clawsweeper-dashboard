## Summary

Keep open: current main and v2026.6.11 still lack a shared prompt-bearing Markdown validation contract across bootstrap files, SKILL.md loading, skill install/update, and ClawHub publish/tag policy.

## What This Changes

Add validation for Markdown files that can become model-visible prompt context, including skill definitions and workspace bootstrap files, to catch prompt-injection and security-risk patterns.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to workspace bootstrap ingestion, extra bootstrap files, runtime SKILL.md discovery/read paths, source and ClawHub skill install/update, and ClawHub publish/tag behavior with explicit docs and tests.
