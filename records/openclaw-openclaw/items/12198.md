## Summary

Keep open: current main still has partial Skill Workshop prompt-content scanning, but it does not provide the shared prompt-bearing Markdown validation contract requested for bootstrap context, runtime SKILL.md loading, active scan flows, and ClawHub install/publish policy.

## What This Changes

Request a Markdown validator for files that can become prompt context, especially SKILL.md and workspace bootstrap files, to catch prompt-injection and security-risk patterns.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior.

## Reproduction Assessment

Yes, at source level: current bootstrap, prompt assembly, runtime SKILL.md loading, and active scanner paths show no shared prompt-bearing Markdown validation policy. This is not a strict bug reproduction because current docs/tests do not already promise such a validator.

## Solution Assessment

No, not as the full original proposal or a scanner-only change. The maintainable solution is a shared security contract with maintainer-decided rules, severity, overrides, diagnostics, and ClawHub policy.
