## Summary

Keep open: current main and latest release still only provide partial skill-content scanning and install trust checks, while the requested shared prompt-bearing Markdown validation contract remains unresolved across bootstrap context, normal SKILL.md reads, ClawHub install/update, and publish policy.

## What This Changes

Requested Markdown validation for prompt-bearing files, especially SKILL.md and workspace bootstrap Markdown, to reduce prompt-injection risk.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior with explicit docs and tests.

## Reproduction Assessment

Yes, at source level: current main still appends bootstrap context and exposes SKILL.md reads without one shared prompt-bearing Markdown validator. This is not a strict bug reproduction because current docs/tests do not define that validator as existing behavior.

## Solution Assessment

No, not as the full proposal verbatim or as a scanner-only change. The maintainable fix is a shared security contract with maintainer-decided rules, severity, overrides, workspace-write scope, and ClawHub policy.
