## Summary

Keep open: current main still lacks a shared prompt-bearing Markdown validation contract across bootstrap context, runtime SKILL.md loading, active skill scanning, and ClawHub install/update policy. Existing Skill Workshop scans and related open PRs are partial rather than a merged replacement.

## What This Changes

The issue requests Markdown validation for prompt-bearing files such as skill definitions and bootstrap Markdown to reduce prompt-injection and hidden-content risk.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior.

## Reproduction Assessment

Yes, at source level: current bootstrap, prompt assembly, runtime SKILL.md loading, scanner, and ClawHub install paths show no shared prompt-bearing Markdown validation policy. This is not a strict bug reproduction because current docs/tests do not already promise such a validator.

## Solution Assessment

No, not as the whole proposal verbatim or as a scanner-only change. The maintainable solution is a shared security contract with maintainer-decided rules, severity, overrides, workspace-write behavior, and ClawHub policy.
