## Summary

Keep open: current main has partial Skill Workshop prompt-content scanning, but it still lacks a shared prompt-bearing Markdown validation contract for workspace bootstrap context, runtime SKILL.md loading, active directory scans, ClawHub install/update, and publish-side policy.

## What This Changes

The issue requests security validation for Markdown files that can be appended to agent prompts, especially SKILL.md and other prompt-bearing workspace files.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior.

## Reproduction Assessment

Yes, at source level: current bootstrap, prompt assembly, runtime SKILL.md loading, and active scan paths show no shared prompt-bearing Markdown validation policy. This is not a strict bug reproduction because current docs/tests do not already promise such a validator.

## Solution Assessment

No, not as the full proposal or a scanner-only change. The maintainable solution is a shared security contract with maintainer-decided rules, severity, overrides, workspace-write scope, and ClawHub policy.
