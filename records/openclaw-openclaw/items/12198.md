## Summary

Keep open: current main still lacks a shared prompt-bearing Markdown validation contract across workspace bootstrap context, runtime SKILL.md loading, active skill scanning, and ClawHub skill install/publish policy; the open scanner PR is a useful but conflicting partial candidate.

## What This Changes

Request to add Markdown validation for prompt-bearing files such as SKILL.md and workspace bootstrap Markdown so risky prompt-injection patterns can be blocked, warned, or tagged before becoming model-visible.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior.

## Reproduction Assessment

Yes, at source level: current bootstrap, prompt assembly, runtime SKILL.md loading, scanner, and ClawHub install paths show no shared prompt-bearing Markdown validation policy. This is not a strict bug reproduction because current docs/tests do not already promise such a validator.

## Solution Assessment

No, not as the full proposal or a scanner-only change. The maintainable solution is a shared security contract with maintainer-decided rules, severity, overrides, workspace-write behavior, and ClawHub policy.
