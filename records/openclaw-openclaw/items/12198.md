## Summary

Keep open: current main has adjacent hardening and Skill Workshop proposal scanning, but it still lacks a shared prompt-bearing Markdown validation contract across workspace bootstrap files, normal `SKILL.md` runtime reads, and native source/ClawHub skill installs. The open scanner PR covers only part of the requested security hardening and is not merged.

## What This Changes

Request adding Markdown validation/linting for prompt-bearing files such as workspace bootstrap Markdown, `SKILL.md` definitions, and ClawHub-published skills to reduce prompt-injection risk.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to workspace bootstrap ingestion, extra bootstrap files, normal `SKILL.md` discovery/read paths, source and ClawHub skill install/update, and ClawHub publish/verification tagging.

## Reproduction Assessment

Yes. Source inspection on current main shows bootstrap Markdown and normal `SKILL.md` bodies can still reach prompt-visible paths without a shared Markdown validation policy; I did not run a live mutation test because this review is read-only.

## Solution Assessment

No submitted patch is being reviewed. The best fix is not a one-off regex in one loader, but a shared security contract with explicit severity, override/tagging, install/update, publish, docs, and tests across the prompt-bearing Markdown surfaces.
