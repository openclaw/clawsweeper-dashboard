## Summary

Keep open: current main and v2026.6.11 still lack one shared prompt-bearing Markdown validation contract across bootstrap files, runtime SKILL.md reads, skill install/update, and ClawHub publish policy.

## What This Changes

Request Markdown validation for prompt-bearing files, especially skill definitions, to catch prompt-injection and security-risk patterns before they are loaded or published.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to workspace bootstrap ingestion, extra bootstrap files, runtime SKILL.md discovery/read paths, source and ClawHub skill install/update, and ClawHub publish/tag behavior with explicit docs and tests.
