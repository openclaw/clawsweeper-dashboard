## Summary

Keep open. Current main still treats workspace bootstrap Markdown and selected SKILL.md instructions as model-visible content without one shared validation contract, while current ClawHub scanning and the closed Markdown-scanner PR cover only parts of the requested boundary. The remaining work is security-sensitive and needs maintainers to define rule scope, severity, enforcement, overrides, and OpenClaw-versus-ClawHub ownership before implementation. ([github.com](https://github.com/openclaw/openclaw/blob/main/src/agents/system-prompt.ts?utm_source=openai))

## What This Changes

Add validation for prompt-bearing Markdown, including skill definitions and workspace prompt files, to detect or flag prompt-injection and sensitive-content patterns.

## Best Possible Solution

Define a small shared prompt-content analysis contract that returns typed findings, reuse maintained scanner primitives where adequate, apply boundary-specific warn/block/tag behavior at bootstrap ingestion, SKILL.md loading, native install/update, and ClawHub publishing, and explicitly reject the proposed second-Git cache and automatic content rewriting.
