## Summary

Keep open: current main and v2026.6.11 have partial skill-content scanning, but they still lack one shared prompt-bearing Markdown validation contract across bootstrap context, normal SKILL.md reads, ClawHub install/update, and publish-side policy.

## What This Changes

The issue requests Markdown validation for prompt-bearing files such as SKILL.md and workspace bootstrap Markdown to reduce prompt-injection and security risks.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior with explicit docs and tests.

## Reproduction Assessment

Yes, at source level: current main still appends bootstrap context and exposes SKILL.md reads without a shared prompt-bearing Markdown validator. This is not a strict bug reproduction because current docs/tests do not define that validator as existing behavior.

## Solution Assessment

No, not as a scanner-only change or the full workspace-write proposal. The maintainable path is a shared security contract with maintainer-decided rules, severity, override behavior, workspace-write scope, and ClawHub policy.
