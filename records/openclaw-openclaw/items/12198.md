## Summary

Keep open: current main and v2026.6.11 have partial skill-content scanning, but they still lack a shared prompt-bearing Markdown validation contract across bootstrap prompt files, normal SKILL.md reads, ClawHub install/update, and publish-side policy; the known scanner PR is open, conflicting, and only covers part of the request.

## What This Changes

Request to add validation or linting for model-visible Markdown prompt files, especially SKILL.md and workspace prompt files, to catch prompt-injection and security-risk patterns.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior with explicit docs and tests.

## Reproduction Assessment

Yes, at source level: current main still appends bootstrap context and exposes SKILL.md reads without a shared prompt-bearing Markdown validator. This is not a strict bug reproduction because current docs/tests do not already define that validator as existing behavior.

## Solution Assessment

No, not as the full proposal or as a scanner-only change. The maintainable path is a shared security contract with maintainer-decided rules, severity, override behavior, workspace-write scope, and ClawHub policy.
