## Summary

Keep open: current main and v2026.6.11 still lack a shared prompt-bearing Markdown validation contract; existing scanner and Skill Workshop coverage is partial, and the open scanner PR is not a merged canonical fix.

## What This Changes

Request to add validation for prompt-bearing Markdown files such as workspace bootstrap files and SKILL.md definitions to reduce prompt-injection and unsafe-content risk.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to workspace bootstrap ingestion, extra bootstrap files, runtime SKILL.md discovery/read paths, source and ClawHub skill install/update, and ClawHub publish/tag behavior with explicit docs and tests.
