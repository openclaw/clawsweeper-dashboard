## Summary

Keep open: current main and v2026.6.11 still have only partial skill-content scanning, while bootstrap prompt files, model-visible SKILL.md reads, native install/update, and ClawHub publish policy still lack one shared prompt-bearing Markdown validation contract.

## What This Changes

The issue requests validation/linting for Markdown files that are appended to model prompts, especially skill definitions and other prompt-bearing Markdown, to reduce prompt-injection and related security risk.

## Best Possible Solution

Define one threat-model-backed prompt-bearing Markdown validation and diagnostics contract, then apply it consistently to bootstrap context, runtime SKILL.md loading, Skill Workshop, ClawHub install/update, and publish-side scan/tag behavior with explicit docs and tests.

## Reproduction Assessment

Yes, at source level: current main still has prompt/bootstrap and SKILL.md read paths without a shared prompt-bearing Markdown validator, while the active directory scanner excludes .md. No live CLI repro was run because this cleanup review is read-only.

## Solution Assessment

No, not as the full proposal or as a scanner-only change. The maintainable path is a shared security contract with maintainer-decided rules, severity, override behavior, workspace-write scope, and ClawHub policy.
