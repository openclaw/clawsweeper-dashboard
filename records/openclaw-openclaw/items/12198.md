## Summary

Keep open: current main and v2026.6.11 still lack a shared prompt-bearing Markdown validation contract across workspace bootstrap files, runtime SKILL.md reads, skill install/update, and ClawHub publish or audit policy. ## What This Changes

Request a Markdown validation or linting policy for Markdown files that become prompt-visible, especially skill definitions and workspace prompt/bootstrap files, to reduce prompt-injection and unsafe-instruction risk.

## Best Possible Solution

Define one shared prompt-bearing Markdown validation contract and apply it consistently to workspace bootstrap ingestion, extra bootstrap files, runtime SKILL.md discovery/read paths, native skill install/update, ClawHub publish/verification tagging, and docs/tests with maintainer-approved severity and override semantics.
