## Review Findings

Overall correctness: not a patch

Overall confidence: 0.91

Full review comments:

- **[P1] Preserve non-cron schedules when editing jobs:** `apps/linux/src/section_cron.c:270-275`
  - body: The edit save path always sends `schedule.kind: "cron"` with an `expr`, but current cron jobs can be `at`, `every`, `cron`, or `on-exit`. Saving an existing non-cron job after an unrelated edit can rewrite or invalidate when it runs, so carry the original schedule variant or block unsupported edits.
  - confidence: 0.93
- **[P2] Preserve session-scoped cron targets:** `apps/linux/src/section_cron.c:342-352`
  - body: The target combo only models four fixed choices and the helper maps unknown values to the first option, but current gateway cron targets include `session:<id>`. Editing a session-scoped job can silently retarget it away from the intended session.
  - confidence: 0.89
- **[P1] Send accepted verbose levels in session patches:** `apps/linux/src/section_sessions.c:175-184`
  - body: The sessions verbose combo sends `none`, `low`, and `high`, while the current server parser accepts only `off`, `on`, and `full`. Verbose updates from this UI path will be rejected instead of changing the session setting.
  - confidence: 0.9
- **[P2] Resolve local logs from session ids:** `apps/linux/src/section_sessions.c:264-266`
  - body: This local transcript probe builds `<storeDir>/<session-key>/transcript.jsonl`, but the gateway resolver uses `sessionId`, optional `sessionFile`, and the sessions directory. The Log action will usually miss existing local transcripts and fall back to the dashboard or fail offline.
  - confidence: 0.9
- **[P2] Bracket IPv6 hosts before composing URLs:** `apps/linux/src/gateway_config.c:1153-1155`
  - body: The URL builder interpolates `config->host` directly as `scheme://host:port`. For an IPv6 literal such as `::1`, that creates malformed health, WebSocket, and dashboard URLs; bracket IPv6 literals before formatting.
  - confidence: 0.86
