Full review comments:

- **[P1] Preserve existing cron schedule variants:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always sends patch.schedule as kind="cron" with expr from the textbox. Existing jobs can use kind="every" or kind="at", so a no-op metadata edit can rewrite or invalidate a valid job created elsewhere; carry the original schedule variant or omit schedule unless it changes.
  - confidence: 0.93
- **[P1] Keep session-scoped cron targets on edit:** `apps/linux/src/test_seams.c:42-47`
  - body: Valid cron targets include session:<id>, but this helper maps any unknown target to index 0, which the save path serializes back as isolated. Editing a session-scoped job can therefore retarget it even when the user changes an unrelated field.
  - confidence: 0.92
- **[P2] Send supported verbose override values:** `apps/linux/src/section_sessions.c:176-184`
  - body: The Sessions UI sends none/low/high as verboseLevel, but the gateway normalizer accepts off/on/full-style values. These session preference changes will be rejected instead of updating verbosity from the Linux app.
  - confidence: 0.9
- **[P2] Send null when clearing the session model:** `apps/linux/src/gateway_mutations.c:148-150`
  - body: Selecting the default model passes NULL, but the mutation helper omits model entirely when NULL. The gateway only clears a session model override when model:null is present, so this UI cannot return a session to its default model.
  - confidence: 0.9
- **[P3] Add Linux app labeler coverage:** `.github/labeler.yml:184-203`
  - body: The PR creates apps/linux/** but the labeler still only covers Android, iOS, macOS, and web UI app surfaces. Add an app: linux label rule so future Linux app changes get stable routing and review ownership.
  - confidence: 0.86
