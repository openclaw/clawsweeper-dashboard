  - body: The edit path always patches `schedule` as `{kind:"cron", expr}`. Jobs created elsewhere with `at`, `every`, or `on-exit` schedules will be rewritten or fail validation even when the user only edits metadata.
  - confidence: 0.94

  - body: The UI sends `none`/`low`/`high` for `verboseLevel`, but `sessions.patch` accepts `off`/`on`/`full`; selecting a verbose option from the Linux app will be rejected by the gateway.
  - confidence: 0.95

  - body: This adds OpenClaw-owned app state as a new INI sidecar under the user state dir.   - confidence: 0.86
