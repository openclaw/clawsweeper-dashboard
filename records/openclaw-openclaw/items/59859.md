## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.93

Full review comments:

- **[P1] Preserve non-cron schedule variants on edit:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always sends `schedule.kind = "cron"` with the textbox as `expr`, but the gateway cron contract supports `at`, `every`, `cron`, and other variants. Saving an existing non-cron job can rewrite or invalidate its schedule even when the user edits only metadata.
  - confidence: 0.95
- **[P1] Keep session-scoped cron targets on edit:** `apps/linux/src/section_cron.c:350-352`
  - body: `session_target_to_index()` collapses valid `session:<id>` targets to the default combo row, and the save path serializes that row back as `isolated`. Editing a session-scoped job therefore silently retargets it away from the chosen session.
  - confidence: 0.93
- **[P2] Send valid verbose override values:** `apps/linux/src/section_sessions.c:176-184`
  - body: The verbose dropdown sends `none`/`low`/`high`, but current `sessions.patch` parsing accepts `off`/`on`/`full` or `null` for clearing. These UI changes will be rejected by the gateway instead of updating the session.
  - confidence: 0.94
- **[P2] Send null when clearing the session model:** `apps/linux/src/section_sessions.c:205-206`
  - body: Selecting the default model row passes `NULL` into `mutation_sessions_patch`, but that helper omits the `model` field entirely when it is `NULL`. Since the gateway uses explicit `model: null` to clear an override and an omitted field means no change, users cannot clear a saved model override from this combo.
  - confidence: 0.91
- **[P3] Add Linux app labeler coverage:** `apps/linux/meson.build:11-13`
  - body: This adds a new `apps/linux` app surface, but current labeler coverage only has Android, iOS, macOS, and web-ui app labels. Root policy requires new app surfaces to update `.github/labeler.yml` and GitHub labels, otherwise Linux app changes will keep being routed as gateway/web-ui instead of a Linux app surface.
  - confidence: 0.86
