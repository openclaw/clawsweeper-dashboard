## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Preserve non-cron schedules when editing jobs:** `apps/linux/src/section_cron.c:270-275`
  - body: The edit save path always sends `schedule_kind = "cron"` and an `expr`, but the gateway supports `at`, `every`, `cron`, and `on-exit` schedules. Editing a job created elsewhere with a non-cron schedule can rewrite or fail that schedule even when the user only changes unrelated fields.
  - confidence: 0.94
- **[P1] Preserve session-scoped cron targets:** `apps/linux/src/test_seams.c:42-48`
  - body: `session_target_to_index()` maps any unrecognized target, including valid `session:<id>` values, to index 0, and saving maps that back to `isolated`. Editing a session-scoped cron job can silently retarget it away from the intended session.
  - confidence: 0.91
- **[P2] Send supported verbose override values:** `apps/linux/src/section_sessions.c:175-184`
  - body: The Sessions view sends `none`, `low`, and `high` for `verboseLevel`, but the current parser accepts the normalized values advertised as `on`, `off`, and `full` plus null for clearing. These UI changes will be rejected instead of updating the session.
  - confidence: 0.9
- **[P2] Send null when clearing the session model:** `apps/linux/src/gateway_mutations.c:148-151`
  - body: Selecting the default model stores a null entry in the combo data, but `mutation_sessions_patch()` omits `model` whenever the pointer is null. The server therefore sees no change, so users cannot clear an existing per-session model override from this UI.
  - confidence: 0.92
- **[P3] Add Linux app labeler coverage:** `.github/labeler.yml:139-147`
  - body: This PR adds a new app surface under `apps/linux/**`, but the labeler still only routes Android, iOS, macOS, and web UI app paths. Future Linux app PRs will miss the app-specific routing expected for new channel/plugin/app/doc surfaces.
  - confidence: 0.83
