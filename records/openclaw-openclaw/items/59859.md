## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Preserve non-cron schedules when editing jobs:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always writes `patch.schedule` as `{kind: "cron", expr: ...}`. Current cron jobs can be `at`, `every`, `cron`, or `on-exit`, so saving metadata on a non-cron job can rewrite or invalidate its schedule instead of preserving the existing variant.
  - confidence: 0.95
- **[P1] Keep session-scoped cron targets editable:** `apps/linux/src/section_cron.c:343-352`
  - body: The target combo has no representation for valid `session:<id>` targets, and unknown values map to the first row before being saved as `isolated`. Editing an existing session-scoped job can silently retarget it away from the intended session.
  - confidence: 0.92
- **[P2] Send supported verbose levels in sessions.patch:** `apps/linux/src/section_sessions.c:176-184`
  - body: The verbose selector sends `none`, `low`, or `high`, but `parseVerboseOverride` accepts the on/off/full family and rejects these values. Users changing verbose mode from the Linux app will get a runtime validation failure instead of updating the session.
  - confidence: 0.94
- **[P2] Send null when clearing a session model:** `apps/linux/src/gateway_mutations.c:148-150`
  - body: Selecting the default model passes `NULL`, but `mutation_sessions_patch` omits `model` whenever the pointer is null. The gateway supports `model: null` to clear the override, so this UI path currently sends a no-op instead of clearing the saved model.
  - confidence: 0.9
- **[P3] Add Linux app labeler coverage:** `apps/linux/README.md:1-3`
  - body: This PR adds a new `apps/linux/**` app surface, but `.github/labeler.yml` still only routes Android, iOS, macOS, and web UI app changes. Future Linux companion PRs will miss the intended app label/reviewer routing unless the labeler rule is added with the app.
  - confidence: 0.86
