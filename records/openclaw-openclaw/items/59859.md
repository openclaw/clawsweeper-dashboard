## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Preserve non-cron schedules on edit:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always sends `patch.schedule` as `{ kind: "cron", expr: ... }`, but existing Gateway jobs can be `at`, `every`, `cron`, or `on-exit`. Opening and saving a non-cron job can fail validation or rewrite scheduling even when the user only edits metadata.
  - confidence: 0.94
- **[P1] Keep session-scoped cron targets on edit:** `apps/linux/src/section_cron.c:351-352`
  - body: The target combo maps unknown targets to index 0 and saves that back as `isolated`, while Gateway accepts `session:<id>` as a valid cron target. Editing a session-scoped job can silently retarget it away from the intended session.
  - confidence: 0.93
- **[P2] Send supported verbose override values:** `apps/linux/src/section_sessions.c:176-184`
  - body: The Sessions UI sends `none`, `low`, and `high`, but `sessions.patch` parses verbose overrides as `off`, `on`, `full`, or null. These updates are rejected by Gateway validation, so users cannot change verbose behavior from this UI.
  - confidence: 0.91
- **[P2] Send explicit null when clearing session model:** `apps/linux/src/gateway_mutations.c:148-150`
  - body: Selecting the default model passes `NULL`, and this helper omits `model` entirely when the pointer is null. Gateway only clears an existing model override when `model: null` is present, so the old override remains in place.
  - confidence: 0.9
- **[P3] Add Linux app labeler coverage:** `apps/linux/meson.build:11`
  - body: This PR adds a new `apps/linux` app surface, but `.github/labeler.yml` still routes only Android, iOS, macOS, and web UI app paths. Root policy requires new app surfaces to update label routing, so future Linux app PRs would miss ownership labels.
  - confidence: 0.82
