Full review comments:

- **[P1] Resolve SecretRefs instead of rejecting gateway auth:** `apps/linux/src/gateway_config.c:370-374`
  - body: `gateway.auth.token` and `gateway.auth.password` SecretRefs are documented supported auth surfaces, but this validation rejects them as unsupported. Existing secure gateway setups that use SecretRefs would be unable to connect from the Linux companion instead of resolving through the existing secret contract.
  - confidence: 0.92
- **[P1] Preserve non-cron schedules when editing jobs:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always sends `schedule_kind = "cron"`, while existing cron jobs can use `every`, `at`, or other schedule variants. Saving a non-cron job after changing unrelated fields can rewrite or invalidate its schedule.
  - confidence: 0.9
- **[P2] Resolve local logs from session IDs:** `apps/linux/src/section_sessions.c:265-266`
  - body: This probes `<storeDir>/<session-key>/transcript.jsonl`, but current transcript resolution uses sessionId/sessionFile candidates as direct files under the sessions directory. The Log action will usually miss local transcripts and fall back to the dashboard, failing in offline or no-dashboard contexts.
  - confidence: 0.88
- **[P2] Bracket IPv6 hosts before composing URLs:** `apps/linux/src/gateway_config.c:1153-1155`
  - body: Interpolating `config->host` directly into `scheme://host:port` makes IPv6 literals such as `::1` produce malformed URLs like `http://::1:18789/`. That breaks dashboard, health, and WebSocket handoffs for valid IPv6/custom-bind setups.
  - confidence: 0.84
- **[P3] Add labeler routing for the Linux app surface:** `apps/linux/meson.build:1`
  - body: Root policy requires new app surfaces to update labeler/GitHub labels, but this branch adds `apps/linux` without labeler coverage. Future Linux app PRs would miss the same app-surface routing used by the other companion apps.
  - confidence: 0.86
