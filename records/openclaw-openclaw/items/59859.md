## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Preserve non-cron schedules when editing jobs:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always sends `schedule.kind = "cron"` and writes the textbox into `expr`. Current cron jobs may be `at`, `every`, `cron`, or `on-exit`, so saving an existing non-cron job can change its schedule shape or fail validation even when the user only edits metadata.
  - confidence: 0.94
- **[P1] Keep session-scoped cron targets on edit:** `apps/linux/src/section_cron.c:351-352`
  - body: The target selector only preserves fixed choices and maps unknown targets through index 0, which serializes back to `isolated`. Current cron contracts accept `session:<id>`, so editing a session-scoped job can silently retarget future runs.
  - confidence: 0.93
- **[P2] Send supported verbose levels:** `apps/linux/src/section_sessions.c:176-184`
  - body: The verbose dropdown sends `none`, `low`, and `high`, but `sessions.patch` accepts `off`, `on`, `full`, or null. Any verbose change from this UI path is rejected instead of updating the session.
  - confidence: 0.95
- **[P2] Serialize null when clearing model overrides:** `apps/linux/src/gateway_mutations.c:148-150`
  - body: Selecting the default model passes a null model to the mutation helper, but the helper omits the `model` field when it is null. The gateway only clears a stored session model override on explicit `model: null`, so users cannot return a session to the default model.
  - confidence: 0.91
- **[P2] Allow empty values to clear skill secrets:** `apps/linux/src/section_skills.c:133-134`
  - body: The env/API-key dialog returns before sending an empty value, but the gateway treats empty `apiKey` and env values as delete operations. That prevents users from removing stale skill credentials or env overrides from the Linux app.
  - confidence: 0.9
- **[P2] Require an installId before sending skills.install:** `apps/linux/src/section_skills.c:80-88`
  - body: The Install button can call `skills.install` with no `installId`, and the mutation helper then omits the field. The legacy install schema requires a non-empty `installId` unless the request uses a `source` variant, so this path can turn a missing UI value into a gateway validation failure.
  - confidence: 0.84
- **[P3] Add labeler coverage for the Linux app:** `apps/linux/README.md:1`
  - body: This PR creates `apps/linux/**`, but `.github/labeler.yml` still has app labels only for Android, iOS, macOS, and web UI. New app surfaces are expected to update label routing, otherwise future Linux app changes will not receive the app label or reviewer routing.
  - confidence: 0.96
