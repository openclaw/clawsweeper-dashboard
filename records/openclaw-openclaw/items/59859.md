  - body: The edit path always serializes the schedule as `{ kind: "cron", expr }`. Editing an existing `at`, `every`, or `on-exit` job can therefore fail validation or rewrite its schedule even when the user only changes metadata.
  - confidence: 0.91

  - confidence: 0.9
