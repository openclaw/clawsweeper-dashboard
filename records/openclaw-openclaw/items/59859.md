## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Preserve existing cron schedule variants:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit save path always writes `patch.schedule` as `kind: "cron"` with an `expr`, but cron jobs can also be `at` or `every`. Saving an existing non-cron job after changing unrelated fields can rewrite or invalidate its schedule; carry the original schedule variant through the dialog or block unsupported variants.
  - confidence: 0.92
- **[P1] Keep session-scoped cron targets on edit:** `apps/linux/src/test_seams.c:47`
  - body: Valid cron targets include `session:<id>`, but this mapper treats any unknown target as index 0, which the edit save path serializes back as `isolated`. Editing a session-scoped job can silently retarget it away from its intended session.
  - confidence: 0.9
- **[P2] Send supported verbose override values:** `apps/linux/src/section_sessions.c:176-178`
  - body: The sessions verbose combo sends `none`, `low`, and `high`, while `sessions.patch` normalizes verbose overrides to `off`, `on`, or `full`. These UI changes will be rejected instead of updating the session setting.
  - confidence: 0.88
- **[P2] Send null when clearing session models:** `apps/linux/src/gateway_mutations.c:148-151`
  - body: Selecting the default model passes `NULL`, but the mutation helper omits `model` when the value is null. The gateway only clears an override when `model: null` is present, so this UI cannot clear an existing session model override.
  - confidence: 0.87
- **[P3] Add Linux app labeler coverage:** `.github/labeler.yml:139-148`
  - body: This PR adds a new `apps/linux/**` app surface, but the labeler still only maps Android, iOS, macOS, and web UI. Add Linux app coverage so future PRs route to the right app/owner labels.
  - confidence: 0.83
