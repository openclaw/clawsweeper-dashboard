Full review comments:

- **[P2] Send supported verbose levels:** `apps/linux/src/section_sessions.c:176-184`
  - body: The Verbose combo sends `none`/`low`/`high` as `sessions.patch.verboseLevel`, but current gateway parsing only accepts `off`/`on`/`full`. Changing this selector from the Linux app will be rejected instead of updating the session, so map the UI choices to the supported wire values before dispatching.
  - confidence: 0.94
- **[P1] Preserve cron schedule shape on edit:** `apps/linux/src/section_cron.c:270-279`
  - body: The edit save path always sends `schedule.kind = "cron"` with `expr`, even when the existing job is `every`, `at`, or `on-exit`. Saving metadata for a non-cron job can therefore reject the update or rewrite scheduling behavior; keep the original schedule variant unless the UI explicitly changes it.
  - confidence: 0.93
- **[P2] Read channel account labels from name:** `apps/linux/src/gateway_data.c:256-263`
  - body: `channels.status` account snapshots expose the friendly account label as `name`, but this parser reads `displayName`. Connected accounts then lose their configured label in the Channels UI and fall back to raw account IDs.
  - confidence: 0.88
