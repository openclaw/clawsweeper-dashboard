## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Preserve cron schedule variants on edit:** `apps/linux/src/section_cron.c:274-275`
  - body: The edit-save path always sends a cron schedule object, so saving an existing every, at, or on-exit job can rewrite or reject its schedule even when the user only changes metadata. Preserve the original schedule variant or block editing unsupported variants.
  - confidence: 0.92
- **[P1] Preserve session-scoped cron targets:** `apps/linux/src/section_cron.c:264-266`
  - body: The edit dialog maps valid session:<id> targets through a fixed combo and saves the selected built-in target, so saving an unrelated field can silently retarget a session-scoped job. Carry unknown/session-specific targets through unchanged unless the user explicitly changes them.
  - confidence: 0.88
- **[P2] Send supported verbose override values:** `apps/linux/src/section_sessions.c:176-184`
  - body: The Linux UI sends none, low, and high, but sessions.patch normalizes verboseLevel to off, on, full, or null. These updates will be rejected at runtime, so the verbose selector cannot reliably change session verbosity.
  - confidence: 0.93
- **[P2] Send null when clearing the session model:** `apps/linux/src/gateway_mutations.c:148-150`
  - body: Selecting the default model passes NULL into mutation_sessions_patch, and the helper omits model entirely. The gateway clears an override only when model is explicitly null, so this path leaves the old model override in place.
  - confidence: 0.9
- **[P3] Add Linux app labeler coverage:** `.github/labeler.yml:200-208`
  - body: This PR creates a new apps/linux app surface, but the labeler still only routes Android, iOS, macOS, and web UI app changes. Add Linux app coverage so future work routes to the right reviewers and labels.
  - confidence: 0.82
