## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Include offset in the sessions list cache key:** `src/gateway/sessions-list-result-cache.ts:40-54`
  - body: `sessions.list` accepts `offset`, and current selection slices rows with it before returning `offset`/`nextOffset`. This cache key includes `limit` but omits `offset`, so calls like `{limit: 50, offset: 0}` and `{limit: 50, offset: 50}` can share one cached result for 60 seconds and return the wrong page.
  - confidence: 0.94
- **[P1] Preserve client-scoped node list filtering:** `src/gateway/server-methods/nodes.ts:897-903`
  - body: Current main routes `node.list` through `listNodesForClient(client, ...)` so read-scoped/mobile clients cannot see other pending node approvals or capability declarations. This cached branch reconstructs `listKnownNodes` directly and drops `client`, so the cache needs to feed the current authorization projection instead of bypassing it.
  - confidence: 0.88
