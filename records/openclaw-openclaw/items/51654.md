## Summary

Keep open: current main and v2026.6.11 still lack a public `sessions_spawn.env` path for ACP sessions, and related env work covers per-agent config, sandbox per-call env, or credential scrubbing rather than this per-spawn ACP API.

## What This Changes

Request support for passing session-level environment variables into ACP sessions from `sessions_spawn`.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire schema, spawn, manager, ACPX/backend behavior, redaction, docs, and tests through that contract before closing this issue.

## Reproduction Assessment

Yes. Current main and v2026.6.11 source/docs show no `sessions_spawn.env` parameter and no env forwarding through ACP spawn, manager initialization, or ACPX session options.

## Solution Assessment

No, not as a raw env-map patch alone; the maintainable path needs a maintainer-approved credential boundary for validation, redaction, allowed sources, persistence, and interaction with inherited-env scrubbing.
