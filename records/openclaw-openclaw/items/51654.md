## Summary

Keep open: current main still lacks a public `sessions_spawn.env` path for ACP sessions. Related open work covers per-agent config env or adjacent env isolation, but it does not settle the per-spawn ACP session credential boundary requested here.

## What This Changes

Request support for passing per-spawn environment variables into ACP sessions through `sessions_spawn`.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire validation/redaction, tool schema, ACP spawn, manager initialization, ACPX session options, docs, and tests through that approved contract.

## Reproduction Assessment

Yes. Source inspection on current main shows no `sessions_spawn.env` parameter and no env forwarding through ACP spawn, manager initialization, or ACPX session options.

## Solution Assessment

No for a raw env-map patch alone. The maintainable path needs a maintainer-approved credential boundary covering allowed sources/keys, redaction, session reuse, and interaction with inherited-env scrubbing.
