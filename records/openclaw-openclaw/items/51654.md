## Summary

Keep open: current main and latest release still lack a public `sessions_spawn.env` ACP path, and the related open work covers per-agent env, sandbox env headers, or credential scrubbing rather than this per-spawn ACP API.

## What This Changes

Request support for passing session-level environment variables into ACP sessions through `sessions_spawn`.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire tool schema, ACP spawn, manager initialization, ACPX delegate options, validation, redaction, docs, and focused tests through that contract.

## Reproduction Assessment

Yes. Source inspection of current main and `v2026.6.11` shows no `sessions_spawn.env` parameter and no env forwarding through ACP spawn, manager initialization, or ACPX session options.

## Solution Assessment

No, not as a raw env-map patch alone. The maintainable path needs a maintainer-approved credential boundary for validation, redaction, allowed sources, persistence, and interaction with inherited-env scrubbing.
