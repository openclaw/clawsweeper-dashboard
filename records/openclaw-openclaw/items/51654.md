## Summary

Keep open: current main and the latest release still lack a public `sessions_spawn.env` path for ACP sessions. Related per-agent env and credential-scrubbing work is useful context, but it does not settle this credential-bearing per-spawn API.

## What This Changes

The issue requests an optional `env` map on `sessions_spawn` for ACP/acpx sessions so each spawn can pass session-specific environment variables to its harness subprocess.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire tool schema, ACP spawn, manager initialization, ACPX session options, validation, redaction, docs, and focused tests through that contract.
