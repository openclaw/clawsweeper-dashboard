## Summary

Keep open: current main and v2026.6.11 still lack a public `sessions_spawn.env` path for ACP sessions, while related env work covers adjacent per-agent, per-call sandbox, or credential-scrubbing concerns rather than this API.

## What This Changes

Request adds a per-spawn env map to `sessions_spawn` for ACP sessions so each ACP child can receive session-specific environment variables.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire tool schema, ACP spawn, manager initialization, ACPX session options, validation, redaction, docs, and focused tests through that contract.
