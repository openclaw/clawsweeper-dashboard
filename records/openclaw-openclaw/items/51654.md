## Summary

Keep this open: current main still lacks a public per-spawn ACP environment API, while the overlapping per-agent, sandbox-header, and exec SecretRef work does not decide whether model-callable `sessions_spawn.env` should exist.

## What This Changes

The issue requests session-level environment variables for ACP `sessions_spawn` calls so credentials and endpoint overrides can be scoped to one spawned ACP session.

## Best Possible Solution

Maintainers should first choose the credential boundary, then implement either a narrow safe ACP per-spawn env contract or explicitly route users to configured/operator-trusted env surfaces.

- **Reject per-spawn env injection:** Close the issue as too broad if model-callable env injection is outside the intended OpenClaw security boundary.
