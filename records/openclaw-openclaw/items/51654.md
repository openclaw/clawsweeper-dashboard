## Summary

Keep open: current main and the latest release still lack a public `sessions_spawn.env` path for ACP sessions. The related open work covers configured per-agent env, sandbox per-call env, or ACP credential scrubbing rather than this per-spawn ACP session API, so the remaining work needs maintainer product/security direction.

## What This Changes

The issue requests an optional `sessions_spawn.env` map that would set or override environment variables for ACP/acpx sessions at spawn time.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire tool schema, ACP spawn, manager initialization, ACPX session options, validation, redaction, docs, and focused tests through that contract.

## Reproduction Assessment

Yes. Source inspection of current main shows no `sessions_spawn.env` parameter and no env forwarding through ACP spawn, manager initialization, or ACPX session options.

## Solution Assessment

No, not as a raw env-map patch alone. The maintainable path needs a maintainer-approved credential boundary for validation, redaction, allowed sources, persistence, and interaction with inherited-env scrubbing.
