## Summary

Keep open: current main and v2026.6.11 still lack a public `sessions_spawn.env` path for ACP sessions. The related env work is useful context, but it covers configured per-agent env, trusted sandbox env, credential scrubbing, or model overrides rather than this per-spawn ACP session API.

## What This Changes

The issue requests an `env` map on `sessions_spawn({ runtime: "acp" })` so each ACP session can receive per-spawn environment variables.

## Best Possible Solution

Define one credential-safe ACP session env contract, then wire tool schema, ACP spawn, manager initialization, ACPX session options, validation, redaction, docs, and focused tests through that contract.
