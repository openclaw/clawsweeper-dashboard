## Summary

This PR has a P1 correctness gap: ordinary npm-global upgrades run post-core convergence in a fresh child, but the new fallback still discards that child’s installed-target compatibility host version. The narrow repair is to preserve the inherited value and cover the fresh-process route before merge.

## What This Changes

Pins post-core npm-plugin compatibility checks during global updates to the installed target OpenClaw version and adds focused regression coverage.

## Best Possible Solution

Use one installed-target compatibility value for both current-process and fresh-process post-core convergence, preserving the child handoff value when no explicit parameter is supplied, then prove the fixed npm-global upgrade path from an exact-head artifact.
