## Summary

Keeping open: the concrete pre-compaction flush prompt leak has been fixed, but current main still lacks a dedicated system/runtime diagnostic presentation and a product-level audience rule for which runtime-originated messages should be hidden versus shown distinctly.

## What This Changes

## Best Possible Solution

Define a shared runtime audience/provenance policy, hide agent-only internals, and render intentionally visible system/runtime notices with a dedicated diagnostic treatment across Control UI/WebChat and TUI.
