## Summary

Keeping open: current main fixed the concrete pre-compaction flush prompt leak, but the broader Control UI/WebChat audience and presentation rule for runtime/system messages is still missing and needs maintainer product direction.

## What This Changes

The issue requests rendering internal runtime/system-originated messages in a distinct UI block instead of normal user or assistant chat bubbles.

## Best Possible Solution

Define a shared runtime audience/provenance policy, hide agent-only internals, and render intentionally visible system/runtime notices with a dedicated diagnostic treatment across Control UI/WebChat and TUI.

## Solution Assessment
