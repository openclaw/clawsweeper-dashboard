## Summary

Keep open: current main hides or filters several concrete internal-message leaks, including the pre-compaction flush follow-up, but it still lacks a shared audience/provenance rule and a dedicated visible system/runtime presentation across Control UI and TUI. The open continuation-message issue overlaps but is narrower and adds dispatch behavior that does not fully replace this broader UI request.

## What This Changes

The issue asks for internal/runtime-originated messages to render separately from normal user and assistant chat bubbles.

## Best Possible Solution

Define a shared audience/provenance policy, hide agent-only internals, and render intentionally visible system/runtime notices with a dedicated diagnostic treatment in Control UI/WebChat and TUI.
