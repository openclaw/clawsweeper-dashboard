## Summary

Keep open: current main fixes several concrete internal-message leaks, including the pre-compaction flush transcript bug, but it still has no shared audience/provenance policy or dedicated visible system/runtime treatment across Control UI/WebChat and TUI.

## What This Changes

Request to render internal runtime/system messages in Control UI/TUI as clearly non-user/non-assistant diagnostic blocks instead of normal chat bubbles.

## Best Possible Solution

Define a shared audience/provenance policy, hide agent-only internals, and render intentionally visible system/runtime notices with a dedicated diagnostic treatment in Control UI/WebChat and TUI.
