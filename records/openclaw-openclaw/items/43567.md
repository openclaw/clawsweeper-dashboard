## Summary

Keep open: the concrete pre-compaction memory-flush leak is already fixed, but current main still lacks a first-class system/runtime chat presentation; visible runtime/provenance rows are either hidden, projected into assistant/user/tool roles, or rendered by generic role grouping.

## What This Changes

Render internal system/runtime messages in a clearly distinct UI treatment instead of allowing visible internal rows to look like normal chat traffic.

## Best Possible Solution

Define a gateway-visible audience/kind contract for intentional runtime/system rows, then render those rows as labeled diagnostic blocks in Control UI and TUI while continuing to hide agent-only prompts such as memory flush.
