## Summary

## What This Changes

The issue requests that internal system/runtime messages be shown separately from normal user and assistant chat bubbles when they are intentionally visible.

## Best Possible Solution

Define a shared audience/provenance policy, hide agent-only internals, and render intentionally visible system/runtime diagnostics distinctly in Control UI/WebChat and TUI.
