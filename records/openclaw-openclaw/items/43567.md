## Summary

Keep open: the concrete pre-compaction memory-flush leak has a merged fix, but current main still lacks a generic runtime/system audience contract and a shared distinct presentation for visible system-originated chat rows.

## What This Changes

Request to render internal/runtime/system messages in a clearly distinct UI treatment instead of ordinary chat bubbles.

## Best Possible Solution

Define a shared runtime/system audience and provenance contract first, then hide agent-only internals and render deliberately visible runtime notices through a dedicated diagnostic block across Control UI/WebChat and TUI.

## Reproduction Assessment

No live current-main repro was run. Source inspection shows generic role: system rows can still flow through the normal grouped message path while only selected artifacts such as compaction, heartbeat, display=false, and subagent announce get special handling.

## Solution Assessment

No; a display-only colored block is only a partial presentation fix. The more maintainable solution is to choose the runtime-message audience/provenance contract before wiring projection and UI rendering.
