## Summary

Keeping open: the concrete pre-compaction memory-flush prompt leak has been fixed and released, but current Control UI/WebChat still lacks the requested dedicated system/runtime diagnostic presentation and the product-level audience rule for which runtime messages should be hidden versus shown distinctly.

## Best Possible Solution

Define a shared runtime audience/provenance policy first, then hide agent-only internals and render intentionally visible system/runtime notices with a dedicated diagnostic treatment across Control UI/WebChat and the TUI.
