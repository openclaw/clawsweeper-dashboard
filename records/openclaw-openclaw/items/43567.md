## What This Changes

The issue asks for internal system/runtime messages to render in a distinct UI treatment instead of normal user or assistant chat bubbles.

## Best Possible Solution

Define one shared audience/provenance policy, hide agent-only internals, and render intentionally visible system/runtime diagnostics distinctly in Control UI/WebChat and TUI.

## Solution Assessment

No, a standalone visual block is only a partial solution. The maintainable path should first define the audience/provenance contract, then hide agent-only internals and render intentionally visible diagnostics distinctly.
