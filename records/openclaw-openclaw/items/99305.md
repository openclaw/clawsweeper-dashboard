## What This Changes

The issue requests fixing Amazon Bedrock Claude Sonnet 5 prompt caching so OpenClaw attaches Bedrock cache points and produces cache reads/writes on repeated long-context turns.

## Best Possible Solution

Update the Amazon Bedrock plugin's Claude prompt-cache eligibility for AWS-supported Sonnet 5/profile identifiers, add focused regression tests, and capture live Bedrock cache counter proof when credentials are available.
