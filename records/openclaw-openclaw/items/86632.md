## Summary

Close as implemented: the shipped lean local-model path now keeps policy-permitted `exec` directly visible beside structured Tool Search controls, resolving the reported dead end where a local model searched for a weather tool and concluded that no executable live-data path existed. The remaining quality of an individual local model's shell command is model behavior rather than an unavailable OpenClaw execution route. ## What This Changes

Provide local embedded Ollama/Qwen sessions a discoverable shell execution path for live-data requests when execution is allowed, rather than leaving them only with unsuccessful weather-tool discovery.

## System Context

Local-model lean mode reduces the tools shown directly to smaller local models while retaining a searchable catalog for the rest. Embedded and harness agent runs construct that tool surface before the model selects a tool, then normal policy, sandboxing, and approval checks govern execution.
