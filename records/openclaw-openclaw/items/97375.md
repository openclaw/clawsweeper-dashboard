## What This Changes

Adds a structured `openclaw doctor` check that finds model references absent from the prepared runtime catalog and repairs affected agent, hook, message, and channel configuration fields.

## System Context

OpenClaw builds a prepared model catalog from configured and runtime provider information, while doctor checks inspect persisted `openclaw.json` and can write repairs. This PR connects the catalog to a new doctor contribution that alters model references later consumed by agent selection, hooks, text-to-speech, and channel routing.

## Best Possible Solution

Restrict automatic repair to references whose provider is definitively absent, preserve parseable references owned by present providers even when their exact model row is absent, and report unrecoverable required references without selecting an arbitrary replacement.
