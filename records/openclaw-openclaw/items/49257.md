## Summary

Keep open: current main still lacks the requested session-only, copyable pre-auth Control UI connection diagnostic log; the remaining work is useful but needs an explicit security/product decision before implementation.

## What This Changes

The issue requests a Control UI debug mode that captures ephemeral WebSocket connection lifecycle, handshake, close, and error details with copy-to-clipboard support.

## Best Possible Solution

Add a login-gate-accessible in-memory diagnostic drawer using sanitized client-side connection timing, close codes, and redacted error details, with gateway log tailing kept behind authenticated `operator.read`.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: What pre-auth connection diagnostics may the Control UI expose and make copyable without weakening the auth, device, and privacy boundary?

Rationale: The feature intentionally surfaces auth-adjacent handshake, device, origin, close, and error details before a trusted session exists, so automation should not choose the disclosure and redaction policy.

Likely owner: Peter Steinberger

Owner reason: The disconnected login gate and auth-adjacent recovery UI are the central placement and disclosure boundary for this decision.

Owner confidence: high

Options:

- **Sanitized client-only diagnostics (recommended):** Expose only sanitized client-side connection timing phases, close codes, redacted error details, and copy support before auth, while leaving `logs.tail` post-auth only.
- **Authenticated-only full diagnostics:** Keep pre-auth UI limited to categorized failure guidance and expose richer gateway logs only after authentication with `operator.read`.
- **Support export workflow:** Design an explicit support export action that combines redacted client diagnostics with authenticated gateway log tails under user consent.

## Solution Assessment

Unclear until maintainers choose the disclosure boundary; the best shape is likely a narrow client-side sanitized diagnostic drawer using the existing connection timing hook, not an unrestricted pre-auth gateway log stream.
