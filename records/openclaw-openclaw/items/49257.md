## Summary

Keep open: current main has structured connect-error messages, sanitized connect timing hooks, and a connected-only Debug event log, but it still lacks the requested opt-in, session-only, copyable pre-auth Control UI connection diagnostic transcript. The linked implementation PR was closed unmerged and had build-blocking review feedback, so it is evidence of demand, not a landed fix.

## What This Changes

The issue requests a session-only Control UI diagnostic mode that exposes WebSocket connection lifecycle, handshake, close/error details, and copyable logs for troubleshooting failed gateway connections.

## Best Possible Solution

Approve and implement a sanitized, opt-in, in-memory Control UI diagnostic transcript available from the disconnected login gate and Debug page, with explicit redaction, copy/export labeling, and no localStorage/IndexedDB persistence.
