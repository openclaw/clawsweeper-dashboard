Keep open: current main and the latest release still lack a session-only, copyable pre-auth Control UI connection diagnostic log. The request is useful, but it needs maintainer product/security direction because browser-visible handshake, device, auth, close-code, and network details need an approved redaction and copy policy.

## What This Changes

Request a Control UI diagnostic mode that captures WebSocket lifecycle, handshake, gateway close/error details, and copyable ephemeral logs without persisting them beyond the browser session.

## Best Possible Solution

Define a narrow, opt-in, session-memory Control UI diagnostic surface with approved pre-auth event fields, redaction rules, copy/export behavior, and retention limits, then integrate it with the existing login/Debug surfaces rather than adding a separate diagnostics model.
