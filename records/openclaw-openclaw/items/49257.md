## Summary

Keep open: current main still lacks the central requested behavior, a session-only, copyable pre-auth Control UI connection diagnostic log. Existing code provides categorized login failure guidance, a connected-only Debug page event log, a post-connect Logs tab, and an internal sanitized connection timing hook, but no login-gate-accessible diagnostic drawer or approved pre-auth disclosure policy.

## What This Changes

Add a Control UI diagnostic mode that exposes ephemeral WebSocket connection lifecycle, handshake, close, and error details in the browser without durable storage after the tab closes.

## Best Possible Solution

Add a login-gate-accessible, in-memory diagnostic drawer that uses sanitized client-side connection timing and redacted error details, includes copy support, never writes to durable browser storage, and keeps gateway-side log streaming behind authenticated operator.read access.
