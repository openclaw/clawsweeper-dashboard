## Summary

Keep open: current main still lacks the central requested session-only, copyable pre-auth Control UI connection diagnostic log, and the only direct implementation PR was closed unmerged.

## What This Changes

Add a session-only Control UI diagnostic mode that captures WebSocket connection lifecycle events, close/error details, and copyable logs without durable browser storage.

## Best Possible Solution

Add a login-gate-accessible, memory-only diagnostic drawer using sanitized client-side connect timing and redacted close/error details, with copy support, while keeping gateway-side log streaming behind authenticated operator.read access.
