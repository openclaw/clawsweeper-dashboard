## What This Changes

Add a Control UI debug mode that captures and displays copyable ephemeral WebSocket connection and pre-auth error diagnostics without durable browser storage.

## Best Possible Solution

Add a maintainer-approved, login-gate-accessible, memory-only diagnostic drawer that uses sanitized client-side timing, close-code, and redacted error facts, while keeping gateway log tails behind authenticated operator.read access.
