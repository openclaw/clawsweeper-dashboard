## Summary

Keep open: current main still lacks a session-only, copyable pre-auth Control UI connection diagnostic log, and the only direct implementation PR was closed unmerged with build-breaking review feedback.

## What This Changes

This issue requests an ephemeral Control UI debug mode that captures WebSocket connection lifecycle, handshake/error details, close codes, and optional authenticated log tails without persisting them beyond the browser session.

## Best Possible Solution

Add a login-gate-accessible, memory-only diagnostic drawer using sanitized client-side connection timing and redacted close/error details, while keeping gateway log tails behind authenticated operator.read access.

- **Consent-Based Support Export:** Design a broader export that combines redacted client diagnostics with authenticated gateway logs after connection succeeds.
