## Summary

Keep open: current main has structured connect-error details, connected-only Debug/Logs pages, and post-connect event logging, but not the requested opt-in, session-only, copyable pre-auth Control UI connection diagnostic transcript. The direct implementation attempt is closed unmerged and had build-blocking review feedback, so it is useful context rather than a landed fix.

## What This Changes

The issue requests an opt-in Control UI diagnostic mode that records session-only connection lifecycle logs, handshake/error details, gateway close data, and copyable support diagnostics for failed gateway connections.

## Best Possible Solution

Add a Control UI-owned, opt-in diagnostic drawer that records a redacted in-memory transcript for the current tab session: lifecycle phases, sanitized connect.challenge/connect metadata, structured detail codes, close codes/reasons, timing, and a copy action that never writes to localStorage or IndexedDB.
