Likely owner: steipete

Owner confidence: high

Options:

- **Sanitized Client Diagnostics (recommended):** Expose only client-side timing phases, close codes, redacted error codes/details, and copy support before auth; keep gateway log tails post-auth.
- **Authenticated Diagnostics Only:** Keep pre-auth UI to categorized failure guidance and expose richer gateway logs only after operator.read is available.
- **Consent-Based Support Export:** Design a broader export that combines redacted client diagnostics with authenticated gateway logs after connection succeeds.
