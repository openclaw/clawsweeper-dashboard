## Summary

Keep open: current main still lacks a copyable, session-only pre-auth connection diagnostic surface. The existing login gate shows categorized failure help and a raw-error detail, while Debug and Logs still require a connected Gateway client; the linked implementation PR is closed unmerged, so this remains product/security design work.

Add a Control UI debug mode that captures ephemeral WebSocket lifecycle, handshake, close, and error details without persistent browser storage.

## Best Possible Solution

Define a narrow in-memory diagnostics panel on the login/connection surface with approved redaction, retention, and copy/export behavior, while keeping connected Debug and Logs as separate tools.
