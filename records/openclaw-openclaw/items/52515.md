  - body: This helper is exported through the plugin SDK baseline and is used by runtime/plugin readers.   - confidence: 0.86

  - body: `renderGatewayServiceCleanupHints()` now returns `[]` when called without a service list, but status output still calls it with no arguments after reporting `extraServices`. That makes `openclaw status --deep` report extra gateway-like services without any cleanup hint.
  - confidence: 0.93
- **[P2] Preserve manual hints for skipped legacy services:** `src/commands/doctor-gateway-services.ts:439-442`
  - body: Filtering every legacy service out before rendering hints drops the only manual cleanup guidance when cleanup is skipped by policy, declined, fails, or is system-scoped. Doctor still reports the service but no longer gives an actionable command.
  - confidence: 0.89
- **[P2] Honor service scope in cleanup commands:** `src/daemon/inspect.ts:38-46`
  - body: The helper receives `svc.scope` but always emits user-domain launchctl and `systemctl --user` commands. For `doctor --deep` findings from system LaunchDaemons or systemd directories, the printed recipe targets the wrong service manager and leaves the detected service installed.
  - confidence: 0.9
