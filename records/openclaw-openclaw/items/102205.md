## Summary

Keep open: current main still classifies top-level `acp` config changes as gateway restarts while ACP config auto-enables `acpx`, and the remaining fix is already owned by the open candidate PR https://github.com/openclaw/openclaw/pull/102212.

## What This Changes

The issue reports that adding ACP config while the gateway is running can make `acpx` disappear after a self-triggered restart and leave the gateway in a restart loop.

## Best Possible Solution

Land one canonical ACP hot-reload fix that covers both running-gateway ACP config edits and fresh-start `acpx` activation, then close this issue with the merged PR as proof.
