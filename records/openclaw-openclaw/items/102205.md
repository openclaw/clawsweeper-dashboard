## Summary

Keep open: current main and the latest release still have the ACP auto-enable and gateway restart-planning behavior described by the report, and the open linked fix PR should own the landing path before this issue closes.

## What This Changes

The issue reports that adding top-level ACP config while the gateway is running auto-enables `acpx`, schedules a gateway restart, and then loops because `acpx` is absent after the self-triggered restart.

## Best Possible Solution

Land or replace the linked gateway fix so top-level ACP config changes hot-reload the plugin/runtime path and the running gateway stabilizes with `acpx` loaded.
