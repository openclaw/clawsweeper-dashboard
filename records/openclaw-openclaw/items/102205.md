## What This Changes

The issue reports that adding ACP config to a running gateway makes ACP auto-enable `acpx`, schedules a gateway restart, then loses `acpx` after the self-triggered restart and repeats the restart loop.

## Best Possible Solution

Land a narrow gateway reload-planner fix that treats ACP config changes as plugin hot reloads with regression coverage, then close this issue after the fixing PR merges and coordinate any remaining fresh-start activation work through https://github.com/openclaw/openclaw/issues/102221.
