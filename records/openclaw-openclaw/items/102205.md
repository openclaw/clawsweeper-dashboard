## Summary

Keep open: current main and the latest release still lack an ACP-specific reload rule, so ACP config changes still fall through to a gateway restart; the central fix is now owned by open PR https://github.com/openclaw/openclaw/pull/102212 and should close this issue only after it or an equivalent fix lands.

## What This Changes

The issue reports that adding ACP configuration while the gateway is running can auto-enable acpx, schedule a restart, then fail to reload acpx after the restart and repeat.

## Best Possible Solution

Land one canonical fix, likely https://github.com/openclaw/openclaw/pull/102212 or an equivalent replacement, that hot-reloads ACP config through plugin reload and preserves fresh-start acpx activation, then close this issue with the merge proof.
