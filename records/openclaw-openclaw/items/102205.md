Keep open: current main still treats top-level `acp` config changes as restart-required, and the linked fix PR is open and unmerged, so this issue should remain open until that candidate lands or is replaced.

## What This Changes

The issue reports that adding ACP config while the gateway is running auto-enables acpx, schedules a gateway restart, then loses the acpx backend and repeats the restart cycle.

## Best Possible Solution

Review and land exactly one focused ACP reload fix so top-level ACP config changes hot-reload plugin services and include regression coverage for the running-gateway add path.
