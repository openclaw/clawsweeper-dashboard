## What This Changes

The issue asks OpenClaw to stop the ACP config self-restart path from dropping the `acpx` backend and looping after `acp` config is added while the gateway is running.

## Best Possible Solution

Fix the gateway/acpx lifecycle so adding ACP config while the gateway is running results in one restart, loads `acpx`, and does not request another restart unless the source config changes again.
