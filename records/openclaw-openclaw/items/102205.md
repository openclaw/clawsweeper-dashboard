## What This Changes

The issue reports that adding ACP config to a running gateway auto-enables `acpx`, triggers a self-restart, then loops because the ACPX backend is not loaded after the restart.

## Best Possible Solution

Review and land one canonical hot plugin-reload fix from https://github.com/openclaw/openclaw/pull/102212 or an equivalent branch, then close this issue after merge while keeping https://github.com/openclaw/openclaw/issues/102221 open if the fresh-start activation gap remains distinct.
