Likely related people: LZY3538 (high confidence) for the preceding merged context-accounting work.

## What This Changes

The branch preserves exact nonzero per-call usage through aborted embedded-agent runs and stops aggregate attempt usage from being treated as a session context snapshot.

## Best Possible Solution

Land the exact-snapshot approach only after an owner confirms that fail-closed unknown context is the intended behavior when no authoritative current-context snapshot exists, then rebase and validate the final merge head.
