## Summary

Current main still allows cumulative non-CLI usage to become the persisted context snapshot, while this PR carries the latest trustworthy per-call usage through abort settlement and session persistence. The linked live reproduction distinguishes the released bug, the insufficient initial fix, and the current head; the competing PR does not cover the zero-usage abort path, so this remains the stronger landing candidate with no actionable correctness finding found.

## What This Changes

Preserves the latest nonzero assistant-call usage across a later zero-usage abort and prevents aggregate billing usage from being persisted as current session context.

## Best Possible Solution

Land one canonical implementation that carries an exact per-call usage snapshot from subscription through attempt settlement and session persistence, while treating context as unknown when no trustworthy snapshot exists; then resolve the linked issue and superseded competing PR.
