## Summary

Keep this PR open for maintainer review. The exact-head patch appears to preserve the intended distinction between cumulative billing usage and a current per-call context snapshot, and the provided live scenario plus focused regression coverage support the fix; however, it deliberately changes session-state behavior when no trustworthy snapshot exists, so the protected `maintainer` label and member authorship require an explicit maintainer decision before merge.

## What This Changes

The branch preserves the latest nonzero per-call usage through aborted embedded-agent runs and stops aggregate attempt usage from being stored or consumed as a current session-context snapshot.

## Best Possible Solution

Preserve aggregate usage only for billing/cost metadata, use an exact current-attempt or last-call snapshot for context decisions, and leave the context snapshot unknown when no trustworthy snapshot exists; merge once the responsible owner confirms that conservative contract and the exact-head checks are green.
