## Summary

Keep open: current main still rejects file-backed Mac node approval snapshots when `lastUsedAt` has fractional milliseconds, and the protected `maintainer` label blocks conservative cleanup closure. The source path is clear: the Mac App stores a `Double` timestamp, while Gateway protocol validation still requires an integer before returning the node approvals CLI payload.

## What This Changes

The issue asks Gateway node approval snapshot validation to accept shipped Mac App file-backed allowlist entries whose `lastUsedAt` timestamp can include fractional milliseconds.

## Best Possible Solution

Widen only the file-backed exec approvals `lastUsedAt` contract to accept finite non-negative numeric milliseconds, keep node snapshot validation fail-closed for malformed payloads, and add focused protocol plus Gateway regression coverage for a fractional Mac timestamp.
