## Summary

The requested read-only context-composition diagnostics already exist. Current OpenClaw exposes `/context list`, `/context detail`, `/context map`, and `/context json` for the active session; they report the system prompt, injected workspace files, skill entries, tool schemas, tracked transcript contributors, and approximate token sizes without dumping prompt contents. The shipped `/context map` addition completed the operator-facing contributor view, so a parallel `context inspect` API/CLI would duplicate the established surface.

## What This Changes

Expose read-only per-session diagnostics that explain which context sources contribute to the effective model prompt and approximate token budget.

## System Context

The agent runtime assembles a system prompt, session transcript, tool definitions, skills, and context-engine output before calling a model. The `/context` command reads the persisted run report or an on-demand estimate and presents safe contributor sizes to the operator.

## Architecture Diagram

## Best Possible Solution

Keep the established `/context` diagnostic family as the canonical operator surface; only extend it when a concrete missing contributor category is demonstrated, rather than adding a parallel CLI or plugin API.
