## Summary

Keep open: current main and the latest release still compose Anthropic OAuth beta headers before user/model headers, so a model-level `anthropic-beta` can replace the OAuth-required beta; the linked fork PR is still open, conflicting, and targets the old `pi-embedded-runner` path.

The issue asks OpenClaw to preserve Anthropic OAuth beta headers when users configure Anthropic beta headers at the model level.

## Best Possible Solution

Preserve OpenClaw-generated Anthropic OAuth betas when merging configured Anthropic beta headers in the active direct transport and provider package, while keeping custom endpoint suppression and GA 1M cleanup intact.
