## Summary

Keep open: current main still allows a model-level Anthropic `anthropic-beta` header to replace the generated OAuth-required beta in the active direct Anthropic transport path, so the reported OAuth 401 regression remains source-reproducible.

## What This Changes

The issue requests preserving Anthropic OAuth beta headers when `context-1m-2025-08-07` is configured through model-level headers instead of `params.context1m`.

## Best Possible Solution

Merge a narrow current-main fix in direct Anthropic header composition that combines generated OAuth/default betas with model-level beta values for direct Anthropic endpoints, preserves custom endpoint beta suppression, and adds regression coverage for OAuth plus model-level `anthropic-beta`.
