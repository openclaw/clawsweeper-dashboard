## Summary

Keep open: current main and the latest release still let a model-level Anthropic `anthropic-beta` header replace the OAuth-required beta header in the direct Anthropic OAuth path, so the reported 401 regression remains source-reproducible.

## What This Changes

The issue reports that Anthropic OAuth tokens fail with HTTP 401 when `context-1m` is configured through model-level headers because `oauth-2025-04-20` is not preserved.

## Best Possible Solution

Merge a narrow current-main fix that combines direct Anthropic OAuth-required betas with model-level beta values, strips retired `context-1m` values from all header config paths, preserves custom endpoint beta suppression, and adds focused direct OAuth/model-header regression coverage.
