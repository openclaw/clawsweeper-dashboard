## Summary

Keep open: current main still lets a model-level Anthropic `anthropic-beta` header replace the generated OAuth-required beta in direct Anthropic OAuth requests, so the reported 401 regression remains source-reproducible.

## What This Changes

This issue reports Anthropic OAuth 401s when model-level `anthropic-beta` headers replace the OAuth-required beta header for direct Anthropic requests.

## Best Possible Solution

Merge a narrow current-main fix that combines generated direct-Anthropic OAuth/default betas with model-level beta values, strips retired `context-1m-*` values, preserves custom endpoint beta suppression, and adds regression coverage for direct OAuth plus model-level `anthropic-beta`.
