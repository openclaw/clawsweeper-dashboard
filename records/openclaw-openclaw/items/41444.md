## Summary

Keep open: current main still allows a configured Anthropic model-level `anthropic-beta` header to replace the generated OAuth-required beta header in direct Anthropic OAuth requests, and related merged GA work or closed PRs do not fix this exact model-header path.

## What This Changes

The issue asks OpenClaw to preserve or inject `oauth-2025-04-20` for Anthropic OAuth tokens when `context-1m` is configured through model-level headers.

## Best Possible Solution

Merge a narrow current-main fix in direct Anthropic header composition that preserves OAuth-required betas while merging model-level beta values for direct Anthropic endpoints, keeps custom endpoint beta suppression intact, and adds regression coverage for OAuth plus model-level `anthropic-beta`.
