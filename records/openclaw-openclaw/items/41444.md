## Summary

Keep open: current main still has a source-level path where a direct Anthropic OAuth request builds the required `oauth-2025-04-20` beta, then lets a model-level `anthropic-beta` header replace it before the request is sent. The linked open fork PR is conflicting and targets older runner logic, so it is not a safe canonical landing path by itself.

## What This Changes

The issue requests preserving Anthropic OAuth-required beta headers when a direct Anthropic model defines `anthropic-beta` through model-level headers.

## Best Possible Solution

Land a narrow current-main fix in the active direct Anthropic header composition that merges OAuth-required betas with model-level beta values for direct Anthropic endpoints, preserves custom endpoint beta suppression, and adds regression coverage for OAuth plus model-level `anthropic-beta`.
