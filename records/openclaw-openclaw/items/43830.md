## Summary

Keep open: current main has strong adjacent redaction, transcript, diagnostic, and SecretRef protections, but it still lacks the requested automatic user-visible final-output sanitization boundary for secrets and PII.

## What This Changes

Request automatic sanitization of agent outputs so API keys, tokens, passwords, and PII are redacted without relying on users or agents to invoke a skill manually.

## Best Possible Solution

Define a security-reviewed core output-sanitization boundary that reuses existing redaction infrastructure, documents defaults and false-positive behavior, and tests final replies, tool results, transcripts, plugins, and channel delivery paths.
