## Summary

Keep open: current main has strong log, transcript, diagnostic, and tool-payload redaction pieces, but it still lacks a maintainer-approved automatic sanitizer for final visible agent output and no merged related PR owns the full request.

## What This Changes

## Best Possible Solution

Keep this open for a maintainer/security design that defines the final-output redaction boundary, chooses core versus plugin ownership, and reuses existing redaction helpers and outbound hook seams instead of adding a parallel sanitizer stack.
