## What This Changes

The issue requests automatic sanitization of API keys, tokens, passwords, and PII in agent outputs, with configurable scope for tool outputs and final responses.

## Best Possible Solution

Define the security-reviewed core-vs-plugin boundary first, then reuse the existing redaction registry and tool redaction helpers in the approved final-reply and adjacent output sinks with focused docs and tests.
