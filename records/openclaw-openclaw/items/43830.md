## Summary

Keep open: current main has strong adjacent log, tool-payload, transcript, diagnostic, SecretRef, and internal-scaffolding protections, but it still lacks the requested automatic sensitive-data sanitizer for every final user-visible agent response.

## What This Changes

The issue requests an automatic sensitive-data sanitization boundary for agent outputs, with configurable modes and scopes for final responses and tool output.

## Best Possible Solution

Define the approved core-vs-plugin security boundary first, then reuse the existing redaction registry and helper stack in a narrow sanitizer with tests for final replies, tool payloads, transcripts, and channel delivery as applicable.
