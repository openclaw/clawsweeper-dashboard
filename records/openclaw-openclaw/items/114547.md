## What This Changes

The PR makes plugin metadata bootstrap use the installed-plugin index, preserves explicit plugin activation scopes, and replaces a multi-entry registry cache with one current process-wide metadata graph.

## System Context

OpenClaw builds plugin metadata from installed plugin manifests, then passes that metadata to plugin activation, provider/model discovery, and authentication resolution. This PR changes how that metadata is bootstrapped, scoped, cached, invalidated, and published to later control-plane consumers.
