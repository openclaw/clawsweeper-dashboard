## Summary

## What This Changes

The PR derives plugin bootstrap metadata from the installed-plugin index, keeps explicit empty or owner-scoped activation requests scoped, and replaces the registry’s historical memo set with one lifecycle-owned current snapshot.

## System Context

Plugin discovery builds an installed-plugin index and manifest registry, which produce metadata used by plugin activation and provider/model discovery. This PR changes when that metadata is published, reused, and cleared across registry lifecycle boundaries.
