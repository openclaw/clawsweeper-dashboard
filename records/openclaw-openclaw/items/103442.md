## Summary

The fix remains necessary: current main can leave Slack’s external byte upload pending indefinitely, and this PR addresses that boundary without timing out the commit-capable completion call. The exact head is technically strong and CI-clean, but merge should remain human-gated because it adds a public replay-safety plugin contract and the material Enterprise Grid routing added after the live proof still lacks exact-head real-workspace evidence.

## What This Changes

The PR adds a 120-second Slack external byte-upload timeout, replay-safe not-dispatched signaling, stricter upload transport policy, and separate Enterprise Grid read and zero-retry delivery clients.

## Best Possible Solution

Keep the timeout limited to the pre-finalization byte transfer, retain conservative handling for ambiguous completion calls, and land the public replay marker only after explicit owner acceptance plus exact-head Enterprise Grid runtime proof.
