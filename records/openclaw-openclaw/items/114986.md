## What This Changes

Fix Control UI assistant attachments so temporary availability failures retry and visibly recover after the existing five-second cooldown without requiring an unrelated rerender.

## System Context

The Control UI renders assistant-message attachment metadata received through the OpenClaw Gateway. Its attachment availability cache decides whether media is currently usable or should be retried, and that decision must trigger a visible message update when the cooldown expires.
