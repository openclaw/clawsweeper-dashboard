## Summary

Keep open: current main classifies the critical repetition correctly but converts it only into a vetoed tool result, so the model can continue issuing calls; the fresh v2026.6.11 logs demonstrate that this can leave a run consuming resources for hours.

## What This Changes

Terminate a stuck agent run when critical loop detection repeatedly blocks the same tool call instead of allowing further model retries.

## Best Possible Solution

Route a critical loop result into the canonical terminal-outcome and session-release path, record a clear stalled/tool-loop reason, and surface a concise failure to the user while leaving warning thresholds and post-compaction behavior unchanged.
