## What This Changes

Repair Codex catalog continuation so that, after adopting a session, the Control UI opens that adopted chat instead of remaining on the default chat route.

## System Context

The Control UI starts an external catalog continuation through the Gateway, which may adopt a new OpenClaw session. The resulting session identity must drive both the chat route and the composer so the visible conversation matches the destination receiving the draft.
