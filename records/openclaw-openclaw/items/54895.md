## Summary

Keep open. Current main still does not provide caller-visible progress streaming, `sessions_subscribe`, `agent.events`, or another buffered run-event read API for long-running peer `sessions_send` runs, and the remaining API/security shape needs maintainer design rather than cleanup closure.

## What This Changes

The issue requests caller-visible progress streaming or subscription support for long-running `sessions_send` peer session runs.

## Best Possible Solution

Add an additive, permission-checked run-progress observation contract with bounded replay and redaction, then expose it through `sessions_subscribe` or a maintainer-approved `sessions_send` progress option.
