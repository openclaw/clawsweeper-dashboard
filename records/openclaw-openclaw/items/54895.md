## Summary

Keep open. Current main and v2026.6.11 still have final/terminal wait and announce behavior for `sessions_send`, but no caller-visible inter-session progress stream, `sessions_subscribe` tool, or gateway `agent.events` read API for long-running delegated runs.

## What This Changes

The issue requests inter-session progress streaming or subscription support so a caller using `sessions_send` can observe long-running target-session work before final completion.

## Best Possible Solution

Choose one authorized run-progress event surface that covers `sessions_send` caller visibility and aligns with the broader structured process-events model, then implement it with focused permission, replay, timeout, and channel-delivery tests.
