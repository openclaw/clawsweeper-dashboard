## Summary

Keep open. Current main improves part of the timeout reporting path, but the central request remains missing: there is still no caller-readable run-event stream, `sessions_subscribe` tool, `agent.events` method, or bounded progress replay path for long-running peer `sessions_send` runs.

## What This Changes

Add caller-visible progress streaming or subscription for long-running `sessions_send` runs, especially ACP/Codex-backed sessions.

## Best Possible Solution

Define an additive, permission-checked run-progress observation contract with bounded replay, redaction, ordering, retention, and cleanup semantics, then expose it through a maintainer-approved `sessions_subscribe` tool or `sessions_send` progress option.
