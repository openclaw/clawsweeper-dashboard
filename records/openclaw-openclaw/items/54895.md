- `impact:session-state`: The missing capability is about observing another session run's progress, lifecycle, and final state from the requester session.

## Summary

Keep open. Current main now avoids treating an ordinary nonterminal `agent.wait` timeout as failed delivery, but it still has no caller-visible progress stream, `sessions_subscribe`, `agent.events`, or buffered delegated-run event API for long-running `sessions_send` work.

## What This Changes

Request caller-visible progress streaming or subscription support for long-running delegated `sessions_send` runs.

## Best Possible Solution

Define an additive, permission-checked run-progress observation contract with bounded replay and redaction, exposed through a maintainer-approved `sessions_subscribe` tool or `sessions_send` progress option.
