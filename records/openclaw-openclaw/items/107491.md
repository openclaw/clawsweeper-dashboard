Keep this issue open for clarification: OAuth refresh and runtime snapshots are real current surfaces, but the report names files absent from current main and provides no provider, version, logs, or request sequence proving that a failed refresh subsequently sends the stale access token.

## What This Changes

Prevent failed OAuth refresh attempts from leaving a stale runtime credential that causes repeated authentication failures.

## Best Possible Solution

Classify refresh failures at the provider-owned OAuth boundary: retain reusable refresh material after transient failures, never send an expired access token after refresh fails, surface a structured retryable error, and require re-authentication only for confirmed permanent credential rejection.
