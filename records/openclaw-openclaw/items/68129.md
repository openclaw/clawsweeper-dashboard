## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] List every allowed approval action in text prompts:** `src/infra/exec-approval-reply.ts:280-282`
  - body: The text fallback only renders `descriptors[0]`, so channels or copied logs that do not show buttons hide allowed decisions such as `deny` and `allow-always`. Text-only approval prompts need to show every allowed action command, not only the first approval path.
  - confidence: 0.93
- **[P1] Refresh session stores after maintenance yields:** `src/tasks/task-registry.maintenance.ts:381`
  - body: The mutating maintenance sweep creates one session-store cache for the full pass, then yields between batches. Session updates that land after a yield remain invisible to later `shouldMarkLost` checks, so active tasks can be marked lost from stale data.
  - confidence: 0.9
- **[P2] Make hidden exec stripping opt-in for general renderers:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatMarkdownPreprocessor.swift:49`
  - body: The preprocessor defaults hidden exec stripping to on, and the general chat renderer calls it without a role-aware opt-out. User-pasted `System ... Exec ...` logs can disappear from normal rendering even when decode preserved them.
  - confidence: 0.88
- **[P2] Do not warn on healthy symlinked installs:** `src/infra/update-check.ts:397-399`
  - body: The install-state detector treats every symlinked active root as suspicious and emits recovery guidance. Symlinked package roots are common for version managers or linked installs, so this can create persistent false drift warnings without an actual mismatch.
  - confidence: 0.86
- **[P2] Accept command-only openclaw gateway listeners:** `src/infra/ports-format.ts:32-33`
  - body: When listener discovery only reports `command: "openclaw"`, `isGatewayArgv` cannot see the `gateway` argument and the fallback only accepts `openclaw-gateway`. That misclassifies a valid gateway listener as unknown and can show a false busy-port warning.
  - confidence: 0.84
