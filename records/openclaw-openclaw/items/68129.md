Full review comments:

- **[P1] List every approval action in text prompts:** `src/infra/exec-approval-reply.ts:260-282`
  - body: `buildExecApprovalPendingText` builds descriptors for all allowed decisions but only renders `descriptors[0]`. Text-only clients and copied logs therefore hide deny/alternate commands, which weakens the command authorization path and can push users toward an unintended approval.
  - confidence: 0.9
- **[P1] Refresh session stores across maintenance yields:** `src/tasks/task-registry.maintenance.ts:381`
  - body: The mutating maintenance sweep creates one cached session-store context for the whole pass while the sweep yields between batches. Session entries created after a yield can be invisible to later `shouldMarkLost` checks, so active tasks can be marked lost from stale state.
  - confidence: 0.86
- **[P2] Make hidden-event stripping opt-in for render callers:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatMarkdownPreprocessor.swift:49-55`
  - body: `stripHiddenSystemEvents` defaults to true, and general markdown render callers still use the default. A user who pastes `System ... Exec ...` logs can have legitimate content stripped from display even though the hidden-event filter should apply only to injected assistant/system noise.
  - confidence: 0.84
- **[P2] Do not warn on healthy symlinked installs:** `src/infra/update-check.ts:397-399`
  - body: `detectInstallState` marks any symlinked root as suspicious, so version-manager or linked package installs can get integrity warnings and recovery hints even when the resolved root is healthy. Symlink status should not be a warning without an actual mismatch or unsafe path.
  - confidence: 0.82
- **[P2] Recognize command-only openclaw gateway listeners:** `src/infra/ports-format.ts:32-34`
  - body: The fallback gateway identity check only accepts the `openclaw-gateway` basename. When listener discovery provides only `command: "openclaw"` for a real `openclaw gateway run` process, status can report a false busy-port conflict instead of gateway-owned usage.
  - confidence: 0.78
