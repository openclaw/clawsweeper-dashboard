Full review comments:

- **[P1] List every allowed approval action in text prompts:** `src/infra/exec-approval-reply.ts:280-282`
  - body: `buildExecApprovalPendingText` builds descriptors for all allowed decisions but only renders `primaryAction` and its full-ID variant. Text-only clients and copied logs therefore hide deny or alternate approval commands, which weakens the command authorization path compared with current main’s secondary action text.
  - confidence: 0.9
- **[P1] Refresh session stores after maintenance yields:** `src/tasks/task-registry.maintenance.ts:381`
  - body: The mutating maintenance sweep creates one session-store cache before the loop and keeps using it after yielding to the event loop. Session entries created or updated during a yield can be invisible to later `shouldMarkLost` checks, so active work can be incorrectly marked lost.
  - confidence: 0.86
- **[P2] Make hidden exec stripping opt-in for general renderers:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatMarkdownPreprocessor.swift:49-55`
  - body: `stripHiddenSystemEvents` defaults to true, and `ChatMarkdownRenderer` still calls the preprocessor without passing the message context. A user who pastes `System ... Exec ...` logs can have legitimate text stripped from normal chat display.
  - confidence: 0.84
- **[P2] Do not warn on healthy symlinked installs:** `src/infra/update-check.ts:397-399`
  - body: `detectInstallState` marks every symlinked package root as suspicious and emits a recovery hint. Linked or version-manager installs can be healthy after realpath resolution, so symlink status alone should not produce an integrity warning.
  - confidence: 0.82
- **[P2] Accept command-only openclaw gateway listeners:** `src/infra/ports-format.ts:32-34`
  - body: The fallback gateway identity check only accepts the `openclaw-gateway` basename after `isGatewayArgv` fails. Listener probes that only provide `command: "openclaw"` for a real gateway process can now be classified as unknown and shown as a false busy-port conflict.
  - confidence: 0.78
