## What This Changes

This PR makes the WhatsApp login tool require a nonempty PNG data URL after its `data:image/png;base64,` prefix and adds a regression test that the model-facing schema pattern is fully anchored.

## System Context

The WhatsApp plugin exposes a login tool whose QR-data argument becomes part of the agent tool catalog sent to model providers. Grammar-constrained local providers translate that JSON Schema into a grammar before tool calling, so an unsupported regex can prevent the whole catalog from compiling.
