## What This Changes

The PR excludes `MEMORY.md` from shared channel bootstrap context, preserves it for private sessions, and moves session chat-type primitives into a dependency-safe module.

## System Context

Workspace bootstrap files such as `MEMORY.md` are assembled before an agent run and become prompt context. The session key identifies whether the run is private or shared, so this classification controls whether private persistent memory can reach a group conversation.
