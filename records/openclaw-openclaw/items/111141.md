## Summary

Keep this PR open: it addresses the reported stale-generation recovery path and now includes meaningful redacted terminal proof, but its version-maximizing recovery can override a valid persisted record after an intentional downgrade or version pin.

## What This Changes

The PR makes managed-plugin recovery choose the highest discovered semver across flat and generation directories, then repoints a stale managed persisted record to that newer path.

## Best Possible Solution

Keep a valid persisted install record authoritative for deliberate version selection, and repair the install/update path to atomically persist the newly written generation; recovery may self-heal only clearly stale or unavailable managed records.
