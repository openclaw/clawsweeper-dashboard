## Summary

Keep this PR open: its recovery direction addresses the reported stale-generation load, but the current head is unchanged from the prior review and still overwrites a valid persisted managed downgrade selection whenever a newer lingering generation is discovered.

## What This Changes

The PR makes managed-plugin recovery choose the highest discovered version across flat and generation project directories and repoint stale managed install records to that newer path.

## Best Possible Solution

Preserve an explicit persisted managed version or resolved selection, and repoint only records that can be identified as stale recovery metadata rather than an intentional downgrade; cover both upgrade recovery and retained-newer-generation downgrade cases.
