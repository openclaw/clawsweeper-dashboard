## What This Changes

The issue reports that memoryFlush is skipped for never-compacted sessions when both compaction counters are 0 because the dedupe guard treats that initial state as already flushed.

## Best Possible Solution

Review and land or reject https://github.com/openclaw/openclaw/pull/83015, preserving a real cycle-0 flush as already flushed while allowing legacy or never-flushed 0/0 rows to flush.
