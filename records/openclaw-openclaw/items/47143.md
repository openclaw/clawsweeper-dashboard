## What This Changes

The issue asks for memoryFlush to run for never-flushed sessions whose `compactionCount` and `memoryFlushCompactionCount` are both `0`.

## Best Possible Solution

Review and land or intentionally replace https://github.com/openclaw/openclaw/pull/83015, preserving once-per-cycle dedupe while distinguishing never-flushed 0/0 rows from real cycle-0 flush records.
