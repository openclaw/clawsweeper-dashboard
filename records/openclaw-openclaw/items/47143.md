## What This Changes

The issue requests fixing memoryFlush so never-compacted, never-flushed sessions with both compaction counters at 0 can still trigger a flush.

## Best Possible Solution

Review and land or intentionally replace https://github.com/openclaw/openclaw/pull/83015, with regression tests that distinguish never-flushed 0/0 rows from real cycle-0 flush records.

Yes. The narrow maintainable fix is to update the existing guard and focused tests, using `memoryFlushAt` or an equivalent explicit marker to preserve real cycle-0 dedupe while allowing never-flushed 0/0 rows to flush.
