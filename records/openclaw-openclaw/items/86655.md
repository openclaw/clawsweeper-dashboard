## What This Changes

This PR adds bundled Claude and GLM bridge harness extensions that spawn an external JSON-RPC bridge for Anthropic-compatible provider turns, along with new plugin configuration, auth forwarding, session handling, commands, UI integration, and plugin-SDK/runtime support.

## System Context

OpenClaw resolves an agent's provider, model, credentials, and tool policy, then dispatches the turn to a selected harness. This PR introduces Claude and GLM harness plugins that spawn an external bridge process, translate its JSON-RPC events into OpenClaw tools, channels, and session state, and persist bridge-thread metadata for later resume.
