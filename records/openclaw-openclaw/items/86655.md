## What This Changes

This PR adds Claude and GLM app-server harness plugins that run provider turns through a local JSON-RPC bridge, with new configuration, auth forwarding, session handling, operator commands, and related core/plugin-SDK integration.

## System Context

OpenClaw chooses an agent runtime for each model turn; an app-server harness can then run the turn through a local subprocess while translating tools, credentials, session state, and streamed output. This PR adds Claude and GLM implementations to that harness layer and feeds their results back into OpenClaw channel delivery and session management.
