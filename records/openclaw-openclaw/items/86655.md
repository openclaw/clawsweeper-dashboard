## What This Changes

This PR adds bundled Claude and GLM bridge harness extensions that spawn an external JSON-RPC bridge for Anthropic-compatible model turns, with new configuration, auth forwarding, session handling, commands, Control UI integration, and supporting runtime APIs.

## System Context

OpenClaw chooses an agent harness for each model turn; the harness then owns provider interaction while returning tool activity, auth context, session metadata, and reply events to the shared runtime. This PR adds a Claude-oriented harness that delegates turns to a local bridge process and feeds its results into existing session and channel-delivery paths.
