## Summary

Keep this PR open for explicit maintainer confirmation and real upgrade-path proof. It intentionally changes omitted code-mode configuration from off to automatic activation for catalog-preferred models, so it is a compatibility-sensitive product default rather than a routine resolver cleanup.

## What This Changes

This PR changes omitted `tools.codeMode.enabled` values to use per-model automatic activation and changes the Labs switch from force-on to Auto/Off behavior.

## System Context

Code mode determines whether an agent sees the compact in-sandbox tool bridge or the normal tool surface. Agent configuration and the Labs switch feed the code-mode resolver, while model-catalog capability flags decide whether the automatic tier engages for a particular run.
