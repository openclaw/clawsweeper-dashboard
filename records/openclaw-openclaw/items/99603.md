## Summary

Keep open: current main and the latest release still stop the watched gateway child before proving the replacement source-checkout build is ready, and the two related fix PRs are still open and unmerged.

## What This Changes

Prevent gateway hot-reload in source checkouts from restarting into half-built or missing dist output during a rebuild.

## Best Possible Solution

Prepare or validate the replacement build for the current checkout before stopping the healthy watched gateway child, then land one canonical fix PR with regression coverage.

## Reproduction Assessment

## Solution Assessment
