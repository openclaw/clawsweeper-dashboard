## What This Changes

The issue requests a fix for a gateway hot-reload race where a production source checkout can restart into a half-built `dist/` tree and crash-loop.

## Best Possible Solution

Land one reviewed watcher readiness fix that keeps the healthy child running until `dist/entry.js` and the build stamp are safe for the current checkout, then close this issue from the merged PR.

## Reproduction Assessment

Yes, a focused watcher readiness guard is the right repair boundary. The issue should remain open while maintainers review the competing open PRs and choose the safest implementation.
