## Summary

Keep open: current main and the latest release still restart the watched child without a replacement-build readiness gate, while open linked PRs still own candidate fixes for the reported crash-loop path.

## What This Changes

The issue requests that gateway hot reload avoid restarting into a half-built source checkout when dist entrypoints are missing during a rebuild.

## Best Possible Solution

Land one canonical watcher lifecycle fix that defers restarts on physically missing or unloadable build output, preserves normal watch rebuild behavior, and adds focused regression coverage for missing dist entrypoints.
