## Summary

Keep this PR open for redesign, but it is not mergeable in its current form: the proposed policy can be bypassed, the host never constructs the new service-context method, the browser example never receives it, and runtime payload validation and real behavior proof are missing. The paired issue and prerequisite PR are still open, so product and API direction should be settled there before stabilizing this public plugin contract.

## What This Changes

Adds six AI-safety diagnostic event types, a manifest-gated plugin emission helper and service-context method, plugin SDK exports, diagnostic handling, and browser navigation emission.

## Best Possible Solution

Land or redesign the core taxonomy separately, then expose one host-bound and plugin-attributed emission method at the normal plugin API boundary; normalize and type-check its manifest declarations, validate every payload at runtime, preserve real session identity, document the contract, and demonstrate allowed, rejected, malformed, and exported events in a live plugin run.
