  - confidence: 0.99

  - body: The patch adds only a TypeScript manifest property. Without loader/schema normalization that rejects unknown event names and produces the authoritative declaration consumed by the host-bound emitter, external-plugin permissions are not enforceable from installed manifests.
  - confidence: 0.99
- **[P1] Validate complete event payloads before dispatch:** `src/plugins/safety-event-emission.ts:102`
  - body: The wrapper checks only the event type before forwarding the object. JavaScript plugins can supply missing fields, invalid enums, non-finite scores, or other malformed values, so validate each discriminated payload at runtime and reject it before it reaches operator-facing diagnostics.
  - confidence: 0.98
- **[P1] Wire the browser example through a reachable capability:** `extensions/browser/src/browser-tool.ts:899`

  - body: `agentSessionKey` or `unknown` is not a reliable diagnostic session identifier, and the general API lets plugins select any `sessionId`. Bind the active diagnostic session in the host-created emitter so plugins cannot misattribute events across sessions.
  - confidence: 0.97
