## Summary

Keep open: the earlier remote-URL trust finding is addressed by eliminating checkout adoption, and the terminal proof is convincing, but the branch introduces forbidden file-backed persistent retry state and changes a public package-to-dev setup contract that needs explicit owner approval.

## What This Changes

The PR makes package-to-dev updates require a fresh Git checkout, sanitizes Git configuration for clone and follow-up commands, and adds durable ownership tracking for safe retries after failed conversions.

## Best Possible Solution

Keep fresh, config-sanitized cloning as the secure default, store retry ownership transactionally in the shared SQLite state database, provide actionable migration guidance for occupied paths, and preserve in-place updates only for installations already running from their own Git checkout.
