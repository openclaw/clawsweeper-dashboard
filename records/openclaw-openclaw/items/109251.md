## Summary

Keep open: the new head addresses the prior checkout-trust finding by refusing adoption and sanitizing Git execution, but the intentional compatibility break needs owner approval and the file-backed retry state should be repaired before merge. ## What This Changes

The PR makes package-to-dev conversion clone into an unused path with sanitized Git configuration, adds managed retry replacement state, and updates CLI tests and documentation.

## Best Possible Solution

Keep fresh-clone-only trust by default, store conversion ownership in the shared SQLite state database, and provide a guided no-adoption recovery path with fresh-install and upgrade proof.
