  - confidence: 0.95

  - body: The branch initializes and updates `stableNodePathPromise`, but `ensureChild()` never reads it and still passes `execPath: process.execPath`. Normal launches and later launches after a retry child exits can keep using the stale Cellar path.
  - confidence: 0.92
- **[P1] Replay the request after starting the retry child:** `packages/memory-host-sdk/src/host/embeddings-worker.ts:313-320`
  - body: The ENOENT handler starts a retry child, then immediately rejects every pending request. The initialize or embed request that triggered recovery is never resent to the retry child, so callers still see failure even if the second fork succeeds.
  - confidence: 0.93
