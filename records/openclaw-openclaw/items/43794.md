## Summary

Keep open: current main still allows plaintext credential persistence, while SecretRefs, owner-only file modes, audit/scrub helpers, and process-local sentinels are partial mitigations rather than native encrypted-at-rest storage.

## What This Changes

The issue requests native encrypted-at-rest protection for OpenClaw config and auth credentials, with keychain or master-password support and backward-compatible migration.

## Best Possible Solution

Define a maintainer/security-approved credential-at-rest design covering openclaw.json, per-agent auth storage, backups and legacy files, SecretRefs, doctor migration, recovery, rotation, and unattended startup.
