## What This Changes

The issue requests encrypted-at-rest handling for OpenClaw credentials and API tokens stored in local config and auth-profile data.

## Best Possible Solution

Land a maintainer/security-approved credential-at-rest design that covers openclaw.json, config backups, the active SQLite auth-profile store, doctor migration, key management, recovery, and rotation while keeping SecretRefs as a supported mitigation.
