## What This Changes

This PR lets the gateway treat a redacted local transcript message and its full-text CLI-imported counterpart as one message while preserving distinct messages that differ beyond redaction.

## System Context

The gateway combines the local transcript, which redacts sensitive-looking text before persistence, with history imported from a bound CLI runtime. The merged history feeds the Control UI, so its equivalence rules determine whether one user message is rendered once or twice.
