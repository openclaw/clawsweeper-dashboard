## What This Changes

The PR updates gateway transcript merging to recognize redacted and full-text copies of the same CLI-bound message while retaining separate messages that differ for reasons other than redaction.

## System Context

The gateway combines its local chat transcript with messages imported from a bound CLI session before the Control UI renders history. Local persistence redacts sensitive-looking text, while CLI imports can retain the full text, so the merge step must distinguish one logical message from genuinely distinct messages.
