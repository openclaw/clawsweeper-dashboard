## Summary

## What This Changes

Normalizes plugin policy and configuration IDs during enablement, validates and deduplicates manifest kinds, and prevents policy-blocked CLI enablement from writing config or changing plugin slots.

## System Context

OpenClaw's plugin control plane reads plugin manifests and persisted configuration, applies allow/deny and slot policy, then lets the CLI update that configuration and refresh the plugin registry. This PR aligns those paths around one canonical plugin identity so policy decisions and mutations produce the same effective state.
