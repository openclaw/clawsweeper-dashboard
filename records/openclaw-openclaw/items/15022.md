## What This Changes

## Best Possible Solution

Define a maintainer-approved opt-in delivery policy in the shared reply pipeline that covers both final payload assembly and block-streamed tool boundaries, then add config/schema/docs plus regression coverage for text-tool-text turns with channel metadata preserved.
