## Summary

Keep open: current main still lacks the requested opt-in coalescing or final-only delivery policy for tool-interleaved assistant text. The open Discord ordering PR at https://github.com/openclaw/openclaw/pull/87707 is related but targets streaming-off ordering, not this issue's one-turn single-message policy.

## What This Changes

Request an opt-in agent or channel delivery mode that merges assistant text blocks interleaved with tool calls into one outbound message per turn.

## Best Possible Solution

Define an explicit opt-in delivery policy for tool-interleaved assistant text, with config/schema/docs and regression coverage across final payload assembly plus streamed tool-start boundaries.
