## What This Changes

The issue requests a configuration-backed way to merge multiple assistant text blocks from one tool-using turn into one outbound channel message.

## Best Possible Solution

Define an explicit opt-in tool-interleaved text delivery policy in the core reply pipeline, with schema/docs and regression coverage for final payload assembly and block-streamed tool-start boundaries.
