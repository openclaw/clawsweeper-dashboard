## Summary

Keep open: current main has partial final-answer collapse for accumulated pre-tool text, but it still lacks an explicit opt-in coalescing or final-only delivery mode across tool-interleaved block streaming, and the remaining choice is product/config policy.

## What This Changes

The issue requests an opt-in mode that merges or suppresses multiple assistant text blocks from one tool-heavy agent turn before sending them as outbound channel messages.

## Best Possible Solution

Define an explicit opt-in tool-interleaved text delivery policy in the core reply pipeline, with schema/docs and regression coverage for final payload assembly plus block-streamed tool-start boundaries.
