## Summary

Keep open: current main still lacks the requested opt-in coalescing or final-only delivery policy for tool-interleaved assistant text, and the related open Discord PR targets ordering under streaming-off delivery rather than this one-message policy.

## What This Changes

The issue requests an opt-in mode to merge tool-interleaved assistant text blocks from one agent turn into one outbound channel message.

## Best Possible Solution

Define an explicit opt-in core delivery policy for tool-interleaved assistant text, with config/schema/docs and regression coverage across final payload assembly and block-streamed tool-start boundaries.
