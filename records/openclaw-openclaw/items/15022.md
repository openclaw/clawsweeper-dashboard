## Summary

Keep open: current main and v2026.6.11 still lack an opt-in mode that coalesces or final-only-delivers tool-interleaved assistant text, and related PRs/issues do not supersede this product/config decision.

## What This Changes

The issue requests an opt-in setting that merges text blocks from one tool-interleaved agent turn into a single outbound channel message.

## Best Possible Solution

Define an explicit opt-in core delivery policy for tool-interleaved assistant text, with config/schema/docs and regression coverage across final payload assembly and block-streamed tool-start boundaries.
