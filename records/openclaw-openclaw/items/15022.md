## Summary

Keep open: current main has partial commentary/final-answer suppression, but it still lacks the requested opt-in policy that coalesces or final-only-delivers tool-interleaved assistant text as one outbound channel message.

## What This Changes

Requests a configurable delivery mode that merges or final-only-delivers assistant text blocks interleaved with tool calls into one outbound message for a single agent turn.

## Best Possible Solution

Define an explicit opt-in core/channel delivery policy for tool-interleaved assistant text, with schema/docs and regression coverage for both final-payload and block-streamed tool-start paths while preserving current defaults unless maintainers choose otherwise.
