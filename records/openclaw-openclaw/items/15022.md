## Summary

Keep open: current main partially improved final payload selection, but it still does not provide the requested opt-in coalescing or final-only delivery mode for tool-interleaved assistant text, and the remaining work is a maintainer delivery/config decision.

## What This Changes

## Best Possible Solution

Define an explicit opt-in tool-interleaved text delivery policy in the core reply pipeline, with schema/docs and regression coverage for both final payload assembly and block-streamed tool-start boundaries.
