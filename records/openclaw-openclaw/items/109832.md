## Summary

Keep open: the report describes a concrete v2026.7.1 upgrade blocker, and the merged migration-convergence work does not clearly prove that current main handles a redundant plugin-state sidecar by comparing its rows or reports only actual conflicting source rows.

## What This Changes

Make legacy plugin-state sidecar migration recognize fully imported or older rows, retire the redundant source, and report only genuine sidecar conflicts.

## Best Possible Solution

Ensure startup or `openclaw doctor --fix` compares each legacy sidecar row with canonical plugin state, archives the sidecar only when canonical data is equal or newer, names actual divergent source rows when blocking, and offers a visible Doctor/Fix recovery path instead of requiring manual state-directory surgery.
