## What This Changes

The PR makes dashboard-created sessions inherit their parent agent and adds a privacy-safe `Workboard: <card-id>` prefix to eligible replies associated with an active Workboard card.

## System Context

The Gateway creates dashboard sessions and determines which agent will run them. The Workboard plugin records which session owns an active card, then observes outgoing reply payloads and adds an identifier only when the session and card are eligible.
