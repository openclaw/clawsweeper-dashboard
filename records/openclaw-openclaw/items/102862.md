## What This Changes

The PR adds bounded request deadlines to MiniMax OAuth device-code and token-poll HTTP POSTs and adds hanging-loopback regression coverage.

## Best Possible Solution

Use the guard’s top-level timeout as the single enforced deadline for both MiniMax OAuth POSTs, keep the loopback regressions, and avoid adding user-facing timeout configuration.
