- **[P1] Raise the MXC plugin host/API compatibility floor:** `extensions/mxc/package.json:24-27`
  - body: This package declares `minHostVersion` and `pluginApi` compatibility back to `2026.6.10`, but the PR-head plugin imports `resolveReadOnlyWorkspaceSkillMounts` from `openclaw/plugin-sdk/sandbox`, which is not exported by the latest shipped `v2026.6.11` host.   - confidence: 0.92
- **[P2] Document the `rw` protected-skill fail-closed path:** `extensions/mxc/README.md:51-52`
  - body: The README says `workspaceAccess: "rw"` mounts the workdir read-write, but current MXC code adds protected skill roots as read-only and rejects readwrite/readonly overlaps because MXC cannot safely enforce nested overlays. In workspaces with `skills/`, `.agents/skills/`, or materialized sandbox skills, users can see MXC exec fail closed instead of getting a writable workspace; document that limitation and the supported alternatives.
