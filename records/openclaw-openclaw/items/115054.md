## What This Changes

This PR makes Infer provider inspection avoid live catalog discovery, recognizes bundled refreshable models during local resolution, reports environment-backed provider state, and adds `infer tts convert --provider <id>` for provider-only TTS backends.

## System Context

The Infer CLI reads model and provider catalog data to inspect or invoke local capabilities, then passes a resolved provider and model selection into the relevant runtime. This change affects catalog inspection, model resolution, provider status output, and TTS conversion selection without changing persisted configuration.
