## Summary

The PR remains necessary because current main still loses non-bot mentions and lacks forwarded-message normalization, but the updated branch retains the previously reported debounce defect: a quote-bearing activity that is not last in a batch loses its supplemental quote context. The protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

The PR adds Microsoft Teams inbound normalization for mention display names, bot mentions, quotedReply entities, inline quote markers, and forwarded-message HTML before agent dispatch.

## Best Possible Solution

Make normalized supplemental-quote data part of each Teams debounce entry and explicitly preserve the applicable quote through multi-entry flushes while retaining sender authorization and Graph full-text behavior; then prove representative real Teams payloads end to end.
