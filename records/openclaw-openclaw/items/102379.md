## Summary

This PR remains necessary because current main still loses non-bot mention text and lacks the broader entity-aware normalization, but the current patch is not merge-ready: a quote-bearing activity can enter debounce and lose its supplemental quote context when a later same-key activity supplies `last.context`. The repeated blocker is narrow and repairable, but merge should wait for that fix and after-fix real Teams evidence.

## What This Changes

The PR replaces blanket Microsoft Teams mention stripping with entity-aware inbound normalization, adds `quotedReply` entity extraction and forwarded-message labeling, and expands parser and authorization tests.

## Best Possible Solution

Keep normalization inside the Teams plugin, but make quote context an explicit debounce fact or bypass debounce for quote-bearing activities, add a quote-first two-message regression for allowed and blocked senders, and then attach redacted live Teams or captured-real activity proof.
