## Summary

The PR is still necessary and targets the correct Teams plugin boundary, but it remains unmergeable as-is: the established inbound debounce path batches normalized text without preserving per-message `quotedReply` metadata, so quoted context can disappear or be associated only with the last activity. The new Azure proof is useful exact-head fixture validation, but it neither exercises that failing path nor demonstrates the changed shapes from a live or captured Teams activity.

## What This Changes

The PR replaces blanket Microsoft Teams mention stripping with entity-aware mention normalization, adds `quotedReply` extraction and forwarded-message labeling, and expands parser and authorization tests.

## Best Possible Solution

Keep the Teams-owned normalizer, but make the debounce entry carry the complete normalized inbound facts—including quote body, sender, sender ID, and message ID—through flush and authorization, then prove both direct and batched mention, quote, and forward behavior with a redacted live tenant run or captured activity replay.
