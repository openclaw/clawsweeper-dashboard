## What This Changes

This PR changes Doctor’s auth-profile migration verification so a non-main agent OAuth credential intentionally deduplicated to the main agent is not treated as a failed SQLite import, and adds a regression test for that upgrade state.

## System Context

Doctor migrates legacy per-agent auth-profile JSON into canonical per-agent SQLite storage before the gateway starts. A non-main agent may intentionally inherit a newer OAuth credential from the main agent, so the migration verifier must distinguish that ownership decision from a missing credential.
