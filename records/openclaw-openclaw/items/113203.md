## What This Changes

Add a lifecycle-status configuration mode that leaves the final done or error reaction on a completed message.

## System Context

Lifecycle status reactions are shared message-completion feedback: channel events begin with an acknowledgement, then status updates represent queued, working, completed, or failed work. The finalization policy determines whether the message restores the acknowledgement, clears reactions, or retains the terminal outcome.
