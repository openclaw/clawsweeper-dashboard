## Summary

This PR should stay open because it is the paired candidate for a real Docker sandbox hardening issue, but it still changes the effective default for existing sandbox users and needs maintainer-approved upgrade semantics plus real Docker behavior proof before merge.

## What This Changes

The PR adds a `DEFAULT_SANDBOX_PIDS_LIMIT` constant and uses it as the fallback `pidsLimit` in sandbox Docker config resolution when neither agent nor global config sets a value.

## Best Possible Solution

Land a maintainer-approved sandbox PID-limit default with documented opt-out semantics, focused config tests, and real Docker proof for fresh-default and override cases.
