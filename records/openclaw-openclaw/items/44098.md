## Summary

Keep open: the linked sandbox hardening problem still exists on current main, but this PR is not merge-ready because it changes the default for every unset Docker sandbox without a documented opt-out path or real Docker behavior proof.

## What This Changes

The branch adds `DEFAULT_SANDBOX_PIDS_LIMIT = 1024` and uses it as the fallback `pidsLimit` when resolving Docker sandbox config.

## Best Possible Solution

Adopt a maintainer-approved PID cap only with an explicit opt-out contract, aligned schema/docs/help, regression coverage, and real Docker proof that the cap reaches container creation.
