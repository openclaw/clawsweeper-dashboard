## Summary

The latest head still changes a broken BOOT.md symlink from the shipped missing/skipped outcome to a failed startup check. The bounded-read mechanism and live oversized-file proof are strong, but merge should wait for that compatibility fix and an owner choice on whether oversize should fail visibly or skip silently.

## What This Changes

The PR replaces the unbounded BOOT.md read with a 16 MiB bounded regular-file read, resolves readable symlinks, and adds oversized, directory, and symlink regression coverage.

## Best Possible Solution

Keep the bounded read and readable-symlink support, map all ENOENT resolution cases back to missing, expose overflow through a stable typed helper contract, and implement the BOOT.md owner-selected visible-failure or silent-skip result with focused coverage.
