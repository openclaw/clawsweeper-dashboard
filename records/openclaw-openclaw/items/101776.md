## What This Changes

The PR changes the gateway BOOT.md loader to use `readRegularFile` with a 16 MiB limit and adds a regression test for oversized BOOT.md files.

## Best Possible Solution

Land a bounded BOOT.md read with regression coverage after deciding the symlink policy; preserve current symlink behavior by default unless maintainers intentionally document and test regular-file-only boot files.
