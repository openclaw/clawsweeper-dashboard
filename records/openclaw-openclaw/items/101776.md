## Summary

Keep open: the size cap is useful and the oversized-file proof is sufficient, but the current patch silently skips every non-missing BOOT.md read failure, which can hide unreadable files and break existing symlinked BOOT.md setups before merge.

## What This Changes

The PR replaces the unbounded BOOT.md read with a 16 MiB `readRegularFile` call and updates gateway boot tests to skip oversized, non-regular, and symlinked BOOT.md paths.

## Best Possible Solution

Keep the 16 MiB bound, but preserve current BOOT.md behavior for readable symlinks and non-size read errors unless maintainers explicitly approve a stricter compatibility change with docs and tests.
