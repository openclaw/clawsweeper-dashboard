## Risks / Open Questions

- A lost or retried `chat.send` ACK can replay cached terminal `ok` while `chatQueuedTurns` still contains the queued turn, causing TUI to clear the pending row and reload history before the queued prompt runs.
- The PR changes message delivery and abort ownership across TUI, Gateway, followup, collect, and overflow paths; small ordering mistakes can drop, preserve, or abort the wrong turn.
- The additive `chat.abort.preserveSideRuns` protocol field and generated Swift client changes are compatibility-sensitive even with the TUI legacy retry.
- Queued-turn abort ownership is security-boundary-sensitive because requester/device/connection authorization must remain correct for queued and active runs.
