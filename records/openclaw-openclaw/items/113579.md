## What This Changes

Updates Qwen Token Plan model metadata to raise three output limits, mark six chat models as video-capable, mirror that metadata into the bundled plugin manifest, and correct Token Plan subscription wording in provider documentation.

## System Context

The Qwen extension selects a Token Plan endpoint from the user’s auth choice, then exposes the static model catalog to model selection and attachment validation. This PR changes the catalog metadata and matching bundled manifest that determine accepted media and requested output limits for Token Plan users.
