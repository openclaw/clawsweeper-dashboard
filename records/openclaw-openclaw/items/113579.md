## Summary

Keep this PR open for a human endpoint-contract decision. The contributor supplied strong redacted live proof for the Global/Singapore Token Plan gateway, but the changed static catalog is shared with the China endpoint and the contributor explicitly cannot validate that endpoint; accepting the widened limits and video capability would therefore advertise unproven behavior to China users.

## What This Changes

The branch raises three Qwen Token Plan output limits, marks six catalog models as accepting video input, mirrors those metadata changes into the bundled plugin manifest, and updates provider docs to describe Token Plan as available to both Personal and Team subscriptions.

## System Context

The Qwen plugin selects a Token Plan endpoint from the user's auth choice, then supplies its static model catalog to model selection and attachment validation. The catalog metadata determines the maximum output requested from the gateway and whether OpenClaw allows a user to attach video before sending the request.

## Best Possible Solution

Either add redacted live China-endpoint proof for every changed limit and modality, or make the catalog endpoint-specific so the proven Global metadata does not silently change the China contract.
