## What This Changes

Fix Code Mode tool compaction and provider payload filtering so trusted native direct-message, computer, and image tools remain model-visible when run policy requires direct delivery, while ordinary tools and MCP lookalikes stay hidden.

## System Context

Code Mode compacts the tools exposed to a model during an agent run, then provider adapters serialize that catalog into provider-specific payloads. Run-level delivery policy must preserve trusted native tools needed to send the required user-visible response without widening access to unrelated tools.
