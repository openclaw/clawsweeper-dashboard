## What This Changes

The issue asks OpenClaw to prevent newly created non-main agents from reaching runtime with a missing `models.json` when provider planning returns an empty skip result.

## Best Possible Solution

Land a rebased, maintainer-approved fix for the missing root models.json skip path, then close this issue once current main contains that behavior.
