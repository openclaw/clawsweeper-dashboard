## What This Changes

The issue reports that a newly created non-main agent can miss `models.json` when provider planning returns `skip`, then fail at runtime with `Unknown model`.

## Best Possible Solution

Review, rebase, and land https://github.com/openclaw/openclaw/pull/58373 or replace it with the maintainer-chosen missing-file fix, then close this issue after the behavior is on main.

## Reproduction Assessment

Yes. Source inspection shows an empty provider plan returns `skip`, the skip branch does not create root `models.json`, the registry treats a missing file as empty, and the runner can still throw `Unknown model` after retry.

## Solution Assessment

Unclear. The desired end state is valid, but maintainers still need to choose whether the best fix is persisted bootstrap, read-through inheritance, or an early actionable failure.
