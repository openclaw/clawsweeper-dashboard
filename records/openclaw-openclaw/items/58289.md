## Summary

Keep open: current `main` and the latest `v2026.6.11` release still have the empty-provider `skip` path that can leave a non-main agent without a root `models.json`, and the open closing PR is still unmerged and conflicting. ## What This Changes

The issue reports that newly created non-main agents can enter the empty-provider `models.json` skip path, keep no per-agent model registry, and later fail with `Unknown model`.

## Best Possible Solution

Land or replace the linked fix with a maintainer-approved change that prevents missing non-main `models.json` from reaching runtime while preserving provider/auth boundaries, then close this issue after the behavior is on `main`.

## Reproduction Assessment

Yes. Source inspection on current `main` shows empty provider resolution returns `skip`, the skip branch does not create root `models.json`, a missing registry loads empty, and the runner can still throw `Unknown model`.

## Solution Assessment

Unclear. The issue's expected end state is valid, but maintainers still need to choose whether persisted bootstrap, read-through inheritance, or an early actionable failure is the best long-term fix.
