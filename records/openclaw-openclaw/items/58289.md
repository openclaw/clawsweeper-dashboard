## Summary

Keep open: current main and v2026.6.11 still have the empty-provider skip path that can leave a non-main agent without a root models.json, and the exact same-repository fix candidate remains open but conflicting. ## What This Changes

The issue asks OpenClaw to prevent newly created non-main agents from reaching runtime with a missing models.json after provider planning returns an empty skip result.

## Best Possible Solution

Land a rebased, maintainer-approved fix for the missing non-main root models.json skip path while preserving existing per-agent catalogs, then close this issue after the fix reaches main.
