## Summary

Keep open: current main and the latest release still have the empty-provider skip path that can leave a non-main agent without root `models.json`, and an open same-repository closing pull request is already the candidate implementation path. The issue remains necessary as the canonical missing-file report until that pull request lands or maintainers choose a different fix shape.

## What This Changes

Non-main agents created without `models.json` can still hit `Unknown model` when empty provider planning skips catalog generation.

## Best Possible Solution

Land a rebased, maintainer-approved fix for the missing non-main root `models.json` skip path, or implement an explicit early actionable failure, then close this issue once current main contains the behavior.

## Reproduction Assessment

Yes. Source inspection shows an empty provider plan returns `skip`, the skip branch does not create root `models.json`, the registry treats a missing file as empty, and the runner can still throw `Unknown model` after retry.

## Solution Assessment

Unclear. The reported end state is the right one, but maintainers still need to choose whether the best implementation is persisted bootstrap, read-through inheritance, or an early actionable failure.
