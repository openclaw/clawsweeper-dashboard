## Summary

Keep open: current main and the latest release still have the empty-provider skip path that can leave a non-main agent without `models.json`, and an open linked pull request already owns the direct missing-file fix.

## What This Changes

Request to prevent non-main agents from reaching runtime with a missing `models.json` when provider planning resolves no providers and later failing with `Unknown model`.

## Best Possible Solution

Land a narrow, maintainer-approved fix that either bootstraps a missing non-main model catalog without overwriting local agent state or fails early with actionable guidance before runtime model resolution.

## Reproduction Assessment

Yes, source inspection gives a high-confidence reproduction path: an empty provider plan returns `skip`, the skip branch does not create root `models.json`, and `ModelRegistry` treats a missing file as an empty model catalog. I did not run a live filesystem repro because this review is read-only.

## Solution Assessment

Unclear until maintainer review of the linked fix: a one-time bootstrap from the main catalog is plausible, but the repository treats provider/auth fallback and persisted model files as compatibility-sensitive, so the final shape needs explicit approval around per-agent isolation and secret handling.
