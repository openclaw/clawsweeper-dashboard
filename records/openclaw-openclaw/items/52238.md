## Summary

Keep open: current main and v2026.6.11 still classify the reported Feishu `oc_...` event with `chat_type: "p2p"` as non-group, so it follows the direct-message route instead of the Feishu group/topic route. The issue remains the canonical tracker because the exact safe discriminator still needs maintainer validation and the linked fix PRs have not landed.

## What This Changes

The issue requests that Feishu topic/OpenChat group messages delivered as `p2p` route as group/topic messages instead of direct messages.

## Best Possible Solution

Keep this as the canonical Feishu inbound classifier bug and land a Feishu-local shared discriminator backed by live or official-contract proof, with regressions that preserve true p2p direct, p2p thread, root-only quote, and card-action behavior.
