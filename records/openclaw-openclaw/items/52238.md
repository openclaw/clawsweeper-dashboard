## Label Justifications

- `P1`: The issue reports real Feishu group/topic messages being routed as direct messages, breaking an active channel workflow for affected users.

## Summary

Keep open: current main and v2026.6.11 still classify the reported Feishu `oc_...` event with `chat_type: "p2p"` as non-group, so it follows the direct-message route instead of the intended Feishu group/topic route. The same-repo issue remains the canonical tracker because the linked external fix is open but conflicting, and the same-repo related PRs cover adjacent outbound or topic-anchor behavior rather than a merged inbound classifier fix.

## What This Changes

Treat Feishu/Lark topic or OpenChat group messages reported as `p2p` as group/topic conversations so replies and session state route back to the Feishu group instead of a direct/main session.

## Best Possible Solution

Keep this as the canonical Feishu inbound classifier bug and land a Feishu-local shared discriminator based on verified topic/OpenChat metadata, with regressions that preserve true p2p direct, p2p thread, root-only quote, reaction, and card-action behavior.
