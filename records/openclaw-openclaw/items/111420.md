## What This Changes

The branch persists per-run cron ownership identities and revisions so completion and startup recovery cannot mutate a job that was rescheduled, edited, or recreated while an older run was active.

## Best Possible Solution

Retain a single guarded ownership model, but merge only after maintainer review confirms legacy persisted jobs recover safely and the PR includes redacted, inspectable Gateway proof that a rescheduled active one-shot survives completion and restart.
