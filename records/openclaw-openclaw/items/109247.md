## Summary

This PR remains necessary: it makes the Usage Overview hints reachable through an actual button and tooltip rather than a passive title attribute, and the submitted before/after screenshot directly shows the central click-to-open improvement. However, the current head does not implement the declared click-toggle contract: the tooltip is configured only for hover and focus, while the click handler merely focuses the button, so a second click on an already focused hint cannot close it as the PR body promises.

## What This Changes

The branch replaces nine Usage Overview `?` title spans with accessible buttons and associated Web Awesome tooltips, with focused unit, Chromium E2E, and styling coverage.

## Best Possible Solution

Use Web Awesome as the sole activation owner with its native `click hover focus` trigger, remove the focus-only click workaround if it is no longer needed, and prove same-hint click open/close plus hover, keyboard focus, blur, and Escape behavior.
