## Summary

Keep open: current main still renders a separate microphone activity status pill and two visually identical stop-style controls when Talk and an abortable run overlap, while the protected maintainer label makes this a product-direction item rather than conservative cleanup.

## What This Changes

The issue requests a Control UI chat composer redesign that folds the realtime Talk microphone activity meter into the active voice-stop button and visually differentiates it from the run-abort stop button.

## Best Possible Solution

Land a focused Control UI change that makes the active voice control own the microphone meter, keeps run abort visually distinct, preserves live-region/error/reduced-motion behavior, and updates chat view plus browser Talk proof.
