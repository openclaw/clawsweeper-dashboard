## Summary

This PR needs revision before merge: the hardening direction is reasonable, but the patch breaks the existing explicit `sessionFile` archive path when `storePath` is undefined and only provides test output rather than real behavior proof.

## What This Changes

The branch changes `archiveSessionTranscriptsDetailed` so transcript archive candidates are always checked against a sessions-directory containment boundary instead of only when `restrictToStoreDir` is set.

## Best Possible Solution

Keep the containment hardening, but derive the boundary from an authoritative store path when present and preserve or explicitly redesign the no-store custom transcript archive contract with focused regression tests.
