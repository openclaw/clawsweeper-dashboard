The earlier timeout-budget blocker is resolved, the supplied real-process proof is convincing, and no blocking correctness or security defect remains; the branch should be refreshed against current main before merge.

## What This Changes

The PR adds timeout-bounded polling to `gateway usage-cost` so the CLI waits for usage caches to settle, plus regression coverage using real session transcripts and the real Gateway handler.

## Best Possible Solution

Keep aggregate cache rebuilding asynchronous for shared Gateway clients, but land this CLI-only settled read so operator audits wait within the existing `--timeout` budget and return accurate totals or a clear timeout.
