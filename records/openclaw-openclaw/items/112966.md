## Summary

Keep this PR open for the assigned maintainer’s compatibility-boundary review. The patch appears to correctly reuse the existing reasoning-effort compatibility mapping, preserve Azure replay material, and has credible live Groq proof, but merging intentionally defines which Responses routes retain encrypted reasoning continuation data.

## What This Changes

The PR makes OpenAI Responses payloads translate reasoning effort through each model’s provider compatibility map, omits OpenAI-only reasoning fields for compatible endpoints, and retains encrypted replay data for OpenAI and Azure Responses routes.

## System Context

The AI provider layer converts an agent run’s reasoning options and model compatibility metadata into a Responses API payload. That payload controls provider-native effort values and, for replay-capable routes, encrypted reasoning material needed by later continuation turns.
