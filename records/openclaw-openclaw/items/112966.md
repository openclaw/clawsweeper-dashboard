## Summary

## What This Changes

The PR maps OpenAI Responses reasoning effort through each provider’s compatibility map and suppresses OpenAI-only reasoning fields for providers other than OpenAI.

## System Context

The OpenAI Responses transport turns an agent run’s reasoning settings into an API payload for OpenAI-compatible model providers. Its payload must use each provider’s accepted effort values while retaining any reasoning data needed to continue a tool or reasoning turn.

## Best Possible Solution

Keep provider-native effort mapping, but select encrypted reasoning replay material through an explicit Responses replay capability so Azure and any other supported replay-capable route retain it; add focused coverage for that route.
