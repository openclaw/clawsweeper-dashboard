## What This Changes

The PR routes OpenAI Responses reasoning efforts through each model’s provider-native `thinkingLevelMap` and limits encrypted reasoning replay fields to native OpenAI and Azure Responses requests.

## System Context

The AI provider layer converts model definitions and run-time reasoning options into OpenAI Responses API requests. The resulting payload determines both the provider-native reasoning effort and whether a later tool or reasoning turn receives encrypted continuation material.
