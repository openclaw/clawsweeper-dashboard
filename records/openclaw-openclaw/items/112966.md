## What This Changes

The PR routes OpenAI Responses reasoning effort through each model’s canonical provider-native `thinkingLevelMap`, omits OpenAI-only replay fields for compatible providers, and preserves encrypted replay material for OpenAI and Azure Responses.

## System Context
