## What This Changes

Updates the OpenAI Responses request builder so provider-declared reasoning-effort values are sent to compatible endpoints, while retaining encrypted replay material for OpenAI and Azure Responses routes.

## System Context

The AI provider layer turns an agent request and model compatibility metadata into a Responses API payload, then streams the provider result back into agent session state. Reasoning-effort normalization and encrypted replay fields determine whether compatible endpoints accept a request and whether follow-up tool or reasoning turns can continue safely.
