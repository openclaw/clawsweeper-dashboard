## What This Changes

Moves the running-task tooltip so it is anchored to the task-count button rather than the entire status row, while preserving a separate polite screen-reader task-count announcement.

## System Context

The Control UI chat footer displays a running-task status row after an agent turn. Its task-count button opens a rich preview and the same status must remain accessible to screen readers without repeatedly announcing the elapsed timer.
