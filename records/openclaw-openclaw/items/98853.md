## Summary

Keep open: current main still has the unbounded usage-template file cache, but this PR is not merge-ready because the eviction runs after watcher allocation, can evict an unrelated cached entry on an existing-key retry, and still lacks real behavior proof for the changed cache path.

## What This Changes

The PR adds a 32-entry cap to the usage-bar template file cache and closes the oldest cached watcher when inserting a new entry.

## Best Possible Solution

Evict only before adding a new cache key, free an old watcher before opening the replacement watcher, and add focused coverage plus contributor real-run proof for more than 32 template paths.

## Reproduction Assessment

Yes by source inspection: current main stores each distinct configured template path in a module-level Map and opens watchers for valid templates without a size bound. I did not run a live more-than-32-path reproduction in this read-only review.

## Solution Assessment

No. The cache boundary is the right place to fix this, but the PR needs to evict before watcher allocation, avoid evicting when overwriting an existing key, and add focused coverage and proof.

Overall confidence: 0.86

Full review comments:

- **[P2] Evict before opening the replacement watcher:** `src/auto-reply/usage-bar/template.ts:149-156`
  - body: This block runs after `watch(path, ...)` has already tried to allocate the replacement watcher. When the cache is full and the process is near watcher or file-descriptor limits, the new watcher can fail before this PR frees an old one, leaving the newly loaded template cached without live refresh even though evicting first could have preserved it.
  - confidence: 0.86
- **[P2] Only evict when adding a new cache entry:** `src/auto-reply/usage-bar/template.ts:149`
  - body: `cacheTemplateFile` is also used to retry paths that are already cached without a watcher. In that case `fileCache.set(path, entry)` overwrites an existing key and does not grow the cache, but this condition can still delete the oldest unrelated entry and close its live watcher.
  - confidence: 0.82
