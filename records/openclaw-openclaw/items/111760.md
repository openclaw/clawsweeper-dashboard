## Summary

The patch is a sound, narrowly scoped hardening change with sufficient real filesystem proof and no discrete correctness defect found. It should remain open for an explicit maintainer decision because upgrading makes previously accepted MXC sandbox-policy files larger than 1 MiB fail to load.

## What This Changes

This PR caps MXC sandbox-policy file reads at 1 MiB, resolves configured symlinks before reading, and adds regression coverage for normal, symlinked, and oversized policy files.

## System Context

MXC loads operator-provided sandbox-policy JSON files before constructing its baseline sandbox policy. This change replaces the loader’s unbounded filesystem read with the plugin SDK’s bounded regular-file read, affecting startup/policy-loading success for configured MXC installations.
