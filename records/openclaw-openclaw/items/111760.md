## Summary

The bounded-read change addresses the reported OOM path and the PR now includes credible terminal proof using the production loader. However, it also changes existing `mxcPolicyPaths` behavior by rejecting symlinked policy files, so it needs a compatibility-preserving repair before merge.

## What This Changes

The PR caps MXC sandbox-policy file reads at 1 MiB through `readRegularFileSync` and adds normal-file and oversized-file tests.

## Best Possible Solution

Keep the 1 MiB cap while preserving the existing ability to use a configured symlink policy path, then add regression coverage for both the supported path form and the oversized-file rejection.
