## Summary

Keep this PR open. The current head addresses the prior symlink-compatibility blocker by resolving configured links before the bounded regular-file read, and the PR body supplies credible real filesystem proof for the boundary, oversized-file rejection, and missing-file behavior. The remaining maintainer choice is whether the deliberate 1 MiB ceiling is acceptable for existing MXC operator policy files.

## What This Changes

The PR replaces MXC’s unbounded sandbox-policy file read with a 1 MiB regular-file read, while retaining configured symlink policy paths and adding bounded-read coverage.

## System Context

MXC loads operator-configured JSON policy layers before constructing the sandbox baseline used for process and filesystem restrictions. This path turns policy-file paths into parsed sandbox settings, so it must reject unsafe or oversized inputs without changing valid policy-path behavior.
