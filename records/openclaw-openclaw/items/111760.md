## Summary

The bounded-read fix has credible live filesystem proof and focused tests, but the proposed helper also changes existing configured-path semantics by rejecting symlinks. That upgrade behavior needs an explicit maintainer decision or a compatibility-preserving implementation before merge.

## What This Changes

The PR caps MXC sandbox-policy file reads at 1 MiB through `readRegularFileSync` and adds tests for normal and oversized policy files.

## Best Possible Solution

Keep the 1 MiB pre-parse limit, but either preserve the established symlink-following configuration behavior with a bounded reader or obtain explicit approval for rejecting symlinked policies and document the upgrade path with focused compatibility coverage.
