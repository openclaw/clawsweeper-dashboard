## What This Changes

This PR makes the Control UI browser gateway client suppress or back off session pull-request RPC calls after the gateway reports that the session-PR surface is unavailable, and routes sidebar and chat callers through that shared method.

## System Context

The Control UI fetches per-session pull-request summaries from a gateway RPC for sidebar indicators and chat suggestions. The browser gateway client is the shared boundary between those UI refreshes and the server-side session-PR provider, so it can prevent each caller from independently retrying an unavailable service.
