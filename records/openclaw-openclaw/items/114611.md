## What This Changes

This PR replaces the retired `hostnameAllowlist` field in the browser-control strict SSRF-policy example with a single `allowedHostnames` list.

## System Context

Browser navigation flows pass destination hostnames through the strict SSRF policy before opening a page. That policy uses pattern-based hostname exceptions separately from exact hostname exceptions, and the documentation example teaches operators how to configure those exceptions.
