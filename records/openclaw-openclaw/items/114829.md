## What This Changes

This PR makes Gateway session-catalog requests reuse lazy SQLite list projections and one request-wide flattened entry list instead of cloning and rebuilding entries for each catalog provider.

## System Context

The Gateway builds a session catalog for Control UI and provider-facing catalog consumers from persisted per-agent session entries. This PR changes the cache-to-catalog handoff so providers read one request-owned, logically frozen snapshot rather than repeatedly cloning or flattening the session store.
