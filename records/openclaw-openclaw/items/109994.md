Keep this PR open for normal maintainer review. The patch is a focused, correct repair for the occupied-port startup failure, carries convincing real-machine proof, and adds focused regression coverage; it is not superseded on current main.

## What This Changes

The PR makes browser control and bridge HTTP startup reject or follow the existing failure path when another process already owns the configured local port, with regression tests using real occupied loopback ports.

## System Context

The browser plugin starts two local HTTP servers: the configured control server and a browser bridge server. Configuration and lifecycle code feed each entrypoint, which binds a loopback TCP port before serving browser-control routes to local clients.
