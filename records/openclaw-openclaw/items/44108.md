## What This Changes

## Best Possible Solution

Keep `agents.files.*` bootstrap-only, build Mission Control workspace browsing on the current read-only `agents.workspace.*` base, route workspace CRUD through the canonical workspace-management design, and treat host system browsing as a separate security-reviewed product decision.
