## Summary

Keep open: current main partially addresses the custom-file viewing problem with a read-only `agents.workspace.list/get` API and mobile app browsers, but the web Mission Control editable scope selector, workspace-wide mutations, and system filesystem scope remain unresolved and security-sensitive.

## What This Changes

The issue requests replacing the web agent-file allowlist with MC/workspace/system scope levels so custom workspace and system files can be browsed and edited from Mission Control.

## Best Possible Solution

Keep `agents.files.*` as the bootstrap-file editor, converge workspace-wide browsing/editing on a separately reviewed `agents.workspace.*` design, and require a distinct security-approved design before any system filesystem scope exists.
