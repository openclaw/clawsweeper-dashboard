## Summary

Keep open: current main has a safer read-only workspace browser API, but this issue still asks for Mission Control scope selection, workspace editing, and host-filesystem browsing that need product and security boundary decisions.

## What This Changes

Request to replace the Mission Control agent-file allowlist with selectable scopes for bootstrap files, all workspace files, and broader system filesystem browsing.

## Best Possible Solution

Keep the bootstrap-files API narrow, build any broader workspace browsing or editing on a bounded `agents.workspace.*` contract, and treat host-filesystem browsing as a separate security design rather than a default Mission Control scope.
