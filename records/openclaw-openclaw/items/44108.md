## Summary

Keep open: current main now has a bounded read-only `agents.workspace.list/get` Gateway slice, but Mission Control still edits only allowlisted core files and the requested workspace-write plus system-filesystem scopes remain product/security decisions.

## What This Changes

The issue requests replacing Mission Control's bootstrap-file-only browser with scope levels for core files, all agent workspace files, and host system filesystem browsing/editing.

## Best Possible Solution

Keep `agents.files.*` as the bootstrap/core-files editing API, build any workspace-wide file management through the canonical `agents.workspace.*` design, and require a separate security-approved product decision before system filesystem scope exists.
