## Summary

Keep open: current main now covers part of the read-only workspace browsing problem, but this issue still asks for editable all-workspace scope and a host-filesystem system scope, which remain product/security boundary decisions and partially overlap the canonical full workspace-management thread.

## What This Changes

Request to replace the agent file browser's bootstrap-file allowlist with MC/all-workspace/system scope levels so custom workspace files can be viewed and edited.

## Best Possible Solution

Keep `agents.files.*` as the bootstrap-file editor, keep the current read-only workspace preview APIs, route workspace-wide CRUD through the canonical workspace-management design, and require a separate security-approved design before any host-filesystem system scope exists.
