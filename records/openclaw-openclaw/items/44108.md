## Summary

Keep open: current main partially addresses workspace browsing with a bounded read-only `agents.workspace.list/get` API, but this issue still asks for Mission Control scope switching, workspace-wide editing, and host/system filesystem access, which remain product and security-boundary decisions.

## What This Changes

The issue requests replacing the Mission Control bootstrap-file allowlist with MC Files, all-workspace, and system filesystem browsing scopes.

## Best Possible Solution

Keep `agents.files.*` as the bootstrap-file editor, use the read-only `agents.workspace.*` rail for bounded previews, and decide workspace mutation plus any host/system scope through a security-reviewed design tied to the canonical workspace-management thread.
