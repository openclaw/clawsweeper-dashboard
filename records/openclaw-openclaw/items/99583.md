## What This Changes

Add configurable delayed session auto-titles, cheap-model routing, topic-aware re-titling, and manual title-lock controls.

## Best Possible Solution

Keep the existing one-shot title path and have maintainers decide whether to extend that service with a single, bounded re-title policy that reuses utilityModel and preserves explicit/manual titles, rather than adding parallel per-session model routing.
