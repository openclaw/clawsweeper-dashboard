## Summary

Keep open: current main and v2026.6.11 do not implement configurable LLM session auto-titling, and the open implementation candidate only covers the basic default-off initial-title path while this proposal adds topic-aware re-titling, cheap-model routing, subagent rules, and manual-lock semantics that need maintainer product review.

## What This Changes

Request lazy opt-in LLM-generated session titles, dedicated cheap title model selection, periodic topic-aware re-titling, and manual/subagent title behavior.

## Best Possible Solution

Settle the basic default-off generated-title path through https://github.com/openclaw/openclaw/issues/77165 and https://github.com/openclaw/openclaw/pull/87643 first, then treat this as a maintainer-designed follow-up for re-titling and title-model semantics if still desired.

## Reproduction Assessment

Not applicable as a bug reproduction; this is a feature proposal. Source inspection confirms current main has deterministic derived titles and manual labels, but no configurable model-generated title or re-title path.

## Solution Assessment

Unclear until maintainers choose the product boundary. The safest direction is a single default-off generated-title source of truth that preserves manual labels, uses existing provider/auth routing, and avoids adding periodic re-title behavior until privacy/cost and flicker semantics are accepted.
