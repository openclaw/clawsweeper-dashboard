## Summary

Keep open: current main and the latest release still only provide deterministic/manual session title sources, and the canonical basic auto-title issue plus open PRs cover only part of this broader lazy-generation, title-model, re-title, and subagent proposal.

## What This Changes

The issue requests an opt-in gateway-side session auto-titling system with lazy initial generation, a cheap title-model override, topic-aware re-titling, manual-title lockout, and subagent-specific behavior.

## Best Possible Solution

Use the canonical basic auto-title work as the base, then split or sponsor focused follow-ups for title-model routing, topic-aware re-titling, and subagent policy after the privacy/config/session-state contract is settled.
