## Summary

Keep open: current main and v2026.6.11 still lack configurable model-generated session titles and topic-aware re-titling. The base once-only generated-title request is already covered by https://github.com/openclaw/openclaw/issues/77165 and its open implementation PR, but this proposal adds dedicated model policy, periodic renames, subagent rules, and `/name --auto` behavior that still need maintainer product, privacy, provider-routing, and config-surface decisions.

## What This Changes

Request lazy, configurable LLM-generated session titles, cheap title-model routing, periodic topic-aware re-titling, manual-lock behavior, and subagent-specific title rules.

## Best Possible Solution

Review or land the base generated-title path through https://github.com/openclaw/openclaw/issues/77165 and https://github.com/openclaw/openclaw/pull/87643, then split or sponsor a separate opt-in topic-aware re-title design that preserves manual labels and explicit provider/privacy routing.
