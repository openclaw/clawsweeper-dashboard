## Summary

Keep open: current main and v2026.6.11 do not implement lazy, model-generated, or topic-aware session auto-titling. Related open work covers basic AI-generated titles and deterministic derived-title quality, but this proposal adds broader config, provider/privacy, subagent, and re-titling choices that need maintainer product review.

## What This Changes

The issue proposes a default-off gateway auto-titling system that lazily generates, stores, and periodically updates session titles using a cheap model while preserving manual labels.

## Best Possible Solution

Define one durable session-title contract that coordinates with the basic generated-title work, preserves manual labels, reuses gateway provider/auth routing, bounds transcript reads, documents privacy/cost behavior, and splits topic-aware re-titling or session-splitting into narrower follow-ups if maintainers want them.

## Reproduction Assessment

Not applicable as a feature proposal. Source inspection does confirm the current behavior is deterministic title derivation, with no lazy generated-title or topic-aware re-title path on main or v2026.6.11.

## Solution Assessment

Unclear as written. The direction is useful, but the best fix needs maintainer decisions on whether to extend the basic auto-title work, how much config to expose, and whether topic-aware re-titling belongs in the first core implementation.
