## Summary

Keep open: current main still lacks inbound Baileys WhatsApp call-event handling, and the merged MeowCaller work only adds an outbound requester-bound call tool that does not solve call-event tracking.

## What This Changes

The issue requests that the WhatsApp Web plugin subscribe to Baileys inbound call events and expose call activity so agents can count calls as contact events.

## Best Possible Solution

Implement plugin-owned, default-off inbound call-event handling in extensions/whatsapp with sanitized metadata, message-equivalent access controls, docs, and focused tests, then expose it through a maintainer-approved session/event/tool surface.
