## Summary

Keep open: current main still lacks inbound Baileys WhatsApp call-event ingestion. The merged MeowCaller work adds a default-off outbound requester-call tool, but it does not subscribe to Baileys `call` events or count received WhatsApp calls as contact activity.

## What This Changes

Request to subscribe to Baileys WhatsApp call events and expose call activity to OpenClaw agents so calls can count as user contact.

## Best Possible Solution

Implement a WhatsApp plugin-owned, default-off inbound call-event path that subscribes to Baileys `call`, applies existing account/sender/privacy gates, normalizes minimal metadata, documents the exposure surface, and covers it with focused unit plus live WhatsApp proof.
