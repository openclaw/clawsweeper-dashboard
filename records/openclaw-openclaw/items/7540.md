## Summary

Keep open: current main still does not subscribe to Baileys inbound WhatsApp call events, and the merged MeowCaller work is an outbound requester-bound call tool rather than the requested inbound activity signal.

## What This Changes

Add support in the bundled WhatsApp plugin for detecting inbound Baileys call events so WhatsApp calls can count as contact activity.

## Best Possible Solution

Implement this inside the WhatsApp plugin as an opt-in, sanitized inbound call-event path with the same account, allowlist, DM/group, self-chat, and privacy boundaries as inbound messages, plus focused tests and docs; keep it separate from outbound MeowCaller calling.
