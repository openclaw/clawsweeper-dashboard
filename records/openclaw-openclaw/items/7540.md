## Summary

Current main still lacks inbound WhatsApp/Baileys call-event handling. The merged requester-bound MeowCaller work is outbound-only and explicitly distinct, while the remaining privacy, access-control, retention, configuration, and public event-contract choices need maintainer direction.

## What This Changes

Add WhatsApp call-event detection so agents can account for voice and video calls when evaluating contact activity.

## Best Possible Solution

Implement a WhatsApp-plugin-owned, opt-in normalized call-activity event that applies existing account and access-control rules, minimizes exposed identifiers, performs no durable retention by default, and leaves any contact-history persistence to a separately approved generic activity-store contract.
