## Summary

Keep open: current main still lacks inbound Baileys WhatsApp call-event handling, and the merged MeowCaller work only adds an outbound requester-bound call tool that explicitly leaves this inbound event request unresolved.

## What This Changes

Request adding opt-in WhatsApp/Baileys call-event tracking so agents can count WhatsApp voice/video calls as contact activity.

## Best Possible Solution

Implement plugin-owned, default-off inbound call-event handling in extensions/whatsapp with sanitized metadata, message-equivalent access controls, docs, and tests, then expose it through a maintainer-approved session/event/tool surface.
