## Summary

Keep open: current main still ignores Baileys inbound call events, while the merged MeowCaller work is outbound-only; implementation should wait for a maintainer decision on privacy, retention, and agent exposure.

## What This Changes

Add inbound WhatsApp voice/video call-event tracking from Baileys so contact activity can include calls as well as messages.

## Best Possible Solution

Implement a WhatsApp-plugin-owned, separately opt-in normalized call-activity event with no durable history initially, apply explicit account/DM/group/allowlist/self identity rules, and add persistence or query tooling only through a later reviewed SQLite-backed contract.

## Solution Assessment

No, not in the full proposed shape. The listener belongs in `extensions/whatsapp`, but session metadata, durable daily history, a query action, and a config key should not be introduced together before maintainers select the narrow privacy and storage contract.
