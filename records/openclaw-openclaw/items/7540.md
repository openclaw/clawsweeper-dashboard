## Label Justifications

- `P2`: This is a bounded WhatsApp channel enhancement with clear user value but it is not a production regression or release-blocking setup failure.
- `impact:security`: WhatsApp call events include sensitive contact, timing, status, and group/DM metadata that need explicit privacy boundaries before exposure.
- `impact:session-state`: The requested behavior is to make contact activity state reflect calls as well as messages, so it affects session/activity memory semantics.

## Summary

Keep open: current main still lacks inbound Baileys WhatsApp call-event handling, and the merged MeowCaller work only adds an outbound requester-bound call tool. The remaining work is a valid WhatsApp-plugin feature, but it needs maintainer product and security direction before implementation because call events expose contact/activity metadata.

## What This Changes

The issue requests support for Baileys WhatsApp `call` events so WhatsApp call activity can count as contact history, not only message activity.

## Best Possible Solution

Implement this inside the WhatsApp plugin by subscribing to Baileys `call`, normalizing and sanitizing events, applying the same account/access/privacy boundaries as inbound messages, and exposing an explicit documented opt-in activity/session or plugin-hook surface distinct from outbound `whatsapp_call`.

## Reproduction Assessment

Yes for source reproduction: current main subscribes to `messages.upsert` and `connection.update`, while the pinned Baileys package exposes a typed `call` event that OpenClaw does not attach. I did not run a live WhatsApp call because the feature is not implemented and the exposure/privacy model is unsettled.

## Solution Assessment

Unclear until maintainers choose the exposure model; the narrowest maintainable direction is WhatsApp-plugin-owned call-event ingestion with explicit opt-in, access-control filtering, sanitized activity/session exposure, and focused tests/docs. The merged MeowCaller outbound tool is adjacent and not the best fix for inbound call tracking.
