## Summary

Keep open: current main still lacks inbound Baileys WhatsApp call-event handling, and the merged MeowCaller work only adds an outbound requester-bound call tool that does not satisfy this contact-activity request.

## What This Changes

Request support for subscribing to Baileys WhatsApp voice/video call events and exposing sanitized call activity to agents or plugins.

## Best Possible Solution

Implement plugin-owned, default-off inbound call-event handling in `extensions/whatsapp` with sanitized metadata, message-equivalent access controls, focused tests/docs, and a maintainer-approved event or activity surface.
