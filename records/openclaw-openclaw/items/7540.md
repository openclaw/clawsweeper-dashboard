## Summary

Keep open: current main and v2026.6.11 still do not subscribe to inbound Baileys call events, and the merged MeowCaller work is adjacent outbound-call support only. The remaining work is valid WhatsApp-plugin-owned feature work that needs product, privacy, and security direction before implementation.

## What This Changes

Request to subscribe the WhatsApp plugin to Baileys `call` events and expose sanitized call activity so agents can count WhatsApp calls as contact.

## Best Possible Solution

Implement this inside `extensions/whatsapp` as an opt-in, sanitized inbound call-activity surface with account, allowlist, group/DM, self-chat, retention, docs, and tests clearly separated from the outbound MeowCaller `whatsapp_call` tool.
