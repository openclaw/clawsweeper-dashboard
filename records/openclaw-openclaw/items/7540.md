## Summary

Keep open: current `main` still lacks inbound Baileys WhatsApp `call` event handling. The merged MeowCaller work is an adjacent outbound `whatsapp_call` tool and does not solve the requested call-activity/contact-history signal.

## What This Changes

Add WhatsApp/Baileys inbound call-event detection so voice/video call activity can count as contact history for agents.

## Best Possible Solution

Keep this open and implement a WhatsApp-plugin-owned, default-off or explicitly opted-in inbound call-activity surface after maintainers decide metadata minimization, retention, access control, and exposure boundaries; do not fold it into PSTN voice-call or outbound MeowCaller work.
