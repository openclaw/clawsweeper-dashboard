## What This Changes

Prevent steering during an active tool call from modifying the session transcript in a way that aborts the embedded agent with `EmbeddedAttemptSessionTakeoverError`.

## Best Possible Solution

Make the active embedded session the sole owner of transcript persistence: route inbound steering into its in-memory Pi steering queue, commit it under the existing attempt session-lock controller at a tool boundary, and add a regression that proves the original tool call completes or is safely interrupted without takeover or message loss.
