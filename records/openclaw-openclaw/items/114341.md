## What This Changes

The PR routes manual Linux update-check terminal results to a native notification as well as the main WebView when that window is showing the remote Gateway dashboard.

## System Context

The Linux desktop companion runs update checks from the tray and normally delivers their terminal results to the main WebView. Once that window navigates from its local bootstrap page to the Gateway dashboard, this PR selects the existing native-notification channel so a manually requested result remains visible.
