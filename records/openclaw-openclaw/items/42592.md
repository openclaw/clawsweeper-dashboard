## Summary

Keep open: current main and v2026.6.11 have partial npm diagnostics and a few targeted retries, but the requested installer error classification, transient retry policy, and cross-platform permission recovery remain unresolved and need maintainer direction.

## What This Changes

The issue requests structured installer error handling, clearer npm remediation, and bounded retries for transient install failures instead of ambiguous best-effort error masking.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries in Bash and PowerShell, with a visible installer Fix/Doctor-style path for permission recovery instead of requiring users to inspect logs or hand-edit config.
