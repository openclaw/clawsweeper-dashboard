## Summary

Keep open: current main and v2026.6.11 have partial npm diagnostics and targeted installer retries, but the requested structured retry/remediation policy is still unresolved and needs maintainer direction.

## What This Changes

Request to add structured installer error classification, actionable npm remediation, and bounded retries instead of opaque or best-effort failure handling.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries in Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
