## Summary

Keep open: current main and the latest release still provide only partial installer diagnostics and targeted retries, while the requested cross-platform npm error classification, retry, and remediation policy remains unresolved.

## What This Changes

The issue requests structured installer error handling, clearer npm failure guidance, and bounded automatic retries for transient install failures.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries across Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
