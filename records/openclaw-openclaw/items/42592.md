## Summary

Keep open: current main and the latest release still only provide partial npm diagnostics and targeted installer retries, while the requested cross-platform installer retry/remediation policy remains a maintainer product decision.

## What This Changes

Request to add structured installer error classification, clearer npm remediation, bounded retries for transient install failures, and less error masking in setup scripts.

## Best Possible Solution

Define a narrow cross-platform installer error policy first, then implement classified npm diagnostics, bounded transient retries, and platform-specific EACCES guidance or repair while preserving optional setup probes unless maintainers choose stricter behavior.
