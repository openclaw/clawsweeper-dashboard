## Summary

Keep open: current main and v2026.6.11 still provide only partial npm install diagnostics and targeted retries, while the requested cross-platform retry/remediation policy remains unresolved and needs maintainer direction.

## What This Changes

The issue requests structured installer error classification, clearer remediation guidance, and bounded retry behavior for npm/install setup failures.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries in Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
