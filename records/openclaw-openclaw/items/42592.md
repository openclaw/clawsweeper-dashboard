## Summary

Keep open: current main and the latest release have partial installer diagnostics and targeted cleanup retries, but not the requested cross-platform structured npm error policy, transient retry policy, or remediation boundary.

## What This Changes

The issue asks for structured installer error handling, clearer npm failure diagnostics, and retry/remediation behavior for transient install failures.

## Best Possible Solution

Define a conservative installer error policy first, then implement shared POSIX/Windows diagnostics that retry only clearly transient network failures and give explicit remediation for permission, disk, engine, package, and certificate failures.
