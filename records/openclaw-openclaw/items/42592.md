## Summary

Keep open: current main and v2026.6.11 still only partially handle installer npm failures, and the requested structured retry/remediation policy needs maintainer direction before implementation.

## What This Changes

The issue requests structured installer error classification, clearer remediation text, and smart retries for npm/network/permission failures instead of generic retries or best-effort error masking.

## Best Possible Solution

Define a conservative cross-platform installer error policy first, then implement shared diagnostics and transient-only retry behavior across POSIX, PowerShell, local-prefix, and container setup paths with focused tests.
