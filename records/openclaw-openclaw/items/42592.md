## Summary

Keep open: current main and v2026.6.11 still provide partial installer npm diagnostics and a few targeted retries, but the requested cross-platform structured retry/remediation policy remains unresolved and product-sensitive.

## What This Changes

The issue asks for structured installer error classification, clearer npm remediation guidance, and bounded smart retries for transient install failures.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries across Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
