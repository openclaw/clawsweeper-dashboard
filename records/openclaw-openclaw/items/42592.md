## Summary

Keep open: current main and v2026.6.11 still provide only partial npm diagnostics and targeted installer retries, while the requested cross-platform error classification, retry, and remediation policy needs maintainer direction.

## What This Changes

Request structured installer npm error classification, clearer remediation, and bounded retry handling for setup failures.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm diagnostics and bounded retries in Bash and PowerShell while keeping optional Docker probes best-effort unless maintainers choose stricter setup behavior.
