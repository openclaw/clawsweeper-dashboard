## Summary

Keep open: current main and v2026.6.11 still provide partial installer npm diagnostics and targeted cleanup retries, but the requested cross-platform structured retry/remediation policy remains unresolved and product-sensitive.

## What This Changes

The issue requests structured installer error classification, clearer remediation guidance, and smarter retry behavior for transient npm/install failures.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries in Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
