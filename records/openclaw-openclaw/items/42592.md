## Summary

Keep open: current main and v2026.6.11 still only partially diagnose installer npm failures, and the requested cross-platform retry, EACCES recovery, and optional probe policy remains a maintainer product decision.

## What This Changes

The issue requests structured installer error codes, clearer npm failure guidance, and smart retries for transient setup failures.

## Best Possible Solution

Define a narrow installer policy: classify known npm failures, retry only idempotent transient network failures, provide inline recovery or Doctor handoff for permission/disk/engine failures, and keep optional probes best-effort unless maintainers choose stricter setup behavior.
