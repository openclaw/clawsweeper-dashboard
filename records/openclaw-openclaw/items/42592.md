## Summary

Keep open: current main and v2026.6.11 still have partial installer npm diagnostics and selected cleanup retries, but they do not implement the requested structured retry/remediation policy across Bash, local-prefix, PowerShell, and container setup paths.

## What This Changes

The issue requests structured installer error classification, clearer remediation messages, and bounded retries for transient npm and setup failures.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries in Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
