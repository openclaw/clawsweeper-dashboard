## Summary

Keep open: current main and the latest release have partial installer diagnostics plus a few targeted retries, but the requested cross-platform structured npm error policy and retry/remediation behavior is still not implemented and needs maintainer direction before a safe repair PR.

## What This Changes

The issue requests structured installer error classification, clearer remediation text, and intelligent retries for transient npm/install failures instead of broad error masking or generic retry behavior.

## Best Possible Solution

Define a conservative installer error policy first, then implement shared POSIX/Windows diagnostics that retry only transient network failures, give explicit remediation for permission/disk/engine/package errors, and avoid silent security or config-probe behavior changes.
