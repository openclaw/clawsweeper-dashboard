## Summary

Keep open: current main and v2026.6.11 still only partially diagnose installer npm failures; the requested cross-platform error taxonomy, retry policy, EACCES recovery, and optional-probe policy remain unresolved.

## What This Changes

The issue requests structured installer error classification, smarter retry behavior for transient npm/network failures, clearer user recovery guidance, and less error masking in setup probes.

## Best Possible Solution

Define a narrow cross-platform installer policy: classify known npm failures, retry only transient idempotent network cases, provide non-technical recovery or Doctor handoff for permission/disk/engine/TLS failures, and keep optional probes best-effort unless maintainers choose stricter setup behavior.
