## Summary

Keep open: current main and the latest release still provide partial npm diagnostics and targeted cleanup retries, but the requested cross-platform structured retry/remediation policy remains unimplemented and product-sensitive.

## What This Changes

The issue requests structured installer/npm error classification, clear remediation messages, and bounded retry behavior for transient install failures.

## Best Possible Solution

Define a maintainer-approved narrow installer error policy, then implement classified npm diagnostics and bounded retries in Bash and PowerShell while leaving optional setup probes best-effort unless that policy changes.
