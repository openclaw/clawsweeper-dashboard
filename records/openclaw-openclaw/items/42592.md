## Summary

Keep open: current main and v2026.6.11 have partial npm diagnostics plus targeted cleanup retries, but the requested cross-platform structured npm error policy and retry/remediation behavior is still missing and needs maintainer policy direction.

## What This Changes

The issue asks OpenClaw to add structured installer error classification, clearer npm remediation messages, and intelligent retry behavior instead of broad error suppression.

## Best Possible Solution

Define a conservative cross-platform installer failure policy: parse npm codes consistently, retry only clearly transient network failures, provide explicit remediation for permission, disk, engine, package, and certificate errors, and preserve intentional best-effort setup probes.
