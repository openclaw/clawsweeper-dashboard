## Summary

Keep open: current main and v2026.6.11 only partially cover npm installer diagnostics and targeted retries; the broader cross-platform retry/remediation policy still needs maintainer product direction.

## What This Changes

Request to add structured npm installer error classification, clearer remediation guidance, bounded retries, and less failure masking in installer/setup scripts.

## Best Possible Solution

Define a narrow installer error policy, then implement classified npm failure guidance and bounded transient retries in Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
