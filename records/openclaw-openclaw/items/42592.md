## Summary

Keep open: current main and the latest release have partial installer diagnostics and a few targeted retries, but the requested cross-platform structured npm error policy, transient retry rules, and remediation behavior are still missing and need maintainer direction.

## What This Changes

The issue requests structured installer error classification, clearer npm remediation, and smarter retry behavior for transient install failures.

## Best Possible Solution

Define a conservative installer error policy first, then implement shared POSIX/Windows diagnostics that retry only clearly transient failures, provide explicit remediation for permission/disk/engine/package errors, and preserve intentional best-effort setup probes.
