## Summary

Keep open: current main and v2026.6.11 still only partially diagnose npm install failures, while the requested cross-platform retry, EACCES recovery, and fail-open/fail-closed installer policy is not implemented and needs maintainer direction.

## What This Changes

The issue requests structured npm/install error classification, clearer recovery guidance, and bounded retries for transient installer failures.

## Best Possible Solution

Define a narrow installer policy: classify known npm failures, retry only idempotent transient network failures, provide inline non-technical recovery or Doctor handoff for permission/disk/engine failures, and keep optional probes best-effort unless maintainers choose stricter setup behavior.
