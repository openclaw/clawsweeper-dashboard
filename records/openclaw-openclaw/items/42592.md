## Summary

Keep open: current main and v2026.6.11 still provide only partial npm diagnostics and selected cleanup retries, while the related macOS EACCES install report shows a remaining cross-platform installer policy gap.

## What This Changes

The issue requests structured installer error classification, clearer npm remediation guidance, bounded smart retries, and explicit handling for currently masked best-effort config reads.

## Best Possible Solution

Define a narrow cross-platform installer error policy, then implement classified npm guidance and bounded retry behavior in each hosted installer without hard-failing optional probes by default.
