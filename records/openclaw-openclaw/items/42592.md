## Summary

Keep open: current main and the latest release still only provide partial npm diagnostics and targeted installer retries, while the requested cross-platform retry/remediation policy remains a maintainer product decision.

## What This Changes

The issue requests structured installer error handling, clearer npm failure remediation, bounded retries for transient failures, and less error masking in setup scripts.

## Best Possible Solution

Define a narrow installer error policy first, then implement classified npm failure guidance and bounded retries in Bash and PowerShell while keeping optional setup probes best-effort unless maintainers choose stricter behavior.
