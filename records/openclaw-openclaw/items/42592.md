## Summary

Keep open: current main and v2026.6.11 have partial installer diagnostics plus a few targeted retries, but the requested cross-platform structured npm error policy and retry/remediation behavior is still missing and needs maintainer direction.

## What This Changes

Request to add structured installer error classification plus intelligent retry/remediation for npm install and setup config failures.

## Best Possible Solution

Define a conservative installer error policy first, then implement shared POSIX, PowerShell, and install-cli diagnostics that retry only clearly transient network errors and give explicit remediation for permission, disk, engine, package, and TLS failures.
