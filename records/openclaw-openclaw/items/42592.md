## Summary

Keep open: current main and v2026.6.11 still only partially handle installer npm failures, and the requested cross-platform structured retry/remediation policy needs maintainer direction before implementation.

## What This Changes

Requests cross-platform installer error handling with structured npm error classification, transient retries, permission remediation guidance, and less masking of setup probe failures.

## Best Possible Solution

Define a conservative installer error policy first, then implement shared POSIX, PowerShell, and install-cli diagnostics that retry only clearly transient network errors and give explicit remediation for permission, disk, engine, package, and TLS failures.
