## Summary

Keep open: current main and v2026.6.11 still only partially diagnose npm install failures, while the requested cross-platform retry, EACCES recovery, and optional-probe failure policy remains a maintainer product decision.

## What This Changes

The issue requests structured installer error classification, clearer npm failure guidance, and smart retries or repair for transient and permission-related installation failures.

## Best Possible Solution

Define a narrow cross-platform installer policy: classify known npm failures, retry only idempotent transient network cases, provide inline non-technical recovery or Doctor handoff for permission/disk/engine failures, and keep optional probes best-effort unless maintainers choose stricter setup behavior.
