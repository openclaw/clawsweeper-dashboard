## Summary

This is a narrow, source-compatible fix for the reported source-build regression: it preserves `node-llama-cpp`’s package-relative `import.meta.url` asset lookup by using the plugin’s existing resolved module URL. The supplied terminal evidence shows the built plugin resolving the dependency from installed `node_modules`, so the PR remains necessary and appears ready for normal maintainer review rather than cleanup closure.

## What This Changes

The PR changes the llama-cpp runtime loader to dynamically import `node-llama-cpp` from the plugin-resolved package URL instead of a bundler-followable package literal.

## Best Possible Solution

Merge the narrow resolved-URL import change after the remaining required CI completes, preserving node-llama-cpp as an external runtime dependency with package-relative native assets.
