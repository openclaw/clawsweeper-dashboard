## Best Possible Solution

## Reproduction Assessment

## Solution Assessment

Mostly yes for the narrow cache leak: terminal lifecycle cleanup is the owner-local place to release this per-session cache entry, and `spawnedBy` is immutable so re-reading on a later run is safe. It is not a complete solution for the broader RSS tracker until the branch is rebased, proof is real-runtime, and the wording is scoped.
