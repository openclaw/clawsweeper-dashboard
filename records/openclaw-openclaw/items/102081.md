## Summary

Keep open: current main and the latest release still prompt when an allowlisted gateway exec command lacks an enforceable POSIX authorization plan; the reporter's updated shell-shaped trigger matches the inspected source and tests, so this needs maintainer/security-boundary direction rather than cleanup.

## What This Changes

The issue asks OpenClaw to stop prompting on macOS for allowlisted `tools.exec` commands under `ask: "on-miss"` when command text includes shell syntax such as `~`, or to document that limitation.

## Best Possible Solution

Teach gateway exec to materialize safe enforceable Darwin plans for deterministic tilde/simple shell shapes, keep explicit approval for unmodelled expansion or carrier cases, and document any remaining command-shape limits.
