## Summary

Keep open: current main and v2026.6.11 still contain the allowlist-plan approval gate and exact warning for allowlist-matched commands when no enforced command can be built, while the docs still describe `on-miss` as prompting only on allowlist misses. This is not conservative cleanup; it needs maintainer/security-boundary review.

## What This Changes

The issue asks OpenClaw to stop prompting on Darwin for allowlist-matched exec commands, especially shell-shaped commands such as tilde paths or chains, under `security: "allowlist"` and `ask: "on-miss"`.

## Best Possible Solution

Normalize only narrow safe shell shapes into enforceable Darwin commands, or document the prompt-only limitation clearly; do not auto-execute raw shell text without an enforcement story.
