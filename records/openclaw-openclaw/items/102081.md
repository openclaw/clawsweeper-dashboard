## What This Changes

The issue requests that macOS gateway exec with `security: "allowlist"` and `ask: "on-miss"` auto-execute matched allowlist commands instead of prompting every time.

## Best Possible Solution

Preserve the documented `on-miss` behavior for enforceable Darwin allowlist matches, keep explicit approval for truly unenforceable plans, and add macOS-focused regression proof plus docs for any intentional limitation.
