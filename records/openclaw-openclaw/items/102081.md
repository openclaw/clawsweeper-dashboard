## Summary

## What This Changes

The issue reports that macOS gateway exec allowlist matches using shell-shaped command text prompt instead of auto-running under `ask: "on-miss"`, causing approval floods and cron timeouts.

## Best Possible Solution

Preserve the documented `on-miss` behavior for enforceable Darwin allowlist matches, keep explicit approval for truly unenforceable shell plans, and add precise docs/warnings for any intentional limitation.
