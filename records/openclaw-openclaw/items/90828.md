## Summary

Keep this PR open, but do not merge the current head. Current main and the latest release still reproduce the stderr-suppression regression, while the newly added retention helper can overwrite stderr appended by a running LaunchAgent; real macOS behavior proof and a maintainer retention decision also remain outstanding.

## What This Changes

The PR routes macOS LaunchAgent stderr to `gateway.err.log`, exposes that log through diagnostics and documentation, and caps oversized stderr files when rewriting the LaunchAgent plist.

## Best Possible Solution

Stop or hand off the LaunchAgent writer before compacting its stderr sink, coordinate continuous retention with the existing canonical retention work, and prove installation, failure capture, bounded storage, and diagnostic readback on a real macOS host.
