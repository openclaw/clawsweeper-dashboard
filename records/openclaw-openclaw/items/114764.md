## What This Changes

The PR changes Control UI session hydration so Gateway snapshots do not trigger extra `sessions.list` requests after initial connection hydration, and adds a regression test for repeated metadata snapshots.

## System Context

The Control UI session capability listens to Gateway connection snapshots and event notifications, then subscribes to session updates and retrieves the session list for display. Gateway lifecycle changes and session mutations feed this capability; its resulting state drives the Control UI’s session views.
