## Summary

Keep open for product direction. Current main supports generic estimated-cost reporting, but Ollama intentionally assigns zero cost to both discovered and manually configured models, so hypothetical Ollama pricing remains unsupported.

## What This Changes

Requests an Ollama cost-simulation setting to estimate expenses as if local model usage were billable.

## Best Possible Solution

Preserve zero cost for automatically discovered local models, honor an explicitly configured common model cost object as a hypothetical estimate, and clearly distinguish estimated values from actual provider billing across usage surfaces.
