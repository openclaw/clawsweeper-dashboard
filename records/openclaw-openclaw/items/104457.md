- `impact:other`: The issue has concrete browser reliability and repeated-side-effect impact outside the narrower owned issue-impact categories.

## Summary

Current `main` and the latest release under-budget valid sequential browser actions: composite waits and nested batches can outlive their outer watchdogs. The issue is actionable and well-scoped, but its protected `maintainer` label requires explicit maintainer handling rather than cleanup closure or automatic repair intake.

## What This Changes

Fix browser `/act` watchdog budgeting so composite waits and recursively nested batches receive enough outer transport time to finish their bounded sequential execution.

## Best Possible Solution

Add one policy-owned recursive execution-budget resolver that normalizes leaf costs, saturates sequential sums, preserves explicit outer overrides, applies transport slack once, and is shared by the direct client, node proxy, and CLI.
