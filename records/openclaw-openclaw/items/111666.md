## What This Changes

This PR pauses the isolated-agent setup timeout while a cron job waits for nested-lane admission, then changes operator-cancelled one-shot runs so they stop without retrying or increasing failure counters.

## System Context

The cron service schedules isolated-agent jobs through execution lanes and uses a watchdog to distinguish runner setup stalls from queued work. After each run, cron applies the outcome to persisted job scheduling, retry, alert, and error-counter state.
