## What This Changes

## Best Possible Solution

Keep strict registry-integrity verification and clean rebuilding, but merge only after the installer owner confirms that preserving the old tree solely for inspection—not automatic rollback—is the intended security and upgrade contract, with the returned error clearly identifying the retry or recovery path.
