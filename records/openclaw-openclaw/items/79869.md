  - body: This branch turns a targeted zero-interval exec event with `heartbeat.target: "none"` into `target: "last"` whenever the event has delivery context.   - confidence: 0.9
- **[P2] Requeue deferred zero-interval exec events:** `src/infra/heartbeat-runner.ts:2242-2243`
  - body: When the fallback agent state defers a second exec event with `not-due` or `min-spacing`, the wake layer does not retry that reason and `scheduleNext()` has no interval-backed agent to arm. The completion event can remain queued until an unrelated wake happens after cooldown, so close background exec finishes can still be lost or delayed indefinitely.
  - confidence: 0.86
