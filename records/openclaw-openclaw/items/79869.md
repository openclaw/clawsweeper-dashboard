- **[P1] Preserve target none for exec completions:** `src/infra/heartbeat-runner.ts:1314-1315`
  - body: This branch converts an explicit `heartbeat.target: "none"` into `target: "last"` whenever a zero-interval exec event has stored delivery context. That opt-out currently suppresses user delivery; with this change, background command output can be pushed to a channel even though the operator configured no heartbeat delivery.
  - confidence: 0.9
- **[P2] Requeue deferred fallback exec events:** `src/infra/heartbeat-runner.ts:2244-2245`
  - body: When the zero-interval fallback agent returns `not-due`, `min-spacing`, or `flood`, the wake layer will not requeue it because it only retries busy skip reasons, and `scheduleNext()` ignores the fallback map. A second background exec finishing during cooldown can therefore leave its completion event queued indefinitely until another unrelated wake occurs.
  - confidence: 0.86
