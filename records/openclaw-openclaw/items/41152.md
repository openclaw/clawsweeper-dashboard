## Summary

Keep open: current main still leaves the explicit async gateway approval follow-up path on the compact 400-character formatter, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate for the remaining fix.

## What This Changes

The issue reports that async gateway exec approval results delivered back to the agent are tailed to about 400 characters and have newline boundaries collapsed before the agent sees them.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so async gateway approval-completion follow-ups preserve captured output and newlines while ordinary background notifyOnExit summaries remain compact.
