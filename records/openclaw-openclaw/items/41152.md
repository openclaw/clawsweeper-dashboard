## Summary

Keep open: current main and latest release still use the compact 400-character, whitespace-normalizing formatter for explicit async gateway approval follow-ups, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate.

## What This Changes

Async gateway exec approval follow-up results should preserve captured multiline output instead of tailing to roughly 400 characters and flattening whitespace.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so async approval-completion follow-ups preserve captured output and newlines while ordinary background notifyOnExit summaries remain compact.
