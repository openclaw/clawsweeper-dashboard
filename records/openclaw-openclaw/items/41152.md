## Summary

Keep open: current main still compacts explicit async gateway exec approval follow-ups to a 400-character whitespace-normalized tail, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate for the remaining fix.

## What This Changes

Async gateway exec approval follow-up results can be delivered to the agent as a compacted tail instead of the full multiline command output.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so explicit async gateway approval-completion follow-ups preserve captured multiline output while ordinary background notifyOnExit summaries remain compact.
