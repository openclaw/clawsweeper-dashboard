## Summary

Keep open: current main and v2026.6.11 still route the explicit async gateway approval follow-up through the compact 400-character notification formatter, while https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate for the remaining fix.

## What This Changes

The issue reports that async gateway exec approval completion messages delivered back to the agent drop the beginning of long output and collapse multiline output into one line.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so async gateway approval-completion follow-ups preserve captured output and newlines while ordinary background notifyOnExit summaries remain compact.
