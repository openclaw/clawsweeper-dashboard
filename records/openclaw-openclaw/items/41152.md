## Summary

Keep open: current main and v2026.6.11 still compact explicit async gateway exec approval follow-ups to a 400-character whitespace-normalized tail, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate for the remaining fix.

## What This Changes

The issue reports async approved gateway exec results being delivered to the agent as a newline-stripped 400-character tail instead of the full captured output.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so explicit async gateway approval-completion follow-ups preserve captured multiline output while ordinary background notifyOnExit summaries remain compact.
