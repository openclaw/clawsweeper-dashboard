## What This Changes

Preserve multiline output from asynchronously approved gateway exec commands when the completion result is delivered back to the agent.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so explicit async gateway approval-completion follow-ups preserve retained multiline output while ordinary background notifyOnExit summaries stay compact.
