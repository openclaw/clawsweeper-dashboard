## Summary

Keep open: current main and the latest release still use the compact approval follow-up formatter on the async gateway path, while https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate and has not merged.

## What This Changes

The issue reports that async gateway exec approval results delivered back to the agent are compacted to a roughly 400-character single-line tail.

## Best Possible Solution

Land a narrow fix that preserves full captured output and newline boundaries for async approval follow-ups, adds a clear capture-cap truncation notice, and leaves ordinary background `notifyOnExit` summaries compact.
