## Summary

Keep open: current main and v2026.6.11 still contain the compact async gateway approval follow-up formatter, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate for the remaining fix.

## What This Changes

The issue reports that async approved gateway exec results delivered back to the agent are truncated to a compact tail and have newlines flattened.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92185 so async gateway approval-completion follow-ups preserve captured output and newlines while ordinary background notifyOnExit summaries remain compact.
