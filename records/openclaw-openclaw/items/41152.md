## Summary

Keep open: current main and the latest release still compact explicit async gateway exec approval follow-ups to a 400-character whitespace-normalized tail, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate for the remaining fix.

## What This Changes

Preserve multiline async gateway exec approval output in the agent System follow-up instead of delivering a 400-character whitespace-normalized tail.

## Best Possible Solution
