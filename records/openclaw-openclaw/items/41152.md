## Summary

Keep open: current main and v2026.6.11 still compact explicit async gateway exec approval follow-ups to a 400-character whitespace-normalized tail, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate rather than a merged fix.

## What This Changes

The issue asks OpenClaw to preserve multiline async gateway exec approval output in the agent-delivered System follow-up instead of sending a truncated single-line tail.

## Best Possible Solution

Fix and land https://github.com/openclaw/openclaw/pull/92185, or replace it with an equivalent narrow PR, so explicit async gateway approval-completion follow-ups preserve retained multiline exec output while ordinary background notifyOnExit summaries stay compact.
