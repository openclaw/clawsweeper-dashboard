## Summary

Keep open: current main still has the compact tail-and-normalize formatter on the remaining async gateway approval follow-up path, and https://github.com/openclaw/openclaw/pull/92185 is the open closing candidate.

## What This Changes

Preserve multiline gateway exec output in async approval follow-up System messages instead of sending a 400-character whitespace-normalized tail.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/92185, or an equivalent narrow formatter split, so approval-completion follow-ups preserve retained multiline exec output while ordinary background notifications stay compact.
