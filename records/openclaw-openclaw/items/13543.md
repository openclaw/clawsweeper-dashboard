## Summary

Keep open: current main and v2026.6.11 still provide session-scoped sandbox activation plus sandbox tool allow/deny filtering, but not the requested per-tool host-vs-sandbox placement contract; the discussion also shows unresolved security/product direction.

## What This Changes

Request a schema-backed per-tool sandbox placement mode that can sandbox web_fetch/browser while keeping exec/message/cron/gateway host-routed in the same session.

## Best Possible Solution

Define one documented core tool-placement contract with explicit precedence between session sandbox mode, tool/plugin declarations, gateway-owned tools, browser and web_fetch behavior, and elevated exec, then test placement separately from tool availability filtering.
