## Summary

Keep open: current main still exposes only session/agent sandbox modes plus allow/deny tool filtering and exec-specific host routing, not the requested per-tool host-vs-sandbox placement contract. The remaining work is a security-sensitive product/API design choice, so it should stay with maintainer review rather than be closed as implemented or automated as a small fix.

## What This Changes

Request per-tool sandbox placement so some tools can be forced into a sandbox, forced onto the host, or inherit the agent/session sandbox default.

## Best Possible Solution

Define one documented core placement contract with explicit precedence between session sandbox mode, tool/plugin declarations, gateway-owned tools, browser/web_fetch behavior, and elevated exec, then add focused tests that prove placement is separate from filtering.
