## Summary

Keep open: current main and the latest release still have SKILL.md metadata, ClawHub verification, install policy, and generic hooks, but not the requested versioned skill.yaml permission manifest with consent, audit/trust grades, signing, and attestation.

## What This Changes

Add a standard skill.yaml permission manifest with install-time review, audit/trust reporting, signing, and attestation for skills.

## Best Possible Solution

Define one versioned skill permission and trust contract coordinated with ClawHub verification, install/update consent, audit reporting, signing/attestation, and runtime enforcement hooks.
