## Summary

Keep open: current main and v2026.6.11 still lack the requested `skill.yaml` permission manifest, install-time consent/audit flow, trust grades, signing, and attestation contract. The linked package, ClawHub skill, fork, narrower RFC, and open PR are useful prior art, but they do not complete this OpenClaw-owned security boundary.

## What This Changes

Define a `skill.yaml` permission manifest standard for skills, with install-time review/audit, trust scoring, signing, attestation, and ClawHub integration.

## Best Possible Solution

Keep this open for a maintainer-approved, versioned skill permission manifest path that stages audit/consent first and explicitly coordinates ClawHub trust, signing/attestation, install policy, and runtime enforcement hooks.
