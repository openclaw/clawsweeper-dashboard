## Summary

Keep open: current main and v2026.6.11 have SKILL.md metadata, ClawHub trust checks, install policy, and generic hooks, but still no versioned skill.yaml permission manifest, install-time consent/audit command, trust grades, signing, or attestation contract. The linked external package, ClawHub skill, fork, RFCs, and open PR are useful prior art, but they do not replace the maintainer product/security decision for this core contract.

## What This Changes

The issue requests a standard skill.yaml permission/trust manifest for skills, with install-time permission review, audit/trust scoring, signing, and attestation integration.

## Best Possible Solution

Define one versioned skill permission and trust contract coordinated with ClawHub verification, install/update consent, audit reporting, signing/attestation, and runtime enforcement hooks.
