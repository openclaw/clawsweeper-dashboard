## Summary

Keep open: current main and v2026.6.11 still lack the requested skill permission manifest, install-time consent review, skills audit/trust grading, signing, and attestation contract. Existing ClawHub trust checks, operator install policy, generic hooks, the linked open-source package, ClawHub skill, and fork are useful prior art, not a complete OpenClaw-owned standard.

## What This Changes

Request a standardized skill permission manifest and trust, audit, signing, and attestation workflow for OpenClaw skills.

## Best Possible Solution

Define one versioned skill permission and trust contract coordinated with ClawHub verification, install/update consent, audit reporting, signing/attestation, and runtime enforcement hooks.
