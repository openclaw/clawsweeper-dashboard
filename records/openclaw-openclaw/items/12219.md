## What This Changes

The issue proposes a standardized `skill.yaml` permission manifest with install-time consent, signing, trust scoring, attestation, and runtime-enforcement integration for skills.

## Best Possible Solution

Adopt one maintainer-approved, versioned capability-manifest direction that defines the relationship among ClawHub metadata, direct install/update consent, runtime enforcement, signing/provenance, and the existing generic hooks before any implementation is scoped.
