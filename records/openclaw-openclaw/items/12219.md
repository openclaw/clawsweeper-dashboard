## Summary

Keep open: current main and the latest release still lack the requested standardized skill permission manifest, install-time consent, skills audit/trust grades, signing, and attestation; related plugins, forks, and PRs are useful prior art but not a complete OpenClaw contract.

## What This Changes

Requests a standardized `skill.yaml` permission manifest for skills, plus install review, audit/trust scoring, signing, and attestation integration.

## Best Possible Solution

Define one versioned skill permission and trust contract coordinated with ClawHub verification, install/update consent, audit reporting, signing/attestation, and runtime enforcement hooks.
