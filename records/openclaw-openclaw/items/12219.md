## Summary

Keep open: current main and v2026.6.11 still lack the requested standardized skill permission manifest, install-time consent/audit flow, trust scoring, signing, and attestation contract; related plugins, forks, RFCs, and PRs are useful prior art but do not complete the OpenClaw-owned security boundary.

## What This Changes

The issue requests a versioned `skill.yaml` permission manifest standard for skills, with install review, audit/trust scoring, signing, and attestation support.

## Best Possible Solution

Define one versioned skill permission and trust contract coordinated with ClawHub verification, install/update consent, audit reporting, signing/attestation, and runtime enforcement hooks.
