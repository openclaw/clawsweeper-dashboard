## Summary

This PR is still necessary because current main retains prototype-inclusive Firecrawl legacy lookups, but the current branch is not merge-ready: the fetch guard runs after Zod has materialized inherited input, the added schema is not a production contract, and the latest force-push broke the integration test.

## What This Changes

The PR replaces two Firecrawl legacy `in` checks with `Object.hasOwn`, exports the fetch resolver, adds a separate Firecrawl Zod schema, and adds three prototype-chain test suites plus extension-runner updates.

## Best Possible Solution

Reject inherited legacy Firecrawl keys at the raw core config boundary before Zod parsing, retain resolver-level `Object.hasOwn` only as defense-in-depth, remove the unregistered schema and test-only export, and prove the actual loader-to-provider path with focused tests and redacted output.
