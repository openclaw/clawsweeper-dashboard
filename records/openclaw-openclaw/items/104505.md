## What This Changes

Replaces Firecrawl legacy search and fetch config membership checks with `Object.hasOwn()` and adds resolver-focused regression tests plus extension-test harness updates.

## Best Possible Solution

Reject or sanitize inherited legacy Firecrawl configuration before Zod materializes it, add regression coverage through `validateConfigObjectRaw`, keep resolver-level ownership checks only as defense in depth, and prove the resulting runtime behavior with redacted output.
