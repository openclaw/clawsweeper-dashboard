The issue asks OpenClaw to keep Google simple-thinking disabled when a requested reasoning level is clamped to `off`.

## Best Possible Solution

Patch the Google simple-thinking helper to return disabled thinking when the clamped reasoning level is `off`, with focused regression coverage for Google and Vertex simple paths and no broader provider API expansion.
