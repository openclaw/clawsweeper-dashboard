## Best Possible Solution

Maintainers should choose the recovery policy explicitly; if this opt-in branch is the path, move retry identity to private queued metadata, rerun exact-head CI/QA proof, and keep the new config contract documented.

Unclear as submitted. The one-shot retry is a safer owner-boundary approach than bypass delivery, but the opt-in config surface needs maintainer policy approval and the retry marker should be private runtime metadata before merge.
