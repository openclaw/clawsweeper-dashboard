## Summary

Keep open. The PR is a focused TUI hyperlink boundary fix, but the current head still has a P2 blocker where a scheme-only wrapped fragment can choose a longer known URL that only shares the next-line prefix, making the visible shorter URL click through to the wrong target.

## What This Changes

The PR changes TUI OSC8 URL extraction and visible-range matching to reject malformed fragments, trim unmatched parenthesis suffixes, preserve parenthetical and IPv6 URLs, and adds focused regression coverage.

## Best Possible Solution

Update the scheme-only continuation path to resolve the next rendered token to the exact intended known URL before falling back to broader prefix behavior, add the short/long shared-prefix regression, and then refresh the dirty branch.

## Solution Assessment

No. The overall fix belongs in the right TUI OSC8 helper, but the current scheme-only continuation selection is too broad and should prefer an exact continuation target for the visible next-line URL.
