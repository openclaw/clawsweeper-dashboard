## What This Changes

The PR replaces text-based Control UI loading placeholders with a centered animated OpenClaw mascot during initial gateway connection, lazy-route loading, and Workboard enablement checks.

## System Context

The Control UI shows a full-screen connection state before the gateway is ready and a temporary placeholder while lazy page modules or Workboard configuration resolve. Once the connection, route, or configuration resolves, the app replaces that placeholder with normal content or retains the existing error/retry state.
