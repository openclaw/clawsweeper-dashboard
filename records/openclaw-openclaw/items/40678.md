## What This Changes

The issue requests a default-off TUI mode or setting that can observe or mirror iMessage, Telegram, cron, and other channel activity for the same agent without undoing isolated TUI sessions.

## Best Possible Solution

Keep this as the canonical design issue for a default-off, authorization-aware read-only TUI observer first; review selected-session live refresh separately and defer bidirectional mirroring until delivery and privacy policy are explicit.
