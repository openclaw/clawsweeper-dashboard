## Summary

The broader request needs maintainer product and security direction because it would expose transcript activity across channel and session boundaries.

## What This Changes

Request an opt-in TUI observe/mirror mode that can display iMessage, Telegram, cron, and other agent activity without reverting isolated TUI sessions.

## Best Possible Solution

Define an explicit read-only observe mode with channel/session scope, owner/operator authorization, and audit expectations, while keeping selected-session live-tail repair separate.
