## What This Changes

Options:

- **Read-only observer first (recommended):** Add a default-off `openclaw tui --observe` style mode that only shows authorized activity for the selected agent/session scope and defers bidirectional channel mirroring.
- **Full bidirectional mirroring:** Allow TUI and channel messages to appear across surfaces only after explicit delivery, authorization, redaction, and upgrade policy are designed.
- **No core observer mode:** Keep raw logs, session-specific live tailing, or a future activity timeline as the supported monitoring path and avoid a core cross-channel TUI feature.
