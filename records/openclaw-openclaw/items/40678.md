Options:

- **Read-only observer first (recommended):** Add a default-off `openclaw tui --observe` style mode that only shows authorized activity for an explicit agent/session scope and defers bidirectional channel mirroring.
- **Full bidirectional mirroring:** Allow TUI and channel messages to appear across surfaces only after specifying delivery, authorization, redaction, and upgrade policy.
- **No core observer mode:** Keep raw logs, selected-session live tailing, or a future activity timeline as the supported monitoring path and avoid core cross-channel TUI mirroring.
