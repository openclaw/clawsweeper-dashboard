## Summary

Keep open: current main and the latest release still lack the requested opt-in TUI cross-channel observe/mirror mode, while the active related PR only targets selected-session live transcript updates.

## What This Changes

The issue requests a default-off TUI mode or setting to observe or mirror iMessage, Telegram, cron, and other channel activity for the same agent without reverting isolated TUI sessions.

## Best Possible Solution

Define a default-off, security-reviewed read-only TUI observe mode or explicitly decline broad mirroring; keep selected-session live updates in the focused PR path.

- **Decline broad mirroring:** Keep core limited to selected-session live updates and direct users to logs or future design for all-channel monitoring.
