## Summary

Keep open: current main and the latest release still lack the requested opt-in TUI observe/mirror mode. The open related PR only addresses the narrower selected-session live-update bug, while this broader cross-channel visibility request needs maintainer product and security direction.

## What This Changes

The issue requests an opt-in TUI observe or mirror mode that can show iMessage, Telegram, TUI, cron, and other same-agent channel activity without undoing TUI session isolation.

## Best Possible Solution

Define an explicit, least-privilege TUI observer design before implementation, preferably read-only first, and keep broad channel-to-channel forwarding in plugin/ClawHub territory unless maintainers identify a missing core API.
