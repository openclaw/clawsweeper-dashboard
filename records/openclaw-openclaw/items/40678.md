## Summary

Keep open: current main and v2026.6.11 still do not provide an opt-in TUI observe or mirror mode, and the open related PR only targets the narrower selected-session live-update bug. The broader request needs maintainer product and security direction because it would expose transcript activity across channel and session boundaries.

## What This Changes

The issue requests an opt-in TUI mode or setting that mirrors or observes iMessage, Telegram, cron, and other channel activity for the same agent without undoing isolated TUI sessions.

## Best Possible Solution

Define an explicit read-only observe mode with channel/session scope, owner/operator authorization, and audit expectations, while keeping the narrow `session.message` live-tail fix as separate work.
