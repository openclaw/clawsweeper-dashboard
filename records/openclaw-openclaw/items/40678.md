## Summary

Keep open: current main and v2026.6.11 still lack an opt-in TUI cross-channel observe or mirror mode, and the open related PR only addresses the narrower selected-session live-update gap. The remaining request needs maintainer product and security direction because it would expose transcript activity across channel and session boundaries.

## What This Changes

Add an opt-in TUI observe or mirror mode for viewing iMessage, Telegram, and other channel activity for the same agent without reverting isolated TUI sessions.

## Best Possible Solution

Keep this as the canonical design issue for a default-off, authorization-aware TUI read-only observe mode, and handle bidirectional channel mirroring only after maintainers choose the transcript visibility boundary.
