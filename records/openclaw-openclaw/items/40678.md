Options:

- **Read-only observer first (recommended):** Add a default-off `openclaw tui --observe` style mode that only shows authorized activity for an explicit agent/session scope and leaves bidirectional channel mirroring out of scope.

- **No core observer mode:** Keep logs, selected-session views, and future activity timelines as the supported monitoring paths and avoid a core cross-channel TUI mirror feature.
