## Summary

## What This Changes

Request an opt-in TUI mode or config that displays iMessage, Telegram, cron, and other channel activity across the same agent without reverting isolated TUI sessions.

## Best Possible Solution

Define a scoped read-only observe mode with explicit channel/session boundaries and authorization, or formally keep support to selected-session live-tail plus logs; do not restore implicit cross-channel bleed.
