## Summary

Keep open: current main still has the lower-level agent delivery, sessions_send, and bounded A2A reply-loop building blocks, but not the requested dial/pickup/send/wrap meeting lifecycle, durable meeting artifact, pickup queue, visible frames, or transcript command. The RFC is concrete and has prior maintainer-scoping support, but implementation needs product and security decisions first.

## What This Changes

The issue requests a scoped agent teleconference primitive with CLI verbs, meeting lifecycle state, durable transcripts, visible channel frames, and an optional per-agent icon/config surface.

## Best Possible Solution

Keep this as the scoped meeting-lifecycle design item and settle storage, transcript privacy, authorization, and handoff layering before any implementation PR.
