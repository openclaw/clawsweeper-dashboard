## Summary

Keep open: current main and the latest listed beta still expose lower-level agent delivery and sessions_send/A2A loops, but not the requested meeting lifecycle, pickup queue, durable meeting artifact, visible frames, or transcript command. The RFC is concrete but needs maintainer product and security decisions before implementation.

## What This Changes

The issue requests a core agent teleconference lifecycle over existing agent delivery, with dial/pickup/send/wrap/list/show/transcript verbs and durable visible meeting transcripts.

## Best Possible Solution

Keep this as the scoped meeting-lifecycle RFC and require a narrow design decision on API shape, storage owner, transcript privacy, authorization, and handoff layering before accepting implementation.
