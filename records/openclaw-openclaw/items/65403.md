## Summary

Keep open: current main and v2026.6.11 still expose lower-level agent/session delivery primitives, but not the requested teleconference lifecycle, pickup queue, durable meeting artifact, visible meeting frames, or transcript command. Older related reports were closed in favor of this RFC, and the remaining work needs product, storage, and security decisions before implementation.

## What This Changes

The RFC requests first-party `openclaw agent teleconference` verbs for scoped agent meeting lifecycle, durable transcripts, visible channel frames, and optional agent icons.

## Best Possible Solution

Keep this as the canonical scoped meeting-lifecycle RFC, then accept only a narrow design or PR that settles API shape, SQLite/storage ownership, transcript privacy, authorization, and its relationship to the broader multi-agent collaboration track.
