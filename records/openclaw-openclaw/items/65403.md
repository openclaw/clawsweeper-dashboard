## Summary

Keep open: current main and the latest release still provide lower-level agent delivery, session tools, and bounded agent-to-agent reply loops, but not the requested dial/pickup/send/wrap meeting lifecycle, pickup queue, durable meeting artifact, visible meeting frames, or transcript command.

## What This Changes

The issue proposes a scoped agent teleconference primitive with CLI verbs, durable lifecycle state, visible channel frames, and transcript output built on existing agent/session delivery primitives.

## Best Possible Solution

Keep this as the scoped meeting-lifecycle RFC, then settle API shape, storage ownership, transcript privacy, authorization, and handoff layering before accepting an implementation PR.
