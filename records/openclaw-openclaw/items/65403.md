## Summary

Keep open: current main still has lower-level agent send, subagent, and `sessions_send` A2A reply/announce primitives, but it does not provide the requested teleconference lifecycle, pickup queue, meeting artifact, visible meeting frames, or transcript command. The RFC is concrete and has useful prototype evidence, but the next step is maintainer product and security direction rather than an automatic fix PR.

## What This Changes

Request to add an agent teleconference primitive with dial/pickup/send/wrap/list/show/transcript verbs, visible meeting frames, durable meeting artifacts, and optional per-agent icons.

## Best Possible Solution

Define a narrow first-party lifecycle layer only after maintainers settle the handoff, authorization, transcript privacy, and storage contract; if accepted, keep it above `sessions_send`/subagent primitives with SQLite-backed state and focused lifecycle/rendering tests.
