## Summary

Keep open: current main still has the lower-level `agent --to --deliver`, `sessions_send`, and bounded A2A reply loop building blocks, but not the requested meeting lifecycle, pickup queue, durable meeting artifact, visible meeting frames, or meeting transcript command. The RFC is concrete and has useful maintainer scoping context, but it still needs product and security decisions before a core implementation is safe.

## What This Changes

The issue requests an agent teleconference primitive with dial/pickup/send/wrap/list/show/transcript verbs, durable meeting lifecycle state, visible channel frames, and an optional agent icon config field.

## Best Possible Solution

A maintainer-sponsored design should either accept a minimal core `meet` lifecycle with explicit storage, authorization, transcript privacy, and handoff rules, or route the capability to a plugin/ClawHub path if core is not the right owner.
