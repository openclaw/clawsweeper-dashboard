## Summary

Keep open: current main and the latest stable release still provide lower-level agent send, session send, and bounded A2A reply loops, but not the requested dial/pickup/send/wrap meeting lifecycle, durable meeting artifact, visible meeting frames, or transcript command. The RFC is concrete, but it needs maintainer product, storage, and security decisions before implementation.

## What This Changes

The issue requests a first-party agent teleconference primitive with explicit meeting lifecycle verbs, durable transcripts, visible channel frames, and scoped agent-to-agent coordination.

## Best Possible Solution

Keep #65403 open as the scoped meeting-lifecycle RFC and require maintainer decisions on lifecycle API, SQLite-backed storage/artifact semantics, transcript privacy, authorization, and handoff layering before implementation.
