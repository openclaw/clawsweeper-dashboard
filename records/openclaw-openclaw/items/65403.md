## Summary

Keep open: current main and v2026.6.11 still expose lower-level agent delivery, session tools, and bounded A2A reply loops, but not the requested meeting lifecycle, pickup queue, durable meeting artifact, visible frames, or transcript command. The issue is the canonical scoped RFC for this area, but implementation still needs maintainer product and security decisions.

## What This Changes

The issue requests a scoped agent teleconference primitive with dial, pickup, send, wrap, list, show, and transcript verbs over existing agent delivery and session primitives.

## Best Possible Solution

Keep this as the scoped meeting-lifecycle RFC; settle storage ownership, transcript privacy, authorization, and the handoff API before accepting core teleconference verbs.
