## Summary

Keep open: current main has lower-level `agent --deliver` and `sessions_send` A2A building blocks, but it does not implement the requested meeting lifecycle, pickup queue, visible meeting frames, durable transcript/artifact, or `meet` command surface. The remaining work is a product and security design decision, especially because the proposal adds cross-agent state, transcript retention, and storage/config surfaces.

## What This Changes

The issue requests a first-party agent teleconference lifecycle with dial, pickup, send, wrap, list/show/transcript commands, visible channel frames, and durable meeting transcripts.

## Best Possible Solution

Keep #65403 as the canonical design item and require a narrow maintainer-approved MVP that reuses existing agent delivery/session primitives, stores canonical meeting state safely, and specifies transcript privacy before any fix PR.
