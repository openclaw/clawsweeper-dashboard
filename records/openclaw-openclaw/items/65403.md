## Summary

Keep open: current main and the latest checked release still provide lower-level delivery/session primitives, but not the requested meeting lifecycle, pickup queue, durable meeting artifact, visible meeting frames, or transcript command. The RFC has useful prototype evidence and a maintainer scoping comment, but it needs product and security decisions before implementation.

## What This Changes

The issue requests a scoped agent teleconference primitive with dial, pickup, send, wrap, list, show, and transcript verbs built over existing agent delivery/session primitives.

## Best Possible Solution

Land a narrow core meeting-lifecycle design only after maintainers settle storage ownership, transcript privacy, authorization, and the relationship to lower-level handoff semantics.
