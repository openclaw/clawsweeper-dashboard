## What This Changes

This PR reduces allocations during long Codex prompt-history rebuilds by making image-payload sanitization copy-on-write and skipping deep message snapshots when no message-bearing prompt hook is active.

## System Context

The Codex extension sanitizes history records before the embedded agent runner rebuilds a prompt. Prompt hooks may inspect and mutate an isolated snapshot, while authoritative conversation history continues into later prompt assembly unchanged.
