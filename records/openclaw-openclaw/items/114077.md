## Summary

This PR addresses a current P1 Google Meet ownership boundary: URL-less recovery can otherwise focus and permission-grant an unrelated tab in OpenClaw’s shared browser profile. The patch uses the runtime’s existing session/tab ownership signals rather than changing the shared meeting controller, and its pasted real-browser before/after transcript directly demonstrates the unsafe path becoming a zero-request refusal. Keep it open for normal owner review because it intentionally changes the existing URL-less recovery contract from broad discovery to fail-closed behavior.

## What This Changes

The PR makes URL-less Google Meet recovery operate only on a tab tracked by the calling runtime session, while preserving explicit-URL recovery and documenting the new scope.

## System Context

The Google Meet plugin exposes agent-tool and CLI recovery actions that call a browser transport to find, focus, permission-grant, and inspect an existing Meet tab. This change supplies session ownership information before the shared meeting-browser controller selects a tab, preventing one session from acting on another session’s meeting.

## Best Possible Solution

Adopt session-scoped URL-less recovery as the canonical safety boundary, retain explicit-URL recovery for intentional cross-session targeting, and ensure the documented refusal message remains actionable for CLI and tool callers.
