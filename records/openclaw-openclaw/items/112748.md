## What This Changes

The PR delays and coalesces Control UI session-catalog refreshes triggered by paired-node presence changes, avoiding immediate follow-up gateway requests while a refresh is scheduled or in flight.

## System Context

The Control UI sidebar listens to gateway presence and catalog-state changes, then requests the session catalog used to render available sessions. This live-state helper decides whether to refresh immediately or schedule the next catalog request, which affects both sidebar freshness and gateway request pressure.
