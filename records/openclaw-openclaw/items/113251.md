## What This Changes

Add an image preview for regular workspace image files opened in the Control UI file browser instead of rendering their binary contents in the text editor.

## System Context

The Control UI offers both session artifacts and regular workspace files. Artifact images already use an authorized download path and image lightbox, while regular file-browser selections follow the workspace-file retrieval path into the text editor; this request concerns adding a safe media-preview decision to that separate path.

## Best Possible Solution

Add a narrow workspace-file media-preview dispatch that reuses the established accessible lightbox only after the regular file path supplies an authorized image source; retain the text editor for non-image and unsupported files.
