## Summary

The PR remains necessary but is not merge-ready: the revised head protects active manager backoff and preserves bounded post-give-up revival, yet it still misclassifies timed-out recovery after prior attempts and can strand the channel. The earlier P1 therefore remains unresolved, and contributor real-runtime proof is still absent.

## What This Changes

The PR adds a three-state restart query to `ChannelManager`, skips health-monitor intervention during active manager backoff, and adds composed manager/monitor regression tests.

## Best Possible Solution

Give timed-out recovery explicit precedence as monitor-owned before evaluating attempt-based backoff, then add a composed regression for prior failed attempt → running task → non-manual stop timeout → successful next-pass replacement while retaining the bounded post-give-up policy.
