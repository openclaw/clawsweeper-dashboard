## What This Changes

## Best Possible Solution

Preserve transcript-only mirror identity across session rebuild/merge where it is lost, then add a narrowly tested replay-history guard that drops only adjacent identical no-tool assistant mirrors from model prompts while keeping receipt rows persisted for delivery idempotency.

## Reproduction Assessment

## Solution Assessment

Yes, if the fix keeps receipt persistence intact. The best path is not to suppress channel-final mirror appends, but to preserve mirror identity through session state transitions and add a bounded no-tool adjacent-duplicate prompt cleanup as defense in depth.
