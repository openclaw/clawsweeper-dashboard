## What This Changes

The PR makes OpenRouter’s official live model-catalog request use the existing trusted environment-proxy guard when callers do not provide a custom guard, with a regression test for that default.

## System Context

The OpenRouter plugin provides model definitions to OpenClaw’s model CLI and runtime. Its live catalog adapter uses the shared guarded-fetch and caching layer to retrieve OpenRouter’s fixed official endpoint, then retains bundled seed models when live discovery fails.
