## What This Changes

The branch makes package-manager detection resolve scoped and unscoped package roots to their owning `node_modules`, recognizes pnpm global-layout markers, and adds scoped, linked, pnpm-global, and Bun regression coverage.

## Best Possible Solution

Land the shared scoped-aware ownership resolver and pnpm global-marker detection as one canonical package-manager decision path, retaining the focused regression cases and existing shrinkwrap safeguards.
