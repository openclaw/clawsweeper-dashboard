## Summary

The PR fixes a real regression in the shared package-manager detector: scoped pnpm and Bun package roots currently bypass ownership checks and fall back to npm when the published package carries `npm-shrinkwrap.json`. The patch is narrowly placed, preserves the canonical npm-shrinkwrap behavior from the earlier fix, has convincing real pnpm proof, and introduces no blocking correctness or security finding; the exact-head CI failures are in unrelated gateway/session tests.

## What This Changes

The PR teaches package-manager detection to resolve scoped direct `node_modules` roots, recognize pnpm global ownership markers, read linked package metadata through its real path, and adds regression tests for scoped pnpm and Bun layouts.

## Best Possible Solution

Land the shared-detector fix with its scoped pnpm/Bun regression tests, preserving npm shrinkwrap precedence for ordinary published roots and using exact-head CI to guard integration drift.
