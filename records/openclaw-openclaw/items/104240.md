## What This Changes

The PR captures ordered LINE API message IDs for push and reply sends, normalizes every physical message into the receipt, and gives each receipt part its own message kind.

## System Context

The LINE channel turns outbound OpenClaw messages into LINE push or reply API calls and returns a normalized receipt to downstream delivery and tracking consumers. This PR changes the mapping from LINE's ordered `sentMessages` response into receipt IDs, primary ID, and per-message parts.
