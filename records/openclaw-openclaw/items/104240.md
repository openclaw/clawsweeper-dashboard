## Summary

The PR fixes the placeholder ID for single-message LINE pushes, but the current head still keeps only the first ID from a response that can identify up to five delivered messages. The existing media-plus-caption path and shared receipt model make that omission concrete, so the prior blocking finding remains.

## What This Changes

The PR captures the LINE push response, uses `sentMessages[0].id` as the send result and sole receipt ID, and updates focused send tests.

## Best Possible Solution

Pass every ordered `sentMessages[].id` into the existing receipt normalizer, retaining the first only as `LineSendResult.messageId` and `primaryPlatformMessageId`.
