The PR captures ordered message IDs from LINE push and reply responses, records every physical message in the receipt with its own kind, and extends the shared receipt normalizer with an optional per-result kind.

## System Context

The LINE channel converts outbound OpenClaw messages into LINE Messaging API push or reply calls. Their returned IDs are normalized into channel send receipts, which downstream delivery tracking and message-correlation code consume.
