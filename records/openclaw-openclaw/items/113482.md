## Summary

Keep this maintainer-labeled PR open. The OpenAI-compatible path wraps the planner schema as `json_schema` but omits `strict: true`, so supported OpenAI models do not receive the exact-schema guarantee that this feature advertises; the PR also needs inspectable after-fix live behavior evidence before merge.

## What This Changes

The PR adds a planner-only JSON Schema response format and maps it through the embedded-agent stream to Ollama, llama.cpp, and selected OpenAI-compatible model backends.

## System Context

The system-agent planner turns a user setup request into a small reply-and-command JSON plan, then sends that plan to an embedded model runner. This change adds provider-native constrained decoding before the tolerant planner parser converts the generated text into an action.
