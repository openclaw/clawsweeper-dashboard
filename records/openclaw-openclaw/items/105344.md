## Summary

Current main still contains the reported asynchronous overwrite: branch discovery guards against stale repository requests but not edits made after the active request starts. The issue is a valid, narrow Control UI bug, and the protected `maintainer` label requires explicit maintainer handling rather than cleanup closure or automatic repair intake.

## What This Changes

Preserve a manually edited or cleared New Session worktree base when an in-flight branch lookup resolves.

## Best Possible Solution

Track a base-field edit generation at the New Session page state owner, snapshot it when each branch lookup begins, and apply the discovered default only when both the request token and edit generation remain unchanged; add deferred-response browser coverage for typing and clearing the field.
