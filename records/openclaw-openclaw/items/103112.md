## Summary

This PR remains necessary because current main enables `localModelLean` without considering the active provider override. However, its hosted-provider table omits supported hosted families such as MiniMax and OpenCode, so those overrides can still inherit lean filtering and lose tools; exact-head live proof is also absent.

## What This Changes

The PR passes runtime provider, API, and model context into local-model lean filtering, classifies configured endpoints and provider identifiers as local or hosted, and adds embedded-runner and harness regression coverage.

## Best Possible Solution

Compute a closed local, hosted, or unknown fact at the model/provider resolution boundary from explicit `localService` and the resolved endpoint, then carry that prepared fact into embedded and harness tool policy with catalog-provider regressions and exact-head live proof.
