## What This Changes

The branch adds an SSRF-guarded provider-download helper, routes BytePlus and Runway generated-video artifact downloads through it, and propagates each provider's existing request policy to that final download step.

## System Context

OpenClaw's video-generation providers submit a job, poll the provider, and download a media URL returned in the completion payload before the agent tool saves the result as an attachment. The changed boundary is that final artifact download, where an untrusted provider-returned URL must obey the same private-network policy as the submit and poll requests.
