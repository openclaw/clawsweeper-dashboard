## What This Changes

The PR adds a shared SSRF-guarded provider-download helper, routes BytePlus and Runway generated-video downloads through it, and forwards each provider’s existing request-policy settings to the guarded download stage.

## Best Possible Solution

Accept the established default-deny SSRF policy for provider-supplied artifact URLs, retain models.providers.<id>.request.allowPrivateNetwork as the sole explicit private-endpoint escape hatch, and merge only after an owner approves the additive provider-HTTP SDK helper contract.
