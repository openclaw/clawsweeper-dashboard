## What This Changes

The PR waits for Gateway configuration convergence before a Claw creates cron work, accepts the scheduler’s trusted-policy default during cron reconciliation, and lets already-consented Claw removal pass a config-size-drop guard.

## System Context

Claws are experimental portable agent packages that create managed agent configuration, workspace state, and optional scheduled jobs. The CLI commits configuration, the Gateway reloads that configuration, and Claw lifecycle state records whether the associated cron jobs and agent can be safely reconciled or removed.
