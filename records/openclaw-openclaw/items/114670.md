## What This Changes

The branch waits for the Gateway to apply a newly committed Claw agent configuration before creating cron jobs, accepts the scheduler’s trusted-policy defaults during removal drift checks, and permits a consented Claw removal to bypass the generic config-size-drop guard.

## System Context

Claws are experimental portable agent packages that use the CLI to create a managed agent, install packages and scheduled work through the Gateway, and later remove only resources recorded in lifecycle provenance. This patch sits between committed agent configuration and scheduler mutation, then affects the guarded cleanup path that removes the managed agent configuration.
