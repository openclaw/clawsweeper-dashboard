## Summary

Keep open: current main still accepts the `provider.request` timeline type but the embedded model-call wrapper only emits `model.call.*` diagnostic events, and this maintainer-labeled issue is not eligible for conservative auto-close.

## What This Changes

The issue asks OpenClaw to emit one terminal `provider.request` diagnostics timeline record for each embedded live provider call.

## Best Possible Solution

Add the JSONL `provider.request` emission at the shared embedded model-call terminal boundary, reusing `terminalEventEmitted` for dedupe and covering success, thrown errors, `result()`, and early iterator return without synthesizing the event for CLI-owned runtimes.
