Keep open: current main and v2026.6.11 still do not expose a machine-readable current timestamp in `session_status`, so the central bug remains. This PR is useful but not merge-ready because it conflicts with current main, lacks sufficient real behavior proof, and should be refreshed to use the shared status renderer instead of appending around it.

## What This Changes

The PR adds a local ISO timestamp formatter, appends local ISO and UTC time to `session_status` output, and adds a regression test for configured timezone output.

## Best Possible Solution

Refresh this PR or replace it with a narrow current-main patch that feeds localized and UTC machine-readable time through the shared status renderer, preserves route context, adds focused regression coverage, and includes redacted real `session_status` output proof.

## Reproduction Assessment

## Solution Assessment
