## Summary

Keep this PR open for rework, but it is not merge-ready: the branch makes profile-backed rows visually distinct without carrying the selected profile into the persisted model selection, so both rows still resolve to the same provider/model and cannot guarantee the intended account.

## What This Changes

Adds `profileId` to discovered model catalog rows and catalog/picker dedupe keys, displays profile hints, and includes incidental generated-docs and Microsoft Teams cleanup changes.

## Best Possible Solution

Keep the model catalog keyed by provider/model and implement profile choice through the existing auth-profile override contract—either enhance the session `/model` picker to emit `model@profileId`, or keep setup/default pickers model-only and direct users to auth-order controls—with regression coverage proving the actual selected credential.
