## What This Changes

The branch changes Feishu custom-domain validation so uppercase or mixed-case HTTPS URLs are accepted and normalized before the channel passes the configured base URL to the Lark SDK.

## System Context

Feishu channel configuration accepts either a built-in regional alias or a custom HTTPS base URL. The schema feeds the domain resolver, which passes the resulting endpoint to the Lark SDK when the channel starts and makes API requests.
