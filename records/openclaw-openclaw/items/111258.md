## Summary

This PR still needs a narrow correction before merge: it handles blank `MISE_DATA_DIR` but falls back to a Unix-style directory even for Windows, where mise’s documented default is `%LOCALAPPDATA%\mise`. The prior P2 finding therefore remains unresolved despite the added live proof.

## What This Changes

The PR treats whitespace-only `MISE_DATA_DIR` as absent, restores the default mise shim directory, and adds focused PATH-bootstrap regressions.

## Best Possible Solution

Preserve blank-as-absent semantics, but centralize mise’s documented data-directory resolution for `MISE_DATA_DIR`, `XDG_DATA_HOME`, Unix defaults, and Windows `%LOCALAPPDATA%`, then prove both fresh Windows and Unix fallback paths.
