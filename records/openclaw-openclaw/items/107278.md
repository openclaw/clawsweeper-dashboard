## Summary

Keep open: current main still lets the fallback tool-error classifier override exec’s completed status for finite non-zero exit codes, while the directly linked fix remains an open, unmerged pull request.

## What This Changes

Stop benign completed exec results with non-zero exit codes from producing user-facing failure warnings and misleading the agent loop.

## Best Possible Solution

Review and land the linked pull request after confirming completed non-zero exec results stay available to the model without warnings while explicit failures, timeouts, and failed statuses still produce the existing error behavior.
