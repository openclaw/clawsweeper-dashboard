## What This Changes

The PR makes bundled MCP tool sessions invalidate and rebuild a dead server’s catalog after a transport close or repeated local request timeouts, while keeping healthy sibling servers available.

## System Context

The bundled MCP runtime creates and caches per-server SDK sessions, discovers their tools into a session catalog, and exposes that catalog to agent tool calls. This change feeds connection-close and repeated-timeout signals back into catalog recovery so agents can regain a restarted child server without restarting the gateway.
