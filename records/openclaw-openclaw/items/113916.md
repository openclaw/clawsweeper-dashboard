## What This Changes

The PR makes bundled MCP child servers rebuild their tool catalog and reconnect after an established transport closes or repeated request timeouts indicate that the child is no longer responsive.

## System Context

The bundled MCP runtime starts and reuses local MCP server processes for agent tool calls. It caches each server’s catalog and session; this change invalidates that cache and retires an unhealthy session so a later agent request can create a replacement child process.
