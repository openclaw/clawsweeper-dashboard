## What This Changes

This PR adds queued-follow-up admission and settlement callbacks so Telegram recreates its draft/progress UI after a queued reply takes ownership, then cleans it up when that reply finishes.

## System Context

Telegram dispatch creates draft and progress UI while a reply runs. Queued follow-ups use the shared auto-reply queue; this change notifies the Telegram controller when ownership transfers and when that queued run settles.
