## What This Changes

This PR restores Telegram progress UI for a reply queued behind an active turn by resetting the channel’s draft/progress state at queue admission, forwarding forced tool-result progress, and cleaning up when that queued follow-up settles.

## System Context

OpenClaw’s auto-reply runner serializes queued agent follow-ups through a reply lane, then sends progress and final messages through the active channel dispatcher. The Telegram plugin owns the ephemeral draft and progress presentation that surrounds that shared runner, while final reply delivery remains on the existing shared path.

## Best Possible Solution
