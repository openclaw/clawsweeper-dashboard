## What This Changes

The PR wraps OpenClaw’s async and synchronous atomic file replacement helpers so requested modes are applied through file descriptors before replacement rather than through a final path-based chmod that can follow a swapped symlink.

## System Context

OpenClaw’s infrastructure layer provides atomic replacement to secrets, credential persistence, and other callers that need durable file updates. Callers supply a destination and optional mode; the helper creates a sibling temporary file, commits it through rename or copy fallback, and returns the replacement result.

## Best Possible Solution

Keep fs-safe responsible for atomic replacement and land the smallest wrapper only after confirming it preserves the dependency contract; then replace the wrapper with an upstream fs-safe release when that release removes the final path-based chmod.
