## What This Changes

The PR makes claiming hooks honor only their registration-level `timeoutMs` and adds a regression test proving they do not inherit a modifying-hook timeout for the same hook name.

## Best Possible Solution

Merge the narrow ownership correction with the regression test, keeping per-registration `timeoutMs` as the sole claiming-hook timeout mechanism rather than adding a parallel claiming default map.
