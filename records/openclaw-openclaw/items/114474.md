## Summary

Keep this PR open for explicit maintainer review. The focused change matches the existing derived-title preservation invariant introduced by the merged accessibility work and adds a regression test for the foreground-refresh sequence that could otherwise revert readable sidebar titles to raw session identifiers; the `maintainer` label also prevents automated cleanup closure.

## What This Changes

The PR makes Control UI mutation refreshes request derived session titles by default unless a caller explicitly disabled them, and adds a regression test for pinning after an un-enriched foreground refresh.

## System Context

Control UI asks the Gateway for session rows to render sidebar threads, then replaces those rows after session mutations such as pinning. Derived titles are optional Gateway enrichment used to keep unnamed sessions readable in the sidebar.

Yes. The PR documents a concrete current-main Chromium sequence—load derived titles, perform an un-enriched foreground list, then pin a session—that loses the readable title on the replacement request; the after-fix Testbox run exercises the same path.
