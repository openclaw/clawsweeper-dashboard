## Summary

Keep this issue open because current `main` still reports raw three-dot divergence counts without checking for a merge base, and the linked open PR is the concrete candidate fix.

## What This Changes

Report ahead/behind as unknown for a Git source install when `HEAD` and its configured upstream have no visible merge base.

## Best Possible Solution

Land a focused guard that checks `git merge-base HEAD <upstream>` before calculating three-dot counts, returning unknown counts only when no merge base exists while preserving normal counts for shallow checkouts that retain one.
