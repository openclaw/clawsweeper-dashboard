## What This Changes

Investigate and prevent unattended changes to OpenClaw configuration that can enable an unusable sandbox mode and cause cron jobs to fail on hosts without Docker.

## System Context

Memory and scheduled-agent work can invoke tool execution, whose sandbox policy is read from canonical OpenClaw configuration. That policy determines whether isolated cron sessions can start, so any automated configuration mutation can affect later scheduled runs across the host.

## Architecture Diagram

  C --> D[Canonical configuration]
  D --> E[Gateway restart or reload]

  F --> G[Scheduled task results]

## Best Possible Solution

Trace every route that can persist configuration from agent or plugin execution, enforce an explicit authorization boundary for unattended writes, and add focused regression coverage for Docker-less scheduled runs and invalid sandbox modes.
