## What This Changes

The issue reports silent automated mutations to `openclaw.json` from memory-core cron housekeeping and agent-visible sandbox error guidance, causing cron jobs to fail on hosts without Docker.

## Best Possible Solution

Define and enforce an operator-approved config mutation boundary: assistant-visible runtime errors should avoid protected config-write instructions, CLI-through-exec/plugin/cron writes need explicit provenance or guardrails, and the supported `non-main` sandbox mode should remain valid.
