## What This Changes

The issue reports that automated config patches from memory-core and sandbox error guidance can silently mutate OpenClaw config and break cron jobs on hosts without Docker.

## Best Possible Solution

Define and enforce an operator-approved config mutation boundary: assistant-visible errors should avoid protected config write recipes, CLI-through-exec/plugin/cron writes to exec or sandbox config need explicit provenance or approval, and `non-main` should remain supported.
