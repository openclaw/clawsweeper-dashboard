## Summary

Keep open: the current head has a blocking command-path regression and only test/CI evidence for the changed behavior. The protected `maintainer` label also requires explicit maintainer handling.

## What This Changes

The PR assigns memory-search credentials to per-agent degraded owners, isolates unavailable owners during Gateway startup, and changes generic and GitHub Copilot embedding adapters to consume prepared credential literals.

## Best Possible Solution

Keep the per-agent degraded-owner model and explicit-credential fail-closed semantics, but make command-time preparation cover memory API keys and every configured remote header before either embedding adapter is called, with regressions for default inheritance, per-agent overrides, and no implicit profile fallback.
