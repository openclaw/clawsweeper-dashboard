## Summary

This PR still needs changes: the claimed media-only event shape is not produced by the current canonical assistant path, while the guard changes every empty replacement into a no-op and can preserve stale text when an empty snapshot is intended to clear it.

## What This Changes

The PR makes OpenResponses streaming retain accumulated text for any empty-string `replace:true` assistant event and adds an HTTP/SSE regression test using a mocked event.

## Best Possible Solution

Establish the real media-only producer contract, then scope preservation to an explicit media-bearing signal or correct the producer so empty text cannot ambiguously mean both “clear” and “no textual update,” with producer-level and SSE regression coverage.
