## Summary

Keep open. Current main and the latest release have `logs.tail`, a Logs page, an Overview log-tail card, and terminal output replay primitives, but they do not have the modular dashboard plugin, widget registry, dashboard binding surface, or dashboard-cell log/output builtins requested here.

## What This Changes

The issue requests new modular dashboard widgets that can tail logs or streams and display command-output results inside dashboard cells.

## Best Possible Solution

Approve or reject the dashboard substrate and binding model first, then add read-only log/output builtins in the dashboard plugin backed by approved `logs.tail`, terminal/output replay, or recorded-run contracts with explicit redaction, scope, retention, and export rules.
