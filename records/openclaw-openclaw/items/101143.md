Keep open: current main and the latest release still lack the modular dashboard plugin/widget registry and the requested log-tail/command-output dashboard builtins; existing Logs/Overview pages, `logs.tail`, `terminal.text`, and command-output progress primitives are useful inputs but do not satisfy the dashboard-cell feature.

## Best Possible Solution

Land or reject the dashboard substrate first, define a narrow read-only log/output data contract with scopes, redaction, retention, and command-execution boundaries, then implement the builtins inside the dashboard plugin rather than adding ad hoc core UI paths.
