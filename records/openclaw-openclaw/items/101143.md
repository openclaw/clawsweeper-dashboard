## Summary

Keep open. Current main and v2026.6.11 have `logs.tail`, the Logs page, and an Overview log-tail card, but they do not have the modular dashboard plugin/widget substrate or the requested log-tail and command-output dashboard builtins; this is a valid component item under the open Wave 2+ dashboard roadmap.

## What This Changes

Add modular-dashboard built-in widgets for live log-tail or stream output and command-run output inside dashboard cells.

## Best Possible Solution

Settle the dashboard substrate first, then add these as trusted built-in dashboard widgets over existing `logs.tail` plus an approved command or stream contract with explicit scoping and redaction.
