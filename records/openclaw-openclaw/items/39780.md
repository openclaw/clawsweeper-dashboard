Keep open: current main and the latest release still present insecure Control UI recovery as manual config guidance, while the existing before/after diff and apply path is scoped to user-staged Config editor changes. ## Best Possible Solution

Define a reusable, allowlisted Control UI recommendation-action model over the existing config RPCs with exact before/after diff, explicit accept/dismiss, confirmation, redaction, restart/audit handling, and security-sensitive copy.
