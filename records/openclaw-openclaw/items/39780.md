## What This Changes

Request a Control UI flow that turns config upgrade or security-hardening recommendations into reviewed before/after diffs users can accept, apply, or dismiss without manually editing files.

## Best Possible Solution

Add a reusable, allowlisted recommendation-action model that previews validated config patches through the existing config RPC path, shows a before/after diff, requires explicit acceptance, records dismissals, and preserves redaction, restart, audit, and concurrency safeguards.
