## What This Changes

The issue requests Control UI config/security recommendations that show a before/after diff and apply accepted config changes automatically instead of directing users to edit `openclaw.json` manually.

## Best Possible Solution

Define one protected-config recommendation policy first, then let Control UI recommendation cards reuse the existing base-hash config patch and diff UI only for approved, auditable paths with explicit accept/dismiss and confirmation behavior.
