## Summary

## What This Changes

## Best Possible Solution

Define a reusable allowlisted Control UI recommendation-action model that previews validated config patches through the existing config.patch path, requires explicit diff acceptance, records dismissals, and preserves redaction, restart, audit, and concurrency safeguards.
