## What This Changes

The issue asks for Control UI configuration recommendations to offer accepted, diff-backed automatic config updates instead of manual JSON editing.

## Best Possible Solution

Define a reusable, allowlisted Control UI recommendation-action model that previews validated config patches through the existing config RPC path, requires explicit diff acceptance, records dismissals, and preserves redaction, restart, audit, and concurrency safeguards.
