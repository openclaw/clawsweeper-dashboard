## What This Changes

The issue asks for Control UI config upgrade and hardening recommendations to show a before/after diff, offer Accept/Dismiss, and apply accepted changes through the config API instead of directing users to edit config files manually.

## Best Possible Solution

Define a reusable allowlisted Control UI recommendation-action model that previews validated config patches, requires explicit diff acceptance, records dismissal and confirmation state, and preserves redaction, restart, audit, and concurrency safeguards.
