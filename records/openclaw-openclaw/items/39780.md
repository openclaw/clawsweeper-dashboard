## Summary

Keep open: current main and v2026.6.11 still render the Control UI insecure-context recovery as manual guidance, while the existing diff/apply path only covers user-staged Config edits.

## What This Changes

The issue asks for Control UI config and hardening recommendations to offer accept/dismissable before/after diffs and apply validated config patches instead of telling users to edit files manually.

## Best Possible Solution

Define a reusable, allowlisted Control UI recommendation-action model that previews validated config patches, requires explicit diff acceptance, records dismissals, and preserves redaction, restart, audit, and concurrency safeguards.
