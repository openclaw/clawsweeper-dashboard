## Summary

Keep open: current main and v2026.6.11 still present the cited Control UI recovery as manual config guidance, and the existing before/after diff/apply flow only covers user-staged Config editor changes. The remaining work is useful but needs product/security direction before browser-originated recommendations can mutate auth-related config.

## What This Changes

Request a Control UI recommendation flow that previews before/after config changes, lets users accept or dismiss, applies accepted changes automatically, and confirms the result.

## Best Possible Solution

Define a reusable allowlisted Control UI recommendation-action model that previews validated config patches, requires explicit diff acceptance, records dismissal/confirmation state, and preserves redaction, restart, audit, and concurrency safeguards.
