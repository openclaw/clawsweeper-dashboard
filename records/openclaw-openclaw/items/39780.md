## Summary

Keep open: current main still renders Control UI hardening recovery as manual config guidance, and the existing diff/apply UI only covers user-staged Config editor changes, not recommendation-owned apply/dismiss actions.

## What This Changes

The issue requests Control UI config and hardening recommendations with one-click apply, before/after diff, accept/dismiss, and confirmation instead of manual file-edit instructions.

## Best Possible Solution

Define a reusable, allowlisted Control UI recommendation-action model that previews validated config patches, requires explicit diff acceptance, records dismissal/confirmation state, and preserves redaction, restart, audit, and concurrency safeguards.
