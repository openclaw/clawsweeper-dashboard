## What This Changes

Start relays for explicitly configured extension-driver browser profiles during Gateway boot, including when the eager browser-control environment flag is enabled.

## System Context

The Gateway starts optional browser-control components for configured browser profiles. Extension-driver profiles need a local relay for the paired Chrome extension; without that relay at startup, the extension cannot reconnect until another browser action lazily initializes the subsystem.
