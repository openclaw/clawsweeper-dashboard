## Summary

Keep this PR open for a narrow pre-merge contract decision. Current `main` still runs the glossary checker’s Git subprocesses without a timeout, so the core reliability problem remains; the branch provides convincing terminal proof and focused fixture coverage, but it also adds an undocumented production environment override that becomes a new validation-policy surface.

## What This Changes

The PR bounds `git merge-base`, `git diff`, and `git show` calls in the docs i18n glossary checker and adds subprocess-fixture tests for timeout and diagnostic behavior.

## System Context

The docs i18n glossary checker runs during documentation validation, using Git to identify changed English documentation before comparing new labels against the glossary. Its result either allows the docs workflow to continue or returns an actionable validation error to developers and CI.

## Best Possible Solution
