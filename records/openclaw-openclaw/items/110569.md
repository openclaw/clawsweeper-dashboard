## Summary

This PR still addresses a useful CI reliability problem and includes convincing real-process proof, but its exported declaration still describes the new asynchronous runner as synchronous. That mismatch is consistent with the reported `check-test-types` failure and should be fixed before merge.

## What This Changes

The PR replaces synchronous Git calls in the docs i18n glossary checker with a one-minute asynchronous runner that terminates and then kills stalled Git children, with focused timeout tests.

## System Context

The docs i18n glossary checker runs Git commands to determine changed English documentation and inspect their content before validating glossary coverage. It feeds local developer and pull-request documentation checks, so an unbounded Git child can stall validation indefinitely.

## Architecture Diagram

  D -->|Yes| E[Changed docs and content]

  F --> G

## Best Possible Solution

Keep the bounded asynchronous runner, update its `.d.mts` contract to return `Promise<string>` and expose `killGraceMs`, then rerun the focused glossary and script-declaration/type checks.
