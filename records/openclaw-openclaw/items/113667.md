## What This Changes

This PR changes Telegram’s persistent dispatch-replay key from account/chat/message coordinates to account/bot/chat/message coordinates, quarantining legacy rows so reused state cannot suppress a different bot’s inbound message.

## System Context

Telegram inbound handlers create a persistent replay claim before handing a message to OpenClaw’s normal inbound processing path. The claim prevents duplicate dispatch after replay, while successful or failed processing settles the claim so later deliveries are handled consistently.
