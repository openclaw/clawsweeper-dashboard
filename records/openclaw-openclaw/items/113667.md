## Summary

## What This Changes

The PR changes Telegram’s persistent dispatch-deduplication key from account/chat/message to account/bot/chat/message, fails open when bot identity is unavailable, and removes the now-unreachable legacy replay-cache migration.

## System Context

Telegram inbound handlers derive the authenticated bot identity before asking the lifecycle runtime to claim persistent replay state. The claim either suppresses a same-bot replay or allows the message through to inbound processing and reply-chain tracking.
