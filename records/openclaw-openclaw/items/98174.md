## Summary

Keep open, but the current patch is not merge-ready: it fixes the prior content-stability concern, yet now classifies data-producing tools as ephemeral and would hide tool outputs the agent needs for follow-up reasoning.

## What This Changes

The PR adds an LLM-side ephemeral tool-result summarizer and applies it while converting tool results for Anthropic, OpenAI chat completions, and OpenAI responses providers.

## Best Possible Solution

Rebase the fix onto the current package provider paths, preserve data-bearing tool outputs by default, summarize only maintainer-approved heartbeat/status-style results, and add live or redacted DeepSeek request/cache proof.
