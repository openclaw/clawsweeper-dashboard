## Summary

Keep open, but the current patch is not merge-ready: it has a useful cache-preservation goal, yet it replaces semantic outputs for core tools with opaque placeholders and is currently dirty against the moved `packages/ai` provider paths.

## What This Changes

The branch adds a shared helper that replaces selected tool-result payloads with fixed placeholders during OpenAI Chat Completions, OpenAI Responses, and Anthropic message conversion, plus unit tests.

## Best Possible Solution

Define a narrow cache-safe tool-result policy in the current `packages/ai` provider paths that preserves semantic outputs for normal tools, uses heartbeat isolation or semantic opt-in compaction for repetitive outputs, and proves the DeepSeek cache effect with redacted live telemetry.
