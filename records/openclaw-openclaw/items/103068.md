## What This Changes

The branch delays the Android `GatewaySession` terminal disconnect callback until the inbound message pump and accepted connect handshake have drained, and updates the reconnect regression test to assert that ordering.

## Best Possible Solution

Land the narrow Android gateway lifecycle fix after real behavior proof is attached and exact-head CI is green, keeping the terminal callback aligned with the existing message-pump and connect-handshake drain boundary.
