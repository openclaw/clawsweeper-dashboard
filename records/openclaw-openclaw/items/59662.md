## What This Changes

The issue reports Anthropic Max OAuth usage-alert text blocks being stored and delivered as normal assistant messages instead of being treated as provider billing metadata.

## Best Possible Solution

Add one owner-approved provider-metadata handling path before transcript persistence and channel delivery, preferably stripping the alert from public output while privately capturing quota metadata only if maintainers want that behavior.
