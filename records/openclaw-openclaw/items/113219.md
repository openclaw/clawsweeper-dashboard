## What This Changes

Fix Windows `exec` and `read` tool decoding so UTF-8 and GBK text reach the agent transcript correctly and do not contribute to failed sessions.

## System Context

OpenClaw’s agent tools capture child-process output and read file buffers before adding decoded text to the agent transcript. On Windows, the shared decoding layer chooses between UTF-8 and the active legacy code page; tool results then affect later model turns and session state.

## Architecture Diagram

  E --> F[Session transcript]
  F --> G[Model turn and session outcome]

## Best Possible Solution

Reproduce the exact buffers on a Windows CP936 host, preserve correct decoding for complete legacy output, and repair the fallback decision with focused `exec`, `read`, truncation, and session-recovery regression coverage; split the downstream failed-session behavior into a linked issue if it reproduces independently.
