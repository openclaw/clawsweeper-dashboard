## What This Changes

Add session-owned self-service tools, route persistent system changes through the OpenClaw system agent with human approval, and remove direct privileged gateway writes from the default agent toolset.

## Best Possible Solution

Approve one canonical phased program only after owners settle the authority model: direct tools stay limited to the owning session, persistent system writes require host-verified human approval, CLI and protocol changes carry explicit upgrade proof, and direct gateway writes become a deliberate allowlist opt-in.
