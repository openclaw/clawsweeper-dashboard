## Summary

This issue should remain open: it is a maintainer-protected, actively sponsored architecture program, current main still has the underlying capability split, and the linked open pull request implements only phase 0 rather than the central session self-service and approval-boundary work.

## What This Changes

Add session-scoped self-service tools for agents and route persistent system-level operations through a human-approved OpenClaw system agent, including a Crestodian rename and later narrowing of direct gateway writes.

## Best Possible Solution

Land the program as separately reviewed phases: keep direct mutations limited to the agent's own session tree, require explicit human approval for persistent system writes, preserve shipped CLI and protocol compatibility with narrow aliases or migrations, and prove fresh-install plus upgrade behavior before narrowing gateway defaults.
