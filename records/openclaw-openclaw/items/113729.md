## What This Changes

Add `denyFrom` and `groupDenyFrom` configuration for WhatsApp channel access control so named senders or groups can be denied before existing allow-list evaluation.

## System Context

Inbound WhatsApp messages pass through channel access control before OpenClaw accepts them for further processing. The requested deny lists would add an explicit rejection decision alongside the existing sender and group allow-list policy.
