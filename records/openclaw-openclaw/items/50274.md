## Summary

## What This Changes

The issue requests benchmark-backed fallback ordering for named OpenRouter models plus a config guardrail for unsupported `models.providers.*.models[*].input` modalities.

## Best Possible Solution

Keep this as the broad fallback-policy tracker, let https://github.com/openclaw/openclaw/issues/50287 own the model-input guardrail subset, and require maintainers to define benchmark criteria plus the capability-authority contract before implementation.
