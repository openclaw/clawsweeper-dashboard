## Summary

Keep open. Current main and v2026.6.11 still reject cross-agent `sessions_send` under `tools.sessions.visibility` below `all` before A2A allow rules can approve it, so the requested send-without-read-visibility behavior remains unresolved and security-sensitive.

## What This Changes

Request to let A2A policy authorize cross-agent `sessions_send` without requiring broad list/history/status visibility.

## Best Possible Solution

Keep this as the narrow canonical tracker and land either a maintainer-approved send-only A2A path or a broader per-capability visibility model with regression proof for read/list/status isolation.
