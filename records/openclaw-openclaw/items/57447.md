## Summary

Keep open. Current main and v2026.6.11 still require effective `tools.sessions.visibility="all"` before A2A allow rules can approve a cross-agent `sessions_send`, so the requested send-without-read-visibility behavior remains unresolved and needs maintainer security/product direction.

## What This Changes

Allow `sessions_send` to target cross-agent sessions when `tools.agentToAgent` allows it without also granting cross-agent list, history, or status visibility.

## Best Possible Solution

Keep this as the canonical narrow tracker and land a maintainer-approved send-only A2A authorization path or fold it into the broader per-capability visibility design, with tests proving read/list/status isolation remains unchanged.
