## Summary

Keep this issue open: current main has a real one-request/multi-command consistency gap, and the linked lifecycle PR only adds command-scoped leases. The issue is also protected by the `maintainer` label and depends on an unsettled sandbox lifecycle boundary.

## What This Changes

Add an operation-scoped sandbox filesystem lease so compound filesystem operations cannot span Docker container generations during automatic rollout.

## Best Possible Solution

Finalize the per-container coordinator, then wrap each upstream `fs/copy` request in one backend-neutral bridge scope whose lease is reused by all nested commands and released on success, failure, or abort.
