## Summary

Keep this PR open for maintainer review: current main still contains the quadratic FTS validation path, while this focused patch preserves canonical-wins and atomic migration semantics and has no concrete correctness finding. The protected `maintainer` label also rules out automated cleanup.

## What This Changes

The PR replaces repeated unindexed FTS identity scans during legacy Memory Core migration with one materialized match pass and indexed lookups, adding conflict-semantic and query-plan regression coverage.

## Best Possible Solution

Rebase onto current main and land the single-scan materialization approach once exact-head checks confirm the conflict, rollback, archive, and query-plan contracts; batching or resumability should remain separate unless full-scale proof shows another bottleneck.
