## Summary

Keep open. Current main and the latest release still use Markdown as the durable memory source while SQLite stores the retrieval index/cache, so the requested typed canonical SQLite record model remains real product/data-model work needing maintainer direction.

## What This Changes

Define a v1 local-first SQLite schema and canonical record model for durable typed memories, revisions, statuses, entities, timestamps, and validity windows.

## Best Possible Solution

Have maintainers define a plugin-owned v1 durable memory contract for records, statuses, revisions, provenance, and doctor/migration behavior, then implement it with embeddings kept retrieval-only.
