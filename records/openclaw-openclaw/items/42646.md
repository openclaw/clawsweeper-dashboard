## Summary

Keep open. Current main and v2026.6.11 still treat Markdown files as durable memory while SQLite stores retrieval/index data, so the requested typed canonical SQLite memory record model remains unimplemented and needs maintainer product/storage direction.

## What This Changes

The issue requests a v1 SQLite schema and canonical typed record model for durable local memory.

## Best Possible Solution

Define the plugin-owned durable memory record contract and migration boundary across the Memory MVP cluster, then implement a conservative SQLite schema while keeping embeddings retrieval-only.
