## Summary

Keep open. Current main and the latest release still use Markdown files as durable memory plus SQLite memory_index_* tables for retrieval/indexing, so the requested typed canonical SQLite memory record model remains unimplemented product/data-model work.

## What This Changes

Define a v1 SQLite source-of-truth schema and canonical record model for durable typed memories, revisions, entities, statuses, and validity windows.

## Best Possible Solution

Keep Markdown as the current durable source until maintainers approve a memory-core durable SQLite record contract and migration plan; then implement the conservative schema with embeddings strictly retrieval-only.
