## Summary

Keep open: current main and the latest release still hardcode the Gateway-visible TUI label as `openclaw-tui`, and `openclaw tui` has no CLI, option-carrier, or docs path for a custom display name. The Gateway already has a display-name seam, but choosing a public flag/config shape and privacy defaults needs maintainer direction.

## What This Changes

Requests a user-settable Gateway-visible display name for `openclaw tui` instances so multiple TUI windows can be distinguished.

## Best Possible Solution

Expose a privacy-safe, opt-in Gateway-mode TUI display-name override that preserves `openclaw-tui` as the default, validates/sanitizes the label, and documents the visibility tradeoff.
