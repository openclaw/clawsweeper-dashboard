## Summary

Keep this open: current main still removes the sandbox runtime and registry row without deleting the non-shared sandbox workspace directory, and the related same-repository fix attempts are closed unmerged. ## What This Changes

The issue requests that sandbox pruning remove expired non-shared workspace directories as well as Docker runtimes and registry entries.

## Best Possible Solution

Implement a narrow core cleanup that deletes only expired non-shared sandbox workspace directories after successful runtime removal, with regression coverage, while keeping the broader lifecycle design in https://github.com/openclaw/openclaw/issues/98516 separate.
