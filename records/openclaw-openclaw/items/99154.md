## Summary

Keep open: the exact-head proof is strong, but the generalized serialization fallback changes established diagnostic byte-accounting semantics for inherited or non-enumerable `toJSON` and accessor-backed provider chunk shapes, so a focused compatibility repair is needed before merge.

## What This Changes

The PR replaces diagnostic model-call stream object-copy accounting with allocation-conscious scalar, proxy, and snapshot paths and adds extensive serialization regression coverage.

## Best Possible Solution

Keep the scalar no-copy fast path, but make every fallback reproduce current main's ordinary object-rest semantics—own enumerable values, `partial` excluded, no inherited or non-enumerable serialization hooks—and add baseline-equivalence tests before refreshing exact-head proof.
