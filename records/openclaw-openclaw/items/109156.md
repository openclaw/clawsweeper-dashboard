## What This Changes

Adds 30-second and 60-second default request timeouts to the Slack web and write client option resolvers, with unit assertions for defaults and explicit overrides.

## Best Possible Solution

Keep `resolveSlackWebClientOptions` timeout-free, apply the 30-second default only when constructing the standalone one-shot WebClient, retain the 60-second write default only on the confirmed write-only path, and prove web, write, and Bolt behavior from the final head.
