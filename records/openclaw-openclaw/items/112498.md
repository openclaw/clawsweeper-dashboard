## Summary

Keep this PR open for normal merge review. The patch is a focused correction to the plugin UI discovery path: it preserves session-pinned descriptors after the mutable runtime registry is swapped, while leaving dynamic session action handling on the active registry as intended. The supplied focused test, real handler invocation, and successful CI provide credible evidence; no discrete correctness or security defect is established from the available review evidence.

## What This Changes

This PR makes the `plugins.uiDescriptors` gateway method read plugin UI descriptors from the session-pinned registry and adds a regression contract test for an emptied active registry.

## System Context

Plugin manifests register Control UI descriptors into a plugin registry. The gateway exposes those descriptors to plugin-hosted UI clients, so the response must retain the session's declared extensions even when the agent runtime replaces its mutable active registry.
