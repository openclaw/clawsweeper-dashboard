## What This Changes

The PR rewrites a plugin host-hook contract test so it asserts that UI descriptors remain visible from the session-pinned plugin registry after the active registry is replaced.

## System Context

The Gateway exposes plugin-hosted UI descriptors to connected clients. Plugin runtime startup pins registries for long-lived surfaces while agent turns may replace the active registry, so the gateway projection must select the registry that owns the client-facing session surface.
