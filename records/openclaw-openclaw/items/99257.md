## Summary

Keep open. Current main still drops room-event turns from the durable transcript, and the live issue has the protected `maintainer` label, so this needs maintainer design rather than conservative cleanup.

## What This Changes

The issue requests durable persistence of ambient room-event observations as bare transcript rows so group awareness survives beyond the per-turn chat window.

## Best Possible Solution

Maintainers should decide the durable ambient transcript contract, then implement it in the core transcript pipeline with one dedupe boundary, replay/compaction coverage, and no sidecar store.

## Reproduction Assessment

Yes at source level: current main still constructs room events with empty transcript bodies and passes persistence-suppression flags through the run and persistence layers. I did not run a live ambient-room session in this read-only review.

## Solution Assessment

Unclear as an implementation path until maintainers choose the transcript contract. Persisting bare rows is plausible, but the safest solution must define row shape, dedupe, replay, compaction, and interaction with the trusted inbound-decoration work.
