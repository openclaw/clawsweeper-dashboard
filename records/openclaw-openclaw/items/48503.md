## Summary

Keep open: current main and the latest checked release still lack stable `before_tool_call` action classification or hook-level input provenance, and the related open/closed work only covers adjacent slices rather than this public SDK contract.

## What This Changes

The issue requests adding action classification and input-provenance context to the `before_tool_call` plugin hook so security plugins can make policy decisions without reimplementing OpenClaw internals.

## Best Possible Solution

Settle one additive plugin-facing policy-facts contract that coordinates action or capability taxonomy with safe provenance fields, then implement it with SDK docs, API baseline updates, and cross-path tests.
