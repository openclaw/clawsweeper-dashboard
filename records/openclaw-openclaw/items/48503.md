## Summary

Keep open: current main and v2026.6.11 still do not expose stable before_tool_call action classification or hook-level input provenance, and the HELM OSS discussion is useful design input rather than an OpenClaw implementation.

## What This Changes

Request adding optional action classification and input provenance fields to the before_tool_call Plugin SDK event for policy, audit, and security plugins.

## Best Possible Solution

Settle one additive plugin-facing policy-facts contract that coordinates action or capability taxonomy with safe provenance fields, then implement it with SDK docs, API baseline updates, and focused tests across core, plugin-tool, Gateway/MCP, and native hook paths.
