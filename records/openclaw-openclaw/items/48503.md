## Summary

Keep open: current main and the latest release still do not expose stable before_tool_call action classification or hook-level input provenance, and the useful HELM OSS reference in the discussion is design input rather than an implemented OpenClaw contract.

## What This Changes

Request to add optional action classification and input provenance fields to the public before_tool_call plugin hook event for security policy, audit, DLP, and rate-limit plugins.

## Best Possible Solution

Settle one additive plugin-facing policy-facts contract that coordinates action or capability taxonomy with safe provenance fields, then implement it with SDK docs, API baseline updates, and focused tests across core, plugin-tool, Gateway/MCP, and native hook paths.
