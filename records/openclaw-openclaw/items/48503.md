## Summary

Keep open: current main and v2026.6.11 still expose only `toolName`/`params` plus limited `toolKind`/`toolInputKind`/`derivedPaths`, not the requested action classification or input provenance. The remaining work is a public Plugin SDK and security-boundary design decision, not stale cleanup.

## What This Changes

Request to enrich `before_tool_call` plugin hook events with stable action classification and input provenance for security policy plugins.

## Best Possible Solution

Define a narrow public Plugin SDK contract that pairs stable tool capability/action metadata with minimized provenance, then land focused docs and tests in coordination with https://github.com/openclaw/openclaw/issues/48510 and https://github.com/openclaw/openclaw/pull/91800.
