## Summary

Keep open: current main and v2026.6.11 still do not retain unmentioned Telegram group media for a later mentioned turn. Core can carry history media when a channel supplies it, but Telegram now intentionally skips unaddressed mention-gated media before download, so the remaining work is a security/product choice about bounded opt-in retention.

## What This Changes

The issue asks Telegram group history to preserve media from unmentioned messages so a later mentioned turn can inspect those attachments.

## Best Possible Solution

Keep the current skip-by-default behavior unless maintainers approve an opt-in, bounded Telegram history-media retention path using shared HistoryEntry.media, redacted prompt notes, TTL/caps, tests, and live Telegram proof.
