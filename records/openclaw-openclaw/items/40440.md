## Summary

Keep open: current main and the latest release still do not make unmentioned Telegram group media available to a later mentioned turn; the source gap is clear, but the fix needs maintainer approval for the privacy and retention boundary around bystander group attachments.

## What This Changes

This issue asks for Telegram group-history entries to preserve media from unmentioned messages so a later mentioned turn can inspect the attachment, not only the placeholder text.

## Best Possible Solution

Reuse the existing HistoryEntry.media and recent-history image pipeline for Telegram skipped group entries with bounded, policy-approved local image retention, no local-path prompt leakage, focused regression tests, and live Telegram proof.
