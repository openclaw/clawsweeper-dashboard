## Summary

Keep open: current main still records skipped Telegram group history as text-only, while the existing history-media pipeline can only replay attachments that were actually stored; the remaining decision is the security boundary for retaining unmentioned group media.

## What This Changes

This issue asks OpenClaw to preserve Telegram group media from unmentioned messages so a later mentioned turn can inspect the recent image instead of seeing only a placeholder.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then reuse HistoryEntry.media, recordWithMedia, and the recent-history image pipeline with focused tests and live Telegram proof.
