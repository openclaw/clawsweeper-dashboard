## Summary

Keep open: current main and the latest release still record Telegram no-mention group history without media, while the existing shared history-media pipeline can only help if Telegram stores media metadata first. The remaining blocker is maintainer approval for the privacy/security shape of retaining and replaying unmentioned group media.

## What This Changes

The issue asks Telegram group-history entries from unmentioned media messages to retain usable media data for a later mentioned turn.

## Best Possible Solution

Approve a bounded Telegram policy, then wire skipped group entries into the existing HistoryEntry.media and recent-history image pipeline with focused regression coverage and live Telegram proof.
