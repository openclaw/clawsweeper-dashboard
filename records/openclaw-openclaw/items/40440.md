## Summary

Keep open: current main and v2026.6.11 still record Telegram mention-skipped group history as text-only, while the shared history-media pipeline exists but is not wired into this Telegram path; the remaining choice is the privacy/security boundary for retaining unmentioned group media.

## What This Changes

Telegram group-history messages skipped by mention gating lose downloaded media metadata, leaving later mentioned turns with only placeholder text.

## Best Possible Solution

Wire Telegram skipped group entries into the existing HistoryEntry.media and recent-history image pipeline with bounded local-image retention, focused source tests, and live Telegram proof after the privacy policy is approved.
