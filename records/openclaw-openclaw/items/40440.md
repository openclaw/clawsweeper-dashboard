## Summary

Keep open: current main and v2026.6.11 still do not make unmentioned Telegram group image media available to a later mentioned turn. The source gap is clear, but retaining and replaying media that did not mention the bot needs an explicit maintainer security/product decision before automation should repair it.

## What This Changes

The issue asks OpenClaw to preserve Telegram group media sent without mentioning the bot so later mentioned turns can inspect the actual media instead of only a `<media:image>` history placeholder.

## Best Possible Solution

Approve and document a bounded Telegram history-media policy, then reuse the shared HistoryEntry.media and recordWithMedia contract so only allowed recent local image media can flow from group history into later mentioned turns.

- **Make retention explicit opt-in:** Add a per-group or per-topic setting before retaining unmentioned group media for later model context.

## Solution Assessment

Unclear until the security/product choice is made. If maintainers approve retaining unmentioned group media, the narrowest maintainable implementation is to reuse the existing bounded HistoryEntry.media / recordWithMedia contract rather than adding Telegram-only mediaPaths/mediaTypes fields.
