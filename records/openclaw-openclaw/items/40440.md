## Summary

Keep open: current main still records unmentioned Telegram group messages as text-only history and current Telegram media gating can skip unaddressed group media before download, so the reported placeholder-without-image problem remains. The fix shape is now clearer because shared HistoryEntry.media plumbing exists, but retaining unmentioned group attachments for later model context needs maintainer security/product approval.

## What This Changes

The issue asks Telegram group history to preserve media from unmentioned group messages so a later mentioned turn can inspect recent images instead of only seeing placeholders.

## Best Possible Solution

After maintainer security/product approval, reuse HistoryEntry.media and createChannelHistoryWindow(...).recordWithMedia for Telegram skipped group media with bounded local-image retention, sender/group visibility checks, focused tests, and live Telegram proof.
