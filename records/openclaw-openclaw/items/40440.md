## Summary

Keep open: current main and v2026.6.11 still record skipped Telegram group history as text-only, so later mentioned turns can see the media placeholder without a usable historical image. Main now has a shared history-media seam, but Telegram still needs a maintainer-approved retention and visibility policy before preserving unmentioned group media.

## What This Changes

The issue asks Telegram group history to preserve media from unmentioned messages so a later bot mention can inspect the prior image instead of only seeing a placeholder.

## Best Possible Solution

Approve a bounded Telegram history-media retention and visibility policy, then populate HistoryEntry.media through the shared recordWithMedia path without regressing pre-download no-error skipping.

## Reproduction Assessment

Yes, source inspection is enough: current main and v2026.6.11 record skipped Telegram group media history as text-only and the later InboundHistory path can only consume media if it was already populated.

## Solution Assessment

No, the old mediaPaths/mediaTypes sketches are not the best final shape; the safer path is to reuse the current HistoryEntry.media and recordWithMedia seam after a maintainer decision on retention and visibility.
