## What This Changes

The issue asks Telegram group history to preserve media from unmentioned messages so a later mentioned turn can inspect the image data instead of only seeing placeholder text.

Approve a bounded Telegram history-media policy, then reuse HistoryEntry.media/recordWithMedia and the recent-history image pipeline with focused tests and live Telegram proof, coordinating the pre-download skip with https://github.com/openclaw/openclaw/issues/92067.
