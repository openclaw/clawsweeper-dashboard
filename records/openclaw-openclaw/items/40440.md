## Summary

Keep open: current main still does not preserve Telegram unmentioned group media for later history replay, and current no-text media can now be skipped before download/history entirely; the remaining blocker is maintainer approval of the bounded retention and privacy/security shape.

## What This Changes

Telegram group media sent without mentioning the bot is reported to be stored or replayed as placeholder history without preserving the actual attachment for a later mentioned turn.

## Best Possible Solution

Approve and land a bounded Telegram implementation that uses the existing HistoryEntry.media and recordWithMedia contract, preserves only recent local image history under clear retention limits, avoids prompt-visible path leakage, and includes focused tests plus live Telegram proof.
