## Summary

Keep open: current main still does not make unmentioned Telegram group media available to a later mentioned turn. The shared history-media pipeline now exists, but the Telegram group-history path either records text-only entries or skips unmentioned media before download, and retaining bystander attachments needs maintainer security/product approval.

## What This Changes

The issue asks Telegram group history to preserve media from unmentioned group messages so later mentioned turns can inspect the images instead of seeing only placeholders.

## Best Possible Solution

After maintainer approval, wire Telegram skipped group-history recording into the existing HistoryEntry.media and recordWithMedia pipeline with bounded local image retention, focused tests, live Telegram proof, and documented privacy behavior.
