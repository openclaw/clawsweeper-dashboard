## Summary

Keep open: current main and v2026.6.11 still record the Telegram no-mention group history entry as text-only, so the later mentioned turn cannot use the already-downloaded media unless a maintainer approves the bounded retention/security shape.

## What This Changes

The issue requests preserving Telegram group media from no-mention history entries so a later mentioned turn can inspect the media instead of only seeing a placeholder.

## Best Possible Solution

Approve a bounded Telegram policy, then wire skipped group entries into the existing HistoryEntry.media and recent-history image pipeline with focused tests and live Telegram proof.
