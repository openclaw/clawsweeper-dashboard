## Summary

Keep open: current main and v2026.6.11 still record skipped Telegram group-history messages as text-only, while fixing the media gap requires an explicit maintainer privacy/security decision about retaining and replaying unmentioned group media.

## What This Changes

Preserve media from unmentioned Telegram group messages in recent group history so a later mentioned turn can inspect the image data instead of only seeing a placeholder.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then reuse HistoryEntry.media and recordWithMedia for skipped group messages with focused source tests and redacted live Telegram proof.
