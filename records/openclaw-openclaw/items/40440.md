## Summary

Keep open: current main still has a Telegram requireMention group-media path that can skip unmentioned media before download, and the later text-only group-history recording path still records sender/body/timestamp/messageId without historical media. The generic HistoryEntry.media pipeline now exists, but Telegram has not wired this issue’s retained-history-media policy through it.

## What This Changes

The issue requests preserving Telegram media from unmentioned requireMention group messages so a later mentioned turn can inspect recent group-history images.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then wire the existing HistoryEntry.media and recordWithMedia path into the requireMention group-media skip so recent local images can be replayed without leaking or retaining more than intended.
