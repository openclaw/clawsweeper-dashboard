## Summary

Keep open: current main and the latest release still record skipped Telegram group-history messages as text-only, while the existing recent-history image pipeline only works when `InboundHistory` entries already carry `media` metadata.

## What This Changes

The issue asks Telegram group-history entries for unmentioned media messages to preserve bounded media metadata so a later mentioned turn can inspect the prior image.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then reuse the existing `HistoryEntry.media` and `recordWithMedia` pipeline with focused source tests and live Telegram proof.
