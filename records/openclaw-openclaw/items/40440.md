## Summary

Keep open: current main and the latest release still have a Telegram requireMention group path that can skip unmentioned media before download and later records group history as text-only unless media is already attached. The technical bug is source-reproducible, but retaining and replaying unmentioned group media needs an explicit privacy/security boundary decision.

## What This Changes

The issue asks Telegram group history to preserve usable media data for unmentioned group messages so a later mentioned turn can inspect those images.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then wire the Telegram skip/history path into the existing `HistoryEntry.media` and recent-history image pipeline with focused tests and redacted live Telegram proof.
