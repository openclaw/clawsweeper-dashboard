## Summary

Keep open: current main still has a source-level Telegram path where unmentioned `requireMention` group media is skipped before download, and the text-history path records only sender/body/timestamp/messageId. The bug is real, but retaining and replaying unmentioned group media needs explicit privacy/security product approval before a fix PR should proceed.

## What This Changes

Telegram group history should preserve enough media metadata for unmentioned group media messages so a later mentioned turn can inspect the recent image.

## Best Possible Solution

Define a bounded, privacy-aware Telegram history-media policy, then implement it through the existing `HistoryEntry.media` and history-image replay path with focused tests and live Telegram proof.
