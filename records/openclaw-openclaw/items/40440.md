## Summary

Keep open: current main and the latest release still do not provide a Telegram-owned path for unmentioned group media to become later-turn media context; the generic history-media plumbing exists, but Telegram's skipped group-history entry and media pre-download gate do not attach it, and the remaining fix needs an explicit privacy/retention decision.

## What This Changes

The issue asks Telegram group history to preserve media from unmentioned messages so a later mentioned turn can inspect those attachments instead of seeing only placeholder text.

## Best Possible Solution

Define a Telegram-owned bounded media-history policy that reuses HistoryEntry.media/recordWithMedia only under approved retention and access rules, then prove it with focused tests plus redacted live Telegram evidence; if retaining unmentioned media is rejected, close this issue with that explicit security/product decision.
