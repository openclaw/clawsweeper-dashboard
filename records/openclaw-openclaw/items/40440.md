## Summary

Keep open: current main and the latest release still record Telegram mention-skipped group history as text-only, while the generic history-media pipeline exists but is not wired into this Telegram path. The remaining blocker is a maintainer decision on bounded retention and exposure of unmentioned group media.

## What This Changes

The issue asks Telegram to preserve media references from unmentioned group messages so a later mentioned turn can inspect those images.

## Best Possible Solution

Wire Telegram skipped group entries into the existing HistoryEntry.media and recent-history image pipeline with bounded local-image retention, focused source tests, and live Telegram proof after the privacy policy is approved.
