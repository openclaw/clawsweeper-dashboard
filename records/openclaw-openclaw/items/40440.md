## Summary

Keep open: current main still does not preserve Telegram unmentioned-group media in the pending history entry, and newer code can skip downloading that media before the no-mention drop path. A fix is still useful, but the retention and replay policy for unmentioned group attachments needs explicit maintainer approval before automation should implement it.

## What This Changes

Preserve Telegram group-history media metadata/files from unmentioned messages so a later mentioned turn can inspect recent images instead of seeing only placeholders.

## Best Possible Solution

Approve a bounded policy, then wire skipped Telegram group entries into the existing HistoryEntry.media and recent-history image pipeline with focused source tests and redacted live Telegram proof.
