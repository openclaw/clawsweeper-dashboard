## Summary

Keep open: current main and the latest release still do not preserve Telegram unmentioned group media for later history use, and the current no-download behavior is intentional for a related no-spam/security case, so this needs maintainer boundary review rather than automatic cleanup.

## What This Changes

Preserve usable media attachments from unmentioned Telegram group-history messages so a later mentioned turn can ask the agent about them.

## Best Possible Solution

Adopt a maintainer-approved bounded Telegram media-history policy that keeps the no-download default safe, uses the existing `HistoryEntry.media` and recent-history attachment pipeline when allowed, and proves the later-mention flow with live Telegram evidence.
