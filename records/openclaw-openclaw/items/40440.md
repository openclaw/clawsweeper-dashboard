## Summary

Keep open: current main and v2026.6.11 still do not make unmentioned Telegram group media available to a later mentioned turn. The remaining work needs maintainer approval because fixing it changes the privacy and retention boundary for bystander media in group chats.

## What This Changes

Preserve Telegram group media from unmentioned requireMention messages so later mentioned turns can inspect the recent images instead of seeing only placeholder history text.

## Best Possible Solution

Approve a bounded Telegram policy, then wire skipped group entries into the existing HistoryEntry.media and recent-history image pipeline with focused tests and live Telegram proof.
