## Summary

Keep open: current main and the latest release still do not make unmentioned Telegram group media available to a later mentioned turn. The current Telegram media gate can skip unaddressed group media before download, while the text history path records only sender/body/timestamp/messageId; a fix is plausible but needs maintainer approval for retaining and replaying unmentioned group media.

## What This Changes

The issue requests preserving media metadata/files for unmentioned Telegram group messages so a later mentioned Telegram turn can inspect recent images from group history.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then reuse the shared HistoryEntry.media and recordWithMedia path so only allowed recent local image media can flow from group history into later mentioned turns.
