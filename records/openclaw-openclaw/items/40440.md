## Summary

Keep open: current main has the shared history-media consumer path, but Telegram still records skipped unmentioned group messages as text-only and also skips non-audio media before download, so the later mentioned turn still has no historical media attachment to inspect.

## What This Changes

The issue requests preserving media from unmentioned Telegram group history entries so a later mentioned agent turn can inspect the prior image instead of seeing only a placeholder.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then use the shared `HistoryEntry.media` and history-window media path instead of reviving the old parallel `mediaPaths`/`mediaTypes` shape.
