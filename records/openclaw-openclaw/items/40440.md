## Summary

Keep open: current main and the latest release still do not make unmentioned Telegram group media available to a later mentioned turn. The shared history-media pipeline now exists, but Telegram records group history as text-only and the current pre-download skip can bypass media/history capture entirely, so the remaining decision is the security boundary for retaining bystander group media.

## What This Changes

The issue asks OpenClaw to preserve Telegram media from unmentioned group history so later mentioned turns can inspect the attachments, not just placeholder text.

## Best Possible Solution

Approve a bounded Telegram policy, then reuse the existing HistoryEntry.media/recordWithMedia and recent-history image pipeline for skipped group entries instead of adding parallel mediaPaths/mediaTypes fields.
