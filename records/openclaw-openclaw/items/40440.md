## Summary

Keep open: current main has the generic history-media machinery, but the Telegram requireMention skip path still does not preserve unmentioned group media for later mentioned turns. The remaining blocker is the privacy/security policy for retaining and replaying media that was not addressed to the bot.

## What This Changes

Preserve Telegram group media from unmentioned history entries so a later mentioned turn can inspect the referenced image data.

## Best Possible Solution

Use the existing HistoryEntry.media and recordWithMedia pipeline for Telegram only after maintainers choose a bounded retention policy, with local image-only limits, sender/group admission checks, TTL cleanup, regression tests, and live Telegram proof.

Owner confidence: medium

Options:

- **Bounded history media retention (recommended):** Retain only admitted local image media in the existing HistoryEntry.media shape with short TTL, media count limits, and live Telegram proof before replaying it into later mentioned turns.
- **Keep media fail-closed:** Keep unmentioned group media out of history unless the sender explicitly mentions or replies to the bot, preserving the strictest privacy boundary but leaving this workflow unsupported.
- **Require explicit opt-in:** Add or reuse an operator-controlled policy knob for unmentioned group media history before enabling retention, accepting additional config and upgrade-review cost.
