## Summary

Keep open: current main and the latest release still do not make unmentioned Telegram group media available to a later mentioned turn. The code now skips unaddressed group media before download, and the skipped-message history path remains text-only; a fix is plausible but needs maintainer approval because it changes retention and replay of unmentioned group media.

## What This Changes

The issue asks OpenClaw to preserve Telegram group media from unmentioned history messages so a later mentioned turn can inspect it.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then reuse the shared HistoryEntry.media and recordWithMedia path so only allowed recent local image media can flow from group history into later mentioned turns.
