## Summary

Keep open: current main and v2026.6.11 still do not make unmentioned Telegram group media available to a later mentioned turn. The source gap is clear, but changing Telegram to retain bystander group attachments needs maintainer privacy/security direction first.

## What This Changes

The issue requests preserving media metadata from unmentioned Telegram group messages so a later mentioned turn can inspect the images.

## Best Possible Solution

If maintainers approve retention, wire Telegram skipped group-history recording into the existing bounded HistoryEntry.media pipeline with image-only caps, safe storage, no prompt-visible local path leakage, TTL-safe semantics, focused tests, and live Telegram proof.
