## Summary

Keep open: current main still does not attach media metadata to skipped Telegram group-history entries, and fixing it needs maintainer security/product approval because it would retain and replay unmentioned group media into later model context.

## What This Changes

Telegram group history is reported to preserve only media placeholder text for unmentioned group messages, losing the actual media references needed by a later mentioned turn.

## Best Possible Solution

Approve a bounded Telegram history-media policy, then reuse HistoryEntry.media/recordWithMedia and the recent-history image pipeline with focused tests and live Telegram proof, coordinating the pre-download skip with https://github.com/openclaw/openclaw/issues/92067.
