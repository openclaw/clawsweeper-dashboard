## Summary

Keep open: current main and v2026.6.11 still do not attach usable media to Telegram group history entries for unmentioned requireMention messages, and the remaining fix is a security-sensitive retention/exposure decision rather than conservative cleanup.

## What This Changes

The issue asks Telegram group history to retain usable media from unmentioned group messages so a later mentioned turn can inspect the images.

## Best Possible Solution

Define the bounded Telegram policy for unmentioned group media, then wire the existing HistoryEntry.media and recent-history image attachment pipeline into that path with regression coverage and live Telegram proof.
