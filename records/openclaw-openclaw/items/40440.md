## Summary

Keep open: current main and v2026.6.11 still record Telegram no-mention group history as text-only, while the existing generic history-media path is not wired into this Telegram skip path. The source-level bug is clear, but retaining and replaying unmentioned group media needs a maintainer-approved security and retention boundary before repair work proceeds.

## What This Changes

The issue asks Telegram group history to preserve usable media references for unmentioned media messages so a later mentioned turn can inspect them.

## Best Possible Solution

Use the existing HistoryEntry.media and recordWithMedia seam to preserve only policy-allowed, bounded recent local image media for Telegram group history, with explicit retention/security rules and regression plus live Telegram proof.

Options:

- **Approve bounded policy-limited retention (recommended):** Record recent local image media in HistoryEntry.media for no-mention group history only within the existing history window, access policy, and short retention cleanup, then replay it to later mentioned turns.
- **Require explicit opt-in first:** Add or require a group-level opt-in before retaining unmentioned group media, trading safer defaults for another configuration surface.
- **Do not replay unmentioned media:** Keep text-only history for unmentioned media and document that users must mention the bot or reply directly when they want media inspected.
