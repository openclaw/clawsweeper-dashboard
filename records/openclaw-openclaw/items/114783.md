## What This Changes

This PR adds an optional `hostIntegrationBundle` declaration to plugin manifests, validates and de-duplicates it during discovery, carries it into plugin registry records, and documents the new static inventory surface.

## System Context

OpenClaw discovers plugin manifests before loading plugin runtime code, validates their static declarations, and turns them into loader-owned records in the process registry. The proposed bundle metadata would let later host-integration consumers inspect an enabled plugin's declared contribution inventory without activating that plugin.
