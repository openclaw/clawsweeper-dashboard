## What This Changes

The PR adds an optional, inert `hostIntegrationBundle` declaration to plugin manifests, validates and de-duplicates it during manifest discovery, and carries enabled bundle records into the plugin registry.

## System Context

OpenClaw discovers plugin manifests before loading plugin runtime, validates their static declarations, and creates registry records that inventory and activation paths consume. This change inserts a versioned host-contribution inventory into that manifest-to-registry pipeline without activating the declared contributions.
