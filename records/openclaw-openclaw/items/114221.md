## Summary

The refactor is narrowly scoped and preserves fixture output for both providers, but the posted proof is mock/test-only while shared code now governs persisted admin-token decoding, pagination, and aggregation across two live provider integrations; the `maintainer` label also requires explicit human handling rather than cleanup automation.

## What This Changes

This PR replaces duplicated Anthropic and OpenAI admin-usage credential cleanup, pagination, aggregation, and snapshot construction with shared helpers exposed through OpenClaw’s provider-usage SDK seam.

## System Context

Provider plugins obtain provider-specific admin usage data, then convert it into a common usage-history snapshot for OpenClaw’s usage reporting surfaces. This change moves the common parsing, pagination, and aggregation steps into a shared SDK-backed helper while leaving each plugin’s endpoint and wire-format handling in its own extension.
