## What This Changes

The PR makes Control UI suppress a critical background-session notice when its event refers to the selected agent’s canonical main or configured global conversation, while retaining notices for real background sessions and other agents.

## System Context

The Control UI receives session-observer digests from the Gateway and turns critical background-session events into actionable notices. This change supplies the active app session context to that notice decision so equivalent global and canonical session identities do not produce a misleading foreground alert.
