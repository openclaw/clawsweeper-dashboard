## Summary

Keep open: the patch correctly hardens the authenticated socket route, but the same delayed authority still reaches the native Gateway node-session route without its original policy snapshot, leaving the central revocation bug reachable.

## What This Changes

The PR adds a portable persisted-policy snapshot to authenticated Mac exec-socket requests and revalidates delayed explicit or auto-review authority before execution and allowlist mutation.

## Best Possible Solution

Decode the prepared plan snapshot in `OpenClawSystemRunParams`, require it for forwarded explicit and auto-review authority in `MacNodeRuntime`, pass it as `delayedPolicySnapshot`, and add a regression covering revocation before native evaluation.

No. The snapshot-and-lock mechanism is appropriate, but applying it only to the authenticated socket is a one-sided fix because native node-session execution consumes the same forwarded authority.
