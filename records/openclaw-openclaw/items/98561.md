## Summary

Keep open: the authenticated local-routing redesign addresses the earlier trust-boundary review, but the new pending route can still dispatch dangerous node work after the originating caller has timed out or disconnected. The linked maintainer security report explicitly treats request cancellation as a prerequisite, and the rewritten head also lacks real after-fix behavior proof.

## What This Changes

The PR propagates authenticated local agent and turn provenance through `node.invoke`, routes plugin node-policy approvals through shared approval delivery, and adds older-Gateway compatibility retries.

## Best Possible Solution

Keep the authenticated local provenance and shared routing design, but make the originating request lifetime authoritative: cancellation, timeout, or disconnect must expire the pending approval and atomically prevent later node dispatch, followed by exact-head live originating-route proof.
