  - body: This deletes `OpenAI-Beta` before opening the socket, while sibling Codex source and tests require `OpenAI-Beta: responses_websockets=2026-02-06` on the WebSocket handshake. The proxy can fail or speak the wrong protocol with compliant Codex backends.
  - confidence: 0.88

  - body: This only strips the `agent:main:` prefix. If a user's default or selected agent is not `main`, a legacy Control UI URL like `agent:work:<uuid>` keeps the prefixed key while the backend now preserves `<uuid>` as canonical, so the same Open WebUI chat can still split in non-main setups.
  - confidence: 0.86
- **[P2] Preserve UUID-shaped main-key aliases:** `src/gateway/session-utils.ts:668-669`
  - body: Returning bare UUIDs before checking the configured main-key alias changes behavior for any install whose `session.mainKey` is UUID-shaped: that key used to resolve to the global main session, but this patch treats it as an external opaque chat id. Keep main-key mapping ahead of the UUID special case or prove UUID-shaped main keys are impossible.
