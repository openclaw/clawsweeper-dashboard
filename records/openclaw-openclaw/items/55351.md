## Summary

Keep this PR open, but it is not merge-ready: the UUID session bug still appears valid on current main, while this branch remains too broad, carries unresolved session/auth/provider risks, and still lacks inspectable real-behavior proof after the prior ClawSweeper review on the same head.

## What This Changes

The branch preserves Open WebUI UUID session keys across gateway session resolution, Control UI URL normalization, and transcript lookup, and also adds unrelated Codex proxy/auth/compaction/send-routing runtime changes.

## Best Possible Solution

Land a narrow UUID-preservation or shared raw-alias session repair on the current session-store-key architecture with upgrade tests and real Open WebUI plus Control UI proof, and move the Codex/provider auth transport work to separate review.
