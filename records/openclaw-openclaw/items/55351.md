  - confidence: 0.86

  - body: OpenClaw currently treats `openai-codex` as legacy migration input and repairs it to `openai/*`; adding it to live Codex proxy handling creates a second active route that can bypass the established doctor/auth migration path.
  - confidence: 0.84
- **[P1] Keep UUID sessions scoped across combined-store round trips:** `src/gateway/session-utils.ts:643-644`
  - body: Returning bare UUIDs from `canonicalizeSessionKeyForAgent` drops the originating agent identity while per-agent stores are merged. With multiple agent stores or a changed default agent, a listed bare UUID can round-trip into the current default store and miss the original session.
  - confidence: 0.82
- **[P2] Check main-key aliases before the UUID fast path:** `src/gateway/session-utils.ts:668-669`
  - body: The new UUID early return runs before the configured `session.mainKey` alias handling, so a UUID-shaped main key now resolves as a bare external session instead of the configured main session. That can split an existing main-session setup that intentionally uses a UUID-like alias.
  - confidence: 0.78
- **[P2] Normalize legacy UUID links for the configured default agent:** `ui/src/ui/app-settings.ts:51-52`

  - confidence: 0.74
