  - body: This PR is scoped to Open WebUI UUID session identity, but this line wraps all embedded agent streams with a new Codex proxy transport.   - confidence: 0.91
- **[P1] Remove the live legacy Codex provider route:** `src/agents/pi-embedded-runner/codex-proxy-transport.ts:33`
  - body: The new transport treats `openai-codex` as a live provider family again. OpenClaw's current provider contract folds Codex into `openai` and treats `openai-codex` as legacy input for doctor/migration, so this can create conflicting auth and provider routing behavior.
  - confidence: 0.86
- **[P1] Preserve agent scope in combined UUID store rows:** `src/gateway/session-utils.ts:643-645`
  - body: Returning bare UUIDs from the agent-specific canonicalizer makes combined per-agent stores expose a UUID row without its owner agent. Later lookups for that bare key resolve against the current default agent, so histories can disappear after a default-agent change or when multiple agent stores exist.
  - confidence: 0.82
- **[P2] Normalize UUID links for the owning agent:** `ui/src/ui/app-settings.ts:51-52`
  - body: This only strips `agent:main:<uuid>`, but legacy links could have been generated with whatever agent was default when the session was created. A default such as `ops` leaves `agent:ops:<uuid>` unnormalized and can keep the same split identity this PR is trying to converge.
  - confidence: 0.84
- **[P2] Resolve main-key aliases before the UUID fast path:** `src/gateway/session-utils.ts:668-669`
  - body: The UUID fast path runs before the configured `session.mainKey` check. If an existing configured main key is UUID-shaped, it now stays bare instead of resolving to the canonical main session key, which can split history for that documented alias path.
  - confidence: 0.78
- **[P2] Avoid duplicating the system prompt in Codex payloads:** `src/agents/pi-embedded-runner/codex-proxy-transport.ts:722-723`
  - body: `buildRequestBody` sets `instructions` from `context.systemPrompt`, while `convertResponsesMessages` also injects the same prompt into the input as a system/developer message. Upstream Codex sends non-lite base instructions through `instructions`, so this doubles prompt content and can change model behavior or token use.
  - confidence: 0.77
