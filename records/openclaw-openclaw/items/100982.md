## What This Changes

The issue reports that delivery-mirror usage can make compaction persist invalid tokensBefore telemetry, causing transcript rewrite to reject compaction records and long sessions to keep replaying untruncated history.

## Best Possible Solution

Land one canonical fix that skips transcript-only mirrors for assistant-usage sampling, normalizes or falls back from non-finite token telemetry, and keeps compaction replay from discarding valid summaries solely because tokensBefore is malformed.
