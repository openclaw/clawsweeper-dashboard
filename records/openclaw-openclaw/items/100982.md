## Summary

Keep open: current main still has a source-backed path where malformed assistant usage can flow into `tokensBefore`, persist as invalid compaction telemetry, and cause replay to reject the compaction record. I did not find a merged fix or a canonical open item that owns this exact remaining failure mode.

## What This Changes

The issue reports that `delivery-mirror` assistant usage can poison compaction `tokensBefore`, causing transcript replay to reject compaction records so safeguard sessions repeatedly compact without truncating.

## Best Possible Solution

Make compaction robust to transcript-only assistant rows and malformed usage: skip synthetic mirrors for assistant-usage sampling, fall back from non-finite or zero telemetry to content estimation, and keep replay from discarding otherwise valid compaction summaries solely because `tokensBefore` telemetry is malformed.
