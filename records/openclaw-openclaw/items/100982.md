## Summary

Keep open: current main still has the source-backed compaction telemetry failure, and https://github.com/openclaw/openclaw/pull/101033 is the active proof-sufficient closing candidate rather than a merged fix.

## What This Changes

Fix compaction so delivery-mirror or malformed assistant usage cannot serialize `tokensBefore` as `null` and cause transcript replay to reject compaction summaries, preventing session truncation.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/101033 or an equivalent layered producer-and-consumer hardening, then treat reclaimable-token no-op compaction behavior as a separate follow-up if it remains user-visible.
