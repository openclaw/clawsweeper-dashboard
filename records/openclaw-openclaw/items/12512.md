## Summary

Keep open: current main and the latest release still expose skills through a model-facing SKILL.md catalog/read-and-follow path, while the requested instruction isolation, role locking, per-skill memory/tool authority, and monitoring remain unresolved security/product design work.

## What This Changes

The issue requests isolating SKILL.md instructions from trusted agent context and adding capability-aware enforcement against malicious skill prompt injection.

## Best Possible Solution

Define one maintainer-approved skill trust and capability contract, then enforce it consistently through prompt selection, SKILL.md loading, tool execution, memory access, sandbox policy, regression tests, and docs.
