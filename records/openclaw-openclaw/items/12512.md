## Summary

Keep open: current main still delegates selected SKILL.md instructions to the model without a per-skill runtime authority boundary, while OpenClaw’s documented threat model treats prompt injection as manipulable content rather than an enforceable security boundary; the recent maintainer-side review also explicitly retained this for security and product design.

## What This Changes

Add enforced isolation between trusted agent instructions and SKILL.md content, including role, memory, tool-capability, and behavioral controls.

## Best Possible Solution

Define skills as typed runtime activation contexts with declared capability requests and enforce tool, filesystem, network, secret, message, and memory access at the existing policy/sandbox boundaries; treat static scanning and prompt delimiters only as supplemental detection and presentation.
