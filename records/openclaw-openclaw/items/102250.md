## What This Changes

The issue asks OpenClaw to stop session auto-retry from retrying permanent provider errors and long-window rate limits that cannot succeed within the 2s/4s/8s retry window.

## Best Possible Solution

Tighten the session retry classifier in the current owner path, add regression tests for incidental status substrings and long-window limits, and avoid adding a new config or generic retry framework.
