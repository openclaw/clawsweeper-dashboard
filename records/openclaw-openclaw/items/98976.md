The issue asks OpenClaw to treat Anthropic refusals and OpenAI content_filter finishes as fallback-eligible so configured model fallback chains are consulted instead of ending turns with a generic LLM failure.

## Best Possible Solution

Review the open refusal-failover PRs and land a maintainer-approved policy that keeps Anthropic's sanctioned provider-side fallback while explicitly deciding how OpenAI and cross-provider refusal fallback should behave.
