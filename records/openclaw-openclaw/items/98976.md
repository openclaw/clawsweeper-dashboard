## What This Changes

The issue requests that provider refusal results, including Anthropic refusal and OpenAI `content_filter`, become failover-eligible so configured model fallbacks are attempted and diagnostics preserve the refusal reason.

## Best Possible Solution

Keep the provider-side Anthropic solution from https://github.com/openclaw/openclaw/pull/99906, then resolve the remaining OpenAI/content-filter and generic refusal semantics through a maintainer-approved refusal reason or an explicitly documented strict behavior before landing one candidate PR.
