## What This Changes

This PR raises the display limit for HTTP(S) URLs and adds URL-aware redaction intended to retain signed asset URL parameters while continuing to redact ordinary token parameters.

## System Context

The agents tool-display layer turns tool arguments into compact detail text for transcript, log, and UI presentation. Tool input flows through value coercion and redaction before being formatted as a user-visible tool summary.

## Best Possible Solution
