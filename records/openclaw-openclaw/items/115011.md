## What This Changes

The PR stops an already-cancelled embedded agent attempt from starting its session prompt, preventing a detached model-processing loop after cancellation or timeout.

## System Context

The embedded agent runner prepares an attempt from a channel, RPC, or scheduled input, then delegates the prompt to an active agent session. That session can start a model/tool loop, while the attempt lifecycle owns cancellation, transcript writes, cleanup, and the final terminal outcome.
