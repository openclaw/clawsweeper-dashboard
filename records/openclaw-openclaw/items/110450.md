## Summary

Keep this PR open for a narrow correction: the oversized-markdown update has convincing real-run proof, but the same branch also introduces an unscoped session-corpus filter that can silently exclude legitimate user or assistant content from dreaming ingestion.

## What This Changes

The PR routes daily inline memory files and `DREAMS.md` through a 16 MiB-aware managed-block updater that streams oversized files while retaining surrounding user content.

## System Context

Memory Core’s optional dreaming sweep consolidates workspace notes into managed phase summaries. Daily memory markdown and the Dream Diary feed the updater, which must preserve user-owned text while replacing only OpenClaw’s marked blocks.
