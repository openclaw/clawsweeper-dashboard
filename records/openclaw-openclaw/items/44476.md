## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P2] Probe trusted-proxy listeners through an actual trusted source:** `src/cli/gateway-cli/run.ts:200`
  - body: The PR adds synthetic trusted-proxy headers, but gateway auth also rejects requests whose socket `remoteAddress` is not in `gateway.trustedProxies`. When the configured proxy is not localhost, this direct probe still fails auth, so a healthy gateway is reported unhealthy and the EADDRINUSE restart loop remains.
  - confidence: 0.86
- **[P2] Bracket IPv6 custom bind hosts before probing:** `src/cli/gateway-cli/run.ts:169`
  - body: `resolveGatewayBindUrl` can return an unbracketed IPv6 URL such as `ws://::1:18789`; this call passes it straight into the URL filter, which rejects it and falls back to IPv4 loopback. A gateway bound only to the IPv6 custom host is then misclassified as unhealthy.
  - confidence: 0.78
