Full review comments:

- **[P2] Probe trusted-proxy only through a trusted source:** `src/cli/gateway-cli/run.ts:562`
  - body: This direct self-probe adds trusted-proxy headers, but current auth also requires the socket remote address to match `gateway.trustedProxies` and rejects loopback unless allowed. For LAN/custom deployments where the real trusted proxy is a different host, the probe will still report a healthy gateway as unhealthy and the restart-loop behavior remains.
  - confidence: 0.85
- **[P2] Bracket IPv6 custom bind hosts before probing:** `src/cli/gateway-cli/run.ts:169`
  - body: The probe uses the bind URL helper output directly, and that helper formats custom hosts as `scheme://host:port`. With an IPv6 custom host such as `::1`, the generated URL is invalid and gets filtered out, so a healthy IPv6-bound gateway can still be treated as unhealthy on EADDRINUSE.
  - confidence: 0.82
