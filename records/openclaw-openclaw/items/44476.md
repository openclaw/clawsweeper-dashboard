Full review comments:

- **[P1] Preserve systemd exit 78 for healthy conflicts:** `src/cli/gateway-cli/run.ts:570`
  - body: Current main intentionally exits 78 for healthy systemd lock/EADDRINUSE conflicts so `RestartPreventExitStatus=78` stops `Restart=always` loops. This patch's healthy-probe path exits 0 unconditionally, which would undo that protection if rebased over the current supervised-lock path.
  - confidence: 0.9
- **[P2] Do not treat synthetic trusted-proxy headers as proof:** `src/cli/gateway-cli/run.ts:208-212`
  - body: The probe can add trusted-proxy headers, but gateway auth also checks the socket source against `gateway.trustedProxies` and rejects loopback unless `allowLoopback` is enabled. Direct self-probes through these headers will still fail in common non-loopback proxy deployments, so the PR does not actually cover all trusted-proxy modes it claims to cover.
  - confidence: 0.84
