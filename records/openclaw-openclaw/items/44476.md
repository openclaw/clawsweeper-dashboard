- **[P2] Probe trusted-proxy through a trusted source:** `src/cli/gateway-cli/run.ts:561`
  - body: The new probe builds trusted-proxy headers locally, but trusted-proxy auth also checks the request source and rejects loopback unless `allowLoopback` is explicitly enabled.   - confidence: 0.88

  - body: Passing `resolveGatewayBindUrl()` output through unchanged leaves custom IPv6 hosts such as `::1` as `ws://::1:<port>`, which is not a valid URL and gets filtered before probing. An IPv6-only healthy listener then falls back to `127.0.0.1` and is misclassified as unhealthy.
  - confidence: 0.76
