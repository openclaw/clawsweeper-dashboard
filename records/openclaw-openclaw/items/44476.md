  - body: The probe uses the bind URL helper output directly, and that helper formats custom hosts as `scheme://host:port`. With an IPv6 custom host such as `::1`, the generated URL is invalid and gets filtered out, so a healthy IPv6-bound gateway can still be treated as unhealthy on EADDRINUSE.
  - confidence: 0.82
