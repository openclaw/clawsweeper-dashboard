## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Route trusted-proxy probes through a trusted source:** `src/cli/gateway-cli/run.ts:562`
  - body: This remains from the prior ClawSweeper review. The probe dials the gateway directly and only injects synthetic trusted-proxy headers, but trusted-proxy auth validates the socket source against `gateway.trustedProxies` before trusting those headers. In deployments that trust a remote proxy rather than the local process, the probe still reports unhealthy and the EADDRINUSE restart-loop path remains.
  - confidence: 0.86
- **[P2] Normalize IPv6 custom bind URLs before probing:** `src/cli/gateway-cli/run.ts:169`
  - body: This remains from the prior ClawSweeper review. `resolveGatewayBindUrl` can return an unbracketed IPv6 URL such as `ws://::1:18789`, which is invalid and gets filtered out before probing. An existing gateway bound only to that IPv6 custom host then falls back to `127.0.0.1`, is treated as unhealthy, and still exits through the EADDRINUSE failure path.
  - confidence: 0.78
