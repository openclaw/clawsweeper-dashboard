Full review comments:

- **[P2] Use one model ordering for index callbacks:** `extensions/telegram/src/model-buttons.ts:271-276`
  - body: Late catch from this review cycle: `mdl_idx_*` stores only the numeric position, but not every Telegram list path builds that position with the same ordering. The direct `/models <provider>` command path passes models sorted with default `.toSorted()` (`src/auto-reply/reply/commands-models.ts:581`), while the callback handler resolves `selectIndex` against `localeCompare` order. Mixed-case or punctuation-heavy long ids can therefore render a fresh over-limit button that immediately token-mismatches and asks the user to refresh instead of selecting it. Please centralize/share the comparator and cover that direct command channelData path before merge.
