Full review comments:

- **[P2] Force chat refreshes to stay on active sessions:** `ui/src/ui/controllers/sessions.ts:1141`
  - body: With this new `archived: true` branch, chat-side refreshes that use `createChatSessionsLoadOverrides(state)` inherit the Sessions page archived-only toggle. Changing model/thinking/speed while that toggle is on can reload `state.sessionsResult` with only archived rows, dropping active chat metadata until another active reload; force chat refreshes to request active sessions.
  - confidence: 0.91
- **[P2] Switch away when table archiving the current session:** `ui/src/ui/views/sessions.ts:1100`
  - body: The Sessions table now archives by calling `props.onPatch(row.key, { archived: ... })`, but the app handler only calls `patchSession`; it does not use the chat picker fallback that switches the selected archived session back to the agent main session. If the archived row is the current chat, Chat can continue on a hidden archived thread despite the PR's stated behavior.
  - confidence: 0.9
- **[P2] Regenerate the locale bundles:** `ui/src/i18n/locales/en.ts:168`
  - body: These new English strings were added without the generated non-English locale bundles, and this repo's `ui:i18n:check` fails on that drift. Run the Control UI i18n sync and commit the generated locale outputs with the English source change.
  - confidence: 0.87
