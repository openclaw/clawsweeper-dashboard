## Summary

Keep open: source and docs show subagent completions are supposed to hand off through the requester session, but current main only exposes detached task state on demand and Telegram still lacks a child-run keepalive or guaranteed visible terminal path. The latest reporter smoke check adds a stronger delivery symptom: raw child output can leak while the parent-facing response remains unfinished.

## What This Changes

Requests Telegram-visible liveness and terminal notification for detached native subagents, including status visibility and one consistent terminal state.

## Best Possible Solution

Define a Telegram-visible detached-subagent contract that reuses existing task/subagent state for sparse redacted liveness, deterministic status, and terminal delivery through the owning chat or topic without exposing raw child output.
