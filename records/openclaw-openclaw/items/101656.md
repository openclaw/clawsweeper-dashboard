## Summary

Keep open: current main has task-ledger status, on-demand session status, early Telegram typing, and terminal-delivery machinery, but it still does not provide a reliable Telegram-visible liveness path or proven terminal handoff for detached Telegram subagents; the closest fix, PR #97963, is open and only covers part of the problem.

## What This Changes

Request deterministic Telegram-visible liveness/status and terminal notification for detached subagents spawned from Telegram-originated turns.

## Best Possible Solution

Use the existing task ledger/session status as the source of truth, make Telegram-originated detached subagents emit deterministic liveness and terminal/blocked messages without exposing raw child output, and land or rework #97963 only with live Telegram proof.
