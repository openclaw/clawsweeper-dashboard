## Summary

Keep open: current main still cancels the existing on-exit watcher during a cron hot reload, rebuilds a fresh watcher service, and reconciles from an empty active map. The linked fix PR is open and appears to own the repair path, so this issue should stay open until that PR lands or is rejected.

## What This Changes

The issue reports that changing any `cron.*` config key during an in-flight on-exit watched command can kill and re-spawn that command.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99724 if it stays clean, then close this issue after the fix reaches main.

## Reproduction Assessment

Yes. Source inspection shows current main maps `cron` changes to `restart-cron`, cancels active exit watchers, and rebuilds a fresh watcher instance; the reporter’s seam proof and the linked PR proof target that same path.

## Solution Assessment

Yes. The narrow maintainable fix is to preserve the existing watcher manager across cron hot reload and let reconciliation continue canceling removed, disabled, or command-changed jobs.
