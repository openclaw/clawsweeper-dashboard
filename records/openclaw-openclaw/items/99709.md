## Summary

Keep open: current main still contains the reported cron hot-reload path that cancels instance-local on-exit watchers and rebuilds a fresh watcher service, and the open linked pull request is the right candidate to review and land before this issue closes.

## What This Changes

Changing any `cron.*` config key during an in-flight on-exit watched command should leave that command running and avoid re-executing it.

## Best Possible Solution

Preserve active on-exit watcher state across same-store cron hot reloads while still canceling on shutdown, disabled or removed jobs, command/cwd changes, and cron store changes.

## Reproduction Assessment

Yes. Source inspection on current main shows `cron.*` reloads still cancel old instance-local exit watchers and reconcile a freshly built watcher manager; the reporter’s seam proof matches that composition, though I did not run a full live config-file reload.

## Solution Assessment

Yes. The narrow maintainable solution is to preserve same-store live watcher state across cron hot reloads while retaining cancellation for real shutdown, removed/changed jobs, and store changes.
