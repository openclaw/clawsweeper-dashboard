## What This Changes

The issue reports that hot reloading any `cron.*` config can cancel and re-execute an in-flight on-exit watched command.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/99724 or an equivalent fix that preserves unchanged live on-exit watcher state across cron hot reload while still canceling on shutdown, disable, removal, or command/cwd changes.

## Reproduction Assessment

Yes from source inspection: current main cancels the old watcher manager and reconciles a fresh one on cron hot reload. I did not run the live config reload path in this read-only review.

## Solution Assessment

Yes: preserving the watcher manager across cron hot reload is the narrow maintainable fix because in-flight command liveness is held by the watcher instance, not by the cron store.
