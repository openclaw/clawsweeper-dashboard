## What This Changes

The issue reports that changing any `cron.*` config key during an in-flight on-exit watched command cancels and re-spawns that watched command.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99724 or an equivalent fix that preserves unchanged live on-exit watchers across cron hot reload without weakening real shutdown or job-change cancellation.

## Reproduction Assessment

Yes, at source level. Current main maps `cron.*` changes to restartCron, cancels the old watcher manager, rebuilds a fresh manager, and reconciles from empty state; the reporter’s seam proof exercises that same path.

## Solution Assessment

Yes. The narrow maintainable solution is to preserve or transfer unchanged live watcher state across cron hot reload, rather than disabling reload or adding a new configuration mode.
