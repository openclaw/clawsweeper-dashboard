## What This Changes

Fix the Control UI so read-only Workboard dashboard cards show their current status without enabling a control that can request an unauthorized card-status mutation.

## System Context

The Control UI renders session-dashboard widgets using Gateway connection capabilities. A Workboard card widget displays card state and may request `workboard.cards.move`; the effective board or widget write capability must flow into that widget before it enables the status selector.
