## Summary

Keep open, but the current patch should not merge: it fixes first-message title generation by removing the only history check, which also makes unnamed historical sessions eligible for retroactive titles and sends an arbitrary later message to the configured utility model. The competing https://github.com/openclaw/openclaw/pull/108263 preserves an explicit first-turn boundary, but it currently has test-only evidence, so it is not yet a proof-positive replacement that safely supports closing this PR as superseded.

## What This Changes

Removes the `systemSent` eligibility guard and its matching skip-case test from dashboard session auto-title generation.

## Best Possible Solution

Carry an explicit pre-bootstrap first-turn fact into title scheduling, retain session-generation and explicit-name protections, and verify that a new chat is titled once while existing unnamed sessions remain untouched on later messages.
