## Summary

Keep this PR open for revision rather than closing it as a duplicate: the reported dashboard regression is valid, but this branch removes an intentional historical-session safeguard instead of preserving the first-turn invariant. The broader candidate at https://github.com/openclaw/openclaw/pull/108263 addresses that invariant, but its test-only evidence is not positive real-behavior proof, so it is not yet a safe superseding target.

## What This Changes

The PR removes the `systemSent` skip condition and its corresponding test case from dashboard session auto-title generation.

## Best Possible Solution

Dashboard titles should be generated exactly once from the first accepted non-command user message, with first-turn state captured before bootstrap and carried through fast-path, accepted-session, reset, and rotation paths while explicit names and historical sessions remain untouched.
