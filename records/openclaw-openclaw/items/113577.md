## What This Changes

Refresh Qwen Token Plan catalog metadata by exposing `qwen3.8-max-preview`, correcting supported output and video-input limits, and removing Team-only terminology from provider docs.

## System Context

The Qwen plugin maps Token Plan credentials to a curated static model catalog that feeds model selection, context limits, and attachment capability checks before requests reach Alibaba’s compatible-mode gateway. Incorrect catalog metadata can hide an entitled model, reject supported video input locally, or impose lower-than-service output limits.
