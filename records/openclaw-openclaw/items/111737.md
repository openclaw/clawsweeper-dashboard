## Summary

This is a useful, well-scoped hardening fix with convincing device-code proof, but it leaves the xAI refresh-token exchange on the replacement-character decoding path; merge after the same invariant covers that sibling OAuth response flow.

## Best Possible Solution

Centralize strict UTF-8 JSON decoding for xAI token responses, apply it to both device-code polling and refresh-token exchange, and cover both flows with malformed-byte regression tests.
