## Summary

This PR addresses a real startup regression at the correct plugin-owned boundary, but it must not merge as written: the blanket downgrade also suppresses genuine or unverified persisted-state conflicts, an unrelated test mock diverges from production behavior, and the submitted screenshot does not prove the migration scenario.

## What This Changes

The PR moves existing-target SQLite migration messages from warnings to notices in Matrix, Memory Core, and Workboard, updates extension tests, and changes a model-selection mock in an agent test.

## Best Possible Solution

Classify only verified equivalent, fully migrated targets as notices; keep mismatched, partial, or merely present targets as blocking warnings, add focused upgrade tests for both cases, and remove the unrelated model-selection mock change.
