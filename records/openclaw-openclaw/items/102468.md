## Label Justifications

- `P1`: The issue describes a production Telegram channel workflow where long turns block group messages and can be killed by the default isolated-ingress handler timeout.
- `impact:message-loss`: Same-lane Telegram messages remain parked at the transport layer and the timeout path marks a spooled update failed while aborting reply work.
- `impact:session-state`: The transport lane prevents inbound messages from reaching session admission and steering state while an active reply operation is running.

## Summary

Keep open: current main still couples Telegram isolated-ingress lane ownership to the full awaited agent turn, and the live item has a protected maintainer label plus design blast radius around spool durability, reply-fence aborts, and session admission.

## What This Changes

Request to detach Telegram isolated-ingress spool claims from full agent-turn lifetime so same-chat messages can reach session admission during long turns and the 25-minute handler guard only protects dispatch handoff.

## Best Possible Solution

Define a Telegram durable-handoff contract that releases the transport lane after the inbound is durably recorded or admitted to session machinery, then prove it with crash/replay tests and live Telegram long-turn proof while tracking claude-cli mid-turn injection separately.

- **Fold Into Run-Lifecycle Stack:** Wait for the broader run-lifecycle work to settle a shared queue/admission invariant before changing Telegram's transport drain ownership.

Yes at source level: current main awaits full Telegram handleUpdate inside the active spooled lane and tests expect timeout recovery that fails the update and restarts ingress. I did not run a live Telegram long-turn reproduction in this read-only review.

## Solution Assessment

Yes at the design level, but the exact implementation needs maintainer review. Detaching at durable handoff appears to be the right ownership boundary, while replay safety, same-lane ordering, and claude-cli live queue injection need explicit contract decisions.
