  - body: `createRequestRateLimiter` is constructed unconditionally from optional config, which turns the new 120 req/min/IP limit on for every upgraded gateway. Existing HTTP or WebSocket clients can start receiving 429s without an explicit operator choice or documented migration path.
  - confidence: 0.9

  - body: The shared bind resolver is used outside startup, including doctor/security diagnostics. Current main keeps the fallback-returning helper and lets startup reject unsafe fallbacks, but this change makes the helper itself throw for loopback/tailnet/custom failures, which can turn diagnostic paths into hard failures.
  - confidence: 0.86
- **[P2] Pass the audit logger through credential auth callers:** `src/gateway/server-http.ts:764`
