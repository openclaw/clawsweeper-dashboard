  - body: The PR adds operator-facing keys here, but `src/config/zod-schema.ts` still uses strict Gateway objects that do not include `ipAllowlist`, `ipBlocklist`, `requestRateLimit`, or `tls.terminatedUpstream`. As written, documented `openclaw config set ...` commands and validated config loads can reject or omit the very settings the runtime reads.
  - confidence: 0.94
- **[P1] Keep request throttling behind an approved default:** `src/gateway/server.impl.ts:531`
  - body: This creates a request limiter unconditionally, so existing Gateway HTTP and WebSocket clients can start receiving `429` after upgrade even when operators did not configure a request limit. That default needs explicit maintainer approval plus fresh-install and upgrade proof, or the limiter should stay opt-in.
  - confidence: 0.9
- **[P1] Keep HSTS opt-in unless the default is approved:** `src/gateway/server-runtime-config.ts:201-202`
  - body: This auto-adds `Strict-Transport-Security: max-age=31536000` whenever Gateway TLS is enabled, while current docs/config describe HSTS as an explicit operator setting. A long-lived HSTS default can pin browser behavior for staging or proxy-fronted deployments, so it needs maintainer-approved default policy and docs before merge.
  - confidence: 0.88
- **[P1] Define audit-log retention before enabling it by default:** `src/gateway/server.impl.ts:534`
  - body: The PR creates the auth audit logger for every Gateway start, and the logger persists client IPs and user identifiers to a JSONL file. Before this is default-on, maintainers need an explicit opt-in/default policy with retention, redaction, and documentation for that sensitive local log.
  - confidence: 0.86
- **[P2] Thread the audit logger into auth verification:** `src/gateway/auth.ts:85-94`
  - body: Adding `auditLogger` to the auth API is not enough: the HTTP and WebSocket auth call sites still call the auth helpers without passing it, so `auth_success` and `auth_failure` are not recorded for normal credential outcomes. That makes the advertised auth audit log incomplete.
  - confidence: 0.87
