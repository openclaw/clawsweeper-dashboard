  - confidence: 0.9

  - body: This default emits `Strict-Transport-Security: max-age=31536000` for any TLS Gateway with no configured header. Current docs and runtime treat HSTS as an explicit rollout choice because it is sticky in browsers, so default-on long-lived HSTS can break staging or reverse-proxy deployments.
  - confidence: 0.91

  - body: The PR starts an auth audit JSONL logger on every Gateway start, and the log records client IPs and users. Before merging a default-on sensitive log sink, the PR needs an explicit privacy/retention/permission policy and operator control.
