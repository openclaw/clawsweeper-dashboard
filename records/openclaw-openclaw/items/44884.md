  - body: This auto-populates `Strict-Transport-Security: max-age=31536000` whenever Gateway TLS is enabled, while current docs make HSTS an explicit operator setting for HTTPS origins they control.   - confidence: 0.9

  - body: Every Gateway start now creates a persistent auth audit logger that records client IPs and user identifiers, but the PR adds no config opt-in, retention/redaction policy, or docs for that data.
