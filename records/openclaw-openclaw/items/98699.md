## What This Changes

The PR reads cron delivery `threadId` type from `job_json` on SQLite reload, falls back to `delivery_thread_id`, and adds regression tests for numeric, numeric-looking string, same-text, and null split-column rows.

## Best Possible Solution

Land the reader-side fix after maintainer compatibility review, keeping the SQLite schema and writer unchanged while using `job_json` only to recover the configured thread ID type.
