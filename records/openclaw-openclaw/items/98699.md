The PR changes cron SQLite delivery decoding to restore `delivery.threadId` from typed `job_json` before falling back to the split text column, and adds store regression tests for numeric, string, and null-column round trips.

## Best Possible Solution

Land the type-preserving reader if maintainers accept `job_json` as the thread-id type source, keeping the split TEXT column as a fallback for older or partial rows.
