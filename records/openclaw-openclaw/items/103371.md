## What This Changes

The PR changes QQBot account resolution, listing, bridge credential lookup, and logout cleanup so only own account entries and own credential fields are treated as configured values.

## System Context

QQBot reads channel configuration to select an account, resolve credentials, and perform gateway logout cleanup. These paths feed account setup and runtime credential handling, so they need to agree on which configuration fields belong to the user.
