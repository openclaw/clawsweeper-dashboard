## What This Changes

The PR changes QQBot credential cleanup to act only on own account and credential properties and adds regression tests for inherited and ordinary credential entries.

## Best Possible Solution

Merge the plugin-local own-property correction after the contributor demonstrates, with redacted live output, that inherited credential data is ignored while ordinary default and named-account credentials still clear correctly.
