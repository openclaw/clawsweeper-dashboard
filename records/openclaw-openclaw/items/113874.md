## What This Changes

The branch makes each QA transport cleanup phase share one in-flight operation, so concurrent teardown callers stop a live adapter and release its credential lease once, receive the same failure, and can retry after a failed cleanup.

## System Context

QA Lab builds transport adapters for live and mock channel scenarios. Gateway and scenario teardown invoke before- and after-gateway cleanup hooks, which stop transport drivers and release their associated credential leases.
