Keep open: current main and v2026.6.11 still write Anthropic setup-token and paste-token profiles to one selected agent store, while runtime read-through only mitigates part of the missing-sibling failure. The remaining UX, validation, and static-token propagation contract need maintainer/security review, especially with an open conflicting fork PR and prior same-repo fixes closed unmerged.

## What This Changes

The issue requests fixes for Anthropic setup-token onboarding guidance, credential persistence validation, and multi-agent auth profile propagation.

## Best Possible Solution

Settle the auth-store sharing contract, then land or replace a focused fix that improves setup-token guidance, adds post-write validation, and implements the chosen static-token sharing or inheritance behavior while preserving OAuth isolation.

## Reproduction Assessment

Partly. Source inspection shows setup-token and paste-token still persist to one selected agent store, but I did not establish a live current-main reproduction of the exact gateway startup failure because runtime read-through may now mask it.

## Solution Assessment
