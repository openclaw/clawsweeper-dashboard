## Summary

Keep open: current main and the latest stable release mitigate the exact missing-sibling runtime symptom with main-store read-through, but Anthropic setup-token and paste-token still write only the selected agent store, the prompt remains thin, and previous sibling-sync fixes exposed credential-propagation security concerns.

## What This Changes

The issue requests reliable Anthropic setup-token onboarding across prompt guidance, token persistence validation, and multi-agent credential availability.

## Best Possible Solution

Settle the auth-store sharing contract, then land or replace a focused fix that improves setup-token guidance, adds post-write/readback validation, and implements only the chosen static-token sync or inheritance behavior without weakening OAuth isolation.
