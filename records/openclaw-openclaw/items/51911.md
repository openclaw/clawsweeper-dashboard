## What This Changes

This issue requests a more reliable Anthropic setup-token onboarding path with clearer Claude CLI guidance, post-write validation, and multi-agent credential availability without manual copying.

## Best Possible Solution

Settle the auth-store sharing contract, then land or replace a focused fix that improves setup-token guidance, adds readback validation against the SQLite auth store, and implements the chosen static-token inheritance or sync behavior without weakening OAuth isolation.
