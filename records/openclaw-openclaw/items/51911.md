## Summary

Keep open: current main still leaves the Anthropic setup-token/paste-token write-side contract and prompt clarity unresolved, while runtime main-store read-through only partially mitigates the reported multi-agent startup failure.

## What This Changes

The issue asks OpenClaw to make Anthropic setup-token onboarding clearer, validate token persistence, and handle multi-agent credential availability without manual auth-store edits.

## Best Possible Solution

Settle the credential-sharing contract, then land or replace a focused fix that improves setup-token guidance, adds SQLite auth-store readback validation, and preserves OAuth isolation while making static Anthropic token availability predictable across agents.

- **Deprecate setup-token onboarding:** Keep setup-token supported only as an advanced/manual path and steer normal users to Claude CLI reuse or Anthropic API keys.
