## Summary

Keep open: current main mitigates the old missing-sibling startup path through SQLite auth storage and main-store read-through, but the remaining setup-token UX, validation, and credential propagation policy are still unresolved and security-sensitive.

## What This Changes

The issue asks OpenClaw to make Anthropic setup-token onboarding reliable by clarifying the Claude CLI flow, validating token persistence, and making credentials available across multiple agents.

## Best Possible Solution

Keep main-store inheritance as the default unless maintainers explicitly approve copying, then improve setup-token prompts, status/doctor validation, and docs around the current SQLite auth model.
