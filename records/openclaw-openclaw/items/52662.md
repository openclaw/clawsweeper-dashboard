## Summary

Keep open. Current main and the latest release still manage sandbox browsers through Docker-specific lifecycle code, and external CDP/noVNC endpoint support remains a product and security-boundary decision rather than implemented behavior.

## What This Changes

The issue requests externally managed browser CDP/noVNC endpoint support so sandbox browser automation can run without a Docker-managed browser container.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
