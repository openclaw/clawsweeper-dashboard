## Summary

Keep open. Current main and v2026.6.11 still route sandbox-browser setup through Docker lifecycle and loopback-published CDP/noVNC ports; the requested external endpoint mode remains a product and security-boundary decision.

## What This Changes

The issue requests externally managed sandbox-browser CDP/noVNC endpoints so non-Docker sandbox backends can use browser automation without a Docker daemon.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
