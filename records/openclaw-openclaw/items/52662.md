## Summary

Keep open. Current main and v2026.6.11 still run sandbox browser lifecycle through Docker-specific container, port, CDP auth, and noVNC paths; the requested external CDP/noVNC endpoint support remains a product and security-boundary decision.

## What This Changes

Request support for externally managed sandbox-browser CDP/noVNC endpoints so non-Docker sandbox deployments can use browser automation without a Docker daemon.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
