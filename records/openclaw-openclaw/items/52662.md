## Summary

Keep open: current main and v2026.6.11 still manage sandbox browsers through Docker-specific lifecycle code, and external CDP/noVNC endpoint support remains an unresolved product and security-boundary decision.

## What This Changes

The issue requests external CDP/noVNC endpoint support so sandbox browser automation can use non-Docker or externally managed browser backends.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
