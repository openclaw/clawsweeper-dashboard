## Summary

Keep open. Current main still keeps sandbox-browser lifecycle Docker-specific, and the requested external CDP/noVNC endpoint support remains a product and security-boundary decision rather than implemented or safely superseded work.

## What This Changes

The issue requests externally managed CDP/noVNC endpoints for sandbox browsers so non-Docker sandbox backends can use browser automation without Docker daemon access.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
