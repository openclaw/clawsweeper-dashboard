## Summary

Keep open. Current main and v2026.6.11 still route sandbox-browser setup through Docker-specific lifecycle and config, while external CDP/noVNC endpoint support remains a sandbox-browser API, config, and security-boundary decision.

## What This Changes

The issue requests external CDP/noVNC endpoint support so the sandbox browser can be managed outside Docker for Kubernetes, Compose, Lightpanda, or other non-Docker deployments.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
