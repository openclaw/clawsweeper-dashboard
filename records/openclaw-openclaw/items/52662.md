## Summary

Keep open. Current main and v2026.6.11 still use a Docker-managed sandbox-browser lifecycle with no external CDP/noVNC endpoint config, and related browser-backend issues overlap but do not replace this narrower sandbox-browser API and security-boundary decision.

## What This Changes

The issue requests externally managed CDP/noVNC endpoint support for sandbox browsers so browser automation can run without Docker-owned browser lifecycle management.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that preserves CDP auth, noVNC observer access, SSRF/source-range validation, lifecycle ownership, docs, and focused tests before exposing public config.
