## Summary

Keep open. Current main and v2026.6.11 still manage the sandbox browser through Docker and do not expose external CDP/noVNC endpoint config, while the requested fix is a public config and security-boundary decision rather than conservative cleanup.

## What This Changes

Request external CDP/noVNC endpoint support for sandbox browsers so non-Docker sandbox deployments can use externally managed browser containers.

## Best Possible Solution

Define a maintainer-approved sandbox-browser backend or external-endpoint contract that supports externally managed browsers while preserving CDP auth, SSRF policy, noVNC observer access, lifecycle semantics, docs, and focused tests.
