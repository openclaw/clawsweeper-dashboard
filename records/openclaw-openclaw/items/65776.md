## Summary

Keep open: current main and the latest release support static remote MCP headers plus MCP OAuth, but not a generic request-scoped header resolver for runtime/session authorization, tenant routing, or correlation headers. The related open issues and PRs cover narrower OAuth, env-substitution, SecretRef, and caller-context slices, so this remains a maintainer product/security decision rather than conservative cleanup.

## What This Changes

Requests dynamic per-request header generation for remote MCP HTTP/streamable-http servers using runtime or session context.

## Best Possible Solution

Define one maintainer-approved remote MCP auth/header contract that reuses OAuth, SecretRef, dynamic env substitution, or caller-context injection where they fit, and only adds a typed opt-in request-context resolver for remaining cases with explicit scoping, redaction, docs, and tests.
