## Summary

Current main still loads the full persisted subagent registry and performs synchronous in-memory filtering for requester/controller list calls, so the optimization remains useful; the earlier cache fix reduced cloning and reloads but did not add scoped SQL reads.

## What This Changes

Replace full-table subagent registry reads followed by linear Map filtering with scoped indexed SQLite queries while preserving process-local overlay behavior.

## Best Possible Solution

Add narrow Kysely store queries and justified indexes for requester/controller predicates, then overlay process-local records through one state-layer composition that preserves requester-run bounds, controller fallback, generation behavior, cross-process visibility, and deterministic output; include realistic before/after timing evidence.
