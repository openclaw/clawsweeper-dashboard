  - body: `clearActiveMcpLoopbackRuntime()` clears the global runtime and token table unconditionally.   - confidence: 0.94

  - body: The new revocation runs after `preparedBackend.cleanup`; if cleanup throws, the scoped bearer remains registered after the run. Put token unregistering in its own finally path so cleanup errors cannot leave stale authorization live.
  - confidence: 0.9
