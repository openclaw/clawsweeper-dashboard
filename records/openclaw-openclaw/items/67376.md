Full review comments:

- **[P1] Bind every current loopback context field:** `src/gateway/mcp-http.loopback-runtime.ts:7-12`
  - body: This token scope only carries the older four fields, but current main threads session id, current channel/thread/message, inbound audio, inbound-event, delivery mode, and explicit-target policy through loopback tool resolution. Rebase the fix so every server-bound MCP context field is stored with the token instead of being dropped or left header-controlled.
  - confidence: 0.96
- **[P1] Guard runtime clearing to the server being closed:** `src/gateway/mcp-http.loopback-runtime.ts:30-32`
  - body: `clearActiveMcpLoopbackRuntime()` clears the active runtime and all registered tokens unconditionally. If a new loopback server starts while an older server is finishing close, the old close can wipe the new server's token table and make fresh backends fail authorization.
  - confidence: 0.93
- **[P2] Revoke the token even when backend cleanup fails:** `src/agents/cli-runner.ts:124-126`
  - body: The token revocation runs after `preparedBackend.cleanup`, so any cleanup exception skips `unregisterMcpLoopbackToken` and leaves the bearer registered past run teardown. Put revocation in its own `finally` path so cleanup failures cannot preserve authorization.
  - confidence: 0.9
- **[P2] Revoke registered tokens on all prepare failures:** `src/agents/cli-runner/prepare.ts:173-177`
  - body: The catch here only covers `prepareCliBundleMcpConfig`; later preparation steps can still throw before the returned cleanup exists. Wrap the whole post-registration preparation path so a token registered for a backend that never starts is always unregistered.
  - confidence: 0.88
- **[P2] Remove the unrelated plugin loader fallback:** `src/plugins/public-surface-loader.ts:112-116`
  - body: This security PR also changes plugin public-surface loading to fall back to Jiti on selected `MODULE_NOT_FOUND` failures. That is outside the MCP loopback auth fix and can alter plugin loading behavior without proof, so split or drop it from this branch.
  - confidence: 0.8
