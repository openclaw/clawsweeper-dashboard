## What This Changes

This PR adds a plugin-managed 1Password exec SecretRef provider, setup and status CLI flows, trusted `op` executable checks, packaged resolver assets, shared SecretRef plan construction, tests, and documentation.

## System Context

OpenClaw SecretRefs resolve configured credentials when the Gateway starts, reloads, audits, or applies a secrets plan. This change lets the bundled 1Password plugin supply that resolution by running the local `op` CLI with a plugin-owned service-account credential, while retaining the existing curated agent broker as a separate opt-in surface.
