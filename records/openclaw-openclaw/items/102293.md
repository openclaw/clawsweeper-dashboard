## What This Changes

This PR lets the bundled 1Password plugin resolve configured OpenClaw SecretRefs through the local `op` CLI, adds setup and status commands, packages the resolver assets, and factors shared SecretRef setup-plan construction into the plugin SDK.

## System Context

SecretRefs keep registered OpenClaw credentials out of configuration files and resolve them when the Gateway starts, reloads, audits, or applies a plan. This change adds a plugin-owned 1Password resolver to that existing execution path while keeping the separate curated agent broker intact.
