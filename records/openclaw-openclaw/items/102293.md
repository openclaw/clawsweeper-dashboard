## What This Changes

Adds a managed 1Password `op`-CLI SecretRef provider, setup/status commands, packaged resolver assets, and a shared plugin-SDK helper for generating validated SecretRef apply plans.

## System Context

OpenClaw SecretRefs let configured credentials be resolved at runtime rather than stored as plaintext in configuration. This PR makes the bundled 1Password plugin an opt-in SecretRef provider: a setup command creates registered-target plans, the secrets subsystem invokes the packaged resolver, and the resolver reads configured 1Password fields through a trusted local `op` executable.
