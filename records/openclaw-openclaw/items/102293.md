## What This Changes

The PR lets the bundled 1Password plugin resolve configured SecretRefs through a trusted local `op` CLI, adds SecretRef setup and status commands, packages the resolver assets, and shares setup-plan construction with the Vault plugin.

## System Context

OpenClaw SecretRefs keep credentials out of configuration and resolve them during apply, audit, reload, and Gateway startup. This change adds 1Password as a plugin-owned exec provider: the setup CLI writes registered target mappings, and the resolver invokes a trusted `op` executable with a token from the plugin credential file.
