## What This Changes

Detect when the running macOS executable no longer matches the installed app bundle and safely relaunch the replacement app instead of leaving the embedded dashboard blank.

## Best Possible Solution

Add an event-driven macOS lifecycle guard at activation or dashboard opening that compares the live executable identity with the installed bundle, verifies the expected signed OpenClaw replacement, launches it once, and terminates the stale process; cover the decision logic with focused tests and prove the full signed `/Applications` replacement flow on macOS.
