## Label Justifications

- `P1`: The embedded macOS dashboard becomes unusable after a live bundle replacement and remains broken until the user manually restarts the app.
- `impact:ux-friction`: Users face a blank application window and must discover that quitting and reopening the app is the recovery path.

## Summary

This is a fresh, concrete native macOS lifecycle bug with a real-machine reproduction and no evidence that current main already recovers automatically. The issue is assigned and has the protected `maintainer` label, so it requires explicit maintainer handling rather than automated cleanup.

## What This Changes

Detect when the running macOS executable no longer matches the installed signed app bundle and safely relaunch the replacement app.

## Best Possible Solution

At an existing macOS activation or dashboard-opening lifecycle boundary, compare the running executable identity with the canonical installed bundle, validate that replacement, and perform a guarded one-time relaunch with focused signed-app tests and real replacement-path proof.
