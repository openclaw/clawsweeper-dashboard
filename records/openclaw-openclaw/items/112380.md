## Summary

This PR fixes the blank-URL exception, but it leaves the newly enabled Gemini request path using the original blank URL when choosing Google client headers. That omits the Google attribution header for blank-config image, audio, and video requests, so the patch needs one bounded follow-up plus real after-fix behavior proof before merge.

Likely related people: MonkeyLeeT is the current repair contributor (low confidence for ownership; main-history attribution could not be established from the available read-only inspection).

## What This Changes

The branch makes blank Google provider base URLs fall back to the canonical Gemini endpoint and adds image-generation regression cases for empty and whitespace-only values.

## System Context

The bundled Google provider turns a configured model provider URL into a trusted Gemini HTTP request, including endpoint validation and Google client attribution headers. Image generation, audio, and video capability callers use that request configuration before sending their API calls.
