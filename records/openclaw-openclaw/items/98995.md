## Summary

Keep open: current main still uses the reported iOS Settings top-right appearance menu, tests assert that placement, and no related open or merged item implements the requested Device-section row. This remains a small iOS UX/product-direction issue, especially because it would revise a same-day maintainer-authored Settings modernization.

## What This Changes

Move the iOS Settings appearance selector from the top-right toolbar menu into a visible Device-section Appearance row showing the current System, Light, or Dark value.

## Best Possible Solution

If maintainers accept the UX direction, move the existing AppAppearancePreference picker into a Device-section Appearance row with the current value, remove the toolbar menu, preserve the `appearance.preference` storage key, and update source guard plus iOS UI/snapshot proof.

## Reproduction Assessment

Yes for the current placement: current source and UI tests show the appearance control as a top-right toolbar menu. The reported iPad visual detachment was not live-run in a simulator during this read-only review.

## Solution Assessment

Unclear until maintainers confirm the Settings design direction. The proposed row is narrow and can reuse the existing preference model, but it reverses current tested toolbar placement from a same-day design pass.
