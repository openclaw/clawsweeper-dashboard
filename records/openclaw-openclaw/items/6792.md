## Summary

Current main and v2026.6.11 still lack an executable plugin-manifest configuration setup contract. The issue remains necessary, but implementation must wait for a maintainer-approved plugin authority and consent contract.

## What This Changes

Allow plugins to declare configuration changes that OpenClaw applies during plugin installation.

## Best Possible Solution

Add typed, path-scoped plugin setup operations backed by centralized config validation, with a displayed diff, explicit consent, conflict-aware collection semantics, and recorded provenance for recovery guidance.
