## Summary

Keep open: current main and the latest release still do not provide a manifest-level install-time config intent contract, and the remaining work is a product/security decision about third-party config mutation rather than conservative cleanup.

## What This Changes

The issue requests a new `openclaw.plugin.json` manifest field that lets plugin installs automatically apply validated config changes instead of requiring users to manually edit `openclaw.json`.

## Best Possible Solution

Define a documented, auditable manifest config-intent contract with validation, operator-visible diff/skip behavior, scoped permissions, conflict and array rules, and uninstall guidance before accepting third-party install-time config writes.
