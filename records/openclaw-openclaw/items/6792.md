## Summary

Keep open: current main and the latest release still lack a manifest-level install-time config intent contract, and the remaining work is a product/security decision rather than conservative cleanup.

## What This Changes

Request to add an install-time `configPatch` or config-intent field to plugin manifests so plugin installation can apply required user config automatically.

## Best Possible Solution

Define an auditable install-time plugin config-intent contract with allowlisted surfaces, validation before commit, visible diff and skip behavior, conflict and array semantics, uninstall provenance, docs, and install-route tests.

- **Accept raw configPatch:** Allow arbitrary manifest deep-merge patches during install, accepting higher config and security risk for plugin setup convenience.
