## Summary

Keep open: current main still lacks a manifest-level install-time config intent contract, and the remaining work is a product/security decision about third-party plugin-authored config mutation rather than stale cleanup.

## What This Changes

The issue requests a manifest-declared install-time plugin config patch so plugin installation can automatically update OpenClaw config instead of requiring manual JSON edits.

## Best Possible Solution

Define an auditable install-time plugin config-intent contract rather than a raw arbitrary deep-merge, with allowlisted surfaces, validation before commit, operator-visible diff and skip behavior, conflict and array semantics, uninstall provenance, docs, and install-route tests.

## Reproduction Assessment

Yes for the source-level gap: current main has no manifest `configPatch` field, install result carrier, or install persistence hook for manifest-declared config mutation. No runtime reproduction was needed because this is a missing contract proposal rather than a broken implemented path.

## Solution Assessment

Unclear as proposed. The ergonomic goal fits the plugin setup surface, but raw arbitrary deep-merge from manifests is not the best shape without an allowlisted, auditable config-intent contract.
