## Summary

Keep open. The requested install-time setup capability is still absent from the published manifest contract, but allowing third-party manifests to overwrite user configuration needs an explicit product and security decision rather than a narrow automatic fix.

## What This Changes

Add a plugin-manifest `configPatch` capability that applies plugin-declared OpenClaw configuration during installation.

## Best Possible Solution

Define an opt-in, allowlisted plugin config-intent contract that previews and validates changes, preserves user-owned settings, records provenance, and provides uninstall guidance instead of accepting arbitrary manifest JSON merges.
