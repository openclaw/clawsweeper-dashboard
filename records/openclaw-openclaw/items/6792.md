## Summary

Keep open: current main still has no general manifest-declared install-time configuration intent, and the requested automatic deep merge would let third-party package metadata overwrite operator-owned settings. ## What This Changes

Add a plugin-manifest contract that configures additional OpenClaw settings during plugin installation.

## Best Possible Solution

Define a generic, path-scoped setup-intent contract with complete-result validation, an exact operator-visible diff, explicit consent or a narrowly defined trusted mode, recorded provenance, and consistent install, update, and removal behavior.

Rationale: Implementation cannot safely proceed until maintainers decide which paths plugins may own, whether approval is mandatory, and how conflicts, arrays, upgrades, user overrides, and recovery behave.

Options:

- **Automatic manifest merge:** Apply manifest patches without confirmation and accept the broader package-trust, overwrite, and upgrade risks.
- **Separate setup flow:** Keep installation plugin-scoped and require explicit onboarding or configure flows for all additional configuration.
