## Summary

Keep open: current main and the latest release still lack a manifest-level install-time config intent contract, and the remaining work is a product/security decision about third-party plugin metadata mutating persisted user config.

## What This Changes

The issue requests a plugin manifest `configPatch` field that `openclaw plugins install` would apply automatically to user config during install.

## Best Possible Solution

Define a documented, auditable manifest config-intent contract with scoped permissions, validation before commit, operator-visible diff and skip behavior, conflict and array rules, install provenance, uninstall guidance, and coverage across every install route.
