## Summary

Keep open: current main and v2026.6.11 still lack a manifest-level install-time config intent contract, and the remaining work is a product/security decision about third-party plugin metadata mutating persisted user config.

## What This Changes

Request a manifest-declared install-time plugin config patch mechanism so `openclaw plugins install` can apply validated setup config without manual `openclaw.json` edits.

## Best Possible Solution

Define an auditable plugin install-time config intent contract that validates before commit, shows the exact diff with a skip path, records provenance for uninstall guidance, and covers all install routes with focused regression tests.

- **Defer to validation hook:** Wait for the broader config pre-apply hook before adding any plugin install-time mutation surface.
