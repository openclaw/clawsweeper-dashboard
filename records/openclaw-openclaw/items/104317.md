## Summary

The bounded streaming reader and request-lifetime abort appear to fix the unbounded Vault response read at the correct owner boundary, but this PR still needs exact-head real behavior proof and maintainer acceptance or calibration of the new hard 1 MiB compatibility boundary.

## What This Changes

This PR replaces two unbounded Vault success-response JSON reads with a streamed 1 MiB reader, keeps the five-second abort active through body consumption, and adds oversized and stalled-body regression fixtures.

## Best Possible Solution

Keep the streamed reader and request-lifetime abort, calibrate or explicitly accept a bounded response limit that covers the supported Vault payload envelope, add a near-limit compatibility case, and attach redacted exact-head terminal proof for both oversized and stalled responses.
