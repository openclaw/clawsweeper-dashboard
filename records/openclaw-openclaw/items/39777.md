## Summary

Keep open: current main still returns silently when the Debug Snapshots refresh is clicked while disconnected, and the Snapshots body has no inline loading or disconnected-state message. A linked fork PR carries the intended small UI fix, but it is dirty, targets the pre-refactor file path, and has not landed upstream.

## What This Changes

The issue requests visible loading feedback and disconnected-gateway feedback in the Control UI Debug Snapshots card.

## Best Possible Solution

Land an updated upstream fix that adds localized inline loading and disconnected states to the current Debug Snapshots card, with focused render coverage for both states.
