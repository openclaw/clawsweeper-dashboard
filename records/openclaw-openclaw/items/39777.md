## Summary

Keep open: current main and the latest release still return from the Debug Snapshots refresh when disconnected before surfacing any visible state, and the Snapshots card still lacks an inline loading or disconnected branch. A same-change fork PR is open but conflicting and not a clean target-repo landing path, while the prior target-repo PR was closed unmerged and superseded by this issue.

## What This Changes

The issue asks for the Control UI Debug Snapshots refresh to show inline progress and a disconnected explanation instead of a silent no-op.

## Best Possible Solution

Add localized inline loading and disconnected states to the Debug Snapshots card using the real gateway connection state, while preserving the current status/health/heartbeat layout and adding focused render coverage.
