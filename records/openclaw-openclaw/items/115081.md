## What This Changes

Bulk official-plugin updates should infer the installed beta core channel when `update.channel` is unset, instead of selecting stable packages.

## System Context

The plugins update CLI resolves package targets for installed plugins. In the bulk official-plugin path, that selection determines which npm package line is proposed and can either preserve or create core/plugin release-channel drift.
