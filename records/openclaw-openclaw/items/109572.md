## Summary

No blocking code defect is evident in the current head, and the narrow fix matches the documented mention-gating contract; keep this PR open because external bug-fix PRs still require after-fix real WhatsApp behavior proof before merge.

## What This Changes

The PR lets configured WhatsApp text mention patterns satisfy group mention gating when native mention metadata targets another participant, while retaining rejection for unmatched patterns and implicit numeric self fallback.

## Best Possible Solution

Keep configured mention regexes authoritative when a message also mentions another participant, preserve the safer block on implicit numeric fallback, and ship the focused tests after a live WhatsApp group run confirms dispatch and nonmatching rejection.
