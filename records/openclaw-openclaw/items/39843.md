## Summary

Keep open: current main still leaves Google Chat's real typing placeholder owned by the plugin outside the shared typing cleanup path, and the only active fix candidate is an open unmerged fork PR.

## What This Changes

The issue requests that Google Chat clear its visible typing placeholder when an agent reacts and then returns a silent `NO_REPLY`.

## Best Possible Solution

Wire the Google Chat plugin's `typingMessageName` into the shared reply lifecycle so silent or empty completion deletes the placeholder, while preserving the existing edit-into-first-reply path for normal replies.
