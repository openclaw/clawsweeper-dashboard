## What This Changes

The issue reports that Google Chat leaves its visible typing placeholder behind when an agent only reacts and returns NO_REPLY.

## Best Possible Solution

Land a current-main Google Chat fix that consumes or deletes the typing placeholder when a turn completes without delivery, while preserving normal first-reply edit behavior.

## Solution Assessment

Yes: the narrow owner-boundary fix is Google Chat-owned placeholder cleanup on no-delivery completion, either by porting the linked candidate or wiring the existing typing cleanup lifecycle.
