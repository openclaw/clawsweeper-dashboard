## What This Changes

The issue reports that `memory_search` waits for a full memory sync on a search miss, causing foreground tool-call timeouts instead of returning an empty result promptly.

## Best Possible Solution

Keep the canonical issue open and land one focused memory-core fix there that keeps QMD update work out of the interactive zero-hit `memory_search` deadline without adding a new config surface unless maintainers explicitly choose one.
