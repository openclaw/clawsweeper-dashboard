## What This Changes

This PR keeps connectivity absent for running channels that do not publish a transport signal, preventing the gateway health monitor from restarting them as if they had reported a disconnect.

## System Context

Channel plugins publish runtime account status, which the shared channel-status projection places into the gateway snapshot. The health monitor, command-line channel status, and web UI consume that snapshot, so an invented `connected: false` can cause both restart decisions and misleading status output.
