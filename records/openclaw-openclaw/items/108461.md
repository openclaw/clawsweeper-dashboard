## Summary

Keep this PR open because the linked outage is valid and current main still contains the failing guard, but the proposed completion test is not safe enough to merge and the claimed live verification is not inspectable.

## What This Changes

The PR changes the OpenAI Responses stream processor to clear lingering tool-call tracking at `response.completed` when the tracked block is present in accumulated output, with two regression tests.

## Best Possible Solution

Reconcile lingering state against completed function-call items from `event.response.output`, run each match through the existing identity, name, argument-snapshot, parsing, cleanup, and `toolcall_end` finalization rules, and retain the unresolved-call error for missing or ambiguous matches.
