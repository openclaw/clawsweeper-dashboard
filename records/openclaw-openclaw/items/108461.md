## What This Changes

The PR changes OpenAI Responses stream handling so a terminal completed-response snapshot can finalize an already-opened function call when its ordinary completion event is missing, while rejecting incomplete, conflicting, unmatched, malformed, and ambiguous snapshots.

## System Context

The OpenAI Responses transport converts provider SSE events into assistant content and tool-call lifecycle events consumed by the agent loop. Its terminal-event path must either finalize only trustworthy already-opened calls or preserve the existing fail-closed error for incomplete streams.
