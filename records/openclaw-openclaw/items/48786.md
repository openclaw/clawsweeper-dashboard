The issue requests resolving Feishu `@_user_N` placeholders in quoted/replied message context to readable mention markup or names.

## Best Possible Solution

## Solution Assessment

Yes. The best fix is a narrow Feishu-plugin parser repair in `extensions/feishu/src/send.ts` that reuses existing mention normalization through a correct SDK-shape adapter, not a broad cross-core branch or downstream display workaround.
