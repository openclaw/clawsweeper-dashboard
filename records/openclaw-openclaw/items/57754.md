## Summary

Keep open: current main and v2026.6.11 still limit Android chat selection to code blocks and have no message-level Copy, Select Copy, Share, or Reply action surface. Same-scope target-repo PR attempts are closed, while the open fork implementation at https://github.com/BingqingLyu/openclaw/pull/1851 is still conflicting and the final action scope needs maintainer choice.

## What This Changes

The issue requests Android chat message copy, selective text selection, sharing, and reply actions for ordinary chat messages.

## Best Possible Solution

Land a refreshed target-repo Android chat implementation that adds the approved message-level copy/select behavior across the current chat message paths, preserves scrolling and link tapping, and includes Android emulator or device proof; decide Share and Reply explicitly before implementation.
