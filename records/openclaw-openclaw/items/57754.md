## Summary

Keep open: current main and v2026.6.11 still render ordinary Android chat message text without a message-level long-press Copy/Select Copy/Share/Reply surface, while code blocks remain the only Markdown blocks wrapped for selection. Same-scope target-repo PR attempts are closed unmerged, and the only linked open fork PR is conflicting, so this issue remains the canonical tracker.

## What This Changes

Request Android chat support for copying whole messages, selecting partial message text, sharing message text, and quoting messages from chat bubbles.

## Best Possible Solution

Keep this issue open until maintainers approve the Android message action scope and land a refreshed target-repo implementation on the active chat renderers with focused coverage and real Android device or emulator proof.

## Reproduction Assessment

## Solution Assessment

Unclear. A message-level long-press action sheet is a plausible maintainable approach that avoids wrapping the whole LazyColumn, but maintainers still need to decide the Copy/Select Copy/Share/Reply scope and ensure link taps and scrolling remain intact.
