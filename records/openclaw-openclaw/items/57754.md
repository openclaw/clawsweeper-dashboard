## Summary

Keep open: current main and v2026.6.11 still do not provide Android chat message-level Copy, Select Copy, Share, or Reply actions for ordinary message text, and the only open linked implementation candidate is a conflicting fork PR that still needs maintainer scope review.

## What This Changes

The issue asks for Android chat bubbles to support copying whole messages, selecting partial text, sharing message text, and quoting a message into the composer.

## Best Possible Solution

Land a refreshed Android message action-menu implementation after maintainers approve the action scope, with Copy and Select Copy as the core behavior, focused UI/unit coverage, and Android device or emulator proof that scrolling and link tapping still work.
