## Summary

Keep open: current main and v2026.6.11 still make only code blocks selectable in Android chat and expose no message-level long-press Copy/Select Copy/Share/Reply surface, while the open fork PR that claims to close this is conflicting and not a landed target-repo fix.

## What This Changes

The issue requests Android chat message long-press copy, selective copy, share, and reply actions so normal message text can be reused from a phone.

## Best Possible Solution

Approve a focused Android message action scope, then land a refreshed target-repo implementation across the active chat paths with device or emulator proof that copy/selection works without breaking scroll or link tapping.
