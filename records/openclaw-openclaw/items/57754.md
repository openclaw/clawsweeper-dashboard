## Summary

Keep open: current main and v2026.6.11 still do not provide Android chat bubble copy, text selection, share, or reply actions for normal message text. The merged URL-link work is adjacent and explicitly left copy/text selection out of scope, while same-scope OpenClaw PR attempts are closed unmerged and the open fork PR remains only a candidate path.

## What This Changes

The issue requests Android chat message copy, selective text copy, share, and reply actions from normal chat message bubbles.

## Best Possible Solution

Land a maintainer-approved Android message action surface, at least Copy and Select Copy, across the active chat renderers while preserving LazyColumn scroll and link tapping, with emulator or device proof.
