## Summary

Keep open: current main and v2026.6.11 still only wrap Android chat code blocks in `SelectionContainer` and expose no message-bubble copy, select-copy, share, or reply actions. ## What This Changes

Request to add Android chat message long-press actions for copy, selective copy, share, and reply so normal message text can be reused from the phone.

## Best Possible Solution
