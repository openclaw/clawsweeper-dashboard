## Summary

Keep open: current main and v2026.6.11 still only make Android code blocks selectable, while ordinary chat message text has no long-press Copy/Select Copy/Share/Reply action surface. The remaining work is real, but the exact Android action scope needs maintainer product direction before a new automated fix lane.

## What This Changes

Add Android chat message copy, selective text copy, share, and reply actions for normal message bubbles.

## Best Possible Solution

Land a refreshed target-repo Android change that adds the approved message-level copy/select behavior across both ChatScreen and ChatMessageListCard/ChatMessageViews while preserving scroll and link handling; include Share/Reply only if maintainers approve that product scope and proof.
