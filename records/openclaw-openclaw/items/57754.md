## Summary

Keep open: current main and v2026.6.11 still lack message-level copy, selective copy, share, or reply actions for Android chat bubbles; the same-scope target-repo PRs are closed unmerged, and the only linked open implementation is a conflicting fork PR that still needs maintainer product review.

## What This Changes

Requested Android chat UX support for copying whole messages, selecting message text, sharing message text, and quoting a message from the chat screen.

## Best Possible Solution

Land a refreshed target-repo Android implementation that adds an approved message long-press action surface to the active ChatScreen and alternate sheet path, keeps Copy and Select Copy as the core scope, and proves the behavior on Android without breaking scrolling or tappable links.

- **Defer Android Message Actions:** Keep the current code-block-only selection behavior until maintainers choose a broader Android chat interaction model.

## Reproduction Assessment

Yes from source inspection: current Android chat bubbles render normal message text without a selectable container or long-press action surface, while ChatMarkdown only wraps fenced and indented code blocks in SelectionContainer. I did not run a live device smoke in this read-only review.

## Solution Assessment

Unclear until maintainers choose the product scope. A message-level long-press action sheet is a plausible maintainable solution that avoids wrapping the full LazyColumn, but the full Copy/Select Copy/Share/Reply set needs a maintainer decision.
