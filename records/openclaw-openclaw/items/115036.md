## Summary

Keep this PR open for human security review. The patch is a focused hardening of the SSH sandbox boundary, but it still has no after-fix real behavior proof, and the `maintainer` label prevents automated cleanup or closure.

## What This Changes

The branch rejects control, whitespace, option-like, and newline-bearing SSH sandbox target or generated-config values before OpenClaw starts an SSH tunnel or writes an SSH config file.

## System Context

OpenClaw accepts operator-provided SSH sandbox settings, parses the target into connection fields, then writes a temporary SSH config and invokes the local SSH client to start a remote agent sandbox. This PR changes validation at both the parsed target boundary and the generated-config boundary before those values reach SSH.
