## Summary

Keep open. Current main still has the cron description data path, edit form, and prompt/system/command detail rendering, but the Control UI job detail renderer does not display `job.description`; the linked implementation PR is open and not merged, so this issue should remain open until that candidate or an equivalent fix lands.

## What This Changes

The issue requests showing a cron job's prompt/task and human-readable summary in the Web UI cron dashboard so users do not need to inspect configuration files.

## Best Possible Solution

Review, refresh, and land https://github.com/openclaw/openclaw/pull/86674 or an equivalent narrow Control UI change that renders non-empty `job.description` as a localized summary for all current cron payload detail branches without changing cron storage or run-history behavior.

## Reproduction Assessment

Yes. Source inspection on current main shows cron descriptions are stored and edited, while the visible job detail renderer covers payload details but never reads `job.description`.

## Solution Assessment

Yes, the best solution is a narrow Control UI presentation fix over the existing cron data model; the linked PR is the right ownership boundary but needs review/refresh before it can close the issue.
