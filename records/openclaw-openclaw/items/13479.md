## Summary

Keep open: current main and the latest release still do not render the saved cron job description in the Control UI job details, and the linked open PR is the implementation candidate rather than a reason to close this issue early.

## What This Changes

The issue requests showing each cron job's prompt/task and human-readable description in the Control UI cron dashboard so users do not need to inspect configuration files.

## Best Possible Solution

Review, refresh, and land https://github.com/openclaw/openclaw/pull/86674 or a narrow replacement so the existing cron description field renders in the Control UI across current payload detail branches.

## Reproduction Assessment

Yes. Source inspection on current main shows cron jobs can carry and edit descriptions, but the visible job detail renderer never reads job.description.

## Solution Assessment

Yes as a direction, but it is not complete on main yet. Rendering the existing cron description field in the Control UI is the narrow owner-boundary fix, with localized copy and coverage for current payload branches.
