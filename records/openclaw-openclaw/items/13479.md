## Summary

Keep open: current main and the latest release still do not render the stored cron job description as a visible Web UI summary, and https://github.com/openclaw/openclaw/pull/86674 is the open unmerged implementation candidate.

## What This Changes

The issue requests that the Web UI cron dashboard expose each cron job's prompt/task and saved human-readable summary so users do not need to inspect configuration files.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/86674, or an equivalent narrow Control UI change, so non-empty job.description renders as a safe localized Summary detail for current cron payload branches without changing cron storage or run-history behavior.

## Reproduction Assessment

Yes. Source inspection on current main shows cron descriptions can be stored and edited, while renderJobPayload never reads job.description for the visible job detail; I did not run UI tests because this review is read-only.

## Solution Assessment

Yes as a direction. Rendering the existing cron description field in the Control UI is the narrow owner-boundary fix, but the open implementation should cover current payload branches and localized copy before the issue closes.
