## Summary

Current main still does not render the saved cron job description as the requested human-readable Summary in the Control UI, and the linked implementation PR is open rather than merged. The issue should stay open until that PR lands or is replaced.

## What This Changes

The issue asks for the Control UI cron dashboard to show each cron job's prompt/task and human-readable summary without requiring users to inspect config files.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/86674 so every current cron payload detail branch renders a non-empty saved description as a localized Summary while leaving cron storage, RPCs, scheduling, and run-history selection unchanged.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: create or edit a cron job with a non-empty description, then view it in the Control UI cron list; current main carries the description but renderJobPayload does not display it.

## Solution Assessment

Yes as a direction. Rendering the existing cron description field in the Control UI is the narrow owner-boundary fix, but the linked PR or replacement should cover systemEvent, command, and agent-turn detail branches and use the Control UI i18n source.
