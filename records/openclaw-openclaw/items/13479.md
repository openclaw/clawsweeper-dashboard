## Summary

Keep open: current main still stores and edits cron descriptions, but the Control UI cron detail renderer does not display `job.description`; the linked implementation candidate at https://github.com/openclaw/openclaw/pull/86674 is still open and unmerged.

## What This Changes

The issue requests showing each cron job's prompt/task and saved human-readable description in the Web UI cron dashboard.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/86674 so `job.description` renders as a localized Summary detail for systemEvent, command, and agent-turn cron jobs without changing cron storage, quick-create, or run-history behavior.
