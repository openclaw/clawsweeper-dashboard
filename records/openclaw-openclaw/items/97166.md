## What This Changes

This PR maps `.vcf` files to `text/vcard`, permits that MIME type on the host-read document path, and requires full-buffer text validation before a sniffed text document is accepted.

## System Context

The agent’s local-media path takes a user-provided file reference from `MEDIA:` or `message(media=...)`, determines its MIME type, and applies the host-read policy before producing a document attachment for channel delivery. This PR changes the policy and MIME mapping for vCard contact files while keeping binary-tailed content outside that boundary.
