## Summary

Keep this PR open for an explicit host-read security-boundary decision. Current main still rejects `text/vcard`, while the patch adds a narrow full-buffer validation guard for sniffed text documents; the mechanics look sound, but allowing a new local-file MIME by default is an owner policy choice. ## What This Changes

The PR recognizes `.vcf` files as `text/vcard`, allows validated vCard documents through host-read media loading, and rejects vCard-prefixed binary payloads.

## System Context

The host-read media loader serves agent `MEDIA:` and `message(media=...)` requests by reading a local file, detecting its MIME type, and enforcing a document/media boundary before a channel receives it. This change expands one allowed document MIME while adding full-buffer validation for sniffed text documents.
