Full review comments:

- **[P1] Honor read-denied media policies before returning configured roots:** `src/media/read-capability.ts:202`
  - body: When `hostMediaReadAllowed` is false, this fallback still returns `getAgentScopedMediaLocalRoots(...)`. With `tools.fs.roots` configured, that exposes those host roots as plain `localRoots` while `readFile` is undefined, so `loadWebMedia` can pass `assertLocalMediaAllowed` and read the file directly despite a sender/group `read` denial. Return only strict generated/base roots, or no configured roots, when read is denied.
  - confidence: 0.94
- **[P1] Do not append the workspace after an explicit roots policy:** `src/media/read-capability.ts:203`
  - body: `appendWorkspaceDirToLocalRoots` turns an explicit empty root list into `[workspaceDir]` and also widens non-empty configured roots with the workspace. That breaks the PR's advertised deny-all and explicit-allowlist semantics for agent-scoped media sends. Preserve explicit `tools.fs.roots` exactly, including `[]`, unless a separate sandbox/generated-media path is intentionally selected.
  - confidence: 0.93
