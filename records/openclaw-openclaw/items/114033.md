## Summary

Keep this PR open for maintainer review. The migration and fail-closed direction are backed by focused coverage and a packaged upgrade-survivor run, but the public Plugin SDK path-taking storage APIs deliberately change their persistence semantics and need an explicit maintainer compatibility decision before merge.

## What This Changes

This PR makes per-agent SQLite the sole steady-state auth-profile store, migrates four retired credential-file sources through `openclaw doctor --fix`, and deprecates path-based session auth storage adapters.

## System Context

OpenClaw resolves model credentials and routing state per agent before starting sessions, providers, and gateway requests. This change moves retired JSON credential inputs through Doctor migration into the per-agent SQLite database, then makes runtime and SDK session storage consume only that canonical database.

## Best Possible Solution

Retain SQLite as the sole runtime store, but obtain explicit maintainer approval for the deprecated path-based SDK contract and document or mechanically constrain its handling of nonstandard plugin paths before merge.

- **Narrow the supported deprecated API:** Reject arbitrary-path compatibility and require an explicit maintainer-approved breaking-change boundary before published plugins must move to `forAgent(agentDir)`.
