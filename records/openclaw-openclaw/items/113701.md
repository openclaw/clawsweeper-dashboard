## What This Changes

Prevent sessions from repeatedly failing or resetting when several individually moderate tool results collectively exceed the model context budget.

## System Context

OpenClaw’s embedded agent runner collects tool results into a session transcript, assembles that transcript for the next model request, and invokes context guards or compaction when the request approaches a model limit. The resulting recovery outcome affects whether the existing session continues, becomes blocked, or requires the user to start over.

## Best Possible Solution

Add or verify one canonical aggregate context-budget guard that invokes bounded tool-result elision and session-preserving recovery before a model request is sent, then cover the multi-medium-result scenario with focused regression proof.
