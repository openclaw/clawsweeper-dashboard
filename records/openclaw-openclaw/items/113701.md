## What This Changes

The issue requests that aggregate medium-sized tool results be detected and recovered before they overflow a model context window and leave a session blocked or reset.

## System Context

OpenClaw adds tool results to an agent session transcript and assembles that transcript into each provider request. Context guards, compaction, and overflow recovery must keep the assembled prompt within the model budget while preserving recoverable session state.
