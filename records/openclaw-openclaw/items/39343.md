## Summary

Keep open: current main covers Telegram albums, but LINE still handles each media webhook as a separate agent turn, so the remaining media-batching request needs maintainer product and config direction.

## What This Changes

The issue requests optional inbound media batching so rapid multi-image or media-plus-text channel messages can reach the agent as one coherent turn.

## Best Possible Solution

Implement only after maintainer approval as a LINE-plugin-owned, opt-in media buffer scoped by account, conversation, and sender; leave Telegram mediaGroupFlushMs and shared text-only debounce unchanged.
