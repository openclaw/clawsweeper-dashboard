## Summary

Keep open. Current main implements the Telegram album half and generic text-only inbound debounce, but the requested LINE-style same-sender media batching remains missing and needs maintainer product/config direction before a safe implementation can proceed.

## What This Changes

Request to add optional media batching for rapid image/media messages, using Telegram media_group_id where available and same-sender time-window batching for LINE-like channels.

## Best Possible Solution

Choose a plugin-owned, opt-in LINE media batching contract that buffers downloadable media by account, conversation, and sender while leaving Telegram mediaGroupFlushMs and generic text debounce unchanged.
