## Summary

Keep open: current main and v2026.6.11 implement the Telegram album buffer/config part, but LINE media webhook events still dispatch one event per turn and no LINE batching config exists, so the remaining request needs maintainer product/config direction.

## What This Changes

The issue requests gateway-layer media batching for rapid image/media updates, including Telegram album grouping and LINE-style sender/chat/time buffering.

## Best Possible Solution

Keep the Telegram album implementation, and if maintainers choose to proceed, add opt-in LINE plugin media batching by account/conversation/sender with documented timer and flush behavior plus focused tests.
