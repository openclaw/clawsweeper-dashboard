## Summary

Keep open: current main handles the Telegram album half, but LINE still dispatches each downloadable media webhook as its own agent turn, so the remaining behavior needs maintainer product/config direction.

## What This Changes

The issue requests gateway-layer media batching so rapid image/media messages from one user are buffered and sent to the agent as one turn, with Telegram using media_group_id and LINE using sender/chat/time proximity.

## Best Possible Solution

Keep the current Telegram album implementation, then approve an opt-in media-aware batching contract, preferably plugin-owned for LINE/WhatsApp-style channels unless maintainers choose a shared SDK seam.
