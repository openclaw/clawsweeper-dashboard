Keep open. Current main covers Telegram album buffering and text-only inbound debounce, but the remaining LINE-style same-sender media batching is still missing and needs maintainer product/config direction before implementation.

## What This Changes

Requested gateway-layer buffering for rapid image/media bursts so related media messages can reach the agent as one turn.

## Best Possible Solution

Choose a plugin-owned, opt-in LINE media batching design that buffers downloadable media by account, conversation, and sender while preserving Telegram mediaGroupFlushMs and text-only debounce behavior.
