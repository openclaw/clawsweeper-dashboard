## Summary

Keep open: current main and the latest release cover Telegram album buffering and its config key, but the broader media-aware batching request remains unresolved because shared inbound debounce is still text-only and LINE media events still dispatch one turn per webhook event.

## What This Changes

Request to add optional media-aware batching so rapid image/media messages from the same sender flush as one agent turn, using Telegram media group ids when available and proximity heuristics for channels like LINE.

## Best Possible Solution

Keep the current Telegram album implementation, then approve an opt-in media-aware batching contract, preferably plugin-owned for LINE and similar channels unless maintainers choose a shared SDK/gateway seam.
