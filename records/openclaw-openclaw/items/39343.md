## Summary

Keep open. Current main implements the Telegram album path and fixed text-only inbound debounce, but LINE-style same-sender media batching remains absent and still needs maintainer product/config direction before implementation.

## What This Changes

The issue requests gateway-layer batching for rapid image/media messages so albums or same-user media bursts reach the agent as one turn instead of separate responses.

## Best Possible Solution

Implement an opt-in LINE plugin media buffer keyed by account, conversation, and sender, with clear timer/text flush semantics, while leaving Telegram mediaGroupFlushMs and text-only inbound debounce unchanged.
