## Summary

Keep open. Telegram album buffering is implemented, but current main and the latest release still leave the LINE heuristic media-batching half unresolved, and choosing that behavior adds a new channel/config surface that needs maintainer product direction.

## What This Changes

The issue requests optional media batching so rapid image/media updates can be flushed as one agent turn, especially for Telegram albums and LINE image bursts.

## Best Possible Solution

Keep the existing Telegram `mediaGroupFlushMs` behavior, and if maintainers accept LINE batching, implement it inside the LINE plugin as an opt-in same-account/conversation/sender media buffer rather than a gateway-global batcher.
