## Summary

Keep open: current main and v2026.6.11 cover Telegram album buffering, but LINE/no-metadata media batching remains absent and needs maintainer product/config direction.

## What This Changes

The issue requests a media batching buffer that groups rapid image/media messages from the same user/chat into one agent turn, using Telegram album metadata where available and heuristics for platforms like LINE.

## Best Possible Solution

Keep Telegram's native album path, then make a maintainer-approved, opt-in LINE/no-metadata batching design with explicit keys, flush rules, latency defaults, docs, and tests.
