## Summary

Keep open. Current main implements the Telegram album half, but the remaining LINE/media-burst behavior is still absent and the requested buffering/config behavior needs maintainer product direction before an automated fix lane should change channel timing semantics.

## What This Changes

Request an optional media batching buffer so rapid same-chat media messages, especially Telegram albums and LINE image bursts, are delivered to the agent as one turn instead of separate turns.

## Best Possible Solution

Keep this as a channel-plugin product/design item: preserve the current Telegram media-group path, decide the LINE opt-in media buffer contract, and only use shared gateway/plugin SDK changes if maintainers want a reusable media-batching seam.
