## Summary

Keep open. Current main and the latest release already cover the Telegram album half with `mediaGroupFlushMs`, but LINE still handles each downloadable media webhook event as an immediate separate turn and the remaining heuristic batching behavior needs maintainer product/config direction.

## What This Changes

The issue requests optional buffering so rapid multi-image/media messages are delivered to the agent as one turn, using Telegram media-group IDs where available and same-sender timing heuristics for LINE.

## Best Possible Solution

Choose the product boundary first, then implement any accepted remaining behavior inside the LINE plugin as an opt-in same-sender media batcher; keep Telegram's current media-group path and avoid a gateway-global batcher unless maintainers approve a shared SDK contract.
