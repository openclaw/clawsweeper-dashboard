Keep open. Current main covers Telegram albums and text-only inbound debounce, but LINE still dispatches each media webhook as its own agent turn, so the remaining media-batching behavior needs maintainer product/config direction.

Implement only after maintainer approval as a LINE-plugin-owned, opt-in media buffer scoped by account, conversation, and sender, while leaving Telegram mediaGroupFlushMs and shared text-only debounce unchanged.
