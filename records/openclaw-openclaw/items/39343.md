## Label Justifications

- `P2`: The issue describes fragmented media turns and reply spam in messaging channels, with limited channel-specific blast radius rather than an outage.
- `impact:session-state`: The requested batching affects whether several related media updates become one coherent agent turn or separate session events.
- `impact:ux-friction`: Users can still send images, but rapid album-style sends can produce fragmented replies and require awkward workarounds.

## Summary

Keep open. Current main already covers the Telegram album half with `mediaGroupFlushMs`, but the broader request is still not fully implemented: LINE still handles each downloadable media webhook event as its own agent turn, and the shared inbound debounce contract explicitly excludes media.

## What This Changes

Request to batch rapid image/media messages into one agent turn, using Telegram media group IDs when available and same-sender timing heuristics for channels like LINE.

## Best Possible Solution

Choose a plugin-owned media batching direction for channels without native album IDs, likely starting with LINE as an opt-in config while keeping Telegram’s existing media-group path and WhatsApp’s narrower work in its own canonical issue.
