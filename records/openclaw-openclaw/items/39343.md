## Summary

Keep open: current main and the latest release cover Telegram albums, but the broader media-aware batching request remains missing for LINE-style independent media events and still needs maintainer product/API direction.

## What This Changes

The issue requests gateway-level or channel-level buffering for rapid media batches so multiple images can reach one agent turn instead of triggering separate replies.

## Best Possible Solution

Keep the current Telegram album implementation, then approve an opt-in media-aware batching contract, preferably plugin-owned for LINE/WhatsApp-style channels unless maintainers choose a shared SDK or gateway seam.
