- `impact:session-state`: Rapid related media can be delivered as separate agent turns, fragmenting one user intent across model-visible session context.

## Summary

Keep open: current main covers Telegram albums and shared text-only debounce, but LINE still processes each downloadable media webhook as its own agent turn with no batching config, so the remaining behavior needs maintainer product/config direction.

## What This Changes

The issue requests a media batching buffer for rapid images/media so related channel updates reach the agent as one combined turn.

## Best Possible Solution

Implement only after maintainer approval as a LINE-plugin-owned, opt-in media buffer scoped by account, conversation, and sender; leave Telegram mediaGroupFlushMs and shared text-only debounce unchanged.

- **Keep unsupported:** Keep native Telegram album buffering only and document that channels without grouping metadata dispatch media events individually.
