## Summary

Keep open: current main covers Telegram album grouping and configuration, but LINE-style independent media bursts still dispatch as separate turns and the remaining work needs maintainer product/API direction.

## What This Changes

Request optional media-aware batching so rapid images or albums from the same chat and sender reach the agent as one combined turn.

## Best Possible Solution

Keep the Telegram album implementation and approve an opt-in media-aware batching contract, preferably plugin-owned for LINE/WhatsApp-style channels unless maintainers choose a shared SDK seam.
