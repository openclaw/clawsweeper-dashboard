## Summary

Keep open: current main and v2026.6.11 cover Telegram album grouping and its config knob, but LINE-style independent media batching remains missing and still needs product/API direction before implementation.

## What This Changes

Request to add an optional media batching buffer so rapid same-sender images or media are grouped into one agent turn, using Telegram media_group_id where available and proximity heuristics for channels like LINE.

## Best Possible Solution

Keep existing Telegram album support, then choose an opt-in plugin-owned media batching contract for channels without grouping metadata unless maintainers explicitly approve a shared SDK or gateway seam.

- **Defer broad batching:** Leave current text debounce and Telegram album behavior as supported, and address only narrower channel bugs such as WhatsApp steer media loss.

## Reproduction Assessment

Yes, source-level. Current main excludes media-bearing messages from shared inbound debounce, and LINE downloads/processes each media event as its own turn; no live LINE webhook run was performed in this read-only review.

## Solution Assessment

Unclear until the product boundary is chosen. Telegram's plugin-owned album buffer is correct for that channel; LINE/WhatsApp-style proximity batching should either stay plugin-owned or be introduced through a narrow SDK seam, not an ad hoc gateway-wide buffer.
