## Summary

Keep open: Telegram album buffering is implemented, but current main and v2026.6.11 still process LINE downloadable media one webhook event at a time, and adding heuristic LINE batching/config needs maintainer product direction.

## What This Changes

Request optional media batching so rapid image sends from Telegram albums and LINE-style channels can reach the agent as one turn instead of separate replies.

## Best Possible Solution

Keep the existing Telegram album implementation, then approve a plugin-owned opt-in media batching contract for LINE-style channels with clear scope, latency, flush, and docs behavior.
