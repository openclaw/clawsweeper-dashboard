Keep open. Current main covers Telegram albums and text-only inbound debounce, but LINE-style same-sender media batching remains missing and needs maintainer product/config direction before a safe implementation.

## What This Changes

The issue requests optional gateway/channel media batching so rapid image or media messages can be delivered to the agent as one combined turn.

## Best Possible Solution

Choose an opt-in, plugin-owned media batching contract for channels without native album ids, starting with LINE and scoped by account, conversation, and sender.
