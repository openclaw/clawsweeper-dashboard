## Summary

Keep open: current main has solved the Telegram media-group/config parts, but the remaining LINE-style no-grouping media burst behavior is still missing and needs a maintainer product/config decision before a repair lane should run.

## What This Changes

The issue requests buffering rapid image/media messages so related uploads are delivered to the agent as one turn rather than separate replies or agent-layer heuristics.

## Best Possible Solution

Keep this issue as the canonical broad media batching tracker, but implement any remaining behavior as a channel-owned LINE feature with explicit defaults/config after maintainer approval, while preserving Telegram mediaGroupFlushMs and tracking WhatsApp through its narrower issue.
