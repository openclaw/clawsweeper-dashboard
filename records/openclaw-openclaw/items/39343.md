## Summary

Keep open. Current main covers fixed text debounce and Telegram album buffering, but the requested LINE-style same-sender media batching remains missing and needs maintainer product/API direction.

## What This Changes

Request gateway or channel-level buffering so rapid image/media messages, including Telegram albums and LINE image bursts, reach the agent as one turn.

## Best Possible Solution

Choose a plugin-owned, opt-in media batching contract for LINE and affected channels before considering any broad gateway default.
