## Summary

Keep open. Telegram albums and shared text-only debounce are covered, but current main and v2026.6.11 still handle LINE media one webhook event at a time with no same-sender media batching config, so the remaining behavior needs maintainer product direction.

## What This Changes

Request optional media batching so rapid Telegram/LINE image messages can be buffered into one agent turn instead of separate turns.

## Best Possible Solution

Have maintainers approve a LINE-plugin-owned, opt-in media buffer scoped by account, conversation, and sender, while leaving Telegram mediaGroupFlushMs and shared text-only debounce unchanged.
