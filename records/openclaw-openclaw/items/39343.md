Keep open. Current main has the Telegram album/config part, but the LINE side still handles each downloadable media webhook event as its own agent turn, and the remaining delayed-batching behavior needs a maintainer product/config decision before an implementation lane should choose semantics.

## What This Changes

Request to add optional media batching so rapid LINE images and Telegram albums are aggregated into one agent turn instead of separate replies.

## Best Possible Solution

Choose the product boundary first, then implement any accepted remaining behavior as opt-in LINE plugin media batching; avoid a gateway-global batcher unless maintainers approve a shared channel SDK contract.
