## Summary

Keep open. Current main and the latest release cover the Telegram album/config half, but LINE still handles downloadable media one webhook event at a time with no batching or config surface, so the remaining request is still necessary and needs maintainer product direction before implementation.

## What This Changes

The issue requests an optional gateway/channel media batching buffer so rapid multi-image sends are delivered to the agent as one turn instead of separate image-only turns.

## Best Possible Solution

Approve a plugin-owned, opt-in LINE media batching design keyed by account, conversation, and sender, while keeping Telegram mediaGroupFlushMs and the separate WhatsApp steer-media issue independent.
