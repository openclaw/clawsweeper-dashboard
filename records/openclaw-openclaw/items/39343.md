## Summary

Keep open. Current main and the latest release already cover Telegram albums with `mediaGroupFlushMs`, but LINE still handles each media webhook event as an immediate separate turn with no same-sender media buffer or LINE config surface, so the remaining behavior needs maintainer product/config direction.

## What This Changes

Requested optional gateway-layer media buffering so rapid LINE images or Telegram albums can be delivered to the agent as one combined turn.

## Best Possible Solution

Choose the product boundary first, then implement any accepted remaining behavior inside the LINE plugin as opt-in media batching; keep Telegram's existing `mediaGroupFlushMs` path and avoid a gateway-global batcher unless maintainers approve a shared SDK contract.
