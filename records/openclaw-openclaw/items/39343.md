## Summary

Keep open. Current main covers Telegram albums and text-only inbound debounce, but the LINE-style same-sender media batching requested here is still missing and needs maintainer product/config direction before implementation.

## What This Changes

The issue requests optional media batching so rapid media messages from the same sender/chat flush into one agent turn, using Telegram media groups when available and sender/chat/time heuristics for channels such as LINE.

## Best Possible Solution

Choose a plugin-owned, opt-in LINE media batching contract that buffers downloadable media by account, conversation, and sender while leaving Telegram mediaGroupFlushMs and generic text-only debounce unchanged.
