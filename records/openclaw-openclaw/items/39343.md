## Summary

Keep open. Current main covers the Telegram album half with media-group buffering, but the LINE-style same-sender media batching remains missing and needs maintainer product/config direction before automation should choose delay, keying, flush, and default behavior.

## What This Changes

The issue requests gateway-layer buffering that batches rapid media messages into one agent turn, using Telegram media group IDs and LINE sender/chat/time proximity heuristics.

## Best Possible Solution

Choose a plugin-owned opt-in LINE batching contract first, then buffer same-account, same-conversation, same-sender downloadable media inside the LINE plugin while leaving Telegram mediaGroupFlushMs and shared text debounce unchanged.

- **Keep unsupported:** Keep native Telegram album buffering only and document that channels without grouping metadata dispatch media events individually.
