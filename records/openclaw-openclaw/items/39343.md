## Summary

Keep open: prior ClawSweeper review identified the remaining LINE media-batching gap, and current main still processes each LINE media webhook event as its own agent turn while Telegram album buffering is already implemented.

## What This Changes

Request to batch rapid image/media messages from the same chat/user into one agent turn, using Telegram album metadata when available and a proximity buffer for LINE-style independent media events.

## Best Possible Solution

Keep this as the canonical media-batching design item, but implement any near-term fix inside the owning channel/plugin boundary, with an explicit opt-in delay and tests proving same-sender media grouping, text-triggered flush, reply-token fallback, and no cross-user coalescing.
