## Summary

Keep open. Current main covers Telegram albums and text-only inbound debounce, but LINE still handles each downloadable media webhook as its own agent turn and has no media batching config/docs surface, so the remaining behavior needs maintainer product/config direction.

## What This Changes

Request to add optional media batching for rapid image/media messages, especially Telegram albums and LINE independent image events, before dispatching one agent turn.

## Best Possible Solution

Implement only after maintainer approval as a LINE-plugin-owned, opt-in media buffer scoped by account, conversation, and sender, while leaving Telegram mediaGroupFlushMs and shared text-only debounce unchanged.
