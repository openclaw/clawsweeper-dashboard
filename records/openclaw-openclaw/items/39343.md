## Summary

Keep open: current main has Telegram album buffering and its config knob, but the broader media-aware batching request remains unresolved because shared inbound debounce still excludes media and LINE still dispatches each downloadable media event as its own turn.

## What This Changes

The issue requests an optional media batching buffer that coalesces rapid image/media messages into one agent turn, using Telegram media-group metadata when available and sender/chat/time proximity for channels like LINE.

## Best Possible Solution

Approve an opt-in media-aware batching contract, preferably plugin-owned for LINE/WhatsApp-style channels unless maintainers choose a shared SDK seam, while preserving the current Telegram album buffer and text-only debounce behavior.
