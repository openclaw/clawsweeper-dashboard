## What This Changes

The PR makes OpenAI Codex device-code polling retry selected transient network errors and HTTP 408, 429, and 5xx responses until the existing authorization deadline expires.

## System Context

OpenClaw’s bundled OpenAI plugin runs an interactive device-code login flow: it requests a browser code, polls the authorization endpoint, then exchanges the authorization result for tokens. This PR changes only the polling stage, affecting whether temporary network or service failures end the user’s active login session.
