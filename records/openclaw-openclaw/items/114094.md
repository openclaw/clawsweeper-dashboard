## What This Changes

The branch makes OpenAI device-code polling wait and retry when the plugin SDK classifies a caught request error as a transient network failure, while retaining immediate failures for cancellation and non-transient errors.

## System Context

The bundled OpenAI plugin performs device-code login by requesting a browser code, polling the authorization endpoint, and exchanging the returned authorization code for tokens. This PR changes the polling stage, determining whether a temporary transport interruption ends or preserves the user's active authorization session.

## Architecture Diagram

## Best Possible Solution

Keep the retry policy local to the OpenAI polling wrapper, retain fail-fast cancellation and terminal authorization handling, and add redacted runtime evidence that one classified transport failure recovers within the original device-code session before merging.
