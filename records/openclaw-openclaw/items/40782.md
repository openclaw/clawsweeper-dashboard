  - confidence: 0.84
- **[P2] Strip fallback-matched mentions before command parsing:** `extensions/feishu/src/bot.ts:797`
  - body: `parseFeishuMessageEvent` can mark the bot mentioned via `botUnionId`, but content normalization still strips only by `botOpenId`. A multi-bot `@Bot /help` matched by union_id can keep the raw mention before `/help`, undermining the slash-command behavior this parser comment protects.
  - confidence: 0.87
- **[P2] Carry fallback identity through debounce mention merging:** `extensions/feishu/src/monitor.account.ts:251`
  - body: This added `botUnionId` only to the final dispatch call, while debounced text and merged mention selection still use open_id-only parsing/filtering. A burst where the target mention is only in an earlier event can still flush as an unmentioned message and be dropped.
