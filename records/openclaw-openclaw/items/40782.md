Full review comments:

- **[P1] Prove the bot union_id source before relying on it:** `extensions/feishu/src/probe.ts:137`
  - body: At the PR head, the local bot info response type only models `bot_name` and `open_id`, while the canonical issue and closed sibling say `bot/v3/info` does not return `union_id`. Reading `bot?.union_id` here likely leaves the new fallback empty, so the multi-bot mention loss remains.
  - confidence: 0.93
- **[P2] Cover post mentions with the fallback identity:** `extensions/feishu/src/bot.ts:479`
  - body: The new fallback only participates in the `message.mentions` branch. Rich-text `post` mentions still compare parsed IDs to `botOpenId`, so the same app-scoped mismatch can still make a post @mention look unmentioned.
  - confidence: 0.84
- **[P2] Strip fallback-matched mentions before command parsing:** `extensions/feishu/src/bot.ts:797`
  - body: This can set `mentionedBot` through `botUnionId`, but content normalization still strips only by `botOpenId`. A multi-bot `@Bot /help` matched by fallback identity can keep the raw mention before `/help`, undermining the slash-command behavior this parser comment protects.
  - confidence: 0.87
- **[P2] Carry fallback identity through debounce batching:** `extensions/feishu/src/monitor.account.ts:251`
  - body: Adding `botUnionId` to the final handler is not enough because debounce text parsing and merged mention filtering remain `botOpenId`-only. A burst where the target mention is only in an earlier event can still produce a merged dispatch that fails the requireMention gate.
  - confidence: 0.81
- **[P2] Use fallback identity for mention-forward detection:** `extensions/feishu/src/bot.ts:820-821`
  - body: Late catch on code unchanged since the prior reviewed head: the parser can mark the bot mentioned via `botUnionId`, but `isMentionForwardRequest` and `extractMentionTargets` still receive only `botOpenId`. A fallback-matched `@Bot @User` message can therefore dispatch without populating the forward targets.
  - late: true
  - confidence: 0.77
