  - confidence: 0.82

  - confidence: 0.86
- **[P2] Carry fallback identity through debounced batches:** `extensions/feishu/src/monitor.account.ts:251`
  - body: The final handler receives `botUnionId`, but the debounced batch path still derives merged text and bot mentions from open_id-only parsing. A burst where the target mention is only in an earlier event can still merge into a message that fails the requireMention gate.
  - confidence: 0.8
