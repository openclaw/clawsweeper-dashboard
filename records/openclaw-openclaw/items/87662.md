## Summary

Keep open. Current main and v2026.6.11 still provide picker/sidebar session switching plus the command palette, but not guarded positional or cyclic Control UI session/agent switching shortcuts; the remaining question is a maintainer UX/product contract, not a stale cleanup close.

## What This Changes

Request guarded keyboard shortcuts in the Control UI for jumping or cycling between visible sessions/agents without firing while editable controls are focused.

## Best Possible Solution

Define the accepted key map, target ordering, and editable-focus guard, then implement it through the existing sidebar/session navigation path and adjacent guarded-shortcut infrastructure with focused UI tests and docs.

- **Decline Global Switching Chords:** Keep session switching in the picker/sidebar and command palette if maintainers decide the key conflicts and hidden state changes are not worth adding.
