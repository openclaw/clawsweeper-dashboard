## Summary

Keep open. Current main still supports Control UI session switching through the sidebar and session picker, plus Cmd/Ctrl+K and Escape handlers, but it does not implement guarded positional or cyclic session/agent switching shortcuts; the adjacent guarded-shortcut PR at https://github.com/openclaw/openclaw/pull/84827 covers different actions.

## What This Changes

Request to add guarded Control UI keyboard shortcuts for jumping among sessions/agents, cycling to the next session, and dismissing the picker without firing from text inputs.

## Best Possible Solution

Choose the shortcut bindings and active-agent ordering, then implement the behavior through a single guarded Control UI shortcut dispatcher that reuses the existing session selection path and editable-target tests.
