## Summary

Keep open. Current main still has click/search-based Control UI session switching plus existing Escape and Cmd/Ctrl+K handlers, but no guarded positional or cyclic session/agent switching shortcuts; the related guarded-shortcuts PR covers different dashboard actions.

## What This Changes

Request guarded Control UI keyboard shortcuts for switching between agent/session entries by position or cycle without firing while editable content is focused.

## Best Possible Solution

Define a focused Control UI shortcut contract that reuses the existing sidebar/session-picker selection path, preserves editable-target guards, and adds focused browser tests before implementing any positional or cyclic session switching.
