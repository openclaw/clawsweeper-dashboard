## Summary

Keep open. Current main and latest release still provide Control UI session switching through the sidebar/session picker plus existing palette/Escape handlers, but they do not implement the requested guarded positional or cyclic session/agent switching shortcuts; the open guarded-dashboard-shortcut PR covers adjacent chat actions, not this session-switching contract.

## What This Changes

Add guarded Control UI keyboard shortcuts for switching among agents or sessions without firing from editable fields.

## Best Possible Solution

Have maintainers choose non-conflicting bindings and session ordering, then implement the behavior through one guarded Control UI shortcut dispatcher that reuses existing sidebar/session-picker selection and editable-target tests.
