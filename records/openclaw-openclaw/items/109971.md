The PR returns an empty capability list for failed Ollama `/api/show` requests and adds unit, integration, and loopback HTTP coverage for conservative tool advertisement.

## Best Possible Solution

Model failed inspection as a distinct outcome, use it to make tool support conservative, and preserve the existing reasoning-name fallback until a successful response supplies authoritative capabilities.
