This issue remains necessary because https://github.com/openclaw/openclaw/pull/98997 is an open closing candidate and https://github.com/openclaw/openclaw/pull/98658 is an overlapping open candidate, but neither has landed and both need the same compatibility decision.

## What This Changes

The issue requests warning on duplicate `agents.defaults.models` aliases and a deterministic conflict policy instead of silent overwrite.

## Best Possible Solution

Land one coherent duplicate-alias fix that warns in both default-model and alias-index resolution while preserving shipped last-wins selection unless maintainers explicitly approve a precedence break.
