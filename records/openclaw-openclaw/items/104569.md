## Summary

Keep open: the new hint can be emitted from `models.mode: "replace"` even when the returned configured catalog still retains auth-backed built-in rows, so it may tell users their settings filtered a catalog that was not actually restricted.

## What This Changes

Adds optional `catalogMode: "replace"` gateway metadata and shows a replace-mode explanation plus Models-settings action in the Control UI chat picker and Quick Settings.

## Best Possible Solution

Make the gateway emit replace-mode metadata only when the returned configured catalog was actually narrowed by replace-mode configuration, and cover both configured-provider discovery and auth-backed built-in provider paths.
