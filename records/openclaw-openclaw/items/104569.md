## What This Changes

The PR adds optional `catalogMode: "replace"` metadata to configured model-catalog responses and uses it in the Control UI model picker and Quick Settings to explain replace-mode filtering and link to model settings.

## System Context

Gateway model-list and chat-metadata responses supply the configured model catalog to the Control UI. This change carries an optional replace-mode fact with that catalog so the picker and Quick Settings can explain locally configured filtering without inferring it from the displayed rows.
