## Summary

Keep this PR open for a narrow correction: its shared watchdog gives the metadata lookup and subsequent image download one combined 30-second budget, so a slow but successful metadata response can cause an otherwise timely image fetch to be aborted. Likely related people: hannasdev is a low-confidence adjacent avatar-path contributor from the merged avatar endpoint work.

## What This Changes

The branch adds a 30-second abort timeout to chat-avatar metadata and local image fetches and replaces the prior render-focused test with local-server behavior coverage.

## Best Possible Solution

Give the metadata lookup and local avatar-image download independent 30-second deadlines, then cover the case where metadata is slow but the image completes within its own bound.
