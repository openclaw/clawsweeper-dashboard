## Summary

Keep open for maintainer product review: current `main` and `v2026.6.11` still define JSON5 `openclaw.json` as the config-file contract, and YAML support would add a second core config format with precedence, parser, write-back, reload, and docs consequences.

## What This Changes

Request support for `openclaw.yaml` or `openclaw.yml` as alternative config file formats alongside the current JSON5 `openclaw.json` contract.

## Best Possible Solution

Maintainers should decide whether to keep JSON5 plus `openclaw config`/`config.patch` as the canonical path, or approve YAML only with a tested parser, precedence, write-back, reload, docs, and upgrade plan.
