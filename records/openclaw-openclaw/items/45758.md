## Summary

Keep open for maintainer product review: current main and v2026.6.11 still define JSON5 `openclaw.json` as the config-file contract, while the issue discussion and docs point to `openclaw config` and `config.patch` as the narrower existing answer for comment-safe scripted edits.

## What This Changes

Request support for `~/.openclaw/openclaw.yaml` or `openclaw.yml` as an alternate config file format while keeping JSON5 `openclaw.json` as the default.

## Best Possible Solution

Maintain JSON5 plus `openclaw config` and `config.patch` as the canonical config mutation path unless maintainers explicitly approve YAML with precedence, parser semantics, write-back behavior, docs, release notes, and regression tests.

## Reproduction Assessment
