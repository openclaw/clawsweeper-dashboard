## Summary

Keep open for maintainer product review: YAML config files are still missing on current main and the latest release, but adding them would expand the stable core config-file contract while JSON5 plus `openclaw config`/`config.patch` already covers commentable scripted edits.

## What This Changes

Request to support `~/.openclaw/openclaw.yaml` and `~/.openclaw/openclaw.yml` as alternatives to the current JSON/JSON5 config file.

## Best Possible Solution

Maintainers should decide whether to keep JSON5 as the single config format and lean on documented `openclaw config`/`config.patch` editing, or sponsor a core YAML design with explicit precedence, write-back, doctor, docs, and upgrade proof.
