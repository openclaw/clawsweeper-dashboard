## Summary

Keep open for maintainer product review: current main and the latest release still keep `openclaw.json` as the JSON/JSON5 config contract, while YAML/YML support would expand a stable core config surface rather than fix broken behavior.

## What This Changes

Support `openclaw.yaml` or `openclaw.yml` as an alternative on-disk config format alongside the current JSON5 `openclaw.json` contract.

## Best Possible Solution

Keep JSON/JSON5 canonical unless maintainers explicitly sponsor a YAML config design; otherwise improve supported CLI, Control UI, and `config.patch` guidance for comment-aware edits.
