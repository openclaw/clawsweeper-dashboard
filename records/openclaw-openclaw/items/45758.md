Keep open for maintainer product review: current main and the latest release still make JSON5 `openclaw.json` the core config-file contract, while the issue discussion reframes the practical pain as comment-safe config mutation rather than a missing YAML parser.

## Best Possible Solution

A maintainer should choose the config-file policy: keep JSON5 canonical and strengthen CLI/RPC editing guidance, or approve YAML with explicit precedence, parser, write-back, reload, doctor, docs, and upgrade tests.
