## Summary

Keep open for maintainer product review: current main and v2026.6.11 still make JSON5 `openclaw.json` the core config-file contract, and the discussion reframes the pain as comment-safe mutation rather than a proven need for a second parser format.

## What This Changes

## Best Possible Solution

Maintainers should either keep JSON5 canonical and strengthen CLI/RPC editing guidance, or explicitly approve YAML with defined precedence, parser, write-back, reload, doctor, docs, and upgrade tests.
