## Summary

Keep open for maintainer product review: current main and the latest release still treat `openclaw.json` as the canonical JSON/JSON5 config file, while YAML/YML support would expand a compatibility-sensitive core config contract rather than fix broken existing behavior.

## What This Changes

Request support for `openclaw.yaml` or `openclaw.yml` as an alternate OpenClaw config file format alongside the current JSON5 config file.

## Best Possible Solution

Keep JSON5 as the canonical config format and improve config-editing guidance unless maintainers approve a YAML design that covers precedence, parser semantics, write-back behavior, docs, and upgrade tests.
