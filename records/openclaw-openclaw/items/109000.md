## Summary

Keep open. Bounding the warning-only caches is reasonable, but the same generic eviction is also applied to pending owner-display secrets whose purpose is to preserve a stable generated HMAC secret until persistence succeeds; that part needs correction and real runtime proof before merge.

## Best Possible Solution
