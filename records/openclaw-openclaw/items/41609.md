## Summary

Keep open. Current main and v2026.6.11 still leave direct inbound Feishu interactive-card events outside the reusable interactive-card parser, while merged related work only covers fetched/quoted card extraction and open siblings cover narrower callback-field and merge_forward subsets.

## What This Changes

Parse Feishu interactive-card content and card-action fields from received events so agents see text, buttons, select choices, and form values instead of only placeholders or raw payloads.

## Best Possible Solution

Keep this as the broad Feishu interactive-card parsing tracker, define the plugin-owned card/action payload contract, then land direct inbound parser reuse while coordinating callback-field and merge_forward details through the narrower linked issues.
