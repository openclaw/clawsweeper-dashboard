## Summary

Keep open. Current main and the latest release still leave direct inbound Feishu `interactive` messages on the raw-content path, while merged and open related work only covers fetched/quoted cards, card-action fields, or merge_forward subsets.

## What This Changes

The issue asks OpenClaw to parse Feishu Interactive Card message content, including card text and interactive component values, instead of exposing only an unsupported/type marker to the agent.

## Best Possible Solution

Keep this as the broad Feishu interactive-card parsing tracker, reuse the existing card parser for direct inbound `interactive` messages, and resolve callback-field and merge_forward details through the narrower linked items after choosing a stable agent-visible payload shape.
