## Summary

Keep open. Current main and v2026.6.11 still leave direct inbound Feishu interactive-card messages on the raw-content path, while related work only covers fetched/quoted cards, card-action callback fields, or merge_forward subsets.

## What This Changes

The issue requests Feishu interactive-card message parsing so agents can see card text, buttons, options, and form/input values instead of placeholders or raw content.

## Best Possible Solution

Keep this as the broad Feishu interactive-card tracker, reuse the existing card parser for direct inbound messages, and resolve callback-field and merge_forward subsets through their narrower linked items after choosing a stable agent-visible payload shape.
