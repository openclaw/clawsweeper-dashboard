## Summary

Keep open: current main still has a source-proven path where a system-event/exec-triggered heartbeat can resolve the originating session before the configured heartbeat session, and the linked fix remains unmerged/conflicting rather than implemented on main.

## What This Changes

The issue asks OpenClaw to keep Telegram DM traffic and heartbeat/system-event heartbeat runs from polluting each other's agent sessions.

## Best Possible Solution

Land a maintainer-approved routing fix where configured heartbeat sessions and isolated heartbeat lanes cannot be overridden by an originating DM/system-event session, with focused regression coverage for exec-triggered wakes and safe event handling.
