## Summary

Keep open: current main and the latest release still have the source-level routing path described here, while the two direct fix PR attempts are closed/unmerged or open only in a conflicting fork and the Telegram default-isolation half still needs maintainer product direction.

## What This Changes

The issue asks OpenClaw to prevent Telegram DM and heartbeat/system-event traffic from sharing or overriding session keys in ways that pollute `agent:main:main` or DM sessions.

## Best Possible Solution

Land a fresh current-main fix that makes explicit `heartbeat.session` win over wake-provided session keys with safe system-event handling, while leaving Telegram/default DM isolation policy unchanged unless maintainers explicitly approve a cross-channel or Telegram-specific policy change.
