## Summary

Keep open: current main and the latest release still resolve an originating forced heartbeat session before explicit `heartbeat.session`, while Telegram DM default-to-main routing remains an intentional compatibility/product decision rather than an implemented fix.

## What This Changes

The issue asks OpenClaw to prevent Telegram DM and heartbeat/system-event traffic from sharing or polluting the agent main/heartbeat session.

## Best Possible Solution

Land a maintainer-approved heartbeat precedence repair so explicit `heartbeat.session` wins for system-event wakes, then decide Telegram DM default isolation separately with compatibility, docs, and regression coverage.

## Solution Assessment

No, closing or landing one broad Telegram-default change is not the best solution yet. The safer path is a narrow heartbeat precedence repair plus a separate maintainer decision for Telegram DM default isolation.
