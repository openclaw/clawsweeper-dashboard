## Summary

Keep open: current main and the latest release still resolve event-provided wake session keys before `heartbeat.session`, and the only linked implementation candidate is still open and conflicting. The issue is still necessary as the canonical bug for heartbeat/session-routing contamination.

## What This Changes

The issue reports Telegram DM and heartbeat/session-routing traffic sharing the wrong agent session, causing session-state pollution and possible lost or misrouted messages.

## Best Possible Solution

Land a maintainer-approved heartbeat precedence fix that makes explicit `heartbeat.session` win for event-triggered wakes and preserves or migrates pending system events without cross-session pollution; decide Telegram DM default isolation separately.
