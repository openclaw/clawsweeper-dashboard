## Summary

Keep open: current main still resolves a wake-provided originating session before `heartbeat.session`, while Telegram DM-to-main isolation remains a separate compatibility/product decision rather than a landed fix.

## What This Changes

Report that Telegram DM and system-event heartbeat traffic can share or override the intended heartbeat/main session boundary, polluting session state and sometimes affecting delivery.

## Best Possible Solution

Land a maintainer-approved heartbeat wake repair that makes explicit `heartbeat.session` win for system-event wakes, and handle Telegram default DM isolation as a separate cross-channel compatibility decision.
