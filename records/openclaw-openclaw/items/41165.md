## Summary

Keep open: current main and latest release still let wake-provided originating sessions outrank explicit `heartbeat.session`, while changing default Telegram DM isolation remains a separate compatibility/product decision.

## What This Changes

Issue requests preventing Telegram DMs and system-event-triggered heartbeats from polluting the configured heartbeat/main session.

## Best Possible Solution

Land a maintainer-approved heartbeat wake repair where explicit `heartbeat.session` wins and queued system events are handled safely, then decide Telegram default DM isolation separately through `session.dmScope`, docs, and tests.
