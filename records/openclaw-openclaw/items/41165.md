## Summary

## What This Changes

Ensure Telegram DM and system-event-triggered heartbeat runs do not pollute main or configured heartbeat sessions.

## Best Possible Solution

Land a maintainer-approved heartbeat wake fix that makes explicit `heartbeat.session` win and preserves pending system events without cross-session pollution, while deciding Telegram DM default isolation separately.
