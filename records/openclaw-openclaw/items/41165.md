## Summary

Keep open: current main and latest release still let event-provided heartbeat wake session keys win before configured `heartbeat.session`, while Telegram DM isolation remains a compatibility-sensitive product decision rather than implemented behavior.

## What This Changes

The issue asks OpenClaw to prevent Telegram DM traffic and event-triggered heartbeat runs from polluting the agent main or configured heartbeat session.

## Best Possible Solution

Land a maintainer-approved fix that makes explicit `heartbeat.session` win for event-triggered wakes and preserves pending system events, then decide Telegram default DM isolation separately with docs and regression coverage.
