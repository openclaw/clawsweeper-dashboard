## Summary

Keep open: current main and the latest release still let event-provided wake session keys win before `heartbeat.session`, while Telegram DMs still collapse to the agent main session unless `session.dmScope` is configured. The linked fork fix targets the heartbeat path, but it is open, conflicting, and not landed.

## What This Changes

Telegram DM and heartbeat-triggered traffic should stay out of the wrong main or heartbeat session when isolation or an explicit heartbeat session is expected.

## Best Possible Solution

Land a maintainer-approved heartbeat routing fix that honors explicit heartbeat session config while preserving or deliberately migrating documented DM isolation defaults.
