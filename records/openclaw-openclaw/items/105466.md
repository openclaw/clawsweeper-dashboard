## Summary

This is a valid, vision-aligned sandbox hardening request. Current main lacks a storage-budget contract, but the proposed Docker option and pre-tool probes do not provide complete workspace or cross-backend containment, so security-owner direction is required before implementation.

## What This Changes

Requests configurable disk quotas and workspace-growth enforcement for Docker and SSH agent sandboxes.

## Best Possible Solution

Define a shared sandbox storage-budget capability with named covered surfaces, backend enforcement or diagnostics, and explicit unsupported behavior, using host or remote filesystem quotas for workspaces rather than relying solely on Docker writable-layer limits or tool probes.
