## Summary

Close as implemented: current main and release v2026.6.11 already render `openclaw logs` text timestamps in local time by default, prefer the log `time` field over `_meta.date`, keep `--local-time` compatibility, and provide `--utc` for explicit UTC output.

## What This Changes

The issue asks for `openclaw logs` to display local-time timestamps instead of UTC by default.

## Best Possible Solution

Keep the shipped local-time default with `--utc` as the explicit UTC opt-in; any future container console or journal-specific UTC report should be filed as a separate focused bug with current-version evidence.
