## Summary

Current main and the stable v2026.5.26 release already solve the central `openclaw logs` problem: text output renders local time by default, the parser prefers the log `time` field when present, and UTC remains available via `--utc`.

## What This Changes

The issue requests that `openclaw logs` display log timestamps in the system local timezone instead of UTC by default.

## Best Possible Solution

Keep the shipped local-time default with `--utc` opt-out; any remaining raw Docker, systemd, or console-prefix timestamp behavior should be filed as a separate focused issue if still reproducible.
