## Summary

Close as implemented: current main and v2026.6.11 render `openclaw logs` timestamps from the parsed `time` field in local time by default, with `--utc` for UTC output, and focused tests/docs cover the behavior.

## What This Changes

The issue asks for `openclaw logs` output to use the user's local timezone instead of UTC by default.

## Best Possible Solution

Keep the current shipped CLI behavior: local timestamp display by default, `--utc` as the explicit opt-in, and parser preference for the log record's `time` field.
