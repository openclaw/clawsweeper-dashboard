## Summary

Current main and the shipped v2026.6.11 release already implement the reported local-time behavior for `openclaw logs`, including local timestamps by default, `--utc` as the opt-in UTC mode, parser preference for the log `time` field, tests, and docs.

The issue requests `openclaw logs` to render timestamps in the system local timezone by default instead of UTC.

## Best Possible Solution
