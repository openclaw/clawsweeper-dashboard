## Summary

Keep this PR open, but it needs a narrow repair before merge: the central metadata-leak fix is valid and current main does not already solve the shared sanitizer path, yet the patch applies a user-role stripping helper to every assistant sanitizer profile and can silently drop legitimate assistant-visible text.

## Best Possible Solution

Keep the shared channel fix, but use a metadata-block-only or leading-metadata cleanup path for assistant delivery that preserves clean assistant prose and add focused sanitizer plus channel-adapter regressions before merge.
