## Summary

Keep open: current main and v2026.6.11 still strip final tags as plain tokens and only collapse duplicate blocks separated by blank lines, so the reported glued same-line and single-newline duplicate output remains unresolved. The direct fix PRs are closed unmerged, and the broad overlapping normalizer PR is still draft/conflicting rather than a safe canonical fix.

## What This Changes

Improve the user-facing output sanitizer so same-line, single-newline, partial, or final-tag-boundary duplicate assistant text is not delivered to users.

## Best Possible Solution

Land a conservative sanitizer repair for concrete adjacent or final-tag-boundary duplicates, with regression tests preserving intentional repeats, ordinary single-newline prose, code indentation, and trailing whitespace.
