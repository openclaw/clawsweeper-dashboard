## Summary

Keep open: current main and v2026.6.11 still strip final tags as tokens and only collapse duplicate blocks separated by blank lines, so the reported glued same-line and single-newline duplicate reply remains unresolved.

## What This Changes

Improve the user-facing output sanitizer so final-tag stripping and duplicate collapse handle glued same-line, single-newline, and carefully bounded partial duplicate assistant text.

## Best Possible Solution

Land a conservative sanitizer repair for concrete adjacent or final-tag-boundary duplicates, with regression tests preserving intentional repeats, ordinary single-newline prose, code indentation, and trailing whitespace.
