## Summary

Keep open: current main and v2026.6.11 still strip final tags as tokens and only collapse duplicate blocks separated by blank lines, so the reported glued same-line and single-newline duplicate output remains unresolved. The direct fix PRs are closed unmerged, and the overlapping broad normalizer PR is still draft/conflicting rather than a safe canonical fix.

## What This Changes

Request to extend `sanitizeUserFacingText()` duplicate cleanup so glued final-tag repeats and supported same-line or single-newline duplicates are removed without over-deleting intentional repetition.

## Best Possible Solution

Land a conservative sanitizer repair for concrete adjacent or final-tag-boundary duplicates, with regression tests preserving intentional repeats, ordinary single-newline prose, code indentation, and trailing whitespace.
