## Summary

Keep open: current main and the latest release still strip final tags as tokens and only collapse blank-line-separated duplicate blocks, so the reported same-line, single-newline, and final-tag-boundary duplicate output remains unresolved. The remaining choice is how conservative the sanitizer heuristic should be before implementation.

## What This Changes

Improve the outbound text sanitizer so final-tag, same-line, single-newline, and partial duplicate assistant output is removed before user-facing delivery.

## Best Possible Solution

Land a conservative sanitizer repair for concrete adjacent or final-tag-boundary duplicates, with regression tests preserving intentional repeats, ordinary single-newline prose, code indentation, and trailing whitespace.
