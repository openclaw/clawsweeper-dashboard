## Summary

Keep open: current main and the latest release still strip final tags as plain tag removal and only collapse blank-line-separated duplicate blocks, so the reported glued same-line and single-newline duplicate output remains unresolved. The direct fix PRs are closed unmerged, and the open broader visible-output PR overlaps the area but is still draft/broad rather than a safe canonical fix.

## What This Changes

The issue requests stronger user-facing output sanitization for same-line, single-newline, partial, and final-tag-boundary duplicate assistant text.

## Best Possible Solution

Bound the sanitizer to conservative adjacent or final-tag-boundary duplicate removal, with regression coverage preserving intentional repeats, ordinary single-newline prose, code indentation, and trailing whitespace.
