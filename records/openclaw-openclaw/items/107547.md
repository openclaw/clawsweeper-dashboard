Full review comments:

- **[P1] Enforce a true rolling restart limit:** `src/infra/channel-health-escalations.ts:53-54`
  - body: The persisted row is a fixed window: once `nowMs - window_started_at_ms` reaches one hour, the counter resets completely. This allows the full allowance just before the boundary and the full allowance again just after it, so nearly 2× `channelMaxRestartsPerHour` whole-gateway restarts can occur inside a rolling hour. Persist individual escalation timestamps or equivalent rolling buckets and prune and count them transactionally before allowing the restart.
  - confidence: 0.96
- **[P1] Fail closed when durable restart budgeting is unavailable:** `src/infra/channel-health-escalations.ts:78-81`
  - body: The catch path returns `allowed: true`, but every successful supervised escalation replaces the process and loses the in-memory cooldown. If the state database keeps failing while the wedge reforms, this bypasses the only restart-surviving cap and can loop whole-gateway restarts indefinitely. Prefer logging manual recovery and skipping escalation when the durable budget cannot be read or committed, or provide another durable bound.
  - confidence: 0.93
