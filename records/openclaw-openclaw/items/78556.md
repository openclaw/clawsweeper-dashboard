Full review comments:

- **[P1] Resolve bridge links from source-origin targets:** `extensions/memory-wiki/src/lint.ts:75-77`
  - body: `extractWikiLinks` already normalizes Markdown links like `./target.md` against the generated wiki page path, so this helper can receive `sources/target.md` rather than the original bridge-relative target. Joining that with `dirname(bridgeRelativePath)` can produce `memory/chatgpt/sources/target.md`, leaving the reported bridge-source false positive unresolved.
  - confidence: 0.91
- **[P2] Guard malformed percent escapes before decoding:** `extensions/memory-wiki/src/lint.ts:69-71`
  - body: Imported bridge content can contain arbitrary Markdown link text. Calling `decodeURIComponent` on every candidate target means a malformed escape like `%ZZ` throws and makes `openclaw wiki lint` fail instead of reporting or ignoring a broken link.
  - confidence: 0.9
- **[P3] Keep the reply directive allowlist exact:** `extensions/memory-wiki/src/lint.ts:53-54`
  - body: The directive matcher makes the suffix optional, so `[[reply_to]]` is also ignored even though the supported directive shapes here are `reply_to_current` and `reply_to:<id>`. Keep the allowlist to known directive shapes so real pages or aliases named `reply_to` can still be linted.
  - confidence: 0.76
