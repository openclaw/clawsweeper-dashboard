This PR remains necessary because current main still performs the heartbeat transcript classification through the pre-streaming path. The revised patch addresses the earlier unbounded-record concern and now includes credible after-fix CLI evidence; no concrete patch defect was identified from the available source and PR evidence.

## What This Changes

The branch replaces Doctor’s full-file heartbeat transcript read with synchronous chunked JSONL scanning, caps retained records at 256 KiB, and adds regression coverage for multi-chunk and oversized-record cases.

## Best Possible Solution

Merge the bounded scanner after the remaining required checks finish successfully, retaining the fail-closed behavior for oversized or malformed JSONL records.
