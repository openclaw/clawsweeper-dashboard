## Summary

Keep this PR open: it targets a real bounded-memory concern, but the proposed chunk loop still needs to bound an unterminated JSONL record before it can guarantee the stated OOM protection.

## What This Changes

The PR replaces full-file doctor heartbeat transcript reads with synchronous chunked scanning and adds coverage for a multi-chunk heartbeat-only transcript.

## Best Possible Solution

Keep streaming the transcript, but impose a conservative maximum retained JSONL-record size or use a truly streaming record parser so a missing or oversized newline cannot recreate the full-file allocation.
