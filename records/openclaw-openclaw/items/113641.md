## Summary

Keep this PR open for maintainer product-direction review and a compatibility correction. Current Workboard documentation defines `done` as operator acceptance and explicitly permits a direct manual move; this patch turns that documented path into a hard proof requirement without a migration, opt-in policy boundary, or updated contract.

## What This Changes

The branch adds fail-closed Workboard completion gates requiring structured passed proof and blocking completion for decomposed work, unresolved children or dependencies, and linked pull requests that are not accepted or merged.

## System Context

Workboard is an optional OpenClaw plugin that records cards created through gateway and agent-tool calls. Card lifecycle transitions update persisted task state and drive completion notifications and automation views.

## Best Possible Solution
