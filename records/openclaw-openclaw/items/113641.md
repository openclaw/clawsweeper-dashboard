## What This Changes

This PR makes the Workboard plugin require structured passed proof before a card can become done, adds completion checks for decomposed or unfinished work, and records new workflow and waiver metadata.

## System Context

Workboard is OpenClaw’s bundled task-card plugin: gateway and tool calls create, decompose, prove, and complete cards. Its store persists card metadata and emits lifecycle notifications, so completion rules affect existing operators, automation, and downstream status reporting.
