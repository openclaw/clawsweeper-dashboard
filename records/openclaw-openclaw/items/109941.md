## Summary

Keep this issue open. The report identifies a concrete macOS restart-health false negative: the stopped-and-port-free early exit can expire inside launchd’s normal throttled KeepAlive respawn window, while the separate related issue concerns the underlying startup failure rather than this incorrect CLI verdict. No merged fix or current-release resolution is established.

## What This Changes

Make macOS gateway restart health checks avoid declaring failure while launchd KeepAlive is still performing a throttled respawn.

## Best Possible Solution

Pass prepared launchd supervision facts into restart-health evaluation and suppress or extend the stopped-free early exit only while a KeepAlive job can still be inside its throttle window, preserving bounded fast failure for removed, disabled, unmanaged, and non-macOS services without adding a new user config knob.
