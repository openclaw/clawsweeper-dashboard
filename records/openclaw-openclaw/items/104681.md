## What This Changes

The PR replaces fixed 1 GiB and 2 GiB default heap-pressure thresholds with 60% and 75% of V8’s effective heap limit, retaining the old values as floors and adding focused unit coverage.

## Best Possible Solution

Keep the no-config V8-relative defaults with conservative floors, but demonstrate real gateway classification on enlarged and ordinary heap limits before merge while retaining unchanged RSS and growth protection.
