## What This Changes

The PR changes Slack thread-context hydration so a thread session created only by outbound delivery receives the visible thread root and prior human context on its first inbound follow-up.

## System Context

Slack inbound message handling resolves a thread’s session state before deciding whether to load bounded thread history for the agent. Outbound delivery can mirror a session before a human responds; this change uses the recorded inbound-interaction signal to decide whether initial context still needs to be supplied.
