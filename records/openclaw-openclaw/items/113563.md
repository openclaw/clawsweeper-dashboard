## What This Changes

The PR changes Slack thread-context initialization so a session created only by outbound delivery is hydrated with the visible thread root, earlier permitted human messages, and starter media when its first inbound follow-up arrives.

## System Context

Slack message handling maps inbound replies into agent sessions and prepares a bounded visible thread transcript before the model runs. Outbound delivery can mirror a reply into a thread session before a human participates, so the context-preparation step must distinguish that delivery-only session from one that already processed inbound conversation.
