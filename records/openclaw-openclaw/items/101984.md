## Summary

Keep open for maintainer review. The PR appears to fix the compact-token corruption with sufficient live-output proof, but it narrows behavior of an SDK-exported parser by dropping compact `key=value` and hyphen-delimited keyed reply forms.

## What This Changes

This PR narrows `parseKeyedAnswers` to whitespace-delimited `:`/`=` labels, removes `-` as a delimiter, and adds regression coverage for compact tokens and hyphenated keys in multi-question agent replies.

## Best Possible Solution

Land the shared-helper fix after maintainers explicitly accept the narrowed keyed-answer syntax; otherwise require a question-aware parser that preserves any accepted legacy forms without reintroducing compact-token corruption.
