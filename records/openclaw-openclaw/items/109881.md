## Summary

This Bedrock-specific report remains necessary. Current main preserves nonblank Bedrock thinking signatures, but its recovery predicate does not match “Invalid signature in thinking block,” and the open native-Anthropic recovery PR does not prove Bedrock coverage. ([raw.githubusercontent.com](https://raw.githubusercontent.com/openclaw/openclaw/main/src/agents/pi-embedded-runner/thinking.ts))

## What This Changes

Prevent rejected historical thinking signatures on Bedrock Claude models from permanently wedging session replay.

## Best Possible Solution

Extend the shared signed-thinking recovery path to recognize Bedrock invalid-signature validation errors, retry once with thinking removed, and durably repair the replay transcript; separately harden Bedrock block assembly only if focused upstream-backed tests prove partial signatures can be persisted before contentBlockStop.
