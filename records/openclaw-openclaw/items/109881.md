## Summary

This is a credible Bedrock-specific replay failure that remains necessary: current safeguards remove missing or blank signatures, while the report shows full signatures rejected by Bedrock and no confirmed recovery on that transport. The broader Anthropic replay issue and open recovery PR overlap, but neither proves that Bedrock Converse is covered.

## What This Changes

Prevent Bedrock Claude extended-thinking sessions from becoming permanently poisoned when a replayed thinking signature is rejected, including safe one-shot recovery without losing visible conversation content.

## Best Possible Solution

Keep modern Claude thinking preservation by default, add Bedrock-specific complete-block persistence coverage, and route a Bedrock invalid-signature rejection through one bounded strip-and-retry repair that preserves visible text and tool structure while durably preventing the poison from being replayed again.
