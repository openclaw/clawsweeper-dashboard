## What This Changes

The issue requests cron execution logging, skipped/failure warnings, a cron-aware health probe, and CLI status warnings for unhealthy scheduled jobs.

## Best Possible Solution

Land one coordinated cron-observability design that records bounded all-outcome logs, annotates unhealthy cron list/show output, and exposes cron health through the maintainer-approved probe surface while preserving existing run history, counters, and failure-alert behavior.
