## Summary

Keep open: current main has partial cron diagnostics, run state, counters, failure alerts, durable run history, and generic probes, but it still lacks all-outcome runtime logging, cron-aware health/readiness behavior, and unhealthy `openclaw cron list` annotations.

## What This Changes

The issue requests cron execution observability: per-attempt logs, cron-aware health/readiness, and warnings in cron list output when jobs skip, fail, or fall overdue.

## Best Possible Solution

Land one coordinated cron-observability design that adds bounded all-outcome runtime logs, unhealthy CLI annotations, and a maintainer-approved cron health/readiness surface while preserving current run history, counters, task rows, and failure-alert behavior.
