## Summary

Keep open: current main only partially covers cron observability; it records run state and logs error statuses, but still lacks all-outcome runtime logging, cron-aware health/readiness, and CLI warnings. Related implementation PRs are closed unmerged, so no canonical fix owns the remaining work.

## What This Changes

The issue requests cron execution observability: per-attempt logging, skipped/failure warnings, a cron health surface, and `openclaw cron list` warnings for unhealthy jobs.

## Best Possible Solution

Land one coordinated cron-observability design that adds bounded all-outcome runtime logs, unhealthy CLI annotations, and a maintainer-approved cron health/readiness surface while preserving existing counters, run history, and failure alerts.
