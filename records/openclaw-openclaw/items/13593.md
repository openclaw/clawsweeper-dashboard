## Summary

Keep open: current main still has only partial cron diagnostics. It records run status/history and logs error statuses, but it does not yet provide all-outcome cron runtime logging, cron-aware health/readiness, or `openclaw cron list` warnings for unhealthy jobs; the related implementation PRs are closed unmerged.

## What This Changes

The issue requests better cron execution observability: structured logging for run outcomes, cron health/probe reporting, and CLI warnings for unhealthy scheduled jobs.

## Best Possible Solution

Land one coordinated cron-observability design that adds bounded all-outcome runtime logs, unhealthy CLI annotations, and a maintainer-approved cron health/readiness surface while preserving existing counters, run history, and failure alerts.
