## What This Changes

This PR rejects shell-shaped source passed to code-mode `exec`, adds guidance and a Doctor advisory for local model providers, and documents the local-model retry problem.

## System Context

Code mode accepts model-supplied JavaScript or TypeScript and executes it in a QuickJS guest runtime; guest code reaches ordinary tools through the catalog. The new validation runs before that guest runtime, while Doctor separately reads configured model routes to show operator advisories.
