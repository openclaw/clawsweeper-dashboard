## What This Changes

This PR adds a Code Mode source classifier that rejects recognizable POSIX and Windows shell commands before QuickJS execution, with documentation and regression coverage for JavaScript, TypeScript, and catalog-tool use.

## System Context

Code Mode exposes `exec` and `wait` to an agent, but their `code` and `command` inputs are guest JavaScript or TypeScript rather than shell commands. The runtime prepares that source before starting a QuickJS worker, then returns a tool result to the agent; this PR inserts a shell-source rejection at that preparation boundary.
