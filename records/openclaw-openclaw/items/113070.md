## What This Changes

The PR adds a pre-execution classifier that rejects recognizable shell source passed through Code Mode’s JavaScript/TypeScript `exec` input, expands regression coverage, and documents the correct catalog-tool workflow.

## System Context

Code Mode lets an agent submit JavaScript or TypeScript that runs in a QuickJS guest environment and can call approved catalog tools. This change sits between the model’s `exec` request and guest-worker startup, deciding whether source is code that may execute or a shell-shaped request that should receive corrective input guidance.
