The PR adds a 30-second timeout to the QQBot token `fetchWithSsrFGuard` call and updates token manager tests to assert the timeout is forwarded.

## Best Possible Solution

Land one QQBot token timeout fix at the guarded-fetch boundary with focused test coverage and redacted stalled-endpoint proof; this PR is the cleaner candidate unless maintainers choose to repair or replace it.
