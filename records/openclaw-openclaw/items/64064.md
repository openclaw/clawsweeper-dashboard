Overall correctness: patch is incorrect

Full review comments:

- **[P1] Validate advisor model pairs before injection:** `extensions/anthropic/stream-wrappers.ts:240-241`
  - body: `advisor: true` always injects `claude-sonnet-4-6`, and custom values only need to match `claude-*`. Anthropic's advisor docs require the executor and advisor to be a valid pair and return 400 for unsupported combinations, so enabling this on an Opus or newer Sonnet executor can turn a valid OpenClaw config into a runtime provider error. Validate the pair against the current compatibility table, or fail the advisor config before adding the beta header/tool.
  - confidence: 0.93
- **[P1] Preserve server-tool blocks for Anthropic replay:** `src/agents/anthropic-transport-stream.ts:812-816`
  - body: The new stream path drops `server_tool_use` and rewrites `*_tool_result` blocks into display-only text that is skipped on API replay. Anthropic's SDK/docs require redacted advisor results and pause_turn/server-tool responses to be sent back as provider-owned content, so this can lose encrypted advisor/web-search state or make resumed server-tool turns fail. Store replayable raw blocks with pruning/sizing support instead of discarding them.
  - confidence: 0.91
