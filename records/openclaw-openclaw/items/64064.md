  - body: Anthropic's advisor docs say follow-up requests must append the full assistant content including `advisor_tool_result`, and redacted results are decrypted on the next turn only when the opaque content is round-tripped. This branch drops `server_tool_use` and turns `*_tool_result` into display-only text, so multi-turn advisor sessions lose required server-side state instead of satisfying the API contract.
  - confidence: 0.94
- **[P1] Validate advisor and executor model compatibility:** `extensions/anthropic/stream-wrappers.ts:227-230`
  - body: The advisor resolver accepts any `claude-*` advisor, but Anthropic requires a valid executor/advisor pair and returns `400 invalid_request_error` for unsupported combinations. For example, `params.advisor: true` on a stronger executor can inject the default Sonnet advisor even when the advisor must be at least as capable as the executor, turning a config toggle into a runtime request failure.
  - confidence: 0.91
