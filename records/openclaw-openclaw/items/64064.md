## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Preserve server-tool blocks for replay:** `src/agents/anthropic-transport-stream.ts:812-849`
  - body: The new stream path converts readable `*_tool_result` blocks to display text and drops `server_tool_use` plus encrypted/unreadable result blocks, but the Anthropic SDK marks advisor encrypted content as opaque state that must be round-tripped verbatim. This can lose server-side tool state across turns instead of preserving the provider contract.
  - confidence: 0.91
- **[P2] Account for server-tool iteration usage:** `src/agents/anthropic-transport-stream.ts:948-970`
  - body: Advisor requests can accrue separate server-tool loop usage, and the SDK exposes that through `usage.iterations`, but this mapping only records the top-level input/output/cache fields. Users can see incomplete cost/token accounting for advisor calls unless the iteration usage is surfaced or the docs explicitly make the limitation clear.
  - confidence: 0.84
- **[P2] Gate advisor models by documented capability:** `extensions/anthropic/stream-wrappers.ts:227-230`
  - body: The advisor guard accepts any `claude-*` model, but Anthropic documents that the advisor must be Sonnet 4.6 or more capable and at least as capable as the executor. This can inject unsupported advisor payloads for weaker or mismatched Claude models instead of rejecting or omitting the beta tool before the API call.
  - confidence: 0.82
