## What This Changes

The PR changes cron command-payload normalization to preserve valid string environment entries while filtering invalid or blank entries, with regression tests for mixed, wholly invalid, and valid maps.

## Best Possible Solution

Use the shared cron input normalizer to retain only valid string env pairs for both create and patch flows, preserving the existing Record<string, string> contract without adding a new config surface or runtime fallback.
