## Summary

Keep this PR open for revision: the reported stale-usage symptom is credible, but the patch changes the meaning and availability of the persisted context-budget denominator instead of fixing the freshness-aware display path, so it can regress new sessions and model switches.

## What This Changes

The PR removes model/config fallback resolution for persisted `contextTokens` and writes that field only when agent runtime metadata supplies a positive value.

## Best Possible Solution

Keep `contextTokens` as the resolved runtime/model context budget, keep actual consumption in freshness-qualified `totalTokens`, and fix any remaining Control UI or gateway presentation path that treats a stale or absent total as full usage; cover missing usage, a fresh session, and a model switch.
