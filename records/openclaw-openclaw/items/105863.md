## What This Changes

Routes logs and hooks fatal errors through the shared runtime exit path and allows JSON-mode logs to send terminal-reset sequences to stderr instead of structured stdout.

## Best Possible Solution

Keep fatal CLI termination centralized in defaultRuntime.exit while routing reset bytes away from structured stdout when JSON mode is active.

## Solution Assessment
