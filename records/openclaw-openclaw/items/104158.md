## What This Changes

The branch adds a read-only `openclaw commands` inventory CLI, including an optional `--node <node-id>` query that normalizes command identifiers advertised by one connected paired node, plus catalog metadata, plugin descriptor handling, tests, and documentation.

## System Context

The CLI’s node diagnostics path talks to the Gateway with pairing-aware operator authentication and receives a connected node’s advertised capabilities and commands. This PR would turn those live command identifiers into an operator/audit inventory alongside static CLI and plugin command metadata.
