## Summary

## What This Changes

## Best Possible Solution

Land the reset/truncation fix with `skippedBytes` if maintainers accept the additive `logs.tail` response contract; otherwise narrow this PR to the reset-only CLI/log-tail fix and track UI skipped-window metadata separately.

## Reproduction Assessment

## Solution Assessment

Yes, conditionally. Fixing the boolean conflation at `readLogSlice` is the right layer, and `skippedBytes` is a narrow additive contract that lets the UI avoid appending across skipped content if maintainers accept the response change.
