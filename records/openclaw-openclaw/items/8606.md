## Summary

Keep open: current main and the latest release still lack a context-pruning lifecycle hook, and https://github.com/openclaw/openclaw/pull/12581 is the open but conflicting implementation candidate that explicitly closes this issue.

## What This Changes

Request to emit a context-pruning lifecycle hook with pruning metadata so external memory or indexing workflows can react without polling.

## Best Possible Solution

Land a maintainer-approved current-path pruning hook with sanitized metadata, bounded best-effort delivery, focused tests, and docs for the event and payload contract.

## Reproduction Assessment

Yes, at source level. Current main prunes through the active agent-hooks context extension and pruner without emitting a pruning hook or returning hook metadata, and the hook catalogs and docs omit a pruning event.

## Solution Assessment

Unclear until maintainers settle the hook contract. A metadata-only session:prune event in the active agent-hooks path looks like the narrowest maintainable direction, while raw pruned-content access needs explicit privacy, size-limit, timeout, and trust-boundary decisions.
