## Summary

This PR should remain open but is not merge-ready: the new unconditional error precedence can display a retained error from the previous gateway while an explicit connection to a different gateway is underway. The branch also needs refresh against current main, whose onboarding implementation has materially moved since the PR base.

## What This Changes

The branch changes iOS gateway status and onboarding precedence so a retained connection error remains visible during automatic reconnect progress, with focused Swift tests and regenerated native localization inventory.

## Best Possible Solution

Track retained gateway problems by endpoint—or clear them when an explicit target changes—while preserving them only for retries of the same target; add same-target and cross-target precedence tests, rebase onto current main, and capture redacted simulator or device proof showing the visible transition.
