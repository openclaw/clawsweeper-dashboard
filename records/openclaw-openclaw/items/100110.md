## What This Changes

This PR changes Linux `ss` listener parsing from substring matching to exact parsed TCP endpoint port equality and adds Unix `ss` regression tests for prefix-conflicting ports.

## Best Possible Solution

Land one focused exact-port parser fix with regression tests after redacted Linux `ss` or OpenClaw port-diagnostic proof is added, then close the canonical issue and the unused duplicate candidate.

## Reproduction Assessment

## Solution Assessment

Yes: exact parsed-port equality through the existing `parseTcpEndpoint` helper is the narrowest maintainable fix and matches the sibling netstat parser. Fixed-column `ss` parsing would be more invasive for little added value here.
