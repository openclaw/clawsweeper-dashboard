## What This Changes

The issue requests that omitted message-tool account IDs auto-select the only enabled account on the selected channel instead of falling back to a disabled `default` account.

## Best Possible Solution

Review, land, or replace https://github.com/openclaw/openclaw/pull/85671 with a shared outbound account resolver that preserves explicit/default/bound precedence, uses plugin config adapter hooks, and documents zero, one, and multiple enabled-account behavior.
