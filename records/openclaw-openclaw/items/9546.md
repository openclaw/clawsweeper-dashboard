## What This Changes

Add a WebChat preference to hide, dismiss, customize, or replace the floating scroll-to-latest indicator.

## Best Possible Solution

Add a browser-local persisted indicator preference through the existing UI settings path, while preserving an accessible manual scroll-to-latest action when the floating control is hidden.
