## Summary

The central request remains unimplemented on current main and in v2026.6.11: WebChat persists auto-scroll behavior, but the New messages indicator is still derived directly from scroll state and rendered without its own visibility or presentation preference. This remains valid low-priority UX work requiring maintainer direction.

## What This Changes

Add a WebChat preference to disable, dismiss, or reduce the New messages indicator while reading long responses.

## Best Possible Solution

If maintainers approve the feature, add a browser-local persisted indicator mode and keep a separate accessible scroll-to-latest action available when automatic scrolling is off.
