## Summary

Current main preserves WebChat backscroll and offers persisted auto-scroll modes, but it still derives and renders the New messages recovery action directly from unseen-content state without any visibility or presentation preference. The related merged work intentionally retained that action, so this remains a distinct feature request requiring a maintainer UX decision rather than conservative cleanup.

## What This Changes

Add a WebChat preference to hide, customize, or replace the New messages indicator.

## Best Possible Solution

Add a browser-local compact or dismissible indicator preference while always retaining an accessible jump-to-latest action; avoid adding gateway or openclaw.json configuration for presentation-only state.
