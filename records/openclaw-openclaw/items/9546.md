## Summary

Keep open. Current main still has WebChat auto-scroll modes, but the New messages catch-up button remains a separate, always-rendered affordance when chatNewMessagesBelow is set, so the requested disable/dismiss/customize behavior still needs a maintainer UX decision.

## What This Changes

The issue requests a WebChat setting or UX mode to disable, dismiss, or reduce the New messages banner while reading chat output.

## Best Possible Solution

Add a browser-local, maintainer-approved New messages indicator mode that preserves an accessible jump-to-latest affordance and keeps retired WebChat gateway config closed unless intentionally reopened.
