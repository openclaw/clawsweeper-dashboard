## Summary

Current main adds persisted auto-scroll modes and preserves backscroll, but still treats the New messages action as the recovery affordance whenever unseen content accumulates. This remains a distinct, low-priority feature request requiring a maintainer UX and accessibility decision rather than conservative cleanup.

## What This Changes

Add a WebChat preference to disable, customize, or replace the New messages indicator.

## Best Possible Solution

Add a browser-local persisted indicator mode that supports a compact, dismissible, or hidden presentation while retaining an accessible catch-up action, rather than expanding `openclaw.json`.

- **Keep Current Action:** Retain the mandatory New messages action as the supported recovery affordance and decline an additional setting.
- **Gateway Configuration:** Add a `gateway.webchat` option, accepting a broader server configuration and upgrade surface for this presentation choice.
