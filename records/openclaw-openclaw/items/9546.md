## Summary

Current main still intentionally shows the floating catch-up control whenever new content arrives without auto-follow, and neither the landed auto-scroll modes nor the backscroll fix adds a visibility preference. This remains the canonical, vision-aligned WebChat ergonomics request, but implementation should wait for a maintainer decision because hiding the control can remove the established unseen-message recovery path.

## What This Changes

Add a persisted WebChat preference to hide, dismiss, or restyle the floating “New messages” catch-up indicator independently of auto-scroll mode.

## Best Possible Solution

Add an opt-in browser-local indicator mode in the existing chat settings, preserve a separate accessible scroll-to-latest action, and document its interaction with the three auto-scroll modes.
