## Summary

Current main still exposes the New messages action whenever unseen WebChat content accumulates, and the landed auto-scroll and backscroll changes intentionally preserve it as the manual recovery affordance. This remains a distinct low-priority feature requiring a WebChat UX and accessibility decision.

## What This Changes

Add a WebChat preference to hide, replace, or reduce the prominence of the New messages indicator.

## Best Possible Solution

If sponsored, add a persisted browser-local indicator presentation setting with the current visible action as the default and retain an accessible way to reach unseen messages in every mode; avoid gateway configuration unless cross-client policy is an explicit requirement.
