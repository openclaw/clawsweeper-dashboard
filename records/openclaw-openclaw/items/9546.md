Request to add a WebChat option or setting to disable, replace, or customize the New messages notification banner.

## Best Possible Solution

Add a browser-local, persisted WebChat new-message indicator mode that preserves an accessible jump-to-latest affordance and does not reopen gateway.webchat config unless maintainers explicitly choose that surface.
