## What This Changes

The issue requests a WebChat setting to disable, replace, or make less intrusive the New messages notification banner while reading chat output.

## Best Possible Solution

Add a default-preserving browser-local New messages indicator preference only after maintainers choose the UX semantics; avoid reopening gateway.webchat config unless that policy surface is explicitly desired.
