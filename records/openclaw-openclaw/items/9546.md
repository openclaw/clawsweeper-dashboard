## Summary

Keep open: the merged auto-scroll selector improves the related reading-flow problem but deliberately retains the “New messages” catch-up control, so suppressing or redesigning that control remains a distinct WebChat product decision.

## What This Changes

The issue requests a WebChat option to suppress, replace, or make less intrusive the “New messages” catch-up banner.

## Best Possible Solution

Choose and document a persisted WebChat presentation mode that preserves a reachable manual catch-up action—such as a smaller/dismissible indicator or a dedicated “hide indicator” mode—then cover all auto-scroll modes with focused scroll and render tests.
