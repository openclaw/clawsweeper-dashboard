## Summary

Keep open. Current main and the latest release have WebChat auto-scroll modes, but the New messages catch-up button is still a separate always-rendered affordance when `chatNewMessagesBelow` is set, and a member comment already confirms the remaining banner preference is a product decision.

## What This Changes

The issue requests a WebChat option or setting to disable, customize, or replace the New messages notification banner.

## Best Possible Solution

Add a browser-local New messages indicator mode that preserves an accessible jump-to-latest affordance, and keep retired WebChat gateway config closed unless maintainers explicitly choose operator-level policy.
