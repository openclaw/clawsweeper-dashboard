## Summary

Keep open. Current main added WebChat auto-scroll modes, but the New messages catch-up button is still controlled directly by scroll state and has no separate disable, dismiss, or customize preference.

## What This Changes

The issue requests a WebChat setting or mode to disable, replace, or make less intrusive the New messages banner.

## Best Possible Solution

Add a browser-local, maintainer-approved New messages indicator mode that preserves an accessible jump-to-latest affordance and keeps retired WebChat gateway config closed unless intentionally reopened.

- **Browser-local indicator mode (recommended):** Add a persisted Control UI/WebChat setting for indicator behavior while retaining an accessible jump-to-latest action.
