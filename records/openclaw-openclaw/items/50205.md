## Summary

Keep open: current main and the latest release still lack a Google/Vertex request-label config contract or payload injection, while the issue discussion shows a concrete billing-attribution need that requires a maintainer product/config decision.

## What This Changes

The issue requests configurable labels on outbound Google/Vertex Gemini requests so operators can attribute GCP billing by deployment or workload.

## Best Possible Solution

Keep this issue open as the canonical request and, after maintainer approval, add a provider-owned Vertex-only label contract with validation, docs, schema/transport tests, and redacted live Vertex proof.

## Reproduction Assessment

Yes, at source level. The proposed `requestLabels` provider key is rejected by the strict model-provider schema, and the current Google/Vertex request builder has no `labels` field to send.

## Solution Assessment

Unclear until maintainers choose the contract. A provider-owned, Vertex-only label field is the likely maintainable path; a broad generic request-body escape hatch would conflict with the repo's high bar for config surface.
