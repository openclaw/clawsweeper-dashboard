## Summary

Keep open: current main and the latest release still lack a Google/Vertex request-label config contract or payload injection, while the issue discussion shows a concrete GCP billing-attribution need that needs maintainer product/config approval.

## What This Changes

The issue requests configurable Google/Gemini request labels, primarily for Vertex AI billing attribution, from OpenClaw provider config into outbound generateContent requests.

## Best Possible Solution

Keep this issue as the canonical request and, if maintainers approve it, add a provider-owned Vertex-only static label contract with strict GCP validation, docs, schema/transport tests, and redacted live Vertex proof.

## Solution Assessment

Unclear until maintainers choose the contract. A provider-owned, Vertex-only static label field is the likely maintainable path; a broad generic request-body escape hatch would conflict with OpenClaw's high bar for config surface.
