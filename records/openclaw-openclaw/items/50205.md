## Summary

Keep open: current main and v2026.6.11 still have no Google/Vertex request-label config contract or payload injection, while the issue discussion and Google’s current docs show a real billing-attribution use case that needs a maintainer product/config decision.

## What This Changes

The issue requests configurable labels on outbound Google Gemini or Vertex generateContent requests so GCP billing can be grouped by deployment, environment, or workload.

## Best Possible Solution

Keep this issue open as the canonical request; after maintainer approval, add a Google-plugin-owned Vertex-only static label contract with validation, docs, schema/transport tests, and redacted live Vertex proof, while deferring dynamic high-cardinality labels unless explicitly approved.
