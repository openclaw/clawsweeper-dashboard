## Summary

Keep open: current main still lacks a Google/Vertex request-label config surface and the Google transport does not add billing labels to Gemini request bodies; the remaining work is a provider/config product decision rather than a narrow bug repair.

## What This Changes

Request configurable Google/Vertex Gemini request labels for GCP billing attribution.

## Best Possible Solution

Add a maintainer-approved, Vertex-aware label config path in the Google plugin with GCP label validation, focused transport/schema tests, and docs; defer dynamic agent/skill/session labels unless maintainers explicitly choose that scope.

## Solution Assessment
