## What This Changes

This PR retains discovered plugin metadata for ClawHub-spec uninstall targets so plugin-owned channel configuration can be removed, and synchronously releases the package lifecycle lease when a CLI exit bypasses asynchronous cleanup.

## System Context

The plugin CLI resolves a user-supplied plugin name or package spec against installed-plugin metadata before handing the selected plugin to uninstall ownership logic. Separately, package install and adoption operations hold a SQLite-backed lifecycle lease so concurrent package actions do not conflict; the lease must be released on both normal completion and forced CLI termination.
