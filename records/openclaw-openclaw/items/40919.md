## Summary

Keep open: current main still builds full dirty session transcript entries and rewrites all indexed chunks for a changed session file. The existing embedding cache mitigates repeated embedding calls, but the requested row-preserving incremental session sync is not implemented on main and the open candidate PR is still only a design/proof path.
