## Summary

Keep open: current main and v2026.6.11 still rebuild dirty session JSONL files as full transcript entries and clear existing session chunks before rewriting them. ## What This Changes

The issue requests incremental session-memory indexing for growing JSONL transcripts instead of full delete-and-reinsert syncs on each dirty session update.

## Best Possible Solution

Keep this issue canonical and land a current memory-core design that preserves unchanged session chunks on append while falling back to full reindex for compaction, rewrites, model/config changes, and unsafe boundary cases.
