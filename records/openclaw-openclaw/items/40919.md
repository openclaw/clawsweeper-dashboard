## Summary

Keep open: current main and the latest release still build full session transcript entries for dirty JSONL files and clear existing session chunks before reinserting regenerated chunks. The issue remains the canonical tracker; the open candidate PR is conflicting and still needs maintainer design/proof work.

## What This Changes

The issue reports that session memory JSONL sync reindexes growing transcripts with a delete-and-reinsert pattern instead of preserving unchanged indexed chunks.

## Best Possible Solution

Keep this issue canonical and land a current memory-core fix that preserves unchanged session chunks across direct and source-wide indexing paths, with overlap, compaction, schema-upgrade, and real-behavior proof.
