## Summary

Keep open: current main and the latest release still build full session transcript entries for dirty JSONL files and clear indexed chunks before reinserting them. The open candidate PR is conflicting and has already been assessed as obsolete against the current memory index schema, so this issue remains the canonical tracker for a current-schema design.

## What This Changes

The issue requests incremental session-memory JSONL indexing so growing transcripts do not trigger repeated full delete-and-reinsert embedding work.

## Best Possible Solution

Implement a current-schema incremental session sync that preserves unchanged chunks, reprocesses overlap-safe boundary chunks, falls back to full reindex on rewrites/compaction, and covers FTS, vector, source-wide batch, and upgrade behavior.
