## Summary

Keep open: current main and v2026.6.11 still reject Feishu/Lark plain non-topic group `thread=true` current-conversation subagent binding, while the related open and merged work covers broader policy or topic-specific routing rather than this exact plain-group contract.

## What This Changes

Restore Feishu/Lark plain group-chat `sessions_spawn({ thread: true, mode: "session" })` binding so each group can keep a dedicated subagent/persona.

## Best Possible Solution

Define the Feishu plain-group current-conversation binding contract, then align the plugin-owned resolver, inbound routing, docs, and regression tests while preserving existing DM and topic behavior.
