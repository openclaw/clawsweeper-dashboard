## Summary

Keep open: current main and v2026.6.11 still reject Feishu/Lark plain non-topic group `thread=true` current-conversation subagent binding, while source, tests, and docs keep support limited to DMs or topic conversations.

## What This Changes

Restore Feishu/Lark plain group-chat `thread=true` subagent binding so `mode="session"` spawns can bind persistent subagent sessions outside DMs and topic threads.

## Best Possible Solution

Define the Feishu plain-group binding semantics, then update the plugin-owned resolver/binding path, inbound routing, docs, and regression tests while preserving documented static `bindings` as the per-group agent routing alternative.

## Reproduction Assessment

Yes, source-level. Current main rejects non-topic Feishu group current-conversation binding and existing tests assert the reported error; no live Feishu/Lark tenant was run in this read-only review.

## Solution Assessment

Unclear as an implementation choice. Enabling plain groups mechanically is plausible, but the maintainable fix needs a maintainer-approved policy for whole-group versus sender-scoped/static/topic-only binding semantics.
