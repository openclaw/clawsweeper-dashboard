## Summary

Keep open: current main and the latest release still do not route plain non-topic Feishu/Lark group conversations through current-conversation binding, and the remaining decision is the group binding contract rather than stale cleanup.

## What This Changes

The issue asks to restore `thread=true` persistent subagent binding for Feishu/Lark group chats so different business groups can route to dedicated agent personas.

## Best Possible Solution

Define the Feishu plain-group current-conversation binding contract, then implement it in the plugin-owned resolver/inbound routing path with regression coverage and docs while preserving existing DM and topic behavior.
