## Summary

Keep open: current main and the latest release still reject Feishu/Lark non-topic group `thread=true` subagent binding, while the related merged core-thread refactor only covers shared mechanics and the open Feishu PR targets topic affinity rather than plain group binding.

## What This Changes

The issue requests restoring Feishu/Lark group-chat `sessions_spawn({ thread: true, mode: "session" })` binding so different non-topic group chats can stay bound to dedicated subagents.

## Best Possible Solution

Define the Feishu plain-group current-conversation binding contract, then align the plugin-owned resolver/binding path, inbound routing, docs, and regression tests while preserving existing DM and topic behavior.

## Reproduction Assessment

## Solution Assessment
