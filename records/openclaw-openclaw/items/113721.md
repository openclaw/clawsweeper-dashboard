## Summary

This PR addresses the open watchdog-timeout bug with a focused post-normalization propagation path and credible real-runtime evidence. The configured ceiling intentionally allows affected streams to run longer, but that behavior is documented, opt-in, and still bounded by explicit run budgets; it should remain open for normal maintainer merge review rather than cleanup.

## What This Changes

The PR preserves `models.providers.<id>.timeoutSeconds` on resolved runtime models after provider-plugin normalization and for inline/native model paths so embedded-agent stream watchdogs honor the configured ceiling.

## System Context

Provider configuration is resolved into runtime model objects before embedded-agent streaming begins. The stream layer reads `requestTimeoutMs` from that resolved model to calculate idle and first-event watchdog limits.
