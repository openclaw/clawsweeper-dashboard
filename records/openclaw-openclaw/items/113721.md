## Summary

This PR remains necessary: current main carries the provider timeout into ordinary resolved-model paths, but the documented timeout can still be lost when a provider plugin legally rebuilds the model during normalization. The patch restores that contract at the terminal model-resolution boundary, preserves explicit run-budget precedence, and includes credible live before/after proof; the remaining action is normal maintainer review after the current required checks complete.

## What This Changes

The PR preserves an existing provider `timeoutSeconds` setting through provider-plugin model normalization and into embedded-run stream watchdogs, including inline-provider and native-harness model paths.

## System Context

Provider configuration is resolved into a runtime model before an embedded agent starts an LLM stream. Provider plugins may normalize that model, and the resulting runtime model supplies timeout facts to the idle and first-event watchdogs that decide whether to abort a silent stream.
