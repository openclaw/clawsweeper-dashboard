## Summary

Keep this PR open: the current-main ordering can lose the provider timeout when a provider plugin rebuilds a resolved model, and the proposed terminal normalization boundary is a plausible repair. Before merge, it needs redacted after-fix proof from a real configured provider run, not only mock-based regression tests.

## What This Changes

The branch reapplies a provider’s existing `timeoutSeconds` setting after plugin model normalization, carries it into inline and native-harness models, and types the runtime model so stream watchdogs can use the value directly.

## System Context

Embedded-agent model resolution combines configured provider settings, discovered models, and provider-plugin hooks into the runtime model used for an agent attempt. Stream watchdogs then use that model’s request timeout to decide how long to wait for an initial event or further stream activity.
