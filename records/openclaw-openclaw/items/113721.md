## What This Changes

The PR makes an existing provider `timeoutSeconds` setting survive provider-plugin model normalization and native/inline model construction so embedded-agent stream watchdogs honor the configured ceiling.

## System Context

Provider configuration is transformed into a resolved runtime model before an embedded agent starts streaming. The idle and first-event watchdogs then read the model’s prepared timeout value together with any run-level limit to decide when to abort a silent stream.
