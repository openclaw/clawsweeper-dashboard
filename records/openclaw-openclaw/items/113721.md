## What This Changes

The PR preserves `models.providers.<id>.timeoutSeconds` on resolved provider runtime models after plugin normalization and on inline/native model paths, allowing the embedded-agent stream watchdogs to use the configured ceiling.

## System Context

Provider configuration is converted into a resolved runtime model before an embedded agent starts its LLM stream. The stream watchdog then reads the model timeout to decide how long to wait for a first event or later activity.
