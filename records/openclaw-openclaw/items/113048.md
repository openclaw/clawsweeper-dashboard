## What This Changes

This PR adds a lightweight Codex native-hook relay entrypoint, bounded per-relay admission and duplicate coalescing, plus cancellation and overload handling to avoid launching a full OpenClaw CLI process for ordinary hook requests.

## System Context

Codex-backed agent hooks send policy-related events through OpenClaw's native-hook relay to the long-lived Gateway, which owns the final approval and hook decisions. This PR changes the short-lived transport process and the Gateway-side relay admission path so bursts cannot create unbounded concurrent policy work.
