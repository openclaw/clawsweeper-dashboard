## Summary

Keep open. The previously raised Bun-runtime blocker remains at the same head: the new fast relay starts through `process.execPath` with Node-specific flags and a `node:sqlite` entry, so Bun-based installations can fail native hooks before the existing CLI fallback is reached. The PR body also lacks an inspectable redacted after-fix run on a real affected Gateway host.

## What This Changes

This PR adds a bounded lightweight subprocess for normal Codex native-hook relay requests, retaining the full CLI route for explicit overrides and selected fallback cases.

## System Context

Codex invokes OpenClaw native hooks as subprocesses; those subprocesses read a relay registration and forward hook requests to the long-lived Gateway, where policy and approvals remain authoritative. This PR changes the subprocess entry and adds per-relay admission control before requests reach Gateway policy handlers.
