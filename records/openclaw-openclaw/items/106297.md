## Summary

This PR addresses the reported runaway loop, but its new embedded-run abort path bypasses the existing agent-core tool-result termination contract and converts a normal critical-loop stop into an aborted assistant terminal outcome. The branch also still lacks after-fix proof from a real OpenClaw run. Likely related people: @steipete (high confidence), plus @akramcodez and @gumadeiras (medium confidence) from the tool-loop feature history.

## What This Changes

Adds an embedded-run helper that aborts critical blocked tool-loop results across direct-tool and Tool Search execution paths, with focused helper tests.

## Best Possible Solution

Mark critical tool-loop blocked results with the existing terminate contract, add a post-turn mixed-batch check at the shared agent-core/session boundary, and prove a real run stops after the critical veto without producing another provider turn or an unintended aborted transcript entry.

## Solution Assessment

No. Stopping the runaway loop is correct, but the narrow maintainable fix should use agent-core's existing terminate and post-turn contracts rather than aborting the embedded attempt from tool wrappers.
