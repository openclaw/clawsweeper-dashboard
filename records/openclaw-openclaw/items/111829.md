## Summary

Keep this PR open: it addresses a valid current-main metadata privacy bug, but its new completeness guard recognizes prefixed reasoning tags that the shared sanitizer does not remove, so some completed reasoning blocks can still be persisted in generated titles.

## What This Changes

The PR sanitizes generated conversation labels and returns no label when it detects an unclosed reasoning block, with regression coverage for basic `<think>` output.

## Best Possible Solution

Use one canonical reasoning-tag grammar in the shared sanitizer, have label generation rely on that grammar for both closed and unclosed cases, and add prefixed-tag regressions before merging.
