## What This Changes

The PR changes hosted official plugin catalog response decoding to use a fatal UTF-8 decoder so malformed bytes fail before JSON parsing.

## Best Possible Solution

Retain the fatal UTF-8 decode at the hosted-catalog boundary and add a focused regression test that supplies invalid bytes, asserts the decode fails, and confirms the established catalog fallback path remains usable.
