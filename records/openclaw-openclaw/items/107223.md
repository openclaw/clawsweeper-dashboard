## Summary

## What This Changes

Prevent a post-update startup-migration checkpoint mismatch from permanently blocking the Gateway when legacy migration sources are already imported or safely archived.

## Best Possible Solution

Ship the unified convergence fix in the next release: safely archived or SQLite-authoritative residue should become a notice and allow checkpoint completion, while divergent state and archive failures remain startup-blocking warnings; do not add an environment variable that bypasses the migration safety gate.
