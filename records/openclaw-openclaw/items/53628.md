## Summary

Keep open: current main and v2026.6.11 still route configured workspace paths through a resolver that only expands `~`, so skill installs can still land under a literal `${XDG_CONFIG_HOME}` path. ## What This Changes

The issue asks skill installs to expand `${XDG_CONFIG_HOME}`-style env placeholders before resolving the workspace skill install directory.

Land or replace the linked resolver-level fix with focused workspace and skill-install coverage plus a documented env placeholder boundary that stays consistent with config substitution and dotenv behavior.
