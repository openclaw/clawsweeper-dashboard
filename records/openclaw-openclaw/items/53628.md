## What This Changes

The issue asks OpenClaw to expand `${XDG_CONFIG_HOME}` instead of using it as a literal directory segment when installing a ClawHub skill.

## Best Possible Solution

Adopt or replace the open fix path with a maintainer-approved shared resolver change that expands known `$VAR` and `${VAR}` placeholders, preserves clear behavior for unset variables, and adds path plus skill-install regression coverage.
