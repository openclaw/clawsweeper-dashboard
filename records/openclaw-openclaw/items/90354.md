The issue requests runtime-level bounded, validated, and de-duplicated append semantics for pre-compaction memory-flush writes to daily memory files.

## Best Possible Solution

Keep this issue open until https://github.com/openclaw/openclaw/pull/96291 or a successor lands a maintainer-approved built-in daily-memory guard with bounds, scaffold rejection, de-dupe, and telemetry; defer any external validator hook to a separate security-reviewed design.
