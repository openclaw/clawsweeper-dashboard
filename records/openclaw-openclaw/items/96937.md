## Summary

Keep this PR open, but it is not ready to merge: the current patch rejects `search_context_size` on Perplexity’s native Search API even though Perplexity documents that parameter for that endpoint, and it still lacks redacted after-fix live-provider proof. The earlier P1 contract finding remains unresolved on the same head.

## What This Changes

The PR adds a low/medium/high search-context budget to OpenClaw’s shared `web_search` tool, forwarding it through Perplexity Sonar/OpenRouter chat completions while documenting and rejecting it for the native Perplexity Search API.

## System Context

OpenClaw exposes a model-facing `web_search` tool, then routes each invocation to a configured provider plugin. The Perplexity plugin selects either the native Search API or a Sonar/OpenRouter chat-completions compatibility transport and must map tool parameters to the contract for that selected endpoint.
