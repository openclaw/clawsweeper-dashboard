Full review comments:

- **[P2] Handle tab-stripped heredoc terminators:** `src/agents/tool-display-exec-shell.ts:258`
  - body: The scanner recognizes `<<-` but the body loop compares `lineContent === heredocDelimiter` without stripping leading tabs. A valid command like `cat <<-EOF\nbody\n\tEOF\ncmd && other` never exits heredoc mode, so the real `&&` after the terminator is skipped and the displayed stages can hide follow-up commands.
  - confidence: 0.88
- **[P2] Keep terminator collection quote-aware:** `src/agents/tool-display-exec.ts:309-316`
  - body: Replacing `scanTopLevelChars` with a raw loop makes `collectHeredocTerminators` treat quoted text such as `printf '<<EOF'` as a real heredoc opener. When a later line matches that token, `commandWithoutHeredocBodies` can drop real command lines from the summary, which is a regression from the current quote-aware scan.
  - confidence: 0.82
