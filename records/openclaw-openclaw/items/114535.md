## What This Changes

The PR moves Skill Workshop proposal records and rollback claims from legacy JSON metadata into additive shared SQLite tables so pending proposals survive interrupted applies and agent workspace moves.

## System Context

Skill Workshop stores proposed skill changes, lets users inspect or apply them, and writes the approved skill into an agent workspace. This PR moves the proposal lifecycle and rollback metadata into OpenClaw’s shared SQLite state database while retaining `PROPOSAL.md` and support files as reviewable on-disk artifacts.
