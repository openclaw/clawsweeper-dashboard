## Summary

Keep open: the cache-fingerprint normalization is aimed at the right bug, but the patch imports the sanitizer through the process-default runtime barrel, adding runtime side effects to pure agent helpers; the external PR also has only unit-test/CI proof so far.

## What This Changes

The PR makes `stableStringify` strip unpaired UTF-16 surrogates from string values and object keys, adds regression coverage, and reuses the same sanitizer in the shared transport payload helper.

## Best Possible Solution

Keep the narrow surrogate normalization, but import the sanitizer through a no-default-runtime path such as a light `@openclaw/ai/internal/shared` export and add real behavior proof for the cache fingerprint path.
