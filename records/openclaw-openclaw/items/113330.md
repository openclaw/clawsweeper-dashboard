## What This Changes

Adds redaction for Shopify `shpat_`, `shpca_`, `shppa_`, and `shpss_` 32-hex credentials in logging and diagnostics, including prefilter reachability and chunk-boundary coverage.

## System Context

OpenClaw sends log lines, diagnostic output, and tool-oriented text through a shared sensitive-text redactor before those strings are displayed or bundled. The redactor uses a cheap prefilter before applying token patterns, and runs patterns that can cross a chunk boundary against the full input.
