## What This Changes

This PR adds Shopify-prefixed 32-hex-character secrets to the default log-redaction patterns, ensures the fast prefilter reaches that pattern, and adds focused regression coverage.

## System Context

OpenClaw’s logging redactor receives text from tool and diagnostic logging surfaces and masks recognized credentials before those values are displayed or included in support output. A prefix prefilter avoids running the full pattern set for ordinary text, so every new vendor-token pattern must also be reachable through that prefilter.
