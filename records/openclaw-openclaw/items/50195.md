## Summary

Keep open: current main and v2026.6.11 still lack the requested WhatsApp pre-built linkPreview pass-through, opt-in automatic high-quality preview config, and send.batch Gateway RPC. The request is valid, but it bundles a narrow Baileys-supported pass-through with SSRF-sensitive URL fetching and a new Gateway protocol surface that need maintainer product and security direction before implementation.

## What This Changes

The issue requests WhatsApp pre-built link-preview pass-through, optional automatic high-quality preview fetching, and a batch Gateway send RPC for bulk sends.

## Best Possible Solution

Split the work: add a typed WhatsApp-owned pre-built linkPreview pass-through first, then design automatic preview fetching and batch Gateway sending separately with explicit security and protocol semantics.

## Reproduction Assessment

Yes, source-level: current main has no WhatsApp linkPreview input path, no preview-fetching config/socket option, and no send.batch Gateway method. This is a missing capability rather than a runtime bug reproduction.

## Solution Assessment

No as one combined change. The pre-built preview pass-through is a narrow dependency-supported increment, but automatic URL fetching and batch Gateway sending should be separate maintainer-approved designs.
