## Summary

Keep open: current main and v2026.6.11 still lack WhatsApp pre-built linkPreview pass-through, an opt-in automatic preview-fetch setting, and a send.batch Gateway RPC. The request is valid, but it bundles a narrow WhatsApp plugin enhancement with SSRF-sensitive URL fetching and a new Gateway protocol surface, so maintainer product and security decisions are still needed.

## What This Changes

Request support for pre-built WhatsApp link preview payloads, a configurable Baileys high-quality preview option, and a batch outbound send RPC for bulk message workflows.

## Best Possible Solution

Split the work: add a typed WhatsApp-owned pre-built linkPreview pass-through first, then design automatic preview fetching and Gateway batch sending separately with explicit security and protocol semantics.

## Reproduction Assessment

Yes. Source inspection on current main shows no WhatsApp linkPreview input path, no preview-fetching config/socket option, and no send.batch Gateway method while Baileys supports the underlying text linkPreview pass-through.

## Solution Assessment

No as one combined change. The pre-built preview pass-through is a narrow dependency-supported increment, but automatic URL fetching and batch Gateway sending should be separate maintainer-approved designs.
