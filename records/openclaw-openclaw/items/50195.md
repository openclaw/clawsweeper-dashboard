Request support for WhatsApp pre-built link preview payloads, an opt-in high-quality preview-fetch config, and a batch send Gateway RPC.

## Best Possible Solution

Use a staged maintainer-approved design: add a safe WhatsApp pre-built `linkPreview` pass-through first, then separately decide the opt-in fetch policy and any additive batch-send Gateway contract with explicit security and delivery semantics.
