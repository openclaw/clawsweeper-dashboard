## What This Changes

The issue requests separate outbound WhatsApp bubbles for blank-line-separated automatic replies from the Codex runtime when newline chunking is configured.

## System Context

Automatic replies flow from an agent runtime into the shared outbound message planner, which converts text and chunking policy into channel send units. WhatsApp and other channel adapters then deliver those units as visible message bubbles.
