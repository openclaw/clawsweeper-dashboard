## What This Changes

Define whether `chunkMode: "newline"` should keep blank-line-separated automatic-reply paragraphs as separate outbound messages instead of packing adjacent paragraphs into one WhatsApp bubble.

## System Context

Automatic replies pass completed agent text to the shared outbound message planner before a channel transport sends it. The planner turns text into channel-sized units, so its newline-mode semantics determine whether a WhatsApp recipient receives one bubble or several.

## Best Possible Solution

Maintain one explicit shared newline-mode contract: either retain paragraph packing, or land a planner-level preserve-paragraph policy with upgrade-impact tests and clear channel-wide semantics rather than a Codex- or WhatsApp-only heuristic.
