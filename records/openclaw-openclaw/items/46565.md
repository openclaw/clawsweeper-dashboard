## Summary

Issue #46565 should remain open: current main has fixed subagent/cron bootstrap allowlists and some current-time support, but it still lacks the requested first-class deterministic bootstrap selector/session-type filtering and any safe dynamic command-expansion contract.

## What This Changes

The issue requests configurable deterministic bootstrap context injection, session-type filtering/exclusion for bootstrap files, dynamic command expansion, and always-available time/timezone context.

## Best Possible Solution

Define one maintainer-approved bootstrap context contract first: a safe selector/tier API that preserves current defaults, with command expansion deferred unless it has an explicit sandboxed and auditable design.
