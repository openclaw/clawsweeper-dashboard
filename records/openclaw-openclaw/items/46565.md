## Summary

Keep open: current main has fixed subagent, cron, and lightweight bootstrap filtering plus documented timezone/session-status support, but it does not implement the requested public bootstrap selector contract, bootstrap `!command` expansion, or built-in deterministic per-session context surface.

## What This Changes

Request deterministic dynamic bootstrap context through command expansion, session-type filtering, and built-in time/timezone context.

## Best Possible Solution

Design one maintainer-approved bootstrap context contract that preserves safe defaults, keeps command execution behind an explicit reviewed boundary, and aligns the related subset PRs instead of adding another ad hoc selector.
