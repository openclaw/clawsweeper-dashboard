## Summary

Keep open: current main and v2026.6.11 cover only parts of the request with hardcoded subagent/cron bootstrap filters, heartbeat lightweight mode, and cache-stable timezone guidance; the requested public bootstrap selector, bootstrap command expansion, and general live-time contract still need maintainer design.

## What This Changes

Request deterministic bootstrap context controls: dynamic bootstrap-file injection, session-type filtering, and built-in current-time/timezone context for autonomous, heartbeat, cron, and subagent sessions.

## Best Possible Solution

Define one maintainer-approved bootstrap context contract that separates session-scoped file selection, safe dynamic context execution, and cache-stable time access before landing overlapping point fixes.
