## Summary

Keep open: current main has fixed subagent, cron, heartbeat-light-context, and timezone guidance pieces, but it still lacks the requested public bootstrap selector, bootstrap command expansion, and deterministic per-session context contract.

## What This Changes

The issue requests dynamic bootstrap-file command expansion, session-type filtering for injected bootstrap context, and built-in time/timezone context for agent runs.

## Best Possible Solution

Define one maintainer-approved bootstrap context contract that preserves safe defaults, keeps command execution behind an explicit reviewed boundary, and aligns the narrower bootstrap PRs under that design.
