## What This Changes

Request deterministic bootstrap context controls: dynamic bootstrap-file injection, session-type filtering, and built-in time context for agent sessions.

## Best Possible Solution

Define one maintainer-approved bootstrap context contract that keeps defaults cache-stable, adds narrowly scoped session selectors if desired, and treats command-backed dynamic content as a separate sandboxed or hook-owned security design.
