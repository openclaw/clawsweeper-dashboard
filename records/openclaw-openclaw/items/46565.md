## Summary

Keep open: current main partially addresses the report with hardcoded subagent/cron bootstrap filtering and cache-stable timezone guidance, but the requested public session-type selector, bootstrap command expansion, and live time contract still need maintainer direction.

## What This Changes

Request deterministic bootstrap context controls for dynamic bootstrap content, session-type filtering, and reliable time/timezone context.

## Best Possible Solution

Define one security-reviewed declarative bootstrap policy for session-scoped context, keep live clock data on the session_status/envelope path unless maintainers approve dynamic prompt time, and land related subset PRs only when they fit that contract.
