## Summary

Keep open: current main and v2026.6.11 solve only parts of the request with hard-coded subagent/cron bootstrap filtering and cache-stable timezone guidance; configurable bootstrap selection and bootstrap command expansion still need maintainer product and security review.

## What This Changes

The issue requests dynamic bootstrap-file command expansion, session-type-aware bootstrap filtering, and built-in time/timezone context for agent sessions.

## Best Possible Solution

Define one additive bootstrap context contract that preserves current safe defaults, settles session selector semantics, and routes dynamic computation through an explicitly reviewed plugin/hook or security-gated core API.
