## Summary

Keep open: current main has some fixed bootstrap filtering, but the requested public session-selector contract, bootstrap command expansion, and deterministic time-context behavior are still unresolved product and security work.

## What This Changes

Request a deterministic bootstrap-context system with dynamic bootstrap-file injection, session-type filtering, and built-in time context for autonomous agents, subagents, heartbeats, and scheduled work.

## Best Possible Solution

Define one maintainer-approved bootstrap context contract that keeps safe defaults, separates stable and dynamic prompt surfaces, and treats command execution as a separate explicit security boundary.

Options:

- **Narrow selector API first (recommended):** Add a small maintained bootstrap tier or selector contract and defer command expansion until a separate security model is approved.
- **Plugin hook only:** Route dynamic per-session context through documented hooks and keep core bootstrap loading limited to safe built-in files.
- **Full command expansion:** Pursue bootstrap command expansion only with explicit sandboxing, provenance, opt-in behavior, upgrade-safe docs, and focused security tests.
