## What This Changes

The branch routes MiniMax web-search credentials through the shared resolver so configured environment SecretRefs take precedence over MiniMax Token Plan fallbacks and unresolved SecretRefs do not fall back to ambient tokens.

## System Context

The MiniMax plugin provides a web-search adapter that merges web-search configuration with plugin configuration, chooses a credential, and sends an authenticated request to MiniMax. Credential selection determines whether the adapter uses an explicit configured key, a referenced environment secret, or documented provider environment fallbacks.
