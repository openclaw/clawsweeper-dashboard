## What This Changes

Request native Opus codec support for the Voice Call plugin and realtime voice plugin surface so telephony providers are not limited to PCMU/G.711 audio.

## Best Possible Solution

Define a maintainer-approved realtime voice codec contract, then add Opus or a documented codec negotiation/transcoding path with Voice Call tests, plugin SDK docs, and redacted live carrier proof.

## Reproduction Assessment

No high-confidence live reproduction was performed against current main. Source inspection does show the current realtime voice and Telnyx streaming paths only expose PCMU/G.711 and PCM16 shapes, so the missing Opus capability is reproducible from code.

## Solution Assessment

Unclear. Native Opus support is a plausible direction, but the best fix should start with a maintainer codec/API decision and live carrier proof rather than changing the hardcoded PCMU path in isolation.
