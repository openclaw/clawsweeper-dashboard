## Summary

Keep open: current main and the latest release still hard-code the voice-call Telnyx realtime stream to PCMU and the shared realtime voice contract has no Opus format, but adding Opus is a feature/product decision rather than a narrow bug-fix automation item.

## What This Changes

Requested native Opus codec support for the Voice Call plugin so international or high-jitter phone-call paths can avoid the current G.711/PCMU-only realtime media path.

## Best Possible Solution

Keep this open for maintainer design: add Opus through the voice-call plugin and shared realtime audio contract with explicit codec negotiation or selection, upgrade-safe config/docs, focused tests, and live Telnyx/provider proof.

## Reproduction Assessment

No. The reporter gave a concrete Telnyx Opus-only workflow and current source confirms a PCMU-only implementation, but this review did not place a live Telnyx Opus-only call to reproduce the immediate disconnect.

## Solution Assessment

Unclear. The request is valid, but a direct hardcode from PCMU to Opus would not be the best fix; the maintainable path is a provider/codec contract with compatibility, dependency, docs, and live proof.
