  - body: When a target Claw adds a workspace/persona entry and the applied Claw has no persisted workspace refs, this fallback makes `claws update ... --dry-run --json` plan against `process.cwd()`. Late discovery: this code was unchanged from the previously reviewed head, but the gap is clear after comparing it with the apply safety contract.
