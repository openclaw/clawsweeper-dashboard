## Summary

Keep this PR open, but do not merge it yet: it handles npm 12’s single-element metadata arrays and protects parser failures, while leaving transient pre-install `npm view` failures able to disable healthy plugins and still providing only test-based proof.

## What This Changes

Accepts single-element npm metadata arrays and adds an install error classification that prevents selected metadata parsing failures from disabling plugins or removing their activation state.

## Best Possible Solution

Classify every failure before package installation or state mutation as non-destructive, preserve the existing plugin entry, allowlist, and slot state, retain fail-closed handling for integrity, scanner, policy, and post-install failures, and prove the result with a live npm 12 update transcript.
