## What This Changes

Accepts singleton-array npm metadata and adds an install error classification that prevents selected metadata parsing failures from disabling plugins or removing their activation state.

## Best Possible Solution

Tie destructive disablement to failures after replacement-package installation or validation has begun; every earlier resolution or registry failure should report the error while preserving the existing plugin configuration and slots, with integrity and security failures remaining fail-closed.
