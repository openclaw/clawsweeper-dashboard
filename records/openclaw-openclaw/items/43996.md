## Summary

Keep open: current main and the latest release still add Docker `--security-opt no-new-privileges` to sandbox containers unconditionally, the direct fix PR is closed unmerged, and the remaining recovery choice changes a sandbox security boundary.

## What This Changes

This issue reports Docker-backed sandbox containers exiting with `exec /usr/bin/sleep: operation not permitted` on affected hosts and requests an opt-out, fallback, or clearer diagnostic for `no-new-privileges`.

## Best Possible Solution

Keep `no-new-privileges` enabled by default, then add a maintainer-approved explicit dangerous opt-out and diagnostic path with real Docker proof on an affected host.
