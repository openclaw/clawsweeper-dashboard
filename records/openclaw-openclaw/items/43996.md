Options:

- **Explicit Dangerous Override (recommended):** Add a documented `sandbox.docker` opt-out that defaults to the current secure behavior and reports weakened sandboxes in status, doctor, and dangerous-config output.

- **Narrow EPERM Fallback:** Retry without the flag only for a tightly detected startup EPERM and record the runtime as weakened for audit/status visibility.
