## Summary

Keep open: current main and the latest release still add Docker `--security-opt no-new-privileges` unconditionally for sandbox containers, and the only direct fix PR is closed unmerged. ## What This Changes

Docker sandbox sessions on affected hosts fail when OpenClaw always creates containers with `--security-opt no-new-privileges`, and the reporter asks for an opt-out, fallback, or clearer diagnostics.

## Best Possible Solution

Keep `no-new-privileges` as the secure default, then add a maintainer-approved recovery path with explicit weakened-sandbox status, doctor/security-audit visibility, focused tests, and real Docker proof on an affected host.
