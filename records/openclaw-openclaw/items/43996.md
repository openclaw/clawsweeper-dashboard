- **Declare affected hosts unsupported:** Treat Docker hosts that reject no-new-privileges as unsupported for Docker sandbox mode and direct users to another backend or host configuration.

## Solution Assessment

Unclear until the security boundary decision is made. The best narrow mitigation appears to be an explicit dangerous opt-out with secure default and reporting; silent automatic fallback would be riskier.
