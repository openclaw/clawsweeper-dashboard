## Summary

The availability bug is valid, but this should not merge as written because it creates a second security-sensitive request-body timeout implementation instead of using the existing Plugin SDK body reader; required real behavior proof is also missing.

## What This Changes

Adds a timeout that destroys authenticated Raft wake requests whose bodies never finish and adds a real TCP regression test.

## Best Possible Solution

Use the shared Plugin SDK request-body reader with the post-auth 16 KiB and timeout values, preserve Raft-specific JSON and HTTP response mapping, retain the TCP regression test, and attach redacted runtime proof that a partial authenticated wake is closed and never queued.
