## Summary

Keep open: the shared-reader direction is appropriate, but the new declared-oversize fast path bypasses socket destruction and leaves an authenticated incomplete-body resource-hold path; the supplied evidence is also still test-only.

## What This Changes

Uses the shared bounded webhook-body reader for authenticated Raft wake requests, maps timeout and size failures, and adds a raw TCP regression test.

## Best Possible Solution

Keep the shared bounded reader, but make every rejected body path terminate the request connection—either by avoiding the precheck or by explicitly closing after the 413—and cover both incomplete normal-sized and incomplete oversized bodies with raw TCP tests plus a redacted real gateway run.
