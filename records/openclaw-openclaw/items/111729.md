## Summary

Keep this PR open: the defensive filtering is directionally sound, but it changes the object shape used by Feishu’s documented `EventDispatcher` custom-adapter pattern and has no regression or real-runtime proof yet.

## What This Changes

The branch replaces the Feishu webhook payload `Object.assign` with a null-prototype envelope that filters `__proto__`, `constructor`, and `prototype` keys before invoking the Lark event dispatcher.

## Best Possible Solution

Keep the existing `Object.create({ headers: req.headers })` adapter shape, copy only unblocked payload keys into it, add focused regression coverage for normal delivery and blocked keys, then attach redacted terminal proof from a running webhook path.
