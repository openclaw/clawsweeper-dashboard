## Summary

The underlying robustness goal is valid and the contributor supplied strong controlled runtime proof, but the current PR head is incompatible with the shared helper on current main: it passes a third `opts` argument to a two-argument function. Keep this PR open for the narrow helper-contract repair and a refreshed changed-check.

## What This Changes

The PR makes Firecrawl Search and Scrape reject successful JSON responses whose top-level value is `null` or an array, with regression coverage for both malformed envelope shapes.

## Best Possible Solution

Extend the shared object-response reader with the same optional byte-limit parameter as the generic JSON reader, forward it unchanged, and retain the Firecrawl Scrape 64 MiB override while rejecting non-object envelopes.
