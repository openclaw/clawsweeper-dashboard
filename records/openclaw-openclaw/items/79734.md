Full review comments:

- **[P1] Disable preflight mutations before dry-run:** `src/commands/doctor-config-flow.ts:72`
  - body: This still calls `runDoctorConfigPreflight` with the default state/config migration behavior while also enabling corrupt-config repair for `dryRun`. Current preflight can migrate legacy state, copy legacy config, and recover corrupt config before the dry-run branch returns `shouldWriteConfig: false`, so `doctor --fix --dry-run` can mutate disk before it previews anything.
  - confidence: 0.91
- **[P1] Keep dry-run out of repair-mode health paths:** `src/flows/doctor-health.ts:13`
  - body: Skipping the immutable-config assertion does not make the command read-only: the same `--fix --dry-run` options still create a repair-mode prompter, and later Doctor health steps key off `prompter.shouldRepair` to run plugin, state, sandbox, or service repairs. Normalize dry-run into a preview mode before creating the prompter or running health contributions.
  - confidence: 0.88
- **[P1] Redact config values in dry-run diffs:** `src/commands/doctor/finalize-config-flow.ts:25-29`
  - body: The dry-run diff serializes and prints raw old/new config values. OpenClaw config includes sensitive paths such as gateway auth tokens/passwords, provider API keys, and channel tokens, so this can leak secrets into terminals, CI logs, or copied proof unless the diff is rendered through path-sensitive config redaction.
  - confidence: 0.93
