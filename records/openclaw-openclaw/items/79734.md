  - body: `doctor --fix --dry-run` still calls config preflight with `repairPrefixedConfig` enabled and leaves the default state/legacy migrations active.   - confidence: 0.93

  - body: This guard bypasses the immutable-config write assertion for dry-run, but `options.repair` remains true when the prompter is created. Downstream Doctor stages key off `prompter.shouldRepair`, so `--fix --dry-run` can still auto-approve UI builds, structured repairs, service repairs, and other mutation-capable health work.
  - confidence: 0.88
- **[P1] Redact dry-run diff values before printing:** `src/commands/doctor/finalize-config-flow.ts:25-29`
  - body: The preview diff prints old and new config values directly via `JSON.stringify`. OpenClaw config can contain tokens, passwords, API keys, SecretRefs, and channel credentials, so this can leak secrets into terminal output, logs, or copied proof unless the diff uses the existing redaction conventions.
  - confidence: 0.94
