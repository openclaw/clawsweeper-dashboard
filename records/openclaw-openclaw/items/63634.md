## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Cache metadata after the final accepted catalog:** `src/agents/agent-bundle-mcp-runtime.ts:327`
  - body: `cacheToolMetadata()` clears the SDK's cached output validators and task-required tool sets every time it is called. Because this loop calls it once per page but returns tools from all pages, a paginated server can expose a repaired typeless tool from page 1 while a later page clears that tool's outputSchema/task metadata, so `callTool()` no longer enforces the guard. Collect the final accepted tools and cache them once, with regression coverage for an earlier-page outputSchema or required-task tool.
  - confidence: 0.92
