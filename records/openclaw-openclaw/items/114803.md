## What This Changes

The PR prevents `openclaw update` dry runs from deleting managed-service handoffs or writing restart state, rejects dry runs for mutating update subcommands, and forwards parent update options to repair and finalization handlers.

## System Context

The update CLI parses parent and subcommand options, validates the target release channel, then runs preview, update, repair, finalization, or wizard flows. Those flows can clean service handoffs and create restart state, so dry-run handling must stop before any mutation owner is reached.
