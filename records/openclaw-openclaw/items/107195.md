## Summary

The previous Bolt shared-client blocker is fixed on the current head: the timeout now belongs only to dedicated Slack read and lookup clients, while shared Bolt and write clients remain unbounded by default. Focused tests and redacted live output support this boundary, so no actionable patch defect remains.

## What This Changes

The PR adds a 30-second default Axios timeout to dedicated Slack read and lookup WebClients, preserves explicit overrides, and leaves Bolt’s shared client plus write and upload clients without a default timeout.

## Best Possible Solution

Land the separated shared, read, write, and lookup client ownership after the exact head passes required checks, keeping mutation and upload clients unbounded while retaining focused boundary tests and the 30-second read deadline.
