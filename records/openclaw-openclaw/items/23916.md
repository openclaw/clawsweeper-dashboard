## What This Changes

## Best Possible Solution

Adopt one coordinated device-identification UX that shows sanitized client, platform, stable ID, and activity metadata in the CLI, preserves `--json`, updates docs/tests, and coordinates editable labels or notes with the narrower naming issue and open rename PR.
