## Summary

Keep open: the shipped Google Chat classifier fix removed one root cause, but current main still has a pre-session mention gate that can drop Space events before group session creation, and the latest v2026.6.11 report says accepted Space delivery still needs a mention-gating workaround.

## Best Possible Solution

Keep the shipped classifier fix, then live-prove and repair the Google Chat mentioned-Space activation path so @mentioned Space events create `googlechat:group` sessions and replies without requiring operators to disable mention gating globally.
