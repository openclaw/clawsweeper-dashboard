## Summary

Keep open: the modern Google Chat space classifier from https://github.com/openclaw/openclaw/pull/58993 is on current main and documented in v2026.6.11, but it was scoped as a partial fix and recent v2026.6.11 evidence still points to accepted Space events being dropped by mention gating before group-session creation.

## What This Changes

The issue asks OpenClaw to process Google Chat Space/group @mention messages by creating `googlechat:group` sessions instead of accepting the webhook and silently dropping the event.

## Best Possible Solution

Keep this as the canonical mentioned Google Chat Space/group ingress bug until a live-verified fix proves Space @mentions create and process `googlechat:group` sessions, while tracking outbound thread-routing and all-message ingestion separately.
