## Summary

Keep open: current main and v2026.6.11 include the modern Google Chat Space/DM classifier, but Space messages can still be accepted and then dropped by the require-mention gate before `googlechat:group` session creation; the latest issue evidence reports this exact v2026.6.11 failure mode.

## What This Changes

The issue asks for Google Chat Space/group messages that return HTTP 200 to create `googlechat:group` sessions and produce agent responses, matching working DM behavior.

## Best Possible Solution

Keep this issue open until Google Chat @mentions in Spaces reliably pass mention gating, create/process `googlechat:group` sessions, and have live Space proof; keep broader receive-all/OAuth/threading parity on the separate Google Chat routing item.
