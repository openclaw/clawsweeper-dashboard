## Summary

Keep open: current main and v2026.6.11 include the modern Google Chat space classifier, but source inspection and the latest reporter evidence still point to Space @mentions being dropped by mention activation before group session creation.

## What This Changes

## Best Possible Solution

Keep this issue open as the canonical Google Chat mentioned-Space ingress bug until a live-proven plugin fix makes delivered @mentions create and process group sessions; track all-message ingestion and thread leakage separately.
