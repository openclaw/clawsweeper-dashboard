## Summary

Keep open: the merged classifier fix is shipped in v2026.6.11, but current main can still accept Google Chat Space events and skip them before session creation when mention activation does not recognize the app mention, and the latest issue discussion reports exactly that remaining v2026.6.11 behavior.
