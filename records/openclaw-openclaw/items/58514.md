## Summary

Keep open: v2026.6.11 and current main include the merged Space/DM classifier fix, but the issue discussion now has fresh post-release evidence that delivered Space @mentions can still die at Google Chat mention gating before group session creation.

## What This Changes

The issue reports Google Chat Space/group messages returning HTTP 200 without creating `googlechat:group` sessions or agent responses while DMs work.

## Best Possible Solution

Keep this issue as the canonical tracker for mentioned Google Chat Space messages until a live-verified fix proves delivered Space @mentions create and process `googlechat:group` sessions, or maintainers explicitly consolidate the remaining mention-gating work elsewhere.
