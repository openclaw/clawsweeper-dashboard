## Summary

Keep open. Current main exposes context usage and parent/child session lineage, but it still lacks a native context-pressure threshold, parent/operator notification, or recovery-routing contract for saturated child sessions; that remaining behavior needs maintainer product direction and live fleet proof.

## What This Changes

The issue requests native notification and recovery behavior when child or specialist agent sessions reach context saturation while a parent orchestrator continues routing work to them.

## Best Possible Solution

Define a narrow context-pressure signal at the session/subagent boundary and route it through an approved diagnostics or operator-notification surface without creating a broad manager-of-managers framework.
