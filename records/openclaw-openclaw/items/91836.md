## Summary

Keep open. Current main exposes context-budget/session-state data and subagent lineage, but it still lacks native child-session context-pressure thresholds, parent/operator notification, or recovery-routing behavior; that remaining product contract needs maintainer direction and live fleet proof.

## What This Changes

Request native notification and recovery behavior when child or sub-agent sessions reach context saturation so parent orchestrators stop routing work to unresponsive children.

## Best Possible Solution

Define a narrow session context-pressure contract at the session-health/subagent boundary, reusing existing lineage and contextBudgetStatus data with explicit alert and recovery semantics instead of adding a broad manager-of-managers framework.
