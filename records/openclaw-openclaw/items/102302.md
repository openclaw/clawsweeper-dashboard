## Summary

Keep open: the supplied live proof confirms the reported Tailscale Serve failure and the prior documentation finding is fixed, but the patch still permits origin-less cross-site browser subresource requests to use ambient Tailscale identity for protected Control UI reads.

## What This Changes

The PR adds verified Tailscale Serve identity authentication to Control UI bootstrap, assistant-media, and avatar HTTP reads, applies the Control UI origin policy when an Origin header is present, updates documentation, and adds gateway authentication tests.

## Best Possible Solution

Reject cross-site Fetch Metadata requests on tokenless Tailscale Control UI reads even when Origin is absent, preserve explicitly safe non-browser requests through a narrow contract, and add route-level coverage for config, media, and avatar reads.
