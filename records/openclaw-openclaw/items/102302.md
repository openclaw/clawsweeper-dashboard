The PR adds an `http-control-ui` auth surface for Control UI bootstrap, assistant-media, and avatar HTTP reads, gates tokenless Tailscale success by browser origin, updates gateway/web docs, and adds gateway auth regression tests.

## Best Possible Solution

Land a security-reviewed variant that keeps tokenless Tailscale identity limited to Control UI HTTP read routes, preserves whois verification and browser-origin checks, and keeps the public auth docs consistent.
