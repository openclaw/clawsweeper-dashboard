  - body: On the second and later verbose-off tool starts, this branch updates the existing activity line and returns before `freezeStreamingRuns()`. Freeze on every new `toolCallId` and add a regression with assistant text between two hidden tools. This path was unchanged at the prior reviewed head, so this is a late discovery.
  - late: true
  - confidence: 0.98

Long verbose-off sessions therefore accumulate one map entry and a growing ID set per run despite `maxComponents`. Delete all three per-run entries together and cover pruning with a regression. This code was unchanged at the prior reviewed head, so this is a late discovery.
  - late: true
