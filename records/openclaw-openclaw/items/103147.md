## Summary

Keep this PR open, but do not merge it as submitted. The chronological TUI rendering fix is source-backed and well targeted, while the combined branch also changes the local-shell privacy contract, lacks inspectable real-behavior proof, and can persist one failed command twice.

## What This Changes

The PR segments assistant text around tool cards, assigns distinct replay turn identities, persists TUI-local `!`/`!!` commands through a new hidden gateway RPC, replays those entries, condenses tool cards, and adds verbose-off activity summaries.

## Best Possible Solution

Land the chronological rendering repair as a focused TUI change, then design shell-history persistence separately with explicit sharing consent, history-only defaults or a clearly approved alternative, once-only transcript appends, user-facing help, and real PTY proof.
