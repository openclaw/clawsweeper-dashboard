## What This Changes

The branch loads quota snapshots for each eligible configured auth profile, shows them in CLI and gateway status output, and adds an exact-profile usage-read API to the plugin runtime.

## System Context

OpenClaw resolves configured auth profiles, obtains provider-specific usage data, and projects the results into `status --usage`, `models status`, and gateway auth-status responses. This PR changes that path from one provider-level snapshot to profile-bound snapshots while preserving provider grouping for presentation.
