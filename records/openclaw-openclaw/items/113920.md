## What This Changes

This PR loads provider quota snapshots for every eligible configured auth profile, attaches them to matching CLI and gateway status rows, and adds a token-free exact-profile usage-read method to the plugin runtime.

## System Context

OpenClaw resolves configured auth profiles into provider credentials, then provider usage collectors fetch quota data for status surfaces. This change would replace the existing provider-keyed view with profile-keyed snapshots before CLI and gateway presentation.
