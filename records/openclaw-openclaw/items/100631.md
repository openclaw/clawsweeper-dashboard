## What This Changes

The issue requests that `openclaw doctor --fix` remove retired or unreferenced environment-variable entries left after profile and provider migrations.

## Best Possible Solution

Define a narrow doctor-owned pruning contract for env entries known to be generated or retired by a migration, preserve operator-authored config env values, and cover both `openclaw.json` and auth-profile-store cases with regression tests.
