## Summary

Keep open for explicit maintainer product direction. The merged Home/sidebar work establishes navigation and a Pages entry point, but this issue still proposes a new persisted dashboard capability spanning widget ownership, page authoring, storage, gateway APIs, sandbox review, and platform parity.

## What This Changes

Add agent- and user-authored Home dashboard widgets and persistent Pages, reusing the widget renderer with SQLite-backed layout/page state and additive gateway support.

## Best Possible Solution

Sponsor a narrow v1 product spec that chooses the Home placement and refresh model, defines per-agent SQLite ownership and migration approval, reuses the existing widget sandbox/renderer, and limits the first gateway contract to additive page and dock operations before implementation begins.
