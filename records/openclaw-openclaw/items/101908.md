  - body: `DashboardStore` creates `workspace.json` plus JSON undo snapshots under the state directory.   - confidence: 0.99

  - body: The bundle is committed before the widget is added to the active tab. If `dashboard.widget.add` fails, the installed name and files remain, and retrying fails with `widget already exists`.
