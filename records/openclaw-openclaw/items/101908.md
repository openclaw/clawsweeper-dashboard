  - confidence: 0.93
- **[P2] Make gallery install placement recoverable:** `ui/src/pages/plugin/dashboard-view.ts:1010-1014`
  - body: `dashboard.widget.install` commits the bundle and pending registry entry before this separate `dashboard.widget.add` call places it on the tab. If placement fails, retrying the gallery install hits the existing-name check and cannot finish the normal flow; make install plus placement atomic, or let an already-pending widget be idempotently placed on retry.

  - confidence: 0.9

  - body: Route-owned misses such as traversal or unapproved assets return iframe-visible error documents without the widget CSP used for successful assets. Keep the same `connect-src 'none'` policy on every handled widget response, including errors.
