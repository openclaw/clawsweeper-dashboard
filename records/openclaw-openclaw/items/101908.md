Full review comments:

- **[P2] Make widget install placement recoverable:** `ui/src/pages/plugin/dashboard-view.ts:1010-1014`
  - body: `dashboard.widget.install` commits the widget files/registry before this separate `dashboard.widget.add` call places it on the tab. If the add call fails after a successful install, retrying from the gallery hits the existing-name check in `installWidgetBundle` and cannot finish placement, leaving an orphan pending widget. Please make install+placement atomic or idempotently recover an already-pending widget by adding it to the tab.
  - confidence: 0.86
- **[P1] Move dashboard runtime state into the canonical store:** `extensions/dashboard/src/store.ts:47-50`
  - body: The new default-on dashboard writes `workspace.json` and undo files directly under the plugin state directory. Root policy requires OpenClaw-owned runtime state and caches to use SQLite/plugin KV unless they are named product artifacts, and this workspace/undo state will need upgrade semantics. Please store it in the canonical state DB/plugin KV or get an explicit storage exception with migration/doctor behavior before enabling it by default.
  - confidence: 0.78
