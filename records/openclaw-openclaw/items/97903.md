## Summary

Keep open: this is a focused, well-proven bug fix with no blocking code findings, but it intentionally preserves the two-run side-effect and possible delivery tradeoff after accepted gateway disconnects, so maintainer acceptance is still needed before merge.

## What This Changes

The branch routes accepted-then-disconnected gateway agent runs to a fresh `gateway-fallback-*` embedded session, adds `gateway_connection_lost` fallback metadata, and covers accepted-close and transient-retry paths.

## Best Possible Solution

Land the fresh-session fallback for the same-session duplicate bug if maintainers accept the existing timeout-style two-run boundary, and keep reattach-first recovery in https://github.com/openclaw/openclaw/issues/98200 as the follow-up product decision.
