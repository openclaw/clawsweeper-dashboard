## What This Changes

This PR rejects malformed base64 returned by Google music/video/realtime, OpenAI realtime, and OpenAI-compatible LanceDB embedding providers, while making malformed realtime audio end the affected session cleanly.

## System Context

OpenClaw provider extensions receive binary data from external model APIs and decode it for generated media, realtime voice, and embedding storage. The affected paths validate that boundary data before it reaches audio/video consumers or a vector store, with realtime bridges also notifying callers when a session cannot safely continue.
