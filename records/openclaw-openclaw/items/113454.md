## Summary

Keep this PR open for a maintainer compatibility decision. The central portable-contract idea is coherent and has meaningful dry-run evidence, but the patch changes the established meaning of a non-empty schema-v1 `CLAW.md` body and then rejects packages that also declare `SOUL.md`; that can make previously valid packages fail to add or update.

## What This Changes

This PR changes experimental Claw packages so a non-empty Markdown body in `CLAW.md` becomes the managed agent prompt in `SOUL.md`, including add, update, and export handling.

## System Context

Claws are portable agent packages read by the CLI into a consented add or update plan, which creates and tracks managed files in an agent workspace. This change makes the package manifest’s Markdown body feed the managed prompt file and later folds that prompt back into package export.
