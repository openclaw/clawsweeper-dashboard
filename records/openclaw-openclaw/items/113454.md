## What This Changes

This PR makes a non-empty `CLAW.md` Markdown body become the managed `SOUL.md` prompt for an experimental Claw agent across add, update, and export.

## System Context

The Claws CLI reads a portable package, plans managed agent-workspace changes, records provenance, and later uses those records for update, removal, status, and export. This change promotes the package document body from descriptive metadata into content that is written into an agent’s prompt file.
