## Summary

Keep this draft PR open for maintainer direction and repair. The new byte-oriented Markdown parser decodes YAML frontmatter through Latin-1, which corrupts valid non-ASCII manifest values; the branch also has only claimed test evidence, not inspected after-fix CLI behavior proof. The `maintainer` label and RFC-linked change make the portable v1 contract a human decision rather than an automated merge path.

## What This Changes

This PR changes experimental Claw packages so a non-empty `CLAW.md` Markdown body is installed, updated, and exported as the agent’s managed `SOUL.md` prompt instead of requiring a separate sidecar.

## System Context

Claws packages describe an agent and the managed files in its workspace. The Claws CLI reads a package, creates a consented workspace plan, records file provenance for updates, and exports the managed agent back into a portable package.

  Consent --> Workspace[Agent workspace files]
  Workspace --> Provenance[File provenance records]
  Provenance --> Export[Portable Claw export]
