## Summary

Keep this PR open: the latest revision addresses the prior buffered-prefix finding, but after the first malformed chunk it decodes every later chunk twice through the same fallback decoder, which can corrupt subsequent multibyte shell output. The repair is narrow, but real runtime proof remains required before merge.

## What This Changes

The PR adds strict UTF-8 detection with a parallel permissive decoder to `OutputAccumulator` and regression tests for malformed bytes across output chunks.

## Best Possible Solution

Keep strict detection and the parallel fallback design, but once binary mode activates decode each later chunk exactly once with the permissive decoder, add a post-fallback multibyte regression case, and provide a redacted real shell-output transcript.
