## What This Changes

The issue asks for plugin node.invoke policy approvals to preserve turn-source routing metadata and use the shared plugin approval pending-route logic.

## Best Possible Solution

Land or replace the linked gateway fix so node policy approvals reuse the shared plugin approval routing path with preserved turn-source metadata.

## Reproduction Assessment

Yes. Source inspection shows the node policy approval path omits turn-source fields and uses local no-approval-route expiry, while the sibling plugin approval route keeps routable turn-source approvals pending.

## Solution Assessment

Yes. The narrow maintainable fix is to preserve the invocation turn-source fields and reuse handlePendingApprovalRequest with approvalKind: "plugin" instead of keeping a duplicate routing branch.
