## Summary

Keep this open: current main and v2026.6.11 still start `sessions_spawn` child tasks without `inputProvenance`, and the direct closing PR is still open, draft, conflicting, and unmerged.

## What This Changes

The issue requests explicit inter-session `inputProvenance` on child tasks created through `sessions_spawn`, including `sourceTool: "sessions_spawn"` and requester lineage where available.

## Best Possible Solution

Keep this issue as the canonical tracker until https://github.com/openclaw/openclaw/pull/47087 is refreshed and landed, or replaced by the same narrow fix at the `spawnSubagentDirect` child `agent` call.
