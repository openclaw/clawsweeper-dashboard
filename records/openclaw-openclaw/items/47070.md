## What This Changes

The issue requests explicit inter-session `inputProvenance` on child tasks created through `sessions_spawn`, including `sourceTool: "sessions_spawn"` and requester lineage where available.

## Best Possible Solution

Keep this issue as the canonical tracker until https://github.com/openclaw/openclaw/pull/47087 is refreshed and landed, or replaced by the same narrow fix at the `spawnSubagentDirect` child `agent` call.

## Reproduction Assessment

Yes, at source level. Current main’s `spawnSubagentDirect()` child `agent` params omit `inputProvenance`, while sibling inter-session paths and Gateway support already carry provenance metadata.

## Solution Assessment

Yes. The narrow maintainable solution is to reuse the existing `InputProvenance` envelope at the child `agent` boundary with `sourceTool: "sessions_spawn"`, not to add a new schema or broader trust system.
