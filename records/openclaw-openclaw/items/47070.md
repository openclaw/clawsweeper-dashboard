Keep open: current main and v2026.6.11 still launch `sessions_spawn` child tasks without `inputProvenance`, and https://github.com/openclaw/openclaw/pull/47087 remains the open direct fix candidate. ## What This Changes

Attach explicit inter-session `inputProvenance` to child tasks started through `sessions_spawn`, including `sourceTool: "sessions_spawn"` and requester lineage where available.

## Best Possible Solution

Keep this issue open until the linked PR is refreshed and landed, or replace it with the same narrow `spawnSubagentDirect()` provenance plumbing and regression test.
