## What This Changes

Attach existing inter-session `inputProvenance` metadata, including `sourceTool: "sessions_spawn"`, to child tasks created by `sessions_spawn`.

## Best Possible Solution

Land or replace the narrow `spawnSubagentDirect` fix that passes the existing `InputProvenance` envelope with `sourceTool: "sessions_spawn"`, then close this issue when the merged code is on main.

## Reproduction Assessment

Yes, at source level: current main’s `spawnSubagentDirect()` child `agent` params omit `inputProvenance`, while sibling inter-session paths already pass provenance metadata. I did not run a live spawned-subagent scenario in this read-only review.

## Solution Assessment

Yes, the requested direction is the narrow maintainable fix: reuse the existing `InputProvenance` envelope at the child `agent` boundary instead of adding a new schema or broader trust system.
