## Summary

Keep open: current main and v2026.6.11 still start the spawned child agent without `inputProvenance`, and https://github.com/openclaw/openclaw/pull/47087 is the open direct fix candidate. ## What This Changes

Attach explicit inter-session input provenance to child tasks created through `sessions_spawn`.

## Best Possible Solution

Land or replace the narrow `sessions_spawn` provenance fix so the initial child `agent` call receives the existing inter-session provenance envelope with `sourceTool: "sessions_spawn"`.
