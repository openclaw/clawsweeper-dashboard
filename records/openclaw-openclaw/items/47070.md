## Summary

Keep open: current main and the latest release still start `sessions_spawn` child tasks without `inputProvenance`, and https://github.com/openclaw/openclaw/pull/47087 remains the open direct fix candidate. ## What This Changes

Attach explicit inter-session `inputProvenance` with `sourceTool: "sessions_spawn"` to child tasks created by `sessions_spawn`.

## Best Possible Solution

Keep this issue open until https://github.com/openclaw/openclaw/pull/47087 is refreshed and landed, or replace it with the same narrow `spawnSubagentDirect()` provenance plumbing and regression test.
