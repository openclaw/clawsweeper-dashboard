## Summary

This is a focused, well-proven hardening PR, but it is not merge-ready because the unchanged `gog` rule breaks valid noninteractive execution and the universal second-approval policy still needs an explicit maintainer decision.

## What This Changes

The PR updates five active skill guides to require agents to preview resolved recipients, order details, email or event content, and selected files before approval of side-effecting commands.

## Best Possible Solution

Adopt one conditional invariant across the skills: require a new preview approval when targets or payloads are ambiguous or derived, preserve the chosen policy for already exact requests, and allow noninteractive CLI flags after approval.
