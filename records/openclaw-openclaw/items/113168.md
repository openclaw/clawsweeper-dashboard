## Summary

This PR addresses a current, deterministic sanitizer bypass and is paired with the still-open canonical bug report. The proposed equal-run delimiter rule matches the reported Markdown invariant, keeps genuine equal-run code examples exempt from sanitization, and includes focused downstream coverage; it should remain open for normal maintainer review rather than being closed or routed to automated repair.

## What This Changes

The branch replaces permissive inline backtick matching with equal-length delimiter pairing in shared text parsing, then adds regression tests showing mismatched delimiters no longer preserve reasoning tags in assistant-visible output.

## System Context

OpenClaw's shared text helpers identify Markdown code regions before assistant-output sanitizers remove internal reasoning and tool markup. Model or provider output enters the code-region detector, which tells visible-text processing what must remain literal before the result is delivered to channels and user-facing surfaces.
