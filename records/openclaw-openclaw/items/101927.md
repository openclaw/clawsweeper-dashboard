## Summary

Keep open: the final commit fixes the earlier binding-order problem, but the app-session create/adopt success cache is still keyed only by session key, so switching gateways can skip creating the dedicated app session on the new gateway. Exact-head CI also has native i18n drift and Android ktlint failures that need contributor follow-up before merge.

## What This Changes

The PR changes Android chat from `node-*` main-session keys to dedicated `openclaw-app-*` app sessions, adds Android tests/docs/i18n updates, and adds a manual emulator media-proof CI job.

## Best Possible Solution

Scope app-session create/adopt tracking by connected gateway stable id or connection generation, add a gateway-switch regression test, refresh generated native i18n, and fix Android ktlint before merge.
