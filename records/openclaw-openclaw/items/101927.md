Full review comments:

- **[P1] Bind chat before the connected refresh:** `apps/android/app/src/main/java/ai/openclaw/app/NodeRuntime.kt:1207`
  - body: `syncMainSessionKey()` now starts `ensureOpenClawAppSessionAsync()` and returns before `chat.applyMainSessionKey()` runs; `onConnected` then immediately calls `chat.onGatewayConnected()`, whose refresh reads the controller's current session key. Because the runtime scope is `Dispatchers.IO`, the session-create/apply coroutine and the connected history refresh race, so a slower create path can still send the first `chat.history` request to the old or generic main session and reintroduce the history bleed this PR is meant to prevent. Please make the app-session bind/adopt deterministic before the connected refresh and add a regression test for that ordering.
  - confidence: 0.86
- **[P2] Pin the proof gateway dependency:** `.github/workflows/ci.yml:2179`
  - body: The new proof job installs `ws@8` into `/tmp` at runtime, which resolves the latest matching package outside the repo lockfile each time the workflow is dispatched. That makes the proof job non-reproducible and executes third-party package install behavior even though the repo already pins `ws`; use the checked-in dependency path or an exact version with scripts disabled.
  - confidence: 0.78
