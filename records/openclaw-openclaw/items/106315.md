## Summary

Keep this fresh Control UI ergonomics request open: current main provides agent switching and agent-grouped sessions, but the report identifies a plausible visual-hierarchy problem that is not already solved by the existence of those controls.

## What This Changes

Make the Control UI sidebar distinguish agent selection more clearly from the selected agent’s session list in both light and dark themes.

## Best Possible Solution

Preserve the existing agent-scoped sidebar model but give agents an unmistakable top-level treatment—explicit labeling or selector affordance, stronger spacing and typography, accessible selected/focus states, and visibly nested session rows—validated in both themes and responsive layouts.
