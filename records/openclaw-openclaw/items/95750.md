## What This Changes

Add a durable cross-boot retry budget for interrupted main-session recovery so a wedged session cannot force repeated gateway restarts until the supervisor gives up.

## System Context

Gateway shutdown records interrupted main sessions and startup recovery decides which persisted sessions can resume. A durable retry decision prevents one unrecoverable session from repeatedly consuming gateway availability while preserving ordinary session continuity.
