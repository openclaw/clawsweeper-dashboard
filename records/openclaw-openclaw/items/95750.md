## What This Changes

Add durable per-session restart-recovery retry accounting so repeatedly wedged main and subagent sessions are quarantined instead of restarting the gateway indefinitely across boots.

## System Context

Gateway shutdown and restart recovery persist interrupted session state, then attempt to resume those sessions on the next gateway boot. The recovery decision affects gateway availability, session continuity, and whether interrupted channel work can safely resume.
