## What This Changes

Disables reusable Tool Search catalog snapshots for catalogs built with a per-run hook context, and adds regression coverage for snapshot retention and unaffected hook-free reuse.

## System Context

Embedded agent runs build Tool Search catalogs that compact the tools supplied to an agent attempt. Catalog compaction may retain a reusable snapshot across cleanup; this change bypasses that reuse mechanism for run-bound tools whose wrappers can retain attempt state.

## Best Possible Solution
