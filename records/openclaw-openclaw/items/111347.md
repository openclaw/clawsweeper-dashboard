## Summary

Keep open for normal review: the patch is a narrow, source-consistent fix for a shared ingress race that can replay already-completed channel work after restart. No discrete correctness defect was found in the proposed ordering, but the external PR still needs after-fix real-behavior proof beyond unit tests and CI before merge.

## What This Changes

The PR reorders shared channel-ingress outcome handling so completed and deferred returns reach the drain when shutdown abort races delivery completion, and adds regressions for both outcomes.

## Best Possible Solution

Keep terminal and deferred ownership decisions in the shared monitor/drain contract, land this narrow ordering change only after a real channel stop/restart proof demonstrates completed work is not replayed and deferred work remains owned.

## Solution Assessment

Yes: preserving explicit terminal and deferred outcomes at the shared monitor boundary is the narrowest fix because it lets the existing drain own abort-time settlement and leaves the no-result retry behavior intact.
