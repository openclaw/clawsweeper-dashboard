- **[P1] Sanitize runtime batch chunks before provider upload:** `extensions/memory-core/src/memory/manager-embedding-ops.ts:256`
  - body: This sanitizes only the inline `provider.embedBatch` path. Current main can route source-wide indexing through `providerRuntime.batchEmbed`, and the OpenAI/Gemini runtime batch adapters serialize `chunk.text` directly, so malformed Unicode can still reach providers and leave indexing stuck.
  - confidence: 0.9

  - body: The structured branch rewrites only `input.text`, but `EmbeddingInput.parts` can also contain provider-facing text. Gemini request building uses `parts[].text` when parts are present, so lone surrogates in those text parts still bypass the sanitizer.
  - confidence: 0.88
- **[P1] Reuse one shared surrogate sanitizer:** `extensions/memory-core/src/memory/manager-embedding-ops.ts:53-70`
  - body: OpenClaw already exports `sanitizeSurrogates` from `openclaw/plugin-sdk/llm`. Adding another regex helper here creates a parallel provider-text contract with different replacement semantics, so the fix should reuse the existing sanitizer or promote one shared memory-specific helper if U+FFFD replacement is required.
  - confidence: 0.82
