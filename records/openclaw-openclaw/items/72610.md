## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Remove the parallel in-core migration registry:** `src/migrations/registry.ts:4`
  - body: Current main already routes `openclaw migrate` through plugin-owned migration providers, including the Hermes provider declared by `extensions/migrate-hermes`. Adding a separate built-in `src/migrations` registry would create a second source of truth for provider discovery, CLI semantics, and security hardening, so this branch should be rebased onto the current plugin-owned path instead of merging the core registry.
  - confidence: 0.91
- **[P1] Require --yes for every non-dry-run apply:** `src/cli/program/register.migrate.ts:129`
  - body: This guard only rejects missing `--yes` when stdout is a TTY. In CI, scripts, or piped output, `process.stdout.isTTY` is false, so `openclaw migrate apply` can write config, `.env`, workspace files, and reports without the explicit confirmation that the help text promises. Require `--yes` for all non-dry-run applies or add a real interactive prompt.
  - confidence: 0.94
- **[P1] Quarantine imported MCP stdio commands:** `src/migrations/providers/hermes.ts:331-334`
  - body: The importer copies Hermes `command`, `args`, `env`, and `cwd` fields into `mcp.servers`, and OpenClaw later spawns stdio MCP servers from that config. A migrated home can therefore persist executable commands that run later; stdio MCP entries should be manual/quarantined or require explicit per-server trust before writing live config.
  - confidence: 0.9
- **[P1] Reject symlinks and path escapes before copying:** `src/migrations/apply.ts:50`
  - body: `copyFile`, `copyTree`, and archive operations trust plan paths and use `fs.copyFile`/`fs.cp` without `lstat`, allowed-root, or destination-symlink checks. A tampered migration source or target can make the importer copy data from outside the source tree or write through symlinked destinations, so the apply layer needs root confinement and symlink rejection before any filesystem write.
  - confidence: 0.86
- **[P2] Redact migration reports structurally:** `src/migrations/report.ts:14`
  - body: The redaction path only regexes a JSON string for mergeConfig actions and writes report reasons directly. Nested `env`, `headers`, `authorization`, cookies, or arbitrary token values can remain in `plan.json`, CLI JSON, or `report.md`; redact recursively by key and apply the same redaction to human-readable report fields.
  - confidence: 0.84

## Security Review

Status: needs_attention

Summary: Needs attention: the branch imports untrusted Hermes data into live config and filesystem writes without enough command, secret, path, or symlink hardening.

  - body: Hermes `mcp_servers` entries with `command`, `args`, `env`, or `cwd` are copied into `mcp.servers`, which OpenClaw resolves into stdio process transports later.
