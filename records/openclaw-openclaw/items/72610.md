Full review comments:

- **[P1] Require --yes before non-dry-run apply:** `src/cli/program/register.migrate.ts:129-132`
  - body: This guard only refuses missing `--yes` when stdout is a TTY. In CI, scripts, or piped output, `openclaw migrate apply` can mutate config/files without the explicit confirmation the command and docs promise; require `--yes` for every non-dry-run apply path.
  - confidence: 0.96
- **[P1] Quarantine executable MCP imports:** `src/migrations/providers/hermes.ts:544-552`
  - body: Hermes `mcp_servers` entries are copied into live `mcp.servers` with `command`, `args`, `env`, and `cwd`. Current MCP runtime turns those fields into a spawned stdio process, so importing an untrusted Hermes home can persist executable commands; make stdio entries manual/disabled or require explicit per-server approval.
  - confidence: 0.93
- **[P1] Reject unsafe config keys during merge:** `src/migrations/config-merge.ts:27-30`
  - body: Migration data can supply provider ids, MCP names, and nested config keys from Hermes YAML, but the merge path assigns them into plain objects without blocking `__proto__`, `constructor`, or `prototype`. Validate keys and use null-prototype merge targets before writing imported config.
  - confidence: 0.9
- **[P2] Refuse symlinks during migration copies:** `src/migrations/apply.ts:49-60`
  - body: The importer copies files and directories from a user-selected Hermes home with `fs.copyFile`, `fs.cp`, and `fs.stat`, all of which can follow source symlinks. A crafted source can cause OpenClaw to import data outside the selected source tree; use `lstat` and a safe walker that rejects symlinks and special files.
  - confidence: 0.86
- **[P2] Redact report data structurally:** `src/migrations/report.ts:13-15`
  - body: `redactMigrationAction` only pattern-redacts serialized `mergeConfig` actions, and `writeMigrationReport` writes result reasons directly. Secrets in nested config keys such as headers, cookies, bearer tokens, or action/result text can remain in `plan.json` or `report.md`; walk objects key-aware and redact all report fields.
  - confidence: 0.84

## Security Review

Status: needs_attention

Summary: The PR introduces security-sensitive migration code that handles untrusted config, secrets, filesystem copies, and executable MCP definitions without enough hardening.

  - body: Hermes `mcp_servers` can include stdio `command`, `args`, `env`, and `cwd`, and the PR merges them into `mcp.servers` where current runtime can spawn them later.

  - confidence: 0.84
