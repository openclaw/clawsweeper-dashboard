  - body: Current main already resolves migration providers through plugin manifest/runtime contracts and has the merged plugin-owned Hermes importer. - **[P1] Require --yes for every non-dry-run apply:** `src/cli/program/register.migrate.ts:129`
  - body: This guard only blocks missing `--yes` when stdout is a TTY. In scripts, CI, or piped output, `process.stdout.isTTY` is false, so `openclaw migrate apply` can mutate files/config without explicit confirmation; current main rejects non-interactive apply without `--yes`.
  - confidence: 0.92
- **[P1] Quarantine executable MCP server imports:** `src/migrations/providers/hermes.ts:544-550`
  - body: Hermes MCP entries with `command`, `args`, `env`, or `cwd` are merged straight into `mcp.servers`; OpenClaw later turns those entries into stdio MCP transports. Imported executable definitions should be manual/disabled until the operator reviews them.
  - confidence: 0.86
- **[P2] Redact migration reports structurally:** `src/migrations/report.ts:13-15`
  - body: Redacting a serialized `mergeConfig` action with token regexes misses many secret-bearing keys, and the Markdown report writes result reasons verbatim. Migration plans/reports need key-aware recursive redaction before writing JSON or Markdown.
  - confidence: 0.82
- **[P2] Reject prototype-polluting config keys:** `src/migrations/config-merge.ts:27-29`
  - body: Imported YAML-derived object keys are merged into normal objects without rejecting `__proto__`, `constructor`, or `prototype`. Validate keys or use null-prototype merge targets before writing untrusted migration config into OpenClaw config objects.
  - confidence: 0.79
- **[P2] Copy migration files through bounded safe helpers:** `src/migrations/apply.ts:44-60`
  - body: The apply path copies plan-controlled sources and targets directly with `fs.copyFile`/`fs.cp`, following symlinks and relying on a separate existence check before writes. Migration file operations should enforce allowed roots and reject symlinks/special files before applying imported data.
  - confidence: 0.75
