  - body: The importer copies Hermes `command`, `args`, `env`, and `cwd` into `mcp.servers`, so an imported Hermes home can persist commands that OpenClaw may later execute. Stdio MCP entries should be manual or quarantined unless the user explicitly approves them.
  - confidence: 0.84

  - body: `mergeConfig` redaction is regex-on-JSON and `report.md` writes reasons directly, so secret-shaped values under keys like headers, cookies, env, or plugin config can survive in generated reports. Walk objects by key and redact all report fields before writing.
  - confidence: 0.82
