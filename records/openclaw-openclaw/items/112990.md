## What This Changes

This PR marks authenticated Telegram 400/403 unreachable-recipient failures as terminal ingress errors and rethrows failed pairing replies so the queued inbound update can be dead-lettered rather than retried.

## System Context

Telegram inbound updates enter a durable ingress queue, where DM pairing may send a reply before dispatch finishes. The ingress drain classifies an error as retryable or terminal, then either retains the event for retry or records it as a dead letter.
