## What This Changes

This PR treats authenticated Telegram 400/403 unreachable-recipient errors as terminal ingress failures and rethrows failed pairing replies so the ingress queue dead-letters them instead of retrying.

## System Context

Telegram polling stores incoming updates in the shared ingress queue before channel dispatch handles DM access and may send a pairing reply. The ingress retry policy decides whether a dispatch error returns the update to the queue or tombstones it as a failed, non-retryable event.
