## Label Justifications

- `P1`: A reproduced released regression can falsely exceed the context budget and stall compaction during real long-running agent workflows.
- `impact:session-state`: The bug persists run-wide billing usage as the session's current context snapshot, corrupting context freshness and compaction decisions.

## Summary

The released bug is reproduced and remains necessary: current main still derives the last-call snapshot from the terminal assistant usage, which can be zero after an abort, while the maintainer-owned linked PR preserves the preceding valid per-call snapshot and proves the persisted result end to end. Keep this issue open until that closing PR lands.

## What This Changes

Fix session context accounting so cumulative cache-read billing usage is not persisted as the current context snapshot or used to trigger compaction.

## Best Possible Solution

Land the producer-side repair that retains the latest committed nonzero per-call usage through a later zero-usage abort, propagates that exact snapshot into session persistence, and reports context usage as unknown when no trustworthy snapshot exists.
