## Summary

Keep open: current main and v2026.6.11 have adjacent update, backup, health, config-snapshot, and recovery primitives, but not the requested opt-in safe-update transaction with update-tied state snapshots, retention, channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an opt-in updater workflow that snapshots OpenClaw state before updating, verifies gateway/channel/agent health afterward, and rolls back or restores on failure.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off mode that orchestrates snapshot creation, retention, update, doctor/status/health checks, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
