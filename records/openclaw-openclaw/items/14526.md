## Summary

Keep open: current main and v2026.6.11 still have adjacent updater, backup, doctor, health, and rollback guidance, but not the requested opt-in safe-update workflow with update-tied snapshots, retention, real channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

Request an optional safe-update workflow that snapshots OpenClaw state before updating, runs post-update health/channel/agent checks, and rolls back or restores on failure.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off mode that orchestrates snapshot creation, retention, update, doctor/status/health checks, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
