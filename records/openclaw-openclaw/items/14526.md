## Summary

Keep open: current main and v2026.6.11 have adjacent updater, backup, doctor, gateway health, plugin convergence, auto-update handoff, and manual rollback primitives, but not the requested opt-in safe-update transaction with update-tied full snapshots, retention, channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an optional safer self-update workflow with pre-update backup, post-update health checks, and rollback or restore when checks fail.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off updater mode that orchestrates snapshot creation, retention, update, doctor/status/health checks, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
