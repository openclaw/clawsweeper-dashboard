## Summary

Keep open: current main and v2026.6.11 have updater, gateway health, manual backup, post-core plugin convergence, and recovery guidance, but not the requested opt-in safe-update transaction with update-tied snapshots, retention, real channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an optional safe-update workflow that snapshots OpenClaw state before updating, runs post-update health and smoke checks, and rolls back or restores state on failure.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off safe-update mode that composes backup creation, retention, update execution, doctor/status/health, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
