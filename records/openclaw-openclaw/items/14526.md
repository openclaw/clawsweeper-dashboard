## Summary

Keep open: current main has adjacent updater, backup, config-snapshot, gateway restart verification, plugin convergence, and manual rollback guidance, but it still lacks the requested opt-in safe-update transaction with update-tied snapshots, retention, channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an optional safer update workflow that backs up OpenClaw state before updating, verifies health afterward, and rolls back or restores state if checks fail.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off updater mode that orchestrates snapshot creation, retention, update, doctor/status/health checks, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
