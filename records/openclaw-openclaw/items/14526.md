## Summary

Keep open: current main and the latest release still provide adjacent updater, backup, doctor, gateway-health, and manual rollback primitives, but not the requested opt-in safe-update transaction with update-tied full snapshots, retention, channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an optional safer self-update workflow that snapshots OpenClaw state before update, runs post-update health and smoke checks, and rolls back or restores state when checks fail.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off updater mode that orchestrates snapshot creation, retention, update, doctor/status/health checks, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
