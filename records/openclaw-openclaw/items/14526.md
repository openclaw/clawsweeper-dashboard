## Summary

Keep open: current main and v2026.6.11 still have updater, auto-update, backup create/verify, doctor, and gateway restart-health primitives, but not the requested opt-in safe-update transaction with update-tied full snapshots, retention, channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an optional safer self-update workflow that backs up OpenClaw state before update, runs post-update health and smoke checks, and rolls back or restores state when checks fail.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off updater mode that orchestrates snapshot creation, retention, update, doctor/status/health checks, channel/agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
