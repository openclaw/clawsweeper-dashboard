## Summary

Keep open: current main and v2026.6.11 still provide adjacent update, doctor, gateway restart verification, plugin convergence, and manual backup primitives, but not the requested opt-in safe-update transaction with update-coupled snapshots, retention, real agent/channel smoke checks, and automatic package plus state rollback.

## What This Changes

The issue requests an optional safer update workflow that snapshots OpenClaw state before updating, runs post-update health and smoke checks, and rolls back or restores state when checks fail.

## Best Possible Solution

Decide the core safe-update scope explicitly; if accepted, make the updater orchestrate snapshot creation, retention, update, doctor/status/gateway/channel/agent smoke checks, and controlled package/plugin/config/state rollback with secret-safe restore guarantees.
