## Summary

Keep open: current main and v2026.6.11 still provide adjacent updater, backup, doctor, plugin convergence, gateway restart verification, and manual rollback primitives, but not the requested opt-in safe-update transaction with update-coupled snapshots, retention, real channel/agent smoke checks, and automatic package plus state rollback.

## What This Changes

Request an optional safe-update workflow with pre-update state backup, post-update health checks, channel/agent smoke checks, retention policy, and rollback/restore on failure.

## Best Possible Solution

Decide the core safe-update scope explicitly; if accepted, make the updater orchestrate snapshot creation, retention, update, doctor/status/gateway/channel/agent smoke checks, and controlled package/plugin/config/state rollback with secret-safe restore guarantees.
