## Summary

Keep open: current main and the latest tagged release still provide adjacent update, backup, doctor, gateway-health, plugin-convergence, and manual rollback primitives, but not the requested opt-in safe-update transaction with update-tied snapshots, retention, channel/agent smoke checks, and automatic package plus state restore.

## What This Changes

The issue requests an optional safe-update workflow that backs up OpenClaw state before updating, runs post-update health checks, and rolls back or restores state when verification fails.

## Best Possible Solution

Keep this as a maintainer-owned core updater design item; if accepted, implement a default-off safe-update mode that coordinates snapshots, retention, update, doctor/status/health, channel or agent smoke checks, and controlled package/plugin/config/state rollback with explicit secret-safe restore guarantees.
