## What This Changes

This PR divides the web chat’s formerly monolithic grouped-message renderer into focused modules for message groups, bubbles, media, timestamps, streaming state, markdown actions, and confirmation controls while keeping `chat-message.ts` as the caller-facing facade.

## System Context

OpenClaw’s web chat converts transcript and streaming items into grouped message UI, including media previews, message actions, timestamps, and confirmation controls. The chat view calls a facade that now delegates those responsibilities to smaller rendering modules.
