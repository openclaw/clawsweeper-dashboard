Keep open: current main and v2026.6.11 still expose only coarse session rows and `sessions.changed` updates, not the requested `sessions.activity.get/list` RPCs, explicit attention state, child rollup, stale-run accounting, or activity statechange contract. Add a gateway-owned per-session activity API and WebSocket activity-change event for busy/idle, explicit waiting states, stale runs, and child-session rollups.
