## Summary

Keep this issue open for a focused current-release verification: current memory documentation and the May readiness work describe an in-process cosine fallback when sqlite-vec cannot load, but the report supplies a concrete v2026.7.1 failure where that promised fallback appears not to preserve results.

## What This Changes

The issue reports that builtin hybrid memory search returns no results when sqlite-vec cannot load through the active Node.js SQLite build, despite indexed embeddings and available keyword matches.

## Best Possible Solution

Reproduce on v2026.7.1 with an extension-disabled Node SQLite build, then make the builtin memory manager retain semantic in-process cosine retrieval and return an explicit vector-store diagnostic rather than silently filtering all relevant results.
