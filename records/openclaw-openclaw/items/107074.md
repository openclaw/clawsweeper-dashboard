## Summary

Keep open: the report provides credible evidence of a stable-release updater regression that caused a managed macOS gateway outage, while current main contains relevant owning-root safeguards but lacks enough current-main reproduction and fix provenance to conclude the reported edge is resolved.

## What This Changes

Fix macOS global npm updates so they update the durable package root owning the active OpenClaw CLI and keep the managed LaunchAgent on that same root.

## Best Possible Solution

Make the invoking or managed service package root authoritative throughout target resolution, staged swap, post-core handoff, bin-shim installation, and LaunchAgent regeneration; on failure, automatically restore the prior canonical root and service instead of requiring terminal recovery.
