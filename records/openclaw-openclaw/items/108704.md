## What This Changes

Make the iPhone Chat screen’s bottom navigation remain usable while the software keyboard is open.

## Best Possible Solution

Define one keyboard-aware iPhone navigation contract, implement it at the `RootTabs`/Chat boundary without regressing the composer’s safe-area behavior, and prove it on a real device or simulator in portrait and compact-height layouts.
