## Summary

Current main keeps the human message bare and moves inbound decoration plus the delivery directive into a distinct marked runtime-context carrier, resolving the reported single-envelope authority ambiguity for the standard embedded runtime. The change is newer than the latest release.

## What This Changes

Separate host-authoritative delivery instructions, untrusted inbound metadata, and the human message in the model-facing inbound envelope.

## Best Possible Solution

Keep the bare-user-turn plus marked runtime-context-carrier design and validate it in the next release on a real message-tool-only Slack lane; report any backend-specific parity gap separately with a current provider payload.

## Solution Assessment

Yes. Reusing the hidden runtime-context carrier while preserving a bare human turn is narrower and more maintainable than adding another textual delimiter inside user-authored content.
