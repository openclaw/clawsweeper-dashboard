## Summary

## What This Changes

The issue asks OpenClaw to stop leaking unconfigured OpenAI/Codex provider errors into Telegram chat, including FastAPI-style top-level `detail` JSON.

## Best Possible Solution

Update or replace the narrow parser fix for top-level `detail` payloads with regression coverage, then make an explicit provider/routing policy decision for unconfigured-provider failures before chat delivery.
