## Summary

Keep open. Current main and the latest release still route browser snapshots through whole-page Playwright, CDP, or Chrome-MCP accessibility reads without a viewport-scoped snapshot or scroll-position contract, and the FSB comment is useful prior art for a maintainer product decision rather than cleanup-close evidence.

## What This Changes

The issue requests that browser snapshots reflect the currently visible viewport after scroll instead of returning top-of-page/full-tree content.

## Best Possible Solution

Define the browser snapshot contract explicitly: add viewport-aware snapshot output or scroll/viewport metadata while preserving an explicit full-tree/raw mode, then prove it with a live scrolled-page browser run across the Playwright, CDP fallback, and Chrome-MCP paths that remain supported.
