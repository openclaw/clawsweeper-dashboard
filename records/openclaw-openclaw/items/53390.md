## Summary

Keep open. Current main and v2026.6.11 still route browser snapshots through full-tree Chrome MCP, Playwright AI/role, or CDP accessibility reads without a visible-viewport or scroll-position contract, so the central problem is still necessary to decide and fix.

## What This Changes

The issue asks for browser snapshots to reflect the currently visible viewport after scrolling instead of returning top/full-page content.

## Best Possible Solution

Define the browser read contract first: add or make explicit a visible-viewport snapshot/read with scroll metadata, while preserving an intentional full/raw snapshot path, then prove it across Chrome MCP, Playwright, and direct CDP paths.
