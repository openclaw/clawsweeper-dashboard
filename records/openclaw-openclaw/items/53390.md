## Summary

Keep open. Current main and the latest release still route browser snapshots through full AI/ARIA/CDP/Chrome-MCP tree reads without a visible-viewport or scroll-position contract, and the linked FSB comment is useful prior art rather than cleanup-close evidence.

## What This Changes

The issue asks for browser snapshots to reflect the current scrolled viewport instead of returning top-of-page content after scroll actions.

## Best Possible Solution

Define the browser read contract first: either make snapshot visibly viewport-scoped with scroll metadata, or add an explicit visible-viewport read while preserving full-page/raw reads, then prove it across managed Playwright, raw CDP, and Chrome MCP.
