## Summary

Keep open. Current main and v2026.6.11 still route browser snapshots through full AI/ARIA/CDP/Chrome-MCP tree reads without viewport scroll metadata, and the FSB comment is useful prior art for a maintainer contract decision rather than cleanup-close evidence.

## What This Changes

The issue asks for browser snapshots to reflect the current visible viewport after scrolling instead of returning the initial top-of-page content.

## Best Possible Solution

Define the browser read contract first: add a visible-viewport snapshot/read with scroll and viewport metadata while preserving explicit full/raw tree reads, then prove it across managed Playwright, raw CDP, and Chrome MCP paths.
