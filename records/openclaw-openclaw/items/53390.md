## Summary

Keep open. Current main and the latest release still build browser snapshots from Playwright, Chrome-MCP, or CDP accessibility-tree reads rather than a visible-viewport read, so the reported behavior remains unresolved and needs a maintainer contract decision; the linked FSB comment is useful prior art for keeping viewport reads distinct from full DOM reads.

## What This Changes

The issue requests that browser snapshots reflect the currently scrolled viewport instead of returning initial top-of-page content.

## Best Possible Solution

Define an additive viewport-aware browser read contract with scroll/viewport metadata while preserving explicit full-tree snapshots, then cover Playwright, CDP, and Chrome-MCP paths with focused tests and live browser proof.
