## Summary

Keep open. Current main and v2026.6.11 still build browser snapshots from Playwright, Chrome-MCP, or CDP accessibility trees rather than a viewport-scoped read, so the central user problem is not implemented; the linked FSB reference is useful prior art for a maintainer contract decision.

## What This Changes

The issue asks for browser snapshot output to reflect the current scrolled viewport instead of returning top/full-page content after scroll actions.

## Best Possible Solution

Define a maintainer-approved viewport-aware browser read contract, preferably additive: visible viewport snapshot or scroll metadata alongside the existing full/raw tree path, with docs, focused tests, and live browser proof.
