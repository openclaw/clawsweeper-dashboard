## Summary

Keep open. Current main and the latest release still route browser snapshots through full accessibility-tree or Playwright/Chrome-MCP snapshot reads without a viewport-scoped snapshot contract, and the FSB comment is useful prior-art context rather than cleanup-close evidence.

## What This Changes

The issue asks for browser `snapshot` output to reflect the current scrolled viewport instead of returning top-of-page content after scroll actions.

## Best Possible Solution

Define the browser snapshot contract explicitly: add viewport-aware snapshot output or scroll/viewport metadata while preserving an explicit full-tree/raw mode, then prove the behavior with a live scrolled-page run across the supported browser backends.
