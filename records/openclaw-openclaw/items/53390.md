## Summary

Keep open. Current main still builds browser snapshots from full accessibility/ARIA trees or Chrome MCP snapshots, and I did not find a viewport-scoped snapshot contract or shipped fix for the scroll-position problem; the FSB comment is useful prior art for the contract decision.

## What This Changes

The issue requests that `browser snapshot` reflect the currently visible viewport after scroll instead of returning top-of-page content.

## Best Possible Solution

Define and implement a viewport-aware snapshot contract across Playwright, raw CDP, and Chrome MCP paths, preferably surfacing scroll/viewport state and preserving an explicit full-tree mode when agents need global refs.
