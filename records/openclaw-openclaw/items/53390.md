## Summary

Keep open. Current main and the latest release still route browser snapshots through whole-page AI/ARIA/CDP/Chrome-MCP tree reads without a visible-viewport or scroll-position contract, and the FSB comment is useful prior art for the maintainer product decision rather than cleanup-close evidence.

## What This Changes

The issue requests that browser snapshots reflect the currently visible viewport after scroll actions instead of returning top-of-page or full-document content.

## Best Possible Solution

Define the browser snapshot contract first, likely as a visible-viewport read with scroll metadata or separate full/visible modes, then prove it across managed Playwright, raw CDP, and Chrome MCP.
