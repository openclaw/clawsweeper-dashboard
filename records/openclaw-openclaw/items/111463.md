## Summary

This PR remains necessary: current `main` already forwards `agentId`, session key, and `sandboxed` through Memory Core fallbacks, but its Memory Wiki query layer has no bridge-page visibility filter or `bridgeAgentIds` parsing. The branch adds that missing enforcement at the shared query boundary and supplies current-head before/after evidence for all four affected tools. Likely related people: steipete (high confidence), as the merged per-agent vault feature author whose ownership model this patch extends.

## What This Changes

The PR adds bridge-page ownership metadata to Memory Wiki query summaries and denies sandboxed callers access to bridged pages owned by another agent or missing ownership metadata, including through registered Memory Core fallback tools.

## System Context

Memory Wiki compiles memory artifacts into a vault that `wiki_get`/`wiki_search` and Memory Core’s `memory_get`/`memory_search` corpus fallbacks can read. This PR inserts one ownership decision before vault pages are returned, while preserving global-vault reads for non-sandboxed callers.
