## Summary

The revised filter resolves the previous global-vault compatibility concern by applying only to sandboxed callers, but it does not cover the documented `memory_get`/`memory_search` corpus-supplement route, so the reported cross-agent disclosure remains reachable there.

## What This Changes

The PR adds bridge-page ownership metadata to Wiki summaries and filters direct shared-vault Wiki get/search results for sandboxed callers while preserving non-sandboxed global-vault reads.

## Best Possible Solution

Forward `agentId` and `sandboxed` through the Memory Wiki corpus supplement for both search and get, then prove direct Wiki and Memory Core fallback calls deny foreign bridge pages while non-sandboxed global-vault reads remain available.
