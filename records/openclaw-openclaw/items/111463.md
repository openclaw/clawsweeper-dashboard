## Summary

The disclosure report is still necessary, but this patch over-applies its visibility gate: every normal agent-scoped call in the default global vault loses access to other agents’ bridge pages, despite the documented global-sharing contract. Likely related people: steipete (high confidence, introduced the current vault-scope behavior in the merged Memory Wiki isolation work).

## What This Changes

The PR exposes bridge ownership metadata to Wiki query pages and filters direct Wiki get/search results by the caller’s resolved agent identity.

## Best Possible Solution

Keep the ownership denial for sandboxed cross-agent reads, but preserve documented global-vault sharing for ordinary non-sandboxed callers; add regression coverage for both the denied sandboxed path and the retained global-sharing path.
