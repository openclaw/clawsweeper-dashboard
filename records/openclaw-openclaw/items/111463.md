## Summary

Keep this PR open: it correctly adds a query-layer visibility rule for direct Memory Wiki reads, but the Memory Core fallback still lacks the sandbox context needed to activate that rule. Likely related people: steipete (high confidence) introduced the current multi-agent vault and bridge-ownership model; the PR author should update the proposed branch after that plumbing is corrected.

## What This Changes

The PR filters bridge-owned pages from sandboxed agents belonging to another identity in direct Memory Wiki reads and intended Memory Core corpus fallback reads, while retaining global-vault sharing for non-sandboxed callers.

## System Context

Memory Wiki compiles agent memory artifacts into a shared or per-agent vault, then exposes them through `wiki_get`/`wiki_search` and through Memory Core’s fallback search and get tools. The query layer must receive trusted caller identity and sandbox state so bridged pages are visible only to permitted callers.
