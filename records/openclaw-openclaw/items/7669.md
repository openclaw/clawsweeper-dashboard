## Summary

Keep this issue open for a release-manager decision: current main supports the dev update channel through a Git checkout, but it deliberately has no npm `dev` publish path, so the requested npm snapshot channel remains a new, security-sensitive release capability rather than a completed fix.

## What This Changes

The issue requests an npm `dev` dist-tag that publishes recent `main` builds with CI verification and accurate channel documentation.

## Best Possible Solution

Choose one canonical contract: either keep dev as the existing git-based moving-main channel and remove the optional npm snapshot promise, or design a separately versioned, provenance-verified npm snapshot release path with post-publish verification.
