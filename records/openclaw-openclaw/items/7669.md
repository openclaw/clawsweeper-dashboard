## Summary

Keep this issue open for a release-owner decision: current main supports the `dev` update channel as a GitHub-main checkout, but it does not publish an npm `dev` dist-tag, so the requested snapshot channel remains a new, security-sensitive release capability.

## What This Changes

Re-enable publishing a moving-main OpenClaw package through npm’s `dev` dist-tag, with verification and accurate channel documentation.

## Best Possible Solution

A release owner should explicitly retain the current Git-only `dev` contract and remove any remaining npm-dev wording, or sponsor a separately designed npm snapshot lane with immutable versions, trusted publication, provenance, registry verification, and update/install documentation.
