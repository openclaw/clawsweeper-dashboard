## Summary

Keep open: current main and the live npm registry still lack the requested moving-main npm `dev` channel, while the permanent relationship between git `dev` and versioned npm `alpha` requires release-owner direction.

Likely related people: `steipete` is the strongest routing candidate, with Onur Solmaz and Vincent Koc also connected through substantial release-workflow and channel-documentation history.

## What This Changes

Add a verified npm `dev` dist-tag publication path that tracks moving `main` builds and align the release-channel documentation.

## Best Possible Solution

Adopt one canonical experimental distribution policy: preferably document `dev` as git-only and reserve npm for versioned `alpha`/`beta` releases, or—if moving-main packages are explicitly desired—add uniquely versioned snapshots with trusted publishing, provenance, focused tests, and registry verification.
