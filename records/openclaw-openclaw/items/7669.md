## Summary

Keep this issue open for a release-owner decision: current `main` and the live npm registry still lack the documented npm `dev` package channel, while OpenClaw now has a separate first-class npm `alpha` release path, so the remaining work is choosing and aligning the permanent channel contract rather than applying a narrow fix.

## What This Changes

Restore or formally resolve the documented npm `dev` distribution channel for moving development builds.

## Best Possible Solution

Expose npm `alpha` as the single packaged edge channel, reserve `dev` for moving git checkouts, and align updater behavior, plugin selection, docs, migration guidance, release automation, and registry verification so package users never resolve a nonexistent `dev` tag.
