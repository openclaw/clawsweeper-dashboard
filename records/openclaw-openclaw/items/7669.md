## Summary

Keep open for a release-manager decision: current main, the latest shipped release, and the live npm registry still leave the documented package `dev` channel unusable, while OpenClaw now has a separate Tideclaw npm `alpha` channel that makes restoring `dev` a product, compatibility, and release-security choice rather than a mechanical CI fix.

## What This Changes

Restore an npm `dev` distribution tag for moving `main` builds and add publishing verification and accurate channel documentation.

## Best Possible Solution

Make one npm snapshot channel canonical, define an explicit migration or alias policy for persisted package `dev` selections, keep git `dev` semantics unambiguous, and align the workflow, release plan, updater, tests, registry verification, and public documentation.
