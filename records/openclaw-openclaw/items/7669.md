## Summary

Keep open for a release-manager decision. Current main still has no npm `dev` publication path; moving-main development uses git, while the newer npm `alpha` path is a separately versioned, gated Tideclaw prerelease track rather than a replacement compatible with `openclaw@dev`.

## What This Changes

Restore a moving-main npm snapshot channel under the `dev` distribution tag and verify its publication.

## Best Possible Solution

Keep `dev` as the canonical git-based moving-main channel and `alpha` as the gated npm prerelease track, then remove the npm `dev` promise from user-facing docs unless release managers explicitly define and own a separate snapshot contract.
