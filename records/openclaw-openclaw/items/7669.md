## Summary

Keep open for a release-manager decision: current `main` and the live npm registry still lack the documented npm `dev` dist-tag, but OpenClaw now has a first-class npm `alpha` channel and a git-based moving `dev` path, so restoring another packaged channel is no longer an implementation-only task.

## What This Changes

Restore or explicitly retire the npm `dev` dist-tag for moving `main` builds, with matching release automation, verification, and documentation.

## Best Possible Solution

Standardize on npm `alpha` for packaged prereleases and git-based `dev` for moving `main`, unless release managers explicitly define a separate snapshot contract with distinct versioning, triggers, provenance, verification, and documentation.
