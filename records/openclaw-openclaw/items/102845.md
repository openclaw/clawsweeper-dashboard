## Summary

Keep open. Current main still allows the usable-model Crestodian path to return conversational text without an `open-tui` directive, which the Gateway surfaces as `action: "none"`; this issue also has the protected `maintainer` label and an open linked fix PR.

## What This Changes

The issue asks for the documented exact Crestodian `talk to agent` command to deterministically return the macOS app handoff action instead of depending on model tool use.

## Best Possible Solution

Land a narrow fix that treats exact host-navigation selectors such as `talk to agent` as deterministic before usable-model delegation, with Gateway/macOS regression proof for the resulting `open-agent` action.
