## Label Justifications

- `P0`: The reported onboarding completion handoff can strand a first-time macOS app user on the Crestodian setup screen instead of opening the configured agent UI.
- `impact:ux-release-blocker`: The affected flow is setup/onboarding, and recovery depends on a host action the app does not receive when the RPC action stays `none`.

## Summary

Keep open: current main still has a model-dependent Crestodian app handoff path, and the live issue has the protected `maintainer` label plus an assignee, so conservative cleanup should not close or auto-queue it.

## What This Changes

The issue reports that the documented Crestodian `talk to agent` command can return no `open-agent` action when a usable model backend handles the turn.

## Best Possible Solution

Make exact host-navigation selectors such as `talk to agent` resolve before the model path in Crestodian chat, preserving AI handling for fuzzy requests and adding gateway/app regression coverage.
