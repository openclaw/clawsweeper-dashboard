## Summary

Keep open. Current main still allows a usable-model Crestodian turn to return text without an `open-tui` directive, which the gateway will surface as `action: "none"`, and the live issue has the protected `maintainer` label.

## What This Changes

The issue requests deterministic host-side handling of the documented `talk to agent` command so `crestodian.chat` returns `open-agent` in the macOS app even when the model does not call the handoff tool.

## Best Possible Solution

Handle exact documented host-navigation selectors such as `talk to agent` before the usable-model turn, preserve natural-language chat as AI-owned, and add focused gateway/chat-engine/macOS-facing regression coverage for the text-only model reply path.
