## Summary

This PR should remain open for contributor follow-up, not cleanup closure. ## What This Changes

The branch exports the Nostr profile request timeout constant and imports it into the focused UI test instead of keeping a separate expected timeout value there.

The Control UI sends Nostr profile publish and import requests through a shared request helper. That helper applies a deadline to gateway fetches, and the focused Vitest suite verifies timeout behavior for those UI operations.
