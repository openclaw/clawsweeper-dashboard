## What This Changes

The branch adds a 15-second abort deadline to the Control UI's Nostr profile publish and import requests, with unit tests for forwarding an abort signal.

## System Context

The Control UI's Channels page sends authenticated HTTP requests to the Nostr channel plugin to publish or import a profile. The page owns pending-form state and turns request failures into retryable errors shown to the operator.
