- **[P1] Gate stripping on the actual provider rejection:** `src/agents/embedded-agent-runner/run.ts:2009`
  - body: This passes `accumulatedReplayState.replayInvalid` as if it means the previous attempt hit Anthropic `replay_invalid`, but current main derives that state from generic replay safety, compaction/timeouts, and incomplete-turn conditions, and it does not inspect the provider rejection before the silent-error retry.   - confidence: 0.86

Compute the preserve decision first and pass it to `stripAllThinkingSignatures`, or avoid all-signature stripping on current tool-turn histories.
