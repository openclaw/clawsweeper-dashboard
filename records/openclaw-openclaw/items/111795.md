## Summary

Keep this PR open: it still does not persist the forced-recovery override through the default SQLite-backed Workboard store, and it bundles an unrelated global queue-admission policy change. It also needs contributor-supplied real behavior proof before merge.

## What This Changes

This PR attempts to keep a Workboard card promoted with `force: true` eligible for dispatch, while also reserving one multi-concurrency command-lane slot for foreground work.

## System Context

The Workboard plugin stores cards, applies dependency and schedule holds, and dispatches ready cards to workers. Gateway-originated plugin subagent runs then enter the shared command queue, so the PR currently mixes card-recovery persistence with global runtime scheduling behavior.
