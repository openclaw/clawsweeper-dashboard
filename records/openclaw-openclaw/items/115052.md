## What This Changes

Fix QA profile planning so Crabline runs only scenarios whose declared channel-driver contract supports Crabline, and reject explicitly incompatible selections before execution.

## System Context

Taxonomy-backed QA profiles select scenarios for a channel and driver, then start the corresponding transport harness and scenario context. The lane planner sits between profile selection and channel execution, so an incorrect eligibility decision creates false CI failures and misleading release evidence.
