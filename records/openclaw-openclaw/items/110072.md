## Summary

Keep open: the approach addresses the reported per-call state loss, but the new retention policy can discard safety-active state, and the supplied proof does not exercise a real Gateway with a paired macOS node.

## What This Changes

The PR extracts computer-tool mutable invocation state and shares it through a bounded per-session Gateway registry so rebuilt tool instances retain frame, held-button, and serialization state.

## Best Possible Solution

Keep Gateway session-scoped invocation state, but expire only disposable frame data; pin held-button and in-flight queue state until explicit completion or cleanup, integrate cleanup with the session lifecycle, and prove the result through a live Gateway and paired Mac.
