## What This Changes

The branch adds a request-local cache for session-store lookups used by sharing resolution during gateway `sessions.list`, plus a regression test that guards against quadratic materialization as row counts grow.

## System Context

Gateway `sessions.list` gathers session records for RPC consumers such as the Control UI. For each listed row, sharing resolution chooses a session-store target; the proposed cache lets that per-row lookup reuse read-only store entries during one request.
