## What This Changes

## Best Possible Solution

Define and prove one secure iOS remote Gateway path: prefer Tailscale Serve/Funnel or native Gateway TLS with visible fingerprint diagnostics, and clearly document whether direct Tailnet CGNAT plaintext is unsupported or only available through an explicit maintainer-approved opt-in.
