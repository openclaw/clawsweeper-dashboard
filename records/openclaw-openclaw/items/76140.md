  - body: When `isShared` is true but `currentAgentId` is absent, this helper returns every recall entry instead of none. An identity-less shared-workspace run can therefore feed legacy or contaminated shared corpus entries into light/REM dreaming even though ingestion tries to fail closed.
  - confidence: 0.9

  - body: This call passes `currentAgentId` and `isShared`, but `RankShortTermPromotionOptions` does not define or consume those fields and the ranker still iterates the whole workspace store.   - confidence: 0.93

  - body: The new provenance store is written as ad hoc JSON under `memory/.dreams`, while current OpenClaw-owned runtime state is supposed to have a canonical SQLite/plugin-state owner and migration path.
