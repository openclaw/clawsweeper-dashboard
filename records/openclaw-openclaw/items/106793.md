Keep open for explicit maintainer API direction: this maintainer-owned, protected-label proposal addresses a real cross-client contract gap that current main does not implement.

Likely related people: RomneyDa — proposal and product/API direction owner (medium confidence).

## What This Changes

Add an additive, non-sensitive presentation object to Gateway session rows so clients receive consistent titles and structured session-family metadata without parsing routing keys.

## Best Possible Solution

Define one additive Gateway-owned presentation projection built from authoritative session and routing metadata, with deterministic title fallbacks, explicit privacy exclusions, generic closed-enough family/background semantics, and an owner extension seam for plugin-specific families rather than client-side key parsing.
