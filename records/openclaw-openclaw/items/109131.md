## Summary

Keep this PR open: it addresses a real E2E hang, but sequential Docker probes reuse a timeout calculated before the first probe, so one stalled call can consume the deadline and later calls can extend the script well beyond it; the submitted validation is fake-Docker test coverage rather than real Docker behavior proof.

## What This Changes

The PR routes package-install and Compose readiness, diagnostics, execution, and cleanup Docker commands through timeout-aware helpers, adds wall-clock readiness deadlines, and extends the Docker script tests.

## Best Possible Solution

Calculate the remaining deadline immediately before every Docker RPC, avoid starting normal probes after expiration, bound post-deadline diagnostics separately, and demonstrate both package-install and Compose failure paths with redacted real Docker terminal or log output.
