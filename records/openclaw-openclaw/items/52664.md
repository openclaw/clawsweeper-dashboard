## Summary

Keep this PR open, but it still needs changes before merge: the rawBody feature is useful and well-proven on the happy paths, yet the active-run queue path can publish a rejected or canceled queued injection as the later hook rawBody.

## What This Changes

The PR adds an optional rawBody field to before_prompt_build, before_agent_start, and agent_end plugin hook events, then threads it through embedded, CLI, Codex, Copilot, followup, collect, and steer paths.

## Best Possible Solution

Fix the queue-state ordering so rawBody changes only after a queued injection is accepted, keep the additive hook API documented and tested, then have maintainers explicitly accept the public contract alongside the broader trusted inbound-decoration direction.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: a queued steer that rejects before transcript commit leaves currentRawBody changed before the await reports failure, and later hook events read that mutated value.

## Solution Assessment

No, not as implemented. The additive hook field is a plausible owner-boundary solution, but the active-run state update must happen only after queue acceptance, and maintainers still need to accept the public plugin contract.
