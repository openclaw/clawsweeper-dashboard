## Label Justifications

- `P2`: The PR is a normal-priority plugin API improvement with a concrete but bounded active-run state bug.
- `merge-risk: 🚨 compatibility`: The diff adds a public optional field to plugin hook event types and docs, creating a contract plugin authors may depend on after release.
- `merge-risk: 🚨 session-state`: The active embedded run stores rawBody as mutable per-run state and the current patch can associate the wrong value with later hook events after queue rejection.
- `merge-risk: 🚨 security-boundary`: rawBody is documented as trusted direct-user input, so provenance-gating mistakes can expose internal or unaccepted text as clean external-user input to plugins.

## Summary

Keep open: the feature is useful and the live/log proof supports the central hook behavior, but the PR still mutates the active run's tracked rawBody before the queued steer is accepted, so a rejected or canceled injection can be misreported in later hook events.

## What This Changes

The PR adds an optional rawBody field to before_prompt_build, before_agent_start, and agent_end plugin hook events and threads it through embedded, CLI, Codex, Copilot, followup, collect, and steer paths.

## Best Possible Solution

Land the hook API only after rawBody state changes are committed after successful queue acceptance, rejection-path tests cover the active-run failure case, and maintainers accept the public plugin-hook semantics alongside the broader inbound-decoration work.

## Reproduction Assessment

Yes by source inspection: the PR sets currentRawBody before awaiting the queue helper, and the queue helper converts active-session steer or transcript-commit rejection into a non-queued outcome. A focused regression test should exercise that rejection path.

## Solution Assessment

No, not yet. The API direction is plausible and better than asking plugins to parse decorated messages, but the active-run state update must happen only after successful queue acceptance and the public hook semantics still need maintainer acceptance.
