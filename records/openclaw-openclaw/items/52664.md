## Summary

Keep this PR open: the hook API addition is still useful and is not implemented on current main, but the branch has a concrete cross-runtime blocker before merge. The embedded path refreshes `rawBody` for queued active-run input, while Codex/Copilot active-run hook events can still report the original turn's `rawBody` after a later user steer is accepted.

## What This Changes

The branch adds an optional `rawBody` field to `before_prompt_build`, legacy `before_agent_start`, and `agent_end` hook events, then threads it through reply, embedded, CLI, Codex, Copilot, queue, collect, steer, docs, and tests.

## Best Possible Solution

Before merge, make Codex and Copilot active-run queue handling update or clear the current hook `rawBody` from queued options exactly like the embedded runner, with focused tests for direct-user steers and internal/system clearing.
