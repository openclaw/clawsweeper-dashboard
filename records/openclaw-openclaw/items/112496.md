## What This Changes

The PR rejects `sessions_send` targets for unconfigured or malformed agent session keys across direct-key, label, and resolved-reference paths, while updating the sessions tests to avoid leaking runtime-config mocks.

## System Context

`sessions_send` lets one OpenClaw agent deliver work into another local session through the Gateway. It first turns a session key, label, or session-id-like reference into a canonical session key, then visibility and dispatch logic can start an agent run; the new check blocks unknown agent identities at that shared canonical stage.
