## What This Changes

The branch rejects malformed or unknown agent targets supplied through `sessions_send` session keys or label resolution before a session, workspace, or model run is created.

## System Context

`sessions_send` turns an agent tool call into a resolved session target, applies visibility and agent-to-agent policy, then dispatches work through the Gateway. This change adds configured-agent validation at the point where direct and label-resolved session keys converge, before downstream session creation and agent execution.

## Architecture Diagram

  B --> C[Resolve label when needed]
  C --> D[Classify key and validate configured agent]
  D -->|valid| E[Resolve visibility and access]
  D -->|unknown or malformed| F[Structured tool error]
  E --> G[Gateway session creation]
  G --> H[Agent run and delivery]

## Best Possible Solution

Rebase onto current `main`, retain the shared key-shape and configured-agent checks before any creation path, and add redacted live Gateway evidence for direct-key and label-resolved unknown-agent calls showing errors with no run/session creation.
