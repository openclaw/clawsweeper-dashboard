## What This Changes

The PR rejects `sessions_send` requests whose direct, label-resolved, or opaque session target maps to an agent absent from configuration, before any agent dispatch can create a run or workspace.

## System Context

`sessions_send` accepts a direct session key, a label lookup, or an opaque stored-session reference, resolves it to a canonical session key, applies visibility and policy checks, then sends the request through the gateway. The new validation sits between resolution and dispatch so an unconfigured agent cannot receive a run.
