  - body: The bridge reads `activityToken` from the page URL, forwards it in the WebSocket query string, and falls back to cleartext `ws://` on HTTP pages. Use a safer token exchange, cookie, or protocol path and fail closed for insecure transport.
  - confidence: 0.9

## Security Review

Status: needs_attention

Summary: The diff introduces public Activity auth, URL token transport, and WebSocket fanout concerns that need security and owner review before merge.

Concerns:
