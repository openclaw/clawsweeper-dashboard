  - body: Current main no longer owns Discord components or Canvas/A2UI routing under these core paths; Discord lives under `extensions/discord` and Canvas routes are registered by `extensions/canvas`.   - body: `isA2uiActivityAccessAllowed` returns true when Activity mode is enabled without a token, and `authorizeCanvasRequest` accepts that before normal Gateway auth. That makes Activity mode an A2UI auth bypass; fail closed unless a real Activity credential or approved exchange is present.

- **[P1] Move Activity config under the Canvas plugin contract:** `src/config/zod-schema.ts:371-377`

  - confidence: 0.93
- **[P1] Stop passing Activity tokens through URLs:** `src/canvas-host/a2ui/index.html:321-325`
  - body: The browser bridge reads `activityToken` from the page URL and appends it to the WebSocket URL, falling back to `ws://` on HTTP. That leaks credentials through URLs, logs, referrers, browser history, and cleartext transport on misconfigured hosts.
  - confidence: 0.92
- **[P2] Bound Activity broadcasts before retaining and fanout:** `src/gateway/a2ui-activity.ts:79-82`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected WebSocket with no byte limit or buffered-send policy. A large payload or slow clients can grow Gateway memory and stall the event loop; enforce payload limits and backpressure before retaining or broadcasting.
  - confidence: 0.9
