Full review comments:

- **[P1] Port Activity handling to plugin-owned paths:** `src/discord/components.ts:35`
  - body: Current main no longer has the old core Discord/Canvas ownership this patch targets; Discord components live under `extensions/discord` and Canvas host/A2UI routes live under `extensions/canvas`. Rebase and implement the Activity action through those plugin-owned surfaces so the code can merge and actually run on current main.
  - confidence: 0.9
- **[P1] Require Activity auth before bypassing Gateway auth:** `src/gateway/a2ui-activity.ts:35-36`
  - body: When Activity mode is enabled and `activity.token` is blank, this returns `true`, and the PR checks it before normal A2UI gateway auth for HTTP and WS. That exposes A2UI on any deployment that enables Activities without a token; require a strong token or verifiable Discord launch assertion before bypassing gateway auth.
  - confidence: 0.92
- **[P1] Move Activity config to the Canvas plugin contract:** `src/config/types.gateway.ts:39-55`
  - body: This adds new `canvasHost.activity` settings to the legacy root Canvas config, but current main hides/migrates root `canvasHost` and owns host config under `plugins.entries.canvas.config.host`. Define the Activity fields in the Canvas plugin schema/migration/docs or remove the config surface until that direction is confirmed.
  - confidence: 0.88
- **[P2] Bound Activity fanout before retaining JSONL:** `src/gateway/a2ui-activity.ts:79-82`
  - body: Every `canvas.a2ui.pushJSONL` stores the full string and sends it to all Activity WebSocket clients without size or slow-client handling. Large or repeated payloads can pin memory or stall the gateway, so reject/truncate oversized payloads and drop slow clients before retaining or broadcasting.
  - confidence: 0.84
- **[P3] Remove the direct changelog edit:** `CHANGELOG.md:16`
  - body: `CHANGELOG.md` is release-owned in this repo; normal feature PRs should carry release-note context in the PR body or squash message instead of editing the generated release file.
  - confidence: 0.78
