## Security Review

Status: needs_attention

Summary: The diff introduces concrete auth bypass, credential-transport, and denial-of-service concerns that need repair before merge.

Concerns:

- **[high] Tokenless Activity mode bypasses Gateway auth:** `src/gateway/a2ui-activity.ts:35`
  - body: `isA2uiActivityAccessAllowed` returns true when Activity mode is enabled without a token, and the PR checks that path before normal Gateway auth for A2UI HTTP and WebSocket requests.
  - confidence: 0.92

  - body: The browser bridge reads the Activity token from the page query string and appends it to the WebSocket URL, which can leak through logs, referrers, history, and non-TLS transport.

  - body: The hub retains arbitrary JSONL and broadcasts it to all WebSocket clients without size limits or slow-client handling, creating a denial-of-service risk on the Gateway process.
