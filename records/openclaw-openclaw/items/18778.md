  - body: This PR still adds the launch action under `src/discord`, but current main no longer has that runtime path; Discord components now live under `extensions/discord`. As written, the branch is stale and cannot land the feature into the active Discord plugin surface.
  - confidence: 0.97

  - body: `isA2uiActivityAccessAllowed` returns true when Activity mode is enabled but no token is configured. Since the Gateway checks this before normal bearer or capability auth, enabling Activity mode can expose A2UI to unauthenticated remote callers.
  - confidence: 0.96

  - confidence: 0.94
- **[P1] Stop carrying Activity tokens in URLs:** `src/canvas-host/a2ui/index.html:321-325`
  - body: The browser bridge reads `activityToken` from the page URL and appends it to the WebSocket query string, with `ws://` fallback on HTTP. That leaks credentials through URLs, logs, referrers, and cleartext transport on misconfigured hosts.
  - confidence: 0.93
- **[P2] Bound Activity broadcasts before fanning out:** `src/gateway/a2ui-activity.ts:79-82`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected Activity WebSocket without a size cap, bufferedAmount check, or slow-client policy. A large A2UI payload or many slow clients can grow memory and stall the Gateway.
  - confidence: 0.9
