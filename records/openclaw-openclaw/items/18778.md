## Security Review

Status: needs_attention

Summary: The diff introduces concrete auth, credential-transport, and denial-of-service concerns that need repair before merge.

Concerns:

- **[high] Tokenless Activity mode bypasses Gateway auth:** `src/gateway/a2ui-activity.ts:35`
  - body: When `canvasHost.activity.enabled` is true and `activity.token` is absent or blank, the new access check returns true before normal Gateway auth, exposing A2UI over a public Activity route.

  - body: The browser bridge reads `activityToken` from the page URL and appends it to the WebSocket query string, falling back to `ws://` on HTTP, which can leak tokens through logs, referrers, history, or cleartext transport on misconfigured hosts.

  - body: The bridge retains arbitrary JSONL and broadcasts it to all WebSocket clients without size limits or slow-client handling, creating a denial-of-service risk on the Gateway process.
