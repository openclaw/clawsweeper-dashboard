  - confidence: 0.88
- **[P1] Stop carrying Activity tokens in URLs:** `src/canvas-host/a2ui/index.html:321-325`
  - body: The bridge reads `activityToken` from the page URL and appends it to the WebSocket URL, including `ws://` on HTTP pages. Move Activity authorization to a non-URL credential exchange or secure cookie and fail closed on non-TLS transport.
  - confidence: 0.86

  - body: Every `canvas.a2ui.pushJSONL` stores the full string and sends it to every connected WebSocket without size or backpressure checks. Large or repeated payloads can pin memory or stall the Gateway; reject or truncate oversized payloads and drop slow clients.
  - confidence: 0.84

## Security Review

Status: needs_attention

Summary: The diff introduces concrete auth bypass, credential-transport, and denial-of-service concerns that need repair before merge.

Concerns:

- **[high] Tokenless Activity mode bypasses Gateway auth:** `src/gateway/a2ui-activity.ts:35`
