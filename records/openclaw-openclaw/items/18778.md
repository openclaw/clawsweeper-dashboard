- **[P1] Port Discord Activity work to current plugin paths:** `src/discord/components.ts:35`
  - body: Current main no longer owns Discord components or Canvas/A2UI routing in `src/discord` and `src/canvas-host`; those surfaces now live under `extensions/discord` and `extensions/canvas`.   - confidence: 0.95
- **[P1] Require Activity credentials before bypassing Gateway auth:** `src/gateway/a2ui-activity.ts:35-36`
  - body: `isA2uiActivityAccessAllowed` returns true when Activity mode is enabled without a configured token, and Gateway auth accepts that before normal auth. Public Activity mode should fail closed unless a real Activity credential or approved exchange is present.
  - confidence: 0.95
- **[P1] Move Activity config under the Canvas plugin contract:** `src/config/zod-schema.ts:371-377`
  - body: The PR adds `canvasHost.activity` under legacy root config, but current main migrates root `canvasHost` into `plugins.entries.canvas.config.host` and hides the root key from public config surfaces. Activity settings need to live in Canvas plugin config or an approved migration path.
  - confidence: 0.93
- **[P1] Stop passing Activity tokens through URLs:** `src/canvas-host/a2ui/index.html:321-325`
  - body: The browser bridge reads `activityToken` from the page URL and appends it to the WebSocket URL, with `ws://` on HTTP. That leaks credentials through URLs, logs, referrers, browser history, and cleartext transport on misconfigured hosts; use a non-URL credential path or server-side exchange.
  - confidence: 0.92
- **[P2] Bound Activity broadcasts before retaining and fanout:** `src/gateway/a2ui-activity.ts:79-82`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected WebSocket with no byte limit or buffered-send policy. A large payload or slow clients can grow Gateway memory and stall the event loop; enforce payload limits and backpressure before retaining or broadcasting.
  - confidence: 0.9
- **[P2] Add a guild id to the Activity launch test:** `src/discord/monitor/monitor.test.ts:325-329`
  - body: Late finding: the handler now returns early for `launch-activity` clicks without `rawData.guild_id`, but this new test fixture omits `guild_id` while expecting the REST callback to fire. Add a guild id or change the expectation so the test proves the intended guild-only launch path.
  - late: true
