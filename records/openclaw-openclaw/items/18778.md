  - body: `activity.enabled` with no configured token currently returns `true`, and the Gateway accepts that before normal auth. That makes A2UI publicly reachable when an operator omits the optional token; require a non-empty credential or launch-context check before bypassing Gateway auth.
  - confidence: 0.95

  - body: The A2UI page pulls `activityToken`/`a2uiToken` from the URL and forwards it into the WebSocket query. These URLs can leak through Discord app configuration, browser history, reverse-proxy logs, referrers, and screenshots; use a launch-context, cookie, or capability handoff that keeps secrets out of URLs.
  - confidence: 0.9
- **[P2] Scope and bound Activity broadcasts before retaining them:** `src/gateway/a2ui-activity.ts:79-82`
  - body: Every `canvas.a2ui.pushJSONL` becomes one global `lastJsonl` and is broadcast to all Activity sockets with no session/node/account scoping or payload cap. That can replay the wrong user's canvas state to another Activity client and lets large JSONL payloads be retained and fanned out repeatedly; key the state by authorized launch context and cap/drop oversized payloads.
  - confidence: 0.88
