## What This Changes

Adds a semantic no-progress watchdog to Ollama setup model pulls, exposes test-only timeout overrides, and adds fake-timer and loopback coverage for dripping and advancing streams.

## Best Possible Solution

Land a progress-aware Ollama setup watchdog that permits unlimited advancing downloads while explicitly defining and testing how the 300-second budget treats duplicate drips, meaningful status-only phase transitions, and slow finalization.
