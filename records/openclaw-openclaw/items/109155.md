## What This Changes

The PR adds a one-hour wall-clock deadline for Ollama setup model-pull response bodies, with fake-timer and loopback regression tests.

## Best Possible Solution

Use a semantic no-progress deadline that resets only when cumulative per-layer completion advances or the pull transitions to a new phase, preserving unlimited healthy progress while terminating repeated no-progress drips.
