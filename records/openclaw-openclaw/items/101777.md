The PR adds stdout/stderr stream-error handling for both Codex sandbox exec-server subprocess owners, extracts streaming HTTP response/error helpers, terminates failed HTTP helpers, and adds lifecycle-sensitive regression tests.

## Best Possible Solution

Keep the stdout/stderr guards and request settlement behavior, but make output-stream failure only record the error, settle the response once, and request termination; retain exactly-once backend finalization exclusively in the child `close` path, then rerun the lifecycle proof on the resulting exact head.
