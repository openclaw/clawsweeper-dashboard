## What This Changes

This PR adds stable managed-image artifact IDs and short-lived Gateway download tickets so generated assistant images can render safely in Android, iOS, macOS, and the Control UI without forwarding a Gateway bearer credential.

## System Context

Generated-image blocks enter chat history from the Gateway and are rendered by native and web chat clients. The PR adds an artifact-download step that turns a transcript-scoped image reference into a short-lived ticketed HTTP fetch, then each client validates and displays the image.
