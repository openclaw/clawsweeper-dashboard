## What This Changes

This PR adds artifact-scoped, short-lived Gateway download tickets so assistant-generated images render in Android, iOS, macOS, and Control UI chat without placing a reusable Gateway bearer credential in image requests.

## System Context

Gateway chat history stores assistant image blocks as managed artifact references. Each client asks the paired Gateway to authorize one transcript artifact, downloads the returned short-lived resource, bounds decoding, and renders the result inline or in a preview.
