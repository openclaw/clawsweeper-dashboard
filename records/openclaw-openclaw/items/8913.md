## Summary

Keep open. Current main still has fixed italic reasoning presentation and no per-channel, per-account, or per-agent reasoning display-format setting; the only direct implementation attempt was closed unmerged after review found incomplete threading.

## What This Changes

Request configurable thinking/reasoning block display formatting, especially for Telegram, with options such as italic, code, spoiler, or blockquote.

## Best Possible Solution

Define one small maintainer-approved reasoning display-format contract, preserve italic as the compatibility default, and thread it through shared agent delivery plus Telegram-owned rendering with schema, docs, and regression tests.

## Reproduction Assessment

Yes. Source inspection is high confidence: current main still has fixed italic-line reasoning display and no reasoning display-format config key; this is a feature gap rather than a runtime bug.

## Solution Assessment

Unclear whether the exact proposed channel-versus-agent config shape is the best permanent API. The maintainable solution is a narrow display-format contract with explicit precedence and compatibility defaults, not another formatter-only option.
