## Summary

Keep open: current main and v2026.6.11 still use a fixed italic-style reasoning presentation and do not expose the requested per-channel or per-agent display-format setting; the only direct implementation attempt is closed unmerged and was incomplete.

## What This Changes

Request to add configurable thinking/reasoning block display format for channels, especially Telegram, with possible per-channel or per-agent defaults.

## Best Possible Solution

Define one maintainer-approved reasoning display-format contract, preserve italic as the compatibility default, and thread it through shared agent delivery plus Telegram-owned rendering with schema, docs, and regression tests.

## Reproduction Assessment

Yes. Source-level reproduction is high confidence: current main still has fixed italic-line reasoning display and no reasoning display-format config key, so this is a feature gap rather than a runtime bug.

## Solution Assessment

Unclear whether the exact proposed channel-versus-agent config shape is the best permanent API. The maintainable solution is a narrow display-format contract with explicit precedence and compatibility defaults, not another formatter-only option.
