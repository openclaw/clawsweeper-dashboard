## Summary

Keep open: current main and v2026.6.11 still use a fixed italic-style reasoning formatter with no per-channel or per-agent display-format config, and the prior implementation attempt is closed unmerged. The remaining work is real, but it needs maintainer direction for the public config surface and precedence rules.

## What This Changes

Request configurable thinking/reasoning block display formats such as italic, code, spoiler, or blockquote, especially for Telegram readability.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through the shared formatter plus channel-owned reasoning callers with focused tests.
