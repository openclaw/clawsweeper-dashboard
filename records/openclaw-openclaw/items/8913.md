## Summary

Keep open. Current main and v2026.6.11 still expose reasoning visibility, but not a per-channel or per-agent reasoning display-format setting; the only direct implementation attempt is closed unmerged after review found incomplete threading.

## What This Changes

The issue requests configurable formatting for visible thinking/reasoning blocks per channel or agent, especially to improve Telegram readability beyond the current italic rendering.

## Best Possible Solution

Define a maintainer-approved reasoning display-format contract, preserve the current italic output as the compatibility default, and thread the selected format through shared agent reasoning delivery plus Telegram-owned rendering with schema, docs, and regression tests.

## Reproduction Assessment

Yes. Source inspection shows current main still has fixed italic-line reasoning display and no channel or agent display-format config key; this is a feature gap rather than a runtime bug.

## Solution Assessment

Unclear whether the exact channel-versus-agent config shape in the issue is the best permanent API. The maintainable solution is a narrow display-format contract with explicit precedence and compatibility defaults, not another formatter-only option.
