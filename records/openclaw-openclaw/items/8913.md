## Summary

Keep open: current main and v2026.6.11 still use fixed italic-style reasoning display with no per-channel or per-agent display-format config, and the prior implementation attempt is closed unmerged. The remaining work is real, but it needs maintainer API and precedence direction before a safe repair PR.

## What This Changes

The issue requests configurable formatting for visible thinking/reasoning blocks per channel or agent, especially to improve Telegram readability.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through all visible reasoning callers with focused default and configured-format tests.
