## Summary

Current main and v2026.6.11 still provide only fixed italic reasoning presentation, and the prior implementation closed unmerged with incomplete runtime threading. Keep this open for the existing maintainer product decision rather than closing or auto-implementing it.

## What This Changes

Add configurable reasoning-block presentation per channel or agent instead of fixed italic formatting.

## Best Possible Solution

If maintainers sponsor this feature, keep reasoning data transport-neutral and add a typed channel-plugin presentation contract with supported modes, italic-compatible defaults, explicit fallback and precedence, aligned schema and docs, and end-to-end Telegram plus sibling-channel coverage.
