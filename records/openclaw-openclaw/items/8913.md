## Summary

Keep open: current main and v2026.6.11 still have fixed italic-style reasoning display with no per-channel or per-agent display-format config, and the prior implementation PR is closed unmerged. The remaining work is real, but the public config/API shape needs maintainer direction.

## What This Changes

The issue requests configurable thinking/reasoning display formatting, especially for Telegram where long italic reasoning blocks are hard to read.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through all visible reasoning callers with focused default and configured-format tests.
