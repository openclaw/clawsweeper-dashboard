## Summary

Keep open: current main and the latest release still expose reasoning visibility but not a per-channel or per-agent reasoning display-format setting, and visible reasoning is still formatted through fixed italic-style paths. The closed implementation attempt at https://github.com/openclaw/openclaw/pull/25336 did not merge and was reviewed as incomplete, so it does not supersede this issue.

## What This Changes

The issue requests a configurable thinking/reasoning display format, especially for Telegram, with options such as italic, code, spoiler, or blockquote at channel or agent-default scope.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through every visible reasoning caller with default and configured-format tests.
