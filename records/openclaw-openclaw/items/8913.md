## Summary

Keep open: current main still has a fixed italic-style reasoning display path and no per-channel or per-agent display-format config; the related implementation attempt is closed unmerged and adjacent Telegram parse/rich-message work does not cover this reasoning-specific contract.

## What This Changes

Request configurable formatting for visible thinking/reasoning messages, especially Telegram choices such as italic, code, spoiler, or blockquote presentation.

## Best Possible Solution

Define one maintainer-approved reasoning display-format contract, preserve the current italic default, specify precedence, and thread it through shared agent delivery plus Telegram rendering with schema, docs, and regression tests.
