## Summary

Keep open: current main and the latest release still use fixed italic-style reasoning display with no per-channel or per-agent display-format setting. The requested gap is real, but the public config surface and precedence rules need maintainer product direction.

## What This Changes

The issue asks for configurable thinking/reasoning block display formatting per channel or per agent, especially to make Telegram reasoning easier to read than fixed italic rendering.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through every visible reasoning caller with focused default and configured-format tests.
