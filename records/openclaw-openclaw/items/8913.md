## Summary

Keep open: current main and v2026.6.11 still provide fixed italic reasoning presentation, the only implementation PR closed unmerged with incomplete runner threading, and the remaining public configuration boundary requires maintainer product direction.

## What This Changes

Add configurable presentation for visible reasoning blocks, potentially at the channel or agent level, with formats such as italic, code, spoiler, or blockquote.

## Best Possible Solution

Define a distinctly named portable reasoning-presentation contract with the current italic form as the default, allow channel overrides only where native capabilities differ, document precedence, and thread the resolved value through core payload, subscription, final-block, Telegram, and Feishu paths with focused integration coverage.
