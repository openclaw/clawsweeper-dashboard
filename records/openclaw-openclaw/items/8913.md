## Summary

Keep open: current main and v2026.6.11 still use one fixed italic reasoning presentation, while the only implementation PR closed unmerged with incomplete runner threading. The user-facing gap is real, but adding a public preference requires maintainer direction on ownership, precedence, supported styles, and cross-channel fallback behavior.

## What This Changes

Add a configurable per-channel or per-agent presentation style for visible reasoning blocks, such as italic, code, spoiler, or blockquote.

## Best Possible Solution

Define a compact portable reasoning-presentation contract only after maintainer approval, preserve the current presentation as the compatibility default, let channel plugins map supported styles with documented fallbacks, and thread the selected style through every shared reasoning-delivery path.
