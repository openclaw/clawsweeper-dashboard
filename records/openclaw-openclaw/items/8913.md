## Summary

Keep open. Current main and v2026.6.11 still expose reasoning visibility, but not a per-channel or per-agent reasoning display-format setting; the only direct implementation attempt is closed unmerged after review found incomplete threading.

## What This Changes

The issue requests configurable display formatting for visible thinking/reasoning blocks, especially to avoid hardcoded italic rendering in Telegram.

## Best Possible Solution

Define a small maintainer-approved reasoning display-format contract, preserve italic as the compatibility default, and thread it through shared agent delivery plus Telegram-owned rendering with schema, docs, and regression tests.

## Reproduction Assessment

Yes. Source inspection shows current main still has fixed italic-line reasoning display and no reasoning display-format config key; this is a feature gap rather than a runtime bug.

## Solution Assessment

Unclear whether the exact proposed channel-versus-agent config shape is the best permanent API. The maintainable solution is a narrow display-format contract with explicit precedence and compatibility defaults, not another formatter-only option.
