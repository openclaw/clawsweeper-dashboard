## Summary

Keep open. Current main and v2026.6.11 still expose reasoning visibility, but not a per-channel or per-agent reasoning display-format setting; the closed implementation attempt at https://github.com/openclaw/openclaw/pull/25336 was not merged.

## What This Changes

Request a configurable display format for reasoning/thinking blocks, especially Telegram alternatives to fixed italic rendering such as code, spoiler, or blockquote.

## Best Possible Solution

Define one small maintainer-approved reasoning display-format contract, preserve italic as the compatibility default, and thread it through shared agent delivery plus Telegram-owned rendering with schema, docs, and regression tests.

## Reproduction Assessment

Yes. Source-level reproduction is high confidence: current main still has fixed italic-line reasoning display and no reasoning display-format config key; this is a feature gap rather than a runtime bug.

## Solution Assessment

Unclear whether the exact proposed channel-versus-agent config shape is the best permanent API. The maintainable solution is a narrow display-format contract with explicit precedence and compatibility defaults, not another formatter-only option.
