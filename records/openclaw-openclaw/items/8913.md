## Summary

Keep open: current main and v2026.6.11 still expose reasoning visibility, but not the requested per-channel or per-agent reasoning display-format setting; the prior implementation attempt closed unmerged after review found incomplete threading.

## What This Changes

Request to add configurable display formatting for visible thinking/reasoning blocks, especially for Telegram readability with code, spoiler, italic, or blockquote-style output.

## Best Possible Solution

Define one maintainer-approved reasoning display-format contract, preserve italic as the compatibility default, specify precedence, and thread it through shared agent delivery plus Telegram-owned rendering with schema, docs, and regression tests.

## Reproduction Assessment

Yes. Source-level reproduction is high confidence: current main still has fixed italic-line reasoning display and no reasoning display-format config key, so this is a feature gap rather than a runtime bug.

## Solution Assessment

Unclear whether the exact proposed channel-versus-agent config shape is the best permanent API. The maintainable solution is a narrow display-format contract with explicit precedence and compatibility defaults, not another formatter-only option.
