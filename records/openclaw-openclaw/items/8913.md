## Summary

## What This Changes

Request to add a per-channel or per-agent configuration option for reasoning/thinking display format, especially to improve Telegram readability.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through the shared formatter plus channel-owned reasoning callers with focused default and configured-format tests.
