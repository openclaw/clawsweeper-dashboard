## Summary

Keep open: current main and v2026.6.11 still use fixed italic-style reasoning display with no per-channel or per-agent display-format config, and the prior implementation attempt is closed unmerged. The remaining gap is real, but the public config surface and precedence rules need maintainer direction.

## What This Changes

The issue requests configurable thinking/reasoning block formatting, especially for Telegram, with display options such as italic, code, spoiler, or blockquote at the channel or agent-default level.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through all visible reasoning callers with focused default and configured-format tests.

## Solution Assessment
