## Summary

Keep open: current main and v2026.6.11 still use fixed italic reasoning presentation, and no merged PR implements configurable formatting. The user need is credible, but maintainers must choose between channel-owned rendering and a new compatibility-sensitive cross-channel config contract.

## What This Changes

Add user-selectable reasoning-block presentation at channel or agent scope instead of always rendering reasoning in italics.

## Best Possible Solution

Keep reasoning identity semantic through delivery and let each channel render it using native capabilities; add a shared semantic presentation preference only if maintainers explicitly approve a stable cross-plugin contract with documented capability fallbacks and channel-over-agent precedence.
