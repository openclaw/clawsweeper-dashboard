## Summary

Keep open: current main and v2026.6.11 still use a fixed italic-style reasoning display with no per-channel or per-agent display-format config, and the prior implementation PR is closed unmerged. The remaining gap is real, but the public config surface and precedence rules need maintainer direction.

## What This Changes

Request to add a configurable thinking/reasoning display format, especially for Telegram, with options such as italic, code, spoiler, or blockquote.

## Best Possible Solution

Define one small reasoning display-format contract with italic as the compatibility default, document precedence, update schema/types/docs, and thread it through all visible reasoning callers with focused default and configured-format tests.

## Solution Assessment

Unclear until maintainers choose the public contract. A shared reasoning presentation contract is safer than a Telegram-only one-off because multiple visible reasoning paths share the same formatter and payload semantics.
