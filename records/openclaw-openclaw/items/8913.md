## Summary

Keep open: current main and v2026.6.11 still use a fixed italic-style reasoning display with no public per-channel or per-agent display-format setting, and the prior implementation attempt is closed unmerged. The remaining work is real, but the config scope, defaults, and channel ownership need maintainer direction.

## What This Changes

Request a configurable thinking/reasoning block display format, especially for Telegram where long italic reasoning is hard to read.

## Best Possible Solution

Define a small reasoning display-format contract that preserves the current italic default, assigns channel versus agent ownership explicitly, wires every reasoning delivery path, and documents/tests the chosen formats.
