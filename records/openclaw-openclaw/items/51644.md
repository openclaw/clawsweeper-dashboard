## What This Changes

Request semantic inbound preprocessing that merges rapid short chat messages, splits or structures multi-topic long messages, and optionally adapts merge windows.

## Best Possible Solution

Keep the fixed inbound debounce baseline, route adaptive timing to https://github.com/openclaw/openclaw/issues/57123 and Telegram bundle metadata to https://github.com/openclaw/openclaw/issues/87002, and decide semantic topic splitting as an opt-in core/plugin API design before implementation.
