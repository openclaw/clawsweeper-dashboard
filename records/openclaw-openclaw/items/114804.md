## What This Changes

The PR initializes the Workboard card-edit dialog from the canonical session resolver and adds rendered UI and Chromium regression coverage so title, notes, or priority edits retain an execution-owned active session.

## System Context

The Control UI opens an edit dialog for a Workboard card and submits the resulting patch through the Gateway to the Workboard plugin store. A session link can be stored directly on the card or on its active execution, and an empty submitted session key is interpreted as an intentional unlink.
