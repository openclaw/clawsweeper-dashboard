## What This Changes

This PR initializes the Workboard card-edit dialog from the canonical card-session resolver so title, note, or priority edits retain execution-owned active session links, with rendered UI and Chromium regression tests.

## System Context

Workboard cards can link an active agent thread either directly on the card or through its running execution. The Control UI reads that link into an edit draft, sends a card update through the Gateway, and the Workboard store applies an empty session key as an intentional unlink.
