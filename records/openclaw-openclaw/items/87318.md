## Summary

Keep open: current main and v2026.6.11 still send the selected Bedrock runtime model id as the AWS Converse `modelId`, so the reported `params.modelId` ARN override remains unresolved even though current code now carries configured params farther into the runtime.

## What This Changes

Request to make the `amazon-bedrock` provider support Haiku 4.5 inference-profile ARN identity for cron/model routing, especially via a `params.modelId` request-identity override.

## Best Possible Solution

Define and document one Bedrock-owned request identity contract, then implement it in the amazon-bedrock runtime/discovery path with cron coverage and live Haiku/profile proof.
