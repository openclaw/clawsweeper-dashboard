## What This Changes

The branch adds a shared UTF-8-safe, bounded line accumulator so MCP stdio stderr and preserved command output retain complete diagnostic lines across stream chunk boundaries, then adds focused regressions.

## System Context

MCP stdio servers emit diagnostics as arbitrary stderr byte chunks while OpenClaw attaches them to agent-side transport setup and debug logging. The new accumulator converts those chunks into bounded, UTF-8-complete lines before MCP logging or command-output preservation consumes them.
