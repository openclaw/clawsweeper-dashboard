## Summary

The patch is technically sound, but merging intentionally changes xAI download timeout semantics and needs an xAI/video owner to accept the new half-request-budget idle cutoff.

The PR adds a per-chunk idle timeout equal to half the resolved xAI video request budget, a provider-specific stall error, and mocked plus real-loopback timeout regressions.

## Best Possible Solution
