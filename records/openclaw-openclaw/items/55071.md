The issue requests a new skill metadata field that lets matched skills activate plugin tool and bundled-skill context per turn.

## Best Possible Solution

Keep this as the specific maintainer design tracker; if accepted, implement one generic activation contract that reuses existing policy/catalog paths and updates skill parsing, snapshots, docs, and compatibility tests together.
