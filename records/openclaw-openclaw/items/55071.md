## Summary

Keep open: current main and the latest release still lack `metadata.openclaw.activates.plugins`. Tool Search and the merged visibility work at https://github.com/openclaw/openclaw/pull/75983 are useful adjacent paths, but neither implements matched-skill plugin activation, so this remains a maintainer product/API design item.

## What This Changes

Request a public skill metadata field, `metadata.openclaw.activates.plugins`, that lets matched skills expose plugin tool schemas and bundled skills only for relevant turns.

## Best Possible Solution

Keep this as a maintainer-owned design item; if accepted, implement one generic activation contract across skill parsing, snapshots, request-time plugin tool planning, docs, and focused precedence tests.
