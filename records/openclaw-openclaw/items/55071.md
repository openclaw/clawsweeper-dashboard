## Summary

Keep open: current main and v2026.6.11 still lack the requested `metadata.openclaw.activates.plugins` contract and matched-skill-driven plugin tool visibility. The merged skills visibility work is useful groundwork, but it explicitly does not implement this behavior, and the broader token/skill-graph issues do not supersede this narrower API decision.

## What This Changes

Add a `metadata.openclaw.activates.plugins` skill metadata contract so matched skills can expose specific plugin tools and bundled skills to the model on demand.

## Best Possible Solution

Keep this as a maintainer-owned design item and settle one generic activation contract that threads parsed skill metadata through skill snapshots into request-time plugin tool planning, with docs and compatibility tests.
