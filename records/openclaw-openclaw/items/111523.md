## Summary

Keep this PR open for a bounded repair: it fixes the reported newline corruption, but the tail-wide code-context rejection still disables Windows-path repair when code-like text precedes a valid drive path in the same JSON value.

## What This Changes

The branch adds a code-context guard before the JSON repair helper’s Windows-path heuristic and regression coverage for multiline Python and shell payloads.

## Best Possible Solution

Scope the exclusion to the actual candidate drive-path suffix, preserving repair for valid Windows paths after code-like command text while retaining the multiline-code regression cases.
