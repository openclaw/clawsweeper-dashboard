## Label Justifications

- `P2`: This is an unshipped current-main Control UI regression with limited scope but clear impact at realistic native-session volume.
- `impact:ux-friction`: Long titles overlap timestamps and large native-session lists obscure the footer, making sidebar navigation difficult while dedicated catalog pages remain available.

## Summary

Current main still contains both reported regressions: native-session titles are not constrained correctly beside timestamps, and the compact sidebar loads and renders catalog-sized session sets. No duplicate tracker or fix PR was found, so this valid protected issue should remain open for explicit maintainer handling.

## What This Changes

Constrain native Codex and Claude session rows and catalog loading so titles truncate, lists stay above the footer, and the compact sidebar shows only a useful recent subset.

## Best Possible Solution

Use a small explicit newest-first per-host sidebar budget for both catalogs, keep full cursor pagination on the dedicated sessions pages, and make the native title wrapper follow the regular sidebar flex/min-width/ellipsis contract; verify with long titles and enough rows to prove timestamps and the footer remain visible.

## Reproduction Assessment

Yes. Current-main markup, CSS, loader logic, and focused tests provide a high-confidence source reproduction for long-title overlap and catalog-sized sidebar rendering, although no live browser run was performed during this read-only review.

## Solution Assessment

Yes in direction. Bounding the compact sidebar independently from full-page pagination and reusing the established regular-row sizing contract is the narrowest maintainable repair; another nested scrolling region would duplicate the existing scroll owner.
