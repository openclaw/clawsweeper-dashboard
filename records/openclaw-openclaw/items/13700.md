## Summary

Keep open: current main still lacks the requested named `/session save` and `/session load` snapshots, reusable templates, arbitrary archive import/restore, and a settled product contract. Existing compaction checkpoint branch/restore, reset-archive fallback reads, and open related items are useful adjacent primitives, but none replaces the broad named snapshot workflow.

## What This Changes

The issue requests named session snapshot commands to save, load, restore, and fork conversation state checkpoints.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that composes existing session store, SessionManager, compaction checkpoint, reset/deleted archive, and subagent fork primitives before exposing save/list/load/branch behavior.
