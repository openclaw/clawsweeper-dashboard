## Summary

Keep open: current main has compaction-scoped checkpoint branch/restore and internal fork/resume primitives, but it still lacks the requested named save/load snapshots, reusable templates, arbitrary archive import, and prompt-cache-aware fork semantics.

## What This Changes

Request first-class session snapshots via `/session save` and `/session load`, plus rollback, branching, reusable templates, and archive-restore use cases.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract with versioned Gateway/session protocol, canonical storage, retention/security rules, save/list/load/branch UX, archive recovery semantics, and focused tests that reuse existing compaction checkpoint primitives where they fit.
