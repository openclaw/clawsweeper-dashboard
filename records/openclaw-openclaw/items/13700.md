## Summary

Keep open: current main and v2026.6.11 have compaction-scoped checkpoint branch/restore and internal fork primitives, but they still do not provide the requested named `/session save` and `/session load` snapshots, reusable templates, or archive import/restore workflow.

## What This Changes

Requests first-class session snapshots that let users save, load, restore, and branch long-running session context by name.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that composes existing session storage, compaction checkpoint, archive, and fork primitives, then expose coherent save/list/load/branch behavior across chat commands, Gateway protocol, CLI/UI, docs, and tests.
