## Summary

Keep open: current main has only compaction-scoped checkpoint branch/restore and reset-archive fallback, while named snapshot save/load, reusable templates, archive import, and a settled product/API contract remain missing.

## What This Changes

Requested explicit session snapshots with `/session save` and `/session load`, plus restore, branching, reusable template, and archive recovery semantics.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that composes existing session store, SessionManager, compaction checkpoint, reset/deleted archive, and subagent fork primitives before exposing save/list/load/branch behavior.
