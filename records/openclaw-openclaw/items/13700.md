## Summary

Keep open: current main has compaction-scoped checkpoint branch/restore and subagent forked context, but it still lacks the requested named `/session save` and `/session load` snapshots, reusable templates, and restore/import from archived transcripts.

## What This Changes

Request to add first-class session snapshots with save/load checkpoint commands, restore semantics, and branching/forking for long-running sessions.

## Best Possible Solution

Define a native session snapshot design that reuses existing session store, SessionManager, compaction checkpoint, archive, and subagent fork primitives, then expose coherent save/list/load/branch semantics across chat commands, Gateway protocol, CLI/UI, docs, and tests.
