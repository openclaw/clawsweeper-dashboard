## Summary

Keep open: current main has compaction-scoped checkpoint branch/restore and a latest reset-archive fallback, but it still lacks the requested named `/session save` and `/session load` snapshots, reusable templates, arbitrary archive import/restore, and a settled product contract.

## What This Changes

The issue requests first-class session snapshots so users can save, load, restore, and branch exact conversation context checkpoints.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that composes existing session store, SessionManager, compaction checkpoint, reset/deleted archive, and subagent fork primitives before exposing save/list/load/branch behavior.
