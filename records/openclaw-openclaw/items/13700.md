## Summary

Keep open: current main and v2026.6.11 still lack the named session snapshot save/load workflow, arbitrary archive restore, and settled snapshot/fork product contract requested here.

## What This Changes

Add first-class session snapshot commands and APIs for saving, loading, restoring, and branching conversation context checkpoints.

## Best Possible Solution

Define a maintainer-approved native snapshot contract that composes SessionManager, session store metadata, compaction checkpoints, reset/deleted archive handling, and fork support before exposing save/list/load/branch behavior across commands, Gateway protocol, CLI/UI, docs, and tests.
