## Summary

Keep open: current main still lacks first-class named session save/load snapshots, reusable templates, arbitrary archive restore, and a settled product/API contract; the related open work covers narrower resume, checkpoint, or archive-recovery slices rather than replacing this issue.

## What This Changes

Request adds named session save/load checkpoints plus restore, branch, and reusable template semantics for long-running OpenClaw sessions.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that composes the session store, SessionManager, compaction checkpoints, reset/deleted archives, and subagent fork primitives before exposing save/list/load/branch behavior.
