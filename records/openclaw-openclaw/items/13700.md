## Summary

Keep open: current main has compaction-scoped checkpoint branch/restore and internal parent-fork primitives, but it still lacks the requested named `/session save` and `/session load` snapshots, reusable templates, and archive import/restore semantics; implementation needs maintainer product/API design.

## What This Changes

The issue requests explicit named session snapshot commands to save, load, restore, and branch/fork conversation context.

## Best Possible Solution

Define a native session snapshot contract that composes SessionManager, session store metadata, compaction checkpoints, reset/deleted archive handling, and parent-fork behavior, then expose coherent save/list/load/branch APIs with docs and tests.
