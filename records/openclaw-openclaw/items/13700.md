## Summary

Keep open: current main has compaction checkpoint branch/restore and export paths, but it still lacks the requested named `/session save` and `/session load` snapshots, reusable templates, prompt-cache-aware forks, and reset/deleted archive import.

## What This Changes

The issue requests native session snapshot commands and APIs to save, load, fork, and reuse exact conversation/context checkpoints.

## Best Possible Solution

Define one native session snapshot design that composes SessionManager transcript lineage, compaction checkpoints, reset/deleted archive discovery, Gateway protocol, chat/CLI/UI commands, security rules, docs, and focused tests.
