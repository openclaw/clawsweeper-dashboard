## Summary

Keep open: current main and v2026.6.11 still lack named `/session save` and `/session load` snapshots, reusable templates, and archive import/restore; existing compaction checkpoint branch/restore and narrower open `/resume` work only cover partial slices.

## What This Changes

The issue requests named session checkpoints plus load/restore/fork behavior for long-running context rollback, branching, and reuse.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that reuses SessionManager, session store metadata, compaction checkpoints, archive handling, and subagent fork primitives, then expose coherent save/list/load/branch semantics with docs and tests.
