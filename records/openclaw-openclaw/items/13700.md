## Summary

Keep open: current main and the latest stable release have compaction-checkpoint branch/restore primitives and internal subagent fork support, but they still lack the requested named `/session save` and `/session load` workflow, reusable templates, arbitrary archive restore/import, and a settled product/API contract.

## What This Changes

Request for first-class session snapshots that can save, load, restore/import, fork, and reuse conversation state.

## Best Possible Solution

Define a maintainer-approved native session snapshot contract that composes the session store, SessionManager, compaction checkpoints, reset/deleted archives, Gateway protocol, CLI/chat/UI surfaces, and subagent fork primitives before exposing save/list/load/branch behavior.
