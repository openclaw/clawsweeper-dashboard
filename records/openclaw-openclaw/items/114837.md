## What This Changes

The branch reuses metadata returned by chat startup, narrows metadata gap-fills, and coalesces sidebar catalog refreshes so timestamp-only session activity does not force a five-second polling cadence.

## System Context

The Control UI opens chats through Gateway startup and metadata requests, then renders available commands and models. Its sidebar separately polls the Gateway session catalog, so metadata completeness and catalog-change detection determine both perceived session-open latency and background request volume.
