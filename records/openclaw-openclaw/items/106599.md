## Summary

Keep open: the prior P1 availability finding remains unchanged on the exact same reviewed head. The single-flight guard prevents overlap, but one indefinitely stalled Discord REST probe can keep the guard occupied forever and suppress every later thread-binding cleanup sweep.

## What This Changes

The PR replaces the Discord thread-binding sweep timer with a single-flight interval helper and adds regression coverage for overlap prevention and guard release after settlement.

## Best Possible Solution

Keep the single-flight scheduling guard, but give the underlying Discord REST lookup an actual abortable deadline and add a regression proving that a never-responding request is cancelled, the guard clears, and a later sweep resumes without leaving uncancellable work behind.
