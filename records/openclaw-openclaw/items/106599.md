## Summary

Keep this PR open: current main still permits overlapping Discord thread-binding sweeps, but this patch can permanently suspend sweeping after one never-settling REST request because the new single-flight guard has no timeout or cancellation path.

## What This Changes

The PR replaces the Discord thread-binding sweep timer with a single-flight interval helper and adds regression coverage for overlap prevention and guard release.

## Best Possible Solution

Keep the single-flight guard, but give the sweeper's Discord REST client a finite timeout with real cancellation and add regression coverage proving that an indefinitely stalled probe cannot overlap and that a later interval resumes after cancellation.
