## What This Changes

The PR makes Discord thread-binding cleanup single-flight, applies a 15-second timeout to sweep-owned REST probes, and adds regression coverage for overlap, timeout, and guard recovery.

## Best Possible Solution

The Discord thread-binding sweeper should retain one in-flight sweep per account, abort each stalled channel probe well before the next 120-second cadence, preserve bindings on transient timeout, and resume normally on a later tick.
