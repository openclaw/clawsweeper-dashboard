## Summary

Keep this PR open: the bounded read prevents unbounded allocation, but the current head still converts an oversized or otherwise rejected registry into the same result as a missing registry, suppressing the audit check without any diagnostic. This is the same unresolved finding from the previous review of this exact head.

## What This Changes

The PR adds a 16 MiB bounded, symlink-preserving reader for the global mcporter registry and regression coverage for oversized and symlinked registry files.

## Best Possible Solution

Return a discriminated registry-read outcome so a genuinely missing file remains non-actionable while oversized, unreadable, malformed, or non-regular inputs produce a stable warning finding; retain bounded symlink support and add focused tests for each outcome after rebasing onto current main.
