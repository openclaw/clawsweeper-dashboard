## Summary

This useful hardening still needs changes before merge: the bounded read prevents excessive allocation, but the latest head silently treats every safely rejected registry as absent, which can hide MCP trust-boundary exposure from the security audit.

## What This Changes

The PR replaces the security audit’s unbounded global mcporter registry read with a 16 MiB regular-file read and adds oversized-file regression coverage.

## Best Possible Solution

Keep the bounded regular-file read, distinguish a genuinely missing registry from rejected inspection, and emit a conservative incomplete-inspection warning when a present registry cannot be safely read.
