## Summary

## What This Changes

The PR persists startup catch-up deferral markers for cron jobs across gateway restarts by adding a catch-up-deferral JSON sidecar plus service state bookkeeping, tests, and a proof script.

## Best Possible Solution

Persist the marker in the SQLite-owned cron runtime store as an internal row/column concept, hydrate it before startup maintenance repair, and clear it when the deferred slot fires or the job becomes irrelevant.
