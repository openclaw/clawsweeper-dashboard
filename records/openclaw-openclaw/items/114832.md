## Summary

This PR addresses a real local-versus-remote classification inconsistency with a focused shared predicate, but it remains open because it carries the protected `maintainer` label and introduces a public Plugin SDK contract that needs maintainer review. The supplied patch, coverage, API baseline, docs update, and CI evidence support the direction; the remaining merge gate is inspectable after-fix runtime proof rather than tests alone.

## What This Changes

The branch exports `isLoopbackHost` from the Plugin SDK and replaces hand-written localhost checks in Codex, Diffs, Nostr, and Ollama so all IPv4 loopback addresses and mapped IPv6 loopback are handled consistently.

## System Context

Several bundled plugins decide whether an incoming client or configured endpoint is on the local machine before allowing local-only behavior or requiring remote authentication. The shared Plugin SDK SSRF runtime is the stable boundary through which plugin code receives host-classification helpers from core networking code.
