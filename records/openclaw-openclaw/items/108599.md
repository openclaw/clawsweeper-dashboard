## Summary

Keep this issue open: the OpenClaw 2026.7.1 report has a concrete same-session HTTP invocation path, while current main now bypasses the A2A announce loop for same-session sends; however, the remaining claude-cli prompt-drift and occasional duplicate-delivery claims have not been verified against current main.

## What This Changes

## Best Possible Solution

Preserve announce synthesis for genuine cross-session A2A calls, verify and ship the current same-session direct-delivery path with a claude-cli regression test, and separately stabilize only true system-prompt bytes if a distinct-session current-main trace still demonstrates reuse drift or duplicate injection.
