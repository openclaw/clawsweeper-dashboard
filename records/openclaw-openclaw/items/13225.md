## Summary

Keep open: current main still lacks the requested post-model, pre-tool-call redirect contract. The existing hook can rewrite params, block, or require approval; ClawRouter adds provider-level managed routing and quotas, but it does not route a pending tool call to a different model/session based on the assistant output or tool call.

## What This Changes

Request a `before_tool_call` enhancement that can inspect preceding model output and redirect a pending tool call to another model or session for delegation, cost, or policy routing.

## Best Possible Solution

Keep this as the canonical maintainer design item for an additive typed pre-tool or continuation-routing contract with explicit security, audit, provider/auth, fallback, and session-state semantics.

## Reproduction Assessment

Yes for the source-level feature gap: current `before_tool_call` event/result/runtime/docs have no preceding-output, redirect, provider/model, or session-target contract. This is not a broken-behavior runtime repro because the item is a feature request.

## Solution Assessment

No for the literal event sketch alone. The maintainable solution is a typed routing phase or hook result that preserves provider/auth, fallback, audit, permission, and session-state contracts.
