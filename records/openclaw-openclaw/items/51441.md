## Best Possible Solution

Yes, at source level: current main still has only requested/runtime `model` and `modelProvider` on public session/status surfaces, while resolved backend and fallback facts remain internal traces or provider-specific fields.

## Solution Assessment

Unclear until maintainers choose the public contract; adding one field only to `session_status` or only to one provider transport would be too narrow for the shared runtime/session/Gateway/UI behavior.
