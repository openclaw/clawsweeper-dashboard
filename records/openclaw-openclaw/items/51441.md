## Summary

Keep open. Current main still has only partial model-attribution plumbing; the requested explicit resolved backend/fallback contract is absent from Gateway session rows, `session_status` details/output, and session usage persistence, so the item remains necessary.

## What This Changes

Expose the actual upstream-resolved provider/model and fallback state to session rows, `session_status`, and agent runtime context instead of showing only the configured or selected model alias.

## Best Possible Solution

Define one additive selected-versus-upstream-resolved model identity contract, derive it from existing response-model and execution-trace plumbing, and surface it consistently in session rows, `session_status`, runtime context, and focused proxy/fallback tests.
