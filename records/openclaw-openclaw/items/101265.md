## What This Changes

The PR lets a cold Gateway startup continue when a built-in TTS provider API-key SecretRef has no value, leaving that provider unconfigured while retaining strict reload and config-write validation.

## Best Possible Solution

If maintainers accept availability over global fail-fast behavior for optional TTS, land the missing-value-only cold-start exception after rerunning the live Gateway scenario on the exact head, while keeping reload, restart-check, write preflight, malformed refs, policy failures, and provider-contract failures strict.
