## Summary

Keep open for maintainer review: the patch looks technically sound and fixes the linked Gateway-startup bug, but it intentionally changes the SecretRef fail-closed boundary for built-in TTS provider keys, so a maintainer should accept that policy before merge.

## What This Changes

The PR marks TTS provider API-key SecretRef assignments optional, downgrades missing optional TTS values to structured warnings, keeps required/policy/shape failures fail-closed, and updates tests and docs.

## Best Possible Solution

Land the scoped TTS optional-SecretRef behavior after maintainer security-boundary acceptance, exact-head CI completion, and a decision on whether status/doctor visibility is required before merge.
