## Summary

## What This Changes

The branch stops Google Chat, LINE, Mattermost, and Zalo from placing `<media:…>` placeholder text in primary inbound bodies, preserves structured media facts, and adds a formatter for text-only channel carriers.

## Best Possible Solution

Keep structured media as the canonical channel contract, but add a downstream ACP-safe text fallback for unsupported captionless media and have prompt-note rendering omit facts with neither a usable path nor URL; then show redacted after-fix channel evidence for successful and failed media-only cases.
