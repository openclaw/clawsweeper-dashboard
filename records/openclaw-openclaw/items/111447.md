## Summary

This PR should remain open. The structured-media direction follows the earlier merged consumer cleanup, but the current producer changes introduce a dispatch regression for captionless non-image LINE and Mattermost attachments and can present blank attachment paths to model prompts; the `maintainer` label also requires explicit human handling rather than cleanup closure.

## What This Changes

The branch removes `<media:…>` primary bodies in Google Chat, LINE, Mattermost, and Zalo, carries structured native attachment facts instead, and adds a public formatter for text-only channel carriers.

## Best Possible Solution

Keep structured native facts as the canonical transport data, but make the shared downstream projection omit non-materialized facts from attachment-path prompt lines and retain formatter-derived fallback text whenever ACP cannot dispatch the attachment type itself.
