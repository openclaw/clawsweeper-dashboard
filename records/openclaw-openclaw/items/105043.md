## Summary

Current main still enters the full CLI bootstrap on every guarded Gateway restart and checks the recorded version only inside doctor preflight, after migration-heavy modules are loaded. The issue remains a well-reproduced current-main performance regression with no canonical replacement; its active assignment and protected `maintainer` label require owner-led follow-up.

## What This Changes

Avoid loading and traversing completed startup migrations on same-version Gateway restarts.

## Best Possible Solution

Consult the existing lightweight version checkpoint before importing doctor and plugin migration modules, while preserving config rechecks, lease ownership, heartbeat, migrations, convergence, and checkpoint recording whenever state is fresh, incomplete, or from another version.
