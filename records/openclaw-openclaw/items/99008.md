- **[P1] Use the provider request language for prompt suppression:** `src/media-understanding/runner.entries.ts:426-427`
  - body: This computes the language for `resolvePrompt` from `entry.language` before the request-scoped override that is actually sent to the provider. With a model entry like `language: "en"` and a CLI/runtime call passing `--language ru`, the request will send `language=ru` but prompt resolution will still see English and keep `Transcribe the audio.`, leaving the reported bug in the documented per-request path. Please resolve the effective audio language once, with request overrides first, and pass that same value to both the prompt resolver and provider request.
