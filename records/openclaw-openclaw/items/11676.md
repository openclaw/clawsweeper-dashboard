## Summary

Keep open: current main still ships a Node/OS-hosted runtime, and the private TypeScript agent-core plus plugin/harness seams do not provide the requested runtime-neutral no-Node or bare-metal protocol. Related browser/WASM and plugin runtime issues are adjacent or narrower, so this remains the canonical product/API discussion for MimiClaw-style embedded portability.

## What This Changes

Request support for running OpenClaw on no-Linux/no-Node devices such as ESP32-class microcontrollers by defining or decoupling a runtime-agnostic agent core/protocol, with MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for whether OpenClaw should own a runtime-neutral agent-core contract with schemas, conformance tests, platform adapters, and a reference non-Node runtime boundary.
