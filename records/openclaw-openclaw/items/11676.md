## Summary

Keep open: current main and the latest release still require a Node-hosted OpenClaw runtime, while the existing agent-core package and harness/plugin seams do not provide the requested bare-metal/no-Node agent-core protocol.

## What This Changes

Request support for running an OpenClaw-style agent loop on embedded or ultra-low-resource devices without Linux or Node.js by defining runtime-agnostic core protocols and platform adapters.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and the core-versus-external-port decision.

- **Close As Not Planned:** Decide that OpenClaw remains Node-hosted and external projects such as MimiClaw are independent ports without compatibility promises.
