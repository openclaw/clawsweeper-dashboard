## Summary

Keep open: current main and the latest release remain Node-hosted, and the current TypeScript agent-core, harness, and plugin-extension surfaces do not provide the requested bare-metal/no-Node runtime protocol. This remains the canonical runtime-portability product/API discussion, with MimiClaw useful external prior art.

## What This Changes

The issue requests a runtime-agnostic OpenClaw agent core or protocol that can run without Linux or Node.js on embedded and ultra-low-resource devices.

## Best Possible Solution

Keep this as the canonical runtime-portability RFC and define stable schemas, platform adapter boundaries, security/session semantics, and conformance proof before accepting embedded, WASM, or bare-metal runtime implementation work.

- **Close As Not Planned:** Decide that OpenClaw remains Node-hosted and external projects such as MimiClaw are independent ports without compatibility promises.
