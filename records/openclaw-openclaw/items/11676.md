## Summary

Keep open: current main and v2026.6.11 still require a Node-hosted CLI/Gateway, and the private TypeScript `@openclaw/agent-core` package plus current harness/plugin seams do not provide the requested bare-metal/no-Node OpenClaw runtime protocol. MimiClaw is useful prior art, while related WASM/plugin issues are narrower or adjacent rather than a replacement tracker.

## What This Changes

Request support for running OpenClaw’s agent loop on no-Linux/no-Node embedded or low-resource devices through runtime-agnostic core interfaces and reference implementations.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and the core-versus-external-port decision.
