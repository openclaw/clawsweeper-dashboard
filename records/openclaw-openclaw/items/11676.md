## Summary

Keep open: current main and v2026.6.11 still make OpenClaw a Node-hosted TypeScript/Gateway runtime, while the newer agent-core and harness surfaces are useful in-process groundwork rather than a stable runtime-neutral protocol for bare-metal, C/Rust/WASM, or ESP32-class ports.

## What This Changes

The issue requests runtime-agnostic, no-Node support for embedded and ultra-low-resource devices, using MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for whether OpenClaw should own a stable runtime-neutral agent-core protocol, platform-adapter boundary, schemas, conformance tests, and reference docs before any embedded/no-Node implementation is attempted.
