## Summary

Keep open: current main and the latest release remain Node-hosted, and the existing agent-core, plugin SDK, Gateway, and harness surfaces do not provide the requested bare-metal/no-Node runtime protocol. This is still a broad maintainer product/API decision, not a conservative cleanup close.

## What This Changes

The issue requests runtime-agnostic OpenClaw support for no-Linux/no-Node devices such as embedded boards and microcontrollers.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a minimal runtime-neutral agent-core contract, including schemas, platform adapters, security boundaries, and conformance proof before accepting embedded or WASM implementation work.
