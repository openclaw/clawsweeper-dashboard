## What This Changes

Request support for running OpenClaw without Linux or Node.js on embedded, microcontroller, or other ultra-low-resource devices.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract, including schemas, platform adapters, security boundaries, and conformance proof before accepting embedded or WASM implementation work.
