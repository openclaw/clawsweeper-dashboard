## Summary

Keep open. Current main and v2026.6.11 contain a reusable private TypeScript agent-core, but OpenClaw still requires Node and provides neither a stable cross-language protocol nor a supported bare-metal runtime. MimiClaw is credible external prior art, while the related browser, WASM-plugin, and JSON-RPC-plugin items do not own this broader product decision.

## What This Changes

Request a runtime-agnostic OpenClaw agent core or protocol for non-Node, bare-metal, C/Rust/WASM, and microcontroller ports.

## Best Possible Solution

Keep this issue as the product-direction tracker and, if sponsored, begin with a narrow versioned protocol RFC plus conformance tests against MimiClaw or another constrained reference runtime rather than attempting to port the entire Node codebase.

Options:

- **Sponsor Protocol RFC (recommended):** Define a minimal versioned event, tool, session, model, and capability contract with conformance tests on a constrained reference runtime.
- **Remain Node-Hosted:** Keep Node and an operating system as the supported runtime boundary and treat MimiClaw-style ports as independent adaptations.
- **Limit To Plugin RPC:** Support non-TypeScript implementation code only through the narrower plugin process boundary tracked in https://github.com/openclaw/openclaw/issues/98004.
