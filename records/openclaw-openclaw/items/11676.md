## Summary

The remaining request is still not implemented on current main or the latest release: OpenClaw remains a Node-hosted CLI/Gateway, and the newer agent-core/harness work is TypeScript/OpenClaw-process groundwork rather than a bare-metal/no-Node protocol. This issue should stay open for maintainer runtime/API product direction, not close as ClawHub-only or as a duplicate of narrower WASM/plugin requests.

## What This Changes

Requested support for a runtime-agnostic or no-Node OpenClaw agent path for embedded, microcontroller, WASM, Rust/C/C++, or similarly constrained environments.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and a decision on what belongs in core versus external ports or plugin APIs.
