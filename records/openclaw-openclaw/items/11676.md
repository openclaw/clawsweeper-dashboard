## Summary

Keep open: current `main` and v2026.6.11 still require a Node-hosted OpenClaw runtime, and the existing plugin/harness seams do not provide the requested bare-metal/no-Node agent-core protocol.

## What This Changes

The issue requests runtime-agnostic OpenClaw support for embedded, microcontroller, WASM, C/C++, or Rust environments that cannot host Linux or Node.js.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and the core-versus-external-port decision.
