## Summary

Keep open: current main and the latest stable release still require a Node-hosted OpenClaw runtime, while the available agent-core and harness surfaces do not provide the requested no-Node, bare-metal, or microcontroller-compatible agent protocol.

## What This Changes

The issue asks to define runtime-agnostic/no-Node OpenClaw support for embedded and ultra-low-resource devices, using MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and the decision on whether OpenClaw supports external no-Node ports as compatible implementations.
