## What This Changes

The issue asks OpenClaw to support a runtime-agnostic agent loop and protocol for no-Node/no-Linux devices such as embedded or microcontroller targets, using MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical runtime-portability design issue and define minimal schemas, platform-adapter boundaries, security rules, and conformance proof before accepting embedded or WASM runtime implementation work.

- **Close As Not Planned:** Decide that OpenClaw remains Node-hosted and external projects such as MimiClaw are independent ports without compatibility promises.
