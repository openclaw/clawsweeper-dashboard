## Summary

Keep open for an explicit product/API decision. Current main has extracted reusable agent-core code, but OpenClaw remains a Node-hosted TypeScript gateway and has no stable cross-language, bare-metal agent-runtime contract; the prior maintainer follow-up also keeps this broader request active.

## What This Changes

The issue requests a runtime-agnostic OpenClaw agent-core protocol and platform adapters so embedded or bare-metal devices can run an OpenClaw-compatible loop without Linux or Node.js.

## Best Possible Solution

Decide whether OpenClaw should own a stable external agent-runtime compatibility contract; if yes, start with a narrowly versioned protocol and conformance suite that separates portable loop events from Node-hosted gateway, tool, credential, and platform capabilities.
