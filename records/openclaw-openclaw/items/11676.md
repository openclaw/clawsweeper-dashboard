## Summary

Keep open: current main and the latest release are still Node-hosted, and the current TypeScript agent-core plus agent-harness surfaces do not provide the requested no-Linux/no-Node runtime ABI. MimiClaw is useful external prior art, while https://github.com/openclaw/openclaw/issues/98004 is only a partial plugin-language overlap, so this remains a maintainer runtime/API product decision.

## What This Changes

Request support or a runtime-agnostic agent-core protocol so OpenClaw-style loops can run on no-Linux/no-Node embedded devices, using MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical runtime-portability RFC and define minimal schemas, platform adapters, security boundaries, and conformance proof before accepting embedded, WASM, C, or Rust runtime implementation work.

- **Close As Not Planned:** Decide that OpenClaw remains Node-hosted and external projects such as MimiClaw are independent ports without compatibility promises.
