## Summary

Keep open: current main and the latest release remain Node-hosted, while the newer agent-core and JSON-RPC/plugin surfaces do not provide the requested no-Node, bare-metal, runtime-neutral OpenClaw protocol. This is still a maintainer product/API direction issue, not a conservative cleanup close.

## What This Changes

Request support for a runtime-neutral OpenClaw agent core/protocol that can run on no-Node, no-Linux embedded devices such as ESP32-class systems.

## Best Possible Solution

Keep this as the canonical runtime-portability RFC for a minimal agent-core contract, platform adapters, security boundaries, and conformance proof before accepting embedded or WASM runtime implementation work.

- **Close As Not Planned:** Decide that OpenClaw remains Node-hosted and external projects such as MimiClaw are independent ports without compatibility promises.
