## Summary

Keep open: current main and v2026.6.11 still require a Node-hosted OpenClaw runtime, while the newer `@openclaw/agent-core` package is a TypeScript/private package with Node execution helpers rather than a stable no-Node or bare-metal agent protocol.

## What This Changes

Request support for running OpenClaw-style agent loops on no-Linux/no-Node devices such as microcontrollers, using MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical runtime-portability design issue until maintainers choose whether OpenClaw should define a stable no-Node agent-core protocol, conformance tests, and platform-adapter boundary.
