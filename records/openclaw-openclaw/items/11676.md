## Summary

Keep open: current main and the latest release still require a Node-hosted OS runtime, while the newer agent-core and harness surfaces are TypeScript/OpenClaw-process contracts rather than the requested no-Linux/no-Node embedded runtime protocol. MimiClaw is useful external prior art, but it does not make OpenClaw core runtime-agnostic today.

## What This Changes

Request to support OpenClaw-style agent loops on no-Linux/no-Node embedded or ultra-low-resource devices by decoupling agent core and defining a runtime-agnostic protocol.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and a clear decision on what belongs in OpenClaw core versus external ports or plugin APIs.

## Solution Assessment
