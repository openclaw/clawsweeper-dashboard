## Summary

Keep open for explicit product/API direction. Current main and v2026.6.11 remain Node-hosted; the extracted TypeScript agent-core and native harness SDK do not provide a versioned language-neutral protocol for bare-metal, C, Rust, or WASM implementations, and the open JSON-RPC plugin proposal covers a narrower child-process plugin bridge.

## What This Changes

Request a runtime-agnostic OpenClaw agent-core protocol and platform-adapter boundary for bare-metal, embedded, or other non-Node runtimes.

## Best Possible Solution

First decide whether OpenClaw compatibility extends beyond the Node-hosted product; if sponsored, define a small versioned protocol, explicit platform capabilities, and conformance tests before adding reference ports, while keeping MimiClaw linked as prior art.
