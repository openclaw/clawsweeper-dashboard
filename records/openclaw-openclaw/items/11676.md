Request support for running OpenClaw concepts on no-Linux/no-Node devices by defining a runtime-agnostic agent core, protocol, and platform adapter boundary.

## Best Possible Solution

Keep this as the canonical runtime-portability design issue and define schemas, platform adapters, security boundaries, and conformance proof before accepting embedded or WASM runtime implementation work.
