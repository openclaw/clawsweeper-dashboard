## What This Changes

The issue requests runtime-agnostic OpenClaw support for no-Node/no-Linux devices such as microcontrollers, inspired by MimiClaw.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and the core-versus-external-port decision.
