## Summary

Keep open: current main and the latest release are still Node-hosted, and the newer private agent-core package plus harness/plugin seams do not provide the requested bare-metal/no-Node runtime protocol. The remaining work is a broad runtime/API product decision, not conservative cleanup.

## What This Changes

Request to support OpenClaw-compatible agent runtimes on embedded, bare-metal, or other no-Node devices through runtime-neutral protocol and adapter boundaries.

## Best Possible Solution

Keep this as the canonical maintainer RFC for a runtime-neutral agent-core contract, with schemas, platform adapters, security boundaries, and conformance proof before accepting embedded or WASM implementation work.
