## Summary

Keep open: current main and v2026.6.11 still enforce a Node-hosted OpenClaw CLI/Gateway, and the existing agent-core and harness surfaces are in-process TypeScript/Node contracts rather than a runtime-neutral protocol for bare-metal, C/Rust/WASM, or ESP32-class ports.

## What This Changes

The issue requests a runtime-agnostic OpenClaw agent/core protocol so OpenClaw-style loops can run on bare-metal, microcontroller, C/Rust/WASM, or otherwise non-Node environments.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and a decision on what belongs in core versus external ports or plugin APIs.
