## Summary

Keep open: current main and the latest release still run OpenClaw as a Node-hosted TypeScript CLI/Gateway, while the existing agent-core and harness surfaces are in-process TypeScript/plugin contracts rather than a runtime-neutral protocol for bare-metal, C/Rust/WASM, or ESP32-class ports.

## What This Changes

The issue requests runtime-agnostic OpenClaw support for devices without Linux or Node.js, using MimiClaw as prior art.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and a clear decision on what belongs in core versus external ports or plugin APIs, with MimiClaw retained as prior art.
