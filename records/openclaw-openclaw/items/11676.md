## Summary

Keep open: current main and v2026.6.11 still require an OS-hosted Node runtime, and the newer internal agent-core/harness work does not provide the requested bare-metal/no-Node compatibility protocol. MimiClaw is useful prior art, but this remains a core runtime/API product decision rather than a ClawHub-only package handoff.

## What This Changes

Request support for running OpenClaw-style agents on devices without Linux or Node.js by decoupling the agent loop and defining a runtime-agnostic protocol for embedded or lightweight runtimes.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract with schemas, conformance tests, platform-adapter boundaries, and a clear core-versus-external-port policy.

- **Close As Not Planned:** Decide that OpenClaw remains a Node-hosted TypeScript/Gateway product and that external projects such as MimiClaw do not receive a compatibility promise.
