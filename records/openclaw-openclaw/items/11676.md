## Summary

Keep open: current main and the latest release remain Node-hosted, and the existing TypeScript agent-core, plugin SDK, and harness surfaces do not provide the requested bare-metal/no-Node runtime protocol. This is still a maintainer product/API direction item, with MimiClaw as useful external prior art rather than an implementation already in OpenClaw core.

## What This Changes

Requested support for running OpenClaw-style agents on no-Linux/no-Node embedded devices, including a runtime-agnostic agent protocol and lightweight reference path inspired by MimiClaw.

## Best Possible Solution

Keep this as the canonical runtime-portability RFC issue and define a minimal agent-core protocol, platform adapter boundary, security model, and conformance proof before accepting embedded, C/Rust, or WASM implementation work.
