## Summary

Keep open: current main and v2026.6.11 still require a Node-hosted OpenClaw CLI/Gateway, and the current agent-core and harness surfaces are TypeScript/OpenClaw-process contracts rather than a runtime-neutral bare-metal or no-Node protocol. MimiClaw is useful external prior art, but this remains a maintainer product/API design decision rather than a cleanup close.

## What This Changes

Request to make OpenClaw portable to no-OS/no-Node devices by defining a runtime-agnostic agent core or protocol, inspired by MimiClaw.

## Best Possible Solution

Keep this as the canonical design item for a runtime-neutral agent-core protocol and conformance story, using MimiClaw as external prior art while maintainers decide what belongs in core, plugin APIs, ClawHub packages, or independent ports.
