## Summary

Current main still provides a Node-hosted OpenClaw runtime with experimental, host-coupled plugin and agent-harness seams. The merged agent-core extraction improves internal ownership but does not provide the requested stable cross-language, bare-metal compatibility contract, so the explicit product/API decision remains unresolved.

## What This Changes

Request a runtime-agnostic OpenClaw agent core for bare-metal, embedded, C/C++/Rust, or WASM runtimes without Node.js.

## Best Possible Solution

If maintainers intend to support independent hosts, define a versioned external agent-runtime protocol covering turns, events, tools, auth and model selection, session persistence, platform capabilities, security rules, and conformance tests, then demonstrate it with a constrained reference port.
