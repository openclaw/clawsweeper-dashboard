## Summary

Keep open: current main and v2026.6.11 still require a Node-hosted OpenClaw runtime, while the existing plugin and harness seams do not provide the requested bare-metal/no-Node agent-core protocol.

## What This Changes

The issue requests runtime-agnostic OpenClaw support for non-Linux/non-Node environments such as embedded devices and microcontrollers.

## Best Possible Solution

Keep this as the canonical maintainer design issue for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and the core-versus-external-port decision.

- **Close As Not Planned:** Decide that OpenClaw remains Node-hosted and external projects such as MimiClaw are independent ports without compatibility promises.
