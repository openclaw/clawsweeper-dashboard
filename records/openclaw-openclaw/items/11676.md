## Summary

Keep open: current main and v2026.6.11 are still Node-hosted, while the agent-core and harness surfaces remain TypeScript/OpenClaw-hosted plugin APIs rather than a runtime-neutral no-Node protocol. MimiClaw is useful external prior art, but it does not make this repository implement the requested embedded/bare-metal contract.

## What This Changes

Request support for running OpenClaw-style agents on no-Linux/no-Node embedded devices by defining a runtime-agnostic core/protocol and adapter boundary.

## Best Possible Solution

Keep this as the canonical design issue for deciding whether OpenClaw should define a runtime-neutral agent-core contract, then specify schemas, conformance tests, platform adapters, and the boundary between supported core compatibility and independent ports.
