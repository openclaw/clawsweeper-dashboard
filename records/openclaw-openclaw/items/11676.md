## Summary

Keep open: current main and the latest release still require an OS-hosted Node runtime, and the newer TypeScript agent-core/harness work is not the requested runtime-neutral contract for bare-metal, C/Rust/WASM, or ESP32-class ports.

## What This Changes

The issue requests runtime-agnostic support so OpenClaw-style agents can run without Linux or Node.js, including embedded, C/Rust/WASM, and microcontroller targets.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, conformance tests, platform-adapter boundaries, and a clear core-versus-external-port decision.

## Reproduction Assessment

## Solution Assessment

Unclear. Existing TypeScript agent-core and harness work is useful groundwork, but the permanent solution requires maintainer direction on whether OpenClaw should own a stable runtime-neutral protocol, extend plugin APIs, publish reference docs, or decline the core scope.
