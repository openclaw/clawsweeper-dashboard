## Summary

Keep open: current main and the latest release still require a Node-hosted OpenClaw CLI/Gateway, and the existing agent-core/harness/plugin seams do not provide the requested bare-metal or no-Node runtime protocol.

## What This Changes

The issue requests runtime-agnostic support so OpenClaw-style agent loops can run on embedded or ultra-low-resource devices without Linux or Node.js.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral OpenClaw agent protocol, conformance tests, platform-adapter boundaries, and the core-versus-external-port decision.
