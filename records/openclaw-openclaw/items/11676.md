## Summary

Keep open: current main and v2026.6.11 still require a Node-hosted OpenClaw CLI/Gateway, and the existing plugin/agent-harness seams are in-process Node SDK surfaces rather than a runtime-agnostic embedded/no-Node agent-core protocol.

The issue requests support for running OpenClaw-style agents on embedded or ultra-low-resource devices without Linux or Node.js, inspired by MimiClaw.
