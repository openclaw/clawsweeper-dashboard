## Summary

Keep open: current main and v2026.6.11 still require a Node-hosted CLI/Gateway, while the current `@openclaw/agent-core` and harness/plugin seams are TypeScript/Node-oriented surfaces rather than the requested runtime-neutral protocol for bare-metal, C/Rust/WASM, or ESP32-class ports.

## What This Changes

The issue requests a runtime-agnostic OpenClaw agent core/protocol that can run without Linux or Node.js on embedded or ultra-low-resource devices.

## Best Possible Solution

Keep this as the canonical maintainer design discussion for a runtime-neutral agent-core contract, platform-adapter boundary, conformance tests, and the decision about which embedded ports belong in core versus external projects.
