## What This Changes

The branch adds a build-all node-step argument resolver that falls back from native TypeScript stripping to `node --import tsx` for `.ts` scripts when Node lacks `process.features.typescript`, plus focused regression tests.

## Best Possible Solution

Land the build-all fallback if maintainers accept the scoped fix, and track direct package-script compatibility separately only if OpenClaw wants a broader source-build guarantee on Node builds without native TypeScript stripping.
