## Summary

Keep open for maintainer review: current main and the latest release still route build-all TypeScript script steps through raw `--experimental-strip-types`, while this PR adds a narrow fallback with sufficient real-environment proof and no blocking review findings.

## What This Changes

The PR changes `scripts/build-all.mjs` to route build-all `node --experimental-strip-types <script>.ts` steps through `node --import tsx` when Node lacks native TypeScript support, with focused regression tests.

## Best Possible Solution

Land the narrow build-all fallback after maintainer review if build-all-only scope is acceptable, and track broader direct-script source-build compatibility separately if maintainers want that guarantee.

## Reproduction Assessment

Yes. Source inspection shows current main and `v2026.6.11` still pass build-all `.ts` steps directly to `--experimental-strip-types`, and the PR body supplies real affected-host proof with `process.features.typescript=false`.

## Solution Assessment

Yes for the reported `pnpm build` path. `resolveBuildAllStep` is the command-selection boundary, the fallback reuses the existing `tsx` dependency, and broader direct package-script compatibility can be handled separately if desired.
