## Summary

Keep open: current main and the latest release still run build-all TypeScript script steps through `node --experimental-strip-types` with no fallback, while this PR narrowly adds a `tsx` fallback plus focused regression coverage and supplied real-environment proof. I found no blocking patch findings; the remaining action is maintainer review of the build-all-only scope and normal check gating.

## What This Changes

The branch changes `scripts/build-all.mjs` to rewrite build-all `node --experimental-strip-types <script>.ts` steps to `node --import tsx <script>.ts` when Node lacks native TypeScript support, with regression tests for fallback and passthrough behavior.

## Best Possible Solution

Land the build-all fallback if maintainers accept that scope, and track direct package-script compatibility separately only if the project wants a wider no-native-TypeScript source-build guarantee.

## Reproduction Assessment

Yes. Source inspection shows current main still passes `--experimental-strip-types` `.ts` build-all steps through unchanged, and the PR body supplies live output from a Node v24.15.0 environment where `process.features.typescript=false`.

## Solution Assessment

Yes for the reported `pnpm build` path. `resolveBuildAllStep` is the command-selection boundary, and this is narrower than changing all package scripts or replacing the build orchestration.
