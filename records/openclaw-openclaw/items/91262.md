## What This Changes

The PR changes `scripts/build-all.mjs` to rewrite build-all `node --experimental-strip-types <script>.ts` steps to `node --import tsx <script>.ts` when Node lacks native TypeScript support, with regression tests.

## Best Possible Solution

Land the build-all fallback after normal maintainer review and refresh if maintainers accept `pnpm build` as the support boundary; track direct package-script no-native-TypeScript compatibility separately only if that wider guarantee is desired.

## Reproduction Assessment

Yes. Source inspection shows current main invokes `node --experimental-strip-types` for build-all `.ts` steps, and the PR body supplies affected-host output where `process.features.typescript` is false and the build previously failed there.

## Solution Assessment

Yes for the reported `pnpm build` path. `resolveBuildAllStep` is the command-selection boundary, and using the existing `tsx` dependency is narrower than rewriting all package scripts or changing build orchestration.
