## Summary

Keep this PR open: current main and the latest release still route build-all TypeScript script steps through native strip-types only, while the PR adds a narrow fallback with focused regression coverage and sufficient real-environment proof.

## What This Changes

This PR updates build-all node-step argument resolution to run `--experimental-strip-types` TypeScript scripts through `node --import tsx` when Node reports no native TypeScript support, with regression tests.

## Best Possible Solution

Land the narrow build-all fallback if maintainers accept the build-all-only scope, and track broader direct package-script compatibility separately only if that source-build guarantee is desired.

## Reproduction Assessment

Yes. Source inspection shows current main still passes native strip-types args unchanged, and the PR body supplies live output from an affected Node v24 host where `process.features.typescript=false`.

## Solution Assessment

Yes for the reported `pnpm build` path. `resolveBuildAllStep` is the build-all command-selection boundary, and this is narrower than rewriting all package scripts or changing OpenClaw's default native strip-types preference.
