- `P2`: The PR fixes a real but bounded source-checkout build failure on Node distributions without native TypeScript stripping support.

## Summary

Keep open: the PR remains useful because current main and the latest release still pass build-all TypeScript script steps through native `--experimental-strip-types`, while the proposed merge result adds a narrow `tsx` fallback with focused regression coverage and sufficient supplied live proof.

## What This Changes

The PR rewrites build-all node steps from `--experimental-strip-types <script>.ts` to `--import tsx <script>.ts` only when the current Node binary does not report native TypeScript support, and adds build-all resolver tests.

## Best Possible Solution

Land the narrow build-all fallback if maintainers accept the build-all-only scope, and track broader direct package-script compatibility separately only if that wider guarantee is desired.

## Reproduction Assessment

Yes. Source inspection shows current main and `v2026.6.11` pass build-all `.ts` strip steps through unchanged, and the PR body supplies live affected-host proof for a Node binary with `process.features.typescript === false`.

## Solution Assessment

Yes for the reported `pnpm build` path. `resolveBuildAllStep` is the command-selection boundary, and reusing the existing `tsx` loader is narrower than rewriting all package scripts or replacing the native strip-types path globally.
