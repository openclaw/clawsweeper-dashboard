## Summary

Keep this PR open: current main still routes build-all TypeScript script steps through native `--experimental-strip-types`, while the branch adds a narrow fallback with focused coverage and sufficient real-environment proof. I found no blocking patch defects; the remaining action is normal maintainer review and exact-head merge/check gating.

## What This Changes

The branch adds a build-all helper that rewrites `node --experimental-strip-types <script>.ts` steps to `node --import tsx <script>.ts` when native Node TypeScript stripping is unavailable, plus focused regression tests.

## Best Possible Solution

Merge the narrow build-all fallback after normal exact-head checks; treat direct package-script support for Node builds without native TypeScript stripping as a separate follow-up only if maintainers want that wider contract.
