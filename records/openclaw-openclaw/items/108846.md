## Summary

This PR should stay open but is not merge-ready: current `deleteSession()` is intentionally a visibility-only registry operation, while the process tool owns cancellation and tree termination before removing a live session. The branch bypasses that ownership boundary, removes the child listeners needed for the terminal transition, and still has only mocked proof rather than a real process run.

## What This Changes

The branch makes `deleteSession()` destroy a stored child process’s streams and stdin, remove its listeners, call `child.kill()`, and adds mocked registry cleanup tests.

## Best Possible Solution

Keep `deleteSession()` visibility-only, preserve the supervisor/process-tree termination path for live sessions, and add a real-process regression proof that removal terminates the process tree while the exit path clears active-session state.
