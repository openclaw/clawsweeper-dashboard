## Summary

Keep open: current main and v2026.6.11 still retain default one-shot subagent sessions, skip archive timers for keep-mode runs, and project stored completed subagent rows through session/status surfaces, so the reported cleanup and responsiveness problem is not implemented away.

## What This Changes

The issue requests that completed one-shot subagent sessions stop persisting as stale visible state and that the parent session remain immediately responsive after subagent completion.

## Best Possible Solution

Define the terminal one-shot subagent retention contract, then apply it consistently across registry cleanup, sessions.list defaults, Control UI/status projection, task reconciliation, attachment retention, and docs.
