## Summary

Keep open: current main and the latest release still default one-shot subagent cleanup to `keep`, keep-mode runs still avoid archive timers, and retained child session rows remain part of normal session history. Recent fixes hide stale child links in some parent/filtered views, but the broader retention, task/status honesty, and post-yield responsiveness contract still needs maintainer direction.

## What This Changes

The issue asks OpenClaw to clean up completed subagent sessions and keep the parent session responsive immediately after subagent completion.

## Best Possible Solution

Define the completed one-shot subagent contract first, then make terminal child sessions non-blocking and honest in session/task/UI views while preserving, hiding, archiving, or pruning history according to that chosen policy.
