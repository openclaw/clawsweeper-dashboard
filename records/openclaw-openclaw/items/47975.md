## Summary

Keep open: current main still defaults `sessions_spawn` to retained run-mode child sessions, skips archive timers for `cleanup: "keep"`, and only partially mitigates stale child visibility and yielded-parent idling. The issue remains the canonical tracker for subagent retention plus related session-state/message-delivery symptoms, but the final repair needs maintainer intent on retention, archive, and hiding semantics.

## What This Changes

The issue asks OpenClaw to clean up completed subagent sessions and keep the parent session responsive after subagent completion.

## Best Possible Solution

Make the documented `archiveAfterMinutes` contract real for default run-mode subagents, preserve recoverable transcript history through the existing archive/delete path, and split list visibility from wake/quota state with focused regression coverage.
