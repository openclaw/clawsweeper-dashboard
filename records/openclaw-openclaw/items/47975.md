## Summary

Keep open: current main still defaults one-shot subagent runs to retained keep-mode sessions, keep-mode runs avoid archive timers, and normal session-list paths still include unarchived stored child rows; the remaining fix needs a maintainer decision on retention/history versus archive/hide semantics.

## What This Changes

The issue asks OpenClaw to clean up or hide completed one-shot subagent sessions so stale child sessions do not leave the main session or UI appearing unresponsive.

## Best Possible Solution

Define the completed one-shot subagent contract first, then make terminal child sessions non-blocking and honest in session, task, UI, and docs surfaces according to the chosen retention policy.
