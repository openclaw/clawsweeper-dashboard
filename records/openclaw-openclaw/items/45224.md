## Summary

Keep open: current main and the latest release still have a Playwright CDP connection path plus a fatal fallback for unclassified unhandled rejections, while the browser-specific suppression only covers dialog races, not the reported CRSession assertion class.

## What This Changes

The issue asks OpenClaw to prevent Playwright CDP assertion failures from crashing the Gateway and losing unrelated in-flight agent/session work.

## Best Possible Solution

Keep the fatal default for unknown process-level rejections, but make the browser plugin own a proven CDP assertion recovery path such as targeted classification plus connection teardown/reconnect, or an explicit isolated browser worker boundary.
