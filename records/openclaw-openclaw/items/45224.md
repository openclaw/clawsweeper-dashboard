## Summary

Keep open: current main and the latest release still have a Playwright CDP connection path plus a fatal fallback for unclassified unhandled rejections, while the browser-owned suppression only covers dialog races rather than the reported CRSession assertion class.

## What This Changes

The issue asks OpenClaw to prevent Playwright CRSession._onMessage CDP assertion failures from crashing the whole Gateway and interrupting unrelated sessions.

## Best Possible Solution

Keep the fatal default for unknown rejections, but make the browser plugin own a repro-backed CDP assertion recovery path that logs, tears down or reconnects only the affected Playwright connection, and preserves unrelated Gateway sessions.
