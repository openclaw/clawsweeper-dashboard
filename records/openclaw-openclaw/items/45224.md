## Summary

Keep open: current main and v2026.6.11 still combine Playwright CDP connections with a fatal fallback for unclassified unhandled rejections, while the browser-specific suppression only covers dialog races rather than the reported CRSession assertion class.

## What This Changes

Request that Playwright CDP assertion failures from CRSession/CRConnection be isolated so browser errors do not crash Gateway or unrelated sessions.

## Best Possible Solution

Keep the process-level fatal default for unknown rejections, but make the browser plugin own a proven CDP assertion recovery path that logs, tears down or reconnects only the affected Playwright connection, and preserves unrelated Gateway sessions.
