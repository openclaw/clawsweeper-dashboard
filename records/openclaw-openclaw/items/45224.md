## Summary

Keep open: current main and the latest release still leave the reported Gateway crash class unresolved. ## What This Changes

The issue asks OpenClaw to prevent Playwright CDP assertion failures from terminating the Gateway and losing unrelated session or cron work.

## Best Possible Solution
