## What This Changes

The issue reports that a Playwright CDP assertion from `CRSession._onMessage` can escape as an unhandled rejection and crash Gateway, interrupting unrelated agent sessions.

## Best Possible Solution

Implement a maintainer-approved browser recovery boundary that prevents Playwright CDP internals from terminating Gateway, degrades or reconnects only the affected browser profile, and preserves unrelated sessions with live raw or remote CDP proof.
