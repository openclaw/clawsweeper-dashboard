## Summary

## What This Changes

The issue requests routing Crestodian's short approval-intent classifier through the configured utility model while preserving primary-model fallback when no utility model is configured.

## Best Possible Solution

Add `useUtilityModel: true` at the approval-intent model preparation call and cover both configured-utility and no-utility fallback behavior with focused regression tests.
