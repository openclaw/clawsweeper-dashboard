## What This Changes

The issue requests live input steering for running ACP/sub-agent sessions from Discord and other chat surfaces.

## Best Possible Solution

Keep this issue open until maintainers land or replace a Discord/session-admission fix that lets eligible thread messages reach active-run steering without breaking session serialization and replay guarantees.
