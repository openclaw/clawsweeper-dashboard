## Summary

## What This Changes

Consolidates duration parsing and formatting across core, the Control UI, scripts, and several plugins using pinned `ms` and `pretty-ms` dependencies.

## Best Possible Solution

Retain the shared library-backed implementation, but make unit requirements a caller-level parser option and route Control UI durations through a locale-aware shared presentation helper before merge.
