## Summary

Keep open: current main and the latest release still lack a Control UI `agent.wait` watchdog for stale `chatRunId`, and https://github.com/openclaw/openclaw/pull/90618 is the open closing fix candidate.

## What This Changes

The issue asks for Control UI chat to recover from a stale busy run after long tasks and flush queued messages automatically.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/90618 with a proven Control UI recovery that uses the existing `agent.wait` contract to clear stale local run state, reload history, and flush queued follow-ups.
