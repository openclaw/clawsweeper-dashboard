## Summary

The PR remains necessary as a memory-safety fix, but the current implementation is not mergeable because it avoids OOM by allowing oversized tracked files with unresolved conflict markers to pass required validation. The latest force-pushed head still contains the same fail-open branch raised in every prior review cycle, and green CI does not exercise the missing over-cap detection invariant.

## What This Changes

The PR adds a 50 MiB pre-read size check that skips oversized conflict-marker candidates with a warning, tightens the script declarations, and adds focused tests.

## Best Possible Solution

Replace the size-based skip with bounded incremental text scanning that preserves binary exclusion, current marker syntax, CRLF handling, exact one-based line numbers, and correctness when marker or newline text crosses chunk boundaries.
