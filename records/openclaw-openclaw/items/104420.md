## Summary

The prior blocker remains on the current head: an oversized file already identified by `git grep` as containing conflict markers is warned about and discarded, allowing the root check to pass. The new tracked-file regression is only about 1 MiB and therefore does not exercise the 50 MiB skip.

## What This Changes

The PR adds a 50 MiB pre-read size limit to the conflict-marker checker, updates its declaration types, and adds focused large-file regression tests.

## Best Possible Solution

Carry exact line information from `git grep` or scan candidates incrementally so oversized text candidates remain fully reported while memory use stays bounded.
