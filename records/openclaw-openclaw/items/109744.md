## What This Changes

This PR removes trailing commas before YAML frontmatter parsing and adds tests for JSON5-style flow collections used in skill metadata.

## System Context

Skill Markdown files enter the markdown-core frontmatter parser before their metadata reaches workspace-skill discovery and the skills CLI. A parser-side normalization therefore affects every consumer of SKILL.md metadata, not only the reported workspace example.
