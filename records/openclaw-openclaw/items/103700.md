## Summary

Keep open: the current head resolves the prior locale-model finding and appears correct for initial join reuse, but the external PR still needs after-fix proof from a real localized Google Meet session before merge; the competing PR is not yet a safe canonical replacement because it also lacks real behavior proof.

## What This Changes

The PR restricts initial join-flow tab reuse to Meet URLs explicitly pinned with `hl=en`, opens a new English-pinned tab otherwise, adds mocked selection and URL tests, exposes the selection function for testing, and includes minor formatting-only edits.

## Best Possible Solution

Keep the separate English-pinned tab strategy for ambiguous initial join reuse rather than reloading an existing meeting tab, then prove it with a redacted localized-account run and keep any still-reproducible create or recovery behavior as separately scoped follow-up work.
