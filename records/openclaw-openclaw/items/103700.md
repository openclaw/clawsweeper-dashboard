## Summary

This PR is not merge-ready: its locale predicate treats a missing `hl` parameter as English, although the linked reproduction and current source establish that an unpinned Meet URL can render from the account or browser locale. It therefore reuses the exact ambiguous tab shape that can leave English-only automation silently broken, and the supplied proof is mock-only.

## What This Changes

The PR adds an `hl`-based filter for Google Meet join-tab reuse and mocked tests for URL classification and browser tab selection.

## Best Possible Solution

Inspect or otherwise prove the candidate tab’s actual document language before reuse, open an English-pinned replacement only when safe, and make recovery return a clear localized-UI diagnostic until it can enforce the same invariant without disrupting an active tab.
