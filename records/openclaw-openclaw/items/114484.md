## What This Changes

The PR makes `rg`, `grep`, and `ripgrep` tool-display summaries fall back to `search text` when a parsed pattern already resembles a generated summary or contains unsafe composite content, with focused regression tests.

## System Context

The agent runtime converts `exec` commands into concise labels for tool timelines and transcripts. Shell command parsing supplies the search pattern and target, and the tool-display formatter turns them into user-visible summaries.
