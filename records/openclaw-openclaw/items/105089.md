## Summary

The latest head resolves the prior P1 correctness finding and uses the shared bounded-body helper appropriately. The PR should remain open for refreshed current-head runtime proof and a Synology-area decision on the new 1 MiB `user_list` compatibility boundary.

## What This Changes

The PR stops buffering unused Synology chatbot POST response bodies, caps `user_list` responses at 1 MiB with cache fallback, and adds oversized-response regression coverage.

## Best Possible Solution

Keep chatbot sends status-driven and non-buffering, retain bounded parsing plus cache fallback for `user_list`, and use a Synology-owner-approved response cap with a representative large-installation safety margin.
