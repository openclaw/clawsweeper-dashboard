## Label Justifications

- `P1`: Current unbounded NAS response buffering can exhaust Gateway memory during an active Synology Chat workflow.

## Summary

Keep open: the patch appears correct and now has sufficient current-head runtime proof, but the new 1 MiB `user_list` compatibility boundary still needs explicit Synology Chat owner approval or payload-size evidence before merge.

## What This Changes

The PR stops buffering unused Synology chatbot POST response bodies, bounds `user_list` response reads at 1 MiB with cache fallback, and adds oversized-response regression coverage.

## Best Possible Solution

Land the bounded status-only response handling with cache fallback, using an owner-approved and evidence-backed maximum for `user_list` responses.
