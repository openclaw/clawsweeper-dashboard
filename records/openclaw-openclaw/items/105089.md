## Summary

Keep this PR open for merge review. Current main still has the reported unbounded buffering, the patch uses the canonical shared stream limiter, and the supplied loopback proof remains applicable to the current head; no blocking correctness or security defect was found. A maintainer should explicitly accept the new fixed response-size and total-read-time boundaries before landing.

## What This Changes

The PR bounds Synology Chat chatbot and user-list HTTP response reads, aborts oversized or stalled streams, and adds regression coverage for fallback and retry behavior.

## Best Possible Solution

Retain the shared bounded-reader design and cache fallback, with maintainers explicitly accepting or recalibrating the fixed size and total-duration budgets as the intended compatibility tradeoff.
