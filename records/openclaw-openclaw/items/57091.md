## Best Possible Solution

Land maintainer-approved skipped-skill diagnostics through loader/status/CLI/Web/docs, or explicitly accept the open lint command as the first step and track normal status/Web visibility separately.

Yes, at source level: malformed, unfenced, or description-less SKILL.md candidates become empty frontmatter or null loader results before status, CLI, or UI surfaces can report them. I did not run a live CLI repro because this cleanup review is read-only.
