## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files in a configured per-agent agentDir, either by warning users or by supporting per-agent bootstrap loading.

## Best Possible Solution

Choose one canonical bootstrap-authority policy, then land the matching linked PR with docs, focused tests, and security/upgrade proof.
