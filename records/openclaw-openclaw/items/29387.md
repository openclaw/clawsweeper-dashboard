## Summary

Keep open: current main and v2026.6.11 still use workspace-only bootstrap loading, and the three open linked PRs cover conflicting warning-only versus agentDir-loading policies that need maintainer/security direction.

## What This Changes

The issue requests a fix for bootstrap-named Markdown files under per-agent `agentDir` being silently ignored, either by loading them per agent or warning users to move them to the workspace.

## Best Possible Solution

Maintainers should pick one bootstrap-authority policy and land one linked PR: warning-only if workspace remains canonical, or explicit agentDir loading with docs, diagnostics, tests, and real-run proof if per-agent prompt authority is desired.
