## Summary

Keep open: current main and v2026.6.11 still load bootstrap prompt files from the resolved workspace only, while three open linked PRs represent warning-only versus agentDir-loading policies that need maintainer/security choice.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed in an agent's agentDir, either by loading them for per-agent prompt context or by warning that only workspace files are injected.

## Best Possible Solution

Choose one canonical bootstrap-authority policy, then land the matching linked PR with docs, focused tests, and security/upgrade proof.
