## Summary

Keep open: current main and v2026.6.11 still resolve bootstrap files from the effective workspace only, and three open closing PRs propose different warning-versus-agentDir-loading policies that need maintainer/security selection before this issue can close.

## What This Changes

The issue reports that bootstrap files placed in a configured per-agent agentDir are silently ignored while workspace bootstrap files are injected into prompt context.

## Best Possible Solution

Choose one canonical bootstrap policy and land one linked PR: warning-only diagnostics and docs if workspace remains canonical, or explicit agentDir loading with precedence, diagnostics, tests, docs, and security/upgrade proof.

## Reproduction Assessment

Yes, source-level. Current main and v2026.6.11 load bootstrap files from workspaceDir only and do not inspect configured agentDir in the resolver; I did not run a live agent setup in this read-only review.

## Solution Assessment

Unclear. Warning-only is the lower-risk repair if agentDir stays state-only, while agentDir loading better satisfies per-agent customization and requires maintainer/security approval for prompt-authority precedence.
