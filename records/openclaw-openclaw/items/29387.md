## Label Justifications

- `P1`: The issue affects real multi-agent prompt and safety-rule behavior, but it is limited to configured agentDir/bootstrap setups rather than making the whole runtime unusable.
- `impact:session-state`: The reported failure is bootstrap context drift: users expect per-agent instructions in a session, but current prompt context comes only from workspace files.
- `impact:security`: Safety instructions placed in agentDir/AGENTS.md can be silently absent from the model prompt under current behavior.

## Summary

Keep open: current main and v2026.6.11 still load bootstrap files from the resolved workspace only, and the open linked PRs now cover conflicting warning-only versus agentDir-loading policies that need maintainer/security direction.

## What This Changes

This issue asks OpenClaw to stop silently ignoring bootstrap-named files placed under a configured per-agent agentDir, either by loading them or by warning and documenting that workspace is the only prompt source.

## Best Possible Solution

Land one maintainer-approved bootstrap policy: warning-only diagnostics if workspace remains canonical, or explicit configured-agentDir loading with documented precedence, aligned diagnostics, focused tests, and real-run proof if agentDir should become prompt-authoritative.
