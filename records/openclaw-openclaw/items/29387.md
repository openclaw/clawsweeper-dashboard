## Summary

Keep open: current main and the latest release still resolve bootstrap files from the effective workspace only, while three open closing PRs propose different warning-versus-loading policies that need maintainer selection.

## What This Changes

The issue asks OpenClaw to either load per-agent bootstrap files from `agentDir` or warn when bootstrap-named files placed there are ignored.

## Best Possible Solution

Pick one canonical bootstrap policy and land one linked PR: warning-only diagnostics and docs if workspace remains canonical, or explicit agentDir loading with precedence, diagnostics, tests, docs, and security/upgrade proof.

## Reproduction Assessment

Yes. Source inspection shows current main and `v2026.6.11` call workspace-only bootstrap loading and never inspect `agentDir` in the resolver; I did not run a live agent setup in this read-only review.

## Solution Assessment

Unclear. Warning-only is the lower-risk repair if `agentDir` stays state-only, while `agentDir` loading better satisfies per-agent customization and requires maintainer/security approval for prompt-authority precedence.
