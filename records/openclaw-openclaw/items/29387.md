## Summary

Keep open: current `main` and the latest release still resolve bootstrap prompt files from `workspaceDir` only, while open linked PRs represent different warning-only versus agentDir-loading policies that need maintainer/security choice before this issue can close.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed in an explicitly configured per-agent `agentDir`, either by loading/merging them or warning users to move them to the workspace.

## Best Possible Solution

Choose one canonical bootstrap-authority policy, then land the matching linked PR with docs, focused tests, and security/upgrade proof.
