## Label Justifications

- `P1`: Bootstrap prompt rules can be silently omitted in multi-agent setups, affecting real agent behavior and safety expectations.
- `impact:session-state`: The issue concerns which per-agent workspace/context files are injected into an agent session's prompt state.

## Summary

Keep open: current main and v2026.6.11 still load bootstrap prompt files from the resolved workspace only, while three open closing PRs represent competing warning-only versus agentDir-loading policies that need maintainer security/product direction.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed under a configured per-agent agentDir, either by loading them or warning clearly.

## Best Possible Solution

Keep workspace as the canonical prompt source unless maintainers explicitly approve agentDir prompt authority; ship one linked PR with diagnostics, docs, resolver/caller tests, and real behavior proof.

Unclear as a product choice. Warning-only is the safest narrow mitigation, while agentDir merge/override satisfies per-agent customization but needs maintainer security approval because it changes prompt authority.
