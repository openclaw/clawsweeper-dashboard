## What This Changes

The issue reports that bootstrap files placed under a configured per-agent `agentDir` are silently ignored while workspace bootstrap files are injected into the system prompt.

## Best Possible Solution

Keep bootstrap prompt files workspace-owned unless maintainers explicitly accept an agentDir trust-boundary expansion; land either the warning/doctor/docs path or a reviewed loading policy with security and upgrade proof.
