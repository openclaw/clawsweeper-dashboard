## Summary

Keep open: current main and v2026.6.11 still load bootstrap prompt files from the resolved workspace only, while three open linked PRs represent incompatible warning-only versus agentDir-loading policies that need maintainer/security choice.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed under a configured per-agent agentDir.

## Best Possible Solution

Maintainers should choose one bootstrap-authority policy, then land the matching PR with docs, focused tests, and security/upgrade proof.
