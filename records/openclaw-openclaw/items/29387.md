## Summary

Keep open: current main and v2026.6.11 still resolve bootstrap prompt files from the workspace only, and three open linked PRs represent competing warning-only versus agentDir-loading policies.

## What This Changes

The issue asks OpenClaw to either load per-agent bootstrap prompt files from `agentDir` or warn clearly when those files are ignored.

## Best Possible Solution

Choose one canonical bootstrap-authority model, then land exactly one linked PR with resolver/caller tests, doctor or diagnostics alignment, docs, and real behavior proof.

Unclear as a product choice. Warning-only is the safest narrow mitigation, while agentDir merge/override satisfies per-agent customization but needs maintainer security approval because it changes prompt authority.
