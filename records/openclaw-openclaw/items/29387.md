## Label Justifications

- `P1`: The issue affects multi-agent prompt/context behavior and can leave user-supplied safety instructions out of real runs without a diagnostic.
- `impact:session-state`: The reported behavior is agent/context state drift: files placed in a configured per-agent directory are not reflected in the session prompt state.
- `impact:security`: Misplaced AGENTS.md or SOUL.md safety rules can be silently absent from the system prompt, making this a prompt-authority and safety-boundary concern.

## Summary

Keep open: current main and the latest shipped release still load bootstrap prompt files from the configured workspace only, while three open linked PRs cover conflicting warning-only versus agentDir-loading policies that need maintainer/security direction before this issue can close.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files under a configured per-agent agentDir, either by loading them under a defined policy or warning and documenting workspace-only injection.

## Best Possible Solution

Maintainers should choose one bootstrap-authority policy and land one linked PR: warning-only if workspace remains canonical, or explicit agentDir loading only with precedence docs, diagnostics, regression tests, and real-run proof.
