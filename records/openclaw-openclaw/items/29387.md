## Summary

Keep open: current main and the latest checked release still load bootstrap prompt files from the workspace only, while three open closing PRs propose competing warning-only and agentDir-loading fixes that need maintainer/security policy.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed in a configured per-agent agentDir, either by loading them or warning users to move them to the workspace.

## Best Possible Solution

Pick the trusted-source policy first: either land the warning/doctor/docs path that preserves workspace-only prompt loading, or explicitly approve agentDir loading with security and upgrade proof.
