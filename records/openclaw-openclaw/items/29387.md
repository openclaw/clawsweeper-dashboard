## Best Possible Solution

Yes, source-level: current main and v2026.6.11 load bootstrap files from workspaceDir only and do not inspect configured agentDir for prompt files or warnings. I did not run a live agent setup in this read-only review.

Unclear. Warning-only is the lower-risk fix if workspace remains canonical, while agentDir loading better satisfies per-agent customization but needs explicit security and precedence approval.
