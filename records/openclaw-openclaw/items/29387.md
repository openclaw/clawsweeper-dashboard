## Summary

Keep open: current main and the latest release still load bootstrap context from the resolved workspace only, while three open linked PRs propose different warning-only versus agentDir-loading policies that need maintainer/security selection.

## What This Changes

The issue requests diagnostics or per-agent bootstrap loading for bootstrap-named files placed in configured agentDir, which are currently not injected from that directory.

## Best Possible Solution

Land one canonical linked PR after maintainer/security decision: warning-only diagnostics and docs if workspace remains the sole prompt source, or explicit agentDir loading with precedence, diagnostics, tests, docs, and upgrade proof.

## Reproduction Assessment

Yes. Source inspection shows current main and v2026.6.11 resolve bootstrap files from workspaceDir only and never inspect agentDir for prompt files; I did not run a live multi-agent setup in this read-only review.

## Solution Assessment

Unclear. Warning-only is the lower-risk repair if agentDir remains state-only, while agentDir loading better satisfies per-agent customization but changes prompt authority and needs maintainer/security approval.
