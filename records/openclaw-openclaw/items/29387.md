- `P1`: The issue affects real multi-agent prompt context and safety-rule behavior for users, but it is not an unusable core-runtime emergency because a workspace workaround exists.
- `impact:security`: Misplaced AGENTS.md or SOUL.md safety instructions in agentDir can be absent from the actual system prompt without warning.
- `impact:session-state`: The reported behavior is agent/session context drift: the session receives workspace bootstrap context while per-agent agentDir context is ignored.

## Summary

Keep open: current main and v2026.6.11 still load bootstrap prompt files from the resolved workspace only, while three open linked PRs represent warning-only versus agentDir-loading policies that need maintainer/security choice.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files in per-agent agentDir, either by loading/merging them into prompt context or by warning users clearly.

## Best Possible Solution

Maintainers should choose one bootstrap authority policy, then land the corresponding linked PR with docs, diagnostics, tests, and real-run proof: warning-only if agentDir remains runtime state, or explicit agentDir bootstrap loading if per-agent instructions are intended.
