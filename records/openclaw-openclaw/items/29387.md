## Summary

Keep open: current main and v2026.6.11 still load bootstrap context from the effective workspace only, and three open closing PRs propose different warning-versus-loading policies that need maintainer selection before this issue can close.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files in a configured per-agent agentDir, either by warning users or by loading/merging those files for per-agent prompt customization.

## Best Possible Solution

Pick one canonical bootstrap policy and land one linked PR: warning-only diagnostics and docs if workspace remains canonical, or explicit agentDir loading with precedence, diagnostics, tests, docs, and security/upgrade proof.

## Reproduction Assessment

Yes, source-level. Current main and v2026.6.11 load bootstrap files from workspaceDir only and never inspect agentDir in the resolver; I did not run a live multi-agent startup in this read-only review.

## Solution Assessment

Unclear. Warning-only is the lower-risk repair if agentDir stays state-only, while agentDir loading better satisfies per-agent customization and requires maintainer/security approval for prompt-authority precedence.
