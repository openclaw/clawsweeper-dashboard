## Summary

Keep open: current `main` and `v2026.6.11` still resolve bootstrap prompt files from the workspace path only, while three open linked PRs represent different warning-only versus agentDir-loading policies that need maintainer/security choice before the issue can close.

## What This Changes

The issue requests that per-agent `agentDir` bootstrap files either participate in prompt bootstrap loading or produce a diagnostic when they are ignored.

## Best Possible Solution

Choose one canonical bootstrap-authority policy, then land the matching linked PR with docs, focused tests, and security/upgrade proof.
