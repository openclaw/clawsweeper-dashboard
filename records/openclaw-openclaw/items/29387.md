## Label Justifications

- `P1`: The issue reports a reproducible broken agent-context workflow where users can believe prompt safety rules are active when the runtime never injects them.

## Summary

Keep open: current main and v2026.6.11 still resolve bootstrap prompt files from the workspace path only, while three open closing PRs cover different policy choices for the same issue.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed under a configured per-agent agentDir, either by loading them or warning clearly.

## Best Possible Solution

Keep bootstrap prompt files workspace-owned; land a warning, doctor, and docs path for misplaced agentDir bootstrap files unless maintainers explicitly choose and document agentDir as a trusted prompt source.
