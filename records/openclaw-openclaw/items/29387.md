## Summary

Keep open: current main still resolves bootstrap files from the agent workspace only, while this issue has three open closing PRs that represent competing fix directions. The remaining decision is maintainer/security policy: warning-only diagnostics versus making explicitly configured `agentDir` files prompt-authoritative.

## What This Changes

The issue requests that per-agent `agentDir` bootstrap files either be loaded or merged into the system prompt, or produce an explicit warning when ignored.

## Best Possible Solution

Keep this issue open until maintainers choose and land one canonical fix path: warning-only diagnostics if workspace remains the sole bootstrap source, or a fully documented/tested `agentDir` loading policy if per-agent prompt authority is accepted.

## Reproduction Assessment

Yes, source-level. Current `resolveBootstrapFilesForRun` reads only files under `workspaceDir`, while `agentDir` is resolved by separate config helpers and is not used by bootstrap injection; I did not run a live multi-agent session in this read-only review.

## Solution Assessment

Unclear. Warning-only diagnostics are the lowest-risk mitigation for silent misconfiguration, but the preferred `agentDir` merge/override behavior is a broader prompt-authority change that requires maintainer/security approval.
