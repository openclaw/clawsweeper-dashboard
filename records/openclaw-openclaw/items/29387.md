Keep open: current main and v2026.6.11 still resolve bootstrap prompt files from the active workspace only, while three open linked PRs cover different warning-only versus agentDir-loading policies that need maintainer/security direction.

## What This Changes

The issue reports that bootstrap files placed in a configured per-agent agentDir are silently ignored while workspace bootstrap files are injected into the system prompt.

## Best Possible Solution

Choose one canonical bootstrap-authority policy, then land the matching linked PR with docs, focused tests, security review, and real-run proof.

## Solution Assessment

Unclear until maintainers choose the policy. Warning-only is the lower-risk bug fix if workspace remains canonical; agentDir loading solves per-agent customization but changes prompt authority and needs security approval.
