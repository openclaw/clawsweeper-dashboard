## What This Changes

## Best Possible Solution

Settle the documented contract in one linked PR: either keep bootstrap files workspace-owned with an explicit diagnostic for misplaced `agentDir` files, or intentionally add per-agent merge/override semantics with upgrade-safe tests and docs.
