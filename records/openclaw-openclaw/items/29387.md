## Summary

Keep open: current main and v2026.6.11 still resolve bootstrap prompt files from the active workspace only, while three open closing PRs implement different warning-versus-agentDir-loading policies that need maintainer security-boundary choice.

## What This Changes

The issue asks OpenClaw to stop silently ignoring AGENTS/SOUL-style bootstrap files placed in a configured per-agent agentDir, either by warning or by supporting agentDir bootstrap loading.

## Best Possible Solution

Choose one canonical bootstrap authority policy, then land the matching linked PR with docs, focused tests, and security/upgrade proof for workspace precedence, hooks, cron/subagent filtering, and diagnostics.
