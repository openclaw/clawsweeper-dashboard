## Summary

Keep open: current main and the latest release still resolve bootstrap prompt files from the agent workspace only, while three open linked PRs propose different warning-only versus agentDir-loading policies that need maintainer/security choice.

## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap-named files placed in a configured per-agent agentDir, either by loading/merging them or warning that only workspace files are injected.

## Best Possible Solution

Keep bootstrap prompt files workspace-owned unless maintainers explicitly accept an agentDir trust-boundary expansion; land either a warning/doctor/docs path or a reviewed loading policy with security and upgrade proof.
