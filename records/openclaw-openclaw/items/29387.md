## Summary

Keep open: current main and the latest release still resolve bootstrap files from the configured workspace only, and three open linked PRs are competing candidate fixes with different security/product tradeoffs.

## What This Changes

The issue requests either per-agent `agentDir` bootstrap loading/merging or a clear warning and documentation when bootstrap-named files in `agentDir` are ignored.

## Best Possible Solution

Choose one bootstrap authority policy, then land a single linked fix with matching diagnostics, docs, tests, and security review before closing this issue.

## Reproduction Assessment

Yes. Source inspection shows current main and `v2026.6.11` load bootstrap files from `workspaceDir` only and do not read or warn on bootstrap-named files in configured `agentDir`.

## Solution Assessment

Unclear. Warning-only diagnostics are the lowest-risk mitigation, while `agentDir` loading better satisfies per-agent customization but changes prompt authority; maintainers need to choose the intended policy.
