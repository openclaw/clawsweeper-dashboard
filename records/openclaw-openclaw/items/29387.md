## What This Changes

The issue asks OpenClaw to stop silently ignoring bootstrap files placed in a configured per-agent agentDir, either by loading/merging them or warning users that only workspace bootstrap files are injected.

Keep this issue open until maintainers choose the bootstrap-authority policy and review/land one linked PR as the canonical fix, then close this issue through that merged implementation.
