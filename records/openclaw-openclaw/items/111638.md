The PR makes Microsoft Teams delegated OAuth reject null, arrays, and other non-object JSON token envelopes before parsing token fields, returning the existing actionable validation error instead of a raw TypeError.

## System Context

The Microsoft Teams plugin exchanges and refreshes delegated OAuth tokens through a guarded HTTP fetch path. The returned JSON is validated before token fields feed into the delegated-auth state used by Teams operations.
