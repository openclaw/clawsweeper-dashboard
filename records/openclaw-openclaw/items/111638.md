## What This Changes

This PR makes Microsoft Teams delegated OAuth token exchange and refresh reject `null`, arrays, and other non-object JSON token envelopes with the existing actionable validation error.

## System Context

Microsoft Teams delegated OAuth uses a guarded HTTP request to exchange or refresh credentials, then validates the returned token fields before handing credentials to the channel’s delegated-auth flow. The proposed guard validates the decoded JSON envelope before token fields are accessed.
