## Summary

Keep open: current main and v2026.6.11 still use an embedded/local Gateway-agent runtime shape, while the open worker-runtime and execution-backend PRs are partial design slices rather than replacements for this distributed runtime RFC.

## What This Changes

Request to split `openclaw gateway` into a control plane plus separately managed per-agent compute runtimes for isolation, scaling, lifecycle, and operability.

## Best Possible Solution

Keep this RFC open as the broad architecture tracker, approve a narrow Phase 0/1 milestone for per-agent lifecycle plus local runtime protocol/trust boundaries, and use the worker/runtime-placement PRs as review inputs rather than replacements.
