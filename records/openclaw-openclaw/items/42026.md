## Summary

This RFC is still necessary: current main documents and implements one gateway process that owns routing/control-plane state while still referencing embedded agent-run state, and the linked worker-isolation/execution-backend work is open and partial rather than a merged replacement. The item should stay open for maintainer product and security architecture review, not automated cleanup.

## What This Changes

The issue requests splitting `openclaw gateway` into a control plane plus per-agent runtime processes with local-split and distributed deployment modes.

## Best Possible Solution

Keep this as the broad maintainer-owned architecture tracker while narrower linked PRs prove worker isolation and execution placement; require an explicit runtime protocol, security model, upgrade path, and session/channel migration plan before implementation.
