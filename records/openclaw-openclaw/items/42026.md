## Summary

Keep open: current main still describes one Gateway process with embedded/local agent execution, while the open worker/backend PRs are partial slices rather than replacements for this distributed runtime RFC.

## What This Changes

Request to split OpenClaw Gateway into a control plane plus per-agent runtime processes or workers for isolation, scaling, lifecycle control, and security.

## Best Possible Solution

Keep this as the broad architecture tracker, decide a narrow Phase 0/1 control-plane/runtime contract and security model, and treat the worker/backend PRs as partial review inputs rather than replacements.
