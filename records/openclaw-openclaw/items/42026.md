## Summary

The remaining request is a broad runtime/control-plane architecture, compatibility, and security decision that should stay maintainer-owned.

## What This Changes

Request a first-class distributed agent runtime that separates gateway control-plane responsibilities from per-agent compute, lifecycle, secrets, tools, memory, and session execution.

## Best Possible Solution

Keep this as the canonical architecture RFC until maintainers choose a phased design that separates control-plane duties from agent compute without breaking existing embedded deployments.
