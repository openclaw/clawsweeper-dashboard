## Summary

Keep open: current main and v2026.6.11 still document and implement a Gateway-owned control plane with embedded/local agent execution, while the open related PRs only cover partial worker or placement slices. This remains a broad product, security, session-state, and delivery architecture RFC rather than a closeable or autonomous fix item.

## What This Changes

The issue proposes splitting `openclaw gateway` into a control-plane process and separate per-agent compute runtimes with local-split and distributed deployment modes.

## Best Possible Solution

Keep this as the broad architecture RFC until maintainers choose the runtime protocol, trust model, lifecycle semantics, session migration plan, and first supported milestone, then split implementation into smaller reviewed issues or PRs.
