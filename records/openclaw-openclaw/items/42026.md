## Summary

Keep open: current main and v2026.6.11 still use an embedded/local Gateway-plus-agent runtime model, and the open worker/backend PRs are partial slices rather than replacements for this distributed runtime RFC.

## What This Changes

Request a distributed runtime architecture that separates Gateway control-plane/channel duties from per-agent compute runtimes.

## Best Possible Solution

Keep this issue as the broad RFC, approve a narrow Phase 0/1 control-plane/runtime contract and security model, and review #82017, #84758, and #78164 as partial inputs rather than replacements.
