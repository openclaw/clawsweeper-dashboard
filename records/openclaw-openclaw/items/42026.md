## Summary

Keep open: current main and v2026.6.11 still document and implement one gateway process with embedded/local agent attempt execution, while the related worker/runtime PRs are open partial slices rather than a replacement for this distributed-runtime RFC. The comments add useful operator evidence for Phase 0/1 value, but this remains a product, compatibility, and security architecture decision.

## What This Changes

Requests a distributed runtime architecture that splits gateway/control-plane responsibilities from per-agent compute/runtime processes while preserving today’s embedded mode.

## Best Possible Solution

Keep this as the architecture umbrella until maintainers choose a phased design; land narrower slices only after the gateway protocol, session-state, delivery, secrets, and upgrade contracts are explicit.
