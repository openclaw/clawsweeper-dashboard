Keep open: current main and v2026.6.11 still use embedded/local agent execution, while the related worker-runtime and execution-backend efforts are partial, closed-unmerged, or still open. ## What This Changes

RFC requesting a split between the Gateway control plane and per-agent runtime compute, with embedded, local-split, and distributed deployment modes.

## Best Possible Solution

Keep this as the broad architecture tracker, approve or reject a narrow Phase 0/1 control-plane/runtime contract and security model, and treat https://github.com/openclaw/openclaw/issues/82017 plus https://github.com/openclaw/openclaw/pull/84758 as partial implementation inputs rather than replacements.
