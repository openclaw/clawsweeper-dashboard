## Summary

Keep open: current main and v2026.6.11 still use a single Gateway-owned control plane with embedded/local agent execution, and the related worker/runtime efforts are partial, unmerged, or narrower than this distributed-runtime RFC.

## What This Changes

The issue requests a distributed agent runtime architecture that separates Gateway/control-plane duties from per-agent compute runtimes.

## Best Possible Solution

Keep this as the broad architecture RFC and define a phased protocol, trust model, lifecycle, session-migration, and compatibility plan before implementation; use https://github.com/openclaw/openclaw/issues/82017 for the narrower execution-placement slice.
