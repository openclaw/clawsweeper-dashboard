## Summary

Keep open: current main and the latest release still use a single Gateway-owned control plane with embedded/local agent execution, and related work is partial or unmerged rather than a replacement for the distributed runtime RFC.

## What This Changes

Requests a distributed agent runtime architecture that separates the Gateway control plane from per-agent compute runtimes while preserving embedded-mode compatibility.

## Best Possible Solution

Keep this as the broad architecture RFC and approve a phased protocol, trust model, lifecycle, and session-migration design before implementation.
