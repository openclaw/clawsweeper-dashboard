## Summary

Keep open: current main and v2026.6.11 still document and implement Gateway-owned control plane with embedded/local agent execution, and the related worker/backend PRs are partial unmerged slices rather than replacements for this RFC.

## What This Changes

The issue requests a distributed control-plane and agent-runtime architecture so agents can run outside the main Gateway process with explicit lifecycle, trust, and isolation boundaries.

## Best Possible Solution

Keep this as the broad architecture RFC and proceed only after maintainers choose the runtime protocol, trust model, lifecycle semantics, session migration strategy, and first milestone boundaries.
