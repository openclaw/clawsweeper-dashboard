## Summary

Keep open: current main and v2026.6.11 still use a Gateway-owned control plane with embedded/local agent execution, while related open PRs are partial slices rather than a merged distributed runtime.

## What This Changes

Request to split the monolithic Gateway into a lightweight control plane plus per-agent runtime processes with lifecycle, isolation, scaling, and protocol support.

## Best Possible Solution

Keep this as the broad architecture RFC and split implementation only after maintainers choose the runtime protocol, trust model, lifecycle semantics, session migration strategy, and first milestone boundaries.
