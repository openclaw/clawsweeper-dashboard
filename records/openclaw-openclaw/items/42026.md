## Summary

Keep open: current main and v2026.6.11 still use embedded/local agent execution, and the open related worker/backend PRs are partial slices rather than replacements for this distributed runtime RFC.

## What This Changes

The issue requests a first-class split between a Gateway control plane and separately deployable per-agent runtime compute.

## Best Possible Solution

Keep this RFC open as the broad architecture tracker, decide a narrow Phase 0/1 control-plane/runtime contract and security model, and treat related backend/worker PRs as partial review inputs rather than replacements.
