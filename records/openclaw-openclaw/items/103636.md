## Summary

Keep open: current main and v2026.6.11 still clear operator scopes from the reported device-less backend connection, and no merged change resolves the host-interface relay case. The issue also exposes compatibility evidence that must be reconciled with the open effort to remove shared-token backend scope preservation.

## What This Changes

Fix gateway backend self-calls that lose operator scopes when a same-host relay presents the host’s non-loopback interface address.

## Best Possible Solution

Move internal backend self-calls to dedicated process-bound authority or device-token authentication, prove agent and approval flows on loopback and relayed same-host paths, then remove or narrowly retain shared-token compatibility without using interface ownership alone as privileged identity.
