## What This Changes

The issue requests that gateway restart continuation messages reach outbound channels as clean continuation content rather than exposing internal inbound-metadata JSON envelopes.

## System Context

A gateway restart persists a continuation for a bound agent session, then replays it after the gateway starts again. That replay enters the agent and channel-delivery pipeline, where internal inbound context must remain available to the model without becoming visible in Discord or other outbound transports.
