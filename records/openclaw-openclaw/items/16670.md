## Summary

Keep open: current main still lacks a first-run or configure memory embedding setup path, and the remaining mandatory-versus-optional onboarding behavior is a product decision rather than conservative cleanup.

## What This Changes

The issue requests a mandatory onboarding wizard step that configures memorySearch embedding provider/model credentials and verifies the embedding endpoint.

## Best Possible Solution

Add a maintainer-approved memory setup/readiness path in onboarding and configure that uses the existing memorySearch config, supports SecretRef or API-key input, verifies readiness, and documents the chosen mandatory-versus-optional policy.
