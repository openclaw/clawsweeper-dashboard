## Summary

Keep open: current main still has diagnostics and manual memory configuration docs, but setup/onboarding/configure do not provide a dedicated memory embedding provider/model/API-key or SecretRef setup path, and making that step mandatory is a maintainer product decision.

## What This Changes

The issue asks for first-run onboarding to make memory embedding provider setup a prominent mandatory step so semantic memory works without manual `memorySearch` config.

## Best Possible Solution

Add a maintainer-approved memory setup/readiness path in onboarding and `openclaw configure` that uses existing `memorySearch` and SecretRef surfaces, verifies readiness, and documents whether the step is mandatory or prominently optional.
