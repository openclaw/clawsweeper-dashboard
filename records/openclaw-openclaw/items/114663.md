## What This Changes

This PR makes `loadPlugins: "never"` CLI commands avoid executable plugin-runtime evaluation during config preflight, then runs the full plugin-aware migration pass when a gateway starts.

## System Context

CLI command bootstrap validates configuration and may run state migrations before dispatching a command. This PR separates plugin-free preflight from the later gateway-startup pass that can load plugin-owned migration and session logic.
