## Summary

This PR is still necessary: it narrows a real Telegram disclosure path without claiming to fix the broader shared outbound-hook contract. The prior P1 was addressed in the revised PR description, and the submitted live Telegram evidence covers both modifier and observer-only behavior. Because the PR carries the protected `maintainer` label and intentionally trades previews for safety whenever a modifying hook is registered, it should remain open for explicit maintainer review rather than automated cleanup.

## What This Changes

The branch prevents Telegram draft and progress previews from appearing before registered outbound rewrite or cancellation hooks can modify or suppress the final reply, while preserving previews when no such hooks are registered.

## System Context

Telegram’s channel plugin can show provider-visible streaming drafts while an agent is generating a reply. The normal final-delivery path then applies outbound plugin hooks, so this change gates early previews when they could expose content that the hooks would rewrite or cancel.
