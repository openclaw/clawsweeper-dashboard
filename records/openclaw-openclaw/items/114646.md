## What This Changes

This PR lets selected session-catalog providers share one lazy Gateway `node.list` result during a catalog request, avoiding repeated node discovery while retaining each provider’s existing runtime fallback.

## System Context

The Gateway’s `sessions.catalog.list` handler asks selected provider plugins to produce session hosts for clients such as the Control UI. Providers may need the Gateway node registry to find remote hosts; this change supplies one request-owned lookup so multiple providers reuse the same node-list operation.
