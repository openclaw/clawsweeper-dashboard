- **[P1] Preserve the no-synthesis rule for interrupted assistant turns:** `src/agents/session-transcript-repair.ts:754-765`
  - body: Do not synthesize a result solely because an `error` or `aborted` assistant message still contains a tool-call-shaped block. These turns may contain incomplete calls that later sanitization removes; the new result then becomes orphaned and Anthropic rejects it with `unexpected tool_use_id`, which is why the current implementation and persistence guard deliberately skip extraction here. Drop or validate the interrupted tool-use block at the canonical replay boundary instead.
  - confidence: 0.98

  - body: Remove this unconditional repair from both `buildSessionContext` implementations.
