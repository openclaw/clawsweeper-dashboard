## Summary

Keep open: the feature is useful and belongs in the Control UI sidebar, but the current implementation can leave large groups only partially renamed or deleted because it treats one bounded `sessions.list` page as unbounded.

## What This Changes

This PR adds Control UI sidebar group header menus for group rename/create/delete, empty-group rendering, a persisted browser-local grouping toggle, tests, regenerated UI locale bundles, and sidebar docs.

## Best Possible Solution

Keep the sidebar UI shape, but make group rename/delete enumerate all active and archived members through a real paginated `sessions.list` path before patching categories.
