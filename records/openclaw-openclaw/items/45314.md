## Summary

## What This Changes

The issue requests that early abort replies interpolate `messages.responsePrefix` template variables instead of sending raw placeholders such as `{model}` and `{thinkingLevel}`.

## Best Possible Solution

Land a focused fix that resolves provider/model/thinking prefix context for early abort replies and adds regression coverage for the `/stop` fast-abort path without leaking raw template tokens.
