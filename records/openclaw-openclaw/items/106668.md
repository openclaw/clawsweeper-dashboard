## Summary

The reported unauthenticated endpoint does not match current main: the referenced tool bridges are MCP loopback surfaces behind bearer-based caller resolution, and requests are filtered by authenticated owner state before tool listing or execution.

## What This Changes

Require authentication for the local MCP tool bridges so unrelated same-host processes cannot invoke privileged OpenClaw tools.

## Best Possible Solution

Keep the existing bearer-authenticated gateway MCP boundary and owner-state filtering; if a bypass is still suspected, require a new report with the exact current command, URL, request headers, OpenClaw version, and a redacted response proving that a request without valid credentials reaches tool execution.
