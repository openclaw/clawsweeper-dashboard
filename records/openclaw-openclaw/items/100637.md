## Summary

Keep open: current main and the latest release still expose the SQLite ACP event ledger without a ledger-level lifecycle close, and production ACP/gateway shutdown paths do not call the existing shared state DB close helper. This is still necessary as a narrow core lifecycle cleanup, not a duplicate of the older memory-core SQLite reports.

## What This Changes

The issue reports that SQLite ACP event ledger `DatabaseSync` handles are not closed during hot reload or shutdown, causing leaked file locks.

## Best Possible Solution

Wire ACP and gateway shutdown to the shared state DB lifecycle owner, add regression coverage that proves the cache closes after shutdown, and avoid new config or a parallel ledger-owned database handle.
