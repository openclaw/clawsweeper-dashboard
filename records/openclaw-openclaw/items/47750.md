## Summary

Keep open: current main still supports non-interactive OpenAI setup through API-key auth, while ChatGPT/Codex OAuth remains browser, remote paste, or device-code based. The requested callback-URL/env setup path is a real auth-provider feature request, but it needs maintainer-approved security and product direction before implementation.

## What This Changes

Request a non-interactive OpenAI/Codex OAuth setup path, such as supplying an OAuth callback URL through an environment variable.

## Best Possible Solution

Design an OpenAI-plugin-owned non-interactive OAuth import or session handoff that preserves PKCE/state validation, avoids secret-bearing callback URLs in env, and ships with focused tests, docs, and redacted real-flow proof.
