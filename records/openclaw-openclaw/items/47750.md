## Summary

Keep open: current main and v2026.6.11 still lack a non-interactive OpenAI ChatGPT/Codex OAuth setup or import path. The request is source-reproducible and useful for setup automation, but it changes auth-provider and secret-handling surface, so it needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a non-interactive way to configure the OpenAI ChatGPT/Codex OAuth model provider, such as supplying an OAuth callback URL through an environment variable.

## Best Possible Solution

Define a provider-owned non-interactive OAuth handoff with PKCE/state validation, secret redaction, focused docs/tests, and explicit persistence of the OpenAI auth profile and default model.
