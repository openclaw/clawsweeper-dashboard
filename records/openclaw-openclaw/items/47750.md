## Summary

Keep open: current main and v2026.6.11 still do not provide a non-interactive OpenAI ChatGPT/Codex OAuth setup/import path. The request is source-reproducible and useful, but the proposed callback-URL environment handoff is security-sensitive auth-provider surface that needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a non-interactive way to configure OpenAI ChatGPT/Codex OAuth for the model provider, such as supplying an OAuth callback URL through an environment variable.

## Best Possible Solution

Design a maintainer-approved OpenAI-plugin-owned non-interactive auth handoff that preserves PKCE/state validation, avoids leaking callback material where possible, documents the supported setup surface, and ships focused tests plus redacted live-flow proof.
