## Summary

Keep open: current main and the latest release still offer non-interactive OpenAI setup through API-key auth, while ChatGPT/Codex OAuth remains an interactive browser, remote paste, or device-code flow. The requested callback-URL/env import is a real provider-auth feature request, but it needs a maintainer-approved security contract before implementation.

## What This Changes

Request a non-interactive OpenAI/Codex OAuth setup path, such as supplying an OAuth callback or redirect URL by environment variable for ChatGPT subscription auth.

## Best Possible Solution

Design an OpenAI-plugin-owned non-interactive auth import or session handoff that preserves PKCE/state validation, avoids secret-bearing callback URLs in env, documents the setup surface, and ships with focused tests plus redacted real-flow proof.
