## Summary

Keep open: current main and v2026.6.11 still support non-interactive OpenAI setup only through API-key auth, while OpenAI ChatGPT/Codex OAuth remains an interactive browser, manual-paste, or device-code flow. The request is valid auth-provider work, but adding a non-interactive OAuth callback/import surface needs maintainer product and security direction first.

## What This Changes

The issue requests a non-interactive OpenAI ChatGPT/Codex OAuth setup path, such as an environment-supplied callback URL, for configuring the OpenAI model provider without an API key.

## Best Possible Solution

Design an OpenAI-plugin-owned non-interactive auth handoff that preserves PKCE/state validation, avoids leaking secret-bearing callback URLs when possible, documents the supported setup path, and ships focused tests plus redacted real-flow proof.
