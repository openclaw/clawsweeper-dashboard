## What This Changes

The issue requests a non-interactive OpenAI ChatGPT/Codex OAuth setup path, such as accepting a redirect callback URL through an environment variable, for instant provider setup with ChatGPT subscriptions.

Define a maintainer-approved OpenAI-plugin-owned non-interactive OAuth handoff that validates PKCE/state, minimizes env/log exposure, documents the security contract, persists the correct auth profile, refreshes running auth state, and covers fresh setup plus upgrade behavior with focused tests.
