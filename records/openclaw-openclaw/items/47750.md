## Summary

Keep open: current main still has non-interactive OpenAI setup for API-key auth only, while OpenAI ChatGPT/Codex OAuth remains an interactive browser, remote paste, or device-code flow. The requested callback-URL environment import is a real auth-provider feature request, but it needs maintainer-approved security and product direction before implementation.

## What This Changes

Request a non-interactive OpenAI ChatGPT/Codex OAuth setup path, proposed as an environment variable containing the OAuth callback or redirect URL.

## Best Possible Solution

Design an OpenAI-plugin-owned non-interactive auth handoff that preserves PKCE and state validation, avoids secret-bearing callback URLs in env when possible, documents the setup surface, and ships focused tests plus redacted real-flow proof.
