## Summary

Keep open: current main and v2026.6.11 still only support non-interactive OpenAI setup for API-key auth, while OpenAI ChatGPT/Codex OAuth remains a browser, device-code, or manual-paste flow. The requested callback/import surface is a valid auth-provider feature request, but it needs maintainer product and security direction before implementation.

## What This Changes

Request a non-interactive OpenAI ChatGPT/Codex OAuth setup path, such as importing a completed callback URL from an environment variable.

## Best Possible Solution

Design an OpenAI-plugin-owned non-interactive auth handoff that preserves PKCE/state validation, avoids secret-bearing callback URLs in env when possible, documents the supported setup surface, and ships focused tests plus redacted real-flow proof.
