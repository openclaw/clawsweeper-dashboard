Keep open: current main and v2026.6.11 still do not provide a non-interactive OpenAI ChatGPT/Codex OAuth setup/import path. The gap is source-reproducible, but accepting callback URLs or OAuth material through automation needs maintainer product and security direction first.

## Best Possible Solution

Define a maintainer-approved OpenAI-plugin-owned non-interactive OAuth handoff that preserves PKCE/state validation, minimizes env/log exposure, documents the security contract, and covers setup plus token persistence with focused tests.
