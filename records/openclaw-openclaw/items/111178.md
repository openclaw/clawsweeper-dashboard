## Summary

Keep this PR open: it fixes a real persistent-state side effect, but the current branch still has a P1 legacy-store regression in transcript search and lacks after-fix real runtime proof. The protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The branch changes gateway session read, search, and abort resolution so unknown agent IDs do not provision agent databases or directories while existing configured, retired, legacy, shared-store, and active-run sessions remain reachable.

## Best Possible Solution

Keep unknown-agent gateway operations read-only, including fixed legacy `sessions.json` transcript searches; use a non-materializing reader or preserve the legacy target rather than deriving and opening SQLite state, then demonstrate no files, registry rows, or session visibility regressions in a real gateway run.
