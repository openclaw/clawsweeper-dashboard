## Summary

Keep this PR open: its central reject-unknown direction is appropriate, but the current head still provisions a derived SQLite store when transcript-searching a legacy-only agent and adds an avoidable full session-key scan to configured fixed-store gateway lookups. The PR body contains test claims but no inspectable after-fix runtime artifact, so real behavior proof is also still needed before merge.

## What This Changes

The PR prevents gateway session read, search, and abort requests for unknown agent IDs from provisioning persistent agent stores, while retaining access to configured, retired, legacy, shared-store, and active-run sessions.

## Best Possible Solution

Keep the reject-unknown boundary, make legacy-only transcript search use a genuinely non-provisioning reader or skip SQLite transcript search for that target, and defer persisted-target discovery until it is needed for an unconfigured or template-backed agent.
