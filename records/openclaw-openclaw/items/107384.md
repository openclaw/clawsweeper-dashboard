## What This Changes

The PR changes gateway control-plane rate-limit eviction to scan for the bucket with the earliest window start instead of deleting the first inserted map key.

## Best Possible Solution

Move an existing bucket to the Map tail when its window resets, preserving window-age insertion order and constant-time cap eviction, then cover the divergent-order sequence and sustained saturated churn with regression and runtime proof.
