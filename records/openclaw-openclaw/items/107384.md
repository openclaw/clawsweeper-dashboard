## Summary

Keep this PR open: the reported age-ordering defect is valid, but the proposed repair moves attacker-influenced cap eviction from constant time to a full 10,000-bucket scan, and the branch still lacks saturated-map runtime proof.

## What This Changes

Changes gateway control-plane rate-limit eviction from the first inserted bucket to the bucket with the smallest `windowStartMs`.

## Best Possible Solution

Reinsert a bucket at the map tail whenever its window resets, retain constant-time head eviction, and add a deterministic regression test plus saturated-map churn benchmark and runtime proof.
