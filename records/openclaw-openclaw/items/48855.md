## What This Changes

Request Android/Termux support for running the OpenClaw Gateway service locally, including dashboard access and remote node management without a separate host.

## Best Possible Solution

Keep this as the canonical Android Gateway-hosting platform decision until maintainers either define a supported Android/Termux Gateway mode with real-device security validation or explicitly keep Android node-only with clearer host guidance.

## Solution Assessment
