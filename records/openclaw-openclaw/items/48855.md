Keep open. Current main and v2026.6.11 still define Android as a companion node rather than a Gateway host, and the managed service resolver still excludes Android, so the remaining work is a platform/security product decision rather than a narrow bug fix.

## What This Changes

The issue requests Android/Termux Gateway service support, or a lightweight/documented mobile Gateway mode, so Android devices can host the dashboard and remote connections without a PC or VPS.

## Best Possible Solution

Keep this as the canonical Android/Termux Gateway-hosting decision until maintainers either define a scoped supported mode with real-device/security validation or explicitly keep Android node-only with clearer host guidance.
