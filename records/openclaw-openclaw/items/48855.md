## Summary

Keep open; current main and the latest release still exclude Android from managed Gateway service hosting, while official Android docs define Android as a companion node. The AndroidForClaw comment is useful ecosystem evidence, but official Android/Termux Gateway hosting still needs maintainer product and security direction.

## What This Changes

Request Android/Termux support for running the OpenClaw Gateway service locally, including dashboard access and remote node connections without a PC or VPS.

## Best Possible Solution

Define a maintainer-approved Android/Termux Gateway-hosting mode with security and lifecycle requirements, or explicitly keep Android node-only with clearer external-host guidance.
