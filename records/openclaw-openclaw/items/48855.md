## Summary

Keep open; current main and v2026.6.11 still exclude Android from managed Gateway service hosting, while the official Android docs describe a companion-node app that requires a separate Gateway host. The linked AndroidForClaw/HermesApp project is useful ecosystem evidence, but official Android/Termux Gateway hosting still needs maintainer product and security direction.

## What This Changes

Requesting official Android/Termux Gateway-host support so mobile-only users can run the Gateway service and dashboard without a separate PC or VPS.

## Best Possible Solution

Keep this issue as the canonical Android/Termux Gateway-hosting decision until maintainers either define one supported mobile Gateway-host model with security/lifecycle proof or explicitly keep Android node-only with clearer external-host guidance.
