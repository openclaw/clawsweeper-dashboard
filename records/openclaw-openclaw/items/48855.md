## Summary

Keep open. Current main and the latest release still define Android as a companion node, not a Gateway host, and Android/Termux Gateway hosting remains a platform, lifecycle, and security product decision rather than implemented or obsolete work.

## What This Changes

Request to support running the OpenClaw Gateway service directly on Android/Termux so mobile users can access the dashboard and remote connections without a PC or VPS.

## Best Possible Solution

Keep this as the canonical Android/Termux Gateway-hosting decision until maintainers define one scoped supported mode with security, lifecycle, docs, and real-device proof, or explicitly keep Android node-only with clearer host guidance.
