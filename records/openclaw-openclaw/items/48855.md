## Summary

Keep open; current main and the latest release still define Android as a companion node, not a Gateway host, while the managed service path still supports only macOS, Linux, and Windows. The AndroidForClaw link is useful ecosystem evidence, but official Android/Termux Gateway hosting remains a product and security decision rather than conservative cleanup.

## What This Changes

Request Android/Termux support for running the OpenClaw Gateway service directly on mobile devices, including local dashboard access and remote node connections without a separate PC or VPS.

## Best Possible Solution

Keep this as the canonical Android/Termux Gateway-hosting decision until maintainers either define a supported host mode with security/lifecycle proof or explicitly keep Android node-only with clearer external-host guidance.
