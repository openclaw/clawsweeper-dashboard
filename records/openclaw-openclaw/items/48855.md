## Summary

Keep open: current main and the latest release still exclude Android from managed Gateway service hosting, while official Android docs define Android as a companion node. AndroidForClaw is useful ecosystem evidence that the use case has demand, but it does not resolve the official OpenClaw product, lifecycle, and security decision.

## What This Changes

Request Android/Termux support for running the OpenClaw Gateway directly on mobile so dashboard access and remote connections work without a separate PC or VPS.

## Best Possible Solution

Keep this as the canonical Android/Termux Gateway-hosting decision until maintainers choose a supported host mode with lifecycle/security proof or explicitly keep Android node-only with clearer external-host guidance.
