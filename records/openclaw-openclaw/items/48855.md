## Summary

Keep open. Current main and the latest release still define Android as a companion node, not a Gateway host, and the requested Android/Termux Gateway service remains a platform, lifecycle, and security product decision.

## What This Changes

Request Android/Termux Gateway hosting so mobile-only users can run the dashboard and remote-node connections without a separate PC or VPS.

## Best Possible Solution

Keep this as the canonical Android/Termux Gateway-hosting decision until maintainers define a scoped supported mode with real-device security/lifecycle proof or explicitly keep Android node-only with clearer host guidance.
