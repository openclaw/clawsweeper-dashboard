## Risks / Open Questions

- Bundling introduces a substantial new channel configuration and environment-variable surface that core would need to support and migrate across releases.
- The shared registerPluginHttpRoute return contract and new fail-fast SMS behavior can make an existing duplicate-path setup stop at startup rather than continue with its previous behavior; fresh-install and upgrade behavior need explicit approval and proof.
- Delivery and read receipt history currently disappears whenever the gateway restarts because it is held only in process memory.
- The shared SMS/RCS webhook, signature-validation, callback acknowledgement, and local forwarding paths affect both message delivery and a public security boundary but have no live provider proof.
- The external PR changes the dependency graph without the required repository-admin or security authorization and also contains unrelated lockfile peer-resolution drift.
