## Summary

This is a thoughtful optional Twilio channel built mostly on existing plugin seams, but it should not be bundled in OpenClaw core. The latest head fixes the earlier read-callback parsing gap; external publication still needs monotonic receipt handling, real Twilio proof, and removal of the bundled-only forwarding mode or a separate generic SDK proposal.

## What This Changes

Adds a bundled Twilio-backed RCS channel plugin with configuration, webhook handling, outbound delivery, status capture, tests, generated metadata, and documentation.

## Best Possible Solution

Move this to an independently maintained RCS channel plugin: remove the bundled-only forwarding mode or split a generic SDK-seam proposal, preserve monotonic read status, verify manifest, entrypoint, permissions, secrets, install/update docs and example usage, add redacted live send/receive/read-receipt proof, and publish through ClawHub; ClawSweeper should not create the external issue, PR, repository, or package on the contributor's behalf.
