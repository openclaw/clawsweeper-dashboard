## Summary

This PR remains useful, but it should not merge while raw terminal input creates a host-command path outside the established exec approval policy and no real Control UI run demonstrates the new security and lifecycle behavior.

## What This Changes

Adds agent-owned gateway PTY sessions, an agent `terminal` tool, shared operator viewing and input, protocol ownership metadata, and Control UI co-attachment.

## Best Possible Solution

Keep the agent-owned and co-attached PTY model, but make command-bearing input preserve exec approval or require an explicit per-agent terminal-input opt-in, then prove the complete shared-terminal flow in a real Control UI setup.
