## What This Changes

The PR adds `activeModel.provider` checks to the xAI `code_execution` and `x_search` lazy tool factories so they return `null` unless the active model provider is `xai`.

## Best Possible Solution

Merge a fail-closed xAI provider gate only after tests prove xAI, non-xAI, and missing-active-model factory behavior, docs match the new availability rule, and maintainers accept the compatibility break or add an explicit opt-in.
