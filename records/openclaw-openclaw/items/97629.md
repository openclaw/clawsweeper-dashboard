## What This Changes

This PR adds active-model provider checks to xAI's lazy `code_execution` and `x_search` tool factories so those xAI-billed tools are only constructed for xAI active-model contexts.

## Best Possible Solution

Land a provider-owned fail-closed gate after xAI factory tests cover xAI, non-xAI, and missing active-model contexts, docs explain the new availability rule, and proof shows the real tool-list behavior.
