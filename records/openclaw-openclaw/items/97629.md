## What This Changes

This PR adds active-model provider checks to the xAI `code_execution` and `x_search` tool factories so they return `null` unless the active provider is `xai`.

## Best Possible Solution

Land a documented, tested fail-closed xAI provider gate that hides xAI-billed tools from non-xAI or unknown active-model contexts, with an explicit opt-in path only if maintainers choose to support cross-provider use.
