## What This Changes

The PR adds `activeModel.provider` checks to the xAI `code_execution` and `x_search` lazy tool factories so they return `null` unless the active model provider is `xai`.

## Best Possible Solution

Land a fail-closed xAI-provider gate only after maintainers accept the compatibility tradeoff, the branch adds factory-level coverage for xAI/non-xAI/missing providers, docs describe model-gated availability, and the contributor provides redacted real behavior proof.
