## What This Changes

This PR persists the origin of non-anonymous Telegram polls and uses later `poll_answer` updates to deliver a selected option to the originating direct-chat or forum-topic agent session.

## System Context

The Telegram plugin sends polls through its outbound transport and receives Telegram updates through durable inbound handlers. Because Telegram poll-answer updates omit chat and topic metadata, this change records the outbound poll origin in plugin state, then uses it to authorize and route a later vote into the appropriate agent session.
