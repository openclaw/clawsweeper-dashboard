## What This Changes

The branch stores the origin of non-anonymous Telegram polls and routes subsequent poll-answer updates through authorization and normal conversation routing into the correct direct or forum-topic agent session.

## System Context

Telegram poll-answer updates include a poll identifier and selected options but omit the originating chat and topic. The Telegram plugin therefore records outbound public-poll context, looks it up on an inbound vote, applies sender authorization and conversation routing, then enqueues an event for the resolved agent session.
