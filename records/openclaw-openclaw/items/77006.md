## Best Possible Solution

Land only after maintainers approve the explicit-home credential boundary, auth writes are confined or explicitly accepted, and redacted live managed Codex ACP proof covers both the isolated default and override paths.

## Solution Assessment

No, not as-is. The override is a plausible mitigation, but the best fix still depends on maintainer approval of the credential boundary and the patch should not silently write auth material into an explicit external Codex home.
