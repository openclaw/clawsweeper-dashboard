## Summary

Keep this PR open. The typography expansion is still useful on current main, but the current head still regresses the documented mobile input floor by scaling touch-primary config inputs below 16px at the 90% Text size stop; the new XXL screenshots improve proof for the large-text surface but do not cover that S-scale touch-input path.

The branch updates Control UI CSS tokens and replaces fixed font sizes across Settings, quick settings, chat text, and composer-adjacent typography so the existing Appearance Text size preference scales more content text.

## Best Possible Solution

Keep the expanded content typography scaling, but leave every focusable text-entry control on `--control-ui-input-text-size` or an equivalent `max(16px, ...)` floor and add 90% touch-primary proof before merge.
