  - body: `toSanitizedMarkdownHtml()` is used outside chat, but this branch rewrites every Mermaid fence into an empty `.mermaid-block__render` placeholder while only the chat lifecycle schedules Mermaid rendering.   - confidence: 0.88
- **[P2] Call Mermaid bindFunctions after inserting SVG:** `ui/src/ui/mermaid.ts:186-187`
  - body: Mermaid 11.13.0 documents that `render()` can return `bindFunctions` that must run after the SVG is inserted. This code only uses `svg`, so diagrams with Mermaid tooltips or click handlers would silently lose their interactions.
  - confidence: 0.9
- **[P2] Let failed Mermaid blocks retry on later renders:** `ui/src/ui/mermaid.ts:150`
  - body: The renderer only selects blocks without `data-mermaid-status`, then marks failed renders as `error`. A transient chunk load failure or incomplete streamed Mermaid definition can therefore permanently skip the same DOM block on later updates instead of retrying when the input is complete.
  - confidence: 0.83
- **[P1] Remove the workspace-wide lodash-es override:** `package.json:1253`
  - body: This root override changes dependency resolution for the whole workspace even though the feature is local to Control UI and Mermaid already brings its own dependency graph. Dependency overrides are security-sensitive in this repo and need either explicit maintainer approval or removal before merge.
  - confidence: 0.86
