  - body: This root override changes lodash-es resolution for the whole workspace, not just the Control UI Mermaid dependency. Delete it if Mermaid can use normal semver resolution, or document the package-owner/security reason for changing every consumer before merge.
  - confidence: 0.86
- **[P2] Scope Mermaid blocks to views that render them:** `ui/src/ui/markdown.ts:263-264`
  - body: toSanitizedMarkdownHtml is shared by markdown sidebars and other UI panes, but this patch rewrites every Mermaid fence into an empty render placeholder while only scheduling rendering from the chat lifecycle.   - confidence: 0.9
- **[P2] Retry Mermaid blocks after transient failures:** `ui/src/ui/mermaid.ts:149-150`
  - body: The renderer only queries blocks without data-mermaid-status, but failed module loads or parse/render errors set data-mermaid-status="error". A streamed or transiently failing diagram will not be retried on later updates even after the source or chunk load becomes valid.
  - confidence: 0.84
- **[P2] Run Mermaid bindFunctions after inserting SVG:** `ui/src/ui/mermaid.ts:186-187`
  - body: Mermaid 11.13.0 render results may include bindFunctions that must run after inserting the SVG for diagram event handlers and tooltips. The local MermaidApi type omits bindFunctions and the code only inserts svg, so interactive Mermaid diagrams can render without their intended behavior.
  - confidence: 0.87
