  - body: Mermaid 11.13.0 documents `render()` returning `bindFunctions` that callers should run after inserting the SVG. This code drops that return value, so diagrams that rely on Mermaid tooltips or click bindings render without their expected interaction behavior.
  - confidence: 0.88
- **[P2] Allow failed Mermaid blocks to rerender:** `ui/src/ui/mermaid.ts:150`
  - body: The renderer only selects blocks without `data-mermaid-status`, then marks failures as `error`. A streamed or transiently invalid Mermaid block can fail once and never be visited again after the message completes or the module import recovers.
  - confidence: 0.87
- **[P1] Remove the workspace-wide lodash-es override:** `package.json:1253`
  - body: A UI-only Mermaid feature should not add a root `pnpm.overrides` pin that changes `lodash-es` resolution across the workspace without explicit maintainer dependency approval. Keep the dependency change local to the UI package or document the approved workspace-wide reason.
  - confidence: 0.9
