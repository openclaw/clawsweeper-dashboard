Overall confidence: 0.88

Full review comments:

- **[P1] Port Mermaid fences to the markdown-it renderer:** `ui/src/ui/markdown.ts:263-264`
  - body: Current main replaced the old marked renderer with markdown-it for the shared markdown pipeline, but this branch adds Mermaid handling inside the obsolete `htmlEscapeRenderer.code` path. Rebase/port this to current main's `md.renderer.rules.fence`/`renderCodeBlock` path so the feature does not conflict with or bypass the current renderer.
  - confidence: 0.94
- **[P1] Remove the workspace-wide lodash override:** `package.json:1253`
  - body: The feature is UI-local, but this line pins `lodash-es` for the entire workspace. Root dependency overrides and lockfile changes are security/compatibility surface here; keep any dependency change local to the Control UI package unless maintainers explicitly approve the global override.
  - confidence: 0.84
- **[P2] Call Mermaid bindFunctions after insertion:** `ui/src/ui/mermaid.ts:186-187`
  - body: Mermaid 11.13.0's `RenderResult` can include `bindFunctions` that callers must invoke after inserting the SVG. This code drops everything except `svg`, so diagrams with Mermaid event bindings, tooltips, or clickable interactions render as static output.
  - confidence: 0.88
- **[P2] Allow failed Mermaid blocks to retry:** `ui/src/ui/mermaid.ts:149-151`
  - body: The selector skips every block once `data-mermaid-status` is set, and the catch path marks transient parse/load failures as `error`. A streamed or temporarily invalid Mermaid block can therefore stay stuck on fallback text after the final diagram source arrives.
  - confidence: 0.86
- **[P2] Only rewrite Mermaid fences where rendering is scheduled:** `ui/src/ui/app-lifecycle.ts:124`
  - body: `toSanitizedMarkdownHtml()` is shared by chat sidebars and other markdown views, but this PR only schedules Mermaid rendering from the chat lifecycle. Shared views can receive an empty Mermaid placeholder with the source hidden under details instead of a rendered diagram or normal code fence.
  - confidence: 0.82
- **[P3] Show fallback text for empty Mermaid definitions:** `ui/src/ui/mermaid.ts:178-180`
  - body: When the Mermaid source is empty or trimmed to empty, this branch sets `data-mermaid-status="error"` and continues without calling the error helper. The user then sees a blank render area rather than an actionable failure message.
  - confidence: 0.77
