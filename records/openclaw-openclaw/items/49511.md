  - body: `toSanitizedMarkdownHtml()` now emits `.mermaid-block` placeholders, but the only scheduler added here runs from the chat lifecycle. Shared markdown consumers such as `ui/src/ui/views/markdown-sidebar.ts` can insert the same placeholders without rendering them, leaving blank blocks.
  - confidence: 0.86
- **[P2] Call Mermaid bindFunctions after SVG insertion:** `ui/src/ui/mermaid.ts:186-187`
  - body: Mermaid 11.13.0 documents that `render()` can return `bindFunctions` and that callers should run it after inserting the SVG. This code discards that callback, so diagrams with Mermaid interactions render without their expected behavior.
  - confidence: 0.88

  - body: Adding a root `pnpm.overrides` pin changes `lodash-es` resolution for every workspace dependency, not just Mermaid/WebChat, and the PR does not justify or prove that cross-workspace package-resolution change.
  - confidence: 0.91
