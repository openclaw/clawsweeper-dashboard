## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Port Mermaid rendering to the markdown-it path:** `ui/src/ui/markdown.ts:263-264`
  - body: Current main no longer uses `htmlEscapeRenderer.code`; fenced blocks now go through `md.renderer.rules.fence` and `renderCodeBlock`. This Mermaid branch is attached to the old marked renderer, so it cannot land cleanly or preserve current code-block behavior until it is ported to the active renderer.
  - confidence: 0.95
- **[P1] Remove the workspace-wide lodash-es override:** `package.json:1253`
  - body: The Mermaid UI feature does not justify forcing every workspace dependency that resolves `lodash-es` to this root override. That changes package resolution outside Control UI and should be removed or replaced with a maintainer-approved, narrowly scoped dependency fix.
  - confidence: 0.86
- **[P2] Run Mermaid bindFunctions after SVG insertion:** `ui/src/ui/mermaid.ts:5`
  - body: Mermaid's render result can include `bindFunctions` that must be called after the SVG is inserted for diagram event handlers to work. This type only models `{ svg }` and the render path discards `bindFunctions`, so interactive Mermaid diagrams will silently render without their interactions.
  - confidence: 0.9
- **[P2] Scope Mermaid placeholders to rendered views:** `ui/src/ui/markdown.ts:263-264`
  - body: `toSanitizedMarkdownHtml()` is shared by views outside chat, but this branch turns every Mermaid fence into an empty `.mermaid-block__render` while only chat lifecycle updates schedule rendering. Shared markdown panes can therefore show a blank Mermaid panel instead of a rendered diagram or ordinary code fence.
  - confidence: 0.88
- **[P2] Allow failed Mermaid blocks to retry:** `ui/src/ui/mermaid.ts:149-150`
  - body: The render pass only selects `.mermaid-block:not([data-mermaid-status])`, and both module-load and render failures set `data-mermaid-status="error"`. A transient chunk, network, or partial-render failure therefore leaves that block permanently skipped until the DOM is recreated.
  - confidence: 0.82
