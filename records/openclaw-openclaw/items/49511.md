  - body: `renderMermaidBlocks()` only selects blocks without `data-mermaid-status`, then marks render/load failures as `error`. A streamed or transiently incomplete Mermaid block can fail once and never be revisited after the definition becomes valid, leaving the transcript stuck on the fallback.

  - confidence: 0.88
- **[P2] Call Mermaid bindFunctions after inserting the SVG:** `ui/src/ui/mermaid.ts:186-187`
  - body: Mermaid's render contract can return `bindFunctions` for event listeners after the SVG is inserted. This code discards that field, so diagrams with Mermaid-managed interactions render as static SVGs with broken tooltips/click bindings.
  - confidence: 0.86
- **[P2] Remove or narrow the root lodash-es override:** `package.json:1253`
