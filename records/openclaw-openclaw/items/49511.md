  - confidence: 0.94

  - body: This root override changes dependency resolution for the whole workspace even though the feature is local to Control UI. Dependency overrides and the lockfile are security-owned here, so this needs explicit approval or a narrower dependency solution before merge.
  - confidence: 0.86
- **[P2] Scope Mermaid rewriting to surfaces that render it:** `ui/src/ui/markdown.ts:263-264`
  - body: `toSanitizedMarkdownHtml()` is used outside chat, but this branch rewrites every Mermaid fence into an empty render placeholder while only chat lifecycle updates schedule Mermaid rendering. Non-chat markdown panes would show blank diagram boxes unless the scheduler is shared or the rewrite is scoped to chat.
  - confidence: 0.88
- **[P2] Call Mermaid bindFunctions after inserting SVG:** `ui/src/ui/mermaid.ts:185-188`
  - body: Mermaid 11.13.0 can return `bindFunctions` from `render()` and documents that callers should run it after the SVG is inserted. This wrapper drops that return value, so diagrams with tooltips or click handlers would render without their interactions.
  - confidence: 0.9
- **[P2] Let failed Mermaid blocks retry on later renders:** `ui/src/ui/mermaid.ts:149-150`
  - body: The renderer selects only blocks without `data-mermaid-status`, then marks failures as `error`. A transient import failure or incomplete streamed diagram can permanently skip the same DOM block instead of retrying after the input completes.
  - confidence: 0.84
- **[P3] Show a fallback message for empty Mermaid definitions:** `ui/src/ui/mermaid.ts:178-180`
  - body: When a Mermaid block has no definition, the code marks the block as `error` but never writes an error message into the render target. That leaves a blank panel with collapsed source instead of the plain-code visibility users had before.
  - confidence: 0.78
