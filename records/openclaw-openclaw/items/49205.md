Keep open: current main and the latest release still have OpenClaw transcript/session persistence for Control UI sends, but no Open WebUI visible-history mirror. The remaining decision is product/storage ownership, because the proposed fix would couple OpenClaw to third-party Open WebUI persistence unless maintainers define a supported adapter boundary.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling and live Docker/OpenWebUI proof, or explicitly document that Control UI co-editing of Open WebUI visible history is unsupported.
