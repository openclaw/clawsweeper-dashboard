## Summary

Keep open: current main and the latest release still have OpenClaw transcript persistence and Gateway chat broadcasts, but no implemented path that mirrors Control UI turns into Open WebUI's visible chat store. The remaining work needs maintainer product direction because it would couple OpenClaw to an external Open WebUI persistence/API boundary, likely with opt-in configuration and live proof.

## What This Changes

The issue asks OpenClaw to make Control UI turns in an Open WebUI-backed chat appear in Open WebUI’s visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/API version handling, docs, focused Gateway tests, and Docker/Open WebUI proof, or explicitly document that Control UI co-editing of Open WebUI visible history is unsupported.
