Keep open: current main and the latest release still lack an Open WebUI visible-history mirror, while the linked PRs cover adjacent session identity/session reuse rather than this rendered-history sync. ## What This Changes

The issue requests that Control UI sends into an Open WebUI-backed chat appear as normal Open WebUI visible chat messages, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling, fresh-turn tests, live Open WebUI Docker proof, and a separate decision on historical backfill.
