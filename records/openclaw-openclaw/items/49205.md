## Summary

Keep open: current main and the latest release still persist and broadcast Control UI turns through OpenClaw’s Gateway/session transcript path, but I found no source path that mirrors those turns into Open WebUI’s visible history store. The remaining work needs maintainer direction because a fix would couple OpenClaw to third-party Open WebUI persistence/API behavior and likely needs opt-in configuration plus live proof.

## What This Changes

Control UI turns sent into an Open WebUI-backed chat should also appear in Open WebUI’s visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, then add focused Gateway coverage and Docker/Open WebUI proof, or explicitly document that Control UI co-editing of Open WebUI visible history is unsupported.
