## Summary

Keep open: current main still persists and broadcasts Control UI chat turns through OpenClaw's transcript/Gateway paths, but there is no current source path that mirrors those external turns into Open WebUI's own visible-history store. The remaining work needs maintainer direction because it crosses third-party Open WebUI persistence/API ownership, operator configuration, schema compatibility, and live proof.

## What This Changes

The issue asks for Control UI turns in an Open WebUI-backed chat to appear in Open WebUI's visible chat history as well as OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary, then add focused Gateway coverage plus Docker/Open WebUI proof; otherwise document that Control UI co-editing of Open WebUI visible history is unsupported.
