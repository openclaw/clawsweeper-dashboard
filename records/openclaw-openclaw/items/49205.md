## Summary

Keep open: current main still has no Open WebUI visible-history mirror for Control UI `chat.send` turns, and the remaining fix needs maintainer direction because it crosses third-party Open WebUI persistence and upgrade boundaries.

## What This Changes

The issue asks OpenClaw to make external Control UI turns in an Open WebUI-backed chat appear in Open WebUI's visible chat history as normal message bubbles.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling, focused Gateway tests, and live Open WebUI Docker proof; otherwise document that Control UI co-editing updates OpenClaw context but not Open WebUI's rendered history.
