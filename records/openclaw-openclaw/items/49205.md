## Summary

Keep open: current main and the latest release still persist and broadcast Control UI `chat.send` turns through OpenClaw transcript/session paths, but there is no supported Open WebUI visible-history mirror path. The remaining work needs maintainer direction because the plausible fix crosses third-party Open WebUI persistence/schema ownership and live proof.

## What This Changes

The issue requests that Control UI turns sent into an Open WebUI-backed chat appear in Open WebUI visible chat history as normal message bubbles, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably an explicit opt-in integration or stable API/adapter path with schema/version handling, fresh-turn tests, and live Open WebUI proof; otherwise document this co-editing limitation clearly.
