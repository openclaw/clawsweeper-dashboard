## Summary

Keep open: current main and the latest release still route Control UI `chat.send` turns through OpenClaw transcript/session event paths, but there is no Open WebUI visible-history mirror. The remaining work needs maintainer direction because a durable fix crosses third-party Open WebUI persistence, schema, and live-proof boundaries.

## What This Changes

Mirror external Control UI turns for Open WebUI-backed chats into Open WebUI visible chat history as well as OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling, future-turn tests, and live Open WebUI proof; otherwise document that Control UI co-editing does not update Open WebUI's rendered history.
