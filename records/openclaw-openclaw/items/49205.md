## Summary

Keep open: current main still persists and broadcasts Control UI turns through OpenClaw's Gateway/session transcript path, but no current source path mirrors those turns into Open WebUI's own visible-history store. ## What This Changes

The issue asks OpenClaw to make Control UI turns in an Open WebUI-backed chat appear in Open WebUI visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved, operator-enabled Open WebUI visible-history sync boundary, prefer a supported Open WebUI API if available, and add schema/version handling, focused Gateway coverage, Docker/Open WebUI plus Control UI proof, and a separate historical backfill decision.
