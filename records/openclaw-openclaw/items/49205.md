## Summary

Keep open: current main and v2026.6.11 still have no path that mirrors Control UI `chat.send` turns into Open WebUI's visible-history store, and the remaining fix needs maintainer direction because it crosses third-party persistence/schema ownership.

## What This Changes

The issue reports that Control UI turns in an Open WebUI-backed chat reach OpenClaw transcript/model context but do not appear as visible Open WebUI chat bubbles.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/API-version handling and Docker proof, or explicitly document that Control UI co-editing of Open WebUI visible history is unsupported.
