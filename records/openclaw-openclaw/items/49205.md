## Summary

Keep open: current `main` and the latest release still persist and broadcast Control UI `chat.send` turns through OpenClaw's own transcript/session paths, but there is no Open WebUI visible-history mirror path. The remaining work needs maintainer direction because the plausible fix crosses third-party Open WebUI persistence/schema ownership, opt-in configuration, and live integration proof.

## What This Changes

The issue asks OpenClaw to make Control UI turns written into an Open WebUI-backed chat also appear as normal messages in Open WebUI's visible chat history.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably an explicit opt-in integration or stable API/adapter path with schema/version handling, fresh-turn tests, and live Open WebUI proof; otherwise document this co-editing limitation clearly.
