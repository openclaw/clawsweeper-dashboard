## Summary

Keep open. Current main still has no Open WebUI visible-history mirror for Control UI-originated turns, and the linked work covers adjacent session identity/header reuse rather than updating Open WebUI's own rendered-history store.

## What This Changes

The issue requests that Control UI turns sent into an Open WebUI-backed chat appear in Open WebUI visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define an explicit, opt-in Open WebUI visible-history sync owner with live E2E proof and a backfill/doctor policy, preferably through a supported API or documented integration boundary rather than an implicit hot-path SQLite write.
