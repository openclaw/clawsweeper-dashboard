## Summary

Keep open: current main and v2026.6.11 still lack an Open WebUI visible-history mirror for Control UI `chat.send` turns, and the remaining fix needs maintainer direction because it crosses third-party Open WebUI persistence ownership and live-proof requirements.

## What This Changes

The issue requests that Control UI turns written into an Open WebUI-backed chat also appear in Open WebUI visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably an explicit opt-in integration or adapter path with schema/version handling, fresh-turn tests, historical-backfill policy, and live Docker/Open WebUI proof.
