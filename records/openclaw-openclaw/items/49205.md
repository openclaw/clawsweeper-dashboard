## Summary

Keep open: current main and v2026.6.11 still persist Control UI `chat.send` turns into OpenClaw transcript/history and live Gateway events, but I found no Open WebUI visible-history mirror into Open WebUI's own chat store. The remaining work needs maintainer direction because the plausible fix crosses third-party Open WebUI persistence/schema ownership and live proof.

## What This Changes

The issue requests that external Control UI turns in an Open WebUI-backed chat also appear as normal visible Open WebUI history messages.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI history-sync boundary that mirrors only verified external turns through a supported API or schema contract, with live Docker/Open WebUI proof and a safe recovery/backfill story for already-missed turns.
