## Summary

Keep open: current main and the latest release still have the OpenClaw transcript/session persistence path for Control UI `chat.send`, but no Open WebUI visible-history mirror. The remaining work needs maintainer direction because a durable fix would couple to third-party Open WebUI persistence or require an approved integration boundary.

## What This Changes

The issue reports that Control UI turns written into an Open WebUI-backed chat can enter OpenClaw transcript/model context without appearing as visible Open WebUI message bubbles.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably opt-in and live-tested, with future-turn behavior separate from any historical backfill repair.

- **Design an integration seam first:** Keep this open until an API/plugin/integration boundary can own Open WebUI-specific storage writes outside the hot `chat.send` path.
