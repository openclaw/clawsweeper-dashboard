Keep open: current main still has the OpenClaw transcript/session path for Control UI `chat.send`, but no Open WebUI visible-history mirror, and the remaining fix needs maintainer direction because it crosses third-party Open WebUI persistence/schema ownership.

## What This Changes

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling, live Docker/OpenWebUI proof, and a separate decision for historical backfill; otherwise document that Control UI co-editing only updates OpenClaw transcript/context.
