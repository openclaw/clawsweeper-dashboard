## Summary

Keep open: current main and the latest release still persist and broadcast Control UI `chat.send` turns through OpenClaw transcript/session paths, but no Open WebUI visible-history mirror exists. The remaining fix needs maintainer direction because it would couple OpenClaw to Open WebUI persistence, schema/version handling, and live Docker proof.

## What This Changes

The issue requests that external Control UI turns in an Open WebUI-backed chat appear in Open WebUI visible chat history after reaching OpenClaw transcript and model context.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably opt-in and schema/version-aware, with fresh-turn tests and live Open WebUI proof; otherwise document that Control UI co-editing updates OpenClaw context but not Open WebUI visible history.
