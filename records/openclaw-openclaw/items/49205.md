## Summary

Keep open: current main and the latest release still persist and broadcast Control UI `chat.send` turns through OpenClaw session/transcript paths, but there is no Open WebUI visible-history mirror. The reporter's local fix evidence is useful, but the remaining direction crosses third-party Open WebUI persistence/schema ownership and needs maintainer direction plus live proof.

## What This Changes

The issue requests that Control UI turns sent into an Open WebUI-backed chat also appear as normal visible message bubbles in Open WebUI history.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling, tests for new turns, and live Docker/Open WebUI proof; otherwise document that Control UI co-editing does not update Open WebUI visible history.
