## Summary

Keep open: current main and the latest release still persist and broadcast Control UI turns through OpenClaw's Gateway/session transcript path, but there is no source path that mirrors those turns into Open WebUI's visible history store. This needs maintainer direction because the plausible fix crosses into third-party Open WebUI persistence ownership, schema/API compatibility, and live proof.

## What This Changes

The issue requests that Control UI turns in an Open WebUI-backed chat appear in Open WebUI visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, then add focused Gateway coverage and Docker/Open WebUI proof, or explicitly document that Control UI co-editing of Open WebUI visible history is unsupported.
