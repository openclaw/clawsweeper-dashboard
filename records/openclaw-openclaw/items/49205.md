## Summary

Keep open: current main and the latest release still persist Control UI turns through OpenClaw transcript/session state and Gateway broadcasts, but they do not mirror those external turns into Open WebUI's own visible-history store. The remaining fix needs maintainer direction because it crosses a third-party persistence/schema boundary.

## What This Changes

The issue asks OpenClaw to keep Open WebUI visible chat history in sync when Control UI writes into the same Open WebUI-backed chat.

## Best Possible Solution

Adopt a maintainer-approved Open WebUI sync boundary: either an official opt-in mirror/repair path with live Docker proof, or an explicit docs/support stance that Control UI turns are not mirrored to Open WebUI visible history.
