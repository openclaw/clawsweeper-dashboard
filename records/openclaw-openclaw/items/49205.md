## Summary

Keep open: current main and v2026.6.11 still persist Control UI `chat.send` turns through OpenClaw transcript/session paths, but there is no Open WebUI visible-history mirror path. The remaining work needs maintainer direction because a durable fix crosses third-party Open WebUI persistence/schema ownership and live-proof requirements.

## What This Changes

The issue requests that Control UI turns sent into an Open WebUI-backed chat be mirrored into Open WebUI visible history as normal message bubbles.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably an explicit opt-in integration or stable adapter/API path with schema/version handling, fresh-turn tests, and live Open WebUI proof.
