## Summary

Keep open: current main and the latest release still have no Open WebUI visible-history mirror for Control UI turns, and the remaining fix needs maintainer direction because it would couple OpenClaw to third-party Open WebUI persistence and upgrade behavior.

## What This Changes

Request that Control UI `chat.send` turns in Open WebUI-backed UUID chats also appear in Open WebUI visible chat history.

## Best Possible Solution

Define a maintainer-approved Open WebUI visible-history sync boundary, preferably an explicit opt-in integration or adapter with schema/version handling, fresh-turn tests, and live Open WebUI proof; otherwise document that Control UI co-editing does not update Open WebUI history.
