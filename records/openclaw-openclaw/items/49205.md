## Summary

Keep open: current main and the latest release still persist and broadcast Control UI `chat.send` turns through OpenClaw's session/transcript path, but there is no Open WebUI visible-history mirror. The remaining work needs maintainer direction because the likely fix crosses third-party Open WebUI persistence and upgrade ownership.

## What This Changes

The issue asks OpenClaw to make Control UI turns in an Open WebUI-backed chat appear in Open WebUI visible chat history, not only in OpenClaw transcript/model context.

## Best Possible Solution

Define a maintainer-approved, opt-in Open WebUI visible-history sync boundary with schema/version handling and live Docker proof, or explicitly document that Control UI co-editing does not update Open WebUI visible history.
