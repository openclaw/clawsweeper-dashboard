## Summary

Keep open. Current main still rebuilds the touched-file list by fully visiting session messages, while this branch introduces a distinct incremental delta fold. The `maintainer` label requires explicit human handling, and the submitted test evidence is useful but does not yet show an after-fix result from a real long-running session.

## What This Changes

The PR changes the gateway’s session-files handlers to cache a bounded touched-file fold and advance it from SQLite transcript deltas instead of rescanning every message for each Files-panel request.

## System Context

The gateway’s `sessions.files.list` and `sessions.files.get` handlers derive workspace files touched by agent tool calls from a session transcript, then return them to the Control UI. This PR replaces the full transcript read at that boundary with a process-local incremental fold driven by the transcript store’s cursor and reset signals.
