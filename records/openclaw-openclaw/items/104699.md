## Summary

The exact PR head has two merge-blocking harness defects: the collision scenario can pass without invoking the selected node tool, and the outer RPC deadline can expire before the gateway returns the agent run’s terminal payload. The `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The PR adds an opt-in live Anthropic model mode to the node-hosted plugin pond E2E, covering MCP tool invocation, node skill injection, and colliding tool-name disambiguation.

## Best Possible Solution

Keep the three live scenarios, but make the selected pond-b command return and record an unpredictable proof value that is asserted from node-side state, and give the outer Gateway RPC request explicit grace beyond the inner agent timeout.
