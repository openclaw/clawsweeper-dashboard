## Summary

Keep this maintainer-labeled PR open. Current `main` hard-fails when an existing gateway identity cannot decode, and the patch directly addresses that recovery gap with bounded reads, quarantine, and atomic persistence; no concrete patch defect was established. The submitted proof is still test-only, so a real Quick Chat recovery run is needed before merge.

## What This Changes

The PR changes the Linux Quick Chat gateway identity store to quarantine malformed identity files, create a replacement identity, preserve version-mismatched files, and write updates atomically.

## System Context

Linux Quick Chat loads a persisted device identity before it can authenticate and open a Gateway connection. That identity selects device-token authentication and is updated after pairing, so load and write failures affect the app’s ability to reconnect.
