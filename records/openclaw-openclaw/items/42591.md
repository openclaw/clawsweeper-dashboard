## Summary

Keep open. Current main and the latest release still ship `scripts/install.sh` as a single public installer, and a modular split remains a broad stable-installer refactor that needs installer-owner direction before implementation.

## What This Changes

The issue requests splitting the large public installer script into smaller shell modules for UI, download, platform detection, package-manager, git, npm, and build-tool responsibilities.

## Best Possible Solution

Preserve the public `openclaw.ai/install.sh` entrypoint and only split modules under an installer-owner-approved plan that updates docs, website sync, ShellCheck, Docker, macOS, and focused installer tests together.
