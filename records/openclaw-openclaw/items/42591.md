Keep open. Current main and the latest release still use one public `scripts/install.sh`; this is a broad installer architecture cleanup on a stable setup surface, so it needs owner direction rather than conservative cleanup closure.

## What This Changes

## Best Possible Solution

Have installer owners approve a split architecture that preserves the public `openclaw.ai/install.sh` entrypoint, then land it incrementally with docs, website-sync, ShellCheck, Docker, and macOS installer proof.
