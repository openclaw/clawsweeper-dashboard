## Summary

Keep open. Current main and the latest release still ship a single public `scripts/install.sh`, and the requested modular split is a broad stable-installer refactor that needs installer-owner product/architecture direction rather than cleanup closure.

## What This Changes

Requested splitting the large macOS/Linux `scripts/install.sh` installer into focused shell modules for UI, download, platform, npm/git, and build-tool logic.

## Best Possible Solution

Have installer owners approve an incremental module architecture that preserves the public `openclaw.ai/install.sh` entrypoint and lands with docs, website-sync, ShellCheck, Docker, macOS, and focused unit proof.
