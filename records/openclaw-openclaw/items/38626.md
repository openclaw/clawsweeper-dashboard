## Summary

Keep open: current main has task summaries, artifact lookup, task cancel, internal subagent kill/steer helpers, and limited audit events, but it still does not provide the requested durable ordered subagent lifecycle receipt or public audited cancel/steer/resume supervision contract.

## What This Changes

Request deterministic async subagent lifecycle receipts, persisted summaries with artifact pointers, and idempotent audited cancel/steer/resume supervision controls.

## Best Possible Solution

Define one redacted SQLite-backed lifecycle and supervision contract, preferably reusing task summaries, audit receipts, artifact RPCs, and session/subagent controls before adding any parallel store.
