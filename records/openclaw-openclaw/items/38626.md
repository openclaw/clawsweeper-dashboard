## Summary

Keep open: current main has task summaries, separate artifact lookup, metadata audit records, subagent lifecycle hooks, and internal list/kill/steer helpers, but it still lacks the requested durable ordered subagent lifecycle receipt and public audited cancel/steer/resume supervision contract.

## What This Changes

Request a core subagent lifecycle receipt and supervision surface with per-run transitions, summaries, artifact pointers, first-failure guidance, and idempotent audited cancel/steer/resume controls.

## Best Possible Solution

Define a bounded metadata-only core contract that links subagent runs to task, artifact, and audit records, exposes ordered lifecycle events and terminal guidance, and makes supervision actions idempotent and auditable without adding a heavy orchestration framework.
