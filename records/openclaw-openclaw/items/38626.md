## Summary

Keep open: current main has task summaries, task cancel RPCs, artifact RPCs, metadata-only audit records, and internal subagent kill/steer helpers, but it still lacks the requested ordered subagent lifecycle receipt and public audited cancel/steer/resume supervision contract.

## What This Changes

Request durable subagent lifecycle events, run summaries with artifact pointers, and idempotent async supervision controls for cancel, steer, and resume.

## Best Possible Solution

Define one redacted SQLite-backed subagent lifecycle receipt and audited supervision API, preferably layering the existing task, audit, artifact, and session-control primitives with explicit operator scopes and upgrade tests.
