## Summary

Keep open: current main has task summaries, task cancel, internal subagent list/kill/steer helpers, audit/list, and artifact RPCs, but still lacks the requested durable ordered per-subagent lifecycle receipt and public audited cancel/steer/resume supervision contract.

## What This Changes

Request deterministic subagent lifecycle events, run summaries with artifacts/failure guidance, and idempotent audited supervision actions.

## Best Possible Solution

Define a small metadata-only subagent lifecycle/supervision contract on top of task, audit, and artifact primitives, with explicit authorization, redaction, retention, and tests before adding UI or CLI.
