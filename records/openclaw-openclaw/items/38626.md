## Summary

Keep open: current main has subagent status/control helpers, task summaries/cancel RPCs, artifact listing, and metadata-only audit events, but it still lacks the requested durable ordered subagent lifecycle receipt and audited public cancel/steer/resume supervision contract.

## What This Changes

Request durable subagent lifecycle events, run summaries with artifact and failure details, and idempotent audited cancel/steer/resume supervision controls.

## Best Possible Solution

Define one redacted SQLite-backed subagent lifecycle receipt and audited supervision API, likely layered through the existing task/audit/artifact primitives, with explicit read/write scopes and upgrade tests.
