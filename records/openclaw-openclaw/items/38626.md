## Summary

Keep open: current main has metadata-only audit, task, subagent summary, and artifact-query foundations, but it still lacks subagent-specific ordered lifecycle receipts, terminal first-failure/recommended-action payloads, and a public audited cancel/steer/resume supervision contract.

## What This Changes

Add durable observability and supervision for asynchronous subagent workflows, including ordered lifecycle events, artifact pointers, failure guidance, and deterministic cancel/steer/resume controls.

## Best Possible Solution

Extend the existing SQLite audit, task, subagent, and artifact foundations into one maintainer-approved subagent lifecycle receipt and supervision API with explicit event taxonomy, permissions, redaction, retention, tests, and docs.
