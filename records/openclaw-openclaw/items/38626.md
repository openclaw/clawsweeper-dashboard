## Summary

Keep open: current main has subagent summaries, task summaries/cancel RPCs, metadata-only audit events, artifact RPCs, and internal subagent kill/steer helpers, but it still lacks the requested durable ordered subagent lifecycle receipt and public audited cancel/steer/resume supervision contract.

## What This Changes

The issue requests deterministic lifecycle observability and supervision controls for async subagent workflows, including event timelines, artifact/failure summaries, and idempotent cancel/steer/resume actions.

## Best Possible Solution

Define one redacted SQLite-backed subagent lifecycle receipt and audited supervision API, likely layered through the existing task, audit, artifact, and session-control primitives with explicit read/write scopes and upgrade tests.
