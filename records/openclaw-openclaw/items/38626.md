## Summary

Keep open: current main has durable background task records, task summaries, artifact lookup, task cancel, Control UI task rows, and internal subagent lifecycle handling, but it still lacks the requested ordered subagent lifecycle receipt and public audited cancel/steer/resume supervision contract.

## What This Changes

The issue requests durable subagent lifecycle observability, artifact-linked run summaries, and idempotent async supervision controls such as cancel, steer, and resume.

## Best Possible Solution

Define one durable, metadata-only subagent lifecycle receipt and supervision API that reuses the task ledger/audit ledger where possible, preserves operator scopes, and avoids adding a parallel orchestration framework.
