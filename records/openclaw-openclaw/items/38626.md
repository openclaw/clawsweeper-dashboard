## Summary

Keep open: current main has task summaries, task broadcasts, artifact lookup, metadata audit records, subagent registry state, and internal kill/steer helpers, but it still lacks the requested durable ordered subagent lifecycle receipt and a public audited supervision contract for cancel/steer/resume.

## What This Changes

Request to add subagent lifecycle timelines, run summaries with artifact and failure guidance, and idempotent async supervision controls.

## Best Possible Solution

Define a bounded metadata-only core receipt that links subagent runs to task, artifact, and audit records, with ordered lifecycle events and idempotent authorized supervision actions.
