## What This Changes

Adds optional `plugins.entries.openshell.config.env`, validates env keys in runtime and manifest schemas, passes entries as repeatable OpenShell `--env KEY=VALUE` sandbox-create args, and updates OpenShell docs/tests.

## Best Possible Solution

Land after maintainer acceptance of the additive OpenShell env config contract and green or waived CI; defer only if maintainers want a broader generic sandbox-env policy instead.

## Reproduction Assessment

## Solution Assessment

Yes, if maintainers accept the new config surface: OpenShell already owns sandbox create flags and plugin config for `from`, providers, GPU, and policy, and upstream docs confirm create-time `--env` semantics. ([docs.nvidia.com](https://docs.nvidia.com/openshell/sandboxes/manage-sandboxes)) The main alternative is a broader generic sandbox-env policy, which is a product decision rather than a patch defect.
