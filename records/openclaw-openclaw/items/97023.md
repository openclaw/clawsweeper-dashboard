The branch converts Anthropic custom tool definitions, custom `tool_choice`, and custom `allowed_tools` entries in the OpenAI-compatible Anthropic stream wrapper into OpenAI function-tool payloads and adds regression coverage for invalid custom tools.

## Best Possible Solution

Land the focused bridge fix once maintainers accept the function-only OpenAI-compatible payload contract, or request one live OpenAI custom-tool failover proof before merge if wrapper-level proof is not enough.
