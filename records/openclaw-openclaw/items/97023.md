The PR changes the OpenAI-compatible Anthropic stream-wrapper bridge and its tests so Anthropic custom tool definitions, pinned choices, and allowed choices are emitted as OpenAI function tools or quarantined when unprojectable.

## Best Possible Solution

Land the wrapper-level projection fix after maintainers accept the public-helper compatibility change, with the existing live OpenAI wrapper test rerun when credentials and runner stability make that practical.

## Solution Assessment

Yes. The compatibility wrapper is the narrow owner boundary, and converting Anthropic custom JSON schemas to OpenAI function tools matches OpenClaw's existing OpenAI projection path without adding config, fallback, or provider-policy surface.
