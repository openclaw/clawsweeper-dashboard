## What This Changes

The branch replaces unbounded QA channel bus client JSON reads with shared 16 MiB bounded readers and adds oversized poll/state regression tests.

## Best Possible Solution

Land the bounded-reader patch once maintainers accept the 16 MiB QA bus cap; if larger QA payloads are valid, document a QA-specific cap and update the tests around it.

## Solution Assessment

Yes. Reusing the existing bounded response helpers in the QA channel client is the narrowest maintainable fix; a server-only guard would not protect exported client or facade use against misbehaving endpoints.
