## Summary

This PR is a useful bounded-read fix, but it is not merge-ready because the current implementation changes shipped `--message-file` path behavior by rejecting symlinks to regular prompt files, and the latest contributor proof still does not show the real `openclaw agent --message-file` CLI path.

## What This Changes

The PR replaces `openclaw agent --message-file` raw `readFile` reads with a 4 MiB `readRegularFile` call and adds oversized-file and directory-error regression tests.

## Best Possible Solution

Keep the 4 MiB pre-dispatch cap, but implement it with a bounded target-file read that preserves symlinks to regular prompt files unless maintainers explicitly approve and document the stricter rule.
