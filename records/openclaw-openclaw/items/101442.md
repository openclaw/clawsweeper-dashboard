## What This Changes

This PR changes `openclaw agent --message-file` to cap reads at 4 MiB through the shared regular-file helper while preserving directory errors and symlinked regular-file paths.

## Best Possible Solution

Implement the cap with a bounded read loop that preserves current readable path types, add FIFO regression coverage, and document the 4 MiB ceiling in both public agent guides.
