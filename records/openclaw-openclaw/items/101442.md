## Summary

## What This Changes

The PR replaces unbounded `openclaw agent --message-file` reads with a 4 MiB `readRegularFile` cap and adds an oversized-file regression test.

## Best Possible Solution

Land a bounded-read fix through the core fs-safe wrapper, normalize too-large and non-file errors into the CLI’s existing message-file wording, document or explicitly confirm the 4 MiB public limit, and include terminal proof for oversized and normal files.
