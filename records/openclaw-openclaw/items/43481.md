## Summary

Keep open: current main still lacks a provider media trust-policy surface, source inspection shows fallback paths can carry or load images without a provider trust decision, and the linked fix candidate remains open rather than landed.

## What This Changes

Requests a provider media trust policy so cross-provider model fallback can avoid sending user images or attachments to fallback providers unless allowed.

## Best Possible Solution

Land a maintainer-approved core fallback media trust boundary covering explicit images, prompt-loaded images, attachments, schema, docs, tests, and upgrade behavior.
