## Summary

Keep open: current main still lacks a provider media trust-policy surface, the affected fallback paths still forward or load prompt-local images in some retry modes, and the open linked PR is an unmerged/conflicting implementation candidate rather than a completed fix.

## What This Changes

Request to add provider-level media trust controls so cross-provider fallback can avoid sending images or attachments to providers trusted only for text fallback.

## Best Possible Solution

Keep this issue open as the canonical tracker until maintainers choose and land a tested provider media trust policy, ideally with compatibility-preserving defaults plus an explicit restriction path and docs.
