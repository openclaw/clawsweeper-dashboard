## What This Changes

The issue asks for provider-level media trust controls so cross-provider fallback can distinguish text fallback trust from image or attachment disclosure trust.

Keep this issue as the canonical tracker until maintainers land or reject a documented provider media trust policy with config/schema, doctor/docs, CLI and embedded fallback coverage, and upgrade behavior.
