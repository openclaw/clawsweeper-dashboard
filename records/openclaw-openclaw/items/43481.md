The issue requests provider trust controls so cross-provider fallback can avoid forwarding user images or attachments to a fallback provider trusted only for text.

Keep this issue open as the canonical tracker until maintainers choose the provider media trust boundary and either land, replace, or close the linked implementation candidate.

Options:

- **Add explicit media trust policy (recommended):** Add a documented config/runtime policy that preserves compatibility by default while allowing users to restrict images and attachments on cross-provider fallback.

- **Fail closed for cross-provider media:** Strip media by default on cross-provider fallback and require an explicit opt-in for fallback vision behavior.
