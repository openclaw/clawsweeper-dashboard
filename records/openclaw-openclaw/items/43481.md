## Summary

Keep open: current main still lacks a provider media trust-policy surface, source inspection shows fallback paths can forward or load images without a provider trust decision, and the linked implementation PR is still open rather than landed.

## What This Changes

The issue requests provider-level trust controls so image or attachment data is not unexpectedly forwarded across provider boundaries during model fallback retries.

## Best Possible Solution

Keep this issue open as the canonical tracker until maintainers choose and land a tested provider media trust policy covering CLI fallback, embedded prompt-image loading, attachments, config, docs, and upgrade-safe defaults.
