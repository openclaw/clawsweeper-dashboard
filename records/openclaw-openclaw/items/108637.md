## What This Changes

Makes message reads reject unknown explicit channels and unrecognized `targets` input, and adds resolved channel/thread identifiers to Slack read results.

## Best Possible Solution

For read actions, resolve every explicit channel before consulting tool-context fallback and reject it whenever it is unknown or unavailable; preserve the existing fallback semantics for send and broadcast, return scope metadata for successful Slack reads, and demonstrate both error and success paths in a real Slack setup.
