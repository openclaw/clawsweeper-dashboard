## Summary

Keep open: the crowded-column scroll/title-collapse part is already fixed in current main and v2026.6.11, but current main still lacks expanded Workboard detail drawer parity for edit, archive, status move, stop, and delete actions. The open linked PR is the current fix candidate, so this issue should remain open until that PR lands or is closed.

## What This Changes

The issue requests scalable, scrollable Workboard columns for many cards and the same card-management actions in the expanded card drawer that exist on compact cards.

## Best Possible Solution

Review and land or close the linked action-parity PR; if landing, reuse the existing compact-card guards in the drawer and keep board-name filtering as a separate enhancement.

Yes, at source level: current main exposes edit, archive, status move, stop, and delete on compact Workboard cards while the detail drawer only exposes open-session and start controls. I did not run a live browser reproduction in this read-only review.

## Solution Assessment

Yes for the remaining bug: adding the existing compact-card actions to the detail drawer with the same guards is the narrowest maintainable fix. The board-name filter should be split out if maintainers want that enhancement.
