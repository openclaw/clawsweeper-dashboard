## Summary

## What This Changes

The issue requests scalable Workboard card layout with action parity between collapsed cards and the expanded card detail UI, plus an optional board-name filter.

## Best Possible Solution

Add the existing collapsed-card actions to the detail drawer using the same Workboard helpers and guards, keep the crowded-column scroll regression intact, and split the board-name filter into a separate enhancement if maintainers want it.

## Reproduction Assessment

Yes at source level: collapsed cards expose edit, archive, status move, stop, delete, session, and start controls, while the detail drawer only exposes open-session and start controls. I did not run a live 15-card browser reproduction in this read-only pass.

## Solution Assessment

Yes for the remaining bug: reusing the existing Workboard action helpers in the detail drawer is the narrowest maintainable fix. The board-name filter request should be handled separately if maintainers want that enhancement.
