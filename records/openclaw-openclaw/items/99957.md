## Summary

Keep open: current main and v2026.6.11 have the previous crowded-column squeeze fix, but the expanded Workboard detail drawer still lacks the same edit/archive/status/delete controls available on collapsed cards.

## What This Changes

The issue asks for scalable, scrollable Workboard cards and action parity between collapsed card summaries and the expanded card view in the web console.

## Best Possible Solution

Add the existing card actions to the detail drawer with the same controller helpers and guards, keep the crowded-column scroll regression covered, and split the board-name filter into a separate enhancement if maintainers want it.

## Reproduction Assessment

Yes at source level: collapsed cards render edit, archive, move/status, delete, stop/session, and start controls, while the detail drawer only renders open-session and start controls. I did not run a live browser reproduction of 15 same-status cards in this read-only pass.

## Solution Assessment

Yes for the main bug: reusing the existing Workboard card action helpers in the detail drawer is the narrowest maintainable fix. The workboard-name filter should be handled separately if maintainers want that enhancement.
