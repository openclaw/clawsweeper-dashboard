## What This Changes

This PR replaces nested stream-wrapper assembly in the bundled xAI, OpenRouter, and vLLM provider plugins with the shared left-to-right composer, and adds coverage for vLLM’s Qwen/Nemotron thinking interaction.

## System Context

Provider plugins receive a model-stream request context and layer vendor-specific routing, authentication, thinking, and tool-stream safeguards around it before sending the request to the model API. This change centralizes that layering through the shared provider stream composer while retaining provider-owned wrapper behavior.
