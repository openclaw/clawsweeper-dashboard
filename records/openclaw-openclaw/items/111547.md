## Summary

Keep this issue open. The supplied released-dist probe and production evidence identify a narrow mismatch in the existing `typingMode: "message"` contract, and no merged fix or canonical replacement is established.

## What This Changes

The issue requests that execution-phase typing respect `typingMode: "message"` by waiting for renderable assistant text before initially starting the typing indicator.

## Best Possible Solution

Add focused core-controller coverage and prevent execution activity from initially starting typing in message mode before renderable text, while retaining refresh behavior for an already-active indicator.
