Adds experimental `claws export <agent> --out <path>` support that serializes one installed agent into a derivative portable Claw package with managed workspace and safe-avatar sidecars.

## Best Possible Solution

Keep healthy, exact recorded state as the default export boundary; if degraded exports are wanted, introduce an explicit snapshot mode that emits structured drift and lineage metadata, then prove both paths with real CLI output on the final stack.
