## Summary

Keep this PR open for maintainer review. It adds a new experimental package-export contract on top of an unmerged lifecycle stack, and the remaining decision is whether exports must reject incomplete/drifted installations by default or support an explicitly marked snapshot mode; the current-head proof does not demonstrate that boundary.

## What This Changes

Adds experimental `claws export <agent> --out <path>` support that projects an installed Claw agent and portable managed workspace state into a derivative package, with CLI tests and documentation.

## Best Possible Solution

Land a single documented export contract: reject incomplete or drifted installations by default, preserve derivative package identity and portable sidecars, and add an explicit snapshot mode only if maintainers want non-reproducible exports with a machine-readable drift report and lineage metadata.
