## What This Changes

Adds an experimental `claws export` command that packages an installed agent’s portable configuration and managed workspace assets under a derivative package identity, with CLI and round-trip lifecycle coverage.

## Best Possible Solution

Define healthy exact-state export as the default, add an explicit snapshot path for drifted or partial state with structured drift and lineage metadata, and align the RFC, round-trip tests, and later `CLAW.md` exporter with that single approved contract.
