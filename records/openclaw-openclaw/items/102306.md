## What This Changes

Adds an experimental `claws export <agent-id> --out <directory>` command that writes portable agent configuration and managed workspace assets as a derivative, content-versioned Claw package.

## Best Possible Solution

Define healthy exact installed state as the default export contract, offer drifted or partial export only through an explicit snapshot mode with lineage and a structured drift report, and then land the lifecycle, export, and canonical-format slices in dependency order.
