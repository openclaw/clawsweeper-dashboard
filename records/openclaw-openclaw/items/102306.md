## What This Changes

Adds an experimental `claws export <agent-id> --out <directory>` command that packages portable agent configuration and managed workspace assets under a derivative, content-versioned Claw package identity.

## Best Possible Solution

Define healthy exact-state export as the default, add an explicit snapshot mode for partial or drifted installations, and embed source identity, integrity, resolved dependency digests, exporter/schema version, content digest, and a machine-readable drift report before freezing the package contract.
