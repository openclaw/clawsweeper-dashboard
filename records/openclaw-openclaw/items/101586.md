Allow the bundled Codex app-server harness to claim configured OpenClaw provider IDs that correspond to Codex `model_providers` entries.

## Best Possible Solution

Review the linked implementation candidate and either land a plugin-owned, documented allowlist with focused config/harness tests or choose a config-derived Codex provider discovery design before changing the public config surface.
