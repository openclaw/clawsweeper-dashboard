## Summary

Keep this PR open: it addresses a real Chrome leave defect, but the patch treats a meeting URL as both tab identity and ownership, creating blocking lifecycle regressions, and its after-fix proof is mock-only.

## What This Changes

The branch makes Google Meet Chrome and Chrome-node leave click the in-call leave control and close a matched tab, adds handoff and shared-session guards, and updates regression tests and plugin docs.

## Best Possible Solution

Store the exact browser context, target id, and opened-versus-reused ownership on each session; leave that exact target, close it only when OpenClaw opened it, and suppress departure only when another active session truly shares the same target and context.
