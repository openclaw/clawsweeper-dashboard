## Summary

Keep open: current main and v2026.6.11 still miss the Google Chat `identity.name` typing fallback, and the markdown half remains an unresolved Google Chat rendering-policy decision rather than an implemented fix.

## What This Changes

The issue asks the Google Chat plugin to avoid raw markdown-looking output and to use the configured agent display name in the typing placeholder.

## Best Possible Solution

Update the Google Chat plugin to use account name, then agent name, then `agent.identity.name`, then `OpenClaw` for typing, and add a maintainer-approved Google Chat renderer with focused tests and live channel proof.
