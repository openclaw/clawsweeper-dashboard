## Summary

Keep open: current main and latest release still miss the `agents.list[].identity.name` typing-name fallback, and the inbound Google Chat reply path still sends markdown chunks without a settled Google Chat formatting conversion policy.

## What This Changes

The issue reports two Google Chat UX bugs: markdown appears as raw syntax and the typing placeholder shows a generic OpenClaw name instead of the configured agent/app identity.

## Best Possible Solution

Keep the issue open until a Google Chat-owned fix adds `identity.name` to the typing fallback and implements a maintainer-approved markdown-to-Google-Chat text policy across inbound replies and message actions, with focused tests and live Google Chat proof.

## Reproduction Assessment

Yes for source-level reproduction: current main and v2026.6.11 still omit `agent.identity.name` from the typing fallback and pass markdown reply chunks directly to Google Chat. No live Google Chat run was performed in this read-only review.

## Solution Assessment

No final fix is present yet. The typing fallback is a narrow code fix, but the markdown half needs a deliberate Google Chat formatting policy instead of another disconnected strip-or-convert patch.
