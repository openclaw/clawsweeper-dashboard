## Summary

Keep open: current main and v2026.6.11 still skip `agents.list[].identity.name` for the Google Chat typing placeholder, and the markdown portion still needs a maintainer-approved Google Chat rendering policy rather than a close as implemented.

## What This Changes

The issue asks for Google Chat replies to avoid raw markdown syntax and for the typing placeholder to use the configured agent display name instead of falling back to OpenClaw.

## Best Possible Solution

Use a maintainer-approved Google Chat renderer that converts supported assistant Markdown into Google Chat text syntax, strips unsupported markers safely, and add the `agent.identity.name` typing fallback with focused tests and live Google Chat proof.
