## Summary

Keep open: current main and the latest v2026.6.11 release still skip `agent.identity.name` in the Google Chat typing-name fallback, and Google Chat reply delivery still sends Markdown chunks without a Google Chat-specific rendering policy. The open cross-repository PR only covers the typing fallback, so the markdown behavior still needs maintainer direction.

## What This Changes

The issue requests Google Chat-specific handling so assistant Markdown does not appear as raw markers and typing placeholders use the configured agent identity name.

## Best Possible Solution

Update the Google Chat plugin to use account name, then agent name, then `agent.identity.name`, then `OpenClaw` for typing, and add a maintainer-approved Google Chat Markdown renderer with focused tests and live channel proof.
