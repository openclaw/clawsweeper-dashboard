## Summary

Keep open: current main and the latest release still miss the Google Chat `identity.name` typing fallback and do not strip or convert assistant Markdown before sending reply text. This issue remains the canonical same-repository tracker because the related same-repo PRs are closed unmerged, and the open cross-repository typing PR covers only half of the report.

## What This Changes

The issue requests fixing two Google Chat UX bugs: raw Markdown markers in replies and a typing indicator that uses `OpenClaw` instead of the configured agent identity name.

## Best Possible Solution

Adopt a maintainer-approved Google Chat formatting policy, then update the plugin so typing resolves account name, `agent.name`, `agent.identity.name`, then `OpenClaw`, with focused tests and live Google Chat proof.
