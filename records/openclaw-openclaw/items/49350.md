## Summary

Keep open: current main and v2026.6.11 still miss the Google Chat `identity.name` typing fallback, and the Markdown half remains an unresolved Google Chat rendering-policy decision rather than an implemented fix.

## What This Changes

The issue asks Google Chat to avoid raw Markdown syntax in sent messages and to use the configured agent identity for the typing indicator.

## Best Possible Solution

Update the Google Chat plugin to use account name, then agent name, then `agent.identity.name`, then `OpenClaw` for typing, and add a maintainer-approved Google Chat Markdown renderer or plain-text policy with focused tests and live channel proof.
