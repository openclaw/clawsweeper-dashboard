## Summary

Keep open: current main and the latest release still miss the Google Chat typing-name fallback for `agents.list[].identity.name`, and the markdown half remains a real Google Chat rendering-policy question rather than an implemented fix.

## What This Changes

The issue asks for Google Chat replies to stop exposing raw Markdown syntax and for the typing placeholder to use the configured agent display name instead of falling back to OpenClaw.

## Best Possible Solution

Update the Google Chat plugin to use account name, then agent name, then `agent.identity.name`, then `OpenClaw` for typing, and add a maintainer-approved Google Chat renderer that converts supported Markdown syntax while stripping or documenting unsupported constructs with focused tests and live channel proof.
