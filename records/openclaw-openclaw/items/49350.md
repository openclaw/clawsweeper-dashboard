## Summary

Keep open: current main and v2026.6.11 still miss the Google Chat typing fallback for `agents.list[].identity.name`, and the markdown half still needs a maintainer choice between Google Chat dialect conversion, plain-text stripping, or keeping the current markdown-capable contract.

## What This Changes

The issue asks Google Chat replies to avoid raw Markdown syntax and to show the configured agent identity name in the typing placeholder.

## Best Possible Solution

Update the Google Chat plugin to resolve typing names as account name, agent name, `agent.identity.name`, then `OpenClaw`, and add a maintainer-approved Google Chat renderer or plain-text policy with focused tests and live Google Chat proof.
