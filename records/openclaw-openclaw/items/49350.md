## Summary

Keep open: current main and the latest release still show the typing fallback skipping `identity.name`, while the markdown behavior needs a maintainer rendering-policy choice rather than a cleanup close.

## What This Changes

The issue asks the Google Chat channel to avoid raw assistant Markdown in sent messages and to show the configured agent identity name in the typing placeholder.

## Best Possible Solution

Approve a Google Chat rendering policy, preferably converting supported assistant Markdown into Google Chat’s subset with graceful degradation, and land it with the `identity.name` typing fallback, focused tests, and live Google Chat proof.
