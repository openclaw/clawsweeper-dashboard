## Summary

Keep open: current main and the latest v2026.6.11 release still skip `agent.identity.name` in the Google Chat typing-name fallback, and Google Chat reply/outbound delivery still lacks a Google Chat-specific Markdown renderer. The open cross-repository PR covers only the typing fallback, so the formatting half still needs maintainer direction.

## What This Changes

The issue asks the Google Chat plugin to render assistant Markdown appropriately for Google Chat and to use the configured agent identity name in the typing placeholder.

## Best Possible Solution

Keep this as the canonical Google Chat plugin issue until maintainers choose the text rendering policy, then land a focused fix that adds the identity-name fallback and covers Google Chat text rendering with tests and real channel proof.
