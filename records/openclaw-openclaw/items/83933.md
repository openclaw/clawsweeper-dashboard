## What This Changes

The PR separates operator cron runs from scheduler and on-exit watcher runs so manual executions preserve one-shot jobs, counters, backoff, enabled state, and scheduled timing.

Adopt one explicit contract in which public operator runs record outcomes without consuming scheduler state, keep consuming origins private to scheduler-owned paths, preserve absent-field upgrade semantics, and demonstrate the overdue maintenance-and-restart case in a live current-head gateway before landing.
