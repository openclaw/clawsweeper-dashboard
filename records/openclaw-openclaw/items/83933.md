## Summary

## What This Changes

The PR marks manual cron completions with `isManual`, preserves scheduled delete/retry/backoff/alert state for manual runs, records `lastRunWasManual`, updates cron protocol schemas, and adds cron regression coverage.

Land after a maintainer explicitly accepts manual cron runs as non-consuming verification operations and confirms the new `lastRunWasManual` state field is the desired compatibility contract.
