## What This Changes

This PR distinguishes operator, timer, and gateway on-exit cron runs so manual `cron run` preserves a scheduled one-shot and its timing while scheduler-owned executions retain deletion, retry, and lifecycle behavior.

## System Context

OpenClaw’s cron service accepts manual CLI/RPC runs, timer ticks, and gateway on-exit watcher events, then records outcomes in the persisted cron job state. Those outcomes drive future scheduling, retry/backoff, job deletion, alerts, and gateway-visible cron status.
