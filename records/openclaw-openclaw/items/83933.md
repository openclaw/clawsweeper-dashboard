## Summary

This PR addresses a valid, still-present manual-run bug and preserves the recently merged on-exit watcher contract, but one scheduler-state defect remains: manual run records can still be interpreted as scheduled completion or cadence anchors during restart or maintenance recomputation. The patch should remain open for that focused repair.

## What This Changes

Separates operator, timer, and on-exit watcher cron finalization so manual runs preserve one-shot jobs and scheduled counters while scheduler-owned runs retain consuming behavior.

## Best Possible Solution

Treat manual outcomes as audit/display state only: make next-run completion and cadence computation ignore manual last-run records, while preserving timer and watcher-terminal ownership and the optional upgrade-safe provenance field.
