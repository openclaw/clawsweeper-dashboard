## Summary

Keep this PR open: the internal origin separation and live proof are strong, but the non-consuming operator contract remains incomplete for jobs whose scheduled slot is already due or overdue. ([github.com](https://github.com/openclaw/openclaw/blob/main/src/cron/service/timer.ts))

## What This Changes

Separates operator, scheduler-timer, and gateway on-exit cron finalization so manual runs preserve one-shot jobs and scheduler-owned counters while scheduled origins retain consuming behavior.

## Best Possible Solution

Keep explicit internal run origins, but make every next-run, expired-slot, retry, disable, and deletion decision consume only scheduler-owned outcomes; operator outcomes may remain visible without becoming scheduling evidence.
