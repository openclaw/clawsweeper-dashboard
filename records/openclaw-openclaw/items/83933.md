## Summary

Keep this PR open: current main still lets the manual cron-run path flow into one-shot deletion and scheduler-state mutation, while this branch introduces a focused origin boundary to separate operator runs from timer and on-exit watcher runs. ## What This Changes

The branch adds internal cron run origins and persisted manual-run attribution so operator-triggered runs preserve one-shot jobs and scheduler timing/counters while scheduled and on-exit watcher runs retain consuming behavior.
