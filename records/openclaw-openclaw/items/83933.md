## Summary

Keep this PR open: it is a focused and well-proven fix for manual cron-run isolation, but the previous blocker still remains because at-job recompute/maintenance paths can still clear a due slot after a manual successful run.

## What This Changes

This PR adds manual-run isolation to cron result handling, records `lastRunWasManual` in cron state/protocol, and expands cron tests for deleteAfterRun, retry counters, backoff, failure alerts, trigger evaluation, and restart catch-up.

## Best Possible Solution

Land the cron-owned manual-run isolation only after every at-job due-slot decision path, including maintenance recompute and restart/read recovery, treats manual terminal status as non-consuming and has focused regression coverage.
