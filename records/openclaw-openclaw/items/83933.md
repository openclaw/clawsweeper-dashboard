## Summary

Keep open: the current head still misclassifies public due checks as scheduled work when trigger evaluation errors, and its exact-head CI also retains a test expecting the old manual-deletion behavior.

## What This Changes

The PR makes manual cron runs preserve scheduled deletion, counters, alerts, backoff, enabled state, and due slots, persists the last run’s manual origin, and adds broad lifecycle regression coverage.

## Best Possible Solution

Carry a closed caller-owned execution origin through preparation and result application: public due and force requests remain manual, while only timer-owned trigger polling mutates scheduled counters and backoff.
