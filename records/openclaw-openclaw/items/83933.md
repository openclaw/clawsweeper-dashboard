## Summary

Keep open: current main still has the destructive manual-run behavior, but this head is not merge-ready because it exposes scheduler-only origin authority through the public cron run contract and supplies only function-level test proof rather than a real CLI/Gateway lifecycle.

## What This Changes

The PR distinguishes operator, timer, and Gateway watcher cron runs so operator runs preserve one-shot jobs and scheduled counters while scheduler-owned runs remain consuming.

## Best Possible Solution

Keep public CronServiceRunOptions payload-only, route watcher-terminal execution through an internal scheduler-owned method or unforgeable capability, preserve the merged on-exit consumption contract, and prove both operator and watcher paths on the exact head with redacted live CLI/Gateway output.
