## What This Changes

This PR makes the Control UI hide Cron create, edit, run, clone, pause, and removal controls from operators without `operator.admin`, while preserving Cron status, filters, selection, settings inspection, and history.

## System Context

The Control UI receives the authenticated operator scope set from the Gateway and renders the Cron management page from that session snapshot. The page must expose browsing to read-only operators while allowing only administrators to dispatch Cron mutation requests to the Gateway.
