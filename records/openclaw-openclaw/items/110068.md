## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.96

Full review comments:

- **[P1] Stop the runner before disposing the tracker:** `extensions/telegram/src/bot-core.ts:421`
  - body: The polling restart path starts `runner.stop()` and `bot.stop()` concurrently, while this wrapper disposes the tracker before its original stop call. Because `runner.stop()` is what halts fetching and waits for active middleware, disposal can latch while an accepted update is still processing; its later `finishUpdate` cannot persist the offset, so restart can replay it. Sequence runner shutdown to completion before tracker disposal and cover an update finishing during that window. This is the still-unfixed finding from the previous review of the same head.
  - confidence: 0.96
