The supplied proof is focused Vitest output rather than after-fix CLI behavior, so it also needs real command proof before merge.

## What This Changes

The PR replaces full-file JSONL line counting in doctor state integrity with 64 KiB synchronous chunk reads and adds tests for multi-chunk and one-line transcripts.

## Best Possible Solution
