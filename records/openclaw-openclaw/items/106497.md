## Summary

The patch is a focused, still-useful fix: the browser client resolves a request deadline but does not pass it to the guarded dispatcher, while the shared fetch guard only configures Undici connect and header timeout floors when `timeoutMs` is supplied. The proposed wiring matches the established network-helper contract, adds focused caller-path coverage, and introduces no correctness or security blocker.

## What This Changes

The PR forwards the browser control client’s resolved timeout to `fetchWithSsrFGuard` and adds regression coverage for explicit, default, and hung-peer timeout behavior.
