Keep this PR open as a sound landing candidate. The new exact-path proof resolves the previous proof gate, the timeout addresses the demonstrated unbounded registry wait at the narrow owning call site, and no actionable correctness or security defect remains.

## What This Changes

The PR adds a 120-second SIGKILL timeout to each raw Docker Buildx attestation inspection, exposes the helper for focused injection, and tests the exact child-process options.

## Best Possible Solution

Land the per-inspection deadline as an internal constant, preserve the existing attestation policy, and allow release verification to fail and retry rather than wait without a bound.
