## Summary

Keep open: current main has improved diagnostics for plugin API mismatch, missing bundled-channel modules, and configured channels with no loadable owner, but it still does not establish the requested gateway startup contract that audits attempted, loaded, and failed channels or resolves the Feishu/runtime health and reload-policy questions.

## What This Changes

The issue asks OpenClaw to make gateway channel startup failures visible when channel plugins are incompatible, absent before registration, missing generated files, timing out during owner setup, or changed after install/update.

## Best Possible Solution

Keep the current partial diagnostics, then define one gateway startup/readiness contract that reports configured channel owner discovery, attempted starts, loaded channels, and failed channels while leaving reload or repair to explicit install/doctor/status flows.
