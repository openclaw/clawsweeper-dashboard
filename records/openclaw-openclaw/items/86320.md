## Summary

Keep open: current main has improved plugin failure reporting, version-drift diagnostics, and configured-channel startup warnings, but the gateway still only starts already-loaded channel plugins and lacks the requested per-configured-channel attempted/loaded/failed startup audit or maintainer-approved fail-fast compatibility contract.

## What This Changes

The issue requests clearer gateway startup handling when configured channel plugins are incompatible, missing generated modules, or absent from the loaded channel registry.

## Best Possible Solution

Define a generic gateway startup contract that visibly accounts for every configured channel, preserves unaffected channel availability by default, and directs plugin incompatibility or missing-module repair through status/doctor unless maintainers explicitly choose fail-fast behavior.
