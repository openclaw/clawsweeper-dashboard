## Summary

Keep open: current main has better plugin and startup warnings than the reported 2026.5.12 build, but the central channel audit gap remains because Gateway channel startup still only iterates already loaded channel plugins.

## What This Changes

The issue requests clearer Gateway/channel startup diagnostics and recovery behavior when channel plugins fail to register because of version mismatch, missing generated modules, API timeout, or heavy startup scans.

## Best Possible Solution

Add an owner-approved Gateway startup audit for configured channels that fail before registration, keep plugin-level diagnostics, and split hot reload/performance caching into separate scoped work if maintainers want those behaviors.
