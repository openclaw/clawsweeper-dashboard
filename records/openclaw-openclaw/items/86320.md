## Summary

Keep open: current main has better plugin and bundled-channel diagnostics than the reported 2026.5.12 build, but it still only starts loaded channel plugins and does not audit configured channels that failed before channel registration.

## What This Changes

The issue asks Gateway startup to clearly report channel/plugin initialization failures from runtime mismatches, missing generated modules, external API timeouts, and related startup-performance problems.

## Best Possible Solution

Add an owner-approved Gateway channel initialization audit that includes configured channels failing before registration, and split hot reload plus broad startup caching into separate tracked work.
