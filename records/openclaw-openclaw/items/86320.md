## Summary

Keep open: current main improves plugin-load and configured-channel diagnostics, but the gateway channel startup manager still audits only registered channel plugins, so a configured channel that fails before registration can still miss the requested channel initialization summary.

## What This Changes

The issue asks for clearer gateway startup diagnostics and recovery behavior when channel plugins fail to load or register, bundled modules are missing, or external API probes time out.

## Best Possible Solution

Keep the existing plugin diagnostics, add an owner-approved configured-channel startup audit that includes channels whose owner plugin failed before registration, and split hot reload plus broad performance caching into separate scoped work if maintainers want them.
