## Summary

Keep open: current main and v2026.6.11 have better bundled-channel missing-module warnings, doctor/status plugin diagnostics, and plugin registration diagnostics than the reported 2026.5.12 build, but the Gateway startup loop still only audits already-loaded channel plugins, so configured channels that fail before registration can remain a late `Channel is unavailable` problem without a clear startup contract.

## What This Changes

The issue asks Gateway startup to make channel/plugin load failures, missing generated modules, external API timeouts, and plugin/runtime mismatches visible instead of letting channels appear unavailable only later.

## Best Possible Solution

Define a single startup health contract for configured channels: every configured or attempted channel should either register successfully or appear in a structured warning/error summary with the reason, while optional unsupported bundled channels remain quiet unless explicitly configured.
