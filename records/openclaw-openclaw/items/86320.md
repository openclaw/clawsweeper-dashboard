## Summary

Keep open: current main materially improves startup visibility for configured-but-unloadable channels and Feishu probe timeouts, but it still does not settle the remaining gateway contract for failed pre-registration channels, bundled generated-module recovery, plugin/core drift policy, hot reload, or startup audit shape.

## What This Changes

Report that Gateway can reach the ready banner while configured channel plugins fail to register or load, leaving channels unavailable without clear channel-health diagnostics.

## Best Possible Solution

Keep the current startup-warning improvements, then define an owner-approved gateway/channel health contract that accounts for configured-but-unregistered channels while splitting bundled generated-module, plugin drift, hot reload, and performance work into their canonical trackers.
