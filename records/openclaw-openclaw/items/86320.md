## Summary

Keep open: current main now warns for some configured channels whose owning plugin is blocked or missing, but the issue still has unresolved gateway startup-contract gaps around pre-registration failures, bundled generated-module diagnostics, channel audit visibility, hot reload, and channel health warnings.

## What This Changes

The issue requests clearer gateway diagnostics and startup handling when channel plugins are incompatible, missing generated module files, or fail before their channel is initialized.

## Best Possible Solution

Keep the current configured-channel warning work, then add an owner-approved startup audit that joins configured channel intent, plugin-loader failures, loaded channel registry state, and channel start outcomes while splitting hot reload, performance caching, and Feishu API health into narrower follow-ups.
