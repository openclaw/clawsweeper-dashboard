## Summary

Keep open: current main has stronger plugin compatibility and plugin-diagnostic paths than the reported 2026.5.12 setup, but the central Gateway startup gap remains because channel startup only audits already-registered channel plugins.

## What This Changes

The issue asks OpenClaw to surface configured channel startup failures caused by plugin/runtime mismatch, missing bundled modules, external API timeouts, and large plugin-skill startup cost instead of letting channels disappear from Gateway startup.

## Best Possible Solution

Add an owner-approved Gateway startup audit for configured channels that failed before registration, keep bundled setup-entry warnings on the existing canonical tracker, and split hot reload/performance/API-timeout policy into narrower follow-ups if maintainers want those behaviors.
