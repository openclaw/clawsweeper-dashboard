## Summary

Keep open: current main has better plugin compatibility and plugin-loader diagnostics than the reported 2026.5.12 build, but it still does not fully solve the central gap where Gateway channel startup audits only loaded channel plugins and configured channels can disappear before channel startup sees them.

## What This Changes

The issue asks Gateway startup to surface clear channel/plugin initialization failures for plugin runtime mismatches, missing generated channel modules, Feishu API timeouts, and large plugin/skill startup delays.

## Best Possible Solution

Add an owner-approved warn-and-continue startup audit that reconciles configured channel ids, plugin registry failures, bundled loader failures, and loaded channel startup results; split hot reload, broad caching, and external API timeout policy into separate scoped follow-ups unless maintainers explicitly combine them.
