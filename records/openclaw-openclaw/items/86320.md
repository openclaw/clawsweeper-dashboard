## Summary

Keep open: current main has useful partial diagnostics for configured-channel blockers, bundled missing modules, and plugin load failures, but a channel that fails before registration still is not represented in the gateway channel startup loop or a channel init audit.

## What This Changes

The issue asks OpenClaw to make gateway channel startup failures visible when plugins mismatch the runtime, generated channel modules are missing, or channel health probes fail.

## Best Possible Solution

Keep the existing partial diagnostics, then add an owner-approved gateway channel initialization audit that includes configured channels that failed before registration; split hot reload, fail-fast compatibility, timeout severity, and broad startup performance into separate decisions if maintainers want them.
