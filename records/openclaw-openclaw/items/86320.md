## Summary

Keep open: current main has useful configured-channel and plugin-loader diagnostics, including a merged partial fix, but it still does not fully cover the reported case where a configured channel fails before registration and is absent from the channel startup audit.

## What This Changes

The issue asks for gateway startup diagnostics and recovery behavior when channel plugins are incompatible, missing generated modules, or otherwise fail before channel initialization.

## Best Possible Solution

Keep this issue open and define a gateway startup contract that reports configured-but-unloaded channels in one tested audit, while splitting hot reload, performance caching, and Feishu API health policy into separate follow-ups if maintainers want them.
