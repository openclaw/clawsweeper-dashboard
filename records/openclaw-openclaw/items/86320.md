## Summary

Keep open: current main has partial fixes for startup visibility, but the remaining issue is still real because Gateway channel startup only audits loaded channel plugins and does not yet provide a complete configured-channel attempted/loaded/failed audit.

## What This Changes

The issue requests clearer Gateway startup diagnostics when configured channels are skipped by plugin/runtime mismatch or missing generated modules, plus related hot reload, missing-module, API-timeout, and startup-performance improvements.

## Best Possible Solution

Keep the existing plugin error diagnostics, add a maintainer-approved configured-channel startup audit, and split hot reload, broad performance caching, and Feishu API timeout severity into separate owned work if maintainers want them.
