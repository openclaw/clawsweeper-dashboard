## Summary

Keep open: current main has better plugin/status diagnostics than the reported 2026.5.12 build, but Gateway startup still only starts already registered channel plugins, so a configured channel that fails before registration can remain outside the channel startup audit.

## What This Changes

The issue requests clearer Gateway startup handling when channel plugins fail to register, bundled channel modules are missing, or channel probes time out, so configured channels are not silently unavailable.

## Best Possible Solution

Add an owner-approved Gateway startup audit that reports configured channels attempted, loaded, and failed with plugin diagnostic reasons, while keeping hot reload, fail-fast compatibility gates, and broad startup caching as separate maintainer decisions.
