## Summary

Keep open: current main still only has partial hook timeouts, session-lock watchdogs, runtime-health storage, tool-schema quarantine, and an Active Memory-local breaker, not the requested framework-level plugin breaker with attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

Request a framework-level plugin circuit breaker that can open, half-open, or force-open per-plugin hook/tool execution while preserving gateway availability.

## Best Possible Solution

Define a SQLite-backed, upgrade-safe breaker contract for plugin hooks/tools with attribution, passive telemetry first, explicit degradation modes, status visibility, reset controls, and maintainer-approved default behavior.
