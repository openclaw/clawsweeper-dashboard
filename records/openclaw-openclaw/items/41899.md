## Summary

Keep open: current main still has hook-level timeouts, runtime health storage, channel crash-loop suppression, and an Active Memory local breaker, but not the requested framework-level plugin circuit breaker with attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

The issue requests a framework-level plugin circuit breaker that times, attributes, persists, and gates misbehaving plugin hooks while preserving the rest of the gateway.

## Best Possible Solution

Keep this as a maintainer-owned design item and define a SQLite-backed plugin hook/tool breaker contract with attribution, lifecycle state, degradation modes, status visibility, reset controls, and upgrade-safe defaults.
