## Summary

Keep open: current main has hook timeouts, fail-open/fail-closed policies, session-lock watchdogs, context-engine quarantine, and an Active Memory-local breaker, but it still lacks the requested framework-level plugin circuit breaker with plugin/hook attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

The issue requests a framework-level plugin circuit breaker so repeated plugin failures degrade gracefully instead of freezing sessions or leaving zombie agent state.

## Best Possible Solution

Design one canonical plugin-runtime breaker contract with passive telemetry first, SQLite-backed health state if persistence is required, operator-visible status/reset controls, and compatibility-tested defaults.
