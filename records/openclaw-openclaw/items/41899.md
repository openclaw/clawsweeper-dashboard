## Summary

Keep open: current main still lacks the requested framework-level plugin circuit breaker; the existing code provides hook timeouts, plugin health records, session-lock watchdog metadata, and an Active Memory-local breaker, but not persisted plugin lifecycle state, operator reset/status controls, hook/tool attribution, or a compatibility-safe degradation policy.

## What This Changes

Request a framework-level plugin circuit breaker that attributes repeated plugin hook/tool failures, persists breaker state, exposes status/reset controls, and degrades only the affected plugin.

## Best Possible Solution

Define a SQLite-backed plugin breaker contract with hook/tool attribution, open/half-open/forced-open lifecycle, per-plugin fail modes, status/reset surfaces, telemetry, and compatibility-safe defaults before implementation.
