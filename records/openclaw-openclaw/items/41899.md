## Summary

Keep open: current main has partial hook timeout/error handling and an Active Memory-local breaker, but it still lacks the shared plugin-scoped breaker lifecycle, durable state, status/reset controls, and degradation policy requested here.

## What This Changes

Requested a framework-level plugin circuit breaker that isolates misbehaving plugin hooks, persists breaker state, exposes operator controls, and degrades affected plugins without taking down the gateway.

## Best Possible Solution

Define a generic plugin-runtime breaker contract around the existing hook runner and status surfaces, store durable breaker state in the canonical SQLite-backed state path, and require maintainer-approved fail-mode defaults before active quarantine ships.
