## Summary

Keep open: current main still has only partial hook timeouts, plugin status/health surfaces, session-lock watchdog metadata, and an Active Memory local breaker; it does not implement the requested framework-level plugin circuit breaker with attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

The issue requests a framework-level plugin circuit breaker that can isolate misbehaving plugin hooks/tools with timing/error attribution, persisted breaker state, status/reset controls, and per-plugin graceful degradation modes.

## Best Possible Solution

Keep this as a maintainer-owned design item and define a SQLite-backed plugin breaker contract for hooks/tools, including attribution, lifecycle state, degradation modes, status visibility, reset controls, telemetry, and upgrade-safe defaults.
