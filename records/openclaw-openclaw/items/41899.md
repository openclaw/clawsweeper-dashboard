## Summary

Keep open: current main has hook timeouts, plugin-local breakers, and channel/startup health guards, but it still lacks the requested framework-level plugin circuit breaker with plugin/hook attribution, persisted lifecycle state, status/reset surfaces, and per-plugin degradation policy.

## What This Changes

The issue requests a gateway/plugin-runtime circuit breaker that times and attributes plugin hook/tool failures, opens only the affected plugin path, persists breaker state, exposes operator visibility/reset, and supports per-plugin degradation modes.

## Best Possible Solution

Define a SQLite-backed plugin breaker contract for hooks/tools with attribution, passive telemetry rollout, status/reset surfaces, per-plugin degradation modes, and upgrade-safe defaults before implementing active open/half-open behavior.
