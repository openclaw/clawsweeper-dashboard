## Summary

Keep open: current main has partial mitigations, but not the requested framework-level plugin circuit breaker with attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

Issue requests a framework-level plugin circuit breaker that attributes plugin hook/tool failures, persists breaker state, degrades only affected plugins, and exposes operator status/reset controls.

## Best Possible Solution

Keep this as a maintainer-owned design item and define a SQLite-backed breaker contract for plugin hooks/tools, including attribution, lifecycle state, degradation modes, status visibility, reset controls, and upgrade-safe defaults.
