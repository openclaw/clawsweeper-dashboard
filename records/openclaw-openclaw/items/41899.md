## Summary

Keep open: current main still has only partial hook timeouts, generic runtime-health storage, session-lock watchdog metadata, and an Active Memory local breaker; it does not implement the requested framework-level plugin circuit breaker with attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

The issue requests a framework-level plugin circuit breaker that can isolate failing plugin hooks, persist state, expose operator controls, and degrade affected plugins without taking down the gateway.

## Best Possible Solution

Keep this as a maintainer-owned design item and define a SQLite-backed breaker contract for plugin hooks/tools, including attribution, lifecycle state, degradation modes, status visibility, reset controls, and upgrade-safe defaults.
