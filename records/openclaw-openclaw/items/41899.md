## Summary

Keep open: current main has hook timeouts, runtime-health storage, session-lock watchdog metadata, gateway crash-loop suppression, and plugin-local breaker precedents, but it still lacks the requested framework-level plugin circuit breaker with plugin/hook attribution, persisted lifecycle state, operator reset controls, and per-plugin degradation policy.

## What This Changes

Requests a framework-level plugin circuit breaker that wraps plugin hook/tool execution, attributes lock overruns to plugins, persists breaker state, and supports open/half-open/forced-open recovery controls.

## Best Possible Solution

Define a SQLite-backed, SDK-compatible breaker contract for plugin hooks/tools with attribution, lifecycle state, degradation modes, status visibility, reset controls, and upgrade-safe defaults.
