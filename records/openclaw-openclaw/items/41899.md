## Summary

Keep open: current main has partial timeouts, plugin-local cooldowns, channel and gateway breakers, but not the requested framework-level plugin breaker with plugin/hook attribution, persisted lifecycle state, operator status/reset controls, and per-plugin degradation policy.

## What This Changes

Request a framework-level plugin circuit breaker that can isolate misbehaving plugin hooks/tools while the rest of the gateway continues operating.

## Best Possible Solution

Define a SQLite-backed plugin breaker contract for hooks/tools with attribution, passive telemetry rollout, operator status/reset surfaces, per-plugin degradation modes, and upgrade-safe defaults before active open/half-open enforcement.
