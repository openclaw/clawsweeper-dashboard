## Summary

Keep open: current main has hook timeouts, session-lock watchdogs, and an Active Memory-local timeout breaker, but it still lacks the requested shared plugin-scoped breaker lifecycle, durable breaker state, plugin/hook lock attribution, status/reset controls, and maintainer-approved degradation policy.

## What This Changes

Request a framework-level plugin circuit breaker that can quarantine misbehaving plugin hooks and degrade only the affected plugin while keeping the gateway responsive.

## Best Possible Solution

Define a generic plugin-runtime breaker contract around the existing hook/tool runner and status surfaces, store durable breaker state in canonical SQLite-backed state, add plugin/hook lock attribution, and require maintainer-approved fail-mode defaults before active quarantine ships.
