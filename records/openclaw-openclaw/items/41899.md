## Summary

Keep open: current main has partial fail-open hook timeouts, session-lock watchdogs, host cleanup bounds, and a plugin-local Active Memory breaker, but it still lacks the requested framework-level plugin circuit breaker with plugin/hook attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

The issue requests a framework-level plugin circuit breaker that times plugin hooks, attributes lock ownership, persists breaker state, skips only unhealthy plugin hooks, and exposes operator reset/status controls.

## Best Possible Solution

Design one canonical plugin-runtime breaker contract with passive telemetry first, SQLite-backed state if persistence is required, operator-visible status/reset controls, and tested default behavior that avoids surprising existing plugin authors.
