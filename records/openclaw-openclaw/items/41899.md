## Summary

Keep open: current main still has hook timeouts and plugin-local breakers, but not the shared plugin-scoped open/half-open/forced-open lifecycle, durable state, status/reset controls, and per-plugin degradation policy requested here.

## What This Changes

Request a framework-level plugin circuit breaker that can quarantine failing plugin hooks, persist breaker state, expose operator status/reset controls, and degrade only the affected plugin.

## Best Possible Solution

Define a generic plugin-runtime breaker contract around hook execution, persist durable breaker state in the canonical SQLite-backed state path, expose read-only status plus explicit reset controls, and ship active quarantine only after maintainer-approved fail-mode defaults and passive telemetry proof.
