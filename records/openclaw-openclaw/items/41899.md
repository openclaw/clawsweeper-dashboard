## Summary

Keep open: current main has hook timeouts, plugin-local memory degradation, channel transport cooldowns, and runtime health records, but not the requested framework-level plugin circuit breaker with plugin/hook lock attribution, persisted open/half-open/forced-open lifecycle, operator status/reset controls, and per-plugin degradation policy.

## What This Changes

Request a framework-level plugin circuit breaker that isolates failing plugin hooks/tools so one plugin cannot freeze sessions, grow queues, or churn the gateway.

## Best Possible Solution

Define a SQLite-backed plugin breaker contract for hooks/tools with attribution, passive telemetry rollout, operator status/reset surfaces, per-plugin degradation modes, and upgrade-safe defaults before active enforcement.
