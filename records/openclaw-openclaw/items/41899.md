## Summary

Keep open: current main has partial hook timeouts, plugin-local breakers, runtime health/quarantine status, and gateway/channel breakers, but not the requested framework-level plugin breaker with plugin/hook attribution, persisted lifecycle state, operator reset/status controls, and per-plugin degradation policy.

## What This Changes

The issue requests a framework-level plugin circuit breaker for graceful degradation when a misbehaving plugin holds locks, times out, or repeatedly errors.

## Best Possible Solution

Define a SQLite-backed plugin breaker contract for hooks/tools with attribution, passive telemetry rollout, operator status/reset surfaces, per-plugin degradation modes, and upgrade-safe defaults before active open/half-open enforcement.
