## Summary

Keep open: current main still has partial hook timeouts, session-lock watchdog metadata, runtime-health storage, gateway restart-loop suppression, and plugin-local breakers, but not the requested framework-level plugin-scoped circuit breaker with attribution, persisted lifecycle state, operator controls, and per-plugin degradation policy.

## What This Changes

This issue requests a framework-level plugin circuit breaker for graceful degradation when plugin hooks, tools, lock holds, or repeated failures threaten gateway reliability.

## Best Possible Solution

Define a SQLite-backed, plugin-runtime-owned breaker contract that covers hook/tool attribution, lifecycle state, status visibility, reset controls, degradation modes, metrics, and upgrade-safe defaults.
