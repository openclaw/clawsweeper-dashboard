## Summary

Keep open: current main has hook timeouts, runtime health storage, channel autostart suppression, and an Active Memory local breaker, but not the requested framework-level plugin circuit breaker with plugin/hook attribution, persisted lifecycle state, operator reset/status controls, and per-plugin degradation policy.

## What This Changes

Request a framework-level plugin circuit breaker that can degrade misbehaving plugin hooks/tools without freezing the gateway or sessions.

## Best Possible Solution

Keep this as a maintainer-owned design item and define a SQLite-backed generic breaker contract for plugin hooks/tools with attribution, lifecycle state, per-plugin degradation modes, status visibility, reset controls, and upgrade-safe defaults.
