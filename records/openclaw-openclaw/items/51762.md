## What This Changes

The PR makes new explicit sessions, delivery-channel hints, and default auth/model storage discovery use the configured default agent instead of assuming the agent is named `main`.

## System Context

Configured agent selection determines which agent owns a session store and default local state. Incoming requests and secret/model discovery resolve that owner, then use its session keys, storage directories, and delivery metadata for subsequent runtime behavior.
