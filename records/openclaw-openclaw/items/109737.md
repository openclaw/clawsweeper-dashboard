## What This Changes

The PR splits full-build tsdown declarations into three independently fingerprinted cache groups, restores their outputs across jobs, narrows group cleanup, and enables the cache in selected CI and release workflows.

## Best Possible Solution

Keep the independently fingerprinted declaration reuse, but merge it into release workflows only after a current-head run proves cold, exact-warm, and coarse-restore builds produce byte-identical declarations when unrelated and declaration-relevant inputs change.
