## Reproduction Assessment

Yes, at source level. Current main and `v2026.6.11` attach stdout/stderr data listeners but no stream-error listeners to the az-login child streams, and Node throws unhandled `error` events without a listener.

## Solution Assessment

Yes. The fix stays in plugin-owned `azLoginDeviceCodeWithOptions`, tears down once on the first stream error, waits for child close or a bounded fallback, and does not add config or API surface.
