## Summary

Keep this issue open: current main still reaches synchronous JSON serialization plus append/full-file writes through the active embedded-run SessionManager path, while existing mitigations and async helpers do not remove that hot-path persistence risk.

## What This Changes

The issue reports synchronous transcript persistence on the active session-manager path as a possible event-loop liveness blocker for large tool-result payloads.

## Best Possible Solution

Measure current-main large tool-result runs under diagnostic liveness sampling, then move active SessionManager transcript persistence off synchronous append/full-write work while preserving write locks, cache publication, redaction, and compaction repair semantics.
