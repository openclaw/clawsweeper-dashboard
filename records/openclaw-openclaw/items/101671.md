## Summary

Keep open: current main and the latest release still route active embedded-run transcript appends through synchronous `SessionManager` JSONL serialization/appends, while existing async transcript helpers and tool-result caps only mitigate adjacent paths.

## What This Changes

The issue asks to eliminate or offload synchronous transcript serialization and file I/O in the embedded-run `SessionManager` path so large tool results cannot stall diagnostic liveness sampling.

## Best Possible Solution

Measure current-main large tool-result runs under diagnostic heartbeat, then remove or offload synchronous active-run `SessionManager` persistence while preserving write locks, cache publication, redaction, repair, and tool-result caps.
