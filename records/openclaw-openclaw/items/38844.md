## Summary

Keep open: current main and the latest release still allow paths-only upload arming and still wrap the Browser agent upload hook with a fixed 20s client timeout. Current dispatcher error handling is better than the original report, but the atomic upload contract and live dynamic-page proof remain unresolved.

## What This Changes

The issue asks for browser file-chooser uploads to avoid stale ref split flows and to keep stale-action failures from being reported as browser control outages.

## Best Possible Solution

Make the Browser upload contract explicit, then align agent guidance, client timeout/error handling, tests, and live dynamic-page proof around that chosen contract.
