## Summary

Keep open: current main and v2026.6.11 still allocate a fresh UUID-backed native subagent session for every spawn, while resume support remains ACP-only and Teams lacks the binding path needed for reusable expert sessions. The gap is real, but the durable fix needs maintainer product/API direction.

## What This Changes

Request native `sessions_spawn(mode="run")` or Teams-compatible subagent spawns to reuse an existing expert session instead of always starting a fresh child session.

## Best Possible Solution

Define an explicit native subagent reuse contract covering isolation scope, requester/target matching, TTL/liveness, locking, cleanup, and Teams/thread-binding behavior before implementation.
