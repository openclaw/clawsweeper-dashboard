## What This Changes

The PR breaks OpenClaw’s large Windows Task Scheduler daemon implementation into private layout, process, runtime, install, and lifecycle modules while retaining `src/daemon/schtasks.ts` as the existing public entry point.

## System Context

OpenClaw’s daemon layer installs and controls the Gateway on Windows using either a scheduled task or a per-user Startup-folder fallback. CLI lifecycle requests feed into this layer, which renders launch scripts, observes gateway processes, and starts, stops, restarts, or uninstalls the selected Windows launcher.
