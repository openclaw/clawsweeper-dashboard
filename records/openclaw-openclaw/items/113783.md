## What This Changes

This PR divides the Windows Task Scheduler Gateway daemon backend into private layout, process, runtime, installation, and lifecycle-control modules while retaining `src/daemon/schtasks.ts` as the existing entry point.

## System Context

OpenClaw’s Windows daemon backend installs, starts, stops, and inspects the Gateway using Windows Task Scheduler, with a per-user Startup-folder launcher as its fallback. Gateway lifecycle requests enter through the scheduler facade, then use launcher rendering, task inspection, and process ownership helpers to report or change service state.
