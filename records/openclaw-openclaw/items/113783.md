## What This Changes

This PR divides OpenClaw’s Windows Task Scheduler daemon backend into private layout, process, runtime, installation, and lifecycle-control modules while preserving `src/daemon/schtasks.ts` as the public facade.

## System Context

OpenClaw’s daemon service layer installs and controls the Gateway on Windows through Task Scheduler, with a per-user Startup-folder fallback when Task Scheduler is unavailable. Service commands flow through the stable scheduler facade into command rendering, process ownership, runtime inspection, installation, and start/stop/restart control paths.
