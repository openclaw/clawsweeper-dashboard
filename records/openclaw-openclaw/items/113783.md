## What This Changes

This PR replaces the large Windows Task Scheduler daemon implementation with private layout, process, runtime, install, and control modules while keeping `src/daemon/schtasks.ts` as the public facade.

## System Context

OpenClaw’s daemon layer installs and controls the local Gateway service. On Windows, the scheduler integration renders launchers, registers or queries Task Scheduler, manages the Startup-folder fallback, and observes or terminates the Gateway process before reporting lifecycle results to the CLI.
