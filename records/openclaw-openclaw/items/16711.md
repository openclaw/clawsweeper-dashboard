## Summary

Keep open: current main has the configurable send shortcut, but it still lacks the requested Control UI Expand button, large composer modal, Apply/Cancel/Send workflow, and modal-owned keyboard semantics.

## What This Changes

The issue requests an Expand button next to the Control UI chat composer that opens a large modal editor with Apply, Cancel/Close, Send, and modal-specific Enter/Ctrl-or-Cmd+Enter behavior.

## Best Possible Solution

Choose the Control UI long-prompt composer pattern first; if the modal is approved, implement it in the chat composer with separate modal draft state and focused UI tests for Apply, Cancel/Close, Send, focus restoration, attachments, and keyboard behavior.
