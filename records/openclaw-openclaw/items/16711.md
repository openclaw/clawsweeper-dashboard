## Summary

## Best Possible Solution

Keep this open until maintainers choose the long-prompt composer UX; if approved, implement the modal in the current chat composer using the existing dialog primitive with focused tests for draft ownership, Apply/Cancel/Send, focus, attachments, keyboard behavior, and unchanged inline behavior.
