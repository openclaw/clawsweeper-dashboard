## Summary

Keep open: current main still lacks the requested Control UI Expand button, large composer modal, Apply/Cancel/Send workflow, and modal-owned draft behavior. The merged composer redesign and send-shortcut work are useful adjacent improvements, but they do not replace this feature request.

## What This Changes

Request an Expand control for the Control UI chat composer that opens a larger modal editor for long prompts with Apply, Cancel/Close, and Send actions.

## Best Possible Solution

Keep this as a first-class Control UI ergonomics request: add an Expand icon near the composer actions, open a large editor modal with isolated draft state, and cover Apply, Cancel/Close, Send, focus, attachments, queued sends, and modal keyboard behavior in focused UI tests.
