## What This Changes

The issue requests an Expand button beside the chat composer that opens a larger modal editor with Apply, Cancel/Close, Send, Enter-for-newline, and Ctrl/Cmd+Enter-to-send behavior.

## Best Possible Solution

Keep this open until maintainers choose the long-prompt composer UX; if approved, implement the modal in the chat composer with focused coverage for draft ownership, Apply/Cancel/Send, focus restoration, attachments, keyboard behavior, and unchanged inline behavior.
