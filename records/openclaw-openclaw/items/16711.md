Keep open: current main has the redesigned inline Control UI composer and configurable send shortcut, but it still lacks the requested Expand button, large composer modal, Apply/Cancel/Send workflow, and modal-specific draft behavior.

## What This Changes

Request an Expand control in the Control UI chat composer that opens a larger long-prompt editor modal with Apply, Cancel/Close, Send, Enter-for-newline, and Ctrl/Cmd+Enter-to-send behavior.

## Best Possible Solution

Choose the Control UI long-prompt composition pattern first; if the modal direction is approved, implement it in the chat composer with focused UI tests for draft state, Apply, Cancel/Close, Send, focus restoration, attachments, slash commands, IME, and keyboard behavior.
