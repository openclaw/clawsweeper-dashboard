## Summary

Keep open: current main and v2026.6.11 still have an inline-only Control UI composer with no Expand button, large editor modal, Apply/Cancel/Send draft workflow, or modal-specific Enter-newline plus Ctrl/Cmd+Enter-send behavior. The related send-hotkey, TUI editor, and iOS auto-grow items only partially overlap, so this remains a product-gated web frontend ergonomics feature rather than conservative cleanup.

## What This Changes

Requests a Control UI chat composer Expand button that opens a larger draft editor modal for long prompts with Apply, Cancel/Close, and Send actions.

## Best Possible Solution
