Keep open: current main has an inline bounded composer and configurable send shortcut, but still lacks the requested Expand button, large editor modal, Apply/Cancel/Send workflow, and modal-specific keyboard behavior. ## What This Changes

The issue requests a Control UI chat-composer Expand button that opens a large modal editor with Apply, Cancel/Close, Send, Enter-for-newline, and Ctrl/Cmd+Enter-to-send behavior.

## Best Possible Solution

If maintainers accept the UX direction, implement the modal inside the Control UI composer using existing UI modal patterns, separate draft state, Apply/Cancel/Send semantics, focus restoration, attachment handling, i18n strings, and focused UI tests; otherwise explicitly document the inline bounded composer plus send-shortcut setting as the intended long-prompt path.
