The issue requests a Control UI chat composer Expand button that opens a larger modal editor for long prompts with Apply, Cancel/Close, and Send actions.

## Best Possible Solution

Choose the Control UI long-prompt composition pattern first; if the modal direction is approved, implement it in the chat composer with focused UI tests for draft state, Apply, Cancel/Close, Send, focus restoration, attachments, slash commands, IME, and keyboard behavior.
