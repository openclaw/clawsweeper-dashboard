## What This Changes

## Best Possible Solution

Choose the Control UI long-prompt composition pattern first; if the modal direction is approved, implement it in the chat composer with separate modal draft state and focused UI tests for Apply, Cancel/Close, Send, focus, attachments, and keyboard behavior.
