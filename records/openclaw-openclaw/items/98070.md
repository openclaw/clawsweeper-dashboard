## Summary

Keep open: current main has Skill Workshop as a proposal primitive, plugin tools, tool allowlists, and per-tool-call policy hooks, but it still lacks a first-class pre-selection skill-creation authority/routing seam that can make a custom workflow run before the model chooses `skill_workshop`.

## What This Changes

Request to make Skill Workshop composable with custom skill-creation workflows so external tools can gather context, validate, and then call the proposal primitive.

## Best Possible Solution

Define one narrow skill-creation authority model that lets custom workflows prepare proposal content while Skill Workshop remains the only persistence/apply boundary.

- **Defer to ClawHub conventions:** Treat custom skill creation workflows as external plugin or skill-bundle patterns unless a stronger missing-core-API case appears.
