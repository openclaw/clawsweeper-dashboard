## What This Changes

This PR makes an embedded/app-server `message` send with an explicit route count as a delivered reply only when that route resolves to the active source conversation.

## System Context

Embedded agent harnesses report tool starts and completions through the agent subscription handler. The handler records source-reply delivery evidence for successful message sends; that evidence prevents stranded-reply recovery from posting an erroneous fallback after a real reply was already delivered.
