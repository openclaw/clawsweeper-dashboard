## Summary

Keep open pending a caller-level reproduction. The cited helper removes registry entries, but existing process-tool design separates record clearing from termination, so the helper body alone does not prove an orphan leak; the related production orphan report concerns embedded `node server.js` workers and has not been tied to this registry path.

## What This Changes

## Best Possible Solution

Add a focused regression that starts a real background command and exercises the supported remove, clear, timeout, or shutdown path; if the child survives, fix cancellation at the supervisor or process-tool lifecycle owner and keep registry deletion side-effect-free unless its contract is deliberately changed.
