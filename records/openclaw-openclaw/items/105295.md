This PR addresses a real authorization-scoped catalog leak, but it is not merge-ready because the new per-token keys turn a previously region-bounded process cache into an unbounded store of historical credential catalogs; the contributor’s evidence is also mock-only.

The PR changes Amazon Bedrock Mantle model discovery caching from a region-only key to normalized region plus a SHA-256 bearer-token fingerprint and adds a cross-token regression test.

## Best Possible Solution

Retain credential-scoped discovery identity, but prune expired entries or enforce a small deterministic bound before inserting new token fingerprints, add rotation/cleanup coverage, and require redacted live Mantle output or logs before merge.
