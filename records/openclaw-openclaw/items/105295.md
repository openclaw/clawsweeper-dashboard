## What This Changes

The PR keys Amazon Bedrock Mantle discovery-cache entries by region and bearer-token fingerprint, purges expired entries, caps retention at 64 entries, and adds regression coverage.

## Best Possible Solution

Use one private, credential-scoped, expiry-aware bounded cache that preserves same-credential hits while preventing catalog reuse across identities, with redacted live Mantle validation confirming the complete behavior.
