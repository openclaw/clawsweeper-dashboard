## What This Changes

The PR keys Amazon Bedrock Mantle model-discovery cache entries by normalized region and bearer-token fingerprint, adds expiry-aware 64-entry eviction, and expands cache-isolation regression tests.

## Best Possible Solution

Keep the plugin-local hashed credential-scoped bounded cache, then require redacted live Mantle output or logs showing that two credential identities in one region trigger separate discovery requests and return their own catalogs before merge.
