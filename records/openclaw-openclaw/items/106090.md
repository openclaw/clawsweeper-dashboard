## Summary

Keep this PR open for repair. Moving scope detection off the shared API quota is well-motivated and the exact-head runs prove the happy path, but the current head executes a local action from the pull-request checkout before deciding whether Periphery scans run; that unresolved trust-boundary defect can let changes to the helper suppress all three scans.

## What This Changes

The PR replaces pull-request files API queries with credential-free checkout, bounded base fetching, and local git-diff scope detection in three Periphery workflows, with corresponding test updates.

## Best Possible Solution

Keep local git-diff scope detection, but place the bounded base-fetch logic directly in each scope workflow—or load it from an immutable trusted source—so changing the helper cannot suppress scans; add an adversarial test proving helper changes cannot bypass scope.
