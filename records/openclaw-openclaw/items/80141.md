## Summary

Keep this PR open for human security-boundary review, but do not merge it as written: the allowed-decision parsing is already present on current main, while the new summary path lets an operator approve a command whose tail is no longer inspectable.

## What This Changes

The branch truncates long exec approval commands across Control UI, fallback, reply, and native approval presentations, and adds UI filtering for gateway-provided approval decisions.

## Best Possible Solution

Keep the full sanitized command available before every approval action, using bounded layout plus an explicit expand, scroll, or copy control; then rebase the narrow Control UI decision rendering change onto current main.
