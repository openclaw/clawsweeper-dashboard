## What This Changes

The PR caps inbound QQBot gateway WebSocket messages at 16 MiB and extends constructor-option coverage for direct and proxied gateway connections.

## System Context

QQBot’s channel plugin opens a long-lived WebSocket to receive gateway events, then passes accepted frames into its gateway connection and message-processing flow. This factory-level option bounds what the underlying WebSocket client buffers before the QQBot event parser and delivery logic run.
