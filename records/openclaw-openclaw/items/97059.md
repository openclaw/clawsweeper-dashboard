## Summary

Keep this PR open: restoring endpoint-aware Ollama cache identity is necessary, but the current shared sanitizer can collapse distinct credential-named tenant or backend identities, and the submitted harness does not prove the actual memory-index rebuild path.

## What This Changes

The PR adds Ollama base URL and sanitized headers to embedding cache identity, changes shared embedding-header sanitization, and adds regression tests.

## Best Possible Solution

Restore Ollama endpoint-aware identity with a structured distinction between credential headers and identity-bearing headers, then prove an actual persisted index rebuild after repointing one provider ID to another endpoint.
