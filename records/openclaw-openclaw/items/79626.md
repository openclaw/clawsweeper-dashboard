## Best Possible Solution

Resolve local image MIME in the media-understanding input/cache owner path after local-root and max-byte checks, while preserving remote URL handling and explicit-model fallback semantics.

No. MIME propagation is the right fix, but this implementation puts full-file MIME sniffing in the CLI before the guarded media path; the maintainable fix belongs in media-understanding input preparation/cache ownership.
