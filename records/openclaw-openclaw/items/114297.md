## What This Changes

The branch reserves explicitly configured browser ports before assigning implicit extension relay ports, bounds allocation to the relay band, and makes the extension-pair command use the resolved relay port.

## System Context

Browser configuration resolves explicit and implicit extension profiles into relay listener ports. The extension pairing CLI then exposes the selected relay endpoint so a browser extension connects to the correct local listener.
