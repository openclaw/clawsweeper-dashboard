## What This Changes

The PR gives ClickClack JSON REST requests a 30-second completion deadline, including response-body reads, while retaining caller cancellation and exempting multipart uploads.

## System Context

ClickClack’s owner-local HTTP client serves gateway startup, inbound lookup, outbound delivery, and activity operations. It turns API responses into bounded JSON or HTTP errors for the surrounding ClickClack channel flows.
