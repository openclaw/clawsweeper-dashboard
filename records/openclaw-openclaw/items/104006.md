## Summary

The patch is technically clean and well-proven, but it deliberately changes ClickClack compatibility by failing JSON REST operations after 30 seconds while leaving multipart uploads unbounded; a ClickClack owner should confirm that policy before merge.

## What This Changes

The PR adds a private 30-second completion deadline to ClickClack JSON REST requests and response-body reads, preserves caller abort signals, and exempts FormData uploads.

## Best Possible Solution

Adopt an owner-confirmed ClickClack completion policy that bounds JSON calls and explicitly decides a safe longer deadline or documented exception for multipart uploads without adding global config surface.
