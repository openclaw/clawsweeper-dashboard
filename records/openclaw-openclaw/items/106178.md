## Summary

Keep open: the guarded-fetch deadline is the correct mechanism and the runtime proof is strong, but the stated verification guarantee remains incomplete because project-number verification still has a separate unbounded certificate fetch.

## What This Changes

Adds a 30-second timeout to Google Chat’s google-auth guarded fetch and updates focused tests to assert timeout forwarding.

## Best Possible Solution

Use one shared plugin-owned 30-second auth-network deadline for both the google-auth transporter and the direct project-number certificate fetch, with stalled and normal-response coverage for each path.
