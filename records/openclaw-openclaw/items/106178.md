## What This Changes

The PR adds a 30-second timeout to Google Chat’s google-auth guarded-fetch adapter and updates focused tests to verify timeout forwarding.

## Best Possible Solution

Keep all Google Chat-owned outbound and auth transport requests on one explicit bounded-network contract, with the 30-second deadline enforced by the existing SSRF-guarded fetch and regression coverage for both stalled and normal responses.
