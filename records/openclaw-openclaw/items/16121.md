Request first-class Telegram custom emoji support for messages, captions, and replies, including Telegram custom emoji identifiers and entity-based sending.

## Best Possible Solution

Choose one canonical product/API representation, then implement validated Telegram custom emoji entity support through the shared message tool and Telegram send/edit/caption/reply paths while keeping current raw HTML and fallback behavior intact.

## Reproduction Assessment

Yes. Source inspection of current main and v2026.6.11 shows `entities` and `caption_entities` are still absent from the shared message tool and Telegram send/edit/caption surfaces, while reporter comments describe production entity arrays being dropped through message-tool sends.

## Solution Assessment

Unclear until maintainers choose the public API shape. Raw `<tg-emoji>` preservation and `richMessages` help some cases, but they are not the full shared message/caption/reply entity solution requested.
