## What This Changes

The PR wraps ElevenLabs buffered TTS, streamed TTS, and voice-listing requests in the plugin SDK’s trusted environment-proxy guarded-fetch preset and adds regression tests for those three call sites.

## System Context

The ElevenLabs plugin turns configured speech-provider requests into API calls for voice discovery and synthesized audio. Those calls pass through OpenClaw’s SSRF guard, which selects either direct pinned-DNS egress or an eligible operator-configured environment proxy before returning voice metadata or audio.
