## Summary

Keep this PR open, but do not merge it as written: the stat-then-read helper still permits an unbounded read after the size check, and rejecting valid oversized legacy state leaves the documented Doctor migration without a recovery path. The contributor’s passing test transcript is useful supplemental evidence, but it is not real after-fix migration proof.

## What This Changes

The branch adds 10 MiB or 50 MiB pre-read size caps to the four legacy Reef Doctor-migration readers for audit, replay, reviews, and delivered state files.

## Best Possible Solution

Use one opened file handle and a truly bounded read or streaming parser, then define and test a Doctor-owned migration path that preserves valid oversized legacy history rather than stranding it behind an arbitrary cap.
