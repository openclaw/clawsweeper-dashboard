## Summary

Keep this PR open: bounding the read is valuable, but valid oversized legacy Reef state currently makes doctor abort without a supported migration or recovery path, and the submitted test transcript is not after-fix doctor behavior proof.

## What This Changes

The branch replaces four unbounded legacy Reef doctor-migration file reads with synchronous descriptor reads capped at 50 MiB for audit/replay logs and 10 MiB for reviews/delivered state.

## Best Possible Solution

Retain the bounded-read protection while defining and proving a supported doctor path for valid oversized legacy Reef state—prefer streamed migration, or an explicitly approved recovery/export flow that preserves user data.
