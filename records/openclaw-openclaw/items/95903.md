## Summary

Keep open, but do not merge the stale branch as-is. Its `chunkText` fallback guarantees length but can split an open fenced Markdown block without closing and reopening it, whereas current main’s shared Markdown chunker explicitly preserves fence structure while bounding chunks; the contributor should rebase or demonstrate a remaining current-main failure before this PR is considered.

## What This Changes

The PR changes Telegram rich-message chunking so an oversize Markdown chunk is hard-split when Markdown-aware splitting cannot reduce it, with regression tests for long code blocks and structured Markdown.

## System Context

Telegram rich messages pass formatted Markdown through a shared chunker before the channel sends each part to the Bot API. The chunker must keep every outbound message within Telegram’s limit without producing malformed Markdown that changes rendering or delivery.
