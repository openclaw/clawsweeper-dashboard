## What This Changes

This PR removes six bundled plugins’ duplicated live-config and activation lookups in favor of the entry-scoped `api.pluginConfig`, while preserving direct runtime snapshots for Codex and Active Memory handlers that reread their own config immediately after writing it.

## System Context

Gateway configuration changes are classified into reload actions, after which the plugin registry registers each active plugin with its validated entry configuration. Plugin tools and commands then read that registration-scoped config, except handlers that mutate and reread configuration before their reload completes.
