## What This Changes

This PR changes six bundled plugins to consume their entry-scoped configuration from `api.pluginConfig`, preserves the deprecated public loader helper for external plugin compatibility, and documents when in-handler writes must use the runtime configuration snapshot instead.

## System Context

Gateway configuration changes rebuild the plugin registry and call each plugin’s registration entrypoint with validated, default-hydrated entry configuration. Plugin tools then use that entry configuration, except handlers that write and reread their own configuration before reload completes, which must use the runtime snapshot.
