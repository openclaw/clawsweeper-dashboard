## Summary

Keep this PR open: bounding the installer fetch is useful, but retrying executable output directly into Bash can concatenate bytes from a failed partial attempt, and the contributor evidence only proves the static workflow guard rather than the real timeout path.

## What This Changes

The PR adds curl connection, transfer, and retry deadlines to both OpenGrep installer steps and adds a workflow guard covering those options.

## Best Possible Solution

Fetch the pinned installer into a temporary file with the bounded curl options, execute it only after curl succeeds, clean it up reliably, and prove stalled and truncated-transfer behavior with a redacted terminal or workflow transcript.
