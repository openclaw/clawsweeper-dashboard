## Summary

The previous P1/P2 blockers are fixed on the current head: both workflows download the pinned installer completely before execution and bound the whole installer subprocess, while the new loopback proof demonstrates both timeout paths. The patch is technically sound, but the protected security label and new hard failure budget require explicit owner review before merge.

## What This Changes

The PR adds bounded retries to the pinned OpenGrep installer-script download, runs the downloaded installer under a five-minute process timeout in both precise-scan workflows, and updates the workflow guard test.

## Best Possible Solution

Keep the completed-download and whole-installer timeout design, then merge only after the OpenGrep workflow owner confirms the retry and five-minute failure budgets are appropriate for Blacksmith Ubuntu runners.
