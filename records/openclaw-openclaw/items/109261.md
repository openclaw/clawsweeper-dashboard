## Summary

The outer script download is bounded, but the pinned installer immediately performs four additional unbounded curl fetches, so the same Install opengrep step can still stall until the workflow’s 30-minute job timeout. The PR should remain open for a full-subprocess deadline and real timeout-path proof.

## What This Changes

Adds curl connection, transfer, and retry limits to the OpenGrep install-script download in both precise-scan workflows and adds a text-based workflow guard.

## Best Possible Solution

Bound the entire Install opengrep subprocess while retaining the pinned installer SHA and version, then demonstrate that a controlled stall retries and exits within the documented deadline in both workflows.
