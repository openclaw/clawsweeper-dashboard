## What This Changes

This PR makes the bounded accumulator used for session bash stdout and stderr create per-stream Windows console decoders by default, with GBK decoding coverage.

## System Context

Session bash commands emit stdout and stderr byte streams that are decoded independently before bounded output is returned as a tool result and recorded in the agent transcript. On Windows, that decoding must preserve the host console code page while retaining independent pending-byte state for each pipe.
