## What This Changes

The PR treats blank `AWS_REGION` and `AWS_DEFAULT_REGION` values as absent so Amazon Bedrock and Bedrock Mantle fall back to a nonblank secondary region or `us-east-1`.

## Best Possible Solution

Keep one shared semantic rule—blank region environment values mean absent—across the affected Bedrock runtime paths, then land the current proof-backed patch after ordinary maintainer review.
