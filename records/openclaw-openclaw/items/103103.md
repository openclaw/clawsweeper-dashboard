## Reproduction Assessment

Yes, at source level. Current `main` sends default `models list` through `appendConfiguredModelRowSources`, which calls `appendAuthenticatedCatalogRows` without checking `models.mode`, so authenticated unconfigured catalog rows can leak into replace-mode default output.

## Solution Assessment

Mostly yes. The helper-level guard fixes the leaking row source while leaving explicit all/provider browse paths on the source-plan cascade, but the PR should remove the changelog edit and add exact-head proof before merge.
