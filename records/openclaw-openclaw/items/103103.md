Full review comments:

- **[P2] Normalize configured model ids before de-duping:** `src/commands/models/list.rows.ts:380`
  - body: In replace mode this path now emits configured provider models that can rely on transport/model normalization, but the row key is built from the raw `configuredModel.id` before `normalizeWithProviderPlugin` runs. If a configured model ID normalizes elsewhere, `seenKeys` will miss the canonical default/allowlist row and the default list can show duplicate or unselectable stale keys; normalize the model ID before computing `key` and the row model.
  - confidence: 0.87
- **[P2] Filter stale defaults before replace-mode rows:** `src/commands/models/list.rows.ts:406`
  - body: This guard only stops authenticated catalog rows after `appendConfiguredRows` has already emitted the resolved default. With `models.mode: "replace"` and no primary, or a primary for a provider absent from `models.providers`, the default list can still show that stale default alongside configured providers, contrary to the replace-mode docs; filter configured entries against the configured provider models before appending them in replace mode.
  - confidence: 0.9
