## What This Changes

The PR rejects explicitly supplied `--channel` and `--to` options for main-session system-event cron jobs and adds focused regression coverage for delivery-option validation.

## Best Possible Solution

Land one fail-fast validation rule for all explicit unsupported chat-delivery options on main-session jobs, preserve webhook and isolated-job behavior, and merge only after the compatibility choice is accepted and exact-head checks are green.
