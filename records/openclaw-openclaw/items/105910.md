## Summary

## What This Changes

The PR makes `cron add` reject explicitly supplied chat-delivery options for main-session system-event jobs and adds focused validation tests.

## Best Possible Solution

Use one shared add/edit validation rule that rejects explicit chat-delivery targets whenever the resulting job is a main-session system event, while preserving implicit `channel=last`, webhook delivery, and isolated agent-turn or command delivery.
