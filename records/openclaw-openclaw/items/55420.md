## Summary

Keep open. Current main still only accepts the existing session visibility modes and has no session-key allowlist branch; related open items cover broader per-capability, per-agent, sandbox, or A2A policy axes rather than safely replacing this requested pattern allowlist.

## What This Changes

Add a `tools.sessions.visibility="allowlist"` mode plus `tools.sessions.allowlist` session-key glob patterns so only explicitly trusted sessions are readable.

## Best Possible Solution

Choose one canonical session visibility design across this issue and the broader per-capability/per-agent work, then update the schema, guard, docs, and focused tests in that single model.

## Reproduction Assessment

Not applicable as a bug reproduction because this is a feature request. Source inspection confirms the current schema and runtime only support `self`, `tree`, `agent`, and `all`, so the requested mode is still absent.

## Solution Assessment

Unclear whether the exact proposed `allowlist` mode is the best final shape. It should be decided alongside the open per-capability and per-agent session visibility proposals so OpenClaw does not grow overlapping authorization knobs.
