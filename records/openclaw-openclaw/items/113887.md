## Summary

Keep this draft open for explicit maintainer review. The branch has a focused safeguard against destructive cleanup after an unverifiable Gateway-service removal, but its claimed validation is fake-service and CI coverage rather than inspectable after-fix behavior from a real service-managed setup; the new immediate post-uninstall check also needs confirmation against supported service-manager semantics.

## What This Changes

This draft makes the uninstall command abort before deleting configuration, state, or workspaces when Gateway service inspection or removal cannot be verified.

## System Context

OpenClaw's top-level uninstall command first removes a running Gateway service, then deletes selected user-owned artifacts. The added service-state verification sits between those phases and determines whether destructive cleanup is allowed to continue.
