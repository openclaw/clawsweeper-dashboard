The reported tests and CI are useful supplemental evidence, but no after-fix native behavior proof is available.

The PR moves the macOS browser-cookie import offer from launch and Gateway-connect events to the first inline-browser use, with eligibility retries, one-shot state handling, regression tests, documentation, and localization inventory updates.

## Best Possible Solution

Make a discarded or generation-stale status response return a non-consuming result, latch the one-shot only after a response is actually applied, add a transition-during-request regression test, and provide redacted native runtime evidence of both silent launch and the first eligible offer.
