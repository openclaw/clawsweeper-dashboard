## Summary

This PR remains necessary because current main still triggers the macOS cookie-import offer during launch and Gateway connection, but the proposed one-shot sidebar trigger is consumed before import eligibility is known. The previous blocker therefore remains: opening the sidebar while remote or not yet onboarded prevents the automatic offer after the reused dashboard later becomes eligible. The branch also still needs after-fix signed-app behavior proof.

## What This Changes

The branch defers the macOS cookie-import offer until the inline browser first opens, adds smoke coverage and docs, refreshes generated native localization outputs, and removes an unused Microsoft Teams helper.

## Best Possible Solution

Keep the offer pending until an eligibility-aware refresh succeeds or reset the trigger when dashboard eligibility changes, add a regression covering ineligible-first-open then local-mode reuse, and attach redacted signed-app proof showing no dashboard/auth banner followed by one eligible first-sidebar offer.
