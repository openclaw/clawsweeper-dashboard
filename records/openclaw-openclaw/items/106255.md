## Summary

Keep this PR open: it removes the premature launch/connect offer, but the current head still does not request the pending offer when an already-open sidebar becomes eligible after onboarding or a Remote-to-Local mode change.

## What This Changes

The PR defers the macOS browser-cookie import offer from app launch and Gateway connection until an eligible inline-browser sidebar open.

## Best Possible Solution

Represent the offer as pending until the sidebar is open and onboarding plus Local mode are all true, retry when either eligibility condition changes, consume it only after that conjunction succeeds, and cover the already-open transition with a regression test.

## Solution Assessment
