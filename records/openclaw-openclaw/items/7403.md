## Summary

Keep open: current main and the latest release still do not provide an enforceable Private/Secret/Incognito session contract, and this remains a privacy-sensitive product/security design item rather than conservative cleanup.

## What This Changes

The issue requests a Mission Control Private Mode that suppresses workspace/persona/memory context, avoids workspace reads and writes, and uses temporary non-persistent session memory.

## Best Possible Solution

Keep this as the canonical tracker and design one additive private/ephemeral session contract across Gateway protocol, SessionEntry/session store/transcripts, bootstrap/memory/compaction/plugins, channel triggers, and Control UI, with tests proving private sessions neither read private context nor write durable history.
