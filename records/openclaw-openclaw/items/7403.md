## Summary

Current main still lacks a selectable and enforceable private-session contract, while live GitHub history confirms this issue remains the canonical tracker for the broader no-context/no-persistence requirement.

## What This Changes

Add an enforceable per-session private mode that suppresses workspace context and durable persistence, with Control UI activation and status.

## Best Possible Solution

Define one additive private-session policy with explicit allowed metadata, then carry and enforce it across session creation, bootstrap reads, transcripts, memory and compaction, tools and media, plugin indexing, channels, and Control UI.

Options:

- **Enforceable per-session mode (recommended):** Promise no private workspace context and no durable conversation content, with explicit narrow metadata exceptions and accepted loss on restart.
- **Demo-only context suppression:** Suppress persona and memory bootstrap files for presentations while explicitly making no no-persistence security promise.
- **Defer the feature:** Retain current retention and deletion controls until complete cross-surface enforcement is supportable.

## Reproduction Assessment

Yes at source level: current protocol and durable session state lack a private/no-persist discriminator, so the requested mode cannot be selected or enforced end to end. This read-only review did not execute a runtime session.

## Solution Assessment

Yes for the cross-surface contract, but not for the UI-toggle-only framing: Mission Control should activate and display the mode, while the actual guarantee must be enforced centrally across every durable effect.
