## Summary

Keep this issue open as the canonical tracker: current main still lacks an enforceable per-session contract that prevents private workspace reads and durable transcript, memory, and related state writes. This remains a security-sensitive product and architecture decision rather than a narrow repair.

## What This Changes

Add a per-session Private Mode that suppresses workspace context and prevents durable transcript, memory, and related state persistence.

## Best Possible Solution

Define one additive private-session contract enforced across Gateway protocol, session storage, transcripts, bootstrap and memory, tools and media, plugins, channels, and Control UI, with explicit retained-metadata rules and end-to-end no-read/no-write proof.
