## Summary

Keep open: current main still lacks an enforceable Private/Secret/Incognito session contract; existing context-injection controls do not stop durable session metadata, transcript creation, memory indexing, or UI/channel exposure.

## What This Changes

The issue requests a Private Mode for demos/content creation that suppresses workspace context and avoids durable transcript, memory, or session persistence for selected conversations.

## Best Possible Solution

Define one additive core private-session contract and enforce it through Gateway protocol, session storage, transcript creation, memory/compaction indexing, plugin/channel artifacts, and dashboard UI before presenting it as a privacy feature.
