## What This Changes

Request a Mission Control private mode that isolates a session from workspace context and prevents durable transcript, memory, and workspace persistence.

## Best Possible Solution

Approve an additive, explicitly documented private-session contract that covers Gateway/session state, transcript and history storage, bootstrap and memory reads, compaction/indexing, tool/media persistence, channel activation, and Control UI indication, then prove both normal and private-session behavior end to end.
