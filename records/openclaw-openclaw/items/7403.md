## Summary

Keep this issue open as the canonical tracker: current main offers limited bootstrap-context suppression but still lacks an enforceable per-session contract preventing workspace reads and durable transcript, memory, and related state writes. The requested guarantee remains a security-sensitive product decision rather than a narrow autonomous fix.

## What This Changes

Add a per-session private mode that suppresses personal workspace context, prevents durable conversation and memory persistence, and displays its state in the Control UI.

## Best Possible Solution

Define one additive Gateway-owned private-session contract with explicit threat-model exclusions, then enforce it across bootstrap reads, workspace and memory writes, transcripts, session metadata, plugins, tools, media, channels, and Control UI with end-to-end no-trace tests.
