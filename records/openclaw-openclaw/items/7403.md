## Summary

Keep open: current main still lacks an enforceable Private/Secret/Incognito session contract; existing context-injection controls do not stop durable session metadata, JSONL transcript creation, memory indexing, or UI/channel exposure.

## What This Changes

The issue requests a Private Mode toggle that suppresses workspace context and prevents durable session, transcript, and memory persistence for demos and privacy-sensitive use.

## Best Possible Solution

Keep this as the canonical tracker and design one additive private/ephemeral session contract across Gateway protocol, SessionEntry/session store/transcripts, bootstrap/memory/compaction/plugins, channel triggers, and Control UI, with regression tests proving private sessions neither read private context nor write durable history.
