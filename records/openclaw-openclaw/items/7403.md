## Summary

Keep open: current main and the latest release still lack an enforceable Private/Secret/Incognito session contract. Existing context-injection controls can suppress bootstrap prompt files, but session creation still writes durable transcript and session metadata, so the requested no-read/no-write/no-history privacy guarantee remains unimplemented.

## What This Changes

Request to add a Mission Control Private Mode that suppresses workspace and memory context, avoids durable session/history writes, uses temporary scratch memory, and shows a UI indicator.

## Best Possible Solution

Define one additive private-session contract across Gateway protocol, session storage/transcripts, memory/compaction, plugin/channel hooks, and Control UI before presenting this as a privacy guarantee.
