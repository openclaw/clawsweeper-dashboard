## Summary

Keep open. Current main still lacks an enforceable per-session Private/Secret/Incognito mode: the protocol, config schema, session entry, transcript creation, bootstrap context resolver, and Control UI session calls do not carry a private/no-persist contract, while related duplicate issues and the closed partial PR all point back to this issue as the canonical tracker.

## What This Changes

Request a Mission Control Private Mode that suppresses workspace/persona/memory context, prevents session/history persistence, and shows a private-mode UI indicator.

## Best Possible Solution

Keep this as the canonical Private/Secret/Incognito tracker and design one additive private-session contract spanning Gateway protocol, SessionEntry/store/transcripts, bootstrap and memory/compaction/plugin enforcement, channel triggers, and Control UI state with tests proving private sessions neither read private context nor write durable history.

- **Design full private-session contract (recommended):** Define and then implement an additive private/ephemeral session bit that every transcript, memory, compaction, plugin, channel, tool/artifact, and UI path must honor before promising privacy.

- **Defer core private mode:** Keep existing contextInjection and session cleanup as the supported mitigations, leaving this issue open or closing only after maintainers decide the broader privacy promise is out of scope.
