## Summary

Keep open: current main still lacks an enforceable Private/Secret/Incognito session contract, and the related comments confirm the remaining user need is a program-level no-read/no-write/no-history privacy guarantee rather than a UI-only context toggle.

## What This Changes

The issue requests a Private Mode that suppresses workspace/persona/history context and prevents durable reads or writes for private demo/content sessions.

## Best Possible Solution

Keep this as the canonical design tracker for one additive private/ephemeral session contract across Gateway protocol, SessionEntry/session store/transcripts, bootstrap/memory/compaction/plugins, channel triggers, and Control UI.
