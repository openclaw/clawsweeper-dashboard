## Summary

Keep open: current main still lacks an enforceable Private/Secret/Incognito session contract; `contextInjection: "never"` only suppresses bootstrap/context injection and does not stop durable session metadata, JSONL transcript creation, memory/compaction/plugin persistence, or UI/channel history exposure.

## What This Changes

Add a Mission Control Private Mode that suppresses workspace/persona/memory context and prevents private session/history/memory persistence.

## Best Possible Solution

Design one additive private/ephemeral session contract across Gateway protocol, SessionEntry/store/transcripts, bootstrap/context/memory, plugin persistence hooks, channels, and Control UI, with tests proving private sessions neither read private workspace/memory context nor write durable history.

## Reproduction Assessment

Yes at source level: current session schemas and creation paths have no private/no-persist field and still create durable session entries plus JSONL transcript headers; no live run was attempted because there is no private-mode flag to exercise.

## Solution Assessment

Yes for triage: keeping #7403 open as the canonical tracker is the best current path because prompt-only, config-only, or UI-only changes would falsely promise privacy without a cross-layer enforcement contract.
