## Summary

Keep open as the canonical tracker: current main still lacks an enforceable per-session private/no-persist contract, and the requested privacy guarantee requires maintainer-approved product and security semantics before implementation.

## What This Changes

Add a Control UI private mode that suppresses workspace and memory context and prevents durable session persistence.

## Best Possible Solution

Define one additive private-session contract with documented exclusions, then enforce it across Gateway protocol, session storage, bootstrap and memory reads, tools and media, channels, and Control UI with end-to-end no-read/no-write/no-history tests.
