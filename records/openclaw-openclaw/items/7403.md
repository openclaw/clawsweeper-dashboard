## Summary

Keep open as the canonical tracker: the recent review and discussion show that current behavior still lacks an enforceable per-session privacy contract, and the `clawsweeper:human-review` label confirms that maintainer product and security decisions are still required.

## What This Changes

Request a Mission Control private mode that suppresses workspace context and makes a session’s memory, transcript, and related state non-persistent.

## Best Possible Solution

Design and approve one additive private/ephemeral session contract that is enforced across Gateway creation, session state and transcripts, bootstrap and memory loading, compaction/indexing, tool and media persistence, channel activation, and Mission Control, with negative persistence tests for every boundary.
