## Summary

Keep open: current main still lacks an enforceable Private/Secret/Incognito session contract, and the existing context-injection controls only suppress bootstrap files rather than preventing durable transcript, session-store, memory-index, or channel/UI persistence.

## What This Changes

Request a Private Mode toggle and session contract that suppresses workspace context and prevents durable session or memory persistence for demo, content-creation, and sensitive conversations.

## Best Possible Solution

Define one additive core private-session contract and enforce it through Gateway protocol, session storage, transcript creation, memory/compaction indexing, plugin/channel artifacts, and Control UI before presenting it as a privacy feature.
