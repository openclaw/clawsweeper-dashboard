## Summary

Keep open: current main still lacks an enforceable Private/Secret/Incognito session contract, and existing context-injection controls only suppress bootstrap files rather than preventing durable transcript, session-store, memory-index, or channel/UI persistence.

## What This Changes

Request a Private Mode that suppresses workspace context, avoids durable session/memory writes, uses temporary working memory, and exposes a visible Mission Control toggle/status.

## Best Possible Solution

Define one additive core private-session contract and enforce it through Gateway protocol, session storage, transcript creation, memory/compaction indexing, plugin/channel artifacts, and Control UI before presenting it as a privacy feature.

Yes for triage: keeping this open for design is the best path because contextInjection:"never" is too narrow to guarantee private session storage, memory, or channel behavior. The implementation should use one enforceable privacy contract rather than partial toggles.
