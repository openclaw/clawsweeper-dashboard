## Summary

Keep open: current main and v2026.6.11 still lack an enforceable per-session private/no-persist contract, and the closed duplicates plus unmerged partial PR confirm this remains the canonical product and security tracker.

## What This Changes

Add an enforceable per-session private mode that suppresses workspace context and prevents durable transcript or memory persistence.

## Best Possible Solution

Define a closed private-session mode at the canonical SQLite session lifecycle boundary, then propagate it through bootstrap, memory/plugin/tool/media access, channel activation, and Control UI with tests proving no durable content writes.
