## Summary

Keep open: current main and v2026.6.11 still lack a final-only normal-chat tool-error delivery policy; they only provide the all-off `messages.suppressToolErrors` boolean plus safety-preserving default warnings for failed mutating tools.

## What This Changes

Request a normal-chat config policy to suppress or delay transient tool-error warning bubbles after successful-looking final replies.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep visible failed-mutation warnings as the default, and add final/off semantics only with schema, docs, payload, progress, and representative channel regression coverage.
