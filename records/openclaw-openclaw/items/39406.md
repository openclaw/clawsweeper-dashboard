## Summary

Keep open: current main and v2026.6.11 cover the explicit all-off operator case through `messages.suppressToolErrors`, but the requested final-only normal-chat policy remains unresolved and needs maintainer product direction because default behavior still intentionally surfaces success-looking mutating failures.

## What This Changes

The issue requests a normal-chat configuration policy to suppress or defer transient tool-error warnings after an agent recovers successfully.

## Best Possible Solution

Define one message-error delivery policy that preserves the default safety warning for unacknowledged failed mutations, keeps or migrates the existing off/internal-only knob, and adds final-only behavior only with focused docs and regression coverage.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should OpenClaw add a new final-only tool-error delivery mode, or keep `messages.suppressToolErrors` as the only normal-chat opt-out for these warning bubbles?

Rationale: The code can implement either shape, but the choice changes user-visible safety semantics for failed mutating actions and adds or redefines configuration surface.

Likely owner: vincentkoc

Owner confidence: high

Options:

- **Add final-only policy (recommended):** Define `all | final | off` semantics, preserve current default safety behavior, and test success/acknowledgement detection before adding the new config surface.
- **Keep off-only policy:** Document `messages.suppressToolErrors` as the supported operator opt-out and decline final-only suppression until stronger failure classification exists.
- **Route warnings elsewhere:** Defer suppression and handle operator noise through a dedicated warning destination/category design such as the related routing issue.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 still test that success-looking mutating failures produce a final assistant reply followed by a warning. I did not run a live channel replay in this read-only review.

## Solution Assessment

Unclear until maintainers choose the policy: the requested all/final/off shape is plausible, but current OpenClaw already has an off knob and intentionally keeps default warnings visible for unacknowledged mutating failures.
