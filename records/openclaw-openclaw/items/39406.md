## Summary

Keep open: current main and v2026.6.11 provide an all-off `messages.suppressToolErrors` boolean and related leak fixes, but they still do not implement the requested normal-chat `all | final | off` delivery policy, so this remains a maintainer product/config decision.

## What This Changes

Request a public config policy for suppressing transient tool-error warning bubbles after successful or useful final replies while keeping tool failures available to the agent and logs.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep visible failed-mutation warnings as the default, and add final/off semantics only with schema, docs, payload, progress, and representative channel regression coverage.
