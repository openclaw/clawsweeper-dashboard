## Summary

Keep open: current main still has an all-off `messages.suppressToolErrors` opt-in and a safety default that shows success-looking mutating-tool failures, but it does not implement the requested `all | final | off` normal-chat delivery policy.

## What This Changes

Request a config policy that can suppress or defer user-visible tool-error warning bubbles after recovered or successful-looking agent turns.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep the safety-preserving current behavior as the default, and add `final` or `off` only with schema, docs, payload, progress, and channel regression coverage.
