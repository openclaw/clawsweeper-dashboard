## Summary

Keep open: the current codebase provides the boolean `messages.suppressToolErrors` all-off path and retains safety warnings for unresolved mutating failures, but the requested `all | final | off` normal-chat delivery policy remains a product/config decision rather than an already-implemented bug fix.

## What This Changes

The issue requests configurable normal-chat delivery of transient tool error warnings so hosted/team-chat deployments can suppress recovered tool-failure bubbles while preserving logs and agent context.

## Best Possible Solution

A maintainer should decide the public operator contract first, then implement a narrow documented policy that preserves agent/log visibility and keeps the existing safety fallback unless an explicit opt-in mode suppresses user-facing bubbles.
