## Summary

Keep open: current main and v2026.6.11 still support all-off suppression through `messages.suppressToolErrors`, but they do not implement the requested final-only `all | final | off` delivery policy. The remaining work changes public config and failed-mutation safety semantics, so it needs maintainer product direction before a fix PR.

## What This Changes

The issue requests a normal-chat config policy for suppressing transient user-visible tool-error warnings after an agent recovers or produces a useful final reply.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep current visible failed-mutation behavior as the default, and add any final/off mode only with schema, docs, and regression coverage for the safety cases.
