## Summary

Keep open: current main and v2026.6.11 have the boolean `messages.suppressToolErrors` all-off opt-in and safety-preserving failed-mutation warnings, but they still do not implement the requested normal-chat `all | final | off` delivery policy.

## What This Changes

Request a normal-chat config policy to suppress transient or recovered tool-error warnings after successful agent replies.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep current safety behavior as the default, and add `final` or `off` only with schema, docs, payload/progress, and representative channel regression coverage.
