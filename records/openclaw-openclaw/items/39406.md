## Summary

Keep open: current main and the latest release cover the all-off `messages.suppressToolErrors` case, but they still do not implement the requested default-compatible `all | final | off` normal-chat delivery policy.

## What This Changes

The issue requests a normal-chat configuration policy for suppressing transient tool-error warning bubbles after an agent recovers successfully.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep the current safety-preserving behavior as the default, and add any `final` or `off` mode only with aligned schema, docs, payload, progress-delivery, and channel regression coverage.
