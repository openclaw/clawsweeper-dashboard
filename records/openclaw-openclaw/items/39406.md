## Summary

Keep open: current main and v2026.6.11 support the existing all-off `messages.suppressToolErrors` boolean, but the requested success-aware normal-chat `all | final | off` delivery policy is still missing and needs a maintainer product/config decision.

## What This Changes

The issue requests a normal-chat configuration policy to suppress or defer transient tool-error warnings after an agent ultimately succeeds.

## Best Possible Solution

Keep the existing `messages.suppressToolErrors` all-off escape hatch, and have maintainers decide whether to add a default-compatible success-aware delivery mode with focused tests across mutating, exec-like, progress, cron, heartbeat, and channel delivery paths.
