## Summary

Keep open: current main still has targeted leak fixes and the all-off `messages.suppressToolErrors` boolean, but not the requested normal-chat `all | final | off` tool-error delivery policy, so the remaining work is a maintainer product/config decision.

## What This Changes

The issue requests a configurable policy for suppressing transient user-visible tool-error warnings after an agent recovers or produces a successful final reply.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep visible warnings as the default, and add final/off semantics only with schema, docs, payload, progress, and representative channel regression coverage.
