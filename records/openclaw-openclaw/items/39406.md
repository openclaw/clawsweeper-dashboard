## Summary

Keep open: current main and v2026.6.11 provide partial all-off suppression through `messages.suppressToolErrors`, but they still do not implement the requested normal-chat `all | final | off` delivery policy for recovered tool errors.

## What This Changes

Request a normal-chat configuration policy that suppresses or delays transient tool-error warning bubbles after agent recovery while preserving the failure for agent context and logs.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep current warning visibility as the default, and add `final` or `off` only with schema, docs, payload/progress coverage, and representative channel regressions.
