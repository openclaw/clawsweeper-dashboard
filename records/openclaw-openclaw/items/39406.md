## Summary

Keep open: current main still provides only the all-off `messages.suppressToolErrors` boolean plus safety-preserving default warnings, while the requested final/off normal-chat delivery policy remains a public config and failed-mutation product decision.

## What This Changes

Request a normal-chat config policy to suppress or defer transient tool-error warning bubbles after an agent recovers and produces a useful final reply.

## Best Possible Solution

Define one default-compatible normal-chat tool-error delivery contract, keep current visible warnings as the default, and add final/off semantics only with schema, docs, payload, progress, and representative channel regression coverage.
