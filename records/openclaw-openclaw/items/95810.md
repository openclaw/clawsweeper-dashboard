- **[P1] Keep shared Claude home opt-in by default:** `scripts/claude-auth-status.sh:18-20`
  - body: The resolver now checks the shared Claude home before the existing $HOME locations.   - confidence: 0.89
- **[P1] Do not treat refresh token presence as healthy by itself:** `scripts/auth-monitor.sh:131-133`
  - body: This branch returns success when the access token is expired but a refresh token string exists. Current OpenClaw auth health/bootstrap only treats credentials as usable when the expiry state is valid, so this can suppress reauth alerts if the Claude CLI cannot refresh in that managed context; require live proof or keep expired status until refresh is verified.
  - confidence: 0.82
- **[P2] Skip CLAUDE_CONFIG_DIR candidates when the env var is unset:** `scripts/claude-auth-status.sh:16-17`
  - body: With CLAUDE_CONFIG_DIR unset, these candidates expand to `/.credentials.json` and `/.claude/.credentials.json`, so a root-level file could be selected before the intended shared or HOME stores. Build these candidates only when CLAUDE_CONFIG_DIR is non-empty.
  - confidence: 0.88
