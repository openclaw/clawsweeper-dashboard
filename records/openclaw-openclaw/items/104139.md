Full review comments:

- **[P2] Request read scope for read-only CLI operations:** `extensions/workspaces/src/cli.ts:132-136`
  - body: This prior finding remains: every non-approval call requests `operator.write` plus `operator.read`, including `workspaces.get` used by tabs/widgets lists and layout get. A device approved only for read access is rejected for asking for the extra scope; select scopes by method.
  - confidence: 0.99
- **[P2] Keep shared prompt locks owned by the acquiring bridge:** `ui/src/lib/workspace/bridge.ts:136-143`
  - body: This prior finding remains: prompt rate state is shared by widget name, but disposing any bridge clears the shared `inFlight` boolean. With two mounted instances, disposing one can unlock the other instance's pending confirmation and allow a second prompt; track the owning bridge or an in-flight count.
  - confidence: 0.97
- **[P2] Close the workspace store when the plugin is retired:** `extensions/workspaces/index.ts:12-13`
  - body: This prior finding remains: the plugin opens a long-lived SQLite store but registers no host-cleanup hook to call `store.close()` on disable or reload. That can leave the database locked and leak a handle per activation.
  - confidence: 0.98
- **[P2] Stop menu pointer events before drag handling:** `ui/src/components/workspace-widget-cell.ts:93-98`
  - body: Late discovery: this was equally visible at the previous reviewed head. The menu only handles `click`, but it is inside the header whose `pointerdown` starts a drag and calls `preventDefault()`; stop menu pointerdown propagation or restrict dragging to the intended handle.
  - late: true
  - confidence: 0.98
- **[P2] Preserve parameters on RPC bindings:** `extensions/workspaces/src/schema.ts:200-207`
  - body: Late discovery: this was equally visible at the previous reviewed head. The parser accepts only `{source, method}`, so parameterized allowlisted calls such as `cron.get`, `node.describe`, and `sessions.get` cannot retain required arguments even though the browser resolver supports `binding.params`.
  - late: true
  - confidence: 0.99
