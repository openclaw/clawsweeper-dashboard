  - body: Prompt state is shared by widget name, but disposing either mounted bridge clears `inFlight` even when a different instance owns the active confirmation. Track the lock owner or use a token/count and release only the lock acquired by this bridge.
  - confidence: 0.98

  - body: The plugin opens a long-lived SQLite store but never registers runtime lifecycle cleanup. Disabling or reloading the plugin can retain the database handle and leak one handle per activation; register cleanup that calls `store.close()`.
  - confidence: 0.99

  - body: The menu is rendered inside the draggable header, but its items only handle `click`; their `pointerdown` bubbles into the drag starter and can be prevented or leave a ghost drag. Stop pointerdown propagation on the menu/items or restrict drag start to the explicit handle.
  - confidence: 0.98
