  - body: The plugin opens a long-lived `WorkspaceStore`/`node:sqlite` handle and shares it across gateway, tools, and HTTP routes, but registration provides no service stop callback. The host stops registered plugin services on reload and shutdown, so disabling or reloading Workspaces can retain the database handle and leak one store per activation. Own the store through a stoppable service and call `store.close()`.
  - confidence: 0.99
