Overall confidence: 0.96

Full review comments:

- **[P2] Request read scope for read-only CLI operations:** `extensions/workspaces/src/cli.ts:132-136`
  - body: `workspaces.get` and every other non-approval CLI call request `operator.write` plus `operator.read`, so a device approved only for reads cannot run the advertised list/get commands. Select scopes by method so read-only RPCs request only `operator.read`.
  - confidence: 0.99
- **[P2] Keep shared prompt locks owned by the acquiring bridge:** `ui/src/lib/workspace/bridge.ts:361-364`
  - body: The rate state is shared by widget name, but disposing either same-name bridge unconditionally clears `inFlight`. If another bridge still owns a pending confirmation, a new request can bypass the one-in-flight guard; track the owner/token or use a count.
  - confidence: 0.99
- **[P2] Close the workspace store when the plugin is retired:** `extensions/workspaces/index.ts:13-14`
  - body: This registration creates a long-lived `WorkspaceStore` but never registers `api.lifecycle.registerRuntimeLifecycle` cleanup. Disabling or reloading the plugin can retain the SQLite handle and lock, so close the store on plugin or host retirement.
  - confidence: 0.98
- **[P2] Stop menu pointer events before drag handling:** `ui/src/components/workspace-widget-cell.ts:93-98`
  - body: Menu items sit inside the draggable header and do not stop `pointerdown`, so choosing Edit, Move, Hide, or Remove can enter the drag path before the click runs. Stop pointer propagation on the menu or restrict drag start to the intended handle.
  - confidence: 0.99
- **[P2] Preserve approvals across workspace replacement:** `extensions/workspaces/src/store.ts:88-94`
  - body: Replacement rebuilds `widgetsRegistry` only from incoming keys. An `operator.write` caller can omit an approved entry and make its assets unavailable without the separate approvals scope; preserve existing registry entries unless an approvals-scoped operation changes them.
  - confidence: 0.99
- **[P2] Count declined prompts in the rate limit:** `ui/src/lib/workspace/bridge.ts:268-277`
  - body: The rolling timestamp is recorded only after confirmation, so a widget can trigger unlimited confirmation dialogs when the operator declines. Count the attempt before or around confirmation so the advertised 10-per-minute guard also limits prompt spam.
  - confidence: 0.98
