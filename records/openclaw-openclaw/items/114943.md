## Summary

Keep this PR open for maintainer review. The new fail-open sanitization does not remove unknown keys from an otherwise valid `context` object, so malformed client hints can still reach the closed protocol schema and reject an otherwise valid chat turn; the `maintainer` label also requires explicit human handling.

## What This Changes

The PR adds an optional Control UI page hint to Ask OpenClaw chat requests so Ask OpenClaw can resolve ambiguous references such as “this page” against the operator’s current page.

## System Context

The Control UI sends user chat turns to the Gateway’s `openclaw.chat` method, which validates requests and hands them to the system-agent chat engine. The engine supplies the model with an ephemeral page hint while keeping the durable conversation history and transcript free of that hint.

Normalize accepted page context to exactly `{ page }` before protocol validation, drop every malformed or extra context field without rejecting the chat turn, and add a Gateway regression test covering a valid page plus an unknown key.
