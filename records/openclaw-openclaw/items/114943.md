## What This Changes

This PR adds an optional current-page hint to Ask OpenClaw chat requests, validates it at the Gateway, and supplies it only to the current system-agent model turn so Control UI questions such as “this page” have ambient route context.

## System Context

The Control UI sends `openclaw.chat` messages through the Gateway to the system-agent chat engine. This change carries a bounded page identifier from the active UI route, sanitizes it at the Gateway, and uses it only while preparing the current model input.
