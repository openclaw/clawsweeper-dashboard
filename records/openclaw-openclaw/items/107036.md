## Summary

Current main does not support the issue’s claimed implementation path: the named files are not the active subagent architecture, completions are deliberately identity-bearing push events, and v2026.7.1 already adds a combined wake after all outstanding children settle. Keep this open only for a narrow maintainer decision about deterministic ordering within that aggregate, because no current-main transcript shows a child result being misassociated or arriving in an unusable order. ([app.unpkg.com](https://app.unpkg.com/openclaw%402026.6.10/files/docs/tools/subagents.md?utm_source=openai))

## What This Changes

Define deterministic ordering for concurrent subagent results presented to a waiting parent agent, preferably preserving invocation order rather than completion order.

## Best Possible Solution

Keep identity-bearing push delivery, and if a latency-controlled current-main reproduction proves the final combined handoff is nondeterministic, order only that waiting-parent aggregate by the registry’s stable spawn sequence while preserving per-child run/session metadata and non-waiting delivery behavior.
