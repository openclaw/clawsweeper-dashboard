## What This Changes

The PR centralizes Browser click-coordinate parsing across the CLI and `/act`, preserving ordinary decimal and fractional inputs while rejecting hexadecimal, exponent-form, and trailing-dot coordinate strings.

## Best Possible Solution

Adopt the single Browser-owned parser if maintainers want one CLI-aligned ordinary-decimal contract, while explicitly accepting that scientific notation and trailing-dot decimal strings stop working for direct `/act` callers.
