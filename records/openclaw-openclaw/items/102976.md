## Summary

Keep this PR open: the latest head resolves the prior bounded, reason-aware diagnostic concern, but its shared compile cache can reuse the wrong regex set when two distinct pattern arrays produce the same delimiter-joined key, altering QQBot mention gating.

## Best Possible Solution
