## Summary

Keep open: the reported latest-release regression is still source-reproducible on current main because the Google thought-signature fallback path only recognizes model ids containing `gemini-3`, while OpenClaw already treats `gemini-flash-latest` as a Gemini 3-style thinking model elsewhere.

## What This Changes

Fix a v2026.6.11 regression where `google/gemini-flash-latest` tool-calling turns fail with Gemini's missing `thought_signature` 400 error.

## Best Possible Solution

Align Google thought-signature fallback detection with the existing Gemini 3 model-family helper, covering latest aliases in both native Google and Google OpenAI-compatible replay without relaxing route trust boundaries.
