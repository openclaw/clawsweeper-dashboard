## Summary

Keep this PR open for a narrow correction: the FIFO queues fix repeated rewritten IDs, but they omit same-model tool-call occurrences, so a mixed replay can still bind the first result to a later rewritten call.

## What This Changes

The branch replaces last-write-wins tool-call ID rewriting with per-ID FIFO queues plus latest-ID fallback, and adds replay regression coverage.

## Best Possible Solution

Represent every assistant tool-call occurrence in the per-ID sequence, including unchanged identity mappings, then add mixed-model collision coverage that proves results retain occurrence order.

Yes, from source: place an unchanged target-model tool call with raw ID `call_1` before a cross-model call with the same ID, then emit two `call_1` results. The current queue records only the second call, so the first result deterministically receives the later rewritten ID.

## Solution Assessment

No. FIFO is the right direction, but the queue must include identity occurrences as well as rewritten occurrences to preserve ordering across mixed source/target-model history.
