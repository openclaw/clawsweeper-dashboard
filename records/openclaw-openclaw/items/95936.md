## Summary

Keep this PR open, but it is not merge-ready: the branch still changes the default memory store identity without an upgrade path, collapses different extraPaths/session scopes into one database without the needed ownership/filter contract, and exposes new SDK helpers before the API is settled.

## What This Changes

The PR redirects memory-source agents to a workspace-hash shared SQLite store, removes extraPaths from the memory index identity hash, and adds memory-host SDK exports for shared-store helpers.

## Best Possible Solution

Keep the canonical design issue open and land a shared-memory store only after maintainers accept the path/session ownership model, add migration or rebuild-warning behavior, and keep new registry/API exports private until the contract is approved.
