## Summary

Keep open: this PR targets real memory duplication/reindex pain, but it is not merge-ready because the proposed shared store moves persistent memory without an automatic migration and lacks per-agent/session/extraPath ownership filters.

## What This Changes

## Best Possible Solution

Land a memory-owner approved shared-index design only with doctor migration/adoption, explicit per-agent/session/extraPaths visibility metadata and filters, and live upgrade plus extraPaths proof; otherwise keep per-agent DBs and solve extraPaths reindexing inside the current store model.
