Investigate whether synchronous fingerprint serialization of large plugin metadata snapshots can block the event loop and cause remote connection timeouts.

## Best Possible Solution

Add focused timing or benchmark coverage around snapshot fingerprint creation using a realistically large installed-plugin index; if blocking is material, compute the fingerprint once at snapshot construction or another lifecycle-owned boundary and carry the prepared value forward rather than introducing general asynchronous JSON chunking.
