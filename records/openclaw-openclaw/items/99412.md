## Summary

Keep open: current main and v2026.6.11 still use Matrix reasoning-only regexes that do not match `mm:` or `antml:` namespaced thinking tags, and the remaining work is represented by open Matrix fix PRs rather than already resolved.

## What This Changes

The issue asks Matrix monitor replies to recognize `mm:` and `antml:` namespaced reasoning tags when suppressing reasoning-only Matrix messages.

## Best Possible Solution

Land one vetted Matrix regex/test PR, such as https://github.com/openclaw/openclaw/pull/94038 or https://github.com/openclaw/openclaw/pull/99415, then close this issue from the merge.

## Reproduction Assessment

Yes, source-level. Current main's Matrix regex returns false for `mm:` and `antml:` namespaced reasoning tags while `deliverMatrixReplies` depends on that classifier before sending Matrix messages.

## Solution Assessment

Yes. Aligning the Matrix-local classifier with the already-merged shared `(?:antml:|mm:)?` reasoning-tag contract and adding focused reply tests is the narrow maintainable fix; broader helper consolidation can remain separate.
