## What This Changes

The issue requests Matrix monitor reply reasoning-tag detection to recognize MiniMax `mm:` thinking tags so reasoning-only replies are suppressed instead of sent to rooms.

## Best Possible Solution

Merge one vetted Matrix regex/test PR, then close this issue from the merged fix and retire the duplicate Matrix branches.

## Reproduction Assessment

Yes, source-level: current main's Matrix classifier still lacks `mm:` in both thinking-tag regexes, while `deliverMatrixReplies()` relies on that classifier before sending. I did not run a live Matrix room repro in this read-only review.

## Solution Assessment

Yes. The narrow maintainable fix is to align the Matrix-local regexes with the already-merged shared `(?:antml:|mm:)?` reasoning-tag contract and add focused Matrix regression coverage; broader deduplication can be separate.
