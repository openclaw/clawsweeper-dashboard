## What This Changes

The issue requests adding MiniMax `mm:` reasoning-tag namespace support to the Matrix monitor reply suppression regexes so reasoning-only replies are not sent to Matrix rooms.

## Best Possible Solution

Land one vetted Matrix regex-and-test PR, preferably the proof-positive https://github.com/openclaw/openclaw/pull/94038 or the closing https://github.com/openclaw/openclaw/pull/99417 after proof review, then close this issue from the merge.

## Reproduction Assessment

Yes, source-level. Current main's Matrix regex returns true for bare `<think>` but false for `<mm:think>` and `<antml:thinking>`, while `deliverMatrixReplies` depends on that classifier before sending Matrix messages.

## Solution Assessment

Yes. Aligning the Matrix-local classifier with the already-merged shared `(?:antml:|mm:)?` reasoning-tag contract and adding focused Matrix reply coverage is the narrow maintainable fix; helper consolidation can remain separate.
