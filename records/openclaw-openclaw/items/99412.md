Keep open: current main and v2026.6.11 still miss the Matrix `mm:` and `antml:` reasoning-tag namespace coverage, and this issue has open candidate fix PRs that should be reviewed and landed before closing.

## What This Changes

The issue requests adding known `antml:`/`mm:` reasoning-tag namespace support to Matrix monitor reply suppression so MiniMax reasoning-only replies are not sent to Matrix rooms.

## Best Possible Solution

Land one vetted Matrix regex-and-test PR, preferably the branch maintainers choose between https://github.com/openclaw/openclaw/pull/94038 and https://github.com/openclaw/openclaw/pull/99417, then close this issue from the merge.

## Reproduction Assessment

Yes, source-level. Current main's Matrix classifier suppresses bare reasoning tags but returns false for `mm:` and `antml:` namespaced reasoning tags, and `deliverMatrixReplies` depends on that classifier before sending Matrix messages.

## Solution Assessment

Yes. Aligning the Matrix-local regexes with the already-merged shared and sibling `(?:antml:|mm:)?` reasoning-tag contract plus focused reply regression coverage is the narrow maintainable fix; broader deduplication can be separate.
