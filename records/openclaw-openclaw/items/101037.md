## What This Changes

The PR adds optional exec approval titles and tool-call identifiers across the public exec caller, Gateway request and broadcast contract, generated Swift model, and ACP permission correlation.

## Best Possible Solution

Make `toolCallId` authoritative whenever present, retain the legacy sole-session fallback only for events where the identifier is absent, and preserve the PR's sanitized optional metadata chain with focused tests for matched, absent, unmatched, and ambiguous cases.
