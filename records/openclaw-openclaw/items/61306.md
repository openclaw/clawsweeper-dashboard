  - body: This writes Claw mission runtime state to `mission-state.json` under the mission directory. OpenClaw-owned runtime state is supposed to live in the canonical SQLite stores or an explicitly approved database owner, so this creates migration and session-state debt before the feature ships.
  - confidence: 0.9

  - body: RPC-supplied `missionId` values are only checked as non-empty strings before being joined into the missions directory. Reject path separators and traversal, or enforce normalized containment under the missions root, before any state/artifact path is resolved.
  - confidence: 0.91
- **[P1] Preserve HTTP/1 dispatcher helpers:** `src/infra/net/ssrf.ts:430-432`
  - body: This constructs Undici dispatchers directly instead of using the local `createHttp1*` helpers that enforce the guarded-fetch HTTP/1 policy. Keep the pinned dispatcher path on those helpers so the SSRF guard does not drift from the rest of the network boundary.
  - confidence: 0.88
