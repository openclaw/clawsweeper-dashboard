  - body: This branch persists mission runtime state as `mission-state.json` under each mission directory and writes control state as another JSON sidecar.   - body: RPC handlers accept any non-empty `missionId`, and `resolveMissionDir()` joins that value directly under the missions root.   - body: This replaces the current `createHttp1*` helper path with raw Undici dispatchers.
