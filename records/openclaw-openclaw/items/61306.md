## Review Findings

Full review comments:

- **[P1] Move mission state into SQLite:** `src/claw/service.ts:1774`
  - body: This writes Claw mission runtime state to mission-state.json under the mission directory. OpenClaw-owned runtime state is supposed to live in the canonical SQLite stores or an explicitly approved database owner, so this creates migration and session-state debt before the feature ships.
  - confidence: 0.9
- **[P1] Validate mission IDs before joining paths:** `src/claw/service.ts:1717-1718`
  - body: Gateway RPC only checks missionId as a non-empty string, then this helper appends it under the missions root. A value containing path separators or .. can escape the mission directory for reads and admin mutations, so validate the generated ID format or enforce normalized containment before resolving paths.
  - confidence: 0.88
- **[P1] Preserve HTTP/1 dispatcher helpers:** `src/infra/net/ssrf.ts:430-432`
  - body: This direct Undici dispatcher construction bypasses the current createHttp1* helpers, which enforce allowH2:false and shared proxy hardening for pinned SSRF-guarded requests. Keep those helpers here so HTTP/2 negotiation cannot bypass the pinned-lookup assumptions.
  - confidence: 0.9
