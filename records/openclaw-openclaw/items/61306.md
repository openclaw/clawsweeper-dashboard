## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Move mission persistence into SQLite:** `src/claw/service.ts:67-70`
  - body: This adds `mission-state.json`, `control-state.json`, and `AUDIT_LOG.jsonl` as durable mission/runtime state, then reads and writes them directly. OpenClaw-owned runtime state is supposed to live in SQLite or an explicit named artifact; otherwise upgrades and recovery get a competing state model before Claw ships.
  - confidence: 0.93
- **[P1] Validate mission IDs before resolving paths:** `src/claw/service.ts:1717-1722`
  - body: RPC handlers accept `missionId` as any non-empty string, and this resolver joins that value into the missions directory. A crafted ID containing path traversal can escape the mission root before reads or writes; validate the generated mission-id format or enforce normalized containment before resolving paths.
  - confidence: 0.91
- **[P1] Preserve the HTTP/1 pinned dispatcher helpers:** `src/infra/net/ssrf.ts:430-432`
  - body: This replaces the current `createHttp1*` helper path with direct Undici dispatcher constructors. Those helpers are where guarded networking pins `allowH2: false`, so bypassing them can re-enable HTTP/2 on SSRF-guarded requests and weaken the pinned-lookup security assumption.
  - confidence: 0.9
- **[P2] Use effective browser plugin activation:** `src/claw/service.ts:600-601`
  - body: The browser plugin is bundled with `enabledByDefault: true`, but this check only accepts an explicit `plugins.entries.browser.enabled === true`. Default installs that leave the browser entry unset can be misreported as disabled and block browser-required Claw missions unnecessarily.
  - confidence: 0.86
- **[P2] Skip malformed audit log lines:** `src/claw/service.ts:3847`
  - body: A single truncated or corrupt JSONL audit line will make the whole `claw.audit.get` request throw. Audit feeds should skip or quarantine malformed lines so operators can still see the valid mission audit history after a partial write or interruption.
  - confidence: 0.82
