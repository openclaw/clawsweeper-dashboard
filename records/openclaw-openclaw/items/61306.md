Full review comments:

- **[P1] Move mission persistence into SQLite:** `src/claw/service.ts:67-70`
  - body: This introduces mission-state.json, control-state.json, and AUDIT_LOG.jsonl as durable OpenClaw runtime state. The repo's runtime-state model expects SQLite or an explicitly approved database owner, so these sidecars create migration and session-state debt before the feature ships.
  - confidence: 0.9
- **[P1] Validate mission IDs before resolving paths:** `src/claw/service.ts:1717-1722`
  - body: Gateway RPC accepts missionId as a non-empty string, and this helper appends it under the missions root with path.join. Reject separators and traversal segments, or enforce normalized containment, before any mission file access.
  - confidence: 0.89
- **[P1] Preserve the HTTP/1 pinned dispatcher helpers:** `src/infra/net/ssrf.ts:430-432`
  - body: The branch bypasses the current createHttp1* helper path for pinned SSRF dispatchers. Those helpers force HTTP/1 behavior and proxy safety policy on guarded requests, so direct Undici constructors weaken the existing network boundary.
  - confidence: 0.86
- **[P2] Return after invalid missionId before reading limit:** `src/gateway/server-methods/claw.ts:372-374`
  - body: readRequiredString and readOptionalPositiveNumber both respond on invalid input. When missionId is missing and limit is invalid, this handler can send two error responses for one request instead of returning after the required-field failure.
  - confidence: 0.86
- **[P2] Use effective browser plugin activation:** `src/claw/service.ts:600-601`
  - body: The browser plugin manifest is enabled by default, but this check only accepts plugins.entries.browser.enabled === true. Default installs that do not spell out the redundant config entry can be treated as browser-disabled and block browser-required missions.
  - confidence: 0.84
- **[P2] Skip malformed audit log lines:** `src/claw/service.ts:3846-3848`
  - body: getAudit parses every JSONL line with a bare JSON.parse, so one truncated or corrupt append makes the whole audit request fail. Skip or isolate the bad record so operators can still read the valid audit entries.
  - confidence: 0.8
