## What This Changes

The issue requests a fix for WebChat/Codex sessions where `chat.send` returns `started` but an orphaned or oversized native Codex thread prevents any agent run, transcript write, or reply.

## Best Possible Solution

Make `chat.send` success contingent on a runnable turn or a visible auditable failure, and clear or rotate over-budget/stale Codex native bindings before returning `started` when the thread cannot safely resume.
