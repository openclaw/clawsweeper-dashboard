## Summary

Keep this PR open because current main does not provide the requested multi-turn side chat, but the patch is not merge-ready: it can discard a typed follow-up when detached sending fails and its trash action suppresses late output without stopping the pending run as documented. The linked feature issue remains canonical, and the branch also needs refresh from its current DIRTY merge state.

## What This Changes

The PR replaces the inline Control UI `/btw` result card with a floating responsive multi-turn side-chat panel supporting contextual follow-ups, hide/reopen, and clear actions.

## Best Possible Solution

Keep the floating multi-turn design, but make detached follow-up submission return an awaited acceptance result, cancel pending side questions through a run-id-scoped abort that cannot affect the concurrent main run, preserve late-event suppression, and prove the corrected exact head against a real Gateway.
