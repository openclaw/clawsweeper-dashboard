## What This Changes

The branch fetches original content for forwarded Feishu interactive cards, sends both direct and forwarded cards through a shared text extractor, and updates Feishu webhook test mocks to use the production-style ingress queue.

## System Context

Feishu inbound handling expands a merged-forward message by retrieving its sub-messages from Feishu, converting each payload into agent-readable text, and then building the body dispatched to the agent. Interactive-card parsing is shared with the direct-card read path so forwarded cards preserve the same readable content.
