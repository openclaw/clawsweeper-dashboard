## Summary

Keep open, but this patch is not merge-ready: it targets the right session lockout area, yet it turns every non-skipped preflight compaction failure into a skipped outcome and lacks real behavior proof for the user-visible Composer recovery.

## What This Changes

The PR changes preflight compaction failure handling to continue after previously terminal failed/non-compacted outcomes, and also adds an unrelated session-label preservation change in session reset persistence.

## Best Possible Solution

Keep the runtime guard as the repair layer, but narrow it to a structured retryability contract with positive timeout/true 429/5xx cases, negative auth/request-shape/thread/guard cases, focused regression tests, no unrelated label change, and redacted real behavior proof.
