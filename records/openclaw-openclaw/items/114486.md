## Summary

## What This Changes

The PR carries a display-name slug through short session URL parsing and uses it to select exactly one session only after the UUID-prefix lookup returns a complete ambiguity.

## System Context

Control UI session links are parsed into a short UUID reference and resolved through gateway session results. The chat route loader opens a unique session, otherwise presents the existing chooser; this change lets the link slug settle a completed short-ID tie without changing unique-resolution behavior.
