## What This Changes

Add a Telegram channel configuration that selects outbound formatting mode, optionally overridden for individual bot accounts.

## System Context

Telegram outbound delivery converts agent output into a Telegram-supported representation before sending final messages, media captions, edits, and draft previews. A formatting setting would need to flow through that shared policy so every delivery path uses the same account-aware contract.

## Best Possible Solution

Define a small Telegram-plugin-owned formatting policy with explicit supported modes, a stable default, top-level versus account-level precedence, and one shared adapter used by final sends, captions, edits, and previews; keep raw HTML and custom-emoji entity support as separately approved capabilities if needed.
