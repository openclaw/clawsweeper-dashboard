## Summary

Keep open. Current main and v2026.6.11 provide an account-inheritable `richMessages` switch, but still do not expose the requested plain-versus-formatted Telegram text mode; adding that public config requires maintainer direction on supported values, escaping/trust semantics, defaults, and inheritance.

## What This Changes

Add a Telegram channel/account configuration option selecting plain, Markdown-family, or HTML outbound formatting.

## Best Possible Solution

Keep standard rendered HTML as the safe default and, if maintainers approve a selector, define one plugin-owned typed mode contract—preferably formatted versus plain first—and apply it consistently across sends, captions, edits, previews, native replies, and fallbacks with fresh-install and upgrade coverage.
