## Summary

Keep open. Current-main review context shows Telegram’s rich-message setting is only a narrower delivery-path choice; it does not provide the requested general formatting-mode selector or per-account precedence. Recent reports of raw Markdown and Telegram Web behavior reinforce that maintainers need to set one coherent Telegram formatting contract before implementation.

## What This Changes

Add a Telegram channel configuration setting, potentially overridable per account, to select outbound formatting behavior such as plain text, HTML, or Markdown.

## Best Possible Solution

Define one plugin-owned Telegram formatting contract: preserve the current default, choose supported modes and account-overrides explicitly, then thread the resolved mode through final sends, captions, edits, and previews with shared escaping and regression coverage.
