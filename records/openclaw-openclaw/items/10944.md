## Summary

Keep open. Current main’s Telegram rich-message toggle covers a narrower delivery choice, but it does not provide the requested general plain-text/HTML/Markdown formatting selector or per-account precedence. Recent reports show remaining formatting friction, so maintainers should choose the supported modes before implementation. Likely related people: `steipete` (high confidence, formatter/config history) and `obviyus` (medium confidence, merged rich-message delivery work).

## What This Changes

Add Telegram channel-level and optional per-account configuration for selecting the outbound message formatting mode rather than relying on the built-in delivery format.

## Best Possible Solution

Keep the existing rich-message behavior as the default and, if maintainers approve additional modes, add one typed Telegram-plugin formatting policy with explicit account override precedence and consistent handling for sends, captions, edits, and previews.
