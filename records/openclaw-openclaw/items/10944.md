## Summary

Keep open: current main and v2026.6.11 expose `richMessages` and `markdown.tables`, but still do not provide a public Telegram `parseMode` or equivalent text-mode config, so this remains a product/config decision rather than conservative cleanup.

## What This Changes

Request a Telegram channel/account parse-mode config so users can choose plain, HTML, Markdown-style, or related Telegram formatting behavior instead of relying on internal rendering modes.

## Best Possible Solution

Keep this open for a Telegram plugin config-design decision, then wire the approved mode consistently across sends, captions, edits, draft previews, generated config metadata/help, docs, and focused tests.
