## Summary

Keep open: current main and the latest release expose adjacent Telegram knobs like `richMessages` and `markdown.tables`, but still do not expose the requested public parse/text-mode selector for plain, HTML, Markdown, or MarkdownV2 delivery.

Request to add a Telegram channel/account `parseMode` config so users can choose plain text, HTML, or Markdown-style Telegram delivery.

## Best Possible Solution

Define a Telegram-owned parse/text-mode contract that preserves the current default, then implement it consistently across schema, exported types, generated metadata, docs, sends, captions, edits, previews, and focused tests.
