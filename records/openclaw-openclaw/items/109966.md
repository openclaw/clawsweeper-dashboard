## Summary

The established in-flight recovery path is a sensible design, but the prior P2 lifecycle finding remains on the current head: retryable cleanup can delete the plan while its run is still active. Real after-fix reconnect proof is also still required before merge.

## What This Changes

The PR adds active plan snapshots to gateway in-flight run replay and reconciles them after reconnect across the web, iOS/macOS, and Android chat clients.

## Best Possible Solution

Give plan snapshots active-run lifetime rather than generic buffered-text lifetime, clearing them only on authoritative terminal or abort cleanup while preserving the existing legacy-gateway reconciliation contract.
