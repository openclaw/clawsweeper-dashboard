## Summary

Keep open. Current main has stronger built-in config-write validation, SecretRef preflight, base-hash checks, destructive-array protection, and agent-tool allowlisting, but it still lacks the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous `config:pre-apply` plugin hook that can inspect and reject pending `config.set`, `config.patch`, and `config.apply` writes before they persist.

## Best Possible Solution

Design a documented synchronous config-write interception point that runs after pending config computation and built-in validation/preflight but before persistence across shared config mutation paths.
