## Summary

Keep open: current main and the latest release have built-in config validation, SecretRef preflight, base-hash guards, destructive-array checks, and a fail-closed agent-tool allowlist, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Request a synchronous `config:pre-apply` hook that lets validators inspect current and pending config and reject config writes before persistence.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across gateway RPC and shared mutation helpers.
