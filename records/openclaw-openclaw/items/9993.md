## Summary

Keep open: current main and the latest release have built-in validation, SecretRef preflight, base-hash checks, and agent-tool restrictions, but still do not expose the requested synchronous plugin/API config-write veto before persistence.

## What This Changes

Request a synchronous `config:pre-apply` hook that can inspect current and pending config for `config.patch`/`config.apply` writes and reject unsafe changes before they are persisted.

## Best Possible Solution

Define a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence, covers all config write paths, and returns a typed reject result without mutating disk or runtime state on rejection.
