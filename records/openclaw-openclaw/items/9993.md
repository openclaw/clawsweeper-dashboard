## Summary

Keep open. The supplied recent maintainer review identifies an unresolved Plugin SDK gap: current validation and guarded config writes do not provide a mandatory synchronous pre-persistence veto for external validators. This is a security-sensitive product and lifecycle contract, not a safe mechanical repair.

## What This Changes

Request a synchronous, rejectable hook before gateway config mutations are persisted so external validators can block unsafe changes.

## Best Possible Solution

Define one documented Plugin SDK rejection-only interception point after core validation and SecretRef preflight but before canonical persistence, cover every supported config writer, and prove a rejection leaves both on-disk and active runtime config unchanged.
