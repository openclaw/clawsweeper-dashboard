## Summary

Keep open. Current main and the latest release have built-in config validation, SecretRef preflight, base-hash guarded writes, destructive-array safeguards, and agent-tool config write allowlists, but they still do not expose the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Request a synchronous plugin-facing `config:pre-apply` hook that can validate and veto `config.set`, `config.patch`, and `config.apply` changes before they are persisted.

## Best Possible Solution

Define a documented config-write interception contract after pending config computation and built-in validation/preflight but before persistence, covering RPC and shared mutation helpers with typed rejection and no-write regression tests.
