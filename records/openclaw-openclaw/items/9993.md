## Summary

Keep open: current main has schema validation, SecretRef preflight, base-hash guarded writes, destructive-array checks, and an agent config-write allowlist, but still lacks the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous `config:pre-apply` plugin hook that can inspect current and pending config and reject `config.set`, `config.patch`, `config.apply`, and shared config writes before disk persistence.

## Best Possible Solution

Design a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence across all shared config mutation paths.
