## Summary

Keep open: current main has built-in config validation, SecretRef preflight, guarded base-hash writes, and an agent-side allowlist, but it still does not expose the requested synchronous plugin/API-level config pre-apply veto before persistence.

## What This Changes

Request a synchronous config pre-apply hook that lets validators inspect current and pending config and block config writes before they are persisted.

## Best Possible Solution

Add a documented synchronous config-write interception seam after pending config computation and built-in validation/SecretRef preflight but before persistence, covering config.set, config.patch, config.apply, and shared mutation helpers with typed rejection and regression tests proving rejected writes leave disk and runtime config unchanged.
