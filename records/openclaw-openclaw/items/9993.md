## Summary

Keep open: current main has schema validation, SecretRef preflight, base-hash guarded writes, destructive-array checks, and an agent-tool allowlist, but still lacks the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Request a synchronous plugin/API-level config pre-apply hook that can inspect and reject pending config writes before `config.set`, `config.patch`, `config.apply`, or shared config mutation helpers persist them.

## Best Possible Solution

Design a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence across all shared config mutation paths.
