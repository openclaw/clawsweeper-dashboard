## Summary

Keep open. Current main and the latest release have validation, SecretRef preflight, base-hash guarded writes, and an agent-tool allowlist, but they still lack the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Requests a synchronous plugin-facing `config:pre-apply` hook that can inspect and reject pending config writes before `config.patch` or `config.apply` persists changes.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across `config.set`, `config.patch`, `config.apply`, and shared mutation helpers.
