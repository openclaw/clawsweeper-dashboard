## Summary

Keep open. Current main and v2026.6.11 have config-write validation, SecretRef preflight, base-hash guards, destructive-array guards, and an agent-tool allowlist, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous config pre-apply hook that can inspect and reject pending config mutations before `gateway config.patch` or related config writes persist changes.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across RPC and shared config mutation helpers.
