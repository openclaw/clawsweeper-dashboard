## Summary

Keep open. Current main and v2026.6.11 have built-in config validation, SecretRef preflight, base-hash guarded writes, destructive-array safeguards, and agent-tool config write allowlists, but they still do not expose the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous plugin-facing `config:pre-apply` hook that can inspect and reject config writes before `config.set`, `config.patch`, or `config.apply` persists them.

## Best Possible Solution

Define a documented config-write interception contract after pending config computation and built-in validation/preflight but before persistence, covering RPC and shared mutation helpers with typed rejection and no-write regression tests.
