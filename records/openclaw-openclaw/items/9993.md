## Summary

Keep open. Current main and v2026.6.11 have config validation, SecretRef preflight, base-hash guarded writes, destructive-array guards, and an agent-tool allowlist, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Request to add a synchronous plugin-facing config pre-apply hook that can inspect and reject pending config writes before persistence.

## Best Possible Solution

Design a documented synchronous config-write interception point that runs after pending config computation and built-in validation/preflight but before persistence across gateway RPC and shared mutation helpers.
