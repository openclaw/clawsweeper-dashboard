## Summary

Keep open: current main and the latest release have config validation, SecretRef preflight, base-hash guarded writes, and agent-tool config mutation guards, but they still do not expose the requested synchronous plugin-facing pre-apply veto before persisted config writes.

## What This Changes

Request a synchronous `config:pre-apply` hook that can inspect and reject pending `config.patch`/`config.apply` changes before they are written.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across gateway RPC and shared mutation helpers.
