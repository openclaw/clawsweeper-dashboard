## Summary

Keep open. Current main and the latest release have built-in config validation, SecretRef preflight, guarded config RPC writes, and agent-tool restrictions, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous config pre-apply validation hook that can inspect and block pending `config.patch` or `config.apply` writes before they persist.

Options:

- **Design the API first (recommended):** Define a documented config-write hook contract covering all config mutation paths, with explicit ordering, typed reject results, actor metadata, and regression tests before implementation.

- **Limit to agent tool writes:** Add a narrower interception point only for agent-issued `config.patch` and `config.apply`, accepting that other config writers will not be covered.
