## Summary

Keep open: current main has built-in config validation, SecretRef preflight, base-hash checks, and agent-tool allowlist guardrails, but it still lacks the requested mandatory plugin/API-level pre-persistence config-write veto.

## What This Changes

Add a synchronous config pre-apply hook that lets plugins validate and reject gateway config writes before they are persisted.

## Best Possible Solution

Define a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence, covers all config write paths, and returns a typed reject result without mutating disk or runtime state on rejection.
