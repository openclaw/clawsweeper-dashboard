## Summary

Keep open: current main has guarded config RPC writes and built-in validation/preflight, but it still lacks the requested mandatory plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Add a synchronous plugin-facing config pre-apply hook that can inspect and veto pending config writes before gateway config mutations are persisted.

## Best Possible Solution

Design a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence across all shared config mutation paths.
