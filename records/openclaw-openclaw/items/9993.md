## Summary

Keep open. Current main has built-in config validation, SecretRef preflight, base-hash guarded writes, destructive-array safeguards, and a post-commit runtime write listener, but it still lacks the requested synchronous plugin-facing config pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous config pre-apply hook that can validate and reject pending gateway config changes before they are written.

## Best Possible Solution

Define a documented config-write interception contract after pending config computation and built-in validation/preflight but before persistence, covering config.set, config.patch, config.apply, and shared config mutation helpers with typed rejection and no-write regression tests.
