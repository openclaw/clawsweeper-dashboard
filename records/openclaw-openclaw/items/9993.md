## Summary

Keep open. Current main and v2026.6.11 have several config-write safeguards, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a `config:pre-apply` hook/API that can synchronously validate and reject pending `config.patch`/`config.apply` writes before they are persisted.

## Best Possible Solution

Design a documented synchronous config-write interception point that runs after pending config computation and built-in validation/preflight but before persistence across `config.set`, `config.patch`, `config.apply`, and shared mutation helpers.
