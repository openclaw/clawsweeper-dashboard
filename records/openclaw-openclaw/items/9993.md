## Summary

Keep open: current main has stronger built-in config validation, SecretRef preflight, base-hash guarded writes, and an agent-tool config-write allowlist, but it still does not expose the requested mandatory synchronous plugin/API-level veto before config mutations are persisted.

## What This Changes

The issue requests a `config:pre-apply` hook that can inspect current and pending config and reject `config.patch` or `config.apply` before the write commits.

## Best Possible Solution

Define a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight, before persistence, and covers `config.set`, `config.patch`, `config.apply`, and shared mutation helpers with typed rejection tests.
