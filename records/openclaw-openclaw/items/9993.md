## Summary

Keep open. Current main has schema validation, SecretRef preflight, base-hash writes, destructive-array protection, and an agent config-write allowlist, but it still lacks the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Request a `config:pre-apply` hook/API that lets validators inspect current and pending config and reject config writes before persistence.

## Best Possible Solution

Design a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence across all shared config mutation paths.
