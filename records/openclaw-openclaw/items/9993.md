## Summary

Keep open: current main and the latest release have built-in config validation, SecretRef preflight, base-hash guarded writes, and tool allowlisting, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Add a synchronous plugin-facing config pre-apply hook that can inspect and reject pending config writes before persistence.

## Best Possible Solution

Design a documented config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across config.set, config.patch, config.apply, and shared config mutation helpers.
