## Summary

Keep open: current main and the latest release still lack the requested synchronous plugin-facing config pre-apply veto before persisted config writes, while existing validation, SecretRef preflight, base-hash writes, and agent-tool guards only cover adjacent safety cases.

## What This Changes

Request a synchronous plugin-facing config pre-apply hook that can inspect and reject pending gateway config mutations before persistence.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across gateway RPC and shared mutation helpers.
