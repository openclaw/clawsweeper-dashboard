## Summary

Keep open: current main and v2026.6.11 have config validation, SecretRef preflight, base-hash writes, and agent-tool guards, but still lack the requested synchronous plugin-facing veto before persisted config mutations.

## What This Changes

Request to add a synchronous config pre-apply hook that can validate and reject pending config writes before they are persisted.

## Best Possible Solution

Design a documented synchronous config-write interception point that runs after pending config computation and built-in validation/preflight but before persistence across RPC and shared mutation helpers, with typed rejection and regression tests proving rejected writes leave disk and runtime config unchanged.
