## Summary

Keep open: current main and v2026.6.11 still have built-in config validation, SecretRef preflight, base-hash guarded writes, and agent-tool config mutation guards, but they do not expose the requested synchronous plugin-facing pre-apply veto before persisted config writes.

## What This Changes

Requested a synchronous plugin-facing config pre-apply hook that can validate and reject gateway config mutations before they are persisted.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across gateway RPC and shared mutation helpers.
