## Summary

Keep open. Current main and the latest release have schema validation, SecretRef preflight, base-hash writes, and an agent config-write allowlist, but they still do not expose the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous `config:pre-apply` hook that can inspect and reject pending config writes before `config.set`, `config.patch`, or `config.apply` persist changes.

## Best Possible Solution

Design a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence across all shared config mutation paths.
