## Summary

Keep open. Current main has stronger built-in config safeguards, but it still lacks the requested synchronous plugin-facing config pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous plugin-facing pre-apply hook that can inspect and reject pending `config.set`, `config.patch`, and `config.apply` writes before persistence.

## Best Possible Solution

Design a documented synchronous config-write interception API that runs after pending config computation and built-in validation/preflight but before persistence across RPC and shared mutation helpers.
