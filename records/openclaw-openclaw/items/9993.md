## Summary

Keep open. Current main and the latest release have stronger built-in config validation, SecretRef preflight, base-hash guarded writes, destructive-array safeguards, and agent-tool allowlists, but they still do not expose the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

Requested a synchronous plugin/API hook that can validate and veto config.patch/config.apply changes before OpenClaw persists them.

## Best Possible Solution

Define a documented config-write interception contract after pending config computation and built-in validation/preflight but before persistence, covering RPC and shared mutation helpers with typed rejection and no-write regression tests.
