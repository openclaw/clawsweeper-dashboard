## Summary

Keep open: current main and v2026.6.11 have built-in config validation, SecretRef preflight, base-hash guarded writes, destructive-array checks, and an agent-tool allowlist, but they still do not provide the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous plugin-facing config pre-apply hook that can validate or reject pending gateway config writes before persistence.

## Best Possible Solution

Design a documented synchronous config-write interception contract that runs after pending config computation and built-in validation/preflight but before persistence across gateway RPC and shared mutation helpers.
