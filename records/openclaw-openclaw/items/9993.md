## Summary

Keep open. Current main and v2026.6.11 have schema validation, SecretRef preflight, baseHash/destructive-array protections, and model-facing gateway-tool guards, but they still lack the requested synchronous plugin-facing pre-apply veto before persisted config writes.

## What This Changes

Request a synchronous plugin/API hook that can inspect and reject pending config writes before config.set, config.patch, config.apply, and shared mutation helpers persist them.

## Best Possible Solution

Design a documented config-write interception seam after pending-config computation and built-in validation/preflight but before persistence, covering RPC and shared mutation paths with typed rejection and regression tests.
