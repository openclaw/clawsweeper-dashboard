## Summary

Keep open. Current main and v2026.6.11 have built-in config validation, SecretRef preflight, base-hash guarded writes, destructive-array safeguards, and agent-tool config write allowlists, but they still do not expose the requested synchronous plugin-facing pre-apply veto before persisted config mutations.

## What This Changes

The issue requests a synchronous config pre-apply hook that lets validation block gateway config mutations before they are persisted.

## Best Possible Solution

Keep this open and design a documented synchronous config-write interception point that runs after pending config computation and built-in validation/preflight but before persistence across config.set, config.patch, config.apply, and shared mutation helpers.
