## Summary

Keep open: current main has stronger built-in config validation and agent-tool guards, and the reporter linked config-guard as a useful external validator, but OpenClaw still lacks the requested mandatory plugin/API-level pre-persistence config veto.

## What This Changes

Add a synchronous `config:pre-apply` hook that can inspect and reject pending `config.set`, `config.patch`, and `config.apply` mutations before they are persisted.

## Best Possible Solution

Design one documented config-write interception seam after pending config computation and built-in validation/preflight but before persistence, covering RPC and shared mutation helpers with typed reject results and regression tests.
