## What This Changes

This PR creates one lazy, request-scoped snapshot of persisted session entries and passes it through gateway, Codex, and Anthropic catalog providers to avoid repeatedly enumerating the same agent stores during a catalog request.

## System Context

The gateway builds the Control UI’s session catalog by invoking registered providers such as Codex and Anthropic. Those providers read persisted agent session entries to recognize adopted sessions, then return catalog hosts and sessions to the gateway response.
