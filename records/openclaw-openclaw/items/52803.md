## Summary

Keep open: current main has useful session lineage metadata and Workboard/task primitives, but it still lacks the requested Control UI orchestration surface with a scalable hierarchy and safe bulk run controls.

## What This Changes

Request a Control UI mission/orchestration view for agent-to-subagent hierarchy, active-first filtering, bulk kill/steer/retry/cleanup, and scalability for many concurrent subagent sessions.

## Best Possible Solution

Keep this as the umbrella Control UI subagent-orchestration request and split it into reviewed slices: scalable read-only hierarchy first, then explicitly authorized bulk intervention and cleanup controls.

## Reproduction Assessment

Yes. Current source shows the requested feature gap: the Sessions page renders a flat paginated table with delete-only bulk selection and no orchestration route or bulk run controls.

## Solution Assessment

Unclear. The direction is coherent, but maintainers need to choose whether the durable shape is a new Orchestration tab, an expanded Sessions mode, a Workboard-backed surface, or a smaller staged hybrid.
