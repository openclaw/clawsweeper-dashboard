## Summary

Keep open: current main still uses raw UTF-16 slicing for fixed-width session key cells, and the protected maintainer label blocks conservative cleanup closure.

## What This Changes

Requests surrogate-safe truncation for long Unicode keys in `openclaw sessions` and `openclaw sessions cleanup --dry-run` table output.

## Best Possible Solution

Update `formatSessionKeyCell` to use the existing surrogate-safe helpers for prefix and suffix truncation while preserving the fixed 26-column layout and adding regression coverage for both table callers.
