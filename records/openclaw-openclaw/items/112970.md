## What This Changes

This PR updates generated-media completion replies so handoff-owned images, video, or audio are emitted at most once per outbound reply batch even if the resumed agent re-attaches the same artifact.

## System Context

Media-generation tasks send a completion event back to the originating agent session, whose reply is converted into outbound channel payloads. This change filters repeated references to media named by that completion event before the payload plan reaches channel delivery.
