## Summary

Keep this PR open for maintainer review. The patch is a plausible, narrowly scoped repair for the broader OpenAI-compatible stream-progress contract, but its cited loopback proof does not establish the original `inference.local` production path on current main because current idle-timeout code classifies `.local` and loopback endpoints as local/self-hosted. ## What This Changes

The PR reports each valid OpenAI-compatible completion chunk as model-request activity in both streaming implementations so hidden reasoning chunks can prevent false idle timeouts without emitting private reasoning.

## System Context

OpenAI-compatible provider streams are decoded by either the built-in AI provider or the managed transport, then passed to agent execution. The agent idle watchdog listens for model-request activity to distinguish active provider output from a genuinely stalled model call.
