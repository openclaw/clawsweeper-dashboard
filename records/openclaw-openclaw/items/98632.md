## Summary

Keep open: the requested 127.0.0.0/8 display fix is still useful on current main, but this PR still uses a hostname prefix check that can misclassify non-loopback DNS names as local and still lacks after-fix real behavior proof.

## What This Changes

The branch changes the model-list/status local URL classifier to treat any hostname beginning with `127.` as local instead of only exact `127.0.0.1`.

## Best Possible Solution

Use parsed loopback IP detection for `127.0.0.0/8`, keep the existing wildcard and mDNS display exceptions explicit, and add focused coverage for both `127.0.0.2` and a non-IP `127.*` hostname.

## Solution Assessment
