## Summary

Keep open: current main still misses the full IPv4 loopback range for the models-list local classifier, but this PR still has the prior correctness blocker because `127.` hostname prefix matching can classify non-loopback DNS names as local and the external proof is only unit-test output.

## What This Changes

The branch changes the model-list local URL classifier from an exact `127.0.0.1` match to any hostname starting with `127.`.

## Best Possible Solution

Use the existing parsed loopback IP helper for canonical IP literals, preserve the explicit localhost/wildcard/mDNS cases, add regression coverage for `127.0.0.2` and a non-IP `127.*` hostname, and include redacted real command output.
