## Summary

Keep open: current main still does not classify the full 127.0.0.0/8 loopback range, but this PR's prefix match would also classify non-IP DNS names as local and the contributor proof is only unit-test output.

## What This Changes

The branch changes `src/commands/models/list.local-url.ts` so model list/status local URL detection treats any hostname starting with `127.` as local instead of only `127.0.0.1`.

## Best Possible Solution

Use canonical loopback IP parsing for IP literals, keep the existing wildcard and `.local` display exceptions explicit, add focused regression coverage, and include redacted real command output for the `127.0.0.2` path.
