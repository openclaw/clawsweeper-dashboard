## Summary

Keep open: the requested 127/8 loopback classification is valid, but this PR still uses a hostname prefix check that can classify non-loopback DNS names as local, and the contributor proof remains unit-test output rather than real command behavior.

## What This Changes

The PR changes the model-list/status local URL classifier from exact `127.0.0.1` matching to any hostname beginning with `127.`.

## Best Possible Solution

Use `isLoopbackIpAddress(host)` for canonical IP literals, preserve the explicit wildcard and mDNS display exceptions, add focused regression coverage for `127.0.0.2` and a non-IP `127.*` hostname, and include redacted real CLI output for the changed command path.
