## Summary

Keep open: the underlying 127/8 local-classification bug still exists on current main, but this PR has the prior correctness blocker unchanged and still lacks contributor-supplied real behavior proof.

## What This Changes

The PR changes the model-list local URL classifier to treat any hostname starting with `127.` as local instead of only exact `127.0.0.1`.

## Best Possible Solution

Use canonical IP loopback parsing for `127.0.0.0/8`, keep the existing wildcard and mDNS display exceptions explicit, and add focused coverage for both `127.0.0.2` and a non-IP `127.*` hostname.

## Solution Assessment

No. The direction is right, but the best fix is to parse canonical loopback IP literals and preserve the current wildcard and mDNS exceptions, not to prefix-match hostnames.
