## Summary

Keep open: current main and v2026.6.11 still default omitted Telegram DM policy to pairing, still issue pairing challenges to unknown DM senders, and still rely on manual numeric allowFrom setup; related open items overlap but do not implement token-verified Telegram owner capture.

## What This Changes

The issue requests that Telegram setup default DMs to allowlist and auto-capture the owner Telegram ID instead of leaving fresh accounts in pairing mode.

## Best Possible Solution

Choose the Telegram trust model, then implement a Telegram-owned token-verified owner capture or maintainer-approved default-flip path with explicit-pairing compatibility, docs, schema, and focused runtime/setup tests.
