## Summary

Keep open: current main and the latest release still default Telegram DMs to pairing and still use manual numeric allowFrom setup, while safe owner capture requires a product/security decision.

## What This Changes

The issue requests changing Telegram first-run DM access from pairing to token-verified allowlist owner setup that writes the owner's Telegram ID into allowFrom.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
