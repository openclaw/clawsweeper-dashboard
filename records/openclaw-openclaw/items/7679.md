## Summary

Keep open: current main and the latest release still default Telegram DMs to pairing, setup still asks for manual numeric allowFrom entry, and the safe owner-capture design needs maintainer product/security approval.

## What This Changes

Make fresh Telegram setup default to dmPolicy="allowlist" by capturing the owner Telegram ID during onboarding and writing it to allowFrom.

## Best Possible Solution

Implement this as Telegram-owned first-run security work: token-verify the intended owner during setup, write dmPolicy="allowlist" plus numeric allowFrom for fresh setups, and preserve or explicitly migrate existing pairing-mode configs.
