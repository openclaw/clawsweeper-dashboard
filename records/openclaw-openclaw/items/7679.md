## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing, setup still relies on manual numeric allowFrom entry, and safe owner capture requires a product/security decision before implementation.

## What This Changes

Request that Telegram fresh setup default to allowlist by capturing the owner’s Telegram ID during onboarding instead of leaving DMs in pairing mode.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
