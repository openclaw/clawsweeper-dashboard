## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still rely on manual numeric allowFrom setup, while safe owner capture needs an explicit product/security decision.

## What This Changes

Request to make fresh Telegram setup default to allowlist mode by capturing and writing the owner Telegram user ID during onboarding.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
