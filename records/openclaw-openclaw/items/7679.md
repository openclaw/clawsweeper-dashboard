## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing, still issue pairing challenges to unknown DM senders, and setup still requires manual numeric allowFrom entry rather than token-verified owner capture.

## What This Changes

Requests fresh Telegram setup to default DMs to allowlist by capturing the owner Telegram user ID during onboarding instead of leaving pairing as the default.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write dmPolicy="allowlist" plus allowFrom for the verified owner on fresh or implicit setups, and preserve explicit pairing-mode configs with docs and regression coverage.
