## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still rely on manual numeric allowFrom setup, while safe owner capture needs a maintainer product/security decision.

## What This Changes

Request fresh Telegram setup/defaults to use allowlist mode with the owner Telegram ID captured during onboarding instead of pairing mode.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
