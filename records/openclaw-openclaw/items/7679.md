## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing, and the safe allowlist-owner path needs a maintainer product/security decision before implementation.

## What This Changes

Request fresh Telegram setup to default to `dmPolicy="allowlist"` by capturing the owner Telegram ID during onboarding.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during fresh setup, write allowlist config for that owner, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
