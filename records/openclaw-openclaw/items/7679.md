## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still use manual numeric allowFrom setup, while token-verified owner capture is a security-sensitive default/product decision.

## What This Changes

Request Telegram setup to default new direct messages to allowlist mode by capturing the owner Telegram ID during onboarding.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
