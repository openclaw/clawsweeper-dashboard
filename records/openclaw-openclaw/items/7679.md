## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still require manual numeric allowFrom setup, while the requested token-verified owner capture is a security-sensitive product/default decision.

## What This Changes

Request that fresh Telegram setup default to allowlist mode by capturing the owner's numeric Telegram ID instead of leaving DMs in pairing mode.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during fresh setup, write allowlist config for that owner, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
