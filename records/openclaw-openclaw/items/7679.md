## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and use manual numeric allowFrom setup, so the requested verified owner-capture allowlist default remains missing and needs product/security direction.

## What This Changes

Request fresh Telegram setup to default to allowlist by capturing the owner Telegram ID during onboarding and writing dmPolicy plus allowFrom.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture for fresh setup, write dmPolicy="allowlist" plus allowFrom for the verified owner, and preserve explicit pairing-mode configs with docs and regression coverage.
