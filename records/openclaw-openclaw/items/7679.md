## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still use manual numeric allowFrom setup; token-verified owner capture remains a security-sensitive product/default decision.

## What This Changes

Request to make Telegram fresh setup default to owner allowlist mode by capturing the owner Telegram ID during onboarding.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during fresh setup, write allowlist config for that owner, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.

No for a literal default-only flip or blind first-message capture. The maintainable path is token-verified owner capture during Telegram setup with explicit pairing-mode compatibility and docs/tests updated together.
