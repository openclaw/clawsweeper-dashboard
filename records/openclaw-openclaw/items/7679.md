## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still use manual numeric allowFrom setup, while verified owner capture is a security-sensitive default and product decision.

## What This Changes

The issue asks for Telegram setup/defaults to switch from pairing mode to allowlist mode seeded with the owner Telegram ID.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
