## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still use manual numeric allowFrom setup, while safe owner capture requires a maintainer product/security decision.

## What This Changes

The issue asks for Telegram setup/defaults to move new configurations from pairing-mode DMs to token-verified owner allowlisting.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
