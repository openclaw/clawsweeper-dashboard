## Summary

The related open items overlap, but none is a merged canonical implementation for this Telegram-specific first-owner setup behavior.

## What This Changes

The issue asks Telegram setup to default direct messages to allowlist mode by token-verifying and capturing the owner Telegram ID during onboarding.

## Best Possible Solution

Choose the Telegram trust model, then implement a Telegram-owned token-verified owner capture or maintainer-approved default-flip path with explicit-pairing compatibility, docs, schema, and focused runtime/setup tests.
