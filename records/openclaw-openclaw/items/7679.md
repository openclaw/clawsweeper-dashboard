## Summary

Keep open: current main still defaults Telegram DMs to pairing, still issues pairing challenges to unknown DM senders, and setup still requires manual numeric allowFrom entry rather than verified owner capture.

## What This Changes

The issue requests fresh Telegram setup to default DMs to allowlist by capturing the intended owner's Telegram ID instead of leaving dmPolicy as pairing.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture for fresh setup, write dmPolicy="allowlist" plus allowFrom for the verified owner, and preserve explicit pairing-mode configs with docs and regression coverage.
