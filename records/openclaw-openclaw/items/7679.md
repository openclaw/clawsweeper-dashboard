## Summary

Keep open: current main and the latest release still default Telegram DMs to pairing, still issue pairing challenges to unknown DM senders, and still rely on manual numeric allowFrom setup rather than token-verified owner capture.

## What This Changes

Request fresh Telegram setup to default to dmPolicy="allowlist" by capturing the owner's Telegram ID during onboarding.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh implicit setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
