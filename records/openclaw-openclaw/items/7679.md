## Summary

Keep open: current main and v2026.6.11 still default Telegram DMs to pairing and still use manual numeric allowFrom setup, while safe owner capture needs a maintainer product/security decision.

## What This Changes

The issue requests changing fresh Telegram setup so the bot defaults to allowlist mode with the owner's verified numeric Telegram ID instead of pairing mode.

## Best Possible Solution

Implement Telegram-owned token-verified owner capture during setup, write allowlist config for fresh setups, preserve explicit pairing-mode configs, and update schema/runtime/docs/tests together.
