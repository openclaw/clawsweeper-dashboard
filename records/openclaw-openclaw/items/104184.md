## Summary

## What This Changes

Adds an additive `sessions.diff` operator-read Gateway method, generated protocol models, and a capability-gated Control UI chat sidebar for reviewing tracked, uncommitted, untracked, binary, and truncated session checkout changes.

## Best Possible Solution

Use one shared session-checkout resolver for PR chips, files, and diffs; preclassify paths and enforce output/time limits before every patch-producing Git call; keep the protocol additive and stats-only for excluded content; then land only after a conflict-free exact-head review and redacted real Gateway/browser proof.
