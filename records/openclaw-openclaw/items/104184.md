## Summary

This PR remains necessary because neither current main nor v2026.6.11 provides a session diff panel, but it is not merge-ready: the new read-scoped RPC has a reproducible Gateway-privilege textconv execution flaw, the UI introduces an import cycle, a mock fixture violates a repository contract check, and the supplied screenshot exercises only mocked data.

## What This Changes

Adds a `sessions.diff` Gateway RPC, protocol models, and a localized Control UI sidebar panel that displays branch, working-tree, and untracked session checkout changes.

## Best Possible Solution

Retain the bounded read-only Gateway RPC and sidebar design, but add `--no-textconv` to every patch-producing Git invocation with exploit-focused tests, move shared diff rendering into a leaf UI module, use contract-safe fixture text, rebase, and demonstrate the panel against a real session checkout.
