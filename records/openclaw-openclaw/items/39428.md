## What This Changes

Request that Discord inbound routing map a non-default Discord accountId to a configured same-named agent after explicit bindings miss instead of falling back to the default agent.

## Best Possible Solution

Maintainers should decide the Discord routing contract, then either implement a guarded Discord-only same-name fallback with clear diagnostics, docs, regression tests, and live Discord proof, or keep explicit bindings as the contract and add doctor/status guidance for risky missing bindings.
