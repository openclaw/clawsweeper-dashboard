## Summary

Keep open: current main and v2026.6.11 still route unmatched Discord account traffic through explicit binding tiers and then the default agent, with no guarded same-name account-to-agent fallback. ## What This Changes

The issue requests Discord inbound routing to map a non-default channel account to a same-named configured agent when no explicit binding matches.
