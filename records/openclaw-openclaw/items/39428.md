## Summary

Keep open: current main and v2026.6.11 still route Discord account traffic through explicit binding tiers and then the default agent, while the same-name fallback work remains unmerged and needs a maintainer product/security decision.

## What This Changes

The issue requests automatic Discord account-to-agent routing by matching the Discord account name to an agent ID when no explicit binding exists.

## Best Possible Solution

Maintainers should choose one explicit Discord routing contract: land a guarded same-name fallback after explicit binding tiers miss, or keep explicit bindings as the contract and add doctor/status/docs guidance for risky missing bindings.
