- **[P2] Detect inline `//` comments outside strings:** `src/config/io.ts:1462`
  - body: Late discovery on an unchanged head: the `^\s*//` alternative only matches comments at line start, but JSON5 permits a single-line comment after any token, such as `{a: 1 // note\n}`. That comment is removed without triggering this warning; scan comment tokens outside strings instead of anchoring `//` to line start.
  - late: true
  - confidence: 0.99
- **[P2] Handle escaped JSON5 line continuations in strings:** `src/config/io.ts:1461`
  - body: The string regex treats an escape as backslash followed by dot, but dot does not match a line terminator. JSON5 allows a backslash and newline inside a quoted string, so comment-like text later in that continued value remains visible to the detector and causes a false warning. Use a lexical scan or explicitly consume every JSON5 line-terminator sequence.
  - confidence: 0.99
