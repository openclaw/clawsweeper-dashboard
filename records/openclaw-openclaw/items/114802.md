## What This Changes

This PR adds shared handling for exec auto-review failures so gateway, remote-node, and direct `system.run` command paths defer to bounded, redacted human approval instead of failing or executing a command.

## System Context

Exec auto-review evaluates commands that need approval and can allow a one-time execution or route them to a human. Gateway and node-host entry points consume that decision before command execution, pending approval registration, or denial messaging.
