## Summary

The original bounded Google error-body fix is sound, but the force-pushed consolidation introduces a blocking cross-provider regression: completed OpenAI-compatible batches containing both successful output and failed-request diagnostics are rejected before successful embeddings are read. The PR also has merge conflicts and its current 18-file scope is not covered by the narrow description and proof.

## What This Changes

The branch centralizes bounded embedding-batch response parsing, completion handling, and batch-unavailable signaling across the memory host SDK plus Google, OpenAI, Voyage, and memory-core callers and tests.

## Best Possible Solution

Keep all remote response and JSONL reads bounded, but process completed batches with both output and error files as mixed results: retain successful embeddings, surface failed-request diagnostics, and reserve total failure for error-only or unusable-output completion.
