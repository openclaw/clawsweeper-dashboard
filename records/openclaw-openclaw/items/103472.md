## Best Possible Solution

Keep the shared bounded HTTP and JSONL readers, but model completed batches as optional success and error artifacts, consume both, correlate records by request/custom id, retain valid embeddings, and report only failed or missing requests; alternatively narrow the branch back to the original proven Gemini error-body fix.
