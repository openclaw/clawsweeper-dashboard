## What This Changes

This PR makes OpenShell mirror sandboxes treat existing `skills/` and `.agents/skills/` directories as read-only for filesystem mutations and preserve those host directories when downloaded mirror contents replace the workspace.

## System Context

OpenShell’s mirror backend lets an agent operate in a remote sandbox while syncing workspace changes back to the host. Filesystem-tool resolution and final mirror download are both enforcement points that must keep owner-controlled skill instructions immutable while allowing ordinary workspace files to synchronize.
