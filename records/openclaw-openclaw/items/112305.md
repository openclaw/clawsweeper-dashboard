## What This Changes

This PR prevents OpenShell mirror sandboxes with writable workspace access from modifying existing `skills/` and `.agents/skills/` directories through filesystem tools or downloaded mirror contents.

## System Context

OpenShell is an extension that runs agent work in a sandbox and maps sandbox paths to a host workspace. Filesystem requests and mirror-download finalization both feed into that workspace, so protected skill directories must remain readable but owner-controlled across both paths.
