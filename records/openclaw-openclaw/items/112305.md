## What This Changes

This PR prevents writable OpenShell mirror sandboxes from changing existing workspace `skills/` and `.agents/skills/` directories through filesystem tools or downloaded mirror contents.

## System Context

OpenShell is an optional sandbox backend for agent execution. In mirror mode it copies a workspace to a remote sandbox, exposes filesystem operations through a bridge, then downloads remote changes back to the local workspace after execution.

## Best Possible Solution

Adopt one documented read-only skill-root policy for OpenShell mirror mode, preserve those roots during mirror download, and land this implementation after the sandbox/security owner confirms the compatibility tradeoff against current `main`.
