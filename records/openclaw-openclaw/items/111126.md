## Summary

Keep this PR open for an explicit gateway/CLI owner decision: the branch has strong real-provider proof and no discrete patch defect found, but it intentionally changes the public process-exit contract for terminal gateway failures.

## What This Changes

The branch derives resolved gateway-run responses from the normalized terminal outcome and makes `openclaw agent` exit nonzero after emitting timeout, error, or cancelled results.

## System Context

A gateway-routed `openclaw agent` request runs an agent turn and returns a normalized terminal result to the CLI. The CLI renders that result for people and automation, so the gateway status and process exit code together define whether a shell or CI job treats the turn as successful.

  F --> G[Shell and CI exit status]

## Best Possible Solution

Adopt one documented terminal-failure contract: gateway timeout, error, and cancellation responses must retain their structured output while reliably producing nonzero CLI status, with the existing success and cleanup controls preserved.
