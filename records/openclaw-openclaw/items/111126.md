## What This Changes

This PR derives resolved gateway-run failure responses from the normalized terminal outcome and makes `openclaw agent` exit with code 1 after emitting timeout, error, or cancellation output.

## System Context

Gateway-routed agent commands execute an agent turn and project its terminal state into a gateway response. The CLI then renders that response for people or automation, so its status and process exit code determine whether scripts treat the turn as complete.
