## What This Changes

Report that xAI/Grok's code-less encrypted_content decrypt 400 misses the Responses stale-replay retry predicate and can trip the per-model breaker for grok-4.3 traffic.

## Best Possible Solution

Extend isInvalidEncryptedContentError narrowly for xAI encrypted_content decrypt messages, keep the existing one-shot strip-and-retry boundary, and cover both the positive xAI case and an unrelated decrypt-message negative case.
