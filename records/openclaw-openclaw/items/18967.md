## Summary

Keep open: current main and the latest release still lack a trusted parent-scoped child-to-parent mid-run send path; only broad `sessions_send` opt-ins, ordinary visibility modes, ACP-only parent streaming, and completion announce paths exist today.

## What This Changes

Request a safe parent-only send path so spawned sub-agents can send mid-run updates or questions back to their direct parent session.

## Best Possible Solution

Define one narrow parent-only send contract derived from trusted active sub-agent metadata, then update policy, resolver, delivery, docs, and security regression tests together.

## Reproduction Assessment

Yes. Source inspection is a high-confidence reproduction path: current main still denies `sessions_send` to sub-agents by default, has no `sessions_send_parent` tool, and does not resolve a trusted `parent` target from sub-agent metadata.

## Solution Assessment

Yes in direction, but not as a broad opt-in to ordinary `sessions_send`. The maintainable solution is a dedicated parent-only operation or trusted parent selector backed by active run metadata and security tests.
