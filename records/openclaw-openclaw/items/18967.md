## Summary

Keep open: current main still lacks a trusted child-to-direct-parent mid-run send path; existing code has completion handoff, ordinary `sessions_send`, tree visibility, and broad opt-ins, but not the requested parent-only API.

## What This Changes

Request parent-scoped session sending so sub-agents can send mid-run updates or clarifying questions only to their direct parent session.

## Best Possible Solution

Define one narrow parent-only send contract derived from canonical active sub-agent metadata, then update policy, resolution, delivery, docs, and security regression tests together.

## Reproduction Assessment

Yes, at source level. Current main still denies `sessions_send` to sub-agents by default, has no `sessions_send_parent` tool, and does not resolve a trusted `parent` target from sub-agent metadata.

## Solution Assessment

Yes in direction, but not as a broad opt-in to ordinary `sessions_send`. The maintainable solution is a dedicated parent-only operation or trusted parent selector backed by active run metadata and security tests.
