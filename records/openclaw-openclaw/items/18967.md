## Summary

Keep open: current main and v2026.6.11 still lack a trusted parent-scoped native send path for mid-run sub-agent updates, and the adjacent announce-routing PR does not cover child-originated questions or progress sends.

## What This Changes

Request a parent-only mechanism, such as `sessions_send_parent` or a trusted `sessionKey: "parent"` selector, so sub-agents can send mid-run updates or questions only to their direct parent session.

## Best Possible Solution

Define one narrow parent-only send contract derived from trusted active sub-agent metadata, then update policy, resolver, delivery behavior, docs, and security regression tests together.
