## Summary

Keep open: current main and v2026.6.11 still do not provide a native parent-scoped mid-run send path for sub-agents. The remaining work is a security-sensitive model-facing session API decision, not stale cleanup.

## What This Changes

Request a parent-only way for sub-agents to send mid-run progress updates or questions to their direct parent session.

## Best Possible Solution

Define one narrow parent-only send contract derived from canonical active sub-agent metadata, then update policy, resolver, delivery, docs, and security regression tests together.

Question: Should OpenClaw add a new model-facing parent-only sub-agent send contract, and should it be a dedicated `sessions_send_parent` tool or a reserved `sessionKey: "parent"` target?

Rationale: The implementation changes session authorization boundaries and model-facing tool semantics, so automation should not choose the permanent API shape without maintainer security/product intent.

Likely owner: steipete

Owner confidence: high

Options:

- **Add a dedicated parent-only contract (recommended):** Implement a dedicated tool or trusted parent selector that derives the direct parent from spawn metadata and rejects siblings, ancestors, cross-agent targets, stale parents, and automatic forwarding.
- **Reserve `sessionKey: "parent"`:** Keep the existing tool name but add a trusted resolver path for the parent alias with the same authorization checks and no broader `sessions_send` exposure.
- **Defer to existing handoff paths:** Keep mid-run child-to-parent sends unsupported for now and document completion handoff, `sessions_yield`, and operator opt-ins as the supported workflows.

## Reproduction Assessment

Yes, at source level. Current main still denies `sessions_send` to sub-agents by default, has no `sessions_send_parent` tool, and does not resolve a trusted `parent` target from sub-agent metadata.

## Solution Assessment

Yes in direction, but not as a broad opt-in to ordinary `sessions_send`. The maintainable solution is a dedicated parent-only operation or trusted parent selector backed by active run metadata and security tests.
