## Summary

Keep open: current main and v2026.6.11 still lack a trusted parent-scoped mid-run send path for native sub-agents, and the remaining work is a security-sensitive model-facing API decision.

## What This Changes

Add a parent-only way for sub-agents to send mid-run updates or questions to their direct parent session without arbitrary session access.

## Best Possible Solution

Define one narrow parent-only send contract derived from active sub-agent metadata, then update policy, resolver, delivery, docs, and security regression tests together.

## Maintainer Decision

Kind: security_boundary

Question: Should OpenClaw add a model-facing parent-only sub-agent send contract, and should that be a dedicated `sessions_send_parent` tool or a reserved `sessionKey: "parent"` selector?

Rationale: The source gap is clear, but the permanent API shape changes child-to-parent session authorization and model-facing tool semantics.

Likely owner: steipete

Owner reason: This handle has the strongest recent history across session resolution, session-send behavior, sub-agent boundary hardening, and docs for this surface.

Owner confidence: high

Options:

- **Add dedicated parent-only contract (recommended):** Implement a dedicated tool or trusted parent selector that derives the direct parent from active spawn metadata and rejects missing, stale, sibling, ancestor, cross-agent, and forwarded targets.
- **Reserve `sessionKey: "parent"`:** Keep one `sessions_send` tool but make `parent` a trusted resolver keyword rather than a literal user-supplied session key.
- **Decline native mid-run sends:** Keep child-originated mid-run sends unsupported and document completion handoff, `sessions_yield`, and explicit trusted operator opt-ins as the supported paths.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 still deny `sessions_send` to sub-agents by default and do not expose a parent-only selector or tool.

## Solution Assessment

Yes in direction, but not as a broad opt-in to ordinary `sessions_send`. The maintainable solution is a dedicated parent-only operation or trusted parent selector backed by active run metadata and security tests.
