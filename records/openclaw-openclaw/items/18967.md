## Summary

Keep open: current main and v2026.6.11 still lack a trusted parent-scoped child-to-parent mid-run send path. Completion handoff, ACP-only parent streaming, and broad `sessions_send` opt-ins are adjacent, but they do not implement the requested parent-only, same-tree, no-chaining contract.

## What This Changes

Add a parent-scoped sub-agent send mechanism for mid-run progress updates and clarification questions to the direct parent session only.

## Best Possible Solution

Define one narrow parent-only send contract derived from canonical active sub-agent metadata, then update policy, resolver, delivery, docs, and security regression tests together.

## Solution Assessment

Yes in direction, but not as a broad opt-in to ordinary `sessions_send`. The maintainable solution is a dedicated parent-only operation or trusted parent selector backed by active run metadata and security tests.
