## Summary

Keep this PR open for a browser-relay owner decision: the patch is technically coherent and well-proven, but intentionally changes the relay’s omitted-parameter CDP compatibility policy, which automation should not approve on maintainer intent alone.

## What This Changes

The PR makes direct-CDP and extension-relay automation tabs open in the background by default while preserving explicit foreground, tab-focus, and window-focus requests.

## Best Possible Solution

Keep the direct-CDP background behavior and merge the relay behavior only after an owner explicitly confirms that omitted relay requests represent OpenClaw automation; otherwise add an OpenClaw-owned signal that preserves raw CDP omission semantics for generic relay clients.
