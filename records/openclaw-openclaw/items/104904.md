## Summary

The latest head resolves the two prior tool-compatibility findings and has convincing live Groq proof, but it still silently caps every implicit `llama-3.3-70b-versatile` request to 1,024 output tokens, including higher-limit accounts that would have accepted the existing model budget. ## What This Changes

The PR adds a Groq model-specific 1,024-token implicit budget and retries a narrowly matched TPM HTTP 413 once without tool fields, while leaving explicit token budgets unchanged.

## Best Possible Solution

Preserve the existing implicit output budget on the first tool-capable request, then apply the 1,024-token budget together with tool removal only during the narrowly matched TPM-413 fallback; explicit budgets and other Groq models should remain untouched.
