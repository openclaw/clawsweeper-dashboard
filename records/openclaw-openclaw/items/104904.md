## Summary

This PR fixes the reported Groq 12K-TPM failure and the refreshed head resolves the prior explicit-budget tool regression, but it still silently makes every implicit `llama-3.3-70b-versatile` turn chat-only. Groq limits are organization-specific and the model supports local tool use, so the global default capability change is broader than the reported base-tier bug and should not merge without a compatibility-preserving design or explicit provider-owner approval.

## What This Changes

The branch injects a 1,024-token default for implicit `groq/llama-3.3-70b-versatile` requests, removes tool fields only for that injected default, and adds focused tests that explicit token budgets retain tools.

## Best Possible Solution

Preserve normal tool-capable requests and add a provider-owned recovery path for the specifically classified oversized-request failure, then prove both normal tool use and base-tier recovery live.
