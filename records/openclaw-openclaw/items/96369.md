## What This Changes

The PR changes `extensions/google/cli-backend.ts` so the existing `google-gemini-cli` backend runs `agy` via stdin/text output with `--dangerously-skip-permissions` instead of invoking `gemini` with stream-json argv/resume args.

## Best Possible Solution

Keep the current Gemini CLI backend intact, handle long prompts with a tested stdin or arg-length fallback if needed, and add `agy` only through a separate maintainer-approved Antigravity backend such as the canonical linked work.
