## Summary

Keep open: current main and v2026.6.11 still hard-code envelope and system-event dates to ISO order, and the requested configurable date display is a real but product-sensitive config expansion.

## What This Changes

The issue requests an `agents.defaults.dateFormat` option for UK, US, ISO, or locale-style human-facing envelope and system-event dates.

## Best Possible Solution

Maintainers should decide the public date-display contract; if accepted, implement a default-preserving enum in the shared human-facing timestamp formatter, wire only envelope/system-event display first, update schema/docs/tests, and leave machine timestamps and filenames ISO.
