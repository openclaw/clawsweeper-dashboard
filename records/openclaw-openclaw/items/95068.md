## What This Changes

## Best Possible Solution

Maintainers should decide the display-date contract first; if accepted, implement it once in shared timestamp formatting, thread it through envelope, system-event, and LLM-boundary callers, update schema/help/docs/tests, and keep filenames and machine-readable timestamps ISO.

## Solution Assessment

Unclear until maintainers confirm the product contract. Reusing the shared formatter is the clean implementation path if accepted, but ISO-only behavior, locale-based behavior, or a narrower scope may be preferable to adding another config key.
