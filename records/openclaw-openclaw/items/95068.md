## Best Possible Solution

Maintainers should decide the date-display contract first; if accepted, implement it once in the shared timestamp formatter, thread it through envelope/system-event callers and config schema/help/docs/tests, and keep filenames plus `timestampUtc` fields ISO.

## Solution Assessment
