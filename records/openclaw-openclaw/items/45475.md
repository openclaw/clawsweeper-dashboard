## Summary

Keep open: current main and v2026.6.11 still route Slack `message_changed` and `message_deleted` through session-scoped system events, while the requested `ignoreSubtypes` config key is absent. The remaining work needs a maintainer product/config decision rather than cleanup closure.

## What This Changes

The issue requests an opt-in Slack channel config key that drops selected Slack message subtypes before they wake an agent session.

## Best Possible Solution

A maintainer-approved Slack edit/delete event policy; if accepted, add a narrow opt-in Slack plugin config field with schema, docs, and regression tests that drops only approved subtypes before session context is queued.
