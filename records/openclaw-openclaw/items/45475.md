## Summary

Keep open: current main and the latest release still map Slack `message_changed` and `message_deleted` into session-scoped system events, and the requested `ignoreSubtypes` config key is not present. The remaining work is a maintainer product/config decision, especially because prior broad-ignore PRs were closed as too broad for the Assistant DM path.

## What This Changes

The issue requests a Slack channel `ignoreSubtypes` config key that can drop selected Slack message subtype events before they wake agent sessions.

## Best Possible Solution

If maintainers accept the direction, add an opt-in Slack-owned suppression list that preserves current defaults and the Assistant DM exception, with schema/types/docs and focused monitor tests proving ignored subtypes do not enqueue system events.
