Requested Slack channel configuration to ignore selected Slack message subtypes before they wake agent sessions.

## Best Possible Solution

Maintainers should decide the Slack edit/delete event policy; if approved, add a narrow Slack plugin config field with schema, docs, and regression tests that drops only approved subtype system events before session wake.
