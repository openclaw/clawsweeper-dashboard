## Summary

Keep open: current main and v2026.6.11 still route Slack `message_changed` and `message_deleted` through the session-scoped system-event queue, and the requested `ignoreSubtypes` config key is not present. Older broad-ignore PRs were closed, so the remaining request needs a maintainer policy/config decision rather than cleanup closure.

## What This Changes

The issue requests a Slack channel `ignoreSubtypes` config key that drops selected Slack edit/delete subtypes before they enter session context.

## Best Possible Solution

A maintainer-approved Slack edit/delete event policy; if accepted, add a narrow opt-in Slack plugin config field with schema, docs, and regression tests that drops only approved subtypes before session context is queued.
