## Summary

Keep open: current main and the latest release still handle Slack edit/delete subtypes as session-scoped system events, while the requested ignoreSubtypes config key is absent. The remaining work is a valid Slack config and event-policy decision, not cleanup closure.

## What This Changes

The issue requests a Slack channel config key that can suppress message_changed and message_deleted events before they wake an agent session.

## Best Possible Solution

A maintainer-approved Slack edit/delete event policy; if accepted, add a narrow opt-in Slack plugin config field with schema, docs, and regression tests that drops only selected edit/delete subtypes before session context is queued.
