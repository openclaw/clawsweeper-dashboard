## Summary

Keep open: current main still queues authorized Slack edit/delete subtype events as session-scoped system events and has no `ignoreSubtypes` config key; the remaining work is a product/config decision, not cleanup closure.

## What This Changes

Request adds a Slack channel `ignoreSubtypes` config key so selected Slack `message_changed` and `message_deleted` events are dropped before they wake an agent session.

## Best Possible Solution

A maintainer-approved Slack edit/delete event policy; if accepted, add a narrow opt-in Slack plugin config field with schema, UI hints, docs, and regression tests that drops selected edit/delete subtypes before session context is queued.
