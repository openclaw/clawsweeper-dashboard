Keep open. Current main still does not implement a provider-level `enabled` contract, and the two related implementation PRs are closed unmerged, so this remains a real but product-sensitive config feature request.

## What This Changes

The issue requests `models.providers.<provider>.enabled?: boolean` so a configured model provider can be temporarily disabled without deleting its config block.

## Best Possible Solution

Add a maintainer-approved provider-level disabling contract that defaults to active and is honored consistently by schema/help, models.json generation, configured model cataloging, fallback selection, and models status output.
