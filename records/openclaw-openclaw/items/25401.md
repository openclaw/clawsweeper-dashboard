The issue requests an optional `models.providers.<id>.enabled` flag that preserves provider config while excluding disabled providers from model resolution, fallback lists, and status output.

Approve one shared provider eligibility contract that defaults omitted values to enabled and consistently gates schema, models.json planning, fallback, catalog/listing, status/probe output, docs, and focused tests.
