## What This Changes

Add an optional `models.providers.<id>.enabled` flag so operators can temporarily disable a configured model provider without deleting its saved config.

## Best Possible Solution

Approve one shared provider eligibility contract that defaults omitted values to enabled and consistently gates schema, models.json planning, fallback, catalog/listing, auth/probe visibility, status output, docs, and focused tests.
