## What This Changes

Add an optional `models.providers.<id>.enabled` flag so users can temporarily disable a configured model provider without deleting its config.

## Best Possible Solution

Approve and implement one documented provider-level `enabled?: boolean` contract that defaults to enabled, preserves disabled config blocks, excludes disabled providers from model generation/catalog/fallback/status/probe use, and adds focused schema, planning, fallback, catalog, status, and docs coverage.
