## What This Changes

Fix deferred browser-panel screenshot, inspection, metrics, and wheel operations so they remain bound to the captured Gateway connection, tab, document, and latest operation after navigation or reconnection.

## System Context

The Control UI browser panel sends tab-scoped operations through the OpenClaw Gateway and applies their deferred results back into the active browser view. A target-ownership check must reject results whose captured connection, tab, document, or operation sequence no longer matches the current view.
