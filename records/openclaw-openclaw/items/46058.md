Keep open: current main has stronger Android Chat/Talk entry points and the merged overview refresh partially helps, but the official app still defaults to the Home/Overview shell and is documented as a Gateway-required companion node. ## What This Changes

The issue asks maintainers to discuss an official chat-first Android surface or selective upstreaming of focused Android UX, connectivity, and media improvements from an independent fork.

## Best Possible Solution

Android owners should define the official launch/navigation and media/connectivity scope first, then invite separate proof-backed PRs for chat entry, richer media handling, and Tailscale/connectivity improvements.
