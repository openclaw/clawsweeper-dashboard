## What This Changes

The issue requests that custom MCP tools configured for an agent be discoverable and callable from Discord-triggered runs in the same way they are from the CLI.

## System Context

Discord messages enter the channel gateway and launch an embedded agent run; that run resolves its tool set, including configured MCP servers, before the model can search for and call a tool. The same agent/tool configuration can also be invoked through the CLI, so a discrepancy could arise in channel-to-agent selection, configuration resolution, tool policy, sandboxing, or model tool discovery rather than in Discord transport alone.
