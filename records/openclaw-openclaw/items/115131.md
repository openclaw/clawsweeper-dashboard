## What This Changes

This PR adds exact-pinned `@lit/task` and replaces selected Control UI read-request counters, abort controllers, loading flags, and stale-result guards with Lit Task lifecycle management across chat, setup, usage, plugins, sessions, memory-import, MCP app, and worktree views.

## System Context

The Control UI renders Gateway-backed pages and components that issue asynchronous read RPCs as connection, route, and user-selection inputs change. This PR moves selected read lanes from component-specific cancellation and stale-result logic into Lit Task, which supplies argument-keyed reruns, cancellation signals, and pending/complete/error state for rendering.

  D --> E[Task lifecycle state]

  C --> G[Superseded request cancellation]

## Best Possible Solution

Keep Task limited to read lanes, preserve the existing mutation and streaming guards, and add redacted browser or terminal-backed proof that deliberately resolves an older Gateway request after a newer selection while the UI continues to display only the newer state.
