## What This Changes

The PR makes Control UI chat model, reasoning, speed, and context controls resolve `main` and `agent:main:main` as the same default session while preferring an exact row and preserving other agents’ isolation.

## System Context

The Control UI receives session rows and defaults from the Gateway, then uses the selected session to render chat controls and send optimistic settings updates. This change centralizes default-session alias resolution so display state and optimistic updates operate on the same intended session row.
