## What This Changes

The PR makes Web UI chat controls resolve `main` and `agent:main:main` as the same default session while preferring an exact row, so persisted model, reasoning, speed, and context settings remain isolated and update the visible row correctly.

## System Context

The Control UI receives a selected chat session key and a Gateway-provided session list, then derives model, reasoning, speed, and context controls from the matching session. Those controls optimistically patch the selected session and send updates through the Gateway session-settings lane.
