## Summary

Keep open. Current main already covers the heartbeat phase-spreading part and cron-expression top-of-hour staggering, but cron every schedules still have no prime, phase, or jitter public contract, so the remaining work needs maintainer product/API direction rather than cleanup closure.

## What This Changes

The issue requests prime-derived heartbeat and cron every scheduling plus deterministic per-agent phase jitter to reduce synchronized scheduling bursts.

## Best Possible Solution

Keep the shipped heartbeat phase spreading and cron-expression stagger, then choose one canonical cron every phase/stagger/prime contract with schema, CLI, persistence, docs, and upgrade tests before implementation.
