## Summary

Keep open. Current main already covers deterministic heartbeat phase spreading and cron-expression top-of-hour staggering, but the requested public prime/phase/jitter contract for cron `every` schedules is still missing and needs maintainer product direction.

## What This Changes

Request prime-derived cadence and deterministic phase jitter controls for heartbeat and cron `every` schedules to reduce synchronized request spikes.

## Best Possible Solution

Keep the shipped heartbeat phase spreading and cron-expression stagger, then decide one canonical cron `every` phase/stagger/prime contract with schema, CLI, persistence, docs, and upgrade tests before implementation.
