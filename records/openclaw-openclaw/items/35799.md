## Summary

Keep open. Current main already has shipped stable per-agent heartbeat phase spreading and cron-expression top-of-hour staggering, but cron `every` remains an anchored fixed-interval schedule and the requested prime/phase/jitter public contract is still missing from config, CLI, docs, and protocol surfaces.

## What This Changes

The issue requests optional or default prime-derived heartbeat and cron `every` cadence plus deterministic phase jitter to reduce synchronized scheduling spikes.

## Best Possible Solution

Keep the shipped heartbeat phase spreading and cron-expression stagger, then choose one canonical cron `every` phase/stagger/prime contract with schema, CLI, persistence, docs, upgrade tests, and explicit default/compatibility behavior before implementation.
