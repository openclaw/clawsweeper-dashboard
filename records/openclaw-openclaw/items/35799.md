## Summary

Keep open. Current main and the latest release already spread heartbeat runs with a stable per-agent phase and stagger top-of-hour cron expressions, but cron `every` schedules are still fixed anchored intervals with no prime/phase/jitter public contract, so the remaining work needs maintainer product direction.

## What This Changes

Request to add prime-derived heartbeat and cron `every` cadence plus deterministic per-agent phase jitter to reduce synchronized scheduler traffic spikes.

## Best Possible Solution

Keep the shipped heartbeat phase spreading and cron-expression stagger, then choose one canonical cron `every` phase/stagger/prime contract with schema, CLI/RPC, persistence, docs, and upgrade tests before implementation.
