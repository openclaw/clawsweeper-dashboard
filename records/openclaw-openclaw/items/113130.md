## What This Changes

Normalize nested MCP tool schemas for native Moonshot/Kimi chat-completions requests so parent-level `anyOf` constraints do not cause the provider to reject the entire tool-enabled request.

## System Context

MCP servers contribute JSON Schema tool definitions to an OpenClaw agent run. Provider-specific conversion then prepares those tools for the selected model endpoint; Moonshot rejects one otherwise valid nested union form before the model can process the request.
