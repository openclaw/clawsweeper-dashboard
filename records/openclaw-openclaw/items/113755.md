## What This Changes

This PR adds a doctor migration warning when a retired WhatsApp acknowledgement setting for direct messages plus mentioned groups cannot be represented by the current shared acknowledgement scope.

## System Context

OpenClaw Doctor rewrites retired channel configuration into the current shared `messages` acknowledgement settings. Channel runtimes then read that shared scope to decide whether inbound direct or group messages receive an acknowledgement reaction.
