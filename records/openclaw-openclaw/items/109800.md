## Summary

Keep open: current main still reads piped model-auth input without a size bound, while this focused patch appears correct and the updated terminal transcript resolves the prior proof blocker. 

## What This Changes

The PR adds a 1 MiB streaming limit for piped model-auth secrets and regression coverage that rejects oversized input before auth-profile mutation.

## Best Possible Solution

Keep one bounded reader at the model-auth command boundary, preserve direct-argument and TTY behavior, and retain regression coverage proving oversized input cannot reach either shared auth mutation path.

## Solution Assessment

Yes. Enforcing the bound while reading, inside the existing shared model-auth stdin helper, is narrower and safer than adding provider-specific checks or validating only after the entire input has been buffered.
