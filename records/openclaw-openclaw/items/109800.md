The PR replaces unbounded string accumulation for piped model-auth secrets with byte-counted Buffer collection capped at 1 MiB, plus a regression test that verifies no auth mutation occurs after rejection.

## Best Possible Solution

Land the bounded streaming read with its explicit error and regression guard, preserving ordinary TTY, direct-argument, and sub-limit piped authentication flows.
