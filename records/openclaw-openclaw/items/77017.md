## What This Changes

Adds 300-pixel authenticated thumbnail previews and Open, Download, and Copy controls for managed generated images in Control UI chat, with fallback across existing Control UI authentication candidates.

## System Context

The Gateway persists generated assistant images as managed media and authorizes requests for their bytes. Control UI fetches those bytes into browser Blob URLs for chat previews and full-image actions, then passes the selected image to the lightbox.
