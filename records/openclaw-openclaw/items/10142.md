## What This Changes

The issue requests a new internal `session:end` hook event for session completion so external workflow systems can react without agent-authored workaround commands.

## Best Possible Solution

Maintainers should choose one supported session-completion contract: add a narrow internal `session:end` event with docs and tests across completion paths, or explicitly document typed plugin `session_end` as the supported replacement and close the partial implementation path.

## Reproduction Assessment

## Solution Assessment
