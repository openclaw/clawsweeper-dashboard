## Summary

Keep open for a maintainer lifecycle-contract decision. Current main has no internal `session:end` event, while the existing typed plugin hooks cover nearby but materially different run, reset, and subagent lifecycles; the open reset-focused PR should not be treated as the implementation of this requested contract.

## What This Changes

Add an internal `session:end` hook so external workflow systems can react when an agent session completes.

## Best Possible Solution

Choose and document one supported workflow-completion contract: prefer a ClawHub-distributed code plugin using the existing typed lifecycle hooks when its semantics fit, or sponsor one additive internal event with a precise terminal-state, ordering, payload, and coverage contract across persistent sessions, cron, and subagents.
