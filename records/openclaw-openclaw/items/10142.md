Keep open: current main and the latest release still lack the requested internal `session:end` HOOK.md event. The issue requests a new internal `session:end` hook event for session completion so external workflow systems can react without agent-written cleanup commands.

## Best Possible Solution

Make an explicit maintainer API decision: either add a typed internal `session:end` event with docs and completion-path tests, or document typed plugin `session_end` as the supported workflow-integration surface and close this internal-hook request.
