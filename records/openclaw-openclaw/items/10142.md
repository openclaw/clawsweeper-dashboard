Add an internal `session:end` hook event that fires when a session completes so operator hooks can signal workflow systems without relying on agent instructions.

## Best Possible Solution

Maintainers should choose and document the supported lifecycle contract: either add a narrow internal `session:end` event with completion-path tests, or explicitly bless typed plugin `session_end` as the supported replacement in internal hook guidance.

## Reproduction Assessment
