## What This Changes

Add an internal `session:end` hook event emitted when an agent session completes so external workflow systems can react without agent-instruction workarounds.

## Best Possible Solution

Maintainers should either bless and document typed plugin `session_end` as the supported workflow-completion surface, or approve a focused internal `session:end` contract with coverage across the relevant session completion paths.
