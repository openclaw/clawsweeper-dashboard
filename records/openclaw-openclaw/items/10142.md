## Summary

Keep open: current main still lacks an internal `session:end` event, while the existing typed `agent_end` and `session_end` plugin hooks are separate contracts; the open linked PR only covers daily/idle reset behavior and does not implement general session completion. ([docs.openclaw.ai](https://docs.openclaw.ai/automation/hooks))

## What This Changes

Requests an internal `session:end` hook that signals external workflow systems when an agent session completes.

## Best Possible Solution

Define `agent_end` as the task/run-completion contract and `session_end` as the persisted-session lifecycle contract, then either document a small plugin/hook-pack path for workflow signaling or add a narrowly defined internal event only if maintainers explicitly want HOOK.md parity.
