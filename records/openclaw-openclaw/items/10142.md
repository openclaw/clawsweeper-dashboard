## What This Changes

Request to add an internal `session:end` hook event that fires when sessions complete for workflow orchestration integrations.

## Best Possible Solution

Maintainers should choose one supported session-completion contract: add a narrow internal `session:end` event with docs and tests across completion paths, or explicitly document typed plugin `session_end` as the supported replacement.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 expose `session:patch` internally and `session_end` as a typed plugin hook, but no documented or typed internal `session:end` event exists.

## Solution Assessment

Unclear. Adding the internal event is plausible, but the existing typed plugin `session_end` surface may be the better long-term contract, so maintainers should decide before implementation.
