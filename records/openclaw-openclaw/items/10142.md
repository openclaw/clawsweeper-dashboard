## Summary

Keep open: current main still lacks the requested internal `session:end` hook event, while the existing `session_end` lifecycle hook is a separate typed plugin surface and the linked open PR only covers a partial reset-hook slice.

## What This Changes

Request to add an internal `session:end` hook event that fires when an agent session completes so workflow orchestrators can react without agent-authored cleanup commands.

## Best Possible Solution

Define one supported session-completion extension contract: either add and document a typed internal `session:end` event across reset, cron, subagent, and shutdown-like completion paths, or explicitly document typed plugin `session_end` as the supported replacement for workflow integrations.
