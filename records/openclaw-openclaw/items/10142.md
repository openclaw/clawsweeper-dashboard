## Summary

Keep open: current main still lacks the requested internal `session:end` hook event, while the existing `session_end` surface is a typed plugin lifecycle hook. The linked open pull request is relevant but explicitly does not add new hook event names, so maintainers still need to settle the hook API boundary before this issue can close.

## What This Changes

Request adds an internal `session:end` hook event that fires when a session completes so external workflow systems can react without agent-authored cleanup commands.

## Best Possible Solution

Maintainers should either define and wire a documented internal session-completion hook across the intended completion paths, or explicitly document the typed plugin `session_end` hook as the supported replacement and close this internal-hook request after that decision.
