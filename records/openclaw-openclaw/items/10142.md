## Summary

Keep open: current main still lacks the requested internal `session:end` HOOK.md event. The existing `session_end` lifecycle surface is a typed plugin hook, and https://github.com/openclaw/openclaw/pull/61675 is still open, dirty, and only partially overlaps the broader internal hook request.

## What This Changes

The issue requests a new internal `session:end` hook event that fires when an agent session completes so external workflow orchestration can react without agent-authored CLI commands.

## Best Possible Solution

Maintainers should choose and document the supported lifecycle contract: add a narrow internal `session:end` event with completion-path tests, or document typed plugin `session_end` as the supported replacement and close this request after that decision.

## Reproduction Assessment

Yes, at source level: current main exposes internal `session:patch` and typed plugin `session_end`, but no documented or typed internal `session:end` event exists.

## Solution Assessment

Unclear. Adding an internal event is plausible, but the existing typed plugin `session_end` surface may be the better owner, so maintainers should decide the supported hook contract before implementation.
