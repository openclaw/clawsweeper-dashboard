## What This Changes

The issue requests a new internal `session:end` hook event for session-completion automation such as workflow orchestration signals.

## Best Possible Solution

Maintainers should choose and document the supported contract: either add a narrow internal `session:end` event with coverage across completion paths, or explicitly declare typed plugin `session_end` the supported replacement for this use case.

## Reproduction Assessment

## Solution Assessment

Unclear. Adding an internal event is plausible, but the existing typed plugin `session_end` surface may be the better contract, so maintainers should decide before implementation.
