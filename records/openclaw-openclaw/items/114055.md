## What This Changes

The PR removes numeric `execution.profiles` indexes from QA scenario YAML, defines curated default scenario lists in channel runners, and replaces the bounded smoke profile with the named `smoke-ci` scenario pack.

## System Context

QA Lab reads scenario YAML for executable behavior and eligibility, then channel runners choose their default scenario IDs for live QA. The CI smoke planner selects a named pack, checks it against taxonomy and provider/channel eligibility, and divides it into four bounded jobs.
