The branch makes chat tool/activity disclosure rows text-selectable, ignores selection-originated pointer clicks, removes redundant error badges, adds an empty failed-tool detail, and updates related UI tests.

## Best Possible Solution

## Reproduction Assessment

## Solution Assessment

Yes. A shared selection-aware disclosure helper applied to both standalone and grouped tool rows is the narrow maintainable fix, and the badge removal keeps existing error classes, labels, icon treatment, and explicit failed-output detail.
