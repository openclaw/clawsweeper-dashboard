## What This Changes

This PR teaches agents to use Markdown `<details>` disclosures for optional reply depth only when the active Telegram rich-message account or Control UI webchat advertises native support, and documents the resulting fallback behavior elsewhere.

## System Context

Runtime channel capabilities flow into the agent system prompt before the model writes a reply. Telegram and the internal Control UI can advertise native disclosure support; the prompt should only encourage collapsible details on those surfaces so other channels retain their existing visible-content behavior.
