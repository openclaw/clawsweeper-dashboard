- **[P2] Bound redirect-body cancellation:** `src/infra/net/fetch-guard.ts:666`
  - body: `fetchImpl` is an injectable runtime contract, but this direct await has no bound and does not race the combined abort signal. If `cancel()` never settles, redirect rejection or continuation never reaches `release()`/`closeDispatcher()`, so a malformed response can leave guarded fetch stuck indefinitely. Keep cancellation non-fatal while coupling it to the existing bounded dispatcher cleanup or another explicit bound.
  - confidence: 0.97
- **[P2] Make the socket test require body cancellation:** `src/infra/net/fetch-guard.integration.test.ts:90`
  - body: The zero-socket assertion also passes through the old implementation because every tested rejection calls `release(dispatcher)`, whose bounded close path destroys the dispatcher and closes the tracked socket. Add an assertion or harness that specifically fails when the response body is not cancelled; otherwise this integration test does not prove the regression it claims to cover.
  - confidence: 0.96
