## Summary

Keep this PR open for a focused repair: eager loading, additive persistence, and protocol ownership are sound, but the current head presents stale tool information as live activity. The protected `maintainer` label also rules out automated cleanup closure.

## What This Changes

The PR eagerly loads chat background tasks, persists tool-use metadata in the task ledger, exposes it through task summaries, and renders elapsed time, tool counts, and tool names in the Control UI rail.

## Best Possible Solution

Model active tool calls by `toolCallId` and clear or select the remaining active call on completion; if only historical activity is intended, rename the protocol field and UI wording to explicitly mean the most recent tool.
