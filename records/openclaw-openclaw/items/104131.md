## Summary

This PR correctly adds background exec sessions to suspension accounting, but its restart fix stops at diagnostic preflight: the callback that actually gates SIGUSR1 emission still omits those sessions, so restart can still terminate the work the PR intends to protect.

## What This Changes

The PR adds a sanitized background-exec count to Gateway active-work snapshots, suspension blockers, restart preflight results, the suspension protocol, and related tests.

## Best Possible Solution

Include running background exec sessions in the callback registered with `setPreRestartDeferralCheck`, then add execution-level coverage proving the restart signal remains withheld until the session exits while preserving explicit bypass and timeout behavior.
