## Summary

Keep open: current main and the latest release still generate the macOS app LaunchAgent environment with only PATH, while the macOS app resolves its active profile from OPENCLAW_CONFIG_PATH and OPENCLAW_STATE_DIR. The open linked PRs at https://github.com/openclaw/openclaw/pull/99739 and https://github.com/openclaw/openclaw/pull/99752 are active fix candidates, not closure reasons.

## What This Changes

The issue requests preserving OPENCLAW_CONFIG_PATH and OPENCLAW_STATE_DIR in the macOS app LaunchAgent created by Launch at Login.

## Best Possible Solution

Land one narrow macOS LaunchAgent fix that preserves non-empty OPENCLAW_CONFIG_PATH and OPENCLAW_STATE_DIR, keeps PATH behavior, escapes plist values safely, and adds focused Swift coverage plus macOS launchd proof.

## Reproduction Assessment
