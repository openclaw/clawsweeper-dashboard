## What This Changes

The PR rejects duplicate, prototype-shaped, and unsupported JSON fields in model-backed automatic command-review responses so ambiguous responses fall back to human confirmation.

## System Context

OpenClaw's optional automatic execution reviewer receives a command and a model decision, then chooses either a one-time automatic approval or human confirmation. This change hardens the model-response parsing boundary before that decision reaches gateway, node, and local execution paths.
