## Summary

Keep open: current main mitigates the doctor false-orphan comparison, but the session resolver still returns and persists realpath-backed transcript paths for symlinked session directories, and an open fork PR still references this issue as the fix candidate.

## What This Changes

The issue reports that symlinked OpenClaw state/session directories can persist realpath-backed session transcript paths, making session metadata non-portable and previously causing false doctor orphan warnings.

## Best Possible Solution

Land or adopt an upstream fix that preserves caller-visible logical session paths while retaining realpath containment checks and doctor canonical comparison coverage, then close this issue after the target repository contains the fix.
