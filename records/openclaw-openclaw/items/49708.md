## Summary

## What This Changes

The issue reports that symlinked OpenClaw state directories cause session transcript paths to be stored with real paths, which can break portability and make doctor report false orphan transcripts.

## Best Possible Solution

Land or replace the linked candidate with a narrow resolver fix that keeps realpath containment checks while persisting caller-visible logical session paths and retaining doctor legacy-realpath coverage.
