## What This Changes

The issue asks OpenClaw to preserve logical session transcript paths for symlinked state directories and avoid false doctor orphan reports.

## Best Possible Solution

Land or adopt a target-repository fix that returns caller-visible logical session paths while retaining realpath containment checks and the existing doctor canonical comparison coverage.
