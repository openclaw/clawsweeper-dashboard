## Summary

Keep open: current main and the latest release still return and persist session paths anchored to the realpath of a symlinked sessions directory. The doctor comparison is now symlink-aware, but the storage/portability half remains and an open fork PR is still the candidate implementation path.

## What This Changes

The issue asks OpenClaw to preserve logical session transcript paths when the state directory is reached through a symlink and to avoid doctor false-positive orphan reports.

## Best Possible Solution

Land or adopt a target-repo fix that returns caller-visible logical session paths while retaining realpath containment checks and the existing doctor canonical comparison coverage.

Yes, the narrow maintainable fix is to separate realpath containment from the returned logical path, keep the doctor canonical comparison, and cover symlinked session directories with regression tests.
