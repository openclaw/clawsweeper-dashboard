## Summary

Keep open: current `main` has fixed the doctor-side comparable-path check, but the session resolver still returns and persists realpath-backed `sessionFile` values when the sessions directory is reached through a symlink. A linked open fix candidate targets the remaining resolver/test work, so this issue should wait for that path to land or be closed explicitly.

## What This Changes

The issue asks OpenClaw to preserve logical session transcript paths under symlinked state directories and avoid false doctor orphan reports.
