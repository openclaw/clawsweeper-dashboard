## Summary

Keep this PR open for revision: the latest head correctly restores faithful shared transport forwarding, but its lifecycle-level cap still silently changes the direct CLI contract, which currently accepts larger values that the live ClawHub API honors. The remaining product-contract choice and missing real CLI proof prevent a merge-ready verdict.

## What This Changes

The PR caps and normalizes ClawHub skill-search limits in `searchSkillsFromClawHub`, preserves verbatim forwarding in shared ClawHub transport helpers, and adds boundary-focused tests.

## Best Possible Solution

Keep shared transport policy-free, retain the Gateway's existing 1–100 schema contract, and either preserve larger direct CLI limits or introduce an explicit, documented CLI validation error only after the feature owner approves that contract and live CLI proof demonstrates the intended behavior.
