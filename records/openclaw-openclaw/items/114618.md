## What This Changes

This PR classifies Node’s `ERR_REQUIRE_ESM_RACE_CONDITION` as an existing native-plugin-loader fallback condition so affected ESM plugins can retry through OpenClaw’s source-transform loader.

## System Context

During Gateway startup or restart, OpenClaw resolves installed plugin entry modules through a native module-loading path. Eligible ESM-loading failures are handed to a source-transform loader; that decision determines whether the plugin loads and the Gateway can become healthy.
