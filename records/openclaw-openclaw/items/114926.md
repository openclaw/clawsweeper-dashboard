## What This Changes

This PR clears only the failed CLI session binding after retryable or terminal CLI failures, preserving concurrent replacements and avoiding replay after generated-media side effects.

## System Context

Inbound channel turns select a CLI candidate using the conversation’s persisted CLI session binding, then run the selected provider. The recovery callbacks coordinate the runner, in-memory session entry, and persisted session store so a dead binding is cleared before a fresh session can be used.
