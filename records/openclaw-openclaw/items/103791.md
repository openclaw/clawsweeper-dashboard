## What This Changes

The PR makes bundled provider-policy lookup return no surface for path-like provider IDs, preserves strict loader validation, and adds regression coverage for colon-, slash-, and traversal-like values.

## Best Possible Solution

Preserve this shared resolver-boundary guard and strict loader validation, then land it after a redacted live gateway run demonstrates that `sessions_list` succeeds for a custom provider with an `org/model` ID while a normal bundled provider still resolves its policy surface.
