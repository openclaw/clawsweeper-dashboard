Keep this PR open: the implementation appears focused and correct, but the external-PR real-behavior proof gate remains unmet because the submitted evidence only exercises tests rather than the affected live gateway workflow.

## What This Changes

The PR makes the direct bundled provider-policy resolver return no surface for path-like provider IDs, extracts the bundled-directory-name predicate, and adds regression coverage.

## Best Possible Solution

Provider-policy resolution should treat IDs that cannot represent bundled directories as having no bundled policy surface while retaining strict loader validation, backed by regression coverage and redacted live gateway proof of the affected session-list path.

## Maintainer Decision

## Reproduction Assessment

Yes from source inspection: a colon- or slash-containing provider ID reaches strict bundled-directory normalization and throws on current main. The failing-first regression independently supports that path, although no live gateway reproduction was run during this review.

## Solution Assessment

Yes. Guarding the shared direct bundled resolver is narrower and more maintainable than weakening filesystem-path validation, and it covers the shared provider-policy callers without adding compatibility or configuration surface.
