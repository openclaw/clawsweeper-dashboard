## Summary

Keep open: current main and the latest release still route Telegram bare URLs through the HTML renderer that escapes ampersands in both href attributes and visible auto-link labels, and no duplicate or merged fix owns the Telegram-specific behavior.

## What This Changes

The issue requests a Telegram formatting fix so bare auto-linked URLs with multiple query parameters navigate with raw query separators instead of literal `&amp;`.

## Best Possible Solution

Fix the Telegram outbound HTML path so auto-linkified bare URL labels and hrefs produce a tappable destination matching the raw query parameters, with focused regression tests and live Telegram proof, while preserving Telegram's required HTML escaping for ordinary text and labeled links.

Do not add a config option or broad channel policy change.
