## Summary

Keep open: this is a protected maintainer bug and current main still has the scheduling shape that can run flow Gateway partitions alongside script-backed Docker/package-prep work. The linked Docker-scenario PR exposes the race, but it is not the orchestration fix.

## What This Changes

The issue asks QA Smoke to isolate script-backed Docker/package-prep scenarios so they cannot rewrite shared `dist/` artifacts while flow scenario Gateways are starting or running.

## Best Possible Solution

Add a focused QA suite orchestration guard that serializes dist-mutating script/Docker package preparation away from flow Gateway partitions, with regression coverage for the mixed flow-plus-script selection.

## Reproduction Assessment

Yes, source-level and CI-backed. The exact-head QA Smoke job shows missing `dist` modules, and current main source shows QA Smoke can run unified flow and script/test-file partitions concurrently at `--concurrency 8`.

## Solution Assessment

Yes, the best fix is the separate orchestration isolation requested here, not reverting the linked Docker scenario coverage or adding a new config knob.
