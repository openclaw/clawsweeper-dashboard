## What This Changes

The issue requests renaming Chinese locale identifiers from `zh-CN`/`zh-TW` to `zh-Hans`/`zh-Hant` across runtime locale types, generated artifacts, detection, docs, saved preferences, and display names.

## Best Possible Solution

Decide the canonical locale-ID policy first, then land one coordinated migration across Control UI, CLI wizard, generated i18n artifacts, docs, workflows, tests, and old saved-value handling.
