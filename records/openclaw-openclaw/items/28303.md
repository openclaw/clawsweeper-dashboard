## What This Changes

Request renames Chinese locale identifiers from `zh-CN` and `zh-TW` to `zh-Hans` and `zh-Hant` across locale types, files, detection, display, docs, and saved preferences.

## Best Possible Solution

Decide the canonical locale-ID policy first, then land one coordinated migration across Control UI, CLI wizard, docs/app mappings, generated i18n artifacts, tests, and old saved-value handling.

- **Approve coordinated script-code migration (recommended):** Make `zh-Hans` and `zh-Hant` canonical and require one migration PR that updates runtime, docs, generated artifacts, tests, and old-value handling together.
