The issue requests renaming Chinese locale identifiers from `zh-CN`/`zh-TW` to `zh-Hans`/`zh-Hant` across locale types, bundles, detection, storage migration, docs, and display surfaces.

## Best Possible Solution

Decide the canonical Chinese locale-ID contract first, then migrate Control UI, CLI wizard, docs publish metadata, generated i18n artifacts, tests, docs, and saved preference handling in one compatibility-aware change.
