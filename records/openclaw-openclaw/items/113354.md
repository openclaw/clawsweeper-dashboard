## What This Changes

The branch adds a Codex OAuth WebRTC fallback for browser and iOS GPT Live Talk when no OpenAI Platform realtime credential is configured, including a Codex app-server offer broker, bounded conversation context, and transcript integration.

## System Context

Talk asks the Gateway to select a realtime provider and create a browser WebRTC session. When direct OpenAI Platform authentication is unavailable, this branch lets the bundled Codex plugin broker a one-time SDP exchange through Codex app-server, then maps the resulting realtime transcript into the active Talk session.
