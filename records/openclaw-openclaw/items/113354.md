## What This Changes

Adds an internal Codex OAuth fallback for browser and iOS OpenAI Realtime Talk, using a one-time Gateway SDP exchange when no OpenAI Platform credential is configured, while retaining the Platform-key route as first choice.

## System Context

Talk asks the Gateway to select a realtime provider and create a browser session, then browser or iOS clients exchange WebRTC SDP with that provider. This change lets the bundled OpenAI provider use a bundled Codex app-server session for OAuth-only browser Talk, then returns audio and transcript events to the active OpenClaw session.
