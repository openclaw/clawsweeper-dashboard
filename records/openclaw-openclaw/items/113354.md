## What This Changes

This PR adds an experimental fallback that lets browser and iOS Talk use the active ChatGPT/Codex OAuth session through a Codex app-server WebRTC broker when no OpenAI Platform realtime credential is configured.

## System Context

Browser and iOS Talk ask the Gateway to create a realtime voice session through a registered provider.
