## Summary

Keep this PR open for explicit maintainer sponsorship and real browser-runtime proof. The branch deliberately avoids the previously unsupported direct OAuth-to-public-Realtime path, but it adds an experimental configuration mode and a public plugin-SDK broker contract that need an owner decision before merge.

## What This Changes

This PR adds an explicit experimental OpenAI Talk authentication mode that lets browser WebRTC sessions use the Gateway’s existing Codex OAuth login through a bundled Codex-plugin SDP broker.

## System Context

Browser Talk asks the Gateway to create a realtime voice session, then the selected provider returns the WebRTC connection details the Control UI uses. This PR inserts a Codex-plugin broker for the OpenAI provider so the browser exchanges SDP with the plugin while the Codex app-server retains OAuth control and receives bounded session context.
