## What This Changes

The branch lets browser and iOS GPT Live Talk use the Gateway’s logged-in Codex OAuth session through a one-time WebRTC offer broker when no OpenAI Platform realtime credential is configured.

## System Context

Talk’s browser and iOS clients ask the Gateway to create a realtime WebRTC session. The OpenAI Talk provider normally uses Platform credentials, while this change lets the bundled Codex runtime supply a bounded OAuth-backed browser session and return transcript events to the active Talk session.
