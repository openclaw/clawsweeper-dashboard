## What This Changes

The branch lets browser and iOS GPT Live Talk use an active Codex OAuth session through a one-time Gateway WebRTC broker when no OpenAI Platform realtime credential is configured.

## System Context

Talk asks the selected realtime provider to create a browser WebRTC session, then the Control UI or iOS client exchanges SDP and streams voice. This branch adds a Codex-plugin broker behind OpenAI Talk selection so OAuth-only users can receive an app-server-backed session without exposing the OAuth credential to the client.
