## Summary

The implementation appears correct and follows the established QMD blank-query behavior, but this external PR should remain open because the posted real CLI proof does not demonstrate the changed outcome: its `provider: "none"` fixture also returns an empty result on current main after the unwanted bootstrap work.

## What This Changes

The PR makes the built-in memory manager return immediately for whitespace-only searches before provider initialization or index bootstrap and adds a focused regression test.

## Best Possible Solution

Built-in memory search should reject normalized blank input at the manager boundary before all provider, index, and sync lifecycle work, matching the existing QMD behavior.

Yes. Source inspection provides a high-confidence path: a whitespace-only built-in search with a required provider reaches provider initialization before preflight, while an empty index reaches forced bootstrap sync first.

## Solution Assessment

Yes. The early guard is the narrowest maintainable fix because it enforces the invariant once at the built-in manager boundary, aligns with QMD, and covers CLI and tool callers without parallel checks.
