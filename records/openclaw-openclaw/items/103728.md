This PR repairs that ordering, matches QMD’s established early-return behavior, adds focused coverage, and now includes the required-provider public CLI proof requested in earlier reviews; no actionable correctness or security defect remains.

## What This Changes

The PR returns early for trimmed-empty built-in memory searches before provider or index bootstrap work, shares normalization with the existing preflight, and adds a manager-level regression test.

## Best Possible Solution

Refresh the branch onto current main, retain the early built-in blank-query return and focused regression test, then land it so built-in and QMD consistently avoid provider, sync, and external-search work for empty input.
