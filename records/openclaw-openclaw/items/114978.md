## What This Changes

The PR documents that link commands must not run during source-checkout updates and makes `openclaw doctor` warn when `package.json` or `pnpm-workspace.yaml` contains a self-referential `openclaw` link.

## System Context

Source-checkout deployments use repository manifests to install and build the gateway. The live-updater instructions guide agents operating those checkouts, while Doctor inspects an installation and reports recoverable setup problems to the operator.
