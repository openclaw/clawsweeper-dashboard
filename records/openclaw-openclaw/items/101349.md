## Summary

Keep open: current main still source-reproduces the corrected residual behavior, where restricted agent-side `toolsAllow: null` is recapped into a default allow-list and non-default allow-lists still fail closed on CLI backends. The open wildcard-policy PR only partially overlaps and does not resolve the inherited restrictive cron trap.

## What This Changes

The issue asks OpenClaw to stop agent-created isolated cron jobs from inheriting or retaining `toolsAllow` in ways that cannot be cleared through the agent tool and then fail on CLI backends.

## Best Possible Solution

Preserve explicit CLI fail-closed behavior, make restricted agent-side clear attempts return an explicit error or documented safe clear path, and add a narrow repair or doctor path only for provably auto-default stale cron caps.
