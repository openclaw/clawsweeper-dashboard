## Summary

Keep open: current main still recaps restricted agent-side `toolsAllow: null` into the creator tool surface, while flagless or explicit cron allow-lists still reach the CLI fail-closed guard; the merged related PRs fixed default-marker cases but not the corrected remaining issue.

## What This Changes

The issue asks OpenClaw to stop agent-created CLI-backed cron jobs from silently keeping inherited `toolsAllow` restrictions that the `claude-cli` backend cannot run.

## Best Possible Solution

Preserve the explicit CLI fail-closed guard, add maintainer-approved explicit feedback for restricted agent-side clears, and provide a narrow repair or doctor path for provably stale auto-default cron caps.
