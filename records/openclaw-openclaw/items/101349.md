## Summary

Keep open: current main fixes normal default-marker CLI cron runs and direct service-level null clears, but a flagless regression-window `toolsAllow` still reaches the CLI fail-closed guard, and the agent-facing null-clear path is intentionally re-capped under creator policy.

## What This Changes

The issue asks OpenClaw to stop auto-injected cron `toolsAllow` values from breaking isolated `agentTurn` jobs that run through a CLI backend.

## Best Possible Solution

Preserve the CLI fail-closed guard for explicit restrictions and add a maintainer-approved narrow repair path, likely doctor/operator repair, for provably stale auto-default cron caps.
