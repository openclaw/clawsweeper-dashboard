## What This Changes

## Best Possible Solution

Carry an explicit hatch-only handoff signal through the system-agent/gateway response contract, have the custodian add the draft only for that signal, preserve ordinary agent handoffs unchanged, and demonstrate the fresh web setup path in a real browser session.
