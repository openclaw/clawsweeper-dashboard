## Summary

Keep this PR open for maintainer calibration and real runtime proof. The patch directly addresses the linked gateway false-positive restart path, but it intentionally changes default restart-driving thresholds for every V8 heap size and currently provides only mocked/unit-test evidence.

## What This Changes

This PR derives the default heap-used warning and critical thresholds from V8’s reported heap limit, while preserving explicit threshold overrides and the existing RSS and growth thresholds.

## System Context

Gateway diagnostic sampling turns Node process-memory facts into warning or critical pressure events; critical pressure can feed the gateway restart path. This change alters the default heap-used limits before those events are classified, while leaving caller-provided overrides intact.
