## Summary

Keep open: current main still has only coarse Control UI run status and a `sessions.list` active-run boolean, while the requested phase/latest-action/elapsed/reconnect progress surface remains unsettled across open Gateway activity and UI candidates.

## What This Changes

Request a compact Control UI run-progress strip for long or multi-agent tasks with phase, latest action, last activity, elapsed time, and reconnect context.

## Best Possible Solution

Choose one gateway-backed session activity and attention contract, then render a compact Control UI strip from that state without raw logs, message-text inference, or channel-local heuristics.
