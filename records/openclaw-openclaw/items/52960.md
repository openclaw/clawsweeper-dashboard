## Summary

Keep open: current main still exposes only coarse active-run state in the Control UI, while the requested compact phase/latest-action/elapsed/reconnect progress model remains unimplemented and tied to an open gateway activity contract decision.

## What This Changes

Request a compact Control UI run-progress surface for long or multi-agent tasks, including phase, latest meaningful action, last activity, elapsed time, and reconnect context.

## Best Possible Solution

Land one gateway-backed session activity and attention contract, then render a compact Control UI status strip near the active chat composer or thread without raw logs or message-text inference.
