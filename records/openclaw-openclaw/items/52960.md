## What This Changes

Request to add a compact Control UI run-progress/status strip for long or multi-agent tasks, including phase, latest action, timing, and reconnect context.

## Best Possible Solution

## Solution Assessment

No current implementation is sufficient. The maintainable solution is a gateway-backed activity/attention contract plus a small Control UI presentation layer, not local UI inference from message text, abortability, or tool streams alone.
