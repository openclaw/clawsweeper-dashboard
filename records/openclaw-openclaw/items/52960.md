## Summary

Keep open: current main partially improves visibility with a coarse composer run chip and a separate Tasks page, but it still lacks the requested compact active-chat progress strip with phase/latest-action state and canonical session activity semantics.

## What This Changes

Request a compact Control UI run-progress surface for long or multi-agent tasks, including phase, latest meaningful action, last activity, elapsed time, and reconnect/session hints.

## Best Possible Solution

Settle one gateway-backed activity/attention contract, then render a compact Control UI status strip near the composer or thread while keeping the Tasks page as a supplemental background-work view.
