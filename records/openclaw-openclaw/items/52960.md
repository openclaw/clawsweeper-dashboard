## Summary

Keep open: current main and v2026.6.11 still expose only coarse Control UI run status plus boolean active-run/session events, not the requested compact active-run progress strip with phase, latest action, last activity, elapsed time, and reconnect context. The backend activity contract remains tracked at https://github.com/openclaw/openclaw/issues/39127, and https://github.com/openclaw/openclaw/pull/96672 is an open implementation candidate that is not merged and still has review/proof blockers.

## What This Changes

Request a compact Control UI run-progress indicator for long or multi-agent tasks, including phase, latest meaningful action, last activity, elapsed time, and reconnect context.

## Best Possible Solution

Define or reuse one canonical gateway session activity/attention contract, then render a compact Control UI status strip near the composer or thread without raw logs or message-text inference.

## Reproduction Assessment

Yes, at source level: current main and the latest release show only a coarse composer status and a boolean session active-run flag, with no dedicated session activity RPC/event or progress metadata model.

## Solution Assessment

Yes for the direction, but not as a UI-only patch. The maintainable solution is a gateway-backed activity/attention contract plus a small Control UI presentation layer, not local inference from message text or tool streams alone.
