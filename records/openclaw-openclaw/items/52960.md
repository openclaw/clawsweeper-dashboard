Keep open: current main still exposes only coarse active/terminal run state in Control UI and `sessions.list`, while the requested compact phase/progress strip depends on an unresolved gateway/session activity contract. ## What This Changes

Requests a compact Control UI progress surface for long or multi-agent runs, including phase, latest meaningful action, elapsed/last-activity timing, and reconnect awareness.

## Best Possible Solution

Make a gateway-backed session activity and attention contract canonical first, then render a compact Control UI strip from that state without raw logs, message-text inference, or channel-local heuristics.
