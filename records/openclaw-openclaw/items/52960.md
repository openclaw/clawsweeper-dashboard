## Summary

Keep open: current main still only exposes coarse chat/session run state, not the requested compact progress model with phase, latest action, last activity, elapsed time, and reconnect context. The remaining work overlaps the broader gateway session-activity design and open implementation PRs, so this should stay in maintainer API/UX review rather than be swept closed.

## What This Changes

Request a compact Control UI run-progress/status display for long and multi-agent tasks.

## Best Possible Solution

Land a gateway-owned session activity contract and a compact Control UI status strip that shows phase, latest meaningful action, last activity, elapsed time, and reconnect context, with focused UI/gateway proof.
