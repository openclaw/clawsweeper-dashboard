## Summary

Keep open: current main still has only coarse Control UI run status plus tool/activity views, while the requested compact phase/latest-action session progress surface depends on unsettled Gateway/session activity semantics and overlapping open PRs have not landed.

## What This Changes

Request a compact Control UI status strip for long or multi-agent runs showing phase, latest meaningful progress, last activity, elapsed time, and reconnect/session context.

## Best Possible Solution

Settle one gateway-backed activity/attention contract, then render a compact Control UI status strip near the composer or thread without raw logs or message-text inference.
