Keep open: current main still exposes only coarse active/terminal session state in the Control UI and gateway protocol, while the related activity/status PRs remain open and conflicting rather than landed fixes.

## What This Changes

The issue requests a compact Control UI run-progress surface for long or multi-agent tasks, including phase, elapsed time, latest action, last activity, subagent/tool waiting, reconnect health, and stale or blocked indications.

## Best Possible Solution

Land one gateway-backed session activity and attention contract, then render the compact Control UI status strip from that state without raw logs, message-text inference, or local-only heuristics.
