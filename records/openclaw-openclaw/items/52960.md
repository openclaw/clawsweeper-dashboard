## Summary

Keep open: current main and v2026.6.11 still expose only coarse active-run state, not the requested compact Control UI progress surface. The broader gateway activity contract and related PR candidates remain open and unmerged, so this is still live product/API work.

## What This Changes

The issue requests a compact Control UI run-progress surface for long-running or multi-agent tasks, including phase, latest meaningful action, last activity, elapsed time, and reconnect context.

## Best Possible Solution

Settle one gateway-owned session activity/attention contract, then render a compact Control UI status strip near the active chat thread or composer without raw logs or message-text inference.
