Keep open: current main still exposes only coarse Control UI run status and coarse session active-run flags, while the requested compact phase/latest-activity/reconnect progress model remains unimplemented and related PRs are still open candidates rather than merged fixes.

## What This Changes

The issue requests a compact Control UI run-progress surface for long or multi-agent tasks, including phase, latest action, last activity, elapsed time, and reconnect state.

## Best Possible Solution

Land one gateway-owned session activity and attention contract, then render a compact Control UI status strip on top of it without raw logs or message-text inference.
