## Summary

Keep open: current main still exposes only coarse Control UI run state and session active-run flags, while the requested compact phase/progress strip depends on an unresolved gateway/session activity contract and overlapping open implementation candidates.

## What This Changes

Request a compact Control UI run-progress indicator for long or multi-agent tasks, including phase, latest action, last activity, elapsed time, and reconnect context.

## Best Possible Solution

Make one gateway-backed session activity and attention contract canonical, then render a compact Control UI status strip from that state without raw logs, message-text inference, or channel-local heuristics.
