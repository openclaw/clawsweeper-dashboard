## Summary

Keep open: current main and v2026.6.11 still do not provide the requested compact Control UI active-run progress strip with phase, latest action, last-activity/elapsed timing, and reconnect context. Existing live tool events and diagnostic activity help with a subset, but the broader gateway activity/attention contract remains open at https://github.com/openclaw/openclaw/issues/39127 and the implementation candidates are still unmerged.

## What This Changes

The issue requests a compact Control UI run-progress surface for long or multi-agent tasks, including phase, latest activity, timing, and reconnect context.

## Best Possible Solution

Land one canonical gateway-owned activity/attention contract, then render a compact Control UI active-run status strip from that contract without raw logs or message-text inference.
