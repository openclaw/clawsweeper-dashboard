## Summary

Keep open: current main still has only coarse Control UI run state and session-row active-run flags, not the requested compact active-run progress strip with phase, latest action, last activity, elapsed time, and reconnect context. ## What This Changes

## Best Possible Solution

Land one gateway-backed session activity/attention contract, then render a compact Control UI status strip near the active chat composer or thread without raw logs or message-text inference.
