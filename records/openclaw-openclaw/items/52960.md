## What This Changes

Requests a compact Control UI active-run progress strip that shows phase, latest action, timing, and reconnect context for long or multi-agent runs.

## Best Possible Solution

Define one gateway-owned activity/attention contract and render it as a compact Control UI status strip without raw logs or message-text inference.

## Solution Assessment

No current implementation is sufficient. The maintainable path is a gateway-backed activity/attention contract plus a small Control UI presentation layer, not UI-local inference from message text, abortability, or tool streams alone.
