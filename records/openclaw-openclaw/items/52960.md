## Summary

## What This Changes

The issue requests a compact Control UI progress surface for long or multi-agent runs, including run phase, latest meaningful activity, last activity time, elapsed time, and reconnect context.

Settle the gateway-owned session activity contract, then implement the Control UI strip from typed activity fields rather than inferring phases from tool text or scattered UI state.
