## Summary

Keep open: current main and v2026.6.11 still do not provide the requested compact Control UI run-progress strip or the gateway-backed activity state it would need. The broader gateway activity contract remains open, and the related implementation PRs are still unmerged candidates rather than shipped fixes.

## What This Changes

The issue requests a low-noise Control UI status surface showing active run phase, latest meaningful action, last activity, elapsed time, and reconnect/session context for long or multi-agent tasks.

## Best Possible Solution

Land one gateway-backed session activity/attention contract, then render a compact Control UI status strip near the active chat composer or thread without raw logs or message-text inference.
