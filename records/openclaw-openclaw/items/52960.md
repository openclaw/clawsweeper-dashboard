## Summary

Keep open: current main still has only coarse Control UI run status and session active-run flags, while the requested compact phase/progress strip depends on unsettled gateway session-activity semantics and overlapping open implementation candidates.

## What This Changes

The issue requests a compact Control UI status strip for long or multi-agent runs, including current phase, latest progress, last activity, elapsed time, and reconnect context.

## Best Possible Solution

Land one gateway-backed session activity and attention contract, then render the compact Control UI status strip from that state without raw logs, message-text inference, or channel-local heuristics.
