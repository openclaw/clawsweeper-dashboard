## Best Possible Solution

Design one shared read-only queue/workload snapshot backend in core, then expose a maintainer-approved subset through a permissioned `queue_status` agent tool with catalog/profile/policy entries, docs, and focused tests.

## Solution Assessment

Unclear until maintainers choose the public metadata contract. The narrowest maintainable shape appears to be a shared read-only snapshot provider reused by a permissioned agent-facing tool and any later operator surface, rather than separate bespoke status models.
