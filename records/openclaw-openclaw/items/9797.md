## Summary

Keep this issue open as the canonical agent-facing queue-capacity request. ## What This Changes

Add an agent-facing read-only queue workload snapshot for intelligent task dispatch.

## Best Possible Solution

Expose a policy-filtered advisory queue-status tool backed by the existing snapshot provider, returning caller-visible lane counts without raw session identifiers or guaranteed idle/busy promises.
