## What This Changes

The issue reports that the Control UI can fail to start in Firefox behind an HTTPS reverse proxy because strict CSP blocks eval/new Function in the bundled UI, followed by WebSocket 1006.

## Best Possible Solution

Keep strict Control UI CSP, configure or isolate the browser bundle so Zod does not use eval/new Function, and validate the Firefox reverse-proxy WebSocket startup path separately before changing gateway connection behavior.
