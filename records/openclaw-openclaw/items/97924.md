## Summary

Keep open: current main still has no session archive/rotation cron event schedule, only adjacent cron `on-exit`, plugin `session_end`, and session lifecycle projection surfaces. The remaining work needs a maintainer product and security decision before any implementation.

## What This Changes

The issue requests a session archive or rotation lifecycle event that cron jobs can subscribe to for event-driven post-session automation.

## Best Possible Solution

Settle one lifecycle automation contract: prefer existing plugin `session_end` plus a narrow SDK/event-scheduling seam if plugins cannot implement this safely, or explicitly add core cron event schedules with scoped metadata, permissions, durable trace, docs, and tests.
