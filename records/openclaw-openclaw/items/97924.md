## Summary

Keep open: current main has typed plugin `session_end` lifecycle hooks and command-exit cron triggers, but it still lacks the requested durable session archive/rotation event that cron jobs can subscribe to.

## What This Changes

Request to add a session archive/rotation lifecycle event that can trigger cron or agent-turn automation with scoped session metadata.

## Best Possible Solution

Define one narrow lifecycle-event contract, preferably plugin/API-first, for durable scoped session archive/rotation metadata and traced cron or plugin dispatch after product and security review.
