## Summary

Keep open: current main has adjacent `session_end` plugin hooks and cron `on-exit`, but it still lacks a session archive/rotation event schedule that cron can subscribe to or an external-plugin-safe way to launch the requested boundary agent turn.

## What This Changes

Request a session archive/rotation lifecycle event that can trigger a cron job or agent turn exactly once at the session boundary.

## Best Possible Solution

Define one maintained lifecycle automation contract: prefer the existing plugin `session_end` hook plus the smallest safe SDK/event seam external plugins need, or explicitly add core cron event schedules with scoped metadata, permissions, durability, and trace semantics.
