## Summary

Keep open: current main has session_end plugin hooks and cron/on-exit scheduling, but not the requested durable session archive/rotation event that cron can subscribe to. This is new product and security-sensitive automation surface, so it needs maintainer design rather than cleanup close.

## What This Changes

The issue requests a first-class session archive/rotation lifecycle event that can trigger cron jobs or isolated agent turns at session boundaries.

## Best Possible Solution

A maintainer-sponsored design should either add a durable, permission-scoped session lifecycle event that cron can subscribe to, or document the existing plugin/internal-hook workaround as the intended boundary.
