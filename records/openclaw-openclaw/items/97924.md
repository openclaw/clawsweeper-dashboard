## Summary

Keep open: current main still lacks a cron-subscribable session archive/rotation lifecycle event. The adjacent typed plugin `session_end` hook and bundled-only scheduled-turn API do not settle the external cron workflow, so this needs maintainer product and security direction.

## What This Changes

Request a session archive/rotation lifecycle event that can trigger cron jobs or agent turns exactly once when a session is archived.

## Best Possible Solution

Define one maintained lifecycle automation contract: preferably bless plugin `session_end` plus the smallest safe SDK scheduling/event seam external plugins need, or explicitly add core cron lifecycle schedules with scoped metadata, permissions, and durable tracing.
