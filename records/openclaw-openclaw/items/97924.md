## Summary

Keep open: current main still has adjacent `session_end` plugin hooks and Cron `on-exit`, but it does not expose a session archive/rotation lifecycle event that Cron can subscribe to. The remaining work is a product and security decision about the public contract, not conservative cleanup.

## What This Changes

Request to add a session archive/rotation lifecycle trigger that can run Cron-backed agent automation at the session boundary.

## Best Possible Solution

Choose one maintained lifecycle automation contract: prefer `session_end` plus the smallest plugin SDK scheduling/event seam if current plugin APIs are insufficient, or explicitly define core Cron event schedules with scoped metadata, permissions, traceability, docs, and upgrade tests.
