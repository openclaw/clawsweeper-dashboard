## Summary

Current main still starts gateway service installation without awaiting the remote wizard warning step, and this focused patch correctly bridges the planner’s synchronous warning callback to the wizard’s asynchronous acknowledgement contract. The PR should remain open because the contributor has only supplied mocked test evidence; external PR policy requires after-fix proof from a real remote-wizard or Gateway API setup before merge.

## What This Changes

The PR buffers warnings emitted while building the gateway install plan and awaits each wizard note before starting gateway service installation, with a regression test for the ordering.

## Best Possible Solution

Keep the planner callback synchronous, collect its warnings at the onboarding boundary, await their ordered presentation, and prove the result with a redacted real Gateway wizard run that observes installation only after acknowledgement.
