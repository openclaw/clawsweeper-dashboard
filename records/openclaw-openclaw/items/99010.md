## What This Changes

The PR changes ACPX process-list parsing to store parsed PID/PPID values in locals and skip rows whose parsed values are not finite.

## Best Possible Solution

Land the inline ACPX-local guard as a small hardening cleanup if maintainers want the defensive behavior, while keeping core PID helpers out of the plugin boundary.

## Reproduction Assessment

## Solution Assessment

Yes as cleanup, not as a reproduced bug fix. The inline guard is the narrowest owner-boundary-safe shape; importing core PID helpers would cross the plugin boundary, and a strict positive-integer helper would not fit PPID 0 semantics.
