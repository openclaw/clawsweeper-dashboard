## What This Changes

The PR parallelizes CLI startup-help generation through the built launcher and changes preflight checkout to fetch the head at depth one followed by blobless parent metadata.

## Best Possible Solution

Keep the single dist-based help-rendering path and split preflight fetch, with exact-head validation covering PR, push, and manual ref-resolution paths plus one monitored main-cycle timing check after landing.
