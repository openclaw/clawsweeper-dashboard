## What This Changes

The PR tags Chat Completions pre-tool text as commentary in both completion processors, rolls back provisional tags when spurious tool calls are stripped, withholds unphased completion deltas from durable block replies, and adds regression coverage.

## Best Possible Solution

Retain the shared phase-tagging and explicit rollback design, then land only after a redacted real-channel run with an OpenAI-compatible completions provider demonstrates a suppressed tool preamble and preserved legitimate replies for both normal and stripped-spurious turns.
