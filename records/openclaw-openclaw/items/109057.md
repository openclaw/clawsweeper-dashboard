## Summary

Keep this PR open: the diagnosis is sound, but commentary classification occurs after consumer-visible stream events, so block and preview delivery can still expose the preamble; the PR also lacks real provider/channel proof.

## What This Changes

The PR tags unphased text from Chat Completions tool-calling turns as commentary in both completion stream processors, shares the agent-side tagging helper, and adds transport-level regression tests.

## Best Possible Solution

Buffer unphased completion text until the terminal stop reason is known, or provisionally classify it before tool-call events with an explicit rollback for stripped spurious calls; cover the embedded subscriber path and provide a redacted live channel transcript or recording.
