## What This Changes

Fix the built-in read tool so a UTF-8 byte-order mark at the start of decoded file text is omitted from model-visible output while embedded markers remain intact.

## System Context

The agent read tool obtains file bytes from local or injected read operations, decodes them, and returns text content to the model. A leading UTF-8 encoding marker currently reaches that final tool result, so the model can receive different first-line text from the logical file content.
