## Summary

Keep open: current main and `v2026.6.11` still lack Anthropic as a registered web-search provider, typed Anthropic native-search config, and native Anthropic server-tool injection; the linked fork PR is open but conflicting and unproven, while the broader server-tools issue only partially overlaps.

## What This Changes

Add Anthropic native web search as a selectable web search provider that passes Anthropic server-tool definitions through the Messages API instead of routing through external search providers.

## Best Possible Solution

If accepted, land an Anthropic-plugin-owned explicit opt-in provider with manifest `webSearchProviders`, typed config/schema/docs, native Messages tool injection, server-result replay policy, auth/security defaults, and focused tests.
