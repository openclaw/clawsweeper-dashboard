## Summary

Keep open: current main and the latest release still do not expose Anthropic native web search as an OpenClaw web_search provider, and the remaining work needs maintainer product/security review rather than stale cleanup.

## What This Changes

The issue requests adding Anthropic native Messages API web search as a selectable web_search provider with Anthropic-specific tool version, domain, location, max-use, citation, and replay handling.

## Best Possible Solution

Keep this as the narrow Anthropic native web_search tracker and, if accepted, land an explicit Anthropic-plugin-owned provider with typed config/schema/docs, selected-provider gating, server-tool injection, replay preservation, security defaults, and focused tests.
