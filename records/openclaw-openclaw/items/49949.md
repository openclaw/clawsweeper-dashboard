## Summary

## What This Changes

## Best Possible Solution

If maintainers accept the direction, land a provider-plugin-owned, explicit opt-in implementation with manifest `webSearchProviders`, typed config/schema/docs, native Anthropic Messages server-tool injection, server-result replay policy, auth/security defaults, and focused tests.
