## Summary

Keep open: current main still lacks Anthropic as a registered `web_search` provider, lacks the typed Anthropic-native search config and manifest contract, and still builds Anthropic Messages requests from OpenClaw client tools rather than Anthropic server-tool definitions.

## What This Changes

Request to add Anthropic native `web_search_20260209` / `web_search_20250305` as a configurable web search provider using Anthropic server-side search.

## Best Possible Solution

Land this only if maintainers accept a plugin-owned, explicit opt-in Anthropic search provider with manifest `webSearchProviders`, typed config/schema/docs, native Messages server-tool injection, replay policy, auth/security defaults, and focused tests.

- **Decline hosted search for now:** Keep managed web-search providers as the supported path and document that Anthropic-hosted search is not currently planned.
