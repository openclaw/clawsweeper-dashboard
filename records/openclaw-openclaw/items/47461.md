## Summary

Keep open: current main still has no Telegram bot profile-photo sync or action, but this is a new opt-in Telegram identity feature with product and privacy implications rather than a broken documented contract.

## What This Changes

Request to synchronize the OpenClaw assistant/Web UI avatar with the Telegram bot profile photo so users do not have to update it manually in BotFather.

## Best Possible Solution

Define an explicit opt-in Telegram plugin feature for bot profile-photo updates, using `setMyProfilePhoto`, clear privacy copy, size/type validation, docs, focused tests, and live Telegram proof before any automatic Web UI sync.
