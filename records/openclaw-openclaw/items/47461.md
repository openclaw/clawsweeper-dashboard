## Summary

Keep open: current main still treats assistant avatars as OpenClaw/UI identity metadata and the Telegram plugin has no bot profile-photo sync path, so this needs a maintainer product/security decision rather than conservative cleanup.

## What This Changes

Request bidirectional synchronization between Web UI assistant avatar changes and the visible Telegram bot profile/avatar so users do not have to update it manually through BotFather.

## Best Possible Solution

Add a maintainer-approved, Telegram-plugin-owned, explicit opt-in profile-photo sync or action using `setMyProfilePhoto`, with clear status/errors, docs/config, and live Telegram proof; otherwise document that bot profile photos stay owned by Telegram/BotFather.
