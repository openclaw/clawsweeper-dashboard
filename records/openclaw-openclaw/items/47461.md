## Best Possible Solution

Add a maintainer-approved, Telegram-plugin-owned explicit opt-in profile-photo action or Control UI control using the correct Telegram bot-profile API, with media validation, clear status/errors, audit behavior, and live Telegram proof; otherwise document that Telegram bot photos remain managed in Telegram/BotFather.
