  - body: The remote `sessions_spawn` branch calls the gateway `agent` method without `idempotencyKey`, but `AgentParamsSchema` requires it and the handler rejects invalid agent params before dispatch. Any cross-gateway spawn will fail before a remote run starts.

  - body: This branch bypasses the existing `resolveGatewayOptions` allowlist and sends peer URLs directly to `callGateway`.   - confidence: 0.9
- **[P1] Route remote spawn through a real spawn contract:** `src/agents/tools/sessions-spawn-tool.ts:158-160`
  - body: The remote spawn path constructs `agent:<id>:main` and sends a normal `agent` message, so it does not create or track a spawned subagent/ACP session, preserve child-session completion semantics, or return the usual spawn result shape. This makes `sessions_spawn` behave like remote `sessions_send`.
  - confidence: 0.88
- **[P2] Reject tokenless peers or make them actually work:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: `gateway.peers[*].token` is optional and the tests expect tokenless peers, but `callGateway` rejects URL overrides without explicit credentials before the RPC is attempted. Either require a token/password for peers or add a deliberate, tested tokenless trust mode instead of advertising a path that fails at runtime.
  - confidence: 0.92
