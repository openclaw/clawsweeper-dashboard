  - body: The remote spawn path calls the gateway `agent` method without `idempotencyKey`, but `AgentParamsSchema` requires it. A `sessions_spawn(..., gateway=...)` call will be rejected as invalid params before the remote run starts.
  - confidence: 0.96
- **[P2] Reject sessionKey and label together remotely:** `src/agents/tools/sessions-send-tool.ts:71-80`
  - body: The remote `sessions_send` branch only checks that at least one target is present, while the local path rejects `sessionKey` plus `label`. With both provided, the remote path silently prefers `sessionKey`, which can ignore the caller's label and route to the wrong remote session.
  - confidence: 0.88
- **[P2] Do not advertise tokenless peers as working:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: `resolveGatewayPeerOptions` can return a URL with no token, and the tests expect that shape, but `callGateway` treats an explicit URL as an override that requires explicit credentials. A peer configured without `token` will fail locally before the remote gateway is contacted.
  - confidence: 0.86
