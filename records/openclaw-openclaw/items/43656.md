Full review comments:

- **[P1] Keep raw gatewayUrl behind the existing tool allowlist:** `src/agents/tools/gateway-peer.ts:66-67`
  - body: This helper accepts any `gatewayUrl` tool argument and the new session fast paths pass it directly to `callGateway`, bypassing the current `resolveGatewayOptions` allowlist for loopback or configured `gateway.remote.url`. That turns a model-facing session tool into arbitrary operator-authenticated WebSocket egress whenever a token is supplied; keep raw URLs on the existing allowlisted path or remove them in favor of named configured peers.
  - confidence: 0.92
- **[P1] Include idempotencyKey in remote spawn agent requests:** `src/agents/tools/sessions-spawn-tool.ts:167-179`
  - body: The remote `sessions_spawn` branch calls the gateway `agent` method with `message`, optional `sessionKey`/`label`, and routing metadata, but it never sends `idempotencyKey`. `AgentParamsSchema` requires that field, so cross-gateway spawn requests are rejected as invalid before the remote run can start.
  - confidence: 0.96
- **[P2] Make tokenless peers explicit instead of silently failing:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: `GatewayPeerConfig.token` is optional and the tests assert that a peer without a token resolves, but both fast paths use `callGateway({ url: peerUrl, token: undefined })`. Current `callGateway` rejects URL overrides without explicit credentials, so tokenless peer entries fail locally before reaching the remote gateway; either require a token for peers or add an intentional, reviewed auth-none path.
  - confidence: 0.9
- **[P2] Preserve sessionKey and label exclusivity remotely:** `src/agents/tools/sessions-send-tool.ts:71-74`
  - body: The remote `sessions_send` branch only rejects the case where neither target is supplied; when both `sessionKey` and `label` are present it silently uses `sessionKey` and ignores `label`. The local path rejects that combination, so cross-gateway sends can route to a different session than the caller intended instead of surfacing an input error.
  - confidence: 0.88
