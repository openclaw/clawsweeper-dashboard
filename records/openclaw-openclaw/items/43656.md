  - confidence: 0.9

  - body: `gateway.peers.<name>.token` is optional here, but both remote paths pass the resulting URL to `callGateway` as a CLI-style URL override. Current `callGateway` rejects URL overrides without explicit credentials, so advertised tokenless peers fail before connecting.
  - confidence: 0.88
