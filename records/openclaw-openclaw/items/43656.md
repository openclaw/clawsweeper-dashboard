## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Restore gateway URL guardrails for explicit remote targets:** `src/agents/tools/gateway-peer.ts:66-67`
  - body: The helper accepts any `gatewayUrl` and the new session fast paths pass it directly to `callGateway`, bypassing the existing agent-tool allowlist in `resolveGatewayOptions` that restricts overrides to loopback or the configured remote gateway. That turns `sessions_send`/`sessions_spawn` into a new arbitrary WebSocket target surface for agent tool calls; route explicit URLs through the existing guardrail or remove raw URL params until a peer allowlist is designed.
  - confidence: 0.9
- **[P1] Include idempotencyKey in remote spawn requests:** `src/agents/tools/sessions-spawn-tool.ts:167-179`
  - body: The remote `sessions_spawn` path calls the gateway `agent` method without `idempotencyKey`, but `AgentParamsSchema` requires that field. Cross-gateway spawn requests will be rejected as invalid params before the remote run starts; generate and forward an idempotency key as the local agent paths do.
  - confidence: 0.93
- **[P2] Reject peers that cannot authenticate before routing:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: This return path allows a configured peer with no resolved token, but `callGateway` rejects URL overrides without explicit credentials. The PR advertises tokenless peers as supported, so those peer entries fail before reaching the remote gateway; either make credentials required for peers or reject the peer with a clear local error.
  - confidence: 0.84
- **[P2] Reject remote sends with both sessionKey and label:** `src/agents/tools/sessions-send-tool.ts:74-80`
  - body: The remote branch only checks for the case where neither selector is present, so a call with both `sessionKey` and `label` silently uses `sessionKey` and ignores the label. The local branch rejects that combination to avoid ambiguous targeting; keep the same validation remotely so cross-gateway sends cannot route to an unintended session.
  - confidence: 0.82
