- **[P1] Keep remote session URLs behind gateway policy:** `src/agents/tools/gateway-peer.ts:66-67`
  - body: `resolveGatewayPeerOptions` accepts raw `gatewayUrl` and both session tools pass the result directly to `callGateway`, bypassing the existing `resolveGatewayOptions` allowlist for model-facing agent tools.   - confidence: 0.96

  - body: The remote `sessions_spawn` fast path calls the gateway `agent` method without `idempotencyKey`, but `AgentParamsSchema` requires that field.   - confidence: 0.98
- **[P2] Make tokenless peer behavior explicit:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: The helper and test suite treat a peer without `token` as valid, but `callGateway` rejects explicit URL overrides unless explicit credentials are supplied. Either require peer credentials in the config/schema or implement a reviewed peer-auth mode; otherwise the documented `studio` example fails at runtime with an auth error.
  - confidence: 0.9
