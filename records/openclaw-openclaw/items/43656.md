  - body: The new remote path passes `peerOpts.gatewayUrl` directly to `callGateway`, bypassing the existing agent-tool `resolveGatewayOptions` allowlist for loopback or configured `gateway.remote.url`.   - body: The remote `sessions_spawn` branch calls the gateway `agent` method without `idempotencyKey`, but `AgentParamsSchema` requires that field. Any cross-gateway spawn that reaches the remote gateway will be rejected as invalid params before the run starts.
  - confidence: 0.97
- **[P2] Reject tokenless peers before calling an override URL:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: `gateway.peers.<name>.token` is documented and typed as optional, but this helper can return a peer URL with `gatewayToken: undefined`; `callGateway` rejects explicit URL overrides without explicit credentials before trying the remote request. The tokenless peer example in the PR body is therefore non-functional unless this path rejects it clearly or uses an approved no-auth peer mode.
  - confidence: 0.9
