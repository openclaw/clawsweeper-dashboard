Full review comments:

- **[P1] Keep remote URLs on the approved gateway path:** `src/agents/tools/gateway-peer.ts:66-67`
  - body: This explicit `gatewayUrl` branch returns any caller-provided URL, and the new session-tool paths pass it directly into `callGateway`.   - confidence: 0.95
- **[P1] Send an idempotency key with remote spawns:** `src/agents/tools/sessions-spawn-tool.ts:167-179`
  - body: The remote `sessions_spawn` branch calls the gateway `agent` method without `idempotencyKey`. `AgentParamsSchema` requires that field, so the remote gateway will reject the request before the spawned run starts.
  - confidence: 0.98
- **[P2] Do not advertise tokenless peers as supported:** `src/config/zod-schema.ts:819`
  - body: `gateway.peers[*].token` is optional here and the helper test expects tokenless peers to work, but `callGateway` treats every explicit URL as an override and requires explicit credentials. A peer without a token will fail before connecting, so either require the token or add a deliberately reviewed auth-none path.
  - confidence: 0.88
