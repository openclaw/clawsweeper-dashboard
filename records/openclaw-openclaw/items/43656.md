  - body: The new remote path passes `peerOpts.gatewayUrl` directly to `callGateway`, and `peerOpts` can come from raw tool params via `gatewayUrl`.   - confidence: 0.96
- **[P1] Send an idempotency key with remote spawns:** `src/agents/tools/sessions-spawn-tool.ts:166`
  - body: The cross-gateway `sessions_spawn` branch forwards to the Gateway `agent` method without `idempotencyKey`. `AgentParamsSchema` requires that field, so remote spawns will be rejected as invalid params before the remote agent run can start.
  - confidence: 0.94
- **[P2] Make tokenless peers explicit or invalid:** `src/agents/tools/gateway-peer.ts:58-61`
  - body: The helper and tests treat `gateway.peers.<name>.token` as optional, but every explicit URL override passed to `callGateway` requires explicit credentials. A configured peer without a token will fail before the remote request is attempted, so the config schema should either require auth for peers or the implementation needs a deliberate tokenless-peer path.
  - confidence: 0.88
