- **[P1] Keep raw gateway URLs behind the tool allowlist:** `src/agents/tools/gateway-peer.ts:66-67`
  - body: The helper returns caller-provided `gatewayUrl` as a peer target, and the session tools then pass it directly to `callGateway`.   - confidence: 0.96
- **[P1] Include idempotencyKey in remote spawn requests:** `src/agents/tools/sessions-spawn-tool.ts:167-179`
  - body: The remote `sessions_spawn` path sends an `agent` request without `idempotencyKey`, but `AgentParamsSchema` requires it. Cross-gateway spawn will be rejected by the remote gateway before any run starts.
  - confidence: 0.97
- **[P2] Reject sessionKey and label together remotely:** `src/agents/tools/sessions-send-tool.ts:70-74`
  - body: The remote `sessions_send` branch only checks that at least one selector exists; unlike the local branch, it does not reject `sessionKey` and `label` together. That makes remote sends silently prefer `sessionKey`, which can target a different remote session than the label the caller supplied.
  - confidence: 0.9
