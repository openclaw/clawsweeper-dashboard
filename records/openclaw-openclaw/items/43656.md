## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Include idempotencyKey in remote spawn requests:** `src/agents/tools/sessions-spawn-tool.ts:167-179`
  - body: The cross-gateway `sessions_spawn` branch forwards to the gateway `agent` method without `idempotencyKey`, but `AgentParamsSchema` requires that field. Any remote spawn using `gateway` or `gatewayUrl` is rejected as invalid params before the remote run can start.
  - confidence: 0.97
- **[P2] Reject tokenless peers before calling remote gateways:** `src/agents/tools/gateway-peer.ts:59-62`
  - body: `gateway.peers.<name>.token` is optional and the helper returns `gatewayToken: undefined`, but `callGateway` requires explicit credentials whenever `url` overrides the target. A tokenless peer therefore fails with an auth-contract error before reaching the remote gateway, despite the schema and tests advertising it as supported.
  - confidence: 0.92
- **[P2] Preserve sessionKey and label exclusivity remotely:** `src/agents/tools/sessions-send-tool.ts:71-74`
  - body: The remote `sessions_send` path rejects only the case where neither target is provided, so a call with both `sessionKey` and `label` silently prefers `sessionKey`. The local path rejects the same input, and the remote path should keep that invariant to avoid sending to an unintended session.
  - confidence: 0.9
