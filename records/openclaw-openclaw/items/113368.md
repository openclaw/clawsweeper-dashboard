## What This Changes

The PR changes isolated Telegram polling so an update is durably written to the ingress spool before its polling offset is persisted and the worker is acknowledged, with regressions for ordering and failure paths.

## System Context

Telegram's isolated polling worker receives updates from Telegram and asks the parent session to durably hand them to the ingress spool. The parent then records the polling offset and acknowledges the worker, determining whether Telegram may redeliver an update after a failure.
