## What This Changes

This PR changes isolated Telegram polling so update offsets advance only after durable spool writes, coordinates concurrent update IDs before advancing the offset, and adds polling-session regression coverage and diagnostics.

## System Context

Telegram isolated polling receives updates from the Bot API, hands them to the durable ingress spool, and advances the saved update offset that tells Telegram which updates no longer need delivery. The spool later feeds the normal inbound-message drain and dispatch path, so advancing the offset early can permanently drop a user message after a crash.
