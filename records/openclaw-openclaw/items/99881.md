## What This Changes

The issue reports that uploading an image to a non-multimodal DeepSeek model can poison later tool-result rendering so normal tool output becomes the literal image placeholder.

## Best Possible Solution

Land a reviewed fix that downgrades every image block shape before non-vision provider replay while preserving text tool-output fallback, then close this issue with the merged PR or release proof.
