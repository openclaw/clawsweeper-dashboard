## What This Changes

The issue reports that uploading an image to a non-multimodal DeepSeek model corrupts subsequent model-visible tool outputs into the literal image placeholder and can leave sessions unrecoverable without cleanup.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/100281 or an equivalent provider/transport fix that downgrades all image block shapes for non-vision models while preserving tool-result text, with an in-product recovery path if already-corrupted sessions still need cleanup.
