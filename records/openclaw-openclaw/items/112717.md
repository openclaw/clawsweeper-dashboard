## Summary

Keep this PR open. The current shutdown path still clears the secrets runtime snapshot in the close prelude before channel teardown, while this patch moves cleanup into the handler’s `finally` block and adds focused ordering/failure coverage; that directly addresses the linked open bug. The implementation needs one release-process cleanup before merge: normal PRs must not edit the release-owned `CHANGELOG.md`.

## What This Changes

Moves gateway SecretRef snapshot cleanup until after channel and plugin teardown, with regression tests for teardown ordering and guaranteed cleanup after a channel-stop failure.

## System Context

Gateway shutdown runs a prelude, then stops channel plugins and other runtime owners before closing transport resources. Channel teardown can resolve account credentials from the active runtime snapshot, so snapshot cleanup must occur only after those credential-dependent owners have finished.
