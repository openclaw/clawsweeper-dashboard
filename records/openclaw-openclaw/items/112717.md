## What This Changes

Moves gateway SecretRef runtime-snapshot cleanup until after channel and plugin teardown, preventing credential-backed channel shutdown from re-reading unresolved raw SecretRefs.

## System Context

Gateway shutdown coordinates diagnostics, channel teardown, plugin services, and runtime cleanup. Channel stop hooks can resolve account credentials, so the resolved SecretRef snapshot must remain available until those teardown steps complete.

## Architecture Diagram

## Best Possible Solution
