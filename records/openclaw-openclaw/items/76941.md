Full review comments:

- **[P2] Prefer provider identity before surface fallback:** `src/auto-reply/reply/agent-runner.ts:902`
  - body: When `OriginatingChannel` is absent, this helper checks `sessionCtx.Surface` before `sessionCtx.Provider`. Relayed external turns can carry `Surface="webchat"` while `Provider` or `messageProvider` remains Telegram/Discord, so they would still be treated as internal and injected into the embedded run. Use `followupRun.run.messageProvider` or `Provider` before `Surface`.
  - confidence: 0.91
- **[P2] Resolve doctor metadata from the stored session file:** `src/commands/doctor-session-transcripts.ts:409`
  - body: `loadSessionMetadata` stores metadata by `sessionId`, but this lookup uses the transcript filename. Session files can be forked or explicit, such as `<timestamp>_<sessionId>.jsonl`, so safe Telegram direct transcripts will be treated as missing metadata and skipped during `doctor --fix`. Resolve through the session store's `sessionFile` and `sessionId` relationship instead.
  - confidence: 0.9
