## Summary

This PR remains necessary as the candidate fix for the confirmed cross-tab custom-group loss. The earlier legacy-replacement concern appears addressed, but the branch needs a current rebase/merge refresh and inspectable after-fix proof showing the actual two-tab outcome before merge.

## What This Changes

The PR adds atomic Gateway operations for adding and reordering custom session groups, updates Control UI callers to use them, and preserves the legacy full-catalog replacement behavior for older clients.

## System Context

Control UI manages custom session groups through Gateway RPC operations backed by the shared SQLite state database. Group mutations are broadcast back to connected clients, so a destructive full-catalog write can overwrite another tab's independently created group.
