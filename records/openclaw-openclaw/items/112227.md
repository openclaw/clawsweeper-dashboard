## What This Changes

The branch adds `sessions.groups.add` as an atomic Gateway operation, moves Control UI custom-group creation to that operation, and preserves `sessions.groups.put` as the legacy full-catalog fallback.

## System Context

Control UI tabs create custom session groups through the Gateway, which persists the shared session-group catalog in SQLite and broadcasts catalog changes back to connected clients. This change replaces a stale client-side read/append/full-replacement write for creation with a semantic single-group mutation.
