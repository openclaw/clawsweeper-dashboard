## Summary

Keep open: current main still lacks a dedicated AWS deployment page or AWS hosting navigation entry. The official AWS Lightsail guide and community sample repository are useful external resources, but they do not resolve the requested ECS/Fargate, Lambda-applicability, and production-operations documentation, and prior maintainer-side review explicitly retained this work for follow-up.

## What This Changes

Add an AWS deployment guide covering EC2 or Lightsail, ECS/Fargate, Lambda applicability, persistence, networking, secrets, monitoring, backups, troubleshooting, and security hardening.

## Best Possible Solution

Ship a bounded `docs/install/aws.md` page and navigation entry that makes EC2 or Lightsail with the canonical Docker Compose path primary, adds an explicitly supported ECS/Fargate topology with durable storage, ALB, task roles, Secrets Manager, logging and backups, states the Lambda support position, reuses canonical security and Gateway docs, and links reviewed AWS-maintained examples where appropriate.
