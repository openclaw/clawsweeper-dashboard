## Summary

Keep open: the linked bug is valid, but this branch is not merge-ready because it retries before valid long server cooldowns expire, does not preserve HTTP status end to end, and provides only mocked after-fix validation.

## What This Changes

The PR parses Anthropic Retry-After headers, propagates a retry delay through assistant-message errors, and uses that delay for agent auto-retries with a 60-second cap.

## Best Possible Solution

Propagate both numeric HTTP status and Retry-After through the generic normalized error result, never retry before the server-requested minimum—decline an automatic retry instead if the wait exceeds the product budget—and prove the full Anthropic transport-to-AgentSession path with a redacted live transcript.
