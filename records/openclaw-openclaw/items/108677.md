## What This Changes

Attaches HTTP status and parsed Retry-After metadata to Anthropic transport errors, propagates retryAfterMs onto assistant messages, and uses it for AgentSession auto-retry delays.

## Best Possible Solution

Propagate both numeric status and retryAfterMs through the normalized assistant-error contract, honor short server cooldowns, route 60s+ windows to failover instead of clamping them into session retries, and prove both paths in a real AgentSession run.
