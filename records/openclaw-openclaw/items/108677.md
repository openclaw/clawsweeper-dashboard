## Summary

Keep this PR open: the revised head appears to address the prior HTTP-status finding, but it still shortens long server cooldowns to 60 seconds and provides only stubbed or mocked after-fix evidence.

## What This Changes

The PR preserves Anthropic error status and Retry-After metadata through the transport and uses the resulting cooldown for AgentSession auto-retry timing.

## Best Possible Solution

Honor the full valid Retry-After value when it fits the session retry budget; when it exceeds an acceptable in-turn wait, skip that automatic retry and surface the rate limit rather than shortening the provider deadline.
