## What This Changes

The branch changes the incomplete-turn fallback so a run whose completed tool work is followed by an empty final model response tells the user that the summary is missing and to inspect produced artifacts.

## System Context

The embedded agent runner executes model turns and tool calls, then converts a terminal result into payloads delivered to the initiating channel. Empty final responses can take the incomplete-turn path after the runner has attempted its existing visible-answer continuation, so this fallback text is the last user-facing recovery message.

  Decision --> Payload[Channel-facing degraded message]

## Best Possible Solution

Keep the existing one-shot visible-answer continuation, preserve the conservative warning for errored or asynchronous tool activity, and add redacted runtime proof showing the new final fallback after a completed-tool empty-response run.
