## Summary

Keep open: the previous P1 blocker remains on the unchanged reviewed head. Windows root exit changes the tracked tree to an permanently unprovable state, while the scope drainer releases only trees proven dead, so normal exits can poison later run-id reuse and cancellation drains.

## What This Changes

The PR adds fail-closed Gateway cancellation that fences scoped spawns, interrupts Codex turns, drains thread background terminals, and waits for supervised and app-server process trees before releasing run ownership.

## Best Possible Solution

Use durable spawn-time Windows descendant ownership, preferably a Job Object, or otherwise report the current drain failure once and retire the non-actionable owner without claiming descendant termination; then prove active-root and root-already-exited cancellation on live Windows while preserving healthy shared app-server sibling turns.
