## Summary

Keep open: current main and the latest release ignore ACP-only `streamTo` on native subagent calls, but they still do not provide live native subagent progress back to the parent. This remains the canonical tracker, and the remaining work needs a maintainer-approved security and routing contract before implementation.

## What This Changes

The issue requests `streamTo="parent"` support for `sessions_spawn` when `runtime="subagent"` so long-running child work can report progress to the parent session.

## Best Possible Solution

Keep this as the canonical tracker and design a bounded native subagent parent-progress relay with explicit redaction, visibility, requester routing, cleanup, tests, and docs before exposing it as `streamTo="parent"`.
