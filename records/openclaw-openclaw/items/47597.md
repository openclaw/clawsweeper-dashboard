## Summary

Keep open: current main and the latest release still treat `streamTo="parent"` as ACP-only for `sessions_spawn`, while native subagents register completion handoffs rather than a live parent progress stream. The old hard error is already fixed by ignoring ACP-only fields for native subagents, but the requested feature remains a product and security-boundary decision.

## What This Changes

The issue requests `streamTo="parent"` support for `runtime="subagent"` so parent sessions can receive live subagent progress instead of only final completion.

## Best Possible Solution

Design a bounded native subagent parent-progress contract with explicit redaction, visibility levels, requester-session routing, cleanup, timeout behavior, tests, and docs before exposing it through `streamTo="parent"`.
