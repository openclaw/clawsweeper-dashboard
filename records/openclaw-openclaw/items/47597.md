## Summary

Keep open: current main still treats `streamTo="parent"` as ACP-only and deliberately drops it for native `runtime="subagent"`; the hard-error/autofilled-parameter failure was fixed by https://github.com/openclaw/openclaw/pull/72101, but the requested native live parent progress stream remains a product/security design question.

## What This Changes

This issue requests `streamTo="parent"` support for native `runtime="subagent"` so parent sessions can receive live child progress instead of only final completion.

## Best Possible Solution

Define a bounded native subagent parent-progress contract before implementation: decide which child events may cross into the parent session, reuse the existing relay/projection/redaction patterns where possible, and keep docs/tests aligned across native, ACP, and yielded-parent flows.
