## Summary

Keep open: current main still ignores `streamTo="parent"` for native `runtime="subagent"`; #72101 fixed the hard-error/auto-filled-parameter failure by stripping the ACP-only field, but it did not implement the requested live parent progress stream.

## What This Changes

Issue requests native subagent `streamTo="parent"` support so parent sessions can receive progress during long-running child work.

## Best Possible Solution

Define a bounded native subagent parent-progress relay with explicit visibility, redaction, requester routing, cleanup, timeout behavior, tests, and docs before exposing it through `streamTo="parent"`.
