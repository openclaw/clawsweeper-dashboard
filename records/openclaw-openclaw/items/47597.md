## Summary

Keep open: current main and v2026.6.11 still treat `streamTo="parent"` as ACP-only for the `sessions_spawn` API; native `runtime="subagent"` accepts and ignores the field after the compatibility fix, so the requested live parent progress stream remains unimplemented and needs maintainer security/product direction.

## What This Changes

The issue requests live parent-session progress streaming for native `sessions_spawn({ runtime: "subagent", streamTo: "parent" })`.

## Best Possible Solution

Define a maintainer-approved native subagent parent-progress contract that emits bounded, redacted progress through existing session/task delivery paths, keeps raw tool data and reasoning hidden by default, and updates docs plus regression tests for both default native behavior and the opt-in stream path.
