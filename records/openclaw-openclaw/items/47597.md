## Label Justifications

- `P2`: This is a normal-priority feature/design request for native subagent progress visibility with limited blast radius and no current documented hard failure.
- `impact:security`: Parent streaming native child progress could expose tool arguments, command output, paths, patches, or reasoning across a session boundary.
- `impact:ux-friction`: The current completion-only behavior leaves long-running native subagents visually silent until the final handoff, creating avoidable user confusion.

## Summary

Keep open: current main and the latest release only fix the older hard-failure facet by ignoring ACP-only `streamTo` on native subagent calls; they still do not provide native `runtime="subagent"` parent progress streaming, and that remaining feature needs security/product design before implementation.

## What This Changes

Add native `runtime="subagent"` support for `streamTo="parent"` so parent sessions can receive real-time child progress instead of only completion events.

## Best Possible Solution

Define a native subagent progress event contract that keeps the current completion-only default, uses `streamTo:"parent"` as an explicit opt-in, and specifies redaction, truncation, routing, wake, and test coverage before implementation.
