## Summary

Keep open: current main still treats `streamTo: "parent"` as ACP-only, and native subagent spawns ignore the field rather than streaming child progress to the parent. The remaining request is a real feature/API gap, but it needs maintainer direction because the visibility and redaction boundary for child-session progress is security-sensitive.

## What This Changes

The issue requests `streamTo: "parent"` support for `runtime: "subagent"` so parent sessions can receive progress while native subagents run.

## Best Possible Solution

Define a bounded native subagent parent-progress contract with explicit redaction, requester routing, cleanup, timeout, mode behavior, tests, and docs before exposing it through `streamTo: "parent"`.
