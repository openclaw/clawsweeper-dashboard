## Summary

Keep open: current main and v2026.6.11 still treat `streamTo` as ACP-only, and the native `runtime="subagent"` path has no parent progress relay. This remains the canonical native subagent parent-stream design tracker and needs maintainer/security direction before implementation.

## What This Changes

Request to make `sessions_spawn` `streamTo="parent"` work for native `runtime="subagent"` so parent sessions receive live progress rather than only final completion.

## Best Possible Solution

Keep this as the canonical native subagent parent-stream design tracker and implement only after maintainers approve a redacted, bounded projection contract for event types, routing, cleanup, and tests.

## Reproduction Assessment

Not applicable as a bug reproduction, but yes at source level for the current behavior: current main and v2026.6.11 only use `streamTo` for ACP, tests assert native spawns drop it, and docs tell users to omit it for native subagents.

## Solution Assessment

No implementation path is approved yet. The best fix is not a guard removal or heartbeat-only patch; it needs a native progress event contract with conservative visibility, redaction, routing, cleanup, and security boundaries.
