## Summary

Keep open: current main and v2026.6.11 still treat `streamTo="parent"` as ACP-only, so the native subagent parent-progress feature remains missing. The hard-error/autofilled-parameter symptom was addressed by https://github.com/openclaw/openclaw/pull/72101, but that PR intentionally ignores the field for native subagents rather than adding a stream.

## What This Changes

Request native `runtime="subagent"` calls to support `streamTo="parent"` or equivalent live parent progress updates during long child runs.

## Best Possible Solution

Define a bounded native subagent parent-progress relay with explicit redaction, requester routing, cleanup, timeout, mode behavior, tests, and docs before exposing it through `streamTo="parent"`.

- **Build Structured Child Event Stream:** Create a broader subscription surface for native child events, accepting a larger design covering tool output, thinking visibility, and channel limits.

## Solution Assessment

Unclear until maintainers choose the visibility and security boundary. Passing `streamTo` through or adding an unscoped heartbeat is not the best safe fix without a redaction, routing, and cleanup contract.
