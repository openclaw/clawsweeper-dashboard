## Summary

Keep open. Current main and v2026.6.11 still lack the requested end-to-end channel creation path: shared and Discord runtime pieces exist, but the CLI/docs expose only channel info/list and Slack lacks discovery, runtime support, scopes, and gates. Because this grants agents workspace/server administration authority, maintainers should decide the product/security boundary before implementation.

## What This Changes

Request to add message-tool and CLI channel creation for Slack, Discord, and similar messaging providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
