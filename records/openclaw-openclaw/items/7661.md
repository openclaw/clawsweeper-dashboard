## Summary

Keep open. Current main and the latest release still do not provide the requested end-to-end channel creation path: Discord has partial provider/runtime support, the CLI still exposes only channel info/list, and Slack lacks channel-create discovery, dispatch, scopes, and gates.

## What This Changes

The issue requests a native message-tool and CLI path for creating messaging channels, especially Slack channel creation and Discord channel administration.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
