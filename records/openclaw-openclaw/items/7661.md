## Summary

Keep open. Current main and the latest release still lack an end-to-end channel creation path: Discord has provider-side action support but the CLI/docs expose only channel info/list, and Slack still lacks channel-create discovery, dispatch, setup scopes, and an accepted safety gate; the open related PR only covers the Discord CLI subset.

## What This Changes

Request programmatic channel creation through the message tool or CLI for Slack, Discord, and similar message providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
