## Summary

Keep open. Current main and the latest release still lack the requested end-to-end channel creation path: Discord has partial provider-side channel admin support, but the CLI/docs expose only channel info/list, and Slack lacks channel-create discovery, runtime handling, setup scopes, and an explicit admin gate.

## What This Changes

Request to add provider-backed channel creation to the message tool and CLI for Slack, Discord, and similar messaging platforms.

## Best Possible Solution

Define a provider-owned, default-off channel-administration model first, then implement Slack channel creation with explicit scopes/gates and land or supersede the Discord CLI subset with matching tests and docs.
