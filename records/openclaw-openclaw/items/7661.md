## Summary

Keep open. Current main and the latest release still do not provide the requested end-to-end channel creation path: Discord has partial message-action runtime support, but the CLI/docs still expose only channel info/list, and Slack still lacks channel-create discovery, dispatch, scope, and gate support.

## What This Changes

The issue requests a native `message` tool and CLI surface for creating provider channels, especially Slack channels and Discord guild channels.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
