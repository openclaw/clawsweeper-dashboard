## Summary

Keep open. Current main still lacks the requested end-to-end channel creation path: Discord has partial provider/runtime support, but the CLI/docs still expose only channel info/list and Slack still has no channel-create discovery, dispatch, scope, or gate.

## What This Changes

Request to add `channel create` support to the message tool and CLI for Slack, Discord, and similar message providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
