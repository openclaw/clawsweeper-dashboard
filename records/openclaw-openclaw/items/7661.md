## Summary

Keep open. Current main and the latest release still lack the requested end-to-end channel creation path: Discord has partial provider-side action support, but the CLI/docs still expose only channel info/list, and Slack still lacks channel-create discovery, dispatch, setup scopes, and an accepted safety gate.

## What This Changes

The issue requests native `openclaw message channel create` or equivalent message-tool channel creation for Slack, Discord, and similar message providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
