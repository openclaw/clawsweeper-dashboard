## Summary

Keep open. Current main and v2026.6.11 still lack the requested end-to-end channel creation path: Discord has partial message-action runtime support, but the CLI/docs expose only channel info/list, and Slack still lacks channel-create discovery, dispatch, setup scope, and gate support.

## What This Changes

Request to add native channel creation support to the message tool and CLI for Slack, Discord, and other messaging providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
