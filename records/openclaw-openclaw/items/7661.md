## Summary

Keep open. Current main and v2026.6.11 still lack the requested end-to-end channel creation path: Discord has provider/runtime support but no CLI/docs create surface, while Slack still lacks channel-create discovery, dispatch, setup scope, and an accepted authority gate.

## What This Changes

The issue requests a native message-tool and CLI path to create channels across Slack, Discord, and similar messaging providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
