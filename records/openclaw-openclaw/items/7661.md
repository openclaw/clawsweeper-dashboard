## Summary

Current main and v2026.6.11 still lack the requested end-to-end channel creation path: Discord has partial provider/runtime support, but the CLI/docs expose only channel info/list, and Slack lacks channel-create discovery, dispatch/runtime support, scopes, and gates. This should stay open for maintainer product/security review because agent-driven workspace or server channel creation expands administrative authority.

## What This Changes

The issue requests a native message tool and CLI path for creating Slack, Discord, and other messaging channels programmatically.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
