## Summary

Keep open. Current main and v2026.6.11 still do not provide the requested end-to-end channel creation path: Discord has partial provider/runtime support but no merged CLI/docs wiring, Slack lacks channel-create discovery/dispatch/setup scope/config gating, and the authority model for letting agents create workspace/server channels needs maintainer product/security review.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack `conversations.create` discovery/dispatch/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider policy into core.
