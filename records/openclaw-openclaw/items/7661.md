## Summary

Keep open. Current main and v2026.6.11 still lack the requested end-to-end channel creation path: Discord has partial provider support but no landed CLI/docs command, and Slack still lacks discovery, dispatch, setup scopes, and an accepted authority model.

## Best Possible Solution

Approve a provider-owned, default-off channel-admin design, then implement Slack channel-create discovery/runtime/setup/docs/tests and land or supersede the narrower Discord CLI wiring without moving provider-specific admin policy into core.
