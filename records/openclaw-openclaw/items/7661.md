## Summary

Keep open. Current main and v2026.6.11 still lack the requested end-to-end channel creation path: Discord has shared/provider-side support but no shipped CLI/docs path, and Slack still lacks channel-create discovery, runtime handling, setup scopes, and gates.

## What This Changes

The issue requests native `openclaw message channel create` and message-tool `channel-create` support for Slack, Discord, and similar messaging providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then add Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
