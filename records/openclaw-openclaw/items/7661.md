## Summary

Keep open. Current main still lacks the requested end-to-end channel creation path: Discord has partial provider/runtime support but no merged CLI command, while Slack still lacks discovery, dispatch, runtime, docs, and an explicit channel-management gate.

## What This Changes

The issue requests native message-tool and CLI support for creating messaging channels, especially Slack and Discord channel creation.

## Best Possible Solution

Approve a provider-owned, explicitly gated design: Slack should add channel-management discovery/runtime support with required setup scopes and docs, while Discord CLI parity can land through the existing focused PR or an equivalent cleaned-up replacement.
