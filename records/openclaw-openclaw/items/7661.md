## Summary

Keep open. Current main and the latest release still lack the requested end-to-end channel creation surface: Discord has partial provider/runtime support, but the CLI and docs still expose only channel info/list, and Slack still lacks channel-create discovery, dispatch, scope, and gate support.

## What This Changes

The issue requests message-tool and CLI channel creation for Slack, Discord, and similar message providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
