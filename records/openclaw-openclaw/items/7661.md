## Summary

Keep open. Current main and the latest release still do not provide the requested end-to-end channel creation path: Discord has partial provider-side support, but the CLI/docs still expose only channel info/list, and Slack still lacks channel-create discovery, dispatch, setup scope, and gate support.

## What This Changes

The issue requests a native `openclaw message channel create` or message-tool `channel-create` path for Slack, Discord, and similar messaging providers.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
