Keep open. Current main and v2026.6.11 still lack the requested end-to-end channel creation path: Discord has partial provider runtime support, but the CLI/docs expose only channel info/list, and Slack still lacks channel-create discovery, dispatch/runtime support, scopes, and gates.

## Best Possible Solution

Approve a provider-owned, default-off channel-creation design, then implement Slack discovery/runtime/setup/docs/tests and land or replace the narrower Discord CLI wiring without moving provider-specific admin policy into core.
