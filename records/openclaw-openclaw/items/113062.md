## What This Changes

The PR replaces cancellation-only delayed iOS toast, camera-flash, and Voice Wake synchronization tasks with generation-guarded actions bound to the active gateway and route.

## System Context

The iOS app schedules short-lived UI feedback and debounced Voice Wake updates from SwiftUI views. These actions flow through the app model to the active gateway, where stale delayed work could otherwise affect newer UI state or synchronize words to a changed connection.
