## What This Changes

The PR disables Discord provider streaming previews when `reply_payload_sending` or `message_sending` hooks can rewrite or cancel the eventual durable reply, and adds regression coverage for preview modes and cancellation behavior.

## System Context

Discord can show provider-generated draft previews while an agent is composing a reply, then sends the authoritative final message through outbound delivery hooks. This PR changes the preview decision so unmodified model text is not exposed before those hooks can rewrite or cancel it.
