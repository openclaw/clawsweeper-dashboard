## Summary

Keep open: the cursor fix is directionally sound, but the send fallback is incomplete for media/file replies and the external PR lacks real behavior proof for the two changed iMessage scenarios, so it is not merge-ready.

## What This Changes

The branch adds an iMessage RPC retry that strips `reply_to` for unsupported threaded text sends and rekeys the downtime recovery cursor by account plus database identity with tests.

## Best Possible Solution

Make the fallback cover every `imsg` `reply_to` rejection that can safely be resent unthreaded, including file/media sends, keep the DB-scoped cursor adoption, and add redacted real iMessage proof for AppleScript-only reply fallback plus dbPath repoint recovery.
