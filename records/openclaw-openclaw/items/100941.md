## Summary

Keep open: current main and v2026.6.11 still have the reported shape where parallel agent tool calls can fan out into many local Gateway WebSocket RPCs, and the 1006 diagnostic still includes a crash hint even when the gateway is healthy.

## What This Changes

The issue asks OpenClaw to make parallel in-process platform tool-to-Gateway calls degrade gracefully and to clarify misleading 1006 Gateway-close diagnostics.

## Best Possible Solution

Add a maintainer-approved backpressure or reusable dispatch path for agent-originated Gateway tool calls, preserve current auth/scoping guarantees, and make 1006 diagnostics describe transient load without implying a crash unless process health confirms it.
