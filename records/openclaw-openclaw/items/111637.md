The PR validates OpenRouter’s video-model catalog envelope and skips malformed rows so valid video models remain discoverable instead of a null row causing a raw exception.

## System Context

The OpenRouter plugin requests the provider’s video-model catalog through a guarded HTTP path, converts usable provider records into OpenClaw’s unified video catalog, and that catalog drives video-generation model and capability selection. This change is at the untrusted provider-response boundary before catalog projection.
