## Summary

Keep open: current main still leaves the TUI live-reasoning UX unresolved. Core/session/docs know about `stream`, and thinking events are emitted on the agent bus, but TUI help still advertises only `on|off` and the TUI agent-event handler has no `stream: "thinking"` presentation path.

## What This Changes

The issue asks for OpenAI/Grok-like live reasoning updates in OpenClaw TUI, including line rewriting or footer-style progress for thinking output.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, docs, and focused TUI/Gateway proof.
