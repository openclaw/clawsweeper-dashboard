## Summary

Keep open: current main still does not provide the requested TUI live reasoning UX. Main now emits `agent` thinking-stream events, but the TUI command hints still advertise only `on|off` and the TUI agent-event handler has no `thinking` rendering path, so the remaining blocker is the product choice for where live reasoning should appear.

## What This Changes

Request asks for OpenAI/Grok-style live reasoning updates in the TUI, including overwriting/updating reasoning text rather than only final thinking history.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, and focused TUI/Gateway proof.
