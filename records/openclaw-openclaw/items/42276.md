## Summary

Issue #42276 is still necessary: current main can accept `/reasoning stream` and produce thinking events, but the TUI still neither advertises `stream` in `/reasoning` help nor renders `agent stream=thinking` events into the terminal experience, so the central TUI UX request remains unresolved and needs a maintainer choice on presentation.

## What This Changes

Request live reasoning output in the OpenClaw TUI, ideally updating automatically during a run and possibly using the footer/status area instead of requiring manual `Show thinking`.

## Best Possible Solution

Maintainers should choose the TUI presentation model first, then update `/reasoning` help plus the TUI event path and tests so streamed thinking is discoverable and rendered consistently.
