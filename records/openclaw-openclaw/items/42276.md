## Summary

Keep open: current main still accepts and documents `reasoningLevel: "stream"`, but the TUI command surface advertises only `on|off` and the TUI agent-event handler still has no `stream: "thinking"` rendering path. The related open producer-side PR is useful context, but it is conflicting and only partially overlaps the TUI presentation request.

## What This Changes

The issue requests OpenAI/Grok-like live reasoning updates in OpenClaw TUI, including `/reasoning stream` behavior and possibly a persistent reasoning display preference.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, finalization cleanup, and focused TUI/Gateway proof while reusing existing reasoning defaults instead of adding a new config knob.
