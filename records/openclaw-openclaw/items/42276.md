## Summary

Keep open: current main still has the TUI reasoning-stream gap. The backend/session contract accepts `stream` and current agent code emits thinking-stream events, but TUI command help still advertises only `on|off` and the TUI agent-event handler has no `thinking` presentation path, so the remaining work needs a maintainer UX decision.

## What This Changes

Request an OpenAI/Grok-like live reasoning display in the OpenClaw TUI for `/reasoning stream`, possibly in an updating chat row or footer/status area.

## Best Possible Solution

Choose one TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, and focused TUI/Gateway proof.
