## Summary

Keep open: current main still lacks the requested TUI live reasoning presentation. The backend can emit thinking events and docs/config accept `stream`, but TUI help/completion still advertises only `on|off` and the TUI agent-event handler does not render `stream: "thinking"` events.

## What This Changes

The issue asks for OpenAI/Grok-like live reasoning stream rendering in the OpenClaw TUI, including line-rewriting or footer-style progress updates.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, and focused TUI PTY proof.
