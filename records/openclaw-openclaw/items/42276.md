## Summary

Keep open: current main and the latest release still accept and document `reasoningLevel: "stream"`, but TUI help/completion omit `stream` and the TUI agent-event handler has no `thinking` rendering path, so the requested live TUI reasoning UX remains unresolved.

## What This Changes

The issue requests OpenAI/Grok-style live reasoning display in OpenClaw TUI, including visible updating thinking output for `/reasoning stream`.

## Best Possible Solution

Choose one TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, and focused TUI/Gateway proof.
