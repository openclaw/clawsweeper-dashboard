## Summary

Keep open: current main still has a TUI-specific `/reasoning stream` gap. ## What This Changes

Request live OpenAI/Grok-style reasoning updates in the OpenClaw TUI for `/reasoning stream`, possibly by rewriting a chat line or using the footer/status area.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, and focused TUI/Gateway proof.
