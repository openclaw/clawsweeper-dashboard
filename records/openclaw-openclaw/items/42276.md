## Summary

Keep open: current main still accepts/documents `reasoningLevel: "stream"`, but the TUI command surface advertises only `on|off` and its agent-event handler does not render `stream: "thinking"` events, so the requested live TUI reasoning stream is not implemented.

## What This Changes

Request OpenAI/Grok-style live reasoning updates in the TUI when `/reasoning stream` is enabled.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completions, thinking-event rendering, cleanup on finalization, and focused TUI/Gateway proof.
