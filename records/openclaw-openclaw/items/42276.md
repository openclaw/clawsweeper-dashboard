## Summary

Keep open: current main still leaves the TUI `/reasoning stream` experience incomplete, and the remaining choice is a maintainer UX decision about whether live reasoning belongs in a transient chat row, the footer/status line, or only the existing Show thinking path.

## What This Changes

The issue asks for OpenAI/Grok-style live reasoning updates in the OpenClaw TUI, including clearer `/reasoning stream` behavior and possibly footer-style line rewriting.

## Best Possible Solution

Choose the TUI live-reasoning presentation contract, then align `/reasoning stream` help/completion, `agent.stream === "thinking"` rendering, cleanup on finalization, and focused TUI/Gateway proof.
