The PR retargets Telegram QA taxonomy claims, adds token-precedence and startup-`getMe` scenarios, and makes the live QA adapter render Telegram bot-targeted commands from portable command metadata.

The QA Lab runs declarative Telegram scenarios through local and live transports, then maps their assertions to taxonomy coverage used by release and maturity reporting. This PR changes how command inputs and startup/token evidence are represented so reports distinguish adapter-level authentication from the Gateway-owned Telegram startup path.
