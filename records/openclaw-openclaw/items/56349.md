## Summary

Keep open. Current main and v2026.6.11 still have only partial `message_sending` coverage; configured dispatcher hooks can omit it, Signal monitor replies still send directly, and hook failures remain fail-open, so the requested pre-send guarantee is not implemented.

## What This Changes

The issue requests a single unbypassable outbound pre-send policy boundary that can validate, modify, or block all user-visible outbound messages.

## Best Possible Solution

Define one versioned outbound lifecycle for user-visible sends, migrate direct and streaming/edit paths onto it, and document intentional non-user-content exceptions.

- **Keep hooks advisory:** Document that strict DLP/compliance enforcement is not guaranteed by the current hook surfaces and keep the remaining work out of core for now.
