## Summary

Keep this PR open: the current head still has two previously raised P1 blockers in the new accepted-manifest publish path—ignored files can be uploaded to a worker, and a failed remote replacement can leave the worker partially mutated. The PR’s stated live failure is valuable context, but its after-fix evidence is tests and checks rather than a real repeated-turn worker run.

## What This Changes

The branch adds deterministic cloud-worker manifest canonicalization and publishes the accepted reconciled workspace state back to the worker before committing the reconciliation journal.

## Best Possible Solution

Preserve the existing Git eligibility contract when computing accepted transfer paths, and make replacement of the live worker workspace atomic or explicitly restore the prior remote state on every post-removal failure; then prove a real two-turn worker scenario including an ignored file and an injected transfer or verification failure.
