## Summary

Keep this PR open: its current head is unchanged from the prior completed review and still has two P1 blockers—ignored Git files can be republished to a cloud worker, and a failed remote replacement can leave a partial worker workspace that later recovery may accept. The branch is not on current `main` or the latest release.

## What This Changes

The PR canonicalizes cloud-worker workspace manifests, republishes the accepted reconciled workspace to the worker, verifies it remotely, and only then commits the reconciliation journal.

## Best Possible Solution

Preserve Git eligibility when selecting accepted-state transfer paths, make remote publication atomic or explicitly reversible, and attach redacted repeated-turn live proof before merge.
