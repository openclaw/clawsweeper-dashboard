## What This Changes

The issue asks OpenClaw CLI bootstrap to honor `OPENCLAW_CONFIG_PATH` from a project-local `.env` instead of falling back to the default config path.

## Best Possible Solution

Maintainers should decide the workspace dotenv trust boundary; if approved, land a narrow fix that allows only the chosen config-path exception while keeping state-dir and other runtime controls blocked, with tests and docs aligned.
