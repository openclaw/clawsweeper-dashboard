## What This Changes

## Best Possible Solution

Keep one canonical caller-controlled connection deadline and add a fake-timer regression test proving that a WebSocket which never emits `open` rejects and cleans up through the existing timer; introduce a separate handshake deadline only if maintainers intentionally want distinct documented semantics.
