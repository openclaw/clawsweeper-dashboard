## What This Changes

This PR carries the DNS lookup approved for a guarded Browser CDP endpoint into WebSocket and Playwright connections, while also adding manifest fields that render plugin-owned root CLI help.

The Browser plugin validates configured Chrome DevTools Protocol endpoints, discovers CDP WebSocket URLs, and then uses those sockets for Playwright sessions and direct browser actions.
