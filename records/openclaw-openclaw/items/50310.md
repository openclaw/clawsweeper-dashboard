## What This Changes

The issue requests automatic or agent-accessible cleanup for stale Discord thread session entries that remain visible after the backing thread is archived or deleted.

## Best Possible Solution

Define a Discord-owned preview-and-revalidate cleanup contract that uses existing sessions.delete lifecycle semantics, preserves transcript-retention rules, and exposes operator or agent control only behind clear permissions.
