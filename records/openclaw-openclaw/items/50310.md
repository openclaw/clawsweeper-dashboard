## Summary

Keep open. Current main and v2026.6.11 still reset archived Discord thread sessions instead of pruning persisted rows, while generic cleanup deliberately preserves durable channel/thread session entries, so the requested auto-cleanup/delete/GC behavior remains a product-sensitive feature decision.

## What This Changes

Request to automatically or explicitly clean up stale Discord thread session entries from persisted session state when the backing Discord thread is archived, deleted, or inaccessible.

## Best Possible Solution

Define a maintainer-approved Discord orphan-session lifecycle with plugin-owned reachability checks, preview or revalidation before deletion, explicit transcript-retention rules, and clear operator or agent permissions before destructive cleanup runs.
