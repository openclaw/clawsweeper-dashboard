## What This Changes

This PR adds a Google-plugin-local strict base64 decoder for music, TTS, generated video, and Live voice media, accepting valid base64url while rejecting malformed payloads before media is materialized.

## System Context

The bundled Google plugin receives inline media from Google generation and realtime APIs, converts it into buffers, and returns audio/video to OpenClaw’s media and voice-call flows. This change validates provider-returned encoded bytes at that plugin boundary before downstream playback, transcoding, or file output.
