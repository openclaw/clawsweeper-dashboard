## Summary

The strict shared decoder and pre-decode video limit are well-scoped, but this PR should not merge as-is because it rejects URL-safe base64 that the existing Node decoder accepts and Google's ProtoJSON bytes contract permits.

## What This Changes

Adds shared strict decoding for Google music, speech, and inline video base64 responses, applies the existing video byte limit before decoding, and adds focused provider tests.

## Best Possible Solution

Keep strict malformed-input rejection and the pre-decode video limit, but make the Google-specific decoder strictly accept both standard and URL-safe base64 variants permitted by the provider contract, with regression tests for each valid alphabet and malformed junk.
