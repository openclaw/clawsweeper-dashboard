## What This Changes

The PR adds a shared strict base64 decoder for Google music, speech, and inline video responses, preserves the generated-video byte cap, and adds malformed-payload regression tests for all three paths.

## Best Possible Solution

Keep the shared plugin-local decoder and regression tests, then demonstrate a redacted live Google media generation or synthesis run showing canonical provider media still succeeds before merging.
