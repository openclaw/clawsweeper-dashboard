## Summary

Keep this PR open. The new lifecycle filter hides deprecated and disabled entries after the normal picker policy is resolved, but its exemption only checks configured model references; an exact deprecated model in `modelPolicy.allow` is therefore filtered out despite the PR’s stated and documented compatibility contract. The `maintainer` label also requires explicit maintainer handling rather than automated cleanup.

## What This Changes

This PR curates bundled provider model catalogs and hides deprecated or disabled catalog rows from default model pickers while keeping exact configured references selectable.

## System Context

Provider plugins contribute static model catalogs to OpenClaw, which the gateway projects into CLI, chat, and Control UI model-picker views. The visibility policy combines provider availability, explicit model policy, and configured references before clients display selectable models.

## Best Possible Solution

Preserve exact explicit `modelPolicy.allow` entries through lifecycle filtering, then add a regression case for a deprecated catalog model that is allowed but otherwise unconfigured; retain the intended hiding behavior for non-exact or unreferenced legacy rows.
