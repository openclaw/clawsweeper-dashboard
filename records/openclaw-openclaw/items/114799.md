## What This Changes

This PR replaces scattered no-visible-reply fallback checks with a per-turn ledger that waits for queued and routed reply delivery settlement before deciding whether to send a fallback message.

## System Context

OpenClaw's auto-reply dispatcher turns an agent result into channel messages, then decides whether a visible turn ended without a reply and needs a fallback. The proposed ledger consolidates delivery facts from dispatcher queues and routed sends before finalization returns the turn result to channel consumers.
