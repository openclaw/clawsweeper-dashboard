## What This Changes

This PR replaces scattered queue-admission visibility checks with a per-turn delivery ledger so the automatic no-visible-reply fallback is decided from settled dispatcher and routed-send outcomes.

## System Context

Auto-reply dispatch turns agent output, hooks, tool results, and routed replies into channel messages. The finalization step decides whether a user has already seen a contentful reply; if not, it can send a fallback instead of allowing the turn to end silently.
