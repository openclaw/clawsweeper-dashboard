## What This Changes

This PR makes the Microsoft Foundry plugin assign documented GPT context-window and output-token limits to custom deployment aliases using each deployment’s canonical discovered model name.

## System Context

The Microsoft Foundry plugin discovers deployments during provider login and writes provider-model metadata into OpenClaw configuration. Agents consume that metadata to decide prompt compaction and output limits, so a deployment alias must retain the capability family of the underlying Foundry model.
