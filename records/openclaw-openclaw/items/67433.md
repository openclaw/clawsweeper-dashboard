- **[P1] Redact hook failure details before returning them:** `src/gateway/server/hooks-request-handler.ts:373-383`
  - body: The new error responses return `String(err)` and `agentError` directly to the external hook caller. `agentError` is derived from run summaries/errors and thrown exceptions can include provider, tool, path, or runtime details, so this should return a stable public error code/message and keep details in logs or internal events.
  - confidence: 0.9
- **[P1] Keep idempotency effective for wait-mode retries:** `src/gateway/server/hooks-request-handler.ts:318-320`
  - body: When `waitForResult` is true, `replayKey` is forced to `undefined`, so a retry with the same idempotency key after a client timeout or lost response starts another isolated agent run. That breaks the existing hook dedupe expectation and can duplicate messages or side effects; preserve/replay the wait result or reject/document idempotency for this mode explicitly.
  - confidence: 0.86
- **[P2] Replay the same accepted response shape on idempotency hits:** `src/gateway/server/hooks-request-handler.ts:340-341`
  - body: The fresh async path now returns `status` and `sessionKey`, but the replay-cache hit still returns only `{ ok, runId }`. A retry with the same idempotency key should not get a different response contract from the original accepted request.
  - confidence: 0.82
- **[P2] Bound and sanitize returned agent output:** `src/gateway/server/hooks-request-handler.ts:387-393`
  - body: `result` reflects `outputText` directly, while the upstream type documents that output text is not truncated. Add a response byte/character cap and the same kind of redaction/control-character handling used by other transcript surfaces before exposing agent text through hook ingress.
  - confidence: 0.84
- **[P2] Document the new hook response contract:** `src/gateway/hooks.ts:229-238`
  - body: This adds public `waitForResult` and `announceToMain` fields plus new response statuses and error semantics, but the gateway docs still list the old async-only `/hooks/agent` contract. Update the public hook docs before merge so external callers know the timeout, idempotency, result, and error behavior.
  - confidence: 0.78
