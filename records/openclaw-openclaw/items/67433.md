## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Redact hook failure details before returning them:** `src/gateway/server/hooks-request-handler.ts:368-379`
  - body: The new error responses return `String(err)` and `agentError` directly to the external hook caller. Those values can include provider, tool, path, runtime, or diagnostic details, so return a stable public error code/message and keep details in logs or internal events.
  - confidence: 0.9
- **[P1] Keep idempotency effective for wait-mode retries:** `src/gateway/server/hooks-request-handler.ts:313-315`
  - body: When `waitForResult` is true, `replayKey` is forced to `undefined`, so a retry with the same idempotency key after a client timeout or lost response starts another isolated agent run. That breaks the existing hook dedupe expectation and can duplicate messages or other side effects.
  - confidence: 0.86
- **[P2] Return the same async response shape on replay hits:** `src/gateway/server/hooks-request-handler.ts:335-336`
  - body: The fresh async path now returns `status` and `sessionKey`, but the replay-cache hit still returns only `{ ok, runId }`. A retry with the same idempotency key should not get a different response contract from the original accepted request.
  - confidence: 0.82
- **[P2] Bound and sanitize returned agent output:** `src/gateway/server/hooks-request-handler.ts:387`
  - body: `result` reflects `outputText` directly, while the upstream type documents that output text is not truncated. Add a response byte/character cap and redaction/control-character handling before exposing agent text through hook ingress.
  - confidence: 0.84
- **[P2] Document the new hook response contract:** `src/gateway/hooks.ts:235-238`
  - body: This adds public `waitForResult` and `announceToMain` fields plus new response statuses and error semantics, but the gateway docs still list the old async-only `/hooks/agent` contract. Update the public hook docs before merge so external callers know the timeout, idempotency, result, and error behavior.
  - confidence: 0.78
