## Summary

Keep open: the reported failure is valid and Gateway-side credential handoff is the right layer, but the unchanged head still creates a reusable origin-wide operator grant without binding it to credential revocation or the selected plugin route. Contributor-provided real browser behavior proof is also still absent.

## What This Changes

The PR adds a five-minute signed HttpOnly cookie that carries authenticated Control UI operator scopes into gateway-protected external plugin iframe routes, with focused gateway and UI tests.

## Best Possible Solution

Use an authenticated per-tab launch endpoint that mints a short-lived grant bound to the selected registered route prefix, least-required scopes, and current Gateway or device-session generation; reject route or generation mismatches before deriving runtime scopes.
