## Summary

Keep this PR open, but do not merge it yet: the gateway-side handoff is directionally appropriate, while the proposed browser credential needs a tighter security boundary and live after-fix proof.

## What This Changes

The PR adds a short-lived signed HttpOnly cookie that carries Control UI operator scopes into gateway-authenticated external plugin iframe routes, with focused gateway and UI tests.

## Best Possible Solution

Use a short-lived plugin-tab launch grant that is bound to the intended plugin route and current gateway authorization generation, preserve direct unauthenticated 401 responses, and prove the complete flow in a real browser with visible network diagnostics.
