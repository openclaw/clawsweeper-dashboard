## What This Changes

The issue reports that `openclaw doctor` can suggest removing the active macOS gateway LaunchAgent plist and can mishandle runtime-resolved `exec:keychain:` SecretRefs as fatal doctor errors.

## Best Possible Solution

Land a focused doctor/status fix that suppresses cleanup hints for the active current gateway, renders cleanup guidance from detected stale or legacy service metadata, preserves strict runtime SecretRef semantics, and adds macOS LaunchAgent plus SecretRef regression coverage.
