## What This Changes

Investigate why a healthy, policy-allowed Streamable HTTP MCP server is not included in a live agent session's discoverable tool surface or invoked through ToolSearch.

## System Context

Configured MCP servers are checked by the MCP probe and doctor commands, then the active agent backend creates a session-scoped MCP runtime and materializes its tools for the agent run. The resulting tool catalog feeds policy filtering and deferred tool discovery, which determines whether the model can find and call the server.
