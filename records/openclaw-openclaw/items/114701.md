## Summary

Keep this PR open for repair and product review. The changed helper can resolve `displayName` and `subject` only when it receives a session entry, but this one-file patch does not update the existing string-based call sites identified by the linked proposal, so the intended title chain is not reached in current ClickClack discussion flows. It also needs redacted after-fix ClickClack proof before merge.

## What This Changes

This PR expands ClickClack discussion-label resolution to prefer a session entry’s explicit label, generated display name, or subject before using the hash fallback.

## System Context

The ClickClack plugin creates and reconciles workspace discussion channels from OpenClaw sessions. Its naming helper determines the human-readable label passed from session metadata into those channels, falling back to a short hash when no title is available.
