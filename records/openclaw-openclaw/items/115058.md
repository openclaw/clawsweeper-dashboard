## Summary

## What This Changes

The branch updates the OpenShell sandbox backend to use 19-character deterministic runtime names, retain matching registered legacy names during upgrade, and refresh OpenShell compatibility tests and documentation.

## System Context

When an agent needs sandboxed execution, OpenClaw resolves the configured backend and asks it to construct a runtime for the agent scope. The OpenShell plugin maps that scope to a managed OpenShell sandbox, while the core registry records runtime identities so existing remote workspaces can remain addressable across upgrades.
