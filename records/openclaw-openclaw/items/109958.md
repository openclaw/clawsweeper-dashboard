## Summary

Keep open for maintainer review: current main still silently discards malformed gateway-port inputs, while the focused patch consistently fixes that behavior without a concrete correctness defect.

## What This Changes

The PR makes `openclaw onboard` and `openclaw setup` validate explicit `--gateway-port` values at the CLI boundary and reject malformed or out-of-range ports before setup begins.

## Best Possible Solution

Keep validation at the shared Commander option boundary, preserve undefined for genuinely omitted values, and land after maintainers explicitly accept malformed explicit ports becoming hard errors.
