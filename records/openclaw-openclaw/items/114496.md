## What This Changes

This PR centralizes Control UI user-avatar identity, authenticated image rendering, and fallback behavior so the roster, profile, and attributed chat show the same initials and color for the same person.

## System Context

The Control UI receives presence and sender identities from Gateway-backed state, then renders those identities in the sidebar, profile, and chat. This change places the common user-avatar presentation lifecycle between the existing identity/image cache and those UI surfaces.
