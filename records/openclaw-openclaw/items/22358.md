## Label Justifications

- `P2`: This is a normal-priority plugin/API feature with real subagent workflow impact, but it is not a current emergency or confirmed outage.
- `impact:session-state`: The requested hook would observe and possibly alter subagent completion state, child-run metadata, and parent-session handoff behavior.
- `impact:security`: The hook could expose child completion data or transcript-derived content to plugins and permit suppression or rewriting at a security-sensitive lifecycle boundary.
- `impact:message-loss`: A primary use case is detecting failed completion announcements and triggering fallback notification before users lose subagent results.

## Summary

Keep open: current main and v2026.6.11 still expose only adjacent observation/routing hooks, while the requested post-subagent-completion/pre-announcement plugin hook with payload access, delivery-result visibility, and announcement mutation semantics remains missing.

## What This Changes

The issue requests a public post-subagent-completion extension hook that can inspect child-run output/history and optionally enrich, suppress, or filter the completion announcement before it reaches the parent session.

## Best Possible Solution

Keep this issue open for maintainer API design: either add a typed plugin hook at the post-subagent-completion/pre-announcement seam, or land a broader lifecycle/delivery contract that covers bounded child metadata, safe result access, delivery-result visibility, and explicit enrichment/suppression semantics.

## Reproduction Assessment

Yes, by source inspection for the missing capability. Current main and v2026.6.11 list only adjacent subagent hooks and the announce flow has no public hook before deliverSubagentAnnouncement or after delivery status is known.

## Solution Assessment

Unclear pending maintainer design. A typed plugin hook is plausible and aligned with the plugin API direction, but the best solution must settle payload bounds, permissions, delivery-result timing, mutation/suppression semantics, and how it relates to the broader lifecycle-hook and guard-hook work.
