## Summary

Keep open. Current main and the latest release still expose only adjacent subagent observation/routing hooks; they do not provide the requested post-subagent-completion, pre-announcement hook that can inspect, enrich, suppress, or observe delivery outcome.

## What This Changes

The issue requests a new plugin extension hook that fires after a spawned subagent completes and before its completion announcement is delivered to the parent session.

## Best Possible Solution

Settle and land a typed plugin API or equivalent lifecycle/delivery contract that covers post-child-result/pre-announcement inspection, bounded safe data access, delivery-status visibility, and explicit return semantics for enrichment, suppression, or blocking.

## Reproduction Assessment

Do we have a high-confidence way to reproduce the issue? Yes by source inspection: current main lacks the requested hook, and the existing subagent hooks cannot inspect or alter the final announcement result.

## Solution Assessment

Is this the best way to solve the issue? Unclear until maintainers settle the API and security model; the maintainable path is a typed plugin hook or equivalent lifecycle/delivery contract, not an ad hoc script hook.
