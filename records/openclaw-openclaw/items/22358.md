## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent lifecycle/routing hooks, while the requested post-completion/pre-announcement plugin interception point remains missing and still needs maintainer API/security design.

## What This Changes

The issue requests a public plugin hook after subagent completion and before the parent completion announcement so plugins can inspect child output/state, persist artifacts, and enrich, suppress, or filter the announcement.

## Best Possible Solution

Define one maintainer-approved typed plugin lifecycle/delivery contract at this seam, with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit return semantics, docs, and focused ordering/regression tests.
