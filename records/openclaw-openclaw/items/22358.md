## Summary

Keep open. Current main and v2026.6.11 still expose only adjacent subagent lifecycle/routing hooks, not the requested post-subagent-completion/pre-announcement hook that can inspect, enrich, suppress, or observe completion delivery; the overlapping open PR is not merged and still needs API/security review.

## What This Changes

Request a plugin extension hook that runs after a spawned subagent completes and before the parent completion announcement, allowing inspection, persistence, enrichment, suppression, or delivery-failure handling.

## Best Possible Solution

Approve a public typed plugin lifecycle/delivery hook, or equivalent canonical lifecycle contract, that covers post-child-result/pre-announcement inspection with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit return semantics, docs, and focused ordering/regression tests.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 lack the requested post-completion/pre-announcement hook, while the adjacent subagent hooks cannot inspect or modify the final announcement result.

## Solution Assessment

Unclear pending maintainer API and security design. A typed plugin hook or equivalent lifecycle/delivery contract is the right layer, but the exact payload, ordering, suppression, and delivery-status semantics still need approval.
