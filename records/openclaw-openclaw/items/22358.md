## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent lifecycle/routing hooks, not the requested post-subagent-completion/pre-announcement hook with child-output access, delivery-result visibility, or announcement mutation semantics.

## What This Changes

The issue requests a public extension hook that runs after a subagent finishes and before the parent-session completion announcement is sent, with access to completion data and possible announcement mutation.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, explicit delivery-status visibility, return semantics, docs, and focused ordering/security regression tests.
