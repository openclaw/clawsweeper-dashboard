## Summary

Keep open: current main and v2026.6.11 still expose adjacent subagent observation/routing hooks only, not the requested post-completion/pre-announcement hook that can inspect child output, observe delivery status, or mutate/suppress the announcement. The remaining work is valid, but it needs maintainer API and security-boundary design, especially after https://github.com/openclaw/openclaw/pull/56904 was closed as the wrong public hook shape.

## What This Changes

Request a public post-subagent-completion hook that can inspect child results or history, observe delivery status, and enrich, filter, or suppress the parent completion announcement.

## Best Possible Solution

Define a maintainer-approved typed plugin lifecycle or delivery boundary for post-child-result/pre-announcement processing, with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit mutation or suppression semantics, docs, and focused ordering/regression tests.
