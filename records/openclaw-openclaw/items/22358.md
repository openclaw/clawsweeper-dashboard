## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent observation/routing hooks, not the requested post-subagent-completion/pre-announcement hook that can inspect child output/history, enrich or suppress announcements, or observe delivery outcome. The exact API should be narrowed by maintainer product/security review after the related guard-hook PR was closed as too broad.

## What This Changes

The issue requests a public plugin hook after a spawned subagent completes and before its completion announcement is delivered.

## Best Possible Solution

Keep this as maintainer API design, narrowed toward safe subagent lifecycle metadata plus a generic product-driven delivery/output boundary for enrichment, filtering, suppression, and delivery-result handling.
