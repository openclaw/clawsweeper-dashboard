## Summary

Keep open. Current main and v2026.6.11 still expose only adjacent subagent lifecycle and routing hooks; the requested post-completion/pre-announcement extension point that can inspect child output, observe delivery status, and modify or suppress the completion announcement is still missing.

## What This Changes

Request a public extension hook that fires after a subagent completes and before its completion announcement is sent upstream.

## Best Possible Solution

Keep this open for maintainer API design: add a typed post-completion/pre-announcement plugin hook or equivalent lifecycle/delivery contract with bounded payloads, delivery status visibility, explicit return semantics, docs, and regression tests.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 list only adjacent subagent hooks, and the announce flow calls delivery without a public interception hook. This is a missing feature rather than a failing runtime bug.

## Solution Assessment

Unclear pending maintainer API and security design. A typed post-completion/pre-announcement hook is plausible, but the best fix must settle payload bounds, delivery status exposure, ordering/timeouts, and return semantics across plugin and lifecycle surfaces.
