## Summary

## What This Changes

Request to add a public post-subagent-completion extension hook that can inspect child run data and enrich, filter, suppress, or otherwise affect the completion announcement before it reaches the parent session.

## Best Possible Solution

Keep this issue open for a maintainer-approved plugin lifecycle/delivery hook contract with bounded payloads, permission gates, clear return semantics, docs, and focused announce-flow tests.

## Reproduction Assessment

Yes. Source inspection on current main shows the hook catalog, ended hook payload, and announce delivery path lack the requested post-completion/pre-announcement interception point; this is a feature gap rather than a failing existing behavior test.

## Solution Assessment

Unclear pending maintainer design. A typed plugin hook at this seam is plausible, but the best solution must settle payload bounds, permission gates, ordering, timeouts, delivery-status visibility, and rewrite/suppression semantics before implementation.
