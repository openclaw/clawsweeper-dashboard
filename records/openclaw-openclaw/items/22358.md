## Summary

Keep open: current main and the latest release still expose only adjacent subagent lifecycle/routing hooks, not a post-subagent-completion/pre-announcement hook that can inspect, enrich, suppress, or observe delivery. The remaining work is real, but recent related PR feedback points toward maintainer API/security design for a generic completion or delivery boundary rather than a narrow subagent-only hook.

## What This Changes

Issue requests a post-subagent-completion plugin hook that can inspect subagent results and influence the parent completion announcement.

## Best Possible Solution

Define a maintainer-approved completion or delivery extension boundary that covers post-subagent completion observation, safe metadata/result access, delivery outcome visibility where appropriate, and any allowed announcement enrichment or suppression, with docs and focused ordering/security tests.
