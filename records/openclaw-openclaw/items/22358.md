## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent observation/routing hooks, not the requested post-completion/pre-announcement extension point with child output/history, delivery-result visibility, or announcement mutation semantics.

## What This Changes

Request a public extension hook that fires after a spawned subagent completes and before the parent completion announcement is delivered, with access to completion state and possible announcement enrichment or suppression.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, explicit delivery-status visibility, return semantics, docs, and focused ordering/security regression tests.
