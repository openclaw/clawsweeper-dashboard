## Summary

Keep open: current main and v2026.6.11 still expose adjacent subagent lifecycle, delivery-target, and message hooks, but not the requested post-subagent-completion/pre-announcement hook with child output/history, delivery-result visibility, or announcement mutation semantics.

## What This Changes

Request a public extension hook after a subagent finishes and before completion announcement delivery so plugins can inspect completion data, persist artifacts, and enrich, filter, or suppress announcements.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, explicit delivery-status visibility, return semantics, docs, and focused ordering/security regression tests.
