## Summary

Keep open. Current main still has only adjacent subagent lifecycle/routing hooks; it does not expose a public post-child-result, pre-announcement hook that can inspect, enrich, suppress, or observe delivery outcome for subagent completions.

## What This Changes

Request a public extension hook that fires after a subagent finishes and before its completion announcement is sent to the parent/requester session.

## Best Possible Solution

Approve and land a typed plugin API that covers post-child-result/pre-announcement inspection with bounded child metadata, safe output access, delivery-status visibility where appropriate, and explicit return semantics for enrichment, suppression, or blocking.

## Reproduction Assessment

Do we have a high-confidence way to reproduce the issue? Not as a runtime bug, but yes by source inspection: current main lacks the requested hook and the existing subagent hooks cannot modify or observe the final announcement result.

## Solution Assessment

Is this the best way to solve the issue? Unclear until maintainers settle the API and security model; the right shape is a typed plugin hook or equivalent lifecycle/delivery contract, not an ad hoc arbitrary script hook.
