## Summary

Keep open: current main and the latest release still expose only adjacent observation/routing hooks, not the requested post-subagent-completion hook that can inspect, enrich, suppress, or react to delivery results before the parent announcement.

## What This Changes

Request a public plugin extension hook after a subagent finishes and before its completion announcement is sent upstream.

## Best Possible Solution

Design a typed plugin hook or lifecycle/delivery API at the post-completion/pre-announcement seam with bounded metadata, safe child-output access, delivery result visibility, explicit rewrite/suppress semantics, docs, and regression tests.

## Reproduction Assessment

Yes for the source-level capability gap: current main exposes adjacent subagent observation/routing hooks, but no public post-completion/pre-announcement hook with payload or delivery-result control. This is a feature request, not a failing runtime reproduction.

## Solution Assessment

Unclear until maintainers settle the API contract. A narrow public plugin hook at the announce seam is plausible, but the best solution must first define privacy, ordering, timeout, and rewrite/suppression semantics.
