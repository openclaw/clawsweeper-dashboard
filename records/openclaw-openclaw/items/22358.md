## Summary

Keep open. Current main and v2026.6.11 still expose only adjacent subagent lifecycle and routing hooks; the requested post-child-result, pre-announcement plugin hook that can inspect, enrich, suppress, or observe delivery outcome does not exist yet.

## What This Changes

Request a public extension hook after a spawned subagent finishes and before or around parent-session completion announcement delivery, with access to completion metadata and optional announcement enrichment or suppression.

## Best Possible Solution

Approve a typed plugin API or equivalent lifecycle/delivery contract that covers post-child-result/pre-announcement inspection with bounded child metadata, safe output access, delivery-status visibility where appropriate, and explicit return semantics for enrichment, suppression, or filtering.

## Reproduction Assessment

Yes by source inspection, not as a runtime bug: current main lacks the requested hook, and the existing subagent hooks cannot modify the announcement or observe the final delivery outcome.

## Solution Assessment

Unclear pending maintainer API and security design; the direction is plausible, but the best solution should be a narrow typed plugin hook or equivalent lifecycle/delivery contract rather than an arbitrary script callback.
