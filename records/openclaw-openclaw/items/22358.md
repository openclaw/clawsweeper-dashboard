## Summary

Keep open: current main and the latest release still expose only adjacent subagent observation/routing hooks, not the requested post-subagent-completion/pre-announcement plugin interception point. The overlapping open implementation PR is blocked by API/security review findings, so it is not a safe replacement or implemented-on-main close path.

## What This Changes

Request a public post-subagent-completion hook that can inspect child results and optionally enrich, filter, or suppress the completion announcement before it reaches the parent session.

## Best Possible Solution

Define a typed plugin lifecycle hook or canonical lifecycle/delivery design that exposes bounded child-run metadata and safe completion output at the pre-announcement point, with explicit return semantics and tests for delivery, suppression, and failure handling.

## Reproduction Assessment

Yes at source level: current main can be checked in the hook catalog, subagent_ended payload, and announce flow to confirm the interception hook is absent. This is a missing feature/API seam rather than a runtime bug reproduction.

## Solution Assessment

Unclear until maintainers settle the plugin API and security contract. A typed hook at this seam is plausible, but the exact payload, ordering, delivery-result visibility, and mutation rights need product/security design.
