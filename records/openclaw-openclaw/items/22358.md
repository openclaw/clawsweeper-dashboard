## Summary

Keep open. Current main and v2026.6.11 still expose only adjacent subagent observation/routing hooks; they do not provide the requested post-child-result, pre-announcement extension point that can inspect, enrich, suppress, or observe delivery outcome for subagent completions.

## What This Changes

Request a public extension hook that fires after a spawned subagent finishes and before the parent completion announcement is delivered, with access to child result/history metadata and announcement return semantics.

## Best Possible Solution

Design a narrow public plugin hook or lifecycle/delivery contract at the post-child-result, pre-announcement point with bounded payloads, explicit ordering, timeout/failure behavior, delivery-status visibility, return semantics, docs, and focused regression tests.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 lack the requested post-completion/pre-announcement hook, while the existing subagent_ended and subagent_delivery_target hooks cover only observation and routing.

## Solution Assessment

Unclear pending maintainer API and security design. A public hook at this seam is plausible, but the best solution must settle bounded payloads, delivery-status exposure, mutation semantics, and how this relates to broader lifecycle-hook work.
