## Summary

Keep open: current main and v2026.6.11 still have adjacent subagent lifecycle and delivery-target hooks, but not a post-subagent-completion/pre-announcement hook with child output/history access, delivery-result visibility, or announcement mutation semantics.

## What This Changes

The issue requests a plugin extension hook that runs after a spawned subagent completes and before the parent-session completion announcement is sent, with access to completion context and possible announcement mutation.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, delivery-status visibility, return semantics, docs, and focused ordering/security regression tests.
