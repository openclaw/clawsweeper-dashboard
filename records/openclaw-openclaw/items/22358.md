## Summary

Keep open. Current main and v2026.6.11 still expose only adjacent subagent lifecycle/routing hooks; the requested post-child-result, pre-announcement hook is missing, and the overlapping PR is open but not a safe canonical replacement yet.

## What This Changes

The issue requests a public post-subagent-completion extension hook that can inspect child completion data, alter or suppress the parent announcement, and support deterministic follow-up processing.

## Best Possible Solution

Approve and land a typed plugin API or equivalent lifecycle/delivery contract that covers post-child-result and pre-announcement inspection with bounded child metadata, safe output access, delivery-status visibility where appropriate, and explicit return semantics for enrichment, suppression, or blocking.

## Reproduction Assessment

Yes by source inspection, not as a failing runtime bug: current main exposes adjacent subagent lifecycle/routing hooks but no hook that can inspect, rewrite, suppress, or observe delivery outcome for the completion announcement.

## Solution Assessment

Unclear until maintainers settle the API and security model; the right shape is a typed plugin hook or equivalent lifecycle/delivery contract, not an ad hoc arbitrary script hook.
