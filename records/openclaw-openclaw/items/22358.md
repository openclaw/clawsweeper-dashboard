## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent observation/routing hooks, not a post-completion/pre-announcement hook with child output/history, delivery-result visibility, or announcement mutation semantics.

## What This Changes

The issue asks for a public hook after spawned subagent completion and before parent announcement delivery so plugins can inspect results/history, persist artifacts, and enrich or suppress completion announcements.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, explicit delivery-status visibility, return semantics, docs, and focused ordering/security regression tests.
