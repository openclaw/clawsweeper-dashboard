## Summary

Keep open. Current main still exposes only adjacent subagent lifecycle and routing hooks, while the requested post-child-result/pre-announcement hook that can inspect, enrich, suppress, or observe completion delivery remains a real plugin API gap.

## What This Changes

Requested a public post-subagent-completion extension hook that can inspect child completion state and influence the completion announcement before it is sent upstream.

## Best Possible Solution

Approve and land a typed plugin API or equivalent lifecycle/delivery contract that covers post-child-result/pre-announcement inspection with bounded child metadata, safe output access, delivery-status visibility where appropriate, and explicit return semantics for enrichment, suppression, or blocking.

## Reproduction Assessment

Yes by source inspection, though this is a feature/API gap rather than a runtime bug: current main lacks the requested post-completion hook and the existing subagent hooks cannot modify or observe final announcement delivery.

## Solution Assessment

Unclear until maintainers settle the API and security model; the maintainable direction is a typed plugin hook or equivalent lifecycle/delivery contract, not an ad hoc arbitrary script hook.
