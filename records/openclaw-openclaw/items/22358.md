## Summary

Keep open: current main and v2026.6.11 still only expose adjacent subagent observation/routing hooks, not the requested post-completion/pre-announcement extension point with child output/history, delivery-result visibility, or announcement mutation semantics.

## What This Changes

The issue requests a public extension hook that runs after a spawned subagent finishes and before its completion announcement is sent, with access to child-run data and optional announcement enrichment, filtering, or suppression.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, explicit delivery-status visibility, return semantics, docs, and focused ordering/security regression tests.
