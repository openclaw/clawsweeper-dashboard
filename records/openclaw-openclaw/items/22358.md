## Summary

## What This Changes

The issue requests a public post-subagent-completion hook that can inspect a finished child run and influence or observe the completion announcement before it is surfaced to the parent session.

## Best Possible Solution

Approve a typed plugin lifecycle or delivery hook, or equivalent canonical lifecycle contract, that covers post-child-result/pre-announcement inspection with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit return semantics, docs, and focused ordering/regression tests.

## Reproduction Assessment

## Solution Assessment

Unclear pending maintainer API and security design. A typed plugin hook or equivalent lifecycle/delivery contract is the right layer, but the exact payload, ordering, suppression, and delivery-status semantics still need approval.
