## Summary

Keep open: current main and v2026.6.11 still expose only adjacent observation/routing subagent hooks, not the requested post-subagent-completion/pre-announcement hook that can inspect, enrich, suppress, or observe delivery. The overlapping guard-hook PR is open but unmerged and still has public API/security blockers, so it is not a safe supersession target.

## What This Changes

Issue requests a public post-subagent-completion hook that can inspect child completion data, persist artifacts, and optionally enrich, filter, or suppress the parent completion announcement.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery hook, or equivalent canonical lifecycle contract, with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit return semantics, docs, and focused ordering/regression tests.
