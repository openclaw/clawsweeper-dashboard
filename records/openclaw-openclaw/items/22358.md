## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent lifecycle/routing hooks, not the requested post-subagent-completion/pre-announcement hook that can inspect, enrich, suppress, or observe completion delivery.

## What This Changes

The issue requests a public plugin hook that fires after a spawned subagent completes and before the completion announcement is sent to the parent session.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery hook, or equivalent canonical lifecycle contract, with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit return semantics, docs, and focused ordering/regression tests.
