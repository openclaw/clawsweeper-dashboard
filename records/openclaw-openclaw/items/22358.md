## Summary

Keep open: current main and the latest release still expose only adjacent subagent observation/routing hooks, while this issue asks for a mutable post-completion/pre-announcement plugin API; the closest implementation PR is still open, conflicting, and review-blocked.

## What This Changes

Request a public extension hook after subagent completion and before parent-session announcement delivery so plugins can inspect child results, persist artifacts, observe delivery status, and enrich or suppress announcements.

## Best Possible Solution

Keep this as the narrow canonical design item, then land either a bounded typed plugin hook at the post-subagent-completion/pre-announcement seam or a broader lifecycle/delivery API that explicitly covers safe child metadata, output access, delivery-result visibility, and announcement mutation semantics.
