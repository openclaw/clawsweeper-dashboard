## Summary

Keep open: current main and v2026.6.11 still expose only adjacent subagent observation/routing hooks, while this issue asks for a mutable post-completion/pre-announcement plugin API; the closest implementation PR is open, conflicting, and review-blocked.

## What This Changes

Request for a public post-subagent-completion hook that can inspect child run output/state, observe delivery status, and optionally enrich, suppress, or filter the completion announcement before it reaches the parent session.

## Best Possible Solution

Keep this open for a maintainer-approved typed plugin/lifecycle contract that covers bounded child metadata, safe completion output access, delivery-status visibility, and explicit return semantics for announcement enrichment, suppression, or filtering, with docs and focused ordering/regression tests.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 expose adjacent observation/routing hooks but no mutable post-completion/pre-announcement hook with completion output, delivery result, or announcement return semantics.

## Solution Assessment

Unclear pending maintainer API/security design. A typed plugin hook at this seam is plausible, but the best solution must settle payload bounds, ordering, delivery-result visibility, and mutation/suppression semantics before implementation.
