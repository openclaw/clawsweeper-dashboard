## Label Justifications

- `P2`: This is a normal-priority plugin API gap with real but bounded impact on production subagent workflows.
- `impact:session-state`: The request centers on child completion state, subagent session history, post-run artifacts, and parent-session completion context.
- `impact:security`: The proposed hook may expose child output/history and allow plugins to rewrite or suppress completion delivery.
- `impact:message-loss`: The discussion ties the missing hook to detecting or recovering failed subagent completion announcements in channel workflows.

## Summary

Keep open: current main and latest release still lack the requested post-subagent-completion/pre-announcement plugin hook; adjacent hooks observe lifecycle or route delivery but cannot inspect child output, enrich or suppress the announcement, or observe final delivery as a public contract.

## What This Changes

The issue requests a typed extension hook after subagent completion and before parent-session completion announcement delivery.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery hook, or equivalent canonical lifecycle contract, with bounded metadata, safe output access, delivery-status visibility where appropriate, explicit return semantics, docs, and focused ordering/regression tests.

Rationale: The source gap is clear, but event naming, payload shape, redaction, timeout/error handling, audit behavior, plugin authority, and compatibility with broader lifecycle work are public API and security-sensitive product decisions.

Likely owner: steipete

Owner confidence: high

Options:

- **Typed Plugin Delivery Hook (recommended):** Add a bounded typed hook at the post-child-result/pre-announcement seam with explicit metadata, redaction, timeout, audit, and return semantics for enrichment or suppression.
- **Fold Into Broader Lifecycle Design:** Hold this request until the broader lifecycle-hook design at https://github.com/openclaw/openclaw/issues/43454 settles one event model across subagents, turns, and tool thresholds.
- **Observation-Only Event:** Expose only a non-mutating completion event and leave announcement mutation or suppression to separate delivery-policy work such as https://github.com/openclaw/openclaw/issues/13911.

## Reproduction Assessment

## Solution Assessment

Unclear pending maintainer API and security design. A typed plugin hook or equivalent lifecycle/delivery contract is the right layer, but payload, ordering, suppression, and delivery-status semantics still need approval.
