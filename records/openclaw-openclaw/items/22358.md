## Summary

Keep open: current main and v2026.6.11 still expose adjacent subagent lifecycle, delivery-target, and message hooks, but not the requested post-subagent-completion/pre-announcement hook with child output/history access, delivery-result visibility, or announcement mutation semantics.

## What This Changes

Request to add a programmatic hook after a spawned subagent completes and before its completion announcement is surfaced to the parent session.

## Best Possible Solution

Approve one typed plugin lifecycle or delivery boundary, or an equivalent canonical delivery contract, with bounded metadata, safe child-output access, explicit delivery-status visibility, return semantics, docs, and focused ordering/security tests.
