## Summary

Keep open: current main and v2026.6.11 still provide only adjacent subagent lifecycle/routing hooks, not the requested post-subagent-completion/pre-announcement plugin hook with safe inspection, mutation, suppression, or delivery-status semantics.

## What This Changes

Request a plugin extension hook after a spawned subagent completes and before its completion announcement is sent upstream.

## Best Possible Solution

Define a maintainer-approved typed plugin lifecycle or delivery contract for completed child runs, with bounded metadata, explicit data-access permissions, delivery-status visibility where appropriate, return semantics, docs, and focused ordering/regression tests.
