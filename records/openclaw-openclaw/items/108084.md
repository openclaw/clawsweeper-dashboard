## Summary

This PR appears to be a bounded and technically plausible repair for failed plugin-registration rollback, with direct terminal proof and focused regression coverage. It should remain open because the same transaction invariant is also implemented by the proof-positive open PR at https://github.com/openclaw/openclaw/pull/108143; a maintainer should choose one canonical branch before either lands, rather than merging overlapping snapshot implementations.

## What This Changes

This PR snapshots registry entries and the active plugin record so a failed plugin registration restores mutable metadata without replacing plugin-owned runtime objects.

## System Context

Runtime, channel setup, and CLI plugin loaders create a transaction around a plugin’s registration callback. The transaction records registry state and the in-progress plugin record, then either commits successful registrations or restores the prior metadata before reporting the failure.
