## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P2] Clear stale CLI validation cache on failed probes:** `apps/macos/Sources/OpenClaw/CLIInstaller.swift:101-103`
  - body: `CLIInstaller.status()` revalidates the preferred cached executable, but when that path is now unusable or incompatible it only returns a non-ready status. Because `CommandResolver.validatedOpenClawExecutable()` still trusts the old stored version string, later Gateway commands keep putting that stale path first and can continue starting or failing against it until a new install overwrites the cache. Clear the validated executable/version when a cached candidate fails validation.
  - confidence: 0.88
- **[P2] Do not classify unfinished onboarding as an upgrade:** `apps/macos/Sources/OpenClaw/MenuBar.swift:361-362`
  - body: A first-run user can select This Mac, which persists `.local`, then quit before Finish sets `onboardingSeen`. On relaunch this branch passes `isExistingInstallation: true` and durably stores the primary identity, so a fresh install loses the dedicated node identity and reuses the operator identity for the app-owned node. Base the upgrade-preservation decision on completed onboarding, not transient connection mode.
  - confidence: 0.91
