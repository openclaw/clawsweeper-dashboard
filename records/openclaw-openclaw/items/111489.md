## Summary

Keep open as a product-direction feature request, not a confirmed bug: current main has an embedded-subagent Workboard dispatch path but no ACP-worker selection contract. The report’s `workboard_dispatch` tool-path claim is outdated on current main—the tool only advances store lifecycle state, while the gateway dispatch method starts workers. Likely related people: RomneyDa, as a recent Workboard-area contributor (medium confidence).

## What This Changes

The issue requests Workboard card dispatch support for ACP-backed workers such as OpenCode, Codex, and Claude Code.

## Best Possible Solution

Decide whether Workboard should officially support ACP-backed card workers; if approved, add a narrow SDK-owned launch/monitor contract and persist an execution kind/backend rather than making the plugin call a core ACP helper directly.
