## Summary

The updated branch still clears its abort watchdog as soon as response headers arrive, so a response whose body stalls can leave managed image thumbnail resolution pending indefinitely. The contributor added an exact-path test file, but the posted real-behavior output remains a standalone generic watchdog reproduction rather than evidence of the corrected production path.

## What This Changes

The PR adds a 30-second abort watchdog to managed outgoing-image retrieval, exports the resolver for testing, and adds local-server coverage for image-fetch outcomes.

## Best Possible Solution

Keep one controller and timeout alive through both `fetch()` and `res.blob()`, add a headers-then-stalled-body regression case, and attach redacted terminal or browser evidence showing that exact resolver returns after the bound while a normal image still resolves.
