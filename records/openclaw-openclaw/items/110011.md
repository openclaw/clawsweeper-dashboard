## Summary

This PR remains necessary but is not ready to merge: its watchdog is cleared immediately after `fetch` resolves, so an endpoint that sends headers and then stalls while streaming the image body can still hang thumbnail resolution indefinitely.

## What This Changes

The PR adds a 30-second `AbortController` timeout to managed outgoing-image fetches and adds resolver tests for stalled, successful, network-error, and unauthorized responses.

## Best Possible Solution

Keep the abort signal and timer alive through `await res.blob()`, clear it only after all response consumption completes, and prove both a headers-then-stalled-body case and a normal image response against the exported resolver.
