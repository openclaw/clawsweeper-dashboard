## Summary

This PR still does not bound the reported failure mode after response headers arrive: it clears the watchdog as soon as `fetch()` resolves, while the subsequent image-body read can remain pending indefinitely. The correction is narrow and should stay on this PR, followed by direct after-fix resolver proof.

## What This Changes

The branch exports `resolveManagedOutgoingImageBlobUrl`, adds a 30-second abort signal to its image fetch, and adds local-server tests for timeout and response outcomes.

## Best Possible Solution

Keep one abort controller and timeout alive through both `fetch()` and `res.blob()`, clear it in an outer `finally`, and add a local-server case that flushes image headers but never ends the body.
