## What This Changes

The PR adds a 30-second AbortController timeout around managed outgoing image retrieval in the web chat UI.

## Best Possible Solution

Keep one watchdog active through both header retrieval and response-body consumption, return the resolver’s normal miss outcome on timeout, and cover a headers-then-stalled-body case without changing cache or authentication semantics.

## Maintainer Decision

Required: false

## Reproduction Assessment

Yes from source, though not by a live run: a managed image endpoint can return headers and then stop producing body bytes, leaving response-body consumption pending indefinitely.

## Solution Assessment

No. AbortController is appropriate, but clearing its timer when fetch returns headers is too early; the watchdog must remain active until the blob body is consumed or fails.
