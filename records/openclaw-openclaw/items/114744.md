## What This Changes

This branch adds stale-state guards and regression tests so concurrent cron edits, exit watchers, Workboard dispatch, notification updates, and Control UI lifecycle refreshes do not apply obsolete job or card state.

## System Context

Cron jobs enter through the CLI and gateway, then the scheduler executes them, records history, and sends failure notifications. Workboard cards and the Control UI share lifecycle state that determines whether a card may start work, refresh task links, or be updated after archival or reassignment.
