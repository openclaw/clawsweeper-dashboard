## What This Changes

Preserves an explicitly supplied empty child `--timeout` so the existing update-command timeout validator rejects it rather than inheriting a parent value or continuing into update work.

## System Context

The update CLI accepts timeout options at parent and child command levels, then passes the resolved value to the shared command runner for validation before registry checks, update actions, repair, or doctor work. This change affects the option-resolution boundary immediately after Commander parses command arguments.
