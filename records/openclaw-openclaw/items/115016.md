## What This Changes

The branch threads the existing observed-reply callback through `/new` and `/reset` hook routing, and preserves a successful message ID from a partially failed route so a visible acknowledgement suppresses the generic no-reply fallback.

## System Context

Auto-reply command handling resets a session and lets internal reset hooks send an acknowledgement through the normal channel router. Dispatch finalization then decides whether the user saw a reply or needs the generic no-visible-reply fallback.
