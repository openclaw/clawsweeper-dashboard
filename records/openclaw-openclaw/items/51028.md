## Summary

Keep open: current main and the latest release still sort and filter session rows by stored `updatedAt`; `lastInteractionAt` exists for reset freshness, but not as a Sessions panel meaningful-activity sort key, reason label, or parent/child rollup.

## What This Changes

The issue requests a Sessions panel activity model that sorts by last meaningful user-visible activity, suppresses heartbeat/background noise, rolls child activity up to parents, and shows a reason label.

## Best Possible Solution

Define a Gateway-owned activity projection with reason metadata and bounded parent rollup semantics, then expose it through `sessions.list` so the Control UI can sort and explain rows without overloading `updatedAt`.

## Reproduction Assessment

Yes. Source inspection shows current main still sorts, filters, and renders Sessions panel rows by `updatedAt`, while the row contract lacks the requested meaningful-activity timestamp and reason fields.

## Solution Assessment

Unclear. The requested behavior is well motivated, but the exact persisted `lastMeaningfulActivityAt` model is not yet the best proven implementation after the write-amplification concern raised in discussion.
