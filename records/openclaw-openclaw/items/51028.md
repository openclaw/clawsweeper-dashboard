## Summary

Keep open: current main and v2026.6.11 still sort and filter Sessions panel rows by stored `updatedAt`; the requested meaningful-activity taxonomy, visible reason label, and parent/child rollup are not implemented and still need maintainer product direction.

## What This Changes

The issue requests that the Sessions panel sort by last meaningful activity, suppress heartbeat/bookkeeping noise, roll child activity up to parent sessions, and show a small reason label for why a row moved.

## Best Possible Solution

Define a core session activity projection that can rank rows by meaningful human-visible activity, ignore heartbeat/bookkeeping noise, roll up child activity without excessive writes, and expose both the timestamp and a short reason label to the Sessions page.

## Reproduction Assessment

Yes by source inspection: the Sessions page defaults to `updated` descending, the UI comparator reads `row.updatedAt`, and the gateway list/filter path also uses `entry.updatedAt`. I did not run a live browser proof because this review is read-only, but the current source path is direct.

## Solution Assessment

No implementation path is selected yet. The requested outcome is plausible, but maintainers should choose the activity taxonomy and read-time versus persisted projection before a fix PR is safe.
