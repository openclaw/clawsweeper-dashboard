## Summary

Keep open: current main and the latest release still sort and filter Sessions rows by stored `updatedAt`, and the requested meaningful-activity projection, visible reason label, and parent/child rollup semantics remain unimplemented. The split sub-agent label issue is closed as implemented, but it does not cover this ordering work.

## What This Changes

Request the Sessions panel sort and explain rows by a meaningful activity projection, with heartbeat/background noise suppressed and child activity rolled up to parents.

## Best Possible Solution

Define a gateway-owned meaningful-activity projection with explicit reason codes and parent/child rollup semantics, then expose it through `sessions.list` for Control UI sorting and display without overloading `updatedAt`.

## Reproduction Assessment

Yes. Source inspection shows the Sessions panel and gateway list path still order and filter by `updatedAt`, with no `lastMeaningfulActivityAt` or reason field in the current session row contract.

## Solution Assessment

Unclear. The requested user outcome is valid, but the proposed persisted `lastMeaningfulActivityAt` may not be the best implementation after the write-amplification concern; a read-time projection from a bounded recent-events tail may be safer.
