## Summary

Keep open: current main still sorts the Sessions panel and Gateway `sessions.list` rows by stored `updatedAt`; OpenClaw now has `lastInteractionAt` for idle freshness, but that field is not exposed as a meaningful-activity sort key, reason label, or parent/child rollup for the Control UI.

## What This Changes

The issue requests that the Sessions panel sort by meaningful user-visible session activity, hide or de-emphasize heartbeat/background noise, roll child activity up to parents, and show why a row moved.

## Best Possible Solution

Define a Gateway-owned activity projection, preferably reusing `lastInteractionAt` where it fits and adding bounded reason/rollup metadata where it does not, then expose it through `sessions.list` so Control UI sorting and labels do not overload `updatedAt`.

## Reproduction Assessment

Yes. Source inspection shows current main still sorts, filters, and live-reorders session rows by `updatedAt`, while the row contract lacks a meaningful-activity timestamp or reason field.

## Solution Assessment

Unclear. The requested product behavior is well motivated, but the exact persisted `lastMeaningfulActivityAt` model is not clearly the best implementation after the documented write-amplification concern.
