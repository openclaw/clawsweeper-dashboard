## Summary

Keep open: current main and the latest release still order the sessions list and recent-session navigation from stored `updatedAt`, while the requested meaningful-activity timestamp, reason label, and parent/child rollup contract are not implemented. The related sub-agent label issue was split and closed as implemented, but it does not cover this ordering model.

## What This Changes

Request sorting Control UI sessions by semantic last meaningful activity, including child-session rollup and visible reason labels, instead of raw `updatedAt` or last-message timing.

## Best Possible Solution

Define one session-activity projection contract for `sessions.list` and Control UI: classify meaningful events, compute or persist the sort key without hot-path write amplification, roll child activity into the parent intentionally, and expose a short reason label for the UI.
