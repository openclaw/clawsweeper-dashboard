## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Persist through the durable user-turn recorder:** `src/gateway/server-node-events.ts:409-418`
  - body: `emitSessionTranscriptUpdate()` fans out a transcript notification; it does not append or rewrite the JSONL transcript. Because this path still dispatches without a durable user-turn recorder or append call, persisted history can remain a plain text turn without `MediaPath`/`MediaPaths` after reload, which is the bug this PR is meant to fix.
  - confidence: 0.92
- **[P2] Interleave saved media using imageOrder:** `src/gateway/server-node-events.ts:357-369`
  - body: This helper saves all inline images first and then appends every offloaded ref, even though `parseMessageWithAttachments()` returns `imageOrder` to preserve the user's attachment order. A request whose first image is offloaded and second is inline will record reversed `MediaPaths`/`MediaTypes`; interleave the saved entries using `imageOrder` like the `chat.send` path.
  - confidence: 0.9
