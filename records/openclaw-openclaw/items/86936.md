## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Persist the media-bearing turn durably:** `src/gateway/server-node-events.ts:409-418`
  - body: `emitSessionTranscriptUpdate()` only broadcasts to transcript listeners; it does not append or rewrite the session transcript. Because this `agent.request` path still dispatches without a durable user-turn recorder or append call, persisted history can remain the plain text turn without `MediaPath`/`MediaPaths` after reload, which is the bug this PR is meant to fix.
  - confidence: 0.93
- **[P2] Preserve parsed image order when recording media paths:** `src/gateway/server-node-events.ts:358-369`
  - body: `parseMessageWithAttachments()` returns `imageOrder` to preserve the user's inline/offloaded image order, but this helper saves every inline image first and then appends every offloaded ref. An offloaded-first or interleaved request will record `MediaPaths`/`MediaTypes` in the wrong order; interleave the saved entries using `imageOrder` like the `chat.send` path.
  - confidence: 0.9
