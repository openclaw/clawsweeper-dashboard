Overall correctness: patch is incorrect

Full review comments:

- **[P1] Persist the media-bearing turn before emitting:** `src/gateway/server-node-events.ts:409-418`
  - body: `emitSessionTranscriptUpdate()` only fans out an already-mutated transcript event; it does not append or rewrite JSONL/session history. This PR builds a media-bearing user message and emits it after dispatch, so live subscribers can see `MediaPaths` while reloadable history still contains the runtime-persisted plain turn. Wire the saved media into durable user-turn recorder/persistence instead.
  - confidence: 0.9
- **[P2] Preserve parsed image order for transcript media:** `src/gateway/server-node-events.ts:368-369`
  - body: This helper saves all inline images first and only then appends all offloaded refs, ignoring `imageOrder`. Mixed requests where an offloaded image precedes an inline image will persist `MediaPaths` in a different order than the user attached them; reuse the chat.send ordering logic or apply `imageOrder` here.
  - confidence: 0.85
