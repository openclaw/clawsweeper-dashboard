Overall correctness: patch is incorrect

Full review comments:

- **[P1] Persist the media-bearing turn, not only an update:** `src/gateway/server-node-events.ts:409-418`
  - body: `emitSessionTranscriptUpdate()` broadcasts listener updates; it does not append or rewrite the durable transcript. Since the dispatch still passes only `message`/`images` into `agentCommandFromIngress`, reloadable history can remain missing `MediaPath`/`MediaPaths`, leaving the reported bug unfixed.
  - confidence: 0.93
- **[P2] Preserve parsed image order when building MediaPaths:** `src/gateway/server-node-events.ts:368-369`
  - body: This helper saves every inline image first and appends every offloaded ref afterward, ignoring the `imageOrder` returned by `parseMessageWithAttachments()`. A request whose first image is offloaded and second is inline will record `MediaPaths`/`MediaTypes` in the wrong order compared with the user's attachments.
  - confidence: 0.9
