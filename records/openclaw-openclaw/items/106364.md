## What This Changes

Preserves paused `sessions_yield` metadata through agent lifecycle events and reactivates an existing required-completion subagent record before a plugin-owned continuation is registered.

## System Context

A Gateway request admits and dispatches an agent run, then publishes lifecycle events consumed by subagent tracking and requester-delivery code. A yielded child run must remain paused until its continuation finishes, so the parent receives one final completion announcement rather than an early failure or duplicate delivery.
