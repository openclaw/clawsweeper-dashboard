Keep open: current main still lacks the broad Anthropic native server-tools capability, and the remaining code_execution/PTC, allowed_callers, server-result replay, billing, and security choices need maintainer direction.

## What This Changes

Add opt-in Anthropic-native server tools for web_search, web_fetch, and code_execution/PTC, including request injection, client-tool suppression, response block handling, and provider-only gating.

## Best Possible Solution

Design a plugin/provider-owned, explicit opt-in Anthropic server-tools contract that preserves current client tools unless deliberately replaced, defines billing and security defaults, handles server-result replay/rendering, and ships with docs plus live Anthropic proof.
