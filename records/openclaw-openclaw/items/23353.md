## Summary

Keep open: current main still does not implement the broad Anthropic native server-side tools request. It has some adjacent Claude CLI transcript handling for server tool blocks, but direct Anthropic Messages transport still lacks server-tool injection, PTC allowed_callers, web_fetch/code_execution support, and full server result handling.

## What This Changes

The issue requests opt-in support for Anthropic server-side web_search, web_fetch, and code_execution/PTC tools, including config, request injection, response-block handling, and Anthropic-only routing.

## Best Possible Solution

Keep this issue as the broad Anthropic server-tools tracker and design a provider-owned, opt-in Anthropic implementation with explicit security defaults, transcript/replay semantics, docs, tests, and coordination with the narrower web_search and advisor items.
