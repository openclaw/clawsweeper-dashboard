## Summary

This issue should stay open: current main still does not implement the requested Anthropic native server-side tool support, and related items only cover narrower or adjacent slices such as native web search, advisor, compaction, or xAI tool gating.

## What This Changes

Request opt-in support for Anthropic native server-side tools including web_search, web_fetch, code_execution/PTC, allowed_callers, request payload injection, and server response block handling.

## Best Possible Solution

Keep this as the broad Anthropic native server-tools tracker and design an explicit Anthropic plugin/transport implementation for native web_search, web_fetch, code_execution/PTC, allowed_callers, server-result display/replay policy, docs, tests, and security defaults.
