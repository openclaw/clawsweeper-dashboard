## Summary

This should stay open: current main has a few adjacent Anthropic server-side fallback and transcript helpers, but it still does not implement the requested Anthropic native web_search, web_fetch, code_execution/PTC, allowed_callers, config, provider contract, or transport result handling.

## What This Changes

The issue requests opt-in Anthropic native server-side tools for web search, web fetch, and code execution/PTC as alternatives to client-side tools.

## Best Possible Solution

Keep this as the broad Anthropic native server-tools tracker and design an explicit Anthropic plugin/transport implementation for native web_search, web_fetch, code_execution/PTC, allowed_callers, server-result display/replay policy, docs, tests, and security defaults.
