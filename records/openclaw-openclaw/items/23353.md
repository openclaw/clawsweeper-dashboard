## Summary

Keep this issue open: current main still lacks the broad Anthropic native server-tools support requested here, and the related open/closed items only cover narrower or adjacent slices.

## What This Changes

Request support for opt-in Anthropic server-side web_search, web_fetch, and code_execution/PTC tools, including config, request injection, response block handling, and provider scoping.

## Best Possible Solution

Keep this as the broad Anthropic server-tools tracker and design a staged Anthropic plugin/transport implementation with explicit opt-in config, server block preservation/replay, PTC allowed_callers handling, billing/security docs, and focused tests.
