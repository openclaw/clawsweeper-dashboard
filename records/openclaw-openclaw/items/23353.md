## Summary

Keep this open: current main still lacks the broad Anthropic-native server-tools request, and the related open advisor PR plus narrower web-search tracker do not cover web_fetch, code_execution/PTC, allowed_callers, config, and replay semantics end to end.

## What This Changes

## Best Possible Solution

Design this as an Anthropic plugin/transport opt-in with provider/model gating, explicit security defaults, typed config/schema/docs, raw server-block preservation and replay, and focused tests; keep https://github.com/openclaw/openclaw/issues/49949 as the narrower native web_search tracker.
