The issue requests opt-in Anthropic native server-side tools for web search, web fetch, code execution, Programmatic Tool Calling, and related response-block handling.

## Best Possible Solution

Design this in the Anthropic plugin/transport boundary as an opt-in, provider-gated capability with explicit security defaults, raw server-block preservation/replay, docs, and focused tests; let https://github.com/openclaw/openclaw/issues/49949 remain the narrower native web_search tracker.
