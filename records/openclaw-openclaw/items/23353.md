## Label Justifications

- `P2`: This is a useful provider capability with clear current-main source gaps, but existing client-side web tools still work and the issue is not a release blocker.

## Summary

Keep open: current main still lacks the broad Anthropic native server-tools support requested here, and the related items cover narrower or adjacent slices rather than a landed replacement for web_fetch, code_execution/PTC, allowed_callers, and server-result handling.

## What This Changes

Add opt-in Anthropic native server-side tools for web_search, web_fetch, and code_execution/PTC, including request injection, client-tool suppression, and server content-block rendering/replay.

## Best Possible Solution

Keep this as the broad Anthropic native server-tools tracker and design an explicit Anthropic plugin/transport implementation for native web_search, web_fetch, code_execution/PTC, allowed_callers, server-result display/replay policy, docs, tests, and security defaults.
