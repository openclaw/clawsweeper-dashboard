## Summary

This PR closes most of the confirmed plugin session-isolation gap, but the previous reset-main blocker remains: ownership is checked before the reset service acquires lifecycle admission, allowing the checked row to be replaced before the protected reset executes.

## What This Changes

The branch enforces plugin-owner equality for session parents and existing targets, persists ownership through creation and reset, and adds gateway session-create regression coverage.

## Best Possible Solution

Pass the authenticated plugin owner into performGatewaySessionReset, compare it with the entry reloaded inside runExclusiveSessionLifecycleMutation before hooks, cleanup, or mutation, and add a deterministic replacement-race regression plus exact-head live proof.
