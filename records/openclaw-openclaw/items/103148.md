## Summary

Keep this PR open: the underlying cross-plugin session exposure remains on current main, but the latest patch still has an authoritative-row reauthorization defect and lacks after-fix proof from a real loaded plugin runtime.

## What This Changes

The PR adds exact plugin-owner checks to session creation, parent use, target takeover, reset, and deletion, consolidates the checks in a shared helper, and adds regression coverage.

## Best Possible Solution

Use one canonical session-ownership authorizer that receives the resolved authoritative store target or agent identifier, applies exact equality consistently across create, patch, reset, and delete, and ships only after ownerless-row policy approval plus a redacted live plugin-runtime Gateway trace.
