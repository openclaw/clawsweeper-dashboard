## What This Changes

The PR passes plugin runtime ownership into session creation, rejects foreign or ownerless parent sessions for plugin callers, and records plugin ownership on parent-derived children.

## Best Possible Solution

Use one creator-ownership invariant in the common creation path: stamp every plugin-runtime-created session, preserve exact parent-owner authorization, type the regression payloads, and prove parentless and parent-derived flows through the real Gateway.
