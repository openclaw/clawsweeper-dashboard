## What This Changes

The PR makes configure-wizard gateway probes ignore blank `OPENCLAW_GATEWAY_TOKEN` and `OPENCLAW_GATEWAY_PASSWORD` values so configured gateway credentials continue to authenticate a local gateway.

## System Context

The configure wizard combines the saved gateway configuration with optional environment overrides before probing the local gateway. Probe results determine whether the wizard reports a healthy gateway and which setup or Control UI guidance it shows next.

## Architecture Diagram

  B[Gateway credential environment variables] --> C
  C --> D[Meaningful credential override selection]
  D --> E[Local gateway health probes]
  E --> F[Setup and Control UI guidance]

## Best Possible Solution

Land the narrow wizard-layer normalization with its regression test after a current-base refresh confirms the affected probe paths remain intact; keep gateway probe helpers unchanged because they may receive intentionally exact credentials from other callers.
