## Summary

Current main intentionally and deterministically supports fractional durations, while the report provides no concrete downstream failure or integer-only consumer; adding strict mode is therefore a new public API policy that needs maintainer sponsorship.

## What This Changes

Add an opt-in parser option that rejects fractional numeric duration segments.

## Best Possible Solution

Keep deterministic fractional parsing in the shared helper and enforce integer-only syntax at a specific consumer boundary if a documented consumer requirement and regression test are provided.
