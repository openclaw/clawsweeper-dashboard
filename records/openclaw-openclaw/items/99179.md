## What This Changes

The PR changes `EmbeddedTuiBackend.sendChat()` to queue non-BTW local runs by resolved agent workspace/backend key and adds focused regression tests for same-agent cross-session queueing, `/btw`, and selected-agent independence.

## Best Possible Solution

Land the workspace-keyed queueing fix after redacted live embedded app-server proof or an explicit maintainer proof override confirms shared-backend serialization without selected-agent false blocking.

## Reproduction Assessment

Yes by source, not by live execution here: current main queues only the same run scope, so different session keys can bypass the wait path. The PR adds focused tests for that path, but they still run through mocked agent ingress rather than a live app-server/provider.

## Solution Assessment

Yes for the code shape, with proof still missing: the PR moves the queue predicate to the core-owned resolved agent workspace boundary and preserves selected-agent independence without importing Codex plugin internals into TUI core. The safer alternative would be an exact backend-client key, but that needs maintainer direction because it crosses the plugin/core boundary.
