## What This Changes

The PR changes embedded local TUI scheduling to queue non-BTW runs by resolved agent workspace/backend key, passes that key as an embedded local process lane, and adds regression coverage for same-agent queueing, `/btw`, and selected-agent independence.

## Best Possible Solution

Land the workspace-keyed queue and lane fix after normal maintainer merge checks, then let #98866 close through the PR.

## Reproduction Assessment

Yes by source: current main uses session-scope queue matching, while Codex shared app-server clients are not keyed by OpenClaw session key; this review did not rerun the live repro.

## Solution Assessment

Yes: keying both the local queue predicate and downstream process lane to the resolved backend workspace is the best core-owned boundary; using the plugin's full shared-client key would cross owner boundaries, and globally serializing all local runs would over-block selected-agent work.
