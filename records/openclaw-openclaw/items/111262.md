## Summary

Keep this PR open, but do not merge it as written: it masks the only human-readable delivery of a newly generated gateway token while retaining the instruction to store that token once. The review discussion identifies the existing command and test contract, so this needs a fleet/CLI product decision rather than another blind review cycle.

## What This Changes

Masks `result.token` with `maskApiKey()` in human-readable `fleet create` and `fleet restore` output, while leaving the existing JSON result unchanged.

## Best Possible Solution

Preserve usable one-time token delivery for an interactive command, while redacting tokens for redirected or explicitly masked output and adding focused coverage for both paths.
