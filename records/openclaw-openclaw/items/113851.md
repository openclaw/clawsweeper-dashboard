## What This Changes

Add an optional `memory.qmd.limits.candidateLimit` setting that limits QMD reranker candidates for both direct CLI and MCP-backed memory searches.

## System Context

OpenClaw's QMD-backed memory search turns agent memory queries into QMD query requests, then returns ranked memory results to the agent. The requested setting would flow from user memory configuration into both supported QMD invocation paths to reduce reranking latency while retaining reranking.
