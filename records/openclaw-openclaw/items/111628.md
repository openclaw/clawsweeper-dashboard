## What This Changes

The PR makes `/acp close` durably mark an ACPX persistent session for replacement so the next message creates a new ACP session instead of resuming the closed one.

## System Context

ACP command handling asks the ACP manager to end a session, while the ACPX extension retains a persistent backend-session record for later reuse. On the next message, ACPX decides from that record whether to start a new backend session or resume the old one.
