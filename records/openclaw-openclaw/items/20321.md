## Summary

Keep open: current main and v2026.6.11 still expose only `open`, `disabled`, and `allowlist`, so the requested bundled Telegram `members` group policy remains missing and needs maintainer/security direction before implementation.

## What This Changes

Request a Telegram `groupPolicy: "members"` mode that authorizes newly created groups by trusted current members instead of requiring each group chat ID to be allowlisted.

## Best Possible Solution

Define and land a bundled Telegram-only `members` policy across config schema/metadata, inbound and native-command authorization, security audit semantics, docs, and focused tests, with fail-closed behavior and unchanged existing policies.
