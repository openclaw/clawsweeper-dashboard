## Summary

Keep open: current main and v2026.6.11 still only expose Telegram group policies `open`, `disabled`, and `allowlist`; the requested `members` policy remains a security-sensitive product/config decision rather than cleanup-close material.

## What This Changes

The issue requests a Telegram `groupPolicy: "members"` mode that authorizes groups from a trusted participant allowlist instead of requiring every new group chat ID to be configured.

## Best Possible Solution
