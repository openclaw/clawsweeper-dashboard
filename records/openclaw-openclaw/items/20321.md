## Label Justifications

- `P2`: This is a normal-priority Telegram access-control enhancement with clear usability value and security-boundary impact but no current core outage.
- `impact:security`: The requested policy changes who may trigger an agent from Telegram groups and how trusted group membership is verified.
- `impact:ux-friction`: The current supported path requires manually registering each Telegram group chat ID, which creates recurring setup friction for heavy group users.

## Summary

Keep open: current main and the latest release still accept only `open`, `disabled`, and `allowlist`, and Telegram inbound/native-command authorization has no all-current-members verification path. The closed same-purpose implementation PRs and the `openclaw-chat-only-trigger` plugin are useful prior art, but they do not provide the requested bundled Telegram access policy.

## What This Changes

Request a new Telegram `groupPolicy: "members"` mode that authorizes newly created groups when all current participants are trusted users instead of requiring each group chat ID to be allowlisted.

## Best Possible Solution

Define and land an explicit bundled Telegram `members` policy across config schema/metadata, inbound and native-command authorization, security audit semantics, docs, and focused tests while preserving existing `open`, `disabled`, and `allowlist` behavior.

## Reproduction Assessment

Yes for the missing capability: current-source inspection shows current main and `v2026.6.11` accept only `open`, `disabled`, and `allowlist`, and the Telegram runtime path has no membership-verification branch. This is a feature request rather than a broken shipped policy, so no live Telegram repro was run.

## Solution Assessment

Unclear until maintainers choose the access-control contract. If accepted, the maintainable solution belongs in the bundled Telegram group-policy path rather than relying on the adjacent chat-only-trigger plugin workaround, because inbound and native-command authorization own this safety boundary.
