## Summary

Keep open: current main and the latest release still do not accept or implement a Telegram `members` group policy. The community chat-only-trigger plugin is useful workaround/prior art, but it does not replace a bundled Telegram authorization policy for inbound messages, native commands, docs, and security audit semantics.

## What This Changes

The issue requests a Telegram `groupPolicy: "members"` mode that allows newly created groups when every current group member is in the trusted user allowlist.

## Best Possible Solution

Define and land a bundled Telegram-only `members` policy across config schema/metadata, inbound and native-command authorization, security audit semantics, docs, and focused tests, with fail-closed behavior and unchanged existing policies.
