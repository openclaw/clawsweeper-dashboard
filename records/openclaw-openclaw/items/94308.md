## Summary

Keep open: the feature is useful and the supplied proof shows the display works, but the current head still puts full-transcript cost scans on default status paths, creating an availability risk for large sessions.

## What This Changes

## Best Possible Solution

Carry cumulative session cost through a persisted, incremental, cached, or bounded source, with exact full aggregation only behind an explicit deep path if maintainers choose that tradeoff.

## Solution Assessment
