## Summary

Keep open: current main and v2026.6.11 still normalize only Homebrew Cellar Node paths, while this issue asks for a Volta-specific LaunchAgent fallback that remains a maintainer policy choice and has an open fork candidate.

## What This Changes

Request macOS gateway LaunchAgent generation to prefer the stable Volta shim over a version-specific Volta tools/image Node path when no better system Node is available.

## Best Possible Solution

Maintainers should decide the Volta service-runtime policy, then land or replace a proof-backed helper-level normalization, or document system Node as the supported managed-service path.
