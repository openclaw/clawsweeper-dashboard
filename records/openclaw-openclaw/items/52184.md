## Label Justifications

- `P2`: The issue affects macOS gateway LaunchAgent stability for Volta-managed installs, with limited blast radius and a bounded implementation shape after policy approval.
- `impact:crash-loop`: A LaunchAgent pinned to a removed Volta tools/image Node executable can leave the managed gateway unable to start after Node upgrades.
- `maturity:stable`: The affected `macos-gateway-host` surface is scored M4 Stable in `qa/maturity-scores.yaml`, including Gateway Service Lifecycle.

## Summary

Keep open: current main and v2026.6.11 still normalize only Homebrew Cellar Node paths, so a supported Volta tools/image Node execPath can still be written back unchanged when no supported system Node is selected first; the remaining question is whether OpenClaw should support the Volta shim as a managed-service fallback.

## What This Changes

The issue requests macOS LaunchAgent generation to prefer `~/.volta/bin/node` over a version-pinned `~/.volta/tools/image/node/<version>/bin/node` path when Volta is the active Node manager.

## Best Possible Solution

Maintainers should decide the Volta service-runtime policy, then land or replace a proof-backed helper-level normalization, or document system Node/Homebrew Node as the only supported managed-service path.

Rationale: The code change is narrow, but accepting it changes managed-service runtime policy from warning against version-manager paths toward supporting a specific Volta shim fallback, and this needs maintainer intent plus live launchd proof.

Owner confidence: high

Options:

- **Review a proof-backed Volta fallback (recommended):** Keep this issue open and require the candidate or a replacement PR to prove a real macOS LaunchAgent install/reinstall under Volta before accepting the policy change.
- **Reject Volta service shim fallback:** Keep the current system/Homebrew Node policy, document that Volta-managed service runtimes remain warned or unsupported, and then close this issue after the maintainer decision.
- **Adopt the narrow helper change now:** Accept the resolver/test change without live proof and own the risk that Volta shims behave differently under launchd than in an interactive shell.
