## Summary

Keep open: current main and the latest release still normalize Homebrew Cellar Node paths only, while this issue asks for a Volta-specific LaunchAgent fallback that remains a service-runtime policy decision and has an open fork candidate.

## What This Changes

The issue requests Volta-aware macOS LaunchAgent Node path selection so generated services prefer the stable Volta shim over a version-pinned Volta image path.

## Best Possible Solution

Maintainers should decide the Volta managed-service policy, then land or replace a proof-backed helper-level normalization, or document system Node as the supported managed-service path.
