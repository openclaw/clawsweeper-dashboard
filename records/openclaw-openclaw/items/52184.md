## Label Justifications

- `P2`: The issue affects macOS gateway LaunchAgent stability for Volta-managed installs, with limited blast radius and a bounded implementation shape.
- `impact:crash-loop`: A LaunchAgent pinned to a removed Volta tools/image Node executable can leave the managed gateway unable to start after Node upgrades.

## Summary

Keep open: current main and v2026.6.11 still leave Volta tools/image Node paths unchanged, and accepting the requested fallback needs maintainer policy confirmation because current service guidance prefers system Node and warns on version-manager runtimes.

## What This Changes

Request to prefer the stable Volta shim over a version-specific Volta tools/image Node path when generating the macOS gateway LaunchAgent.

## Best Possible Solution

Decide the Volta service-runtime policy, then either land helper-level Volta tools/image normalization with focused tests and live macOS LaunchAgent proof, or document that system Node remains the supported managed-service path.
