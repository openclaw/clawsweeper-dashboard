## Label Justifications

- `P2`: The issue affects macOS LaunchAgent stability for Volta-managed Node installs, but the blast radius is bounded to gateway service runtime path selection.
- `impact:crash-loop`: A LaunchAgent pinned to a removed Volta tools/image Node executable can leave the managed gateway unable to start after Node upgrades.
- `maturity:stable`: The affected macOS Gateway host surface is `macos-gateway-host`, scored M4 Stable in `qa/maturity-scores.yaml`.

## Summary

Keep open: current main and v2026.6.11 still leave Volta tools/image Node paths unchanged, and the remaining work is a policy-sensitive macOS LaunchAgent runtime improvement rather than cleanup-safe closure.

## What This Changes

Request macOS gateway LaunchAgent generation to prefer an accessible Volta shim path over a version-pinned Volta tools/image Node path when no better stable system Node is available.

## Best Possible Solution

Decide the Volta fallback policy, then either land helper-level Volta tools/image normalization with focused tests and live macOS LaunchAgent proof, or document that system Node remains the supported managed-service path.
