- `maturity:stable`: The affected `macos-gateway-host` surface is scored M4 Stable in `qa/maturity-scores.yaml`.

## Summary

Keep open: current main and v2026.6.11 still normalize only Homebrew Cellar Node paths, so the requested Volta tools/image path fallback remains unresolved and is already paired with an open candidate PR.

## What This Changes

The issue requests that macOS gateway LaunchAgent generation prefer a stable Volta shim path over a version-pinned Volta Node image path.

## Best Possible Solution

Decide the Volta fallback policy, then either land a helper-level Volta tools/image normalization with focused tests and live macOS LaunchAgent proof, or document that system Node remains the supported managed-service path.

## Reproduction Assessment

No, not live with high confidence. Source inspection gives a medium-confidence reproduction path: a supported Volta tools/image `process.execPath` falls through unchanged when no supported system Node is selected first.

## Solution Assessment

Unclear. Extending `resolveStableNodePath` is the narrowest technical boundary, but maintainers still need to accept or reject Volta shim fallback versus the current documented preference for system Node in managed services.
