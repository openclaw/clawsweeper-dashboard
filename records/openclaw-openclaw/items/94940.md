## What This Changes

This PR adds an opt-in `channels.googlechat.serviceAccountAdc` setting that activates Google Chat without a configured service-account key and mints an outbound access token through a guarded GCE metadata-server request.

## System Context

The Google Chat plugin resolves each configured account’s credential source before mounting its webhook and sending replies. The new path changes that resolution from an explicit service-account key to a token obtained from Google’s ambient runtime identity, then supplies the token to outbound Chat requests.
