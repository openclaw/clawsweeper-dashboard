## Summary

Keep open: current main and v2026.6.11 still lack a registered one-click Anthropic browser OAuth onboarding choice; the existing OAuth helper and callback hardening are lower-level pieces, not the requested product flow.

## What This Changes

Request to replace manual Anthropic auth setup with a browser-based one-click OAuth onboarding flow that detects subscription/API billing and configures auth automatically.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth/browser auth method only after approving the security, billing/account, docs, and fallback contract, while keeping API-key, setup-token, and Claude CLI choices available.
