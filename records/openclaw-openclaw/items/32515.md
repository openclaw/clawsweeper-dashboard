## Summary

Keep open: current main and v2026.6.11 still lack a registered Anthropic OAuth/browser auth choice in onboarding, and the merged callback hardening work only secures the internal helper rather than exposing one-click Anthropic auth.

## What This Changes

The issue requests one-click Anthropic browser OAuth onboarding that detects account type and removes manual API-key, setup-token, and config decisions for first-time users.

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve the security, billing, docs, and fallback contract, while keeping API-key, setup-token, and Claude CLI choices explicit.
