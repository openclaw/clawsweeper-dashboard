## Summary

Keep open: current main still exposes Anthropic Claude CLI, setup-token, and API-key auth choices, and the recent OAuth callback hardening only secures an internal helper rather than adding one-click Anthropic browser OAuth onboarding.

## What This Changes

Request one-click Anthropic browser OAuth onboarding that auto-detects subscription or API-credit auth and avoids manual token/config setup.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve the scope, callback, storage, refresh, account/billing detection, fallback, docs, and live-proof contract while keeping the existing auth paths.
