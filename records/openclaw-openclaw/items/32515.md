## Summary

Keep open: current main and v2026.6.11 still expose Anthropic Claude CLI, setup-token, and API-key auth choices, but no one-click Anthropic browser OAuth onboarding method is wired through provider auth.

## What This Changes

The issue requests a one-click Anthropic browser OAuth onboarding flow that detects account/token type and configures OpenClaw without manual keys or config edits.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve scopes, callback handling, token storage and refresh, billing/account detection, docs, and fallback behavior while preserving existing auth paths.
