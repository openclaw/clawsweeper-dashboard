## Summary

Keep open: current main and the latest release still do not expose a one-click Anthropic browser OAuth onboarding method; the existing pieces are explicit API-key, setup-token, Claude CLI reuse, and a lower-level OAuth helper, so the remaining work needs maintainer product and security direction.

## What This Changes

The issue requests replacing Anthropic auth setup with a one-click browser OAuth flow that detects account type and configures OpenClaw without manual tokens, API keys, env files, or config edits.

## Best Possible Solution

Add an additive Anthropic provider-owned browser OAuth auth method only after approving the security, billing/account, docs, callback, storage, refresh, and fallback contract while keeping current auth choices available.
