## Summary

Keep open: current main still exposes Anthropic Claude CLI, setup-token, and API-key onboarding, while the browser OAuth helper hardened by the merged callback PR is not wired as a one-click Anthropic auth choice.

## What This Changes

Request a one-click Anthropic browser OAuth onboarding flow that detects account or token type and configures Anthropic auth without manual keys, tokens, or config editing.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after security, provider-policy, billing/account detection, docs, and fallback behavior are approved, while keeping the existing explicit Anthropic auth paths.
