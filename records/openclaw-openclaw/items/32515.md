## Summary

Keep open: current main still exposes Anthropic API-key, setup-token, and Claude CLI auth paths, plus an internal Anthropic OAuth helper, but it does not register a one-click Anthropic browser OAuth method for onboarding or provider auth.

## What This Changes

Request one-click Anthropic authentication through an OAuth browser flow that opens from onboarding, detects account type, and configures Anthropic auth automatically.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve the security, provider-policy, billing/account-detection, docs, and fallback contract, while keeping API-key, setup-token, and Claude CLI paths available.
