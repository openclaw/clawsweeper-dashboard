## Summary

Keep open: current main and v2026.6.11 expose Anthropic API-key, setup-token, and Claude CLI auth choices, and current main has an internal Anthropic OAuth helper, but there is still no one-click Anthropic browser OAuth onboarding choice wired through provider auth.

## What This Changes

Request one-click Anthropic browser OAuth in onboarding, with automatic account-type detection and configuration instead of manual API key or token setup.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve scopes, callback handling, token storage and refresh, billing/account detection, docs, and fallback behavior, while keeping API-key, setup-token, and Claude CLI paths explicit.
