## What This Changes

The issue requests one-click Anthropic OAuth onboarding that opens a browser, detects account type, and configures Anthropic auth without manual token or API-key setup.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve scopes, callback handling, token storage and refresh, billing/account detection, docs, and fallback behavior, while keeping API-key, setup-token, and Claude CLI paths explicit.
