## Summary

Keep open: current main has Anthropic API-key, setup-token, and Claude CLI setup paths plus a hardened internal OAuth helper, but it still does not expose a one-click Anthropic browser OAuth onboarding/auth method.

## What This Changes

The issue requests a one-click Anthropic OAuth onboarding flow that opens a browser, detects account type, and configures OpenClaw without manual tokens, API keys, env files, or config editing.

## Best Possible Solution

Add an additive provider-owned Anthropic OAuth auth method only after maintainers approve the security, billing/account-detection, docs, fallback, and upgrade contract, while keeping API-key, setup-token, and Claude CLI setup paths explicit.
