## Summary

Keep this PR open: the earlier lint blockers are fixed and the real-path proof is strong, but queued follow-ups discard buffered failures before confirming the clean final reply was actually delivered, which can leave users with neither result.

## What This Changes

## Best Possible Solution

Keep buffered follow-up failures until final routing completes, discard them only after a non-error payload is actually delivered, and flush them when no clean visible delivery succeeds.
