## Summary

The prior block-delivery finding is fixed, but a routed final suppressed by the payload-sending hook is still counted as clean delivery, which can discard the buffered failure even though no reply reached the user.

## What This Changes

The PR buffers regular-verbose failed command, item, and tool-result progress in direct and queued auto-reply flows, then discards it after a non-error reply is considered delivered while preserving full-verbose and terminal-failure diagnostics.

## Best Possible Solution

Use the existing suppression-aware delivered predicate for every direct routed clean final and TTS decision, then add regressions proving hook-suppressed clean replies flush buffered failures while delivered replies discard them.
