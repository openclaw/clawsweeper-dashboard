## Summary

This PR addresses a valid Codex runtime regression, but the implementation treats every upstream `interrupted` completion as an OpenClaw-aborted run. Upstream collapses several abort reasons into that status, while current OpenClaw intentionally requires locally observed cancellation before setting its generic abort flag; the branch also lacks after-fix live proof and currently conflicts with main.

## What This Changes

The PR marks Codex app-server interrupted turns as aborted and prevents synthesized missing-tool-result errors from becoming the run-level prompt error when the projector is aborted.

## Best Possible Solution

Keep upstream interruption distinct from locally observed cancellation, preserve the synthetic failed tool result for transcript integrity, and select the run-level outcome from an authoritative OpenClaw abort cause or real failure; cover explicit cancellation, replacement/review/budget interruption, timeout, and partial-output retention with tests and live proof.
