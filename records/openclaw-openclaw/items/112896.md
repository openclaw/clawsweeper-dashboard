## What This Changes

Adds private recovery capture and restore commands plus a Gateway startup fence that restores an accepted SQLite recovery point, reconciles scheduler and owners, records readiness, and only then admits public work.

## System Context

Gateway startup assembles runtime state, starts scheduler and sidecars, and then publishes work readiness. This branch adds a recovery-journal-driven gate between restored state and public work admission so a replacement Gateway stays closed until recovery reconciliation completes.
