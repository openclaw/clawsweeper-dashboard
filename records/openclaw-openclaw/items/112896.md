## What This Changes

The branch adds hidden recovery capture and restore commands plus a Gateway startup fence that keeps public work admission closed until restored SQLite state, scheduler reconciliation, and owner readiness are durably recorded.

## System Context

OpenClaw’s snapshot layer captures OpenClaw-owned SQLite state, while Gateway startup controls when a process may accept work. This branch links an accepted recovery point to startup so a replacement Gateway remains fenced until scheduler and required-owner reconciliation complete.
