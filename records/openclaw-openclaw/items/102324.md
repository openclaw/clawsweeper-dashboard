## Summary

Keep open: current main still emits Anthropic tool_result image blocks without checking text-only model capability, and the linked open PR is the active fix candidate rather than a reason to close the issue.

## What This Changes

The issue reports that the managed anthropic-messages transport sends image tool_result blocks to text-only models instead of omitting them based on model.input capability.

## Best Possible Solution

Review and land or replace the linked narrow PR so Anthropic tool_result conversion drops image blocks for text-only models while preserving image-capable behavior with regression coverage.
