## Summary

Keep open: current main still has the managed Anthropic transport bug where tool_result image blocks are emitted without checking the target model's input capabilities, and the related PRs do not supersede this narrow remaining fix.

## What This Changes

The issue requests gating Anthropic Messages tool_result image emission for text-only anthropic-messages models so replayed tool results do not produce provider 400s.

## Best Possible Solution

Gate managed Anthropic tool-result image emission on model.input.includes("image"), add focused request-payload regression coverage for text-only and image-capable models, and leave broader media-block cleanup to the separate package-level PR.
