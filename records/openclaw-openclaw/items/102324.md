## Summary

Keep open: current main still builds Anthropic tool_result content without checking text-only model capability, and the linked open PR is the active fix candidate rather than a reason to close this issue.

## What This Changes

Request to gate Anthropic Messages tool_result image blocks on model.input so text-only models receive text or placeholders instead of native images.

## Best Possible Solution

Review and land or replace the linked narrow PR so managed Anthropic tool_result conversion drops image blocks for text-only models while preserving image-capable behavior with regression coverage.

Yes. Current main has a high-confidence source reproduction: the Anthropic tool-result converter ignores model.input, and the existing text-only test fixture still expects a native image block in the outgoing payload.

## Solution Assessment

Yes. Passing model capability, or an equivalent allowImages boolean, into convertContentBlocks is the narrow maintainable fix and matches the existing Anthropic user-message and OpenAI tool-result gates.
