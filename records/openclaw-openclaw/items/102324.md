## Summary

Keep open: current main still sends Anthropic tool_result image blocks without checking text-only model capability, and the linked open PR is the active fix candidate rather than a reason to close the issue.

## What This Changes

The issue asks OpenClaw to drop native image blocks from Anthropic Messages tool_result payloads when the selected model only supports text input.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/102329, or an equivalent narrow change, so the Anthropic tool_result converter respects model input capabilities while preserving image-capable behavior.

## Solution Assessment

Yes. Passing the model into the Anthropic tool-result converter and gating native image emission on model.input is the narrowest fix, matching the existing Anthropic user-message and OpenAI tool-result gates.
