## Summary

Keep open: current main still sends Anthropic tool_result image blocks without checking whether the target model accepts images, and https://github.com/openclaw/openclaw/pull/102329 is the active open fix candidate rather than a reason to close this issue.

## What This Changes

The issue requests gating Anthropic Messages tool_result image blocks on model image capability so text-only anthropic-messages models do not receive invalid image content.

## Best Possible Solution
