## What This Changes

The branch adds `openclaw agent exec`, an isolated one-shot embedded agent runner with ephemeral state by default, structured JSON results, timeout exit codes, explicit fallback models, and environment-only authentication by default.

## System Context

The CLI command layer routes `openclaw agent exec` around normal Gateway/config/plugin startup into the embedded agent runtime. The runtime receives a prompt, workspace, model/auth policy, and timeout, then returns a machine-readable terminal result to CI or coding-automation callers.
