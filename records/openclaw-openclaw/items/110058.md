## What This Changes

The PR adds a LINE plugin Doctor migration that converts legacy pre-drain webhook-spool rows into the canonical durable ingress-queue payload and identity format before LINE delivery begins.

## System Context

The proposed Doctor migration runs at the persisted-state upgrade boundary, translating obsolete row shapes into the canonical queue contract or recording identity-invalid rows as dead letters.
