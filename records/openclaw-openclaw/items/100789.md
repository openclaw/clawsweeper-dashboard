Full review comments:

- **[P2] Filter the recent task request to terminal rows:** `ui/src/pages/tasks/tasks-page.ts:107`
  - body: The Recent fetch is unfiltered, so when 200 queued/running tasks have newer activity than terminal rows, this call can return only active tasks; after merge/partition the Recent section is empty even though completed tasks exist. Request terminal statuses here, or page until enough terminal rows are collected.
  - confidence: 0.91
- **[P2] Prefer terminal end time for completed task updates:** `src/gateway/server-methods/task-summary.ts:29`
  - body: `taskUpdatedAt` uses `lastEventAt` before `endedAt` for terminal records. Callers such as `tryFinalizeTrackedAgentTask` can finalize with only `endedAt`, leaving an old progress `lastEventAt`, so a just-finished long-running task sorts and displays by stale progress time and can miss the Recent page.
  - confidence: 0.88
- **[P2] Keep task pagination stable while tasks update:** `src/gateway/server-methods/tasks.ts:124-131`
  - body: This changes `tasks.list` to mutable activity-time ordering while retaining numeric offset cursors. Workboard follows `nextCursor`; if a later-page task emits progress between page requests, it can move before the offset and be skipped, so this needs a stable ordering or opaque snapshot/keyset cursor before merge.
  - confidence: 0.86
