## What This Changes

The PR makes visible assistant-thinking Markdown headings use subdued callout typography on iOS and macOS while preserving response heading hierarchy and accessibility semantics.

## System Context

The shared Apple chat UI parses assistant text into response and visible-thinking segments, then renders each segment as SwiftUI Markdown. This change supplies the renderer with one semantic typography profile per segment so prose, inline math, lists, and headings remain visually consistent.
