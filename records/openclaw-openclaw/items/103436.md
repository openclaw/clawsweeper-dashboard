## What This Changes

This PR gives the shared iOS/macOS Markdown renderer complete response and thinking typography profiles, so visible assistant-trace headings stay subordinate while normal response headings retain their hierarchy and accessibility semantics.

## System Context

The shared Apple chat UI parses assistant text into response and thinking segments, then renders each segment as Markdown for iOS and macOS chat views. This change selects a semantic typography profile at that segment boundary and carries it through headings, prose, inline math, and nested lists.
