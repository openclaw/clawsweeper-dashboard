## What This Changes

The PR replaces separate Apple Markdown font inputs with response and thinking typography profiles so completed and streaming assistant trace headings retain subdued italic styling while response headings keep their normal hierarchy.

## System Context

Apple chat messages are split into response and thinking segments before the shared Markdown renderer produces SwiftUI content for iOS and macOS. The selected typography profile controls prose, inline math, lists, and heading presentation for each segment.
