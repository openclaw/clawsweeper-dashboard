## What This Changes

The branch infers an image tool agent directory from the session agent when `agentDir` is absent, uses it for image understanding and image generation, and adds regressions for inferred and explicit directories.

## Best Possible Solution

Merge a focused session-agent-directory inference for image tools only, retaining explicit `agentDir` precedence and the two regression cases so per-agent OAuth resolution follows the same identity already used for workspace selection.
