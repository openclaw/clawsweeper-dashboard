## Summary

Keep open. Current main and v2026.6.11 still have no supported user-supplied pricing overlay for auto-discovered Amazon Bedrock models; the earlier implementation PR is closed unmerged, and the remaining blocker is the maintainer-approved config/API shape.

## What This Changes

Request adding user-supplied cost metadata for auto-discovered Amazon Bedrock models so status and usage surfaces can show USD estimates without duplicating explicit provider model entries.

## Best Possible Solution

Choose a current pricing-overlay API, preferably plugin-owned Bedrock discovery config unless maintainers approve a general model-cost overlay, then update schema, SDK types, docs, cache keys, discovery behavior, and focused tests together.

## Reproduction Assessment

Yes. Source inspection on current main shows discovered Bedrock models use zero DEFAULT_COST and the strict plugin discovery schema exposes no costs field; live AWS credentials are not needed to observe that missing config path.

## Solution Assessment

Unclear until maintainers choose the API shape. The old models.bedrockDiscovery.costs proposal no longer matches the current plugin-owned discovery config path, while a generic overlay needs broader product approval.
