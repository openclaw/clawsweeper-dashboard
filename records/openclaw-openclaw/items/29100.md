## Summary

Keep open. Current main and v2026.6.11 still default Bedrock auto-discovered models to zero cost and the plugin discovery schema has no pricing overlay; the remaining work is choosing the supported config/API shape now that discovery config is plugin-owned.

## What This Changes

Request to let Bedrock auto-discovered models receive local cost metadata without duplicating explicit provider model entries.

## Best Possible Solution

Choose one supported pricing-overlay API, preferably plugin-owned Bedrock discovery config unless maintainers approve a general models cost overlay, then update schema, docs, discovery cache keys, model materialization, and focused tests together.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows discovered Bedrock models and inference profiles receive zero/default cost metadata while the plugin discovery schema exposes no pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The legacy models.bedrockDiscovery.costs path is not the best exact path on current main because discovery config is now plugin-owned, while a generic models.costs overlay needs broader config approval.
