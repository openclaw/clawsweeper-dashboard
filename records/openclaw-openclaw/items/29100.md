## Summary

Keep open. Current main and v2026.6.11 still do not provide a supported cost overlay for auto-discovered Amazon Bedrock models; the linked implementation PR is closed unmerged, and the remaining decision is the supported config/API shape.

## What This Changes

Request support for attaching cost metadata to auto-discovered Amazon Bedrock models without duplicating an explicit provider model block.

## Best Possible Solution

Maintainers should choose one supported pricing-overlay API, then wire it through Bedrock discovery, cache keys, schema/UI metadata, docs, and focused tests without changing model routing.

## Reproduction Assessment

Yes. Source inspection shows current Bedrock discovery assigns zero/default cost metadata and the plugin discovery schema exposes no pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The old models.bedrockDiscovery.costs shape is no longer the best exact path on current main because discovery config is plugin-owned.
