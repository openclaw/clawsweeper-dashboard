## Summary

Keep open. Current main and latest release still assign zero/default cost metadata to auto-discovered Bedrock models and expose no supported pricing overlay; the linked implementation pull request is closed unmerged, so the remaining work is a maintainer API-shape decision.

## What This Changes

Add a supported cost metadata overlay for auto-discovered Amazon Bedrock models so status and usage surfaces can estimate costs without duplicating explicit provider model entries.

## Best Possible Solution

Choose one supported pricing-overlay shape, preferably plugin-owned unless maintainers want a broader model-cost overlay, then update Bedrock discovery, schema/UI hints, docs, cache/fingerprint behavior, and focused tests together.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows Bedrock discovery emits zero/default cost metadata and the plugin discovery schema exposes no pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The old legacy models.bedrockDiscovery.costs path is not the best exact path on current main because discovery config is plugin-owned, while a generic models.costs overlay would need broader config approval.
