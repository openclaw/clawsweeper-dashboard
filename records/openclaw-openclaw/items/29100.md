## Summary

Keep open. Current main and v2026.6.11 still lack a user-supplied pricing overlay for auto-discovered Amazon Bedrock models, and the only direct implementation attempt was closed unmerged against the old core config shape.

## What This Changes

Request to attach per-model cost metadata to auto-discovered Amazon Bedrock models without duplicating explicit provider model entries.

## Best Possible Solution

Choose a plugin-owned Bedrock discovery cost overlay under plugins.entries.amazon-bedrock.config.discovery, then update schema, docs, discovery cache behavior, model enrichment, and focused tests without changing AWS auth or routing.
