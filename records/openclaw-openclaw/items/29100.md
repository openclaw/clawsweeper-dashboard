## Summary

Keep open. Current main and v2026.6.11 still do not provide a user-supplied cost overlay for auto-discovered Amazon Bedrock models; the remaining blocker is choosing the public config/API shape.

## What This Changes

The issue requests cost metadata for Amazon Bedrock models discovered through Bedrock auto-discovery without duplicating an explicit provider model block.

## Best Possible Solution

Choose a plugin-owned Bedrock discovery cost overlay under plugins.entries.amazon-bedrock.config.discovery, then update schema, docs, discovery enrichment, cache/fingerprint behavior, and focused tests without changing routing or AWS auth.
