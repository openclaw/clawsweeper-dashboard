## Summary

Keep open. Current main and v2026.6.11 still do not provide a user-supplied pricing overlay for auto-discovered Amazon Bedrock models, and the remaining blocker is the maintainer choice of config/API shape.

## What This Changes

The issue requests a pricing metadata overlay for auto-discovered Amazon Bedrock models so status and usage surfaces can show estimated USD without duplicating an explicit provider model list.

## Best Possible Solution

Choose a plugin-owned Bedrock discovery cost overlay under plugins.entries.amazon-bedrock.config.discovery, then update schema, docs, discovery cache keys, model-definition enrichment, and focused tests while leaving routing and AWS auth unchanged.
