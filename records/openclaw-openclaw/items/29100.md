## Summary

Keep open. Current main and the latest release still have no supported pricing overlay for auto-discovered Amazon Bedrock models; the linked implementation PR is closed unmerged, and the remaining blocker is the maintainer-approved config/API shape.

## What This Changes

Request to let auto-discovered Amazon Bedrock models carry user-supplied cost metadata without duplicating explicit provider model entries.

## Best Possible Solution

Choose the supported pricing-overlay API, preferably plugin-owned unless maintainers approve a general models overlay, then update schema, docs, discovery cache keys, model materialization, and focused tests together.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows discovered Bedrock models and inference profiles receive zero/default cost metadata while the plugin discovery schema and docs expose no pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The old models.bedrockDiscovery.costs proposal is not the best exact path on current main because discovery config is now plugin-owned, while a generic models.costs overlay needs broader config approval.
