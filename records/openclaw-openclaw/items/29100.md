## Summary

Keep open. Current main and v2026.6.11 still lack a user-supplied pricing overlay for auto-discovered Amazon Bedrock models; the merged AWS SDK cost-display fix only covers explicit `models.providers.*.models[].cost` entries, and the remaining decision is the config/API shape.

## What This Changes

Request to attach cost-per-token metadata to Bedrock models produced by auto-discovery without duplicating an explicit provider model list.

## Best Possible Solution

Choose the pricing-overlay API, preferably plugin-owned Bedrock discovery config, then update schema, SDK/config types, docs, discovery cache keys, model-row enrichment, and focused regression tests without changing routing or AWS auth.

Question: Which pricing-overlay API should OpenClaw support for auto-discovered Amazon Bedrock models?

Rationale: The fix adds a user-facing provider/config contract, and automation should not choose between a narrow Bedrock plugin-local overlay and a broader generic model-cost overlay without maintainer intent.

Likely owner: steipete

Owner confidence: high

Options:

- **Use Bedrock plugin discovery costs (recommended):** Add a `costs` map under `plugins.entries.amazon-bedrock.config.discovery` keyed by Bedrock model/profile ID, with schema, docs, cache-key, discovery, and regression coverage.
- **Use a generic model cost overlay:** Add a top-level model-cost overlay that can patch discovered models across providers, accepting a broader config surface and compatibility review.
- **Keep explicit provider pricing only:** Decline a new overlay and document that users must define explicit provider model entries or rely on external pricing bootstrap for local cost estimates.

## Reproduction Assessment

Yes. Current main's strict Bedrock discovery schema has no pricing overlay and discovered model rows still assign zero DEFAULT_COST, so the missing local cost metadata path is source-reproducible without AWS credentials.

## Solution Assessment

Unclear until maintainers choose the API shape. The issue's legacy `models.bedrockDiscovery.costs` path no longer matches the current plugin-owned config boundary, while a generic overlay needs broader product approval.
