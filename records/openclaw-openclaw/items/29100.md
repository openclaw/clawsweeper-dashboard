## Summary

Keep open. Current main and the latest stable release still lack a user-supplied pricing overlay for auto-discovered Amazon Bedrock models; the direct implementation attempt was closed unmerged, and the remaining blocker is the maintainer-approved config/API shape.

## What This Changes

Add cost metadata for auto-discovered Amazon Bedrock models so usage/status surfaces can estimate USD without duplicating explicit provider model entries.

## Best Possible Solution

Choose the pricing-overlay API, preferably a plugin-owned Bedrock discovery config surface, then update schema, SDK types, docs, cache keys, discovery behavior, and focused tests without changing routing or AWS auth.

## Reproduction Assessment

Yes at source level, though this is a feature request rather than a broken existing contract. Current main exposes no Bedrock discovery cost field and assigns zero cost to discovered Bedrock models without needing live AWS credentials to observe the gap.

## Solution Assessment

Unclear until maintainers choose the API shape. The old models.bedrockDiscovery.costs proposal no longer matches the current plugin-owned discovery config path, while a generic overlay needs broader product approval.
