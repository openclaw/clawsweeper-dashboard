## Summary

Keep open. Current main and latest release still materialize auto-discovered Bedrock models with zero/default cost metadata and expose no supported operator pricing overlay; the linked implementation PR is closed unmerged, and the remaining question is the supported plugin/config API shape.

## What This Changes

The issue requests cost metadata overlays for Bedrock auto-discovered models so IAM-based discovery can show USD estimates without duplicating explicit provider model entries.

## Best Possible Solution

Choose one current API shape for pricing overlays, likely plugin-owned Bedrock discovery config unless maintainers approve a general model-cost overlay, then update schema, docs, cache keys, discovery behavior, and focused tests together.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows auto-discovered Bedrock models and inference profiles receive zero/default cost metadata while the plugin discovery schema and docs expose no pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The old legacy `models.bedrockDiscovery.costs` path is not the best exact path on current main because discovery config is now plugin-owned, while a generic `models.costs` overlay would need broader config approval.
