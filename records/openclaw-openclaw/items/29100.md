## Summary

Keep open. Current main and the latest release still build auto-discovered Amazon Bedrock models with zero/default cost metadata and expose no supported discovery pricing overlay; the old proposed `models.bedrockDiscovery.costs` path is now outdated by plugin-owned discovery config, so the remaining work is a maintainer product/API-shape decision.

## What This Changes

Add a supported way to attach cost metadata to auto-discovered Amazon Bedrock models without duplicating explicit provider model entries.

## Best Possible Solution

Have maintainers choose the supported pricing-overlay API shape, then update the Bedrock plugin config schema, discovery cache key, model materialization, docs, and focused tests in one bounded change.

## Reproduction Assessment

Yes. Source inspection on current main and `v2026.6.11` shows auto-discovered Bedrock models and inference profiles receive zero/default cost metadata while the plugin discovery schema and docs expose no pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. A pricing overlay is plausible, but the legacy `models.bedrockDiscovery.costs` path is no longer the best exact path on current main because discovery config is now plugin-owned.
