## Summary

Keep open. Current main and v2026.6.11 still give auto-discovered Amazon Bedrock model rows default zero cost metadata, while the plugin-owned discovery config exposes no supported pricing overlay; the linked implementation PR was closed unmerged and targeted the old legacy config path.

## What This Changes

Request to add a supported cost metadata overlay for Amazon Bedrock auto-discovered models so IAM/aws-sdk discovery users do not need duplicate explicit provider model entries for pricing.

## Best Possible Solution

Pick one current API shape for discovery pricing, preferably plugin-owned unless maintainers approve a general model-cost overlay, then update schema, cache keys, discovery behavior, docs, and focused tests together.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows discovered Bedrock model definitions use default zero cost metadata and the discovery config schema has no supported pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The old `models.bedrockDiscovery.costs` path is not the best exact path on current main because discovery config is plugin-owned, while a generic `models.costs` overlay would need broader config approval.
