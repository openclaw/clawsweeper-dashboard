## Summary

Keep open. Current main and v2026.6.11 still do not provide a user-supplied pricing overlay for auto-discovered Amazon Bedrock models; the remaining blocker is maintainer choice of the public config/API shape.

## What This Changes

The issue requests cost metadata overlays for auto-discovered Amazon Bedrock models without duplicating explicit provider model entries.

## Best Possible Solution

Choose a plugin-owned Bedrock discovery cost overlay under plugins.entries.amazon-bedrock.config.discovery, then update schema, docs, discovery cache keys, model-definition enrichment, and focused tests while leaving routing and AWS auth unchanged.
