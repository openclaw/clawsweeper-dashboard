## Summary

Keep open. Current main and v2026.6.11 still discover Bedrock models with zero/default cost metadata and expose no supported pricing overlay; the same-scope implementation pull request is closed unmerged, so the remaining work is a maintainer API-shape decision.

## What This Changes

Request adding cost metadata for auto-discovered Amazon Bedrock models so status and usage surfaces can show estimates without replacing the discovered provider catalog with explicit model entries.

## Best Possible Solution

Choose one pricing-overlay API shape, then update Bedrock discovery, schema/UI hints, docs, cache-key behavior, and focused tests together while preserving existing discovery config compatibility.

## Reproduction Assessment

Yes at source level. Current main and v2026.6.11 build auto-discovered Bedrock foundation models and inference profiles with DEFAULT_COST while the strict discovery schema exposes no cost overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. The legacy models.bedrockDiscovery.costs proposal is not the best exact path on current main because discovery config is now plugin-owned; a top-level models cost overlay would need broader config approval.
