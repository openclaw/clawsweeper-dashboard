## Summary

Keep open. Current main and the latest release still materialize auto-discovered Amazon Bedrock models with zero/default cost metadata, and the only exact implementation PR was closed unmerged; the remaining blocker is choosing the supported user-facing config/API shape.

## What This Changes

Request support for attaching cost metadata to auto-discovered Amazon Bedrock models without duplicating an explicit provider model list.

## Best Possible Solution

Choose the supported pricing overlay shape for plugin-owned Bedrock discovery, then add schema, docs, tests, and deterministic cost application before discovered models enter the provider catalog.

## Reproduction Assessment

Yes from source inspection: current discovery builds Bedrock model definitions with zero/default cost, and the plugin discovery config has no cost overlay field. I did not run a live AWS discovery path.

## Solution Assessment

Unclear until maintainers choose the config surface. A plugin-owned discovery cost map is the narrowest likely path, while a top-level cross-provider costs map is broader product/API work.
