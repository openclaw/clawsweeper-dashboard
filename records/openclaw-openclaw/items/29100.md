## Summary

Keep open. Current main and v2026.6.11 still build auto-discovered Amazon Bedrock models with zero/default cost metadata and expose no supported pricing overlay for discovery, while the one linked implementation PR is closed unmerged and targeted the older config path.

## What This Changes

The issue requests a supported way to attach per-model token pricing metadata to Amazon Bedrock models produced by automatic discovery without duplicating explicit provider model entries.

## Best Possible Solution

Choose the supported pricing-overlay API, preferably plugin-owned Bedrock discovery config unless maintainers approve a broader model-cost overlay, then update schema, discovery cache keys, docs, and focused discovery/status usage tests together.

## Reproduction Assessment

Yes. Source inspection shows discovered Bedrock models and inference profiles receive zero/default cost metadata, while the current schema and docs expose no discovery pricing overlay.

## Solution Assessment

Unclear until maintainers choose the API shape. A plugin-local Bedrock discovery costs map is the narrowest likely implementation, while the proposed generic `models.costs` overlay needs broader config approval.
