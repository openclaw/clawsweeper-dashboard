## Summary

Keep open: current main and the latest release only partially address the Feishu active-run command regression. Feishu `/stop` now has a separate control lane, but `/status` still maps to the normal same-chat lane and `/new` is explicitly excluded from the current fast path, so the documented command-only bypass is not restored for the full report.

## What This Changes

The issue asks OpenClaw to restore immediate Feishu text command handling for `/stop`, `/new`, and `/status` during an active agent run.

## Best Possible Solution

Define a Feishu text-command lane policy that keeps `/stop` immediate, adds tested immediate handling for safe read-only command-only text such as `/status`, and explicitly decides whether `/new` should bypass active runs or stay queued with corrected docs.
