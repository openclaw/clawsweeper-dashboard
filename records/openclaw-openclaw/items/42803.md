## Summary

Keep open: current main and v2026.6.11 still only partially address the Feishu active-run command regression. `/stop` now has a Feishu control lane, but `/status` still uses the ordinary same-chat key, `/new` remains stateful command behavior that is not safely covered by the current fast path, and the related open PR targets ordinary follow-ups rather than this command lane.

## What This Changes

Feishu text commands such as `/stop`, `/new`, and `/status` should execute immediately during an active Feishu agent run instead of waiting behind the same-chat queue.

## Best Possible Solution

Keep this issue open as the active-run Feishu text-command regression, then choose and land one Feishu-owned command-turn and queue policy with focused tests and live proof for the selected command set.
