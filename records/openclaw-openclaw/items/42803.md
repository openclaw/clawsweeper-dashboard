## Summary

Keep open: current main and v2026.6.11 still only partially satisfy the Feishu active-run text-command fast path. `/stop` has a separate Feishu control lane, but `/status` and `/new` are not covered by the same immediate path, Feishu still does not pass structured text-slash command facts, and the linked open or closed PRs have not landed a complete same-repo fix.

## What This Changes

The issue asks OpenClaw to restore Feishu command-only text handling so `/stop`, `/new`, and `/status` bypass active-run queueing and execute immediately.

## Best Possible Solution

Keep this issue open, choose the Feishu text-command authorization and queue-bypass policy, then land or replace a focused proof-backed fix for `/stop`, `/new`, and `/status` with Feishu DM/group tests and live Feishu proof.
