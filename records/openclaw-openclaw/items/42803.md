## Label Justifications

- `P1`: Feishu users can be unable to stop, reset, or inspect an active agent run through text commands during a live channel workflow.
- `impact:session-state`: The affected commands operate on active session state, including stop, reset, and status behavior during an existing run.

## Summary

Keep open: current main still only partially addresses the Feishu active-run text-command regression. `/stop` has a dedicated control lane, but `/status` and `/new` remain on the ordinary same-chat queue and Feishu text slash messages are not marked as structured command turns.

## What This Changes

The issue asks for Feishu text commands such as `/stop`, `/new`, and `/status` to bypass active-run queueing and execute immediately.

## Best Possible Solution

Choose the Feishu text-command contract, then implement a Feishu-scoped fix that marks authorized whole-message slash commands as structured command turns where appropriate and routes only explicit immediate controls out of the normal same-chat lane with DM/group tests and live proof.
