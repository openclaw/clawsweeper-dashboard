## Summary

The issue remains necessary: current main still resolves a role-snapshot budget without applying it to Playwright or raw CDP, while Chrome MCP truncates before URL expansion and keeps refs/stats from a different artifact. The report is a concrete existing-behavior bug, but its protected `maintainer` label requires explicit maintainer handling rather than automated repair dispatch.

## What This Changes

Ensure all browser role-snapshot backends enforce the resolved character budget and return refs, labels, stored refs, truncation state, and stats for the same final artifact.

## Best Possible Solution

Add one backend-neutral role-snapshot finalizer after filtering and URL expansion, apply the resolved budget at complete UTF-16-safe line/ref boundaries, prune refs, and derive storage, labels, stats, and truncation state from that single artifact.
