## Label Justifications

- `P2`: The deterministic browser snapshot bug can inflate model context and return stale action references, but its blast radius is limited to role snapshots.
- `impact:other`: The issue causes excess model context, latency, cost, and misleading browser action metadata outside the more specific owned impact categories.

## Summary

The bug remains in current main and v2026.6.11: role-snapshot budgets are resolved but not propagated to Playwright/CDP, while Chrome MCP truncation, URL expansion, refs, labels, and stats are finalized from different artifacts. The protected `maintainer` label requires explicit maintainer handling, so this issue should remain open without automated repair dispatch.

## What This Changes

Fix role snapshots so resolved character budgets, returned and stored refs, labels, truncation state, and stats describe the same final artifact across Playwright, Chrome MCP, and raw CDP.

## Best Possible Solution

Add one shared role-snapshot finalizer after filtering and URL expansion that applies the resolved cap on complete UTF-16-safe lines, retains only refs present in final text, recomputes stats, and supplies the identical ref set to storage and labels across all three backends.

Required: false

## Reproduction Assessment

Yes at source level: current main deterministically omits the resolved budget or retains refs and stats for text removed by filtering or truncation. No runtime test was run because this is a read-only review.

## Solution Assessment

Yes in direction: a single post-filter and post-URL finalizer is the narrowest maintainable way to keep text, refs, storage, labels, stats, and truncation atomic across sibling backends.
