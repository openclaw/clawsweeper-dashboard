## Summary

Keep this PR open: the ClickClack activity publisher is well-scoped and has real before/after UI proof, but the new opt-in config and required bot scope are not documented, while the current ClickClack docs still tell users that normal agent chat only needs `bot:write`.

## What This Changes

The PR adds a ClickClack `agentActivity` account option plus an activity publisher that posts and patches durable `agent_commentary` and `agent_tool` rows from agent item events, with tests and generated channel config metadata.

## Best Possible Solution

Land the plugin implementation only after the ClickClack docs make the `agentActivity` option and `agent_activity:write` scope a clear public setup contract while keeping the default off.

## Reproduction Assessment

Not applicable as a bug repro; this is a feature PR. The PR includes before/after ClickClack UI proof, and I inspected the supplied contact sheets showing activity rows after the change.

## Solution Assessment

The code is in the right owner boundary and uses the existing `onItemEvent` seam, but it is not yet the best merge state because the new config and required scope are undocumented.
