## Summary

Keep open: current main still has explicit agent configuration and explicit gateway/CLI agent management, but no trusted external-workspace agent-config discovery contract. This remains a product/security decision, not a narrow fix-PR candidate.

## What This Changes

The issue requests an `agents.autoDiscover` configuration surface that scans external workspace directories for agent configuration files and loads them without manual central registration.

## Best Possible Solution

Keep explicit registration as the default until maintainers define a trusted discovery contract covering roots, precedence, validation, reload behavior, and security proof.
