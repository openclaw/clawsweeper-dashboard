## Summary

Keep open: current main and the latest stable release still use explicit `agents.list` registration plus explicit agent create/update/delete paths; external workspace agent-config discovery is not implemented and needs product/security direction.

## What This Changes

Request to add an `agents.autoDiscover`-style config surface that scans trusted workspace directories for agent config files and registers discovered agents.

## Best Possible Solution

Maintainers should first decide whether OpenClaw keeps explicit agent registration or adds a narrow trusted discovery contract covering roots, precedence, validation, reload/watch behavior, and security proof.
