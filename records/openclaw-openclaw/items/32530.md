## Summary

Keep open: current main and the latest release still lack trusted external workspace agent-config discovery, and the remaining work needs maintainer product/security direction rather than cleanup closure.

## What This Changes

The issue requests an `agents.autoDiscover` config surface that scans external workspace directories for agent configuration files and loads them into OpenClaw automatically.

## Best Possible Solution

Maintainers should decide the trust and product boundary first; if accepted, the design should specify trusted roots, bounded globbing, validation, precedence, reload semantics, audit/doctor behavior, docs, and upgrade/security proof.

- **Design trusted discovery:** Approve core discovery only after maintainers define trusted roots, glob bounds, realpath/symlink behavior, validation, precedence, reload semantics, and security proof.

## Solution Assessment

Unclear until maintainer direction: direct glob discovery may help multi-project operators, but explicit zero-restart agent registration could solve much of the reported pain with a smaller trust boundary.
