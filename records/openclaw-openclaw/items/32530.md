## Summary

Keep open: current main still has explicit `agents.list`/`openclaw agents add` and `$include` paths, but no trusted external workspace agent-config discovery; the request changes config authority, session identity, and security boundaries enough to need maintainer product/security review.

## What This Changes

Request automatic discovery and loading of agent configuration files from configured external workspace directories instead of requiring each agent to be registered in the central config.

## Best Possible Solution

Decide the product/security boundary first, then either keep using explicit `agents.list` plus `$include`/CLI hot reload, or design a narrow trusted discovery contract with precedence, validation, audit logging, and upgrade tests.
