## Summary

Keep open: current main and v2026.6.11 still support explicit agent registration, explicit Gateway mutation RPCs, and hot reload of `agents.list`, but they do not implement trusted external-workspace agent config discovery. The remaining blocker is product and security design, not stale cleanup.

## What This Changes

Request to add a trusted `agents.autoDiscover`-style mechanism that scans configured external workspace directories for agent config files and loads them without manual central `agents.list` registration.

## Best Possible Solution

Define a trusted agent registration/discovery contract with explicit security, precedence, reload, deletion, session, and auth semantics; keep explicit `agents.list` and `agents.create` canonical until then.
