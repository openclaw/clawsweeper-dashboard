## Summary

Keep open: current main and v2026.6.11 still require explicit agent registration, while automatic external workspace agent-config discovery remains a product and security design question.

## What This Changes

Request to add an `agents.autoDiscover` configuration surface that scans trusted workspace directories for agent config files and registers agents automatically.

## Best Possible Solution

Define a trusted agent registration/discovery contract with explicit security, precedence, reload, and deletion semantics before implementing any scanner; keep explicit registration canonical until then.

## Reproduction Assessment

## Solution Assessment

Unclear pending maintainer direction. A glob scanner is plausible, but the best fix requires a settled trust, precedence, deletion, reload, and session/auth ownership model first.
