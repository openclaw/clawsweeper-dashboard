## Summary

Keep open: current main and v2026.6.11 still support explicit agent registration through `agents.list`, `openclaw agents add`, and Gateway `agents.create/update/delete`, but there is no trusted external-workspace agent-config discovery contract. The remaining work is a product and security decision, not conservative cleanup.

## What This Changes

Requested automatic discovery and loading of agent configuration files from configured external workspace directories.

## Best Possible Solution

Define a trusted agent registration/discovery contract with explicit security, precedence, reload, deletion, session, and auth semantics; keep explicit `agents.list` and `agents.create` canonical until then.

## Reproduction Assessment

Not applicable as a bug reproduction. Source and release inspection show OpenClaw supports explicit `agents.list`, explicit agent creation, and config hot reload, not automatic external workspace agent-config discovery.

## Solution Assessment

Unclear pending maintainer direction. A glob scanner is plausible ergonomically, but the best fix needs a settled trust, precedence, deletion, reload, session, and auth ownership model first.
