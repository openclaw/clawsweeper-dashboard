## Summary

Keep open: current main still only supports explicit agent registration and bounded config includes, while automatic discovery from external workspaces would add trusted-root, config, gateway reload, session/auth, and security semantics that need maintainer direction.

## What This Changes

The issue requests automatic discovery of agent configuration files from external workspace directories instead of requiring each agent to be added to central OpenClaw config.

## Best Possible Solution

Define a trusted agent registration/discovery contract, including security boundary and reload behavior, before implementing any scanner; keep explicit agents.list, agents add, and bounded $include as canonical until then.

## Reproduction Assessment

Not applicable as a bug reproduction; source inspection gives high confidence current main only supports explicit agents.list, agents add/RPC registration, and bounded $include composition, not external workspace auto-discovery.

## Solution Assessment

Unclear pending maintainer direction; adding a glob scanner is plausible, but the issue has not settled trusted roots, precedence, deletion, reload, and session/auth ownership semantics needed for a best fix.
