## Summary

Keep open: current main and the latest release still use explicit agent configuration and agent-management APIs, while trusted external workspace agent-config discovery remains unimplemented and needs maintainer product/security direction.

## What This Changes

Request to add trusted workspace directory scanning so OpenClaw can discover and load external agent configuration files without manually adding every agent to central config.

## Best Possible Solution

Maintain explicit registration for now, then have maintainers choose either a bounded trusted discovery contract or a smaller zero-restart explicit agent-management path before any implementation starts.
