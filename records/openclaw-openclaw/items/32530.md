## Summary

Keep open: current main and v2026.6.11 still expose only explicit central `agents.defaults`/`agents.list` configuration, while the related hot-reload and workspace-capability docs threads only partially overlap the requested external workspace agent discovery.

## What This Changes

Enable OpenClaw to auto-discover agent configuration files from external workspace directories instead of requiring central `agents.list` updates.

## Best Possible Solution

Define an operator-controlled discovery/import design with trusted roots, deterministic validation, conflict precedence, live lifecycle semantics, doctor/security checks, docs, and focused tests before adding config/runtime surface.
