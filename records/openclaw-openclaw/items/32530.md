## Summary

Keep open: current main still has explicit `agents.list` registration and explicit `agents.create/update/delete` mutation paths, but it does not implement trusted external-workspace agent-config discovery.

## What This Changes

The issue requests automatic discovery and loading of agent configurations from external workspace directories instead of manually adding every agent to central config.

## Best Possible Solution

Keep explicit registration as the default unless maintainers approve a trusted discovery design covering roots, filenames, validation, precedence, agentDir/session isolation, reload semantics, and security/audit proof.
