Keep open: current main and v2026.6.11 still do not implement workspace-directory scanning, `agents.autoDiscover`, or workspace-owned agent config loading; this remains a security-sensitive product/config decision rather than a stale cleanup candidate.

## Best Possible Solution

Have maintainers decide the discovery authority first, then implement a bounded opt-in design with trusted roots, explicit-list precedence, hot-load semantics, validation, docs, and focused tests.
