## Summary

Keep open: current main still requires explicit `agents.list` registration or explicit `agents.create/update/delete` mutation, and the requested trusted external-workspace agent-config discovery is not implemented or owned by a merged/runtime PR.

## What This Changes

Add a core `agents.autoDiscover`-style config surface that scans trusted workspace directories for agent config files and loads discovered agents without manual central registration.

## Best Possible Solution

Keep explicit registration by default unless maintainers approve a trusted discovery design covering roots, file names, validation, precedence, agentDir/session isolation, reload semantics, and security/audit proof.
