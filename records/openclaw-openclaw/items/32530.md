## Summary

Keep open: current main and the latest release still require explicit agent entries and do not implement `agents.autoDiscover` or equivalent workspace-owned agent config loading. The linked workspace-capability docs work is useful but intentionally docs-only, so the remaining work is a product and security design decision, not conservative cleanup.

## What This Changes

Request to add an `agents.autoDiscover` configuration surface that scans trusted workspace directories for agent config files and merges discovered agents with explicit agent entries.

## Best Possible Solution

Define an operator-controlled discovery or import design with trusted roots, deterministic conflict handling, validation behavior, and live agent lifecycle semantics before adding any core config source.

No. The proposed glob-based merge is a plausible direction, but the maintainable solution needs a maintainer-approved trust, precedence, validation, and lifecycle model before implementation.
