## Summary

## What This Changes

Request to add opt-in discovery of agent configuration files from external workspace directories so multi-project deployments do not have to manually register every agent in central config.

## Best Possible Solution

Define the trusted discovery model first, then implement the smallest opt-in core/API path that validates discovered configs, makes precedence deterministic, updates live Gateway agent state safely, and documents upgrade/security behavior.
