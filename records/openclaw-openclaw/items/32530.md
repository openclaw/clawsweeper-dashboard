## Summary

Keep open: current main still only supports explicit `agents.list` registration plus `agents.create/update/delete`; external workspace agent-config discovery is not implemented and needs maintainer product/security direction before automation.

## What This Changes

Request automatic discovery and loading of agent config files from trusted external workspace directories instead of manually registering each agent in central config.

## Best Possible Solution

Keep explicit registration as the default until maintainers define a trusted discovery or zero-restart registration contract covering roots, precedence, validation, reload behavior, and security proof.
