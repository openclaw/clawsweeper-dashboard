## Summary

Keep open: current main and v2026.6.11 still use explicit agent config entries plus explicit `agents.create/update/delete`; external workspace agent-config discovery is not implemented and needs product/security direction before any fix PR.

## What This Changes

Add a trusted `agents.autoDiscover`-style mechanism that scans configured workspace directories for agent configuration files and loads them without manual central registration.

## Best Possible Solution

Keep explicit registration as the default until maintainers define a trusted discovery contract or choose to extend explicit `agents.create/update/delete` for zero-restart workflows.
