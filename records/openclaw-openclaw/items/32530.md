## Summary

Keep open: current main and the latest release still require explicit agent registration through `agents.defaults/list` and explicit agent-management APIs; trusted external workspace agent-config discovery remains unimplemented and needs maintainer product/security direction.

## What This Changes

Request to add `agents.autoDiscover` so OpenClaw can scan trusted workspace directories for agent config files and merge discovered agents with explicit configuration.

## Best Possible Solution

Keep explicit registration as the default until maintainers approve either a bounded trusted discovery contract or a narrower zero-restart explicit agent-management path.
