## Summary

Keep open: current main and v2026.6.11 still require explicit agent registration through `agents.list` or `agents.*` RPCs, while trusted external workspace agent-config discovery remains unimplemented and needs product/security direction.

## What This Changes

Request to add trusted workspace-directory scanning that loads agent configuration files into agent registration without manual central config edits.

## Best Possible Solution

Choose the product/security boundary first; if discovery is accepted, specify trusted roots, glob limits, schema validation, explicit-over-discovered precedence, reload behavior, audit/doctor handling, docs, and upgrade tests.
