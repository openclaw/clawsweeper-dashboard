## Summary

Keep open: current main still supports explicit configured agents plus explicit agent-management RPCs, but does not implement trusted external workspace agent-config auto-discovery; the remaining choice is product/security direction, not a narrow bug fix.

## What This Changes

The issue requests an `agents.autoDiscover` configuration surface that scans trusted workspace directories for agent config files instead of requiring every agent in central config.

## Best Possible Solution

Keep explicit registration as the default unless maintainers design a trusted discovery contract with roots, precedence, validation, reload behavior, and security proof.
