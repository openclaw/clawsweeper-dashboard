## Summary

Keep open: current main supports explicit agent registration and hot handling for `agents.list` changes, but it still does not implement workspace-directory scanning, `agents.autoDiscover`, or loading workspace-owned agent config files; this remains a security-sensitive product/config decision.

## What This Changes

Request an `agents.autoDiscover` config surface that scans trusted external workspace directories for agent config files and merges discovered agents with explicit configured agents.

## Best Possible Solution

Have maintainers decide the discovery authority first, then implement a bounded opt-in design with trusted roots, explicit-list precedence, hot-load semantics, validation, docs, and focused tests; otherwise keep explicit `openclaw agents add` plus hot `agents.list` reload as the supported path.
