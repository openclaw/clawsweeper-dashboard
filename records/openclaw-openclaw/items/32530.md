## Summary

Keep open: current main has explicit `agents.list` configuration plus `agents.create/update/delete` and hot-reloads `agents.list` changes, but it still has no trusted external-workspace agent-config discovery contract.

## What This Changes

The issue requests automatic discovery and loading of agent configuration files from trusted external workspace directories instead of manually registering each agent in central config.

## Best Possible Solution

Define the trusted-discovery contract first: roots, precedence over explicit agents, validation, reload semantics, security proof, and whether it extends `agents.create/update` rather than adding an ad hoc workspace scan.

- **External Operator Tooling:** Leave workspace scanning to a plugin, script, or ClawHub package unless it exposes a missing core API.
