## Summary

Keep open: current main still lacks an `agents.autoDiscover` or workspace config-pattern surface, while existing code and docs keep agent registration explicit through `agents.list`, `$include`, and `agents.create/update/delete`; the request needs product/security direction before implementation.

## What This Changes

Request automatic discovery and loading of agent configurations from external workspace directories instead of manually registering every agent in central config.

## Best Possible Solution

Decide whether to keep explicit registration or design a trusted discovery contract with roots, precedence, validation, reload behavior, and security proof.
