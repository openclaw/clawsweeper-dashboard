## Summary

Keep open: current main and v2026.6.11 still only support explicit `agents.list`, RPC, and CLI agent registration; trusted external-workspace scanning remains a product and security-boundary decision.

## What This Changes

Request to add `agents.autoDiscover` so OpenClaw can scan configured workspace directories and load agent configuration files without manual central registration.

## Best Possible Solution

Keep explicit registration as the default unless maintainers approve a trusted discovery design covering roots, file names, validation, precedence, agentDir/session isolation, reload semantics, and security/audit proof.

- **Narrow To Zero-Restart Management:** First improve explicit runtime registration and binding reload semantics, then revisit whether external workspace glob discovery belongs in core.
