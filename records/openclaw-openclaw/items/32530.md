## Summary

Keep open: current main and the latest stable tag still support explicit agent registration and mutation, but not trusted external workspace agent-config auto-discovery; the remaining decision is product/security scope rather than stale cleanup.

## What This Changes

Request to let OpenClaw discover agent configurations from configured external workspace directories instead of requiring every agent to be explicitly registered in central config.

## Best Possible Solution

Keep the issue open until maintainers choose either a bounded trusted-discovery design or an explicit zero-restart agent-management direction built around the existing `agents.create/update/delete` and `agents.list` surfaces.
