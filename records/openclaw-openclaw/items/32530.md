## Summary

Keep open: current main supports explicit `agents.list`, manual agent mutation, `$include`, and hot-applied agent-list changes, but it still has no trusted external workspace agent-config discovery path. TinyTb's comment usefully reframes part of the pain as zero-restart agent management; current hot reload partly addresses that, but not directory scanning or external config ingestion.

## What This Changes

Add an `agents.autoDiscover` configuration surface that scans trusted workspace directories for agent config files and loads them without manually registering every agent in central config.

## Best Possible Solution

Define an operator-controlled discovery or registration model that reuses existing schema validation, explicit agent mutation, trusted-root policy, and hot reload semantics; otherwise keep `$include` and `openclaw agents add` as the supported path.
