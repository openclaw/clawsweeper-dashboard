## What This Changes

The issue requests automatic discovery and loading of agent configurations from external workspace directories instead of requiring every agent to be listed in central config.

## Best Possible Solution

Define an operator-controlled discovery or registration model that reuses schema validation, trusted-root policy, explicit agent mutation, and hot reload semantics; otherwise keep `$include` and `openclaw agents add` as the supported path.
