## What This Changes

The PR adds a five-second timeout to the synchronous Codex CLI PATH lookup and updates the associated mocked call assertion.

## Best Possible Solution

Make the lookup genuinely bounded—prefer a nonblocking/cancellable lookup or an explicit hard-kill strategy while preserving the existing `null` fallback—and demonstrate that local TUI `/auth` recovers after a deliberately stalled lookup.
