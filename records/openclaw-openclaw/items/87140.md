## Summary

Keep open: current main and v2026.6.11 still keep macOS Push-to-Talk coupled to Apple Speech, while the existing batch STT and realtime transcription provider surfaces do not reach the native PTT capture pipeline before text forwarding.

## What This Changes

Request a configurable speech-to-text backend boundary for native macOS Push-to-Talk while preserving Apple Speech as the default.

## Best Possible Solution

Design a narrow native PTT transcription boundary that keeps Apple Speech as the default, reuses Gateway media-audio/provider contracts where maintainers choose, and documents credential, network, fallback, overlay-state, and review-before-send behavior before implementation.
