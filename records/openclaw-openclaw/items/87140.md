## Summary

Keep open: current main and v2026.6.11 still run native macOS Push-to-Talk through Apple Speech, while `tools.media.audio` remains a separate media-understanding path. This is a useful feature request, but it needs maintainer product and security direction before implementation.

## What This Changes

Add a configurable STT backend abstraction for native macOS Push-to-Talk while preserving Apple Speech as the default.

## Best Possible Solution

Design a narrow native PTT batch-STT boundary that keeps Apple Speech as the default, reuses existing Gateway media/provider security contracts where chosen, and treats streaming/wake-word replacement as follow-up scope.
