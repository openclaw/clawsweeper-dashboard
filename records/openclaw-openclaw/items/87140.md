## Summary

Keep open: current main and v2026.6.11 still hardwire native macOS Push-to-Talk to Apple Speech, while `tools.media.audio` remains a separate media-understanding path. The request is valid, but it needs maintainer product and security design before implementation.

## What This Changes

Request to add a configurable STT backend abstraction for native macOS Push-to-Talk while keeping Apple Speech as the default.

## Best Possible Solution

Define a narrow native PTT batch-STT boundary that preserves Apple Speech by default, reuses existing media/provider contracts where suitable, and documents credential, network, fallback, and overlay-state behavior before implementation.
