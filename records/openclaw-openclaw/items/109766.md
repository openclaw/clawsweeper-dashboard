## Summary

The account-isolation direction is still necessary and follows the owner model established by the merged provider/TTS work, but the current head retains a startup regression for disabled channels with explicit accounts and is not ready to merge.

## What This Changes

Assigns channel credentials to normalized account owners and keeps only accounts with unavailable SecretRefs cold during Gateway channel activation.

## Best Possible Solution

Keep the account-owner isolation design, add a universal channel-enabled gate in the shared top-level collector with a disabled-channel regression test, then refresh the Plugin SDK compatibility review and targeted built-Gateway proof.
