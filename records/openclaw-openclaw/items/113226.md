## What This Changes

The PR adds explicit read-only repository-content permission to both GitHub App tokens in the labeler workflow so its configuration lookup passes workflow sanity checks.

## System Context

The labeler workflow handles issue and pull-request labeling by minting a GitHub App installation token, loading repository label rules, and calling GitHub APIs. Workflow Sanity audits the workflow declarations so automation keeps explicit, least-privileged access.
