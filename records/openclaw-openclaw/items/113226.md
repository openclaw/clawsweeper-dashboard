The labeler additions remain justified for loading repository label configuration, so the narrow fix is to remove only the two auto-response additions before merge.

## What This Changes

The PR adds explicit `contents: read` permission to the primary and fallback GitHub App tokens used by the auto-response and labeler GitHub Actions workflows.

## System Context

OpenClaw’s repository automation workflows mint short-lived GitHub App installation tokens to perform tasks such as responding to contributors and applying labels. Those tokens pass into local workflow scripts and GitHub API calls, so each requested permission determines the security boundary of automated repository actions.
