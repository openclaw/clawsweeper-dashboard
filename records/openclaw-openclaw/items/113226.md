## What This Changes

The PR grants repository-content read access to both labeler GitHub App installation tokens so the labeler can fetch its repository routing configuration while processing pull requests.

## System Context

The labeler workflow runs on GitHub pull-request and issue events, creates a short-lived GitHub App token, reads the repository’s label-routing configuration, and then applies labels through the GitHub API. This change affects the token used by the labeler action, not OpenClaw runtime or user data.
