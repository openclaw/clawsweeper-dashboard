## What This Changes

The PR explicitly grants `contents: read` to the primary and fallback GitHub App tokens used by the auto-response and labeler workflows, allowing Workflow Sanity to audit their permissions without reducing audit coverage.

## System Context

OpenClaw's repository automation runs on GitHub events, mints short-lived GitHub App installation tokens, then labels pull requests or posts automated responses. The requested token permissions determine what those automations can read or modify after the workflow starts.
