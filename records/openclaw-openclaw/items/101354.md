  - body: Workspaces already supports policy-approved sandboxed URLs through `builtin:iframe-embed`.   - confidence: 0.91

  - body: The renderer ignores `_value` and reads only `widget.props.url`, so URLs supplied through the normal static/RPC binding resolution path never reach the preview frame. Evaluate the resolved value, consistent with the builtin renderer contract.
  - confidence: 0.98

  - body: The selected viewport is initialized from `defaultViewport` on every render and subsequent clicks only mutate the current DOM. Any workspace update that rerenders the widget resets the selection; keep it in component or workspace state keyed by widget identity.
  - confidence: 0.93

  - body: Adding the English preview keys without the generated locale updates leaves the dedicated `control-ui-i18n` check failing and ships an incomplete localization surface. Run the authenticated locale synchronization before merge rather than landing a known-dirty baseline.
