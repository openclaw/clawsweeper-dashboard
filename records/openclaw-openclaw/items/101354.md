- **[P2] Use the resolved widget value as the preview URL:** `ui/src/lib/workspace/widgets/preview.ts:28`
  - body: `renderPreview` discards the value supplied by the Workspaces binding pipeline and reads only `widget.props.url`. A preview configured with a static or RPC binding therefore cannot display or react to the resolved URL. Pass the resolved value through the same canonical path used by other bound builtins.
  - confidence: 0.98
- **[P2] Retain viewport selection across Workspaces rerenders:** `ui/src/lib/workspace/widgets/preview.ts:51`
  - body: The selected viewport is changed by mutating the mounted DOM, while each render derives state again from `defaultViewport`. Any normal parent update resets the operator to the default viewport. Store the selection in Workspaces-owned reactive state keyed by the widget so rerenders preserve it.
  - confidence: 0.93
