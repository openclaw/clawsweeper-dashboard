## What This Changes

Adds a capability-negotiated QR-code presentation and Continue acknowledgement for system-agent setup chat, spanning Gateway protocol types, hosted wizard prompts, and the Control UI.

## System Context

The system-agent setup conversation runs through Gateway `openclaw.chat`, where hosted setup wizards can ask the connected client for structured input. This change lets a capable Control UI receive a bounded QR PNG data URL, render it beside a non-skippable acknowledgement action, and return the user’s Continue response to the wizard.
