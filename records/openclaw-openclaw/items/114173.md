## What This Changes

This PR adds a capability-negotiated QR-code acknowledgement step to system-agent gateway chat and renders it in the Control UI as a non-skippable Continue action.

## System Context

System-agent setup uses the Gateway chat API to drive interactive wizard steps in the Control UI. This change lets a capable browser advertise QR-image support, receive a validated QR acknowledgement step, display it, and send the acknowledgement back through the existing chat session.
