## Summary

Keep open: current main and v2026.6.11 still route generic Discord component callbacks to agents as text-only inbound turns, while richer interaction fields are limited to plugin interactive handlers. The remaining work is a public metadata-contract and trust-boundary decision, not conservative cleanup.

## What This Changes

Request structured Discord button/select interaction metadata in generic agent callback context instead of label-only text.

## Best Possible Solution

Define a narrow documented Discord/channel interaction metadata contract populated from registry state and Discord interaction payload for buttons, selects, and modals, with tests/docs and plugin boundary semantics preserved.
