## Summary

Keep this PR open: it still has the previously reported P1 correctness defect because each helper validates a pathname with `statSync` and then reopens that pathname with unbounded `readFile`; it also lacks contributor-supplied real Doctor behavior proof.

## What This Changes

The branch adds 10 MiB checks and oversized-file migration warnings for legacy state reads in the Reef, Active Memory, and Device Pair plugin Doctor contracts.

## Best Possible Solution

Replace the pathname check/read pairs with a single opened-file, size-bounded read primitive shared or consistently applied across the three plugin contracts, add focused oversized and normal-migration regression coverage, then post redacted real Doctor output for both paths.
