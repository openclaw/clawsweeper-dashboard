## Summary

Keep this PR open for a narrow correction: the new rejection path silently converts valid oversized legacy state into “no state” in two migrations, and the stat-then-read sequence still does not bound the eventual read. The stated OOM hardening remains necessary, but this patch is not yet a safe implementation.

## What This Changes

Adds 10 MiB metadata pre-check helpers before three plugin doctor migrations read and parse legacy JSON state files.

## Best Possible Solution

Use one shared bounded legacy-file reader that reads a fixed maximum through a stable descriptor/stream, preserves rejected legacy sources for recovery, and emits migration warnings instead of treating policy rejection as absent state.
