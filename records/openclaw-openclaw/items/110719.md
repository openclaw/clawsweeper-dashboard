## Summary

Keep this PR open: the latest revision addresses the earlier warning-propagation gaps, but its `statSync(path)` followed by `readFile(path)` pattern still leaves the bounded-read guarantee vulnerable to a path swap. ## What This Changes

Adds 10 MiB checks and oversized-file warnings before three plugin doctor migrations parse legacy Reef, Active Memory, and Device Pair state files.

## Best Possible Solution

Use one opened file descriptor per legacy source, validate that descriptor with `fstat`, and perform an explicitly size-bounded read from that descriptor; then add focused migration coverage and redacted live Doctor proof for normal and oversized files.
