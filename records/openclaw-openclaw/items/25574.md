## What This Changes

The issue asks OpenClaw to log identical config warning payloads only once per unchanged warning state while still re-logging changed or reappearing warnings.

## Best Possible Solution

Land the linked PR after review, or replace it with a narrower config IO fix that dedupes unchanged warning payloads across load/write paths and re-emits when the warning state changes.

## Solution Assessment
