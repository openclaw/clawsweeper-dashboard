## Summary

Keep this PR open for normal maintainer review. It is a narrow, additive documentation correction: npm’s own v11 documentation confirms that global installs must use `--allow-scripts` rather than `npm approve-scripts`, and the PR places that guidance beside OpenClaw’s existing npm install path without changing the default command.

## What This Changes

This PR adds an npm 11+ install note telling global-install users how to allow OpenClaw’s package lifecycle scripts when npm warns that those scripts were skipped.

## System Context

The install guide is the user-facing entry point for manually installing the OpenClaw CLI with npm, pnpm, or Bun. Its npm section feeds directly into onboarding and gateway setup, while lifecycle-script behavior is controlled by npm rather than by OpenClaw’s runtime.
