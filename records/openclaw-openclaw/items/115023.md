## What This Changes

This PR changes QMD memory-search output parsing so bracketed diagnostics and no-results warnings do not hide a later valid JSON result array, with regression coverage for noisy stdout.

## System Context

The memory host invokes QMD as a subprocess and converts its stdout and stderr into normalized search hits. This parser sits between the QMD command output and memory retrieval, so it must separate diagnostics from the JSON array consumed by the search result pipeline.
