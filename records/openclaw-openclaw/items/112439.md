## What This Changes

This PR makes Baseten’s live model-catalog request use OpenClaw’s trusted environment proxy preset when no custom fetch guard is supplied, while retaining injected fetch guards for tests and callers.

## System Context

The Baseten bundled provider supplies model metadata to `openclaw models list`. Its live catalog discovery uses an SSRF-guarded request and falls back to bundled static models when live discovery cannot complete.
