The PR allows fixed HTTPS provider model catalogs to honor eligible proxy environment settings while keeping custom or local endpoints strict, and repairs Google Chat `NO_PROXY` parsing for whitespace-separated and lowercase fallback rules.

Provider plugins use the shared live-catalog runtime to fetch dynamic model lists before OpenClaw exposes them to model selection. The runtime applies SSRF, DNS-pinning, redirect, and proxy-routing policy; Google Chat separately applies compatible proxy bypass rules while obtaining auth tokens.
