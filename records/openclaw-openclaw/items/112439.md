## Summary

Keep this PR open for the assigned maintainer’s approval. The consolidated patch has credible real-environment proof and preserves the intended strict path for explicit, local, and cleartext discovery endpoints, but it intentionally broadens proxy routing for canonical provider catalogs and includes an OpenAI Codex catalog path that needs the repository-required direct Codex-contract check before a final merge verdict.

## What This Changes

The PR lets fixed, canonical HTTPS provider-model catalogs use eligible proxy environment settings while keeping custom and local catalog URLs direct, and fixes Google Chat handling of spaced and lowercase no-proxy environment rules.

## System Context

Provider plugins request live model catalogs during provider setup and model listing. Those requests pass through the Plugin SDK’s SSRF-guarded fetch layer, which either keeps the request direct or selects an eligible environment proxy before returning catalog rows to provider configuration and the CLI.
