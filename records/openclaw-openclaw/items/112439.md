## What This Changes

This PR moves provider catalog discovery onto an origin-scoped environment-proxy path for canonical HTTPS provider endpoints while leaving custom, local, and cleartext endpoints on strict guarded routing.

## System Context

Provider plugins use the Plugin SDK’s live-catalog helper to fetch model lists before OpenClaw presents available models to users. This change determines whether each catalog request can use environment proxy settings, while the shared fetch guard continues to enforce SSRF, redirect, DNS-pinning, and header-handling rules.
