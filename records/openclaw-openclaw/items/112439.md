## What This Changes

Centralizes eligible HTTP(S) proxy use for remote live provider model catalogs, keeps local or private catalog origins direct, and fixes Google Chat handling of spaced and lowercase no-proxy environment rules.

## System Context

Live provider discovery retrieves remote model catalogs used by provider plugins and the model-listing experience. Requests pass through OpenClaw’s SSRF guard and proxy policy before catalog rows are normalized, cached, and exposed to provider selection; Google Chat separately uses the guarded transport for OAuth traffic.
