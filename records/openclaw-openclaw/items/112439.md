## What This Changes

This PR makes fixed, canonical HTTPS provider model catalogs honor eligible HTTP(S) proxy settings while retaining strict direct routing for custom or local catalog endpoints, and fixes Google Chat parsing of whitespace and lowercase no-proxy rules.

## System Context

Provider plugins obtain live model lists through the shared Plugin SDK catalog runtime; those requests feed provider configuration and model selection. The PR changes how fixed vendor endpoints choose an outbound transport while preserving the SSRF guard, redirect limits, and static-catalog fallbacks.
