## What This Changes

The PR lets fixed canonical HTTPS provider model catalogs use eligible HTTP(S) proxy environment settings, keeps custom or local catalog URLs on strict direct routing, tightens redirect handling, and fixes Google Chat `NO_PROXY` parsing.

## System Context

Provider plugins fetch live model catalogs during model discovery, then fall back to bundled catalog data when discovery cannot complete. These requests pass through OpenClaw's SSRF guard, which selects strict direct routing or an explicitly trusted environment-proxy route before returning catalog rows to the provider runtime.
