## What This Changes

This PR makes Baseten live model discovery select OpenClaw’s trusted-environment HTTP(S) proxy mode by default while preserving caller-injected fetch guards, and adds a regression test for that default.

## System Context

The Baseten plugin supplies model definitions to the CLI’s provider catalog flow. A live catalog request passes through OpenClaw’s SSRF-guarded fetch layer, then returns discovered model rows or keeps the bundled fallback catalog when discovery cannot succeed.
