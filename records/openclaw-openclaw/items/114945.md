## What This Changes

This PR changes Code Mode’s QuickJS worker lifecycle so compiled WebAssembly is reused across workers, worker deadlines and cancellation share one watchdog, suspended runs expire on a timer, and output/tool budgets apply across execution legs.

## System Context

Code Mode executes sandboxed JavaScript in QuickJS worker threads and relays guest tool calls through OpenClaw’s host bridge. Interactive and headless runners store suspended snapshots, wait for bridge completion, then resume, fail, or expire the run.

  State --> Decision[Resume, expire, or cancel]
  Decision --> Result[Output and execution result]
