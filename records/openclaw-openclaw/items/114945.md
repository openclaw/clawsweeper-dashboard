## What This Changes

This PR refactors Code Mode’s QuickJS worker lifecycle to share compiled WebAssembly, unify worker deadlines and cancellation, expire inactive suspended runs, and enforce output and tool budgets across resumed worker legs.

## System Context

Code Mode runs user scripts in isolated QuickJS workers and pauses them when they need host-side tools or agent operations. The execution and headless paths restore those snapshots, settle bridge calls, and return script output while enforcing time, output, and tool-call limits.

  F --> G[Output, result, timeout, or abort]
