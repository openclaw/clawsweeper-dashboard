## What This Changes

This PR adds sanitized, actionable OpenAI Realtime authentication diagnostics for clearly Azure- or proxy-shaped credentials, documents a recovery override, and adds resolver regression coverage.

## System Context

The bundled OpenAI plugin resolves Realtime credentials for Talk and other voice surfaces before creating browser client secrets or backend WebSocket bridges. Its resolved authentication mode feeds browser WebRTC or gateway-relay sessions, so credential classification affects both user-facing readiness errors and whether OAuth fallback can run.
