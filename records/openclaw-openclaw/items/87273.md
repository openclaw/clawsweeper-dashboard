## What This Changes

This PR changes the shared OpenAI Realtime voice provider to reject known Azure/proxy credentials on direct `api.openai.com` sessions, replace unsafe provider errors with an actionable diagnostic, add regression coverage, and document the direct-key requirement.

## System Context

OpenClaw’s shared OpenAI Realtime voice provider resolves credentials for browser client-secret sessions and server-side WebSocket bridges used by Talk and other voice surfaces. It chooses between direct OpenAI and configured custom/Azure endpoints, then passes the resulting session or error to the calling voice flow.
