## What This Changes

The branch changes the session find tool’s optional `limit` from a general number to an integer, rejects direct fractional execution inputs, and adds production-schema regression coverage.

## System Context

The session find tool accepts model-supplied glob search parameters, validates them, then normalizes the result limit before invoking file-globbing operations. This PR changes the boundary between accepted tool arguments and the normalization behavior that controls the returned result count.
