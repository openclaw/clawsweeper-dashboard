## What This Changes

The PR changes the session file-search tool so its optional `limit` parameter accepts integers only and rejects fractional values during direct execution.

## System Context

Session agents call the file-search tool with model-generated parameters. The tool validates its input, normalizes the result limit, delegates to custom or default file-search operations, and returns matching paths to the agent.
