## Summary

Keep open: current main does not contain this viable fix, and the linked issue remains open. The prior restart-durability finding should no longer block because OpenClaw already documents subagent announces as best-effort across gateway restarts, while the latest commit protects orderly restart by registering the wake as tracked root work.

## What This Changes

The PR adds wave-scoped terminal-settle detection, bounded requester-wake retries, retired child-result retention, and gateway root-work accounting so top-level parallel-subagent workflows synthesize after draining.

## Best Possible Solution

Rebase onto current main and land the bounded, idempotent runtime wake with tracked root-work accounting, retaining abrupt-restart loss as the documented best-effort boundary unless maintainers separately decide to make all subagent announce obligations durable.
