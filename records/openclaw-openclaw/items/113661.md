## What This Changes

The PR makes the SearXNG web-search client reuse a configured URL path already ending in `/search`, including a trailing-slash form, and adds focused URL-builder tests.

## System Context

The bundled SearXNG plugin converts a configured self-hosted instance URL plus a search query into a JSON search request. That request is validated and sent through OpenClaw’s guarded web-search transport, then normalized into tool results for agents.
