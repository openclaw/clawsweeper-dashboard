- `impact:crash-loop`: The reported orphan trees can drive memory growth and process-level availability pressure.

## Summary

Keep open: current main and v2026.6.11 still use process-local supervisor and background exec registries, while the linked fix PR is open and only covers in-process orphan reconciliation rather than durable restart/session-loss cleanup.

## What This Changes

The issue asks OpenClaw to prevent background PTY exec process trees from surviving gateway restart or session-state loss as untracked orphans.

## Best Possible Solution

Add a core-owned durable supervisor lifecycle for PTY background execs, preferably using the shared state DB rather than sidecar files, then reconcile previous-epoch runs on startup after maintainers choose kill versus reattach semantics; land the linked PR or a replacement only if it matches that policy.
