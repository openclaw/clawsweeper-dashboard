## Summary

The exact head still contains the previously reported edit fallback bug: explicit authored text is dropped when it is merely a substring of longer block text. The Slack visualization direction and most API-limit handling are sound, but this user-visible regression blocks merge.

## Best Possible Solution

Replace substring de-duplication with exact normalized paragraph or represented-fragment matching, add the `OK` versus `Not OK` regression test, and retain the documented 4,000-character edit cap.
