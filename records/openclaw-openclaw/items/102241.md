## Summary

The prior lifecycle race is fixed, but the central command-request metrics are attached to Codex hook configuration generation rather than hook execution. A command installed once and executed many times is therefore summarized as one request, making the aggregate misleading for the stated process fan-out investigation. Exact-head runtime proof is also still pending.

## What This Changes

The PR adds registration-scoped native hook relay counters, slow-invocation warnings, deferred final summaries, and lifecycle regression tests.

## Best Possible Solution

Count actual hook attempts at the CLI or bridge request boundary, separately report successful local invocations and unavailable/no-op outcomes, retain the lifecycle-safe registration summary, and prove the resulting fields with a redacted exact-head Codex run.
