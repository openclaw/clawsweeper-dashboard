Keep open. ## What This Changes

Reduce fixed per-session model context by pruning, compressing, or lazily loading tool schemas and duplicated tool prompt text.

## Best Possible Solution

Keep this as the canonical maintainer-owned tracker and sequence compatible reductions: avoid empty tool-definition payloads, remove duplicated Tooling text when approved, prune high-footprint schemas by channel/capability where safe, shorten long descriptions, and reuse Tool Search directory mode before adding any new public API or config surface.
