## What This Changes

This PR adds regression coverage that provider-level `models.providers.<id>.timeoutSeconds` becomes `requestTimeoutMs` when a model is resolved from the bundled static catalog fallback.

## System Context

Embedded agent model resolution combines configured provider settings with either configured models, provider runtime results, or the bundled static catalog. The resolved model’s request timeout then feeds the LLM idle watchdog used by channel and other non-cron agent runs.
