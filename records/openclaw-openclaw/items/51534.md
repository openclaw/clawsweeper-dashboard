## Summary

Keep open: current main and the latest release still lack an original-reply-author auto-mention policy; related Discord mention fixes only handle outbound text that already contains a targeted mention. The remaining work needs maintainer product direction because it would add Discord notification semantics and new config surface.

## What This Changes

The issue asks for Discord guild replies to optionally auto-prepend the original author's `<@userId>` mention when OpenClaw sends a reply message.

## Best Possible Solution

If accepted, implement this in the Discord plugin as a default-off reply-author mention policy that carries the original author ID into outbound delivery, deduplicates existing mentions, preserves broadcast safeguards, documents the config, and proves live guild behavior.
