## Summary

Keep this open: current main and v2026.6.11 still do not implement original-author auto-mention injection for Discord guild replies. The related merged Discord fix only reroutes replies that already contain a mention, while this request adds new opt-in notification policy and config surface that needs maintainer direction.

## What This Changes

Requests an opt-in Discord setting that prepends the original reply author's mention to guild reply text when OpenClaw sends a Discord reply.

## Best Possible Solution

Decide the Discord notification policy first; if accepted, implement it inside the Discord plugin reply-delivery path with opt-in scoped config, schema/docs/tests, and live guild proof that only the intended reply author is pinged.

## Reproduction Assessment

No high-confidence live Discord reproduction is attached. Source inspection does show the requested behavior is absent: current replies add message_reference and only rewrite mentions already present in outbound text.

## Solution Assessment

Unclear pending product direction. Discord-plugin post-processing is the plausible owner boundary, but the config name, default, inheritance scope, and notification safety rules need maintainer approval before this is the best fix.
