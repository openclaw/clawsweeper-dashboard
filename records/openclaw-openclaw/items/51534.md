## Summary

Keep open: current main and v2026.6.11 still lack a Discord policy that synthesizes a visible mention for the original guild reply author. Related merged Discord mention fixes cover mentions already present in outbound text or live-preview delivery, but this remaining request needs maintainer product direction because it changes notification semantics and adds config surface.

## What This Changes

The issue requests a default-off Discord option to prepend `<@originalAuthorId>` to guild reply text when a reply lacks a visible mention of the original author.

## Best Possible Solution

If maintainers accept the policy, implement it in the Discord plugin as a default-off reply-author mention option that carries the original author ID into outbound delivery, deduplicates existing mentions, preserves broadcast safeguards, updates docs/schema/UI hints, and includes focused tests plus live guild proof.
