## Summary

Keep open: current main and the latest release have Discord reply references and deterministic `mentionAliases`, but they still do not provide the requested opt-in policy that prepends the original guild reply author's `<@id>` mention.

## What This Changes

Request to add a Discord `autoMentionReply`-style option that prepends the original guild reply author's `<@id>` mention to outbound replies when the reply text does not already include it.

## Best Possible Solution

Keep the current `mentionAliases` and fresh-final-message behavior, and add an opt-in Discord-owned reply-author mention policy only if maintainers approve the config shape, defaults, and guild-only safety rules.
