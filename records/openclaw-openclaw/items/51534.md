## Summary

Keep open: current main and v2026.6.11 still do not auto-prepend the original Discord reply author's mention. The related merged work fixes mention-bearing final replies, but this issue asks for a distinct opt-in notification policy and config surface that needs maintainer product judgment.

## What This Changes

The issue requests an opt-in Discord setting that prepends the original guild reply author's mention when the outbound reply text does not already mention them.

## Best Possible Solution

Confirm the Discord notification policy first; if accepted, implement it inside the Discord plugin as an opt-in config with author-ID-aware prefixing, mention/broadcast safety checks, docs, and live guild proof.

## Reproduction Assessment

Yes, at source level: current main builds native replies with message_reference only and has no autoMentionReply config or author-prefix path. I did not run a live Discord guild reproduction.

## Solution Assessment

Unclear until maintainers decide the notification policy. The requested config is plausible, but the best fix must balance explicit mentions, Discord native reply behavior, broadcast safety, and config-surface cost.
