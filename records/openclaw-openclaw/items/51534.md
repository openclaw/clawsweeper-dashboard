## Summary

Keep open: current main and v2026.6.11 still do not provide the requested opt-in Discord reply-author mention injection. ## What This Changes

Requests an opt-in Discord config that prepends the original guild reply author's `<@id>` mention to outbound reply messages when the model omits it.

## Best Possible Solution

Confirm the Discord notification policy first; if accepted, implement it inside the Discord plugin as an opt-in config with author-ID-aware prefixing, mention/broadcast safety checks, docs, focused tests, and live guild proof.

## Reproduction Assessment

## Solution Assessment
