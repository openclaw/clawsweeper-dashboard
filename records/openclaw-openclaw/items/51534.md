## Summary

Keep open: current main and v2026.6.11 still do not auto-prepend the original Discord reply author's visible mention, and the related merged mention work only covers replies that already contain a target mention.

## What This Changes

The issue requests an opt-in Discord setting that prepends the original guild reply author's `<@userId>` mention to outbound reply text when the model did not include it.

## Best Possible Solution

Decide the Discord notification policy first; if accepted, implement it in the Discord plugin as a default-off author-ID-aware reply formatting policy with duplicate-mention, broadcast, bot-loop, docs, focused tests, and live guild proof.
