## Summary

Keep this open. Current main has the adjacent Discord mention-alias and reply-reference machinery, including the merged live-preview fix for mention-bearing final replies, but it still does not implement automatic original-author mention injection for guild replies or the proposed `channels.discord.autoMentionReply` config surface.

## What This Changes

Request automatic Discord guild-reply mention injection so replies can prepend the original author's `<@id>` when `replyToMode` and mention-gated multi-agent setups need reliable visible notifications.

## Best Possible Solution

Decide the Discord notification policy first; if accepted, implement it inside the Discord plugin reply-delivery path as a narrow opt-in with schema, docs, tests, and live guild proof that only the intended reply author is pinged.

## Reproduction Assessment

## Solution Assessment
