## What This Changes

This PR makes model-authored Telegram sends discard an incidental populated location when real text or media is present, while retaining location-only sends and direct/API mixed-payload rejection.

## System Context

OpenClaw's message tool and Gateway both route outbound actions to channel plugins. This change inserts a Telegram-specific normalization step before shared validation and channel dispatch, so accidental model fields do not suppress otherwise valid Telegram content.
