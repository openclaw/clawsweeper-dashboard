## Summary

## What This Changes

This PR makes model-authored Telegram `send` calls discard an incidental populated location when they also contain real content, while preserving standalone location sends and strict rejection for direct/API mixed payloads.

## System Context

OpenClaw’s message tool and Gateway both route outbound actions through shared channel dispatch and validation. This change classifies a trusted model-originated Telegram request before dispatch so content can reach Telegram without weakening the public direct/API mixed-location contract.
