## Summary

Keep open: current main still lacks native outbound Telegram album sending. The current implementation preserves multiple `mediaUrls` but routes them through sequential single-media sends, and an open external draft with closing syntax leaves the permanent API shape for maintainers to decide.

## What This Changes

Request support for Telegram media groups/albums in the message tool so 2-10 related media items can be sent as one album with a shared caption.

## Best Possible Solution

Choose one Telegram message-tool API shape, preferably reusing existing `send` plus `mediaUrls`, then implement native album grouping for eligible media while preserving sequential fallback with focused tests, docs, and live Telegram proof.
