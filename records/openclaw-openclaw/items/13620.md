## Summary

Keep open: current main still lacks outbound Telegram album delivery via `sendMediaGroup`; existing `mediaUrls` paths are preserved but delivered as individual media sends, and the remaining work needs maintainer API-shape review because an open external draft proposes a new parallel action.

## What This Changes

Request support for Telegram media groups/albums in the message tool so 2-10 related media items can be sent as one Telegram album with a shared caption.

## Best Possible Solution

Choose one Telegram message-tool API shape, preferably reusing the existing `send` action with `mediaUrls` to group eligible 2-10 photo/video items via `sendMediaGroup` while preserving sequential fallback, then document it and prove it with a live Telegram run.
