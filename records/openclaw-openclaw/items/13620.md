## Summary

Keep open: current main still does not implement Telegram outbound album delivery via `sendMediaGroup`; it only preserves multiple media URLs and sends them one at a time, and an open external draft with closing syntax still needs maintainer API-shape review before this tracker can resolve.

## What This Changes

Request to add Telegram outbound media group/album sending to the message tool so multiple media files can be delivered as one Telegram album with a shared caption.

## Best Possible Solution

Add album behavior inside the bundled Telegram plugin’s existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks, documenting the chosen message-tool API, and proving it with focused tests plus live Telegram evidence.
