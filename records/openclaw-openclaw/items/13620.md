## Summary

Keep open: current main still has no outbound Telegram `sendMediaGroup` album path; multiple media URLs are preserved but delivered as individual sends, and an open external draft with closing syntax means maintainers should choose the permanent API shape before cleanup or a separate repair lane.

## What This Changes

Request to support Telegram outbound media groups/albums from the message tool so 2-10 related photos or videos can be sent with shared album semantics.

## Best Possible Solution

Choose one Telegram message-tool API shape, preferably reusing `send` with `mediaUrls` for eligible albums, then implement `sendMediaGroup` in the Telegram-owned send paths with sequential fallback, docs, focused tests, and live Telegram proof.
