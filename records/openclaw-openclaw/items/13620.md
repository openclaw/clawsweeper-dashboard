## Summary

Keep open: current main still lacks outbound Telegram `sendMediaGroup` album delivery. The code now preserves multiple media URLs, but it sends them sequentially, and an open external draft with closing syntax still needs maintainer API/product review before this issue can close.

## What This Changes

Request support for sending Telegram media groups/albums from the message tool, with 2-10 related photos/videos grouped under a shared caption.

## Best Possible Solution

Implement the end state in the bundled Telegram plugin: use Telegram album delivery for eligible 2-10 photo/video groups across message actions, reply delivery, and outbound payload delivery, while retaining existing single-media and non-groupable fallbacks with focused tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 lack an outbound `sendMediaGroup` branch, and plural media URLs are routed through sequential single-media sends.

## Solution Assessment

Unclear. Telegram-plugin-owned `sendMediaGroup` support is the right broad direction, but maintainers still need to choose the public message-tool/action shape and decide whether the external draft is the best base to port.
