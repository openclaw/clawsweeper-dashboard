## What This Changes

## Best Possible Solution

Implement native Telegram sendMediaGroup delivery inside the bundled Telegram plugin for eligible existing mediaUrls send, reply, and outbound payload paths, with sequential fallback plus focused tests, docs, and live Telegram proof.
