## Summary

Keep open: current main still sends outbound Telegram media sequentially rather than as Telegram albums, and an open draft fork PR with closing syntax needs maintainer product/API review before cleanup can close this issue.

## What This Changes

Request support for Telegram media groups/albums in the message tool so multiple related media items can be sent as one grouped album with a shared caption.

## Best Possible Solution

Implement or port album support inside the bundled Telegram plugin by using sendMediaGroup for eligible 2-10 groupable media sets across direct message actions, reply delivery, and outbound payload delivery while preserving current sequential fallback, tests, docs, and live Telegram proof.
