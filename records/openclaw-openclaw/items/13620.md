## Summary

Keep open: current main and v2026.6.11 still route outbound Telegram media as sequential single-media sends, and the open cross-repository draft with closing syntax needs maintainer review or porting rather than cleanup closure.

## What This Changes

Request support for Telegram media groups/albums so the message tool can send 2-10 related photos or videos as one Telegram album with shared caption behavior.

## Best Possible Solution

Keep this issue as the canonical outbound Telegram album tracker while maintainers review, port, or supersede the open draft with a Telegram-plugin implementation covering action sends, reply delivery, outbound payload delivery, focused tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main has no sendMediaGroup path, and the inspected action, reply, and outbound adapter funnels route multiple media URLs through sequential single-media sends; I did not run a live Telegram transport reproduction in this read-only review.

## Solution Assessment

Unclear for the exact API shape. sendMediaGroup support belongs in the Telegram plugin, but maintainers still need to choose whether to extend the existing send/mediaUrls path, add a dedicated album action, or port the open draft.
