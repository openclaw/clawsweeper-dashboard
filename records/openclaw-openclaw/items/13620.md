## Summary

Keep open: current main and the latest release still do not implement outbound Telegram album sending. The code now preserves multiple media URLs, but it delivers them as sequential per-item sends; an open external draft with closing syntax is still the implementation candidate, so maintainers need to choose the permanent API and delivery shape.

## What This Changes

The issue requests Telegram media-group album support for the message tool so 2-10 related photos/videos can be sent as one Telegram album with a shared caption.

## Best Possible Solution

Implement native Telegram album delivery inside the bundled Telegram plugin for eligible 2-10 groupable media items across message.send, reply delivery, and outbound payload delivery, while preserving sequential fallback for single/non-groupable media and adding Telegram live proof plus focused tests/docs.
