## Summary

Keep open: current main and v2026.6.11 still lack native outbound Telegram album delivery, and the linked external draft with closing syntax needs a maintainer API-shape decision before cleanup or a separate repair lane.

## What This Changes

Request support for sending multiple Telegram photos/videos from the message tool as a native media group/album with a shared caption.

## Best Possible Solution

Implement native Telegram `sendMediaGroup` delivery in the bundled Telegram plugin for eligible 2-10 groupable media, preferably on existing structured `mediaUrls` send/reply/outbound paths unless maintainers intentionally choose a new action, with sequential fallback plus focused docs, tests, and live Telegram proof.
