## Summary

Keep open: current main still has sequential Telegram mediaUrl/mediaUrls delivery, but no outbound sendMediaGroup album behavior, and the linked draft fork PR with closing syntax is still the implementation candidate that needs maintainer product/API review.

## What This Changes

The issue requests Telegram outbound album/media-group support for the message tool so multiple photo/video media items can be sent with Telegram sendMediaGroup and a shared caption.

## Best Possible Solution

Implement or port album support in the bundled Telegram plugin at the Telegram-owned send boundary, using sendMediaGroup for eligible 2-10 groups while preserving current sequential fallbacks, docs, focused tests, and live Telegram proof.
