## Summary

Keep open: current main and the latest release still do not implement outbound Telegram album delivery via `sendMediaGroup`, and an open draft PR with closing syntax is already the implementation candidate that needs maintainer API-shape review.

## What This Changes

Add Telegram message-tool support for sending 2-10 related photos/videos as one album/media group with a shared caption.

## Best Possible Solution

Implement album behavior in the bundled Telegram plugin's existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks and documenting the chosen message-tool contract.

## Reproduction Assessment

Yes. Source inspection is enough: current Telegram outbound paths preserve multi-media input but send one media item per Telegram API call, and no outbound `sendMediaGroup` implementation exists on current main or v2026.6.11.

## Solution Assessment

No. The requested capability is valid, but the proposed new `mediaGroup`/`album` or linked `send-media-group` API is only one plausible shape; maintainers should choose whether to reuse existing `mediaUrls` before implementation lands.
