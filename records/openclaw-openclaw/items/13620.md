## Summary

Keep open: current main and the latest release still lack outbound Telegram `sendMediaGroup` album delivery, and the open linked draft plus the message-tool API shape need maintainer review before a separate repair lane is queued.

## What This Changes

Support Telegram media-group/album sending from the message tool so eligible multiple media items can be delivered with Telegram `sendMediaGroup` instead of separate messages.

## Best Possible Solution

Implement album behavior in the bundled Telegram plugin's existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks and documenting the chosen message-tool contract.
