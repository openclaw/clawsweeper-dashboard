## Summary

Keep open: current main and v2026.6.11 still lack outbound Telegram `sendMediaGroup` album delivery, and an open linked draft plus the message-tool API shape need maintainer review before implementation.

## What This Changes

Request to add Telegram media-group/album sending to the message tool so 2-10 related photos/videos can be delivered as one album with a shared caption.

## Best Possible Solution

Implement album behavior in the bundled Telegram plugin's existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks and documenting the chosen message-tool contract.
