Keep open: current main and the latest release still lack native outbound Telegram album/sendMediaGroup delivery, and an open external draft with closing syntax is already the implementation candidate for maintainer API-shape review.

## What This Changes

Request support for Telegram outbound media albums through the message tool, using Telegram media-group semantics instead of one media send per file.

## Best Possible Solution

Implement native Telegram sendMediaGroup delivery in the bundled Telegram plugin for eligible existing mediaUrls send, reply, and outbound payload paths, with sequential fallback, focused tests, docs, and live Telegram proof.
