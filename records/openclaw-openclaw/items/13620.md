## Summary

Keep open. Current main and the latest release still do not implement native outbound Telegram album sending; OpenClaw now preserves multiple media URLs better than when this was filed, but the Telegram paths still send them sequentially instead of using `sendMediaGroup`, and an open fork PR with closing syntax remains the implementation candidate for maintainer review.

## What This Changes

The issue requests Telegram outbound media-group/album support so message sends with multiple photos or videos can use Telegram `sendMediaGroup` with a shared caption.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 media groups across direct message actions, reply delivery, and outbound payload delivery while preserving single-media and non-groupable sequential fallbacks with focused tests, docs, and live Telegram proof.
