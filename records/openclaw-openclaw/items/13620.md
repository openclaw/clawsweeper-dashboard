## Summary

Keep open: current main still lacks outbound Telegram album delivery via `sendMediaGroup`; it preserves multiple media URLs but sends them one at a time, and the open draft with closing syntax still needs maintainer API-shape review before this can resolve.

## What This Changes

Request support for Telegram media-group albums in the message tool so multiple media paths can be sent as one Telegram album with a shared caption.

## Best Possible Solution

Add album behavior in the bundled Telegram plugin’s existing send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks, documenting the chosen message-tool API, and proving it with focused tests plus live Telegram evidence.
