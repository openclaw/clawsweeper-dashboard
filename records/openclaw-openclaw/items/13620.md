## Summary

Keep open: current main and v2026.6.11 still lack outbound Telegram album delivery through sendMediaGroup, and the open linked fork PR is an implementation candidate for maintainer review rather than a reason to close this issue.

## What This Changes

Request support for Telegram media-group album sends from the message tool, with multiple media paths and a shared caption.

## Best Possible Solution

Review the open fork implementation or port a current-main Telegram-plugin version that uses sendMediaGroup for eligible 2-10 album sends while preserving existing sequential fallbacks and adding focused tests plus Telegram/message docs.

Options:

- **Explicit album parameter (recommended):** Add a clearly documented mediaGroup or album array on the existing send action, grouping only eligible 2-10 Telegram photo/video items and falling back otherwise.
- **Auto-group mediaUrls:** Treat existing mediaUrls as album candidates on Telegram when they meet API constraints, accepting more implicit behavior change for current callers.
- **Separate send-media-group action:** Keep current send behavior unchanged and expose album sending as a new Telegram-specific action, at the cost of another user-facing action surface.
