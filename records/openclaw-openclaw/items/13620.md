## Summary

Keep open. Current main and the latest release still lack native outbound Telegram album/media-group sending; the remaining work is product-shaped Telegram plugin behavior, not the narrower mediaUrls sequential fan-out that already landed.

## What This Changes

The issue requests Telegram message-tool support for sending multiple media items as a native Telegram album/media group with a shared caption.

## Best Possible Solution

Add native Telegram album handling inside the bundled Telegram plugin for eligible grouped media while preserving the current sequential fallback, durable delivery semantics, docs, focused tests, and live Telegram proof.
