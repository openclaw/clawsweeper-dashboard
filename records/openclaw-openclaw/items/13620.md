## Summary

Keep open. Current main and the latest release still support multiple Telegram media URLs only as sequential sends, while the requested native Telegram album/sendMediaGroup behavior remains missing and an open draft fork PR is still the implementation candidate.

## What This Changes

The issue requests Telegram message-tool support for sending 2-10 related photos/videos as a native Telegram media group/album with shared caption semantics.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses sendMediaGroup for eligible 2-10 photo/video groups across direct message actions, reply delivery, and outbound payload delivery while preserving single-media and non-groupable sequential fallbacks.
