## Summary

Keep open: current main still lacks outbound Telegram album delivery via `sendMediaGroup`, and an open external draft with closing syntax needs maintainer API-shape review before this can be cleaned up.

## What This Changes

Request outbound Telegram message-tool album support so multiple photos/videos can be sent as a native Telegram media group with one shared caption.

## Best Possible Solution

Choose one Telegram message-tool API shape, preferably reusing `send` + `mediaUrls`, then implement `sendMediaGroup` for eligible 2-10 photo/video groups with sequential fallback across action, reply, and outbound delivery paths.
