## Summary

Keep open. Current main and the latest release still lack outbound Telegram sendMediaGroup album support; current mediaUrls handling sends items sequentially, and an open fork PR with closing syntax is already the implementation candidate that maintainers should review, port, or supersede.

## What This Changes

Add Telegram message-tool support for sending 2-10 media files as a grouped sendMediaGroup album with a shared caption.

## Best Possible Solution

Implement album batching in the bundled Telegram plugin for eligible mediaUrls across direct message actions, reply delivery, and outbound payload delivery, while preserving sequential fallback for single or non-groupable media and adding focused tests plus live Telegram proof.
