## Summary

Keep open. Current main and the latest release still lack native outbound Telegram album sending; existing code accepts or derives multiple media URLs but sequentializes them rather than using Telegram `sendMediaGroup`, and the linked open fork PR remains the implementation candidate for maintainer review.

## What This Changes

The issue requests Telegram media-group album support so the message tool can send multiple related photos or videos as one grouped Telegram album with a shared caption.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 photo/video groups across direct message actions, reply delivery, and outbound payload delivery while preserving existing single-media and non-groupable sequential fallbacks.
