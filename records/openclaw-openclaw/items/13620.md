## Summary

Keep open: current main still does not implement outbound Telegram album/media-group sending, and the issue has an open draft fork PR with closing syntax that should be reviewed, ported, or explicitly superseded before cleanup.

## What This Changes

The issue requests Telegram album/media-group support for outbound message tool sends so multiple related photos or videos can be sent as one Telegram media group with a shared caption.

## Best Possible Solution

Maintainers should choose the public message-tool/API shape, then land or port a Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 photo/video groups while preserving single-media, non-groupable, reply/thread, caption, button, pin, and sequential fallback behavior with focused tests and Telegram proof.
