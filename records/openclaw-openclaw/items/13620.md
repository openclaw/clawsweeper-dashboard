## Summary

Keep open: current `origin/main` and `v2026.6.11` still do not implement native outbound Telegram album delivery. The current paths normalize multiple media URLs but send them sequentially, and the open external draft with closing syntax still needs maintainer API-shape review.

## What This Changes

The issue requests native Telegram media-group album support for outbound message sends, grouping multiple photos/videos with a shared caption instead of separate Telegram messages.

## Best Possible Solution

Implement native Telegram `sendMediaGroup` delivery in the bundled Telegram plugin for eligible grouped media across existing send, reply, and outbound payload paths, with sequential fallback, docs, focused tests, and live Telegram proof.
