## Summary

Keep open: current main still lacks outbound Telegram album delivery via `sendMediaGroup`, and the remaining work needs maintainer API-shape review because an open external draft proposes a parallel message-tool action.

## What This Changes

Add outbound Telegram media-group support so multiple related media items can be sent as a Telegram album with a shared caption instead of separate messages.

## Best Possible Solution

Add album behavior inside the bundled Telegram plugin’s existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 media groups while preserving current sequential fallbacks and documenting the chosen message-tool contract.
