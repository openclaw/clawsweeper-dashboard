## Summary

Keep open: current checked-out main and the latest release still lack outbound Telegram `sendMediaGroup` album delivery, and an open external draft with closing syntax exists but needs maintainer API-shape review before it can become canonical.

## What This Changes

The issue requests Telegram outbound media group support so the message tool can send multiple photos or videos as a Telegram album with one shared caption.

## Best Possible Solution

Implement native Telegram `sendMediaGroup` delivery in the bundled Telegram plugin for eligible existing `mediaUrls` send, reply, and outbound payload paths, with sequential fallback, focused tests, docs, and live Telegram proof after the API direction is chosen.
