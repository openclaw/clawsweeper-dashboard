## Summary

Keep open. Current main and the latest release still lack native outbound Telegram album sending: the Telegram paths accept or derive multiple media URLs, but they sequentialize sends instead of calling `sendMediaGroup`, and an open fork PR with closing syntax remains the implementation candidate for maintainer review.

## What This Changes

Requests native Telegram album/media-group support in the message tool so multiple photos or videos can be sent as one album with a shared caption.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 media groups across direct message actions, reply delivery, and outbound payload delivery while preserving single-media and non-groupable sequential fallbacks.
