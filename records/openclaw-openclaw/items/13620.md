## Summary

Keep open: current main and the latest release still do not implement outbound Telegram sendMediaGroup album sending, and an open draft fork PR with closing syntax is already the implementation candidate to review, port, or supersede.

## What This Changes

The issue requests Telegram album/media-group support for outbound message sends so multiple related photos or videos can be sent with Telegram sendMediaGroup rather than as separate messages.

## Best Possible Solution

Implement native Telegram album sending inside the bundled Telegram plugin for eligible 2-10 groupable media across message actions, reply delivery, and outbound payload delivery, while preserving the existing sequential fallback and documenting the supported action/payload shape.
