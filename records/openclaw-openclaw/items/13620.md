## Summary

Keep open: current `origin/main` still has no outbound Telegram `sendMediaGroup` album path; it preserves multiple `mediaUrls` and sends them one at a time, while the open cross-repository draft that closes this issue still needs maintainer API-shape review.

## What This Changes

Request support for Telegram media groups/albums in the message tool so multiple photos or videos can be sent with shared album-style caption behavior.

## Best Possible Solution

Add album behavior in the bundled Telegram plugin’s existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks, documenting the chosen message-tool API, and proving it with focused tests plus live Telegram evidence.

- **Accept Explicit Album Action:** Sponsor a separate `send-media-group` action only if maintainers want album sending to be opt-in and separately documented from normal sends.
- **Defer API Shape:** Keep the issue open and ask the draft PR author to pause until maintainers choose the permanent message-tool contract.

## Solution Assessment
