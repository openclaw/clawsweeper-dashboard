## Summary

Keep open: current main and v2026.6.11 still fan Telegram multi-media sends out as separate single-media messages rather than using Telegram album delivery, and the live closing reference is an open cross-repository draft that needs maintainer API-shape review before this tracker can close.

## What This Changes

Add Telegram media group/album support to the message tool so 2-10 related photos/videos can be sent as one `sendMediaGroup` album with a shared caption.

## Best Possible Solution

Keep this as the canonical outbound Telegram album tracker and have maintainers review, port, or supersede the linked draft with a current-main Telegram plugin design covering message actions, reply delivery, outbound payload delivery, tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes. Source inspection shows current main gathers multiple media URLs but routes them through sequential single-media sends rather than Telegram album delivery; I did not run live Telegram transport in this read-only review.

## Solution Assessment

Unclear. `sendMediaGroup` support belongs in the Telegram plugin, but maintainers still need to choose the public action/parameter shape and whether to port the existing draft or replace it.
