## Summary

Keep open: current main and the latest release support sequential multi-media Telegram delivery, but they still do not implement Telegram album/sendMediaGroup behavior, and the linked draft fork PR needs maintainer API/product review rather than a separate cleanup close.

## What This Changes

Request to add Telegram media-group/album sending to the message tool, using Telegram sendMediaGroup for multiple related photos/videos with one caption.

## Best Possible Solution

Review the linked draft implementation and either port or replace it with a current-main Telegram plugin implementation that uses sendMediaGroup for eligible 2-10 album media while preserving existing sequential fallback behavior and focused Telegram tests/docs.
