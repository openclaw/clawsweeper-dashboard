## Summary

Keep open: current main and the latest release still lack outbound Telegram album delivery via `sendMediaGroup`, and the open linked draft with closing syntax needs maintainer API-shape review before this issue can resolve.

## What This Changes

The issue requests Telegram outbound media-group or album support so the message tool can send 2-10 related photo/video files as one Telegram album with a shared caption.

## Best Possible Solution

Land or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 media sets across message actions, reply delivery, and outbound payload delivery, while preserving sequential fallbacks and adding Telegram docs plus live proof.
