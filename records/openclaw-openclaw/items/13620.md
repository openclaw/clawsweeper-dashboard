## Summary

Keep open: current main supports sequential multi-media URL delivery, but it still does not implement Telegram album/sendMediaGroup behavior, and an open draft fork PR remains a candidate that needs maintainer product/API review.

## What This Changes

Add outbound Telegram media-group/album support to the message tool so related media items can be sent as a grouped Telegram album with a shared caption.

## Best Possible Solution

Implement or port album support in the bundled Telegram plugin by using sendMediaGroup for eligible 2-10 groupable media sets while preserving current sequential fallback, reply/thread handling, button follow-ups, focused tests, docs, and live Telegram proof.
