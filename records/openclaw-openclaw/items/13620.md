## Summary

Keep open: current main still does not implement outbound Telegram album delivery via `sendMediaGroup`, and the open external draft with closing syntax needs maintainer API-shape review before this should be closed or queued independently.

## What This Changes

Add Telegram album/media-group support to the message tool so multiple related media items can be sent as one native Telegram album with a shared caption.

## Best Possible Solution

Choose one Telegram message-tool API shape, preferably reusing the existing `send` action with `mediaUrls`, then group eligible 2-10 photo/video sends through `sendMediaGroup` while preserving sequential fallback and documenting the behavior.
