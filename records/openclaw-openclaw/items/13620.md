## Summary

Keep open: current main handles multiple Telegram media URLs as sequential sends, but it still does not implement Telegram album/media-group delivery via sendMediaGroup, and an open external draft PR is already the implementation candidate for maintainers to review, port, or supersede.

## What This Changes

The issue requests Telegram album/media-group support for the message tool so related photos or videos can be sent as one Telegram album with a shared caption.

## Best Possible Solution

Implement album support inside the bundled Telegram plugin using Telegram sendMediaGroup for eligible media groups, while preserving existing sequential single-media/non-groupable fallback behavior and documenting the supported message-tool shape.
