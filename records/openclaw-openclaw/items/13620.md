## Summary

Keep open: current main and the latest release still send Telegram media items sequentially rather than as Telegram albums, and the open draft implementation with closing syntax needs maintainer API-shape review before this tracker can resolve.

## What This Changes

Request support for Telegram media-group album sends from the message tool, using Telegram sendMediaGroup semantics for multiple media paths with a shared caption.

## Best Possible Solution

Choose the stable message-tool contract, then implement album delivery in the bundled Telegram plugin’s existing outbound send funnels with sendMediaGroup for eligible groups and current sequential fallbacks for non-groupable media.
