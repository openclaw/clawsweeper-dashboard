## Summary

Keep open: current main and the latest release still lack outbound Telegram `sendMediaGroup` album delivery, while an open external PR with closing syntax remains the implementation candidate for maintainer review or porting.

## What This Changes

Request to add Telegram album/media-group support to the message tool so multiple photos/videos can be sent as one grouped Telegram album with a shared caption.

## Best Possible Solution

Review the open external implementation and either port or replace it with a current-main Telegram plugin change that uses grammY `sendMediaGroup` for eligible 2-10 media groups across message actions and outbound/reply delivery, while preserving sequential fallbacks and adding focused tests, docs, and live Telegram proof.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should outbound Telegram album support be implemented by porting the open external `send-media-group`/`filePaths` action, by extending the existing `mediaUrls` send path to group eligible media automatically, or by keeping sequential sends as the supported behavior for now?

Rationale: The missing capability is source-backed, but the public tool/action shape and fallback semantics affect Telegram UX, message-tool API expectations, and the existing durable send path, so automation should not choose the permanent product contract alone.

Likely owner: steipete

Owner reason: steipete has the strongest combined signal from prior issue review, Telegram/plugin boundary history, and repeated central-file ownership.

Owner confidence: high

Options:

- **Port album support into existing send surfaces (recommended):** Implement `sendMediaGroup` inside the current Telegram plugin send/reply/outbound funnels using existing `mediaUrls` where possible, preserving single-media and non-groupable fallbacks.
- **Adopt a separate album action:** Review or port the external PR's explicit `send-media-group` action if maintainers want album sends to be opt-in rather than automatic for multi-media sends.
- **Keep sequential sends for now:** Leave current sequential media fan-out as the supported behavior and close or narrow the album request only after a maintainer decides album grouping is out of scope.

## Reproduction Assessment

Yes, at source level: current main has multiple-media sequential fan-out but no outbound `sendMediaGroup` branch in the Telegram action, reply, send-helper, outbound adapter, or docs paths. A live Telegram run was not needed to confirm the requested album capability is still missing.

## Solution Assessment

Unclear until maintainers choose the public action/API shape. The best technical direction is to use grammY's native `sendMediaGroup` primitive inside the Telegram plugin funnels, but whether this is automatic for `mediaUrls` or an explicit album action is a product decision.
