## Summary

Keep open: current main and the latest release still lack outbound Telegram album delivery via sendMediaGroup, and an open draft implementation with closing syntax should be reviewed, ported, or explicitly superseded rather than closing this tracker.

## What This Changes

The issue requests Telegram outbound album/media-group support in the message tool so multiple related photos/videos can be sent as a grouped Telegram album with a shared caption.

## Best Possible Solution

Keep the existing sequential single-media behavior as the fallback and add Telegram sendMediaGroup support for eligible 2-10 outbound photo/video groups inside the bundled Telegram plugin, with the user-facing message-tool API shape explicitly chosen by maintainers.
