## Summary

Keep open: current main still lacks outbound Telegram album delivery via sendMediaGroup, and the linked cross-repository draft with closing syntax needs maintainer API-shape review before this tracker can be resolved.

## What This Changes

The issue requests Telegram message-tool support for sending 2-10 related media items as one album/media group with a shared caption.

## Best Possible Solution

Implement the feature in the bundled Telegram plugin on current main, using Telegram sendMediaGroup for eligible grouped photo/video sends across message actions, reply delivery, and outbound payload delivery while preserving existing single-media fallbacks, docs, focused tests, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main can carry multiple mediaUrls but routes them through sequential single-media sends rather than Telegram album delivery; I did not run a live Telegram transport reproduction in this read-only review.
