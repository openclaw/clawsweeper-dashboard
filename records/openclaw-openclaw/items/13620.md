Keep open. Current main and the latest release still lack native outbound Telegram `sendMediaGroup` album sending, and an open draft fork PR with closing syntax remains the implementation candidate for maintainer review.

## What This Changes

Request native Telegram media-group/album support for message-tool sends so 2-10 related photos or videos can be sent as one album with shared caption semantics.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 photo/video groups across direct message actions, reply delivery, and outbound payload delivery while preserving existing single-media and non-groupable sequential fallbacks.
