## Summary

Keep open: current main and the latest release still send Telegram multi-media payloads sequentially and do not call `sendMediaGroup`; the linked fork draft with closing syntax remains an implementation candidate but needs maintainer API-shape review.

## What This Changes

Request support for Telegram native media-group albums from the message tool so multiple related media items can be sent as one grouped album with a shared caption.

## Best Possible Solution

Implement native `sendMediaGroup` delivery in the bundled Telegram plugin for eligible existing `mediaUrls` send, reply, and outbound payload paths, with sequential fallback plus focused tests, docs, and live Telegram proof.
