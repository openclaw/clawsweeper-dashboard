## Summary

Keep open: current main still does not implement outbound Telegram album delivery via `sendMediaGroup`; it preserves multiple media URLs and sends them one at a time, while an open external closing PR still needs maintainer API-shape review.

## What This Changes

Request support for Telegram media groups/albums so the message tool can send 2-10 related photos or videos as one grouped album with a shared caption.

## Best Possible Solution

Add album behavior inside the bundled Telegram plugin's existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 photo/video groups while preserving current sequential fallbacks, documenting the chosen message-tool API, and proving it with focused tests plus live Telegram evidence.

## Reproduction Assessment

Yes, source inspection is enough to reproduce the current limitation: multi-media Telegram payloads are preserved as `mediaUrls`, but the outbound paths iterate and send one media item per Telegram API call. I did not run live Telegram proof because the remaining question is feature/API shape, not an unreproduced crash or regression.

## Solution Assessment

No, the currently linked draft is only a plausible implementation direction because it adds a new action and `filePaths` surface beside existing `sendMessage`/`mediaUrls`. The best fix should first choose the stable message-tool contract, then implement albums consistently across the action, durable outbound, and reply delivery funnels.
