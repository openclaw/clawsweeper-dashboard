## Summary

Keep open: current main and the latest release still lack outbound Telegram album delivery via `sendMediaGroup`, and the open cross-repository draft with closing syntax needs maintainer API-shape review before this tracker can be resolved.

## What This Changes

Request support for Telegram message-tool media groups so 2-10 media items can be sent as one album with a shared caption.

## Best Possible Solution

Land or port a current-main Telegram plugin implementation that uses Telegram/grammY `sendMediaGroup` for eligible media sets across message actions, reply delivery, and outbound payload delivery, while preserving sequential fallbacks and adding live Telegram proof.
