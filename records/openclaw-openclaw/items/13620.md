## Summary

Keep open: current main and the latest release still lack outbound Telegram sendMediaGroup album delivery, while an open draft external PR with closing syntax is already the implementation candidate for maintainer review.

## What This Changes

The issue requests Telegram album/media-group support in the message tool so multiple photos or videos can be sent together with a shared caption.

## Best Possible Solution

Land or port a maintainer-approved Telegram plugin implementation that uses sendMediaGroup for eligible 2-10 item albums while preserving current single-media, sequential mediaUrls, non-groupable fallback, durability, and docs behavior.
