## Summary

Keep open. Current `main` and the latest release still send Telegram multi-media payloads as sequential media messages rather than a native Telegram album, and an open draft fork PR is already the linked implementation candidate for maintainers to review, port, or reject.

## What This Changes

This issue requests Telegram message-tool media groups/albums so multiple photos or videos can be sent as one Telegram album with a shared caption.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible multi-photo/video sends across direct message actions, reply delivery, and outbound payload delivery, while preserving existing single-media and non-groupable fallbacks.
