## Summary

Keep open: current main now preserves and sequentially sends multiple Telegram media URLs, but it still has no outbound Telegram album/sendMediaGroup path, and the open linked draft fork PR is an implementation candidate that needs maintainer API/product review rather than automatic cleanup.

## What This Changes

Request Telegram message-tool/media delivery support for sending multiple photos/videos as a grouped album via Telegram sendMediaGroup instead of only sequential media sends.

## Best Possible Solution

Implement or port Telegram album support inside the bundled Telegram plugin by using sendMediaGroup for eligible grouped media while preserving current sequential fallback, reply/thread behavior, button follow-ups, tests, docs, and live Telegram proof.
