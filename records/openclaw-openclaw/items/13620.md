## Summary

Keep open: current main and v2026.6.11 still lack outbound Telegram `sendMediaGroup` album delivery. The current code accepts multiple media URLs but sends them sequentially, and an open external draft with closing syntax still needs maintainer API/product review before this issue can close.

## What This Changes

Request outbound Telegram album/media-group support for the message tool so 2-10 related photos/videos can be sent via Telegram `sendMediaGroup` with a shared caption.

## Best Possible Solution

Keep this as the canonical outbound Telegram album tracker while maintainers review, port, or replace the open draft with a current-main Telegram plugin implementation covering message actions, reply delivery, outbound payload delivery, focused tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 collect multiple media URLs but route them through sequential single-media sends, and no outbound `sendMediaGroup` branch exists in the Telegram source or docs.

## Solution Assessment

Unclear. `sendMediaGroup` support belongs in the Telegram plugin, but maintainers still need to choose the public action/parameter shape and decide whether to port the open draft or replace it.
