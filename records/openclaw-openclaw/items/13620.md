## Summary

Keep open: current main still lacks outbound Telegram album/sendMediaGroup support. Existing mediaUrls support now sends multiple attachments sequentially, and a linked draft fork PR remains an implementation candidate that needs maintainer product/API review before this issue can close.

## What This Changes

Request Telegram message sending to support media groups/albums with a shared caption instead of separate media sends.

## Best Possible Solution

Implement or port album support in the bundled Telegram plugin using sendMediaGroup for eligible 2-10 media groups, while preserving existing sequential fallback, reply/thread handling, buttons follow-up behavior, focused tests, docs, and live Telegram proof.
