## Summary

Keep open: current main and v2026.6.11 still lack native outbound Telegram album delivery, and the open external draft with closing syntax is an implementation candidate rather than a reason to close this issue before maintainer API-shape review.

## What This Changes

Request to add Telegram outbound media-group album support to the message tool so multiple photos or videos can be sent as one Telegram album with a shared caption.

## Best Possible Solution

Implement native Telegram `sendMediaGroup` delivery in the bundled Telegram plugin for eligible existing multi-media payloads, with sequential fallback plus focused tests, docs, and live Telegram proof.
