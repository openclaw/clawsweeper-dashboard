## Summary

Keep open: current main and the latest release still lack outbound Telegram sendMediaGroup album support. The current mediaUrls work preserves multiple media items, but Telegram still delivers them as sequential sends, and an open draft fork PR remains an implementation candidate that needs maintainer product/API review before this issue can close.

## What This Changes

The issue requests Telegram media-group/album support for outbound message-tool sends with multiple media paths and a shared caption.

## Best Possible Solution

Implement or port album support in the bundled Telegram plugin so eligible 2-10 media groups use sendMediaGroup, while preserving the current sequential fallback, reply/thread handling, buttons follow-up behavior, tests, docs, and live Telegram proof.
