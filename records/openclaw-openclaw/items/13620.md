## Summary

Keep open. Current main and the latest release still do not implement native outbound Telegram album sending; the Telegram paths accept multiple media URLs but sequentialize them, and an open linked fork PR remains the implementation candidate for maintainer review.

## What This Changes

Request support for sending Telegram media groups/albums from the message tool via Telegram `sendMediaGroup`.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 photo/video groups across message actions, reply delivery, and outbound payload delivery while preserving existing single-media and non-groupable fallbacks.
