## Summary

Keep open: current main and v2026.6.11 still lack outbound Telegram album delivery via `sendMediaGroup`; current paths collect multiple media URLs but send them as sequential single-media messages, and the open implementation candidate is a stale draft that needs maintainer API/product review.

## What This Changes

Add Telegram album/media-group sending to the message tool so related photos/videos can be delivered as one grouped Telegram album with a shared caption.

## Best Possible Solution

Keep this issue as the canonical outbound Telegram album tracker while maintainers port or replace the draft with a current-main Telegram plugin implementation covering actions, reply delivery, outbound payload delivery, docs, focused tests, and live Telegram proof.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 collect media URL arrays but route them through sequential single-media sends, and no outbound `sendMediaGroup` branch exists in Telegram source or docs.

## Solution Assessment

Unclear until maintainers choose the public API shape; the Telegram plugin is the right owner, but the open draft's `send-media-group`/`filePaths` approach differs from this issue's proposed `mediaGroup`/`album` parameter and current `mediaUrls` contracts.
