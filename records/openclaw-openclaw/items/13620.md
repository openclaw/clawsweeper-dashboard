## Summary

Keep open: current main and v2026.6.11 still lack outbound Telegram sendMediaGroup album sending, and an open cross-repository draft with closing syntax needs maintainer review or porting before cleanup closure.

## What This Changes

Add Telegram album/media-group sending to the message tool and outbound Telegram delivery so multiple eligible media files can be sent as one native album with a shared caption.

## Best Possible Solution

Keep this issue as the canonical outbound Telegram album tracker while maintainers review, port, or supersede the open draft with a Telegram-plugin implementation covering action sends, reply delivery, outbound payload delivery, focused tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 have no outbound sendMediaGroup path, and the action, reply, and outbound adapter funnels route multiple media URLs through sequential single-media sends.

## Solution Assessment

Unclear for the exact API shape. The Telegram plugin is the right boundary, but maintainers still need to choose between extending existing mediaUrls behavior, adding an explicit album/mediaGroup parameter, or porting the open draft's dedicated action.
