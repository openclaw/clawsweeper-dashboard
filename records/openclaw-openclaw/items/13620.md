## Summary

Keep open: current main and v2026.6.11 still do not implement native outbound Telegram album delivery. The existing code preserves multiple `mediaUrls` but sends them sequentially, while the open external draft with closing syntax still needs a maintainer API-shape decision.

## What This Changes

The issue requests Telegram media-group/album support in the message tool so multiple photos or videos can be sent as one album with a shared caption.

## Best Possible Solution

Implement native Telegram `sendMediaGroup` delivery in the bundled Telegram plugin for eligible 2-10 groupable media across existing `mediaUrls` send, reply, and outbound payload paths, with sequential fallback plus focused tests, docs, and live Telegram proof.
