## Summary

Keep open: current main and the latest release still lack outbound Telegram `sendMediaGroup` album sending, while an open cross-repository draft with closing syntax already exists and needs maintainer API-shape/product review before a new repair lane is useful.

## What This Changes

The issue requests Telegram album/media-group support in the message tool so multiple related media items can be sent as one grouped album with a shared caption.

## Best Possible Solution

Settle the Telegram message-action API shape, then implement album support inside the bundled Telegram plugin using the existing durable outbound paths with focused tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main gathers multiple Telegram media URLs but routes them through sequential single-media sends, and exact source search finds no outbound `sendMediaGroup` implementation; I did not run a live Telegram transport test in this read-only review.

## Solution Assessment

Unclear until maintainers choose the product/API contract. `sendMediaGroup` support belongs in the Telegram plugin, but the best implementation shape needs a maintainer decision on action naming, parameters, fallbacks, and whether to port or replace the open draft.
