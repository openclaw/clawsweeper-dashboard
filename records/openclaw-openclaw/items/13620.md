## Summary

Keep open: current main and the latest release still do not implement outbound Telegram album sending via sendMediaGroup; they only preserve/fan out multiple media URLs as sequential sends, and there is still an open draft external implementation candidate that maintainers should review, port, or supersede.

## What This Changes

The issue requests outbound Telegram album/media-group support for the message tool so multiple photos or videos can be sent via Telegram sendMediaGroup with a shared caption.

## Best Possible Solution

Add native sendMediaGroup support in the bundled Telegram plugin for eligible 2-10 photo/video groups across message actions, reply delivery, and outbound payload delivery, with sequential fallback for non-groupable media and live Telegram proof.
