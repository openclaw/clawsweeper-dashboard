## Summary

Keep open. Current main and the latest release still do not implement native outbound Telegram album sending; the code can carry multiple media URLs, but it sends them sequentially rather than via `sendMediaGroup`, and the linked open fork PR remains the implementation candidate for maintainer review.

## What This Changes

The issue requests Telegram `message` tool support for sending multiple media files as a grouped album via Telegram `sendMediaGroup`.

## Best Possible Solution

Adopt or port a current-main Telegram plugin implementation that uses `sendMediaGroup` for eligible 2-10 media groups across direct message actions, reply delivery, and outbound payload delivery while preserving existing single-media and non-groupable fallbacks.
