## Summary

The issue should stay open: current main preserves multiple media URLs and sends them sequentially, but the requested Telegram album/sendMediaGroup behavior is still absent, and a draft fork PR remains the linked implementation candidate that requires maintainer API/product review.

## What This Changes

Request to add Telegram media-group/album support to the message tool so 2-10 related photos/videos can be sent through Telegram as a grouped album with one caption.

## Best Possible Solution

Implement or port album support in the bundled Telegram plugin at the Telegram-owned send boundary, using sendMediaGroup for eligible 2-10 media groups while preserving existing sequential fallback, reply/thread handling, button follow-up behavior, focused tests, docs, and live Telegram proof.
