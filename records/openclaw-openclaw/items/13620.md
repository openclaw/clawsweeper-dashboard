## Summary

Keep open: current main still does not implement outbound Telegram album delivery via `sendMediaGroup`; multiple media URLs are preserved but sent one at a time, and the linked open cross-repo draft needs maintainer API-shape review before this tracker can resolve.

## What This Changes

Request Telegram message-tool support for sending 2-10 related media items as a single Telegram album/media group with a shared caption.

## Best Possible Solution

Implement album behavior inside the bundled Telegram plugin's existing outbound send pipeline, using `sendMediaGroup` for eligible 2-10 media groups while preserving sequential fallbacks, documenting the chosen message-tool contract, and proving it with focused tests plus live Telegram evidence.
