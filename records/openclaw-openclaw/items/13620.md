## Summary

Keep open: current main and the latest release still support multi-media fan-out, but not native Telegram album delivery via `sendMediaGroup`. The remaining work is a maintainer API-shape decision, especially because an open fork PR already claims this issue with closing syntax while same-repo attempts are closed unmerged.

## What This Changes

The issue requests Telegram outbound album/media-group support for the message tool so multiple photos or videos can be sent as one grouped album with a shared caption.

## Best Possible Solution

Implement native Telegram album grouping inside the bundled Telegram plugin for eligible multi-media sends, preferably integrated with the existing `mediaUrls` message/reply/outbound paths and falling back to the current sequential delivery behavior when albums are not valid or not supported.

Yes. Source inspection gives a high-confidence reproduction path: pass multiple media URLs through Telegram `message.send` or reply delivery and current main plans/sends them as separate media messages, with no `sendMediaGroup` source path.
