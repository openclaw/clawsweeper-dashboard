- `impact:ux-friction`: Without album support, multi-media Telegram sends are delivered as separate messages or require awkward workarounds rather than the grouped user experience Telegram users expect.

## Summary

Keep open: current main and the latest release still do not implement outbound Telegram `sendMediaGroup` album delivery, and an open cross-repository draft with closing syntax already exists but needs maintainer API-shape review before this issue can be resolved.

## What This Changes

The issue requests Telegram album/media-group support for the message tool so 2-10 related photos or videos can be sent as one grouped album with a shared caption.

## Best Possible Solution

Keep this as the canonical outbound Telegram album tracker while maintainers review, port, or supersede the open draft with a current-main Telegram plugin implementation covering direct message actions, reply delivery, outbound payload delivery, focused tests, docs, and live Telegram proof.

## Reproduction Assessment

Yes, at source level. Current main accepts or resolves multiple media URLs in some paths, but the Telegram send surfaces still route them through sequential single-media sends and never call `sendMediaGroup`; I did not run a live Telegram transport reproduction in this read-only review.

## Solution Assessment

Unclear. `sendMediaGroup` support belongs in the Telegram plugin, but maintainers still need to choose the public action/parameter shape and decide whether to port the open draft or replace it.
