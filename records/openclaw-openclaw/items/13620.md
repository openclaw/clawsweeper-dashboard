## Summary

Keep open: current main and the latest release still lack native outbound Telegram album sending. The existing multi-media paths preserve `mediaUrls` but deliver them sequentially, and an open external draft with closing syntax leaves maintainer API-shape review as the next step.

## What This Changes

Request support for Telegram media-group/album sending from the message tool so 2-10 media items can be sent as one native album with a shared caption.

## Best Possible Solution

Choose one Telegram message-tool API shape, preferably reusing existing `send` plus `mediaUrls`, then implement native `sendMediaGroup` grouping for eligible media while preserving sequential fallback and adding focused Telegram tests/docs.
