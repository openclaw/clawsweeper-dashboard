## Best Possible Solution

## Solution Assessment

Yes, this is the best narrow fix: `deliverFollowupToolSummary` is the shared queued seam for embedded follow-ups and CLI tool summaries. Moving the rule into channel adapters or final warning payload construction would duplicate policy or miss this progress-delivery path.
