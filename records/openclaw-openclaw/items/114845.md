## What This Changes

This PR tracks in-flight starts per process scope so replacement launches wait for earlier starts, cancel superseded active runs, and avoid canceling processes that arrive after the replacement.

## System Context

The process supervisor starts and tracks child or PTY processes used by resumed CLI sessions and scheduled watchers. Callers can replace a scope, so the supervisor must coordinate startup and cancellation before placing the new managed run in the active registry.
