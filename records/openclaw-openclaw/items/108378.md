## Label Justifications

- `P0`: The underlying ordering defect can permanently destroy conversation transcripts during a crash or write failure in file-backed disk-budget maintenance.
- `merge-risk: 🚨 session-state`: The optional callback permits durable session metadata and transcript artifacts to become irreversibly inconsistent for an unwired mutating caller.

## Summary

Keep this PR open: the commit-before-delete direction and real filesystem proof are strong, but the new commit callback remains optional, so a valid mutating caller can still delete an evicted transcript without first committing the reduced durable index.

## What This Changes

The PR defers deletion of disk-budget-evicted session artifacts until the reduced file-backed session index has been atomically persisted.

## Best Possible Solution

Make every mutating disk-budget eviction establish a durable commit boundary before unlinking; if no callback is available, retain the artifacts or fail before deletion, and cover that path with a regression test.
