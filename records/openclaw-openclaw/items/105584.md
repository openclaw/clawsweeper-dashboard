## Summary

Keep this PR open: the linked P0 credential-egress issue is valid and the submitted proof is strong, but the patch redirects credentials with unsupported recorded origins to public GitHub rather than refusing to transmit them, so it needs a security-boundary correction before merge.

## What This Changes

The PR extracts the GitHub Copilot domain allowlist into a shared SDK leaf, applies it to OAuth and model endpoint construction, and normalizes legacy doctor-migrated enterprise domains.

## Best Possible Solution

Use separate policies for pre-auth configuration and credential-bearing runtime paths: strictly validate persisted origins, refuse unsupported values without issuing a request, preserve diagnostic context, and let doctor guide the user through removing or reauthenticating the legacy profile.
