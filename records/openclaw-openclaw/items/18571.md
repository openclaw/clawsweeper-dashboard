Keep open. Current main and the latest release include the sessionKey-only slice and the newer reply_payload_sending hook, but outbound message_sending still lacks runId and a bounded same-turn tool-call/result evidence contract for deterministic verification.

Request a pre-send outbound hook context that exposes outbound text, session/run identity, and same-turn tool evidence so plugins can verify, rewrite, or block delivery.

## Best Possible Solution

Define a maintainer-approved additive plugin hook contract for outbound run identity plus redacted, bounded same-turn evidence, then wire shared delivery and direct-reply paths with docs and focused tests.
