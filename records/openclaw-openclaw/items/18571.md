## Summary

Keep open: current main has partial pre-send hook support, including outbound sessionKey and an adjacent reply_payload_sending hook with runId, but it still lacks the requested outbound runId plus bounded transcript/tool-call/result evidence contract for deterministic verification.

## What This Changes

The issue requests a pre-send outbound hook context that exposes outbound content, route/session/run identity, and bounded tool-call evidence so a plugin can annotate or block delivery.

## Best Possible Solution

Define one additive plugin-hook contract for pre-send verification, either by extending message_sending or explicitly choosing reply_payload_sending as the supported path, with runId, redacted bounded evidence, permissions, docs, and focused tests.
