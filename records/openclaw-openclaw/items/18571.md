## Summary

Keep open: current main has partial pre-send coverage via `message_sending`, merged sessionKey plumbing, and the newer `reply_payload_sending` hook, but the requested outbound runId plus bounded same-turn transcript/tool-call/result evidence contract is still missing and needs maintainer product/security direction.

## What This Changes

The issue requests a pre-send outbound hook with session/run identity and verification context so plugins can inspect, annotate, or block unsupported agent claims before delivery.

## Best Possible Solution

Define a maintainer-approved additive hook contract for outbound run identity plus redacted, bounded same-turn verification evidence, then wire the shared outbound and direct-reply paths with docs and focused regression tests.

## Solution Assessment

Unclear until product/security review. Adding run identity is plausible, but the best fix for transcript/tool-call evidence needs a bounded, redacted, permission-aware plugin SDK contract rather than an ad hoc metadata dump.
