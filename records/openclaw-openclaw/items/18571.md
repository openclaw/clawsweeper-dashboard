## Summary

Keep open: current main and the latest stable release have partial pre-send hook support, but still lack outbound run identity plus bounded transcript/tool-call/result evidence for deterministic verification.

## What This Changes

The issue requests a pre-send outbound hook context that exposes outbound text, session/run identity, and bounded tool/result evidence so plugins can annotate or block unverified claims before delivery.

## Best Possible Solution

Define one additive, permissioned plugin-hook contract for deterministic pre-send verification, either by extending message_sending or making reply_payload_sending the supported surface, with run/session identity, bounded redacted evidence, docs, and regression tests.
