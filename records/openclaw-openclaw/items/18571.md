## Summary

Keep open. Current main has the pre-send `message_sending` hook and the merged sessionKey slice, but the requested runId plus bounded tool-call/result evidence contract for deterministic outbound verification is still missing.

## What This Changes

The issue requests a pre-send outbound hook context that exposes outbound text, destination, session/run identity, and recent tool-call/result evidence so plugins can annotate or block unverifiable messages.

## Best Possible Solution

Define a maintainer-approved additive `message_sending` contract that carries runId when available plus a redacted, bounded same-turn evidence view, then wire shared outbound delivery and direct-reply paths with docs and focused tests.

## Reproduction Assessment

Yes. Source inspection shows current `message_sending` can rewrite/cancel but shared outbound delivery still does not pass runId or bounded same-turn tool-call/result evidence.

## Solution Assessment
