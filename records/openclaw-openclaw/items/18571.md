## Summary

Keep open: current main has the sessionKey subset and an adjacent reply-payload hook, but the requested outbound runId plus bounded transcript/tool-call/result evidence contract is still missing.

## What This Changes

The issue requests a pre-send outbound hook that can inspect outbound text, correlate it to session/run identity, access bounded tool-call evidence, and block or annotate delivery before users see unsupported claims.

## Best Possible Solution

Define one additive plugin-hook contract for deterministic pre-send verification, with explicit run/session identity, bounded recent evidence fields, redaction/permission rules, docs, and regression coverage across shared outbound delivery and reply paths.
