- `impact:session-state`: The requested hook context is about correlating outbound messages with session/run state and tool history.

## Summary

Keep open: current main has partial pre-send hook support, but the central request remains missing because outbound `message_sending` still has no outbound `runId` and no bounded transcript/tool-call/result evidence contract for deterministic verification.

## What This Changes

Requests a pre-send outbound plugin hook/evidence contract that exposes outbound text, session/run identity, and bounded tool/transcript evidence so plugins can annotate or block delivery deterministically.

## Best Possible Solution

Define one additive Plugin SDK contract for pre-send verification that either extends `message_sending` or names `reply_payload_sending` as the supported path, with explicit run/session identity and bounded redacted evidence across shared outbound delivery and direct reply paths.
