## Summary

Keep open: current main has partial pre-send hook support, but it still lacks the requested outbound run identity plus bounded transcript/tool-call/result evidence contract for deterministic verification.

## What This Changes

The issue requests a pre-send outbound hook/context contract that can inspect outbound text plus session/run/tool evidence and block or annotate delivery.

## Best Possible Solution

Define one additive plugin-hook contract for pre-send verification that either extends `message_sending` or names `reply_payload_sending` as the supported path, with explicit run/session identity and bounded recent evidence fields across shared outbound delivery and reply paths.
