## Summary

Keep open: current main still only partially implements the request. Outbound hooks can now rewrite/cancel and carry `sessionKey` in some paths, and `reply_payload_sending` carries `runId` plus usage state, but no outbound pre-send hook exposes outbound `runId` together with bounded same-turn transcript/tool-call/result evidence for deterministic verification.

## What This Changes

Request an outbound pre-send hook/context that exposes session/run identity and bounded verification evidence so plugins can annotate or block unsupported outbound claims before delivery.

## Best Possible Solution

Define a maintainer-approved additive plugin hook contract for outbound run identity plus redacted, bounded same-turn verification evidence, then wire shared outbound/direct reply paths with docs and focused tests.
