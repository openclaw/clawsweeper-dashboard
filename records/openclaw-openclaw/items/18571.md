## Summary

Keep open: current main provides a cancellable `message_sending` hook and has shipped partial session-key plumbing, but it still lacks the requested outbound run identity and bounded transcript/tool-call/result evidence needed for deterministic pre-send claim verification.

## What This Changes

Expose outbound pre-send hook context with session/run identity and bounded recent tool/transcript evidence so plugins can verify or block claims before delivery.

## Best Possible Solution

Define one additive Plugin SDK contract for pre-send verification, including privacy/redaction/size/trust boundaries, then thread run/session identity and bounded evidence consistently across shared outbound delivery and direct reply paths.
