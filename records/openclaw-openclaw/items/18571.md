## Summary

Keep open: current main has `message_sending` cancellation, outbound `sessionKey` plumbing, and the adjacent `reply_payload_sending` hook, but it still lacks outbound `runId` plus bounded transcript/tool-call/result evidence for deterministic pre-send verification.

## What This Changes

Expose enough outbound pre-send plugin-hook context for verification plugins to inspect outbound text, run/session identity, and bounded tool-result evidence before allowing, annotating, or blocking delivery.

## Best Possible Solution

Define one additive plugin-hook contract for deterministic pre-send verification, with explicit run/session identity, bounded recent evidence fields, redaction and permission rules, docs, and regression coverage across shared outbound delivery and reply paths.
