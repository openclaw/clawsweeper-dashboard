## Summary

Keep open: current main and v2026.6.11 have the sessionKey subset and an adjacent reply-payload hook, but the requested outbound runId plus bounded transcript/tool-call/result evidence contract is still missing and needs maintainer API/security direction.

## What This Changes

The issue requests a pre-send outbound message hook/context that exposes outbound text, routing, run/session identity, and bounded session tool-call evidence so plugins can deterministically verify, annotate, or block messages before delivery.

## Best Possible Solution

Define one additive plugin-hook contract for deterministic pre-send verification, with explicit run/session identity, bounded recent evidence fields, redaction/permission rules, docs, and regression coverage across shared outbound delivery and reply paths.
