## Summary

Keep open: current main still lacks the requested outbound pre-send run identity plus bounded transcript/tool-call/result evidence contract; existing hooks only cover sessionKey, payload mutation, and usage metadata in separate partial surfaces.

## What This Changes

Request to expose outbound pre-send hook context with session/run identity and session tool/result evidence so plugins can deterministically verify, annotate, or block messages before delivery.

## Best Possible Solution

Define a maintainer-approved additive hook contract for outbound run identity plus capped, redacted same-turn verification evidence, then wire shared outbound and direct-reply paths with docs and focused regression tests.
