## Summary

Keep open: current main and v2026.6.11 only cover the sessionKey subset, while the requested outbound run identity plus bounded transcript/tool-call/result evidence contract for deterministic pre-send verification remains missing and needs maintainer product/security direction.

## What This Changes

The issue requests a pre-delivery outbound hook context that exposes outbound text, session/run identity, recent tool evidence, and cancellation support for deterministic verification before users see a message.

## Best Possible Solution

Define one additive Plugin SDK contract for pre-send verification that specifies redacted run/session identity and bounded recent evidence fields, then implement it consistently across shared outbound delivery and reply paths with docs and regression tests.
