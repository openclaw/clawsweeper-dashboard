## Summary

Keep open: current main has useful partial work, but the central request remains missing because outbound `message_sending` still lacks `runId` and any bounded transcript/tool-call/result evidence for deterministic pre-send verification.

## What This Changes

The issue requests a pre-send outbound hook context with session/run identity, outbound message details, and same-turn verification evidence so plugins can annotate or block delivery.

## Best Possible Solution

Define a maintainer-approved additive hook contract for outbound run identity plus capped, redacted same-turn verification evidence, then wire shared outbound and direct-reply paths with docs, API baseline updates, and focused regression tests.
