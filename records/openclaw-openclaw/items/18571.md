## Summary

Keep open: current main and the latest release have partial pre-send hook support, but the requested outbound run identity plus bounded transcript/tool-call/result evidence contract for deterministic verification is still missing and needs maintainer API/security direction.

## What This Changes

The issue requests a pre-send outbound message hook contract that exposes outbound text, routing, session identity, run identity, and bounded tool/transcript evidence so plugins can deterministically verify or block a message before delivery.

## Best Possible Solution

Define one additive, bounded pre-send plugin-hook evidence contract with explicit run/session identity, redaction/size limits, cancellation semantics, docs, API-baseline updates, and regression tests across shared outbound delivery and reply paths.
