## Summary

Keep open: current main has partial hook support, but the requested outbound `message_sending` run identity plus bounded transcript/tool-call evidence contract is still missing and needs maintainer product/security direction.

## What This Changes

The issue requests outbound pre-send hook context that exposes session/run identity and bounded verification evidence so plugins can deterministically inspect or block messages before delivery.

## Best Possible Solution

Define one additive plugin-hook contract for pre-send verification that either extends `message_sending` or names `reply_payload_sending` as the supported path, with explicit run/session identity and bounded recent evidence fields across shared outbound delivery and reply paths.
