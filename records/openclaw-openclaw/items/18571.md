## Summary

Keep open: current main still exposes only partial outbound hook correlation. `message_sending` can rewrite or cancel and now receives `sessionKey`, but it still lacks outbound `runId` and any bounded transcript/tool-call/result evidence needed for deterministic pre-send verification.

## What This Changes

Request an additive outbound pre-send plugin hook contract that exposes outbound text, session/run identity, bounded verification evidence, and cancellation or annotation before delivery.

## Best Possible Solution

Define a maintainer-approved additive hook contract for outbound run identity plus capped, redacted same-turn verification evidence, then wire shared outbound and direct-reply paths with docs, API baseline updates, and focused regression tests.
