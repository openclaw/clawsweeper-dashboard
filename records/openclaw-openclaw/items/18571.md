## Summary

Keep open: current main implements the text rewrite/cancel hook and part of the sessionKey/runId adjacency, but it still does not expose outbound runId plus bounded transcript/tool-call/result evidence for deterministic pre-send verification.

## What This Changes

Request to expose outbound pre-send message context with session/run identity and tool-call/result evidence so a plugin can annotate, block, or retry unsupported claims before delivery.

## Best Possible Solution

Define one additive, permission-aware plugin-hook contract for deterministic pre-send verification, with explicit run/session identity, bounded recent evidence fields, redaction rules, docs, and regression coverage across shared outbound delivery and reply paths.
