## Summary

Keep open: current main still has no settled capability-aware guardrail for configured model inputs. The config schema and exported type accept audio/video and a current regression test preserves those values, while docs and registry/runtime paths still reflect narrower text/image behavior.

## What This Changes

The issue requests schema, CI, tests, and docs guardrails for unsupported model input modalities in configured provider model definitions.

## Best Possible Solution

Define one canonical configured-model input capability authority, then align schema, exported types, registry validation, media routing, tests, docs, and any needed doctor migration around that contract.
