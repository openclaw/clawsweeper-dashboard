## Best Possible Solution

Define one canonical configured-model input contract, then align Zod schema, exported types, TypeBox registry validation, catalog normalization, runtime selection diagnostics, tests, docs, and any needed doctor migration around that decision.

## Solution Assessment

No, not as a blanket schema-only rejection. The best fix requires a maintainer decision on whether audio/video are valid metadata, unsupported runtime capabilities, or an explicit override-gated contract.
