## Summary

Keep open: current main still has conflicting model-input contracts, with configured inputs accepting audio/video, registry validation still narrower in one generated-catalog path, docs describing text/image behavior, and runtime selection still trusting configured image capability without a capability authority.

## What This Changes

The issue requests pre-deployment guardrails, tests, and docs so unsupported `models.providers.*.models[*].input` modality declarations are rejected before deploy.

## Best Possible Solution

Define one authoritative model-input capability contract, then align schema, exported types, registry validation, configured-catalog normalization, media selection, docs, tests, and any required doctor migration or override gate around that contract.
