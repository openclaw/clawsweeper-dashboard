## Summary

Keep open: current main still lacks a single configured-model input capability contract. The schema accepts audio/video, the session registry still narrows to text/image, and image routing trusts configured metadata, so this remains real work but needs maintainer API/product direction before implementation.

## What This Changes

Request to add schema, tests, CI, and docs guardrails so unsupported configured model input modalities fail before deployment.

## Best Possible Solution

Define one canonical configured-model capability authority, then align schema, exported types, registry validation, media routing, diagnostics, regression tests, and docs around that contract without silently breaking valid custom-provider metadata.
