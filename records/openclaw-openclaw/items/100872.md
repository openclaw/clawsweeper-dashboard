## Summary

Keep open: current main still has the retained-lock teardown and watchdog behavior that can leave an alive same-process session write-lock held until the lock's hold budget expires, and the linked closing PRs are still open. This issue remains useful as the canonical report for the alive-holder abnormal-run cleanup failure.

## What This Changes

Release the session write-lock promptly after an abnormal agent run or tool-execution failure so later messages to the same session are not blocked until watchdog/manual cleanup.

## Best Possible Solution

Consolidate or review the linked session-lock PRs into one focused fix that bounds alive same-process retained-lock teardown while preserving configured maxHold/compaction windows, with regression coverage and redacted real-run recovery proof.
