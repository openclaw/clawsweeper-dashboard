## What This Changes

Request a staged model migration UX that adds a candidate as fallback, verifies it, promotes it to primary, preserves the old primary, and supports rollback.

## Best Possible Solution

Design one coherent `openclaw models` migration workflow that stages arbitrary candidate models, verifies them before promotion, preserves the old primary as fallback, persists rollback state in the canonical store, and documents/tests the config transitions alongside related probe work.
