## Summary

The report identifies a concrete Discord ingress boundary where release 2026.7.1 resolves raw `message.content` without the existing internal-context sanitizer, and no merged fix or current-main implementation provenance was found; this should remain open as a narrow bundled Discord regression.

## What This Changes

Strip OpenClaw internal runtime-context envelopes from Discord inbound visible text before debounce, preflight, and session processing, suppressing wrapper-only turns.

## Best Possible Solution

Make the Discord plugin's canonical visible-text resolver strip internal runtime-context envelopes after assembling text and resolving mentions, then add regressions for mixed text, wrapper-only text, fallback text, referenced messages, and forwarded snapshots while proving empty sanitized events stop before session dispatch.
