## What This Changes

This PR replaces substring-based Tool Search matching with BM25 lexical ranking over tool metadata and trusted first-party parameter metadata, updates the tool instructions and docs, and adds regression coverage.

## System Context

Tool Search helps an agent select a relevant tool from the effective catalog before requesting its full input schema or invoking it. The runtime turns an agent query and compact catalog metadata into ranked, bounded results that influence the agent's next tool action.
