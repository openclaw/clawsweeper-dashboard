## Summary

Keep this PR open for revision: the reported routing bug is source-reproducible and the history overlay is well-founded, but the new early return bypasses established self-chat handling and can suppress valid messages; the PR also lacks after-fix real iMessage proof.

## What This Changes

The PR overlays `sender`, `destination_caller_id`, `is_from_me`, and `service` from exact-GUID iMessage history during anchorless repair and drops repaired rows marked as outgoing.

## Best Possible Solution

Retain the authoritative exact-GUID routing-field overlay, remove the unconditional repair-layer direction drop, and let the existing self-chat-aware inbound decision reject ordinary outgoing rows while preserving supported self-chat behavior.
