## Summary

Keep open: current main still lacks trusted per-job cron or heartbeat provenance for elevated execution, and the merged cron caller-scope work only limits agent cron operations to the calling agent.

## What This Changes

Request a per-job elevated execution authority model for cron jobs and heartbeat so internal cron/heartbeat senders no longer require wildcard elevated allowlists.

## Best Possible Solution

Design one security-reviewed provenance model for scheduled and heartbeat elevated execution, with stored operator-approved authority, auditability, docs, and migration away from wildcard internal-source elevation.
