## Summary

Keep open: current main has adjacent cron caller scoping and owner attribution, but it still lacks the requested trusted elevated-exec provenance for individual cron jobs and heartbeat state.

## What This Changes

The issue requests per-job elevated-exec trust metadata for cron jobs and heartbeat so internal scheduled work no longer needs wildcard elevated access.

Define one security-reviewed provenance and approval model for scheduled and heartbeat elevated execution, then migrate users away from wildcard internal-source elevation with audit, docs, and focused tests.
