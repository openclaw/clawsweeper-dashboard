## Summary

Keep open: current main still lacks trusted per-job or heartbeat elevated-exec provenance. The merged agent cron caller-scope work narrows cross-agent cron operations, but elevated exec is still authorized by provider/sender allowlists and this needs maintainer security/product direction before implementation.

## What This Changes

The issue requests per-job and heartbeat-scoped elevated-exec authority so scheduled or heartbeat runs do not rely on wildcard internal-source allowlists.

## Best Possible Solution

Define one security-reviewed provenance model for scheduled and heartbeat elevated execution, then migrate users away from wildcard internal-source elevation with audit coverage and docs.
