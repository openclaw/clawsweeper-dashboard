## Summary

Keep open: current main still has no per-job or heartbeat-owned elevated-exec authority record; the merged cron caller-scope work only limits agent cron operations to the calling agent.

## What This Changes

Requests per-job and heartbeat provenance controls so elevated exec can be granted to operator-approved scheduled work without wildcard internal-source elevation.

## Best Possible Solution

Design one security-reviewed provenance model for scheduled and heartbeat elevated execution, with stored operator-approved authority, auditability, docs, and migration away from wildcard internal-source elevation.
