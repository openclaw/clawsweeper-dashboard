## Summary

Keep open: current main still lacks trusted per-job cron or heartbeat elevated-exec provenance, and the merged cron caller-scope work does not replace the wildcard internal-source elevated boundary.

## What This Changes

The issue requests persisted per-cron-job elevated authority and heartbeat provenance so autonomous cron and heartbeat runs do not inherit elevated exec from wildcard internal event sources.

## Best Possible Solution

Define one security-reviewed provenance model for scheduled and heartbeat elevated execution, store operator-approved authority with the relevant cron or heartbeat state, and migrate users away from wildcard internal-source elevation with audit and docs.
