## Summary

Keep open: current main still lacks a trusted per-job or heartbeat provenance boundary for elevated execution, and the related merged cron scoping work only limits agent cron calls to the calling agent.

## What This Changes

Request adds a trusted elevated-execution provenance model for cron and heartbeat runs so scheduled or autonomous turns cannot inherit wildcard internal-source elevated privileges without operator-approved state.

## Best Possible Solution

Design one security-reviewed provenance model for scheduled and heartbeat elevated execution, with stored operator-approved authority, auditability, docs, and migration away from wildcard internal-source elevation.
