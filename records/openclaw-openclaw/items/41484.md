## Summary

Keep open: current main partially scopes agent cron operations by caller, but it still lacks durable per-job elevated approval and heartbeat provenance, so the host-exec security boundary remains unresolved.

## What This Changes

## Best Possible Solution

Define one security-reviewed Gateway-stamped provenance contract that binds approved cron and heartbeat elevation to create, update, execution, audit, and migration behavior before removing internal-source wildcards.
