## Summary

Keep open: current main contains useful agent cron caller scoping and tool caps, but it still lacks the requested per-job elevated provenance and heartbeat elevated trust model.

## What This Changes

Request per-job elevated execution provenance for cron jobs and heartbeat so only owner-approved scheduled or internal runs can inherit elevated exec.

## Best Possible Solution

Define one security-reviewed provenance model for scheduled and heartbeat elevated execution, store operator-approved authority with cron jobs or heartbeat configuration, and migrate users away from wildcard internal-source elevation with audit and docs.
