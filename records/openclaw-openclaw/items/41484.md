## Summary

Keep open: current main still uses provider allowlists and wildcards for elevated decisions, with no durable cron-job or heartbeat authority record; the merged caller-scope work only covers which agent may manage a job.

## What This Changes

Requests per-job and heartbeat provenance so unattended cron and heartbeat runs can use elevated exec only when explicitly approved instead of via internal-source wildcards.

## Best Possible Solution

Define one security-reviewed provenance contract that binds approved cron and heartbeat elevation to create, update, and execution authority, then migrate away from internal-source wildcard elevation.
