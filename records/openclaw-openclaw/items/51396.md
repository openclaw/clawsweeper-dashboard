## What This Changes

The issue reports that non-local token-authenticated WebSocket operator clients lose requested operator scopes and then fail write-scoped calls such as chat.send.

## Best Possible Solution

Resolve the canonical Gateway auth issue with a maintainer-approved bounded token-scope or device-token contract, then land source, tests, docs, and real Gateway proof before closing this issue.

## Solution Assessment

No for unconditional retention of client-declared scopes. The safer solution is a bounded maintainer-approved token-scope or device-token contract rather than trusting remote device-less operator scope claims by default.
