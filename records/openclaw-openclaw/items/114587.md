## What This Changes

This PR adds an opt-in coordinator intended to send bounded progress and exactly one durable final reply for a stalled primary Telegram direct-message turn, plus dispatcher delivery-outcome tracking.

## System Context

Telegram inbound messages enter the channel dispatch turn, which asks the shared reply dispatcher to emit progress and final payloads. This change inserts a recovery lifecycle before delivery and changes how the Telegram adapter treats a recovery-owned final reply.
