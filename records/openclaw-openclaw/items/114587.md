## What This Changes

The branch adds an opt-in coordinator for stalled Telegram direct-message turns and shared reply-dispatch delivery-outcome tracking, with unit coverage for progress and terminal-reply handling.

## System Context

Telegram messages enter the Telegram extension’s dispatcher, which starts an agent turn and sends replies through the shared reply dispatcher before Telegram delivery. The proposed coordinator observes that lifecycle to send delayed progress and enforce a single durable final reply for one narrowly scoped direct-message flow.
