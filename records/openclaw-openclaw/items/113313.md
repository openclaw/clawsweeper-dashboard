## What This Changes

This PR moves Windows long-path normalization into the internal `node:sqlite` helper, applies it to backup and local snapshot verification database opens, and adds Windows-focused regression coverage and CI routing.

## System Context

Backup verification and local snapshot repositories stage or extract SQLite files, then open them with Node’s SQLite binding to validate integrity before reporting success. On Windows, the database-open boundary must convert ordinary filesystem paths to namespaced paths so SQLite’s VFS can open long staged paths while archive and repository logic stays unchanged.
