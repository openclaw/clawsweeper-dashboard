## Summary

The diagnostic is useful and the patch has strong live proof, but the current suppression rule can miss the reported failure when an unrelated pre-existing descendant is active; this needs a causal continuation rule and regression coverage before merge.

## What This Changes

Adds a shared continuation-evidence predicate, emits a user-visible diagnostic for yielded embedded-agent turns without recognized continuation evidence, and expands orchestration regression tests.

## Best Possible Solution

Define a causal continuation contract—prefer same-turn accepted work or a registry record proving a pending wake is associated with this session turn—then cover both legitimate pre-existing waits and the reported obsolete-watcher scenario.
