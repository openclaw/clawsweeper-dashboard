## Label Justifications

## Summary

Keep open: the patch appears correct and well-proven, but maintainers still need to confirm whether pre-existing controller-wide descendant activity is sufficient to suppress the diagnostic for a newly yielded turn.

## What This Changes

The PR adds a user-visible diagnostic for yielded embedded-agent turns without recognized continuation evidence, centralizes the evidence predicate, and adds regression coverage.

## Best Possible Solution

Treat a yielded turn as safely silent only when the runtime has explicit wake evidence bound to that parent and continuation, otherwise emit the diagnostic while preserving yielded and paused lifecycle metadata.
