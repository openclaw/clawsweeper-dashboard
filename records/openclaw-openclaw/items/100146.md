The PR centralizes yielded-turn continuation detection and emits a visible diagnostic when an embedded-agent turn yields with no payload or recognized continuation evidence.

## Best Possible Solution

Keep the diagnostic in terminal resolution, backed by one owner-approved canonical continuation predicate, focused helper coverage, and a runner smoke that proves both warning emission and suppression while preserving the paused lifecycle tuple.
