## Summary

This remains a useful candidate fix for the silent bare-yield bug, but the current head has a type-safety regression and still needs maintainer confirmation that broad terminal evidence—including any active descendant or cron add—is the intended diagnostic-suppression contract.

## What This Changes

The PR adds a shared continuation-evidence predicate and emits a diagnostic payload when a yielded embedded-agent turn otherwise finishes without visible output.

## Best Possible Solution

Separate already-visible delivery evidence from continuation evidence that is explicitly registered to wake this yielded turn, emit the diagnostic when neither exists, and cover stale descendants plus each cron, approval, delivery, spawn, and async branch with focused tests.

## Solution Assessment

Not yet. An additive terminal diagnostic is the narrowest safe shape, but the suppression helper should distinguish visible outcomes from a future wake that is actually relevant to this yielded turn.
