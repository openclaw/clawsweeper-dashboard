## Summary

Keep open: the issue has a protected `maintainer` label, a fresh Docker image-swap repro, and current `main` still only runs limited startup state migration before gateway readiness rather than a version-transition upgrade/doctor contract.

## What This Changes

The issue asks for container image gateway startup to detect OpenClaw version changes on mounted state/config and run or block on pending upgrade migrations before readiness.

## Best Possible Solution

Define a maintainer-owned startup upgrade contract that records the last successfully migrated state/config version and either runs safe idempotent migrations under a lock before readiness or fails readiness with actionable doctor/upgrade guidance.
