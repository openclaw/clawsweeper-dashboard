## What This Changes

The PR makes Gemini web search resolve a configured environment SecretRef before ambient `GEMINI_API_KEY` or the Google model-provider key, and returns the existing missing-key result instead of silently falling back when that configured reference is unavailable.

## System Context

The bundled Google plugin provides Gemini-backed `web_search`; it receives active web-search configuration and selects one credential before sending a guarded request to the Gemini grounding API. This change sits at that credential-selection boundary, affecting which configured Google account receives a search request and whether an invalid configured reference blocks the request.
