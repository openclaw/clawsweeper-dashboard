## Summary

The idempotent settlement approach appears to address the reported indefinite wait without a concrete correctness or security defect, but this external PR remains open because its evidence only exercises mocked children and does not demonstrate the changed lifecycle with a real subprocess that resists termination or omits `close`.

## What This Changes

The PR makes agent-core command execution settle immediately after timeout, abort, or forced-kill errors, ignores later child events, and adds race and missing-`close` regression tests.

## Best Possible Solution

Keep the single-settlement state machine, but demonstrate it with a real subprocess that remains alive or delays closure, showing bounded caller completion, first-cause precedence, harmless late events, and the observable handling of any surviving child.
