## Summary

Keep open. Current main and the latest release still reject trusted-proxy requests when the configured identity header is absent, and adding a fallback/default identity changes a security-sensitive Gateway auth boundary that needs maintainer approval.

## What This Changes

The issue requests a trusted-proxy fallback/default user option for requests from trusted proxy sources when the configured identity header is absent.

## Best Possible Solution

Keep trusted-proxy identity validation fail-closed by default unless maintainers approve a narrow explicit single-principal fallback mode with config, schema, docs, audit guidance, and regression coverage.

Question: Should trusted-proxy auth support an explicit fallback/default identity when a request from a trusted proxy source lacks the configured identity header?

Rationale: The code change is mechanically bounded, but it changes Gateway auth from requiring per-request identity evidence to accepting proxy-source trust plus a configured principal, which automation should not decide.

Likely owner: vincentkoc

Owner confidence: high

Options:

- **Approve narrow fallback mode (recommended):** Add an explicit opt-in single-principal fallback with fail-closed defaults, audit/docs/schema updates, and tests for proxy source, loopback, required headers, origin, and allowlist semantics.
- **Keep fail-closed:** Document Cloudflare Zero Trust IP-whitelist/no-identity WebSocket setups as unsupported for trusted-proxy auth and point users to password auth, Tailscale Serve, or a proxy path that forwards identity headers on WebSocket upgrades.
- **Require live Cloudflare proof first:** Ask for reproducible Cloudflare Tunnel/WebSocket proof before deciding whether OpenClaw should add a headerless trusted-proxy identity surface.

Yes for the OpenClaw source path: current main deterministically rejects trusted-proxy requests without the configured identity header, and a focused test asserts trusted_proxy_user_missing. I did not live-reproduce Cloudflare's WebSocket header stripping.
