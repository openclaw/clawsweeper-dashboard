## Summary

Keep open: current main and the latest release still reject Synology Chat HEAD probes and still ACK accepted webhook POSTs with 204/no body, while the focused fixing PR remains open and unmerged.

## What This Changes

The issue requests that the Synology Chat webhook handler return 200 OK for HEAD probes and return 200 with {"success":true} for accepted POST acknowledgements.

## Best Possible Solution

Land or replace the focused Synology Chat fix so the plugin accepts HEAD probes and returns 200 {"success":true} for accepted POST ACKs while preserving POST token validation, allowlist checks, rate limits, invalid-token throttling, and in-flight guards.
