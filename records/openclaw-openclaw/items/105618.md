## Summary

Keep this issue open. Current main permits the reported race, no duplicate or fix PR owns it, and the protected `maintainer` label requires explicit human handling rather than automated cleanup.

## What This Changes

Fix the Control UI Skills page so overlapping successful mutations cannot leave a stale status report that contradicts persisted Gateway state.

## Best Possible Solution

Give every Skills write one shared mutation epoch or serialized lane, reject status responses started before a newer accepted write, and guarantee one authoritative refresh after the latest mutation settles, with a deferred-request regression test and real-Gateway Playwright proof.
