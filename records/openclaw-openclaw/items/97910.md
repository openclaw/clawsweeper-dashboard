  - body: `workboard_complete` currently returns the standard `{ card }` payload through `runClaimedCardMutation`, and the focused tool test reads `completed.card`.   - confidence: 0.94

  - body: The PR persists a new `ready_to_merge` status, but Control UI keeps its own status list and normalizes unknown card statuses to `todo`.
