## What This Changes

The issue requests an exec-level or per-agent option, or parser exemption, to disable credential-like redaction for inline command secrets.

## Best Possible Solution

Keep forced redaction as the default, then only add an explicit privileged local-only ephemeral debug or SecretRef-style path if maintainers approve the security model.
