## Summary

## What This Changes

The issue requests a global or per-agent way to disable exec command credential masking, or a narrower parser change that avoids replacing secret-like text inside quoted or heredoc content.

## Best Possible Solution

Keep forced safety-boundary redaction by default, collect an exact current-main repro if shell execution is actually mutated, and only add a narrow trusted opt-out or display/parser exemption after maintainer security approval with docs and tests.
