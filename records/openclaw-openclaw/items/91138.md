## Summary

Keep open for maintainer product/security review: current main has no `credentialGuard` opt-out and intentionally forces redaction on safety-boundary tool/UI surfaces, while the inspected exec launch path still passes `params.command` into execution rather than proving pre-shell command mutation.

## What This Changes

Requested a global or per-agent exec credential-redaction opt-out, or a quoted/heredoc parser exemption, so inline credential-shaped command text can be used without replacement.

## Best Possible Solution

Keep secure default redaction, collect an exact live repro for any command mutation, and only add a narrow maintainer-approved trusted secret path or display/parser exemption if the security model supports it.
