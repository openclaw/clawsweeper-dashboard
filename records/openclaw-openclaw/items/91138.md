## Summary

Keep open for maintainer security/product review: current main and v2026.6.11 still force redaction on tool and approval safety-boundary surfaces, while the reported pre-shell command mutation is not proven by source inspection and a broad opt-out would weaken a documented credential boundary.

## What This Changes

## Best Possible Solution
