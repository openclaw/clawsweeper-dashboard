## Summary

Keep this draft PR open for maintainer review. The reported JSONL logging defect and after-fix evidence are credible, but the repair also adds a documented plugin CLI metadata callback and changes stdout/stderr routing for existing command families; that compatibility contract needs an explicit owner decision before merge.

## What This Changes

The branch makes JSON console diagnostics use one formatter across CLI startup paths and adds root command metadata so plugin commands with machine-readable stdout can route diagnostics away from result output.

## System Context

OpenClaw’s CLI initializes logging before it chooses gateway fast paths, routed commands, or Commander commands. Plugin CLI descriptors then identify commands whose stdout is reserved for machine output so diagnostics can remain structured without corrupting command results.
