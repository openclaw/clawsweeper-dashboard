## What This Changes

The branch installs console capture before CLI routing and unifies JSON-console formatting so native console calls, raw subsystem diagnostics, entry validation errors, and routed CLI output remain structured JSONL while explicit command `--json` output stays raw.

## System Context

The CLI receives arguments through the entry wrapper, performs early validation and route selection, then reaches either a fast path or Commander execution. Logging captures native console calls and subsystem output at those boundaries and sends JSONL or human-readable records to operators according to `logging.consoleStyle`.
