## Summary

Keep it open for maintainer review because it deliberately widens the output contract for existing `logging.consoleStyle: "json"` users and carries the protected `maintainer` label.

## What This Changes

Centralizes JSON console-envelope formatting, enables console capture before CLI routes diverge, and changes direct diagnostics and explicit CLI JSON results to preserve structured log lines and raw machine output respectively.

## System Context

OpenClaw’s CLI starts through fast paths, routed commands, and Commander commands before reaching gateway and plugin subsystems. This PR makes diagnostics from those paths pass through a shared JSON formatter when operators opt into JSON console output, while explicit command result objects continue through the raw machine-output sink.
