## What This Changes

The branch installs console capture before CLI routing and uses one JSON formatter so native console calls, raw subsystem output, and route-first CLI diagnostics remain JSONL when `logging.consoleStyle` is set to `json`.

## System Context

CLI startup loads dotenv and then selects a route-first command or the Commander command tree. Both paths emit console and subsystem logs, which are formatted for terminal output and may be consumed as JSONL by operator log collectors.
