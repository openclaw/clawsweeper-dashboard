## What This Changes

This PR centralizes JSON console-line formatting, installs console capture before CLI routes diverge, converts several direct diagnostics to that formatter, and preserves explicit command `--json` results as raw machine-readable output.

## System Context

OpenClaw’s CLI reads logging configuration during startup, then routes commands through fast paths or Commander handlers. Logging calls, direct stderr diagnostics, and explicit machine-output helpers ultimately write to operator-facing stdout or stderr, where JSONL consistency matters to log collectors.
