## What This Changes

This PR centralizes JSON console-line formatting and installs console capture before CLI route selection so native console calls, raw subsystem output, gateway fast paths, and Commander commands keep JSON logging structured while explicit `--json` results remain raw machine output.

## System Context

OpenClaw's CLI initializes logging before choosing gateway fast paths, routed commands, or Commander commands. Those routes emit root and subsystem diagnostics to console sinks, where `logging.consoleStyle: "json"` must produce JSONL for downstream log collectors without changing explicit CLI result serialization.
