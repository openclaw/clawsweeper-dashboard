## Summary

Keep this PR open for maintainer review. The patch appears to address the reported JSONL logging gap across the common CLI boundary and direct diagnostic paths, with real Node/Bun process proof in the PR body; however, its 51-file opt-in compatibility change deliberately alters previously plain diagnostic records for existing `logging.consoleStyle: "json"` users and carries the protected `maintainer` label.

## What This Changes

Centralizes JSON console-line formatting, installs console capture before CLI route dispatch, and converts selected raw diagnostics and plugin CLI JSON results to structured logging or explicit raw machine output.

## System Context

OpenClaw reads console logging style during CLI startup, then routes command output, diagnostics, subsystem logs, and native console calls to stdout or stderr. This change affects the boundary that turns those paths into JSONL for operators' log collectors while preserving explicit command-result JSON as raw objects.
