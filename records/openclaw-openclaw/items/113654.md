## What This Changes

The branch centralizes JSON console diagnostic formatting across CLI startup routes, console capture, and raw subsystem output, while adding plugin metadata that marks commands whose stdout is reserved for machine-readable results.

## System Context

OpenClaw’s CLI initializes logging before it dispatches route-first commands, Commander commands, or plugin command groups. The logging layer sends diagnostics to console streams, while plugin CLI descriptors tell the dispatcher when a command must preserve raw machine-readable stdout.
