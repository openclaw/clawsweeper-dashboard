## Summary

This PR has focused before/after process proof and no concrete patch defect from the supplied review context, but it intentionally broadens the explicit JSON-console contract to early CLI validation and routing diagnostics. Its `maintainer` label, draft status, and prior ClawSweeper review make that compatibility boundary a maintainer decision rather than an automated merge or close outcome.

## What This Changes

The branch centralizes JSON console-line formatting and installs console capture before CLI routes diverge, so selected console and diagnostic paths emit JSONL when `logging.consoleStyle` is `json` while explicit command `--json` output remains raw.

## System Context

OpenClaw’s logging layer formats subsystem logs and optionally captures native console calls, while the CLI entrypoint validates arguments and chooses container, routed, gateway, or Commander execution. This PR moves capture earlier and gives pre-capture diagnostics the same JSON envelope so operators can consume one structured stream.
