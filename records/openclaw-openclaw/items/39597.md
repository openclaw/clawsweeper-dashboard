## Summary

Keep open. ## What This Changes

## Best Possible Solution

Define one additive Gateway-owned client metadata contract with explicit trusted/untrusted semantics, then propagate it through WebChat/native chat.send paths into runtime metadata with focused protocol, prompt, and security tests.
