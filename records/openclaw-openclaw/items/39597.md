## Summary

Keep open. ## Best Possible Solution

Define one additive Gateway-owned client metadata contract with explicit trusted/untrusted semantics, then propagate the approved fields through WebChat/native chat.send paths into runtime metadata with focused protocol, prompt, and native/browser proof.
