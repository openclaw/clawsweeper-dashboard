## Summary

Keep open. Current main already distinguishes WebChat clients during the Gateway WebSocket connect handshake, but it still does not expose a stable agent-visible WebChat client-type or runtime metadata field; the remaining work needs maintainer security/product direction.

## What This Changes

Request to expose whether a WebChat turn came from the native Mac app, browser WebChat, or mobile web in agent/runtime context.

## Best Possible Solution

Define one additive Gateway-owned client metadata contract with explicit trusted/untrusted semantics, then propagate it through WebChat/native chat.send paths into runtime or inbound metadata with focused tests and docs.
