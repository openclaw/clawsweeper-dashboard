Overall correctness: patch is incorrect

Full review comments:

- **[P2] Protect session.started with terminal handling:** `src/agents/cli-runner/execute.ts:477-487`
  - body: `session.started` is recorded before prompt/image/skills/args/queue prep and before the try/catch/finally that records `session.ended` and flushes. Because recorder construction writes the pointer immediately, a later prep failure can leave pointer/event state without a flushed terminal sidecar; move post-recorder prep inside the protected lifecycle scope or delay `session.started` until that scope begins.
  - confidence: 0.9
- **[P2] Move prompt.submitted to the execution boundary:** `src/agents/cli-runner/execute.ts:508-516`
  - body: `prompt.submitted` is emitted before skills plugin prep, execution-arg resolution, CLI arg construction, queue-key resolution, and `enqueueCliRun`. A failure in those steps records a submitted prompt even though no CLI process could receive it, so emit this only after execution-blocking prep has succeeded and is covered by terminal handling.
  - confidence: 0.88
- **[P2] Flush trajectory before cleanup failures escape:** `src/agents/cli-runner/execute.ts:1539-1558`
  - body: The flush block runs after `cleanupOuterResource(...)`, but on a successful run a cleanup rejection can throw before flush is reached. That drops the queued `model.completed` and `session.ended` events; flush from a nested finally or preserve and rethrow cleanup errors only after the recorder flush completes.
  - confidence: 0.91
