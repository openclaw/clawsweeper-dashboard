Full review comments:

- **[P2] Protect session.started with the trajectory lifecycle:** `src/agents/cli-runner/execute.ts:479-488`
  - body: This records `session.started` before image, skills, args, and queue prep, but the terminal-event/flush try block starts later. Since recorder creation writes the pointer immediately, a post-start prep failure can still exit without `session.ended` or `flush`; move post-recorder prep inside the protected scope or delay `session.started`.
  - confidence: 0.94
- **[P2] Emit prompt.submitted only once the CLI can run:** `src/agents/cli-runner/execute.ts:511-517`
  - body: `prompt.submitted` fires before skills plugin prep, execution-arg resolution, CLI arg construction, queue-key resolution, and `enqueueCliRun`. A failure in those steps records a submitted prompt that no CLI process could receive, so emit this after execution-blocking prep succeeds and cover the late-prep failure path.
  - confidence: 0.9
- **[P2] Flush trajectory even when cleanup throws:** `src/agents/cli-runner/execute.ts:1546-1554`
  - body: The new flush block sits after cleanup calls that can rethrow on a successful run. If that happens, queued `model.completed` and `session.ended` events are dropped; run trajectory flushing from a nested `finally` or preserve cleanup errors until after flushing.
  - confidence: 0.91
