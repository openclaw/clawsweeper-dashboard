## Summary

Keep this PR open: explicit SDK barrels are directionally sound, but immediately removing thousands of non-deprecated public exports can break unindexed external plugins and needs an explicit compatibility decision plus upgrade proof before merge.

## What This Changes

This PR replaces 31 public plugin SDK wildcard barrels with explicit export lists, adapts internal consumers, and deletes code made unreachable by the narrowed surface.

## Best Possible Solution

Keep the explicit permanent export lists, but place previously shipped omitted symbols in an explicit deprecated compatibility layer with dated removal records and package-level upgrade smoke proof before deleting them.
