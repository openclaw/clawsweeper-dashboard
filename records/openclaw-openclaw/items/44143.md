  - confidence: 0.9
- **[P2] Bound waits behind stalled sends:** `src/infra/outbound/deliver.ts:1278`
  - body: Every later same-key send now waits for the prior promise to settle, but that wait has no abort, timeout, or stale-claim recovery; a stalled Discord webhook fetch can wedge the recipient queue until restart. Add bounded waiting and abort propagation, or use a claim path with stale recovery, before serializing production sends.
  - confidence: 0.86
