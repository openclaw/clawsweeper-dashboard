## Summary

Keep open: the primary long-session fix is strong and well proven, but the shared fallback helper introduces a blocking regression that can hide audio or other omitted media when an explicit empty text block is present.

## What This Changes

The branch reorders aggregate recovery to preserve fresh non-trailing tool results and changes provider serializers to suppress generic media placeholders when explicit text blocks are present.

## Best Possible Solution

Keep the fresh-result recovery and image fixes, but make fallback suppression depend on actual media delivery so empty text never hides unsupported audio or other omitted media.
