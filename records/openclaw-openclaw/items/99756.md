## Summary

Keep open: the central long-session recovery has strong proof, but the Google transport fallback can emit empty model-visible output for an explicit empty-text-plus-image result on text-only models. The July 9 field report usefully exposed the earlier incomplete fix, and the updated branch now addresses that broader recovery path, but the Google regression must be repaired before merge.

## What This Changes

The PR suppresses generic media placeholders when explicit tool-result text blocks exist and changes aggregate recovery to reduce older projected history before fresh non-trailing tool results.

## Best Possible Solution

Retain the general fresh-projection recovery invariant, but base serializer fallback on useful delivered content: text-only Google routes should emit a non-empty media-omission description, while vision routes may omit a redundant placeholder when the image itself is delivered.
