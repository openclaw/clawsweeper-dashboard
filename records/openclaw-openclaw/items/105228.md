## Repair Work Prompt

Fix requester-wide cancellation for ACP-spawned background tasks. Current `src/auto-reply/reply/abort.ts` stops subagent-registry children but does not enumerate owner-scoped ACP detached tasks created by `src/agents/acp-spawn.ts`; individual ACP task cancellation already routes through `src/tasks/task-registry.ts` to `AcpSessionManager.cancelSession`. Add a canonical owner-scoped helper or equivalent narrow path that cancels active ACP detached tasks when the requester is stopped. Preserve reusable ACP session-mode behavior: cancel the active turn without unconditionally killing the persistent runtime, and close one-shot run-mode sessions only where terminal cleanup requires it so the ACPX process-tree cleanup contract runs. Add regression coverage for requester stop cancelling an ACP run child, cascading through descendants if applicable, avoiding duplicate cancellation, and preserving persistent-session reuse. Do not add a new config option, bypass the task registry, duplicate ACPX process-kill logic in core, or change unrelated subagent cancellation behavior. No changelog edit is required for this repair review.
