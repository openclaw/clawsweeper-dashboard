## Summary

Current `main` still leaves CLI MCP OAuth discovery and auth-profile token fetches without the configured request deadline. The current PR fixes that at the existing SSRF-guarded fetch boundary, preserves caller cancellation, deliberately avoids timing out long-lived MCP transports, and has focused tests plus convincing live CLI proof; no actionable defect remains from prior review cycles.

## What This Changes

The PR adds optional timeout and caller-signal propagation to guarded MCP HTTP fetches, applies configured request deadlines to CLI OAuth login and auth-profile token resolution, and adds lifecycle regression coverage.

## Best Possible Solution

Merge the focused guarded-fetch timeout propagation after exact-head required checks complete, preserving the current split between bounded short-lived OAuth operations and unbounded long-lived MCP transport streams.
