## What This Changes

The PR changes the voice-call diagnostic CLI to read growing JSONL logs in fixed-size chunks, retain incomplete records between polls, and reset follow state after truncation or file replacement.

## System Context

The voice-call plugin provides a local diagnostic CLI that follows JSONL files and prints complete records to an operator's terminal. Its file reader converts diagnostic-log bytes into JSONL output, so read-size limits and rotation handling affect both process memory and the continuity of displayed records.
