## Summary

Keep this PR open: it addresses the unbounded-read problem and includes useful real-module proof, but the new arbitrary byte tail can begin in the middle of a JSONL record, unlike the established bounded-tail implementation, so `latency` can receive invalid JSON and `tail` can emit a truncated record.

## What This Changes

The PR replaces full-file JSONL reads in voice-call diagnostic `tail` and `latency` commands with a shared 1 MB synchronous tail reader.

## Best Possible Solution

Keep the 1 MB cap, but make the helper or each consumer discard the initial fragment when the capped read starts after a non-newline byte, with regression coverage for both diagnostic commands.
