## Summary

Keep this PR open for owner review. It removes a public Gateway RPC advertised since the 2026.7 train, but the branch supplies no compatibility transition or versioning decision for independently upgraded clients; its stated validation is tests, mocks, and CI rather than real upgrade behavior proof. The merged session-companion work provides a plausible replacement, but it does not by itself establish that all released RPC consumers can safely lose `sessions.observer.ask`.

## What This Changes

Removes the `sessions.observer.ask` Gateway RPC, its schemas and generated Android/Swift protocol types, and switches internal mock tooling to `sessions.companion.ask`.

## System Context

Gateway methods are the RPC contract used by Control UI and native or external clients. The session observer continues to publish visibility and digest information, while the session companion provides a separate persistent question-and-answer path for RPC-capable clients.
