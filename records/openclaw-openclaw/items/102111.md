Full review comments:

- **[P3] Skip empty peek chunks before declaring truncation:** `src/agents/tools/web-shared.ts:279-280`
  - body: The main read loop already ignores zero-length chunks, but the new peek treats any non-done read as overflow. A stream that yields exactly `maxBytes`, then an empty chunk, then EOF will still return `truncated: true` even though no bytes were omitted; keep peeking until EOF or a non-empty chunk before flipping the flag.
