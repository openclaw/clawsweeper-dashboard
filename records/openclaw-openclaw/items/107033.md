## Summary

Current main still leaves Linux node services vulnerable to stopping after SSH logout: the node installer creates a systemd user service without the established linger flow, and node documentation omits the persistence prerequisite. Keep this issue open because two open pull requests propose fixes; it should close only after one is reviewed and merged.

## What This Changes

Document and prevent Linux node user services from silently stopping after logout when systemd lingering is disabled.

## Best Possible Solution

Reuse the existing systemd linger flow immediately after successful Linux node service installation, return a structured actionable warning when enablement is unavailable, document the requirement in node setup, CLI, and troubleshooting pages, and prove both fresh installation and SSH-logout persistence without changing non-Linux behavior.
