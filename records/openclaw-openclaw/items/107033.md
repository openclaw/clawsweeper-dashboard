## Summary

Current main still documents `openclaw node install` as a managed service without the Linux linger requirement, while two open pull requests are active implementation candidates; keep this issue as the canonical tracker until one lands and the other is superseded.

## What This Changes

Document and detect the systemd-user lingering requirement so Linux node services remain online after SSH logout.

## Best Possible Solution

Reuse the existing systemd-linger owner after successful Linux node-service installation, attempt safe non-interactive enablement, preserve an actionable text and JSON warning when permission is denied, and document the recovery command in node setup and troubleshooting.
