## Summary

Current main still documents `openclaw node install` as a Linux user service without explaining systemd lingering, while two open pull requests explicitly implement the missing persistence guidance and installer handling; this issue should remain canonical until one fix is reviewed and merged.

## What This Changes

Document and handle the systemd lingering requirement so Linux node services remain online after the installing user logs out.

## Best Possible Solution

Land one canonical fix that reuses the existing systemd-linger helper after Linux node service installation, safely enables lingering when permitted, returns an exact visible recovery command when not, and documents the requirement in node setup, CLI, and troubleshooting pages.
