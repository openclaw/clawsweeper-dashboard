## Summary

## What This Changes

## Best Possible Solution

Use the existing systemd-linger helper after successful Linux node service installation, preserve actionable text and JSON warnings when enablement is unavailable, document recovery in node setup and troubleshooting, and cover both successful enablement and fallback behavior with focused tests.
