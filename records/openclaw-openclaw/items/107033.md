## Summary

Keep this issue open as the canonical Linux node-service persistence bug. Current main documents and repairs systemd lingering for Gateway services, but the node install path and node-specific docs still omit equivalent protection, and two open closing pull requests remain competing fixes.

## What This Changes

Ensure Linux node services survive logout by detecting or enabling systemd lingering and documenting the required recovery command.

## Best Possible Solution

Reuse the existing systemd-linger owner after a successful Linux node-service install, attempt safe non-interactive enablement, preserve an actionable text/JSON warning when permission is unavailable, and document the same recovery path in node setup, CLI, and troubleshooting pages.
