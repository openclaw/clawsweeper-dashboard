## Summary

Keep this issue open: current main still omits the Linux linger requirement from the managed node-service path, and two open closing pull requests are competing implementation candidates; this issue should remain the canonical tracker until one lands and the other is superseded.

## What This Changes

Document and detect Linux systemd user lingering for managed node services so nodes remain online after SSH logout.

## Best Possible Solution

Reuse the existing systemd-linger flow after successful Linux node service installation, fall back to an actionable text and JSON warning when enablement is unavailable, document the requirement in node setup and troubleshooting, and provide a visible doctor/fix recovery path for already-installed nodes.
