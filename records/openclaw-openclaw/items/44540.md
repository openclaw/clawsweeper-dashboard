## Summary

Keep open: current main and the latest release still apply uniform hybrid scoring that discounts vector-only image/audio memory results, and https://github.com/openclaw/openclaw/pull/92196 is the open linked fix path with sufficient proof but no merge yet.

## What This Changes

The issue reports that default hybrid memory search under-ranks multimodal image/audio chunks because their near-zero BM25 text score is blended into otherwise valid vector matches.

## Best Possible Solution

Review, land, revise, or reject https://github.com/openclaw/openclaw/pull/92196; close this issue only after that fix or another canonical solution reaches main.

## Reproduction Assessment

Yes. Source inspection on current main shows vector-only candidates enter hybrid fusion with textScore 0 and are scored with the default 0.7 vector plus 0.3 text formula; I did not run a live Gemini-keyed scenario in this read-only review.

## Solution Assessment

Yes. The narrowest maintainable fix belongs at the memory-core hybrid fusion boundary using the existing multimodal classifier, which is exactly the shape of the linked PR.
