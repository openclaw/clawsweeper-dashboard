## Summary

Keep open: current main and v2026.6.11 still score vector-only media candidates with the uniform hybrid formula, and https://github.com/openclaw/openclaw/pull/92196 is the open closing PR rather than merged implementation.

## What This Changes

The issue reports that default hybrid memory search down-ranks opt-in multimodal image/audio results because BM25 contributes near-zero text score for synthetic media labels.

## Best Possible Solution
