## Summary

Keep open: current main and the latest release still use uniform hybrid scoring that discounts vector-only image/audio memory results, and the open linked PR at https://github.com/openclaw/openclaw/pull/92196 is the active fix path.

## What This Changes

Reports that default hybrid memory search ranks opt-in image/audio multimodal chunks below text chunks because their BM25/text score is near zero.

## Best Possible Solution

Review and land, revise, or reject https://github.com/openclaw/openclaw/pull/92196; close this issue only after that fix or another canonical solution reaches main.

## Reproduction Assessment

Yes. Source inspection shows vector-only multimodal chunks are merged with textScore 0 and scored by the uniform 0.7/0.3 hybrid formula; I did not run a live Gemini embedding scenario in this read-only pass.

## Solution Assessment

Yes. The best fix belongs at the memory-core hybrid fusion boundary using the existing multimodal path classifier, and the open linked PR follows that shape without new config or persisted schema surface.
