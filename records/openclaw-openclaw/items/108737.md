## Summary

Keep this PR open for maintainer review: the implementation is coherent, but `ui.command` currently grants one initiating turn control over every capable Control UI connection rather than a session-bound or originating screen, and the PR provides only test-based proof for a strongly user-visible feature.

## What This Changes

Adds an agent-facing `screen` tool, a capability-gated `ui.command` gateway channel, and Control UI handlers for chat layout, panels, sidebar visibility, and session navigation.

## Best Possible Solution

Bind each command to the originating Control UI connection, or to an explicitly approved session-bound recipient set, while retaining capability and owner-only gating; add two-client isolation coverage and redacted live Control UI proof.
