## Summary

Keep this PR open: the feature remains unique and useful, but the current head still advertises command support from Control UI documents that do not mount the command handler, allowing the gateway to acknowledge commands that are silently dropped.

## What This Changes

The PR adds a capability-gated agent `screen` tool, a `ui.command` gateway method and event, and Control UI handlers for layout, panels, sidebar visibility, focus, and navigation.

## Best Possible Solution

Advertise `ui-commands` only from documents with a mounted consumer, retain reliable lazy panel delivery, and use a maintainer-approved connection-targeting policy with live single- and multi-client proof.
