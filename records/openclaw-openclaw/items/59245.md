## Summary

Keep open: current main and v2026.6.11 still provide Voice Call call-control, DTMF, realtime voice, and consult/context primitives, but not the autonomous outbound task-call workflow requested here. The narrower private-objective PR was closed unmerged by owner decision, so IVR/hold handling, user escalation, authorization policy, timeout behavior, and callback continuity remain unsolved product/security work.

## What This Changes

The issue requests an outbound Voice Call task mode where the agent places real phone calls, navigates waiting/IVR flows, escalates to the user for decisions, shares only authorized information, and resumes long-lived call/callback context.

## Best Possible Solution

Keep this as the umbrella Voice Call product/security tracker, then sponsor narrower plugin-owned design and implementation slices for task objectives, IVR/hold handling, user escalation, callback continuity, post-call reporting, and authorization policy after maintainers choose the safety contract.
