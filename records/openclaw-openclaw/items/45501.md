## Summary

Keep open: current main and v2026.6.11 still hardcode the bare reset startup prompt and strict config schemas do not expose the requested global or per-agent override; this remains a compatibility-sensitive reset/config product decision, not conservative cleanup.

## What This Changes

The issue requests a global and per-agent `session.resetPrompt` config override for the hardcoded startup message used after bare `/new` or `/reset`.

## Best Possible Solution

Define one maintainer-approved reset-start policy that covers prompt text customization, acknowledgement-only resets, optional startup/model turns, bootstrap/current-time safeguards, schema/help/docs, and focused tests.
