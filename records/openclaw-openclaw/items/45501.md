## Summary

Keep open: current main and the latest release still hardcode the bare reset startup prompt, and strict config schemas do not accept the requested global or per-agent override.

## What This Changes

Request adds global and per-agent configuration to override the startup prompt used after bare `/new` or `/reset` while preserving the current default when unset.

## Best Possible Solution

Maintain one canonical reset-start contract that preserves the default prompt, defines global and per-agent precedence if approved, and updates schema, help, docs, runtime prompt construction, and focused reset tests together.
