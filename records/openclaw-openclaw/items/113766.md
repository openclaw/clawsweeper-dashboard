## What This Changes

This PR clears all agent-owned native session-catalog rows, pagination state, and revision tokens when a user switches agents in the Control UI, with Chromium regressions for stale rows and delayed old-agent events.

## System Context

The Control UI sidebar requests session catalogs through the Gateway for the currently selected agent and renders progressive host results. On an agent switch, the controller must discard every prior agent’s catalog state before accepting the replacement agent’s catalog events and pagination cursor.
