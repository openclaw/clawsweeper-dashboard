## Summary

Keep this PR open: the bounded-read fix is plausible and focused, but the supplied live output does not directly exercise the newly defaulted public-helper paths, and the helper-wide 30-second/10-second policy needs owner approval because it can undercut existing caller or provider timeout choices.

## What This Changes

The branch adds idle and total timeout options to four provider response helpers, gives JSON/text reads a 30-second idle default and error-body reads a 10-second default, and adds stalled-stream regression coverage.

## Best Possible Solution

Integrate stalled-body protection with the canonical provider or operation deadline so configured caller budgets remain authoritative, give error-body cleanup an explicitly approved shorter budget, and prove both default and override behavior through the exported helpers.
