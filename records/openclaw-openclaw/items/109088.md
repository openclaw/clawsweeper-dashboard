## Summary

Keep this PR open for a maintainer timeout-contract decision. The hang is real, the bounded-read implementation and live proof are strong, and no discrete patch defect remains, but fixed helper-level ceilings can conflict with OpenClaw’s existing operator-selected provider timeout contract.

## What This Changes

The branch adds optional idle and total timeout controls to four provider response-body helpers, applies 30-second JSON/text and 10-second error-body idle defaults, leaves binary reads opt-in, and adds stalled-stream regression coverage.

## Best Possible Solution

Use one canonical resolved provider/request budget throughout fetch and body consumption, derive a documented idle watchdog from that budget, retain a bounded fallback only when no explicit budget exists, and cover both default and long-configured-timeout upgrade behavior.
