## Summary

Keep open: current main has scoped temp-root hardening, workspace-only temp guidance, static tmp-path checks, volatile state-dir doctor checks, and narrow session temp cleanup, but it still lacks creation-time temp artifact classes, a provenance registry, janitor semantics, and broad runtime-critical `/tmp` guardrails.

## What This Changes

Request a core temp-artifact provenance model, durable-path defaults, janitor semantics, and runtime-critical `/tmp` guardrails for agent-created artifacts.

## Best Possible Solution

Define a narrow core-owned design for runtime-critical temp-path safety and OpenClaw-created artifact provenance, backed by the existing SQLite state model, while routing workflow-specific audit/review classifications to plugins, skills, or ClawHub unless a missing core seam is proven.
