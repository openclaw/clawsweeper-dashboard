Keep open: current main and v2026.6.11 have safe temp-root helpers, workspace-only temp guidance, transcript artifact RPCs, static temp source guardrails, and volatile state-dir doctor checks, but they still do not provide creation-time temp artifact classes/provenance, janitor semantics, or broad runtime-critical /tmp path checks.

## What This Changes

The issue requests first-class temp artifact provenance, cleanup semantics, and durable-path guardrails for agent-created files and runtime-critical temp-backed paths.
