## What This Changes

The issue requests built-in temp artifact provenance, cleanup classification, and runtime-critical `/tmp` path guardrails for agent-created temp files.

## Best Possible Solution

Define a narrow design where core owns runtime/install/doctor temp-path safety and any OpenClaw-owned provenance in SQLite, while workflow-specific audit/review classification uses plugin, SDK, or ClawHub surfaces unless a missing core API is identified.
