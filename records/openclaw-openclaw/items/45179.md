## Summary

Keep open: current main and the latest release have partial temp-root hardening and plugin-specific ephemeral artifact cleanup, but they still lack the requested built-in temp artifact classification, janitor semantics, and broad runtime-critical temp-path validation.

## What This Changes

The issue requests default temp artifact provenance/classes, durable-path guardrails, cleanup awareness, and runtime-critical `/tmp` detection for OpenClaw-created artifacts.

## Best Possible Solution

Define a scoped SQLite-backed provenance and cleanup contract for first-class agent artifacts, add doctor/runtime checks for critical paths that resolve into system temp, and leave plugin-specific ephemeral artifacts in their owning plugin stores.
