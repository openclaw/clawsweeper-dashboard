## Summary

Keep open: current main has scoped temp-root hardening, agent workspace guidance, static tmp-path checks, and narrow doctor/session cleanup behavior, but it still lacks the requested creation-time temp artifact classes, provenance registry, janitor semantics, and broad runtime-critical `/tmp` guardrails.

## What This Changes

The issue requests built-in temp artifact provenance, durable-path defaults, cleanup awareness, and runtime-critical temp-path guardrails for agent-created files outside the workspace.

## Best Possible Solution

Define a narrow core-owned design for runtime-critical temp-path safety and OpenClaw-created artifact provenance, backed by the existing SQLite state model, while leaving workflow-specific audit/review classifications to plugins, skills, or ClawHub unless a missing core seam is proven.
