## What This Changes

## Best Possible Solution

Core should own runtime-critical temp-path detection and any minimal SQLite-backed provenance seam that plugins need, while workflow-specific audit/review classification should live in plugins or ClawHub unless maintainers decide the full registry/janitor model is a core product contract.
