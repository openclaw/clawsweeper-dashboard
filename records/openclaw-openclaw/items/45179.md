## Summary

Keep open: current main has a hardened OpenClaw temp root, transcript-scoped artifact APIs, workspace temp guidance, static temp-path guardrails, and volatile-state doctor checks, but it still lacks the requested creation-time temp artifact classes, cleanup/janitor semantics, and broad live runtime-critical `/tmp` guardrails.

## What This Changes

Request to add default temp artifact provenance, durable-path routing, cleanup semantics, and runtime-critical temp-path guardrails for agent-created files outside the workspace.

## Best Possible Solution

Define a narrow design where core owns runtime/install/doctor temp-path safety and any OpenClaw-owned provenance in SQLite, while workflow-specific audit/review classification uses plugin, SDK, or ClawHub surfaces unless a missing core API is identified.
