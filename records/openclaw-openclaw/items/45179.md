## Summary

Keep open: current main has useful temp-path hardening, but it still does not implement creation-time temp artifact classes, durable routing, a provenance registry, or janitor semantics. The remaining work is broad enough to need maintainer product and storage-scope review.

## What This Changes

The issue requests default OpenClaw support for classifying temporary agent artifacts, recording provenance, routing durable outputs out of system temp, and warning on runtime-critical temp-backed paths.

## Best Possible Solution

Core should own runtime-critical temp-path checks and a minimal SQLite-backed provenance or diagnostic seam, while workflow-specific audit/review classification stays in plugins or ClawHub unless maintainers explicitly choose a full core registry.
