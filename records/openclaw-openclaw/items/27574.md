## Summary

Keep open: current main has browser CLI/RPC primitives and generic plugin-tab plumbing, but it still has no browser-specific Dashboard/Control UI live preview panel; the remaining work needs product and security direction before implementation.

## What This Changes

The issue requests a live browser preview panel in the Dashboard/Control UI for remote users to see browser state, URL/title, console errors, screenshots, and optional manual interaction.

## Best Possible Solution

Design a secured, admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, gates write actions explicitly, and coordinates with the browser handoff and plugin-tab work.
