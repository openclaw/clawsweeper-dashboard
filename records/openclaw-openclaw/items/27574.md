## Summary

Keep open: current main and v2026.6.11 still provide browser CLI/RPC/control primitives, but no Dashboard/Control UI route, sidebar entry, page module, or live preview consumer for the requested browser panel.

## What This Changes

## Best Possible Solution

Design and ship a secured, admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, gates write actions explicitly, and coordinates with the browser handoff and plugin UI entry-point work.
