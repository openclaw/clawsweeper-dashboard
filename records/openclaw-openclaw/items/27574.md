## Summary

Keep open: current main has browser CLI/RPC/control primitives and generic plugin-tab plumbing, but it still does not provide a browser-specific Dashboard/Control UI live preview panel. The remaining work needs maintainer security and product direction rather than conservative cleanup.

## What This Changes

Request to add a live Dashboard/Control UI browser preview panel showing the managed browser view, URL/title, console errors, and optional interaction controls for remote users.

## Best Possible Solution

Design a secured, admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, adds explicit gates for write actions, and coordinates with the browser handoff and plugin UI entry-point tracks.
