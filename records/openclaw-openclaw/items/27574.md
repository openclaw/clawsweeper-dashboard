## Summary

Keep open: current main has browser CLI/RPC/control primitives and generic plugin tab plumbing, but the browser plugin still does not expose a Dashboard/Control UI live preview panel; the remaining blocker is the secured browser-preview trust model and UI ownership boundary.

## What This Changes

The issue requests a live Dashboard browser preview panel showing screenshots, URL/title, console errors, and optional manual actions for remote/VPS browser users.

## Best Possible Solution

Design an admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, gates write actions explicitly, and coordinates with the browser handoff and plugin UI entry-point tracks.
