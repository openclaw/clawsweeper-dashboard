## Summary

## What This Changes

Request a live Dashboard/Control UI browser preview panel that shows the managed browser view, URL/title, console errors, and optional user controls for remote debugging.

## Best Possible Solution

Design a secured, admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, gates write actions explicitly, and coordinates with the browser handoff and plugin UI entry-point work.
