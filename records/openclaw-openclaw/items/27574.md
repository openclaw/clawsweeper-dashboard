## Summary

Keep open: current main has browser CLI/RPC/control primitives and generic plugin tab plumbing, but the browser plugin still does not expose a Dashboard/Control UI live preview panel; the remaining decision is the secured browser-preview trust model and UI ownership boundary.

## What This Changes

The issue requests a live Dashboard browser preview panel showing the managed browser's URL/title, screenshots, console errors, and optional interaction for remote VPS/container users.

## Best Possible Solution

Design a secured, admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, adds explicit gates for write actions, and coordinates with the browser handoff and plugin UI entry-point tracks.
