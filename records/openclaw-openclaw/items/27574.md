## Summary

Keep open: current main still lacks a browser-specific live preview/dashboard surface; it has browser RPC/control primitives and a generic plugin tab seam, but no built-in browser panel, live screenshot consumer, console/error view, or finalized security boundary.

## What This Changes

The issue requests a live Control UI browser preview panel showing the managed browser's screenshots, URL/title, console errors, and optionally user navigation or clicks for remote debugging.

## Best Possible Solution

Design and ship an admin-scoped, read-only-first browser preview surface that reuses browser.request/browser-control primitives, gates write actions explicitly, and coordinates with the browser handoff and plugin UI work.
