## Summary

Keep open. Current source and shipped build ordering support the report that the full build can clean and replace executable output before later validation completes, creating a credible restart-time availability hazard. Likely related people: @steipete is the strongest routing candidate at medium confidence from recent build-orchestration history.

## What This Changes

Make the full source build publish its executable artifacts only after all build and validation steps succeed, preserving the last successful runtime after failure.

## Best Possible Solution

Build every publishable output into an isolated sibling staging tree, run postbuild, asset, and UI gates against that complete staged artifact set, then perform a cross-platform rollback-safe promotion while retaining the previous successful tree until promotion completes.
