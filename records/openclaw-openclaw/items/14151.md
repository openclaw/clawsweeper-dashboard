## Summary

Keep open: current main still lacks this capability, the direct implementation PR closed unmerged, and later reasoning-tag fixes address different failures. The remaining question is whether undelimited local-model reasoning should be normalized by provider/model adapters or supported through a new core configuration contract.

## What This Changes

Add a default-off global or per-model option that synthesizes an opening `<think>` delimiter before reasoning parsing for local models that omit it.

## Best Possible Solution

Prefer structured provider reasoning; if legacy completion backends remain supported, define a narrow provider/model compatibility hint and normalize exactly once at the transport boundary before shared parsing.
