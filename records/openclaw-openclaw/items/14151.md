## What This Changes

Request a user-configurable, default-off way to synthesize opening `<think>` delimiters for local reasoning model output before existing reasoning parsing.

## Best Possible Solution

If sponsored, add one documented default-off config contract, resolve precedence before embedded-agent runs, pass it through runner/subscriber params, and synthesize the tag exactly once with a native-tag guard before current parsing.

## Reproduction Assessment

Yes for a source-level missing-feature check: current main has no config/schema, runner/subscriber, or message-parser path for force-prepending `<think>`. This is not a failing bug reproduction because the issue asks for a new option.

## Solution Assessment

Unclear. A default-off config option is plausible, but OpenClaw's config-surface bar is high and existing provider thinking controls are not equivalent, so maintainers should decide whether core config, provider/model compat metadata, or prompting owns this behavior.
