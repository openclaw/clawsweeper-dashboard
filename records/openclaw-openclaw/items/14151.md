Keep open: current main and v2026.6.11 still lack the requested default-off force-prepend opening `<think>` option, and the direct implementation PR was closed unmerged. ## What This Changes

Request a default-off option to synthesize an opening `<think>` delimiter for local reasoning models that omit reasoning tags.

## Best Possible Solution

Maintainers should decide whether this belongs as core config or provider/model metadata; if sponsored, implement one documented default-off path that resolves precedence before embedded-agent runs and injects exactly once before current parsing with a native-tag guard.

## Reproduction Assessment

Yes for a source-level missing-feature check: current main has no config/schema, runner/subscriber, or message-parser path for force-prepending `<think>`. This is not a failing bug reproduction because the issue asks for a new option.

## Solution Assessment

Unclear. A default-off option is plausible, but OpenClaw's config-surface bar is high and existing provider params plus reasoning visibility controls are adjacent rather than equivalent, so maintainers should choose the owner boundary before implementation.
