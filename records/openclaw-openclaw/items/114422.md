## What This Changes

The branch makes Control UI session navigation resolve uncached session URLs through the gateway so stored Chat/Dashboard preference and one-segment display-name slugs work consistently across deep links and navigation surfaces.

## System Context

Control UI surfaces such as the sidebar, tasks, worktrees, and command palette generate session URLs and navigation actions. The chat route loader resolves an unknown session through the gateway, canonicalizes the URL, and renders the session on its stored Chat or Dashboard face.

## Best Possible Solution
