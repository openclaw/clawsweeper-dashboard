## What This Changes

This PR removes a final `NO_REPLY` token when it is attached directly to a multi-word reply ending in `.`, `!`, or `?`, while retaining ordinary token mentions.

## System Context

Auto-reply normalization removes internal silent-response tokens from completed model output before it becomes a reply payload. That payload then feeds channel delivery, so token-cleanup mistakes can expose control text to users or suppress visible content.
