  - body: This rethrow stops the prepared-attempt loop for every unavailable SecretRef, including profiles selected with source `auto`.   - confidence: 0.99

  - body: The changed resolver now requires a published runtime snapshot for ref-backed static profiles, but non-interactive onboarding calls `resolveApiKeyForProfile` without activating the secrets runtime. Add an explicit setup-only resolution path.
  - confidence: 0.98
- **[P1] Honor credentials inherited from the main runtime snapshot:** `src/agents/auth-profiles/oauth.ts:352`
  - body: Child and ad-hoc agents intentionally inherit materialized credentials from the main agent store when they have no local profile. Requiring a snapshot published under the child `agentDir` rejects that already-resolved credential. Treat inherited runtime credentials as published or consult the owning main snapshot.
  - confidence: 0.98

  - body: The unavailable check keys only on owner identity and publication state. If the operator replaces the failed ref or saves plaintext material in-process, the old degraded-owner record still blocks the repaired profile until a full refresh or restart. Compare the degraded `refKeys` with the profile's current ref before throwing.
