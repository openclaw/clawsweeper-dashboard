## Summary

Keep this PR open for maintainer review: the earlier registry-propagation and changelog concerns appear resolved, but the updated branch intentionally makes an unavailable explicit SecretRef terminal across credential fallback candidates, which can turn one stale profile into a request-time provider outage.

## What This Changes

The PR isolates unavailable stored auth-profile SecretRefs during startup and propagates their degraded-owner state through model-auth and agent-run credential resolution.

## Best Possible Solution

Isolate the failed profile owner during startup, remove only its unresolved runtime credential, and continue trying healthy configured profile or route candidates while keeping config, direct preparation, and reload paths strict.
