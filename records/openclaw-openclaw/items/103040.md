## Summary

Keep this PR open, but it is not merge-ready: the single-quote wrapper changes the shell `-c` program semantics and breaks ordinary PTY commands, while the security claim still has only mocked unit-test proof.

## What This Changes

The PR single-quote escapes PTY command text before passing it as the resolved shell's `-c` argument and updates the supervisor unit test to expect that escaped payload.

## Best Possible Solution

Preserve the command-as-`-c`-program contract and only add targeted hardening after a real end-to-end PTY exploit or regression proof shows a boundary that current argv handling does not cover.
