## Summary

Keep open: current main still has an unbounded process-local session-maintenance warning dedupe Map, while this PR adds a focused private LRU cap with targeted coverage and no blocking review findings.

## What This Changes

Adds a 4096-entry LRU cap to the session-maintenance warning dedupe cache and tests eviction plus changed-context redelivery.

## Best Possible Solution

Land the private LRU cap with the added regression coverage once normal exact-head merge gates are acceptable.

## Solution Assessment

Yes. A private bounded LRU map is the narrowest maintainable fix because it preserves the public warning API and caller, and the existing timestamp-only dedupe helper does not store warning-context values.
