## What This Changes

The branch adds a 4096-entry LRU cap to the session-maintenance warning dedupe cache and extends the warning tests for eviction and changed-context redelivery.

## Best Possible Solution

Land the private bounded LRU cache and focused regression tests once normal exact-head merge gates and maintainer review are satisfied.

## Maintainer Decision

## Reproduction Assessment

Yes. Source inspection shows current main writes each new warned session context into a module-level Map with no cap, and the reply-session caller can supply distinct session keys over time; I did not run a live memory-growth repro in this read-only review.

## Solution Assessment

Yes. A private bounded LRU map is the narrowest maintainable fix because it preserves the public warning API and caller while the existing key-only dedupe helper cannot store the warning context value needed for changed-context redelivery.
