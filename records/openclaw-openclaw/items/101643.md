## Summary

Keep open: current main and the latest release still keep session maintenance warning contexts in an unbounded private Map, and this PR is a narrow, proven mitigation with no blocking code-review finding. Maintainers still need to accept the bounded-LRU trade-off where very high-cardinality gateways can see a warning re-delivered after eviction.

## What This Changes

The PR caps the private session maintenance warning dedupe Map at 4096 entries with touch-on-read LRU eviction and adds tests for eviction and changed warning contexts.

## Best Possible Solution

Land the private bounded LRU if maintainers accept the above-cap re-warning trade-off, with exact-head gates refreshed before merge.
