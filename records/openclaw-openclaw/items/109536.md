## What This Changes

This PR makes the browser tab reachability retry delay respond immediately to the request abort signal while preserving the original cancellation reason returned to callers.

## System Context

Browser tab actions pass through the browser extension’s route handlers, which first probe whether the selected browser profile is reachable before applying a close, focus, or select mutation. When the first probe fails, this retry delay determines whether a caller cancellation stops promptly or waits for the next probe.
