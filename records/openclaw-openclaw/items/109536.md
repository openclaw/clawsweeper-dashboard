## What This Changes

This PR makes the browser tab reachability retry delay observe the request abort signal, allowing cancelled close, focus, and select actions to return before the 250 ms retry window expires.

## System Context

Browser tab actions enter the bundled browser plugin through gateway routes, which probe the configured browser profile before changing a tab. If the first probe fails, the route waits briefly and probes again; this PR makes that wait cancellable by the originating request.
