## What This Changes

This PR makes the browser tab route’s 250 ms reachability retry delay abortable, so a cancelled tab action returns promptly while preserving the original abort reason.

## System Context

Browser tab routes check whether the selected browser profile is reachable before performing close, focus, or selection mutations. A request abort signal flows through that reachability retry and then determines whether the route retries the probe or stops the tab action.
