## What This Changes

This PR makes the browser tab route’s 250 ms reachability retry delay abortable so a cancelled close, focus, or select action returns promptly while retaining the caller’s original abort reason.

## System Context

Browser tab actions enter the browser extension’s route handler, which verifies that the selected browser profile is reachable before issuing a tab mutation. The reachability retry sits between the incoming action’s AbortSignal and the CDP reachability probe, so its cancellation behavior determines how quickly a cancelled request completes.
