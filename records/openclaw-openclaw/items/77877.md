## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Require owner auth before serving document bytes:** `src/gateway/managed-document-attachments.ts:843-845`
  - body: The new route treats device-token/trusted-scope access as privileged and otherwise trusts a client-declared requester-session header before reading `record.original.path`. Current managed-image downloads require authenticated owner/admin context and safe file reads, so this endpoint needs the same protection before serving local documents.
  - confidence: 0.93
- **[P1] Preserve outgoing-doc URLs in WebChat:** `src/gateway/server-methods/chat.ts:460-470`
  - body: This emits `/api/chat/media/outgoing-doc/...` attachment URLs, but current WebChat only exempts `/api/chat/media/outgoing/` from local-source wrapping. These document URLs can therefore be routed through `/__openclaw__/assistant-media`, losing the new route's attachment headers or failing to download.
  - confidence: 0.9
- **[P1] Strip document blocks when transcript append fails:** `src/gateway/server-methods/chat.ts:469-470`
  - body: The PR adds document managed blocks to assistant content, but the append-failure fallback still strips only managed-image blocks. If append fails, the broadcast can include document links whose records remain transient and can be cleaned up, leaving users with dead download links.
  - confidence: 0.86
- **[P2] Update the stale media-core import:** `src/gateway/managed-document-attachments.ts:27`
  - body: Current main moved media constants to `@openclaw/media-core/constants`, so `../media/constants.js` no longer exists. This new module must use the current import path before the branch can build or be safely loaded.
  - confidence: 0.91
- **[P2] Guard the document route before importing it:** `src/gateway/server-http.ts:750-753`
  - body: The image route is only added when the scoped path matches, but this PR adds the document stage for every HTTP request. That makes unrelated requests import the new module and magnifies any module-load failure into a broader gateway availability problem.
  - confidence: 0.84
- **[P2] Encode Unicode filenames with filename*:** `src/gateway/managed-document-attachments.ts:927-928`
  - body: `safeAttachmentFilename` preserves Unicode inside the plain `filename="..."` header value. Non-ASCII document names need an ASCII fallback plus `filename*` encoding; otherwise Node can reject the header or browsers can receive an invalid filename.
  - confidence: 0.82
