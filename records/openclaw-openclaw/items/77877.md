Full review comments:

- **[P1] Replace the copied data URL regex:** `src/gateway/managed-document-attachments.ts:247`
  - body: This new parser copies the old nested data-URL regex shape that current main replaced in `79d3daa09b57a9db0a50e424fec22f3921a6c3c0`. A model-emitted malformed document data URL can hit this path from the reply media pipeline and spend excessive time backtracking before `continueOnPrepareError` can recover, so port the current first-comma parser and its malformed-input coverage instead.
  - confidence: 0.97
- **[P1] Require owner auth before serving document bytes:** `src/gateway/managed-document-attachments.ts:880-906`
  - body: The document route serves saved file bytes after checking a client-declared requester-session header for non-privileged callers. Current managed-image serving explicitly requires authenticated owner/admin sender context before reading the file because requester-session headers are not a security boundary; mirror that check here before serving document bytes.
  - confidence: 0.95
- **[P1] Preserve outgoing-doc URLs in WebChat:** `src/gateway/managed-document-attachments.ts:161-162`
  - body: The new blocks use `/api/chat/media/outgoing-doc/...`, but current WebChat only treats `/api/chat/media/outgoing/` as a non-local managed URL. Because `outgoing-doc` does not match that guard, document links are treated as local paths and wrapped through `/__openclaw__/assistant-media`, losing this handler's `Content-Disposition: attachment` response.
  - confidence: 0.94
- **[P1] Strip document blocks when transcript append fails:** `src/gateway/server-methods/chat.ts:469-470`
  - body: These document blocks are added to the assistant content, but the fallback path still strips only managed image blocks when transcript append fails. In that failure mode the broadcast can contain an outgoing-doc link whose record remains transient and fails transcript membership, so the user receives a broken 404 attachment; strip managed document blocks in the same failure path.
  - confidence: 0.91
- **[P2] Import media constants from media-core:** `src/gateway/managed-document-attachments.ts:27`
  - body: Current main no longer has `src/media/constants.ts`; media constants now come from `@openclaw/media-core/constants`. This new file will not build after rebasing unless the import is updated to the current package path.
  - confidence: 0.99
- **[P2] Guard the document route before lazy import:** `src/gateway/server-http.ts:750-753`
  - body: This stage is pushed for every request, so every non-earlier gateway request tries to lazy-import the document module before Control UI handling. Follow the current managed-image pattern by checking the path first, otherwise a document-module import failure or cold import cost can affect unrelated gateway requests.
  - confidence: 0.9
