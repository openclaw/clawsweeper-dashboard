## Summary

## What This Changes

The PR makes both Zalo User text chunkers step back from UTF-16 high-surrogate boundaries and adds hard-limit, preferred-break, and one-unit-limit regression tests.

## Best Possible Solution

Use one shared boundary helper with explicit one-unit semantics that always keeps a valid surrogate pair together, cover both chunking modes by asserting every sent chunk is well-formed, and provide redacted proof from the actual OpenClaw-to-Zalo delivery path.
