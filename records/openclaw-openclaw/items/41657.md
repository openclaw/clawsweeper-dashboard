## Summary

Keep open: current main and v2026.6.11 still provide Slack file placeholders plus downloaded media path/type fields, but not the requested structured per-file metadata block for agents.

## What This Changes

The issue requests Slack inbound file attachment metadata such as file ID, filename, MIME type, and size be delivered to agents.

## Best Possible Solution

Define a shared inbound attachment metadata contract in the channel/plugin API, populate Slack file id, filename, MIME type, and size first, and keep existing placeholders and media fields intact.
