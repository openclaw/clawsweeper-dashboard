## Summary

Keep open: current main and the latest release still expose Slack files through placeholders plus legacy Media* fields, but they do not provide the requested structured per-file metadata contract for agents.

## What This Changes

Request to add agent-visible metadata for inbound Slack file attachments, including file ID, name, MIME type, and size.

## Best Possible Solution

Define a shared InboundAttachments-style channel/plugin SDK contract that preserves existing placeholders and Media* fields while mapping provider file IDs, filenames, MIME types, sizes, local paths, and download status across Slack and sibling channels.
