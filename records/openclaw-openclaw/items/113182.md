## What This Changes

Fix a suspected lane-queue timeout race that can abort a legitimate Codex-assisted agent turn after the model generated output, causing the final assistant text to be lost.

## System Context

Gateway lane queues serialize agent work for shared and per-session lanes. Each queued turn runs the embedded agent runtime and should hand its completed assistant text to the session and channel result path unless it is genuinely cancelled or timed out.
