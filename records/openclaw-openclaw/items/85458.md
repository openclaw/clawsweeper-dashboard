## What This Changes

The issue asks OpenClaw to clean up or otherwise own the Codex app-server thread created during missing-thread bound-turn recovery when the retry rejects.

## Best Possible Solution

Define the intended bound-thread subscription lifecycle, then implement the retry-rejection cleanup or retention rule with consecutive-turn and missing-thread recovery coverage.
