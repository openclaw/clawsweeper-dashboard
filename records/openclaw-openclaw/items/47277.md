  - body: `resolveMemorySearchConfig` defaults isolation to enabled, but `readIsolation` returns `null` when the `memory.isolation` block is absent. That means default configs skip identity resolution and memory_search/memory_get can run unscoped, defeating the advertised default-on isolation.
  - confidence: 0.9

  - body: Passing `userId` only changes the QMD cache/state directory; `resolveMemoryBackendConfig` still builds workspace-wide `MEMORY.md` and `memory/**` collections. Each user-specific QMD index can therefore ingest/search every workspace memory file unless the default collections are also user-scoped or filtered.
  - confidence: 0.88
- **[P1] Stop indexing shared flush files for every isolated user:** `packages/memory-host-sdk/src/host/internal.ts:262-263`
  - body: In isolation mode `listMemoryFiles` still adds root-level `memory/*.md` for every user, while the current flush plan writes durable notes to `memory/YYYY-MM-DD.md`. A compaction from one user can be indexed for all users, so flush output needs a user-scoped target or isolated scans must exclude private root flush files.
  - confidence: 0.86
