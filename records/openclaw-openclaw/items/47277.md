  - body: `resolveMemorySearchConfig` returns `isolation.enabled: true` when `cfg.memory?.isolation` is absent, but this resolver returns `null` for the same absent block and `resolveIsolationIdentity` then returns `undefined`. Default configs therefore create memory managers without a user scope, so the advertised default-on isolation is silently not enforced.
  - confidence: 0.93
- **[P1] Scope QMD collections, not only manager state:** `extensions/memory-core/src/memory/qmd-manager.ts:347-351`
  - body: This adds `userId` to the QMD state directory, but the resolved QMD collections still come from the workspace-wide defaults (`MEMORY.md` plus `memory/**/*.md`) and are not filtered or rewritten by user. Each user can get a separate QMD index over the same shared corpus, so QMD memory_search can still surface other users' memory.
  - confidence: 0.9
- **[P1] Stop indexing shared flush files for every isolated user:** `packages/memory-host-sdk/src/host/internal.ts:262-263`
  - body: In isolation mode this still scans root-level `memory/*.md` for every user. The default compaction flush target remains `memory/YYYY-MM-DD.md`, so durable notes written during one user's flush can be indexed and returned for other isolated users.
  - confidence: 0.88
