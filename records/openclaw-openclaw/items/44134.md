## Summary

Keep open: current main and v2026.6.11 still run provider tool-schema normalization from the embedded attempt path without a provider-normalized schema cache, and the direct cache PR is open rather than merged.

## What This Changes

The issue asks OpenClaw to stop repeatedly reloading or normalizing Google/Gemini tool schemas during active provider sessions because it may trigger provider anti-abuse checks and memory pressure.

## Best Possible Solution

Refresh, land, or replace https://github.com/openclaw/openclaw/pull/78664 with a bounded internal provider-normalization cache that avoids new operator config and proves cache hits plus stale-closure/custom-hook safety.
