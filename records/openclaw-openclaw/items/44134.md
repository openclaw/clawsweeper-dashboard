## Summary

Keep open: current main and v2026.6.11 still run provider tool-schema normalization from the embedded-attempt path without a provider-normalized schema cache, and the direct cache PR remains open and conflicting rather than merged.

## What This Changes

The issue asks OpenClaw to stop repeatedly reloading or normalizing Google/Gemini tool schemas during active use because the churn may trigger provider anti-abuse bans and gateway memory pressure.

## Best Possible Solution

Refresh or replace the open cache PR with a bounded internal provider-normalization cache, no new operator config by default, and focused cache-hit plus live-provider or heap proof on a real Google/Gemini path.
