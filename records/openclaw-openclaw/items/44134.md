## What This Changes

The issue asks OpenClaw to stop repeatedly rebuilding or normalizing provider tool schemas across agent attempts because the behavior can trigger Google anti-abuse flags and gateway memory pressure.

## Best Possible Solution

Refresh, land, or deliberately replace the existing provider-normalization cache PR with a bounded internal cache that keeps custom provider hooks uncached and still rebuilds tool objects, closures, approval state, and runtime policy per turn.
