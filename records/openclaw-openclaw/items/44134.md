## Summary

Keep open: current main and the latest release still normalize provider tool schemas from the embedded-attempt path without a provider-normalized schema cache, and the direct cache PR is still open rather than merged.

## What This Changes

The issue asks OpenClaw to stop repeatedly reloading or normalizing Google/Gemini provider tool schemas during active use, preferably through caching rather than session churn.

## Best Possible Solution

Refresh or replace the open cache PR with a bounded internal provider-normalization cache that preserves fresh tool objects and closures, bypasses custom provider hooks, avoids new operator config by default, and includes focused cache-hit plus live or heap proof.
