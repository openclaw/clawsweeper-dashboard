## What This Changes

The issue asks OpenClaw to stop repeatedly reloading or normalizing Google/Gemini tool schemas during active sessions to avoid provider bans, hangs, and memory pressure.

## Best Possible Solution

Refresh, land, or deliberately replace https://github.com/openclaw/openclaw/pull/78664 with a bounded internal provider-normalization cache that keeps custom provider hooks uncached and rebuilds tool objects, closures, approval state, and policy per turn.
