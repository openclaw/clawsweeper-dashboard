## Summary

Keep this PR open: it validates the retry configuration before writing `openclaw.json`, but the retry path can still persist an invalid credential into the auth-profile store before validation fails.

## What This Changes

The branch loops live inference verification for retried wizard candidates and writes the candidate configuration only after a successful verification.

## Best Possible Solution

Use the existing unpersisted provider-auth result path to stage both config and profile credentials, then commit both only after live verification succeeds; keep Continue fully non-mutating for the retried candidate.
