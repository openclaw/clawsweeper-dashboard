## What This Changes

This PR adds an opt-in `models.providers.openai.params.codexProxyBaseUrl` setting that routes token/OAuth Codex model discovery and Responses requests through a validated loopback proxy while API-key profiles remain on the OpenAI Platform API.

## System Context

The bundled OpenAI plugin resolves an authentication profile, discovers available models, and sends Responses requests for agent runs. The proposed proxy setting enters that routing decision only for Codex-style token/OAuth paths, then affects the catalog endpoint and inference endpoint while preserving `openai/*` model references.
