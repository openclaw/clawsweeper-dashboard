## What This Changes

This PR adds `models.providers.openai.params.codexProxyBaseUrl` so the bundled OpenAI provider can send token/OAuth Codex model discovery and Responses traffic to a validated local loopback broker while API-key routes remain on OpenAI’s Platform API.

## System Context

The OpenAI plugin resolves a selected credential into a live model catalog and model base URL, then the shared AI package sends Responses requests using that model configuration. This change introduces a constrained local-broker branch for Codex credentials while retaining the normal direct API-key branch.
