## What This Changes

This PR adds `models.providers.openai.params.codexProxyBaseUrl` so Codex token/OAuth model discovery and Responses requests can use a validated local loopback credential broker while API-key routes remain direct.

## System Context

The bundled OpenAI provider chooses an auth profile, discovers models, and passes the selected model endpoint to the shared Responses transport. This change optionally substitutes a loopback `/codex` endpoint for Codex credential-bearing discovery and inference while leaving API-key and image-generation paths on their existing direct routes.
