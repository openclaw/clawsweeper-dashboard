## Best Possible Solution

Define a maintainer-approved no-outbound channel/account contract, then implement a focused WhatsApp or shared channel enforcement path with config/schema/docs, upgrade guidance, exhaustive outbound-path tests, and live WhatsApp proof while leaving hooks-only/no-agent ingestion tracked separately.
