## Summary

Keep open: current main still has the Feishu reply-mention false-negative path, the original same-repository fix PR is closed unmerged, and the open fork copy is conflicting rather than a safe canonical landing path.

## What This Changes

The issue reports that Feishu reply messages that @-mention the bot can be missed when Feishu omits the bot from the mentions array, and that detected reply mentions may route the bot response through root_id/thread context.

## Best Possible Solution

Land a current-main Feishu plugin fix that uses bot-specific dropped-mention evidence and lets scope-aware routing choose main-chat versus topic replies, then close this issue after the target-repository fix merges.
