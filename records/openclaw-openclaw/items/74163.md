## What This Changes

This PR adds a Markdown dashboard for Microsoft-related issues and pull requests, a Node generator that can refresh the file and edit a PR body through GitHub CLI, and a changelog entry announcing that workflow.

## System Context

The proposed generator queries GitHub items, classifies them into Microsoft ecosystem categories, and renders a maintainer-facing tracker. Its optional update mode sends the generated Markdown back to a pull-request body, so classification and output escaping affect GitHub workflow state as well as documentation.

First decide whether this tracker belongs in OpenClaw at all; if approved, keep it read-only and deterministic, remove the release changelog edit, classify Azure Speech only under Azure unless another independent Teams signal exists, add focused fixture-based verification, and prove a redacted live generation run before considering any PR-body update mode.
