Full review comments:

- **[P1] Neutralize copied closing references before body updates:** `scripts/generate-microsoft-tracker.mjs:240`
  - body: `prRow` copies raw titles into Markdown, and `--update-pr-body` later publishes that Markdown as a PR body. The live PR is already a closing candidate for unrelated open issues, so the generator needs to escape or rewrite closing keywords before body updates.
  - confidence: 0.94
- **[P1] Honor live priority labels before keyword escalation:** `scripts/generate-microsoft-tracker.mjs:151-153`
  - body: `priorityFor` ignores existing `P0`-`P3` labels and scans broad substrings instead. That escalates labeled work such as a `P3` Windows installer suggestion to `P0`, which makes the tracker misroute maintainer queues.
  - confidence: 0.9
- **[P2] Require token boundaries for Windows matching:** `scripts/generate-microsoft-tracker.mjs:140`
  - body: The category matcher uses raw substring matching, so titles like macOS WindowServer reports still enter the Windows tracker. Use token-aware matching or explicit platform signals before adding a row.
  - confidence: 0.88
- **[P2] Add a check mode for the generated tracker:** `scripts/generate-microsoft-tracker.mjs:422`
  - body: The script writes a committed generated artifact, but the PR adds no package `*:gen` or `*:check` command to verify the checked-in tracker matches the generator. That lets the tracker drift immediately after merge.
  - confidence: 0.86
- **[P3] Emit valid Markdown separator cells from the generator:** `scripts/generate-microsoft-tracker.mjs:362`
  - body: The generator emits `-` for the `#` separator cells in issue, PR, and appendix tables. GitHub-flavored Markdown expects at least `---`, so rerunning the generator can produce tables that render inconsistently.
  - confidence: 0.82
- **[P3] Remove the release-owned changelog entry:** `CHANGELOG.md:8`
  - body: Root policy makes `CHANGELOG.md` release-owned for normal PRs. This admin tracker change should keep release-note context in the PR body rather than adding an unreleased changelog line.
  - confidence: 0.8
- **[P3] Point tracker update instructions at the edited surface:** `MICROSOFT_TRACKER.md:7`
  - body: The committed tracker file tells maintainers to edit the PR body to mark rows resolved. If this file is merged as the artifact, that instruction sends maintainers to the wrong place.
  - confidence: 0.78
