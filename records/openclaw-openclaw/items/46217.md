## Summary

Keep open: current main still leaves visible Control UI Settings text in English for Chinese locales, and the two linked PRs are open partial fixes rather than merged resolution for the Settings schema/category/Quick Settings localization scope.

## What This Changes

The issue requests Chinese localization for English text that still appears in the Control UI Settings section.

## Best Possible Solution

Adopt one Settings i18n contract covering toolbar chrome, Quick Settings, section metadata, and schema/uiHint-derived field labels with English fallback, then sequence or replace the partial PRs against that contract.
