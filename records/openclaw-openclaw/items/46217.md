## Summary

Keep open: current main still leaves visible Control UI Settings text in English for Chinese locales, and the two linked implementation PRs are still open, partial, and conflicting rather than merged fixes.

## What This Changes

The issue requests fuller Chinese localization for the Control UI Settings section, including Settings chrome and configuration labels.

## Best Possible Solution

Adopt one generated Settings i18n contract that covers toolbar chrome, Quick Settings, section metadata, and schema/uiHint-derived field labels with English fallback, then rebase or replace the partial PRs against that contract.
