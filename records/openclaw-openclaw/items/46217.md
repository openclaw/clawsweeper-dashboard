## Summary

Keep open: current main still leaves Chinese users with English text in the Control UI Settings categories, toolbar, quick-settings Appearance card, and schema-derived config field labels. The linked PRs are useful partial candidates, but both are still open/conflicting and the full schema-label localization contract still needs maintainer direction.

## What This Changes

The issue asks to translate the Control UI Settings/configuration section into Chinese because Chinese users still see English configuration labels and controls.

## Best Possible Solution

Define one Settings i18n contract that routes toolbar, quick-settings, section metadata, and schema/uiHint field labels through generated locale keys with English fallback, then land focused refreshed PRs against that contract.
