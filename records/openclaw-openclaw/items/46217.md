## Summary

Keep open: current main still renders English Settings toolbar, Quick Settings, section/category, and schema-derived config labels for Chinese locales, while the linked implementation PRs are still open partial candidates rather than merged fixes.

## What This Changes

Translate the Control UI Settings/configuration section into Chinese so Chinese users do not see English labels and controls.

## Best Possible Solution

Adopt one Settings i18n contract that covers toolbar chrome, Quick Settings, section metadata, and schema/uiHint-derived field labels with English fallback, then rebase or replace the partial PRs against that contract.
