## Summary

Keep open: current main and the latest release still leave visible Control UI Settings text in English for Chinese locales, and the linked implementation PRs are open partial candidates rather than merged fixes.

## What This Changes

Request to translate the Control UI Settings section, including configuration labels and controls, into Chinese.

## Best Possible Solution

Adopt one Settings i18n contract that covers toolbar chrome, Quick Settings, section metadata, and schema/uiHint-derived labels with English fallback, then rebase or replace the partial PRs against that contract.
