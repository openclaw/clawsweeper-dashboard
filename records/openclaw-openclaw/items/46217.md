## Summary

Keep open: current main still leaves Settings navigation, toolbar, Quick Settings, and schema-derived config labels in English for Chinese locales, while the linked pull requests are open partial fixes rather than a merged implementation.

## What This Changes

The issue requests Chinese localization for the Control UI Settings section, especially English configuration labels shown under Chinese locales.

## Best Possible Solution

Define one Settings i18n contract covering toolbar chrome, Quick Settings, section metadata, and schema/uiHint-derived field labels with English fallback, then sequence or replace the partial PRs through the UI i18n generator pipeline.
