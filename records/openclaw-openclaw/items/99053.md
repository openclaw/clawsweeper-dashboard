## Summary

## What This Changes

## Best Possible Solution

Land one canonical Discord-owned fallback that preserves configured or discoverable upload limits, degrades to text after an actual 413 or verified cap, records the fallback receipt accurately, and closes the linked message-loss issue after merge.

## Solution Assessment
