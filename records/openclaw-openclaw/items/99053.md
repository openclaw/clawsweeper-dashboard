Full review comments:

- **[P1] Preserve configured Discord upload limits:** `extensions/discord/src/send.shared.ts:400-403`
  - body: This caps every Discord media send at 10 MiB before trying the API, even when mediaMaxMb is configured higher. Discord documents 10 MiB as a default per-file limit that can be higher by user/server context, and Create Message allows requests up to 25 MiB, so existing configured/boosted setups could lose attachments that would have uploaded; prefer catching 413 or using a discovered/configured channel limit instead. ([discord.com](https://discord.com/developers/docs/reference))
  - confidence: 0.89
- **[P2] Report stripped media as text-only delivery:** `extensions/discord/src/send.shared.ts:447`
  - body: When this branch strips the attachment, sendMessageDiscord still wraps the returned result as kind media because opts.mediaUrl is set. That leaves durable receipts and diagnostics able to claim a media part was delivered even though only fallback text reached Discord, so the fallback needs text-only or partial-delivery metadata and a receipt assertion.
  - confidence: 0.86
