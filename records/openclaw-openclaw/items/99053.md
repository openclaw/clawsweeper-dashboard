## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Preserve configured Discord upload caps:** `extensions/discord/src/send.shared.ts:402-404`
  - body: This caps every media send at 10 MiB even when `channels.discord.mediaMaxMb` is explicitly higher. Discord documents 10 MiB as the default but allows higher limits in some contexts, so existing operators who configured a higher Discord cap can have valid uploads silently stripped; keep the default protection without overriding explicit higher caps or add a maintainer-approved migration/policy.
  - confidence: 0.86
- **[P2] Report stripped media as text-only delivery:** `extensions/discord/src/send.shared.ts:448`
  - body: When the attachment is stripped, this returns the text-send result to an outer caller that still wraps all `mediaUrl` sends as `kind: "media"`. Delivery accounting can therefore claim a media part was sent even though only fallback text reached Discord; carry a text-only or partial-delivery result and assert the receipt kind in tests.
  - confidence: 0.88
