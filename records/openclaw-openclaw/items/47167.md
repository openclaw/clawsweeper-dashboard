Keep this open: current main still lacks a public early read-only Plugin SDK hook for mention-skipped messages, and the open implementation PR remains the active API/privacy decision path.

## What This Changes

The issue requests a passive early inbound hook so archive plugins can observe group messages intentionally skipped by requireMention without creating sessions or replies.

## Best Possible Solution

Review PR 83101 or a successor as the canonical implementation path, preferably landing a gated read-only hook with documented payload semantics and tracked multi-channel rollout.

Options:

- **Gate The Public Hook Before Landing (recommended):** Add an explicit operator or plugin permission gate, document the payload boundary, and land the hook only after that contract is visible.

- **Keep Internal Ingest Only:** Pause or reject the public hook and leave full-fidelity archive plugins dependent on internal or channel-specific integrations for now.
