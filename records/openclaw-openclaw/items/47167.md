## What This Changes

The issue requests a passive, read-only early inbound plugin hook so archive plugins can observe group messages skipped by `requireMention` without creating sessions or replies.

## Best Possible Solution

Keep this as the canonical tracker, then review or replace PR https://github.com/openclaw/openclaw/pull/83101 with a maintainer-approved, access-gated read-only Plugin SDK hook and clear follow-up for non-Telegram rollout.
