## Summary

Keep this open: current main and the latest release still lack a public early inbound Plugin SDK hook for mention-skipped messages, and the linked implementation PR remains the active API/privacy decision point.

## What This Changes

The issue requests a public read-only early inbound plugin hook so archive plugins can observe group messages skipped by mention gating without dispatching them to an agent.

## Best Possible Solution

Review https://github.com/openclaw/openclaw/pull/83101 or a successor as the canonical API/security path, preferably with an explicit visibility gate, clear read-only semantics, and tracked multi-channel rollout.
