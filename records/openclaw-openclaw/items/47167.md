## Summary

## What This Changes

The issue requests a passive plugin-observable event for group messages skipped by `requireMention` before they enter dispatch/session hooks.

## Best Possible Solution

Review or replace https://github.com/openclaw/openclaw/pull/83101 with a maintainer-approved, read-only, access-gated Plugin SDK hook; land a one-channel rollout only if the remaining channels are explicitly tracked.

## Reproduction Assessment

Yes, at source level: Telegram and Discord `requireMention` skip branches return `null` before downstream public `message_received` can run. I did not run live channel traffic in this read-only review.

## Solution Assessment

Unclear until maintainer approval: a separate read-only observation hook is a plausible clean solution, but the API name, access gate, privacy boundary, and rollout scope are product/security decisions.
