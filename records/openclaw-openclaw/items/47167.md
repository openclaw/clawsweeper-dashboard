## Summary

Keep this open: the public conversation-archive plugin already covers standard hook-visible messages, but current main and v2026.6.11 still lack a public early inbound hook for mention-skipped messages, and the linked implementation PR remains the active API/privacy decision point.

## What This Changes

The issue requests a passive read-only early inbound plugin hook so mention-skipped group messages can be archived without creating sessions or replies.

## Best Possible Solution

Review https://github.com/openclaw/openclaw/pull/83101 or a successor as the canonical API/security path, preferably with an explicit visibility gate, clear read-only semantics, and tracked multi-channel rollout.
