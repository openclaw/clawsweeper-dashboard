## What This Changes

This issue requests a read-only early inbound plugin hook so archive/history plugins can observe group messages skipped by requireMention without creating sessions or replies.

## Best Possible Solution

Review https://github.com/openclaw/openclaw/pull/83101 or a successor as the canonical API/security decision, preferably with an explicit opt-in visibility gate and clear docs for skipped-message payloads and non-routing semantics.
