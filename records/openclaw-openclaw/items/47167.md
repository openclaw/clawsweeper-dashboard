## Summary

Keep this open: current main still lacks the requested public early read-only inbound hook, and the open linked implementation PR is the direct place to resolve the API, privacy, and Telegram behavior questions.

## What This Changes

Request a passive plugin-visible early inbound/skipped-message event so archive plugins can observe requireMention-skipped group messages without creating sessions or replies.

## Best Possible Solution

Review the linked implementation PR toward a narrow, opt-in, read-only early observation hook with minimized payload, explicit privacy docs, and no routing/reply authority.
