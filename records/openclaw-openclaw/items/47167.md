## Summary

Keep this open: current main still lacks a public early read-only inbound hook for skipped group messages, and the active candidate PR remains a product/security API decision rather than a merged fix.

## What This Changes

Request a public read-only early inbound plugin hook so archive plugins can observe group messages skipped by `requireMention` without creating sessions or replies.

## Best Possible Solution

Keep this as the canonical tracker, then review or replace PR https://github.com/openclaw/openclaw/pull/83101 with a maintainer-approved, access-gated read-only Plugin SDK hook and a clear rollout plan for non-Telegram channels.
