## What This Changes

The PR adds JSON and text health diagnostics that report when a gateway is still running an older configuration after restart-required model, provider, auth, or secret changes on disk.

## System Context

The gateway config reloader watches configuration changes and retains the live runtime snapshot when a change needs restart handling. The health RPC and `openclaw health` CLI then expose operational state to read-scoped and admin-scoped callers, including cached responses.
