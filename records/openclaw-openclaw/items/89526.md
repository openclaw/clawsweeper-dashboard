## What This Changes

This PR adds a `runtimeConfig` health diagnostic that reports restart-required live-versus-disk configuration drift in JSON and text health output, while redacting sensitive details for non-admin callers.

## System Context

The gateway reloader observes configuration changes and may keep a running configuration when a change requires restart. The health RPC and CLI consume cached and live gateway state; this PR would add a drift signal so operators can see when disk configuration has not yet become the runtime configuration.
