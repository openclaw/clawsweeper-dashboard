## Summary

The diagnostic addresses a real operator blind spot and has strong live proof, but the patch puts full config-file rediscovery on every cached gateway health request instead of carrying reloader-owned state forward, so it should not merge in its current form.

## What This Changes

Adds a `runtimeConfig` live-versus-disk drift diagnostic to JSON and text health output, recomputes it on cached gateway health responses, gates sensitive details by admin scope, and adds focused tests.

## Best Possible Solution

Keep the operator diagnostic, but compute and store restart-required drift when the config reloader evaluates a snapshot, expose that prepared process-local state through the existing runtime-handle/request-context accessor pattern, and keep cached health responses disk-free with sensitive details admin-only.
