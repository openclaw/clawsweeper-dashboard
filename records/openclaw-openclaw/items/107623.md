## Summary

The patch is technically coherent and has strong focused proof, but it defines compatibility-sensitive duration grammar in the outer watchdog without establishing that the same grammar governs actual computer-tool execution; a Codex-area owner should confirm that contract before merge.

## What This Changes

The PR replaces JavaScript number coercion for Codex computer wait durations with type-sensitive parsing and adds dedicated boundary coverage for malformed strings, fractional numbers, non-finite numbers, and non-duration actions.

## Best Possible Solution

Define duration normalization at the computer-tool owner boundary and reuse that canonical result for both execution and watchdog budgeting, with tests proving identical accepted and rejected forms across both paths.
