## What This Changes

Add an optional `sessions_spawn` lane and compatible per-lane concurrency configuration while preserving the existing default sub-agent lane.

## Best Possible Solution

Define trusted configured lane profiles with validated identifiers, preserve `subagent` as the default, enforce an aggregate sub-agent ceiling, specify configuration precedence and reload behavior, and thread the resolved lane consistently through native and ACP spawn paths with schema, docs, and regression coverage.
