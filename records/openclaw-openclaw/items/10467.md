## Summary

Keep open: current main and v2026.6.11 still expose only one fixed subagent queue lane, and the remaining work is a public model-facing tool/config scheduler feature rather than conservative cleanup.

## What This Changes

Request adds caller-selected `sessions_spawn.lane` and per-lane subagent concurrency config while preserving the default `subagent` lane.

## Best Possible Solution

Define a maintainer-approved, additive `sessions_spawn.lane` contract that defaults to `subagent`, validates bounded lane names, forwards the resolved lane through native and ACP spawn paths, preserves the current scalar default, and adds compatible per-lane caps with docs and regression tests.
