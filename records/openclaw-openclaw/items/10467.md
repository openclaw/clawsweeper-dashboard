## Summary

Keep open: current main and v2026.6.11 still expose one fixed subagent queue lane, while this request adds model-facing lane selection and per-lane config semantics that need maintainer direction before implementation.

## What This Changes

Request adds caller-selected lanes to `sessions_spawn` with per-lane subagent concurrency config while preserving the default `subagent` lane.

## Best Possible Solution

Define a maintainer-approved additive `sessions_spawn.lane` contract that defaults to `subagent`, validates bounded lane names, forwards the resolved lane through native and ACP spawns, preserves the scalar global safety cap, and adds compatible per-lane caps with docs and regression tests.
