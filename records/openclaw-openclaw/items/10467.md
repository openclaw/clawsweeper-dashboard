## Summary

Keep this issue open: the requested sub-agent isolation remains absent from both v2026.6.11 and current main, no related item safely owns this exact behavior, and maintainer direction is still needed for the public scheduling contract.

## What This Changes

## Best Possible Solution

Define one bounded scheduler contract with validated isolation groups, per-group and aggregate limits, and shared observability, then apply it consistently to native and ACP spawns while preserving the existing default lane.
