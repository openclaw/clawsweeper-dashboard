## Summary

Keep open: current main and v2026.6.11 still lack caller-selected subagent queue lanes, and the requested tool/config scheduler contract needs maintainer direction before implementation.

## What This Changes

Request adding an optional `lane` parameter to `sessions_spawn` plus per-lane subagent concurrency configuration with `subagent` as the default fallback.

## Best Possible Solution

Define a maintainer-approved, additive `sessions_spawn.lane` contract that defaults to `subagent`, validates bounded lane names, forwards the resolved lane through native and ACP spawn paths, preserves the scalar default, and adds compatible per-lane caps with docs and regression tests.
