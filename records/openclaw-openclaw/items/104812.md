## What This Changes

The PR changes Moonshot/Kimi web search to resolve the configured API key through the shared SecretRef-aware credential resolver and adds regression coverage for configured refs, normal environment fallback, and missing-reference failure.

## System Context

The Moonshot plugin supplies Kimi as a web-search provider. Its tool setup receives plugin configuration, resolves the credential before a search request is made, then either sends an authenticated request or reports a missing-key error without contacting Kimi.

## Best Possible Solution

Adopt the shared resolver so Kimi matches other web-search providers, but merge only after the credential owner explicitly accepts fail-closed behavior for an unresolved configured SecretRef and documents any intended upgrade expectation in the PR discussion.
