## Summary

Keep open: current main and the latest release still ignore `agentId` and `sessionKey` on mapped `action: "wake"` hooks, while the linked fixing PR remains open and conflicting rather than merged.

## What This Changes

The issue reports that mapped wake hooks accept `agentId` and `sessionKey` but dispatch ignores them and wakes the default main session.

## Best Possible Solution

Review, rebase, prove, and land https://github.com/openclaw/openclaw/pull/70268 or an equivalent narrow fix that routes mapped wake hooks through the existing hook agent/session policy before closing this issue.

## Solution Assessment
