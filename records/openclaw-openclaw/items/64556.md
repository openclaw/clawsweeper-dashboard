Keep open: current main and the latest release still drop wake-mapping agent/session fields, and the linked fixing PR is still open rather than merged.

## What This Changes

Mapped `action: "wake"` webhook hooks should honor configured `agentId` and `sessionKey` instead of silently waking the main session.

## Best Possible Solution

Rebase, prove, and land https://github.com/openclaw/openclaw/pull/70268, or replace it with a narrow equivalent that threads mapped wake routing through the existing hook agent/session policy helpers.
