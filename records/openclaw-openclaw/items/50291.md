## Summary

Keep open: current main has implemented useful runId, sender, sessionKey, and trace-carrier slices, but the central Plugin SDK trace-correlation contract is still incomplete across agent context, outbound message, and subagent parent/child hook surfaces.

## What This Changes

Request to add uniform trace-correlation fields to Plugin SDK hook events and contexts so observability plugins can build accurate trace trees across concurrent runs, outbound messages, and subagents.

## Best Possible Solution

Define one additive Plugin SDK trace-correlation contract covering agent lifecycle identity, outbound message run/message correlation, and subagent requester/child run IDs, then update docs, API baselines, and focused hook tests together.
