## Summary

Current main has added useful trace primitives and runId coverage for some lifecycle hooks, but the issue's central request is not fully implemented: outbound `message_sending` still lacks run/message correlation context and subagent hooks still do not expose a complete parent/child run relationship.

## What This Changes

Request to expose stable trace correlation fields such as messageId, runId, parentSpanId, and subagent parent/child run identifiers across Plugin SDK hooks for observability plugins.

## Best Possible Solution

Define one additive Plugin SDK trace-correlation contract covering lifecycle hooks, outbound message hooks, and subagent parent/child run identity, then update docs, API baselines, and focused hook tests together.
