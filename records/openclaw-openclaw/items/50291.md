## Summary

Keep open: current main and the latest release only partially address the request. Agent lifecycle hooks now carry runId and message hook contexts have some correlation fields, but outbound message hooks still lack end-to-end run correlation and subagent hooks still lack a requester/child run hierarchy for deterministic trace trees.

## What This Changes

The issue requests a richer Plugin SDK hook trace context, including message/run/span identifiers across agent lifecycle, message, and subagent hooks.

## Best Possible Solution

Define one additive Plugin SDK trace-correlation contract, reconcile the open agent-start and outbound-message slices into it, then implement the agreed fields with docs, API baseline updates, and focused hook-family tests.
