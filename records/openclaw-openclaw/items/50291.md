## Summary

Keep open: current main has partial hook correlation support, but the requested public Plugin SDK trace contract still remains incomplete across outbound run identity, compaction events, subagent requester-run hierarchy, and first-class span aliases.

## What This Changes

The issue requests richer Plugin Hook trace context, including message identity, run identity, sender identity, and parent/current span metadata across agent, message, compaction, and subagent hooks.

## Best Possible Solution

Define one additive Plugin SDK trace-correlation contract, then wire agent, message, compaction, and subagent hook families consistently with docs, API baselines, and focused regression tests.
