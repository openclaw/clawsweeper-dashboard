## Summary

Keep open: current main has partial correlation work, including runId backfill for legacy agent lifecycle hooks and message context fields, but the broad Plugin SDK trace-context request remains incomplete for outbound delivery, agent-context message/span aliases, and subagent requester-run hierarchy.

## What This Changes

Request to add Plugin SDK hook trace and correlation fields such as messageId, runId, senderId, parentSpanId, and subagent requester/child run IDs across hook families.

## Best Possible Solution

Define one minimized additive Plugin SDK trace-correlation contract, then wire agent, outbound message, and subagent hook families consistently with docs, API baseline updates, and focused hook-order/correlation tests.
