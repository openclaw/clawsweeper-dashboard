Full review comments:

- **[P1] Keep newline expansion inside the chunking limit:** `extensions/feishu/src/send.ts:586`
  - body: Normal outbound and reply-dispatcher Feishu text is chunked to the channel limit before it reaches `sendMessageFeishu`. Expanding single newlines here happens after those chunks are produced, so a newline-heavy chunk that was within the 4000-character cap can grow past the advertised limit and fail as one oversized post instead of being split.
  - confidence: 0.88
- **[P2] Upgrade breaks next to code regions:** `extensions/feishu/src/send.ts:619`
  - body: The helper slices text around each code region and runs the newline regex inside each slice. A newline immediately before or after an inline or fenced code region sits at a slice edge, so the lookbehind/lookahead cannot see the non-newline character on the other side and the break stays single; Feishu can still collapse `before\n`code`\nafter`. This is a late finding on code unchanged since the prior review cycle.
  - late: true
  - confidence: 0.79
