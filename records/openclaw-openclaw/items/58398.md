## What This Changes

The issue asks OpenClaw to adopt several Claude Code-inspired compaction ideas, including pre-summarization tool-output pruning, scratchpad summarization, post-compact restoration, partial compaction, transcript recovery, and persistent session memory.

## Best Possible Solution

Keep this as the canonical product-design issue until maintainers decide which compaction layers belong in core, which can be delegated through compaction providers, and what security boundaries apply to transcript references, file restoration, and session memory.
