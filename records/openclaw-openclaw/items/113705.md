This draft replaces several OpenClaw filesystem locking, publication, archive, secret-read, directory-walk, hashing, and Windows ACL implementations with fs-safe 0.5 primitives while adding archive, root-walk, and secret-file plugin SDK subpaths.

OpenClaw core and bundled plugins use filesystem helpers for credentials, gateway locks, archives, snapshots, and local staging. This PR routes those callers through fs-safe 0.5 and exposes selected bounded filesystem operations to plugins through the public SDK.
