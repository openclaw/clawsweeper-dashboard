## What This Changes

This PR upgrades OpenClaw to `@openclaw/fs-safe` 0.5, replaces duplicated filesystem safety helpers across core and bundled plugins, updates `tar`, and adds public SDK subpaths for bounded archives, root-bounded walks, and secret files.

## System Context

OpenClaw core and bundled plugins perform archive extraction, publication, secret reads, locking, snapshots, and directory scans on local files. This PR routes those operations through fs-safe primitives, then exposes selected helpers through the Plugin SDK for bundled and external plugin consumers.
