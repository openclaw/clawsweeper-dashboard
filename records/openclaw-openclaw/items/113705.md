## What This Changes

This PR upgrades OpenClaw to `@openclaw/fs-safe` 0.5, replaces duplicated filesystem-safety helpers across core and bundled plugins, updates `tar`, and adds public SDK entrypoints for archive handling, root-bounded walks, and secret files.

## System Context
