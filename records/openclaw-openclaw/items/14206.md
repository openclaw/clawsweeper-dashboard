## What This Changes

This issue requests configurable Feishu channel outbound message pacing so bursty chunked replies do not trigger Feishu API frequency bans.

## Best Possible Solution

Review and land, replace, or deliberately reject https://github.com/openclaw/openclaw/pull/96513 with Feishu-plugin-local, default-off per-account/per-target pacing that covers burstable text, card, media, comment, and streaming-card send surfaces.
