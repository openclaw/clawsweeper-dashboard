## Best Possible Solution

## Solution Assessment

Yes. Reusing the existing Feishu reply fallback helper in the media senders and threading the dispatcher flag is the narrowest maintainable fix; duplicating custom catch logic in `media.ts` would be a less reliable parallel contract.
