## Summary

Keep open: current main still has before_tool_call policy hooks, trusted tool policies, sessions_spawn, sandbox checks, and plugin trust documentation, but it does not expose a plugin-returned quarantined execution directive or standardized isolated-result trust metadata. This remains a security-sensitive Plugin SDK/runtime design item, not a cleanup-close candidate.

## What This Changes

The issue requests a public Plugin SDK/runtime mechanism for plugins to request isolated or quarantined execution with constrained capabilities and provenance/trust metadata.

## Best Possible Solution

Design an additive Plugin SDK/runtime isolation contract that reuses existing sessions_spawn, sandbox, tool-policy, session, and provenance primitives with explicit enforceable guarantees before exposing it to plugins.
