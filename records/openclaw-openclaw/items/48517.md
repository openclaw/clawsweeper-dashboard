## Summary

Keep open: current main still has adjacent before_tool_call, subagent, sandbox, and plugin trust primitives, but it does not expose a plugin-returned quarantined execution directive with constrained capabilities and standardized trust/provenance metadata. This remains a security-sensitive Plugin SDK/runtime design item rather than a cleanup-close candidate.

## What This Changes

The issue requests a public plugin hook/runtime capability that lets plugins ask OpenClaw to run untrusted work in an isolated session and return quarantined results with trust metadata.

## Best Possible Solution

Design an additive Plugin SDK/runtime isolation contract that reuses existing sessions_spawn, sandbox, tool-policy, session, and provenance primitives with explicit enforceable guarantees before exposing it to plugins.
