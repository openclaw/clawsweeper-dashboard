## Summary

Keep open: current main and v2026.6.11 still have adjacent primitives for before_tool_call decisions, subagent spawning, sandbox requirements, and isolated child context, but they do not implement a plugin-returned quarantine directive with constrained execution and trust/provenance metadata. This remains a security-boundary Plugin SDK/runtime design item.

## What This Changes

Request a Plugin SDK/runtime capability for plugins to ask OpenClaw to run untrusted work in an isolated session and return a provenance-tagged result.

## Best Possible Solution

Design an additive Plugin SDK/runtime isolation contract that reuses sessions_spawn, sandbox, tool-policy, session, and provenance primitives with explicit enforceable guarantees before exposing it to plugins.

- **Close As Out Of Scope:** Reject plugin-requestable trust-boundary execution if maintainers decide strong isolation must stay at separate gateway or OS-host boundaries.
