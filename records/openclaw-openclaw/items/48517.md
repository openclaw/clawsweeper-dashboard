## Summary

Keep open: current main and v2026.6.11 still lack a plugin-returned isolation directive with constrained execution and provenance/trust metadata. This is a public Plugin SDK/runtime security-boundary design item, not conservative cleanup.

## What This Changes

Request to let plugin hooks ask the runtime to execute untrusted work in a constrained isolated context and return provenance or trust metadata.

## Best Possible Solution

Keep this as a design item for an additive Plugin SDK/runtime isolation contract that reuses existing sessions_spawn, sandbox, tool-policy, session, and provenance primitives with explicit enforceable guarantees.
