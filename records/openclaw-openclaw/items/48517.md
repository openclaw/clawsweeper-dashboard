## Summary

Keep open: current main has adjacent before_tool_call controls, plugin approvals, and sandboxed sub-agent delegation, but not the requested plugin-returned quarantined execution directive with constrained runtime execution and structured trust/provenance metadata.

## What This Changes

Request a Plugin SDK/runtime feature that lets plugins ask for isolated/quarantined execution from a hook and receive result provenance or trust metadata.

## Best Possible Solution

Keep this as a maintainer-owned security design item until the Plugin SDK contract names the isolation guarantee, enforcement owner, constrained tool model, and standardized result provenance shape.
