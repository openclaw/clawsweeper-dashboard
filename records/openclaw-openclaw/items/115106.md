## What This Changes

The PR changes Claude and Pi adopted-session transcript scans to use a shared bounded range reader so complete JSONL rows are still detected when positional file reads return short.

## System Context

Adopted-session polling reads appended Claude and Pi transcript rows, classifies complete external user turns, and sends activity back into session handling. This PR replaces each scanner’s one-read buffer fill with a shared bounded reader before the scanners decide whether to advance their cursors.
