## System Context

Channel setup wizards read a channel account’s existing configuration, let an operator choose a DM policy, then write the resulting policy and allowlist patch back to canonical channel config. This PR moves the shared policy-descriptor behavior into the plugin SDK while retaining channel-specific account resolution and patch logic.
