This PR adds the public `openclaw/plugin-sdk/channel-dm-policy` factory and migrates bundled channel setup code to use it for account-aware direct-message policy and allow-list updates.

## System Context

Channel plugins expose setup wizards that read account-specific configuration and write DM access policy plus `allowFrom` values. This factory sits between each plugin's account/config adapter and the common setup UI, producing config keys and patches that the setup workflow persists.
