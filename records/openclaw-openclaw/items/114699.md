## Summary

Keep this PR open, but do not merge it as a resolution for the linked CLI compaction report. The proposed guard suppresses the reported `trim()` exception, while the linked report still identifies an unresolved session-compaction path that sees only a thin CLI-session mirror and can rotate the session with an unusable summary.

## What This Changes

This PR changes CLI session binding normalization so a missing binding or session ID returns without calling `trim()`.

## System Context

CLI-backed agents keep their authoritative conversation in the CLI harness while OpenClaw maintains a session binding and mirror used by agent and compaction flows. A compaction request passes through session preparation and binding updates before producing a summary or preserving the session transcript.

## Best Possible Solution

Define the supported RPC compaction behavior for CLI-backed sessions, then implement that boundary so absent mirrored content returns an explicit safe outcome or compacts the authoritative CLI transcript without replacing useful session history; cover both the direct RPC and mid-turn paths.
