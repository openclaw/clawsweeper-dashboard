## What This Changes

The PR caps model-supplied `maxBytesMb` and `maxImages` values for the image agent tool at 100, exposes those limits in the tool schema, logs clamping, and adds regression tests.

## System Context

The image agent tool accepts model-generated image references and optional limits, then sends those limits into image loading and compression. Its parameter boundary determines how much work and memory later media-processing stages may receive.
