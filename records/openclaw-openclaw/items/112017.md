## What This Changes

The PR caps model-supplied `maxBytesMb` and `maxImages` values for the image agent tool at 100, advertises those maxima in the tool schema, logs clamping, and adds regression tests.

## System Context

The image agent tool accepts model-generated image references and media limits, then validates the request before running image preparation and vision-model routing. These two limits govern how much image input reaches the media-processing path and how many references pass the tool's preflight gate.
