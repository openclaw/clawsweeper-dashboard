## What This Changes

Prevent isolated cron jobs using the Claude CLI backend from treating fresh streaming progress as a stuck session and invoking recovery against the live run.

## System Context

Isolated cron jobs create agent sessions that report diagnostic activity while a backend streams output. The diagnostic heartbeat classifies session state and can request recovery; that decision affects whether the live run, its lane bookkeeping, and later scheduled jobs continue normally.

## Best Possible Solution

Verify an isolated Claude CLI cron run on v2026.7.1 or current main for the reported fresh-progress signature; close as implemented if recovery no longer runs while progress is fresh, and retain a narrower issue only if the later `runtime-plugins` stall still occurs independently.
