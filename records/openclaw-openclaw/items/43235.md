## Summary

Issue #43235 is still necessary: current main and the latest checked release still route normal embedded agent runs into the shared `main` global lane, while previous implementation PRs were closed without landing and the remaining design needs owner-backed config and scheduler direction.

## What This Changes

The issue requests per-agent command-lane configuration so long-running agents can be isolated from the shared main queue in multi-agent deployments.

## Best Possible Solution

Keep #43235 open as the canonical per-agent foreground lane design item and land only an owner-backed config/schema/docs/runtime/test change that preserves current defaults for existing deployments.
