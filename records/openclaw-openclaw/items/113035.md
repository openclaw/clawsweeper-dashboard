## What This Changes

Changes the browser extension’s Copilot gateway client to exponentially back off approval-required reconnects and updates the side panel to explain that device approval is pending and connection will resume automatically.

## System Context

The browser extension’s Copilot side panel connects a browser device identity to an OpenClaw gateway. Gateway connection failures become retry decisions and status updates, which then control both reconnection timing and the user-facing pairing state.
