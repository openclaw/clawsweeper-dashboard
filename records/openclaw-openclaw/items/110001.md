## Label Justifications

- `P1`: A cache-key collision can silently route an inbound conversation and its session context to the wrong configured agent.

## Summary

Keep open: the structured key fixes the demonstrated tab and comma boundary collisions, but missing guild and team values are still encoded as `"-"`, so an actual `"-"` identifier can collide and reuse another context's cached agent. The contributor's after-fix output also remains an isolated in-memory run rather than real gateway or channel proof.

## What This Changes

The PR replaces delimiter-concatenated route-result cache keys with JSON-encoded inputs and adds regression tests for peer/guild tab collisions and role-ID comma collisions.

## Best Possible Solution

Serialize nullable cache components as actual `null` values and peer identities as structured tuples, retain sorted role arrays, add absent-versus-hyphen guild and team regressions, and provide redacted gateway logs showing distinct agents selected in one running process.
