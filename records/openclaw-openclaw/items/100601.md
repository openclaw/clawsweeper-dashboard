Overall correctness: patch is incorrect

Full review comments:

- **[P2] Require the lock before mutating records:** `apps/macos/Sources/OpenClaw/PortGuardian.swift:592`
  - body: `withRecordFileLock` falls back to `body()` when the lock file cannot be opened and ignores the result of `flock(fd, LOCK_EX)`. If either step fails, the shared `port-guard.json` read-merge-write still runs unlocked and can clobber a sibling instance's tunnel record, which is the failure this PR is trying to remove.
  - confidence: 0.9
- **[P2] Persist kept own records during no-op reaps:** `apps/macos/Sources/OpenClaw/PortGuardian.swift:146`
  - body: When disk is missing or stale but this instance's live tunnel is still in `plan.keep`, `removals` is empty and this early return skips rewriting `port-guard.json`. A later crash then leaves that live tunnel unrecorded and unreapable, so the reap path should also restore kept owned records when disk no longer matches them.
  - confidence: 0.88
