## Summary

## What This Changes

The PR threads `ExecSecurity` into exec script preflight, skips the ambiguous-interpreter fail-closed heuristic whenever security is `full`, adds regression tests for full-security fail-closed cases, and updates exec docs.

## Best Possible Solution

Land only after maintainers either keep the bypass scoped to the current YOLO `security=full` plus `ask=off` contract or explicitly approve the broader full-security policy with aligned docs, tests, and live proof.

## Reproduction Assessment

## Solution Assessment

No. The PR is a plausible policy expansion, but the safest maintainable fix is to keep the fail-closed bypass tied to the established YOLO contract unless maintainers explicitly approve changing full-security approval modes too.
