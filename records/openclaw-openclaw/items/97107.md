The PR threads `security` into exec script preflight, skips the ambiguous-interpreter fail-closed heuristic whenever `security` is `full`, adds tests for that policy, and updates exec docs.

## Best Possible Solution

A maintainer should either approve the broader `security=full` trust policy and require matching docs plus real exec proof, or narrow the code and docs back to the shipped `security=full && ask=off` YOLO boundary.

## Solution Assessment
