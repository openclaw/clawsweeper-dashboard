## Summary

Keep open: current main and v2026.6.11 still carry the core streaming scanner mismatch. The shared final sanitizer accepts attribute-bearing reasoning tags, but the embedded streaming scanner does not, so hidden reasoning can still be treated as visible channel text before final sanitization runs.

## What This Changes

The issue asks OpenClaw to stop exposing internal agent thinking/planning text in user-visible messaging replies.

## Best Possible Solution

Unify the embedded streaming scanner with the shared reasoning-tag grammar, including attributes and known namespaces, then add focused streamed chunk-boundary regression tests.
