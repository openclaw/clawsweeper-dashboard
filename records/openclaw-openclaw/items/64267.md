## Summary

Keep open: current main and v2026.6.11 still have a source-level mismatch where the embedded streaming scanner misses attribute-bearing thinking tags, while the shared final sanitizer strips them; related open issues cover broader default-policy and inter-tool text leaks, but they do not replace this narrower core streaming sanitizer gap.

## What This Changes

The issue reports that OpenClaw sends internal agent reasoning/thinking text to users in chat responses, especially after the 2026.4.9 upgrade.

## Best Possible Solution

Unify the embedded streaming scanner with the shared reasoning-tag grammar, including attributes and known namespaces, then add focused streamed attribute-tag regression coverage before closing this issue.
