Keep open: current main and the latest release still have a source-level mismatch where the embedded streaming scanner misses attribute-bearing thinking tags while the shared final sanitizer strips them, so the reported internal-reasoning exposure remains a core security/privacy bug.

## What This Changes

The issue reports internal agent thinking/planning text leaking into user-visible chat responses after an OpenClaw 2026.4.9 upgrade, observed through the WeChat plugin and across multiple models.

## Best Possible Solution

Unify the embedded streaming scanner with the shared reasoning-tag grammar, including attributes and known namespaces, and add focused streamed/chunk-boundary regression tests that preserve code literals and explicit reasoning output.
