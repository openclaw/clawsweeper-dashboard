## What This Changes

The issue reports that WebChat restores visible session history after restart, but the next `chat.send` does not include that persisted history in the model context.

Keep this issue open until https://github.com/openclaw/openclaw/pull/96391 or an equivalent gateway/session fix lands, with proof that `chat.history` and the following `chat.send` use the same stored session context without breaking idle/daily reset semantics.
