## Summary

Keep open. ## What This Changes

The issue reports intermittent failed `web_search` calls when configured to use Ollama, with the returned error claiming DuckDuckGo requires a query despite a non-empty query being supplied.

## Best Possible Solution

Verify the failure against a signed-in Ollama host, then either document the Ollama proxy/hosted behavior clearly, improve provider error diagnostics, or add maintainer-approved fallback semantics under the existing web-search provider contract.
