## Summary

Keep open for landing: current main still allows the startup identity request to wait indefinitely, while the prior request-lifecycle blocker is resolved and the current patch is correct, narrowly scoped, and supported by convincing transport-level proof.

## What This Changes

Adds a dedicated Slack WebClient with a 10-second timeout, no retries, and immediate rate-limit rejection for the startup `auth.test` call, plus regression coverage for timeout, socket closure, preserved transport options, and degraded startup ordering.

## Best Possible Solution

Keep the timeout isolated to the one-shot startup identity client, preserve the resolved proxy agent and Slack API root, leave Bolt's long-lived listener transport unchanged, and retain regression proof that timeout failure closes the socket before degraded startup continues.
