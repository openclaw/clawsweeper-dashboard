## Summary

Keep this PR open: the explicit retry loop fixes the current curl retry-boundary flaw, but the new IPv4 parser accepts a trailing dot, allowing malformed endpoint output to reach the AWS ingress command.

## What This Changes

Replaces curl-managed runner-IP retries with three bounded Bash attempts, clears failed partial output, validates IPv4 octets, and expands the executable CI workflow guard.

## Best Possible Solution

Keep the explicit bounded retry loop and failed-output clearing, but validate the complete IPv4 string shape before checking octet ranges and add a trailing-dot regression case before merge.
