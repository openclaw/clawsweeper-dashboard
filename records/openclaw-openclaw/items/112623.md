## What This Changes

This PR adds a capped 30-minute summary of recently completed subagents to later parent-agent prompts, with separate guidance for successful and unsuccessful child outcomes.

## System Context

Parent agents receive runtime-generated prompt context from the subagent registry. This change makes recent terminal child-run information available on later parent turns, influencing whether the parent yields, retries, recovers, or starts new work.
