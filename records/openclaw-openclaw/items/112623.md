## Summary

This PR addresses a plausible orchestration gap, but it adds a new dynamic parent-prompt behavior and changes its retention default to 120 minutes without maintainer-confirmed product direction or real runtime evidence. Keep it open for an agents-area decision and an after-fix gateway transcript that demonstrates reduced duplicate spawning without suppressing legitimate retries.

## What This Changes

The PR injects recently completed child-run status, task, and identifier data into later parent-agent prompts for 120 minutes, adds focused unit coverage, and documents the new prompt block.

## System Context

OpenClaw records subagent lifecycle state and returns completion events to the parent/requester agent. The parent prompt currently receives active-child context for orchestration; this PR would also feed recently ended child metadata into later model turns.
