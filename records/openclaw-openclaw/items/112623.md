## What This Changes

This PR injects up to eight newest recently completed child-run anchors from the 30-minute registry window into subsequent parent-agent system prompts, with tests and documentation.

## System Context

OpenClaw records subagent runs in a registry and adds runtime-owned status context to later parent-agent turns. This change carries bounded completed-run status into that prompt so a parent can recognize work that has already finished while leaving the normal completion handoff separate.
