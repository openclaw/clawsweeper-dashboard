## Summary

This focused feature patch is plausibly correct and current main does not yet expose the documented recently-completed context block, but it remains a merge blocker until the contributor shows an after-fix runtime trace in which a parent sees a completed child on a later turn and avoids re-spawning it. The proposed 120-minute default also changes prompt content for existing orchestrations, so maintainers should evaluate real prompt-size and retry behavior before accepting the product direction.

## What This Changes

The PR injects recently completed subagent status into later parent-agent prompts for a 120-minute window, adds focused unit coverage, and documents the new context block.

## System Context

OpenClaw records spawned child-agent runs and injects active run state into the parent agent's next system prompt. This change would also feed recently finished run identifiers, status, labels, and tasks into that prompt so the parent can decide whether work has already completed.
