## Summary

Keep this PR open. The new completion anchor is demonstrated by a redacted later-turn runtime trace and extends the existing active-subagent prompt pattern, but the patch injects every recently completed child from the 30-minute window into every later parent prompt with no count or byte budget. That can turn bursty sequential subagent work into prompt growth or context-limit failures; cap the retained entries before merge.

## What This Changes

This PR adds a runtime-generated “Recently Completed Subagents” section to parent-agent prompts, documents it, and tests the 30-minute completion window.

## System Context

OpenClaw’s parent agent receives runtime-generated subagent state before each normal turn. The state comes from the subagent run registry and influences whether the parent waits, synthesizes a child result, or starts more work.

## Architecture Diagram

flowchart LR
  A[Parent agent turn] --> B[Subagent run registry]
  B --> C[Build active and recent lists]
  C --> D[Prompt context formatter]
  D --> E[Parent system prompt]
  E --> F[Spawn, yield, or synthesize response]
  G[Completed child runs] --> C

## Best Possible Solution

Retain the completion-anchor feature, but render only a deterministic, newest-first bounded subset of recent entries within a defined prompt budget, add regression coverage for that limit, and update the PR description to the 30-minute default.
