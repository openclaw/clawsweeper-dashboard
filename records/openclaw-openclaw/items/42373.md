## Summary

Keep open: current main and v2026.6.11 still treat configured model costs as USD local estimates, while provider-reported billing can display provider units separately; this remains a product/config contract decision rather than implemented cleanup.

## What This Changes

Request a `costCurrency` configuration option so locally configured model-cost estimates can display CNY, EUR, USD, or another currency instead of always using dollars.

## Best Possible Solution

Define a durable local model-cost currency contract first: scope, ISO validation, display versus accounting semantics, mixed-currency aggregation, persisted naming, docs, and focused regression coverage.
