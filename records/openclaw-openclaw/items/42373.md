## Summary

Keep open: current main still has no `costCurrency` or non-USD contract for configured local model-cost estimates; related usage and provider-billing work added adjacent cost visibility but kept local estimates USD-shaped.

## What This Changes

Request to add a `costCurrency` configuration option so configured model-cost estimates can display currencies such as CNY, RMB, or EUR instead of always `$`.

## Best Possible Solution

Define the local model-cost currency contract first, including scope, ISO validation, display versus accounting semantics, mixed-currency aggregation, docs, and focused regression coverage.

- **Allow Display-Only Override:** Permit a narrow symbol or ISO display override while explicitly preserving USD-shaped storage and aggregate semantics.
