## Summary

Keep open: current main and the latest release still have a USD-only model-cost/session-display contract with no `costCurrency` surface, but adding currency semantics is a new config and accounting/display product decision rather than a narrow bug fix.

## What This Changes

Request to add a `costCurrency` config option so model-cost and session/status displays can show non-USD currencies such as CNY or EUR.

## Best Possible Solution

Define one currency contract first, including scope, ISO-code handling, mixed-provider aggregation, and display-only versus accounting semantics, then update schema, docs, status, usage, UI, and persisted/API names together if maintainers accept it.
