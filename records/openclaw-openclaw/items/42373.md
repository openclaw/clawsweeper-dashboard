## Summary

Keep open: current main still has no configured currency contract for local model-cost estimates, and the existing cost/status/UI surfaces remain USD-shaped despite adjacent provider-billing work.

## What This Changes

Request a costCurrency configuration option so local model-cost estimates can display CNY, EUR, or another currency instead of hard-coded dollar formatting.

## Best Possible Solution

Define the currency contract first: scope, ISO validation, local-estimate versus provider-invoice separation, mixed-currency aggregation, persisted-field semantics, docs, and focused regression coverage.
