## Summary

Keep open: current main still has no configurable model-cost currency, and the request changes public config plus USD-shaped cost accounting semantics rather than fixing a narrow bug.

## What This Changes

Request to add a `costCurrency` configuration option so configured model-cost estimates can display currencies such as CNY or EUR instead of always using USD-style output.

## Best Possible Solution

Define one cost-currency contract first: scope, ISO-code validation, mixed-currency aggregation, display-only versus accounting semantics, persisted USD fields, docs, and focused regression coverage.
