## Summary

Keep this issue open: current main still hard-codes dollar display for model/session cost surfaces, but adding `costCurrency` is a new config and model-cost contract that needs maintainer product direction first.

## What This Changes

The issue requests a configurable currency for model cost display so provider costs can be shown as CNY, EUR, or another local currency instead of always dollars.

## Best Possible Solution

Define one canonical currency contract for model-cost estimates, keep USD as the default, then propagate that contract through config/schema, model registry, session/usage UI, docs, and focused upgrade/fresh-config tests.
