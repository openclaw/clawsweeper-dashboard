## Summary

Keep open: current main and the latest release still use a USD-only model cost contract with dollar-format display, while adding a configurable currency is a cross-surface config/accounting decision rather than a narrow bug fix.

## What This Changes

Request to add a `costCurrency` configuration option so model cost estimates can display non-USD currencies such as CNY or EUR.

## Best Possible Solution

Define one currency contract first, including ISO-code versus symbol behavior, scope, mixed-currency aggregation, and display-only versus accounting semantics, then update schema, docs, status, usage, UI, and telemetry surfaces together.
