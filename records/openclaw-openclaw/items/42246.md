## Summary

Keep open: current main and v2026.6.11 still lack configurable timed outbound Telegram digest aggregation, and the remaining work is a product/config decision rather than conservative cleanup.

## What This Changes

Request an opt-in Telegram outbound notification batching layer that collects short events over a configurable window and sends fewer digest messages.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and flushes through existing durable delivery and Telegram throttling.
