## Summary

Keep open: current main still lacks configurable timed outbound Telegram notification digest aggregation, and the related items solve adjacent throttling, one-turn text coalescing, inbound aggregation, or stream overflow rather than this product/config decision.

## What This Changes

The issue requests an opt-in Telegram outbound notification aggregator that batches many short automation events into fewer digest messages with configurable flush and grouping behavior.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and routes flushed digest payloads through existing durable delivery and Telegram throttling.
