## Summary

Keep open: current main and v2026.6.11 still have durable Telegram sends, throttling, and streaming/status coalescing, but not the requested timed outbound notification digest layer; the remaining work needs maintainer direction on product policy, config shape, durability, and urgent-message bypass behavior.

## What This Changes

Add opt-in Telegram outbound notification batching so bursts of short events can be delivered as digest messages instead of immediate one-event sends.

## Best Possible Solution

Define an opt-in digest policy seam above final Telegram transport, persist pending digest state in SQLite when durability is required, and route completed digest payloads through the existing durable delivery and throttled Telegram send paths.
