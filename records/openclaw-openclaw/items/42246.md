## Summary

Keep open: current main still lacks configurable timed digest aggregation for independent outbound Telegram notifications, and the remaining work needs maintainer product/config direction rather than automatic cleanup.

## What This Changes

Request an opt-in Telegram outbound notification batching layer that groups bursty events into digest messages with configurable interval, max size, grouping, and shutdown flush behavior.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and flushes through the existing durable delivery and Telegram throttling paths.
