## Summary

Keep open: current main still lacks an opt-in timed Telegram notification digest; existing durable sends, chunking, throttling, and the cosmetic per-turn progress summary do not aggregate independent outbound notifications.

## What This Changes

The issue requests configurable outbound Telegram batching that groups short notifications into digest messages over a time window.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and flushes through existing durable delivery and Telegram throttling.
