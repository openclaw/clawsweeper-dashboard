## Summary

Keep open: current main and the latest release still lack timed outbound Telegram notification digest aggregation, and the remaining work needs maintainer direction on policy, config, durability, and bypass semantics.

## What This Changes

The issue requests an opt-in Telegram outbound notification batching layer that groups bursts of short events into digest messages.

## Best Possible Solution

Define an opt-in digest policy seam above final Telegram transport, persist pending digest state in SQLite when durability is required, and route completed digest payloads through the existing durable delivery and throttled Telegram send paths.
