## Summary

Keep open: current main still lacks configurable timed outbound Telegram notification digest aggregation, and the remaining work is a product/config decision rather than conservative cleanup.

## What This Changes

Request an opt-in Telegram outbound notification batching layer that aggregates many short automation events into digest messages.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and routes flushed digest payloads through existing durable delivery and Telegram throttling.
