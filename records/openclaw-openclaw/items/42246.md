## Summary

Keep open: current main still lacks configurable timed outbound Telegram notification digest aggregation, and the related items cover adjacent throttling, stream preview, inbound aggregation, or single-turn coalescing rather than this product/config decision.

## What This Changes

Add an opt-in batching/digest layer for outbound Telegram notifications so bursts of short automation events can be grouped before delivery.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and flushes through existing durable delivery and Telegram throttling.
