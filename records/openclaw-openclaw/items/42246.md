## Summary

Keep open: current main and v2026.6.11 still lack configurable outbound Telegram digest aggregation. Existing inbound debounce, streaming/progress coalescing, durable payload batching, and throttling do not collect independent outbound notifications into timed grouped messages, and the config/durability semantics need maintainer product direction.

## What This Changes

Add opt-in batching and digest formatting for outbound Telegram notifications so high-volume background events send as fewer grouped messages.

## Best Possible Solution

Define a maintainer-approved outbound digest policy seam above final Telegram transport, persist pending digest state in SQLite when durability is required, and route completed digest payloads through the existing durable delivery and Telegram throttling paths.
