## Summary

Keep open: current main and v2026.6.11 still lack configurable timed outbound Telegram notification digest aggregation, and the related items solve adjacent throttling, single-turn text coalescing, inbound aggregation, WhatsApp batching, or stream overflow rather than this product/config decision.

## What This Changes

Request an opt-in Telegram batching layer that aggregates many outbound OpenClaw notifications into digest messages with configurable timing, grouping, flush, and durability behavior.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that keeps immediate delivery as the default, persists pending digest state when durability is required, and flushes through the existing durable delivery and Telegram throttling paths.
