## Summary

Keep open: current main and the latest release still lack configurable timed outbound Telegram digest aggregation, and the remaining work is a product/config decision rather than conservative cleanup.

## What This Changes

Request to add an opt-in outbound Telegram notification batching/digest layer with configurable interval, max batch size, grouping, and shutdown flush behavior.

## Best Possible Solution

Define an opt-in Telegram-owned or shared outbound digest policy that preserves immediate delivery by default, uses durable state when buffering must survive failure, and flushes through the existing Telegram send/throttling paths.
