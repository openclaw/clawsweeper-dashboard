## What This Changes

The issue requests a real session-stable bootstrap snapshot or equivalent cache-boundary/documentation fix to prevent mid-session writes to bootstrap-injected files from repeatedly invalidating prompt cache on long sessions.

## Best Possible Solution

Choose and document one supported prompt-cache contract for volatile workspace files, then implement it with schema/docs/tests and clear upgrade semantics across bootstrap loading and prompt assembly.
