## Summary

Keep open. Current main and v2026.6.11 still refresh bootstrap files from disk and replace the cached session result when content changes, while related open issues cover overlapping mitigations rather than superseding this cacheWrite/session-freeze report.

## What This Changes

The issue reports that mid-session writes to bootstrap-injected workspace files destabilize prompt-cache prefixes and cause high cacheWrite cost in long Anthropic sessions.

## Best Possible Solution

Maintainers should choose one documented prompt-cache contract, then implement it across bootstrap cache behavior, config/docs where needed, and focused cache-boundary tests without silently breaking users who rely on live bootstrap visibility.
