## Summary

Keep open: current `main`, the reported `v2026.3.8`, and latest `v2026.6.11` do not define a Feishu `ignoreFileContent` setting, while Feishu media handling still downloads supported inbound media into the agent context path. This is not cleanup-closeable because the useful remaining work is a maintainer decision on a supported Feishu attachment-ingestion policy.

## What This Changes

The issue requests that Feishu `ignoreFileContent: true` prevent inbound file downloads and send only placeholder context to the model.

## Best Possible Solution

Define a documented Feishu attachment-ingestion opt-out, keep current media downloads as the default for compatibility, and add focused tests/docs proving placeholder-only context when the opt-out is enabled.
