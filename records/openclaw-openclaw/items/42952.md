## Summary

Keep open: current main and the latest release still do not support `ignoreFileContent`, and Feishu inbound media is still downloaded and passed into agent context. The remaining work is a product/config decision, not a conservative cleanup close.

## What This Changes

The issue requests a supported Feishu setting that prevents inbound file/media content from being downloaded and sent into model context.

## Best Possible Solution

Define a Feishu-owned attachment-context policy with a backward-compatible default, documented top-level/per-account config, placeholder-only behavior when disabled, and focused tests proving no download or media fields reach the agent.
