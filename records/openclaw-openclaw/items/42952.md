## Summary

Keep open: current main, the reported release, and the latest release do not define a Feishu `ignoreFileContent` setting, while Feishu still downloads supported inbound media and projects saved media into agent context. The remaining work is a maintainer product decision on a supported Feishu attachment-ingestion policy, not conservative cleanup.

## What This Changes

Request to make Feishu skip downloading or injecting inbound file contents when an `ignoreFileContent` configuration flag is set.

## Best Possible Solution

Define a documented, backward-compatible Feishu attachment-ingestion opt-out in the plugin-owned config, defaulting to current downloads and adding tests/docs for placeholder-only context when enabled.
