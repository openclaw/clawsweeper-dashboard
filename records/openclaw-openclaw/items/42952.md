## Summary

Keep open: current main and the latest release still do not implement `ignoreFileContent`, while Feishu inbound media is downloaded and attached to the agent context. This is not a cleanup close; it needs a maintainer decision on whether Feishu should gain a supported attachment-context opt-out.

## What This Changes

The issue asks Feishu to honor `ignoreFileContent: true` by keeping uploaded file bodies out of model context and sending placeholder-only context instead.

## Best Possible Solution

Define a Feishu-owned attachment-context policy with a backward-compatible default, per-account/top-level schema and docs, placeholder-only behavior when disabled, and focused tests proving no download or `MediaPaths` reach the agent in that mode.
