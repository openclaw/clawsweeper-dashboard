## Summary

Keep open: current main and the latest release still lack a supported Feishu file-content ignore option, while inbound Feishu media is still downloaded and projected into model-facing context. Because `ignoreFileContent` is not a current documented Feishu config key, this needs maintainer product direction before a fix PR.

## What This Changes

Request for Feishu configuration to stop inbound file/media contents from being downloaded into model context.

## Best Possible Solution

Define a Feishu-owned attachment-context opt-out with a backward-compatible default, top-level and per-account schema/docs, placeholder-only behavior when disabled, and focused tests proving no download or `MediaPaths` reach the agent in that mode.
