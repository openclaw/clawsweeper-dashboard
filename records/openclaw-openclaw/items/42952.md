## Summary

Keep open: current main still has no supported Feishu `ignoreFileContent` config and still stages inbound Feishu file/media attachments into the shared media pipeline, where eligible document text can be appended to the agent-visible context. This needs a maintainer product decision rather than cleanup closure.

## What This Changes

The issue requests that Feishu `ignoreFileContent: true` prevent uploaded file contents from being downloaded or added to model context.

## Best Possible Solution

Decide the product boundary, then implement one documented control that keeps Feishu file messages as placeholders and prevents shared file-text extraction when that control is enabled.
