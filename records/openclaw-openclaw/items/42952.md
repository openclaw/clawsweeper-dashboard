## Summary

Keep open: current Feishu source still has no supported `ignoreFileContent` key, and inbound media handling downloads file/image/media attachments into the agent media context; adding or restoring an opt-out needs a plugin config/product decision.

## What This Changes

The issue asks Feishu to honor `ignoreFileContent: true` by not downloading inbound file contents for model context and sending only a file placeholder.

## Best Possible Solution

Decide the Feishu-owned contract first; if accepted, add a documented inbound media opt-out in the plugin schema/manifest/docs and make the media resolver keep a placeholder without downloading files, with focused regression coverage.
