## Summary

Keep open. ## What This Changes

The issue asks Feishu to honor `ignoreFileContent` so inbound file contents are not downloaded or included in model context.

## Best Possible Solution

Add a documented Feishu-owned inbound-media content policy, or a generic plugin SDK policy if maintainers prefer, that prevents download/model-context inclusion when disabled, with account-level precedence, docs/schema/doctor handling for any legacy key, focused tests, and live Feishu proof.
