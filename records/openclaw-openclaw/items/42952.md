## Summary

Keep open: current main and v2026.6.11 still do not define a Feishu `ignoreFileContent` setting, while the current Feishu media path downloads supported inbound media and passes media facts into the shared inbound context. The remaining work needs a maintainer decision on whether Feishu should support a documented attachment-content opt-out and what canonical config shape should own it.

## What This Changes

The issue requests a Feishu configuration option that prevents inbound file content from being downloaded into model context and uses placeholder-only context instead.

## Best Possible Solution

Define one supported Feishu attachment-ingestion policy in the Feishu plugin, keep current downloads as the compatibility default, and add docs plus focused tests for placeholder-only context when the opt-out is enabled.
