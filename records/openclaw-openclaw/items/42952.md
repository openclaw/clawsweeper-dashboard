## Summary

Keep open: current main and the latest release still lack a supported Feishu `ignoreFileContent` setting, and Feishu inbound media is still downloaded and attached to agent context. This needs maintainer direction on the supported Feishu attachment-ingestion policy rather than cleanup closure.

## What This Changes

The issue requests a Feishu setting that prevents inbound file content/media from being downloaded and included in model context while preserving a file notice.

## Best Possible Solution

Add a Feishu-owned inbound attachment opt-out only after maintainers confirm the setting name, default behavior, docs, and upgrade expectations; the implementation should keep filename/type placeholders while omitting inbound media paths from agent context.
