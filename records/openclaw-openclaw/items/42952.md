## Summary

Keep open: current main and v2026.6.11 still lack a supported Feishu attachment-content opt-out, while inbound Feishu media is downloaded and projected into agent context. The remaining work needs a maintainer product decision on the canonical config shape before a repair PR is safe.

## What This Changes

Request that Feishu honor an `ignoreFileContent`-style attachment opt-out so inbound files are represented as placeholders instead of downloaded into model context.

## Best Possible Solution

Define a documented Feishu-owned attachment-context policy with a backward-compatible default, top-level and per-account schema, placeholder-only behavior when disabled, and focused tests proving no download or `MediaPaths` reach the agent in that mode.
