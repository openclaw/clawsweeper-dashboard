The issue requests a Feishu setting that prevents inbound file contents from being downloaded and included in model context.

## Best Possible Solution

Define a Feishu-owned attachment-context policy with a backward-compatible default, top-level and per-account schema/docs, placeholder-only behavior when disabled, and focused tests proving no download or `MediaPaths` reach the agent in that mode.
