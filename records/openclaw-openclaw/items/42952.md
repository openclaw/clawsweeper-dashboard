## Summary

Keep open: current main and the latest release still do not implement a supported Feishu file-content ignore setting, while Feishu inbound media is downloaded and projected into the agent context. This is not cleanup-closeable; it needs a maintainer choice on the Feishu attachment policy shape before a repair PR.

## What This Changes

The issue requests a Feishu configuration option that prevents inbound file contents from being downloaded and included in model context, leaving only a file notification or placeholder.

## Best Possible Solution

Define a documented Feishu-owned attachment-context opt-out that defaults to current download behavior, supports top-level and per-account config, skips downloads when disabled, sends only placeholders, and has focused tests proving no `MediaPath` or saved file reaches the agent in that mode.
