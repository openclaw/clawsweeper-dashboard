## Summary

Keep open: current main still has no supported Feishu `ignoreFileContent` or equivalent attachment-context opt-out, and current Feishu inbound media is still downloaded and projected into agent context. The remaining work needs maintainer direction because the reported key is not a documented current config contract and an equivalent fix would add a new Feishu or shared channel media-ingestion policy.

## What This Changes

The issue requests that Feishu respect an `ignoreFileContent` setting so inbound files are represented by placeholders instead of downloaded content in model context.

## Best Possible Solution

Define a documented attachment-ingestion policy, preferably in the Feishu plugin unless maintainers want a shared channel media policy, with the current download behavior preserved by default and placeholder-only handling when the opt-out is enabled.
