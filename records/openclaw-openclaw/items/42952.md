The issue requests a Feishu channel setting that prevents sent file contents from being downloaded and included in model context.

## Best Possible Solution

Define a Feishu-owned attachment-context policy with a backward-compatible default, documented top-level and per-account behavior, placeholder-only handling when disabled, and focused tests proving no download or media paths reach the agent in that mode.
