## Summary

Keep open: current main and the latest release still do not define a Feishu `ignoreFileContent` setting, while Feishu continues to download supported inbound media and project saved media paths into agent context. The remaining work is a maintainer product decision on a supported Feishu attachment-ingestion opt-out, not conservative cleanup.

## What This Changes

Request for Feishu `ignoreFileContent` configuration that prevents inbound file content from being downloaded or included in model context.

## Best Possible Solution

Define a documented, default-compatible Feishu plugin attachment-ingestion opt-out that keeps current downloads as the default, emits placeholder-only context when enabled, and updates schema, docs, and focused media tests.
