## Summary

Keep open: current main and the latest release still lack a supported Feishu attachment-content opt-out, while the Feishu inbound path still downloads media and projects saved media into the agent context. The remaining decision is product/config direction, not conservative cleanup.

## What This Changes

The issue requests that Feishu respect an `ignoreFileContent`-style setting so inbound files are represented as placeholders instead of being downloaded into model context.

## Best Possible Solution

Define a Feishu-owned attachment-context policy with a backward-compatible default, documented top-level and per-account behavior, placeholder-only agent context when disabled, and focused tests proving downloads and `MediaPaths` are skipped in that mode.
