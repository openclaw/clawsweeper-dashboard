## Summary

Keep open: current main and v2026.6.11 still do not implement a Feishu `ignoreFileContent` setting, and the Feishu media path still downloads supported inbound media into the shared agent context path. This should not be closed as cleanup; it needs a maintainer decision on the supported Feishu attachment-ingestion policy.

## What This Changes

The issue asks Feishu to stop downloading or injecting inbound file content when an opt-out is configured.

## Best Possible Solution

Define one supported Feishu attachment-ingestion policy, preserve current media downloads by default for compatibility, and add tests/docs proving placeholder-only context when the opt-out is enabled.
