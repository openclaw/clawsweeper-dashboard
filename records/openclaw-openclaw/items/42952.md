## Summary

Keep open: current main and the latest release still lack a Feishu `ignoreFileContent` contract, while Feishu inbound media is downloaded and projected into agent context. This needs a maintainer product decision before a repair PR.

## What This Changes

Request to make Feishu honor an `ignoreFileContent` setting so inbound files are represented as placeholders instead of downloaded and added to model context.

## Best Possible Solution

Define a Feishu-owned attachment-context policy with a backward-compatible default, documented top-level/per-account schema, placeholder-only behavior when disabled, and focused tests proving no download or MediaPaths reach the agent in that mode.
