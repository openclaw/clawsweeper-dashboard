## Summary

Keep open: current main and the latest release do not define `ignoreFileContent`, while the Feishu inbound path still downloads file/audio/video/post media into the agent turn media payload. This needs a maintainer product decision because the likely fix is a new, documented media-ingestion config surface rather than a narrow bug fix to an existing setting.

## What This Changes

The issue asks for Feishu `ignoreFileContent: true` to prevent inbound file contents from being downloaded or included in model context.

## Best Possible Solution

Add or reject a canonical Feishu inbound-media opt-out explicitly: if accepted, implement it in the Feishu plugin schema/runtime/docs/tests with the existing default preserving downloads and a clear placeholder-only behavior.
