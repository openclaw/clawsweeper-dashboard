Keep open: current main, the reported release, and the latest release still do not define a supported Feishu `ignoreFileContent` setting, while Feishu continues to download supported inbound media and pass saved media into agent context. ## What This Changes

Request to make Feishu inbound file messages use placeholder-only context instead of downloading file contents when an attachment-ignore setting is enabled.

## Best Possible Solution

Define a documented, backward-compatible Feishu attachment-ingestion opt-out in the plugin-owned config, defaulting to current downloads and adding tests/docs for placeholder-only context when enabled.
