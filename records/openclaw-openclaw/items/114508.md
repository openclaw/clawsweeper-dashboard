## What This Changes

Adds an automatic, bounded directory of trusted searchable tool capabilities to agent system prompts when Tool Search is enabled, with documentation and gateway-fixture coverage.

## System Context

Embedded agent runs assemble a system prompt from the enabled tool configuration and policy-filtered tool catalog before sending a request to a model provider. Tool Search replaces many direct schemas with compact discovery controls; this PR also gives the model a safe summary of capabilities it can discover.
