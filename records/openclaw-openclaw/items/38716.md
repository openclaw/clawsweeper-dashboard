## Summary

Keep open. Current main still handles Slack assistant thread context without retaining event-scoped action tokens, has no `assistant.search.context` helper or dispatch path, and the related `search.messages` / broad action-parity PRs closed without landing the requested Slack RTS path.

## What This Changes

Request Slack Real-Time Search support by extracting Slack assistant action tokens and exposing a read-only search action or tool.

## Best Possible Solution

Keep this open for a maintainer-approved Slack-plugin RTS design that keeps action tokens ephemeral and scoped, exposes a typed read-only search action, preserves privacy/read-target guardrails, and lands with docs, focused tests, and live Slack proof.
