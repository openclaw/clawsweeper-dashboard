## Summary

Keep open. Current main now has Slack assistant-thread lifecycle support, but it still does not capture Slack RTS action tokens or expose an `assistant.search.context` search action; the legacy `search.messages` PRs are closed unmerged, and the broad Slack action-parity PR explicitly routed Slack search back to this issue.

## What This Changes

Request Slack RTS support by capturing Slack assistant action tokens and exposing `assistant.search.context` through a Slack-owned search/message action.

## Best Possible Solution

Add a narrow Slack-plugin-owned RTS action only after maintainers approve the token, privacy, scope, and read-target contract; keep action tokens out of config/logs/transcripts, document required scopes, add focused tests, and require redacted live Slack proof.
