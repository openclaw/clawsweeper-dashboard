## Summary

Keep open. Current main and the latest release still lack Slack RTS/action-token search, the adjacent `search.messages` PRs were closed unmerged, and the broad Slack action-parity PR was closed with Slack search explicitly left to this issue.

## What This Changes

Request support for Slack Real-Time Search by capturing Slack assistant action tokens and exposing a read-only `assistant.search.context` search action or tool.

## Best Possible Solution

Implement this as Slack-plugin-owned RTS support with a typed read-only action, event-scoped token containment, explicit scope/rate-limit docs, focused tests, and redacted live Slack proof after maintainers approve the security boundary.
