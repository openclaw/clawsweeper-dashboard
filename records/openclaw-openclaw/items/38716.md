## Summary

Keep open. Current main and the latest release still lack the requested Slack RTS path: assistant events preserve thread context but not `action_token`, Slack does not advertise or dispatch a `search` message action, and existing reads use conversations APIs rather than `assistant.search.context`.

## What This Changes

Request to add Slack Real-Time Search support by extracting assistant event `action_token` and exposing `assistant.search.context` through a Slack message action or dedicated tool.

## Best Possible Solution

Add a Slack-plugin-owned RTS action only after maintainers approve the token, privacy, scope, rate-limit, and read-target policy contract; keep event-scoped tokens out of persisted config/logs/transcripts and require focused tests plus redacted live Slack proof.
