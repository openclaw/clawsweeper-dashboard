## Summary

Keep open. Current main and v2026.6.11 still lack Slack RTS support: no action-token field is retained, no `assistant.search.context` helper exists, Slack does not advertise or dispatch a search action, and the closed legacy search PRs do not satisfy the requested assistant action-token path.

## What This Changes

Request Slack RTS support by capturing Slack assistant action tokens and exposing `assistant.search.context` as a read-only Slack message/search action.

## Best Possible Solution

Land a narrow Slack-plugin RTS design that captures the Slack action token only in the authorized event context, keeps it ephemeral, exposes a typed read-only search action, preserves explicit Slack read/privacy boundaries, and includes docs, tests, and live Slack proof.

## Solution Assessment

Unclear until maintainers choose the security contract. A narrow Slack-plugin RTS action is the maintainable shape; exposing raw tokens or reviving legacy `search.messages` as a parallel path would be weaker.
