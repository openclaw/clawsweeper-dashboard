Keep open. Current main and the latest release still lack the requested Slack RTS path: assistant events keep thread context but not `action_token`, Slack message actions do not advertise or dispatch search, and related Slack search PRs were closed unmerged.

## Best Possible Solution

Add Slack-plugin-owned RTS only after maintainers approve the token, privacy, scope, rate-limit, and read-target contract, with no persisted `action_token`, focused tests, docs, and redacted live Slack proof.
