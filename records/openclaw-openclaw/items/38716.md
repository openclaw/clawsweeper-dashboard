## Summary

Keep open. Current main still lacks the requested Slack RTS/action-token path: Slack assistant-thread handling stores context but no `action_token`, Slack actions do not advertise or dispatch an RTS search action, and the overlapping open Slack action-parity PR targets user-token `search.messages` rather than `assistant.search.context`.

## What This Changes

The issue requests Slack Real-Time Search support by capturing assistant action tokens from Slack assistant-thread events and exposing workspace search through message actions or a dedicated tool.

## Best Possible Solution

Keep this open until maintainers approve a Slack-plugin-owned RTS design that captures the action token narrowly, exposes a typed read-only `assistant.search.context` action, documents scopes/privacy/rate limits, and proves live Slack behavior without credential leakage.
