## Summary

Keep open. The current Slack implementation still handles assistant thread context without retaining event-scoped action tokens, does not expose an RTS search action, and the related search/action-parity PRs were closed without landing the requested `assistant.search.context` path.

## What This Changes

The issue requests Slack RTS support by capturing assistant event `action_token`s and exposing `assistant.search.context` through a message or dedicated tool action.

## Best Possible Solution

Keep the issue open for a maintainer-approved Slack-plugin RTS design that keeps action tokens ephemeral and scoped, exposes a typed read-only search action, preserves read-target/privacy guardrails, and lands with docs, focused tests, and live Slack proof.
