## Summary

Keep open. Current main and the latest release still lack the Slack RTS/action-token search path, and the broad adjacent Slack action PR was closed with Slack search explicitly left to this issue.

## What This Changes

Add Slack RTS workspace search by capturing Slack assistant action tokens from assistant-thread events and exposing `assistant.search.context` through a Slack message/tool action.

## Best Possible Solution

Keep the issue open until maintainers approve a Slack-plugin-owned RTS contract that narrowly contains event action tokens, exposes a typed read-only `assistant.search.context` action, documents scopes/privacy/rate limits, preserves read-target boundaries, and includes live redacted Slack proof.
