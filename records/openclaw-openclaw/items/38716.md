## Summary

Keep open. Current main and the latest release still lack Slack RTS/action-token search: assistant thread handling preserves thread context but not `action_token`, Slack does not advertise or dispatch a search action, and the related closed PRs targeted user-token `search.messages` or broader action parity rather than `assistant.search.context`.

## What This Changes

The issue requests Slack Real-Time Search support by extracting Slack assistant action tokens and exposing `assistant.search.context` through a Slack message/tool action.

## Best Possible Solution

Keep this open until maintainers approve a Slack-plugin-owned RTS design that captures event-scoped action tokens narrowly, exposes a typed read-only `assistant.search.context` action, documents scopes/privacy/rate limits, and proves live Slack behavior without credential leakage.
