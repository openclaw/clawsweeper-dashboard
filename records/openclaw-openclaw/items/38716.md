## Summary

Keep open. Current main and the latest release still lack Slack `action_token` capture and `assistant.search.context` dispatch, so the request remains a valid but security-sensitive Slack workspace-search feature needing maintainer direction.

## What This Changes

Request Slack RTS support by capturing Slack assistant action tokens and exposing `assistant.search.context` through the Slack message/tool surface.

## Best Possible Solution

Keep the issue open for a maintainer-approved Slack-plugin RTS design that keeps action tokens ephemeral and scoped, exposes a typed read-only search action, preserves read-target/privacy guardrails, and lands with docs, focused tests, and live Slack proof.
