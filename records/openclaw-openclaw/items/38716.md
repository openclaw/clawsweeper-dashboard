Keep open. Current main and the latest release still lack Slack RTS/action-token search, and the remaining work is security- and product-sensitive rather than a stale duplicate.

## What This Changes

Add Slack Real-Time Search support by capturing Slack action tokens and exposing `assistant.search.context` as a read-only Slack message/tool action.

## Best Possible Solution

Land a narrow Slack-plugin RTS design that keeps action tokens ephemeral and redacted, exposes a typed read-only `assistant.search.context` action, preserves Slack read/privacy boundaries, and includes docs, focused tests, and live Slack proof.
