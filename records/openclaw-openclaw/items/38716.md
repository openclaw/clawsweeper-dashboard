## Summary

Keep open. Current main and the latest release still lack Slack RTS/action-token search, and the remaining work crosses Slack token containment, workspace-search privacy, and public action/API shape boundaries that need maintainer direction.

## What This Changes

The issue requests Slack Real-Time Search support by capturing Slack assistant event action tokens and exposing `assistant.search.context` through a Slack message/tool action.

## Best Possible Solution

Add a narrow Slack-plugin RTS design that keeps action tokens ephemeral and scoped, exposes a typed read-only search action, preserves read-target/privacy guardrails, documents setup/scopes, and lands with focused tests plus redacted live Slack proof.
