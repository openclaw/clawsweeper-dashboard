## Summary

Keep open. Current main and the latest release still lack the requested Slack RTS path: assistant events do not capture an `action_token`, Slack message actions do not advertise or dispatch a search/RTS action, and the related Slack `search.messages` PRs were closed unmerged and do not satisfy `assistant.search.context`.

## What This Changes

The issue requests Slack Real-Time Search support by capturing assistant-event action tokens and exposing an `assistant.search.context`-backed search action to agents.

## Best Possible Solution

Define a Slack-plugin-owned RTS contract that captures the event action token narrowly, exposes a typed read-only `assistant.search.context` action, documents scopes/privacy/rate limits, and proves live Slack behavior with redacted evidence.

## Solution Assessment
