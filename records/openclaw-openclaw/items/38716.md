## Summary

Keep open. Current main and the latest release still lack the requested Slack RTS/action-token search path: assistant events preserve thread context but not `action_token`, Slack message actions do not advertise or dispatch `search`, and the existing read implementation uses Slack conversations APIs rather than `assistant.search.context`.

## What This Changes

The issue requests Slack Real-Time Search support by extracting Slack assistant action tokens from assistant events and exposing them through a Slack search action or tool.

## Best Possible Solution

Add a Slack-plugin-owned RTS action only after maintainers approve the token, privacy, scope, rate-limit, and read-target policy contract; keep event-scoped tokens out of persisted config/logs/transcripts and require focused tests plus redacted live Slack proof.
