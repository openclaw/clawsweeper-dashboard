## What This Changes

Request Slack RTS support by capturing Slack assistant-event action tokens and exposing `assistant.search.context` through a Slack-owned message/tool action.

## Best Possible Solution

Implement a narrow Slack-plugin-owned RTS contract that captures the event-scoped action token only for the authorized assistant context, keeps it non-persisted or tightly scoped and redacted, exposes a typed read-only `assistant.search.context` action, documents scopes/privacy/rate limits, and proves live Slack behavior.
