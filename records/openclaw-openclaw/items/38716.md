## Summary

Keep open. Current main and the latest release still lack the requested Slack RTS path: assistant events preserve thread context but not `action_token`, Slack does not advertise or dispatch a `search` message action, and existing reads use conversations APIs rather than `assistant.search.context`.

## What This Changes

Add Slack Real-Time Search support by capturing assistant action tokens and exposing a Slack-owned search action or tool.

## Best Possible Solution

Add a Slack-plugin-owned RTS action only after maintainers approve token containment, privacy, scope, rate-limit, and read-target policy rules; keep event-scoped tokens out of persisted config/logs/transcripts and require focused tests plus redacted live Slack proof.
