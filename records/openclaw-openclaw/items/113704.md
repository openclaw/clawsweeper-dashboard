## Summary

## What This Changes

The issue requests a host-owned deadline and optional cancellation signal for context-engine post-turn persistence so a hung plugin cannot keep the same-session processing lane occupied.

## System Context

After an agent produces its response, the harness asks the selected context engine to persist or finalize turn state. That finalization remains on the active session path, so an unresolved context-engine operation can delay terminal completion and prevent the next same-session turn from starting.

## Architecture Diagram

  C --> D{Context engine completes?}

  D -->|No| F[Session lane remains occupied]
  G[Host timeout and abort signal] --> C

## Best Possible Solution

Confirm a single host-owned, fail-open post-turn deadline and cancellation contract, then implement it around the complete finalization operation with focused tests for `afterTurn`, batch ingest, sequential ingest, caller abort, and non-cooperative engines.
