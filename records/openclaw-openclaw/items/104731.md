## Summary

Current main still has the deterministic quadratic manifest-write pattern, and no replacement fix is established; this protected maintainer issue should remain open for a bounded migration repair.

## What This Changes

Fix quadratic recovery-manifest serialization while archiving unreferenced legacy JSONL transcripts during session SQLite migration.

## Best Possible Solution

Precompute collision-free archive moves, persist the complete plan once before mutation, perform all renames, and persist completion in one bounded checkpoint while preserving crash-before-completion restore tests and adding a many-artifact write-count regression test.

## Maintainer Decision

Required: false

## Reproduction Assessment

Yes at source level with high confidence: current main loops over every unreferenced JSONL, and each move causes two synchronous full-manifest serializations whose payload grows with the number of moves. This read-only review did not execute a large-store timing benchmark.

## Solution Assessment

Yes in principle: batch plan durability before mutation and bounded completion checkpointing is the narrowest maintainable repair. It removes the quadratic work without adding config or weakening the established restore model.
