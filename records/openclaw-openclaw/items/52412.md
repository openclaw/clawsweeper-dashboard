## Summary

Keep open: current main still lacks the requested injected `api.runtime.agent.abort({ runId })` plugin runtime API. Adjacent Gateway cancellation paths exist, but exposing run-abort authority to plugin code remains a product and security-boundary decision rather than a cleanup-close candidate.

## What This Changes

Request adds an injected plugin runtime method, `api.runtime.agent.abort({ runId })`, so plugins can cancel in-progress agent runs by run id.

## Best Possible Solution

Maintainers should decide the plugin abort authority model first; if approved, add a narrow scoped runtime method with SDK docs, API baseline coverage, and focused Gateway/plugin tests.
