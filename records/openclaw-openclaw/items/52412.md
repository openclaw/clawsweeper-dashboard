## Summary

Keep open: current main still lacks the requested injected `api.runtime.agent.abort({ runId })` plugin runtime API. Adjacent Gateway and session cancellation paths exist, but deciding whether plugins should get a run-id abort helper is still a product and security-boundary decision.

## What This Changes

Requested addition of a plugin runtime API, `api.runtime.agent.abort({ runId })`, so plugins can cancel in-progress agent runs.

## Best Possible Solution

Maintainers should decide the plugin abort authority model first; if approved, add a narrow scoped runtime method with ownership/session checks, SDK docs, API baseline coverage, and focused Gateway/plugin tests.
