## Summary

## What This Changes

The PR rejects malformed base64 returned by Volcengine TTS streaming and legacy APIs rather than decoding it into corrupted audio, with regression coverage for both response paths.

## System Context

The Volcengine plugin sends text to either BytePlus Seed Speech streaming or the legacy Volcengine TTS API, then decodes returned base64 audio into the buffer passed back to the calling speech workflow. This change sits at the provider-response boundary and turns invalid provider payloads into clear synthesis errors instead of corrupted audio output.
