## Summary

This is a necessary, focused, and contract-backed fix for an open Claude CLI max-turn diagnostics bug. No concrete correctness or security defect remains; maintainer review is needed because the patch intentionally makes recognized max-turn outcomes terminal rather than automatically replaying potentially completed tool actions.

## What This Changes

The PR parses Claude CLI max-turn terminal results, formats actionable OpenClaw and Claude session recovery context, preserves that message in normal replies, and prevents automatic replay through profile or model fallback.

## Best Possible Solution

Keep the parser-owned max-turn classification, shared attributed recovery formatting, closed `cli_max_turns` code, and both replay guards, then merge after the CLI/fallback owner explicitly accepts terminal non-replay semantics and the unrelated timed-out CI shard is rerun or waived.
