## Summary

Keep open. Current main partially improves persistent `current` and `session:<id>` cron targets, but default agent-turn cron jobs still default to isolated run-scoped sessions and Web UI chat/tool streaming still filters to the selected/global session, so the requested live progress behavior is not fully defined or proven fixed.

## What This Changes

Show cron job execution logs/progress in the Web UI chat as each assistant operation completes instead of only after the cron task finishes.

## Best Possible Solution

Define the cron live-progress destination, then align cron event routing, Web UI chat/tool-stream filtering, docs, focused tests, and live Control UI proof with that contract.
