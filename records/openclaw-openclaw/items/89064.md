## Summary

Keep open. Current main still does not provide a user-visible way for cron operation logs to stream into the watched Web UI chat before the cron run finishes; the code scopes cron execution to a run session and the chat/tool stream handlers only render events for the selected matching session, while docs describe final delivery or `cron.runs` polling rather than live chat mirroring.

## What This Changes

The issue asks for cron job execution logs to stream into the selected Web UI chat session as operations complete instead of appearing only after the cron task finishes.

## Best Possible Solution

Define a cron live-progress contract, preferably a run-scoped Follow/Open Running Chat path that preserves cron isolation while showing live chat/tool events before the terminal run result.
