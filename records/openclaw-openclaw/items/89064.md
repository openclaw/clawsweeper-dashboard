## Summary

Keep open. Current main and the latest release still route isolated cron progress under run-scoped session keys while the Web UI chat and tool-stream handlers render only events matching the selected chat session; docs describe final delivery and run polling, not live cron progress mirrored into the watched chat.

## What This Changes

Requests that Web UI chat show cron job execution logs or progress as each assistant operation completes instead of only after the cron task finishes.

## Best Possible Solution

Define the intended live-progress surface for cron runs, then align cron event routing, Web UI filtering, docs, and focused regression plus live Control UI proof with that contract.
