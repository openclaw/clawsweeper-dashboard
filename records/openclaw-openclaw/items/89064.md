## Summary

Keep open. Current main still routes isolated cron progress under a run-scoped cron session while the Web UI chat accepts live events for the selected session, so this is an unresolved UX/product-direction item rather than an implemented fix.

## What This Changes

Request live cron execution logs or progress to appear immediately in the watched Web UI chat instead of only after the cron run completes.

## Best Possible Solution

Define the cron live-progress destination contract, then align cron session routing, Gateway subscriptions, Control UI filters, docs, and live proof with that contract.
