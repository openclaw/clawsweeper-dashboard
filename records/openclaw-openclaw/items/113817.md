## Summary

The cache is a focused, plausible performance improvement and current model resolution copies the selected inline entry into later normalization/override paths rather than mutating the cached projection. Current main still rebuilds this projection for each explicit model lookup, so the PR remains necessary; however, the supplied before/after timings are summarized rather than backed by an inspectable redacted trace or terminal capture, so real behavior proof is still needed before merge.

**Likely related people:** gumadeiras is a medium-confidence routing candidate from earlier `models.providers` resolution work; the present file-history trail could not be completed in the read-only sandbox.

## What This Changes

This PR memoizes the runtime projection of configured inline provider models by `models.providers` object identity and adds unit coverage for cache reuse and rebuilding after the object changes.

## System Context

The embedded agent runner resolves an agent’s configured provider and model before it initializes auth and starts a turn. Inline provider configuration is projected into runtime model records, then merged with catalog metadata and provider-specific transport settings.
