## What This Changes

The PR makes paired-node screenshot requests choose PNG or JPEG from a caller-supplied output filename, keeps that validated filename unchanged, and rejects returned media whose reported encoding contradicts it.

## System Context

The Nodes agent tool asks a paired device to capture screen media through the Gateway, then writes the returned base64 bytes to an output path that has already passed workspace checks. The node-reported encoding, requested format, and saved filename must agree so later viewers, uploads, and attachment handlers receive the correct media type.
