## Summary

The reported unbounded retention path does not exist on current main: both ledger implementations trim immediately after appending, and the in-memory ledger already enforces event-count, session-count, and serialized-byte limits. The proposed ring buffer would duplicate existing retention policy; a new report would need a heap profile showing a different retaining path.

## Best Possible Solution
