## What This Changes

Move the macOS dashboard titlebar controls from an AppKit titlebar accessory into the Control UI while retaining native traffic lights, drag regions, history-state bridging, and compatibility with shipped app/web combinations.

## Best Possible Solution

Adopt one web-owned toolbar layout, leaving AppKit responsible only for traffic lights and narrowly scoped native capabilities, with explicit compatibility behavior and regression proof for current, older-app, and older-Gateway combinations.
