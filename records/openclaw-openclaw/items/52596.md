## Summary

Keep open. Current main and the latest release still have the before-tool-call choke point, plugin approval hooks, session reset lifecycle, and durable session state, but not the requested `session.auth.pin` config, framework-owned authenticated-session bit, or trusted TypeScript PIN verifier outside model context.

## What This Changes

The issue requests a framework-level session PIN gate that blocks tool calls until a session is authenticated outside model context.

## Best Possible Solution

Design either a core security primitive or an approved plugin/API extension with a SecretRef-backed secret source, authenticated session state cleared on `/new` and `/reset`, a trusted native verifier, and regression coverage for tool blocking plus PIN non-leakage.
