## Summary

The new live proof resolves the prior evidence gap, but the patch still changes cancellation into permanent abandonment of recall-session cleanup. The current test demonstrates one later recall works; it does not establish a bounded or durable lifecycle-cleanup path for repeated cancellations, so this should not merge unchanged.

## What This Changes

The PR passes the recall abort signal into Active Memory cleanup retry sleeps and adds regression coverage for cancelled cleanup and a subsequent recall.

## Best Possible Solution

Keep the recall’s main outcome from being masked by cleanup failure, but give lifecycle cleanup an explicit durable and bounded owner that is not silently abandoned by the recall cancellation signal; add coverage for repeated cancellation and eventual artifact disposition.
