Keep this PR open for repair and real provider-path proof. The refactor correctly moves the proposed decoding boundary out of the generic write tool, but the new decoder still uses a NUL-character sentinel that can corrupt valid tool arguments containing NUL bytes; the supplied evidence remains unit-test-only rather than an after-fix Volcengine/Deepseek stream result.

## What This Changes

The PR declares Volcengine tool-call arguments as escape-sequence encoded and decodes repeated literal newline and tab sequences in streamed tool-call argument objects before tools receive them.

## System Context

Volcengine model compatibility feeds the embedded agent runner with a declared tool-call argument encoding. The runner wraps the provider stream, transforms decoded tool-call argument values, and then passes those arguments to OpenClaw tools such as file writing.
