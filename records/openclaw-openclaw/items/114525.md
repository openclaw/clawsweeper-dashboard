## Summary

This PR addresses a still-open Volcengine DeepSeek regression; current `main` has no escape-sequence decoding mode. The narrowed write-content scope fixes prior broadness concerns, but the remaining count-based heuristic can silently change legitimate file content, and the supplied proof exercises a synthetic decoder stream rather than an actual Volcengine response.

## What This Changes

The PR adds a DeepSeek-model Volcengine compatibility mode that normalizes repeated literal escape sequences only in `write` tool `content` arguments before the tool writes a file.

## System Context

Volcengine model metadata selects compatibility behavior for an embedded agent run. The embedded stream guard then transforms structured tool-call arguments before the `write` tool receives content and persists it to the workspace.
