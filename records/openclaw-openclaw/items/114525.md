## Label Justifications

## Summary

Keep this PR open: it repairs the correct provider-side boundary and resolves the earlier sentinel concern, but it enables destructive escape decoding for every Volcengine model based on evidence for one model family, and it still lacks an after-fix Volcengine runtime proof.

## What This Changes

The PR declares Volcengine tool-call arguments as escape-sequence encoded and decodes repeated literal newline and tab escapes in streamed tool arguments before tools receive them.

## System Context

Volcengine model metadata selects compatibility behavior for embedded agent streams. The stream guards transform provider-specific tool-call argument objects before OpenClaw dispatches them to tools such as file writing.

## Architecture Diagram

  D --> E[Tool execution]

## Best Possible Solution

Constrain escape-sequence decoding to the verified affected Volcengine model or a demonstrated transport capability, add regression coverage for intentionally escaped multi-sequence content, and attach redacted after-fix provider-stream/output-byte proof before merge.
