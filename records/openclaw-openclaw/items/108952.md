## What This Changes

## System Context

Embedded agent attempts assemble runtime extensions before executing tools. Tool-result middleware then delivers post-tool-call events to installed plugins for auditing, telemetry, or policy handling, so the callback context determines whether those plugins can associate an event with its active agent session and run.
