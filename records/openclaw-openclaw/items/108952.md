## Summary

This remains a valid, narrow bug-fix PR: current `main` still creates the OpenClaw middleware runner with only its runtime, while the PR carries the available embedded-run identity through to that runner. The prior session-ID finding is resolved, but the PR body currently provides focused test output only, not after-fix evidence from an installed middleware, so it needs real behavior proof before merge.

## What This Changes

The PR forwards the embedded agent’s agent, session, and run identifiers to OpenClaw tool-result middleware so installed middleware can scope post-tool-call handling to the active run.

## System Context

Embedded agent runs build extension factories before creating the active agent session. The tool-result middleware factory receives identity from the attempt setup and supplies it to installed middleware whenever a tool returns a result.
