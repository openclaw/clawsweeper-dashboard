Keep this PR open for normal review: the patch follows the shared live-registry precedence contract and its focused regression test covers the reported active-versus-pinned case, but the external contribution has not supplied after-fix real runtime output beyond tests and an illustrative harness.

## What This Changes

The PR makes requester-scoped MCP resolver lookup read all live plugin registries in active-first order and adds a regression test for a pinned HTTP registry surviving an active-registry swap.

## System Context

Plugin registries supply MCP connection resolvers while OpenClaw starts and refreshes runtime surfaces. The agent MCP path uses those resolvers to decide which configured servers must be resolved per requester rather than treated as static server definitions.

## Architecture Diagram

## Best Possible Solution
