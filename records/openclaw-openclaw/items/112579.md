## What This Changes

The branch makes requester-scoped MCP connection resolution search active and pinned live plugin registries in precedence order, adds a regression test for a pinned registry surviving an active-registry swap, and includes a separate compact-CI worker pin for the CLI shard.

## System Context

OpenClaw classifies configured MCP servers before an agent run and asks plugins to resolve requester-specific transport details only when the host supplied a trusted requester identity. Plugin runtime registry state supplies those resolver registrations; the resulting connection is used to materialize scoped MCP tools without falling back to another requester’s credentials.
