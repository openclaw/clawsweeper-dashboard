## What This Changes

The PR makes QQBot `GatewayConnection.start()` settle when its abort signal fired before the final listener registration and adds a regression test for a pre-aborted signal.

## Best Possible Solution

QQBot startup should treat both already-fired and later-fired abort signals as terminal without leaving a lifecycle promise pending, with regression coverage and redacted live stop/restart evidence.
