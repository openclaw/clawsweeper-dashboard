## Summary

This PR should remain open because the prior P1 lifecycle finding still applies to the latest head: repeated sandbox preparation can remove setup-installed skills. The proposed public config contract also remains an unresolved product decision.

## What This Changes

Adds an opt-in `agents.*.sandbox.skipSkillsSync` setting that bypasses sandbox skill copying, generates a name-only skill prompt, guards command-prompt inspection, and updates related config metadata, tests, baselines, and documentation.

## Best Possible Solution

Prefer a sandbox-backend capability that returns prepared readable skill paths and prompt data, keeps operator-managed files outside OpenClaw cleanup, and is proven through both fresh and reused sandbox runs with an actual agent reading a preinstalled skill.
