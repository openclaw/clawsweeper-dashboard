## Summary

The optimization remains useful, but the current implementation can erase the preinstalled skills it documents after the container’s one-time setup has run. The attached proof does not exercise container reuse or show an agent reading a preinstalled skill, so this PR needs a lifecycle repair and maintainer product direction before merge.

## What This Changes

The PR adds an opt-in sandbox config to skip OpenClaw skill copying, preserve eligibility through a name-only prompt, guard command-prompt inspection, and update config metadata, tests, and sandbox documentation.

## Best Possible Solution

Define one owner for sandbox skill materialization: preferably let each backend declare an already-materialized sandbox skill root, preserve files outside OpenClaw-owned sync directories, rebuild prompt entries from that root, and prove repeated-container use with a real agent skill read.
