## What This Changes

Adds an opt-in `agents.*.sandbox.skipSkillsSync` setting that bypasses sandbox skill copying, supplies a name-only skill prompt, guards command-prompt inspection, and updates config metadata, tests, generated baselines, and sandbox documentation.

## Best Possible Solution
