## What This Changes

Adds a Docker-only `skipSkillsSync` option that bypasses skill copying, emits a name-only skill catalog, and updates sandbox config metadata, documentation, propagation, and tests.

## Best Possible Solution

Use the existing empty skill allowlist for deployments that need no skills; for preinstalled skills, add a Docker-owned, verified root or manifest that produces trusted sandbox-readable locations before exposing a new sync-suppression option.
