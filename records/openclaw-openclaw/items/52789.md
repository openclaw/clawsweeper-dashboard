## Summary

Close as duplicate/superseded: current main and v2026.6.11 still lack a cron `delivery.mode="session"`, but the remaining cron output-routing work is already covered by https://github.com/openclaw/openclaw/issues/49078, with https://github.com/openclaw/openclaw/issues/44309 tracking the adjacent one-way A2A dispatch semantics.

## What This Changes

The issue requests a new cron `delivery.mode="session"` that would deliver completed cron output internally to another session via the framework instead of relying on model-called `sessions_send`.

## Best Possible Solution

Keep the remaining design in https://github.com/openclaw/openclaw/issues/49078, using https://github.com/openclaw/openclaw/issues/44309 for any required one-way A2A dispatch semantics instead of adding a one-off cron session mode here.
