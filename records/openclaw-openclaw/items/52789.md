## Summary

Close as a duplicate: the request is valid but is the session-target subset of the older open cron output-routing tracker, which explicitly covers session targets while current main and the latest stable/prerelease releases still lack a `session` cron delivery mode.

## What This Changes

Add `delivery.mode="session"` for cron jobs so cron output can be delivered internally to another session via `sessions_send` instead of visible channel delivery or model-issued tool calls.

## Best Possible Solution
