## Summary

Close as superseded: the remaining cron-session delivery work is now covered by the broader open cron output-routing design issue, while the A2A dispatch semantics it would depend on are tracked separately.

## What This Changes

Add a cron delivery mode that routes completed cron output directly into another OpenClaw session through the internal session-send path.

## Best Possible Solution

Keep the remaining design consolidated in https://github.com/openclaw/openclaw/issues/49078, with any session-specific implementation aligned to the A2A dispatch semantics in https://github.com/openclaw/openclaw/issues/44309.
