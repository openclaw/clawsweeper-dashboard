## Summary

Close as duplicate/superseded: the requested cron-to-session delivery mode is the session-target subset of the open canonical cron output-routing design at https://github.com/openclaw/openclaw/issues/49078, while https://github.com/openclaw/openclaw/issues/44309 tracks the adjacent one-way A2A dispatch semantics.

## What This Changes

Request adds a cron `delivery.mode: "session"` configuration that routes completed cron output internally to a target session via `sessions_send`.

## Best Possible Solution

Use https://github.com/openclaw/openclaw/issues/49078 as the canonical cron output-routing design, with https://github.com/openclaw/openclaw/issues/44309 informing any one-way internal session dispatch semantics.

## Reproduction Assessment

Not applicable as a strict bug reproduction; this is a feature/config request. Source, protocol, docs, and the latest release show the requested session delivery mode is absent.

## Solution Assessment

No as a standalone ticket. A one-off `delivery.mode="session"` would fragment the broader cron output-target contract and A2A dispatch/security decisions already tracked by the canonical issue.
