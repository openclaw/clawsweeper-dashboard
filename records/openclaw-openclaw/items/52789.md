## Summary

Close as duplicate/superseded: current main and the latest release still lack a cron `delivery.mode="session"`, but the remaining work is the session-target subset of the broader open cron output-routing design, with one-way A2A semantics tracked separately by the dispatch-mode issue.

## What This Changes

The issue requests a new cron job delivery mode that routes completed cron output directly into another session through internal session delivery rather than visible channel announce or model-authored tool calls.

## Best Possible Solution

Keep the remaining design in https://github.com/openclaw/openclaw/issues/49078, using https://github.com/openclaw/openclaw/issues/44309 for one-way A2A semantics rather than implementing a session-only cron mode as a separate track.

## Reproduction Assessment

Not applicable as a strict bug reproduction; this is a feature/config request. Source, protocol, docs, and latest-release inspection give high confidence that the requested cron session delivery contract is absent.

## Solution Assessment

No as a standalone issue. The narrow session mode should be handled as part of the broader cron output-target contract, with one-way A2A dispatch semantics decided in the adjacent canonical session issue.
