## Summary

Close as duplicate: this is the session-only slice of cron output routing, while https://github.com/openclaw/openclaw/issues/49078 is open and explicitly tracks deterministic cron output targets including session injection. Current main and v2026.6.11 still lack `delivery.mode="session"`, and https://github.com/openclaw/openclaw/issues/44309 remains the adjacent A2A one-way dispatch design input rather than the cron-output canonical tracker.

## What This Changes

The issue requests a new cron `delivery.mode="session"` that routes completed cron output internally to a target session via `sessions_send`.

## Best Possible Solution

Keep the detailed cron-to-session example linked from https://github.com/openclaw/openclaw/issues/49078, and resolve the shared cron output-routing schema, authorization, and A2A dispatch semantics there instead of implementing a session-only satellite mode here.
