## Summary

Close as duplicate/superseded: current main and v2026.6.11 still lack a cron `delivery.mode="session"`, but the same remaining cron output-routing problem is already tracked by the open canonical issue for file/channel/session cron output targets.

## What This Changes

Request to add a cron `delivery.mode="session"` config that routes cron completion output internally to another session via `sessions_send`.

## Best Possible Solution

Track the cron output-target design in https://github.com/openclaw/openclaw/issues/49078, with https://github.com/openclaw/openclaw/issues/44309 informing any one-way session dispatch semantics.

Not applicable as a strict bug reproduction; this is a feature/config request. Source, protocol schema, docs, and the latest release show the requested session delivery mode is absent.

## Solution Assessment

No as a standalone tracker. A one-off `delivery.mode="session"` would duplicate the broader cron output-target contract and depends on unresolved A2A dispatch/security semantics.
