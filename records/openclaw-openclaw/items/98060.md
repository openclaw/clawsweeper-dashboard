## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Stop advertising unimplemented context-engine methods:** `src/gateway/methods/core-descriptors.ts:63-66`
  - body: `CORE_GATEWAY_METHOD_SPECS` feeds the advertised Gateway method list and auth classification, but this PR only adds HTTP routes and does not add `coreGatewayHandlers` or lazy RPC handlers for `contextEngine.*`. Clients can discover these methods as supported and then fail with unknown-method behavior; either remove the descriptors for an HTTP-only API or add real Gateway RPC handlers and protocol docs.
  - confidence: 0.91
- **[P2] Initialize engines before resolving the control target:** `src/gateway/context-engine-control-shared.ts:197-201`
  - body: Existing runtime paths call `ensureContextEnginesInitialized()` before `resolveContextEngine`, but this new resolver calls `resolveContextEngine` directly. On a fresh Gateway process using the default built-in engine, the registry may not contain `legacy` yet, so capabilities/control can return degraded 503 before any agent path initializes engines.
  - confidence: 0.84
- **[P2] Catch capability probe failures in control dispatch:** `src/gateway/context-engine-control-shared.ts:379-381`
  - body: `invokeContextEngineControl` awaits `engine.getControlCapabilities()` outside the control error handling, unlike the capabilities endpoint. A plugin exception there escapes the sanitized control outcome and reaches the outer server path as a generic 500; wrap this probe with the same unavailable/degraded handling used for resolution and control execution.
  - confidence: 0.82
- **[P3] Document the new control contract:** `src/context-engine/types.ts:464-470`
  - body: The patch adds public `ContextEngine` methods plus authenticated `/v1/context-engine/*` endpoints, but it does not update the context-engine or gateway docs with scopes, payloads, result sanitation, and whether these are HTTP-only or Gateway RPC methods. This leaves plugin authors and control-plane clients without a stable contract for the new API.
  - confidence: 0.78
