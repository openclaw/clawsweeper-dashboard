## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Wire advertised contextEngine methods to dispatch:** `src/gateway/methods/core-descriptors.ts:63-66`
  - body: These new core method specs are advertised through `listGatewayMethods()`, but the PR does not add matching `coreGatewayHandlers` entries. `createCoreGatewayMethodDescriptors()` skips specs with no handler, so Gateway clients can discover `contextEngine.status` or `contextEngine.rotate` and then get an unknown-method dispatch path. Add real Gateway method handlers, or keep these as non-advertised/internal policy names for the direct HTTP endpoints.
  - confidence: 0.9
- **[P1] Canonicalize session keys before control dispatch:** `src/gateway/context-engine-control-shared.ts:414-419`
  - body: The new dispatcher looks up `store[sessionKey]` and passes the request key through to `engine.control()`. Existing Gateway storage canonicalizes opaque request keys into agent-scoped keys, so a supported request like `user:u1:chat` can miss the real stored session and target a different context-engine namespace. Resolve the key for the requested agent store before lookup and pass that canonical key to the engine.
  - confidence: 0.86
