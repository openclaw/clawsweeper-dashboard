## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Canonicalize the session key before dispatching control:** `src/gateway/context-engine-control-shared.ts:414-419`
  - body: This accepts bare keys like `incident-42` for a requested agent but forwards that raw key to session lookup, rotate budgeting, and `engine.control()`. Current Gateway session helpers canonicalize bare keys into `agent:<agentId>:...`, so status/doctor/rotate can target a different or missing engine session than the chat runtime uses. This is the same blocker from the previous review cycle and is still present on the unchanged head.
  - confidence: 0.9
- **[P2] Stop advertising control methods without handlers:** `src/gateway/methods/core-descriptors.ts:63-66`
  - body: Adding these names to the core method table makes Gateway method discovery advertise `contextEngine.*`, but this PR only adds separate HTTP endpoints and no matching RPC handlers in `coreGatewayHandlers`. Clients that discover and call the listed methods would get an unsupported method path, so either add handlers or keep these names out of advertised core methods.
  - confidence: 0.84
