## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Sanitize unavailable reason codes before returning them:** `src/gateway/context-engine-control-shared.ts:284-287`
  - body: This copies `error.reasonCode` from a context-engine/plugin-thrown error directly into the HTTP response. Because status/doctor can be read-scoped and the endpoint is described as sanitized, a buggy engine could leak a token, local path, or provider debug string here; restrict this to a small safe enum/pattern or omit it from the response.
  - confidence: 0.84
- **[P2] Hide or implement the advertised contextEngine methods:** `src/gateway/methods/core-descriptors.ts:63-66`
  - body: Adding these names to `CORE_GATEWAY_METHOD_SPECS` makes them part of the advertised Gateway method catalog, but the branch does not add matching `coreGatewayHandlers` entries. Clients that discover `contextEngine.status` or `contextEngine.rotate` over the WS/RPC catalog will see methods they cannot dispatch; either add real RPC handlers/tests or mark these descriptors non-advertised/keep them out of the catalog if they are only HTTP scope sentinels.
  - confidence: 0.88
