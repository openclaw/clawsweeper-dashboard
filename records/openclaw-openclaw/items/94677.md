## Summary

Close as implemented: the specific claude-cli native Monitor path reported here is now denied in current main and in v2026.6.11, so OpenClaw no longer offers a completion-callback affordance that can be killed at the next turn boundary.

## What This Changes

The issue reports that non-persistent Claude native Monitor tasks on claude-cli can be killed by a later user turn before delivering their watched completion event.

## Best Possible Solution

Keep the shipped claude-cli deny-list for unsupported native Monitor/background Bash and use https://github.com/openclaw/openclaw/issues/97919 for the broader durable background-work lifecycle design.
