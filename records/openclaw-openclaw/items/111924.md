## Summary

This enhancement remains open: no current-main evidence establishes a searchable Control UI model picker, and the reported 100+ model case is a concrete ergonomics gap. The related catalog-filtering work is adjacent but does not replace text search; a maintainer should set the reusable picker scope before implementation.

## What This Changes

Add real-time text search, with an optional provider filter, to the Control UI model-selection dropdown.

## Best Possible Solution

Add an accessible reusable text-searchable model picker in the Control UI while keeping model eligibility and catalog scope owned by `models.list`; add provider faceting only if its behavior is defined against that catalog contract.
