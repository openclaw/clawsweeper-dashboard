## What This Changes

This PR preserves an external channel plugin’s canonical active-conversation target alongside a model-requested current-room alias so delegated message actions can resolve the intended room after a core/plugin version mismatch.

## System Context

OpenClaw’s message-action runner turns agent tool calls into channel actions, then dispatches them to a bundled or external channel plugin. For read-capable delegated actions, the shared dispatcher verifies that the requested target is the active conversation before the plugin resolves and executes the provider-specific action.

## Best Possible Solution
