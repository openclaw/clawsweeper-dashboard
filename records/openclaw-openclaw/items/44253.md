## Summary

Keep open: current main and v2026.6.11 still lack a delegate-only/self-deny tool-policy surface, and source shows inherited parent tool policy is propagated to children, so this remains a security-sensitive public config decision.

## What This Changes

Request to add per-agent delegate-only tool denial so an agent can hide exec/write/edit from its own model while still passing them to spawned subagents.

## Best Possible Solution

Add a maintainer-approved delegate-only tool policy in core config schema, runtime policy resolution, docs, diagnostics, and regression tests, while keeping normal deny absolute and defining subagent/ACP inheritance behavior explicitly.
