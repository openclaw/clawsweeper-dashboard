## Summary

Keep open: current main and v2026.6.11 still cannot express requester-hidden, delegate-only tool inheritance; the related per-spawn allowlist work is only a partial overlap, and the remaining fix is a security-sensitive public config/API decision.

## What This Changes

The issue requests a per-agent `tools.selfDeny` or `delegateOnly` policy so an agent can delegate high-risk tools to spawned children without seeing or calling them itself.

## Best Possible Solution

Add a maintainer-approved delegate-only/self-deny policy in core schema, tool resolution, docs, diagnostics, and regression tests, while preserving deny-wins semantics and defining interaction with per-spawn `toolsAllow`.
