## Summary

Keep open: current main still has no per-agent `selfDeny`/delegate-only policy, and the open per-spawn `toolsAllow` work only narrows child tools rather than preventing the parent agent from seeing or using delegated tools directly.

## What This Changes

Add a per-agent `tools.selfDeny` or equivalent delegate-only config so an agent can pass selected tools to subagents without being able to use those tools itself.

## Best Possible Solution

Define one maintainer-approved delegate-only policy that removes selected tools from the parent agent's own model/tool surface while preserving explicit deny-wins inheritance and aligning with per-spawn `toolsAllow` semantics.
