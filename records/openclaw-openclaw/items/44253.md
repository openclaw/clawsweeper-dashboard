## What This Changes

The issue requests a per-agent `tools.selfDeny` or delegate-only policy that hides tools from the requester model while still allowing eligible subagents to inherit them.

## Best Possible Solution

Keep this as the canonical delegate-only design issue, then add one additive public contract only after maintainers choose the API name, deny-wins semantics, schema/docs updates, and regression coverage.
