## Summary

Keep open: current main still lacks a delegate-only/self-deny tool policy, and adjacent per-spawn `toolsAllow` work does not hide tools from the parent agent. The remaining choice is a security-sensitive public config/API decision, not conservative cleanup.

## What This Changes

Add an optional per-agent `tools.selfDeny` or equivalent delegate-only policy so an agent can hide tools from its own model turn while still allowing controlled subagent inheritance.

## Best Possible Solution

Keep this as the canonical delegate-only tool-policy design tracker, then implement an additive config contract with deny-wins semantics, schema/docs updates, and focused tests for parent-direct denial plus child inheritance.
