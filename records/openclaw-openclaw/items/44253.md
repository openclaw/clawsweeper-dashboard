## Summary

Keep open: current main and the latest release still lack a parent-only/delegate-only tool policy, and the remaining work is a security-sensitive public config/product decision rather than conservative cleanup.

## What This Changes

The issue requests a new per-agent tool policy key such as `tools.selfDeny` so an agent can hide tools from its own model surface while still allowing those tools to be inherited by spawned subagents.

## Best Possible Solution

Pick one maintainer-approved delegation contract for requester-visible tools versus inherited child tool pools, then update config schema, runtime policy resolution, docs, and regression coverage in the same security-reviewed change.
