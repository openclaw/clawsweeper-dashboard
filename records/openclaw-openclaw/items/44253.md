## Summary

Keep open: current main and the latest release still cannot express requester self-denial with delegated child tool inheritance, and the remaining work is a security-sensitive public config/API decision.

## What This Changes

The issue requests a per-agent delegate-only tool policy so an agent can hide tools from its own model session while still allowing spawned subagents to receive them.

## Best Possible Solution

Add a maintainer-approved delegate-only/self-deny policy in core schema, tool resolution, diagnostics, docs, and regression tests, while preserving deny-wins semantics and documenting interaction with per-spawn toolsAllow.
