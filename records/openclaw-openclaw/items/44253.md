Keep open: current main and v2026.6.11 still lack a `tools.selfDeny`/delegate-only per-agent tool policy, and the new peer-mesh comment adds real-world evidence that this is still an active separation-of-duties gap rather than stale cleanup.

## What This Changes

The issue requests an additive per-agent tool policy that hides selected tools from an agent's own model turn while still allowing those tools to be delegated to permitted subagents.

## Best Possible Solution

Keep this as the canonical design issue, then implement one additive delegate-only contract after maintainers choose the API name, deny-wins semantics, schema/docs updates, and policy tests.
