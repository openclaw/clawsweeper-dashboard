## Summary

Keep open: current main and v2026.6.11 still lack a delegate-only or `tools.selfDeny` policy, and the open `sessions_spawn.toolsAllow` PR is adjacent child-narrowing work rather than a parent-self denial fix.

## What This Changes

The issue requests a per-agent tool policy that hides selected tools from the agent's own model-visible tool list while still allowing those tools to be inherited by eligible subagents.

## Best Possible Solution

Keep this issue as the canonical delegate-only tool-policy design tracker, then implement one additive config contract with explicit deny-wins precedence, docs, and tests proving requester-visible tools and child-inherited tools diverge only as intended.
