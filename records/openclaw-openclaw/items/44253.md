## Summary

Keep open: current main still cannot express delegate-only tool inheritance, and the remaining work is a security-sensitive public config decision rather than a stale or already-implemented bug fix.

## What This Changes

The issue requests a per-agent delegate-only tool policy so an agent can pass tools to subagents without exposing those tools to its own model context.

## Best Possible Solution

Add a maintainer-approved delegate-only tool policy in core schema, tool-policy resolution, docs, diagnostics, and regression tests, while keeping normal deny absolute and defining ACP/subagent inheritance behavior explicitly.
