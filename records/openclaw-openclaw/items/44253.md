## Summary

Keep open: current main and v2026.6.11 still do not provide `selfDeny`, `delegateOnly`, or an equivalent parent-self-only tool denial policy. The request remains the canonical security/product design thread because ordinary parent allow/deny policy is still part of the child inheritance path, while related issues cover child narrowing or separate inherited-policy bugs.

## What This Changes

Request to add a per-agent tool policy setting that hides tools from an agent's own model surface while still allowing those tools to be delegated to subagents.

## Best Possible Solution

Design a maintainer-approved delegate-only policy that keeps ordinary `deny` absolute, hides selected tools only from the requester model surface, and documents/audits child access across native, ACP, gateway, and upgrade paths.
