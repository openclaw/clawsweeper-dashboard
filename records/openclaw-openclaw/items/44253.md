## Summary

Keep open: current main and v2026.6.11 still lack a `tools.selfDeny`/delegate-only per-agent tool policy, and the new peer-mesh comment adds real-world evidence that this is still an active separation-of-duties gap rather than stale cleanup.

## What This Changes

The issue requests a per-agent `tools.selfDeny` or delegate-only tool policy that hides selected tools from the agent's own model context while preserving them for subagent inheritance.

## Best Possible Solution

Keep this open as the canonical delegate-only tool-policy design thread until maintainers choose an additive, documented contract with deny-wins semantics, upgrade behavior, and focused tests for parent-visible versus child-delegable tools.
