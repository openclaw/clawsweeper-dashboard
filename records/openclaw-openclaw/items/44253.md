## Summary

Keep open: current main and v2026.6.11 still do not provide a delegate-only/self-deny tool-policy surface, and the remaining work is a security-sensitive public config decision rather than conservative cleanup.

## What This Changes

The issue requests an optional per-agent delegate-only tool policy, such as `tools.selfDeny`, so an agent can pass tools to subagents without seeing or using those tools itself.

## Best Possible Solution

Keep this as the canonical design issue, then implement an additive delegate-only config contract after maintainers choose the API name, child-inheritance semantics, schema/docs updates, and focused security tests.
