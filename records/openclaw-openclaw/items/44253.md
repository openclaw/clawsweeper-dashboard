## Summary

Keep open: current main and v2026.6.11 still cannot express requester-only tool denial while preserving delegated child access, and the remaining work is a security-sensitive public config/API decision rather than stale cleanup.

## What This Changes

The issue requests a per-agent delegate-only or self-deny tool policy so an agent can pass tools to subagents without seeing or calling those tools itself.

## Best Possible Solution

Add a maintainer-approved delegate-only tool policy in the core config schema, tool-policy resolver, docs, diagnostics, and regression tests, while keeping normal deny absolute and defining child inheritance behavior explicitly.
