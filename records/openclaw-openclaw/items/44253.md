## Summary

Keep open: current main still cannot express requester-hidden delegate-only tools, and the remaining work is a security-sensitive public config/API decision rather than a cleanup close.

## What This Changes

Add per-agent tool policy such as `tools.selfDeny` so an agent can pass tools to spawned subagents while the requester model cannot see or call those tools directly.

## Best Possible Solution

Add a maintainer-approved delegate-only/self-deny policy in core schema, runtime tool resolution, sessions_spawn inheritance, docs, diagnostics, and focused regression tests, while preserving absolute deny-wins semantics.
