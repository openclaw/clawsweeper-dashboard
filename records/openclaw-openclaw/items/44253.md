The issue requests an additive per-agent tool-policy option that hides tools from the requesting agent while still allowing those tools to be inherited by spawned subagents.

Keep this issue as the canonical delegate-only design tracker, then implement one additive per-agent contract after maintainers choose naming, deny-wins semantics, schema/docs updates, and focused policy tests.
