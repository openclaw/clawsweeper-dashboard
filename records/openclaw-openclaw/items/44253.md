Keep open: current main still cannot express delegate-only tool inheritance, and the remaining change is a security-sensitive public config/API decision rather than an already-implemented cleanup candidate.

## What This Changes

The issue requests a per-agent delegate-only tool policy so a requester/orchestrator can hide tools from its own model surface while still allowing spawned subagents to inherit them.

## Best Possible Solution

Add a maintainer-approved delegate-only/self-deny policy in core schema, tool resolution, docs, diagnostics, and regression tests, while preserving deny-wins semantics and documenting interaction with per-spawn toolsAllow.
