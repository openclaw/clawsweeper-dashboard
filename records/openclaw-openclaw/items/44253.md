## Summary

Keep open: current main and v2026.6.11 still cannot express delegate-only tool inheritance, and the new peer-mesh comment adds another real separation-of-duties use case. The remaining work is a security-sensitive public config/API decision, not a stale or already-implemented cleanup item.

## What This Changes

The issue requests a per-agent `tools.selfDeny` or equivalent policy that hides tools from a requester agent while still allowing selected subagents to inherit them.

## Best Possible Solution

Add a maintainer-approved delegate-only/self-deny policy in core schema, tool resolution, inherited-policy storage, diagnostics, docs, and regression tests, or explicitly fold or reject it in the per-spawn tool-policy design.
