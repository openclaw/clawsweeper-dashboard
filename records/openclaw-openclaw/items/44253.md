## Summary

Keep open: current main and v2026.6.11 still cannot express requester-hidden, child-inherited tool delegation, and the remaining work is a security-sensitive public config/API decision rather than cleanup.

## What This Changes

The issue requests a per-agent `tools.selfDeny` or equivalent delegate-only tool policy so an agent can hide tools from its own model surface while still allowing selected subagents to inherit them.

## Best Possible Solution

Add a maintainer-approved delegate-only tool policy in core config, tool resolution, docs, diagnostics, and regression tests, preserving deny-wins semantics and explicitly defining interaction with per-spawn `toolsAllow`.
