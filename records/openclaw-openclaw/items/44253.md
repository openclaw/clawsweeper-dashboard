## Summary

Keep open: current main and the latest release still lack a delegate-only per-agent tool policy, and the adjacent toolsAllow work narrows child tools without hiding those tools from the requester model.

## What This Changes

The issue requests a per-agent delegate-only tool policy so an agent can pass tools to spawned subagents without seeing or calling those tools itself.

## Best Possible Solution

Keep this as the canonical design issue, then implement one additive core tool-policy contract after maintainers choose the API name, deny-wins semantics, schema/docs updates, and regression coverage.
