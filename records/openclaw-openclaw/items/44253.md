## Summary

Keep open: current main and v2026.6.11 still lack a `tools.selfDeny` or equivalent delegate-only policy, and the remaining behavior is a security-sensitive product/config decision rather than cleanup.

## What This Changes

Request to add a per-agent delegate-only tool policy so an agent can hide tools from its own model surface while still allowing controlled inheritance to spawned subagents.

## Best Possible Solution

Keep this as the canonical design issue until maintainers approve an additive delegate-only/self-deny contract that preserves deny-wins semantics and aligns with per-spawn `toolsAllow`, then update schema, policy resolution, docs, and focused tests together.
