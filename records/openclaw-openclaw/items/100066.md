## What This Changes

The issue reports contradictory recovery guidance where an unknown-model error tells operators to add provider model config for a legacy/bundled OAuth provider, but the config validator rejects that edit and can leave the gateway in a startup crash-loop.

## Best Possible Solution

Keep `openai-codex` as legacy-only input and update the unknown-model recovery path to route legacy or auth-gated provider misses to doctor/auth guidance while preserving the custom-provider registration hint.
