## Summary

Keep this issue open: current main recognizes the terminal `toolUse` shape as an incomplete turn, but no evidence shows that it safely continues the existing Codex thread after completed side-effecting tools, and no canonical fix currently owns the remaining behavior.

## What This Changes

Add bounded safe continuation for Codex app-server turns that finish after completed tool calls without a final assistant response, and address missing retry handling for genuinely empty turns.

## Best Possible Solution

Model completed-tools-without-final-assistant as a Codex-harness recovery outcome, perform at most one thread-bound follow-up that cannot replay the original prompt, and prove with focused tests and a live transcript that completed tools are not re-executed.
