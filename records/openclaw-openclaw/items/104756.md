## Label Justifications

- `P1`: The PR fixes a real cancellation defect affecting active agent workflows, but its current implementation introduces repeated listener retention on tool-heavy runs.
- `merge-risk: 🚨 availability`: Merging the direct shared-signal wiring can accumulate abort listeners and retained request closures across successful MCP calls in a long-lived run.

## Summary

This remains a useful cancellation fix, but the prior blocking signal-lifecycle finding is still present on the refreshed head: successful MCP requests leave abort listeners attached to the long-lived run signal.

## What This Changes

The PR forwards per-call abort signals through bundled MCP tool, resource, and prompt execution, keeps caller aborts neutral to server backoff, and adds signal-forwarding coverage.

## Best Possible Solution

Keep the cancellation propagation, but relay the run signal through a request-scoped controller or helper whose upstream abort listener is detached in a `finally`, with focused coverage proving both cancellation delivery and zero listener growth after settled requests.
