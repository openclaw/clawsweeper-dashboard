## Summary

Keep open: current main and the latest checked release still provide only partial cron, hook, command-job, tool allow-list, light-context, timeout, and post-run cost telemetry primitives, not the requested first-class scoped/script-limited agent mode with script registry, dry-run/cost preview, budget admission, daily ceilings, and structured planned-vs-actual run receipts.

## What This Changes

Request a scoped/script-limited agent execution mode for cron and automation that constrains scripts, tool execution, context, and spend before work runs.

## Best Possible Solution

Keep this as the umbrella scoped automation product/API tracker and design shared primitives across cron, hooks, command jobs, tool policy, budget admission, context handling, run receipts, docs, and tests while coordinating narrower sibling issues.
