## Summary

Keep open: current main still has useful cron command jobs, isolated-session controls, tool allow-lists, light context, model/fallback/timeout controls, and usage telemetry, but not the requested first-class scoped/script-limited mode with script registry, dry-run cost preview, token/spend ceilings, daily budget aborts, and planned-vs-actual run receipts.

## What This Changes

Request for a scoped/script-limited agent mode that bounds cron/script execution, tool scope, token and spend budgets, context accumulation, dry-run previews, and run transparency.

## Solution Assessment
