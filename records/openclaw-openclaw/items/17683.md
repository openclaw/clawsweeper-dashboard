## Summary

Keep open: current main and latest release still provide partial cron, hook, timeout, light-context, command-job, tool allow-list, and post-run cost observability primitives, but not the requested first-class scoped/script-limited mode with script registry, dry-run/cost preview, pre-run budget admission, daily ceilings, and structured planned-vs-actual run receipts.

## What This Changes

The issue requests a first-class scoped/script-limited agent mode with admin-approved scripts, cron-first execution, token/spend ceilings, minimal context, and transparent run planning/logging.

## Best Possible Solution

Keep this as the umbrella product/API tracker and design shared scoped-automation primitives across cron, hooks, command jobs, tool policy, budget admission, context handling, run receipts, docs, and tests.
