## Summary

Keep open: current main and v2026.6.11 still provide only partial cron, hook, timeout, light-context, tool allow-list, command-job, and post-run usage primitives, not the requested first-class scoped/script-limited mode with script registry, dry-run/cost preview, budget admission, and structured run receipts.

## What This Changes

The issue requests a scoped, script-limited agent mode with cron-first execution, script allow-lists, dry-run/cost previews, token and spend ceilings, minimal context, and structured run transparency.

## Best Possible Solution

Keep this as the umbrella product/API tracker and design shared scoped-automation primitives across cron, hooks, command jobs, tool policy, budget admission, context handling, run receipts, docs, and tests.
