## Summary

Keep open: current main and v2026.6.11 still provide partial cron, hook, command-job, timeout, light-context, tool allow-list, and post-run usage primitives, but not the requested first-class scoped/script-limited mode with an admin script registry, dry-run/cost preview, budget admission, daily ceilings, or planned-vs-actual run receipts.

## What This Changes

The issue requests a first-class scoped/script-limited agent mode for predictable cron/script automation, token/spend control, minimal context, and transparent execution logs.

## Best Possible Solution

Keep this as the umbrella product/API tracker and design shared scoped-automation primitives across cron, hooks, command jobs, tool policy, budget admission, context handling, run receipts, docs, and tests.
