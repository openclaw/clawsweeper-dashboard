## What This Changes

Add QQBot gateway heartbeat-ACK tracking and a liveness watchdog so a connection that stops receiving heartbeat confirmations can be closed and reconnected.

## System Context

The QQBot channel maintains a WebSocket gateway connection to receive platform events. Gateway frames enter the connection handler, which sends periodic heartbeats; a liveness decision would determine whether to retain the socket or let the existing close-and-reconnect path restore delivery.
