## What This Changes

This PR makes the OpenAI OAuth image provider reject Responses SSE streams that end before `response.completed`, preserve nested provider error and incomplete-reason details, and reject completed responses with no usable image.

## System Context

OpenClaw's OpenAI plugin sends OAuth image-generation requests to the Responses API, collects server-sent events, and converts image-generation output into image attachments for callers. This change validates that the provider has reached a terminal completed response before returning that result.
