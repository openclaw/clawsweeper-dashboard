## What This Changes

The PR preserves detected MIME types for Discord attachments sent through regular messages, component messages, and native slash-command replies, with regression tests that inspect serialized multipart requests over localhost HTTP.

## System Context

Discord media loading produces bytes, a filename, and a detected MIME type for outbound attachments. The Discord plugin converts those inputs into multipart file payloads for regular channel sends, component messages, and interaction replies before its REST client sends them to Discord.
