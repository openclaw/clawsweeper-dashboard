## What This Changes

This PR preserves detected MIME types for regular Discord attachments, component-message attachments, and native slash-command reply uploads by converting byte buffers into typed `Blob` objects.

## System Context

OpenClaw’s Discord plugin loads outbound media and packages it for Discord REST message endpoints or interaction replies. Discord receives multipart upload files from those paths, where the Blob MIME type determines the attachment content type exposed to Discord clients and APIs.
