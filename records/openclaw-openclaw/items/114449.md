## What This Changes

The branch makes a successful empty-transcript compaction result a benign skip in shared compaction handling, preventing CLI delivery, manual `/compact`, and memory preflight from treating that outcome as a failure.

## System Context

OpenClaw compacts a session transcript before context-constrained agent and CLI operations. The compaction result then drives CLI completion delivery, the manual `/compact` command, and memory preflight, each of which must distinguish an intentional skip from a failed compaction.
