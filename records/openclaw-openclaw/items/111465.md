## Summary

Keep this PR open: the prior P2 remains on the current head. Its new batch-level superseded-error suppression can hide a genuine refresh failure from another owner, leaving that owner’s prepared runtime stale without the intended warning or retry signal.

## What This Changes

The branch hardens first-run web onboarding redirects, reserved setup-runtime rebinding, one-shot chat drafts, and auth-triggered prepared-runtime refresh logging.

## Best Possible Solution

Handle publication outcomes per owner, or inspect all settled outcomes before ignoring only superseded ones, and add a mixed-batch regression test that proves a genuine sibling failure is still surfaced.
