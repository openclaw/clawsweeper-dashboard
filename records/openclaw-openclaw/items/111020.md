## What This Changes

The PR changes Codex `message(final:true)` and `sessions_yield` terminal replies to wait for Codex’s natural `turn/completed` notification, using an absolute 10-second interrupt fallback for runaway work or a new inbound user message.

## System Context

The Codex extension runs app-server turns and turns terminal dynamic-tool results into OpenClaw attempt completion, channel delivery, and persisted Codex thread-rollout context. This change sits between a delivered terminal tool result and the final app-server notification that determines whether the attempt succeeds, aborts, or records a prompt error.
