## What This Changes

The PR makes Codex terminal message and yield replies wait for Codex’s natural completion instead of immediately interrupting the turn, with a bounded interrupt fallback for runaway work or a new inbound message.

## System Context

The Codex extension turns app-server notifications and dynamic tool results into an OpenClaw attempt result and the Codex thread’s persisted rollout. Terminal message/yield delivery currently crosses from tool handling into turn completion, steering, timeout watches, and final result projection.
