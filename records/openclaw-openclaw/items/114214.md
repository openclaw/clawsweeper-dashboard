## What This Changes

The PR changes live model-switch handling so a target absent from the configured fallback chain is rethrown to the bounded agent or cron retry owner, while configured later targets still redirect within that chain.

## System Context

An active agent turn can receive a session-level model change while the fallback runner is selecting configured model candidates. The fallback runner must either redirect to a later configured candidate or return the switch signal to the outer retry owner so the same turn can restart against the selected model.
