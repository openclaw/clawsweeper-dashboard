## Summary

Keep this PR open for a narrow correctness repair before merge. The new command reads `sourceConfig` for mutation, but validates the requested id through a helper that reads the normalized `agents.list` projection; the submitted unit-test snapshot contains only persisted `agents.entries`, so the command rejects a configured target instead of performing the reassignment. The `maintainer` label also requires explicit human handling of this new public CLI surface.

## What This Changes

This PR adds `openclaw agents set-default <id>` so operators can move the default-agent marker through the CLI, with JSON output, command registration, tests, and agent documentation.

## System Context

The agent CLI reads a validated configuration snapshot, identifies a configured agent, and writes an updated default marker back to the OpenClaw config. The resulting default agent is then used by routing and agent-selection paths when callers do not specify an agent explicitly.
