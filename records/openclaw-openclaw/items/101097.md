## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Preserve hidden widgets as hidden after refetch:** `ui/src/lib/dashboard/index.ts:168-176`
  - body: The backend schema persists `hidden`, and `hideWidget` only removes the widget optimistically. On the next `dashboard.workspace.get`, broadcast refresh, or reload, `normalizeWidget` drops `hidden` and the grid renders every widget again, so hidden widgets reappear and still participate in layout/binding work. Keep `hidden` in the UI model and filter hidden widgets from render/layout/binding paths.
  - confidence: 0.91
- **[P1] Send the move-to-tab parameters the gateway accepts:** `ui/src/lib/dashboard/index.ts:622-629`
  - body: `moveWidgetToTab` sends `{ slug, toSlug, widgetId }`, but the `dashboard.widget.move` gateway handler accepts `tab`, `id`, `grid`, and `toTab` and rejects unexpected keys. The Move to tab menu will fail and roll back until this client call uses the backend contract.
  - confidence: 0.93
- **[P1] Wrap file bindings in the data-read binding parameter:** `ui/src/lib/dashboard/index.ts:705-711`
  - body: For file bindings the UI calls `dashboard.data.read` with top-level `path` and `pointer`, while the gateway reads only a `binding` parameter and resolves that binding object. The advertised file-backed markdown/table widgets therefore cannot load through the RPC path; send `{ binding }` or align the gateway and tests.
  - confidence: 0.9
