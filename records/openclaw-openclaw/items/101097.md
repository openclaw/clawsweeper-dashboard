- **[P1] Use the gateway's widget mutation parameter shape:** `ui/src/lib/dashboard/index.ts:545-546`
  - body: The gateway rejects unknown keys before dispatch: `dashboard.widget.move/update/remove` accept `tab`/`id`, and update expects a nested `patch`, but the UI sends `slug`/`widgetId` with fields at the top level. Drag/resize, collapse, title, hide, remove, and move-to-tab all fail instead of persisting.
  - confidence: 0.96
- **[P1] Send file bindings under dashboard.data.read binding:** `ui/src/lib/dashboard/index.ts:705-708`
  - body: `dashboard.data.read` only accepts `{ binding }` and the resolver expects `source`/`path` inside that object, but this sends `{ path, pointer }`. File-bound markdown/table widgets will be rejected with an unexpected-param error instead of rendering their data.
  - confidence: 0.94
- **[P2] Keep hidden widgets out of the rendered read model:** `ui/src/lib/dashboard/types.ts:38-47`
  - body: The backend schema stores `DashboardWidget.hidden`, but the UI type/normalizer drops that field and `renderGrid` maps every widget. Agent- or CLI-hidden widgets therefore render again after load/refetch, even after the mutation payload shape above is fixed.
  - confidence: 0.9
