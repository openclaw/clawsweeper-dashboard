Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Use the gateway's widget mutation parameter shape:** `ui/src/lib/dashboard/index.ts:546`
  - body: The gateway rejects unknown params before dispatch: widget mutations accept `tab`/`id`, and `dashboard.widget.update` expects a nested `patch`. This helper sends `slug`/`widgetId` and top-level mutation fields, so drag/resize, collapse/title/hide/remove, and move-to-tab fail instead of persisting.
  - confidence: 0.96
- **[P1] Send file bindings under dashboard.data.read binding:** `ui/src/lib/dashboard/index.ts:705-708`
  - body: `dashboard.data.read` only accepts `{ binding }`, and the resolver expects `source`/`path` inside that object. This call sends top-level `path`/`pointer`, so file-bound markdown/table widgets are rejected before their data can render.
  - confidence: 0.94
- **[P2] Preserve hidden widgets in the UI model:** `ui/src/lib/dashboard/types.ts:38-47`
  - body: The backend schema persists `DashboardWidget.hidden`, but this UI type and normalizer drop the field while `renderGrid` maps every widget. After load/refetch, widgets hidden by CLI, agent, or UI will show again once the payload-shape bug is fixed.
  - confidence: 0.9
