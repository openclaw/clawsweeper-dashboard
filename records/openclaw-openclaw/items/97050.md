  - body: This runtime `COPY` still includes `.npmrc`, but the repository keeps that file for registry/auth-only entries. Current main does not copy `.npmrc` into the final image; keep it out of the runtime image path so future registry/auth entries are not shipped in published containers.

  - body: The PR still removes the separate `FROM base-runtime` final stage and weakens tests to accept `AS base-runtime` instead.   - confidence: 0.92

  - body: Late discovery: this was visible on the earlier reviewed head but not raised then. The async helper now re-reads even when `snapshot.readError` is set, so exported writes for unreadable configs can throw raw read errors before the `CONFIG_WRITE_REJECTED` guard saves a rejected artifact and preserves the live file.
  - late: true
