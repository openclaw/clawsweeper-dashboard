## Summary

Keep this PR open for a maintainer decision: the code-point truncation is mechanically safe, but the current treemap path sanitizes labels to ASCII before truncation, so this helper-only change does not establish an observable Unicode-label behavior or a necessary production fix.

## What This Changes

The PR changes `truncateLabel` in `src/auto-reply/reply/context-treemap.ts` to count Unicode code points with `Array.from` rather than UTF-16 code units.

## Best Possible Solution

First decide whether context-treemap labels should remain intentionally ASCII or gain supported Unicode rendering; keep the current sanitization invariant if ASCII is intentional, otherwise make the change end to end with rendering/layout coverage.
