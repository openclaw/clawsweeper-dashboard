## Summary

This PR is not ready to merge: it admits Unicode labels into a bitmap renderer that only defines ASCII glyphs, so the intended CJK-label display fix still renders as blank space.

## What This Changes

The branch broadens context-treemap label sanitization to retain Unicode letters and numbers and switches truncation from UTF-16 code units to code points.

## Best Possible Solution

First choose whether `/context map` should support Unicode glyph rendering; if yes, replace the ASCII bitmap-glyph boundary with a Unicode-capable rendering approach and add visual output coverage, otherwise retain the current ASCII sanitization contract.
