## Summary

Keep open: current main and v2026.6.11 still have internal cron reservation state and SQLite-backed storage, but no public claim/lease, CAS remove, claim-aware exit code, or documented single-flight contract for concurrent dispatch/removal.

## What This Changes

The issue requests a public cron claim/lease, CAS remove, or enforced single-flight contract so external code can safely retire jobs while the scheduler dispatches them.

## Best Possible Solution

Choose one additive cron precondition contract, then align Gateway schema, service results, CLI flags/help, docs, and focused concurrency tests around that contract.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Which public cron precondition should OpenClaw expose for concurrent dispatch/removal: narrow CAS/if-unclaimed remove, full lease-token dispatch, or documented current behavior with no new API?

Rationale: The source gap is clear, but the durable public contract affects Gateway schema, CLI flags, exit codes, docs, and external automation semantics.

Likely owner: steipete

Owner reason: steipete has the strongest inspected history on the cron scheduler and public cron surfaces affected by this API choice.

Owner confidence: high

Options:

- **Add narrow claim-aware remove (recommended):** Add an additive --if-unclaimed or expected-version remove contract with a documented conflict exit and tests before considering full lease-token payloads.
- **Design full dispatch leases:** Expose lease tokens on dispatch/show/remove so external callers can validate or revoke in-flight work at the cost of a larger public API.
- **Document no precondition API:** Keep cron remove unconditional, document idempotent cleanup expectations, and close this direction as out of scope.

## Reproduction Assessment

Not applicable as a bug reproduction; this is a feature/API request. Source inspection gives high confidence that current main lacks the requested public claim/lease/CAS fields, CLI flags, and documented conflict exit contract.

## Solution Assessment

Unclear until maintainers choose the contract. A narrow additive CAS or --if-unclaimed remove path looks smaller than a full lease-token system, but either choice is public API direction.
