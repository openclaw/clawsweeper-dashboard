## What This Changes

The issue requests an opt-in TTL/expiry policy for persisted outbound delivery queue entries so stale queued messages are not replayed after gateway restart.

## Best Possible Solution

Unclear until maintainer policy is chosen. The maintainable fix is a narrow current-main expiry policy that covers startup recovery and reconnect drain while aligning strict config/default semantics with compatibility guidance.
