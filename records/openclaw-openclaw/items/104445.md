## Summary

The compact row redesign is useful and the desktop screenshots show a clear improvement, but the implementation misses the composer’s existing phone-width override: below 768px the queue remains 28px narrower than the composer. The protected `maintainer` label also requires explicit maintainer handling, so this PR should stay open for the focused responsive fix and refreshed proof.

## What This Changes

This PR replaces Control UI queued-message cards with compact composer-adjacent rows, adds inline state icons and actions, and consolidates queue styling in `components.css`.

## Best Possible Solution
