## What This Changes

The PR changes QA Lab’s OpenClaw/Codex runtime-tool parity and coverage reports so only successful tool calls linked to non-error results can satisfy required coverage, while unavailable or report-only paths become skips.

## System Context

QA Lab runs equivalent tool scenarios through OpenClaw and Codex, captures each runtime’s persisted tool evidence, then turns the paired outcomes into a release-validation coverage report. This PR changes the classification between pass, fail, and skip before the coverage gate is calculated.
