## System Context

QA Lab executes runtime-tool scenarios against OpenClaw and Codex, reads durable session transcripts, classifies parity for each runtime, and turns that evidence into a release-validation coverage gate. This PR changes the boundary between diagnostic intent/availability data and evidence of a successful product tool call.
