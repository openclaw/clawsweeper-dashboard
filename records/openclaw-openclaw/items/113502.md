## What This Changes

The PR makes paired OpenClaw/Codex QA record pass, fail, or skip per runtime cell and counts required tool coverage only when a target product call has a linked successful result.

## System Context

QA Lab runs the same scenario through OpenClaw and Codex, captures runtime session evidence, then projects the paired result into suite status and tool-coverage reporting. This PR changes the evidence threshold that turns captured tool activity into required QA coverage.
