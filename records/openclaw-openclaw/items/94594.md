## Summary

Keep this PR open. It addresses the open three-or-more-agent loop report, but it introduces deliberate fail-closed routing semantics that need maintainer product acceptance, still lacks inspectable real-runtime proof, and retains the prior minor error-chain duplication issue.

## What This Changes

This PR adds an optional visited-agent chain to inter-session provenance and uses it to block `sessions_send` before it starts a target agent run that would revisit an agent already in the route.

## System Context

`sessions_send` sends an agent-to-agent request through the gateway, then internal A2A reply and announcement paths can continue the interaction. The proposed provenance chain moves through those boundaries so the send tool can stop an otherwise cyclic route before the next target run begins.
