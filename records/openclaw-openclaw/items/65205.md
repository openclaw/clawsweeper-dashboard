## Review Findings

Overall confidence: 0.9

Full review comments:

- **[P1] Move Activity config into the Canvas plugin contract:** `src/config/zod-schema.ts:660-667`
  - body: This adds `canvasHost.activity` under the retired root Canvas config even though current main resolves Canvas host settings from the Canvas plugin and keeps root `canvasHost` only as legacy migration input. Merging this would create a second runtime owner for Canvas Activity behavior; rebase and put the Activity settings/routing behind the Canvas plugin contract or an explicit plugin API.
  - confidence: 0.93
- **[P1] Require credentialed Activity auth before bypassing Gateway auth:** `src/gateway/a2ui-activity.ts:150-154`
  - body: With Activity enabled and no configured token, `isCanvasActivityAccessAllowed` returns true after checking only launch-context markers, and `authorizeCanvasRequest` accepts that before bearer or node-capability auth. Those markers can be supplied in query/cookie/referer state, so public Canvas/A2UI access must require a non-spoofable credential or signed Discord assertion before this bypass is safe.
  - confidence: 0.94
- **[P1] Bundle or pin the Discord SDK instead of importing CDNs:** `src/canvas-host/a2ui.ts:171-176`
  - body: The injected Canvas helper executes `@discord/embedded-app-sdk` from jsDelivr or esm.sh in the Canvas page origin at runtime. That adds third-party script execution to a public Activity surface; use a bundled/pinned SDK path or an explicitly approved controlled loader before merge.
  - confidence: 0.91
- **[P1] Bound Activity A2UI broadcasts before fanout:** `src/gateway/a2ui-activity.ts:240-243`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected Activity client without size limits, rate limits, or backpressure checks. A large or repeated `canvas.a2ui.push*` payload can retain memory and stall slow clients, so cap payloads and drop or close overloaded sockets before enabling this hub.
  - confidence: 0.9
- **[P1] Stop sending Activity tokens in WebSocket URLs:** `src/canvas-host/a2ui/index.html:325-329`
  - body: The browser bridge copies `activityToken` from the page URL into the WebSocket query string and falls back to `ws://` on HTTP pages. That exposes the Activity secret to URLs, logs, referrers/intermediaries, and cleartext transport on misconfigured hosts; use a secure cookie, protocol, or exchange flow instead.
  - confidence: 0.9
- **[P2] Clear failed Discord SDK loads so retries can recover:** `src/canvas-host/a2ui.ts:202-208`
  - body: If the CDN import or `DiscordSDK.ready()` fails once, the rejected promise remains in `state._loadPromise`, so later `OpenClaw.discord.load()` calls keep reusing the same failure until page reload. Clear the cached promise on failure so transient network or Discord readiness errors can retry.
  - confidence: 0.86
