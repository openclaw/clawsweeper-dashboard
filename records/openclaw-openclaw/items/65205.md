Overall confidence: 0.9

Full review comments:

- **[P1] Move Activity config under the Canvas plugin contract:** `src/config/types.gateway.ts:41-59`
  - body: Current main moved Canvas host ownership into `extensions/canvas` and migrates legacy root `canvasHost` into `plugins.entries.canvas.config.host`, but this PR adds a new root `canvasHost.activity` surface. Landing that reopens a retired core config owner and splits Activity behavior between core and the Canvas plugin, so plugin installs, doctor migrations, and docs can drift.
  - confidence: 0.91
- **[P1] Require credentialed Activity auth before bypassing Gateway auth:** `src/gateway/a2ui-activity.ts:150-154`
  - body: `isCanvasActivityAccessAllowed` returns true when Activity mode is enabled and no token is configured after only accepting spoofable query/cookie/referer launch markers. Since `authorizeCanvasRequest` accepts that result before bearer/capability auth, an external request with a fake launch marker can reach Canvas/A2UI routes without Gateway credentials.
  - confidence: 0.95
- **[P1] Stop loading the Discord SDK from public CDNs:** `src/canvas-host/a2ui.ts:172-176`
  - body: The injected Canvas helper executes `@discord/embedded-app-sdk` from jsDelivr with an esm.sh fallback inside the Canvas origin. Production Gateway pages should not delegate executable code integrity to public CDN resolution; bundle/pin this through owned assets or a plugin-controlled runtime path.
  - confidence: 0.9
- **[P1] Bound Activity broadcasts before fanning out:** `src/gateway/a2ui-activity.ts:240-243`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected Activity WebSocket client without size limits or backpressure checks. Because `node.invoke` can forward A2UI payloads into this hub, a large or repeated payload can retain memory and stall Gateway WebSocket sends.
  - confidence: 0.88
- **[P1] Keep Activity tokens out of URLs and cleartext WebSockets:** `src/canvas-host/a2ui/index.html:325-329`
  - body: The browser bridge reads `activityToken` from the page URL and appends it to the Activity WebSocket query, using `ws://` when the page is served over HTTP. That exposes a bearer-style secret through browser history, logs, referrers, and non-TLS connections; use a secure cookie/server-side exchange and require WSS for tokened traffic.
  - confidence: 0.89
- **[P2] Clear the failed SDK load promise before retrying:** `src/canvas-host/a2ui.ts:166-210`
  - body: If the SDK import or `sdk.ready()` path rejects once, `state._loadPromise` remains set to the rejected promise. Later `OpenClaw.discord.load()` calls re-await the same failure, so a transient Discord/CDN/ready timeout cannot recover without a full page reload.
  - confidence: 0.86

## Security Review

Status: needs_attention

Summary: The PR changes public Gateway/Canvas auth and browser-executed code paths and still has concrete auth-bypass, token-transport, CDN code-loading, and DoS concerns.

Concerns:

- **[high] Credentialless Canvas Activity auth bypass:** `src/gateway/a2ui-activity.ts:150`
  - body: Activity-enabled deployments without a configured token can accept spoofable launch markers before normal Gateway auth, exposing Canvas/A2UI routes to unauthenticated requests.
  - confidence: 0.95
- **[high] Remote SDK execution in Canvas origin:** `src/canvas-host/a2ui.ts:172`
  - body: The injected helper imports executable SDK code from public CDNs at runtime, which creates supply-chain exposure for hosted Canvas pages.
  - confidence: 0.9
- **[medium] Activity token leakage through URLs and ws://:** `src/canvas-host/a2ui/index.html:325`
  - body: The browser bridge propagates activityToken in query strings and uses ws:// for HTTP pages, exposing bearer-like tokens to logs, referrers, browser history, and cleartext transport.
  - confidence: 0.89
- **[medium] Unbounded Activity WebSocket fanout:** `src/gateway/a2ui-activity.ts:240`
  - body: The Activity hub stores and broadcasts unbounded payloads to all clients without backpressure, which can become a memory or event-loop availability issue.
  - confidence: 0.88
