  - body: Late discovery on the unchanged head: current main no longer owns Canvas under `src/canvas-host`; the A2UI/Canvas routes and config now live under `extensions/canvas` with plugin auth.   - late: true

  - body: `isCanvasActivityAccessAllowed` returns true when Activity mode is enabled without a configured token, and `authorizeCanvasRequest` accepts that before normal Gateway auth. Query/cookie/referer launch markers are spoofable, so public Activity access must fail closed unless a real credential or approved exchange is present.
  - confidence: 0.96
- **[P1] Move Activity config under the Canvas plugin contract:** `src/config/zod-schema.ts:660-667`
  - body: This adds `canvasHost.activity` to the legacy root config surface, but current main migrates root `canvasHost` into `plugins.entries.canvas.config.host` and hides the root key from public schema output. Activity settings should live in the Canvas plugin config or an explicit maintainer-approved migration path.
  - confidence: 0.94
- **[P1] Stop carrying Activity tokens through URLs:** `src/canvas-host/a2ui/index.html:325-329`
  - body: The browser bridge reads `activityToken` from the page query and appends it to the WebSocket URL, with `ws://` on HTTP. That exposes credentials through URLs, logs, referrers, browser history, and cleartext transport on misconfigured hosts; use a non-URL credential path or server-side exchange.
  - confidence: 0.93
- **[P1] Stop loading the Discord SDK from public CDNs:** `src/canvas-host/a2ui.ts:171-176`
  - body: The injected helper dynamically imports executable SDK code from jsDelivr or esm.sh at runtime. For a Gateway-hosted surface, this should be pinned and bundled or otherwise owned by the plugin so a CDN/dependency-resolution change cannot run arbitrary code in the Canvas origin.
  - confidence: 0.91
- **[P2] Bound Activity broadcasts before retaining and fanning out:** `src/gateway/a2ui-activity.ts:240-243`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected Activity WebSocket with no byte limit or buffered-send policy. A large payload or slow clients can grow Gateway memory and stall the event loop; enforce payload limits and backpressure before retaining or broadcasting.
  - confidence: 0.9
- **[P2] Clear failed Discord SDK load promises:** `src/canvas-host/a2ui.ts:166-208`
  - body: If `OpenClaw.discord.load()` fails once, the rejected `_loadPromise` is retained and every later call re-awaits the same rejection. Clear the cached promise on failure so transient CDN, network, or `ready()` failures can recover without a full page reload.
  - confidence: 0.86
