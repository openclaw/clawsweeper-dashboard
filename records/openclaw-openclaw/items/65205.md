- **[P1] Move Activity config under the Canvas plugin contract:** `src/config/zod-schema.ts:660-667`
  - body: Current main treats root `canvasHost` as legacy migration input and routes Canvas through `plugins.entries.canvas.config.host`.   - confidence: 0.93
- **[P1] Require credentialed Activity auth before bypassing Gateway auth:** `src/gateway/a2ui-activity.ts:151-154`
  - body: With `activity.enabled` and no token, this returns true after checking only query/cookie/referer launch markers. Because Canvas authorization calls this before bearer or capability auth, an external caller can spoof the launch markers and reach Canvas/A2UI without normal Gateway auth.
  - confidence: 0.96
- **[P1] Stop loading the Discord SDK from public CDNs:** `src/canvas-host/a2ui.ts:173-175`
  - body: The injected helper executes `@discord/embedded-app-sdk` from jsDelivr or esm.sh inside the Canvas page origin at runtime. That adds an unpinned third-party code execution boundary to a Gateway-served surface; bundle or otherwise pin/control the SDK before exposing it.
  - confidence: 0.91
- **[P1] Bound Activity broadcasts before fanning out:** `src/gateway/a2ui-activity.ts:240-243`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected WebSocket without a size limit, send queue check, or slow-client policy. A large A2UI payload or many slow clients can grow memory and stall the Gateway.
  - confidence: 0.9
- **[P1] Stop carrying Activity tokens in URLs:** `src/canvas-host/a2ui/index.html:325-329`
  - body: The browser bridge reads `activityToken` from the page URL and appends it to the WebSocket URL, falling back to `ws://` on HTTP. That leaks the token through URLs, logs, referrers, and cleartext transport on misconfigured hosts.
  - confidence: 0.9
- **[P2] Clear the failed Discord SDK load promise:** `src/canvas-host/a2ui.ts:203-208`
  - body: If `OpenClaw.discord.load()` fails once, the rejected promise remains in `state._loadPromise`; later calls re-await the same failure and cannot recover without a page reload. Clear the cached promise on failure if this helper remains after the SDK-loading design is fixed.
  - confidence: 0.86
