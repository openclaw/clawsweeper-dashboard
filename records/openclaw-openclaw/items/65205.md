  - body: `isCanvasActivityAccessAllowed` returns true when no token is configured after accepting launch-context markers that are only query/cookie/referrer values.   - confidence: 0.96

  - body: The injected Canvas helper imports executable SDK code from jsDelivr and esm.sh at runtime. Production Activity pages should use a package-pinned/bundled SDK or another maintainer-approved supply-chain path so dependency review, lockfiles, and CSP can cover the code being executed.
  - confidence: 0.91
- **[P1] Bound Activity broadcasts before fanning out:** `src/gateway/a2ui-activity.ts:240-243`
  - body: `broadcastPush` stores arbitrary JSONL and sends it to every connected Activity WebSocket without size or `bufferedAmount` checks. A large A2UI payload or slow clients can create unbounded memory/CPU pressure on the Gateway process.
  - confidence: 0.9
- **[P1] Stop carrying Activity tokens in URLs:** `src/canvas-host/a2ui/index.html:325-329`
  - body: The browser bridge reads `activityToken` from the page query and reconnects with it in the WebSocket URL, while the server also accepts tokens from referrers.   - confidence: 0.93

  - confidence: 0.86
