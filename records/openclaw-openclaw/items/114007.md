## Summary

## What This Changes

The issue requests bounded retention or smaller stored payloads for trajectory runtime events so long-lived agent SQLite databases cannot grow indefinitely as session count increases.

## System Context

Trajectory capture records runtime events for agent sessions in each agent's SQLite database. Event capture feeds the runtime-store persistence layer, which currently limits data per session; the retained rows then affect database size, shutdown work, and restart readiness on long-lived hosts.
