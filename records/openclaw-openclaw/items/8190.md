## Summary

Current main still lacks a global, context-preserving auth refresh/reset across active sessions; the remaining work crosses Gateway protocol, session lifecycle, auth-provider routing, and security-sensitive credential invalidation, so it should stay open for maintainer product/security review.

## What This Changes

The issue requests a global session reset or auth-refresh action that switches active sessions to current auth credentials while preserving conversation context across channels.

## Best Possible Solution

Define an additive, admin-scoped Gateway/session auth-refresh contract that enumerates active sessions, invalidates stale auth-backed runtime state, preserves intended context and user selections, and documents security semantics.
