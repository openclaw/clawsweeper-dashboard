Keep open: current main and v2026.6.11 still expose single-session reset and per-session CLI auth invalidation, but not the requested global, context-preserving auth refresh/reset across active sessions.

## What This Changes

Request adds a global auth-switch session refresh/reset that invalidates stale active-session auth while preserving conversation context across channels.

## Best Possible Solution

Design an additive, admin-scoped Gateway/session auth-refresh contract that enumerates active sessions, invalidates stale auth-backed runtime state, preserves intended context and user selections, and documents security semantics.
