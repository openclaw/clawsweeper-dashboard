## Summary

## What This Changes

Add a global session auth-refresh/reset capability that updates all active sessions after an auth or provider switch without discarding their context.

## Best Possible Solution

Define an additive, admin-scoped global auth-refresh lifecycle that invalidates only auth/runtime bindings while preserving canonical session IDs and transcripts, then cover authorization, active-run behavior, partial failures, and provider/session override precedence with focused gateway and session-store tests.
