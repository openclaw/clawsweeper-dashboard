## Summary

This remains necessary as a product-design issue: it proposes a new privileged gateway and persisted-session contract, not a confirmed regression or an already-landed implementation. The request needs an owner decision on whether durable session-scoped prompt provenance belongs in core and, if so, its authorization, visibility, precedence, and inheritance rules.

## What This Changes

Add an operator-authorized `sessions.create` input that persists a bounded system-prompt addition with a session and layers it into later session runs.

## System Context

The Gateway accepts operator session-creation requests and persists canonical session metadata for later adoption and restart. Reply execution then combines session state with agent, group, and per-run prompt inputs before calling the selected model.
