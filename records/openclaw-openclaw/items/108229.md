## Summary

This remains a useful, proof-positive memory-core bug fix rather than a cleanup candidate. The final branch handles optional-provider initialization failures, preserves explicit-provider fail-closed behavior, and adds focused coverage for fresh FTS-only indexes and read-only fallback over existing semantic indexes; the remaining gate is a memory-core owner decision on the intentional upgrade behavior when previously semantic indexes lose optional credentials.

## What This Changes

The branch converts unavailable optional memory embedding providers into FTS-only mode, keeps existing semantic indexes read-only during that fallback, and adds regression coverage for index identity, sync cleanup, and tool search behavior.

## Best Possible Solution

Keep explicit providers fail-closed, land the optional-provider FTS fallback only after confirming that read-only stale keyword recall is the preferred recovery contract for existing semantic indexes, and retain the new fresh-index and no-vector-table regression coverage.
