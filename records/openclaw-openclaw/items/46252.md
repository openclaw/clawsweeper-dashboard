## Summary

Keep open: current main counts reset/deleted archives for global usage and archive-only discovery, but per-session summary, cache, time-series, and logs still resolve a single active transcript when one exists; https://github.com/openclaw/openclaw/pull/92610 remains the open closing fix candidate.

## What This Changes

The issue asks for cost and usage views to include `.jsonl.reset.*` archived transcripts created by `/new` or `/reset` so daily and per-session spend are not undercounted.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92610 with a bounded fix that aggregates canonical usage-counted active plus reset/deleted lineage files for per-session summary, cache, time-series, and logs while excluding backups and checkpoints.

Yes, source-reproducible without a live run: when `<id>.jsonl` and same-stem `.jsonl.reset.*` files coexist, current main returns the active transcript and scans only that file for per-session summary, time-series, and logs. ## Solution Assessment
