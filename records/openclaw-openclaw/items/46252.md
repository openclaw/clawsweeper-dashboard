## What This Changes

The issue asks for cost and usage views to include reset/deleted session archive transcripts so `/new` or `/reset` history is not dropped from spend totals.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92610 with a narrow per-session lineage aggregation that merges active plus same-stem reset/deleted transcripts through the existing usage-counted filename contract while excluding `.bak`, checkpoint, and trajectory artifacts from cost totals.
