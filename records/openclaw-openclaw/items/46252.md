## Summary

Keep open: current main includes reset/deleted archives in global usage discovery, but the per-session summary, time-series, logs, and cache paths still resolve and scan one transcript file when an active primary exists. The open linked PR remains the candidate fix, so this issue should stay open until that PR or an equivalent fix lands.

## What This Changes

The issue reports undercounted cost/dashboard usage because reset archive transcripts created by `/new` are omitted from historical session cost calculations.

## Best Possible Solution

Review and land or replace the open per-session lineage fix so summary, cache, time-series, and logs aggregate active plus same-stem reset/deleted transcripts without counting backups.
