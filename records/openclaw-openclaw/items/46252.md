## Summary

Keep open: current main and the latest release count reset/deleted archives for global usage and archive-only fallback, but per-session summary, cache, time-series, and logs still resolve one active transcript when it exists; https://github.com/openclaw/openclaw/pull/92610 remains the open closing fix candidate.

## What This Changes

The issue reports that the cost dashboard and session usage views undercount spend when `/new` or reset creates `.jsonl.reset.*` archive transcripts next to active `.jsonl` files.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/92610 with a bounded fix that aggregates canonical active plus reset/deleted lineage files for per-session summary, cache, time-series, and logs while excluding backups and checkpoints; track broader filename classes separately.
