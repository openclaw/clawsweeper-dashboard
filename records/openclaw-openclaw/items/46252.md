## Summary

Keep open: current main is archive-aware for global usage and archive-only fallback, but active per-session detail/cache/time-series/log paths still resolve and scan one active transcript, so same-stem reset/deleted archives remain undercounted until the linked closing PR lands or is replaced.

The issue requests cost dashboard and session usage accounting to include `.jsonl.reset.*` archive files created by `/new` or `/reset`.

## Best Possible Solution
