## What This Changes

This PR replaces LINE actions whose opaque callback data or URLs exceed provider limits with bounded unavailable actions, including raw Flex payloads sent through push and reply APIs.

## System Context

OpenClaw's LINE plugin converts directive-generated cards and raw channel payloads into LINE Messaging API messages. Card builders and the final push/reply send boundaries now normalize actions before LINE receives a payload that could reject an entire reply.
