## What This Changes

The PR centralizes LINE action validation across cards, templates, rich menus, imagemaps, and send boundaries so over-limit actions are replaced with a deliverable unavailable-action fallback instead of making LINE reject the entire reply.

## System Context

The LINE plugin converts agent reply directives and card builders into Messaging API actions, then sends the resulting message through the LINE SDK. Invalid action fields can make LINE reject the whole payload, so this change normalizes actions before they reach the outbound API boundary.
