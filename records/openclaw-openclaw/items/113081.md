## Summary

The branch has a credible delivery-preserving fix for the linked LINE overflow bug, but the contributor explicitly reports that the current fallback/warning implementation lacks current-head live LINE proof and leaves a real policy choice for full imagemaps.

## What This Changes

The PR centralizes LINE action-size normalization across card builders, templates, imagemaps, and outbound push/reply calls so oversized callback data or URLs degrade without causing LINE to reject the whole reply.

## System Context

OpenClaw's LINE plugin turns agent directives and card helpers into Flex, template, and imagemap payloads, then submits them through LINE push or reply APIs. Action fields that exceed LINE caps can make LINE reject the entire outbound message, so this change validates them both when cards are built and immediately before delivery.
