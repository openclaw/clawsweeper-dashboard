## What This Changes

The branch normalizes LINE action objects in card, template, and send paths so invalid oversized postback callbacks or URI actions become a deliverable “Unavailable” action instead of causing LINE to reject the entire reply.

## System Context

The LINE plugin converts agent directives and card data into LINE action objects, then submits message payloads to the LINE Messaging API. This PR hardens the action-construction and final-send boundary so one invalid interactive control does not make the whole reply undeliverable.

## Best Possible Solution

Land a single shared LINE action-normalization policy that preserves valid controls, replaces only unrecoverable oversized callback or URL actions with a provider-valid fallback, and retains the send-boundary safeguard for raw Flex payloads.
