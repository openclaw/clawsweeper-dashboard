## Summary

Keep open: current main has improved plain-text tool-call repair, but it still does not promote the reported special tagged tool calls when they exist only inside thinking content. ## What This Changes

The issue reports model-specific subagent truncation where Qwen/ModelStudio-style tagged tool calls in thinking blocks are not converted into structured tool calls, causing premature completion output.

## Best Possible Solution

Add a narrowly gated provider-owned Qwen/ModelStudio normalization path, or a shared helper approved for that provider family, that promotes only validated standalone tagged thinking sections for allowed tools and proves the behavior with live provider evidence.
