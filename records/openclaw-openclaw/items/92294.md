## Summary

The patch remains necessary on current `main`, has no concrete correctness finding, and has strong before/after proof; keep it open for an explicit area-owner decision on the intentional direct-shell security boundary.

## What This Changes

The PR restores policy-filtered OpenClaw `exec` and `process` tools for direct Codex app-server turns and `/btw` side questions when no Codex execution environment exists, and extracts node-shell adapters into a dedicated module.

## Best Possible Solution

Land the bounded zero-environment fallback after owner approval, retain the existing policy and exclusion gates, and track explicit-allowlist tool-surface failures separately rather than broadening this PR.
