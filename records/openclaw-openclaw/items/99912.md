Keep open: the latest reporter evidence and current source indicate the older cron-agent reload fix does not settle the newer `session.scope: "global"` heartbeat path. ## What This Changes

The issue requests that per-agent heartbeats execute in the configured agent's own session and workspace, including when `isolatedSession` is enabled and global/direct-message session scoping is configured.
