## Summary

Keep open: the latest reporter evidence and current source both point to an unresolved global-session-scope secondary-agent heartbeat routing bug, distinct from the stale-runtime reload case already covered by https://github.com/openclaw/openclaw/pull/65085. Current main and v2026.6.11 still collapse global-scope heartbeat sessions to the literal `global` session/default-agent store path, so this needs maintainer/live reproduction rather than cleanup closure.

## What This Changes
