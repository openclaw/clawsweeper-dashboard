## Summary

Keep open: current main and v2026.6.11 still lack Discord category-level guild allowlist inheritance, and this issue remains the canonical tracker for an authorization-sensitive config decision.

## What This Changes

The issue requests Discord guild allowlist support for category-level channel configuration so child channels inherit settings without per-channel config edits or gateway restarts.

## Best Possible Solution

Maintainers should approve one Discord-owned category inheritance contract, then implement it with explicit channel-over-category precedence, schema/types/docs/status/audit updates, and focused ingress tests.
