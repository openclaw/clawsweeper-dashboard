## Summary

Keep open. Current main and v2026.6.11 still expose Discord reactions as routed system events, but the public plugin hook contract has no reaction add/remove hook and the related wake-policy work is adjacent rather than a replacement.

Define a maintainer-approved observation-only reaction hook contract, then wire Discord through the existing authorized reaction notification path while keeping reaction-triggered agent wakeups in the separate wake-policy track.
