## Summary

Keep open. Current main and v2026.6.11 still convert accepted Discord reactions into routed system events, but the public plugin hook API has no reaction add/remove hook; the open reaction-wake and broader external non-message-event items are adjacent rather than replacements.

## What This Changes

Request to expose Discord reaction add/remove events through the plugin Hooks system so plugins can automate on user reactions.

## Best Possible Solution

Define a maintainer-approved observation-only reaction hook contract, then wire Discord through the existing authorized reaction notification path while keeping reaction-triggered agent wakeups in the separate wake-policy track.
