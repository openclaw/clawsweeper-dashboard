## Summary

Keep open. Current main and latest v2026.6.11 still expose Discord reaction notifications only as routed system events, not as typed plugin hook events, and the requested public hook contract needs maintainer API/product review rather than cleanup closure.

## What This Changes

The issue requests Discord reaction add/remove events in the plugin Hooks system so plugins can automate reaction-driven workflows.

## Best Possible Solution

Define a maintainer-approved observation-only reaction hook contract at the plugin SDK boundary, then wire Discord reactions through it while preserving existing reaction notification system events and access gating.
