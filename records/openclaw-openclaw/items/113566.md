## What This Changes

This PR moves browser-tab cleanup from the Gateway’s scheduled-cron wrapper into the shared isolated agent-run finalizer, using the detached run’s canonical session key so scheduled and hook-triggered runs clean their own tabs.

## System Context

Scheduled cron jobs and hooks both invoke OpenClaw’s isolated agent-run lifecycle, which creates a detached session key for the run. Browser tabs are stored against that exact key, so final lifecycle cleanup must use the detached identity before the run exits.
