## What This Changes

Updates browser auto-discovery on macOS and Linux to ignore non-regular or non-executable browser candidates and continue to a later runnable candidate, with regression coverage and a separate SQLite smoke-test timeout increase.

## System Context

The bundled browser plugin resolves a browser executable from platform-specific discovery candidates before browser automation launches it. This change affects the candidate-selection step so a stale path does not prevent a later installed browser from being selected.
