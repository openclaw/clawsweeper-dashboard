## What This Changes

The PR changes browser auto-discovery so macOS and Linux skip candidates that are not executable regular files and continue searching for a later runnable supported browser.

## System Context

The bundled browser plugin discovers a local Chrome-family executable before browser automation starts. Operating-system and Playwright candidate paths enter discovery, which selects one executable path for the subsequent browser launch.
