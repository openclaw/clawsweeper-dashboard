## What This Changes

This PR changes the bundled Codex extension to discover connected apps from `app/installed`, enrich them through batched `app/read` requests, and retain `app/list` only for supported older app-server versions.

## System Context

The Codex extension starts a native Codex app-server for provider runs, installs configured plugins, and builds the enabled-app policy sent to each Codex thread. The changed inventory cache turns app-server runtime and metadata responses into the existing OpenClaw plugin-policy input.
