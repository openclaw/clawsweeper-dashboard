## Summary

Current main still stores variable-size dynamic-tool and user-MCP fingerprints inside one Codex binding value, so the documented 65,536-byte plugin-state limit can stop an agent run before it responds. This protected beta blocker should remain open while the directly linked candidate fix is reviewed and resolved.

## What This Changes

Store bounded deterministic Codex app-server binding fingerprints so large dynamic-tool and user-MCP surfaces cannot exceed the plugin-state per-value limit.

## Best Possible Solution

Land the owner-local bounded-hash implementation from the linked PR after focused tests and a real plugin-heavy Codex smoke, while retaining the [] sentinel for transient no-tool turns.
