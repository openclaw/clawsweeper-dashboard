## Summary

Keep open: current main and v2026.6.11 still provide only coarse compaction start/end visibility plus generic diagnostics, while the requested staged WebChat lifecycle, compaction-specific diagnostics API/CLI, and running-summary guidance remain partly unresolved.

## What This Changes

The issue requests staged WebChat compaction progress events, a compaction watchdog diagnostics surface, and clearer context-engine guidance for running-summary style pre-compaction.

## Best Possible Solution

Define a narrow core observability contract for safe staged compaction events and redacted diagnostics, while keeping running-summary acceleration as a context-engine plugin pattern unless a concrete SDK gap is found.
