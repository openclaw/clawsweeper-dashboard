## What This Changes

The issue reports that 1Password CLI exec secret providers can spawn cache-daemon processes and hang on macOS Tahoe unless `--cache=false` or `OP_CACHE=false` is supplied.

## Best Possible Solution

Document and diagnose the 1Password cache workaround first using the existing exec-provider `env` or `args` surface, and add generic runtime behavior only if maintainers explicitly choose that broader exec-provider contract.
