## What This Changes

The PR stores the authorization-server issuer alongside an MCP OAuth refresh token, refuses to give the token to the MCP SDK after discovery selects a different issuer, and migrates recoverable issuer provenance from older stored rows.

## System Context

OpenClaw stores MCP OAuth credentials in its shared SQLite state database, then its bearer wrapper asks the MCP SDK to discover authorization metadata and refresh access tokens for remote MCP requests. The changed provider is the credential handoff seam between persisted tokens and the SDK’s token-endpoint requests.
