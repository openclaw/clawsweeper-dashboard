## Summary

Keep open for an explicit maintainer scope ruling. Current main has no first-class RCS channel, but its public channel SDK and the SMS package’s npm/ClawHub distribution model support an external implementation; the issue is intentionally paired with an open PR and should remain open until maintainers choose the ownership tier.

## What This Changes

Add a first-class Twilio-backed RCS channel alongside SMS, including rich messages, suggested actions, delivery/read receipts, branded sender support, and RCS-specific webhook handling.

## Best Possible Solution

Publish the existing implementation as an independently maintained channel plugin through npm and ClawHub unless maintainers explicitly sponsor bundled ownership; a sponsored core path should require assigned ownership and live Twilio RCS end-to-end proof before merge.
