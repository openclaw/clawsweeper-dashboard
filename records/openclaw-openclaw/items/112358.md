## What This Changes

This PR lets Google Meet `test-speech` callers supply a bounded per-request timeout, forwarding it from the CLI and tool Gateway paths to the audio-output probe while retaining the existing default wait when omitted.

## System Context

The Google Meet plugin accepts probe requests from the CLI and the agent tool, routes them through a Gateway handler, then polls Chrome audio health after joining a meeting. This change adjusts the requested speech-probe wait and the client RPC deadline so callers can receive the eventual probe result instead of a fixed short timeout.
