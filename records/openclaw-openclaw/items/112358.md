## What This Changes

The PR adds an explicit `--timeout-ms` path for Google Meet `test-speech`, forwards it through Gateway and tool calls, extends the caller deadline, and keeps the five-second default when no timeout is supplied.

## System Context

Google Meet is a bundled meeting plugin that exposes CLI and agent-tool probe actions through the Gateway. A speech probe joins or reuses a meeting session, then waits for Chrome audio-bridge health signals and returns a verification or timeout result.
