## Summary

## What This Changes

Request to prevent memory compaction and memoryFlush from blocking Telegram or other foreground message processing when session maintenance hangs or runs long.

## Best Possible Solution

Implement a maintainer-approved isolated or preemptible compaction/memoryFlush scheduling design that keeps foreground messages admitted or visibly recoverable without corrupting transcript ordering or compaction rotation.
