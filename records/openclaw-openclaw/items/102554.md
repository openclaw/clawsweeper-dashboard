## Summary

Keep open: the current head fixes the earlier public run-params API issue, but the replacement AsyncLocalStorage guard can leak into async work spawned by prompt-build hooks and make later non-raw embedded runs skip hooks.

## What This Changes

The PR makes prompt-build hook suppression implicit via an AsyncLocalStorage reentrancy guard around embedded-attempt hook resolution and adds helper/active-memory tests for the active-memory recall sub-run.

## Best Possible Solution

Keep the active-memory reentrant recall fix, but make the hook-skip marker expire after the awaited hook dispatch and add a regression test for delayed async children.
