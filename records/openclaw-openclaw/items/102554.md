## Summary

Keep this PR open: the latest head fixes the previous public plugin-runtime API blocker, but the new AsyncLocalStorage guard can leak the hook-skip state into delayed async work created by prompt hooks, so normal later embedded runs may silently skip queued injections and prompt-build hooks.

## What This Changes

Adds an internal prompt-build-hook reentrancy guard around embedded-run prompt hook dispatch, with focused helper and active-memory recall tests.

## Best Possible Solution

Keep hook suppression internal and limited to the awaited nested recall sub-run, with regression coverage proving delayed async work scheduled from a hook does not inherit the skip state.

- **[P1] Prevent hook-skip state from leaking to delayed work:** `src/agents/embedded-agent-runner/run/attempt.prompt-helpers.ts:113`
  - body: `AsyncLocalStorage.run(true, ...)` marks every async resource created by a prompt hook, not only the awaited nested recall run. A `before_prompt_build` handler that schedules later work, such as a timer or promise callback that calls `runEmbeddedAgent`, will still make `shouldSkipPromptBuildHooks` return true after hook dispatch has returned, so that normal plugin-initiated run silently loses queued injections and prompt-build hooks. Keep the marker limited to the actual in-flight nested run or explicitly clear it for detached async descendants.
  - confidence: 0.86
