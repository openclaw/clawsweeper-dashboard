## Summary

Keep open: the caller-settable plugin API concern is resolved, but the prior P1 remains because the current AsyncLocalStorage marker can survive completed hook dispatch in inherited asynchronous resources; the live proof validates the intended recall behavior but not this lifetime boundary.

## What This Changes

The branch wraps embedded-agent prompt-build hook resolution in an internal AsyncLocalStorage reentrancy guard and adds helper and active-memory regression tests so nested recall runs skip the prompt-build hook family.

## Best Possible Solution

Use a per-dispatch mutable token stored in AsyncLocalStorage, deactivate it in a `finally` block when hook dispatch settles, and retain hook suppression only while that token is active, with a delayed-child regression test.
