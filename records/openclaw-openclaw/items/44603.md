## What This Changes

The issue requests a global `tools.exec.pty` config option so long-running exec commands can default to PTY streaming without relying on each model tool call to pass `pty: true`.

## Best Possible Solution

If maintainers approve the config surface, add a default-off `tools.exec.pty` contract across schema, types, resolved defaults, direct exec, gateway approval exec, docs, and focused tests while preserving per-call override precedence and coordinating sandbox behavior.
