## Summary

Keep open: current main and v2026.6.11 still expose PTY only as a per-call exec parameter, while the requested global `tools.exec.pty` default is absent from schema, resolved defaults, runtime wiring, and docs. ## What This Changes

The issue requests a global `tools.exec.pty` default so long-running exec commands can stream output without every tool call explicitly passing `pty: true`.

## Best Possible Solution

If maintainers approve the config surface, add a default-off `tools.exec.pty` contract across schema, types, resolved defaults, direct exec, gateway approval exec, docs, and focused tests while preserving per-call override precedence and coordinating sandbox behavior.
