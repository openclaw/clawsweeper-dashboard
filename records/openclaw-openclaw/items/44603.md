## Summary

Keep open: current main and v2026.6.11 still expose PTY only as a per-call exec parameter, while the requested global `tools.exec.pty` default is absent from schema, types, default resolution, and docs. The remaining blocker is maintainer approval for a new security-sensitive exec configuration surface.

## What This Changes

The issue requests a global `tools.exec.pty` setting so exec commands can default to PTY mode and stream intermediate output without every tool call passing `pty:true`.

## Best Possible Solution

If approved, add a default-off `tools.exec.pty` contract across schema, types, resolved defaults, direct and gateway exec, docs, and focused tests while preserving per-call override precedence and explicit sandbox behavior.
