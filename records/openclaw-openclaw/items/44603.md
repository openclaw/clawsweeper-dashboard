## Summary

Keep open: current main and v2026.6.11 still expose PTY only as a per-call exec parameter, while the requested global `tools.exec.pty` default is absent from schema, types, runtime default resolution, and docs. The remaining blocker is maintainer approval for a new security-sensitive exec configuration surface.

## What This Changes

The issue requests a global `tools.exec.pty` config setting so exec calls can default to PTY streaming without relying on each model call to pass `pty: true`.

## Best Possible Solution

If approved, add a default-off `tools.exec.pty` contract across schema, types, resolved defaults, direct and gateway exec, docs, and focused tests while preserving per-call override precedence and sandbox suppression behavior.
