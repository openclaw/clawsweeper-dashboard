  - body: In explicit fallback mode, this catch path retries every thrown error while `allowFallback` is true. That can send auth, permission, bad-request, unsupported-filter, or deterministic provider-specific failures to later providers; add a terminal/recoverable classifier before retrying.
  - confidence: 0.87

  - body: Configured fallback ids are looked up in the loaded candidate set and missing entries are filtered out, so a typoed fallback looks configured while never running. Surface unresolved ids through validation, diagnostics, or the final fallback error instead of silently ignoring them.
  - confidence: 0.84
