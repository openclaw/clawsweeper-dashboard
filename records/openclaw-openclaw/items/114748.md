## What This Changes

This PR makes Control UI board reads avoid widget HTML BLOBs, lengthens widget-view ticket lifetime, and reduces redundant refreshes from hidden, collapsed, and same-tick board consumers.

## System Context

The Control UI calls the gateway's board API to obtain board state and short-lived widget frame tickets. The gateway reads board storage, issues frame URLs, and the UI refreshes those tickets while board widgets remain active.
