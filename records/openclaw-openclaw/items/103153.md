## Summary

Keep open: the exact reviewed head still contains the prior P1 blocker. The summary-chunk worker receives projected messages and returns those projected messages as summary material, so oversized tool-result content can be silently replaced by its bounded sample during compaction.

## What This Changes

Bounds compaction-planning worker payloads by sampling oversized tool-result text and removing image bytes while retaining conservative token-pressure metadata.

## Best Possible Solution

Keep projection data worker-internal: return chunk boundaries or message indexes from planning, rebuild summary chunks from the original sanitized messages, and add a packaged-worker regression asserting identical serialization for oversized text.
