## Summary

The availability fix remains useful, but the branch currently lets planning projections escape the worker boundary and replace original oversized tool-result content in downstream compaction outputs; that silent summary-input change should be repaired before merge.

## What This Changes

Bounds compaction-planning worker payloads by sampling oversized tool-result text and removing image bytes while preserving conservative planning pressure.

## Best Possible Solution

Keep projections strictly inside planning: return structural plans or message indexes from the worker, reconstruct message-bearing results from the original sanitized arrays on the main thread, and prove exact serialized-summary equivalence for oversized text and images.
