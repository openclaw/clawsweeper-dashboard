## Summary

Keep open: current `main` and the latest stable tag still build Gmail watcher serve args without `--exclude-labels`, and https://github.com/openclaw/openclaw/pull/56720 is still the open candidate fix for this issue.

## What This Changes

Restore Gmail watcher excluded labels so sent mail, drafts, spam, and trash do not trigger Gmail hook processing.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/56720, or replace it with a narrow fix that restores DRAFT/SENT filtering in the shared Gmail watcher argv builder before closing this issue.

## Reproduction Assessment

Yes, at source level. Current main resolves Gmail watcher runtime config and builds the shared serve argv without `--exclude-labels`, while gogcli defaults only exclude `SPAM,TRASH`.

## Solution Assessment

Yes for the narrow default restoration in `buildGogWatchServeArgs`. The configurable `hooks.gmail.excludeLabels` part of the open PR is a maintainer choice, but a new config option is not required to fix the reported regression.
