## Summary

Keep open: current main and `v2026.6.11` still build the Gmail watcher serve argv without `--exclude-labels`, and https://github.com/openclaw/openclaw/pull/56720 is an open candidate fix that has not merged.

## What This Changes

The issue requests restoring Gmail watcher excluded-label handling so SENT and DRAFT changes do not trigger Gmail hook processing.

## Best Possible Solution

Land a refreshed Gmail watcher fix that restores DRAFT/SENT exclusions by default, either as a narrow default restore or with maintainer-approved, tested `hooks.gmail.excludeLabels` semantics.

## Reproduction Assessment

Yes, at source level. Current main and `v2026.6.11` build the shared Gmail watcher argv without `--exclude-labels`, while upstream gogcli defaults only exclude `SPAM,TRASH`; I did not run a live Gmail watcher in this read-only review.

## Solution Assessment

Yes for the narrow bug: restoring the default excluded labels in the shared Gmail serve-argv helper is the right fix location. A configurable `hooks.gmail.excludeLabels` surface is optional and should land only with accepted semantics and proof.
