## What This Changes

Fix Tool Search catalog snapshots so finished embedded runs do not retain run-scoped tool wrappers and their completed gateway object graphs.

## System Context

Embedded agent runs build a Tool Search catalog before calling the model. The catalog lifecycle records active state for the run and may retain reusable snapshots for later runs; incorrect retention can keep completed run/session data alive in the long-lived gateway process.
