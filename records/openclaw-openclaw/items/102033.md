## Summary

Keep open. The forward-only scanner is aimed at a real web_fetch HTML-conversion hang surface, but this PR is not merge-ready because the new attribute reader can pick href-looking text from another attribute and the external PR has only test proof, not real behavior proof.

## What This Changes

The PR replaces regex-based web_fetch HTML-to-markdown fallback conversion with a forward-only scanner, raw-text block handling, adjusted fenced-code stripping, and focused utility tests.

## Best Possible Solution

Keep the scanner direction, but parse attributes while respecting quoted values and valid attribute-name delimiters, add a regression for misleading href-like attributes, and include redacted terminal/live proof for a large or malformed HTML conversion run.
