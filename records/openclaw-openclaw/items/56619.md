## Summary

Keep open: current main and the latest release still expose `pairing approve --notify`, but WhatsApp has no pairing approval notifier, and the exact prior fix PRs are closed unmerged rather than superseding this issue.

## What This Changes

The issue asks for WhatsApp senders approved through DM pairing to receive a same-channel approval notification instead of guessing when to retry.

## Best Possible Solution

Ship a focused WhatsApp implementation for the existing `--notify` approval flow with targeted tests and redacted live WhatsApp or gateway proof; leave default-on notification and original-message replay as separate product decisions.
