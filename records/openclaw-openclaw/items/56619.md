## Summary

Keep open: current main and the latest release still expose the pairing approval notification path, but WhatsApp does not implement the adapter hook that would deliver the same-channel approval message. The earlier WhatsApp notification PRs are closed unmerged, and the currently open pairing-request hook PR is adjacent rather than a fix for approval notification.

## What This Changes

Request to notify a newly approved WhatsApp sender after DM pairing approval, preferably through the existing pairing approval notification flow.

## Best Possible Solution

Add a WhatsApp-owned implementation for the existing pairing `--notify` approval seam using the shared approval message and outbound WhatsApp send path, with focused tests and no new config/default/replay behavior unless maintainers approve that separately.
