## Summary

Keep open: current main and v2026.6.11 still expose the shared `pairing approve --notify` path, but WhatsApp has no `notifyApproval` adapter hook, so approval notification delivery still no-ops for the reported channel. The direct fix PRs are closed unmerged, and the currently open pairing-request hook PR is adjacent rather than a fix for approval confirmation.

## What This Changes

Request that WhatsApp send a confirmation to the newly approved sender after DM pairing approval, with optional broader ideas for default notification or replaying the originally blocked message.

## Best Possible Solution

Wire WhatsApp into the existing `pairing approve --notify` notification seam with a WhatsApp-owned sender notifier and focused regression coverage, leaving default notification and original-message replay for separate product decisions.
