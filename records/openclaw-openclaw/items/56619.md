## Summary

Keep open: current main and the latest release still have a documented `--notify` approval path, but WhatsApp does not provide the notifier hook, and the dedicated fix PRs were closed unmerged rather than shipped.

## What This Changes

The issue asks OpenClaw to notify an approved WhatsApp sender after DM pairing approval, with optional broader behavior such as default notification or original-message replay.

## Best Possible Solution

Land a focused WhatsApp repair for the existing `--notify` path through the shared outbound gateway delivery route, with maintainer-approved SDK/core seam choice and redacted live WhatsApp or gateway proof; keep default notification and message replay separate.
