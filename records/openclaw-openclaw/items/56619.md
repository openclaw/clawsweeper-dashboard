## Summary

Keep open: current main and the latest release still expose the opt-in pairing approval notification path, but WhatsApp still does not implement the adapter hook that would actually notify the approved sender.

## What This Changes

Requested WhatsApp pairing approval feedback so an approved sender receives a same-channel confirmation instead of guessing when to retry.

## Best Possible Solution

Wire WhatsApp's pairing adapter into the existing `--notify` approval notifier using the plugin-owned send path, with focused tests, and leave default notification/config/replay behavior for separate product discussion.
