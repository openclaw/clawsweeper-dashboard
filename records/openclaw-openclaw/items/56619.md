## Summary

Keep open: current main and v2026.6.11 still have the generic pairing `--notify` path, but WhatsApp does not implement the adapter hook that would send the approval confirmation, and the prior WhatsApp fix PRs are closed unmerged.

## What This Changes

Request to notify a WhatsApp sender after the owner approves that sender's DM pairing code.

## Best Possible Solution

Wire WhatsApp into the existing `openclaw pairing approve --notify` approval-notification seam with account-aware delivery, without adding new config, changing the default approval behavior, or replaying the blocked original message.

## Solution Assessment

Yes for the narrow repair: WhatsApp should implement the existing notification seam. Default-on notification, configurable text, and original-message replay should remain separate product choices.
