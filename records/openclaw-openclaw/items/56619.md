## Summary

Keep open: current main and v2026.6.11 still document `openclaw pairing approve --notify`, but WhatsApp has no `notifyApproval` hook, so approval notification delivery remains missing after the two linked candidate PRs closed unmerged.

## What This Changes

The issue requests notifying a WhatsApp sender after their DM pairing request is approved so they know they can start interacting.

## Best Possible Solution

Wire WhatsApp into the existing documented `pairing approve --notify` path with focused regression coverage, while leaving default-on notification, config knobs, and blocked-message replay for a separate maintainer-sponsored decision.
