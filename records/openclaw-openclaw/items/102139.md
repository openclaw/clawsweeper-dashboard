## Summary

Keep open: current main still fetches a single fixed 100-message Control UI history page, and the linked closing PR is open and unmerged. ## What This Changes

The issue requests Control UI chat history behavior that can load more than the first 100 messages, either through pagination, a larger limit, or a configurable limit.

## Best Possible Solution
