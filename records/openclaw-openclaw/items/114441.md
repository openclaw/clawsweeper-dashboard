## What This Changes

The PR replaces batch-end cron outcome persistence with a shared coalescing completion drain so each completed scheduled or startup-recovery job clears durable running state, records task history, and removes successful one-shot jobs before slower sibling jobs finish.

## System Context

OpenClaw's cron service admits due and restart-catch-up jobs, executes them concurrently within configured limits, then persists terminal job state and task records. This change sits between execution completion and the SQLite-backed cron store, affecting future scheduling, active markers, one-shot cleanup, and restart recovery.
