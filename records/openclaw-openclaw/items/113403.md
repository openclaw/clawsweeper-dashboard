## What This Changes

The PR lets embedded Automations with an explicit `toolsAllow: []` reach the model with zero tools by excluding inherited non-enforcing allowlists from the empty-tool guard.

## System Context

Embedded Automations pass their runtime tool policy into the embedded agent runner, which builds callable tools and checks that configured allowlists leave a valid set. This change adjusts that validation path so an explicit tool-less Automation can call the model without inherited ordinary allowlists turning the intentional empty set into a preflight error.
