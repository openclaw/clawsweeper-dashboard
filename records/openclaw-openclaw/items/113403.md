## What This Changes

Allows embedded Automations that explicitly request `toolsAllow: []` to reach the model with zero callable tools despite inherited non-enforcing tool allowlists, while retaining command-time enforcement sources.

## System Context

Embedded Automations build an effective tool catalog from runtime settings, inherited tool policy, and host-required tools before invoking a model. The empty-allowlist guard prevents accidental no-tool execution when an enforced allowlist cannot resolve, while this change distinguishes an intentional no-tools Automation run.
