## What This Changes

The PR updates embedded agent tool construction so an explicit runtime `toolsAllow: []` bypasses inherited non-enforcing allowlists while preserving sources marked to remain enforced when tools are disabled.

## System Context

Embedded Automations prepare an effective tool allowlist before constructing the model-facing tool catalog. The allowlist guard then rejects impossible requested-tool configurations; this PR changes the guard’s treatment of deliberately tool-less runs before the model is invoked.
