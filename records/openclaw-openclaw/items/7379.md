## Best Possible Solution

Review and repair https://github.com/openclaw/openclaw/pull/96339, or land a narrow replacement that reuses the provider-usage formatter while keeping provider-specific fetching plugin-owned and bounded.

## Reproduction Assessment

## Solution Assessment

Yes, the best direction is the generic provider-usage footer bridge already attempted by the linked PR: reuse existing provider usage formatting and keep provider-specific fetching inside plugins with bounded omit-on-failure behavior.
