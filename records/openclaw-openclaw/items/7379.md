## Summary

Keep open. Current main and the latest v2026.6.11 release still do not append provider quota windows to the per-response `/usage` footer, and https://github.com/openclaw/openclaw/pull/96339 is an open closing candidate but is not merged and is currently conflicting.

## What This Changes

Request to append active-provider quota windows such as GitHub Copilot Premium/Chat percentages to the per-response `/usage tokens` and `/usage full` footer.

## Best Possible Solution

Land a rebased provider-usage footer change that appends bounded active-provider window summaries to `/usage tokens` and `/usage full` while leaving provider fetch/auth logic in plugins.

## Reproduction Assessment

Yes, from source inspection: current main's reply footer path formats token/cache/cost data without loading provider usage windows, while `/status` already loads those windows. I did not run a live GitHub Copilot quota flow in this read-only review.

## Solution Assessment

Yes: the maintainable direction is a generic footer bridge that reuses the provider-usage loader/formatter and keeps provider-specific fetching in plugins. The open linked PR is the current candidate, but it must be rebased or replaced before this issue can close.
