## Summary

Keep open. Current main and the latest release still do not add provider quota windows to per-response `/usage` footers, and https://github.com/openclaw/openclaw/pull/96339 is the open closing implementation candidate rather than a reason to close this issue before merge.

## What This Changes

The request is to append active-provider quota windows, especially GitHub Copilot Premium/Chat percentages, to `/usage tokens` or `/usage full` reply footers.

## Best Possible Solution

Review https://github.com/openclaw/openclaw/pull/96339 as the canonical fix, land it if the bounded provider-quota lookup tradeoff is acceptable, or ask that PR for a cached/preloaded design before closing this issue.
