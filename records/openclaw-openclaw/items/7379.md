## Summary

Keep open. Current main and the latest release still do not append provider quota windows to per-response `/usage` footers, and the open linked PR is the active implementation candidate rather than a reason to close the issue before merge.

## What This Changes

Request to append active provider quota-window summaries, such as GitHub Copilot Premium/Chat percentages, to `/usage tokens` or `/usage full` reply footers.

## Best Possible Solution

Review and repair https://github.com/openclaw/openclaw/pull/96339, then land it if maintainers accept the bounded provider-usage lookup; otherwise redesign the fix around cached or preloaded quota snapshots while keeping provider-specific fetching plugin-owned.
