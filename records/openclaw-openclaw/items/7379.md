## Summary

Current main still limits per-response usage footers to turn, model, context, and cost state; provider quota windows remain on status-oriented surfaces. Four direct implementation PRs closed unmerged, including a proof-sufficient candidate, so this remains valid but needs explicit direction on automatic display and snapshot ownership.

## What This Changes

Add active-provider quota windows, including GitHub Copilot Premium and Chat percentages, to per-response `/usage` footers.

## Best Possible Solution

Extend the generic reply-usage contract with an active-provider quota snapshot prepared before final formatting, then render a compact summary without provider-specific core logic or footer-time network work.
