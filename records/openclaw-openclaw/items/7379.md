Keep open for an explicit product decision. Current main still omits provider quota windows from per-response usage footers, while all direct implementation PRs were closed unmerged; the newer customizable usage-bar path provides a better canonical seam but does not itself satisfy the request.

## What This Changes

Add active-provider quota percentages, including GitHub Copilot Premium and Chat windows, to per-response `/usage` footers.

## Best Possible Solution

If maintainers approve the feature, extend the canonical usage-bar contract with generic cached or already-prepared active-provider quota windows, preserving plugin-owned fetching and avoiding a blocking per-response network lookup or Copilot-specific core branch.
