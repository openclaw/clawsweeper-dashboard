## What This Changes

The issue requests adding GitHub Copilot Premium/Chat quota percentages to the per-response `/usage` footer when provider quota data is available.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/96339, or land a narrow replacement that reuses the generic provider-usage formatter while keeping provider-specific fetching plugin-owned and bounded.

## Reproduction Assessment

Yes. Source inspection on current main shows `/usage` reply footers format local turn usage/cost/template text only, while `/status` separately loads provider quota windows.

## Solution Assessment

Yes. The best direction is the generic provider-usage footer bridge already attempted by the linked PR: reuse existing provider usage formatting and keep provider-specific fetching inside plugins with bounded omit-on-failure behavior.
