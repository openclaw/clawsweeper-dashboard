## What This Changes

This PR makes Claude bundle-MCP temporary configuration directories owner-aware and sweeps ones whose gateway owner is demonstrably gone when the gateway starts, while retaining live, queued, and legacy directories.

## System Context

Claude CLI runs receive a rendered bundle-MCP `mcp.json` in a temporary directory, including runtime-resolved connection details. The gateway starts sidecars after becoming ready; this change adds one that decides whether each leftover directory belongs to a live process, a live queued run, a legacy installation, or a dead gateway generation.

Retain the owner-encoded, fail-closed sweep and shared rollback writer, then add one redacted current-head real-host proof that creates the owner-encoded Claude config through the actual preparation path and demonstrates both dead-owner removal and live-owner/legacy retention.
