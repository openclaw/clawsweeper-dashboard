- `merge-risk: 🚨 availability`: A startup sweep can remove a live workflow's required MCP configuration before its child process starts.

## Summary

Keep this PR open for repair: the linked leak is valid and the cleanup direction is reasonable, but the fixed grace period can misclassify a legitimate prepared run because its temporary config is created before CLI queue admission.

## What This Changes

The PR adds a post-ready gateway sweep for orphaned Claude bundled-MCP temporary configuration directories and shares the directory prefix with the creator.

## Best Possible Solution

Give each prepared directory explicit live gateway/run ownership, or create it only after queue admission, so reclamation never relies on an arbitrary age threshold for a state that can wait indefinitely.

## Solution Assessment

No. Child-argv liveness plus a fixed grace does not cover the prepared-but-queued lifecycle; explicit ownership or post-admission creation is the narrower safe solution.
