Request stable usage/status JSON attribution fields for agent, session kind, cron job, channel, model, and runtime so dashboards do not join OpenClaw internals.

Define a narrow documented attribution contract on `sessions.usage` first, reuse existing session-entry/session-key metadata for cron and channel classification, and only extend `status --usage --json` if maintainers want that CLI surface to carry per-session rows too.
