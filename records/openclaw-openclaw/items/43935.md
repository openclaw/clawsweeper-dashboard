## Summary

Keep open: current main and the latest release still collapse account-scoped channel config changes into whole-channel restarts, and the remaining work is owned by open implementation PRs rather than a merged fix.

## What This Changes

The issue requests account-scoped gateway reload planning so `channels.<channel>.accounts.<accountId>.*` changes restart only that account instead of the whole channel.

## Best Possible Solution

Land one canonical generic account-scoped reload fix, preferably the current-base https://github.com/openclaw/openclaw/pull/99312 if gateway owners accept its contract, then close this issue and duplicate same-root reports after merge.

## Reproduction Assessment

Yes. At source level, account-scoped channel config paths still match channel reload rules that can only store whole-channel restarts, and the handler restarts the channel with no account id.

## Solution Assessment

Yes, with a maintainer contract check. Carrying account-scoped restart targets through the generic gateway planner and handler is the narrow maintainable fix because the channel lifecycle already accepts account ids, but maintainers should confirm the cross-channel fallback rules before merge.
