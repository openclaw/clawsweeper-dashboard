## What This Changes

The issue asks the gateway reload planner to restart only affected channel accounts for `channels.<channel>.accounts.<accountId>.*` config edits instead of restarting the entire channel.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/99312 if gateway owners accept the generic account-scoped reload contract, preserving whole-channel fallbacks for default-account, channel-global, mixed, unlisted-account, and secrets reload cases.
