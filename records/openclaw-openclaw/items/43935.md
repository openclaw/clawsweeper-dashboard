## What This Changes

The issue requests account-scoped gateway reload planning so account-only channel config changes do not restart the entire channel and disrupt unrelated active traffic.

## Best Possible Solution

Land one canonical generic reload-planner fix that carries `(channel, accountId)` restart targets through the gateway handler, while preserving whole-channel fallback for channel-global, default-account, mixed, plugin-reload, removed-account, and unsafe account cases.
