## Summary

Keep open: current main still collapses account-scoped channel config changes into whole-channel reloads, reporter logs show message delivery failures on that path, and the linked fix PRs are still open rather than merged.

## What This Changes

The issue requests account-scoped gateway channel reloads for `channels.<channel>.accounts.<accountId>.*` changes instead of restarting the whole channel.

## Best Possible Solution

Land one generic gateway reload-planner fix that carries `(channel, accountId)` restart targets through the reload handler while preserving whole-channel restarts for channel-global, mixed, default-account, removed-account, or non-canonical account changes.
