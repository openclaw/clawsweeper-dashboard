## Summary

Keep open: current main still represents channel reloads as whole-channel restarts, while the same issue is already paired with open fix PRs, especially the mergeable account-scoped reload candidate at https://github.com/openclaw/openclaw/pull/99312.

## What This Changes

The issue asks for gateway reload planning to restart only the affected channel account for strictly account-scoped channel config changes instead of restarting the entire channel.

## Best Possible Solution

Review and land the viable account-scoped reload PR, keeping whole-channel restarts for global or ambiguous changes and requiring the PR-level upgrade/live proof before merge.

Yes, the maintainable fix is to extend the gateway reload plan/executor to carry account-scoped restart targets while retaining whole-channel behavior for global or ambiguous changes. A second ClawSweeper fix PR is not the best next step while open PRs already own that work.
