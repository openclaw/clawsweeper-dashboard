## What This Changes

Make an explicitly configured Tailscale gateway bind fail startup with a clear error when no Tailscale address can be bound.

## Best Possible Solution

Resolve explicit `tailnet` binding before the listener starts, emit an actionable diagnostic and refuse startup when no usable Tailscale address exists, while preserving any documented fallback only for an automatic bind mode; cover successful tailnet binding, missing-address failure, and authentication validation with focused tests.
