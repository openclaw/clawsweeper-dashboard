## Summary

Keep this PR open for maintainer review. It addresses the linked, reproducible CLI startup delay and includes credible real-database timing evidence, but it deliberately changes when ordinary commands discover current-schema integrity damage and the branch is currently conflicted with `main`; that tradeoff and the resolved merge result need confirmation.

## What This Changes

This PR lets ordinary CLI and TUI startup use a scoped current-schema SQLite preflight instead of a full database integrity scan, while retaining full verification for Doctor, schema migrations, quarantined databases, and gateway checkpoint paths.

## System Context

CLI commands run configuration and legacy-state preflight before executing. This PR changes the shared SQLite state-database repair decision so ordinary commands can pass quickly on a verified current schema, while Doctor and migration owners retain full repair and integrity verification.
