## Summary

Keep this issue open: current main and the latest tagged release still expose ordinary agent `write` as overwrite-only, while the open linked pull request is the active implementation candidate and still needs maintainer API-shape review.

## What This Changes

The issue requests a first-class append-capable write primitive so ordinary agent and cron writes can add to shared workspace or memory files without truncating existing content.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/77127 after rebase and API sign-off, or replace it with an equally narrow append-capable write contract that preserves overwrite defaults plus workspace and sandbox guards.
