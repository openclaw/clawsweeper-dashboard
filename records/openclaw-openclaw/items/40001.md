## Summary

Keep this open: current main and v2026.6.11 still expose ordinary `write` as overwrite-only, while the open append-mode implementation at https://github.com/openclaw/openclaw/pull/77127 is unmerged and currently conflicting.

## What This Changes

Request a first-class append-capable write primitive because ordinary agent and cron writes can overwrite shared memory or workspace files.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/77127 or an equivalent narrow append-capable write contract after maintainer API sign-off, preserving overwrite-by-default behavior and the existing workspace and sandbox guards.
