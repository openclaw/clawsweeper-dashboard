## Summary

Keep this issue open: current main and the latest release still expose ordinary `write` as overwrite-only, while https://github.com/openclaw/openclaw/pull/77127 is the unmerged implementation candidate and still needs maintainer API-shape and merge-conflict review.

## What This Changes

Add first-class append-capable write behavior so isolated cron and ordinary agent sessions can update shared memory/workspace files without truncating existing content.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/77127, or replace it with an equally narrow append-capable write contract that preserves overwrite defaults, workspace/sandbox guards, and queued file mutation behavior.
