## Summary

Keep this issue open: current main and the latest release still expose ordinary `write` as overwrite-only, and the open linked implementation candidate still needs maintainer API-shape review.

## What This Changes

The issue requests a first-class append-safe write path so isolated cron and ordinary agent sessions do not overwrite shared memory or workspace files.

Review and land https://github.com/openclaw/openclaw/pull/77127, or replace it with an equally narrow append-capable write contract that preserves overwrite defaults, workspace and sandbox guards, and queued file mutation behavior.
