## Summary

Keep open: current main and the latest release still expose ordinary `write` as overwrite-only outside the memory-flush wrapper, and https://github.com/openclaw/openclaw/pull/77127 remains open and unmerged as the linked implementation candidate.

## What This Changes

The issue requests a first-class append-capable write primitive for ordinary agent and isolated cron writes so shared memory/workspace files are not truncated.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/77127, or replace it with an equally narrow append-capable write contract that preserves overwrite defaults plus workspace, sandbox, and path guards.
