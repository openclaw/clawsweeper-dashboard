## Summary

Keep this issue open: current main and the latest release still expose ordinary `write` as overwrite-only, the memory append wrapper is limited to memory-flush runs, and the linked append-mode pull request is open but unmerged and currently needs maintainer API-shape review.

## What This Changes

The issue requests a safe append-capable write path so agent and cron writes do not overwrite shared memory or workspace files.

## Best Possible Solution

Land or replace https://github.com/openclaw/openclaw/pull/77127 with a narrow append-capable write contract that preserves overwrite defaults plus workspace, sandbox, queueing, docs, and regression coverage.
