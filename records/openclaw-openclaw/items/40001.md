## Summary

Keep this issue open: current main and the latest checked release still expose ordinary agent `write` as overwrite-only, while open PR #77127 is the active fix candidate pending maintainer API-shape acceptance.

## What This Changes

The issue requests safe append semantics for ordinary agent writes so cron, monitor, and agent workflows can add to existing files without truncating prior content.

## Best Possible Solution

Review and land PR #77127 or an equivalent narrow append-capable write contract that preserves overwrite defaults, workspace/sandbox guards, and serialized file mutation behavior.
