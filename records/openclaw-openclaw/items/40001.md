## Summary

Keep this issue open: current main and the latest release still expose ordinary `write` as overwrite-only, the existing append wrapper is limited to memory-flush runs, and https://github.com/openclaw/openclaw/pull/77127 is the open unmerged implementation candidate.

## What This Changes

The issue requests a first-class append-capable write path so isolated cron and ordinary agent sessions can accumulate shared workspace files without truncating existing content.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/77127, or replace it with an equally narrow append-capable write contract that preserves overwrite defaults plus workspace, sandbox, and session-state guards.
