## What This Changes

The PR routes Android release-signing subprocesses through a shared synchronous helper that kills commands after 120 seconds and adds a timeout test.

## System Context

The Android release-signing script invokes external tools to synchronize and materialize signing data for Android releases. This PR inserts a bounded process-execution layer between that script and those external commands so a hung tool returns an error to the release lane instead of blocking it indefinitely.
