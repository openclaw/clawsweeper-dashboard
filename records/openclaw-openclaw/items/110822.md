## What This Changes

The PR sends Android release-signing Git and OpenSSL subprocesses through a private synchronous helper that kills a timed-out command after 120 seconds and adds a regression test for a hung child process.

## System Context

Android release signing synchronizes encrypted signing material by running Git and OpenSSL from a Node script before Android builds consume the material. The new helper is the boundary between the release script and those external processes, converting a stalled command into a bounded release-lane failure.
