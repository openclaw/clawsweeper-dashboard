## Summary

Keep this open: current `main` and the latest release cover the GPU part through typed `sandbox.docker.gpus`, but host IPC and generic Docker-argument passthrough are still absent and remain a sandbox security-boundary decision.

## What This Changes

Requests sandbox Docker configuration for custom Docker run options, specifically `--gpus all` and `--ipc=host`.

## Best Possible Solution

Keep the shipped typed GPU support, and only add a narrow audited host IPC setting if secops/product owners approve it; avoid generic raw Docker argument passthrough.
