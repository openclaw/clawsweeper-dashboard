## Summary

Keep this open: current main and v2026.6.11 already cover the GPU half through typed `sandbox.docker.gpus`, but host IPC or generic Docker argument passthrough remains absent and needs an explicit sandbox security-boundary decision.

## What This Changes

The issue requests custom Docker sandbox parameters, specifically GPU passthrough and host IPC support.

## Best Possible Solution

Keep the shipped typed GPU support, and add host IPC only if maintainers approve a narrow audited break-glass config field rather than generic raw Docker argument passthrough.
