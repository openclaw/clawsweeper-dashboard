Keep this open: the GPU part is already implemented and shipped, but host IPC or raw Docker flag passthrough remains absent and needs an explicit sandbox security-boundary decision.

## What This Changes

Request to allow Docker sandbox configuration for GPU passthrough plus host IPC or custom Docker run flags.

## Best Possible Solution

Keep the shipped typed GPU support, and only add a narrow audited host-IPC break-glass setting if security owners approve; do not add generic raw Docker argument passthrough by default.
