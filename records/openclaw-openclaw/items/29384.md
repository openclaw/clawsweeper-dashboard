## Summary

Keep this open: the GPU part is already implemented and shipped, but host IPC or generic Docker flag passthrough is still absent and remains a sandbox security-boundary decision.

## What This Changes

The issue requests custom Docker sandbox parameters such as `--gpus all` and `--ipc=host`, likely through new sandbox Docker configuration.

## Best Possible Solution

Keep the shipped typed GPU support; if maintainers approve host IPC, add a narrow audited break-glass field with schema, config hash, security audit coverage, docs, and focused tests rather than generic raw Docker args.
