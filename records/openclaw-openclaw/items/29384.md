## Summary

Keep this open: current main already implements and ships the GPU passthrough subset, but host IPC or generic raw Docker argument passthrough is still absent and remains a sandbox security-boundary product decision.

## What This Changes

The issue requests support for Docker sandbox options such as `--gpus all` and `--ipc=host` through OpenClaw sandbox configuration.

## Best Possible Solution

Keep the shipped typed GPU support, and add host IPC only if maintainers approve a narrow audited break-glass config field with schema, docs, config hashing, Docker create-args support, security-audit coverage, and tests; do not add generic raw Docker argument passthrough by default.
