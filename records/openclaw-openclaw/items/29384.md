## Summary

Keep this open: current main and v2026.6.11 already support typed Docker GPU passthrough, but host IPC or generic raw Docker argument passthrough remains absent and still needs a sandbox security-boundary decision.

## What This Changes

Request support for passing Docker sandbox flags such as GPU passthrough and host IPC into sandbox containers.

## Best Possible Solution

Keep the shipped typed GPU support; if maintainers approve host IPC, add a narrow audited break-glass sandbox.docker.ipc field with schema, docs, security audit coverage, config hashing, Docker create-args support, and focused tests rather than generic raw argument passthrough.

Options:

- **Add narrow IPC break-glass field (recommended):** Expose typed opt-in IPC support with schema, Docker create args, security-audit coverage, docs, config hashing, and tests while keeping raw Docker args unsupported.

- **Define broader namespace policy first:** Pause implementation until maintainers define one policy for IPC, PID, network namespace joins, capabilities, and other dangerous Docker options.
