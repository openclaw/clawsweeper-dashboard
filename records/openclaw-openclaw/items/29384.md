## Summary

Keep this open: current main and v2026.6.11 already support the GPU half through typed `sandbox.docker.gpus`, but host IPC or generic Docker flag passthrough is still absent and remains a sandbox security-boundary product decision.

## What This Changes

The issue requests support for custom Docker sandbox run parameters such as `--gpus all` and `--ipc=host`.

## Best Possible Solution

Keep the shipped typed GPU support, and add host IPC only if maintainers approve a narrow audited break-glass config field with schema, docs, config hashing, Docker create-args support, security-audit coverage, and tests; do not add generic raw Docker argument passthrough by default.
