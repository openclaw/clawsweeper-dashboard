Keep this open: current main and the latest release already cover the GPU half with typed `sandbox.docker.gpus`, but host IPC and generic Docker-run parameter passthrough remain absent and security-sensitive.

## What This Changes

Request to add configurable Docker sandbox parameters such as GPU access and host IPC for AI/ML workloads.

## Best Possible Solution

Keep the shipped typed GPU option and, if maintainers approve host IPC, add a narrow explicit Docker sandbox field with validation, docs, audit/doctor coverage, and focused tests rather than generic raw Docker flag passthrough.

## Solution Assessment

No for the proposed generic custom-flag passthrough: the safer OpenClaw-shaped solution is a narrow typed field for any approved capability, with validation and docs matching the existing Docker security model.
