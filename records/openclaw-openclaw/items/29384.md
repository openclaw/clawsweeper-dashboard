## Summary

Keep this open: current main and v2026.6.11 support the GPU half through typed `sandbox.docker.gpus`, but host IPC and generic Docker-argument passthrough are still absent and security-sensitive.

## What This Changes

Request to allow Docker sandbox configuration to pass GPU, host IPC, or other Docker runtime flags to sandbox containers.

## Best Possible Solution

Keep the shipped GPU support; if maintainers approve host IPC, add a narrow explicitly dangerous IPC setting with schema validation, audit/docs visibility, and focused Docker-args tests rather than arbitrary flag passthrough.

## Reproduction Assessment

Yes for the feature gap: source inspection shows current main and v2026.6.11 expose `sandbox.docker.gpus`, but no IPC field, raw Docker-args field, or `--ipc` Docker create emission exists.

## Solution Assessment

No for generic Docker flag passthrough. The maintainable solution is a narrow typed, explicitly dangerous IPC option only if maintainers accept the sandbox security tradeoff.
