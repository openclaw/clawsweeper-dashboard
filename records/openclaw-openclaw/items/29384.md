## Summary

Keep this open: current main and the latest release cover the GPU half through typed `sandbox.docker.gpus`, but host IPC and generic Docker-argument passthrough are still absent and require a security/product decision.

## What This Changes

Request to let sandbox Docker configuration pass GPU and host IPC/custom Docker flags such as `--gpus all` and `--ipc=host`.

## Best Possible Solution

Keep the shipped GPU support; if maintainers approve host IPC, add a narrow explicitly dangerous IPC setting with schema validation, audit visibility, config-hash coverage, docs, and focused Docker-args tests rather than arbitrary flag passthrough.

## Reproduction Assessment

Yes. Source inspection and Docker CLI help show current main supports `sandbox.docker.gpus` and emits `--gpus`, while no IPC field, raw Docker-args field, or `--ipc` emission exists.

## Solution Assessment

No for generic Docker flag passthrough. The maintainable OpenClaw-shaped path is a narrow typed host IPC option only if maintainers accept the sandbox security tradeoff.
