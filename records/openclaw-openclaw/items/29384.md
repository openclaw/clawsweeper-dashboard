## Summary

Keep this open: current main and v2026.6.11 implement the GPU half through typed `sandbox.docker.gpus`, but host IPC and generic Docker-run argument passthrough remain absent and security-sensitive.

## What This Changes

Request support for Docker sandbox run parameters such as GPU passthrough and host IPC through OpenClaw configuration.

## Best Possible Solution

Keep the shipped typed GPU support, and only add further Docker sandbox privilege knobs as narrow audited config fields with schema/docs/tests and explicit maintainer/security approval.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 accept `sandbox.docker.gpus` and emit `--gpus`, while the strict sandbox Docker schema and create-args path have no `ipc` or raw Docker-args field. This is a feature gap, not a failing existing behavior path.

## Solution Assessment

No for the proposed generic Docker flag passthrough. The safer OpenClaw-shaped solution is a narrow typed host IPC or privilege option only if maintainers accept the sandbox security tradeoff.
