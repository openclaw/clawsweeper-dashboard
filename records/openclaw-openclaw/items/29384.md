## Summary

Keep this open: current main and v2026.6.11 cover the GPU passthrough half, but host IPC or raw Docker argument passthrough is still absent and remains a sandbox security-boundary decision.

## What This Changes

The issue requests custom Docker sandbox parameters such as `--gpus all` and `--ipc=host` for GPU and host IPC workloads.

## Best Possible Solution

Keep the shipped typed GPU support, and only add host IPC as a narrow audited break-glass setting if security/product owners approve it; do not add generic raw Docker argument passthrough.
