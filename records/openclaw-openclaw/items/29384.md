## Summary

Keep this open: current main and v2026.6.11 solve the GPU passthrough half with typed `sandbox.docker.gpus`, but host IPC or generic Docker argument passthrough is still absent and changes the sandbox security boundary.

## What This Changes

The issue requests Docker sandbox config support for custom runtime flags such as `--gpus all` and `--ipc=host`.

## Best Possible Solution

Keep the shipped typed GPU support, and expose host IPC only if maintainers approve a narrow audited break-glass config field instead of generic raw Docker argument passthrough.
