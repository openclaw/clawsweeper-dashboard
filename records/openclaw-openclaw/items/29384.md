## Summary

Keep this open: current main and v2026.6.11 support typed Docker GPU passthrough, but host IPC or raw Docker argument passthrough is still absent and remains a sandbox security-boundary decision.

## What This Changes

The issue asks OpenClaw to allow Docker sandbox parameters such as `--gpus all` and `--ipc=host` through configuration.

## Best Possible Solution

Keep the shipped typed GPU support, and add host IPC only if maintainers approve a narrow audited break-glass config field with schema, docs, create-args support, config hashing, security-audit coverage, and tests; avoid generic raw Docker argument passthrough by default.
