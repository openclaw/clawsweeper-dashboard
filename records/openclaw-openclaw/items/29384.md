## Summary

Keep open: current main and v2026.6.11 cover the GPU half through typed `sandbox.docker.gpus`, but host IPC and raw Docker flag passthrough are still absent and require a sandbox security/product decision.

## What This Changes

Request to allow Docker sandbox parameters such as `--gpus all` and `--ipc=host` for GPU-accelerated and host-IPC-dependent workloads.

## Best Possible Solution

Keep the shipped typed GPU support, then either reject host IPC or add a narrow audited `sandbox.docker.ipc` break-glass setting with schema, docs, config hashing, Docker args, audit coverage, and real Docker proof; avoid generic raw Docker argument passthrough.

- **Design broader namespace policy:** Pause implementation until maintainers define one policy for IPC, PID, network namespace joins, capabilities, and other dangerous Docker options.
