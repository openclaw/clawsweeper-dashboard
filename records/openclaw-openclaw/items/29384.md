## Summary

Keep this open: current main and v2026.6.11 already support typed GPU passthrough, but host IPC or generic raw Docker argument passthrough remains absent and needs a sandbox security-boundary decision.

## What This Changes

Request typed support for Docker sandbox parameters such as GPU passthrough and host IPC/raw Docker flags.

## Best Possible Solution

Keep the shipped typed GPU support; if maintainers approve host IPC, add a narrow audited break-glass `sandbox.docker.ipc` field with schema, docs, security audit coverage, config hashing, Docker create-args support, and focused tests rather than generic raw argument passthrough.
