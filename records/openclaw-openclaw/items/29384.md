## Summary

Keep this open: current main and the latest release solve the GPU half through typed `sandbox.docker.gpus`, but the requested host IPC or generic Docker flag passthrough remains absent and is a sandbox security-boundary decision.

## What This Changes

The issue requests support for Docker sandbox parameters such as GPU passthrough and host IPC/raw Docker run flags.

## Best Possible Solution

Keep the shipped typed GPU support, and add host IPC only if maintainers approve a narrow audited break-glass config field rather than generic raw Docker argument passthrough.
