Keep this open: current main and the latest release implement typed GPU passthrough, but host IPC and generic Docker argument passthrough remain absent and security-sensitive.

## What This Changes

The issue requests sandbox Docker support for custom parameters such as `--gpus all` and `--ipc=host`.

## Best Possible Solution

Keep the shipped typed GPU support; if maintainers approve host IPC, add a narrow audited IPC config surface with validation, audit visibility, docs, and focused Docker-args tests rather than arbitrary flag passthrough.

## Reproduction Assessment

Yes. Source inspection shows current main exposes typed `sandbox.docker.gpus` and Docker `--gpus` emission, while bounded current-source search and schema inspection show no IPC/raw Docker args field.

## Solution Assessment

No for the proposed generic Docker flag passthrough. The safer OpenClaw-shaped solution is a narrow typed host IPC option only if maintainers accept the sandbox security tradeoff.
