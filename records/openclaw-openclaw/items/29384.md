## Summary

Keep this open: `sandbox.docker.gpus` now covers the GPU half, including in `v2026.6.11`, but host IPC or raw Docker argument passthrough remains absent and security-sensitive.

## What This Changes

The issue requests support for custom Docker sandbox run parameters such as `--gpus all` and `--ipc=host`.

## Best Possible Solution

Keep the shipped typed GPU support, and only add a narrow audited host IPC break-glass field if secops maintainers approve the sandbox tradeoff; avoid a generic raw Docker args passthrough.
