## What This Changes

Respect `auth.order` when choosing the active GitHub Copilot auth profile instead of using raw stored-profile insertion order.

## Best Possible Solution

Land a narrow fix that routes Copilot discovery and provider-auth profile selection through `resolveAuthProfileOrder()` with regression coverage for configured order and unresolved tokenRef fallback.
