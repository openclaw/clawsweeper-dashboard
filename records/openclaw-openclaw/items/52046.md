## Summary

Keep open: current main and v2026.6.11 still run heartbeat as an awaited main-session agent turn, with busy deferral and tuning mitigations but no non-blocking heartbeat execution lane. The related open PR only addresses the narrower retry-cadence problem in https://github.com/openclaw/openclaw/issues/40611, so this remains a product and architecture decision.

## What This Changes

The issue requests non-blocking heartbeat execution so heartbeat checks do not delay incoming message handling.

## Best Possible Solution

Keep this as the architecture tracker until maintainers define a heartbeat isolation lane or worker contract covering session state, delivery ordering, busy checks, and tool side effects.
