## Summary

## What This Changes

The issue requests a non-blocking heartbeat execution model so heartbeat work does not delay incoming message processing.

## Best Possible Solution

Keep this as the broad tracker for a maintainer-approved heartbeat isolation model, while the narrower retry cadence regression remains owned by https://github.com/openclaw/openclaw/issues/40611 and https://github.com/openclaw/openclaw/pull/89989.

Unclear: a background worker or separate heartbeat lane is plausible, but the best solution needs a maintainer-defined isolation contract for session state, delivery ordering, retry behavior, and tool side effects.
