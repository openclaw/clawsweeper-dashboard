## Summary

Keep open: current main still runs heartbeat through shared runner and wake paths, awaits the normal reply path, and documents skip-and-retry behavior when the main queue or target session lane is busy, so the requested non-blocking heartbeat execution model is not implemented.

## What This Changes

Request to run heartbeat checks outside the main message-processing path so inbound messages are not queued during heartbeat work.

## Best Possible Solution

Keep this as the broad tracker for a maintainer-approved heartbeat isolation model while the narrower retry-cadence regression remains owned by https://github.com/openclaw/openclaw/issues/40611 and https://github.com/openclaw/openclaw/pull/89989.
