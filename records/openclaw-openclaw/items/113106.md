## What This Changes

This PR validates Base64 audio returned by Xiaomi MiMo text-to-speech, rejects malformed payloads before decoding, and adds a regression test for the provider error path.

## System Context

The Xiaomi plugin requests synthesized audio from the Xiaomi TTS service, interprets the response payload, and supplies decoded bytes to OpenClaw audio-file or voice-note output. This change guards the network response boundary so invalid text cannot become a corrupted audio artifact downstream.
