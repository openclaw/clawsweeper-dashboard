## What This Changes

The branch moves task-list filtering, activity ordering, pagination, and defensive cloning into the task registry so Gateway `tasks.list` clones only the requested task page.

## System Context

Gateway clients request task pages through `tasks.list`; the Gateway handler asks the task registry for a filtered page and returns task summaries and cursor information. The registry owns retained task records and now limits defensive cloning to records that leave that boundary.
