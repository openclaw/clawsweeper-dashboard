## What This Changes

The PR makes the task registry filter, sort, paginate, and clone only the requested `tasks.list` page rather than cloning the complete retained task history before Gateway filtering.

## System Context

Gateway clients call `tasks.list` to inspect background task history. The Gateway asks the task registry for a filtered page, maps those records to transport summaries, and returns a cursor-based response to the operator client.
