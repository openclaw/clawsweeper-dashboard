## What This Changes

Changes Gateway task listing so filtering, ordering, and pagination happen on retained registry records, then defensively clones only the returned task page.

## System Context

The Gateway `tasks.list` method reads retained task records from the in-process task registry and returns a paginated task summary to clients. This change moves page selection to the registry query boundary so discarded historical records are not deep-cloned before the response page is formed.
