## What This Changes

The issue requests a fix for local `openclaw agent --local` runs that time out before an Ollama request even though a direct local model probe succeeds.

## System Context

The local agent CLI resolves the selected Ollama model and starts an embedded agent run, which builds agent context and tools before streaming a native Ollama chat request. The lean inference command bypasses that full agent surface, so it is a connectivity probe rather than an equivalent agent-turn test.

  B --> C[Embedded agent run]
  C --> D[Build session context and tools]
  D --> E[Native Ollama chat request]
  E --> F[Agent response or timeout]
  G[Lean model probe] --> H[Direct inference request]
  H --> I[Connectivity result]

## Best Possible Solution

Run the supplied comparison on current main with the native Ollama configuration, resolved model settings, and redacted Ollama request logs; add a focused embedded-run regression only if the native request still never reaches Ollama, otherwise document or diagnose the model-capacity boundary.
