## Summary

Keep open: current main and v2026.6.11 still provide usage/cost reporting and a plugin-level pre-run block hook, but not native per-agent spend-budget config, durable reservations, pre-dispatch cost admission, receipts, or operator status/doctor UX. This issue is also already the canonical thread for narrower closed spend-budget requests, so the remaining work needs maintainer product/API direction rather than cleanup closure.

## What This Changes

The issue requests optional daily/monthly per-agent spend caps enforced before gateway model dispatch, with block/warn/pause behavior and status/doctor visibility.

## Best Possible Solution

Define one narrow, additive budget-admission design: either a core per-agent spend reservation/enforcement contract with status/doctor UX, or an explicit decision that plugins/external supervisors own this and core only fills any missing hook/API gaps.
