## Summary

Keep open: current main still lacks native per-agent spend-budget config, durable gateway admission/reservation accounting, budget receipts, reset-window semantics, and status/doctor enforcement UX; existing cost reporting, ClawRouter quota visibility, and pre-run plugin blocking are adjacent but do not implement the requested core guardrail.

## Best Possible Solution

Keep this as the canonical design tracker until maintainers choose native core admission or a deliberate budget-capable plugin/API boundary, then implement durable SQLite accounting, reservations/refunds, receipts, status/doctor UX, and focused upgrade tests.
