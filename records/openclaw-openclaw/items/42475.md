## Summary

Keep open: current main still has per-agent/all-agent usage and cost reporting plus reactive provider cooldown/failover handling, but no native per-agent spend-budget config, durable budget reservation/receipt, or pre-dispatch admission gate. The comments add useful external and production design context, but the remaining work is a core product/API decision rather than a stale or already-implemented issue.

## What This Changes

Request optional per-agent daily/monthly cost budgets enforced before gateway model dispatch, with status and doctor visibility.

## Best Possible Solution

Sponsor a focused design for a core gateway admission-control path with canonical config, SQLite-backed reservations/receipts, status/doctor reporting, and explicit behavior for unknown pricing, warn/block/pause actions, and concurrent runs.
