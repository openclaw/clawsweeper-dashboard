## Summary

Keep open: current main still has cost/usage reporting and a plugin-level run block hook, but not native per-agent spend-budget config, durable reservations, pre-dispatch budget admission, receipts, or status/doctor UX.

## What This Changes

Request optional per-agent daily/monthly cost budgets enforced before model dispatch, with configurable block/warn/pause behavior and operator-visible status.

## Best Possible Solution

Use this issue as the canonical design tracker for an opt-in budget admission layer before model dispatch, backed by durable accounting/reservations and operator-visible status/doctor UX, or explicitly choose a plugin/API-only boundary.
