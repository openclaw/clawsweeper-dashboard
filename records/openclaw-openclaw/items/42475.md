## Summary

Keep open: current main has per-agent cost reporting and a pre-run block hook, but it still lacks native per-agent spend-budget config, durable reservations, pre-dispatch budget admission, receipts, and operator UX.

## What This Changes

Request optional daily/monthly per-agent model-spend budgets enforced by the gateway before model calls are dispatched.

## Best Possible Solution

Use this issue as the canonical design tracker for opt-in budget admission before model dispatch, backed by durable accounting/reservations, structured receipts, and status/doctor UX.
