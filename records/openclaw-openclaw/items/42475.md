## Summary

Keep open: current main has cost reporting, provider usage visibility, and a plugin pre-run block hook, but no native per-agent spend-budget config, durable reservations, per-model-call admission, budget receipts, or status/doctor enforcement.

## What This Changes

Add optional per-agent daily/monthly cost budgets enforced by the gateway before dispatching model calls.

## Best Possible Solution

Use this as the canonical design tracker for opt-in pre-dispatch budget admission with durable accounting, reservations/refunds, receipts, and status/doctor UX, or explicitly choose a plugin/API-only boundary.
