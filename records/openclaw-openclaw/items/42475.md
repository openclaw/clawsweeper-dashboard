## What This Changes

The issue requests optional per-agent daily/monthly cost budgets enforced before gateway model dispatch, with operator status and doctor visibility.

## Best Possible Solution

Use this as the canonical design tracker for an opt-in budget admission layer before model dispatch, backed by durable accounting/reservations and operator-visible status/doctor UX, or explicitly choose a plugin/API-only boundary.
