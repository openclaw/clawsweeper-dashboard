## Summary

Keep open: current main has cost/usage reporting and a plugin-level pre-run block hook, but it still lacks native per-agent spend-budget config, durable reservations, pre-dispatch budget admission, receipts, and operator UX.

## What This Changes

The issue requests optional per-agent daily/monthly cost budgets enforced by the gateway before model dispatch.

## Best Possible Solution

Use this issue as the canonical design tracker for opt-in budget admission before model dispatch, backed by durable accounting/reservations, structured receipts, and status/doctor UX.
