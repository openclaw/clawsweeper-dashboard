## Summary

Keep open: current main still has cost/quota reporting, ClawRouter provider-wide budget visibility, and a plugin-level pre-model block hook, but not native per-agent spend-budget config, gateway admission, durable reservations/refunds, budget receipts, or status/doctor enforcement UX.

## What This Changes

The issue requests optional per-agent daily/monthly cost budgets enforced before gateway model dispatch to prevent runaway metered-provider spend.

## Best Possible Solution

Keep #42475 as the canonical design tracker for opt-in pre-dispatch budget admission with durable SQLite accounting, reservations/refunds, receipts, and status/doctor UX, unless maintainers explicitly choose a plugin/API-only boundary.

## Risks / Open Questions

- Budget enforcement still needs product choices for approximate estimates, missing or zero pricing, reset windows/time zones, concurrent reservations/refunds, and over-budget actions such as block, pause, alert, queue, or downgrade.
- Adding agents.defaults or per-agent budget config plus durable accounting is compatibility- and state-sensitive under the repository policy, especially for upgrades and doctor migration behavior.
- A plugin-only before_agent_run policy can block before model input, but without a native ledger, serialized decisions, budget receipts, and provider-fallback semantics it may produce inconsistent operator experience.
- ClawRouter can provide scoped proxy budgets for one provider path, but it does not cover direct-provider users or OpenClaw-native per-agent admission across all model dispatch paths.
