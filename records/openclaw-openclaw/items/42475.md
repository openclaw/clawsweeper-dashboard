## Summary

Keep open: current main has per-agent cost reporting, ClawRouter provider-wide quota visibility, and a plugin run-block hook, but it still lacks native per-agent budget config, pre-dispatch provider admission, durable reservation/refund accounting, budget receipts, and status/doctor enforcement UX.

## What This Changes

Request optional per-agent daily/monthly model-spend budgets enforced before gateway model dispatch, with block/warn/pause actions and operator-visible status.

## Best Possible Solution

Keep #42475 as the canonical design tracker for opt-in pre-dispatch budget admission with durable SQLite accounting, reservations/refunds, receipts, and status/doctor UX unless maintainers explicitly choose a plugin/API-only boundary.
