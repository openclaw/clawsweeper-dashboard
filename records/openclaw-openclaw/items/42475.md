## Summary

Keep open: current main and v2026.6.11 provide cost/usage reporting, provider billing visibility, auth cooldowns, and plugin pre-run blocking, but no native per-agent spend budget config, durable reservation/accounting state, or gateway model-call admission enforcement.

## What This Changes

Add optional per-agent daily/monthly cost budget enforcement at the gateway before model dispatch, with block/warn/pause actions and status/doctor visibility.

## Best Possible Solution

Decide the native budget contract first: default-unlimited config, SQLite-backed per-agent reservations and receipts, pre-dispatch admission at the model-call boundary, and status/doctor visibility for operators.
