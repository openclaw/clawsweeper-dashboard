## Summary

Keep open. Current main and the latest release still provide cost reporting, provider quota/cooldown handling, and a plugin-level pre-run block hook, but they do not provide native per-agent spend-budget config, durable budget accounting/reservations, budget receipts, or status/doctor UX.

## What This Changes

Issue requests optional per-agent daily/monthly model-spend budgets enforced before gateway model dispatch.

## Best Possible Solution

Keep this as the canonical design tracker for opt-in native budget enforcement across config, durable accounting, pre-dispatch admission, reservations, receipts, status/doctor UX, and plugin interaction.

## Reproduction Assessment

Yes, at source level. Current main has cost reporting and a plugin block hook, but lacks native per-agent budget schema, durable budget state, and model-call admission/reservation.

## Solution Assessment

Unclear until maintainers scope it. Native core may be justified for generic model-dispatch budget admission, but it should reuse existing usage, hook, and provider fallback primitives rather than creating a second policy stack.
