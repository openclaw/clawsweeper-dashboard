## Summary

Keep open: current main still provides cost visibility and reactive provider cooldown/failover behavior, but it does not have a native budget config, durable reservation/receipt accounting, or a pre-dispatch gateway admission gate; the related duplicate issues have already been consolidated here as the canonical product/API decision.

## What This Changes

Request optional gateway-level per-agent and default spend budgets with daily/monthly caps and block, warn, or pause behavior before model dispatch.

## Best Possible Solution

Define one maintainer-approved gateway admission contract with additive config, SQLite-backed reservations/receipts, status and doctor visibility, and explicit unknown-pricing and concurrency behavior before implementation.
