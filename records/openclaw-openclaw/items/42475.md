## Summary

Keep open: current main still has usage/cost reporting, reactive auth-profile cooldowns, disk-budget cleanup, and a plugin-level `before_agent_run` block hook, but not native per-agent spend-budget config, durable reservations, pre-dispatch budget admission, receipts, or status/doctor UX.

## What This Changes

The issue requests optional daily/monthly per-agent spend budgets enforced before gateway model dispatch, with operator-visible status and doctor checks.

## Best Possible Solution

Use this issue as the canonical design tracker for an opt-in budget admission layer before model dispatch, backed by durable accounting/reservations and operator-visible status/doctor UX, or explicitly choose a plugin/API-only boundary.
