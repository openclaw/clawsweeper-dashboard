## Summary

Keep open: current main has cost reporting and provider cooldown visibility, plus a plugin pre-run block path, but it does not have native per-agent spend-budget config, durable pre-dispatch admission/reservation accounting, budget receipts, reset-window semantics, or status/doctor enforcement UX. This issue should remain the canonical product/design item for gateway-level spend enforcement.

## What This Changes

Request optional per-agent spend caps enforced before gateway model dispatch, with budget status, reset-window semantics, and block/warn/pause behavior.

## Best Possible Solution

Keep this as the canonical design item, then implement a generic gateway/agent admission contract with durable SQLite reservations/receipts, clear reset windows, status/doctor visibility, and no default cap for existing users.
