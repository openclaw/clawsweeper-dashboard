## Summary

Keep open: current main and v2026.6.11 provide usage and cost reporting plus plugin-level pre-run blocking, but they still lack native per-agent spend budgets, durable reservations/accounting, pre-dispatch budget admission, receipts, and operator UX.

## What This Changes

## Best Possible Solution

Use this issue as the canonical tracker for an opt-in pre-dispatch budget admission layer with durable SQLite accounting, reservations/refunds, receipts, and operator-visible status/doctor UX, or explicitly choose a plugin/API-only boundary.
