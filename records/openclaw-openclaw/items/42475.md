## Summary

Keep open: current main has cost usage reporting and a pre-run plugin block hook, but not the requested native per-agent spend budget config, durable admission/reservation ledger, structured budget receipts, or operator-facing budget status/doctor UX.

## What This Changes

Request optional per-agent cost budgets enforced by the gateway before model dispatch.

## Best Possible Solution

Define one additive budget-policy contract with default-unlimited behavior, durable reservations and receipts, operator-visible status/doctor recovery, and a clear core/plugin boundary before implementation.
