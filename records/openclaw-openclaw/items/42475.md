## Summary

Keep open: current main has usage and cost reporting, provider usage windows, reactive auth cooldowns, disk-budget cleanup, and a plugin-level `before_agent_run` block hook, but it does not have native per-agent spend-budget config, durable budget reservations/refunds, gateway budget admission before dispatch, budget receipts, or status/doctor UX. The remaining work is a product/API boundary decision rather than a small bug fix.

## What This Changes

Request optional per-agent daily/monthly model-spend budgets enforced at the gateway before dispatch.

## Best Possible Solution

Use this issue as the canonical design tracker for opt-in budget admission before model dispatch, backed by durable accounting/reservations/refunds and operator-visible status/doctor, or explicitly choose a plugin/API-only boundary.
