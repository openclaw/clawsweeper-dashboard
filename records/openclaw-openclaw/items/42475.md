## Summary

Keep open: current main has cost/usage reporting and a plugin-level `before_agent_run` block hook, but it still lacks native per-agent budget config, durable spend/reservation accounting, pre-dispatch budget admission, receipts, and status/doctor UX. The remaining work is a product/API/config/state decision rather than a conservative cleanup close.

## What This Changes

Request optional per-agent daily/monthly cost budgets enforced before gateway model dispatch, with block/warn/pause actions and status/doctor visibility.

## Best Possible Solution

Use this as the canonical design tracker for an opt-in budget admission layer before model dispatch, backed by durable SQLite accounting/reservations and operator-visible receipts/status/doctor UX, or explicitly choose a plugin/API-only boundary.
