## Summary

Keep open: current main exposes cost and provider-usage reporting plus coarse plugin gates, but it does not provide native per-agent spend-budget configuration, durable pre-dispatch accounting, per-call reservations, receipts, or status/doctor enforcement, so the issue remains the canonical tracker for a real product decision.

## What This Changes

The issue requests gateway-level per-agent cost budget enforcement so OpenClaw can refuse or stop model work before an agent exceeds a configured spend limit.

## Best Possible Solution

Maintain this as the canonical design item until maintainers choose native opt-in budget admission versus a plugin/API boundary; a native path should include durable SQLite accounting, reservations/refunds, budget receipts, status/doctor UX, docs, and upgrade tests.
