## Summary

Keep open: current main still has cost/usage reporting, provider usage visibility, LiteLLM/external spend-limit workarounds, and a plugin-level pre-run block hook, but not native per-agent spend-budget config, durable reservations, pre-dispatch budget admission, receipts, or status/doctor enforcement.

## What This Changes

Request to add optional per-agent daily/monthly model-spend budgets enforced before gateway model dispatch.

## Best Possible Solution

Use this issue as the canonical design tracker for opt-in budget admission before model dispatch, backed by durable accounting/reservations and operator-visible status/doctor UX, or explicitly choose a plugin/API-only boundary.
