## Summary

Keep open: current main has post-call cost reporting and a plugin block primitive, but not native per-agent spend budgets with durable pre-dispatch reservations, reset-window accounting, receipts, or status/doctor enforcement UX.

## What This Changes

Request optional per-agent daily/monthly spend caps enforced before gateway model dispatch, with over-budget actions and operator visibility.

## Best Possible Solution

Keep this as the canonical design tracker until maintainers choose the ownership boundary, then implement opt-in default-unlimited budgets with durable SQLite accounting, reservations/refunds, receipts, and status/doctor UX together.
