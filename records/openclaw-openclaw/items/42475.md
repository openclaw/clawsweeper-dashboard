## Summary

Keep open: current main has cost reporting, ClawRouter quota visibility, and a plugin-level pre-model block hook, but still lacks native per-agent budget config, gateway admission, durable accounting, and status/doctor enforcement UX.

## What This Changes

The issue requests optional per-agent daily/monthly cost budgets enforced before gateway model dispatch, with block/warn/pause behavior and operator-visible budget status.

## Best Possible Solution

Keep #42475 as the canonical design tracker for opt-in pre-dispatch budget admission with durable SQLite accounting, reservations/refunds, receipts, and status/doctor UX unless maintainers choose a plugin/API-only boundary.
