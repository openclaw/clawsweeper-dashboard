## Summary

Keep open: current main and v2026.6.11 provide cost reporting, reactive provider cooldown/failover behavior, and a plugin-level block hook, but they do not provide native per-agent spend budgets, pre-dispatch cost admission, durable reservations/receipts, or operator UX for budget enforcement.

## What This Changes

Request optional per-agent daily or monthly cost budgets enforced before model dispatch at the gateway, with operator-visible status and doctor reporting.

## Best Possible Solution

Keep this as the canonical design tracker until maintainers choose either an opt-in core admission layer with durable accounting and operator UX or an explicit plugin/API-only boundary.
