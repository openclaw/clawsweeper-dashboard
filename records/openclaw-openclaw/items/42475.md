## Summary

Keep open: current main and v2026.6.11 still provide cost reporting and a plugin-level pre-submission block hook, but not native per-agent spend-budget config, pre-dispatch admission, durable reservations/refunds, receipts, or budget status UX.

## What This Changes

Issue requests optional global and per-agent gateway budget configuration that enforces daily/monthly cost caps before model dispatch and reports budget status in status/doctor surfaces.

## Best Possible Solution

Use this as the canonical design tracker for an opt-in pre-dispatch budget admission layer with durable accounting/reservations/receipts and status/doctor UX, or explicitly choose a plugin/API-only boundary.
