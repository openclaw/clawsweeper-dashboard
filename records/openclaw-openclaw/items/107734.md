## Summary

Keep this PR open: the independent admission root addresses the reproduced outage and the earlier SDK-documentation finding is fixed, but the helper currently starts plugin work synchronously and can undermine the ack-first guarantee it is intended to preserve. The expanded current head also lacks live after-fix proof for Google Chat, SMS, and Zalo.

## What This Changes

Adds a public Plugin SDK helper for independently admitted post-ack webhook work, adopts it in LINE, Google Chat, SMS, and Zalo handlers, documents the API, and adds regression tests.

## Best Possible Solution

Reserve the independent root synchronously but microtask-defer the supplied callback, document that reservation is immediate while processing begins after the current request stack, add explicit ack-before-callback tests, and provide redacted live proof for each retained channel integration.
