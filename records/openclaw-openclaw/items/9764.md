## Summary

Keep open: current main and v2026.6.11 still have Google Chat wired to service-account app auth only, so the requested user OAuth credential path for outbound reactions, native media upload, reaction typing, and user-scoped DM lookup remains missing.

Keep this as the canonical Google Chat user-OAuth tracker and implement it only after maintainers approve a SecretRef-aware credential model plus scoped app-versus-user routing for the bundled plugin.
