## Summary

Keep open: current main and v2026.6.11 still only model Google Chat service-account app auth with `chat.bot`, while the requested user OAuth credential path for reactions, native media upload, reaction typing, and email-alias DM lookup remains missing and security-sensitive.

## Best Possible Solution

Keep this as the canonical Google Chat user-OAuth tracker and implement it only after maintainers approve a secret-aware credential model, scoped app-versus-user routing, fallbacks, tests, and docs in the Google Chat plugin.
