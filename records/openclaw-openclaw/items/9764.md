## Summary

Keep open. Current main and v2026.6.11 still wire Google Chat through service-account credentials and the `chat.bot` scope only; the open media-fallback PRs mitigate one upload-loss symptom but do not implement the requested user OAuth credential model for reactions, native uploads, reaction typing, or proactive DM email-alias lookup.

## What This Changes

The issue requests optional Google Chat user OAuth credentials and scoped routing for operations that service-account app auth cannot perform, including reactions, media uploads, and proactive DMs.

## Best Possible Solution

Keep this as the canonical Google Chat user OAuth design issue and implement a plugin-owned, security-reviewed credential model with scoped routing, absent-OAuth fallback semantics, docs, and focused tests before enabling the new capability.
