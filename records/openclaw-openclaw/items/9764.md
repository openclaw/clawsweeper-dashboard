## Summary

Keep open: current main and the latest release still use Google Chat service-account app auth with the chat.bot scope only, so the requested user OAuth credential path for outbound reactions, native media upload, reaction typing, and email-alias DM lookup remains missing and security-sensitive.

## What This Changes

The issue requests optional Google Chat user OAuth credentials for operations that service-account app auth cannot perform, while preserving service-account behavior for webhook and bot-level flows.

## Best Possible Solution

Keep this issue as the canonical Google Chat user-OAuth tracker and implement it in the bundled Google Chat plugin only after a security-reviewed SecretRef-aware credential model, scoped app-versus-user routing, setup/docs updates, and fallback behavior are approved.
