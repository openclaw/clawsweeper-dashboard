## Summary

Keep open. Current main and v2026.6.11 still use service-account Google Chat credentials with the `chat.bot` scope only, while this issue asks for a new user OAuth credential and routing model; the related media-fallback work only mitigates one upload-loss symptom.

## What This Changes

The issue requests optional Google Chat user OAuth credentials alongside service-account auth so reactions, media uploads, reaction typing, and proactive DMs can use user-scoped Google Chat APIs.

## Best Possible Solution

Keep this as the canonical Google Chat OAuth design issue and implement a plugin-owned, secret-aware user OAuth model with scoped routing, docs, fallback semantics, and security review before enabling the new capability.
