## Summary

Keep open: current main and v2026.6.11 still use Google Chat service-account app auth with the chat.bot scope only, so the requested user OAuth path for native reactions, attachment upload, reaction typing, and broader user-auth routing remains missing.

## What This Changes

Add optional Google Chat user OAuth credentials and route user-scoped reactions, media uploads, and proactive DM lookup through them while preserving service-account app auth.

## Best Possible Solution

Keep this issue as the canonical Google Chat user-OAuth tracker and implement it in the bundled Google Chat plugin only after a security-reviewed SecretRef-aware credential model, scoped app-versus-user routing, setup/docs updates, and fallback behavior are approved.
