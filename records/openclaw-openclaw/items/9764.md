## Summary

Keep open: current main and v2026.6.11 still only model Google Chat service-account app auth with `chat.bot`, while the requested user OAuth credential path for reactions, native media upload, reaction typing, and email-alias DM lookup remains missing and security-sensitive.

## What This Changes

Request to add optional Google Chat user OAuth support for outbound reactions, native media uploads, reaction typing, and proactive email-alias DM lookup while retaining service-account auth for webhook and bot operations.

## Best Possible Solution

Keep this as the canonical Google Chat user-OAuth tracker and implement it only after maintainers approve a secret-aware credential model, scoped app-versus-user routing, fallbacks, tests, and docs in the bundled Google Chat plugin.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 have strict service-account config and a `chat.bot`-only auth path, while the requested user OAuth credential and scoped client routing do not exist. I did not run a live Google Workspace repro in this read-only review.
