## Label Justifications

- `P2`: This is a normal-priority Google Chat channel enhancement with real delivery/auth impact but limited blast radius and product/security design work still needed.
- `impact:security`: The requested solution would introduce OAuth refresh-token and client-secret handling for Google Chat.
- `impact:message-loss`: Media replies and reaction actions can fail under service-account auth, leaving users without the intended attachment or reaction result.
- `impact:auth-provider`: The core request is to add a second Google Chat authentication mode and route operations by required Google OAuth scope.

## Summary

Keep open: current main and the latest release still have Google Chat wired to service-account credentials with the `chat.bot` scope only, and the related media-fallback work does not implement user OAuth for reactions, uploads, or proactive DM alias resolution.

## What This Changes

Requests optional Google Chat user OAuth support for reactions, media uploads, reaction typing indicators, and proactive DMs while keeping existing service-account webhook behavior.

## Best Possible Solution

Implement this in the Google Chat plugin with a strict, secret-aware user OAuth credential model, scoped OAuth clients for user-only operations, service-account auth retained for webhook/app sends, and documented fallback behavior when user OAuth is absent.

## Reproduction Assessment

Yes for source-level reproduction: current main only accepts service-account Google Chat credentials and scopes API calls to `chat.bot`, while the affected reaction/media operations require user-auth scopes. I did not run a live Google Chat OAuth workspace repro in this read-only review.

## Solution Assessment

Partly: user OAuth in the Google Chat plugin is the right owner boundary, but the raw config sketch is not enough by itself. The maintainable solution should use OpenClaw's secret-aware credential patterns, explicit fallback semantics, docs, and security review rather than ad hoc plaintext refresh-token config.
