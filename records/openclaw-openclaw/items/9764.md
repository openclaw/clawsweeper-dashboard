## Summary

Keep open. Current main and v2026.6.11 still expose Google Chat through service-account credentials and the `chat.bot` scope only, while the related media-fallback PRs address one upload-loss symptom rather than the requested user OAuth credential model.

## What This Changes

The issue requests optional Google Chat user OAuth credentials and scoped routing for reactions, media uploads, reaction typing, and proactive DMs while preserving service-account webhook behavior.

## Best Possible Solution

Approve and implement a plugin-local, SecretRef-aware Google Chat user OAuth model that routes only user-scope operations through scoped OAuth clients while preserving service-account webhook and bot-level behavior.
