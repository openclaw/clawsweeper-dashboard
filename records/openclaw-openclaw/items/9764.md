## Summary

Keep open. Current main and v2026.6.11 still expose Google Chat through service-account credentials and the `chat.bot` scope only; the related media-fallback work mitigates one upload-loss symptom but does not add the requested user OAuth credential model.

## What This Changes

Request optional Google Chat user OAuth credentials for reactions, attachment uploads, reaction typing, and proactive DM lookup while preserving service-account webhook and app-auth behavior.

## Best Possible Solution

Keep this as the canonical Google Chat user OAuth design issue and implement a plugin-owned, security-reviewed credential model with scoped routing, absent-OAuth fallback semantics, docs, and focused tests before enabling the new capability.
