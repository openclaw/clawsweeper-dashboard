## Summary

Keep open. Current main and v2026.6.11 still have Google Chat wired to service-account credentials and the `chat.bot` scope only; related media-fallback PRs mitigate one 403 symptom but do not add the requested user OAuth credential/routing model.

## What This Changes

Request optional Google Chat user OAuth credentials so reactions, native media uploads, reaction typing, and proactive DMs can use user-scoped Chat APIs while service-account auth remains for webhook and bot operations.

## Best Possible Solution

Keep this as the canonical Google Chat OAuth design issue and implement a plugin-owned, secret-aware user OAuth model with scoped routing, fallback semantics, docs, tests, and security review before enabling the capability.
