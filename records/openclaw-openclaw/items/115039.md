## What This Changes

Move QA Lab’s one-time infrastructure retry from the aggregate CLI suite invocation into each scheduled partition, so a late retryable channel-startup failure reruns only that partition.

## System Context

QA Lab launches mixed channel scenarios through CLI and HTTP entry points, then partitions and schedules them by channel. A retry boundary around the entire suite can replay completed partitions; a partition-local boundary would preserve completed results while retrying only the failing channel setup.

## Best Possible Solution

Implement one partition-local retry helper in QA Lab’s suite-launch path, apply it consistently to CLI and HTTP launches, preserve scheduler reservation through teardown and retry, and add focused mixed-partition and flow-only regression coverage.
