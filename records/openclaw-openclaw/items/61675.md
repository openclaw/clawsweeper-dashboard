## Summary

Keep open: current main still limits bundled session-memory to manual `command:new` and `command:reset`, so the underlying automatic-rollover gap remains; however, this branch exposes automatic resets as new command actions, which conflicts with the documented command-event contract and needs a maintainer lifecycle-API decision before merge.

## What This Changes

The branch dispatches internal and `before_reset` hooks for lazy daily and idle session rollovers, adds `command:daily` and `command:idle` support to session-memory, and updates related docs and tests.

## Best Possible Solution
