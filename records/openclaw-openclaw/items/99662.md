## Summary

Keep open: current main and v2026.6.11 still allow Discord partial preview finals to complete by editing an existing preview message, and the open candidate fix at https://github.com/openclaw/openclaw/pull/99711 has not merged yet.

## What This Changes

The issue reports that Discord partial-streamed turns can finish by editing a preview message, which may not trigger Discord unread/channel highlighting after the user navigates away.

## Best Possible Solution

Review and either land https://github.com/openclaw/openclaw/pull/99711 or replace it with a maintainer-approved Discord finalization policy that gives partial preview turns a fresh completion event with focused tests and live Discord proof.

## Reproduction Assessment

Yes for source reproduction: current main and v2026.6.11 still have a path where partial-mode final replies edit an existing preview message. I did not live-reproduce the Discord client's unread/highlight behavior in this read-only review.

## Solution Assessment

Unclear: sending a fresh final message is the likely Discord notification primitive, but disabling final edits for an existing streaming mode is a compatibility and UX decision that maintainers should make while reviewing the linked PR.
