## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Keep health probes on a loopback-safe connection:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: This helper builds a new channel from `GatewayEndpointStore.localConfig()` and passes token/password into it. That config can resolve `tailnet` or `custom` hosts and defaults to `ws`, so local process probes can repeatedly send gateway credentials to a non-loopback endpoint; keep this on the existing resolved connection path or force a loopback-only unauthenticated probe.
  - confidence: 0.89
- **[P1] Block dot navigation behind the acknowledgement gate:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:62`
  - body: `finish()` now persists the security acknowledgement unconditionally, but the page dots still let a first-run user jump past page 0 without checking the box and then finish onboarding. The acknowledgement needs to gate all page transitions or `finish()` should refuse to persist completion until the user explicitly opted in.
  - confidence: 0.91
- **[P1] Preserve env and launchd auth in the node-mode gate:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:145-147`
  - body: The new node-mode gate falls back only to `hasExistingLocalSetup(root:)`, which inspects `openclaw.json`. Existing local installs can legitimately get gateway auth from `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, or the launchd snapshot, so those upgraded setups will disconnect until onboarding is rerun even though the gateway is configured.
  - confidence: 0.86
- **[P2] Do not make debug installs fall back to latest:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:99-102`
  - body: Returning `nil` for `.debug` bundle identifiers flows into `CLIInstaller.install()` as `latest`, which is then installed via the existing network-fetched shell script. Debug/test builds on real machines should stay pinned or require an explicit developer opt-in before running an unpinned installer target.
  - confidence: 0.78
- **[P2] Add a recheck path after manual CLI installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:747-748`
  - body: The new CLI page disables Next until `cliInstalled` is true, but the manual install button only copies the command and never refreshes `installedLocation()` afterward. Users who install in Terminal while staying on this page can remain stuck until they leave and re-enter onboarding; add a recheck button or active refresh for the manual path.
  - confidence: 0.82
