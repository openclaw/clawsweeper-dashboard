## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Keep health probes from using credentialed remote config:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: This process-manager health probe uses `GatewayEndpointStore.localConfig()`, which can resolve custom or tailnet hosts and carries token/password values. Startup polling can therefore send local Gateway credentials to a non-loopback endpoint; keep this probe on a loopback-only/no-secret path or the injected `GatewayConnection`.
  - confidence: 0.9
- **[P1] Do not persist a skipped security acknowledgement:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:62`
  - body: `finish()` now writes the acknowledgement key unconditionally, but the page dots only honor the wizard lock, so a first-run user can jump past page 0 and finish without checking the box. Make the acknowledgement gate apply to every navigation path, or only persist it after an explicit acknowledgement.
  - confidence: 0.86
- **[P2] Keep node-mode gating aligned with all auth sources:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:147`
  - body: This fallback only inspects `openclaw.json`, while the endpoint resolver also treats `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, and the launchd snapshot as valid local auth sources. Upgraded installs using those auth sources can be disconnected until onboarding is rerun.
  - confidence: 0.78
- **[P2] Avoid unpinned debug installs through latest:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:102`
  - body: Returning `nil` for `.debug` bundle IDs makes the installer fall back to `latest`, and this branch still runs `curl -fsSL https://openclaw.bot/install-cli.sh | bash`. Debug/tester builds should not silently switch to unpinned remote code execution without an explicit opt-in or integrity-checked artifact.
  - confidence: 0.77
- **[P2] Add a recheck path for manual CLI installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:747-749`
  - body: The manual install path only copies a command, while `Next` remains disabled until `cliInstalled` refreshes. A user who runs the copied command from Terminal has no in-page way to detect success unless they leave and re-enter this page.
  - confidence: 0.74
