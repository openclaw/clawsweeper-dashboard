## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Keep local health probes on loopback:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: This new probe uses `GatewayEndpointStore.localConfig()`, which can resolve tailnet/custom hosts and includes token/password auth. `GatewayChannelActor` sends those credentials in the connect frame, so startup polling can transmit local gateway credentials to a non-loopback endpoint; process-manager probes should force loopback or reject secrets off-loopback.
  - confidence: 0.91
- **[P1] Block page-dot bypass of the security notice:** `apps/macos/Sources/OpenClaw/OnboardingView+Layout.swift:116-117`
  - body: The new acknowledgement only gates `handleNext`, but the page dots still jump to later pages directly and `finish()` then persists the acknowledgement. A first-run user can complete onboarding without checking the box, so the notice must be enforced for every navigation path and before persisting completion.
  - confidence: 0.88
- **[P1] Preserve env-backed auth before blocking node mode:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:45-49`
  - body: This gate only treats current UserDefaults or `openclaw.json` auth as an existing local setup. Current endpoint resolution also accepts `OPENCLAW_GATEWAY_TOKEN` / `OPENCLAW_GATEWAY_PASSWORD` and launchd snapshots, so upgraded users with those valid auth sources will have node mode disconnected until they rerun onboarding.
  - confidence: 0.86
- **[P2] Add a recheck path for manual CLI installs:** `apps/macos/Sources/OpenClaw/Onboarding.swift:161-162`
  - body: `canAdvance` now requires `cliInstalled`, but the manual install path only copies the command and does not refresh installation status while the user stays on the page. After running the copied command in Terminal, the user can remain stuck with Next disabled until they leave and re-enter onboarding.
  - confidence: 0.82
- **[P2] Do not default debug installs to latest:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:99-102`
  - body: Returning nil for `.debug` bundle identifiers makes `CLIInstaller.install()` fall back to `latest` and execute the remote `curl | bash` installer without a pinned version. Debug/test builds on real machines should stay pinned or require an explicit opt-in for moving latest.
  - confidence: 0.78
