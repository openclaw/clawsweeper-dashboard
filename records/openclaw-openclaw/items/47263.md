  - confidence: 0.91

  - body: `GatewayEndpointStore.localConfig()` can resolve `tailnet` or `custom` hosts and attach token/password auth. Using it for process-manager health polling means startup can repeatedly send gateway credentials to a configured non-loopback host before issuing the health request.
  - confidence: 0.87
- **[P2] Preserve env-backed local auth for node-mode startup:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:145-147`
  - body: `shouldConnectNodeMode` now decides existing setup from `openclaw.json` only. Existing local installs that rely on `OPENCLAW_GATEWAY_TOKEN` / `OPENCLAW_GATEWAY_PASSWORD` or the launchd snapshot still have valid gateway auth, but this gate will disconnect node mode until onboarding is rerun.
  - confidence: 0.84
- **[P2] Preserve injected gateway readiness checks:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:380`
  - body: The readiness loops now call `probeLocalGatewayHealth` directly, bypassing the `testingConnection` hook that the existing `GatewayProcessManagerTests` use. Those tests can no longer drive the path with their fake websocket and will depend on a real local socket instead.
  - confidence: 0.86
- **[P2] Add a recheck path for manual CLI installs:** `apps/macos/Sources/OpenClaw/Onboarding.swift:161-162`
  - body: The manual path only copies `npm install -g ...`, but `Next` stays disabled until `cliInstalled` refreshes. Users who install in Terminal while staying on this page have no recheck button unless the Command Line Tools preflight is failing.
  - confidence: 0.79
- **[P2] Keep debug CLI installs pinned:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:99-102`
  - body: Returning nil for `.debug` bundle identifiers makes both the automated installer and copied manual command fall back to `latest`. That expands a remote `curl | bash` install path from a version-pinned app build to moving, unpinned code for developer/test builds.
  - confidence: 0.77
