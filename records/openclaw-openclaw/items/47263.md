## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Keep local health probes on the injected connection:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: This bypasses `self.connection` and builds a fresh `GatewayChannelActor` from `localConfig()` for every readiness probe. `localConfig()` can resolve custom/tailnet hosts and gateway auth, and the channel sends token/password in the connect frame, so local process-manager polling can leak credentials off-loopback and also bypasses the existing test injection path.
  - confidence: 0.9
- **[P1] Require acknowledgement before finishing onboarding:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:62`
  - body: The checkbox only gates `Next`, but the page dots still jump to later pages and `finish()` then writes the acknowledgement key unconditionally. A first-run user can complete onboarding without ever acknowledging the warning, so the new security control is ineffective.
  - confidence: 0.88
- **[P1] Preserve env and launchd auth for node startup:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:147`
  - body: This fallback only checks `openclaw.json`, but macOS also treats environment and launchd snapshot token/password values as valid local Gateway auth. Upgraded users who rely on those sources can have node-mode disconnected until they rerun onboarding despite already having a configured local Gateway.
  - confidence: 0.84
- **[P2] Do not make debug installs implicitly use latest:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:102`
  - body: Returning `nil` for `.debug` bundles flows into `expectedGatewayVersionString() ?? "latest"` and the existing `curl | bash` installer command. Debug builds on real machines should not silently move to unpinned remote code without an explicit opt-in or integrity-checked pinned installer path.
  - confidence: 0.78
- **[P2] Add a recheck path after manual CLI install:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:747-748`
  - body: The manual install path only copies a command while `Next` remains disabled until `cliInstalled` refreshes. If the user runs the command in Terminal and stays on this page, the view has no success recheck unless they navigate away or restart onboarding.
  - confidence: 0.82
