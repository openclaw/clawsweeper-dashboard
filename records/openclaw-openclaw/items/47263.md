## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Preserve env-backed auth before blocking node mode:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:147`
  - body: `shouldConnectNodeMode` only preserves existing installs when `openclaw.json` contains local setup data. Current gateway resolution also treats `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, and launchd snapshot credentials as valid local auth, so upgraded users using those sources can have node mode disconnected until they rerun onboarding despite a configured gateway.
  - confidence: 0.88
- **[P1] Do not persist security consent from skipped first page:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:62`
  - body: `finish()` unconditionally writes the security acknowledgement, but the page dots still let a first-run user jump away from page 0 without toggling the checkbox. That lets onboarding complete and permanently records consent that the user never gave; gate all navigation paths or require the flag before finishing.
  - confidence: 0.9
- **[P2] Keep readiness probes on the injectable connection:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:414-425`
  - body: The new helper creates a fresh `GatewayChannelActor` from live local config, so `setTestingConnection` no longer drives attach/start/readiness checks and the polling loops can create repeated websocket channels. Keep this on the shared/injected connection or add a bounded probe dependency so tests and startup behavior stay deterministic.
  - confidence: 0.86
- **[P2] Add a recheck path for manual CLI installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:747-749`
  - body: The manual install path only copies the command, while `canAdvance` requires `cliInstalled`. If the user runs the copied command in Terminal, nothing refreshes this page unless they leave and re-enter it, so `Next` can stay disabled after a successful manual install.
  - confidence: 0.84
