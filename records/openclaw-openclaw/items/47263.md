  - body: The new gate only affects `canAdvance`, but progress dots still set `currentPage` directly and `finish()` then writes the acknowledgement key. A first-run user can skip the checkbox and still complete onboarding, so the security acknowledgement is not actually enforced.
  - confidence: 0.9

  - body: This helper builds a fresh channel from `GatewayEndpointStore.localConfig()` instead of using `self.connection`, so startup probes bypass the existing test injection and shared GatewayConnection lifecycle.   - confidence: 0.86

  - body: Current macOS auth resolution accepts `OPENCLAW_GATEWAY_TOKEN` / `OPENCLAW_GATEWAY_PASSWORD` and launchd snapshots, but this fallback only checks `openclaw.json`. Existing local installs using those supported auth sources can have node mode disconnected until onboarding is rerun.
  - confidence: 0.88
- **[P2] Add a CLI recheck path for manual installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:747-749`
