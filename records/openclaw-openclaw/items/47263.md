Full review comments:

- **[P1] Constrain local health probes to loopback:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: `probeLocalGatewayHealth` creates a fresh `GatewayChannelActor` from `GatewayEndpointStore.localConfig()` and passes token/password. `localConfig()` can resolve `custom` or `tailnet` hosts, and the channel sends those credentials in the connect auth frame before the health RPC, so startup polling can leak Gateway credentials off loopback.
  - confidence: 0.9
- **[P1] Preserve env and launchd auth in the node gate:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:145-147`
  - body: `shouldConnectNodeMode` preserves upgraded installs only when `openclaw.json` has wizard or gateway auth fields. The macOS app also treats `OPENCLAW_GATEWAY_TOKEN`/`OPENCLAW_GATEWAY_PASSWORD` and launchd snapshots as valid local auth sources, so those existing local installs can be disconnected until onboarding is rerun.
  - confidence: 0.86
- **[P2] Gate page-dot navigation on acknowledgement:** `apps/macos/Sources/OpenClaw/OnboardingView+Layout.swift:115-123`
  - body: `canAdvance` blocks the Next button, but the page-dot buttons still mutate `currentPage` directly, and `finish()` unconditionally persists the acknowledgement. A first-run user can skip page 0, finish onboarding, and record the security acknowledgement without checking the box.
  - confidence: 0.88
- **[P2] Keep debug CLI installs pinned:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:98-103`
  - body: Returning `nil` for `.debug` bundle identifiers flows into `CLIInstaller.install()` as `latest`, which drives the existing network installer path without a pinned version. Debug/tester builds should not silently switch to moving remote code unless maintainers explicitly choose that risk.
  - confidence: 0.78
