## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Keep local health probes from sending gateway secrets remotely:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: `probeLocalGatewayHealth()` resolves `GatewayEndpointStore.localConfig()` and passes token/password into a fresh `GatewayChannelActor`. Because local config can resolve custom or tailnet hosts and the channel sends auth in its connect frame, startup health checks can leak gateway credentials to a non-loopback `ws://` endpoint; use the shared connection/test seam or an explicit loopback-safe unauthenticated probe.
  - confidence: 0.9
- **[P1] Require acknowledgement before completion is persisted:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:61-63`
  - body: `finish()` now unconditionally writes the acknowledgement key, but the page-dot buttons still jump to later pages without checking `canAdvance`. A first-run user can skip page 0, press Finish, and persist acknowledgement without checking the security notice.
  - confidence: 0.9
- **[P2] Preserve env and launchd auth when gating node mode:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:45-49`
  - body: The new node-mode gate only inspects `openclaw.json` through `hasExistingLocalSetup(root:)`. Current local auth resolution also accepts `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, and launchd snapshots, so upgraded installs using those supported sources can be disconnected until onboarding is rerun.
  - confidence: 0.86
- **[P2] Add a same-page recheck for manual CLI installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:744-749`
  - body: The manual path only copies an install command while `canAdvance` requires `cliInstalled`. If the user installs from Terminal, nothing on the page refreshes CLI status unless they leave and re-enter the page, so the new flow can strand them with Next disabled.
  - confidence: 0.82
- **[P2] Avoid implicit latest installs for debug builds:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:98-103`
  - body: Returning `nil` for `.debug` bundle identifiers flows into `CLIInstaller.install()` as the existing `latest` fallback for a network-fetched shell installer. That makes debug/tester builds install moving code without an explicit opt-in or pinned version.
  - confidence: 0.78
