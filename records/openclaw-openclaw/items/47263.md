## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Constrain health probes before passing gateway credentials:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: `localConfig()` can resolve `gateway.bind=custom` or `tailnet` and includes token/password from config, env, or launchd state, so this automatic process-manager probe can send gateway credentials to a non-loopback `ws://` endpoint during startup. Keep local process health checks loopback-only or validate the endpoint before passing credentials.
  - confidence: 0.9
- **[P2] Route readiness checks through the injectable connection:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:380`
  - body: `waitForGatewayReady()` no longer uses `self.connection`, so the DEBUG `setTestingConnection` hook used by `GatewayProcessManagerTests` cannot drive this path and the test now depends on a real local socket. Preserve the injectable connection path or add an explicit injectable health-probe dependency.
  - confidence: 0.86
- **[P1] Block page-dot navigation behind the acknowledgement:** `apps/macos/Sources/OpenClaw/OnboardingView+Layout.swift:115-116`
  - body: The new consent gate only disables `Next`; the page dots still set `currentPage` directly, and `finish()` then stores the acknowledgement unconditionally. Route dot navigation through the same gate or disable later dots until the checkbox is explicitly acknowledged.
  - confidence: 0.9
- **[P2] Preserve env and launchd auth in node-mode gating:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:145-147`
  - body: This fallback only checks `openclaw.json`, but `GatewayEndpointStore` already treats `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, and the launchd snapshot as valid local auth sources. Upgraded installs using those sources will disconnect node mode until onboarding is rerun.
  - confidence: 0.84
- **[P2] Avoid implicit latest installs for debug builds:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:99-102`
  - body: Returning `nil` for `.debug` bundle identifiers flows into `CLIInstaller.install()` as `latest`, which makes debug/tester app builds execute the remote installer against an unpinned package version. Keep a pinned app-compatible version by default or require an explicit developer opt-in for `latest`.
  - confidence: 0.78
- **[P2] Add a recheck path for manual CLI installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:747-749`
  - body: The manual install path only copies the command, but `Next` remains gated on `cliInstalled` and this page has no check-again action unless Command Line Tools are missing. A user who installs manually while staying on this page can be stuck until they leave and re-enter onboarding.
  - confidence: 0.75
