## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Keep health probes on a loopback-safe connection:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: This replaces the existing `self.connection` health checks with a new `GatewayChannelActor` built from `GatewayEndpointStore.localConfig()`. That config can resolve `custom` or `tailnet` hosts and includes token/password values, so startup/readiness polling can send local gateway credentials outside loopback; use the existing injected connection or a loopback-only unauthenticated probe instead.
  - confidence: 0.86
- **[P1] Enforce acknowledgement before persisting completion:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:61-63`
  - body: `finish()` now stores the security acknowledgement unconditionally, but the page dots still let users jump away from the first page without checking the toggle. A first-run user can complete onboarding and persist acknowledgement without explicitly accepting the notice, so completion should verify the acknowledgement or all navigation paths should enforce the gate.
  - confidence: 0.9
- **[P2] Preserve env-backed local auth in node-mode gating:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:136-148`
  - body: `shouldConnectNodeMode()` falls back only to `OnboardingWizardModel.hasExistingLocalSetup(root:)`, which reads `openclaw.json`. Existing local setups that provide gateway auth through `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, or the launchd snapshot can be disconnected until onboarding is rerun even though `GatewayEndpointStore` otherwise treats those auth sources as valid.
  - confidence: 0.82
- **[P2] Do not make debug installs fall back to latest:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:98-103`
  - body: Returning `nil` for `.debug` bundle identifiers makes downstream installer and dev-link code use `latest` for the CLI target. Because this path executes a network installer on developer/tester machines, the debug build should stay pinned or require an explicit opt-in for unpinned installs.
  - confidence: 0.76
