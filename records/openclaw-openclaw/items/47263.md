## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Keep local health probes loopback-only:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:415-419`
  - body: These startup/readiness probes now build a fresh channel from `GatewayEndpointStore.localConfig()`, which can resolve `tailnet` or `custom` hosts while carrying token/password. Because `GatewayChannelActor` sends auth during connect, the process manager can automatically transmit local gateway credentials to a non-loopback endpoint during health checks; keep this probe loopback-only or validate/TLS-gate the target before sending auth.
  - confidence: 0.92
- **[P1] Gate every path before persisting security acknowledgement:** `apps/macos/Sources/OpenClaw/OnboardingView+Actions.swift:62`
  - body: The new acknowledgement only blocks `Next`, but the page dots still jump directly to later pages; a first-run user can land on the final page and `finish()` will persist the acknowledgement anyway. Route dot navigation through the same guard or refuse to persist unless the user explicitly checked the box.
  - confidence: 0.9
- **[P2] Do not make debug installs run unpinned latest:** `apps/macos/Sources/OpenClaw/GatewayEnvironment.swift:102`
  - body: Returning `nil` for `.debug` bundles feeds `CLIInstaller.install()`'s `?? "latest"` fallback, so debug builds run the remote install script against a moving package version. Keep debug installs pinned or require an explicit developer opt-in before `latest`.
  - confidence: 0.86
- **[P2] Preserve env and launchd auth in node-mode gating:** `apps/macos/Sources/OpenClaw/NodeMode/MacNodeModeCoordinator.swift:147`
  - body: This fallback only checks `openclaw.json` via `hasExistingLocalSetup(root:)`, but the app already treats `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_GATEWAY_PASSWORD`, and the launchd snapshot as valid local auth sources. Upgraded users with auth there will be disconnected from node mode until they rerun onboarding even though their gateway auth is configured.
  - confidence: 0.87
- **[P2] Add a CLI install recheck for manual installs:** `apps/macos/Sources/OpenClaw/OnboardingView+Pages.swift:748`
  - body: The manual path only copies the install command, while `Next` remains disabled until `cliInstalled` refreshes. Since refresh currently happens on page entry or after the in-app installer, a user who runs the copied command in Terminal gets stuck on this page until they navigate away and back.
  - confidence: 0.84
- **[P3] Preserve the injected readiness connection:** `apps/macos/Sources/OpenClaw/GatewayProcessManager.swift:380`
  - body: Replacing `self.connection.requestRaw` with `probeLocalGatewayHealth()` bypasses the DEBUG `setTestingConnection` hook used by `GatewayProcessManagerTests`, so attach/start/readiness tests can no longer drive the path with a fake gateway connection and will depend on a real local socket instead.
  - confidence: 0.8
