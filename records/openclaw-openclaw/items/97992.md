## Summary

Keep open: current main still keeps macOS Gateway LaunchAgent PATHs on the canonical system-only policy, skips Darwin user-bin/Nix dirs by default, and does not preserve manually added macOS PATH entries on reinstall. The merged pnpm 11 PATH work only partially overlaps and does not settle the macOS user-bin default or opt-in decision.

## What This Changes

The issue requests macOS Gateway service PATH generation to include common user bin directories such as Nix, Bun, and local bins, or provide an operator override.

## Best Possible Solution

Keep the canonical macOS service PATH unless maintainers explicitly approve a safer operator-controlled opt-in; if approved, align schema, docs, doctor guidance, and regression coverage for fresh install, reinstall, and command-resolution security.
