## Summary

Keep open: current main and v2026.6.11 still omit macOS user-bin and Nix directories from the generated Gateway service PATH, and the current docs/tests treat that as a deliberate LaunchAgent hardening policy. Changing that behavior needs maintainer product and security review rather than conservative cleanup.

## What This Changes

The issue requests that the macOS Gateway service PATH include or allow opt-in user bin directories such as Nix, Bun, and local bins, and preserve manual PATH additions across reinstall.

## Best Possible Solution

Keep the canonical macOS service PATH unless maintainers explicitly approve a safer operator-controlled opt-in; if approved, add schema/docs/doctor guidance plus regression coverage for fresh install, reinstall, and command-resolution security.
