## Summary

Keep open: current main still skips macOS user-bin and Nix directories in the generated Gateway LaunchAgent PATH by default, while reinstall still does not preserve edited macOS PATH entries. The recently merged pnpm 11 PATH PR only partially overlaps; the remaining macOS default/config behavior needs maintainer product and security review.

## What This Changes

Request macOS Gateway LaunchAgent service PATH generation include or preserve user-level bin directories such as Nix, Bun, local bin, and similar package-manager paths.

## Best Possible Solution

Keep the canonical macOS service PATH unless maintainers approve an explicit operator-controlled opt-in; if approved, add schema/docs/doctor guidance and regression coverage for fresh install, reinstall, and command-resolution safety.
