## Summary

Keep open: current main and v2026.6.11 still intentionally omit macOS user-bin/Nix directories from the managed Gateway LaunchAgent PATH, and changing that default or adding an opt-in is a product/security policy decision rather than conservative cleanup.

## What This Changes

The issue requests including macOS user bin directories, especially Nix/Bun/local paths, in the managed Gateway daemon PATH or exposing an operator opt-in for them.

## Best Possible Solution

Maintainers should decide the macOS managed-service PATH policy first; if support is accepted, prefer a documented opt-in with doctor guidance and regression coverage over silently changing the canonical default.

- **Keep current policy:** Document that managed macOS services intentionally omit user-bin directories and direct exec-only use cases to `tools.exec.pathPrepend` or absolute commands.
