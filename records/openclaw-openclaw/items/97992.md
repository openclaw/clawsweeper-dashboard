## Summary

Keep open: current main still excludes macOS user-bin/Nix directories from generated Gateway LaunchAgent PATHs and still discards existing macOS PATH edits on reinstall, while the Nix docs still promise service PATH discovery on both macOS launchd and Linux. The recently merged pnpm PATH PR only partially overlaps and does not resolve the Darwin user-dir default or preservation behavior.

## What This Changes

The issue requests that macOS Gateway daemon PATH generation include or preserve user-level bin directories such as Nix, Bun, local, and other package-manager paths.

## Best Possible Solution

Resolve the docs/code mismatch with an explicit maintainer-approved PATH policy: keep the canonical macOS service PATH by default unless maintainers approve a narrow Nix/user-bin opt-in with schema, doctor, docs, and security regression coverage.
