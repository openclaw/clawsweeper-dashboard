## Summary

Keep open: current main and the latest release still intentionally omit macOS user-bin directories from managed Gateway service PATH, so this remains a product and security-boundary decision rather than cleanup.

## What This Changes

Requests macOS managed Gateway services include or preserve user-level binary directories such as Nix, Bun, and local bins so Gateway exec commands can find those tools.

## Best Possible Solution

Decide the macOS managed-service PATH policy first; if these dirs are supported, prefer a maintainer-approved opt-in with doctor, docs, and regression coverage while keeping the secure canonical default.
