## Summary

Keep open: current main and v2026.6.11 still omit macOS user-bin and Nix directories from the generated Gateway service PATH by default, and reinstall still drops existing macOS PATH entries. The merged pnpm 11 PATH PR is relevant but only partially overlaps because it did not change the macOS LaunchAgent default or preservation policy.

## What This Changes

Request macOS Gateway managed services include common user-bin paths such as Nix, Bun, and local bins, or provide an operator opt-in, while preserving manual PATH additions across reinstall.

## Best Possible Solution

Keep the canonical macOS service PATH by default unless maintainers approve an explicit operator-controlled opt-in with docs, doctor guidance, schema coverage, and security regression tests.
