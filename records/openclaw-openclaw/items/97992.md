## Summary

Keep open: current main and v2026.6.11 still omit macOS Nix/user-bin directories from the managed Gateway service PATH, and the remaining question is a product/security policy choice rather than conservative cleanup.

## What This Changes

The issue asks OpenClaw to include macOS user-bin directories such as Nix, Bun, and local bin paths in the Gateway daemon PATH or expose an operator opt-in for them.

## Best Possible Solution

Make a maintainer-approved macOS service PATH policy decision; if supporting these dirs, prefer an explicit, documented opt-in with doctor/audit coverage over silently expanding the canonical default.

Options:

- **Keep default and fix docs:** Leave the macOS service PATH canonical and update Nix/install guidance to use supported per-exec or wrapper paths instead of promising launchd auto-discovery.

## Solution Assessment
