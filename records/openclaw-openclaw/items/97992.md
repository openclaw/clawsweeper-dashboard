## Summary

Keep open: current main and v2026.6.11 still exclude macOS user-bin and Nix directories from the generated Gateway service PATH, while current docs/tests disagree about whether macOS launchd Nix discovery is supported. Resolving that conflict needs maintainer product and security review, not conservative cleanup.

## What This Changes

The issue requests that macOS Gateway service PATH generation include or preserve user-level binary directories such as Nix, Bun, and local bin paths for daemon-run exec commands.

## Best Possible Solution

Keep the hardened macOS service PATH unless maintainers approve an explicit opt-in; then align code, tests, docs, doctor guidance, and macOS install/reinstall proof around that choice.
