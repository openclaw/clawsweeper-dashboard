## Summary

Keep open: current main still omits macOS user-bin and Nix directories from the generated Gateway service PATH by default, and the merged pnpm PATH PR only partially overlaps this broader macOS LaunchAgent policy question.

## What This Changes

The issue requests macOS Gateway service PATH support for user-level binary directories such as Nix, Bun, and local bins, or an operator-facing service PATH opt-in.

## Best Possible Solution

Keep the canonical macOS service PATH unless maintainers approve an explicit operator-controlled opt-in; then align the service PATH builder, reinstall behavior, docs, doctor/audit messaging, and regression tests around one security-reviewed policy.
