## Summary

Keep open. Current main and latest release still hardcode bootstrap file order and classify only `HEARTBEAT.md` as dynamic, so the requested cache-boundary/order control remains missing and needs maintainer product/API direction.

## What This Changes

Request configurable bootstrap dynamic-file classification and injection ordering so volatile workspace files can land below the prompt-cache boundary while stable prefix order stays deterministic.

## Best Possible Solution

Maintainers should choose one documented prompt-cache context contract, then implement dynamic-file classification and deterministic ordering through that surface with schema, docs, and focused prompt-boundary tests.
