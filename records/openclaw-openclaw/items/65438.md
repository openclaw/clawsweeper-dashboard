## Summary

Keep open. Current main and v2026.6.11 still hardcode bootstrap context ordering and only classify `HEARTBEAT.md` as dynamic, so the requested configurable dynamic-file and ordering surface remains missing and needs maintainer product/API direction.

## What This Changes

The issue requests configurable workspace bootstrap file ordering and dynamic-file classification so frequently changing files can be placed after the prompt-cache boundary.

## Best Possible Solution

Maintainers should choose one documented prompt-cache/context contract, then implement dynamic-file classification and deterministic ordering through that surface with schema, docs, and focused prompt-shape coverage.
