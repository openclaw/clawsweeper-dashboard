## Summary

Keep open. Current main and v2026.6.11 still hardcode bootstrap file order and only classify `HEARTBEAT.md` as dynamic, while the requested `bootstrapDynamicFiles` / `bootstrapFileOrder` surface remains a prompt-cache config/product decision.

## What This Changes

Add configurable bootstrap dynamic-file classification and optional injection ordering so volatile workspace files can be placed after the prompt-cache boundary.

## Best Possible Solution

Maintain a documented cache-aware bootstrap contract that lets operators classify volatile bootstrap files without breaking default behavior, with deterministic ordering, schema/docs, and prompt-shape regression coverage.
