## Summary

## What This Changes

Update cron top-of-hour stagger detection so step, list, and range minute fields that include minute zero receive the default stagger instead of requiring a literal `0` minute field.

## Best Possible Solution

Land one narrow core fix in `src/cron/stagger.ts` that detects minute-zero inclusion with Croner-compatible parsing, preserves explicit `staggerMs: 0`, and adds focused helper, service/default, normalization, and doctor migration coverage.
