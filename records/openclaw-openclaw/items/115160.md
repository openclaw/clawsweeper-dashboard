## Summary

This appears to be a focused fix for the linked QMD parser crash: malformed external rows are filtered before the memory manager consumes them, while valid result objects retain their order. The supplied regression, real-child-process coverage, and successful real-behavior-proof check support keeping this PR open for ordinary maintainer review and completion of its in-progress required checks; its protected `maintainer` label rules out automated cleanup.

## What This Changes

This PR filters null, primitive, and nested-array entries from QMD JSON search output so QMD-backed memory search preserves valid hits instead of crashing.

## System Context

QMD-backed memory search invokes an external QMD process and parses its JSON result array in the memory host SDK before the memory manager turns hits into user-visible memory results. This change strengthens that parser boundary so malformed external rows do not reach downstream hit handling.
