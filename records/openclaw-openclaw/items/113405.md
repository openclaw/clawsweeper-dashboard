## What This Changes

The PR adds native OS-realpath validation for raw workspace-path parents and regression coverage for a symlink-followed-by-`..` path that lexically appears in-root but resolves outside the workspace.

## System Context

Agent tools pass workspace-relative or absolute paths through the sandbox-path guard before files are read, written, patched, or attached. The guard normalizes accepted paths for downstream filesystem-safe operations, so its boundary decision must agree with operating-system symlink resolution.
