Keep open. Current main still refuses ambiguous Telegram `send_attempt_started` recovery without adapter reconciliation, Telegram does not advertise that reconciliation capability, and the Control UI history-refresh path still has plausible burst/backpressure exposure during active stream updates.

## Best Possible Solution
