## Summary

Keep open: current main and v2026.6.11 still lack the requested workspace/internal subagent-completion, turn-completion, and tool-call-threshold hook surface. Adjacent typed plugin hooks and open PRs cover parts of the lifecycle space, but the workspace hook payload, authority, ordering, and threshold semantics remain a maintainer product/security decision.

## What This Changes

The issue requests Gateway/workspace lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define a maintainer-approved lifecycle hook split: expose only safe observation events to workspace/internal hooks, keep mutation/control and sensitive runtime policy in typed plugin hooks, and decide how the open turn-end/save PRs relate to any remaining subagent and threshold events.
