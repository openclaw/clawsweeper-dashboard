## Summary

Keep open: current main and v2026.6.11 still do not expose the requested workspace/internal lifecycle hook surface. The gap is source-proven, but the safe API needs maintainer direction because it touches hook permissions, session/completion payloads, ordering, and a possible new threshold config surface.

## What This Changes

The issue requests workspace-visible lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define a narrow, documented lifecycle-hook contract that first settles the workspace-hook versus typed-plugin boundary, then adds only the minimal events and payload fields with focused tests for ordering, security-sensitive data, and docs.
