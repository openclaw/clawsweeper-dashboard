## Summary

Keep open: current main still lacks the requested workspace/internal `subagent:ended`, turn-complete, and tool-call-threshold hook surface. Adjacent typed plugin hooks cover some lifecycle and tool-control use cases, but they do not satisfy the requested HOOK.md workspace hook workflow, and the remaining decision is a product/security-boundary choice.

## What This Changes

Request to expose gateway/workspace lifecycle hooks for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define a maintainer-approved split: expose only safe observation events to workspace/internal hooks, keep mutating or sensitive lifecycle control in typed plugin hooks, and document/test payload, ordering, permissions, and threshold semantics.
