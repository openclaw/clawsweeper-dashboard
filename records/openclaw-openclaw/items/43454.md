## What This Changes

The issue requests workspace/internal lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define a minimal documented lifecycle contract that separates observation-only workspace events from richer typed plugin control hooks, then add source, docs, and tests for the approved event set and payloads.
