- `impact:session-state`: The motivating use cases are memory, learning loops, subagent completion processing, and turn-level state handling.

## Summary

Keep open: current main and v2026.6.11 still lack the requested workspace/internal `subagent:ended`, turn-complete, and tool-call-threshold hook events. Existing plugin hooks are adjacent but do not close the workspace hook API gap, and overlapping open PRs still need maintainer API/security design.

## What This Changes

Request to add gateway/workspace lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Maintainers should settle one lifecycle-hook contract covering workspace/internal hooks and typed plugin hooks, then land it with explicit event names, payloads, ordering, timeout/security behavior, docs, and regression tests.

## Reproduction Assessment

Yes for the source-level gap: current main can be checked by inspecting the internal hook event union, subagent completion emitter, and internal hook docs. A runtime repro is not required because this is a missing API surface rather than a broken existing contract.

## Solution Assessment

Unclear as proposed: exposing `subagent:ended` is plausible, but turn-complete and threshold hooks need maintainer decisions on naming, payloads, ordering, config, and security. The safer solution is a designed lifecycle contract rather than a one-off plumbing patch.
