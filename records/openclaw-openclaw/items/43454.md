## Summary

Keep open: current main and v2026.6.11 still lack the requested workspace/internal lifecycle hook surface, and the remaining payload, authority, ordering, and threshold semantics need maintainer product/security review.

## What This Changes

The issue requests workspace/internal gateway lifecycle hooks for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define a maintainer-approved lifecycle contract that exposes only safe observation data to workspace/internal hooks, keeps mutating or sensitive control in typed plugin hooks, and documents/tests payload, ordering, permissions, and threshold behavior.

- **Keep Lifecycle Plugin-Only:** Treat existing typed plugin hooks as the supported lifecycle/control surface and decline expanding HOOK.md workspace hooks for this data.
- **Design Unified Lifecycle Contract:** Pause implementation until maintainers define one lifecycle model covering internal hooks, typed plugin hooks, payloads, thresholds, permissions, and ordering.

## Solution Assessment

Unclear as proposed. A narrow observation-only `subagent:ended` internal hook may be maintainable, but turn-complete and threshold behavior need a maintainer-approved API/security split because plugin hooks already cover some lifecycle and tool-control use cases.
