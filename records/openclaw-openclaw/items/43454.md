## Summary

Keep open: current main and v2026.6.11 still do not expose the requested workspace/internal lifecycle hook surface for subagent completion, turn completion, or tool-call thresholds, and the remaining API, ordering, payload, and security choices require maintainer direction.

## What This Changes

The issue requests new Gateway/workspace lifecycle hooks for subagent completion, per-turn completion, and optional tool-call threshold events.

## Best Possible Solution

Define one maintainer-approved lifecycle hook contract: safe observation-only workspace/internal events where appropriate, typed plugin hooks for mutation/control, and explicit payload, permission, ordering, docs, and regression tests before implementation.
