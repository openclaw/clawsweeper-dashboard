## What This Changes

Request workspace/internal gateway lifecycle hooks for subagent completion, turn completion, and tool-call thresholds so hook authors can build event-driven learning, memory, and audit workflows.

## Best Possible Solution

Define a maintainer-approved lifecycle contract: expose narrow observation-only workspace/internal events where safe, keep mutating or sensitive control in typed plugin hooks, and document/test payload, ordering, timeout, and threshold semantics.

Owner confidence: medium

Options:

- **Stage observation-only internal hooks (recommended):** Add safe, non-mutating internal events for subagent and turn completion while leaving mutation, blocking, and sensitive child/session access in typed plugin hooks.
- **Keep lifecycle hooks plugin-only:** Treat typed plugin hooks as the supported lifecycle surface and narrow this issue away from HOOK.md workspace hooks that need sensitive runtime state.
- **Design one lifecycle model first:** Pause implementation until maintainers define a combined internal/plugin lifecycle model covering payloads, ordering, thresholds, and security limits.
