## Summary

Keep open: current main and v2026.6.11 still only expose adjacent plugin-level subagent hooks and lack the requested internal/workspace subagent, turn-complete, and tool-call-threshold lifecycle hook surface; related PRs are open/conflicting or closed unmerged, so this remains a maintainer product/security API design item.

## What This Changes

Requests workspace/internal lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds so automation and memory loops can react without polling or prompt rules.

## Best Possible Solution

Define a narrow lifecycle hook contract with documented event names, bounded payloads, ordering, timeout/failure semantics, security review, and focused tests before adding subagent completion, turn completion, or opt-in threshold behavior.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 lack the requested internal subagent, turn-complete, and threshold events, while subagent completion only dispatches the adjacent plugin-level subagent_ended hook.

## Solution Assessment

Unclear pending maintainer API and security design. The direction is plausible, but the best solution must settle internal versus typed plugin surfaces, event naming, payload bounds, execution ordering, timeout behavior, and whether threshold config belongs under hooks.internal.entries.
