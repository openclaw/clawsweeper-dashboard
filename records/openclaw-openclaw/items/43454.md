## Summary

Keep open: current main still lacks the requested workspace/internal lifecycle hook surface. The plugin `subagent_ended` hook exists, but it is not exposed as the HOOK.md/internal event requested here, and the related open PRs are partial or conflicting rather than a merged canonical fix.

## What This Changes

Request to add workspace/internal gateway lifecycle events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define one additive lifecycle contract for subagent completion and agent/tool turn boundaries, decide workspace-vs-plugin ownership and security gating, then update source, docs, and focused hook tests together.

Yes, from source inspection: current main omits a `subagent` internal hook family and the subagent completion helper only emits the plugin `subagent_ended` hook. I did not run runtime tests because this was a read-only cleanup review.

## Solution Assessment

Unclear: the first phase is a plausible small bridge, but the full request mixes workspace hooks, typed plugin hooks, turn boundaries, and a new threshold config. Maintainers should choose the durable security and API contract before implementation.
