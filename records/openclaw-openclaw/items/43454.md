## Summary

Keep open: current main and the latest release still have adjacent plugin-level lifecycle hooks, but not the requested workspace/internal `subagent:ended`, turn-complete, or tool-call-threshold hook surface. Several related PRs cover pieces of the design, but they are open, partial, conflicting, or closed unmerged, so this remains a maintainer product/security API decision.

## What This Changes

The issue requests new workspace/internal gateway lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Maintainers should settle one lifecycle-hook contract covering workspace/internal hooks and typed plugin hooks, with explicit event names, payloads, ordering, timeout/security behavior, docs, and focused tests, then land or close the partial PRs against that design.

## Reproduction Assessment

Yes. The source-level gap is reproducible by inspecting `InternalHookEventType`, the subagent completion emitter, and the internal hook docs; no runtime repro is needed for this missing API surface.

## Solution Assessment

Unclear as proposed. Exposing `subagent:ended` is plausible, but the combined turn-complete and threshold request needs maintainer decisions on names, payloads, ordering, config, and security before implementation.
