## Best Possible Solution

Define a maintainer-approved lifecycle contract that exposes only safe observation events to workspace/internal hooks, keeps mutating or sensitive lifecycle control in typed plugin hooks, and documents/tests ordering, payload, permission, and timeout behavior.
