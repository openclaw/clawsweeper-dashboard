Keep open: current main and v2026.6.11 still lack the requested workspace/internal lifecycle hooks, while adjacent typed plugin hooks do not satisfy the HOOK.md workspace-hook workflow. ## What This Changes

The issue requests workspace/internal hook events for subagent completion, agent turn completion, and tool-call threshold crossings.

## Best Possible Solution

Define a maintainer-approved split: safe observation-only workspace/internal lifecycle events where appropriate, typed plugin hooks for mutation or sensitive runtime control, and documented payload/order/security tests for the chosen contract.
