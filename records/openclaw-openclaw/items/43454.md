## What This Changes

Request to expose workspace hook events for subagent completion, agent turn completion, and tool-call threshold lifecycle boundaries.

## Best Possible Solution

Define a minimal documented lifecycle contract that separates observation-only workspace events from richer typed plugin control hooks, then add focused source, docs, and tests for the approved event set and payloads.
