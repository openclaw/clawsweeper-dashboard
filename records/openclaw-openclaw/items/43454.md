## Summary

Keep open: current main still does not expose the requested workspace/internal lifecycle hook surface, while adjacent typed plugin hooks only cover part of the need. The remaining work is a product and security-boundary decision because it would define new event payloads, ordering, and possibly threshold config behavior.

## What This Changes

The issue requests gateway/workspace lifecycle hooks for subagent completion, agent turn completion, and tool-call threshold events.

## Best Possible Solution

Define a narrow documented lifecycle-hook contract that separates observation-only workspace events from typed plugin control hooks, then add the minimal events with focused payload, ordering, security, and docs coverage.

- **Add the full workspace lifecycle surface:** Add subagent, turn-complete, and threshold workspace events after maintainers define payloads, ordering, and config semantics.
