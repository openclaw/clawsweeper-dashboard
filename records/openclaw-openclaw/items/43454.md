## Summary

Keep open: current main and v2026.6.11 still lack the requested workspace/internal `subagent:ended`, turn-complete, and tool-call-threshold hook surface. Adjacent plugin hooks and open PRs cover parts of the lifecycle story, but there is no merged complete fix, and the remaining work is a product/API design decision because it exposes session, tool, and subagent state and may add config surface.

## What This Changes

The issue requests new gateway/workspace lifecycle hook events for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Keep this open as a maintainer-sponsored hook API design item, then choose a narrow event/payload model with explicit security boundaries, docs, and focused tests before any implementation PR.
