## Summary

Keep open: current main and v2026.6.11 still lack the requested workspace/internal lifecycle hook surface. Plugin hooks cover adjacent `subagent_ended` and `agent_end` cases, but the workspace hook API still has no `subagent` family, no turn-complete event with tool-count context, and no tool-call-threshold event.

## What This Changes

The issue requests additive workspace/internal lifecycle hooks for subagent completion, agent turn completion, and tool-call thresholds.

## Best Possible Solution

Define a narrow additive lifecycle contract first, then implement only the approved event names, safe payload fields, docs, and focused tests for workspace/internal hooks and any matching plugin hook surface.
