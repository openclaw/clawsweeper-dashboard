## Summary

Keep open: current main and the latest release still do not expose the requested workspace/internal lifecycle hook events, while adjacent typed plugin hooks cover only part of the use case. The remaining work is a product and security-boundary decision about event families, payloads, ordering, and whether threshold behavior belongs in workspace hooks or typed plugin APIs.

## What This Changes

Request to add gateway/agent lifecycle hook events for subagent completion, turn completion, and tool-call thresholds so workspace hooks can drive learning, memory, and audit workflows.

## Best Possible Solution

Define a minimal documented lifecycle contract that separates observation-only workspace events from richer typed plugin control hooks, then add focused source/docs/tests for the approved event set and payloads.
