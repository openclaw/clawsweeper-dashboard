## What This Changes

The issue requests per-boot, server-enforced internal capabilities for embedded cron operations and subagent completion without exposing broad Gateway credentials.

## System Context

Embedded agent runtimes communicate with the local Gateway to schedule cron work and finalize child-agent runs. The proposed capability layer would constrain those runtime calls before they reach cron and session-state operations.

## Best Possible Solution

Define one Gateway-owned ephemeral internal-principal protocol, including trusted bootstrap transport and exact audience/resource contracts, then implement cron and subagent completion as narrowly tested consumers of that protocol.
