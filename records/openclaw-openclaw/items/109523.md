## What This Changes

Adds a five-second timeout to the shared launchctl helper used for legacy macOS gateway-service bootout and unload cleanup.

## Best Possible Solution

Keep a bounded launchctl deadline, but return an explicit cleanup outcome, verify that bootout or unload succeeded before moving the plist and reporting removal, preserve the plist with an actionable doctor warning when both attempts time out, and cover success and timeout paths with focused tests plus a redacted real macOS run.
