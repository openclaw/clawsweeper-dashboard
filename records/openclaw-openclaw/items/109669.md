## Summary

The patch is a focused, source-backed fix for corrupted UTF-8 at byte-bounded E2E diagnostic tails. Current main decodes arbitrary byte slices directly, while the PR removes only a split leading code point and uses Node’s decoder to avoid emitting an incomplete trailing code point; no blocking correctness or security issue is evident.

The PR adds UTF-8-safe decoding for byte-bounded string and file tails in the E2E text-file helper and adds focused emoji-boundary regression cases.

## Best Possible Solution
