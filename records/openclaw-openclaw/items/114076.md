## What This Changes

The PR changes the debug proxy’s HTTP response forwarding so slow or disconnected downstream clients pause, resume, or terminate the upstream response safely.

## System Context

The debug proxy receives an HTTP request from a local client, forwards it to an upstream target, captures a bounded preview, and streams the upstream response back to that client. This change sits in the response-forwarding stage, where downstream writable capacity determines whether upstream reads may continue.
