## What This Changes

Updates the debug proxy’s HTTP response forwarding so it pauses an upstream response when the downstream client applies backpressure, resumes on drain, and stops forwarding when the downstream response closes or errors.

## System Context

The debug proxy forwards HTTP responses from an upstream origin to a local client while recording a bounded response preview. Upstream response chunks flow through the proxy’s downstream ServerResponse, where writable-stream backpressure and disconnect handling determine whether the proxy remains responsive.
