## What This Changes

The PR updates the debug proxy’s HTTP response forwarding to pause upstream reads when a slow client applies writable-stream backpressure, resume after `drain`, and stop upstream forwarding when the downstream response closes or errors.

## System Context

The debug proxy forwards an HTTP response from a target server to a local client while recording a bounded response preview for test diagnostics. The changed forwarding loop sits between Node’s readable upstream response and writable downstream `ServerResponse`, so it governs memory pressure and cleanup when clients are slow or disconnect.
