## Label Justifications

- `P2`: This is an opt-in, LINE-specific improvement, but the proposed failure and bypass paths can lose or mis-associate queued attachments.
- `merge-risk: 🚨 message-delivery`: The PR consumes pending attachments before successful delivery and can flush them on an admitted non-mention command turn.

## Summary

Current `main` does not provide this optional behavior, and the paired issue remains open. The PR is useful but not merge-ready because queued media can be consumed by a non-mention command and is removed before the consuming turn succeeds.

## What This Changes

The PR adds opt-in LINE mention gating for non-text group messages and a bounded in-memory queue that attaches skipped downloadable media to a later group turn.

## Best Possible Solution

Attach pending media only when the activation decision reflects an actual or accepted implicit mention, retain the queue through downstream failures, and clear it only after the consuming turn succeeds; then prove skip, command-bypass, failure/retry, and successful delayed delivery in a real LINE group.

Yes. Queue a skipped media event, then either send an authorized control command without a mention or make the later consuming turn fail; the source deterministically exposes both incorrect consumption paths.

## Solution Assessment

No. The opt-in direction is compatible with existing behavior, but queue attachment must use the activation result and queue clearing must follow successful processing rather than precede it.
