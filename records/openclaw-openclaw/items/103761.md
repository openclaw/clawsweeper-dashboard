## Summary

This PR remains useful and should stay open, but the latest head still has a same-group concurrency defect: pending media is serialized while its coupled pending-history entry is not, so overlapping webhook deliveries can retain an attachment while erasing its context. ## What This Changes

The PR adds two opt-in LINE group settings and a keyed bounded queue that retains skipped non-text media for delivery with a later genuinely mentioned message.

## Best Possible Solution
