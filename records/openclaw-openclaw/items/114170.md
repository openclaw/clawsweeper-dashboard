## What This Changes

This PR makes the Control UI use the runtime configuration capability as the sole settings writer, adding connection-epoch and snapshot-freshness fences so stale Gateway callbacks or concurrent writes cannot overwrite another account’s preferences, sidebar state, or locale.

## System Context

The Control UI receives Gateway connection snapshots, creates a runtime configuration owner, reconciles server-backed preferences and sidebar state, and sends configuration patches back to the Gateway. This PR changes how those snapshot updates and writes are tied to a physical Gateway connection so obsolete callbacks cannot affect a newer connection or account.
