## What This Changes

The PR saves a browser user’s valid New Session workspace, worktree, model, and reasoning selections per Gateway and agent, then restores them only after current Gateway data accepts them.

## System Context

The Control UI’s New Session page collects the agent, workspace, folder, worktree, model, and reasoning choices before starting a session through the Gateway. This change adds browser-local preference storage and validation so later drafts can reuse still-valid choices without making those preferences server configuration.
