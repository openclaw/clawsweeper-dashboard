## What This Changes

This PR stores per-browser, per-Gateway, per-agent New Session workspace, folder, worktree, model, and reasoning selections in local storage, then revalidates them before restoring a new draft.

## System Context

The Control UI’s New Session page combines browser-held draft choices with current Gateway and agent metadata before creating a session. This PR inserts a browser-local preference store into that flow and falls back when the Gateway no longer recognizes a remembered folder or model.
