## What This Changes

This PR stores each browser user’s last valid new-session workspace, folder, worktree, model, and reasoning selections per Gateway and agent, then revalidates them before restoring a draft.

## System Context

The Control UI’s new-session page combines the active agent, Gateway folder metadata, and model catalog into a draft that becomes a session only when the user submits it. This change adds browser-local draft preferences between those catalog inputs and the restored form controls, while keeping unavailable folders and models from being reused.
