## What This Changes

This PR stores each browser user's New Session workspace, worktree, model, and reasoning choices per Gateway and agent, then restores them only after current Gateway metadata accepts them.

## System Context

The Control UI New Session page gathers an agent, workspace or folder, worktree mode, and model controls before creating an agent session. This change adds browser-local preference storage between drafts, then validates restored values against live Gateway catalogs so obsolete folders and models fall back safely.
