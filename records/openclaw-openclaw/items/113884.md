## Summary

Keep this PR open for maintainer review. The implementation is a credible, narrowly scoped way to remember New Session choices and its connected-Gateway comment describes after-fix restoration, but it introduces a new persisted browser preference behavior while the linked request and this PR retain a `maintainer`/product-decision signal; that direction should be explicitly sponsored before merge.

## What This Changes

The PR stores per-Gateway, per-agent New Session workspace, worktree, model, and reasoning choices in browser-local storage, then restores only choices accepted by current Gateway metadata.

## System Context

The Control UI’s New Session page gathers a workspace, optional worktree, and model settings before creating an agent session. The PR inserts browser-local preference storage between a user’s prior selection and the next draft, with Gateway folder and model metadata deciding whether a saved value can be reused.
