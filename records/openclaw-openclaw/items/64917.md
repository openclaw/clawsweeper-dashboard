## Summary

## What This Changes

The issue asks for `sessions_send` from visible webchat to internal sessions to remain internal, avoid raw visible replies, and avoid rebinding target session delivery context to webchat.

## Best Possible Solution

Define the strict-internal versus announce-capable `sessions_send` contract, then align the tool, A2A helper, gateway delivery-context persistence, projection, tests, and docs so internal handoffs cannot leak raw replies or silently rebind targets.
