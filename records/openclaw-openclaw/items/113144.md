## Summary

Keep this issue open: current `main` still treats `<thinking/>` as an opening reasoning tag, so strict sanitization drops the remaining visible suffix. Two open PRs explicitly propose to close the issue; the stronger candidate also identifies an unresolved static-versus-streaming parser boundary that needs maintainer direction. Likely related people: steipete (high confidence, active area contributor and decision owner) and licheer-zte (medium confidence, author of the directly related repair commit).

## What This Changes

Fix assistant-text extraction so self-closing reasoning markers are removed without discarding visible text that follows them.

## System Context

OpenClaw removes model reasoning markup before delivering assistant text. Complete responses use the shared text sanitizer, while streamed responses use a separate partitioner to split visible output from hidden reasoning before delivery.
