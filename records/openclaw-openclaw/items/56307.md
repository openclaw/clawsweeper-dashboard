## Summary

Keep open. Current main still lacks the requested channel-declared auto-injection policy for `sessions_spawn`; the remaining work is a public plugin SDK/session-routing product decision, not conservative cleanup.

## What This Changes

The issue requests a channel plugin threading policy that automatically injects `thread: true` and `mode: "session"` for subagent spawns on channels that require thread-bound sessions.

## Best Possible Solution

Define one maintainer-approved channel-owned session/thread policy contract, then update the SDK surface, `sessions_spawn` schema/execution, channel metadata, docs, and focused tests together.
