## What This Changes

This PR caches the device-pairing snapshot used by gateway `node.list` and `node.describe` requests, invalidates it after pairing writes, detects external SQLite commits, and reuses the loaded snapshot for node-pairing projection.

## System Context

Gateway node reads combine persisted device-pairing records with current node connections to return node lists and descriptions. The pairing store now becomes the shared read boundary, while the gateway projects node-specific fields from that one loaded pairing snapshot.
