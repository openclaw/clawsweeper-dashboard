## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P1] Preserve SSRF policy for remote prompt images:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` with only `maxBytes`, while existing remote media fetchers pass the configured SSRF policy into guarded fetches. This means a prompt URL preload can ignore operator-defined web-fetch restrictions that the image tool already honors.
  - confidence: 0.9
- **[P1] Avoid fetching every URL in vision prompts:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches any HTTP(S) URL, and the detector later sends every match through `loadWebMedia` for vision-capable prompts. A normal link in the user's text can now trigger an outbound gateway fetch before the model call, even when it is not an explicit image reference.
  - confidence: 0.88
- **[P2] Do not mark skipped bracket URLs as seen:** `src/agents/pi-embedded-runner/run/images.ts:347`
  - body: When a media bracket has both a local path and a URL, this branch adds the URL to `seen` even though no `remote-url` ref is emitted. If the user repeats that URL elsewhere in the prompt, the full-prompt scan suppresses it and the image can still be missing from native vision input.
  - confidence: 0.82
- **[P2] Trim closing delimiters from URL refs:** `src/agents/pi-embedded-runner/run/images.ts:96`
  - body: The URL regex allows `)` but the trailing sanitizer does not remove it, so parenthesized or Markdown-style URLs can be normalized as `https://host/image.png)` and fetched from the wrong path. Add closing delimiter trimming or exclude those delimiters from the match.
  - confidence: 0.78
- **[P2] Keep remote URL dedupe case-sensitive:** `src/agents/pi-embedded-runner/run/images.ts:290`
  - body: `addRemoteUrlRef` reuses `normalizeRefForDedupe`, which lowercases keys on Windows for filesystem paths. HTTP URL paths can be case-sensitive, so two distinct remote image URLs can collapse into one and silently drop an image on Windows hosts.
  - confidence: 0.76
