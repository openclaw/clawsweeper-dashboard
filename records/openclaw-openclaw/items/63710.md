  - body: `HTTP_URL_REGEX_SOURCE` matches every HTTP(S) URL, so ordinary links in prompts can trigger gateway network fetches before non-image responses are discarded. The fix should only preload explicit safe image refs, or keep ambiguous links on the existing fallback path.
  - confidence: 0.93
- **[P1] Forward the configured SSRF policy for remote refs:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` with only `maxBytes`, while other remote-media tool paths pass the configured SSRF policy. This bypasses operator-configured remote-media SSRF behavior on a new prompt-controlled fetch path.
  - confidence: 0.94
- **[P2] Trim closing URL delimiters before fetching:** `src/agents/pi-embedded-runner/run/images.ts:96`
  - body: The URL matcher can include a closing parenthesis, but the punctuation trimmer does not remove it. Parenthesized or Markdown-style image URLs can be fetched as `/image.png)`, causing avoidable image-load failures.
  - confidence: 0.82
- **[P2] Keep remote URL dedupe case-sensitive:** `src/agents/pi-embedded-runner/run/images.ts:290`
  - body: Remote URL dedupe reuses the Windows local-path lowercasing rule, but HTTP path casing can be significant. On Windows, two distinct URLs that differ only by case can collapse to one image ref.
  - confidence: 0.79
