## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Forward SSRF policy into remote URL loading:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` with only `maxBytes`, so any configured SSRF allowlist, origin policy, or dispatcher policy is skipped for prompt-preloaded URLs. Thread the existing policy through this path before enabling remote prompt preloads.
  - confidence: 0.9
- **[P1] Restrict prompt URL preloads to image URLs:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches every HTTP(S) link in the prompt, so ordinary hyperlinks trigger gateway fetches before non-image responses are discarded. Limit detection to explicit image URLs or another maintainer-approved safe signal.
  - confidence: 0.92
- **[P2] Use URL-specific dedupe keys:** `src/agents/pi-embedded-runner/run/images.ts:290`
  - body: `addRemoteUrlRef` reuses the path dedupe normalizer, which lowercases keys on Windows. HTTP URL paths can be case-sensitive, so two distinct remote images can collapse into one native vision input.
  - confidence: 0.86
- **[P2] Do not mark skipped bracket URLs as seen:** `src/agents/pi-embedded-runner/run/images.ts:347`
  - body: When a bracketed attachment has a local path, this branch records the remote URL as seen even though no `remote-url` ref is emitted. A later explicit copy of that URL in the prompt is then suppressed and never loaded.
  - confidence: 0.84
- **[P2] Trim closing delimiters from remote URLs:** `src/agents/pi-embedded-runner/run/images.ts:96`
  - body: The sanitizer trims commas and periods but not closing delimiters, so parenthesized or Markdown-style image URLs can be fetched with a trailing `)` and fail unnecessarily.
  - confidence: 0.82
