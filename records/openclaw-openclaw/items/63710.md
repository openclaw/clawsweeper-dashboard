## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.92

Full review comments:

- **[P1] Restrict prompt URL preloads to explicit image refs:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches every HTTP(S) URL in the prompt, so ordinary links like docs pages are fetched by the gateway before `media.kind !== "image"` can discard them. This expands prompt text into network activity and latency outside the stated mixed image URL fix.
  - confidence: 0.94
- **[P1] Forward the configured SSRF policy:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` without passing the configured SSRF policy, unlike the existing media-tool URL path. Any operator-configured remote-media restrictions are silently skipped for this prompt preload path.
  - confidence: 0.93
- **[P2] Do not suppress a URL ref that was never emitted:** `src/agents/pi-embedded-runner/run/images.ts:340-347`
  - body: When a `[media attached: path | url]` entry has a local path, this branch marks the URL as seen even though no `remote-url` ref is emitted. A later explicit occurrence of the same URL is then suppressed, so the image can still be missing if the local path cannot be loaded.
  - confidence: 0.86
- **[P2] Trim closing parentheses from prompt URLs:** `src/agents/pi-embedded-runner/run/images.ts:96`
  - body: The URL regex can capture a trailing `)` from parenthesized or Markdown-style links, but the trailing punctuation sanitizer does not remove it. That makes the preload fetch the wrong URL path for common prompt formatting.
  - confidence: 0.82
- **[P2] Keep HTTP URL dedupe case-sensitive on Windows:** `src/agents/pi-embedded-runner/run/images.ts:290-294`
  - body: `addRemoteUrlRef` reuses the local-path dedupe normalizer, which lowercases keys on Windows. HTTP URL paths can be case-sensitive, so distinct remote images such as `/Image.png` and `/image.png` can collapse into one native image ref.
  - confidence: 0.8
