## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Restrict remote URL detection before fetching:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches every HTTP(S) link, so a prompt that mentions a normal webpage will now trigger a gateway fetch before `media.kind !== "image"` can discard it. Limit preloading to intentional image refs, such as image-extension URLs or a maintainer-approved image URL boundary, so ordinary prompt links do not become outbound requests.
  - confidence: 0.92
- **[P1] Forward SSRF policy to remote preloads:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` with only `maxBytes`, but `loadWebMedia` supports `ssrfPolicy` and passes it into the guarded remote fetch. Thread the configured policy into this path so prompt-preloaded images obey the same SSRF boundary as other remote media loads.
  - confidence: 0.9
- **[P2] Do not mark skipped bracket URLs as seen:** `src/agents/pi-embedded-runner/run/images.ts:340-348`
  - body: When a `[media attached: path | url]` bracket has a local path, this code still records the remote URL in `seen` even though it emits no `remote-url` ref. If the user repeats that URL elsewhere in the prompt, the full-prompt scan suppresses it and the image can still be dropped.
  - confidence: 0.82
- **[P2] Keep URL dedupe case-sensitive on Windows:** `src/agents/pi-embedded-runner/run/images.ts:290-295`
  - body: `addRemoteUrlRef` uses `normalizeRefForDedupe`, which lowercases keys on Windows for filesystem paths. HTTP URL paths can be case-sensitive, so `https://host/Image.png` and `https://host/image.png` may collapse into one native image on Windows deployments.
  - confidence: 0.78
- **[P2] Trim closing delimiters from detected URLs:** `src/agents/pi-embedded-runner/run/images.ts:96-113`
  - body: The URL regex can capture a closing parenthesis in Markdown or parenthesized prose, and the punctuation trimmer does not remove `)`. That makes `(https://example.com/image.png)` fetch `image.png)` instead of the intended image URL.
  - confidence: 0.8
