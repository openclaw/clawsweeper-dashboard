## What This Changes

The PR changes embedded-runner image detection and tests to treat HTTP(S) prompt URLs as remote image refs, preload them with `loadWebMedia`, and merge them with inline images.

## Best Possible Solution

Land a refreshed fix on the current runner path that only preloads explicit image URL refs under the shared remote-media SSRF policy, preserves fallback behavior for ambiguous URLs, and includes focused regression plus redacted WebUI proof.

Overall confidence: 0.91

Full review comments:

- **[P1] Restrict preload detection to image URLs:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches every HTTP(S) link, so ordinary prompt text like a docs URL now triggers a gateway fetch before `media.kind !== "image"` can discard it. Please only preload URLs that are clearly intended image refs, or add an explicit policy for probing ambiguous URLs.
  - confidence: 0.92
- **[P1] Forward SSRF policy to remote image loads:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` with only `maxBytes`, but `loadWebMedia` and the guarded fetch path honor `ssrfPolicy` when supplied. This drops configured remote-media network policy on a new prompt-controlled fetch path.
  - confidence: 0.9
- **[P2] Do not mark skipped bracket URLs as seen:** `src/agents/pi-embedded-runner/run/images.ts:346-348`
  - body: When a `[media attached: path | url]` entry has a local path, this `else` still adds the URL to `seen` even though no remote ref is emitted. A later explicit occurrence of the same URL is then suppressed, so the request can still lose that image if the local path cannot load.
  - confidence: 0.84
- **[P2] Dedupe remote URLs case-sensitively:** `src/agents/pi-embedded-runner/run/images.ts:290-295`
  - body: `normalizeRefForDedupe` lowercases on Windows, which is valid for local filesystem paths but not HTTP URL paths. Mixed prompts containing `https://host/Image.png` and `https://host/image.png` can collapse two distinct remote images into one.
  - confidence: 0.82
- **[P2] Trim closing delimiters from remote URLs:** `src/agents/pi-embedded-runner/run/images.ts:96-118`
  - body: The new URL regex can include a closing parenthesis, but the trailing sanitizer does not remove `)`. Parenthesized or Markdown-style image links will fetch `image.png)` instead of `image.png`, causing avoidable remote image load failures.
  - confidence: 0.78
