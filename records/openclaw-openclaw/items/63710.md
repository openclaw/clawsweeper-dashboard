## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Forward SSRF policy on remote prompt-image loads:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` path calls `loadWebMedia` without the configured `ssrfPolicy`. Other remote media callers preserve that policy before reaching the guarded fetch layer, so this path can bypass operator SSRF settings for prompt-preloaded URLs.
  - confidence: 0.9
- **[P1] Avoid fetching every HTTP link in prompts:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches any HTTP(S) URL, so ordinary prompt links such as docs pages trigger gateway fetches before `media.kind !== "image"` can discard them. Restrict detection to explicit image refs or another owner-approved image URL shape.
  - confidence: 0.9
- **[P2] Keep remote URL dedupe case-sensitive:** `src/agents/pi-embedded-runner/run/images.ts:290-295`
  - body: `addRemoteUrlRef` reuses `normalizeRefForDedupe`, which lowercases dedupe keys on Windows for filesystem paths. HTTP URL paths can be case-sensitive, so two distinct remote images can collapse into one native image input on Windows.
  - confidence: 0.82
- **[P2] Do not mark skipped bracket URLs as seen:** `src/agents/pi-embedded-runner/run/images.ts:347`
  - body: When a `[media attached: path | url]` bracket has a local path, this `else` marks the URL as seen even though no remote ref is emitted. If the same URL is explicitly repeated later in the prompt, the full-prompt scan suppresses it and can lose the image.
  - confidence: 0.86
- **[P2] Strip closing delimiters from detected URLs:** `src/agents/pi-embedded-runner/run/images.ts:96`
  - body: The new trimmer removes commas and sentence punctuation but not closing `)` characters. Parenthesized or Markdown-style image URLs can be accepted as `...png)` and fetched from the wrong path.
  - confidence: 0.78
