  - body: When a media attachment bracket has a local path plus URL, this branch records the URL as seen even though it does not emit a remote ref. A later explicit repeat of that URL is suppressed, so the URL image can still be lost if the local path cannot load.
  - confidence: 0.83
- **[P2] Preserve HTTP URL casing when deduping:** `src/agents/pi-embedded-runner/run/images.ts:287`
  - body: Remote URLs reuse filesystem dedupe lowercasing on Windows, but HTTP path case can identify different resources. A prompt with both `Image.png` and `image.png` would collapse to one native image.
  - confidence: 0.82
