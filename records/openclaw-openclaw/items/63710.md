## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.9

Full review comments:

- **[P1] Limit remote image detection before fetching URLs:** `src/agents/pi-embedded-runner/run/images.ts:42`
  - body: `HTTP_URL_REGEX_SOURCE` matches any HTTP(S) URL, so ordinary prompt links can trigger gateway network fetches before non-image responses are discarded. The detector should only preload URLs inside the agreed image boundary, or keep non-obvious remote URLs on the existing image-tool path.
  - confidence: 0.92
- **[P1] Forward configured SSRF policy to remote URL loads:** `src/agents/pi-embedded-runner/run/images.ts:460-462`
  - body: The new `remote-url` branch calls `loadWebMedia` with only `maxBytes`, while the existing image tool forwards the configured remote-media SSRF policy. This new prompt preload path must honor the same policy before it can safely fetch user-supplied URLs.
  - confidence: 0.94
- **[P2] Keep skipped bracket URLs eligible for later explicit refs:** `src/agents/pi-embedded-runner/run/images.ts:340-348`
  - body: When a media-attached bracket has a local path, this block still adds the bracket URL to `seen` even though no `remote-url` ref is emitted. If the user repeats that URL explicitly elsewhere, the later full-prompt scan will suppress it and can still lose the image.
  - confidence: 0.83
- **[P2] Use URL-specific dedupe for remote refs:** `src/agents/pi-embedded-runner/run/images.ts:290-295`
  - body: `addRemoteUrlRef` reuses filesystem dedupe normalization, which lowercases keys on Windows. HTTP path casing can be significant, so distinct remote image URLs can collapse into one native image input on Windows deployments.
  - confidence: 0.78
- **[P2] Trim closing delimiters from detected remote URLs:** `src/agents/pi-embedded-runner/run/images.ts:96-118`
  - body: The trailing-punctuation sanitizer does not trim `)`, but the URL regex can include it, so Markdown or parenthesized image links can be fetched with the wrong path and fail unnecessarily.
  - confidence: 0.76
