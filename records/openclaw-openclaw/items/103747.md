## Summary

Keep open for a maintainer product decision. ## What This Changes

The issue requests a three-tier cognitive-framework system prompt and runtime enforcement for selected behavioral and safety rules, replacing much of the existing fragmented prompt guidance.

## Best Possible Solution

First define a cross-provider evaluation harness that measures rendered prompt size and task outcomes, then trial a bounded cognitive overlay through the existing provider-contribution and prompt-mode seams while preserving safety and delivery contracts.
