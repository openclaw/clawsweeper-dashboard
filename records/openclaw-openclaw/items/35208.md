## Summary

Keep open: current main and v2026.6.11 still lack owner/human handoff config or per-DM pause state for manual owner replies, and the only implementation attempt is closed unmerged prior art.

## What This Changes

The issue requests a configurable owner takeover mechanism that pauses per-DM auto-replies when the account owner sends a manual outgoing message, with explicit or cooldown-based resume behavior.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
