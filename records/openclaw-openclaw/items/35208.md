## Summary

Keep open: current main and v2026.6.11 still lack owner/human handoff config or per-DM pause state for manual owner replies, and the linked implementation attempt is closed unmerged prior art.

## What This Changes

Request owner/human handoff for DM auto-reply by detecting manual owner `fromMe` messages and pausing auto-replies per thread with configurable resume behavior.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, with per-account/per-conversation pause state, schema/docs, focused tests, and live transport proof.
