## Summary

Keep open: current main and latest release still lack owner/human handoff config or pause state for manual owner replies, and the only implementation attempt is a closed unmerged PR, so the central user problem remains.

## What This Changes

The issue requests an owner takeover or human handoff mode that pauses DM auto-replies when the account owner manually replies in WhatsApp or Telegram.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
