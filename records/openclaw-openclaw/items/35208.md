## Summary

Keep open: current main and the latest release still lack owner/human handoff config or per-DM pause state for manual owner replies, and the only linked implementation attempt is closed unmerged prior art.

## What This Changes

Request owner takeover for DM auto-reply so manual owner messages in personal WhatsApp/Telegram conversations pause AI replies per thread until a selected resume condition.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
