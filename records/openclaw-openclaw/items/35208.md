## Summary

Keep open: current main still lacks owner/human handoff behavior for manual DM replies, and the only linked implementation PR is closed unmerged prior art rather than an implemented or safe superseding fix.

## What This Changes

The issue requests an opt-in owner takeover mechanism that pauses per-DM auto-reply after the owner sends a manual message, with cooldown or explicit resume behavior.

## Best Possible Solution

Make this an opt-in, plugin-owned WhatsApp handoff first unless maintainers explicitly choose a shared channel contract, with clear pause/resume semantics, no default behavior change, tests, docs, and live transport proof.
