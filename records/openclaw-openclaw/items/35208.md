## What This Changes

The issue requests an owner/human handoff mode that pauses DM auto-replies when the account owner manually replies in the same WhatsApp or Telegram thread.

## Best Possible Solution

Ship a maintainer-approved, default-off WhatsApp-owned handoff policy first, with unchanged defaults, per-thread pause isolation, explicit resume semantics, docs, regression tests, and live WhatsApp proof; consider a shared channel contract only after the WhatsApp behavior is proven.
