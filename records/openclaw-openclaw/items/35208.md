Keep open: current main and the latest release still lack owner/human handoff behavior for manual DM replies, and the linked implementation PR is closed unmerged prior art rather than a shipped or viable superseding fix.

## What This Changes

The issue requests configurable owner takeover for WhatsApp/Telegram DM auto-reply so manual owner messages pause AI replies per thread until cooldown or explicit resume.

## Best Possible Solution

Ship an opt-in WhatsApp-owned owner handoff first unless maintainers choose a shared channel contract, with current-schema config, per-thread pause state, explicit or cooldown resume semantics, unchanged defaults, tests, docs, and live WhatsApp proof.
