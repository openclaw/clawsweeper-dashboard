## Summary

Keep open: current main still has no owner/human handoff pause state for manual DM replies, and the linked implementation is closed unmerged prior art rather than a shipped fix.

## What This Changes

Requested automatic owner takeover / human handoff behavior that pauses DM auto-replies when the owner manually replies in a conversation.

## Best Possible Solution

Keep this issue as the canonical product/design tracker and define the channel-owned pause-state contract before any implementation PR.
