## Summary

Keep open: current main and v2026.6.11 still lack owner/human handoff behavior for manual DM replies, while the linked implementation is closed unmerged prior art rather than a shipped fix.

## What This Changes

The issue requests a configurable owner takeover mode that pauses DM auto-replies when the account owner manually replies in a DM conversation.

## Best Possible Solution

Add a maintainer-approved, plugin-owned WhatsApp handoff design that detects non-gateway manual `fromMe` DMs, stores bounded per-account/per-conversation pause state, and documents explicit resume or cooldown behavior; consider Telegram/Discord parity only after the core config contract is agreed.
