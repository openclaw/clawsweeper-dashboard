## What This Changes

The issue requests owner/human handoff for DM auto-reply so manual outgoing owner messages pause AI replies per conversation with configurable cooldown or resume behavior.

## Best Possible Solution

Ship a maintainer-approved, default-off WhatsApp-owned handoff policy first, with unchanged defaults, per-thread pause isolation, clear resume/cooldown semantics, docs, regression tests, and live WhatsApp proof; consider a shared channel contract only after that behavior is proven.
