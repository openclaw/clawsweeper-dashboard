## Summary

Keep open: current main and the latest release still lack owner/human handoff config or per-DM pause state for manual owner replies, and the only linked implementation is a closed, unmerged PR that is useful prior art rather than shipped behavior.

## What This Changes

The issue requests an opt-in owner/human handoff mode that pauses DM auto-replies when manual outgoing owner messages are detected.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
