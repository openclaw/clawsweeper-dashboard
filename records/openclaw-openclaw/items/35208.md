## Summary

Keep open: current main and v2026.6.11 still do not provide owner/human handoff for DM auto-reply, and the linked implementation PR is closed unmerged prior art rather than a safe canonical fix.

## What This Changes

The issue requests a configurable owner-takeover mechanism that detects manual outgoing DM replies and pauses auto-replies per conversation until cooldown or explicit resume.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
