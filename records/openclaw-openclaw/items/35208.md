## Summary

Keep open: current main and v2026.6.11 still lack owner/human handoff config or per-DM pause state for manual owner replies, and the linked implementation PR is closed unmerged prior art rather than shipped behavior.

## What This Changes

Request owner takeover for DM auto-reply, especially WhatsApp, by detecting manual owner outgoing messages and pausing per-thread AI replies until a cooldown or explicit resume.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
