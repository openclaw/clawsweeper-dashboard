## Summary

Keep open: current main and v2026.6.11 still lack owner/human handoff config or per-DM auto-reply pause state, and the only matching implementation PR is closed unmerged prior art.

## What This Changes

Request owner/human handoff for DM auto-reply by detecting manual outgoing owner messages and pausing AI replies per conversation until cooldown or explicit resume.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then add schema, docs, focused tests, and live transport proof for per-account/per-conversation pause and resume semantics.
