## What This Changes

The issue requests configurable DM human handoff that pauses auto-replies after owner/manual outgoing messages and resumes by cooldown or explicit command.

Define a maintainer-approved plugin-owned handoff contract, likely WhatsApp-first, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
