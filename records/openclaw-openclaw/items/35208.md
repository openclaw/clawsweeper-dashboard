## Summary

Keep open: current main and the latest release still lack owner/human handoff behavior for manual DM replies, and the linked implementation PR is closed unmerged prior art rather than an implemented or safe superseding fix.

## What This Changes

Request an opt-in owner/human handoff mechanism that pauses DM auto-replies when the account owner manually sends a WhatsApp or Telegram DM reply.

## Best Possible Solution

Ship an opt-in WhatsApp-owned owner handoff first unless maintainers choose a shared channel contract, with current-schema config, per-thread pause state, explicit or cooldown resume semantics, unchanged defaults, tests, docs, and live WhatsApp proof.
