The issue requests configurable owner takeover/human handoff so manual DM replies pause channel auto-replies per conversation.

## Best Possible Solution

Add a maintainer-approved, plugin-owned WhatsApp handoff design that detects non-gateway manual fromMe DMs, stores bounded per-account/per-conversation pause state, and documents explicit resume or cooldown behavior; evaluate Telegram/Discord parity separately after the contract is chosen.
