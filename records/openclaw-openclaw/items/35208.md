## Summary

Keep open: current main and v2026.6.11 still do not implement owner/human handoff for DM auto-reply, and the linked implementation attempt is closed unmerged prior art rather than a safe landing path.

## What This Changes

The issue requests a configurable owner/human handoff mode that pauses per-DM auto-replies when the account owner sends a manual outgoing message.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
