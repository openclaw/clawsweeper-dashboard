## Summary

Keep open: current main and v2026.6.11 still lack owner/human handoff config or per-DM pause state, and the linked implementation attempt is closed unmerged prior art.

## What This Changes

The issue requests an opt-in owner/human handoff that pauses DM auto-replies when manual outgoing owner messages are detected, especially for WhatsApp personal-number use.

## Best Possible Solution

Define a plugin-owned handoff contract, likely WhatsApp-first unless maintainers choose a shared channel API, then implement per-account/per-conversation pause and resume semantics with schema, docs, focused tests, and live transport proof.
