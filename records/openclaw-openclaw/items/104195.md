## What This Changes

  - body: The reported path is an ordinary 30-second request timeout on a still-open Gateway connection, but this controller is aborted only when the WebSocket closes.   - confidence: 1
- **[P1] Remove the per-request close listener:** `src/gateway/server/ws-connection/message-handler.ts:2668-2672`
  - body: Every request adds a `once("close")` listener, including requests that complete normally, and nothing removes it when `dispatch` settles. A long-lived connection retains one closure per completed request until disconnect and can exceed listener limits or grow memory. Detach the listener during dispatch cleanup or use a connection-owned cancellation fanout.
  - confidence: 0.99
