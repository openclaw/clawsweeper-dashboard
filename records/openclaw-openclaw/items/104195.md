## Summary

## What This Changes

The PR propagates an optional abort signal from each Gateway WebSocket request into plugin-backed node invocation policy so disconnected requests cannot dispatch approved work later.

## Best Possible Solution

Add a backward-compatible per-request cancel or deadline path, expire already-aborted approvals immediately, and use one authoritative pending-to-effecting transition before node transport dispatch.
