## Summary

Keep open: current main still learns a Telegram forum topic name as `TopicName` but does not propagate it through the generic `ThreadLabel` session-label path, and the open linked implementation candidate at https://github.com/openclaw/openclaw/pull/96793 explicitly addresses that remaining gap. This issue remains the canonical tracker until that PR is reviewed and merged or replaced.

## What This Changes

Add human-readable Telegram forum-topic names to session-selector labels while retaining the parent group/forum label.

## Best Possible Solution

Review and land a narrow Telegram-plugin change that assigns known forum `topicName` to the existing generic `ThreadLabel` while preserving `ConversationLabel` for the parent forum, with focused regression coverage for session metadata and selector rendering.
