## Summary

Keep open: current main still exposes learned Telegram forum titles only as `TopicName`, while the generic session display path requires `ThreadLabel`; open pull request https://github.com/openclaw/openclaw/pull/96793 owns the focused remaining implementation.

## What This Changes

Add human-readable Telegram forum topic names to session-selection labels instead of showing raw or indistinguishable numeric topic sessions.

## Best Possible Solution

Land one narrow metadata fix that maps a known Telegram forum topic name to generic `ThreadLabel` while preserving the parent group `ConversationLabel`, then demonstrate the resulting human-readable label in a real Telegram session selector.
