## Summary

The open closing pull request remains the focused implementation candidate, so this canonical issue should stay open until that pull request is landed or replaced.

## What This Changes

## Best Possible Solution

Land or replace the focused pull request so Telegram supplies its learned topic name through the existing supplemental thread-label contract, with regression coverage and redacted live session-selector proof.
