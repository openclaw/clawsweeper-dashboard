## Summary

Keep open. Current main still learns Telegram forum topic names as `TopicName`, but it does not propagate the value as generic `ThreadLabel`/session display metadata, and the open closing PR is the current repair candidate.

## What This Changes

Request to show known Telegram forum topic names instead of raw numeric topic identifiers in Telegram session dropdown labels.

## Best Possible Solution

Land or close https://github.com/openclaw/openclaw/pull/96793; the desired end state is a generic `ThreadLabel`/session-display path populated from known Telegram forum topic names while preserving the parent group label.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: current main learns `TopicName` for Telegram forum topics but does not set `ThreadLabel`, while session rows and the Control UI selector consume labels/display names before falling back to parsed keys.

## Solution Assessment

Yes. The narrow maintainable direction is to reuse the existing Telegram topic-name cache and generic `ThreadLabel` metadata rather than adding Telegram-specific UI formatting or a new config field.
