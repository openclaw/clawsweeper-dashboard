## Summary

Keep open: current main still learns Telegram forum topic names without passing them into the generic session display-label field, and the open closing pull request remains the active candidate fix rather than an implemented change.

## What This Changes

Surface known Telegram forum topic names as generic thread labels so session selectors can distinguish topics while retaining the parent group label.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/96793 after live Telegram selector proof confirms that known topic names become session display names without replacing the parent group label or changing routing.
