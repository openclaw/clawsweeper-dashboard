## Summary

The latest head fixes the prior same-shell `cd`/`stat` concern, but the generated plan still exits before producing its ENOENT sentinel when the anchored parent is absent, so `stat()` throws for one ordinary missing-path case. The PR should remain open for a focused correction and proof matching the final generated command.

## What This Changes

Changes sandbox filesystem `stat` handling to use an exit-code-2 ENOENT sentinel with `LC_ALL=C`, plus focused bridge tests for missing-file and generic-error outcomes.

## Best Possible Solution

Use one anchored shell operation that preserves the same-shell directory context while mapping both missing leaf and missing parent states to the structured ENOENT result, propagates permission and I/O failures, and is covered by a test that executes the generated plan plus matching terminal or container proof.
