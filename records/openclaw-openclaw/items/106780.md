## Summary

The locale bug remains present on current main, so this PR is still useful, but the current head introduces a missing-parent regression: `stat("missing-dir/file")` now exits at `cd` before the ENOENT sentinel logic and throws instead of returning `null`. The focused repair is mechanical, after which the security-sensitive sandbox path still needs its normal CODEOWNERS review.

Likely related people: `openclaw/openclaw-secops` (high confidence; required sandbox-path reviewer), `steipete` (high confidence; repeated sandbox/security history), and `davidbors-snyk` (medium confidence; original filesystem-bridge implementation).

## What This Changes

This PR pins sandbox `stat` diagnostics to the C locale, maps its ENOENT diagnostic to an exit-code-2/stdout sentinel, recognizes that sentinel in the filesystem bridge, and adds focused tests.

## Best Possible Solution

Preserve canonical-parent anchoring while classifying C-locale ENOENT from both the parent-change and `stat` stages, retain propagation of permission and I/O failures, and cover an absent-parent target with a regression test.
