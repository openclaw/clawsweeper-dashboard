## Summary

Keep this PR open: the locale-independent ENOENT direction is sound, but the unchanged head still throws when the requested file and its anchored parent directory are both absent, so the existing null-on-missing contract is not fully preserved.

## What This Changes

Pins sandbox `stat` diagnostics to the C locale, translates recognized ENOENT failures into an exit-code-2/stdout sentinel, updates bridge handling, and adds focused tests.

## Best Possible Solution

Make ENOENT classification cover both a missing leaf and a missing anchored parent without weakening anchored path safety, then add regression coverage for nested missing paths and retain propagation of permission and I/O failures.

## Solution Assessment
