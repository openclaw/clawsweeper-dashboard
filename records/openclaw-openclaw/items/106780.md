## Label Justifications

## Summary

Keep open: the current head retains both previously reported P1 blockers—a predictable temporary-file redirection inside the sandbox and an overbroad parent-error match—and the submitted Docker transcript does not exercise the actual bridge or those adversarial cases.

## What This Changes

Changes sandbox stat handling to emit and consume an exit-code-2 `ENOENT` sentinel under `LC_ALL=C`, with focused mocked error-path tests.

## Best Possible Solution

Keep the sentinel contract and same-shell anchoring, but capture parent stderr without a predictable persistent file, match only the diagnostic reason suffix, and add generated-plan plus bridge-level Docker coverage for localized ENOENT, non-ENOENT parent failures, crafted operands, and temporary-file safety.
