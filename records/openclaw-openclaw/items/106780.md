## What This Changes

The PR changes sandbox file-stat missing-path detection to use a shell-generated `ENOENT` sentinel and adds mocked regression tests for missing and non-ENOENT results.

Keep the anchored single-target stat flow, classify ENOENT through a directly verified mechanism—such as a controlled C-locale diagnostic or an errno-aware helper guaranteed by supported sandbox images—and execute that real command in GNU and BusyBox coverage instead of inferring errno through `find`.
