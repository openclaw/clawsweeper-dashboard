## Summary

Keep open: the current head still classifies `stat` failures by matching an English diagnostic without enforcing the C locale, so localized sandbox environments can still hit the original exception path.

## What This Changes

The PR adds a shell-level ENOENT sentinel for sandbox `stat` failures, maps that sentinel to `null`, and adds mocked regression tests.

## Best Possible Solution

Set `LC_ALL=C` on the actual `stat` invocation, retain explicit sentinel handling for ENOENT, and prove both localized missing-path behavior and a non-ENOENT failure through the real sandbox command path.
