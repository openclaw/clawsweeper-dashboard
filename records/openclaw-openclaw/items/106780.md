## Summary

Keep open: the locale-dependent failure is valid, but the current head still misclassifies a non-ENOENT stat failure when the operand itself contains the matched English phrase; the remaining repair is narrow and mechanical.

## What This Changes

Pins sandbox stat execution to the C locale, maps recognized missing-file diagnostics to an ENOENT sentinel, updates bridge handling, and adds anchored-operation regression tests.

## Best Possible Solution

Keep the C-locale sentinel design, but match only a terminal ENOENT diagnostic that cannot be satisfied by operand text, with coverage for both localized missing paths and a misleading-filename non-ENOENT failure.
