## Summary

Keep open: current main and v2026.6.11 still have the wildcard-only runtime alias generator while the compaction path imports a default-only helper through that alias; the linked open PR remains the focused fix path.

## What This Changes

The issue reports that generated stable runtime aliases use wildcard-only re-exports, dropping default exports and breaking post-compaction bookkeeping.

## Best Possible Solution

Review and land the linked runtime-postbuild fix or an equivalent generator repair that forwards default exports only when the target chunk actually has one.

## Reproduction Assessment

Yes. Current main and v2026.6.11 show wildcard-only generated aliases, a default import through the compaction alias, and a default-only target helper; a Node ESM probe confirms the export contract.

## Solution Assessment

Yes. The best fix boundary is the alias generator because the caller and helper agree on a default export and the generated alias is the layer dropping it.
