The issue requests making Feishu sender attribution and live peer listing work without default organization-wide contact-directory permissions.

## Best Possible Solution

Make Feishu inbound sender attribution contact-free by default, fall back quietly to a stable sender id, and gate contact-backed profile lookup plus live user-directory listing behind explicit operator opt-in with docs and regression tests.
