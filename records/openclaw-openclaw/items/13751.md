## Summary

Keep open: current main and the latest release still default Feishu sender-name lookup to the contact user API, and live user listing still uses the contact directory. The issue remains valid, but the repair changes a security-sensitive Feishu permission/default boundary and overlaps an open maintainer-owned Feishu display-name PR, so it should stay in maintainer review rather than be auto-closed or queued as a competing repair.

## What This Changes

Request to make Feishu basic sender-name resolution and live user-directory behavior stop depending on organization-wide contact-directory permission by default.

## Best Possible Solution

Make basic inbound Feishu messages contact-free by default, use verified lower-scope metadata or stable sender ids, and require explicit opt-in for contact-backed sender lookup and live user-directory listing with docs and regression coverage.
