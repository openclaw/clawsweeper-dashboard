## Summary

Keep open: current main and v2026.6.11 still default Feishu sender-name resolution to a contact-backed lookup, live peer listing still uses the Feishu contact directory, and the overlapping open Feishu PR is conflicting and does not fully own the contact-free default.

The issue requests making Feishu sender-name resolution and related live directory lookup work without requiring broad organization contact-directory permissions.

## Best Possible Solution

Make default Feishu inbound sender attribution contact-free, fall back quietly to a stable sender id, and require explicit operator opt-in for contact-backed profile lookup and live user-directory listing with docs and regression tests.
