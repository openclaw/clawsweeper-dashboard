## What This Changes

This PR adds busy and stale run-state visibility to channel status, records accepted Discord actions accurately, and sends Discord/Telegram acknowledgements when active work queues or steers an incoming message.

## System Context

Channel adapters report transport and account status to the gateway and CLI status command, while reply admission decides whether an incoming channel message can run immediately, be steered into active work, or be queued. This PR carries active-run facts through the shared status projection and returns a visible acknowledgement for Discord and Telegram when work cannot start immediately.
