## What This Changes

The issue reports that Anthropic replay can strip a NO_REPLY yield-turn separator, merge that assistant turn into the following tool-use assistant turn, and send multiple signed thinking blocks in one provider message.

## Best Possible Solution

Land a maintainer-approved Anthropic replay repair that prevents stripped NO_REPLY yield turns from leaving orphaned signed-thinking blocks that can merge into the next tool-use assistant message, with focused regression coverage and live provider proof when feasible.

## Reproduction Assessment
