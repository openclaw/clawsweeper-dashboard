## What This Changes

Repair long-running Discord DM turns so their visible progress or waiting state remains trustworthy and later inbound messages are processed once the active turn completes, fails, or times out.

## System Context

Discord direct messages enter the Gateway and are bound to an agent session queue; the running turn emits progress to Discord while the session lifecycle decides whether queued inbound messages may run. The channel-visible typing/draft state and the final reply should accurately reflect the same terminal outcome that releases the session queue.

## Best Possible Solution

Instrument one long Discord DM turn end-to-end, then repair the proven lifecycle boundary so real turn progress refreshes or replaces expiring Discord status and every terminal path releases queued inbound work with a visible final or failure state.
