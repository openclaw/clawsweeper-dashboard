Keep open: current main still lacks an operator-controlled permission policy for agent-created user-facing files, and the source shows host, workspace, sandbox, apply_patch, and exec write paths do not share a configurable mode or umask boundary.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep private OpenClaw state restrictive, and test host, sandbox, exec, and apply_patch behavior together.
