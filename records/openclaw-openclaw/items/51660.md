Keep open: current main and v2026.6.11 still lack a configurable user-output file-permission policy, and the remaining work is a security-sensitive product/config decision rather than stale cleanup.

## What This Changes

Request to add an opt-in umask or file/directory mode policy for agent-created user-facing files while preserving restrictive permissions for private OpenClaw state.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep private OpenClaw state restrictive, and cover host Write/Edit, apply_patch, sandbox bridge writes, exec-created artifacts, media, docs, and focused regression tests together.
