## Summary

Keep open: current main and v2026.6.11 still lack a permission policy for agent-created user-facing files, and adding one needs maintainer product/security direction because it changes config and local filesystem access boundaries.

## What This Changes

Request an opt-in umask/file-mode policy for agent-created user-facing files such as Write/Edit, apply_patch, sandbox, and exec outputs.

## Best Possible Solution

Define a scoped opt-in user-output permission policy, keep private state/config/credential/session paths restrictive, and cover host Write/Edit, apply_patch, sandbox bridge, exec-created output, docs, and regression proof together.
