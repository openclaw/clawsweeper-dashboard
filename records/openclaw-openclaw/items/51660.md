## Summary

Keep open: current main and the latest release still lack an operator-controlled permission policy for agent-created user-facing files, and the remaining work is a security-sensitive product/config decision rather than conservative cleanup.

## What This Changes

Request to add configurable umask or explicit file and directory modes for agent-created user-facing files while preserving restrictive handling for private OpenClaw state.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep restrictive defaults for private OpenClaw state, and test host, sandbox, apply_patch, and exec-created output together.
