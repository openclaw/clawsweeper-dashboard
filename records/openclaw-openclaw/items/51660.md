## Summary

Keep open: current main and v2026.6.11 still do not provide a configurable permission policy for agent-created user-facing files, and the remaining work is a product/security boundary decision rather than conservative cleanup.

## What This Changes

The issue requests configurable umask or explicit file and directory modes for agent-created user-facing files in Docker, NAS, and shared-host deployments.

## Best Possible Solution

Define a narrow opt-in user-output file permission policy for agent-created artifacts, keep OpenClaw private state restrictive, and document/test every supported write path including host Write/Edit, apply_patch, sandbox bridge, exec outputs, and media.
