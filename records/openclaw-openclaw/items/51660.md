## Summary

Keep open: current main still lacks any configurable user-output file permission policy, and the remaining work needs maintainer product/security direction because it would add config surface across agent write paths.

## What This Changes

Request an opt-in umask or file/directory mode policy for agent-created user-facing files so Docker/NAS/shared-host deployments can make outputs group-writable without external chmod jobs.

## Best Possible Solution

Define a scoped opt-in user-output permission policy that excludes private OpenClaw state, documents the supported Docker/NAS/shared-host model, and covers host Write/Edit, apply_patch, sandbox bridge, exec outputs, and managed media consistently.
