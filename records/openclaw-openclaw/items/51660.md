## Summary

Keep open: current main and v2026.6.11 still do not expose a user-output file-permission policy, and the request remains a valid but security-sensitive config/product decision rather than conservative cleanup.

## What This Changes

Add a configurable user-output umask or file-mode policy for files and directories created by agent tools without changing private OpenClaw state permissions.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep private OpenClaw state restrictive, and cover host, workspace, sandbox, apply_patch, exec/media behavior, docs, and regression tests together.
