## Summary

Keep open: current main and v2026.6.11 still lack a configurable permission policy for agent-created user-facing files, and the remaining work is a security-sensitive product/config decision rather than conservative cleanup.

## What This Changes

The issue requests a configurable umask or file/directory mode policy for agent-created user-facing workspace outputs without relaxing internal sensitive files.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep private OpenClaw state restrictive, and cover host Write/Edit, apply_patch, sandbox bridge, exec-created output, docs, and regression proof together.
