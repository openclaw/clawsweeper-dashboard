## Summary

Keep open: current main and the latest release still lack a scoped permission policy for agent-created user-facing files, and the remaining work is a security-sensitive config/product decision rather than conservative cleanup.

## What This Changes

Request a configurable umask or file/directory mode policy for user-facing files created by agent tools such as exec, write, edit, and apply_patch.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep private OpenClaw state restrictive, and cover host tools, apply_patch, sandbox bridge writes, exec-created output, media, docs, and regression proof together.

- **Document external ownership:** Decline core config and document host umask, ACL, group, or container-user setup as the supported operator path.
