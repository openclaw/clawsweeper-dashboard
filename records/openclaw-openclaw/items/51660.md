## Summary

Keep open: current main and v2026.6.11 still lack a configurable permission policy for agent-created user-facing output, and the remaining work is a security-sensitive product/config decision rather than conservative cleanup.

## What This Changes

Requests a configurable tools-level umask or file/dir mode policy for agent-created user-facing files in shared Docker/NAS environments.

## Best Possible Solution

Define an opt-in user-output filesystem permission policy at the tools/runtime boundary, keep private OpenClaw state restrictive, and cover host write/edit, apply_patch, sandbox bridge, exec-created output guidance, docs, and regression proof together.
