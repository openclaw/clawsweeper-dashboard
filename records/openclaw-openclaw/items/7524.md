## Summary

Current main and the latest release still isolate group peers, while an open linked PR now implements the focused request. The issue remains necessary until maintainers choose the configuration and trust-boundary contract and then review or close that implementation.

## What This Changes

Add an opt-in global or per-binding group session scope that routes selected group conversations into the agent’s main session.

## Best Possible Solution

Keep group isolation as the unchanged default and, if maintainers accept the trust model, expose an explicit per-binding trusted-peer opt-in with clear warnings and consistent inbound, outbound, queue, thread, sandbox, schema, and documentation behavior; avoid a global fold-all-groups default unless that broader policy is deliberately approved.
