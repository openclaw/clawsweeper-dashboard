## Label Justifications

- `P2`: This is a bounded but optional session-routing enhancement with meaningful design and trust implications, not an active runtime outage.
- `impact:session-state`: The requested configuration changes which inbound conversations share an agent transcript and queue identity.
- `impact:security`: Opting a group into the main session changes the context-exposure boundary between group participants and private direct-message history.

## Summary

Keep this issue open: current main still isolates non-direct peers, and the linked open PR is the concrete implementation candidate, but maintainers must decide whether group-to-main routing is acceptable only for explicit trusted bindings or also as a global default.

## What This Changes

Add an opt-in `session.groupScope` and per-binding override so selected group chats can share an agent’s main session instead of receiving isolated group session keys.

## Best Possible Solution

Land one documented, backward-compatible session-routing contract only after maintainers choose the trust boundary; prefer an explicit per-binding peer opt-in with inbound/outbound symmetry, regression tests for isolation defaults, and clear warnings that the group shares main-session context.
