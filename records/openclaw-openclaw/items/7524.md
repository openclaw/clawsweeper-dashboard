## Summary

Current main and v2026.6.11 still isolate non-direct peers and expose only DM-specific scoping, while the directly linked implementation PR remains open and unmerged; keep this focused issue open for maintainer product/security review and resolution through that PR.

## What This Changes

Add isolated-by-default global and per-binding group session scoping so selected trusted groups can share the agent main session.

## Best Possible Solution

Land one canonical isolated-by-default contract through the linked PR only after maintainers approve the boundary: exact binding overrides should take precedence over the global default, non-direct peer kinds must be defined, outbound replies must preserve the originating destination, and docs/security audit guidance must warn that merged group content becomes main-session context.
