## Summary

Keep this issue open: current main still isolates group and channel peers, while the linked implementation remains open and requires an explicit decision about the configuration shape and the trust boundary created by sharing a group with the private main session.

## What This Changes

Add an opt-in global or per-conversation session scope that routes selected group chats into an agent's main session instead of an isolated group session.

## Best Possible Solution

Keep group isolation as the default and add a narrowly explicit binding-level opt-in to the main or a named shared session, with prominent trust warnings and cross-channel regression coverage for routing, delivery, serialization, threads, memory, and sandbox behavior.
