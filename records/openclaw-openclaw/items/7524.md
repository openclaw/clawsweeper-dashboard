## Summary

Keep open: current main and v2026.6.11 still only support DM-specific session scoping, strict config cannot express group-to-main routing, and the linked implementation candidate is open, conflicting, and unmerged.

## What This Changes

The issue requests an additive `groupScope`-style session routing option so selected group chats can share the agent main session instead of always using isolated group sessions.

## Best Possible Solution

Keep this focused tracker open until https://github.com/openclaw/openclaw/pull/91702 or an equivalent opt-in group-to-main contract lands with inbound/outbound parity, strict schemas/types/help/docs, security guidance, and regression coverage.

## Reproduction Assessment

Yes, at source level. Current main deterministically derives isolated keys for non-direct peers and the strict schemas cannot express a group-to-main option.

## Solution Assessment

Unclear as a final product path. `groupScope` is a plausible additive direction with an open implementation PR, but maintainers still need to settle config scope, security posture, proof, and PR readiness before this issue can close.
