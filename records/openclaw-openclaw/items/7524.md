## Summary

Keep this issue open: current main still isolates non-direct peers and the linked open implementation PR is the concrete candidate, but maintainers must first confirm the opt-in trust boundary and permanent configuration shape for folding a group into a private main session.

## What This Changes

The issue requests an opt-in `groupScope` configuration that routes selected group chats into an agent’s main session instead of always isolating them.

## Best Possible Solution

Sponsor a narrowly opt-in, default-isolated group-to-main contract only if maintainers accept that trust boundary; then land it with inbound/outbound routing, strict schema/type/docs, and regression coverage while leaving broader named shared-session groups to https://github.com/openclaw/openclaw/issues/19929.
