## Summary

Current main and v2026.6.11 still isolate groups and rooms from the main session. The open linked implementation keeps this issue necessary, but maintainers must choose the privacy and sandbox boundary before accepting its configuration contract.

## What This Changes

Add an opt-in configuration that routes selected group or channel conversations into an agent’s main session instead of isolated peer sessions.

## Best Possible Solution

Keep isolated group sessions as the default and add an explicit trusted-binding route-to-main contract with security warnings and end-to-end routing, queue, outbound-delivery, and sandbox coverage.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should trusted group or channel bindings be allowed to join the main session, and should that capability be per-binding only or also available as a global session default?

Rationale: Joining main changes transcript visibility, queue serialization, outbound routing, and the documented non-main sandbox/tool boundary, so permanent configuration semantics require maintainer intent.

Likely owner: steipete

Owner reason: The strongest history signal spans session-key routing, route resolution, and the user-facing session and group security documentation.

Owner confidence: high

Options:

- **Per-binding opt-in only (recommended):** Allow an explicitly matched trusted binding to route to main while preserving isolated behavior everywhere else and omitting a global collapse switch.
- **Global plus binding overrides:** Accept the linked PR’s broader model after documenting the security implications and proving global defaults, override precedence, and upgrades.
- **Keep groups isolated:** Reject group-to-main routing and use cross-session history, search, memory, or the broader shared-session design instead.

## Reproduction Assessment

Not applicable as a bug reproduction; current source-facing documentation provides high-confidence evidence that groups and rooms still use isolated non-main sessions.

## Solution Assessment

Unclear pending maintainer direction; a per-binding trusted opt-in is safer and more maintainable than making group-to-main routing available as a broad global default.
