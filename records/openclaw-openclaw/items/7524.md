Keep this issue open: the linked implementation PR remains open and explicitly uses closing syntax for this issue, so it is an implementation candidate rather than a reason to close before merge. ## What This Changes

Add an opt-in group-session scope so selected group chats can share an agent’s main session instead of always using isolated group session keys.

## Best Possible Solution

Land one explicitly opt-in, backwards-compatible session-routing contract only after maintainers approve the group-to-main trust boundary; preserve isolated groups by default, document the exposure, and cover inbound plus outbound routing and override precedence.
