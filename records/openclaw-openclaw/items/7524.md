## Summary

Current main and v2026.6.11 still isolate non-direct peers, and the open linked implementation remains conflicting and unresolved. Keep this issue open while maintainers choose the privacy boundary and review the candidate PR.

## What This Changes

Add an opt-in global and per-binding session setting that routes selected group conversations into an agent’s main session.

## Best Possible Solution

Adopt a narrowly scoped trusted-conversation opt-in, preferably per-binding only, with isolated defaults, inbound/outbound parity, security-audit warnings, privacy documentation, and redacted live proof before landing the linked PR.

## Solution Assessment

No, the global-plus-binding proposal is not yet proven to be the best permanent contract; per-binding-only better matches the trusted-group use case and reduces privacy blast radius unless maintainers explicitly choose broader behavior.
