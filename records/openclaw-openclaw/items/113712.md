## What This Changes

This PR replaces Control UI chat’s single detail sidebar with persistent, resizable columns for dashboard chat, message details, and Session Discussion that can be tabbed or dragged independently.

## System Context

Control UI’s chat page combines the selected session transcript with transient message details, Session Discussion, and an optional Workboard dashboard chat dock. The new layout model converts those surfaces into per-session persisted sidebar columns before rendering the chat workspace.
