## What This Changes

This PR replaces Control UI chat’s single detail sidebar with persistent, resizable columns for dashboard chat, message details, and Session Discussion that users can tab or drag independently.

## System Context

Control UI chat combines the primary conversation with transient message details, Session Discussion, and optional dashboard chat. This change stores a sidebar-column layout by canonical session and gateway scope, then renders those panels as persistent columns or a narrow tabbed region.
