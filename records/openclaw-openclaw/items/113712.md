This PR replaces the Control UI chat’s single sidebar with independently resizable, tab-capable Chat, Details, and Session Discussion columns that persist per session.

## System Context

Control UI chat combines the conversation, message-detail tools, Session Discussion, and optional Workboard dashboard. The changed layout layer maps session state and persisted UI preferences into draggable, resizable sidebar columns around that chat surface.
