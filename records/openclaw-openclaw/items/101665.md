## What This Changes

Adds a yield-only control to plugin tool results, exposes `yieldToolResult(...)`, applies controls after result-finalization hooks, and routes embedded sessions through the existing turn-yield lifecycle.

## Best Possible Solution

Adopt the control only with explicit owner approval, keep it yield-only and host-owned, preserve finalized results across every supported execution path, and retain the documented explicit error for runtimes without a handler.
