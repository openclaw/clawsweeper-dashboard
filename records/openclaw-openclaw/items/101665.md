## Summary

Keep this PR open: the latest head resolves the prior parallel-sibling scheduling blocker, but the public documentation omits the required sequential tool declaration, and maintainers still need to accept the permanent Plugin SDK scheduling contract.

## What This Changes

The PR adds a result-level yield control to the Plugin SDK, applies it after tool-result finalization, and maps it to embedded session turn handoff.

## Best Possible Solution

Accept the post-finalization result-control design as the narrow host-owned seam, then document and demonstrate the mandatory sequential tool declaration before landing it.
