## What This Changes

Prevent ordinary memory-wiki supplement searches from performing an uncancelled exhaustive Markdown scan after digest candidates underfill the requested result count.

## Best Possible Solution

Forward an optional AbortSignal through the corpus-supplement contract, make wiki enumeration and page reads abort-aware, and disable exhaustive backfill for ordinary supplement recall while retaining exhaustive body scanning for explicit wiki_search.
