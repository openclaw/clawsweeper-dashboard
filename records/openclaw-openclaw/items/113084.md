## What This Changes

The PR projects existing run, usage, and session-lifecycle events into persistent elapsed-time/output-token telemetry and a completed-turn recap across Control UI, shared iOS/macOS chat, and Android chat.

## System Context

Gateway chat events describe a run’s activity, token usage, and terminal state; each client keeps local chat state and turns those events into transcript rows. This PR changes that client-side projection so active work remains visible during streaming and a terminal summary persists until the next turn.
