## Summary

Keep this PR open for revision: it addresses a source-reproducible plugin registration failure, but the branch contradicts existing gate tests, lacks real runtime proof, and needs maintainer confirmation of the permanent plugin-state trust boundary.

## What This Changes

The branch allows plugins with global or workspace origins to use the three `api.runtime.state` storage helpers and adds a new origin-gate test file.

## Best Possible Solution

Define one maintainer-approved state-capability rule—preferably tied to explicit activation or validated trust rather than an expanding origin allowlist—then apply it consistently to bundled, managed, global, workspace, and configured load-path plugins with updated contract tests and documentation.
