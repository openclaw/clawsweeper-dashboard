## Summary

The core blocker-lifetime change is directionally correct, but detached background sessions lose the sandbox cleanup error that changes a successful process into a failed final outcome; the PR also supplies only test evidence for a real lifecycle change.

## What This Changes

The PR keeps background exec lifecycle admission active until sandbox finalization settles, delays terminal state and notification until then, and rejects process-control actions during finalization.

## Best Possible Solution

Keep the single suspension-safe finalization path, but commit the complete final outcome—including cleanup diagnostics—to canonical session and finished metadata before the one terminal transition and notification.
