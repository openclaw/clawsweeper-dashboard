## What This Changes

The PR moves scheduled outbound-delivery ownership, retry fencing, completion receipts, and attachment custody from process-local handling into the existing SQLite delivery queue to prevent duplicate, lost, or falsely acknowledged sends.

## System Context

Cron and other producers create outbound delivery intents, which are persisted in the shared SQLite queue before channel providers send messages or attachments. Recovery workers later reconcile queued entries and terminal receipts so gateway restarts and competing producers do not change the recipient-visible delivery result.
