## Summary

Keep open; the previous self-recursion blocker still applies at the unchanged PR head, so this hardening should not merge until the global hook candidate is checked against the repository hook.

## What This Changes

The PR modifies `git-hooks/pre-commit` to run an executable global `core.hooksPath` pre-commit hook before the repo's staged-file formatting flow.

## Best Possible Solution

Keep the global-hook chaining idea only after resolving the candidate hook and skipping it when it is the same executable as the repo-local hook, with focused coverage for a relative global `hooksPath`.
