- `merge-risk: 🚨 compatibility`: Existing contributors with relative or same-file global hooksPath values can have their local commit workflow broken by the new hook chain.

## Summary

Keep open: the prior self-recursion blocker is still present at the same PR head, because a relative or matching global hooksPath can point back to this repo hook and recurse before the local formatter flow.

## What This Changes

This PR makes `git-hooks/pre-commit` read global `core.hooksPath` and invoke an executable global `pre-commit` before the existing staged-file formatting flow.

## Best Possible Solution

Resolve the configured global hook and the current repo hook to canonical paths, skip the global call when they are the same executable, and add focused coverage for the relative/same-file hooksPath case before merge.
