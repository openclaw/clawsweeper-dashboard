## Summary

The PR is narrow and useful, but it still needs changes before merge because the added global-hook chaining can invoke the same repository hook recursively before OpenClaw's existing staged-file checks run.

## What This Changes

The PR modifies `git-hooks/pre-commit` to run an executable globally configured `pre-commit` hook before the existing OpenClaw staged-file hook flow.

## Best Possible Solution

Keep the global guard chaining only after resolving and skipping the same hook executable, while preserving the existing repo-local staged-file formatting flow.
