## What This Changes

This PR adds a global `core.hooksPath` pre-commit invocation ahead of the existing repo-local staged-file formatting hook.

## Best Possible Solution

Keep the global-hook chaining idea, but first resolve the candidate hook and skip it when it is the same executable as the repo-local hook, with focused validation for the relative hooksPath case.
