## Summary

Keep this PR open: the useful global-hook chaining idea is still blocked by the same self-recursion defect from the prior ClawSweeper review, and the current head has not changed since that finding.

## What This Changes

The branch adds a global `core.hooksPath` lookup to `git-hooks/pre-commit` and invokes an executable global `pre-commit` hook before the existing staged-file formatter flow.

## Best Possible Solution

Keep the global-hook chaining only after resolving the candidate hook and this repository's hook, skipping the global call when both point to the same executable, with focused coverage for a relative global `core.hooksPath` case.
