## Summary

Keep open: the head is unchanged since the prior ClawSweeper review, and the added global hook path can still recurse into this repository's hook when a relative global `core.hooksPath` resolves to the worktree.

## What This Changes

The PR updates `git-hooks/pre-commit` to invoke an executable globally configured `pre-commit` hook before the existing project staged-file flow.

## Best Possible Solution

Keep the global-hook chaining idea only after resolving the candidate hook and skipping it when it is the same executable as the repo-local hook, with focused coverage for a relative global hooksPath case.
