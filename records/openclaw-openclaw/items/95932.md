## Summary

Keep open: the prior same-file recursion blocker is still present on the current PR head and in the potential merge result, so this useful hook-hardening change is not merge-ready yet.

## What This Changes

The PR changes `git-hooks/pre-commit` to invoke an executable globally configured `pre-commit` hook before the existing staged-file checks.

## Best Possible Solution

Keep the global-hook chaining idea only after resolving the candidate hook and skipping it when it is the same executable as the repo-local hook, with focused hook coverage for that case.
