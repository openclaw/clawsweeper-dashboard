## Summary

Keep this PR open, but it still needs the same-file recursion guard from the prior ClawSweeper review before merge. The branch adds a useful local security-hardening idea, but current source and Git's hook-path contract show that a relative global `core.hooksPath=git-hooks` can resolve back to this repository's own hook and recurse.

## What This Changes

The PR changes `git-hooks/pre-commit` to run an executable globally configured `pre-commit` hook before the existing OpenClaw staged-file formatting flow.

## Best Possible Solution

Keep the global-hook chaining behavior only after resolving the configured global hook and skipping it when it is the same executable as this repository's hook, with focused coverage for the relative `core.hooksPath=git-hooks` case.
