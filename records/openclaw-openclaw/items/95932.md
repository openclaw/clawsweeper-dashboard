- `merge-risk: 🚨 compatibility`: Existing contributors with relative or same-file global `core.hooksPath` values can have local commits broken by the new hook chain.

## Summary

Keep open: the hook-hardening idea is useful, but the current branch still has the prior blocking defect because a globally configured hook can resolve to the same `git-hooks/pre-commit` file and recurse before the existing staged-file flow runs.

## What This Changes

The branch adds a global `core.hooksPath` pre-commit invocation to `git-hooks/pre-commit` before the existing staged-file formatting flow.

## Best Possible Solution

Resolve the configured global candidate and the current hook to canonical paths, skip the global call when they point to the same executable, and keep focused coverage for a relative global `hooksPath` plus the normal formatting path.
