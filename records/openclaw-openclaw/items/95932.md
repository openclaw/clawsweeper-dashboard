- `P3`: This is a local developer hook hardening PR with limited blast radius and no OpenClaw runtime product impact.
- `merge-risk: 🚨 compatibility`: Existing contributors with relative or same-file global hooksPath values can have their local commit workflow broken by the new hook chain.
- `merge-risk: 🚨 availability`: The same-file hook case can repeatedly invoke the hook and stall local pre-commit execution before formatting runs.

## Summary

Keep open: the PR still adds the global pre-commit invocation without guarding against the configured global hook resolving to this same repo hook, so the previous self-recursion blocker remains at the current head.

## What This Changes

The PR changes `git-hooks/pre-commit` to read global `core.hooksPath` and run an executable global `pre-commit` hook before the existing OpenClaw staged-file formatting flow.

## Best Possible Solution

Resolve the configured global hook candidate and the current repo hook path, skip the global call when they are the same executable, and add focused temp-repo coverage for the relative `core.hooksPath=git-hooks` case.
