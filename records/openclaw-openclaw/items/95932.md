## Summary

Keep this PR open with changes required: the previous self-recursion blocker is still present at the current head, so the global hook chain can call this same pre-commit hook before reaching the existing staged-file flow.

## What This Changes

The branch adds a `git-hooks/pre-commit` block that reads global `core.hooksPath` and invokes its executable `pre-commit` before the repo-local staged-file flow.

## Best Possible Solution

Keep the global-hook chaining idea only after resolving the configured global hook and the current repo hook to comparable paths, skipping the call when they are the same executable, and validating the relative/same-file case against current main.
