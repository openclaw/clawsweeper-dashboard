## Summary

The PR is still necessary but not merge-ready: it adds useful global pre-commit chaining, yet the current head still lacks the same-hook guard from the prior review, so a global `core.hooksPath` that resolves to this repository's `git-hooks/pre-commit` can recurse before OpenClaw's checks run.

## What This Changes

The PR changes `git-hooks/pre-commit` to run an executable globally configured `pre-commit` hook before the existing OpenClaw staged-file lint and format flow.

## Best Possible Solution

Keep the global-hook chaining idea, but resolve the candidate global hook and current project hook before invocation and skip the global call when they point to the same executable, with focused validation for missing, non-executable, distinct, and same-target global hooks.
