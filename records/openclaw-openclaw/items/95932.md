## Summary

Keep open: the useful hardening idea is still blocked because the current PR head can chain `git-hooks/pre-commit` into itself when the global hook path resolves to the same repo hook.

## What This Changes

The PR adds a global `core.hooksPath` pre-commit invocation before the repo-local staged-file formatting flow in `git-hooks/pre-commit`.

## Best Possible Solution

Keep the global-hook chaining only after resolving the candidate global hook and current repo hook to canonical paths, skipping the chain when they are the same file, with focused validation for both the relative same-file case and a normal external global hook.
