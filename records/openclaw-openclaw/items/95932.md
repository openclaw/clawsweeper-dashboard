## Summary

Keep open: the unchanged PR head still adds global hook execution without guarding the same-file case, and current main does not already implement this global pre-commit chaining safely.

## What This Changes

The PR changes `git-hooks/pre-commit` to run an executable globally configured `pre-commit` hook before the existing repo-local staged-file formatting flow.

## Best Possible Solution

Keep the global-hook chaining only after resolving both the configured global hook candidate and the current repo hook, skipping the call when they point to the same executable, and covering the relative `core.hooksPath` case.
