- `merge-risk: 🚨 compatibility`: Existing contributors with relative or same-file global hooksPath values can have their local commit workflow broken by the new hook chain.

## Summary

Keep open: the global-hook chaining idea is useful, but the current head still has the prior same-file recursion blocker, so it is not merge-ready.

## What This Changes

The branch adds a global `core.hooksPath` lookup to `git-hooks/pre-commit` and invokes that global `pre-commit` hook before OpenClaw's staged-file flow.

## Best Possible Solution

Keep the global-hook chaining only after resolving the global candidate and the current repo hook to canonical paths, skipping the global call when they point to the same executable.
