## Summary

Keep this PR open: the global-hook chaining idea is still unique and not implemented on current main, but the previous same-file recursion blocker is still present at the current head.

## What This Changes

## Best Possible Solution

Keep the global-hook chaining only after rebasing onto the current hook and adding a same-file resolution guard plus focused coverage for a relative global `core.hooksPath`.
