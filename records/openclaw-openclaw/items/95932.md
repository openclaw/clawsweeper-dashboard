## Label Justifications

- `merge-risk: 🚨 compatibility`: Existing contributors with relative or same-file global hooksPath values can have their local commit workflow broken by the new hook chain.
- `merge-risk: 🚨 availability`: The same-file hook case can repeatedly invoke the hook and stall pre-commit execution before OpenClaw's formatter flow runs.

## Summary

Keep open: the previous self-recursion blocker is still present on the current head, and the PR needs a same-file guard before this security hardening can safely merge.

## What This Changes

The PR adds a global `core.hooksPath` lookup and invokes its `pre-commit` hook before the existing repo-local pre-commit flow.

## Best Possible Solution

The repo hook should chain a distinct executable global pre-commit guard while preserving current staged-file behavior and skipping paths that resolve to the same hook.
