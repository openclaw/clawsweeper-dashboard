## What This Changes

Routes native-command replies in bundled Discord, Mattermost, Slack, and Telegram plugins through the shared channel-turn lifecycle so outbound reply hooks run once per logical payload.

## System Context

Bundled channel plugins receive native commands and dispatch agent replies through provider-specific delivery adapters. The shared channel-turn lifecycle records inbound session context, applies outbound hooks, and tracks whether delivery became visible before each provider sends its reply.
