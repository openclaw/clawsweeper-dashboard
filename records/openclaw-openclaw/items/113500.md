## What This Changes

Routes Discord, Mattermost, Slack, and Telegram native-command replies through the shared inbound channel-turn lifecycle so outbound hooks, cancellation, session recording, and provider delivery are coordinated once per logical reply.

## System Context

Bundled channel plugins turn native commands into agent reply payloads, then hand those payloads to the shared channel-turn lifecycle. That lifecycle records session context, applies outbound hooks, and delegates the final visible message to the channel provider.
