## What This Changes

Routes bundled Discord, Mattermost, Slack, and Telegram native-command replies through the shared channel-turn lifecycle so outbound hooks run once per logical payload and cancelled replies do not produce false delivery completion.

## System Context

Channel plugins translate native commands into an inbound turn, while the shared channel-turn kernel records session context, runs outbound hooks, and delegates visible delivery back to the provider. This change moves four bundled command paths into that shared lifecycle and adds a record-target override for Telegram's distinct command and target sessions.
