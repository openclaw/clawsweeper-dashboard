## Label Justifications

- `P0`: The issue reports repeated malformed persisted `openclaw.sqlite` state, CLI unavailability, gateway degradation, and restore-from-backup recovery.
- `impact:data-loss`: The affected persisted SQLite state can become malformed, requiring restoration from an older backup snapshot.
- `impact:session-state`: The shared state DB backs runtime/plugin state used by agent and channel workflows, and malformed reads broke plugin-state access while the gateway kept running.
- `maturity:stable`: The affected gateway health/status/stability surface maps to `gateway-runtime`, which is scored M4 Stable in `qa/maturity-scores.yaml`.

## Summary

Keep open: current main and the latest stable release still expose mutable shared-state SQLite open/checkpoint paths from CLI/status/diagnostic surfaces, while the merged related PRs only cover adjacent WAL durability and handle-lifecycle issues.

## What This Changes

Issue #101290 reports repeated `openclaw.sqlite` corruption after routine health/status/stability CLI invocations touched the live shared state DB while the gateway was running.

## Best Possible Solution

Make status, health, and stability prefer running-gateway RPC, and ensure any CLI fallback file access while the gateway owns the state DB is read-only and no-maintenance with an explicit maintainer-approved lease or maintenance-mode policy for repair writes.

Owner confidence: high

Options:

- **RPC-first plus no-maintenance CLI (recommended):** Route health/status/stability through the running gateway first and make fallback file opens read-only with no journal, checkpoint, or doctor-migration side effects while a gateway is active.
- **Gateway single-writer lease:** Have the gateway own the state DB write/maintenance lease and make non-gateway processes fail closed or route through gateway APIs for writes and maintenance.
- **Forensic harness before implementation:** Pause code changes until the reporter's corrupt DB bundle and a native runtime harness identify the exact OpenClaw helper/runtime interaction.

## Solution Assessment
