## What This Changes

The PR reuses a compatible lifecycle-owned plugin metadata snapshot for plugin loading and facade manifest resolution, while preserving rediscovery for custom profiles, activation-source load paths, and explicit discovery overrides.

## System Context

OpenClaw’s plugin loader turns configuration, workspace scope, environment, and installed-plugin records into a discovery generation that later loads plugin modules. Gateway and facade callers consume that discovery metadata for channel catalogs, plugin status, and runtime resolution, so reusing it must preserve the scope and activation boundaries that decide which plugins are visible.
