## What This Changes

The PR validates ClawHub GitHub skill install resolver commits as full immutable SHAs before download and records the normalized commit in install metadata.

## Best Possible Solution

Keep the immutable-commit guard and merge after maintainer acceptance that the documented ClawHub GitHub resolver contract is full-SHA-only for all compatible registries.

## Reproduction Assessment

Yes. Current main passes `latestResolution.github.commit` directly from unvalidated resolver JSON into both the GitHub codeload download and install metadata path, so a branch-like value can reach the fetch path.

## Solution Assessment

Yes, subject to maintainer compatibility acceptance. Reusing the existing 40-hex commit normalizer at the resolver-to-download boundary is the narrowest maintainable fix and aligns installation with the existing verified-provenance display path.
