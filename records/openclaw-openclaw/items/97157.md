## Summary

Keep open: current main still passes the ClawHub resolver commit directly into GitHub codeload and install metadata, while this PR fixes that path with focused tests and sufficient CLI proof. The remaining blocker is maintainer acceptance of the intentional compatibility break for custom ClawHub-compatible registries that return branch names, tags, or short SHAs.

## What This Changes

The PR validates GitHub-backed ClawHub skill install resolver commits as full immutable SHAs before codeload download and stores the normalized SHA in install metadata.

## Best Possible Solution

Merge this patch after maintainers confirm that the documented full-SHA resolver contract should apply to every ClawHub-compatible GitHub install source.
