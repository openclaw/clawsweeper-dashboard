## Summary

This PR remains necessary because current `main` accepts mutable GitHub refs for a resolution that it records as immutable. The exact-head patch matches the official ClawHub pinned-commit contract, has convincing CLI proof, and has no actionable correctness or security findings; it should stay open for normal maintainer merge handling.

## What This Changes

The PR validates successful ClawHub GitHub resolutions as normalized full 40-hex commit SHAs before download and adds positive and negative lifecycle tests.

## Best Possible Solution

Land the resolver-boundary validation so every GitHub-backed ClawHub install uses one normalized full commit SHA for download, policy, provenance, lock metadata, and telemetry, while archive and explicitly mutable direct-git installs remain unchanged.
