## What This Changes

The PR rejects mutable or invalid GitHub refs returned by the ClawHub install resolver and propagates one normalized full commit SHA through download and install metadata.

## Best Possible Solution

Land the single acceptance-boundary validation so download, policy, provenance, lock, and telemetry always consume one canonical immutable commit, while retaining the clear error for nonconforming custom registries.
