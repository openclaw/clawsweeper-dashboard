## Summary

This PR has focused real-process proof and no newly supported correctness defect, but it intentionally changes a previously unbounded local workflow-check contract into a fixed five-minute hard failure. Keep it open for an explicit maintainer decision on whether that deadline is acceptable for legitimate slow actionlint, Go fallback, and pre-commit bootstrap runs.

## What This Changes

The branch gives each external command used by the local workflow-sanity script a fixed five-minute timeout, terminates stalled processes by platform, reports the timed-out command, and adds regression coverage and script declarations.

## System Context

The workflow-sanity script runs local external validators before repository workflow checks, including actionlint and fallback/bootstrap commands. Its subprocess results determine whether a developer or CI run completes successfully or fails with a diagnostic.

## Best Possible Solution

Keep bounded termination and its platform-specific proof, but merge only after the scripts owner explicitly accepts five minutes as the supported maximum for all existing workflow-check subprocesses or narrows the policy to avoid rejecting legitimate slow runs.
