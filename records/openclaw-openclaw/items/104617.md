## Summary

The latest head resolves both prior review blockers: active and pinned sessions remain in the bounded window, and the long-list browser scenario expands pagination before full-list assertions. The implementation is otherwise coherent and well-proven, but one edge case leaves a permanently ineffective See less control when more than thirty rows are required because they are pinned or active.

## What This Changes

This PR limits the Control UI sidebar to ten sessions initially, adds ten-row See more pagination and a See less collapse action, and updates styles, localization artifacts, component tests, and browser coverage.

## Best Possible Solution

Keep the shared required-row limiter, but derive See less availability from whether the numeric page limit was actually expanded, then retain focused coverage for active, pinned, grouped, selected, and drag-managed rows.
