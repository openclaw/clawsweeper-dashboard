## Summary

This maintainer-owned draft should remain open. The pagination approach is reasonable, but the unchanged head still has the previously reported partial-page contraction bug: after revealing a non-multiple-of-ten final page, See less subtracts from the partial total rather than returning to the prior page boundary.

## What This Changes

This PR adds ten-session incremental pagination controls to the Control UI sidebar, with styles, generated localization updates, and focused component and mocked browser coverage.

## Best Possible Solution

Keep pagination capacity aligned to ten-session pages, clamp only the rendered slice to the available total, and add 31- or 35-session regression coverage without changing grouping, sorting, drag, or agent-selection behavior.

## Solution Assessment

No in its current form; incremental disclosure is a suitable and narrow solution, but the stored pagination capacity must remain independent of the partial final-page render count.
