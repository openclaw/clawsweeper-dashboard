## Summary

The feature remains useful, but the current decrement logic mishandles partial final pages: after revealing all 31 or 35 sessions, See less drops to 21 or 25 instead of the preceding 30-session boundary. The PR should stay open for this focused correction; its draft, behind-main, and protected maintainer states are workflow context rather than close reasons.

## What This Changes

The PR paginates Control UI sidebar sessions in batches of ten and adds See more/See less controls, styles, generated locale updates, and focused component and E2E coverage.

## Best Possible Solution

Keep page capacity on ten-session boundaries while clamping only the rendered row slice to the available total, then add regression cases for 31 and 35 sessions without changing grouping, sorting, drag, agent-selection, or i18n behavior.
