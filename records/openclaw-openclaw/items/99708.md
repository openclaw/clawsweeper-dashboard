## Summary

Keep open: current main and the latest release still route the preserved human Notes block through a string replacement, and two open linked PRs are candidate fixes that should be reviewed or landed before the issue closes.

## What This Changes

The issue asks to preserve user-authored memory-wiki ChatGPT import Notes byte-for-byte when they contain JavaScript `$` replacement sequences.

## Best Possible Solution

Review and land one of the linked focused fixes, then close this issue from the merged PR after the literal-replacement change and regression test are on main.

## Reproduction Assessment

Yes from source inspection: current main feeds the preserved human Notes block into `String.prototype.replace` as a string replacement, which makes `$` sequences replacement patterns. I did not run the reproducer because this review is read-only and tests can write artifacts, but the path is direct.

## Solution Assessment

Yes: the narrow maintainable fix is to insert the preserved block literally via a replacer callback and add a ChatGPT re-import regression for `$$`, `$&`, `$`` and `$'`. The two open linked PRs already implement that shape and should be reviewed against each other.
