## What This Changes

The issue reports memory-wiki ChatGPT re-import corrupting user-authored Notes that contain JavaScript replacement-pattern dollar sequences.

## Best Possible Solution

Review and land one narrow PR that inserts the preserved ChatGPT human block literally and adds a re-import regression for `$$`, `$&`, `$`` and `$'` Notes text.

## Reproduction Assessment

Yes, at source level: current main passes the preserved human block into a string replacement, and a focused probe shows the reported dollar sequences are expanded instead of preserved. I did not run the full importer in this read-only review.

## Solution Assessment

Yes, the best fix is the narrow literal-insertion change in the ChatGPT import preservation helper plus a regression that drives the real re-import path. Because open PRs already target this issue, the next step is maintainer review of those PRs, not another queued repair.
