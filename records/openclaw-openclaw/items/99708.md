## What This Changes

Track a memory-wiki ChatGPT re-import bug where preserved human Notes containing JavaScript replacement-pattern dollar sequences can be corrupted.

## Best Possible Solution

Land one of the open narrow fixes that inserts the preserved human block literally and adds a ChatGPT re-import regression, then close this issue once main contains the fix.

## Reproduction Assessment

Yes, at source level: current main still passes the preserved user-authored human Notes block as the string replacement argument to `String.prototype.replace`. The issue body also provides concrete import, edit, re-import steps and before/after output.

## Solution Assessment

Yes. The best fix is the narrow owner-local change to insert `params.replacement` literally, using a replacer callback or equivalent slice-based replacement, plus a regression that drives the ChatGPT re-import path with `$$`, `$&`, `$`` and `$'`.
