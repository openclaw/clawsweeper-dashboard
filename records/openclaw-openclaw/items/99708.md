## What This Changes

The issue reports memory-wiki ChatGPT re-import corrupting preserved human Notes text containing JavaScript replacement-pattern dollar sequences.

## Best Possible Solution

Review and land one of the linked fix PRs with a ChatGPT re-import regression, then let the closing reference resolve this issue after merge.

## Reproduction Assessment

Yes, source-reproducible: current main extracts the existing human Notes block and passes it to a regex replace as the string replacement. A focused Node probe confirms the reported `$` replacement tokens corrupt literal user text.

## Solution Assessment

Yes, the narrow maintainable fix is to insert the preserved human block literally, using a replacer function or slice-based replacement, and cover the ChatGPT re-import path with a regression. Because two open PRs already close this issue, the issue itself should stay open until one lands.
