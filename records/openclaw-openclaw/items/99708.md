## Summary

Keep open: current main and the latest release still pass the preserved memory-wiki ChatGPT Notes block to a string replacement, so dollar sequences can corrupt user-authored Notes; two open focused PRs now own the fix path and the issue should close only after one merges.

## What This Changes

Fix ChatGPT re-import so memory-wiki preserves user-authored Notes containing JavaScript replacement-pattern dollar sequences.

## Best Possible Solution

Merge one of the open focused PRs that inserts preserved human blocks literally and adds a ChatGPT re-import regression, then close the issue.

## Reproduction Assessment

Yes, source-level reproduction is high confidence: current main passes the extracted human Notes block into a string replacement, and a focused Node probe shows the reported dollar sequences are expanded. I did not run the full importer in this read-only review.

## Solution Assessment

Yes. The narrow maintainable fix is to make the existing ChatGPT managed-block helper insert `params.replacement` literally, with a regression that drives ChatGPT re-import after Notes contain `$$`, `$&`, `$`` and `$'`.
