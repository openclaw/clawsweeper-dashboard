## Summary

Keep open: current main and the latest release still use a string replacement for the preserved ChatGPT human Notes block, so `$` replacement sequences can corrupt user text; two open PRs now close this issue and should be reviewed rather than starting another repair lane.

## What This Changes

The issue requests that memory-wiki ChatGPT re-import preserve user-authored `## Notes` blocks containing JavaScript `$` replacement sequences byte-for-byte.

## Best Possible Solution

Review and land exactly one of the open candidate PRs, then close this issue once current main contains the literal Notes-preservation fix.

## Reproduction Assessment

Yes, at source level. Current main routes the extracted human Notes block into a string replacement, and a focused probe plus linked PR proof show the reported dollar sequences are expanded instead of preserved.

## Solution Assessment

Yes. The best fix is the narrow helper change already proposed by the open PRs: insert the extracted human block literally with a replacer callback or equivalent slice-based replacement and keep the ChatGPT re-import regression.
