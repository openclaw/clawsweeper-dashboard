## What This Changes

This PR replaces the 4,502-line Control UI chat-pane implementation with focused inherited modules and a dependency barrel while retaining `chat-pane.ts` as the public custom-element entrypoint.

## System Context

The Control UI chat pane receives Gateway snapshots and browser interactions, keeps selected-session and connection state, then renders chat, history, boards, sharing, and header controls. This refactor divides that central UI coordinator into ownership-focused modules without intending to change the Gateway or user-facing chat behavior.
