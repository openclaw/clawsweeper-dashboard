## Summary

Keep open: current main and v2026.6.11 still let the native macOS app return a literal `${OPENCLAW_GATEWAY_TOKEN}` before LaunchAgent fallback and encode it into the dashboard URL. Several linked PRs are open, but none has merged, so this issue remains the canonical report.

## What This Changes

The issue requests that the macOS app stop using unresolved gateway auth env placeholders in dashboard URLs and provide a recoverable token-resolution path.

## Best Possible Solution

Land one canonical native macOS resolver fix that follows the existing SecretRef grammar, falls through to LaunchAgent-resolved local credentials when the app env cannot resolve them, and shows an in-app recovery or Doctor path when no usable token can be found.
