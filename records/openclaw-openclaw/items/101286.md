## Summary

Keep open: current main and the latest shipped release still return a non-empty local `gateway.auth.token` before consulting the LaunchAgent token, so the reported macOS dashboard lockout remains source-reproducible. Several linked PRs are candidate fixes, but none has merged yet, so this issue should stay open until one canonical fix lands.

## What This Changes

The issue reports that the macOS app can build a dashboard URL with a literal unresolved `${OPENCLAW_GATEWAY_TOKEN}` fragment when the real token is only available to the gateway LaunchAgent, locking users out of the dashboard and Settings UI.

## Best Possible Solution

Land one canonical native macOS resolver fix that follows the existing SecretRef grammar, falls through to LaunchAgent-resolved local credentials when the app env cannot resolve them, and shows a native actionable recovery path when no usable token can be found.
