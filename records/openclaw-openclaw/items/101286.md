## Summary

Keep open: current main and the latest release still let a non-empty local `gateway.auth.token` win before the macOS LaunchAgent token fallback, so `${OPENCLAW_GATEWAY_TOKEN}` can still become the dashboard fragment token. Several linked PRs are candidate fixes, but none has merged yet.

## What This Changes

The issue reports a macOS dashboard and Settings lockout when `gateway.auth.token` is configured as `${OPENCLAW_GATEWAY_TOKEN}` but that env var is only available to the gateway LaunchAgent, not the GUI app.

## Best Possible Solution

Land one canonical native macOS resolver/recovery fix that treats documented env SecretRef shorthands as unresolved rather than literal dashboard tokens, falls through to LaunchAgent token/password, and shows a clear in-app recovery path when auth cannot resolve.
