## Summary

Keep open: current main and the latest shipped release still return the configured local token before the LaunchAgent fallback, so a literal `${OPENCLAW_GATEWAY_TOKEN}` can still reach the macOS dashboard URL. ## What This Changes

The issue reports that the macOS app can pass an unresolved `${OPENCLAW_GATEWAY_TOKEN}` placeholder into the dashboard URL when the token is only available to the gateway LaunchAgent environment, locking users out of the dashboard and Settings recovery path.

## Best Possible Solution

Land one canonical native macOS resolver fix that mirrors the shared SecretRef grammar, falls through to LaunchAgent-resolved local credentials when app-env resolution fails, and surfaces an actionable native recovery path if no usable credential exists.
