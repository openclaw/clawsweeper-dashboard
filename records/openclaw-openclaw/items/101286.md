## Summary

Keep open: current main and the latest release still prefer the raw local `gateway.auth.token` string before the LaunchAgent credential fallback, so the reported dashboard lockout remains source-reproducible. Several open linked PRs are candidate fixes, but none has merged yet.

## What This Changes

The issue asks the macOS app to avoid passing unresolved gateway-token env placeholders into the dashboard URL and to provide an in-app recovery path.

## Best Possible Solution

Land one canonical native macOS resolver fix that follows the SecretRef grammar, falls through to LaunchAgent-resolved local credentials when app env cannot resolve them, and shows a native actionable recovery path when no usable token exists.
