## Summary

## What This Changes

The issue asks the macOS app dashboard auth path to stop passing unresolved env placeholders as tokens and to provide an in-app recovery path when the token cannot be resolved.

## Best Possible Solution

Land one canonical native macOS resolver fix that follows the existing SecretRef env-shorthand grammar, falls through to LaunchAgent-resolved local credentials when the app env cannot resolve them, preserves literal credential and remote behavior, and shows an actionable native recovery path when no usable token exists.
