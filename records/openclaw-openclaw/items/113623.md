## What This Changes

This PR makes Control UI multi-select session actions defer each row’s canonical session-list refresh and issue one final refresh per affected agent after the batch.

## System Context

The Control UI sidebar turns archive, restore, read-state, and group selections into session patch requests to the Gateway. Gateway change events reconcile rows during a batch, while a canonical session-list refresh reconciles the final sidebar state after the batch finishes.
