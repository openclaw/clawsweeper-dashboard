## Summary

## What This Changes

This PR recognizes Anthropic’s “Extra usage is required for long context requests” 429 as a context overflow so an embedded agent compacts the session and retries instead of using billing or fallback handling.

## System Context

The embedded agent receives provider failures after a model attempt and classifies them into recovery paths. Context-overflow failures use bounded session compaction and retry; after exhaustion, the agent reports a blocked terminal state rather than selecting another model.
