## What This Changes

The branch treats Anthropic’s specific long-context 429 response as context overflow, sending embedded-agent runs through bounded compaction and retry rather than billing/fallback handling.

## System Context

The embedded-agent runtime receives provider errors, classifies them, and selects either compaction recovery or its normal billing/rate-limit handling. This change alters one Anthropic error classification, affecting retry behavior, fallback selection, and the run’s final session state.
