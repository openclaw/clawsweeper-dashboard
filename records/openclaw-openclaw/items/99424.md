## What This Changes

The issue asks OpenClaw to strip `CONDA_PREFIX` from sanitized host subprocess environments the same way `VIRTUAL_ENV` is already stripped.

## Solution Assessment

Yes. Adding `CONDA_PREFIX` to the same shared policy bucket as `VIRTUAL_ENV`, while keeping the generated macOS mirror and regression tests aligned, appears to be the narrowest maintainable fix.
