## What This Changes

The branch imports a bounded, idempotent window of native Pi and OpenCode conversation history into the OpenClaw transcript when a catalog session is adopted.

## System Context

Pi and OpenCode plugins expose native session catalogs that users can continue from OpenClaw. During adoption, the plugins read normalized native transcript items, persist a recent bounded window into the new OpenClaw transcript, then the shared upstream monitor distinguishes those imported rows from new external human turns.
