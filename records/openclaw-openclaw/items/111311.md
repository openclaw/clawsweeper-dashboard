## Summary

Keep this PR open for maintainer review. The connection-time profile snapshot is a coherent continuation of the merged identity/profile work, but it changes newly persisted gateway sender IDs from readable emails to opaque profile IDs without preserving a display fallback when a profile has no name.

## What This Changes

The PR resolves authenticated gateway users to durable profiles at connection setup and propagates the prepared profile identity into presence and gateway user-turn attribution.

## Best Possible Solution

Keep durable profile IDs as the persisted sender key, but preserve a human-readable fallback for unnamed profiles and add an upgrade-focused regression test covering an existing email-identified gateway user.
