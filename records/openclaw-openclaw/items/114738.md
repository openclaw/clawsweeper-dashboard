This PR removes Slack-only inline button/select directive parsing, retires the related root and per-account configuration, and directs users to typed presentation actions with Doctor-based config cleanup.

## System Context

OpenClaw agents and CLI commands produce shared reply payloads that channel plugins render for delivery. The Slack plugin converts typed presentation actions into Slack Block Kit and routes interaction callbacks back into the existing Slack event flow.
