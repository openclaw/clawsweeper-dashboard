  - body: This prior blocker is still present.   - confidence: 0.92
- **[P1] Move emit audit writes off the restart path:** `src/infra/restart.ts:625-630`
  - body: This prior blocker is still present. `process.emit("SIGUSR1")` invokes the run-loop listener, which starts an async IIFE and returns before consuming authorization and calling `request("restart", ...)`; the synchronous SQLite write here can block the event loop before the restart request actually runs. Queue this audit write after the restart handler can proceed, or otherwise prove it cannot delay restart handling.
  - confidence: 0.86
