## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Redact sensitive parent payloads before storage:** `src/infra/restart.ts:371-389`
  - body: A sensitive key is only redacted when its value is a string. If audit metadata contains `authorization: { value: "Bearer ..." }`, `token: { raw: ... }`, or an array of objects under a sensitive key, the sanitizer descends into that payload and can persist raw nested values in `gateway_restart_audit.audit_json` or `preflight_json`. Redact the whole subtree when `keyHint` is sensitive and add object/array regressions.
  - confidence: 0.92
- **[P1] Move emit audit writes off the restart path:** `src/infra/restart.ts:625`
  - body: Late discovery: this line is unchanged since an earlier reviewed head, but the issue is still merge-blocking. `process.emit("SIGUSR1")` invokes the run-loop listener, whose body starts an async IIFE and returns before it consumes authorization and calls `request("restart", ...)`; the synchronous SQLite write here can block the event loop before the restart request actually runs. Queue this audit write after the restart handler has had a chance to proceed, or otherwise prove the DB write cannot delay restart handling.
  - late: true
  - confidence: 0.86
