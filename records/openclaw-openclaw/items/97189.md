## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.84

Full review comments:

- **[P2] Do not let audit writes delay immediate restarts:** `src/infra/restart.ts:1299-1310`
  - body: This scheduled audit write runs synchronously right after arming the timer. For `delayMs: 0` restarts, a busy shared state DB can block inside `runOpenClawStateWriteTransaction` before the event loop can run the timer callback, so the audit row can still delay the actual restart even though the pending state was armed. Please move this write off the restart-critical path or prove a blocking audit writer cannot delay zero-delay restart emission.
  - confidence: 0.87
- **[P2] Thread audit context through config reload restarts:** `src/infra/restart.ts:778`
  - body: The new `auditEvent` support does not cover the existing config-reload caller: `src/gateway/server-reload-handlers.ts` still calls `deferGatewayRestartUntilIdle` without reason/audit context and calls `emitGatewayRestart()` directly for immediate restarts. Those paths will write weak `emit_requested` rows with no source/preflight, leaving the config watcher restart family with the same attribution gap this PR is meant to close.
  - confidence: 0.83
