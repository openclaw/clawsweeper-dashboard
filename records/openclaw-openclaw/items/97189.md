  - body: The previous blocker is still present: a sensitive key only redacts when its value is a string.   - confidence: 0.92

  - body: Late discovery: this line is unchanged since the previous reviewed head, but the issue is still merge-blocking. `process.emit("SIGUSR1")` invokes the run-loop listener, whose body starts an async IIFE and returns before it consumes authorization and calls `request("restart", ...)`; the synchronous SQLite write here can block the event loop before the restart request actually runs, especially under the shared DB busy timeout. Queue this audit write after the restart handler has had a chance to proceed, or otherwise prove the DB write cannot delay restart handling.
  - late: true
  - confidence: 0.86
