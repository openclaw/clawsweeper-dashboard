## Summary

Keep this PR open: the latest head still has a blocking durable-storage privacy defect in the config-reload restart audit path, even though the safe-restart preflight fix and proof improved the branch.

## What This Changes

The PR adds a shared-SQLite `gateway_restart_audit` table and threads restart source, session, and preflight metadata through gateway restart paths with redaction, retention, and tests.

## Best Possible Solution

Persist bounded restart audit rows as metadata-only: strip task titles from every durable audit producer, keep restart-critical paths non-blocking, and land only after maintainer/security acceptance of the table and retention policy.
