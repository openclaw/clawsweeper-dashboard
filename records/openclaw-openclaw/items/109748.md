## Summary

The production change is narrow and matches the credential-detection contract, but the new Vertex and Bedrock regressions inherit unrelated ambient credentials and can fail on machines that already have those variables set. The PR also provides test output rather than after-fix proof from the real provider-selection path, so it is not merge-ready yet.

## What This Changes

The PR trims environment values when detecting configured API keys, Google Vertex ADC settings, and Amazon Bedrock credentials, and adds three regression tests for whitespace-only values.

## Best Possible Solution

Keep the shared trim-based presence checks, isolate every alternate Vertex and Bedrock credential variable in the regressions, and add a redacted runtime probe showing blank values do not select those auth paths while valid credentials still do.
