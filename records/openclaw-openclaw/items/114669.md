## What This Changes

This PR replaces several provider-local OpenAI-compatible reasoning replay normalizers with one plugin-SDK helper, shares Ollama’s native transport/replay hooks, and routes xAI through the existing generic payload wrapper.

## System Context

Provider plugins prepare model-specific stream payloads before OpenClaw sends requests to OpenAI-compatible and native provider transports. The shared replay helper determines whether historical assistant reasoning is retained, removed, or backfilled when tool-call conversations switch among those transports.
