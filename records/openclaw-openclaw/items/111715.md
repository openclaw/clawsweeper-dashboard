## What This Changes

The PR moves iMessage SSH-wrapper remote-host detection into a small helper and expands `~` with the plugin’s canonical home-directory resolver when `HOME` is blank.

## System Context

The iMessage plugin reads its configured CLI wrapper path when monitoring a remote iMessage setup. It expands that path, inspects the wrapper for its SSH destination, and supplies the inferred remote host to the monitor workflow.
