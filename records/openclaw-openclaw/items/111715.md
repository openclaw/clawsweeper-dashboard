## What This Changes

The PR makes iMessage remote-wrapper detection expand `~` from the operating-system account home when `HOME` is explicitly blank or whitespace, then reuses that resolver for the monitor and recovery-cursor paths.

## System Context

The iMessage plugin receives a configured command-wrapper path and may inspect that wrapper to infer a remote SSH host. The shared home-path resolver expands local `~` paths for remote-host detection and for the monitor and recovery cursor’s local Messages database identity.
