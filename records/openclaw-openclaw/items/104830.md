## Summary

This PR remains necessary, but the exact head is unchanged since the prior review and still retains the P1 re-entrant inspection-hook defect; the contributor also provides focused tests and checks rather than real Gateway behavior proof.

## What This Changes

The branch changes restart deferral to treat pending-work inspection failures as unknown active work, retain config-reload deferral state, retry polling, and add regression coverage.

## Best Possible Solution
