## Summary

Keep open: current main still has the reported split between redacted JSON/report output and unredacted terminal/wizard text output, with no duplicate or open fixing PR found.

## What This Changes

The issue asks OpenClaw to apply the existing migration-plan redaction pass before rendering migration preview/apply text output in the CLI and onboarding wizard.

## Best Possible Solution

Apply the existing migration redaction helper once at the text-rendering boundary for preview/result output, then add regression coverage for secret-shaped `message` and `reason` values across CLI formatter and wizard-facing paths.
