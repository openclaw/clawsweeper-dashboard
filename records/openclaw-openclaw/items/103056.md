## Summary

Keep open: current main and the latest release still have divergent migration redaction behavior, with terminal/wizard text rendering raw MigrationItem messages or reasons while JSON and report paths use the redaction helper. This is a narrow security-sensitive bug, but it should be maintainer-promoted because it touches secret-handling output.

## What This Changes

The issue requests consistent redaction for migration preview, confirmation, result, and CLI text output so it matches report.json and --json rendering of the same MigrationPlan.

## Best Possible Solution

Apply the existing redactMigrationPlan path before every migration terminal/wizard preview and result render, then add focused regression coverage for secret-shaped message and reason text on preview, plan, and apply text output.
