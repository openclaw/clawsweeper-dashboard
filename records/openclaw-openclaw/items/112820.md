## What This Changes

Adds `api.runtime.talk.openSession`, allowing Gateway-authenticated plugins to create a realtime voice session that keeps provider credentials and agent/workspace execution inside the Gateway.

## System Context

A plugin page sends microphone PCM to the Plugin SDK runtime, which opens a Gateway-owned Talk session. The Gateway resolves the realtime provider and agent session, coordinates agent consultation and output, then returns owner-scoped audio and lifecycle events to the plugin.
