## What This Changes

This branch adds `api.runtime.talk.openSession`, allowing trusted Gateway-authenticated plugins to send PCM microphone audio through a Gateway-managed realtime provider and receive owner-scoped audio and lifecycle events while agent tools run in the selected workspace.

## System Context

The Plugin SDK gives trusted plugin routes runtime capabilities through the Gateway. This feature takes plugin audio into the Talk relay, where OpenClaw resolves the realtime provider and agent session, then returns audio and state events to the plugin-owned callback.
