## What This Changes

This PR changes OpenClaw’s shared streamed-draft loop so text queued during a background channel edit returns through the configured throttle, while explicit stop/finalization flushes still send the newest text immediately.

## System Context

The shared draft-stream loop receives incremental agent output through channel draft controls and turns it into edit requests for channel transports. Its scheduler determines when background preview updates are sent and how a final draft flush bypasses the normal interval.
