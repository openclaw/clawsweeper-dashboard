## What This Changes

Adds OpenAI Realtime Video Talk to the Control UI with local camera preview, one-frame `describe_view` injection over WebRTC, protocol capability negotiation, camera permission handling, tests, and documentation.

## Best Possible Solution

Declare video-frame support on the OpenAI realtime provider, derive tool registration and Control UI visibility from `talk.catalog`, retain explicit session consent and a visible local preview, and land only after a redacted live OpenAI `describe_view` round trip proves the browser-to-provider boundary.
