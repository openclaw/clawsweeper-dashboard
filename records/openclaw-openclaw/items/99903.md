## What This Changes

The issue requests that Control UI WebChat reconnect after brief Android browser backgrounding without prompting again for the gateway token.

## Best Possible Solution

Define and test a mobile-safe Control UI resume path, preferably through paired device/session auth or explicit remember-device behavior, while keeping shared gateway tokens out of durable storage by default.

## Solution Assessment

Unclear until maintainers choose the security boundary. The best direction is not durable localStorage by default; it should be a mobile-safe resume or device/session auth path with Android proof and credential-exposure review.
