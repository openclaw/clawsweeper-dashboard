## Summary

This PR still addresses a live, bounded agent-cancellation gap: it wires the existing session abort signal into compaction’s retry sleep so cancellation does not wait through a 500 ms–5 s retry delay. The supplied current-head CI, real loopback-HTTP regression, prior proof review, and narrow runtime change support keeping it open for normal maintainer landing; no actionable patch defect is established. The branch is behind `main`, so merge readiness should be refreshed against the actual landing result.

## What This Changes

The PR makes transcript-compaction summary retries interrupt their backoff immediately when the owning session is cancelled, adding focused and production-path loopback HTTP regression coverage.

## System Context

Agent compaction summarizes earlier conversation messages through a model request when a session approaches its context limit. Transient model failures enter a retry loop; session cancellation must interrupt both an active request and the interval before the next retry so compaction can stop without altering the source history.
