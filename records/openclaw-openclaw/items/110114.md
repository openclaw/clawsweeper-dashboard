## Summary

## What This Changes

This PR makes transcript-compaction summary retries stop their backoff delay promptly when the owning session is cancelled, with a regression test for the mid-backoff path.

## System Context

Agent compaction turns long session transcripts into summaries through model calls. When a model call is retryable, the retry scheduler waits before trying again; this change carries the session cancellation signal into that wait so cancelled sessions return promptly without another summary request.
