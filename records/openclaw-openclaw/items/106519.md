## Summary

The patch is technically sound and still necessary: current `main` leaves the WebSocket upgrade unbounded, while the proposed transport-level timeout follows the upstream `ws` contract and preserves successful connections. No blocking correctness or security finding remains, and the final-head real-socket proof is sufficient for normal maintainer merge handling.

## What This Changes

The PR applies a shared 30-second handshake timeout to Codex app-server TCP and Unix WebSocket transports, guards error forwarding when no listener exists, and adds stalled-handshake regression and real-socket proof coverage.

## Best Possible Solution

Keep one Codex-owned WebSocket options builder that applies the 30-second handshake bound to both TCP and Unix upgrades while preserving healthy round trips and the transport error-then-exit contract.
