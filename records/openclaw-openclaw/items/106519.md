## Summary

No blocking correctness finding remains: the transport-layer fix is well scoped, regression-tested, and backed by real-socket proof. Keep the PR open for a maintainer to accept the intentional fixed 30-second availability cutoff and refresh the behind branch before merge.

## What This Changes

The PR applies a shared 30-second WebSocket handshake timeout to Codex app-server TCP and Unix transports, guards unhandled error re-emission, and adds stalled-peer regression plus real-socket proof coverage.

## Best Possible Solution

Keep one transport-owned handshake bound shared by TCP and Unix, preserve exit-driven request rejection, and land it after maintainers confirm that 30 seconds is the intended fixed availability policy.
