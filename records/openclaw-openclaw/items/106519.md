## What This Changes

Adds a fixed 30-second opening-handshake timeout to Codex app-server TCP and Unix WebSocket transports, adjusts unobserved transport-error handling, and adds stalled-handshake regression coverage.

## Best Possible Solution

Keep one transport-owned handshake deadline shared by TCP and Unix, then prove normal connections to a real Codex app-server on both modes plus the stalled-upgrade failure through a withholding proxy before landing.
