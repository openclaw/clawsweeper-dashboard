## Summary

Keep open for a Codex owner to accept the compatibility tradeoff. The implementation is correct and well proven, but a fixed timeout and revised error/exit semantics intentionally change the transport contract in a way CI cannot authorize.

## What This Changes

The PR adds a 30-second WebSocket opening-handshake timeout for Codex TCP and Unix transports, conditionally forwards transport errors, and adds stalled-peer regression coverage plus live-socket proof.

## Best Possible Solution

Adopt a private transport-level handshake bound with one owner-confirmed duration, avoid adding configuration, and retain focused TCP and Unix-path regression coverage.
