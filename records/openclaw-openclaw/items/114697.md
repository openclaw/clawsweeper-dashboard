## What This Changes

The branch removes unrecoverable model rows from OpenClaw-generated SQLite model catalogs before startup loads them, preventing repeated missing-transport-metadata validation failures.

## System Context

Plugin-generated model catalogs are persisted in each agent’s SQLite database and read during startup to populate the model registry. That registry feeds gateway and CLI model selection, so a malformed generated cache entry can affect discovery of otherwise valid models.
