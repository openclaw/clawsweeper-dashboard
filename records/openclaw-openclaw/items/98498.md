## Summary

Keep open: current main and the latest release support per-message Telegram `silent` delivery and `silentErrorReplies`, but they do not provide the requested global, account, or group default for all outbound Telegram messages. This is a plausible Telegram plugin feature, but it adds config/default policy and needs maintainer direction before implementation.

## What This Changes

Request a Telegram config option to make outbound Telegram messages silent by default, with optional account/group overrides and per-message opt-out.

## Best Possible Solution
