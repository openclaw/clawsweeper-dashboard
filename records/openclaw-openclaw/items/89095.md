## Summary

Keep open: current main has the merged wait-layer timeout race fix, but the issue was explicitly reopened because no-deliverable-payload subagent completions can still fail delivery and leave yielded parents without a terminal wakeup. ## What This Changes

The issue asks OpenClaw to notify a parent session when a sub-agent terminates without delivering a completion event, including timeout and no-output completion paths.

## Best Possible Solution

Land or replace the complementary delivery-layer fix so yielded parents receive a bounded terminal notice for no-deliverable-payload completions, with focused tests and live parent-wakeup proof.
