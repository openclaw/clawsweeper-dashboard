## Label Justifications

- `P1`: The bug can leave a yielded parent session parked without a terminal subagent completion event, breaking real agent workflows.
- `impact:session-state`: A child run can reach terminal state while the parent session lacks the corresponding completion state and remains waiting.

## Summary

Keep open: the wait-layer hard-timeout race is fixed on current main by https://github.com/openclaw/openclaw/pull/89367, but the reported parent-notification problem still remains for clean or timed-out subagents that produce no deliverable payload. Current delivery code still treats those completions as `visible_reply_missing`, and https://github.com/openclaw/openclaw/pull/96189 is the active but not-yet-ready complementary work.

## What This Changes

The issue requests a parent-visible terminal notification when a subagent timeout or no-output completion would otherwise be silently dropped while the parent is waiting.

## Best Possible Solution

Keep the landed wait-layer fix, then land or replace the complementary delivery-layer change so no-payload clean or timed-out subagent completions wake yielded parents exactly once with a bounded redacted terminal notice.
