## Summary

Keep open: current main fixed the wait-layer timeout snapshot race, but the reopened issue still has a source-backed remaining failure in the announce-delivery path where no-output subagent completions are treated as undeliverable and can leave a yielded parent without the promised terminal notice.

## What This Changes

The issue requests that timed-out or otherwise no-output subagent completions still notify the parent session instead of silently dropping the completion event.

## Best Possible Solution

Keep this umbrella open until https://github.com/openclaw/openclaw/pull/96189, or a narrower replacement, lands the no-deliverable-payload parent wake path with focused tests and live yielded-parent proof.
