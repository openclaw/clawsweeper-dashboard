## Summary

Keep open: current main has the wait-layer timeout race fix from the merged follow-up, but the central parent-notification problem remains in the announce-delivery path for clean or timed-out subagents with no deliverable payload, and an active delivery-layer PR still needs maintainer review and proof.

## What This Changes

The issue asks OpenClaw to notify the parent session when a sub-agent times out or otherwise completes without a deliverable completion payload instead of silently dropping the completion event.

## Best Possible Solution

Keep this umbrella open while maintainers review, repair, or replace the active delivery-layer fix so no-output subagent completions wake yielded parents exactly once with a bounded terminal notice and live parent-wakeup proof.
