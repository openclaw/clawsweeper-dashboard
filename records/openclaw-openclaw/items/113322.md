## What This Changes

The PR stops ordinary Gateway snapshots from replacing the active Control UI session’s assistant identity with the configured fallback, while retaining fallback reset when the logical connection changes.

## System Context

The Control UI receives Gateway snapshots and stores connection state plus the assistant identity displayed for the active chat session. Session-specific identity is loaded separately, and this snapshot handler decides when the UI should preserve it or revert to configured identity defaults.

## Best Possible Solution

Keep session identity as the authoritative UI value across ordinary snapshots, reset it only at the verified connection boundary, and add visible split-view evidence plus focused coverage for both preserve and reset/reload paths.
