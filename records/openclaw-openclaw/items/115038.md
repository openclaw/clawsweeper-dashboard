## What This Changes

The branch classifies WebSocket upgrade headers more strictly so malformed or unsupported upgrade claims receive an HTTP `400 Bad Request` response instead of being left without a response.

## System Context

The gateway HTTP server handles ordinary HTTP requests while Node's upgrade event routes WebSocket handshakes to the WebSocket server. This request-stage guard decides whether an upgrade-shaped request stays on the HTTP path for an error response or is left to the WebSocket upgrade path.
