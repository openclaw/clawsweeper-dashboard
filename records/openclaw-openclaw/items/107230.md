## Summary

The intended LINE over-activation fix is valid and the live proof is convincing, but the patch still replaces a shared ingress command fact with the precise detector for every group message. That fact also controls whether `CommandAuthorized` is computed, so mentioned group messages containing inline directives can lose authorization metadata; the prior P1 finding remains unresolved on the unchanged production diff.

## What This Changes

The PR changes LINE groups to use registered-command detection for mention bypass, retains broad inline-token detection for direct messages, and adds regression tests plus redacted live LINE evidence.

## Best Possible Solution

Separate the broad “compute command authorization” fact from the precise “may bypass requireMention” fact in the shared ingress and LINE wiring, then independently cover unmentioned chatter, registered commands, and mentioned inline directives.
