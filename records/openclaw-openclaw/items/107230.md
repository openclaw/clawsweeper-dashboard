## Summary

Keep open: the reported LINE over-activation is valid and the real behavior proof is strong, but the current patch conflates mention-bypass detection with command-authorization candidate detection and can silently disable inline directives in mentioned group messages.

## What This Changes

The PR makes LINE groups use registered control-command detection for mention bypass while retaining broad inline-token authorization detection for direct messages, with focused regression coverage.

## Best Possible Solution

Carry two separate facts through LINE ingress: use broad inline-token detection only to decide whether command authorization must be computed, and use exact registered-command detection only for group mention bypass; cover unmentioned chatter, leading commands, and mentioned inline directives independently.
