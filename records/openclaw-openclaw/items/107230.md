## Summary

The real LINE proof convincingly demonstrates the over-activation bug, but the prior P1 remains unresolved on the same reviewed head: the patch reuses precise command detection for the shared ingress command gate, so valid group messages containing authorized inline directives can lose `CommandAuthorized` computation. The PR needs a narrow separation between command-authorization detection and mention-bypass detection before merge.

## What This Changes

The PR changes LINE groups to use registered-command detection for mention bypass while retaining broad inline-token detection for direct messages, and adds focused regression tests.

## Best Possible Solution

Represent coarse authorization-request detection and precise mention-bypass detection as separate shared ingress facts, have LINE groups pass both, and cover plain unmentioned inline text, mentioned authorized inline directives, and standalone registered-command bypass without adding a LINE-only fallback.
