Investigate QQ Bot direct-chat approval callbacks that reject Allow clicks and cause skill_workshop approvals to expire.

## Best Possible Solution

Keep explicit actor authorization as the default, make unauthorized approval prompts fail immediately with actionable in-chat guidance, and add a narrower C2C trust rule only if maintainers define and live-prove an identity binding that cannot broaden approval authority under open DMs.
