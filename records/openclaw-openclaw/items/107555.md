## Summary

Keep this issue open with its paired fix PR: current QQ Bot documentation intentionally requires explicit, non-wildcard authorization for approval buttons, so allowing all direct-chat callbacks is a security-policy change rather than an established bug fix and needs focused maintainer review.

## What This Changes

Change QQ Bot direct-chat approval handling so eligible Allow button clicks resolve plugin approval requests instead of being rejected and timing out.

## Best Possible Solution

Preserve explicit approval authority unless the callback actor can be securely matched to the exact prompt recipient, return an immediate visible unauthorized result instead of waiting for expiration, and cover authorized owner, wildcard open-DM non-owner, group, Allow, and Deny cases with focused tests plus redacted live QQ proof.
