## What This Changes

Resolve QQ Bot plugin approval clicks in direct conversations where users without an explicit non-wildcard approval allowlist currently receive buttons but cannot authorize the request.

## Best Possible Solution

Preserve explicit approval authority, route plugin approval prompts only to a configured QQ approver or owner, and otherwise suppress unusable buttons in favor of clear in-chat setup guidance; prove live that an authorized C2C user succeeds while an open-DM sender cannot self-approve.
