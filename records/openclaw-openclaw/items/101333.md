## Summary

## What This Changes

## Best Possible Solution

Land a validated layered-auth contract that is accepted only for supported token/password modes, is preserved by every Gateway auth config writer, and keeps the existing tokenless Tailscale default unchanged unless the new flag is explicitly enabled.
