## What This Changes

This PR makes `openclaw tasks notify` accept only the existing `done_only`, `state_changes`, and `silent` notification-policy values and adds regression coverage for valid, invalid, and missing arguments.

## System Context

The tasks CLI parses an operator's task lookup and notification policy, then invokes task notification handling through the runtime. This change rejects an unsupported policy during Commander argument parsing so task pre-actions, task-store access, and notification handling do not run.
