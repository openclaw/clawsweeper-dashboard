## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.89

Full review comments:

- **[P1] Gate group-chat quote expansion by sender visibility:** `extensions/msteams/src/monitor-handler/message-handler.ts:609`
  - body: This condition includes group chats, but the fetched body replaces Teams' truncated preview without resolving the quoted message sender. In a `contextVisibility: "allowlist"` group, an allowed sender can quote a non-allowlisted member and this path will send the full Graph-fetched parent body to the agent; restrict this to DMs or fetch `from` and apply the allowlist before substituting `quoteBodyFull`.
  - confidence: 0.87
- **[P2] Remove the unsupported `$select` from chatMessage fetches:** `extensions/msteams/src/graph-thread.ts:131`
  - body: Microsoft's get-chatMessage contract says this endpoint does not support OData query parameters, but the helper calls `/chats/{id}/messages/{id}?$select=id,body`. Tenants that enforce the documented contract will reject the call and always fall back to the truncated preview, so request the message without `$select` and read `body` from the normal response.
  - confidence: 0.78
- **[P2] Export the new helper from graph-thread mocks:** `extensions/msteams/src/monitor-handler/message-handler.ts:36`
  - body: `message-handler.ts` now imports `fetchChatMessageText`, but `message-handler.authz.test.ts` and `message-handler.thread-parent.test.ts` use explicit `vi.mock("../graph-thread.js")` factories that only return the old exports. Those test modules will fail during import until the new helper is included in their mock state/factory.
  - confidence: 0.95
