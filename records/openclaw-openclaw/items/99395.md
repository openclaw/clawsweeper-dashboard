## Summary

Keep open: current main still lacks a top-level requester drain wake for this sessions_yield fan-out case, and the linked open PR is the active closing fix candidate, so the issue should stay open until that PR or an equivalent fix merges.

## What This Changes

The issue reports that a top-level sessions_yield parent that spawned parallel subagents can park after the last child settles because only nested subagent-run records get an all-descendants-settled wake.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/99396, or an equivalent top-level requester-settle wake through the existing announce pipeline, with regression coverage for delivered completions, give-up/suspension, and concurrent last-child settle races.

## Solution Assessment
