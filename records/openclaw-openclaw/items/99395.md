## Summary

Keep open: current main still lacks a top-level requester drain wake for this `sessions_yield` fan-out case, and the open closing PR is the active fix candidate. The issue should close only after https://github.com/openclaw/openclaw/pull/99396 or an equivalent implementation lands.

## What This Changes

The issue reports that top-level sessions using parallel subagents and `sessions_yield` can park permanently after all children settle because no final aggregate wake is delivered.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/99396, or an equivalent top-level requester drain wake through the announce pipeline, then close this issue as implemented.
