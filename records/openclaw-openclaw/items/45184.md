## Summary

Keep open: current main and v2026.6.11 still lack a Matrix-owned gate that skips ambient dispatch when a human message explicitly mentions a different configured Matrix account, and the remaining work needs a product/config decision before implementation.

## What This Changes

Request a Matrix option or mode that lets ambient rooms keep responding to general messages while skipping dispatch when a message explicitly mentions another configured Matrix account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, docs, and handler tests that preserve current ambient-room behavior by default.

Yes. Source inspection shows Matrix resolves mentions only for the current account and, when requireMention is false, proceeds toward dispatch without an other-configured-account mention filter.

## Solution Assessment

Unclear until maintainers choose the config shape. A narrow Matrix plugin gate before typing and dispatch is likely the right layer; a broad AI participation system would be too large for this request.
