## Summary

Keep open: current `main` and `v2026.6.11` still lack a Matrix opt-in gate that suppresses dispatch when a human room message explicitly mentions a different configured Matrix account. The source gap is clear, but the fix adds Matrix routing/config semantics and needs maintainer product direction before an automated fix PR.

## What This Changes

The issue requests an opt-in Matrix routing/config gate that skips LLM dispatch when a room message explicitly mentions a different configured OpenClaw bot account.

## Best Possible Solution

Add a Matrix-owned, default-off `ignoreOtherMentions`-style pre-dispatch gate with schema/docs/tests, sibling-account mention detection, pending-history behavior, and no change to existing default dispatch behavior.
