## Summary

Keep open: current main and v2026.6.11 still lack a Matrix gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account; this remains a useful but compatibility-sensitive config/product decision.

## What This Changes

The issue requests an opt-in Matrix dispatch gate that skips LLM handling when an inbound room message explicitly mentions another configured bot account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema/types/docs/tests and proof that disabled/default ambient behavior is unchanged.
