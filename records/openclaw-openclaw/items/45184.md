## Summary

Keep open: current main still lacks a Matrix opt-in gate that skips dispatch when a human message mentions a different configured Matrix account; the merged Slack work is adjacent but does not implement the Matrix behavior.

## What This Changes

Request an opt-in Matrix policy that lets non-mentioned accounts skip dispatch when a room message explicitly mentions another configured account's bot.

## Best Possible Solution

Add a Matrix-owned, default-off sibling/other-mention gate before typing and LLM dispatch, with schema/types/docs/tests aligned and explicit coordination with outbound sibling mention metadata.
