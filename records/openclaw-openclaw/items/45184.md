## Summary

Keep open: current main and v2026.6.11 still lack a Matrix gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account; this remains a product/config decision rather than a cleanup close.

## What This Changes

Requested behavior: add Matrix dispatch suppression for non-mentioned configured bot accounts when a room message explicitly mentions a different OpenClaw bot account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema/docs/tests and proof that disabled/default ambient behavior is unchanged.
