## Summary

Keep open: current main and v2026.6.11 still lack a Matrix gate that skips ambient dispatch when a human message explicitly mentions a different configured Matrix account; this remains a product/config contract decision rather than a cleanup-close candidate.

## What This Changes

Request an opt-in Matrix dispatch policy that lets ambient room messages proceed unless they explicitly mention a different configured bot account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, docs, and handler tests that preserve current ambient-room behavior by default.
