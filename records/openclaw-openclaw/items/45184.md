## Summary

Keep open: current main still has no Matrix opt-in gate that drops ambient room dispatch when a human message explicitly mentions a different configured Matrix account. The analogous Slack `ignoreOtherMentions` work has now merged, but it is channel-specific and does not implement the Matrix policy requested here.

## What This Changes

Request an opt-in Matrix policy that skips LLM dispatch for non-mentioned Matrix accounts when a room message explicitly mentions another configured account.

## Best Possible Solution

Define a Matrix-owned, default-off other-mention dispatch gate at the plugin boundary before typing and LLM dispatch, with schema, types, docs, and handler coverage that preserves existing ambient-room behavior by default.
