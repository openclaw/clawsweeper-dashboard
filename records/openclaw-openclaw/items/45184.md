## Summary

Keep open: current main and v2026.6.11 still lack a Matrix gate that skips ambient dispatch when a human message explicitly mentions a different configured Matrix account; the remaining work is a product/config contract choice, not a cleanup-close candidate.

## What This Changes

Add an opt-in Matrix policy to skip LLM dispatch when a room message explicitly mentions a different configured Matrix account while this account is otherwise allowed to respond without a mention.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, types, docs, and handler tests that preserve current ambient-room behavior by default.

Yes. Source inspection shows the Matrix handler resolves mentions only for the current account and, when requireMention is false, proceeds toward typing and dispatch with no other-configured-account mention filter.

## Solution Assessment

Unclear until maintainers choose the config shape. A narrow Matrix plugin gate before typing and dispatch is the likely right layer, while a broad AI participation system or default behavior change would be too compatibility-sensitive for an automatic fix.
