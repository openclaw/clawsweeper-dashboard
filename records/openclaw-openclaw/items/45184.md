## Summary

Keep open: current Matrix code and v2026.6.11 still lack a gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account, and the remaining fix needs maintainer approval for the Matrix config/product contract.

## What This Changes

The issue requests an opt-in Matrix dispatch rule that lets ambient room messages through unless they explicitly mention another configured Matrix bot account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, docs, handler tests, and proof that current ambient-room behavior remains the default.

Yes. Source inspection shows Matrix resolves mentions only for the current account and, when requireMention is false, proceeds toward dispatch with no other-configured-account mention filter.

## Solution Assessment

Unclear until maintainers choose the config shape. A narrow Matrix plugin gate before typing and dispatch is the likely right layer; a broad AI participation system would be too large for this request.
