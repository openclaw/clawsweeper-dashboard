## Summary

Keep open: current main and v2026.6.11 still do not provide a Matrix gate that skips a human room message when it explicitly mentions a different configured Matrix account while this bot has `requireMention: false`; the source gap is real, but the fix is a compatibility-sensitive Matrix routing/config product decision.

## What This Changes

Request an opt-in Matrix dispatch gate so non-mentioned bot accounts skip LLM dispatch when a room message explicitly mentions a different configured bot account.

## Best Possible Solution

Add a Matrix-owned opt-in room/account policy that detects explicit Matrix mentions for configured sibling accounts, suppresses non-mentioned accounts before typing/LLM dispatch, preserves the chosen history semantics, and documents/tests the fresh-install and upgrade-safe default behavior.
