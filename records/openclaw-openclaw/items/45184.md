## Summary

Keep open: current main and the latest tagged release still lack a Matrix gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account; the remaining work is a Matrix product/config contract decision, not conservative cleanup.

## What This Changes

Request to add an opt-in Matrix dispatch rule that lets ambient rooms keep `requireMention: false` while skipping LLM dispatch when the message explicitly targets another configured Matrix bot account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, docs, and handler tests that preserve current ambient-room behavior by default.
