## Summary

Keep open: current main and the latest release still lack a Matrix-owned gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account; this remains a product/config contract decision rather than conservative cleanup.

## What This Changes

Request a Matrix option or mode that lets ambient rooms skip LLM dispatch when a message explicitly mentions another OpenClaw Matrix account instead of the current bot.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, docs, and handler tests that preserve current ambient-room behavior by default.

Yes. Source inspection of current main shows Matrix only checks whether the current account was mentioned and only suppresses configured-bot senders, so a human message mentioning another configured account still reaches ambient dispatch when requireMention is false.

## Solution Assessment

Unclear until maintainers choose the config shape. The likely best layer is a narrow Matrix plugin gate before typing and dispatch; a broad AI participation system would be too large for this request.
