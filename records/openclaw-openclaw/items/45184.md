## Summary

Keep open: current main still lacks a Matrix-owned gate that skips ambient dispatch when a human message explicitly mentions a different configured Matrix account, and the remaining work needs maintainer product/API direction before implementation.

## What This Changes

The issue requests an opt-in Matrix dispatch policy that lets always-on room bots ignore messages explicitly addressed to another configured Matrix account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, aligned with Slack/Discord semantics, with schema, docs, handler tests, and proof that current ambient-room behavior remains the default.
