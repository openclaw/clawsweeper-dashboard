## Summary

Keep open: current main and the latest release still lack a Matrix opt-in gate that skips ambient dispatch when a human message explicitly mentions a different configured Matrix account, and the remaining work is a channel/config product decision rather than an already-implemented cleanup.

## What This Changes

The issue requests an opt-in Matrix policy that skips LLM dispatch for non-mentioned accounts when a human message explicitly mentions another configured Matrix account.

## Best Possible Solution

Define a Matrix-plugin-owned, default-off sibling-mention skip policy that runs before typing and LLM dispatch, with schema/types/docs and handler coverage that preserves existing ambient-room behavior by default.
