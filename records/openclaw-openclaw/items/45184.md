## Summary

Keep open: current main and the latest release still lack a Matrix gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account, and the remaining work needs a Matrix config/product decision rather than cleanup closure.

## What This Changes

Requests a Matrix option or exclusive mention mode to skip LLM dispatch for ambient room messages that explicitly mention a different configured Matrix account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention dispatch gate before typing and LLM dispatch, with schema, docs, handler tests, and proof that current ambient-room behavior remains the default.
