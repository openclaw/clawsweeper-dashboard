## Summary

Keep open: current main and the latest release still have no Matrix opt-in gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account. The Slack sibling feature has merged, but it is channel-specific and does not implement the Matrix behavior requested here.

## What This Changes

Requested an opt-in Matrix policy that skips non-target account dispatch when a room message explicitly mentions another configured bot account.

## Best Possible Solution

Add a Matrix-owned, default-off other-configured-account mention gate before typing and LLM dispatch, with schema, types, docs, and handler coverage that preserves current ambient-room behavior by default.

## Solution Assessment

Unclear until maintainers choose the config shape. A narrow Matrix plugin gate before typing and dispatch is the likely right layer, while a broad AI participation system or default behavior change would be too compatibility-sensitive for an automatic fix.
