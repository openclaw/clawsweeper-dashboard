## Summary

Keep open: current main still lacks a Matrix gate that skips ambient dispatch when a human room message explicitly mentions a different configured Matrix account, and the remaining work is a compatibility-sensitive Matrix config/product choice.

## What This Changes

Request an opt-in Matrix room/account policy that suppresses dispatch for non-mentioned bot accounts when a human message explicitly mentions another configured Matrix account.

## Best Possible Solution

Add a Matrix-owned, default-off other-mention gate before typing and LLM dispatch, aligned with Slack/Discord semantics if maintainers choose that config contract, with schema, docs, focused tests, and live Matrix proof.
