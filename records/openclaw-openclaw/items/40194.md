## Summary

Keep open: current main and v2026.6.11 still omit a Feishu bot/account discriminator from durable group session identity, so multiple Feishu bot apps in one group can still share one group session/account boundary.

## What This Changes

The issue reports Feishu same-group multi-bot identity confusion where different mentioned bot apps route through one durable group session.

## Best Possible Solution

Adopt a maintainer-approved Feishu group session identity that includes a stable bot/account boundary, with doctor or migration handling for existing group keys, focused regression tests, and redacted live multi-bot Feishu proof.
