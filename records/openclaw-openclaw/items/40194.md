## Summary

Keep open: current main and the latest checked release still key Feishu group sessions by group/sender/topic without the Feishu account or app identity, so the reported same-group multi-bot identity collision remains source-reproducible and needs maintainer-owned session migration direction.

## What This Changes

The issue asks OpenClaw to prevent multiple Feishu bot accounts in the same group from sharing or confusing group conversation/session identity.

## Best Possible Solution

Define a canonical account/app-scoped Feishu group session identity, add migration or doctor repair for existing group sessions, update docs, and prove multi-bot same-group delivery with live Feishu evidence.
