## Summary

Keep open: current main still routes Feishu group sessions through chat/topic/sender peer ids without a bot account/app discriminator, so the reported multi-bot group identity collision remains a valid session-state, message-routing, and security-boundary issue.

## What This Changes

The issue requests Feishu group session identity isolation so multiple Feishu bot apps in the same group do not share one OpenClaw session/account identity.

## Best Possible Solution

Add maintainer-approved Feishu group session identity that separates bot account/app identity in multi-bot groups while preserving or migrating existing group sessions.
