## Summary

Keep open: current main and latest release still build Feishu group session identity from the group/topic/sender peer, while accountId/appId only influence route matching and direct-message session keys. ## What This Changes

The issue requests Feishu group sessions to distinguish multiple bot apps/accounts in the same group so each mentioned bot keeps the correct identity and context.

## Best Possible Solution
