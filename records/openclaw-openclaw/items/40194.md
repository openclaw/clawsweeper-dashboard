## Label Justifications

## Summary

Keep open: current main and v2026.6.11 still omit a Feishu bot/app/account discriminator from durable group session identity, so the reported multi-bot group session collision remains a valid session, delivery, and security-boundary bug.

## What This Changes

The issue requests Feishu group session identity to distinguish multiple bot applications in the same group.

## Best Possible Solution

Adopt a maintainer-approved Feishu group session identity that includes a stable bot/account boundary, with upgrade-safe doctor or migration handling, regression tests, and live multi-bot Feishu proof.
