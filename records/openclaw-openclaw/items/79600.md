## What This Changes

This PR changes Discord token resolution so a blank `accounts.default.token` on the default account falls through to the top-level token or `DISCORD_BOT_TOKEN`, with added resolver tests for that behavior.

## Best Possible Solution

Use one Discord default-account token-selection rule across runtime, account inspection, setup/status, and tests, with explicit maintainer acceptance of the blank-token compatibility change and redacted live gateway proof.
