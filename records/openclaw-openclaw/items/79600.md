## Summary

Keep open. ## What This Changes

The branch changes Discord token resolution so a blank `accounts.default.token` falls through to top-level or `DISCORD_BOT_TOKEN` fallback, with added resolver unit tests.

## Best Possible Solution

Decide the default-account blank-token compatibility contract, then implement one shared Discord token-state path used by resolver, account inspect, and setup status with upgrade-focused tests and redacted live gateway proof.
