## What This Changes

This PR adds an optional `atomicGate` parameter to native `sessions_spawn` that rejects a child launch unless its resolved model matches an expected value and the child is sandboxed, then returns an admission receipt to the parent.

## System Context

The native subagent spawn tool accepts a parent agent’s request, resolves the child model and launch plan, then starts a child agent session. This change inserts an optional admission decision before dispatch and exposes its result back to the parent agent.

## Architecture Diagram

flowchart LR
  A[Parent agent] --> B[Native sessions_spawn request]
  B --> C[Child launch planning]
  C --> D[Model and sandbox admission check]
  D -->|admitted| E[Child agent dispatch]
  D -->|rejected| F[Forbidden or error result]
  E --> G[Admission receipt to parent]

## Best Possible Solution

Either design this as a host-enforced, narrowly scoped authority capability whose receipt is bound to the actual sandbox filesystem policy and child attempt, or keep the existing spawn contract and expose only clearly labeled diagnostic launch metadata rather than a security assurance.
