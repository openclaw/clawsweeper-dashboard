## Summary

Keep open: the current patch still publishes raw watched-session keys through the global presence snapshot, crossing the existing `operator.read` session-discovery boundary for pairing-only and node recipients; it also still compares global row keys without normalizing the gateway’s scoped subscription key. The shared-gateway direction is useful, but the protected `maintainer` label and privacy-contract choice require human confirmation before repair. ## What This Changes

Adds optional watched-session keys to gateway presence and Control UI facepiles for identified online users and per-session viewers.

## Best Possible Solution

Add a recipient-scoped presence projection that exposes watched-session information only to clients authorized to read each session, normalize global session keys at the UI projection boundary, and attach redacted live shared-gateway proof for both allowed and disallowed recipients.
