## Summary

Keep this PR open: current main still strands finalized results after a failed prompt submission, and this ownership-preserving fix is narrower and safer than making cleanup-owned entries generally steerable. The remaining merge blocker is contributor-supplied proof from a real OpenClaw parent/subagent run rather than a custom harness with a mocked submission boundary.

## What This Changes

The PR clears the cleanup lock when its matching steering lease is released and adds regression coverage for immediate retry of finalized subagent results.

## Best Possible Solution

Rebase this ownership-preserving patch, prove one real parent prompt failure followed by exactly-once next-turn subagent-result delivery, then land it as the canonical fix and close the competing implementation.
