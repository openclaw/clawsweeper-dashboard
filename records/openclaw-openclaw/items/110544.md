## What This Changes

This PR makes Active Memory’s doctor migration read legacy `session-toggles.json` through an 8 MiB bounded reader, reports oversized files without migrating or archiving them, and adds migration coverage.

## System Context

Active Memory’s doctor migration converts legacy per-session opt-out JSON into the plugin’s keyed state store. The migration first previews the old file, then imports valid entries and archives the legacy source, while this change returns a visible warning and preserves sources that exceed the read limit.
