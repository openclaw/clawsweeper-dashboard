## Summary

This PR remains necessary: the current migration path reads the retired Active Memory toggle file without a size bound, while the proposed path caps that legacy read and retains an oversized source with a clear warning. The posted real-module run demonstrates both successful migration below the cap and non-destructive handling above it; no concrete patch defect was established, but maintainers should explicitly accept the upgrade behavior that leaves exceptionally large legacy opt-out files unmigrated until an operator resolves them.

## What This Changes

This PR replaces Active Memory doctor migration’s unbounded legacy toggle-file read with an 8 MiB bounded reader and adds coverage for maximum-size valid input and oversized-source recovery.

## System Context

Active Memory records per-session opt-outs in plugin state. `openclaw doctor` migrates a retired `session-toggles.json` file into that store, then archives the old source only after a successful migration.

## Best Possible Solution
