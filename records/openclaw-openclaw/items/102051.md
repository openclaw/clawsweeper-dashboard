## Summary

Keep open: the linked fallback observability bug is valid, but this patch emits `model.failover` for terminal failures and single-model failures because it does not require a next fallback candidate; it also lacks real behavior proof from a real fallback/exporter run.

## What This Changes

The branch modifies `src/agents/model-fallback.ts` to emit the existing `model.failover` diagnostic event from `observeFailedCandidate` for normal model fallback failures.

## Best Possible Solution

Emit `model.failover` only for actual next-candidate transitions, keep the existing exporter contract, add focused regression coverage for transition and terminal/no-fallback cases, then merge after real behavior proof or maintainer proof override.
