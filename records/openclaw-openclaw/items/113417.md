## What This Changes

The branch rejects invalid, disabled, conflicting, or channel-mismatched explicit channel account IDs before outbound work, and binds Gateway retries to the validated channel/account route so idempotent operations cannot drift after configuration changes.

## System Context

OpenClaw's CLI, agent tool, and Gateway send paths turn a requested channel/account into an outbound provider operation. This change validates caller-supplied account selection before secret scoping and delivery, then retains the validated route for retries and idempotent replay.

## Best Possible Solution

Adopt one documented routing rule: explicit caller account selections must resolve to an enabled account for the selected channel, while omitted selections and host-derived conversation bindings retain their existing default-routing behavior; then merge only after maintainers confirm that upgrade contract and the refreshed merge head passes.
