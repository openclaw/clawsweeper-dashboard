## What This Changes

This PR rejects malformed, unknown, disabled, conflicting, or channel-mismatched explicit account selections before outbound channel actions resolve secrets, targets, media, or provider operations.

## System Context

Outbound actions enter through the agent message tool, CLI command, Gateway, and conversation-delivery paths. Those paths select a channel account before resolving credentials and dispatching the message, so explicit account validation must be consistent while trusted conversation defaults continue to route normally.
