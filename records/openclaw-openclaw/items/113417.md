## What This Changes

This PR makes explicit channel account selections fail when malformed, unknown, disabled, conflicting, or mismatched instead of silently using another configured account, while preserving omitted and host-derived defaults and canonical retry routing.

## System Context

OpenClaw's outbound-message layer receives account hints from the CLI, agent message tools, gateway methods, and channel-specific tools before resolving channel plugins, secret scopes, and provider calls. This PR validates caller-supplied account IDs at those entry points, then carries the selected route into delivery and idempotency handling.
