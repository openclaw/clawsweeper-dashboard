## What This Changes

This PR makes CLI, agent-tool, gateway, broadcast, and Feishu outbound operations reject invalid, disabled, conflicting, or channel-mismatched explicit account selections rather than silently using another configured account.

## System Context

OpenClaw accepts outbound message requests from the CLI, agent message tool, and Gateway, then resolves a channel and account before it loads credentials and sends a provider action. This PR centralizes explicit-account validation and carries the effective route into broadcast secret scoping and idempotency so rejected requests cannot send through a fallback account.
