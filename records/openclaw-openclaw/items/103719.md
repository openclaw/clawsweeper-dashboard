## Summary

This PR targets a valid P1 Google Meet locale bug, but the unchanged current head still has two blocking lifecycle defects: its active-call guard depends on the same English-only detection that fails on localized pages, and recovery navigates tabs before inspecting their state. Focused mocked tests are useful but do not provide the required real Chrome/Meet proof.

## What This Changes

The PR normalizes eligible reused and recovered Google Meet Chrome tabs to English, adds an active-call preflight, adopts navigation-returned target IDs, and expands focused regression tests.

## Best Possible Solution

Use locale-independent signals to inspect active-call state before any navigation in both reuse and recovery, normalize only confirmed non-active tabs, preserve the browser-returned target identity, and demonstrate the complete lifecycle in a real localized Meet session.
