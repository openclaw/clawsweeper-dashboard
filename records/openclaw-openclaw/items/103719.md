## Summary

Green CI does not cover that omitted runtime path, and the PR still lacks live localized Chrome/Meet proof.

## What This Changes

## Best Possible Solution

Use one canonical adopted-tab helper that focuses the tab, forces `hl=en` when appropriate, adopts any navigation-returned target ID, and only then grants permissions or runs DOM automation from join reuse, create reuse, and both recovery transports.
