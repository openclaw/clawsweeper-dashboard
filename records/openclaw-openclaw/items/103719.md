## Summary

This PR remains useful but is not merge-ready: the documented recovery workflow still sends localized tabs directly into English-only DOM evaluation, and the contributor has supplied mocked tests rather than after-fix live Chrome/Meet proof.

## What This Changes

The PR navigates initially reused Google Meet Chrome tabs to an English-language URL in join and create flows, adopts navigation-returned target IDs, and adds mocked regression tests.

## Best Possible Solution

Use one canonical existing-tab adoption path across join reuse, create reuse, local recovery, and node recovery that focuses the tab, navigates to `hl=en` only when needed, adopts the returned tab and target ID, and only then grants permissions or runs DOM automation.
