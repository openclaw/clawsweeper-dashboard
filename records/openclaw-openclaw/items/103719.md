## Summary

This PR takes a reasonable normalization approach for reused join and create tabs, but it remains incomplete: both recovery entry points can still select a localized tab and run English-only Meet automation against it. The linked bug should stay open with this PR as a candidate fix until that P1 gap is repaired and after-fix live Chrome/Meet proof is provided.

## What This Changes

Conditionally navigates reused Google Meet join and create tabs to an English-localized URL, adopts any replacement browser target, and adds mocked regression coverage.

## Best Possible Solution

Use one shared normalize-adopt-inspect path for all reused or recovered Meet tabs—join, create, local recovery, and node recovery—then validate a localized existing tab through joining, captioning, status recovery, and meeting creation in a real Chrome session.
