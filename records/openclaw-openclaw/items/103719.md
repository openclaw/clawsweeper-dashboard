## Summary

The patch addresses the linked locale-dependent failure at the correct plugin boundary, but the join reuse path does not carry forward the post-navigation target identity and the contributor supplied only mocked proof, so it is not ready to merge.

## What This Changes

The PR navigates reused Google Meet Chrome tabs to an `hl=en` URL in join and create flows and adds mocked regression tests.

## Best Possible Solution

Keep the `hl=en` mitigation in the Google Meet plugin, but assign `targetId` from the parsed `/navigate` response before permissions and DOM actions, add a regression case with a changed target ID, and prove both reused join and create flows in a redacted live Chrome session.
