## Summary

The PR remains necessary for the canonical localized-Meet bug, but it is not merge-ready: the newest commit fixes navigation target adoption while the patch still reloads reused tabs in place, leaves both recovery entry points on English-only inspection, and has no after-fix live Chrome/Meet proof.

## What This Changes

The PR navigates reused Google Meet join and create tabs to an English-language URL and adopts the navigation-returned tab target for subsequent automation.

## Best Possible Solution

Preserve localized user-owned tabs by opening a separate English plugin-owned tab, apply the same locale invariant to local and node recovery, and prove join/create/recovery in a real non-English Chrome profile before merge.
