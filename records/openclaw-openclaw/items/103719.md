## Summary

Keep open: the current head remains incomplete because both current-main recovery paths can inspect localized Meet tabs with English-only DOM matching, preserving the reported failure after session recovery or restart.

## What This Changes

The PR navigates reused Google Meet join/create tabs to an English UI, adopts navigation-returned targets, adds mocked regression coverage, and includes unrelated lint-only changes in two core test files.

## Best Possible Solution

Rebase and route initial reuse, create reuse, and both recovery transports through one Google Meet-owned helper that focuses the selected tab, forces `hl=en`, adopts the authoritative returned target, and only then performs DOM inspection.
