## Summary

Keep open: current main and latest release still use synchronous Signal daemon shutdown, and the focused closing fix remains open at https://github.com/openclaw/openclaw/pull/71863.

## What This Changes

The issue requests awaited, bounded Signal daemon shutdown during gateway restarts so a new signal-cli instance does not race an old process holding the port or config lock.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/71863, or an equivalent Signal-owned fix that makes daemon stop async, idempotent, bounded by SIGKILL fallback, and awaited through monitor teardown.
