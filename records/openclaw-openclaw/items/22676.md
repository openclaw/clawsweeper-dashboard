## Summary

Keep open: current main still has the Signal daemon stop race, the latest release still ships the same fire-and-forget shutdown, and the focused closing PR is open and unmerged.

## What This Changes

The issue reports that Signal hot-restart teardown sends SIGTERM to signal-cli without waiting for exit, allowing orphaned daemons, port/config-lock races, and send failures after restart.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/71863, or an equivalent Signal-owned lifecycle fix that awaits daemon exit after SIGTERM, escalates after a bounded timeout, and keeps monitor teardown open until cleanup finishes.
