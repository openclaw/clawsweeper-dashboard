## Summary

Keep open: current main and the latest release still use fire-and-forget Signal daemon shutdown, and the linked closing PR remains open and unmerged.

## What This Changes

Fix the Signal daemon SIGUSR1/config-reload restart race by waiting for signal-cli to exit, with bounded SIGKILL escalation, before starting a replacement daemon.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/71863, or an equivalent Signal-owned lifecycle fix that awaits daemon exit after SIGTERM, escalates after a bounded timeout, and keeps monitor teardown open until cleanup finishes.
