## Summary

Keep open: current main and v2026.6.11 still use fire-and-forget Signal daemon shutdown, and the focused closing fix at https://github.com/openclaw/openclaw/pull/71863 remains open and unmerged.

## What This Changes

The issue requests fixing Signal auto-start daemon shutdown so hot reload or restart waits for signal-cli to exit, with bounded escalation, before starting a replacement process.

## Best Possible Solution

Keep this issue open and land https://github.com/openclaw/openclaw/pull/71863 or an equivalent Signal-owned lifecycle fix that awaits daemon exit after SIGTERM, escalates after a bounded timeout, and keeps monitor teardown open until cleanup finishes.
