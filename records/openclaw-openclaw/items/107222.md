## Summary

Keep open: the report identifies a concrete npm output-contract regression in the supported plugin install/update path, and current main still routes npm update checks through the affected metadata resolver without evidence that array-shaped results are normalized. The related reports describe separate allowlist and migration-checkpoint failures rather than replacing this work.

## What This Changes

Accept array-shaped JSON from `npm view` when resolving npm plugin metadata so plugin installs, updates, and repair flows retain package identity and version fields.

## Best Possible Solution

Normalize both legacy object output and one-record array output inside the shared npm metadata resolver, reject empty or malformed arrays, and add regression coverage for install, update preflight, and repair callers without changing plugin policy or adding configuration.
