## What This Changes

The issue reports intermittent builtin `memory_search` failures where the tool returns `index metadata is missing` while the durable memory index appears valid.

## Best Possible Solution

Review, land, or explicitly replace https://github.com/openclaw/openclaw/pull/90453 with one manager-level read barrier that preserves true provider/model mismatch fail-closed behavior and coordinates adjacent memory metadata cleanup.

## Solution Assessment

Yes for the current direction: a manager-level read barrier and stable status snapshot address the lifecycle race more directly than a tool-wrapper mitigation. Maintainers still need to accept the wait-through-reindex latency tradeoff and coordinate adjacent metadata cleanup.
