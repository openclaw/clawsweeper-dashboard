Full review comments:

- **[P2] Reset cached titles when the active gateway changes:** `ui/src/pages/chat/tool-titles.ts:119-121`
  - body: `getToolCallTitle` returns the process-global cached title before the new client can discover that its gateway has `toolTitles` disabled, while `configureToolTitleFetcher` only clears the disabled flag. Switching gateways can therefore keep rendering an AI title on a default-off gateway; clear or namespace cached titles with the client context.
  - confidence: 0.99
- **[P2] Scope failed title keys to the fetch context:** `ui/src/pages/chat/tool-titles.ts:150`
  - body: `failedKeys` is global and keyed only by the tool digest, so a no-title response or transient failure for one client, session, or agent permanently suppresses the same call in a later context that can generate it. Clear or namespace failures when the fetch context changes.
  - confidence: 0.99
- **[P2] Drop inherited profiles for session provider overrides:** `src/gateway/chat-tool-titles.ts:338-340`
  - body: With no `sessionAuthProfile`, the code keeps `resolvedRef` unchanged. The utility resolver can append the agent primary model's profile even when `sessionPrimaryProvider` selects another provider, causing that provider's derived utility model to request a stale profile; strip the inherited profile when the provider came from a session override.
  - confidence: 0.97
- **[P2] Do not apply a session profile to another provider:** `src/gateway/chat-tool-titles.ts:338-340`
  - body: When an explicit utility model uses a different provider, this branch replaces its profile with the session's auth profile unconditionally. That can lock the utility request to a profile id belonging to the session's provider; only apply the session profile to a same-provider derived utility ref.
  - confidence: 0.98
