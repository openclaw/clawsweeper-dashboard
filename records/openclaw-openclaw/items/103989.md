## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.98

Full review comments:

- **[P2] Clear cached titles when the gateway client changes:** `ui/src/pages/chat/tool-titles.ts:134-136`
  - body: `configureToolTitleFetcher` resets only the disabled flag, while `getToolCallTitle` returns `titlesByKey` entries before contacting the active gateway. Switching from a title-enabled gateway to one with the feature disabled can therefore keep rendering an old AI title and never obtain the disabled response; clear or context-key the cached titles on client changes.
  - confidence: 0.98
- **[P2] Scope failed title keys to the active fetch context:** `ui/src/pages/chat/tool-titles.ts:148-150`
  - body: A missing title or request error permanently adds the digest to the process-global `failedKeys`, blocking later requests for the same call from another gateway, session, or agent even after routing or connectivity is fixed. Key failures by client/session/agent or clear them whenever that context changes.
  - confidence: 0.99
- **[P2] Drop inherited profiles for session provider overrides:** `src/gateway/chat-tool-titles.ts:338-340`
  - body: With no session auth override, this preserves `resolvedRef` unchanged. The utility resolver can append the agent primary model's profile even when `sessionPrimaryProvider` derives a utility model for a different provider, producing refs such as `anthropic/...@openai-profile`; strip inherited profiles when the session provider differs.
  - confidence: 0.97
- **[P2] Do not apply a session profile to another provider:** `src/gateway/chat-tool-titles.ts:338-340`
  - body: When an explicit utility model uses a different provider, this unconditionally replaces its profile with the session provider's `authProfileOverride`. That can turn an OpenAI utility ref into `openai/...@anthropic-profile`, causing credential failure or use of the wrong account; apply the session profile only to same-provider derived refs and preserve explicit cross-provider profiles.
  - confidence: 0.98
- **[P1] Redact tool-title input before truncating it:** `src/gateway/chat-tool-titles.ts:72-76`
  - body: The code slices the raw input before exact registered-secret and pattern redaction. If the 2,000-character boundary cuts through a secret, the remaining fragment no longer matches the registered value and can enter both the cache key and utility-model prompt. This was missed on the previous review of the same head; redact the complete bounded protocol input first, then truncate the redacted result.
  - late: true
  - confidence: 0.99
