## Summary

The PR addresses a real current-main restart bug and has strong live proof, but the latest patch still records all module-loader imports without their owning plugin root. That leaves split setup/runtime plugin dependencies incompletely evicted and also enrolls the shared OpenClaw runtime module in restart eviction, so the patch is not yet safe to merge.

## What This Changes

The PR clears plugin loader, manifest, activated runtime, and native module caches during in-process gateway restarts and adds workspace-plugin reload regression coverage.

## Best Possible Solution

Track only plugin-owned entrypoints with their discovered package root at each load site, exclude the shared OpenClaw runtime module from restart eviction, and add a split setup/runtime regression with a dependency outside the runtime entry directory.
