## What This Changes

The branch records durable deletion of an active cron job and prevents its later manual, queued, scheduled, or startup completion from mutating a newly created job with the same ID.

## System Context

OpenClaw cron stores reminder definitions durably and separately tracks admitted in-process runs. When a run completes, the service normally applies terminal state and delivery history back to the stored job; this patch distinguishes a deleted old job from a same-ID replacement before that finalization occurs.
