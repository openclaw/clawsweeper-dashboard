## What This Changes

The PR adds six AI-safety diagnostic event types and exporter mappings, an in-memory query store, two gateway RPCs, an `openclaw safety events` command, and a Control UI `/safety` dashboard.

## Best Possible Solution

Extend the existing diagnostics-stability pipeline instead of creating a parallel store: canonical typed events should pass through its bounded sanitizer into an approved SQLite retention model, with read-scoped queries shared by the existing gateway CLI and the new dashboard; prerequisite taxonomy, exporter, and plugin contracts should then land separately in an explicitly reviewed order.
