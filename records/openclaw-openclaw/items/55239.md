## Summary

Keep open. Current main has Telegram transport plumbing for commands that already carry `descriptionLocalizations`, but the reported Chinese/configurable Telegram command-menu descriptions are still missing for built-in commands and `channels.telegram.customCommands`.

## What This Changes

Request support for configurable Chinese or other localized descriptions in the Telegram Bot command menu.

## Best Possible Solution

Adopt one additive `descriptionLocalizations` locale-map contract for Telegram built-in, custom, plugin, and skill command-menu descriptions, with schema/docs/tests and English fallback preserved.
