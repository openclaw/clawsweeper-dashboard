## Summary

Keep open. Current main has partial Telegram transport support for `descriptionLocalizations`, but Telegram custom config and built-in command definitions still cannot provide Chinese or other localized command-menu descriptions; the broader open i18n issue overlaps but does not fully replace this Telegram config request.

## What This Changes

Request configurable localized Telegram Bot command-menu descriptions, especially Simplified Chinese labels for entries such as `/tts` and `/help`.

## Best Possible Solution

Adopt one additive `descriptionLocalizations` locale-map contract for Telegram built-in, custom, plugin, and skill command-menu descriptions, with schema/docs/tests and English fallback preserved.
