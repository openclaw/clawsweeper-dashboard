## Summary

Keep open. Current main and the latest release have Telegram transport support for command descriptions that already carry `descriptionLocalizations`, but they still do not provide the requested configurable or built-in Chinese descriptions; the broader open i18n tracker overlaps but is not a confirmed replacement for this focused Telegram issue.

## What This Changes

Requested configurable Chinese localized descriptions for Telegram Bot command menus, such as Chinese descriptions for `/tts` and `/help`.

## Best Possible Solution

Keep this as the focused Telegram tracker unless maintainers explicitly consolidate it into https://github.com/openclaw/openclaw/issues/79458; the eventual fix should extend the existing `descriptionLocalizations` locale-map contract through built-in commands and Telegram custom config with docs and focused tests.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows localized Telegram registration only works when commands already carry `descriptionLocalizations`, while built-in commands and Telegram custom config still expose one fallback description string.

## Solution Assessment

Unclear. The existing `descriptionLocalizations` map is the likely best contract, but maintainers still need to choose translation ownership, config/API scope, and whether this focused tracker should consolidate into https://github.com/openclaw/openclaw/issues/79458.
