## Summary

Close as duplicate/superseded. Current main and the latest release only partially support Telegram localized command descriptions, and the remaining shared locale-map/API decision is now better tracked by the broader open slash-command localization issue.

## What This Changes

The issue requests localized Telegram bot command-menu descriptions, especially Chinese descriptions for commands such as `/tts` and `/help`, preferably configurable in OpenClaw.

## Best Possible Solution

Consolidate the remaining work under https://github.com/openclaw/openclaw/issues/79458: extend the existing `descriptionLocalizations` contract consistently, preserve stable command names, and include Telegram config/docs/tests if maintainers want user-configurable overrides.
