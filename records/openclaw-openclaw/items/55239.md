## Summary

Keep open. Current main and v2026.6.11 include partial Telegram `setMyCommands` `language_code` plumbing, but the requested configurable or built-in Chinese Telegram command-menu descriptions are still missing and the remaining API/config shape needs maintainer product judgment.

## What This Changes

Request localized Simplified Chinese descriptions for Telegram bot command menus, preferably configurable through OpenClaw configuration while keeping command tokens stable.

## Best Possible Solution

Adopt one additive `descriptionLocalizations`-style locale-map contract for built-in commands and Telegram custom config, preserve English fallback behavior, and update schema/docs/tests before enabling Chinese menu descriptions.

## Reproduction Assessment

Yes. Source inspection on current main and v2026.6.11 shows Telegram can register language-specific variants only when commands already carry `descriptionLocalizations`, while built-in and custom config paths still expose one fallback description string.

## Solution Assessment

Unclear. A Telegram-only config override would solve the immediate request, but the maintainable path is likely a shared `descriptionLocalizations` locale-map contract after maintainers choose translation ownership and API scope.
