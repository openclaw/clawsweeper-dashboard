This PR adds an AG-UI HTTP/SSE channel that authenticates inbound clients, runs embedded OpenClaw agent sessions, and streams AG-UI events back to application UIs.

## System Context

The proposed AG-UI channel would be an inbound gateway channel: browser or server clients send HTTP requests, the channel authenticates and assigns a session, then OpenClaw’s embedded agent runtime streams protocol events back over SSE. It touches plugin discovery, packaged distribution, session state, gateway authentication, and agent tool-event projection.
