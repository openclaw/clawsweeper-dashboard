## Summary

Keep open: current main still exposes split/panel state as operator-controlled UI and terminal sessions as admin-scoped, connection-owned PTYs, while this maintainer-labeled proposal requires explicit product and security direction before implementation.

## What This Changes

Add agent-facing Control UI layout commands and agent-owned terminal sessions that operators can observe or co-control.

## Best Possible Solution

Define and land capability-gated, session-targeted ephemeral screen commands first, then handle agent-owned PTYs as a separate security-reviewed design with explicit ownership, approval, audit, sandbox, reconnect, and co-attachment contracts.
