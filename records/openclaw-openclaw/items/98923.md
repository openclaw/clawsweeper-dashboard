## Summary

Keep this PR open: the temp-dir migration is useful, but the compaction test changes can delete the temporary session-store directory before fire-and-forget reconciliation writes have drained, so the patch is not merge-ready yet.

## What This Changes

The PR migrates four agent test files from raw `fs.mkdtemp`/`fs.mkdtempSync` calls to the shared `withTempDir` test helper.

## Best Possible Solution

Keep the temp-dir migration, but drain session-store writer work before each compaction `withTempDir` callback exits and add cleanup-specific after-fix proof.

## Reproduction Assessment

Yes, by source inspection: PR-head compaction tests call `handleCompactionEnd` inside `withTempDir`, while current `handleCompactionEnd` launches persisted count reconciliation asynchronously and returns before that write is guaranteed to drain.

## Solution Assessment

No: `withTempDir` is appropriate for synchronous test-owned directories, but these compaction success cases need to await or drain delayed session-store writes before the helper removes the directory.
