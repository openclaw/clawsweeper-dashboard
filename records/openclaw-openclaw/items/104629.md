## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.97

Full review comments:

- **[P1] Use a timeout primitive supported by older WebViews:** `extensions/telegram/src/miniapp/page.ts:52`
  - body: `AbortSignal.timeout(...)` is evaluated before `fetch()` returns a promise. On a supported Telegram WebView where this newer static method is unavailable, it throws synchronously and bypasses `.catch(showExpired)`, so even healthy auth cannot open the dashboard. Use an `AbortController` with a cleared timer, or establish and test an explicit supported client floor.
