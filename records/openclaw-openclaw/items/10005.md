## What This Changes

The issue requests a configuration option to suppress the rendered chat/session status card while preserving the current card by default.

## Best Possible Solution

Define a maintainer-approved status-card visibility contract that preserves current rendering by default, covers the sensitive per-agent or per-section disclosure case, and updates schema, help/docs, and focused chat/tool tests together.
