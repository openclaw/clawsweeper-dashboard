## What This Changes

The issue requests a configurable way to suppress the rendered chat/session status card while keeping current behavior by default.

## Best Possible Solution

Add a documented status-card visibility contract for chat `/status` and `session_status`, preserving current rendering by default and covering the privacy-sensitive usage/cost case with schema, docs, and focused tests.
