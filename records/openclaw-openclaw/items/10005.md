## Summary

Keep open: current main and v2026.6.11 still unconditionally render status text for authorized chat `/status` and `session_status`, with no supported visibility setting. This remains the canonical tracker, but implementation requires a maintainer-owned privacy and configuration decision.

## What This Changes

Add a configuration policy to hide or reduce the rendered session status card returned by chat `/status` and the `session_status` tool.

## Best Possible Solution

Create one agent-aware, section-level visibility policy over canonical structured status facts, then apply it consistently to `/status` and `session_status` while preserving current output by default.
