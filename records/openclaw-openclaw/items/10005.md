## What This Changes

The issue requests a new configuration option to hide or JSON-only the rendered status card returned by chat `/status` and the `session_status` tool.

## Best Possible Solution

Add a documented default-on status-card visibility contract for chat `/status` and `session_status`, with explicit privacy semantics, schema/docs coverage, and tests for both command and tool paths.
