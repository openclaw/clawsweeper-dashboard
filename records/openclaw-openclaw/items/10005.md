Keep open: current main and v2026.6.11 still render chat `/status` and `session_status` through the shared status-card text path with no supported hide, JSON-only, or section-visibility setting. The remaining work is a product/security config decision, not an already-implemented cleanup item.

## What This Changes

The issue requests a config-supported way to hide or replace the chat `/status` and `session_status` rendered status card with JSON-only output.

## Best Possible Solution

Define a maintainer-approved status-card visibility contract that preserves current rendering by default, covers per-agent or per-section privacy, and updates schema, help/docs, and focused chat/tool tests together.
