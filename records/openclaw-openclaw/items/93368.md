  - body: This still validates only the lexical `resolve()` strings. If `cwd` is under a symlink inside `workspaceDir` that resolves outside the workspace, the prefix check passes and the loop reads AGENTS.md/CLAUDE.md through that outside target before any canonical containment check, so the security boundary remains bypassable. This is the same prior blocker on the current head; canonicalize existing cwd/workspace paths and verify each directory before reading.
  - confidence: 0.9
- **[P1] Use platform-safe descendant checks:** `src/agents/sessions/resource-loader.ts:123`
  - body: The descendant test appends a literal `/` to `boundary`, but this code runs with `node:path` platform semantics. On Windows, resolved paths use `\`, so a valid child like `C:\ws\task` does not start with `C:\ws/` and the loader returns early, dropping legitimate workspace context. Use `path.relative`/`path.isAbsolute` or an existing helper and cover the Windows path shape.
  - confidence: 0.88
