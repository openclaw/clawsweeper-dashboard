Full review comments:

- **[P1] Canonicalize real paths before checking the workspace boundary:** `src/agents/sessions/resource-loader.ts:123`
  - body: This guard still compares only `path.resolve()` strings. If `cwd` is `workspace/link/task` and `workspace/link` is a symlink to a directory outside the workspace, the lexical prefix passes, then `loadContextFileFromDir` follows the symlink and reads an outside `AGENTS.md` into system prompt context. Please canonicalize the existing cwd/workspace boundary with realpath-aware containment before reading any ancestor context files.
  - confidence: 0.9
- **[P1] Use platform-safe descendant checks:** `src/agents/sessions/resource-loader.ts:123`
  - body: The descendant check appends `/` to the boundary, but native Windows paths from `path.resolve()` use backslashes. A valid child like `C:\ws\task` will not start with `C:\ws/`, so sessions with `workspaceDir` fail closed and lose workspace ancestor context on Windows. Please use `path.relative` plus `path.isAbsolute`/native separators, or a shared containment helper.
  - confidence: 0.88
