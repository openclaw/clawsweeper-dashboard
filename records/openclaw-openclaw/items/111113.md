## Summary

Keep this PR open for normal merge review: current main still decodes self-hosted discovery bytes leniently, while this focused change rejects malformed UTF-8 before a corrupted model identifier can be returned. The one-line runtime fix, regression test, and pasted before/after live output support the proposed boundary; no blocking patch defect was found.

## What This Changes

The PR changes self-hosted provider discovery to decode response bytes with fatal UTF-8 validation and adds a regression test for an invalid byte inside a discovered model ID.

## Best Possible Solution

Land the focused fatal-decoding change with its regression test so malformed self-hosted discovery bytes fail at the shared parser instead of becoming usable model identifiers.
