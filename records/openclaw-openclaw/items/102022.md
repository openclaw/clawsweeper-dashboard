## Summary

Keep open: the branch fixes the prior ordinary-run `{}` default-flow-state gap and adds stronger real-runtime proof, but the linked report also calls out blank `flowStateJson`; this PR still parses that value before the new managed-run gate, so an ordinary run carrying `flowStateJson: ""` would fail before reaching the runner.

## What This Changes

The PR changes Lobster tool flow-argument parsing so schema-default flow fields do not select managed TaskFlow mode, and adds regression tests for ordinary and managed run/resume behavior.

## Best Possible Solution

Normalize blank and empty-object schema-default `flowStateJson` as absent before mode selection, keep managed mode keyed on controller/goal or `flowId`, and retain proof for ordinary run/resume plus managed paths.
