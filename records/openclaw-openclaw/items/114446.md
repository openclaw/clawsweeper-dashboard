The patch is a narrow, source-aligned repair with focused unit and source-process coverage, but the PR body does not include inspectable after-fix terminal output or an artifact for its claimed live scenarios; the protected `maintainer` label also requires human handling.

## What This Changes

This PR changes CLI profile environment projection so an explicit named `--profile` replaces inherited canonical state and configuration paths from another profile while retaining noncanonical user overrides.

## System Context

OpenClaw CLI commands project a selected profile into environment variables before configuration, plugin, and state operations start. Gateway-launched shells can inherit those variables, so this projection decides which profile’s files later commands read or modify.
