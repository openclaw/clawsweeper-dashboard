## What This Changes

Make the Control UI’s `/new` prompt composer grow to about ten lines before scrolling and make its internal scrollbar visually unobtrusive.

## System Context

The Control UI opens `/new` as a full-page draft where a user writes the first prompt before any session exists. Submitting that prompt creates the session and navigates into chat, so the draft composer’s sizing and scrollbar styling affect the first interaction with a new session.

## Best Possible Solution

Add a focused browser regression that enters a ten-line draft at `/new`, then adjust the responsible autosize cap and scrollbar styling so the field grows smoothly before its deliberate scroll boundary without regressing the regular chat composer.
