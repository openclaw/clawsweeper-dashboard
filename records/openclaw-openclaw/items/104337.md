The PR makes agent node execution use `/bin/sh -c` for Darwin and versioned macOS platforms, preserves existing Windows and other POSIX transports, adds focused constructor tests, and records the repair in the changelog.

## Best Possible Solution

Land the platform-specific constructor change before the unreleased universal `-lc` behavior ships, keeping the Mac host’s exact-executable binding as the canonical authorization contract and leaving Linux and Windows behavior unchanged.
