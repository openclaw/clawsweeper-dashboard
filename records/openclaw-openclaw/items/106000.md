## Summary

This PR remains necessary: current main retains finished bash sessions only by TTL and does not clear matching finished records on session reset. The patch is technically coherent and has credible live proof, but a runtime owner must explicitly accept the intentional pre-TTL eviction contract before merge.

## What This Changes

The branch caps finished bash-process retention by session count and aggregate output size, and removes exact-scope finished records during gateway session reset/delete cleanup.

## Best Possible Solution

Adopt one explicit, documented internal retention contract: retain complete aggregates while under a bounded global budget, evict oldest finished entries under pressure, and keep reset/delete cleanup exact-scope only.
