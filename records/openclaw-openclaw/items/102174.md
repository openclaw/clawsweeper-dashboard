## Summary

Keep open: current main still has the cron/Claude CLI shape where isolated cron can accept returned CLI text as the run result, deliver it, and then close the Claude live session whose managed process tree is cancelled. The overlapping long-work issues share the lifecycle root cause, but they do not fully own this issue's cron success, delivery, and partial-state invariant.

## What This Changes

The issue reports cron agentTurn returning and announcing a placeholder before a long foreground Bash tool subprocess finishes, leaving partial state while the run records success.

## Best Possible Solution

Define a cron/Claude CLI contract where isolated cron cannot record or deliver success while foreground native tool work remains pending; unsupported long foreground work should fail with explicit diagnostics or be routed through a durable command, on-exit, or exec-process path.
