## Summary

Keep open: current main still lets isolated cron accept a returned Claude CLI result, mark the cron outcome from that text, and then close the Claude live session without any source-visible pending foreground Bash/native-tool guard. The related long-work issues share the process-lifecycle root cause, but they do not fully cover this issue's cron green-status, announce-placeholder, and partial-state invariant.

## What This Changes

The issue reports that isolated cron `agentTurn` can return and announce a placeholder before a long foreground Claude CLI Bash subprocess finishes, after which teardown kills the subprocess and leaves partial run state.

## Best Possible Solution

Define a cron and Claude CLI lifecycle contract where isolated cron cannot record or deliver success while foreground native tool work is still pending; unsupported long foreground work should fail with explicit diagnostics or move to a durable command/on-exit/exec-process path.
