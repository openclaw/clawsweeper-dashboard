## Summary

Keep open: current main still has the isolated cron/Claude CLI path where returned CLI text can become the cron result before live-session cleanup cancels the managed process tree, and the existing stale-ack retry does not cover the reported foreground Bash placeholder/pending-tool invariant.

## What This Changes

The issue requests that cron `agentTurn` not finish as `ok` and deliver placeholder text while long foreground Claude CLI Bash work remains pending and is killed during cleanup.

## Best Possible Solution

Define a cron/Claude CLI lifecycle contract where isolated cron cannot record or deliver success while foreground native tool work remains pending; unsupported long foreground work should fail explicitly or route through a durable command/on-exit path.
