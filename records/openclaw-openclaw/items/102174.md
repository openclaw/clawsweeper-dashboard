## Summary

Keep open: current main still has the source-level path where an isolated cron Claude CLI result can be accepted as `ok`, delivered, and then the live session cleanup cancels the managed process tree; the related open issues share the lifecycle root cause but do not fully cover this issue's cron success and placeholder-delivery invariant.

## What This Changes

The issue reports cron `agentTurn` returning a successful announce summary before a long foreground Bash subprocess finishes, killing work mid-stream and leaving partial state.

## Best Possible Solution

Define a cron/Claude CLI lifecycle contract where isolated cron cannot record or deliver success while foreground native tool work remains pending; unsupported long foreground work should fail with explicit diagnostics or be routed through a durable command/on-exit/exec-process path.
