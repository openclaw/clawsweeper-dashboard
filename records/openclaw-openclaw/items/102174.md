## Summary

Keep open: current main still has the isolated cron/Claude CLI shape where returned CLI text can become the cron result while the Claude live session is closed and its process tree cancelled, and the existing interim-message retry does not cover pending foreground native-tool work. The overlapping long-work issues share the lifecycle root cause, but they do not fully own this issue's cron success, delivery, and partial-state invariant.

## What This Changes

The issue reports scheduled `agentTurn` returning a placeholder before long foreground Bash work completes, causing live-session cleanup to kill the in-flight work while cron records and announces success.

## Best Possible Solution

Define a cron/Claude CLI contract where isolated cron cannot record or deliver success while foreground native tool work remains pending; unsupported long foreground work should fail with explicit diagnostics or be routed through a durable command/on-exit/exec-process path.
