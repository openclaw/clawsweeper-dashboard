## Summary

Keep open: current main still allows isolated cron to accept returned Claude CLI text as the cron result, then close the Claude live session and cancel the supervised process tree; related issues share the lifecycle root cause but do not fully own this issue's cron `ok` status and placeholder-delivery invariant.

## What This Changes

The issue reports that cron agentTurn can finish and deliver a placeholder before a long foreground Bash tool subprocess has completed, leaving partial workspace state and no failure signal.

## Best Possible Solution

Define a cron/Claude CLI lifecycle contract where isolated cron cannot record or deliver success while foreground native tool work remains pending; unsupported long foreground work should fail with explicit diagnostics or be routed through durable command/on-exit execution.
