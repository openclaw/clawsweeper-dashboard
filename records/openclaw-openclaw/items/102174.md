## Label Justifications

- `impact:data-loss`: The reported failure leaves partial per-run state, missing output files, and killed wrapper work after a successful-looking cron record.

- `impact:session-state`: The failure is a mismatch between Claude CLI live-session/tool process state and the cron run state recorded as complete.

## Summary

Keep open: current main still allows an isolated cron Claude CLI run to turn returned CLI text into an `ok` cron outcome while the cleanup path closes the Claude live session and cancels its process tree; the existing interim-message retry is subagent-oriented and does not prove foreground native Bash completion.

## What This Changes

The issue asks OpenClaw to prevent cron `agentTurn` jobs from recording and delivering success while a foreground Claude CLI Bash subprocess is still pending or killed mid-run.

## Best Possible Solution

Define a cron/Claude CLI contract where isolated cron cannot record or deliver success while foreground native tool work remains pending; unsupported long foreground work should fail with explicit diagnostics or be routed through a durable command/on-exit/exec-process path.
