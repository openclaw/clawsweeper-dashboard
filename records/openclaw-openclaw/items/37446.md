## Summary

Keep open: current main covers gateway/message-tool exact retry dedupe in important paths, but it still does not provide the broader sub-agent logical-action claim/replay contract needed to prevent duplicate arbitrary external POST side effects after a lost acknowledgement.

## What This Changes

Request a sub-agent idempotency and recovery mechanism so timed-out POST retries do not create duplicate external comments or actions.

## Best Possible Solution

Keep this as a design thread for durable logical-action idempotency across sub-agent side effects: define the identity, storage/expiry/audit semantics, and tool or plugin opt-in boundary before implementation.
