## Summary

Keep open: current main has exact-key idempotency for gateway agent/message sends and the merged message-tool retry mitigation, but it still does not define durable logical-action identity and replay semantics for arbitrary sub-agent side effects after a lost acknowledgement. The linked ClawHub skill is useful operator guidance, not a replacement for a core contract if maintainers decide this guarantee belongs in OpenClaw.

## What This Changes

Request durable idempotency/replay semantics for sub-agent POST side effects so timeout recovery does not duplicate completed actions.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, expiry, result replay, and audit behavior, then prove it with a lost-ack regression or live scenario.
