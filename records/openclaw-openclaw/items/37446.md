## Summary

Keep open: the merged message-tool work covers exact retry dedupe for channel sends, but current main still lacks the requested durable logical sub-agent action identity and claim/replay state for broader external/API side effects. The ClawHub skill linked in the discussion is useful operational guidance, but it is a workaround rather than an OpenClaw core guarantee.

## What This Changes

Request durable idempotency or replay semantics for sub-agent timeout recovery so one logical external/API POST cannot be repeated after an ambiguous lost acknowledgement.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, result replay, expiry, and regression or live lost-ack proof.
