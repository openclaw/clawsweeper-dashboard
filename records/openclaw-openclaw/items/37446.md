Keep open: the merged message-tool work covers exact timeout retries for channel sends, but current main still lacks the requested durable logical sub-agent action identity and claim/replay state for broader external/API side effects.

## What This Changes

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, result replay, expiry, and regression or live lost-ack proof.
