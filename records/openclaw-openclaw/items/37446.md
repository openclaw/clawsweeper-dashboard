## Summary

Keep open: current main has per-surface Gateway and message-tool idempotency, and the merged message-tool fix covers exact retry duplicate sends, but the requested logical-action replay boundary for arbitrary sub-agent side effects after a lost acknowledgement is still missing.

## What This Changes

Request a durable idempotency or replay mechanism so sub-agent timeout recovery does not repeat already-committed POST side effects.

## Best Possible Solution

Define a narrow core/plugin SDK logical-action claim, commit, and replay contract for OpenClaw-owned side-effecting paths, reusing existing idempotency and persistent-dedupe helpers while leaving third-party API-specific keys to the owning plugin or skill unless core owns the side effect.
