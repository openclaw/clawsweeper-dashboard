## Summary

Keep open: current main has exact-key gateway dedupe and the merged message-tool retry mitigation, but it still lacks the requested durable logical sub-agent action identity and claim/replay semantics for arbitrary external POST side effects.

## What This Changes

The issue requests idempotency or recovery semantics so sub-agent timeout retries do not duplicate one logical external POST action.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, expiry, result replay, and audit behavior, then prove it with a lost-ack regression or live scenario.
