## Summary

Keep open: current main and v2026.6.11 have exact-key idempotency for gateway sends and the merged message-tool retry mitigation, but they still do not define durable logical-action identity and replay semantics for arbitrary sub-agent side effects after a lost acknowledgement.

## What This Changes

The issue requests durable idempotency for sub-agent timeout recovery so lost acknowledgements do not create duplicate external POST side effects.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, expiry, result replay, and audit behavior, then prove it with a lost-ack regression or live scenario.
