## Summary

Keep open: current main has exact-key gateway/message-tool retry dedupe, but it still does not provide the durable logical-action identity and replay semantics needed to prevent arbitrary sub-agent POST side effects from duplicating after a lost acknowledgement.

## What This Changes

Request durable idempotency and replay behavior for sub-agent timeout recovery so retries after lost acknowledgements do not duplicate external POST side effects.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, expiry, result replay, and audit behavior, then prove it with a lost-ack regression or live scenario.
