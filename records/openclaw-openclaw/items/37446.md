## Summary

Keep open: current main has exact-key gateway/message-tool dedupe for one retry slice, but it still lacks the durable logical sub-agent action claim/replay contract needed for arbitrary external POST side effects after a lost acknowledgement.

## What This Changes

The issue requests durable idempotency and recovery semantics for sub-agent POST retries when the original side effect may have committed but the response was lost.

## Best Possible Solution

Define a narrow core logical-action idempotency contract for sub-agent/tool side effects, including claim, commit, replay, expiry, and audit behavior, then prove it with a lost-ack regression or live scenario.
