## Summary

Keep open: current main and v2026.6.11 include the narrower message-tool exact-retry mitigation, but the requested durable logical sub-agent action identity and replay/claim state for broader external API side effects is still missing. ## What This Changes

Add idempotency or recovery semantics so a sub-agent timeout after a successful POST does not retry into duplicate comments or actions.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, result replay, expiry, and regression or live lost-ack proof.
