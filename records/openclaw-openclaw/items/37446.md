## Summary

Keep open: current main and the latest release have useful message-tool/gateway idempotency mitigations, but the requested durable logical sub-agent action identity and claim/replay semantics for arbitrary external POST side effects are still missing.

## What This Changes

The issue asks for durable idempotency or replay protection so sub-agent timeout recovery does not commit the same logical external POST action twice after an ambiguous timeout.

## Best Possible Solution

Define a maintainer-approved logical-action idempotency contract for OpenClaw-owned sub-agent side effects, including durable claim/replay state and clear documentation for external services that must supply their own idempotency keys.
