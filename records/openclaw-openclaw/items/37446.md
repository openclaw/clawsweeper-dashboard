## Summary

Keep open: current main and the merged message-tool fix cover exact-key/message retries, but arbitrary sub-agent external side effects still lack durable logical-action identity, claim, and replay semantics.

## What This Changes

The issue requests durable idempotency for sub-agent timeout recovery so a lost acknowledgement after a successful external POST does not create duplicate posts or actions.

## Best Possible Solution

Define a narrow durable logical-action idempotency contract for sub-agent/tool side effects, including target scope, payload digest, result replay, expiry, and regression or live lost-ack proof.
