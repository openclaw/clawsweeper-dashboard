The PR changes the model-switch acknowledgement so the model selection is shown before an automatic thinking-level remap in both directive acknowledgement builders, with a regression test for the direct directive path.

## System Context

OpenClaw parses inline commands such as `/model`, persists any session-level model change, checks whether the stored thinking level remains supported, and returns a plain-text acknowledgement to the active chat surface. This change affects only the order of two messages in that acknowledgement after a model switch triggers a compatibility remap.
