## Best Possible Solution

Land the host-owned SQLite lease design only with an enforceable tagged upgrade path—such as a bounded transition lock or fail-closed old-process detection—plus fresh-install and upgrade tests, transient-row backup coverage, and a real concurrent QMD gateway-plus-CLI proof.
