- `P2`: A malformed public Microsoft catalog response can prevent voice discovery, but the failure is limited to the optional Microsoft speech provider.

## Summary

This PR remains necessary: current `main` still maps the Microsoft voice payload as a trusted typed array, so a null or malformed row can abort discovery. The provider-local unknown-data parsing, focused regression coverage, and exact-head before/after runtime proof support ordinary maintainer merge review; likely related people: @extrasmall0 (medium confidence, adjacent Microsoft TTS history).

## What This Changes

The branch parses Microsoft voice-list responses as unknown data, skips malformed rows and tag values, and preserves valid voice entries with regression tests.

## Best Possible Solution

Merge the provider-local defensive normalization after the routine maintainer refresh for the current merge head; keep HTTP-error and timeout behavior unchanged.
