## What This Changes

This PR makes the Android release workflow fail normal releases when matching Android assets already exist, while retaining the recovery warning path.

## System Context

The Android Release workflow is a child of the release-publish process. It validates a release approval and draft release, builds and attests the signed APK, then uploads or byte-verifies the canonical Android assets before final release verification.
