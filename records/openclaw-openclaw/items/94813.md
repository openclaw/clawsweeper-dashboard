## Best Possible Solution

Keep the scoped direct-chat shortening, fix non-direct fallback handling so typed labels are not duplicated or made less useful, then require a redacted real Control UI screenshot or recording before merge while leaving the broader friendly-name issue open.

## Reproduction Assessment

## Solution Assessment

No, not as written. The Sessions-only direct-key formatter is the right narrow layer, but the non-direct fallback branch should not prepend parser prefixes again or broaden the behavior beyond the intended long direct-chat IDs.
