Keep open: current main still accepts the reported Feishu/Lark announce cron shape with `delivery.channel` set and no `delivery.to`, while runtime Feishu delivery still requires a concrete target. Reject cron create/update requests for Feishu/Lark announce delivery when no explicit or deterministically resolved delivery target exists.
