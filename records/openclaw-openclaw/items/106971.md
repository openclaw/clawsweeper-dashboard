## Summary

Keep this PR open, but do not merge it as written: the repeated P1 security finding remains on the unchanged head because bypassing the writer-held lock can evaluate exec authorization against policy state that is not transactionally committed. The linked production report is credible, but the proposed availability fix weakens the revocation invariant and the submitted proof is test-only.

## What This Changes

The branch permits synchronous exec-approval reads without the sidecar lock during same-process contention, extracts copy-fallback persistence helpers, and adds a regression test for avoiding fail-closed denial.

## Best Possible Solution

Keep synchronous authorization decisions tied to a stable committed policy snapshot—prefer a process-local immutable last-committed snapshot or a unified lock owner rather than reading the file locklessly—then add revoke-versus-read race coverage and a live concurrent gateway proof.
