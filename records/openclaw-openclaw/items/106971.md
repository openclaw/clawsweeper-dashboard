## Summary

The underlying lock wedge is credible, but this patch trades the permanent fail-closed failure for an authorization-ordering race: file existence does not prove that the same-process writer has committed its policy mutation.

## What This Changes

The PR lets synchronous exec-approval readers bypass same-process lock contention, extracts copy-fallback persistence helpers, and adds a regression test.

## Best Possible Solution

Introduce a process-local transaction owner that distinguishes true reentrant reads from unrelated readers, supplies transaction-consistent policy to the owner, and keeps unrelated synchronous reads fail-closed until the mutation commits; then prove both revocation ordering and live gateway recovery.
