## Summary

Keep open: the previously reported P1 blocker remains. The new lockless path can read the authorization file while the existing copy-based fallback is modifying or rolling back that same file, and the supplied validation does not exercise a live writer or gateway contention scenario.

## What This Changes

The PR makes synchronous exec-approval reads bypass same-process lock contention, adds a regression test, and extracts the existing copy-based fallback-write implementation into a separate module.

## Best Possible Solution

Keep synchronous authorization reads serialized with writes, or serve same-process contention from an immutable last-committed in-process snapshot; preserve fail-closed initial creation and add coverage for successful copy writes, partial-write failure, rollback, and repeated live gateway exec decisions.

No. Avoiding the immediate timeout is necessary, but an unlocked disk read is not the safest fix because the store has an in-place copy fallback and rollback path; the read must remain tied to a committed snapshot.
