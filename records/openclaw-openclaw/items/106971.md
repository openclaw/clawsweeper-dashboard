## Summary

The reported P1 regression is valid, but the prior blocking correctness issue remains on the unchanged head: synchronous authorization reads may bypass the lock while the copy fallback is modifying policy bytes in place. The focused test and transcript do not exercise that active-writer state.

## What This Changes

The PR adds a same-process lock-contention fallback for synchronous exec-approval reads, extracts the copy-based persistence fallback, and adds a focused regression test.

## Best Possible Solution

Serve same-process synchronous readers from a process-local last-committed policy snapshot, or redesign the ownership boundary so they remain serialized, then test a paused copy-fallback write and provide a redacted live gateway concurrency transcript.
