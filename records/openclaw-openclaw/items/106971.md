## Summary

## What This Changes

The PR makes synchronous exec-approval readers bypass same-process lock contention, extracts the copy-based persistence fallback, and adds a lock-contention regression test.

## Best Possible Solution

Keep synchronous authorization reads bound to a process-local last-committed policy snapshot or another serialization mechanism that cannot deadlock the async writer, preserve fail-closed initial creation, and cover actual async update, revocation, atomic-rename, and copy-fallback contention before merge.
