## Summary

Keep this PR open for security-boundary review. The focused fix plausibly addresses the linked exec-denial regression, but it introduces lockless authorization-store reads without real gateway proof and relies on every authorization consumer revalidating under the write lock.

## What This Changes

The PR makes synchronous exec-approval readers fall back to an unlocked existing-file read during same-process lock contention and adds a synthetic contention regression test.

## Best Possible Solution

Make existing-file snapshot reads explicitly lock-free by contract, retain locking for creation and mutations, and prove that every execution authorization is revalidated against the current policy before launch; accompany that invariant with a live gateway contention transcript.
