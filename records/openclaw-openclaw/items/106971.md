## Summary

The prior P1 remains: the proposed fallback fixes the denial wedge by allowing authorization reads to observe the pre-update policy while a same-process writer holds the lock, which can temporarily preserve permissions being revoked. The original bug is valid, but this security-sensitive ordering tradeoff and the missing live concurrency proof block merge.

## What This Changes

The PR lets synchronous exec-approval readers bypass same-process lock contention, extracts fallback-write helpers, and adds a simulated contention regression test.

## Best Possible Solution

Preserve fail-closed authorization ordering while removing the wedge, preferably by giving synchronous readers an explicitly committed process-local snapshot or restructuring callers so they never synchronously contend with an active async policy mutation; add a revocation-race regression and live gateway concurrency proof.
