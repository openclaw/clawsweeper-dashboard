The linked bug remains valid and this PR remains its candidate fix, but it is not safe to merge in its current form.

## What This Changes

The branch adds a lockless fallback for synchronous exec-approval reads during same-process async lock contention, adds a synthetic regression test, and removes two unused environment helpers from `src/process/exec.ts`.

## Best Possible Solution

Keep authorization reads linearized with policy writes, and remove the self-contention by carrying the already-locked snapshot through nested same-process calls or by giving the store one shared lock owner; cover recovery, initial creation, and concurrent revocation with focused tests plus a redacted live gateway or Docker transcript.
