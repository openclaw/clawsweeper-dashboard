## Summary

## What This Changes

## Best Possible Solution

Capture the timeout-abort caller and reason on current main, keep nested Agent gateway-call failures tool-scoped, persist a visible terminal failure for any parent timeout, and deterministically promote or explicitly fail queued followups instead of discarding them.
