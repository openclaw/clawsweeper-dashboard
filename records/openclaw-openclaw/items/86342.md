## Summary

Keep open: current main and the latest release still contain the broad harness-registry lifecycle hazard, while related merged work only covers narrower CLI-alias and disabled-Codex doctor/config slices. The open candidate PR is still unmerged, conflicting, and blocked on the ownership semantics for preserving versus clearing harnesses during empty plugin-scope reloads.

## What This Changes

Fix a MissingAgentHarnessError race where plugin cache or reload paths can clear the process-wide agent harness registry before Discord, cron, or gateway agent dispatch selects the configured runtime harness.

## Best Possible Solution

Land an ownership-aware harness lifecycle fix that preserves only approved always-on harnesses, clears disabled or unscoped plugin-owned harnesses, covers both loader and gateway empty-scope paths, and includes patched real gateway proof for the affected channel/cron dispatch path.
