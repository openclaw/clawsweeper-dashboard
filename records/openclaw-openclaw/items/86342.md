## What This Changes

The issue asks OpenClaw to prevent intermittent MissingAgentHarnessError failures when plugin cache or reload cycles clear registered agent harnesses used by Discord, cron, and gateway agent turns.

## Best Possible Solution

Land an ownership-aware harness lifecycle fix that preserves approved always-on or bundled provider harnesses across empty reloads, still clears disabled or out-of-scope plugin-owned harnesses, and proves loader, gateway, Discord or cron behavior with focused tests plus live gateway evidence.
