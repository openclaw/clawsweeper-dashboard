## Summary

Keep open: current main and v2026.6.1 fixed the narrow `claude-cli` CLI-alias throw path, but the broader harness registry lifecycle request is still unresolved and the open candidate PR is blocked on ownership semantics.

## What This Changes

The issue asks OpenClaw to prevent `MissingAgentHarnessError` during plugin cache/reload cycles by retrying lane spawn, making harness restore atomic, or gating channel dispatch on harness readiness.

## Best Possible Solution

Land an ownership-aware harness lifecycle fix that preserves only approved always-on harnesses, clears disabled or unscoped plugin-owned harnesses, covers both loader and gateway empty-scope paths, and includes patched real gateway proof for the affected channel/cron dispatch path.
