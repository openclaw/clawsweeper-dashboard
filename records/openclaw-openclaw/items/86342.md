Keep open: current main and the latest release still have loader and gateway empty-scope paths that clear process-global harness state without restoring an ownership-safe subset. The `claude-cli` alias symptom is partly fixed on main, but the broader plugin lifecycle issue remains paired with an open, conflicting candidate PR that needs a maintainer decision on harness ownership semantics.

## What This Changes

The issue requests a fix for intermittent `MissingAgentHarnessError` during plugin-loader cache or reload cycles, suggesting bounded retry, atomic harness restore, or dispatch readiness gating.

## Best Possible Solution

Keep this as the canonical lifecycle bug until maintainers land an ownership-aware harness preservation or reload fix that covers loader and gateway empty-scope paths, preserves only approved always-on harnesses, clears disabled plugin-owned harnesses, and includes regression plus patched real-behavior proof.
