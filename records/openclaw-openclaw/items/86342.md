## Summary

Keep open: current main has fixed the narrower `claude-cli` CLI-alias fallback, but the broader harness-registry lifecycle issue remains because loader and gateway empty-scope paths still clear process-global harness state without an ownership-aware restore, and the related candidate PR is still open, conflicting, and blocked on restore semantics.

## What This Changes

The issue reports intermittent `MissingAgentHarnessError` during Discord/channel dispatch when plugin loader cache clear/restore cycles leave the agent harness registry empty.

## Best Possible Solution

Land an ownership-aware harness lifecycle fix that preserves only approved always-on harnesses, clears disabled or unscoped plugin-owned harnesses, covers loader and gateway empty-scope paths, and includes patched gateway proof for the affected channel/runtime flow.
