## Summary

Keep open: current main and the latest release still have the harness-registry clear paths that match the central lifecycle problem, while the related CLI-alias failure mode is already fixed and a candidate lifecycle PR remains open, conflicting, and waiting on semantics.

## What This Changes

The issue reports intermittent MissingAgentHarnessError during plugin cache or reload cycles when registered agent harnesses are cleared or unavailable while Discord, cron, or gateway dispatch selects a runtime.

## Best Possible Solution

Decide the plugin lifecycle contract for empty-scope reloads, then land https://github.com/openclaw/openclaw/pull/87046 or a narrower replacement with loader and gateway regression coverage that preserves the intended harness class without keeping disallowed plugin state alive.
