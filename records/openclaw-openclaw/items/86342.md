## What This Changes

Reports a plugin reload/cache lifecycle bug where process-global agent harness registrations can be cleared or restored unsafely, causing Discord, cron, or gateway turns to fail with `MissingAgentHarnessError`.

## Best Possible Solution

Land or replace the candidate with an ownership-aware harness lifecycle repair that preserves only approved always-on/native harness availability during reload windows, clears disabled or unscoped plugin-owned harnesses, and proves Discord/cron or gateway turns no longer surface `MissingAgentHarnessError`.
