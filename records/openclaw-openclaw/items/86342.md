## What This Changes

The issue reports intermittent `MissingAgentHarnessError` during Discord, cron, and gateway agent turns when plugin loader cache or empty-scope reloads clear the process-wide agent harness registry before or without restoring it.

## Best Possible Solution

Define and implement owner-aware harness lifecycle semantics for plugin reloads, then land either the existing candidate PR or a replacement with loader/gateway regression coverage and patched real-behavior proof.
