## Summary

Keep open: current main and v2026.6.11 still support daily, idle, manual reset, and thread-binding max age, but not normal-session max-age or max-turn automatic rotation; the remaining work needs maintainer product/config direction.

## What This Changes

The issue requests configurable session maximum age and turn limits that automatically rotate long-lived agent sessions after saving memory.

## Best Possible Solution

Approve one canonical opt-in core reset policy that covers max age and max turns with safe pre-rotation memory handoff, active-run safety, docs, and upgrade expectations.
