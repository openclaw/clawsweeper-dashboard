## Summary

Keep open: current main and the latest release still provide daily/idle reset, manual reset, thread-binding max-age, compaction, pruning, and pre-compaction memory flush, but not the requested normal-session max-age or max-turn rotation policy.

## What This Changes

Request to add configurable session age and turn-count limits that automatically rotate agent sessions after saving memory and logging the rotation.

## Best Possible Solution

Design one core session lifecycle policy that adds age/turn triggers, durable accounting, safe memory or continuity behavior, docs, and upgrade tests without duplicating context-pruning or thread-binding semantics.
