## Summary

Keep open: current main and v2026.6.11 still lack a normal-session max-age or max-turn rotation policy, and the closed turn-count issue explicitly consolidated that remaining work here. This is a real session-lifecycle feature request, but it needs maintainer product/config direction before implementation.

## What This Changes

The issue requests configurable maximum session age and turn-count rotation with a pre-rotation memory save for long-running agent sessions.

## Best Possible Solution

Define one maintainer-approved core session rotation contract that covers max age, max turns, trigger timing, memory handoff, logs, docs, tests, and upgrade behavior without changing existing daily/idle defaults unexpectedly.
