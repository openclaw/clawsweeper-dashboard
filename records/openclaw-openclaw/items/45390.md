## Summary

Keep open: current main and v2026.6.11 still lack normal-session max-age or max-turn automatic rotation; the existing daily/idle reset, compaction, and thread-binding max-age paths do not satisfy the requested session lifetime cap, and the remaining work needs a maintainer product/config decision.

## What This Changes

Request configurable session max-age and max-turn rotation that saves memory, starts a fresh session, and logs the rotation before long-running contexts hit provider limits.

## Best Possible Solution

Design one maintainer-approved core session lifecycle policy with age/turn triggers, durable accounting, safe memory or continuity behavior, docs, and focused upgrade tests.
