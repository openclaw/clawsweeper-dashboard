## Summary

Keep open: current main and latest release still provide daily, idle, manual reset, thread-binding max-age, and compaction-related transcript controls, but not the requested general max-age/max-turn automatic session rotation with safe memory handoff.

## What This Changes

The issue requests configurable session maximum age and turn-count rotation that saves agent memory, starts a fresh session, and logs the lifecycle event.

## Best Possible Solution

Approve one opt-in core session lifecycle policy that combines age/turn triggers with explicit memory handoff, continuity behavior, docs, schema, and focused upgrade tests.
