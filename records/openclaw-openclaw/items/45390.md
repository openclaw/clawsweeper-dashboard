## Summary

Keep open: current main still supports daily, idle, manual reset, and thread-binding max-age, but not the requested general max-age or max-turn automatic session rotation with safe memory handoff.

## What This Changes

Requests configurable max-age and max-turn session rotation so long-running agent sessions automatically start fresh after saving useful state.

## Best Possible Solution

Approve one opt-in core session lifecycle policy that combines age/turn triggers with explicit memory handoff, continuity behavior, docs, schema, and focused upgrade tests.
