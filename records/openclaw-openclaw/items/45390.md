## Summary

Keep open: current main and v2026.6.11 still support daily, idle, and manual reset for normal sessions, but not the requested max-age or max-turn automatic rotation with memory/continuity handoff.

## What This Changes

The issue requests configurable session maximum age and turn-count rotation so long-running agent sessions rotate before unbounded context growth degrades reliability.

## Best Possible Solution

Define one opt-in core session lifecycle policy covering age, turn count, and handoff semantics, with memory preservation, schema/docs alignment, and upgrade tests.
