## Summary

Keep open: current main and v2026.6.11 still support daily, idle, and manual normal-session resets, but not the requested max-age or max-turn automatic rotation policy.

## What This Changes

The issue requests configurable session max-age and max-turn rotation with memory preservation before a fresh session starts.

## Best Possible Solution

Define one opt-in core session lifecycle policy for age, turn, and handoff semantics, with safe pre-rotation memory preservation, schema/docs alignment, and focused upgrade tests.
