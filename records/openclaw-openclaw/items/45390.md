## Summary

Keep open: current main and v2026.6.11 still provide daily, idle, manual reset, compaction, and thread-binding max-age behavior, but not the requested general max-age or max-turn automatic session rotation with safe memory handoff.

## What This Changes

The issue requests configurable session maximum age and maximum turns that automatically rotate long-running agent sessions after saving memory and logging the rotation.

## Best Possible Solution

Approve one opt-in session lifecycle policy under session.reset that covers max-age and max-turn triggers plus memory, transcript, delivery-route, provider-continuity, docs, schema, and upgrade behavior.
