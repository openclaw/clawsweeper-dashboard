## Summary

Keep open: current main and v2026.6.11 still support daily, idle, manual reset, and thread-binding max-age, but not the requested normal-session max-age or max-turn automatic rotation policy.

## What This Changes

The issue requests configurable session max-age and max-turn limits that rotate long-lived agent sessions after safely preserving memory.

## Best Possible Solution

Approve one canonical opt-in core reset policy that combines age/turn triggers with safe memory handoff, continuity behavior, docs, and focused upgrade tests.
