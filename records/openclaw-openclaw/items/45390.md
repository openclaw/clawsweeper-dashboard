## Summary

Keep open: current main and the latest release still only support daily, idle, and manual session resets for normal sessions, while the requested max-age/max-turn automatic rotation remains a product/config design gap.

## What This Changes

Add configurable max-age and max-turn session rotation that saves memory, starts a fresh session, and logs the rotation when thresholds are exceeded.

## Best Possible Solution

Approve one opt-in core session lifecycle policy that covers age, turn, and handoff semantics with safe memory preservation, documentation, schema coverage, and focused upgrade tests.
