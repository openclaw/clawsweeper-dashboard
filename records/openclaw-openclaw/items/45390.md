## Summary

Keep open: current main and v2026.6.11 still provide daily, idle, manual, and thread-binding max-age lifecycle paths, but not the requested general max-age or max-turn automatic session rotation with safe memory handoff.

## What This Changes

Request add configurable max-age and max-turn session rotation that auto-saves memory, starts a fresh session, and logs the rotation.

## Best Possible Solution

Approve one opt-in session lifecycle policy under session.reset that adds max-age/max-turn triggers with schema, docs, focused tests, and explicit memory, transcript, delivery-route, and provider continuity semantics.
