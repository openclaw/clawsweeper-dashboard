## Summary

Keep open: current main and v2026.6.11 still support daily, idle, manual reset, compaction/memory flush, and thread-binding max age, but not the requested normal-session max-age or max-turn automatic rotation policy.

## What This Changes

The issue requests configurable automatic session rotation by max age or max turns, with memory preservation before the fresh session starts.

## Best Possible Solution

Define one maintainer-approved, opt-in normal-session rotation policy that covers max age, max turns, continuity/memory flush, transcript archive, provider-owned sessions, docs, schema, and upgrade behavior.
