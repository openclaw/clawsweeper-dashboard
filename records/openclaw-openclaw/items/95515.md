## Best Possible Solution

Land the schema-verified doctor guard in the open candidate PR after maintainer acceptance, or replace it with an equivalent fix that leaves schemaless external channel config untouched unless core can prove the target schema accepts the key.

## Solution Assessment

Yes: the best fix is the narrow conservative doctor write guard that skips schemaless external channels, with existing bundled-channel behavior covered by tests. The linked open PR appears to implement that direction, so this issue should stay open pending that review/merge path.
