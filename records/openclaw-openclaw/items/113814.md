## What This Changes

The PR makes the embedded-agent stream normalizer recover an allowed tool name when a provider appends XML-like quote or angle-bracket fragments, while leaving unknown prefixes unchanged.

## System Context

The embedded-agent runner receives streamed assistant tool-call blocks from provider runtimes and normalizes their names against the tools enabled for that request. The normalized name then drives tool dispatch and unknown-tool retry handling.
