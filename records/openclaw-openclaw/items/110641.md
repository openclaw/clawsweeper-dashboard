## Summary

Keep this PR open, but do not merge it: the new safe-only window helper skips a valid exact boot echo when its only 80-code-unit windows cross a surrogate-pair boundary, so the existing echo-suppression guarantee regresses.

## What This Changes

The PR replaces fixed-width raw UTF-16 slices in the gateway boot-echo guard with a shared safe-slicing wrapper and adds surrogate-boundary regression tests.

## Best Possible Solution

Preserve detection for every copied substring meeting the existing 80-code-unit threshold, including boundary-ending non-BMP text; only adopt Unicode-safe chunk semantics after a current-base failure demonstrates why raw code-unit equality is insufficient.
