  - confidence: 0.9

  - body: This branch makes channel posts reach command auth, but the auth context still uses only `msg.from` for `senderId`. Telegram channel posts normally carry the posting identity in `sender_chat`, and shared command auth does not fall back to `From` for group-like contexts, so configured `commands.allowFrom` or owner allowlists can reject the intended channel identity.
  - confidence: 0.88

  - body: Enabling channel_post native commands also enables commands that emit inline buttons, but the callback handler still classifies `chat.type === "channel"` as non-group. Those follow-ups can be authorized with direct rules and resolve state through the clicking user's direct context instead of the channel conversation.
  - confidence: 0.84
