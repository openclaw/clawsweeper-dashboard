Channel command follow-ups can be dropped or mutate the wrong session unless callbacks are routed through the channel conversation.
  - confidence: 0.84

  - body: The PR skips allowlist authorization for channel posts here and later authorizes them by explicit groupConfig only. Deployments that configured per-chat sender allowFrom or allowlist-style channel policy can have that restriction bypassed for newly enabled native commands, so the security semantics need to be preserved or explicitly failed closed.
