## What This Changes

The PR updates Telegram native command handling and keying to read channel_post via ctx.msg, treats channel posts as group-like for command authorization, and adds channel-post auth and sequential-key tests.

## Best Possible Solution

Define one maintainer-approved Telegram channel_post command policy, implement authorization and callback/session routing against that policy, keep the same-author policy issue linked, and require focused tests plus redacted live Telegram proof before merge.
