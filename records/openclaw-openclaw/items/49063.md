  - body: For channel posts with useAccessGroups disabled and no commands.allowFrom, this branch builds an empty authorizer list and modeWhenAccessGroupsOff "configured" allows the command. That contradicts the PR's explicit-chat boundary and can authorize slash commands from any readable channel.
  - confidence: 0.86

  - body: When commands.allowFrom is configured, this path depends on SenderId from msg.from, but Telegram channel posts usually carry the channel identity in sender_chat.   - confidence: 0.84
- **[P1] Keep channel callbacks in channel session context:** `extensions/telegram/src/bot-native-commands.ts:602`
  - body: Switching native commands to ctx.msg makes channel commands with inline buttons reachable, but the callback handler still classifies channel chats as non-group and uses DM-style authorization/session routing. Interactive commands such as model selection can be dropped or mutate the wrong session after the initial channel command succeeds.
  - confidence: 0.83
