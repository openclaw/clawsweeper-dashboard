## What This Changes

Repair macOS external-camera snapshots so capture retains a suitable uncropped landscape device format instead of switching to a portrait format when the AVCapture session starts.

## System Context

A gateway camera command is sent to an approved macOS node, where the native capture service configures an AVFoundation session and returns a JPEG through the gateway. The affected decision is the device-format selection between session startup and photo capture, which determines the captured image dimensions and crop.

## Architecture Diagram

flowchart LR
  A[Gateway camera snap command] --> B[Approved macOS node]
  B --> C[Native camera capture service]
  C --> D[AVFoundation session startup]
  D --> E[Device format selection]
  E --> F[JPEG returned through gateway]

## Best Possible Solution

Add a generalized macOS capture-format selection step after session startup and before warm-up/capture, choose from the camera’s advertised formats using requested capture constraints and a documented landscape preference, and prove that it preserves uncropped output on the reported webcam without adding a new user configuration surface.
