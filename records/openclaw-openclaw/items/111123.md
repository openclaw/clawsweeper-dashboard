## What This Changes

The PR makes Anthropic OAuth token responses fail on malformed UTF-8 at the shared HTTP decode point and adds a refresh-flow regression test using an invalid response byte.

## System Context

Anthropic OAuth exchanges and refreshes read an HTTP token response, decode it, validate its JSON credentials, and return credentials for later provider use. This change sits at the byte-to-text boundary so malformed network data fails before it can be parsed and retained as an access or refresh token.
