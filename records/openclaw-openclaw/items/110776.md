## Summary

This PR has strong real-session proof and fixes the descriptor-read race raised in the prior review, but it still changes the established project-instruction contract: an existing `AGENTS.md` or `CLAUDE.md` over 1 MiB is now omitted from the session prompt. The repository policy treats removed fallback/compatibility behavior as merge-sensitive, so a session-area owner must explicitly choose the upgrade behavior before merge.

## What This Changes

The PR replaces unbounded reads of session project-context and file-backed system-prompt files with descriptor-level bounded reads, using 1 MiB for context files and 10 MiB for prompt inputs.

## Best Possible Solution

Keep descriptor-bounded reads for untrusted prompt-input files, then have a session-area owner explicitly approve a documented project-instruction size contract or adjust the context-file path to preserve existing behavior while bounding memory use.
