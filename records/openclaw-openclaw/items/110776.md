Full review comments:

- **[P2] Read through a bounded descriptor, not after a separate stat:** `src/agents/sessions/resource-loader.ts:63-80`
  - body: `statSync(filePath)` validates one pathname, but `readFileSync(filePath)` opens it again. A concurrent replacement between those calls can make the second open target a multi-GB regular file, bypassing the cap and retaining the OOM path this PR is meant to remove. Open the file once, validate its descriptor, and perform a bounded read from it.
  - confidence: 0.96
- **[P1] Do not silently drop existing oversized project context:** `src/agents/sessions/resource-loader.ts:104`
  - body: This applies the new 1 MiB policy to auto-discovered `AGENTS.md`/`CLAUDE.md`, whereas current main loads any readable candidate into the agent context. Existing repositories above the threshold will start without their instructions after upgrade. Preserve that behavior or obtain explicit owner approval for the compatibility break and prove the selected upgrade path.
  - confidence: 0.93
