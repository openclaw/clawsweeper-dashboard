## Summary

Keep this PR open: it has credible real session-startup proof and addresses a real bounded-read problem, but it still changes the established project-context contract by dropping any existing `AGENTS.md` or `CLAUDE.md` over 1 MiB, and the new descriptor reader does not respect a short `readSync` result after a concurrent truncation.

## What This Changes

The PR replaces unbounded session resource-loader reads for project context and file-backed system prompts with descriptor-based reads capped at 1 MiB and 10 MiB respectively, with focused tests.

## Best Possible Solution

Preserve existing project-context loading until a session-area owner explicitly accepts a size-limit policy, then make the bounded reader return only bytes actually read and retain the tested caps for explicitly supplied prompt files.
