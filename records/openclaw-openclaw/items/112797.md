## What This Changes

This PR makes `openclaw doctor` warn and emit a structured health finding when an old `identity/device-auth.json` store still needs migration into SQLite.

## System Context

The device-auth store supplies locally cached credentials for Gateway connections, while Doctor inspects the same local state and tells operators how to repair upgrade problems. This change lets Doctor detect the retired JSON store before the token loader suppresses normal device-token diagnostics.
