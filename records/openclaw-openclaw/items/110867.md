## Summary

Keep this PR open: the sentinel approach addresses the reported unreachable-breaker path, but the current streak scan lets a veto bridge across a later changed tool outcome and can prematurely trip the global circuit breaker.

## What This Changes

The branch gives tool-loop vetoes a stable result-hash sentinel, counts that sentinel in no-progress streaks, and adds a regression test for the global circuit breaker.

## Best Possible Solution

Preserve the sentinel-based accounting only within one unchanged outcome run: a changed ordinary result hash must reset the streak even when a tool-loop veto appears between the two outcomes.
