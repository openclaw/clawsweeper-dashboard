## Summary

## What This Changes

The PR caps multiselect `maxSelections` at the supplied option count and adds unit coverage for zero-, one-, and multi-option inputs.

## Best Possible Solution

Make `poll-runtime` accept only normalized option counts of at least two, reject invalid counts explicitly, preserve current behavior for valid polls, and cover both the public SDK entrypoint and a real terminal invocation.
