## What This Changes

The PR changes agent-session command execution so a caller-provided AbortSignal causes the returned promise to reject after cancelling the child process, while timeout-triggered termination still resolves with a killed result.

## System Context

Agent session tools run local commands for agent and plugin workflows. A plugin-facing execution helper forwards command options, including cancellation, to the session runner, which starts and terminates the child process before returning a result or error to the caller.
