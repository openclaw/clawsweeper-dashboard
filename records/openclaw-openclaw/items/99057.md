## Best Possible Solution

Land the Matrix plugin fix if maintainers want message reads and pins to be display-oriented while keeping raw pin `events`; otherwise add an explicit raw timeline path instead of making the shared table formatter handle Matrix internals.

## Reproduction Assessment

## Solution Assessment

Yes, with a compatibility caveat. Normalizing at the Matrix plugin result boundary keeps the shared formatter generic and preserves raw pin events, while timestamp-based edit dedupe is a reasonable owner-local fix for Matrix streaming noise.
