## Summary

## What This Changes

The PR renames the Codex plugin destructive-action policy value from `"always"` to `"ask"` across manifest schema, runtime policy, persisted bindings, migration code, docs, and focused tests.

## Best Possible Solution

Keep the `"ask"` rename, but preserve Codex's app-scoped `apps.<id>.approvals_reviewer` routing, remove the whole-thread/turn/fork reviewer override, and require maintainer sign-off plus real approval-flow proof before merge.

## Reproduction Assessment

## Solution Assessment

No. The rename is a useful direction, but the safest implementation is to keep reviewer routing app-scoped through Codex's supported app config and treat the hard config cut as a maintainer-approved compatibility decision.
