## What This Changes

Repairs Docker sandbox filesystem-stat handling so Codex native writes through the sandbox exec-server can probe mount roots, report missing parents as not found, and inspect existing directories.

## System Context

The sandbox filesystem bridge translates Codex exec-server file RPCs into guarded operations against Docker-mounted workspace paths. Its stat result controls whether Codex can create parent directories and retry a native file write without bypassing OpenClaw's mount and path-safety checks.
