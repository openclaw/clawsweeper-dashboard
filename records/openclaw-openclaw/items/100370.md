## Summary

Keep open for normal maintainer review: current main still tears down inactive Voice Wake by touching `AVAudioEngine.inputNode`, while this PR uses the recognition request as the pipeline sentinel and has sufficient simulator launch proof with no blocking findings.

## What This Changes

The branch changes iOS VoiceWakeManager teardown to skip `inputNode.removeTap` unless a recognition pipeline existed, and adds release-note entries for that iOS fix.

## Best Possible Solution

Land the narrow teardown guard after normal maintainer review, preserving active and failed-start tap cleanup while avoiding audio input initialization for inactive stops.
