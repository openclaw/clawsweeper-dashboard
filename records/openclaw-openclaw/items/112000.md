## What This Changes

The PR replaces trust-worded inbound prompt-context labels with plain labels carrying a provenance marker, renames related channel-context SDK APIs with deprecated aliases, moves the remaining `System:` protection to the queued-event boundary, and adds Doctor repairs for legacy session and memory data.

## System Context

Channel adapters and plugins assemble externally sourced context into the user-role prompt, which is then rendered in session history, UI clients, tracing, and memory recall. This PR changes how injected context is identified across those producers and consumers, while Doctor migrates persisted prompt-bearing data to the new canonical form.
