This PR changes inbound prompt-context rendering to use plain labels with a fixed provenance marker, renames related plugin SDK context identifiers with temporary aliases, removes the system-tag sanitizer, and adds Doctor repairs for legacy transcript and memory rows.

The changed code decides which text is marked or normalized before it reaches model-bound system-event rendering, transcript displays, memory capture, and plugin SDK consumers.
