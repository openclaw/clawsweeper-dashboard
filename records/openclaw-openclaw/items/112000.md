## Summary

Keep this PR open for maintainer review. The latest branch still removes the shared sanitization boundary from queued system events while retaining arbitrary multiline external event text; a newline followed by `System:` can therefore be rendered as another system-style prompt line outside the hook-specific whitespace collapse. ## What This Changes

This PR replaces trust-worded inbound prompt-context labels with plain labels plus a provenance marker, renames related plugin SDK context fields with deprecated aliases, removes the system-tag sanitizer, and adds Doctor repairs for affected transcripts and LanceDB rows.

## System Context

Inbound messages and channel metadata are assembled into model-bound prompt context, persisted session transcripts, and optional memory recall records. Separately, gateway and channel events enter a per-session system-event queue that later renders text into the agent prompt.
