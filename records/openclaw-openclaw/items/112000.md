## Summary

Keep this PR open for maintainer review. The latest patch removes the only queue-boundary rewrite that prevented newline-delimited external event text from becoming additional `System:` lines when formatted for a model prompt; the proposed marker covers inbound context blocks, but not generic system-event text.

## What This Changes

This PR changes OpenClaw-generated inbound context to plain labels with a provenance suffix, renames related channel-context SDK APIs with deprecated aliases, removes the broad system-tag sanitizer, and adds Doctor repairs for legacy transcript and LanceDB data.

## System Context

Channel and gateway inputs are assembled into a model-visible user prompt, while operational events enter a separate per-session system-event queue before being formatted as `System:` prompt lines. The PR changes both the inbound-context identification scheme and the safety treatment of text that can flow into transcripts, memory, UI displays, and the system-event prompt prelude.

Keep the plain-label marker refactor, but restore a narrow queue-boundary invariant that prevents queued text from producing a second `System:` render line, retain a focused multiline regression test, and then have the prompt/security owners re-evaluate the intended removal of cosmetic bracket rewriting separately.
