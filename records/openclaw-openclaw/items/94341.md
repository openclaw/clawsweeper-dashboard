## Summary

This PR is still necessary only if maintainers choose to make `agentDir` a second bootstrap authority, but the current patch does not activate that behavior in the primary embedded runtime because its caller omits `agentId`. The authority and upgrade policy also needs explicit maintainer direction before merge.

## What This Changes

The PR loads bootstrap files from an explicitly configured per-agent `agentDir`, gives them precedence over same-named workspace files, and suppresses `agentDir/BOOTSTRAP.md` after setup completion.
