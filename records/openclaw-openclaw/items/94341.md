## Summary

This PR should stay open but should not merge as written: current OpenClaw documentation and architecture make the workspace the bootstrap authority and `agentDir` the state/credential directory, while per-agent workspaces already provide the requested customization. The remaining choice is a maintainer product and security-boundary decision, and the submitted proof is unit-test-only.

## What This Changes

The PR loads bootstrap files from an explicitly configured per-agent `agentDir`, merges them with workspace files, and gives same-named `agentDir` files precedence.

## Best Possible Solution

Keep each agent's workspace as the single bootstrap authority, direct per-agent customization through `agents.list[].workspace`, and add a clear warning or doctor-style recovery when bootstrap-named files are detected in `agentDir`.
