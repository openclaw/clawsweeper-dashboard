## Summary

Keep this PR open for an explicit maintainer decision: the reported silent misconfiguration is credible, but making `agentDir` an overriding instruction source conflicts with the documented workspace authority, duplicates the existing per-agent workspace mechanism, and widens a security-sensitive boundary without live upgrade proof.

## What This Changes

This PR loads bootstrap files from an explicitly configured per-agent `agentDir`, gives them precedence over workspace files, and derives the agent identity from session keys when necessary.

## Best Possible Solution

Keep each agent's configured workspace as the single bootstrap authority and add an actionable warning or Doctor repair for bootstrap-named files found in `agentDir`; only adopt dual roots after maintainers explicitly define and document precedence, threat boundaries, migration behavior, and live proof.
