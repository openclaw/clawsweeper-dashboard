## Summary

Keep this PR open for an explicit product decision, but do not merge its current direction: it turns a directory documented for private runtime and authentication state into a second prompt-instruction authority, duplicating the existing per-agent workspace mechanism and allowing previously inert files to override agent behavior.

## What This Changes

The PR loads standard bootstrap files from an explicitly configured per-agent agentDir, gives them precedence over same-named workspace files, and excludes agentDir BOOTSTRAP.md after setup completes.

## Best Possible Solution

Preserve workspace as the single bootstrap authority, direct per-agent customization through agents.list[].workspace, and add an actionable warning when bootstrap-named files are found in agentDir; only adopt dual-source loading after an explicit maintainer decision plus documented precedence, upgrade behavior, isolation coverage, and live proof.
