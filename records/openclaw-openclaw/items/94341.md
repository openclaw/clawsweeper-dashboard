## Summary

Keep open: the documented runtime contract makes each agent’s configured workspace the bootstrap-context authority, while this branch adds the state-oriented `agentDir` as an overriding prompt source without the required product/security decision or live runtime proof. ([github.com](https://github.com/openclaw/openclaw/blob/main/docs/concepts/agent-workspace.md))

## What This Changes

The PR loads bootstrap files from an explicitly configured per-agent `agentDir`, gives those files precedence over workspace copies, and derives the agent id from session keys when needed.

## Best Possible Solution

Keep the configured per-agent workspace as the single bootstrap authority and add a clear runtime/Doctor warning for bootstrap-named files misplaced in `agentDir`; adopt a second root only through an explicit, documented opt-in contract with precedence and upgrade proof.
