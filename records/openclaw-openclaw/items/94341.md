## Summary

Keep this PR open for an explicit maintainer decision, but do not merge it as written: the report identifies real silent confusion, while the patch changes the documented bootstrap trust boundary and precedence without live runtime proof.

## What This Changes

The branch loads bootstrap files from an explicitly configured per-agent `agentDir`, gives them precedence over workspace copies, and derives the agent id from session keys for background invocations.

## Best Possible Solution

Keep `agents.list[].workspace` as the sole bootstrap authority, emit an actionable warning when bootstrap-named files are misplaced in `agentDir`, document the distinction, and prove the warning in a real multi-agent CLI or Gateway run.
