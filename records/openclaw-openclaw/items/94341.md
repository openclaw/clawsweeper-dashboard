## Summary

Keep open: current main and the latest release still load bootstrap files from `workspaceDir` only, but this PR changes prompt authority by allowing explicit `agentDir` files to override workspace bootstrap files. That may be the right policy, but it still needs maintainer/security approval, real-run proof, and diagnostic/docs alignment before merge.

## What This Changes

The PR changes `src/agents/bootstrap-files.ts` so explicitly configured per-agent `agentDir` bootstrap files are merged with workspace bootstrap files and can override same-named workspace files.

## Best Possible Solution

Land one maintainer-approved bootstrap policy: either explicit configured-agentDir precedence with diagnostics, docs, focused tests, and real-run proof, or warning-only diagnostics that keep workspace as the canonical bootstrap source.
