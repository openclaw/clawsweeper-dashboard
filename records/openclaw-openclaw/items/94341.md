## Summary

Keep this PR open for an explicit bootstrap-authority decision, but do not merge the current override behavior: current source and public docs define each agent’s configured workspace as the bootstrap context root, while `agentDir` owns runtime state. The latest head still lets same-named files in `agentDir` silently replace workspace instructions, and the PR provides focused tests rather than after-fix runtime proof.

## What This Changes

The PR loads bootstrap files from an explicitly configured per-agent `agentDir` and gives them filename-based precedence over files from the configured workspace.

## Best Possible Solution

Keep the configured per-agent workspace as the single bootstrap authority and add a clear diagnostic when standard bootstrap filenames are found in `agentDir`; if maintainers instead want two roots, define explicit precedence and trust semantics, align docs and tests, and prove fresh-install and upgrade behavior before merging.
