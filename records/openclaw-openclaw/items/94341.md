## Summary

Keep this PR open but do not merge it as-is: the primary embedded-agent caller does not pass `agentId`, so the new branch is skipped in normal runs, while the broader decision to make `agentDir` an instruction source still needs explicit ownership approval and live proof.

## What This Changes

The branch loads bootstrap files from an explicitly configured per-agent `agentDir`, gives same-named files precedence over workspace files, and suppresses `BOOTSTRAP.md` after setup.

## Best Possible Solution

Keep per-agent workspaces as the canonical bootstrap source and add a clear warning or Doctor-style recovery for bootstrap files misplaced in `agentDir`; only add `agentDir` prompt authority if maintainers explicitly approve that boundary, document precedence, cover every caller, and prove both fresh and upgrade behavior.
