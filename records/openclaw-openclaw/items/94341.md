## Summary

The reported silent ignore is real, but this patch changes the product contract by making the per-agent state/auth directory a second bootstrap authority; current code, docs, and CLI already define each agent’s configured workspace as the bootstrap and instruction boundary.

## What This Changes

The PR loads bootstrap files from an explicitly configured `agentDir`, merges them with workspace files, and gives same-named `agentDir` files precedence.

## Best Possible Solution

Keep the configured workspace as the sole bootstrap authority and add an actionable diagnostic that directs misplaced `agentDir` bootstrap files to that agent’s `agents.list[].workspace`; adopt dual-root loading only after an explicit maintainer decision with updated setup, docs, upgrade behavior, and security proof.
