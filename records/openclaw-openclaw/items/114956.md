## What This Changes

This PR caches the macOS gateway-profile registry after its first Keychain read and gives DEBUG builds separate Keychain service names for gateway profiles and onboarding route bindings.

## System Context

The macOS app reads saved gateway profiles from the login Keychain whenever its dashboard refreshes the gateway catalog. Those profiles determine which gateway connections appear next in the dashboard and can trigger Keychain access prompts when the stored item’s ACL does not admit the running binary.
