## Summary

Keep open: the force-pushed head still value-imports the Copilot SDK converter during module evaluation, so fallback-only installations can fail before the plugin’s documented loader and actionable missing-SDK error run; the prior P1 finding remains, and the PR still lacks after-fix fallback-path proof.

## What This Changes

The PR replaces Copilot-local session-compaction and tool-result adapters with contracts from the pinned Copilot SDK.

## Best Possible Solution

Keep the SDK-owned result converter, but obtain it from the module returned by `loadCopilotSdk` or inject it after loading so package-local lookup, fallback lookup, and `COPILOT_SDK_MISSING` remain one canonical path.

## Solution Assessment
