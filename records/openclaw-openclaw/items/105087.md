## Summary

Current main still reproduces the reported await cycle: the channel keeps reconnect blocked while awaiting session-owned disconnect cleanup, and that cleanup can suspend indefinitely in an owner callback. The direct fix remains open at https://github.com/openclaw/openclaw/pull/105091, so this issue is still necessary until that PR lands or is rejected.

## What This Changes

Fix the macOS app node watchdog so suspended disconnect lifecycle cleanup cannot permanently block transport reconnection.

## Best Possible Solution

Land the focused session-owner repair that lets GatewayChannelActor complete teardown and reconnect immediately while GatewayNodeSession retains lifecycle-generation and admission barriers for cleanup, readiness, and invoke dispatch.
