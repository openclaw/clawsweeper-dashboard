## Summary

Keep open: current main still tombstones Telegram isolated-ingress handler-timeout and retry-limit failures without automatic replay or a user-visible failure reply; newer channel-status plumbing partially improves operator visibility, but it does not close the central message-loss policy gap.

## What This Changes

The issue reports that Telegram isolated ingress dead-letters timed-out spooled updates without replay, user notice, or durable operator recovery visibility.

## Best Possible Solution

Adopt one Telegram-owned failed-spool policy: keep lane-unblocking tombstones, but add a deliberate user-notice and durable operator recovery surface unless maintainers explicitly choose a one-shot replay rule for zero-attempt handler timeouts.
