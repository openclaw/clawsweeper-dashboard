## Summary

Keep open: current main and the latest release still dead-letter timed-out Telegram isolated-ingress updates as failed tombstones while suppressing the normal user-facing fallback, so the reported silent-loss policy gap remains real.

## What This Changes

The issue requests a Telegram isolated-ingress fix so handler-timeout or retry-limit dead-lettered spooled updates are not silent to the sender or invisible to operators.

## Best Possible Solution

Define a Telegram failed-ingress policy that preserves duplicate-safety while making handler-timeout and retry-limit tombstones actionable through operator visibility and a maintainer-approved user notice or guarded replay path.

Kind: product_direction

Question: For Telegram isolated-ingress failed tombstones, should OpenClaw preserve terminal dead-letter semantics with visibility/notification, or automatically replay handler-timeout rows that had zero attempts?

Rationale: The source-level failure is clear, but the permanent behavior affects duplicate delivery, reply-fence cleanup, retry policy, operator diagnostics, and Telegram user messaging, so maintainers need to choose the product contract before an automated fix is safe.

Likely owner: joshavant

Owner reason: joshavant authored the earlier spooled replay and stalled isolated spool handler lifecycle work that frames the duplicate-safety versus replay tradeoff.

Owner confidence: high

Options:

- **Surface And Notify Failed Tombstones (recommended):** Preserve terminal failed rows for unsafe timeout and retry-limit cases, add failed-ingress operator visibility, and send one duplicate-safe failure notice when a user message is dead-lettered.
- **Replay Handler-Timeouts Once:** Allow a guarded one-time replay for handler-timeout rows with zero attempts, but require proof that late original handlers cannot duplicate replies or session effects.
- **Operator Visibility Only:** Expose failed tombstones in status or doctor without Telegram user notices, accepting that senders may still see silence while operators get a repair path.
