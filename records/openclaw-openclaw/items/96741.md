## What This Changes

The PR adds an opt-in `diagnostics.otel.sessionAttribute` setting that exports a SHA-256 digest of the session key under three OpenTelemetry session/conversation attributes on root run spans.

## Best Possible Solution

Hash the event's opaque, rotating `sessionId` for each root-span path, retain default-off behavior, document that resets create a new telemetry group, and demonstrate enabled and disabled spans through a real redacted OTLP collector or backend.
