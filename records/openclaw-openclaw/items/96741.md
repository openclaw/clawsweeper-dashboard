## What This Changes

The PR adds an opt-in OpenTelemetry configuration option that exports a hashed session-derived identifier under three grouping attributes on root run spans, with schema, tests, and documentation.

## Best Possible Solution

Keep the feature opt-in, derive one centralized grouping value from the rotating high-entropy `sessionId` without falling back to `sessionKey`, cover all root-span creation paths, test reset isolation, document the pseudonymous-data boundary accurately, and provide redacted collector or backend output before merge.
