## What This Changes

Adds an opt-in `diagnostics.otel.sessionAttribute` setting that hashes a session-derived identifier into three OTel root-span attributes, with config metadata, tests, generated baselines, and documentation.

## Best Possible Solution

After owner approval, centralize identifier generation in one helper, derive it from the reset-bounded `sessionId`, emit only the approved standard/vendor compatibility attributes, describe the digest as pseudonymous rather than irreversible, and prove the emitted OTLP payload from a real collector.
