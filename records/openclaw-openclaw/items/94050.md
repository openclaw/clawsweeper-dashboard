## What This Changes

The PR makes nonzero foreground exec outcomes output-insensitive for loop detection, propagates structured failure identity through exec producers, and adds runtime-path tests and documentation.

## Best Possible Solution

Fingerprint stable repeated failures without letting volatile identifiers reset the breaker, but reset or preserve progress when intervening exec activity or meaningful nonzero output changes; cover both runaway retries and legitimate polling/interleaving with production-hook tests.
