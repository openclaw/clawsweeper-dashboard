## Summary

Keep this PR open for repair: common foreground commands that exit nonzero, including exit code 1, remain `completed`, so their varying output still prevents the critical/global no-progress streak from accumulating.

## What This Changes

The branch makes failed exec hashes ignore volatile output, propagates stable failure metadata through foreground exec producers, and adds production-path tests and loop-detection documentation.

## Best Possible Solution

Fingerprint completed exec outcomes with nonzero exit codes as stable failures—ignoring volatile output while retaining the exit code and stable termination facts—while continuing to treat changing output from exit-code-zero commands as progress.
