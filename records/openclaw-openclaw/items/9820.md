## Summary

Keep open. Current main and v2026.6.11 still do not support arbitrary JSONL extraPaths in the builtin memory indexer; session-memory and QMD paths are related alternatives, but maintainer product/security direction is still needed before broadening raw-log ingestion.

## What This Changes

Request native JSONL ingestion for memorySearch.extraPaths so raw message-log JSONL can be indexed without converting to Markdown.

## Best Possible Solution

Keep builtin extraPaths Markdown/multimodal-only unless maintainers sponsor JSONL; either document the supported QMD/session-memory/converter/plugin workflow or implement first-class line-aware JSONL with watcher, memory_get, tests, docs, and privacy guardrails.
