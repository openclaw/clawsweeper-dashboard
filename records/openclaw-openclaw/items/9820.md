## Summary

Keep open. Current main and the latest release still keep builtin memory extra path indexing Markdown/multimodal-oriented, while session JSONL indexing is a separate opt-in path; this request remains useful but needs explicit product/security direction before implementation.

## What This Changes

Requests native JSONL ingestion for builtin `memorySearch.extraPaths` so raw message logs can be indexed without converting them to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across builtin discovery, chunking, watching, `memory_get`, docs, and tests with privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
