## Summary

Keep open. Current main and the latest release still exclude arbitrary JSONL from builtin memory extra-path discovery, memory_get, and watcher filtering; the remaining work needs an explicit maintainer product/security decision rather than cleanup closure.

## What This Changes

Add native JSONL support to the builtin memory indexer so JSONL files in memorySearch.extraPaths can be discovered, chunked, searched, watched, and read without conversion.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across builtin discovery, parsing, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow.
