## Summary

Keep open: current main and the latest release still exclude arbitrary JSONL files from builtin `memorySearch.extraPaths`; the remaining work is useful but needs maintainer product and security direction before implementation.

## What This Changes

The issue requests native JSONL ingestion for builtin `memorySearch.extraPaths` so raw message-hook logs can be indexed without conversion.

## Best Possible Solution

Define a safe JSONL extra-path ingestion contract, or document the supported QMD, session-memory, converter, or plugin alternative if arbitrary raw JSONL is out of builtin scope.
