## Summary

The feature remains absent from current source and v2026.6.11, with no canonical replacement found. Keep this issue open for a maintainer decision: builtin extra paths remain document-oriented, while transcript JSONL uses a separate shaped and sanitized corpus, so arbitrary raw-log support changes privacy, visibility, deletion, and ownership contracts rather than only file admission.

## What This Changes

Add native JSONL ingestion to builtin memory extra paths so structured message logs can be semantically indexed without Markdown conversion.

## Best Possible Solution

Keep sanitized session search and QMD export as the default structured-history path; add generic JSONL only after approving a bounded record schema, explicit field sanitization, visibility and deletion behavior, size limits, line provenance, retrieval support, watcher behavior, docs, and focused tests.
