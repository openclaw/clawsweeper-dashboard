## Summary

Keep open. Current main still does not provide native JSONL ingestion for builtin `memorySearch.extraPaths`, and the remaining choice is a maintainer product/security decision rather than a narrow bug fix.

## What This Changes

The issue asks the builtin memory indexer to accept `.jsonl` files from `memorySearch.extraPaths` and chunk each JSONL line for semantic search.

## Best Possible Solution

Maintainers should choose and document the boundary: either implement builtin JSONL ingestion across discovery, parsing/chunking, line mapping, watching, `memory_get`, docs, and tests with explicit security expectations, or document the supported QMD/converter/plugin workflow for raw logs.
