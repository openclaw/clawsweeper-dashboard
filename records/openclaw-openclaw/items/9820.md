## Summary

Keep open. Current main still does not implement native JSONL support for builtin memorySearch.extraPaths, and the remaining choice is a product/security boundary decision rather than a narrow bug fix.

## What This Changes

Request native JSONL ingestion for builtin memorySearch.extraPaths so raw message logs can be indexed and recalled without conversion to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement first-class line-aware JSONL support across builtin discovery, chunking, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
