## Summary

Keep open. Current main and v2026.6.11 still exclude arbitrary JSONL files from builtin memory extra-path discovery, memory_get, and watcher filtering, while raw-log ingestion remains a product and security decision.

## What This Changes

Request native JSONL ingestion for builtin memorySearch.extraPaths so raw message-log JSONL can be indexed and searched without conversion.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, chunking, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow.
