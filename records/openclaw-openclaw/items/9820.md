## Summary

Keep open. Current main and the latest release still keep builtin memory extra-path ingestion Markdown/multimodal-only, while arbitrary JSONL raw-log ingestion remains a product and security-boundary decision.

## What This Changes

The issue requests native JSONL indexing for `memorySearch.extraPaths` so raw message-log JSONL can be searched without a converter.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, watching, `memory_get`, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow.
