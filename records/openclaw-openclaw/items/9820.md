## Summary

Keep open. Current main still admits only Markdown plus enabled multimodal files for builtin memorySearch.extraPaths, while JSONL support remains limited to the separate opt-in session transcript path; native raw JSONL ingestion needs maintainer product and security direction.

## What This Changes

Request native JSONL support for memorySearch.extraPaths so raw message log JSONL files can be indexed without first converting them to Markdown.

## Best Possible Solution

Define one product contract: either first-class builtin JSONL ingestion with parsing, line mapping, redaction/visibility, memory_get, watcher, docs, and tests, or document that raw hook logs should use QMD/session-memory or a converter plugin instead.
