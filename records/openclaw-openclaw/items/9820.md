## Summary

Keep open. Current main and the latest release still keep builtin memorySearch.extraPaths to Markdown plus enabled multimodal files, while JSONL support remains limited to opt-in session transcript indexing; the remaining decision is whether arbitrary raw JSONL logs belong in builtin memory at all.

## What This Changes

The issue requests native JSONL ingestion for memorySearch.extraPaths so raw message hook logs can be semantically indexed without conversion.

## Best Possible Solution

Keep this open until maintainers either sponsor line-aware builtin JSONL ingestion with privacy guardrails or document the supported QMD, session-memory, converter, or plugin-owned workflow for raw-log recall.
