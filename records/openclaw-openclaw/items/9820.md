## Summary

Keep open. Current main still does not index arbitrary `.jsonl` files from builtin `memorySearch.extraPaths`, and the existing session transcript JSONL parser is a separate sanitized session-memory path rather than general raw-log ingestion.

## What This Changes

Request to add native JSONL support to builtin `memorySearch.extraPaths` so raw message logs can be indexed without converting them to Markdown.

## Best Possible Solution

Either keep builtin extraPaths Markdown/multimodal-only and document the QMD/session-memory or converter-plugin workflow, or approve a scoped builtin JSONL parser with sanitization, line mapping, watcher coverage, `memory_get` support, docs, and tests.
