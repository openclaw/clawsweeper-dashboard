## Summary

Keep open: current main and v2026.6.11 still exclude arbitrary JSONL files from builtin `memorySearch.extraPaths`; this remains a useful memory feature request, but implementation needs maintainer product and security direction.

Request native JSONL ingestion for builtin memory indexing so raw message logs in `memorySearch.extraPaths` can be searched without converting them to Markdown.

## Best Possible Solution

Define a safe JSONL extra-path ingestion contract, or document the supported QMD, session-memory, converter, or plugin alternative if arbitrary raw JSONL is out of builtin scope.
