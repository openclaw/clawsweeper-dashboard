- `impact:session-state`: The request affects whether raw conversation logs can become searchable durable memory and later retrieved context.

## Summary

Keep open: current main still filters builtin memorySearch.extraPaths to Markdown or enabled multimodal files, while session JSONL indexing is a separate sanitized transcript path. The gap is real, but arbitrary raw JSONL ingestion needs maintainer product and security direction before implementation.

## What This Changes

Request native JSONL ingestion for memorySearch.extraPaths so raw message-log records can be chunked and embedded without converting them to Markdown.

## Best Possible Solution

Keep this open until maintainers define a complete JSONL extra-path ingestion contract or document the supported converter, QMD, session-memory, or plugin alternative.

## Reproduction Assessment

Yes, at source level: current main still rejects ordinary .jsonl files from builtin extra-path discovery and memory_get, and watcher/indexing paths remain Markdown or enabled multimodal only. I did not run a live indexing command because this is a read-only review and the source path is sufficient.

## Solution Assessment

Unclear. The proposed extension-list change is not sufficient by itself; the durable fix needs one contract for admission, JSONL parsing/chunking, line mapping, memory_get, watcher behavior, docs, tests, and redaction/security semantics.
