## Summary

Keep open. Current main and the latest release still keep builtin memory extra paths Markdown/multimodal-only; arbitrary JSONL ingestion remains a product and security decision rather than implemented behavior.

## What This Changes

The issue requests native JSONL ingestion for `memorySearch.extraPaths` so raw message logs can be indexed without converting them to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across builtin discovery, parsing, chunking, watching, `memory_get`, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
