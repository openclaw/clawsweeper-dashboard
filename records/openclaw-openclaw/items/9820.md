## Summary

Keep open. Current main and v2026.6.11 still limit builtin memory extra paths to Markdown plus enabled multimodal files; arbitrary JSONL ingestion remains a product/security decision rather than implemented behavior.

## What This Changes

Request native JSONL ingestion for builtin memory indexing so raw message logs in `memorySearch.extraPaths` can be searched without converting them to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, chunking, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
