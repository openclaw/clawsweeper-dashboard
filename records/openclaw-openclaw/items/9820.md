## Label Justifications

- `P2`: This is a normal-priority memory indexing enhancement with a documented Markdown-conversion workaround and no evidence of urgent runtime breakage.
- `impact:session-state`: The request affects whether raw conversation logs can become searchable durable memory and retrieved context.

## Summary

Keep open: current main and v2026.6.11 still exclude arbitrary JSONL from builtin extra-path memory indexing, and implementing it needs maintainer product/security direction rather than conservative cleanup closure.

## What This Changes

Request native JSONL ingestion for builtin `memorySearch.extraPaths` so raw message logs can be indexed and recalled without converting them to Markdown.

## Best Possible Solution

Define one safe JSONL extra-path contract across admission, parsing/chunking, line mapping, `memory_get`, watcher behavior, docs, tests, and redaction, or document the QMD/session-memory/converter/plugin alternative.
