## Summary

Keep open: current main and v2026.6.11 still exclude plain JSONL from builtin memorySearch.extraPaths, and the remaining work needs a product/security contract rather than cleanup closure.

## What This Changes

Request native JSONL ingestion for builtin memorySearch.extraPaths so raw message logs can be indexed without converting them to Markdown.

## Best Possible Solution

Define a safe JSONL extra-path ingestion contract, or document the supported QMD, session-memory, converter, or plugin alternative if arbitrary raw JSONL is out of builtin scope.
