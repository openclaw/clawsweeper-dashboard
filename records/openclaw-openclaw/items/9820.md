## Summary

Keep open. Current main and the latest release still keep builtin memory extra-path ingestion Markdown/multimodal-oriented, while arbitrary raw JSONL log ingestion needs an explicit product and security decision before implementation.

## What This Changes

The issue requests native JSONL ingestion for `memorySearch.extraPaths` so raw message-hook logs can be indexed and retrieved without converting them to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, chunking, watching, `memory_get`, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
