## Summary

Keep open. Current main and v2026.6.11 still keep builtin memory extra-path ingestion Markdown/multimodal-oriented, while native JSONL support for arbitrary raw message logs remains a product and security decision.

## What This Changes

The issue requests native JSONL ingestion for builtin memorySearch.extraPaths so raw message-hook logs can be indexed and searched without converting them to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, chunking, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
