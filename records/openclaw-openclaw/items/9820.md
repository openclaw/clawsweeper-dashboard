## Summary

Keep open: current main still excludes arbitrary JSONL files from builtin memorySearch.extraPaths, and the remaining work needs a product and security decision rather than cleanup closure.

## What This Changes

The issue requests native JSONL ingestion for the memory indexer so raw message-log files in memorySearch.extraPaths can be semantically searched without converting them to Markdown.

## Best Possible Solution

Define a safe JSONL extra-path ingestion contract, or document the supported QMD, session-memory, converter, or plugin alternative if arbitrary raw JSONL is out of builtin scope.
