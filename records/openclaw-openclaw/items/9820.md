## Summary

Keep open. Current main and v2026.6.11 still keep builtin memory extra-path indexing Markdown/multimodal-oriented, while existing session JSONL handling is a separate session-transcript path; the remaining blocker is a maintainer product/security decision about arbitrary raw-log ingestion.

## What This Changes

Add native JSONL ingestion and chunking for memorySearch.extraPaths so raw message logs can be indexed without converting them to Markdown.

## Best Possible Solution

Make an explicit product/security choice, then either implement JSONL across discovery, parsing, line-aware indexing, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin path.
