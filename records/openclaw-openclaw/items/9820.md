## Summary

Keep open. Current main and the latest release still limit builtin memory extra paths to Markdown plus enabled multimodal files, while arbitrary JSONL raw-log indexing remains an unresolved product and security decision.

## What This Changes

Request native JSONL ingestion for memorySearch.extraPaths so raw message logs can be indexed without a converter.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, chunking, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
