## Summary

Keep open. Current main and v2026.6.11 still restrict builtin memory extraPaths to Markdown or enabled multimodal files, while JSONL handling is scoped to opt-in session transcript indexing; arbitrary raw-log ingestion needs maintainer product and security direction.

## What This Changes

The issue requests native JSONL ingestion for memorySearch.extraPaths so raw message logs can be indexed without converting them to Markdown.

## Best Possible Solution

Maintainers should either sponsor first-class line-aware JSONL support with privacy guardrails across discovery, parsing, watcher, memory_get, docs, and tests, or document the supported non-builtin workflow for raw log recall.
