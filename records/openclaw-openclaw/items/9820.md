## Summary

Keep open: current main and the latest release still exclude arbitrary JSONL files from builtin `memorySearch.extraPaths`; the request is clear, but it needs maintainer product and security direction before implementation.

## What This Changes

The issue requests native JSONL ingestion for builtin memory indexing so raw message-log files in `memorySearch.extraPaths` can be searched without conversion to Markdown.

## Best Possible Solution
