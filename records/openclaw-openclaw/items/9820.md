## Summary

Keep open. Current main and the latest release still do not implement native JSONL ingestion for builtin memorySearch.extraPaths; the remaining decision is whether raw-log JSONL belongs in builtin memory at all or should be documented as a QMD/session-memory/converter/plugin workflow.

## What This Changes

The issue requests native JSONL ingestion for builtin memory indexing so raw message-log files in memorySearch.extraPaths can be semantically indexed without conversion.

## Best Possible Solution

Keep this open until maintainers choose and document the supported raw-log memory path; either implement complete builtin JSONL support across discovery, parsing, watching, memory_get, docs, and tests, or point users to QMD/session-memory/converter/plugin workflow.
