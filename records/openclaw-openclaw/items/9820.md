## Summary

Keep open. Current main and the latest release still exclude plain JSONL from builtin memory extra-path indexing, while session JSONL and QMD are separate alternatives; this needs a maintainer product/security decision before implementation.

## What This Changes

Request to make builtin `memorySearch.extraPaths` index raw `.jsonl` logs as line-aware semantic memory instead of requiring conversion to Markdown.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, chunking, watching, `memory_get`, docs, and tests with privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
