## Summary

Keep open: current main and the latest release still exclude arbitrary JSONL files from builtin `memorySearch.extraPaths`, and the remaining work needs an explicit product and security decision rather than cleanup closure.

## What This Changes

The issue requests native JSONL ingestion for builtin memory indexing so raw message-log files in `memorySearch.extraPaths` can be searched without conversion.

## Best Possible Solution

Define a safe JSONL extra-path ingestion contract, or document the supported QMD, session-memory, converter, or plugin alternative if arbitrary raw JSONL is out of builtin scope.
