## Summary

Keep open. Current main and the latest release still keep builtin memory extra-path ingestion Markdown/multimodal-oriented, and the remaining blocker is a maintainer product/security decision about arbitrary raw JSONL log ingestion.

## What This Changes

The issue requests native JSONL ingestion for builtin memory extra paths so raw message logs can be semantically indexed without conversion.

## Best Possible Solution

Make an explicit product/security choice: either implement line-aware JSONL support across discovery, parsing, chunking, watching, memory_get, docs, tests, and privacy guardrails, or document the supported QMD/session-memory/converter/plugin workflow instead.
