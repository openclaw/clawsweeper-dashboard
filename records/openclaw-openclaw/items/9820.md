## Summary

Keep open: current main still ignores plain `.jsonl` files in builtin memory `extraPaths`, and adding native ingestion needs a maintainer product/security decision rather than cleanup closure.

## What This Changes

The issue requests native JSONL ingestion for builtin memory indexing so raw message-log files in `memorySearch.extraPaths` can be searched without conversion to Markdown.

## Best Possible Solution

Maintainers should either approve a scoped builtin JSONL ingestion design covering parsing, line mapping, `memory_get`, watcher behavior, and sensitive-log guidance, or document the supported QMD/session-memory/converter/plugin workflow instead.
