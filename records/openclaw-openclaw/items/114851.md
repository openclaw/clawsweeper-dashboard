## What This Changes

Investigate and prevent Slack durable-ingress admission from delaying unrelated conversations while one hybrid execution/process turn remains active.

## System Context

Slack Socket Mode accepts inbound events, derives ingress lanes, and hands claimed events to the shared durable-ingress drain before the agent main lane can start a turn. A wait at the monitor/drain boundary can therefore delay otherwise independent Slack conversations even when downstream agent concurrency is available.

## Architecture Diagram

flowchart LR
  A[Slack Socket Mode events] --> B[Slack ingress adapter]
  B --> C[Durable ingress queue]
  C --> D[Ingress pump and lane claims]
  D --> E[Turn adoption]
  E --> F[Agent main lanes]
  F --> G[Slack replies]
  D --> H[Other pending conversations]

## Best Possible Solution

Make the durable-ingress pump admit independent ready lanes without waiting for a long adopted turn, while retaining ordering within the same Slack conversation or thread; add lifecycle timestamps and regression coverage for both same-thread and unrelated-conversation traffic.
