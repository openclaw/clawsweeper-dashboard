## Label Justifications

- `P1`: A default unrestricted agent-write path can now fail for existing hard-linked files or silently alter host-file access metadata on successful writes.
- `merge-risk: 🚨 compatibility`: The patch replaces prior in-place writes with a hard-link rejection and an inode swap that does not retain all existing destination properties.
- `merge-risk: 🚨 security-boundary`: Dropping ACLs or extended security metadata during agent-triggered host-file replacement can change access-control behavior beyond the requested content update.

## Summary

This PR has strong real-world evidence that sibling staging prevents interrupted unrestricted writes from truncating the original file, and it addresses the prior review’s read-only target concern. It is not ready to merge because the replacement changes two existing host-file contracts: valid hard-linked targets now fail, and replacing the inode drops metadata beyond owner and mode, including platform ACLs and extended attributes.

## What This Changes

The PR changes unrestricted agent write and edit operations to stage file content beside the resolved host destination and rename it into place only after the staged write completes.

## System Context

Agent write and edit tools accept a host path and content from an agent session, then update that filesystem target when workspace-only protection is disabled. This path feeds edit recovery and user-visible tool results, so it must preserve both file contents on failure and the pre-existing host-file access contract on success.

## Architecture Diagram

flowchart LR
  A[Agent write or edit request] --> B[Unrestricted host path]
  B --> C[Resolve destination and inspect target]
  C --> D[Stage sibling temporary file]
  D --> E[Check destination before replacement]
  E --> F[Rename staged content into destination]
  F --> G[Tool result or edit recovery]

## Best Possible Solution

Keep atomic staging for ordinary single-link files, but preserve the existing host-file contract for metadata-bearing and hard-linked targets through an explicitly approved compatibility strategy with focused cross-platform regression coverage.
