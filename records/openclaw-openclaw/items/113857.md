## What This Changes

The PR strengthens the internal Auto QA skill and four evidence guides so campaigns verify canonical clean source, live worker identity, real provider/session results, browser failures, and ongoing-soak provenance before treating evidence as valid.

## System Context

The Auto QA skill governs how OpenClaw maintainers conduct multi-lane product campaigns. It takes repository state, worker observations, Gateway/provider runs, and browser checks as inputs, then produces an evidence ledger used to assess and count validated campaign outcomes.
