## Summary

Keep open: the PR is aimed at the right user-visible bug and has useful terminal proof, but the current settlement can still leave embedded lifecycle state based on the previous tool-use assistant message because no `message_end`-driven terminal source is updated.

## What This Changes

The branch marks `MidTurnPrecheckSignal` with a private `Symbol.for` sentinel, makes `Agent.handleRunFailure` emit a non-error control-flow settlement for that sentinel, and adds Agent-level regression tests.

## Best Possible Solution

Keep the no-error control-flow suppression, but make the settlement update the same terminal state consumed by embedded subscribers and add lifecycle coverage for a post-tool mid-turn precheck retry.
