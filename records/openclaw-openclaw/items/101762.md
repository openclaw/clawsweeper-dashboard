  - body: This emits `agent_end` with no messages after a `turn_end` object that never goes through `message_end`.   - confidence: 0.88

Extension `turn_end` handlers and other subscribers receive this as an ordinary `AgentMessage`, so omitting those fields can break consumers that follow the existing event type contract on this control-flow path. Use a valid message shape or a distinct internal settlement signal instead of casting an incomplete assistant.
