## What This Changes

This PR adds an opt-in `--severity-min` threshold to `openclaw secrets audit --check`, documents the exit-code contract, and covers severity parsing and exit-code priority with focused tests.

## System Context

The secrets audit command scans OpenClaw-managed credential surfaces and emits structured findings for plaintext values, unresolved references, precedence drift, and legacy residue. The CLI renders that report and maps it to an automation-friendly exit code for operator and CI use.
