## Summary

Keep open: current main and v2026.6.11 still route Feishu plain `message` card JSON through the text path, and the direct fix PRs are closed unmerged pending maintainer proof/adoption direction.

## What This Changes

The issue reports that Feishu proactive `message(action=send)` sends valid interactive-card JSON as raw text instead of rendering it as a Feishu card.

## Best Possible Solution

Keep this as the canonical issue and either adopt a narrow Feishu-plugin parser with real Feishu proof, or explicitly document that raw card JSON in plain `message` is no longer supported.
