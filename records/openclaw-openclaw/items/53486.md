Keep open: current main still routes Feishu `message(action=send)` card-shaped plain `message`/`text` values to the plain text send branch, and the exact-fix PRs found are closed unmerged rather than landed.

## What This Changes

Feishu proactive `message(action=send)` with card JSON in the plain message parameter should render an interactive card instead of raw JSON text.

## Best Possible Solution

Keep this issue open as the canonical report and fix it inside the Feishu plugin boundary by detecting/sanitizing card-shaped text before the plain-text branch or by preparing `channelData.feishu.card`, with focused regression coverage and live Feishu proof.
