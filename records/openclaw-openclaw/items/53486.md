## What This Changes

The issue asks to restore Feishu proactive `message(action=send)` card JSON auto-detection so card-shaped plain `message` text sends as an interactive card instead of raw text.

## Best Possible Solution

Keep this as the canonical issue and land a narrow Feishu-plugin-owned fix only after live Feishu proof, or explicitly document that raw card JSON in plain `message` is no longer a supported send shape and steer users to `presentation` or structured channel data.
