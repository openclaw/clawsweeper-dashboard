## Summary

Keep this PR open: the parse-coalescing fix is directionally sound and addresses the linked performance report, but the added unconditional 256 KB Anthropic tool-argument limit changes an existing native transport contract and can turn previously successful large file-write or patch calls into errors. The PR also needs inspectable after-fix benchmark evidence rather than only summarized claims.

## What This Changes

The PR reduces repeated parsing during Anthropic fine-grained tool streaming, adds a final authoritative parse at tool-block completion, and adds cooperative yielding plus a 256 KB argument-buffer limit.

## System Context

The native Anthropic transport converts streamed provider events into OpenClaw assistant content and tool-call events. Tool-argument deltas update a live partial preview before the completed arguments are passed to the agent tool-execution path.

## Best Possible Solution

Keep the parse coalescing, final completion parse, and cooperative yield, but remove the unrelated native Anthropic hard cap unless maintainers explicitly choose and document a compatible cross-transport size contract; then add a redacted benchmark transcript showing the before/after path.
