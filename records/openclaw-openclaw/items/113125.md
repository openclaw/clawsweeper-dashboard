## Summary

This PR has a focused, evidence-backed fix for excessive synchronous parsing in native Anthropic tool-call streaming. The prior argument-cap blocker is resolved, and no new concrete patch defect is evident; keep it open for normal maintainer review because the intentional 4,096-character partial-preview cadence is a compatibility choice that tests do not fully settle.

## What This Changes

The branch coalesces reparsing of native Anthropic streamed tool arguments, performs a final parse when the tool block ends, yields cooperatively between stream events, and adds regressions for parsing fidelity and uncapped large arguments.

## System Context

The Anthropic Messages transport consumes streaming events, accumulates partial JSON tool arguments, and sends incremental tool-call updates to the agent runtime. This patch changes how often the accumulated partial JSON is parsed while preserving an authoritative final parse at tool-block completion.

## Best Possible Solution

Keep the native Anthropic path uncapped, retain the authoritative final parse and byte-identical regression coverage, and land only if maintainers accept the bounded partial-preview freshness tradeoff for the event-loop performance gain.
