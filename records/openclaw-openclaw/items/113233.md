## What This Changes

This PR removes file-backed active transcript runtime handling and passes structured SQLite session identities through agent, gateway, plugin, memory, compaction, and trajectory flows while retaining JSONL only as an import, test, or export artifact.

## System Context

OpenClaw’s agent runtime receives channel and CLI requests, then persists active conversation state for compaction, plugins, gateway operations, memory indexing, and exports. This refactor replaces file-path identity in those active paths with SQLite session targets while leaving files as deliberate import and export artifacts.
