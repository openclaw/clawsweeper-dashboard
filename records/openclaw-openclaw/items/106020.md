## Summary

Keep this issue open: current main still omits realtime provider voices and declared realtime/transcription models from the Talk catalog, and the linked closing PR remains open; repository policy keeps an issue open until its implementation PR merges.

## What This Changes

Add provider-advertised realtime voices and consistently project non-empty voice, model, and alias lists into `talk.catalog`.

## Best Possible Solution

Expose provider-owned, non-empty voice and model lists through one additive Talk catalog contract, then migrate web and iOS pickers to consume that metadata while retaining a clear older-gateway and no-enumeration fallback.
