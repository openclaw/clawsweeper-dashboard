## What This Changes

The issue reports repeated Mac device-pairing approval alerts for one retrying device, where stale approval dialogs no-op after their gateway request IDs expire or are superseded.

## Best Possible Solution

Fix the gateway and Mac app together so one retrying device keeps one live approvable request, stale request IDs are resolved or removed from clients, and the Mac app coalesces queued pairing prompts per device.
