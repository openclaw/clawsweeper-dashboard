## Summary

The proposed process-tree cleanup is a plausible bounded repair with strong terminal proof, but it introduces a new hard ten-minute failure mode for every plugin pretag build and pack stage. The implementation should stay open for an explicit release-tooling decision on whether that compatibility tradeoff is intended before merge.

## What This Changes

The PR routes plugin pretag runtime-build, npm-pack, and ClawHub-pack commands through the managed child-process runner with a ten-minute process-tree timeout and stage-specific timeout errors.

## Best Possible Solution

Keep managed process-tree termination, but merge only after release-tooling owners explicitly accept the ten-minute deadline for all three stages or choose a narrower timeout policy that preserves supported long-running plugin releases.
