Full review comments:

- **[P1] Stop persisting app session and tool payloads:** `src/agents/mcp-ui-resource.ts:96-100`
  - body: `buildMcpAppCanvasJson` spreads `params.view.mcpApp`, which can include `sessionKey`, and then stores full `toolInput` and `toolResult` in canvas JSON rendered from chat. That extends a session-bound bridge capability and sensitive MCP payloads beyond the live UI session; keep session binding in memory and persist only minimal non-sensitive view identity.
  - confidence: 0.9
- **[P1] Bound MCP App resources before decoding:** `src/agents/mcp-ui-resource.ts:49-53`
  - body: `resources/read` can return arbitrary text/blob strings, but this path accepts full text or decodes a full base64 blob before writing the HTML to canvas storage. A buggy or compromised trusted MCP server can exhaust memory or disk when `mcp.apps.enabled` is on; enforce an explicit byte cap before base64 decode and before persistence.
  - confidence: 0.88
- **[P1] Enforce MCP resource CSP and permissions:** `ui/src/ui/components/mcp-app-view.ts:249-250`
  - body: The MCP Apps dependency puts CSP and requested browser permissions on UI resource metadata, but this iframe path applies only a fixed `navigate-to`/`form-action` CSP and never builds an iframe `allow` policy. Parse and enforce the resource metadata, or fail closed with documented denial semantics.
  - confidence: 0.84
