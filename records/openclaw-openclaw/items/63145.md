## Summary

Keep open: current main still has `models status --probe` selecting one probe model per provider/auth profile, and the user-requested `--probe --all` configured-model health check is not implemented. A prior implementation PR is closed unmerged, while related open items cover fallback-chain testing or provider policy rather than replacing this exact CLI preflight request.

## What This Changes

Request adds `openclaw models status --probe --all` to send live minimal requests to every configured primary, fallback, and image model and report per-model health.

## Best Possible Solution

Keep the existing one-model probe as the default and add an explicit, bounded `--probe --all` mode that reuses current probe target construction, scopes provider/profile filters correctly, clearly reports rate limits/timeouts, and includes tests for fresh config and upgrade-safe CLI behavior.
