Add a `models status --probe --all` mode that sends live minimal requests to every configured primary, fallback, and image model and reports per-model health.

## Best Possible Solution

Define one canonical configured-model health probe contract for `models status --probe --all`, then implement it in the existing status/probe path with docs, focused tests, and redacted live CLI proof.
