## What This Changes

Request adds `openclaw models status --probe --all` to send live minimal requests for every configured primary, fallback, and image model and report per-model health.

## Best Possible Solution

Define one canonical core CLI diagnostic that enumerates configured primary, fallback, and image model refs, reuses the existing probe executor, and documents cost, rate-limit, timeout, redaction, and JSON behavior.
