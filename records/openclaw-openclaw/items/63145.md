## What This Changes

Request adds an `--all` mode to `openclaw models status --probe` so every configured primary, fallback, image, and agent-scoped model can be probed individually.

## Best Possible Solution

Define one canonical configured-model health probe contract, then implement it in the existing `models status --probe` path with default behavior preserved, focused tests, docs, and redacted live CLI proof.
