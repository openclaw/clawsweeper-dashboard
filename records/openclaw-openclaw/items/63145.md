Request to add a `models status --probe --all` mode that live-probes every configured primary, fallback, and image model and reports per-model health.

## Best Possible Solution

Define one canonical configured-model health probe contract for `models status --probe --all`, preserve the existing default one-model-per-provider behavior, then implement it with focused tests, docs, and redacted live CLI proof.
