Keep open: current main and the latest release still lack an opt-in all-configured-model probe for `models status --probe`, the exact implementation attempt is closed unmerged, and related open items overlap but do not replace this narrower request.

## What This Changes

The issue requests `openclaw models status --probe --all` to send live minimal requests to every configured primary, fallback, and image model and report per-model health.

## Best Possible Solution

Define one canonical configured-model health probe contract, then implement it behind an explicit opt-in status flag with docs, focused target-selection tests, JSON coverage, and redacted live CLI proof.
