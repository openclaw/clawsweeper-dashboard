## Summary

Keep open: current main and v2026.6.11 still lack a `models status --probe --all` path, and the remaining work is a new live CLI probe contract that needs maintainer product scoping before implementation.

## What This Changes

Add an opt-in `openclaw models status --probe --all` mode that sends live, per-model probes for every configured primary, fallback, and image model and reports per-model health.

## Best Possible Solution

Define one canonical configured-model health probe contract in the existing models status/probe surface, then ship an additive `--probe --all` implementation with docs, focused tests, and redacted live CLI proof.
