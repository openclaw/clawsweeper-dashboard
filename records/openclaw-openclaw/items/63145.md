## What This Changes

Request to add a `--all` mode to `openclaw models status --probe` that probes each configured primary, fallback, and image model and reports per-model health.

## Best Possible Solution

Define one canonical configured-model health probe contract, then implement it in the existing `models status --probe` path behind `--all` with docs, focused tests, and redacted real CLI/provider proof.
