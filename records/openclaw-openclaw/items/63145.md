## Summary

Keep open: current main and the latest release still lack `models status --probe --all`; the existing path remains a live auth/profile probe that selects one model per provider. The direct implementation PR is closed unmerged, and the remaining work needs maintainer product scoping before another implementation attempt.

## What This Changes

Request a `--all` mode for `openclaw models status --probe` that sends real probe requests to every configured primary, fallback, and image model and reports per-model health.

## Best Possible Solution

Define one canonical configured-model health probe contract, then implement it in the existing `models status --probe` path with docs, typed JSON output, focused target-selection tests, and redacted real CLI/provider proof.
