## What This Changes

The PR restores Ctrl+D forward deletion in nonempty terminal prompts while retaining Ctrl+D as the exit shortcut for an empty prompt, with unit and PTY Gateway coverage.

## System Context

OpenClaw’s terminal UI passes key input to a prompt editor, then sends submitted text through the local or Gateway-backed chat path. Ctrl+D has two context-dependent outcomes: an empty prompt exits the terminal, while a nonempty prompt should let the pinned editor delete the grapheme at the cursor.
