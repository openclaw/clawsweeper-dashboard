## System Context

OpenClaw’s terminal UI routes keystrokes through a custom editor before it submits a prompt to either local execution or a Gateway-backed agent session. The custom editor adds OpenClaw-specific exit behavior, while the pinned editor library owns normal text editing such as forward deletion, multiline edits, and grapheme handling.
