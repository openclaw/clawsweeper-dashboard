## Summary

Keep open: current main still handles token pressure through compaction, memory flush, and transcript rotation, but it does not implement configurable context-threshold session rollover with durable handoff and fresh-session routing.

## What This Changes

Request automatic token-pressure session splitting with memory flush, continuity context injection, and new-session routing before a long-running session reaches the model context limit.

## Best Possible Solution

Define one opt-in core session lifecycle policy for token-pressure rollover that covers threshold evaluation, durable handoff, delivery identity preservation, docs, config schema, and upgrade behavior.
