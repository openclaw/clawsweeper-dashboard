## Summary

Keep open: current main and v2026.6.11 still mitigate context pressure with compaction, memory flush, transcript successor rotation, and daily/idle/manual reset, but they do not provide the requested configurable token-threshold auto split with durable handoff and fresh-session routing.

## What This Changes

Request a configurable automatic session split when a session nears the model context limit, carrying summary/task state into a fresh backing session without requiring manual `/new`.

## Best Possible Solution

Design one maintainer-approved core session lifecycle policy for context-pressure rollover with canonical config, durable handoff semantics, delivery identity preservation, idempotent rotation, docs, and upgrade tests.
