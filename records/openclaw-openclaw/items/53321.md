## Summary

Keep open: current main and v2026.6.11 still handle token pressure through compaction, memory flush, transcript rotation, and daily/idle/manual reset, but they do not provide the requested configurable context-threshold auto split with durable handoff and fresh-session routing.

## What This Changes

The issue requests configurable automatic session rollover near the model context limit, including a memory flush, fresh session routing, and continuity context injection.

## Best Possible Solution

Define one maintainer-approved, opt-in session lifecycle policy that covers token-pressure rollover, durable handoff, delivery identity preservation, config schema, docs, and upgrade behavior.
