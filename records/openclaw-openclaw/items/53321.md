## Summary

Keep open: current main still has compaction, memory flush, successor transcript rotation, daily/idle/manual reset, and thread-binding age controls, but not the requested configurable token-threshold auto split with durable handoff and fresh-session routing.

## What This Changes

The issue requests a configurable context-pressure policy that compacts or flushes memory, creates a fresh backing session, injects continuity state, and routes later messages into that session before the context window is exhausted.

## Best Possible Solution

Design one maintainer-approved core session lifecycle policy for context-pressure rollover with canonical config, durable handoff semantics, delivery identity preservation, idempotent rotation, docs, and upgrade tests.
