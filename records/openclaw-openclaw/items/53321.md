Request automatic session splitting when a session approaches the context window limit, with configurable thresholds, memory flush, continuity handoff, and subsequent-message routing to a fresh session.

## Best Possible Solution

Design one maintainer-approved core session lifecycle policy for context-pressure rollover with canonical config, durable handoff semantics, delivery identity preservation, idempotent rotation, docs, and upgrade tests.
