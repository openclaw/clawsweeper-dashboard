## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Gate Slack prompts on inspected events:** `src/infra/heartbeat-runner.ts:1251`
  - body: `interactionEvents` is populated even when `preflight.shouldInspectPendingEvents` is false, but the consume selector immediately returns `[]` in that mode. A queued Slack interaction seen by a non-hook heartbeat can therefore be injected into the prompt and left in the queue, so later heartbeats replay the same stale click. Gate this collection on the same inspect condition or otherwise make render and consume symmetric.
  - confidence: 0.88
- **[P2] Render modal inputs before consuming them:** `src/infra/heartbeat-events-filter.ts:291`
  - body: Real Slack modal submissions are queued as `slack:interaction:view...` events with their field values under `inputs[]`, but this parser only extracts top-level `value`, `selectedValues`, and `inputValue`. Those modal events now match `isSlackInteractionEvent`, get consumed by the Slack branch, and still lose the actual submitted input values. Render nested inputs or exclude unsupported interaction shapes from this branch.
  - confidence: 0.9
