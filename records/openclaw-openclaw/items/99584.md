Full review comments:

- **[P1] Parse the real Slack interaction event shape:** `src/infra/heartbeat-events-filter.ts:242-247`
  - body: The real Slack path enqueues text as `Slack interaction: ${JSON.stringify({ actionId, inputValue, selectedValues, ... })}`. This parser calls `JSON.parse(eventText)` and looks for `actions[0].action_id/value`, so the live button value stays undefined while the interaction is consumed. Strip the prefix and parse the queued camelCase summary, or include the formatted event text verbatim.
  - confidence: 0.95
- **[P2] Render every interaction you consume:** `src/infra/heartbeat-events-filter.ts:238`
  - body: `buildSlackInteractionEventPrompt` receives all selected Slack interaction events, but this line keeps only the first while the runner consumes every `isSlackInteractionEvent` entry. If two distinct clicks are queued before the run, only the first reaches the prompt and the rest are dropped. Render all selected events or consume only the rendered one.
  - confidence: 0.89
