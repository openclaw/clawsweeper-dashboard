## Summary

## What This Changes

This PR changes agent timeout resolution so `timeoutSeconds: 0` means an unlimited run budget while LLM creation/idle watchdogs stay finite, raises implicit self-hosted idle tolerance, and updates resolver/schema/docs/tests.

## Best Possible Solution
