## What This Changes

The issue requests that `openclaw uninstall` remove OpenClaw-owned shell-completion profile entries and remaining installed command paths so new shells do not retain broken OpenClaw references.

## System Context

The CLI installer adds shell-completion setup to user profile files, while the uninstall command removes OpenClaw state and related local resources. A complete uninstall path must decide which profile entries and package-manager-installed command paths it owns, then leave a new shell without dangling references.
