## Summary

Keep open: current main provides the plugin-owned catalog, paired-node, and Control UI pattern for Codex, but no OpenCode or Pi catalog implementation was found; this fresh maintainer-labeled request needs an explicit decision on official plugin ownership and default activation.

## What This Changes

Add view-only OpenCode and Pi session catalogs for the Gateway and paired nodes, with Control UI settings to disable either catalog.

## Best Possible Solution

Implement separate plugin-owned OpenCode and Pi read-only catalog providers that reuse the generic catalog UI and versioned node-command contracts, preserve bounded pagination and per-node opt-in, and expose clear privacy-aware enable/disable controls without adding core storage scanners.
