## Summary

Keep open. Current main and v2026.6.11 still serialize each session lane at one active run and do not expose session-concurrency or auto-yield config; the lane-wait warning threshold is only covered by a narrower open PR.

## What This Changes

Request configurable same-session lane concurrency, automatic yielding after tool execution, and a configurable lane-wait warning threshold.

## Best Possible Solution

Keep this as the umbrella design tracker, land or replace the narrow diagnostics-threshold PR separately, and implement session concurrency or auto-yield only after a maintainer-approved scheduler contract.
