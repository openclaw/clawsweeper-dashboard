## Summary

Keep open. Current main and the latest release still serialize each session lane at one active run, expose only global/subagent/cron concurrency config, and leave auto-yield as explicit `sessions_yield` behavior; the open diagnostics PR only covers the warning-threshold slice.

## What This Changes

The issue requests configurable per-session lane concurrency, automatic yielding during long tool execution, and a configurable lane-wait warning threshold for queued interactive messages.
