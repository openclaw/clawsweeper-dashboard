## Summary

Keep open. Current main and the latest release still serialize session lanes at one active run, do not expose the requested session concurrency or auto-yield config, and only the lower-risk lane-wait warning threshold slice has an open unmerged PR.

## What This Changes

This issue requests configurable per-session lane concurrency, automatic yielding during long tool execution, and a configurable lane-wait warning threshold.

## Best Possible Solution

Keep this as the umbrella design tracker, review the lane-wait diagnostics PR separately, and require a maintainer-approved session scheduler contract before adding concurrency or auto-yield config.
