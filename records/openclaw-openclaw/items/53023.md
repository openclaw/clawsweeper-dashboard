## Summary

Keep open. Current main and v2026.6.11 still serialize session lanes at one active run, do not expose the requested session-concurrency or auto-yield config, and only the lane-wait warning threshold has a separate open implementation candidate.

## What This Changes

The issue requests configurable per-session lane concurrency, automatic yielding during long tool execution, and a configurable lane-wait warning threshold for interactive agent sessions.

## Best Possible Solution

Keep this as the umbrella scheduler design tracker, land or replace the diagnostics-threshold slice separately, and require a maintainer-approved session concurrency or fairness contract before adding new config.
