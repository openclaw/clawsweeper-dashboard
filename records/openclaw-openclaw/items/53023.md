## Summary

Keep open. Current main and latest release still serialize each session lane at one active task, the requested session-concurrency and auto-yield config surfaces are absent, and only the narrower lane-wait warning threshold has an open unmerged PR.

## What This Changes

Request configurable per-session lane concurrency, automatic yielding after long tool execution, and a configurable lane-wait warning threshold for interactive agents.

## Best Possible Solution

Keep this as the umbrella scheduler-design tracker, land or replace the diagnostics-threshold slice separately, and implement session concurrency or auto-yield only after maintainers define transcript, cancellation, delivery, and config semantics.
