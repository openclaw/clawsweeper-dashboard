## Summary

Keep open. The PR fixes the visible Telegram long-model button drop in the right area and has strong Telegram Desktop proof, but the current fingerprint guard still permits a stale same-count model list collision that can resolve and persist the wrong model.

## What This Changes

The PR changes Telegram /model picker callbacks from name-embedded selection data to provider/page/index/count/fingerprint callback data, preserves legacy callback parsing, and updates Telegram model-button tests.

## Best Possible Solution

Keep the index-based Telegram callback scheme, but length-prefix or otherwise boundary-encode every model name in the fingerprint input and add a same-count stale-list regression before merge.
