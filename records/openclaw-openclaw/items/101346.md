## Summary

Keep open: the PR targets a real availability gap, but no-op suppression is unsafe in the final archive policy gate because a stdout stream failure can leave a partial tar listing that is later treated as successful.

## What This Changes

The PR adds no-op `error` listeners to the stdout and stderr streams used while listing `dir.fetch` archives with tar.

## Best Possible Solution

Handle stdout and stderr stream errors by settling `ARCHIVE_ENTRIES_UNREADABLE` and stopping tar, while keeping the existing settled `stdin` EPIPE behavior and adding focused regression coverage plus real run proof.
