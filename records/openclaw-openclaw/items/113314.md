## Summary

Keep this issue open. Two same-day external-fork jobs timed out in the same isolated TUI-shell test while 1,169 other tests passed, which is enough evidence of a contributor-CI regression; the earlier runner-specific wrapper fix is relevant precedent but does not establish the same root cause.

## What This Changes

Make the system-agent shared-TUI-shell test reliable on GitHub-hosted external-PR runners instead of allowing it to hang until Vitest's 120-second timeout.

## System Context

The `core-unit-fast-isolated` CI shard runs focused core tests for external pull requests. Its system-agent TUI test starts OpenClaw through the shared terminal shell and must finish its child-process setup and teardown so the CI shard can report the PR result.

## Best Possible Solution
