Full review comments:

- **[P1] Read Codex identity from the active app server:** `extensions/codex/provider.ts:158`
  - body: This copies `ctx.email`, but the local app-server quota is owned by the Codex login and synthetic usage-auth callers do not populate that field. Even when an OpenClaw profile email exists, it can differ from the active app-server account. Codex already exposes that account's email through `account/read`; pair it with the rate-limit request and test mismatched or absent profile identity.
  - confidence: 0.98
- **[P2] Bind the Claude email cache to the matched token:** `extensions/anthropic/usage.ts:526-527`
  - body: The login-token check occurs before reading a cache keyed only by `configPath`. If the credential cache refreshes to account B while the independently timed email cache still contains account A, usage for B is mislabeled until this TTL expires. Store the matched token or a non-secret token identity with the cache entry and only reuse the email for that same login.
  - confidence: 0.94
