## Summary

Keep open. Current main and v2026.6.11 still absorb queued diagnostic writer mkdir/append failures without a warning, while related work only added queue diagnostics/caps and the same-repo warning PR was closed unmerged.

## What This Changes

The issue requests a bounded diagnostic signal when queued file writes for payload/cache trace logs fail repeatedly instead of being silently absorbed.

## Best Possible Solution

Keep diagnostic writes non-fatal, but add a maintainer-approved bounded and redacted warning or debug signal if OpenClaw wants operator visibility for repeated diagnostic write failures.
