## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.93

Full review comments:

- **[P1] Authorize Slack search read targets:** `extensions/slack/src/action-runtime.ts:577-583`
  - body: `searchMessages` sends a free-form user-token query to Slack without requiring a channel target or applying the existing Slack read-target allowlist. Existing Slack read actions call `assertSlackReadTargetAllowed`, and Discord search applies read-target or guild authorization before searching, so this can expose workspace results outside configured channel policy. Constrain search to approved targets or get an explicit workspace-wide search contract before exposing it.
  - confidence: 0.93
- **[P1] Keep advanced Slack scopes out of the default manifest:** `extensions/slack/src/setup-shared.ts:42-64`
  - body: Bookmarks, canvases, and reminders are opt-in action groups, but the default app manifest now requests their read/write scopes for every new Slack install. Keep the base manifest least-privilege or gate these scopes behind explicit setup opt-in before broadening Slack token authority.
  - confidence: 0.91
- **[P2] Parse numeric epoch strings before Date.parse:** `extensions/slack/src/action-runtime.ts:214-217`
  - body: `postAt` accepts strings, but a digit-only Unix timestamp like `"1725000000"` falls into `Date.parse` and becomes `NaN`, so serialized scheduled-send payloads throw despite the error saying Unix seconds are supported. Parse digit-only strings as epoch seconds before date parsing.
  - confidence: 0.9
