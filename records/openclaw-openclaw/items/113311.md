## What This Changes

This PR preserves full Workboard proof history across later SQLite-backed card writes, then adds opt-in bounded proof views and backward pagination for Gateway, agent tools, Control UI, and the iPad Workboard.

## System Context

Workboard persists operational cards and proof records in its plugin-owned SQLite database, then serves cards to Gateway clients, agent tools, the Control UI, and the iPad app. This change separates canonical proof persistence from smaller client-facing card projections while retaining full responses by default.
