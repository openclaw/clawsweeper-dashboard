## Summary

Keep this PR open for a compatibility repair and real after-fix proof. ## What This Changes

The PR makes Workboard proof records append-only in SQLite, projects bounded recent-proof windows through Gateway and agent tools, and adds pagination plus Control UI copy for older proof history.

## System Context

Workboard persists cards and proof records in its plugin-owned SQLite database, then returns cards through Gateway RPC, agent tools, CLI commands, and the Control UI. The PR separates canonical proof history from bounded card views so output-size limits no longer remove durable audit records during later card mutations.
