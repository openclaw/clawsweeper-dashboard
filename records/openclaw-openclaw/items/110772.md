## Summary

The descriptor-bound read is a sound direction and the updated terminal proof addresses the prior bounded-read evidence gap, but this branch newly rejects otherwise valid legacy session stores above 50 MiB; current main has no such migration limit, so the compatibility contract needs resolution before merge.

## What This Changes

The branch replaces path-based legacy session-store reads in Doctor with descriptor-bound, byte-capped reads and adds tests for stat failures, non-regular paths, and oversized stores.

## Best Possible Solution
