## Summary

This PR remains necessary, but its open-before-type-check sequence can block `openclaw doctor` indefinitely on a FIFO or other blocking special file. The descriptor-bound size limit and proof address regular-file growth, but the reader must reject special files without a blocking open before it is ready to merge.

## What This Changes

The branch replaces the legacy session-store path read with an open/fstat/bounded descriptor read and adds Doctor tests for stat failures and non-regular paths.

## Best Possible Solution

Acquire the legacy-store descriptor without permitting a blocking special-file open, then retain descriptor-bound `fstat` and bounded reading, with focused special-file regression coverage on supported platforms.
