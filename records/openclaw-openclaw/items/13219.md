## What This Changes

Request native per-model and per-call usage logging for cost tracking, model-mix analysis, and cron/session attribution.

## Best Possible Solution

Define one canonical, privacy-safe completed-model-call usage ledger or equivalent core accounting contract, then derive usage.cost, sessions.usage, CLI/UI summaries, backfill, and plugin/export views from that source.
