## Summary

Keep open: current main and the latest release still do not provide a Telegram TTS delivery-mode selector, and the remaining work is a product/config contract decision rather than conservative cleanup.

## What This Changes

Request a Telegram TTS option that sends full-width text and the voice note as separate messages instead of one voice message with a caption.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request, then implement a backward-compatible documented TTS delivery policy only after maintainers decide how it coexists with captioned-final and voice-only modes.
