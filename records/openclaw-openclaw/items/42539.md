## What This Changes

Add a Telegram TTS delivery mode that sends readable text and a separate voice note instead of putting the text in the voice message caption.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request until maintainers define a backward-compatible TTS delivery policy, choose the global-versus-channel config shape, and reconcile it with captioned-final and voice-only modes.
