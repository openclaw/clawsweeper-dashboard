## Summary

Keep this open: current main and v2026.6.11 still lack a Telegram TTS separate-delivery selector, and the active related PR targets single voice-with-caption final delivery rather than the requested full-width text plus separate voice note.

## What This Changes

The issue requests a configurable Telegram TTS mode that sends readable text as its own message and the generated voice note separately instead of using a voice caption.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request until maintainers define a backward-compatible TTS delivery policy and reconcile it with captioned-final and voice-only modes.
