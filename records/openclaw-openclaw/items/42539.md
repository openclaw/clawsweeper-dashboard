## Summary

Keep this open: current main and the latest release still lack a Telegram TTS delivery selector, and Telegram still keeps normal-length voice text as a caption rather than a separate full-width message.

## What This Changes

This issue requests a configurable Telegram TTS mode that sends readable text and the generated voice note as separate messages instead of one captioned voice message.

## Best Possible Solution

Define a backward-compatible Telegram TTS delivery policy that coexists with captioned-final and voice-only modes, then implement it with schema, docs, and Telegram delivery tests.
