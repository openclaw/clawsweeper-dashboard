## Summary

Keep this open: current main and v2026.6.11 still lack a Telegram TTS separate-delivery selector, and the active related work targets captioned final-mode delivery rather than this requested text-plus-voice mode.

## What This Changes

Add a TTS delivery mode option so Telegram can send full-width text and a separate voice message instead of putting text in the voice caption.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request, then implement a backward-compatible documented policy only after maintainers choose how it coexists with captioned-final and voice-only TTS modes.
