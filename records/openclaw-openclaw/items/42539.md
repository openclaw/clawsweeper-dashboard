## Summary

Keep this open: current main and v2026.6.11 still lack a Telegram TTS separate-delivery selector, while the active related PR addresses captioned final-mode churn rather than the requested full-width text plus separate voice-note mode.

## What This Changes

Add a configurable Telegram TTS delivery mode that sends readable text separately from the voice note instead of always using a voice caption when text fits Telegram's caption limit.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request until maintainers define a backward-compatible TTS delivery policy, decide the global-versus-channel config shape, and require Telegram tests plus live proof for the chosen mode.
