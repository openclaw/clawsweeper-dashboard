## Summary

Keep open: current main and v2026.6.11 still lack a Telegram TTS selector for full-width text plus a separate voice note, while related active work targets captioned final-mode delivery rather than this requested delivery mode.

## What This Changes

The issue requests a configurable Telegram TTS delivery mode that sends normal text and the voice note as separate messages instead of one captioned voice message.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request until maintainers define a backward-compatible TTS delivery policy, decide the global-versus-channel config shape, and reconcile it with captioned-final and voice-only modes.
