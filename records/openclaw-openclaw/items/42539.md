## Summary

Keep this open: current main and v2026.6.11 still lack a Telegram TTS delivery selector, while the existing Telegram path sends successful TTS as one audio-bearing payload and captions short text on the voice note.

## What This Changes

Request a configurable Telegram TTS delivery mode that sends readable text separately from a voice note instead of using a voice-note caption by default.

## Best Possible Solution

Define a backward-compatible TTS text/voice delivery policy, choose whether it lives globally or in Telegram channel/account config, document it, and require Telegram tests plus live proof for captioned and separate modes.
