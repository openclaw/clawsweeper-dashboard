## Summary

Keep this open: current main and v2026.6.11 still lack a Telegram TTS separate-delivery selector, and the active related PR targets captioned final-mode delivery rather than the requested full-width text plus voice-note mode.

## What This Changes

The issue requests a Telegram TTS delivery option that sends readable full-width text and the voice note as separate Telegram messages instead of bundling text as a voice caption.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request until maintainers define a backward-compatible TTS text/voice delivery policy, choose the global-versus-channel config shape, and reconcile it with captioned-final and voice-only modes.
