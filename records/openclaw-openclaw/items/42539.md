## Summary

Keep this open: current main and v2026.6.11 still lack a Telegram TTS separate-delivery selector, while the active related work is for captioned final-mode delivery rather than the requested full-width text plus voice-note mode.

## What This Changes

Requested behavior: add a Telegram TTS delivery option that sends readable text and the voice note as separate messages instead of bundling text into the voice caption.

## Best Possible Solution

Keep this as the canonical Telegram separate-delivery request until maintainers define a backward-compatible TTS delivery policy, decide the global-versus-channel config shape, and reconcile it with captioned-final and voice-only modes.
