## Summary

Keep this PR open, but do not merge this head: the reported target-agent allowlist bug is real, yet the patch can create a new final allow-only inherited policy from configured `alsoAllow` entries when the parent has no restrictive inherited allowlist.

## What This Changes

The PR changes native subagent spawn session persistence to merge caller, global subagent, and target-agent `alsoAllow` entries into the child session's `inheritedToolAllow`, with regression tests for global and target config sources.

## Best Possible Solution

Conditionally append configured target/global extras only when preserving an existing non-empty inherited allowlist, keep empty inherited allowlists empty, add regression coverage for unrestricted parents, and then provide redacted after-fix runtime proof.
