## Summary

Keep this PR open for maintainer direction, but it is not merge-ready: the architecture addresses a genuine composition gap, while the proposed public contract is broader than the implemented lifecycle semantics and still violates the repository’s canonical-config migration policy.

## What This Changes

Adds five global and per-agent memory role selectors and threads them through plugin activation, runtime selection, configuration, Doctor, diagnostics, install/update/uninstall flows, documentation, and tests.

## Best Possible Solution

Land only memory roles that have complete generic, agent-aware host invocation contracts—currently recall and compaction—or first implement those contracts for capture, dreaming, and user modeling; in either case, make Doctor replace the legacy selector, keep runtime canonical-only, restore current-main documentation, and prove fresh-install and tagged-upgrade behavior on the final conflict-free head.
