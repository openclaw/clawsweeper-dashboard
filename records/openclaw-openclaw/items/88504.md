## Summary

Keep this PR open for maintainer review. It proposes a valuable but very broad plugin/configuration contract change; the current branch still makes an existing legacy memory selection resolve to the default recall plugin until a user manually runs Doctor, so an upgrade can silently change configured memory behavior. The supplied proof description also names earlier heads rather than the current head, so it does not yet establish the final branch’s upgrade behavior.

## What This Changes

This PR introduces five role-specific memory plugin slots, including per-agent overrides, and wires them through configuration, plugin activation, memory runtime dispatch, Doctor, diagnostics, UI, documentation, and bundled memory plugins.

## System Context

OpenClaw reads plugin-slot configuration to decide which memory plugin is active for an agent, then loads that plugin’s runtime and hooks for recall, capture, compaction, dreaming, and related management commands. This PR expands that one-owner selection model into separate role owners, affecting saved configuration, plugin activation, session behavior, and diagnostics.
