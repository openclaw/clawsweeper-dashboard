## What This Changes

This PR replaces the single active memory-plugin selection with five global and per-agent role selections for recall, capture, compaction, dreaming, and user modeling, then wires them through plugin loading, runtime routing, Doctor, diagnostics, UI, docs, and bundled memory plugins.

## System Context

OpenClaw’s plugin configuration selects which memory implementation participates in agent execution. This change feeds global and agent-specific memory-role selections into plugin activation, hook dispatch, runtime lookup, compaction, diagnostics, and the Control UI.
