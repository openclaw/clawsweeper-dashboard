## What This Changes

This PR replaces the single memory-plugin selector with five role-specific global and per-agent slots for recall, capture, compaction, dreaming, and user modeling, then applies those selections across configuration, plugin loading, runtime routing, diagnostics, UI, docs, and bundled memory plugins.

## System Context

OpenClaw’s plugin configuration selects memory providers, then the plugin loader activates them and runtime services use the selected provider for agent work. This PR expands that selection boundary from one global recall-oriented memory owner to several role owners that can differ by agent, affecting hooks, session compaction, memory search, diagnostics, and plugin lifecycle operations.
