Keep this PR open for maintainer product review. It introduces a broad, durable memory-routing contract rather than a bounded regression repair, and the latest reviewed proof does not demonstrate real behavior on the current head after the final formatting/dead-code commit.

## What This Changes

This PR replaces the single active memory-plugin selector with five global and per-agent role selectors for recall, capture, compaction, dreaming, and user modeling, then updates plugin loading, runtime routing, diagnostics, UI, docs, and bundled plugins.

## System Context

OpenClaw configuration chooses plugins that contribute memory behavior to agent prompts, memory capture, compaction, dreaming, command-line tools, and status output. The proposed role selectors would let different plugins own those responsibilities independently, including for individual agents.
