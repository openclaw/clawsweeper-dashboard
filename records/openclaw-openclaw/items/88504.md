## What This Changes

The PR adds five global and per-agent memory role slots and routes plugin activation, hooks, runtime selection, migration, diagnostics, lifecycle cleanup, SDK types, tests, and documentation through them.

## Best Possible Solution

Use one canonical agent-aware dreaming-owner resolver across backend and Control UI, add regression and browser proof for non-default global and per-agent owners, refresh exact-head fresh-install and upgrade evidence, and merge only after memory/plugin owners sponsor the permanent role taxonomy and fallback policy.
