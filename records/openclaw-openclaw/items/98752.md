- **[P1] Preserve existing camera capability on upgrade:** `apps/android/app/src/main/java/ai/openclaw/app/SecurePrefs.kt:71`
  - body: This changes the missing-key default for `camera.enabled` from true to false, while that flag controls whether Android advertises camera commands and the camera capability. Existing installs or re-onboarding runs that never wrote the preference can silently lose camera tools; split fresh-install privacy defaults from upgrade behavior, or add an explicit tested migration for the intended reset.
  - confidence: 0.9

  - confidence: 0.82

  - body: For action rows without a route, the chevron repeats the row title as its `contentDescription` even though the row text already announces the action. Make that icon decorative and leave the row click semantics to announce the actual control.
