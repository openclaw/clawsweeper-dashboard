Full review comments:

- **[P1] Preserve existing camera capability on upgrade:** `apps/android/app/src/main/java/ai/openclaw/app/SecurePrefs.kt:71`
  - body: This changes the missing-key default for camera.enabled from true to false, while the same value controls whether Android advertises camera tools. Existing installs that never wrote the preference can silently lose camera.list/camera.snap/camera.clip after upgrade or re-onboarding; split fresh-install privacy defaults from upgrade behavior, or add an explicit tested migration for the intended reset.
  - confidence: 0.9

  - body: While the recovery screen waits for node approval, this loop can call refreshNodesDevices() every 1.5 seconds for the entire owner wait. That is unnecessary network and battery load during long approvals; use a slower interval, backoff, or event-driven refresh with occasional retry.
  - confidence: 0.82
