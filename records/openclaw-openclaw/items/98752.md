Full review comments:

- **[P1] Preserve existing camera capability on upgrade:** `apps/android/app/src/main/java/ai/openclaw/app/SecurePrefs.kt:71`
  - body: This changes the missing-key default for camera.enabled from true to false, while that flag controls whether Android advertises camera commands and the camera capability.
