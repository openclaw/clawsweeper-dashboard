## Summary

Keep open: current main has implemented a substantial Web UI/session-thread slice, including labels, grouping, archive/pin/delete, picker/sidebar actions, and slash-command naming, but the umbrella request still asks for broader cross-surface topic/session management that is not yet fully owned by current CLI, TUI, metadata, tagging, description, or import/export flows.

## What This Changes

The issue requests a unified topic/session management experience with create/rename/delete/switch workflows, metadata such as descriptions and tags, organization, CLI/TUI/Web UI support, and import/export-style lifecycle controls.

## Best Possible Solution

Use the current session label/category/archive/pin/checkpoint model as the foundation, then have maintainers split accepted residual work into explicit CLI lifecycle, TUI controls, richer metadata/tags/families, and import/export follow-ups without adding a second topic store.
