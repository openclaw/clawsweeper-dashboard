## What This Changes

Request a filesystem sandboxing configuration surface with mode, allowed paths, denied paths, and enforcement across file tools and exec-related filesystem access.

## Best Possible Solution

Keep this issue open until maintainers choose a canonical filesystem policy contract and explicit exec scope, then land one reviewed implementation path with path normalization, deny precedence, file/media/apply_patch coverage, docs, and upgrade proof.
