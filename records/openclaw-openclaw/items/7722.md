## What This Changes

The issue requests a configurable filesystem access policy for OpenClaw tools, including sandbox/full mode, allowed paths, denied paths, and coverage across file and exec operations.

## Best Possible Solution

Keep this as the canonical tracker until maintainers define a versioned `tools.fs` allow/deny policy, enforce it across file tools, apply_patch, and local media, and either include exec or split the exec limitation into an explicit linked policy contract.
