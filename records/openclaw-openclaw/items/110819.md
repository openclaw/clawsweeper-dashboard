## Summary

The availability fix is useful, but the patch silently overrides caller-supplied child-process limits in a shared helper; preserve those explicit options before merge.

## What This Changes

The PR adds a shared 120-second timeout and `SIGKILL` timeout signal to the synchronous GitHub CLI calls in `scripts/lib/plain-gh.mjs`.

## Best Possible Solution

Keep a 120-second `SIGKILL` default while preserving explicit `options.timeout` and `options.killSignal` values, with focused coverage for both the default and caller-override paths.
