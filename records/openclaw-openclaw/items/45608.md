## Summary

Keep open: current main and v2026.6.11 still run the tool-capable agentic memory flush only in the normal reply/compaction maintenance path, not before explicit or daily/idle session reset. Related open reset-hook work addresses mechanical session-memory persistence, but it does not replace this issue's requested bounded agentic pre-reset flush and security/product decision.

## What This Changes

Request a silent agentic memory flush before `/new`, `/reset`, and daily/idle session rollover retire the current session.

## Best Possible Solution

Define a maintainer-approved reset-memory lifecycle that preserves curated memory before explicit, daily, and idle session destruction while honoring sandbox/tool approvals, read-only and CLI guards, timeouts, auditability, and plugin ownership.
