## Summary

Keep open: current main and the latest release still only run the silent agentic memory flush from the reply/compaction path, while reset paths emit lifecycle hooks and the bundled session-memory hook remains mechanical. The open reset-hook PR is useful partial work but does not replace the product/security decision about silent reset-time agent execution.

## What This Changes

Request to add a compaction-style silent agentic memory flush before explicit, daily, and idle session resets so important context can be curated before rollover.

## Best Possible Solution

Design one maintainer-approved reset-lifecycle memory preservation path that covers explicit, daily, and idle rollovers while making latency, consent, sandbox, audit, and plugin/config boundaries explicit.
