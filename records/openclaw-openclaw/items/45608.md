## Summary

Keep open: current main still separates reset rollover from the compaction-style agentic memory flush, and the active related PR only targets daily/idle hook dispatch for raw session-memory behavior, not the requested pre-reset agentic flush.

## What This Changes

## Best Possible Solution

Design one maintainer-approved reset-lifecycle memory finalization path for explicit, daily, and idle rollover, with clear privacy, timeout, sandbox, provider/config, and duplicate-write semantics.
