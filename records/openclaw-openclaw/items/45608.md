## Summary

Keep open: current main still runs the silent agentic memory flush from the reply/pre-compaction path, while reset rollover captures and archives the outgoing session, then emits lifecycle hooks without a pre-reset agentic flush. The newer post-reset startup prompt and the open reset-hook PR are useful adjacent work, but they do not settle the requested silent tool-capable memory write before `/new`, `/reset`, daily, or idle rollover.

## What This Changes

Request a silent agentic memory flush before `/new`, `/reset`, and automatic daily/idle reset destroy the outgoing session.

## Best Possible Solution

Define one bounded reset-lifecycle memory preservation contract covering manual, daily, and idle rollovers with timeout, dedupe, opt-out/config, sandbox/tool/audit rules, and regression proof.
