## Summary

Keep open: current main has reset hooks, startup daily-memory loading, and the normal compaction-gated memory-flush turn, but no source path that runs an agentic memory flush before explicit, daily, or idle session rollover. The world-model-mcp comment is useful external/plugin context, but it does not replace the missing OpenClaw reset-boundary policy decision.

## What This Changes

Run a silent compaction-style agentic memory flush before `/new`, `/reset`, and automatic daily/idle session rollover destroys the current session.

## Best Possible Solution

Design one maintainer-approved reset-lifecycle memory preservation path that covers explicit, daily, and idle rollovers while making latency, consent, sandbox, timeout, redaction, plugin, and config boundaries explicit.

## Reproduction Assessment

Yes, from source inspection: reset rollover and memory-flush execution are separate current-main paths, so explicit or stale reset can rotate the session without invoking an agentic pre-reset write.

## Solution Assessment

Unclear: reusing the existing memory-flush turn is plausible, but blocking reset, background cleanup, copying existing compaction summaries, and plugin lifecycle contracts have different latency and security tradeoffs.
