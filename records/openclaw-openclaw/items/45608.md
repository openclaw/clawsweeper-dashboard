## Summary

Keep open: current main still separates reset rollover from the agentic memory-flush path. Manual and stale resets preserve some lifecycle/mechanical hook context, but there is still no maintainer-approved policy for running a silent, tool-capable pre-reset agent turn.

## What This Changes

Request a silent agentic memory flush before manual, daily, and idle session resets so durable notes can be written before the old session is destroyed.

## Best Possible Solution

Define one maintainer-approved reset-memory lifecycle policy covering explicit, daily, and idle rollovers, with timeout, dedupe, audit, consent, plugin, and config boundaries before implementation.
