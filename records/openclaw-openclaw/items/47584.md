## Summary

Keep open: current main and v2026.6.11 still do not provide a native iOS Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The request fits the iOS companion-app direction, but it needs maintainer product and security design before implementation because the proposed hook-based path would let Siri/Shortcuts initiate Gateway agent work.

## What This Changes

Add native iOS AppIntent/Siri/Shortcuts support so dictated questions can be sent to OpenClaw and returned as spoken replies without opening the app.

## Best Possible Solution

Define and land a maintainer-approved native iOS AppIntent that reuses paired-device identity or a hardened hook boundary, routes agent/session context deliberately, preserves local permission/confirmation controls, and returns spoken replies without weakening Gateway security.

## Reproduction Assessment

Not applicable for a feature request. Source and release inspection show no native Ask OpenClaw AppIntent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.

## Solution Assessment

Unclear as proposed. Native AppIntent support likely belongs in the iOS app, but posting directly to /hooks/agent is not the best proven boundary until maintainers decide auth, session routing, reply collection, and spoken-dialog behavior.
