## Summary

Keep open: current main and latest release still lack the requested parameterized iOS Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The request is clear, but implementation needs maintainer product and security direction before a fix PR.

## What This Changes

Add native iOS Siri/Shortcuts App Intent support so users can ask OpenClaw a dictated question and receive a spoken reply without opening the app.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission and confirmation, and returns spoken replies without weakening Gateway controls.

Options:

- **Sponsor paired-node AppIntent design (recommended):** Implement the feature in apps/ios using the authenticated paired Gateway/node session, explicit session behavior, local confirmation rules, and focused iOS proof before merge.
- **Use hooks as opt-in integration:** Keep Siri/Shortcuts execution outside normal paired-node chat and require explicit hook token configuration, restricted session prefixes, and documented operator opt-in.
- **Keep Shortcuts workaround only:** Do not add native AppIntent support until a maintainer wants to own the product and security surface.
