Keep open: current main and the latest release still lack the native parameterized Siri/App Intent flow that accepts a dictated OpenClaw question and returns a spoken reply. The request remains useful, but implementation should wait for maintainer product and security direction because the proposed hook-style path would expose agent execution through Siri and Shortcuts.

## What This Changes

Requested native iOS Siri App Intent support so a dictated OpenClaw question can be sent to the paired gateway and returned as a spoken Siri/Shortcuts reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or an explicitly secured hook boundary, chooses agent/session routing deliberately, handles local confirmation and permissions, and returns spoken replies without bypassing Gateway security controls.
