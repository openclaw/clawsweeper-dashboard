## Summary

Keep open: current main and v2026.6.11 still do not provide a native iOS Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken dialog reply. The request is valid feature work, but it needs maintainer product and security direction before implementation because Siri/Shortcuts would become a new agent-invocation surface.

## What This Changes

Request native iOS Siri/App Intent support so users can ask OpenClaw a parameterized question through Siri or Shortcuts and receive a spoken reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or an explicitly hardened hook boundary, chooses agent/session routing deliberately, handles confirmation and permissions, and returns spoken replies without bypassing Gateway security controls.

## Reproduction Assessment

Not applicable for a feature request. Source and release inspection show there is no native Ask OpenClaw App Intent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.

## Solution Assessment

Unclear as proposed. Native App Intent support likely belongs in the iOS app, but directly posting to `/hooks/agent` is not the best proven boundary until maintainers approve auth, session routing, reply collection, and spoken-dialog behavior.
