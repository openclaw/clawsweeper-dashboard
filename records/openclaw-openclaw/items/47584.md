## Summary

Keep open: current main still lacks native parameterized Siri/App Intent support that accepts a dictated OpenClaw question and returns a spoken reply. The request remains useful, but it needs maintainer product and security direction because the proposed hook-based path would expose agent execution through Siri and Shortcuts.

## What This Changes

The issue requests native iOS Siri/App Intent support so users can dictate a question to OpenClaw and receive a spoken reply without opening the app.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or an explicitly secured hook boundary, chooses agent/session routing deliberately, handles local confirmation and permissions, and returns spoken replies without bypassing Gateway security controls.

## Reproduction Assessment

Not applicable for a feature request. Source inspection shows current main has no native Ask OpenClaw App Intent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.

## Solution Assessment

Unclear as proposed. Native App Intent support likely belongs in the iOS app, but directly posting to `/hooks/agent` is not the best proven boundary until maintainers approve auth, session routing, reply collection, and spoken-dialog behavior.
