## Summary

Keep open: current main and v2026.6.11 still lack the requested parameterized Siri/App Intent with spoken reply, and the remaining work needs maintainer product and security-boundary direction before implementation.

## What This Changes

The issue requests native iOS Siri/App Intent support so users can ask OpenClaw questions via Siri or Shortcuts and receive spoken replies without opening the app.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, and returns spoken replies without weakening Gateway controls.
