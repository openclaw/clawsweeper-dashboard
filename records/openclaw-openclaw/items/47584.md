## What This Changes

The issue requests native iOS Siri/App Intents support so users can ask OpenClaw a parameterized question from Siri or Shortcuts and receive a spoken reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, and returns spoken replies without weakening Gateway controls.
