## Summary

Keep open: current main and v2026.6.11 still lack a parameterized native iOS Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The open Action Button/Dynamic Island PR only overlaps with launch-to-Talk behavior, while this issue still needs a maintainer product and security boundary decision before implementation.

## What This Changes

Request native iOS Siri/App Intent and Shortcuts support that sends a dictated OpenClaw question to the paired Gateway and returns a spoken response.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission and confirmation, and returns spoken replies without weakening Gateway controls.
