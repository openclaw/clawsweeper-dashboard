## Summary

Keep open: current main and v2026.6.11 still do not provide a native parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The request is aligned with the iOS companion-app direction, but it needs maintainer product and security design before implementation because the proposed hook-based path would let Siri/Shortcuts initiate Gateway agent work.

## What This Changes

Request native iOS Siri/App Intent support so users can invoke OpenClaw by voice or Shortcuts and receive spoken replies without opening the app.

## Best Possible Solution

Define a maintainer-approved native iOS App Intent design that either reuses paired-device identity or introduces a hardened hook boundary, then implement explicit agent/session routing, local confirmation, spoken reply handling, and focused iOS/Gateway tests.

## Reproduction Assessment

Not applicable for a feature request. Source and release searches show no native Ask OpenClaw App Intent, AppShortcutsProvider for parameterized questions, or ProvidesDialog-style spoken reply implementation to reproduce today.

## Solution Assessment

Unclear as proposed. Native App Intent support likely belongs in the iOS app, but posting directly to /hooks/agent is not the best proven boundary until maintainers choose the auth, session-routing, reply, and confirmation model.
