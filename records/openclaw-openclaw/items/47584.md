## What This Changes

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a deliberately hardened hook boundary, chooses agent/session routing explicitly, handles local confirmation and idempotency, and returns spoken replies without bypassing Gateway security controls.
