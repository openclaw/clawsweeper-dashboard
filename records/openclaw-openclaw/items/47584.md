## Summary

Keep open: current main and the latest release still lack a native parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The request remains useful, but it needs maintainer product and security direction before implementation because the Siri/Shortcuts surface can initiate Gateway-controlled agent work.

## What This Changes

The issue requests native iOS Siri/App Intent support so users can ask OpenClaw a dictated question through Siri or Shortcuts and receive a spoken reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or an explicitly hardened hook boundary, chooses agent/session routing deliberately, handles local confirmation and permissions, and returns spoken replies without bypassing Gateway security controls.

## Reproduction Assessment

Not applicable for a feature request. Source and release inspection show there is no native Ask OpenClaw App Intent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.

## Solution Assessment

Unclear as proposed. Native App Intent support likely belongs in the iOS app, but directly posting to /hooks/agent is not the best proven boundary until maintainers approve auth, session routing, reply collection, and spoken-dialog behavior.
