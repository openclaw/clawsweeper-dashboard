Keep open: current main and v2026.6.11 still lack a native iOS Siri/AppIntent registration path, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

The issue requests native iOS Siri/AppIntent and Shortcuts support so users can ask OpenClaw questions by voice without opening the app.

## Best Possible Solution

Define a maintainer-approved first-party iOS AppIntent design that reuses paired-device identity or another hardened gateway boundary, preserves session routing deliberately, and returns spoken replies without weakening gateway controls.

- **Keep webhook workaround external:** Decline first-party Siri agent execution until demand or extension APIs justify the security surface, leaving Shortcuts plus webhook as the workaround.
