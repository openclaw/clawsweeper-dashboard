## What This Changes

Request native iOS Siri/AppIntent support so users can ask OpenClaw by voice, send the prompt to a paired Gateway, and receive a spoken reply through Siri or Shortcuts.

## Best Possible Solution

Ship a scoped native iOS AppIntent only after maintainers choose the user flow, route it through existing paired Gateway auth/session contracts, preserve safe defaults, and capture device proof for Siri/Shortcuts plus spoken reply behavior.

## Reproduction Assessment

The maintainable path is a maintainer-approved native intent that reuses the paired Gateway node/operator contracts and explicit session/delivery policy.
