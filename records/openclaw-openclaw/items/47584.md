## Summary

Keep open: current main and the latest release still do not provide a native, parameterized Siri/App Intent that accepts an OpenClaw question and returns a spoken reply. The request is useful and aligned with iOS companion-app direction, but it needs maintainer product and security review before implementation because it would add a new voice/Shortcuts-triggered agent execution surface.

## What This Changes

Request native iOS Siri/App Intent support so users can ask OpenClaw questions through Siri or Shortcuts and receive spoken replies.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that uses paired-device identity or an explicitly hardened hook boundary, routes agent/session state deliberately, handles local confirmation and permissions, and returns spoken replies without bypassing Gateway security controls.

Not applicable: this is a feature request rather than a broken existing behavior report. Current source and release inspection show no native Ask OpenClaw App Intent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.
