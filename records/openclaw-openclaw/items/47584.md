## Summary

Keep open: current main still lacks the requested parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The closest open PR only opens Talk Mode, and the exact earlier attempt is closed unmerged, so this still needs maintainer product and security direction.

## What This Changes

Add native iOS Siri/App Intent support so a dictated “Ask OpenClaw” question can be sent to a paired Gateway and returned as a spoken Shortcuts/Siri reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, deliberately chooses agent/session routing and confirmation behavior, and returns spoken replies without weakening Gateway controls.

## Reproduction Assessment

## Solution Assessment
