## Summary

Keep open: current main and v2026.6.11 still lack a native parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The request is valid iOS companion-app product work, but it needs maintainer product and security direction before implementation because it would add a new voice/Shortcuts entry point for agent execution.

## What This Changes

Request native iOS Siri/App Intent support so users can ask OpenClaw a dictated question from Siri or Shortcuts and receive a spoken reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a deliberately hardened hook boundary, chooses agent/session routing explicitly, keeps local confirmation where needed, and returns spoken replies without bypassing Gateway security controls.

## Reproduction Assessment

Not applicable: this is a new iOS Siri/App Intent capability request, not a report of broken existing behavior. Source and release inspection show there is no native Ask OpenClaw App Intent to reproduce today.

## Solution Assessment

No, not as proposed: native App Intent support likely belongs in the iOS app, but directly posting to `/hooks/agent` is not the best proven boundary until maintainers approve auth, session routing, reply collection, and spoken-dialog behavior. A paired-node or explicitly hardened hook design is safer.
