## Summary

Keep open: current main still lacks a native parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply. The request is aligned with iOS companion-app direction, but implementation needs maintainer product and security direction before code work because the proposed hook-style path would expose agent execution through Siri and Shortcuts.

## What This Changes

Request to add native iOS Siri/App Intent support so users can ask OpenClaw a dictated question via Siri or Shortcuts and receive a spoken reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or an explicitly secured hook boundary, chooses agent/session routing deliberately, handles local confirmation and permissions, and returns spoken replies without bypassing Gateway security controls.

## Solution Assessment
