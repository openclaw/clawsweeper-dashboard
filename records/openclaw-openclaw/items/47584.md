Keep open: current main and v2026.6.11 still lack a native iOS Siri/AppIntent flow for asking OpenClaw, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

Add native iOS Siri/AppIntent and Shortcuts support so dictated prompts can start an OpenClaw agent turn and return a spoken reply.

## Best Possible Solution

Define a maintainer-approved first-party iOS AppIntent design that reuses paired-device identity or a hardened hook boundary, preserves session routing deliberately, and returns spoken replies without weakening Gateway controls.
