## What This Changes

Options:

- **Approve paired-node App Intent design (recommended):** Implement Siri/Shortcuts on top of the existing paired iOS node/operator identity and chat/session routing so it inherits existing Gateway trust controls.

- **Defer native ask-and-reply:** Keep Shortcuts plus webhook and the Talk Mode launch path as the supported workaround until maintainers prioritize the full Siri surface.
