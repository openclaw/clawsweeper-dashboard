## Summary

Keep open: current main still lacks a native parameterized iOS Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

Requests native iOS Siri/App Intent and Shortcuts support so users can ask OpenClaw a dictated question and receive a spoken response without opening the app.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission and confirmation, and returns spoken replies without weakening Gateway controls.
