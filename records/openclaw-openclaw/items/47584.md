## Summary

Keep open: current main and v2026.6.11 still do not provide a parameterized iOS Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply, and the remaining work needs product and security direction before implementation.

## What This Changes

Request native iOS Siri/App Intent support so users can ask OpenClaw a dictated question and receive a spoken response without opening the app.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that uses paired-device identity or an explicitly hardened hook boundary, preserves agent/session context, asks for confirmation where needed, and returns spoken replies without bypassing Gateway security controls.

## Reproduction Assessment

Not applicable for a feature request. Source and release inspection show there is no native Ask OpenClaw App Intent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.

## Solution Assessment

Unclear as proposed. Native App Intent support likely belongs in the iOS app, but directly posting to /hooks/agent is not the best proven boundary until maintainers approve auth, session routing, reply collection, and spoken-dialog behavior.
