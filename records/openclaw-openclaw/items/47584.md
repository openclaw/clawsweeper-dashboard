Keep open: current main and the latest release still lack a native iOS Siri/App Intent ask-and-spoken-reply flow, and the remaining work needs maintainer product and security direction before implementation.

## What This Changes

The issue requests native iOS Siri/App Intents support so users can ask OpenClaw questions through Siri or Shortcuts and receive spoken replies.

## Best Possible Solution

Define a maintainer-approved native App Intent design that uses paired-device identity or a hardened hook boundary, explicit session routing and confirmation policy, spoken-reply behavior, and real iOS device proof.
