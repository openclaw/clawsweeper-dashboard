## Summary

Keep open: current main and v2026.6.11 still do not provide a parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply, and the remaining work needs maintainer product/security direction before implementation.

## What This Changes

The issue requests native iOS Siri/App Intent support so users can ask OpenClaw questions through Siri or Shortcuts and receive spoken replies.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission and confirmation, and returns spoken replies without weakening Gateway controls.
