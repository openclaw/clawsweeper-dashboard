## Summary

Keep open: current main and v2026.6.11 still do not implement a parameterized Siri/App Intent that accepts a dictated OpenClaw question and returns a spoken reply, and the remaining work needs maintainer direction on the security and session boundary before implementation.

## What This Changes

Request native iOS Siri/App Intent support so users can ask OpenClaw a question from Siri or Shortcuts and receive a spoken reply without opening the app.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission and confirmation, and returns spoken replies without weakening Gateway controls.
