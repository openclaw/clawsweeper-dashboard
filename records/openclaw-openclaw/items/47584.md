## What This Changes

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission/confirmation, and returns spoken replies without weakening Gateway controls.
