## Summary

Keep open: current main still has no native iOS App Intent that accepts a dictated OpenClaw question and returns a spoken Siri/Shortcuts reply, and the remaining work needs maintainer product and security-boundary direction.

## What This Changes

Request native iOS Siri/App Intent support so users can ask OpenClaw a parameterized question from Siri or Shortcuts and receive a spoken reply.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that reuses paired-device identity or a hardened hook boundary, chooses agent/session routing deliberately, handles local permission and confirmation, and returns spoken replies without weakening Gateway controls.
