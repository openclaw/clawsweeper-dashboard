## Summary

Keep open: current main and the latest release still lack a native parameterized Siri/App Intent that accepts an OpenClaw question and returns a spoken reply. The related https://github.com/openclaw/openclaw/pull/40874 only overlaps with launch-to-Talk behavior, and the remaining Siri/Shortcuts agent-entry path needs maintainer product and security direction.

## What This Changes

Request native iOS Siri/App Intent support that accepts a dictated OpenClaw question, invokes the paired Gateway, and returns a spoken reply through Siri or Shortcuts.

## Best Possible Solution

Define a maintainer-approved iOS App Intent design that uses paired-device identity or a hardened hook boundary, preserves local confirmation and session routing rules, and adds redacted device or simulator proof for the Siri ask-and-spoken-reply flow.

## Reproduction Assessment

Not applicable for a feature request. Source and release inspection show there is no native Ask OpenClaw App Intent, AppShortcutsProvider, or ProvidesDialog implementation to reproduce today.

## Solution Assessment
