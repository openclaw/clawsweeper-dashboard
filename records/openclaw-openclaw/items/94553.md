## Best Possible Solution

Land a narrowed QQBot-owned retry hardening change that clamps the final jittered delay, clears lint, retains bounded token response reads, proves the background loop behavior with redacted runtime or realistically wired logs, and gets maintainer acceptance of the cooldown default.

## Solution Assessment
