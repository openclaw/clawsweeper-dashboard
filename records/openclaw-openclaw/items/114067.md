## What This Changes

Avoid loading the full configuration stack for `openclaw --help` when a parsed `plugins` value cannot change the precomputed root-help output.

## System Context

Root CLI help normally prints precomputed command text, but it first checks live plugin configuration because plugin settings and plugin-related environment variables can alter that output. The proposed optimization decides whether that live check is necessary, preserving the full configuration path whenever config or dotenv state could affect plugin help.
