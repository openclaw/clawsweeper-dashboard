## What This Changes

The PR retries a protected local chat-avatar image request with newly available Control UI authentication candidates after the first request receives 401 or 403.

## System Context

Control UI chat first requests avatar metadata, then fetches local avatar bytes from the gateway and converts them to a browser object URL. This change only affects recovery when the image request starts before a usable live-session credential is available.
