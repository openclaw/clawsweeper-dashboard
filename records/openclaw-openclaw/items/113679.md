## What This Changes

The branch retries a failed local chat-avatar image request with Control UI authentication candidates that become available after the first 401 or 403 response.

## System Context

Control UI chat refreshes an assistant avatar by reading avatar metadata and then fetching local avatar bytes for display. This change sits between the browser's session credentials and the rendered chat avatar, so it affects recovery when credentials arrive after the initial image request.
