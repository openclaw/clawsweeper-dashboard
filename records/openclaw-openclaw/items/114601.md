## Summary

Keep this PR open. The local filesystem path now gives useful directory guidance, but the conditional `ops.stat` guard leaves supported injected read backends on the same raw-error path; this repeats the prior P2 finding and remains a merge blocker.

## What This Changes

The PR adds an optional stat operation to the agent read tool and uses it in the local backend to reject directory paths before attempting a file read.

## System Context

OpenClaw agents call the read tool through a filesystem-operation abstraction that can be backed by local, sandboxed, or remote storage. The tool validates a requested path and returns file content or an error message to the model, which then chooses a follow-up action such as listing a directory.

## Best Possible Solution

Make directory rejection a read-tool invariant across local, sandboxed, and remote operation implementations, then add focused coverage for both a directory and a normal file in each supported backend path.
