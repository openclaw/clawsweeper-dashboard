## Summary

Keep this PR open, but it is not ready to merge: the watchdog treats local `tar` output as end-to-end SSH progress, so a valid small upload can become silent locally while the SSH session is still legitimately completing or draining and then be killed after 30 seconds. The real-client proof credibly establishes the reported hang, but the proposed liveness boundary needs correction before merge.

## What This Changes

The PR adds a 30-second idle watchdog and regression tests so SSH sandbox directory uploads reject and terminate their child processes when the upload pipeline stops making local progress.

## System Context

Agent sandbox setup archives a local workspace with `tar` and feeds that stream into the system SSH client, which extracts it in a remote sandbox. This helper sits on the setup path before an agent can use the remote workspace, so its completion and cancellation behavior controls sandbox availability.

## Best Possible Solution

Use a timeout boundary that distinguishes a genuinely wedged SSH pipeline from a completed local producer with remaining valid SSH work, then add focused coverage for a small archive whose SSH child closes only after the idle interval and refresh the branch against current `main`.
