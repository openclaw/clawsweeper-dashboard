## Summary

The PR addresses a real unbounded SSH-upload wait with a narrowly scoped no-progress watchdog, strong real-client proof, and focused regression coverage. It remains necessary because current main still waits only for process errors or both child closes; a sandbox-area owner should explicitly accept the new default 30-second no-progress failure boundary before merge.

## What This Changes

The branch adds a 30-second idle watchdog, an optional internal `idleTimeoutMs` override, and stream-error regression tests for `uploadDirectoryToSshTarget`.

## Best Possible Solution

Keep the progress-based watchdog and merge only after the SSH sandbox owner confirms that a 30-second zero-progress failure is the intended default compatibility boundary.
