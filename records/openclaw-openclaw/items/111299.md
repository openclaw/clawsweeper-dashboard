## Summary

## What This Changes

Adds a 30-second no-progress watchdog, optional `idleTimeoutMs` override, and regression coverage for SSH sandbox directory uploads that stall without transferring data.

## Best Possible Solution

Keep the progress-aware watchdog, confirm that a 30-second zero-progress failure is the intended sandbox-upload contract, and land it with the focused regression coverage and real-client proof retained in the PR body.
