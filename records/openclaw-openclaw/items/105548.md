## Summary

Keep open: the unchanged head still exposes a 120-second hosted timeout but does not pass it from hosted production callers, so OpenAI, Google, and Voyage memory requests inherit the 600-second local default instead of the advertised bound. The proof is strong and the remaining repair is narrow.
