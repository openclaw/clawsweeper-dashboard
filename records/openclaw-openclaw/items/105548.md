## Summary

Keep this PR open: the unchanged head still has the previously reported P1 defect, because hosted embedding requests inherit the 600-second local timeout instead of their established 120-second budget.

## What This Changes

The branch adds a default timeout floor to memory remote HTTP, permits `postJson` timeout overrides, exports timeout constants through the plugin SDK, and adds hung-response regression coverage.

## Best Possible Solution

Keep the 600-second compatibility default for local/self-hosted requests, explicitly pass the 120-second constant from every hosted provider path, and prove both timeout classes without adding unnecessary permanent SDK surface.
