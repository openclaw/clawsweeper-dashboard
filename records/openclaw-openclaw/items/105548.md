## Summary

Keep open: the reliability fix is valid and strongly demonstrated, but the current head still defines a 120-second hosted timeout without passing it from hosted provider callers, so those requests inherit the 600-second local floor. The prior P1 finding remains unresolved on the same reviewed SHA.
