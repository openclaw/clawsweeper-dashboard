## Summary

Keep open: the hang is real and the shared wrapper improves it, but the previously reported hosted-provider propagation gap remains unchanged at the same reviewed head, so the PR is not merge-ready.

## What This Changes

Adds local and hosted timeout constants to memory remote HTTP, applies a default local timeout floor, forwards optional overrides through `postJson`, exports the constants through the plugin SDK, and adds hung-response coverage.

## Best Possible Solution

Keep the 600-second local/self-hosted default, pass the 120-second hosted timeout from the actual hosted provider call sites, preserve explicit overrides and caller cancellation, and cover both direct and batch production callers.
