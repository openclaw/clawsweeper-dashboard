## Summary

Keep this PR open, but do not merge its current head. The previously reported P1 remains unchanged: hosted OpenAI, Voyage, and Google memory requests still inherit the 600-second local/self-hosted floor because the new 120-second hosted timeout is defined and exported but not passed by the hosted callers.

## What This Changes

Adds provider-aware default timeout floors to memory remote HTTP, forwards timeout overrides through JSON posts, exports the timeout constants through the plugin SDK, and adds hung-response regression coverage.

## Best Possible Solution

Keep the 600-second compatibility default for local/self-hosted endpoints, explicitly pass the 120-second constant from every hosted provider upload, submit, poll, and result-download path, and add propagation tests proving both timeout tiers.
