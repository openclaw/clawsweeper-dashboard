## Summary

Keep this PR open: the default timeout correctly addresses indefinite remote-memory hangs, but the provider-based hosted classification can regress supported custom/self-hosted endpoints, and the submitted evidence remains test-only rather than after-fix real behavior proof.

## What This Changes

Adds 600-second local and 120-second hosted memory HTTP timeout defaults, composes them with caller abort signals, introduces hosted Plugin SDK helpers, migrates hosted provider callers, and adds regression tests.

## Best Possible Solution

Classify the resolved endpoint rather than the provider name: apply 120 seconds only to known vendor-hosted routes, preserve 600 seconds for configured custom/self-hosted endpoints, retain explicit overrides and earlier caller aborts, and demonstrate the corrected paths in a redacted standalone or real-provider run.
