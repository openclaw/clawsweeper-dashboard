## What This Changes

The PR adds a 120-second default timeout to memory remote HTTP, composes it with caller cancellation, and forwards explicit timeout overrides through `postJson`.

## Best Possible Solution

Keep the shared timeout at the memory HTTP owner boundary, preserve caller cancellation and explicit overrides, and land it after redacted live-provider evidence confirms ordinary embedding requests still succeed under the 120-second default.
