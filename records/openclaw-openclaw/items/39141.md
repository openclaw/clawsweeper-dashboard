## Summary

Keep open: current main still has internal liveness diagnostics and session active-run flags, but not the requested default-off session activity watchdog with public activity state, attention timers, deduped operator alerts, delivery/webhook outputs, or optional tokenized summaries.

## What This Changes

Request to add an opt-in gateway-side session activity watchdog that consumes a future sessions.activity API and emits operator alerts for stale or blocked sessions.

## Best Possible Solution

Settle the public session activity and attention contract first, then design a lean default-off watchdog with payload-minimized alerts, dedupe/cooldowns, docs, tests, and separately gated delivery or summary extensions.
