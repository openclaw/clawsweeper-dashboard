Keep open: current main and the latest release still lack the requested default-off gateway-side session activity watchdog, alert delivery, cooldown/dedupe policy, and optional tokenized summaries. ## What This Changes

Request a default-off gateway-side watchdog that consumes session activity state and emits operator alerts for stale, waiting, or stuck child-session states.

## Best Possible Solution

Settle the public session activity and attention contract first, then design a lean default-off watchdog with payload-minimized alerts, dedupe/cooldowns, docs, tests, and separately gated delivery or summary extensions.
