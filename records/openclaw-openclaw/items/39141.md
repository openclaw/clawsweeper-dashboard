## Summary

Keep open: current main and v2026.6.11 still lack the requested default-off session activity watchdog, deduped operator alerts, webhook/channel delivery, and optional tokenized summaries; related open work is prerequisite or partial overlap, not a replacement.

## What This Changes

Add a default-off gateway-side session activity watchdog that consumes sessions.activity state and emits deduped operator alerts with optional summaries.

## Best Possible Solution

Settle the public sessions.activity and attention contract first, then design a lean default-off watchdog with metadata-only baseline alerts, dedupe/cooldowns, tests, docs, and separately gated delivery or summary extensions.
