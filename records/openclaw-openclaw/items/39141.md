## Summary

Keep open: current main and v2026.6.11 have diagnostic stuck/stalled session telemetry and recovery hooks, but not the requested default-off session activity watchdog with operator alerts, delivery targets, webhooks, dedupe/cooldowns, or optional summaries. The prerequisite gateway activity-state contract remains open, and the related PRs are partial, open, and conflict-marked rather than merged canonical fixes.

## What This Changes

The issue requests an optional gateway-side session activity watchdog that consumes session activity state and emits configurable, deduped operator alerts with optional tokenized summaries.

## Best Possible Solution

Settle and land one gateway-owned activity/attention contract first, then design a default-off watchdog that emits payload-minimized alerts with dedupe, cooldowns, docs, and tests for no-credential baseline behavior plus gated optional summaries.
