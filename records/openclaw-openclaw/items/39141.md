## Summary

Keep open: current main and v2026.6.11 still lack the requested default-off gateway-side session activity watchdog, alert delivery, cooldown/dedupe policy, and optional tokenized summaries; existing diagnostics and open related PRs are partial prerequisites, not replacements.

## What This Changes

Request a built-in optional gateway-side watchdog that consumes session activity state and emits low-noise operator alerts for stale, waiting, or stuck session work.

## Best Possible Solution

Settle the public session activity and attention contract first, then design a lean default-off watchdog with payload-minimized alerts, dedupe/cooldowns, docs, tests, and separately gated delivery or summary extensions.
