## Summary

Keep open: current main and v2026.6.11 still lack the requested default-off gateway-side session activity watchdog, alert delivery, cooldown/dedupe policy, and optional tokenized summaries; existing diagnostics and open PRs are partial prerequisites, not replacements.

## What This Changes

The issue requests an optional gateway-side watchdog that consumes per-session activity state and emits operator alerts for stale, waiting, or stuck child-session work.

## Best Possible Solution

Settle the public session activity and attention contract first, then design a lean default-off watchdog with payload-minimized alerts, dedupe/cooldowns, docs, tests, and separately gated delivery or summary extensions.
