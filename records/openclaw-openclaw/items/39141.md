## Summary

Keep open: current main and v2026.6.11 still lack the requested default-off gateway-side session activity watchdog, alert delivery surface, cooldown/dedupe policy, and optional tokenized summaries. The related activity API issue and open PRs are prerequisites or partial overlaps, not replacements for this operator alerting feature.

## What This Changes

The issue requests an opt-in gateway-side session activity watchdog that consumes per-session activity state and emits privacy-conscious alerts for stale, waiting, or stuck child-session conditions.

## Best Possible Solution

Settle the public session activity and attention contract first, then design a lean default-off watchdog with payload-minimized alerts, dedupe/cooldowns, tests, docs, and separately gated delivery or summary extensions.
