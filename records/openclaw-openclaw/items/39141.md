Keep open: current main and v2026.6.11 still lack the requested default-off session activity watchdog, deduped operator alerts, delivery targets, webhook output, and optional tokenized summaries. ## What This Changes

The issue requests a default-off gateway-side session activity watchdog that consumes session activity state and emits deduped/rate-limited operator alerts, optional delivery/webhooks, and opt-in tokenized summaries.

## Best Possible Solution
