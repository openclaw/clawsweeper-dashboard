## Summary

Keep open: current main still lacks the public session-activity contract and the downstream default-off watchdog/alert delivery layer requested here; the related open PRs are prerequisites or partial overlaps, not replacements.

## What This Changes

Request an opt-in gateway-side session activity watchdog that consumes session activity state and emits deduped operator alerts, webhook/channel outputs, and optional tokenized summaries.
