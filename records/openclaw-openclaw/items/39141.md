## Summary

Keep open: current main and latest release still lack the requested default-off session activity watchdog and operator alerting layer. Existing diagnostics/telemetry and open PRs are useful adjacent work, but they do not replace deduped threshold alerts, delivery targets, webhook output, privacy-scoped payloads, or optional gated summaries built on the still-open activity contract.

## What This Changes

The issue requests an optional gateway-side watchdog that consumes session activity state, detects stale or blocked sessions, and emits deduped operator alerts with optional tokenized summaries.

## Best Possible Solution

Settle the canonical session activity/attention API first, then design a lean default-off watchdog that emits payload-minimized alerts with dedupe, cooldowns, docs, tests, and separately gated optional summaries or plugin-owned delivery surfaces.
