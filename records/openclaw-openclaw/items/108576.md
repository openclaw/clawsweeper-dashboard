## What This Changes

The PR changes OC Path URI length enforcement and diagnostics from JavaScript string units to UTF-8 bytes and adds multibyte limit regressions.

## Best Possible Solution

Land the centralized UTF-8 byte enforcement in the parser and formatter while retaining the existing 4,096-byte contract and the raw, post-NFC, formatted-output, boundary, and diagnostic regressions.
