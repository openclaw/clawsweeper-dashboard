## What This Changes

This PR yields between paged SQLite transcript-delta reads and shares one in-flight touched-files fold per session so a cold Files-panel request does not monopolize the gateway event loop.

## System Context

The gateway's `sessions.files.list` method folds a session's paged SQLite transcript delta into a list of touched files for the Control UI. The fold uses a process-local cache; this change lets the event loop serve other requests between pages while preventing concurrent callers for the same cache key from mutating that cache in parallel.
