## What This Changes

The branch preserves canonical Voice Wake SQLite data when legacy Voice Wake JSON conflicts, archives the legacy files after a committed migration, propagates migration notices, and adds regression plus foreground Gateway proof coverage.

## System Context

Voice Wake settings are being migrated from legacy JSON files into OpenClaw’s shared SQLite state database. Startup and Doctor aggregate migration warnings before Gateway readiness, so a non-converging legacy source can otherwise prevent the Gateway from becoming ready on every boot.
