## Summary

Keep open. Current main still lacks REST-native session reset/status/compact/model/reasoning endpoints for HTTP integrations; the related plugin reset work and broader HTTP-query tracker do not cover this mutating control-plane surface.

## What This Changes

Request authenticated REST endpoints for HTTP integrations to reset, inspect, compact, and update per-session model/reasoning state without enabling slash-command dispatch.

## Best Possible Solution

Add a narrow authenticated Gateway HTTP session-management surface that maps to existing session RPC/shared helpers, enforces operator scopes, preserves default-deny slash-command handling, and updates route/auth/docs tests.

## Reproduction Assessment

Yes. Source inspection shows current main has no /v1/sessions reset/status/compact/model/reasoning routes, while /v1/chat/completions still sends ordinary agent turns without CommandAuthorized.

## Solution Assessment

Unclear until maintainers approve the HTTP API and security shape. The best direction is a focused Gateway HTTP route layer over existing session RPC/helpers, not re-enabling slash-command interpretation for HTTP chat.
