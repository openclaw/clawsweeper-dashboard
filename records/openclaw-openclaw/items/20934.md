## Summary

Keep open: current main and v2026.6.11 still lack REST-native reset/status/compact/model/reasoning endpoints for HTTP integrations, while the existing plugin reset PR, admin HTTP RPC plugin, and broader read-only REST issue only partially overlap.

## What This Changes

Request REST-native session reset, status, compact, model, and reasoning controls for clients using the OpenAI-compatible `/v1/chat/completions` HTTP gateway.

## Best Possible Solution

Choose one public HTTP control-plane shape and, if approved, implement narrow authenticated `/v1/sessions/*` routes over existing Gateway session RPC handlers with docs, route/auth tests, reserved-key validation, and slash-command default-deny preserved.
