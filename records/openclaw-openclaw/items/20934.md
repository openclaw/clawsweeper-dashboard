## What This Changes

The issue requests authenticated REST session-management endpoints for clients using the OpenAI-compatible `/v1/chat/completions` HTTP API.

## Best Possible Solution

Add a narrow authenticated Gateway HTTP session-management surface that maps reset/status/compact/model/reasoning to existing Gateway session RPC/shared helpers, preserves default-deny slash-command handling, and includes route/auth/request/response docs and tests.
