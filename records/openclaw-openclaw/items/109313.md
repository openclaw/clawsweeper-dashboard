## What This Changes

The PR reclassifies bare provider `finish_reason: error` and stop-reason `error` messages from timeout to server error while preserving fallback eligibility and raw operator-facing diagnostics.

## Best Possible Solution

Keep the dedicated server-error classification, update the Model failover documentation to distinguish bare `error` from abort/network/malformed timeout signals, and prove the full gateway path with a local OpenAI-compatible fixture or a redacted live OpenRouter run.
