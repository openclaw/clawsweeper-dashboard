## What This Changes

This PR adds optional per-run budgets for embedded agents, stopping model/tool/provider work at configured limits and returning a typed terminal envelope through the OpenAI-compatible chat API.

## System Context

Embedded-agent runs power OpenClaw agent commands and gateway requests: a selected agent invokes a model, may call server tools, and can retry through provider fallbacks. This PR inserts one run-level budget controller across those steps and forwards its terminal result to OpenAI-compatible HTTP clients.
