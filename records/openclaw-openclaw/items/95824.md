## Summary

Keep this PR open: the latest head validates the new DeepInfra paths, but still silently changes the shipped meaning of `nativeBaseUrl`, so existing custom native-endpoint setups can stop generating video after an upgrade.

## What This Changes

Moves DeepInfra text-to-video generation to its asynchronous OpenAI-compatible videos API with live model discovery, tags DeepSeek-family models with the DeepSeek thinking dialect, and updates focused tests and provider documentation.

## Best Possible Solution

Keep the new hosted DeepInfra OpenAI-video flow and DeepSeek dialect tagging, while preserving native behavior whenever the shipped `nativeBaseUrl` key is present—or replacing it only through an explicit owner-approved deprecation/migration—with fresh-install and upgrade regression coverage.
