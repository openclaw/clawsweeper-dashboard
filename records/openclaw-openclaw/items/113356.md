## What This Changes

The PR queues detached chat-row cleanup until after Lit finishes re-stamping the virtualized transcript, preventing overlapping or gapped bubbles when users switch between Chat and Dashboard faces.

## System Context

The Control UI renders each session transcript as virtualized, absolutely positioned chat rows. Lit row references feed the virtualizer’s measurement and ResizeObserver tracking, which determines row positions in both the full Chat face and Dashboard’s docked chat panel.
