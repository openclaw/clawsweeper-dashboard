## Summary

The compaction and JSON-escaping fixes are well-supported, but the validation wording change breaks established mixed-version gateway fallbacks that recognize only single-quoted property names, so this PR is not merge-ready.

## What This Changes

The PR emits `after_compaction` for successful no-op compactions with an optional reason and JSON-escapes property names in gateway and plugin validation messages.

## Best Possible Solution

Centralize tolerant recognition of unsupported-property validation errors so both legacy single-quoted and new JSON-quoted gateways preserve mixed-version retries, then retain the JSON escaping and exactly-once no-op compaction notification fixes.
