## What This Changes

This PR emits `after_compaction` after successful no-op compactions, JSON-quotes validator property names, and keeps older-gateway retry fallbacks working with either legacy or JSON-quoted validation errors.

## System Context

Embedded-agent compaction notifies internal and plugin hooks before and after it processes a session; plugin observers use those signals to coordinate recovery work. Gateway and plugin schema validators send parameter errors back to tools and models, while several callers recognize those errors to retry against older gateways.
