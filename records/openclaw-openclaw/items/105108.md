The PR makes both paid and free Parallel web-search tools reject explicit counts that are not integers from 1 through 40 before transport, with regression coverage for each provider.

## Best Possible Solution

Land the shared strict-validation change for both Parallel transports while preserving configured/default result-count fallback and the existing final normalization for trusted configuration values.
