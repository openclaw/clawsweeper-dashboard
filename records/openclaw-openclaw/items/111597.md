## What This Changes

The issue proposes replacing platform-specific offline persistence with installation-wide SQLite cache and durable client-state stores shared by Apple clients and conceptually mirrored on Android.

## Best Possible Solution

Review the Apple PR as a bounded first step, require explicit migration and recovery guarantees for existing installs, and retain this issue as the canonical cross-platform contract until an Android implementation and shared ownership criteria are defined.
