## What This Changes

This PR records a locale whose lazy translation module failed while offline, retries it when the Gateway reconnects, and falls back to the existing guarded stale-chunk reload mechanism when the browser keeps the failed import cached.

## System Context

The Control UI loads non-default translations lazily from the Gateway. A language selection flows through the i18n manager into browser module loading; Gateway connection state then triggers retry recovery so the rendered UI chrome can match the persisted preference.
