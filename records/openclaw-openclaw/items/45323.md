Request Slack-style `@agent-name` autocomplete, mention chips, validated history rendering, and possibly a new agent-directory RPC for the Control UI chat composer.

## Best Possible Solution

Define one shared accessible composer suggestion model for slash commands, agent mentions, and adjacent custom-term suggestions, then reuse `agents.list` or extend it only if maintainers confirm a directory-specific API is needed.
