## Summary

Keep open: current main and the latest release still have a slash-only textarea Control UI composer, no @agent autocomplete, no mention chips, and no validated mention rendering. The request is useful, but it needs maintainer product/API scoping because `agents.list` already exposes agent identity metadata and the adjacent custom-term autocomplete issue overlaps without fully duplicating it.

## What This Changes

Add Slack-style @agent mention autocomplete, styled mention chips, and validated mention rendering to the Control UI chat composer.

## Best Possible Solution

Define one shared accessible Control UI composer suggestion model for slash commands, agent mentions, and custom terms, then reuse or deliberately extend `agents.list` only if the existing metadata contract is insufficient.
