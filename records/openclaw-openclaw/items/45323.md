## Summary

Keep open: current main and the latest release still only support slash-command suggestions in the Control UI chat composer; the requested @agent dropdown, mention chips, validated history rendering, and optional new agent-directory API are not implemented. The adjacent custom-term autocomplete issue overlaps at the composer-suggestion layer but is not a duplicate, so this needs maintainer product/API scoping rather than cleanup closure.

## What This Changes

Request to add Slack-style @agent mention autocomplete, mention chips, and validated mention rendering to Control UI chat, with possible gateway agent-directory metadata.

## Best Possible Solution

Define one shared accessible composer suggestion model for slash commands and @agent mentions, reuse agents.list metadata unless a real gap requires a new API, and add mention rendering with focused UI and gateway tests.
