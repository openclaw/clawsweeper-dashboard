## Summary

Keep open: current main and the latest release still only provide slash-command textarea suggestions in Control UI chat; no @agent dropdown, mention chips, validated mention rendering, or agents.directory RPC exists. The adjacent custom-term autocomplete issue overlaps at the shared composer-suggestion level but is not a duplicate, so this needs maintainer product/API scoping rather than cleanup closure.

## What This Changes

Request adding Slack-style @agent mention autocomplete, styled mention chips, and validated mention rendering to the Control UI chat composer, possibly backed by a new agent directory RPC.

## Best Possible Solution

Define one shared accessible composer suggestion model for slash commands, @agent mentions, and future custom terms, reusing agents.list metadata unless a specific missing metadata gap requires a new RPC.
