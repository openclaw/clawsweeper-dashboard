## Summary

Keep open: current main still has slash-command-only textarea suggestions in Control UI chat, no @agent dropdown, no mention chips, no validated mention rendering, and no `agents.directory` RPC. The related custom-term autocomplete issue overlaps at the composer-suggestion layer but is distinct, so this needs maintainer product/API scoping rather than cleanup closure.

## What This Changes

Request adds @agent mention autocomplete, styled mention chips, validated history rendering, and possibly a new `agents.directory` gateway RPC in Control UI chat.

## Best Possible Solution

Define one shared accessible composer suggestion model for slash commands, @agent mentions, and future custom terms, reusing `agents.list` metadata unless a specific metadata gap requires a new RPC.
