## Summary

Keep open: current main still documents and tests that substantive `message_tool_only` finals can be withheld, while session persistence and replay keep assistant messages as normal context without a delivery-status marker; the follow-up comment adds concrete production evidence that this phantom context caused later agent actions.

## What This Changes

The issue asks OpenClaw to represent withheld `message_tool_only` assistant finals in agent-facing context so later turns know the user did not receive them.

## Best Possible Solution

Make delivery reality part of the core replay contract: a withheld message_tool_only final should either be replayed with an explicit undelivered marker or replaced by a concise system notice, coordinated with stranded-final recovery work.
