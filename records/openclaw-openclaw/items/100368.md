## Summary

Keep open: current main still suppresses substantive `message_tool_only` finals while replay/persistence paths can keep the undelivered assistant text as ordinary assistant context, so the reported session-state drift remains unresolved.

## What This Changes

The issue requests that withheld `message_tool_only` final replies be represented in later agent context as undelivered instead of ordinary assistant turns.

## Best Possible Solution

Make delivery reality part of the replay/session-context contract: a withheld `message_tool_only` final should either replay with an explicit undelivered marker or be replaced by a concise system notice, coordinated with stranded-final recovery.
