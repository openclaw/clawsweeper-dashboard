## Summary

Keep open: current main still has the reported delivery/context mismatch. Source inspection shows substantive `message_tool_only` finals are kept private and not delivered, while CLI/context-engine paths can persist or ingest the assistant final as an ordinary assistant turn without an undelivered marker; the active recovery PR overlaps the message-loss side but does not settle replay truth for already-withheld finals.

## What This Changes

The issue asks OpenClaw to make withheld `message_tool_only` assistant finals visible as undelivered in agent-facing context so later turns do not treat them as messages the user saw.

## Best Possible Solution

Make delivery reality part of the core session/replay contract: withheld `message_tool_only` finals should either replay with an explicit undelivered marker or be replaced by a concise undelivered notice, coordinated with the active stranded-final recovery work.
