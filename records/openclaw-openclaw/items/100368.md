## Summary

Keep open: current main still treats substantive `message_tool_only` finals as private and undelivered, while the assistant text can persist and replay as ordinary context without a delivery-status marker; this needs maintainer direction, not cleanup closure.

## What This Changes

The issue requests that withheld `message_tool_only` final replies stop replaying to the agent as ordinary delivered assistant turns.

## Best Possible Solution

Make delivery reality part of the core replay contract: a withheld `message_tool_only` final should either replay with an explicit undelivered marker or be replaced by a concise system notice, coordinated with stranded-final recovery work.
