## Summary

Keep open: current main still suppresses substantive `message_tool_only` finals while session persistence and replay keep assistant messages as ordinary context, so the agent can later reason from text the user never received. The related recovery PR may reduce the missing-outbound cases, but it does not by itself settle the durable replay representation for already-withheld finals.

## What This Changes

Request to mark or replace withheld `message_tool_only` finals in agent-facing context so later turns know the user did not receive them.

## Best Possible Solution

Make delivery reality part of the core replay contract: a withheld `message_tool_only` final should either replay with an explicit undelivered marker or be replaced by a concise notice, coordinated with stranded-final recovery work.
