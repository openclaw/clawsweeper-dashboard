## Summary

Keep open: current main still treats substantive `message_tool_only` finals as private and non-delivered, while Codex records/replays assistant response items as normal model history without an OpenClaw delivery-status marker, so the reported context desynchronization remains unresolved.

## What This Changes

The issue asks OpenClaw to make withheld `message_tool_only` finals visible as undelivered in later agent context instead of replaying them as normal assistant turns.

## Best Possible Solution

Make delivery reality part of the replay contract: a withheld `message_tool_only` final should either be replayed with an explicit undelivered marker or replaced by a concise system notice, coordinated with stranded-final recovery work.
