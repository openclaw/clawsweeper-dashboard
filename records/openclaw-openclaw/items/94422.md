Full review comments:

- **[P2] Preserve snapshot replacement before substring dedupe:** `src/channels/progress-draft-compositor.ts:531-535`
  - body: This guard now runs before `options?.snapshot` and `isReasoningSnapshotText()`. For snapshot providers, `incoming` is the full replacement state; if a later snapshot shortens from `Reading files` to `Reading`, this returns the stale longer buffer instead of replacing it. Move this guard after the snapshot branch, or skip it when the payload is a snapshot, and add the shorter-snapshot regression.
  - confidence: 0.9

  - body: The Slack sibling helper has the same ordering regression: the new shorter-prefix guard returns `current` before the explicit Slack snapshot branch. That can leave stale visible Slack progress text when a snapshot payload revises or shortens the buffer, so apply the same snapshot-precedence fix and test here too.
  - confidence: 0.88
