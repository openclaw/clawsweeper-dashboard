## Summary

Keep open: current main and latest release still reset the gateway model catalog/provider auth during hot reload without clearing the per-agent model discovery cache, and the open closing PR that addresses that gap has not merged.

## What This Changes

The issue reports that gateway hot reload can leave include-defined models out of an in-memory model registry, causing phantom `Unknown model` failover errors until restart.

## Best Possible Solution

Keep this issue open until https://github.com/openclaw/openclaw/pull/99789 or a narrower equivalent lands with include-root hot-reload proof.
