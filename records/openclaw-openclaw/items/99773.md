## Summary

Keep open: current main still omits embedded-agent model discovery cache invalidation during hot reload, and the report is now backed by production logs plus open candidate fix PRs. The issue should stay open until one canonical fix PR merges.

## What This Changes

The issue reports that config hot reload can leave include-defined provider models out of long-running gateway model registries, causing `Unknown model` failover errors until restart.

## Best Possible Solution

Land one canonical narrow cache-invalidation PR, with https://github.com/openclaw/openclaw/pull/99853 currently carrying the strongest proof, then close this issue as implemented.
