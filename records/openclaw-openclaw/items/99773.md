## What This Changes

The issue requests that gateway hot reload preserve or rebuild models supplied through config includes authorized by OPENCLAW_INCLUDE_ROOTS so running sessions do not fail with phantom Unknown model errors.

## Best Possible Solution

Fix the canonical hot-reload/model-registry lifecycle so effective model-source changes, including external config includes, invalidate or refresh every registry snapshot used for turns, with regression coverage for an unrelated channel reload preserving include-defined models.
