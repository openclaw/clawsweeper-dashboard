## Summary

Keep open: current main and the latest release still omit embedded-agent model-discovery cache invalidation during gateway hot reload, while multiple open PRs are candidate fixes rather than merged implementations.

## What This Changes

The issue reports that gateway hot reload can leave include-defined models missing from running in-memory model registries, causing `Unknown model` failover errors until restart.

## Best Possible Solution

Land one narrow cache-invalidation PR that clears the embedded-agent discovery cache during the existing gateway hot-reload model-state reset, then close the duplicate candidate PRs and this issue with the merged commit.

## Reproduction Assessment

Yes, at source level: current main can reuse cached embedded-agent registries whose fingerprint omits resolved `models.providers`, and hot reload does not clear that cache. I did not run a live failing gateway reproduction in this read-only review.

## Solution Assessment

Yes: invalidating the existing embedded-agent discovery cache in the hot-reload model-state reset is the narrow maintainable fix, avoiding steady-state polling or downstream unknown-model fallbacks.
