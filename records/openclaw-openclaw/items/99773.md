## What This Changes

The issue reports that config hot reload can make `OPENCLAW_INCLUDE_ROOTS` include-defined models disappear from running gateway model registries until restart.

## Best Possible Solution

Land one narrow cache-invalidation fix, preferably the smallest proven candidate, then close this issue with the merged commit and any release provenance.

## Reproduction Assessment

Do we have a high-confidence way to reproduce the issue? Yes for source-level triage: reporter logs show the production failure, and current main shows cached model discovery stores are reused without a resolved-config fingerprint or hot-reload reset. I did not run a live current-main gateway reproduction in this read-only pass.

## Solution Assessment

Is this the best way to solve the issue? Yes: invalidate or rebuild the embedded-agent discovery cache during the existing hot-reload model-state reset, with include-backed regression coverage. A fallback that accepts unknown models would mask the stale-registry bug rather than fix the owner boundary.
