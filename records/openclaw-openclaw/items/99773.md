## What This Changes

Issue reports that config hot reload can leave include-defined models out of the running gateway model registry, causing in-process failover to reject valid model ids until restart.

## Best Possible Solution

Land one narrow, proof-backed fix that clears the embedded-agent model discovery cache during hot reload and proves include-backed model survival, then close this issue.
