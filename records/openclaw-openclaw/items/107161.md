## Summary

Current main has a mature generic diagnostics pipeline, including bounded security and tool-policy events, but it does not provide the requested safety-focused query and dashboard surfaces. This issue should remain open because an open linked PR is the active implementation candidate and the parent program still requires product and security decisions about extending generic diagnostics versus creating a separate core safety taxonomy.

## What This Changes

Add a CLI command and Control UI dashboard for querying, summarizing, filtering, and visualizing AI safety taxonomy events at scale.

## Best Possible Solution

Approve one canonical diagnostics contract first, then build the CLI and Control UI as filtered views over a bounded, authorized, SQLite-backed event store with server-side pagination and aggregates; represent safety policy through typed event fields rather than a parallel telemetry pipeline.
