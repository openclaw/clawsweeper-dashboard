## Summary

Keep open: PNG preservation is useful, but the current head retains the previously identified Android sizing defect and has only mock/test evidence rather than an observed native-client send.

## What This Changes

The PR changes Android and Apple native attachment processing to retain PNG encoding, MIME type, filename extension, and transparency while applying existing transport bounds.

## Best Possible Solution
