## What This Changes

The PR changes Android picker, Apple chat, and iOS share processing so bounded PNG attachments retain PNG encoding, MIME type, filename extension, transparency, and metadata stripping instead of being normalized to JPEG.

## Best Possible Solution

Adopt one explicit cross-native image-upload policy—preferably bounded PNG preservation when maintainers want PNG fidelity, with JPEG retained for other formats—then require redacted real-device sends through Android picker, Apple chat, and iOS share that verify gateway MIME, filename, transparency, metadata removal, dimensions, and payload size.
