## What This Changes

The PR changes Android, Apple chat, and iOS share image processing so bounded PNG inputs retain PNG encoding, MIME type, filename extension, transparency, and metadata stripping instead of being normalized to JPEG.

## Best Possible Solution

Adopt one explicit cross-native upload policy—prefer bounded PNG preservation if native owners accept its size and scaling tradeoffs—then prove Android picker, Apple chat, and iOS share sends on real clients with gateway-observed PNG bytes, MIME type, filename, transparency, and payload limits.
