## Summary

The focused tests and six prior review cycles support the implementation shape, but this PR should stay open because it reverses the established native JPEG-normalization policy without native-owner confirmation and still lacks after-fix real-device-to-gateway proof.

The PR changes Android, Apple chat, and iOS share image processing so PNG attachments remain bounded PNGs with matching MIME types and filenames instead of being normalized to JPEG.

## Best Possible Solution

Adopt one explicit cross-native upload policy—preferably preserving PNG when alpha or format fidelity requires it while retaining a bounded delivery path for opaque or oversized inputs—then prove Android picker, Apple chat, and iOS share sends on real devices with gateway-observed bytes, MIME type, filename, dimensions, and transparency.
