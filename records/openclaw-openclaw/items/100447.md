## Summary

Keep open. Current main and v2026.6.11 still lack a supported external-channel non-message event contract; existing system-event/inbound-runner primitives and the related open PR only partially cover the requested SDK direction.

## What This Changes

External channel plugin authors are asking for a public SDK/runtime hook or dispatch path for inbound non-message events such as reactions, edits, read receipts, and presence.

## Best Possible Solution

Bless one public path: document system events for reaction/edit/read-receipt style notifications if sufficient, otherwise add a narrow versioned channel event SDK contract with focused docs and contract tests.
