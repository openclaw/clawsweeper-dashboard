## Summary

Keep open. Current main and v2026.6.11 still lack a public external-channel non-message event contract; the existing inbound runner and system-event primitives are only partial answers, and the related open hook work does not settle the broader API direction.

## What This Changes

Request to expose or document a public SDK path for external channel plugins to emit or handle inbound non-message events such as reactions, edits, deletes, typing, presence, and read receipts.

## Best Possible Solution

Bless one public path: document system events for agent-visible non-message notifications if sufficient, otherwise add a narrow versioned channel event SDK contract with focused docs and contract tests.
