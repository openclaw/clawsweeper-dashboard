## Summary

Keep open. Current main and v2026.6.11 still lack a dedicated external-channel non-message event hook or dispatch contract; existing system-event, channel-ingress, and inbound-runner primitives only partially cover the request, and https://github.com/openclaw/openclaw/pull/79855 is overlapping but not a complete canonical fix.

## What This Changes

Requests a public Plugin SDK path for external channel plugins to dispatch or handle inbound non-message events such as reactions, edits, typing, presence, and read receipts.

## Best Possible Solution

Bless one public path: document system-event based non-message notifications if that is sufficient, otherwise add a narrow versioned channel event SDK contract with docs, baseline updates, and contract tests.
