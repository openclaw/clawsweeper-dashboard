## Summary

Keep open. Current main and the latest release still expose message-oriented inbound helpers but no dedicated public non-message event hook for external channel plugins, and the related open hook PR only partially overlaps this API direction.

## What This Changes

This issue requests a supported Plugin SDK path for external channel plugins to emit or handle inbound non-message events such as reactions, edits, read receipts, typing, and presence.

## Best Possible Solution

Bless one public path: document existing system-event or inbound-runner semantics if sufficient, otherwise add a narrow versioned channel event SDK contract with docs, contract tests, and coordination with the open inbound_activity and Discord lifecycle work.
