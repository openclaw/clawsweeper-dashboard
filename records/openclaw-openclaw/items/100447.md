## Summary

Keep open. Current main already has partial primitives for raw channel inbound events and session system events, but this request asks maintainers to bless or add a public external-channel non-message event contract, and the related open hook PR only partially overlaps that direction.

## What This Changes

Request to expose or document a supported plugin-SDK path for external channel plugins to surface reactions, edits, read receipts, and other non-message inbound activity to agents.

## Best Possible Solution

Bless one public path: document system events for reaction/edit/read-receipt style notifications if sufficient, otherwise add a narrow versioned channel event SDK contract with focused docs and contract tests.
