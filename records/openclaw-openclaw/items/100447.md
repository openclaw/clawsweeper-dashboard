## Summary

Keep open. Current main exposes partial primitives for raw channel inbound events and session system events, but it still lacks a documented public external-channel contract for non-message events such as reactions; the related hook PR is open and only partially overlaps this broader SDK direction.

## What This Changes

Request to expose or document a supported inbound non-message event path for external channel plugins, especially reactions, edits, read receipts, typing, and presence.

## Best Possible Solution

Bless one public path: document the system-event/inbound-runner recipe for external channel non-message events if sufficient, otherwise add a narrow versioned SDK event contract with docs and contract tests.
