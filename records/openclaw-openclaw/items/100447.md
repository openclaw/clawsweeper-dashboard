## Summary

Keep open. Current main and v2026.6.11 expose partial inbound-runner and system-event primitives, but they do not provide or document a supported external-channel non-message event contract for reactions, edits, receipts, or similar activity.

## What This Changes

The issue requests a public Plugin SDK path for external channel plugins to emit or handle inbound non-message events such as reactions.

## Best Possible Solution

Bless one public path: document the system-event plus heartbeat/channel-runtime recipe if it is sufficient, otherwise add a narrow versioned channel event SDK contract with docs, export checks, and contract tests.
