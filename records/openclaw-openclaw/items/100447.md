## Summary

Keep open. Current main and v2026.6.11 expose message-turn and system-event primitives, but they still do not bless a public external-channel non-message event contract; the related hook issue and inbound_activity PR only partially overlap and need maintainer API direction.

## What This Changes

The issue requests a public plugin SDK contract for external channel plugins to emit or handle inbound non-message events such as reactions, edits, deletes, typing, presence, or read receipts.

## Best Possible Solution

Bless one public path: document system events plus heartbeat for external channel events if sufficient, or add a narrow versioned SDK event contract with docs, baseline/export checks, and focused channel/plugin tests.
