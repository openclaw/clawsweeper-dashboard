## Summary

It introduces a new authenticated Workboard binding surface and a session-ownership invariant that can reject existing cross-session card operations; the branch needs maintainer confirmation that this is the intended durable API and inspectable after-fix proof before merge.

## What This Changes

This PR adds bind, rebind, and detach operations for Workboard card session links, applies a one-primary-card-per-session rule, and makes Control UI card edits update the session link atomically with the rest of the card.

## System Context

Workboard is a bundled plugin that stores operational cards and exposes them through Gateway, agent tools, and the Control UI. Card edits and claims flow into the Workboard store, which persists session associations and then governs which agent session can act on a card.
