## Summary

This PR has credible after-fix proof and no discrete correctness defect visible in the supplied patch context, but it creates a durable Workboard contract: every non-blocked, non-done card can reserve a primary session before it is claimed. That changes how existing Workboard automation, Gateway callers, and agent-tool callers may coexist, so it should remain open for an explicit owner decision and a refresh against current `main` before merge.

Likely related people: `fr-meyer` is the active contributor for the proposed Workboard binding contract (low-confidence routing; current proposal history only).

## What This Changes

The PR adds explicit session bind, rebind, and detach operations for Workboard cards, rejects duplicate primary-session reservations across create/update/claim paths, and makes Control UI card edits update the session link atomically.

## System Context

Workboard stores cards and their lifecycle state in the Workboard plugin, while the Gateway, agent tools, and Control UI create and mutate those cards. This change carries a caller session into card mutations, reserves one active primary card for that session, and exposes the result through the existing operator surfaces.
