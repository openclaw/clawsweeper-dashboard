## Summary

Keep open: current main and the latest release still lack the requested official `models reconcile` and bulk `sessions model-reset` surfaces. Current code and docs partially cover current-session clearing, reset preservation, status warnings, and doctor repair for specific stale route cases, but the remaining bulk reconcile/reset behavior needs a compatibility-sensitive product decision.

## What This Changes

The issue proposes official model/session reconcile and reset tooling so model defaults, allowlists, provider state, generated catalogs, and persisted session overrides can be inspected or converged from one supported surface.

## Best Possible Solution

Adopt a maintainer-approved, report-first recovery design with dry-run JSON output, source-aware status, and opt-in scoped reset for session, agent, provider, generated catalog, and auth pins.
