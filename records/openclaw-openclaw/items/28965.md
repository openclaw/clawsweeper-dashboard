Use this as a maintainer-sequenced umbrella: land the shared resolver direction in https://github.com/openclaw/openclaw/issues/87957, keep specific fixes tracked in https://github.com/openclaw/openclaw/issues/51251 and https://github.com/openclaw/openclaw/issues/76128, then decide whether a source-aware `models reconcile` or scoped session reset command is still needed.
