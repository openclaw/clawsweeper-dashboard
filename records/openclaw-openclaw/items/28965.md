## Summary

Keep open: current main and v2026.6.11 still lack the requested official model reconcile and bulk session model-reset command surfaces. Current code has partial status, doctor, and per-session clearing behavior, but the remaining reset/reconcile semantics are compatibility-sensitive and need maintainer product direction.

## What This Changes

The issue proposes an official model-configuration reconciliation command, a bulk session model override reset command, and clearer model-source observability.

## Best Possible Solution

Adopt a maintainer-approved report-first recovery design with dry-run output, source-aware status, and opt-in scoped reset for session, agent, provider, and auth pins.
