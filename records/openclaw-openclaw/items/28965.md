## What This Changes

The issue proposes a single-source model configuration reconcile command, a session model override reset command, and clearer model-source observability.

## Best Possible Solution

Stage this around the shared session model/auth resolver, then add a non-destructive reconcile report and explicit scoped reset path after maintainers choose preservation, warning, and migration semantics.

## Reproduction Assessment

Not applicable as a single bug reproduction; this is a feature/product proposal. Source inspection gives high-confidence proof that the requested `models reconcile` and bulk `sessions model-reset` command surfaces are absent on current main and v2026.6.11.

## Solution Assessment

No, not as one broad automatic reset/reconcile change. The safer path is a source-aware resolver plus staged CLI, doctor, docs, and status behavior after maintainers decide which selections should be preserved, warned about, or reset.
