Keep open: current main and v2026.6.11 still lack the proposed official model reconcile and bulk session model-reset surfaces, while existing reset, doctor, and status behavior only cover narrower pieces. The issue proposes a single-source model reconciliation command, a session override reset command, and clearer model-source observability.
