## Summary

Keep open: current main and v2026.6.11 still lack official `openclaw models reconcile` and bulk `openclaw sessions model-reset` surfaces, while the existing reset, status, and doctor paths only cover parts of the reported model/session-state confusion. The remaining behavior is compatibility-sensitive product work because it would report or mutate persisted model, provider, session, agent-default, generated catalog, and auth-profile state.

## What This Changes

The issue proposes adding a single-source model-configuration reconcile command, a bulk session model override reset command, and clearer model-source observability.

## Best Possible Solution

Adopt a maintainer-approved report-first reconcile design with dry-run output, source-aware status, and opt-in scoped reset flags for session, agent, provider, generated-catalog, and auth pins.
