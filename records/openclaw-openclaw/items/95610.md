## What This Changes

Fix OpenAI prompt-cache misses caused when per-turn reply-delivery state changes the system prompt and `message` tool schema inside the reusable request prefix.

## System Context

Source-reply delivery mode determines how an agent must send a visible reply, then agent prompting and tool assembly turn that decision into model-visible system instructions and tools. OpenAI automatic caching reuses only a byte-identical request prefix, so turn-specific prompt or tool changes can force cold requests even while the session remains active.
