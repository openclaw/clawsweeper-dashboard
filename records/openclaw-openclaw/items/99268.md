## Summary

Keep open: current main and the latest release still byte-match private Codex guidance prose for abort markers, while Codex exposes structured interrupted turn status; the protected maintainer label and open candidate PRs also rule out conservative cleanup closure.

## What This Changes

The issue asks OpenClaw to stop classifying Codex app-server turn aborts by exact private guidance prose and instead use structured turn status or stable abort markers.

## Best Possible Solution

Keep this issue open until a maintainer lands a Codex harness fix that derives abort/failure classification from turn/completed Turn.status and Turn.error, with any replay-marker fallback keyed to marker shape rather than private prose.

## Reproduction Assessment

Yes, at source level: current main strictly compares the marker body to copied Codex guidance prose, and the inspected Codex rust-v0.142.4 source shows that prose is crate-private while turn/completed carries structured status. I did not run a live Codex interruption.

## Solution Assessment

Yes: deriving abort/failure classification from structured turn/completed status and error is the most stable fix, with marker-shape fallback only for replayed history paths that need it. The current open marker-only PRs are useful partial candidates but should not close the full issue before merge and maintainer acceptance.
