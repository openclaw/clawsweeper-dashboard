## Summary

Keep this PR open: the compaction export correction is narrowly plausible, but the subagent change removes an existing privilege-containment filter for every statically configured target without an explicit per-delegation authority contract. That security-boundary change needs maintainer direction and a safer opt-in before merge.

## What This Changes

The branch changes the compaction reconciler from a default to a named lazy export and stops inheriting the parent tool allowlist when a spawned target resolves from `agents.list`.

## Best Possible Solution

Keep parent-to-child authority containment by default, then add a deliberately reviewed, explicit operator opt-in for named-agent delegation if the product intends routers to invoke a configured child’s broader tool surface; verify both the production bundle and the real delegation flow afterward.
