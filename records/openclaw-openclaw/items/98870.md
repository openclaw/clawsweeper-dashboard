## Summary

Keep open: current main and the latest release still fetch only the first Teams Graph replies page, so long channel threads can omit newer replies from agent context, and no open PR currently owns the fix.

## What This Changes

Fix Microsoft Teams channel thread context so reply pagination is followed and the newest relevant replies are included instead of only the first page.

## Best Possible Solution

Implement a bounded Teams Graph replies pagination fix in `fetchThreadReplies`, keep the newest requested reply window in chronological order for formatting, and add focused regression coverage while leaving the closed stale PR superseded by this issue.

Yes: the narrowest maintainable fix belongs in the Teams `fetchThreadReplies` helper, reusing the existing Graph pagination pattern and preserving the monitor handler's best-effort degradation. A new config or product policy choice is not needed.
