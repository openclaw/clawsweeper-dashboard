## What This Changes

The issue asks OpenClaw to paginate Microsoft Teams channel-message replies so long thread context includes the newest relevant replies instead of only the first 50.

## Best Possible Solution

Implement the fix in `fetchThreadReplies` by reusing the existing bounded Graph pagination helper, selecting the newest requested reply window, preserving best-effort failure behavior, and adding focused regression coverage.
