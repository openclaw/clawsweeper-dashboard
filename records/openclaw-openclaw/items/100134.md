- **[P1] Preserve tail truncation semantics:** `src/node-host/invoke.ts:235`
  - body: `truncateUtf16Safe(raw, maxChars)` keeps the first `maxChars` UTF-16 code units, but this exec-event path intentionally prefixes `... (truncated)` and keeps the last `maxChars` code units. Merging this would hide the most recent command output; use a UTF-16-safe tail slice such as `sliceUtf16Safe(raw, raw.length - maxChars)`.
  - confidence: 0.98
- **[P1] Honor runtime postbuild syncedAt stamps:** `scripts/watch-node.mjs:164-165`
  - body: This branch also includes the watcher guard from the separate crash-loop PR. That guard requires `.runtime-postbuildstamp` to contain `builtAt`, but current main writes `syncedAt`, so valid builds can remain not-ready and `gateway:watch` restarts can stall; keep this out of the node-host PR or fix it in the dedicated watcher branch.
  - confidence: 0.94
