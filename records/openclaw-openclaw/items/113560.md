## Summary

This is a focused fix for a reported Microsoft Teams regression and remains necessary: the current outbound SharePoint upload path replaces same-named files, while this PR opts into Graph rename-on-conflict behavior. The patch is mechanically sound against the documented Graph contract, but it changes the established re-upload semantic from replacing an item to retaining a renamed copy; maintainers should explicitly accept that boundary and require a redacted tenant-backed after-fix proof before merge.

## What This Changes

This PR makes Microsoft Teams’ SharePoint uploads request a unique name on collisions so repeated generated filenames create separate drive items instead of overwriting earlier files.

## System Context

The Microsoft Teams plugin uploads outbound files into a SharePoint folder through Microsoft Graph, then turns the returned drive item into a Teams file card. A filename collision currently affects both SharePoint retention and which asset Teams renders from the card.
