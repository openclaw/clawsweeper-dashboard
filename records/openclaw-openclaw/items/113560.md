## Summary

Keep this PR open as the candidate fix for the linked Microsoft Teams regression. The patch uses Microsoft Graph’s supported rename-on-conflict behavior at the SharePoint upload boundary and includes focused regression coverage, with no discrete correctness defect found; however, the contributor explicitly provides only contract and unit-test evidence, not after-fix behavior from a real Teams/SharePoint setup, so it needs redacted live proof before merge.

## What This Changes

The PR makes Microsoft Teams’ SharePoint upload request rename-on-conflict behavior so repeated generated filenames create distinct drive items instead of replacing earlier files.

## System Context

The Microsoft Teams plugin uploads generated attachments to a SharePoint folder through Microsoft Graph, then uses the returned drive-item information to build Teams file-card content. A collision decision at this upload boundary determines whether earlier generated files are preserved and whether the card can point to a fresh SharePoint item.
