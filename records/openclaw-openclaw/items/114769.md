## Summary

Keep this PR open for maintainer review. The asynchronous transport addresses a credible gateway hot-path stall, but the branch also adds a public plugin-SDK callable for process shutdown and deliberately changes file-log durability under overload and bounded shutdown; those contracts need an owner decision and real after-fix behavior proof before merge.

## What This Changes

Replaces synchronous JSONL file-log appends with a bounded ordered asynchronous queue, adds shutdown draining, and updates logging tests to wait for queued writes.

## System Context

Gateway request tracing and other runtime paths emit structured logs through the shared logger. This change moves file-backed JSONL writes off those request paths, then coordinates flushing during gateway shutdown so queued records reach the configured log file.
