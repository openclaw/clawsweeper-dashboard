## Summary

Keep this PR open for maintainer review. The async design directly changes file-log durability under load: once the bounded queue fills, it drops the oldest records, whereas the prior synchronous path applied request-path backpressure; that operational tradeoff needs an explicit owner decision and real gateway evidence before merge.

## What This Changes

This PR replaces synchronous JSONL file-log appends with a bounded asynchronous queue, ordered background flushing, rotation in the flusher, and shutdown draining.

## System Context

OpenClaw’s process logger receives records from gateway and CLI activity, formats and redacts them, then sends them to console and optional JSONL file transports. This change sits between log production and filesystem persistence, affecting request latency, log ordering, rotation, and shutdown behavior.
