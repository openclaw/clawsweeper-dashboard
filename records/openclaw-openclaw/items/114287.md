## What This Changes

The draft PR adds a publication-preflight script, a `pre-push` hook, tests, and contributor documentation intended to scan outgoing changes and require an approved local manifest before publishing a branch.

## System Context

This change sits in OpenClaw’s contributor tooling rather than its runtime: Git invokes a pre-push hook before a developer sends a branch to a remote. The hook would hand the branch, diff, identity, and manifest to the proposed preflight script, which either permits the push or blocks it.
