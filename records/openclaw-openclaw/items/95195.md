## What This Changes

Adds a default 16 MiB per-stream stdout/stderr capture cap to `NodeExecutionEnv.exec`, exposes `maxOutputBytes` on `ExecutionEnvExecOptions`, and adds regression tests.

## Best Possible Solution

Land the bounded capture once maintainers accept the 16 MiB per-stream default, or revise the default/opt-up behavior if full large-output capture remains a supported harness contract.
