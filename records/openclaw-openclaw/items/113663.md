## What This Changes

This PR adds the required Grok client-version request header to both xAI OAuth provider catalog paths and tests the live-discovery, fallback, and API-key catalog results.

## System Context

The bundled xAI extension creates provider catalog entries that route authenticated model discovery and agent inference to either xAI's API-key endpoint or Grok's subscription OAuth proxy. Those catalog settings become runtime request configuration and are merged into outbound model requests.

## Architecture Diagram

flowchart LR

  B --> C[OAuth proxy endpoint]
  B --> D[Operator base URL override]
  C --> E[Runtime request headers]

  E --> F[Grok inference request]
  F --> G[Agent response or HTTP 426]

## Best Possible Solution

Attach `x-grok-client-version` only when the resolved effective OAuth endpoint is the canonical `cli-chat-proxy.grok.com` proxy, preserve header-free behavior for custom base URLs, and add regression coverage for that override.
