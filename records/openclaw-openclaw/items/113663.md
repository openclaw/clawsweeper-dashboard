The proposed fix is narrowly scoped to the xAI OAuth proxy route, matches the reported HTTP 426 behavior, and adds coverage for both the discovered and fallback catalogs; no concrete patch defect is apparent from the supplied diff and request-path evidence.

## What This Changes

This PR adds the required `x-grok-client-version` request header to the xAI OAuth provider’s discovered and fallback catalog configurations, plus tests that preserve the API-key route without that header.

## System Context

The xAI extension turns OAuth credentials and model discovery into a provider configuration. OpenClaw carries that configuration’s headers through the model registry when it sends Responses API inference requests to the selected xAI endpoint.
