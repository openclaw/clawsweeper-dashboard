## Summary

This PR remains necessary because the linked xAI OAuth inference bug is still open. The submitted change is narrowly scoped to the two OAuth provider configurations, preserves the API-key route, and is backed by redacted live HTTP evidence showing the required header changes the proxy result from HTTP 426 to streaming success; no concrete patch defect is evident from the supplied diff and review context. The branch is behind current `main`, so normal merge-queue revalidation should apply to the exact merged head.

## What This Changes

The PR adds xAI’s required Grok client-version header to live-discovery and fallback OAuth provider configurations, with tests confirming both OAuth paths include it and the API-key provider does not.

## System Context

The bundled xAI plugin creates provider configurations for API-key and OAuth sign-ins. Those configurations are projected into agent runtime models, whose headers and credentials are merged into outbound inference requests to either xAI’s standard API or the Grok OAuth proxy.
