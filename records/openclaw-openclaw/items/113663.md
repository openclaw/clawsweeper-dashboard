## Summary

This PR addresses a real P1 xAI OAuth inference failure and includes credible redacted live HTTP proof, but the current patch still injects the Grok version header as provider-level configuration. Because that header follows an operator’s overridden xAI base URL, it can alter custom-proxy requests instead of remaining limited to the native Grok OAuth proxy. Keep the PR open for that focused compatibility repair.

## What This Changes

The PR adds the `x-grok-client-version` compatibility header to xAI OAuth provider catalog results and tests the live-discovery, fallback, and API-key provider paths.

## System Context

The bundled xAI plugin converts OAuth discovery into a provider configuration used by the agent model runtime. That configuration supplies the proxy endpoint and request headers used when a Grok subscription sends inference requests.

## Best Possible Solution

Resolve the effective request endpoint and add the Grok version header only for the canonical `https://cli-chat-proxy.grok.com/v1` OAuth proxy; retain custom base-URL behavior without OpenClaw injecting this vendor-specific header.
