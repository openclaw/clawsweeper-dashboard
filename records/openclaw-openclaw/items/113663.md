## Summary

## What This Changes

The PR adds the xAI-required `x-grok-client-version` header to live-discovery and fallback Grok OAuth provider configurations, with tests that preserve the header-free API-key route.

## System Context

The bundled xAI extension turns OAuth or API-key credentials into model-provider configurations. OpenClaw projects those configurations into runtime models and uses them to construct outbound inference requests to either the Grok OAuth proxy or xAI’s API-key endpoint.

## Best Possible Solution

Retain one OAuth-proxy-specific compatibility header on both OAuth catalog paths, while explicitly deciding whether the existing custom-base-URL override contract should carry that non-secret header or require host-aware routing.
