## Summary

Keep this PR open as the active candidate fix for the linked xAI OAuth inference regression. The proposed provider-level header is narrowly scoped to the Grok OAuth proxy, covers both discovery and fallback catalog paths, preserves the API-key route, and the supplied live HTTP evidence plus focused test results support the patch; no discrete patch defect is established.

## What This Changes

The PR adds the required `x-grok-client-version` header to xAI OAuth provider configurations and tests both the live-discovery and fallback paths while confirming the API-key route remains header-free.

## System Context

The xAI plugin turns OAuth credentials and model discovery into a provider configuration for the agent runtime. That configuration supplies request headers when OpenClaw sends inference requests to either the Grok subscription proxy or the API-key endpoint.
