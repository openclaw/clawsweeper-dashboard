## Summary

Keep open: current main and the latest release still use prefix-based frontmatter fence checks, and three open PRs already reference this issue as candidate fixes; close this issue only after one canonical fix merges.

## What This Changes

The issue asks OpenClaw to treat only whole `---` lines as Markdown frontmatter fences so dash-prefixed body text is not parsed or stripped as metadata.

## Best Possible Solution

Land one canonical fix that centralizes exact delimiter-line recognition for parser and strip helpers, adds regression cases for `---not`, `----`, and valid fences, then close the issue after merge.
