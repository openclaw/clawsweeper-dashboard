## What This Changes

The PR resolves session creator IDs against gateway self and presence users so owner chips in the sidebar, creator menus, and chat header can show real avatars while unmatched actors continue to show initials.

## System Context

The web UI receives the authenticated self user and presence records from the gateway, then renders session rows and chat headers from session creator attribution. This change joins creator IDs to those runtime identities before passing the result into the shared owner-chip presentation component.

  OwnerChip --> Sidebar[Sidebar rows and creator menus]
  OwnerChip --> Header[Chat session header]
  OwnerChip --> Fallback[Initials for unmatched actors]
