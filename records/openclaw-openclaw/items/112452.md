## What This Changes

This PR starts the Gmail watcher’s `gog gmail watch serve` process in its own Unix process group and uses OpenClaw’s shared tree terminator during shutdown so its descendants are stopped too.

## System Context

The Gmail hook starts a long-running external `gog` watcher after configuration and Gmail watch setup. On replacement or gateway shutdown, the watcher lifecycle must stop that external process and any helper processes it created before the gateway continues.
