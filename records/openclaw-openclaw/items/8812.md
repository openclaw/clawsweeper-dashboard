## Summary

Keep open: current main and the latest release still render URL-bearing tool output as plain escaped text in Control UI tool cards and native WebChat, and both linked implementation attempts are closed unmerged prior art rather than shipped fixes.

## What This Changes

Request to render URLs inside Control UI and WebChat tool output cards as clickable links while preserving JSON/plain-text formatting.

## Best Possible Solution

Implement an escape-first URL-aware renderer across Control UI tool-output paths, then either add equivalent native WebChat URL rendering or explicitly split that scope.

## Reproduction Assessment

Yes, at source level: current main renders URL-bearing Control UI tool output through Lit text bindings and native WebChat through plain SwiftUI Text. I did not run browser or app proof because this read-only review can prove the missing link renderer from source.

## Solution Assessment

Unclear as a product decision: the Control UI implementation shape is clear, but maintainers should decide whether native WebChat remains in scope before another fix PR is queued. The safest implementation should preserve raw formatting, escape text before link creation, and only produce safe http/https anchors.
