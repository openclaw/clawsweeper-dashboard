## Summary

Keep open: current main and the latest release still render URL-bearing tool output as plain text in the Control UI tool-card paths and native WebChat, and the linked fix PRs are closed unmerged prior art rather than shipped fixes.

## What This Changes

Request linkification of http(s) URLs inside Control UI and WebChat tool output cards so users can open tool-result URLs without copy/paste.

## Best Possible Solution

Implement an escape-first URL-aware renderer across Control UI tool-output paths, then either add equivalent native WebChat link rendering or explicitly split WebChat into a follow-up.

## Reproduction Assessment

Yes, at source level: current main renders URL-bearing Control UI tool output through Lit text bindings and native WebChat through plain SwiftUI Text/String formatting. I did not run browser or app proof because the missing link renderer is clear from current source.

## Solution Assessment

Unclear as a product decision: the Control UI fix boundary is concrete, but maintainers should decide whether native WebChat remains in this issue before another fix is queued. The maintainable implementation should preserve raw formatting, escape text first, and only produce safe http/https anchors.
