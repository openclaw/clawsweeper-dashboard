## Summary

This feature remains necessary: current main and v2026.6.11 still render URL-bearing tool results as plain text, no open replacement owns the work, and both linked implementation attempts closed unmerged. The technical direction is bounded, but maintainers should confirm whether native WebChat parity is required in the same deliverable.

## What This Changes

Render HTTP and HTTPS URLs in Control UI and native WebChat tool-result cards as safe clickable links while preserving output formatting.

## Best Possible Solution

Add a reusable safe URL-segmentation renderer at the current Control UI tool-output boundary, preserve whitespace and copyable raw text across all accepted card variants, and add equivalent framework-native attributed links in WebChat if native parity is included.
