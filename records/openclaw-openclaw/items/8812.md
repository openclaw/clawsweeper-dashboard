## Label Justifications

- `P3`: Clickable tool-result URLs are a useful ergonomics improvement, but the current behavior does not block tool execution or chat use.
- `impact:ux-friction`: Users must copy and paste URLs from tool output instead of opening them directly while reviewing results.

## Summary

Keep open: current Control UI still renders tool input/output through Lit text bindings, so HTTP(S) URLs remain non-clickable in expanded blocks, raw details, collapsed previews, and short inline cards; native WebChat likewise presents formatted tool output with SwiftUI `Text`. The two linked implementation attempts, https://github.com/openclaw/openclaw/pull/8880 and https://github.com/openclaw/openclaw/pull/83479, were closed unmerged and are useful prior art rather than a replacement. Likely related people: steipete (high-confidence recent Control UI history) and Takhoffman (medium-confidence recent tool-card contributor).

## What This Changes

Add safe clickable HTTP(S) links for URLs displayed inside Control UI tool-output cards and decide whether native WebChat needs matching behavior.

## System Context

Tool calls and results enter the chat transcript as text, then Control UI and native WebChat turn that text into tool cards alongside normal assistant messages. Normal chat content has richer rendering paths, while tool-card output uses dedicated plain-text renderers that feed expanded, collapsed, raw-detail, and sidebar views.

## Architecture Diagram

flowchart LR
  A[Tool result text] --> B[Chat transcript]
  B --> C[Control UI tool-card renderer]
  B --> D[Native WebChat tool-result card]
  C --> E[Expanded, preview, raw, sidebar views]
  D --> F[SwiftUI tool output]
  E --> G[User opens result URL]
  F --> G

## Best Possible Solution

Choose whether built-in native WebChat must match Control UI, then add one safe URL-token renderer per client that preserves exact text, admits only validated HTTP(S) destinations, uses new-tab/noopener behavior in the browser, and covers every tool-output presentation route.
