## Summary

Keep open: current main and the latest release still render URL-bearing tool output as plain text in the Control UI tool-card paths and native WebChat, and the two linked implementation attempts are closed unmerged prior art.

## What This Changes

The issue requests clickable URL rendering inside Control UI and native WebChat tool-output cards.

## Best Possible Solution

Define the scope, then implement safe URL-aware rendering across every selected tool-output surface with http/https-only links, escaping, trailing-punctuation handling, raw-text preservation, and focused UI/native tests.
