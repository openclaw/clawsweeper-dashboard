## Summary

This feature is still necessary: exact current main and the latest release continue to render URL-bearing tool results as plain text, and both linked implementation attempts closed unmerged. The safe Control UI fix is bounded, but maintainers should decide whether native WebChat parity is required in the same deliverable.

## What This Changes

Render HTTP(S) URLs in Control UI and native WebChat tool-result cards as safe clickable links while preserving structured output.

## Best Possible Solution

Land a shared safe URL-tokenization renderer for the canonical Control UI tool-output paths, preserving copyable text, whitespace, punctuation, and HTTP(S)-only links; track native SwiftUI parity separately unless its owner explicitly sponsors a cross-platform deliverable.
