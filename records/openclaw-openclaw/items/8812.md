Keep open: current main still renders URL-bearing tool output as plain text in the Control UI and native WebChat paths, and the linked implementation attempts are closed unmerged prior art rather than shipped behavior.

## What This Changes

Request to render URLs inside Control UI and WebChat tool output cards as safe clickable links instead of plain text.

## Best Possible Solution

Define the selected scope, then add safe URL-aware rendering across those tool-output surfaces with escaping, http/https-only links, trailing-punctuation handling, raw-text preservation, and focused UI/native tests.
