## Summary

This feature remains necessary: current main and v2026.6.11 still render URL-bearing tool results as plain text, and both linked implementation attempts closed unmerged. The Control UI fix is well bounded, but maintainers should decide whether native WebChat parity is required in the same deliverable.

## What This Changes

Add safe clickable HTTP(S) links to URL-bearing tool-result text in Control UI and, if included, native WebChat.

## Best Possible Solution

Use one safe URL-token renderer across every Control UI tool-text path, preserving JSON layout and copied text, with focused tests and Playwright proof; track equivalent native SwiftUI rendering separately unless maintainers explicitly require parity here.
