## Summary

Keep open: current main and v2026.6.11 still render URL-bearing tool results as plain text, while both linked implementation attempts closed unmerged. The feature is aligned with UI ergonomics, but maintainers should decide whether native WebChat parity belongs in the same change.

## What This Changes

Add safe clickable HTTP(S) links to URL-bearing tool output in Control UI and, if in scope, native WebChat.

## Best Possible Solution

Implement a safe HTTP(S)-only URL-aware text renderer that preserves formatting and copied text across all selected Control UI tool-output paths, with focused punctuation, escaping, and interaction tests; track equivalent SwiftUI AttributedString handling separately unless maintainers explicitly require cross-stack parity.

Yes, at source level. Current Control UI tool output is rendered through escaped text bindings, and native tool results are displayed with plain SwiftUI Text, so neither path creates clickable URL anchors.

## Solution Assessment
