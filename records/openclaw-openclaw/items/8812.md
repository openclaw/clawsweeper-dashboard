## Summary

Keep open: current main still renders ordinary Control UI tool-output text through Lit text bindings rather than URL anchors, while both linked Control UI implementation attempts closed unmerged. The feature fits the project’s stated frontend-ergonomics direction, but maintainers need to choose whether native WebChat parity is part of this deliverable. Likely related people: Chris Zhang (original renderer history) and steipete (recent area review).

## What This Changes

Add safe clickable http/https links for URLs displayed in Control UI tool-output cards and decide whether native WebChat receives equivalent rendering.

## Best Possible Solution

Implement a shared URL-aware presentation helper for every Control UI tool-output surface that emits only validated http/https anchors without changing copied text or whitespace, then either add equivalent native SwiftUI rendering or track that parity explicitly as a follow-up.
