## Summary

Keep open: current main and the latest release still render URL-bearing tool output as plain text in Control UI and native WebChat, while both linked implementation attempts are closed unmerged prior art.

## What This Changes

The issue requests automatic hyperlink rendering for URL strings shown inside Control UI and WebChat tool output cards.

## Best Possible Solution

Use a shared safe URL-aware renderer across Control UI tool-output paths, then either add native WebChat link rendering or explicitly split that scope.

## Reproduction Assessment

Yes. Source inspection shows URL-bearing tool output reaches Lit text bindings in Control UI and SwiftUI Text via plain strings in native WebChat, so it renders as text instead of clickable anchors/links on current main.

## Solution Assessment

Unclear as a product-scope decision. The Control UI fix shape is clear: escape arbitrary text before creating http/https anchors and cover every tool-card display path; native WebChat should either get equivalent link rendering or be split explicitly.
