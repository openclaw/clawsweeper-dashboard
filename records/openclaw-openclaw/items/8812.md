## Summary

Current main and v2026.6.11 still render URL-bearing tool results as plain text in Control UI and native WebChat. No newer canonical item exists, and both linked implementation attempts closed unmerged, so the requested usability improvement remains necessary.

## What This Changes

Add safe clickable URL rendering to tool output in the Control UI and potentially native WebChat.

## Best Possible Solution

Implement an escape-preserving, HTTP/HTTPS-only URL token renderer across all selected Control UI tool-output paths, then track native SwiftUI parity separately unless maintainers explicitly require one cross-platform deliverable.

## Reproduction Assessment

Yes, from current source: Control UI tool outputs are Lit text bindings inside code blocks, and native WebChat uses plain SwiftUI Text, so URL strings are not clickable.

## Solution Assessment

No, the proposed broad regex-to-HTML replacement is not the best solution; safe tokenization with platform-native rendering, complete path coverage, and focused browser/native proof is narrower and safer.
