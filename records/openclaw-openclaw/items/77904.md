## Summary

This PR is still necessary because current main does not have a one-shot exit path for the route-first model inspection commands. The latest head appears to fix the prior stream-callback blocker, and I did not find a new blocking correctness issue in the reviewed CLI lifecycle path.

## What This Changes

The PR adds a default-runtime one-shot exit helper, wires `models list` and `models status` successful output paths to request it, flushes it from `runCli` teardown, and adds focused regression coverage.

## Best Possible Solution

Land the focused teardown-level exit helper after normal exact-head CI finishes, keeping the behavior scoped to default-runtime `models list/status` success output and preserving custom-runtime and Vitest-worker exclusions.
