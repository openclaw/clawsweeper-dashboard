## Summary

Keep open: current main still reads and snapshots HEARTBEAT.md before run-kind filtering, docs still allow normal-run injection when heartbeat guidance is enabled, and changing that default needs maintainer product direction.

## What This Changes

Requests loading or injecting HEARTBEAT.md only for heartbeat runs instead of every normal message to reduce per-turn bootstrap tokens.

## Best Possible Solution

Define a run-kind-aware bootstrap loader/cache contract that skips HEARTBEAT.md for ordinary non-heartbeat runs before reads, snapshots, hooks, and prompt injection, while preserving real heartbeat behavior and updating docs/tests after maintainers choose the normal-run visibility contract.
