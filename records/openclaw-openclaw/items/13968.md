## Summary

Keep open: current main still includes HEARTBEAT.md in ordinary default-agent context when heartbeat guidance is enabled; recent cache-boundary work improves prompt caching but does not deliver the requested token reduction. The remaining choice changes the documented default context contract and needs maintainer product direction.

## What This Changes

Requests loading HEARTBEAT.md only for heartbeat runs instead of injecting it into ordinary default-agent messages.

## Best Possible Solution

If maintainers approve the contract change, make bootstrap selection run-kind aware before filesystem reads and snapshot caching: omit HEARTBEAT.md from ordinary default-agent runs, preserve it for real heartbeat runs and lightweight heartbeat mode, and align focused tests plus heartbeat/context documentation without adding a new config option.
