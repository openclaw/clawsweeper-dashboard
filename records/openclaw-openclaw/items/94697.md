## Summary

Keep open: the runtime fix is still needed for the linked process-group regression, but the new ps-failure tests have one deterministic-test blocker because they can fall through to the host's live `/proc` state.

## What This Changes

The branch changes Unix process-tree termination to verify group leadership before default group kills, threads `detached: true` through detached cleanup callers, and adds process cleanup regression tests.

## Best Possible Solution

Land this PR or an equivalent process-cleanup fix after the `/proc`-dependent test flake is removed and maintainers accept the leader-check cleanup contract.

## Reproduction Assessment

Yes at source level: current main still uses `opts?.detached !== false` for omitted Unix cleanup, and the linked issue plus PR proof show the attached-child versus detached-child process-group behavior. I did not rerun the full macOS launchd gateway scenario in this read-only review.

## Solution Assessment

Mostly yes: enforcing the group-leader invariant in the shared helper while explicitly preserving known detached cleanup paths is the right narrow runtime shape. The test suite needs deterministic `/proc` isolation before this is the best mergeable version.
