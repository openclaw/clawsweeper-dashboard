## Summary

Keep open: current main and v2026.6.11 still keep `sessions_send` and `sessions_spawn` gateway-local, and the open closing PR plus broader federation tracker need product/security review before this can close.

## What This Changes

Request native cross-gateway `sessions_send` and `sessions_spawn` routing so agents on separate gateway instances can communicate without SSH or ad hoc bridge workarounds.

## Best Possible Solution

Define the maintainer-approved cross-gateway contract first, then either rework and land https://github.com/openclaw/openclaw/pull/43656 against that contract or route the capability to plugin/MCP bridge seams with any missing core APIs tracked separately.
