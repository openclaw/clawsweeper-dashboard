## What This Changes

The issue requests native cross-gateway `sessions_send`/agent messaging so agents on different gateway instances can address each other without SSH or an external relay.

## Best Possible Solution

Choose and document a secure gateway-to-gateway session messaging contract, or explicitly route the work to a plugin/API bridge, with peer identity, scopes, session history semantics, and live multi-gateway proof before closing this issue.
