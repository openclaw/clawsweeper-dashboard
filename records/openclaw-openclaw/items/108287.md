## What This Changes

The PR adds an environment-variable override that permits older-version shared-system SQLite builds after an operator verifies a WAL-reset fix backport, while retaining the version block for embedded SQLite.

## Best Possible Solution

Keep the strict default; if maintainers accept an escape hatch, retain the shared-library restriction but add a supported backport-verification and revalidation procedure plus redacted live proof from the affected distribution image before merge.
