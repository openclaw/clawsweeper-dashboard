## What This Changes

The PR adds `OPENCLAW_ASSUME_SYSTEM_SQLITE_WAL_RESET_SAFE=1` to bypass the WAL-reset version guard only for Node builds using shared system SQLite, with tests ensuring embedded builds remain blocked.

## Best Possible Solution

Retain the strict default and support a shared-library-only escape hatch only if its operator verification procedure is documented, demonstrated on the affected distribution, and explicitly accepted as the permanent trust contract.
