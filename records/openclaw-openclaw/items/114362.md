## What This Changes

This PR sorts channel-status probe tasks by channel ID so keyed status maps are deterministic, while adding gateway tests for concurrent probes, stable map ordering, and per-channel timeout isolation.

## System Context

The Gateway `channels.status` endpoint combines registered channel metadata with optional account-probe results into a status response. The registry order remains the UI-facing channel order, while the keyed status maps are constructed from probe work and can affect downstream consumers that serialize or cache the payload.
