## What This Changes

The branch lets gateway-isolated model attempts use eligible provider-plugin synthetic credentials, such as Google ADC, without re-enabling stored auth-profile fallback.

## System Context

Gateway-routed model calls prepare an isolated credential attempt so an unrelated stored profile cannot replace the selected environment or configuration source. The core auth resolver can also invoke an eligible provider plugin’s synthetic-auth hook, allowing providers such as Anthropic Vertex to obtain Google ADC credentials before the model runtime makes its request.
