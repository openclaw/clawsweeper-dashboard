Current main still couples plugin synthetic-auth to `allowAuthProfileFallback`, while this branch separates those gates and keeps eligibility private to core; however, GitHub reports the branch as dirty, so it needs a rebase and a fresh review of the resulting merge head before landing.

## What This Changes

The PR decouples provider-plugin synthetic authentication from stored auth-profile fallback for gateway-isolated model attempts, adds prepared lookup scoping, and adds regression/harness coverage.
