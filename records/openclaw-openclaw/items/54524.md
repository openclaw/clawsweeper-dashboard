Create a narrow docs-only PR for https://github.com/openclaw/openclaw/issues/54524. Add warning guidance to docs/reference/memory-config.md and docs/automation/hooks.md explaining that the bundled session-memory hook writes session-derived Markdown under <workspace>/memory/, while memorySearch.sources including "sessions" indexes raw session transcripts, so enabling both can duplicate the same conversation in memory_search results and embedding cost.
