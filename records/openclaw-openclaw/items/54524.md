## Repair Work Prompt

Fix the documentation gap for https://github.com/openclaw/openclaw/issues/54524. Add a concise warning to the memory search config docs and session-memory hook docs explaining that the bundled `session-memory` hook writes session-derived Markdown under `<workspace>/memory/`, while `memorySearch.experimental.sessionMemory: true` with `sources: ["memory", "sessions"]` indexes raw session transcripts too, so enabling both can duplicate the same conversation in memory search results and embeddings. Recommend `sources: ["memory"]` when the hook is the session recall path, or disabling the hook when raw transcript search via `sessions` is desired. Keep this as documentation only: do not add new runtime dedupe, config options, defaults, migrations, or changelog edits unless a maintainer explicitly changes the scope. Consider whether the bundled hook `HOOK.md` should mirror the public guidance if it is shown by hook-info commands.
