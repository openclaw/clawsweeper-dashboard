## What This Changes

The issue requests documentation or design guidance to avoid duplicate memory indexing when the bundled session-memory hook and raw session transcript search are enabled together.

## Best Possible Solution

Add the narrow public docs warning now, and leave runtime session-provenance dedupe as a separate design discussion if maintainers want more than documentation.
