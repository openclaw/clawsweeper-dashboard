The issue requests documentation or design guidance to prevent duplicate memory indexing when the bundled session-memory hook and raw session transcript indexing are enabled together.

## Best Possible Solution

Add a concise docs-only warning in the memory configuration reference and hooks docs that the session-memory hook and raw session transcript indexing overlap, recommending one recall path at a time while leaving runtime dedupe and configurable hook output for separate product work.
