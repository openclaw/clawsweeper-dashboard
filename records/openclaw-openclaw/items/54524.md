Fix the documentation gap reported in https://github.com/openclaw/openclaw/issues/54524. Add a concise warning to `docs/reference/memory-config.md` near the session memory search section and to `docs/automation/hooks.md` near the bundled `session-memory` hook docs explaining that the hook writes session-derived Markdown under `<workspace>/memory/`, while `memorySearch.experimental.sessionMemory: true` plus `sources: ["memory", "sessions"]` can index the same conversation through both memory files and raw session transcripts. Recommend choosing one session recall path: keep `sources: ["memory"]` when relying on the hook, or disable the hook when raw transcript search via `sources: ["sessions"]` is desired.
