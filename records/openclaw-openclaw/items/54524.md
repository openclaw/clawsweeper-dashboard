## What This Changes

The issue asks for documentation or design guidance to prevent duplicate memory indexing when raw session indexing and the bundled session-memory hook are enabled together.

## Best Possible Solution

Add narrow warnings in the memory config and bundled hook docs that these two recall paths overlap, while leaving runtime deduplication and configurable hook output behavior to separate memory product work.
