## What This Changes

The issue requests documentation or design guidance to prevent duplicate memory indexing when the bundled session-memory hook writes summaries into workspace memory while memorySearch also indexes raw session transcripts.

## Best Possible Solution

Add a narrow public warning in the memory search/config docs and session-memory hook docs that users should choose one session recall path, while leaving runtime dedupe and configurable hook output paths to separate memory product work.
