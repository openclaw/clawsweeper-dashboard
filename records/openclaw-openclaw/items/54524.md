## Repair Work Prompt

Add a docs-only warning for this issue in `docs/reference/memory-config.md` and `docs/automation/hooks.md`: explain that the bundled `session-memory` hook writes session-derived Markdown into `<workspace>/memory/`, while `memorySearch.experimental.sessionMemory: true` with `sources: ["memory", "sessions"]` can also index raw session transcripts for the same conversation. Recommend `sources: ["memory"]` when the hook is the session recall path, or disabling the hook when raw transcript search is desired. Use the closed unmerged docs PR as wording reference, but do not add runtime dedupe, new config options, hook output paths, storage changes, or changelog edits.
