## What This Changes

Document or otherwise prevent duplicate indexing when the session-memory hook writes summaries into workspace memory while memory search also indexes raw session transcripts.

## Best Possible Solution

Add the overlap warning to both the memory config reference and bundled hook docs, then leave runtime dedupe or configurable hook output paths to separate memory product work.

## Reproduction Assessment

Yes, at source level. ## Solution Assessment
