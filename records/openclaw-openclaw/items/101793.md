Keep open. ## What This Changes

Report that Signal can silently omit assistant text that precedes a tool call in a `toolUse` turn while the transcript records that text as assistant output.

## Best Possible Solution

Make delivery reality explicit across the source-reply pipeline: either safely deliver intended pre-tool user text before tool execution or mark suppressed pre-tool text in agent-facing context so later turns cannot treat it as seen by the user.
