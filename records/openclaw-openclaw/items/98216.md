## Summary

## What This Changes

This PR allows Docker sandbox environment entries to use SecretRefs, resolves active entries through OpenClaw’s secret runtime before container creation, and adds the new credential paths to secret-management commands and reference documentation.

## System Context

Agent configuration is validated and converted into a runtime secret snapshot before a sandbox is launched. The sandbox configuration then passes resolved Docker environment strings to container creation, while the secret target registry lets CLI secret workflows discover and audit the same configured values.

  SecretCLI[Secrets plan configure audit] --> Registry
