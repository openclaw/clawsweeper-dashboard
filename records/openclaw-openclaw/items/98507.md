## Best Possible Solution

Land the provider-local bounded-read and bounded-gunzip fix only after mapping Node 24 overflow errors, removing the PR-only proof script, and rerunning the focused Google ADC tests on the repaired head.

Not yet. The fix direction is the right owner-boundary approach because it uses the shared bounded reader inside the Google plugin, but this branch should not merge until the Node 24 overflow code and committed proof script are repaired.
