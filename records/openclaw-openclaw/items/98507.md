## Summary

Keep this PR open: current `main` and the latest release still buffer the Google Vertex ADC OAuth token response with `arrayBuffer()`, while this branch now addresses the prior review blockers by removing the proof script and handling Node 24 gzip overflow codes.

## What This Changes

The branch replaces the unbounded Google Vertex ADC OAuth token response read with a bounded 16 MiB reader, adds bounded gzip decompression, exports the parser for tests, and adds focused parser regression coverage.

## Best Possible Solution

Use this PR as the canonical fix if maintainers want one patch covering both wire-size and gzip decoded-size caps; otherwise land the narrower sibling and track decoded gzip hardening separately.
