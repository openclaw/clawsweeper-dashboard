Full review comments:

- **[P1] Escape percent text before quoting cmd.exe args:** `src/process/windows-command.ts:40-43`
  - body: When an arg needs quotes, this branch returns it with `%` untouched, but `cmd.exe /c` substitutes `%VAR%` values before the `.cmd` shim receives argv.
