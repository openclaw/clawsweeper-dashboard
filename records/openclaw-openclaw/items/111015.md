## Label Justifications

## Summary

Keep this maintainer-labeled PR open. Current `main` has the reported teardown hole, but the proposed non-local watchdog bypasses the existing opt-in `forceProcessExitOnReturn` boundary and can terminate programmatic Gateway-backed callers after they have returned control.

## What This Changes

The branch extracts TUI shutdown and signal helpers, retains an unref’d hard-exit watchdog for non-local shutdown, and adds unit coverage for hung gateway teardown and signals.

## Best Possible Solution

Keep the hard-exit deadline for the command-owned TUI path, but preserve normal returns for embedded and programmatic callers unless they explicitly opt into `forceProcessExitOnReturn`; add a regression test for that Gateway-backed programmatic path.

## Solution Assessment

No. The watchdog is the right mechanism for the reported hang, but tying persistent process exit to non-local mode broadens the existing caller contract; retain the explicit `forceProcessExitOnReturn` boundary instead.
