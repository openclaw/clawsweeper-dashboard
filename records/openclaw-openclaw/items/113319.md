## What This Changes

Make iOS native Talk/Wake system speech use the configured Speech Language locale, such as `tr-TR`, instead of defaulting to the device voice for non-English replies.

## System Context

iOS Talk/Wake receives reply text plus language information from local settings, gateway configuration, and optional response directives. The native playback path resolves a system voice and sends the utterance to Apple speech synthesis, which determines the language users hear.
