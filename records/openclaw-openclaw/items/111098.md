## What This Changes

The PR removes the model-pricing cache’s local host classifier, imports the shared gateway host classifier, and adds regression tests for DNS names that resemble private IPv4 prefixes.

## System Context

The gateway model-pricing cache may refresh pricing data from a configured base URL. Before the refresh, it classifies the URL host to decide whether local or private targets must be excluded, then either performs the fetch or retains cached pricing data.

## Architecture Diagram

flowchart LR
  A[Configured pricing base URL] --> B[Parse URL host]
  B --> C[Pricing endpoint safety policy]
  C -->|private or local target| D[Skip refresh]
  C -->|allowed target| E[Fetch pricing data]
  E --> F[Update pricing cache]

## Best Possible Solution

Keep a pricing-endpoint-specific, fail-closed safety policy at the cache boundary, with an explicit resolver-aware design if arbitrary DNS endpoints must be supported; test the actual refresh decision for local and public DNS cases rather than only the shared predicate.
