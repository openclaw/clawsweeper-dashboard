## Summary

Keep open: current main and v2026.6.11 still derive the macOS app Launch at login toggle from live LaunchAgent state and do not provide durable app intent or post-update reconciliation for the app-owned `ai.openclaw.mac` plist.

## What This Changes

The issue asks for the macOS app Launch at login setting to remain enabled and keep auto-starting across app restarts and Sparkle updates without UI state drifting from launchd.

## Best Possible Solution

Define the macOS app's launch-at-login source of truth, then add guarded startup/update reconciliation for `ai.openclaw.mac` with signed packaged update proof.
