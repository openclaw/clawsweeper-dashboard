Keep open: current main and the latest release still make the macOS Launch at login toggle reflect live app LaunchAgent state, with no persisted app-owned intent or Sparkle/update reconciliation for the reported post-update drift.

## What This Changes

The issue reports that the macOS app Launch at login setting appears to turn itself off after updates and stops reliably launching OpenClaw at login.

## Best Possible Solution

Define the macOS app's Launch at login source of truth, then add a guarded startup/update reconciliation path that preserves explicit in-app enablement without overriding deliberate OS-level disables.
