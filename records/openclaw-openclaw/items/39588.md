## Summary

Keep open: current main and the latest release still use live app LaunchAgent state as the macOS Launch at login toggle source of truth, with no persisted app intent or Sparkle/update reconciliation for the reported post-update drift.

## What This Changes

The issue reports that the macOS app Launch at login setting can stop staying enabled after app updates, so OpenClaw may not auto-launch on the next macOS login.

## Best Possible Solution

Define the macOS app's Launch at login source of truth, then add a bounded startup or update reconciliation path that preserves explicit in-app enablement without overriding deliberate OS-level disables.
