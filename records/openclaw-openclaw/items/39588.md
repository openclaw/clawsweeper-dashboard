## Summary

Keep open: current main and the latest release still treat live `ai.openclaw.mac` LaunchAgent state as the Launch at login source of truth, and the Sparkle updater path does not reconcile an app-owned login intent after app replacement.

## What This Changes

The issue asks for macOS app Launch at login to stay enabled across restarts and app updates instead of the toggle or auto-launch behavior drifting off.

## Best Possible Solution

Define the macOS app Launch at login source of truth, then add guarded app-owned intent persistence and startup/Sparkle-update reconciliation that restores only OpenClaw-owned LaunchAgent drift.
