## Summary

Keep open: current main and v2026.6.11 still derive the macOS Launch at login toggle from live launchd state, while the merged related fixes cover startup-time plist deletion and KeepAlive relaunch behavior rather than Sparkle/update-time intent drift.

## What This Changes

The issue reports that the macOS app's Launch at login setting can appear to turn off after app updates, causing OpenClaw not to autostart on the next login.

## Best Possible Solution

Define the macOS app's launch-at-login source of truth, then add a bounded startup/update reconciliation path that preserves explicit in-app enablement without overriding deliberate OS-level disables, backed by live packaged-update proof.
