## Summary

Keep open: current main and the latest release still derive the macOS Launch at login toggle from live launchd state, while the related merged fixes cover startup deletion and KeepAlive relaunch behavior rather than update-time intent drift.

## What This Changes

The issue reports that the macOS app's Launch at login setting can appear to turn off and stop autostarting after app updates.

## Best Possible Solution

Define the macOS app's launch-at-login source of truth, then add guarded startup/update reconciliation that preserves explicit in-app enablement without overriding deliberate OS-level disables.
