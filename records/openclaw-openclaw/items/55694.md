## Summary

## What This Changes

The issue reports an agent/tool-call failure loop where repeated failed tool calls produce repeated visible channel messages and can spam users.

## Best Possible Solution

Keep this open until core has a maintainer-approved default policy that classifies deterministic tool failures, blocks runaway repeated failures, and emits at most one structured channel-visible failure message.
