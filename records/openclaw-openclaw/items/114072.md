## What This Changes

The branch changes Workboard decomposition so newly created child cards use non-blocking orchestration provenance instead of reciprocal hard dependency links, and adds diagnostics, repair APIs, and a Doctor migration for narrowly proven legacy SQLite links.

## System Context

Workboard is OpenClaw’s bundled card-management plugin: operators and agents create aggregate and child cards, which are persisted in SQLite and surfaced through gateway methods, agent tools, and the web UI. Card links influence whether a child is runnable, while Doctor migrations repair old persisted Workboard state before normal runtime use.
