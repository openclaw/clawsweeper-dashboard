## What This Changes

This PR makes newly decomposed Workboard child cards use non-blocking orchestration provenance by default, adds hard-dependency unlink and legacy-repair operations, and reports dependency graph problems.

## System Context

Workboard stores cards and their relationship metadata, then uses those relationships to decide whether work can be claimed or completed. Decomposition creates child cards; the resulting relationship data feeds card status checks, agent tools, gateway methods, and operator diagnostics.
