The implementation is a focused repair for the linked Gateway wizard lifecycle bug, with no discrete correctness defect found in the reviewed patch; however, the additive `installDaemon` Gateway RPC field becomes a generated cross-client contract and needs explicit owner acceptance before merge.

## What This Changes

The PR runs Gateway-hosted setup and channel wizards with a non-exiting runtime, preserves exclusive ownership through cancellation settlement, skips unused headless catalog loading, and adds an optional `installDaemon` RPC parameter.

## System Context

Gateway RPC lets remote clients run OpenClaw setup and channel wizards inside an already-running shared Gateway. The Gateway translates RPC parameters into wizard options, streams session progress, and must keep the host process alive for subsequent client requests.
