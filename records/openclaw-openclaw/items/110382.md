## What This Changes

The PR runs Gateway-hosted setup and channel wizards with a non-exiting runtime, adds optional `installDaemon` forwarding, and keeps cancelled wizard sessions exclusive until their runner settles.

## System Context

Gateway RPC lets remote clients run setup or channel wizards inside a long-lived Gateway process. The RPC handler starts a wizard session, supplies runtime behavior to the CLI-oriented wizard runner, and returns session progress and terminal results to the remote client.
