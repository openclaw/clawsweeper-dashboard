## Summary

Keep open: current main and the latest release still have the reported cleanup-to-cancel-to-process-tree-kill path, and the overlapping open issues do not supersede this sharper claude-cli lifecycle/no-opt-out decision.

## What This Changes

The issue reports that claude-cli turn-end cleanup kills Claude Code background or child tool processes with no opt-out or parent-visible failure signal.

## Best Possible Solution

Define an owner-approved claude-cli lifecycle contract that either boundedly drains or detaches in-flight CLI-owned background work with typed failure/telemetry, or explicitly denies unsupported post-turn work while preserving safe process-tree cleanup.

- **Declare unsupported post-turn work:** Document or enforce that Claude CLI Workflow/background grandchildren cannot survive OpenClaw turn cleanup and route users to ACP, exec/process, or detached task surfaces.
