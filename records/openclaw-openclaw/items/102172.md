## Summary

Keep open: current main still has the reported claude-cli cleanup-to-managed-run-cancel-to-process-tree SIGTERM/SIGKILL path, and the related open issues overlap but do not supersede this sharper lifecycle/no-opt-out decision.

## What This Changes

The issue requests a claude-cli lifecycle change so OpenClaw does not silently kill CLI-owned Workflow/background grandchildren at turn end without bounded opt-out, telemetry, or parent-visible failure signal.

## Best Possible Solution

Define an owner-approved claude-cli lifecycle contract that either boundedly drains or detaches in-flight CLI-owned background work with typed failure/telemetry, or explicitly denies unsupported post-turn work while preserving safe process-tree cleanup.

- **Declare unsupported post-turn work:** Document or enforce that Claude CLI Workflow/background grandchildren cannot survive OpenClaw turn cleanup and route users to ACP, exec/process, or task surfaces.
