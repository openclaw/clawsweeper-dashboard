## Summary

Keep open: current main and v2026.6.11 still have the reported claude-cli cleanup path that closes the live session after a turn and cancels the detached process tree, and the related open issues do not supersede this sharper no-opt-out lifecycle decision.

## What This Changes

The issue requests a bounded opt-out or telemetry path so claude-cli Workflow and other CLI-owned background grandchildren are not silently killed at turn-end cleanup.

## Best Possible Solution

Define an owner-approved claude-cli lifecycle contract that boundedly drains or explicitly fails in-flight CLI-owned background work while preserving safe process-tree cleanup and surfacing forced cleanup to the parent context.

- **Declare post-turn CLI work unsupported:** Document or enforce that Claude CLI Workflow/background grandchildren cannot survive OpenClaw turn cleanup and route users to exec/process, cron, or other durable task surfaces.
