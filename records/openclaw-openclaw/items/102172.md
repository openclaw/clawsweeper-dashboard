## Summary

Keep open: current main and the latest release still perform the reported claude-cli live-session cleanup chain, and neither the same-root sibling issue nor the broader lifecycle umbrella has landed a fix or supersedes this narrower process-tree cleanup decision.

## What This Changes

Request to prevent or visibly report claude-cli turn-end cleanup killing in-flight Workflow/Bash grandchildren after a channel turn completes.

## Best Possible Solution

Define a maintainer-approved claude-cli lifecycle contract that keeps process-tree cleanup safe, but prevents a turn from being treated as cleanly finished while owned tool grandchildren are still running or at least surfaces a typed failure/telemetry signal.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should claude-cli live-session cleanup remain unconditional at turn end, or should OpenClaw add a bounded drain/telemetry contract for in-flight CLI-owned background grandchildren?

Rationale: The source confirms the reported behavior, but changing it affects process-tree cleanup, orphan prevention, user-visible terminal state, and likely config/default surfaces.

Likely owner: obviyus

Owner confidence: high

Options:

- **Adopt bounded drain plus telemetry (recommended):** Add a narrow, owner-approved contract for detecting in-flight CLI-owned background children, deferring cleanup only within a bounded ceiling, and reporting any forced cleanup to the parent/session.
- **Telemetry first:** Keep unconditional cleanup for now, but snapshot/log or surface killed grandchildren so the silent failure class becomes observable before changing lifecycle behavior.
- **Keep cleanup as the contract:** Document that Claude CLI Workflow/Bash grandchildren are not supported across turn boundaries and route users to OpenClaw exec/process or detached task surfaces instead.

## Solution Assessment

Unclear until maintainers choose the lifecycle contract: a raw config opt-out is plausible but risky, while a bounded drain plus typed failure/telemetry signal better preserves cleanup safety.
