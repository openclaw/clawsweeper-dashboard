## What This Changes

Repair embedded-agent tool-call normalization so an XML-polluted provider tool name resolves only when its prefix exactly matches a tool allowed for the active request.

## System Context

The embedded-agent runner prepares the effective tool catalog for a run and passes it into the agent session, where provider stream output is normalized before tool dispatch. A malformed provider tool name currently reaches dispatch without matching the prepared allowed-tool set, causing an intended tool call to be treated as unknown.
