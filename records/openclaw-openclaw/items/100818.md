## What This Changes

The issue asks OpenClaw to stop Feishu from sending the no-visible-content fallback when a long markdown-heavy assistant reply was actually produced for the user.

## Best Possible Solution

Preserve the no-visible fallback for true empty turns, but add a focused Feishu/shared-dispatch fix that proves long markdown finals are either delivered and counted as visible or fail with an accurate recoverable error state instead of the generic fallback.
