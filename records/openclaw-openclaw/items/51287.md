## Summary

Keep open: current main and v2026.6.11 still use a fixed 30-minute exec approval timeout with no supported config or environment override, and the related implementation attempts are closed unmerged or adjacent rather than canonical fixes.

## What This Changes

Request to expose a configurable exec approval timeout so operators can tune the fixed pending host-exec approval window.

## Best Possible Solution

If maintainers approve the product direction, add one bounded canonical timeout setting, preserve the current 30-minute default, and propagate the resolved value through agent, gateway, node, CLI transport, docs, and focused tests.
