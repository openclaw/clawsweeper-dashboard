## Summary

Keep open: current main and v2026.6.11 still use a fixed 30-minute exec approval timeout with no public config key, and the remaining request is a security-sensitive product/API decision rather than an implemented fix.

## What This Changes

The issue requests an operator-configurable exec approval timeout, likely through `openclaw.json`, instead of relying on hardcoded approval timeout constants.

## Best Possible Solution

Define one bounded approval-timeout contract with a safe default, documented maximum, precedence rules, and consistent propagation across schema, docs, agent registration, gateway/node waits, CLI paths, and tests.
