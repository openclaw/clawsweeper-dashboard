## Summary

Keep open: current main and v2026.6.11 still expose only a fixed 30-minute exec approval timeout, so the remaining request is a security-sensitive config/product decision rather than an implemented fix.

## What This Changes

Request to add a public OpenClaw config or equivalent setting for exec approval timeout instead of relying on hardcoded defaults.

## Best Possible Solution

Define one bounded approval-timeout contract with a safe default, maximum, documented precedence, and consistent propagation across schema, docs, agent registration, gateway wait, node/CLI paths, and transport timeouts.
