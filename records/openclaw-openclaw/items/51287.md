## Summary

Keep open: current main and v2026.6.11 still use a fixed 30-minute exec approval timeout with no supported user config key, and exposing one is a security-sensitive product/config decision rather than a narrow bug fix.

## What This Changes

Request to let operators configure the exec approval wait window instead of relying on OpenClaw's fixed default timeout.

## Best Possible Solution

Decide the security policy first, then either add one bounded documented config key with schema/help/docs/tests and upgrade proof, or explicitly keep the fixed 30-minute default and document why.
