## Summary

Keep this PR open for normal merge review: it restores the existing `media.localRoots` containment contract for relative filesystem paths, has focused regression coverage, and includes a real filesystem before/after run. The only remaining review step is to refresh the branch against current `main` and confirm the intentional compatibility effect for callers that previously supplied relative paths outside their configured roots.

## What This Changes

The PR resolves relative local media sources before managed outgoing-image handling so `media.localRoots` is enforced for relative, absolute, and `file://` filesystem paths while URL-like sources still pass through.

## System Context

Managed outgoing image attachments accept media references from gateway reply handling, classify local filesystem sources, and save approved media for downstream delivery. `media.localRoots` is the operator-configured boundary that decides which local paths this flow may read.
