## What This Changes

The branch delivers newly critical background-session health digests to authorized Control UI subscribers, displays a one-click attention notice for those sessions, and guides webchat agents to use the read-only session companion for status questions.

## System Context

The gateway turns agent-run activity into session-health digests and sends them to authorized Control UI connections, where the session rail shows per-session state. This PR adds a transient alert path for critical state in a background session and adds Control UI-specific agent prompt guidance.
