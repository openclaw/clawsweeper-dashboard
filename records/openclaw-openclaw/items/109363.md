## Summary

Keep this PR open: the workspace-skill improvement is focused, but the same dangerous SKILL.md content remains invisible when the skill is supplied by an installed plugin, so the security blind spot is only partially closed. ([raw.githubusercontent.com](https://raw.githubusercontent.com/openclaw/openclaw/main/src/security/audit-extra.async.ts))

## What This Changes

The branch scans each non-plugin installed skill’s SKILL.md with the skill-text and source scanners and adds regression coverage for dangerous and clean workspace skill instructions.

## Best Possible Solution

Separate SKILL.md scanning from directory code scanning, apply it once to every discovered non-bundled skill—including plugin-provided entries—then cover both workspace and plugin origins without adding `.md` to the global extension set.
