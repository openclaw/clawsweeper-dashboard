## Summary

This security fix is still necessary and appears correct: current main omits SKILL.md from deep skill audits, while the PR adds the scan at the skill-owner boundary without broadening global Markdown scanning. The existing plugin-skill concern does not reproduce from current loader design because declared plugin skills are published under the generated plugin-skills path and retain that path for discovery, so they reach this collector rather than the installed-extension skip.

## What This Changes

The PR scans each installed skill’s SKILL.md through the existing skill-text and source scanners during deep security audits and adds regression coverage for dangerous and clean Markdown content.

## Best Possible Solution

Land the focused per-skill SKILL.md scan with its regression test while retaining the existing global Markdown exclusion, after exact-head checks confirm the current-main merge result.
