## Summary

Keep this PR open: the bounded-read direction is sound, but the new hard cap can silently remove previously valid bundle commands and the PR provides no after-fix real-behavior proof.

## What This Changes

The PR replaces the synchronous unbounded read of Claude-format plugin bundle command Markdown with `readRegularFileSync` and a 1 MiB size cap.

## Best Possible Solution

Retain the bounded-read hardening only with an explicit, observable oversized-command outcome, focused boundary coverage, and maintainer confirmation that 1 MiB is the intended compatibility contract for installed command templates.
