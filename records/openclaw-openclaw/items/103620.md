## Summary

Keep this PR open for revision. The signed-callback quota isolation is well targeted, but the latest commit introduces a blocking regression by raising the documented signature-validation-disabled path from 30 to 300 accepted callbacks per minute.

**Likely related people**
- @steipete — high confidence; introduced the bundled SMS channel and recently merged adjacent webhook hardening.

## What This Changes

The PR separates invalid-request throttling from signed Twilio callback quota, scopes limiter keys by SMS account, route, and resolved client address, and updates SMS webhook tests and security documentation.

## Best Possible Solution

Retain the separate 300-per-minute budget only for requests that fail parsing, signature, payload, or account validation, while enforcing the existing 30-per-minute accepted-callback cap in both signature modes.
