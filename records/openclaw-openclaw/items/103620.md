## Summary

Keep this PR open, but it is not merge-ready: the latest head retains the previously reported P1 same-key denial path, so invalid traffic can still block a later valid signed SMS callback before authentication. The protected `maintainer` label and unresolved security-versus-delivery policy require explicit owner handling.

## What This Changes

The PR splits SMS webhook throttling into a 300-per-minute pre-validation gate and a 30-per-minute authenticated callback gate, scopes both by account, route, and proxy-resolved client address, and adds documentation and tests.

## Best Possible Solution

Replace the attacker-consumable early quota with bounded body-size and concurrency protection plus rejected-outcome accounting that cannot spend authenticated callback capacity, then prove an invalid same-key burst followed by a valid signed callback over real HTTP while preserving replay-saturation behavior.
