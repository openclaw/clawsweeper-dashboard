## What This Changes

The PR replaces the SMS webhook’s single 30/min source-IP gate with separate 300/min failed-request and 30/min dispatchable-callback limits keyed by SMS account, route, and trusted-proxy-resolved client address, with regression tests and documentation.

## Best Possible Solution

Keep the two-stage limiter architecture, because it removes invalid-versus-valid quota contention without adding configuration, and land it only after the SMS owner explicitly accepts or retunes the failed-request threshold and tracked-key bound.
