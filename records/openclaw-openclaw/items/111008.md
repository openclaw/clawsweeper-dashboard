## Summary

Keep this PR open for maintainer product-direction review and a narrow correctness repair. It silently changes documented system-event/no-model semantics into an isolated model-backed agent turn, and its “routable target” test treats `threadId` or `accountId` metadata alone as sufficient to bypass the existing creation-time rejection.

## What This Changes

The PR converts unpinned system-event cron jobs with explicit announce-delivery fields into isolated agent-turn jobs and adds normalization plus create-pipeline regression tests.

## Best Possible Solution
