## What This Changes

Keeps Codex app-servers configured to use the operator’s user home on native Codex authentication instead of preparing and injecting an OpenClaw OpenAI profile.

## System Context

The bundled Codex plugin converts an agent’s resolved OpenAI/Codex auth route into app-server startup options. In user-home mode, that process shares the operator’s Codex CLI/Desktop home, so the connection must retain its native account rather than receive prepared credentials.
