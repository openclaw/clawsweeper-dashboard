## What This Changes

The branch makes embedded-agent steering writes fence-aware, prevents SDK retries inside the released prompt-lock window, retries eligible transport failures outside that window, and returns resend guidance instead of silently losing a reply after session takeover.

## System Context

An embedded agent releases its session write lock while a model call is in flight, then reacquires it before continuing the transcript. The auto-reply runner coordinates provider candidates, fallback, retry, and the final channel reply, so retry placement affects both session consistency and whether a user receives a response.

Keep SDK retries disabled during the released prompt-lock window, but restore configured provider retries at the failing provider-candidate boundary with lock reacquisition for every attempt; then publish redacted current-head real output covering configured multi-model fallback order.
