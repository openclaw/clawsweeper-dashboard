## What This Changes

The PR makes embedded session steering fence-aware, disables SDK retries while the prompt lock is released, restores retry attempts at the outer reply orchestration layer, and gives users resend guidance after a session takeover.

## System Context

An inbound message enters the auto-reply runner, which invokes an embedded agent while temporarily releasing the session write lock during provider I/O. The runner then reacquires and fences the transcript before it either delivers the reply, retries the whole turn, or returns an actionable failure message.
