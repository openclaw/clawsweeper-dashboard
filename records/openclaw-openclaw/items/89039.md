The branch makes embedded steering writes fence-aware, disables SDK retries while the prompt lock is released, forwards retry options through OpenAI transports, retries selected transport failures at the outer runner, and returns resend guidance for session takeovers.

## Best Possible Solution

Keep SDK retries disabled inside the released prompt-lock window, but carry the existing configured provider retry budget to the outer attempt owner so each retry reacquires the lock and the configured resilience contract remains intact.
