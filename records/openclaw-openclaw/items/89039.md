## Summary

Keep this PR open: its released-lock invariant and takeover guidance are well targeted, but the current patch still makes an existing configured provider retry budget ineffective for embedded prompt calls, which is a P1 compatibility regression.

## Best Possible Solution

Keep SDK retries disabled within the released lock window, but have the full-attempt owner honor the existing configured provider retry budget with lock reacquisition on every retry and add regression coverage for configured values.
