## What This Changes

The branch makes embedded-agent steering writes fence-aware, suppresses provider-SDK retries while the session lock is released, retries transient failures at the reply orchestrator, and returns resend guidance after a session takeover.

## System Context

The embedded agent runner releases a session write lock while it calls a model provider, then reacquires it before continuing the turn. Incoming steering writes, provider retry behavior, and the reply orchestrator must agree on transcript ownership so a failed turn reaches the channel with a meaningful outcome.
