## Summary

Keep open: the underlying message-loss fix remains necessary and the lock-ownership direction is sound, but the current head still replaces the established configured provider retry budget with a single outer retry, and its proof remains a test harness rather than an observed live Gateway flow.

## What This Changes

The PR coordinates owned steering writes, embedded OpenAI retry suppression and propagation, takeover recovery messaging, outer connection and timeout retries, phase diagnostics, and regression coverage.

## Best Possible Solution

Keep SDK retries at zero only while the prompt lock is released, translate the configured provider retry budget into bounded whole-attempt retries that reacquire the lock each time, retain explicit takeover resend guidance, and prove both configured and unconfigured paths through a redacted live Gateway/provider/channel run.
