## What This Changes

The PR makes embedded steering writes fence-aware, disables SDK retries while the embedded prompt lock is released, adds takeover resend guidance, and adds transport, retry, and takeover regression coverage.

## Best Possible Solution

Keep SDK `maxRetries` fixed at zero during every released-lock model call, but consume the configured provider retry budget at the outer full-attempt owner so each retry starts a new lock-owning attempt and preserves existing configuration semantics.
