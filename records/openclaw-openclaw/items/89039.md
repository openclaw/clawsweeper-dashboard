## What This Changes

The branch makes embedded-session steering writes fence-aware, prevents SDK retries while the prompt lock is released, retries transient failures at the reply orchestrator, and returns resend guidance after a session takeover instead of silently losing the reply.

## System Context

The auto-reply runner executes model turns through an embedded agent that temporarily releases a session transcript lock around a provider call. Session fencing, provider retry policy, and model fallback must preserve transcript ownership while still delivering a reply or a clear terminal response to the originating chat channel.
