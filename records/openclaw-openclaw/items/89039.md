## What This Changes

This PR makes embedded-session steering writes fence-aware, prevents SDK retries during a released prompt-lock window, retries eligible failures outside that window, and returns resend guidance instead of silently losing a reply.

## System Context

The auto-reply runner executes an embedded agent while a session-file fence coordinates transcript writes and prompt-lock release. Provider transport failures and queued steering messages feed into the runner’s fallback logic, which must either deliver a reply or produce an explicit user-visible terminal outcome.
