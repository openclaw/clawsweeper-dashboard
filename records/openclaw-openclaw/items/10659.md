## Summary

Keep open: current main has substantial SecretRef, redaction, audit, command-scoped secret-resolution, and plugin-hook mitigations, but it still does not provide the native masked-secret or process-isolation boundary requested here.

## What This Changes

Request a native masked-secrets system so agents can use API keys without seeing raw values, including placeholder substitution, output redaction, and command/file/env protections.

## Best Possible Solution

Keep this issue open until secops/product choose and ship, or explicitly reject, a native credential boundary that keeps raw values out of agent-readable files, env, context, transcripts, and command output while preserving controlled dispatch-time use.
