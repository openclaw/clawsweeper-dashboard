## Summary

Keep this issue open. Current main has useful SecretRef hardening, but its own secrets documentation still states that plaintext credentials remain agent-readable when stored in inspectable files; it does not provide the requested general agent-exec isolation boundary. The active maintainer-authored scoped broker in https://github.com/openclaw/openclaw/pull/98707 is a promising bounded first step for declared plugin operations, but it intentionally does not cover arbitrary agent commands or replace an owner decision for this issue.

Likely related people: `@openclaw/secops` is the security-routing owner indicated by the repository policy context (high confidence); `@steipete` is the recent adjacent contributor through the open credential-broker design (high confidence).

## What This Changes

Add a native masked-secret boundary so agents can invoke approved credentialed work without reading raw API keys, leaking them in output, or replaying them into chat context.

## System Context

OpenClaw resolves configured SecretRefs into a gateway runtime snapshot for supported provider, channel, and plugin owners, then passes credentials to their egress paths. Agent shell tools and plugin operations are separate consumers, so preventing plaintext from reaching agent-visible files, environment, arguments, output, and transcripts requires an explicit cross-boundary contract.

## Architecture Diagram

flowchart LR
  A[Secret source] --> B[Gateway SecretRef resolution]
  B --> C[Active runtime snapshot]
  C --> D[Provider and channel egress]
  C --> E[Plugin credential operation]
  F[Agent command or tool request] --> G[Scoped authorization boundary]
  G --> E
  E --> H[Redacted result and transcript]

## Best Possible Solution

Adopt an owner-approved, capability-scoped credential boundary that keeps plaintext outside agent-readable files, ambient environment, tool arguments, outputs, and persisted context; treat https://github.com/openclaw/openclaw/pull/98707 as a possible first plugin-operation slice, not as complete resolution.
