## Summary

Keep open: current main has SecretRef resolution, default log redaction, host-env filtering, and command-scoped secret injection, but it still documents that plaintext credentials remain agent-readable and does not provide the native masked-secret or isolation boundary requested by this issue.

## What This Changes

The issue requests a native masked-secrets system so agents can use configured credentials without seeing raw API keys, with output redaction and controls for shell/file/environment exposure.

## Best Possible Solution

Keep the issue open until maintainers choose and ship a native credential-use boundary, likely combining SecretRef migration, scoped broker/proxy semantics, exact redaction, and explicit docs for OS/process isolation limits.
