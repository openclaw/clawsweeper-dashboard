## Summary

Keep open: current main and the latest release include substantial SecretRef, redaction, audit, and plugin-hook mitigations, but they still do not provide the native masked-secret or process-isolation boundary requested here.

## What This Changes

The issue requests a native masked-secrets system so agents can use API keys through references without seeing raw values, with runtime substitution, output redaction, command/file access policy, and config support.

## Best Possible Solution

Keep this issue open until secops/product choose and ship, or explicitly reject, a native credential boundary that keeps raw values out of agent-readable files, env, context, transcripts, and command output while preserving controlled dispatch-time use.
