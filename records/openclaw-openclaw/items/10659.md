## Summary

Keep open: current main has SecretRefs, command-scoped resolution, host env sanitization, plugin hooks, and redaction mitigations, but it still does not provide the native masked-secret or process-isolation boundary requested here.

## What This Changes

The issue asks for a native masked-secrets system so agents can use credentials without reading raw API keys, with placeholder substitution, output redaction, command blocking, and a mask-list config surface.

## Best Possible Solution

Keep this open until secops/product choose and ship, or explicitly reject, a native credential boundary that keeps raw values out of agent-readable files, env, context, transcripts, and command output while preserving controlled dispatch-time use.
