## Summary

Keep open: current main has SecretRef, redaction, audit, and plugin-hook mitigations, but it still lacks the native masked-secret/process-isolation boundary requested for arbitrary agent-executed commands and output.

## What This Changes

Request a native masked-secrets system that lets agents use API keys without seeing raw values, with placeholder substitution, output redaction, command/file-read limits, and mask-list config.

## Best Possible Solution

Define and ship, or explicitly reject, a native credential boundary that keeps raw values out of agent-readable files/env/context/transcripts while supporting controlled dispatch-time use through core, SDK, or plugin seams.
