## Summary

Keep open: current main has SecretRefs, audit/configure/apply, redaction, and plugin-hook mitigations, but it still lacks the native masked-secret or process-isolation boundary requested here.

## What This Changes

Request native masked-secret handling so agents can use credentials without seeing raw API keys, including command substitution, output redaction, blocked secret reads, and mask-list config.

## Best Possible Solution

Have secops/product define and ship, or explicitly reject, a native credential boundary that keeps raw values out of agent-readable files, env, context, transcripts, and command output while preserving controlled dispatch-time use.
