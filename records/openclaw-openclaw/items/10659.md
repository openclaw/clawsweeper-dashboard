## Summary

Keep open: current main and the latest release have meaningful SecretRef, redaction, runtime snapshot, and plugin-hook hardening, but they still do not implement the native masked-secret or process-isolation boundary requested here.

## What This Changes

Request a native masked-secrets system so agents can use API keys without seeing raw values, including placeholder substitution, output redaction, command blocking, and mask-list config.

## Best Possible Solution

Keep this issue open until security/product maintainers either ship or explicitly supersede a native credential-isolation design for agent-executed commands and process output, while documenting current plugin and OS-isolation mitigations as interim options.
