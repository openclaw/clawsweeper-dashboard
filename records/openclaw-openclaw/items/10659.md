## Summary

Keep open: current main has strong SecretRef, audit, redaction, host-env, and plugin-hook mitigations, plus linked user-isolation and credential-vault workarounds, but it still does not provide the native agent-inaccessible masked-secret boundary requested here.

## What This Changes

Request native masked-secrets support so agents can use API keys through references without seeing raw values, including substitution, output redaction, secret-read blocking, and mask-list config.

## Best Possible Solution
