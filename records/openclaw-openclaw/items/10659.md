## Summary

Keep open for explicit security-owner product direction. The supplied current-main review and discussion show substantial SecretRef and redaction hardening, but not the requested boundary between the general agent shell and credentials used by approved tools; direct checkout verification was blocked by the command sandbox in this review.

## What This Changes

Add a masked-secret system that lets agents use approved credentials without reading raw values and redacts secret-bearing command output before it reaches chats or persisted state.

## Best Possible Solution

Define a security-reviewed credential-broker contract that injects narrowly scoped credentials only at approved tool dispatch, keeps raw values out of agent-readable files, prompts, and general shell environments, and redacts exact values before persistence or delivery, with documented limits and plugin-provider seams.
