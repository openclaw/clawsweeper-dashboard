Keep open: current main and latest release still expose standard file chooser, direct file-input, and Chrome MCP upload_file paths only. ByteUploader-style drop, paste, or native-drag support remains a security-sensitive Browser plugin capability that needs maintainer API direction and live custom-uploader proof.

## Best Possible Solution

Add an explicit Browser plugin drop-file, paste-file, or native-drag upload mode only after maintainers settle the API and security contract; keep standard file-input upload unchanged and require live custom-uploader proof.
