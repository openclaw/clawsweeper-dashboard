Likely related people: DrCrinkle is the strongest routing candidate because the earlier merged CLI-exit lifecycle fix appears to date to commit 874ff7089cc116682baed7aaca55b95ae5ff59e8 (high confidence).

## What This Changes

Ensure short-lived OpenClaw CLI commands terminate cleanly on native Windows after completing or returning an error.

## Best Possible Solution

Make short-lived CLI teardown lifecycle-owned: flush output, close any CLI-installed dispatcher or other owned handles, and exit only after routed or Commander commands finish, while preserving intentionally long-running commands; cover packaged Windows npm invocations of `status` and `--version` plus a long-running-command control case.
