## What This Changes

The issue requests that short-lived OpenClaw CLI commands on native Windows exit after printing their result instead of leaving a separate Node process alive.

## System Context

OpenClaw’s CLI entrypoint initializes command dependencies, runs a command such as `status`, and should release retained resources so the Node process can exit. If a handle survives command completion, the result is printed but the one-shot CLI process remains running.
