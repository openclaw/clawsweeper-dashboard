## What This Changes

The PR makes iMessage poll-vote notifications render each participant’s complete current selection list from plural vote entries, while retaining the singular vote field as a fallback.

## System Context

The iMessage extension receives poll-update payloads from the `imsg` monitor and turns them into text that agents can observe. This change sits in that rendering step, affecting the poll-selection message that reaches an agent after an iMessage poll event.
