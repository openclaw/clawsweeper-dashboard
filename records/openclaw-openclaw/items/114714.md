## What This Changes

The PR changes iMessage poll-vote notifications to render each participant’s complete current selection snapshot from plural vote entries, while retaining the legacy single-vote field as a fallback.

## System Context

The iMessage extension monitors decoded Messages events and turns incoming poll payloads into text that OpenClaw agents receive. This change sits between the `imsg` decoder payload and the agent-visible poll notification, ensuring multi-select votes describe current selections rather than an inferred delta.

## Best Possible Solution

Keep plural `poll.votes` as the authoritative snapshot path and preserve the singular fallback only for decoders that omit plural data, then attach redacted current-head native-Messages evidence for multi-select, deselection, and empty-selection states.
