## Summary

This PR remains open because its test-only branch preserves a current numeric-input contract, but its title and premise do not match current `main`: both `offset` and `limit` use `Type.Number()`. A maintainer should decide whether that compatibility behavior deserves a narrowly named regression test or whether fractional limits should instead be rejected in a separately approved compatibility change.

## What This Changes

The branch adds tests for the session read tool that assert fractional `limit` values pass schema validation and are normalized during execution.

## System Context

The session read tool takes model-supplied file and pagination arguments, validates them with TypeBox, then reads and slices workspace content before returning it to the agent. Its numeric `limit` is normalized at execution time to bound the number of returned lines.
