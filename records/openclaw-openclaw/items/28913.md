## Summary

Keep this open: current main and v2026.6.11 still lack a memory-lancedb captureFilter or default external-content wrapper gate, and the related open items are broader provenance/security architecture trackers rather than replacements for this narrow autoCapture boundary.

## What This Changes

Request to add source-wrapper filtering for memory-lancedb autoCapture so wrapped EXTERNAL_UNTRUSTED_CONTENT content is not stored as long-term memory.

## Best Possible Solution

Define a host-owned autoCapture trust boundary, preferably rejecting OpenClaw external-content wrappers before trigger matching by default unless maintainers explicitly approve an opt-in captureFilter surface, with focused tests and docs.
