## Summary

Keep open: current main and v2026.6.11 still lack a memory-lancedb captureFilter or default rejection of OpenClaw external-content wrappers, and no merged or open canonical PR now owns the narrow autoCapture filtering work.

## What This Changes

Add source-based filtering for memory-lancedb autoCapture so wrapped untrusted external content is not stored as long-term memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer default rejection of OpenClaw-authored external-content wrappers before trigger matching, with docs and regression tests, unless maintainers explicitly approve a captureFilter config surface.
