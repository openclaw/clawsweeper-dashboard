## Summary

Keep this open: current main and the latest release still lack a memory-lancedb source-wrapper gate or captureFilter, and the related open issues are broader provenance/security architecture trackers rather than replacements for this narrow autoCapture boundary.

## What This Changes

The issue requests a memory-lancedb autoCapture filter that skips content wrapped in external untrusted-content tags before trigger matching and storage.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with focused docs and regression tests, unless maintainers explicitly choose an opt-in captureFilter surface.
