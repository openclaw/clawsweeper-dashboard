## Summary

Keep open: current main and v2026.6.11 still lack a memory-lancedb captureFilter or default EXTERNAL_UNTRUSTED_CONTENT exclusion before autoCapture trigger matching, and the remaining choice is a maintainer security/product boundary rather than cleanup-closeable work.

## What This Changes

Request source-based memory-lancedb autoCapture filtering so OpenClaw-wrapped external content is excluded from automatic long-term memory capture.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer default rejection of OpenClaw-authored external-content wrappers before trigger matching, with docs and regression tests, unless maintainers explicitly approve a captureFilter config surface.
