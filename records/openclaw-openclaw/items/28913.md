## Summary

Keep open: current main and v2026.6.11 still lack a memory-lancedb captureFilter or default external-wrapper gate, and the related open issues track broader trust/provenance architecture rather than this narrow autoCapture boundary.

## What This Changes

The issue requests a source-aware memory-lancedb autoCapture filter, such as `captureFilter.excludeWrapped`, so wrapped external content is not automatically stored as long-term memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer default rejection of OpenClaw external-content wrappers before trigger matching, with focused regression coverage and docs, unless maintainers explicitly choose an opt-in config surface.
