## Summary

Keep this open: current main and v2026.6.11 still lack a memory-lancedb captureFilter or default EXTERNAL_UNTRUSTED_CONTENT autoCapture gate, and the related open issues are broader provenance/security trackers rather than replacements for this narrow capture-time boundary.

## What This Changes

The issue requests source-based autoCapture filtering so wrapped external/untrusted content is excluded from long-term memory storage.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with focused plugin docs and regression tests, unless maintainers explicitly choose an opt-in captureFilter surface.
