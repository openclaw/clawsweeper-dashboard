## Summary

Keep this open: current main and the latest release still lack a memory-lancedb `captureFilter` or default `EXTERNAL_UNTRUSTED_CONTENT` autoCapture gate, and the related open issues cover broader provenance/security architecture rather than replacing this narrow capture-time boundary.

## What This Changes

Request adds source-based filtering to memory-lancedb autoCapture so wrapped untrusted external content is skipped before trigger matching and storage.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with focused memory-lancedb docs and regression coverage, unless maintainers explicitly choose an opt-in `captureFilter` surface.
