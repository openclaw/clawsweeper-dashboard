## Summary

Keep open: current main and v2026.6.11 still lack captureFilter or a source-wrapper rejection in memory-lancedb autoCapture, and the remaining work is a security/product decision rather than cleanup.

## What This Changes

Request to add a memory-lancedb autoCapture filter that excludes EXTERNAL_UNTRUSTED_CONTENT-wrapped text from being persisted as long-term memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer default rejection of OpenClaw-authored external-content wrappers before trigger matching, with memory-lancedb docs and regression tests unless maintainers explicitly approve a captureFilter config surface.
