## Summary

Keep open: current main and v2026.6.11 still lack a memory-lancedb `captureFilter` or default `EXTERNAL_UNTRUSTED_CONTENT` autoCapture gate, and the related open issues track broader provenance/trust architecture rather than this narrow capture-time boundary.

## What This Changes

Add source-based filtering for memory-lancedb autoCapture so wrapped untrusted external content is not persisted as long-term memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with memory-lancedb tests and docs, unless maintainers explicitly choose an opt-in `captureFilter` surface.
