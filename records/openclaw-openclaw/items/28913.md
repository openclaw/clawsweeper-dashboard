## Summary

Keep open: current main and v2026.6.11 still lack a memory-lancedb `captureFilter` or default `EXTERNAL_UNTRUSTED_CONTENT` autoCapture gate, and the linked issues remain broader provenance/security trackers rather than replacements for this narrow capture-time boundary.

## What This Changes

The issue requests a source-aware memory autoCapture filter that skips content wrapped as `EXTERNAL_UNTRUSTED_CONTENT` before it can be stored as long-term LanceDB memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first, preferably rejecting OpenClaw external-content wrappers before trigger matching by default unless maintainers explicitly choose an opt-in config surface.
