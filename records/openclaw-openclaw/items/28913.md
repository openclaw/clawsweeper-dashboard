## Summary

Keep open: current main and v2026.6.11 still lack a memory-lancedb `captureFilter` or default `EXTERNAL_UNTRUSTED_CONTENT` autoCapture gate, and the related open issues are broader provenance/trust trackers rather than replacements for this narrow capture-time boundary.

## What This Changes

The issue requests source-based filtering so memory-lancedb autoCapture skips content wrapped in OpenClaw external-content security markers.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with memory-lancedb docs and regression coverage, unless maintainers explicitly choose an opt-in `captureFilter` surface.
