## Summary

Keep this open: current main and v2026.6.11 still lack the requested source-wrapper filter for memory-lancedb autoCapture, while the related open issues cover broader provenance/trust architecture rather than this narrow capture-time boundary.

## What This Changes

Request to add source-based filtering for memory-lancedb autoCapture so wrapped external/untrusted content is not automatically stored as long-term memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with focused memory-lancedb tests and docs, unless maintainers explicitly choose an opt-in captureFilter surface.
