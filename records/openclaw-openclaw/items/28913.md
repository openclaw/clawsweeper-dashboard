## Summary

Keep this issue open: current main and v2026.6.11 still lack a memory-lancedb `captureFilter` or default rejection of OpenClaw external-content wrappers before autoCapture trigger matching, and the remaining choice is a security/product boundary decision.

## What This Changes

The issue requests source-based filtering for memory-lancedb autoCapture so wrapped `EXTERNAL_UNTRUSTED_CONTENT` does not become persisted memory.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer default rejection of OpenClaw-authored external-content wrappers before trigger matching, with focused docs and regression tests, unless maintainers explicitly approve a `captureFilter` config surface.
