## Summary

Keep this open: current main still lacks a memory-lancedb captureFilter or default EXTERNAL_UNTRUSTED_CONTENT autoCapture gate, and the related open issues are broader provenance/security trackers rather than replacements for this narrow capture-time boundary.

## What This Changes

Request source-based autoCapture filtering so memory-lancedb can skip storing content wrapped as EXTERNAL_UNTRUSTED_CONTENT.

## Best Possible Solution

Define the host-owned autoCapture trust boundary first; prefer rejecting OpenClaw external-content wrappers before trigger matching by default, with focused plugin docs and regression tests, unless maintainers explicitly choose an opt-in captureFilter surface.
