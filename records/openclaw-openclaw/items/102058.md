## Summary

Keep open: the PR fixes the main timestamp ordering and includes copied live-output proof, but the current head can record `session.cleanup_completed` and preserve a pre-cleanup terminal status even when cleanup failed and the attempt is about to rethrow.

## What This Changes

Moves embedded-attempt `session.ended` trajectory recording from inline after `model.completed` to the cleanup `finally` path, adds `session.cleanup_completed`, carries terminal status/error, and flushes after final trajectory events.

## Best Possible Solution

Derive the cleanup failure before final trajectory emission, emit `session.cleanup_completed` only for successful cleanup, make `session.ended` reflect cleanup failures, and still flush before any rethrow.
