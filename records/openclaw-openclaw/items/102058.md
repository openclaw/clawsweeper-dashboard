## What This Changes

This PR defers embedded-runner `session.ended` trajectory recording until after cleanup, adds `session.cleanup_completed`, carries terminal status/error, and moves the trajectory flush after those final events.

## Best Possible Solution

Finalize trajectory events and flush them in a cleanup-finalization path that runs before any cleanup failure is rethrown, while preserving terminal status/error payloads and existing cleanup error semantics.
