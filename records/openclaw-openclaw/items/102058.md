## Summary

## What This Changes

The branch moves embedded-runner `session.ended` trajectory recording out of the normal return path and into the `finally` path while carrying `terminalError`.

## Best Possible Solution

Emit the resolved `session.ended` event at the real post-cleanup boundary, then flush trajectory data after that event, preserving terminal status/error and proving the result with a redacted trajectory export or runtime log.
