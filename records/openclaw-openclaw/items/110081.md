## Summary

Keep this PR open: agent-scoped startup isolation is directionally correct, but the current head still changes inactive SSH refs into config-write dependencies and does not resolve SecretRefs for standalone sandbox lifecycle commands.

## What This Changes

This PR assigns SSH sandbox SecretRefs to normalized agent owners, isolates unavailable credentials per agent, blocks ambient SSH identity fallback, and preserves credentials for runtime inspection and removal.

## Best Possible Solution

Keep agent-scoped degraded owners for Gateway startup, preserve inactive-ref semantics for config writes, and make sandbox lifecycle commands use the existing targeted secrets-resolution path before invoking SSH manager hooks without permitting ambient identity fallback.
