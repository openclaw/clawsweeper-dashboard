## Summary

Keep this PR open: the agent-scoped isolation direction is sound, but the current head intentionally activates SSH SecretRefs for disabled sandboxes, contradicting the existing inactive-secret contract and requiring compatibility/security resolution before merge.

## What This Changes

The PR assigns SSH sandbox SecretRefs to normalized agent owners, guards sandbox and lifecycle access against unresolved credentials, derives lifecycle ownership from registry sessions, and keeps SSH credentials materialized after sandbox deactivation.

## Best Possible Solution

Keep agent-scoped degraded ownership and the pre-access fallback guard, but preserve inactive disabled-agent refs by resolving credentials only for an actual registry-backed SSH lifecycle operation, with focused upgrade tests, updated secret-surface documentation, live redacted proof, and security-owner approval.
