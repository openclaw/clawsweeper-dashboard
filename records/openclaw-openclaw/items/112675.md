## What This Changes

The PR makes the Nextcloud Talk reaction action reject disabled or credential-incomplete accounts before it calls the provider sender.

## System Context

Nextcloud Talk is a bundled channel plugin that turns model-selected message actions into provider API requests. The action adapter receives channel configuration and an optional account selection, validates the account and target, then passes an allowed reaction to the channel sender.
