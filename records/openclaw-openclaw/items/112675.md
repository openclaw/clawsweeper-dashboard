## What This Changes

The PR rejects Nextcloud Talk reaction requests for disabled or incompletely configured resolved accounts before they reach the provider, and adds tests for both rejection paths.

## System Context

Nextcloud Talk is a bundled channel plugin whose message-action adapter receives agent reaction requests and sends them to the Talk provider. The adapter resolves an account, validates whether it may act, then delegates eligible reactions to the sender that performs the authenticated API request.
