## Summary

This PR addresses a concrete Nextcloud Talk dispatch gap, and its focused tests match the stated failure mode. ## What This Changes

The PR adds a Nextcloud Talk reaction-dispatch guard that rejects disabled or unconfigured resolved accounts and adds regression tests for both cases.

## System Context

OpenClaw’s portable message-action layer routes a reaction request to the Nextcloud Talk channel adapter, which resolves the selected account before delegating to the provider sender. The adapter must keep its tool-advertisement eligibility rule aligned with actual dispatch so disabled accounts cannot make outbound API calls.
