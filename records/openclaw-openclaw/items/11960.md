## Summary

Keep open. Current main still captures prior daily/idle rollover session state but does not route that rollover through the reset hook surface that bundled session-memory listens to; https://github.com/openclaw/openclaw/pull/61675 remains the active candidate and the durable hook contract still needs maintainer choice.

## What This Changes

Request to add a session reset or before-reset hook for automatic daily/idle resets so session-memory and custom hooks can persist prior context, plus allow per-hook config keys such as messages.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/61675 or a maintainer-approved replacement that persists session-memory on daily/idle rollover, keeps manual resets single-fired, documents the chosen hook contract, and covers daily plus idle regressions.
