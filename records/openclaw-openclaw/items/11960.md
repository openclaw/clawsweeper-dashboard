## Summary

Keep open. Current main and the latest release still cover daily/idle rollover only through typed session lifecycle hooks, while bundled session-memory remains command-only; the secondary hook config schema mismatch is fixed, but the primary automatic reset persistence contract still needs maintainer selection and review of https://github.com/openclaw/openclaw/pull/61675 or a replacement.

## What This Changes

Request a `session:reset` or `session:before-reset` hook so session memory can persist context during automatic daily or idle resets, plus hook-specific config support for keys such as `messages`.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/61675 or a maintainer-approved replacement that persists session-memory on daily/idle rollover, keeps manual reset behavior single-fired, documents the chosen hook contract, and adds focused daily plus idle regression coverage.
