## Summary

Keep open. Current main still captures old session state on daily/idle rollover but does not route automatic rollovers through the reset persistence hook surface; the secondary hook-config schema mismatch is fixed, and the remaining work is a maintainer choice about the durable hook contract.

## What This Changes

The issue requests a session reset hook or pre-reset event so bundled session-memory and custom hooks can persist context when daily or idle auto-resets clear session history.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/61675 or a maintainer-approved replacement that persists session-memory on daily/idle rollover, keeps manual reset behavior single-fired, documents the chosen hook contract, and adds focused daily plus idle regression coverage.
