## Summary

Keep open. Current main still has the automatic daily/idle rollover persistence gap: the previous session is captured and lifecycle hooks run, but bundled session-memory still only listens to command new/reset, while https://github.com/openclaw/openclaw/pull/61675 remains the active candidate and the durable reset-hook contract still needs maintainer choice.

## What This Changes

The issue requests a session reset or before-reset hook for automatic daily/idle resets so session-memory and custom hooks can persist context before rollover, plus a hook-config schema fix for session-memory options.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/61675 or a maintainer-approved replacement that persists session-memory on daily/idle rollover, keeps manual reset behavior single-fired, documents the chosen hook contract, and adds focused daily plus idle regression coverage.
