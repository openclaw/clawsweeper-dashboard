## Summary

Keep open. Current main still captures the old session entry and emits session lifecycle hooks on automatic daily/idle rollover, but it does not route that rollover through the reset persistence surface that bundled session-memory uses; the secondary hook-config schema mismatch is already fixed.

## What This Changes

The issue requests a session reset hook or equivalent pre-reset persistence surface so bundled session-memory and custom hooks can preserve context on automatic daily and idle session resets.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/61675 or a maintainer-approved replacement that persists session-memory on daily/idle rollover, keeps manual reset behavior single-fired, documents the chosen hook contract, and adds focused daily plus idle regression coverage.
