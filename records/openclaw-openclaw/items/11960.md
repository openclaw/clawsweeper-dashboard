## Summary

Keep open. ## What This Changes

Request adds a session reset or before-reset hook path so session-memory and custom hooks can persist context during automatic daily and idle session rollovers.

## Best Possible Solution

Keep this as the canonical tracker and land, replace, or reject a maintainer-approved implementation that gives automatic daily and idle rollovers the same effective pre-reset persistence opportunity as manual resets.

## Reproduction Assessment

Yes. Source inspection shows a daily/idle stale rollover archives the previous session and emits session_end/session_start, while the manual reset helper that triggers command hooks and before_reset is only reached for explicit /new or /reset commands.

## Solution Assessment

Unclear. A plugin-visible reset hook is the right boundary, but the durable API shape still needs maintainer choice to avoid a one-off or compatibility-sensitive hook contract.
