## Summary

Keep open. Current main still captures the previous session on daily/idle rollover and emits session_start/session_end plugin lifecycle hooks, but it does not invoke the reset hook surface that bundled session-memory handles; the hook-config schema mismatch is already fixed, and the remaining work needs maintainer selection of the reset hook contract.

## What This Changes

Request a session reset or before-reset hook for automatic daily and idle resets so session-memory and custom hooks can persist the previous session before it is cleared, plus hook-specific config schema support.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/61675 or a maintainer-approved replacement that persists session-memory on daily/idle rollover, keeps manual reset behavior single-fired, documents the chosen hook contract, and adds focused daily plus idle regression coverage.
