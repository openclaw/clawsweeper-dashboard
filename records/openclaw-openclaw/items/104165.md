## What This Changes

The issue requests that the installed `china-weather` skill’s `/weather` command resolve to a callable weather tool instead of producing an unknown-tool error.

## System Context

OpenClaw skills can expose slash commands that dispatch into the agent tool catalog. A command configured for tool dispatch supplies a tool name; the catalog then either resolves that registered tool or returns an unknown-tool error.
