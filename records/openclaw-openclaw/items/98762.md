## Summary

Keep open: current `main` and the latest release still have a plausible `requestExit()` -> embedded backend stop -> active-run abort path, and the reporter added fresh context that the local macOS TUI exits without an intentional `/exit`, Ctrl-D, terminal close, or signal. ## What This Changes

The issue asks OpenClaw to keep `openclaw chat` attached to active embedded Codex turns unless the user exits, the terminal is genuinely lost, or another documented shutdown condition occurs.

## Best Possible Solution

Keep this open for maintainer-owned local TUI lifecycle work: first capture the exact `requestExit()` trigger, then preserve or clearly classify active embedded turns according to whether the exit was intentional or genuine terminal loss.
