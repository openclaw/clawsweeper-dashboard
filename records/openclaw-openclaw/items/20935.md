## Summary

Keep open: current main and the latest release still provide memory lifecycle events and a general metadata-only Gateway audit ledger, but not the requested all-write memory mutation audit trail with cause, actor/session context, and tamper-evidence. Pinchy, world-model-mcp, and the open Memory Audit PR are useful prior art, but none is a merged OpenClaw core implementation for this exact memory-file audit gap.

## What This Changes

Request an append-only audit log for all agent memory file changes, including what changed, when it changed, why it changed, and session or user context.

## Best Possible Solution

Design a memory plugin or SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
