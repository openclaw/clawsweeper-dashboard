## Summary

Keep open: current main still has lifecycle memory events, but not the requested all-write mutation audit trail for MEMORY.md and memory/*.md with cause, actor/session context, and tamper-evidence. The Pinchy and world-model-mcp comments are useful prior art, and the open Memory Audit PR is related, but none close the OpenClaw memory-file audit gap.

## What This Changes

The issue requests an append-only audit log for agent memory file mutations, including what changed, when, why, and session/user context.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
