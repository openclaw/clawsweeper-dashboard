## Summary

Keep open: current main still has lifecycle memory events and a general metadata-only Gateway audit ledger, but not the requested append-only audit trail for every MEMORY.md and memory/*.md mutation with cause, actor/session context, and tamper-evidence. Prior art in Pinchy and world-model-mcp is useful, and the open Memory Audit PR overlaps, but no merged OpenClaw implementation closes this narrower memory-file audit gap.

## What This Changes

Request an append-only audit log for agent memory-file changes that records what changed, when, why, and relevant session/user context.

## Best Possible Solution

Define a memory plugin/SDK-owned mutation audit contract for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
