## Summary

Keep open: current main and the latest release expose memory lifecycle/event-log and metadata audit surfaces, but not an all-write MEMORY.md and memory/*.md mutation audit with cause, actor/session context, and tamper-evidence.

## What This Changes

The issue requests an append-only audit log for all agent memory file mutations, including what changed, when, why, session/user context, and tamper-evidence.

## Best Possible Solution

Define a memory plugin or SDK-owned mutation audit contract for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
