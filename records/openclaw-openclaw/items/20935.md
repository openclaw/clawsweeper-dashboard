## Summary

Keep open: current main and v2026.6.11 still provide only lifecycle memory events and general Gateway audit metadata, not the requested all-write mutation audit for `MEMORY.md` and `memory/*.md` with cause, actor/session context, and tamper-evidence.

## What This Changes

Request to add an append-only audit log for all agent memory-file changes, including what changed, when, why, session/user context, and tamper-detection support.

## Best Possible Solution

Define a memory plugin/SDK-owned mutation audit contract for `MEMORY.md` and `memory/*.md` writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
