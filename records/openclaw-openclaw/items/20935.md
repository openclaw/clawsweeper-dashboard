## Summary

Keep open: current main still has lifecycle memory event JSONL, Gateway metadata audit, and useful external prior art, but not the requested all-write memory mutation audit for `MEMORY.md` and `memory/*.md` with cause, actor/session context, and tamper-evidence.

## What This Changes

The issue requests an append-only audit log for agent memory file changes, including what changed, when, why, and session/user context.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for `MEMORY.md` and `memory/*.md` writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
