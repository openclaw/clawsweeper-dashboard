## Summary

Keep open: current main still has memory lifecycle events and a metadata-only Gateway audit ledger, but not the requested all-write memory mutation audit with cause, actor/session context, and tamper-evidence. Pinchy, world-model-mcp, and the draft Memory Audit PR are useful prior art, but they do not close the OpenClaw memory-file audit gap.

## What This Changes

Request adds an append-only audit log for agent memory file changes that records what changed, when, why, session/user context, and tamper-detection context.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
