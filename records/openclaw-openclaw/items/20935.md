## Summary

Keep open: current main still lacks a first-class all-write memory mutation audit for MEMORY.md and memory/*.md with cause, actor/session context, and tamper-evidence semantics. Existing lifecycle events, Memory Wiki, Pinchy/world-model-mcp prior art, and open memory audit PRs are useful context but do not close the OpenClaw memory-file audit gap.

## What This Changes

Request an append-only audit log for agent memory file changes, including what changed, when, why/trigger, session/user context, and tamper-detection support.

## Best Possible Solution

Define and document a memory plugin/SDK-owned mutation audit contract for MEMORY.md and memory/*.md writes, using Pinchy and world-model-mcp as prior art while deciding storage, privacy, cause propagation, and tamper-evidence semantics before implementation.
