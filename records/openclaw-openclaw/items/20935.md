## Summary

Keep open: current main still has lifecycle memory events, but not the requested all-write audit trail for MEMORY.md and memory/*.md with cause, actor/session context, and tamper-evidence. Pinchy and world-model-mcp are useful prior art, and the open Memory Audit PR is related, but none of them currently close the OpenClaw memory-file audit gap.

## What This Changes

Request an append-only audit log for agent memory-file changes that records what changed, when, why, session/user context, and supports tamper-detection.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.

## Reproduction Assessment

Yes. Source inspection reproduces the gap: current memory events cover recall, promotion, and dreaming, while memory flush and other memory-file writes do not emit mutation audit records with cause, session/user, and integrity context.

## Solution Assessment

Unclear as proposed. An append-only log is the right direction, but the best OpenClaw solution needs maintainer decisions for storage, privacy, cause propagation, and tamper-evidence before a fix PR.
