## Summary

Keep open: current main and the latest release still expose lifecycle memory events, not the requested all-write audit trail for MEMORY.md and memory/*.md with cause, actor/session context, and tamper-evidence.

## What This Changes

The issue requests an append-only audit log for every agent memory-file mutation, including what changed, when, why, and session/user context.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
