## Summary

Keep open: current main still has lifecycle memory events and a metadata-only run/tool audit ledger, but not the requested all-write memory mutation audit trail with cause, session/user context, and tamper-evidence.

## What This Changes

Add an append-only audit log for MEMORY.md and memory/*.md changes that records what changed, when, why, session/user context, and tamper-detection data.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
