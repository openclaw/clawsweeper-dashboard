## Summary

Keep open: current main still has lifecycle memory events and a general Gateway audit ledger, but not the requested all-write memory mutation audit with cause, actor/session context, and tamper-evidence. Pinchy, world-model-mcp, and related OpenClaw PRs are useful prior art, but none is a merged native fix for MEMORY.md and memory/*.md mutation auditing.

## What This Changes

Request an append-only audit log for agent memory-file changes that records what changed, when, why, session/user context, and tamper-detection support.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
