## Summary

Keep open: current main still has lifecycle memory event JSONL and a general metadata audit ledger, but not the requested all-write memory mutation audit for `MEMORY.md` and `memory/*.md` with cause, actor/session context, and tamper-evidence. Pinchy and world-model-mcp are useful prior art, but they are external implementations rather than a native OpenClaw memory contract.

## What This Changes

The issue requests an append-only audit log for all agent memory-file changes, including what changed, when, why, and session or user context.

## Best Possible Solution

Design a memory plugin or SDK-owned mutation audit layer for `MEMORY.md` and `memory/*.md` writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before accepting implementation.
