## Summary

Keep open: current main still has lifecycle memory events, but not the requested all-write audit trail for MEMORY.md and memory/*.md with cause, actor/session context, and tamper-evidence. Pinchy and world-model-mcp are useful prior art, and the open Memory Audit PR is related, but none of them currently close the OpenClaw memory-file audit gap.

## What This Changes

Issue requests an append-only audit log for agent memory-file changes, including what changed, timestamp, trigger or reason, session/user context, and tamper-detection value.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
