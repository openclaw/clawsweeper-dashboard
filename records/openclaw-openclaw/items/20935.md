## Summary

Keep open: current main still has lifecycle memory events and a metadata-only Gateway audit ledger, but not the requested all-write memory mutation audit with cause, actor/session context, and tamper-evidence. Pinchy, world-model-mcp, the draft Memory Audit PR, and broader provenance issues are useful context, but none is a merged native fix for MEMORY.md and memory/*.md mutation auditing.

## What This Changes

The issue requests an append-only audit log for every agent memory-file change, including what changed, when, why, session/user context, and tamper-detection support.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
