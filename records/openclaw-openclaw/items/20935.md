## Summary

Keep open: current main still has memory lifecycle events and the metadata-only Gateway audit ledger, but not the requested all-write memory mutation audit with trigger, actor/session context, and tamper-evidence. Pinchy, world-model-mcp, memory-wiki, and the open Memory Audit PR are useful prior art, but none close the OpenClaw MEMORY.md and memory/*.md mutation-audit gap.

## What This Changes

The issue requests an append-only audit log for agent memory-file changes, including what changed, when, why, session/user context, and tamper-detection support.

## Best Possible Solution

Define a memory plugin/SDK-owned mutation audit contract for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
