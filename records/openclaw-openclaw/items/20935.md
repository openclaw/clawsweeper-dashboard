## Summary

Keep open: current main has memory lifecycle events and related prior art, but it still does not provide the requested all-write mutation audit trail for `MEMORY.md` and `memory/*.md` with cause, actor/session context, and tamper-evidence.

## What This Changes

The issue requests an append-only audit log for agent memory-file changes that records what changed, when, why, session/user context, and tamper-detection metadata.

## Best Possible Solution

Design a first-class memory mutation audit contract around the actual memory-file write surfaces, with explicit cause propagation, privacy limits, tamper-evidence strategy, and public memory docs before implementation.
