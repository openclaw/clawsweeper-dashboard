## Summary

Keep open: current main and the latest release only provide lifecycle memory-host events, not the requested all-write mutation audit for MEMORY.md and memory/*.md with cause, actor/session context, and tamper-evidence. The Pinchy and world-model-mcp comments are useful prior art, and the open Memory Audit PR overlaps, but none is a merged safe replacement for the core memory-file audit gap.

## What This Changes

Request to add an append-only audit log for agent memory-file changes, including what changed, when, why, session/user context, and tamper-detection value.

## Best Possible Solution

Design a memory plugin/SDK-owned mutation audit layer for MEMORY.md and memory/*.md writes with operation, content summary or hash, cause, session/run/user context, privacy rules, tamper-evidence, and public docs before implementation.
