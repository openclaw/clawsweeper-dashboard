## Summary

Keep open: current main and the latest release expose a memory lifecycle event journal, but they do not implement the requested all-write audit trail for `MEMORY.md` and `memory/*.md` with actor/session/cause context and tamper-evidence. Pinchy, world-model-mcp, and the open Memory Audit review-queue PR are useful prior art or partial overlap, not an OpenClaw core implementation of this request.

## What This Changes

The issue requests an append-only audit log for all agent memory file changes, including what changed, when, why, session/user context, and tamper-detection support.

## Best Possible Solution

Define a maintainer-approved memory mutation audit contract around all durable memory write surfaces, with storage/integrity/privacy choices settled up front, cause propagation from callers, focused tests for direct writes, promotion, dreaming, and memory flush, and public docs for the resulting operator contract.
