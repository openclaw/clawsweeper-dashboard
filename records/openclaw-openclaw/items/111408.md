## What This Changes

The branch snapshots a cron job’s admitted schedule and prevents a completed running invocation from deleting, disabling, advancing, retrying, or otherwise overwriting a later one-shot reschedule while still recording that run’s outcome metadata.

## System Context

OpenClaw’s cron service persists scheduled jobs and dispatches due jobs to isolated or manual execution paths. When an invocation finishes, its outcome handler updates the stored job; this change distinguishes the schedule owned by the completed run from a schedule an operator edited while that run was active.
