## Summary

Keep open. Current main and the latest release still do not carry explicit LiteLLM Claude cache retention into the Anthropic `cache_control` payload path, and the open linked PR is an unmerged fix candidate rather than an implemented fix.

## What This Changes

Honor explicit `cacheRetention` for LiteLLM-proxied Anthropic models by carrying it through cache-retention resolution and injecting Anthropic `cache_control` markers on OpenAI-compatible payloads.

## Best Possible Solution

Review and land or replace https://github.com/openclaw/openclaw/pull/99574 with a narrow explicit-only LiteLLM Claude cache-control fix, focused regression tests, docs alignment, and redacted live provider proof when credentials are available.
