## What This Changes

The branch resolves Zsh and Fish completion startup profiles from their effective configuration roots and uses that shared resolution for installation, Doctor diagnostics, and onboarding reload instructions.

## System Context

OpenClaw's CLI writes generated completion scripts into a state cache and adds a source command to the startup file used by the selected shell. Doctor and onboarding consume the same completion information to report status and tell users how to activate it.
