## Summary

This PR has a concrete native macOS layout regression: at narrow desktop widths the changed titlebar condition removes the only reliably reachable new-thread action while the sidebar action can sit beneath the native titlebar strip. Keep it open for a focused layout correction before merge.

## What This Changes

The PR renames chat-creation UI copy to “thread”, relocates the new-thread action to the sidebar brand row, moves drafts into the Threads section, and reduces sidebar-section chrome.

## Best Possible Solution

Preserve one visible, clickable new-thread affordance throughout the native macOS desktop width range, either by retaining the titlebar control until sidebar clearance applies or by changing the native/sidebar layout so the brand-row control cannot be occluded.

## Solution Assessment

No: the UI cleanup is otherwise coherent, but hiding the titlebar action solely from `navCollapsed` does not account for the native sidebar-clearance breakpoint. The fix should key the affordance to the actual reachable layout state.
