## Summary

Keep open: current main still does not implement the broader Discord active-target scoping requested here, and the remaining fix changes stable multi-agent routing precedence, role semantics, and bot-loop behavior.

## What This Changes

The issue asks OpenClaw to tighten Discord preflight mention gating so messages aimed at another agent, unrelated role mentions, quoted later mentions, and other configured agent bots do not route to the current agent.

## Best Possible Solution

Maintainers should define one Discord-owned active-target contract, then implement target selection in the Discord plugin before shared default routing with focused preflight tests and redacted live multi-bot Discord proof.
