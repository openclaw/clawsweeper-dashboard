## Summary

Keep open: current main and the latest release still resolve Discord routing before any competing active-target decision, match mention regexes against the full message text, and only compare explicit/reply metadata to the current bot id. The source-level bug remains valid, but the durable fix needs maintainer confirmation for Discord multi-agent precedence, role mentions, quoted text, home-channel defaults, and bot-authored messages.

## What This Changes

The issue requests stricter Discord mention/preflight routing so messages targeting another agent, role, quoted mention, or configured agent bot are not incorrectly accepted by the current agent.

## Best Possible Solution

Confirm the Discord active-target contract, then implement target selection inside the Discord plugin before default admission with focused regression coverage for other-agent, role, quoted-mention, and bot-authored cases.
