## Summary

Keep open: current main and v2026.6.11 still make Discord route and mention decisions around the running/default route, with no active-target attention window or configured-other-agent suppression, so the reported Discord misrouting and false-positive mention-gating problem remains.

## What This Changes

Tighten Discord preflight so only the active current-agent target in the opening attention context wakes the agent, while other-agent, unrelated-role, later quoted mention, and cross-bot cases are dropped or routed correctly.

## Best Possible Solution

Define one Discord-owned active-target rule: evaluate an opening attention window, map configured bot/user/role signals to OpenClaw agents before default routing, suppress the default owner when another configured target wins, and cover the behavior with focused preflight/routing tests plus redacted live Discord proof.
