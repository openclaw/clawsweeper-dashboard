## Summary

Keep open: current main and v2026.6.11 still resolve Discord routing before any cross-agent active-target decision, and the open related PR only covers a narrower bot-authored reply policy.

## What This Changes

The issue reports Discord preflight and mention gating allowing messages through when another agent, role, quoted mention, or bot-authored mention-only message should not target the current agent.

## Best Possible Solution

Confirm the Discord active-target contract, then implement target selection inside the Discord plugin before default routing with focused regression coverage for other-agent, role, quoted-mention, bot-authored, and default-owner suppression cases.

## Reproduction Assessment

Yes, at source level: current main resolves the Discord route before cross-bot target selection, matches configured mention regexes against the full message text, and compares explicit/reply metadata only to the current handler bot id. I did not run a live Discord replay in this read-only review.

## Solution Assessment

Unclear until maintainers confirm the product contract. The attention-window direction is plausible, but the durable fix needs approved precedence for cross-bot targets, role mentions, quoted text, home-channel defaults, and bot-authored messages.
