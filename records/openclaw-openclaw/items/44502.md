## Summary

Keep open: current main and v2026.6.11 still do not implement the broader Discord active-target scoping requested here, and the remaining fix changes stable multi-agent routing precedence, role semantics, and bot-loop behavior.

## What This Changes

Tighten Discord preflight so multi-agent guild messages only wake the actively addressed bot and ignore other-agent, unrelated-role, bot-loop, or quoted/later mention signals.

## Best Possible Solution

Maintainers should define one Discord-owned active-target contract, then implement target selection in the Discord plugin before shared default routing with focused preflight tests and redacted live multi-bot Discord proof.
