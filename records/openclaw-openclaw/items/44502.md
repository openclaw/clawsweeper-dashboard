## Summary

Keep open: current main still routes Discord messages before it can make a full active-target decision, uses only the current bot ID for explicit/reply mention checks, and scans the full typed text for regex mention matches rather than a bounded attention window. The issue remains valid, but the permanent fix changes stable Discord multi-agent routing and needs maintainer product direction.

## What This Changes

The issue asks OpenClaw to tighten Discord preflight attention scoping so messages aimed at other agents, unrelated roles, quoted mentions, or other configured bot senders are not routed to the current agent.

## Best Possible Solution

Define one Discord-owned active-target rule before dispatch: inspect a bounded opening attention window, prefer configured bot mentions and reply targets over the default owner, preserve explicit opt-in role semantics, and prove the behavior with focused preflight/routing tests plus live Discord proof.
