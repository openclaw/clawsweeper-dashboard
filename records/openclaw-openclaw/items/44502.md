## Summary

## What This Changes

The issue asks to tighten Discord preflight so only the actively addressed agent passes and other-agent, unrelated-role, quoted-mention, and bot-authored mention-only cases are dropped.

## Best Possible Solution

Confirm the Discord active-target contract, then implement target selection in the Discord plugin before default dispatch with focused regression coverage for other-agent, role, quoted-mention, and bot-authored cases.

Yes, at source level: current main routes before target selection, passes full baseText into mention matching, and checks explicit/reply metadata only against params.botUserId; no live Discord replay was run.
