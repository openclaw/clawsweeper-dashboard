## Summary

Keep open: current main and v2026.6.11 still route Discord messages before choosing a cross-bot active target, compare mention/reply metadata only to the current handler bot ID, and match configured mention text against the whole message rather than an attention window.

## What This Changes

The issue reports overly permissive Discord preflight mention gating that can route messages to the wrong agent in multi-agent Discord setups.

## Best Possible Solution

Confirm the Discord active-target contract, then implement target selection inside the Discord plugin before default routing with focused regression coverage for other-agent, role, quoted-mention, bot-authored, and default-owner cases.

## Reproduction Assessment

Yes, at source level: current preflight resolves Discord routing before cross-bot target selection, checks explicit/reply metadata only against the current handler bot ID, and still matches mention regexes against full message text. I did not run a live Discord replay in this read-only review.

## Solution Assessment

Unclear until maintainers confirm the product contract. A simple attention-window patch is only a partial fix unless it also defines cross-bot target precedence, role semantics, bot-authored messages, and default-owner suppression.
