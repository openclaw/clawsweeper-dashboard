## Summary

Keep open: current main and latest checked release still make Discord mention decisions from route-selected/current-bot facts and full message text, so the multi-agent misrouting and quoted/role mention cases described in the issue remain unresolved. The fix needs maintainer confirmation of Discord active-target precedence before implementation.

## What This Changes

The issue reports overly permissive Discord preflight routing and mention gating in multi-agent channels, including other-agent targets, role mentions, quoted mentions, and bot-authored messages.

## Best Possible Solution

Confirm the Discord active-target contract, then implement target selection inside the Discord plugin before default routing with regression coverage for other-agent, role, quoted-mention, and bot-authored cases.

## Reproduction Assessment

Yes at source level: current main resolves Discord routing before cross-bot target selection, matches mentions against full message text, and compares explicit/reply metadata only to the current handler bot id; no live Discord replay was run.
