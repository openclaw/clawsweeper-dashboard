## Summary

Keep open: current main and the latest release still lack the broader Discord active-target scoping reported here, and the remaining fix needs maintainer direction because it would change stable multi-agent Discord routing precedence.

## What This Changes

The issue asks Discord preflight to ignore quoted/later mentions, suppress messages aimed at other configured agents or unrelated roles, and avoid cross-agent bot loops in mention-gated channels.

## Best Possible Solution

Define one Discord-owned target-selection rule, then implement it in the bundled Discord plugin before shared default routing with focused preflight/routing tests and redacted live Discord proof.
