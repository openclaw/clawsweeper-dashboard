## Summary

Keep open: current main and v2026.6.11 still resolve Discord routing around the current/default route and current bot id, with no active-target attention window or configured-other-agent suppression, so the reported Discord misrouting and false-positive mention-gating problem remains.

## What This Changes

Issue requests stricter Discord mention preflight and routing so messages targeting another agent, unrelated roles, quoted mentions, or other configured agent bots are not accepted by the current agent.

## Best Possible Solution

Define one Discord-owned active-target rule: evaluate an opening attention window, map configured bot/user/role/reply signals to OpenClaw agents before default routing, suppress non-target agents, and cover the behavior with focused preflight/routing tests plus redacted live Discord proof.
