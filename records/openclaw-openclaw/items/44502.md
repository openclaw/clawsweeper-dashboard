## Summary

Keep open: current main still resolves Discord routing before any cross-agent active-target decision, compares mention/reply metadata only to the current bot, and scans the full message text rather than a scoped attention window. Existing `ignoreOtherMentions` and `allowBots="mentions"` cover adjacent cases but do not implement the requested configured-agent suppression, quoted-mention scoping, or role semantics.

## What This Changes

The issue requests tighter Discord preflight mention routing so messages targeting other configured agents, unrelated roles, quoted mentions, or other agent bots do not wake the current agent.

## Best Possible Solution

Define the Discord active-target contract, then implement a Discord-owned preflight selector that uses native mention/reply metadata plus scoped attention text before default routing.
