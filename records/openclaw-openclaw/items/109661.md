## What This Changes

The PR makes WhatsApp group mention gating evaluate configured text mention patterns when native mention metadata names another participant, while continuing to suppress the numeric self-number fallback in that branch.

## Best Possible Solution

Preserve the patch’s narrow distinction between operator-configured text patterns and the numeric fallback, then land it once a redacted live WhatsApp group run demonstrates one matching-pattern admission and one unmatched control rejection.

## Solution Assessment

Yes. Evaluating only configured patterns before the existing rejection is narrower and safer than falling through to the shared numeric fallback, and the tests cover both the corrected behavior and the over-admission boundary.
