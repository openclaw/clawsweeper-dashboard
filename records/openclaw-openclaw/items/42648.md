## Summary

Keep open: current main and the latest release still provide append-only daily memory capture, short-term promotion into MEMORY.md, and Memory Wiki claims/evidence, but not the requested durable write resolver with typed classification, source-required dedupe/merge decisions, conflict state, and revision history.

## What This Changes

The issue requests a Memory MVP write pipeline that classifies candidate memories, attaches source evidence, dedupes or merges before durable write, and routes conflicts or low-confidence candidates to review.

## Best Possible Solution

Define one active-memory write contract first, then implement SQLite-backed canonical records, resolver decisions, provenance/revision history, conflict review state, and memory-core/Memory Wiki interaction tests together.
