## Summary

Keep open: current main still lacks the durable memory write resolver requested here; memory-core provides file-backed search/promotion and memory-wiki provides an adjacent claim layer, but neither classifies, dedupes/merges, preserves revisions, and routes conflicts before durable write.

## What This Changes

The issue requests a Memory MVP write pipeline that classifies candidate memories, attaches provenance, dedupes or merges before durable write, and routes conflicts instead of silently overwriting.

## Best Possible Solution

Define one plugin-owned active-memory write contract first, then implement a SQLite-backed resolver with provenance, revisions, conflict review, and focused memory-core/wiki integration tests.
