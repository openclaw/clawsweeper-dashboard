## Summary

## What This Changes

The issue requests a conservative durable memory write pipeline that classifies candidate memories, attaches source provenance, deduplicates or merges before durable write, and routes conflicts for review.

## Best Possible Solution

Define one plugin-owned active-memory write contract first, then implement the SQLite-backed canonical records, resolver decisions, provenance/revision trail, conflict review path, and memory-core/Memory Wiki interaction tests together.
