## Summary

Keep open: current main and the latest release still provide file-backed memory search/get, dreaming promotion, and Memory Wiki mutations, but not the requested durable write resolver with typed classification, required source/provenance, dedupe/merge decisions, conflict state, and revision history.

## What This Changes

Build a conservative Memory MVP write pipeline that classifies candidate memories, attaches sources, dedupes or merges before durable storage, and routes conflicts or low-confidence candidates to review.

## Best Possible Solution

Define one plugin-owned active-memory write contract first, then implement the SQLite-backed schema, resolver decisions, provenance/revision trail, conflict review path, and focused memory-core/Memory Wiki interaction tests together.
