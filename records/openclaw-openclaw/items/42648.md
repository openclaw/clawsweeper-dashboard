## Summary

Keep open: current main still has Markdown-backed memory files, memory_search/memory_get, short-term promotion into MEMORY.md, and a Memory Wiki knowledge layer, but it does not implement the requested durable write resolver with typed classification, source-required dedupe/merge decisions, conflict state, and revision history. ## What This Changes

Request to add a conservative durable memory write pipeline that classifies candidates, attaches source provenance, dedupes or merges near-duplicates, and routes conflicts before writing.

## Best Possible Solution

Define one plugin-owned active-memory write contract first, then implement SQLite-backed canonical records, resolver decisions, provenance/revision history, conflict review state, and memory-core/Memory Wiki interaction tests together.
