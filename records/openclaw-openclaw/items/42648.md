## Summary

Keep open: current main still has Markdown-backed memory, SQLite indexing, thresholded promotion, and an adjacent wiki belief layer, but not the requested durable candidate write resolver with classification, source-required dedupe/merge, conflict state, and revision history.

## What This Changes

Add a durable memory candidate write pipeline that classifies candidates, attaches sources, dedupes or merges near matches, and routes conflicts or low-confidence writes for review.

## Best Possible Solution

Define one plugin-owned active-memory write contract first, then implement the SQLite records, revisions, provenance, conflict review path, and memory-core or memory-wiki interaction tests against that contract.
