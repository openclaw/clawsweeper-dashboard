## Summary

Keep open: current main still has file-backed memory search/indexing, thresholded short-term promotion, and a separate memory-wiki contradiction layer, but not the requested durable candidate write resolver with typed classification, source-required dedupe/merge decisions, conflict state, and revision history.

## What This Changes

Request to build a Memory MVP write pipeline that classifies candidate memories, attaches sources, dedupes or merges near matches, routes conflicts for review, and preserves provenance/revisions before durable writes.

## Best Possible Solution

Define one plugin-owned active-memory write contract first, then implement the SQLite-backed schema, resolver decisions, provenance/revision trail, conflict review path, and focused memory-core plus memory-wiki interaction tests together.
