## Summary

The patch is a credible fix for a P1 macOS availability failure, but this protected PR still needs inspectable after-fix evidence from a real in-place replacement before merge. The code and focused tests support the bounded-retry design; the PR body currently documents a pre-fix live reproduction and test coverage rather than an observable post-fix macOS handoff.

## What This Changes

This PR makes macOS in-place app replacement distinguish a slow live child from a failed child, bound retry attempts with exponential backoff, and preserve the existing app when handoff recovery is exhausted.

## System Context

The macOS app watches its installed bundle for an atomic replacement and starts the new bundle through an inherited readiness pipe. The old process decides whether to exit, retry, or remain running, so this handoff path determines whether an update succeeds without creating a relaunch loop.
