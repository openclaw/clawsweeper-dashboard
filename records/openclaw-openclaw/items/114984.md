## What This Changes

The PR changes macOS in-place app replacement so readiness follows child liveness, replacement failures use bounded backoff, and a terminal handoff failure leaves the existing app running.

## System Context

The macOS app watches the installed application bundle for an in-place replacement, then launches the replacement and waits for it to become ready. That handoff determines whether the replacement takes over or the current app remains running while a retry policy handles failure.
