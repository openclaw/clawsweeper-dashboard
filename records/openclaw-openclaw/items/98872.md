## What This Changes

The issue reports misleading terminal table path shortening when a value shares the home-directory string prefix without being inside the home directory.

## Best Possible Solution

Make `displayString` shorten only the exact effective home path or real child paths with a path-boundary check, then add a focused terminal-core regression test for table cells.

## Reproduction Assessment

Yes. A direct current-main module import with `HOME=/home/alice` renders `/home/alice2/project` as `~2/project`, matching the reported failure.

## Solution Assessment

Yes. The narrow maintainable fix is boundary-aware home shortening in `displayString` plus regression coverage; no new config, docs surface, or product decision is needed.
