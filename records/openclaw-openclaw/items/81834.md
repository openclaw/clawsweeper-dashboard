  - body: The successful TTS path reads the entire provider JSON with `response.json()` and then decodes whatever hex audio the upstream returns.   - confidence: 0.91
- **[P1] Do not auto-select TTS from the ASR key without approval:** `extensions/senseaudio/speech-provider.ts:164-165`
  - body: Existing installs may already export `SENSEAUDIO_API_KEY` for transcription.   - confidence: 0.87

  - body: The documented `tts set-provider senseaudio` command will fail because current CLI defines `set-provider` with required `--provider <id>`. Update the example to `pnpm openclaw infer tts set-provider --provider senseaudio`.
