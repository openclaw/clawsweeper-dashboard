Full review comments:

- **[P1] Redact sensitive wizard replies before echoing them:** `apps/macos/Sources/OpenClaw/OnboardingCrestodianChat.swift:51`
  - body: Sensitive channel/plugin wizard answers are only redacted from the engine history after this append. The macOS and TUI hosts have already stored/displayed the raw token or password, regressing the previous sensitive-field wizard behavior.
  - confidence: 0.93
- **[P1] Clear tool proposals when the user declines:** `src/crestodian/chat-engine.ts:300-302`
  - body: A `no` here clears only `this.pending`; proposals registered by the `crestodian` tool remain in `agentSession.proposalRef.current`. A later bare `yes` can arm the stale operation, so declined mutations must clear both proposal stores.
  - confidence: 0.9
- **[P1] Preserve the existing workspace default:** `src/crestodian/onboarding-welcome.ts:53-55`
  - body: For a valid partial config that already has `agents.defaults.workspace`, this always falls back to `DEFAULT_WORKSPACE` unless a CLI workspace param was passed. Accepting the setup proposal can silently replace the user's configured workspace, unlike the current wizard path.
  - confidence: 0.88
- **[P2] Run channel post-write hooks after chat setup:** `src/crestodian/chat-engine.ts:94-103`
  - body: This chat-hosted setup writes the new channel config without collecting or draining `afterConfigWritten` hooks. Channels such as encrypted Matrix use that hook for bootstrap, so chat can report setup complete while required post-write work never ran.
  - confidence: 0.88
- **[P2] Respect paused local mode before starting Crestodian:** `apps/macos/Sources/OpenClaw/OnboardingView+CrestodianSetup.swift:35`
  - body: The old macOS wizard refused to start local setup while paused, but this guard only checks `cliInstalled`. Because `GatewayConnection.request` auto-activates local mode on failure, opening the page can restart a paused gateway.
  - confidence: 0.84
- **[P2] Keep the app timeout above the server deadline:** `apps/macos/Sources/OpenClaw/OnboardingCrestodianChat.swift:75`
  - body: The app times out the `crestodian.chat` RPC at 120s, while the server-side agent-loop deadline is 180s. A slow local turn can therefore fail in the app while the gateway continues processing the setup turn.
  - confidence: 0.82
- **[P2] Auto-advance non-input wizard steps:** `src/crestodian/chat-engine.ts:568`
  - body: Note/progress/action steps are returned as chat prompts instead of being advanced automatically, so completion notes can make setup look finished while the wizard is still suspended before the config write/audit completes.
  - confidence: 0.86
- **[P2] Expose read-only health and plugin-list tool actions:** `src/agents/tools/crestodian-tool.ts:39-63`
  - body: The tool schema omits the implemented `health` and `plugin-list` operations, so model-backed Crestodian turns cannot perform safe fuzzy health/plugin-list checks even though exact typed commands can.
  - confidence: 0.82
