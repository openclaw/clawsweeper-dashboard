Full review comments:

- **[P1] Reject npm-prefixed local plugin targets:** `src/crestodian/operations.ts:371-373`
  - body: `validateCrestodianPluginInstallSpec` only rejects local paths and URLs at the outer string, so `npm:file:../pkg` and `npm:https://example/pkg.tgz` pass this guard and then the installer strips `npm:` before npm resolution. That bypasses the new Crestodian package-only restriction for arbitrary package sources; validate the inner `npm:` target before executing approved `plugin-install` actions.
  - confidence: 0.96
- **[P1] Clear declined Crestodian tool proposals:** `src/crestodian/chat-engine.ts:300-302`
  - body: An explicit `no` or `cancel` clears only `this.pending`, but model-tool proposals are stored in `this.agentSession.proposalRef.current`. A later unrelated bare `yes` can arm the stale hash and let the model retry the already-declined mutation with `approved=true`, so decline/cancel must also clear the tool proposal ref.
  - confidence: 0.93
- **[P1] Preserve the existing workspace default:** `src/crestodian/onboarding-welcome.ts:53-55`
  - body: For a valid config that already has `agents.defaults.workspace` but still needs setup, this welcome seeds `DEFAULT_WORKSPACE`; accepting setup writes that value through `applyLocalSetupWorkspaceConfig`. The classic quickstart path preserved the configured workspace, so this can silently move an existing user back to the default workspace.
  - confidence: 0.94
- **[P2] Run channel post-write hooks from chat setup:** `src/crestodian/chat-engine.ts:94-103`
  - body: The chat-hosted `connect <channel>` path calls `setupChannels` and writes config without passing `onPostWriteHook` or draining `runCollectedChannelOnboardingPostWriteHooks`. Channels such as Matrix rely on `afterConfigWritten` for required bootstrap, so the chat can report setup complete while that post-write work never ran.
  - confidence: 0.93
- **[P2] Respect paused local mode before starting chat:** `apps/macos/Sources/OpenClaw/OnboardingView+CrestodianSetup.swift:35`
  - body: This guard starts the `crestodian.chat` RPC whenever local onboarding reaches the page after CLI install. The shared local gateway request path can auto-reactivate a failed/stopped local gateway, so simply opening this page can restart a gateway the user intentionally paused instead of showing or respecting the paused state.
  - confidence: 0.9
- **[P2] Keep the app timeout above server turns:** `apps/macos/Sources/OpenClaw/OnboardingCrestodianChat.swift:72-75`
  - body: The app times out `crestodian.chat` at 120 seconds, while the server chat engine can wait 180 seconds for an agent-loop turn and the embedded run itself is allowed 120 seconds. A cold local turn can show an app error while server-side setup continues; align the client timeout above the server deadline or lower the server deadline for this RPC.
  - confidence: 0.88
- **[P2] Use a distinct transcript per chat session:** `src/crestodian/agent-turn.ts:61-66`
  - body: Each new `CrestodianAgentSession` receives a unique session id, but all sessions reuse `state/crestodian/sessions/agent.jsonl`. A second `crestodian.chat` session or `reset: true` can therefore load prior assistant history into the embedded loop; use a per-session transcript path or clear the transcript on reset.
  - confidence: 0.88
- **[P2] Expose health and plugin-list to the tool:** `src/agents/tools/crestodian-tool.ts:39-63`
  - body: The operation union, parser, and executor support read-only `health` and `plugin-list`, but the model-facing action enum and mapper omit them.   - confidence: 0.85
