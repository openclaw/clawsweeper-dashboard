## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.91

Full review comments:

- **[P1] Clear declined Crestodian tool proposals:** `src/crestodian/chat-engine.ts:300-302`
  - body: When a mutation proposal was registered by the model-facing `crestodian` tool, an explicit `no` clears only `this.pending`; `agentSession.proposalRef.current` remains set. A later unrelated bare `yes` arms the turn and can let the model retry the stale operation with `approved=true`, so decline/cancel needs to clear the tool proposal too.
  - confidence: 0.93
- **[P1] Preserve the existing workspace default:** `src/crestodian/onboarding-welcome.ts:53-55`
  - body: For a valid config that already has `agents.defaults.workspace` but still needs setup, this welcome seeds `DEFAULT_WORKSPACE`; accepting setup writes that workspace back. That regresses the classic quickstart behavior and can silently move an existing user to the default workspace.
  - confidence: 0.94
- **[P2] Run channel post-write hooks from chat setup:** `src/crestodian/chat-engine.ts:94-103`
  - body: The chat-hosted `connect <channel>` path calls `setupChannels` and writes config without collecting or draining `afterConfigWritten` hooks. Channels such as Matrix rely on that hook for bootstrap, so the chat can report setup complete while required post-write work never ran.
  - confidence: 0.93
- **[P2] Respect paused local mode before starting chat:** `apps/macos/Sources/OpenClaw/OnboardingView+CrestodianSetup.swift:35-51`
  - body: This starts the `crestodian.chat` RPC whenever local onboarding reaches the page after CLI install. In local mode `GatewayConnection.request` auto-recovers by calling `GatewayProcessManager.shared.setActive(true)`, so opening the page can reactivate a gateway the user intentionally paused.
  - confidence: 0.9
- **[P2] Keep the app timeout above server turns:** `apps/macos/Sources/OpenClaw/OnboardingCrestodianChat.swift:72-75`
  - body: The app times out `crestodian.chat` at 120 seconds, but the server chat engine can wait 180 seconds for an agent-loop turn and the embedded run itself is allowed 120 seconds. A slow local turn can therefore show an app error while server-side setup continues.
  - confidence: 0.88
- **[P2] Use a distinct transcript per chat session:** `src/crestodian/agent-turn.ts:61-66`
  - body: Each new `CrestodianAgentSession` gets a unique id, but all sessions reuse `state/crestodian/sessions/agent.jsonl`. A new session or `reset: true` can still load prior assistant history into the embedded loop, violating the session/reset contract.
  - confidence: 0.88
- **[P2] Expose health and plugin-list to the tool:** `src/agents/tools/crestodian-tool.ts:39-63`
  - body: The operation union, parser, and executor support `health` and `plugin-list`, but the model-facing Crestodian tool action enum omits them. Natural-language agent-loop turns cannot perform these safe read-only checks even though typed commands can.
  - confidence: 0.85
