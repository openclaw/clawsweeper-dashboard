  - confidence: 0.87

  - body: This chat-hosted setup writes the new channel config without collecting or draining `afterConfigWritten` hooks. Channels such as encrypted Matrix use that hook for bootstrap, so chat can report setup complete while required post-write work never ran.
  - confidence: 0.88

  - confidence: 0.86

  - body: Note/progress/action steps are returned as chat prompts instead of being advanced automatically, so completion notes can leave setup suspended before config write and audit completion while appearing done to the user.
  - confidence: 0.84

  - body: Every Crestodian agent-loop turn is still handed the same `state/crestodian/sessions/agent.jsonl` path, even though `crestodian.chat` has separate `sessionId`s and `reset`. That can feed prior chat history into a new or reset session.
