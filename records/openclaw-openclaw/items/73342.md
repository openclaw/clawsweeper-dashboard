  - body: `withMemoryHostServices()` writes one module-global `activeServices` value.   - confidence: 0.93

  - body: The default service ignores the provided buffer and trusts only a short extension map. `buildFileEntry()` passes bytes and then accepts any MIME matching the modality prefix, so renamed non-images can be treated as images while valid audio/video inputs that current media-core detects can be dropped.
  - confidence: 0.91
- **[P2] Preserve cancellation in the remote HTTP service wrapper:** `packages/memory-host-sdk/src/host/remote-http.ts:13-21`
  - body: The new service-wrapper signature omits `signal`, so remote memory POSTs cannot carry the current-main AbortSignal through `withRemoteHttpResponse()` to the guarded fetch after rebase. Keep the signal parameter in the wrapper and service call so provider-backed requests remain cancellable.
  - confidence: 0.86
- **[P2] Keep usage-counted session archives indexed:** `packages/memory-host-sdk/src/host/session-files.ts:49-54`
  - body: This helper now skips every session archive artifact name. Current main intentionally keeps `.jsonl.reset.*` and `.jsonl.deleted.*` usage-counted archives indexed so memory search can surface post-reset/post-delete history, so the service migration needs to preserve that exception.
