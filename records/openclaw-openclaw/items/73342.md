Full review comments:

- **[P1] Scope service overrides to async or host-only use:** `packages/memory-host-sdk/src/host/services.ts:82-84`
  - body: `withMemoryHostServices` swaps a module-global `activeServices` value around an async callback. Overlapping memory operations can observe another operation's auth, guarded fetch, redaction, MIME, or session-sanitization hooks, and the setters are also re-exported through SDK facades. This needs AsyncLocalStorage-style scoping or host-internal wiring before it is safe as an SDK boundary.
  - confidence: 0.93
- **[P1] Use byte-aware MIME detection in default services:** `packages/memory-host-sdk/src/host/services.ts:130`
  - body: The default `detectMime` ignores the supplied buffer and trusts only a small image-extension map, while the current core implementation sniffs bytes and covers audio/video/document formats. `buildFileEntry` passes a buffer for multimodal validation, so standalone/default services can both drop valid files and accept renamed non-images as images.
  - confidence: 0.9
- **[P2] Keep the exported heartbeat prompt aligned with core:** `packages/memory-host-sdk/src/host/services.ts:9-10`
  - body: This constant is now exported from the package foundation surface, but the value is the task prompt prefix rather than current core's `HEARTBEAT_PROMPT`. Any caller importing it from the memory-host SDK gets different heartbeat filtering behavior than the existing bridge provided.
  - confidence: 0.82
