## Summary

Keep this PR open for maintainer review. It is a focused mitigation for a credible Anthropic live-discovery failure mode, but it also adds a provider-facing Plugin SDK callback while the linked product-direction issue still leaves the stage-1 policy choice open.

## What This Changes

Adds an Anthropic-specific gate that hides newly discovered Claude model IDs unless their advertised capabilities match OpenClaw’s current request-shaping contracts, plus an optional live-catalog callback used to apply that gate.

## System Context

Anthropic’s provider plugin refreshes its model catalog from the vendor API and passes discovered rows through the shared Plugin SDK normalizer. The normalizer preserves manifest-known models and turns accepted unknown rows into selectable catalog entries that later feed request shaping.
