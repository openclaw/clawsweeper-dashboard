## Label Justifications

- `merge-risk: 🚨 security-boundary`: The fixed edge windows cause previously detected suspicious middle-body content to evade the secops-owned warning scanner.

## Summary

Keep open: the availability problem is reproducible, but this patch is not mergeable because it replaces whole-body security monitoring with edge-only scanning and therefore misses established suspicious-pattern cases. CI is green, but the contributor evidence is test-only and does not address that semantic regression.

## What This Changes

Routes external-content suspicious-pattern checks through the shared 2,048-character head/tail bounded-regex helper and adds large-input timing and head-marker tests.

## Best Possible Solution

Implement whole-body, linear-time detection for the fixed suspicious-pattern set, or first give every detector a bounded-span contract and scan overlapping chunks across the entire body; retain middle-body coverage and prove the pathological input no longer blocks the event loop.
