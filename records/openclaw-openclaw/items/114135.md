## What This Changes

Request an agent-specific model allowlist so a model can appear in one agent’s picker and slash-command menu without becoming selectable for every agent.

## System Context

OpenClaw builds a model catalog for the active agent, then sends that filtered catalog to model-selection surfaces such as the UI picker and slash-command menu. Agent configuration supplies the policy that decides which configured provider/model references are selectable for that agent.
