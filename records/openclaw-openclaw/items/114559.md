## What This Changes

The PR marks optional missing agent workspace files as expected absent, then moves them from fault-badged tabs into an Add file picker that creates the selected file on save.

## System Context

The gateway inventories an agent workspace’s canonical core files and sends their state through the gateway protocol to the Control UI. The agent Files panel turns that inventory into editable tabs, so the new signal distinguishes a genuinely missing required file from an optional file that an operator may create later.
