## What This Changes

The PR adds an optional `expectedAbsent` gateway field for normally absent agent workspace files and changes the Control UI to offer those files through an Add file picker instead of displaying them as missing-fault tabs.

## System Context

An agent workspace exposes its canonical core files through gateway RPC methods, and the Control UI renders that metadata as editable file tabs. This change distinguishes required missing files from optional files that have not yet been created, then lets the UI offer the latter for creation on save.
