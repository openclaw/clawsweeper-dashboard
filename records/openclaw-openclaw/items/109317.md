## Summary

This protected maintainer PR remains necessary: current main still reconnects the shared Control UI socket after one silent terminal probe failure, while the branch adds a bounded two-failure tolerance with activity-aware resets and focused regression coverage. The patch appears correct and narrowly owned, with no concrete defect found; merge should wait for the current-base refresh and ordinary required checks.

## What This Changes

The PR changes the Control UI terminal liveness watchdog to require two consecutive silent probe failures before reconnecting the shared gateway socket and expands timer-driven regression coverage.

## Best Possible Solution

Keep one shared, activity-aware liveness policy that tolerates a single transient stall, resets its streak on any evidence of life or reconnect, and retains focused tests for both transient and genuinely dead sockets.
