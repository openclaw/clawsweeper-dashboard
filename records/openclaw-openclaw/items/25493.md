## Summary

Keep open. Current main and the latest release still hardcode OpenClaw-owned prompt sections and expose only narrower provider, hook, bootstrap, and channel prompt surfaces, so the remaining work is a maintainer product and security-boundary decision.

## What This Changes

Request to make fixed OpenClaw-owned system prompt sections editable, for example through SAFETY.md or template-backed overrides.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, and prompt regression coverage; if rejected, document hooks, provider overlays, channel prompts, and bootstrap files as the supported alternatives.
