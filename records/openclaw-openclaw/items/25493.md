## What This Changes

Request to make fixed OpenClaw system prompt sections, especially Safety and system tips, editable through a first-class template or workspace-file override surface.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, prompt-cache behavior, and regression coverage; if rejected, document existing provider, hook, channel, and bootstrap surfaces as the supported alternatives.
