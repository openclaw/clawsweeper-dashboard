Keep open. Current main and v2026.6.11 still hardcode OpenClaw-owned prompt sections such as Safety, OpenClaw Control, and Self-Update, while related implementation attempts are closed unmerged or narrower than this request.

## What This Changes

Request to make OpenClaw-owned system prompt templates or sections, especially Safety, user-editable.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, prompt-cache behavior, and regression coverage; if rejected, document the existing provider, hook, channel, and bootstrap surfaces as the supported alternatives.
