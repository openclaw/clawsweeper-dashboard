## Summary

Keep open. Current main and v2026.6.11 still hardcode the requested OpenClaw-owned prompt sections and only expose narrower provider, hook, bootstrap, or adjacent identity/config prompt surfaces, so this remains a maintainer product and security-boundary decision.

## What This Changes

The issue requests a user-editable template or override mechanism for fixed OpenClaw system prompt sections such as Safety and system tips.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, and prompt regression coverage; if rejected, document hooks, provider overlays, and bootstrap files as the supported alternatives.
