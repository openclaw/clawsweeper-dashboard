## Summary

Keep open. Current main and v2026.6.11 still hardcode OpenClaw-owned prompt sections and expose only narrower provider, hook, bootstrap, or adjacent config surfaces, so the remaining work is a maintainer product and security-boundary decision.

## What This Changes

Request to make fixed OpenClaw system prompt template sections, especially Safety/system tips, editable through files or templates instead of core literals.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, and prompt regression coverage; if rejected, document hooks, provider overlays, channel prompts, and bootstrap files as the supported alternatives.
