## Summary

Keep open. Current main and the latest release still hardcode the requested OpenClaw-owned prompt sections and only expose narrower provider, hook, bootstrap, or channel prompt surfaces, so the remaining work is a maintainer product and security-boundary decision.

## What This Changes

Request to make OpenClaw-owned system prompt sections editable or template-backed, such as allowing a SAFETY.md-style override for the Safety section.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, and prompt regression coverage; if rejected, document hooks, provider overlays, and bootstrap files as the supported alternatives.
