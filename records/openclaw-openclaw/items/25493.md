## Summary

Keep open. Current main and v2026.6.11 still keep Safety, OpenClaw Control, and OpenClaw Self-Update as OpenClaw-owned prompt literals, while the only section override contract is provider-owned and limited to three named sections; this remains a product and security-boundary decision, not conservative cleanup.

## What This Changes

The issue asks for user-editable OpenClaw system prompt templates or sections, with a SAFETY.md-style override suggested for fixed core prompt text.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, prompt-cache behavior, and regression coverage; if rejected, document provider overlays, hooks, channel prompts, and bootstrap files as the supported alternatives.
