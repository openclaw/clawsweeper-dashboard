## Summary

Keep open. Current main and the latest release still keep the requested OpenClaw-owned system prompt sections fixed, and the remaining work is a maintainer product/security-boundary decision rather than conservative cleanup.

## What This Changes

The issue requests user-editable templates or section overrides for fixed OpenClaw system prompt content such as Safety and other core prompt guidance.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, prompt-cache behavior, and regression coverage; if rejected, document current provider, hook, channel, and bootstrap customization paths as the supported alternatives.
