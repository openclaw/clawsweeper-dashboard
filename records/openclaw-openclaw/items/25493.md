## Summary

Keep open. Current main and the latest release still keep OpenClaw-owned prompt sections fixed, and making Safety or other core prompt text editable needs maintainer product and security direction.

## What This Changes

The issue requests a user-editable system prompt template or section override surface, such as a SAFETY.md override or template language for fixed core prompt sections.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, prompt-cache behavior, docs, and regression coverage; if rejected, document the existing provider, hook, channel, and bootstrap surfaces as the supported alternatives.
