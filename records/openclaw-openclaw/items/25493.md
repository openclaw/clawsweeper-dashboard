## Summary

Keep open. Current main and the latest release still hardcode OpenClaw-owned prompt sections and only expose narrower provider, bootstrap, hook, channel, or adjacent config surfaces, so this remains a product and security-boundary decision rather than cleanup-close material.

## What This Changes

Request to make fixed OpenClaw system prompt sections, especially Safety and system tips, editable through a section/template override surface such as SAFETY.md.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, and prompt regression coverage; if rejected, document provider overlays, channel prompts, bootstrap files, and prompt hooks as the supported alternatives.
