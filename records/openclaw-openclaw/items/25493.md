## What This Changes

Request to make fixed OpenClaw-owned system prompt sections editable, for example through SAFETY.md or a template mechanism.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, prompt-cache behavior, and regression coverage; if rejected, document existing provider, hook, channel, and bootstrap surfaces as supported alternatives.

- **Defer To Narrower Prompt Work:** Let identity-line, config-rules, include, and hook-replacement work proceed independently while leaving broad Safety/template editing unresolved.

## Solution Assessment
