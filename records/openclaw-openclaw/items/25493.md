Keep open. Current main and latest release still hardcode OpenClaw-owned prompt sections such as Safety, Tool Call Style, OpenClaw Control, and Self-Update, and the related implementation attempts are closed unmerged or narrower than this request.

## What This Changes

Request to make fixed OpenClaw-owned system prompt sections editable through a template or override surface such as SAFETY.md.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, prompt-cache behavior, and regression coverage; if rejected, document the existing provider, hook, channel, and bootstrap surfaces as the supported alternatives.
