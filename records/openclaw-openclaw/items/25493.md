## Summary

Keep open. Current main and latest release still do not provide SAFETY.md-style or named user-editable overrides for OpenClaw-owned system prompt sections, and the remaining work is a product/security-boundary decision rather than a stale cleanup candidate.

## What This Changes

Request to make fixed OpenClaw-owned system prompt sections or templates user-editable, such as overriding Safety via workspace files.

## Best Possible Solution

Define one maintainer-approved named-section override contract with explicit trust boundaries, precedence, schema or workspace-file rules, docs, and prompt regression coverage; if rejected, document existing hook, provider, channel, and bootstrap surfaces as the supported alternatives.
