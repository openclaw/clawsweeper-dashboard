The PR moves the Browser mutation CSRF guard before JSON parsing and adds loopback HTTP regressions for rejected malformed JSON and accepted valid JSON.

## Best Possible Solution

Keep the shared order as request-lifetime middleware, header-only mutation guard, then JSON parser across both Browser servers, and land it after redacted exact-head HTTP proof demonstrates both the cross-site 403 and an allowed parsed mutation.
