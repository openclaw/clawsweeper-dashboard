## Summary

Keep open. Current main has adjacent model-not-found hardening and bounded announce-delivery tests, but source still shows requester `chat.history` probing, announce retry/give-up paths, and no proof that the reported `Model not available: fable` provider error can no longer trigger the combined subagent/gateway starvation failure; #90178, #84212, and #91307 each cover only part of the incident.

## What This Changes

The issue asks OpenClaw to turn terminal provider model-unavailable errors in subagent announce flows into bounded failures instead of allowing retries/history polling to starve the gateway.

## Best Possible Solution

Land a maintainer-approved bounded failure path that classifies terminal model-unavailable provider errors correctly, avoids announce cleanup amplifying requester history reads, and wakes or blocks the parent completion deterministically while tracking config validation/watchdog work in the linked issues.
