## Summary

Keep open. ## What This Changes

The issue asks OpenClaw to bound terminal provider model errors so one bad model ref cannot drive subagent announce retries, requester history polling, and gateway starvation.

## Best Possible Solution

Land a maintainer-approved bounded failure path that classifies terminal model-unavailable provider errors correctly, prevents announce cleanup from amplifying requester history polling, wakes or blocks the parent deterministically, and tracks config hot-reload validation separately if needed.
