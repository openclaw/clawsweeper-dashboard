## What This Changes

The issue asks for terminal provider model-unavailable errors during subagent completion to fail in a bounded way without causing announce retries, repeated history polling, parent-session hangs, or gateway unresponsiveness.

## Best Possible Solution

Land a maintainer-approved core runtime fix that classifies terminal model-unavailable provider errors, avoids control-plane amplification in announce cleanup, and deterministically wakes or blocks the parent completion; keep broader config hot-reload validation and watchdog recovery as linked follow-ups if needed.
