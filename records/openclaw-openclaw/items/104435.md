Current `main` still lacks the requested diagnostic-prepack profile selector: normal prepack always runs the default build, while the recently merged source-performance work only added the reusable profile. This fresh issue is maintainer-authored, assigned, protected, and not superseded by another issue or PR.

## Best Possible Solution

Let diagnostic packaging request the existing `sourcePerformance` profile through the canonical build argument path, preserve `full` as ordinary prepack's default, leave prepared release packaging unchanged, and add focused coverage for default, selected, and invalid profiles.
