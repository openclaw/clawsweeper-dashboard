## Summary

Keep this PR open. The second commit resolves the previous focus-transfer finding, but the revised one-stop tab model still lacks composite-widget semantics that expose arrow navigation to assistive technology, and no inspectable browser proof demonstrates the resulting interaction.

## What This Changes

Adds left/right arrow cycling, roving tabindex, and focus transfer to the Control UI theme-mode selector.

## Best Possible Solution

Implement the selector as native same-name radios or a complete ARIA radiogroup; alternatively expose the existing toggle buttons as a toolbar, then add focused browser coverage and a short recording proving Tab entry, arrow navigation, wraparound, selection, and focus.
