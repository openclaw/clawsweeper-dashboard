## What This Changes

This PR adds a cache-only replay protocol so `openclaw agent` can reconnect after an ambiguous Gateway disconnect, wait for the original detached run, and return its cached terminal result without rerunning the turn.

## System Context

`openclaw agent` submits a turn to the Gateway, which can continue the accepted run after the client connection ends. The proposed recovery path reconnects the CLI to wait for that run and replay its cached terminal result, affecting command output, delivery behavior, and mixed-version Gateway clients.
