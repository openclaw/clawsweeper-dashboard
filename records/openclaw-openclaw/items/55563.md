## What This Changes

The issue reports two v2026.3.24 regressions: `openclaw browser tabs --browser-profile remote` now rejects a previously accepted option order, and `openclaw doctor --fix` can cycle a Gateway service whose systemd unit points at an unstable nvm-managed Node path.

## Best Possible Solution

Land or replace the focused browser CLI compatibility fix, then resolve the Gateway runtime-path contract through the existing NVM/runtime-path issue and PR track before closing this composite report.
