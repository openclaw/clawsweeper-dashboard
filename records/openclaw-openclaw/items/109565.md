## Summary

The prefix correction is useful, but the proposed suffix expression can still return an orphaned low surrogate when the final four-code-unit boundary splits an emoji; this correctness blocker and test-only proof should be resolved before merge.

## What This Changes

The PR changes media-generation live-test API-key redaction to use a UTF-16 truncation helper and adds focused unit coverage for the helper module.

## Best Possible Solution

Use a canonical UTF-16-safe tail-slicing mechanism that validates the starting boundary, apply the invariant consistently across all three media redactors, and cover both prefix-high-surrogate and suffix-low-surrogate boundary cases.
