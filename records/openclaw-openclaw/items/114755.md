## What This Changes

This PR centralizes CJK-aware, UTF-16-safe tool-result budgeting for live truncation and the context guard, adds focused regressions and a Gateway QA scenario, and adjusts an auto-reply test harness to preload mocked lazy runtimes without a synthetic turn.

## System Context

The embedded agent runner collects text returned by tools, bounds it before adding it to the next model prompt, and may trim it again when the in-turn context nears its limit. This change makes those independent budgeting stages use the same text-cost calculation so dense CJK output is not treated like low-cost ASCII text.
