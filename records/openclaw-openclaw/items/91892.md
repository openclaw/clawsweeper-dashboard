## What This Changes

The issue asks OpenClaw cron jobs to deliver main-session system events reliably, bound or recover isolated model-stream stalls, and report immediate wake failures accurately.

## System Context

OpenClaw's cron subsystem turns scheduled jobs into either main-session events or isolated agent runs, then routes any resulting output to configured delivery channels. Isolated runs pass through the agent runner and model-fallback logic, while cron wake requests enqueue an immediate heartbeat against an existing session.
