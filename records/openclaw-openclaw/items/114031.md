## What This Changes

Improve Control UI new-session responsiveness by rendering the chat destination immediately while the Gateway creates the canonical session, then restoring the full draft and original New session location if creation fails.

## System Context

The Control UI sends a first-message draft to the Gateway to create a session, then routes the browser to that session’s chat view. This proposal changes the client-side transition so users can enter the chat surface before the creation response arrives, while preserving failure recovery.
