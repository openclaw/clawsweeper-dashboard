## Summary

Keep open. Current main and the latest release still reject non-thread `mode="session"` in both native subagent and ACP spawn paths, and the requested decoupling remains a product/session-routing contract change rather than conservative cleanup.

## What This Changes

The issue requests allowing persistent `sessions_spawn` sessions without requiring channel thread binding.

## Best Possible Solution

Define a first-class non-thread persistent-session contract, then update native spawn, ACP spawn, model-facing schema, follow-up targeting, cleanup, docs, and focused tests together.

Unclear. Decoupling persistence from thread binding is plausible, but direct guard removal is not the best fix without an explicit non-thread ownership, delivery, targeting, and cleanup contract.
