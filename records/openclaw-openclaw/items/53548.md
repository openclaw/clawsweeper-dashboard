## Summary

Keep open. Current main and the latest release still reject `mode="session"` without `thread: true` in both native subagent and ACP spawn paths, and the requested unbound persistent-session behavior remains a product/session-routing decision rather than cleanup-closeable.

## What This Changes

The issue asks OpenClaw to allow persistent ACP and native subagent sessions without requiring channel thread binding.

## Best Possible Solution

Define a first-class parent-owned unbound persistent child-session contract, then update native spawn, ACP spawn, schema exposure, follow-up targeting, lifecycle cleanup, docs, and focused tests around that contract.
