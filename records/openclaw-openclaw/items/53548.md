## Summary

Keep open: current main and the latest release still reject non-thread `mode="session"` in both native subagent and ACP spawn paths, and the requested decoupling is a session-routing product contract rather than conservative cleanup.

## What This Changes

Request to allow persistent native and ACP `sessions_spawn` sessions without requiring channel thread binding.

## Best Possible Solution

Define a first-class non-thread persistent-session contract, then update native spawn, ACP spawn, model-facing schema, follow-up targeting, cleanup, docs, and focused tests together.

## Solution Assessment

Unclear. Decoupling persistence from thread binding is plausible, but direct guard removal is not the best fix without an explicit non-thread ownership, delivery, targeting, cleanup, and ACP inline-delivery contract.
