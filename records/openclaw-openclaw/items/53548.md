- `P2`: The issue blocks useful multi-session orchestration on non-thread or non-child-thread flows, but the fix requires product design rather than an emergency patch.

## Summary

Keep open. Current `main` and the latest release still reject `mode="session"` without `thread: true` in both native subagent and ACP spawn paths, and the requested headless persistent-session behavior needs an explicit routing, lifecycle, cleanup, and ownership contract before implementation.

## What This Changes

The issue requests allowing persistent `mode="session"` ACP/subagent sessions without requiring channel thread binding.

## Best Possible Solution

Define a bounded headless persistent child-session contract, then implement it consistently across native subagent and ACP spawn with explicit delivery, cleanup, `sessions_send`, and docs coverage.

Rationale: The source repro is clear, but the requested fix changes durable session lifecycle, routing, cleanup, and channel delivery semantics rather than only repairing a narrow regression.

Likely owner: osolmaz

Owner confidence: high

Options:

- **Define headless persistent sessions (recommended):** Specify non-thread `mode="session"` semantics for both ACP and native subagents, then implement with focused tests for `sessions_send`, cleanup, and delivery behavior.
- **Keep session mode thread-bound:** Leave runtime behavior intact and improve docs/tool copy around `mode="run"`, `sessions_send`, and supported thread-bound channels.
- **Limit to ACP affinity only:** Add a separate ACP persistence contract such as affinity-backed sessions while keeping native `mode="session"` thread-bound.

## Reproduction Assessment

Yes. Source inspection shows both native and ACP spawn paths return an error before creating a persistent child session when `mode="session"` is used without `thread: true`; I did not run a live channel repro in this read-only sweep.

## Solution Assessment

Unclear. Removing only the guard is too narrow unless maintainers also define the non-thread lifecycle, delivery, cleanup, visibility, and ACP/native consistency contract.
