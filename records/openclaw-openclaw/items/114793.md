## Summary

The patch is a focused, plausible fix for an abort-insensitive browser lifecycle wait and adds a regression test that preserves the lifecycle owner. It should stay open for normal review because the submission supplies a live pre-fix observation and mock-level regression coverage, but no inspectable after-fix real browser run yet.

## What This Changes

This PR makes cancelled browser profile operations stop waiting on a pending per-profile lifecycle transition while allowing the transition owner to finish for other callers.

## System Context

The bundled browser plugin serializes start, stop, and ordinary profile work through a per-profile lifecycle actor. Browser routes and diagnostics enter that actor before they access Chrome or Playwright, so an aborted request must be released without cancelling the shared profile transition.

  D -- yes --> F[Run profile operation]
