Keep open; current main still drops `seq: 0` from SDK normalized event IDs even though the gateway protocol allows zero-valued event sequences, so this is a real narrow SDK bug rather than cleanup-close material.

## What This Changes

The issue reports that SDK gateway event normalization omits valid zero sequence values from normalized gateway event IDs.

## Best Possible Solution

Keep the issue open and fix `normalizeGatewayEvent` so only absent optional id components are skipped while valid numeric zero values from `seq` and `payload.ts` are preserved, with a focused SDK regression test.
