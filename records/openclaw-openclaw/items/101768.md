Keep open: current main still builds normalized SDK event IDs with a Boolean filter that drops valid zero values, and no related issue or PR currently owns the fix.

## What This Changes

The issue asks OpenClaw to preserve protocol-valid `seq: 0` values when constructing SDK normalized gateway-event IDs.

## Best Possible Solution

Preserve finite zero values in `normalizeGatewayEvent()` IDs while still omitting only absent optional parts, with a focused regression test for `seq: 0` and `ts: 0`.
