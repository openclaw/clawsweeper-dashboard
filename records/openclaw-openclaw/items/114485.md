## What This Changes

Generate readable default names for managed worktrees and session-owned worktree branches while retaining explicit names and the existing 64-character contract.

## System Context

Managed worktrees are checkouts created for sessions and other OpenClaw clients. A creation request selects or allocates a branch and checkout path, then returns that checkout to the caller for session and review workflows.
