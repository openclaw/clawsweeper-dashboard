## What This Changes

The PR changes Chrome-extension relay health checks and Playwright tab enumeration so an already-connected browser can list and select healthy shared tabs when another tab wedges on Runtime-dependent operations.

## System Context

OpenClaw's browser tools connect through a local Chrome extension relay to enumerate user-shared tabs and issue CDP commands. The relay's tab list feeds `tabs`, `open`, and `snapshot`, so a blocked tab-discovery step can stall otherwise healthy browser operations.
