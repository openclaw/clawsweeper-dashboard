## Summary

Keep open: current main exposes the effective level in run metadata and interactive thinking controls explain unsupported choices, but it does not provide one explicit requested-versus-applied diagnostic contract across agent, persisted-default, and spawn paths.

## What This Changes

Add a consistent warning or result diagnostic whenever OpenClaw reduces or rewrites a requested thinking level.

## Best Possible Solution

Resolve requested, applied, and reduction reason once at the canonical thinking-policy boundary, carry that prepared diagnostic through every execution result, and emit a deduplicated user warning only on surfaces where users cannot inspect structured metadata.
