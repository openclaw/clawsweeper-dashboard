## What This Changes

This PR adds `openclaw automations` as an alias for the existing scheduler CLI command and changes selected CLI, Doctor, and config-schema display wording from “cron” to “automations” without renaming `cron.*` configuration or schedule syntax.

## System Context

The scheduler is exposed through the OpenClaw CLI, which resolves the typed command path before lazily loading the command implementation and applying gateway/config policies. This change adds a second public command token that must reach the same scheduler commands, output, gateway behavior, completion, and operator guidance as `openclaw cron`.
