## Summary

The prior blocking concern remains on the latest head: doctor accepts a symlink during detection, moves it out of the workspace, and only then invokes a reader that rejects symlinks. That can produce an apparently successful archive-only repair without merging the durable memory content, so this PR is not merge-ready.

## What This Changes

The PR adds bounded reads for AGENTS.md and root-memory files, introduces archive-only migration reporting, and adds oversized-file regression coverage.

## Best Possible Solution

Apply one consistent filesystem contract before prompting or mutating durable state: reject unsupported paths before moving them, or use an explicitly approved bounded-following primitive; only archive and merge after safe reads succeed, with regression coverage for symlinked and oversized inputs.
