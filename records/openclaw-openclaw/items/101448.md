## Summary

The resource-bounding fix is necessary, focused, and well-proven for regular files, but the selected reader introduces a blocking compatibility regression: it rejects symlinked root-memory files that current doctor behavior accepts, after the legacy memory has already been archived.

## What This Changes

The PR caps doctor reads of AGENTS.md at 1 MiB and root-memory files at 8 MiB, adds archive-only migration reporting, and adds oversized-file regression tests.

## Best Possible Solution

Bound byte reads without silently narrowing the existing root-memory path contract: either safely preserve current symlink behavior or explicitly retire it before mutation, then report the actual recovery reason and add focused regression coverage.
