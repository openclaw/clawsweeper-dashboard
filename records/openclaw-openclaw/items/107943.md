## Summary

## What This Changes

The PR parses Anthropic error response status and Retry-After values, propagates them through assistant-message error metadata, and uses them when calculating session auto-retry delays.

## Best Possible Solution

Retain the structured status and Retry-After metadata path, but share the existing long-delay policy so short cooldowns delay retry while long cooldowns return control to profile/model failover, with unrelated branch churn removed.
