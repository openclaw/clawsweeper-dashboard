## What This Changes

The branch gives debug-proxy HTTP CONNECT upstream sockets a 30-second establishment deadline, records a local capture error and returns HTTP 504 on timeout, then clears the deadline for established tunnels.

## System Context

Debug Proxy captures traffic from clients and opens a TCP upstream for HTTP CONNECT requests. This change sits between CONNECT request parsing and the bidirectional tunnel, turning a stalled upstream opening into a captured error and bounded client response.
