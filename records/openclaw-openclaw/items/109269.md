## What This Changes

The PR gives debug-proxy HTTP CONNECT upstream socket establishment a 30-second deadline, emits a local capture error and HTTP 504 on timeout, then removes that opening deadline once the tunnel connects.

## System Context

The debug proxy accepts client HTTP traffic and creates an upstream TCP connection for CONNECT tunnels while recording capture events. This change sits at the connection-opening boundary and affects whether stalled upstream handshakes terminate cleanly or leave the client and capture flow pending.
