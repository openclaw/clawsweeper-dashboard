## Summary

Keep open: current main still discards the Gateway’s partial initial-run outcome and navigates to an empty created session. The report is source-reproducible, narrowly actionable, and protected by the `maintainer` label.

## What This Changes

Retain a new Control UI session’s first message and expose the actionable Gateway rejection when session creation succeeds but the initial run does not start.

## Best Possible Solution

Return a typed full create outcome to Control UI, retain the rejected prompt as durable failed-send state tied to the created session, show the actionable `runError`, and allow retry without duplicating a successfully started run.
