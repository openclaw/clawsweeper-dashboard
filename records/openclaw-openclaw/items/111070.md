## What This Changes

The PR makes QA-channel thread creation, thread replies, and message edits consume the shared `target`, `threadName`, and `message` action fields while retaining older direct-adapter aliases.

## System Context

QA scenarios and message tools send actions through the shared outbound message-action runner into the QA-channel plugin. The plugin resolves a QA conversation or thread target, performs the matching QA bus operation, and returns the resulting message or thread target to the caller.
