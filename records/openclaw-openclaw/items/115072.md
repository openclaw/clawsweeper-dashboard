## What This Changes

Prevent a service-managed gateway from repeatedly restart-looping on an agent SQLite schema mismatch and from remaining auto-start-suppressed after `openclaw doctor --fix` repairs the database.

## System Context

Gateway startup opens each agent’s SQLite-backed state before channel and provider accounts start. A schema-version guard can direct the user to Doctor migration; the service manager may retry failed boots, while the gateway’s restart-loop protection can suppress account auto-start after repeated failures.
