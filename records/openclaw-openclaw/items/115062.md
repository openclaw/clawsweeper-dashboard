## Summary

This remains necessary: the report gives a specific, repeatable Control UI failure where a valid custom-provider file SecretRef works for normal agent inference but fails only in the isolated system-agent probe. The available context does not show a merged fix or a canonical open item that owns this exact credential-isolation failure, so it should stay open for source confirmation and a focused repair.

## What This Changes

Repair the Control UI system-agent’s isolated inference probe so it can use an already-valid file SecretRef for a custom OpenAI-compatible default model provider.

## System Context

The Gateway resolves configured model-provider credentials, including SecretRefs, for normal agent inference. The Control UI system assistant creates an isolated read-only setup-inference runtime to verify the selected model before starting its session; that probe must retain authorized credential resolution without weakening isolation.
