## What This Changes

The PR makes non-interactive onboarding place an implicit workspace under a non-default state directory and prevents isolated gateways from loading or watching the operator-home personal skill directory.

## System Context

Non-interactive onboarding persists the initial agent workspace into OpenClaw configuration, and the gateway later uses that workspace plus managed, project, and personal roots to load skills. The change gates home-scoped roots on whether the process is using the default state directory so scratch and multi-instance gateways remain self-contained.
