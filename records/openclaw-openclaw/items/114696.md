## What This Changes

This PR changes agent compaction so a failed summary of history pruned for budget reasons cancels compaction instead of advancing the stored boundary while the pruned context is absent.

## System Context

The agent compaction safeguard receives a session transcript and produces a compacted summary plus a boundary that replaces older history. When it must separately summarize a pruned prefix, that prefix summary feeds the final compaction result; this PR changes a prefix-summary failure from a warning-and-continue path to a cancellation that leaves the transcript available for retry.
