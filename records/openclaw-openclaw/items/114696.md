## Summary

This is a narrow, evidence-backed repair for a real session-state loss mode: a failed summary of pruned history now cancels compaction before any boundary can be persisted. The posted real-session cancellation and retry transcript addresses the prior proof request; keep the PR open for normal maintainer review because it carries the protected `maintainer` label.

## What This Changes

The branch makes agent-session compaction retain the full transcript when summarizing a pruned history prefix fails, and adds regressions for failure, success, and caller-abort behavior.

## System Context

Agent-session compaction trims a long transcript by summarizing an older prefix and writing a compaction boundary for later model runs. This safeguard sits between the prepared session history and persistent session state, so its failure path determines whether old context is retained or silently discarded.
