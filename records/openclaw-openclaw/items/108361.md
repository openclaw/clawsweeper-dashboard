## Summary

## What This Changes

Prevent stale claims on completed Workboard cards from consuming an owner’s dispatch slot and stranding later ready cards.

## Best Possible Solution

Review and land a focused fix that makes owner capacity reflect active work only, preserves claimed review and running behavior, and adds a real-store regression for a done card retaining its claim.
