## Summary

Keep open: current main still lacks this PR's bridge import/index-refresh coalescing and imported-source stat/read retry, while the PR has sufficient targeted proof but still needs maintainer acceptance of the session-state coalescing identity and current QA Smoke CI disposition before merge.

## What This Changes

The PR adds bounded `path-mismatch` retry handling for memory-wiki imported source pages, coalesces concurrent bridge imported-source syncs by resolved config identity, and adds focused regression coverage.

## Best Possible Solution

Land this as the canonical memory-wiki bridge reliability fix only if maintainers accept the coalescing identity and proof scope; otherwise keep https://github.com/openclaw/openclaw/issues/91154 open and split coalescing design from the already-merged guarded write retry.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainer sign-off: the bounded retry matches the fs-safe failure mode and current guarded-write direction, but coalescing bridge import/index refresh across callers is a session-state design choice. The safest final path is owner acceptance of the key and proof scope before merge.
