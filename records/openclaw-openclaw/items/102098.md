## Summary

Keep open: current main still lacks a cron/subagent requester-context contract for OAuth-dependent plugin tools, and the remaining work is a security-sensitive runtime and Plugin SDK API decision rather than conservative cleanup.

## What This Changes

The issue requests a generic way for cron jobs and sessions_spawn subagent runs to carry trusted user context for OAuth-dependent plugin tools.
