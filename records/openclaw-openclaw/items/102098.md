## What This Changes

The issue requests a generic way for cron jobs and `sessions_spawn` subagents to carry requester user context for OAuth-dependent plugin tools.

## Best Possible Solution

Design and document a typed runtime-supplied requester identity contract for cron and subagent execution in the Plugin SDK, with explicit authorization, audit, privacy, revocation, and focused cron/subagent/plugin-tool coverage.
