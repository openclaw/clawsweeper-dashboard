## What This Changes

Fix Slack so bot-authored messages from peer bots remain available in agent context when bot messages and full context visibility are enabled.

## System Context

The Slack plugin authorizes inbound Slack events, records permitted room messages, and prepares thread or room history before dispatching an agent turn. The context-visibility setting controls which supplemental history reaches the agent, while loop protection prevents the current bot from re-consuming its own messages.
