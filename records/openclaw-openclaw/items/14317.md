## What This Changes

Request to add a Slack `groupPolicy: "private"` config mode that allows private Slack channels while blocking public channels unless explicitly allowlisted.

## Best Possible Solution

Have maintainers approve or reject the Slack private-channel trust boundary; if approved, implement it as a Slack-scoped policy across config/schema, normal routing, slash/action authorization, security audit guidance, docs, and focused tests while preserving existing defaults unless a migration is explicitly approved.

## Solution Assessment
