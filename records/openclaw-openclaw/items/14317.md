Add a Slack-only `groupPolicy: "private"` mode that allows private channels by default while still allowing explicit public-channel allowlist entries.

## Best Possible Solution

Have maintainers approve or reject the Slack private-channel trust boundary; if approved, implement it as a Slack-scoped policy across config/schema, routing, action authorization, security audit guidance, docs, and tests while preserving existing defaults unless separately approved.
