## What This Changes

Add a Slack `groupPolicy: "private"` mode that allows invited private channels by default while requiring explicit allowlist entries for public channels.

## Best Possible Solution

If maintainers approve the trust boundary, implement a Slack-scoped private policy through config schema/types/metadata, normal and slash-command routing, security audit guidance, docs, and focused tests while preserving the current fail-closed allowlist default unless a separate default migration is approved.

## Solution Assessment

Unclear until maintainers approve the security boundary. The maintainable path is a Slack-owned policy extension plus docs and tests, not an automated change that silently redefines channel trust or defaults.
