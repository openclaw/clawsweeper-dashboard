## What This Changes

Requested Slack support for a `groupPolicy: "private"` mode that permits invited private channels while excluding public channels unless allowlisted.

## Best Possible Solution

Have maintainers approve or reject the Slack private-channel trust boundary; if approved, implement it Slack-scoped across config/schema, routing, slash/action authorization, security audit guidance, docs, and focused tests while preserving existing defaults unless a migration is separately approved.
