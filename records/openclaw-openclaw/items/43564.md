## Summary

Keep open: current main and v2026.6.11 still lack a `sessions_spawn(runtime: "acp")` skill selector or ACP runtime carrier for selected/rendered skill context, and the remaining work is a product/security contract decision rather than conservative cleanup.

## What This Changes

Request optional OpenClaw skill-context injection for ACP session spawns, including explicit, automatic, or default skill selection.

## Best Possible Solution

Define one ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction, then update `sessions_spawn`, ACP runtime types, docs, and focused tests together.
