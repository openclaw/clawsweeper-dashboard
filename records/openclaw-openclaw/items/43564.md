## Summary

Keep open: current main still has no ACP `sessions_spawn` skill selector or ACP runtime skill-context carrier, and the open related prompt-parity issue does not cover the ACP spawn API/security contract.

## What This Changes

The issue requests optional injection of selected, automatic, or default OpenClaw skill context into ACP `sessions_spawn` sessions.

## Best Possible Solution

Define the ACP skill-context contract first, then implement an explicit audited selector with redaction, limits, source metadata, docs, and parity tests before considering auto/default modes.
