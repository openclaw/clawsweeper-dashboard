## Summary

Keep open: current main and v2026.6.11 still expose no `sessions_spawn(runtime="acp")` skill selector, rendered skill-context carrier, or ACP runtime prompt/audit field. The request is a real feature gap, but the remaining decision crosses session context, prompt authority, redaction, and child-harness security boundaries, so it is not conservative cleanup.

## What This Changes

The issue requests optional OpenClaw skill context injection for ACP-spawned agents, with explicit skill ids, automatic relevance selection, or a default skill set.

## Best Possible Solution

Define one ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and child-harness authority before updating `sessions_spawn`, ACP runtime types, docs, and focused tests.
