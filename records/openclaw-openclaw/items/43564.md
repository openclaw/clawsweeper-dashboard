## Summary

Keep open: current main and the latest stable release still lack an ACP skill selector or skill-context carrier for `sessions_spawn(runtime: "acp")`, and the requested feature needs maintainer decisions around selection, redaction, auditability, persistence, and config/default behavior before implementation.

## What This Changes

Request optional injection of selected, default, or automatically matched OpenClaw skill context into ACP sessions spawned through `sessions_spawn(runtime: "acp")`.

## Best Possible Solution

Define a maintainer-approved ACP skill-injection contract covering selection mode, redaction, observability, persistence/resume behavior, config/default semantics, and harness-specific delivery before implementing schema, runtime, docs, and tests.

## Reproduction Assessment

Yes. Source inspection shows `sessions_spawn` has no `skills` parameter, ACP spawn params carry no skill context, and ACP runtime turn input has no skill carrier on current main and v2026.6.11.

## Solution Assessment

Unclear for implementation. The request is valid, but the best fix depends on maintainer choices about explicit/default/auto selection, redaction, observability, persistence, and whether a new default skill-set config should exist.
