## Summary

Keep open: current main and v2026.6.11 still have no `sessions_spawn(runtime: "acp")` skill selector or ACP skill-context carrier, and the remaining work needs a maintainer-approved product/security contract rather than cleanup closure.

## What This Changes

Request to allow ACP session spawns to inject selected OpenClaw skill context into Codex, Pi, OpenCode, or Gemini child-agent prompts.

## Best Possible Solution

Define a maintainer-approved ACP skill-context contract that reuses existing skill snapshot/filtering, starts with explicit selection, and records selection/redaction/size/version audit data before any automatic mode.
