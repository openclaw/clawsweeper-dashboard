## Summary

Keep open: current main and the latest stable release still lack an ACP `sessions_spawn` skill selector or ACP runtime carrier for selected/rendered skill context, and the remaining work needs a product/security contract decision rather than cleanup closure.

## What This Changes

Request to let `sessions_spawn(runtime: "acp")` inject selected or default OpenClaw skill context into ACP child sessions.

## Best Possible Solution

Define one audited ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction before changing `sessions_spawn`, ACP runtime types, docs, and tests.
