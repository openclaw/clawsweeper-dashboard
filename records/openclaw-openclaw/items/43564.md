## Summary

Keep open: current main and the GitHub-latest stable release still lack an ACP `sessions_spawn` skill selector or runtime carrier for rendered skill context, and the remaining work needs an explicit product/security contract before implementation.

## What This Changes

The issue requests optional explicit/default/automatic OpenClaw skill context injection into ACP sessions spawned with `sessions_spawn(runtime: "acp")`.

## Best Possible Solution

Define one audited ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native interaction before changing `sessions_spawn`, ACP runtime types, docs, and tests.
