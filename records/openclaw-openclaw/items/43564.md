## Summary

## What This Changes

The issue requests optional OpenClaw skill context injection for ACP session spawns, including explicit, automatic, or default skill selection.

## Best Possible Solution

Define one audited ACP skill-context contract, preferably starting with explicit skill ids, before changing schema, runtime types, docs, and tests.
