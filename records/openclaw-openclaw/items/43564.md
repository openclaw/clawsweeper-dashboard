## Summary

Keep open: current main and the latest release still do not provide an ACP `sessions_spawn` skill selector or a runtime carrier for selected/rendered skill context, and the remaining work needs a product/security contract decision rather than conservative cleanup closure.

## What This Changes

Add an optional way for `sessions_spawn(runtime: "acp")` to inject selected or rendered OpenClaw skills into spawned ACP session context.

## Best Possible Solution

Define a single audited ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction before changing tool schemas, ACP runtime types, docs, and tests.
