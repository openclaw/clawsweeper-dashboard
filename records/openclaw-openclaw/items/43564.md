## Label Justifications

- `P2`: This is a normal-priority feature/design issue with bounded but real impact on ACP child-session context and security semantics.

## Summary

Keep open: current main and v2026.6.11 still lack an ACP `sessions_spawn` skill selector or ACP runtime carrier for selected/rendered OpenClaw skill context, and the remaining work is a product/security contract decision rather than cleanup.

## What This Changes

Request optional explicit, automatic, or default OpenClaw skill-context injection into ACP child sessions spawned through `sessions_spawn(runtime: "acp")`.

## Best Possible Solution

Define a single audited ACP skill-context contract covering selection modes, prompt layer, redaction, provenance, observability, resume behavior, and Codex-native skill interaction before changing schema, runtime, docs, and tests.
