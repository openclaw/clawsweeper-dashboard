## Summary

Keep open: current main and v2026.6.11 still lack a `sessions_spawn(runtime: "acp")` skill selector or ACP skill-context carrier, and the remaining work needs a maintainer product/security contract rather than cleanup closure.

## What This Changes

The issue requests optional OpenClaw skill context injection for ACP sessions spawned through `sessions_spawn(runtime="acp")`, including explicit, automatic, or default skill selection.

## Best Possible Solution

Define a generic ACP skill-context contract before implementation: explicit per-call skill ids first, redacted bounded rendered content, audit metadata, clear no-tool-authority transfer, and docs/tests across Codex, native, and ACP paths.
