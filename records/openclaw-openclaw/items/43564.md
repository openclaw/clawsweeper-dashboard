## Summary

Keep open: current main and v2026.6.11 still lack an ACP `sessions_spawn` skill selector, rendered skill-context payload, or audit/redaction contract, and the related Codex/native skill-contract issue only partially overlaps this ACP spawn boundary.

## What This Changes

The issue requests optional OpenClaw skill-context injection for ACP `sessions_spawn` sessions, with explicit, automatic, or default skill selection.

## Best Possible Solution

Define a narrow, audited ACP skill-context contract first, preferably explicit opt-in skill ids with redaction/audit metadata, before adding schema, runtime, docs, and parity tests.
