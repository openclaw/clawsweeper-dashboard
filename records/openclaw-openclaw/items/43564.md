## Summary

Keep open: current main and v2026.6.11 still lack a `sessions_spawn(runtime: "acp")` skill selector or ACP runtime carrier for selected/rendered skill context, and the remaining work needs a maintainer product/security contract decision rather than cleanup closure.

## What This Changes

The issue requests optional OpenClaw skill-context injection for ACP sessions spawned through `sessions_spawn(runtime: "acp")`, including explicit, automatic, or default skill selection.

## Best Possible Solution

Define a single audited ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction before changing `sessions_spawn`, ACP runtime types, docs, and tests.
