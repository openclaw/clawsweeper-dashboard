## Summary

Keep open: current main and the latest release still do not expose a `sessions_spawn(runtime: "acp")` skill selector or ACP skill-context carrier, so the useful work remains but needs a maintainer-owned product and security contract before implementation.

## What This Changes

Allow `sessions_spawn(runtime: "acp")` to optionally inject selected, automatic, or default OpenClaw skill context into spawned ACP child sessions.

## Best Possible Solution

Define one ACP skill-context contract covering selection modes, prompt layer, redaction, audit metadata, resume semantics, and Codex-native interaction before implementing the tool schema, runtime types, spawn dispatch, docs, and tests.
