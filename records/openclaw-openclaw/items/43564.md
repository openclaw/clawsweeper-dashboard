## Label Justifications

- `P2`: This is a normal-priority feature/design issue with bounded but real impact on ACP child-session context and security semantics.
- `impact:session-state`: The request changes what skill context is attached to spawned ACP sessions and how that context may interact with resume and prompt history.
- `impact:security`: The request would forward local skill material into external harness prompts, requiring explicit redaction, isolation, and authority semantics.
- `maturity:stable`: The requested `sessions_spawn` contract touches the M4 Stable Gateway runtime/tool API surface, even though ACP external-runtime behavior is less mature.

## Summary

Keep open: current main and latest stable release still lack an ACP `sessions_spawn` skill selector, rendered skill-context carrier, or audit/redaction contract, and the related prompt-contract parity issue only partially overlaps this ACP spawn boundary.

## What This Changes

Request optional injection of selected, automatic, or default OpenClaw skill context into ACP `sessions_spawn` child sessions.

## Best Possible Solution

Define a narrow, audited ACP skill-context contract first, preferably explicit opt-in skill ids with redaction and audit metadata, before adding schema, runtime wiring, docs, and parity tests.
