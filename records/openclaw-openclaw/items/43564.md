## Summary

Keep open: current main and the latest release still lack a `sessions_spawn(runtime: "acp")` skill selector or ACP skill-context carrier, and the remaining work needs a maintainer-approved product/security contract rather than cleanup closure.

## What This Changes

Request optional ACP `sessions_spawn` skill context injection with explicit, automatic, or default skill selection and rendered skill content in the child session prompt.

## Best Possible Solution

Define one ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction, then update `sessions_spawn`, ACP runtime types, docs, and focused tests together.
