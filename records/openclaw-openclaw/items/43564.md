## Summary

Keep open: current main and the latest stable release still lack a `sessions_spawn(runtime: "acp")` skill selector or ACP runtime carrier for selected/rendered skill context, and the remaining work needs a product/security contract decision rather than conservative cleanup.

## What This Changes

The issue requests optional OpenClaw skill-context injection for spawned ACP sessions, including explicit skill lists, automatic selection, and default skill sets.

## Best Possible Solution

Define one ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction, then update `sessions_spawn`, ACP runtime types, docs, and focused tests together.
