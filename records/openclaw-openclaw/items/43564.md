Keep open: current main and v2026.6.11 still lack an ACP `sessions_spawn` skill selector or ACP runtime carrier for selected/rendered skill context, and the remaining work is a product/security contract decision rather than conservative cleanup.

## What This Changes

The issue requests optional injection of selected OpenClaw skill context into ACP session spawn prompts.

## Best Possible Solution

Define a single audited ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction before changing `sessions_spawn`, ACP runtime types, docs, and tests.
