## Summary

Keep open: current main and v2026.6.11 still lack a `sessions_spawn(runtime: "acp")` skill selector or ACP skill-context carrier, and the remaining work needs maintainer product/security direction rather than cleanup closure.

## What This Changes

Request to let `sessions_spawn(runtime: "acp")` optionally inject selected OpenClaw skill context into spawned ACP sessions.

## Best Possible Solution

Define one ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native skill interaction, then update `sessions_spawn`, ACP runtime types, docs, and focused tests together.
