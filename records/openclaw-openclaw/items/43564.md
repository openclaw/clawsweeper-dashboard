## Summary

Keep open: current main and v2026.6.11 still do not provide a `sessions_spawn(runtime: "acp")` skill selector or ACP skill-context carrier, and the remaining work is a product/security contract decision rather than conservative cleanup.

## What This Changes

Issue requests optional skill-context injection for ACP-backed `sessions_spawn` calls, including explicit skill lists, automatic selection, and default skill sets.

## Best Possible Solution

Define one ACP skill-context contract covering explicit/default/auto selection, redaction, observability, prompt layer, resume behavior, and Codex-native interaction, then update `sessions_spawn`, ACP runtime types, docs, and focused tests together.
