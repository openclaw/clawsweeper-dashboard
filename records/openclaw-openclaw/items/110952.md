## What This Changes

The branch stages cloud-worker workspace results as durable local Git refs, persists each ref on the pending-result row, and applies or recovers the staged result after a worker environment disappears.

## Best Possible Solution

Keep the state schema at v4 with an idempotent additive ensure, preserve changed-path-only reconciliation limits, make explicit abandonment tolerate an unavailable worktree, and attach a redacted live recovery run before merge.
