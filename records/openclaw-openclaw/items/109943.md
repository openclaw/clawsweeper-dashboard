## Summary

Keep open: the patch treats a merely configured model route as working inference, allowing guarded onboarding to launch the assistant without the live completion that defines successful guided setup. The existing configured route should remain untouched, but onboarding must exit or verify it before continuing. ([docs.openclaw.ai](https://docs.openclaw.ai/start/wizard?utm_source=openai))

## What This Changes

The PR carries the config-only `setupComplete` classification through guarded manual setup so configured-route skip and no-option paths continue to the hatch TUI.

## Best Possible Solution

Return distinct manual-stage outcomes such as `cancelled`, `keepConfigured`, and `applied`, but permit hatch continuation only after the current route has passed the normal live inference verification; otherwise preserve the config and exit with accurate recovery guidance.

## Solution Assessment

No. Preserving configuration is correct, but using config-only `setupComplete` as proof of working inference is broader than necessary; the narrow solution must distinguish outcomes and retain the live verification gate.
