Keep open: current main still loses actionable Full Disk Access guidance when the diagnostic is split across stderr chunks, while the current PR head has convincing real-process proof and no actionable correctness or security finding; it should proceed through normal exact-head merge validation.

## What This Changes

Buffers and UTF-8-decodes iMessage RPC stderr as complete lines, flushes the final unterminated line on process close, and adds regression coverage for split Full Disk Access diagnostics.

## Best Possible Solution

Retain the plugin-local StringDecoder line framing and focused real-child regression test, then merge after current-main compatibility and exact-head checks are confirmed.
