## What This Changes

This PR makes the Apple localization compiler emit translated `InfoPlist.strings` files for macOS privacy prompts, including the legacy screen-capture key, and extends compiler-output tests.

## System Context

The Apple localization compiler reads native strings and translation artifacts, then generates localized resources consumed by the packaged iOS and macOS applications. This PR extends the macOS output so the operating system receives localized privacy-permission descriptions instead of only the base English plist values.
