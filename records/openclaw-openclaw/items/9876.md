## Summary

Keep open: current main still carries `sessionKey` into the native macOS exec approval prompt path, but `buildAccessoryView` does not render a Session row, and the richer requester-context part needs privacy/security direction before implementation.

## What This Changes

Request to show the originating session and safe requester/channel context in the macOS native exec approval popup.

## Best Possible Solution

Stage the fix: render a trimmed non-empty Session row in the macOS prompt first, then add only maintainer-approved and redacted requester/channel fields to the native request model and display path.
