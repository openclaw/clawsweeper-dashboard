## Summary

Keep open: current main and the latest release still omit the Session row from the macOS native exec approval popup, while the related open PR only covers channel/chat approval prompts; richer requester fields need maintainer privacy and security direction.

## What This Changes

The issue asks for the macOS exec approval popup to show the triggering session and possibly higher-level requester context such as channel, sender, or tool reason.

## Best Possible Solution

Stage the fix by rendering a trimmed non-empty Session row in the macOS prompt first, then add only maintainer-approved and redacted requester/channel fields to the native request model and display path.
