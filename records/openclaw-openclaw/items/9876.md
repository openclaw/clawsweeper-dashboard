## Summary

Keep open: current main and the latest release still carry session metadata to the macOS exec approval path, but the native popup still does not render the existing session key or any richer requester context.

## What This Changes

The issue asks for the macOS native exec approval popup to show the triggering session and, after policy review, readable requester/channel/sender context.

## Best Possible Solution

Stage the work by adding a trimmed non-empty Session row to the macOS native prompt first, then add only maintainer-approved and redacted requester/channel fields to the Swift request model and display path.
