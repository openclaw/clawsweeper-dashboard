## Summary

Keep open: current main and the latest release still omit session identity from the macOS approval popup, while richer requester context requires an explicit privacy and security decision.

## What This Changes

The issue requests showing the originating session and safe requester context in the macOS exec-approval popup.

## Best Possible Solution

Render a sanitized, non-empty Session row first, then add only maintainer-approved human-readable Channel, Sender, or Thread values with explicit redaction rules, focused decoding tests, and macOS visual proof.
