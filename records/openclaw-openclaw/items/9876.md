## Summary

Keep open. Current main still omits session identity from the native macOS approval dialog, the related open PR explicitly excludes this surface, and displaying richer requester metadata requires a maintainer-owned disclosure and redaction decision.

## What This Changes

Show the originating session and safe channel, sender, or request context in the macOS exec approval dialog.

## Best Possible Solution

Render a concise, redacted session identity from the existing sessionKey in the native dialog, and add channel, sender, or thread fields only through typed trusted metadata with explicit minimization rules and focused macOS prompt coverage.
