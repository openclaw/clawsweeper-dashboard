## Summary

Keep open: current main and the latest release still carry session and turn-source metadata, but the macOS native exec approval popup does not render the existing session key or richer requester context.

## What This Changes

The issue asks for the macOS native exec approval popup to show the session key and, if approved, richer requester context such as channel, sender, and reason.

## Best Possible Solution

Stage the work by adding a trimmed non-empty Session row to the macOS native prompt first, then add only maintainer-approved and redacted requester/channel fields to the Swift request model and display path.
