## Summary

## What This Changes

The issue requests adding session identity and richer requester/channel context to the macOS native exec approval popup.

## Best Possible Solution

Stage the fix: render a trimmed non-empty Session row in the macOS prompt first, then add only maintainer-approved requester/channel fields after privacy and security review.
