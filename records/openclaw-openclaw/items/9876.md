## Summary

Keep open: current main and the latest release still carry session metadata into the macOS exec approval request, but the native popup still does not render the session key or any richer requester context.

## What This Changes

The issue requests adding session and requester/channel context to the macOS exec approval popup so users can identify which session or sender triggered an approval.

## Best Possible Solution

Stage the work by adding a trimmed non-empty Session row to the native popup first, then add only maintainer-approved and redacted requester/channel fields to the Swift request model and display path.
