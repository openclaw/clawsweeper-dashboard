## Summary

Keep open: current main and the latest release still carry session identity into the macOS exec approval request but do not render it in the native popup, and the richer channel/sender/requester context needs maintainer privacy and security direction.

## What This Changes

## Best Possible Solution

Stage the fix: render a trimmed non-empty Session row in the macOS popup first, then add only maintainer-approved and redacted requester/channel fields to the native request model and display path.
