## Summary

Keep open: current main and v2026.6.11 still omit session identity from the native macOS approval popup, and the linked channel-prompt PR explicitly leaves this surface unresolved.

## What This Changes

Show the originating session and useful requester context in the macOS exec approval popup.

## Best Possible Solution

Render a sanitized Session row now, then separately introduce a typed, redacted requester-display identity if richer channel or sender context is approved.
