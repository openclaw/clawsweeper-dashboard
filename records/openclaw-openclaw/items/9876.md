## Summary

Keep open: current main and the latest release still carry session metadata, but the macOS native exec approval popup does not display the existing session key or richer requester context; https://github.com/openclaw/openclaw/pull/99485 only covers channel/chat approval prompt text and explicitly leaves this native popup out of scope.

## What This Changes

The issue asks the macOS native exec approval popup to show the originating session key and, subject to policy, richer channel/sender/requester context.

## Best Possible Solution

Stage the work by adding a trimmed non-empty Session row to the macOS native prompt first, then add only maintainer-approved and redacted requester/channel fields to the Swift request model and display path.
