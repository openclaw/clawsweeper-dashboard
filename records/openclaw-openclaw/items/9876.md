## Summary

Keep open. Current main still carries session and turn-source metadata into the approval path without presenting it in the native macOS dialog, while the related open PR explicitly limits itself to channel-delivered prompts; richer requester disclosure needs a maintainer-approved privacy boundary.

## What This Changes

Show session identity and safe requester/channel context in the macOS native exec-approval popup.

## Best Possible Solution

Display a compact, sanitized origin summary in the native popup—session plus approved channel/account/thread context—using explicit truncation and redaction rules, focused Swift coverage, and a redacted live macOS screenshot or recording.
