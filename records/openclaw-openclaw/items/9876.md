## Summary

## What This Changes

Request to display the triggering session and safe requester/channel context in the macOS native exec approval popup.

## Best Possible Solution

Stage a trimmed non-empty Session row first, then add only maintainer-approved and redacted Channel/Sender/Thread context to the Swift request model and gateway payload path.
