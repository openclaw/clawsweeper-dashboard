## Summary

## What This Changes

Add session identity and, if approved, safe requester context to the macOS native exec-approval dialog.

## Best Possible Solution

First render a non-empty existing `sessionKey` as a Session row, then add only maintainer-approved, redacted requester fields through the gateway-to-Swift contract with focused native prompt coverage.
