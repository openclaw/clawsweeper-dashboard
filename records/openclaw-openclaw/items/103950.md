## Summary

The branch materially strengthens exec approval persistence and delayed authorization, but it is not safe to merge alone: the exact head forwards an approval-time policy snapshot to the privileged macOS HMAC exec host while the Swift request decoder still drops that field, leaving the final native owner unable to reject a policy revocation that occurs after approval. The PR also has a protected `maintainer` label and only test/CI evidence, so the integrated security boundary and real socket-path behavior need maintainer review before landing.

## What This Changes

The PR adds compare-and-swap approval-store updates and canonical policy-snapshot validation for delayed exec authorization across the CLI, Gateway, node host, protocol, and direct macOS paths.

## Best Possible Solution

Decode and canonicalize the forwarded snapshot in the Swift HMAC request, carry it into the final native authorization commit, reject any mismatch before execution, and land only an exact-head integrated stack with redacted runtime proof of a delayed approved run being denied after policy revocation.
