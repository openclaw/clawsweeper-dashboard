## Summary

Keep this PR open, but do not merge it as written: the hang is source-reproducible, while the unconditional one-hour cap creates a competing absolute timeout that can terminate otherwise healthy long-running proxy streams, and the external PR supplies only mocked proof.

## What This Changes

Adds a post-header wall-clock deadline to proxied SSE agent streams and regression coverage for continuously dripping response bodies.

## Best Possible Solution

Keep the idle guard, derive any absolute deadline from the caller-owned run abort/deadline—or use an explicitly approved budget that cannot undercut configured long-running streams—and prove both dripping failure and healthy completion through a loopback SSE proxy.
