## Summary

Keep open for a Telegram-owner product decision. Current main has rich-message delivery but intentionally retains editable preview streaming and marks native draft-preview keys as retired, so the requested Bot API 10.2 Thinking block is not already implemented and should not be treated as a small transport substitution.

## What This Changes

Add an optional Telegram native rich-draft Thinking indicator during agent work, with a persistent rich final response and compatibility fallback.

## Best Possible Solution

If a Telegram owner sponsors the UX, add it only as a narrowly scoped opt-in progress-state path in the Telegram plugin, never expose reasoning/tool contents, retain the existing editable-preview default, and prove private-chat, expiration, final-delivery, unsupported-client, quote-reply, and failure cleanup behavior.
