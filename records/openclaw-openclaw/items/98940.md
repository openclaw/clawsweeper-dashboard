## Summary

## What This Changes

The PR changes the browser plugin's Playwright response-body reader from full text decoding to body()+bounded decode, adds a content-length precheck for known-large responses, and adds adjacent tests.

## Best Possible Solution

Keep the bounded decode and pre-read mitigation only if known-large responses return a clear truncation signal or explicit oversized-response error, backed by current-head real browser or terminal proof.

## Reproduction Assessment

## Solution Assessment

No. A Playwright body()+bounded-decode fallback is a reasonable mitigation, but the current pre-read guard silently drops known-large bodies and the proof no longer covers the current behavior.
