## Summary

This PR is a useful browser OOM mitigation, but it is not merge-ready: the known-large content-length path now produces blank default CLI output, current-head real behavior proof is still incomplete, and the branch adds an unrelated plugin SDK budget bump.

## What This Changes

The PR replaces the browser plugin's Playwright response-body text decoding with a `body()` plus `subarray()` decode path, adds content-length pre-reject coverage, updates tests, and raises plugin SDK surface budget thresholds.

## Best Possible Solution

Keep the bounded decode mitigation, but make known-large omissions visible in the CLI/API contract, split or justify the SDK budget bump, and refresh current-head real behavior proof before merge.
