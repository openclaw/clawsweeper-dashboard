## What This Changes

The PR changes browser `responsebody` reads from Playwright `Response.text()` to content-length pre-reject plus `Response.body().subarray()` bounded decoding, adds an omitted-body CLI notice, and extends browser responsebody tests.

## Best Possible Solution

Land the passive Playwright mitigation once maintainers accept the omitted-body contract; otherwise adjust the branch to preserve prefix semantics or hold for a streaming design that preserves page delivery.
