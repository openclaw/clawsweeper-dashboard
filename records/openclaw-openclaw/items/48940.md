## Review Findings

Full review comments:

- **[P1] Move ACP runtime state into SQLite:** `src/acp/store/store.ts:111-112`
  - body: This new durable runtime store writes `state/acp/gateway-node-runtime-store.json`, but OpenClaw-owned runtime state, checkpoints, queues, cursors, and caches now belong in SQLite with doctor/migration ownership. Keeping a new JSON sidecar here creates a competing persistence model for upgrade, backup, and recovery.
  - confidence: 0.94
- **[P1] Gate ACP node commands explicitly:** `src/gateway/node-command-policy.ts:54-58`
  - body: Adding all six ACP worker commands to `SYSTEM_COMMANDS` makes them default desktop node commands. These commands start, cancel, close, and status-check ACP execution, so they need an ACP-specific capability/authorization policy instead of inheriting the generic system command defaults.
  - confidence: 0.9
- **[P1] Propagate ACP worker event send failures:** `src/node-host/invoke.ts:424-427`
  - body: ACP worker events and terminals are sent through `sendNodeEvent`, but that helper swallows `node.event` request failures. A node can therefore settle locally while the gateway never persists the terminal, leaving replay and cancel state inconsistent.
  - confidence: 0.88
- **[P1] Do not restart active projection runners:** `src/auto-reply/reply/dispatch-acp-replay.ts:454-456`
  - body: When a projection for the same target already exists, `ensureProjection` calls `existing.start()`, and `start()` launches `run()` again. A second ensure call can start a second polling loop for the same target and race or duplicate outward delivery.
  - confidence: 0.86
- **[P1] Stop the projection runner on pre-run failures:** `src/auto-reply/reply/dispatch-acp.ts:394-396`
  - body: The durable path starts a projection runner with `waitForRunStart: true`, but if `runTurn` fails before a durable run exists, the branch rethrows without stopping that runner. It can keep polling forever for a run that will never appear.
  - confidence: 0.85
- **[P1] Await reconnect reconciliation before worker frames:** `src/gateway/server/ws-connection/message-handler.ts:1024-1038`
