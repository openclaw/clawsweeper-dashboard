Full review comments:

- **[P1] Move durable ACP state out of JSON sidecar storage:** `src/acp/store/store.ts:112`
  - body: This adds steady-state OpenClaw runtime state at `state/acp/gateway-node-runtime-store.json`, including runs, events, leases, checkpoints, targets, and idempotency. Root policy requires OpenClaw-owned runtime state, cursors, queues, and checkpoints to live in SQLite with a clear owner, so this needs to move to the shared state DB, agent DB, or an explicitly approved SQLite schema before merge.
  - confidence: 0.93
- **[P1] Propagate ACP worker event send failures:** `src/node-host/invoke.ts:426`
  - body: The ACP bridge awaits `sendNodeEvent(...)`, but that helper still swallows failed `node.event` RPCs. A node can therefore mark a worker event or terminal as delivered locally while the gateway never persists it, leaving the durable run stuck in recovery or replaying from incomplete state.
  - confidence: 0.9
- **[P1] Do not restart an active projection runner:** `src/auto-reply/reply/dispatch-acp-replay.ts:456`
  - body: When a target is already active, `ensureProjection` calls `existing.start()`, but `start()` launches `run()` every time. A second ensure for the same target can create another delivery loop over the same run, racing checkpoints and potentially duplicating outbound effects.
