  - body: `handleInvoke` wires ACP worker delivery through `sendNodeEvent`, but that helper catches and ignores `client.request("node.event", ...)` failures. A node can therefore finish a turn locally while the gateway never records the worker event or terminal, leaving durable ACP state stuck or inconsistent instead of putting the node session into explicit recovery/error state.
  - confidence: 0.94
- **[P1] Reuse the active projection runner:** `src/auto-reply/reply/dispatch-acp-replay.ts:456`
  - body: When a projection for the same target is already active, `ensureProjection` calls `existing.start()`, and `start()` launches `run()` every time. A duplicate ensure can therefore create multiple polling/delivery loops for one target, racing checkpoint updates and potentially duplicating outbound sends.
  - confidence: 0.95
- **[P2] Stop projections when turn start creates no run:** `src/auto-reply/reply/dispatch-acp.ts:396`
  - body: The durable ACP path starts a projection with `waitForRunStart: true`, then rethrows `turnError` when no durable run exists. Because the runner is not stopped on that branch, it can keep polling forever for a run that will never be created after an early `runTurn` failure.
  - confidence: 0.9
- **[P1] Serialize reconnect reconciliation before worker events:** `src/gateway/server/ws-connection/message-handler.ts:1024`
  - body: Node reconnect handling starts `handleNodeConnected(...)` fire-and-forget, so a worker event or terminal can arrive while the lease is still `suspect` and be rejected as missing an active lease. That race can strand a run in recovery even though the same node completed it.
  - confidence: 0.91
- **[P1] Validate run reuse by session and request:** `src/acp/store/store.ts:534`
  - body: `startRun` returns any existing `store.runs[runId]` as idempotent without verifying the same `sessionKey` and `requestId`. If two sessions reuse a provider/message-derived run id, the second session aliases the first run record and later lease/session validation can corrupt delivery bookkeeping or wedge the turn.
  - confidence: 0.95
