## Summary

Keep open. Current main and the latest release still accept OGG/Opus as Gemini multimodal memory audio, preserve the detected audio MIME type, and send it unchanged to Gemini, while the current Gemini embeddings docs list audio support as MP3/WAV only.

## What This Changes

The issue asks OpenClaw to stop Gemini multimodal memory indexing from failing on OGG/Opus audio files discovered through `memorySearch.extraPaths`.

## Best Possible Solution

Make the Gemini multimodal memory path provider-aware: either reject or skip unsupported audio with clear diagnostics and aligned docs, or approve and test an explicit transcode path if OGG/Opus should remain supported.
