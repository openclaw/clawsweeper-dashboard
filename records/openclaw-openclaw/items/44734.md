## Summary

Keep open: current main and the latest stable release still accept OGG/Opus as multimodal memory audio and pass the detected MIME type unchanged into Gemini, while current official Gemini Embeddings docs list audio support as MP3/WAV only. This is still necessary, but the repair needs a maintainer choice between narrowing the public Gemini audio contract and owning transcoding.

## What This Changes

The issue requests fixing Gemini-backed multimodal memory indexing so OGG/Opus audio files no longer cause Gemini embedding 400 errors.

## Best Possible Solution

Define the Gemini-specific audio contract, then either enforce MP3/WAV-only with clear non-fatal diagnostics and docs or add a consciously owned, tested transcode path before the Gemini call.
