## Summary

Keep open. Current main and the latest release still advertise OGG/Opus as Gemini multimodal memory audio formats, preserve the detected audio MIME type, and pass it unchanged to Gemini inlineData, while the official Gemini embeddings page currently lists audio embedding support as MP3/WAV only.

## What This Changes

The issue reports that Gemini multimodal memory indexing accepts OGG/Opus audio from memorySearch.extraPaths but Gemini rejects those raw audio formats during embedding.

## Best Possible Solution

Make Gemini multimodal memory provider-aware: align docs and runtime validation with Gemini's supported audio formats now, or explicitly approve a tested OGG/Opus-to-MP3/WAV transcode path if those formats should remain advertised.
