## Best Possible Solution

Settle the memory lifecycle and owner boundary first, then add one narrow active-memory operator facade with docs, scenario proof, and plugin/API compatibility tests; keep backend-specific implementations as plugin or ClawHub options unless they reveal a missing SDK seam.
