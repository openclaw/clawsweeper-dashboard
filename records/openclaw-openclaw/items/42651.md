## Summary

Keep open: current main has partial memory search, promotion, REM backfill, Memory Wiki, and LanceDB store/recall/forget surfaces, but it still lacks the requested unified remember/recall/review/edit/forget operator facade backed by settled ingestion, provenance, and lifecycle semantics.

## What This Changes

Expose a minimal memory operator interface with ingestion helpers, remember/recall/review/edit/forget commands, provenance, and match explanations.

## Best Possible Solution

Settle the memory lifecycle and ownership contract first, then add one narrow default-plugin operator facade with docs and tests; keep backend-specific or Engram-style implementations as plugin/ClawHub options unless they expose a missing SDK seam.
