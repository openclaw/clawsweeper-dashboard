## What This Changes

The PR hides terminal and gateway-browser docks while Settings owns the Control UI viewport, then restores their previously saved open state after the operator leaves Settings.

## System Context

The Control UI shell decides when Settings takes over the viewport and renders the terminal and gateway-browser dock panels. Each panel delegates open state and layout reservations to the shared dock layout controller, which now temporarily suppresses automatic restoration during that takeover.
