## Summary

Keep open. Current main and the latest release still lack the exec-side guard for raw global OpenClaw package-manager self-updates, and this maintainer-protected issue is already paired with an open conflicting candidate fix.

## What This Changes

The issue asks OpenClaw to force explicit agent self-update requests through `update.run`/`openclaw update`, or otherwise guarantee a gateway restart after any raw package-manager upgrade.

## Best Possible Solution

Land or replace the linked fix with a shared exec-control guard that blocks raw global OpenClaw package-manager upgrades before process launch, keeps `update.run`/`openclaw update` as the supported self-update path, and includes focused parser/tool tests plus real behavior proof.
