## What This Changes

Adds compact live Swarm progress cards to Android, iOS, and macOS chat, using gateway metadata and child-session events to show worker states, phases, and narrator updates above the composer.

## System Context

The gateway exposes whether Swarm is enabled for an agent and provides child-session data; native chat clients then project active workers into temporary progress groups. Those groups are rendered between the transcript and composer and cleared when the active route or focused parent session changes.
