Full review comments:

- **[P2] Use a full page size when scanning replies:** `extensions/msteams/src/graph-thread.ts:139`
  - body: Line 139 uses the requested reply window as the Graph `$top` page size. For `maxReplies=1` or `30`, Graph will return 1/30-item pages, so a long oldest-first thread can still hit the 50-page cap before reaching the newest replies; the new tests miss this by mocking 50-item pages even when the request asks for fewer. Request full pages for the scan and use the clamped reply count only when slicing the final window.
