## Summary

Keep open: current main and v2026.6.11 still expose only a single-select message presentation/message-tool contract; adjacent Telegram OC_MULTI handling, Discord components, Slack modal work, and the closed dialog PR do not provide the requested portable selected-values callback.

## Best Possible Solution

Design one additive portable batch-selection presentation/message-tool contract with typed selected-value aggregation, SDK/docs updates, and Slack, Discord, Telegram, and fallback renderer/callback coverage.
