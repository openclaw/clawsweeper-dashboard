## Summary

Keep open: current main and the latest release still lack the requested portable message-tool multi-select contract with min/max selection semantics and one selected-values callback across channels. The issue remains useful, but it needs maintainer API/product direction before implementation.

## What This Changes

Add a cross-platform multi-select capability to the message tool so agents can collect several visually selected options in one interaction.

## Best Possible Solution

Design one additive portable batch-selection presentation/message-tool contract with typed selected-value aggregation, explicit channel limits and fallback text, SDK/docs updates, and channel adapter coverage for Slack, Discord, Telegram, and non-native fallbacks.
