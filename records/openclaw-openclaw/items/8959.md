## Summary

Current main and v2026.6.11 still expose only scalar portable message-presentation selects. Native channel capabilities and the closed dialog proposal do not provide the requested cross-platform, one-submit selected-values contract, so the feature remains necessary but needs a maintainer API and product decision.

## What This Changes

Add a cross-platform message-tool multi-select action that submits all selected values in one interaction and triggers one agent turn.

## Best Possible Solution

Define one additive typed batch-selection presentation action with explicit limits and a structured selected-values array, then add capability-based native rendering for approved channels and a numbered-text fallback without introducing a separate dialog subsystem.
