## Summary

Keep open: current main and v2026.6.11 still expose only a single-select portable message presentation contract, while related dialog, Slack modal, Telegram managed-select, poll, and native channel primitives do not provide the requested cross-platform message-tool batch-select callback.

## What This Changes

The issue requests an additive cross-platform multi-select component for the message tool so users can visually choose multiple options and submit one structured callback.

## Best Possible Solution

Design one additive portable batch-selection contract in the shared message presentation/message-tool surface, export it through the plugin SDK, document it publicly, and implement channel render/callback handling plus fallback text behavior together.
