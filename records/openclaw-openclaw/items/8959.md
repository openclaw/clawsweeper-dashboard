Keep open: current main still lacks the requested portable message-tool batch-select contract; related dialog, hook, Telegram packet, Slack modal, and Claude picker work overlap but do not provide one cross-channel selected-values callback.

## What This Changes

Requested addition of a cross-platform multi-select capability to the message tool so users can select multiple options and submit them in one callback.

## Best Possible Solution

Design one additive portable batch-selection contract in message presentation/message tool, export and document it through the plugin SDK, and implement channel-specific rendering plus callback aggregation with fallback text semantics.
