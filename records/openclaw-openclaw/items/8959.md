## What This Changes

Add a portable message-tool multi-select that lets users choose several options and submit the selected values in one callback rather than triggering an agent turn for each toggle.

## Best Possible Solution

Define one additive portable batch-selection presentation contract with structured selected-values callbacks and explicit fallback semantics, then implement and document an initial supported channel matrix without coupling it to a separate dialog/session subsystem.
