## Summary

Keep open. The supplied July 18 current-main review found that the shared message presentation contract still has only scalar select semantics, so the requested one-submit cross-platform multi-select remains a product and public API decision rather than a completed capability.

## What This Changes

Add a portable message-tool multi-select interaction that returns several selected values in one callback instead of requiring an agent turn for each toggle.

## Best Possible Solution

Define an additive typed batch-selection presentation action with structured selected-values callbacks, document its support and fallback matrix, and let each channel plugin render native controls only where that contract can be preserved.
