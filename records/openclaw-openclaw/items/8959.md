## What This Changes

The issue requests a cross-platform message-tool multi-select component that lets users batch-select multiple options and submit one structured callback to the agent.

## Best Possible Solution

Design one additive portable batch-select presentation/message-tool contract with typed selected-value aggregation, channel limits, fallback text, SDK/docs updates, and Slack, Discord, Telegram, and fallback adapter coverage.

## Reproduction Assessment

Not applicable: this is a new-capability request, not a broken established behavior. Current source, docs, release-tag inspection, and related-item review give high confidence that the requested portable batch-select contract is absent.

## Solution Assessment

Unclear on the exact API shape, but the best owner boundary is the shared message presentation/message tool plus plugin SDK contract. A channel-only renderer, a poll workaround, or the closed dialog branch would not satisfy the cross-platform selected-values callback requirement.
