## Summary

Keep open: current main and v2026.6.11 still lack a portable message-tool multi-select contract, and the adjacent Slack, Discord, Telegram poll, and closed dialog-tool paths do not satisfy the requested single batch-selection callback across channels.

## What This Changes

Request to add a cross-platform multi-select capability to the message tool so agents can present visual batch choices and receive selected values in one callback.

## Best Possible Solution

Design one additive portable batch-select presentation/message-tool contract with typed selected-value aggregation, SDK/docs updates, channel limits, fallback text, and channel adapter coverage.
