## Summary

Current main and v2026.6.11 still expose only scalar portable selects; native multi-value pieces in Discord and Slack do not provide the requested shared one-callback result, and Telegram still maps portable options to separate buttons. A prior human review explicitly kept the issue open, so the remaining work needs a maintainer decision on the public presentation and fallback contract rather than cleanup closure.

## What This Changes

Add a portable message-tool multi-select that batches selected values into one callback across supported channels with a documented fallback.

## Best Possible Solution

Add one typed batch-select extension to the existing portable presentation contract, with array-valued callback semantics, native channel mappings, deterministic fallback, public SDK exports, documentation, and cross-channel compatibility coverage.
