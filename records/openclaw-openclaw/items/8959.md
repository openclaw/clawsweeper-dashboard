## Summary

Keep open: current main and the latest release still lack the requested portable message-tool multi-select contract; existing CLI, poll, Discord, Slack, Telegram, and hook primitives are adjacent but do not provide one shared selected-values callback across channels.

## What This Changes

The issue requests a portable multi-select message component so agents can present many choices and receive all selected values in one callback.

## Best Possible Solution

Design one additive portable batch-selection presentation/message-tool contract with typed selected-value aggregation, explicit channel limits and fallback text, SDK/docs updates, and channel adapter coverage for Slack, Discord, Telegram, and non-native fallbacks.
