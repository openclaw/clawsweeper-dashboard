## Summary

Current main and v2026.6.11 still provide only scalar portable selects; channel-native multi-value capabilities do not supply the requested shared one-callback contract. Keep this open for a maintainer product/API decision because the durable fix changes the public message presentation and plugin SDK contract across unequal channel capabilities.

## What This Changes

Add a portable cross-platform multi-select message interaction that batches selected values into one callback.

## Best Possible Solution

Add a minimal additive typed batch-selection block and structured selected-values result in the portable presentation/SDK contract, let channel adapters own native encoding and explicit button/text degradation, and keep workflow state or form orchestration in plugins.

## Solution Assessment
