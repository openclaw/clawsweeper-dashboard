## Summary

Keep open: current main and v2026.6.11 still expose a single-select shared message-presentation/message-tool contract, while adjacent Telegram, Slack, Discord, dialog, and plugin-hook primitives do not provide the requested portable batch-select callback.

## What This Changes

Add a portable message-tool multiselect/select-menu capability so users can choose multiple options visually and submit one aggregated selection back to the agent.

## Best Possible Solution

Design one additive portable batch-select presentation/message-tool contract with typed selected-value aggregation, channel limits, fallback text, SDK/docs updates, and channel adapter coverage.
