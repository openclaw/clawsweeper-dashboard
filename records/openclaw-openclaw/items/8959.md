## Summary

Keep open: current main and the latest release still expose only a portable single-select message presentation/message-tool contract. Slack, Discord, and Telegram have adjacent native selection primitives, but they do not add the requested cross-platform `multiSelect`/`selectMenu` schema, SDK type, docs, or one selected-values callback contract.

## What This Changes

Request a cross-platform multi-select capability in the message tool so users can batch-select options visually and submit all selections in one agent callback.

## Best Possible Solution

Design one additive portable batch-selection presentation/message-tool contract with typed selected-value aggregation, explicit channel limits and fallback text, SDK/docs updates, and channel adapter coverage for Slack, Discord, Telegram, and non-native fallbacks.
