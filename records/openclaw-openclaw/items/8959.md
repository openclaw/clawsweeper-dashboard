## Summary

Current main and v2026.6.11 still lack the requested portable batch-selection contract: shared presentation and message-tool schemas remain scalar, while native multi-value handling exists only in adjacent channel-specific paths. Keep this issue open for a maintainer product/API decision rather than treating the closed dialog proposal or Slack modal request as a replacement.

## What This Changes

Add a portable message-tool multi-select that lets users submit several visual choices in one structured callback across supported channels.

## Best Possible Solution

Define an additive portable batch-select block with min/max cardinality and a typed selected-values array, while channel plugins own native rendering and documented numbered-text or equivalent fallback behavior.
