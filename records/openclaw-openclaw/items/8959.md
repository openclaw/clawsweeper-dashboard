Keep open: current main and latest release still lack the requested portable message-tool multi-select contract, and the related dialog PR is closed unmerged while polls, wizard multiselects, and the merged before_agent_reply hook do not provide one cross-channel selected-values callback.

Add a cross-platform multi-select capability to the message tool so users can choose multiple options visually and submit one aggregated selection callback.

## Best Possible Solution

Design one additive portable batch-selection contract in message presentation/message tool, export and document it through the plugin SDK, and implement channel-specific rendering plus callback aggregation with fallback text semantics.
