## Summary

Keep open. Current main and v2026.6.11 provide only scalar portable selects; native Discord and Slack multi-value capabilities do not supply the requested shared one-callback contract, and the related dialog PR closed unmerged.

## What This Changes

Add a portable message-tool multi-select interaction that returns several selected values in one callback.

## Best Possible Solution

Extend the shipped portable presentation API additively with a batch-select block and structured selected-values result, then implement explicit native rendering or deterministic text degradation in each channel plugin.
