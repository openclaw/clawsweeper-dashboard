## Summary

Keep open. ## What This Changes

Request an opt-in provider-profile pool routing layer for multi-account OAuth/API-key workloads, including routing strategies, cooldown/failure awareness, per-profile concurrency, and observable pool state.

## Best Possible Solution

Keep this as the umbrella design issue until maintainers approve one opt-in provider-pool contract that covers config, persisted state, observability, upgrade behavior, and how narrower rate-limit/key-pool issues plug into it.
