## Summary

Keep this PR open for an explicit gateway security/product decision. ## What This Changes

Adds the hot-reloadable `gateway.controlPlaneWritesPerMinute` config field, preserving the three-per-minute default while making the shared per-identity control-plane write budget configurable from 1 to 600.

## Best Possible Solution

Retain the default of three and the per-identity bucket protections, then ship the capped global opt-in only after a gateway security owner explicitly accepts the hot, remotely configurable boundary and the rebased head preserves the documented warnings and coverage.
