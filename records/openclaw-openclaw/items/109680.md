## Summary

This is a valid P1 authentication fix, but the latest head still exposes an internal credential sanitizer through the public Mantle plugin barrel and does not provide direct after-fix real-runtime proof for the newly covered Mantle IAM-token path.

## What This Changes

Normalizes whitespace-only Amazon Bedrock bearer, static, and session credential environment values before standard Bedrock and Mantle clients resolve AWS authentication, with expanded regression coverage.

## Best Possible Solution

Keep credential normalization private to the owning provider implementations, test it through production entry points rather than a new barrel export, and demonstrate redacted after-fix Mantle IAM-token generation falling through from blank environment credentials to a valid default-chain source.
