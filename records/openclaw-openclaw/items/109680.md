## Summary

Keep this PR open: the latest head resolves the prior Mantle IAM-path finding, but it unnecessarily promotes a process-global credential sanitizer through the public Mantle plugin barrel; remove that export and add after-fix Mantle runtime proof before merge.

## What This Changes

Normalizes whitespace-only Amazon Bedrock bearer, static, and session credential environment values before Converse, discovery, embedding, inference-profile, and Mantle IAM-token authentication resolves credentials.

## Best Possible Solution

Keep blank-credential normalization private to each owning Bedrock provider, run it immediately before SDK client or IAM-token credential resolution, preserve every nonblank credential unchanged, and cover each production path with regression tests plus redacted Mantle runtime output.
