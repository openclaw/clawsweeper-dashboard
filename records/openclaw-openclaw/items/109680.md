## Summary

The earlier blank-static-key finding is only partially repaired: streaming now sanitizes whitespace credentials, but Bedrock discovery and embeddings still construct AWS clients after cache refresh without sanitizing those values, leaving two supported paths broken.

## What This Changes

The PR trims Bedrock bearer tokens, treats whitespace credential variables as absent during shared-config refresh, and deletes blank static AWS credential variables before the streaming client resolves authentication.

## Best Possible Solution

Create one shared Bedrock pre-client credential preparation path that sanitizes blank static keys and refreshes shared configuration, invoke it before streaming, discovery, and embedding clients resolve credentials, and prove one real default-chain fallback.
