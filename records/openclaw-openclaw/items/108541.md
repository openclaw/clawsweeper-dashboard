## Summary

## What This Changes

Prevent a rejected claude-cli cron agent turn with a tool allowlist from causing the next inbound message to rotate the target session and displace its active transcript.

## Best Possible Solution

Validate unsupported claude-cli tool restrictions before mutating target-session or CLI-binding state, and guarantee failure cleanup leaves the session id, active transcript, delivery route, and runtime binding unchanged; add regression coverage for both the failed cron turn and the next inbound message.
