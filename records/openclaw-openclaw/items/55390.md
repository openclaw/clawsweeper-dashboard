Full review comments:

- **[P1] Preserve include roots during startup schema stamping:** `src/config/local-json-schema.ts:98`
  - body: `maintainLocalConfigJsonSchemaArtifacts` calls `writeConfigFile` with the resolved snapshot after adding a default `$schema`. For a config whose root uses `$include`, that write path can persist the resolved included content back into `openclaw.json` just because a read-style CLI startup saw a missing `$schema`, destroying the user's modular root file. Limit stamping to safe owned writes or preserve the authored root/include structure.
  - confidence: 0.88

That means `openclaw config unset '$schema'` cannot persist while the new feature is enabled, so a user preference is silently overwritten by the default-on behavior.
  - confidence: 0.86
