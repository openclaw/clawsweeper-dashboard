Full review comments:

- **[P1] Avoid startup rewrites of resolved include configs:** `src/config/local-json-schema.ts:98`
  - body: `maintainLocalConfigJsonSchemaArtifacts` calls `writeConfigFile(nextConfig)` just because `$schema` is missing. On this branch the write path builds from the resolved snapshot, so a normal CLI startup can rewrite the root config and flatten or reformat `$include`-backed authoring just to add editor schema metadata. Keep startup maintenance sidecar-only, or limit root `$schema` stamping to an existing OpenClaw-owned config write that already preserves includes.
  - confidence: 0.86
- **[P1] Honor explicit root schema removals:** `src/config/io.ts:1775`
  - body: The write path applies `unsetPaths` and then immediately calls `withDefaultLocalConfigSchemaRef`, so `openclaw config unset '$schema'` or another explicit removal will be persisted with `$schema` added back whenever maintenance is enabled. That makes the default impossible to remove and overrides user intent; skip the default when the root `$schema` path is explicitly unset.
  - confidence: 0.9
