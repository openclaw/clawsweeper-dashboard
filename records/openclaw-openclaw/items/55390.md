## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Avoid startup writes that flatten include-backed configs:** `src/config/local-json-schema.ts:98`
  - body: `maintainLocalConfigJsonSchemaArtifacts()` calls `writeConfigFile()` just to add a missing `$schema`. On this branch, `writeConfigFile()` merge-patches against the resolved config shape, so a root using `$include` can be rewritten from resolved contents during read-style commands like `status`, dropping the user's include structure and comments. Refresh the sidecar without rewriting the root, or only stamp `$schema` during an already-owned config write.
  - confidence: 0.9
- **[P2] Respect explicit `$schema` removal:** `src/config/io.ts:1775`
  - body: `unsetPaths` are applied above, but this line immediately defaults `$schema` back whenever schema maintenance is enabled. That means `openclaw config unset '$schema'` cannot remove the field unless the user also discovers and sets the new opt-out, so the writer overrides an explicit user edit.
  - confidence: 0.83
