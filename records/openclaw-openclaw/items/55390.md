Full review comments:

- **[P1] Avoid rewriting include-backed configs on startup:** `src/config/local-json-schema.ts:98`
  - body: `snapshot.config` is the normalized config after `$include` resolution, so this startup path can persist a resolved object just to add `$schema`. On include-backed configs, the branch writer merge-patches against `snapshot.resolved` and serializes the full result, which can replace the user's root `$include` structure during a normal CLI run. Refresh only the sidecar, or wait for an include-aware OpenClaw-owned config write before stamping the root.
  - confidence: 0.88
- **[P1] Honor explicit `$schema` unsets:** `src/config/io.ts:1775`
  - body: This default runs after `options.unsetPaths` have already removed requested fields, so `openclaw config unset '$schema'` can immediately write `$schema` back into the file. Existing unset calls pass `unsetPaths` for non-array fields; skip the default when `$schema` is explicitly unset or require the user to opt back in separately.
  - confidence: 0.86
