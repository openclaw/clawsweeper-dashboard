- **[P1] Avoid startup writes that flatten include-backed configs:** `src/config/local-json-schema.ts:98`
  - body: `maintainLocalConfigJsonSchemaArtifacts` calls `writeConfigFile` with the full runtime snapshot when `$schema` is missing. On this branch, `writeConfigFile` derives a patch from `snapshot.config` and persists it against the include-expanded `snapshot.resolved`, so a read-style startup path can rewrite the root config and lose authored `$include` structure. Limit schema stamping to root config writes already being committed, or preserve include ownership before writing.
  - confidence: 0.87
- **[P1] Respect explicit $schema unsets:** `src/config/io.ts:1775`

That means `openclaw config unset '$schema'` removes the key and then adds `openclaw_schema.json` back, overwriting an explicit user config change.
  - confidence: 0.9
