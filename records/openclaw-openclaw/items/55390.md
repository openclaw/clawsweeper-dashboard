Full review comments:

- **[P1] Avoid startup rewrites through the resolved config:** `src/config/local-json-schema.ts:98`
  - body: `maintainLocalConfigJsonSchemaArtifacts` adds `$schema` and then calls `writeConfigFile` during startup. On this branch, that writer computes the persisted payload from `snapshot.resolved`, so an include-backed config can be rewritten from the resolved shape just because a read-style CLI command ran, flattening `$include` structure and comments. Refresh the schema sidecar without a root rewrite, or rebase onto the current include-preserving config mutation path before stamping `$schema`.
  - confidence: 0.89
- **[P2] Respect explicit `$schema` removals:** `src/config/io.ts:1775`
  - body: `withDefaultLocalConfigSchemaRef` runs after `unsetPaths` are applied, so a writer that explicitly unsets `$schema` will immediately persist the default schema ref again. Once this PR makes `$schema` auto-managed, explicit removal should remain honored unless the user opts back in through config.
  - confidence: 0.75
