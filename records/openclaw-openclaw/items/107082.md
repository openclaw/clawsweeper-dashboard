## What This Changes

Add a supported production dreaming mode or public controls that permit reflection while preventing durable startup-memory writes.

## Best Possible Solution

Expose one stable promotion policy at the memory-core owner boundary—such as automatic versus report-only—reuse the existing phase pipeline, fail before every durable sink in report-only mode, and return an auditable result listing phases, artifacts, attempted writes, performed writes, and failures.
