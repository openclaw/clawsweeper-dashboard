  - body: The `afterSeq` path still reads exactly `limit` raw entries before running `dropPreSessionStartAnnouncePairs`. If the page boundary splits those rows, no page emits the user-visible sent text; this was already visible at the prior reviewed head, so this is a late catch.
  - late: true
  - confidence: 0.88

  - confidence: 0.9
