## Summary

Keep open: the PR fixes a real temporal-decay gap for session-reset archives, but it is not merge-ready because the new private reset-only parser diverges from the existing session archive contract and leaves accepted sibling archive forms on the old skipped-decay path.

## What This Changes

The PR changes memory-core temporal decay to parse timestamps from `.jsonl.reset.<timestamp>` session archive filenames and adds two regression tests.

## Best Possible Solution

Route temporal decay through the shared session archive timestamp parser via the memory-host facade, cover reset and deleted archive forms, preserve live `.jsonl` mtime fallback, and refresh the branch.

## Reproduction Assessment

Yes, at source level. A logical `sessions/main/*.jsonl.reset.*` hit with no matching file under `workspaceDir` follows current main into `fs.stat` failure and skipped decay.

## Solution Assessment

No. Parsing archive timestamps before `fs.stat` is the right layer, but this implementation duplicates the existing archive contract and misses sibling reset/deleted/no-millisecond forms.
