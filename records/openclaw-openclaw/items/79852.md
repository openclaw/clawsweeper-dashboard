## Summary

Keep open: the reported temporal-decay bug still exists on current main and the latest release, but this PR is not merge-ready because it adds a private reset-only archive parser instead of reusing the shared reset/deleted archive timestamp contract.

## What This Changes

The PR adds session-reset archive filename parsing to memory-core temporal decay and two regression tests for reset archive ranking.

## Best Possible Solution

Expose or route the shared session archive timestamp parser through the memory-host facade, use it before filesystem fallback for accepted usage-counted archive forms, preserve live `.jsonl` mtime fallback, and refresh the branch.

## Reproduction Assessment

Yes at source level: a logical `sessions/main/*.jsonl.reset.*` search hit with no matching file under `workspaceDir` reaches current main's `fs.stat` fallback and skips decay when the stat fails.

## Solution Assessment

No. Parsing archive timestamps before `fs.stat` is the right layer, but the PR duplicates the archive contract and misses sibling accepted archive forms that current main already recognizes.
