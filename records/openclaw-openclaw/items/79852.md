## What This Changes

## Best Possible Solution

Route temporal decay through the shared session archive timestamp parser via the memory-host facade, cover reset/deleted and optional-millisecond/no-millisecond archive forms, preserve live `.jsonl` mtime fallback, and refresh the branch.

## Solution Assessment
