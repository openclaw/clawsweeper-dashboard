## Summary

Keep this PR open, but it is not merge-ready: the bug is real and the proof is useful, yet the patch adds a private reset-only timestamp parser instead of using the shared session archive contract that already covers reset/deleted archives and optional milliseconds.

## What This Changes

The PR parses session-reset archive timestamps in memory-core temporal decay and adds regression tests so archived session hits can decay without workspace-relative `fs.stat`.

## Best Possible Solution

Route temporal decay through the shared session archive timestamp parser via the memory-host facade, cover reset and deleted archive forms, keep live `.jsonl` mtime fallback, and refresh the branch before merge.

## Reproduction Assessment

Yes, at source level. A logical `sessions/main/*.jsonl.reset.*` hit with no matching file under `workspaceDir` follows current main into `fs.stat` failure and skipped decay.

## Solution Assessment

No. Parsing archive timestamps before `fs.stat` is the right layer, but this implementation duplicates an existing archive contract and misses sibling accepted archive forms.
