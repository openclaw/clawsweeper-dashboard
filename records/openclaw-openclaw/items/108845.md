## What This Changes

The PR changes ignore-file loading to suppress ENOENT while rethrowing other filesystem read errors.

## Best Possible Solution

Read each ignore file directly, suppress only verified ENOENT failures, and handle other failures at an explicit scanner boundary that prevents unsafe scanning while returning contextual diagnostics instead of an accidental process-level exception.
