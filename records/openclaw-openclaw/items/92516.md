## Label Justifications

- `impact:security`: The requested fix changes how OpenClaw proves an external plugin may access host-managed persistent keyed state and channel ingress APIs.
- `impact:crash-loop`: The reported Microsoft Teams channel exits after the trusted-state gate denies access and then enters automatic restart attempts.

## Summary

Keep open: current main still requires bundled origin or trusted official-install provenance before a channel plugin can use keyed state, and the remaining ask is the broader immutable-container deployment contract rather than the narrower official ClawHub npmSpec fix.

## What This Changes

The issue asks for a supported, provenance-preserving way to run externalized channel plugins such as Microsoft Teams in self-hosted containers when the runtime state directory is mounted separately from image-baked plugin files.

## Best Possible Solution

Keep the fail-closed keyed-state gate and design a maintainer-approved official plugin provenance path for immutable containers, such as a separate trusted install/provenance root or image packaging contract that survives mounted runtime config/state.
