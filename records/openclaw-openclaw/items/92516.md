## Summary

Keep open: current main and v2026.6.11 still require bundled origin or trusted official-install provenance for keyed plugin state, and no current code, docs, release, or related PR provides the requested immutable-container path where official plugin package/provenance survive a mounted runtime state directory.

## What This Changes

The issue asks for a provenance-preserving way for self-hosted immutable/container deployments to run externalized official channel plugins that need trusted keyed-store access.

## Best Possible Solution

Keep the fail-closed trust gate and design a supported portable official-plugin install/provenance path for immutable images whose plugin package and install record survive a mounted runtime state directory.
