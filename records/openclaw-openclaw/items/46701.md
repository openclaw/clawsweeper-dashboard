## Summary

Keep open: current main and v2026.6.11 still silently skip Telegram group messages from non-allowlisted senders, and the related open issues cover owner/audit visibility or broader group pairing rather than this exact sender-facing onboarding reply. ## What This Changes

Request that Telegram group senders outside `groupAllowFrom` receive an onboarding reply with their Telegram user ID and admin-contact instructions instead of being silently dropped.

## Best Possible Solution

Define a Telegram-owned opt-in unauthorized-group-sender notice that is topic-aware, rate-limited, privacy-documented, configurable for admin-contact wording, and keeps silent fail-closed behavior as the default unless maintainers choose otherwise.
