## Summary

Keep open: current main and v2026.6.11 still silently deny non-allowlisted Telegram group senders, while the requested sender-facing reply remains a product/security-sensitive change that needs maintainer direction before implementation.

## What This Changes

Request an opt-in Telegram group denial reply that tells unauthorized senders how to contact an admin and includes their Telegram user ID.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-safe delivery, per-sender cooldown, admin-contact configuration, privacy-documented raw ID handling, and silent fail-closed behavior as the default unless maintainers choose otherwise.
