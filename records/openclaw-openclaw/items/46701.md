## Summary

Keep open: current main and the latest release still deny non-allowlisted Telegram group senders without the requested onboarding reply, and changing that silent authorization boundary needs maintainer product/security direction first.

## What This Changes

Request to add a Telegram group auto-reply that tells non-allowlisted senders how to contact an admin and includes their Telegram user ID.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-safe delivery, per-sender cooldown, configurable admin-contact wording, documented raw-ID handling, and silent denial as the default unless maintainers choose otherwise.
