## Summary

Keep open: current main and the latest release still silently deny non-allowlisted Telegram group senders, and adding a visible denial reply needs product/security decisions around opt-in behavior, rate limiting, raw ID disclosure, and admin-contact wording.

## What This Changes

Request an auto-reply for Telegram group senders blocked by groupAllowFrom/groupPolicy that explains authorization and shows the sender's Telegram user ID for admin approval.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-aware delivery, per-sender cooldown, configurable admin-contact text, documented raw-ID handling, and default silent fail-closed behavior unless maintainers choose otherwise.
