## Summary

Keep open: current main and the latest release still block non-allowlisted Telegram group senders without the requested onboarding reply, and changing that denial into visible group output needs maintainer product/security direction.

## What This Changes

Request to add a Telegram group auto-reply for senders blocked by `groupAllowFrom`/`groupPolicy`, including admin-contact instructions and the sender's Telegram user ID.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-safe delivery, per-sender cooldown, configurable admin-contact text, documented raw-ID handling, and silent denial as the default unless maintainers choose otherwise.
