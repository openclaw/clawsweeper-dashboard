## Summary

Keep open: current main and the latest release still silently drop or skip ordinary Telegram group messages from non-allowlisted senders, while adding a sender-facing denial reply needs product/security direction on opt-in defaults, rate limiting, admin-contact wording, and Telegram user ID disclosure.

## What This Changes

The issue requests a Telegram group denial reply that tells non-allowlisted senders how to contact an admin and includes their Telegram user ID.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-safe delivery, per-sender cooldown, configurable admin-contact wording, documented raw-ID behavior, and silent denial as the default unless maintainers choose otherwise.
