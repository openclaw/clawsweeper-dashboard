## Summary

Keep open: current main and v2026.6.11 still silently block non-allowlisted Telegram group senders, and adding a sender-facing denial reply needs maintainer product/security decisions around opt-in behavior, cooldowns, raw ID disclosure, topic delivery, and admin-contact wording.

## What This Changes

Request an automatic Telegram group reply that tells non-allowlisted senders how to contact an admin and includes their Telegram user ID.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-aware delivery, per-sender cooldown, configurable admin-contact text, documented raw-ID handling, and default silent fail-closed behavior.
