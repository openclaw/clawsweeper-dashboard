## Summary

Keep open: current main and the latest release still silently block non-allowlisted Telegram group senders, and adding a sender-facing denial reply needs maintainer product/security direction before implementation.

## What This Changes

The issue requests a Telegram group onboarding reply for non-allowlisted senders that includes their Telegram user ID and admin contact guidance.

## Best Possible Solution

Define a Telegram-owned, opt-in denied-sender notice with topic-safe delivery, per-sender cooldown, configurable admin-contact wording, documented raw-ID behavior, and silent denial as the default unless maintainers choose otherwise.
