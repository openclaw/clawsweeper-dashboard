## What This Changes

## Best Possible Solution

Define a Telegram-owned opt-in unauthorized-group-sender notice that is topic-aware, rate-limited, privacy-documented, configurable for admin-contact wording, and preserves silent fail-closed behavior unless maintainers choose otherwise.
