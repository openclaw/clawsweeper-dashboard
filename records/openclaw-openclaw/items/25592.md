## Summary

Keep open: current main has partial suppression for commentary/pre-tool and some cron announce paths, but the generic source-reply defaults and tests still preserve automatic delivery of ordinary unphased or post-tool assistant text, and the linked fix PRs are not merged.

## What This Changes

The issue requests suppressing assistant text produced between tool calls so only final or explicitly sent user-facing content reaches messaging channels.

## Best Possible Solution

Adopt a generic final-only or message-tool-only channel delivery policy with a documented compatibility plan and regression coverage across subscriber, payload, and cron announce paths.
