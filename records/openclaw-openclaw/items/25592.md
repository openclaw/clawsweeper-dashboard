- `P1`: The bug affects real messaging-channel workflows and production customer conversations, but it does not make the core runtime completely unusable.

## Summary

Keep open: current main has partial commentary-phase and message-tool-only safeguards, but normal source replies still default to automatic delivery and source tests still preserve pre-tool text flushing, so the central channel-leak bug remains unresolved.

## What This Changes

The issue requests that internal or pre-final assistant text between tool calls stop being delivered as visible messaging-channel output, leaving only intentional final or message-tool sends visible.

## Best Possible Solution

Keep #25592 canonical and land one maintainer-approved generic channel/source delivery rule that blocks pre- and inter-tool text from leaving the agent while preserving deliberate final-reply compatibility through explicit policy and regression proof.
