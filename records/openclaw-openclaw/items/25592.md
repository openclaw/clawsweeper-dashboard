## Summary

Keep open: current main has useful commentary and message-tool-only guards, but automatic direct/source delivery, unphased text buffering, and cron multi-payload selection can still surface internal assistant text; linked implementation PRs are still open or partial.

## What This Changes

Suppress intermediate or private assistant text between tool calls so messaging channels only receive intentional final or message-tool output.

## Best Possible Solution

Keep this as the canonical bug until maintainers choose the direct/source delivery policy and land one fix covering automatic, message_tool_only, streaming, final, and cron paths with regression proof.
