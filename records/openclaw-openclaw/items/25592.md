## Summary

Keep open. Current main has important commentary/final-answer safeguards, but the central channel leak remains source-reproducible because phase-less or no-canonical-final runs can still deliver every accumulated assistant text segment, and recent comments show the issue still affects production channel workflows.

## What This Changes

The issue asks OpenClaw to stop routing intermediate assistant text between tool calls to external messaging channels, leaving only intentional final or explicit message-tool output visible.

## Best Possible Solution

Define one upgrade-safe delivery policy at payload construction or a shared lower layer so non-final/commentary assistant segments are suppressed or marked private across interactive and cron delivery, with explicit config/default behavior and regression coverage for phase-tagged and phase-less providers.
