## Summary

Issue #25592 should stay open because current main still has automatic visible delivery paths for direct/group/channel turns and locked-in pre-tool block flushing, while the merged changes only cover narrower commentary/reasoning phases. The open linked PRs are useful candidate fixes, but they are unmerged or partial and do not replace the canonical cross-channel leakage issue.

## What This Changes

The issue requests preventing assistant text produced before or between tool calls from leaking as visible messages to external messaging channels.

## Best Possible Solution

Keep #25592 as the canonical issue until maintainers choose the delivery policy, then land a generic fix with upgrade proof and regression coverage for direct chats, groups/channels, cron announcements, message-tool sends, unphased text, and commentary/reasoning suppression.
