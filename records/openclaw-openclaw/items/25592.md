## Summary

Keep open: current main has useful commentary-phase and Anthropic pre-tool mitigations, but the broader cross-channel leak is still source-provable and this issue is still linked to open implementation PRs.

## What This Changes

The issue reports that assistant text produced before or between tool calls is delivered as visible Slack, Telegram, iMessage, Discord, WhatsApp, and related channel messages instead of remaining internal.

## Best Possible Solution

Keep this issue as the canonical product bug while maintainers choose a direct-chat-safe policy and review or supersede the linked implementation PRs, preserving existing commentary-phase safeguards and adding coverage for unphased pre-tool/inter-tool text plus cron reasoning delivery.

No single current or proposed path is proven as the best fix yet; the safest solution needs maintainer direction on direct-chat automatic delivery, explicit-send/final-only behavior, and cron reasoning filtering without breaking existing bare-text reply setups.
