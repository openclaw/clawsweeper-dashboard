## Summary

Keep open: current main has important partial guards for commentary-phase output and opt-in message-tool-only delivery, but automatic source delivery, direct-chat defaults, cron delivery selection, and unphased assistant text still leave the central cross-channel leak unresolved.

## What This Changes

Requests suppressing intermediate assistant text, tool narration, and reasoning/progress artifacts so messaging channels receive only final or explicitly sent output.

## Best Possible Solution

Adopt a unified external-channel delivery boundary that keeps tool-running intermediate text private, preserves existing commentary/final_answer guards, uses explicit message-tool or final-only delivery for visible output, and includes compatibility guidance plus focused regression coverage for direct, group, cron, and streaming paths.

## Maintainer Decision

Required: true

Kind: security_boundary

Question: Should external source-channel turns move to a safer default that suppresses automatic intermediate/final-looking text during tool-running turns, including direct chats and cron announce delivery, or should stricter delivery remain opt-in via existing visible-reply settings?

Rationale: The source-level bug is clear, but the permanent fix changes a user-visible delivery/security boundary and can break setups that intentionally rely on automatic bare-text replies.

Likely owner: scoootscooob

Owner reason: Their merged visible-reply policy work is the closest owner-history signal for this delivery boundary decision.

Owner confidence: medium

Options:

- **Safer external default (recommended):** Make external tool-running source turns private unless output is final-only or sent via the message tool, with an explicit opt-out or migration guidance for legacy automatic replies.
- **Opt-in stricter mode only:** Keep automatic replies as the default and land only narrower filters or docs around `messages.visibleReplies`, minimizing upgrade breakage but leaving more leak risk on default installs.
- **Split by surface:** Keep ordinary direct chats automatic while making shared rooms, cron announce, and ambient contexts message-tool-only or final-only by default.

## Solution Assessment
