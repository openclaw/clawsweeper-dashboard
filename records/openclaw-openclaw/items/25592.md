## Summary

Keep open: current main has partial phase/commentary and message-tool-only safeguards, but automatic visible source replies remain the documented default and current source still has paths that can deliver or select unphased inter-tool assistant text and cron payloads without reasoning metadata.

## What This Changes

The issue asks OpenClaw to stop routing assistant text produced between tool calls to messaging channels as visible user messages.

## Best Possible Solution

Keep this as the canonical tracker until maintainers choose the generic source-reply policy and land cross-channel regression coverage for interactive, message-tool, failure fallback, and cron announce paths.
