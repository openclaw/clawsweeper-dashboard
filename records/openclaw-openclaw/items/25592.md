## Summary

Keep open: current main has important commentary-phase and message-tool-only suppression, but the central default path still auto-delivers unphased assistant text to source replies and has tests preserving pre-tool flush behavior.

## What This Changes

The issue asks OpenClaw to stop sending intermediate assistant text between tool calls to messaging channels, leaving only final or explicitly sent user-visible replies.

## Best Possible Solution

Define one shared external-channel delivery boundary that keeps internal progress/commentary/reasoning private, preserves explicit message-tool sends, and proves fresh-install plus upgrade behavior for automatic-reply users.
