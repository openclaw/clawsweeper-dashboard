## What This Changes

The issue requests suppressing intermediate assistant text between tool calls so only intentional final replies or explicit message-tool sends reach messaging channels.

## Best Possible Solution

Keep this issue as the canonical tracker and land a maintainer-approved delivery policy that preserves compatibility intentionally while adding regression coverage for unphased pre-tool/inter-tool text, message-tool turns, cron announce delivery, and phased commentary/final-answer handling.
