## Summary

Keep open. Current main has useful partial suppression, but source and docs still allow automatic source delivery and unphased assistant text can still be buffered/flushed to channels; the thread also has fresh cross-channel security/message-delivery reports and open candidate PRs, so conservative cleanup should not close it.

## What This Changes

The issue asks OpenClaw to stop delivering intermediate/internal assistant text between tool calls to messaging channels, leaving only final or explicit user-visible sends.

## Best Possible Solution

Keep this as the canonical bug, have maintainers choose the direct/source delivery policy, review focused candidate PRs such as https://github.com/openclaw/openclaw/pull/86175, and add regression coverage for unphased inter-tool text, NO_REPLY finals, cron announce delivery, and direct/group channel modes.
