## Summary

Keep open. Current main has important phase-aware protections, but the central cross-channel leak is not fixed because phase-less or no-canonical-final runs still fall back to delivering every accumulated assistant text segment, and automatic source replies remain the default for direct chats and configured group/channel chats.

## What This Changes

The issue reports that intermediate assistant text between tool calls is delivered as user-visible messaging-channel output in channels such as Slack, Telegram, iMessage, WhatsApp, Discord, and Feishu.

## Best Possible Solution

Make a maintainer-owned channel delivery decision, then land one shared payload-construction fix that covers interactive and cron delivery, phase-less transports, and automatic versus message-tool-only upgrade behavior with focused regression tests.

- **Keep automatic delivery and document workarounds:** Preserve current behavior and rely on prompts/configuration, leaving the recurring leak risk to operators.
