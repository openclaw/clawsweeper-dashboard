- `P1`: The issue describes recurring real-user channel leaks across Slack, Telegram, Discord, WhatsApp, and Feishu, but the remaining fix needs maintainer policy review rather than emergency closure.

## Summary

Keep open: current main and v2026.6.11 still preserve automatic visible delivery paths that can surface unphased pre-tool/inter-tool text, while the implemented commentary-phase suppression only covers part of the reported leak. The issue also has open unmerged closing PRs, so it should stay canonical until maintainers choose and land the delivery policy.

## What This Changes

The issue asks OpenClaw to prevent assistant text produced before or between tool calls from leaking into visible messaging-channel replies.

## Best Possible Solution

Keep this as the canonical bug and have maintainers choose a channel-safe delivery policy that preserves explicit message-tool and commentary-phase safeguards while adding regression coverage for unphased pre-tool/inter-tool text and cron announce payloads.
