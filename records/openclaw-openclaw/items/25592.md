## Summary

Keep open: current main has meaningful partial safeguards for commentary-phase text and message-tool-only modes, but the central leak class is still source-reproducible on automatic delivery paths and remains an upgrade-sensitive product/security decision.

## What This Changes

The issue asks OpenClaw to prevent intermediate assistant text between tool calls from being delivered as visible messages to messaging channels.

## Best Possible Solution

Keep this issue as the canonical bug until maintainers choose a delivery policy and land a focused fix that suppresses intermediate/unphased assistant text across source replies, cron announce delivery, and message-tool-only paths without breaking intentional final replies.
