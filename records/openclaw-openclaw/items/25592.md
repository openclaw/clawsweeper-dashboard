## Summary

Keep open: current main has important partial safeguards, but the central cross-channel leak is not fully resolved and live context still has open implementation candidates plus unresolved direct-chat, generic pre-tool, and cron-delivery paths.

## What This Changes

The issue asks OpenClaw to stop delivering assistant text produced before or between tool calls as visible messaging-channel output, allowing only final or explicit-send content to reach channels.

## Best Possible Solution

Keep this issue as the canonical cross-channel leak bug, choose a safe default/final-delivery policy for direct and source chats, then land or close the narrower candidate PRs with regression coverage for direct chats, group/topic turns, cron/heartbeat delivery, and history/webchat projection.
