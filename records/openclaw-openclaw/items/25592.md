## Summary

Keep open: current main still has automatic delivery paths that can flush unphased assistant text before tool execution, while the issue has recent cross-channel production reports and open partial implementation candidates rather than a merged complete fix.

## What This Changes

Suppress internal or inter-tool assistant text from messaging channels so only intentional final replies or explicit message-tool sends are delivered.

## Best Possible Solution

Keep this as the canonical bug until maintainers choose a source-reply delivery policy, preserve upgrade compatibility deliberately, and land regression coverage for unphased pre-tool/inter-tool text across streaming, final assembly, message-tool-only, and cron announce paths.
