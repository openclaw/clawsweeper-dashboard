## Summary

The PR is a focused and technically sound fix for unbounded retained session-history state, but it should remain open because the external contributor has not provided inspectable after-fix proof from the real gateway SSE path. Source and tests support the steady-state cap, while initialization and refresh still read/project the full transcript before trimming, so the PR does not by itself establish bounded peak memory for very large existing sessions.

## What This Changes

The PR caps unpaginated gateway session-history SSE state at 500 projected messages across initialization, inline append, and refresh, while preserving explicit limit/cursor pages and adding regression tests.

## Best Possible Solution

Land the centralized unpaginated-only retention helper after a redacted real gateway SSE run demonstrates bounded retained state and correct older-page retrieval across initialization, append, and refresh; track a bounded-tail read for unpaginated initialization/refresh separately if peak full-transcript memory remains observable.
