## What This Changes

This PR defers the reusable workspace skill snapshot cache-key fingerprint until a cache lookup or cache write actually needs it, reducing synchronous per-message work on the already-hydrated path.

## System Context

Inbound reply handling resolves a reusable workspace skill snapshot before running an agent turn. The snapshot resolver either builds and caches resolved skills or hydrates an existing snapshot, then passes the resolved skills to the reply pipeline.

## Architecture Diagram
