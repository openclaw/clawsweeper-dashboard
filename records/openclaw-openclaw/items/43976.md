## Summary

Keep open: current main still has static binding/default routing, subagent/thread focus commands, TUI-local agent switching, and HTTP per-request agent selection, but no channel-visible `/agent <name>` command that temporarily switches one conversation to another configured agent without changing global bindings or restarting Gateway.

## What This Changes

The issue requests channel/session-scoped `/agents` and `/agent <name>` commands for temporarily switching the active configured agent in a conversation without restarting Gateway.

## Best Possible Solution

Define a guarded session-scoped route override that exposes only authorized configured agents, stores canonical session state, reuses existing subagent/tool/sandbox policy, uses typed command actions, and never mutates global bindings.
