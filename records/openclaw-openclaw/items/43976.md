## Summary

This issue should stay open: current main has adjacent pieces like TUI `/agent`, `/agents` for thread-bound subagents, `/focus`, and Feishu dynamic-agent creation, but it does not implement the requested channel-general `/agent <name>` command that temporarily switches a conversation to a configured agent without mutating global bindings or restarting Gateway.

## What This Changes

The issue requests chat commands to list configured agents and temporarily switch the current channel conversation to another agent without editing bindings or restarting Gateway.

## Best Possible Solution

Define a guarded session-scoped routing override that reuses existing agent discovery and delegation policy, stores canonical session state, exposes portable typed command actions, and never mutates global bindings.
