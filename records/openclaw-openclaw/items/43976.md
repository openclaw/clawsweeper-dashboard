## Summary

Keep open: current main still routes channel messages through static bindings/default-agent selection, while `/agents` is a thread-bound subagent/session-binding status command and `/agent <name>` only exists in the TUI.

## What This Changes

Add channel-visible commands to list configured agents and temporarily switch the current conversation to another agent without restarting Gateway.

## Best Possible Solution

Define a maintainer-approved core design for an authorization-gated session-level agent switch that keeps static bindings as defaults and preserves per-agent workspace, credential, and transcript isolation.
