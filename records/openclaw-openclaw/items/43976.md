## Summary

Keep open. Current main supports static binding-based channel routing, channel /agents for thread-bound subagent/session targets, and TUI-local /agent selection, but it still does not provide a channel-visible temporary switch to another configured agent; the remaining work is a product and security contract, not a stale cleanup close.

## What This Changes

Request to add channel commands that list configured agents and temporarily switch a single chat's active agent without restarting Gateway.

## Best Possible Solution

Define a generic, policy-gated conversation active-agent routing contract with authorization, persistence, cleanup, docs, and tests, or explicitly document static bindings plus /focus as the supported channel model.
