## Summary

This issue should stay open because current main still has only static binding/default routing plus adjacent TUI and thread-bound subagent controls; it does not implement a channel-wide, session-scoped `/agent <name>` switch for configured agents.

## What This Changes

Add channel commands to list configured agents and temporarily switch the current conversation to another agent without editing bindings or restarting Gateway.

## Best Possible Solution

Define a guarded session-scoped routing override that lists only authorized configured agents, stores the active agent in canonical session state, reuses typed command actions, and leaves global bindings unchanged.
