## Summary

## What This Changes

## Best Possible Solution

Land the provider-local bounded discovery fix once maintainers accept the 30s/4 MiB catalog boundary; keep broader dynamic-catalog configurability or provider policy changes out of this narrow patch.

Yes. Reusing the existing plugin-sdk response limiter inside the Mantle provider boundary plus a fetch abort signal is the narrow maintainable fix; the broader live-catalog helper path does not own this provider-specific implicit discovery flow.
