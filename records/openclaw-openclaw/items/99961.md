## What This Changes

## Best Possible Solution

Yes, provided maintainers accept the boundary. Reusing the existing bounded response reader inside the Mantle provider boundary plus a fetch abort signal is the narrow maintainable fix; broader provider-catalog sweeps can stay separate.
