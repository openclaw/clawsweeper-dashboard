## Best Possible Solution

Land one Mantle discovery guard that proves stalled fetches and oversized streamed bodies fail soft, while using a maintainer-accepted timeout and byte cap that do not conflict with the existing provider JSON hardening path.

## Reproduction Assessment

## Solution Assessment

Unclear as the final merge shape: adding timeout and bounded parsing is the right layer, but the 4 MiB cap and overlap with the open shared-reader PR need maintainer acceptance. The safest version is one accepted discovery boundary with real after-fix proof.
