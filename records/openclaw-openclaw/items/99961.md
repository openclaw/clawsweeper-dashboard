## What This Changes

Adds a 30s timeout and 4 MiB bounded JSON reader to Amazon Bedrock Mantle model discovery, with tests covering timeout-signal wiring and oversized-response fallback.

## Best Possible Solution

Land the provider-local bounded discovery fix once maintainers accept the 30s/4 MiB Mantle catalog boundary; keep broader provider-catalog sweeps separate.

## Solution Assessment

Yes. Reusing the existing bounded response reader inside the Mantle provider boundary plus a fetch abort signal is the narrow maintainable fix; the shared `readProviderJsonResponse` helper has the byte cap but not the body-idle timeout this PR needs.
