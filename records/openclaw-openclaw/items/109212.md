## Summary

Keep open: the current head still has a blocking operator-only recovery gap—native clients advertise inline widgets on operator connections, but an expired operator Canvas route cannot be refreshed without a live node session. The strong cross-platform proof and substantial security hardening are positive, but the protected maintainer label, unresolved merge conflicts, and new native WebView trust boundary require maintainer review before merge.

## What This Changes

Adds capability-gated inline Canvas widget rendering to iOS, Android, and macOS chats with isolated web views, TLS-bound routes, capability refresh handling, tests, localization, and documentation.

## Best Possible Solution

Provide one generic caller-owned plugin-surface refresh contract that can rotate the current connection's own Canvas capability for both operator and node roles, track which route produced the failed resource, and add operator-only expiry/reload tests across Swift and Android without granting cross-client authority.
