## Best Possible Solution

Land the prerequisite, then accept one canonical migration contract: preferably all legacy JSON retirement is performed by `openclaw doctor --fix`, with Apple runtimes failing closed and directing users to Doctor; if native import remains necessary, document and approve that narrow exception with upgrade and mixed-version proof.
