## Summary

Current main still separates source-keyed native-command admission from target-keyed continued agent work, leaving a credible concurrency gap not covered by existing tests; this valid maintainer-labeled bug should remain open.

## What This Changes

Ensure native-command turns that continue into full agent turns adopt target-session run and lifecycle ownership before target work begins.

## Best Possible Solution

Add one atomic adoption primitive that moves the existing outer reply operation and lifecycle lease from source to target only when command handling continues, before target agent preparation, while preserving immediate source-keyed handling for pure commands.

## Reproduction Assessment

Yes at source level with high confidence: current main visibly combines source-keyed outer admission with target-keyed session work. This read-only review did not execute the concurrent runtime scenario, so it is not classified as fully reproduced.

## Solution Assessment

Yes, the proposed ownership handoff is the narrowest maintainable direction because it preserves the predecessor fix for pure commands while restoring one target owner for continued agent work; it should reuse the existing operation rather than create a parallel one.
