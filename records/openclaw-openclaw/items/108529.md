## Summary

Keep open: this is a recent, well-scoped shipped QQBot regression with strong artifact and request-shape evidence, but the proposed direct-URL restoration crosses the SSRF boundary and the control test does not yet isolate URL forwarding from `srv_send_msg=true`.

## What This Changes

Restore readable tall-image delivery in QQBot while retaining the media URL security hardening.

## Best Possible Solution

Run a four-path live QQ C2C matrix that independently varies `url` versus `file_data` and direct send versus follow-up `msg_type=7`; prefer validated bytes with `srv_send_msg=true` if that preserves quality, and consider guarded URL forwarding only if it is uniquely required and its downstream-fetch security model is explicitly approved.
