## What This Changes

## Best Possible Solution

Keep one strict, single-pass decoder in the shared agent utility, retain compatibility coverage for historical numeric and mixed-case behavior, then rebase and land only after fresh exact-head dependency, agent, build, and shrinkwrap checks pass.
