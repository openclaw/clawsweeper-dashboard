## What This Changes

This PR changes isolated cron-job heartbeat suppression so the last outbound-capable payload, rather than an earlier acknowledgement or trailing empty payload, determines whether the scheduled result is delivered.

## System Context

Isolated cron jobs run an agent and collect its outbound payloads before creating a delivery request for the configured channel. The heartbeat policy suppresses genuinely terminal acknowledgement-only runs while allowing substantive scheduled results to proceed to channel delivery.
