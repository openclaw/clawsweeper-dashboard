## Summary

This PR addresses a real shipped UI bug, but it has one blocking semantic error: it labels the full discovered skill inventory as “skills installed,” including skills that are ineligible or missing requirements. The branch also lacks after-fix proof from a live Gateway and browser session.

## What This Changes

The PR loads Cron and Skills inventory counts into the Control UI Quick Settings Automations card and adds loading, offline, unavailable, and regression-test coverage.

## Best Possible Solution

Keep the Cron total loader, derive the Skills value from the status field matching the existing ready/eligible semantics—or rename the row if total discovered inventory is intentionally desired—and prove the corrected card against a live Gateway in the browser.
