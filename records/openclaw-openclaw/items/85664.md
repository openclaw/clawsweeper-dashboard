## What This Changes

This PR adds a default-off, owner-gated configuration path that materializes OpenClaw’s built-in `read` coding tool for Gateway HTTP `/tools/invoke` and SDK `tools.invoke`, while preserving same-named plugin tools and documenting/auditing the exposure.

## System Context

Gateway direct invocation authenticates a caller, resolves available core and plugin tools under policy, runs the tool hook, and returns the result through HTTP or SDK RPC. This PR adds a narrowly gated built-in host-filesystem reader to that shared resolution path.
