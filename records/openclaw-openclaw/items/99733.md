## Summary

The implementation is coherent for stateless delegated text inference, but it is not merge-ready: exact-head behavior is unproven, native-tool semantics are not demonstrated, and first-party bundled ownership remains an explicit product decision.

## What This Changes

Adds a bundled experimental `google-antigravity-cli` provider plugin that probes a local `agy` binary and runs serialized, stateless `agy --print` inference for three model aliases.

## Best Possible Solution

Keep the canonical replacement request open; either publish this narrow delegated-inference implementation as an external plugin with explicit limitations, or bundle it only after exact-head text/tool proof, stable installed-model validation, clear user-facing distinction from Gemini CLI compatibility, and explicit owner sponsorship.
