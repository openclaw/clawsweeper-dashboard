- **[P1] Preserve history for no-session Antigravity runs:** `extensions/google/antigravity-cli-backend.ts:57`
  - body: `sessionMode: "none"` means there is no reusable CLI session id, and current raw transcript reseeding is opt-in. Without enabling and testing raw transcript reseed for this text backend, follow-up turns before compaction can be sent without prior conversation context.
  - confidence: 0.88
- **[P2] Forward selected Antigravity models to agy:** `extensions/google/antigravity-cli-backend.ts:53`
  - body: The backend always runs `agy --print {prompt}` and never declares `modelArg`, while the CLI runner only appends the chosen model when `modelArg` exists. Non-default refs such as pro/high variants can therefore report one OpenClaw model while `agy` runs its default.
  - confidence: 0.9
- **[P1] Preserve Gemini CLI OAuth refresh upgrades:** `extensions/google/oauth.ts:121-130`
  - body: Current main refreshes stored `google-gemini-cli` OAuth profiles from their saved refresh token. This branch instead throws unless the official Gemini CLI cache provides a usable access token, so existing OpenClaw-created profiles can stop working after token expiry without a tested migration or explicit maintainer-approved break.
  - confidence: 0.86
