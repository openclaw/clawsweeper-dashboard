- **[P1] Preserve Gemini CLI OAuth refresh upgrades:** `extensions/google/oauth.ts:121-130`
  - body: Current main can refresh stored `google-gemini-cli` OAuth profiles from their saved refresh token.   - confidence: 0.88
- **[P1] Forward selected Antigravity models to agy:** `extensions/google/antigravity-cli-backend.ts:53`
  - body: The backend always invokes `agy --print {prompt}` and does not set `modelArg`, while the CLI runner only appends the selected model when `backend.modelArg` is present. Non-default `google-antigravity/...` refs can therefore report one OpenClaw model while `agy` runs its default.
  - confidence: 0.9
- **[P1] Preserve history for no-session Antigravity runs:** `extensions/google/antigravity-cli-backend.ts:57`
  - body: `sessionMode: "none"` means OpenClaw has no reusable CLI session id for `agy`, and raw transcript reseeding is opt-in. Without enabling and testing `reseedFromRawTranscriptWhenUncompacted` or another strategy, follow-up turns before compaction can be sent without prior conversation context.
  - confidence: 0.87
- **[P2] Add Antigravity setup auth discovery:** `extensions/google/openclaw.plugin.json:657`
  - body: The manifest advertises `google-antigravity` as a CLI backend, but the setup entry still registers only the Gemini CLI backend and the manifest auth choices still list only `google` and `google-gemini-cli`. Add the setup-safe backend/provider choice so onboarding can configure the provider that runtime can execute.
  - confidence: 0.84
