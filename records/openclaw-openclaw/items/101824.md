## What This Changes

The issue requests a dashboard widget publish command, a zero-infra widget registry convention, and agent browse/adapt support for community widget bundles.

## Best Possible Solution

After the dashboard base and gallery install path are accepted, implement publish/registry as a dashboard-plugin feature backed by ClawHub/package-style provenance, explicit approval/scanning, and registry schema/docs before allowing raw registry URLs.
