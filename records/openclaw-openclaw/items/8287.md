## Summary

Keep open: current main and v2026.6.11 still expose connected nodes as capabilities plus command names, not node-advertised model-visible tools. The open implementation candidate is relevant but unmerged, conflicting, and still needs maintainer acceptance of the node-to-model security boundary.

## What This Changes

The issue requests a Gateway/node protocol feature that lets connected nodes advertise first-class agent tool definitions which the Gateway exposes directly to the LLM without a wrapper plugin.

## Best Possible Solution

Keep this issue as the canonical design thread while maintainers decide and repair the node-hosted tool contract: additive protocol schema, per-node lifecycle storage, node-provenance tool inventory, policy-aware execution through node.invoke, docs, and upgrade proof.
