## Summary

Current main and v2026.6.11 still expose connected nodes through capabilities and command names, not dynamically published model-visible tools. The proof-positive implementation at https://github.com/openclaw/openclaw/pull/90431 remains open but conflicts with main, so this issue should remain the canonical product and security decision record until that PR is refreshed and either landed or explicitly rejected.

## What This Changes

Allow connected nodes to advertise schemas that become first-class agent tools and execute through the Gateway node path.

## Best Possible Solution

Refresh and review the canonical PR against current main, then either land its Gateway-validated plugin-owned tool model or explicitly reject the direction; arbitrary raw node-provided schemas should not become model-callable.
