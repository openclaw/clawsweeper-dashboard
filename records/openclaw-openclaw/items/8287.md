## What This Changes

Allow connected nodes to publish dynamically available agent tools without requiring an HTTP-loopback wrapper plugin.

## Best Possible Solution

Adopt one Gateway-validated, plugin-backed node-tool contract by refreshing the existing proof-positive candidate, preserving explicit node provenance, online/offline invalidation, provider-safe naming, and existing node command authorization.
