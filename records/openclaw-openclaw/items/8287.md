## Summary

Keep open: current main and the latest release still expose connected nodes as capabilities plus command names, not node-advertised model-visible tools. The linked implementation candidate is relevant but unmerged and still needs maintainer acceptance of the node-to-model security boundary.

## What This Changes

Request connected nodes to advertise tool descriptors that the Gateway can expose directly as agent-visible tools without wrapper plugins.

## Best Possible Solution

Keep this as the canonical design thread while maintainers decide and repair the node-hosted tool contract: additive protocol schema, per-node lifecycle storage, node-provenance inventory, policy-aware execution through node.invoke, docs, and upgrade proof.
