Keep open: current main and latest release still lack node-advertised model-visible tools, and the open implementation candidate has not merged. The issue remains the canonical product/security thread for Gateway protocol, node provenance, and tool-policy design.

Keep this issue as the canonical product/security thread until https://github.com/openclaw/openclaw/pull/90431 lands or maintainers choose a different additive Gateway protocol and node tool policy shape.
