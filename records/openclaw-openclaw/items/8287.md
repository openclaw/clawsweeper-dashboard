Keep open: current main and v2026.6.11 still expose node capabilities and command names, not node-advertised model-visible tools; the open candidate PR is relevant but unmerged and currently conflicting.

## What This Changes

Request to let connected nodes register agent-visible tool descriptors that the Gateway exposes to the LLM and routes through node invocation without a wrapper plugin.

## Best Possible Solution

Keep this issue as the canonical design thread while maintainers decide and repair the node-hosted tool contract: additive protocol schema, per-node lifecycle storage, node-provenance tool inventory, policy-aware execution through node.invoke, docs, and upgrade proof.
