## Summary

Keep open: current main and v2026.6.11 still model connected nodes as capabilities plus command names, not node-advertised model-visible tools. The open implementation candidate is useful context, but it is unmerged, currently conflicting, and still needs maintainer acceptance of the node-to-model security boundary.

## What This Changes

The issue requests an additive Gateway/node protocol so connected nodes can advertise agent-visible tool definitions that route directly through node.invoke instead of requiring wrapper plugins.

## Best Possible Solution

Keep this issue as the canonical design thread while maintainers decide and repair the node-hosted tool contract: additive protocol schema, per-node lifecycle storage, node-provenance tool inventory, policy-aware execution through node.invoke, docs, and upgrade proof.
