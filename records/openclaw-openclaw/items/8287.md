Keep open: current main still lacks node-advertised model-visible tools, and the open implementation candidate has not merged. This remains the canonical product/security thread for Gateway protocol, node provenance, and node tool policy design.

## What This Changes

The issue requests Gateway support for connected nodes to advertise model-visible agent tools directly, avoiding wrapper plugins and HTTP loopback through the existing nodes tool.

## Best Possible Solution

Keep this issue as the canonical product/security design thread until https://github.com/openclaw/openclaw/pull/90431 lands or maintainers choose a different additive Gateway protocol and node tool policy shape.
