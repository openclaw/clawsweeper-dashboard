## Summary

Keep open: pinned current main and v2026.6.11 still expose connected nodes through command claims and the generic `nodes` tool, while the protected open implementation candidate remains unmerged and requires maintainer acceptance of its narrower plugin-backed trust model.

## What This Changes

Allow connected nodes to advertise dynamic model-visible tools that the Gateway registers while connected, routes through node invocation policy, and removes on disconnect.

## Best Possible Solution

Adopt the registry-backed node-hosted plugin-tool seam as the secure core capability, retaining Gateway validation, node provenance, command allowlisting, lifecycle cleanup, and plugin ownership; consider standalone raw node schemas only through a separate explicitly approved trust model.
