## Solution Assessment

Yes: the narrow maintainable fix is to classify `browser.profiles.*` as hot while preserving restart classification for broader browser settings and covering the `config.patch` path. The open closing PR already attempts that path, so the issue should stay open until it merges or maintainers reject it.
