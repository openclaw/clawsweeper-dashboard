## Summary

Keep open: current main and the latest release still classify all `browser.*` plugin config as restart-scoped, so `browser.profiles.*` can still drive the `config.patch` SIGUSR1 path; the open closing PR is the active fix candidate, not a reason to close this issue before merge.

## What This Changes

The issue asks for `config.patch` to skip SIGUSR1 restarts when the changed paths are hot-reloadable browser profile config such as `browser.profiles.*`.

## Best Possible Solution

Review and land or reject https://github.com/openclaw/openclaw/pull/93827 as the canonical fix, preserving restart behavior for service-level browser config while making per-profile browser config hot-reloadable.
