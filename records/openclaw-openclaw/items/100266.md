## Summary

Keep open: the patch covers top-level mutation tombstones, but snapshot-shaped `sessions.changed` events still parse from `event.session` and ignore the top-level `label: null` / `displayName: null`, so subscribed clients can keep stale labels.

## Best Possible Solution

Make label/displayName tombstones survive both mutation and snapshot-shaped `sessions.changed` events, then land with producer and consumer regressions for both shapes.
