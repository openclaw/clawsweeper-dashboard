## What This Changes

Fix Code Mode’s module-access preflight so inert template text and regular-expression text can execute while real module access and executable template interpolations remain blocked.

## System Context

Code Mode replaces a model’s broad tool surface with an `exec` interface that runs JavaScript or TypeScript inside a QuickJS-WASI guest. Before guest startup, its source-validation boundary rejects module-capability syntax, then passes accepted code to the isolated guest and host-tool bridge.
