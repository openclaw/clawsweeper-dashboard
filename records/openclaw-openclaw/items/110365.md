## Label Justifications

- `merge-risk: 🚨 automation`: The changed retry runner expressions alter GitHub Actions execution paths and expose a cross-attempt artifact dependency that normal unit checks do not prove.

## Summary

Keep this PR open: its failed-jobs-only retry route can leave the shared OpenClawKit intersection job looking for an attempt-2 artifact from a sibling scan that succeeded only on attempt 1. The patch also lacks real after-fix proof of that mixed-attempt recovery path, and the `maintainer` label requires owner handling rather than automated cleanup.

## What This Changes

The branch conditionally tolerates a missing historical package script in release validation, routes retried native macOS scans to GitHub-hosted runners, freezes the release-gate merge snapshot, and refreshes generated Apple locale files.

## Best Possible Solution

Preserve failed-jobs-only recovery by making the shared intersection resolve each producer's latest valid artifact independently, then prove a one-producer attempt-2 retry completes the intersection without rerunning the successful sibling.
