## Summary

Keep open: current main and v2026.6.11 have internal private gateway-client and App SDK groundwork, but the requested public, platform-agnostic Gateway WebSocket client package is still unpublished and needs maintainer product/security direction.

## What This Changes

Request to publish a reusable, platform-agnostic `@openclaw/gateway-client` WebSocket SDK for third-party Gateway clients and eventually shared CLI/Control UI protocol logic.

## Best Possible Solution

A maintainer should sponsor a versioned, documented, security-reviewed public Gateway/App SDK contract and explicitly choose whether the supported package is raw `@openclaw/gateway-client`, higher-level `@openclaw/sdk`, or both.
