## Summary

Keep open. This is the consolidated tracker for a concrete large-attachment failure, and the linked implementation candidate remains open rather than merged; no current-main or release provenance demonstrates that the requested stack-safe parsing and stale queue cleanup are already available to users.

## What This Changes

Make Control UI and gateway processing of large base64 attachment data URLs stack-safe, while removing persisted composer queue entries created by the historical stack-overflow failure.

## System Context

Control UI serializes selected files into attachment payloads and sends them through the Gateway chat path. The Gateway validates, stages, and may offload those attachments before the agent receives the message, while the Control UI persists composer queue state for retries.
