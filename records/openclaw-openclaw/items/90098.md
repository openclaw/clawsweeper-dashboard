## What This Changes

Make Control UI and gateway attachment parsing stack-safe for large data URLs, validate large base64 payloads without full-payload regexes, and remove persisted composer entries created by the historical overflow.

## System Context

Control UI converts chosen files into attachment payloads and sends them over the chat gateway, which validates and stages the attachment before it reaches the agent workflow. The composer also persists unsent entries locally, so a failed large attachment can otherwise be restored and replayed.
