## Summary

This remains a useful, vision-aligned Control UI feature: current main has single-target sidebar actions and batch deletion only on the Sessions page. Because the issue has a protected maintainer label and changes the primary navigation interaction model, maintainers should choose the initial action scope before implementation.

## What This Changes

Add modifier-key multi-selection to Control UI sidebar sessions and batch read-state, grouping, archive, and delete actions while preserving single-session behavior.

## Best Possible Solution

Add an accessible typed sidebar selection model and canonical batch-patch capability with explicit partial results, active-session transition rules, and shared summaries; reuse deleteMany and preserve ordinary navigation when no multi-selection exists.
