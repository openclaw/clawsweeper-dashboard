## What This Changes

The issue asks OpenClaw to make fenced legacy `MEDIA:` attachment directives less silent, either by extracting them, warning about skipped tokens, or documenting the plain-text requirement.

## Best Possible Solution

Review and repair or close https://github.com/openclaw/openclaw/pull/80396; keep fenced `MEDIA:` non-extracting unless maintainers explicitly accept broader attachment parsing from code fences.
