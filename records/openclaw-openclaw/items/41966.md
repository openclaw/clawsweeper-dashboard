## What This Changes

The issue asks OpenClaw to make legacy `MEDIA:` directives inside Markdown code fences visible to users or operators instead of silently leaving the attachment undelivered as text.

## Best Possible Solution

Address and land https://github.com/openclaw/openclaw/pull/80396 or an equivalent patch that emits one warning at the real outbound delivery boundary while preserving fenced examples as text unless maintainers explicitly choose extraction or docs-only behavior.
