## What This Changes

The issue reports that `MEDIA:` attachment directives inside markdown code fences are silently skipped, leaving the raw path visible instead of delivering media or warning the user.

## Best Possible Solution

Keep this issue as the canonical tracker until the focused warn-only runtime fix lands, or until maintainers explicitly choose a different parser contract such as extracting fenced tokens or documenting the behavior as by design.

Options:

- **Warn at delivery boundary (recommended):** Keep fenced `MEDIA:` examples as text, propagate a skipped-token signal through user-visible delivery paths, and merge the warning PR after maintainer re-review.
- **Extract fenced tokens:** Change the parser contract so standalone fenced `MEDIA:` tokens are delivered, with tests documenting the intentional risk to code examples and transcripts.
- **Docs-only constraint:** Treat fenced tokens as by-design invalid output and rely on prompt/docs guidance instead of adding runtime diagnostics.
