## What This Changes

Reject Git installer destinations that contain `.git` but have no resolvable `HEAD`, before any checkout, update, or build operation begins.

## System Context

OpenClaw’s Git installers accept a destination path and decide whether to clone or update a checkout before installing and building the application. The reported guard belongs at the existing-checkout validation boundary so invalid repository state cannot reach later checkout and package-build steps.
