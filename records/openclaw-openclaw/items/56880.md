## Summary

Keep open: current main still serializes same-session agent runs, and the existing steer/followup/collect/interrupt modes are mitigations rather than true parallel or fast-lane turns. The open linked fork PR is conflicting and unproven, so the remaining work needs maintainer product and session-safety direction.

## What This Changes
