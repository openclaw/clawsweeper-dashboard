## What This Changes

Request concurrent or fast-lane handling for same-session chat messages so quick follow-ups can respond while a long agent turn is active.

## Best Possible Solution

Keep this issue open as the design tracker for same-session fast-lane or parallel turns, then implement only after maintainers choose a bounded scheduler contract that preserves transcript, delivery, and tool safety.
