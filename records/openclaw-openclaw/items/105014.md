## What This Changes

The PR makes Markdown and CSV workspace file bindings preserve omitted or root-pointer reads while rejecting malformed or missing non-root pointers through the existing binding error contract.

## Best Possible Solution

Adopt one canonical contract in which omitted and root pointers return raw Markdown/CSV content, non-root raw-text pointers fail closed, and the Workspaces documentation clearly distinguishes raw-file pointer behavior from structured JSON traversal.
