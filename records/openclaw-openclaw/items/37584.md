## Summary

Keep open: current main still has global web-search provider and credential settings, while per-agent tool config only covers policy-style tool controls; the remaining work needs a maintainer product/security contract rather than a narrow fix PR.

## What This Changes

Request to let `agents.list[]` override global web/tool settings such as web-search provider, API key, timeout, and related tool configuration.

## Best Possible Solution

Define one SecretRef-aware agent-scoped tool/plugin credential contract, then wire web-search provider selection through that boundary with schema, docs, doctor/security review, and upgrade tests.
