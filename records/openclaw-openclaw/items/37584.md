## Summary

Keep open: current main and the latest release still lack an accepted per-agent web/tool credential override surface, while current code already covers most of the newer per-agent model/thinking comment through `agents.list[].model` and `thinkingDefault`. ## What This Changes

Add an agent-scoped configuration surface so each configured agent can override web/tool settings such as web-search API keys, provider choice, timeouts, and related settings.

## Best Possible Solution

Define one maintainer-approved agent-scoped credential contract covering web tools, plugin-owned `webSearch` config, SecretRefs, precedence, docs, validation, and upgrade behavior.
