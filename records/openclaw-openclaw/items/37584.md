## Summary

Keep open: current main and v2026.6.11 still lack agent-scoped web/tool credential settings, and the requested credential isolation is useful but needs a maintainer-owned product/security contract before implementation.

## What This Changes

The issue requests per-agent overrides for nested tool settings such as `agents.list[].tools.web.search.apiKey`, provider, and timeouts so different agents can use different web-search credentials or providers.

## Best Possible Solution

Define a maintainer-approved agent-scoped web/tool credential contract covering provider/plugin config ownership, SecretRefs, precedence, validation/reload, doctor behavior, docs, and focused multi-agent tests before implementation.
