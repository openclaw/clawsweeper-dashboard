## Summary

Keep open: current main and v2026.6.11 still have global `tools.web.search` settings and per-agent tool policy only, while the requested per-agent web/tool credential and provider settings remain security-sensitive product work.

## What This Changes

The issue requests per-agent overrides for web-search and other tool-specific settings under `agents.list[].tools`.

## Best Possible Solution

Define a maintainer-approved agent-scoped web/tool settings contract that is explicit about precedence, SecretRef/redaction, plugin-provider ownership, docs, and two-agent regression coverage.
