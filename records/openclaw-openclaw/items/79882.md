- **[P2] Recompute shared runtime TTL after detach:** `src/agents/agent-bundle-mcp-runtime.ts:1184-1187`
  - body: When a shared runtime has one attached session with `sessionIdleTtlMs: 0` and another with a finite TTL, detaching the unbounded session returns here while `idleTtlMsByRuntimeKey` remains `0`.
