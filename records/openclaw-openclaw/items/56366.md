Keep open: current main and the latest release still load and watch the personal `$HOME/.agents/skills` source with no source-level opt-out, and the closed overlapping report points back to this issue as the canonical tracker. ## What This Changes

Request an option to disable or ignore OpenClaw's built-in personal `.agents/skills` scan to avoid prompt bloat and skill precedence conflicts when coexisting with Claude Code.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract, then apply it consistently before discovery and watcher registration with schema, docs, and focused regression coverage.
