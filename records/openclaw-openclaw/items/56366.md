## What This Changes

The issue requests a configuration option to disable OpenClaw's personal `.agents/skills` scan so Claude Code skill directories do not inflate or override OpenClaw skill context.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract, then implement it across discovery, watcher registration, schema/help, docs, status behavior, and focused regression tests.
