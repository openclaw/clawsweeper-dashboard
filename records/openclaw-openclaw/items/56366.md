## Summary

Keep open: current main and v2026.6.11 still load and watch `~/.agents/skills` as a built-in personal skill source, and the strict `skills.load` config surface has no source-level opt-out. The overlapping source-disable report was closed in favor of this issue, so the remaining work is a maintainer product/config decision rather than conservative cleanup.

## What This Changes

Request to add a public skill-loading option to disable scanning `~/.agents/skills` for Claude Code coexistence, with a possible broader ignore-list/source-disable design.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract and apply it before both discovery and watcher registration, while preserving current load order when unset and updating schema, docs, status behavior, and regression tests together.
