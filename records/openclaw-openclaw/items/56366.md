Keep open: current main and v2026.6.11 still load and watch `~/.agents/skills` as a built-in source with no source-level opt-out. The remaining work is a maintainer product/config decision, not conservative cleanup.

## What This Changes

The issue requests a configuration option to disable scanning `~/.agents/skills` so OpenClaw can coexist with Claude Code skill directories without prompt bloat or source conflicts.

## Best Possible Solution

Keep this issue open until maintainers choose the skill-source control surface, then implement a documented config/schema/help/docs/test path that preserves current default loading while allowing users to opt out before discovery and watcher registration.
