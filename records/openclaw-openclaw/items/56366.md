## What This Changes

The issue requests a configuration option or ignore list to disable scanning `~/.agents/skills` for users who share that directory with Claude Code or external skill routers.

## Best Possible Solution

Decide the supported skills-source control model first, then implement it in the canonical config schema, loader, docs, and regression tests without changing existing default behavior for upgrades.
