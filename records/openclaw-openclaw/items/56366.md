## Summary

Current main and the latest stable release still load and watch the personal `~/.agents/skills` source with no source-level opt-out. The issue remains useful, but it requires maintainer product/API direction because the fix adds public skills config semantics and changes built-in skill-source behavior.

## What This Changes

Issue requests a user-configurable way to disable automatic scanning of Claude Code-compatible `~/.agents/skills` skill directories to avoid prompt bloat and skill conflicts.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract, then implement it consistently across discovery, watcher registration, config schema/help, docs, status behavior, and focused regression tests.
