## Summary

## What This Changes

The issue requests a `skills.load` option to disable or ignore the personal `~/.agents/skills` source so Claude Code skill directories do not automatically enter OpenClaw skill discovery and prompts.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract, then implement it consistently across discovery, watcher registration, config schema/help, docs, status behavior, and focused regression tests.

## Reproduction Assessment

Yes. Source inspection shows current main and `v2026.6.11` still load and watch `~/.agents/skills` as `agents-skills-personal`, while strict `skills.load` config has no source-disable field.

## Solution Assessment

Unclear until maintainers choose the public API shape. A generic source-disable setting is plausible, but the config-surface bar is high and the fix must cover discovery, watching, docs, and tests together.
