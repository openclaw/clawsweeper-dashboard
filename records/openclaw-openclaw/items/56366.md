Keep open: current main and latest release still load and watch `~/.agents/skills` as a built-in personal skill source with no source-level opt-out, and https://github.com/openclaw/openclaw/issues/64639 was closed in favor of this canonical issue. ## What This Changes

Request a config option to disable or ignore the built-in `~/.agents/skills` scan so Claude Code personal skills do not enter OpenClaw prompts.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract, then implement it consistently across discovery, watcher registration, config schema/help, docs, status/snapshot behavior, and focused regression tests.
