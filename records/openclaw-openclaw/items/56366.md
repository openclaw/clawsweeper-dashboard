## Summary

Keep open: current `main` and v2026.6.11 still load and watch `~/.agents/skills` as a built-in personal skill source with no source-level opt-out. The remaining work is valid, but it adds public `skills.load` config surface and needs maintainer product/API direction before implementation.

## What This Changes

The issue requests a configuration or ignore-list option to stop OpenClaw from scanning Claude Code-style personal skills under `~/.agents/skills`.

## Best Possible Solution

Maintainers should choose a backward-compatible skill-source opt-out contract and then apply it consistently across discovery, watcher registration, config schema/help, docs, status behavior, and focused regression tests.
