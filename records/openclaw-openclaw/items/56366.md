## Summary

Keep open: current main and v2026.6.11 still load and watch the personal `~/.agents/skills` source without a source-level opt-out, and the exact duplicate was closed in favor of this issue. The remaining work is a real product/config contract decision, not conservative cleanup.

## What This Changes

Request to add a config-supported way to disable the personal `~/.agents/skills` skill source, and possibly other built-in skill roots, to reduce prompt bloat and conflicts.

## Best Possible Solution

Maintainers should choose a backward-compatible built-in skill-source opt-out contract and implement it consistently across discovery, watcher registration, config schema/help, docs, status/snapshot behavior, and focused tests.
