## Summary

Keep open: current main and the latest release still load and watch `~/.agents/skills` as a built-in personal skill source, while the strict `skills.load` config has no source-level opt-out. The remaining work is a maintainer product/config decision, not conservative cleanup.

## What This Changes

The issue requests a config option to disable or ignore personal `~/.agents/skills` discovery so Claude Code skill directories do not automatically affect OpenClaw sessions.

## Best Possible Solution

A maintainer-approved, backward-compatible skill-source opt-out should skip disabled built-in roots before discovery and watcher registration, with schema/help/docs/status behavior and regression tests aligned while preserving current defaults when unset.
