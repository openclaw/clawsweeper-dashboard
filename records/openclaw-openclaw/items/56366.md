## Summary

Keep open: current main and the latest release still load and watch `~/.agents/skills` with no source-level opt-out. The overlapping report at https://github.com/openclaw/openclaw/issues/64639 was closed in favor of this issue, so the remaining work is a maintainer product/config decision rather than cleanup.

## What This Changes

Request a `skills.load` option to disable or ignore hardcoded `~/.agents/skills` scanning so Claude Code skills do not bloat or override OpenClaw skill prompts.

## Best Possible Solution

Maintainers should choose one backward-compatible source opt-out contract and apply it before discovery and watcher registration, with schema, help, docs, status behavior, and regression tests updated together.

- **General source-disable list (recommended):** Add a typed `skills.load.disabledSources`-style list for built-in source ids and apply it consistently across discovery, watcher registration, docs, and status surfaces.

- **Decline new config:** Keep current cross-agent discovery semantics and ask users to move or individually disable skills, accepting the reported prompt-bloat tradeoff.
