## Summary

Keep open. Current main and v2026.6.11 still let real stored auth profiles win before env/config fallback, and the existing auth/secrets commands expose per-agent operations plus diagnostic REF_SHADOWED rather than a bulk key-rotation workflow.

## What This Changes

The issue requests an auth sync, warning, or fallback workflow so provider API key rotations do not leave stale per-agent credentials active.

## Best Possible Solution

Add an explicit, audited SQLite-backed bulk auth update or doctor/secrets warning workflow that preserves deliberate auth precedence and avoids silent cross-agent credential copying unless maintainers choose that policy.
