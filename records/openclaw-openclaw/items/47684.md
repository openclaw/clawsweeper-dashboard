## Summary

Keep open. Current main and v2026.6.11 still lack a bulk auth rotation/sync command or inline shadowing recovery path, and choosing sync, warning, doctor repair, or runtime fallback changes credential precedence and secret propagation.

## What This Changes

The issue requests a user-friendly command or automatic workflow to rotate provider API keys across per-agent auth stores without manual file edits.

## Best Possible Solution

Design an explicit, audited SQLite-backed auth rotation or doctor/status warning path, and avoid automatic fallback-on-401 unless maintainers intentionally choose that security tradeoff.
