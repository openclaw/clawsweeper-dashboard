## Summary

Keep open. Current main and v2026.6.11 still lack a bulk auth rotation/sync command or inline config-env shadow warning, and the remaining fix choice affects credential propagation, provider auth precedence, and per-agent auth state.

## What This Changes

Request a user-friendly way to sync, warn about, or otherwise handle env-backed API key rotation when per-agent auth profiles shadow the updated key.

## Best Possible Solution

Design an explicit, audited SQLite-backed auth rotation or doctor/status warning path, and avoid automatic fallback-on-401 unless maintainers intentionally choose that security tradeoff.
