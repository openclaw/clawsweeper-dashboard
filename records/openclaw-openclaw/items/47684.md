Keep open. Current main and the latest release still lack a bulk auth sync/rotation command or inline rotation warning for env-backed API-key changes, while related closed items cover narrower auth propagation cases or closed-unmerged proposals.

## What This Changes

Request to add bulk auth credential sync, automatic sync, warning, or fallback behavior so API-key rotation does not leave per-agent auth stores stale.

## Best Possible Solution

Design an explicit, audited SQLite-backed auth rotation or doctor/status warning path, and avoid fallback-on-401 unless maintainers deliberately choose that security tradeoff.

- **Runtime fallback on auth failure:** Try env/config credentials after a stored-profile failure, trading recovery convenience for a more complex and surprising auth precedence model.
