## Summary

Keep open. Current main and the latest release still lack a bulk auth sync/migrate command or inline rotation warning for env-backed API-key changes, while related closed items only cover narrower explicit-config precedence or missing-auth inheritance cases.

## What This Changes

The issue requests a user-facing way to rotate an Anthropic API key across per-agent auth stores, via auto-sync, a sync command, a shadowing warning, or fallback behavior.

## Best Possible Solution

Design an explicit, audited SQLite-backed bulk auth rotation or doctor/status warning path, and avoid fallback-on-401 unless maintainers deliberately choose that security tradeoff.
