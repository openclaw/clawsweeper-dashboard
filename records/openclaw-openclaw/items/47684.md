## Summary

Keep open. Current main has fixes for explicit `models.providers.*.apiKey` precedence, but it still lacks the requested bulk rotation/sync or repair path for env-backed API keys shadowed by stored per-agent auth profiles, and the remaining fix changes security-sensitive credential propagation semantics.

## What This Changes

The issue requests a user-facing command, automatic sync, warning, or fallback behavior for rotating provider API credentials across agent auth stores.

## Best Possible Solution

Add an explicit, audited SQLite-backed auth rotation or doctor/status repair path that detects shadowed rotated static keys and updates affected agent stores only with clear operator intent.
