## Summary

Keep open: current main has the Gemini Embedding 2 provider path, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but the central PDF/video and remembered inbound-attachment memory behavior is still missing and needs product/security direction.

## What This Changes

The issue asks to extend `memorySearch` so Gemini Embedding 2 can index multimodal media and attachments, configure output dimensions, and retrieve relevant media through text queries.

## Best Possible Solution

Keep this as the canonical product/security tracker, define the opt-in media upload and retention contract, then implement the approved attachment/PDF/video modalities with reindexing, docs, and provider-contract tests.
