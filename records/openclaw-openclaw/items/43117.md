## Summary

Keep open: current main and v2026.6.11 include Gemini Embedding 2, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but PDF/video support and remembered inbound attachment indexing are still missing and need product/security review.

## What This Changes

The issue requests multimodal memory search support for Gemini Embedding 2, including media embeddings, configurable output dimensionality, and cross-modal retrieval.

## Best Possible Solution

Keep this as the canonical product/security item, define the opt-in media upload and retention contract, then implement the approved attachment/PDF/video modalities with reindexing and provider-contract tests.
