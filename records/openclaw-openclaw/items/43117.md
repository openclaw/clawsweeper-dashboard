## Summary

Keep open: current main and v2026.6.11 already cover Gemini Embedding 2 text embeddings, output dimensionality, and opt-in image/audio files, but PDF/video modalities, mixed-media query inputs, and remembered inbound-attachment indexing remain missing and product/security-sensitive.

## What This Changes

The issue requests Gemini Embedding 2 multimodal memory search for media attachments, configurable embedding dimensions, and cross-modal retrieval from conversation history.

## Best Possible Solution

Keep the shipped image/audio extraPaths foundation, then split the remaining work into a maintainer-approved PDF/video modality contract and a separate explicit remembered-attachment storage and upload policy.
