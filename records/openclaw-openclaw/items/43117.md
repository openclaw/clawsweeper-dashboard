Keep open: current main and v2026.6.11 implement Gemini Embedding 2 output dimensionality and opt-in image/audio indexing from `memorySearch.extraPaths`, but PDF/video support and remembered inbound attachment indexing are still missing and need maintainer product/security direction.

The issue requests extending `memorySearch` Gemini Embedding 2 support to multimodal attachments, PDF/video/audio/image retrieval, mixed-modal search, and configurable output dimensionality.

## Best Possible Solution

Keep this as the canonical product/security item, define the opt-in media upload and retention contract, then implement approved attachment/PDF/video modalities with reindexing and provider-contract tests.
