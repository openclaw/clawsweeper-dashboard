## Summary

Keep open: current main and the latest release cover Gemini Embedding 2 text embeddings, output dimensionality, and opt-in image/audio files from extraPaths, but PDF/video modalities, mixed-media query input, and remembered inbound-attachment indexing remain missing and need product/security direction.

## What This Changes

Add Gemini Embedding 2 multimodal memory support, including media/attachment embedding, output dimensionality, and mixed-modal retrieval.

## Best Possible Solution
