## Summary

Keep open: current main ships the Gemini Embedding 2 prerequisite, output dimensionality, and opt-in image/audio indexing under `memorySearch.extraPaths`, but PDF/video modalities and remembered inbound-attachment indexing are still missing and need maintainer product/security direction.

## What This Changes

Request to expand `memorySearch` to use Gemini Embedding 2 multimodal embeddings for media and attachments, configurable output dimensionality, and text queries that can retrieve relevant media.

## Best Possible Solution

Keep the shipped image/audio `extraPaths` foundation, define the media upload and retention contract, then implement only maintainer-approved attachment/PDF/video modalities with reindexing, docs, provider-contract tests, and live Gemini proof.
