## Summary

Keep open: the shipped config note in the discussion is correct for Gemini Embedding 2, output dimensions, and opt-in image/audio files under `memorySearch.extraPaths`, but current main still lacks PDF/video modalities and remembered inbound attachment indexing.

## What This Changes

The issue requests Gemini Embedding 2 multimodal memory search for attachments and media, configurable output dimensions, and cross-modal retrieval from conversation history.

## Best Possible Solution

Keep the shipped image/audio `extraPaths` foundation, define an explicit media upload and retention contract, then implement only the maintainer-approved attachment/PDF/video modalities with reindexing, docs, provider-contract tests, and live Gemini proof.
