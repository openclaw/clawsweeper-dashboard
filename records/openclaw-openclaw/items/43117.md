## Summary

Keep open: current main and v2026.6.11 cover the Gemini Embedding 2 prerequisite, output dimensionality, and opt-in image/audio indexing under `memorySearch.extraPaths`, but the requested PDF/video modalities and remembered inbound-attachment indexing path remain missing and need product/security direction.

## What This Changes

The issue requests multimodal memorySearch support for Gemini Embedding 2, including embedding attachments, configurable output dimensionality, and text queries that can retrieve stored media.

## Best Possible Solution

Keep the shipped image/audio `extraPaths` foundation, define the retained-media upload and deletion contract, then implement only the approved PDF/video and attachment-memory scope with docs, reindex behavior, provider-limit tests, and live Gemini proof.
