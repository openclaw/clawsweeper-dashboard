## Summary

Keep open: current main and the latest release ship the Gemini Embedding 2 prerequisite, output dimensionality, and opt-in image/audio indexing under `memorySearch.extraPaths`, but the requested PDF/video modalities and remembered inbound-attachment indexing path are still missing.

## What This Changes

The issue requests Gemini multimodal memory search for media and attachments, configurable embedding dimensions, and cross-modal retrieval from conversation history.

## Best Possible Solution

Keep the shipped image/audio `extraPaths` foundation, define the media upload and retention contract, then implement only the maintainer-approved attachment/PDF/video modalities with reindexing, docs, provider-contract tests, and live Gemini proof.
