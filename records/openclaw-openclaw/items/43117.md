## Summary

Keep open: current main and v2026.6.11 already cover Gemini Embedding 2 text embeddings, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but PDF/video modalities and remembered inbound attachment indexing are still missing and need product/security direction.

## What This Changes

The issue requests Gemini Embedding 2 multimodal memory search for images, attachments, video, audio, PDFs, mixed-modal retrieval, and configurable output dimensionality.

## Best Possible Solution

Keep this as the canonical product/security tracker, define the opt-in media upload and retention contract, then implement the approved attachment/PDF/video modalities with reindexing, docs, provider-contract tests, and live Gemini proof.
