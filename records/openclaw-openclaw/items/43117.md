- `impact:session-state`: The request changes what conversation memory indexes and retrieves across sessions, including remembered media and attachments.

## Summary

Keep open: current main and the latest release already cover Gemini Embedding 2 text embeddings, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but PDF/video modalities and remembered inbound attachment indexing are still missing and need product/security direction.

## What This Changes

Request to extend `memorySearch` so Gemini Embedding 2 can embed and retrieve multimodal conversation content, add/confirm output dimensionality control, and support mixed-modal search results.

## Best Possible Solution

Keep this as the canonical product/security tracker, define the opt-in media upload and retention contract, then implement the approved attachment/PDF/video modalities with reindexing, docs, provider-contract tests, and live Gemini proof.
