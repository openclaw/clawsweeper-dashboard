## Summary

Keep open: current main and v2026.6.11 cover Gemini Embedding 2 preview, outputDimensionality, and opt-in image/audio files under extraPaths, but PDF/video modalities, mixed-media query inputs, current Gemini model migration, and remembered inbound-attachment indexing remain unresolved product/security work.

## What This Changes

The issue requests multimodal Gemini Embedding 2 support in memory search, including attachment/media indexing, mixed-modal queries, and configurable embedding dimensionality.

## Best Possible Solution

Keep the shipped image/audio extraPaths foundation, then split the remaining work into a maintainer-approved PDF/video modality contract, current Gemini model support, and a separate retained-attachment ingestion policy with explicit opt-in and lifecycle controls.
