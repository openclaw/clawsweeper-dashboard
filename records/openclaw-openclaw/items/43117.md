Keep open: current main implements Gemini Embedding 2 text embeddings, outputDimensionality, and opt-in image/audio indexing from extraPaths, but the requested attachment, PDF, video, and broader multimodal memory contract is still missing and security-sensitive.

## Best Possible Solution

Keep this as the canonical design tracker, define the opt-in media upload and retention contract, then implement approved PDF/video/attachment modalities on the existing memory-host and Gemini path with reindex and provider-contract tests.
