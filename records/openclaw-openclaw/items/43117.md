## Summary

Keep open: current main and the latest release cover Gemini Embedding 2, outputDimensionality, and opt-in image/audio files under extraPaths, but PDF/video modalities, mixed-media query inputs, and remembered inbound-attachment indexing remain missing and need product/security direction.

The issue asks memorySearch to use Gemini Embedding 2 for multimodal memory, including attachment/media embedding, output dimensionality, and mixed-modal retrieval.

## Best Possible Solution

Keep the shipped image/audio extraPaths foundation, then split the remaining work into a maintainer-approved PDF/video modality contract and a separate remembered-attachment ingestion policy.
