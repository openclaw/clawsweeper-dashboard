## Summary

Keep open: current main and v2026.6.11 ship Gemini Embedding 2, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but PDF/video support and remembered inbound-attachment indexing remain missing and need product/security direction.

## What This Changes

Request support for Gemini Embedding 2 multimodal memory search across attachments, images, video, audio, and PDFs, including output dimensionality and mixed-modal retrieval.

## Best Possible Solution

Keep this as the canonical design item, define the opt-in media upload, retention, redaction, provider-limit, and reindex contract, then implement the approved PDF/video and attachment modalities in the memory host and Google provider paths.
