## Summary

Keep open: current main and the latest release already include Gemini Embedding 2, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but the requested PDF/video support and remembered inbound-attachment indexing remain missing and need product/security direction.

## What This Changes

The issue requests Gemini Embedding 2 multimodal memory search support for attachments and mixed-modal queries, plus configurable embedding output dimensionality.

## Best Possible Solution

Keep this as the canonical product/security item, define the opt-in media upload and retention contract, then split implementation into approved PDF/video extraPaths support and a separate explicit remembered-attachment path if maintainers want it.
