## Summary

Keep open: current main and v2026.6.11 have the Gemini Embedding 2 provider path, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but the requested PDF/video support and remembered inbound attachment indexing are still missing and need product/security direction.

## What This Changes

The issue requests Gemini Embedding 2 multimodal memory search for media and attachments, configurable output dimensionality, and cross-modal memory retrieval.

## Best Possible Solution

Keep this as the canonical product/security tracker, define the opt-in media upload and retention contract, then implement the approved attachment/PDF/video modalities with reindexing, docs, and provider-contract tests.
