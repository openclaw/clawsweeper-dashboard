## Summary

Keep open: current main and the shipped release cover Gemini Embedding 2 text embeddings, output dimensionality, and opt-in image/audio indexing from `memorySearch.extraPaths`, but the requested PDF/video support and remembered inbound-attachment indexing remain outside the public memory contract.

## What This Changes

Request to extend `memorySearch` so Gemini Embedding 2 can embed and retrieve multimodal memory, including attachments, images, video, audio, PDFs, and configurable embedding dimensions.

## Best Possible Solution

Keep the shipped image/audio `extraPaths` foundation, then define a maintainer-approved contract for PDF/video modalities and a separate explicit remembered-attachment ingestion path with consent, retention, deletion, and provider-upload limits.
