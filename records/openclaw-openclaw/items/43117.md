## Summary

Keep open: current main and shipped releases cover Gemini Embedding 2, output dimensionality, and opt-in image/audio indexing from extraPaths, but the requested session-attachment, PDF, and video memory behavior remains missing and needs product/security direction.

## What This Changes

The issue requests Gemini Embedding 2 multimodal memory search for text, images, video, audio, PDFs, and attachments, with configurable output dimensions and mixed-modal retrieval.

## Best Possible Solution

Define a secure opt-in media-memory contract first, then implement the approved attachment/PDF/video modalities on the existing Gemini structured-input foundation with docs, schema, and upgrade-safe tests.
