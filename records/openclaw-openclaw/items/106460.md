## Summary

Keep this issue open: the beta report provides a precise, repeatable failure with exact gateway rejection text, and current documentation confirms that partial settings changes should use `config.patch` rather than resubmitting the entire redacted configuration.

## What This Changes

Make Control UI Context Profile Apply and Save update only the three profile-owned agent-default fields without resubmitting concealed SecretRefs, and show an inline operation result.

## Best Possible Solution

Route Context Profile Apply and Save through one hash-guarded `config.patch` containing only `agents.defaults.bootstrapMaxChars`, `agents.defaults.bootstrapTotalMaxChars`, and `agents.defaults.contextInjection`, then render a clear inline success or gateway error state.
