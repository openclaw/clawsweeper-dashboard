## What This Changes

Prevent Context Profile saves from resubmitting unrelated redacted SecretRef fields, and report save failures beside the profile controls.

## Best Possible Solution

Make Context Profile actions use the existing partial-update contract to write only `agents.defaults.bootstrapMaxChars`, `agents.defaults.bootstrapTotalMaxChars`, and `agents.defaults.contextInjection`, with an inline success or failure state and regression coverage for an unrelated redacted SecretRef.
