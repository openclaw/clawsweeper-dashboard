## Summary

([github.com](https://github.com/openclaw/openclaw/blob/main/extensions/telegram/src/button-types.ts))

## What This Changes

Adds diagnostic warnings and regression coverage when Telegram button conversion drops callback data exceeding the 64-byte limit.

## Best Possible Solution

Have final keyboard resolution report degradation only after it knows the selected keyboard, while preserving shared builder coverage and adding a structured caller-visible warning if maintainers choose that contract.
