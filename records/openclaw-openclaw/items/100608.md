## Summary

Keep open: current main has the provider usage/billing foundation from https://github.com/openclaw/openclaw/pull/100520, but it still exposes only quota windows, plan, balance/spend/budget summary fields for Anthropic/OpenAI rather than Admin API daily cost history, token/request totals, model mix, or cost categories. The protected maintainer label and the new Admin API/env/SDK/UI surface make this maintainer-owned design work rather than conservative cleanup.

## What This Changes

The issue requests provider-reported Anthropic and OpenAI Admin API cost history with daily spend, token/request totals, model breakdowns, and categories while preserving existing Claude/Codex subscription quota views.

## Best Possible Solution

Keep this as the maintainer-owned design target and implement a provider-neutral history contract with plugin-owned Anthropic/OpenAI Admin API fetchers, no new provider IDs, docs/tests, and Control UI rendering after credential precedence and sensitive-data handling are approved.
