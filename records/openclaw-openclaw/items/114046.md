## What This Changes

The PR validates xAI realtime voice WebSocket audio deltas before decoding them, reports malformed data through the existing error callback, and adds regression coverage.

## System Context

The bundled xAI plugin receives realtime voice events from the provider over a WebSocket and forwards decoded audio to OpenClaw Talk playback. This handler sits between untrusted provider event data and the host audio callback, so invalid deltas must be rejected before audio reaches playback.
