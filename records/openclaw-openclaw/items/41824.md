## Summary

Keep open: current main and v2026.6.11 still lack structural side-effect claim verification, and outbound message hooks still cannot reliably correlate delivery to an exact runId under concurrent same-session turns.

## What This Changes

The issue reports Telegram/source-chat turns where the agent claims file-write or message-send side effects completed even though no matching tool execution or target write occurred.

## Best Possible Solution

Keep claim-verification policy in a plugin/ClawHub package, and add only the smallest core exact-run outbound correlation seam if maintainers confirm plugins cannot safely verify concurrent turns today.
