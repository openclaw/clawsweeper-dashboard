## Summary

The requested TUI external-editor compose handoff is still missing on current main and the latest release. Keep this open because the remaining work is source-reproducible, adjacent long-prompt issues do not replace it, and maintainers still need to decide the shortcut or slash-command UX plus the local editor/temp-file security boundary.

## What This Changes

This issue requests a TUI composer mode that opens the current draft in `$VISUAL` or `$EDITOR`, then reloads the edited text without auto-submitting it.

## Best Possible Solution

Approve one guarded core TUI handoff that reuses the suspension pattern, opens a restrictive temporary markdown draft through `$VISUAL` then `$EDITOR` without unsafe shell parsing, reloads text without auto-submit, reports failures clearly, cleans up safely, and documents the approved trigger.
