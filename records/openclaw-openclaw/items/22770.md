## What This Changes

The issue requests a TUI compose mode that opens the current draft in $VISUAL or $EDITOR, then loads the edited multiline prompt back without auto-submitting.

## Best Possible Solution

Add a maintainer-approved core TUI compose handoff that suspends and restores the TUI, round-trips the current draft through a temporary markdown file via VISUAL then EDITOR, returns edited text without submitting, and documents clear error states.
