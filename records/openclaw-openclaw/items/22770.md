## Summary

Keep open: current main still lacks an active TUI external-editor compose handoff, and the open related items are adjacent long-prompt/editor requests rather than a replacement for this workflow.

## What This Changes

Add a core TUI compose mode that opens the current draft in `$VISUAL` or `$EDITOR`, reloads the edited text, and leaves submission manual.

## Best Possible Solution

Add one maintainer-approved core TUI handoff that safely suspends the TUI, writes a restrictive temporary markdown draft, launches the selected editor without shell ambiguity, reloads the draft without auto-submit, and documents the workflow.

## Reproduction Assessment

Yes. The missing capability is source-reproducible: current main has no active TUI external-editor trigger, `$VISUAL`/`$EDITOR` resolution path, temporary draft file handoff, or edited-draft restore path.

## Solution Assessment

Unclear until maintainers settle the shortcut or slash-command UX and local process/tempfile security contract. The core TUI composer is the right surface, but the safety rules need approval first.
