## What This Changes

## Best Possible Solution

Approve one guarded core TUI handoff with argv-safe editor resolution, restrictive temporary markdown drafts, cleanup, no auto-submit, clear errors, focused TUI tests, and public TUI docs; keep vi-mode and inline newline work separate.
