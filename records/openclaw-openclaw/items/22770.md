## Summary

Keep open: current main and v2026.6.11 still do not implement a TUI `$VISUAL`/`$EDITOR` compose handoff, and the related TUI long-prompt issues cover adjacent input modes rather than this exact workflow.

## What This Changes

The issue requests a TUI external editor compose mode that opens `$VISUAL` or `$EDITOR` on a temporary markdown prompt and reloads the edited text without auto-submitting.

## Best Possible Solution

Add one maintainer-approved core TUI handoff that safely suspends the TUI, writes a restrictive temporary markdown draft, launches the selected editor without auto-submit, reloads the draft, and documents the workflow.

## Reproduction Assessment

Yes. The missing capability is source-reproducible because current main has no active TUI external-editor trigger, `$VISUAL`/`$EDITOR` resolution path, temporary draft file handoff, or edited-draft restore path.

## Solution Assessment

Unclear until maintainers settle the UX and local process/tempfile security contract. The core TUI composer is the plausible implementation surface, but the shortcut and safety rules need explicit approval first.
