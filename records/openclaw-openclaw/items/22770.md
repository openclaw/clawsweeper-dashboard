## Summary

Keep open: current main and the latest release still lack an active TUI $VISUAL/$EDITOR compose handoff, and the related long-prompt/editor issues cover adjacent surfaces rather than this workflow.

## What This Changes

The issue requests a TUI external-editor compose mode that opens $VISUAL/$EDITOR for long prompt editing and loads the edited text back into the composer without auto-submitting.

## Best Possible Solution

Add one maintainer-approved core TUI compose handoff that safely suspends the TUI, writes a restrictive temporary markdown draft, launches the selected editor without auto-submit, reloads the draft, reports failures, and documents the workflow.

## Reproduction Assessment

Yes. Source inspection shows current main has no active TUI external-editor trigger, $VISUAL/$EDITOR resolution path, temporary draft file handoff, or edited-draft restore path.

## Solution Assessment

Unclear until maintainers settle the shortcut or slash-command UX and local process/tempfile security contract. The core TUI composer is the likely right surface, but the boundary is product-sensitive.
