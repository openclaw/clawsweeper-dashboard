## Summary

Keep open: current main and v2026.6.11 still lack the requested TUI $VISUAL/$EDITOR external-editor compose handoff, and the related composer/editor issues cover adjacent but different workflows.

## What This Changes

The issue requests a TUI compose mode that opens the current prompt in $VISUAL or $EDITOR, reloads the edited draft into the composer, and does not auto-submit it.

## Best Possible Solution

Approve one core TUI handoff that safely suspends the TUI, writes a restrictive temporary markdown draft, launches the selected editor without shell ambiguity or auto-submit, reloads the draft, reports failures clearly, and documents the workflow.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers settle the shortcut or command UX and the local process/tempfile security contract. The core TUI composer is the right surface if those boundaries are approved.
