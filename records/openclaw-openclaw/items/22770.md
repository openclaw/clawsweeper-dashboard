## Summary

Keep open: current main and the latest release still do not implement the requested TUI external-editor compose handoff, and related long-prompt/input-mode issues do not replace it. ## What This Changes

The issue requests a TUI compose mode that opens the current prompt in `$VISUAL` or `$EDITOR`, reloads the edited text into the composer, and does not auto-submit it.

## Best Possible Solution

Approve one guarded core TUI handoff that reuses the suspension pattern, launches an argv-safe `$VISUAL`/`$EDITOR` process, writes restrictive temporary drafts, reloads without auto-submit, reports failures clearly, cleans up, and documents the approved trigger.
