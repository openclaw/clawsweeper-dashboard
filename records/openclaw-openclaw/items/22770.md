## Summary

Keep open: current main and v2026.6.11 still lack an active TUI $VISUAL/$EDITOR compose handoff, and the related long-prompt/editor issues cover adjacent surfaces rather than this workflow.

## What This Changes

Request to add a TUI external-editor compose mode that writes the current draft to a temporary markdown file, opens $VISUAL or $EDITOR, restores the edited text into the composer, and leaves submission manual.

## Best Possible Solution

Add one maintainer-approved core TUI handoff that safely suspends the TUI, writes a restrictive temporary markdown draft, launches the selected editor without auto-submit, reloads the draft, and documents the workflow.

## Reproduction Assessment

Yes. The missing capability is source-reproducible: current main has no active TUI external-editor trigger, $VISUAL/$EDITOR resolution path, temporary draft handoff, or edited-draft restore path.

## Solution Assessment

Unclear until maintainers settle the shortcut or slash-command UX and local process/tempfile security contract. The core TUI composer is the right surface, but the exact safe behavior needs product and security signoff first.
