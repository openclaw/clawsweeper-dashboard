## Summary

Current main and latest release still lack the requested TUI external-editor compose handoff, so this issue remains necessary; the next blocker is maintainer approval for the trigger UX and local editor/temp-file security boundary.

## What This Changes

The issue requests a TUI compose mode that opens the current prompt in `$VISUAL` or `$EDITOR`, reloads the edited text into the composer, and does not auto-submit it.

## Best Possible Solution

Approve one guarded core TUI handoff that reuses the existing suspension pattern, creates restrictive temporary markdown drafts, launches the approved editor without unsafe shell parsing, reloads text without auto-submit, reports failures clearly, cleans up safely, and documents the chosen keybinding or command.
