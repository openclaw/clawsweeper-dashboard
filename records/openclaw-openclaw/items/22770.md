## Summary

Keep open: current main and the latest release still do not implement a TUI `$VISUAL`/`$EDITOR` compose handoff, and the related issues track adjacent long-prompt ergonomics rather than this external-editor flow.

## What This Changes

Add a TUI external-editor compose mode that writes the current composer text to a temporary markdown file, opens `$VISUAL` or `$EDITOR`, reloads the edited text, and leaves submission manual.

## Best Possible Solution

Approve one guarded core TUI handoff with argv-safe editor resolution, restrictive temporary markdown drafts, cleanup, no auto-submit, clear status errors, focused tests, and public TUI docs.
