## What This Changes

This PR broadens MCP bearer projection so `oauth.authProfileId` can resolve stored static token profiles as well as refreshable OAuth profiles, with documentation and focused tests.

## System Context

OpenClaw’s MCP client resolves an auth-profile identifier into a bearer credential for external HTTP or SSE MCP servers. CLI projection writes only a runtime environment placeholder into derived MCP configuration, while embedded clients apply the credential only to same-origin requests.
