## Summary

Keep this PR open for explicit maintainer product-direction review. The implementation and redacted current-head runtime trace support the intended no-literal-token flow, but extending OAuth-named `oauth.authProfileId` to authorize static bearer-token profiles creates a durable configuration and security contract that is broader than the existing OAuth lifecycle.

## What This Changes

This PR allows MCP HTTP/SSE bearer authentication to resolve stored `type: "token"` profiles as well as OAuth profiles, adds expiry fail-closed behavior, and documents projection and rotation behavior.

## System Context

OpenClaw’s MCP client configuration turns saved server definitions into CLI or embedded MCP connections. This change resolves an auth profile at connection/request time, then injects a bearer header without serializing the secret into the MCP configuration.
