## What This Changes

This PR adds a top-level MCP auth-profile selector that projects stored token or OAuth credentials as runtime bearer headers while retaining compatible legacy OAuth-nested configuration.

## System Context

MCP server definitions are consumed by embedded agent requests and CLI-managed MCP processes. This selector resolves a stored auth profile at runtime, projects its bearer credential only into the active request/process environment, and removes OpenClaw-only selector fields before downstream MCP configuration is serialized.
