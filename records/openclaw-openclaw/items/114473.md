## What This Changes

This PR lets an MCP server configured with an auth-profile reference project a `type: "token"` profile into its bearer header, while retaining refreshed OAuth access-token handling and rejecting unsupported profile types.

## System Context

MCP server configuration can reference an OpenClaw auth profile instead of storing a bearer secret directly in the server configuration. The resolver loads that profile, produces an environment-backed bearer value for the MCP client, and removes the auth-profile configuration from the launched client configuration.
