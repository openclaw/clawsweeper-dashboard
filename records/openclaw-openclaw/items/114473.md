## Summary

This PR remains necessary: it adds bearer projection for stored static token profiles while retaining OAuth projection and rejecting unsupported profile types. The prior documentation finding appears addressed, but the provided evidence is still test and review output rather than an after-fix MCP runtime connection or request trace, so it needs real behavior proof before merge.

## What This Changes

The PR lets MCP servers configured with `oauth.authProfileId` project a stored `type: "token"` credential into a bearer header, alongside existing OAuth-profile handling, and documents static-token expiry and rotation behavior.

## System Context

MCP client configuration can name an OpenClaw auth profile instead of storing an `Authorization` value in server config. Before an MCP CLI runtime or embedded same-origin request runs, the auth-profile layer resolves the credential and projects a bearer header while keeping the secret out of serialized configuration.
