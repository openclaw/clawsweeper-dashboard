## What This Changes

The issue asks for Web UI chat/sidebar images to remain consistently bounded instead of becoming oversized during longer conversations.

## Best Possible Solution

Resolve the sidebar CSS parity fix so sidebar markdown images use the same bounded dimensions as main chat markdown images, then close after browser proof or merge.

## Solution Assessment
