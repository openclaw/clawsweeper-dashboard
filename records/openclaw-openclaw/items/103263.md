## Label Justifications

- `P0`: The remaining removal path can delete an active agent run's checkout and in-flight files, making the core run unusable.
- `merge-risk: 🚨 availability`: A supported separate process can bypass the new lease and invalidate the cwd of a live run.

## Summary

The revision fixes the previously reported same-process GC race, but it does not protect an active run from supported removal in another OpenClaw process: the new lease is instance memory, while the run never takes the existing Git worktree lock that non-forced removers honor.

## What This Changes

The PR adds per-managed-worktree FIFO leases held across agent runs and destructive removal, including resolution from nested worktree paths.

## Best Possible Solution

Use one managed-worktree lifecycle primitive that resolves nested paths, reference-counts concurrent local users, queues same-process removal, and holds the existing Git worktree lock until the final active run releases it.
