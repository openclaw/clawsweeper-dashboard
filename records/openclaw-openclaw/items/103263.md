## Summary

The core approach matches the maintainer-directed design and the latest push fixes the prior removal-claim exclusivity blocker, but the PR is not merge-ready because failed persistent lease cleanup can become non-retryable and block worktree removal until process exit.

## What This Changes

This PR adds SQLite-backed shared run leases and token-owned exclusive removal claims for managed session worktrees, integrates lease admission into agent runs, and adds worktree lifecycle regression tests.

## Best Possible Solution

Keep the SQLite shared-reader and exclusive-removal design, but make lease release retryable and preserve the secondary guard until the token-owned persistent row is confirmed removed; add fault-injection coverage for failure followed by successful cleanup and removal.
