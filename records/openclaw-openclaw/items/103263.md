## What This Changes

The branch adds run-lifetime FIFO leases and reference-counted Git locks for managed session worktrees, rejects admission through removed checkouts, and adds service and composed race regressions.

## Best Possible Solution

Keep one service-owned lease around the full workspace-dependent run, serialize every managed-worktree removal through that owner, preserve unconditional outer cleanup, and handle the manual-GC caller omission as separate work.
