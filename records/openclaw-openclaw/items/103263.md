## Summary

Keep open because exact-head lease cleanup is not failure-safe: it can declare cleanup complete when the persistent owner token was not deleted, so the patch is not merge-ready despite strong real behavior proof and green CI.

## What This Changes

The PR adds SQLite-backed shared run leases and token-owned exclusive removal claims for managed session worktrees, integrates lease admission into agent runs, and adds worktree lifecycle race tests.

## Best Possible Solution

Keep the SQLite shared-reader and exclusive-removal design, but make lease release retryable and retain the secondary Git guard until the token-owned persistent row is confirmed removed, with fault-injection coverage for failure followed by successful cleanup and removal.
