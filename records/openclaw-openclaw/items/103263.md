## Summary

Keep this PR open for repair: the current head still allows a second live remover to replace the first removal claim and lets either path clear the other's ownership, so the stated exclusive-remover invariant is not enforced.

## What This Changes

This PR adds shared SQLite-backed run leases and removal claims to prevent active managed session worktrees from being removed during agent runs.

## Best Possible Solution

Return an opaque removal token, reject an existing live removal owner, and make abort and finalize conditional on that token while retaining dead-owner and reused-PID recovery.
