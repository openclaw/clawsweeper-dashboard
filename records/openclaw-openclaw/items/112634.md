## What This Changes

The PR triggers the chat composer’s existing render lifecycle after ArrowUp or ArrowDown successfully recalls draft history, with focused tests for both handled and unhandled key paths.

## System Context

The web chat composer receives keyboard navigation events and delegates recalled drafts to its existing history handler. A handled recall mutates the draft and schedules persistence; the render lifecycle then requests a Lit update so the textarea displays that draft immediately.
