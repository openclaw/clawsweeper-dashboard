## What This Changes

The PR invalidates the web chat composer’s render lifecycle after a handled ArrowUp or ArrowDown input-history recall and adds regression tests for handled and unhandled keys.

## System Context

The web chat composer routes keyboard events through history-navigation state that can mutate the draft directly. The render lifecycle then requests Lit to refresh the textarea so the stored draft and visible composer remain synchronized.
