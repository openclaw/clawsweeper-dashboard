## What This Changes

The PR invalidates the web chat composer’s render lifecycle after a handled ArrowUp or ArrowDown history recall and adds handled and unhandled-path regression tests.

## System Context

The web chat composer passes keyboard events to draft-history navigation, which can directly replace the saved draft text. The render lifecycle then asks Lit to update the textarea so the visible composer matches that changed draft.
