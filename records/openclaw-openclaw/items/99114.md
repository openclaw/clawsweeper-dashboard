## What This Changes

The branch imports `shortenHomePath` in `src/hooks/bundled/session-memory/handler.ts` and uses it for the two session-memory log path displays.

## Best Possible Solution

Land the narrow helper swap once hook-level proof or a maintainer override confirms the log output in a real session-memory run.

## Reproduction Assessment

Yes, source inspection gives a high-confidence reproduction path: current main formats the log path with `memoryFilePath.replace(os.homedir(), "~")`, so `/home/user2/...` with home `/home/user` becomes `~2/...`. I did not run the hook end-to-end in this read-only review.

## Solution Assessment

Yes, replacing the ad hoc `String.replace()` with the existing boundary-aware path display helper is the narrowest maintainable fix for a standalone path. A custom session-memory-only helper or `shortenHomeInString()` would add more surface or use the wrong string-wide behavior.
