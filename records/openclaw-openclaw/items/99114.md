## Best Possible Solution

Land the narrow helper swap after ordinary maintainer review, keeping broader path-output policy questions separate from this sibling-prefix corruption fix.

## Reproduction Assessment

Yes. Source inspection shows current main uses unbounded string replacement at both log display sites, so `/home/user2/...` is reproducibly mangled when `os.homedir()` is `/home/user`; I did not execute tests in this read-only review.

## Solution Assessment

Yes. Reusing the existing `shortenHomePath()` helper is the narrowest maintainable fix for a standalone filesystem path, while `shortenHomeInString()` or a new hook-local helper would be broader or duplicative.
