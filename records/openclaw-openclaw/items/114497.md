## What This Changes

This PR snapshots OpenClaw’s bundled-plugin package inventory at verifier initialization so later build filters cannot reduce the manifests checked in a published npm installation.

## System Context

The npm postpublish verifier inspects the artifacts placed in a published OpenClaw package, then checks runtime sidecars and bundled extension manifests before release publication is accepted. Build filtering feeds the artifact inventory; the verifier emits package-validation errors when required installed artifacts are absent.
