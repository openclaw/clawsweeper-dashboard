## Summary

Keep this PR open for normal maintainer merge review. The focused patch replaces Node’s permissive base64 decode with the shared plugin-SDK validator, retains both pre-decode and post-decode byte-limit checks, and includes convincing live module output showing malformed input is rejected without creating another saved file.

## What This Changes

The branch validates browser-proxy file base64 before decoding or persisting it, with a regression test for malformed payloads.

## System Context

The Browser plugin receives file payloads from a node-hosted browser proxy and persists them as local media before rewriting returned paths. This validation step sits between proxy output and the local media store so corrupted payloads do not become saved screenshots or downloads.
