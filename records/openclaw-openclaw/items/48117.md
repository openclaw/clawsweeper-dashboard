## What This Changes

Windows PowerShell hosted installer can fail during the default global npm install with a Node/npm TLS leaf-certificate verification error.

## Best Possible Solution

Ship a security-reviewed Windows installer recovery path that keeps strict TLS as the default and gives users an explicit CA/trust remediation flow when npm reports certificate verification failure.
