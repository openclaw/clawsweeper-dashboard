## Summary

Keep open: current main fixed the Feishu Drive list continuation half, but the info action still performs a single-page lookup and can falsely report an existing file as missing. The remaining behavior needs maintainer direction because Feishu bot credentials do not have a browsable root, so the durable fix should be an explicit folder-scoped contract rather than automatic root draining.

## What This Changes

The issue reports that Feishu Drive list/info actions ignore Drive API pagination, making later pages inaccessible and causing info lookups to report files past the first page as missing.

## Best Possible Solution

Keep the merged list pagination behavior, then land a Feishu-plugin-local info fix that accepts an explicit concrete folder scope, follows Drive cursors until the file is found or pages are exhausted, updates the skill, and adds focused proof.
