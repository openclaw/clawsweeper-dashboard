## Summary

Keep open: current main fixed Feishu drive `list` continuation in merged https://github.com/openclaw/openclaw/pull/101572, but `info` still performs a single first-page `drive.file.list` lookup and can still report `File not found` for later-page files.

## What This Changes

The issue requests Feishu drive pagination support for both `list` and `info`, including cursor continuation for folder listings and multi-page lookup for file metadata.

## Best Possible Solution

Add a Feishu-plugin-local, folder-aware `info` lookup path that paginates only within a concrete folder scope, preserves the merged list cursor behavior, and includes focused regression proof for later-page files.
