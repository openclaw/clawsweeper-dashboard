## Summary

Keep open: the merged current-main change fixes Feishu Drive `list` continuation, but `info` still performs a single `drive.file.list` request and can still report `File not found` before checking later pages. The remaining work is real, but it should pause for a maintainer-confirmed folder-scoped `info` contract because Feishu bot credentials do not have a browsable root.

## What This Changes

The issue requests Feishu Drive pagination support for folder listing and file info lookup so files beyond the first Drive API page remain accessible.

## Best Possible Solution

Define and implement a Feishu-plugin-local `info` lookup contract that paginates only within a concrete shared folder scope, keeps root behavior explicit, and adds focused regression plus SDK-boundary proof.
