## Summary

Keep open: https://github.com/openclaw/openclaw/pull/101572 fixed the `list` continuation half on current `main`, but `info` still calls `drive.file.list` once and throws `File not found` when the target is not on that first page.

## What This Changes

The issue asks Feishu drive `list` and `info` to honor Lark pagination so later pages are reachable and existing later-page files are not reported missing.

## Best Possible Solution

Define a Feishu-plugin-local, folder-scoped `info` lookup contract that paginates `drive.file.list` within a concrete folder, preserves the list continuation behavior already on main, and adds SDK-boundary regression proof for later-page files.

- **Leave token-only info unchanged:** Document that `info` is first-page/root-limited and rely on callers to use paginated `list` for folder traversal.
