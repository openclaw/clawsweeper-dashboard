## Summary

Keep this PR open: it fixes the prior silent-acknowledgement direction by retaining HTTP 429 for a sender that exceeds quota, but it changes the documented accepted-callback admission policy from one address-scoped budget to potentially many 30/minute sender budgets. That availability tradeoff needs an SMS owner decision and exact-head real webhook evidence before merge.

## What This Changes

The branch scopes signature-validated Twilio SMS dispatch quotas to the canonical `From` sender, while leaving the unauthenticated signature-disabled quota scoped to client address and updating tests and SMS documentation.

## Best Possible Solution

Adopt per-sender fairness only with an explicit, documented aggregate admission policy that bounds total validated webhook work per SMS account or route without restoring shared-egress cross-throttling, then add redacted exact-head live Twilio/Gateway evidence for normal delivery, sender-specific overload, and recovery.
