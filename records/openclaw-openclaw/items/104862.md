## Summary

Keep this PR open: sender-scoped fairness addresses the reported cross-throttling, but the patch still removes any bounded aggregate admission policy for validated SMS callbacks, and the external PR has only test-based proof rather than an exact-head live Twilio/Gateway result.

## What This Changes

The branch changes validated Twilio SMS webhook dispatch limiting from resolved client address to canonical sender identity, retains client-address limiting when signature validation is disabled, and updates SMS webhook tests and documentation.

## Best Possible Solution

Preserve sender fairness with a canonical-sender quota, but pair it with a bounded post-validation account-and-route aggregate admission cap selected by the SMS owner, keep HTTP 429 for rejected callbacks, and add a multi-sender fan-out regression before merging.
