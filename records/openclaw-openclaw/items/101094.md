- **[P1] Store dashboard state in SQLite:** `extensions/dashboard/src/store.ts:70-73`
  - body: This constructor creates OpenClaw-owned runtime state as `workspace.json` plus an undo JSON ring under `stateDir/dashboard`. Root policy expects runtime state, registries, checkpoints, and plugin scratch data to live in SQLite unless they are named artifacts; the nearby Workboard plugin uses SQLite. Please move the workspace and undo model to the canonical SQLite/plugin-state shape before merge.
  - confidence: 0.93
- **[P2] Keep undo workspace versions monotonic:** `extensions/dashboard/src/store.ts:141-146`
  - body: `undo()` writes the saved snapshot back verbatim, including its older `workspaceVersion`. After versions 1 -> 2 -> 3, undo can broadcast version 2 again, so clients that use the version to ignore stale refetches can miss the undo; restore through a normal mutation or assign a fresh current+1 version.
  - confidence: 0.88
- **[P2] Derive gateway actors from trusted context:** `extensions/dashboard/src/gateway.ts:83-89`
  - body: Every gateway write can still accept `actor` from params, so any `operator.write` caller can stamp `user`, `system`, or `agent:*` provenance and approval broadcasts. The agent tools already derive actor from tool context; the gateway path should derive provenance from trusted request/client context instead.
  - confidence: 0.86
