## Summary

This remains a useful, narrow Windows regression fix. The submitted head replaces locale-dependent error-text matching with the Task Scheduler’s numeric state and confines idempotent success to disabled or ready tasks; the provided native Windows proof and focused tests support normal maintainer review rather than cleanup closure.

## What This Changes

The PR makes Windows Scheduled Task stopping locale-independent by checking the Task Scheduler COM state after a failed `schtasks /End` command and adds regression tests for inactive and fail-closed states.

## System Context

The Windows gateway lifecycle stops OpenClaw through a registered Scheduled Task, then reports a successful mutation so surrounding restart and cleanup flows can continue. A failed `schtasks /End` result now passes through a read-only Task Scheduler state check before it can be considered an idempotent stop.

Land the narrow numeric-state interpretation only with the current fail-closed state matrix preserved, so localized inactive-task errors no longer block stop/update while ambiguous task states remain visible to operators.
