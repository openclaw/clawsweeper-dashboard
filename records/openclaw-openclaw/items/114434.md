## What This Changes

This PR makes Windows Scheduled Task stopping locale-independent by treating a failed `/End` call as already stopped only when the Task Scheduler state probe reports the task is disabled or ready.

## System Context

OpenClaw’s Windows gateway lifecycle uses `schtasks` to start and stop its registered Scheduled Task, then reports the completed mutation to the surrounding daemon flow. This change affects the error-recovery decision after Task Scheduler rejects an `/End` request, before cleanup and mutation reporting continue.
