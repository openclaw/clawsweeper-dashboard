## What This Changes

Replaces English-text matching after a failed Windows Scheduled Task stop with a locale-independent Task Scheduler state probe, plus focused stop-path coverage.

## System Context

OpenClaw uses a Windows Scheduled Task to run the Gateway. The daemon asks `schtasks` to end that task, then performs gateway cleanup; this change decides whether a nonzero stop result is an expected idle-task outcome or a real failure.
