## What This Changes

This PR replaces English-only matching of a failed Windows Scheduled Task stop response with a Task Scheduler COM state probe that accepts only disabled or ready tasks as already inactive.

## System Context

OpenClaw's Windows gateway lifecycle code starts and stops the background Gateway through a registered Scheduled Task. The stop operation calls `schtasks`, then either records a successful stop or surfaces an error to the operator.
