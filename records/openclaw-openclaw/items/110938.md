## Summary

This PR addresses a real Reef delivery-observability gap, but the current patch can send misleading or misrouted owner notices in three concrete delivery states. Keep it open for a bounded repair and maintainer review of the notification contract.

## What This Changes

Adds persisted overdue-delivery tracking, periodic owner notices for Reef sends without receipts, a late-delivery follow-up, focused tests, and Reef delivery-outcome documentation.

## Best Possible Solution

Keep the receipt binding separate from delivery-notice eligibility: notify only for accepted or explicitly ambiguous relay outcomes, route every follow-up through the original peer session with wake behavior, and give rotated-key records a safe neutral owner notice instead of silently excluding them.
