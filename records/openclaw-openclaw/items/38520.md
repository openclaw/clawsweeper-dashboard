## Summary

Keep open: current main has adjacent compaction notices, silent memoryFlush, lifecycle hooks, checkpoint metadata, and internal background maintenance, but it still lacks the requested configurable pre-threshold agent warnings, structured handoff turn, and agent-requested bounded deferral contract. This remains product and security-boundary design work, not conservative cleanup.

## What This Changes

Request adds pre-compaction threshold warnings, a structured handoff turn, and bounded compaction deferral for long-running agent sessions.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hooks, and checkpoints, adding warning, handoff, or deferral only with explicit timeout, audit, scope, and authorization rules.
