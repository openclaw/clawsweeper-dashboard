## Summary

Keep open: current main has adjacent memory flush, user compaction notices, lifecycle hooks, and session checkpoint infrastructure, but it still lacks the requested configurable pre-threshold warning policy, structured handoff/checkpoint turn, and bounded agent-requested deferral. This remains product and security-boundary design work, not a conservative cleanup close.

## What This Changes

Request configurable pre-compaction warning events, a structured handoff/checkpoint turn, and bounded compaction deferral for long-running agent workflows.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hooks, and checkpoints, adding opt-in warning, handoff, or deferral only with explicit timeout, audit, workspace scope, and authorization rules.
