## Summary

Keep open: current main and the latest release have adjacent compaction notices, memoryFlush, lifecycle hooks, and checkpoint metadata, but they still lack the requested pre-threshold warning policy, structured handoff turn, and agent-requested bounded deferral.

## What This Changes

The issue requests configurable pre-compaction warnings, a structured handoff/checkpoint turn, and a bounded compaction deferral mechanism for long-running agent workflows.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hooks, and checkpoints, adding warning, handoff, or deferral only with explicit timeout, audit, scope, and authorization rules.
