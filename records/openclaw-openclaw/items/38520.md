## What This Changes

The issue requests configurable pre-compaction warning thresholds, a structured handoff turn, and a bounded agent deferral mechanism before compaction proceeds.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hook, and checkpoint boundaries, adding opt-in warning or handoff behavior only with explicit timeout, audit, workspace scope, and approval-expiry rules.
