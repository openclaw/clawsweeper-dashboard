## Summary

Keep open: current main has adjacent memory flush, user compaction notices, immediate compaction hooks, and checkpoint metadata, but it still lacks the requested pre-threshold warning policy, structured handoff turn, and bounded agent-requested deferral.

## What This Changes

Request to add configurable pre-compaction warning events, a structured pre-compaction handoff turn, and bounded agent-requested compaction deferral.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hooks, and checkpoints, adding warning, handoff, or deferral only with explicit timeout, audit, workspace scope, and authorization rules.
