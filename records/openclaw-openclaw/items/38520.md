## Summary

Keep open: current main and the latest release still only provide adjacent compaction notices, memoryFlush, immediate compaction hooks, and checkpoint metadata; they do not implement configurable pre-threshold warning events, a structured pre-compaction handoff window, or bounded agent-requested compaction deferral.

## What This Changes

The issue requests configurable pre-compaction warning events, a structured pre-compaction handoff turn/checkpoint window, and bounded compaction deferral for long-running agent workflows.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing checkpoints, hooks, memoryFlush, and notifyUser where they fit, then add only narrow opt-in warning, handoff, or deferral surfaces with explicit audit and security policy.
