## Summary

Keep open: current main and v2026.6.11 still only provide adjacent compaction notices, silent memoryFlush, immediate lifecycle hooks, and transcript-boundary checkpoints; they do not implement configurable pre-threshold warning events, a structured agent handoff turn, or an agent-requested bounded deferral mechanism.

## What This Changes

Issue #38520 requests configurable pre-compaction warning thresholds, a structured pre-compaction handoff turn, and a bounded compaction deferral tool for long-running sessions.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing checkpoints, hooks, memoryFlush, and notifyUser where they fit, then add only narrow opt-in warning, handoff, or deferral surfaces with explicit audit and security policy.

## Reproduction Assessment

Not applicable as a runtime bug; source inspection confirms the requested warning, handoff, and deferral surfaces are absent on current main while adjacent compaction lifecycle features exist.

## Solution Assessment

Unclear as proposed; adding all knobs directly is not yet proven best, and the maintainable path is one lifecycle design that names deferral/security policy and reuses existing compaction surfaces.
