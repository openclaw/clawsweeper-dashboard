## Summary

## What This Changes

The issue requests configurable pre-compaction warning events, a structured pre-compaction handoff turn, and bounded deferral for short critical sections.

## Best Possible Solution

Define one maintainer-approved pre-compaction lifecycle contract that reuses existing hooks, memoryFlush, notices, and checkpoint metadata where possible, and only then add any public config, handoff turn, deferral API, docs, and regression coverage.
