## Summary

Keep open: current main has adjacent compaction notices, memoryFlush, hook events, and checkpoint metadata, but it still lacks the requested pre-threshold warning policy, structured handoff window, and bounded agent-requested deferral. The June 23 checkpoint comment usefully sharpens the security boundary: a handoff summary, continuity checkpoint, and future authorization must stay separate.

## What This Changes

The issue requests configurable pre-compaction warning events, a structured pre-compaction handoff turn, and bounded compaction deferral for long-running agent sessions.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses the existing memoryFlush, notifyUser, hook, and checkpoint boundaries, adding opt-in warnings or handoff only with explicit timeout, audit, workspace scope, and approval-expiry rules.
