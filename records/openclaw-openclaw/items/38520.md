## Summary

Keep open for a maintainer product and security decision. Current main already provides a configurable soft-threshold memory-flush turn, user-facing start/complete notices, persisted compaction summaries, and compaction hooks, but it does not define the requested threshold-warning policy, visible handoff turn, or bounded agent-authorized deferral contract. The proposed deferral must not silently preserve tool authority across a compaction boundary.

## What This Changes

Add configurable pre-compaction warnings, an agent handoff opportunity, and a time-bounded deferral mechanism for long-running sessions.

## System Context

OpenClaw’s Gateway tracks each agent session, invokes a pre-compaction memory flush near context pressure, then writes a compaction summary and continues the next turn from the summary plus recent tail. The requested behavior would add policy and lifecycle controls between context-pressure detection and that persistent session transition.

## Architecture Diagram

flowchart LR
  A[Session transcript and context usage] --> B[Context pressure detection]
  B --> C[Memory flush turn]
  C --> D[Compaction lifecycle policy]
  D --> E[Summary and session checkpoint]
  E --> F[Next agent turn]
  D --> G[Plugin and security hooks]

## Best Possible Solution

Decide whether OpenClaw needs a narrowly scoped, audited compaction-policy API; if so, define bounded deferral, checkpoint validity, and authority-reset rules before adding any user config or agent tool.
