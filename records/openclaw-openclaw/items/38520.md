## Summary

Keep open: current main has adjacent compaction notices, memoryFlush, lifecycle hooks, and checkpoint metadata, but it still lacks the requested pre-threshold warning policy, structured handoff turn, and agent-requested bounded deferral. This is still product and security-boundary design work, not conservative cleanup.

## What This Changes

The issue requests configurable pre-compaction warning events, a structured pre-compaction handoff turn, and a bounded compaction deferral mechanism for long stateful agent workflows.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hooks, and checkpoints, adding warning, handoff, or deferral only with explicit timeout, audit, scope, and authorization rules.
