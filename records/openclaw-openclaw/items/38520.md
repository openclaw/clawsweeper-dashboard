## Summary

Keep open: current main has adjacent compaction hooks, silent memoryFlush, brief user notices, pre-prompt overflow routing, and compaction checkpoints, but it still lacks the requested threshold warning policy, structured handoff window, and bounded agent-requested deferral mechanism.

## What This Changes

The issue requests configurable pre-compaction warnings, a structured handoff turn for preserving critical state, and bounded agent-requested compaction deferral.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, session_before_compact/session_compact hooks, and checkpoint metadata where possible, then add only the minimal schema/runtime/docs/tests needed for warning, handoff, and deferral semantics.
