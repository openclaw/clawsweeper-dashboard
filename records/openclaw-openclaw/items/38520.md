## Summary

Keep open: current main has adjacent memoryFlush, notifyUser, compaction hooks, context-engine maintenance, and checkpoint infrastructure, but it still lacks the requested pre-threshold warning policy, structured handoff turn, and agent-requested bounded deferral contract.

## What This Changes

The issue requests configurable pre-compaction warning events, a structured pre-compaction handoff turn, and a bounded compaction deferral mechanism for long-running agent workflows.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses current memoryFlush, notifyUser, hooks, and checkpoints, and add only the warning, handoff, or deferral pieces whose timeout, audit, scope, and authorization rules are explicit.
