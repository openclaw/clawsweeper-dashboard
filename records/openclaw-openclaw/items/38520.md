## Summary

Keep open: current main has adjacent memory flushes, user compaction notices, hooks, and checkpoint metadata, but it still lacks the requested pre-threshold warning policy, structured handoff turn, and agent-requested bounded deferral.

## What This Changes

The issue asks for configurable pre-compaction warnings, a structured handoff/checkpoint turn, and a bounded agent deferral mechanism before automatic compaction proceeds.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hooks, and checkpoints, adding warning, handoff, or deferral only with explicit timeout, audit, workspace scope, and authorization rules.
