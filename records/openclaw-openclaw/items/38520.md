## Summary

Keep open: current main has adjacent memoryFlush, notifyUser, precheck, hook, and checkpoint surfaces, but it still lacks the requested pre-threshold warning policy, structured handoff turn, and bounded agent deferral contract.

## What This Changes

The issue requests configurable pre-compaction warnings, an agent handoff window, and a bounded compaction deferral mechanism for long stateful sessions.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hook, precheck, and checkpoint boundaries, adding warning or handoff behavior only with explicit timeout, audit, workspace scope, and approval-expiry rules.
