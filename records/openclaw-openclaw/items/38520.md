## What This Changes

The issue requests configurable pre-compaction warnings, a structured handoff turn that can persist state, and a bounded/audited compaction-deferral mechanism.

## Best Possible Solution

Design one canonical compaction lifecycle that exposes only the necessary warning and handoff hooks, then decide whether any bounded deferral can be safely represented as an expiring, non-authorizing checkpoint rather than a general continuation permission.
