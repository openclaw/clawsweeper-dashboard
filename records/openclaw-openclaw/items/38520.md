## Summary

Keep open: current main and the latest release still have only adjacent memoryFlush, notifyUser, hook, precheck, and checkpoint surfaces; the requested threshold warning policy, structured handoff window, and bounded agent deferral contract remain missing and are not fully owned by another open tracker.

## What This Changes

The issue requests pre-compaction warning events, a structured pre-compaction handoff turn, and a bounded compaction deferral mechanism for long stateful agent workflows.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses existing memoryFlush, notifyUser, hook, precheck, and checkpoint boundaries, adding warning or handoff behavior only with explicit timeout, audit, workspace scope, and approval-expiry rules.

Options:

- **Adopt Warning And Checkpointed Handoff First (recommended):** Add opt-in threshold warnings plus a structured handoff/checkpoint path while leaving agent-requested deferral out until authority semantics are settled.
- **Adopt Full Bounded Deferral:** Allow ALLOW/BLOCK/DEFER semantics only with explicit max duration, audit trail, idempotent checkpoint matching, workspace scope, and approval-expiry rules.
- **Decline New Lifecycle Surface:** Keep memoryFlush, notifyUser, hooks, precheck recovery, and checkpoint APIs as the supported compaction surfaces and document recovery patterns.
