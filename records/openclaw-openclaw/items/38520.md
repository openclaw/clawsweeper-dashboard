Keep open: current main and v2026.6.11 still lack the requested pre-threshold warning policy, structured handoff turn, and agent-requested bounded deferral, while the existing memoryFlush, notifyUser, hook, and checkpoint surfaces only cover adjacent pieces. ## What This Changes

The issue requests pre-compaction warning events, a structured pre-compaction handoff window, and a bounded compaction deferral mechanism for long-running agent sessions.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses memoryFlush, notifyUser, hook, and checkpoint boundaries, adding opt-in warning or handoff behavior only with explicit timeout, audit, workspace scope, and approval-expiry rules.
