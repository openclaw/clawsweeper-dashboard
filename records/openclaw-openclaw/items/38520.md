## Summary

Keep open: current main has adjacent memoryFlush, notifyUser, compaction hooks, and checkpoint support, but it still lacks the requested configurable pre-threshold warning policy, structured pre-compaction handoff turn, and agent-requested bounded deferral contract.

## What This Changes

The issue requests configurable pre-compaction warning thresholds, a structured handoff turn before compaction, and a bounded `compaction_defer` mechanism for short critical sections.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses current memoryFlush, notifyUser, hooks, and checkpoints, and add only the warning, handoff, or deferral pieces whose timeout, audit, scope, and authorization rules are explicit.
