## Summary

Keep open: current main and v2026.6.11 have adjacent compaction notices, memoryFlush, lifecycle hooks, deferred context-engine maintenance, and checkpoint metadata, but they still do not implement configurable pre-threshold warning events, a structured handoff turn, or agent-requested bounded compaction deferral. This remains product/security design work rather than conservative cleanup.

## What This Changes

The issue requests configurable pre-compaction warning events, a structured handoff/checkpoint turn, and bounded compaction deferral for long-running agent sessions.

## Best Possible Solution

Define one maintainer-approved compaction lifecycle contract that reuses notifyUser, memoryFlush, compact hooks, and checkpoint metadata where they fit, then add only narrow opt-in warning, handoff, or deferral surfaces with explicit audit and security policy.

## Reproduction Assessment

Not applicable: this is a feature/design request rather than broken existing behavior. Source inspection confirms the requested warning, handoff, and deferral surfaces are absent on current main while adjacent compaction lifecycle features exist.

## Solution Assessment

Unclear as proposed; adding all knobs directly is not yet proven to be the best solution. The maintainable path is a maintainer-approved lifecycle design that names the deferral/security policy and reuses existing compaction surfaces where possible.
