## Summary

Keep open: current main and latest release still do not expose a Bedrock config path for custom `anthropic_beta` or other Converse `additionalModelRequestFields`, and the remaining choice is the public provider config contract shape.

## What This Changes

Request to let Amazon Bedrock model config pass custom `anthropic_beta` or `additionalModelRequestFields` so users can opt into Claude Bedrock beta features such as 1M context.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field contract with docs, merge and de-duplication tests for `anthropic_beta`, and redacted live Bedrock proof before landing.

## Solution Assessment

Unclear until maintainers choose the config contract. A Bedrock-owned request-field merge path looks maintainable, but the exact breadth of that public surface needs maintainer approval.
