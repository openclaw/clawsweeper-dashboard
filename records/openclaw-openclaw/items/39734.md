## Summary

Keep open: current main and v2026.6.11 still lack a configurable Bedrock `anthropic_beta` or generic `additionalModelRequestFields` merge path, and the remaining blocker is choosing the public provider config contract.

## What This Changes

The issue requests a Bedrock model-config path for custom `anthropic_beta` flags so Claude beta features can be passed through `additionalModelRequestFields` without patching provider code.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or deliberately choose a narrower typed `anthropicBeta` or `context1m` option, with docs, merge/dedup tests, and redacted live Bedrock Converse proof.
