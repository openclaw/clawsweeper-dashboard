## Summary

Keep open: current main and the latest release still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and all related implementation PRs for this Bedrock gap are closed unmerged.

## What This Changes

The issue requests a Bedrock model-config path for custom Anthropic beta flags so users can pass Bedrock Converse `additionalModelRequestFields.anthropic_beta` without patching provider code.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, focused tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.

Options:

- **Add only typed beta config:** Support a narrow Bedrock `anthropicBeta` or `context1m` path for Claude long context while avoiding arbitrary Converse body passthrough.
- **Decline custom betas:** Keep Bedrock request shaping internal and require first-class provider support for each beta feature before OpenClaw sends it.

## Solution Assessment

Unclear. A configurable Bedrock request-field path is plausible, but maintainers should choose the public config contract before implementation because this expands provider-owned request surface.
