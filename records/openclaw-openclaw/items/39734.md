## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-owned config path to merge custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining choice is the public provider config contract.

## What This Changes

Allow Bedrock model configuration to provide custom `anthropic_beta` values for Claude beta features.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower typed `anthropicBeta` option, with docs, focused merge/dedup tests, and redacted live Bedrock proof.
