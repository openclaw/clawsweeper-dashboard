## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-owned way to merge custom `anthropic_beta` values or generic `additionalModelRequestFields`; the remaining blocker is maintainer choice of the public provider config contract.

## What This Changes

The issue requests configurable Bedrock Anthropic beta flags, such as `context-1m-2025-08-07`, from model config into Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower typed `anthropicBeta` option, with docs, focused merge/dedup tests, and redacted live Bedrock proof.
