## Summary

Keep open: current `main` and the latest release still lack a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining fix is a provider config contract decision.

## What This Changes

The issue requests a Bedrock model-config path for custom `anthropic_beta` flags so users can opt into Bedrock Claude beta features without patching provider code after upgrades.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract with docs and focused tests for `anthropic_beta` merge/de-duplication, then back it with redacted live Bedrock proof before landing.
