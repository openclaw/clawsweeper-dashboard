## Summary

Keep open: current main and the latest release still lack a Bedrock-owned config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining question is the public provider config contract rather than whether the source gap exists.

## What This Changes

The issue asks OpenClaw to let Bedrock model config specify custom `anthropic_beta` flags and merge them into the Bedrock Converse `additionalModelRequestFields` payload.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field or beta merge contract with schema validation, docs, tests for merging and invalid shapes, and redacted live Bedrock proof before landing.
