## Summary

Keep open: current main and v2026.6.11 still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining blocker is the public provider config contract.

## What This Changes

The issue asks for a Bedrock model configuration path that can pass custom Anthropic beta flags into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-backed request-field or beta merge contract with docs, focused merge/de-duplication tests, and redacted live Bedrock proof before landing.
