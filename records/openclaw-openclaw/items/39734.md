## Summary

Keep open: current main and the latest release still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining choice is the public provider config contract rather than stale cleanup.

## What This Changes

The issue requests a configurable Bedrock passthrough for Anthropic `anthropic_beta` flags so users can enable Bedrock-only beta request fields without patching provider output.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, focused tests for `anthropic_beta` merge/de-duplication, and redacted live Bedrock proof before landing.
