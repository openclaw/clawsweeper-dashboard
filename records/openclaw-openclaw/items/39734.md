## Summary

Keep open: current main and v2026.6.11 still lack a configurable Bedrock `anthropic_beta` or generic `additionalModelRequestFields` merge path, and the remaining blocker is choosing the public provider config contract.

## What This Changes

Request to let Bedrock model config pass custom `anthropic_beta` or `additionalModelRequestFields` values into Converse payloads instead of patching provider code after upgrades.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or deliberately choose a narrower typed `anthropicBeta`/`context1m` option, with docs, merge/dedup tests, and redacted live Bedrock Converse proof.
