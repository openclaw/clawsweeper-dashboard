## Summary

Keep open: current main and v2026.6.11 still lack a configurable Bedrock `anthropic_beta` or generic `additionalModelRequestFields` merge path, and the remaining blocker is choosing the public provider config contract.

## What This Changes

Request configurable Bedrock Converse `anthropic_beta` or provider request fields from model config so users can opt into dated Anthropic beta flags without patching provider code.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or choose a deliberately narrower typed `anthropicBeta`/`context1m` option, with docs, merge/dedup tests, and redacted live Bedrock Converse proof.
