## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-owned config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining choice is a public provider-config contract decision rather than stale cleanup.

## What This Changes

The issue requests a Bedrock model-config mechanism for forwarding custom Anthropic beta flags into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract with documented precedence, `anthropic_beta` de-duplication, focused tests, and redacted live Bedrock proof before landing.
