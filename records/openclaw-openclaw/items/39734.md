## Summary

Keep open: current main and the latest release still have no Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, while the related implementation PRs are closed or only solve direct Anthropic behavior.

## What This Changes

Request to let Amazon Bedrock model configuration pass custom Anthropic beta flags into Converse `additionalModelRequestFields`, especially for long-context Claude models.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
