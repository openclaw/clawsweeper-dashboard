## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-owned config path to merge custom `anthropic_beta` or generic `additionalModelRequestFields`, while current Bedrock discovery can advertise 1M Claude context windows that may require that request-field flag.

## What This Changes

The issue requests a per-model Bedrock config mechanism for forwarding custom `anthropic_beta` flags into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract with docs, focused tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
