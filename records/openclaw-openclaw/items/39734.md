## Summary

Keep open: current main and v2026.6.11 still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`; the source gap is clear, but the fix needs maintainer choice on the public provider contract.

## What This Changes

The issue requests a Bedrock model configuration path for custom Anthropic beta flags so users can pass `anthropic_beta` via Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Choose a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower `anthropicBeta` option, then add docs, merge/dedup tests, and redacted live Bedrock proof without putting generic passthrough policy in core.
