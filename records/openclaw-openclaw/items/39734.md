Request to support custom Anthropic beta flags in the Amazon Bedrock provider by merging configured fields into Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower typed `anthropicBeta` option, with docs, merge/dedup tests, and redacted live Bedrock proof.
