## Summary

Keep open: current main still lacks a Bedrock-owned config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining question is the public provider config contract rather than whether the source gap exists.

## What This Changes

The issue requests a configurable Bedrock provider path for custom `anthropic_beta` flags so Bedrock Converse request fields can be passed without patching installed provider code.

## Best Possible Solution

Add a Bedrock-plugin-owned, validated request-field merge contract with schema/docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
