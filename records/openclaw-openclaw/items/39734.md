## Summary

Keep open: current main and the latest release still lack a Bedrock config path for custom `anthropic_beta` or generic Converse `additionalModelRequestFields`, and the remaining decision is the public Bedrock provider config contract.

## What This Changes

The issue requests a configurable Bedrock Anthropic beta/request-field passthrough so users can send values such as `anthropic_beta` in Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-backed request-field or beta merge contract with docs, focused merge/de-duplication tests, and redacted live Bedrock proof before landing.

Unclear. The requested configurable passthrough is plausible, but maintainers should choose the public Bedrock config contract before implementation because it expands provider-owned request surface.
