## Summary

Keep open: current main and the latest release still lack a Bedrock-owned config path to merge custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining blocker is choosing the public provider config contract.

## What This Changes

The issue requests a Bedrock provider config path for user-specified Anthropic beta flags such as `anthropic_beta` in Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, focused tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
