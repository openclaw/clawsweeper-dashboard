Keep open: current main and v2026.6.11 still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining choice is the provider config contract maintainers want.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract with docs, focused tests for `anthropic_beta` merging, and redacted live Bedrock proof before landing.
