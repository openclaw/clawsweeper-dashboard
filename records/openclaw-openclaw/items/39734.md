## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-configurable `anthropic_beta` or generic `additionalModelRequestFields` merge path, and the remaining decision is the public provider config contract.

## What This Changes

The issue requests a Bedrock model configuration path for custom Anthropic beta flags so they can be merged into Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or deliberately choose a narrower typed `anthropicBeta`/`context1m` option, with docs, merge/dedup tests, and redacted live Bedrock proof.

Unclear until maintainers choose the public config contract. A Bedrock-owned validated merge path is the flexible fix, while a narrower typed option is safer if broad passthrough is not desired.
