## Summary

Keep open: current main and v2026.6.11 still lack a configurable Bedrock `anthropic_beta` or generic `additionalModelRequestFields` merge path, and the remaining blocker is choosing the public Bedrock provider config contract.

## What This Changes

The issue requests a configurable way to pass Anthropic Bedrock beta flags into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or deliberately choose a narrower typed `anthropicBeta` or `context1m` option, with docs, merge/dedup tests, and redacted live Bedrock Converse proof.
