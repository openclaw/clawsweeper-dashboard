## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-owned config path to merge custom `anthropic_beta` values or generic `additionalModelRequestFields`; the remaining blocker is maintainer choice of the public provider config contract.

## What This Changes

Request a Bedrock model/provider config path to merge custom `anthropic_beta` values into Converse `additionalModelRequestFields` so users can opt into Bedrock-only Anthropic beta features such as 1M context.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower typed beta option, with docs, focused merge/dedup tests, and redacted live Bedrock proof.

- **Decline custom beta config:** Keep beta flags internal and require users to wait for first-class provider features instead of sending custom vendor request fields.

## Solution Assessment
