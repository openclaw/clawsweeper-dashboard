## Summary

Keep open: current `main` and the latest release still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and all related Bedrock fix PRs found are closed unmerged.

## What This Changes

Request support for configuring Bedrock Anthropic beta flags so OpenClaw can pass them through as Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, validation, tests for `anthropic_beta` merging and coexistence with reasoning fields, plus redacted live Bedrock proof before landing.
