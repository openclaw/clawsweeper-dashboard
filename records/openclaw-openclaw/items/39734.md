## Summary

Keep open: current `main` and v2026.6.11 still lack a configurable Bedrock `anthropic_beta` or generic `additionalModelRequestFields` merge path, and the remaining blocker is choosing the public provider config contract.

## What This Changes

The issue requests a Bedrock model-config mechanism for custom Anthropic beta flags, especially `context-1m-2025-08-07`, so users do not patch provider build output after upgrades.

## Best Possible Solution

Define a Bedrock-owned, documented request-field contract that can safely merge Anthropic beta flags into Converse requests, with focused tests for fresh config, upgrade behavior, and preservation of existing reasoning beta behavior.
