## Summary

Keep open: current main and the latest release still lack a Bedrock-owned config path to merge custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining choice is the public provider config contract.

## What This Changes

The issue requests a Bedrock model-config path for custom Anthropic beta flags, especially `anthropic_beta` values passed through `additionalModelRequestFields` for Claude 1M context on Bedrock.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower typed `anthropicBeta` option, with docs, focused merge/dedup tests, and redacted live Bedrock proof.
