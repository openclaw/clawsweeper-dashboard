## Summary

Keep open: current main and the latest release still lack a Bedrock-owned config merge point for custom `anthropic_beta` or Converse request fields, while AWS docs and the issue's live Bedrock transcript support the underlying request-field need. This is a maintainer product/config-contract decision, not a cleanup close.

## What This Changes

The issue requests a configurable Bedrock model field such as `providerFields.anthropic_beta` so users can opt into Claude Bedrock beta features without patching provider code after upgrades.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field contract with schema validation, docs, focused merge/de-duplication tests for `anthropic_beta`, and redacted live Bedrock proof before landing.
