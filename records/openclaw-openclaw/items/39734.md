## Summary

Keep open: current main and the latest release still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, while the open discussion has newer live Bedrock evidence that the 1M beta flag still matters for Bedrock.

## What This Changes

The issue requests a configurable Bedrock model/provider setting that merges custom `anthropic_beta` flags into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.

Options:

- **Add Bedrock-owned request fields (recommended):** Expose a Bedrock plugin or per-model params contract that safely merges request fields, validates shape, documents upgrade behavior, and covers `anthropic_beta` without creating a core-wide generic passthrough.
- **Add only a narrow beta flag:** Support a typed Bedrock `anthropicBeta` or `context1m` path for Claude long context while avoiding a general Converse body passthrough.
- **Decline custom betas:** Keep Bedrock request shaping internal and ask users to wait for first-class provider support for each beta feature.
