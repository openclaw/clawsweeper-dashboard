## Summary

Keep open: current main and the latest stable release still lack a Bedrock-owned config path for custom `anthropic_beta` or generic Converse request fields, while the issue discussion includes credible Bedrock evidence that the gap still matters.

## What This Changes

Request to let Amazon Bedrock model config pass custom `anthropic_beta` flags into Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field or beta-list contract with docs, merge/de-duplication tests for `anthropic_beta`, and redacted live Bedrock proof before landing.

## Solution Assessment

Unclear until maintainers choose the config contract. A Bedrock-owned request-field merge path looks maintainable, but the exact breadth of that public surface needs maintainer approval.
