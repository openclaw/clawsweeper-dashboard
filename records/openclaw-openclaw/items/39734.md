## Summary

Keep open: current main and the latest release still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the related PR attempts are closed or only cover direct Anthropic behavior.

## What This Changes

Allow Bedrock Claude model config to pass custom `anthropic_beta` flags or request fields into Bedrock Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
