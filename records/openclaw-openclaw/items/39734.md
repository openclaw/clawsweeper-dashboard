## Summary

Keep open: current main and v2026.6.11 still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, while the issue now has source-level and live Bedrock evidence that the gap still matters.

## What This Changes

Request support for configuring Bedrock Claude `anthropic_beta` flags, such as `context-1m-2025-08-07`, from model config instead of patching provider runtime code.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
