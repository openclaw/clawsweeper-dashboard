## What This Changes

The issue requests a Bedrock model-config passthrough for custom Anthropic beta flags so users can send `anthropic_beta` through Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
