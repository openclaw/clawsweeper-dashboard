Keep open: current main and v2026.6.11 still lack a Bedrock-owned config path to merge custom `anthropic_beta` or generic Converse request fields, while the issue and later comment provide credible Bedrock evidence that this is still needed.

## What This Changes

The issue asks OpenClaw to let Bedrock model configuration supply custom `anthropic_beta` flags that are merged into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field contract with schema validation, docs, focused tests for `anthropic_beta` merge and de-duplication, and redacted live Bedrock proof before landing.
