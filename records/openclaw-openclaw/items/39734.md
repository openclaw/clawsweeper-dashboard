## Summary

Keep open: current main and v2026.6.11 still lack a Bedrock-owned config path to merge custom `anthropic_beta` or generic `additionalModelRequestFields`, and choosing that public provider config contract needs maintainer intent.

## What This Changes

The issue requests configurable Amazon Bedrock Anthropic beta flags, such as `context-1m-2025-08-07`, to be merged into Bedrock Converse `additionalModelRequestFields` from OpenClaw config.

## Best Possible Solution

Add a Bedrock-plugin-owned, schema-validated request-field merge contract, or a deliberately narrower typed `anthropicBeta` option, with docs, merge/dedup tests, and redacted live Bedrock proof.
