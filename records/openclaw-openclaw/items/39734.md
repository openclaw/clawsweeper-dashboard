## Summary

Keep open: current main still lacks a Bedrock-owned config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and the remaining choice is the public provider config contract rather than whether the source gap exists.

## What This Changes

Request to let Amazon Bedrock model configuration supply custom `anthropic_beta` flags that are merged into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
