Keep open: current main and v2026.6.11 still do not expose a Bedrock config path for custom `anthropic_beta` or generic `additionalModelRequestFields`, and all closely related fix PRs are closed or unmerged.

## What This Changes

Request support for configuring custom Amazon Bedrock Anthropic beta flags, especially `anthropic_beta`, from model configuration instead of patching provider code after upgrades.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field contract with schema/docs/tests for safe `anthropic_beta` merging, de-duplication, invalid-shape handling, and redacted live Bedrock proof before landing.
