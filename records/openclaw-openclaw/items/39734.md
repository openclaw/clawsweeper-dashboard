## Summary

Keep open: current main and the latest release still do not provide a Bedrock config path for custom `anthropic_beta` or generic Converse `additionalModelRequestFields`, and the remaining decision is the public provider config contract rather than whether the source gap exists.

## What This Changes

The issue requests a Bedrock model-config option that can merge custom `anthropic_beta` flags into Converse `additionalModelRequestFields`.

## Best Possible Solution

Add a Bedrock-plugin-owned request-field merge contract with schema, docs, tests for `anthropic_beta` merging and de-duplication, and redacted live Bedrock proof before landing.
