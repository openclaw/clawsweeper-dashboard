## Summary

Keep open: current main and v2026.6.11 still do not expose a Bedrock `providerFields`, `anthropicBeta`, or generic `additionalModelRequestFields` config path, and the remaining decision is which public Bedrock provider contract maintainers want.

## What This Changes

Request to let Bedrock model config supply custom Anthropic beta flags that are merged into Converse `additionalModelRequestFields`.

## Best Possible Solution

Choose and document a Bedrock-plugin-owned request-field contract, preferably schema-validated with explicit `anthropic_beta` merge/dedup precedence, then add unit coverage and redacted live Bedrock Converse proof.

## Solution Assessment

Unclear until maintainers choose the public config contract. A Bedrock-owned validated merge path is the flexible fix, while a narrower typed option is safer if broad passthrough is not desired.
