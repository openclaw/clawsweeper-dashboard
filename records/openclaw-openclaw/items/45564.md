## Summary

Keep open. Current main and the latest release still only guard the button-triggered Control UI New Chat path; typed `/new`, hard `/reset`, TUI, and channel/auto-reply reset paths remain immediate, so the remaining work needs maintainer product direction.

## What This Changes

Request adds a confirmation flow, ideally configurable, before `/new` or hard `/reset` wipes or rotates a session.

## Best Possible Solution

Define one default-safe confirmation contract for destructive manual session resets across Control UI, TUI, Gateway, and channel command paths; add config only if maintainers explicitly approve an opt-out surface.
