## Summary

The patch appears correct and the new real HTTP/SSE output resolves the previous proof gap, but the PR should remain open for a maintainer to accept the fail-closed compatibility change and select one of the two overlapping implementations.

## What This Changes

Adds terminal-state tracking for OpenAI Responses streams, maps `response.incomplete` to a length stop, treats EOF without a terminal event as an error, and adds focused regression coverage.

## Best Possible Solution

Land one canonical transport-boundary implementation that accepts completed and incomplete terminal events, preserves incomplete content as a length stop, throws on terminal-less EOF before success persistence, and retains real HTTP/SSE regression proof.
