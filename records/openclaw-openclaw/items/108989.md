## Summary

This is a credible, narrowly scoped fix with sufficient after-fix behavior evidence, but it should remain open for an agents-runtime owner to choose one canonical cross-provider EOF contract and implementation among the two active fixes.

## What This Changes

The PR makes Responses SSE handling distinguish completed and incomplete terminal events, and turns EOF without a terminal event into an error instead of a successful stop.

## Best Possible Solution

Adopt one documented Responses-stream contract: completed and incomplete terminal events preserve valid output, while missing terminal events fail before session or gateway success finalization; then land one consolidated implementation with shared-harness coverage for completed, incomplete, EOF, and tool-use EOF.
