## Summary

Keep this PR open for maintainer selection. Its terminal-state model addresses the reported false-success path and the supplied HTTP/SSE proof is meaningful, but merging deliberately changes how OpenAI-compatible Responses proxies that omit a terminal event fail; maintainers should choose the canonical implementation for the linked report before landing either competing PR.

## What This Changes

This PR distinguishes completed and incomplete OpenAI Responses SSE terminal events, maps incomplete results to a length stop, and turns EOF without a terminal event into an error before a successful assistant response is emitted.

## System Context

The OpenAI Responses transport converts streamed provider events into an assistant output consumed by the agent run and gateway. Its terminal result determines whether OpenClaw persists and delivers a completed response or surfaces a provider-stream failure.
