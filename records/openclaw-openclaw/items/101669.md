## Summary

Keep open: the PR is a focused fix for a real Windows-native exec approvals gap, but the current head still rejects ordinary Windows native rules whose optional metadata is serialized as null, so the central read path can fail before CLI or Control UI can render it.

## What This Changes

The PR adds native Windows exec approval snapshot and write support across the gateway protocol, gateway handlers, CLI, Control UI, generated Swift models, tests, and docs.

## Best Possible Solution
