## Summary

Keep open for normal maintainer review: the patch addresses a real unbounded pre-open transport wait through the existing timeout contract, and the production wiring, live loopback proof, dependency contract, and green checks support correctness. The remaining merge consideration is whether maintainers accept making slow HTTP/TLS upgrades fail closed under the existing preauth budget.

## What This Changes

The PR applies the existing configurable preauth timeout to the gateway client's WebSocket opening handshake and adds production-wiring plus live loopback regression coverage.

## Best Possible Solution

Use one canonical preauth budget for both the WebSocket opening upgrade and post-open challenge phase, with coverage for timeout failure, a delayed successful upgrade under a raised configured budget, and observable reconnect/error propagation.
