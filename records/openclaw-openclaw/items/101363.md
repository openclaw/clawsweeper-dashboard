## What This Changes

This issue reports iOS remote pairing failures in the official 2026.6.11 app and requests both recommended Tailscale Serve guidance and an advanced public `wss://` pairing recipe for split admin/mobile hostnames.

## Best Possible Solution

Keep this open for maintainer-reviewed release and docs follow-up: publish Tailscale Serve as the default remote path, document an advanced split-host public `wss://` mobile pairing recipe with `trustedProxies`, `allowedOrigins`, and no browser SSO on the mobile bootstrap host, and confirm the QR fix in a newer App Store build.
