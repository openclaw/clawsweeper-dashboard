## What This Changes

This PR centralizes durable outbound queue acknowledgement and failure ownership so live sends and crash recovery use the same claim fence, while Discord and Slack reuse prepared outbound send context.

## System Context

Agent and gateway message actions select a channel plugin, then send directly or through the durable outbound queue for retries and crash recovery. The queue records the platform-send attempt and decides whether to acknowledge, fail, or retain media artifacts after the channel transport returns.
