## What This Changes

This PR consolidates outbound delivery and crash-recovery queue ownership behind a claim-fenced core helper, while simplifying Discord and Slack adapters to reuse the resolved message-dispatch context.

## System Context

Outbound replies enter from follow-up runs and message actions, then flow through the durable delivery queue before a channel plugin performs the native send. The queue records platform-send ownership and delivery outcomes so recovery can safely retry without acknowledging or failing a newer attempt.
