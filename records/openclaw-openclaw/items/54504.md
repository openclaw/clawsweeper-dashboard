## Summary

Keep open: current main still lacks label-backed subagent role-file lookup, role-file prompt injection, frontmatter-driven model/tool policy, and loaded-file audit metadata. The request remains useful but needs maintainer product and security direction because it would add a new trusted instruction surface for spawned sessions.

## What This Changes

Add lightweight persistent per-role subagent instruction files that `sessions_spawn` can auto-load by label, with optional frontmatter for model/tool overrides and workspace/user precedence.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit spawn-argument overrides, narrowing-only capability semantics, memory/writeback ownership, docs, tests, and loaded-file audit metadata before implementation.
