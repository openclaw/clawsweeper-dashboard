## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter parsing, role-file prompt injection, or role-file tool/model defaults; the request is valid but needs maintainer product and security direction before implementation.

## What This Changes

Add persistent per-role Markdown instruction files for ephemeral native `sessions_spawn` subagents, with optional frontmatter for role defaults such as model and tool policy.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract before implementation, including lookup precedence, explicit spawn-argument override rules, narrowing-only tool policy, model/provider limits, memory/writeback ownership, docs, and loaded-file audit metadata.

## Reproduction Assessment

Yes, at source level. Current main accepts `label` but has no path that resolves a matching role file, parses frontmatter, applies role defaults, or injects a role-file body before the child run starts.

## Solution Assessment

Unclear until maintainers choose the product and security boundary. The proposed file convention is plausible, but prompt authority, explicit-argument precedence, tool narrowing, model overrides, memory, and audit semantics must be settled first.
