## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter-derived model/tool policy, role-body prompt injection, memory/writeback semantics, or loaded-file audit metadata, and the live workflow comment shows this remains an active multi-agent ergonomics gap needing product/security direction.

## What This Changes

The issue requests persistent per-role Markdown instruction files for `sessions_spawn(label=...)`, with optional frontmatter for model/tool behavior and automatic workspace/user-scope lookup.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only tool/model semantics, memory/writeback ownership, and loaded-file audit metadata before implementation.
