## Label Justifications

## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter parsing, role-file prompt injection, or loaded-file audit metadata; the remaining work needs maintainer product and security direction.

## What This Changes

Request to add persistent Markdown role files for native `sessions_spawn` subagents, keyed by label, with optional frontmatter for model/tool defaults and workspace/user lookup precedence.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only capability semantics, bounded model overrides, memory/writeback ownership, docs, tests, and loaded-file audit metadata.
