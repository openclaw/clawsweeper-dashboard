## Summary

Keep open: current main and the latest release still lack automatic `sessions_spawn(label=...)` role-file lookup, role-file body injection, or frontmatter-driven model/tool precedence; the request is valid but needs maintainer product and security direction before implementation.

## What This Changes

The issue requests persistent lightweight per-role subagent instruction files that `sessions_spawn` can auto-load by label, including frontmatter-driven model/tool overrides and workspace/user precedence.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only tool policy, model/provider limits, memory ownership, loaded-file audit metadata, docs, and regression tests.
