## Label Justifications

- `impact:session-state`: The requested role and memory files would change persistent context, persona, and writeback behavior for spawned subagent sessions.

## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter parsing, role-file prompt injection, or loaded-file audit metadata, and the added workflow comment shows this remains a live multi-agent ergonomics gap that needs product and security direction.

## What This Changes

The issue requests persistent per-role Markdown instruction files for `sessions_spawn(label=...)`, including workspace/user lookup, prompt-body injection, and optional model/tool frontmatter for ephemeral subagents.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only tool/model semantics, memory/writeback ownership, and loaded-file audit metadata before implementation.
