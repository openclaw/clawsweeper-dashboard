## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter-derived model/tool policy, role prompt injection, memory/writeback semantics, or loaded-file audit metadata, and the live workflow comment shows this remains an active multi-agent ergonomics gap needing product and security direction.

## What This Changes

Add persistent label-backed subagent role Markdown files for `sessions_spawn` that inject standing role instructions and optional frontmatter defaults without requiring full `agents.list` entries.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only tool/model semantics, memory/writeback ownership, and loaded-file audit metadata before implementation.
