## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, role Markdown/frontmatter injection, and loaded-file audit metadata; the workflow comment shows this remains a live multi-agent ergonomics gap that needs product and security direction.

## What This Changes

Add persistent label-named Markdown role files for `sessions_spawn` subagents so stable role instructions and selected frontmatter defaults can be loaded without full `agents.list` entries.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit spawn argument priority, narrowing-only tool/model semantics, memory/writeback ownership, docs, tests, and loaded-file audit metadata before implementation.
