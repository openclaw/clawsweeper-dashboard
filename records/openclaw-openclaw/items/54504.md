## Label Justifications

- `P2`: This is a meaningful multi-agent ergonomics and policy feature with source-level evidence, but it is not an outage or urgent shipped regression.
- `impact:session-state`: The requested role and memory files would change persistent context, persona, writeback, and audit identity for spawned subagent sessions.

## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter parsing, role-file prompt injection, or loaded-file audit metadata, and the live workflow comment shows this remains an active multi-agent ergonomics gap that needs product and security direction.

## What This Changes

The issue requests lightweight `sessions_spawn(label=...)` subagent instruction files with markdown body injection and optional model/tool frontmatter overrides.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only tool/model semantics, memory/writeback ownership, and loaded-file audit metadata before implementation.
