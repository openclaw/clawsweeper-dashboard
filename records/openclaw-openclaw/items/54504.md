## Summary

Keep open: current main and v2026.6.11 still lack label-backed subagent role-file lookup, frontmatter application, and role-file prompt injection; the remaining work needs maintainer product and security direction rather than cleanup closure.

## What This Changes

Request persistent per-role Markdown instruction files for `sessions_spawn(label=...)`, with optional frontmatter for model/tool defaults and workspace-over-user lookup precedence.

## Best Possible Solution

Define a maintainer-approved subagent role-profile contract covering lookup precedence, explicit-argument overrides, narrowing-only tool policy, model/provider limits, memory ownership, plugin-vs-core boundary, and loaded-file audit metadata before implementation.

## Reproduction Assessment

Yes, at source level. Current main and v2026.6.11 accept `label` but have no path that resolves `subagents/<label>.md`, parses frontmatter, applies role defaults, or injects a role-file body before the child run starts.

## Solution Assessment

Unclear until maintainers choose the product and security boundary. The requested file convention is plausible, but prompt authority, tool narrowing, model overrides, memory writeback, plugin feasibility, and audit semantics need a design decision first.
