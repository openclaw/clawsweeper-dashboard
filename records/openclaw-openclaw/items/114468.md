## What This Changes

The branch adds generation- and session-bound recovery receipts so overlapping orphan-recovery scans cannot dispatch duplicate resumes for the same interrupted subagent session.

## System Context

During Gateway startup and registry restoration, OpenClaw scans persisted subagent sessions marked as interrupted and resumes them through the Gateway. The recovery path then updates the registry and session marker so later scans know whether that interrupted generation has already been handled.
