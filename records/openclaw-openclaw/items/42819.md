## Summary

Keep open: current main and v2026.6.11 solve the brittle versioned Playwright lookup by autodetecting Docker-managed Chromium, but they still keep browser files under `/home/node/.cache/ms-playwright` and do not provide stable `chrome`/`chromium` PATH commands.

## What This Changes

The issue requests a Docker browser image contract where Playwright browser files live outside the hidden node cache and Chrome/Chromium is available through a stable PATH command.

## Best Possible Solution

Keep the shipped Playwright cache autodetection unless maintainers explicitly approve a Docker image contract change; if approved, land a focused Dockerfile/docs/test update with live proof for browser-enabled, browser-disabled, runtime-install, persisted-volume, and upgrade scenarios.
