## Summary

Keep open: current main and the latest release partially solve the brittle versioned Playwright path by auto-detecting the Docker Playwright cache, but the Docker image still stores browsers under the hidden node cache and does not expose stable `chrome` or `chromium` commands on PATH. The remaining request changes Docker image defaults and needs maintainer product direction.

## What This Changes

The issue asks Docker browser-enabled images to store Playwright browser files outside `.cache` and expose a stable browser binary on PATH.

## Best Possible Solution

Keep the shipped Playwright cache autodetection unless maintainers explicitly approve an `/opt` plus PATH migration with Dockerfile, docs, tests, and live container proof for browser-enabled, browser-disabled, and existing-cache upgrade scenarios.
