## Summary

Keep open: current main and v2026.6.11 solve the brittle versioned executable lookup by autodetecting Playwright-managed Chromium, but the requested Docker image contract change to a non-hidden `/opt` path plus stable `chrome`/`chromium` PATH commands remains unimplemented and needs maintainer direction.

## What This Changes

The issue asks OpenClaw Docker browser builds to stop requiring versioned Playwright cache paths by moving browser files out of `/home/node/.cache/ms-playwright` and exposing a stable browser command on PATH.

## Best Possible Solution

Keep the shipped Playwright cache autodetection unless maintainers explicitly approve a Docker image contract change; if approved, land a focused Dockerfile/docs/test update with live proof for browser-enabled, browser-disabled, runtime-install, and upgrade scenarios.
