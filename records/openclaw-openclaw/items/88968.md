## Summary

Keep open: current main and the latest release still abort the user reply when memoryFlush emits visible error payloads, while this PR changes that path to log-and-continue with exhausted-session rotation. The patch has strong proof and no concrete line-level defect from this pass, but it needs maintainer approval for fail-open delivery, active session rotation, expanded notifyUser semantics, and reconciliation with the open memoryFlush ordering PR.

## What This Changes

The PR changes memoryFlush failure handling in runReplyAgent to log visible maintenance errors, continue the main reply, rotate exhausted sessions while preserving transcripts, clear flush metadata on reset, update notifyUser docs, and add regression tests.
