## What This Changes

This PR makes Feishu custom-domain settings accept case-insensitive HTTPS schemes, normalize them to canonical `https://` URLs, and adds regression coverage for top-level and per-account configuration.

## System Context

The bundled Feishu channel receives its domain from OpenClaw configuration before channel startup. Its schema validates and normalizes that setting for the Feishu runtime and for generated bundled-channel configuration metadata.
