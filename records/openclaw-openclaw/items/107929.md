## Summary

Current main still renders chat tables without zebra striping or inferred numeric alignment and resets paragraph/list margins in a way that leaves the reported spacing gap unresolved. This is a valid, bounded Control UI improvement, but automatic numeric detection and signed-delta coloring need a small product/design decision before implementation.

## What This Changes

Improve Control UI chat markdown tables with clearer row and numeric-column styling, and restore spacing between lists and following paragraphs.

## Best Possible Solution

Add neutral header, zebra-row, list-boundary, and tabular-number styling in the chat stylesheet; preserve markdown-declared column alignment, and add inferred numeric classes only under a narrowly tested renderer rule while deferring signed-delta coloring until design approval.

- **Include delta semantics:** Add numeric inference plus success/danger coloring for signed-delta columns with accessibility and theme-token review.

## Reproduction Assessment

Yes from source inspection: current main has no zebra or inferred numeric table styles, and its margin reset plus list rules provide no dedicated gap before a following paragraph. A browser screenshot should still be captured before implementation to establish the visual baseline.

## Solution Assessment

Partly. CSS is the best boundary for spacing, striping, and typography, but CSS cannot reliably infer numeric or signed-delta cell content; that portion belongs in the markdown renderer under an explicit, tested rule.
