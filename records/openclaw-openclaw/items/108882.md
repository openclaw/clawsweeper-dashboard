## Summary

Keep this PR open: the shared accessory design is coherent and well demonstrated, but the hat-tip branch suppresses the destination mood’s entrance gesture, so successful update completion loses its existing celebration animation. The protected `maintainer` label also requires explicit maintainer handling rather than cleanup closure.

## What This Changes

The PR adds a shared mascot accessory channel, sleepy nightcaps, an onboarding graduation cap, and a hat-tip animation when leaving the working mood.

## Best Possible Solution

Keep gesture composition in the shared animator, but defer and start the destination mood’s entrance immediately after the hat-tip completes, preserving the one-hat invariant and adding focused working-to-celebrating transition coverage.

Yes, from source: transition the post-update mascot from `.working` to `.celebrating`; `setMood` selects `.hatTip` and skips the celebration entrance. The supplied test does not exercise this sequencing.

## Solution Assessment

Mostly, but not yet completely: a shared animator-owned accessory and gesture channel is the maintainable layer, while making the hat-tip mutually exclusive with destination entrances is not the best transition model.
