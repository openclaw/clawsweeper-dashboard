## Summary

The PR’s custom descriptor reader regresses non-regular input handling and duplicates Node’s existing descriptor-bound `readFile` implementation, so it is not ready to merge as written.

## What This Changes

The branch replaces capability-CLI media reads with an explicit `open`/`stat`/manual-read helper and adds focused normal-file tests.

## Best Possible Solution

Restore the standard `fs.readFile` path unless maintainers require an explicit descriptor boundary; in that case use `fs.open` plus `handle.readFile()` and add a pipe/FIFO regression test so Node’s unknown-size descriptor semantics remain intact.
