## Summary

Keep open: current main deliberately reruns the scanner before apply and exposes no scanner-exception policy, so the reported specialist-workflow gap remains; however, the permanent exception model is a security and product decision rather than a routine configuration addition.

## What This Changes

Add narrowly scoped, auditable exceptions for selected Skill Workshop scanner findings while retaining strict default blocking.

## Best Possible Solution

Provide an explicit, hash-bound operator action that applies one inspected quarantined proposal despite named findings while retaining those findings, the acknowledgement, actor, reason, and content hash in audit metadata; consider persistent rule policy only after security-owner approval.
