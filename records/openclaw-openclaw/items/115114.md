## What This Changes

The branch keeps Slack portable previews enabled for custom outbound usernames or icons by using an app-authored disposable preview and a separately customized final reply, and isolates an unrelated model-catalog unit fixture from runtime plugin normalization.

## System Context

Slack’s message handler chooses native or portable streaming for an inbound message, then manages a temporary preview before sending the final reply. Slack custom outbound identity belongs on the final delivery, while the temporary preview must remain app-authored so OpenClaw can update or remove it.
