## Summary

Keep open: current main and v2026.6.11 still lack a supported cross-channel text acknowledgement that sends before agent processing and then continues normal dispatch; related items are narrower channel-specific placeholders or reaction work, not a merged canonical fix.

## What This Changes

The issue requests a reliable, configurable text acknowledgement message before agent processing across Slack, WhatsApp, WebChat, Feishu, and similar chat channels.

## Best Possible Solution

Define one default-off send-and-continue acknowledgement lifecycle contract with config, docs, and focused channel tests, or explicitly route each channel-specific placeholder through its own narrower open item.
