## Summary

Keep open: current main and the latest release still lack a supported cross-channel acknowledgement text config or send-and-continue hook before agent processing. Existing ack reactions, status reactions, typing indicators, progress drafts, and terminal hooks cover adjacent feedback but do not satisfy the requested text acknowledgement contract.

## What This Changes

The request is to add configurable text acknowledgement sent before agent processing, similar to ackReaction, across messaging channels.

## Best Possible Solution

Choose a maintainer-approved, default-off acknowledgement-text or send-and-continue hook contract, then update config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 expose reactions, typing indicators, progress drafts, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path. No live transport run is needed to prove the requested capability is absent.

## Solution Assessment

Unclear until maintainers choose the product/API boundary. messages.ackText is plausible, but a non-terminal plugin or channel hook may be the cleaner long-term seam for cross-channel and channel-specific behavior.
