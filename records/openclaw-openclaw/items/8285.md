## Summary

Keep open: current main still has no supported cross-channel text acknowledgement config or non-terminal send-and-continue hook before agent processing. Existing reactions, status reactions, typing indicators, and channel-specific placeholder requests are adjacent but do not satisfy this broad feature request.

## What This Changes

The issue requests a configurable text acknowledgement message, similar to `messages.ackReaction`, that can be sent before agent processing across chat channels.

## Best Possible Solution

Approve one default-off acknowledgement contract, then implement it with scoped config or a documented non-terminal hook, per-channel/account overrides, schema/help/docs alignment, focused channel regression tests, and live proof on representative chat surfaces.
