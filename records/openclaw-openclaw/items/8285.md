## Summary

Keep open: current main and v2026.6.11 still lack a supported cross-channel pre-processing acknowledgement text config or non-terminal send-and-continue hook; existing reactions, typing indicators, channel-specific placeholders, and progress drafts do not satisfy the requested contract.

## What This Changes

Add a supported way to send a brief configurable text acknowledgement before normal agent processing continues across chat channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement schema/types/help/docs plus channel delivery tests and live proof for affected messaging surfaces.
