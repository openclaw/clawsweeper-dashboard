## Summary

Keep open: current main still lacks a supported cross-channel text acknowledgement before agent processing. The issue is a valid source-level feature gap, but it adds config or plugin/API surface and overlaps several channel-specific placeholder/presence requests, so it needs maintainer product direction rather than cleanup close or an automatic fix PR.

## What This Changes

The issue requests a configurable pre-processing acknowledgement text message, similar to `ackReaction`, that can be sent before normal agent work begins.

## Best Possible Solution

Choose one supported acknowledgement-text contract, then implement it through the proper config/plugin-channel boundary with schema, docs, channel coverage, authorization-safe ordering, cleanup semantics, and live proof on the affected messaging surfaces.
