## Summary

Keep open: current main still lacks a supported cross-channel acknowledgement-text contract; existing reactions, status reactions, typing indicators, channel-specific progress surfaces, and the terminal `before_dispatch` hook do not satisfy the requested send-text-and-continue behavior.

## What This Changes

The issue requests configurable text acknowledgements, such as `messages.ackText`, sent before agent processing across chat channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, either shared `messages.ackText` config with channel/account overrides or a documented non-terminal plugin/channel hook, then update schema, docs, channel coverage, and tests.
