## Summary

Keep open: current main still has reactions, status reactions, typing indicators, and terminal hooks, but no supported cross-channel text acknowledgement contract before agent processing.

## What This Changes

The issue requests a configurable pre-processing text acknowledgement, such as `messages.ackText`, for chat channels before the agent starts work.

## Best Possible Solution

Choose a generic cross-channel acknowledgement-text contract or a documented non-terminal plugin/channel hook, then update config types, strict schema, generated metadata/help, public docs, and focused channel regression tests without hardcoding one channel’s UX into core.
