## Summary

Keep open: current main and the latest release still lack a supported cross-channel acknowledgement text contract; existing reactions, typing indicators, and channel progress previews only partially cover the UX gap and do not provide the requested pre-processing text message API.

## What This Changes

The issue requests configurable text acknowledgement, such as `messages.ackText`, sent before normal agent processing across messaging channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, either shared `messages.ackText` with scope and per-channel/account overrides or a typed non-terminal send-and-continue hook, then update schema, docs, channel behavior, and regression proof together.
