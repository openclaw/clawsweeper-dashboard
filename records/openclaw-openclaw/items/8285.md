## Summary

Keep open: current main and v2026.6.11 still have reactions, status reactions, typing indicators, and terminal before_dispatch hooks, but no supported cross-channel text acknowledgement that sends before agent processing and then continues normal dispatch.

## What This Changes

Request to add a configurable text acknowledgement that sends immediately before agent processing and then continues normal dispatch across messaging channels.

## Best Possible Solution

Define one default-off acknowledgement-text lifecycle contract, ideally a generic send-and-continue seam that channels and plugins can implement consistently with config, docs, and focused channel tests.
