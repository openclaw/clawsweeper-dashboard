## Summary

## What This Changes

Request to add a supported configurable text acknowledgement before agent processing, similar to ack reactions but delivered as a message across chat channels.

## Best Possible Solution

Choose a maintainer-approved, default-off acknowledgement-text or non-terminal send-and-continue hook contract, then align config types, strict schema/help, public docs, channel docs, and focused regression coverage.
