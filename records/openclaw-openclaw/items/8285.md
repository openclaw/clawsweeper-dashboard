## Summary

Keep open: current main still has reaction/status/typing acknowledgements and a terminal before_dispatch hook, but no supported cross-channel acknowledgement text contract for sending a visible interim message before normal agent processing continues.

## What This Changes

Request a configurable cross-channel acknowledgement text message, such as messages.ackText, that sends immediately before agent processing and then allows the normal reply path to continue.

## Best Possible Solution

Choose one acknowledgement-text contract, then implement it as default-off shared config or a documented non-terminal hook with schema, docs, channel coverage, and focused tests.
