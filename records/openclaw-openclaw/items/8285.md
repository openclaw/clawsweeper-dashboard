## Summary

Keep open: current main and v2026.6.11 still do not provide a supported cross-channel text acknowledgement before agent processing. Existing ack reactions, status reactions, typing indicators, and progress drafts are adjacent, but none provide the requested configurable send-and-continue acknowledgement text contract.

## What This Changes

Request a supported cross-channel pre-processing text acknowledgement that sends before agent work starts and then lets normal dispatch continue.

## Best Possible Solution

Adopt a maintainer-approved, default-off acknowledgement-text or send-and-continue hook contract, then update config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 expose reactions, status reactions, typing indicators, progress drafts, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path. No live transport run is needed to prove the requested capability is absent.

## Solution Assessment

Unclear until maintainers choose the product/API boundary. The proposed messages.ackText config is plausible, but a non-terminal plugin/channel hook may be the cleaner long-term seam for cross-channel and channel-specific behavior.
