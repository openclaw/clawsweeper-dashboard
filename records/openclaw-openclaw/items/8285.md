## Summary

Keep open: current main and the latest release still lack a supported cross-channel pre-processing acknowledgement text config or non-terminal send-and-continue hook; this remains a product/API decision rather than cleanup-close material.

## What This Changes

Request a configurable immediate text acknowledgement before agent processing starts, similar to ack reactions but as a message across Slack, WhatsApp, WebChat, Feishu, and other channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement schema, types, generated help/docs, channel delivery tests, and live proof for at least one affected messaging surface.

Options:

- **Channel-specific placeholders only:** Keep this issue as the broad cluster and solve Slack, Telegram, Discord, and other surfaces independently where channel UX differs.
