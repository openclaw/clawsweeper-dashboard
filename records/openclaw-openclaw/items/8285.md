## Summary

Keep open: current main still lacks a supported cross-channel text acknowledgement that sends before agent processing and then continues normal dispatch. The source-reproducible gap remains, but the fix needs maintainer product/API direction because it would add a new config surface or a new non-terminal channel/plugin hook.

## What This Changes

Request a configurable pre-processing acknowledgement text message, similar to ack reactions, for messaging channels such as Slack, WhatsApp, WebChat, and Feishu.

## Best Possible Solution

Choose a maintainer-approved, default-off acknowledgement-text or send-and-continue hook contract, then update config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes. Source inspection shows current main and v2026.6.11 expose reactions, typing indicators, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path.

## Solution Assessment

Unclear until maintainers choose the product/API boundary. `messages.ackText` is plausible, but a non-terminal plugin or channel hook may be the cleaner long-term seam for cross-channel and channel-specific behavior.
