## Summary

Keep open: current main and the latest release still provide reactions, status reactions, typing indicators, and a terminal `before_dispatch` hook, but no supported cross-channel acknowledgement text contract that sends an interim text message and then continues normal processing.

## What This Changes

The issue requests a configurable text acknowledgement before agent processing across messaging channels, similar to `messages.ackReaction` but with visible text.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement it through shared config or a documented non-terminal hook with schema, docs, per-channel coverage, and focused live/channel tests.
