## Summary

Keep open: current main still lacks a supported cross-channel acknowledgement text message that sends before agent processing and then continues normal dispatch.

## What This Changes

The issue requests configurable pre-processing acknowledgement text, such as messages.ackText with scope controls, for messaging channels.

## Best Possible Solution

Choose a maintainer-approved, default-off acknowledgement-text or send-and-continue hook contract, then align config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level: current main exposes reactions, typing indicators, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path.

## Solution Assessment

Unclear until maintainers choose the boundary; messages.ackText is plausible, but a non-terminal plugin or channel hook may be the cleaner long-term seam.
