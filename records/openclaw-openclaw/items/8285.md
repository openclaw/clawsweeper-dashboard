## Summary

Keep open: current main and v2026.6.11 still lack a supported cross-channel text acknowledgement before agent processing; existing ack reactions, status reactions, typing indicators, and terminal before_dispatch hooks are adjacent but do not provide the requested ackText-style contract.

## What This Changes

Requests configurable pre-processing text acknowledgements across messaging channels, analogous to ackReaction with scope controls.

## Best Possible Solution

Choose a maintainer-approved default-off acknowledgement-text or non-terminal send-and-continue hook design, then align config types, strict schemas, generated help/metadata, public docs, channel overrides, regression tests, and live channel proof.
