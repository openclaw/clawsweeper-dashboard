## Summary

Keep open: current main still lacks a supported cross-channel acknowledgement text config or send-and-continue lifecycle hook before agent processing; related Slack, Discord, and Telegram items are narrower channel-specific presence or placeholder requests, not replacements for this product/API decision.

## What This Changes

The issue requests configurable cross-channel pre-processing acknowledgement text before agent dispatch, similar to existing acknowledgement reactions but sent as a message.

## Best Possible Solution

Define one default-off acknowledgement lifecycle contract, preferably a generic send-and-continue hook plus aligned config/docs/tests, or explicitly route each channel-specific placeholder through its narrower issue.
