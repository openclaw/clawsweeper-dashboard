## Summary

Keep open: current main still lacks a supported cross-channel acknowledgement-text contract; existing behavior covers reactions, status reactions, typing indicators, and terminal hooks, but not a configurable interim text message that sends before normal agent processing continues.

## What This Changes

Request to add a configurable automatic text acknowledgement before agent processing, similar to ack reactions but visible as a chat message across messaging channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement it through shared config or a documented non-terminal hook with schema, docs, channel coverage, and focused tests.
