## Summary

Keep open: current main and v2026.6.11 still do not provide a supported configurable acknowledgement text message before agent processing; the source gap is clear, but the fix is a product/config/API decision rather than an automatic bug repair.

## What This Changes

Request to add configurable pre-processing acknowledgement text, similar to ack reactions, for messaging channels such as Slack, WhatsApp, WebChat, and Feishu.

## Best Possible Solution

Choose a default-off supported acknowledgement-text contract or non-terminal pre-processing hook with scope/per-channel overrides, schema/docs/tests, and channel-specific live proof; otherwise explicitly route users to channel-specific presence/status alternatives.
