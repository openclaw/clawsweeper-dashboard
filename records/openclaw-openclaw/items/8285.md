## Summary

Keep open: current main and v2026.6.11 still have reactions, status reactions, typing indicators, conditional progress drafts, and a terminal `before_dispatch` hook, but not the requested supported text acknowledgement that sends before processing and then continues normal agent dispatch.

## What This Changes

The issue requests configurable cross-channel text acknowledgements that are sent before agent processing starts.

## Best Possible Solution

Choose one supported non-terminal acknowledgement contract, preferably a generic plugin/channel seam or a narrowly justified `messages.ackText` config, then update schema, docs, channel behavior, and regression coverage without duplicating progress-draft semantics.
