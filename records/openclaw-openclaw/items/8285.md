## Summary

Keep open: current main and v2026.6.11 still lack a supported cross-channel text acknowledgement sent before agent processing. Existing reactions, status reactions, typing indicators, terminal `before_dispatch` handling, and channel-specific placeholder proposals are adjacent but do not implement the requested `messages.ackText`-style contract.

## What This Changes

Request configurable cross-channel text acknowledgement before agent processing begins, similar to ack reactions but sent as a message.

## Best Possible Solution

Keep this open until maintainers choose a default-off acknowledgement-text contract or a non-terminal plugin/channel hook, then implement it with schema/help/docs and focused coverage across the affected messaging surfaces.
