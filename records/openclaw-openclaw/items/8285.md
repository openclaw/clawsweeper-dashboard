## Summary

Keep open: current main and v2026.6.11 still do not provide a supported cross-channel text acknowledgement before agent processing; the existing reaction, status-reaction, typing, and terminal hook paths are adjacent but do not satisfy the requested contract.

## What This Changes

The issue requests a configurable text acknowledgement, such as `messages.ackText`, that sends before agent processing begins on messaging channels.

## Best Possible Solution

Keep the issue open until maintainers choose a default-off acknowledgement text or non-terminal pre-processing hook contract, then implement it with schema, docs, per-channel behavior tests, and live proof for the affected messaging surfaces.
