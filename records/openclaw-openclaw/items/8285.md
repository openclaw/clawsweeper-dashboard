## Summary

Keep open: current main and v2026.6.11 still do not provide a supported cross-channel text acknowledgement that sends before agent processing and then continues normal dispatch.

## What This Changes

The issue requests configurable pre-processing acknowledgement text, such as `messages.ackText`, for messaging channels before normal agent processing begins.

## Best Possible Solution

Define one default-off send-and-continue acknowledgement lifecycle contract with config, docs, and focused channel tests, or explicitly route each channel-specific placeholder through its narrower issue.
