Keep open: current main and v2026.6.11 still provide ack reactions, status reactions, typing indicators, and terminal `before_dispatch`, but not a supported cross-channel text acknowledgement that can send interim text and then continue normal agent processing.

Choose one default-off acknowledgement-text contract, then implement it as shared `messages.ackText` config or a documented non-terminal hook with schema, docs, channel coverage, and focused tests.
