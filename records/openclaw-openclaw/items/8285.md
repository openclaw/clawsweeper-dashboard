## What This Changes

Add a configurable pre-processing text acknowledgement, similar to ackReaction, that sends before agent processing across chat channels.

## Best Possible Solution

Define one default-off send-and-continue acknowledgement lifecycle contract with config, docs, and focused channel tests, or explicitly route channel-specific placeholders through narrower issues.
