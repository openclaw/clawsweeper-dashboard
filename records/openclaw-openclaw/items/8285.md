## Summary

Keep open: current main and the latest release still lack a supported cross-channel text acknowledgement or non-terminal send-and-continue hook before normal agent processing, so this remains a product/API decision rather than cleanup-close material.

## What This Changes

Request a supported pre-processing text acknowledgement, such as `messages.ackText`/`ackTextScope`, across messaging channels before agent processing continues.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement it through shared config or a documented non-terminal hook with schema, docs, channel coverage, and focused live proof.
