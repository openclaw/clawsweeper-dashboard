## Summary

Keep open: current main and v2026.6.11 still provide ack reactions, status reactions, typing indicators, and terminal `before_dispatch`, but no supported cross-channel acknowledgement-text contract that sends interim text and continues normal processing.

## What This Changes

Add a supported pre-processing acknowledgement text message, such as `messages.ackText`, before agent work begins across messaging channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement it as shared config or a documented non-terminal hook with schema/help/docs, channel coverage, and live channel proof.
