## Summary

Keep open: current main and the latest release still do not provide a supported cross-channel acknowledgement text message that sends before agent processing and then continues normal dispatch.

## What This Changes

The issue requests configurable text acknowledgement, such as `messages.ackText`, before agent processing across messaging channels.

## Best Possible Solution

Choose a default-off acknowledgement-text or send-and-continue hook contract, then align config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 expose reactions, typing indicators, progress drafts, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path.

## Solution Assessment

Unclear until maintainers choose the product/API boundary. `messages.ackText` is plausible, but a non-terminal plugin or channel hook may be the cleaner long-term seam for cross-channel and channel-specific behavior.
