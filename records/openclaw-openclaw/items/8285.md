## Summary

Keep open: current main and v2026.6.11 still lack a supported cross-channel acknowledgement text config or send-and-continue lifecycle hook before agent processing. The related Slack, Discord, Telegram, and Feishu items are narrower channel-specific placeholder/presence work, so this remains the canonical product/API decision.

## What This Changes

The issue requests a cross-channel configurable text acknowledgement sent immediately before normal agent processing continues.

## Best Possible Solution

Define one default-off send-and-continue acknowledgement lifecycle contract with config, docs, and focused channel tests, or explicitly route each channel-specific placeholder through its narrower issue.
