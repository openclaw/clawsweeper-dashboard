## Summary

Keep open: current main and the latest release still do not provide a supported cross-channel acknowledgement text message before agent processing; the remaining work is a real feature/API decision rather than stale cleanup.

## What This Changes

The issue requests a supported pre-processing text acknowledgement message, similar to ackReaction, that can be sent before agent processing across chat channels.

## Best Possible Solution

Choose a maintainer-approved, default-off acknowledgement-text or send-and-continue hook contract, then update config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 expose reactions, typing indicators, progress drafts, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path. No live transport run is needed to prove the requested contract is absent.

## Solution Assessment

Unclear until maintainers choose the product/API boundary. messages.ackText is plausible, but a non-terminal plugin or channel hook may be the cleaner long-term seam for cross-channel and channel-specific behavior.
