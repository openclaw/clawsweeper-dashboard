## Summary

Keep open. Current main and the latest release still do not provide a supported cross-channel text acknowledgement before agent processing; the existing reaction, status-reaction, typing, and terminal hook surfaces do not satisfy the requested `messages.ackText`-style contract.

## What This Changes

Request to add configurable cross-channel acknowledgement text, such as `messages.ackText` and scope controls, before normal agent processing begins.

## Best Possible Solution

Define one maintainer-approved acknowledgement contract: either a narrow `messages.ackText` configuration with per-channel/account capability rules, or a generic non-terminal pre-processing hook that channels/plugins can implement consistently.
