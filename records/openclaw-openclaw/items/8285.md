Keep open: current main and v2026.6.11 still lack a supported cross-channel text acknowledgement before agent processing. Existing ack reactions, status reactions, typing indicators, terminal pre-dispatch hooks, and channel-specific placeholder proposals are adjacent but do not implement the requested `messages.ackText`-style contract.

## What This Changes

The issue requests configurable pre-processing acknowledgement text before agent work begins across messaging channels.

Keep this open until maintainers choose a default-off acknowledgement-text contract or a non-terminal plugin/channel hook, then implement it with schema/help/docs and focused coverage across affected messaging surfaces.
