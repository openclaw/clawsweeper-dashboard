## Summary

Keep open: current main still has reactions, status reactions, typing indicators, progress drafts, and a terminal before_dispatch hook, but not a supported cross-channel acknowledgement-text contract that sends visible interim text before normal agent processing continues.

## What This Changes

Request a configurable automatic text acknowledgement before agent processing, similar to ackReaction but visible as a chat message across Slack, WhatsApp, WebChat, Feishu, and other channels.

## Best Possible Solution

Choose one acknowledgement-text contract, then implement it as default-off shared messages config or a documented non-terminal hook with schema/help, public docs, channel coverage, and focused regression plus live-channel proof.
