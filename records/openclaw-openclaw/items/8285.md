## Summary

Keep open: current main and v2026.6.11 still provide reactions, status reactions, typing indicators, and a terminal `before_dispatch` hook, but not a supported cross-channel acknowledgement-text contract that can send interim text and continue normal agent processing.

## Best Possible Solution

Choose one acknowledgement-text contract, then implement it as default-off shared config or a documented non-terminal hook with schema, docs, channel coverage, and focused tests.
