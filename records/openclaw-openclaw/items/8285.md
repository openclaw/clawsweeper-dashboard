## Summary

Keep open: current main and v2026.6.11 still do not provide a supported cross-channel text acknowledgement that can send an interim message before normal agent processing continues.

## What This Changes

The issue requests configurable pre-processing acknowledgement text, such as `messages.ackText`, for Slack, WhatsApp, WebChat, Feishu, and similar chat channels.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement it through shared config or a documented non-terminal hook with schema, docs, channel coverage, and focused tests.

Yes, at source level: current main and v2026.6.11 expose reactions, status reactions, typing, and terminal `before_dispatch`, but no accepted ack text or send-and-continue interim text hook. This is not a failing-bug reproduction because the issue requests a new capability.

## Solution Assessment

Unclear until maintainers choose the API shape. Prompt instructions and private channel workarounds are not reliable; a default-off shared `ackText` contract or typed non-terminal hook would be the maintainable path.
