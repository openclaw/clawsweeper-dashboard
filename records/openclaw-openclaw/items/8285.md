## Summary

Keep open. Current main still lacks a supported cross-channel text acknowledgement contract before agent processing; existing ack reactions, status reactions, typing indicators, and Slack/GoogleChat-specific progress surfaces do not satisfy the requested `messages.ackText`-style behavior, and the related channel-specific items are still open rather than merged fixes.

## What This Changes

Request a configurable pre-processing text acknowledgement, scoped like `ackReaction`, for messaging channels such as Slack, WhatsApp, WebChat, Feishu, and Telegram.

## Best Possible Solution

Approve one supported acknowledgement lifecycle contract, preferably a generic plugin/channel seam with a minimal opt-in text config if maintainers want global UX, then update config types, schema/help, public docs, and focused channel regression coverage.
