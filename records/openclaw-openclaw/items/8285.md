## Summary

Keep open: current main and the latest release still do not provide a supported cross-channel acknowledgement text message that can be sent before normal agent processing continues, and the remaining choice is product/API shape rather than conservative cleanup.

## What This Changes

The issue requests a configurable pre-processing acknowledgement text message, similar to `ackReaction`, for messaging channels such as Slack, WhatsApp, WebChat, Feishu, and related chat surfaces.

## Best Possible Solution

Choose one default-off acknowledgement-text contract, then implement it through shared config or a documented non-terminal hook with schema, docs, channel coverage, and focused tests.
