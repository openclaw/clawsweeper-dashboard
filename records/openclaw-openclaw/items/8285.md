## Summary

Keep open: current main and v2026.6.11 still lack a supported cross-channel acknowledgement text message that sends before agent processing and then continues normal dispatch.

## What This Changes

The issue requests a configurable cross-channel text acknowledgement that sends before agent processing and then allows normal dispatch to continue.

## Best Possible Solution

Choose a maintainer-approved, default-off acknowledgement-text or non-terminal send-and-continue hook contract, then align config types, strict schema/help, public docs, channel docs, and focused regression coverage.

## Reproduction Assessment

Yes, at source level: current main and v2026.6.11 expose reactions, typing indicators, terminal hooks, and final replies, but no supported send-and-continue acknowledgement-text path. No live transport run is needed to prove the requested capability is absent.

## Solution Assessment

Unclear until maintainers choose the product/API boundary. `messages.ackText` is plausible, but a non-terminal plugin or channel hook may be the cleaner long-term seam for cross-channel and channel-specific behavior.
