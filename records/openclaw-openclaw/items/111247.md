## What This Changes

The PR makes MCP App sandbox CSP query metadata accept only the exact base64url and normalized JSON form emitted by OpenClaw, rejecting padded, appended, or extra-field aliases with HTTP 400.

## System Context

MCP App resources generate a sandbox URL containing CSP metadata, and the gateway decodes that metadata before serving the isolated app origin. This change sits at that URL-to-policy boundary and determines whether a sandbox response is served or rejected.
