## Summary

Keep this PR open for maintainer review. The migration removes the deprecated registration, but its replacement drops DeepInfra’s existing automatic-selection policy, so configured auto-selection can regress even though explicit DeepInfra requests and doctor output improve.

## What This Changes

Migrates the DeepInfra plugin from the deprecated memory-specific embedding registration to the generic embedding-provider contract and adjusts provider lookup so an exact plugin ID wins before configured aliases.

## System Context

DeepInfra is an external provider plugin that supplies embeddings to OpenClaw’s memory and retrieval features. Plugin manifests register provider capabilities, and the shared embedding runtime resolves the configured provider into the adapter used for embedding requests.

## Best Possible Solution

Retain the generic contract migration, but preserve DeepInfra’s prior auto-selection and missing-credential continuation semantics through the supported generic path, with focused regression coverage for both explicit and auto-selected configurations.
