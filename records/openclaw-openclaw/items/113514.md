## Summary

Keep this PR open for normal maintainer review. The branch applies the existing Gateway continuation-admission primitive at both detached streaming entry points, and the added endpoint regressions now exercise the handler-return timing that caused the false draining failure; steipete is assigned and added the regression coverage after the initial review.

## What This Changes

The PR keeps Gateway root-work admission alive for detached streamed OpenAI-compatible chat and Responses runs, then releases it when each run finishes, with regression tests for both HTTP endpoints.

## System Context

The Gateway exposes OpenAI-compatible streaming HTTP endpoints that start an agent run after the HTTP handler returns. Gateway work admission tracks active runs so subordinate session and command-lane work is accepted during a turn and graceful draining waits for genuinely active work.
