## Label Justifications

- `P1`: A production Feishu group workflow can silently lose the agent's completed final response after the turn finishes.

## Summary

Keep open: current main and v2026.6.11 still have a Feishu zero-final path that sends only the generic no-visible fallback rather than recovering the current-turn assistant final from the session transcript, and the newer main-only suppressed-final recording commit is not proof of Feishu delivery.

## What This Changes

Feishu group turns can finish with `queuedFinal=false, replies=0` while the assistant final text exists in the session transcript and no Feishu message is sent.

## Best Possible Solution

Settle the durable final recovery contract in #87561, then patch Feishu or shared dispatch so current-turn final text is delivered or counted with explicit failure semantics without broad steady-state transcript scraping.
