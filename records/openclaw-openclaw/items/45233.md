## Summary

Keep open for maintainer product direction: current main and v2026.6.11 still do not advertise FreeBSD as a supported OS, the shell installer recognizes only macOS/Linux/WSL2, and Gateway service management is limited to macOS, Linux, and Windows. The narrower Homebrew-on-FreeBSD onboarding bug was fixed by https://github.com/openclaw/openclaw/pull/93521, but Tier 1 FreeBSD support remains a broader support-contract decision.

## What This Changes

Request to add FreeBSD as a Tier 1 supported OS with pkg/ports distribution.

## Best Possible Solution

Maintainers should decide the FreeBSD support tier first, then split any approved work into ports/pkg coordination, installer/update behavior, service management, docs, CI, and release validation before advertising official support.
