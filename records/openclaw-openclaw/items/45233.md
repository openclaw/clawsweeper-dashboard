Keep open for maintainer product direction: current main and v2026.6.11 still do not treat FreeBSD as an official install, service, release-validation, or documented platform. The narrower Homebrew-on-FreeBSD bug is fixed, and there is external FreeBSD-port-style prior art, but Tier 1 FreeBSD support remains an OpenClaw support-contract decision.

## What This Changes

Request to add FreeBSD as a supported OpenClaw operating system with a FreeBSD pkg/ports release path.

## Best Possible Solution

Maintainers should decide the FreeBSD support tier first, then split any approved work into ports/pkg coordination, installer/update behavior, service management, docs, CI, and release validation before advertising official support.
