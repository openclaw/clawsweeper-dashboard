## Summary

Keep open for maintainer product direction: current main and v2026.6.11 still do not advertise FreeBSD as an official supported OS, the hosted shell installer rejects non-macOS/Linux hosts, managed Gateway service support is limited to macOS/Linux/Windows, and release validation has no FreeBSD lane. The narrower Homebrew-on-FreeBSD bug is fixed, and an external FreeBSD ports entry now exists, but that is not the same as Tier 1 OpenClaw support. ([freshports.org](https://www.freshports.org/misc/openclaw/))

## What This Changes

Request official FreeBSD OS support for OpenClaw, including FreeBSD pkg/ports distribution.

## Best Possible Solution

Maintainers should define the FreeBSD support tier first, then split any approved work into ports/pkg coordination, installer/update behavior, service management, docs, CI, and release validation before advertising official support.
