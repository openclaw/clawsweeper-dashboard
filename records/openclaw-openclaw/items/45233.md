## Summary

Keep open for maintainer product direction: current main and v2026.6.11 still do not list FreeBSD as an official supported OS, the installer rejects non-macOS/Linux shell hosts, the Gateway service registry supports only macOS/Linux/Windows, and release checks expose no FreeBSD lane. The narrower Homebrew-on-FreeBSD bug is fixed by https://github.com/openclaw/openclaw/pull/93521, but Tier 1 FreeBSD support remains a broader support-contract decision.

## What This Changes

The issue requests official FreeBSD support, including FreeBSD package/ports distribution and Tier 1 operating-system support.

## Best Possible Solution

Maintainers should decide the FreeBSD support tier first, then split any approved work into ports/pkg coordination, installer/update behavior, service management, docs, CI, and release validation before advertising official support.
