## Summary

Keep open for maintainer product direction: current main and v2026.6.11 still do not advertise FreeBSD as an official platform, the shell installer accepts only macOS/Linux/WSL, Gateway managed services are only darwin/linux/win32, and release checks expose Linux/Windows/macOS lanes only. ## What This Changes

The issue requests Tier 1 FreeBSD support, including official OpenClaw releases as FreeBSD packages/ports.

## Best Possible Solution

Maintainers should decide the FreeBSD support tier first, then split any approved work into ports/pkg coordination, installer/update behavior, service management, docs, CI, and release validation before advertising official support.
