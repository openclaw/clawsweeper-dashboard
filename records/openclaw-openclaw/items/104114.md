## Summary

This PR remains necessary as the candidate fix for the open routing bug, but the latest head still makes skill-first authoring unconditional even though Workshop tool availability does not guarantee `skill-creator` eligibility. The attached screenshot shows one successful skill-present run only, so the compatibility branch and lifecycle routing remain unproven.

## What This Changes

The PR changes the Skill Workshop system-prompt rule to always route skill creation and editing through `skill-creator` first, while directing proposal lifecycle actions straight to `skill_workshop`.

## Best Possible Solution

Make Workshop prompt routing depend on the eligible skill inventory, retain direct Workshop authoring when `skill-creator` is unavailable, keep lifecycle actions direct, and verify all three states on the final head.
