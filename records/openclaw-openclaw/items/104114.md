## Summary

This PR addresses a real source-level routing conflict, but the unchanged reviewed head still applies `skill-creator` precedence to all durable workshop work instead of only authoring, so it can misroute proposal lifecycle and broader workflow requests; it also lacks after-fix real-agent proof.

## What This Changes

The PR appends an unconditional `skill-creator`-first instruction to the prompt sentence that routes durable skill creation, updating, and management through `skill_workshop`.

## Best Possible Solution

Define an explicit routing split: load `skill-creator` for skill creation, editing, validation, or restructuring; route existing-proposal lifecycle operations directly to `skill_workshop`; retain the no-direct-files rule; and cover and prove both paths.
