## Best Possible Solution

Land or replace a narrow doctor gateway-lock contribution that reuses the existing gateway owner-status semantics, reports stale/malformed locks, and removes only safe stale locks in repair mode.

## Reproduction Assessment

## Solution Assessment

Yes. A narrow doctor contribution is the right layer, but it should reuse or expose the gateway runtime owner-status logic instead of adding a weaker PID-only check.
