## Summary

The issue requests enforceable execution anti-drift guardrails: durable run state, artifact-gated status updates, status-loop escalation, timer thresholds, and post-green no-idle handling.

## Best Possible Solution

Define one core execution reliability contract for durable run state, artifact semantics, blocker/escalation behavior, and post-verification closure, then implement it through existing agent diagnostics/session architecture with SQLite-backed persistence where durable state is needed.
