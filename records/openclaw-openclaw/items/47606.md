## Summary

Keep open: current main has adjacent tool-call loop detection, cron phase watchdogs, process-local stuck-session diagnostics, heartbeat outcomes, and durable task/flow records, but it still lacks the requested durable artifact-gated status contract, escalation timers, and no-idle-after-green watchdog.

## What This Changes

The issue requests runtime anti-drift guardrails that persist per-run state, require status updates to cite new artifacts or blockers, escalate stale progress, and close or continue promptly after green verification.

## Best Possible Solution

Define one core execution reliability contract for artifacts, phases, blockers, escalation cooldowns, and post-verification closure, implemented through existing session/task/lifecycle ownership with SQLite persistence where durable state is required.
