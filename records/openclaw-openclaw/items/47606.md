## Summary

Keep open: current main has adjacent strict-agentic, terminal-outcome, and post-compaction loop safeguards, but it does not implement the requested persisted run-state, artifact-gated status, escalation-timer, and no-idle-after-green enforcement contract.

## What This Changes

The issue requests enforceable execution guardrails that persist per-run state, gate progress messages on new artifacts, detect no-progress loops, escalate stalls, and prevent post-green idle gaps.

## Best Possible Solution

Define one additive lifecycle/progress contract that covers execution evidence, required terminal completion or blocker state, restart-persistent guard state, escalation timers, telemetry, and client-visible semantics without creating a second competing progress state machine.
