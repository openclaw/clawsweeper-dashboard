## Summary

Keep open: current main has adjacent loop detection, heartbeat outcome recording, cron phase watchdogs, and subagent run persistence, but it still does not implement the requested durable artifact-gated status contract, escalation timers, or no-idle-after-green watchdog. This remains a product-contract design item rather than a narrow cleanup close.

## What This Changes

The issue requests runtime guardrails to prevent execution-status drift by persisting per-run state, gating status updates on new artifacts, adding escalation timers, and enforcing no idle time after green verification.

## Best Possible Solution

Define one core execution reliability contract for durable run state, artifact semantics, blocker/escalation behavior, and post-verification closure, implemented through existing session/task/diagnostic ownership with SQLite persistence where durable state is needed.
