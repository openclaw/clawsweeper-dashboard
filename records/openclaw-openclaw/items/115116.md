## What This Changes

The PR removes Ollama setup’s private non-Error rejection coercion helper, uses the shared `openclaw/plugin-sdk/error-runtime` helper instead, and adds coverage for a non-Error model-pull stream rejection.

## System Context

Ollama setup probes the configured local Ollama endpoint and pulls a selected model when it is absent. A pull-stream failure is converted to an Error, formatted into user-facing progress output, and surfaced to the onboarding caller as a cancellation failure.
