## What This Changes

This PR makes the scheduled external-link audit ignore upstream 5xx responses, replaces or removes verified dead documentation targets, and resolves README contributor links through durable GitHub account IDs so renamed or deleted handles are not mislinked.

## System Context

The scheduled external-link workflow scans public documentation URLs and publishes an advisory link-rot report without gating pull requests. Separately, the contributor generator builds README credit links from GitHub contributor metadata and historical seed entries.
