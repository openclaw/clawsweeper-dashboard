## Summary

Keep open: current main and the latest release still lack a TUI viewport/follow policy, and both the current and shipped pinned pi-tui renderers can still full-redraw through the scrollback-clearing path. The merged WebChat auto-scroll setting is a different surface and does not fix terminal viewport anchoring.

## What This Changes

The issue asks for TUI viewport stability and controlled auto-follow during chat streaming so new input/output does not aggressively jump the terminal view.

## Best Possible Solution

Resolve this as TUI viewport/follow stability: prevent content-driven full redraws from clearing or jumping scrollback, follow only when the user is already at the tail, and prove the behavior with a real PTY run plus PI_DEBUG_REDRAW evidence.
