## Summary

Keep open: current main still routes TUI streaming through ChatLog/Markdown into pi-tui without a TUI viewport anchor or auto-scroll policy, and the merged WebChat auto-scroll selector is explicitly a different surface.

## What This Changes

The issue reports disruptive TUI viewport jumps during active chat use and asks for stable scroll anchoring or an explicit TUI auto-scroll control.

## Best Possible Solution

Choose a TUI scroll policy, then fix the TUI/pi-tui rendering path so streaming updates preserve the viewport unless the user is intentionally following the tail.
