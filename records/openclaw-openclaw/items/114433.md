## What This Changes

The PR changes Chat’s background-task rail and the gateway task-list filter so a chat thread requests, receives, and updates tasks associated with its canonical session instead of every task for the same agent.

## System Context

Chat’s background-task rail asks the gateway for task-ledger records and also receives live task updates. This change makes the session key, rather than the agent id, the scope passed through that request-and-update path so adjacent chat threads do not display each other’s work.
