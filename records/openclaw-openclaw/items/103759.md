## Summary

Keep this PR open for repair. The isolation from credentials and registry mutation is sound, but two central contracts are broken: the artifact path skips runtime generation performed by publication, and the trusted-main requirement makes branch-bound Tideclaw and extended-stable source validation unreachable. Green static checks do not exercise either dispatch scenario.

## What This Changes

Adds a trusted-main, non-publishing plugin npm artifact preflight mode with immutable artifact upload/readback verification, focused workflow tests, changed-test routing, and operator instructions.

## Best Possible Solution

Keep the workflow implementation trusted from `main`, but prepare artifacts through the same deterministic runtime-build and manifest-overlay path as publication and validate the selected source SHA against its actual main, release, Tideclaw, or extended-stable branch independently of `github.ref`.
