## Summary

Keep open: current main and v2026.6.11 still delegate Codex compaction to native app-server state without an OpenClaw-visible summary payload, and the nearest related issues do not own the specific topic-diversity failure after a topic switch.

## What This Changes

The issue reports that Codex-runtime native compaction loses earlier topic diversity, causing ambiguous follow-up messages after a topic switch to be interpreted only through the most recent topic.

## Best Possible Solution

Design an owner-approved Codex continuity path that preserves bounded cross-topic anchors after native compaction, preferably by consuming upstream summary metadata if Codex exposes it or by injecting a tested topic/ambiguity index without rewriting Codex-owned thread history.

## Reproduction Assessment
