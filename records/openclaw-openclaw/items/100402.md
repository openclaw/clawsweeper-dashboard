Overall confidence: 0.91

Full review comments:

- **[P1] Keep lost-relay PreToolUse approval-safe:** `src/agents/harness/native-hook-relay.ts:598`
  - body: This marks loop-detection-only PreToolUse commands as safe to no-op when the relay is unavailable, but the normal path also enforces core Skill Workshop lifecycle approval through `resolveSkillWorkshopToolApproval`, which `hasBeforeToolCallPolicy()` does not cover. If Gateway state is lost, Codex treats the no-op as continue and `skill_workshop` apply/reject/quarantine can proceed without the approval that would have run through the relay; include that core policy in the decision or keep this path fail-closed.
  - confidence: 0.93
- **[P2] Move private runbook out of public docs:** `docs/operations/aerith-openclaw-runtime-resilience.md:9-10`
  - body: This page is added under public `docs/operations`, which the docs sync publishes except for `docs/internal`, and it includes Aerith/phoning.ai/Termius-specific operator text plus hard-coded `/home/node` paths. Public docs must stay generic, so move this runbook to ignored internal/private docs or rewrite it as a generic user-facing recovery page.
  - confidence: 0.91
- **[P2] Handle missing session directories:** `scripts/aerith-runtime-resilience.mjs:121-122`
  - body: When `--session-id` is omitted, this unguarded `readdirSync` throws if `agents/main/sessions` has not been created yet, which is plausible on a fresh or partially recovered home. The diagnostic should report no bindings or a missing-sessions finding instead of exiting with a stack trace.
  - confidence: 0.88
- **[P2] Resolve Codex from current plugin install roots:** `scripts/aerith-runtime-resilience.mjs:142-145`
  - body: The diagnostic only reads the legacy flat npm root and two fixed hashed chunk files, but documented/current npm plugin installs live under `npm/projects/<encoded-package>` and rebuilt chunks will have different names. That can report `ok` for a missing persistence fix or false guidance after a normal rebuild; use install records/project roots and scan stable runtime contents instead.
  - confidence: 0.9
- **[P2] Reuse one backup directory timestamp:** `docs/operations/aerith-openclaw-runtime-resilience.md:149-150`
  - body: The runbook computes the backup directory timestamp separately for `mkdir` and `cp`, so a second rollover can make the copy target a directory that was never created, and `|| true` hides the failed backup. Store the backup path once and reuse it for both commands.
  - confidence: 0.85
- **[P2] Add script tests to the full-suite planner:** `test/vitest/vitest.tooling.config.ts:18`
  - body: Adding `scripts/*.test.mjs` to the Vitest config does not make the default full-suite planner run the new test, because `listToolingFullSuiteTestTargets` still enumerates only `.test.ts` files under `test` and `src/scripts`. Update the enumerator or move the test under an existing enumerated tooling test root.
  - confidence: 0.9
