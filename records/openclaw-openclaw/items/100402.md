  - body: When `skills.workshop.approvalPolicy` is `"auto"`, the live `runBeforeToolCallHook` path passes the registration config into `resolveSkillWorkshopToolApproval` and allows lifecycle actions.   - confidence: 0.9

  - body: This page is added under public `docs/operations`, but it names private app/operator context and hard-coded host paths.   - confidence: 0.94

  - body: The diagnostic checks only `~/.openclaw/npm/node_modules/@openclaw/codex/dist` and two fixed hashed chunk names.   - body: The backup commands compute the timestamp twice, so a one-second rollover can make `cp` target a directory that `mkdir` never created, and `|| true` hides the failed backup. Store the backup directory once and use that variable for both commands.
