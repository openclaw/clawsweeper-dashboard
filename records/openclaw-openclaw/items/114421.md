## Summary

Keep this PR open for maintainer review. Preferring the durable run session key fixes new DM-created cron bindings, but the patch does not show how already-persisted jobs with the stale policy-scoped key are repaired or safely handled after upgrade.

## What This Changes

The PR makes cron tool creation prefer the live run's durable store session key over a DM policy-scoped key and adds wiring coverage for that preference and fallback.

## System Context

Embedded agent runs give tools both a policy-scoped session key for sandbox and delivery rules and, when different, a durable store session key that owns the conversation transcript. The cron tool persists a chosen session binding for later runs, wakes, and reminder-history lookups.
