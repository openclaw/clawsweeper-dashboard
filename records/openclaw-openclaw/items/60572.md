## What This Changes

Requests replacing the single `plugins.slots.memory` selector with purpose-specific, per-agent memory role slots for recall, compaction, capture, user modeling, and related memory lifecycle work.

## Best Possible Solution

Keep this issue as the canonical tracker until maintainers either land or replace the linked role-slot implementation, or explicitly choose a narrower single-slot-compatible memory plugin API direction.
