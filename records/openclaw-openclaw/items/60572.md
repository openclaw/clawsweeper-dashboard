## Summary

Keep open: current `main` and the latest release still expose one scalar `plugins.slots.memory` owner, while the requested role-slot architecture is only represented by the open, conflicting implementation PR at https://github.com/openclaw/openclaw/pull/88504.

## What This Changes

The issue requests purpose-specific, optionally per-agent memory role slots so memory recall, capture, compaction, dreaming, and user modeling plugins can coexist.

## Best Possible Solution

Keep this as the canonical memory role-slot discussion until maintainers either land an approved, conflict-free role-slot implementation or explicitly decide to keep memory single-slot with companion plugin hooks.
