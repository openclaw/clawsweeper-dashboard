## Summary

Keep open: current main and the latest stable release still expose a single exclusive scalar memory slot, and the open linked implementation candidate has not merged. The remaining decision is whether OpenClaw should accept durable memory role-slot config/API surface in core.

## What This Changes

This issue requests replacing the single `plugins.slots.memory` selector with purpose-specific global and per-agent memory role slots for recall, compaction, capture, dreaming, and user modeling.

## Best Possible Solution

Use https://github.com/openclaw/openclaw/pull/88504 as the canonical review path, decide the role taxonomy and upgrade behavior there, and close this issue only after that PR merges or maintainers reject the direction.
