## Summary

Keep open: current main and the latest release still expose one scalar memory slot, while the linked role-slot implementation is open, unmerged, and currently conflicting.

## What This Changes

Replace the single `plugins.slots.memory` owner with role-specific global and per-agent memory slots for recall, capture, compaction, dreaming, and user modeling.

## Best Possible Solution

Decide the role-slot product direction, then either land the linked PR with schema, doctor, docs, upgrade proof, and conflict resolution, or close this after maintainers explicitly reject the architecture.
