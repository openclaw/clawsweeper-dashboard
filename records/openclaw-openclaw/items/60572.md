## Summary

Keep open: current main and v2026.6.11 still model one exclusive scalar memory slot, and https://github.com/openclaw/openclaw/pull/88504 remains open and conflicting. The discussion adds useful production evidence for Honcho, Mem0, ByteRover, Hindsight, and dreaming coexistence, but the remaining work is a public memory role-slot/plugin API decision rather than conservative cleanup.

## What This Changes

Request to replace the single exclusive `plugins.slots.memory` selector with purpose-specific memory role slots and per-agent memory-slot overrides so multiple memory providers can coexist.

## Best Possible Solution

Settle the memory role-slot API in maintainer review, then either land a conflict-free, tested successor to https://github.com/openclaw/openclaw/pull/88504 or explicitly choose a narrower single-slot plus plugin-workaround direction.
