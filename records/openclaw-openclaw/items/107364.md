Full review comments:

- **[P1] Keep terminal uploads out of direct node.invoke:** `src/gateway/node-command-policy.ts:75`
  - body: Spreading NODE_FILE_COMMANDS into the general desktop-node allowlist makes terminal.upload callable as a standalone admin node command.   - confidence: 0.99
- **[P2] Append terminal.upload after the legacy method tail:** `src/gateway/methods/core-descriptors.ts:345`
  - body: This descriptor sequence is compatibility-sensitive and guarded as append-only, but the new entry shifts every advertised method index after sessions.catalog.read. Append terminal.upload after the established legacy tail instead of inserting it here.
  - confidence: 0.99
- **[P2] Hide uploads on Android or add its native chooser:** `apps/android/app/src/main/java/ai/openclaw/app/gateway/GatewayProtocol.kt:368`
  - body: Android now declares terminal.upload while its fullscreen terminal WebView does not implement WebChromeClient.onShowFileChooser. The shared UI therefore renders a picker that cannot return files when tapped in the Android app; add the native chooser bridge or suppress the upload affordance for that host.
  - confidence: 0.97
