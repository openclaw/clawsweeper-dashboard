## Summary

Keep this PR open for a small test-race correction: the new predicate still accepts a partially written numeric PID, so it can proceed before the PID file is complete and retain the intermittent failure mode. The PR has focused terminal proof and no security concern, but the `maintainer` label requires explicit maintainer handling rather than automated cleanup.

## What This Changes

This PR updates the plugin-gateway gauntlet test so it polls the grandchild PID file until it can parse an integer instead of waiting only for the file to exist.

## System Context

The plugin gateway gauntlet starts helper processes to exercise command timeouts and process-group cleanup. This test reads a spawned grandchild’s PID, verifies it is alive, then checks that timeout cleanup reaches the correct process group.

## Architecture Diagram

## Best Possible Solution

Use an unambiguous completion signal for this test case—such as atomically replacing the PID file or waiting on a separate ready marker written after the PID write—then retain the focused process-alive assertion.
