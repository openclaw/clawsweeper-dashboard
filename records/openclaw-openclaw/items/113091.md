This PR documents how operators can diagnose and manually recover channel auto-start after the gateway crash-loop breaker enters safe mode, with links from gateway and channel troubleshooting pages.

## System Context

The gateway records repeated unclean boots and can suppress automatic startup of channels while retaining a healthy control plane. Operators inspect gateway and channel status, correct the underlying startup fault, then either use the manual channel-start control-plane request or wait for the breaker window to drain.
