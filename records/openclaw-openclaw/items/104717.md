## Summary

The exact-head re-review confirms that five of six prior blockers are fixed, but failed Claude catalog adoption can still strand a locked initializing session because rollback selects a harness-only capability for a plugin-owned CLI row. ## What This Changes

Adds generic `sessions.catalog.*` Gateway and Plugin SDK contracts, renders Claude and Codex catalogs in the native sidebar and Chat pane with pagination, adopts supported local sessions into native chats, and removes the provider-specific session views.

## Best Possible Solution

Make session-creation rollback select the guarded deletion capability from actual ownership (`agentHarnessId` versus `pluginOwnerId`), preserve the existing catalog opt-out unless maintainers explicitly approve a new consent contract, and provide redacted real sidebar/Chat proof for pagination, transcript reading, and continuation.
