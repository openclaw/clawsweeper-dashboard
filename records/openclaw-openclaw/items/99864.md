The PR changes compaction token estimation to reject cache-bucket fallbacks above the model context window, passes context windows into compaction callers, and adds cached-usage regression tests.

## Best Possible Solution

Populate or carry a trusted latest per-call context total/prompt snapshot before compaction, keep cache-inclusive fallback semantics for true single-call usage, and land one canonical fix for https://github.com/openclaw/openclaw/issues/99843.
