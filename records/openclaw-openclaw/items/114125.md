The PR passes the existing Telegram `linkPreview` setting into streamed draft replies so both the initial message and subsequent edits suppress URL previews when the setting is `false`.

## System Context

Telegram draft streaming sends a provisional reply and edits it while an agent response arrives. The Telegram channel configuration must be applied to both API operations so streamed replies honor the same presentation policy as ordinary sends.
