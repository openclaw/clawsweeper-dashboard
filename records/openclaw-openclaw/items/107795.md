## Summary

This is a worthwhile prerequisite isolation repair, but it deliberately breaks the shipped ACP manager-instance contract and current-head evidence is test-only. Keep it open for ACP/plugin-owner direction on preserving class identity, real behavior proof, and conflict resolution.

## What This Changes

The PR adds a canonical plugin session projection/reconciliation layer and replaces the Plugin SDK ACP manager object with a restricted frozen facade so core restart-recovery state cannot be observed or mutated by plugins.

## Best Possible Solution

Keep one canonical projection/reconciliation owner for every plugin session surface, but harden `AcpSessionManager` itself with runtime-private dependencies and projected public results so `getAcpSessionManager()` can retain its shipped instance contract; then add current-head real plugin proof and resolve the merge conflict.
