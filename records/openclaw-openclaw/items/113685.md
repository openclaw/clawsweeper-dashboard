The branch adds a shared CLI helper that converts child-process termination signals into conventional shell exit codes and uses it for debug-proxy and container-targeted commands.

## System Context

OpenClaw’s CLI can run nested commands through a debug proxy or a configured container. Those wrappers receive a child process’s numeric status or terminating signal and expose an exit code to the invoking shell, scripts, and supervisors.
