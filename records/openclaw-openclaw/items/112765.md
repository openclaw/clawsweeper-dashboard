## What This Changes

This PR adds `openclaw mcp call <server> <tool>` so operators can invoke one configured, filtered MCP tool with bounded JSON input and receive its structured result on stdout.

## System Context

The MCP CLI manages configured outbound MCP servers and already provides static diagnostics and live catalog probing. This PR would add one-shot tool execution through the same session-scoped runtime, transport, OAuth state, filters, and timeouts used for agent-side MCP access.
