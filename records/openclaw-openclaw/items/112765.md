## What This Changes

This PR adds `openclaw mcp call <server> <tool>` to execute one enabled, filter-visible configured MCP tool with JSON input and print its structured result for operator scripting and verification.

## System Context

OpenClaw stores outbound MCP server definitions in its central configuration and later projects them into agent runtimes. This command would add a direct operator path that resolves that saved configuration, opens a session-scoped MCP runtime, invokes one allowed tool, and returns the tool result to the terminal.
