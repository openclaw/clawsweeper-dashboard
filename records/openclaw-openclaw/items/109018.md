## Summary

Keep this PR open: the linked shipped-version failure is credible and the patch appears technically coherent, but the external contribution provides only simulated localhost/test evidence rather than the required after-fix CLI behavior from a real rate-limited provider.

## What This Changes

The PR propagates provider retry timing into embedding errors, adds a shared bounded cooldown for concurrent memory indexing, increases indexing retries, and retains the shorter interactive-query retry policy.

## Best Possible Solution

Keep interactive memory queries on their short budget while allowing indexing workers to share a bounded, abortable provider-advertised cooldown, then demonstrate the complete CLI path against a real transient quota window before merge.
