## Summary

This is a credible fix for the linked indexing failure, but it needs changes before merge: Google-specific `RetryInfo` parsing is placed in the shared provider HTTP helper rather than the Google plugin, and the external PR provides only localhost integration-test proof rather than a real quota-limited provider run.

## What This Changes

The PR adds provider retry-delay metadata, a shared abortable cooldown for concurrent memory embedding batches, and a longer bounded retry policy for indexing while retaining shorter query retries.

## Best Possible Solution

Keep standard transport-neutral retry metadata in the shared provider error contract, move Google `RetryInfo` extraction into the Google plugin through a narrow generic hook or error-construction input, retain the bounded memory-core cooldown, and demonstrate both transient recovery and permanent-quota exit behavior through the real CLI.
