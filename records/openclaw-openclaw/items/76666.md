## What This Changes

The PR adds a gateway startup task that preloads non-transient builtin memory managers for sessions-enabled agents so session transcript listeners are armed before the first memory search.

## Best Possible Solution

Land the builtin startup preload only after the archive scheduling fix is merged or included, remove release-owned changelog churn, correct the backend-scope comment, and make the builtin-only lifetime/qmd deferral an explicit maintainer decision.

## Reproduction Assessment

Yes, at source level. Current main and the computed merge result do not construct a builtin MemoryIndexManager at gateway startup, and the current listener still returns before scheduling reset/deleted archive file events.

## Solution Assessment

No, not as-is. The builtin preload is the right timing half of the fix, but it needs the archive-listener guard removed or already merged so the preloaded listener can actually schedule reset/deleted archives.
