## Summary

Keep this PR open for one narrow correctness repair: the new SQLite head budget sums `event_json` byte lengths but omits JSONL newline separators, so it can read past the file-backed 8 KiB boundary it claims to match. The submitted terminal proof is otherwise concrete, and the earlier oversized-row blocker appears addressed.

## What This Changes

The PR replaces full SQLite transcript materialization for derived session titles with byte-bounded head and tail reads and adds regressions for compact, oversized, and malformed events.

## Best Possible Solution

Keep the bounded SQLite design, but make its contiguous-prefix selection count the JSONL separators before each later record and add a boundary regression showing the SQLite and file-backed title windows select the same final fitting record.
