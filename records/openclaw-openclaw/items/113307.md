## Summary

This PR addresses a real source-level installer failure path and has credible shell-level proof, but its raw-shebang rule deliberately tightens the accepted contract for trusted upstream setup scripts. Keep it open for the explicit compatibility/security-boundary decision rather than treating the earlier closed replacement PR as a resolution. ## What This Changes

The branch makes remote-script downloads fail closed before execution, rejects empty or non-shebang files, sanitizes invalid-content diagnostics, and adds installer test coverage for the new validation path.

## System Context

OpenClaw’s shell installer downloads third-party Homebrew and NodeSource setup scripts while preparing a machine for installation. This change inserts a guard between the download helper and `/bin/bash`, so malformed downloads stop the installer instead of being interpreted as shell input.

## Best Possible Solution

Retain the explicit downloader-result checks and, if maintainers accept the compatibility tradeoff, document the raw-shebang requirement as the bounded contract for these managed upstream script URLs with focused fixtures for each supported provider.
