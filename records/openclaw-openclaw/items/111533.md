## Label Justifications

- `P1`: The patch addresses a macOS gateway startup regression that can leave HTTP and WebSocket traffic unresponsive during provider initialization.

## Summary

This PR remains necessary: the merged warmup in https://github.com/openclaw/openclaw/pull/111473 is currently too late for a worker provider that performs its first TLS work during reconciliation. The proposed post-attach barrier moves that work ahead of reconciliation while delegating CA-option precedence to Node; the protected `maintainer` label means it should proceed through normal maintainer review rather than automated cleanup.

## What This Changes

Moves the macOS system-CA warmup from sidecar startup to post-attach startup before worker reconciliation, and replaces custom system-CA option parsing with Node’s effective default-CA resolution.

## Best Possible Solution

Keep the pre-reconciliation warmup barrier, preserve Node as the authority for effective CA selection, and land only after the normal maintainer review confirms the cited macOS proof remains representative.
