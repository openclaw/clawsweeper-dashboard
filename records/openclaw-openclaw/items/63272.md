## Summary

Keep open: current main and the latest release still lack `openclaw skills uninstall`, while source inspection confirms ClawHub skill installs write tracking metadata that `skills update --all` later consumes. The issue remains the canonical design/product tracker because prior implementation PRs are closed unmerged and the destructive CLI semantics still need maintainer direction.

## What This Changes

Request to add `openclaw skills uninstall <slug>` so a ClawHub-installed skill can be removed from the selected skills directory and its `.clawhub/lock.json` tracking entry cleaned up together.

## Best Possible Solution

Keep this issue open as the canonical design tracker, settle the destructive CLI contract, then land a narrow implementation in the skills CLI and lifecycle helpers with path-containment checks and focused lockfile/update tests.
