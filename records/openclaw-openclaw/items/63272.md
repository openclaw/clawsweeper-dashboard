## Summary

Keep open: current main and v2026.6.11 still expose `openclaw skills` search/install/update/verify without `skills uninstall`, and the linked CLI implementation PR is closed unmerged.

## What This Changes

Add an `openclaw skills uninstall <slug>` CLI workflow that safely removes a workspace ClawHub skill directory and its `.clawhub/lock.json` entry.

## Best Possible Solution

Keep this as the canonical design tracker until maintainers approve a narrow CLI lifecycle implementation that deletes only safe workspace skill directories and updates `.clawhub/lock.json`, with tests and docs for global, agent, and manual-skill semantics.
