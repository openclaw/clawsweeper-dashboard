## Summary

Keep open: current main and v2026.6.11 still lack `openclaw skills uninstall`, while ClawHub install/update code still writes and consumes the lockfile state that makes manual deletion incomplete. The issue remains the canonical CLI design tracker because the direct implementation attempt at https://github.com/openclaw/openclaw/pull/94828 and the adjacent Gateway RPC attempt at https://github.com/openclaw/openclaw/pull/69319 are both closed unmerged.

## What This Changes

The issue requests a CLI `openclaw skills uninstall <slug>` command that removes a ClawHub-installed skill directory and cleans the workspace `.clawhub/lock.json` entry.

## Best Possible Solution

Keep this as the canonical CLI uninstall design tracker until maintainers approve a narrow lifecycle/CLI/docs implementation or deliberately choose a different skill removal surface.

## Maintainer Decision

Question: Should OpenClaw add a destructive `openclaw skills uninstall <slug>` CLI now, and should it remove only provenance-valid ClawHub skill directories plus lockfile entries or also support manual skill directories?

Rationale: The code path is clear enough to implement, but deleting workspace directories and deciding how manual, stale-lock, global, and agent-scoped installs behave is a product/security contract rather than a purely mechanical bug fix.

Likely owner: steipete

Owner reason: This person introduced the native ClawHub install and skills CLI flows that the proposed command extends.

Owner confidence: high

Options:

- **Approve narrow ClawHub uninstall CLI (recommended):** Add a CLI command that deletes only provenance-valid ClawHub skill directories, cleans stale lockfile entries, supports dry-run/JSON/confirmation, and documents the contract.
- **Require Gateway-first semantics:** Defer the CLI until a Gateway `skills.uninstall` contract is approved so UI and CLI use the same lifecycle behavior.
- **Decline destructive CLI for now:** Keep manual deletion and documentation as the supported path until maintainers want first-class skill removal.
