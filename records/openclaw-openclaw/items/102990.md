## Summary

Keep this PR open for revision: the latest head fixes cross-origin deletion but still lets one active webhook evict another same-NAS webhook’s last-known-good reply mapping, and the supplied proof is limited to tests and synthetic cache output.

## What This Changes

The PR adds same-origin TTL eviction for Synology Chat user-cache entries and regression coverage for same-origin eviction and cross-origin fallback preservation.

## Best Possible Solution

Use an explicitly bounded or plugin-owned endpoint lifecycle policy that reclaims obsolete URLs without allowing one active webhook URL to erase another active webhook’s stale-on-error users, with a same-origin two-token failure regression.
