## Summary

The current head narrows the prior global sweep, but it still deletes another active webhook’s last-known-good user list whenever both webhooks share one NAS origin. That leaves the central message-delivery regression unresolved for the same-origin multi-webhook scenario the PR targets, so the patch still needs changes before merge.

## What This Changes

The PR evicts TTL-expired Synology Chat user-cache entries from the current URL origin and adds tests for same-origin eviction and cross-origin preservation.

## Best Possible Solution

Track or bound obsolete webhook cache entries at a plugin-owned endpoint lifecycle boundary, while preserving each active webhook’s last-known-good users through transient refresh failures; add a same-origin, two-token failure regression test.
