## What This Changes

The issue requests human-friendly names for paired devices, settable from CLI and visible in the CLI and Control UI paired-device lists.

## Best Possible Solution

Land or replace the linked narrow implementation with a durable operator-owned label across Gateway protocol, CLI, Control UI, docs, and authorization coverage while keeping broader device metadata display in the separate canonical issue.

## Reproduction Assessment

## Solution Assessment

Yes. A separate operator-owned label with explicit precedence over client displayName is the narrow maintainable solution; reusing displayName would let reconnect metadata overwrite the user label.
