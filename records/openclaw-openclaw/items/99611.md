## Summary

Keep open. This is a maintainer-authored, protected-label feature request: current main has Active Memory and session-backed memory search, but it still lacks the requested default-off per-assistant private cross-conversation recall setting with narrower authorization than session tools.

## What This Changes

The issue requests a default-off per-assistant mode that lets a trusted personal assistant use bounded read-only recall from its other private conversations while preserving existing session/tool visibility boundaries.

## Best Possible Solution

Keep this issue open as the canonical maintainer design item for a default-off, owner/admin-controlled Active Memory recall mode that preserves transcript and delivery isolation while adding a narrower read-only same-assistant private recall authorization path.

## Reproduction Assessment

Not applicable as a runtime bug repro; this is a feature request for a new default-off recall mode. Source inspection does confirm the missing product surface: current main has Active Memory and session transcript search, but no per-assistant remember-across-private-conversations setting.

## Solution Assessment

Likely yes as a product direction, but it needs maintainer design approval. Reusing Memory Core plus Active Memory is the right boundary; widening tools.sessions.visibility is not the best solution because it also expands explicit session tools.
