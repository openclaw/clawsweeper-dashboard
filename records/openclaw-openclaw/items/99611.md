## Summary

Keep open. Current main and v2026.6.11 still require experimental session transcript indexing plus broader session-tool visibility for same-agent cross-session recall, and this MEMBER-authored, maintainer-labeled feature asks for a narrower default-off product/security setting that is not implemented.

## What This Changes

The issue requests a default-off per-assistant setting that lets trusted personal assistants use bounded read-only context from their other private conversations while keeping shared conversations and session tools isolated.

## Best Possible Solution

Add a default-off Active Memory/Memory Core authorization path for same-assistant private transcript snippets only, with owner/admin controls, unchanged session tools, shared-conversation exclusion, builtin plus QMD parity tests, and public docs.

## Reproduction Assessment

Not applicable as a bug reproduction; this is a feature/product request. Source and docs confirm the missing surface because current main has Active Memory and session transcript search but no default-off per-assistant remember-across-private-conversations setting.

## Solution Assessment

Likely yes as a product direction, but it needs maintainer design and security approval. Reusing Memory Core plus Active Memory is the right boundary; widening tools.sessions.visibility is not the best fix because it expands explicit session tools too.
