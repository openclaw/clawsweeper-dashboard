## Summary

Keep open. This maintainer-authored, protected-label feature request is still necessary: current main has session transcript indexing and Active Memory recall, but no default-off per-assistant private cross-conversation recall setting, and the existing session-backed recall path still depends on broader session-tool visibility.

## What This Changes

Request a default-off, owner/admin-controlled per-assistant setting that lets Active Memory use relevant context from the same assistant's other private conversations without changing session-tool visibility or shared-conversation isolation.

## Best Possible Solution

Keep this as the canonical product/design item for a default-off per-assistant Active Memory mode that grants only bounded read-only same-assistant private recall while preserving transcript, group/channel, cross-assistant, sandbox, session-tool, and delivery-route boundaries.

## Reproduction Assessment

Not applicable as a feature request. Source inspection confirms the missing product surface: current main has Active Memory and session transcript search, but no per-assistant remember-across-private-conversations setting.

## Solution Assessment

Likely yes as a product direction, but it needs maintainer security/design approval. Reusing Memory Core and Active Memory is the right boundary; widening `tools.sessions.visibility` alone is not the best fix because it also expands explicit session tools.
