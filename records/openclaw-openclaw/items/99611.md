## Summary

Keep open. This is a maintainer-authored, protected-label feature request; current main has session transcript indexing and Active Memory recall, but session-backed hits still rely on `tools.sessions.visibility` and there is no default-off per-assistant setting for private cross-conversation recall.

## What This Changes

Request a default-off per-assistant Owner/admin setting that lets Active Memory use relevant same-assistant private transcript snippets across private conversations without widening ordinary session tools or group/channel boundaries.

## Best Possible Solution

Keep this issue open as the canonical maintainer product/design item for a default-off, owner/admin-controlled Active Memory recall mode that preserves transcript and delivery isolation while granting only bounded read-only same-assistant private recall.

## Reproduction Assessment

Not applicable as a feature request. The source check does confirm the missing product surface: current main has Active Memory and session transcript search, but no per-assistant remember-across-private-conversations setting.

## Solution Assessment

Likely yes as a product direction, but it needs maintainer design approval. Reusing Memory Core and Active Memory is the right boundary; simply widening `tools.sessions.visibility` is not the best solution because it also expands explicit session tools.
