## Summary

Keep open. This is a MEMBER-authored, maintainer-labeled feature/product item; current main and v2026.6.11 have Active Memory plus opt-in session transcript search, but not the requested default-off per-assistant private cross-conversation recall authorization.

## What This Changes

Requests a default-off per-assistant setting that lets owner-approved private conversations use relevant context from the same assistant's other private conversations without broadening session tools.

## Best Possible Solution

Keep this as the canonical maintainer product/security design item and implement a default-off Active Memory/Memory Core recall mode that preserves transcript, delivery, group/channel, sandbox, and tool-visibility boundaries.

## Reproduction Assessment

Not applicable as a bug reproduction; this is a feature/product request. Source and docs confirm the missing surface: current main has Active Memory and opt-in session transcript search, but no per-assistant remember-across-private-conversations setting.

## Solution Assessment

Likely yes as a product direction, but it needs maintainer design and security approval. Reusing Memory Core plus Active Memory is the right boundary; widening `tools.sessions.visibility` is not the best fix because it also broadens explicit session tools.
