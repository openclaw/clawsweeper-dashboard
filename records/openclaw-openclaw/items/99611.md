## Summary

Keep open. Current main has Active Memory, session transcript indexing, and session-hit visibility filtering, but it still lacks the requested default-off per-assistant private cross-conversation recall setting; the issue is maintainer-authored, protected by the `maintainer` label, and needs product/security review before implementation.

## What This Changes

Request a default-off, owner/admin-controlled per-assistant mode that lets Active Memory recall relevant snippets from the same assistant's other private conversations without broadening ordinary session tools.

## Best Possible Solution

Keep this issue as the canonical product/security design item for a default-off Active Memory recall mode that preserves transcript, group/channel, assistant, sandbox, and delivery-route boundaries while granting only bounded same-assistant private recall.

## Reproduction Assessment
