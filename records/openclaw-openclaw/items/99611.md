## What This Changes

The issue requests a default-off per-assistant setting for automatic read-only recall across the same assistant’s private conversations while keeping shared conversations isolated.

## Best Possible Solution

Define a maintainer-approved, default-off per-assistant private recall mode that reuses Memory Core and Active Memory while keeping normal session tools and shared conversations isolated.
