Keep open. ## What This Changes

Add a default-off per-assistant setting that lets trusted personal assistants use bounded Active Memory recall from other private conversations without widening ordinary session tools.

## Best Possible Solution

Keep this issue open as the canonical maintainer design item for a default-off Owner/admin-controlled Active Memory recall mode that preserves transcript, delivery, group/channel, assistant, and session-tool boundaries.

## Solution Assessment

Likely yes as a direction, but it needs maintainer design approval. Reusing Memory Core and Active Memory is the right owner boundary; widening tools.sessions.visibility is not the best fix because it expands explicit session tools too.
