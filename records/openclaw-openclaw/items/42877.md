## Summary

Keep open: current main and v2026.6.11 still expose memory recall and bounded read/flush helpers, but not the requested bounded add/replace/remove memory write contract with hard per-store character limits, usage feedback, duplicate handling, frozen snapshot semantics, and credential-safety policy.

## What This Changes

Request a built-in bounded memory write tool for add/replace/remove operations with hard character limits, duplicate handling, and optional credential-pattern blocking.

## Best Possible Solution

Define a memory-core-owned bounded CRUD contract with explicit write authority, hard-limit and usage semantics, replacement identity, duplicate/consolidation policy, secret handling, docs, and focused tests before implementation.
