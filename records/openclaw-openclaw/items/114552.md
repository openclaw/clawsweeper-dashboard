## What This Changes

The Slack plugin changes durable ingress lane selection so room messages in different Slack threads use separate lanes, while direct messages and non-threaded channel events retain their existing lane behavior.

## System Context

Slack events enter the bundled Slack plugin and are assigned a durable-ingress lane before they are admitted for agent delivery. That lane determines which events wait for one another, so a channel-only key serialized otherwise independent threads before agent concurrency could apply.
