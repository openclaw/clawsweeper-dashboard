## What This Changes

Prevent the Control UI from requesting approval lists and history for connected operators that lack the `operator.approvals` scope.

## System Context

The Control UI connects to the OpenClaw Gateway and bootstraps operator-facing pages. Its approvals page should use the connected operator's granted capabilities before issuing approval RPCs, so read-only and write-only operators do not receive authorization failures.
