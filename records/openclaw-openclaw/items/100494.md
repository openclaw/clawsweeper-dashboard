## Summary

Keep open: current main still has the central gap, and the issue carries a protected `maintainer` label. Provider usage collection still starts from a closed core provider list, the snapshot schema only has `plan` and free-form `summary` for billing-like data, and the Control UI Usage page loads transcript-derived `sessions.usage` plus `usage.cost` rather than provider `usage.status`.

## What This Changes

Request auto-discovered provider-owned usage hooks plus structured provider billing/quota data in the Control UI Usage dashboard.

## Best Possible Solution

Define one additive provider-owned usage and billing contract, have core discover enabled providers with usage auth plus snapshot hooks, then render `usage.status` peer data in Usage dashboard cards without adding new config or moving provider-specific auth/parsing into core.
