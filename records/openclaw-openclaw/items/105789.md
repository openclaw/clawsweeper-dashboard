## What This Changes

The PR adds a private shared retry package, keeps core diagnostics in a thin adapter, and migrates memory-host, ClawHub, QQBot, cron-delivery, and media-store bounded retry paths to the shared scheduler.

## Best Possible Solution

Land one private dependency-free scheduler, keep OpenClaw-only diagnostics in `src/infra/retry.ts`, expose bundled plugin use through the intended SDK facade, and preserve each caller's retry count, schedule, abort, disposal, logging, and terminal-error contract.
