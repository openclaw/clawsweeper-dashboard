## Summary

Keep this PR open: it addresses the real unbounded-cache bug, but the replacement ordering evicts every previously cached entry—including recently used ones—when a refresh contains enough entirely new model keys. The current-head evidence is also test-only, so it still needs redacted after-fix runtime proof before merge.

The PR caps the gateway model-pricing cache at 4096 entries, promotes cache hits in Map order, and adds focused eviction tests.

## Best Possible Solution
