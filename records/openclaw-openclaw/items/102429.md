## What This Changes

This PR adds `messages.operationalReplies` policies that keep automatic runtime notices visible, suppress them, show them once per source session, or redirect them away from the source chat.

## System Context

OpenClaw turns agent, heartbeat, ACP, follow-up, and plugin events into reply payloads before dispatching them to a source chat. This change inserts a shared operational-notice policy at those delivery boundaries and records per-session state for the `once` mode.
