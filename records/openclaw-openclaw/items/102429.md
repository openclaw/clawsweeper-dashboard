## What This Changes

This PR adds `messages.operationalReplies`, letting host-generated fallback, status, compaction, usage-limit, and failure notices stay visible, be shown once, be suppressed, or be written to a designated operator session instead of the source chat.

## System Context

Automatic notices originate in agent execution and are delivered through direct dispatch, ACP, follow-up, and heartbeat paths. The new policy classifies host-authored notices before those paths decide whether to publish to the source conversation, suppress the notice, or record it in an operator session.
