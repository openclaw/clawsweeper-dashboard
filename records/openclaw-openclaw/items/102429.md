## What This Changes

This PR adds `messages.operationalReplies` so OpenClaw can keep automatic runtime notices visible, silence them, show them once per source session, or redirect them to a configured operator session across direct, ACP, follow-up, and heartbeat delivery.

## System Context

OpenClaw creates automatic notices in agent execution, ACP, follow-up, and heartbeat flows, then routes reply payloads through delivery coordinators to source chats. This PR adds a shared policy between payload classification and final delivery so operational notices can be suppressed, deduplicated, or written to another session without changing ordinary assistant replies.
