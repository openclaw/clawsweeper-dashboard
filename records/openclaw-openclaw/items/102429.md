This PR is not merge-ready because redirect mode can discard an operational notice when the target transcript write fails. Adds `messages.operationalReplies` with `always`, `silent`, `once`, and `redirect` modes across direct replies, ACP delivery, queued follow-ups, heartbeat notices, config/docs, persisted session state, and plugin hook metadata.

## Best Possible Solution

Suppress the source only after a successful authorized redirect write; otherwise preserve current source delivery or emit a separately reliable operator-visible failure. Then resolve conflicts without losing current-main delivery behavior and obtain explicit approval for the new config, persistence, and plugin contracts.
