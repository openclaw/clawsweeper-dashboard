## What This Changes

This PR adds `messages.operationalReplies`, allowing host-generated fallback, status, compaction, heartbeat, ACP, and similar notices to remain visible, be silent, appear once per source session, or redirect to an operator session.

## System Context

OpenClaw’s reply pipeline converts agent and runtime events into channel delivery through direct dispatch, ACP, follow-up, and heartbeat paths. This policy classifies host-authored operational notices before those paths decide whether to send to the source conversation, suppress the notice, or write it to an operator-owned session.
