## What This Changes

Adds a `messages.operationalReplies` policy to keep automatic runtime notices visible, show them once, suppress them, or redirect them away from the source chat across reply, ACP, follow-up, and heartbeat delivery paths.

## System Context

OpenClaw’s reply-delivery layer receives normal assistant output and host-generated operational notices from agent runs, ACP, follow-ups, and heartbeats. This PR classifies the latter and applies a policy before they reach the originating chat or an operator-owned session.
