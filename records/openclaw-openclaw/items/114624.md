## What This Changes

This PR caches shared-state SQLite schema-migration detection per open database handle, revalidates it against schema and migration-relevant data changes, and adds regression coverage for drift and handle lifecycle behavior.

## System Context

The shared state registry checks a SQLite database for migration or repair requirements before it lists registered agent databases for CLI and Gateway workflows. This PR inserts a bounded, handle-owned cache between registry reads and the detector while retaining fail-closed recomputation when the observed database state changes.
