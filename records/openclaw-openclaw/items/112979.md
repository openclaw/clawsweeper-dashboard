## What This Changes

Add Gateway HTTP support for continuing a valid W3C `traceparent` only when the direct TCP peer is in `gateway.trustedProxies`, otherwise retaining a fresh trace.

## System Context

Gateway HTTP requests enter through a network-facing server, where the direct socket peer determines whether forwarded context may be trusted. The chosen trace context then feeds OpenClaw diagnostic spans, allowing downstream agent work to correlate with an upstream orchestration trace without changing Gateway request payloads.
