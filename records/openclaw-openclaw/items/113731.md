## What This Changes

The PR removes repeated per-step setup-cancellation hints and appends one hint only when the assembled chat reply still waits for a user wizard response.

## System Context

The system-agent chat engine converts channel-setup wizard steps into one assistant reply for chat, TUI, and other text surfaces. Auto-advanced informational steps can be joined into the same outgoing message before the next input-required step is shown.
