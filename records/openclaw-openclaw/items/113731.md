## What This Changes

The PR removes the cancel sentence from each rendered setup-wizard step and appends it once to the assembled chat reply only while the wizard is waiting for an answer.

## System Context

The system-agent chat engine drives channel setup wizards and turns a sequence of wizard steps into a portable text reply. That reply is then rendered by OpenClaw chat surfaces, so its wording and ordering affect every text-based setup flow.
