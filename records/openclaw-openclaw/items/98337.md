## What This Changes

## System Context

Nostr is a bundled channel plugin whose startup path resolves configured accounts before opening a gateway connection. Core secret discovery loads each channel’s contract, resolves SecretRefs into runtime values, and Nostr then treats the resolved private key as the account credential.
