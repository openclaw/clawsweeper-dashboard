## Summary

The normal targeted-restart path is well designed and strongly proven, but the rebased head leaves one existing gateway lifecycle mode incorrect: with channel autostart suppressed, a targeted-only reload enters the suppression branch with no wholesale channels, so the changed account is neither stopped nor restarted and can continue using stale configuration.

## What This Changes

The PR adds account-scoped gateway reload planning and targeted channel-account stop/start execution, with whole-channel fallbacks and regression tests.

## Best Possible Solution

Share the normal path's account validation and wholesale-promotion invariant with the suppression branch, but stop valid targeted accounts non-manually without restarting them while suppression remains active.
