## What This Changes

Adds an opt-in channel-plugin capability that lets Mattermost restart only changed named accounts during config reload while preserving whole-channel fallbacks for shared, default, removed, unresolved, secret, and unsafe changes.

## Best Possible Solution

Adopt the documented opt-in capability at the plugin boundary with Mattermost as the first implementation, retain conservative whole-channel promotion for every ambiguous path, and require isolation and lifecycle contract tests for each future opt-in.
