## Summary

Keep this PR open: current main still plans a wholesale restart for every channel config-prefix change, so the multi-account Mattermost disruption remains unresolved. ## What This Changes

The branch adds an opt-in `reload.accountScopedRestart` channel-plugin capability and uses it for Mattermost so isolated named-account config changes restart only that account rather than the whole channel.

## Best Possible Solution
