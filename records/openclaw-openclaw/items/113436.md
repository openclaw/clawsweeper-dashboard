## Summary

The report identifies a real Windows command-execution failure, but the failing `wxc-exec`/MXC implementation is owned by the separate Windows Companion project rather than this OpenClaw core repository. Route the reproduction and crash diagnostics to that project so its executable and packaging path can be fixed at the owner boundary.

## What This Changes

Fix Windows Companion command execution when its approved `system.run` request reaches the MXC sandbox but `wxc-exec` exits or crashes before returning command output.

## System Context

The OpenClaw Gateway sends approved node commands to a Windows Companion over the node protocol. The Companion owns the local `system.run` implementation, including the MXC sandbox and `wxc-exec` executable, then returns stdout, stderr, and exit status to the Gateway.
