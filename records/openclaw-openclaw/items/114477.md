## Summary

This is a substantive, proof-backed hardening PR rather than cleanup material. The patch closes several concrete session ownership and lifecycle gaps, but it deliberately changes plugin-runtime operations from permissive to fail-closed for cross-owner sessions; the protected `maintainer` label and that compatibility/security boundary require an explicit maintainer decision before merge.

## What This Changes

The branch serializes session lifecycle mutations, enforces same-plugin ownership for session operations, restores inherited MCP-tool visibility for spawned agents, adds per-run subagent timeouts, and documents/tests the resulting session controls.

## System Context

Gateway session handlers create, patch, reset, fork, archive, and delete persisted agent sessions on behalf of operators, agents, and plugin runtimes. Agent tools and in-process Gateway calls feed those handlers; their decisions affect session state, transcript access, spawned-agent capabilities, and plugin isolation.
