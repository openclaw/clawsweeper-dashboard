## What This Changes

Adds an optional `messageId` for the assistant message produced by a run to Gateway `chat` final and aborted events, including embedded and CLI-backed agent runs.

## System Context

The Gateway broadcasts terminal chat events to external clients after an embedded or CLI-backed agent run finishes. This change carries the identifier assigned when the assistant turn is persisted so clients can identify the exact produced transcript message instead of inferring the transcript tail.

## Architecture Diagram

  D --> E[Terminal lifecycle metadata]
  E --> F[Gateway final or aborted event]
  F --> G[Client deduplication by session and message]

## Best Possible Solution
