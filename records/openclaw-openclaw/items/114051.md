## What This Changes

The PR deletes idle default-concurrency session, scoped nested, and deferred context-maintenance command lanes after their queued work drains, and adds concurrent lifecycle regression coverage.

## System Context

OpenClaw agents enqueue session-scoped work into an in-process command queue, which serializes work per lane and tracks active tasks in a shared registry. This change retires an eligible lane only after its pump has stopped and no queued or active work remains, reducing later scans of obsolete session schedulers.
