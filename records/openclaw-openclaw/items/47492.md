## Summary

Keep open: current main has adjacent input-provenance, before_tool_call policy hooks, and exec approvals, but it still lacks the requested verified-human instruction provenance contract and sensitive-target enforcement.

## What This Changes

Add a gateway-enforced policy layer that requires sensitive exec, gateway, or outbound-action targets to trace back to a verified human instruction or stricter approval challenge.

## Best Possible Solution

Define a generic provenance and intent contract that flows from verified human-originated turns into tool-call policy, then use it to gate sensitive exec, gateway, and outbound targets through explicit approval or challenge paths without weakening existing approvals.
