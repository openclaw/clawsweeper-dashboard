## What This Changes

The issue requests a gateway-enforced policy layer that requires sensitive exec, gateway, and outbound-message actions to trace back to a verified human instruction.

## Best Possible Solution

Define a maintainer-approved provenance and sensitive-target policy contract, then enforce it at the gateway/tool-policy/approval boundary with public SDK shape, config/schema guidance, docs, and focused security regression coverage.
