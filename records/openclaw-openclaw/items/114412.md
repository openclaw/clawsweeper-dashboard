## What This Changes

This PR caches SQLite-derived session branch summaries using transcript watermarks so repeated branch-list requests avoid reparsing an unchanged full transcript.

## System Context

The session accessor derives branch dropdown data from each agent session’s SQLite transcript, which the Control UI requests while changing sessions. This PR adds an in-process cache between that transcript read path and callers, checking a transcript sequence and rewrite generation before returning cloned cached summaries.
