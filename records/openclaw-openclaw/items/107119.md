## What This Changes

This PR limits selected capability CLI input-reading, MIME-detection, generated-media writing, and video-output batches to 20 concurrent tasks using the existing `p-map` dependency.

## System Context

The capability CLI receives file arguments and provider results, reads and classifies local media, calls image/video model operations, and writes generated assets for CLI output. This patch changes the batching layer between those file/provider operations and the final CLI result.
