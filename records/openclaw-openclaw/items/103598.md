- `merge-risk: 🚨 compatibility`: The new process environment variable creates a plugin-specific activation path with undefined interaction with persisted plugin configuration and upgrades.

## Summary

This PR is not merge-ready: the new check misses OpenClaw’s separate CLI-metadata import path, while its placement in the shared loader can suppress the configured memory plugin outside CLI processes. Current plugin architecture already provides generic CLI metadata and command-scoping seams, and the PR supplies no real behavior proof showing those seams are insufficient.

## What This Changes

The PR adds an environment-variable fast path in the shared plugin loader that omits the external `openclaw-hybrid-memory` plugin, plus a loader unit test.

## Best Possible Solution

Keep core plugin-agnostic: formalize or document the generic lightweight CLI metadata entry contract, add command activation metadata where appropriate, and update the external hybrid-memory plugin so CLI discovery does not import its heavy runtime graph while normal gateway memory activation remains unchanged.
