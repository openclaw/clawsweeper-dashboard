## What This Changes

Adds `skills-sh:owner/repo/slug` as a ClawHub-resolved CLI reference for installing unclaimed skills.sh entries from commit-pinned GitHub sources while retaining an explicit unscanned trust state through search, install, update, and verification.

## System Context

The Skills CLI resolves install references into managed workspace skills. This change introduces an external skills.sh reference that is resolved by ClawHub, downloaded from the resolver-approved pinned GitHub source, and recorded in local origin and lock metadata for later update and verification.
