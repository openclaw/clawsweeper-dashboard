## What This Changes

The branch adds `skills-sh:owner/repo/slug` as a ClawHub-resolved, commit-pinned external skill reference and carries its unscanned provenance through install, search, update, and verification.

## System Context

The skills CLI turns a user-supplied reference into a ClawHub installation request, then records the resolved source in workspace skill metadata. This change adds a distinct external-catalog reference so later search, update, and verification flows can preserve and display its trust provenance.
