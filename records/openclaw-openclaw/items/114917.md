## Summary

Keep this PR open for protected-label human review. The proposed owner-local lifecycle change plausibly closes the startup cancellation race and adds focused regression coverage, but the submitted body does not expose inspectable after-fix runtime evidence for the claimed real child/PTY scenarios.

## What This Changes

The process supervisor records cancellation while a child or PTY adapter is still starting, then terminates the real operating-system process once startup completes; scope cancellation also includes already-pending starts.

## System Context

Agent tools and background execution create child or PTY processes through the process supervisor. The supervisor records lifecycle state, applies run or scope cancellation, and reports the terminal outcome back to the agent and gateway callers.

## Best Possible Solution

Keep a single supervisor-owned reservation and sticky cancellation state, then merge only after a reviewer can inspect redacted real-process evidence showing both termination of pending child/PTY starts and preservation of later scoped processes.
