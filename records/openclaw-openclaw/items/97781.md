## Summary

The PR now fixes the earlier production-route coverage problem by moving the live Teams sign-in invoke routes onto the bounded helper, but it is not merge-ready because that replacement drops the Teams SDK's cloud-specific User Token service endpoint routing for non-public Teams clouds.

## What This Changes

The PR replaces Microsoft Teams SSO User Token success JSON reads with a 16 MiB bounded reader and routes monitor-registered sign-in invokes through local bounded handlers with route-level tests.

## Best Possible Solution

Keep the bounded local sign-in routes, but derive and pass the configured Teams cloud User Token service URL so Public, USGov, USGovDoD, and China preserve the SDK routing contract before merge.
