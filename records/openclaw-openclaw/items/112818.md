## What This Changes

This draft refactor makes the shared realtime voice session harness return the Talk turn and audio events it emits, then changes the Gateway relay and existing voice callers to forward those exact events rather than reconstructing them.

## System Context

Realtime voice providers feed audio, transcripts, and tool calls into the shared session harness, which owns Talk turn state and emitted events. The Gateway relay and voice-call or meeting integrations then deliver those events to their own transport or playback surfaces.
