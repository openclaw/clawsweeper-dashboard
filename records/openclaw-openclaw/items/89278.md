## Summary

Keep open: current main fixed adjacent masking paths, but the original valid-slow Codex external-auth callback can still fail because OpenClaw still force-refreshes the app-server token-refresh request while upstream Codex still cancels that parent callback after 10 seconds.

## What This Changes

The issue reports Codex OAuth refreshes taking longer than the 10-second external-auth callback budget, causing cron or heartbeat agent runs to fail even when the profile can refresh successfully.

## Best Possible Solution

Keep this issue open until maintainers choose and validate a Codex auth-bridge mitigation that avoids spending the 10-second callback budget on unnecessary refreshes without breaking explicit 401 recovery.
