## What This Changes

The issue reports Codex/OpenAI OAuth sessions that probe successfully but fail cron, heartbeat, and embedded agent turns because auth-refresh callbacks hit a hard 10-second timeout and mask actionable credential state.

## Best Possible Solution

Keep this as the specific Codex external-auth timeout issue and land a maintainer-approved bridge fix that answers within Codex's 10s callback when cached credentials are usable, while broader provider quarantine and incident status stay tracked by the related auth-provider issues.
