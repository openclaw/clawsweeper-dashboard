## What This Changes

The PR updates Chrome page sharing so oversized page content and highlighted selections reserve space for their truncation marker and do not end on an unpaired Unicode surrogate.

## System Context

The Chrome extension turns a web page or highlighted selection into a page-share payload before relaying it through OpenClaw. This helper bounds each producer field so the downstream relay receives valid, predictable page text without changing its separate combined-payload limit.
