## Summary

The patch is a correct, focused hardening of the newly added native approval delivery-failure notice. Although the default host exec path generates ASCII UUIDs, the coordinator consumes the shared `ExecApprovalRequest.id` boundary rather than a locally guaranteed UUID-only type, and using the repository’s established safe-slice primitive preserves valid output without changing matching or authorization behavior.

## What This Changes

The PR replaces raw eight-code-unit truncation of exec approval IDs in the native delivery-failure notice with `sliceUtf16Safe` and adds focused regression tests.

## Best Possible Solution

Land the focused safe-slice change and retain the regression test so the native approval fallback always emits well-formed text without altering the existing eight-code-unit short-code contract.
