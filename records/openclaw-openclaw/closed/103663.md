## Summary

Keep this PR open. The current patch still invokes unscoped staged-media cleanup from `AgentSessionBase.dispose()`, so disposing one session can remove workspace artifacts needed by another concurrent session; the PR also has only test output rather than inspected after-fix runtime proof of the cross-turn flow.

## What This Changes

The PR copies inbound `media://inbound/` files into `workspace/media/inbound/` during read-path resolution and attempts to remove staged copies when an agent session is disposed.

## Best Possible Solution

Stage inbound media through the session-owned, root-scoped workspace-write boundary, record ownership per session, and delete only artifacts owned by the disposing session; then provide redacted runtime evidence of a later path-only read succeeding.
