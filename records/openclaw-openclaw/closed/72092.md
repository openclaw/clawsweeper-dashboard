## Summary

## What This Changes

The branch lets Bedrock `aws-sdk` image and PDF media tool paths pass an empty credential sentinel to Bedrock-owned streams, treats configured SDK auth as tool-available, and registers plugin streams for non-native PDF completion.

## Best Possible Solution

Land the focused current-head fix after routine branch/check freshness so Bedrock `aws-sdk` image and PDF tools share chat's keyless credential behavior while strict non-`aws-sdk` auth remains unchanged.
