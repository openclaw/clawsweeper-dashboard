## What This Changes

This PR introduces a dedicated `--run` color token and uses it for Control UI sidebar running indicators so active sessions no longer visually resemble failures.

## System Context

The Control UI sidebar combines session state with icons and status controls to help users scan active, waiting, and failed work. Theme tokens flow into the run ring/spinner and child-session toggle, which are then rendered beside session rows.
