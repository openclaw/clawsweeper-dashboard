## Summary

This is a well-supported model-switch reproduction of the native Anthropic historical-thinking replay failure already tracked by the open canonical issue, which also has a linked fix PR; current main does not yet document model-mismatch sanitization, so the new evidence should be preserved on the canonical thread rather than maintained separately.

## What This Changes

Prevent foreign model-scoped Anthropic thinking signatures from being replayed after a session changes models and permanently poisoning subsequent requests.

## Best Possible Solution

Keep one canonical fix under https://github.com/openclaw/openclaw/issues/94228 and require its linked PR to cover explicit model switches and fallback route changes while preserving only valid active same-model tool-turn thinking blocks.
