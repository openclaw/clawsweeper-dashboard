## Summary

The earlier retry-budget defect is fixed, and channel-owned retry matches the Slack and Signal precedents. This PR still needs an abort-safe retry lifecycle and real Feishu proof before merge because pending timers can retry inbound work after channel shutdown begins.

## What This Changes

The PR adds four bounded Feishu agent-dispatch retries with 250 ms, 500 ms, 1 s, and 2 s backoff for reply-session initialization conflicts, plus six focused fake-timer tests.

## Best Possible Solution

Keep bounded retries at Feishu’s serialized channel boundary, but make each delay abort-aware and owned by the monitor drain lifecycle, then prove conflict recovery, single ordered delivery, exhaustion, and shutdown cancellation on the real path.
