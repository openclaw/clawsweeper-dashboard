## Summary

The reported bug is valid and the shared CJK estimator is the right primitive, but this PR is not merge-ready because its average-ratio conversion does not guarantee the actual retained text fits the intended budget. The linked issue should remain open while the implementation and real-behavior proof are corrected.

## What This Changes

The PR changes tool-result length accounting to use CJK-weighted estimates and converts per-block estimated shares into physical UTF-16 truncation budgets, with added CJK-focused tests.

## Best Possible Solution

Enforce the estimated-character budget on the actual retained prefix/head/tail and suffix, then cover single-block mixed text with CJK concentrated at both retained boundaries.
