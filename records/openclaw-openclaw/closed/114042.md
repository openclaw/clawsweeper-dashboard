## What This Changes

The PR binds the Control UI’s temporary first-prompt handoff to the persistent logical Gateway browser client rather than a per-transport handshake, preserving the prompt through a reconnect until chat history owns it.

## System Context

The Control UI submits a new task through the Gateway, then temporarily projects the first user prompt in the chat pane while the authoritative transcript catches up. A Gateway reconnect replaces handshake state but should not discard that temporary prompt for the same browser client.
