## Summary

Keep this PR open for explicit maintainer review. The patch addresses a real Codex Computer Use startup failure and provides unusually strong implementation and runtime evidence, but it also adds a public Plugin SDK error contract that defines cross-plugin model-fallback behavior; that contract should receive an owner decision before merge. ## What This Changes

The PR copies the signed macOS Computer Use service into an isolated Codex home when auto-install is authorized, detects empty MCP tool exposure before live probes, and prevents model fallback from repeating a model-independent harness readiness failure.

## System Context

A Codex-mode agent turn enters OpenClaw’s model-fallback runner, which starts the Codex app server and performs Computer Use readiness checks before a model attempt begins. This PR changes that handoff so local, model-independent readiness failures terminate fallback once while macOS isolated homes can receive the required desktop-bundled service.
