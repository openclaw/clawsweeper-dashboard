## What This Changes

The issue reports that MCP per-server include/exclude filters silently remove a server's tools when users copy the namespaced tool names shown by `openclaw mcp probe`.

## Best Possible Solution

Land or replace the focused MCP filter fix so filter matching accepts the names users see from probe, preserves raw-name compatibility, and warns when a non-empty include exposes no tools.
