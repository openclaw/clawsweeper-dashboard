## What This Changes

Fix browser tabs and durable tab-ownership rows that remain after isolated cron or hook agent runs finish because cleanup may use a base session key instead of the run-scoped owner key.

## System Context

Isolated cron and hook runs create a run-scoped agent session that can open browser tabs. The browser subsystem records tab ownership by session key, and terminal lifecycle cleanup must use that same canonical key to close tabs and remove durable ownership.

## Architecture Diagram

flowchart LR

  B --> C[Run-scoped session key]
  C --> D[Browser tab ownership registry]
  B --> E[Terminal lifecycle cleanup]
  E --> F[Close matching tabs]
  F --> G[Remove durable ownership]

## Best Possible Solution

Verify the terminal paths for isolated cron and hook runs, then centralize browser cleanup at the lifecycle boundary that holds the canonical run-scoped session key and cover success, error, timeout, and restart-persistence behavior.
