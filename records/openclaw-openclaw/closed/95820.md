## What This Changes

The PR changes the bundled session-memory hook so it removes duplicate OpenClaw bookkeeping assistant rows from generated memory transcripts while retaining unique assistant replies.

## System Context

The bundled session-memory hook reads a prior session JSONL transcript when `/new` or `/reset` runs and writes a compact user/assistant excerpt into the workspace memory directory. Its transcript renderer decides which persisted assistant rows become future memory context, so filtering mistakes can omit useful session state.
