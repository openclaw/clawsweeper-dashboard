## Summary

Close as duplicate: the requested cron `delivery.mode="session"` is the session-target subset of the broader open cron output-routing design, and current main plus the latest release still lack a separate session delivery mode.

## What This Changes

The issue requests a new cron delivery mode that sends completed job output into an internal session via `sessions_send` instead of a visible channel or webhook.

## Best Possible Solution
