## Summary

Keep this fresh PR open for normal review, but treat it as a worst-case discovery-latency reduction rather than a fix for an indefinite hang: current main already gives optionless `runExec` calls a 10-second timeout, while this branch lowers the Tailscale-specific `which` and `locate` bounds to 3 and 5 seconds without real-host proof that those thresholds preserve discovery.

## What This Changes

Adds named 3-second probe and 5-second search timeouts to Tailscale binary discovery commands and unit coverage asserting the timeout options.

## Best Possible Solution
