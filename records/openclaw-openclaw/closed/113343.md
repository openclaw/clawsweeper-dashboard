## What This Changes

This PR replaces the sidebar’s shared session-row limit with separate Show more and Collapse controls for each expanded session section, so expanding one section does not consume another section’s visible-row budget.

## System Context

The Control UI sidebar groups recent sessions into sections such as Threads, categories, Groups, and Coding. Session-navigation logic selects which rows each section exposes, and the sidebar renderer places controls that let users reveal more rows before handing interaction back to the session data controller.
