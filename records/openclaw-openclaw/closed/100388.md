## Summary

Keep open: current main and v2026.6.11 provide basic WebChat compaction start/end indicators and general stability diagnostics, but not the requested staged compaction lifecycle, compaction-specific watchdog API/CLI, or Session Memory reference/plugin docs.

Define a narrow core observability contract: safe staged compaction events for WebChat, redacted compaction diagnostics through the existing gateway diagnostics/CLI model, and separate ClawHub/context-engine documentation for async Session Memory.
