## Summary

Keep open: current main confirms that cron `agentTurn` messages are passed to the agent as prompts rather than dispatched by OpenClaw as shell commands, but memory-core still does not reliably intercept legacy light/REM markers carried in `payload.message`. The open linked fix PR targets that exact gap and has not merged, so this issue should remain open until the PR is proven and landed or replaced.

## What This Changes

Prevent legacy memory-core dreaming cron markers from reaching the agent harness and triggering erroneous tool execution instead of being intercepted and migrated.

## Best Possible Solution

Keep interception and migration inside the memory-core plugin: recognize legacy light/REM tokens from both supported cron payload fields, reconcile the persisted job to the canonical unified marker, suppress the current legacy-triggered agent turn, and prove the behavior with a real persisted-job cron run plus focused regression tests.
