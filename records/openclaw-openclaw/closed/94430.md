## Summary

## What This Changes

The PR adds generic moderation-error string matching in embedded-agent failover classification, maps those messages to `rate_limit`, adds classifier tests, and edits `CHANGELOG.md`.

## Best Possible Solution

Define explicit maintainer-approved content-policy/moderation semantics, preferably through provider-owned classification or a dedicated reason, and only opt into fallback/cooldown behavior when that policy is intentional and proven.
