## Summary

Keep this PR open for human maintainer review: the animation and wait-phrase work are well-scoped UI polish, but the new recap can knowingly attribute a different same-session terminal run to a queued or cancelled send because the displayed terminal row has no run identity.

## What This Changes

The PR changes the Control UI chat working-claw animation, adds rotating long-wait phrases, and adds a persistent per-turn duration/token recap row.

## Best Possible Solution

Keep the calmer animation and long-wait phrases, but make the recap fail quiet until the gateway/session terminal data exposes a run identifier that can be matched to the observed send; otherwise remove the recap portion from this PR.
