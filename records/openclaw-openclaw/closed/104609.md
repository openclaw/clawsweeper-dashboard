## Summary

Codex review confirms this is a valid current-main regression: the documented admin-scoped CLI commands are rejected by a redundant host-local policy branch before their existing Browser routes run. No linked fix PR or canonical duplicate owns the work, and the protected `maintainer` label independently requires the issue to remain open for explicit handling.

## What This Changes

Restore documented host-local browser profile create, delete, and reset commands while continuing to deny persistent profile mutations through browser-node proxies.

## Best Possible Solution

Treat profile create, delete, and reset as authenticated host-local admin routes, remove only the redundant local rejection, and add focused gateway tests that prove all three local routes dispatch while both proxy layers still reject them.
