## Summary

The patch addresses a concrete Chrome copilot turn-isolation regression and includes detailed real-Chromium evidence, but the protected `maintainer` label requires explicit maintainer handling before a merge decision.

## What This Changes

The PR filters delayed Gateway chat events by the browser copilot session’s active run so prior turns cannot alter the active side panel turn.

## System Context

The Chrome browser copilot keeps a per-tab session subscribed to Gateway events while the background controller tracks the current run. Gateway chat events are forwarded to the side panel, where streaming and terminal events update the active conversation and composer state.
