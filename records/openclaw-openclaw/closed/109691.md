## Summary

This PR remains necessary: current `main` still treats whitespace-only environment values as configured in the shared AI credential path. The branch centralizes the nonblank check, preserves fallback ordering, and removes Azure Responses’ divergent raw-environment reread; no actionable patch defect was found.

The PR makes shared AI environment credential lookup ignore whitespace-only values, trims selected credentials, and makes Azure Responses use that resolved credential rather than rereading `AZURE_OPENAI_API_KEY`.

## Best Possible Solution

Land the shared normalization path with its focused regression coverage, so credential discovery, provider status, and Azure request construction all agree that blank environment values are absent.
