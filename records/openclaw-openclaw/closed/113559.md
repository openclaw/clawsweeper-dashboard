## What This Changes

This PR centralizes the supported `OPENCLAW_AGENT_DIR` shared-main auth path, retains a configured agent as a claimant for an exact shared SQLite session store after its physical owner leaves the roster, and detects Unicode case aliases when resolving agent databases.

## System Context

OpenClaw resolves agent auth profiles and session transcripts from per-agent or shared SQLite-backed stores. Runtime path resolution and Doctor both inspect those stores, while session-target discovery chooses one configured logical agent to access a shared physical database.
