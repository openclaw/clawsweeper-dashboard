## What This Changes

The PR adds a shared CLI exit-code resolver so proxy-run and container-targeted commands preserve numeric child exits and translate terminating signals such as SIGINT and SIGTERM to shell-standard results.

## System Context

OpenClaw CLI commands sometimes wrap another process directly or through Docker/Podman. Those wrappers receive a numeric status or a terminating signal from the child and return a CLI result to shells, scripts, and supervisors.
