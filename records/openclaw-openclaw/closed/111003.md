## Summary

Keep this PR open for repair: the intended AA improvements regress readable text for supported custom themes and for Dash seam-color overrides, so the current patch is not safe to merge unchanged.

## What This Changes

The PR darkens OpenKnot and Dash dark-theme primary/destructive fills and changes selected action controls to use `--primary-foreground` instead of literal white.

## Best Possible Solution

Make primary fills, hover fills, and foregrounds a verified token pair for both built-in themes and runtime/custom overrides; update the seam-color path to set compatible primary tokens and add regression coverage for the supported custom-theme fixture and a dark seam color.
