## Summary

The PR changes `findModelAliasCandidate` to warn when a duplicate model alias is found and keep the first matching configured model entry.

## Best Possible Solution

Warn on duplicate aliases while preserving shipped winner semantics unless maintainers explicitly approve a precedence break, and apply duplicate detection consistently to alias-index consumers with focused regression coverage.
