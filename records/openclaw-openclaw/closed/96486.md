## What This Changes

## Best Possible Solution

Maintainers should choose a compatibility-aware Control UI origin hardening plan, preferably steering users to explicit `allowedOrigins` or constrained origin patterns while adding targeted origin/fetch-metadata tests and only narrowing or removing the dangerous fallback with an upgrade plan.
