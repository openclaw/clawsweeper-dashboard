## What This Changes

The PR makes shared approval prompts emit Markdown-bold headers and labels, updates iMessage, Signal, and WhatsApp reaction binding parsers to recognize the formatted text, and sends Signal approval prompts in Markdown mode.

## System Context

The plugin SDK builds one approval prompt for an agent action, then reaction-capable channel plugins send it and later correlate user reactions or replies back to the approval request. This PR changes the shared prompt presentation while preserving each channel’s delivery and approval-binding path.
