## Summary

Keep this PR open for maintainer review. The patch addresses a concrete persisted-database integrity concern with focused migration guards and regression coverage, but advancing the shared and agent SQLite schema versions changes upgrade behavior and needs explicit owner confirmation before merge.

## What This Changes

This PR makes shared and per-agent SQLite upgrades reject missing stable tables and unknown schema drift before mutation, while migrating only known additive historical table groups and repairing canonical indexes.

## System Context

OpenClaw opens a shared SQLite database for global runtime state and separate SQLite databases for agent-scoped state such as sessions and boards. Startup and maintenance first check database ownership and schema version, then migrate supported historical versions and expose the validated database to runtime features.
