  - body: The zsh dispatch patterns join aliases with spaces, producing shapes like `(tui terminal chat)`. Shell case alternatives need `|`, so alias dispatch should be emitted as `(tui|terminal|chat)` or the alias path will not dispatch correctly.
  - confidence: 0.82
