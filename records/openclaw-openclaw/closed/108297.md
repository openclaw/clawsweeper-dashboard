## Summary

The report accurately describes behavior in v2026.6.11, but the matching macOS device-identity persistence fix is present on current main and shipped in v2026.7.1 through merged pull request https://github.com/openclaw/openclaw/pull/101105.

Persist and reuse the macOS app's node identity so reconnecting to a co-located gateway does not generate repeated pairing approvals and stale node records.

## Best Possible Solution

Keep the shipped stable-identity implementation and have affected v2026.6.11 users update the CLI and macOS app together to v2026.7.1 or newer.
