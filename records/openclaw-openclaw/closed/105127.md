## Summary

The requested capability is still missing on current main, and the protected maintainer label rules out cleanup closure. The issue accurately identifies a native paging and CLI-import integration gap, but its auto-load premise is outdated and an older open PR proposes a competing cursor contract, so maintainer direction is needed before implementation.

## What This Changes

Add import-aware paging for native chat history so users can load transcript messages older than the current fixed tail.

## Best Possible Solution

Keep one offset-based gateway paging contract, return explicit completeness metadata on the initial page, define CLI-bound sessions as either fully loaded or consistently pageable, and expose native paging through the current shared Load older control with scroll-anchor and streaming-regression proof.
