## Summary

Close the core feature request as plugin-scoped: current main still renders the bootstrap files as ordered Project Context entries, but the public bootstrap and prompt-injection hooks now provide the missing extension boundary for configurable elevation without adding another core config surface.

## What This Changes

Allow users to map selected bootstrap files such as SOUL.md, IDENTITY.md, USER.md, and MEMORY.md into dedicated ordered system-prompt sections and exclude them from generic Project Context.

## Best Possible Solution

Publish a narrow native code plugin that validates an ordered pattern-to-section config in `openclaw.plugin.json`, removes matched files through `agent:bootstrap`, reinjects their bounded contents through `before_prompt_build`, documents permissions/config/install/update behavior, and provides a real prompt smoke test; ClawSweeper should not open a ClawHub issue or PR, create tracking work, or publish the package for the contributor.
