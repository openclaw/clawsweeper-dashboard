## Summary

Keep open for explicit maintainer direction: current main still documents the second-work-event fast start, narrated status remains synthetic, and typed preamble commentary remains opt-in, so the requested behavior is not implemented. The proposal is coherent but changes default cross-channel status semantics, and the protected `maintainer` label prevents automated cleanup.

## What This Changes

Delay ordinary progress drafts until the time gate expires, defer utility-model narration until visibility, and use typed model preamble commentary as the primary status headline.

## Best Possible Solution

Keep fast turns silent, preserve explicit immediate starts for approvals and patches, start the narrator only after draft visibility, and make sanitized typed preamble the headline with a bounded staleness rule and cross-channel regression coverage.
