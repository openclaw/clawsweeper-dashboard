## What This Changes

The issue asks OpenClaw to stop offering a dead brew-only installer for the bundled summarize skill on Linux/Docker and to show actionable Control UI feedback when enable/install cannot make the skill usable.

## Best Possible Solution

Choose and implement a truthful bundled summarize contract: use a verified maintained installer with platform metadata and visible UI/install feedback, or remove/de-bundle the skill so users are not pointed at a dead brew formula.
