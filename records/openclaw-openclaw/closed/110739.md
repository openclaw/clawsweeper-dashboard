## Summary

Keep this PR open: it avoids changing the direct gateway RPC, but the 1,000-item tool cap silently makes sessions beyond the first page unreachable through `sessions_list` because the tool exposes neither an offset input nor continuation metadata.

## What This Changes

The branch clamps model-supplied `sessions_list.limit` values to 1,000 before dispatching the existing `sessions.list` gateway call and adds a mocked regression test.

## Best Possible Solution

Define `sessions_list` as an explicitly paginated agent tool—bounded per-page limit plus an additive cursor input and returned continuation metadata—or retain its existing unbounded tool behavior until that contract is approved.
