## What This Changes

The PR changes `listControlledSubagentRuns` so a run is listed when either its stored `controllerSessionKey` or `requesterSessionKey` matches the caller key.

## Best Possible Solution

Land this as a narrow subagent visibility fix only after the lint error is repaired and the PR includes proof that both the agent-tool list and Telegram `/subagents list` see the same spawned child run.

## Reproduction Assessment
