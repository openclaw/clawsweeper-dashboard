Full review comments:

- **[P1] Preserve non-cron schedules when saving edited jobs:** `apps/linux/src/section_cron.c:270-276`
  - body: The edit-save path always sends `schedule_kind = "cron"` even for existing jobs whose schedule is `at`, `every`, or `on-exit`. Opening Edit and saving an unrelated field can therefore fail validation or convert the job to a cron expression instead of preserving the original schedule shape.
  - confidence: 0.93
- **[P1] Keep session-scoped cron targets intact:** `apps/linux/src/test_seams.c:42-48`
  - body: Unknown targets are mapped to index 0 and then saved back as `isolated`, but valid cron targets include `session:<id>`. Editing a session-scoped job can silently retarget it away from its intended session.
  - confidence: 0.91
- **[P2] Send supported verbose override values:** `apps/linux/src/section_sessions.c:176-184`
  - body: The UI sends `none`, `low`, and `high` for `verboseLevel`, but the gateway parser accepts the `off`/`on`/`full` family. These updates will be rejected instead of changing session verbosity.
  - confidence: 0.9
- **[P2] Send explicit null when clearing the session model:** `apps/linux/src/gateway_mutations.c:148-150`
  - body: Selecting the default model passes a null pointer, and this helper omits the `model` field entirely when `model` is null. The gateway only clears a model override when it receives JSON `model: null`, so the clear action currently becomes a no-op.
  - confidence: 0.9
- **[P3] Add Linux app labeler coverage:** `.github/labeler.yml:139-148`
  - body: This PR creates a new `apps/linux/**` app surface, but the labeler still only has Android, iOS, macOS, and web UI app patterns. Without a Linux app label/routing update, future changes to this surface will not be classified correctly.
  - confidence: 0.82
