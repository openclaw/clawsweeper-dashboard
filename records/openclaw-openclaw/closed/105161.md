## Summary

This PR remains necessary because current main still has the signal-less exhaustive supplement path, but it is not merge-ready: the shared soft abort shortens primary memory’s effective deadline, the new race callback fails lint, and representative exact-head proof does not yet show partial wiki recall.

## What This Changes

The PR adds cancellation and completed-partial-result semantics to memory corpus supplements, introduces a one-second soft deadline window, and makes memory-wiki enumeration and page reads abort-aware.

## Best Possible Solution

Keep the abort-aware wiki traversal and optional supplement signal, but give supplements a separate early cancellation or grace signal while primary memory retains the full hard deadline; then provide exact-head Gateway proof that partial wiki hits return and no new vault reads start after cancellation.
