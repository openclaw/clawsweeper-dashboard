## Label Justifications

## Summary

Close as implemented on current `main`: the Anthropic provider normalizer now accepts cost-less configured Sonnet 5 rows and applies canonical pricing instead of dereferencing `cost`. The reported stable package line may still need a release containing this merge, but the source-level bug is no longer open work on `main`.

## What This Changes

Prevent `openclaw models list` from crashing when a configured Anthropic Sonnet 5 model cannot be resolved from the registry and therefore has no cost metadata.

## System Context

The models-list command builds rows from configured model references and sends them through provider-owned normalization before rendering CLI output. Anthropic normalization adds current Sonnet 5 capabilities and pricing, which then feeds the displayed configured-model table or JSON output.

  E --> F[Models list CLI output]

## Best Possible Solution

Keep the provider-owned missing-cost normalization now on `main`, and ensure the next stable release includes it so affected installed packages can upgrade rather than patching built artifacts.
