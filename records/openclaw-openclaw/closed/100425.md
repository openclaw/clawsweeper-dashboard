- `maturity:stable`: The issue maps to gateway-runtime, an M4 Stable feature covering Gateway runtime session and event handling.

## Summary

Close as implemented: the narrow lock-across-provider-I/O behavior is already fixed in v2026.6.11 and current main by releasing the retained session write lock before provider stream submission and reacquiring it afterward, while transcript writes still run through explicit write-lock helpers.

## What This Changes

The issue asks OpenClaw to stop holding a session transcript write lock across provider/model I/O and instead lock only around transcript appends.

## Best Possible Solution

Keep the shipped prompt-release implementation for this narrow behavior, and leave broader session-delivery contract problems on their existing trackers.
