## What This Changes

The PR adds a private 30-second timeout to Mattermost WebSocket upgrade requests and regression coverage showing stalled handshakes return control to the reconnect loop.

## Best Possible Solution

Land the native `ws` handshake deadline at the Mattermost plugin-owned factory, preserve current-main changes while refreshing the branch, and retain focused proof that timeout closure reaches the existing reconnect policy without adding another config or fallback surface.
