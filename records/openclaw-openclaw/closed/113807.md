## What This Changes

The PR moves OpenClaw’s agent shell-execution pipeline out of one large module into focused modules for script analysis, safe preflight, request preparation, and policy/host/process execution, while preserving the existing public facade.

## System Context

The agent exec tool receives a shell request from an agent, derives workdir and environment facts, applies command policy and approval rules, then launches on an allowed host and reports process output and lifecycle state. This refactor separates those internal stages while keeping the original exec entry point for callers.
