## What This Changes

The branch upgrades `@openclaw/fs-safe` and centralizes durable file-publication behavior for SQLite snapshots, archives, generated Gateway TLS files, Reef journals, memory exports, and QA atomic files.

## System Context

Several OpenClaw workflows publish files that must survive a crash or power loss, including backups, restored databases, generated TLS credentials, journal entries, and exported agent state. Each workflow prepares a file or directory, invokes the shared filesystem-durability boundary, and then either reports success, preserves an explicitly compatible unsupported-filesystem path, or propagates a real I/O failure.
