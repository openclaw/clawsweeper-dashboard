Keep this issue open for explicit iOS product review: current behavior exposes QR pairing, but the reported ordering makes a routine first-device task less discoverable, and the protected `maintainer` label prevents automated cleanup. ## What This Changes

Reorganize the iOS Gateway settings screen so QR pairing is always reachable and pairing controls appear before manual connection and advanced settings.

## Best Possible Solution

Use one canonical QR-pairing action from the existing Gateway settings owner, expose it in the navigation bar and unpaired status card, group setup code and discovery under a single Add Gateway section, and move manual/advanced controls last while preserving all existing paired and offline states.
