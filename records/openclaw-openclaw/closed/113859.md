## Summary

This issue is a duplicate of the already-open canonical report for the same missing-`cost` Anthropic normalization crash. The canonical report covers the same unfiltered `models list` failure, the same fallback-row contract violation, and the related Control UI impact, so consolidating there preserves the complete fix discussion.

## What This Changes

Fix the configured-model listing path so Anthropic Sonnet 5 pricing normalization handles fallback model rows that have no `cost` object instead of crashing the CLI.

## System Context

The model-list command builds rows from configured models and fallback entries, then gives each row to its provider normalizer before rendering the CLI output. Anthropic normalization enriches Sonnet 5 pricing; a missing pricing field must be treated as data to supply rather than a reason to abort listing.
