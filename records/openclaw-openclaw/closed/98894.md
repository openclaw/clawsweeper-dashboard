## What This Changes

A contributor reports that a claude-cli live-session timeout can reject an unobserved turn promise while `stdin.write` is still pending, causing the gateway unhandled-rejection handler to exit the process.

## Best Possible Solution

Fix the local live-session promise ownership so timeouts while stdin writes are pending reject through the normal awaited turn path, with regression coverage for a non-calling stdin write callback.

## Reproduction Assessment

Yes, at source level: use a claude-stdio ManagedRun whose `stdin.write` callback never fires, let the no-output timer expire, and `failTurn` rejects the turn promise before any handler is attached. No live process reproduction was run in this read-only review.

## Solution Assessment

Yes. The narrow maintainable fix is in `claude-live-session.ts` promise handling plus a regression test; globally suppressing `FailoverError` in the unhandled-rejection handler would mask the local ownership bug.
