## What This Changes

Fix git plugin installs so a cloned repository can be staged and published when the process temp directory and OpenClaw state directory are on different filesystems.

## Best Possible Solution

Land https://github.com/openclaw/openclaw/pull/99896 or an equivalent narrow git-installer repair that keeps staging and publish on a cross-device-safe path while preserving install-policy, npm install, rollback, and security-event behavior.
