## What This Changes

The PR recovers a complete, verified SQLite snapshot whose `.pending` marker survived an interruption, making the backup available again to list, verify, and restore operations while retaining fail-closed handling for incomplete or unsafe directories.

## System Context

The local SQLite snapshot repository creates a backup directory, writes its manifest and database artifact, then removes a pending marker before exposing it to backup commands. Listing and resolving snapshots are the boundary that decides whether an on-disk directory becomes a usable backup or remains unavailable.
