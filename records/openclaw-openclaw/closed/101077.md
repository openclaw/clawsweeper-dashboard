## Summary

Current main already applies the non-visible retry guard by model API, so OpenAI-compatible local providers are no longer limited to GPT-5/OpenAI strict-agentic matching for reasoning-only visible-answer recovery; the central fix shipped after the reporter's pinned 2026.4.23 build.

## What This Changes

The issue requests reasoning-only visible-answer retry recovery for non-GPT-5 OpenAI-compatible reasoning models such as LM Studio/Qwen-family models.

## Best Possible Solution

Keep the shipped modelApi-based recovery path for this retry-gate bug; broader reasoning-field reporting remains on https://github.com/openclaw/openclaw/issues/74021 and group silent-reply policy remains on https://github.com/openclaw/openclaw/issues/85684.
