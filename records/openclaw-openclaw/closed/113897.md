## Summary

The PR is a focused, correct repair for machine-readable empty model-list output: current `main` unconditionally emits `No models found.` before the structured renderer, while the renderer already produces the intended empty JSON object and silent plain output. The patch preserves normal interactive output and adds coverage for all three modes. It should remain open for the normal protected-label maintainer review path.

## What This Changes

This PR makes `openclaw models list` send empty JSON and plain-text results through the canonical renderer, returning `{ "count": 0, "models": [] }` for JSON and zero lines for plain output while retaining the normal terminal message.

## System Context

The models CLI collects configured, catalog, and discovered model rows, then presents them as a terminal table, plain keys, or JSON for scripts. The changed decision sits after row collection and determines whether an empty result is rendered structurally or replaced with human prose.
