## Summary

Keep this PR open, but do not merge the current ordering: it prevents the reported post-adoption abort while introducing a window where a slow or retrying completion write no longer renews its claim, allowing another spool to reclaim and redeliver an already-adopting turn.

## What This Changes

The PR stops the LINE webhook spool’s claim-refresh fence before persisting adoption completion and adds a deterministic regression test for the refresh/completion race.

## Best Possible Solution

Introduce an adoption-started state that prevents refresh failures from aborting the turn while continuing successful claim renewal until the token-fenced completion transition settles, with coverage for both delayed completion and competing-worker reclamation.
