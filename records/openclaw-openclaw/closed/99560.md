## Best Possible Solution

Keep the focused parser-level normalization if redacted Android device/emulator proof shows scoped IPv6 manual or QR gateway input reaches the gateway connection path successfully.

## Reproduction Assessment

## Solution Assessment

Yes, pending proof: normalizing at the endpoint parse boundary is the narrowest maintainable layer because the parsed host is used for display, saved config, and GatewayEndpoint.manual. A later build-only normalization would leave stored/displayed endpoint state inconsistent.
