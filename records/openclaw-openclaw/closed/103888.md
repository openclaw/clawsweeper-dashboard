## Summary

Current `main` still ships three invalid `system.which` examples, while both node implementations require a `bins` array and reject the documented `name` shape. The issue remains necessary, but its protected `maintainer` label requires explicit maintainer handling rather than automated cleanup or repair intake.

## What This Changes

Correct the `system.which` CLI help and node documentation examples to use the supported `bins` array parameter.

## Best Possible Solution

Retain the canonical `bins` array RPC contract, change all three shipped examples together, and add a focused assertion that the CLI help example uses the same request shape as the node decoders; do not add a runtime alias for the erroneous documentation.
