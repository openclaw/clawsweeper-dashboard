## What This Changes

The PR rewrites selected bundled Control UI icon and manifest links to the dashboard root or configured base path so nested dashboard routes do not request those files relative to the current page.

## System Context

The Gateway returns the built Control UI HTML for dashboard requests at either the root or a configured base path. Browsers resolve the document’s icon and manifest URLs before the client application starts, so this HTML-side rewrite determines which static-file URLs the Gateway receives.
