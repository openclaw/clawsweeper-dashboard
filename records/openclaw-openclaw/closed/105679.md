## Repair Work Prompt

Fix the Telegram formatter bug where intentionally authored Markdown links such as `[main.ts](https://main.ts)` lose their target because file-reference autolink suppression cannot distinguish authored links from compiler-generated autolinks. Preserve Markdown-it link-origin metadata through `MarkdownLinkSpan` and every clamp, slice, and table transformation; make Telegram suppress only implicit file-reference autolinks; and make direct HTML normalization conservative so it cannot destroy authored anchors. Add regression tests for authored matching-label HTTP and HTTPS links while retaining proof that implicit plain file references render as code without previews. Do not add configuration, change unrelated Telegram delivery behavior, or edit `CHANGELOG.md`.
