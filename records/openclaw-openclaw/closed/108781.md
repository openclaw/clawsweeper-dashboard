## What This Changes

Add a first-party Wear OS companion through staged typed RPC, phone-side proxy, watch UI, paired-device proof, and release integration work.

## Best Possible Solution

Land three bounded Android-owned changes: a versioned and size-limited RPC contract, a phone bridge that exclusively owns gateway authentication and routes only allowlisted calls to the requesting paired node, then the watch app with hardware/emulator proof and release wiring; retain credit and useful UX lessons from the prior prototype.
