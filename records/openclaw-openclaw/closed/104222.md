## What This Changes

The PR passes run-level cancellation through Context Engine bootstrap, maintenance, and assembly, makes aborts terminal during preflight, and uses one attempt deadline across preflight and active execution.

## Best Possible Solution

Keep the host-owned cancellation and single-deadline design, then demonstrate it with an installed external Context Engine by cancelling during preflight and showing that no model backend starts, the run settles with the expected abort reason, and any session write lock remains owned until engine settlement.
