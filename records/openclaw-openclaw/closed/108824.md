## What This Changes

Normalize non-interactive ambient terminal values so web-terminal Codex resume sessions receive a usable PTY type while preserving valid terminal types.

## Best Possible Solution

Normalize missing, blank, or non-interactive `TERM` values in the shared PTY launcher to the established interactive default, preserve valid values such as `screen-256color`, and add focused coverage for both the environment passed to the child and the PTY terminal name.
