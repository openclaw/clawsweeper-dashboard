## Summary

## What This Changes

The branch adds a process-wide FIFO queue keyed by hook session key for detached agent-hook runs, plus same-session and HTTP dispatch tests.

## Best Possible Solution

First add an unmocked regression that proves two direct hook requests reach the same claimed `agentSessionKey`; if that occurs, coordinate work at that shared admission identity rather than at the earlier request key, while preserving cross-session concurrency.
