## Summary

Keep open: current main still blocks custom app protocols and the contributor supplied convincing live proof, but the prior P1 blocker remains unchanged because the hardcoded list treats automation-capable local handlers as inherently safe.

## What This Changes

The PR adds eight desktop-app URI schemes to Control UI markdown sanitization and tests preservation of an Obsidian link.

## Best Possible Solution

Keep custom protocols blocked by default; if maintainers accept the feature, define a centralized click-time policy with explicit operator opt-in or confirmation, validate scheme-specific actions rather than scheme names alone, and cover automation, overwrite, extension-handler, unknown-scheme, and dangerous-scheme cases.
