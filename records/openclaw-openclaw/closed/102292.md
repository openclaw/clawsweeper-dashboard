## What This Changes

The PR moves startup catch-up deferral protection into persisted cron job state and removes the internal marker from Gateway read, event, webhook, and plugin-hook snapshots.

## Best Possible Solution

Keep the marker atomically persisted beside `nextRunAtMs`, but route every external cron job surface—including `PluginHookGatewayContext.getCron()` results—through one Gateway-owned public projection before merge.
