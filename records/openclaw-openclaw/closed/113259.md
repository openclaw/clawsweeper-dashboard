## What This Changes

This PR makes the shared Gateway usage-range resolver reject `usage.cost` and `sessions.usage` requests that send only `startDate` or only `endDate`, preventing a fallback report for an unrelated range.

## System Context

Gateway clients, the Admin HTTP RPC surface, and dashboard bindings use the Gateway usage methods to obtain cost and session summaries. Both methods pass their request dates through one shared resolver before loading cached usage data and returning an RPC result.
