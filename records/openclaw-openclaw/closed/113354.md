## What This Changes

The PR lets browser and iOS OpenAI Realtime Talk use the Gateway’s existing Codex OAuth session through an internal, one-time WebRTC broker when no OpenAI Platform credential is configured.

## System Context

Talk selects an OpenAI realtime provider, then the Gateway creates a browser WebRTC session and records resulting conversation turns. This PR preserves the direct OpenAI Platform path while adding a bundled Codex app-server route for OAuth-only browser and iOS sessions.
