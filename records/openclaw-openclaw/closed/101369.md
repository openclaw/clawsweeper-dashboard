## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P2] Keep download transports open until saves finish:** `extensions/browser/src/browser/client-actions-core.ts:72`
  - body: `Page.waitForEvent('download')` only waits for the download event; OpenClaw then awaits `download.saveAs(...)`, which can take longer than this fixed 5 second grace window for large or slow exports. A download detected near the wait deadline can therefore be saved successfully by the browser route while the new agent action reports a timed-out browser request, so the host and node/Gateway timeout calculations need to cover the full save path.
  - confidence: 0.9
- **[P2] Wrap page-controlled download metadata:** `extensions/browser/src/browser-tool.actions.ts:654`
  - body: The new explicit download action returns `jsonResult(result)`, putting page/header-controlled `download.url` and `download.suggestedFilename` directly into model-visible tool text. Other browser-originated text in this module is wrapped as untrusted external content; this new result should use the same pattern so a malicious filename or URL cannot inject instructions into the next agent turn.
  - confidence: 0.88
