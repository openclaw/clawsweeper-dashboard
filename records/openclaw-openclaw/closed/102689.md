## Summary

Keep open: current main still has only gateway snapshots, manual RPC, models, and event-log sections on the authenticated Debug page, while the requested allowlisted UI/browser diagnostics table is not implemented and the protected maintainer label requires human handling.

## What This Changes

The issue requests a support-safe diagnostics table on the authenticated Control UI Debug page for browser, rendering, display, accessibility, capability, and media facts.

## Best Possible Solution

Add a narrow authenticated Debug-page diagnostics section with a typed allowlist, explicit redaction/no-identifier rules, focused render coverage, and browser proof, without dumping raw browser or app objects.
