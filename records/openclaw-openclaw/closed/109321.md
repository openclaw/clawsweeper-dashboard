## What This Changes

Prevent generated shell completions from interpreting the `|` inside option argument syntax as a flag and causing Fish to create or truncate a file named `-l`.

## Best Possible Solution

Build completion option metadata from Commander's parsed `Option.short` and `Option.long` fields, then cover shared metadata output and a real Fish source operation that asserts no `-l` file is created or truncated.
