## Summary

Close this PR in favor of the more direct, proof-positive runtime-level fix in https://github.com/openclaw/openclaw/pull/114077. That PR addresses the missing Google Meet ownership wiring at its owner boundary, while this branch changes the shared recovery helper and also references a runtime tab map that current `main` does not define.

## What This Changes

The branch makes URL-less Google Meet tab recovery require a runtime-owned target and prevents the shared meeting-browser controller from enumerating arbitrary Meet tabs when no URL is supplied.

## System Context

The Google Meet plugin receives tool and CLI recovery requests, resolves a browser transport, and delegates tab inspection to the shared meeting-browser controller. That controller can focus a tab, grant media permissions, and dispatch the Meet status script, so ownership must be established before it selects a tab.
