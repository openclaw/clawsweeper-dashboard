## Summary

The central aggregate-tool-result recovery problem is already tracked by the closed canonical report at https://github.com/openclaw/openclaw/issues/15409 and is superseded by current recovery code: unset live tool results now use a 16,000-character ceiling, and recovery calculates aggregate reducibility rather than requiring an individually oversized result.

## What This Changes

The issue requests that large-context overflow recovery still reduce cumulative current-turn tool results when the auto-selected per-result ceiling would otherwise leave no reducible content.

## Best Possible Solution

Keep the canonical aggregate-overflow recovery implementation and direct any fresh reproduction on the current release to https://github.com/openclaw/openclaw/issues/15409 with a redacted current log and effective tool-result-cap value.
