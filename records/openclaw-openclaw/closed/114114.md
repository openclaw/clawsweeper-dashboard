## Summary

This issue duplicates the still-open canonical llama.cpp tool-schema report. Both reports describe the same exact llama.cpp parser error when OpenClaw sends a full tool set with an unanchored JSON Schema `pattern`; the earlier report isolates the currently implicated cron-tool field and provides a narrower workaround and repair direction.

## What This Changes

Normalize or remove unanchored JSON Schema patterns so llama.cpp-compatible tool-calling backends accept OpenClaw’s tool definitions.

## System Context

OpenClaw builds tool JSON Schemas and sends them through OpenAI-compatible provider requests. llama.cpp converts those schemas into a constrained grammar before an agent turn, so one unsupported schema pattern can reject the entire tool-enabled request.
