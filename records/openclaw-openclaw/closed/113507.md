## Summary

Keep this PR open, but do not merge it as written: it changes every unrecognized remote Qwen 3.5+ custom route from OpenClaw’s default OpenAI reasoning dialect to Qwen’s top-level `enable_thinking` dialect. The upstream compatibility contract reserves that dialect for DashScope-style endpoints, while local Qwen-compatible servers need the separate `qwen-chat-template` dialect; the PR also needs redacted real-route proof before merge.

## What This Changes

The PR infers reasoning capability and a Qwen thinking request format for selected Qwen 3.5+ model IDs in configured catalogs, the model registry, and embedded agent model resolution.

## System Context

Agent model selection combines configured and discovered model metadata into the resolved model record used by the embedded runner. Its compatibility settings determine which reasoning-control fields OpenClaw sends to the selected provider endpoint.
