## What This Changes

This PR replaces the fixed default for global concurrent agent runs with a process-memoized CPU-derived value between 8 and 16, while retaining explicit `agents.defaults.maxConcurrent` overrides.

## System Context

Inbound agent runs are serialized per session and then admitted through a global lane that limits concurrent work across sessions. Configuration defaults feed that lane limit, which affects queue latency, resource contention, and whether waiting turns expire before they begin.
