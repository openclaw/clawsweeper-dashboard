## Summary

This remains useful work, but it is not merge-ready: cleanup removes the child-process `error` handler before SSH failure paths finish terminating the child, creating an unhandled-error crash path, while the memory claim has only automated-test proof. Likely related people are cxbAsDev and vincentkoc with high confidence, plus steipete with medium confidence, based on recent merged history in these paths.

## What This Changes

The PR adds a shared helper that removes child-process lifecycle listeners and stdio data listeners on settlement across local bash, Docker, SSH command/upload, and shell-snapshot execution paths.

## Best Possible Solution

Use operation-owned cleanup functions that detach their exact data, stream-error, and lifecycle callbacks, retain minimal non-capturing child/stream error guards until termination is complete, and demonstrate reduced retention in a real repeated-execution run.
