## What This Changes

This PR splits OpenClaw Control UI chat state responsibilities—routing, refreshes, page setup, Gateway-event reconciliation, rendering, and lifecycle control—into focused modules while retaining `chat-state.ts` as the caller-facing facade.

## System Context

The Control UI chat page receives route changes and Gateway events, restores composer and session state, reconciles queued sends and streamed responses, then schedules Lit rendering. This refactor reorganizes that orchestration without changing the public chat-page facade used by existing callers.
