## Summary

Keep open: this is a useful targeted performance fix, but the unchanged PR head is still not merge-ready because the tail fast path can accept an incomplete sampled transcript and rotate away preserved session/model state that full rotation keeps.

## What This Changes

The PR adds a bounded header-and-tail transcript reader for file-backed post-compaction successor rotation and a long-transcript regression test for avoiding full JSONL rereads.

## Best Possible Solution

Keep the bounded reader, but use it only when the sample proves all successor-preserved state and metadata rows are present; otherwise fall back to the full reader and cover that case with a long-file regression.

## Reproduction Assessment

## Solution Assessment

No. The PR is in the right layer, but the completion condition is too weak; the maintainable fix is a stricter proof gate plus fallback to the existing full reader when preserved state cannot be proven.
