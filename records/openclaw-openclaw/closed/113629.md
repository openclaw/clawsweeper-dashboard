## What This Changes

This PR changes the OpenAI-compatible Responses endpoint so provider or client-tool failures emit one `response.failed`, send `[DONE]`, release stream resources, and close the HTTP response without a later completion event.

## System Context

The Gateway’s OpenAI-compatible Responses endpoint converts agent and provider lifecycle outcomes into server-sent events for external API clients. A failed agent run must terminate the HTTP stream cleanly while preserving gateway work-admission cleanup and preventing a contradictory successful terminal event.
