## Summary

The patch is correct and still necessary: current `main` forwards `messageAction()` text unchanged, while LINE requires that field to be no more than 300 grapheme clusters. The shared helper is the right boundary, the added tests cover both the direct constructor and outbound quick-reply payload, and the redacted live validation/push evidence is sufficient. No mechanical repair or further product decision is indicated; this PR is ready for normal channel-owner review.

## What This Changes

Caps LINE message-action `text` at 300 grapheme clusters in the shared action helper and adds direct plus outbound quick-reply regression tests.

## Best Possible Solution

Merge the bounded helper-level grapheme cap so every existing `messageAction()` caller emits a LINE-valid action payload while preserving the rest of the channel action types unchanged.

## Solution Assessment
