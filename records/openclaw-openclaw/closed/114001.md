## What This Changes

This PR allows a harness-owned agent runtime to continue native compaction without a host ambient API key when route/auth preparation fails, while preserving the fail-closed behavior when an ambient key exists and adding warning logs.

## System Context

Agent turns can invoke a native runtime's context-compaction hook after a response. The harness-selection layer prepares any host-owned credentials, then hands the attempt to the runtime or falls back to the context engine when that runtime intentionally declines automatic compaction.
