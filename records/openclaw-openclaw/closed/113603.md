## What This Changes

The PR updates security audit, policy, and skill-workshop diagnostics to display canonical `agents.entries.<id>` configuration paths instead of internal `agents.list` projection paths.

## System Context

OpenClaw normalizes agent configuration for runtime use, while security audits and diagnostics turn that configuration into remediation text for operators. These messages feed CLI audit output and policy explanations, so their paths must name editable `openclaw.json` locations.
