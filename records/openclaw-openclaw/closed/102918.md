## Summary

Keep open: current main still lets conversational Crestodian setup persist a macOS CLI candidate based on detection alone, while the protected maintainer label prevents cleanup closure or autonomous repair intake.

## What This Changes

Require Crestodian conversational setup to live-test installed CLI candidates before persisting a default model, falling through to the next candidate or provider setup when a candidate cannot complete.

## Best Possible Solution

Route conversational Crestodian setup through the same live-test activation ladder as guided setup: persist a candidate only after a real completion succeeds, try the next candidate on failure, and otherwise finish setup without a model while offering provider setup.
