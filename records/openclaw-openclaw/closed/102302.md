## Summary

## What This Changes

The PR adds an `http-control-ui` gateway auth surface, routes Control UI HTTP read requests through it, and adds gateway auth tests for tokenless Tailscale identity on bootstrap/media/avatar reads.

## Best Possible Solution

Allow tokenless Tailscale identity on Control UI HTTP reads only if the same origin/allowed-origin policy is enforced, docs/tests are updated, and real Tailscale Serve proof is added; otherwise keep HTTP reads on bearer/device-token auth.
