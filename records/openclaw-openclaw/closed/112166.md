## Summary

Keep this PR open. ## What This Changes

Persist `killed` terminal session metadata after force-clearing stuck embedded-agent runs, while ensuring delayed cleanup cannot affect a replacement run, reply operation, or session entry.

## System Context

Embedded-agent recovery clears stalled runs triggered by heartbeat or timeout cleanup. Its result feeds both the reply-run registry and persisted session metadata, which later dispatch and session-listing paths use to decide whether a new message can proceed.

## Architecture Diagram

## Best Possible Solution

Land the bounded recovery fix only after exact-head CI is clean, preserving the captured-owner checks and atomic session-ID guard so force-clear writes a terminal snapshot without clobbering a newer session.
