## Summary

Current `main` and v2026.6.11 silently flatten a supported Claude adaptive setting to medium effort, so the issue remains necessary. Keep it open while the linked fix PR is reviewed; its direction is sound, but its wording and coverage should treat omitted `--effort` as delegation to Claude Code settings/defaults and settle fallback-model behavior.

## What This Changes

Stop the `claude-cli` backend from silently converting a supported adaptive thinking selection into explicit medium effort.

## Best Possible Solution

Remove the silent adaptive-to-medium coercion in the Anthropic plugin, document that adaptive delegates effort selection to Claude Code, and add regression coverage for explicit levels, configured-effort precedence, unsupported-model clamping, and fallback candidates.
