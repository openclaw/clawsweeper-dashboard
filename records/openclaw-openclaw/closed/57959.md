Full review comments:

- **[P1] Block CLI prompt-ref images on cross-provider retries:** `src/agents/command/attempt-execution.ts:451`
  - body: This only strips the explicit image payload before calling the CLI runner. When `images` is absent, `executePreparedCliRun` still calls `loadPromptRefImages({ prompt, workspaceDir })`, and new-session fallback retries can preserve the original prompt, so a cross-provider retry to a CLI-backed provider can still load and send local image refs from the prompt. Thread the suppression policy into the CLI image-loading path or pass an explicit empty-image/no-detect state, with a CLI regression test.
  - confidence: 0.9
- **[P2] Populate partialExecution before relying on it:** `src/agents/model-fallback.ts:818-831`
  - body: `runWithModelFallback` now forwards `described.partialExecution`, but the production `new FailoverError` call sites in the embedded and CLI runners do not set that field; only the new tests synthesize it. As a result, the replay-avoidance system prompt is never emitted for real partial tool execution. Populate it from the existing attempt tool metadata or split the plumbing out of this claimed fix.
  - confidence: 0.84
