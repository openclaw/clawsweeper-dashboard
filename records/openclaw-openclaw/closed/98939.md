## Summary

Current main and the latest release already canonicalize allowed local media roots before comparing them with canonicalized media paths, so the reported symlinked workspace MEDIA failure is implemented rather than remaining actionable.

## What This Changes

The issue reports that symlinked agent workspaces are rejected for outbound MEDIA attachments because files are compared after realpath canonicalization while allowed roots remain symlink paths.

## Best Possible Solution

Keep the shipped shared media-root canonicalization and ask for a new report only if a current release still rejects a distinct symlinked workspace MEDIA path.

## Reproduction Assessment

No current-main failure was reproduced. Source inspection shows the reported raw-root versus realpathed-file mismatch is already addressed by canonicalizing allowed roots before comparison.

## Solution Assessment

Yes. The current shared validator canonicalizes roots in one place, which is the narrow maintainable fix for webchat, gateway, outbound, and channel callers that pass agent-scoped roots.
