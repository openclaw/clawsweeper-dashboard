## Summary

This is a credible, narrow Control UI clarity problem, but the permanent color meaning for “running” is a cross-surface product decision. The protected `maintainer` label also requires explicit maintainer handling, so this issue should remain open for that choice.

## What This Changes

Change Control UI run indicators so active sessions no longer use the same red visual family as error and timeout states in the dark theme.

## System Context

Control UI session state is rendered as run, waiting, and failure indicators in the sidebar, chat, catalogs, collapsed session groups, and sessions page. Shared palette tokens determine how quickly users can distinguish active work from attention-required failures.

## Best Possible Solution

Choose one existing non-error token for active running work, apply it consistently to the two shared run-indicator rules, and visually verify the affected Control UI surfaces in both themes.
