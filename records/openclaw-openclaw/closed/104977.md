## What This Changes

The issue reports that refreshing or unregistering a provider in one session clears process-global OAuth provider state used by other live sessions.

## Best Possible Solution

Make the effective OAuth provider registry instance-owned by session services or AuthStorage, seed built-ins per instance, and route registration, lookup, refresh, enumeration, override, and teardown through that owner.
