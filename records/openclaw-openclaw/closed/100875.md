## Summary

## What This Changes

The PR threads model `reasoning` metadata into native chat model choices, hides the shared iOS/macOS thinking picker when gated, and sends `off` while the picker is hidden.

## Best Possible Solution

Make non-off gateway session/default thinking metadata authoritative, use `reasoning == false` only when refreshed gateway metadata is absent or off-only, and add proof that the native picker hide/show path works in a real app run.

## Solution Assessment

No: the current implementation is too broad because generic model `reasoning == false` can override authoritative gateway thinking metadata. The best fix is to let non-off gateway metadata win and keep the model flag as a temporary fallback signal.
