## What This Changes

The PR changes QA Lab’s isolated-Gateway parent grace period from five to thirty seconds so the Gateway can finish its existing bounded shutdown and persist provider state before the QA runner escalates to a process-tree kill.

## System Context

QA Lab starts an isolated Gateway for restart and replay scenarios, then stops and replaces it during validation. The parent shutdown timer must leave room for the Gateway’s own shutdown watchdog to flush channel/provider state before QA verifies the replacement Gateway’s behavior.
