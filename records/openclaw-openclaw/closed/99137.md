Full review comments:

- **[P2] Suspend in-flight Voice Wake starts:** `apps/ios/Sources/Voice/VoiceWakeManager.swift:274`
  - body: `scheduleStart` clears `scheduledStartTask` just before entering `start()`, then `isStarting` stays true while permission/audio setup awaits. If push-to-talk, camera audio, or background capture calls `suspendForExternalAudioCapture()` during that window, this guard returns false because `isListening` is still false and there is no pending task, so the in-flight start can continue toward `installTap` while another capture owns the mic. Treat `isStarting` as suspendable, or otherwise cancel/mark the in-flight start for retry before returning false.
  - confidence: 0.84
