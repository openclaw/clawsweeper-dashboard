## What This Changes

This PR changes Google Chat, Slack, Zalo, and Mattermost account discovery so unavailable configured SecretRefs skip only the affected account while healthy accounts still expose message actions and Mattermost directory access.

## System Context

Channel plugins supply account-specific actions to OpenClaw’s shared message tool. Account discovery reads configured credential state to decide which actions to advertise, while actual sends and runtime startup use strict credential resolution.

## Best Possible Solution

Preserve the plugin-owned inspection APIs, retain strict credential resolution for send/startup paths, and land only after the assigned owner confirms the exact-head merge result still covers healthy and unavailable multi-account combinations.
