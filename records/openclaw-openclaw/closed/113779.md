## What This Changes

This PR replaces the 2,200-line embedded-agent session-lock implementation with focused controller, fencing, ownership, prompt-release, entry-classification, and write-scope modules while preserving `attempt.session-lock.ts` as the compatibility entry point.

## System Context

Embedded agent attempts serialize writes to each persisted session transcript, temporarily releasing the lock while a model prompt runs. The session-lock lifecycle then reacquires ownership, fences against external file changes, and permits only validated transcript updates to reach the session file.
