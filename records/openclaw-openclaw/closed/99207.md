## Summary

Keep open: current main still hard-codes Voice Call Telnyx realtime media to PCMU/u-law and the realtime voice SDK has no Opus audio format, so the requested Opus support remains missing and needs maintainer codec/API direction.

## What This Changes

Request native Opus codec support in the Voice Call plugin and realtime audio contracts so Telnyx/OpenAI-style voice calls can work on high-jitter international links.

## Best Possible Solution

Design a Voice Call codec negotiation path that can accept and emit Opus where carriers and realtime providers support it, update the SDK audio-format contract deliberately, and prove Telnyx carrier behavior with focused tests plus live Opus-only call evidence.

## Reproduction Assessment

No. The reporter gives detailed Telnyx Opus-only steps and source confirms current main only configures PCMU/u-law media, but I did not run a live Telnyx call to observe the disconnect.

## Solution Assessment

No. A simple codec string swap is not the best fix because the bridge, pacer, tests, and SDK audio types currently assume mu-law/PCM; maintainers need a codec contract and provider negotiation decision.
