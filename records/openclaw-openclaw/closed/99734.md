## Summary

Keep open because the maintainer-labeled issue reports a valid QA Smoke orchestration race exposed by https://github.com/openclaw/openclaw/pull/99705; current main still schedules test-file/script work alongside flow partitions and no merged fix or canonical duplicate was found.

## What This Changes

Prevent unified QA Smoke scheduling from allowing script-backed Docker/package-build scenarios to mutate shared dist while flow Gateway partitions are starting or running.

## Best Possible Solution

Add scheduler-level isolation so package-mutating script/Docker partitions cannot overlap flow Gateway partitions in one checkout, with focused regression coverage and without changing the Docker lane implementations.
