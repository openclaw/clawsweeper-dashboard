## Summary

The reported production crash path does not reproduce on current main because the runtime worktree GC target is an async method whose pre-await throws become promise rejections caught by the existing handler; the only bypass case requires an invalid non-Promise test override.

## What This Changes

The issue reports that the worktree cleanup interval can crash the maintenance worker if the GC call throws synchronously before a promise catch is attached.

## Best Possible Solution

Close this report and keep the current async GC contract; reopen only with a real runtime stack trace or caller that passes a non-Promise cleanup function.
