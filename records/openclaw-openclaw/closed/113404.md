## What This Changes

The PR makes existing OpenClaw state-database read-only access respect SQLite locking and journals, then verifies quarantine, integrity, and canonical schema state before diagnostics read the database.

## System Context

OpenClaw state diagnostics open the shared SQLite state database to inspect and repair runtime state. This path feeds doctor and maintenance reporting, so it must not treat pages from an interrupted writer as committed state or silently accept quarantined, corrupt, or noncanonical databases.
