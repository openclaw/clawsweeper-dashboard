## What This Changes

The PR associates execution approvals with agent runs, cancels run-bound approvals on abort, emits approval-parking lifecycle events, and adds run/session/tool-call metadata to the approval protocol.

## Best Possible Solution

Centralize run-bound approval cancellation at the shared abort owner, propagate run and tool-call ownership plus post-approval abort checks through node-host execution, suppress lifecycle clears after a terminal abort, and make the sweep continue after individual persistence/publication failures.
