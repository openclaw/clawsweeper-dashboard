## What This Changes

This PR adds a shared Plugin SDK resolver for normalized native approval targets and migrates the iMessage, Signal, and WhatsApp channel plugins to use it.

## System Context

Native approval routing turns an approval request into a channel-specific destination before the channel sends or suppresses an approval prompt. This change moves the common destination normalization used by three messaging plugins into the Plugin SDK while retaining each channel's transport policy locally.
