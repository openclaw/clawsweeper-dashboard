## System Context

OpenClaw’s SSH sandbox helper runs remote setup, validation, and cleanup commands for sandbox-backed agent sessions. Callers provide a remote command and optional cancellation signal; the helper launches SSH and returns output or an error to the surrounding sandbox workflow.
