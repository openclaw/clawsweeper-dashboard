## What This Changes

This PR splits OpenClaw’s agent pre-tool-call approval, policy, diagnostics, and execution handling into focused modules while retaining the existing facade and execution interfaces.

## System Context

Before a tool runs for an agent, OpenClaw prepares parameters, evaluates ordered safety and approval policies, records diagnostics, and then reconciles/finalizes parameters before execution. This boundary feeds both wrapped agent-tool execution and the adapter path that exposes tools to clients.
