## Review Findings

Full review comments:

- **[P2] Cap macOS export filenames by UTF-8 byte length:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatInlineWidgetView.swift:281-291`
  - body: `filename(title:)` only strips path and control characters. Widget titles can remain arbitrarily long, and this value becomes the `NSSavePanel` default filename, which can exceed the destination filesystem component limit and leave a valid export unsavable. Preserve `.png` while truncating on UTF-8 code-point boundaries. This repeats an earlier unresolved finding because the current head still has no bound.
  - confidence: 0.98
- **[P2] Wait for the current widget navigation before snapshotting:** `apps/shared/OpenClawKit/Sources/OpenClawChatUI/ChatInlineWidgetView.swift:309-329`
  - body: The web view begins navigation asynchronously, but export availability is not tied to successful completion of the current navigation. An immediate export can therefore copy or save a blank or partial viewport as a valid PNG; track readiness for the active resource and disable or defer the action until it completes.
  - confidence: 0.9
- **[P2] Route widget export strings through the macOS catalog:** `apps/ios/Resources/Localizable.xcstrings:43793-43935`
  - body: The new strings are added to the iOS catalog and generated artifacts, but the macOS packaging path compiles a separate macOS localization catalog. Add the shared export labels and error messages there so non-English macOS users do not receive this new flow in English.
  - confidence: 0.96
