## Summary

Keep this PR open for maintainer review. The patch presents a coherent, additive way to make custom session-group placement durable across Control UI browsers, and the supplied before/after browser proof directly demonstrates the requested interaction; however, it introduces a synced configuration contract and the current head still has failing CI lanes that should be resolved or scoped before merge.

## What This Changes

This PR adds the optional `ui.prefs.sessionSectionOrder` preference and sidebar drag handling so a custom session-group header can be positioned relative to Threads, Groups, Coding, and other custom groups.

## System Context

The Control UI turns gateway session rows and the gateway-owned custom-group catalog into sidebar sections. This change adds a persisted section-order preference between the UI settings sync path and the sidebar renderer, while keeping the group catalog as the native-client ordering source.
