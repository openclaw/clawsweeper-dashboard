## Summary

Current and shipped OpenClaw already canonicalize remote media Content-Type values before Feishu routing, so mixed-case MIME headers cannot reach the case-sensitive helper through the production URL path; buffer sends carry no MIME value. The PR’s direct helper proof therefore exercises an unreachable input, making the extra Feishu normalization redundant.

## What This Changes

The PR adds Feishu-local MIME lowercasing before outbound media routing and directly tests mixed-case classifier inputs through a new export.

## Best Possible Solution

Keep shared web-media loading as the single MIME-canonicalization owner and avoid exporting or adding Feishu-only handling for inputs the production API cannot produce.
