## Label Justifications

- `P1`: Signal users cannot stop active work through the same channel because the control turn is delayed until the run completes.
- `impact:message-loss`: Urgent control input is held before admission until it is no longer actionable.

## Summary

Current main still delays later same-key Signal controls behind the active awaited debounce flush, and the paired fix PR remains open. The issue is necessary until a narrowed implementation lands.

## What This Changes

Restore immediate authorized Signal abort and safe active-run control handling while preserving ordinary and state-mutating command ordering.

## Best Possible Solution

Give Signal a separate serialized lane for aborts and an explicit small set of safe active-run controls, cancel pending ordinary text only for authorized aborts, and keep reset, config, model, and other state-mutating commands on the normal conversation chain.
