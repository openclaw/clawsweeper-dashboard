## What This Changes

## Best Possible Solution

Create sibling Kova and source-probe producer jobs from the same resolved SHA, upload independently immutable attempt-scoped artifacts, and make publication validate and consume an attempt-coherent artifact pair across both single- and multi-artifact download layouts.
