## Summary

Keep open: current main still records an interrupted run as an empty aborted assistant message without durable model-visible recovery context, and the open linked implementation PR must be reviewed or replaced before this issue can close.

**Likely related people**
- `steipete` — high confidence; introduced and merged the current OpenClaw-owned agent-core and transcript architecture.

## What This Changes

Persist a hidden model-visible interruption marker after an aborted run so the next turn knows prior tool actions may have partially executed.

## Best Possible Solution

Define one append-only, hidden agent-core interruption message with harness-neutral guidance, persist it exactly once for every genuinely aborted run, replay it on the next model request, and cover abort paths, compaction, provider conversion, and channel-history visibility with focused tests.
