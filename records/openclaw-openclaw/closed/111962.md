## What This Changes

This PR retries MCP tool catalogs that contain discovery diagnostics after a five-second cooldown, while retaining healthy sibling catalogs and refreshing the combined catalog once the failed server recovers.

## System Context

The session MCP runtime discovers tools from configured MCP servers and exposes the resulting catalog to agents. The combined runtime merges multiple catalog sources, so it must preserve healthy tools while a failed source retries and later contributes recovered tools.
