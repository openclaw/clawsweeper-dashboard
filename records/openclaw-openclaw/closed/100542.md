## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P2] Keep scanning the heredoc opener line:** `src/agents/tool-display-exec-shell.ts:332`
  - body: This starts the skipped body immediately after the delimiter token. In shell, the heredoc body starts after the newline that ends the whole command line, so `python3 <<PY && npm test\n...\nPY` would have the real `&& npm test` stage hidden from the summary instead of displayed after the inline script.
  - confidence: 0.88
- **[P2] Only strip tabs for <<- heredocs:** `src/agents/tool-display-exec-shell.ts:373-374`
  - body: The terminator search always removes leading tabs before comparing the line with the delimiter. Plain `<<EOF` does not allow tab-stripped terminators, so a body line like `\tEOF` can terminate early and expose later heredoc body text as real command stages.
  - confidence: 0.84
