## Summary

Current main still has the reported terminal-ordering defect: background lifecycle admission is released before asynchronous sandbox cleanup settles. The issue is concrete and necessary, but its protected `maintainer` label requires explicit maintainer handling.

## What This Changes

Keep background sandbox exec lifecycle admission active until process outcome and sandbox finalization have both settled, while preserving primary terminal errors and emitting one terminal transition.

## Best Possible Solution

Introduce one idempotent exec terminalization path that records the process outcome, awaits sandbox finalization, selects cleanup failure only when no primary failure exists, and then releases lifecycle admission and publishes the terminal state exactly once.

## Solution Assessment
