## Summary

Keep open. The patch is not merge-ready: the Docker command payload is still not passed through the supervisor input contract, and the claimed shell-injection mitigation is ineffective because `/bin/sh -l` still parses metacharacters read from stdin.

## What This Changes

The branch changes Docker sandbox exec construction to launch `/bin/sh -l`, return a command stdin payload, keep Docker exec stdin open, and update focused unit tests.

## Best Possible Solution

Preserve the existing shell-command contract unless maintainers approve a no-shell or validated-command design; for this PR, wire Docker input through the typed supervisor contract and prove normal plus metacharacter Docker cases before merge.
