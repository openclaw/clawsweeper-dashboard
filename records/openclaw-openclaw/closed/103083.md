## Summary

Keep open: current main and the latest release still route the named provider-supplied video result URLs through unguarded fetch paths, and the related open PRs are partial or adjacent rather than a merged canonical fix.

## What This Changes

This issue requests SSRF guarding for provider-supplied generated-video result downloads in the BytePlus, MiniMax, xAI, Runway, and Vydra bundled provider paths.

## Best Possible Solution

Land a security-reviewed provider hardening change that carries the resolved request policy through each affected submit, poll, metadata, and result-download leg, uses guarded fetch helpers by default, and adds SSRF regression coverage for default-deny and explicit private-network opt-in behavior.
