## Label Justifications

- `P2`: Daily-only operational residue can pollute durable memory for Dreaming users, but Dreaming is opt-in and can be disabled without making the core runtime unusable.
- `impact:session-state`: The issue concerns low-value transient material being promoted into persistent MEMORY.md and consequently altering future agent context.

## Summary

This is a well-supported current-production instance of the signal-semantics problem already tracked by the open canonical issue; the new 2026.7.1 measurements are valuable evidence, but the promotion-policy decision should remain consolidated there.

## What This Changes

Separate organic recall/query evidence from repeated daily-ingestion persistence so daily-only operational residue cannot silently qualify for durable promotion.

## Best Possible Solution

Use the canonical issue to define one explicit evidence contract—preferably requiring organic or grounded durable evidence before automatic writes while treating daily persistence as scoring reinforcement—then align ranking, apply filtering, explain output, regression tests, and docs without adding another config knob unless maintainers intentionally want a compatibility mode.
