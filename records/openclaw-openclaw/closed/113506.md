## What This Changes

This PR adds logical display geometry and multi-monitor inventory to macOS computer-use screenshots, preserves a frame after pre-input rejections, changes macOS node-worker startup in debug builds, and adds `SKIP_MLX_TTS=1` to omit the MLX TTS helper during app packaging.

## System Context

The computer tool asks a connected macOS node for a screenshot, then uses that frame and display geometry to validate later mouse or keyboard actions. The macOS node combines native commands with a node-host worker manifest before advertising capabilities and connecting to the Gateway.

## Best Possible Solution

Keep the screenshot metadata and frame-retry improvements, but retain a configured worker’s manifest in DEBUG builds—use a deterministic project executable or a bounded startup/recovery path rather than returning `nil`; scope or remove the MLX skip switch unless maintainers explicitly support helper-less developer packages.
