## Summary

Keep open: current main does not provide durable narration without tool summaries, and no related item owns that remaining behavior. The existing progress-commentary setting is transient, so maintainers must decide whether durable narration should become a supported public mode.

## What This Changes

Requests separate control of commentary narration and tool-summary verbosity in chat progress output.

## Best Possible Solution

Make Mattermost honor the existing commentary setting independently first, then add one additive `commentary` verbosity level only if maintainers confirm durable narration is a distinct supported mode.
