## What This Changes

The PR changes two macOS chat test fixtures to timestamp durable history relative to the actual history-fetch or completed-send event instead of test initialization time.

## Best Possible Solution

Keep test history timestamps causally anchored to the send and fetch events they model, so executor starvation cannot make durable assistant rows appear older than their user turn.
