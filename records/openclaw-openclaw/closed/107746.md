## What This Changes

Correct `openclaw update` ownership detection for pnpm 11 global link-store installs and prevent unproven ownership from silently targeting npm.

## Best Possible Solution

Use one authoritative active-root ownership result across dry-run and execution, recognize verified pnpm 11 link-store installs, preserve their owning target, and make unresolved package ownership explicit without invoking a different manager after compatibility-safe caller updates.
