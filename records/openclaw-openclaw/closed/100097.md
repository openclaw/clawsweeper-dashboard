Keep open: current main and the latest release still expose Copilot quota windows and token-derived estimated USD, but not actual per-request billed AIC; the remaining work needs maintainer direction on the upstream billing contract and the permanent usage/status schema.

## What This Changes

The issue asks OpenClaw to read GitHub Copilot `copilot_usage.total_nano_aiu`, persist it as actual AIC, and optionally surface per-session totals and token-type breakdowns.

## Best Possible Solution

Confirm the GitHub Copilot response contract, then add a provider-owned actual-AIC usage field through the existing usage/session/status pipeline while keeping token counts and estimated USD clearly separate.

## Reproduction Assessment

Not applicable as a bug reproduction: this asks for a new billing signal, not a failing documented command. Source inspection confirms the current gap because main and `v2026.6.11` expose quota windows and estimated costs, not actual per-request Copilot AIC.
