- `maturity:stable`: The issue affects the M4 `gateway-runtime` Hosted Web Surface/WebSocket Connection area reported by the maturity shortlist.

## Summary

Keep open: current main still gates Control UI chat composition on live Gateway connectivity, while the lower-level send path already supports disconnected `waiting-reconnect` queueing. The protected `maintainer` label also prevents conservative cleanup from closing or auto-repairing this issue.

## What This Changes

The issue requests that Control UI chat composition remain available during a recoverable Gateway reconnect, queue pending input, and send it once the Gateway reconnects.

## Best Possible Solution

Keep this issue open and implement a narrow Control UI capability split: allow composing and enqueueing during the reconnecting mounted-shell state, persist the queued item, and flush it through the existing reconnect queue once the Gateway is available.
