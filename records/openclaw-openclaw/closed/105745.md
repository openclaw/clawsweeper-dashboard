## What This Changes

Avoid loading the expensive plugin repair and payload-validation runtime during fresh Gateway startup when canonical config and managed-install state conclusively require no plugin convergence work.

## Best Possible Solution

Add a cheap, conservative convergence-needs check over canonical config and the persisted plugin index before importing repair modules; skip only for conclusively empty fresh state, fall through on ambiguity, and cover both empty and plugin-bearing startup paths with focused profiling.
