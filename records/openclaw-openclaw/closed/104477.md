Keep open. The root-cause fix remains useful and no discrete defect is evident on its branch base, but the head conflicts with current main’s newer cancellation path and lacks required real behavior proof, so the integrated authentication behavior is not yet ready for approval.

## What This Changes

The PR adds 30-second deadlines covering fetch and response-body reads for OpenAI device-code login, retries timed-out authorization polls within the 15-minute window, and adds regressions for pre-header and partial-body stalls.

## Best Possible Solution

Rebase onto current main, compose the caller AbortSignal with a bounded per-operation deadline across both fetch and body consumption, retry polling only for the operation-timeout reason, and provide redacted CLI-level or equivalent real-setup proof.
