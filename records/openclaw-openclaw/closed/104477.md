## Summary

The timeout bug is valid and the proof is convincing, but the previously raised P1 blocker remains on the unchanged head: the patch creates a parallel raw-fetch OAuth request path instead of using the guarded request lifecycle already established by current main.

## What This Changes

Adds 30-second fetch-and-body deadlines to the three OpenAI device-code HTTP operations, preserves caller cancellation, retries timed-out authorization polls, and expands regression coverage.

## Best Possible Solution

Use one guarded OAuth HTTP operation path for all three device-code calls, covering headers and bounded body reads while preserving caller cancellation, poll-only timeout retries, audit context, proxy behavior, and resource release.
