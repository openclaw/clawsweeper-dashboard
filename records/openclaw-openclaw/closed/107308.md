## Summary

This request duplicates the previously considered cross-rollover chat-history request at https://github.com/openclaw/openclaw/issues/43929, which is closed as not planned; the broader but distinct transcript-management work remains tracked at https://github.com/openclaw/openclaw/issues/42980.

## What This Changes

Requests loading older messages while scrolling within the same apparent conversation, including messages hidden by the daily session rollover.

## Best Possible Solution

Keep the existing daily rollover semantics and closed product decision; if maintainers reconsider continuous history, reopen https://github.com/openclaw/openclaw/issues/43929 and design explicit paginated cross-segment history with clear rollover boundaries instead of creating another parallel tracker.

## Solution Assessment

No. Generic scroll-triggered importing would obscure session-rollover boundaries; any reconsidered solution should deliberately paginate rolled transcript segments and visibly preserve their session and time context.
