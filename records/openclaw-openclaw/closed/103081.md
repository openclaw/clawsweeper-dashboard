## Summary

Keep open: current main still creates visible `model-run-<uuid>` gateway session rows, and the merged cleanup only prunes stale rows under maintenance pressure, so the requested ephemeral or hidden one-shot behavior remains a product/session-lifecycle decision.

## What This Changes

The issue asks for `openclaw infer model run --gateway` to stop leaving durable session rows/transcripts, or at least make those one-shot probe sessions synthetic, opt-out, or filterable.

## Best Possible Solution

Choose one explicit lifecycle contract for gateway model probes: make them internal/ephemeral or hidden from normal session lists by default while keeping legacy cleanup, or deliberately document visible pressure-gated probe history as intended.
