## Summary

Keep open. Current main still treats room_event turns as prompt-only context with durable transcript persistence suppressed, and the live issue has the protected maintainer label plus product/storage contract decisions.

## What This Changes

Request durable ambient group awareness by appending observed room_event messages as bare session transcript rows and shrinking the chat window to only unpersisted messages.

## Best Possible Solution

Maintainers should define the ambient transcript-row contract, dedupe boundary, replay/compaction behavior, and mention-only policy before a focused core implementation.
