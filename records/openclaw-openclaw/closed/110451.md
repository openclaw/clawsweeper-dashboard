Keep open: the merged standalone host deliberately denied tool and resource calls, while the existing authenticated Control UI bridge owns the corresponding policy. ## What This Changes

Add ticket-bound standalone MCP App access to only app-visible tools and owning-server resources, without exposing Gateway bearer credentials or general Gateway RPC.

## Best Possible Solution

Implement one shared typed MCP App operation layer, authorize every ticketed request against the live owning-server view state, and advertise only handlers that are actually active; keep general Gateway RPC and bearer credentials unavailable to the standalone host.
