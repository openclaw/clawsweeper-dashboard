## Summary

Keep open: the patch is a narrow and likely-correct fix for unbounded qa-lab Convex credential lease response reads, but this external PR still needs contributor-supplied real behavior proof before merge and one unrelated CI shard is currently failing.

## What This Changes

The branch replaces raw `response.text()` in the qa-lab Convex credential lease helper with the bounded provider text reader, caps ordinary acquire/release/heartbeat responses at 1 MiB, preserves the configured chunk payload cap, and adds regression tests.

## Best Possible Solution

Land this narrow bounded-read fix after contributor real behavior proof is added and CI is green or the unrelated failure is resolved, keeping the chunk payload path on its larger configured limit.

## Reproduction Assessment

Yes. Current main clearly reads the full broker response with `response.text()` before error handling, and the PR's loopback test demonstrates the oversized failure path through `acquireQaCredentialLease`; I did not execute tests because this review is read-only.

## Solution Assessment

Yes, this appears to be the best fix shape: it reuses the existing SDK bounded HTTP reader at the shared credential lease boundary and preserves the separate chunk payload contract instead of adding a new local stream reader.
