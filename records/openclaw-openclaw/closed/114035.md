## What This Changes

This PR replaces the Copilot plugin’s monolithic attempt runtime with dedicated preparation, session setup, execution, active-run, cleanup, finalization, configuration, and type modules while retaining the existing attempt entry surface.

## System Context

The Copilot plugin turns an agent-harness attempt into a Copilot SDK session, streams its events and tool activity, then classifies and finalizes the result. This refactor reorganizes those lifecycle stages without intending to change the caller-facing attempt API or user-visible Copilot behavior.
