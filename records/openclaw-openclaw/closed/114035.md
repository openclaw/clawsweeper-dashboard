## What This Changes

This PR replaces the 2,048-line Copilot attempt runtime with focused modules for preparation, execution, session setup, cleanup, completion, active-run routing, configuration, and shared types while preserving the existing public entry module.

## System Context

The bundled Copilot plugin translates an agent-harness attempt into Copilot SDK session setup, streaming execution, tool and user-input bridging, transcript mirroring, cleanup, and a normalized terminal result. This refactor reorganizes that orchestration without intending to change the agent-facing runtime contract.
