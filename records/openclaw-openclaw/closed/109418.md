## Summary

Keep open for explicit maintainer approval: the patch appears correct and well-proven, but it intentionally makes trusted hosted ClawHub curation authoritative over bundled Featured metadata for published plugins.

## What This Changes

The PR propagates optional hosted `featured` metadata into the managed plugin catalog and applies it to uniquely provenance-matched published plugins while retaining local curation for private bundled plugins and offline fallback.

## Best Possible Solution

Adopt one provenance-checked catalog merge path in `management-service.ts`, with hosted curation authoritative for uniquely matched published packages, bundled metadata retained only for private/offline entries, and the omission semantics documented by focused contract tests.
