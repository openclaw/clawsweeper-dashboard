## What This Changes

This PR replaces parallel, partially optional catalog-owner shapes with one resolved agent-layer contract carrying the canonical agent, directories, configuration, and prepared model catalog for Gateway and isolated cron consumers.

## System Context

OpenClaw prepares model catalogs for individual agents, then Gateway request handlers and isolated cron runs use those catalogs to select, display, and execute models. This change moves the agent/config/workspace identity accompanying a published catalog into one resolved ownership contract before those downstream consumers project or execute it.
