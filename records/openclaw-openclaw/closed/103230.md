## What This Changes

## Best Possible Solution

Consume `sliceUtf16Safe` through `openclaw/plugin-sdk/text-utility-runtime`, make the generated wrapper’s 256 KiB retention slices surrogate-safe as well, and cover both boundaries before providing redacted live error-path proof.
