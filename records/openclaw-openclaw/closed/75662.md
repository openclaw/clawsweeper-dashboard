## Summary

This PR’s central fix is now superseded by the merged canonical yielded-parent lifecycle work in https://github.com/openclaw/openclaw/pull/95996. That implementation keeps a yielded parent nonterminal through the internal lifecycle contract while deliberately retaining the existing public session status shape; this branch’s remaining `paused`/`pauseReason` protocol and UI expansion would reintroduce the compatibility decision that the canonical fix avoided.

## What This Changes

The branch adds a persisted `paused` session status and `sessions_yield` pause reason so yielded main-session continuations remain nonterminal across Gateway recovery, session tools, protocol clients, and Control UI.

## System Context

A model turn can call `sessions_yield` while OpenClaw owns queued continuation work. Runner lifecycle events flow through Gateway session persistence and broadcasts to session tools and Control UI, which must distinguish a waiting parent task from a completed one without breaking existing session-status consumers.
