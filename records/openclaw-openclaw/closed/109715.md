## Summary

Keep this PR open: the latest head still resolves secrets for disabled webhook routes, which can reject otherwise valid reload or startup checks, and the shipped webhook-secret rotation boundary needs explicit maintainer acceptance before merge.

## What This Changes

The PR moves webhook route SecretRef resolution from request time into Gateway startup snapshot materialization, adds per-route owner isolation metadata, and updates webhook tests and documentation.

## Best Possible Solution

Keep startup snapshot isolation, exclude disabled routes before SecretRef collection, and prove that `openclaw secrets reload` atomically activates rotated webhook secrets, revokes the prior value, preserves healthy siblings, and retains typed degraded-owner diagnostics.
