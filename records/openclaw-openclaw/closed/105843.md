## Summary

Keep open for explicit maintainer handling: current main deliberately uses bounded mobile operator handoff scopes, while this fresh, assigned, maintainer-labeled issue proposes a security-sensitive change to that default and is not duplicated by the existing one-step pairing work.

## What This Changes

Make official iOS and Android setup grant node access plus the full server-defined native operator scope set by default, while retaining explicit limited-access and node-only setup paths.

## Best Possible Solution

Implement a fixed server-owned full native-mobile profile with a clearly selectable bounded alternative, display the active access level in both apps, and provide an in-product reconnect or upgrade flow without broadening other bootstrap profiles.
