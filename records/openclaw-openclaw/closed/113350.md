## What This Changes

The PR changes release dependency validation so packages from official plugins installed as separate npm projects are excluded from root-distribution dependency-conflict checks.

## System Context

OpenClaw release validation reads plugin package manifests to detect runtime dependency versions that would conflict inside the root distribution. The result feeds packaging and release preflight gates, while external plugins retain their own manifest, lockfile, install, and runtime validation boundaries.

## Architecture Diagram

## Best Possible Solution

Merge the bounded manifest-boundary check after the remaining release checks complete, keeping dependency-conflict enforcement for every plugin bundled into the root distribution and plugin-owned validation for isolated packages.
