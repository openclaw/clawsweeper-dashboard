## Summary

The patch is a focused, owner-correct fix for the linked regression: it keeps Google client attribution on outbound requests while removing the generated version value from strict durable-memory identity. No code defect was found, but this external PR still needs real installed upgrade proof before merge; its current evidence is mock-based tests and computed identity comparison only.

## What This Changes

The PR excludes generated `x-goog-api-client` version attribution from Gemini durable-memory identity and adds focused tests for version-stable identity and semantic-header invalidation.

## Best Possible Solution

Keep the generated Google attribution header on requests, omit it only from canonical durable identity, and add redacted real-runtime proof that an existing index is reused and `memory_search` succeeds after a version-only upgrade.
