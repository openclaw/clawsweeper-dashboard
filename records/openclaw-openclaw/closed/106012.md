## Summary

This PR is still necessary: it is a focused candidate fix for the linked, reproducible Control UI bug, and current public documentation still describes nodes without directory-browsing support as disabled. Keep it open for maintainer review because the protected `maintainer` label applies, the documentation needs alignment, and the external-PR evidence does not yet show the after-fix behavior against a real Gateway. ([docs.openclaw.ai](https://docs.openclaw.ai/web/control-ui?utm_source=openai))

## What This Changes

The PR keeps connected `system.run` nodes selectable in the New Session folder picker for typed absolute paths, avoids `fs.listDir` calls on nodes without browsing support, and adds browser E2E regression coverage.

## Best Possible Solution

Land a refreshed patch that applies one capability rule across both selectors: connected executable nodes permit typed absolute cwd values, only browse-capable nodes issue directory-list RPCs, offline or non-executable nodes remain unavailable, and the public Control UI documentation reflects that distinction.
