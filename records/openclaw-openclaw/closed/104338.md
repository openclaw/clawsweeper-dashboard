## Summary

Current main only partially covers the request: it shows Control UI build identity on About and in a dev-only tooltip, plus a separate always-visible off-main gateway branch strip, but it does not show commit and build age persistently. The maintainer-protected issue should remain open for an explicit decision on permanent sidebar prominence and artifact-versus-gateway identity semantics.

## What This Changes

Add an always-visible Control UI sidebar chip showing short commit, relative build age, branch and dirty state, with full identity details and an About-page link.

## Best Possible Solution

Add a compact accessible link for the Control UI artifact commit and relative age, retain the existing gateway off-main branch warning as a distinct signal, and add artifact branch/dirty fields only after defining deterministic build semantics and responsive proof.
