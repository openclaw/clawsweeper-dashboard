## Summary

Keep this PR open: its manual-dispatch path checks out and later imports code from the selected ref after minting a Barnacle app token, so a collaborator-controlled branch can bypass the protected-main review boundary and run privileged close/reopen automation.

## What This Changes

Adds an hourly GitHub Actions sweeper that detects recently opened pull requests with missing or startup-failed CI and re-triggers CI by guarded close/reopen operations using an app token.

## Best Possible Solution

Keep the scheduled repair loop on trusted default-branch code and move any manual dry-run capability behind a trusted-default-branch dispatcher or remove it until that boundary can be enforced before the app token is available.
