## What This Changes

This PR prevents plugin discovery from warning that a dependency is missing when an explicitly configured plugin file belongs to a validated manifest whose canonical ID satisfies that dependency.

## System Context

Plugin discovery gathers configured paths, installed packages, and bundled roots into candidate plugins, then reports dependencies that do not match a discovered candidate ID. This change consults a configured file candidate’s validated manifest only when producing that missing-dependency diagnostic, so valid local plugin dependencies are recognized without changing candidate selection or loading.
