## What This Changes

The PR makes Control UI active-run follow-ups inherit Gateway and session queue modes by default while retaining a visible, reversible browser-local override.

## Best Possible Solution

Expose one normalized Gateway-owned queue-policy contract consistently through session list, history, and live event payloads, then have the UI consume that contract without independently reinterpreting persisted values.
