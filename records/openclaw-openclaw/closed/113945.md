## What This Changes

This PR adds optional restored image attachments to session rewind and fork results, then places validated images back into the web, iOS/macOS, and Android chat composers.

## System Context

A session rewind or fork cuts an existing conversation at a selected user message and returns the text that should be edited next. This change also carries image blocks from that selected transcript message through the gateway protocol into each client composer without persisting them as drafts.
