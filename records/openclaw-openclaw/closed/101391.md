## Summary

Keep open: the bounded-read direction is right, but the fixed 8 MiB container cap bypasses existing Signal mediaMaxMb/maxBytes settings, so this patch can break configured larger media sends and still lacks real container proof.

## What This Changes

The PR replaces the Signal container outbound attachment fs.readFile path with readRegularFile capped at 8 MiB and adds an oversized-file regression test.

## Best Possible Solution

Keep the fs-safe bounded read, but feed it the same resolved maxBytes/mediaMaxMb limit used to resolve outbound media, add a configured-over-8-MiB regression test, and include redacted real container-send proof.
