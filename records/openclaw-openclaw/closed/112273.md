## Summary

Keep this PR open. ## What This Changes

This PR adds a process-local SQLite session-store cache with invalidation and cross-process checks, plus lightweight and paginated session listings for gateway consumers handling many sessions.

## System Context

The SQLite session accessor turns per-agent session rows into session summaries used by gateway RPCs and the Control UI. This PR inserts a cache and a reduced listing mode between the database rows and those consumers to avoid repeatedly materializing a large session store.

## Architecture Diagram

  B --> C[Full JSON parsing]
  C --> D[Cache and coherence checks]
  D --> E[Lightweight gateway listing]
  E --> F[Gateway RPC and Control UI]

## Best Possible Solution

Use a dedicated SQL-side projection for the gateway light-list reader so `systemPromptReport` and `skillsSnapshot` never cross the SQLite boundary or reach `JSON.parse`, keep complete by-key readers unchanged, and then publish redacted final-head runtime proof covering cold, warm, and external-write refresh behavior.
