## What This Changes

The PR sets Zod’s global `jitless` mode in the Control UI’s first inline bootstrap and extends the strict Content Security Policy regression test to Chromium plus available Firefox.

## System Context

The Control UI is static HTML plus JavaScript modules served by the Gateway with a strict `script-src` policy. The inline bootstrap runs before module imports, so it can configure Zod before schema validation probes for dynamic code generation and before the UI mounts.
