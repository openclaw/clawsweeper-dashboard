This PR replaces the short-term promotion path’s in-place `MEMORY.md` rewrite with the shared atomic file-replacement helper and adds a partial-write regression test.

## Best Possible Solution

Use one owner-local atomic replacement for promotion output, preserve existing permissions, and retain focused coverage proving a failed temporary write cannot alter previously persisted long-term memory.
