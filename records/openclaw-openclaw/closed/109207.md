## What This Changes

The PR adds a five-second forced-termination limit to POSIX and Windows process-tree metric probes and updates focused tests to assert the bounded spawn options.

## Best Possible Solution

Keep metric sampling optional, bound every platform probe with the same internal timeout, force termination when the probe stalls, and preserve `null` as the failure result; this PR implements that end state cleanly.
