## Risks / Open Questions

- A retried chat.send can still replay cached terminal ok while chatQueuedTurns owns the queued prompt, causing the TUI to clear pending UI before the prompt runs.
- Queued `/btw` prompts can still be aborted by a main-session Esc or `/stop` because queued-turn entries do not preserve turnKind and the queued abort path does not receive preserveSideRuns.
- The additive chat.abort preserveSideRuns protocol field and generated Swift model change are compatibility-sensitive for mixed-version TUI/Gateway clients.
- Queued-turn abort ownership changes are security-boundary-sensitive because requester, device, and connection authorization must stay correct for queued and active runs.
