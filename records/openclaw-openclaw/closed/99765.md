Full review comments:

- **[P1] Export Type from a real module:** `extensions/transcript-stats/api.ts:2`
  - body: `openclaw/plugin-sdk/plugin-entry` does not export `Type`, so this barrel re-export makes the plugin module fail to link before registration. Import `Type` from `typebox` where it is used and remove this invalid export.
  - confidence: 0.96
- **[P1] Use the injected filesystem in recent mode:** `extensions/transcript-stats/index.ts:238`
  - body: `loadRecentSessions` receives `params.filesystem`, but this line calls a bare `filesystem.readFile` that is not defined in this scope. `scope: "recent"` will fail instead of reading the selected sessions.
  - confidence: 0.95
- **[P2] Declare the TypeBox runtime dependency:** `extensions/transcript-stats/package.json:6-8`
  - body: The plugin imports `Type` from `typebox`, but its package only declares `@openclaw/plugin-sdk` as a dev dependency. Sibling tool plugins that import TypeBox declare it under `dependencies`, so this package would rely on root hoisting instead of its own runtime contract.
  - confidence: 0.9
- **[P1] Constrain transcript roots before exposing the tool:** `extensions/transcript-stats/index.ts:250-251`
  - body: As a bundled default-on agent tool, model-supplied `workspaceDir` or `sessionsDir` can point outside OpenClaw's session store and the implementation reads local `.jsonl` files to report metadata. This needs an operator-owned root or external-plugin install boundary before it is safe to ship in core.
  - confidence: 0.89
