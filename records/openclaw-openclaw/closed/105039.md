## Summary

This PR addresses a real resumed-session pagination failure and includes credible module-level proof, but its global `page_token`/`page_cursor` allowlist weakens transcript secret protection for tool arguments whose names are not reliable credential semantics. The linked canonical issue remains open for the broader replay-integrity and security design.

## What This Changes

The PR bypasses transcript key-based masking for `page_token`, `next_page_token`, and `page_cursor` fields while retaining value-pattern redaction, and adds regression coverage for cursor preservation and secret-shaped values.

## Best Possible Solution

Keep key-level transcript masking as the safe default and introduce cursor preservation only from a trustworthy semantic source—such as typed tool/schema metadata or a reversible replay representation—rather than from a global argument-name allowlist.
