This PR should remain open because its broader same-PR reuse policy can authorize landing a code revision that the reused hosted gates did not test. The protected maintainer-owned item needs either patch-equivalence enforcement or explicit acceptance of the weaker merge boundary.

## What This Changes

The PR allows a successful hosted-gate cohort from a recent earlier head of the same PR to authorize the current head for up to 12 hours.

## Best Possible Solution

Retain the shorter reuse window only for fallback SHAs whose PR patch or tree is proven equivalent to the current head; otherwise require exact-head gates.
