## Summary

This is a high-confidence duplicate of the already-open canonical MCP/sub-agent report: both describe the same restrictive inherited allowlist snapshot removing every bundle-MCP `<server>__*` tool from `sessions_spawn` children while built-in tools remain available. The newer report adds useful confirmation across stdio and streamable HTTP MCP transports, but it does not establish a distinct root cause or a separate product behavior.

## What This Changes

The issue requests that a spawned sub-agent retain explicitly allowed MCP-server tools instead of having them removed by the inherited-tool policy step.

## System Context

OpenClaw builds an agent tool surface from configured profiles and policies, then starts bundled MCP runtimes and filters their MCP tools for the run. A spawned child also receives inherited tool restrictions from its parent, which determine which tools reach the model and can be invoked.
