## Summary

This PR addresses a real archive-containment gap and the latest commit fixes the prior candidate-derived-root blocker, but the replacement root derivation still weakens containment for nonstandard store layouts and needs correction before merge.

## What This Changes

The branch makes transcript archive containment unconditional, adds store, agent, and legacy containment roots, and adds filesystem regression coverage for valid and poisoned transcript candidates.

## Best Possible Solution

Centralize archive authorization on the existing validated store-layout helper or typed candidate provenance, never infer an agents root from `basename === "sessions"`, and add coverage for canonical stores, noncanonical custom stores, legacy paths, cross-root upgrades, and poisoned structurally shaped `.jsonl` paths.
