## What This Changes

Adds captured PTY terminal output to TUI fixture-RPC timeout errors so a swallowed terminal command can be diagnosed alongside the fixture RPC log.

## System Context

The TUI PTY harness drives typed terminal commands against an in-process fixture gateway and waits for recorded fixture RPCs. When that wait times out, its error output is consumed by CI and developers to identify whether the command reached the gateway or was rejected in the terminal first.
