## What This Changes

This PR captures packaged-plugin CLI stderr in private temporary files, redacts it before bounded logging, preserves subprocess exit behavior, and forwards an enabled lifecycle-trace setting into the Docker acceptance runner.

## System Context

Packaged-plugin acceptance starts OpenClaw CLI commands inside the Docker-based E2E harness and currently needs useful failure output when a plugin assertion fails. This change sits between the subprocess and the harness logger, affecting what maintainers can diagnose after a failed package run.
