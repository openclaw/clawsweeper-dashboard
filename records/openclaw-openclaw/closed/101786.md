## Summary

Close as duplicate/superseded: the exact double-prepended `GRAPH_ROOT` loop is not present on current main, and the real remaining Teams long-thread reply pagination problem is already tracked by https://github.com/openclaw/openclaw/issues/98870 with https://github.com/openclaw/openclaw/pull/100166 as the current open fix candidate.

## What This Changes

The issue reports that Microsoft Teams thread-reply pagination would fail if an absolute Microsoft Graph `@odata.nextLink` URL were passed back through `fetchGraphJson`, causing `GRAPH_ROOT` to be prepended twice.

## Best Possible Solution

Keep https://github.com/openclaw/openclaw/issues/98870 as the canonical tracker and review or repair https://github.com/openclaw/openclaw/pull/100166 there; preserve this report's absolute-nextLink warning as useful implementation context for that fix path.
