## Summary

Close as a duplicate: the earlier backup-race report already covered volatile agent runtime paths, and its merged repair explicitly includes `shell_snapshots` plus handling for volatile paths that disappear before tar can `lstat` them.

## What This Changes

Exclude volatile Codex shell snapshot directories from backup traversal so a file that disappears during archive creation does not abort the backup.

## System Context

`openclaw backup create` walks the OpenClaw state directory and packages durable state into an archive. A volatile-path classifier prevents disposable runtime directories from entering that archive path, while preserving durable agent and browser data.
