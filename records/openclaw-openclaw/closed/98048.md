## Best Possible Solution

Merge a narrow provider parse guard with focused regression coverage after removing the broken standalone proof script and adding redacted standalone OpenClaw/MiniMax runtime proof.

## Reproduction Assessment

Yes by source inspection: current main routes non-empty MiniMax music SSE `data:` frames through a bare `JSON.parse`, so malformed JSON can throw before later valid audio frames are processed. I did not run a live malformed MiniMax stream in this read-only review.

## Solution Assessment

Partly: the provider-local try/catch is the narrow maintainable runtime fix, but committing a loopback proof script that cannot pass the real guarded HTTP path is not the best merge shape. The better path is to keep the Vitest regression and provide real proof as PR evidence or a maintained harness.
