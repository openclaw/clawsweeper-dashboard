## Summary

Keep open as a feature/product decision: current main and v2026.6.11 still use collision-only provider suffixes in the Control UI picker with no config flag, while the TUI source already uses provider/model refs and the new MiniMax comment confirms real multi-provider-routing friction remains.

## What This Changes

Request an opt-in config flag so Control UI and TUI model pickers can always show provider labels instead of only disambiguating name collisions.

## Best Possible Solution

Choose one canonical model-picker visibility policy first, then implement it consistently across Control UI and any TUI picker that still hides provider context, adding schema/docs/tests only if maintainers explicitly accept a new config option.
