- `merge-risk: 🚨 compatibility`: The PR can make existing context-engine plugins appear compatible with generic CLI hosts even when CLI cannot honor their full assemble contract.
- `merge-risk: 🚨 session-state`: Running assembly before CLI bootstrap and with bounded hook history can produce stale or incomplete context-engine state for the model turn.

## Summary

Keep this draft PR open, but the current patch is not merge-ready because it advertises full generic-CLI context-engine assembly support while only applying `systemPromptAddition`, and it runs assembly before the CLI bootstrap lifecycle that sibling hosts run first.

## What This Changes

The PR adds `assemble-before-prompt` to generic CLI host capabilities, calls `assembleHarnessContextEngine()` during CLI run preparation, prepends returned `systemPromptAddition`, and updates host-compatibility tests.

## Best Possible Solution

Either keep generic CLI rejecting full `assemble-before-prompt`, or implement full CLI support by bootstrapping first and projecting the complete assemble result into the actual CLI prompt path with focused tests and proof.

Full review comments:

- **[P1] Do not advertise full assemble support without projection:** `src/context-engine/host-compat.ts:18`
  - body: Adding this capability makes `assertContextEngineHostSupport` pass for engines that require `assemble-before-prompt`, but the new CLI path only uses `assembled.systemPromptAddition`; it does not project returned `messages`, `promptAuthority`, or `contextProjection` into the CLI prompt/reseed path. The current contract uses this capability for engines that must control the actual model prompt through `assemble()`, so generic CLI can silently run engines it still cannot host correctly.
  - confidence: 0.9
- **[P2] Run CLI assembly after context-engine bootstrap:** `src/agents/cli-runner/prepare.ts:1082`
  - body: This assemble call happens during prepare, but generic CLI runs `bootstrapHarnessContextEngine()` later in `runPreparedCliAgent`; embedded and Codex hosts bootstrap before assembly/projection. Engines whose bootstrap or maintenance rewrites state before assembly will now assemble from pre-bootstrap state, and this block also uses the bounded hook-history loader instead of the context-engine snapshot loader used by CLI finalization.
  - confidence: 0.86
