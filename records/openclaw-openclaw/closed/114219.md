## What This Changes

This PR lets core AI transports retain coded abort reasons in persisted assistant messages so restart recovery can distinguish a gateway restart from an unrelated provider timeout without relying on error text.

## System Context

Gateway restart recovery reads the final persisted assistant message from an interrupted agent turn to decide whether it can safely resume. AI transport code creates that terminal message, so preserving a coded abort reason there lets recovery make a structured decision instead of interpreting provider-specific text.
