## What This Changes

## Best Possible Solution

Merge the narrow helper swap after normal exact-head CI and maintainer review; the current code layer and helper choice are appropriate for this bug.

## Reproduction Assessment

Yes. Source inspection shows current main slices fallback reason text at `max - 1` UTF-16 code units, so an emoji whose high surrogate lands at the cutoff can produce a dangling surrogate before the ellipsis.

## Solution Assessment

Yes. The shared `truncateUtf16Safe` helper is the existing canonical helper for this pattern, preserves the current code-unit cap semantics, and is cleaner than adding a local surrogate scanner.
