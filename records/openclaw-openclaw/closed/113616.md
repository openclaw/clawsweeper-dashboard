## What This Changes

The PR compacts fenced untrusted conversation JSON, removes redundant metadata fields, formats reply dates for the envelope timezone, and moves generic bot-mention guidance from each turn into the stable system prompt.

## System Context

Inbound channel events are converted into a system metadata prompt plus fenced user-role context before an embedded agent sends the assembled conversation to a model. This PR reduces the repeated context carried on active turns while preserving the distinction between authoritative system metadata and untrusted user-provided text.
