## Summary

The bounded-response hardening is still needed on current main and the supplied proof is strong, but the latest head retains the prior blocking partial-result defect: the shared completion helper turns mixed success/error batches into total failure before successful embeddings are consumed.

## Best Possible Solution

Keep the shared bounded HTTP and JSONL readers, but model completion as successful output plus optional per-request error rows, correlate both artifacts by custom_id, preserve valid embeddings, and report only failed or missing requests.
