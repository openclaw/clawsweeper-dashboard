## Summary

Keep open: current main still uses the modal and free-text folder flow, with no host-directory listing RPC. The roadmap supports the UX direction, but the protected maintainer signal requires explicit approval for this new product and security boundary.

## What This Changes

Replace the Control UI new-session modal with a routed full-page composer and add an admin-gated gateway-host directory browser for selecting the session working directory.

## Best Possible Solution

Use one full-page session-draft route backed by the existing sessions.create contract, adding a narrowly specified admin directory-navigation RPC only after host scope, symlink handling, error disclosure, and paired-node UX are approved.
