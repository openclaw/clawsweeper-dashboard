Current `main` and release `v2026.6.11` under-budget valid sequential Browser actions: composite waits and recursively nested batches can outlive active outer watchdogs. Fix Browser `/act` watchdog budgets so composite waits and nested sequential batches can complete within their normalized runtime limits.

## Best Possible Solution

Centralize a saturating recursive execution-budget resolver, reuse it across the direct client, node proxy, and CLI, preserve explicit outer overrides, and add the five-second transport slack exactly once.
