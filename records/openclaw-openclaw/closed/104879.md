## What This Changes

Adds an opt-in `append` parameter to the write tool and an optional native `appendFile` capability for supported host, Docker, and remote-shell filesystem bridges.

## Best Possible Solution

Keep a single opt-in append contract that is advertised only for authoritative native backends, preserves explicit non-retryable uncertainty semantics, and lands only after an agent/plugin SDK owner sponsors the API and the refreshed head retains the current proof.
