- **[P1] Preserve external attachment URLs:** `ui/src/ui/chat/grouped-render.ts:963-964`
  - body: `buildAssistantAttachmentDownloadUrl` appends `download=1` to every non-image attachment URL, including external URLs that `buildAssistantAttachmentUrl` intentionally returns unchanged.   - confidence: 0.9
- **[P2] Encode filenames before setting Content-Disposition:** `src/gateway/control-ui.ts:521-522`
  - body: The new header interpolates the basename directly after only replacing quotes and CR/LF. Node rejects values such as `filename="報告.md"` with `ERR_INVALID_CHAR`, and this handler catches that as a not-found response, so Unicode filenames would fail instead of downloading; use an ASCII fallback plus `filename*` encoding and cover it with a header-validation test.
  - confidence: 0.88
