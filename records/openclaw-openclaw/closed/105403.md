## Summary

Current main already fixes the reported Telegram DM duplication by correlating outbound cache entries with canonical transcript messages through stable projection identity, so Markdown rendering differences no longer defeat deduplication. The fix is not included in v2026.6.11 but landed on main on July 11, 2026.

## What This Changes

Prevent a Telegram DM assistant reply from appearing in prompt context as both a delivery-rendered channel entry and a raw session-transcript entry.

## Best Possible Solution

Keep the merged projection-ID implementation and include it in the next release; it preserves cross-transport context while deduplicating rendered Telegram output by stable transcript identity.
