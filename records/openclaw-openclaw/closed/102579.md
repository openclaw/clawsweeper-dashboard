## What This Changes

## Best Possible Solution

Add an explicit per-turn task-suggestion action-sink capability, expose `spawn_task` and `dismiss_task` only when that sink exists, and either implement the Gateway-backed TUI accept/dismiss flow or keep those tools out of TUI-backed sessions until it exists.
