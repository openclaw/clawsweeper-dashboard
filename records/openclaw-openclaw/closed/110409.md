## Summary

## What This Changes

This PR journals iMessage inbound rows through the shared durable ingress queue before advancing the recovery cursor, replacing the old persistent replay guard with queue tombstones.

## Best Possible Solution

Make merged lifecycle settlement fault-isolating: invoke every constituent terminal callback, collect any callback failures, and surface the failure only after later claims have been settled; then show a redacted real crash/restart replay result.
