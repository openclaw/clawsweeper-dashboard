## Label Justifications

- `P2`: This is a concrete Gemini CLI auth/runtime bug with limited blast radius to concurrent same-profile runs, not a confirmed outage across core runtime.
- `impact:data-loss`: The report and source path can corrupt, delete, or overwrite staged token/cache files for the selected Gemini CLI profile home.
- `impact:security`: The affected code stages OAuth access, refresh, and ID-token material for an external CLI subprocess.
- `impact:auth-provider`: The bug can make selected Gemini CLI auth profiles fail or race against stale credential state during provider execution.
- `maturity:stable`: The affected CLI setup/auth reliability surface matches `cli-install-update-onboard-doctor`, scored M4 Stable in the maturity shortlist.

## Summary

Keep open: current main and the latest release still mutate the shared Gemini CLI per-agent/profile auth home before the serialized run queue starts, and still write staged credential JSON in place. No open or merged duplicate currently owns this exact race/atomicity bug.

## What This Changes

The issue asks OpenClaw to serialize Gemini CLI credential staging with execution and write staged token files atomically.

## Best Possible Solution

Make Gemini credential staging an atomic, serialized owner-local operation: guard shared per-profile home mutations with the same execution queue or a per-home lock covering preparation through process completion, and replace direct credential writes with atomic tmp+rename via the supported plugin SDK helper.

## Reproduction Assessment

Yes at source level. Same-agent same-profile Gemini CLI runs share one staged home, and current main mutates that home before the later `serialize: true` execution queue; I did not run a live two-process race repro.

## Solution Assessment

Yes. Serializing the shared auth-home mutation with the child process, or using a per-home mutex covering both staging and execution, plus atomic file replacement is the narrow maintainable fix without adding config or public plugin API surface.
