## What This Changes

Moves browser-tab cleanup from the Gateway scheduled-cron wrapper into the shared isolated-agent-run finalizer, using the detached run’s canonical session key for scheduled and hook-triggered runs.

## System Context

Cron schedules and hook requests both enter the isolated agent runner, which creates a run-scoped session identity and can open browser-owned tabs. When that run terminates, lifecycle cleanup must use the same canonical identity to remove the associated durable browser session rows and tabs.
