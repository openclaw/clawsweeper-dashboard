## Summary

## What This Changes

The issue reports that CLI taglines containing shell-sensitive characters can be expanded by zsh when rendered through shellCommandPrefix.

## Best Possible Solution

Keep the direct-stdout banner implementation and only reopen if a concrete repro shows banner text being fed back into an evaluated shell.
