## What This Changes

The PR marks global agent-lane admission as a healthy reply wait, runs restart recovery behind live turns, and makes stale recovery plus dropped-reply feedback match actual execution state.

## System Context

Incoming channel replies create reply operations and eventually enter the process-global agent lane before an embedded agent run begins. Session diagnostics and recovery observe that operation state; channel dispatch then either delivers the agent result or communicates a genuine pre-output failure to the user.
