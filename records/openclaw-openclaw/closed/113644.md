## What This Changes

The PR makes the terminal UI request the existing operator admin, read, write, and approvals scopes when it connects to the Gateway, and adds regression coverage for upgrading a cached read-only device token.

## System Context

The terminal UI connects to the Gateway through its chat client, presenting device credentials and requested operator scopes. The Gateway decides whether the cached token is sufficient or requires a device-approved pairing upgrade before the UI can send chat, session, or approval requests.
