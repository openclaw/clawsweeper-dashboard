## Summary

Keep open. Current main still has the reported race: the active branch-discovery response ignores edits made after its request began and replaces the value later sent to session creation. No later fix or canonical PR exists, and the protected `maintainer` label requires explicit sponsorship rather than automated repair intake.

## What This Changes

Prevent asynchronous branch discovery from overwriting a manually entered or cleared worktree base in the New Session form.

## Best Possible Solution

Track a base-field edit generation, snapshot it when branch discovery starts, and apply the discovered default only when both the request token and edit generation remain unchanged; add deferred-response coverage for both typing and clearing the field.
