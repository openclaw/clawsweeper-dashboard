## What This Changes

This PR adds a shared public Plugin SDK helper that fans one merged inbound turn’s lifecycle across durable channel-ingress claims, then replaces equivalent logic in seven bundled channel adapters.

## System Context

Channel adapters create durable inbound claims, then may debounce or merge several messages into one agent turn. The lifecycle fan-in decides whether every underlying claim is adopted or abandoned, controlling replay and duplicate-delivery behavior after dispatch.
