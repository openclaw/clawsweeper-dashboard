## Summary

Close as duplicate: the same Control UI CSP/Zod eval-equivalent failure is already the canonical open thread at https://github.com/openclaw/openclaw/issues/78362, and this report adds v2026.6.11 release evidence for that same root cause rather than a distinct fix path.

## What This Changes

The issue reports that v2026.6.11 Control UI fails under strict browser CSP because `script-src` omits eval permission while the `config-runtime`/Zod path uses eval-equivalent `Function` code.

## Best Possible Solution

Consolidate this report under https://github.com/openclaw/openclaw/issues/78362 and fix the Control UI bundle there by removing or disabling the eval-equivalent Zod path while preserving strict CSP.
