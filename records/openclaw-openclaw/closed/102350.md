Full review comments:

- **[P1] Reset attempts only after a stable reconnect:** `src/realtime-transcription/websocket-session.ts:259`
  - body: Deleting the raw-open reset fixes the tight flap loop, but this branch never resets `reconnectAttempts` after a reconnect becomes healthy. That makes the cap cumulative for the whole session, so a long-lived transcription session that successfully recovers from enough intermittent drops will later stop reconnecting even though those were not consecutive failures. Add a stable-ready reset boundary, or defer to the existing PR that does.
  - confidence: 0.88
- **[P2] Import WebSocket as a value:** `src/realtime-transcription/websocket-session.test.ts:94`
  - body: The new test helper compares `ws.readyState` to `WebSocket.OPEN`, but this file imports `WebSocket` with `import type`, so `check:test-types` fails with TS1361 at this line. Import the value form before this can merge.
  - confidence: 0.99
