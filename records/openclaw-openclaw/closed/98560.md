## Summary

Keep open: current `main` still has the separate plugin `node.invoke` policy approval path that can expire as `no-approval-route`, and the open linked PR is the unmerged candidate fix.

## What This Changes

Request to make plugin `node.invoke` policy approvals carry invocation turn-source fields and use the shared plugin approval pending-route logic.

## Best Possible Solution

Land or replace the linked gateway fix so policy-created plugin approvals use the same pending-route helper and turn-source metadata as ordinary plugin approvals.

## Reproduction Assessment

Yes. Source inspection shows policy-created plugin approvals omit turn-source fields and use local `no-approval-route` expiry logic while the ordinary plugin approval route keeps routable turn-source approvals pending.

## Solution Assessment

Yes. The requested fix matches the existing maintainable path: copy the invocation turn-source fields and reuse `handlePendingApprovalRequest` with `approvalKind: "plugin"` instead of duplicating route checks.
