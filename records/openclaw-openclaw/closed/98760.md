## Summary

Keep open. Current main still has a source-level path where Anthropic thinking recovery retries with all thinking blocks stripped, including the latest assistant turn, and the related open work is not a safe canonical closure target for this newer latest-turn failure mode.

## What This Changes

Investigate and fix an Anthropic retry path that strips or modifies thinking blocks in conversation history, causing repeated provider 400s and a session reset.

## Best Possible Solution

Define the Anthropic recovery retry policy so latest assistant thinking is preserved for `cannot be modified` failures while invalid prior replay is still repairable, then cover that boundary with focused tests and redacted live Anthropic proof.

## Reproduction Assessment

Yes at source level, but not as a deterministic live recipe. Current main has a recovery retry path that strips all thinking blocks, and existing tests prove that latest thinking can be removed during a rejected-request retry.

## Solution Assessment

Unclear as an automated fix. Preserving latest thinking for this error is likely necessary, but maintainers need to choose how that interacts with existing invalid-signature strip-and-repair recovery.
