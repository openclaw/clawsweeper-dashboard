## What This Changes

The issue reports that Gateway Crestodian chat using Codex-harness models cannot access its required `crestodian` tool because it is deferred behind Codex dynamic tool search.

## Best Possible Solution

Land a narrow fix that registers `crestodian` as a direct Codex dynamic tool whenever a run carries `crestodianTool`, with regression coverage for searchable loading and Crestodian gateway validation.
