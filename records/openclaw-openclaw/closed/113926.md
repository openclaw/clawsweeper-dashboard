## What This Changes

This PR makes remote Browser-node proxy startup retryable after a rejected or disabled startup attempt, while keeping simultaneous proxy requests on one shared startup operation.

## System Context

A paired remote Browser node receives browser-proxy requests through the Gateway and lazily starts its local browser-control service. This startup gate then forwards requests to the browser dispatcher; a rejected cached startup previously blocked all later requests until the node restarted.
