## What This Changes

The branch adds one shared macOS CLI config-path resolver so `connect`, `wizard`, and `configure-remote` honor `OPENCLAW_CONFIG_PATH`, then `OPENCLAW_STATE_DIR/openclaw.json`, before the default home config.

## Best Possible Solution

Adopt one macOS CLI config resolver with the established explicit-path, state-directory, and home-default precedence, while retaining the unchanged default-home behavior for users without either environment override.
