## Summary

This is a valid current bug, not cleanup: both v2026.6.11 and current main deliberately exit a launchd-managed gateway after a routine restart while relying on KeepAlive, even though the repository already has an active launchctl handoff for managed daemon restarts. The issue should remain open as the narrow macOS config-restart outage report.

## What This Changes

Fix macOS LaunchAgent-managed gateway restarts so configuration-triggered or gateway-tool restarts actively relaunch instead of leaving the gateway stopped.

## Best Possible Solution

Route launchd-detected routine restarts through the existing detached launchctl handoff, verify the replacement becomes reachable, and fall back to an in-process restart if handoff scheduling fails.
