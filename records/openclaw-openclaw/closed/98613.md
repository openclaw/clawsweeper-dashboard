## Best Possible Solution

## Solution Assessment

Yes: the parser boundary is the narrowest maintainable layer because direct SDK callers otherwise need to duplicate the fallback that `probeVideoDimensions` already owns. Caller-side catching would leave the exported helper inconsistent with the unknown-dimensions contract.
