## Summary

Keep this PR open: the retry-capacity change still cannot complete the shared Periphery intersection when only one producer is rerun, and the supplied successful retry runs do not exercise that partial-rerun path.

## What This Changes

The branch conditionally skips a new script guard for historical release targets, routes retried macOS scans to hosted runners, freezes the release-gate merge snapshot, and refreshes generated Apple locale files.

## Best Possible Solution

Make the intersection resolve a valid artifact for each producer across attempts, or make partial retries rerun both producers as one recovery unit; add a regression test and a redacted one-producer retry proof before merge.

## Reproduction Assessment

Yes, at source level: let one shared producer succeed on attempt 1, rerun only its failed sibling, and run the intersection while its artifact names use attempt 2. The current artifact-attempt coupling makes the missing sibling artifact deterministic from the workflow contract.

## Solution Assessment

No: the current runner fallback is useful, but it does not preserve the downstream artifact contract for a partial retry. Per-producer artifact resolution or paired producer reruns is the narrower complete fix.
