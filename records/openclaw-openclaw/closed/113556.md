The patch appears to preserve the existing generated-media limit behavior while removing duplicate provider logic, but it adds one Plugin SDK runtime export, so maintainers should confirm that this is the intended long-lived plugin contract before merge.

## What This Changes

The PR exposes the shared generated-media byte-limit resolver through the Plugin SDK runtime surface and replaces duplicated image, audio, and video limit calculations across bundled providers.

## System Context

Generated-media providers read `agents.defaults.mediaMaxMb` before downloading, decoding, or storing image, audio, and video output. The shared media layer converts the configured MiB value into a byte cap or falls back to the established per-kind default, which each provider then enforces.

## Best Possible Solution
