## Summary

Keep open: current main and the latest release still construct Matrix helper API URLs in a way that drops a configured homeserver path prefix, and https://github.com/openclaw/openclaw/pull/93516 is the open closing candidate.

## What This Changes

The issue reports Matrix channel connection failures when a configured homeserver URL includes a reverse-proxy path prefix.

## Best Possible Solution

Review and land or replace https://github.com/openclaw/openclaw/pull/93516 so Matrix transport resolves helper endpoints relative to the full homeserver base path, then close this issue after the fix reaches main.
