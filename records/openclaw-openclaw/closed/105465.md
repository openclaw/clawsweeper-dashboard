## Summary

The issue requests user-supplied restrictive AppArmor and seccomp profile overrides for Docker sandbox containers.

## Best Possible Solution

Keep the shipped `agents.defaults.sandbox.docker.seccompProfile` and `apparmorProfile` settings as the sole override contract, with OpenClaw blocking known weakening values and Docker reporting profile-loading failures.
