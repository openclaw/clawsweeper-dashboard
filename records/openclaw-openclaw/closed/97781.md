## Summary

This remains a useful hardening PR, but the latest head still needs changes before merge: the previously reported User Token status-mapping regression has no targeted fix in the subsequent commit history, and the latest head also has an unresolved high-precision CodeQL correctness alert.

## What This Changes

## Best Possible Solution

Keep the bounded local handlers, but make their invoke status and response body exactly match the pinned Teams/Bot Framework contract for success, fallback, malformed input, missing token, and service failure; resolve the non-callable CodeQL path and prove all cases through the registered routes.
