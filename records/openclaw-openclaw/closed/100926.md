## Summary

Keep open. Current main still treats `reasoning: "off"` as a truthy enabled-thinking request in the Google and Anthropic simple adapters, and the linked fixing PR is open/unmerged and still targets the pre-`packages/ai` provider paths.

## What This Changes

Ensure `SimpleStreamOptions` with `reasoning: "off"` disables thinking in the Anthropic and Google simple provider adapters.

## Best Possible Solution

Land a focused provider-runtime fix in `packages/ai` that treats `reasoning: "off"` like `false` before provider effort or budget mapping, with regression coverage for Google, Google Vertex, ordinary Anthropic adaptive models, and mandatory adaptive-thinking exceptions.
