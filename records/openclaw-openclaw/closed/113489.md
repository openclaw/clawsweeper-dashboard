## What This Changes

This PR makes Matrix reuse a canonical storage root immediately when its token, device, and claimed-current-state metadata agree, avoiding scans of historical token-hash roots while retaining the existing fallback for unsettled roots.

## System Context

The Matrix plugin derives a per-account storage root from the configured access token and device identity, then opens the selected SQLite-backed state for client startup. This resolver determines whether startup uses the canonical root directly or examines historical token-rotation roots for recoverable state.
