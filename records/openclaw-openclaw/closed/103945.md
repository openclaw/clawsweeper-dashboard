The PR adds an optional host-resolved-defaults field to Mac App node approval snapshots, requests it only for identified Mac App node sessions, and makes remote CLI effective-policy output unavailable when a file-backed node cannot attest its defaults.

## Best Possible Solution

Land the additive host-attestation design after adding redacted live proof that a current signed Mac App reports its actual resolved defaults and that a non-attesting older node produces the documented unavailable result without changing runtime enforcement.
