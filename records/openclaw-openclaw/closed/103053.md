## Summary

Keep open: current main still renders raw MCP server definitions from `/mcp show` without redaction or group-to-private routing, so the credential disclosure reported here remains actionable.

## What This Changes

Prevent `/mcp show` and `/mcp show <name>` from exposing credential-bearing MCP `env` or `headers` values in shared chats.

## Best Possible Solution

Make the group-visible `/mcp show` reply never contain raw `env`, `headers`, or sensitive URL values, preferably by redacting before rendering and adding a group invocation regression for named and all-server output.
