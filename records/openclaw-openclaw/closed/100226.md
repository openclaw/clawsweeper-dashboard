## Summary

Keep open: this maintainer-labeled issue is protected from cleanup closure, and current main still has a local-default `prepare_gates` path that runs build/check/full `pnpm test` on the maintainer host. Existing fixes addressed deterministic macOS test failures and nested-worktree manifest poisoning, but not the reported busy-host no-output watchdog and whole-gate lock contention problem.

## What This Changes

The issue asks for `scripts/pr` prepare gates to support a sanctioned remote full-suite/Testbox path and to serialize concurrent gate blocks before local shards start.

## Best Possible Solution

Define one supported `scripts/pr` broad-gate policy: reuse or document the existing exact-head Testbox verifier when adequate, add a remote full-test lane only if needed, and wrap local build/check/test under one gate-level lock so concurrent preparations queue before starting work.
