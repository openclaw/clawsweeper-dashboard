## Summary

The current head resolves the prior active-lock-generation finding and has strong real race proof, but force-removing a live leased worktree leaves its later Git-guard cleanup retrying against an already removed checkout. This narrow current-head defect should be repaired before merge.

## What This Changes

The PR adds SQLite-backed shared run leases and exclusive removal claims for managed session worktrees, with a secondary Git worktree guard and focused race regressions.

## Best Possible Solution

Keep the SQLite immediate transaction as the single cross-process admission and removal authority, but make Git-guard cleanup treat an already removed worktree as complete and add a force-remove-live-lease regression proving no pending cleanup or false guard survives.
