## What This Changes

This PR publishes fallback model pricing in the hosted catalog, makes runtime cost estimation read that catalog instead of per-Gateway source fetches, removes `models.pricing`, and adds a Doctor migration for that retired setting.

## System Context

The model catalog combines bundled and hosted provider metadata for Gateway model selection and cost estimates. This PR moves third-party pricing acquisition to the catalog publisher, then lets Gateway cost formatting resolve catalog data, configured prices, and safe hosted fallbacks.
