## Summary

Keep this PR open for maintainer review. The hosted-catalog approach removes duplicated third-party pricing fetches, but the Doctor migration silently drops an existing explicit pricing opt-out; after upgrade, affected users can resume hosted catalog traffic unless they independently set a different option. The `maintainer` label also requires explicit maintainer handling.

## What This Changes

This PR publishes fallback model pricing in the hosted catalog, uses that catalog for local cost estimates, removes Gateway-side OpenRouter/LiteLLM pricing refreshes, and retires `models.pricing` through Doctor.

## System Context

The model catalog publisher gathers plugin-owned model metadata and source pricing into a hosted bundle. Gateway and usage reporting load the bundled or refreshed catalog, then resolve model costs for session totals and CLI output without each Gateway querying pricing sources directly.

## Best Possible Solution

Decide and document the supported upgrade semantics, then migrate or preserve an existing explicit pricing opt-out so upgrade behavior is deliberate, observable, and covered by a regression test.
