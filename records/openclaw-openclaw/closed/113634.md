## What This Changes

The PR tracks session-observer visibility per live Gateway connection and replays it after reconnects so Android, iOS, and macOS session views continue receiving live updates through visibility and window changes.

## System Context

Native apps subscribe to Gateway session events and declare whether a session observer is currently visible. That connection-bound declaration controls whether session and chat views receive live updates after reconnects, app foregrounding, and macOS window lifecycle changes.
