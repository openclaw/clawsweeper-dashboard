## Summary

This PR remains necessary: it moves existing Ollama deadlines onto the shared guard path that also bounds DNS/proxy preflight, and the supplied exact-head socket proof shows the stalled-lookup failure now returns near the intended deadline without dispatching HTTP. No concrete patch defect was found in the provided diff and review context; it needs ordinary maintainer review rather than cleanup closure.

## What This Changes

Moves five Ollama guarded-fetch deadlines from `RequestInit.signal` to top-level `timeoutMs`, adds injected DNS-preflight regression coverage for model discovery, and updates the web-search request assertion.

## Best Possible Solution

Keep the shared guard as the single timeout owner for these Ollama calls, retain the focused preflight regression test, and merge after maintainers accept the existing timeout budgets for remote Ollama deployments.
