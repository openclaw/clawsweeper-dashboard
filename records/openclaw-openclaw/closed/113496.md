## Summary

Keep this PR open: its facts-first migration is still necessary after the merged writer bridge, but the history-pruning path leaves canonical persisted media behind when it is explicitly asked to drop media. The branch also needs inspectable after-fix UI/runtime proof before merge.

## What This Changes

This branch changes transcript, gateway, agent, Control UI, hook, media-understanding, and trajectory consumers to prefer persisted `__openclaw.media` facts over legacy top-level `Media*` fields while retaining a narrow reader for older rows.

## System Context

Inbound channel media is normalized into runtime facts, persisted into session history, then consumed by prompt hydration, history pruning, gateway display, the Control UI, hooks, and trajectory export. This PR moves those downstream readers to the persisted canonical facts so later migration work can retire the legacy projections safely.
