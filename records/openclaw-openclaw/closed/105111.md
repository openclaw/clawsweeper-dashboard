## Summary

Current main still has a valid, narrowly scoped bug: Crestodian’s temporary embedded turn is treated as SQLite-backed for trajectory capture even though no persistent session row is created. No linked or searched item currently owns the fix, and the protected maintainer label requires explicit maintainer handling.

## What This Changes

Fix Crestodian fuzzy-planner cleanup so ephemeral turns do not flush SQLite trajectory rows without a persisted session record.

## Best Possible Solution

Add an explicit ephemeral transcript/persistence decision at the embedded-run boundary and use it to retain Crestodian’s temporary JSONL transcript without creating a SQLite trajectory recorder; preserve and test existing SQLite trajectory capture for persisted sessions.
