## Summary

## What This Changes

Correct the Control UI so working workspace skills do not display an unavailable security-verdict badge.

## Best Possible Solution

Track the fix in https://github.com/openclaw/openclaw/issues/108647: hydrate security verdicts whenever route-loaded status contains linked skills, and represent loading or fetch failure separately from a genuinely unavailable verdict.
