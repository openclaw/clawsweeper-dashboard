The PR marks `messages.visibleReplies` and `messages.groupChat.visibleReplies` as gateway hot-reload paths and adds CLI/reloader tests for visible-reply reload hints and callbacks.

## Best Possible Solution

Classify visible-reply mode changes as hot reload even when the write creates `messages` or `messages.groupChat`, cover those first-write cases in tests, and add redacted real behavior proof of a no-restart mode switch.
