## What This Changes

The branch decomposes the browser plugin’s 2,110-line Playwright interaction implementation into navigation, action, content, and execution modules while leaving the original interaction module as an import-compatible facade.

## System Context

The browser plugin translates CLI and gateway browser-action requests into Playwright operations against an attached page, applying SSRF and navigation policy before returning results. This PR reorganizes the interaction layer beneath that stable facade, affecting action dispatch, page navigation checks, screenshots/uploads, and abort handling.
