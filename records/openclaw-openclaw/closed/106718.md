## Summary

Current main already uses the requested database-first architecture: runtime state is owned by global or per-agent SQLite databases, legacy JSON/JSONL files are doctor-only migration inputs, and the issue’s named files do not represent the current implementation. The central migration landed through https://github.com/openclaw/openclaw/pull/94646 and shipped in v2026.6.9-beta.1.

## What This Changes

Deprecate file-based runtime-state sidecars, move their data into canonical global or per-agent SQLite schemas, and restrict legacy-file imports to doctor migrations.

## Best Possible Solution

Keep the shipped canonical SQLite architecture and its database-first regression guard; any newly observed runtime sidecar write should be reported as a narrow bug with the actual current path, writer, version, and reproduction.
