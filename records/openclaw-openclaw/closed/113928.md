## What This Changes

This PR makes the chat background-tasks rail prioritize running work by collapsing finished history initially, splitting scrolling between the two sections, and widening the tasks column.

## System Context

The Control UI receives task state from the chat background-task host and renders running and finished task sections in the chat rail. This change adjusts the initial presentation and CSS layout so active task progress remains visible while completed history remains available on demand.
