## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.94

Full review comments:

- **[P1] Reject private OpenClaw imports before allowlists:** `src/plugins/import-policy.ts:371-372`
  - body: `allowedPackages.has(barePackage)` returns before the private `openclaw/*` rejection, so a plugin that declares `openclaw` can make `openclaw/runtime` pass this policy check. That defeats the boundary this PR is adding instead of enforcing it consistently.
  - confidence: 0.96
- **[P1] Block computed module specifiers before loading:** `src/plugins/import-policy.ts:273-278`
  - body: The scanner only records literal `require(...)`, `require.resolve(...)`, and `import(...)` specifiers, but the loader executes the plugin after this check. A plugin can build the same forbidden specifier dynamically, skip `violations`, and still reach module resolution.
  - confidence: 0.94
- **[P1] Validate plugin-local dependency entrypoints:** `src/plugins/import-policy.ts:439-455`
  - body: Allowed bare imports stop at this `continue`, so code inside a declared dependency under the plugin root is never scanned before the plugin is executed. That lets a plugin hide forbidden private imports or root escapes in its own `node_modules` entrypoint while the top-level policy passes.
  - confidence: 0.93
- **[P1] Reject traversal in allowed bare subpaths:** `src/plugins/import-policy.ts:355-358`
  - body: This accepts any specifier starting with `openclaw/plugin-sdk/` before normalizing the subpath. Node resolves bare requests with `path.resolve`, so forms like `openclaw/plugin-sdk/../runtime` can leave the allowed SDK subpath and should be rejected by the policy before allowlists are considered.
  - confidence: 0.86
- **[P1] Normalize overlay forwards before allowing them:** `src/plugins/import-policy.ts:63-76`
  - body: The runtime overlay exception allows any raw string beginning with `../../../dist/` and returns success before the normal root checks. A path such as `../../../dist/../../outside.js` still has that prefix but resolves outside the intended canonical dist root.
  - confidence: 0.9
- **[P2] Preserve package.json directory resolution:** `src/plugins/import-policy.ts:318-324`
  - body: Local resolution only tries direct files and `index.*`, but CommonJS directory resolution also uses `dir/package.json` `main`. Valid in-package imports like `require("./dir")` can be rejected as unresolved even though Node would load them.
  - confidence: 0.82
