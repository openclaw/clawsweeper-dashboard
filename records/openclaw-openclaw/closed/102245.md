## Summary

Keep open: the exact in-progress state cleared after the report, but live evidence still shows the automerge repair timed out waiting for an exact-head review and left the referenced PR blocked with automerge armed.

## What This Changes

The issue reports that a ClawSweeper automerge repair can push a repaired PR branch, then remain ambiguous or blocked while waiting for exact-head review and merge gates.

## Best Possible Solution

Make automerge branch-repair waits terminal and self-recovering: if exact-head review dispatch is missing or cancelled after the timeout, ClawSweeper should surface a blocked or requeued state with the exact blocker instead of reporting completion while the PR remains armed and blocked.
