## What This Changes

The PR passes the active board’s mutation capability into the Chat sidebar so Chat close and cross-side drag controls are omitted when that board is read-only or cannot mutate, while other sidebar panels keep their controls.

## System Context

Control UI’s Chat pane renders board-specific sidebar panels such as Chat, Details, and Discussion. The active board supplies its mutability state to the sidebar region, which decides whether each panel may expose layout-changing controls.

## Architecture Diagram

  C --> D[Sidebar region]

  E --> G[Visible close and drag actions]

## Best Possible Solution

Keep the per-slot capability boundary, then add redacted before/after browser proof showing Chat controls absent on a non-mutable board and present on a mutable board.
