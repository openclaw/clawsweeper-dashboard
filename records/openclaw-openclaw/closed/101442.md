## What This Changes

The PR caps `openclaw agent --message-file` reads at 4 MiB by resolving symlinks and using the regular-file helper, with tests for oversized files, directories, and symlink chains.

## Best Possible Solution

Use a bounded incremental descriptor read that retains regular-file, symlink, FIFO or named-pipe, missing-file, directory, UTF-8, BOM, and empty-input behavior, then state the 4 MiB limit in command help and the CLI reference.
