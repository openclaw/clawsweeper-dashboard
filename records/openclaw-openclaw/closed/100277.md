## Summary

Keep open: this is useful iOS work for the reconnect cursor stack, but the PR currently breaks its promised older-gateway fallback because a rejected `afterSeq` request is logged and abandoned instead of retrying full history.

## Best Possible Solution

Keep the iOS cursor adoption, but retry legacy full `chat.history` when the cursor request is rejected, cover that thrown-fallback case with a Swift regression test, and land only after the gateway cursor PR is accepted.
