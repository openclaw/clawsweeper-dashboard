## Summary

Keep open. Current main still misses percent-encoded URL extensions, but this patch is not merge-ready because it decodes the whole pathname instead of the final filename segment and the PR body only provides test-based proof.

## What This Changes

The branch decodes HTTP(S) URL pathnames before media-core extension lookup and adds focused tests for encoded URL extensions.

## Best Possible Solution

Keep the shared media-core fix, but decode only the final HTTP(S) pathname segment and add regression cases for malformed earlier segments and encoded path separators.
