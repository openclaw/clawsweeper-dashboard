## What This Changes

This PR adds a local tokenizer-based context-usage estimate to session metadata and Gateway session rows so the Control UI can display session pressure when a provider omits a full context snapshot.

## System Context

OpenClaw records prompt and transcript diagnostics on a session, then projects that data through Gateway session rows to the Control UI. The proposed fallback estimates token pressure locally when provider-reported context usage is unavailable.
