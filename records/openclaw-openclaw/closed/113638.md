## What This Changes

The branch reuses the Gateway’s canonical owner resolver and passes its verified result into Chat Completions and Responses agent commands so authenticated owners retain owner-only tool authority in streaming and non-streaming HTTP requests.

## System Context

OpenAI-compatible Chat Completions and Responses requests enter the Gateway, where authentication determines operator scopes and trusted owner status. The resulting agent command controls tool authority, so losing that verified owner fact causes correctly authenticated callers to be treated as non-owners.
