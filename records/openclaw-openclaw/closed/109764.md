## Summary

Keep open: the cross-surface progress feature remains useful and is not on current main, but the current head is not merge-ready because its long-running prepare path can overwrite concurrent config edits.

## What This Changes

Adds an admin gateway prepare session that streams provider progress through wizard surfaces, supports cancellation, and offers an Ollama tools-capable model pull when none is installed.

## Best Possible Solution

Keep WizardSession progress streaming, but compute provider output without persistence, then acquire the current write path, re-read authoritative config, verify the original hash or absent-file precondition, merge only the provider-owned result, and reject conflicts with focused existing-file and absent-file race tests.
