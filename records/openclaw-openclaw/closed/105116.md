Overall confidence: 0.97

Full review comments:

- **[P2] Report the pushed branch's diff beside the Create PR link:** `src/gateway/control-ui-session-prs.ts:240-249`
  - body: The eligibility check and URL target `origin/<branch>`, but these statistics are computed from local `HEAD` plus uncommitted and untracked files. If the agent has unpushed commits or working-tree changes, the row advertises a size that the linked GitHub PR will not contain. Compute the PR count from the remote ref, or label local pending work separately.
  - confidence: 0.98
- **[P2] Avoid one git process per untracked file on the minute timer:** `src/gateway/control-ui-session-prs.ts:199-213`
  - body: This loop can run 100 sequential `git diff --no-index` processes, and branch metadata is recomputed by every active chat pane every 60 seconds. Large or slow working trees can therefore stall this optional status request repeatedly. Reuse a bounded aggregate from the existing session-diff owner or otherwise enforce a fixed total work budget.
  - confidence: 0.97
- **[P3] Make the test's remote branch match its context:** `src/gateway/control-ui-session-prs.test.ts:428`
  - body: The fixture writes `refs/remotes/origin/feature`, but `resolveGitContext` still returns the shared `claude/browser-tabs-tighter-header` branch. The pushed-branch gate correctly looks for that latter ref and CI receives `undefined`. Build the context from `branch: "feature"` or create the matching remote ref.
  - confidence: 0.99
- **[P3] Remove the unnecessary empty spread fallback:** `src/gateway/control-ui-session-prs.ts:300`
  - body: Oxlint rejects `...(stats ?? {})` under `unicorn/no-useless-fallback-in-spread`, so the changed gateway file does not pass the repository lint gate. Spread `stats` directly or construct the optional fields without the empty fallback.
  - confidence: 0.99
