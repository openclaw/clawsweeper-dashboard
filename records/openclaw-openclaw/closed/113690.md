## What This Changes

This PR updates Control UI history reconciliation so a newly sent repeated user message remains visible when a stale Gateway history response still ends at an earlier identical message.

## System Context

The Control UI keeps an optimistic local chat row while it asks the Gateway for authoritative transcript history. The history reconciler merges those inputs so a refresh neither hides a pending user turn nor leaves a duplicate after the transcript-backed row arrives.
