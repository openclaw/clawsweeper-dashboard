## Summary

This PR remains necessary: current main still applies the same weighted formula to all hybrid candidates, while the linked report describes a reproducible multimodal ranking failure; the scoped patch and supplied runtime proof address that case without changing ordinary text or mixed-signal scoring.

## What This Changes

The branch makes hybrid memory fusion use raw vector relevance for vector-only classified image/audio results and adds regressions preserving keyword-only, mixed-signal, zero-vector-weight, and non-normalized custom-weight behavior.

## Best Possible Solution

Keep the classifier-derived exception limited to vector-only enabled multimodal paths, retain the ordinary weighted formula for every other candidate, and land after the current head's required checks complete.
