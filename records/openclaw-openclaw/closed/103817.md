  - body: `agents.list` IDs are canonicalized with `normalizeAgentId`, but these checks compare raw trimmed strings.   - confidence: 0.96

  - body: Autonomous capture can iterate over multiple grouped proposals, but this recorder refuses every write after the first unconsumed notice. Later proposals are still created or revised silently, leaving the central accumulation problem unresolved. Store a bounded queue or aggregate so every newly pending proposal is represented.
  - confidence: 0.98

  - body: This consumes and durably clears the notice while preparing context, before the agent run or outbound response succeeds. A failed, cancelled, or suppressed turn permanently loses the only operator reminder. Keep it pending until a user-visible turn carrying the notice completes successfully.
  - confidence: 0.95
