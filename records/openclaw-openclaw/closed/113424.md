## Summary

Keep this PR open for maintainer review. Current `main` still has the Claude CLI route probe tied to the packaged default model, while this patch centralizes route lookup and reuses the routed model for both session creation and adoption; the member-authored, `maintainer`-labeled PR is not eligible for automated cleanup.

## What This Changes

This PR changes Anthropic’s Claude CLI session catalog to detect a configured supported Claude model route and use that routed model when advertising or adopting a Claude session.

## System Context

The Anthropic plugin’s session catalog decides whether an agent can create or adopt a local Claude CLI session from OpenClaw configuration. It resolves an agent’s model-to-runtime route, then returns a model/runtime pair that the session UI and adoption flow use to start or resume the session.

## Best Possible Solution

Keep the canonical-default-first behavior, merge the shared routed-model resolution after maintainer review, and ensure every supported Claude CLI model remains represented by the allowlist-derived probe set when model support changes.
