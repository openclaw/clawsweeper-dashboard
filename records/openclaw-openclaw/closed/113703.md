## What This Changes

The PR changes Gateway CLI-session history merging so two messages with different authoritative upstream identities remain distinct even when their role, text, and timestamp match.

## System Context

Gateway imports prior CLI session transcripts and merges them with locally held chat history before exposing the reconstructed conversation to later session and agent flows. The merge code decides whether an imported record is already represented locally or should remain as a separate message.
