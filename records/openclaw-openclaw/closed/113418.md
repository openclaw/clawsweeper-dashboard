## What This Changes

This PR routes core and bundled plugin SQLite opens through one shared factory that preserves SQLite URI and in-memory semantics while normalizing ordinary Windows database paths.

## System Context

OpenClaw's state stores, doctor commands, snapshots, and bundled plugins open SQLite databases for runtime and maintenance work. This refactor moves those opens behind one core-owned factory, exposed to plugins through the public plugin SDK, before SQLite receives the database location.
