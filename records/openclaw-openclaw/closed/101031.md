## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.87

Full review comments:

- **[P2] Preserve close results for benign stdin EPIPE:** `src/agents/sandbox/ssh.ts:713-715`
  - body: This handler kills and rejects on every stdin stream error. Existing process, secret, and policy command runners treat `EPIPE`/`ERR_STREAM_DESTROYED` as benign because children can exit before consuming input; SSH sandbox `runRemoteShellScript` passes caller stdin here, so a successful remote command that closes stdin early can become a pipe failure instead of using the child close result. Please ignore those benign write errors and keep non-benign stdin failures explicit.
  - confidence: 0.88
- **[P2] Do not let upload stdin EPIPE hide ssh stderr:** `src/agents/sandbox/ssh.ts:819`
  - body: `tar.stdout.pipe(ssh.stdin)` can see a benign stdin pipe error when the remote shell exits before reading the full archive, including failure paths where `ssh.stderr` carries the useful reason. Routing every `ssh.stdin` error to `fail()` kills both children and rejects before `maybeResolve()` can report the tar/ssh close status and captured stderr, so handle benign broken-pipe errors without settling early.
  - confidence: 0.84
