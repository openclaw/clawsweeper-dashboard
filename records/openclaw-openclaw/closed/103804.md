## Summary

The report describes a severe, concrete released-version failure, but current source does not support the proposed cause: the launchd writer shell-quotes strings and the SecretRef collectors copy environment values without JSON serialization. Keep this issue open for an urgent placeholder-credential reproduction that identifies whether quotes enter through setup/config parsing, the invoking process environment, or regeneration of an existing service file.

## What This Changes

Fix generated gateway service environment files so provider region and credential variables retain their raw string values without embedded JSON quote characters.

## Best Possible Solution

Reproduce with non-secret placeholder AWS, Gemini, and ElevenLabs values through both fresh macOS installation and regeneration of an affected env file, then fix the single boundary that introduces or preserves JSON encoding and add an in-product doctor/fix recovery for affected installations if migration is required.
