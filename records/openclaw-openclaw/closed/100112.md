## Summary

## What This Changes

The issue requests preserving recoverable full-output pointers when history elision replaces exec results and adding bounded spill-file recovery for truncated web_fetch output.

## Best Possible Solution

Keep this maintainer-protected issue open for a deliberately designed recovery contract that preserves details stripping, gates visible spill pointers by read capability and sandbox state, and adds bounded web_fetch spill recovery only if maintainers accept the lifecycle model.
