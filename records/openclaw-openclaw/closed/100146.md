## Summary

Keep open: this is a useful candidate fix for the open source-reproduced `sessions_yield` silent-park bug, but the patch currently duplicates continuation-evidence logic and can still suppress the diagnostic for invalid delivery evidence.

## What This Changes

The PR adds a fallback diagnostic payload in `src/agents/embedded-agent-runner/run.ts` when `yieldDetected` returns no payloads, plus a mocked orchestration regression test.

## Best Possible Solution

Land a narrow diagnostic guard only after it reuses normalized continuation/delivery evidence and has proof that a no-continuation yielded direct turn produces a visible diagnostic while legitimate yield paths stay unchanged.

## Reproduction Assessment

Yes, at source level: current main lets `yieldDetected` suppress incomplete-turn fallback and return no payload when there is no terminal payload. The PR’s own mocked test demonstrates the intended diagnostic path, and the remaining defect is visible from the new raw evidence checks versus existing normalized helpers.

## Solution Assessment

No, not yet. The terminal-path diagnostic is a plausible interim fix, but the current implementation bypasses existing delivery/spawn evidence helpers and needs real behavior proof before it is the best mergeable solution.
