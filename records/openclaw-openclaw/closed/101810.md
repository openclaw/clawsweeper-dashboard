## Summary

Keep open: current main still runs Android link-preview metadata and image fetches through blocking OkHttp `Call.execute()` work on `Dispatchers.IO` without a cancellation hook, and no duplicate or merged fix was found.

## What This Changes

Reported Android LinkPreviewFetcher cancellation bug where synchronous OkHttp calls launched on `Dispatchers.IO` can keep blocking after the link-preview coroutine is cancelled.

## Best Possible Solution

Make the Android link-preview fetch path cancellation-aware by cancelling the active OkHttp `Call` for both metadata and image fetches, with a focused MockWebServer regression that cancels an in-flight fetch.
