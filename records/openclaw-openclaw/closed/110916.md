## Summary

Keep this PR open for maintainer review: the durable-ingress design is useful, but the new production state dependency appears unavailable to the documented local/path installation mode, which can prevent all inbound Zalo Personal processing.

## What This Changes

The branch persists accepted raw Zalo Personal socket callbacks in a durable ingress queue, replays pending work after restart, and documents the resulting crash-window durability boundary.

## Best Possible Solution

Keep the durable queue, but route its persistence through a deliberately supported plugin-scoped storage contract that works for documented local/path installs, with an integration test covering that install trust mode.
