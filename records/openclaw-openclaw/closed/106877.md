## Summary

Current `main` still exposes a hand-built plugin API range evaluator whose focused tests cover only a subset of semver range grammar. The report remains necessary because ClawHub install compatibility can reject valid tilde or partial-wildcard ranges and mishandle prerelease caret ceilings; the protected `maintainer` label requires explicit maintainer handling.

## What This Changes

Correct ClawHub plugin API compatibility checks so standard tilde, partial-wildcard, caret, and prerelease semantics work while preserving OpenClaw correction-version normalization and legacy bare `major.minor` behavior.

## Best Possible Solution

Normalize OpenClaw correction versions and legacy bare `major.minor` inputs at the boundary, use the pinned semver engine for supported comparator tokens, continue explicitly rejecting unsupported union and hyphen-range grammar, and add focused regressions for tilde, partial wildcards, caret ceilings, and prerelease hosts.
