## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P2] Exclude reply templates from native i18n:** `apps/android/app/src/main/java/ai/openclaw/app/ui/chat/ChatMessageActions.kt:44`
  - body: `quoteChatMessage` returns the structural template `$quoted\n\n`, and the Android string-function extractor treats helper names ending in `Message` as translatable, so this PR already commits that template into `apps/.i18n/native-source.json`. Locale refresh can preserve the `$quoted` placeholder and line breaks while still changing surrounding punctuation or text, which would corrupt quoted reply drafts. Build the suffix without a translatable string literal or filter this helper/template out of the native inventory.
  - confidence: 0.91
- **[P2] Keep structural marker arguments out of i18n:** `scripts/native-app-i18n.ts:89`
  - body: The generalized named-literal matcher now captures any composable argument whose name ends in `text`, which adds `markerText = "$index."` from `ChatMarkdown.kt` to the native source inventory. The locale guard preserves the `$index` interpolation but not the marker punctuation, so a later native locale refresh can alter ordered-list formatting and break Markdown list numbering. Narrow the matcher or explicitly filter helper/layout arguments like `markerText`.
  - confidence: 0.9
