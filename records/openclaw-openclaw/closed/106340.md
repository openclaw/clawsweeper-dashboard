## Summary

This is a well-supported current Control UI bug: rejected custom-group creation can fail without visible feedback, and no merged fix or canonical replacement owns it. The protected `maintainer` label also requires explicit maintainer handling rather than automatic cleanup.

## What This Changes

Make rejected custom-session-group creation display the Gateway validation error instead of producing an unhandled promise rejection and silent failure.

## Best Possible Solution

Centralize group-mutation rejection normalization in the shared Sessions capability, publish the actionable error through the existing Sessions error state, retain the page's connection-generation guard, and add focused coverage for both the dedicated Sessions page and sibling sidebar callers.
