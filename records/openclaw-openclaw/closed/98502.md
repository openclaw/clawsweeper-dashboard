## Best Possible Solution

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: a large OpenAI token endpoint error is drained by `postTokenForm` with `response.arrayBuffer()` before the PR's bounded reader can execute.

## Solution Assessment

No. `readResponseTextLimited` is the right primitive for direct streamed responses, but the OpenAI OAuth fix needs to apply it before or inside the token fetch helper rather than after the helper has copied the full body.
