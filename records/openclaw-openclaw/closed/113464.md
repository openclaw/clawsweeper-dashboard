## What This Changes

This PR maps selected Control UI computed CSS custom properties to standardized MCP Apps `hostContext.styles.variables` and republishes them when the host theme changes.

## System Context

Control UI mounts embedded MCP apps inside a sandbox and sends them host context such as the active theme and container dimensions. This change adds resolved host design values to that context so apps can style their own UI consistently with the enclosing OpenClaw surface and update when the host theme changes.
