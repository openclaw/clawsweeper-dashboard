## What This Changes

The branch maps selected Control UI CSS custom properties to standardized MCP Apps style variables and sends them with each embedded app host-context update.

## System Context

Control UI renders MCP Apps in a sandboxed embedded surface and supplies host context so the app can adapt to the host environment. This change derives selected theme tokens from the host document and passes them through the existing host-context path to the embedded app.
