## Summary

This remains a valid current-main CLI bug: both the packaged launcher and source-checkout compile-cache wrapper convert a signaled child exit to status 1. The `maintainer` label also requires explicit human handling rather than automated cleanup.

## What This Changes

Preserve forwarded SIGINT and SIGTERM through CLI respawn wrappers as exit 130 and 143 instead of reporting generic failure status 1.

## Best Possible Solution

Use one explicit signal-to-exit-status contract across every respawn wrapper, add focused POSIX coverage for SIGINT and SIGTERM plus hard-failure cases, and preserve existing timeout/kill behavior.
