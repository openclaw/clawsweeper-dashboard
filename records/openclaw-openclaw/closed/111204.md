## Summary

Keep this PR open: persisting bare media-only transcript text is the right user-facing direction, but the new marker injection only covers normal LLM dispatch and leaves compaction and branch-summary inputs able to discard media-only turns.

## What This Changes

Moves the media-only caption placeholder out of persisted transcript content and injects it at the normal LLM boundary so clients render bare media while providers retain the marker.

## Best Possible Solution

Keep transcript storage bare, but centralize media-only normalization so provider dispatch, compaction, and branch summarization all preserve the same model-facing marker, with regression coverage for each serialization boundary.
