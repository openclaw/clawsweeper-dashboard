## Summary

## What This Changes

## Reproduction Assessment

Yes, from source with high confidence: a persistence exception returns before current main records the cooldown timestamp, so the next timer tick can attempt the same store again. No real current-main runtime reproduction artifact was supplied.

## Solution Assessment

Yes. Recording the attempt immediately after the throttle check is narrower and more robust than recording completion in a finally block because it fixes error retries while also preventing overlapping slow attempts, without changing the existing disabled-retention outcome.
