## Summary

Current `main` still has the reported lifecycle bug: the launched process may exit while `ShellExecutor` remains blocked awaiting pipe EOF from descendants. Keep this issue open because https://github.com/openclaw/openclaw/pull/104827 is the direct unmerged fix candidate, and the protected `maintainer` label requires explicit maintainer handling.

## What This Changes

Make macOS shell execution complete when its launched process exits even if descendants retain inherited output handles, so onboarding cannot spin indefinitely.

## Best Possible Solution

Land one canonical executor lifecycle fix that completes on root-process exit, captures available output, preserves deterministic timeout classification, removes temporary capture artifacts, and restores onboarding’s existing error/retry path.
