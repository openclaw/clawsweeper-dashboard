## What This Changes

The branch prevents ordinary in-place OpenClaw session resets from permanently retiring the reused Codex session generation, while retaining retirement for deleted sessions.

## System Context

The agent runner owns logical OpenClaw chat sessions and tells registered harnesses when a session resets or is deleted. The Codex extension stores the corresponding Codex thread binding and uses that lifecycle signal to decide whether the next turn may create a replacement thread.
