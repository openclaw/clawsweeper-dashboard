## Summary

The patch does not yet provide a gateway-wide pause: ordinary channel messages can still start embedded runs, and each engage surface aborts only one of the two active-run registries. The new durable remote safety control also needs explicit product and security approval, plus live behavior proof.

## What This Changes

Adds a persisted gateway-wide operator killswitch with CLI and owner-only Signal triggers, agent/cron enforcement, in-flight abort handling, shared-state schema, tests, and documentation.

## Best Possible Solution

Extend the canonical gateway admission/suspension owner with a durable emergency-paused state, then route every trigger through one operation that rejects all root work and aborts all tracked run families with explicit storage-failure semantics.
