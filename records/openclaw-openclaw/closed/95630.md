## Summary

Keep open: current main and v2026.6.11 bound silent model streams, but provider progress heartbeats still reset that watchdog without requiring durable tool or text progress, leaving the central request unresolved. The requested default, progress definition, provider scope, and cancellation semantics require maintainer direction.

## What This Changes

Add a configurable wall-clock bound for channel turns that emit progress but never reach durable tool or text settlement, with clean cancellation and no restart-recovery marking.

## Best Possible Solution

Add a central durable-progress deadline in the embedded run lifecycle, reset only by defined user-visible or durable tool progress, and reuse canonical terminal-outcome cleanup; expose it only after maintainers choose provider scope and default.
