## Summary

Keep this PR open for maintainer review. The startup-stall proof is strong, but the new unconditional static Gateway mode appears to remove an existing live-catalog path for providers that do not expose a static catalog; the protected `maintainer` label also requires explicit human handling.

## What This Changes

The PR makes Gateway prepared model-runtime startup and reload publication use configured/static provider facts rather than synchronous live provider catalog discovery.

## Best Possible Solution

Publish the static ready-state synchronously, then retain compatible live-catalog augmentation off the readiness-critical path with an atomic refresh, or explicitly approve and document a supported static-only migration for live-only providers.
