## Summary

Keep open: current main confirms that proactive state notices are limited to spawn-lineage watchers, while authorized peer coordination through `sessions_send` has no watch-registration path. The proposed extension is technically bounded, but the protected label and new model-facing coordination semantics require explicit maintainer product approval.

## What This Changes

Add an opt-in `sessions_send` watch that notifies authorized coordinators of later human or goal-state changes in non-spawned target sessions.

## Best Possible Solution

Implement a narrow opt-in peer watch in the existing session-state owner: authorize first, preserve cursor watermarks on re-registration, union registered target watchers for material events, and retain polling as the default behavior.
