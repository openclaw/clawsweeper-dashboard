## What This Changes

The PR updates `createThreadDiscord` so route-less Discord forum/media thread creation tries to copy the parent channel's `default_auto_archive_duration` into `auto_archive_duration` when no explicit archive window is set.

## Best Possible Solution

Fix the forum-parent `sendMessageDiscord` branch in `extensions/discord/src/send.outbound.ts` so it carries the fetched forum/media channel default into the create-thread body, with a shared helper only if it reduces drift with `createThreadDiscord`.
