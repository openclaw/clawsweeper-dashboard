## What This Changes

The PR delays clearing a pending tool-call identifier until a plugin’s message-write hook accepts the real tool result, so the existing repair path can synthesize a paired result before the next user message.

## System Context

The session transcript guard records assistant tool calls and their tool results before later provider turns consume the persisted conversation. Plugin message-write hooks can reject individual messages, so the guard must keep enough pending state to repair an otherwise unpaired tool call.
