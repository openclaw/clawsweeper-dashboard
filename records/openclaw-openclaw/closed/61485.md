- **[P1] Bound awaited LLM hooks with default timeouts:** `src/agents/embedded-agent-runner/run/attempt.ts:4115`
  - body: This changes `llm_input` from a background observation hook into an awaited hook, but the modifying-hook default timeout map does not include `llm_input` or `llm_output`. A plugin that already registered an observer and never resolves can now stall the agent turn instead of being logged in the background.
  - confidence: 0.93
- **[P1] Apply prompt rewrites before image and budget checks:** `src/agents/embedded-agent-runner/run/attempt.ts:4146`
  - body: The PR assigns the returned prompt after the current path has already loaded prompt-local images and run context-budget prechecks. A plugin rewrite can add/remove image refs or expand the prompt without re-detection or overflow handling, so the model call uses stale safety decisions.
  - confidence: 0.91
- **[P1] Apply systemPrompt overrides to the model call:** `src/agents/embedded-agent-runner/run/attempt.ts:4149`
  - body: This assignment only changes the local `systemPromptForHook` value used for hook/trajectory payloads; the active session system prompt and Google prompt-cache wrapper were already prepared from `systemPromptText`. Plugins returning `systemPrompt` therefore do not reliably change the actual model request.
  - confidence: 0.88
- **[P1] Redact transcript state before downstream hooks:** `src/agents/embedded-agent-runner/run/attempt.ts:4950`
  - body: The output override is captured after `messagesSnapshot` and `agent_end` side effects are built from the original assistant message. That means a redaction plugin can change returned `assistantTexts` while the original response remains visible in transcript state and downstream hooks.
  - confidence: 0.9
- **[P2] Track plugin-suppressed output before live-model restart:** `src/agents/embedded-agent-runner/run/attempt.ts:5142`
  - body: An `llm_output` hook can now intentionally return an empty `assistantTexts` array, but the run loop still treats an attempt with zero assistant texts as safe for live-model restart. That can rerun a turn that the plugin deliberately suppressed.
  - confidence: 0.82
