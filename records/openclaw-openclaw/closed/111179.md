## Summary

Keep this PR open: it establishes useful identity plumbing, but two current data-semantics defects can misattribute presence or publish arbitrary identifiers as email addresses; the protected maintainer label also calls for maintainer handling of the public identity contract.

## What This Changes

The branch adds optional authenticated-user identity to gateway connection state and presence snapshots, updates Swift protocol bindings, and adds connect/disconnect audit logging and focused tests.

## Best Possible Solution

Make `user` a replacement value on every presence update so an unauthenticated reconnect clears it, publish only the opaque `id` until an email-guaranteeing identity contract exists, and add redacted live gateway proof for identified and userless reconnects.
