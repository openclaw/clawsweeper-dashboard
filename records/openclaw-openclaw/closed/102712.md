## Summary

Keep open. This PR targets a real Slack room-history bug, but the patch currently wires open-channel rooms into a finalizer that clears after dispatch rather than after confirmed visible Slack delivery, and the contributor proof is test-only.

## What This Changes

The PR widens Slack room-history finalizer metadata from mention-required rooms to all roomish Slack turns with history enabled and adds a prepare-stage regression test.

## Best Possible Solution

Clear Slack open-channel room history only after confirmed visible reply delivery, with coverage for both visible-reply and silent/no-visible-reply turns plus redacted Slack runtime proof; otherwise deliberately keep rolling behavior and update wording/docs.
