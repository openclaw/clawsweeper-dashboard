## Summary

Keep open for explicit product and security direction: current main has useful prerequisites, but this remains a new cross-boundary capability, and the protected `maintainer` label requires human handling.

## What This Changes

Add capability-gated agent commands for controlling the Control UI layout and for opening, reading, writing, resizing, sharing, and closing embedded terminal sessions.

## Best Possible Solution

Land an additive, session-targeted Phase A only after command targeting and opt-out semantics are approved, and track Phase B separately with an explicit agent-owned PTY security model, approval policy, lifecycle cleanup, co-attach isolation, protocol tests, Control UI tests, and user documentation.
