## Summary

Keep open. Current main still delivers Feishu streamed replies as interactive cards without a search-indexable final message, the direct fallback PR closed unmerged, and the overlapping auto-rendering report would reduce exposure but would not solve searchability for explicitly requested cards.

## What This Changes

Make completed Feishu streaming-card replies discoverable through Feishu conversation search without unsafe duplicate delivery.

## Best Possible Solution

Restore searchable plain bubbles for auto-mode prose, retain explicit card mode, and address explicit-card searchability only through a live-proven native mechanism or clear limitation documentation rather than an unconditional duplicate fallback.
