## Summary

Keep this PR open for maintainer review: it has direct Control UI proof and focused coverage, but the current scope-change path appears to carry a prior gateway’s dismissal state into the next gateway identity, suppressing all health nudges until remount.

## What This Changes

The branch adds a dismissible, severity-ranked health-event nudge to the Control UI custodian page and submits its diagnosis prompt through the existing `openclaw.chat` flow.

## Best Possible Solution

Reset the per-visit dismissal state together with the pending nudge whenever gateway identity changes, then cover a dismiss → gateway-switch → qualifying-health-event sequence in the custodian-page tests.
