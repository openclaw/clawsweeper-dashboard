## What This Changes

This PR lets SQLite snapshot creation recover a copied rollback-journal database after a killed writer prevents the normal read-only open, while preserving the original database files.

## System Context

OpenClaw’s SQLite snapshot layer supports backup and restore operations for persisted state. It normally opens the live source read-only and performs an online SQLite backup; this change adds a private copied-recovery route only when a hot rollback journal blocks that normal path.
