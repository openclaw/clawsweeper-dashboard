## Summary

Keep open for explicit maintainer design sponsorship. This is a large, compatibility-sensitive phase of the open ChannelAdapter v2 program rather than an already-implemented or safely autonomous fix, and the protected `maintainer` label requires human handling.

## What This Changes

Create a core-owned durable channel-ingress worker and adoption lifecycle, then migrate Telegram and WhatsApp away from channel-local drain, fence, liveness, retry, and watchdog implementations.

## Best Possible Solution

Define one core-owned durable ingress lifecycle with explicit invariants and contract tests, then stage Telegram and WhatsApp migrations through shippable pilots with current Plugin SDK compatibility, restart replay, adoption-race, and live channel proof.
