## What This Changes

This PR changes the QA Lab transport registry so overlapping before- and after-gateway cleanup calls share one in-flight operation, expose the same failure to all callers, and allow a later retry after failure.

## System Context

QA Lab creates transport adapters for scenario and live-channel runs. Their cleanup hooks stop channel drivers and release credential leases during gateway teardown, so concurrent lifecycle callers must observe one ordered cleanup result before the surrounding scenario can finish.
