## Summary

Keep open: current main still contains the reported macOS authorization mismatch, the issue supplies credible live evidence, and no related pull request currently owns the repair. The protected `maintainer` label also requires explicit maintainer handling.

## What This Changes

Make agent node execution use a bindable non-login shell transport on macOS while retaining existing Linux and other POSIX behavior.

## Best Possible Solution

Emit static `/bin/sh -c` only for Darwin at the existing node-shell constructor, retain `/bin/sh -lc` for Linux and unknown POSIX platforms, cover both agent construction and native bound-command execution, and prove an exact allowlisted executable succeeds on a real current Mac App node.
