## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Keep reply leases on the canonical session key:** `src/infra/runtime-activity-emitter.ts:111`
  - body: `policyKey` is the delivery-target policy session, not the control session that produced the reply; current outbound lifecycle deliberately avoids using it for correlation. Falling back to it here can mark the wrong Command Center session active for redirected replies, so emit only from the canonical key or reuse the same lifecycle-key semantics as message hooks.
  - confidence: 0.9
- **[P2] Make activity session IDs collision-safe:** `src/infra/runtime-activity-emitter.ts:30`
  - body: Truncating the sanitized key to 96 characters drops the suffix that often distinguishes long channel/thread session keys. Two sessions with the same prefix would post the same `sessionId` and collapse Live Activity, so preserve the full key if the endpoint allows it or append a stable hash suffix before truncating.
  - confidence: 0.84
