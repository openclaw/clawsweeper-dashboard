## Summary

Keep open. This is a newly filed, maintainer-labeled coordination issue for a broad optional shared-gateway identity program; it explicitly requires product, protocol, persistence, and trust-boundary decisions before implementation can safely begin.

## What This Changes

Add optional trusted-user identity threading, durable profiles, viewing presence, and prompt attribution for shared gateways authenticated through trusted proxies.

## Best Possible Solution

First approve a narrow identity contract for trusted-proxy gateways—connection-scoped opaque identity, minimal additive protocol fields, and explicit privacy defaults—then split implementation into owner-reviewed stages for protocol/presence, durable profiles, and UI attribution.
