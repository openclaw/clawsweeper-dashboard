## Summary

Current main still deterministically stages the full deep-profile bundle, including archives over GitHub’s 100 MB file limit. No open fix or duplicate owns the defect, and the protected maintainer label requires explicit maintainer handling.

## What This Changes

Change the deep-profile report publisher to retain raw diagnostics as Actions artifacts while committing only lightweight report outputs to clawgrit-reports.

## Best Possible Solution

Keep raw profile archives exclusively in bounded-retention Actions artifacts, publish report JSON/Markdown, index, bundle metadata, and checksums only, and reject any unexpectedly oversized staged file before commit or push.
