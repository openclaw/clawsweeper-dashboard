## What This Changes

This PR keeps the Threads sidebar header available when all visible thread rows are in custom categories, so users retain sort, filtering, flattening, and new-thread controls.

## System Context

The Control UI sidebar renders session sections from gateway-backed thread data. The ungrouped Threads section owns global navigation actions, while categorized sections own their visible rows; this change keeps that global control surface reachable when the ungrouped section has no rows.
