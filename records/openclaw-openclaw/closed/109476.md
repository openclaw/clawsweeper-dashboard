## Summary

Current main still performs an unbounded synchronous Git probe, while this PR narrowly bounds that probe and preserves the existing filesystem fallback; no actionable correctness defect was found.

## What This Changes

The PR gives Canvas A2UI tracked-input discovery a one-second forced timeout and adds a process-level regression test covering stalled Git fallback.

## Best Possible Solution

Keep the native spawnSync deadline at the plugin-owned Git probe, preserve the existing fallback, and retain the real-process regression test without adding configuration or another process-management abstraction.
