## Summary

Keep open. The report is valid: current main and the latest release both use markdown-link URL regexes that exclude `)`, the TUI wrapper relies on this extraction for OSC8 link targets, and a lightweight Node reproduction captures the example URL without its closing parenthesis.

## What This Changes

Fix TUI OSC8 markdown URL extraction so markdown link targets containing balanced closing parentheses remain clickable instead of being truncated.

## Best Possible Solution

Update the TUI OSC8 URL extractor with a small parser or tightly scoped balanced-parentheses matcher, plus regression tests for parenthesized markdown hrefs and unchanged bare-URL behavior.
