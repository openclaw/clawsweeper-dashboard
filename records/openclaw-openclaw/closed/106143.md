## Summary

Keep this PR open: the useful locale fix remains necessary, but the current head still has the previously reported failure-classification blocker and provides only mocked rather than real-container behavior proof.

## What This Changes

The PR replaces English `stat` stderr matching with a reserved stdout marker and adds mocked coverage for missing paths, dangling symlinks, and non-missing failures.

## Best Possible Solution

Make the sandbox command distinguish a genuine missing basename from every other `stat` failure—preferably by stabilizing GNU `stat` with `LC_ALL=C` or using an available structured errno source—while preserving the original failure diagnostics, then prove all three outcomes in a real localized container.
