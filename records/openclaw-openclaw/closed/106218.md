## Summary

Keep open for explicit maintainer handling. The report has a credible current-main race, while current documentation now promises ordered picker patches only for web chat; the broader macOS, iOS, and Android invariant and the exact implementing provenance remain unverified.

## What This Changes

Ensure model selection completes before validating and applying a model-specific reasoning level, and prevent immediate message submission from observing partially applied settings.

## Best Possible Solution

Use one client-owned serialized session-settings queue across model, thinking, reasoning, and speed changes; validate thinking against the model returned by the completed model patch, and block send until that queue settles, with focused race coverage for web and each native client.
