The issue requests that the macOS GUI LaunchAgent auth fallback read Node-generated launchd service-env wrapper files and merge their token/password env over inline plist env.

## Best Possible Solution

Implement env-wrapper parsing in the macOS LaunchAgent snapshot path and keep `GatewayEndpointStore` consuming that canonical snapshot, with focused Swift regression coverage and macOS launchd proof.

I did not run a live macOS launchd GUI setup, so this is source-reproducible rather than live reproduced.

## Solution Assessment

Yes, the best fix is to align the macOS snapshot parser with the existing Node launchd reader and add Swift regression tests for snapshot parsing and local auth fallback. No new config surface or product decision is needed.
