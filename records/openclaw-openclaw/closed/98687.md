## What This Changes

The PR makes `openclaw memory promote` omit `dreaming.maxAgeDays` for one explicit non-apply threshold combination and adds a regression test for old recall rows.

## Best Possible Solution

Merge after documenting the exact relaxed inspection command while preserving `maxAgeDays` for scheduled dreaming, default review, and `--apply`.

## Reproduction Assessment

Yes, from source: current main always passes `dreaming.maxAgeDays` into preview ranking, so an old short-term recall remains filtered even when the visible threshold flags are relaxed. I did not execute the CLI in this read-only review.

## Solution Assessment

Mostly yes: placing the relaxation only in non-apply CLI ranking avoids new config and keeps write paths conservative. The safer finishing step is to document the exact command shape so operators do not change deep config to inspect old rows.
