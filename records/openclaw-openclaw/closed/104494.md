The contributor must correct that boundary and add real installed-runtime proof; maintainers should also choose one canonical API between this branch and the competing fix.

## What This Changes

Adds a manager/monitor recovery-ownership contract that skips health-monitor restart/reset during active crash-loop backoff or give-up, preserves stop-timeout recovery, and adds focused gateway lifecycle tests.

## Best Possible Solution
