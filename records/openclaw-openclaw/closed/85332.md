Keep open: current main and the latest release still only support extra APT packages during image builds, while the requested pulled-image or production-safe prebuild path remains a product and security decision.

## What This Changes

Request an opt-in Docker image mode or bootstrap path for installing deployer-selected APT packages while keeping the official image slim.

## Best Possible Solution

Define an explicit derived-image prebuild and restart workflow, with docs, tests, package-trust guidance, and a clear decision on whether startup-time APT is only a dev fallback.
