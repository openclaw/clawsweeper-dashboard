## Summary

The report identifies a real current-main gap in the shipped Mistral normalization repair: the shared helper bypasses its per-model safe cap whenever an explicit value is below the context window, so both config loading and doctor repair preserve 17,000 instead of 16,384. No duplicate or open fix PR was found, and the issue is a narrow repair candidate.

## What This Changes

Clamp explicit Mistral maxTokens values to the existing per-model safe limit even when they are below the model context window.

## Best Possible Solution

Make the shared helper clamp Mistral maxTokens to the minimum of the configured value, context window, and existing model-safe limit, with regressions for both config loading and doctor repair.
