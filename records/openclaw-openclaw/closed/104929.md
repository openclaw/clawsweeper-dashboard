## Summary

The branch is a technically strong, proof-positive fix for escaped ACPX descendants, and current main still lacks its survivor verification and containment-failure handling. Keep it open for an explicit lifecycle-policy decision because the patch couples upstream `cancel` and `close` across every shared cancellation caller and makes unresolved stale containment disable ACPX registration.

## What This Changes

The PR adds lease- and Gateway-scoped discovery and verified termination of detached ACPX descendants, closes cached runtime handles during cancellation, blocks ACPX registration when stale leases cannot be drained, and reports containment failures instead of normal abort success.

## Best Possible Solution

Keep cooperative `cancel` reusable, add an explicit terminate-and-drain operation for abort, reset, and task teardown, move reusable process-containment mechanics upstream to ACPX where feasible, and provide a visible Doctor/Fix or quarantine recovery path before stale containment can disable ACPX registration.
