## Summary

Keep open: current main and the latest release still do not provide the requested default-off session-key metadata forwarding on MCP tools/call, and the related caller-context PR deliberately excludes session keys rather than owning this exact request. The item should stay as a product/security decision, not an autonomous fix lane.

## What This Changes

Request an optional, default-off MCP server setting that forwards the current session key in tools/call params._meta.

## Best Possible Solution

Decide the session-identity disclosure contract first, then either implement a narrow default-off per-server MCP option with schema/docs/tests or fold it into the broader caller-context design.
