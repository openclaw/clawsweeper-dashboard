## Summary

The patch is focused, proof-positive, and has no concrete correctness or security blocker, but it intentionally turns a formerly successful raw-text read into an error and therefore needs explicit maintainer acceptance of the upgrade behavior before merge.

## What This Changes

The PR routes Markdown and CSV workspace file bindings through the existing pointer helper and adds regression coverage for omitted, root, malformed, and unresolved pointers.

## Best Possible Solution

Adopt the shared pointer contract for every supported file type, preserve omitted and root raw-text reads, reject malformed or unresolved raw-text pointers consistently, and record the intentional compatibility correction in merge or release-note context.
