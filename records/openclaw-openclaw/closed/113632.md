## What This Changes

This PR renders locked automation `script` and `command` payloads as resizable, syntax-highlighted read-only code blocks in Control UI while leaving editable payload types as textareas.

## System Context

Control UI builds an automation editor from cron-job form state. Locked source-bearing payloads are displayed to users, while heartbeat, system-event, and agent-turn payloads remain editable controls that feed normal validation and payload construction.
