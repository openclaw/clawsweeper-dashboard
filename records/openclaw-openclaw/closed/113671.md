## What This Changes

This PR changes Chat’s Background tasks rail so selecting a subagent opens a compact in-rail detail view, preserving the main chat conversation and providing Back navigation to the grouped task list.

## System Context

The Control UI receives task summaries and detail lookups from the Gateway and renders them in each chat pane’s Background tasks rail. The rail must show live task state, cancellation, and bounded task details without changing the chat pane’s active conversation.
