## Summary

## What This Changes

The PR replaces the Tool Search code-mode child serializer’s JSON round-trip with `structuredClone`.

## Best Possible Solution

Keep the Tool Search bridge payload contract JSON-safe across the VM context, child-process IPC, parent bridge handling, and transcript projection, with focused code-mode bridge coverage.

## Reproduction Assessment

Yes. A read-only Node v24.18.0 VM probe reproduces the PR-introduced failure: `structuredClone` is unavailable in the sandbox and the patched helper returns `"[object Array]"` instead of array bridge args.

## Solution Assessment

No. Replacing the JSON-safe bridge serializer with `structuredClone` is the wrong layer because the data must survive the VM realm, child-process IPC, JSON parsing, and transcript projection.
