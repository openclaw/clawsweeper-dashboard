## What This Changes

The PR changes the bundled LanceDB memory plugin to atomically create a schema-defined `memories` table, retry brief readiness races, and add a six-process initialization regression test.

## System Context

The LanceDB memory plugin opens a vector-memory table when a gateway or worker needs memory storage. Its initialization path must leave a schema-readable table so later memory reads and writes can proceed even when several OpenClaw processes start together.
