## What This Changes

The branch passes the agent’s prepared reasoning level and provider-aware stream function through the safeguard compaction hook so summaries use the same provider route as normal agent turns.

## System Context

Safeguard compaction summarizes older agent-session turns before the next model call, preserving a usable compacted transcript. The summary call must retain the prepared provider execution context so provider routing and reasoning configuration are not lost at the extension boundary.
