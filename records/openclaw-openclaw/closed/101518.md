- **[P2] Preserve missing prompt usage instead of synthesizing zero:** `extensions/diagnostics-otel/src/service.ts:2706`
  - body: This line now exports `gen_ai.usage.input_tokens` for any finite `genAiInputTokens`, but that value is still computed as `(usage.input ?? 0) + (usage.cacheRead ?? 0) + (usage.cacheWrite ?? 0)` when `promptTokens` is absent.
