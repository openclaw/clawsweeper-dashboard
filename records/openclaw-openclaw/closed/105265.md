Full review comments:

- **[P2] Use form-capable semantics for the Where popover:** `ui/src/pages/new-session/new-session-page.ts:807-810`
  - body: The popup is still exposed as `role="menu"` even though it contains editable base-branch and worktree-name inputs. ARIA menus are for menu-item descendants, so assistive technology can switch into menu navigation and make these form fields unreliable; use dialog or popover semantics for the mixed-content panel, or move the fields outside the menu role.
  - confidence: 0.97
- **[P2] Restore folder-trigger focus after applying a folder:** `ui/src/pages/new-session/new-session-page.ts:696-701`
  - body: `Use this folder` closes the browser through `closeBrowser()`, which hides the focused button without returning focus to the summary. This leaves keyboard users focused on collapsed content or at a browser-dependent fallback; mirror `closeMenuFrom()` and focus the folder trigger when applying the path.
  - confidence: 0.96
