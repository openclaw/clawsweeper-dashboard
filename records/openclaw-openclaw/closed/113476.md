## What This Changes

Adds web and macOS onboarding actions that let an administrator start Ollama or llama.cpp local-model preparation through the existing Gateway wizard and see its streamed progress.

## System Context

Gateway setup detection supplies provider choices and advertised methods to the web model-setup page and macOS onboarding. These clients start the existing preparation wizard, render progress updates, then refresh detection without claiming that a downloaded model became the selected default.
