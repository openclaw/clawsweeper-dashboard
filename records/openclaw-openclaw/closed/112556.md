## What This Changes

The branch makes the release-metadata guard terminate stalled `git diff` and `git show` lookups after a bounded timeout, report the exact timed-out operation, and regression-test a hanging fake git executable.

## System Context

The release-metadata guard is a repository script that asks Git for changed paths and commit metadata before allowing metadata-only release changes. Its Git results feed a pass/fail CI decision, so a stalled subprocess currently prevents the gate from producing a usable outcome.
