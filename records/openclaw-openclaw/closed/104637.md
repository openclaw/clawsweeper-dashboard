## What This Changes

The PR replaces KeepAlive-only launchd full-process restarts with a PID-aware detached handoff that preserves healthy replacements, actively restarts inert jobs, and falls back in process when helper spawning fails.

## Best Possible Solution

Keep one launchd-owned restart path with three explicit outcomes: yield to a healthy replacement, actively kickstart an inert job, and resume in process when the detached helper cannot start.
