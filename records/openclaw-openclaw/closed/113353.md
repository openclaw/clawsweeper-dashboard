## What This Changes

Add an explicit experimental browser Talk mode that brokers WebRTC through Codex OAuth instead of requiring a separate OpenAI Platform API key.

## System Context

Control UI Talk asks the Gateway to create a browser WebRTC session, then the browser exchanges SDP with the realtime provider. The proposed mode would route that setup through the bundled Codex app-server while keeping the OAuth credential on the server and writing completed speech back to the active OpenClaw session.
