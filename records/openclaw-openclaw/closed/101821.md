## Summary

Keep open: current main has plugin-tab and `chat.send` surfaces, but no dashboard workspace/action-form widget, and the requested prompt-dispatch UI is a new security-sensitive product surface rather than conservative cleanup.

## What This Changes

## Best Possible Solution

Keep this as a roadmap item until maintainers accept the dashboard substrate and dispatch security contract; if accepted, implement it as a first-party dashboard plugin builtin that reuses `chat.send` authorization, explicit confirmation, rate limits, and schema-validated field interpolation with adversarial tests.
