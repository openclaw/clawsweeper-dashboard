## What This Changes

The PR scopes the existing memory-search deadline so the configured QMD timeout applies only to active QMD or mcporter search commands, while setup, fallback, supplements, filtering, cancellation, and cleanup remain separately bounded.

## Best Possible Solution

Land the phase-owned timeout implementation after resolving the exact-head architecture check: apply `memory.qmd.limits.timeoutMs` only to actual QMD commands, keep every surrounding phase bounded, preserve caller cancellation, and give builtin fallback a fresh default budget.
