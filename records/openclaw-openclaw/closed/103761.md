## Summary

The current head is not merge-ready: the latest lock predicate conflicts with LINE’s existing effective `requireMention` default, leaving the first pending-media write and a concurrent mentioned turn unsynchronized. The submitted live run also stops before a successful real media retention and flush, and current `main` now produces generated-file conflicts.

## What This Changes

Adds two opt-in LINE group settings that gate non-text messages and retain a bounded process-local media queue for attachment to a later mentioned turn, with tests, generated config metadata, and documentation.

## Best Possible Solution

Align queue synchronization with LINE’s effective mention default, then land the bounded best-effort retention design only after maintainers approve that lifecycle and a real LINE-hosted media item is successfully retained and flushed on the reviewed head.
