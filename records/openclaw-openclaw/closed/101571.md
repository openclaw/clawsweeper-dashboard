## Summary

Keep open: this is the right Gateway surface and the PR has useful tests/proof, but it is not merge-ready because the new stream error listeners are registered only after awaited auth and transcript-history reads, leaving the same unhandled-error crash window during early disconnects.

## What This Changes

The PR updates the Gateway session-history SSE handler to attach request/response stream error listeners and extends session-history HTTP tests for cleanup on stream errors and early close.

## Best Possible Solution

Install session-history SSE stream error ownership before the first awaited request-specific operation for streaming requests, preserve the local cleanup/end behavior, and land one canonical fix for the linked issue.
