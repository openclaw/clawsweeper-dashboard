## Summary

The reported missing relay cache-affinity mechanism is already implemented and shipped: compatible third-party Completions models can opt into a stable `prompt_cache_key`, while unsupported proxy payloads remain unchanged.

## What This Changes

Ensure GPT requests through third-party OpenAI-compatible relays carry a stable prompt-cache affinity key so repeated prompt prefixes can be reused.

## Best Possible Solution

Keep the shipped capability-gated behavior: users of relays that accept OpenAI cache affinity should set `compat.supportsPromptCacheKey: true` on the custom model and run a current release, while incompatible endpoints remain opted out.
