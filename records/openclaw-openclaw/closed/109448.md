## Summary

Keep open: the bounded probe is directionally useful, but the new timeout currently enters a fallback that can misclassify an unknown filesystem as local, so the patch is not safe to merge as written.

## What This Changes

Adds a five-second timeout to the synchronous mount-table probe used by SQLite WAL maintenance and asserts the new child-process options in the focused test.

## Best Possible Solution

Represent mount discovery failure as an explicit unknown result, keep SQLite in conservative DELETE mode whenever the filesystem cannot be classified, and prove the chosen probe mechanism against a controlled stalled command without overstating kernel-level deadline guarantees.
