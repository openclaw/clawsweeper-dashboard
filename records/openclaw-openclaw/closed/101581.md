Overall correctness: patch is incorrect

Full review comments:

- **[P2] Preserve usage query task failures:** `src/gateway/server-methods/usage.ts:892`
  - body: `runTasksWithConcurrency` catches task rejections and reports them through `hasError`/`firstError`; it does not throw for the caller. This patch immediately uses `summariesResult.results`, so if any agent's usage-cache load still fails, that slot stays `undefined` and the aggregation loop throws a later `TypeError`, masking the original SQLite/cache failure. Please use the existing sibling pattern: `errorMode: "stop"`, check `hasError`, and throw `firstError` before iterating results.
  - confidence: 0.9
