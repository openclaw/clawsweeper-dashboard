## Summary

Current main appears to preserve provider-bound thinking signatures when the model API and identity match, even after the provider route changes. This issue should remain open while the explicitly linked closing PR is reviewed; GitHub should close it only after that fix merges. Likely related people: YangManBOBO is the high-confidence routing candidate as the author of the focused linked fix.

## What This Changes

Prevent signed or redacted Anthropic thinking blocks from being replayed after a session switches to another provider serving the same model identity.

## Best Possible Solution

Land a focused shared-gate fix that preserves signed thinking only on the issuing provider route, keeps same-provider replay unchanged, and validates an actual provider switch; retain transcript-healing work for already-poisoned sessions as a separate recovery concern.
