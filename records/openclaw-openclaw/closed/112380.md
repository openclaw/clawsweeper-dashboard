## Summary

This PR fixes the blank-URL validation failure but still leaves the newly unblocked native Gemini request without its Google client-attribution header. The prior P2 finding remains at the latest head, and the PR also needs after-fix real Google-provider proof before merge.

## What This Changes

The branch makes blank Google image-provider base URLs fall back to Gemini’s canonical endpoint and adds image-generation regressions for empty and whitespace-only configured values.

## System Context

The bundled Google plugin turns configured provider credentials and endpoint settings into native Gemini image-generation HTTP requests. Its request resolver supplies the trusted endpoint and headers consumed by the image provider before the request is sent to Gemini.
