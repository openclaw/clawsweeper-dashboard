## Summary

Current main still has the reported admission gap: core HTTP work is tracked, but matched plugin HTTP handlers run directly and plugin-owned upgrades are offered before the prepared-state fence. No duplicate or fix PR currently owns the work, and the protected maintainer label requires explicit maintainer handling.

## What This Changes

Make matched plugin HTTP handlers and plugin-owned WebSocket upgrade work participate in Gateway suspension admission while preserving authenticated suspension status and resume access.

## Best Possible Solution

Extend the canonical root-work admission seam to matched, authenticated plugin handler execution and new plugin-owned upgrade ownership, with a narrowly verified exemption for authenticated suspension status/resume and focused lifecycle regression coverage.
