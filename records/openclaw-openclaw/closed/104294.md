## What This Changes

Add full agent-session execution on ephemeral SSH-reachable workers, with gateway-proxied inference, durable session synchronization, managed workspace transfer, and plugin-provided environment lifecycle.

## Best Possible Solution

Keep a distinct full-session architecture track, share one generic environment/provider foundation with per-spawn backend work, publish the complete plan, and gate staged implementation on threat modeling, fault injection, upgrade safety, and provision-to-destroy end-to-end proof.
