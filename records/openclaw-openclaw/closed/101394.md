## Summary

Keep open: the PR targets a real voice-call tunnel startup crash path, but the new stream-error paths can reject after starting a tunnel process without leaving any lifecycle cleanup handle, and the external proof is mock-focused only.

## What This Changes

The branch adds stdout/stderr error handling and regression tests for voice-call ngrok/Tailscale tunnel startup, plus an ngrok closed-state shortcut for `stop()`.

## Best Possible Solution

Keep the stream-error handling, but make each startup-failure path perform one-shot cleanup or termination before rejecting and back it with regression tests plus redacted real tunnel startup/failure proof.
