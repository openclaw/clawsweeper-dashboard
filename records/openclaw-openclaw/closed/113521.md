## Summary

This report duplicates an already-open canonical report with the same `applyAnthropicSonnet5Cost` missing-cost dereference, CLI crash, and repair direction. Keep the actual regression work consolidated in the canonical issue, which also contains an isolated configuration-only reproduction.

## What This Changes

The issue requests that Anthropic Sonnet 5 model normalization handle configured rows without a `cost` object so `openclaw models list` does not crash.

## System Context

The models CLI turns configured model references into display rows and passes them through provider-specific normalization before rendering. Anthropic normalization enriches Sonnet 5 rows with current pricing; an unguarded optional price field can abort the entire listing command.
