## Summary

Keep open: current main still source-reproduces the silent failed-image-load path, and no merged fix or canonical open PR owns the visibility contract yet.

## What This Changes

The issue reports that native image attachment load failures are counted internally but omitted from the model prompt and user-facing diagnostics.

## Best Possible Solution

Define one safe skipped-image visibility contract in the shared image-loading result and consume it consistently from embedded, CLI, and harness callers without leaking full local paths by default.
