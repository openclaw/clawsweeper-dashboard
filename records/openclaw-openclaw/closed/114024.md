## What This Changes

This PR makes provider, agent, and gateway live tests load host configuration through an isolated best-effort helper, adds a regression test and source guard, and gives the xAI live suite a minimal local provider configuration.

## System Context

OpenClaw live-test suites read operator configuration to select provider credentials, model profiles, and gateway settings before they start a real scenario. This change moves that test-only setup through a tolerant, environment-isolated read so retired host keys do not abort setup before the provider, agent, or gateway path runs.
