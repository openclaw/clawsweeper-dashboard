Full review comments:

- **[P2] Require CSS metrics before forwarding pointer actions:** `ui/src/components/browser/browser-panel.ts:747-749`
  - body: When the metrics probe is disabled or fails, this maps clicks using decoded screenshot dimensions even though `clickCoords` consumes CSS viewport coordinates. HiDPI or resized captures can click a different element; disable pointer actions until CSS metrics are available instead of using image pixels.
  - confidence: 0.98
- **[P2] Retry screenshot media fetch with alternate auth:** `ui/src/components/browser/browser-client.ts:308-330`
  - body: The panel receives only one resolved token, so a valid password-auth session with a stale stored gateway token gets 401 for every screenshot. Use the existing ordered auth-candidate contract and retry on 401/403 before failing.
  - confidence: 0.97
- **[P2] Resolve the inspected element at pointer-down:** `ui/src/components/browser/browser-panel.ts:849-853`
  - body: Inspect mode sends the last throttled hover result through `this.inspected`. A quick move-and-click can attach and describe the previous element; inspect the current pointer coordinates before composing the annotation.
  - confidence: 0.99
- **[P2] Clear provisional new-tab state when canceled:** `ui/src/components/browser/browser-panel.ts:684-690`
  - body: The provisional `pendingNewTab` flag remains set when the user abandons the flow by pressing Escape, entering an invalid value, or selecting an existing tab. A later URL submit can therefore open an extra tab instead of navigating the active one; clear the intent on every cancellation path.
  - confidence: 0.97
- **[P2] Serialize forwarded browser keystrokes:** `ui/src/components/browser/browser-panel.ts:843-844`
  - body: Each keydown starts an independent `browser.request`, so fast typing can overlap downstream and arrive out of order. Queue browser mutations per active tab before forwarding the next key.
  - confidence: 0.98
- **[P2] Reject stale same-tab browser captures:** `ui/src/components/browser/browser-panel.ts:456-480`
  - body: The freshness check covers only connection epoch and active tab. Two captures for the same tab can finish out of order, allowing an older screenshot and URL to overwrite a newer navigation or refresh; add a per-refresh sequence guard.
  - confidence: 0.99
