## Summary

Keep this PR open: a dedicated Codex home addresses the reported OAuth collision, but the proposed setup also replaces the worker’s entire Codex configuration with a new ChatGPT-oriented profile, which can break existing custom-provider and configured-worker setups.

## What This Changes

The PR updates the bundled coding-agent instructions to create, authorize, and command-scope a persistent worker-only `CODEX_HOME` for both normal and scratch Codex launches.

## Best Possible Solution

Keep a dedicated worker profile, but initialize or explicitly migrate its non-secret Codex configuration, run login only when the selected provider requires it, document the one-time operator setup and headless path, and prove both the ChatGPT isolation case and one configured non-default worker case.
