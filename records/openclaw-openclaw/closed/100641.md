## Summary

Keep open for maintainer direction: current main drops any ad hoc image sizing fields, but OpenClaw does not currently define width/height on ImageContent and Google's Part/Blob contract does not accept raw layout dimensions.

## What This Changes

Request that Google Gemini payload conversion preserve user-provided image layout dimensions and metadata for base64 image blocks.

## Best Possible Solution

Decide whether OpenClaw should add a canonical image sizing or media-resolution contract, then implement it at image normalization/provider mapping rather than passing arbitrary width/height through google-shared.
