## Summary

This PR remains necessary, but it is not merge-ready: a timeout during asynchronous cron preparation can return 503 before the real runtime reaches an abort gate, allowing later startup work despite the failed response. Real Gateway proof and owner confirmation of the changed acknowledgement contract also remain outstanding.

## What This Changes

The PR makes direct and mapped agent hooks wait for isolated-run admission, return classified pre-start HTTP failures, cancel admission timeouts, and share pending idempotent dispatch results.

## Best Possible Solution

Add a canonical abort check after cron preparation and immediately before any runner-entry callback or startup hook, cover delayed preparation through the real CLI and embedded paths, then obtain hook-owner approval for the acknowledgement contract and attach redacted live Gateway proof.
