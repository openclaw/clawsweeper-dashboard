## Summary

Keep this PR open: it is a focused fix for the linked Responses early-abort usage bug, but the new `response.incomplete` path still leaves `usage.cost` at zero, so it does not satisfy the cost-accounting part of the reported problem.

## What This Changes

The PR extracts Responses usage mapping, records `responseId` and token usage on `response.incomplete`, and adds a regression test for token buckets when no `response.completed` event arrives.

## Best Possible Solution

Route `response.incomplete` through the same terminal usage cost calculation path as `response.completed`, add a regression assertion that incomplete usage produces nonzero cost, and include real redacted stream proof for the Azure/OpenAI early-abort case.
