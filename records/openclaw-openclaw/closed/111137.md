## Summary

Keep open: the lifecycle-local ownership direction is sound, but the patch leaves the shipped Plugin SDK registration facade snapshot-only, so a provider registered after a `ModelRegistry` starts is invisible to that active lifecycle. **Likely related people:** `steipete` is the likely routing contact for the lifecycle refactor (low-confidence history signal from the current implementation work).

## What This Changes

The PR makes API-provider registries and LLM runtimes lifecycle-local to each `ModelRegistry` and threads that owner through agent, worker, simple-completion, media, and Amazon Bedrock stream paths.

## Best Possible Solution

Keep registries lifecycle-local, but preserve the shipped SDK facade contract by publishing late facade registrations into active lifecycle registries (or obtain explicit maintainer approval for a documented, backward-safe replacement lifecycle contract).
