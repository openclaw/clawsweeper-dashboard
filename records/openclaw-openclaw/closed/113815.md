## What This Changes

This PR decomposes the Matrix SDK client into lifecycle, transport, verification, support, device-information, and event-bridge modules while keeping `matrix/sdk.ts` as the public facade.

## System Context

The Matrix plugin wraps `matrix-js-sdk` to construct a client, synchronize rooms, persist sync and crypto state, bridge Matrix events, and expose transport and verification operations to the channel runtime. This change reorganizes that client implementation without intending to alter the plugin’s public SDK entry point or user-visible Matrix behavior.
