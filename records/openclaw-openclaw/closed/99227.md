## What This Changes

The issue requests an opt-in on-device LLM path for iOS Talk Mode, with model management and configurable fallback to the existing gateway-backed route.

## Best Possible Solution

First define a supported iOS Talk local-inference product boundary—supported devices and backend, model acquisition and integrity policy, tool/fallback behavior, storage limits, and upgrade-safe settings—then implement it as a staged, owner-reviewed design rather than a single autonomous fix.
