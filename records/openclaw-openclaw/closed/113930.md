## What This Changes

Moves Control UI sidebar-section ordering from the unreleased `ui.prefs.sessionSectionOrder` setting into gateway-owned SQLite state, so built-in and custom sections can be reordered and the layout follows the gateway across clients.

## System Context

The Control UI reads a session-group catalog from the gateway to build its sidebar. This PR extends that gateway response and mutation path with a persisted section order, then uses it to render and reorder sidebar headers while leaving session drop targets unchanged.
