## What This Changes

Correct node approval diagnostics so omitted host policy fields cannot be reported as permissive when the node runtime enforces stricter defaults.

## Best Possible Solution

Add host-resolved approval defaults to the node snapshot contract for both node implementations, consume them in effective-policy reporting, and render older nodes without that metadata as explicitly unknown.
