## What This Changes

The PR changes outbound queued-message recovery to use the persisted completed retry count so retries become eligible at the intended 5-second, 25-second, and 120-second delays.

## System Context

OpenClaw persists outbound channel deliveries so a gateway restart or failed send can resume them later. Recovery reads each pending entry, decides whether its retry delay has elapsed, and hands eligible entries back to the channel delivery path.
