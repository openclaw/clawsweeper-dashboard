## Summary

Keep this PR open for a focused repair: the exact head still permits startup cleanup to delete a valid bundled-MCP configuration while its run is waiting for serialized CLI admission. The contributor’s real-host proof is strong for spawned processes, but it does not cover this pre-spawn lifecycle state.

## What This Changes

The PR adds a cross-platform gateway-startup sidecar that removes aged bundled-MCP temporary configuration directories when no visible process command line references them.

## Best Possible Solution

Give each generated directory explicit live gateway/run ownership through queue admission and child spawn, or create the directory only after admission, and reclaim it only when both owner and child liveness are absent.
