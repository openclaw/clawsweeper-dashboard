## What This Changes

Prevent automatic Docker sandbox config rollout from force-removing containers while real exec, filesystem-bridge, or browser operations remain active.

## Best Possible Solution

Land one owner-reviewed lifecycle repair where all real Docker exec, filesystem-bridge, and authenticated browser operations hold shared per-container leases, automatic replacement owns an exclusive drain-and-recheck claim through recreation, and explicit operator recreation remains intentionally forceful.
