## Summary

Current main still uses a limited hand-written entity decoder in the built-in HTML extraction path, so the deterministic output-corruption bug remains; the protected `maintainer` label also requires explicit maintainer handling.

## What This Changes

## Best Possible Solution

Use the maintained HTML5 entity decoder at the shared HTML-to-text boundary, retain the existing tokenizer and sanitization flow, and add focused coverage for common named references plus supplementary-plane numeric references.
