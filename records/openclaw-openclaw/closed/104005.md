## Summary

Current main does not provide bulk pairing decisions, and the open linked PR is the direct implementation candidate. Keep this protected issue open until maintainers explicitly accept the change from per-device authorization to one-click batch approval and resolve that PR.

## What This Changes

Add Approve All and Reject All footer actions to the Mac pairing approval panel when multiple requests are pending.

## Best Possible Solution

Resolve the existing linked PR after explicit Mac app owner approval; if bulk approval is accepted, retain per-request routing and in-flight guards, omit an approval keyboard shortcut, keep single-request behavior unchanged, and prove the multi-request native panel behavior on macOS.
