## Summary

The bug remains on current main: concurrent token minting can own the asynchronous exec-approvals lock while Gateway authentication performs a synchronous read, which rejects the same-process owner and substitutes a tokenless fail-closed snapshot. The report has strong live evidence, no duplicate or fix PR exists, and the protected authentication surface should stay open for maintainer-owned repair.

## What This Changes

Fix concurrent agent-node calls that intermittently reject valid freshly minted local runtime identity tokens during Gateway authentication.

## Best Possible Solution

Add a lock-aware asynchronous secret read and token verification path at the exec-approvals owner, await it from Gateway connection authentication, and cover same-process concurrent mint/verify plus unchanged cross-process fail-closed behavior.

## Solution Assessment
