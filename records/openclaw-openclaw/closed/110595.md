## Summary

The central fix is useful, but the earlier P1 remains: when gateway transport teardown times out and rejects, TUI terminal cleanup is skipped. This PR also still needs inspectable after-fix runtime proof before merge; the `maintainer` label requires explicit maintainer handling.

## What This Changes

The PR makes `GatewayChatClient.stop()` await gateway transport teardown and adds TUI shutdown-contract, watchdog, and PTY cleanup coverage.

## Best Possible Solution

Make TUI terminal drain/stop unconditional in a `finally` around gateway teardown, preserve the teardown error only after local terminal cleanup, and add a timeout-rejection regression test plus redacted PTY proof.
