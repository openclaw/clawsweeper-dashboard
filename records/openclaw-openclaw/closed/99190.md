Request to replace repeated full transcript JSONL and AGENTS.md policy scans on hot agent session paths with bounded or cached reads so long-running sessions do not add linear per-turn cost.

## Best Possible Solution

Keep this issue as the canonical tracker until a merged fix bounds the startup/header and digest scans and either bounds or explicitly follows up the readTranscriptFileState and SessionManager full-read hot paths with equivalence coverage.

## Solution Assessment

Yes for the direction, but not as a wholesale replacement of readTranscriptFileState. The maintainable fix is targeted bounded readers or indexes for read-only hot-path metadata, while preserving full parsing where migration, mutation, repair, and rewrite paths need it.
