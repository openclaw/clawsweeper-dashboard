## What This Changes

The issue reports that reopening the macOS desktop app against a remote SSH gateway can make Open Dashboard show a WebSocket connect failure because the remote gateway rejects the browser origin from a stale or random local tunnel port.

## Best Possible Solution

Keep the current main implementation: reap recorded orphaned SSH tunnels before choosing a tunnel port, preserve broad remote-mode listener safety, and rely on the dashboard endpoint-refresh path for live tunnel changes.
