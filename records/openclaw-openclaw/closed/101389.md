## What This Changes

The branch adds `error` handlers to the three Windows `taskkill.exe` spawns in `runCommandWithTimeout` so async taskkill start failures fall back to `child.kill("SIGKILL")`.

## Best Possible Solution

Land a narrow process-layer fix that preserves the trusted System32 taskkill lookup, handles async taskkill child errors, and includes focused fallback coverage plus real Windows proof.
