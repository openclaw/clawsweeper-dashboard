## Summary

This issue remains necessary: current main implements the preceding fixed titlebar navigation design, but not the requested state reporting, adaptive controls, or native search/new-session actions. The feature fits the macOS companion-app roadmap, while the protected `maintainer` label and stable native/web contract require an explicit maintainer product decision.

## What This Changes

Make the macOS dashboard titlebar switch between history controls and search/new-session controls according to the Control UI sidebar state.

## Best Possible Solution

Add a typed, version-tolerant app-host navigation-state bridge that reports hidden state and width, route native search/new-session events through the existing palette and `new-session` handlers, and retain the fixed titlebar controls until a compatible report is received.
