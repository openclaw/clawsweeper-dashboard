## What This Changes

Publish a safe subset of resolved Control UI style variables to embedded MCP apps through the additive host-context styles field, while retaining the existing light/dark theme name.

## System Context

The Control UI embeds MCP apps and sends each app host context such as the active theme. The requested extension would turn resolved host design tokens into a sandbox-safe style-variable payload so embedded apps can visually align with the UI and update when the theme changes.
