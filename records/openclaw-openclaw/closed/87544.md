## Summary

Keep open. Current main has durable outbound queues, queue-level unknown-send recovery, dead-letter health, and transcript mirror markers, but it still lacks the requested durable transcript-entry to provider-message receipt ledger, per-entry delivery state, and origin-delivery reconciler.

## What This Changes

The issue asks for durable transcript-to-client delivery receipts and reconciliation for channel-scoped sessions.

## Best Possible Solution

Design a single SQLite-backed origin-delivery receipt model that maps transcript entries to platform receipts, exposes per-entry state to operators, and lets channel adapters reconcile or redeliver only when they can do so idempotently.
