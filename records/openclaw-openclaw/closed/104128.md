## Summary

This PR should not merge as written: upstream Chromium and Playwright contracts use the supplied origin only as a permission-state scope, so applying page-navigation SSRF checks does not close the claimed network path and instead blocks valid permission workflows.

## What This Changes

The PR validates normalized permission origins with the profile-aware browser navigation guard before browser startup or CDP/Playwright permission grants.

## Best Possible Solution

Keep SSRF enforcement on actual page navigation and CDP endpoint connections; only add a permission-specific restriction if a concrete separate authorization boundary is demonstrated, and preserve valid local, private-origin, and proxy-routed permission scopes.
