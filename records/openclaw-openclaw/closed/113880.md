## What This Changes

This PR splits embedded-agent direct compaction from one large module into preparation, prepared-runtime construction, locked session execution, diagnostics, and a small public fallback facade.

## System Context

Embedded-agent compaction condenses a session transcript when context must be discarded. It receives the selected model, session state, tools, skills, and hooks, then writes checkpointed transcript results and releases runtime resources for the next agent turn.
