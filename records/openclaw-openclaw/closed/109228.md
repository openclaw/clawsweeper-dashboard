## Label Justifications

- `P0`: The report describes a non-technical fresh-install path that cannot reach the first useful run without acquiring credentials or installing and configuring another runtime.
- `impact:ux-release-blocker`: Credential-less Apple Silicon users are reported to stop at the mandatory inference gate with no in-product zero-key recovery route.
- `impact:auth-provider`: The requested capability changes provider detection, model routing, guided activation, and the credential-free inference path.

## Summary

Keep this maintainer-protected feature open for product direction: the provider-plugin and guided-onboarding boundaries exist, but official bundling, the macOS 26 executable fallback, and the model's setup-agent role need explicit ownership and validated Apple contracts.

## What This Changes

Add an Apple Foundation Models provider plugin that offers zero-key guided inference setup on supported Apple Silicon Macs.

## Best Possible Solution

Keep the implementation provider-owned, first validate a macOS 27 `fm respond` or native-framework transport with real guided-setup evaluations, and add a signed macOS 26 helper only if maintainers explicitly accept its release and security lifecycle.
