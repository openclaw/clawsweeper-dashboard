## What This Changes

This PR adds an operator recovery procedure for channel auto-start suppression after the gateway crash-loop breaker trips, plus cross-links from gateway and channel troubleshooting docs.

## System Context

The gateway crash-loop breaker prevents repeated failed boots from automatically starting channel and provider accounts, while leaving the gateway control plane available for diagnosis. Operators inspect the still-running gateway and channel state, correct the cause, then manually start a selected channel or allow the suppression window to expire before a later boot.

## Architecture Diagram

flowchart TD
  A[Repeated unclean gateway boots] --> B[Crash-loop breaker]
  B --> C[Gateway control plane starts]
  B --> D[Channel auto-start suppressed]
  C --> E[Operator inspects gateway and channels]
  E --> F[Fix underlying startup cause]
  F --> G[Manual channel recovery or later boot]
  G --> H[Channel connections resume]

## Best Possible Solution

Keep the recovery guidance focused on the existing manual `channels.start` override, retain the explicit current-boot versus later-boot distinction, then merge a refreshed documentation-only branch after final maintainer review.
