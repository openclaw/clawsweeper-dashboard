## What This Changes

This PR adds `openclaw agent exec`, an isolated headless command for one embedded agent turn with ephemeral state by default, machine-readable JSON results, explicit model fallbacks, and scoped authentication and host-environment handling.

## System Context

OpenClaw’s CLI normally routes agent turns through Gateway-backed or operator-configured flows. This new command would instead construct an embedded agent run directly, apply an isolated runtime policy, then return a bounded JSON envelope and process exit status to scripts or CI.
