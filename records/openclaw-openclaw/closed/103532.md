## Summary

The issue remains necessary: Novita shipped as a bundled provider in v2026.6.11, but current model listing and runtime registration are constrained by its static catalog, which omits a provider route Novita currently exposes.

## What This Changes

Fix Novita model discovery so configured accounts can list, select, and run currently available provider routes instead of being limited to the bundled static catalog.

## Best Possible Solution

Implement authenticated live catalog discovery in the Novita plugin through existing provider SDK seams, retaining its manifest catalog only as an explicit failure fallback and using one normalized result for listing, selection, and runtime resolution.
