## What This Changes

The branch adds a shared Plugin SDK builder for moving legacy configuration keys and replaces five channel plugins’ duplicated doctor-migration implementations with it.

## System Context

Plugin doctor contracts scan persisted channel configuration for retired keys, rewrite them into canonical keys, and report each repair to the operator. This PR moves the common traversal, precedence, deletion, and reporting mechanics into the Plugin SDK while leaving each channel plugin responsible for its own legacy-key mapping.
