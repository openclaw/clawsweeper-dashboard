## Summary

Keep open: the PR targets a real source-reproduced Control UI lockout bug, but the patch is not merge-ready because it treats the whole provider 4xx bucket as transient even though that bucket also includes non-retryable 400/401/403 failures, and the PR only provides mocked/unit proof.
