## What This Changes

The branch changes cron local-provider preflight diagnostics to retain elapsed probe time, show chained error details, distinguish timeout failures, and include the reason in the fallback warning.

## System Context

Cron isolated-agent jobs preflight their selected local model provider before running. The preflight probe feeds either the selected provider, a configured fallback, or a skipped-run diagnostic, so its reason string is the operator-facing explanation for a scheduling decision.
