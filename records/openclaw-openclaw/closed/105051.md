- `maturity:stable`: The issue affects the M4 Stable gateway-runtime surface across nodes, RPC APIs, roles, permissions, and security controls.

## Summary

Current main still has the reported Gateway-only browser boundary, while the established node-command system provides a viable implementation seam; this protected feature should remain open pending explicit approval of the remote filesystem-discovery boundary.

## What This Changes

Add a synthetic Gateway-and-nodes root to the New session folder browser, browse compatible node directories, and bind the selected node path to node session creation.

## Best Possible Solution

Model the browser root as hosts, add one read-only directory-listing command through the existing declared node-command contract, keep unsupported and offline hosts visible but disabled, bind nodeId and cwd atomically, and retain Gateway-only managed worktrees.
