## Summary

The shared SecretRef refactor is the right ownership direction and the loopback proof is strong, but the branch suppresses Ollama’s existing ambient cloud credential whenever any configured credential resolves. That broader auth-precedence change can remove a valid hosted fallback, and the exported resolver hooks also need explicit plugin-SDK owner approval.

## What This Changes

The PR extends the shared web-search credential resolver with provider normalization and unavailable-ref handling, migrates Ollama web search to it, and adds focused resolver and provider tests.

## Best Possible Solution

Keep the shared SecretRef resolver and fail-closed handling for unavailable configured refs, continue resolving `OLLAMA_API_KEY` independently for the distinct hosted-cloud attempt, add mixed-credential regression coverage, and obtain plugin-SDK owner approval for the two optional hooks.
