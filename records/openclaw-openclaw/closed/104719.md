## What This Changes

Make memory-wiki corpus supplements honor the memory tool deadline and avoid exhaustive remaining-vault fallback during ordinary memory recall.

## Best Possible Solution

Add an optional AbortSignal to supplement search, forward the existing memory_search deadline, make wiki enumeration and page reads abort-aware, and disable exhaustive backfill for supplement recall while retaining it for explicit wiki_search.
