## Summary

Keep open: the protected `maintainer` label requires human handling, and the current head still has a blocking stable-release publication defect. The linked Linux package proof is useful but does not exercise the new release promotion and rerun path.

## What This Changes

Adds an operator-dispatched workflow to build and attach stable-tagged Linux deb/AppImage packages and checksums, aligns Linux CI with Ubuntu 22.04, and documents the release assets and installation steps.

## Best Possible Solution

Keep the stable-only workflow, but make publication immutable and idempotent: skip identical existing assets, upload only missing assets, and fail closed on mismatches unless an explicit documented recovery operation is selected; then demonstrate first upload and safe rerun behavior on a disposable release.
