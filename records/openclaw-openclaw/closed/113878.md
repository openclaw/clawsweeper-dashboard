## Summary

This issue duplicates a previously reported and merged fix for the same allowlisted-but-uncataloged model-picker omission. Current main contains the generic synthetic catalog-row path, so explicit model allowlist entries no longer need a built-in or provider-config catalog row to reach `models.list` and the Control UI picker.

## What This Changes

Make explicitly allowlisted model IDs appear in the Control UI model picker even when they have no built-in or configured provider catalog entry.

## System Context

The gateway assembles provider and configured model catalogs, applies the agent model allowlist, and returns the visible result through `models.list` to Control UI and command pickers. Explicit allowlist references are now converted into minimal catalog entries when catalog discovery has no matching row.
