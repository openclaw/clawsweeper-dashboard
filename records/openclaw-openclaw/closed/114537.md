## What This Changes

The branch normalizes plugin manifest `kind` declarations to the supported `memory` and `context-engine` values, removes invalid or duplicate entries, and adds regression coverage for exclusive memory-slot enforcement.

## System Context

Plugin manifests declare capabilities that feed plugin discovery and runtime slot selection. The normalized `kind` value affects whether a plugin is eligible for exclusive memory or context-engine roles and how CLI inspection reports the plugin.
