## Summary

Keep this PR open. The current head fixes the earlier missing in-memory `close()` contract, but the shutdown path now waits forever on in-flight ACP gateway event promises before closing the SQLite ledger, so a stalled handler can still prevent the database handle from being released.

## What This Changes

Adds a required `AcpEventLedger.close()` hook, implements it for SQLite and in-memory ledgers, and calls it from ACP gateway shutdown after tracking in-flight gateway event handlers for https://github.com/openclaw/openclaw/issues/100637.

## Best Possible Solution

Land one complete ACP shutdown lifecycle fix that stops accepting new events, drains in-flight handlers with a bounded timeout, closes the shared SQLite state DB after final writes, verifies the cached DB is closed, and includes current-head proof.
