## Summary

Keep this PR open for repair: bounding the process-lifetime cache is necessary, but the hard-stop policy permanently suppresses every new channel-selection diagnostic after 512 distinct errors, and the external PR provides no after-fix runtime proof.

## What This Changes

The PR caps the process-lifetime channel-selection error-deduplication set at 512 entries by refusing new keys after the limit is reached.

## Best Possible Solution

Use a bounded insertion-order cache that evicts the oldest key at capacity before recording and logging the newest distinct error, preserving duplicate suppression without permanently blinding later diagnostics.

## Solution Assessment
