## Summary

This report adds useful current-release Feishu evidence, but its central failure—subagent completion or wake handling compacting a parent session far below its context limit—is already tracked by the open canonical issue at https://github.com/openclaw/openclaw/issues/86684. The separate reserve-floor concern is not supported by current documentation, which says `reserveTokensFloor` raises the effective Pi `reserveTokens` value rather than replacing that setting. ([github.com](https://github.com/openclaw/openclaw/issues/86684))

## What This Changes

Prevent subagent activity from inflating parent-session context accounting and triggering premature compaction.

## Best Possible Solution

Consolidate this evidence into https://github.com/openclaw/openclaw/issues/86684, then make successful-turn compaction consume only authoritative parent-context usage and add regressions covering subagent wake/direct-announce, model switches, and aggregate tool or cache usage without changing the existing reserve-floor contract.
