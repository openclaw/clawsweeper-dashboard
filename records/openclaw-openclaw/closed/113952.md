## What This Changes

The PR wraps the Control UI’s line-icon SVG bodies in a shared shell that supplies inline Lucide stroke attributes so icons also render inside Lit shadow roots.

## System Context

The Control UI imports reusable Lit icon templates into both ordinary light-DOM pages and shadow-DOM components such as the image lightbox. The shared SVG shell supplies presentation defaults at the icon boundary, while component CSS can still override visual styling for a specific surface.
