## Summary

Current main has a deterministic save-settlement race that silently overwrites newer agent-file edits. No duplicate or fix PR owns the work, and the protected `maintainer` label requires explicit maintainer handling rather than cleanup closure.

## What This Changes

Fix the Agents file editor so a completed save does not discard edits typed after that save request began.

## Best Possible Solution

Capture the submitted draft snapshot, always advance the saved baseline after success, and advance the live draft only if it still equals that snapshot; add a pending-save draft mutation regression test and repeat the isolated-Gateway Playwright scenario.
