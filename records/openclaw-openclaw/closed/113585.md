## What This Changes

Splits the browser plugin’s monolithic Playwright session manager into focused state, dialog, download, connection, navigation, and page-action modules while retaining `pw-session.ts` as the public facade.

## System Context

OpenClaw’s browser plugin uses a Playwright-over-CDP session layer to connect to a browser, locate pages, enforce navigation safety, and report browser state to browser tools. This refactor rearranges the internal lifecycle implementation while callers continue to enter through the session facade.
