## Summary

The reported gap remains in both current main and the latest release: WhatsApp and Signal consume a losing approval reaction and log the gateway failure without visible operator feedback. No canonical issue or PR replaces this fresh, protected maintainer item, so it should remain open.

## What This Changes

Add visible terminal feedback when WhatsApp or Signal reaction-based operator approvals lose a first-answer race.

## Best Possible Solution

Expose a structured losing-race outcome with canonical resolution text from shared approval infrastructure, then let WhatsApp and Signal deliver it through their existing plugin-owned outbound paths with focused race tests.
