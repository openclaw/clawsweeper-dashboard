- **[P2] Keep queued voice turns pending until delivery completes:** `apps/ios/WatchApp/Sources/WatchInboxView.swift:1125`
  - body: `sendChatMessage` returns the command id before the async WatchConnectivity send result is known, so voice turns start the 90-second timeout even when delivery falls back to a queued transfer. A delayed queued command can reach the phone and complete after this timeout, causing the Watch to ignore the eventual `watch.chat.completion` reply.
  - confidence: 0.9
- **[P2] Avoid matching queued voice turns by substring:** `apps/ios/Sources/Model/NodeAppModel.swift:3621`
  - body: When the exact `runId:user` row is missing, `entry.text.contains(submittedText)` can anchor short dictated text such as `ok` to a later unrelated user row after `submittedAtMs`. The spoken reply can then belong to that later turn rather than the Watch command.
  - confidence: 0.89
- **[P2] Stop fallback reply search at the next user turn:** `apps/ios/Sources/Model/NodeAppModel.swift:3624-3626`
  - body: After choosing a fallback user row, the code scans all later rows and returns the first terminal assistant message, even if another user turn appears first. In interleaved iPhone and Watch use this can speak the later user's assistant response for the Watch voice turn.
  - confidence: 0.88
- **[P2] Route voice UI strings through native i18n:** `apps/ios/WatchApp/Sources/WatchInboxView.swift:1090-1093`
  - body: The new `Speaking reply...` and `Waiting for spoken reply...` states are returned from a computed `String?` property, and the PR-head inventory search only found `Message OpenClaw`. Localized watchOS builds will keep these new voice states and related accessibility labels in English unless they use an extracted/localized path.
  - confidence: 0.92
- **[P2] Remove the release-owned changelog entry:** `CHANGELOG.md:32`
  - body: `CHANGELOG.md` is release-owned in this repo; normal feature PRs should carry release-note context in the PR body or commit message. Adding this entry directly can leave generated release notes duplicated or stale.
