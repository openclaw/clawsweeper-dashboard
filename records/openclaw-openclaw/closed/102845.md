## Summary

Keep open. Current main still lets a usable-model Crestodian turn return ordinary text without an `open-tui` directive, which the gateway maps to `action: "none"`, and the issue is protected by the `maintainer` label with an open linked fix PR still pending.

## What This Changes

The issue asks for the documented `talk to agent` Crestodian command over `crestodian.chat` to deterministically return `open-agent` so the macOS app opens the configured agent UI.

## Best Possible Solution

Review and land https://github.com/openclaw/openclaw/pull/102883, or a narrower host-side equivalent, so exact documented handoff selectors bypass model discretion while broader natural-language Crestodian chat remains AI-owned.
