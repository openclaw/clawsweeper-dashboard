## Summary

This issue duplicates the already closed Feishu runtime-context leak report at https://github.com/openclaw/openclaw/issues/92589. The canonical fix wraps generated runtime context in the existing internal-context delimiters so the shared user-visible-text sanitizer removes the whole block, rather than relying on a Feishu-only filter. ([github.com](https://github.com/openclaw/openclaw/pull/92593))

## What This Changes

Prevent Feishu direct-message replies from exposing the internal OpenClaw runtime-context envelope and its metadata.

## System Context

The agent runtime builds hidden per-turn context, then channels render the model’s final reply for external users. Shared sanitization removes internal runtime-context blocks before those replies reach Feishu cards or plain-text delivery.
