## Summary

## What This Changes

The issue reports first-run CLI startup failing after the curl installer on macOS with Node v23.7.0 because opening the plugin state database throws `statement.columns is not a function`.

## Best Possible Solution

Keep the prior canonical decision: affected Node 23 users should move to Node 24+ or Node 22 LTS, and maintainers should reopen the canonical runtime-support discussion only if they want to support Node 23.0-23.10 again.
