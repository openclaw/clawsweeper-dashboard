## Summary

Close: current main fixes the reported provider-side AbortError fallback path via the merged model-fallback guard change in https://github.com/openclaw/openclaw/pull/90908; the fix is current-main-only and is not present in v2026.6.11.

## What This Changes

The report asks OpenClaw to treat provider-side `AbortError("This operation was aborted")` as a fallback-eligible transport timeout instead of user cancellation.

## Best Possible Solution

Keep the current-main behavior from https://github.com/openclaw/openclaw/pull/90908 and let the next release carry it; broader Bedrock or replay-safe prompt-abort work should stay on its separate canonical issues/PRs.

## Solution Assessment
