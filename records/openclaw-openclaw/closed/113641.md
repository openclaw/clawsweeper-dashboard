## What This Changes

The PR makes automated Workboard completion require structured proof and lifecycle checks, preserves direct operator completion with audit metadata, and changes decomposition to leave the parent open unless completion is explicitly requested.

## System Context

Workboard is OpenClaw’s plugin for tracking work cards and their completion evidence. Operator and agent tool calls enter the plugin, which validates lifecycle state and proof before updating a card, recording metadata, and publishing Workboard events.
