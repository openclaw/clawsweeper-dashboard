## What This Changes

The PR changes default agent compaction reserve calculations to align with an 85% context-usage threshold, flushes oversized tool-result content before preflight compaction, and emits context-engine compaction events so the Control UI can show activity.

## System Context

The agent reply pipeline estimates transcript and tool-result pressure before invoking compaction to keep a model request within its context window. Context-engine compaction runs through a safety-timeout wrapper and reports agent events that downstream UI state can render.
