## What This Changes

Restore llama.cpp-compatible tool schemas so enabling the built-in cron tool does not make otherwise valid OpenAI-compatible requests fail.

## Best Possible Solution

Preserve the intended nonblank-string contract with a llama.cpp-compatible anchored constraint or an established centralized schema-compatibility path, add focused generated-schema coverage, and prove a real request against llama.cpp or LM Studio before landing the linked PR or a replacement.
