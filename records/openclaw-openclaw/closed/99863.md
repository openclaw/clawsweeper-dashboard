## Summary

Keep open: this targets the right compaction regression, but the patch replaces the overcount with a likely undercount by dropping cached prompt tokens whenever totalTokens is missing or zero. The PR also lacks after-fix real behavior proof from a real affected or representative run, so it is not ready to merge.

## What This Changes

The PR changes compaction token estimation to use only input plus output when totalTokens is missing or zero, and adds calculateContextTokens regression tests for turn-aggregated cache fields.

## Best Possible Solution

Preserve the issue-linked fix path, but make compaction use a latest real context or prompt snapshot, or populate totalTokens before threshold evaluation, with tests for both turn-aggregated cache buckets and missing-total cached single-call usage.

## Reproduction Assessment

Yes at source level: the linked token sample and current main fallback reproduce the inflated estimate when totalTokens is zero. I did not run a live Anthropic/container reproduction in this read-only review.

## Solution Assessment

No: the PR changes the right function, but input + output is not a safe context fallback when cacheRead/cacheWrite may represent real cached prompt context. The better fix is to carry the latest real context or prompt total into compaction rather than dropping all cache buckets.
