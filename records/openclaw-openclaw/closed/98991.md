Full review comments:

- **[P1] Use normalized usage for cost emission:** `src/plugins/runtime/runtime-llm.runtime.ts:490`
  - body: The new block calls `estimateUsageCost({ usage, ... })` after `usage` has been converted to `LlmCompleteUsage` with `inputTokens`/`outputTokens` fields. `estimateUsageCost` reads normalized `input`/`output` buckets, and the computed `costUsd` is unused, so this fails the typed/linted path and would not emit the cost value.
  - confidence: 0.91
- **[P2] Preserve plugin attribution in the usage event:** `src/plugins/runtime/runtime-llm.runtime.ts:496-502`
  - body: The linked issue asks for plugin-owned LLM spend to be attributable to the calling plugin, but this event only sends session, agent, provider, and model. Without adding a bounded plugin field through the diagnostic type and exporters, plugin completions remain indistinguishable from ordinary runtime usage.
  - confidence: 0.86
