## Label Justifications

## Summary

The open canonical issue already tracks the same active-memory failure boundary: arbitrary non-`NONE` subagent prose passes weak normalization and is injected as recalled context. This report adds valuable evidence that plausible factual confabulations, not only obvious assistant chitchat, can cross that boundary, but it does not identify a distinct root cause or separately owned fix.

## What This Changes

Require active-memory to reject ungrounded, malformed, or partial recall-subagent output before injecting it into the main agent context.

## Best Possible Solution

Keep https://github.com/openclaw/openclaw/issues/84034 as the single tracking issue and implement a parsed, fail-closed recall result with retrieval provenance checks, complete-sentence limits, and no default injection of timeout partials.
