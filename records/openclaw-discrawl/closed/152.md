## What This Changes

This PR configures the shared release workflow to consider only `push` and `pull_request` GitHub Actions runs as CI evidence while retaining unresolved non-Actions checks and commit statuses.

## System Context

Discrawl’s release workflow freezes a commit SHA, gathers its CI evidence, and then signs/publishes the release only when the gate passes. This change narrows the GitHub Actions runs included in that evidence so unrelated scheduled automation on the same SHA does not block the release path.
