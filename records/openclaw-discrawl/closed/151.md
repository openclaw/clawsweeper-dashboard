## What This Changes

Moves Discrawl publishing from its local GoReleaser and post-publish workflows to the shared OpenClaw reusable release pipeline, while retaining the published archive contract and redirecting local release commands to GitHub Actions.

## System Context

Discrawl's release configuration turns a signed version tag and repository release secrets into signed platform archives, checksums, notarized macOS binaries, and a Homebrew tap update. This PR replaces the repository-local orchestration with an OpenClaw-managed reusable workflow while keeping GoReleaser responsible for archive layout.
