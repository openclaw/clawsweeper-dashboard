## What This Changes

The PR resolves requested Discord channel IDs directly before broad archived-thread discovery, caches those lookups, rejects DMs from the guild path, and adds targeted sync regression coverage.

## System Context

Discrawl's targeted sync accepts selected guild and channel IDs, builds a channel catalog, then retrieves Discord messages into the local archive. This change adjusts the catalog stage so archived thread IDs can be resolved directly rather than depending on a broad guild-thread discovery pass.
