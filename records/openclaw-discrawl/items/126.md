## Label Justifications

- `merge-risk: 🚨 message-delivery`: Resolving failures outside the active guild scope can permanently hide messages that were never recovered.

## Summary

This maintainer-authored PR addresses a real Discord tail reliability problem and adds substantial regression coverage, but two message-delivery blockers remain: scoped tail runs can resolve failures from other guilds without recovering them, and persistent systemic handler failures still have no bounded escalation path.

## What This Changes

The branch makes event-scoped Discord tail failures nonfatal, records failed message identities, and replays unresolved messages by exact channel and message ID during periodic repair.

## Best Possible Solution

Keep isolated event failures nonfatal, retain unresolved failures outside the active guild scope, add a bounded circuit breaker for repeated systemic failures, and validate both a live tail run and an upgrade from a v0.11.5 failure ledger.
