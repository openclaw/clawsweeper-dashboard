## Summary

Keep this PR open for a narrow correction: the new early help interception ignores the standard end-of-options delimiter, so a literal `-h` or `--help` argument after `--` is incorrectly replaced with command help.

## What This Changes

The PR replaces static CLI help with Kong-generated root, command, and nested-group help, dispatches help before runtime initialization, and adds focused regressions.

## Best Possible Solution

Make early help detection stop at `--`, preserve subsequent help-shaped tokens as positional input, and add a regression using a text-accepting command such as `search`.
