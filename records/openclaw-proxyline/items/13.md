## What This Changes

The branch adds a shared proxy-userinfo decoder that maps malformed percent encoding to `INVALID_PROXY_USERINFO`, then uses it for CONNECT tunnels and Node HTTP-agent Basic authentication with regression coverage.

## System Context

Proxyline receives proxy URLs from callers and uses their userinfo to build Basic authentication for explicit CONNECT tunnels and Node HTTP/HTTPS agent requests. The shared decoder sits between URL parsing and authorization-header construction so malformed credentials return a Proxyline error instead of escaping as a raw URI decoding exception.
