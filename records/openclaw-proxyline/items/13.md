## Summary

The PR remains necessary: current main still uses bare `decodeURIComponent` in both proxy Basic-auth builders, while this branch converts malformed proxy-userinfo encoding into a controlled `INVALID_PROXY_USERINFO` failure. The patch is narrow, has direct regression coverage, and the contributor supplied an exact-head built-artifact runtime transcript; no correctness blocker was identified. Likely related people: SebTardif is the only evidenced contributor for this exact change, but current-main ownership could not be conclusively traced in the available read-only environment.

## What This Changes

The PR replaces raw percent-decoding of proxy usernames and passwords in CONNECT tunnels and Node HTTP-agent authentication with a shared decoder that reports malformed encodings as `INVALID_PROXY_USERINFO`, plus regression tests.

## System Context

Proxyline receives proxy URLs from callers and builds Basic `Proxy-Authorization` headers for CONNECT tunnels and Node HTTP agents. This change sits at the credential-decoding boundary before those transport paths establish outbound connections.
