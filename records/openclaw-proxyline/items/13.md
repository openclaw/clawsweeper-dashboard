## What This Changes

The branch adds a shared proxy-userinfo decoder that converts malformed percent-encoding into `INVALID_PROXY_USERINFO`, then uses it when building Basic proxy authentication for CONNECT tunnels and Node HTTP agents.

## System Context

Proxyline receives a proxy URL and derives proxy credentials before opening either a CONNECT tunnel or a Node HTTP(S) request. The decoded username and password become the Basic authorization header sent to the proxy; malformed URL userinfo should become a typed Proxyline failure rather than an uncaught URI decoding exception.
