## Summary

Keep this open for an explicit product decision: neither current main nor v0.33.0 provides persistent MCP capability profiles, and the proposal fits the agent-safety direction, but its durable schema and default-versus-ceiling precedence are not established by current behavior.

## What This Changes

Add optional global and per-account MCP capability profiles in config.json, with tool overrides and CLI precedence while retaining the current read-only default.

## Best Possible Solution

Introduce a single resolver for built-in global and per-account profiles after final account resolution, treat baked safety profiles as the immutable ceiling, preserve the no-config read-only behavior, and defer custom bundles and per-tool maps until focused precedence tests prove the contract.
