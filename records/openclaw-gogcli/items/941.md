## Summary

Keep this PR open. The patch directly targets a destructive positional-update path and includes focused unit and command-level coverage, but it needs redacted after-fix evidence from a real Sheets run before merge; no discrete correctness defect is established from the supplied patch.

## What This Changes

The PR makes positional Google Sheets updates preserve literal text for one cell and reject row or column shapes that exceed a requested finite range, while allowing `links set --cells-json` to read JSON from a file or standard input.

## System Context

The Sheets CLI turns positional or JSON values into a Google Sheets Values API update request. A1 parsing and named-range resolution establish the target grid shape before that request, so this path determines whether a command can change cells beyond the range the user selected.
