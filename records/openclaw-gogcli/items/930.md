## Summary

Keep this PR open: it addresses a real terminal-OAuth retry storm, but acknowledging the only notification can leave already-arrived mail unprocessed until another mailbox change happens after re-authentication. The patch also needs after-fix real behavior proof before merge.

## What This Changes

The PR classifies terminal Gmail OAuth refresh failures, acknowledges the related Pub/Sub push or pull delivery, preserves the Gmail history cursor, and documents re-authentication recovery.

## Best Possible Solution

Keep terminal failures from producing an unbounded retry storm, but add a durable re-authentication recovery path that replays history from the preserved cursor immediately after credentials become usable, and prove both the terminal and recovery paths against a real setup.
