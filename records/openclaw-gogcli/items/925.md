## Risks / Open Questions

- A recursive mutating command needs a precisely ordered preflight phase so duplicate names, wrong remote types, symlinks, and inaccessible descendants cannot leave a partially updated tree before a deterministic error.
- Checksum behavior must define files without `md5Checksum`, Google-native items, concurrent remote changes, pagination, and shared-drive edge cases before the CLI contract is stable.
- Live validation requires a disposable Drive hierarchy covering create, unchanged, replace, ambiguity, dry-run, and shared-drive cases; unit tests alone cannot establish safe reconciliation behavior.
