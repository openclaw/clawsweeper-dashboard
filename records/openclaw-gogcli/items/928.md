## Summary

Keep this issue open for a maintainer product decision. Current main has separate Photos and encrypted account-backup surfaces but no Takeout or Data Portability command, and Google’s complete current Data Portability scope list does not include Google Photos; however, Takeout supports Photos archives, scheduled exports every two months for one year, and Drive delivery, leaving a meaningful narrower ingestion workflow to evaluate. ([developers.google.com](https://developers.google.com/data-portability/user-guide/scopes?hl=en))

## What This Changes

Explore an official, automatable Google Photos backup workflow through Data Portability, Takeout orchestration, or verified ingestion of Drive-delivered Takeout archives.

## Best Possible Solution

Publish a feasibility document first, then favor a narrow, composable Takeout-ingestion command that discovers user-created Drive deliveries, resumes downloads, records processed archive identity, verifies completion, and never deletes remotely by default; pursue a Data Portability command only if Google adds an official Photos resource and maintainers accept its OAuth obligations.
