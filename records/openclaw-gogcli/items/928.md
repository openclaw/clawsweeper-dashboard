## Summary

Keep this issue open for an explicit product and security decision. Current main provides separate Photos Library, Photos Picker, Drive, and encrypted account-backup primitives, but no Takeout or Data Portability workflow; the proposed feasibility document remains useful because full-library export, Drive-delivered archive ingestion, and recurring backup have materially different API and authorization boundaries.

## What This Changes

Explore an official, automatable workflow for complete Google Photos backups through Data Portability, Takeout, or Drive-delivered archive ingestion.

## Best Possible Solution

Start with a feasibility and threat-model document; if maintainers approve implementation, prefer a narrow Drive-delivered Takeout ingestion primitive that resumes downloads, verifies integrity, records processed archives, and never deletes remote or local data by default.
