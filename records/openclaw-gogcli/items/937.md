## Summary

## What This Changes

This PR changes Gmail dry-run summaries to report exact byte lengths for compose bodies, HTML bodies, and forwarded-message notes, including trailing newlines, and adds regression coverage for file-backed inputs.

## System Context

Gmail compose commands load inline or file-backed body content, then either submit it to Gmail or emit a parseable dry-run request summary. This change affects only the summary’s length metadata, so operators can verify that the bytes supplied through file flags are preserved consistently before a mutation is made.
