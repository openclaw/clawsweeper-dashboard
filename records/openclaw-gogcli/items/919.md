## Summary

## What This Changes

Adds `--inline` base64 and `--text` extraction modes to Gmail attachment downloads, including metadata fallback, size limits, parseable plain output, tests, docs, and a PDF parser dependency.

## Best Possible Solution

Land the proven `--inline` mode independently, and add `--text` only with an execution boundary that can terminate timed-out parser work or after maintainers explicitly accept the residual in-process risk.
