## Summary

## What This Changes

Make Linux Tailscale setup detect BackendState correctly and automatically join with `tailscale_authkey`, while retaining manual instructions when no key is supplied.

## Best Possible Solution

Land one narrow fix that treats only `BackendState == "Running"` as connected, invokes `tailscale up --authkey` under `no_log: true` when needed, verifies the resulting state, and shows manual instructions only without a key; keep Tailscale SSH enablement as a separate explicit decision.
