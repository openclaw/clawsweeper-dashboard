## Summary

Keep this PR open for human review: it introduces a useful NetBird provider option, but it silently disables existing `tailscale_enabled: true` installations and its auth-key join condition still skips the normal unauthenticated Tailscale state. The PR also needs inspectable after-fix proof from a disposable Linux host before merge.

## What This Changes

This PR replaces the legacy Tailscale toggle with a `vpn_provider` selector, adds NetBird installation and setup-key joining, and adds a Tailscale auth-key join task plus conditional VPN sudoers.

## Best Possible Solution

Preserve the legacy Tailscale setting through a documented migration or compatibility mapping, determine Tailscale connection state from `BackendState`, and merge NetBird only after maintainers approve the provider/security boundary and a redacted disposable-host run proves install, join, idempotency, firewall behavior, and scoped sudoers.
