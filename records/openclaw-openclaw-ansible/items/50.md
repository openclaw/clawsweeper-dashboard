## Summary

Keep open for maintainer product-direction review: current `main` still always installs `openclaw@latest`, while this PR adds a tested and documented opt-in exact-version pinning contract; no concrete patch defect remains in this review cycle.

## What This Changes

Adds an `openclaw_version` release-mode variable, validates it as a safe dist-tag or exact version, skips reinstalling an already installed exact pin, handles development-to-release binary provenance, and documents the configuration.

## Best Possible Solution

Adopt version pinning as an opt-in release-mode setting with `latest` retained as the default, document the update responsibility of pinned operators, and preserve the tested development-to-release provenance guard.
