## What This Changes

The PR adds an `openclaw_version` release-mode variable for validated npm dist-tags or exact OpenClaw versions, skips reinstalling a matching pnpm release pin, cleans development-mode binary shadows, and documents the behavior.

## Best Possible Solution

Formally support exact release pins as an opt-in release-mode setting, retaining `latest` as the default and documenting that pinned fleets must choose and roll forward their own update cadence.
