## Summary

Keep this PR open: the auth-key/state-refresh work is useful and the previous prefs redaction concern is fixed, but the branch still has a merge-blocking operator overwrite/security-boundary issue and only mock/stub real-behavior proof.

## What This Changes

The branch parses Tailscale BackendState, uses `tailscale_authkey` for no-log auto-connect, refreshes state after connect, grants `openclaw` as Tailscale operator after user creation, and narrows serve-related sudoers entries.

## Best Possible Solution

Keep the auth-key and BackendState repair, but preserve existing Tailscale operators by default or require an explicit opt-in before transfer, then merge only after redacted live Debian/Ubuntu Tailnet proof covers fresh install and upgrade paths.
