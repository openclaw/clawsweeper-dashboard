## Summary

Keep this PR open: it addresses two real Tailscale gaps, but its operator task can silently replace an existing Tailscale operator and the supplied evidence still lacks a real Linux/Tailnet after-fix run.

## What This Changes

The branch wires `tailscale_authkey` into Linux setup, derives connection state from `BackendState`, and grants the OpenClaw service user Tailscale operator permissions for serve mode.

## Best Possible Solution

Preserve a nonempty existing Tailscale operator by default, set `openclaw` only when no operator is configured or through an explicitly approved override, then provide redacted live Linux proof for first join, serve, and rerun idempotency.
