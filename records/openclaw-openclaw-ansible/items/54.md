## Summary

The central auth-key bug is still present on current main, so this PR remains necessary. However, both prior blocking findings remain unchanged on the same reviewed head, and the claimed live Debian validation still has no inspectable artifact.

## What This Changes

The branch derives Linux Tailscale connection state from `BackendState`, auto-joins with `tailscale_authkey`, suppresses manual instructions when a key is present, and adds configurable Tailscale SSH enabled by default.

## Best Possible Solution

Land the focused auto-connect fix with explicit BackendState handling, reconnect Stopped nodes without an auth key, keep Tailscale SSH opt-in by default, and require redacted live-host proof for fresh-join and upgrade/rerun paths.
