## Summary

This PR remains useful and has convincing local-run proof, but the unchanged head still bypasses the adapter verifier for memory, session, cron, and other state queries, so capable non-OpenClaw adapters can fail through the gateway-only verifier path. The previously reported blocker remains unresolved and should be fixed before merge.

## What This Changes

The branch makes registered non-OpenClaw adapters executable through the generic harness, adds local Hermes configuration and workspace-scoped prompt guidance, and expands harness and Hermes tests.

## Best Possible Solution

Use one adapter-aware verification path: keep deterministic workspace checks local, route canonical state queries through `AgentAdapter.verify_state_query`, translate `StateQueryResult` into verifier outcomes, and add coverage proving both supported and capability-missing behavior without changing OpenClaw scoring.
