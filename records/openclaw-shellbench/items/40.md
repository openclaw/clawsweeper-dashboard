## Summary

Keep this PR open. The dependency refresh has useful validation and green checks, but the MLflow 2.21.3→3.14 deployment-default change is only proven against a fresh server; it needs upgrade-path evidence before a Kubernetes deployment can safely roll existing tracking data forward.

## What This Changes

The branch raises Python dependency floors, updates four GitHub Actions workflow references, changes the default Kubernetes MLflow image to v3.14.0, and fixes Ruff import ordering in two task verifiers.

## System Context

ShellBench packages a Python benchmark and deploys an optional MLflow tracking service to Kubernetes. Dependency metadata feeds local installs and CI, while the MLflow image default feeds the deployment script and Kubernetes manifest used by operators.
