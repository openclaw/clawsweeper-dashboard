## Summary

Keep this PR open for maintainer review. The branch has focused coverage and green CI, but it changes the benchmark’s eligibility policy so a run with pre-agent infrastructure failures can still qualify for the leaderboard; that audit-policy choice needs explicit maintainer confirmation. The author is a repository member, so this cleanup workflow should not auto-close it.

## What This Changes

The PR archives complete OpenClaw and Hermes sessions, exports their native events as Harbor-compatible ATIF-v1.7 trajectories, recovers active fleet leases, and separates the benchmark judge’s reasoning effort from the agent’s setting.

## System Context

ShellBench’s native-evaluation runner launches agent harnesses through a fleet controller, captures session artifacts, converts them into scored trajectories, and aggregates them into leaderboard eligibility. This PR changes the capture and conversion path, then changes the aggregation and proxy configuration that determine whether a completed run is comparable and eligible.
