Keep this issue open because current main has no per-crawler Codex or Claude bundles, and the discussion explicitly leaves their contents, ownership, and publishing model undecided. ## What This Changes

Create per-crawler Codex and Claude plugin bundles combining native crawler operations with higher-level workflow skills.

## Best Possible Solution

Define and prototype one bundle in each relevant downstream crawler, publish through the appropriate assistant marketplaces, and move only a proven provider-neutral manifest or shared workflow convention into crawlkit after at least two apps demonstrate the same need.
