## Summary

Keep this open for a maintainer product decision. Portable skills already cover several crawlers, but the issue intentionally leaves the complete crawler set, bundle contents, marketplace targets, and standardization scope undefined; crawlkit policy also places crawler-specific workflows in downstream apps rather than this shared Go library.

## What This Changes

Requests per-crawler Codex and Claude plugin bundles combining native crawler actions with higher-level workflows.

## Best Possible Solution

Define a small cross-crawler bundle checklist, then let each downstream crawler own an AgentSkills-compatible skill or plugin with metadata, binary requirements, permissions, secrets/config guidance, installation and update documentation, examples, and smoke proof; add crawlkit APIs only when at least two apps demonstrate the same missing reusable primitive.
