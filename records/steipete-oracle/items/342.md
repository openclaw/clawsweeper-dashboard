## Summary

Keep this PR open: it correctly identifies an adjacent browser-selection gap, but the new mapping collapses the requested GPT-5.6 Sol Pro target to the generic label `Pro`, so selection can be verified without establishing that GPT-5.6 Sol is active.

## What This Changes

This PR adds `gpt-5.6-sol-pro` as a browser-selectable target and changes GPT-5.6 Sol picker checks so ChatGPT’s separate Pro effort control can be selected and verified.

## System Context

Oracle converts a CLI model request into labels for ChatGPT’s signed-in browser picker, then validates the composer state before sending a prompt. The affected path covers model-name parsing, browser label mapping, picker interaction, and post-selection verification.
