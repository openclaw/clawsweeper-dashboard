## Summary

Keep this PR open: the patch is focused, matches the source-level root cause, and has no concrete correctness finding, but this external browser-lifecycle change still needs after-fix proof from a real `oracle serve` setup before merge.

## What This Changes

The PR separates shared Chrome process retention from completed run-tab cleanup so manual-login service requests close their own successful tabs while preserving explicit keep-browser, attached-tab, and recovery behavior.

## Best Possible Solution

The final behavior should keep one authenticated service Chrome process reusable across requests, close only successfully captured tabs created by that request, and retain explicit keep-browser, attached-existing, failed, and reattachable tabs.
