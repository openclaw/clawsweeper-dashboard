Remove the specialized option or replace it with repository-neutral, configurable semantics and tests.
  - confidence: 0.99

  - body: The common option promises to restrict findings to one repository, but the runner consults it only in action mode. Listing or inspecting with `--repo` therefore returns unrestricted data without warning. Either filter and validate list/detail results too, or expose this option only on the action command with an action-specific description.
  - confidence: 0.97
