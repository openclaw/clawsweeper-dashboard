## What This Changes

Add a browser startup step that normalizes new ChatGPT Work sessions to Chat while preserving explicit Work-conversation resume semantics.

## Best Possible Solution

Land a reviewed guard in the shared browser startup boundary that detects exact mode signals, safely resets non-resume Work attachments, refuses to abandon explicit resumed conversations, and remains compatible with layouts lacking those signals.
