## Summary

Keep open: current main and the latest release still only treat exact tool-only Deep Research captures as recoverable, so the reported structured `Deep Research App` wrapper can still fall through to saved-log replay instead of completed-session reattach.

## What This Changes

The issue asks Oracle to recognize structured ChatGPT Deep Research App tool-call wrapper captures as incomplete so `oracle session <id> --render` live-reattaches and recovers the completed report instead of replaying wrapper text.

## Best Possible Solution

Broaden the shared Deep Research incomplete-capture detector to recognize structured tool-call wrappers, reuse it consistently across session replay and browser status/report filtering, and cover the new wrapper plus false-positive guards in focused tests.
