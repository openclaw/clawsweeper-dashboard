The branch updates Oracle’s signed-in ChatGPT browser automation so GPT-5.6 Sol maps `--browser-thinking-time heavy` to a standalone `Pro` effort control, with fixture coverage for selected and unselected Pro rows.

## System Context

Oracle’s browser engine maps CLI model and thinking-time requests onto controls in the ChatGPT composer. It inspects the combined intelligence picker, selects or verifies the requested effort, then submits the prompt and reports the resolved browser state.
