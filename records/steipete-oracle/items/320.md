## Summary

Keep open: the focused patch has strong live proof for the Sol-plus-Pro state, but it regresses the established effort contract by accepting a carried-over Pro pill even when the request did not explicitly ask for Pro effort. That can silently submit a base Sol request at Pro effort, so a narrow repair is needed before merge.

## What This Changes

Updates browser model-selection matching and regressions so GPT-5.6 Sol is accepted when ChatGPT exposes Sol separately from a Pro effort pill.

## Best Possible Solution

Preserve Sol-plus-Pro compatibility only when Pro was explicitly requested, and otherwise use the existing browser effort-selection path to clear or replace a carried-over Pro pill before confirming base Sol.
