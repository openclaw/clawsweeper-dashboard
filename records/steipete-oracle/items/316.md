## Summary

This is a focused, well-proven compatibility enhancement, but the conversation classifier misses Oracle’s supported project URLs, so attached Work conversations inside a configured project can still bypass normalization.

## What This Changes

Adds browser startup detection and normalization for ChatGPT Work-mode pages and attached Work conversations before normal Chat model selection and submission.

## Best Possible Solution

Make conversation detection project-aware by matching the current conversation ID and active history href regardless of path prefix, then add root and project conversation tests while retaining trusted clicks, older-layout fallback, and explicit-resume fail-closed behavior.
