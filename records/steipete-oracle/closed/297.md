## Summary

Keep open: current main still only treats exact tool-only Deep Research captures as recoverable, so the reported multi-line "Deep Research App" wrapper can still replay stale session output instead of triggering live reattach.

## What This Changes

Placeholder-capture detection should recognize the structured ChatGPT "Deep Research App" wrapper so completed deep-research sessions can live-reattach instead of replaying stale wrapper text.

## Best Possible Solution

Broaden the shared Deep Research incomplete-capture detector to recognize structured tool-call wrappers, reuse it consistently in session replay and browser filtering, and add focused false-positive regression coverage.
