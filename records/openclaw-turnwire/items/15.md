## What This Changes

The PR makes Turnwire’s CLI return success when a downstream command closes an output pipe early, ignores Unix SIGPIPE so that behavior is reachable, and adds focused writer tests.

## System Context

Turnwire’s CLI initializes Unix signal behavior at process startup and uses shared output helpers for command responses such as help and version text. Shell pipelines consume those streams, and may close them before the command finishes writing.
