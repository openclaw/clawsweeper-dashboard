## What This Changes

The PR changes shared CLI output handling to treat broken stdout pipes as successful termination and adds tests for pipe versus non-pipe write errors.

## System Context

Turnwire commands send version, help, and other text through a shared CLI output helper. The helper writes to stdout and decides whether the command returns success or a shell-visible error.
