## What This Changes

The branch adds a React SDK server evaluator plus optional `initialValues` bootstrap support so server-rendered feature variants remain stable through hydration until a browser refresh completes.

## System Context

Krillswitch’s React SDK turns an application-owned typed flag manifest into hooks and a provider that refreshes remotely evaluated values. This change adds a server-side evaluation path that feeds initial values into the provider before the existing browser cache, polling, ETag, and persistence flow resumes.
