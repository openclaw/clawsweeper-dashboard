## What This Changes

Adds a 202-line GitHub Actions workflow that dispatches Crabpot issue, pull-request, and command-comment events to ClawSweeper using an optional GitHub App token.

## System Context

The workflow sits at Crabpot’s GitHub event boundary. It filters repository activity, creates a narrowly scoped token when configured, and sends event metadata to the central ClawSweeper repository for review handling.
