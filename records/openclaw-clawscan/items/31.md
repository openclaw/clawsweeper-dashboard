## What This Changes

The PR redacts values of environment variables explicitly declared by a user-defined scanner from that scanner’s failed-command error text while leaving scanner JSON evidence unchanged.

## System Context

User-defined scanner profiles declare command environment-variable names, then the runner executes the scanner and records a result artifact. On command failure, this change sanitizes the human-readable error before it is stored, while raw JSON stdout remains the scanner’s unmodified evidence.
