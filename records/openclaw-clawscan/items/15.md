## Summary

This PR remains necessary because current `main` still documents and implements skill-only target handling, while the proposed plugin support would add a useful missing capability. The remaining blocker is compatibility: the PR rejects JSON5-only `openclaw.plugin.json` files even though OpenClaw’s manifest loader uses a JSON5 fallback, so valid OpenClaw plugins can fail before any scan runs.

## What This Changes

The PR adds explicit OpenClaw plugin targets, plugin-aware scanner capability gating and artifacts, full ClawHub-profile handling, deterministic VirusTotal plugin archives, judge context, documentation, and regression coverage.

## Best Possible Solution

Match OpenClaw’s JSON5-compatible manifest acceptance for explicit plugin targets, retain the existing symlink and size protections, and add fixture coverage for comments and trailing commas before landing.
