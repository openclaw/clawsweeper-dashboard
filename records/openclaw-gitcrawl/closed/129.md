## Summary

## What This Changes

The PR makes failed reset/pull repair of a portable-store checkout escalate to the existing reclone fallback, records a 15-minute reclone-attempt backoff, and adds regressions for corruption and missing-source recovery.

## System Context

Portable-store refresh reads a Git-backed source database into a runtime mirror used by the CLI. A corrupt checkout or missing source database enters a repair path, which may reclone the checkout while retaining a healthy mirror as a fallback.
