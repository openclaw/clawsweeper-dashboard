## What This Changes

This PR replaces Gitcrawl’s local and repository-specific release workflows with the shared OpenClaw Go CLI release pipeline, while preserving the documented archives, checksums, macOS identity, and Homebrew publication path.

## System Context

Gitcrawl’s release path takes a signed version tag and produces platform archives, checksums, signed/notarized macOS binaries, a GitHub Release, and a Homebrew update. This PR moves that privileged publication path into a reusable workflow hosted in the shared OpenClaw release-workflows repository.
