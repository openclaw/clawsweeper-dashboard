## System Context

`fill-pr-details` hydrates pull-request details into gitcrawl’s local database and emits a JSON summary for automation. The database runtime may write directly to a local database or to a portable-store runtime mirror, so the emitted target metadata lets downstream pipelines verify the destination they actually used.
