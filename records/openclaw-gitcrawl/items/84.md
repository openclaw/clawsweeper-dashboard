## Summary

Keep open: current main and v0.7.1 still lack a durable per-item sync/hydration failure ledger, while the proof-backed closing implementation at https://github.com/openclaw/gitcrawl/pull/90 remains open and conflicting. The issue should remain paired with that PR until maintainers accept or revise its compatibility-sensitive schema and JSON contract.

## What This Changes

Persist queryable sync and hydration failure attempts, distinguish them from unattempted data, and mark failures resolved after successful retries.

## Best Possible Solution

Rebase the linked implementation onto the current hydration-observation model, preserve legacy read-only archive compatibility, intentionally approve the stored and JSON contracts, and close this issue when that PR merges.
