- **[P2] Ignore stale rate-limit cache entries before stopping:** `internal/cli/app.go:2782-2784`
  - body: The reserve check stops whenever the cached quota has `Remaining <= reserve`, but `currentFillRateLimit` returns shared cache state without checking whether `reset_at` has passed or the cache is old. Please ignore expired/stale cache state or refresh quota before enforcing the reserve.
