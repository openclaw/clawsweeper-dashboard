## Best Possible Solution

## Solution Assessment

Yes, if `release-mac-app` is the supported shared helper name: changing both automatic lookup locations and the README is the narrowest fix. The safer compatibility variant would search `release-mac-app` first and keep `mac-app-release` as a legacy fallback.
