## Summary

Current main still reproduces the reported cross-cutting error conversion: bridge operation failures can be wrapped with a generic primary message and then emitted as UNKNOWN_ERROR. The issue is a valid focused bug, and its collaborator authorship also requires it to remain open for maintainer handling.

## What This Changes

Propagate actionable bridge operation error codes and messages to the CLI instead of replacing them with generic UNKNOWN_ERROR failures.

## Best Possible Solution

Preserve each operation’s actionable message as the bridge envelope’s primary message and map stable bridge classifications to existing CLI codes, retaining details, permission, kind, context, and completion uncertainty as supplemental diagnostics.
