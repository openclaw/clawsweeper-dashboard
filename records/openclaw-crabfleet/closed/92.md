## What This Changes

The PR makes card-run completion update `run_attempts` only from permitted pre-terminal states and writes its audit event in the same guarded D1 batch, with real-Miniflare-D1 regression coverage.

## System Context

The Worker’s card lifecycle advances a card’s run when an operator moves it to Done, Human Review, or Backlog. That completion write shares the persisted `run_attempts` record with timeout reconciliation, and it emits an audit event consumed by the card activity history.
