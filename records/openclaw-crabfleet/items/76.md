## Summary

This is a necessary security hardening follow-up with strong proof, but one blocking archive-refresh defect remains: a repaired D1 row can return successfully while the existing credential-bearing R2 archive is left unchanged until a later finalizer retry.

## What This Changes

The PR restricts terminal structured events to exact replays, redacts credentials before D1/R2 persistence, repairs legacy rows, preserves legacy summary anchors, and adds focused tests and documentation.

## Best Possible Solution

Force archive replacement specifically when a legacy credential-bearing row is repaired, retain the durable pending-finalization fallback, and add a regression test with an already-current same-count archive to prove the obsolete R2 objects are replaced before returning.
