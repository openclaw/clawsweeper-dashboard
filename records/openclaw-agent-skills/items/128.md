## Summary

Keep this PR open for a security-boundary decision and a patch revision: decoding confirms renderable pixels, but it does not make all data carried by a WebP container reviewable. The current autoreview behavior deliberately rejects tracked binary diffs rather than silently omitting them, so the proposed exemption weakens that fail-closed boundary.

## What This Changes

The PR permits validated tracked WebP files to be omitted from autoreview source bundles while including their metadata, and preserves rejection for invalid, oversized, or other binary files.

## Best Possible Solution

Keep tracked binary diffs fail-closed unless maintainers approve an asset-review design that makes every accepted container payload inspectable or explicitly separates binary-asset review from source-diff approval.
