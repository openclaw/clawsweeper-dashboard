Keep this issue open for a narrow, language-aware correction; accepting every bare identifier globally could weaken scanning of YAML and other unquoted configuration formats.

## What This Changes

Prevent autoreview from rejecting TypeScript secret assignments whose values are identifier or member-expression references rather than embedded credentials.

## Best Possible Solution

Make reference recognition source-language-aware: accept syntactically bounded identifiers and member/index expressions in JavaScript and TypeScript diff sections, retain fail-closed handling for unquoted configuration values and ambiguous expressions, and add positive and adversarial regression cases.
