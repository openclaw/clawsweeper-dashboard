## Summary

Keep open: the scanner behavior remains present at the reviewed main SHA, and the report gives a precise source-reproducible example of safe TypeScript references causing branch review to fail closed. The bug warrants a narrow correction, but the scanner’s credential-protection boundary needs to remain intact.

## What This Changes

Prevent the autoreview secret scanner from refusing branch-review bundles when credential-named properties contain ordinary TypeScript identifier or member-expression references.

## Best Possible Solution

Make safe-reference recognition context-aware: accept syntactically valid identifier and member-expression values in code assignments while preserving fail-closed detection for quoted literals, token formats, URI credentials, and ambiguous unquoted configuration values, with positive and negative regression cases.
