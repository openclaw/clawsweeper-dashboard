## What This Changes

This PR validates the authenticated Bird account before collection sync writes, adds structured web-sync logs and new-item counts, and introduces `BIRDCLAW_WEB_SYNC_MODE` to select Bird or Xurl transport.

## System Context

Birdclaw’s web-sync dispatcher runs live timeline, mention, collection, and message fetches through Xurl or Bird adapters and persists their results to the local SQLite store. The changed code selects the adapter, verifies the account before collection writes, and reports each job outcome to the service operator.
