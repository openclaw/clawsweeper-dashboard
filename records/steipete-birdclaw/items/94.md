Keep open for maintainer review: current main still hardcodes `/bin/bash`, and this PR addresses the Windows shell problem with focused tests and sufficient Windows smoke proof, but the new shell override needs an explicit support/documentation decision before merge.

## What This Changes

The PR replaces the bird stdout redirect wrapper’s hardcoded `/bin/bash` with a Windows-aware Git Bash selector, adds a `BIRDCLAW_BASH_COMMAND` override, and adds focused unit coverage.

## Best Possible Solution

Merge the Windows-aware shell selector after maintainers either document `BIRDCLAW_BASH_COMMAND` as supported config or remove the override and keep automatic Git Bash discovery only.
