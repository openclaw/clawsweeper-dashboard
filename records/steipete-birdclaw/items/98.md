## Summary

Current main does not import third-party passive-capture formats. The request fits Birdclaw’s local-first direction, but it introduces permanent source-provenance, account-binding, collection-completeness, backup, and format-support contracts that require maintainer approval before implementation.

## What This Changes

Add an idempotent CLI importer that normalizes Scrollmark and twitter-web-exporter captures into Birdclaw’s canonical local store.

## Best Possible Solution

Start with versioned Scrollmark canonical bundle v1 only, represent capture provenance and partial completeness explicitly, create account-scoped edges only from proven semantics, include the new metadata in backup round-trips, and add legacy formats later through separately validated adapters.
