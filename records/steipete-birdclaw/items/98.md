## Summary

Keep this issue open: current main has no passive-capture importer, and the idea fits Birdclaw’s attributable local-data vision, but its initial source and provenance contracts require maintainer product direction.

## What This Changes

Add idempotent imports for Scrollmark and twitter-web-exporter files into canonical tweets, profiles, account-scoped edges, FTS, and media metadata.

## Best Possible Solution

Start with validated Scrollmark canonical bundle v1, additive entity upserts, explicit partial-membership semantics, and durable provenance included in backups; defer legacy and twitter-web-exporter adapters until that contract is proven.

- **Keep current sources only:** Continue supporting official archives, Birdclaw backups, and live transports without establishing a third-party capture contract.
