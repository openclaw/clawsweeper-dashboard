Add an idempotent CLI importer for Scrollmark and twitter-web-exporter captures that normalizes supported records into Birdclaw’s canonical local store.

## Best Possible Solution

Start with a version-pinned Scrollmark canonical bundle importer that reuses existing canonical repositories, records explicit import provenance and partial-completeness metadata, and defers legacy auto-detection until representative fixtures establish stable mappings.
