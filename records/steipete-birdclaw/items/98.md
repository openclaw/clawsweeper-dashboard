## Summary

Current main still supports only official archive, backup, and live-transport ingestion. The request is directionally aligned with Birdclaw’s local-first data model, but maintaining compatibility with external producer schemas requires an explicit owner decision before implementation.

## What This Changes

Add an idempotent CLI import path for Scrollmark and twitter-web-exporter captures into Birdclaw’s canonical local store.

## Best Possible Solution

Approve a Scrollmark canonical bundle v1 importer first, implemented as a source adapter into existing canonical repositories with explicit provenance, partial-completeness semantics, bounded ZIP validation, and deterministic reporting.
