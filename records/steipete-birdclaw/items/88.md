## What This Changes

This PR adds a `bird whoami` fallback to `import hydrate-profiles` that updates `acct_primary` and `profile_me` in local mode, parses display names, clears stale identity fields, and adds focused tests.

## Best Possible Solution

Land the focused explicit-command fallback if maintainers accept persisted bird-local identity hydration, while keeping startup free of automatic `bird whoami` side effects.

## Reproduction Assessment

## Solution Assessment

Yes, if maintainers accept the compatibility-sensitive persisted mutation: the fallback stays behind the explicit hydrate command, parses `bird whoami`, handles idful and idless identity changes, and adds focused tests. Startup auto-hydration should remain a separate product choice.
