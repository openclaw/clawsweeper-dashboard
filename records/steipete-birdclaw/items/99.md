## Summary

Keep this issue open for a maintainer product decision. Current main has no FxTwitter adapter, and the request fits Birdclaw’s vision for bounded, attributable live reads, but adopting a public third-party service and new configuration surface requires explicit sponsorship.

## What This Changes

Add an opt-in, read-only FxTwitter transport for public posts, threads, profiles, timelines, and search with explicit capability, privacy, persistence, and pagination boundaries.

## Best Possible Solution

If sponsored, deliver a staged core adapter beginning with explicit post, thread, profile, timeline, and search reads, strict capability gating, safe HTTPS base-URL validation, canonical persistence, source attribution, and recorded-fixture tests before expanding to social graphs or trends.
