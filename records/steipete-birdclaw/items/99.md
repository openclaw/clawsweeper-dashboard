## Summary

Keep this recent feature proposal open for repository-owner review. Current main does not provide FxTwitter support, and the proposal fits Birdclaw’s local-first multi-source direction, but adopting a third-party public service and defining configurable endpoint safety require explicit product and security approval.

## What This Changes

Add an explicitly selected FxTwitter transport for public post, thread, conversation, profile, timeline, and search reads with canonical persistence and capability-aware errors.

## Best Possible Solution

Adopt a narrow core MVP only after approval, keeping it explicit and read-only, forbidding automatic fallback, persisting normalized provenance and completeness metadata, and enforcing a reviewed endpoint and privacy policy.
