## What This Changes

Add an explicit, opt-in FxTwitter/FxEmbed read transport for public posts, threads, profiles, timelines, and search with capability, privacy, pagination, and self-hosting boundaries.

## Best Possible Solution

If core ownership is approved, begin with explicit post lookup and thread/conversation ingestion through the existing canonical models, require HTTPS and hardened base-URL validation, preserve source/completeness metadata, and add profiles or search only after the narrow adapter proves stable.
