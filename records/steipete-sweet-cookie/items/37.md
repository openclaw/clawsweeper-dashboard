It changes partial-success semantics by returning permission warnings from inaccessible Chromium roots even when another root supplies cookies, so a maintainer should confirm that caller-visible contract before merge. ## What This Changes

The branch preserves permission-denied warnings discovered while scanning Chromium profiles for macOS cookie reads and adds a regression test for all-profile discovery.

## System Context

The macOS Chromium provider discovers browser profile directories, finds cookie databases, and returns cookies to its callers. This change carries filesystem-access warnings from profile discovery into that result so callers can distinguish denied access from an absent database.
