- **[P1] Use an immutable image version for Helm upgrades:** `deploy/helm/reef-relay/values.yaml:5-6`
  - body: The default `latest` tag combined with `IfNotPresent` means `helm upgrade` does not change the Deployment pod template and even recreated pods may keep a cached image. Default the tag from a released chart/app version or require an immutable tag/digest and cover an upgrade rollout.
  - confidence: 0.98

  - body: Enabling forwarded-header trust for every default install lets the relay derive its rate-limit identity from headers without a configured trusted proxy boundary. Default this off or accept forwarded addresses only from explicit trusted proxy CIDRs or hops.
