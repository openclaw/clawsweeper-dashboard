## Summary

Current main still permits a sticky attention card to remain interactive indefinitely without validating that its visible content remains onscreen, so the reported click-blocking safety problem remains actionable despite the intermittent rendering trigger not being reproduced.

## Plan

Fix the existing macOS attention-card safety bug where an invisible, invalid, or offscreen card panel can remain topmost and intercept clicks. Preserve full-screen decorative border panels as click-through and preserve healthy sticky behavior when no duration is supplied. Enable mouse events only after the card has a valid frame intersecting a current screen and has been successfully presented; during display changes or presentation failure, immediately make the card click-through or close all attention panels. Add a visible menu-bar dismissal action, and coordinate any shared acknowledgement semantics with https://github.com/steipete/Nameplate/pull/24 if it remains open.
