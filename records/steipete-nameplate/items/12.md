## What This Changes

Extend remote-only overlay visibility to detect active sessions from proprietary remote desktop tools without treating an installed or idle client as a connection.

## Best Possible Solution

Add a redacted diagnostics export for connected and disconnected sessions, then implement only stable active-session signals in `NameplateCore` with positive, negative, and false-positive fixtures while retaining the existing VNC and virtual-display paths.
