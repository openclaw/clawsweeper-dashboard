## Summary

This request remains necessary: current main and v0.2.5 provide Linux tarballs but no Linux Homebrew formula, while the existing tap contains only a macOS cask. Keep it open for a maintainer decision because official Linuxbrew support creates an ongoing cross-repository packaging and dependency-maintenance commitment.

## What This Changes

Add a supported Homebrew installation and upgrade path for Nameplate on Linux.

## Best Possible Solution

Maintain a Linux formula in `steipete/homebrew-tap` that selects the versioned x86_64 or arm64 release archive, declares required GTK4/X11 dependencies, installs the binary, and adds source-repository documentation plus fresh-install and upgrade smoke verification.

## Risks / Open Questions

- The formula likely belongs in the separate `steipete/homebrew-tap` repository, so implementation and release automation must remain coordinated across repositories.
- A formula that installs the binary without correct GTK4/X11 dependencies could appear successful but fail at runtime.
- Using stable `releases/latest` URLs would weaken formula checksum and version semantics; the formula should use versioned per-architecture assets and be updated for each release.
