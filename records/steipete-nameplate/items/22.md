## Summary

Current main still permits a sticky attention card to remain interactive indefinitely without validating that its visible content remains onscreen, so the reported click-blocking safety problem remains actionable despite the intermittent rendering trigger not being reproduced.

## What This Changes

Prevent an invisible or invalid attention card from intercepting clicks and provide safe in-product dismissal or teardown recovery.

## Best Possible Solution

Keep healthy no-duration alerts sticky, enable card input only after valid onscreen presentation, immediately disable or close invalid attention panels, and provide a visible menu-bar dismissal action for recovery.
