## Summary

This request remains necessary: current documentation supports Linux only through direct tarball installation, while the existing Homebrew tap contains a macOS cask but no Linux formula. Adding and maintaining a new package-manager distribution surface needs explicit repository-owner direction, so the issue should remain open.

**Likely related people**
- `steipete` — medium confidence; repository owner and the clearest routing candidate for Nameplate releases and the associated Homebrew tap.

## What This Changes

Add Linuxbrew installation and upgrade support for Nameplate's Linux builds.

## Best Possible Solution

If approved, add a versioned `nameplate` formula to `steipete/homebrew-tap` for x86_64 and arm64 release tarballs, declare GTK4 requirements and graphical-session caveats, automate checksum/version updates from releases, document `brew install` and `brew upgrade`, and validate fresh installs and upgrades on Linuxbrew.
