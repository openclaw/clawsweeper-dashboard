## Summary

Keep open: current main still replaces the active archive during sync or snapshot restore and does not provide cumulative historical search or first-class isolated account profiles. The request combines two substantial storage-product decisions, so it needs maintainer direction before implementation.

## What This Changes

Requests isolated multi-account profiles and searchable, deduplicated cumulative history across current imports and older backup snapshots.

## Best Possible Solution

Define an explicit account/profile identity and append-or-upsert archive contract first, then preserve point-in-time backups while adding deduplicated cumulative search with documented migration and deletion semantics.

- Searching every encrypted snapshot instead of materializing a cumulative archive could create substantial checkout, decryption, indexing, and performance costs.
