## Label Justifications

- `P2`: This is a substantial archive-retention and account-isolation improvement, but the reported historical data remains recoverable from existing snapshots.
- `impact:data-loss`: Normal replacement imports can remove older messages from the active searchable archive when WhatsApp Desktop no longer exposes them.

## Summary

This remains necessary: current main intentionally replaces the active archive on each import and restores snapshots as separate point-in-time archives, so neither cumulative historical search nor first-class isolated accounts exists. The request combines two storage and UX directions that need an explicit maintainer decision before implementation.

## What This Changes

Add isolated WhatsApp account profiles and a deduplicated cumulative archive or cross-snapshot search for retained historical messages.

## Best Possible Solution

Approve a staged design: first define durable per-account archive/backup isolation, then add either a cumulative deduplicated archive or an explicit federated historical-search layer with migration and restore compatibility tests.
