## What This Changes

This PR replaces whitespace-delimited legacy dispatch parsing with NUL-delimited fields so issue events with no target branch resolve the target repository’s default branch instead of attempting to fetch branch `0`.

## System Context

The sweep workflow receives legacy repository-dispatch intake payloads, extracts the target repository, optional target branch, and source-authority flag, then admits the item to the review queue. The target branch determines which repository revision the queue worker fetches before it runs a review.
