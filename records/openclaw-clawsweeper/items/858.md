## What This Changes

This PR adds scrubbed telemetry that traces legacy exact-review publication batches from dispatcher reservation through workflow claim, state projection, and final GitHub application, while marking direct Cloudflare publication as outside that batch timing.

## System Context

Exact-review results are dispatched through a Durable Object queue and ordinarily published directly through the Cloudflare-canonical path, with a bounded legacy state-repository batch path available as fallback. This change records and returns timing data for the legacy path so operators can identify where a delayed batch is waiting without attributing those timings to direct publication.
