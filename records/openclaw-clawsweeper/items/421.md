## Summary

Keep open. Current main still represents real-behavior proof as a model/status verdict and close-safety checks trust the resulting label or report status; the requested reproduce-and-attest lane is aligned with ClawSweeper's proof goals but needs maintainer security-boundary approval.

## What This Changes

Request a default-off proof reproduction and attestation lane that reruns declared offline reproductions against base and head, records a head-pinned behavior delta, and later lets close-safety prefer valid attestations over model-derived proof labels.

## Best Possible Solution

Keep this issue as the canonical design thread and, if maintainers accept the direction, land a staged implementation that starts with schema and read-only attestation records before any close-safety trust change.
