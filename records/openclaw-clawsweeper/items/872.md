## What This Changes

This PR removes partial-clone recovery for state publishing, uses at most two ordinary `--deepen=512` fetches, records shallow-history exhaustion, and rebuilds from the remote head after a matching repeat.

## System Context

The state materializer drains generated review records and publishes them to the durable state repository. Before committing, the Git publisher fetches state history and tries to establish a merge base so it can reconcile the local working tree with the remote branch.
