## Summary

Keep this PR open: the main re-review ledger idea is useful and has solid proof, but the patch currently lets stale-head status comments become fake completed review-history cycles.

## What This Changes

The PR adds a bounded durable-comment review-history ledger, exposes prior review cycles to review context, and adds optional late-finding metadata through schema, report rendering, prompt policy, docs, and tests.

## Best Possible Solution

Land this after the history helper records only completed review verdicts, skips durable status comments such as stale-head notices, and has focused coverage for that edge.

## Reproduction Assessment

Yes, from source inspection: a stale-head durable comment starts with a `Codex review:` line and has only a `clawsweeper-review-status:stale` marker, while the new helper will turn that body into a cycle with `unknown` reviewedAt and sha. I did not execute it because this review is read-only.

## Solution Assessment

No, not yet: the ledger should preserve completed review cycles only, so status comments need to be filtered before conversion. Once that edge is fixed, the implementation path is narrow and consistent with existing durable comment rendering.
