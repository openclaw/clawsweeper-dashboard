## What This Changes

This PR extends durable cluster intake so the state materializer claims, authenticates, dispatches, recovers, and restores repair-planning jobs without duplicate planning runs.

## System Context

ClawSweeper’s repair intake pipeline turns selected issue clusters into durable state records, then starts planning workers that may propose focused repair PRs. This PR sits between the durable intake ledger and the worker workflow, carrying a validated job payload, capacity reservation, dispatch claim, and terminal worker outcome across that boundary.
