## What This Changes

The branch adds durable, authenticated, exactly-once dispatch and recovery for cluster repair jobs, including state-materializer logic, worker-workflow inputs, job restoration, and focused regression coverage.

## System Context

The repair cluster pipeline accepts candidate clusters into durable state, materializes them into worker jobs, and dispatches GitHub Actions planning workers. This PR changes the middle of that pipeline so dispatch claims, worker inputs, recovery, capacity reservations, and terminal results remain tied to the same durable job.

  Ledger --> Materializer[State materializer]
  Materializer --> Claim[Stable dispatch claim]
  Claim --> Worker[Planning worker workflow]
  Worker --> Verify[Verify job and result]
  Verify --> Result[Durable terminal result]
