## What This Changes

The branch neutralizes model-authored Markdown before it enters durable review reports and makes front matter authoritative when reading proof and PR-rating status.

## System Context

ClawSweeper converts model-produced review data into durable Markdown reports, then later reads those reports to determine labels, merge gates, and repair routing. Model prose enters the decision parser, report rendering writes trusted sections and front matter, and downstream automation consumes the parsed result.
