## What This Changes

This PR adds an opt-in Worker-backed snapshot-and-journal transport for hydrating generated state records, with Git retained as the default source.

## System Context

ClawSweeper workflows hydrate generated review records before review and apply jobs use them. This PR adds an optional path that reads per-repository snapshots and journal deltas from the authenticated dashboard Worker and its R2-backed snapshot store instead of the state Git checkout.
