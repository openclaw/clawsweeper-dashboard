## Summary

## What This Changes

This PR records durable published, superseded, and closed outcomes for exact-review publication revisions so repeat deliveries are no-ops while later revisions can still enter the queue.

## System Context

Exact-review publication receives review events, places them in a durable queue, and publishes the resulting review state. This change adds a terminal-outcome ledger between delivery intake and queue admission so a terminal revision is not published again.
