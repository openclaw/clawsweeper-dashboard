## Summary

Keep this PR open: it addresses visible review-comment clutter, but the cleanup is only attempted after a durable-comment write, so a transient cleanup failure can become permanent once later applies decide the durable comment is already synchronized.

## What This Changes

Adds a post-publish sweep for expired or legacy ClawSweeper review-start placeholder comments, with helper coverage and a changelog entry.

## Best Possible Solution

Run the stale-placeholder sweep independently of whether the durable review body needs rewriting, retain the existing lease and bot-author safeguards, add a retry-path regression test, and omit the release-owned changelog edit.
