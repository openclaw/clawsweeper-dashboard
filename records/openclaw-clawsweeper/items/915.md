## What This Changes

Adds the two scripts required by the shared state-setup action to the repair-comment-router and spam-scanner sparse checkouts, plus a workflow test that derives required relative script dependencies from that action.

## System Context

The comment router and spam scanner are GitHub Actions lanes that sparse-check out this repository before invoking the shared state-setup action. That action hydrates generated state used by command routing and spam triage, so missing scripts stop both lanes before their main jobs run.
