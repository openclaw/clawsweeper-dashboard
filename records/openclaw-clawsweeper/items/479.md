## Summary

The security design and exact-head workflow proof are strong, but the patch remains incomplete because model-generated assist or visual comments can still be accepted and dispatched by the fast webhook classifier before the later scheduled-router guard rejects them.

## What This Changes

The PR separates untrusted assist generation from a fresh narrowly credentialed publisher, adds strict bounded artifact and live-state validation, stabilizes idempotent publication, and adds assist/visual command-routing guards.

## Best Possible Solution

Reject assist and visual publication markers in the fast webhook classifier before command matching, retain the later router guard as defense in depth, and prove those comments produce neither acknowledgement nor workflow dispatch.
