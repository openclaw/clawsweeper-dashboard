## Summary

The PR’s credential isolation, artifact binding, stale-state checks, and retry idempotency are strongly demonstrated, but the exact head still leaves the fast issue-comment webhook outside the new assist/visual publication guard. A marked bot publication containing command-like text can therefore receive an acknowledgement and launch a command-router run before the later scheduled-router guard drops it, so the stated categorical no-routing boundary is not yet complete.

## What This Changes

The branch separates untrusted assist generation from trusted comment publication, introduces a strictly validated bounded artifact and fresh narrow publisher token, stabilizes retry identity, and adds assist/visual command-routing guards.

## Best Possible Solution

Reject assist and visual publication markers in the fast webhook classifier before command matching, retain the later router guard as defense in depth, and prove those comments produce neither acknowledgement nor workflow dispatch while preserving the live-proven publisher isolation.
