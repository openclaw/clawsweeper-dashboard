## Repair Work Prompt

Fix the PR interference radar containment bug in https://github.com/openclaw/clawsweeper/pull/433. In `src/pr-interference.ts`, make containment conservative: if either side of a compared same-path file has `line_ranges: null`, containment must not report `a_within_b`, `b_within_a`, or `equal`; it should stay `none` unless both sides have comparable line ranges and every inner range is covered. Add focused regression coverage in `test/pr-interference.test.ts` for opaque-vs-line and opaque-vs-opaque same-path overlaps. Do not change the workflow publishing policy, dashboard layout, schema version, or CHANGELOG.md. Validate with `pnpm run check` on Node 24 or newer.
