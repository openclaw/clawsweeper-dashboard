## What This Changes

The PR adds a `CLAWSWEEPER_MODEL_COMMAND` env override before `CODEX_BIN` in Codex command selection and adds codex-process tests for argv/stdin preservation.

## Best Possible Solution

Make the override bypass later `CODEX_BIN` re-resolution, document the precedence and argv/stdin contract next to existing Codex execution settings, and merge only after maintainer approval plus real behavior proof.

## Reproduction Assessment

Yes. Source inspection is enough to reproduce the precedence issue: `codexSpawnInvocation` passes the selected command through `resolveSpawnCommand`, whose `resolveCommand` step can still apply `CODEX_BIN` when the selected model command is `codex`.

## Solution Assessment

No. The command hook is a narrow direction, but the implementation should first make precedence exact, document the new env var, and provide real external-worker proof rather than relying only on unit-test output.
