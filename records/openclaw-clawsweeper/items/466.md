## Summary

This proposal remains necessary: current main binds ClawSweeper’s generated review to the live PR head, but contributor proof still arrives as free-form context without deterministic evidence-head metadata. The narrow parser boundary fits the project’s proof-quality direction, while the permanent contributor-facing input contract needs maintainer approval.

## What This Changes

Accept one optional, bounded `clawsweeper-proof` JSON block in a PR description and normalize its claimed head and evidence metadata for review without treating it as authoritative proof.

## Best Possible Solution

Add the parser only after surface approval, keeping it in a narrow module that emits bounded normalized context with explicit current-head, stale-head, or invalid status and cannot change proof sufficiency, labels, gates, comments, or artifact fetching.
