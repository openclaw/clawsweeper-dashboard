## System Context

ClawSweeper receives issue, pull-request, and maintainer-comment events from configured target repositories, generates durable reviews, and records target status in its dashboard/state flow. An official target profile supplies repository-specific validation and review policy, while the target repository dispatcher forwards events into that review pipeline.
