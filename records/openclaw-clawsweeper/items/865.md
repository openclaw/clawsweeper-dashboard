## Summary

Keep this PR open for human merge review. The patch is narrowly targeted and aligns with the documented production 403 pattern, but the available after-fix probe uses a fine-grained personal token rather than the repository’s GitHub App installation token; an in-org reconciliation run against a pull request should confirm the exact workflow path before merge.

## What This Changes

This PR grants the reconciliation workflow’s target-repository token pull-request write access, alongside issue write access, so stranded pull requests can receive the recovery label, and updates the workflow assertion accordingly.

## System Context

The exact-review reconciliation workflow scans target-repository items whose review-started placeholder was never replaced by a published review. It obtains a scoped GitHub App token, then uses it to apply a recovery label so operators can identify stranded reviews across both issues and pull requests.
