## Summary

Keep open: the durable recovery direction is useful, but this head removes the existing exact-review `workflow_dispatch` fallback and needs either a migrated fallback or an explicit maintainer decision to fail closed.

## What This Changes

The PR changes command dispatch recovery for review, assist, and repair workflows by adding deterministic receipt keys, durable claim recovery, receiver-side duplicate gates, and focused tests.

## Best Possible Solution

Preserve the existing fallback by giving `workflow_dispatch` the same deterministic dispatch key and recoverable run title, or get explicit maintainer approval that exact-review commands should fail closed when `repository_dispatch` cannot be created.

## Reproduction Assessment

Yes. Source inspection shows current main dispatches exact reviews via `repository_dispatch` and falls back to `workflow_dispatch` on failure, while the PR head throws on that same failure path after writing the durable claim.

## Solution Assessment

No. The durable receipt direction is reasonable, but removing the fallback is not the narrowest safe fix unless maintainers explicitly choose fail-closed dispatch semantics.
