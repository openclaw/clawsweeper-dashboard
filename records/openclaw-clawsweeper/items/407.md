  - confidence: 0.93

  - body: When `dispatchClaimDecision()` says a stale claim should retry, this path returns to dispatch without writing a fresh claim because `claimDispatchCommands()` skips commands with any prior claim.   - confidence: 0.9

  - body: This recovers on any matching successful workflow run, but the new assist/repair receipt job can skip a duplicate with `proceed=false` and still make that workflow run succeed without running the assist or cluster worker. If the older real run later fails, a retry can recover the skipped duplicate and mark the command executed even though no worker completed.
