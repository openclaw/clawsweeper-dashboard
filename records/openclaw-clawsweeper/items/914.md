## Summary

## What This Changes

Repair the sparse checkout lists used by the repair comment router and spam scanner so the shared state-setup action receives every script it executes and imports.

## System Context

The repair comment router and spam scanner are GitHub Actions lanes that hydrate ClawSweeper state before routing comment commands or classifying reports. Each lane uses a sparse checkout of this repository, then passes that checkout to the shared state-setup action; missing action dependencies stop the lane before it can process work.
