## Summary

The PR presents a focused, well-evidenced fix for an exact-review queue item that otherwise retries indefinitely. Its attempt ceiling intentionally changes recovery behavior after sustained failures, so it should remain open for normal maintainer review rather than cleanup closure.

## What This Changes

This PR tracks failed exact-review completions separately and parks a review queue item after eight failures, reporting the parked reason through the item-status endpoint.

## System Context

The exact-review queue is ClawSweeper’s Durable Object-backed dispatcher for GitHub review work. Webhook decisions and explicit review commands enter the queue; it dispatches review runs, processes their completion callbacks, and exposes item status and recovery paths to operators.

## Best Possible Solution

Land a narrowly tested bounded-retry policy only if maintainers accept parking after eight failed review completions and the existing explicit re-review or verified-head paths as the recovery mechanism.
