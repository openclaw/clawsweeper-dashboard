## Summary

Keep this RFC open for an explicit maintainer architecture decision. The merged lease and priority work addresses the current Git-writer contention, but it does not decide whether durable-object materialization should replace that design; this proposal introduces a new internal state-write and migration model rather than a narrow bug fix.

## What This Changes

The issue proposes routing state writes through a single-writer Durable Object that batches and materializes them into the state repository, retiring Git lease-based coordination.

## Best Possible Solution

Approve a staged design with a bounded Durable Object append window, explicit push-before-ack recovery semantics, and a reversible lane-by-lane migration before removing the existing Git coordination path.
