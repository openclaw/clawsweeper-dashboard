## What This Changes

Adds bounded digest cursors for pull-request review activity and revalidates them before cached-review reuse, apply mutations, repair dispatch, and trusted automerge actions.

## Best Possible Solution

Land the bounded digest cursor as the common authorization-freshness contract, retain fail-closed handling for incomplete state, and sequence dependent repair and proof changes only after validating operational API load and legacy-verdict refresh behavior.
