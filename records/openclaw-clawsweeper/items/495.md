## Summary

The prior P1 blocker remains on the current head: pinned-base reproduction still symlinks the repaired checkout’s mutable `node_modules`, while the new guard detects only tracked manifest and toolchain changes. An ignored dependency mutation with unchanged manifests can therefore contaminate both validations and be misclassified as an external base blocker.

## What This Changes

The PR pins repair attempts to one base SHA, adds pinned-base validation reproduction and external-blocker classification, performs one final synchronized validation and review, updates repair documentation, and expands regression coverage.

## Best Possible Solution

Give pinned-base reproduction a dependency environment that cannot share mutable contents with the repaired checkout, or fail closed whenever that isolation cannot be proven, and add an unchanged-manifest ignored-dependency mutation regression.
