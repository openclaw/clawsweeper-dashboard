## Summary

The current head retains two concrete blockers: it can skip newly created report files and cannot authenticate the deploy runner’s cross-repository checkout. The isolation architecture is worthwhile, but this revision is not safe to merge until those paths and a real workflow run are fixed.

## What This Changes

The PR splits maintainer report generation, Git publication, and Cloudflare deployment into three isolated jobs, transfers reports through a bounded artifact, and adds static credential-boundary coverage.

## Best Possible Solution

Keep the three-runner secret isolation, but detect staged, modified, deleted, and untracked report changes; give deploy a job-local contents-read token for `openclaw/maintainers`; update the focused assertions; and prove both full and deploy-only workflows on the exact head.
