## Best Possible Solution

Land a narrower apply fix that ignores only the timeline duplicate for the command/comment already covered by the fresh review, keeps later re-review requests as activity, removes the CHANGELOG edit, and includes real apply-path proof.

## Reproduction Assessment

## Solution Assessment

No, not yet: the direction is narrow, but ignoring every timeline `commented` event for label reconciliation also ignores later command-only re-review requests that should make the stored review stale. The safer fix is to match or bound the duplicate event to the review being applied.
