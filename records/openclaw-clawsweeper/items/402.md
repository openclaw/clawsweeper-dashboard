## Best Possible Solution

Compute the candidate-quality mix after reconciliation from the same post-reconcile selector inputs used for apply selection, then rebase the branch and keep the telemetry reporting-only.

## Reproduction Assessment

## Solution Assessment

No. The bucket model is a reasonable direction, but the workflow should generate it from post-reconcile state before it is safe to merge.
