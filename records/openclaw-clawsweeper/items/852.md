## What This Changes

This draft PR removes the revision rebasing introduced by https://github.com/openclaw/clawsweeper/pull/851, returning existing exact-review items to local increment-only revisions and deleting the associated regression test.

## System Context

The exact-review queue receives repository events and commands, assigns a revision to each review cycle, and later hands its verdict to a durable publication queue. That publication queue rejects artifacts below the target’s recorded revision head, so revision assignment directly determines whether a review verdict can reach its final GitHub comment.
