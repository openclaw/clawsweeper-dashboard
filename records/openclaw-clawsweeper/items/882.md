## What This Changes

The branch adds a durable `cluster_intake` state-append kind and gives its coordinator requests bounded shared priority over ordinary state writers, with migration and fairness coverage.

## System Context

The repair cluster intake pipeline records selected repair-work clusters in durable state before later stack layers materialize and dispatch them. This PR changes the queue and coordinator that accept those state writes, affecting whether intake work is admitted promptly without starving ordinary publication and comment-routing writes.
