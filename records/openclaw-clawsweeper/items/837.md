## What This Changes

This PR makes the review-placeholder recovery sweep inspect older matching items before applying its check budget, select marker-tagged placeholder comments instead of the newest bot comment, report unexamined search matches, and expose recovery alert settings in the reconcile workflow.

## System Context

The exact-review reconciliation workflow periodically searches target repositories for ClawSweeper “review started” placeholders that should have been removed after a durable verdict is published. It selects a bounded set for comment inspection, queues or cleans confirmed stale placeholders, and reports recovery health back through the scheduled GitHub Actions job.
