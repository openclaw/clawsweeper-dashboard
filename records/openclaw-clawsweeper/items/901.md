## What This Changes

This PR routes cluster-repair intake through an authenticated durable queue and state materializer, validates result target repositories before minting read tokens, narrows workflow credentials, and adds recovery-focused tests and documentation.

## System Context

Cluster repair intake turns GitCrawl candidate evidence into a durable accepted intent instead of publishing from its checkout. The state materializer then projects the accepted paths, dispatches the repair worker, and result publication reads worker artifacts to update the durable state safely.
