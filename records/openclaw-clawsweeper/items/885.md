## Summary

Keep this PR open: its recency arbitration depends on state-branch commit timestamps, but the new reconciliation workflow checks out the state repository at depth 1. That prevents reliable timestamp lookup for historical records that were not changed in the state branch’s tip commit, so the proposed repair can make incorrect authority decisions.

## What This Changes

This PR adds a manual Worker-record reconciliation workflow that compares Git-backed records with the canonical Worker store, then imports or replays the side selected by live GitHub state and record recency.

## System Context

ClawSweeper keeps durable review records both in a Git state branch and in a canonical Worker-backed store. The reconciliation workflow reads both replicas and live GitHub item status, decides which representation is authoritative, and writes corrective imports or projections to restore parity.
