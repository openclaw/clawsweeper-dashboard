## What This Changes

Add a staged advisory release-train system covering a maintainer-owned scope contract, deterministic release-delta audits, durable reports, non-blocking Check Runs, and shadow evaluation.

## Best Possible Solution

Approve a maintainer-owned release metadata and exception contract first, then implement a read-only fixture-backed classifier and durable report, validate it through one shadow release train, and add advisory Check Runs only after false-clear and timing criteria pass.
