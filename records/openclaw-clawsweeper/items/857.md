## What This Changes

This PR adds a seven-day durable fingerprint cursor so unchanged `pull_request.edited` inputs do not create another exact-review request, while changed review-relevant fields continue to enqueue.

## System Context

Exact-review ingress accepts GitHub pull-request events and converts them into durable review requests. This change sits between webhook or fallback intake and the Durable Object queue, deciding whether an edited pull request represents new review work.

## Architecture Diagram

  D --> E[Durable semantic cursor]
  E -->|Changed state| F[Durable review request]
  E -->|Unchanged edit| G[Deduped response and metric]
  F --> H[Exact-review worker]

## Best Possible Solution

Adopt the scoped semantic-deduplication policy only if maintainers want unchanged edited pull-request deliveries to be coalesced for seven days, while retaining fail-open admission for incomplete legacy fallback payloads and the separate cross-route design in https://github.com/openclaw/clawsweeper/pull/706.
