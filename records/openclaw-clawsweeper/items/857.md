## What This Changes

The PR suppresses semantically unchanged `pull_request.edited` webhook inputs so they do not create a second durable exact-review request, while preserving changed edits and source-order tracking.

## System Context

Exact-review ingress turns GitHub webhook events into durable review requests for the review worker. This change adds a semantic decision between webhook classification and queue admission so duplicate edited-PR states are suppressed without losing newer source authority.
