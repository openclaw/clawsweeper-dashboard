## Summary

Keep open for normal maintainer merge review: current main still queues an immediate apply continuation for any runtime-budget skip, and this narrow PR covers the zero-progress and progressed cursor cases with no actionable correctness findings.

## What This Changes

Adds a guard to `automatic_apply_runtime_reached` so automatic runtime-yield checkpoints only queue immediate continuations after positive cursor progress, with regression coverage in the sweep workflow tests.

## Best Possible Solution

Land the narrow guard with regression coverage if maintainers accept the scheduled apply run as the backstop for zero-progress automatic runtime yields.
