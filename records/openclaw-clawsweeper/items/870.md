## What This Changes

The branch makes primary state records authoritative over plan and decision-packet sidecars, and isolates individual record-tuple projection failures so independent tuples can continue publishing.

## System Context

ClawSweeper's state materializer projects review records into durable item, closed-item, plan, and decision-packet files, then the Git publisher reconciles and pushes them to the state repository. A malformed record tuple should be quarantined without preventing independent state updates from being published.

## Best Possible Solution

Retain strict repository-wide transport and parse failures, and merge tuple-level convergence only after focused proof shows orphaned sidecars are removed while valid sibling tuples still publish.
