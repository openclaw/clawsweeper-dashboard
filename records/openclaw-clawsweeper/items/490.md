## Summary

Current main still contains both demonstrated defects: mixed-case event record lookup prevents successful publication, and expired dedicated review placeholders are ignored rather than reaped. A live failing run confirms production impact, and no open pull request currently owns the fix.

## What This Changes

Normalize mixed-case event record lookup and remove expired trusted review-start placeholders before posting replacements.

## Best Possible Solution

Use the shared normalized repository slug for every event tuple path and add a trusted expired-lease selector that removes stale dedicated placeholders before replacement, with focused regressions for mixed-case repositories and lease trust boundaries.
