## What This Changes

The PR adds an `unknown` queue-pressure level so failed, malformed, timed-out, or 5xx pressure probes use the existing hard-pressure background-worker budget instead of normal capacity.

## System Context

ClawSweeper's scheduled sweep and commit-review workflows estimate review-worker admission from an exact-review queue-pressure probe. The shared limit calculation turns that pressure level into background worker counts, while exact-item work retains a separate interactive reservation.
