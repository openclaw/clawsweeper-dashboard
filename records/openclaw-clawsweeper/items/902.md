## What This Changes

This PR adds an `unknown` queue-pressure state so failed or malformed pressure probes use the existing hard-pressure background budget while exact-item work retains its independent capacity.

## System Context

The sweep and commit-review workflows probe the exact-review queue before admitting background review work. Their selected pressure level feeds the worker-limit utility, which determines how many background jobs can enter the review and publication pipeline while reserving capacity for exact-item work.
