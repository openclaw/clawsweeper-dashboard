## What This Changes

This PR makes Durable Object SQLite the canonical store for exact-review records, writes Git state through a materializer projection, and adds authenticated record read/list routes plus migration and retention handling.

## System Context

Exact-review automation accepts review records and persists item, plan, decision-packet, and closure data for later GitHub workflow processing. This PR changes the authority from the state repository to Cloudflare Durable Object storage, with a materializer emitting Git records as a downstream projection.
