## What This Changes

This PR changes the exact-review queue and `sweep.yml` so structured 422 payload-validation errors retain allowlisted diagnostics and park only the affected item, while opaque 422s use bounded global backoff and source-head data remains compatible with legacy workflow payloads.

## System Context

Exact review turns queue entries created from pull-request and command events into GitHub `repository_dispatch` requests that start the review workflow. The dispatcher’s response classification determines whether a queue item is parked, retried globally, or handed to the workflow with the correct source revision.
