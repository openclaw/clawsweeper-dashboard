## What This Changes

This PR adds authenticated R2 blob endpoints, a resumable ledger/assets migration workflow, and an opt-in worker-backed hydration path while retaining git as the default state source.

## System Context

ClawSweeper currently hydrates generated state from the state repository for its review and apply automation. This change adds an optional Cloudflare Worker and R2 path for the large ledger and asset trees, feeding the same local worktree hydration step without removing the existing git path.
