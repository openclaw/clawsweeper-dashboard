## Summary

Current main still has the reported integration bug: ClawSweeper-managed maturity labeling changes the issue revision used for review-start coordination, so exact-head matching can miss the existing lease. The issue remains necessary, and no canonical fix PR was found.

## What This Changes

Prevent the managed `maturity:stable` issue label from invalidating an active review-start lease and causing duplicate status placeholders and notifications.

## Best Possible Solution

Classify the ClawSweeper-owned stable-maturity label as advisory for issue source revisions and add focused digest coverage proving bot label sync cannot move the lease key while substantive human changes still do.
