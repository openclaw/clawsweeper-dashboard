## What This Changes

This PR adds repository-variable inputs to normal `setup-state` workflow calls so record hydration can switch from the git state checkout to the Worker/R2 transport, while seed, migration, verify, and reconcile jobs remain pinned to git.

## System Context

ClawSweeper workflow jobs hydrate durable review records before running review, repair, publication, and audit work. Each job invokes the local state setup action, which chooses either the git-backed record checkout or the Worker/R2 record transport and exposes the hydrated records to later steps.
