## What This Changes

This PR makes the exact-review publisher capture its baseline tuple from the durable state checkout before an isolated worker creates fresh artifacts, and restores a verified-pull admission fixture in dashboard-worker coverage.

## System Context

Exact-review workers generate review records in isolated directories, then the publication step compares and applies those records to the durable ClawSweeper state store that drives GitHub review status. The changed baseline snapshot determines whether a newly generated record is safely recognized as a fresh update rather than rejected as an invalid tuple.
