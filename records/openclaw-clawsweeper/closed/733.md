## What This Changes

This PR adds a distinct Publishing and Applying & writing view to OpenClaw Bay by projecting active durable publication-batch ownership into the dashboard, while expanding worker telemetry and focused dashboard tests.

## System Context

OpenClaw Bay is ClawSweeper’s read-only operational dashboard for the exact-review pipeline. It combines scrubbed durable queue and publication-batch state with cached workflow status so operators can see whether an item is arriving, being reviewed, published, applied, recovered, or completed.
