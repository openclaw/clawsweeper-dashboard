## What This Changes

The PR rebases an existing exact-review queue item’s revision above its target’s durable publication head when a newer source event updates that item, with regression coverage for the stale-item case.

## System Context

Exact review turns incoming repository events into queued review work and then into durable publication artifacts that post the final verdict. A per-target publication head rejects stale artifacts, so the queue must keep an updated review item’s revision above that head before dispatching publication.
