## What This Changes

The PR classifies exact-review repository-dispatch failures, parks permanent item rejections, applies dispatcher-wide backoff to transient failures, and adds queue-state telemetry plus focused tests.

## System Context

Exact review places repository items into a durable queue and dispatches sweep workflow events to process them. The dispatcher’s failure handling determines whether individual items retry, stay parked for recovery, or whether the whole queue pauses before sending more workflow events.
