## What This Changes

Add a bounded freshness lane to exact-review publication admission so current authoritative results receive service during historical FIFO cleanup without weakening the existing safety fences.

## System Context

The exact-review publication queue turns completed Codex reviews into durable GitHub/state updates. It receives queued publication candidates, admits bounded batches under durable ownership rules, then prepares and publishes each eligible result while fencing stale revisions.
