## What This Changes

This PR raises the GitHub Actions state-blob migration job timeout from 120 to 350 minutes and records the reported reason for the longer budget.

## System Context

The state-blob migration workflow uploads a large ledger tree into R2-backed durable state. Its job timeout bounds how long per-file authenticated uploads may run before the migration stops and relies on idempotent resume.
