## Summary

Current main still exposes contributor proof as free-form PR-body context without deterministic metadata tying the evidence claim to the live head. The proposed parser is narrow and consistent with the repository’s exact-head and proof-quality direction, but the fenced packet syntax is a new contributor-facing contract that needs maintainer approval before implementation.

## What This Changes

Accept one optional size-bounded `clawsweeper-proof` JSON block in a PR description, compare its claimed head with the live PR head, and pass normalized untrusted proof context to review.

## Best Possible Solution

Approve and document a small versioned, size-bounded, non-executing packet contract, then parse it fail-closed into separate current-head or stale untrusted context without changing proof sufficiency, labels, gates, or free-form evidence support.
