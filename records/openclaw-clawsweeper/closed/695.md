## Summary

Keep this PR open: it recovers the partial GraphQL payload but does not remove the listed comments whose requested node resolved to `null`, so the deleted-comment race can still create model results, audit records, and processed-ledger entries for comments that no longer exist.

## What This Changes

## Best Possible Solution

Preserve the recovered partial-response behavior, but carry requested node IDs through hydration and exclude comments whose nodes resolve to null before prioritization, model scanning, audit writing, and ledger updates.
