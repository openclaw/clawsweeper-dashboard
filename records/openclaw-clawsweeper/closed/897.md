## What This Changes

This PR retries transient GitHub provenance-read failures during worker-record reconciliation, then records a canonical-wins degradation and replays the projection if retries are exhausted.

## System Context

The reconciliation worker compares canonical ClawSweeper records with their state-repository projection and GitHub item state to decide which record representation should be authoritative. Git provenance timestamps inform content-difference recency decisions; this PR changes the failure path when those timestamps cannot be read.
