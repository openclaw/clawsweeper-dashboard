## What This Changes

This PR makes artifact and decision publication write decision-packet references relative to an explicitly supplied isolated record workspace.

## System Context

Exact-review workers generate review artifacts in isolated workspaces, then publication commands validate their record tuples and synchronize durable review results. This change controls how those commands derive the canonical decision-packet path that later tuple validation and GitHub publication consume.
