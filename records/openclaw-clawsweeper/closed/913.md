## What This Changes

The PR treats empty or whitespace-only `CLAWSWEEPER_RECORDS_REPO_SLUGS` as no explicit override so worker-mode hydration can discover record-repository slugs from the Worker store.

## System Context

The state setup workflow passes configuration into hydration, which builds the records cache needed for safe state cutover. Hydration can use an explicit repository-slug list or discover slugs from the canonical Worker store; this PR restores the discovery path when setup exports an empty environment value.
