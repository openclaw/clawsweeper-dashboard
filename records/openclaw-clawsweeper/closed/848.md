## What This Changes

Adds an optional Claude CLI runtime with Anthropic, Bedrock, Vertex, and Foundry credential setup so ClawSweeper workflows can run Claude Opus 5 while retaining Codex as the default.

## System Context

ClawSweeper workflows start model-backed review, repair, reporting, and spam-audit jobs through a shared CLI launcher. This PR inserts a Claude compatibility runtime and provider credential setup between those workflows and the existing process/structured-output contract.
