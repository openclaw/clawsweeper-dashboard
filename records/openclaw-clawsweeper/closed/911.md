## What This Changes

This PR preserves repository slug, HTTP request, response-code, body-snippet, and partial-progress context when Worker snapshot hydration refuses a cutover and falls back to Git records.

## System Context

Worker-backed state hydration requests each repository’s latest snapshot, materializes it into the generated state tree, and falls back to Git records if the Worker snapshot cannot be read. This PR carries the refusal context through the Worker reader, cache-preparation command, hydration log, and fallback result so operators can identify the failing repository and request.
