## What This Changes

This PR replaces whitespace-delimited legacy intake fields with NUL-delimited fields so omitted target branches resolve through the repository default-branch fallback, and adds executable workflow-serializer regression tests.

## System Context

The legacy-event workflow translates issue and pull-request dispatch payloads into a queue request before ClawSweeper creates durable review work. Its repository, target-branch, and source-authority fields determine which branch is fetched and whether an event can enter the review pipeline.
