## Label Justifications

- `P2`: The issue is a bounded coordinator authorization bug with single-use tickets and a 120-second stale-authority window.
- `impact:security`: The report concerns generated bridge credentials and lease share authorization boundaries.

## Summary

Keep open: current main still accepts valid unused WebVNC and Code bridge-agent tickets after loading the lease without re-checking whether the ticket principal still has manage access; the related fixes cover active viewers and egress, not this remaining ticket path.

## What This Changes

The issue reports that unused WebVNC and Code bridge-agent tickets remain consumable for up to their short TTL after the manager who minted them loses lease manage access.

## Best Possible Solution

Add consume-time current-manager authorization checks for WebVNC and Code tickets, delete stale tickets on failure, and cover the revoked-manager unused-ticket cases in Worker tests.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: mint a WebVNC or Code ticket as a manager, downgrade or remove that manager, then consume the unused ticket before expiry; no live WebSocket harness was run in this read-only review.

## Solution Assessment

Yes. Mirroring the existing egress consume-time leaseManagerAuthorized check for WebVNC and Code is the narrowest maintainable repair for the observed asymmetry.
