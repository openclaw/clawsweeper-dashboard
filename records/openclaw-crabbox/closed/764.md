## Summary

Keep open. Current main still renders the five reported provider endpoint fields raw in both config-show outputs, but an older broad URL-userinfo redaction report was closed as not planned, so this needs a narrow maintainer security/product decision rather than cleanup closure.

## What This Changes

The issue asks Crabbox to redact URL userinfo in Morph, E2B, Upstash Box, SmolVM, and ASCII Box endpoint overrides in `crabbox config show` text and JSON output.

## Best Possible Solution

Make a narrow maintainer decision for these five provider endpoint fields: either redact their URL userinfo in config-show with regression tests, or document why those endpoint overrides are intentionally outside the redacted diagnostic contract.

## Reproduction Assessment

Yes. Source inspection on current `main` shows the five reported fields are passed directly to the JSON view and text renderer, while adjacent provider endpoints use the existing URL redaction helpers.

## Solution Assessment

Unclear. The mechanical fix is small and matches current sibling redaction patterns, but https://github.com/openclaw/crabbox/issues/421 was closed with pushback against broad URL-userinfo redaction, so maintainers should confirm the five-provider policy first.
