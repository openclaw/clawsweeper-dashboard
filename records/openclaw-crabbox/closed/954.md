## Summary

Keep open; current main still collects only older environment variables for exact diagnostic redaction while several documented env-only provider keys are resolved outside Config. The report matches Crabbox's documented credential-redaction guarantee, and no canonical merged fix or open replacement was found.

## What This Changes

This issue reports that exact diagnostic secret redaction misses env-only provider API keys for OpenComputer, CodeSandbox, OpenSandbox, Superserve, and Crownest.

## Best Possible Solution

Add a provider-owned credential-source inventory or redaction hook that feeds configuredDiagnosticSecrets for env-only provider keys, with regression tests proving unusual diagnostic contexts redact the affected values.
