## Summary

Keep open: current main still has the reported common diagnostic-redaction gap for non-Bearer/non-Basic authorization schemes, and the related merged bearer fix does not cover this exact case.

## What This Changes

The issue asks Crabbox to redact complete Authorization and Proxy-Authorization header values for non-Bearer/non-Basic schemes in both Go CLI and Worker diagnostics.

## Best Possible Solution

Update the shared Go CLI and Worker diagnostic redactors to consume the complete Authorization/Proxy-Authorization value for any valid scheme, with Token and Digest regression coverage plus existing behavior checks.
