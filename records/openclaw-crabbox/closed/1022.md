Keep open: current main still lets E2B stop delete a provider-resolved sandbox based on Crabbox-looking metadata without proving an exact local lease claim, and no merged/open canonical fix owns the E2B work.

## What This Changes

Require E2B destructive stop and recovery resolution to prove an exact local Crabbox lease claim instead of trusting provider metadata fallbacks.

## Best Possible Solution

Make E2B destructive lifecycle paths fail closed unless an exact local claim binds the target sandbox, with any adoption or claim-loss recovery scoped explicitly and covered by regression tests.
