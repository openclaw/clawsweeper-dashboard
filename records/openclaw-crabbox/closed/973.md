## Summary

Keep open: current main still allows unauthenticated GitHub OAuth start/login requests to allocate into one global 100-entry pending queue, and no canonical fixing issue or PR was found.

## What This Changes

The issue reports that unauthenticated GitHub OAuth start requests can fill the shared pending-login queue and block new CLI and portal GitHub logins.

## Best Possible Solution

Keep the issue open for a security-reviewed OAuth throttling or partitioning fix that preserves unauthenticated login bootstrap while preventing one caller from consuming the global pending queue.
