## Summary

Keep open: the PR is pointed at the right P0 security bug, but it is not merge-ready because the new delete path can misreport an inventoried Azure candidate as terminated when the retained lease belongs to another provider scope, and live Azure proof is still pending.

## What This Changes

The branch routes Azure orphan-sweep deletion through optional owned-delete support, updates Worker fleet tests for owned-delete routing and rejection, and adds a changelog entry.

## Best Possible Solution

Require Azure orphan-sweep deletion to prove the same retained lease, resource name, region, and Azure provider scope as the inventoried candidate before calling owned delete, keep mismatches failed/report-only with diagnostics, and land only with redacted live Azure cleanup proof.
