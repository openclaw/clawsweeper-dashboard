## Summary

Keep this PR open: current main still has the controller identity regression from the redacted public config JSON path, and this branch provides a focused repair with regression coverage and live CLI proof. The main merge question is whether maintainers are comfortable with the new internal config-show mode emitting the raw coordinator binding for same-user subprocess use.

## What This Changes

The PR adds an internal `config show --json --controller-provider-identity` contract for controller subprocesses, switches controller identity resolution to that contract, unifies endpoint URL redaction, and adds focused config/controller tests.

## Best Possible Solution

Land a narrow fix that keeps normal `config show` output redacted while giving controller subprocesses a bounded raw identity contract; add an explicit unsafe/internal cue first if maintainers want stronger protection against accidental human use.
