## Summary

Keep open: source review supports a narrowed current-main gap. The Cloudflare cron route is version-stamped and can reconcile idle sockets, but direct `FleetCoordinator.alarm()` and Node pg-boss recurring reconciliation call the alarm path without a request/version, so the documented scheduled reconciliation contract is not uniformly covered.

## What This Changes

The issue requests scheduled reconciliation for idle admin-authorized bridge/control WebSocket attachments after admin grant rotation, or documentation that idle sockets are only revalidated on traffic, later requests, or connection lifecycle.

## Best Possible Solution

Add a provider-neutral scheduled admin-grant sweep shared by direct alarms and Node pg-boss reconciliation, keep the existing request and traffic checks, and add focused Worker tests for idle control, WebVNC, Code, and egress admin sockets.
