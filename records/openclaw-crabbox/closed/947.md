## Summary

Keep open. Current main and the latest release still omit the GCP `x-goog-*` signed-query parameters from the Worker diagnostic redactor, while the Go helper and security docs support redacting credential-bearing query components.

## What This Changes

The issue asks Crabbox to redact GCP signed-query credential parameters from coordinator diagnostic text in the Worker redaction helper.

## Best Possible Solution

Align `worker/src/http.ts` with the existing Go diagnostic redaction policy for GCP signed-query names and add focused Worker regression coverage without broadening unrelated provider behavior.
