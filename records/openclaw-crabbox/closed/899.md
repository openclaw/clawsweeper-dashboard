## Summary

Keep open: current main still lacks a final redaction layer in `crabbox doctor`, so raw coordinator errors and provider doctor messages/details can reach text and JSON diagnostics despite the documented secret-redaction boundary.

## What This Changes

The issue asks for `crabbox doctor` to redact credential-bearing coordinator and provider diagnostic text in both text and JSON output.

## Best Possible Solution

Add a provider-neutral doctor diagnostic redaction layer immediately before text printing and JSON serialization, preserve useful non-secret fields, and add focused text/JSON regressions for coordinator errors, provider-readiness checks, admin failures, and direct provider doctor failures.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: a coordinator or provider returns credential-bearing error text or DoctorCheck details, and `crabbox doctor` records those values through the unsanitized text/JSON sink.

## Solution Assessment

Yes. The requested centralized sink redaction is the narrowest maintainable fix because caller-by-caller sanitization has already left gaps, and AGENTS.md favors provider-neutral core handling for generic diagnostics.
