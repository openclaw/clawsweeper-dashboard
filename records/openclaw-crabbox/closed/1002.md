## Summary

Keep open: current main still emits unprefixed portal and Code viewer cookies and still resolves duplicate cookie names by first match, while no open or merged host-prefix fix was found.

## What This Changes

The issue asks Crabbox to harden portal and isolated Code browser session cookies against sibling-origin shadowing by moving to host-prefixed names and clearing legacy names during transition.

## Best Possible Solution

Move the portal and isolated Code viewer session cookies to host-prefixed names, clear legacy unprefixed names on login/logout or session handoff, and add Worker regressions for duplicate-name shadowing and cookie-to-bearer conversion.
