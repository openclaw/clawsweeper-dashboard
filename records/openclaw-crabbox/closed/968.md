## Label Justifications

- `P2`: The issue is a bounded credential-redaction bug in generated diagnostics with meaningful mitigations, not an active outage or broad security bypass.
- `impact:security`: The report concerns credential material remaining visible in Crabbox-generated diagnostic output.
- `impact:auth-provider`: The affected values are authorization, API-key, token, and bearer credential-shaped diagnostics tied to auth/provider secret handling.

## Summary

Keep open: current main still partially redacts punctuation-bearing bearer/header values and leaves suffixes visible, despite the documented diagnostic redaction guarantee; exact configured-secret replacement mitigates known values but does not cover the generic fallback gap.

## What This Changes

The issue asks Crabbox to fully redact punctuation-bearing authorization/header and bearer credential values in coordinator diagnostics instead of leaving suffixes after comma, semicolon, or single quote.

## Best Possible Solution

Harden the existing diagnostic redaction helpers to consume full credential tokens through punctuation that can be part of values, add focused header-style and standalone bearer regressions, and keep CLI and Worker behavior aligned.
