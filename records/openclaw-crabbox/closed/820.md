## Summary

Keep open for maintainer merge review. The PR is a narrow candidate fix for a real current-main credential redaction bug, now with terminal proof; the remaining concern is the intentional compatibility change that generated stop commands no longer carry URL-userinfo credentials.

## What This Changes

The PR redacts URL userinfo from Proxmox, Daytona, Sprites, Morph, and Hostinger generated stop-command routing flags, adds table-driven Go regression coverage, and updates the security docs.

## Best Possible Solution

Land the narrow redaction fix after hosted CI passes, preserving endpoint routing while preventing Crabbox-generated diagnostics and artifacts from carrying URL-userinfo credentials.

## Reproduction Assessment

Yes. Source inspection shows a credential-bearing API URL in any of the five affected provider configs flows directly into `runStopCommand` output on current main without the existing `routingSafeURL` redaction used by adjacent providers.

## Solution Assessment

Yes. Reusing `routingSafeURL` at the five stop-routing append sites is the narrowest maintainable fix and matches the existing Namespace Instance, XCP-ng, and Vast patterns.
