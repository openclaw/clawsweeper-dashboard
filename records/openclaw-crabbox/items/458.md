  - confidence: 0.99
- **[P1] Redact credentials from Orgo HTTP error bodies:** `internal/providers/orgo/client.go:314-315`
  - body: Sanitize the configured API key from non-2xx response bodies before storing or formatting the error. Custom or upstream endpoints can echo the bearer value, which this path returns verbatim.
  - confidence: 0.99
- **[P1] Require an explicit successful Bash result:** `internal/providers/orgo/client.go:274-283`
  - body: Do not default a response with neither a success field nor an exit-code field to exit 0. An upstream error or schema change would otherwise be reported as a successful command.
  - confidence: 0.99
- **[P1] Keep cleanup state until deletion is confirmed:** `internal/providers/orgo/client.go:244-252`
  - body: Require an explicit successful delete response before removing the lease claim. The current path accepts an empty or status-only response as success, so failed cleanup can become undiscoverable.
  - confidence: 0.98
- **[P1] Reject redirects for bearer-authenticated Orgo requests:** `internal/providers/orgo/client.go:148-155`
  - body: Use an Orgo-specific client policy that rejects redirects or verifies the exact approved origin before following them. Reusing a general client allows authenticated requests to cross this provider's credential-destination boundary.
  - confidence: 0.94
- **[P1] Validate returned computer identity before use:** `internal/providers/orgo/backend.go:354-365`
  - body: Require create and get responses to return a nonempty computer ID and the requested workspace and name before recording or deleting the resource. Filling missing identity fields and accepting mismatches can bind a claim to the wrong computer.
  - confidence: 0.96
- **[P1] Do not cascade-delete an unverified workspace:** `internal/providers/orgo/backend.go:511-517`
  - body: Remove automatic workspace deletion or require an atomic upstream precondition. Another client can add a computer after any inventory check, and this cascading delete would then remove a resource Crabbox does not own.
  - confidence: 0.99
