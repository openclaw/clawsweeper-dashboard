- **[P1] Persist recovery state before creating Orgo resources:** `internal/providers/orgo/backend.go:344-354`
  - body: `CreateWorkspace` and `CreateComputer` run before any durable claim is written, so process death can leave paid resources without identities available for retry cleanup. Persist mutation state before each call and record returned IDs immediately.
  - confidence: 0.99
- **[P1] Redact credentials from Orgo HTTP error bodies:** `internal/providers/orgo/client.go:314-315`
  - body: Non-2xx response bytes are surfaced verbatim. A configured or upstream endpoint that echoes the bearer value exposes the API key in CLI output; redact raw and `Bearer` forms before creating the error.
  - confidence: 0.99
- **[P1] Require explicit success from Orgo Bash responses:** `internal/providers/orgo/client.go:274-283`
  - body: Responses without either exit-code field or explicit success currently return exit 0, so malformed or changed API envelopes can report failed or unexecuted commands as successful. Reject responses that do not prove success.
  - confidence: 0.99
- **[P1] Keep cleanup state until deletion is confirmed:** `internal/providers/orgo/backend.go:510-522`
  - body: A successful cascading workspace delete clears an earlier computer error and removes the claim, losing retry evidence despite ambiguous exact-computer cleanup. Retain state until exact deletion is independently confirmed.
  - confidence: 0.98
- **[P1] Reject redirects for bearer-authenticated requests:** `internal/providers/orgo/client.go:148-156`
  - body: The client sends the bearer token using an ambient or default `http.Client` without an Orgo-specific redirect policy. Use a cloned client that rejects redirects or enforces the exact configured origin.
  - confidence: 0.98
- **[P1] Validate returned computer identity before destructive use:** `internal/providers/orgo/backend.go:279-309`
  - body: The backend accepts the fetched object without checking that its ID and workspace match the claim, then later deletes `computer.ID`. Require exact claimed ID and workspace identity before use or cleanup.
  - confidence: 0.99
