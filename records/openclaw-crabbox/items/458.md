## What This Changes

## Best Possible Solution

Require an operator-managed workspace and never delete workspaces; persist durable pending computer ownership before remote mutations, validate exact identities and explicit success envelopes, restrict authenticated redirects, redact credentials, and land only after redacted hosted lifecycle proof.

Rationale: Orgo's cascading delete lacks a conditional or version precondition, so a local inventory check cannot prevent deletion of a concurrently added unrelated computer; selecting the ownership boundary changes the public provider contract.

- **Wait for Orgo API:** Defer built-in support until Orgo provides conditional, versioned, or non-cascading workspace deletion.
- **Keep integration external:** Close the built-in proposal and leave Orgo support to a custom integration if core should not own this contract.

## Solution Assessment

No; automatic temporary workspace ownership and fail-open response handling are unsafe. An operator-managed workspace with exact computer-only ownership is the narrowest maintainable built-in design.

## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.99

Full review comments:

- **[P1] Persist recovery state before remote Orgo creates:** `internal/providers/orgo/backend.go:346`
  - body: `CreateWorkspace` and `CreateComputer` run before any lease claim is durably recorded. A crash after either successful API call leaves paid resources with no local identity for `stop` or cleanup; durably record and update pending ownership before each mutation, then finalize it after identity validation.
  - confidence: 0.99
- **[P1] Redact the API key from Orgo error bodies:** `internal/providers/orgo/client.go:315`
  - body: A non-2xx response body is stored verbatim and included in `orgoHTTPError.Error()`. Upstream proxies and custom API bases can echo `Bearer <key>` or the raw key, exposing credentials in output and logs; redact the configured key before constructing the error.
  - confidence: 0.99
- **[P1] Require an explicit successful Bash result:** `internal/providers/orgo/client.go:280-283`
  - body: Responses with no exit code and no explicit `success:false` fall through to exit 0, and the tests explicitly accept that case. A schema change or incomplete response would report an unknown command outcome as successful; require a supported explicit success signal or fail closed.
  - confidence: 0.99
- **[P1] Keep recovery state until deletion is confirmed:** `internal/providers/orgo/client.go:249-252`
  - body: `deleteResource` accepts a response with no `success` field, after which `deleteLease` can remove the claim. An ambiguous delete envelope can leave a live paid resource while discarding its recovery identity; require explicit deletion success or verified absence before clearing state.
  - confidence: 0.98
- **[P1] Reject redirects for authenticated Orgo requests:** `internal/providers/orgo/client.go:148-155`
  - body: The client reuses `rt.HTTP` or `http.DefaultClient` without an Orgo-specific redirect policy, while every request carries `Authorization: Bearer`. Reject redirects or permit only same-origin HTTPS redirects so credentials cannot cross origins.
  - confidence: 0.98
- **[P1] Validate returned computer identity before use:** `internal/providers/orgo/backend.go:354-367`
  - body: The create and refresh paths accept returned computer objects without checking that the ID and workspace match the requested operation. A malformed or stale response can make Bash or destructive cleanup target the wrong computer; validate exact identity and workspace membership before persisting or acting.
  - confidence: 0.97
- **[P1] Do not cascade-delete Orgo workspaces:** `internal/providers/orgo/backend.go:511-517`
  - body: Deleting a Crabbox-created workspace permanently deletes every computer in it, and there is no atomic guard preventing another client from adding a computer after Crabbox checks inventory. Require an operator-managed workspace and remove workspace deletion unless Orgo adds a conditional or non-cascading primitive. citeturn0view0.
  - confidence: 0.99
