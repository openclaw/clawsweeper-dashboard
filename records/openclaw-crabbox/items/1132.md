## Summary

Keep this issue open: current main’s Apple Container cleanup path is source-reproducible as authorizing stopped-container deletion before proving an exact local claim, and the related reports address release paths or other providers rather than this cleanup case.

## What This Changes

Require Apple Container cleanup to skip stopped containers unless an exact local lease claim is bound to the candidate container.

## Best Possible Solution

Move exact provider/resource/claim validation ahead of every destructive cleanup decision, revalidate immediately before force deletion, and add table-driven tests for missing, conflicting, matching, kept, dry-run, stale, and orphan-recovery cases.
