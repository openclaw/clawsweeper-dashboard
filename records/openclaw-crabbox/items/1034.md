## Summary

Keep open: current main still reads explicit JUnit result paths with symlink-following POSIX and Windows primitives before parsing and storing the bounded result summary, so the reported workdir-confined ingestion problem remains actionable.

## What This Changes

This issue reports that configured JUnit result paths can resolve through symlinks or reparse points outside the remote workdir and be parsed into stored run results.

## Best Possible Solution

Constrain explicit result reads to resolved workdir-contained regular files on POSIX and native Windows, skip or warn on escapes, and add regression coverage for leaf symlinks, intermediate link components, Windows reparse points, and valid in-workdir reports.
