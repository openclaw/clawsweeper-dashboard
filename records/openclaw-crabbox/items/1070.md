The linked open pull request is the active implementation candidate, and the new CLI/schema contract requires a maintainer product decision before this issue can be resolved.

## What This Changes

Add a repeatable `--require-artifact-schema REMOTE=SCHEMA` post-run gate that validates required JSON artifacts against a fail-closed schema subset.

## Best Possible Solution

Choose one durable validation boundary: either sponsor a narrowly specified core schema gate and land https://github.com/openclaw/crabbox/pull/1071 after redacted live SSH proof and compatibility review, or retain repository-owned validation and document a clear command-level pattern.
