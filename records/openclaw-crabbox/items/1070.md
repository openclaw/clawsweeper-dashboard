## Summary

Keep open: current `main` deliberately provides only artifact-existence gating, while the linked open pull request is the implementation candidate and maintainers must decide whether JSON-schema semantics belong in Crabbox core.

## What This Changes

Requests a repeatable `--require-artifact-schema` post-run gate that validates JSON artifacts against a local schema and records validation results.

## Best Possible Solution

Keep artifact validation repo-owned unless maintainers explicitly approve a built-in, standards-clear validator with bounded reads, unambiguous unsupported-keyword behavior, provider capability rules, and upgrade-stable timing evidence.
