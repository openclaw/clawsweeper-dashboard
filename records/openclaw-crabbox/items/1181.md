## Summary

Keep this PR open. It targets a defined cancellation bug and adds focused regression coverage, but its reported verification is test-only and does not yet show the Apple VM helper handling an actual interrupted start; the new five-second cleanup deadline also needs evidence that it does not leave a helper or VM running.

## What This Changes

This PR makes Apple VM helper termination polls context-aware, adds interrupt handling for delete, and bounds cleanup after a cancelled start.

## System Context

The Apple VM helper is the macOS-native process that starts and stops local Apple Virtualization VMs for Crabbox leases. CLI start or delete commands enter its lifecycle paths, which poll process state and then return cleanup status to the caller.
