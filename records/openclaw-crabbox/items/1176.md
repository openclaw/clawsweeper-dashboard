## What This Changes

The issue requests that Semaphore pagination links be resolved and constrained to the configured origin so an authenticated request cannot be redirected to an attacker-selected host.

## Best Possible Solution

Parse and resolve each pagination reference against the configured Semaphore base URL, reject any result whose scheme, canonical host, effective port, or userinfo differs from that base origin, and cover accepted and rejected pagination forms with transport-level regression tests.
