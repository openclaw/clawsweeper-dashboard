## Summary

Keep open: current main still prints the effective coordinator URL raw in the reported login, whoami, and doctor paths, while the adjacent config display path already uses the safer URL redaction helper.

## What This Changes

The issue reports that CLI login, whoami, and doctor output can print credential-bearing broker/coordinator URLs without using the existing redaction helper.

## Best Possible Solution

Use the existing URL redaction helper for every broker/coordinator URL printed by login, whoami, and doctor, then add focused regression coverage for userinfo, query, and fragment redaction.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: configure a coordinator URL with URL userinfo, query, or fragment credentials and reach the login, whoami, or doctor output path that formats `cfg.Coordinator` directly.

## Solution Assessment

Yes. The narrowest maintainable fix is to reuse the existing `redactedConfigURL` helper in the affected output paths and cover those commands with regression tests.
