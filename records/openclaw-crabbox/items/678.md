  - confidence: 0.99

  - confidence: 0.97

  - body: The upload callback turns the full tarball into a base64 field and then marshals the complete request for the Python subprocess, creating multiple in-memory copies. `--force-sync-large` can therefore exhaust the Crabbox process; use a bounded file/stream handoff or reject archives above a documented bridge limit.
  - confidence: 0.93
