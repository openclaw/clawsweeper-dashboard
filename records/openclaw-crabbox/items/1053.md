## Summary

The PR targets a real source-reproducible AWS/Tailscale bootstrap bug, but its condition overrides the established `public` and `auto` network behavior whenever Tailscale provisioning is enabled. Keep it open for a narrow mode-aware repair and real AWS proof.

## What This Changes

The PR changes AWS acquire and resolve SSH targets to use a rendered or explicit Tailscale hostname whenever Tailscale is enabled and adds a focused hostname-selection unit test.

## Best Possible Solution
