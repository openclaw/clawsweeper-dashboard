## Summary

Keep open: current main still lets JUnit failure messages flow into human CLI results and failure-digest output without display sanitization, and no duplicate or merged fix was found.

## What This Changes

The issue requests stripping or normalizing terminal control sequences from JUnit failure messages before human CLI results and failure-digest output renders them.

## Best Possible Solution

Add a shared display-safe formatter for TestFailure messages across results, --failed-only, shard summaries, and failure digests, with regression tests that preserve JSON/raw machine output semantics.
