## Summary

Keep open: current main still prints the adapter relay connected-status coordinator value from `coord.BaseURL` directly to stdout, while adjacent broker/coordinator display paths now use the redaction helper.

## What This Changes

Redact credential-bearing coordinator URL components in the adapter relay connected-status output and add focused regression coverage.

## Best Possible Solution

Keep the full coordinator URL only for internal HTTP/WebSocket routing, render the connected-status coordinator value through `redactedConfigURL`, and add an adapter relay status test with userinfo, query, and fragment secrets.

## Reproduction Assessment

Yes. Source inspection gives a high-confidence path: configure a credential-bearing coordinator URL, reach a successful adapter relay connection, and `connectAdapterRelay` formats `coord.BaseURL` directly to stdout.

## Solution Assessment

Yes. The narrow maintainable fix is to reuse the existing URL display redaction helper only for the status line while preserving the raw base URL for routing.
