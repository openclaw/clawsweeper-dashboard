## Summary

Keep open: the maintainer-approved v1 scope remains necessary because current main has owner-scoped portal and API authentication but no iOS app, browser pairing grant, revocable device-token audience, or mobile CI/proof surface.

## What This Changes

Implement a first-party read-only iOS companion that pairs through the coordinator and uses revocable, owner-bound device tokens to list and inspect visible leases.

## Best Possible Solution

Implement coordinator pairing, scoped token verification, revocation, and destructive-route denial with focused Worker tests first; then add the minimal SwiftUI shell and shared Swift package with Keychain storage, exact-origin policy, unsigned simulator builds, and redacted pair/list/revoke/denial proof.
