## Summary

Keep open. Current main and the latest release still use standalone bearer redaction patterns that only match spaces or tabs after `bearer`, so the documented bearer-value diagnostic redaction guarantee is still missing the reported colon-delimited and folded forms.

## What This Changes

The issue requests broader Worker and Go CLI diagnostic bearer-token redaction for colon-delimited and line-folded bearer forms.

## Best Possible Solution

Broaden standalone bearer redaction in both Worker and Go diagnostic helpers, preserve existing exact-secret/header/URL/query/JSON/PEM behavior, and add regression cases for ordinary, colon-delimited, folded, structured-header, and already-redacted bearer diagnostics.
