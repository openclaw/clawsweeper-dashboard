## What This Changes

This PR adds Worker-coordinated ready-pool capacity reconciliation, atomic fill claims, provider-neutral compatibility keys, borrow heartbeats and cleanup, plus matching CLI commands, documentation, and regression tests.

## System Context

Crabbox's ready-pool feature lets clients register hydrated provider leases with the Worker coordinator, then borrow and return them for later runs. This PR moves warm-capacity decisions into that singleton coordinator so concurrent CLI clients can safely decide whether to prewarm or reuse capacity.
