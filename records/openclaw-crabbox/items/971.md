- `impact:security`: The issue concerns generated desktop credentials being copied from protected lease files into default CLI stdout.

## Summary

Keep open: current main and v0.36.0 still print generated managed VNC credentials in the default `crabbox vnc` output, and the security policy treats Crabbox-generated credentials exposed beyond the current OS user as an in-scope boundary.

## What This Changes

The issue requests that `crabbox vnc` stop printing generated VNC and desktop passwords to stdout by default and make any cleartext reveal explicit.

## Best Possible Solution

Adopt a WebVNC-style secure default for `crabbox vnc`: print connection details without generated credentials, keep native/private reveal handoff explicit with a warning, and add focused CLI/docs regression coverage.
