## Summary

Keep this canonical security tracker open: current main does not resolve all three reported cleanup races, two provider fixes remain open, and the external-provider path has no linked fix yet.

## What This Changes

Track cross-process orphan-sweep races that can delete live lease claims in the apple-container, local-container, and external provider cleanup paths.

## Best Possible Solution

Use the established provider-adapter pattern in all affected paths: snapshot eligible claims before resource inventory, revalidate the exact claim under its lock immediately before mutation, preserve provider-specific key and scope semantics, and add deterministic base-fails/head-passes interleaving tests.
