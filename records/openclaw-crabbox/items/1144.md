## What This Changes

Track and fix cross-process orphan-sweep races that can remove healthy lease claims in apple-container, local-container, and external provider cleanup paths.

## Best Possible Solution

Land separate provider-adapter fixes that snapshot orphan candidates before resource listing, conditionally remove only unchanged claims, and add deterministic regressions for both post-snapshot acquisition and mid-cleanup rebinding.
