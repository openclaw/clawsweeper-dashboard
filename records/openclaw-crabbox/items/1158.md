## Summary

Keep this PR open for a maintainer decision on the deliberate legacy-identity upgrade contract and for redacted real OAuth behavior proof. The security-hardening direction is coherent and focused, but merging as written would make existing email-owned sessions and durable records fail closed for non-admin users, which is an intentional compatibility break that tests alone do not settle.

## What This Changes

The PR binds portal OAuth callbacks to the initiating browser and changes GitHub-backed session ownership from verified email addresses to immutable numeric GitHub account IDs.

## Best Possible Solution

Adopt immutable GitHub account IDs as the long-term ownership boundary, but land it only with an explicitly approved and documented upgrade path—either a narrow migration/recovery flow or an intentional fail-closed rollout with operator and user remediation guidance—plus redacted live OAuth proof.
