## Summary

Keep this PR open: immutable GitHub account IDs and browser-bound OAuth are sound hardening goals, but the branch deliberately makes existing email-owned sessions and durable records inaccessible without a defined recovery or migration contract. It also still needs redacted real OAuth behavior proof before merge.

## What This Changes

The branch adds a browser-bound portal OAuth callback cookie and changes GitHub-backed session and ownership identities from verified email addresses to immutable numeric account IDs.

## Best Possible Solution

Keep immutable `github:<id>` as the new authorization identity, but ship an explicit, narrowly authorized migration or recovery flow that maps legacy records only after a verified OAuth account is confirmed, with upgrade and rollback coverage.
