## Label Justifications

- `P2`: The report describes a bounded medium-severity artifact publishing confidentiality issue requiring local write access and a timing race.
- `impact:security`: The issue concerns a security boundary that can disclose files outside the selected artifact bundle through trusted upload paths.

## Summary

Keep open: current main still validates artifact bundle entries during enumeration, then later reuses pathnames for broker hashing/upload and S3/R2/Cloudflare delegation, leaving the reported TOCTOU boundary gap unresolved.

## What This Changes

Fix artifact publishing so symlink and regular-file validation remains bound to the files later read or delegated by broker, object-store, and manifest publication paths.

## Best Possible Solution

Harden the shared artifact publish boundary by binding validation to the opened file object or by revalidating containment and regular-file identity immediately before every backend read/delegation, with regression coverage for post-enumeration symlink replacement.
