## Summary

The request is not implemented by the existing VM-oriented GCP provider, and no duplicate or candidate PR exists. Current architecture can support it, but Google’s public-preview model appears to require a Cloud Run-hosted bridge plus new IAM, deployment, and lifecycle support, so maintainers should first approve a bounded feasibility spike.

## What This Changes

Add Google Cloud Run sandboxes as a Crabbox execution provider.

## Best Possible Solution

Prototype a separate delegated-run provider and authenticated Cloud Run bridge that encapsulate Google-specific IAM, deployment, sandbox naming, state transfer, ownership metadata, and cleanup, then require live create/execute/destroy and residue proof before production support.
