## Summary

Keep open: neither current main nor v0.38.0 supports Google Cloud Run sandboxes. The existing GCP provider provisions Compute Engine SSH leases, while the linked public-preview sandbox runs inside a deployed Cloud Run service, so maintainers must first approve a distinct delegated-provider and hosted-runner contract.

## What This Changes

Requests support for Google Cloud Run sandboxes as a Crabbox execution provider.

## Best Possible Solution

Approve a bounded prototype for a separately named delegated provider, preferably through the external-provider surface first, and promote it to built-in support only after authenticated command and artifact transport plus residue-free deployment and cleanup are proven.

- **Defer preview support:** Wait for Google to expose a stable standalone remote sandbox lifecycle that maps more directly to Crabbox.
