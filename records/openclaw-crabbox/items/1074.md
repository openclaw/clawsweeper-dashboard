## Summary

Keep this issue open. The merged scrub work addressed safe return and reuse, but the central broker-mediated access and atomic desired-capacity capabilities remain unfinished; current documentation still describes direct client access with client-owned per-lease SSH keys.

## What This Changes

Add provider-neutral, borrow-scoped machine access and atomic desired-capacity reconciliation for reusable ready pools, including expiry, quarantine, compatibility, stale-record cleanup, and metrics.

## Best Possible Solution

Implement this as a phased provider-neutral coordinator contract: borrow-bound short-lived access grants and atomic capacity claims in the broker, provider-specific installation and revocation in adapters, explicit min/max policy configuration, fail-closed quarantine, and focused concurrency plus live AWS/Azure validation.
