## Summary

Keep this issue open. The merged scrub work secures return and reuse, but current main still lacks the central portable broker credential handoff and atomic desired-capacity reconciler; these are substantial security and product-contract decisions rather than minor leftovers.

## What This Changes

Requests broker-mediated portable ready-pool access, atomic desired-capacity reconciliation, compatibility matching, abandoned-borrow handling, stale-record pruning, lease rotation, and pool metrics.

## Best Possible Solution

Adopt a staged provider-neutral design: first define expiring borrow-bound access capabilities and provider adapter hooks, then add atomic capacity claims with explicit min/max policy, heartbeat-driven quarantine, stale pruning, lease rotation, compatibility keys, and observable metrics.
