## Summary

Keep open: merged work now covers the documentation, generated coverage matrix, lifecycle unit gate, and secretless end-to-end tier, but the authenticated hosted-provider tier remains intentionally unimplemented pending decisions about credentials, spend, cancellation, and orphan cleanup. The explicit maintainer follow-up confirms that this remaining scope is still wanted and policy-sensitive.

## What This Changes

Requests comprehensive connector lifecycle documentation and coverage, with hermetic merge-gating CI plus a separately governed authenticated live-provider tier.

## Best Possible Solution

Retain the merged secretless gates and generated matrix, then define a maintainer-approved hosted-live policy before adding a bounded schedule/dispatch workflow with isolated credentials, strict spend limits, non-cancelling provider cleanup, read-only orphan auditing, and live create/use/destroy proof.
