## What This Changes

Prevent generated workspace SSH host private keys from being retained in AWS user-data, Azure custom data, GCP metadata, or equivalent provider-controlled bootstrap storage.

## Best Possible Solution

Use guest-generated SSH host identity and return only an authenticated public key or fingerprint through a narrowly scoped readiness channel, with regression tests proving private-key material never enters provider bootstrap metadata.
