## What This Changes

Add a long-running loopback port forward for an already-resolved SSH-backed lease, with deterministic readiness and structured local endpoint output.

## Best Possible Solution

Add a provider-neutral single-lease forwarding command over the shared resolved SSH target, bind it to `127.0.0.1`, emit stable text and JSON endpoint data after the forward is usable, and retain pond forwarding for multi-lease topology.
