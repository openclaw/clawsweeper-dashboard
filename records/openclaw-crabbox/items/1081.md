## Summary

Keep open: Crabbox’s current synchronization contract is explicitly Git-based, so the reported Jujutsu multi-parent workflow remains unsupported and can select an unintended workspace state. Native support is plausible, but maintainers must first define the interoperability contract and obtain a minimized reproduction.

## What This Changes

Add reliable workspace synchronization for Jujutsu repositories, including complex multi-parent working-copy graphs.

## Best Possible Solution

Add a generic repository-state interface that derives the manifest, deletions, identity, seed revision, and comparison base from Git or Jujutsu, backed by colocated and multi-parent integration fixtures that prove the remote workspace exactly matches the intended local change.
