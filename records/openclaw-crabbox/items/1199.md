## Summary

## What This Changes

The branch adds browser-initiated, owner-bound pairing grants and revocable device credentials that can only read redacted coordinator lease status.

## System Context

The Worker coordinator authenticates portal and API requests before passing an authorized request context to the fleet service. This change inserts a device-specific principal that can pass only through lease-status reads after an uncached GitHub membership check.
