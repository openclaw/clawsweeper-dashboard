Keep this PR open for human review. It is a docs-only proposal that extends the merged deterministic-evidence contract with a concrete Wasmtime fuel design, but the linked canonical issue still has unresolved product, runtime-boundary, and schema-governance decisions.

## What This Changes

Adds a proposed design document for deterministic Wasmtime fuel evidence and updates the existing feature contract to point to it and name the metric as fuel rather than native instructions.

## System Context

Crabbox collects run artifacts and policy results from disposable remote execution environments. This proposal would add a provider-neutral deterministic performance-evidence path: a metered WASI workload produces a versioned artifact that later gate logic could consume without making Wasmtime a core dependency.
