## Summary

Keep open for security triage. The report identifies a concrete current-main Orgo request flow where credentialed JSON requests appear to use Go’s default redirect behavior after attaching a Bearer token; the claimed disclosure boundary needs independent security-owner confirmation before a provider-scoped fix is accepted.

## What This Changes

Add provider-scoped redirect confinement for Orgo requests so 307/308 redirects cannot replay command bodies or Bearer credentials to a different scheme, host, or effective port.

## Best Possible Solution

Implement and security-review a cloned, Orgo-only HTTP client that permits redirects only when scheme, canonical hostname, and effective port remain equal to the configured API base; add focused tests proving rejected targets receive neither request bodies nor credentials.
