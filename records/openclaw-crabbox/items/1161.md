## What This Changes

Add reserved `CRABBOX_LEASE_ID`, `CRABBOX_RUN_ID`, and `CRABBOX_SLUG` variables to remote executions, with a unique run ID for every invocation and consistent behavior across coordinator, direct SSH, and delegated-provider paths.

## Best Possible Solution

Adopt a centrally constructed, provider-neutral execution metadata object that generates one run ID before dispatch, preserves a coordinator-issued ID when present, reserves the three names against forwarded-variable overrides, and is covered across direct, coordinator, and delegated execution paths with lifecycle documentation.
