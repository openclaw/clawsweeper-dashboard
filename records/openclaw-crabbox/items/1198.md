## Summary

Keep this PR open for maintainer direction and two targeted corrections: it adds a useful execution-metadata capability with convincing live CLI proof, but it silently repurposes previously forwardable user environment names and edits the release-owned changelog.

## What This Changes

The branch adds Crabbox-controlled `CRABBOX_LEASE_ID`, `CRABBOX_RUN_ID`, and `CRABBOX_SLUG` to remote command environments, documents their precedence and lifecycle, and adds coverage across command modes and providers.

## System Context

`crabbox run` collects permitted ambient and profile environment values, acquires or resolves a remote lease, then dispatches a command through SSH or a delegated provider. This PR inserts execution identity into that environment pipeline so remote jobs can namespace resources and correlate their output with the lease and invocation.

## Best Possible Solution

Adopt one explicit, documented execution-metadata contract only after maintainers decide that these three names are reserved for Crabbox; preserve compatibility through a migration or opt-in path if existing forwarded values must remain supported, and leave the release-owned changelog to the release flow.
