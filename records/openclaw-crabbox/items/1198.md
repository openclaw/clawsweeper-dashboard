## Summary

This PR has convincing real-run proof for the new metadata behavior, but it still changes existing forwarded environment values without an approved upgrade contract and retains a release-owned changelog edit. Keep it open for a maintainer decision and a compatibility-safe revision.

## What This Changes

The PR injects Crabbox-owned `CRABBOX_LEASE_ID`, `CRABBOX_RUN_ID`, and `CRABBOX_SLUG` into remote command environments, using a local run ID when no coordinator-issued ID exists.

## System Context

Crabbox combines ambient variables, profile environment files, presets, and run context before sending commands to SSH, local-container, and delegated providers. This PR adds execution metadata at that final environment-selection step and reuses the run ID in status, timing, proof, and receipt outputs.
