## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Require reclaim before adopting Parallels VMs:** `internal/providers/parallels/backend.go:285`
  - body: This exact-claim guard can still be bypassed after one ordinary resolved reuse: Parallels `Resolve` accepts raw VM IDs/names and returns a target without checking `req.Reclaim`, then the generic `run --id` path writes the resolved target as an exact local claim with `reclaim=false`. A later `stop` now passes this guard, so recovered or claimless Parallels VMs are not actually forced through the explicit `--reclaim` adoption promised by the PR and docs. Add the same non-reclaim rejection used by Hyper-V and Multipass before Parallels can bind a raw or legacy target.
  - confidence: 0.88
