## Summary

Keep open: the detailed current-main source analysis establishes a credible artifact-integrity gap, and no supplied evidence shows that the zero-size ambiguity has been fixed or superseded.

## What This Changes

Require artifact pulls to distinguish an omitted size from an explicit zero and reject non-empty content declared as zero bytes.

## Best Possible Solution

Use presence-aware manifest decoding, preserve omitted-size compatibility if intended, enforce every present non-negative value including zero, and apply that limit before writing remote content.
