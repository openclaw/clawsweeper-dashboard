Full review comments:

- **[P2] Match the actual Unix teardown signal:** `internal/cli/pond_mesh_cancel_unix.go:22`
  - body: `Signaled()` is true for every signal termination, not only the SIGKILL issued by this Cancel hook. If a forward independently dies from SIGSEGV, SIGTERM, or another signal while sibling cancellation races, this returns true and silently discards that genuine failure. Inspect `WaitStatus.Signal()` and suppress only the teardown signal, with a regression covering a different signal.
  - confidence: 0.96
- **[P2] Recognize Windows processes that already exited:** `internal/cli/pond_mesh_cancel_windows.go:16`
  - body: This assumes an already-finished child makes `Process.Kill` return `os.ErrProcessDone`, but Windows `TerminateProcess` can report access denied when the process has already terminated. The Cancel hook then leaves `killFoundExited` false, and this line suppresses the child's genuine nonzero result. Handle the Windows already-terminated result explicitly and add a behavior-level race test.
  - confidence: 0.9
