## Summary

Keep open: this is useful new evidence functionality and the refreshed branch addresses the prior review items, but the direct SSH path still shares one digest between stdout and stderr writers that can be written concurrently, so signed `log_sha256` receipts are not merge-safe yet.

## What This Changes

The PR adds `crabbox run --attest` signed Ed25519 receipt output, a `crabbox verify` command, docs, and Go tests for receipt signing, verification, key handling, output-path collisions, and wrapper flag rejection.

## Best Possible Solution

Keep the PR open, serialize or otherwise define mixed-stream digest capture before signing receipts, preserve the documented self-signed v1 boundary, and land only after maintainers accept that security model.
