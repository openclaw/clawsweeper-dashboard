## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.88

Full review comments:

- **[P1] Send raw JSON to CubeSandbox envd process start:** `internal/providers/cubesandbox/client.go:363-367`
  - body: CubeSandbox's Go SDK marshals the process-start payload to raw JSON and sends that directly to `/process.Process/Start`; only the response is a Connect stream. Wrapping the request with `encodeConnectJSONEnvelope` can make real `crabbox run --provider cubesandbox` calls fail before the user command starts.
  - confidence: 0.9
- **[P1] Handle CubeSandbox snake_case exit codes:** `internal/providers/cubesandbox/client.go:498`
  - body: CubeSandbox's SDK accepts both `exitCode` and `exit_code` and errors if neither is present. This struct only decodes `exitCode`, so a real `exit_code: 7` end event is decoded as zero and the provider can report a failing command as success.
  - confidence: 0.86
- **[P2] Preserve the virtual host when dialing CubeProxy:** `internal/providers/cubesandbox/client.go:475`
  - body: With `CUBE_PROXY_NODE_IP`, the CubeSandbox SDK keeps `49999-<sandbox>.<domain>` as the request URL host and overrides dialing to the node. Replacing the URL host with the node and only setting `Host` can break HTTPS SNI or virtual-host routing in proxy mode.
  - confidence: 0.82
