## Review Findings

Overall correctness: patch is incorrect

Overall confidence: 0.86

Full review comments:

- **[P1] Reject plaintext API URLs before attaching Cube credentials:** `internal/providers/cubesandbox/client.go:136-137`
  - body: This accepts any `http://` Cube API URL, and `doJSON` later sends `Authorization: Bearer` whenever a CubeSandbox, Cube, or fallback E2B API key is present. That regresses the existing provider safety pattern that only allows plaintext loopback endpoints before credentials are attached, so a self-hosted `http://cubeapi.example.internal:3000` config can leak the token on the network. Please require HTTPS for non-loopback URLs when a key is configured, or add an explicit maintainer-approved insecure/no-auth mode.
  - confidence: 0.86
