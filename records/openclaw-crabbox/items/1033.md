- `impact:security`: The issue concerns possible disclosure of a trusted provider secret to an unapproved redirect destination.

## Summary

Keep open: current main and v0.36.0 still build the Scaleway SDK client without a same-origin redirect guard, while repository security docs and comparable providers establish this credential-destination boundary.

## What This Changes

Refuse cross-origin redirects for credentialed Scaleway SDK requests so the provider token cannot be replayed to a redirect-selected origin.

## Best Possible Solution

Land a focused security fix in the Scaleway provider that wraps the SDK HTTP client with a same-origin redirect guard for both default and runtime-supplied clients, preserving caller hooks and adding token non-delivery regression coverage.
