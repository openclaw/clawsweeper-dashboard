## Summary

This is a concrete, security-sensitive Tart desktop exposure report with a source-level path and no evidenced current-main fix or canonical replacement. Keep it open for a maintainer security-boundary decision before attempting a repair.

## What This Changes

The issue reports that desktop-enabled Tart leases expose macOS Screen Sharing to the host-local network while the default guest account retains the shared `admin`/`admin` credential.

## Best Possible Solution

Make desktop acquisition safe by refusing the known shared default credential until Crabbox can reliably install a unique per-lease Screen Sharing credential, and restrict direct listener reachability where the supported Tart networking model permits it; preserve and test explicitly configured non-default credentials.
