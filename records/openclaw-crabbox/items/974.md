## Summary

This security report should stay open: current main still has the described fallback redaction gap in both the Go CLI and Worker redactors, and related open reports cover adjacent redaction misses rather than superseding this exact `}`/`&`/`#`/`?` suffix-leak case.

## What This Changes

The issue requests hardening Crabbox diagnostic redaction so fallback header and standalone bearer matching redacts complete credential-like values instead of leaving suffixes after selected stop characters.

## Best Possible Solution

Harden the shared redaction policy in both Go and Worker, add focused regression coverage for the reported stop characters, and have maintainers decide whether to land it together with the adjacent diagnostic-redaction security fixes.
