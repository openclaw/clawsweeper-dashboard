- `impact:security`: The issue concerns stale bridge credentials being accepted after the authorization basis has been revoked.

## Summary

Keep open: current main still stores WebVNC and Code backend tickets without GitHub bridge-grant material and consumes them without the GitHub revocation check that egress tickets now perform.

## What This Changes

The issue requests WebVNC and Code backend bridge tickets to preserve and revalidate GitHub bridge grants at consumption time, matching the egress ticket path.

## Best Possible Solution

Align WebVNC and Code tickets with egress by storing CachedBridgeGrant context, rejecting revoked GitHub grants before WebSocket acceptance, deleting stale tickets, and adding Worker regression coverage for the revoked-ticket path.
