## Summary

Keep this issue open for a product-direction decision. Replicate is absent from current main and v0.38.0, while the only implementation candidate, https://github.com/openclaw/crabbox/pull/690, closed unmerged without live Replicate proof. The delegated-run architecture can accommodate this provider, but Crabbox still needs an intentional decision about owning a built-in integration whose behavior depends on a separately maintained runner contract.

## What This Changes

Requests a built-in Replicate delegated-run provider backed by a compatible Replicate runner model or deployment.

## Best Possible Solution

Define and validate a versioned delegated-runner contract first, including archive transport limits, exit-code and log semantics, cancellation, credential isolation, and one end-to-end Replicate deployment proof; then accept a focused built-in adapter only if maintainers agree to support that contract.
