## Summary

Current main still exposes exact authenticated organization and owner values through reversible public-link path segments, and no open issue or pull request owns this distinct confidentiality gap. The issue should remain open for a maintainer security-boundary decision because the fix must preserve both the shipped namespace-isolation guarantees and existing published URLs.

## What This Changes

Prevent public artifact URLs from reversibly disclosing authenticated organization and owner identities.

## Best Possible Solution

Mint future grants under a versioned deployment-keyed pseudonymous identity namespace, retain existing v2 URLs, document secret-rotation and public-metadata behavior, and add route-level confidentiality and isolation regression tests.

Rationale: This choice establishes both a cryptographic key-lifecycle contract and a persisted storage compatibility boundary that automation should not invent.

Likely owner: steipete

Owner confidence: high

Options:

- **Domain-separated existing secret (recommended):** Derive v3 organization and owner pseudonyms from an existing stable deployment secret with domain separation while leaving all v2 URLs valid.
- **Dedicated namespace secret:** Add a separate versioned artifact-namespace secret with explicit setup, rotation, and migration documentation.
- **Accept documented disclosure:** Retain reversible v2 segments and explicitly document that public artifact links expose exact authenticated identity metadata.

## Reproduction Assessment

Yes at source level: the current key builder, public-read URL path, documentation, and route test prove that exact organization and email-form owner strings are reversibly encoded into returned public URLs. A runtime deployment is not required to establish this deterministic disclosure.

## Solution Assessment

The proposed non-reversible namespace direction is correct, but the best implementation is a new versioned keyed pseudonym scheme that preserves existing v2 links and the current byte-level isolation guarantees. The secret source and rotation contract require maintainer approval.
