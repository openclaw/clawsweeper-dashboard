## Summary

Keep open: current main and the latest release still omit several Azure/GCP provider credential identifiers from the coordinator exact-value redaction set, while the provider registry and security docs treat those configured values as credential material that should be redacted.

## What This Changes

The issue asks Crabbox to redact Azure tenant/client/subscription IDs and the GCP service-account email value in coordinator diagnostics alongside other required provider secrets.

## Best Possible Solution

Make the coordinator exact-redaction source derive from provider registry `requiredSecrets` where possible, then add focused tests for Azure UUID-like identifiers and GCP service-account email values across returned and persisted diagnostics.

Rationale: The source and docs support the report, but accepting identifier redaction as the security boundary is a maintainer-owned security-policy call before shipping the fix.

Likely owner: Peter Steinberger

Owner confidence: high

Options:

- **Redact all required provider secrets (recommended):** Treat the Azure/GCP identifiers as configured provider credential material and make the diagnostic redaction source registry-driven or otherwise complete.
- **Document identifiers as routing context:** Keep those identifiers visible only if maintainers explicitly decide they are non-secret routing context and update the security guide to narrow the redaction promise.
- **Redact only selected identifiers:** Patch the four reported values directly, but accept a higher chance of future provider-registry drift unless tests enforce the policy.

## Reproduction Assessment

Yes. Source inspection shows the exact redaction list excludes the reported configured values while the generic patterns do not redact bare UUIDs or service-account email values by themselves.

## Solution Assessment

Yes, with a provider-neutral implementation. The narrowest maintainable fix is to feed all configured provider required-secret values into coordinator diagnostic redaction and add regression coverage for the omitted identifier shapes.
