## What This Changes

The PR resolves Semaphore pagination Link targets against the configured API origin, rejects authority-changing URLs, and adds regression fixtures preventing provider credentials from being sent to another host.

## System Context

The Semaphore provider lists projects across paginated API responses and follows the response Link header with an authenticated HTTP client. Pagination-link validation sits between an untrusted server-provided URL reference and the next request that carries the provider token.
