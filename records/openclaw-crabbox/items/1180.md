## What This Changes

The branch resolves Semaphore pagination `Link` targets against the configured API origin, rejects authority-changing references, and adds HTTP-fixture regression coverage to ensure credentials are not sent to an attacker-controlled host.

## System Context

The Semaphore provider uses pagination `Link` headers while resolving projects through its authenticated API client. Pagination targets determine the next outbound request, so validation here protects the configured API origin and bearer token before another page is fetched.
