## What This Changes

The branch resolves Semaphore pagination `Link` targets against the configured API origin, rejects authority-changing references, and adds regression coverage to prevent API credentials reaching another host.

## System Context

The Semaphore provider uses an authenticated HTTP client to discover and lease CI jobs for Crabbox. Pagination links from Semaphore responses feed subsequent authenticated requests, so URL resolution determines whether the bearer token remains scoped to the configured provider origin.

## Best Possible Solution

Preserve same-origin-only pagination for authenticated Semaphore requests, with focused tests for accepted same-origin links and rejected malformed, userinfo, and cross-origin links, then add redacted provider-runtime evidence before merge.
