## Summary

Keep open for security triage. The report identifies a concrete current-main credentialed Tencent Cloud request path that appears able to follow 307/308 redirects, but the provider redirect boundary and compatibility policy require explicit human approval before a repair is promoted.

## What This Changes

Add origin-confining redirect handling to Tencent Cloud API requests so credentials and cloud-init request bodies are not replayed to a different scheme, host, or effective port.

## Best Possible Solution

Clone the effective Tencent HTTP client per provider instance, reject redirects that leave the initiating request’s HTTPS origin and effective port with a redacted error, preserve a stricter caller policy, and add negative regression coverage proving headers and bodies do not reach rejected targets.
