## Summary

The reported duplication is real, but this implementation is unsafe to merge: globally sharing the parent namespace can discard legitimate child usage, cached siblings do not reclaim replay ownership after file removal, and the generated parser hash does not correctly invalidate old cache entries.

## What This Changes

The PR uses `forkedFromId` as the deduplication namespace for forked Codex rows, updates the generated parser hash, and adds an unresolved-parent sibling regression test.

## Best Possible Solution

Deduplicate fork-family replays only with copy-stable event identity, persist deterministic ownership and migration across cached refreshes and file removal, keep ambiguous rows fail-open, regenerate the parser hash, and prove initial and cached scans against a redacted real corpus.
