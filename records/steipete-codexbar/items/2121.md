  - body: Pass the child session ID as `sessionId` and the parent separately as `forkedFromId`.   - confidence: 0.98

  - body: Limit invalidation to siblings that will be rescanned, or rescan every removed cached sibling. The current family selection can delete historical siblings outside the active file list while rescanning only active-window paths, leaving retained cache ranges with missing days.
  - confidence: 0.96
- **[P2] Filter cached forks against earlier contributors:** `Sources/CodexBarCore/Vendored/CostUsage/CostUsageScanner.swift:2688`
  - body: Run fresh cached fork rows through row-level uniqueness filtering whenever parent-scoped keys may already exist. Merely remembering cached rows retains replayed days when a restored parent or earlier sibling has already contributed the same turns, so totals can remain duplicated until a force rescan.
  - confidence: 0.98
