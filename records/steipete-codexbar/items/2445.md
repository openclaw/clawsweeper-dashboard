## What This Changes

The PR changes Claude’s menu action so authenticated accounts use the shared “Switch Account…” action while signed-out accounts keep the Claude Code sign-in action.

## System Context

CodexBar’s provider menu turns a provider usage snapshot and recovery state into account actions in the macOS menu bar. Claude can override the shared action for web re-login or terminal recovery, and otherwise should defer to the account-state result.
