## Summary

The shared resolver change appears aligned with the reported automatic-display behavior and has focused unit coverage, but this external UI PR still needs after-fix runtime proof before merge and should preserve confidence that provider-specific window semantics remain valid.

## What This Changes

The PR changes automatic quota selection to prefer the most-used available window, updates localized pace formatting to use the resolved app locale, and adds resolver tests for exhausted multi-window quotas.

## Best Possible Solution

Keep the common highest-usage resolver only after a redacted fresh-bundle capture demonstrates that automatic mode selects an exhausted non-primary quota without regressing representative provider-specific window meanings.
