## Summary

Keep this PR open: the generalized resolver can still hide a provider with a partially exhausted quota from the highest-usage display, and the locale change bypasses the existing stringsdict pluralization path. The proposed behavior is useful, but it needs those repairs plus after-fix runtime evidence before merge.

## What This Changes

This PR changes automatic quota-window resolution to select the highest-used window across default providers, updates forecast text formatting to use the app-resolved locale, and adds resolver tests.

## Best Possible Solution

Retain the exhausted-window priority while making highest-usage exclusion depend on all relevant lanes being exhausted, and preserve stringsdict-aware plural formatting with the resolved app locale; then attach redacted after-fix menu/runtime evidence.
