## What This Changes

This branch adds a local Codex Workspaces foundation that attributes existing Codex usage scans to projects, sessions, models, and days, then persists derived snapshots in a CodexBar-owned SQLite sidecar.

## System Context

CodexBar scans local Codex rollout files and reads Codex catalog metadata to calculate usage. This change turns those inputs into scoped project/session/model snapshots stored locally for a later menu and inspector integration.
