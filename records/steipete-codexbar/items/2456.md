## What This Changes

Adds a local Codex Workspaces indexing foundation that derives project, session, model, and daily usage from existing local Codex data and stores it in a new cache and SQLite sidecar.

## System Context

CodexBar’s local cost scanner reads Codex rollout files and its thread catalog, then produces cached usage totals for the menu-bar app. This PR adds a scoped attribution index and a CodexBar-owned SQLite sidecar between those local inputs and future presentation/UI consumers.
