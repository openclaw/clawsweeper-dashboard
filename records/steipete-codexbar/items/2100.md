## Summary

The updated PR now has credible real-path proof and has removed the release-owned changelog edit, but it still introduces a blocking compatibility regression: discovery selects only the first installed Tailscale executable and never reaches the working app fallback when that candidate fails. Keep the PR open for the narrow fallback repair.

## What This Changes

The PR makes Agent Sessions probe standard Tailscale CLI locations before the app executable, injects a shell marker to keep probes headless, and adds focused ordering and environment tests.

## Best Possible Solution

Keep the standard-path lookup and headless environment safeguard, but try executable candidates sequentially and accept only the first successful, parseable Tailscale status response.
