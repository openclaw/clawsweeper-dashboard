## Summary

Keep this issue open: current `main` still gives Codex historical predictions precedence over an explicit work-day schedule, and the open linked pull request is the appropriate fix candidate. ## What This Changes

Make Codex weekly pace honor explicit 4-, 5-, or 7-day schedules when historical tracking has enough data to activate.

## Best Possible Solution

Land a focused implementation where Automatic may use Codex historical predictions, explicit 4/5/7-day schedules use the work-day-aware curve, history continues collecting in the background, and settings copy plus regressions clearly document the precedence.
