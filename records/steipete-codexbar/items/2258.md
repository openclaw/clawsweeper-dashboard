## Summary

Keep open: the leak diagnosis is credible, but the proposed EMFILE guard has a check-then-act race that can still reach the same Foundation precondition and SIGILL under concurrent descriptor pressure. Real Linux behavior proof is also not attached for inspection.

## What This Changes

The PR explicitly closes completed pipe read handles, adds a Linux fallback when descriptor duplication fails, and adds a repeated-capture file-descriptor leak test.

## Best Possible Solution

Keep explicit post-capture handle closure, replace the preflight duplication with a Linux capture path that cannot invoke Foundation's trapping setter when descriptors are exhausted, and validate both repeated cleanup and concurrent near-limit startup in a real Linux daemon run.
