## Summary

Keep open for maintainer-directed product tracking: current main now supports several provider-specific multi-account patterns, but the requested generic duplicate-provider-instance model is intentionally not the chosen architecture and the remaining scope needs an explicit umbrella disposition.

## What This Changes

Add generic, independently labeled provider instances so one provider can monitor multiple accounts with separate credentials or data directories.

## Best Possible Solution

Retain provider-specific credential ownership, expand simultaneous display through the neutral account-snapshot and token-account paths, and use the linked focused issues for remaining display and account-management ergonomics.
