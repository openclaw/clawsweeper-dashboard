The issue proposes a `codexbar guard` command that converts provider quota headroom into automation-friendly exit codes and optional structured output.

## Best Possible Solution

Establish a narrow `guard` contract only after maintainer approval, reuse the existing single-provider fetch pipeline without interactive credential access, document stable exit semantics, and cover safe, insufficient, boundary, unknown, and fail-open decisions with focused tests.
