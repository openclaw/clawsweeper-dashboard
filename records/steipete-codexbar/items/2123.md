## Summary

This is a current, evidence-backed Codex quota gap rather than a cleanup candidate. The reported Plus account supplies only a weekly window, while the repository promises session and weekly usage; however, the safest recovery behavior needs maintainer direction because broad CLI fallback previously caused recurring process and token costs.

## What This Changes

## Best Possible Solution

Preserve legitimate weekly-only plans, but for plans expected to have a five-hour quota, reconcile the missing lane from a same-account source without enabling recurring background CLI fallback; if recovery is unavailable, show an explicit unavailable state with a useful diagnostic.
