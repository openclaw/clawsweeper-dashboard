## What This Changes

The PR makes LongCat’s Automatic cookie import check Firefox after Chrome and updates the provider’s browser-order regression test.

## System Context

CodexBar chooses browser cookie sources from provider-specific metadata when a provider is configured for Automatic import. The selected browser order feeds the shared cookie reader, which obtains the LongCat session used by the provider’s authenticated usage requests.
