## Summary

Current main does not provide the requested all-provider accounting summary: the merged Overview colocates selected provider data, while cost reporting remains split between local Codex/Claude estimates and provider-specific spend or budget snapshots. The request fits CodexBar’s vision, but it needs maintainer sponsorship because safe totals require explicit rules for compatible units, currencies, estimated versus billed spend, overlapping sources, time ranges, and persisted provider inclusion.

## What This Changes

Add Overview and CLI summaries that aggregate compatible token and cost data across selected providers, with time ranges, provider breakdowns, currency handling, estimate labeling, and double-count protection.

## Best Possible Solution

Define a shared provider-contribution model that emits typed token periods and currency-separated monetary amounts with source identity, estimation status, and deduplication metadata, then use that single report for an Overview summary and explicit CLI all-provider mode while visibly listing exclusions and unavailable values.
