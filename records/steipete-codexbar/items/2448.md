## Summary

Keep this issue open for maintainer review. The related report says the existing Alibaba Token Plan provider already has an international Team Edition endpoint, while this report says its international Model Studio cookie and quota path still fails; resolving that conflict needs a real international-plan capture and source-level confirmation before closing or implementing.

## What This Changes

Support Alibaba Model Studio’s international token-plan console so cookie discovery and quota fetching work for subscriptions managed at the international host.

## System Context

CodexBar’s provider probes obtain browser or manual cookies, call each provider’s subscription APIs, and turn returned quota data into menu-bar usage status. The Alibaba Token Plan path must select the correct regional console host and response shape before it can show an account’s remaining quota.

## Best Possible Solution

Confirm the authenticated international Model Studio request/response shape from a redacted subscribed-account capture, then make regional host selection explicit in the existing Alibaba provider path and add fixture-based tests for the international response without mixing China-mainland account data.
