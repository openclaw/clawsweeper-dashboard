## Summary

## What This Changes

The branch prevents CodexBar from directly reading Claude Code’s Keychain credential, uses safe direct OAuth sources before an authenticated Claude CLI fallback, partitions OAuth caches by Claude profile, and updates tests, docs, and the ownership verifier.

## System Context

CodexBar’s Claude provider chooses a usage source from direct OAuth credentials, the locally authenticated Claude CLI, Web, or an Admin API key. This change sits between credential discovery and provider fetching, then affects menu usage results, account identity reconciliation, cached OAuth state, and user recovery actions.
