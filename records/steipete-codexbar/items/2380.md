## What This Changes

This PR stops CodexBar from directly reading Claude Code’s Keychain credential, then routes Claude usage through safe direct OAuth sources or the authenticated Claude CLI while adding profile-scoped cache compatibility, test isolation, live verification, and documentation.

## System Context

CodexBar’s Claude provider selects a credential and usage source for the app or CLI, then sends the resulting usage snapshot to the menu bar and command-line output. This PR changes the boundary between Claude-owned credentials, CodexBar-owned OAuth cache data, source fallback decisions, and account-state reconciliation.
