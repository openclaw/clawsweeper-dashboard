## Summary

The implementation is focused and has strong mirrored test coverage, but this external feature PR still needs real two-account behavior proof and an explicit maintainer decision on whether an optional claude-swap failure may turn otherwise successful ambient CLI output into a command failure.

## What This Changes

The PR makes enabled claude-swap inventories with two or more accounts replace ambient Claude output in full and brief CLI cards, with active and sentinel rendering, bypass rules, diagnostics, documentation, and mirrored macOS/Linux tests.

## Best Possible Solution

Keep automatic multi-account cards opt-in, preserve successful ambient exit status when only the optional adapter fails unless maintainers explicitly choose strict behavior, and merge only after redacted real two-account terminal proof confirms full and brief output.
