## What This Changes

Show optional Claude Code model-scoped quota labels, such as `Fable only`, in provider usage data and its CLI/menu-bar presentations while omitting unavailable metadata.

## System Context

CodexBar’s Claude provider reads OAuth or web usage responses, converts provider-specific quota records into shared named rate windows, and feeds those windows into the generic usage snapshot used by JSON, CLI, and menu-bar displays. The mapper keeps model scope attached to the specific Claude quota window without mixing identity or plan data from another provider.
