## What This Changes

Reorders Claude web/session and OAuth extra usage rows so model-scoped weekly limits appear before Daily Routines, adding three focused parser regression tests.

## System Context

CodexBar collects Claude usage from web/session and OAuth responses, maps optional usage windows into ordered extra rows, and passes those rows to the Claude menu-bar card. This PR changes the ordering contract between the usage parsers and the card without changing the reported usage values.
