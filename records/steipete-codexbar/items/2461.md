## What This Changes

The PR changes the Claude web/session and OAuth usage paths so model-scoped weekly rows render before the Daily Routines row, without adding a user setting.

## System Context

CodexBar obtains Claude usage from web/session, OAuth, or CLI sources and converts optional quota windows into ordered rows for the Claude card and CLI output. The changed web and OAuth paths determine the extra-row sequence before the card model displays it; the CLI path keeps the source order from Claude CLI output.
