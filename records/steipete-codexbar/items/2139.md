## Summary

Keep this PR open, but do not merge the current head: the linked intermittent-output bug is credible, while the new unconditional PTY-closure break can regress commands whose PTY descriptors close before the child exits, and after-fix real behavior proof is still absent.

## What This Changes

The PR adds a bounded late-output drain to the non-Codex PTY deadline path, treats PTY closure as terminal for polling, and adds a regression test for retaining delayed OAuth prompt output.

## Best Possible Solution

Drain late readable output without equating PTY closure with child termination: continue waiting for a live child up to the configured deadline, add a regression for closed PTY descriptors followed by a delayed successful exit, and demonstrate both cases with a redacted live terminal transcript.
