## What This Changes

The PR adds a one-shot, interaction-aware viewport restoration that returns an oversized tracked menu to its provider header after the initiating manual refresh clears an error.

## Best Possible Solution

Manual refreshes should re-anchor only their initiating oversized menu after layout settles, while background refreshes and any deliberate user interaction, menu lifecycle change, submenu activity, or provider/account switch preserve the current viewport.
