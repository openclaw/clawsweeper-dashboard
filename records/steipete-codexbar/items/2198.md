## Summary

The core fix is valid and has useful real-app evidence, but the latest patch still filters unlimited direct snapshots only after response decoding has preferred them over finite monthly or limited-user fallbacks. This can suppress a real metered Copilot quota bar for mixed payloads, so the PR needs a narrow fallback-selection correction before merge.

## What This Changes

The PR removes Copilot quota snapshots marked unlimited from displayed usage windows, preserves finite Premium and Chat bars, and adds focused regression tests plus release text.

## Best Possible Solution

Treat an unlimited direct snapshot as unusable during per-lane response fallback selection, choose any valid finite monthly or limited-user snapshot for that lane, and omit the bar only when no metered snapshot exists; lock this down with mixed-payload regression coverage.

## Solution Assessment

No, not yet. Filtering unlimited markers is correct, but it must happen before or during per-lane fallback selection so finite fallback quotas remain visible.
