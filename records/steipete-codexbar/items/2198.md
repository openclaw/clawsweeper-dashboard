## Summary

The UX fix is valid and the before/after screenshots demonstrate the intended result, but the current head filters unlimited snapshots only after response decoding has already preferred the direct snapshot over finite monthly or limited-user fallback data. The existing P2 review concern therefore remains merge-blocking: mixed responses can lose a real finite quota bar.

## What This Changes

Filters explicitly unlimited Copilot quota snapshots from rendered usage windows, preserves plan identity, and adds regression coverage for unlimited and finite quota responses.

## Best Possible Solution

Make unlimited direct snapshots ineligible during Copilot lane selection so finite monthly or limited-user fallbacks remain available, while returning no window when every candidate is unlimited; cover both mixed-lane cases with regression tests.
