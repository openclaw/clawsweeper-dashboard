## Summary

This active PR remains necessary because current main still converts an explicitly unlimited Copilot quota marker into a misleading empty usage bar. The latest head narrowly fixes that behavior, preserves finite fallback quotas and decoded unlimited markers, and addresses both earlier review comments; it should remain open for normal completion of exact-head checks.

## What This Changes

This PR suppresses explicitly unlimited Copilot quota bars while preserving finite Premium or Chat fallbacks, account metadata, regression coverage, and release-note context.

## Best Possible Solution

Keep unlimited markers in the decoded provider model, prefer any real finite fallback for the same lane, and suppress only explicitly non-metered snapshots when constructing user-visible rate windows.
