The implementation, regression coverage, and before/after UI proof support normal merge review rather than cleanup closure.

The PR filters explicitly unlimited Copilot quota snapshots from metered usage windows while preserving finite Premium or Chat quotas, plan and identity metadata, and regression coverage.

## Best Possible Solution

Merge the fetcher-boundary filter after the exact head completes required checks, retaining the finite-quota and metadata regression cases so unlimited markers cannot reappear as actionable usage bars.
