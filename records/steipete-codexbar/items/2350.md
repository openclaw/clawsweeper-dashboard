## Summary

The request remains necessary: current documentation describes Claude Admin API output as organization-level spend/messages, while Anthropic supports workspace grouping. The feature is plausible but needs a maintainer decision on whether it belongs in the compact menu-card experience and what its opt-in UX should be.

## What This Changes

Add an optional Anthropic Admin API workspace-level spend breakdown that preserves the current organization summary by default.

## Best Possible Solution

If sponsored, retain the organization summary by default and add a bounded opt-in detail surface that handles workspace labels, the default workspace, pagination, sorting, and large-workspace truncation explicitly.
