## Summary

Keep this open: current main still presents bounded recent cost data rather than a dedicated all-time ledger, and the related merged cost-window work explicitly states that it does not implement this request. The idea fits CodexBar’s spend-control purpose, but the lifetime-data contract needs maintainer product sign-off before implementation.

## What This Changes

Add a persistent all-time usage and cost view that distinguishes durable usage history from retention-limited local cost data.

## Best Possible Solution

Approve a compact lifetime view only if it clearly separates full local usage-history coverage from the independently retained local cost estimate, labels the coverage start and gaps, and avoids implying that it is an authoritative provider bill.
