## What This Changes

Add Volcengine Coding Plan support that exposes session, five-hour, and weekly usage windows in CodexBar.

## System Context

CodexBar's provider probes turn account credentials and provider API responses into usage windows shown in the menu-bar app and CLI. The Doubao/Volcengine path must keep provider-specific credentials and plan data separate while mapping supported usage data into CodexBar's shared usage display.
