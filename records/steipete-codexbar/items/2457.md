## What This Changes

Adds CLIProxyAPI evidence collection and attribution so Claude Code usage routed through that proxy can be priced under the appropriate upstream provider totals and displayed with route provenance in the spend dashboard.

## System Context

CodexBar scans local Codex and Claude Code session data into cached daily cost reports, then aggregates those reports for provider totals and the spend dashboard. The new CLIProxyAPI resolver combines local proxy logs, telemetry, and configured upstream metadata to decide which Claude Code records should be shown as proxied Codex usage.
