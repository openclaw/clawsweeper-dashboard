## Summary

Keep open: current main has the Phase 1 Claude multi-account foundation and stacked menu cards, but per-account status-bar items remain a documented later phase and the owner comment explicitly left the product choice open.

## What This Changes

The issue requests an opt-in way to display multiple accounts for the same provider directly in the status bar/menu bar.

## Best Possible Solution

Implement the accepted selected-account status-item mode when maintainers are ready: opt-in per provider, replace the aggregate provider item, cap at four accounts, disable while Merge Icons is enabled, and use privacy-safe aliases or ordinals.
