## Summary

Keep open: current main has the Claude multi-account menu-card foundation and an accepted design, but the requested per-account status bar items are still a later product decision and the owner comment explicitly left this issue open.

## What This Changes

The issue requests showing multiple accounts for the same provider as independent status bar icons so each account's usage can be monitored without opening the menu.

## Best Possible Solution

Graduate the documented Phase 2 design: opt-in selected account icons, capped at four, replacing the provider item, disabled while Merge Icons is enabled, with privacy-safe aliases and migration/model tests.
