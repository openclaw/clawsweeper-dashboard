## Summary

Keep open: current main still creates status bar items at provider scope, while the merged architecture document and owner comment say per-account status item behavior remains a product choice with no runtime or persistence change yet.

## What This Changes

Request to show multiple accounts for the same provider as separate or selectable status bar items so each account's usage is visible without opening the menu.

## Best Possible Solution

Land the maintainer-approved provider-neutral account snapshot path first, then add opt-in, capped selected-account status items that replace the provider item, preserve upgrade placement, respect privacy, and stay mutually exclusive with Merge Icons.

## Reproduction Assessment

Not applicable; this is a feature request, not a broken-behavior report. Source inspection confirms the missing behavior because current status items are provider-scoped while multi-account displays live inside menus.

## Solution Assessment

Unclear until maintainers finish the product choice; the merged design now favors selected account icons that replace a provider item rather than the original additive toggle. The narrowest maintainable path is to follow that provider-neutral design after adapter/model proof.
