## Summary

Keep open: current main still cannot render multiple same-provider accounts as separate status bar items, and the merged architecture record plus owner comment explicitly leave the runtime/status-item work for product and auth-boundary decisions.

## What This Changes

Request per-account status bar visibility for multiple accounts under the same provider so each account's usage can be monitored without opening the menu.

## Best Possible Solution

Implement the accepted provider-neutral account snapshot path first, then add opt-in selected account status items that replace the provider item, cap selected accounts, preserve existing provider positions, and stay mutually exclusive with Merge Icons.

## Reproduction Assessment

Not applicable as a bug reproduction: this is a feature request. Source inspection still confirms the missing capability because current main has provider-scoped status item identity/storage and no account-scoped status item case.

## Solution Assessment

No for the original additive toggle as written; the narrower maintainable direction is the documented selected-account replacement mode after provider-neutral account snapshots land.
