## What This Changes

The issue requests showing multiple accounts for the same provider as separate or independently visible menu bar status items so each account's usage can be monitored without opening the menu.

## Best Possible Solution

Use the accepted provider-neutral account snapshot path, then add opt-in selected account status items that replace the provider item, cap selected accounts, preserve existing provider positions, and stay mutually exclusive with Merge Icons.
