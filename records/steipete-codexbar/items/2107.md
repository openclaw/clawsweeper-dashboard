## Label Justifications

- `P3`: This is a non-blocking, opt-in UI ergonomics feature for heavy multi-provider users rather than a regression or broken workflow.
- `impact:ux-friction`: Users with more than three active providers can continue by scrolling or switching tabs, but the current cap prevents the requested single-glance workflow.

## Summary

Current main and the latest release still intentionally limit Overview to three providers, while the requested compact mode and higher cap are new UX and configuration choices that fit CodexBar’s purpose but require product sign-off.

## What This Changes

Requests an opt-in compact Overview layout and a configurable provider limit above three.

## Best Possible Solution

Add an opt-in, provider-driven compact Overview presentation that preserves the existing default, exposes secondary windows through an accessible disclosure control, and raises the selection cap only when the compact layout has bounded-height UI proof.
