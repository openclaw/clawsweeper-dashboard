## Summary

The final head still carries the new provider-scoped reset boundary across cached token-account activation, so a newly selected account with an earlier valid boundary can have its legitimate restored notification suppressed. The earlier missing-`resetsAt` finding was fixed, but this later account-switch blocker remains unchanged and should be repaired before merge.

The PR adds reset-boundary-aware Codex session notification transitions, monotonic boundary recording, centralized transition-state cleanup, and focused regression tests for transient zero samples.

## Best Possible Solution
