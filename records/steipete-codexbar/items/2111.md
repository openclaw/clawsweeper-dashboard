## Summary

The prior unset-cadence compatibility finding is fixed, but this PR still silently expands an existing Adaptive preference to authorize recurring local process and transcript-metadata scans. The fresh-install rollout also requires explicit maintainer approval and stronger packaged-app proof.

## What This Changes

The PR makes Adaptive the persisted fresh-install cadence, incorporates recent local Codex and Claude activity into scheduling, and reuses the local Agent Sessions scanner while keeping its UI and remote features disabled by default.

## Best Possible Solution

Separate cadence choice from local-activity consent: preserve menu-only behavior for existing Adaptive users, require explicit or versioned fresh-install authorization for agent-aware scanning, and approve a new default only after packaged fresh-install, upgrade, and sustained-runtime proof.
