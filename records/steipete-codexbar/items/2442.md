## Summary

Keep this PR open for normal review. The implementation is narrowly scoped and its focused tests cover the intended bundled-OpenAI and unambiguous catalog fallbacks, but it needs redacted after-fix evidence from a real Claude proxy usage scan before merge; model-ID-only pricing also leaves a user-visible accuracy risk that maintainers should assess.

## What This Changes

The branch lets Claude usage logs price proxy-routed non-Anthropic model IDs through CodexBar’s existing OpenAI rates or a single unambiguous models.dev provider match, and refreshes the catalog before retrying unknown prices.

## System Context

CodexBar scans Claude Code JSONL history, turns token records into per-model cost breakdowns, and feeds those totals into the menu-bar and spend views. This PR changes the pricing-resolution layer between parsed model IDs and those aggregate cost displays.
