Keep open. ## What This Changes

Allow Claude model-scoped weekly usage rows to appear above Daily Routines, or provide a supported ordering/visibility control for optional Claude usage rows.

## System Context

Claude usage data is collected from OAuth, web, CLI, and optional claude-swap sources, then normalized into session, weekly, model-scoped, and optional Daily Routines windows. The menu-bar Claude card renders those windows as usage rows for users to compare their active quota limits.

## Architecture Diagram

flowchart TD
    A[Claude usage sources] --> B[Normalize quota windows]
    B --> C[Session and weekly rows]
    B --> D[Model-scoped weekly rows]
    B --> E[Daily Routines row]
    C --> F[Claude menu card]
    D --> F
    E --> F
    F --> G[Menu-bar usage display]

## Best Possible Solution

Choose one Claude-card policy for optional rows, then implement the smallest consistent version: a fixed scoped-weekly-before-Routines order if configurability is out of scope, or one narrowly documented visibility/order setting that also resolves the related request.
