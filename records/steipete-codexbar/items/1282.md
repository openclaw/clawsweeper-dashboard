## Summary

Keep open: current main still persists the named UI preferences in UserDefaults, and the only portable-preferences prototype was closed unmerged because the contract was unsafe and incomplete.

## What This Changes

The issue asks for syncable, JSON-backed CodexBar UI/application preferences instead of relying only on macOS User Defaults.

## Best Possible Solution

Approve a separate opt-in portable preferences file for a narrow non-secret allowlist, then wire SettingsStore import/export or dual-write behavior with upgrade tests and diagnostics.
