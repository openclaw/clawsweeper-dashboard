## What This Changes

The issue asks for general UI/app preferences to be stored in a version-control-friendly JSON config or preferences file for dotfiles syncing.

## Best Possible Solution

Define an opt-in portable preferences schema separate from secret-bearing provider config, preserve unknown fields or fail safely, wire only approved SettingsStore keys with clear precedence, and document diagnostics for import/export or sync.
