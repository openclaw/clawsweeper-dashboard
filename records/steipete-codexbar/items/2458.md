## What This Changes

This PR lets an explicit `codexbar cookie refresh --provider grok` import browser cookies, caches a validated Grok session for later usage fetches, and evicts that cache only after authentication failures.

## System Context

CodexBar gathers provider usage through CLI and web fetch strategies. Grok's web strategy may validate browser-derived cookies against its billing endpoint, then use a cached validated session for later background or CLI usage requests.
