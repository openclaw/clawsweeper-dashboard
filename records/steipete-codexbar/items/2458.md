## What This Changes

This PR permits an explicit Grok cookie-refresh command to import and cache a validated Chrome session, while ordinary CLI and background fetches remain browser-import gated and can reuse the cached session.

## System Context

CodexBar’s Grok provider fetches usage through CLI/auth-file data and, when needed, a browser-cookie billing fallback. The refresh command supplies provider interaction context to that fallback, which validates and caches a session for later app or CLI usage requests.
