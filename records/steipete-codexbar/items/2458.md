## What This Changes

This PR permits an explicit Grok CLI cookie refresh to import and cache a validated browser session while keeping ordinary CLI and background browser imports gated.

## System Context

CodexBar's Grok provider obtains account usage from local credentials and, when needed, a Chrome browser session. The provider's fetch strategy controls browser-Keychain access, saves validated cookie headers for later reuse, and supplies usage or identity-only results to the CLI and menu-bar app.

## Best Possible Solution

Retain the narrow explicit-refresh-only import rule, cache only successfully validated Grok sessions, and land after the owner confirms the interaction-context boundary and stale-cache fallback behavior on the final head.
