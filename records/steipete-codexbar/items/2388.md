## What This Changes

The PR makes refresh-all-on-menu-open schedule a nonblocking forced token-cost rescan and coalesces overlapping requests so cost data refreshes even when another token sequence is active.

## System Context

CodexBar refreshes provider usage when its macOS menu opens, then publishes the resulting snapshots into the menu. Token-cost collection runs through a separate TTL-aware sequence, so this patch routes the refresh-all menu path through that existing coordinator to update the Cost row.
