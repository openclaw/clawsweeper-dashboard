## What This Changes

## Best Possible Solution

A stable guard command should share account resolution and placeholder-aware metric selection with `usage`, define explicit behavior for providers without a real session window, document its command-specific exit contract, and demonstrate both safe and blocked outcomes using redacted real-provider output.
