## Summary

Keep this PR open, but do not merge the current head: the new parse-failure preservation is provider-wide rather than restricted to the Claude CLI attempt, so Web/OAuth failures can retain stale usage bars. Likely related people: @steipete (high confidence) and @rohitjavvadi (medium confidence), based on the merged Claude CLI loading and resilience history.

## What This Changes

The PR changes Claude refresh failure handling to retain prior subscription snapshots after repeated parse failures or quota-unavailable responses and adds regression coverage in two test files.

## Best Possible Solution

Preserve parse-failure snapshots only when the terminal failed attempt is Claude CLI, retain the intended subscription-only behavior, add Web/OAuth non-preservation coverage, and demonstrate the reported CLI sequence with redacted runtime evidence.
