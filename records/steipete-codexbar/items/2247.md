## Summary

Keep this PR open: preserving snapshots across ordinary CLI parse failures is appropriate, but the quota-unavailable branch can retain stale subscription limits after a real plan transition, and the required after-fix behavior proof is missing.

## What This Changes

The PR retains prior Claude subscription snapshots across repeated CLI parse failures and quota-unavailable responses, with regression coverage in two Claude test suites.

## Best Possible Solution

Preserve the last-good snapshot for genuine CLI parse failures, but distinguish transient or ambiguous subscription-only parsing from authoritative Education or changed-plan responses, clearing stale limits for the latter and covering both paths with focused tests and a freshly built app run.
