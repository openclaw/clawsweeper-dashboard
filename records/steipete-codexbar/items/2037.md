## Summary

## What This Changes

Correct Ultra-mode Terra and Sol local usage accounting so forked or replayed context is not repeatedly attributed as new token and cost usage.

## Best Possible Solution

Implement a scan-wide fork-family provenance ledger with copy-stable event identity, cross-window family closure, collision-safe ownership and cache migration, while preserving distinct events and nonlinear pricing, then validate it against the sanitized corpus and redacted initial and cached repeat scans from an affected setup.
