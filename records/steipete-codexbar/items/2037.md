## Summary

Current main and v0.42.0 intentionally retain the known scanner baseline after the attempted fix was reverted, and the repository owner explicitly confirms that cross-file fork duplication remains unresolved.

## What This Changes

Correct Ultra-mode Pi usage accounting so copied ancestor context across fork-related session files is not counted repeatedly.

## Best Possible Solution

Add scan-wide fork-family and stable event provenance, preserve complete per-event context for nonlinear pricing, and verify exact token and dollar totals against a sanitized real Ultra fork corpus plus distinct-event, missing-parent, and cache-growth regressions.
