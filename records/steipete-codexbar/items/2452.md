## What This Changes

The PR limits local Codex session-log cost scans by skipping oversized files, applying a per-refresh byte budget, and processing newer sessions before older backlog files.

## System Context

CodexBar derives local token-cost history by scanning Codex session JSONL files and caching per-file totals for its usage display. The changed scanner decides whether a file can reuse cached data, be incrementally parsed, be fully rescanned, or be deferred until a later refresh.
