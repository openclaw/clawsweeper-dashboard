## Summary

Keep this PR open, but do not merge it yet. The diagnosis and coalescing approach are credible, while the blanket six-hour response to any timeout can suppress a healthy Claude CLI after transient slowness; the branch also lacks after-fix macOS proof and currently conflicts with `main`.

## What This Changes

The PR adds outcome-aware, coalesced Claude CLI auth probes, persists cooldowns for failed background Auto preflights, preserves explicit recovery paths, and adds focused regression tests.

## Best Possible Solution

Coalesce identical probes and use a short graduated backoff for generic failures, reserving a long persisted cooldown for repeated or specifically confirmed blocked-prompt behavior while explicit refresh and successful fetches clear the gate.
