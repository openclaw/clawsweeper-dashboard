## Summary

This PR is still necessary: current `main` performs persisted plan-history decoding synchronously during `UsageStore` initialization, while the branch moves that work off the main actor and protects persisted history from startup races. The current head resolves all earlier ClawSweeper findings, has no remaining actionable correctness or security defect, and should stay open for normal merge handling rather than cleanup closure.

## What This Changes

Moves persisted plan-utilization history decoding off the startup main thread, gates history access and mutation until loading completes, and adds async-load regression coverage plus deterministic test isolation.

## Best Possible Solution

Merge the one-shot utility-priority history decode after required checks complete, preserving atomic main-actor publication, startup mutation gating, and the existing persistence schema and account-ownership semantics.
