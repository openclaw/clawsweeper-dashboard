## Summary

## What This Changes

Moves persisted plan-utilization history decoding off the startup main thread, gates reads and mutations until loading completes, and adds focused asynchronous-load regression tests.

## Best Possible Solution

Make the gate remember cancellation or make `wait()` cancellation-aware so future waiter registration cannot suspend, add a regression test for immediate cancellation, rebase narrowly onto main, and demonstrate the fresh release bundle with a redacted startup trace or benchmark.
