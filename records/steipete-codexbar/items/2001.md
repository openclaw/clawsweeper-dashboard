## Summary

The hardened implementation remains useful, but newly available account-scoping evidence shows that `quota_low` transition state can cross-contaminate accounts; after that repair, the repository owner must still approve core command execution and the stable external event contract.

## What This Changes

Adds opt-in external command hooks for six quota and provider-state events across shared configuration, app settings, CLI commands, event detection, subprocess execution, localization, and tests.

## Best Possible Solution

Keep the opt-in direct-exec design, key every quota transition baseline by stable provider account ownership, add multi-account crossing regressions, and merge only after the repository owner explicitly accepts the trusted-command and event-compatibility contract.
