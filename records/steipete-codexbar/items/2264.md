## What This Changes

The PR adds picker-row action support and a refresh button for OpenCode and OpenCode Go that clears cached cookies, imports a browser session, and refreshes the provider.

## Best Possible Solution

Retain the last known-good cached cookie until a replacement imports successfully, render the control after the picker, and keep Chrome-first re-import behavior unless maintainers explicitly approve an all-browser recovery flow.
