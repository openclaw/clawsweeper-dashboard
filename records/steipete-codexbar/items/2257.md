## Summary

Keep this issue open: current main exposes provider-scoped model breakdowns but does not solve the requested cross-provider model view, and this new feature needs maintainer direction on scope and product semantics before implementation.

## What This Changes

Requests a model-centric token and cost view across providers, including canonical model identity, currency-safe reporting, double-counting controls, UI placement, settings, and CLI support.

## Best Possible Solution

Stage the work by first exposing provider-scoped model summaries in a dedicated detail surface with costs separated by source and currency, then consider cross-provider token aggregation only after maintainers approve canonical identity and provenance rules.
