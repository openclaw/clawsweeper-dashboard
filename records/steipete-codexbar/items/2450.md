Keep this PR open for ordinary maintainer review. The patch narrowly removes a fabricated Claude quota row when the payload has no routines data, preserves real windows, and now has direct runtime proof; likely related person: AISupplyGuy (feature introducer, medium confidence).

## What This Changes

The PR updates Claude OAuth and web usage parsing so a present-but-null routines payload produces no Daily Routines card row instead of a synthetic 0% quota window.

## System Context

CodexBar retrieves Claude usage through OAuth and web API routes, normalizes quota windows into usage-card rows, and renders those rows in the menu bar. This change affects the optional Daily Routines row when the upstream payload explicitly contains no usable routines window.

## Architecture Diagram

  B --> C{Routines window has utilization?}
  C -->|Yes| D[Create Daily Routines row]
  C -->|No or null| E[Omit routines row]
  D --> F[Claude usage card]
  E --> F

## Best Possible Solution

Merge the narrow null-payload correction while retaining the existing real-routines-window behavior and the two focused parser regressions; keep the separate general hide-option request in https://github.com/steipete/CodexBar/issues/2353 for product discussion.
