## What This Changes

This PR changes Claude OAuth and Claude web usage parsing so a present-but-null routines payload omits the Daily Routines bar instead of rendering a synthetic 0% quota.

## System Context

Claude usage data arrives through OAuth and web API payloads, then provider-specific parsers turn valid quota windows into a usage snapshot. That snapshot drives the menu bar card, so emitting a placeholder routines window creates a visible quota row even when the provider supplied no routines quota.

## Architecture Diagram

flowchart LR
    A[Claude OAuth or web payload] --> B[Claude usage parsers]
    B --> C{Usable routines window?}
    C -->|Yes| D[Daily Routines usage window]
    C -->|Null or incomplete| E[Omit routines window]
    D --> F[Usage snapshot]
    E --> F
    F --> G[Menu bar usage card]

## Best Possible Solution

Land the shared OAuth and web parser behavior after a redacted runtime capture shows null routines data omits the row and real routines data still renders it; leave the separate unconditional-hide option request to https://github.com/steipete/CodexBar/issues/2353.
