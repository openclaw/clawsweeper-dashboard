This was equally visible on the earlier reviewed head and is being raised late.
  - late: true

  - body: Modeling `nextDateReset` only as `Double?` makes decoding throw when AWS returns an ISO-8601 string; the decoder’s date strategy does not apply to a numeric field. Decode both representations so an otherwise valid response does not fall back to the broken CLI path. This was equally visible on the earlier reviewed head and is being raised late.
  - late: true
