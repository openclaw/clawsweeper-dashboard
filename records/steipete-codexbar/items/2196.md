## Summary

This PR addresses a valid unbounded-memory bug, but the previously reported line-buffer boundary defect remains at the current head and real process-level proof is still absent, so it is not ready to merge.

## What This Changes

Bounds accumulated PTY, CLI-session, and newline-delimited RPC output at 1 MiB, terminates overflowing child processes, and adds focused buffer tests alongside Linux CI and Claude platform-test changes.

## Best Possible Solution

Process complete newline-delimited records incrementally and enforce the limit only on the retained partial line, add a split-newline boundary regression test, separate unrelated CI/platform-test changes, and provide redacted terminal or runtime proof for normal and overflowing child processes.

- **[P2] Drain complete lines before rejecting the chunk:** `Sources/CodexBarCore/Host/Process/BoundedOutputBuffer.swift:50-52`
