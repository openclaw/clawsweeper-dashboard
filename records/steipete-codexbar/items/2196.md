## Summary

This draft remains necessary, but it is not merge-ready: the revised head still rejects valid newline-delimited output before draining complete records, and the PR provides tests rather than real process-level proof.

## What This Changes

The PR adds 1 MiB bounds to PTY and CLI output, introduces a shared bounded newline buffer for Codex and Grok RPC clients, terminates overflowing processes, and adds boundary tests.

## Best Possible Solution

Process incoming RPC bytes incrementally, drain complete records before enforcing the limit on the retained unterminated line, add a same-chunk cross-boundary regression test, and provide redacted synthetic process output for overflow and normal paths.
