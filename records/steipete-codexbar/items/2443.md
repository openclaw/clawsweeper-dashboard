## What This Changes

This PR fetches Claude prepaid Usage-credit balances through the Claude web API, merges a matching balance into Claude OAuth/CLI snapshots, and renders it as a Credits value in the menu and CLI.

## System Context

CodexBar collects provider usage from OAuth, CLI, and browser-backed web sources, then normalizes it into a usage snapshot for the menu bar, preferences view, and CLI. This change adds a separate prepaid-balance field to Claude’s cost snapshot and conditionally enriches primary Claude data with browser-session information.
