## Summary

This should not merge yet: the cache can retain stale versions behind stable wrappers, and unsuccessful probes can permanently cache diagnostic output. The latest real-executable transcript also does not demonstrate subprocess reuse or executable-change invalidation.

## What This Changes

The PR adds an executable-fingerprint cache and single-flight coalescing for Claude CLI version probes, with cache, invalidation, concurrency, retry, benchmark, and live-executable tests.

## Best Possible Solution

Keep single-flight caching, but use wrapper-safe bounded revalidation, cache only confirmed successful probe results, and provide redacted process or runtime-log proof of one cold subprocess, warm reuse, and one reprobe after a real target change.
