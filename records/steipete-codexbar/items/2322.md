## What This Changes

This branch replaces the basic Usage & Spend presentation with model- and tool-grouped history, broader local-session scanners, price-cache improvements, billing attribution, a token-activity heatmap, and localized dashboard UI.

## System Context

CodexBar collects usage from provider APIs and local CLI/session stores, normalizes it into token and cost snapshots, and renders those snapshots in its Usage & Spend preferences dashboard. This PR expands both the local collection layer and the dashboard’s aggregation/presentation layer, including model, tool, and subscription-oriented views.
