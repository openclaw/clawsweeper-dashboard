## Summary

This is a substantial, proof-backed dashboard feature, but the current branch has verified correctness gaps in its new local-history and subscription-attribution paths. It should remain open for targeted repairs and a maintainer decision on the dashboard’s billing-vendor versus tool semantics.

## What This Changes

This PR replaces the basic Usage & Spend presentation with model- and tool-grouped usage history, additional local session scanners, pricing and billing attribution logic, a 52-week token heatmap, and localized dashboard UI.

## System Context

CodexBar collects provider APIs and local CLI/session logs into normalized usage snapshots, then renders them in its macOS Usage & Spend settings pane. This PR expands the snapshot inputs and transforms them into model, client, and subscription-oriented dashboard views.
