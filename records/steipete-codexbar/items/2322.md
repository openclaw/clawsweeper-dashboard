This PR rebuilds the Usage & Spend preferences dashboard with model and tool views, local-history scanners for additional clients, pricing-cache recovery, subscription attribution, and a 52-week token activity heatmap.

## System Context

CodexBar collects usage data from provider APIs and local client session stores, normalizes it into token and cost snapshots, and renders those snapshots in the Usage & Spend preferences dashboard. This PR expands both the local-data ingestion layer and the cross-provider aggregation and presentation layer.
