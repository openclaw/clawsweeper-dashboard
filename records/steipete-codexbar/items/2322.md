## System Context

CodexBar collects usage snapshots from provider APIs and local CLI/application histories, then aggregates them into the Usage & Spend preferences surface. This PR expands the local-history inputs and changes how those snapshots are grouped into model, client, billing, chart, and heatmap outputs.
