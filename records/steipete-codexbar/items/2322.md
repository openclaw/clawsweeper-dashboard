## What This Changes

This PR rebuilds CodexBar’s Usage & Spend dashboard with model and tool views, broader local usage scanning, cost attribution, a 52-week token heatmap, and localized dashboard strings.

## System Context

The Usage & Spend dashboard combines provider snapshots and local CLI/session histories into daily token and cost records, then renders provider, model, tool, and subscription summaries in the macOS preferences UI. Local scanners feed the dashboard model; attribution and presentation layers transform those records into user-visible spend and usage views.

## Best Possible Solution

Use WAL-aware read-only SQLite access for every local database scanner and restrict fallback subscription labels to providers with an explicit plan-bearing identity contract, with focused regression tests for both behaviors.
