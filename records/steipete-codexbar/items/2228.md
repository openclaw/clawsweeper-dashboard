## Summary

The report and real-corpus proof strongly establish the copied-prefix overcount, but the proposed classifier has a merge-blocking edge case: later metadata without a concrete ID is treated as ancestor proof, which can reintroduce parent-baseline undercounting for reset-only subagents.

## What This Changes

The PR classifies explicit Codex subagent rollouts as independent or copied-prefix, accounts for a detected leaf-owned suffix, and retains parent cache dependencies only when accounting uses parent totals.

## Best Possible Solution

Keep the copied-prefix suffix design, but require a different concrete metadata ID to prove an ancestor when the leaf ID is known, preserve independent accounting for later idless metadata, and cover that mixed shape across both parsers and cache modes.
