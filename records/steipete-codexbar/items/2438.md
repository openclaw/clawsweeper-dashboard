## What This Changes

The PR parses Amp subscription-plan CLI output, exposes its “other” and “orb” pools as renewal-based usage windows, and labels those pools consistently in the menu card and widget.

## System Context

CodexBar gathers Amp usage through provider fetch strategies, parses the resulting CLI text into an Amp snapshot, then converts that snapshot into generic usage windows for the menu bar, widget, and CLI-facing status surfaces. The changed path begins with `amp usage` text and ends with two displayed subscription-pool metrics plus plan metadata.
