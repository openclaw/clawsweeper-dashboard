## Summary

Keep this PR open for a narrow repair: its new regression tests directly mutate the real `com.steipete.codexbar` UserDefaults suite, which conflicts with the stated goal of keeping ordinary test runs isolated from a developer’s persisted app state.

## What This Changes

The PR isolates Claude OAuth unit tests from local credentials, prompt preferences, and pending-cache state, and preserves prompt policy inside detached refresh work.

## System Context

CodexBar’s Claude OAuth provider combines credential-file state, app prompt preferences, cache markers, and delegated CLI refreshes to obtain usage data. The changed safety layer determines whether test runs use isolated substitutes before those provider paths read or write local state.

## Architecture Diagram

    State --> Regression[Isolation regression tests]

## Best Possible Solution

Keep all ordinary test assertions inside task-local or injected test stores, so the regression coverage proves isolation without ever opening or mutating the production application defaults suite.
