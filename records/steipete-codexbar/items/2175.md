## Summary

Keep this PR open for explicit maintainer resolution of the accounting contract, real-session proof, and conflict resolution. The official documentation supports the stated model multipliers for ChatGPT credit consumption, but separately describes API-key usage as token-priced; that does not by itself establish that multiplying Standard USD rates is the correct CodexBar metric. Likely related people: steipete for the pending product decision, iam-brain for prior pricing work, and 0xSMW for recent GPT-5.6 pricing history.

## What This Changes

The PR replaces explicit per-model Codex Priority rates with generation-based multipliers over models.dev-first Standard pricing, updates scanner cache fingerprinting, and adds focused pricing and scanner tests.

## Best Possible Solution

Define separate, documented accounting semantics for signed-in ChatGPT Fast credit estimates and API-key Priority token costs, preserve existing explicit rates until that boundary is approved, and validate the chosen path with a redacted real-session trace plus the displayed CodexBar result.
