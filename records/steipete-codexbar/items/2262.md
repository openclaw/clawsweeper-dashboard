## Summary

This draft PR should stay open with its paired feature issue: the current implementation can delete a valid cookie without restoring it, does not provide true refresh behavior for most providers, and still needs maintainer direction plus real runtime proof.

## What This Changes

Adds `codexbar cookie refresh` commands that clear provider cookie caches and attempt or defer browser-session re-import for one or all cookie-based providers.

## Best Possible Solution

Use one explicit command contract—preferably an opt-in re-import mode on the existing cache command or signed-app delegation—that honors each provider's metadata order, clears only when restoration can proceed safely, and reports imported versus deferred results accurately.
