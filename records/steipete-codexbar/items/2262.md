## Summary

Keep open. The current patch still appears to bypass each provider’s supported browser-import order in both settings actions, which can clear a valid cached session without refreshing users authenticated in other supported browsers; maintainer direction and real behavior proof are also still needed before merge.

## What This Changes

This PR adds `codexbar cookie refresh` CLI subcommands plus refresh buttons for OpenCode and OpenCode Go provider settings, with text/JSON reporting and cache re-import behavior.

## Best Possible Solution

Choose one supported cookie-recovery contract, make every immediate refresh use the provider’s automatic browser order, clearly limit or document immediate refresh to providers with dedicated importers, and validate both successful import and failed-import fallback behavior on a signed app.
