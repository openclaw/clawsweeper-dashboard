## Summary

The patch is a focused, technically sound fix for a real temporary-session lifecycle leak: current code creates a delegated ephemeral URLSession per Ollama request without invalidating it, and the added defer covers success and failure exits. The PR should remain open because its heap evidence demonstrates the leaking baseline but does not yet demonstrate after-fix resource stabilization; likely related people are @ratulsarna and @CryptoSageSnr.

## What This Changes

The PR invalidates each temporary Ollama dashboard URLSession after its request and adds a regression test asserting cleanup on an error path.

## Best Possible Solution

Keep the defer-based invalidation and focused regression test, then confirm the final branch with a redacted before/after Instruments or heap run showing temporary Ollama session resources stabilize across repeated refreshes.
