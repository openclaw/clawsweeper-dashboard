## Summary

The patch and proof are strong, but the current head leaves a Darwin descriptor-inheritance race that can make cleanup target an unrelated child process.

## What This Changes

The PR defers Codex RPC login-shell PATH capture, preserves login PATH for script overrides, adopts raw shell probes into process-group cleanup, and adds cross-platform lifecycle tests.

## Best Possible Solution

Make Darwin descriptor creation and inheritance safety global to the process-spawn boundary, or redesign output-holder cleanup so a transiently inherited probe descriptor can never authorize terminating an unrelated process, then add a concurrent unrelated-spawn regression test.
