## Summary

The central capability-aware gate is a sound fix direction, but the patch also lets no-prompt callers invoke the experimental `security(1)` reader, which has no enforced non-interactive contract and can therefore violate `.never` before reaching the explicit no-UI Security.framework fallback. The external PR also provides only synthetic proof, so it is not ready to merge.

## What This Changes

The PR changes Claude Keychain gating so `.never` permits callers marked as non-prompting and adds regression tests for missing-file repair, credential availability, and continued interactive-read denial.

## Best Possible Solution

Pass prompt capability through the experimental CLI reader as well, skipping `/usr/bin/security` whenever prompts are forbidden and using only `KeychainNoUIQuery`; retain the focused regressions and add redacted real macOS proof of silent missing-file recovery.
