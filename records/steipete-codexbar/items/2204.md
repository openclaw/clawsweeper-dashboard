## Summary

The merged fixes address only two explicitly partial subsets, and no later fix in the supplied current-main history completes the remaining process-global override migration. This issue still tracks meaningful test-race cleanup and should remain open.

## What This Changes

Migrate the remaining test-only process-global override setters to existing task-local scopes and remove their unsafe global storage and setters.

## Best Possible Solution

Re-inventory current main and finish the migration in small subsystem PRs by scoping tests with existing `with…OverrideForTesting` APIs, removing each proven-unused global setter and storage pair, and adding focused concurrent isolation and restoration coverage without accessing real credentials.
