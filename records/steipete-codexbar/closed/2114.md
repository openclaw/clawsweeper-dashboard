## Summary

Current main still offers separate provider status items or one merged icon, but not the compact multi-glyph group requested here. The idea remains useful, partially overlaps with the hybrid pinning proposal, and needs maintainer direction on interaction behavior before implementation.

## What This Changes

Requests a compact, visually grouped menu-bar presentation for multiple enabled provider icons.

## Best Possible Solution

If accepted, implement one compact status item that renders ordered provider glyphs and opens the existing merged menu, preserving current modes and defaults while avoiding independent per-glyph hit-testing complexity.
