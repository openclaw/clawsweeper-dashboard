## What This Changes

Fix the Linux `CodexBarCLI serve` subprocess pipe-descriptor leak that eventually exhausts `RLIMIT_NOFILE` and crashes while installing a `FileHandle.readabilityHandler`.

## Best Possible Solution

Give subprocess pipes explicit ownership: stop and drain capture, clear monitoring, close every parent-side read and write handle on success, failure, timeout, and cancellation, reject invalid descriptors before installing handlers, and add a Linux stress test proving descriptor counts remain bounded across repeated version probes.
