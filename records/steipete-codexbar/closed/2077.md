## Summary

Current main still lacks a mode that continuously shows quota percentage and reset timing together. The earlier matching request closed without implementation, so this fresh issue should remain open as the canonical product-sign-off request.

## What This Changes

Requests an opt-in menu-bar mode that displays usage percentage and time until quota reset together, with an optional pace-marker visualization.

## Best Possible Solution

Add one opt-in compact textual mode through the existing display-mode pipeline, reusing the selected metric window and reset formatter while preserving every current default; evaluate the pace-marker visualization separately.
