## What This Changes

This PR adds an opt-in `candidate/embed.css` export that translates MCP Apps host style variables into Carapace semantic tokens, with documentation, preview imports, package checks, and CSS-contract tests.

## System Context

Carapace provides shared design tokens and opt-in candidate layers for OpenClaw consumers. An MCP Apps host can resolve the scoped embed variables from Carapace, publish them to a sandboxed embedded app, and the app then uses those values to render host-consistent surfaces and typography.
