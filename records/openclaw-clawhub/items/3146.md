## Summary

Keep open: two independent publishers reproduced the same production failure on July 17, 2026, while current main’s publish contract expects an accepted version to create a release record and update its package or skill summary. No current-main fix, safe self-service recovery path, or canonical replacement item was found.

## What This Changes

Repair published skill and plugin versions whose version numbers are reserved even though the releases remain unavailable for inspection, discovery, and installation.

## Best Possible Solution

Provide an administrator-safe reconciliation operation that audits each accepted publish from attempt through storage, release row, tags, latest-version summary, moderation visibility, and search indexing; restore the existing versions idempotently and add post-publish read-after-write verification so success is not reported for an unavailable release.
