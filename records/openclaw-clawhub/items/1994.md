## Summary

Keep open. Current main still has no public Verified or vetted-community request path for community plugins like the linked Spectyra plugin; Official remains a staff-managed publisher policy, and the overlapping plugin-verify PR is still an open draft evidence endpoint rather than a status workflow.

## What This Changes

The issue asks how a community publisher can get a published skill and plugin marked as Verified on ClawHub.

## Best Possible Solution

Resolve the community-plugin verification policy in https://github.com/openclaw/clawhub/issues/2272, then document and apply a publisher or package review request flow for Spectyra without conflating it with Official status or release verification tiers.

Options:

- **Define a vetted-community path (recommended):** Create a distinct policy and workflow for reviewed community plugins, including package-versus-publisher scope, evidence requirements, review authority, expiry, and revocation.
- **Keep Official-only endorsement:** Document that community plugins can use source/provenance and scan evidence but cannot request a Verified badge unless maintainers explicitly mark the publisher Official.
- **Pilot evidence first:** Land a carefully scoped plugin evidence endpoint before deciding whether any public Verified or vetted-community badge should exist.
