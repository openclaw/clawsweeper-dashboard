## Summary

Keep open. Current main still lacks a public Verified or vetted-community request path for community plugins like Spectyra; existing Verified UI maps to staff-controlled Official state, and the related RFC/API proposal remain open policy work.

## What This Changes

The issue asks how a community skill and plugin publisher can get Verified status for their published Spectyra skill and plugin.

## Best Possible Solution

Resolve the community-plugin verification policy in https://github.com/openclaw/clawhub/issues/2272 first, then document a clear request/status path and apply it consistently to Spectyra without conflating it with Official status.
