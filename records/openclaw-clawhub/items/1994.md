Keep open. Current main still does not provide a public Verified or vetted-community request path for community plugins; the remaining work is a security/product trust-policy decision already covered by the open vetted-community RFC.

## What This Changes

The issue asks how a published community skill and plugin, including Spectyra, can become Verified or otherwise gain a trusted public signal on ClawHub.

## Best Possible Solution

Resolve the community-plugin verification policy in https://github.com/openclaw/clawhub/issues/2272, then document and apply a general publisher or package review request flow for Spectyra without conflating it with Official status.

- **Perform a one-off Spectyra review:** Maintainers could manually review Spectyra, but that risks creating precedent before the wider trust model is defined.
