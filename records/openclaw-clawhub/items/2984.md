## Summary

Keep open: current main still routes flagged skill publishes into `publishAttempts` and returns pending until the prepublication worker finalizes them, while multiple live reports show attempts staying pending and hidden from public skill lookup. The linked mitigation at https://github.com/openclaw/clawhub/pull/2985 is still open, so this issue is not implemented on main.

## What This Changes

The issue reports ClawHub skill publishes getting stuck in `pending_checks` after staged prepublication checks were enabled, leaving submitted skills uncreated and returning 404 on lookup.

## Best Possible Solution

Restore staged publish finalization while preserving secure defaults: inspect and drain affected `publishAttempts`, fix the worker/backlog failure, and add operator-visible retry/status or an operator-controlled emergency control if a bypass is needed.
