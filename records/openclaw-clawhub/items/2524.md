## What This Changes

The issue asks maintainers to replace the production GitHub OAuth App credentials so GitHub consent shows official ClawHub/OpenClaw ownership instead of personal ClawdHub branding.

## Best Possible Solution

Create or transfer the production GitHub OAuth App to official OpenClaw/ClawHub ownership, rotate the Convex production OAuth credentials, keep homepage/callback URLs aligned, and validate fresh browser plus CLI auth before closing.
