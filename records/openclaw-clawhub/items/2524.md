## What This Changes

## Best Possible Solution

A maintainer should create or transfer the production GitHub OAuth App to official ClawHub/OpenClaw ownership, rotate the Convex production GitHub OAuth credentials, keep callback/homepage URLs aligned, and smoke-test fresh browser plus CLI auth.

## Solution Assessment
