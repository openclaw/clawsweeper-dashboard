## Summary

Keep open. Current main and v0.23.1 still install/update skill files and metadata without an active-session handoff, and collaborator discussion says this should be prioritized rather than cleaned up.

## What This Changes

Request a post-install/update active-session system event that tells the agent to read the installed skill's SKILL.md and complete onboarding or update instructions.

## Best Possible Solution

Maintainers should define a consent-aware ClawHub/OpenClaw install-update handoff contract, or explicitly keep the inspectable copy-prompt flow as the supported setup path.

## Reproduction Assessment

Yes, at source level: current cmdInstall and cmdUpdate install or update files and metadata without an active-session event or SKILL.md onboarding read. I did not run a live OpenClaw gateway/session reproduction.

## Solution Assessment

No, not exactly as proposed: a handoff may be appropriate, but unconditional setup execution from SKILL.md needs a maintainer-approved consent, session-targeting, trust, and failure-handling contract.
