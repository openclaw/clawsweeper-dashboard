## Summary

Keep open. Current main still has no post-install/update active-session event or SKILL.md onboarding trigger, and the requested behavior needs maintainer product/security judgment before implementation.

## What This Changes

Requests ClawHub install/update to notify the active OpenClaw session to read the installed or updated skill's SKILL.md and complete setup/onboarding.

## Best Possible Solution

Define a consent-aware ClawHub/OpenClaw install-update handoff contract with explicit session targeting, inspectable setup guidance, approval before consequential actions, docs, and focused CLI/session tests.

## Reproduction Assessment

Yes, at source level. Current cmdInstall and cmdUpdate install or update files and metadata and print success without an active-session system event or SKILL.md onboarding read; I did not run a live OpenClaw gateway reproduction.

## Solution Assessment

No, not exactly as proposed. A notification may be appropriate, but unconditional instructions to execute setup from SKILL.md should become a maintainer-approved consent, session-targeting, trust, and failure-handling contract.
