## Summary

Keep open. Current main and v0.23.1 still install/update skill files and metadata without an active-session system event, and a collaborator explicitly said this should be prioritized rather than cleaned up.

## What This Changes

Request to notify the active OpenClaw session after `clawhub install` or `clawhub update` so the agent reads the installed skill's `SKILL.md` and completes setup guidance.

## Best Possible Solution

Define a consent-aware ClawHub/OpenClaw install-update handoff contract, or explicitly keep the inspectable copy-prompt flow as the supported setup path.
