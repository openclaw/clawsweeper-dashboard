## Summary

Keep open. Current main and the latest release still install/update skill files and metadata without an active-session handoff, and a collaborator explicitly said this should be prioritized rather than cleaned up.

## What This Changes

The issue requests a post-install/update active-session system event that tells the agent to read the installed skill's SKILL.md and perform onboarding or update instructions.

## Best Possible Solution

Maintainers should define the install/update boundary explicitly: either add a user-consented OpenClaw session handoff contract with focused CLI/session tests and docs, or document the inspectable copy-prompt flow as the intended setup path.
