## Summary

Current main and v0.23.1 still complete skill installation and updates without an active-session handoff, and collaborator discussion explicitly supports prioritizing the idea. The issue remains necessary, but automatic execution would cross the current ClawHub/OpenClaw trust boundary and needs a maintainer-approved consent and delivery contract first.

## What This Changes

Add a post-install/update active-session handoff so OpenClaw can discover and complete skill onboarding steps.

## Best Possible Solution

Define a typed, authenticated OpenClaw runtime notification carrying bounded skill identity, version, path, and operation data, then present consent-gated setup actions instead of automatically executing SKILL.md instructions.

- **Automatic onboarding execution:** Inject a directive that tells the active agent to read and execute installed SKILL.md setup instructions immediately.
