## Summary

Keep this draft PR open, but do not merge it as written: the fixed 8,000-skill ceiling can eventually make every scheduled scan incomplete and suppress all percentile-based moderation signals. The full-population direction is reasonable, but it needs a bounded continuation strategy and real Convex runtime validation.

## What This Changes

The PR benchmarks temporal abuse signals across scanned active skills, suppresses incomplete-scan percentiles, requires P99 plus absolute traffic floors, raises scheduled scan bounds, and updates the moderation UI, tests, and security specification.

## Best Possible Solution

Use bounded pages with durable continuation or a resumable snapshot until every active skill is included, publish the benchmark only after that complete snapshot, expose incomplete-scan telemetry, and validate completed and interrupted runs against real Convex state.
