Keep open: current main and the latest release still intentionally render the dashboard drift alert when frontend and Convex build SHAs are both present and unequal, so the central warning-policy question is not implemented away.

## What This Changes

The issue reports a persistent dashboard deployment-version drift warning even though the dashboard still works.

## Best Possible Solution

Keep deployment drift detection, but make the contract explicit: coordinated production deploys should stamp the same SHA, and expected partial-deploy drift should have maintainer-approved severity, copy, tests, and deploy-runbook language.
