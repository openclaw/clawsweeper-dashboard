## Summary

Keep open. Current main and v0.23.1 provide skill and plugin/package discovery, publishing, inspection, and installation, but not a shareable cron-template catalog or a safe one-click scheduled-job installation contract; the remaining work requires explicit product and security-boundary decisions.

## What This Changes

Requests a browsable catalog of shareable cron-job templates with preview and one-click installation into an OpenClaw instance.

## Best Possible Solution

Define the intended end state in a focused spec: either let skills or bundle plugins publish reusable cron examples while schedule creation remains explicit and local, or introduce a dedicated automation manifest with inspectable schedules, prompts, permissions, secrets, confirmation, lifecycle controls, moderation, and safe install/update removal semantics.
