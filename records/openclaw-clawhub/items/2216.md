## Summary

Keep open: current main still lacks the RFC's shared Weekly/Monthly/All time popularity contract and publisher-period ranking, even though it now has partial seven-day skill/plugin trending and package daily stats.

## What This Changes

The issue requests period-based popularity tabs and supporting temporal ranking data for publishers, skills, and plugins.

## Best Possible Solution

Keep this as the canonical RFC, settle the period/scoring/attribution policy, then add publisher rollups and snapshot-pinned weekly/monthly leaderboards before wiring the three browse UIs.

## Reproduction Assessment

## Solution Assessment

Yes as an RFC, but not as a UI-only change. The maintainable path is to choose the data semantics first, then implement the temporal rollups and leaderboards before showing period tabs.
