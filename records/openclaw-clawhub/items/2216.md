## Summary

Keep open: current main has partial seven-day Trending support for skills and plugins, plus adjacent publisher dashboard analytics, but it still lacks the requested Weekly/Monthly/All time browse contract across creators, skills, and plugins and has no publisher temporal leaderboard foundation.

## What This Changes

This RFC asks ClawHub to add Weekly, Monthly, and All time popularity tabs for creators/publishers, skills, and plugins backed by aligned temporal popularity data.

## Best Possible Solution

Approve one shared temporal popularity contract first, then implement package and publisher daily rollups, weekly/monthly snapshot leaderboards, and the browse UI tabs against that contract.
