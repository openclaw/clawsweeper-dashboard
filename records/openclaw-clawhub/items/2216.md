## Summary

Keep open: current main has partial seven-day Trending support for skills and plugins, but it still lacks the requested Weekly/Monthly/All time period contract across creators, skills, and plugins, and publisher period popularity still needs a shared data model and product decisions.

## What This Changes

The RFC requests Weekly, Monthly, and All time popularity tabs across creator, skill, and plugin browse surfaces backed by shared temporal stats, publisher aggregation, and snapshot-pinned pagination.

## Best Possible Solution

Approve one shared temporal popularity contract first, then implement package and publisher daily rollups, weekly/monthly snapshot leaderboards, and the browse UI tabs against that contract.
