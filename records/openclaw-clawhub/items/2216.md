## Summary

Keep open: current main has partial seven-day skill/plugin trending and package daily stats, but it still lacks the shared Weekly/Monthly/All time contract, publisher temporal rollups, monthly/snapshot-pinned leaderboard pagination, and the requested browse-page period tabs.

## What This Changes

The issue requests period-based popularity tabs for publishers, skills, and plugins backed by a shared temporal popularity data contract.

## Best Possible Solution

Keep this as the canonical RFC, settle the shared period/scoring/attribution policy, then implement publisher rollups and snapshot-pinned weekly/monthly leaderboards before wiring the three browse UIs.
