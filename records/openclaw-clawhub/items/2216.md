## Summary

Keep open: current main has some seven-day skill/plugin trending and package daily-stat foundation, but it does not implement the requested Weekly/Monthly/All time period contract across publishers, skills, and plugins.

## What This Changes

Add semantically aligned Weekly, Monthly, and All time popularity tabs for publishers, skills, and plugins backed by temporal stats and leaderboard snapshots.

## Best Possible Solution

Define the shared period, scoring, ownership-attribution, and snapshot-pagination contract first, then ship backend leaderboards before adding tabs to the three browse surfaces.
