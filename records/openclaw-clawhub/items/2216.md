## Summary

Keep open: current main partially provides seven-day trending for skills and plugins, but it still lacks Monthly and All time period selection, temporal creator rankings, and a shared cross-surface contract. This member-authored RFC remains necessary and requires a maintainer product decision.

## What This Changes

Add aligned Weekly, Monthly, and All time popularity controls and temporal ranking data for creators, skills, and plugins.

## Best Possible Solution

Approve and document one cross-surface period contract, preserve existing all-time paths, add creator daily rollups plus versioned 7-day and 30-day snapshots, then land focused backend and UI PRs with realistic-state tests.

Question: Should ClawHub standardize trailing 7-day and 30-day popularity across creators, skills, and plugins, and what activity score and creator ownership-attribution rule should define V1?

Rationale: Current main only provides separate seven-day skill and plugin foundations; monthly ranking, creator aggregation, score alignment, ownership transfers, and rollout semantics cannot be safely selected by automation.

Likely owner: vyctorbrzezowski

Owner reason: They introduced and repeatedly maintained the publisher and creator discovery surface and authored this RFC.

Owner confidence: high

Options:

- **Standardize shared periods (recommended):** Use trailing completed-day windows, preserve all-time ranking, and define one explainable activity score with event-time creator attribution.
- **Keep current trending:** Retain independent skill and plugin Trending views and defer Monthly and creator period ranking.
- **Stage explicit semantics:** Allow surface-specific period features only when each UI clearly labels its available metric and window until a shared contract exists.
