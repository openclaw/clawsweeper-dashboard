## Summary

Keep open: current main has partial seven-day skill/plugin trending and package daily stats, but the shared Weekly/Monthly/All time popularity contract, publisher period rollups, monthly leaderboards, snapshot-pinned period pagination, and browse-page period tabs are still missing.

## What This Changes

Request for weekly, monthly, and all-time popularity across publisher, skill, and plugin browse surfaces with a shared temporal data contract.

## Best Possible Solution

Keep this as the canonical RFC, settle the period/scoring/attribution policy, then implement publisher rollups and snapshot-pinned weekly/monthly leaderboards before wiring the browse UI tabs.
