## Summary

Keep open: current main and v0.23.1 ship a seven-day skill/plugin trending foundation, but not the requested monthly mode, publisher temporal ranking, or shared period contract. This member-authored RFC still requires an explicit product decision before implementation.

## What This Changes

Add aligned Weekly, Monthly, and All time popularity controls for creators, skills, and plugins.

## Best Possible Solution

Approve and document one temporal popularity contract in `specs/`, extend existing skill/package rollups to monthly snapshots, add plugin-inclusive publisher aggregation, and then implement synchronized selectors on `/creators`, `/skills`, and `/plugins`.

Options:

- **Approve shared periods (recommended):** Extend the current skill/package rollups to monthly snapshots, add publisher aggregation, and expose aligned selectors across all three browse pages.
- **Retain independent sorts:** Keep seven-day Trending as a skills/plugins sort and leave creators on all-time/recent ranking.
- **Stage without creators:** Standardize skill/plugin periods first and defer creator periods until publisher attribution is approved.
