## Summary

Keep this RFC open: current main has partial seven-day trending infrastructure for skills/plugins, but it does not implement aligned Weekly/Monthly/All time period popularity across publishers, skills, and plugins.

## What This Changes

The issue requests period-based popularity tabs and supporting temporal leaderboard/data contracts for publishers, skills, and plugins.

## Best Possible Solution

Approve a shared temporal popularity contract first, then land phased backend rollups/leaderboards and finally add the aligned period tabs to the three browse surfaces.
