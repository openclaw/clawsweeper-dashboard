## Summary

Keep open: current main has partial seven-day trending support for skills and plugins, but it still lacks the requested Weekly/Monthly/All time period contract across publishers, skills, and plugins, especially publisher daily aggregation and monthly/snapshot leaderboard semantics.

## What This Changes

The issue requests period-based popularity tabs and a shared temporal popularity data contract for publisher, skill, and plugin browse surfaces.

## Best Possible Solution

Approve one shared temporal popularity contract first, then land the package/publisher daily rollups, weekly/monthly snapshot leaderboards, and browse-page period tabs in staged PRs.
