Keep open. The loading-improvement goal is plausible, but the patch currently puts homepage-specific resource hints in the root head, so every route can preload the 12 Simple Icons, and the external PR has no inspectable real-behavior proof for the loading change.

## What This Changes

The PR adds a Simple Icons CDN preconnect and 12 image preload links for the homepage Popular app-grid icons.

## Best Possible Solution

Scope the resource hints to the `/` route, preferably deriving URLs from the same homepage icon data, then verify the hard-refresh behavior with real before/after proof.

## Solution Assessment

No. A global root-head preload is the wrong layer for a homepage-only optimization; route-scoped links or a shared helper derived from the homepage app icon data would be narrower and more maintainable.
