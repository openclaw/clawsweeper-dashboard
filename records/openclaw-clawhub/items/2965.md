## Summary

Keep this PR open: the homepage icon flash is a plausible issue, but the patch currently adds homepage-only resource hints to the root route, which makes every ClawHub page preload unused external SVGs, and the PR has only before-state proof.

## What This Changes

The branch adds one jsDelivr preconnect and twelve Simple Icons image preload links to the root route head for the homepage Popular app grid.

## Best Possible Solution

Scope the resource hints to the homepage route and derive them from the existing home app icon data, then merge only with real browser hard-refresh proof that icons load earlier without adding non-home route cost.
