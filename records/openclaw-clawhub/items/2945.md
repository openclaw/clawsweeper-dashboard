## Summary

Keep open: current main and the latest release have adjacent acceptable-use, security-audit, and ClawScan language, but they do not yet define the requested publisher/moderator policy boundary for agent-directed SKILL.md/README instructions. This is an active security RFC that needs maintainer/security policy review rather than cleanup closure.

## What This Changes

The issue requests a documented policy distinguishing acceptable task-scoped skill instructions from unacceptable agent-directed instructions that fetch/run code, escalate privileges, bypass confirmation, or exceed the skill's stated purpose.

## Best Possible Solution

Have maintainers choose the acceptable/needs-review/not-allowed boundary, then record durable intent in specs/security-moderation.md and public guidance in docs/acceptable-usage.md, docs/security-audits.md, or docs/skill-format.md.
