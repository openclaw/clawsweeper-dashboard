## Summary

Keep open: current main internally evaluates instruction scope and publicly identifies suspicious install instructions as reportable, but it does not publish the requested acceptability standard for agent-directed documentation. The broader content-policy RFC partially overlaps without resolving this narrower trust-boundary decision, and this RFC remains within its active feedback period through July 30, 2026.

## What This Changes

Define a shared public policy for acceptable agent-directed instructions in skill documentation.

## Best Possible Solution

Publish a narrow rule in the public acceptable-usage or moderation documentation, preserve rationale and moderator invariants in a focused spec, and coordinate its declaration and appeal semantics with the related content-policy and capability-manifest RFCs.
