## Summary

Keep open: current main has adjacent acceptable-use, security-audit, and ClawScan guidance, but it still does not define the requested public policy boundary for agent-directed instructions in SKILL.md/README content. This is an active security RFC with a future feedback deadline and needs maintainer/security policy review rather than cleanup closure.

## What This Changes

The issue proposes a documented acceptability guideline for agent-directed instructions in skill documentation, distinguishing normal task-scoped usage guidance from unsafe instructions such as external fetch-and-run, privilege escalation, or bypassing user confirmation.

## Best Possible Solution

Have maintainers/security reviewers decide the acceptability boundary, then capture durable intent in specs/security-moderation.md and public publisher/moderator guidance in docs/acceptable-usage.md or docs/security-audits.md.
