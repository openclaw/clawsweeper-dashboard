## Summary

Keep open: the prior review remains valid. Current main prohibits unsafe execution requirements and confirmation-boundary bypasses, but it does not explicitly govern instructions addressed to the agent or define the requested task-scope boundary, so this active security-policy RFC still needs maintainer judgment.

## What This Changes

Establish a documented acceptability boundary for agent-directed instructions embedded in skill documentation.

## Best Possible Solution

Add an explicit agent-directed-instruction section to public acceptable usage, preserve its rationale and edge-case rules in a moderation/security spec, and treat capability declarations as review context rather than automatic approval.
