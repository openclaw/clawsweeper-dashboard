## What This Changes

The issue reports that running `curl -fsSL https://molt.bot/install.sh | zsh` failed during npm install because zsh treated an unmatched `.clawdbot-*` Homebrew npm cleanup glob as an error.

## Best Possible Solution

Resolve the installer boundary explicitly: either make the legacy installer source traceable and harden its zsh cleanup glob, or retire/redirect it to the maintained OpenClaw and ClawHub install commands with a clear Node support range.
