## What This Changes

This PR adds immutable digest-addressed catalog shards, signed shard roots, publication retention and leasing, public feed routes, and schema support for scalable plugin and skill catalog snapshots.

## System Context

ClawHub builds official plugin and skill catalog snapshots from publishable package records, then exposes them through the public feed API. This PR adds a signed sharded representation so consumers can retrieve a compact root and verify immutable payload shards without replacing the existing unsigned compatibility feed.
