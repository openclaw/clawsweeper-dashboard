## Summary

Current main still runs both gates without the requested transient-failure controls, and this MEMBER-authored issue requires explicit maintainer scoping rather than automatic cleanup.

## What This Changes

Harden the HTTP and local-auth CI gates against transient GitHub lookup failures, local Convex saturation, navigation retry amplification, and uncertain runner capacity.

## Best Possible Solution

Split the work into HTTP fixture reliability and local-auth capacity/load reliability, first measure actual CPU and classify Convex timeouts, then add bounded retry for retryable GitHub failures and replace query-heavy navigation loops with backend readiness polling plus inactive-query gating.
