## Repair Work Prompt

Fix the ClawHub package publish client/API contract for staged prepublication pending responses. Current main can return `{ ok: true, status: "pending", attemptId, packageName, version }` from `convex/packages.ts`, while the package CLI schemas still require `packageId` and `releaseId` and `cmdPublishPackage` validates against that strict schema. Add a discriminated published-vs-pending response shape in both package schema copies, update CLI JSON and human output to show pending attempt status without reading `releaseId`, and add regression coverage for the pending package publish response. Coordinate context with https://github.com/openclaw/clawhub/issues/2990, https://github.com/openclaw/clawhub/issues/2983, and https://github.com/openclaw/clawhub/issues/2984. Do not add a staging bypass, change scanner/security verdict policy, or broaden worker recovery in this fix unless a maintainer explicitly expands the scope.
