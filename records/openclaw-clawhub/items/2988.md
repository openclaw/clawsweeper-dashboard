## Repair Work Prompt

Fix the ClawHub package publish pending-response regression reported here. Current main returns `{ ok: true, status: "pending", attemptId, packageName, version }` from `convex/packages.ts` when staged prepublication is enabled, but `clawhub package publish` validates `POST /api/v1/packages` with `ApiV1PackagePublishResponseSchema` requiring `packageId` and `releaseId`. Update the package publish response schemas in both schema packages to accept finalized and pending responses, update `packages/clawhub/src/cli/commands/packages.ts` to print a clear pending security-checks result without reading `releaseId`, and add regression tests for package CLI pending responses plus the HTTP/contract shape. Keep the fix limited to package publish response handling; do not add an emergency bypass, disable staged security checks, or change worker policy in this PR. Related context: https://github.com/openclaw/clawhub/issues/2983, https://github.com/openclaw/clawhub/issues/2984, and https://github.com/openclaw/clawhub/pull/2985. No changelog edit is needed.
