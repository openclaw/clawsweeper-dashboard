## Summary

Keep open: current main and the latest release still accept lowercase and legacy skill metadata filenames and do not reject case-colliding duplicates; `PROTOCOL.md` is not a defined ClawHub package contract, so this needs a maintainer policy decision.

## What This Changes

Request validation that enforces a single canonical casing for skill package metadata files, especially `SKILL.md` and `PROTOCOL.md`, to avoid case-insensitive filesystem conflicts.

## Best Possible Solution

Maintainers should define the casing policy, likely preserve documented lowercase aliases while rejecting case-colliding duplicates, decide whether `PROTOCOL.md` belongs in the package contract, and then update docs, validation, tests, and any external content cleanup plan consistently.
