## What This Changes

Bound publisher profile, membership, catalog, and GitHub display-manifest reads so callers do not collect complete resource catalogs when they only need a summary or one page.

## Best Possible Solution

Preserve the current GitHub-backed display semantics while replacing the full-catalog manifest dependency with a bounded representation or a deliberately paginated display contract, backed by table-read-bound regression tests.
