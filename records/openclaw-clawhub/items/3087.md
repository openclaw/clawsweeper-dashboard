## Summary

Keep this draft open: the implementation direction is substantial, but the new public skill-version paginator advances past rows it does not return, which would silently omit version-history entries. The PR also still lacks its stated preview/runtime proof for security gating and legacy-CLI upgrades.

## What This Changes

## Best Possible Solution

Preserve cursor correctness with a page design that never consumes unreturned published rows, add multi-page mixed-status regression coverage, document the publication-state invariants in `specs/`, and attach redacted real preview or local proof using both current and older released CLIs before merge.
