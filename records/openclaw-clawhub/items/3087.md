## Summary

Keep this PR open for maintainer review: the compatibility repair addresses documented staged-publish regressions, but the new preview-proof workflow creates a security blocker and the draft, conflicted head still lacks non-mocked preview evidence for the complete publish lifecycle.

## What This Changes

The branch creates private pending skill versions and package releases, promotes them after TruffleHog and ClawScan checks, preserves legacy publish response IDs, updates current CLI messaging, and expands workflow and lifecycle coverage.

## Best Possible Solution

Preserve the additive legacy-ID response design, but isolate preview validation from environment credentials, explicitly validate trusted checkout ancestry, and prove fresh, upgrade, retry, blocked, and promotion flows against a real preview before enabling staged publication.
