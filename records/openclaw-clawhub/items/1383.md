## Summary

Keep open. Current main still has ranked skill search, local installed-skill listing, and bounded registry browsing, but it does not expose deterministic exact-slug or slug-prefix enumeration through the ClawHub CLI or public v1 API.

## What This Changes

The issue requests deterministic ClawHub CLI registry discovery, such as exact slug lookup, prefix enumeration, or a hub-backed list mode, instead of relying only on ranked search.

## Best Possible Solution

Add a documented, indexed, cursor-pageable registry discovery path for exact slug lookup and slug-prefix enumeration while preserving relevance-ranked search semantics.

## Reproduction Assessment

Yes, source inspection provides a high-confidence reproduction path: current main exposes ranked search, local installed-skill listing, and bounded registry browsing, but no exact or prefix enumeration input in the CLI or public v1 API.

## Solution Assessment

Unclear until maintainers choose the public contract. The maintainable direction is an explicit indexed enumeration API exposed through CLI flags or a dedicated list mode, not making ranked search imply complete listing semantics.
