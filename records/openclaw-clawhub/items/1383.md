## Summary

Keep open. Current main still offers relevance-ranked skill search and bounded registry browsing, but not deterministic exact-slug or slug-prefix enumeration through the ClawHub CLI/API path.

## What This Changes

The issue requests a registry-oriented ClawHub CLI discovery path for exact slug, prefix, or full hub skill enumeration instead of relying on ranked search.

## Best Possible Solution

Add a documented, indexed, cursor-paginated registry discovery surface for exact slug lookup and slug-prefix enumeration while preserving relevance-ranked search semantics.

## Reproduction Assessment

Yes. Source inspection on current main shows ranked search, local installed-skill listing, and bounded registry explore, but no exact or prefix enumeration input in the CLI or public v1 API.

## Solution Assessment

Unclear until maintainers choose the public contract. The maintainable direction is an indexed, cursor-pageable exact/prefix registry API exposed through explicit CLI flags or a dedicated list mode, not implicit total listing through ranked search.
