## Summary

Keep open. Current main and the v0.23.1 CLI/API surface still provide ranked skill search, bounded registry browsing, and local installed-skill listing, but not deterministic exact-slug or slug-prefix registry enumeration.

## What This Changes

The issue requests deterministic registry-oriented skill discovery in the ClawHub CLI, such as exact-slug, prefix, or list-style hub enumeration.

## Best Possible Solution

Add a documented, indexed, cursor-pageable registry discovery surface for exact slug and slug-prefix queries, then expose it through an explicit CLI/API contract while preserving ranked search semantics.

## Reproduction Assessment

Yes. Source inspection on current main shows CLI search only accepts query and limit, list is local-only, explore is bounded browsing, and the public API handlers lack exact or prefix enumeration inputs.

## Solution Assessment

Unclear until maintainers choose the public contract. The maintainable direction is an indexed, cursor-pageable exact/prefix registry API exposed through explicit CLI flags or a dedicated list mode, not stretching relevance-ranked search into an implicit total listing.
