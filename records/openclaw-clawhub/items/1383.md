## Summary

Keep open. Current main and the latest tagged CLI release still provide relevance-ranked skill search plus bounded registry browsing, but not deterministic exact-slug or slug-prefix enumeration for registry discovery.

## What This Changes

The issue requests deterministic ClawHub CLI/API discovery for exact skill slugs and slug-prefix registry enumeration instead of relying on ranked search.

## Best Possible Solution

Expose an indexed, cursor-paginated exact/prefix registry discovery API and wire it to explicit CLI flags or a dedicated list mode while preserving ranked search semantics.

## Maintainer Decision

Required: true

Kind: product_direction

Question: Which public discovery contract should ClawHub expose for deterministic skill enumeration: search flags, a hub-list mode, /api/v1/skills filters, or another API shape?

Rationale: The missing behavior is clear, but implementing it fixes a public CLI/API contract and moderation visibility policy that should be chosen deliberately before automation writes code.

Likely owner: Patrick-Erichsen

Owner reason: The current CLI and v1 API surfaces most directly route through files currently blamed to Patrick-Erichsen.

Owner confidence: high

Options:

- **Add API filters plus CLI modes (recommended):** Expose exact and prefix filters on a cursor-pageable indexed registry endpoint, then map CLI --exact/--prefix or a hub-list mode to that contract.
- **Keep ranked search only:** Leave search as relevance lookup and defer deterministic enumeration until a broader catalog API design is approved.
- **Add CLI-only filtering:** Filter existing browse pages client-side, but that would remain incomplete for counts and namespaces unless the API contract changes too.

## Reproduction Assessment

Yes. Source inspection on current main shows ranked search, local installed-skill listing, and bounded registry explore, but no exact or prefix enumeration input in the CLI or public v1 API.

## Solution Assessment

Unclear until maintainers choose the public contract. The narrow maintainable direction is an indexed, cursor-pageable exact/prefix registry API exposed through explicit CLI modes, not implicit total listing through ranked search.
