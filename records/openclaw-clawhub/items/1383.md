## Summary

Keep open. Current main and the latest CLI release still expose relevance-ranked search plus bounded browse/local-list surfaces, but no deterministic exact-slug or slug-prefix enumeration contract; the remaining decision is the public CLI/API shape.

## What This Changes

Request deterministic exact-slug and slug-prefix registry discovery in the ClawHub CLI/API instead of relying only on relevance-ranked search.

## Best Possible Solution

Expose an indexed, cursor-pageable exact/prefix registry discovery endpoint and CLI surface while keeping ranked search relevance-oriented.
