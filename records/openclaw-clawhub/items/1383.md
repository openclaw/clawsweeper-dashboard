## Summary

Keep open. Current main and v0.23.1 still expose relevance-ranked skill search, local installed-skill listing, and bounded registry browsing, but not deterministic exact-slug or slug-prefix enumeration through the ClawHub CLI/API path.

## What This Changes

Request deterministic CLI registry discovery for skills by exact slug, slug prefix, or hub-list style enumeration instead of relying only on relevance-ranked search.

## Best Possible Solution

Add a documented, indexed, cursor-paginated registry discovery path for exact slug lookup and slug-prefix enumeration while preserving relevance-ranked search semantics.

## Reproduction Assessment

Yes. Source inspection on current main shows ranked search, local installed-skill listing, and bounded registry explore, but no exact or prefix enumeration input in the CLI or public v1 API.

## Solution Assessment

Unclear until maintainers choose the public contract. The maintainable direction is an indexed, cursor-pageable exact/prefix registry API exposed through explicit CLI flags or a dedicated list mode, not implicit total listing through ranked search.
