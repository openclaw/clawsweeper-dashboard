## Summary

Keep open: current main still exposes relevance-oriented skill search rather than a deterministic public exact/prefix enumeration contract, and the concrete implementation candidate at https://github.com/openclaw/clawhub/pull/2969 remains open. The linked PR should be reviewed against a maintainer-approved CLI/API contract instead of creating competing work.

## What This Changes

The issue requests explicit exact or prefix-based registry skill discovery in the ClawHub CLI/API so users can enumerate matching skill slugs instead of relying on ranked search.

## Best Possible Solution

Keep relevance search as the default and approve one bounded, documented registry-discovery contract—such as explicit exact and prefix modes with deterministic ordering, limits, and pagination—then validate and land the linked implementation if it meets that contract.
