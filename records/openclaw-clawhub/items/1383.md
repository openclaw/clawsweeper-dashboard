## Summary

Current main still exposes relevance-ranked search rather than deterministic exact or prefix enumeration, and the linked open pull request is the active implementation candidate, so this issue remains necessary until that candidate is merged or rejected.

## What This Changes

Requests deterministic exact and prefix-based registry skill discovery through the ClawHub CLI instead of relying solely on relevance-ranked search.

## Best Possible Solution

Preserve relevance search as the default while adding explicit, documented exact and prefix modes with deterministic slug ordering, bounded or paginated results, shared visibility rules, and CLI/API regression coverage; close this issue only after the linked pull request or an equivalent implementation merges.
