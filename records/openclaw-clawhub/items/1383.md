## Summary

Keep open. Current main and the latest v0.23.1 release still provide ranked skill search, local installed-skill listing, and bounded registry browsing, but not deterministic exact-slug or slug-prefix enumeration through the CLI/API.

## What This Changes

The issue requests deterministic ClawHub CLI registry discovery for exact slugs, slug prefixes, or full hub listing instead of relevance-only search.

## Best Possible Solution

Add a documented, indexed, cursor-pageable registry discovery path for exact slug lookup and slug-prefix enumeration while preserving relevance-ranked search semantics.

## Reproduction Assessment

Yes. Source inspection on current main shows ranked search, installed-skill list, and bounded registry explore, but no exact or prefix enumeration input in the CLI or public v1 API.

## Solution Assessment

Unclear until maintainers choose the public contract. The maintainable direction is an indexed, cursor-pageable exact/prefix registry API exposed through explicit CLI flags or a dedicated list mode, not implicit total listing through ranked search.
