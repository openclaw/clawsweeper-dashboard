## Summary

Keep open. Current main still has relevance-ranked skill search, local installed-skill listing, bounded registry browsing, and bulk/API feed surfaces, but no deterministic CLI/API mode for exact slug or slug-prefix registry enumeration.

## What This Changes

The issue requests a registry-oriented ClawHub CLI discovery path for exact, prefix, or full-list skill enumeration instead of relying only on ranked search.

## Best Possible Solution

Add a documented, indexed, cursor-pageable registry discovery path for exact slug lookup and slug-prefix enumeration while preserving relevance-ranked search semantics.

## Reproduction Assessment

Yes. Source inspection on current main shows ranked search, local installed-skill listing, and bounded registry browse/export surfaces, but no exact or prefix enumeration input in the CLI or public v1 API.

## Solution Assessment

Unclear until maintainers choose the public contract. The maintainable direction is an indexed, cursor-pageable exact/prefix registry API exposed through explicit CLI flags or a dedicated list mode, not implicit total listing through ranked search.
