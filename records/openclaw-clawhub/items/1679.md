Keep open: current ClawHub still treats these inputs as registry slugs, while the reported names are bundled OpenClaw skills rather than established ClawHub records. The merged owner-scoping work improves resolution for existing records but does not provide bundled-skill setup guidance or trusted canonical records, so the user-facing mismatch remains.

Provide a successful or actionable setup path when users pass bundled OpenClaw skill names to the ClawHub-backed install command.

## Best Possible Solution

Have OpenClaw recognize bundled skill names before performing a ClawHub lookup and show the exact enablement, dependency, and update instructions; reserve owner-qualified references for skills that are actually distributed through ClawHub.
