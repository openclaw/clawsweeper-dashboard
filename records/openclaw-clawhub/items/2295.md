## Summary

Current main and v0.23.1 still finish skill installation without registering bundled OpenClaw hooks. The request remains necessary, but automatic activation crosses an unresolved executable-code trust and consent boundary that requires maintainer direction.

## What This Changes

Automatically detect and register bundled OpenClaw hooks when installing a ClawHub skill so hook-dependent behavior becomes active.

## Best Possible Solution

Specify a cross-repository hook manifest and safety contract, then detect hooks during installation, disclose their events and permissions, require explicit confirmation or an approved trust tier, register through a stable OpenClaw API, and prove both accepted and declined flows.

Question: Should installing a ClawHub skill be allowed to register executable OpenClaw hooks, and what declaration, scanning, disclosure, trust, and user-consent rules must gate that activation?

Rationale: Current main treats skill copying and code-plugin installation as separate surfaces, while the requested behavior would cross into executable gateway activation.

Likely owner: Patrick-Erichsen

Owner confidence: high

Options:

- **Prompted Registration (recommended):** Detect a typed hook declaration, show scan and permission details, and require explicit confirmation before registration.
- **Manual Registration:** Keep activation separate but emit a prominent post-install warning with the exact registration and restart steps.
- **Trusted Auto-Registration:** Permit automatic activation only for a narrowly defined vetted or official package tier with an auditable policy.

## Reproduction Assessment

Yes, at source level. Current main ends installation after extraction, metadata persistence, telemetry, and success output, with no hook or plugin registration handoff.

## Solution Assessment

No, unconditional automatic registration is not the safest maintainable solution. A typed, disclosed, consent-aware registration flow solves the installed-but-inactive state without silently enabling executable code.
