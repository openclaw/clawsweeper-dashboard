## Summary

Keep open. Current main and latest release still install or update skill files and local ClawHub metadata without detecting `hooks/openclaw`, registering a hook bundle with OpenClaw, or defining hook-specific consent and scanner disclosure.

## What This Changes

The issue requests that `clawhub install` automatically detect OpenClaw hook files inside installed skills and register them with the OpenClaw gateway.

## Best Possible Solution

Define a maintainer-approved, consent-aware hook registration contract, then implement detection, hook-specific scanner and disclosure checks, OpenClaw gateway handoff, docs, and focused install/update tests.

## Reproduction Assessment

Yes, at source level. Current `cmdInstall` and `cmdUpdate` install or refresh skill files and metadata without hook discovery, gateway registration, or hook-specific consent handling; I did not run a live OpenClaw gateway reproduction.

## Solution Assessment

No, not as unconditional automatic registration. The maintainable path is a maintainer-approved consent, scanner/disclosure, and OpenClaw registration contract rather than blindly running `openclaw plugins install` after every skill install.
