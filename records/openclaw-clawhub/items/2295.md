## Summary

Keep open. Current main and v0.23.1 still install or update skill files and local metadata without discovering `hooks/openclaw`, registering an OpenClaw hook bundle, or defining hook-specific consent and scanner disclosure.

## What This Changes

Request automatic, consent-safe registration of OpenClaw hook bundles when `clawhub install` installs a skill containing `hooks/openclaw`.

## Best Possible Solution

Define a consent-aware hook registration contract, then implement discovery, scanner disclosure, explicit approval, gateway registration, docs, and tests across ClawHub and OpenClaw.
