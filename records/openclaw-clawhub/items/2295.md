## Summary

Keep open. Current main and v0.23.1 still install or update skill files and local metadata without discovering `hooks/openclaw`, registering an OpenClaw hook bundle, or defining hook-specific consent and scanner disclosure.

## What This Changes

The issue asks for `clawhub install` to detect OpenClaw hook bundles inside installed skills and register them with the gateway automatically.

## Best Possible Solution

Define a maintainer-approved, consent-aware hook registration contract, then implement detection, hook-specific scanner/disclosure checks, OpenClaw gateway handoff, docs, and focused install/update tests.

## Reproduction Assessment

Yes, at source level. Current `cmdInstall` and `cmdUpdate` install or refresh skill files and metadata without hook discovery, gateway registration, or hook-specific consent handling; I did not run a live OpenClaw gateway reproduction.

## Solution Assessment

No, not as unconditional automatic registration. The maintainable path is a maintainer-approved consent, scanner/disclosure, and OpenClaw registration contract rather than blindly running `openclaw plugins install` after every skill install.
