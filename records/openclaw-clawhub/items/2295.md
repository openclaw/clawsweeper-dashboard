## Label Justifications

- `P2`: The issue causes a real silent installation failure for hook-dependent skills, but it affects an optional advanced workflow and has a manual activation workaround.
- `impact:security`: The proposed behavior would automatically install and activate third-party executable hook code across a persistent runtime boundary.
- `impact:session-state`: Affected hooks such as `agent:bootstrap` alter agent bootstrap and session context, so missing or stale registration changes session behavior.
- `impact:ux-friction`: Installation reports success while required hook-dependent behavior remains inactive, forcing users to diagnose and run undocumented manual activation steps.

## Summary

Current main and the provided v0.23.1 release evidence still leave skill installation as download, extraction, origin metadata, and lockfile persistence without bundled hook registration. The user problem remains valid, but automatic activation would execute third-party code and therefore needs an explicit trust, consent, and cross-repository lifecycle decision before implementation. ([github.com](https://github.com/openclaw/clawhub/blob/main/packages/clawhub/src/cli/commands/skills.ts))

## What This Changes

Detect OpenClaw hook packs bundled in installed skills and activate them as part of the skill installation flow.

## Best Possible Solution

Keep skill downloads non-executing by default, detect and prominently disclose bundled hook packs, scan their declared entrypoints, and hand activation to an explicit user-confirmed OpenClaw hook-pack installation API with fail-closed noninteractive behavior and symmetric update/uninstall cleanup; record the trust and lifecycle invariants in `specs/`.

Options:

- **Prompt Before Activation (recommended):** Detect and scan hook packs, show their events and executable entrypoints, then require explicit confirmation before OpenClaw installs and enables them.
- **Download And Warn:** Keep skill installation non-executing and emit a prominent warning with a supported explicit OpenClaw activation command.
- **Require Plugin Packaging:** Reject executable hook packs inside ordinary skills and require authors to publish them as bundle or code-plugin packages with declared capabilities.
