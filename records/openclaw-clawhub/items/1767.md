## Summary

Keep open. Current main and v0.23.1 provide useful partial paths through `clawhub package validate`, publish dry-run, and a repo-local ClawScan helper, but they still do not provide the requested supported local plugin scanner/linter with hosted scan parity; `clawhub scan` still rejects local folders.

## What This Changes

The issue requests a supported local plugin scanner CLI that catches manifest, SKILL.md, and security scan findings before plugin authors publish.

## Best Possible Solution

Define a maintainer-approved local plugin scanner contract, then implement it through the supported ClawHub CLI with shared Plugin Inspector/static checks, redacted output, stable severity and JSON semantics, and documented hosted-scan parity gaps.
