## Summary

Keep open. The prior current-main review found only partial coverage: a trusted-developer repository script and package validation exist, while the supported public scanner still does not accept local unpublished artifacts. The remaining request needs an explicit maintainer decision on public CLI scope, parity with hosted scanning, and safe handling of security-sensitive heuristics.

## What This Changes

Add a supported local CLI or package that scans an unpublished plugin before publishing and returns structured validation and security findings.

## Best Possible Solution

Define a versioned public local-validation contract that reuses deterministic shared rules, clearly labels checks unavailable outside hosted moderation, emits stable JSON and exit codes, and documents that a clean local run is not a publication approval.
