## Summary

Keep open. Current main and v0.23.1 include useful partial validation through `clawhub package validate`, `package publish --dry-run`, and a repo-local ClawScan helper, but the requested supported local plugin scanner/linter is still missing; the public scan path still rejects local folders.

## What This Changes

Request a local pre-publish plugin scanner or CLI lint flow that reports manifest, SKILL.md, and code/security findings before publishing.

## Best Possible Solution

Define a maintainer-approved local plugin scanner contract, likely by expanding `clawhub package validate` or adding a focused sibling command with shared safe checks, redacted JSON/human output, and documented hosted-scan parity gaps.
