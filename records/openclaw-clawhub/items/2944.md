## Summary

Keep this open: current main still lacks the requested first-class skill capability manifest for network, filesystem, external-code execution, and secret-reading boundaries; existing env/dependency metadata and ClawScan checks are adjacent but not equivalent.

## What This Changes

The issue proposes a machine-readable skill capability manifest for trust-boundary behavior such as network access, filesystem reads, executing external code, and reading secrets.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, update docs and ClawScan output to compare declared versus observed behavior, and decide a legacy rollout path before making it required.
