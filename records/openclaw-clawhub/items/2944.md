## Summary

Keep open: current main has adjacent env/dependency metadata and ClawScan coherence checks, but it does not implement the requested declared capability manifest for network, filesystem, external-code execution, or secret-reading boundaries. This remains a security RFC that needs maintainer schema, authority, rollout, and security-review decisions.

## What This Changes

Request a standard machine-readable SKILL.md capability manifest for trust-boundary behavior such as network access, filesystem access, external code execution, and secret reads.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, and update docs plus ClawScan output to compare declared versus observed behavior after maintainers choose rollout and authority.
