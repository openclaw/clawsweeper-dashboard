## Summary

Keep this open: current main has skill runtime metadata and ClawScan coherence checks, but it still lacks the requested standard machine-readable capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security/trust RFC that needs maintainer product and security direction before implementation.

## What This Changes

The issue proposes a SKILL.md frontmatter capability manifest for declared-vs-observed review of network, filesystem, external-code, and secret-reading behavior.

## Best Possible Solution

Keep the RFC open for maintainer security/product design, then add a spec-backed capability schema, parser/storage/API surface, docs, and advisory review output that coordinates with the existing ClawScan pipeline.
