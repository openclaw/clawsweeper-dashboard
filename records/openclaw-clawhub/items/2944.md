## Summary

Keep open: current main supports declared environment variables and dependencies and performs behavioral security review, but it does not provide the requested machine-readable declarations for network, filesystem, secret access, or external-code execution. The remaining schema, trust semantics, compatibility, and rollout choices require explicit security and product ownership.

## What This Changes

Define an advisory skill-manifest schema for declaring network, filesystem, external-code execution, and secret-access capabilities, with eventual declared-versus-observed review checks.

## Best Possible Solution

Adopt a versioned, optional-first capability schema shared with the relevant OpenClaw contract, preserve legacy submissions as explicitly undeclared, expose declared and observed values separately, add ClawScan mismatch reporting without immediate blocking, and document the trust semantics and rollout in a focused security spec.
