## Summary

Keep open: current main and the latest release still have adjacent env/dependency metadata and ClawScan coherence checks, but not the requested declared capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security RFC needing maintainer schema, authority, and rollout decisions.

## What This Changes

The issue requests a standard machine-readable skill capability manifest for trust-boundary behavior such as network access, filesystem access, external code execution, and secret reads.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, and update docs plus ClawScan output to compare declared versus observed behavior after maintainers choose rollout and authority.
