## Summary

Keep open: current main and v0.23.1 have adjacent env/dependency metadata plus ClawScan coherence checks, but not the requested declared capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security RFC that needs maintainer decisions on schema, authority, rollout, and legacy behavior.

## What This Changes

The issue requests a standard SKILL.md frontmatter capability manifest for trust-boundary behavior and declared-versus-observed review.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, update public docs, and have ClawScan report declared-versus-observed mismatches after maintainers choose the schema and rollout.
