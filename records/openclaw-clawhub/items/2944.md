## Summary

Keep this open: current main has adjacent runtime metadata, env/dependency declarations, and ClawScan coherence checks, but it still lacks the requested machine-readable capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security/product RFC rather than implemented cleanup.

## What This Changes

The RFC requests a machine-readable SKILL.md capability manifest for declaring trust-boundary behavior such as network, filesystem, external execution, and secret access.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, update docs and ClawScan review output to compare declared versus observed behavior, and coordinate rollout with the adjacent security RFCs.
