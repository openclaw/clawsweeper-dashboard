## Summary

Keep this open: current main has adjacent skill runtime metadata and ClawScan coherence checks, but it still lacks the requested machine-readable capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This is a security/trust RFC that needs maintainer product and security direction before implementation.

The issue proposes a standard SKILL.md frontmatter capability manifest so skills can declare trust-boundary behavior for declared-vs-observed review.

## Best Possible Solution
