## Summary

Keep this open: current main has declared skill runtime metadata and env-mismatch scanning, but it does not implement the requested machine-readable capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This is a security/trust RFC that needs maintainer product and security direction before implementation.

## What This Changes

Request a standard SKILL.md capability manifest and rollout path for declared-vs-observed trust-boundary review.

## Best Possible Solution

Keep the RFC open for maintainer security/product design, then add a spec-backed capability schema, parser/storage/API surface, and advisory review output that coordinates with the existing scan pipeline.
