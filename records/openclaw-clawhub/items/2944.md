## Summary

Keep open: current main exposes structured environment-variable and dependency metadata, but it does not provide the requested trust-boundary capability contract or declared-versus-observed review model. This is a security-sensitive product and policy RFC whose schema, authority, legacy handling, and advisory-to-enforcement rollout require maintainer direction.

## What This Changes

The issue proposes an advisory, machine-readable skills capability manifest for network, filesystem, external-code execution, and secret-reading declarations.

## Best Possible Solution

Adopt a narrowly versioned, advisory-first capability schema with an explicit unknown/legacy state, parser validation, visible review evidence, and a separately approved policy for any future mismatch handling or enforcement.

- **Limit v1 to existing metadata:** Standardize only dependencies and environment declarations now, while reserving execution, filesystem, network, and secret claims for a later security design.
