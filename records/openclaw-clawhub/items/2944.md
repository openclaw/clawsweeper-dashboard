This remains a security/trust RFC that needs maintainer product and security direction before implementation.

## What This Changes

The issue proposes a machine-readable SKILL.md capability manifest for trust-boundary declarations such as network access, filesystem access, external-code execution, and secret reads.

## Best Possible Solution

Keep the RFC open for maintainer security/product design, then implement a spec-backed capability schema, parser/storage/API surface, docs, and advisory review output that coordinates with ClawScan and related security RFCs.
