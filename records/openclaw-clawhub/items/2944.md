## Summary

Keep open: current main has adjacent env/dependency metadata and ClawScan review prompts, but it still lacks the requested first-class skill capability manifest for network, filesystem, external-code execution, and secret-reading boundaries.

## What This Changes

The issue proposes a machine-readable SKILL.md capability block for declaring network, filesystem, external-code execution, and secret-reading behavior.

## Best Possible Solution

Define a spec-backed advisory skill capability manifest, parse/store/expose it, and update ClawScan and docs to compare declared versus observed behavior before making it required.
