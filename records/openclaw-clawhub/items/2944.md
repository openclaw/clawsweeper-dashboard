## Summary

Keep this open: current main has adjacent skill env/dependency metadata and ClawScan coherence checks, but it does not implement the requested declared capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security/product RFC that needs maintainer schema, authority, and rollout decisions.

## What This Changes

The issue requests an RFC decision for a machine-readable SKILL.md capability manifest declaring network, filesystem, external-code execution, and secret-reading boundaries.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, and update ClawScan/docs to compare declared versus observed behavior before any required rollout.
