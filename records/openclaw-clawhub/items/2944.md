## Summary

Keep this open: current main still has adjacent env/dependency metadata, ClawScan coherence guidance, and plugin capability planning, but it does not implement the requested machine-readable SKILL.md capability manifest. The prior capability-manifest PR was closed unmerged, so this remains the canonical security/product RFC needing maintainer direction.

## What This Changes

The issue requests a machine-readable skill capability manifest for trust-boundary behavior such as network access, filesystem access, external code execution, and secret reads.

## Best Possible Solution

Define a spec-backed advisory capability schema first, then parse/store/expose it and have ClawScan compare declared versus observed behavior before considering any required rollout.
