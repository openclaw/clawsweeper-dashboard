## Summary

Keep open: current main and v0.23.1 provide adjacent environment, dependency, install, and scanner-coherence metadata, but they do not implement the requested trust-boundary capability declarations. The earlier implementation attempt was closed unmerged for concrete compatibility regressions, so this RFC remains the canonical place for maintainer security and product direction.

## What This Changes

Add a machine-readable skill manifest declaring network, filesystem, external-code execution, and secret-reading capabilities for declared-versus-observed security review.

## Best Possible Solution

Define a durable spec-backed advisory schema inside existing skill metadata, preserve declared versus observed or verified provenance, expose it through the API and review tooling, and gather mismatch data before considering mandatory enforcement.
