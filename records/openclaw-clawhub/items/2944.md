## Summary

Keep open: current structured environment-variable and dependency metadata is a useful foundation, but it does not establish the requested trust-boundary capability contract or declared-versus-observed review model. The schema, authority, legacy treatment, and advisory-to-enforcement rollout remain security and product decisions. Likely related people: mahsumaktas (medium confidence) introduced the merged structured-manifest foundation.

## What This Changes

The issue proposes a machine-readable skill capability manifest and advisory tooling that compares declared capabilities with observed network, filesystem, secret, and external-execution behavior.

## Best Possible Solution

Define an advisory-first capability schema with explicit authority and legacy semantics, surface it through the registry and security-review path, then require evidence that declared-versus-observed comparisons are accurate before considering enforcement.
