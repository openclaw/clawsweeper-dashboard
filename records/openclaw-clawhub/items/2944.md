## Summary

Keep open: current main still has adjacent env/dependency declarations and ClawScan coherence review, but not the requested declared capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security/trust RFC that needs maintainer decisions on schema, authority, rollout, and legacy handling.

## What This Changes

Request to add a machine-readable SKILL.md capability manifest so skills can declare trust-boundary behavior and tooling can compare declared versus observed behavior.

## Best Possible Solution

Define a spec-backed advisory capability schema, parse/store/expose it in skill metadata, document it publicly, and have ClawScan report declared-versus-observed mismatches after maintainers choose the schema and rollout.
