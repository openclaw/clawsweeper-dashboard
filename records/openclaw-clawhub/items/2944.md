## Summary

Keep this open: current main has adjacent runtime metadata, env/dependency declarations, and ClawScan coherence checks, but it still lacks the requested machine-readable capability manifest for network, filesystem, external-code execution, and secret-reading boundaries.

## What This Changes

Add a standard machine-readable SKILL.md capability manifest so skills can declare trust-boundary behavior for review and declared-versus-observed checks.

## Best Possible Solution

Define a spec-backed advisory capability schema under skill metadata, parse/store/expose it, update docs and ClawScan review output to compare declared versus observed behavior, and only tighten rollout after maintainer security review.
