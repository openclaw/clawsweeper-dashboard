## Summary

Keep this open: current main has adjacent skill runtime metadata and env-focused security checks, but it still lacks the requested declared capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This is a security/trust RFC that needs maintainer product and security direction before implementation.

## What This Changes

The issue proposes a machine-readable SKILL.md capability manifest for declared trust-boundary behavior such as network access, local filesystem access, external code execution, and secret reads.

## Best Possible Solution

Define a maintainer-approved capability-manifest contract for skills, document the rollout and trust-boundary intent in specs/docs, and wire scanner/review output to declared-vs-observed diffs only after the policy is settled.
