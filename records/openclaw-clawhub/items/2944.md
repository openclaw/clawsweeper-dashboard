## Summary

Keep this open: current main has adjacent skill runtime metadata, ClawScan coherence checks, and package/plugin capability summaries, but it still lacks the requested first-class SKILL.md capability manifest for network, filesystem, external-code execution, and secret-reading boundaries. This remains a security-boundary RFC that needs maintainer schema and rollout decisions.

## What This Changes

This RFC requests a standard machine-readable skill capability manifest for declared trust-boundary behavior in SKILL.md frontmatter.

## Best Possible Solution

Define a spec-backed advisory skill capability schema, parse/store/expose it through skill metadata and APIs, update docs and ClawScan output to compare declared versus observed behavior, then decide the required-manifest rollout after review data exists.
