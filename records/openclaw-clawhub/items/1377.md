## Summary

Keep open. Current main, the latest release lineage, and the live ClawHub API still expose a platform-wide MIT-0/no-attribution skill license, while the reported upstream package metadata says MIT; resolving that mismatch requires maintainer/legal product direction rather than cleanup closure.

## What This Changes

The issue asks ClawHub to stop showing the reported skill as MIT-0/no-attribution and instead display the package's standard MIT license.

## Best Possible Solution

Maintainers should choose one license model and implement it consistently across upload consent, Convex storage, API schemas, listing UI, CLI output, docs, migrations or backfills, and publisher communication.

## Reproduction Assessment

Yes. Source inspection and the live ClawHub API show the reported skill still exposes MIT-0, while the upstream package metadata and LICENSE report MIT.

## Solution Assessment

No. A display-only MIT label is not the best fix because it would contradict ClawHub's current platform license contract unless maintainers first decide to support per-skill licensing and migrate the related surfaces together.
