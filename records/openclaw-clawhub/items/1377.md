## Summary

Keep open. Current main and the latest release still intentionally model ClawHub skill licensing as platform-wide MIT-0, while the live reported skill API returns MIT-0 and npm reports the upstream package as MIT; resolving this requires maintainer/legal product direction rather than conservative cleanup closure.

## What This Changes

The issue asks ClawHub to stop displaying the reported MIT-licensed skill as MIT-0/no-attribution.

## Best Possible Solution

Maintainers should choose one license model and then align upload consent, Convex storage, public API schemas, listing UI, CLI output, docs, migrations or backfills, and tests to that model.

## Reproduction Assessment

Yes. The live ClawHub API returns MIT-0 for the reported skill while npm reports MIT for the upstream package, and current main encodes MIT-0 as the platform skill license.

## Solution Assessment

No automatic display-only fix is clearly best. Showing MIT for this skill would contradict the current platform license contract unless maintainers decide to support per-skill or package-source licensing and migrate the related surfaces together.
