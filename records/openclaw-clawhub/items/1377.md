Keep open. Current main and the live ClawHub API still report MIT-0 for this skill, while the linked fix remains open; historical discussion confirms that changing this behavior reverses an intentional platform-wide licensing policy and therefore needs maintainer approval.

## What This Changes

Support declared standard MIT licenses so ClawHub does not represent MIT-licensed skills as MIT-0.

## Best Possible Solution

Support authoritative standard MIT declarations across publish and import detection, stored metadata, public APIs, CLI, and UI, while retaining explicit publisher consent and using a conservative backfill limited to records with clear root MIT evidence.
