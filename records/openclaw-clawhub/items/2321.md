## Summary

Keep this open: it is a collaborator-authored moderation/security RFC with protected review signals, and current main only partially resolves the requested policy framework. The remaining category boundaries and enforcement choices require explicit maintainer product and security judgment.

## What This Changes

Define content-policy categories and map them to registry visibility, upload review, installability, and account-enforcement outcomes.

## Best Possible Solution

Retain the context-sensitive acceptable-use model and publish a maintainer-approved category-to-consequence matrix that clearly separates public rules, reviewer-only guidance, positive trust signals, artifact actions, and account escalation.
