## Summary

Keep this open: it is a collaborator-authored moderation/security RFC, and current main only partially addresses it through behavior-based acceptable-use and enforcement rules. The remaining category-wide financial-content boundary and category-to-enforcement mapping require explicit maintainer product and security judgment.

## What This Changes

Define content-policy categories and their effects on registry visibility, upload review, installability, and account enforcement.

## Best Possible Solution

Retain a concise behavior-based public policy, record the durable category-to-visibility/install/account-action matrix in the moderation spec, and adopt any category-wide financial-content exclusion only through an explicit maintainer security and product decision.
