## Summary

Current main still exposes most skill operations as top-level commands alongside separate `skill` and `package` groups, so the requested consolidation is not implemented. This collaborator-authored, milestoned feature should remain open for an explicit decision on namespace naming and backward compatibility.

## What This Changes

Consolidate skill-oriented top-level ClawHub CLI commands beneath a dedicated skill namespace now that the CLI also supports plugin packages.

## Best Possible Solution

Adopt one canonical skill namespace, retain the current top-level forms as documented deprecated aliases for a defined compatibility window, and cover both canonical and legacy invocations in CLI tests and package documentation.
