## Summary

Keep open: current main and latest release v0.23.1 still expose the reported skill operations as root-level CLI commands, and this collaborator-authored CLI taxonomy change needs maintainer direction before implementation.

## What This Changes

Request to consolidate most top-level skill-related `clawhub` CLI commands under a skills namespace now that plugin/package commands also exist.

## Best Possible Solution

Define a maintainer-approved CLI taxonomy that adds or migrates to a consistent skill namespace while preserving compatibility aliases or a clear deprecation path, then update CLI docs and package tests together.
