## Summary

The requested consolidation remains missing from both current main and v0.23.1, and no canonical issue or PR supersedes it. This collaborator-authored, milestoned request should remain open because the permanent CLI naming and compatibility policy require explicit maintainer direction.

## What This Changes

Consolidate the full skill lifecycle under one canonical ClawHub CLI namespace while separating it clearly from package and plugin commands.

## Best Possible Solution

Make one complete skill namespace canonical, retain current root and superseded namespace spellings as compatibility aliases through a documented deprecation window, and cover canonical plus compatibility invocations in built-artifact tests and README examples.

Options:

- **Expand singular `skill` (recommended):** Make the established namespace cover the complete lifecycle and retain root aliases through a documented transition.
- **Introduce plural `skills`:** Adopt the requested plural namespace and explicitly transition both the singular group and root commands.
- **Keep mixed hierarchy:** Preserve all current invocation paths and treat visual help grouping as the permanent organization.

## Reproduction Assessment

Yes. Current source, README examples, help grouping, artifact tests, and the v0.23.1 tree all reproduce the mixed root and singular-group command hierarchy with high confidence.

## Solution Assessment

The consolidation goal is appropriate, but an immediate move to plural `skills` is not established as the best solution; expanding one canonical namespace while preserving compatibility aliases is the narrowest maintainable direction.
