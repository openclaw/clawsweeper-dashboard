## Summary

Keep open: current main and released CLI v0.23.1 retain root-level skill commands, while the singular `skill` namespace covers only a narrow published-skill subset. This collaborator-authored, roadmap-aligned request still needs maintainer intent on naming, scope, aliases, and deprecation timing.

**Likely related people:** Patrick-Erichsen and steipete have the strongest CLI history; vyctorbrzezowski recently owned the help-grouping UX.

## What This Changes

Consolidate most skill-specific root commands under a canonical skill-oriented ClawHub CLI namespace now that package and plugin commands coexist.

## Best Possible Solution

Choose one canonical skill namespace for the complete lifecycle, retain every established root invocation as a compatibility alias through a documented migration window, and update help, README usage, and CLI integration coverage together.
