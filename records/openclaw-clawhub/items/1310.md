## Summary

Keep open: current main and v0.23.1 have a consolidated security audit surface and a deterministic publish-time quality gate, but they do not implement the requested public, multidimensional skill-quality signals or the product policy needed to make those signals trustworthy.

## What This Changes

The issue asks ClawHub to consider public skill-quality signals covering documentation, claim accuracy, maintenance, dependency hygiene, alternatives, and other dimensions beyond security scanning.

## Best Possible Solution

Define an advisory quality-signal contract distinct from security and moderation verdicts, then add schema, API/search, backfill, and browse/detail UI only after product and security approval.

Not applicable: this is a product/data proposal for new public quality signals, not a broken existing behavior report. The high-confidence check is source and docs inspection showing the requested public scoring surface is absent on current main.
