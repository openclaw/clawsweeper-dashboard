## Summary

## What This Changes

The PR replaces homepage app/plugin favicon rendering with a Simple Icons/local SVG resolver, adds curated brand SVG assets and preloads, updates homepage icon CSS, and adds icon-source tests.

## Best Possible Solution

Land a stable, maintainer-approved icon source that preserves the intended brand color treatment or explicitly chooses monochrome icons, with fresh latest-head browser proof across affected tabs and light/dark mode.

## Reproduction Assessment

Yes for the review findings by source inspection: the latest head maps many brands to Simple Icons and renders them as one-color masks from an unpinned CDN base. I did not run a local browser; the posted screenshot is stale relative to the latest head.

## Solution Assessment

No. The resolver abstraction is plausible, but this is not the best final solution until maintainers approve the icon source/color strategy and the contributor refreshes proof for the latest head.
