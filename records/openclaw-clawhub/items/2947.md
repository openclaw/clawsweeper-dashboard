## Review Findings

Overall correctness: patch is incorrect

Full review comments:

- **[P1] Require package management permission before previewing:** `convex/packages.ts:7806-7809`
  - body: This new public action only checks that the caller is signed in, then the preview helper reads the named package's latest release README and may send it to OpenAI. Other package management paths, such as `getManageContext`, verify owner/admin access first; without the same check, any signed-in user can request a changelog preview for a private or blocked package by name and receive a summary of release content. Gate the previous-release lookup behind package manage permission before reading storage or calling OpenAI.
  - confidence: 0.91
- **[P2] Use package README labels in the AI preview input:** `convex/lib/changelog.ts:245-251`
  - body: Passing `subjectLabel: "Package"` changes the heading and instructions, but `generateWithOpenAI` still labels the content as `Previous SKILL.md` and `New SKILL.md`. When `OPENAI_API_KEY` is configured, package previews can still be generated from skill-specific labels and produce the wording this PR is meant to avoid. Make the README labels subject-specific and cover the AI-input path in tests.
  - confidence: 0.82
