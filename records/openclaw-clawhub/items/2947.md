- **[P1] Authorize package history before previewing it:** `convex/packages.ts:7806`
  - body: This new public action only checks that the caller is signed in, then `generatePackageChangelogPreview` reads the named package and latest release README via internal queries.   - confidence: 0.88

With `OPENAI_API_KEY` enabled, package previews can still produce skill-specific changelog text, so the AI prompt path should use package/README labels and have coverage for that path.
