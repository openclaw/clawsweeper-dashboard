## Summary

Keep this PR open because its unique reliability fix is not present on current main, but the proposed implementation is not merge-ready: the generic claim-error handler retries permanent failures as though they were transient OCC conflicts.

## What This Changes

Retries failed security-scan lease claims with a one-second backoff until the claim window closes and adds focused tests for recovery and deadline behavior.

## Best Possible Solution

Retry only explicitly recognized transient OCC or transport failures with bounded backoff, fail promptly for permanent errors, document the retry invariant in the security-worker specification, and validate both paths in a real Convex worker run.
