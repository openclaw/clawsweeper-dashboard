- **[P2] Wire the Signals deep link into route state:** `convex/publisherAbuse.ts:2490`
  - body: `dashboardUrl` sends Hermit recipients to `/management?view=abuse&tab=signals`, but `validateSearch` drops `tab` and `publisherAbuseTab` still initializes to `potential_ban_candidate`. - **[P2] Query open signals by status before paginating:** `src/routes/management.tsx:290-292`
  - body: For the default Open status, the UI passes `{}` to `listSignalsPage`, so the backend paginates all signals by `lastSeenAt` and filters to open after fetching the page. Recent snoozed or dismissed rows can make the Open tab empty or underfilled even when open rows exist later, and it bypasses the status index the schema added.
  - confidence: 0.9
- **[P3] Use valid status-filter semantics:** `src/routes/-management/AbusePage.tsx:320-326`
  - body: The signal status filter is declared as a `tablist`, but the children are plain buttons with `aria-selected`. Screen readers will not get a valid selected state here; make this a real tab set or use toggle/radio semantics such as `aria-pressed` or a radiogroup.
  - confidence: 0.84
