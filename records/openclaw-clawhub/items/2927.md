Full review comments:

- **[P2] Wire the Signals deep link into route state:** `convex/publisherAbuse.ts:2490`
  - body: `dashboardUrl` sends Hermit recipients to `/management?view=abuse&tab=signals`, but the management route validation drops `tab` and the abuse tab state still starts on `potential_ban_candidate`.   - confidence: 0.94
- **[P2] Page the open Signals queue by status:** `src/routes/management.tsx:288-292`
  - body: The Open filter path sends `{}` to `listSignalsPage`, so the backend paginates by `lastSeenAt` across all signal statuses and only filters to open after selecting the page. Once recent snoozed or dismissed rows exist, the default Open queue can render short or empty pages while open rows sit behind later cursors; paginate over `reviewStatus: 'open'` or otherwise page only open rows.
  - confidence: 0.88
- **[P3] Use valid status-filter semantics:** `src/routes/-management/AbusePage.tsx:320-327`
  - body: The signal status filter is declared as a `tablist`, but the children are plain buttons with `aria-selected`. Screen readers will not get a valid selected state here; make this a real tab set or use toggle/radio semantics such as `aria-pressed` or a radiogroup.
  - confidence: 0.83
