## What This Changes

This issue asks whether ClawHub should add skill recommendation, dependency/conflict metadata, and production pinning guidance for agents with many installed or loaded skills.

Maintainers should define a ClawHub skill-governance contract first, then add any chosen metadata, API, UI, and CLI behavior with specs that separate package dependencies, skill conflicts, recommendation signals, and local pin/load policy.
