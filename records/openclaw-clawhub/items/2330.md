## Summary

Keep open for maintainer product direction. This collaborator-authored feature request remains necessary: the prior current-main review found no publisher-wide install command, while skills and plugins still have different installation lifecycles; the related CLI-consolidation issue overlaps but does not decide this behavior.

## What This Changes

Add a `clawhub` workflow to install all skills and plugins published by a specified publisher.

## Best Possible Solution

Define a publisher-scoped install contract first—preferably starting with skills unless plugin package installation semantics are explicitly specified—then implement a bounded CLI command with selection, failure reporting, idempotent updates, and documentation for mixed publisher inventories.

Options:

- **Ship skills-only bulk install (recommended):** Add an explicit publisher skills command while leaving plugin package installation as its existing separate workflow.
- **Define unified publisher installation:** Design and approve plugin package selection, verification, permission, update, and partial-failure semantics before exposing one command for both artifact types.
- **Defer the feature:** Keep the current per-skill and package workflows until maintainers prioritize a broader publisher onboarding experience.
