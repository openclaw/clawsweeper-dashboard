## Summary

Keep open for maintainer direction. Current main and v0.23.1 still provide single-item installation rather than publisher-wide installation, and the requested bulk workflow requires explicit decisions about artifact families, trust prompts, compatibility checks, and partial failures.

## What This Changes

Add a ClawHub CLI workflow to install all skills or plugins published by one publisher.

## Best Possible Solution

Define a family-aware publisher catalog preview that preserves per-artifact trust, moderation, and compatibility decisions, then installs a confirmed snapshot with deterministic ordering and clear partial-failure reporting.

- **Discovery without bulk install:** Expose publisher catalog listing in the CLI but retain individual install or download commands for every artifact.
