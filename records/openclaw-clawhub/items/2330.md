## Summary

Keep open for maintainer product direction. Current main and v0.23.1 still provide per-item skill and plugin workflows rather than publisher-wide installation, and this collaborator-authored request cannot be auto-closed.

## What This Changes

Add a publisher-scoped workflow that installs all selected skills and plugins published by that owner.

## Best Possible Solution

Define a previewable, versioned publisher bundle that selects explicit skills and plugins, delegates each artifact to its existing safe installer, reports partial failures, and records the trust and installability invariants in `specs/`.

Rationale: The choices have materially different consent, supply-chain, compatibility, and cross-repository implications that cannot be selected from existing behavior alone.

Likely owner: Patrick-Erichsen

Options:

- **Require curated bundles (recommended):** Let publishers explicitly version a bundle whose members are previewed before the existing skill and plugin installers process them.
- **Support skills only:** Add publisher-scoped bulk skill installation while leaving plugins on their existing explicit per-package path.
- **Install every listing:** Dynamically resolve all current publisher skills and plugins and install them with mixed partial-failure handling.
