## Summary

Keep open for maintainer direction. Current main and v0.23.1 still provide only single-skill installation, and this collaborator-authored, milestoned request requires an explicit decision about whether ClawHub should also orchestrate OpenClaw’s separate plugin installer.

## What This Changes

Requests a CLI capability to install every skill and plugin published by a selected publisher.

## Best Possible Solution

Add a publisher-scoped skill command that enumerates eligible skills and reuses the existing installer per item with resumable results, then add plugin support only after maintainers define a stable ClawHub-to-OpenClaw installation contract.
