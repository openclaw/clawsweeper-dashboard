## What This Changes

## Best Possible Solution

Create or transfer an official ClawHub/OpenClaw GitHub OAuth App, rotate the production `AUTH_GITHUB_ID` and secret while preserving the intended callback, then capture redacted fresh browser and CLI authentication proof.
