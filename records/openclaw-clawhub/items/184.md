## Summary

Current main has adjacent trust, moderation, and badge primitives, but no paid expedited human-review certification program. The request remains necessary if maintainers want that product, and it requires an explicit trust, security, operations, and payment-policy decision before implementation.

## What This Changes

Add a paid expedited human security-review pipeline and public approval badge for skills that pass manual review.

## Best Possible Solution

If approved, create a distinct, auditable, expiring artifact-review attestation whose fee purchases queue priority rather than a favorable outcome, without overloading Official or automated scan status.
