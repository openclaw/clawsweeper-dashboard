## What This Changes

The issue requests a product policy that keeps published skill titles short and concise.

## Best Possible Solution

Define the display-name length policy and legacy behavior, then enforce it consistently in shared backend validation, web publish/import UI, CLI/API schemas, docs, and regression tests.

## Reproduction Assessment

Yes, at source level: the current shared publish helper, schema, web validation, GitHub import, and CLI request schema accept any non-empty displayName and do not encode a maximum length. I did not run a live publish because this review is read-only and the validators already show the missing policy.

## Solution Assessment

Unclear until maintainers choose the maximum length and legacy handling. A presentation-only clamp would be too narrow because CLI, API, web publish, and GitHub import would remain inconsistent.
