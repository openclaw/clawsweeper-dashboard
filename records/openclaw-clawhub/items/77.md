## Summary

Keep open. Current main and v0.23.1 still do not enforce a skill display-name length limit, and the open linked PR is the active fix candidate rather than a reason to close this issue before merge.

## What This Changes

The issue asks ClawHub to enforce short, concise skill titles/display names so oversized names do not dominate catalog UI.

## Best Possible Solution

Review and land an upgrade-safe implementation such as https://github.com/openclaw/clawhub/pull/2962, or replace it with an equivalent policy-confirmed cap that covers hosted publish, GitHub-backed sync, schemas, docs, and tests.
