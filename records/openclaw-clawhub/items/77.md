## What This Changes

Request a skill title/display-name limit so public skill listings stay short and concise.

## Best Possible Solution

Define the public skill display-name policy, then enforce it in shared backend validation with aligned web publish, GitHub import, CLI/API schema/docs, and regression coverage for existing long-name behavior.

## Solution Assessment
