## What This Changes

The issue requests a maximum length or policy for skill titles so they stay short and concise.

## Best Possible Solution

Define the public skill display-name maximum and legacy policy, then enforce it in shared backend validation with aligned web publish, GitHub import, CLI/API schema, docs, and regression tests.

## Reproduction Assessment

## Solution Assessment

Unclear until maintainers choose the maximum length and legacy handling. The maintainable solution is a shared backend rule with UI/API/CLI/docs/test alignment, not a presentation-only clamp.
