## What This Changes

The issue proposes optional skill and plugin manifest metadata for task routing, advisory risk preflight, verification expectations, and reusable operational playbooks for Harness-style consumers.

## Best Possible Solution

Define a narrowly versioned, optional advisory metadata contract—starting with machine-readable routing and verification hints—while keeping publisher risk declarations non-authoritative and preserving OpenClaw policy enforcement as the hard boundary.
