## Summary

Current ClawHub supports runtime/setup metadata and registry search, but not the proposed routing, verification, risk, or playbook contract. This valid, vision-aligned RFC should remain open for a narrow product and trust-boundary decision.

## What This Changes

Requests optional skill/plugin routing, risk, verification, and playbook metadata exposed through ClawHub API and CLI consumers.

## Best Possible Solution

Define a small versioned advisory v1 for intents and machine-readable verification hints, expose raw fields through detail/inspect APIs and CLI, treat author risk claims as untrusted, and defer registry ranking, quality scoring, and playbook promotion until evaluation data supports them.

- **Decline registry routing metadata:** Keep routing in external harnesses using existing descriptions, content, and search results to avoid another long-lived contract.
