## Summary

Keep open for a maintainer product and trust-boundary decision: current main has adjacent structured manifest metadata, but it does not provide the requested routing, advisory-risk, verification, or playbook contract.

## What This Changes

Request optional skill and plugin manifest metadata for routing candidates, advisory risk/preflight hints, verification expectations, and reusable playbook signals exposed through ClawHub APIs and CLI.

## Best Possible Solution

Define a small versioned advisory metadata namespace shared by skills and packages, expose raw values before any ClawHub ranking, and explicitly keep runtime authorization and security decisions in OpenClaw policy and moderation systems.

Options:

- **Keep this external to ClawHub:** Leave routing indexes and evaluation policy to Harness implementations and retain only existing install, compatibility, and scan metadata in the registry.
