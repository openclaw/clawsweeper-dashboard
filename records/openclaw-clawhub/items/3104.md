## Summary

Keep open for a maintainer product and trust-boundary decision. Current main supports structured runtime/install metadata and registry discovery, but it does not provide the proposed routing-candidate contract, advisory risk/preflight semantics, verification hints, or playbook metadata; those fields need a deliberately narrow public contract before implementation.

## What This Changes

The issue proposes optional skill and plugin manifest metadata for routing, advisory risk/preflight, verification, and playbook hints, exposed through ClawHub APIs and CLI.

## Best Possible Solution

Adopt a small, explicitly advisory routing-metadata v1 only after defining its public semantics, API representation, abuse handling, and the hard boundary that OpenClaw—not ClawHub metadata—remains responsible for execution policy.
