## Summary

The request remains necessary because current main provides deterministic publish-quality enforcement and extensive security scanning, but not semantic quality judging, eval-based behavior testing, or version regression analysis. Official adoption requires maintainer direction on evaluator authority and external-model data handling.

## What This Changes

Evaluate whether ClawHub should integrate or officially endorse an external CLI for semantic skill scoring, eval-based behavior testing, and version regression checks.

## Best Possible Solution

Specify an advisory-only quality-signal contract in `specs/`, including provider/data policy, reproducibility and provenance requirements, and strict separation from moderation, then evaluate a narrow pilot against current deterministic and ClawScan signals.
