## Summary

Keep this PR open, but do not merge it as-is: it targets a real publish blockage tracked at https://github.com/openclaw/clawhub/issues/2984, yet the patch makes the prepublication TruffleHog/ClawScan gate client-bypassable by any authenticated publisher.

## What This Changes

The PR adds a public `stagePrePublicationChecks` boolean to skill publish schemas and forwards `false` from CLI/API publish requests to bypass staged prepublication checks.

## Best Possible Solution

Keep staged checks as the default and expose emergency recovery through an audited operator/staff-only path that can target stuck attempts or temporarily drain/disable staging, with regression tests and live publish proof.
