## Summary

Keep open: this is a new RFC for a separate organization-profile identity, and the supplied context shows meaningful product and authorization choices that current discussion has not resolved. No merged or open implementation PR in the provided context owns the work.

## What This Changes

Add optional GitHub identity metadata for organization publishers so their public profile can link to a GitHub account independent of the immutable ClawHub handle and package coordinate.

## Best Possible Solution

Adopt a display-only organization `githubHandle` or normalized GitHub profile URL with handle-derived fallback, authorize the chosen organization role narrowly, and keep it explicitly separate from package ownership, artifact provenance, and trusted-publishing claims.
