## Summary

Keep this issue open because current `main` still requires users to build and copy `axorc` manually, and the official OpenClaw tap has no AXorcist formula. The remaining blocker is a maintainer decision about whether `axorc` is a supported standalone distribution and whether Homebrew should install release binaries or build from source.

**Likely related people**
- `steipete` — high confidence; released both tagged AXorcist versions and is the strongest available owner for release and Homebrew direction.
- `WinnCook` — medium confidence; substantial contributor to the AXorcist codebase and useful for CLI/build compatibility review.

## What This Changes

Requests a supported Homebrew installation path for the AXorcist `axorc` CLI on macOS.

## Best Possible Solution

If standalone distribution is approved, publish a versioned macOS CLI archive, add an `axorc` formula to `openclaw/homebrew-tap`, document Accessibility permission and upgrade behavior, and verify clean install, `--help`, and a harmless live command on supported macOS versions.

Options:

- **Ship release binaries (recommended):** Publish a versioned universal or per-architecture macOS archive and install it through the official OpenClaw tap, matching the established Peekaboo distribution pattern.
- **Build from source:** Add a source formula that builds the tagged Swift package, accepting a Swift toolchain dependency and slower installation in exchange for simpler release artifacts.
- **Keep CLI developer-only:** Decline standalone AXorcist packaging and clarify that end users should use the supported Peekaboo CLI while `axorc` remains a source-build tool.
