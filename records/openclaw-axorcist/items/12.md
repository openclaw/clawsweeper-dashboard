## Summary

This request remains necessary because current main provides the `axorc` executable but only supports a SwiftPM build and manual binary copy; no Homebrew installation path is present.

## What This Changes

Add a supported Homebrew installation path for the AXorcist CLI on macOS.

## Best Possible Solution

Publish a versioned `axorc` formula through the official OpenClaw tap, pin its source or binary checksum, automate formula updates from tagged releases, and document installation, upgrading, permissions, and a clean-machine smoke test while keeping AXorcist-local changes minimal.
