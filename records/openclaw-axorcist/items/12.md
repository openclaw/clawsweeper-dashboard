## Summary

This request remains necessary: current main exposes the `axorc` executable but only documents building it with SwiftPM and copying it manually. An official OpenClaw Homebrew tap exists, but maintainers still need to choose tap ownership and whether AXorcist should ship source-built or prebuilt release artifacts.

## What This Changes

## Best Possible Solution

Publish versioned, checksummed macOS CLI artifacts from tagged AXorcist releases, update an `axorc` formula in `openclaw/homebrew-tap`, smoke-test fresh install and upgrade paths, and document the resulting `brew install` command while keeping Peekaboo integration unchanged.
