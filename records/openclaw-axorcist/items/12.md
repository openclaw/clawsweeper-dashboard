## Summary

This request remains necessary: current main defines the standalone `axorc` executable but documents only building it with SwiftPM and copying it into `/usr/local/bin`, while the official OpenClaw tap has no AXorcist formula. The implementation should wait for a maintainer decision on whether AXorcist is distributed independently and whether Homebrew builds from source or installs release artifacts. ([github.com](https://github.com/openclaw/AXorcist/blob/main/Package.swift))

## What This Changes

Add a supported Homebrew installation path for the `axorc` macOS CLI.

## Best Possible Solution

Publish `axorc` through `openclaw/tap` using versioned macOS artifacts, automated checksum updates, an installation smoke test, and README instructions; keep AXorcist-side changes minimal and document how releases remain synchronized with Peekaboo. ([github.com](https://github.com/openclaw/homebrew-tap))

## Maintainer Decision

Required: true

Kind: product_direction

Question: Should AXorcist's `axorc` executable be supported as an independently distributed CLI, and if so should Homebrew install prebuilt release artifacts or build the Swift package from source?

Rationale: The repository exposes and documents the CLI, but neither the release notes nor official tap establish a supported standalone distribution contract; choosing that contract determines the release workflow, formula design, and Peekaboo synchronization responsibilities.

Likely owner: steipete

Owner reason: The AXorcist release and recent CLI history most strongly points to `steipete`, and this decision affects the project's release contract.

Owner confidence: high

Options:

- **Ship artifact-backed formula (recommended):** Publish versioned Apple Silicon and Intel macOS CLI archives and install them through `openclaw/tap`, avoiding a Swift toolchain requirement for users.
- **Ship source-build formula:** Add a tap formula that builds the tagged Swift package locally, accepting Xcode/Swift requirements and slower installs.
- **Keep manual installation:** Treat `axorc` as a developer-oriented companion executable and retain the documented SwiftPM build-and-copy workflow.
