## Summary

The revised branch addresses both previous review findings, but the no-interaction path can still reject an import before checking later Safe Storage aliases, and live macOS Keychain proof remains absent.

## What This Changes

The PR preserves default interactive Keychain recovery, adds a TaskLocal host scope that suppresses prompts, limits allowed imports to one interactive lookup, and expands injected lookup tests.

## Best Possible Solution

Keep interactive recovery as the default, expose a maintainer-approved scoped no-prompt API, scan every candidate noninteractively before failing that scope, and allow only one host-alerted interactive retry after noninteractive options are exhausted.

- **Use an import option:** Replace the public gate with an explicit per-import policy parameter so interaction intent is visible at the call site.
- **Defer public API:** Keep the existing released behavior and postpone background prompt suppression until the host contract is better defined.

## Solution Assessment
