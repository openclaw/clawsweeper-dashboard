## Label Justifications

- `P3`: This is a useful but non-urgent additive browser-compatibility feature rather than a regression in existing supported behavior.
- `impact:other`: Users cannot select Firefox release channels as distinct sources, a concrete browser-coverage impact outside the more specific owned categories.

## Summary

Keep open: current main and release 0.4.1 still lack distinct Firefox channel choices, but the requested folder-only approach could duplicate or mislabel profiles because the existing Gecko design maps each Browser case to a single profile root. The feature remains useful and unsuperseded, with the public API model needing owner direction before implementation.

## What This Changes

Add first-class Firefox Beta, Developer Edition, Nightly, and compatible Gecko browser choices with macOS cookie-store discovery.

## Best Possible Solution

Implement an install-aware Firefox discovery model that attributes and deduplicates profiles before exposing separate channel cases; if reliable attribution is unavailable, retain one Firefox source and improve its profile labels and documentation instead.
