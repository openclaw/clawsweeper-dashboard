## Summary

Current main and release 0.4.1 still support only Firefox and Zen as Gecko browser choices, and live repository search found no open implementation or alternate tracker, so this remains a valid bounded feature request.

## What This Changes

Add first-class discovery and cookie-store support for Firefox Developer Edition, Beta, Nightly, and compatible Firefox variants on macOS.

## Best Possible Solution

Add only verified Firefox-channel cases and catalog metadata, reuse the shared Gecko importer, and deduplicate store discovery when multiple distributions resolve to the same profile root.
