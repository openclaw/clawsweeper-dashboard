## What This Changes

This PR makes pipeline handoff, workflow execution, external process calls, resume cleanup, and PR-monitor snapshot writes abort-aware so cancellation does not start later external work or leave replayable resumed state.

## System Context

Lobster’s tool runtime executes pipelines and file-defined workflows, which can invoke external processes and save state for later approval or input resumes. The changed cancellation path controls whether later stages run, whether persisted monitor data is committed, and whether a resume capability remains usable after an aborted execution.
