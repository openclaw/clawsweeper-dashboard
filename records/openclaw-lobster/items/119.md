## What This Changes

This PR makes pipeline handoff, workflow resume cleanup, process-backed commands, and PR-monitor state writes abort-aware so cancellation prevents later external work and replayable resume state.

## System Context

Lobster accepts tool and workflow requests, then runs pipelines that may stream lazy values into external commands or persist resumable state. This PR changes the cancellation boundary between a parent abort signal, downstream commands, workflow resume tokens, and monitor snapshots.

## Best Possible Solution

Adopt the explicit contract that cancellation before a workflow begins dispatch remains retryable, while cancellation after dispatch begins consumes every resolved workflow resume alias and approval index to prevent external-side-effect replay.
