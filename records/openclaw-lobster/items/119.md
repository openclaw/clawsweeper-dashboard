## Summary

This PR appears to close the previously reported cancellation gaps with focused production-path coverage and no remaining discrete code defect established from the supplied final diff. It should stay open for a maintainer to confirm the intended workflow-resume contract: cancellation after the first dispatched step consumes the resume capability, while cancellation during setup leaves it retryable.

## What This Changes

The PR propagates parent cancellation through pipelines, workflow execution, child processes, resume cleanup, and atomic monitor-state writes so cancelled runs cannot continue later external work or persist replayable state.

## System Context

Lobster’s runtime executes command pipelines and workflow files, some of which launch external programs and save state for later resume. An abort signal must stop later dispatch, preserve safe retry paths before execution starts, consume already-used resumes, and prevent cancelled runs from publishing state.
