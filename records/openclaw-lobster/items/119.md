## What This Changes

The PR propagates cancellation through pipelines, workflow steps, child processes, resume cleanup, and monitor-state writes so cancelled runs do not start later external work or preserve replayable post-start resume state.

## System Context

Lobster runs command pipelines and workflow files, passing a parent abort signal into commands, lazy stream handoff, workflow dispatch, and persisted state. Resume tokens and monitor snapshots are written to local state, so cancellation must stop later side effects while preserving or removing state at the correct lifecycle boundary.

  Streams --> Abort
  Abort --> Cleanup[Resume cleanup and iterator closure]
