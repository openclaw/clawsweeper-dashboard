## Summary

The earlier blocker remains on the current PR head: cancellation during an in-flight Gmail send preserves that send’s result but can still cross the unchanged pipeline boundary and start a later external stage. The process-termination changes are otherwise focused and well-proven.

## What This Changes

The PR adds cancellation-aware subprocess shutdown for Gmail search and GitHub PR monitoring, stops later drafts in a Gmail send batch after cancellation, and adds process-level regression tests and fixtures.

## Best Possible Solution

Keep definitive results from already-started side effects, but enforce an abort boundary before invoking any subsequent pipeline stage and cover that boundary with a downstream sentinel regression test.
