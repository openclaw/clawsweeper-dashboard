## Summary

This PR has strong real-behavior evidence and resolves several earlier replay and cancellation concerns, but it still lets an already-aborted workflow enter a non-pipeline step before cancellation is checked. That can start an external command despite the central guarantee, so it needs one focused repair before merge.

The branch adds cancellation boundaries for tool and workflow pipelines, abort-aware subprocess handling, resume-state cleanup, and cancellation regression tests.

## Best Possible Solution

Add a cancellation check immediately before workflow-step dispatch, cover pre-aborted non-pipeline workflow steps with regression tests, and retain the existing distinction between pre-execution retryability and post-start state consumption.
