## What This Changes

The branch makes cancelled pipelines and workflows stop later external work, removes replayable resumed state after post-start cancellation, and prevents cancelled GitHub PR-monitor runs from publishing a snapshot.

## System Context

Lobster executes tool pipelines and workflow files that can invoke external commands and persist resumable state. Cancellation enters through a parent abort signal, flows through lazy pipeline handoffs and workflow-step dispatch, then determines which output and resume-state cleanup is committed.
