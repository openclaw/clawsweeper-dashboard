## What This Changes

The branch makes pipeline, workflow, subprocess, and state-write cancellation abort later external work while retaining retryable resume state until workflow execution begins and deleting it after an aborted started resume.

## System Context

Lobster executes command pipelines and workflow files, passing a parent abort signal through command execution, lazy output, workflow dispatch, and persistent resume or monitor state. The changed paths determine whether cancellation stops downstream side effects and whether a later retry can safely reuse a saved continuation.
