- `merge-risk: 🚨 message-delivery`: A retained token can rerun an already-completed Gmail send after a downstream abort.

## Summary

Needs changes before merge: the new abort cleanup consumes only direct approval resumes, so aborted input and workflow resumes can retain tokens after an earlier side-effecting stage completed and replay that work on retry. Likely related people: steipete (low confidence; adjacent runtime/release history).

## What This Changes

The PR propagates parent cancellation to selected subprocess-backed commands, halts direct tool pipelines after an aborted stage, and consumes approval-resume state on aborted direct resumes.

## Best Possible Solution

Consume the prior resume state for any resumed execution that aborts after it may have performed side effects, while preserving retryability for ordinary non-abort failures; add focused direct-input and workflow-file replay regressions.
