## Summary

The final head removes the previously reviewed resume-state and generic-iterator changes, confining cancellation to commands that directly own child processes. The focused implementation is still needed, matches the supplied runtime proof, and has no discrete correctness or security blocker, so this PR should remain open for normal maintainer review and merge.

The PR propagates cancellation to Gmail search and GitHub monitor subprocesses, prevents later Gmail drafts from starting after cancellation, and adds three process-lifecycle regression tests with executable fixtures.
