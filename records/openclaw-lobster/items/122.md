## Summary

This is a focused, proof-positive reliability fix for an unhandled child-stdin error path that remains present on current main. The patch has no discrete correctness or security finding; it should stay open for ordinary maintainer review rather than cleanup closure.

## What This Changes

The PR installs no-op error listeners on child stdin in workflow shell and stdlib exec runners, and adds a regression test for a large workflow-stdin payload sent to a fast-exiting command.

## Best Possible Solution

Merge the focused guard with its workflow regression test so fast-exiting child commands preserve normal error reporting, approval handling, and resume behavior.
