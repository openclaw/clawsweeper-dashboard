## Summary

Keep open for product direction: the supported runtime remains Cloudflare-native, and a non-Cloudflare deployment would require equivalent authority, storage, identity, and operational contracts rather than Docker packaging alone.

## What This Changes

Requests a supported self-hosted ClawRouter deployment path without a hard Cloudflare dependency, ideally using Docker.

## Best Possible Solution

Define provider-neutral interfaces and conformance tests for policy storage, atomic budget enforcement, grant storage, identity, usage events, and migrations; only then add a reference Docker runtime that passes the same security and failure-mode contract as the Cloudflare deployment.
