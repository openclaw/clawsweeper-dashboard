## Summary

Current main offers Wrangler-based local development but no supported non-Cloudflare runtime. The request remains useful, but it requires a maintainer decision on platform scope and a portability contract for authoritative state, identity, queues, retention, assets, migrations, and operations before implementation can be safely scoped.

## What This Changes

Add a Docker-oriented self-hosting path that removes the hard production dependency on Cloudflare.

## Best Possible Solution

Sponsor a portability design that preserves the small provider-neutral request path, defines explicit runtime service adapters and parity requirements, and only then adds a Docker-backed implementation.
