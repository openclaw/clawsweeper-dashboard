## Summary

Current main supports local Wrangler development, but production still depends on Cloudflare Workers, Durable Objects, KV, Queues, R2, and Access. This request remains necessary and should be the canonical self-hosting proposal; the newer same-scope report should consolidate here. A second production platform requires explicit maintainer direction on security, durability, operational parity, and support scope.

**Likely related people:** steipete (high confidence, recent data-plane and deployment work) and vincentkoc (high confidence, initial platform architecture).

## What This Changes

Request a supported Docker-style self-hosting path without a hard Cloudflare runtime dependency.

## Best Possible Solution

Approve a portability architecture contract with shared runtime-neutral interfaces and parity tests, then implement Docker deployment using explicit durable services while retaining one provider-neutral request path.

- **Offer evaluation container:** Provide a best-effort local container without promising production durability, security, migration, or operational parity.
