## Summary

Current main does not provide a non-Cloudflare production runtime: Cloudflare Workers and its state, queue, archive, asset, and Access services are part of the documented architecture. The request is valid but requires an explicit platform-support decision and portability design before implementation can be scoped safely.

## What This Changes

Request a Docker-oriented self-hosting deployment path without a hard Cloudflare dependency.

## Best Possible Solution

If maintainers sponsor portability, first define a provider-neutral runtime adapter and conformance-test contract for authoritative state, queues, archives, identity, and assets, then ship one explicitly supported container deployment with documented parity, migration, backup, and upgrade behavior.
