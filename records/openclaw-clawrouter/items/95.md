## Summary

Current main supports Wrangler-based local execution and configurable self-hosted provider origins, but it does not provide a supported Cloudflare-independent production runtime. This remains a valid feature request, although maintainers must first choose the platform scope and required safety and feature parity.

## What This Changes

Request a supported local or Docker-based ClawRouter deployment path without a hard Cloudflare dependency.

## Best Possible Solution

Approve a portability design that preserves the provider-neutral hot path, defines explicit runtime service interfaces and parity guarantees, and only then adds one supported Docker-backed implementation.
