The prior self-host work documented console sessions as unavailable, and the proposed replacement adds a new local authentication boundary that needs product and security approval before it can resolve the request.

## What This Changes

Add an opt-in local browser-console login for Docker self-hosting when Cloudflare Access is unavailable.

## System Context

The self-host profile runs the Worker locally and currently uses an admin bearer token for management because Cloudflare Access identities are absent. This request would turn that existing operator credential into a server-side console session so the admin UI and session-scoped features can work in a browser.
