## What This Changes

Add per-principal budget isolation for assignment-rule users and allow authenticated maintainers to issue their own policy-bound proxy credentials.

## Best Possible Solution

Keep authorization policy-centric, introduce one canonical budget-subject abstraction that isolates verified human principals without fragmenting service credentials, and expose a constrained session endpoint that mints only revocable credentials bound to the caller's active principal and policy.
