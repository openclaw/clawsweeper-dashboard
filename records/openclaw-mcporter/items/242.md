## What This Changes

This PR changes the Windows OAuth browser opener to pass the authorization URL as a separate `cmd /c start` argument, adds quote-bearing URL unit coverage, and adds OAuth changelog entries.

## System Context

`mcporter auth` obtains an OAuth authorization URL and passes it to a platform-specific external-browser launcher before waiting for the OAuth callback. On Windows that launcher currently invokes `cmd.exe` and its `start` builtin, so the URL crosses a command-interpreter boundary before it reaches the default browser.
