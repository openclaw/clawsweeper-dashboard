## What This Changes

This PR adds guidance that generated MCP clients need an application-owned policy boundary for per-call authorization and that record/replay fixtures must be redacted before sharing.

## System Context

mcporter generates standalone command-line clients and typed clients from MCP server definitions, which can run outside the original client application. Its record/replay feature stores JSON-RPC exchanges as strict fixtures, so the documentation explains the security boundary around generated calls and safe handling of captured data.
