## What This Changes

This draft updates generated-CLI and record/replay documentation with guidance on external per-call policy wrappers and redacting JSON-RPC captures before sharing them as fixtures.

## System Context

mcporter can generate standalone CLIs and typed clients for MCP servers, allowing tools to be called outside the MCP client that originally configured them. Its recording and strict replay flow captures JSON-RPC exchanges for reproducible tests, so fixtures must be sanitized before distribution.

## Best Possible Solution

Keep the safety guidance in the existing generated-CLI and replay guides, while making the replay page explicitly identify the wrapper as an application-owned external policy layer rather than an mcporter feature.
