## What This Changes

This PR adds documentation explaining that generated CLIs need an application-owned per-call policy/audit wrapper and that record/replay fixtures must be redacted before sharing.

## System Context

mcporter generates standalone CLI and typed-client surfaces from MCP server invocations, while record/replay captures JSON-RPC exchanges for repeatable testing. The added guidance explains that authorization and auditing must remain in an application-owned wrapper and that recorded fixture data must be sanitized before it becomes a shared regression artifact.
