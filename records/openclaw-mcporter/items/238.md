## What This Changes

Adds documentation that generated CLIs require an application-owned policy/audit wrapper for per-call controls and that record/replay fixtures must be redacted before sharing.

## System Context

mcporter generates standalone CLIs for MCP servers and can record/replay JSON-RPC exchanges for deterministic regression testing. The proposed guidance explains that those generated artifacts and recordings leave the original client’s approval/audit boundary, so applications must add their own policy layer and redact captures.

## Architecture Diagram

flowchart LR
  A[Configured MCP server] --> B[Generated CLI or typed client]
  B --> C[Application-owned policy wrapper]
  C --> D{Evaluate and approve}
  D -->|Allowed| E[Execute MCP tool call]
  D -->|Blocked or declined| F[Redacted audit outcome]
  E --> F
  E --> G[Record or replay fixture]
  G --> H[Redacted regression fixture]

## Best Possible Solution

Merge the focused guidance if maintainers agree with the wording, keeping the wrapper explicitly application-owned and retaining the redaction-first replay-fixture advice.
