## Summary

This maintainer-authored PR should remain open. Timeline compaction aligns with Kova’s raw-artifact model, but the PID cache can indefinitely trust a stale or reused live PID and corrupt gateway resource attribution.

## What This Changes

Caches gateway PIDs across resource samplers and snapshots, removes duplicate timeline nesting, and compacts redundant cumulative timeline event arrays after evaluation.

## Best Possible Solution

Keep the timeline compaction, but refresh or validate cached gateway identity at a bounded cadence so stale live PIDs cannot persist, and attach a redacted before/after Kova measurement demonstrating the overhead reduction.
