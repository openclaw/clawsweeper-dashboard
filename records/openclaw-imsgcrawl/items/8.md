The branch migrates archives to a tombstone-and-revision schema, changes sync to merge by default with `--restore` replacement, parses iMessage revision metadata, and updates archive queries, CLI output, documentation, and tests.

## Best Possible Solution

Preserve replacement as the compatibility default unless a maintainer explicitly approves merge-by-default, add reverse stable-handle identity validation with regression coverage, remove the release-owned changelog entry, and attach redacted real CLI proof covering merge, restore, and revision/tombstone visibility.
