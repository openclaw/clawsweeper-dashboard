  - body: `0x81` denotes one following byte in the existing streamtyped encoding, but this branch reads two. The second byte is commonly the next stream tag, so ordinary `attributedBody` values are rejected and messages that rely on them lose their readable/searchable text.
  - confidence: 0.99
- **[P1] Clear stale text when an edit cannot be decoded:** `internal/archive/sync.go:177`
  - body: When a known new revision cannot reconstruct its current body, retaining the older archived text leaves superseded or withdrawn content active in reads and FTS. Only retain a body when it is proven to represent the same revision; otherwise clear it as the partial-unsend path does.
  - confidence: 0.91

  - body: This validation checks only whether the incoming row ID already represents another handle.   - confidence: 0.96
