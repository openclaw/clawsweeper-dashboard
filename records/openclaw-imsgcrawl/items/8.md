## Summary

Keep this PR open: it introduces a substantial archive-contract and persistent-schema change that needs explicit maintainer approval for the new default sync behavior, and it still lacks inspectable real-behavior proof.

## What This Changes

The branch migrates archives to schema v2, preserves deletion tombstones and iMessage revision events, changes sync to merge by default with `--restore` for replacement, and hides tombstoned data from normal reads and search.

## Best Possible Solution

Preserve replacement as the default until a maintainer explicitly approves merge-by-default semantics; if approved, land the migration only with redacted live CLI proof covering both an upgraded archive and a fresh archive.
