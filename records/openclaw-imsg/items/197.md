## What This Changes

The branch moves external-process timeout and termination behavior into a shared helper, then uses it to cap `osascript` waits for message-send fallback and reaction automation while preserving the existing attachment-conversion timeout.

## System Context

The imsg CLI uses Messages automation through `/usr/bin/osascript` for fallback sending and reactions. Those subprocesses return either a normal exit result or an AppleScript error to the CLI/RPC caller, so a bounded wait protects the command from an indefinitely hung automation process.
