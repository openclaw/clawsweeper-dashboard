## What This Changes

History and watch output should resolve `poll.vote.option_text` for native iMessage poll choices added after the original poll creation row.

## Best Possible Solution

Review and land the linked candidate PR, or replace it with an equivalent narrow fix that merges original poll options with native add-choice update rows while preserving existing poll JSON fields.

## Solution Assessment

Yes, the narrow maintainable fix is to extend poll option lookup to include associated option update rows and add a deterministic regression fixture for the original-poll vote shape.
