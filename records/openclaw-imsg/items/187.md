## What This Changes

This PR makes `imsg rpc` skip an undecided Contacts permission prompt only when stdin is noninteractive, while retaining prompt-capable Contacts setup for interactive terminals.

## System Context

`imsg rpc` opens the Messages database and creates a Contacts resolver before it starts its stdin/stdout JSON-RPC server. The resolver supplies optional contact-name enrichment to RPC methods, so its authorization policy determines whether a headless host can begin serving requests.
