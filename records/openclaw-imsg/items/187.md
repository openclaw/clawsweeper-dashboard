## What This Changes

This PR selects a non-blocking Contacts policy for noninteractive `imsg rpc` stdin, preserves the interactive permission-request path, adds policy tests, and adds a changelog entry.

## System Context

`imsg rpc` opens a Messages store and creates an optional Contacts resolver before it starts its stdin/stdout JSON-RPC server. A Contacts authorization decision at startup therefore determines whether headless automation can begin serving chat and message requests.
