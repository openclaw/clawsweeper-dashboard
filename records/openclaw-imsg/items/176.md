## What This Changes

The PR adds a monotonic 60-second deadline and escalating process termination to ffmpeg attachment conversion, plus a deterministic hung-converter regression test.

## Best Possible Solution

Keep the monotonic bounded wait and escalating termination, restore cross-platform POSIX imports with Darwin/Glibc conditionals, retain the focused regression test, and use the conversion owner’s accepted deadline while keeping timeout failure diagnosable.
