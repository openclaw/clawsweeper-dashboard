## What This Changes

This PR adds a global Vercel `Strict-Transport-Security` header with a two-year `max-age` and `includeSubDomains` for the public site.

## System Context

`vercel.json` supplies edge response headers and host-based redirects for the OpenClaw public site. Browsers cache HSTS from an HTTPS response, then automatically upgrade later requests for the covered host tree to HTTPS.
