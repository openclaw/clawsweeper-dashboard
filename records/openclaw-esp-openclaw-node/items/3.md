## What This Changes

## Best Possible Solution

Keep node-role authorization semantics explicit: either retain empty node scopes and expose the separately granted bounded operator token through a distinct operator-client API, or document and enforce a maintainer-approved node-scope contract; in either case, use one complete representation for signing and JSON and prove pairing plus reconnect on real hardware.
