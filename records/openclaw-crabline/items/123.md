## Summary

This member-authored draft should remain open because the blanket Microsoft Teams acknowledgement incorrectly treats every non-message activity—including native `invoke` activities—as successfully handled with an empty response.

## What This Changes

Tightens webhook field normalization across Google Chat, Matrix, Microsoft Teams, Slack, Zalo, and the shared local mock while acknowledging selected non-message callbacks without recording them.

## Best Possible Solution

Restrict no-content Teams acknowledgements to explicitly supported lifecycle activity types, handle native `invoke` responses separately or reject unsupported invokes clearly, add focused regression coverage, and leave release notes to the release process.
