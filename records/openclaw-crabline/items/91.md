## What This Changes

## Best Possible Solution

Keep genuinely unauthenticated public ingress fail-closed, recognize each provider-native authenticated mode—including Feishu verification tokens—provide explicit upgrade diagnostics for newly invalid configurations, remove the changelog edit, and verify accepted and rejected requests against real provider-shaped clients.
