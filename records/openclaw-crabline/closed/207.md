## Summary

This PR remains necessary because its recorder and Windows lock-root hardening is not on current main, but it is not merge-ready: the unchanged head still replaces the existing Windows script fallback with a mandatory Job Object helper, so ordinary configured script execution can stop when helper setup is unavailable. The prior P1 compatibility finding therefore remains open.

## What This Changes

The branch hardens recorder identity locking and Windows lock-root validation, requires Windows script Job Object containment, and expands cross-platform regression coverage.

## Best Possible Solution

Keep the recorder and lock-root hardening, preserve direct-shell execution as the default compatibility path, and offer mandatory Job Object containment only through an explicit strict setting with focused tests and live Windows proof for both modes.
